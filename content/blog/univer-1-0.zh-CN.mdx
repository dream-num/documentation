嘿，各位开发者，自 2026 年 4 月起，我们就一直在筹备 Univer 的大版本更新。今天，很高兴终于可以和大家分享这个版本：**Univer 1.0 正式发布。**

**Univer Team** 从电子表格出发，始终致力于让每一位 builder 在自己的应用里构建符合自身需求的办公体验。

过去数月的改进集中在大表格的滚动和计算、长文档的分页、复杂画布的渲染，以及 Office 文件导入后的格式与内容还原度。

这次更新包含了我们最初承诺的 **Univer Docs 和 Univer Slides**，也带来了此前从未对外公布的 **Univer Boards、Univer Bases 和 Univer PDFs**。加上持续改进的 Univer Sheets，六大编辑器覆盖电子表格、文档、演示文稿、白板、多维表格和 PDF，你可以通过同一套 SDK 将它们集成到自己的产品中。

各编辑器沿用 Univer 的插件和命令体系，各自提供面向内容的 Facade API。应用可以按需组合它们，继续使用自己的导航、用户体系和业务数据。

你可以在 [Univer Office](https://office.univer.ai) 中体验这些编辑器，或参考[入门指南](#开始构建)接入自己的项目。

### Univer Sheets

这次我们重整了公式引擎，将公式注册和计算调度统一到共享模块中，供 Sheets、Bases、Docs 行内公式和公式形状复用。Sheets 还优化了增量计算和共享公式查找，减少单元格修改引起的重复计算。

1.0 也完善了结构化引用、数组公式、隐式交叉和 Excel 日期系统的计算行为，减少已有工作簿导入后结果不一致的情况。新增的[三维引用](/guides/sheets/features/core/formula#三维引用)可以汇总连续工作表中的数据，例如 `=SUM(Jan:Mar!B2)` 会计算工作簿中从 `Jan` 到 `Mar` 各张工作表的 B2 单元格总和。

现在，公式可以引用其他工作簿的数据。在同一计算环境中加载来源工作簿后，就可以在汇总表中计算 `Sales.xlsx` 的销售额：

```text
=SUM('[Sales.xlsx]Data'!B2:B100)
```

应用还可以为来源配置稳定的文档 ID 绑定，具体方式见[跨工作簿引用](/guides/sheets/features/core/formula#跨工作簿引用)。

工作表中的形状也可以绑定公式。例如，用 `=SUM(B2:B100)` 在一个形状中展示销售总额，数据变化并重新计算后，形状中的结果随之更新。形状和连接线还支持跟随行列结构变化，按锚定方式调整位置与尺寸。

透视表增加了日期分组、更多布局，以及百分比、差异和累计等值显示方式。新增的[透视图](/guides/sheets/features/pivot-chart)与关联的透视表共用字段、筛选和排序配置，随着报表的分析维度一起更新。

例如，一份销售报表可以先按月份和地区汇总，再显示各地区占总额的比例，最后用透视图呈现结果。

普通图表也扩展了<span className="whitespace-nowrap"><UniverIcon name="HistogramChartIcon" aria-hidden="true" className="mr-1 inline size-4 align-[-0.125em]" />直方图</span>、<span className="whitespace-nowrap"><UniverIcon name="TreemapChartIcon" aria-hidden="true" className="mr-1 inline size-4 align-[-0.125em]" />矩形树图</span>、<span className="whitespace-nowrap"><UniverIcon name="SunburstChartIcon" aria-hidden="true" className="mr-1 inline size-4 align-[-0.125em]" />旭日图</span>、<span className="whitespace-nowrap"><UniverIcon name="GaugeChartIcon" aria-hidden="true" className="mr-1 inline size-4 align-[-0.125em]" />仪表盘图</span>等类型，并增加了多级分类轴、隐藏数据控制和 SVG 导出。这些能力由共享图表引擎提供，再接入不同的编辑器。了解更多：[图表指南](/guides/sheets/features/charts)。

### Univer PDFs

PDFs 支持查看和编辑 PDF、管理页面、添加文本、图片、表格与批注，再按需要导出或打印。导入的源文档与编辑数据分别保存。

具体功能与接入方式见 [PDF 编辑指南](/guides/pdfs/features/core/editing)。

## 跨文档嵌入与编辑

1.0 支持在一份 Univer 文档中嵌入其他类型的文档，并保留其原生编辑能力。例如，在 Docs 正文中嵌入 Sheets 后，用户仍然可以修改单元格、输入公式。在 Slides 页面中嵌入 Boards 时，也可以继续编辑白板中的形状和连接线。

嵌入也可以出现在工作簿标签页、幻灯片页面列表或多维表格的数据表列表中。例如，你可以为一份工作簿增加 Docs 标签页，用来编写报表说明。切换到这个标签页，就能使用 Docs 的菜单和编辑工具。

被嵌入的文档通过引用与主文档关联，各自保留独立的数据模型，由应用分别保存。支持的嵌入位置、编辑器组合和接入方式见[跨文档嵌入指南](/guides/fundamentals/features/embed)。

## 为触屏设计的移动端体验

1.0 的移动端支持覆盖 **Sheets、Docs、Slides、Boards 和 Bases**。工具栏、属性面板和内容导航都针对小屏幕重新安排，触摸手势与软键盘弹出后的布局也有调整。

- **Sheets：** 改进单元格选择、编辑和公式输入，并为图表、透视表等高级功能提供移动端面板。
- **Docs：** 支持触摸文字选择、双指缩放与移动端格式工具栏，图片、链接和评论也有相应的操作界面。
- **Slides：** 提供页面列表、画布编辑和移动端放映，可通过轻点或滑动切换幻灯片。
- **Boards：** 通过拖动和双指手势平移、缩放画布，并使用底部面板插入和设置形状、连接线等对象。
- **Bases：** 围绕记录编辑、数据表与视图切换组织界面，提供适合触屏的字段输入、筛选与排序面板。

接入时使用各编辑器的移动端 UI 插件，桌面端与移动端沿用相同的数据模型。

## 性能优化

**Sheets 减少重复绘制和计算。** 滚动时复用已有画面，增量绘制新进入视口的区域。批量粘贴和公式更新也减少了重复工作。改进后的增量计算和共享公式查找，让局部数据变化尽量只触发相关计算。

**Docs 优先处理用户正在阅读和编辑的内容。** 长文档可以分步排版，先准备当前操作位置附近的页面，再继续处理后续内容。局部修改时，编辑器会尽可能复用已有的排版结果。应用还可以配置布局 Worker，将排版工作移到后台线程。

**Boards 和 Slides 减少复杂画布中的无关刷新。** 大场景绘制、拖动过程中的渲染和形状缓存复用都有优化，演示文稿缩略图也按可见范围调度更新。

日常体验的改进还包括 Ribbon 布局、深色主题和 RTL 支持。评论、权限控制和版本历史也覆盖了更多编辑器，快照比较 API 则帮助应用展示修改前后的差异。

## Office 文件兼容性

**Server SDK** 的 Exchange 支持导入 XLS / XLSX 表格、DOC / DOCX 文档，以及 PPT / PPTX 演示文稿，编辑后可以分别导出为 XLSX、DOCX 和 PPTX。电子表格还支持 CSV 和 TSV 的导入导出。

具体内容的兼容性改进包括：

- **电子表格：** 完善 Excel 日期系统、公式缓存和引用的处理，改进图表、透视表与公式的兼容性。
- **文档：** 改进分节、分页、列表编号、边框和图文排版。
- **演示文稿：** 完善 PPTX 文本、形状、背景和图表的还原与编辑。

文件转换也可以直接在 Node.js 中完成，供批量处理和后台任务使用。具体接入方式见 [Server SDK 文件转换指南](/server/import-export/node)，以及 [Sheets](/guides/sheets/features/import-export)、[Docs](/guides/docs/features/import-export) 和 [Slides](/guides/slides/features/import-export) 的导入导出指南。

## Univer Office SDK：让集成更容易

在实践中我们发现，过去 **Web SDK** 在插件化架构方面的探索，使得产品在前端集成中获得了极大的可扩展性。因此我们也在此次推出了 **Server SDK** 和 **AI SDK**。以便在前端之外的服务端模块，以及供产品内 Agent 获得同样的可扩展性来适配各种场景下的复杂需求。

| SDK | 在应用中的职责 |
| --- | --- |
| [Web SDK](/guides/sheets) | 把编辑器放进你的界面，通过插件、主题和 Facade API 连接交互与业务逻辑。 |
| [Server SDK](/server) | 把协同与文件转换接入你的后端，连接应用已有的身份、权限、存储和部署环境。 |
| [AI SDK](/ai) | 提供构建 Office CLI 的 TypeScript 能力，让产品中的 Agent 和自动化程序读取、修改和检查内容。 |

在报表应用中，Server SDK 负责 Excel 文件转换，Web SDK 提供表格编辑界面。产品中的 Agent 则通过 AI SDK 读取数据、修改公式、生成图表，也可以对结果进行[视觉检查](/ai/visual-inspection)。

## 从 0.25 升级

<Callout type="warning" title="0.25 系列维护政策">
  **自 Univer 1.0 发布之日起，0.25 系列将仅提供为期一年的安全相关更新。** 如需后续的新功能和其他改进，请升级至 1.0。
</Callout>

1.0 包含 API 清理和包结构调整。已有项目升级时，建议先检查以下几处：

1. **运行环境和构建方式。** Web SDK 的编译目标从 Chrome 70 提高到 Chrome 88，支持基线为 Chrome / Edge 88、Firefox 90、Safari 14.1 和 Electron 12。Preset 移除了原有的 UMD 构建入口，使用脚本标签加载 Preset 的项目需要调整为模块构建方式。
2. **旧 Facade 调用。** 已弃用的入口被移除，例如 `createUniverSheet()`、`getActiveUniverSheet()` 和 `getUniverSheet()`，分别使用 `createWorkbook()`、`getActiveWorkbook()` 和 `getWorkbook()`。旧事件 Hook 需要迁移到 `addEvent()`。
3. **导入导出。** Exchange API 按产品拆分。例如，表格导入使用 `@univerjs-pro/sheets-exchange-client/facade` 中的 `importSheetToSnapshotAsync()`，替代旧的 `importXLSXToSnapshotAsync()`。同时检查插件注册和服务配置，见[导入导出指南](/guides/sheets/features/import-export)。
4. **高级功能与自定义扩展。** Docs、图表和形状的 Facade 有调整。包结构也有变化，历史记录改为共享模块与各产品插件组合，部分公式服务和类型移至 `engine-formula`。手动注册插件或使用底层服务的项目，应对照当前[功能指南](/guides/sheets/features/core)和 [API 参考](/reference)检查导入、参数和返回值。
5. **自定义代码的执行方式。** Uniscript 已移除。通过 RPC 传递函数源码并在远端反序列化的自定义公式注册路径已关闭。需要在 Worker 中使用的可信函数，应随 Worker 代码部署，并在执行端注册。

升级时保持相互依赖的 Univer 功能包版本一致，再用现有的典型文档检查编辑、保存、撤销、导入导出和协同流程。只使用某一类编辑器的项目，可以继续按需安装相应功能。
