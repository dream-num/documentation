For current plans, prices, and usage limits, see [Pricing](https://univer.ai/pricing/). Direct purchasing questions to the contact-sales entry on that page. This guide covers configuration.

You obtain a License from the [Univer website](https://univer.ai), which also lists the licensing options. A License consists of two files: `license.txt` holds the License content, and `licenseKey.txt` holds the key the server uses to verify it.

| Where it runs                           | Files needed                       | Without a License                                                    |
| --------------------------------------- | ---------------------------------- | -------------------------------------------------------------------- |
| [Web SDK](#web-sdk) | `license.txt` | Client features and local printing work, with watermarks on affected output |
| [Collaboration SDK](#collaboration-sdk) | `license.txt` and `licenseKey.txt` | Free tier: 1 collaboration node, 3 collaborative editing connections |
| [Exchange](#exchange)                   | `license.txt` and `licenseKey.txt` | Free tier: 10 watermark-free exports per month; further complete exports carry watermarks |

At each of these locations you provide the file contents. The License determines which features are available. Whether a user may view or edit a document is a separate matter, governed by the application's [identity and authorization](/server/collaboration/identity-and-authorization).

## Web SDK [#web-sdk]

Charts, sparkline editing, PivotTable and dashboard creation, and local printing all work without a signed client license; this includes the Sheets print and screenshot APIs. Chart, print, and screenshot output may carry a License watermark, depending on the feature and its authorization. Collaboration and Exchange each use their own server-side License.

Freemium provides evaluation access with watermarks and usage limits. Freemium, Business, and Enterprise support unlimited print jobs and pages under their licenses. Freemium printouts carry watermarks. Printing, including saving as PDF through the print function, uses zero export quota. PDF generation through file conversion follows the applicable export rules. Commercial production deployments require a valid Business or Enterprise license. Commercial and dedicated local licenses retain their own entitlements and usage terms.

### Plugin mode [#in-plugin-mode]

`UniverLicensePlugin`

| <span data-config-options="">Option</span> | Type | Default | What it does |
| --- | --- | --- | --- |
| `license` | `string` |  | Contents of the client License file. |

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE', // content of license.txt
})
```

Register `UniverLicensePlugin` on the existing Univer instance before the other plugins.

### Preset mode [#in-preset-mode]

`UniverSheetsAdvancedPreset`

| <span data-config-options="">Option</span> | Type | Default | What it does |
| --- | --- | --- | --- |
| `license` | `string` |  | Contents of the client License file. |

```ts
UniverSheetsAdvancedPreset({
  // Keep your other options.
  license: 'YOUR_LICENSE', // content of license.txt
})
```

Add `license` to the existing preset options; the example above uses `UniverSheetsAdvancedPreset`. Collaborative applications configure a License in the browser as well. The browser example in [Collaboration Quick Start](/server/collaboration/quick-start) shows where the License plugin sits relative to the collaboration plugins.

## Collaboration SDK [#collaboration-sdk]

```ts
import { UniverCollabService } from '@univerjs-pro/collaboration-service'

const collabService = new UniverCollabService({
  dbAdapter,
  license: 'YOUR_LICENSE', // content of license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // content of licenseKey.txt
})
```

When `license` and `licenseKey` are omitted, `UniverCollabService` reads the `UNIVER_LICENSE` and `UNIVER_LICENSE_KEY` environment variables. If neither source is set, it runs on the free tier. The License determines the number of collaborative editing connections, the authorized domains, the number of collaboration nodes, and which document types are covered; see [Collaboration SDK License](/server/collaboration/license).

## Exchange [#exchange]

```ts
import { configureExchange } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: 'YOUR_LICENSE', // content of license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // content of licenseKey.txt
})
```

This call is optional. Exchange reads `UNIVER_LICENSE` and `UNIVER_LICENSE_KEY` on the first export or quota query, and uses the free tier when neither is set. Imports consume no quota; exports are counted against the License. See [Exchange License](/server/import-export/license) for quota queries and errors.

When Collaboration SDK and Exchange run in the same process, set the environment variables once:

```bash
export UNIVER_LICENSE="$(cat license.txt)"
export UNIVER_LICENSE_KEY="$(cat licenseKey.txt)"
```

## Check the configuration [#check]

Reopen the application and test the features you need. If watermarks or License restrictions persist, verify that the License content is complete, still valid, and covers the feature and release in question. In plugin mode, also verify that `UniverLicensePlugin` is registered before the other plugins. If the issue persists, contact the License provider.
