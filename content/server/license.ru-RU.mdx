О текущих планах, ценах и ограничениях использования см. [ценообразование](https://univer.ai/pricing/). Вопросы о прямых покупках для входа в контактные продажи на этой странице. Это руководство охватывает конфигурацию.

Вы получаете Лицензию от [Сайт Univer](https://univer.ai), в которой также перечислены варианты лицензирования.Лицензия состоит из двух файлов: `license.txt` содержит Лицензионный контент, а `licenseKey.txt` имеет ключ, который сервер использует для его проверки.

| Где работает | Нужные файлы | Без лицензии |
| --- | --- | --- |
| [Web SDK](#web-sdk) | `license.txt` | Функции клиента и локальные печатные работы с водяными знаками на затронутом выходе |
| [Collaboration SDK](#collaboration-sdk) | `license.txt` и `licenseKey.txt` | Бесплатная версия: 1 узел совместного редактирования, 3 подключения совместного редактирования |
| [Exchange](#exchange) | `license.txt` и `licenseKey.txt` | Бесплатная версия: 10 экспортов в месяц |

В каждом из этих мест вы предоставляете содержимое файла. Лицензия определяет, какие функции доступны. Может ли пользователь просматривать или редактировать документ, это отдельный вопрос, регулируемый [удостоверение личности и разрешение](/server/collaboration/identity-and-authorization) приложения.

## Web SDK [#web-sdk]

Диаграммы, редактирование блеска, создание PivotTable и приборной панели и локальная печать все работают без подписанной клиентской лицензии; это включает в себя API-интерфейсы печати листов и скриншотов. Диаграмма, печать и вывод скриншита могут нести водяной знак Лицензии, в зависимости от функции и ее авторизации. Сотрудничество и обмен каждый используют свою собственную лицензию на стороне сервера.

### Режим плагинов [#in-plugin-mode]

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое файла клиентской лицензии. |

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE', // содержимое license.txt
})
```

Зарегистрируйте `UniverLicensePlugin` на существующем экземпляре Univer перед другими плагинами.

### Режим пресетов [#in-preset-mode]

`UniverSheetsAdvancedPreset`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое файла клиентской лицензии. |

```ts
UniverSheetsAdvancedPreset({
  // Сохраните остальные параметры.
  license: 'YOUR_LICENSE', // содержимое license.txt
})
```

Добавьте `license` к существующим предустановленным параметрам; в приведенном выше примере используется `UniverSheetsAdvancedPreset`. Совместные приложения также настраивают Лицензию в браузере. В примере браузера в [Сотрудничество Quick Start](/server/collaboration/quick-start) показано, где находится плагин Лицензии относительно плагинов совместной работы.

## Collaboration SDK [#collaboration-sdk]

```ts
import { UniverCollabService } from '@univerjs-pro/collaboration-service'

const collabService = new UniverCollabService({
  dbAdapter,
  license: 'YOUR_LICENSE', // содержимое license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // содержимое licenseKey.txt
})
```

Когда `license` и `licenseKey` опущены, `UniverCollabService` считывает переменные среды `UNIVER_LICENSE` или `UNIVER_LICENSE_KEY`. Если ни один из источников не установлен, он работает на свободном уровне. Лицензия определяет количество соединений для совместного редактирования, авторизованные домены, количество узлов совместной работы и типы документов, которые охватываются; см. [Лицензия Collaboration SDK](/server/collaboration/license) .

## Exchange [#exchange]

```ts
import { configureExchange } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: 'YOUR_LICENSE', // содержимое license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // содержимое licenseKey.txt
})
```

Этот вызов необязателен. Биржа читает `UNIVER_LICENSE` и `UNIVER_LICENSE_KEY` по первому запросу на экспорт или квоту и использует свободный уровень, когда ни один из них не установлен. Импорт не потребляет квоту; экспорт засчитывается против Лицензии. См. [Лицензия Exchange](/server/import-export/license) для запросов на квоты и ошибок.

Если Collaboration SDK и Exchange работают в одном процессе, переменные окружения достаточно задать один раз:

```bash
export UNIVER_LICENSE="$(cat license.txt)"
export UNIVER_LICENSE_KEY="$(cat licenseKey.txt)"
```

## Проверка настройки [#check]

Если водяные знаки или ограничения Лицензии сохраняются, проверьте, что содержимое Лицензий является полным, все еще действительным, и охватывает эту функцию и выпуск, о котором идет речь. В режиме плагина также проверьте , что `UniverLicensePlugin` зарегистрирован перед другими плагинами. Если проблема сохраняется, обратитесь к поставщику Лицензионных услуг.
