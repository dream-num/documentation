На [сайте Univer](https://univer.ai) можно узнать варианты лицензирования и получить лицензию. Лицензия состоит из двух файлов: `license.txt` содержит саму лицензию, а `licenseKey.txt` — ключ, которым сервер её проверяет.

| Где работает | Нужные файлы | Без лицензии |
| --- | --- | --- |
| [Web SDK](#web-sdk) | `license.txt` | Бесплатные функции |
| [Collaboration SDK](#collaboration-sdk) | `license.txt` и `licenseKey.txt` | Бесплатная версия: 1 узел совместного редактирования, 3 подключения совместного редактирования |
| [Exchange](#exchange) | `license.txt` и `licenseKey.txt` | Бесплатная версия: 10 экспортов в месяц |

Указывайте содержимое файлов. Лицензия определяет доступные функции; кто может просматривать или редактировать документ, определяют [идентификация и авторизация](/server/collaboration/identity-and-authorization) вашего приложения.

## Web SDK [#web-sdk]

### Режим плагинов [#in-plugin-mode]

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE', // содержимое license.txt
})
```

Зарегистрируйте `UniverLicensePlugin` в существующем экземпляре Univer раньше остальных плагинов.

### Режим пресетов [#in-preset-mode]

```ts
UniverSheetsAdvancedPreset({
  // Сохраните остальные параметры.
  license: 'YOUR_LICENSE', // содержимое license.txt
})
```

Добавьте `license` в существующую конфигурацию пресета; в примере используется `UniverSheetsAdvancedPreset`. Приложения совместного редактирования тоже настраивают лицензию в браузере. Браузерный пример в [быстром старте совместного редактирования](/server/collaboration/quick-start) показывает, где регистрируется плагин лицензии рядом с плагинами совместного редактирования.

## Collaboration SDK [#collaboration-sdk]

```ts
import { UniverCollabService } from '@univerjs-pro/collaboration-service'

const collabService = new UniverCollabService({
  dbAdapter,
  license: 'YOUR_LICENSE', // содержимое license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // содержимое licenseKey.txt
})
```

Если `license` и `licenseKey` не переданы, `UniverCollabService` читает переменные окружения `UNIVER_LICENSE` и `UNIVER_LICENSE_KEY`; если нет ни того, ни другого, работает бесплатная версия. Лицензия определяет подключения совместного редактирования, разрешённые домены, узлы совместного редактирования и типы документов; см. [Лицензия Collaboration SDK](/server/collaboration/license).

## Exchange [#exchange]

```ts
import { configureExchange } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: 'YOUR_LICENSE', // содержимое license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // содержимое licenseKey.txt
})
```

Этот шаг можно пропустить: Exchange читает переменные окружения `UNIVER_LICENSE` и `UNIVER_LICENSE_KEY` при первом экспорте или запросе квоты, а если они тоже не заданы, работает бесплатная версия. Exchange считает экспорты по лицензии, импорт квоту не расходует; запрос квоты и обработку ошибок см. в разделе [Лицензия Exchange](/server/import-export/license).

Если Collaboration SDK и Exchange работают в одном процессе, переменные окружения достаточно задать один раз:

```bash
export UNIVER_LICENSE="$(cat license.txt)"
export UNIVER_LICENSE_KEY="$(cat licenseKey.txt)"
```

## Проверка настройки [#check]

Откройте приложение заново и проверьте нужные функции. Если водяные знаки или ограничения лицензии остались, убедитесь, что содержимое лицензии полное, срок её действия не истёк и она покрывает нужную функцию и версию; в режиме плагинов также проверьте, что `UniverLicensePlugin` зарегистрирован раньше остальных плагинов. Если проблема не решена, обратитесь к поставщику лицензии.
