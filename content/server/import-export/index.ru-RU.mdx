Чтобы открыть Excel в Univer, сначала преобразуйте файл в данные редактора. При экспорте преобразуйте изменённые данные обратно в Excel. Серверный `@univerjs-pro/exchange-node` выполняет преобразование, а браузер загружает файлы, открывает документы и скачивает результаты.

## Без совместного редактирования

Например, пользователь загружает Excel, редактирует его на странице и скачивает результат в Excel.

1. Браузер загружает файл, сервер преобразует его в данные Univer и возвращает их.
2. Браузер открывает таблицу с этими данными для редактирования.
3. При экспорте браузер отправляет изменённые данные серверу, который создаёт файл Excel.

Сервис совместного редактирования здесь не нужен. «Снимок» в браузерных API — это используемые здесь данные документа. Импорт и экспорт снимков всё равно требуют серверного преобразования. Для сохранения и дальнейшего продолжения работы приложение должно хранить эти данные.

Установка и применение модуля описаны в [Импорте и экспорте Office](/server/import-export/node). Оттуда же начните, если нужна только обработка файлов в Node.js.

## С совместным редактированием

Например, пользователь импортирует Excel, делится документом с коллегами, редактирует его вместе с ними и затем экспортирует.

1. Сервер преобразует загруженный файл и сохраняет совместный документ.
2. Возвращает ID, который открывает браузер; другие пользователи входят по тому же ID.
3. При экспорте сервер читает актуальное содержимое и создаёт Excel для скачивания.

`unitId` браузерных API — этот ID. Сначала завершите [интеграцию совместного редактирования](/server/collaboration/browser-integration), затем запустите [пример Exchange](/server/collaboration/examples#exchange). Изучайте его браузерный, серверный и преобразующий код вместе.

Перед экспортом дождитесь синхронизации, иначе файл может не содержать последних изменений. Чтение и преобразование совместных документов описано в серверном Office Exchange раздела [Модули расширений](/server/collaboration/extensions).

## Подключение кнопок импорта и экспорта

Когда преобразование на сервере работает, подключите его к странице:

- **Меню Univer или API Facade:** реализуйте загрузку, преобразование, опрос задач и скачивание по [примеру Exchange](/server/collaboration/examples#exchange), затем настройте браузерные плагины. Адреса запросов и форматы ответов должны совпадать.
- **Собственные кнопки:** вызывайте API приложения. После импорта откройте полученные данные или ID, после экспорта скачайте результат.

Настройки браузера см. в [Sheets](/guides/sheets/features/import-export), [Docs](/guides/docs/features/import-export), [Slides](/guides/slides/features/import-export), [Boards](/guides/boards/features/import-export), [Bases](/guides/bases/features/import-export) и [PDFs](/guides/pdfs/features/import-export). Совместный пример использует Sheets. Для остальных проверьте [Импорт и экспорт Office](/server/import-export/node) и форматы своего выпуска.

## Проверка интеграции

Импортируйте реальный файл, отредактируйте и экспортируйте. Откройте его в Office и проверьте изменения, формулы, изображения и макет. Для совместной работы также проверьте доступ других пользователей и сохранность после перезапуска сервера.

До развёртывания замените временные файлы и задачи в памяти хранилищем приложения, ограничьте размеры загрузок и обработайте ошибки и тайм-ауты. Загрузка, опрос задач и скачивание требуют проверки доступа; см. [Идентификация и авторизация](/server/collaboration/identity-and-authorization).
