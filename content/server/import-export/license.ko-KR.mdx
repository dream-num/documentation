Exchange는 `@univerjs-pro/exchange-node`를 실행하는 서버 프로세스 내에서 라이센스를 읽습니다. 변환 자체에 대해서는 [Office 파일 가져 오기 및 내보내기](/server/import-export/node) 를 참조하십시오.

## 인증 설정 [#configure]

`UNIVER_LICENSE` 및 `UNIVER_LICENSE_KEY`를 환경 설정하는 표준 접근법은 다음과 같습니다. `configureExchange`는 다음 선택 사항입니다. SDK는 첫 번째 수출 또는 할당량 쿼리에 한 번 환경을 읽고 프로세스의 나머지 구성을 유지합니다. 변수가 설정되지 않을 때, 무료 적용이 적용됩니다. 변수가 설정되어있을 때, 자격 증명은 유효하지 않습니다, 통화는 오류를 반환하고, 그 자격 증명은 수출에 사용할 수 없습니다.

명시된 구성의 경우 `configureExchange({ license, licenseKey })`를 호출합니다. 함수는 `Promise<void>`을 반환하고 환경을 완전히 무시하므로 새로운 자격 증명을 사용해야 수출을 시작하기 전에 기다립니다.

```ts
import { configureExchange, getExportQuota } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: '<license content>',
  licenseKey: '<licenseKey content>',
})

const quota = await getExportQuota()
```

라이센스 제공자가 제공하는 `license` 및 `licenseKey` 콘텐츠는 파일에 접근하지 않습니다. 두 값을 함께 설정하고 응용 프로그램의 비밀 관리 시스템에서 읽으십시오.

| 입력 | 동작 |
| --- | --- |
| `configureExchange`를 호출하지 않음 | 두 환경 변수는 첫 번째 사용에 읽습니다. 변수가 설정되지 않을 때 무료 적용. |
| `configureExchange({ license, licenseKey })` | 명시된 자격 증명만 사용됩니다. 환경은 무시됩니다. |
| `configureExchange({})` | 자유롭게 선택되어 있습니다. 환경은 무시됩니다. |
| 선택된 소스에서 1개의 credential만 | 호출은 `INVALID_ARGUMENT`를 반환합니다. 다른 필드는 다른 소스에서 채워지지 않습니다. |

완전한 환경 설정이 읽기되면 나중에 작동이 실패하더라도 고정됩니다. 런타임에서 기본 자격 증명을 대체하려면 `configureExchange`를 호출하고 기다립니다. 실패한 통화는 이전 구성을 남겨 새로운 수출을 시작하기 전에 오류를 처리합니다.

ESM 및 CommonJS는 동일한 JavaScript 컨텍스트 내에서 단일 구성을 공유합니다. 각 `worker_threads` Worker는 자체 또는 초기화해야 합니다. 수출은 공공 수출 방식이 호출되었을 때 배치 된 구성을 사용합니다. 나중에 credentials 변경은 이미 시작된 수출에 영향을 미치지 않습니다.

### 한 번의 작업에 인증 지정

기본 구성을 변경하지 않고 단일 통화를 승인하려면, 완전한 `license` 및 `licenseKey` 쌍을 수출 API 또는 `getExportQuota`의 옵션으로 전달하십시오. 다음 예제는 같은 자격 증명과 할당량 및 수출을 쿼리합니다.

```ts
import { UniverInstanceType } from '@univerjs/core'
import { ExchangeFormat, exportToBuffer, getExportQuota } from '@univerjs-pro/exchange-node'

const credentials = { license: '<license content>', licenseKey: '<licenseKey content>' }
const quota = await getExportQuota(credentials)
const output = await exportToBuffer(workbook, {
  type: UniverInstanceType.UNIVER_SHEET,
  format: ExchangeFormat.XLSX,
  ...credentials,
})
```

파일 내보내기, Snapshot 수출 및 옵션 PDF 수출은 동일한 쌍을받습니다. 두 필드가 omitted 때, 기본 구성이 적용됩니다; 하나의 필드가 공급될 때, 호출은 `INVALID_ARGUMENT`를 반환합니다. 명시된 쌍은 기본 구성 또는 환경에서 완료되지 않으며 빈 문자열은 omitted 필드로 계산되지 않습니다. 잘못된 자격 증명 반환 `LICENSE_INVALID`, SDK는 기본 상용 라이센스로 돌아 가지 않습니다.

### 선택적 PDF 지원

PDF 확장 패키지를 설치하고, 인증을 설정하기 전에 해당 진입점을 가져옵니다.

```sh
pnpm add @univerjs-pro/exchange-node @univerjs-pro/exchange-pdf-node-binding
```

```ts
import '@univerjs-pro/exchange-node/pdf'
import { configureExchange, getExportQuota } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: '<license content>',
  licenseKey: '<licenseKey content>',
})

const quota = await getExportQuota()
```

수입은 PDF 지원 및 기본 구성 요소로드를 등록하면 먼저 사용됩니다. PDF는 `importBuffer`, `importFile`의 `exportToBuffer` 및 `exportToFile`와 같은 `UniverInstanceType.UNIVER_PDF`과 `ExchangeFormat.PDF`를 사용합니다. PDF 만 처리하는 응용 프로그램은 Office 네이티브 구성 요소가 필요하지 않습니다. 환경 기반 구성은 PDF뿐만 아니라 적용됩니다.

## 남은 할당량 조회 [#quota]

`getExportQuota({ license, licenseKey })`는 허가 주식이 있는 사무실과 PDF 할당량을 위한 `Promise<ExportQuota>`를 반환합니다. 자격 증명이 omitted 때, 통화 쿼리는 기본 구성을 쿼리합니다. 통화는 단위 유형을 받아들이지 않으며 특정 수출 유형이 허용되지 않다는 것을 검사하지 않습니다; 그것은 수출 도중 발생합니다.

쿼리는 소모하거나 예비 할당량, 그리고 그것은 SDK 버전, 활성화 시간, 또는 수출 유형 제목을 확인하지 않습니다. 0 균형은 여전히 성공적인 스냅 샷을 반환합니다. 다른 요청은 즉시 할당량을 소비 할 수 있으므로 실제 수출에 의해 반환된 오류를 처리 할 수 있습니다.

승인이 효력을 발생하기 전에, 제한된 할당량에 대한 쿼리는 첫 번째 승인 월 스냅 샷을 반환, 그 `periodStart`는 미래에 속한다. 성공적인 쿼리, 또는 `valid` 상태, 수출이 허용되지 않는 의미하지 않습니다. SDK는 버전, 활성화, 유형 제목, 사용 가능한 할당량 및 수출 중 통화를 확인합니다.

| 필드 | 타입 | 의미 |
| --- | --- | --- |
| `licenseStatus` | `'not_configured' \| 'expired' \| 'valid'` | 수출 가입은 구성되지 않습니다, 만료, 또는 아직 만료되지 않습니다. `valid`는 수출입이 통과 한 것을 의미하지 않습니다. 잘못된 자격 증명은 오류를 반환합니다. |
| `expiresAt` | `string \| null` | UTC ISO 타임스탬프로 내보내기 구독의 유효성. 아무것도 구성하거나 만료되지 않는 경우 `null`는 적용되지 않습니다. |
| `observedAt` | `string` | 이 스냅샷의 UTC ISO 타임스탬프. |
| `limit` | `number \| null` | 현재 월간 수출 제한. 할당량이 제한 될 때 `null`. |
| `used` | `number \| null` | 현재 달에 있는 성공적인 수출. 할당량이 무제한 때 `null`. |
| `reserved` | `number \| null` | 현재 달에 할당량을 보유하는 Flight 수출. 할당량이 무제한 때 `null`. |
| `remaining` | `number \| null` | `max(0, limit - used - reserved)`로 계산된 수출은, 할당량이 무제한 때 `null`입니다. |
| `periodStart` | `string \| null` | UTC ISO는 매달 할당량 창의 시작을 포함. 첫 번째 기간은 활성화하기 전에 미래에 시작. 할당량이 제한 될 때 `null`. |
| `periodEnd` | `string \| null` | 매달 할당된 할당량 창의 독점적인 UTC ISO 끝. 할당량은 무제한일 때 `null`. |

Free(Freemium)의 할당량은 월별 워터마크 없는 내보내기 허용량이며 전체 내보내기 횟수 제한이 아닙니다. `remaining`이 0이어도 워터마크가 있는 전체 파일을 내보낼 수 있습니다. 이 잔여량만으로 Free 내보내기를 거부하지 마세요. 상업용 구독이 만료되면 Free 규칙이 적용되지만 월별 허용량이 추가로 초기화되거나 상용 운영 사용 권한이 갱신되지는 않습니다.

`periodEnd`는 다음 월 할당량 창의 시작이며 `expiresAt`은 수출 구독의 끝입니다. 구독이 유효하지만, 항상 상업 할당량을 사용합니다. 배출은 무료로 선택하지 않으며 다음 상업 창은 다음 달에 시작합니다. 나머지 무료 할당량으로만 구독 만료 스위치 만 다시 재설정 할 수 없습니다.

할당량이 제한된 스냅샷 예시:

```json
{
  "licenseStatus": "valid",
  "expiresAt": "2027-10-19T23:59:59Z",
  "observedAt": "2026-10-21T09:00:00Z",
  "limit": 500,
  "used": 20,
  "reserved": 1,
  "remaining": 479,
  "periodStart": "2026-10-19T00:00:00Z",
  "periodEnd": "2026-11-19T00:00:00Z"
}
```

## 할당량 사용 [#accounting]

Free(Freemium)는 각 라이선스 월에 워터마크 없는 내보내기 10회를 제공합니다. 해당 월의 11번째 성공한 내보내기부터도 워터마크가 있는 전체 파일을 내보낼 수 있습니다. 워터마크 없는 허용량은 매월 초기화되며 이월되지 않습니다. 상업용 내보내기 할당량, 동시 실행 수 및 버전 권한은 구매한 라이선스에 따릅니다. Free와 상업용 라이선스 모두 파일 크기나 셀 수를 제한하지 않습니다. 현재 기간과 잔여량은 쿼리 결과를 확인하세요.

수입은 수출 허가를 요구하고 수출 할당량은 사용하지 않습니다. 하나의 배포, 사무실 및 PDF 내보내기에서 동일한 상업 라이센스 공유 할당량을 사용합니다. 교환 변환 형식은 [Office 파일 가져 오기 및 내보내기](/server/import-export/node)에 나열됩니다.

성공한 변환은 1회로 계산하며 Buffer 반환을 성공으로 간주합니다. 이후 파일 쓰기, 업로드 또는 다운로드가 실패해도 횟수는 반환되지 않으며 다시 변환에 성공하면 다시 계산됩니다. Free의 워터마크 없는 허용량을 소진해도 이후 워터마크가 있는 전체 파일을 내보낼 수 있습니다. 유효한 상업용 라이선스의 할당량을 소진하면 다음 라이선스 기간 또는 더 높은 할당량의 유효한 라이선스로 업그레이드할 때까지 새 내보내기가 거부됩니다. Free 할당량으로 전환되지 않습니다.

## 오류 처리 [#errors]

`message` 텍스트를 파싱함으로써 구조화된 `code`에 의한 오류를 식별합니다. UI는 로컬화된 메시지에 오류 코드를 매핑할 수 있습니다. 기술 지원에 대한 진단 세부 정보를 유지하십시오.

```ts
import { UniverInstanceType } from '@univerjs/core'
import { ExchangeError, ExchangeFormat, exportToBuffer } from '@univerjs-pro/exchange-node'

try {
  const output = await exportToBuffer(workbook, {
    type: UniverInstanceType.UNIVER_SHEET,
    format: ExchangeFormat.XLSX,
  })
} catch (error) {
  if (error instanceof ExchangeError) {
    // error.code에 맞는 메시지를 표시. 할당량이 부족하면 LICENSE_EXPORT_QUOTA_EXCEEDED
    console.error(error.code)
  } else {
    throw error
  }
}
```

아래 표는 할당량 쿼리 (`getExportQuota`) 또는 실제 수출에서 오류가 발생했는지 여부를 나타냅니다. 두 APIs 반환 약속은 `await` 및 `try/catch`를 요구합니다.

| 코드 | 발생 작업 | 의미와 대응 |
| --- | --- | --- |
| `LICENSE_EXPORT_QUOTA_EXCEEDED` | 내보내기만 | 현재 기간의 상업용 내보내기 할당량이 부족합니다. 할당량을 조회하거나 영업팀에 라이선스 조정을 문의하세요. Free의 워터마크 없는 허용량 소진만으로는 이 오류가 발생하지 않습니다. |
| `LICENSE_CONCURRENCY_TIMEOUT` | 내보내기만 | 수출 concurrency 슬롯에 대한 대기 시간. 다시 제출하기 전에 concurrent 수출을 감소. |
| `LICENSE_UNIT_TYPE_REJECTED` | 내보내기만 | 수출 유형은 라이센스에 의해 포함되지 않습니다, 또는 그것의 유형 제목은 만료되었습니다. 유형을 커버하는 유효한 면허를 제공하십시오. |
| `LICENSE_INVALID` | 조회, 내보내기 | 라이센스는 유효하지 않습니다. 완전한 자격 증명을 확인하거나 라이센스 제공자로부터 업데이트를 요청하십시오. |
| `LICENSE_POLICY_INVALID` | 조회, 내보내기 | 인증 구성은 SDK 요구 사항을 충족하지 않습니다. 라이센스 제공자로부터 업데이트를 요청하십시오. |
| `LICENSE_NOT_YET_EFFECTIVE` | 내보내기만 | 저자화는 아직 효력을 가지고 있지 않았습니다. 그것의 효과적인 날짜 후에 그것을 사용하십시오. |
| `LICENSE_VERSION_NOT_ALLOWED` | 내보내기만 | 현재 SDK 버전이 라이선스 범위 밖임. 맞는 버전을 사용하거나 라이선스를 갱신. |
| `UNSUPPORTED_FORMAT` | 내보내기만 | 형식은 지원되지 않거나 단위 유형과 일치하지 않습니다. 수출 옵션을 확인하십시오. |
| `INVALID_FILE` | 내보내기만 | 변환 입력은 유효하지 않습니다. 입력 내용을 확인합니다. |
| `INCOMPLETE_SNAPSHOT` | 내보내기만 | 수출 자료는 불완전합니다. 완전한 자료 또는 완전한 Snapshot를 제공하십시오. |
| `CONVERSION_FAILED` | 내보내기만 | 변환이 실패했습니다. 오류를 유지하고 입력 내용을 확인합니다. |
| `IO_ERROR` | 내보내기만 | 파일 입력 또는 출력 실패. 변환이 성공하고 출력을 작성하면 수출이 이미 소모되었습니다. |
| `INVALID_ARGUMENT` | 조회, 내보내기 | Arguments 또는 credentials는 불완전합니다. 윤곽을 검사하십시오. |
| `NATIVE_LOAD_FAILED` | 조회, 내보내기 | 네이티브 SDK 구성 요소가 로드에 실패했습니다. 설치 패키지가 실행 환경과 일치한다는 것을 확인하십시오. |
| `LICENSE_USAGE_STATE_INVALID` | 조회, 내보내기 | 라이센스 사용 상태는 검증되지 않습니다. 오류 및 연락처 기술 지원을 유지합니다. |
| `LICENSE_USAGE_STORAGE_ERROR` | 조회, 내보내기 | 라이센스 사용 처리 실패. 오류를 유지, 기술 지원 접촉, 그리고 자동으로 다시 금지하지. |

애플리케이션은 `licenseStatus` 및 `expiresAt`에서 만료된 알림을 구축할 수 있습니다. SDK는 별도의 공지 목록을 반환하지 않습니다.

라이센스 사용 처리 오류 후, 수출이 계산 된 경우 오류에서 infer하지 마십시오. 전체 오류를 유지하고 기술 지원을 접촉하십시오.
