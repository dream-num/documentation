[Univer 웹사이트](https://univer.ai)에서 라이선스 범위를 확인하고 라이선스를 받으세요. 라이선스는 두 파일로 구성됩니다. `license.txt`는 라이선스 내용이고, `licenseKey.txt`는 서버가 검증에 사용하는 키입니다.

| 실행 위치 | 필요한 파일 | 설정하지 않은 경우 |
| --- | --- | --- |
| [Web SDK](#web-sdk) | `license.txt` | 무료 기능 사용 |
| [Collaboration SDK](#collaboration-sdk) | `license.txt`, `licenseKey.txt` | 무료 버전: 협업 노드 1개, 협업 편집 연결 3개 |
| [Exchange](#exchange) | `license.txt`, `licenseKey.txt` | 무료 버전: 매월 내보내기 10회 |

설정할 때는 파일 내용을 넣습니다. 라이선스는 사용할 수 있는 기능을 결정하며, 누가 문서를 보거나 편집할 수 있는지는 애플리케이션의 [인증과 권한](/server/collaboration/identity-and-authorization)이 결정합니다.

## Web SDK [#web-sdk]

### 플러그인 모드 [#in-plugin-mode]

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE', // license.txt의 내용
})
```

기존 Univer 인스턴스에 다른 플러그인보다 먼저 `UniverLicensePlugin`을 등록합니다.

### 프리셋 모드 [#in-preset-mode]

```ts
UniverSheetsAdvancedPreset({
  // 기존의 다른 설정은 그대로 유지
  license: 'YOUR_LICENSE', // license.txt의 내용
})
```

기존 프리셋 설정에 `license`를 추가합니다. 위 예시는 `UniverSheetsAdvancedPreset`입니다. 협업 애플리케이션도 브라우저에서 라이선스를 설정합니다. [협업 빠른 시작](/server/collaboration/quick-start)의 브라우저 예제에서 라이선스 플러그인과 협업 플러그인의 등록 위치를 확인할 수 있습니다.

## Collaboration SDK [#collaboration-sdk]

```ts
import { UniverCollabService } from '@univerjs-pro/collaboration-service'

const collabService = new UniverCollabService({
  dbAdapter,
  license: 'YOUR_LICENSE', // license.txt의 내용
  licenseKey: 'YOUR_LICENSE_KEY', // licenseKey.txt의 내용
})
```

`license`와 `licenseKey`를 생략하면 `UniverCollabService`는 환경 변수 `UNIVER_LICENSE`와 `UNIVER_LICENSE_KEY`를 읽습니다. 둘 다 없으면 무료 버전으로 실행됩니다. 라이선스는 협업 편집 연결 수, 승인된 도메인, 협업 노드 수, 협업할 수 있는 문서 유형을 결정합니다. 자세한 내용은 [Collaboration SDK 라이선스](/server/collaboration/license)를 참고하세요.

## Exchange [#exchange]

```ts
import { configureExchange } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: 'YOUR_LICENSE', // license.txt의 내용
  licenseKey: 'YOUR_LICENSE_KEY', // licenseKey.txt의 내용
})
```

이 단계는 생략할 수 있습니다. Exchange는 첫 내보내기 또는 할당량 조회 시점에 환경 변수 `UNIVER_LICENSE`와 `UNIVER_LICENSE_KEY`를 읽고, 환경 변수도 없으면 무료 버전으로 실행됩니다. Exchange는 라이선스에 따라 내보내기 횟수를 세며, 가져오기는 할당량을 소비하지 않습니다. 할당량 조회와 오류 처리는 [Exchange 라이선스](/server/import-export/license)를 참고하세요.

Collaboration SDK와 Exchange가 같은 프로세스에서 실행되면 환경 변수를 한 번만 설정하면 됩니다.

```bash
export UNIVER_LICENSE="$(cat license.txt)"
export UNIVER_LICENSE_KEY="$(cat licenseKey.txt)"
```

## 설정 확인 [#check]

애플리케이션을 다시 열고 필요한 기능을 사용해 보세요. 워터마크나 라이선스 제한이 남아 있다면 라이선스 내용이 완전한지, 유효 기간 내인지, 해당 기능과 릴리스를 포함하는지 확인하세요. 플러그인 모드에서는 `UniverLicensePlugin`이 다른 플러그인보다 먼저 등록되었는지도 확인합니다. 그래도 해결되지 않으면 라이선스 제공자에게 문의하세요.
