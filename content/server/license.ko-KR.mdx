현재 계획, 가격 및 사용 제한을 위해 [가격 책정](https://univer.ai/pricing/)를 참조하십시오. 그 페이지에 연락처 판매 항목에 직접 구매 질문. 이 가이드는 구성을 다룹니다.

[Univer 웹 사이트](https://univer.ai)에서 라이센스를 취득한 경우 라이센스를 취득할 수 있습니다. 라이센스는 2개의 파일로 구성되어 있습니다: `license.txt`는 라이센스 콘텐츠를 보유하고 있으며 `licenseKey.txt`에는 서버가 확인하는 데 사용됩니다.

| 실행 위치 | 필요한 파일 | 설정하지 않은 경우 |
| --- | --- | --- |
| [Web SDK](#web-sdk) | `license.txt` | 고객 기능 및 현지 인쇄 작업, 영향을받은 출력에 워터 마크 |
| [Collaboration SDK](#collaboration-sdk) | `license.txt`, `licenseKey.txt` | 무료 버전: 협업 노드 1개, 협업 편집 연결 3개 |
| [Exchange](#exchange) | `license.txt`, `licenseKey.txt` | 무료 버전: 매월 내보내기 10회 |

이 위치의 각 파일 내용을 제공합니다. 라이센스는 기능이 사용할 수 있음을 결정합니다. 사용자가 볼 수 있거나 문서를 편집 할 수 있는지 여부는 별도의 문제이며 응용 프로그램의 [ID 및 인증](/server/collaboration/identity-and-authorization)에 의해 지배됩니다.

## Web SDK [#web-sdk]

차트, Sparkline 편집, PivotTable 및 대쉬보드 생성 및 서명된 클라이언트 라이선스 없이 로컬 인쇄 작업; 이것은 시트 인쇄 및 스크린 샷 API를 포함합니다. 차트, 인쇄 및 스크린샷 출력은 기능 및 권한에 따라 라이센스 워터 마크를 수행 할 수 있습니다. 협업 및 Exchange는 각 서버 측 라이선스를 사용합니다.

### 플러그인 모드 [#in-plugin-mode]

`UniverLicensePlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `license` | `string` |  | 클라이언트 라이선스 파일의 내용입니다. |

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE', // license.txt의 내용
})
```

다른 플러그인의 앞에 기존 Univer 인스턴스에 `UniverLicensePlugin` 등록.

### 프리셋 모드 [#in-preset-mode]

`UniverSheetsAdvancedPreset`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `license` | `string` |  | 클라이언트 라이선스 파일의 내용입니다. |

```ts
UniverSheetsAdvancedPreset({
  // 기존의 다른 설정은 그대로 유지
  license: 'YOUR_LICENSE', // license.txt의 내용
})
```

`license`를 기존의 프리셋 옵션에 추가하십시오. 위의 예는 `UniverSheetsAdvancedPreset`을 사용합니다. Collaborative 응용 프로그램은 브라우저에서 라이센스를 구성하고 있습니다. [협업 빠른 시작](/server/collaboration/quick-start)의 브라우저 예는 라이센스 플러그인이 협업 플러그인과 관련이 있는지 보여줍니다.

## Collaboration SDK [#collaboration-sdk]

```ts
import { UniverCollabService } from '@univerjs-pro/collaboration-service'

const collabService = new UniverCollabService({
  dbAdapter,
  license: 'YOUR_LICENSE', // license.txt의 내용
  licenseKey: 'YOUR_LICENSE_KEY', // licenseKey.txt의 내용
})
```

`license`와 `licenseKey`가 omitted일 때, `UniverCollabService`는 `UNIVER_LICENSE` 및 `UNIVER_LICENSE_KEY` 환경 변수를 읽습니다. 소스가 설정되지 않으면 무료 계층에서 실행됩니다. 라이센스는 공동 편집 연결의 수를 결정하고 공인 된 도메인, 협업 노드 수 및 문서 유형이 덮여 있습니다. [Collaboration SDK 라이센스](/server/collaboration/license)를 참조하십시오.

## Exchange [#exchange]

```ts
import { configureExchange } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: 'YOUR_LICENSE', // license.txt의 내용
  licenseKey: 'YOUR_LICENSE_KEY', // licenseKey.txt의 내용
})
```

이 호출은 선택 사항입니다. 교환은 첫 번째 수출 또는 할당량 쿼리에 `UNIVER_LICENSE` 및 `UNIVER_LICENSE_KEY`를 읽고 설정할 때 무료 계층을 사용합니다. 수입은 할당량없이 소비합니다. 수출은 라이센스에 대해 계산됩니다. 할당량 채취 및 오류에 대한 [Exchange 라이센스](/server/import-export/license) 참조하십시오.

Collaboration SDK와 Exchange가 같은 프로세스에서 실행되면 환경 변수를 한 번만 설정하면 됩니다.

```bash
export UNIVER_LICENSE="$(cat license.txt)"
export UNIVER_LICENSE_KEY="$(cat licenseKey.txt)"
```

## 설정 확인 [#check]

응용 프로그램을 열고 필요한 기능을 테스트합니다. 워터 마크 또는 라이센스 제한 persist가되면 라이센스 콘텐츠가 완료되고, 여전히 유효하며 기능 및 문제의 릴리스가 있는지 확인합니다. 플러그인 모드에서는 `UniverLicensePlugin`가 다른 플러그인 이전에 등록되어 있는지 확인합니다. 문제가 지속되면 라이센스 공급자에게 문의하십시오.
