---
title: 라이선스
description: Univer Office SDK 라이선스를 발급받아 브라우저 애플리케이션에 설정합니다.
---

라이선스가 필요한 기능은 [Univer 웹사이트](https://univer.ai)에서 제공되는 라이선스 옵션을 확인하고 발급받으세요. 프로젝트에서 사용하는 프리셋 모드 또는 플러그인 모드로 **클라이언트 라이선스 내용**을 설정하세요.

## 프리셋 모드 [#in-preset-mode]

기존 프리셋 설정에 `license`를 추가하세요. 다음은 `UniverSheetsAdvancedPreset` 예제입니다.

```ts
UniverSheetsAdvancedPreset({
  // Keep your other options and replace this placeholder with the client license content.
  license: 'YOUR_CLIENT_LICENSE',
})
```

라이선스 파일 경로가 아니라 라이선스 내용을 전달하세요.

## 플러그인 모드 [#in-plugin-mode]

기존 Univer 인스턴스에서 다른 플러그인보다 먼저 `UniverLicensePlugin`을 등록하세요.

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_CLIENT_LICENSE',
})
```

## 공동 편집 애플리케이션

공동 편집 애플리케이션도 브라우저에서 라이선스를 설정합니다. [Office 빠른 시작](/server/collaboration/quick-start)의 브라우저 예제는 공동 편집 플러그인과 함께 라이선스 플러그인을 등록할 위치를 보여 줍니다. 브라우저와 서버 패키지는 [SDK 환경 및 버전 요구 사항](/server/requirements)에 맞춰 통일하세요.

라이선스는 사용 가능한 기능을 결정하고, 애플리케이션 권한은 문서를 보거나 편집할 수 있는 사용자를 결정합니다. 라이선스를 설정한 뒤 [서버 통합](/server)에 따라 로그인과 문서 권한을 연결하세요.

## 설정 확인

애플리케이션을 다시 열고 필요한 기능을 사용해 보세요. 워터마크나 라이선스 제한이 남아 있다면 라이선스 내용이 완전하고 유효하며 해당 기능과 릴리스를 포함하는지 확인하세요. 플러그인 모드에서는 등록 순서도 확인하세요. 문제가 계속되면 라이선스 제공업체에 문의하세요.
