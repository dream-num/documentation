---
title: ライセンス
description: Web SDK のライセンスを取得し、ブラウザーアプリケーションに設定します。
---

ライセンスが必要な機能については、[Univer のサイト](https://univer.ai)で利用できるプランを確認し、ライセンスを取得してください。プロジェクトで使用しているプリセットモードまたはプラグインモードで、**クライアントライセンスの内容**を設定します。

## プリセットモード [#in-preset-mode]

既存のプリセット設定に `license` を追加します。`UniverSheetsAdvancedPreset` の例です。

```ts
UniverSheetsAdvancedPreset({
  // Keep your other options and replace this placeholder with the client license content.
  license: 'YOUR_CLIENT_LICENSE',
})
```

ライセンスファイルのパスではなく、ライセンスの内容を渡してください。

## プラグインモード [#in-plugin-mode]

既存の Univer インスタンスに、他のプラグインより先に `UniverLicensePlugin` を登録します。

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_CLIENT_LICENSE',
})
```

## 共同編集アプリケーション

共同編集アプリケーションでもライセンスはブラウザー側で設定します。[Office クイックスタート](/server/collaboration/quick-start)のブラウザー例では、共同編集プラグインとともにライセンスプラグインを登録する位置を示しています。ブラウザーとサーバーのパッケージを [SDK の動作環境とバージョン要件](/server/requirements)に従って統一してください。

ライセンスは利用可能な機能を決めます。誰がドキュメントを閲覧・編集できるかはアプリケーションの権限が決めます。ライセンス設定後、[サーバー統合](/server)に従ってログインとドキュメント権限を接続してください。

## 設定の確認

アプリケーションを開き直し、必要な機能を試します。透かしや制限が残る場合は、ライセンスの内容が完全で、有効期限内であり、対象の機能とリリースを含むことを確認してください。プラグインモードでは登録順序も確認します。解決しない場合はライセンス提供元にお問い合わせください。
