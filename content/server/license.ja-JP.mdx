現在の計画、価格、使用制限については、[利用料金](https://univer.ai/pricing/)を参照してください。そのページの連絡先販売エントリへの質問を直接購入します。このガイドは、設定をカバーします。

[Univer ウェブサイト](https://univer.ai)からライセンスを取得して、ライセンスオプションもリストします。ライセンスは2つのファイルで構成されます。`license.txt`はライセンスコンテンツを保持しており、`licenseKey.txt`にはサーバーが使用しているキーが保持されています。

| 実行場所 | 必要なファイル | 未設定の場合 |
| --- | --- | --- |
| [Web SDK](#web-sdk) | `license.txt` | クライアントの機能とローカル印刷作業、影響を受ける出力の透かし付き |
| [Collaboration SDK](#collaboration-sdk) | `license.txt`、`licenseKey.txt` | 無料版：共同編集ノード 1 つ、共同編集接続 3 つ |
| [Exchange](#exchange) | `license.txt`、`licenseKey.txt` | 無料版：毎月 10 回の透かしなしエクスポート。以後も透かし付きの完全なファイルをエクスポート可能 |

これらの各場所では、ファイルコンテンツを提供します。 ライセンスは、どの機能が利用可能であるかを決定します。 ユーザーがドキュメントを表示または編集するかどうかは、アプリケーションの[アイデンティティと権限](/server/collaboration/identity-and-authorization)に準拠した別の問題です。

## Web SDK [#web-sdk]

チャート、スパークライン編集、PivotTableおよびダッシュボード作成、および署名されたクライアントライセンスなしですべての作業をローカル印刷する。これは、スプレッドシートプリントとスクリーンショットAPIを含みます。チャート、プリント、スクリーンショット出力は、機能およびその認可に応じて、ライセンス透かしを運ぶことができます。各コラボレーションと交換は、独自のサーバーサイドライセンスを使用します。

Freemium は評価用で、透かしと使用量制限があります。Freemium、Business、Enterprise には印刷回数やページ数のライセンス上の上限はありません。Freemium の印刷出力には透かしが付きます。印刷機能による PDF 保存を含む印刷はエクスポート枠を消費しません。ファイル変換による PDF 生成には該当するエクスポート規則が適用されます。機能が利用できても商用利用の許諾を意味しません。商用の本番環境には Business または Enterprise が必要です。商用ライセンスと専用ローカルライセンスには、それぞれの権利と利用条件が引き続き適用されます。

### プラグインモード [#in-plugin-mode]

`UniverLicensePlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `license` | `string` |  | クライアント用ライセンスファイルの内容。 |

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE', // license.txt の内容
})
```

他のプラグインの前に、既存のUniverインスタンスに`UniverLicensePlugin`を登録します。

### プリセットモード [#in-preset-mode]

`UniverSheetsAdvancedPreset`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `license` | `string` |  | クライアント用ライセンスファイルの内容。 |

```ts
UniverSheetsAdvancedPreset({
  // 他の既存設定はそのまま残す
  license: 'YOUR_LICENSE', // license.txt の内容
})
```

`license`を既存のプリセットオプションに追加します。上記の例では、`UniverSheetsAdvancedPreset`を使用します。 コラボレーションアプリケーションは、ブラウザでライセンスを設定しています。 [コラボレーションクイックスタート](/server/collaboration/quick-start)のブラウザの例では、ライセンスプラグインがコラボレーションプラグインと関連している場所を示しています。

## Collaboration SDK [#collaboration-sdk]

```ts
import { UniverCollabService } from '@univerjs-pro/collaboration-service'

const collabService = new UniverCollabService({
  dbAdapter,
  license: 'YOUR_LICENSE', // license.txt の内容
  licenseKey: 'YOUR_LICENSE_KEY', // licenseKey.txt の内容
})
```

`license`と`licenseKey`が省略された場合、`UniverCollabService`は`UNIVER_LICENSE`および`UNIVER_LICENSE_KEY`環境変数を読みます。 ソースが設定されていない場合は、無料のティアで動作します。 ライセンスは、コラボレーション編集接続の数、認定ドメイン、コラボレーションノード数、およびどのドキュメントタイプがカバーされているかを決定します。 [Collaboration SDKライセンス](/server/collaboration/license)を参照してください。

## Exchange [#exchange]

```ts
import { configureExchange } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: 'YOUR_LICENSE', // license.txt の内容
  licenseKey: 'YOUR_LICENSE_KEY', // licenseKey.txt の内容
})
```

このコールはオプションです。Exchange は `UNIVER_LICENSE` と `UNIVER_LICENSE_KEY`を最初のエクスポートまたはクォータクエリで読み込み、どちらも設定されていないときに無料のティアを使用します。インポートはクォータを消費しません。エクスポートはライセンスに対してカウントされます。クォータのクエリとエラーについては、[為替ライセンス](/server/import-export/license)を参照してください。

Collaboration SDK と Exchange が同じプロセスで動作する場合、環境変数は一度設定するだけで済みます。

```bash
export UNIVER_LICENSE="$(cat license.txt)"
export UNIVER_LICENSE_KEY="$(cat licenseKey.txt)"
```

## 設定の確認 [#check]

アプリケーションを再オープンし、必要な機能をテストします。透かしまたはライセンス制限が主張している場合は、ライセンスの内容が完全であることを確認し、有効であり、問題の機能とリリースをカバーします。プラグインモードでは、`UniverLicensePlugin`が他のプラグインの前に登録されていることを確認します。問題が主張している場合はライセンスプロバイダにお問い合わせください。
