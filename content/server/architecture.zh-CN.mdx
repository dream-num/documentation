**Univer** 是一套用于构建人类与 AI Agent 共同操作 Office 内容的开发工具集。一个 Univer
应用可以同时提供面向人类的 Web、面向 Agent 的 CLI，以及二者共享的 Server，也可以只采用
其中一部分。

## SDK 组成

<Mermaid chart={"flowchart LR\n    Human([人类用户]) --> Web[\"Web<br/>Web SDK\"]\n    Agent([Agent]) --> CLI[\"CLI<br/>AI SDK\"]\n    Web --> Server[\"Server<br/>Univer Collaboration SDK<br/>+ 业务代码\"]\n    CLI --> Server"} />

| 组件   | 运行环境 | 主要 SDK                 | SDK 提供                        | 应用负责                           |
| ------ | -------- | ------------------------ | ------------------------------- | ---------------------------------- |
| Web    | 浏览器   | Web SDK       | 交互式 Office 内容展示与编辑    | UI、产品交互与浏览器集成           |
| CLI    | Node.js  | AI SDK           | 面向 Agent 的内容检查与修改入口 | Agent workflow、工具调用与任务边界 |
| Server | Node.js  | Univer Collaboration SDK | Web 与 CLI 共享的自托管协同能力 | 业务 API、身份、权限、数据与部署   |

文档按 [Web SDK](/guides/sheets)、[Server SDK](/server) 和 [AI SDK](/ai) 组织，分别介绍编辑器、协同与导入导出服务、Agent 内容操作。

AI SDK 会复用 Web SDK 的 headless 内容能力。这里的三个组件表示主要开发入口和运行位置，
并非三套互不依赖的技术栈，也不是开箱即用的完整产品。

## 部署形态

| 形态         | Web                | CLI                  | Server     | 适用范围                 |
| ------------ | ------------------ | -------------------- | ---------- | ------------------------ |
| 本机应用     | 本机浏览器或桌面壳 | 本机进程             | 本机进程   | 单机 Office 与本地 Agent |
| SaaS 应用    | 浏览器             | 用户机器或云端 Agent | 远程服务   | 多用户与集中运维         |
| Web + Server | 浏览器             | —                    | 本机或远程 | 暂不提供 Agent 入口      |
| Web-only     | 浏览器或桌面壳     | —                    | —          | 本地、单用户、非协同编辑 |

组件可以部署在同一台机器，也可以跨客户端与云端部署。部署位置不会改变组件职责；存在 Server 时，
Web 与 CLI 都通过它访问共享内容和产品能力。
