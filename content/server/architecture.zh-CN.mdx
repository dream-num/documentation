Univer Office SDK 由三个 SDK 组成：[Web SDK](/guides/sheets) 运行嵌入式编辑器，也能以无头方式[^headless-mode]处理内容；[Server SDK](/server) 负责协同与文件导入导出；[AI SDK](/ai) 负责 Agent 工作流。

**Univer** 是一套用于构建 Office 应用的开发工具集，人与 AI Agent 操作同一份内容。应用可以为人提供 Web 界面、为 AI Agent 提供 CLI，并提供一个供两者共用的 Server，也可以只采用需要的部分。

## SDK 组成

| 组件   | 运行环境 | 主要 SDK                 | SDK 提供                        | 应用负责                           |
| ------ | -------- | ------------------------ | ------------------------------- | ---------------------------------- |
| Web    | 浏览器   | Web SDK       | 在浏览器中展示并编辑 Office 内容的编辑器 | UI、产品交互与浏览器集成           |
| CLI    | Node.js  | AI SDK           | 面向 AI Agent 的检查与编辑 | AI Agent workflow、工具调用与任务边界 |
| Server | Node.js | Server SDK（Collaboration、Exchange） | 自托管协同与 Office 文件导入导出 | 业务 API、身份、权限、文件存储与部署 |

文档按 [Web SDK](/guides/sheets)、[Server SDK](/server) 和 [AI SDK](/ai) 分成三部分，分别介绍编辑器、协同与导入导出服务、AI Agent 的内容操作。

AI SDK 复用 Web SDK 的 headless 内容能力。这三个组件标示主要开发入口和运行位置；它们既不是三套互不依赖的技术栈，也不是无需业务代码即可部署的完整产品。

## 导入导出如何接入

Office 文件与 Univer 文档数据之间的转换由 Server SDK 中的 `@univerjs-pro/exchange-node` 提供。应用集成该转换模块，并自行提供上传、转换和下载接口。浏览器一侧由 Web SDK 处理，CLI 可以在 Node.js 中调用转换模块。各产品在浏览器中的配置仍写在对应产品的 Web SDK 文档中。

- **不使用协同编辑：** 将文件转换为文档快照，在浏览器中打开该快照进行编辑；导出时将最新快照交给转换模块，由它生成文件。这一流程需要服务端转换，不需要协同服务。
- **使用协同编辑：** 将导入的数据保存为协同文档，Web SDK 和 AI SDK 通过文档 ID 操作同一份内容。导出前先同步当前修改，再读取最新的文档数据并完成转换。

只做文件转换时，在本地 Node.js 进程或远程服务中运行 Exchange 即可，不需要 AI SDK，也不需要协同编辑。应用的接入流程见[导入导出集成](/server/import-export)，转换模块的用法见[Office 文件导入导出](/server/import-export/node)。

## 部署形态

| 形态         | Web                | CLI                  | Server     | 适用范围                 |
| ------------ | ------------------ | -------------------- | ---------- | ------------------------ |
| 本机应用     | 本机浏览器或桌面壳 | 本机进程             | 本机进程   | 单机 Office 与本地 AI Agent |
| SaaS 应用    | 浏览器             | 用户机器或云端 AI Agent | 远程服务   | 多用户与集中运维         |
| Web + Server | 浏览器             | —                    | 本机或远程 | 暂不提供 AI Agent 入口      |
| Web-only     | 浏览器或桌面壳     | —                    | —          | 本地、单用户、非协同编辑 |

组件可以全部运行在一台机器上，也可以分布到客户端和云端。部署位置不改变各组件的职责。系统中存在 Server 时，Web 和 CLI 都通过它访问共享内容和产品能力。
