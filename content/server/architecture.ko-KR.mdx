Univer Office SDK는 3개의 부품으로 이루어져 있습니다: [Web SDK](/guides/sheets) 는 헤드리스 Mode[^headless-mode]에 있는 임베디드 편집기와 프로세스 내용을 실행합니다; [Server SDK](/server)은 협력과 파일 교환을 처리합니다; 그리고 [AI SDK](/ai)에는 대리인 워크플로우를 포함합니다.

**Univer**는 사람들과 AI Agents가 동일한 콘텐츠에서 작동하는 Office 응용 프로그램을 구축하기위한 도구 키트입니다. 응용 프로그램은 사람들을 위해 웹 인터페이스를 제공 할 수 있으며, 에이전트를위한 CLI, 둘 다 공유하는 서버, 또는 필요한 부품 만 취할 수 있습니다.

## SDK 구성

| 구성 요소 | 실행 환경 | 주요 SDK | SDK 제공 | 애플리케이션 담당 |
| --- | --- | --- | --- | --- |
| Web | 브라우저 | Web SDK | 브라우저에서 Office 콘텐츠를 표시하고 편집하는 편집기 | UI, 제품 상호 작용 및 브라우저 통합 |
| CLI | Node.js | AI SDK | AI Agents 검사 및 편집 | AI Agent 흐름, 도구 호출, 작업 경계 |
| Server | Node.js | Server SDK(Collaboration, Exchange) | 자체 호스팅 공동 편집 및 Office 파일 교환 | 업무 API, 신원, 권한, 파일 저장, 배포 |

각 부분에는 자체 섹션이 있습니다. [Web SDK](/guides/sheets)는 편집기를 커버하고 [Server SDK](/server)은 협업 및 파일 교환 서비스를 다룹니다. 그리고 [AI SDK](/ai) 는 AI 에이전트에 대한 콘텐츠 작업을 다루고 있습니다.

AI SDK는 Web SDK의 헤드리스 콘텐츠 기능을 재사용합니다. 이 구성 요소는 주요 개발자 항목과 각 부분의 실행 시간을 식별합니다. 그들은 세 가지 분리 된 스택이 아니며, 그 중 아무도 응용 코드없이 배포 할 수있는 완제품입니다.

## 파일 가져오기·내보내기 통합

Server SDK 모듈 `@univerjs-pro/exchange-node`는 Office 파일과 Univer 문서 데이터 사이 변환합니다. 이 응용 프로그램은 변환 모듈을 삽입하고 업로드, 변환 및 API를 다운로드합니다. Web SDK은 브라우저 측을 처리하고 CLI는 Node.js의 변환 모듈을 호출 할 수 있습니다. 각 제품에 대한 브라우저 설정은 해당 제품 Web SDK 문서를 유지합니다.

- **협업 편집 없이:**는 문서 스냅 샷으로 파일을 변환 한 다음 브라우저에서 스냅 샷을 열고 편집합니다. 내보내기하려면, 파일을 생성하는 변환 모듈에 최신 스냅 샷을 전달하십시오. 이 흐름은 서버 측 변환하지만 협업 서비스가 필요하지 않습니다.
- **협업 편집:**는 공동 문서로 수입 된 데이터를 저장합니다. Web SDK 및 AI SDK은 문서 ID를 통해 동일한 컨텐츠에 작동합니다. 내보내기 전에 현재의 편집 동기화, 다음 최신 문서 데이터를 읽고 변환하십시오.

Node.js 프로세스 또는 원격 서비스에 Exchange를 실행하면 AI SDK 또는 협업 편집이 필요하지 않습니다. [파일 교환 통합](/server/import-export)는 응용 흐름을 설명하고 [Office 파일 가져 오기 및 내보내기](/server/import-export/node) 변환 모듈을 사용하는 방법을 보여줍니다.

## 배포 형태

| 형태 | Web | CLI | Server | 용도 |
| --- | --- | --- | --- | --- |
| 로컬 앱 | 로컬 브라우저/데스크톱 UI | 로컬 프로세스 | 로컬 프로세스 | 데스크톱 Office와 로컬 AI Agent |
| SaaS 앱 | 브라우저 | 사용자 장치/클라우드 AI Agent | 원격 서비스 | 다중 사용자 및 중앙 운영 |
| Web + Server | 브라우저 | — | 로컬 또는 원격 | 아직 AI Agent 진입점이 없음 |
| Web 전용 | 브라우저/데스크톱 UI | — | — | 로컬 단일 사용자 비공동 편집 |

모든 구성 요소는 하나의 기계에서 실행할 수 있습니다, 또는 그들은 사용자 장치와 클라우드 인프라를 통해 배포 될 수 있습니다. 배포 위치는 각 구성 요소의 책임을 변경하지 않습니다. 서버가 현재되면, 웹 및 CLI는 공유 콘텐츠 및 제품 기능에 액세스 할 수 있습니다.
