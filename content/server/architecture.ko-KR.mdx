**Univer**는 사람과 AI Agent가 같은 Office 콘텐츠를 조작하는 애플리케이션을 만드는 도구 집합입니다. 사람을 위한 Web, AI Agent를 위한 CLI, 둘이 공유하는 Server를 제공하거나 필요한 부분만 사용할 수 있습니다.

## SDK 구성

| 구성 요소 | 실행 환경 | 주요 SDK | SDK 제공 | 애플리케이션 담당 |

| Web | 브라우저 | Web SDK | 대화형 Office 표시 및 편집 | UI, 제품 상호작용, 브라우저 통합 |
| CLI | Node.js | AI SDK | AI Agent용 검사 및 편집 | AI Agent 흐름, 도구 호출, 작업 경계 |

문서는 [Web SDK](/guides/sheets), [Server SDK](/server), [AI SDK](/ai)로 나뉘며 편집기, 공동 편집·파일 교환 서비스, AI Agent 콘텐츠 작업을 다룹니다.

AI SDK는 Web SDK의 헤드리스 콘텐츠 기능을 재사용합니다. 이 구성 요소는 주요 개발 진입점과 실행 위치를 나타내며, 독립된 세 기술 스택이나 애플리케이션 코드 없이 배포할 수 있는 완성 제품이 아닙니다.

## 파일 가져오기·내보내기 통합

Server SDK의 `@univerjs-pro/exchange-node`는 Office 파일과 Univer 문서 데이터를 변환합니다. 애플리케이션이 변환 모듈을 통합하고 업로드, 변환, 다운로드 API를 제공합니다. Web SDK는 브라우저 상호작용을 담당하고 CLI는 Node.js에서 모듈을 호출할 수 있습니다. 브라우저 설정은 각 제품의 Web SDK 문서에 있습니다.

- **공동 편집 없이:** 파일을 문서 스냅샷으로 변환해 브라우저에서 열고 편집합니다. 내보낼 때 최신 스냅샷을 변환 모듈에 전달합니다. 서버 변환은 필요하지만 공동 편집 서비스는 필요하지 않습니다.
- **공동 편집 사용:** 가져온 데이터를 공동 편집 문서로 저장합니다. Web과 AI SDK가 문서 ID로 같은 내용을 조작합니다. 내보내기 전에 변경을 동기화하고 최신 데이터를 읽어 변환합니다.

변환만 필요하면 로컬 Node.js 프로세스나 원격 서비스에서 Exchange를 사용할 수 있으며 AI SDK나 공동 편집은 필요하지 않습니다. 흐름은 [파일 교환 통합](/server/import-export), 모듈 사용은 [Office 파일 가져오기 및 내보내기](/server/import-export/node)를 참고하세요.

## 배포 형태

| 형태 | Web | CLI | Server | 용도 |
| --- | --- | --- | --- | --- |
| 로컬 앱 | 로컬 브라우저/데스크톱 UI | 로컬 프로세스 | 로컬 프로세스 | 데스크톱 Office와 로컬 AI Agent |
| SaaS 앱 | 브라우저 | 사용자 장치/클라우드 AI Agent | 원격 서비스 | 다중 사용자 및 중앙 운영 |
| Web + Server | 브라우저 | — | 로컬 또는 원격 | 아직 AI Agent 진입점이 없음 |
| Web 전용 | 브라우저/데스크톱 UI | — | — | 로컬 단일 사용자 비공동 편집 |

한 장치 또는 클라이언트와 클라우드에 나눠 실행할 수 있습니다. 위치가 역할을 바꾸지는 않습니다. Server가 있다면 Web과 CLI는 이를 통해 공유 콘텐츠와 제품 기능에 접근합니다.
