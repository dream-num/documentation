## 실행 환경 요구 사항

| SDK / 기능 | 요구 사항 |
| --- | --- |
| SQLite를 사용하는 Collaboration Server | Node.js 22+ |
| PostgreSQL을 사용하는 Collaboration Server | Node.js 22+, PostgreSQL 13+ |
| 다중 노드로 배포하는 Collaboration Server | Node.js 22+, Redis 6.2+ |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

응용 프로그램은 npm, pnpm, 원사 또는 다른 패키지 관리자를 사용할 수 있습니다. `engines` 필드는 설치 패키지에 의해 선언, 그리고 그것의 기본 의존성 요구 사항, 우선 복용.

하나의 응용 프로그램 내에서, 모든 `@univerjs/*` 및 `@univerjs-pro/*` 패키지는 브라우저 및 서버 패키지를 포함한 매칭 릴리즈를 사용해야합니다.
