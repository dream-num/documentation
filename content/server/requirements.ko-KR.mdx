## 실행 환경 요구 사항

| SDK / 기능 | 요구 사항 |
| --- | --- |
| SQLite를 사용하는 Collaboration Server | Node.js 22+ |
| 다중 노드로 배포하는 Collaboration Server | Node.js 22+, Redis 6.2+ |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

npm, pnpm, Yarn 등의 패키지 관리자를 사용할 수 있습니다. 실제 요구 사항은 설치한 패키지의 `engines`와 네이티브 의존성 요구 사항을 기준으로 합니다.

한 애플리케이션의 `@univerjs/*` 및 `@univerjs-pro/*` 패키지는 브라우저와 서버를 포함하여 서로 맞는 릴리스로 통일하세요.
