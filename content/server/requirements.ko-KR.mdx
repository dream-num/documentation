## 실행 환경 요구 사항

| SDK / 기능 | 요구 사항 |
| --- | --- |
| SQLite를 사용하는 Collaboration Server | Node.js 22+ |
| Collaboration 브라우저 클라이언트 | Web SDK가 지원하는 브라우저 |
| AI SDK | Node.js 22.12+ |
| CLI 스크린샷, 렌더링, 레이아웃 검사 | Chrome, Chromium 또는 Edge |

npm, pnpm, Yarn 등의 패키지 관리자를 사용할 수 있습니다. 실제 요구 사항은 설치한 패키지의 `engines`와 네이티브 의존성 요구 사항을 기준으로 합니다.

<Callout title="버전 일치">
  이 문서는 `1.0.0-beta.2`에 해당합니다. 하나의 애플리케이션에서 사용하는 모든 `@univerjs/*`, `@univerjs-pro/*`, `@univer-cli/*` 패키지는 이 버전으로 통일해야 합니다.
</Callout>

패키지 선택과 설치 방법은 [Collaboration 패키지](/server/collaboration/packages)와 [CLI 패키지](/ai/packages)를 참고하세요.
