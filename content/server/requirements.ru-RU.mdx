## Среда выполнения

| SDK / возможность | Требование |
| --- | --- |
| Collaboration Server с SQLite | Node.js 22+ |
| Collaboration Server с PostgreSQL | Node.js 22+, PostgreSQL 13+ |
| Collaboration Server на нескольких узлах | Node.js 22+, Redis 6.2+ |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

Приложения могут использовать npm, pnpm, Yarn или другой диспетчер пакетов.Преимущество имеет поле `engines`, объявленное установленным пакетом, и его собственные требования к зависимости.

В рамках одного приложения каждый пакет `@univerjs/*` и `@univerjs-pro/*` должен использовать соответствующие выпуски, включая пакеты браузера и сервера.
