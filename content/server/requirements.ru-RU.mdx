## Среда выполнения

| SDK / возможность | Требование |
| --- | --- |
| Collaboration Server с SQLite | Node.js 22+ |
| Браузерный клиент Collaboration | Браузер, поддерживаемый Web SDK |
| AI SDK | Node.js 22.12+ |
| Снимки экрана, рендеринг и проверка макета в CLI | Chrome, Chromium или Edge |

Можно использовать npm, pnpm, Yarn или другой менеджер пакетов. Окончательные требования определяются полем `engines` установленного пакета и его нативными зависимостями.

<Callout title="Согласование версий">
  Эта документация соответствует версии `1.0.0-beta.2`. Все пакеты `@univerjs/*`, `@univerjs-pro/*` и `@univer-cli/*` в одном приложении должны использовать эту версию.
</Callout>

Выбор и установка пакетов описаны в разделах [Пакеты Collaboration](/server/collaboration/packages) и [Пакеты CLI](/ai/packages).
