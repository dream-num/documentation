## Среда выполнения

| SDK / возможность | Требование |
| --- | --- |
| Collaboration Server с SQLite | Node.js 22+ |
| Collaboration Server на нескольких узлах | Node.js 22+, Redis 6.2+ |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

Можно использовать npm, pnpm, Yarn или другой менеджер пакетов. Окончательные требования определяются полем `engines` установленного пакета и его нативными зависимостями.

Используйте согласованные выпуски всех пакетов `@univerjs/*` и `@univerjs-pro/*` приложения, включая браузерную и серверную части.
