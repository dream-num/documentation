Pour les plans, les prix et les limites d'utilisation actuels, consultez [Prix](https://univer.ai/pricing/). Questions d'achat direct à l'entrée contact-vente sur cette page. Ce guide couvre la configuration.

Vous obtenez une licence de la [Site web de Univer](https://univer.ai), qui énumère également les options de licence. Une licence se compose de deux fichiers: `license.txt` détient le contenu de la licence, et `licenseKey.txt` possède la clé utilisée par le serveur pour la vérifier.

| Où elle s’exécute | Fichiers nécessaires | Sans licence |
| --- | --- | --- |
| [Web SDK](#web-sdk) | `license.txt` | Caractéristiques du client et travaux d'impression locaux, avec filigranes sur la sortie affectée |
| [Collaboration SDK](#collaboration-sdk) | `license.txt` et `licenseKey.txt` | Version gratuite : 1 nœud de collaboration, 3 connexions d’édition collaborative |
| [Exchange](#exchange) | `license.txt` et `licenseKey.txt` | Version gratuite : 10 exports sans filigrane par mois ; les suivants restent complets, avec filigrane |

À chacun de ces emplacements, vous fournissez le contenu du fichier. La Licence détermine quelles fonctionnalités sont disponibles. La question de savoir si un utilisateur peut consulter ou modifier un document est une question distincte, régie par le [identité et autorisation](/server/collaboration/identity-and-authorization) de l'application.

## Web SDK [#web-sdk]

Graphiques, édition scintillante, création de PivotTable et tableau de bord, et impression locale de tous les travaux sans une licence client signée; cela inclut les API d'impression et de capture d'écran de feuilles. Graphique, impression et sortie de capture d ́écran peuvent porter un filigrane de licence, selon la fonction et son autorisation. Collaboration et échange chaque utiliser leur propre licence côté serveur.

Freemium offre un accès d’évaluation avec filigranes et limites d’utilisation. Les licences Freemium, Business et Enterprise permettent un nombre illimité d’impressions et de pages. Les impressions Freemium portent des filigranes. L’impression, y compris l’enregistrement en PDF via la fonction d’impression, consomme zéro unité du quota d’export. La génération de PDF par conversion suit les règles d’export applicables. Un déploiement commercial en production nécessite une licence Business ou Enterprise valide. Les licences commerciales et locales dédiées conservent leurs droits et conditions d’utilisation propres.

### Mode plugins [#in-plugin-mode]

`UniverLicensePlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenu du fichier de licence côté client. |

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE', // contenu de license.txt
})
```

Enregistrer `UniverLicensePlugin` sur l'instance existante Univer avant les autres plugins.

### Mode presets [#in-preset-mode]

`UniverSheetsAdvancedPreset`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenu du fichier de licence côté client. |

```ts
UniverSheetsAdvancedPreset({
  // Conservez vos autres options.
  license: 'YOUR_LICENSE', // contenu de license.txt
})
```

Ajouter `license` aux options préréglées existantes; l'exemple ci-dessus utilise `UniverSheetsAdvancedPreset`. Les applications collaboratives configurent également une licence dans le navigateur. L'exemple du navigateur dans [Début rapide de la collaboration](/server/collaboration/quick-start) montre où le plugin Licence se situe par rapport aux plugins de collaboration.

## Collaboration SDK [#collaboration-sdk]

```ts
import { UniverCollabService } from '@univerjs-pro/collaboration-service'

const collabService = new UniverCollabService({
  dbAdapter,
  license: 'YOUR_LICENSE', // contenu de license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // contenu de licenseKey.txt
})
```

Lorsque `license` et `licenseKey` sont omis, `UniverCollabService` lit les variables d'environnement `UNIVER_LICENSE` ou `UNIVER_LICENSE_KEY`. Si aucune source n'est définie, elle s'exécute sur le niveau libre. La licence détermine le nombre de connexions d'édition collaborative, les domaines autorisés, le nombre de nœuds de collaboration et les types de documents couverts; voir [Licence Collaboration SDK](/server/collaboration/license) .

## Exchange [#exchange]

```ts
import { configureExchange } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: 'YOUR_LICENSE', // contenu de license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // contenu de licenseKey.txt
})
```

Cet appel est facultatif. Exchange lit `UNIVER_LICENSE` et `UNIVER_LICENSE_KEY` sur la première requête d'exportation ou de contingent, et utilise le niveau libre quand aucun n'est défini. Les importations ne consomment aucun quota; les exportations sont comptées par rapport à la licence. Voir [Licence d'échange](/server/import-export/license) pour les requêtes de contingent et les erreurs.

Lorsque Collaboration SDK et Exchange s’exécutent dans le même processus, il suffit de définir les variables d’environnement une fois :

```bash
export UNIVER_LICENSE="$(cat license.txt)"
export UNIVER_LICENSE_KEY="$(cat licenseKey.txt)"
```

## Vérifier la configuration [#check]

Si des marques de flottaison ou des restrictions de licence persistent, vérifiez que le contenu de la licence est complet, toujours valide et couvre la fonctionnalité et la version en question. En mode plugin, vérifiez également que `UniverLicensePlugin` est enregistré avant les autres plugins. Si le problème persiste, contactez le fournisseur de licence.
