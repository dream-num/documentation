Consultez la [page des tarifs](https://univer.ai/pricing/) pour les offres, prix et limites actuels. Utilisez son lien de contact commercial pour les achats ; ce guide explique comment configurer une licence obtenue.

Consultez le [site d’Univer](https://univer.ai) pour connaître les options de licence et en obtenir une. Une licence se compose de deux fichiers : `license.txt` contient la licence et `licenseKey.txt` contient la clé que le serveur utilise pour la vérifier.

| Où elle s’exécute | Fichiers nécessaires | Sans licence |
| --- | --- | --- |
| [Web SDK](#web-sdk) | `license.txt` | Fonctionnalités gratuites |
| [Collaboration SDK](#collaboration-sdk) | `license.txt` et `licenseKey.txt` | Version gratuite : 1 nœud de collaboration, 3 connexions d’édition collaborative |
| [Exchange](#exchange) | `license.txt` et `licenseKey.txt` | Version gratuite : 10 exports par mois |

Fournissez le contenu des fichiers. La licence détermine les fonctionnalités disponibles ; l’[identité et l’autorisation](/server/collaboration/identity-and-authorization) de votre application déterminent qui peut consulter ou modifier un document.

## Web SDK [#web-sdk]

### Mode plugins [#in-plugin-mode]

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE', // contenu de license.txt
})
```

Enregistrez `UniverLicensePlugin` sur l’instance Univer existante, avant les autres plugins.

### Mode presets [#in-preset-mode]

```ts
UniverSheetsAdvancedPreset({
  // Conservez vos autres options.
  license: 'YOUR_LICENSE', // contenu de license.txt
})
```

Ajoutez `license` à la configuration existante du preset ; l’exemple utilise `UniverSheetsAdvancedPreset`. Les applications collaboratives configurent aussi la licence dans le navigateur. L’exemple navigateur du [Démarrage rapide de la collaboration](/server/collaboration/quick-start) montre où le plugin de licence s’enregistre à côté des plugins de collaboration.

## Collaboration SDK [#collaboration-sdk]

```ts
import { UniverCollabService } from '@univerjs-pro/collaboration-service'

const collabService = new UniverCollabService({
  dbAdapter,
  license: 'YOUR_LICENSE', // contenu de license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // contenu de licenseKey.txt
})
```

Si `license` et `licenseKey` sont omis, `UniverCollabService` lit les variables d’environnement `UNIVER_LICENSE` et `UNIVER_LICENSE_KEY` ; sans l’une ni l’autre source, il fonctionne en version gratuite. La licence détermine les connexions d’édition collaborative, les domaines autorisés, les nœuds de collaboration et les types de documents ; voir [Licence de Collaboration SDK](/server/collaboration/license).

## Exchange [#exchange]

```ts
import { configureExchange } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: 'YOUR_LICENSE', // contenu de license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // contenu de licenseKey.txt
})
```

Cette étape est facultative : Exchange lit les variables d’environnement `UNIVER_LICENSE` et `UNIVER_LICENSE_KEY` lors du premier export ou de la première consultation de quota, et fonctionne en version gratuite si elles ne sont pas définies non plus. Exchange décompte les exports selon la licence et les imports ne consomment pas de quota ; voir [Licence d’Exchange](/server/import-export/license) pour la consultation du quota et les erreurs.

Lorsque Collaboration SDK et Exchange s’exécutent dans le même processus, il suffit de définir les variables d’environnement une fois :

```bash
export UNIVER_LICENSE="$(cat license.txt)"
export UNIVER_LICENSE_KEY="$(cat licenseKey.txt)"
```

## Vérifier la configuration [#check]

Rouvrez l’application et testez les fonctionnalités nécessaires. Si des filigranes ou des restrictions de licence persistent, vérifiez que le contenu de la licence est complet, toujours valide et couvre la fonctionnalité et la version ; en mode plugins, vérifiez aussi que `UniverLicensePlugin` est enregistré avant les autres plugins. Si le problème persiste, contactez votre fournisseur de licence.
