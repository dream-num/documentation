Univer Office SDK состоит из трех частей: [Web SDK](/guides/sheets) запускает встроенные редакторы и обрабатывает контент в безголовом режиме [^headless-mode]; [Server SDK](/server) обрабатывает совместную работу и обмен файлами; и [AI SDK](/ai) охватывает рабочие процессы Агента.

**Univer** — это набор инструментов для создания приложений Office, в которых люди и агенты ИИ работают над одним и тем же контентом.Приложение может предоставлять веб-интерфейс для людей, CLI для агентов и сервер, который ими совместно используется, или оно может занимать только те части, которые ему нужны.

| Компонент | Среда | Основной SDK | SDK предоставляет | Приложение отвечает |
| --- | --- | --- | --- | --- |
| Web | Браузер | Web SDK | Редактор, который отображает и редактирует содержимое Office в браузере | UI, взаимодействие с продуктом и интеграция браузера |
| CLI | Node.js | AI SDK | Инспекция и редактирование для агентов ИИ | Процессы AI Agent, вызовы инструментов, границы задач |
| Server | Node.js | Server SDK (Collaboration, Exchange) | Самостоятельно размещённая совместная работа и обмен Office | Бизнес-API, личность, права, файлы и развёртывание |

Каждая часть имеет свой раздел: [Web SDK](/guides/sheets) охватывает редакторы, [Server SDK](/server) - службы совместной работы и обмена файлами, а [AI SDK](/ai) – операции с контентом для агентов ИИ.

AI SDK повторно использует возможности безголового контента Web SDK. Эти компоненты определяют основные точки входа разработчика и время выполнения каждой части. Они не являются тремя изолированными стеками, и ни один из них не является готовым продуктом, который может быть развернут без кода приложения.

## Интеграция импорта и экспорта

Модуль Server SDK `@univerjs-pro/exchange-node` преобразует между файлами Office и данными документа Univer. Приложение встраивает модуль преобразования и обеспечивает саму загрузку, конверсию и загрузку API. Web SDK обрабатывает сторону браузера, а CLI может вызвать модуль преобразования в Node.js . Настройка браузера для каждого продукта остается в документации Web SDK этого продукта.

- **Без совместного редактирования:** преобразует файл в снимок документа, затем открывает и редактирует этот снимок в браузере. Для экспорта передайте последний снимок модулю преобразования, который производит файл. Этот поток требует преобразования на стороне сервера, но без службы совместной работы.
- **С совместным редактированием:** сохраняет импортированные данные в качестве совместного документа. Web SDK и AI SDK затем работают на одном и том же контенте через свой идентификатор документа. Перед экспортом синхронизируйте текущие изменения, затем прочитайте последние данные документа и преобразуйте их.

Если требуется только конверсия, запустите Exchange в локальном процессе Node.js или удаленной службе; ни AI SDK, ни совместное редактирование не требуется. [Обмен файлами интеграция](/server/import-export) описывает поток приложений, а [Офисные файлы импорт и экспорт](/server/import-export/node) показывает, как использовать модуль конверсии.

## Варианты развёртывания

| Вариант | Web | CLI | Server | Назначение |
| --- | --- | --- | --- | --- |
| Локальное приложение | Локальный браузер/настольный UI | Локальный процесс | Локальный процесс | Настольный Office и локальный AI Agent |
| SaaS | Браузер | Устройство пользователя/облачный AI Agent | Удалённый сервис | Несколько пользователей и централизованная эксплуатация |
| Web + Server | Браузер | — | Локальный или удалённый | Пока без входа AI Agent |
| Только Web | Браузер/настольный UI | — | — | Локальное одиночное редактирование |

Все компоненты могут работать на одной машине, или они могут быть распределены между пользовательскими устройствами и облачной инфраструктурой. Место развертывания не меняет ответственности каждого компонента. Как только сервер присутствует, Web и CLI используют его для доступа к общему контенту и возможностям продукта.
