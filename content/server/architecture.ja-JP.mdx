Univer Office SDKは3つの部分で構成されます:[Web SDK](/guides/sheets)のは埋め込まれたエディタを実行し、ヘッドレスモードでコンテンツを処理する[^headless-mode]; [Server SDK](/server)がコラボレーションとファイル交換を処理します。 そして、[AI SDK](/ai) はエージェントのワークフローをカバーしています。

**Univer**は、人やAIエージェントが同じコンテンツで動作するOfficeアプリケーションを構築するツールキットです。アプリケーションは、人、エージェント用のCLI、および共有の両方のサーバーにWebインターフェイスを提供するか、必要な部品だけを取ることができます。

## SDK の構成

| コンポーネント | 実行環境 | 主な SDK | SDK が提供 | アプリケーションが担当 |
| --- | --- | --- | --- | --- |
| Web | ブラウザー | Web SDK | ブラウザにOfficeコンテンツをディスプレイおよび編集するエディタ | UI、プロダクト相互作用およびブラウザの統合 |
| CLI | Node.js | AI SDK | AIエージェントの検査・編集 | AI Agent フロー、ツール呼び出し、タスク境界 |
| Server | Node.js | Server SDK（Collaboration、Exchange） | 自己ホスト共同編集と Office 入出力 | 業務 API、ID、権限、ファイル保存、配置 |

[Web SDK](/guides/sheets)は、各部に独自のセクションがあります。[Server SDK](/server)では、コラボレーションとファイル交換サービスをカバーし、[AI SDK](/ai)にはAIエージェントのコンテンツ操作をカバーしています。

AI SDKは、Web SDKのヘッドレスコンテンツ機能を再使用しています。 これらのコンポーネントは、メイン開発者のエントリーポイントと各パートのランタイムを識別します。 彼らは3つの独立したスタックではありません。 そのうちのどれも、アプリケーションコードなしで展開できる最終製品です。

## ファイルの入出力の統合

Server SDKモジュール`@univerjs-pro/exchange-node`は、OfficeファイルとUniverドキュメントデータの間で変換します。このアプリケーションは、変換モジュールを埋め、アップロード、変換、およびAPI自体をダウンロードします。 Web SDKでは、ブラウザ側を扱い、CLIはNode.jsで変換モジュールを呼び出すことができます。各製品のブラウザ設定は、その製品のWeb SDKのドキュメントに残ります。

- **共同編集なしで:**はファイルをドキュメントスナップショットに変換し、ブラウザでスナップショットを開き、編集します。エクスポートするには、ファイルを生成するコンバージョンモジュールに最新のスナップショットを渡します。このフローは、サーバー側のコンバージョンではなくコラボレーションサービスが必要です。
- **共同編集を使って:**は、インポートされたデータを共同ドキュメントとして保存します。 Web SDKとAI SDKでは、ドキュメントIDを介して同じコンテンツを操作します。 エクスポートする前に、現在の編集を同期させ、最新の文書データを読み込み、それを変換します。

変換のみが必要な場合は、ローカルNode.jsプロセスまたはリモートサービスでExchangeを実行してください。AI SDKも共同編集が必要です。[ファイル交換統合](/server/import-export)はアプリケーションフローを記述し、[オフィスファイルのインポートとエクスポート](/server/import-export/node)ではコンバージョンモジュールの使用方法を示します。

## 配置構成

| 構成 | Web | CLI | Server | 用途 |
| --- | --- | --- | --- | --- |
| ローカルアプリ | ローカルブラウザー／デスクトップ UI | ローカルプロセス | ローカルプロセス | デスクトップ Office とローカル AI Agent |
| SaaS | ブラウザー | ユーザー端末／クラウド AI Agent | リモートサービス | 複数ユーザーと集中運用 |
| Web + Server | ブラウザー | — | ローカルまたはリモート | AI Agent 入口をまだ提供しない |
| Web のみ | ブラウザー／デスクトップ UI | — | — | ローカル、単独、非共同編集 |

すべてのコンポーネントは 1 つのマシンで実行できます。または、ユーザー デバイスとクラウド インフラストラクチャを横断して配布することができます。デプロイメントの場所は、各コンポーネントの責任を変更しません。サーバーが存在したら、Web と CLI を使用して共有コンテンツと製品の機能にアクセスします。

[^headless-mode]: Headless は、対話型エディター UI をマウントせずに文書内容を操作することです。共同編集、永続化、ファイル変換サービスが含まれるという意味ではありません。
