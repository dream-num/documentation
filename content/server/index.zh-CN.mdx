**Univer Server SDK 是一组需要应用自行组装的模块。** 按应用需要选出用得到的模块，接入自己的后端，再部署该应用。身份认证、权限、文档归属、文件存储和运维都由应用负责。

本页介绍服务端的搭建、存储和权限。[协同集成](/server/collaboration/browser-integration)介绍编辑器如何连接共享文档，[导入导出集成](/server/import-export)介绍文件上传、转换和下载。请阅读所需功能对应的文档。功能涉及许可证时，先完成[许可证配置](/server/license)。仅在浏览器中编辑时，不需要接入协同服务。

## 按步骤完成集成

1. [运行 Quick Start](/server/collaboration/quick-start)：在两个独立的浏览器上下文中打开同一份文档，确认修改可以双向同步。
2. [接入持久化](/server/collaboration/database-adapters#verify-persistence)：重启 SQLite 示例，确认数据仍然存在。
3. [接入身份与权限](/server/collaboration/identity-and-authorization#verify-permissions)：分别以 editor 和 viewer 身份登录，比较两者允许执行的操作。
4. [连接业务前端](/server/collaboration/browser-integration)：将演示身份、文档创建逻辑和协议地址替换为自己的实现。
5. [按需增加扩展](/server/collaboration/examples)：核心链路完成后，再增加历史记录、评论、Worktree 或 Exchange。仅需文件转换时，直接从 [Exchange](/server/import-export/node) 开始。

## 选择需要的服务

| 需求 | 服务端需要准备 | 实现文档 |
| --- | --- | --- |
| 多人编辑同一份文档 | Collaboration SDK、文档存储和用户权限 | [协同快速开始](/server/collaboration/quick-start) |
| 导入或导出 Office 文件 | 文件转换、上传、任务查询和下载接口 | [文件转换](/server/import-export/node)与 [Exchange 示例](/server/collaboration/examples#exchange) |
| 历史记录或共享评论 | 对应的服务、存储和权限 | [协同扩展模块](/server/collaboration/extensions) |

只接入实际用得到的服务。仅做文件转换时，不需要协同编辑。先按 [SDK 环境与版本要求](/server/requirements)准备运行环境，并保持 Univer 各包版本兼容。

## 连接业务系统和存储

先运行所选服务的示例，再将其接入自己的后端。协同文档由业务后端创建、记录归属，并将文档 ID 返回给浏览器；创建接口的用法见[模块边界与关系](/server/collaboration/modules)。用户、项目和目录仍由业务系统管理。

协同示例将数据保存在内存中，重启后内容即丢失。按 [Database Adapter 文档](/server/collaboration/database-adapters)接入数据库，再确认重启后仍能读出已保存的文档。

文件转换还需要为上传文件、转换任务和下载文件提供存储空间，并安排清理。具体做法见 [Exchange 示例](/server/collaboration/examples#exchange)。

## 接入登录和权限

按[身份与权限](/server/collaboration/identity-and-authorization)校验应用现有的登录凭证，并判断当前用户是否可以读取或修改某份文档。示例中的固定用户和默认放行规则需要替换。

权限检查须覆盖文档读取、协同连接、修改提交，以及已启用的历史记录、评论和文件下载。将前端设为只读并不能代替服务端的权限检查。

## 部署并连接前端

将接口部署在应用自己的域名下。接入协同服务后，反向代理须同时转发 HTTP 和 WebSocket 流量，HTTPS 页面应使用 WSS。限制上传文件大小，并处理转换失败和超时。单台机器容量不足时，按[部署指引](/server/deployment)拆分服务并运行多个协同节点。

后端就绪后，完成所需的功能集成：

- [协同集成](/server/collaboration/browser-integration)：连接编辑器，创建并打开共享文档，确认两边的修改都能呈现。
- [导入导出集成](/server/import-export)：接通上传、转换和下载，并用真实文件验证结果。
