**Univer** es un conjunto de herramientas para crear aplicaciones Office donde personas y AI Agents operan el mismo contenido. Puede ofrecer Web para personas, CLI para AI Agents y un Server compartido, o usar solo los componentes necesarios.

## Composición de los SDK

| Componente | Entorno | SDK principal | Proporciona | Responsabilidad de la aplicación |
| --- | --- | --- | --- | --- |
| Web | Navegador | Web SDK | Visualización y edición interactiva de Office | UI, interacción del producto e integración con el navegador |
| CLI | Node.js | AI SDK | Inspección y edición para AI Agent | Flujos AI Agent, llamadas a herramientas y límites de tareas |
| Server | Node.js | Server SDK (Collaboration, Exchange) | Colaboración autoalojada e intercambio Office | API de negocio, identidad, permisos, archivos y despliegue |

La documentación se organiza en [Web SDK](/guides/sheets), [Server SDK](/server) y [AI SDK](/ai), para editores, servicios de colaboración y archivos y operaciones de contenido de AI Agents.

AI SDK reutiliza las capacidades sin interfaz de Web SDK. Los componentes indican entradas de desarrollo y ubicaciones de ejecución, no tres pilas independientes ni productos completos desplegables sin código de aplicación.

## Integrar importación y exportación

`@univerjs-pro/exchange-node` de Server SDK convierte archivos Office y datos Univer. La aplicación integra el módulo y ofrece API de subida, conversión y descarga. Web SDK gestiona la interacción del navegador y una CLI puede llamar al módulo en Node.js. La configuración del navegador sigue en la documentación Web SDK de cada producto.

- **Sin colaboración:** convierte el archivo en una instantánea, ábrela y edítala en el navegador. Para exportar, envía la instantánea más reciente al módulo. Requiere conversión en servidor, pero no colaboración.
- **Con colaboración:** guarda lo importado como documento colaborativo. Web y AI SDK operan el mismo contenido mediante su ID. Antes de exportar, sincroniza las ediciones, lee los datos actuales y conviértelos.

Para convertir únicamente archivos, usa Exchange en Node.js local o en un servicio remoto; no se requiere AI SDK ni colaboración. Consulta [Integración de intercambio](/server/import-export) para el flujo e [Importación y exportación de Office](/server/import-export/node) para el módulo.

## Formas de despliegue

| Forma | Web | CLI | Server | Uso |
| --- | --- | --- | --- | --- |
| Aplicación local | Navegador local/UI de escritorio | Proceso local | Proceso local | Office de escritorio con AI Agent local |
| SaaS | Navegador | Dispositivo del usuario/AI Agent en nube | Servicio remoto | Varios usuarios y operación centralizada |
| Web + Server | Navegador | — | Local o remoto | Sin entrada AI Agent todavía |
| Solo Web | Navegador/UI de escritorio | — | — | Edición local, individual y no colaborativa |

Los componentes pueden ejecutarse en una máquina o repartirse entre clientes y nube. La ubicación no cambia sus responsabilidades. Si existe Server, Web y CLI acceden al contenido compartido y funciones mediante él.
