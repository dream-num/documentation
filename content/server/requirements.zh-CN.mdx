## 运行环境

| SDK / 能力                          | 要求                        |
| ----------------------------------- | --------------------------- |
| Collaboration Server + SQLite       | Node.js 22+                 |
| Collaboration Server + PostgreSQL   | Node.js 22+，PostgreSQL 13+ |
| Collaboration Server 多节点部署      | Node.js 22+，Redis 6.2+     |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

应用可以使用 npm、pnpm、Yarn 或其他包管理器。以已安装的 package 在 `engines` 字段中声明的要求及其原生依赖要求为准。

同一个应用内，所有 `@univerjs/*` 和 `@univerjs-pro/*` 包必须使用相匹配的发布版本，浏览器包和服务端包均包括在内。
