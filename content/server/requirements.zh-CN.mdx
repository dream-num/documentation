## 运行环境

| SDK / 能力                          | 要求                        |
| ----------------------------------- | --------------------------- |
| Collaboration Server + SQLite       | Node.js 22+                 |
| Collaboration Browser Client        | Web SDK 支持的浏览器 |
| AI SDK                      | Node.js 22.12+              |
| CLI Screenshot、Render、Layout Lint | Chrome、Chromium 或 Edge    |

应用可以使用 npm、pnpm、Yarn 等包管理器。目标 package 的 `engines` 与原生依赖要求是最终依据。

<Callout title="版本统一要求">
  当前文档对应 `1.0.0-rc.0`。同一个应用中的所有 `@univerjs/*`、`@univerjs-pro/*` 和
  `@univer-cli/*` package 必须统一使用该版本。
</Callout>

选包与安装方式见 [Collaboration Package 概览](/server/collaboration/packages)和
[CLI Package 概览](/ai/packages)。
