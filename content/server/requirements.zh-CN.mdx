## 运行环境

| SDK / 能力                          | 要求                        |
| ----------------------------------- | --------------------------- |
| Collaboration Server + SQLite       | Node.js 22+                 |
| Collaboration Server 多节点部署      | Node.js 22+，Redis 6.2+     |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

应用可以使用 npm、pnpm、Yarn 等包管理器。目标 package 的 `engines` 与原生依赖要求是最终依据。

同一个应用中的 `@univerjs/*` 和 `@univerjs-pro/*` 包应使用相匹配的发布版本，前后端包也需保持一致。
