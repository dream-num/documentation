## Environnements d’exécution

| SDK / fonctionnalité | Prérequis |
| --- | --- |
| Collaboration Server avec SQLite | Node.js 22+ |
| Client Collaboration pour navigateur | Un navigateur compatible avec Web SDK |
| AI SDK | Node.js 22.12+ |
| Capture d’écran, rendu et vérification de mise en page de la CLI | Chrome, Chromium ou Edge |

Vous pouvez utiliser npm, pnpm, Yarn ou un autre gestionnaire de paquets. Les contraintes `engines` du paquet installé et celles de ses dépendances natives font foi.

<Callout title="Alignement des versions">
  Cette documentation correspond à la version `1.0.0-beta.2`. Tous les paquets `@univerjs/*`, `@univerjs-pro/*` et `@univer-cli/*` d’une même application doivent utiliser cette version.
</Callout>

Consultez les [paquets Collaboration](/server/collaboration/packages) et les [paquets CLI](/ai/packages) pour choisir et installer les paquets nécessaires.
