## Environnements d’exécution

| SDK / fonctionnalité | Prérequis |
| --- | --- |
| Collaboration Server avec SQLite | Node.js 22+ |
| Collaboration Server sur plusieurs nœuds | Node.js 22+, Redis 6.2+ |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

Vous pouvez utiliser npm, pnpm, Yarn ou un autre gestionnaire de paquets. Les contraintes `engines` du paquet installé et celles de ses dépendances natives font foi.

Utilisez des versions correspondantes pour tous les paquets `@univerjs/*` et `@univerjs-pro/*` de l’application, côté navigateur comme côté serveur.

[paquets Collaboration](/server/collaboration/packages)
