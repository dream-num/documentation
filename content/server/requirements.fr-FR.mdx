## Environnements d’exécution

| SDK / fonctionnalité | Prérequis |
| --- | --- |
| Collaboration Server avec SQLite | Node.js 22+ |
| Collaboration Server avec PostgreSQL | Node.js 22+, PostgreSQL 13+ |
| Collaboration Server sur plusieurs nœuds | Node.js 22+, Redis 6.2+ |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

Les applications peuvent utiliser npm, pnpm, Yarn, ou un autre gestionnaire de paquets. Le champ `engines` déclaré par le paquet installé, et ses exigences de dépendance native, ont priorité.

Dans une application, chaque paquet `@univerjs/*` et `@univerjs-pro/*` doit utiliser des versions correspondantes, y compris les paquets navigateur et serveur.
