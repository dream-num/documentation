## Runtime requirements

| SDK / capability                    | Requirement                           |
| ----------------------------------- | ------------------------------------- |
| Collaboration Server with SQLite    | Node.js 22+                           |
| Collaboration Server with PostgreSQL | Node.js 22+, PostgreSQL 13+          |
| Collaboration Server multi-node deployment | Node.js 22+, Redis 6.2+        |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

Applications may use npm, pnpm, Yarn, or another package manager. The `engines` field declared by the installed package, and its native dependency requirements, take precedence.

Within one application, every `@univerjs/*` and `@univerjs-pro/*` package must use matching releases, including browser and server packages.
