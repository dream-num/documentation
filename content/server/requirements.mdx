## Runtime requirements

| SDK / capability                    | Requirement                           |
| ----------------------------------- | ------------------------------------- |
| Collaboration Server with SQLite    | Node.js 22+                           |
| Collaboration Server multi-node deployment | Node.js 22+, Redis 6.2+        |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

Applications may use npm, pnpm, Yarn, or another package manager. The installed package's
`engines` and native dependency requirements are authoritative.

Keep all `@univerjs/*` and `@univerjs-pro/*` packages in an application on matching releases, including browser and server packages.
