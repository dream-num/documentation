Consulta los planes, precios y límites actuales en la [página de precios](https://univer.ai/pricing/). Usa su enlace de contacto comercial para compras; esta guía explica cómo configurar la licencia obtenida.

Visita el [sitio web de Univer](https://univer.ai) para consultar las opciones de licencia y obtener una. Una licencia consta de dos archivos: `license.txt` contiene la licencia y `licenseKey.txt` contiene la clave que el servidor usa para verificarla.

| Dónde se ejecuta | Archivos necesarios | Sin licencia |
| --- | --- | --- |
| [Web SDK](#web-sdk) | `license.txt` | Funciones gratuitas |
| [Collaboration SDK](#collaboration-sdk) | `license.txt` y `licenseKey.txt` | Versión gratuita: 1 nodo de colaboración y 3 conexiones de edición colaborativa |
| [Exchange](#exchange) | `license.txt` y `licenseKey.txt` | Versión gratuita: 10 exportaciones al mes |

Proporciona el contenido de los archivos. La licencia determina qué funciones están disponibles; la [identidad y autorización](/server/collaboration/identity-and-authorization) de tu aplicación determina quién puede ver o editar un documento.

## Web SDK [#web-sdk]

### Modo de plugins [#in-plugin-mode]

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE', // contenido de license.txt
})
```

Registra `UniverLicensePlugin` en la instancia existente de Univer, antes de los demás plugins.

### Modo de presets [#in-preset-mode]

```ts
UniverSheetsAdvancedPreset({
  // Conserva tus demás opciones.
  license: 'YOUR_LICENSE', // contenido de license.txt
})
```

Añade `license` a la configuración existente del preset; el ejemplo usa `UniverSheetsAdvancedPreset`. Las aplicaciones colaborativas también configuran la licencia en el navegador. El ejemplo de navegador de [Inicio rápido de colaboración](/server/collaboration/quick-start) muestra dónde se registra el plugin de licencia junto a los de colaboración.

## Collaboration SDK [#collaboration-sdk]

```ts
import { UniverCollabService } from '@univerjs-pro/collaboration-service'

const collabService = new UniverCollabService({
  dbAdapter,
  license: 'YOUR_LICENSE', // contenido de license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // contenido de licenseKey.txt
})
```

Si se omiten `license` y `licenseKey`, `UniverCollabService` lee las variables de entorno `UNIVER_LICENSE` y `UNIVER_LICENSE_KEY`; sin ninguna de las dos fuentes, funciona con la versión gratuita. La licencia determina las conexiones de edición colaborativa, los dominios autorizados, los nodos de colaboración y los tipos de documento; consulta [Licencia de Collaboration SDK](/server/collaboration/license).

## Exchange [#exchange]

```ts
import { configureExchange } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: 'YOUR_LICENSE', // contenido de license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // contenido de licenseKey.txt
})
```

Este paso es opcional: Exchange lee las variables de entorno `UNIVER_LICENSE` y `UNIVER_LICENSE_KEY` en la primera exportación o consulta de cuota, y funciona con la versión gratuita si tampoco están definidas. Exchange cuenta las exportaciones según la licencia y las importaciones no consumen cuota; consulta [Licencia de Exchange](/server/import-export/license) para las consultas de cuota y los errores.

Cuando Collaboration SDK y Exchange se ejecutan en el mismo proceso, basta con definir las variables de entorno una vez:

```bash
export UNIVER_LICENSE="$(cat license.txt)"
export UNIVER_LICENSE_KEY="$(cat licenseKey.txt)"
```

## Comprobar la configuración [#check]

Vuelve a abrir la aplicación y prueba las funciones que necesitas. Si siguen apareciendo marcas de agua o restricciones de licencia, verifica que el contenido de la licencia esté completo, siga siendo válido y cubra la función y la versión; en modo de plugins, comprueba también que `UniverLicensePlugin` se registre antes de los demás plugins. Si el problema persiste, contacta con el proveedor de la licencia.
