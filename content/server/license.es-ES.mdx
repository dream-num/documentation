Para los planes actuales, precios y límites de uso, consulte [Precios](https://univer.ai/pricing/). Preguntas de compra directa a la entrada de contacto-venta en esa página. Esta guía cubre la configuración.

Usted obtiene una Licencia del [Sitio web de Univer](https://univer.ai), que también enumera las opciones de licencia. Una Licencia consta de dos archivos: `license.txt` contiene el contenido de la Licencia, y `licenseKey.txt` tiene la clave que el servidor utiliza para verificarlo.

| Dónde se ejecuta | Archivos necesarios | Sin licencia |
| --- | --- | --- |
| [Web SDK](#web-sdk) | `license.txt` | Características del cliente y trabajos de impresión local, con marcas de agua en la salida afectada |
| [Collaboration SDK](#collaboration-sdk) | `license.txt` y `licenseKey.txt` | Versión gratuita: 1 nodo de colaboración y 3 conexiones de edición colaborativa |
| [Exchange](#exchange) | `license.txt` y `licenseKey.txt` | Versión gratuita: 10 exportaciones sin marca de agua al mes; las siguientes siguen completas, con marca de agua |

En cada una de estas ubicaciones usted proporciona el contenido del archivo. La Licencia determina qué características están disponibles. Si un usuario puede ver o editar un documento es un asunto separado, gobernado por el [identidad y autorización](/server/collaboration/identity-and-authorization) de la aplicación.

## Web SDK [#web-sdk]

Cartas, edición de chispa, creación de PivotTable y dashboard, e impresión local todo trabajo sin una licencia de cliente firmada; esto incluye las API de impresión y captura de pantalla. Carga, impresión y salida de captura de pantalla pueden llevar una marca de agua de la licencia, dependiendo de la característica y su autorización. Colaboración e Intercambio cada uso de su propia licencia de servidor.

Freemium permite evaluar el producto con marcas de agua y límites de uso. Freemium, Business y Enterprise no tienen límites de licencia sobre el número de impresiones o páginas. Las impresiones de Freemium llevan marcas de agua. Imprimir, incluido guardar como PDF mediante la función de impresión, no consume cuota de exportación. Generar PDF mediante conversión de archivos sigue las reglas de exportación correspondientes. La disponibilidad de funciones no implica autorización comercial: los despliegues comerciales en producción requieren Business o Enterprise. Las licencias comerciales y las licencias locales dedicadas conservan sus propios derechos y condiciones de uso.

### Modo de plugins [#in-plugin-mode]

`UniverLicensePlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenido del archivo de licencia del cliente. |

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE', // contenido de license.txt
})
```

Registrar `UniverLicensePlugin` en la instancia Univer existente antes de los otros plugins.

### Modo de presets [#in-preset-mode]

`UniverSheetsAdvancedPreset`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenido del archivo de licencia del cliente. |

```ts
UniverSheetsAdvancedPreset({
  // Conserva tus demás opciones.
  license: 'YOUR_LICENSE', // contenido de license.txt
})
```

Añadir `license` a las opciones de preestablecimiento existentes; el ejemplo anterior utiliza `UniverSheetsAdvancedPreset`. Aplicaciones colaborativas configuran una Licencia en el navegador también. El ejemplo del navegador en [Inicio rápido de la colaboración](/server/collaboration/quick-start) muestra dónde el plugin de licencia se encuentra en relación con los plugins de colaboración.

## Collaboration SDK [#collaboration-sdk]

```ts
import { UniverCollabService } from '@univerjs-pro/collaboration-service'

const collabService = new UniverCollabService({
  dbAdapter,
  license: 'YOUR_LICENSE', // contenido de license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // contenido de licenseKey.txt
})
```

Cuando se omiten `license` y `licenseKey`, `UniverCollabService` lee las variables de entorno `UNIVER_LICENSE` y `UNIVER_LICENSE_KEY`. Si no se establece ninguna fuente, se ejecuta en el nivel gratuito. La Licencia determina el número de conexiones de edición colaborativa, los dominios autorizados, el número de nodos de colaboración, y qué tipos de documentos están cubiertos; véase [Licencia Collaboration SDK](/server/collaboration/license).

## Exchange [#exchange]

```ts
import { configureExchange } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: 'YOUR_LICENSE', // contenido de license.txt
  licenseKey: 'YOUR_LICENSE_KEY', // contenido de licenseKey.txt
})
```

Esta llamada es opcional. El intercambio lee `UNIVER_LICENSE` y `UNIVER_LICENSE_KEY` en la primera consulta de exportación o cuota, y utiliza el nivel libre cuando no se establece. Las importaciones no consumen cuota; las exportaciones se contabilizan en contra de la Licencia. Ver [Licencia de cambio](/server/import-export/license) para consultas de cuota y errores.

Cuando Collaboration SDK y Exchange se ejecutan en el mismo proceso, basta con definir las variables de entorno una vez:

```bash
export UNIVER_LICENSE="$(cat license.txt)"
export UNIVER_LICENSE_KEY="$(cat licenseKey.txt)"
```

## Comprobar la configuración [#check]

Si persisten marcas de agua o restricciones de licencias, compruebe que el contenido de la licencia es completo, todavía válido, y cubre la función y la versión en cuestión. En modo plugin, también verifique que `UniverLicensePlugin` está registrado antes de los otros plugins. Si el problema persiste, póngase en contacto con el proveedor de licencia.
