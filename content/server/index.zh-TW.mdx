Univer Office SDK 包含三個 SDK：[Web SDK](/guides/sheets) 提供嵌入式編輯器和無頭內容處理能力，[Server SDK](/server) 提供協同與檔案匯入匯出能力，[AI SDK](/ai) 提供 Agent 工作流程能力。

後端負責儲存文件、檢查使用者權限，並提供協同編輯或檔案轉換介面。目前版本透過 [Server SDK](/server)，在你自己的應用程式環境中整合這些能力。

本頁介紹後端設定、儲存與權限。[協同整合](/server/collaboration/browser-integration)將編輯器連接到共用文件；[檔案交換整合](/server/import-export)則介紹上傳、轉換與下載。請依所需功能選擇指南。需要授權的功能請先完成[授權設定](/server/license)。僅在瀏覽器編輯不需要協同服務。

## 選擇所需服務

| 需求 | 後端準備 | 實作指南 |
| --- | --- | --- |
| 共用文件編輯 | Collaboration SDK、文件儲存與權限 | [協同快速開始](/server/collaboration/quick-start) |
| Office 檔案匯入匯出 | 轉換、上傳、任務查詢與下載 | [檔案轉換](/server/import-export/node)與 [Exchange 範例](/server/collaboration/examples#exchange) |
| 歷史記錄或共用留言 | 各自的服務、儲存與權限 | [擴充模組](/server/collaboration/extensions) |

只選擇需要的能力。單純轉換檔案不需要協同編輯。請準備 [SDK 環境](/server/requirements)，並保持 Univer 套件版本相容。

## 連接應用程式與儲存

先執行所選服務的範例，再接入自己的後端。協同文件由應用程式建立、記錄擁有者，並將 ID 傳回瀏覽器。建立 API 請參閱[模組邊界](/server/collaboration/modules)。使用者、專案與資料夾仍由應用程式管理。

協同範例使用記憶體儲存，重啟後內容會遺失。請依[資料庫介接器](/server/collaboration/database-adapters)接入資料庫，並驗證已儲存文件在重啟後仍然存在。

檔案轉換也需要管理上傳、任務與下載的儲存及清理，請參考 [Exchange 範例](/server/collaboration/examples#exchange)。

## 接入登入與權限

依[身分與授權](/server/collaboration/identity-and-authorization)驗證既有登入憑證，並檢查使用者是否可讀取或修改文件。請替換範例中的固定使用者與全部允許規則。

對文件讀取、協同連線、編輯提交，以及已啟用的歷史記錄、留言與下載進行保護。瀏覽器編輯器設為唯讀不能取代伺服器權限檢查。

## 部署並連接前端

將介面部署到應用程式網域。協同編輯的代理伺服器須同時轉送 HTTP 與 WebSocket 流量；HTTPS 頁面應使用 WSS。限制檔案上傳，並處理轉換失敗與逾時。

後端準備完成後，繼續整合對應功能：

- [協同整合](/server/collaboration/browser-integration)：連接編輯器、建立並開啟共用文件，以及驗證同步。
- [檔案交換整合](/server/import-export)：接通上傳、轉換與下載，並使用實際檔案驗證。
