**Univer Server SDK 是一組需要應用自行組裝的模組。** 按應用需要選出用得到的模組，接入自己的後端，再部署該應用。身分認證、權限、文件歸屬、檔案儲存和運維都由應用負責。

本頁介紹伺服器端的搭建、儲存和權限。[協同整合](/server/collaboration/browser-integration)介紹編輯器如何連線共享文件，[匯入匯出整合](/server/import-export)介紹檔案上傳、轉換和下載。請閱讀所需功能對應的文件。功能涉及許可證時，先完成[許可證配置](/server/license)。僅在瀏覽器中編輯時，不需要接入協同服務。

## 逐步完成整合

1. [執行 Quick Start](/server/collaboration/quick-start)。在兩個瀏覽器視窗中開啟同一份文件，確認修改可以雙向同步。
2. [接入持久化](/server/collaboration/database-adapters#verify-persistence)：重啟 SQLite 範例，確認資料仍然存在。
3. [接入身分與權限](/server/collaboration/identity-and-authorization#verify-permissions)：分別以 editor 和 viewer 身分登入，比較兩者允許執行的操作。
4. [連線業務前端](/server/collaboration/browser-integration)：將演示身分、文件建立邏輯和協議地址替換為自己的實現。
5. [按需增加擴充套件](/server/collaboration/examples)：核心鏈路完成後，再增加歷史記錄、評論、Worktree 或 Exchange。僅需檔案轉換時，直接從 [Exchange](/server/import-export/node) 開始。

## 選擇所需服務

| 需求 | 後端準備 | 實作指南 |
| --- | --- | --- |
| 共用文件編輯 | Collaboration SDK、文件儲存與權限 | [協同快速開始](/server/collaboration/quick-start) |
| Office 檔案匯入匯出 | 轉換、上傳、任務查詢與下載 | [檔案轉換](/server/import-export/node)與 [Exchange 範例](/server/collaboration/examples#exchange) |
| 歷史記錄或共用留言 | 各自的服務、儲存與權限 | [擴充模組](/server/collaboration/extensions) |

只接入實際用得到的服務。僅做檔案轉換時，不需要協同編輯。先按 [SDK 環境與版本要求](/server/requirements)準備執行環境，並保持 Univer 各包版本相容。

## 連接應用程式與儲存

先執行所選服務的範例，再將其接入自己的後端。協同文件由業務後端建立、記錄歸屬，並將文件 ID 返回給瀏覽器；建立介面的用法見[模組邊界與關係](/server/collaboration/modules)。使用者、專案和目錄仍由業務系統管理。

Quick Start 範例將修改保存在記憶體中，服務停止後修改就會遺失。依照 [Database Adapter 文件](/server/collaboration/database-adapters)接入資料庫，再確認重啟後仍能讀取已儲存的文件。

檔案轉換還需要為上傳檔案、轉換任務和下載檔案提供儲存空間，並安排清理。具體做法見 [Exchange 範例](/server/collaboration/examples#exchange)。

## 接入登入與權限

按[身分與權限](/server/collaboration/identity-and-authorization)校驗應用現有的登入憑證，並判斷當前使用者是否可以讀取或修改某份文件。範例中的固定使用者和預設放行規則需要替換。

權限檢查須覆蓋文件讀取、協同連線、修改提交，以及已啟用的歷史記錄、評論和檔案下載。將前端設為只讀並不能代替伺服器端的權限檢查。

## 部署並連接前端

將介面部署在應用自己的域名下。接入協同服務後，反向代理須同時轉發 HTTP 和 WebSocket 流量，HTTPS 頁面應使用 WSS。限制上傳檔案大小，並處理轉換失敗和超時。單臺機器容量不足時，按[部署指引](/server/deployment)拆分服務並執行多個協同節點。

後端就緒後，完成所需的功能整合：

- [協同整合](/server/collaboration/browser-integration)：連線編輯器，建立並開啟共享文件，確認兩邊的修改都能呈現。
- [匯入匯出整合](/server/import-export)：接通上傳、轉換和下載，並用真實檔案驗證結果。
