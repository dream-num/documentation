Univer Office SDK comprend [Web SDK](/guides/sheets) pour les éditeurs intégrés et le traitement de contenu headless, [Server SDK](/server) pour la collaboration et l’import/export de fichiers, et [AI SDK](/ai) pour les workflows des agents.

**Univer** est une boîte à outils pour construire des applications Office où humains et AI Agents manipulent le même contenu. Une application peut offrir un Web pour les humains, une CLI pour les AI Agents et un Server partagé, ou n’utiliser que les composants nécessaires.

| Composant | Runtime | SDK principal | Fourni par le SDK | Responsabilité applicative |
| --- | --- | --- | --- | --- |
| Web | Navigateur | Web SDK | Affichage et édition Office interactifs | UI, interactions produit, intégration navigateur |
| CLI | Node.js | AI SDK | Inspection et édition pour AI Agent | Parcours AI Agent, appels d’outils, limites des tâches |
| Server | Node.js | Server SDK (Collaboration, Exchange) | Collaboration auto-hébergée et échange de fichiers Office | API métier, identité, droits, stockage et déploiement |

La documentation se divise en [Web SDK](/guides/sheets), [Server SDK](/server) et [AI SDK](/ai), couvrant éditeurs, services collaboratifs et de fichiers, puis opérations de contenu des AI Agents.

AI SDK réutilise les capacités de contenu sans interface de Web SDK. Ces composants désignent les principaux points d’entrée et lieux d’exécution, pas trois piles indépendantes ni des produits déployables sans code applicatif.

## Intégrer l’import-export

Le module Server SDK `@univerjs-pro/exchange-node` convertit fichiers Office et données Univer. L’application l’intègre et fournit les API de téléversement, conversion et téléchargement. Web SDK gère les interactions navigateur ; une CLI peut appeler le module dans Node.js. La configuration navigateur reste dans la documentation Web SDK de chaque produit.

- **Sans collaboration :** convertissez le fichier en instantané, ouvrez-le et modifiez-le dans le navigateur. Pour exporter, transmettez le dernier instantané au module. Une conversion serveur est nécessaire, mais pas de service collaboratif.
- **Avec collaboration :** enregistrez les données importées comme document collaboratif. Web et AI SDK travaillent sur le même contenu via son ID. Avant export, synchronisez les modifications, puis lisez et convertissez les données actuelles.

Pour la seule conversion, utilisez Exchange dans un processus Node.js local ou un service distant, sans AI SDK ni collaboration. Consultez l’[intégration de l’échange de fichiers](/server/import-export) pour le parcours et [Import-export Office](/server/import-export/node) pour le module.

## Formes de déploiement

| Forme | Web | CLI | Server | Portée |
| --- | --- | --- | --- | --- |
| Application locale | Navigateur local/UI de bureau | Processus local | Processus local | Office de bureau et AI Agent local |
| SaaS | Navigateur | Appareil utilisateur/AI Agent cloud | Service distant | Plusieurs utilisateurs et exploitation centralisée |
| Web + Server | Navigateur | — | Local ou distant | Pas encore d’entrée AI Agent |
| Web seul | Navigateur/UI de bureau | — | — | Édition locale, individuelle, non collaborative |

Les composants peuvent partager une machine ou être répartis entre clients et cloud. L’emplacement ne change pas leurs responsabilités. Lorsqu’un Server existe, Web et CLI l’utilisent pour accéder au contenu partagé et aux capacités produit.
