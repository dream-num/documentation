當前方案、價格和使用額度見[定價頁面](https://univer.ai/pricing/)。購買相關問題請透過該頁面的聯絡銷售入口提出。本頁介紹許可證的配置方法。

[Univer 官網](https://univer.ai) 列出授權選項，許可證也透過該網站取得。一份許可證包含兩個檔案：`license.txt` 是許可證內容，`licenseKey.txt` 是伺服器端校驗用的金鑰。

| 使用位置 | 所需檔案 | 未設定時 |
| --- | --- | --- |
| [Web SDK](#web-sdk) | `license.txt` | 客戶端功能和本地列印可用，受影響的輸出帶水印 |
| [Collaboration SDK](#collaboration-sdk) | `license.txt`、`licenseKey.txt` | 免費版：1 個協同節點、3 個協同編輯連線 |
| [Exchange](#exchange) | `license.txt`、`licenseKey.txt` | 免費版：每月 10 次免水印匯出，超額後仍可匯出帶水印的完整檔案 |

以上各處均需填寫檔案內容。許可證決定哪些功能可用；使用者能否檢視或編輯某份文件屬於另一類問題，由應用的[身分與權限](/server/collaboration/identity-and-authorization)決定。

## Web SDK [#web-sdk]

圖表、迷你圖編輯、透視表和儀表盤建立以及本地列印都不需要簽名客戶端許可證，Sheets 的列印和截圖 API 同樣如此。圖表、列印和截圖輸出是否帶許可證水印，取決於具體功能及其授權狀態。協同和 Exchange 各自使用伺服器端的許可證。

Freemium（免費版）提供帶水印和用量限制的評估體驗。免費版、商業版和企業版的許可均支援無限次、無限頁數的列印，免費版列印輸出帶水印。列印及透過列印功能儲存為 PDF 的匯出計次為 0；透過檔案轉換產生 PDF 則遵循相應的匯出規則。商業生產部署需要有效的 Business 或 Enterprise 許可。商業許可和專用本地許可仍遵循各自的權益與使用條款。

### 外掛模式 [#in-plugin-mode]

`UniverLicensePlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 用戶端授權檔的內容。 |

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE', // license.txt 的內容
})
```

在已有的 Univer 例項上註冊 `UniverLicensePlugin`，註冊順序在其他外掛之前。

### 預設集模式 [#in-preset-mode]

`UniverSheetsAdvancedPreset`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 用戶端授權檔的內容。 |

```ts
UniverSheetsAdvancedPreset({
  // 保留其他既有設定
  license: 'YOUR_LICENSE', // license.txt 的內容
})
```

在已有的預設配置中加入 `license`，上面的範例以 `UniverSheetsAdvancedPreset` 為例。協同應用同樣需要在瀏覽器中配置許可證，[協同快速開始](/server/collaboration/quick-start)的前端範例展示了許可證外掛與協同外掛的相對位置。

## Collaboration SDK [#collaboration-sdk]

```ts
import { UniverCollabService } from '@univerjs-pro/collaboration-service'

const collabService = new UniverCollabService({
  dbAdapter,
  license: 'YOUR_LICENSE', // license.txt 的內容
  licenseKey: 'YOUR_LICENSE_KEY', // licenseKey.txt 的內容
})
```

省略 `license` 和 `licenseKey` 時，`UniverCollabService` 讀取環境變數 `UNIVER_LICENSE` 和 `UNIVER_LICENSE_KEY`；兩者都未設定時，按免費版執行。許可證決定協同編輯連線數、授權域名、協同節點數以及文件型別的覆蓋範圍，詳見 [Collaboration SDK 許可證](/server/collaboration/license)。

## Exchange [#exchange]

```ts
import { configureExchange } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: 'YOUR_LICENSE', // license.txt 的內容
  licenseKey: 'YOUR_LICENSE_KEY', // licenseKey.txt 的內容
})
```

這一步可以省略。Exchange 在首次匯出或查詢額度時讀取 `UNIVER_LICENSE` 和 `UNIVER_LICENSE_KEY`，兩者都未設定時按免費版執行。匯入不消耗額度，匯出按許可證計次，額度查詢和錯誤處理見 [Exchange 許可證](/server/import-export/license)。

Collaboration SDK 和 Exchange 執行在同一程序中時，環境變數只需設定一次：

```bash
export UNIVER_LICENSE="$(cat license.txt)"
export UNIVER_LICENSE_KEY="$(cat licenseKey.txt)"
```

## 設定後檢查 [#check]

重新開啟應用，驗證所需功能。如果仍有水印或授權限制，請檢查許可證內容是否完整、是否仍在有效期內、是否覆蓋當前功能和版本。外掛模式還需確認 `UniverLicensePlugin` 註冊在其他外掛之前。問題仍然存在時，聯絡許可證提供方。
