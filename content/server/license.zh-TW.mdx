---
title: 授權
description: 取得 Web SDK 授權並在瀏覽器應用程式中設定。
---

若功能需要授權，請前往 [Univer 網站](https://univer.ai)了解授權方案並取得授權。依專案使用的預設集模式或外掛模式，設定**用戶端授權內容**。

## 預設集模式 [#in-preset-mode]

在現有預設集設定中加入 `license`。例如使用 `UniverSheetsAdvancedPreset`：

```ts
UniverSheetsAdvancedPreset({
  // Keep your other options and replace this placeholder with the client license content.
  license: 'YOUR_CLIENT_LICENSE',
})
```

請提供授權內容，不是授權檔案路徑。

## 外掛模式 [#in-plugin-mode]

在既有 Univer 執行個體上，先於其他外掛註冊 `UniverLicensePlugin`：

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_CLIENT_LICENSE',
})
```

## 協同應用程式

協同應用程式同樣在瀏覽器中設定授權。[Office 快速開始](/server/collaboration/quick-start)的瀏覽器範例展示如何與協同外掛一起註冊授權外掛。瀏覽器與伺服器套件版本應符合 [SDK 環境與版本要求](/server/requirements)。

授權決定可用的功能，應用程式權限則決定誰可檢視或編輯文件。完成授權設定後，請依[伺服器整合](/server)接入登入與文件權限。

## 檢查設定

重新開啟應用程式並測試所需功能。若浮水印或授權限制仍然存在，請檢查授權內容是否完整、有效，且涵蓋所需功能與版本。外掛模式還需檢查註冊順序。若問題持續，請聯絡授權提供者。
