当前方案、价格和使用额度见[定价页面](https://univer.ai/pricing/)。购买相关问题请通过该页面的联系销售入口提出。本页介绍许可证的配置方法。

[Univer 官网](https://univer.ai) 列出授权选项，许可证也通过该网站获取。一份许可证包含两个文件：`license.txt` 是许可证内容，`licenseKey.txt` 是服务端校验用的密钥。

| 使用位置                                | 所需文件                          | 未配置时                               |
| --------------------------------------- | --------------------------------- | -------------------------------------- |
| [Web SDK](#web-sdk) | `license.txt` | 客户端功能和本地打印可用，受影响的输出带水印 |
| [Collaboration SDK](#collaboration-sdk) | `license.txt`、`licenseKey.txt`   | 免费版：1 个协同节点、3 个协同编辑连接 |
| [Exchange](#exchange)                   | `license.txt`、`licenseKey.txt`   | 免费版：每月 10 次免水印导出，超额后仍可导出带水印的完整文件 |

以上各处均需填写文件内容。许可证决定哪些功能可用；用户能否查看或编辑某份文档属于另一类问题，由应用的[身份与权限](/server/collaboration/identity-and-authorization)决定。

## Web SDK [#web-sdk]

图表、迷你图编辑、透视表和仪表盘创建以及本地打印都不需要签名客户端许可证，Sheets 的打印和截图 API 同样如此。图表、打印和截图输出是否带许可证水印，取决于具体功能及其授权状态。协同和 Exchange 各自使用服务端的许可证。

Freemium（免费版）用于评估，带水印和用量限制。免费版、商业版和企业版均不设打印次数或页数的许可上限，免费版打印输出带水印。打印及通过打印功能保存为 PDF 不消耗导出额度；通过文件转换生成 PDF 则遵循相应的导出规则。功能可用不代表商业授权有效，商业生产部署需要 Business 或 Enterprise 许可。商业许可和专用本地许可仍遵循各自的权益与使用条款。

### 插件模式 [#in-plugin-mode]

`UniverLicensePlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 客户端许可证文件的内容。 |

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE', // license.txt 的内容
})
```

在已有的 Univer 实例上注册 `UniverLicensePlugin`，注册顺序在其他插件之前。

### 预设模式 [#in-preset-mode]

`UniverSheetsAdvancedPreset`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 客户端许可证文件的内容。 |

```ts
UniverSheetsAdvancedPreset({
  // 保留其他已有配置
  license: 'YOUR_LICENSE', // license.txt 的内容
})
```

在已有的预设配置中加入 `license`，上面的示例以 `UniverSheetsAdvancedPreset` 为例。协同应用同样需要在浏览器中配置许可证，[协同快速开始](/server/collaboration/quick-start)的前端示例展示了许可证插件与协同插件的相对位置。

## Collaboration SDK [#collaboration-sdk]

```ts
import { UniverCollabService } from '@univerjs-pro/collaboration-service'

const collabService = new UniverCollabService({
  dbAdapter,
  license: 'YOUR_LICENSE', // license.txt 的内容
  licenseKey: 'YOUR_LICENSE_KEY', // licenseKey.txt 的内容
})
```

省略 `license` 和 `licenseKey` 时，`UniverCollabService` 读取环境变量 `UNIVER_LICENSE` 和 `UNIVER_LICENSE_KEY`；两者都未设置时，按免费版运行。许可证决定协同编辑连接数、授权域名、协同节点数以及文档类型的覆盖范围，详见 [Collaboration SDK 许可证](/server/collaboration/license)。

## Exchange [#exchange]

```ts
import { configureExchange } from '@univerjs-pro/exchange-node'

await configureExchange({
  license: 'YOUR_LICENSE', // license.txt 的内容
  licenseKey: 'YOUR_LICENSE_KEY', // licenseKey.txt 的内容
})
```

这一步可以省略。Exchange 在首次导出或查询额度时读取 `UNIVER_LICENSE` 和 `UNIVER_LICENSE_KEY`，两者都未设置时按免费版运行。导入不消耗额度，导出按许可证计次，额度查询和错误处理见 [Exchange 许可证](/server/import-export/license)。

Collaboration SDK 和 Exchange 运行在同一进程中时，环境变量只需设置一次：

```bash
export UNIVER_LICENSE="$(cat license.txt)"
export UNIVER_LICENSE_KEY="$(cat licenseKey.txt)"
```

## 配置后检查 [#check]

重新打开应用，验证所需功能。如果仍有水印或授权限制，请检查许可证内容是否完整、是否仍在有效期内、是否覆盖当前功能和版本。插件模式还需确认 `UniverLicensePlugin` 注册在其他插件之前。问题仍然存在时，联系许可证提供方。
