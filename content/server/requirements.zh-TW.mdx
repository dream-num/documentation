## 執行環境要求

| SDK／功能 | 要求 |
| --- | --- |
| 使用 SQLite 的 Collaboration Server | Node.js 22+ |
| 使用 PostgreSQL 的 Collaboration Server | Node.js 22+，PostgreSQL 13+ |
| 多節點部署的 Collaboration Server | Node.js 22+、Redis 6.2+ |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

應用可以使用 npm、pnpm、Yarn 或其他包管理器。以已安裝的 package 在 `engines` 欄位中宣告的要求及其原生依賴要求為準。

同一個應用內，所有 `@univerjs/*` 和 `@univerjs-pro/*` 包必須使用相匹配的釋出版本，瀏覽器包和伺服器端包均包括在內。
