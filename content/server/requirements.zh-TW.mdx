## 執行環境要求

| SDK／功能 | 要求 |
| --- | --- |
| 使用 SQLite 的 Collaboration Server | Node.js 22+ |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

應用程式可使用 npm、pnpm、Yarn 或其他套件管理工具。實際要求以已安裝套件的 `engines` 與原生相依套件要求為準。

<Callout title="版本一致性">
  本文件對應 `1.0.0-rc.0`。同一應用程式中的所有 `@univerjs/*` 和 `@univerjs-pro/*` 套件都必須使用此版本。
</Callout>
