## 執行環境要求

| SDK／功能 | 要求 |
| --- | --- |
| 使用 SQLite 的 Collaboration Server | Node.js 22+ |
| Collaboration 瀏覽器用戶端 | Web SDK 支援的瀏覽器 |
| AI SDK | Node.js 22.12+ |
| CLI 截圖、渲染、版面檢查 | Chrome、Chromium 或 Edge |

應用程式可使用 npm、pnpm、Yarn 或其他套件管理工具。實際要求以已安裝套件的 `engines` 與原生相依套件要求為準。

<Callout title="版本一致性">
  本文件對應 `1.0.0-rc.0`。同一應用程式中的所有 `@univerjs/*`、`@univerjs-pro/*` 和 `@univer-cli/*` 套件都必須使用此版本。
</Callout>

套件選擇與安裝方式請參閱 [Collaboration 套件](/server/collaboration/packages)與 [CLI 套件](/ai/packages)。
