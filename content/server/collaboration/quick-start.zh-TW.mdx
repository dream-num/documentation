title: 快速開始
description: 執行雙瀏覽器協同，再將最小 Client、Transport、Endpoint、Service 與 Adapter 組合整合到應用程式。
---

本頁包含兩條路徑。第一條路徑執行官方範例，在兩個瀏覽器中驗證完整的協同鏈路；第二條路徑說明最小的 Server 與 Web 組裝方式，可複製到自己的 Univer 應用中。

開始之前，請先完成[環境與版本要求](/server/requirements)。所有 `@univerjs/*` 與 `@univerjs-pro/*` package 都必須固定在同一個匹配的 release cohort 上，不能混用版本。

## 路徑一：執行官方範例

### 執行前準備

本倉庫要求 **Node.js 24+**，並宣告使用 **pnpm 10.32.1**。請檢查 `node --version` 與 `pnpm --version` 的輸出，使用倉庫自帶的鎖檔案，並在倉庫根目錄下執行所有 `pnpm example:*` 命令。這些命令會建置瀏覽器端和伺服器端、檢查範例的型別，然後啟動服務，並不是熱更新開發伺服器；因此修改原始碼後需要停止程序並重新執行命令。

已有許可證時，請在執行命令前於終端設定 `UNIVER_LICENSE` 與 `UNIVER_LICENSE_KEY`。建置時 `vite.config.ts` 會把 `UNIVER_LICENSE` 寫入瀏覽器產物，服務啟動時 Collaboration SDK 會讀取這兩個變數。更換許可證後需重新執行命令。說明見[許可證](/server/license#collaboration-sdk)。

```bash
git clone https://github.com/dream-num/univer-collaboration-examples.git
cd univer-collaboration-examples
pnpm install --frozen-lockfile
pnpm example:quick-start
```

開啟以下地址：

```text
http://127.0.0.1:3010/?unit=quick-start-sheet
```

### 驗證即時協同

1. 在一個瀏覽器視窗開啟完整 URL。
2. 在另一個瀏覽器 profile 或無痕視窗中再次開啟同一 URL。
3. 在任意一個視窗的 Sheet 中修改一個單元格。
4. 確認另一個視窗中出現了同一處修改。

兩個視窗必須使用相互獨立的瀏覽器 Context，伺服器端才會建立兩個不同的線上 Session。僅在同一頁面中檢視自己的修改，不足以驗證 Room、ACK 與廣播這一段鏈路。

### 成功代表什麼

```text
Univer Collaboration Client
  → Node Transport
  → UniverCollabEndpoint
  → UniverCollabService
  → MemoryDatabaseAdapter
```

兩個瀏覽器能夠保持同步，說明整條路徑都正常工作：每個瀏覽器都透過 HTTP 載入 Unit，使用一次性 Session Ticket 建立 WebSocket Session，並 JOIN 同一個 Room。隨後 Service 執行 OT，確認新的 revision，透過 Adapter 儲存，再由 Endpoint 廣播給其他成員。

## 路徑二：整合到應用程式

以下是最小的 Server 與 Web 組裝方式。完整的應用結構見官方 Quick Start：

- [server/main.ts](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/server/main.ts)
- [web/main.ts](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/web/main.ts)
- [package.json](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/package.json)

如果已有 Univer Web 應用，請保留其 Runtime、Preset 和 UI，只新增下面這份 Collaboration Client 配置與 Server。如果從空專案開始，請把 Quick Start 目錄中的 `index.html`、`vite.config.ts` 和樣式檔案複製過來，作為應用外殼。

### 從可執行檔案開始整合

請把 `examples/quick-start` 複製為初始骨架，並保留 `package.json`、`index.html`、`vite.config.ts`、`web/styles.css`、`web/main.ts` 和 `server/main.ts`。build 和 start 指令碼需要在該目錄中執行，因為 Express 會按工作目錄查詢 `dist/web`。請保留 Vite 中的許可證定義，並確保 `#app` 具有非零高度。下面的程式碼只說明這些部分如何組合；如需一個可執行的完整專案，請直接使用倉庫中的檔案。

範例中頁面與 `/universer-api` 同源。如果前端部署到其他位置，需要把 HTTP 和 WebSocket Upgrade 都代理到後端，或者同時修改客戶端的五個協議地址。`unit` 必須與後端建立的 ID 一致；僅在 URL 中寫參數不會建立文件。範例讀取 `unit` 後透過 `loadSheetAsync()` 顯式載入。接入自己的應用時，請按[協同整合](/server/collaboration/browser-integration)的說明先設定當前使用者，再執行載入。

### 1. 安裝同一組相符版本的套件

伺服器端需要 Transport、Endpoint、Service 和一個 Database Adapter，瀏覽器端需要 Collaboration Client。請先安裝這些 package，再把所有 Univer package 固定到同一個精確版本：

```bash
pnpm add \
  @univerjs-pro/collaboration \
  @univerjs-pro/collaboration-client \
  @univerjs-pro/collaboration-client-ui \
  @univerjs-pro/collaboration-database-memory \
  @univerjs-pro/collaboration-endpoint \
  @univerjs-pro/collaboration-service \
  @univerjs-pro/collaboration-transport-node \
  @univerjs-pro/license \
  @univerjs/core \
  @univerjs/preset-sheets-core \
  @univerjs/presets \
  @univerjs/protocol \
  express react react-dom rxjs
```

當前需要安裝哪些 package、精確到哪個版本，以官方範例的 manifest 為準，該檔案本身即可執行。

### 2. 建立 Service、Endpoint 與初始 Unit

`UniverCollabService` 是協同的權威核心。Endpoint 把瀏覽器協議對映到 Service，Memory Adapter 則暫時負責儲存 snapshot、changeset 和 revision：

```ts
import type { IWorkbookData } from "@univerjs/core";
import { createServer } from "node:http";
import express from "express";
import { LocaleType } from "@univerjs/core";
import { MemoryDatabaseAdapter } from "@univerjs-pro/collaboration-database-memory";
import { UniverCollabEndpoint } from "@univerjs-pro/collaboration-endpoint";
import { UniverCollabService } from "@univerjs-pro/collaboration-service";
import { createNodeTransport } from "@univerjs-pro/collaboration-transport-node";
import { ErrorCode, UniverType } from "@univerjs/protocol";

const UNIT_ID = "quick-start-sheet";
const unitData: IWorkbookData = {
  id: UNIT_ID,
  rev: 1,
  name: "Quick Start Sheet",
  appVersion: "",
  locale: LocaleType.EN_US,
  sheetOrder: ["sheet-1"],
  sheets: {
    "sheet-1": {
      id: "sheet-1",
      name: "Sheet 1",
      rowCount: 100,
      columnCount: 26,
      cellData: {},
    },
  },
  styles: {},
  resources: [],
};

const database = new MemoryDatabaseAdapter();
const service = new UniverCollabService({ dbAdapter: database });
const endpoint = new UniverCollabEndpoint(service);
const transport = createNodeTransport();

transport.use(async (context, next) => {
  context.userID = "demo-user";
  await next();
});
transport.register(endpoint);

await service.createUnitFromData(
  { type: UniverType.UNIVER_SHEET, data: unitData },
  { userID: "demo-user" },
);
```

這裡固定 `demo-user`，是為了展示可信身分如何從 Transport 傳遞到 Endpoint 和 Service。生產應用應在 `transport.use()` 中驗證自己的 Cookie、Bearer token 或 Session，驗證透過後再設定穩定的業務 `userID`。

### 3. 掛載授權、HTTP 與 WebSocket 入口

當前 Collaboration Client 會查詢授權協議。Quick Start 對該介面的每次請求都返回 `allowed: true`，並把 Transport 掛載到應用的 HTTP Server 上：

```ts
const app = express();

app.post("/universer-api/authz/-/object/-/batch_allowed", express.json(), (request, response) => {
  const body = request.body as {
    requests: Array<{ unitID: string; objectID: string; actions: unknown[] }>;
  };
  response.json({
    error: { code: ErrorCode.OK, message: "" },
    objectActions: body.requests.map((item) => ({
      unitID: item.unitID,
      objectID: item.objectID,
      actions: item.actions.map((action) => ({ action, allowed: true })),
    })),
  });
});

app.use(express.static("dist/web"));

const server = createServer(app);
transport.attach(server);
server.listen(3010, "127.0.0.1");
```

一律允許只是教學範例的簡化做法，並不構成安全邊界。正式應用必須保護 HTTP read、即時 JOIN、changeset submit 和 Unit 生命週期操作，完整的權限覆蓋模型見[身分與權限](/server/collaboration/identity-and-authorization)。

### 4. 在瀏覽器 Runtime 註冊 Collaboration Client

瀏覽器端沿用 Web SDK 和 Preset，再補充 Collaboration 的外掛與協議地址：

#### 外掛設定 [#plugin-configuration]

`UniverLicensePlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 用戶端授權檔的內容。 |

`UniverCollaborationClientPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `socketService` | `Ctor<ICollaborationSocketService>` |  | 當前執行環境使用的 Socket 實現。 |
| `sendChangesetTimeout` | `number` | `2000` | 變更發出前的合批等待時間，單位毫秒。 |
| `authzUrl` | `string` | `'/universer-api/authz'` | 檢查權限的端點。 |
| `snapshotServerUrl` | `string` | `'/universer-api/snapshot'` | 讀取文件快照的端點。 |
| `collabSubmitChangesetUrl` | `string` | `'/universer-api/comb'` | 提交變更集的端點。 |
| `collabWebSocketUrl` | `string` | `'ws://127.0.0.1:8000/universer-api/comb/connect'` | 同步即時變更的 WebSocket 位址。 |
| `wsSessionTicketUrl` | `string` | `'/universer-api/user/session-ticket'` | 取得 WebSocket 工作階段票證的端點。 |

#### 預設設定 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 編輯器掛載的元素，或該元素的 DOM ID。 |

```ts
import { LocaleType, LogLevel } from "@univerjs/core";
import { UniverCollaborationPlugin } from "@univerjs-pro/collaboration";
import { UniverCollaborationClientPlugin } from "@univerjs-pro/collaboration-client";
import CollaborationClientEnUS from "@univerjs-pro/collaboration-client/locale/en-US";
import {
  BrowserCollaborationSocketService,
  UniverCollaborationClientUIPlugin,
} from "@univerjs-pro/collaboration-client-ui";
import CollaborationClientUIEnUS from "@univerjs-pro/collaboration-client-ui/locale/en-US";
import { UniverLicensePlugin } from "@univerjs-pro/license";
import { UniverSheetsCorePreset } from "@univerjs/preset-sheets-core";
import UniverPresetSheetsCoreEnUS from "@univerjs/preset-sheets-core/locales/en-US";
import { createUniver, defaultTheme, mergeLocales } from "@univerjs/presets";
import "@univerjs-pro/collaboration-client/facade";
import "@univerjs/preset-sheets-core/lib/index.css";
import "@univerjs-pro/collaboration-client-ui/lib/index.css";

const httpProtocol = location.protocol === "https:" ? "https" : "http";
const wsProtocol = location.protocol === "https:" ? "wss" : "ws";
const baseURL = `${httpProtocol}://${location.host}/universer-api`;

const unitId = new URLSearchParams(location.search).get("unit");
if (!unitId) throw new Error("Open the URL printed by the server; it names the Sheet with ?unit=.");
const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      CollaborationClientEnUS,
      CollaborationClientUIEnUS,
    ),
  },
  theme: defaultTheme,
  logLevel: LogLevel.WARN,
  collaboration: true,
  presets: [UniverSheetsCorePreset({ container: "app" })],
  plugins: [
    [UniverLicensePlugin, { license: import.meta.env.UNIVER_LICENSE || undefined }],
    UniverCollaborationPlugin,
    [
      UniverCollaborationClientPlugin,
      {
        socketService: BrowserCollaborationSocketService,
        sendChangesetTimeout: 200,
        authzUrl: `${baseURL}/authz`,
        snapshotServerUrl: `${baseURL}/snapshot`,
        collabSubmitChangesetUrl: `${baseURL}/comb`,
        collabWebSocketUrl: `${wsProtocol}://${location.host}/universer-api/comb/connect`,
        wsSessionTicketUrl: `${baseURL}/user/session-ticket`,
      },
    ],
    UniverCollaborationClientUIPlugin,
  ],
});

const workbook = await univerAPI.getCollaboration().loadSheetAsync(unitId);
if (!workbook) throw new Error("Document could not be loaded");
```

頁面中需要一個具有 `id="app"` 的元素，Unit 透過查詢參數指定：

```text
/?unit=quick-start-sheet
```

### 5. 將教學設定換成應用程式能力

| 教學設定 | 接入應用時應替換為 |
| --- | --- |
| 固定 `demo-user` | 應用自身的認證 Middleware 和穩定使用者 ID |
| 權限檢查一律允許 | 覆蓋 read、JOIN、submit 和生命週期操作的伺服器端 ACL |
| 固定 Unit | 呼叫 `createUnitFromData()` 的應用建立 API 和產品記錄 |
| Memory Adapter | SQLite 或透過契約測試的自定義持久化 Adapter |

接下來閱讀 [Database Adapter](/server/collaboration/database-adapters) 和[身分與權限](/server/collaboration/identity-and-authorization)，再按需新增 [History、Thread Comment、Worktree 或 Exchange](/server/collaboration/extensions)。所有可執行的組裝方式收錄在[範例索引](/server/collaboration/examples)中。

## 首次執行排查

| 現象 | 檢查 |
| --- | --- |
| 安裝或建置失敗 | Node.js 24+、倉庫宣告的 pnpm 版本、Univer 包版本是否一致 |
| 3010 被占用 | 停止前一個範例，或設定 `PORT=3011`，並在兩個瀏覽器地址中都使用該埠 |
| 白屏或缺少資源 | 建置是否完成、是否從範例目錄啟動、`#app` 是否具有高度 |
| 修改不同步 | 兩個視窗的完整 URL 是否相同；snapshot 與 session-ticket 請求是否成功；`/universer-api/comb/connect` 是否建立了 WebSocket 連線 |
| 重啟後資料遺失 | Quick Start 使用記憶體儲存；請繼續執行 SQLite 範例 |
