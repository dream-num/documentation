## 빠른 시작 [#quick-start]

Collaboration Client, Transport, Endpoint, Service, Memory Adapter를 조합합니다. 두 브라우저에서 같은 Sheet의 HTTP 로드, WebSocket Session, Room, ACK, 브로드캐스트를 확인합니다.

```bash
pnpm example:quick-start
```

`http://127.0.0.1:3010/?unit=quick-start-sheet`를 엽니다.

- [예제 가이드](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/README.md)
- [서버 진입점](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/server/main.ts)
- [Web 진입점](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/web/main.ts)
- [이 사이트의 단계별 가이드](/server/collaboration/quick-start)

```bash
pnpm example:permissions
```

`http://127.0.0.1:3010`를 엽니다.

## 기록 [#history]

핵심 밖에 History Service, 독립 Adapter, History Endpoint, 브라우저 기록 진입점을 추가합니다. Unit 생성·변경 커밋 Events로 재구축 가능한 파생 기록 인덱스를 만듭니다.

```bash
pnpm example:history
```

`http://127.0.0.1:3010/?unit=history-sheet`를 열고 Sheet를 편집한 뒤 상단의 `History`를 선택합니다.

- [예제 가이드](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/README.md)

## 파일 서비스 [#file-service]

File Service와 File Endpoint를 연결합니다. Sheet에 삽입한 이미지는 서버에 업로드되고 Unit 데이터에는 파일 ID만 기록됩니다.

```bash
pnpm example:file-service
```

`http://127.0.0.1:3010/?unit=file-service-sheet`를 열고 **Insert → Image → Float Image**로 이미지를 삽입합니다.

## 다중 노드 배포 [#multi-node]

Nginx 뒤에서 두 개의 협업 노드를 실행합니다. Redis가 노드 간 실시간 업데이트를 전달하고 Session Ticket을 공유하므로 어떤 노드든 모든 요청을 처리할 수 있습니다. Docker Compose와 두 노드를 포함하는 [라이선스](/server/collaboration/license#nodes)가 필요합니다.

```bash
pnpm example:multi-node
```

`http://127.0.0.1:3010/`를 열고 **New Sheet**를 클릭해 파일을 만듭니다. 전체 URL을 다른 탭에 복사하여 같은 문서의 협업 편집을 확인하세요. 파일을 몇 개 더 만들어 여러 노드에 어떻게 할당되는지 살펴보세요.

- [예제 가이드](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/multi-node/README.md)

<Callout title="예제는 운영 애플리케이션이 아닙니다">
고정 사용자, 교육용 권한, Memory Adapter, 로컬 비밀 정보, 메모리 작업 저장소는 학습용입니다. 신원 확인, 권한, 영속성, 비밀 정보, 파일, 배포, 제품 상호작용은 애플리케이션이 담당합니다.
</Callout>
