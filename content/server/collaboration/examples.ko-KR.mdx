## 빠른 시작 [#quick-start]

협업 클라이언트, 운송, 엔드포인트, 서비스 및 메모리 어댑터를 조립합니다. 두 브라우저를 사용하여 HTTP 로딩, WebSocket 세션, 룸, ACK 및 동일한 시트를 방송합니다.

```bash
pnpm example:quick-start
```

`http://127.0.0.1:3010/?unit=quick-start-sheet`를 엽니다.

- [예제 가이드](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/README.md)

- [Web 진입점](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/web/main.ts)
- [이 사이트의 단계별 가이드](/server/collaboration/quick-start)

## 데이터베이스 어댑터 [#database-adapter]

내장 SQLite 어댑터로 시작하면 PostgreSQL 접합기 또는 어댑터로 교체하십시오.

## 기록 [#history]

History Service, 별도의 어댑터, History Endpoint 및 브라우저 역사 항목, 모든 외부 코어를 추가합니다. 단위 생성 및 변경 사항은 이벤트 빌드 기록에 따라 재구성 될 수 있는 파생된 인덱스로 작성됩니다.

```bash
pnpm example:history
```

`http://127.0.0.1:3010/?unit=history-sheet`를 열고 Sheet를 편집한 뒤 상단의 `History`를 선택합니다.

- [예제 가이드](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/README.md)
- [서버 진입점](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/server/main.ts)
- [Web 진입점](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/web/main.ts)

## 댓글 [#comments]

스레드 코멘트 서비스, 별도의 어댑터, 코멘트 엔드포인트 및 프론트 엔드 댓글 입력을 추가하십시오. 코멘트 엔드포인트는 메인 협업 엔드포인트의 세션 및 유닛 룸에 재사용합니다.

## Worktree [#worktree]

전체 수명주기를 따르십시오 : 격리 된 초안, 준비, Reopen 및 per-Unit Merge. 간선과 초안 사이의 전환은 합병 될 때까지 어떻게 분리되는지 관찰합니다.

```bash
pnpm example:worktree
```

`http://127.0.0.1:3010/?unit=worktree-sheet&worktree=demo-worktree`를 엽니다.

## 파일 서비스 [#file-service]

File Service 및 File Endpoint를 연결하십시오. Sheet에 삽입 된 이미지는 서버로 업로드되며, Unit Data 레코드는 파일 ID 만 연결됩니다.

```bash
pnpm example:file-service
```

`http://127.0.0.1:3010/?unit=file-service-sheet`를 열고 **Insert → Image → Float Image**로 이미지를 삽입합니다.

## 파일 변환 [#exchange]

Exchange Service 및 Exchange Endpoint for server-side Sheet 가져오기 및 내보내기, 작업 polling 및 확인된 개정에 수출을 통합합니다.

```bash
pnpm example:exchange
```

## 다중 노드 배포 [#multi-node]

Nginx 뒤에 두 개의 협업 노드를 실행하십시오. Redis는 노드와 공유 세션 티켓 간의 실시간 업데이트를 릴레이하므로 노드가 어떤 요청을 제공 할 수 있습니다. 예를 들어 Docker Compose와 [이름 *](/server/collaboration/license#nodes)가 두 노드를 다룹니다.

```bash
pnpm example:multi-node
```

`http://127.0.0.1:3010/`를 열고 **새로운 시트** 파일을 만들 수 있습니다. 다른 탭으로 전체 URL을 복사하여 동일한 문서의 협업 편집을 확인합니다. 그런 다음 여러 파일을 만들고 노드를 통해 배포하는 방법을 관찰하십시오.

- [예제 가이드](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/multi-node/README.md)
