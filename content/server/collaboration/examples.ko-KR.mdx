## 빠른 시작 [#quick-start]

Collaboration Client, Transport, Endpoint, Service, Memory Adapter를 조합합니다. 두 브라우저에서 같은 Sheet의 HTTP 로드, WebSocket Session, Room, ACK, 브로드캐스트를 확인합니다.

```bash
pnpm example:quick-start
```

`http://127.0.0.1:3010/?unit=quick-start-sheet&type=2`를 엽니다.

- [예제 가이드](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/README.md)
- [서버 진입점](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/server/main.ts)
- [Web 진입점](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/web/main.ts)
- [이 사이트의 단계별 가이드](/server/collaboration/quick-start)

## 데이터베이스 어댑터 [#database-adapter]

사용자 정의 Memory, PostgreSQL, 내장 SQLite Adapter를 비교합니다. 트랜잭션, 리비전 CAS, 배치 원자성, `customData` 트랜잭션 경계를 보여줍니다.

```bash
pnpm example:database-adapter
```

`http://127.0.0.1:3010/?unit=database-adapter-sheet&type=2`를 엽니다.

- [예제 가이드](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/database-adapter/README.md)

## 권한 [#permissions]

Cookie로 신뢰할 수 있는 신원을 만들고 Unit HTTP 읽기, 실시간 JOIN, 변경 집합 제출을 각각 보호합니다. 페이지에서 교육용 `editor`와 읽기 전용 `viewer`를 전환합니다.

```bash
pnpm example:permissions
```

`http://127.0.0.1:3010`를 엽니다.

## 기록 [#history]

핵심 밖에 History Service, 독립 Adapter, History Endpoint, 브라우저 기록 진입점을 추가합니다. Unit 생성·변경 커밋 Events로 재구축 가능한 파생 기록 인덱스를 만듭니다.

```bash
pnpm example:history
```

`http://127.0.0.1:3010/?unit=history-sheet&type=2`를 열고 Sheet를 편집한 뒤 상단의 `History`를 선택합니다.

- [예제 가이드](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/README.md)
- [서버 진입점](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/server/main.ts)
- [Web 진입점](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/web/main.ts)

## 댓글 [#comments]

Thread Comment Service, 독립 Adapter, Comment Endpoint, 프런트엔드 댓글 진입점을 추가합니다. Comment Endpoint는 주 협업 Endpoint의 Session과 Unit Room을 재사용합니다.

```bash
pnpm example:comments
```

`http://127.0.0.1:3010/?unit=comments-sheet&type=2`를 열고 셀을 선택해 댓글 기능을 사용합니다.

- [예제 가이드](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/comments/README.md)

## Worktree [#worktree]

## 파일 변환 [#exchange]

`@univerjs-pro/exchange-node`와 Collaboration Service로 서버 Sheet 가져오기·내보내기, 작업 폴링, 스냅샷 가져오기, 확정 리비전 내보내기를 구성합니다.

```bash
pnpm example:exchange
```

`http://127.0.0.1:3010/?unit=exchange-sheet&type=2`를 엽니다. **File → Open (File)**로 가져오고 **File → Save As**로 내보냅니다.

- [예제 가이드](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/README.md)
- [서버 진입점](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/server/main.ts)
- [파일 변환 흐름](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/server/exchange.ts)
- [Web 진입점](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/web/main.ts)

<Callout title="예제는 운영 애플리케이션이 아닙니다">
고정 사용자, 교육용 권한, Memory Adapter, 로컬 비밀 정보, 메모리 파일·작업 저장소는 학습용입니다. 신원 확인, 권한, 영속성, 비밀 정보, 파일, 배포, 제품 상호작용은 애플리케이션이 담당합니다.
</Callout>
