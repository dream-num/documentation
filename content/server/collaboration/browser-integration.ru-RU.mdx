Совместное редактирование подключает браузерные редакторы к сервису общих документов. Например, два пользователя открывают одну таблицу, и изменение в одном браузере появляется в другом.

Подготовьте сервер по руководству [Интеграция сервера](/server), затем настройте редактор и загрузку ниже. Рассматривайте Server и Web из [Быстрого старта Office](/server/collaboration/quick-start) вместе.

## Подключение существующего редактора

Сохраните ваш редактор Web SDK. По [настройке браузера в быстром старте](/server/collaboration/quick-start) добавьте плагины совместного редактирования и адреса загрузки документов, отправки изменений и WebSocket. Поддерживайте совместимые версии браузерных и серверных пакетов.

Фиксированные пользователи и права примера предназначены для демонстрации. В приложении передавайте учётные данные в запросах, чтобы сервер проверял личность и доступ к документу. Лицензирование описано в [настройке лицензии](/guides/license).

## Создание и открытие одного документа

Создание и открытие — разные действия:

1. При создании документа сервер сохраняет его и возвращает ID.
2. Браузер загружает этот ID. Используйте его повторно при открытии или передаче другому пользователю.

Поле API `unitId` — это ID документа. Не создавайте новый пустой локальный документ при каждом посещении.

Например, после регистрации Sheets и совместных плагинов загрузите серверную таблицу:

```ts
import '@univerjs-pro/collaboration-client/facade'

const workbook = await univerAPI.getCollaboration().loadSheetAsync('your-document-id')
if (!workbook) throw new Error('Document could not be loaded')
```

Способы загрузки для продуктов описаны в [Sheets](/guides/sheets/features/collaboration), [Docs](/guides/docs/features/collaboration), [Slides](/guides/slides/features/collaboration), [Boards](/guides/boards/features/collaboration), [Bases](/guides/bases/features/collaboration) и [PDFs](/guides/pdfs/features/collaboration). Проверьте поддержку в продукте и целевом серверном выпуске.

## Проверка синхронизации, сохранения и прав

Откройте один документ в двух независимых сеансах, например обычном и приватном окне. Измените его в одном и проверьте второй. Затем проверьте содержимое после обновления, переподключения и перезапуска сервера.

Тестируйте редактора, читателя и пользователя без доступа. Режим только для чтения в UI управляет взаимодействиями страницы, но сервер всё равно должен отклонять неавторизованные чтения и изменения.

Если загрузка работает, а синхронизация нет, проверьте WebSocket. Если после перезапуска содержимое исчезает, проверьте серверное хранилище. Настройки описаны в [интеграции сервера](/server).

## Добавление обмена файлами, комментариев или истории

Для совместного редактирования импортированного файла создайте документ из преобразованных данных; см. [Интеграция обмена файлами](/server/import-export). Комментарии и история требуют собственных плагинов, сервисов и прав. Следуйте разделу [Модули расширений Office](/server/collaboration/extensions).

Настройка панелей истории описана в [Sheets](/guides/sheets/features/edit-history), [Docs](/guides/docs/features/edit-history), [Slides](/guides/slides/features/edit-history), [Boards](/guides/boards/features/edit-history) и [Bases](/guides/bases/features/edit-history). Текущие возможности PDFs см. в [Истории PDFs](/guides/pdfs/features/edit-history).
