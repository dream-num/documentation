## Inicio rápido [#quick-start]

Assemble Cliente de Colaboración, Transporte, Endpoint, Servicio y Adaptador de Memoria. Utilice dos navegadores para verificar la carga HTTP, sesiones WebSocket, la Sala, ACK y la transmisión para la misma Hoja.

```bash
pnpm example:quick-start
```

Abre `http://127.0.0.1:3010/?unit=quick-start-sheet`.

## Permisos [#permissions]

Construir una identidad de confianza de una cookie, luego proteger la unidad HTTP lecturas, INGRESO en tiempo real, y la presentación de cambios por separado. La página cambia entre la cuenta de enseñanza **Alice · Editor** y la cuenta de sólo lectura **Bob · Visor**.

```bash
pnpm example:permissions
```

Abre `http://127.0.0.1:3010`.

## Historial [#history]

Añadir Servicio de Historia, un adaptador separado, el punto final de la historia y la entrada de la historia del navegador, todo fuera del núcleo. La creación de la unidad y los cambios comprometen Eventos construyen la historia como un índice derivado que puede ser reconstruido.

```bash
pnpm example:history
```

Abre `http://127.0.0.1:3010/?unit=history-sheet`, edita la Sheet y selecciona `History` arriba.

- [Guía del ejemplo](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/README.md)
- [Entrada del servidor](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/server/main.ts)
- [Entrada Web](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/web/main.ts)

## Comentarios [#comments]

Añadir Thread Comment Service, un adaptador separado, el comentario Endpoint, y la entrada de comentario de frontend. El comentario Endpoint reutiliza las sesiones y las salas de unidad de la colaboración principal Endpoint.

```bash
pnpm example:comments
```

Abre `http://127.0.0.1:3010/?unit=comments-sheet`, selecciona una celda y usa la entrada de comentarios.

## Worktree [#worktree]

## Servicio de archivos [#file-service]

Conectar el servicio de archivos y el endpoint de archivo. Las imágenes insertadas en la hoja se cargan al servidor, y los datos de la unidad solo registran el ID de archivo.

## Despliegue en varios nodos [#multi-node]

Ejecutar dos nodos de colaboración detrás de Nginx. Redis transmite actualizaciones en tiempo real entre los nodos y las acciones de sesión, por lo que cualquier nodo puede servir cualquier solicitud. El ejemplo también requiere Docker Compose y un [Licencia](/server/collaboration/license#nodes) que cubre dos nodos.

```bash
pnpm example:multi-node
```

Abra `http://127.0.0.1:3010/` y seleccione **Nueva hoja de página** para crear un archivo. Copiar la URL completa en otra pestaña para verificar la edición de colaboración del mismo documento. A continuación, crear varios archivos más y observar cómo se distribuyen a través de los nodos.

- [Guía del ejemplo](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/multi-node/README.md)
