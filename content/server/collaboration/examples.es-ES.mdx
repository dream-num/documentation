## Inicio rápido [#quick-start]

Combina Collaboration Client, Transport, Endpoint, Service y Memory Adapter. Verifica en dos navegadores la carga HTTP, Sessions WebSocket, Room, ACK y difusión para la misma Sheet.

```bash
pnpm example:quick-start
```

Abre `http://127.0.0.1:3010/?unit=quick-start-sheet&type=2`.

- [Guía del ejemplo](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/README.md)
- [Entrada del servidor](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/server/main.ts)
- [Entrada Web](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/web/main.ts)

## Permisos [#permissions]

Crea una identidad fiable desde una cookie y protege por separado lectura HTTP Unit, JOIN en tiempo real y envío de cambios. La página alterna entre un `editor` didáctico y un `viewer` de solo lectura.

```bash
pnpm example:permissions
```

Abre `http://127.0.0.1:3010`.

- [Guía del ejemplo](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/permissions/README.md)

## Historial [#history]

Añade fuera del núcleo History Service, un Adapter separado, History Endpoint y la entrada de historial del navegador. Los Events de creación Unit y commit construyen un índice derivado reconstruible.

```bash
pnpm example:history
```

Abre `http://127.0.0.1:3010/?unit=history-sheet&type=2`, edita la Sheet y selecciona `History` arriba.

- [Guía del ejemplo](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/README.md)
- [Entrada del servidor](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/server/main.ts)
- [Entrada Web](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/web/main.ts)

## Worktree [#worktree]

Demuestra el ciclo completo de borrador aislado, Ready, Reopen y Merge por Unit. Alterna tronco y borrador para ver cómo los cambios del AI Agent quedan aislados antes de fusionar.

```bash
pnpm example:worktree
```

Abre `http://127.0.0.1:3010/?unit=worktree-sheet&type=2&worktree=demo-worktree`.

## Conversión de archivos [#exchange]

Combina `@univerjs-pro/exchange-node` y Collaboration Service para importar/exportar Sheet en servidor, consultar tareas, importar instantáneas y exportar revisiones confirmadas.

```bash
pnpm example:exchange
```

Abre `http://127.0.0.1:3010/?unit=exchange-sheet&type=2`. Importa con **File → Open (File)** y exporta con **File → Save As**.

- [Guía del ejemplo](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/README.md)
- [Entrada del servidor](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/server/main.ts)
- [Flujo de conversión](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/server/exchange.ts)
- [Entrada Web](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/web/main.ts)

<Callout title="Los ejemplos no son aplicaciones de producción">
Usuarios fijos, autorización didáctica, Memory Adapters, secretos locales y almacenamiento de archivos y tareas en memoria son solo educativos. La aplicación gestiona identidad, autorización, persistencia, secretos, archivos, despliegue e interacción.
</Callout>
