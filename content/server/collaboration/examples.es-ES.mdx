## Inicio rápido [#quick-start]

Combina Collaboration Client, Transport, Endpoint, Service y Memory Adapter. Verifica en dos navegadores la carga HTTP, Sessions WebSocket, Room, ACK y difusión para la misma Sheet.

```bash
pnpm example:quick-start
```

Abre `http://127.0.0.1:3010/?unit=quick-start-sheet`.

## Permisos [#permissions]

```bash

```

Abre `http://127.0.0.1:3010`.

## Historial [#history]

Añade fuera del núcleo History Service, un Adapter separado, History Endpoint y la entrada de historial del navegador. Los Events de creación Unit y commit construyen un índice derivado reconstruible.

```bash

```

Abre `http://127.0.0.1:3010/?unit=history-sheet`, edita la Sheet y selecciona `History` arriba.

## Despliegue en varios nodos [#multi-node]

Ejecuta dos nodos de colaboración detrás de Nginx. Redis reenvía las actualizaciones en tiempo real entre nodos y comparte los session tickets, de modo que cualquier nodo puede atender cualquier solicitud. Requiere Docker Compose y una [licencia](/server/collaboration/license#nodes) que cubra dos nodos.

```bash
pnpm example:multi-node
```

Abre `http://127.0.0.1:3010/` y haz clic en **New Sheet** para crear un archivo. Copia la URL completa en otra pestaña para verificar la edición colaborativa del mismo documento. Después, crea algunos archivos más para observar cómo se distribuyen entre los nodos.

- [Guía del ejemplo](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/multi-node/README.md)

<Callout title="Los ejemplos no son aplicaciones de producción">
Usuarios fijos, autorización didáctica, Memory Adapters, secretos locales y almacenamiento de tareas en memoria son solo educativos. La aplicación gestiona identidad, autorización, persistencia, secretos, archivos, despliegue e interacción.
</Callout>
