## Быстрый старт [#quick-start]

Соберите Collaboration Client, Transport, Endpoint, Service и Memory Adapter. Проверьте в двух браузерах HTTP-загрузку, Sessions WebSocket, Room, ACK и рассылку одной Sheet.

```bash
pnpm example:quick-start
```

Откройте `http://127.0.0.1:3010/?unit=quick-start-sheet&type=2`.

- [Руководство примера](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/README.md)
- [Серверная точка входа](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/server/main.ts)
- [Точка входа Web](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/web/main.ts)
- [Пошаговое руководство на сайте](/server/collaboration/quick-start)

## Адаптер базы данных [#database-adapter]

Сравните собственные Memory и SQLite Adapters со встроенным SQLite. Показаны транзакции, CAS ревизии, атомарность пакетов и транзакционная граница `customData`.

```bash
pnpm example:database-adapter
```

Откройте `http://127.0.0.1:3010/?unit=persistent-sheet&type=2`.

- [Руководство примера](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/database-adapter/README.md)

- [Точка входа Web](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/database-adapter/web/main.ts)

## Права доступа [#permissions]

Создайте доверенную идентичность из cookie и отдельно защитите HTTP-чтение Unit, JOIN и отправку изменений. Страница переключается между учебным **Alice · Editor** и **Bob · Viewer** только для чтения.

```bash
pnpm example:permissions
```

Откройте `http://127.0.0.1:3010`.

- [Руководство примера](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/permissions/README.md)

- [Руководство идентификации и авторизации](/server/collaboration/identity-and-authorization)

## История [#history]

Добавьте вне ядра History Service, отдельный Adapter, History Endpoint и вход истории браузера. Events создания Unit и коммита строят восстанавливаемый производный индекс.

```bash
pnpm example:history
```

Откройте `http://127.0.0.1:3010/?unit=history-sheet&type=2`, измените Sheet и выберите `History` сверху.

- [Руководство примера](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/README.md)
- [Серверная точка входа](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/server/main.ts)

## Комментарии [#comments]

Добавьте Thread Comment Service, отдельный Adapter, Comment Endpoint и вход комментариев интерфейса. Comment Endpoint использует Sessions и Rooms Unit основного Endpoint.

```bash
pnpm example:comments
```

Откройте `http://127.0.0.1:3010/?unit=comments-sheet&type=2`, выберите ячейку и откройте комментарии.

## Worktree [#worktree]

Показан полный цикл изолированного черновика, Ready, Reopen и Merge по Unit. Переключайтесь между основной веткой и черновиком, чтобы увидеть изоляцию правок AI Agent до слияния.

```bash
pnpm example:worktree
```

Откройте `http://127.0.0.1:3010/?unit=worktree-sheet&type=2&worktree=demo-worktree`.

- [Руководство примера](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/worktree/README.md)
- [Серверная точка входа](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/worktree/server/main.ts)
- [Точка входа Web](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/worktree/web/main.ts)
- [CLI и проверка человеком](/ai/worktree)

## Преобразование файлов [#exchange]

Объедините `@univerjs-pro/exchange-node` и Collaboration Service для серверного импорта/экспорта Sheet, опроса задач, импорта снимков и экспорта подтверждённых ревизий.

```bash
pnpm example:exchange
```

Откройте `http://127.0.0.1:3010/?unit=exchange-sheet&type=2`. Импортируйте через **File → Open (File)**, экспортируйте через **File → Save As**.

- [Руководство примера](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/README.md)
- [Серверная точка входа](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/server/main.ts)
- [Процесс преобразования](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/server/exchange.ts)
- [Точка входа Web](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/web/main.ts)

<Callout title="Примеры не являются промышленными приложениями">
Фиксированные пользователи, учебная авторизация, Memory Adapters, локальные секреты и хранение файлов и задач в памяти служат обучению. Приложение отвечает за идентификацию, авторизацию, хранение, секреты, файлы, развёртывание и взаимодействие.
</Callout>
