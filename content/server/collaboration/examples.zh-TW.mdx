## 快速開始 [#quick-start]

組裝 Collaboration Client、Transport、Endpoint、Service 與 Memory Adapter。在兩個瀏覽器中開啟同一個 Sheet，可以驗證 HTTP 載入、WebSocket Session、Room、ACK 與廣播。

```bash
pnpm example:quick-start
```

開啟 `http://127.0.0.1:3010/?unit=quick-start-sheet`。

## 權限 [#permissions]

從 Cookie 建立可信身分，再分別保護 Unit HTTP 讀取、即時 JOIN 與 changeset 提交。頁面在 **Alice · Editor** 與只讀的 **Bob · Viewer** 兩個教學賬號之間切換。

```bash
pnpm example:permissions
```

開啟 `http://127.0.0.1:3010`。

## 歷史 [#history]

在 Core 之外加入 History Service、獨立的 Adapter、History Endpoint 與瀏覽器歷史入口。Unit 建立與 changeset commit 兩個 Event 將 History 建立為可重建的派生索引。

```bash
pnpm example:history
```

開啟 `http://127.0.0.1:3010/?unit=history-sheet`，編輯 Sheet，然後選擇頁面上方的 `History`。

- [範例指南](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/README.md)

## 留言 [#comments]

加入 Thread Comment Service、獨立的 Adapter、Comment Endpoint 與前端評論入口。Comment Endpoint 複用主協同 Endpoint 的 Session 與 Unit Room。

## Worktree [#worktree]

完整演示獨立 draft、Ready、Reopen 與逐 Unit Merge 的生命週期。在 trunk 與 draft 之間切換，可以觀察到 Agent 的修改在合入前始終保持隔離。

```bash
pnpm example:worktree
```

開啟 `http://127.0.0.1:3010/?unit=worktree-sheet&worktree=demo-worktree`。

## 檔案服務 [#file-service]

## 多節點部署 [#multi-node]

在 Nginx 後執行兩個協同節點。Redis 在節點之間轉發即時更新並共享 Session Ticket，因此任意節點都能處理任意請求。執行本範例還需要 Docker Compose 和一個覆蓋兩個節點的[許可證](/server/collaboration/license#nodes)。

```bash
pnpm example:multi-node
```

開啟 `http://127.0.0.1:3010/`，選擇 **New Sheet** 建立檔案。將完整 URL 複製到另一個標籤頁，驗證同一份文件的協同編輯。再建立若干檔案，觀察它們在不同節點上的分配情況。

- [範例指南](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/multi-node/README.md)
