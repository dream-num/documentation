## 快速開始 [#quick-start]

組合 Collaboration Client、Transport、Endpoint、Service 與 Memory Adapter。使用兩個瀏覽器驗證同一 Sheet 的 HTTP 載入、WebSocket Session、Room、ACK 與廣播。

```bash
pnpm example:quick-start
```

開啟 `http://127.0.0.1:3010/?unit=quick-start-sheet&type=2`。

## 資料庫配接器 [#database-adapter]

比較自訂 Memory、PostgreSQL 與內建 SQLite Adapter。這些實作展示交易、修訂版本 CAS、批次原子性及 `customData` 交易邊界。

```bash
pnpm example:database-adapter
```

開啟 `http://127.0.0.1:3010/?unit=database-adapter-sheet&type=2`。

## 權限 [#permissions]

從 Cookie 建立可信身分，分別保護 Unit HTTP 讀取、即時 JOIN 與變更集提交。頁面可切換教學用 `editor` 與唯讀 `viewer`。

```bash
pnpm example:permissions
```

開啟 `http://127.0.0.1:3010`。

- [範例指南](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/permissions/README.md)

## 歷史 [#history]

在核心之外加入 History Service、獨立 Adapter、History Endpoint 與瀏覽器歷史入口。透過 Unit 建立及變更集提交 Events，將 History 建為可重建的衍生索引。

```bash
pnpm example:history
```

開啟 `http://127.0.0.1:3010/?unit=history-sheet&type=2`，編輯 Sheet，再選取頁面頂部的 `History`。

- [範例指南](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/README.md)

## Worktree [#worktree]

展示隔離草稿、Ready、Reopen 與逐 Unit Merge 的完整生命週期。切換主幹與草稿，觀察 AI Agent 的變更在合併前如何保持隔離。

```bash
pnpm example:worktree
```

開啟 `http://127.0.0.1:3010/?unit=worktree-sheet&type=2&worktree=demo-worktree`。

## 檔案轉換 [#exchange]

組合 `@univerjs-pro/exchange-node` 與 Collaboration Service，實現服務端 Sheet 匯入匯出、任務輪詢、快照匯入與已確認修訂版本匯出。

```bash
pnpm example:exchange
```

開啟 `http://127.0.0.1:3010/?unit=exchange-sheet&type=2`。透過 **File → Open (File)** 匯入，透過 **File → Save As** 匯出。

- [範例指南](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/README.md)
- [服務端入口](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/exchange/server/main.ts)
