Esta página explica cómo seleccionar paquetes de Collaboration SDK. Comience con la colaboración de núcleo, a continuación, agregue los módulos de extensión que el producto requiere. Instalar cada paquete no es necesario.

Los paquetes de servidor para Adaptadores de Bases de Datos, File y Office Exchange son de código abierto bajo Apache-2.0, y su código fuente se publica en [univer-collaboration-sdk-community](https://github.com/dream-num/univer-collaboration-sdk-community). Estos paquetes utilizan el mismo paquete prefijo y versión como cualquier otro paquete, y se instalan de la misma manera.

## Core Collaboration

Core Collaboration proporciona la ruta principal: colaboración con el navegador, manejo del protocolo del servidor, OT, revisiones y persistencia.

| Entorno | Paquete | ¿Qué hace? |
| -------- | ---------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Navegador  | [**@univerjs-pro/collaboration**](https://www.npmjs.com/package/@univerjs-pro/collaboration)                                 | Registra las capacidades básicas de colaboración del navegador               |
| Navegador  | [**@univerjs-pro/collaboration-client**](https://www.npmjs.com/package/@univerjs-pro/collaboration-client)                   | Carga Units, envía cambios y mantiene sincronización en tiempo real |
| Navegador  | [**@univerjs-pro/collaboration-client-ui**](https://www.npmjs.com/package/@univerjs-pro/collaboration-client-ui)             | Proporciona UI y estilos de estado colaborativo                             |
| Server   | [**@univerjs-pro/collaboration-transport-node**](https://www.npmjs.com/package/@univerjs-pro/collaboration-transport-node)   | Recibe tráfico HTTP y WebSocket de Node.js                             |
| Server   | [**@univerjs-pro/collaboration-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-endpoint)               | Implementa protocolo Client, Sessions, Rooms y Presence           |
| Server   | [**@univerjs-pro/collaboration-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-service)                 | Gestiona Units, OT, revisiones y API centrales                     |
| Base de datos | [**@univerjs-pro/collaboration-database-memory**](https://www.npmjs.com/package/@univerjs-pro/collaboration-database-memory) | Almacenamiento en proceso para pruebas, ejemplos y desarrollo temporal       |
| Base de datos | [**@univerjs-pro/collaboration-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-database-sqlite) | Persistencia SQLite para desarrollo, pruebas, uso local y pequeña escala |
| Base de datos | [**@univerjs-pro/collaboration-database-postgres**](https://www.npmjs.com/package/@univerjs-pro/collaboration-database-postgres) | Persistencia PostgreSQL compartida por varios nodos |
| Multi-node | [**@univerjs-pro/collaboration-cluster-redis**](https://www.npmjs.com/package/@univerjs-pro/collaboration-cluster-redis) | Adaptador pub/sub y almacén de session tickets sobre Redis para el despliegue en varios nodos |

Un servidor básico requiere Transporte, Endpoint, Service y un adaptador de base. Memoria, SQLite y PostgreSQL implementan el mismo contrato de Adaptador, por lo que una aplicación normalmente selecciona uno de ellos. Un despliegue de varios nodos requiere además un adaptador pub/sub y una tienda de tickets de sesión compartida. El Endpoint define ambos contratos (`IPubSubAdapter`, `ISessionTicketStore`), y el SDK proporciona una implementación de Redis.

## History

La historia construye un índice de historia-versión de la creación de la Unidad y los cambios de compromiso Eventos que Core emite.

| Entorno | Paquete | ¿Qué hace? |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| Navegador  | Reutiliza Core Client/UI                                                                                                                        | Muestra y lee entradas del historial                   |
| Server   | [**@univerjs-pro/collaboration-history-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-history-service)                 | Construye y consulta el índice del historial                 |
| Server   | [**@univerjs-pro/collaboration-history-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-history-endpoint)               | Proporciona el protocolo History al Client |
| Base de datos | [**@univerjs-pro/collaboration-history-database-memory**](https://www.npmjs.com/package/@univerjs-pro/collaboration-history-database-memory) | Almacenamiento en proceso del índice History |
| Base de datos | [**@univerjs-pro/collaboration-history-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-history-database-sqlite) | Guarda el índice derivado de History                     |

Los datos de historia son un índice derivado y siempre se pueden reconstruir. Los cambios básicos siguen siendo autorizados para el contenido de la unidad.

## Thread Comment

Thread Comment gestiona los órganos de comentarios, las respuestas y el estado resuelto en hojas y documentos.

| Entorno | Paquete | ¿Qué hace? |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Navegador  | Reutiliza paquetes Core Collaboration                                                                                                           | Usa Comment Client y UI                                |
| Server   | [**@univerjs-pro/collaboration-comment-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-comment-service)                 | Gestiona comentarios y el evento `commentCommitted`            |
| Server   | [**@univerjs-pro/collaboration-comment-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-comment-endpoint)               | Proporciona el protocolo y publica cambios en Unit Rooms |
| Base de datos | [**@univerjs-pro/collaboration-comment-database-memory**](https://www.npmjs.com/package/@univerjs-pro/collaboration-comment-database-memory) | Almacenamiento de comentarios en proceso                                             |
| Base de datos | [**@univerjs-pro/collaboration-comment-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-comment-database-sqlite) | Persistencia de comentarios en SQLite                                             |

Comment Adapter guarda los comentarios. Los anclajes que se mueven con el contenido siguen en instantáneas y cambios Core.

## Worktree

Worktree ofrece borradores aislados, transiciones y fusión por Unit.

| Entorno | Paquete | ¿Qué hace? |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| Navegador  | [**@univerjs-pro/collaboration-worktree-client**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-client)                   | Conecta borradores, estados y fusión Worktree |
| Server   | [**@univerjs-pro/collaboration-worktree-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-service)                 | Gestiona cambios del borrador, estado y fusión             |
| Server   | [**@univerjs-pro/collaboration-worktree-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-endpoint)               | Proporciona el protocolo a Worktree Client       |
| Base de datos | [**@univerjs-pro/collaboration-worktree-database-memory**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-database-memory) | Almacenamiento Worktree en proceso                             |
| Base de datos | [**@univerjs-pro/collaboration-worktree-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-database-sqlite) | Persistencia Worktree en SQLite                             |

El servicio Worktree finalmente se fusiona en el maletero a través del servicio básico, por lo que Middleware debe ser configurado en ambos límites del servicio.

## File

Los archivos almacenan los archivos binarios que los clientes de Univer suben: imágenes y archivos adjuntos insertados en una Unidad, junto con los archivos fuente y resultado de una importación o exportación.

| Entorno | Paquete | ¿Qué hace? |
| --- | --- | --- |
| Navegador | Reutiliza el Core Collaboration Client | Sube imágenes y adjuntos y resuelve los ID de archivo a URL |
| Server | [**@univerjs-pro/collaboration-file-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-service) | Aplica las reglas de propiedad, el Middleware y la limpieza de archivos temporales |
| Server | [**@univerjs-pro/collaboration-file-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-endpoint) | Proporciona las rutas de subida, sign-url y descarga |
| Base de datos | [**@univerjs-pro/collaboration-file-memory**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-memory) | Almacenamiento en proceso de metadatos y contenido |
| Base de datos | [**@univerjs-pro/collaboration-file-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-database-sqlite) | Persistencia SQLite de los metadatos de archivo |
| Base de datos | [**@univerjs-pro/collaboration-file-database-postgres**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-database-postgres) | Persistencia PostgreSQL de los metadatos de archivo |
| Almacenamiento | [**@univerjs-pro/collaboration-file-blob-local**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-blob-local) | Guarda el contenido en un directorio local |
| Almacenamiento | [**@univerjs-pro/collaboration-file-blob-s3**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-blob-s3) | Guarda el contenido en un almacenamiento de objetos compatible con S3, con enlaces directos firmados |

Los metadatos y el contenido son dos contratos independientes, por lo que cada uno puede utilizar el almacenamiento que la aplicación ya proporciona. Los metadatas pueden residir en la base de datos mientras el contenido reside en el almacenamiento de objetos.

## Office Exchange

Office Exchange importa archivos Office como Units colaborativas y exporta Units como archivos. File guarda los archivos de origen y resultado.

| Entorno | Paquete | ¿Qué hace? |
| --- | --- | --- |
| Navegador | [**@univerjs-pro/exchange-client**](https://www.npmjs.com/package/@univerjs-pro/exchange-client) | Proporciona intercambio básico de archivos del navegador |
| Navegador | [**@univerjs-pro/sheets-exchange-client**](https://www.npmjs.com/package/@univerjs-pro/sheets-exchange-client) | Proporciona importación y exportación Sheet |
| Server | [**@univerjs-pro/collaboration-exchange-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-exchange-service) | Gestiona las task de importación y exportación, el Middleware y la creación y lectura de Units |
| Server | [**@univerjs-pro/collaboration-exchange-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-exchange-endpoint) | Proporciona las rutas de importación, exportación y task |
| Server | [**@univerjs-pro/exchange-node**](https://www.npmjs.com/package/@univerjs-pro/exchange-node) | Convierte Office y datos Univer en Node.js |

Exchange Service crea y lee Unidades a través de Core Service y lee y escribe archivos a través de File Service, por lo que debe ser reunido junto con Core y File.

## Reglas de selección

1. Empieza por los paquetes Core de [Inicio rápido](/server/collaboration/quick-start).
2. Elige un Core Database Adapter: Memory, SQLite, PostgreSQL o propio.
3. Para un despliegue en varios nodos, añade el adaptador pub/sub y el almacén de session tickets sobre Redis.
4. Instala sólo los paquetes de módulos de extensión que utiliza el producto.
5. Si el producto requiere imágenes, apegos, o importación y exportación, ensamblar el archivo primero y añadir Office Exchange sólo cuando sea necesario.
6. Cree un adaptador separado para cada módulo incluso cuando varios módulos comparten una base de datos.

Vea [Módulos de extensión de colaboración](/server/collaboration/extensions) para las relaciones entre módulos, y el [índice de ejemplos](/server/collaboration/examples) de montajes ejecutables.
