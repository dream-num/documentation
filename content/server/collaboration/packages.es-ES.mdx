Esta página guía la selección. Compón primero Core Collaboration y añade las extensiones necesarias. No necesitas instalar todos los paquetes.

## Core Collaboration

Core Collaboration proporciona el flujo principal de colaboración en navegador, protocolo de servidor, OT, revisiones y persistencia.

| Entorno  | Paquete                                                                                                                      | Responsabilidad principal                                                  |
| -------- | ---------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Navegador  | [**@univerjs-pro/collaboration**](https://www.npmjs.com/package/@univerjs-pro/collaboration)                                 | Registra las capacidades básicas de colaboración del navegador               |
| Navegador  | [**@univerjs-pro/collaboration-client**](https://www.npmjs.com/package/@univerjs-pro/collaboration-client)                   | Carga Units, envía cambios y mantiene sincronización en tiempo real |
| Navegador  | [**@univerjs-pro/collaboration-client-ui**](https://www.npmjs.com/package/@univerjs-pro/collaboration-client-ui)             | Proporciona UI y estilos de estado colaborativo                             |
| Server   | [**@univerjs-pro/collaboration-transport-node**](https://www.npmjs.com/package/@univerjs-pro/collaboration-transport-node)   | Recibe tráfico HTTP y WebSocket de Node.js                             |
| Server   | [**@univerjs-pro/collaboration-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-endpoint)               | Implementa protocolo Client, Sessions, Rooms y Presence           |
| Server   | [**@univerjs-pro/collaboration-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-service)                 | Gestiona Units, OT, revisiones y API centrales                     |
| Base de datos | [**@univerjs-pro/collaboration-database-memory**](https://www.npmjs.com/package/@univerjs-pro/collaboration-database-memory) | Almacenamiento en proceso para pruebas, ejemplos y desarrollo temporal       |
| Base de datos | [**@univerjs-pro/collaboration-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-database-sqlite) | Persistencia SQLite para desarrollo, pruebas, uso local y pequeña escala |

Core Server necesita Transport, Endpoint, Service y un Database Adapter. Memory y SQLite cumplen el mismo contrato; normalmente se elige uno.

## History

History construye un índice de versiones con eventos de creación de Unit y commit del Core.

| Entorno  | Paquete                                                                                                                                      | Responsabilidad principal                               |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| Navegador  | Reutiliza Core Client/UI                                                                                                                        | Muestra y lee entradas del historial                   |
| Server   | [**@univerjs-pro/collaboration-history-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-history-service)                 | Construye y consulta el índice del historial                 |
| Server   | [**@univerjs-pro/collaboration-history-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-history-endpoint)               | Proporciona el protocolo History al Client |
| Base de datos | [**@univerjs-pro/collaboration-history-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-history-database-sqlite) | Guarda el índice derivado de History                     |

El historial es un índice derivado reconstruible. Los cambios Core siguen siendo la referencia del contenido.

## Thread Comment

Thread Comment gestiona textos, respuestas y estado resuelto en Sheets y Docs.

| Entorno  | Paquete                                                                                                                                      | Responsabilidad principal                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Navegador  | Reutiliza paquetes Core Collaboration                                                                                                           | Usa Comment Client y UI                                |
| Server   | [**@univerjs-pro/collaboration-comment-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-comment-service)                 | Gestiona comentarios y el evento `commentCommitted`            |
| Server   | [**@univerjs-pro/collaboration-comment-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-comment-endpoint)               | Proporciona el protocolo y publica cambios en Unit Rooms |
| Base de datos | [**@univerjs-pro/collaboration-comment-database-memory**](https://www.npmjs.com/package/@univerjs-pro/collaboration-comment-database-memory) | Almacenamiento de comentarios en proceso                                             |
| Base de datos | [**@univerjs-pro/collaboration-comment-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-comment-database-sqlite) | Persistencia de comentarios en SQLite                                             |

Comment Adapter guarda los comentarios. Los anclajes que se mueven con el contenido siguen en instantáneas y cambios Core.

## Worktree

Worktree ofrece borradores aislados, transiciones y fusión por Unit.

| Entorno  | Paquete                                                                                                                                        | Responsabilidad principal                                  |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| Navegador  | [**@univerjs-pro/collaboration-worktree-client**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-client)                   | Conecta borradores, estados y fusión Worktree |
| Server   | [**@univerjs-pro/collaboration-worktree-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-service)                 | Gestiona cambios del borrador, estado y fusión             |
| Server   | [**@univerjs-pro/collaboration-worktree-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-endpoint)               | Proporciona el protocolo a Worktree Client       |
| Base de datos | [**@univerjs-pro/collaboration-worktree-database-memory**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-database-memory) | Almacenamiento Worktree en proceso                             |
| Base de datos | [**@univerjs-pro/collaboration-worktree-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-database-sqlite) | Persistencia Worktree en SQLite                             |

Worktree Service fusiona en trunk mediante Core Service; configura Middleware en ambas fronteras.

## Office Exchange

Office Exchange combina conversión y Collaboration Service en un flujo de aplicación; no tiene Database Adapter colaborativo independiente.

| Entorno | Paquete                                                                                                        | Responsabilidad principal                                   |
| ------- | -------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| Navegador | [**@univerjs-pro/exchange-client**](https://www.npmjs.com/package/@univerjs-pro/exchange-client)               | Proporciona intercambio básico de archivos del navegador |
| Navegador | [**@univerjs-pro/sheets-exchange-client**](https://www.npmjs.com/package/@univerjs-pro/sheets-exchange-client) | Proporciona importación y exportación Sheet                    |
| Server  | [**@univerjs-pro/exchange-node**](https://www.npmjs.com/package/@univerjs-pro/exchange-node)                   | Convierte Office y datos Univer en Node.js         |

Al importar se pasan datos convertidos a `createUnitFromSnapshot()`. Al exportar se lee una revisión confirmada por Core Service. Archivos, tareas y API siguen bajo control de la aplicación.

## Reglas de selección

1. Empieza por los paquetes Core de [Inicio rápido](/server/collaboration/quick-start).
2. Elige un Core Database Adapter: Memory, SQLite o propio.
3. Instala solo las extensiones que use el producto.
4. Crea Adapters separados por módulo aunque compartan un archivo SQLite.

Consulta [Extensiones de colaboración](/server/collaboration/extensions) para relaciones e [Índice de ejemplos](/server/collaboration/examples) para composiciones ejecutables.
