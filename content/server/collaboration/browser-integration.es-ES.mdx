La colaboración conecta los editores del navegador a un servicio de documentos compartidos. Por ejemplo, dos usuarios abren la misma hoja de cálculo y una edición en un navegador aparece en el otro.

Prepara el backend con la [integración del servidor](/server) y configura el editor y la carga de documentos a continuación. Sigue conjuntamente el código Server y Web de [Inicio rápido de Office](/server/collaboration/quick-start).

## Conectar el editor existente

Conserva tu editor Web SDK. Sigue la [configuración del navegador del inicio rápido](/server/collaboration/quick-start) para añadir plugins de colaboración y configurar carga, envío de cambios y direcciones WebSocket. Mantén compatibles las versiones de los paquetes del navegador y del servidor.

Los usuarios fijos y permisos predeterminados son demostrativos. En tu aplicación, incluye las credenciales de inicio de sesión en las solicitudes para que el backend verifique identidad y acceso al documento. Consulta la [configuración de la licencia](/server/license).

## Crear y abrir el mismo documento

Crear y abrir son acciones distintas:

1. Cuando un usuario crea un documento, el backend lo guarda y devuelve su ID.
2. El navegador carga ese ID. Reutilízalo al volver a abrir o compartir el documento.

El `unitId` de la API es ese ID de documento. No crees un documento local vacío nuevo en cada visita.

Por ejemplo, tras registrar Sheets y los plugins de colaboración, carga una hoja de cálculo del servidor:

```ts
import '@univerjs-pro/collaboration-client/facade'

const workbook = await univerAPI.getCollaboration().loadSheetAsync('your-document-id')
if (!workbook) throw new Error('Document could not be loaded')
```

Consulta las guías de [Sheets](/guides/sheets/features/collaboration), [Docs](/guides/docs/features/collaboration), [Slides](/guides/slides/features/collaboration), [Boards](/guides/boards/features/collaboration), [Bases](/guides/bases/features/collaboration) y [PDFs](/guides/pdfs/features/collaboration) para la carga específica. Comprueba la compatibilidad del producto y la versión de backend objetivo.

## Verificar sincronización, guardado y permisos

Abre el mismo documento en dos sesiones independientes, como una ventana normal y otra privada. Edita en una y comprueba la otra. Verifica el contenido tras actualizar, reconectar y reiniciar el servidor.

Prueba con un editor, un lector y un usuario sin autorización. Los ajustes UI de solo lectura controlan la interacción de la página; el servidor debe seguir rechazando lecturas y cambios no autorizados.

Si los documentos cargan pero las ediciones no se sincronizan, revisa WebSocket. Si el contenido desaparece al reiniciar, revisa el almacenamiento del backend. Consulta esos ajustes en [Integración del servidor](/server).

## Añadir intercambio, comentarios o historial

Para editar juntos un archivo importado, crea un documento colaborativo con los datos convertidos; consulta la [integración de intercambio de archivos](/server/import-export). Los comentarios y el historial necesitan sus propios plugins, servicios y permisos. Sigue los [módulos de extensión de Office](/server/collaboration/extensions).

Para configurar el panel de historial, consulta [Sheets](/guides/sheets/features/edit-history), [Docs](/guides/docs/features/edit-history), [Slides](/guides/slides/features/edit-history), [Boards](/guides/boards/features/edit-history) y [Bases](/guides/bases/features/edit-history). Consulta el alcance actual de PDFs en [Historial de PDFs](/guides/pdfs/features/edit-history).
