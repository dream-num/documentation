На этой странице описаны два пути. Первый запускает официальный пример и проверяет полный путь совместной работы в двух браузерах. Второй представляет минимальную сборку Server и Web, которую можно скопировать в собственное приложение Univer.

Перед началом выполните [требования к среде и версиям](/server/requirements). Все пакеты `@univerjs/*` и `@univerjs-pro/*` должны быть закреплены за одним совместимым набором выпусков.

## Первый путь: официальный пример

### Подготовка к запуску

Этот репозиторий требует **Node.js 24+** и объявляет **pnpm 10.32.1**. Проверяйте `node --version` и `pnpm --version`, используйте файл блокировки репозитория и запускайте все команды `pnpm example:*` из корня репозитора. Каждая команда строит браузер и сервер, проверяет тип примера, а затем запускает его. Эти команды не обеспечивают сервер разработки горячей перезагрузки, поэтому после редактирования исходных файлов вы должны остановить процесс и запустить команду снова.

Если у вас есть Лицензия, установите `UNIVER_LICENSE` и `UNIVER_LICENSE_KEY` в своей оболочке перед запуском команды. В сборку встраивается `UNIVER_LICENSE` через `vite.config.ts`, а Collaboration SDK считывает обе переменные при запуске сервера. Перезапустите команду после изменения Лицензии. См. [Лицензия](/server/license#collaboration-sdk).

```bash
git clone https://github.com/dream-num/univer-collaboration-examples.git
cd univer-collaboration-examples
pnpm install --frozen-lockfile
pnpm example:quick-start
```

Откройте следующий URL:

```text
http://127.0.0.1:3010/?unit=quick-start-sheet
```

### Проверка совместного редактирования в реальном времени

1. Откройте полный URL в одном окне браузера.
2. Откройте тот же URL во втором окне или на другой вкладке.
3. Измените одну ячейку в любом листе.
4. Убедитесь, что изменение появилось во втором браузере.

Каждое окно открывает собственную сессию WebSocket. Когда будете проверять две учётные записи в [примере настройки прав](/server/collaboration/examples#permissions), используйте разные профили браузера, чтобы разделить файлы cookie для входа.

### Что подтверждает успех

```text
Univer Collaboration Client
  → Node Transport
  → UniverCollabEndpoint
  → UniverCollabService
  → MemoryDatabaseAdapter
```

Если два браузера остаются синхронизированными, работает полный путь. Каждый браузер загружал блок по HTTP, открывал сеанс WebSocket с одноразовым билетом на сеанс и присоединялся к той же комнате. Сервис выполнял OT, подтверждал новую редакцию, сохранял ее через адаптер, а Endpoint транслировал эту редакцию другим участникам.

## Второй путь: перенос в приложение

Код ниже - минимальная серверная и веб-ассемблера. Официальный Quick Start содержит полную структуру приложения:

- [server/main.ts](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/server/main.ts)
- [web/main.ts](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/web/main.ts)
- [package.json](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/package.json)

Если у вас уже есть веб-приложение Univer, сохраните его время выполнения, предустановки и пользовательский интерфейс и добавьте только конфигурацию клиента совместной работы и сервер, описанные ниже. Для пустого проекта скопируйте `index.html`, `vite.config.ts` и стили из каталога Quick Start и используйте их в качестве оболочки приложения.

### Перенос исполняемых файлов

Скопируйте `examples/quick-start` в качестве исходного скелета и сохраните `package.json`, `index.html`, `vite.config.ts`, `web/styles.css`, `web/main.ts` и `server/main.ts`. Запустите его сценарии сборки и запуска из этого каталога, потому что Express обслуживает `dist/web` относительно рабочего каталога. Сохраните определение лицензии Vite и дайте `#app` ненулевую высоту. Код ниже только объясняет, как эти части собираются; для полного запуска проекта используйте файлы репозитория.

Пример обслуживает страницу и `/universer-api` из одного и того же источника. Если вы перемещаете интерфейс в другое место, прокси-сервер как HTTP, так и обновление WebSocket в бэкэнд или меняете все пять URL-адресов клиента вместе. `unit` должен соответствовать идентификатору, созданному бэкэндом; один только параметр URL не создает документ. Пример читает `unit` и загружает документ явно с `loadSheetAsync()`. В вашем приложении установите текущего пользователя перед загрузкой, как описано в [Интеграция сотрудничества](/server/collaboration/browser-integration) .

### 1. Установка совместимого набора пакетов

Серверу нужен Транспорт, Конечная точка, Сервис и один Адаптер Базы данных. Браузеру нужен Клиент Сотрудничества. Установите пакеты, затем прикрепите каждый пакет Univer к одной и той же точной версии:

```bash
pnpm add \
  @univerjs-pro/collaboration \
  @univerjs-pro/collaboration-client \
  @univerjs-pro/collaboration-client-ui \
  @univerjs-pro/collaboration-database-memory \
  @univerjs-pro/collaboration-endpoint \
  @univerjs-pro/collaboration-service \
  @univerjs-pro/collaboration-transport-node \
  @univerjs-pro/license \
  @univerjs/core \
  @univerjs/preset-sheets-core \
  @univerjs/presets \
  @univerjs/protocol \
  express react react-dom rxjs
```

Официальный пример манифеста является беговой, авторитетный справочник для текущего состава пакета и точных версий.

### 2. Создание Service, Endpoint и начальной Unit

`UniverCollabService` является авторитетным ядром совместной работы. Конечная точка отображает протокол браузера на Сервисе, а адаптер памяти временно хранит снимки, изменения и изменения:

```ts
import type { IWorkbookData } from "@univerjs/core";
import { createServer } from "node:http";
import express from "express";
import { LocaleType } from "@univerjs/core";
import { MemoryDatabaseAdapter } from "@univerjs-pro/collaboration-database-memory";
import { UniverCollabEndpoint } from "@univerjs-pro/collaboration-endpoint";
import { UniverCollabService } from "@univerjs-pro/collaboration-service";
import { createNodeTransport } from "@univerjs-pro/collaboration-transport-node";
import { ErrorCode, UniverType } from "@univerjs/protocol";

const UNIT_ID = "quick-start-sheet";
const unitData: IWorkbookData = {
  id: UNIT_ID,
  rev: 1,
  name: "Quick Start Sheet",
  appVersion: "",
  locale: LocaleType.EN_US,
  sheetOrder: ["sheet-1"],
  sheets: {
    "sheet-1": {
      id: "sheet-1",
      name: "Sheet 1",
      rowCount: 100,
      columnCount: 26,
      cellData: {},
    },
  },
  styles: {},
  resources: [],
};

const database = new MemoryDatabaseAdapter();
const service = new UniverCollabService({ dbAdapter: database });
const endpoint = new UniverCollabEndpoint(service);
const transport = createNodeTransport();

transport.use(async (context, next) => {
  context.userID = "demo-user";
  await next();
});
transport.register(endpoint);

await service.createUnitFromData(
  { type: UniverType.UNIVER_SHEET, data: unitData },
  { userID: "demo-user" },
);
```

Фиксированный `demo-user` иллюстрирует, как доверенная личность перетекает из Транспорта в конечную точку и Сервис.Производственное приложение проверяет свои собственные файлы cookie, токен на предъявителя или сеанс внутри `transport.use()`, а затем устанавливает стабильный бизнес `userID`.

### 3. Подключение авторизации, HTTP и WebSocket

Текущий клиент Collaboration запрашивает протокол авторизации. Quick Start возвращает `allowed: true` для этого маршрута по каждому запросу и прикрепляет Транспорт к HTTP-серверу приложения:

```ts
const app = express();

app.post("/universer-api/authz/-/object/-/batch_allowed", express.json(), (request, response) => {
  const body = request.body as {
    requests: Array<{ unitID: string; objectID: string; actions: unknown[] }>;
  };
  response.json({
    error: { code: ErrorCode.OK, message: "" },
    objectActions: body.requests.map((item) => ({
      unitID: item.unitID,
      objectID: item.objectID,
      actions: item.actions.map((action) => ({ action, allowed: true })),
    })),
  });
});

app.use(express.static("dist/web"));

const server = createServer(app);
transport.attach(server);
server.listen(3010, "127.0.0.1");
```

Предоставление каждого запроса - это ярлык обучения, а не граница безопасности. Производственное приложение должно защищать HTTP-считывания, JOIN в реальном времени, представление изменений и операции жизненного цикла блока. См. [Идентификация и авторизация](/server/collaboration/identity-and-authorization) для полной модели покрытия.

### 4. Регистрация клиента Collaboration в браузерном Runtime

Сохраните стандартные Web SDK и предустановки, затем добавьте плагины Collaboration и URL-адреса протокола:

#### Настройка плагинов [#plugin-configuration]

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое файла клиентской лицензии. |

`UniverCollaborationClientPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `socketService` | `Ctor<ICollaborationSocketService>` |  | Реализация сокета использует текущее время выполнения. |
| `sendChangesetTimeout` | `number` | `2000` | Как долго редактируются изменения, в миллисекундах, прежде чем они будут отправлены. |
| `authzUrl` | `string` | `'/universer-api/authz'` | Конечная точка проверки разрешений. |
| `snapshotServerUrl` | `string` | `'/universer-api/snapshot'` | Конечная точка загрузки снимков документа. |
| `collabSubmitChangesetUrl` | `string` | `'/universer-api/comb'` | Конечная точка отправки наборов изменений. |
| `collabWebSocketUrl` | `string` | `'ws://127.0.0.1:8000/universer-api/comb/connect'` | Адрес WebSocket для синхронизации в реальном времени. |
| `wsSessionTicketUrl` | `string` | `'/universer-api/user/session-ticket'` | Конечная точка получения билета сеанса WebSocket. |

#### Настройка пресетов [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | DOM-элемент для размещения редактора или его идентификатор. |

```ts
import { LocaleType, LogLevel } from "@univerjs/core";
import { UniverCollaborationPlugin } from "@univerjs-pro/collaboration";
import { UniverCollaborationClientPlugin } from "@univerjs-pro/collaboration-client";
import CollaborationClientEnUS from "@univerjs-pro/collaboration-client/locale/en-US";
import {
  BrowserCollaborationSocketService,
  UniverCollaborationClientUIPlugin,
} from "@univerjs-pro/collaboration-client-ui";
import CollaborationClientUIEnUS from "@univerjs-pro/collaboration-client-ui/locale/en-US";
import { UniverLicensePlugin } from "@univerjs-pro/license";
import { UniverSheetsCorePreset } from "@univerjs/preset-sheets-core";
import UniverPresetSheetsCoreEnUS from "@univerjs/preset-sheets-core/locales/en-US";
import { createUniver, defaultTheme, mergeLocales } from "@univerjs/presets";
import "@univerjs-pro/collaboration-client/facade";
import "@univerjs/preset-sheets-core/lib/index.css";
import "@univerjs-pro/collaboration-client-ui/lib/index.css";

const httpProtocol = location.protocol === "https:" ? "https" : "http";
const wsProtocol = location.protocol === "https:" ? "wss" : "ws";
const baseURL = `${httpProtocol}://${location.host}/universer-api`;

const unitId = new URLSearchParams(location.search).get("unit");
if (!unitId) throw new Error("Open the URL printed by the server; it names the Sheet with ?unit=.");
const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      CollaborationClientEnUS,
      CollaborationClientUIEnUS,
    ),
  },
  theme: defaultTheme,
  logLevel: LogLevel.WARN,
  collaboration: true,
  presets: [UniverSheetsCorePreset({ container: "app" })],
  plugins: [
    [UniverLicensePlugin, { license: import.meta.env.UNIVER_LICENSE || undefined }],
    UniverCollaborationPlugin,
    [
      UniverCollaborationClientPlugin,
      {
        socketService: BrowserCollaborationSocketService,
        sendChangesetTimeout: 200,
        authzUrl: `${baseURL}/authz`,
        snapshotServerUrl: `${baseURL}/snapshot`,
        collabSubmitChangesetUrl: `${baseURL}/comb`,
        collabWebSocketUrl: `${wsProtocol}://${location.host}/universer-api/comb/connect`,
        wsSessionTicketUrl: `${baseURL}/user/session-ticket`,
      },
    ],
    UniverCollaborationClientUIPlugin,
  ],
});

const workbook = await univerAPI.getCollaboration().loadSheetAsync(unitId);
if (!workbook) throw new Error("Document could not be loaded");
```

Страница требует элемент с `id="app"` и выбирает Блок через параметры запроса:

```text
/?unit=quick-start-sheet
```

### 5. Замена учебных настроек возможностями приложения

| Учебная настройка | Замена |
| --- | --- |
| Фиксированный `demo-user` | Middleware аутентификации и стабильный ID пользователя |
| Проверки разрешений, которые всегда позволяют | Серверный ACL для чтения, JOIN, отправки и жизненного цикла |
| фиксированная единица | API создания и запись продукта, вызывающие `createUnitFromData()` |
| Адаптер памяти | SQLite или собственный постоянный Adapter с контрактными тестами |

Продолжайте с [Адаптер баз данных](/server/collaboration/database-adapters) и [Идентификация и авторизация](/server/collaboration/identity-and-authorization). Затем добавьте [История, Thread Comment, Worktree или Exchange](/server/collaboration/extensions) по мере необходимости. [Примеры индексов](/server/collaboration/examples) охватывает каждую исполняемую композицию.

## Проблемы первого запуска

| Симптом | Проверка |
| --- | --- |
| Ошибка установки или сборки | Node.js 24+, заявленный pnpm, одинаковые версии Univer |
| Порт 3010 занят | Остановить предыдущий пример или задать `PORT=3011` и обновить оба URL |
| Пустая страница или нет ресурсов | Завершена сборка; запуск выполняется из каталога примеров; `#app` имеет высоту |
| Изменения не синхронизируются | Один и тот же полный URL-адрес в обоих окнах; успешные запросы на снимок и сеансовый билет; подключение к WebSocket в `/universer-api/comb/connect` |
| Данные исчезли после перезапуска | Quick Start использует память; перейти к SQLite |
