title: 授權
description: Collaboration SDK 依授權決定協同編輯連線、授權網域、協同節點與可協同的文件類型。
---

`UniverCollabService` 在構造時載入許可證，Endpoint 與 Worktree 共用同一份。許可證的配置方式見[許可證](/server/license#collaboration-sdk)；未配置許可證時，SDK 按免費版執行。許可證校驗失敗時，建構函式丟擲 `CollabError`（`LICENSE_INVALID` 或 `LICENSE_POLICY_INVALID`），服務無法完成啟動。

## 授權決定的四項 [#limits]

| 項目 | 檢查位置 | 超出時 |
| --- | --- | --- |
| 協同編輯連線 | Endpoint 接收提交時 | 新連線的修改留在瀏覽器中，自動重試 |
| 授權網域 | Endpoint 建立連線、接收提交時 | 瀏覽器中的協同工作階段轉為離線 |
| 協同節點 | Endpoint | 超出的節點經過寬限期後下線 |
| 文件類型 | Service 建立 Unit、提交修改時 | 建立與提交均被拒絕，已有文件仍可檢視 |

### 協同編輯連線 [#editing-connections]

名額僅計入正在編輯的連線。一條協同連線在首次成功提交後佔用一個名額，並在連線關閉或距最近一次成功提交滿 120 秒時釋放該名額。僅開啟文件檢視的連線可以隨時加入。Worktree 內的編輯與主線編輯共用同一個名額池。

名額佔滿後，新連線提交的修改會保留在瀏覽器中，由 Web SDK 按退避間隔持續重發，直到有名額釋放；已佔用名額的連線可繼續編輯。瀏覽器端的 `CollaborationChangesetResend` 透過 `reason: 'license_editing_connections_exceeded'` 上報這類重發。

### 授權網域 [#domains]

Web SDK 每次建立協同連線或提交修改時，Endpoint 都會用頁面域名核對許可證中的授權域名。域名不在授權範圍內時，請求返回 `403`，瀏覽器中的協同會話轉為離線並顯示原因；使用者重新連線或開啟其他文件時，會話會再次嘗試。

### 協同節點 [#nodes]

**單節點許可證**（含免費版）執行一個協同節點。向 Endpoint 傳入 `pubSub` 時，建構函式丟擲 `LICENSE_POLICY_INVALID`。

**多節點許可證**規定節點數上限。實際執行的節點數超過上限時，最新加入的節點進入寬限期，期間警告逐級升級，隨後下線：新連線返回 `503`，已有連線斷開。上限以內的節點繼續提供服務。寬限期內節點數降回上限以內時，超出的節點恢復正常。已下線的節點在程序重啟後作為新節點重新計數。多節點部署見[部署](/server/deployment#多協同節點)。

### 文件類型 [#unit-types]

許可證列明可協同的文件型別。建立其他型別的 Unit 時會丟擲 `LICENSE_UNIT_TYPE_REJECTED`，提交的修改也會被拒絕；瀏覽器端 `CollaborationConflict` 的 `reason` 為 `license_unit_type_rejected`。已有文件仍可開啟檢視。

## 觀察狀態 [#observe]

```ts
// Service
collabService.license.status // 授權狀態：'not_configured' | 'expired' | 'valid'
collabService.license.editingConnectionsLimit // 協同編輯連線上限：number | null，null 表示不限
collabService.license.nodesLimit // 協同節點上限：number | null，null 表示不限
collabService.license.domains // 授權網域：string[]
collabService.license.expiresAt // 到期時間：ISO 字串 | null，未設定時為 null
collabService.license.update({ license, licenseKey }) // 替換授權：驗證失敗時拋錯並保留目前授權

// Endpoint
endpoint.license.editingConnections.limit // 名額上限：number | null，null 表示不限
endpoint.license.editingConnections.used // 已佔名額：number | null，limit 不限時為 null
endpoint.license.editingConnections.remaining // 剩餘名額：number | null，null 表示不限
endpoint.license.editingConnections.has(memberID) // 該成員是否佔有名額：boolean，limit 不限時為 false
endpoint.license.nodes.limit // 節點上限：number | null，null 表示不限
endpoint.license.nodes.status // 本節點狀態：'normal' | 'exceeded' | 'exceeded-warning' | 'exceeded-offlineSoon' | 'exceeded-offline'

// 事件
endpoint.license.on('editingConnectionsChanged', ({ change, memberIDs, used, limit }) => {}) // 名額被佔用或釋放時觸發：change 為 'acquired' | 'released'，used 為變化後的值，limit 不限時不觸發
endpoint.license.on('editingConnectionsExceeded', ({ memberID, userID, unitID, used, limit }) => {}) // 名額已滿，新連線的提交未能儲存時觸發
endpoint.license.on('nodesStatusChanged', ({ status, previousStatus, limit, reason }) => {}) // 本節點狀態變化時觸發，reason 僅在下線時有值
```

`nodesStatusChanged` 在本節點狀態每次變化時觸發一次。`status` 變為 `exceeded-offline` 時，該節點已停止接受新連線，應將其從負載均衡中移除，或發出告警。
