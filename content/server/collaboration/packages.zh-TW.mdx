本頁說明如何從 Collaboration SDK 中選擇 package。先組裝 Core Collaboration，再按產品需要加入擴充套件模組，不需要安裝全部 package。

Database Adapter、File 和 Office Exchange 的伺服器端 package 以 Apache-2.0 協議開源，原始碼釋出在 [univer-collaboration-sdk-community](https://github.com/dream-num/univer-collaboration-sdk-community)。這些 package 使用與其他 package 相同的包名字首和版本，安裝方式也相同。

## Core Collaboration

Core Collaboration 提供主鏈路：瀏覽器協同、伺服器端協議、OT、revision 與持久化。

| 執行環境   | 套件                                                                                                                                   | 主要職責                                                           |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 瀏覽器     | [**@univerjs-pro/collaboration**](https://www.npmjs.com/package/@univerjs-pro/collaboration)                                           | 註冊瀏覽器基礎協同能力                                             |
| 瀏覽器     | [**@univerjs-pro/collaboration-client**](https://www.npmjs.com/package/@univerjs-pro/collaboration-client)                             | 載入 Unit、提交變更集並維持即時同步                                |
| 瀏覽器     | [**@univerjs-pro/collaboration-client-ui**](https://www.npmjs.com/package/@univerjs-pro/collaboration-client-ui)                       | 提供協同狀態 UI 與樣式                                             |
| Server     | [**@univerjs-pro/collaboration-transport-node**](https://www.npmjs.com/package/@univerjs-pro/collaboration-transport-node)             | 接收 Node.js HTTP 與 WebSocket 流量                                |
| Server     | [**@univerjs-pro/collaboration-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-endpoint)                         | 實作 Client 協定、Session、Room 與 Presence                        |
| Server     | [**@univerjs-pro/collaboration-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-service)                           | 管理 Unit、OT、修訂版本與核心 Service API                          |
| 資料庫     | [**@univerjs-pro/collaboration-database-memory**](https://www.npmjs.com/package/@univerjs-pro/collaboration-database-memory)           | 用於測試、範例與臨時開發的程序內儲存                               |
| 資料庫     | [**@univerjs-pro/collaboration-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-database-sqlite)           | 適用開發、測試、本機及小規模使用的 SQLite 持久化                   |
| 資料庫     | [**@univerjs-pro/collaboration-database-postgres**](https://www.npmjs.com/package/@univerjs-pro/collaboration-database-postgres)       | PostgreSQL 持久化，多個節點共用一個資料庫                          |
| 資料庫     | [**@univerjs-pro/collaboration-database-postgres-s3**](https://www.npmjs.com/package/@univerjs-pro/collaboration-database-postgres-s3) | 將 Sheet 資料區塊存入 S3，減少 PostgreSQL 資料庫及其備份的大小     |
| Multi-node | [**@univerjs-pro/collaboration-cluster-redis**](https://www.npmjs.com/package/@univerjs-pro/collaboration-cluster-redis)               | 基於 Redis 的 pub/sub 介面卡與 Session Ticket 儲存，用於多節點部署 |

Core Server 需要 Transport、Endpoint、Service 和一個 Database Adapter。Memory、SQLite、PostgreSQL 與 PostgreSQL + S3 實現同一套 Adapter 契約，應用通常只選用其中一種。多節點部署還需要一個 pub/sub 介面卡和一份共享的 Session Ticket 儲存。這兩個契約（`IPubSubAdapter`、`ISessionTicketStore`）由 Endpoint 定義，SDK 提供 Redis 實現。

## History

History 依據 Core 發出的 Unit 建立與 changeset commit Event 建立版本歷史索引。

| 執行環境 | 套件                                                                                                                                             | 主要職責                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------- |
| 瀏覽器   | 重用核心 Client／UI                                                                                                                              | 顯示與讀取歷史項目           |
| Server   | [**@univerjs-pro/collaboration-history-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-history-service)                     | 建立與查詢歷史索引           |
| Server   | [**@univerjs-pro/collaboration-history-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-history-endpoint)                   | 為 Client 提供 History 協定  |
| 資料庫   | [**@univerjs-pro/collaboration-history-database-memory**](https://www.npmjs.com/package/@univerjs-pro/collaboration-history-database-memory)     | History 索引的程序內儲存     |
| 資料庫   | [**@univerjs-pro/collaboration-history-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-history-database-sqlite)     | 儲存衍生的 History 索引      |
| 資料庫   | [**@univerjs-pro/collaboration-history-database-postgres**](https://www.npmjs.com/package/@univerjs-pro/collaboration-history-database-postgres) | 在 PostgreSQL 中儲存歷史索引 |

History 資料是派生索引，可以隨時重建。Unit 內容仍以 Core changeset 為準。

## Thread Comment

Thread Comment 管理留言本文、回覆和解決狀態。

| 執行環境 | 套件                                                                                                                                             | 主要職責                               |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------- |
| 瀏覽器   | 重用核心協同套件                                                                                                                                 | 使用 Comment Client 與 UI 能力         |
| Server   | [**@univerjs-pro/collaboration-comment-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-comment-service)                     | 管理留言操作與 `commentCommitted` 事件 |
| Server   | [**@univerjs-pro/collaboration-comment-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-comment-endpoint)                   | 提供留言協定，透過 Unit Room 發布更新  |
| 資料庫   | [**@univerjs-pro/collaboration-comment-database-memory**](https://www.npmjs.com/package/@univerjs-pro/collaboration-comment-database-memory)     | 程序內留言儲存                         |
| 資料庫   | [**@univerjs-pro/collaboration-comment-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-comment-database-sqlite)     | SQLite 留言持久化                      |
| 資料庫   | [**@univerjs-pro/collaboration-comment-database-postgres**](https://www.npmjs.com/package/@univerjs-pro/collaboration-comment-database-postgres) | 在 PostgreSQL 中儲存留言與回覆         |

評論資料由 Comment Adapter 儲存。隨內容移動的 anchor 仍屬於 Core snapshot 與 changeset。

## Worktree

Worktree 提供隔離的 draft、狀態流轉以及以 Unit 為單位的合入。

| 執行環境 | 套件                                                                                                                                               | 主要職責                           |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| 瀏覽器   | [**@univerjs-pro/collaboration-worktree-client**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-client)                       | 接入 Worktree 草稿、狀態與合併能力 |
| Server   | [**@univerjs-pro/collaboration-worktree-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-service)                     | 管理草稿變更集、狀態與合併         |
| Server   | [**@univerjs-pro/collaboration-worktree-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-endpoint)                   | 提供 Worktree Client 協定能力      |
| 資料庫   | [**@univerjs-pro/collaboration-worktree-database-memory**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-database-memory)     | 程序內 Worktree 儲存               |
| 資料庫   | [**@univerjs-pro/collaboration-worktree-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-database-sqlite)     | SQLite Worktree 持久化             |
| 資料庫   | [**@univerjs-pro/collaboration-worktree-database-postgres**](https://www.npmjs.com/package/@univerjs-pro/collaboration-worktree-database-postgres) | 在 PostgreSQL 中保存 Worktree 草稿 |

Worktree Service 最終透過 Core Service 合入 trunk，因此需要在兩個 Service 邊界上分別配置 Middleware。

## File

File 儲存 Univer 用戶端上傳的二進位檔案：插入 Unit 的圖片與附件，以及匯入匯出的來源檔與結果檔。Unit 資料只記錄檔案 ID。

| 執行環境 | 套件 | 主要職責 |
| --- | --- | --- |
| 瀏覽器 | 重用 Core Collaboration Client | 上傳圖片與附件，依檔案 ID 換取下載網址 |
| Server | [**@univerjs-pro/collaboration-file-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-service) | 執行檔案歸屬規則、Middleware 與暫存檔清理 |
| Server | [**@univerjs-pro/collaboration-file-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-endpoint) | 提供上傳、sign-url 與下載路由 |
| 資料庫 | [**@univerjs-pro/collaboration-file-memory**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-memory) | 中繼資料與內容的程序內儲存 |
| 資料庫 | [**@univerjs-pro/collaboration-file-database-sqlite**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-database-sqlite) | 檔案中繼資料的 SQLite 持久化 |
| 資料庫 | [**@univerjs-pro/collaboration-file-database-postgres**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-database-postgres) | 檔案中繼資料的 PostgreSQL 持久化 |
| 儲存 | [**@univerjs-pro/collaboration-file-blob-local**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-blob-local) | 檔案內容儲存在本機目錄 |
| 儲存 | [**@univerjs-pro/collaboration-file-blob-s3**](https://www.npmjs.com/package/@univerjs-pro/collaboration-file-blob-s3) | 檔案內容儲存在 S3 相容物件儲存，可簽發直連網址 |

後設資料與內容屬於兩套獨立契約，可以分別使用應用現有的儲存，例如後設資料存放在資料庫、內容存放在物件儲存。

## Office Exchange

Office Exchange 將 Office 檔案匯入為協同 Unit，也支援將 Unit 匯出為檔案。原始檔和結果檔案由 File 儲存。

| 執行環境 | 套件 | 主要職責 |
| --- | --- | --- |
| 瀏覽器 | [**@univerjs-pro/exchange-client**](https://www.npmjs.com/package/@univerjs-pro/exchange-client) | 提供瀏覽器基礎檔案交換能力 |
| 瀏覽器 | [**@univerjs-pro/sheets-exchange-client**](https://www.npmjs.com/package/@univerjs-pro/sheets-exchange-client) | 提供 Sheet 檔案匯入匯出 |
| Server | [**@univerjs-pro/collaboration-exchange-service**](https://www.npmjs.com/package/@univerjs-pro/collaboration-exchange-service) | 管理匯入匯出 task、Middleware 與 Unit 的建立和讀取 |
| Server | [**@univerjs-pro/collaboration-exchange-endpoint**](https://www.npmjs.com/package/@univerjs-pro/collaboration-exchange-endpoint) | 提供匯入、匯出與 task 查詢路由 |
| Server | [**@univerjs-pro/exchange-node**](https://www.npmjs.com/package/@univerjs-pro/exchange-node) | 在 Node.js 轉換 Office 檔案與 Univer 資料 |

Exchange Service 透過 Core Service 建立和讀取 Unit，透過 File Service 讀寫檔案，因此需要與 Core 和 File 一起組裝。

## 選擇原則

1. 從 [Quick Start](/server/collaboration/quick-start) 中的 Core package 開始。
2. 依應用程式的儲存需求選擇一個 [Core Database Adapter](/server/collaboration/database-adapters)。
3. 多節點部署時，加入 Redis 的 pub/sub 介面卡與 Session Ticket 儲存。
4. 只安裝產品實際使用的擴充套件模組 package。
5. 需要圖片、附件或匯入匯出能力時，先組裝 File，再按需加入 Office Exchange。
6. 即使多個模組共用一個資料庫，也要為每個模組分別建立 Adapter。

模組之間的關係見[協同擴充套件模組](/server/collaboration/extensions)，可直接執行的組合見[範例索引](/server/collaboration/examples)。
