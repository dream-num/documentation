---
title: 许可证
description: Collaboration SDK 按许可证决定协同编辑连接、授权域名、协同节点与可协同的文档类型。
---

`UniverCollabService` 在构造时加载许可证，Endpoint 与 Worktree 共用同一份。许可证的配置方式见[许可证](/server/license#collaboration-sdk)；未配置许可证时，SDK 按免费版运行。许可证校验失败时，构造函数抛出 `CollabError`（`LICENSE_INVALID` 或 `LICENSE_POLICY_INVALID`），服务无法完成启动。

## 许可证决定的四项 [#limits]

| 项目         | 校验位置                      | 超出时                               |
| ------------ | ----------------------------- | ------------------------------------ |
| 协同编辑连接 | Endpoint 接收提交时           | 新连接的修改留在浏览器中，自动重试   |
| 授权域名     | Endpoint 建立连接、接收提交时 | 浏览器中的协同会话转为离线           |
| 协同节点     | Endpoint                      | 超出的节点经过宽限期后下线           |
| 文档类型     | Service 创建 Unit、提交修改时 | 创建与提交均被拒绝，已有文档仍可查看 |

### 协同编辑连接 [#editing-connections]

名额仅计入正在编辑的连接。一条协同连接在首次成功提交后占用一个名额，并在连接关闭或距最近一次成功提交满 120 秒时释放该名额。仅打开文档查看的连接可以随时加入。Worktree 内的编辑与主线编辑共用同一个名额池。

名额占满后，新连接提交的修改会保留在浏览器中，由 Web SDK 按退避间隔持续重发，直到有名额释放；已占用名额的连接可继续编辑。浏览器端的 `CollaborationChangesetResend` 通过 `reason: 'license_editing_connections_exceeded'` 上报这类重发。

### 授权域名 [#domains]

Web SDK 每次建立协同连接或提交修改时，Endpoint 都会用页面域名核对许可证中的授权域名。域名不在授权范围内时，请求返回 `403`，浏览器中的协同会话转为离线并显示原因；用户重新连接或打开其他文档时，会话会再次尝试。

### 协同节点 [#nodes]

**单节点许可证**（含免费版）运行一个协同节点。向 Endpoint 传入 `pubSub` 时，构造函数抛出 `LICENSE_POLICY_INVALID`。

**多节点许可证**规定节点数上限。实际运行的节点数超过上限时，最新加入的节点进入宽限期，期间警告逐级升级，随后下线：新连接返回 `503`，已有连接断开。上限以内的节点继续提供服务。宽限期内节点数降回上限以内时，超出的节点恢复正常。已下线的节点在进程重启后作为新节点重新计数。多节点部署见[部署](/server/deployment#多协同节点)。

### 文档类型 [#unit-types]

许可证列明可协同的文档类型。创建其他类型的 Unit 时会抛出 `LICENSE_UNIT_TYPE_REJECTED`，提交的修改也会被拒绝；浏览器端 `CollaborationConflict` 的 `reason` 为 `license_unit_type_rejected`。已有文档仍可打开查看。

## 观察状态 [#observe]

```ts
// Service
collabService.license.status // 许可证状态：'not_configured' | 'expired' | 'valid'
collabService.license.editingConnectionsLimit // 协同编辑连接上限：number | null，null 表示不限
collabService.license.nodesLimit // 协同节点上限：number | null，null 表示不限
collabService.license.domains // 授权域名：string[]
collabService.license.expiresAt // 到期时间：ISO 字符串 | null，未配置时为 null
collabService.license.update({ license, licenseKey }) // 替换许可证：校验失败时抛错并保留当前许可证

// Endpoint
endpoint.license.editingConnections.limit // 名额上限：number | null，null 表示不限
endpoint.license.editingConnections.used // 已占名额：number | null，limit 不限时为 null
endpoint.license.editingConnections.remaining // 剩余名额：number | null，null 表示不限
endpoint.license.editingConnections.has(memberID) // 该成员是否占有名额：boolean，limit 不限时为 false
endpoint.license.nodes.limit // 节点上限：number | null，null 表示不限
endpoint.license.nodes.status // 本节点状态：'normal' | 'exceeded' | 'exceeded-warning' | 'exceeded-offlineSoon' | 'exceeded-offline'

// 事件
endpoint.license.on('editingConnectionsChanged', ({ change, memberIDs, used, limit }) => {}) // 名额被占用或释放时触发：change 为 'acquired' | 'released'，used 为变化后的值，limit 不限时不触发
endpoint.license.on('editingConnectionsExceeded', ({ memberID, userID, unitID, used, limit }) => {}) // 名额已满，新连接的提交未能保存时触发
endpoint.license.on('nodesStatusChanged', ({ status, previousStatus, limit, reason }) => {}) // 本节点状态变化时触发，reason 仅在下线时有值
```

`nodesStatusChanged` 在本节点状态每次变化时触发一次。`status` 变为 `exceeded-offline` 时，该节点已停止接受新连接，应将其从负载均衡中移除，或发出告警。
