## Quick Start

Assemble Collaboration Client, Transport, Endpoint, Service, and Memory Adapter. Use two browsers to verify HTTP loading, WebSocket sessions, the Room, ACK, and broadcast for the same Sheet.

```bash
pnpm example:quick-start
```

Open `http://127.0.0.1:3010/?unit=quick-start-sheet`.

- [Example guide](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/README.md)

- [Step-by-step guide on this site](/server/collaboration/quick-start)

## History

Add History Service, a separate Adapter, the History Endpoint, and the browser history entry, all outside Core. The Unit creation and changeset commit Events build History as a derived index that can be reconstructed.

```bash
pnpm example:history
```

Open `http://127.0.0.1:3010/?unit=history-sheet`, edit the Sheet, and select `History` at the top of the page.

## Multi-node

Run two collaboration nodes behind Nginx. Redis relays realtime updates between the nodes and shares session tickets, so any node can serve any request. The example also requires Docker Compose and a [License](/server/collaboration/license#nodes) that covers two nodes.

```bash
pnpm example:multi-node
```

Open `http://127.0.0.1:3010/` and select **New Sheet** to create a file. Copy the full URL into another tab to verify collaborative editing of the same document. Then create several more files and observe how they are distributed across the nodes.

- [Example guide](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/multi-node/README.md)
