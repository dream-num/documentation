이 페이지는 두 가지 경로가 설명합니다. 첫 번째는 공식 예제를 실행하고 두 브라우저에서 완전한 협업 경로를 지정합니다. 두 번째는 최소한의 서버와 웹 어셈블리를 제공하며, 자신의 Univer 응용 프로그램에 복사 할 수 있습니다.

시작 전에 [환경 및 버전 요구 사항](/server/requirements)을 충족하세요. 모든 `@univerjs/*`와 `@univerjs-pro/*` 패키지는 같은 호환 릴리스 집합으로 고정해야 합니다.

## 경로 1: 공식 예제 실행

### 실행 전 준비

이 저장소는 **Node.js 24+**를 요구하고 **오후 10.32.1**을 선언합니다. `node --version` 및 `pnpm --version` 확인하고 저장소록을 사용하며 저장소 루트에서 모든 `pnpm example:*` 명령을 실행합니다. 각 명령은 브라우저와 서버, 유형 검사를 빌드하고, 그 다음 시작하십시오. 이 명령은 핫로드 개발 서버를 제공하지 않습니다. 그래서 파일을 다시 실행하고 다시 실행하면 파일을 다시 실행해야합니다.

`UNIVER_LICENSE`와 `UNIVER_LICENSE_KEY`를 명령을 실행하기 전에 쉘에 설정하면 됩니다. 빌드는 `UNIVER_LICENSE`가 `vite.config.ts`을 통해 브라우저 번들에 삽입하고 Collaboration SDK는 서버가 시작될 때 두 변수를 읽습니다. 라이센스 변경 후 명령을 다시 실행하십시오. [이름 *](/server/license#collaboration-sdk) 를 참조하십시오.

```bash
git clone https://github.com/dream-num/univer-collaboration-examples.git
cd univer-collaboration-examples
pnpm install --frozen-lockfile
pnpm example:quick-start
```

다음 URL을 엽니다:

```text
http://127.0.0.1:3010/?unit=quick-start-sheet
```

### 실시간 공동 편집 확인

1. 브라우저 창에서 완전한 URL을 엽니다.
2. 다른 브라우저 창이나 탭에서 같은 URL을 엽니다.
3. 한 셀을 시트로 변경하십시오.
4. 다른 브라우저에 같은 변경이 나타나는지 확인하세요.

각 창은 별도의 WebSocket 세션을 엽니다. 나중에 [권한 예제](/server/collaboration/examples#permissions)에서 두 계정을 테스트할 때는 서로 다른 브라우저 프로필을 사용해 로그인 쿠키를 분리합니다.

### 성공으로 확인되는 내용

```text
Univer Collaboration Client
  → Node Transport
  → UniverCollabEndpoint
  → UniverCollabService
  → MemoryDatabaseAdapter
```

두 브라우저가 동기화되면, 전체 경로가 작동합니다. 각 브라우저는 HTTP를 통해 단위를로드하고, 한 번 세션 티켓과 WebSocket Session을 열고 동일한 룸에 합류했습니다. 이 서비스는 OT을 수행하고, 어댑터를 통해 저장된 새로운 개정을 확인하고, 다른 회원에게 개정하는 엔드포인트 방송을 엽니다.

## 경로 2: 애플리케이션에 통합

아래 코드는 최소 서버 및 웹 어셈블리입니다. 공식 빠른 시작은 완전한 응용 구조를 포함합니다 :

- [server/main.ts](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/server/main.ts)
- [web/main.ts](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/web/main.ts)
- [package.json](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/package.json)

이미 Univer 웹 응용 프로그램을 가지고 있다면 Runtime, presets 및 UI를 유지하고 아래 설명 된 협업 클라이언트 구성 및 Server 만 추가하십시오. 빈 프로젝트의 경우 `index.html`, `vite.config.ts` 및 Quick Start 디렉토리의 스타일이 적용 쉘으로 사용하십시오.

### 실행 가능한 파일을 기준으로 이전

`examples/quick-start`를 초기 골격으로 복사하고 `package.json`, `index.html`의 `vite.config.ts`는 `web/styles.css`와 `web/main.ts` 및 `server/main.ts`을 유지합니다. 그 디렉토리에서 빌드 및 시작 스크립트를 실행하기 때문에 Express는 작업 디렉토리에 `dist/web` 상대를 제공합니다. Vite 라이센스 정의를 유지하고 `#app`XZ를 제공하지 않습니다. 이 프로젝트는 다음과 같은 작업을 수행하는 방법을 설명합니다.

예를 들어 같은 기원에서 페이지와 `/universer-api`를 제공합니다. 다른 곳에서 프론트엔드를 이동하면 HTTP와 WebSocket 업그레이드를 백엔드로 이동하거나 모든 5개의 클라이언트 URL을 모두 변경할 수 있습니다. `unit`는 백엔드가 생성한 ID와 일치해야 합니다. URL 매개 변수는 문서가 생성되지 않습니다. 예를 들어 `unit`을 읽고 `loadSheetAsync()`로 명시적으로 문서를로드합니다. 응용 프로그램에서 현재 사용자를로드하기 전에 [협업 통합](/server/collaboration/browser-integration)에 설명된 것과 같이 설정하십시오.

### 1. 호환되는 동일 버전 패키지 집합 설치

서버는 수송, 엔드포인트, 서비스 및 1개의 데이타베이스 접합기를 필요로 합니다. 브라우저는 협업 클라이언트를 필요로 합니다입니다. 포장을 설치하고, 그 후에 동일한 정확한 버전에 Univer 포장을 핀으로 꼿습니다:

```bash
pnpm add \
  @univerjs-pro/collaboration \
  @univerjs-pro/collaboration-client \
  @univerjs-pro/collaboration-client-ui \
  @univerjs-pro/collaboration-database-memory \
  @univerjs-pro/collaboration-endpoint \
  @univerjs-pro/collaboration-service \
  @univerjs-pro/collaboration-transport-node \
  @univerjs-pro/license \
  @univerjs/core \
  @univerjs/preset-sheets-core \
  @univerjs/presets \
  @univerjs/protocol \
  express react react-dom rxjs
```

공식 예는 현재 패키지 구성 및 정확한 버전에 대한 runnable, authoritative 참조입니다.

### 2. Service, Endpoint, 초기 Unit 생성

`UniverCollabService`는 권위있는 협력 핵심입니다. Endpoint는 서비스에 브라우저 프로토콜을 맵핑하고, 일시적으로 스냅 샷, 변경 세트 및 개정을 저장합니다.

```ts
import type { IWorkbookData } from "@univerjs/core";
import { createServer } from "node:http";
import express from "express";
import { LocaleType } from "@univerjs/core";
import { MemoryDatabaseAdapter } from "@univerjs-pro/collaboration-database-memory";
import { UniverCollabEndpoint } from "@univerjs-pro/collaboration-endpoint";
import { UniverCollabService } from "@univerjs-pro/collaboration-service";
import { createNodeTransport } from "@univerjs-pro/collaboration-transport-node";
import { ErrorCode, UniverType } from "@univerjs/protocol";

const UNIT_ID = "quick-start-sheet";
const unitData: IWorkbookData = {
  id: UNIT_ID,
  rev: 1,
  name: "Quick Start Sheet",
  appVersion: "",
  locale: LocaleType.EN_US,
  sheetOrder: ["sheet-1"],
  sheets: {
    "sheet-1": {
      id: "sheet-1",
      name: "Sheet 1",
      rowCount: 100,
      columnCount: 26,
      cellData: {},
    },
  },
  styles: {},
  resources: [],
};

const database = new MemoryDatabaseAdapter();
const service = new UniverCollabService({ dbAdapter: database });
const endpoint = new UniverCollabEndpoint(service);
const transport = createNodeTransport();

transport.use(async (context, next) => {
  context.userID = "demo-user";
  await next();
});
transport.register(endpoint);

await service.createUnitFromData(
  { type: UniverType.UNIVER_SHEET, data: unitData },
  { userID: "demo-user" },
);
```

고정 `demo-user`는 엔드포인트 및 서비스로 운송에서 신뢰할 수있는 정체성을 어떻게 흐름하는지 설명합니다. 생산 응용 프로그램은 자체 쿠키, Bearer 토큰 또는 `transport.use()` 내부 세션을 검증하고 안정적인 비즈니스 `userID`를 설정합니다.

### 3. 권한 부여, HTTP, WebSocket 진입점 연결

현재 협업 클라이언트 쿼리 작성자 프로토콜. 빠른 시작은 `allowed: true`를 반환하여 해당 경로에 대한 모든 요청 및 응용 프로그램의 HTTP 서버로 전송을 첨부:

```ts
const app = express();

app.post("/universer-api/authz/-/object/-/batch_allowed", express.json(), (request, response) => {
  const body = request.body as {
    requests: Array<{ unitID: string; objectID: string; actions: unknown[] }>;
  };
  response.json({
    error: { code: ErrorCode.OK, message: "" },
    objectActions: body.requests.map((item) => ({
      unitID: item.unitID,
      objectID: item.objectID,
      actions: item.actions.map((action) => ({ action, allowed: true })),
    })),
  });
});

app.use(express.static("dist/web"));

const server = createServer(app);
transport.attach(server);
server.listen(3010, "127.0.0.1");
```

모든 요청을 부여하는 것은 보안 경계가 아니라 교육 단축키입니다. 생산 응용 프로그램은 HTTP 읽기, 실시간 가입, 변경 제출 및 단위 수명주기 작업을 보호해야합니다. 완전한 적용 모델에 대한 [Identity 및 인증](/server/collaboration/identity-and-authorization)를 참조하십시오.

### 4. 브라우저 Runtime에 Collaboration Client 등록

표준 Web SDK 및 사전 설정 유지, 다음 협업 플러그인 및 프로토콜 URL을 추가:

#### 플러그인 설정 [#plugin-configuration]

`UniverLicensePlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `license` | `string` |  | 클라이언트 라이선스 파일의 내용입니다. |

`UniverCollaborationClientPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `socketService` | `Ctor<ICollaborationSocketService>` |  | 소켓 구현 현재 실행 시간 사용. |
| `sendChangesetTimeout` | `number` | `2000` | 얼마나 긴 편집은 일괄 처리, 밀리 초에서, 그들이 전송하기 전에. |
| `authzUrl` | `string` | `'/universer-api/authz'` | 권한을 확인하는 엔드포인트입니다. |
| `snapshotServerUrl` | `string` | `'/universer-api/snapshot'` | 문서 스냅샷을 읽는 엔드포인트입니다. |
| `collabSubmitChangesetUrl` | `string` | `'/universer-api/comb'` | 변경 집합을 제출하는 엔드포인트입니다. |
| `collabWebSocketUrl` | `string` | `'ws://127.0.0.1:8000/universer-api/comb/connect'` | 실시간 변경을 동기화하는 WebSocket 주소입니다. |
| `wsSessionTicketUrl` | `string` | `'/universer-api/user/session-ticket'` | WebSocket 세션 티켓을 얻는 엔드포인트입니다. |

#### 프리셋 설정 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 편집기를 마운트할 DOM 요소 또는 해당 요소의 ID입니다. |

```ts
import { LocaleType, LogLevel } from "@univerjs/core";
import { UniverCollaborationPlugin } from "@univerjs-pro/collaboration";
import { UniverCollaborationClientPlugin } from "@univerjs-pro/collaboration-client";
import CollaborationClientEnUS from "@univerjs-pro/collaboration-client/locale/en-US";
import {
  BrowserCollaborationSocketService,
  UniverCollaborationClientUIPlugin,
} from "@univerjs-pro/collaboration-client-ui";
import CollaborationClientUIEnUS from "@univerjs-pro/collaboration-client-ui/locale/en-US";
import { UniverLicensePlugin } from "@univerjs-pro/license";
import { UniverSheetsCorePreset } from "@univerjs/preset-sheets-core";
import UniverPresetSheetsCoreEnUS from "@univerjs/preset-sheets-core/locales/en-US";
import { createUniver, defaultTheme, mergeLocales } from "@univerjs/presets";
import "@univerjs-pro/collaboration-client/facade";
import "@univerjs/preset-sheets-core/lib/index.css";
import "@univerjs-pro/collaboration-client-ui/lib/index.css";

const httpProtocol = location.protocol === "https:" ? "https" : "http";
const wsProtocol = location.protocol === "https:" ? "wss" : "ws";
const baseURL = `${httpProtocol}://${location.host}/universer-api`;

const unitId = new URLSearchParams(location.search).get("unit");
if (!unitId) throw new Error("Open the URL printed by the server; it names the Sheet with ?unit=.");
const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      CollaborationClientEnUS,
      CollaborationClientUIEnUS,
    ),
  },
  theme: defaultTheme,
  logLevel: LogLevel.WARN,
  collaboration: true,
  presets: [UniverSheetsCorePreset({ container: "app" })],
  plugins: [
    [UniverLicensePlugin, { license: import.meta.env.UNIVER_LICENSE || undefined }],
    UniverCollaborationPlugin,
    [
      UniverCollaborationClientPlugin,
      {
        socketService: BrowserCollaborationSocketService,
        sendChangesetTimeout: 200,
        authzUrl: `${baseURL}/authz`,
        snapshotServerUrl: `${baseURL}/snapshot`,
        collabSubmitChangesetUrl: `${baseURL}/comb`,
        collabWebSocketUrl: `${wsProtocol}://${location.host}/universer-api/comb/connect`,
        wsSessionTicketUrl: `${baseURL}/user/session-ticket`,
      },
    ],
    UniverCollaborationClientUIPlugin,
  ],
});

const workbook = await univerAPI.getCollaboration().loadSheetAsync(unitId);
if (!workbook) throw new Error("Document could not be loaded");
```

페이지는 `id="app"`와 요소가 필요하며 쿼리 매개 변수를 통해 Unit을 선택합니다.

```text
/?unit=quick-start-sheet
```

### 5. 학습용 설정을 애플리케이션 기능으로 교체

| 학습용 설정 | 교체 대상 |
| --- | --- |
| 고정 `demo-user` | 애플리케이션 인증 Middleware 및 안정적인 사용자 ID |
| 항상 허용하는 권한 확인 | 읽기, JOIN, 제출, 수명 주기를 포괄하는 서버 ACL |
| 고정 단위 | `createUnitFromData()`를 호출하는 생성 API 및 제품 레코드 |
| 메모리 어댑터 | SQLite 또는 계약 테스트를 통과한 사용자 지정 영구 저장 Adapter |

[데이터베이스 어댑터](/server/collaboration/database-adapters)와 [Identity 및 인증](/server/collaboration/identity-and-authorization)로 계속하십시오. 그런 다음 [역사, 스레드 논평, Worktree, 또는 교환](/server/collaboration/extensions)를 필요에 따라 추가하십시오. [예제 인덱스](/server/collaboration/examples)는 각 runnable 구성을 포함합니다.

## 첫 실행 문제 해결

| 증상 | 확인 |
| --- | --- |
| 설치·빌드 실패 | Node.js 24+, 지정 pnpm, 동일 Univer 버전 |
| 3010 사용 중 | 이전 예제 중지 또는 `PORT=3011` 설정 후 두 브라우저 URL 변경 |
| 빈 화면·리소스 누락 | 완료; 시작은 예 디렉토리에서 실행; `#app`는 높이가 |
| 편집 동기화 실패 | 두 창에서 동일한 완전한 URL; 성공적인 스냅 샷 및 세션 티켓 요청; `/universer-api/comb/connect`의 WebSocket 연결 |
| 재시작 후 데이터 소실 | Quick Start는 메모리 저장이므로 SQLite 예제로 진행 |
