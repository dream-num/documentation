## クイックスタート [#quick-start]

コラボレーションクライアント、トランスポート、エンドポイント、サービス、およびメモリアダプタを組み立てます。 2つのブラウザを使用して、HTTPローディング、WebSocketセッション、Room、ACK、および同じシートの放送を確認します。

```bash
pnpm example:quick-start
```

`http://127.0.0.1:3010/?unit=quick-start-sheet` を開きます。

- [サンプルガイド](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/README.md)
- [サーバー入口](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/server/main.ts)
- [Web 入口](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/web/main.ts)
- [当サイトの手順ガイド](/server/collaboration/quick-start)

## 権限 [#permissions]

信頼できるアイデンティティをクッキーからビルドし、ユニットHTTP読み取り、リアルタイムJOIN、およびチェンジセットの送信を別々に保護します。 このページは、**アリス・エディタ**アカウントと読み取り専用**ボブ・ビューア**口座を教えている間を切り替えます。

```bash
pnpm example:permissions
```

`http://127.0.0.1:3010` を開きます。

## 履歴 [#history]

履歴サービス、別のアダプター、履歴エンドポイント、およびブラウザ履歴エントリ、すべての外部コアを追加します。 ユニット作成と変更セットコミットイベントは、再構築できる派生したインデックスとして履歴を構築します。

```bash
pnpm example:history
```

`http://127.0.0.1:3010/?unit=history-sheet` を開き、Sheet を編集してページ上部の `History` を選びます。

- [サンプルガイド](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/README.md)

## コメント [#comments]

スレッドコメントサービス、別のアダプター、コメントエンドポイント、およびフロントエンドコメントエントリを追加します。コメントエンドポイントは、メインコラボレーションエンドポイントのセッションとユニットルームを再利用します。

## Worktree [#worktree]

ライフサイクル全体に従う: 分離された草案、準備、再開、およびパーユニットマージ。 トランクとドラフトの間の切り替えは、エージェントがマージするまでの分離状態をどのように観察するかを観察します。

```bash
pnpm example:worktree
```

`http://127.0.0.1:3010/?unit=worktree-sheet&worktree=demo-worktree` を開きます。

## ファイルサービス [#file-service]

ファイルサービスとファイルエンドポイントを接続します。シートに挿した画像はサーバーにアップロードされ、ユニットデータはファイルIDのみを記録します。

```bash
pnpm example:file-service
```

`http://127.0.0.1:3010/?unit=file-service-sheet` を開き、**Insert → Image → Float Image** で画像を挿入します。

- [サンプルガイド](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/file-service/README.md)

## 複数ノードへのデプロイ [#multi-node]

Nginx の背後にある 2 つのコラボレーション ノードを実行します。Redis は、ノード間でリアルタイムの更新を中継し、セッション チケットを共有します。そのため、どのノードでもリクエストを処理できます。例としては、Docker Compose と 2 つのノードをカバーする [ライセンス](/server/collaboration/license#nodes) が必要です。

```bash
pnpm example:multi-node
```

`http://127.0.0.1:3010/` を開き、**新着シート**を選択してファイルを作成します。URL を別のタブにコピーして、同じドキュメントの共同編集を確認します。その後、複数のファイルを作成し、ノード間で配布されている方法を観察します。

- [サンプルガイド](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/multi-node/README.md)
