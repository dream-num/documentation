## Démarrage rapide [#quick-start]

Adaptateur de Collaboration Client, Transport, Endpoint, Service et Mémoire. Utilisez deux navigateurs pour vérifier le chargement HTTP, les sessions WebSocket, la salle, ACK, et diffusé pour la même feuille.

```bash
pnpm example:quick-start
```

Ouvrez `http://127.0.0.1:3010/?unit=quick-start-sheet`.

- [Guide de l’exemple](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/README.md)
- [Entrée serveur](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/server/main.ts)
- [Entrée Web](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/quick-start/web/main.ts)
- [Guide pas à pas sur ce site](/server/collaboration/quick-start)

## Permissions des objets [#object-permissions]

## Historique [#history]

Ajouter le service History, un adaptateur séparé, le point d'arrivée History et l'entrée de l'historique du navigateur, tout en dehors du noyau. La création d'unité et les changementset commit Events build History en tant qu'index dérivé pouvant être reconstruit.

```bash
pnpm example:history
```

Ouvrez `http://127.0.0.1:3010/?unit=history-sheet`, modifiez la Sheet puis choisissez `History` en haut.

- [Guide de l’exemple](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/history/README.md)

## Commentaires [#comments]

Ouvrez `http://127.0.0.1:3010/?unit=comments-sheet`, sélectionnez une cellule et utilisez les commentaires.

## Service de fichiers [#file-service]

Connectez le service de fichiers et le point d'extrémité du fichier. Les images insérées dans la feuille sont téléchargées sur le serveur, et les données de l'unité n'enregistrent que l'ID du fichier.

```bash
pnpm example:file-service
```

Ouvrez `http://127.0.0.1:3010/?unit=file-service-sheet` et insérez une image via **Insert → Image → Float Image**.

## Déploiement à plusieurs nœuds [#multi-node]

Exécutez deux nœuds de collaboration derrière Nginx. Redis relaie les mises à jour en temps réel entre les nœuds et partage les tickets de session, de sorte que tout noeud peut servir n'importe quelle requête. L'exemple nécessite également Docker Compose et un [Licence](/server/collaboration/license#nodes) qui couvre deux nœuds.

```bash
pnpm example:multi-node
```

Ouvrez `http://127.0.0.1:3010/` et sélectionnez **Nouvelle feuille** pour créer un fichier. Copiez l'URL complète dans un autre onglet pour vérifier l'édition collaborative du même document. Puis créez plusieurs fichiers et observez comment ils sont distribués à travers les nœuds.

- [Guide de l’exemple](https://github.com/dream-num/univer-collaboration-examples/blob/main/examples/multi-node/README.md)
