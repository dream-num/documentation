## Requisitos de ejecución

| SDK / función | Requisito |
| --- | --- |
| Collaboration Server con SQLite | Node.js 22+ |
| Cliente Collaboration para el navegador | Un navegador compatible con Web SDK |
| AI SDK | Node.js 22.12+ |
| Capturas, renderizado y revisión del diseño de la CLI | Chrome, Chromium o Edge |

Puedes usar npm, pnpm, Yarn u otro gestor de paquetes. Los requisitos definitivos son los indicados en `engines` del paquete instalado y en sus dependencias nativas.

<Callout title="Alineación de versiones">
  Esta documentación corresponde a `1.0.0-beta.2`. Todos los paquetes `@univerjs/*`, `@univerjs-pro/*` y `@univer-cli/*` de una misma aplicación deben utilizar esta versión.
</Callout>

Consulta [Paquetes de Collaboration](/server/collaboration/packages) y [Paquetes de la CLI](/ai/packages) para seleccionar e instalar los paquetes.
