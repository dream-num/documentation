## Requisitos de ejecución

| SDK / función | Requisito |
| --- | --- |
| Collaboration Server con SQLite | Node.js 22+ |
| Collaboration Server con PostgreSQL | Node.js 22+, PostgreSQL 13+ |
| Collaboration Server en varios nodos | Node.js 22+, Redis 6.2+ |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

Las aplicaciones pueden utilizar npm, pnpm, Yarn u otro gestor de paquetes. El campo `engines` declarado por el paquete instalado, y sus requisitos de dependencia nativa, tienen precedencia.

Dentro de una aplicación, cada paquete `@univerjs/*` y `@univerjs-pro/*` debe utilizar versiones de coincidencia, incluyendo paquetes de navegador y servidor.
