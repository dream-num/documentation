## Requisitos de ejecución

| SDK / función | Requisito |
| --- | --- |
| Collaboration Server con SQLite | Node.js 22+ |
| Collaboration Server en varios nodos | Node.js 22+, Redis 6.2+ |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

Puedes usar npm, pnpm, Yarn u otro gestor de paquetes. Los requisitos definitivos son los indicados en `engines` del paquete instalado y en sus dependencias nativas.

Usa versiones correspondientes de todos los paquetes `@univerjs/*` y `@univerjs-pro/*` de la aplicación, tanto en el navegador como en el servidor.

[Paquetes de Collaboration](/server/collaboration/packages)
