## 実行環境の要件

| SDK／機能 | 要件 |
| --- | --- |
| SQLite を使用する Collaboration Server | Node.js 22+ |
| PostgreSQL を使用する Collaboration Server | Node.js 22+、PostgreSQL 13+ |
| 複数ノードで動かす Collaboration Server | Node.js 22+、Redis 6.2+ |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

アプリケーションは、npm、pnpm、Yarn、または別のパッケージマネージャを使用する場合があります。 インストールされたパッケージによって宣言された`engines`フィールドとそのネイティブの依存性要件は、優先します。

1つのアプリケーション内で、`@univerjs/*`と`@univerjs-pro/*`パッケージは、ブラウザとサーバーパッケージを含むマッチングリリースを使用する必要があります。
