## 実行環境の要件

| SDK／機能 | 要件 |
| --- | --- |
| SQLite を使用する Collaboration Server | Node.js 22+ |
| 複数ノードで動かす Collaboration Server | Node.js 22+、Redis 6.2+ |
| [univer-collaboration-examples](https://github.com/dream-num/univer-collaboration-examples) | Node.js 24+, pnpm 10.32.1 |

npm、pnpm、Yarn などのパッケージマネージャーを使用できます。実際の要件は、インストールしたパッケージの `engines` とネイティブ依存関係の要件を確認してください。

同じアプリケーションの `@univerjs/*` と `@univerjs-pro/*` パッケージは、ブラウザー側とサーバー側を含めて対応するリリースに統一してください。
