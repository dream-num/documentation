## 実行環境の要件

| SDK／機能 | 要件 |
| --- | --- |
| SQLite を使用する Collaboration Server | Node.js 22+ |
| Collaboration ブラウザークライアント | Web SDK が対応するブラウザー |
| AI SDK | Node.js 22.12+ |
| CLI のスクリーンショット、レンダリング、レイアウト検査 | Chrome、Chromium、または Edge |

npm、pnpm、Yarn などのパッケージマネージャーを使用できます。実際の要件は、インストールしたパッケージの `engines` とネイティブ依存関係の要件を確認してください。

<Callout title="バージョンの統一">
  このドキュメントは `1.0.0-rc.0` に対応しています。同一アプリケーション内のすべての `@univerjs/*`、`@univerjs-pro/*`、`@univer-cli/*` パッケージをこのバージョンに統一してください。
</Callout>

パッケージの選択とインストールについては、[Collaboration パッケージ](/server/collaboration/packages)と [CLI パッケージ](/ai/packages)を参照してください。
