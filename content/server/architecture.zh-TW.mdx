Univer Office SDK 由三個 SDK 組成：[Web SDK](/guides/sheets) 執行嵌入式編輯器，也能以無頭方式[^headless-mode]處理內容；[Server SDK](/server) 負責協同與檔案匯入匯出；[AI SDK](/ai) 負責 Agent 工作流。

**Univer** 是一套用於建置 Office 應用的開發工具集，人與 AI Agent 操作同一份內容。應用可以為人提供 Web 介面、為 AI Agent 提供 CLI，並提供一個供兩者共用的 Server，也可以只採用需要的部分。

| 元件 | 執行環境 | 主要 SDK | SDK 提供 | 應用程式負責 |
| --- | --- | --- | --- | --- |
| Web | 瀏覽器 | Web SDK | 在瀏覽器中展示並編輯 Office 內容的編輯器 | UI、產品互動與瀏覽器整合 |
| CLI | Node.js | AI SDK | 面向 AI Agent 的檢查與編輯 | AI Agent 流程、工具呼叫與任務邊界 |
| Server | Node.js | Server SDK（Collaboration、Exchange） | 自託管協同與 Office 檔案匯入匯出 | 業務 API、身分、權限、檔案儲存與部署 |

文件按 [Web SDK](/guides/sheets)、[Server SDK](/server) 和 [AI SDK](/ai) 分成三部分，分別介紹編輯器、協同與匯入匯出服務、AI Agent 的內容操作。

AI SDK 複用 Web SDK 的 headless 內容能力。這三個元件標示主要開發入口和執行位置；它們既不是三套互不依賴的技術棧，也不是無需業務程式碼即可部署的完整產品。

## 整合檔案匯入匯出

Office 檔案與 Univer 文件資料之間的轉換由 Server SDK 中的 `@univerjs-pro/exchange-node` 提供。應用整合該轉換模組，並自行提供上傳、轉換和下載介面。瀏覽器一側由 Web SDK 處理，CLI 可以在 Node.js 中呼叫轉換模組。各產品在瀏覽器中的配置仍寫在對應產品的 Web SDK 文件中。

- **不使用協同編輯：** 將檔案轉換為文件快照，在瀏覽器中開啟該快照進行編輯；匯出時將最新快照交給轉換模組，由它生成檔案。這一流程需要伺服器端轉換，不需要協同服務。
- **使用協同編輯：** 將匯入的資料儲存為協同文件，Web SDK 和 AI SDK 透過文件 ID 操作同一份內容。匯出前先同步當前修改，再讀取最新的文件資料並完成轉換。

只做檔案轉換時，在本地 Node.js 程序或遠端服務中執行 Exchange 即可，不需要 AI SDK，也不需要協同編輯。應用的接入流程見[匯入匯出整合](/server/import-export)，轉換模組的用法見[Office 檔案匯入匯出](/server/import-export/node)。

## 部署形態

| 形態 | Web | CLI | Server | 適用範圍 |
| --- | --- | --- | --- | --- |
| 本機應用程式 | 本機瀏覽器／桌面 UI | 本機程序 | 本機程序 | 桌面 Office 與本機 AI Agent |
| SaaS 應用程式 | 瀏覽器 | 使用者裝置／雲端 AI Agent | 遠端服務 | 多使用者與集中維運 |
| Web + Server | 瀏覽器 | — | 本機或遠端 | 尚未提供 AI Agent 入口 |
| 僅 Web | 瀏覽器／桌面 UI | — | — | 本機、單人、非協同編輯 |

元件可以全部執行在一臺機器上，也可以分佈到客戶端和雲端。部署位置不改變各元件的職責。系統中存在 Server 時，Web 和 CLI 都透過它訪問共享內容和產品能力。

| 目標 | 從這裡開始 |
| --- | --- |
| 在 Web 應用中嵌入 Office 編輯器 | [Web SDK 文件](/guides/sheets) |
| 為編輯器加入 Office 匯入匯出 | [檔案交換整合](/server/import-export) |
| 在 Node.js 轉換 Office 檔案 | [Office 檔案匯入匯出](/server/import-export/node) |
| 在自己的伺服器上執行即時協同 | [Collaboration SDK 概覽](/server/collaboration/overview) |
| 讓 AI Agent 讀寫 Office 內容 | [AI SDK 概覽](/ai) |
| 瞭解 CLI 背後的 headless Runtime | [Runtime 重用與 Daemon](/ai/runtime-architecture) |

如果不確定應選擇哪條路徑，請先閱讀[開始使用](/guides/sheets)。

[^headless-mode]: 無頭（headless）指不掛載互動式編輯器介面，直接操作文件內容；它不代表已包含協同、持久化儲存或檔案轉換服務。
