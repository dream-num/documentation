## Runtime requirements

AI SDK runs on Node.js. The capabilities that render or inspect a page also require a browser.

| SDK / capability                    | Requirement               |
| ----------------------------------- | ------------------------- |
| AI SDK                              | Node.js 22.12+            |
| CLI Screenshot, Render, Layout Lint | Chrome, Chromium, or Edge |

Applications can use npm, pnpm, Yarn, or another package manager. In all cases, the `engines` and native dependency requirements of the installed package determine compatibility.

<Callout title="Version alignment">
  This documentation corresponds to `1.0.0-rc.0`. Every `@univerjs/*`, `@univerjs-pro/*`, and `@univer-cli/*` package in one application must use this version.
</Callout>

For the full package list, see [CLI Packages](/ai/packages).
