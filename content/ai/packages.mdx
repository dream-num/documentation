AI SDK currently publishes 25 independent packages. Install the base packages that the application needs, then add a command preset from the same row when its default terminal interaction fits the product.

## Two package roles

| Role                   | Provides                                                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Base package           | Structured TypeScript APIs, with no dependency on Commander and no opinion about command names, output, or exit behavior |
| Command preset package | A native Commander `Command` backed by a base package, with default arguments, help, and terminal interaction            |

Command presets usually end in `-command`. Not every base package needs a preset.

## How to choose

1. Start with the base package that matches the business task.
2. Add its command preset only when the default Commander interaction fits the product.
3. When the CLI, Web, and Server share a Unit, use a collaboration runtime instead of reading the collaboration database directly.
4. Add a pool, daemon, or Render Runtime only when the application needs reuse, cross-process access, or browser rendering.
5. Read the target package README for its public APIs and for details on ownership and disposal.

For concepts and core usage, see [Document loading and content operations](/ai/content-operations), [Visual inspection](/ai/visual-inspection), and [Runtime reuse and Daemon](/ai/runtime-architecture).
