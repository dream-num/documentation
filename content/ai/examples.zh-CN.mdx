[`univer-cli-examples`](https://github.com/dream-num/univer-cli-examples) 提供四个独立、可运行的教学 application。
每个目录都有自己的 `package.json` 和 lockfile，后一个 example 保留前一个的能力，再只增加一个主题。

## 学习顺序

| Example                 | 学习目标                           | 新增能力                                |
| ----------------------- | ---------------------------------- | --------------------------------------- |
| `01-content-operations` | 读取、修改并查看 Sheet、Doc、Slide | CLI、Server、Web、Collaboration Runtime |
| `02-file-exchange`      | 导入和导出 Office 文件             | Exchange、UnitData、原生 binding        |
| `03-visual-inspection`  | 检查 Unit 的实际渲染结果           | Render Page、Screenshot、Layout Lint    |
| `04-worktree`           | 隔离 Agent 编辑并交给人审阅        | Worktree、Ready、Merge、Reopen          |

## 运行方式

进入任意 example 后使用相同的启动方式：

```bash
pnpm install
pnpm build
pnpm link-cli
pnpm start-server
```

Server 启动后，在另一个终端运行 `univer-example-cli`。完整的可复制流程和 Agent skill 输入位于每个 example
自己的 README。

这些 examples 是最小教学装配，不是完整产品。Application 仍然负责自己的命令、target、身份权限、输出和部署。
