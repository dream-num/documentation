[`univer-cli-examples`](https://github.com/dream-num/univer-cli-examples) 包含四个可独立运行的教学应用。每个目录各有自己的 `package.json` 和 lockfile；每个示例保留前一个示例的能力，并增加一个主题。

## 学习顺序

| Example                 | 学什么                                       | 新增能力                                |
| ----------------------- | -------------------------------------------- | --------------------------------------- |
| `01-content-operations` | 读取、修改并查看 Sheet、Doc、Slide 三种 Unit | CLI、Server、Web、Collaboration Runtime |
| `02-file-exchange`      | 导入和导出 Office 文件                       | Exchange、UnitData、原生 binding        |
| `03-visual-inspection`  | 检查 Unit 的实际渲染效果                     | Render Page、Screenshot、Layout Lint    |
| `04-worktree`           | 隔离 Agent 的编辑，再交给人审阅              | Worktree、Ready、Merge、Reopen          |

## 运行方式

每个示例使用相同的启动步骤。在任意示例目录中依次执行以下命令：

```bash
pnpm install
pnpm build
pnpm link-cli
pnpm start-server
```

Server 启动后，在另一个终端中运行 `univer-example-cli`。每个示例的 README 都包含完整的操作流程，可直接复制，并附有一段 Agent skill prompt。

这些示例是用于教学的最小组合，不是完整产品。命令的名称、命令所作用的 target、身份与权限校验、输出格式以及部署位置，仍由应用自行决定。
