[`univer-cli-examples`](https://github.com/dream-num/univer-cli-examples) contiene cuatro aplicaciones de enseñanza independientes que puede ejecutar. Cada directorio tiene su propio `package.json` y el archivo de bloqueo. Cada ejemplo conserva las capacidades del ejemplo anterior y añade un tema.

## Orden de aprendizaje

| Ejemplo | Lo que cubre | Capacidad añadida |
| --- | --- | --- |
| `01-content-operations` | Leer, editar y visualizar unidades Sheet, Doc y Slide | CLI, Server, Web, Collaboration Runtime |
| `02-file-exchange` | Importar y exportar archivos Office | Exchange, UnitData, enlace nativo |
| `03-visual-inspection` | Comprueba cómo la Unidad realmente rinde | Página de renderizado, captura, revisión del diseño |
| `04-worktree` | Isolate agent edits, luego dáselos a la revisión humana | Worktree, Ready, Merge, Reopen |

## Ejecutar un ejemplo

Todos los ejemplos utilizan la misma secuencia de inicio:

```bash
pnpm install
pnpm build
pnpm link-cli
pnpm start-server
```

Después de que el Servidor comience, ejecute `univer-example-cli` desde una segunda terminal. Cada ejemplo README contiene el flujo completo, que se puede copiar directamente, y un aviso de habilidad del Agente.

Estos ejemplos son asambleas de enseñanza mínimas en lugar de productos completos. La aplicación sigue siendo responsable de sus comandos, los objetivos en los que operan esos comandos, identidad y autorización, salida y despliegue.
