[`univer-cli-examples`](https://github.com/dream-num/univer-cli-examples) contiene cuatro aplicaciones didácticas independientes y ejecutables. Cada directorio tiene su propio `package.json` y archivo de bloqueo. Cada ejemplo conserva las capacidades anteriores y añade un tema.

## Orden de aprendizaje

| Ejemplo | Qué aprender | Capacidad añadida |
| --- | --- | --- |
| `01-content-operations` | Leer, editar y visualizar unidades Sheet, Doc y Slide | CLI, Server, Web, Collaboration Runtime |
| `02-file-exchange` | Importar y exportar archivos Office | Exchange, UnitData, enlace nativo |
| `03-visual-inspection` | Comprobar la unidad renderizada realmente | Página de renderizado, captura, revisión del diseño |
| `04-worktree` | Aislar cambios de un AI Agent y entregarlos para revisión humana | Worktree, Ready, Merge, Reopen |

## Ejecutar un ejemplo

Usa la misma secuencia de inicio dentro de cualquier directorio de ejemplo:

```bash
pnpm install
pnpm build
pnpm link-cli
pnpm start-server
```

Cuando el servidor se haya iniciado, ejecuta `univer-example-cli` en otro terminal. Cada README contiene el flujo completo que puedes copiar y un prompt de habilidad para AI Agent.

Son configuraciones didácticas mínimas, no productos completos. La aplicación sigue siendo responsable de comandos, destinos, identidad y autorización, salida y despliegue.
