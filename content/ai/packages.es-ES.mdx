AI SDK publica actualmente 25 paquetes independientes. Instala solo los paquetes base necesarios y añade el preset de comandos de la misma fila si su interacción de terminal encaja en el producto.

## Dos roles de paquetes

| Rol                   | Proporciona                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| Paquete base           | API TypeScript estructuradas sin depender de Commander ni decidir nombres, salidas o comportamiento de terminación |
| Paquete de preset de comandos | Un `Command` nativo de Commander basado en un paquete base, con argumentos, ayuda e interacción de terminal predeterminados  |

Los presets de comandos suelen terminar en `-command`. No todos los paquetes base necesitan un preset correspondiente.

## Cómo elegir

1. Empieza por el paquete base adecuado para la tarea.
2. Añade el preset solo si la interacción Commander predeterminada encaja en el producto.
3. Si CLI, Web y Server comparten una Unit, usa un runtime de colaboración en vez de acceder directamente a su base de datos.
4. Añade un pool, daemon o Render Runtime solo cuando necesites reutilización, acceso entre procesos o renderizado en navegador.
5. Lee el README del paquete para conocer sus API públicas, propiedad y liberación de recursos.

Consulta [Carga y operaciones de contenido](/ai/content-operations), [Inspección visual](/ai/visual-inspection) y [Reutilización del Runtime y Daemon](/ai/runtime-architecture) para conceptos y uso básico.
