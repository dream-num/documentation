AI SDK publica actualmente 25 paquetes independientes. Instale los paquetes base que la aplicación necesita, a continuación, agregue un preset de comando de la misma fila cuando su interacción terminal predeterminada se ajuste al producto.

## Dos roles de paquetes

| Rol                   | Proporciona                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| Paquete base | API TypeScript estructurada, sin dependencia de Commander y sin opiniones sobre nombres de comando, salida o comportamiento de salida |
| Paquete de preset de comandos | Un `Command` nativo de Commander basado en un paquete base, con argumentos, ayuda e interacción de terminal predeterminados  |

Los presets de comando generalmente terminan en `-command`. No todos los paquetes base necesitan un preset.

## Cómo elegir

1. Empieza por el paquete base adecuado para la tarea.
2. Añade el preset solo si la interacción Commander predeterminada encaja en el producto.
3. Cuando el CLI, Web y Server compartan una Unidad, use un tiempo de ejecución de colaboración en lugar de leer directamente la base de datos de colaboración.
4. Añade un pool, daemon o Render Runtime solo cuando necesites reutilización, acceso entre procesos o renderizado en navegador.
5. Lea el paquete de destino README para sus API públicas y para detalles sobre propiedad y eliminación.

Para conceptos y uso básico, consulte [Carga de documentos y operaciones de contenido](/ai/content-operations), [Inspección visual](/ai/visual-inspection) y [Reutilización del tiempo de ejecución y Daemon](/ai/runtime-architecture).
