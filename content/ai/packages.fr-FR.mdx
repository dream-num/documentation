AI SDK publie actuellement 25 paquets indépendants. Installez uniquement les paquets de base nécessaires, puis ajoutez le préréglage de commande de la même ligne si son interaction terminal convient au produit.

## Deux rôles de paquets

| Rôle                   | Fournit                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| Paquet de base           | API TypeScript structurées, sans dépendance à Commander ni choix des noms de commandes, des sorties ou du comportement de fin |
| Paquet de préréglage de commande | Un `Command` Commander natif reposant sur un paquet de base, avec arguments, aide et interaction terminal par défaut  |

Les préréglages de commandes se terminent généralement par `-command`. Tous les paquets de base n’ont pas besoin d’un préréglage correspondant.

## Comment choisir

1. Commencez par le paquet de base correspondant à la tâche métier.
2. Ajoutez son préréglage uniquement si l’interaction Commander par défaut convient au produit.
3. Si CLI, Web et Server partagent une Unit, utilisez un runtime collaboratif plutôt qu’un accès direct à la base de collaboration.
4. Ajoutez pool, daemon ou Render Runtime seulement pour la réutilisation, l’accès interprocessus ou le rendu navigateur.
5. Lisez le README du paquet pour ses API publiques, sa propriété des ressources et sa libération.

Consultez [Chargement et opérations de contenu](/ai/content-operations), [Inspection visuelle](/ai/visual-inspection) et [Réutilisation du Runtime et Daemon](/ai/runtime-architecture) pour les concepts et usages essentiels.
