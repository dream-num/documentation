## Environnements d’exécution

AI SDK fonctionne sur Node.js. Les capacités qui rendent ou inspectent une page nécessitent également un navigateur.

| SDK / fonctionnalité | Prérequis |
| --- | --- |
| AI SDK | Node.js 22.12+ |
| Capture d’écran, rendu et vérification de mise en page de la CLI | Chrome, Chromium ou Edge |

Les applications peuvent utiliser npm, pnpm, Yarn ou un autre gestionnaire de paquets. Dans tous les cas, les exigences de dépendance `engines` et native du paquet installé déterminent la compatibilité.

<Callout title="Alignement des versions">
  Cette documentation correspond à `1.0.0-rc.0`. Chaque paquet `@univerjs/*`, `@univerjs-pro/*` et `@univer-cli/*` dans une seule application doit utiliser cette version.
</Callout>

Pour la liste complète des paquets, voir [Emballages CLI](/ai/packages).
