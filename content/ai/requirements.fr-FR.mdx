## Environnements d’exécution

| SDK / fonctionnalité | Prérequis |
| --- | --- |
| AI SDK | Node.js 22.12+ |
| Capture d’écran, rendu et vérification de mise en page de la CLI | Chrome, Chromium ou Edge |

Vous pouvez utiliser npm, pnpm, Yarn ou un autre gestionnaire de paquets. Les contraintes `engines` du paquet installé et celles de ses dépendances natives font foi.

<Callout title="Alignement des versions">
  Cette documentation correspond à la version `1.1.0`. Tous les paquets `@univerjs/*`, `@univerjs-pro/*` et `@univer-cli/*` d’une même application doivent utiliser cette version. Les paquets de binding natifs, comme `@univerjs-pro/exchange-node-binding`, ont leur propre numéro de version ; utilisez la version requise par le paquet du SDK qui en dépend.
</Callout>
