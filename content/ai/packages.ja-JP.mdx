AI SDKは現在、25個の独立したパッケージを公開しています。 アプリケーションが必要とするベースパッケージをインストールし、デフォルト端末の相互作用が製品に適合したときに、同じ行からコマンドプリセットを追加します。

## 2 種類のパッケージの役割

| 役割                   | 提供するもの                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| 基礎パッケージ | Commander の依存性無しで TypeScript API を構造化し、コマンド名、出力、または退出の動作に関する意見はありません。 |
| コマンドプリセットパッケージ | 基礎パッケージを利用するネイティブ Commander `Command`。標準の引数、ヘルプ、端末操作を提供  |

コマンドプリセットは通常、`-command`で終了します。すべてのベースパッケージはプリセットを必要としません。

## 選び方

1. 業務の目的に合う基礎パッケージから始めます。
2. 標準の Commander 操作が製品に合う場合だけプリセットを追加します。
3. CLI、Web、および Server がユニットを共有する場合、コラボレーション・データベースを直接読み込む代わりに、コラボレーション・ランタイムを使用します。
4. 再利用、プロセス間アクセス、ブラウザー描画が必要になってからプール、Daemon、Render Runtime を追加します。
5. 公開 API の対象となるパッケージ README を読み込み、所有権と処分の詳細を確認できます。

コンセプトとコア使用については、[文書の読み込みとコンテンツの操作](/ai/content-operations)、[外観検査](/ai/visual-inspection)および[ランタイムリユースとデーモン](/ai/runtime-architecture)を参照してください。
