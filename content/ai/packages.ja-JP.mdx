AI SDK は現在 25 個の独立したパッケージを公開しています。必要な基礎パッケージだけを入れ、同じ行のコマンドプリセットの標準操作が製品に合う場合に追加してください。

## 2 種類のパッケージの役割

| 役割                   | 提供するもの                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| 基礎パッケージ           | Commander に依存せず、コマンド名・出力・終了動作を決めない構造化 TypeScript API |
| コマンドプリセットパッケージ | 基礎パッケージを利用するネイティブ Commander `Command`。標準の引数、ヘルプ、端末操作を提供  |

コマンドプリセットの名前は通常 `-command` で終わります。すべての基礎パッケージにプリセットが必要なわけではありません。

## 選び方

1. 業務の目的に合う基礎パッケージから始めます。
2. 標準の Commander 操作が製品に合う場合だけプリセットを追加します。
3. CLI、Web、Server が Unit を共有する場合は、データベースに直接アクセスせず共同編集ランタイムを使います。
4. 再利用、プロセス間アクセス、ブラウザー描画が必要になってからプール、Daemon、Render Runtime を追加します。
5. 対象パッケージの README で公開 API、所有権、破棄動作を確認します。

概念と基本的な使い方は[ドキュメントの読み込みと操作](/ai/content-operations)、[視覚的検査](/ai/visual-inspection)、[ランタイム再利用と Daemon](/ai/runtime-architecture)を参照してください。
