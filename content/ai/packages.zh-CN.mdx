AI SDK 当前提供 25 个可独立发布的 package。应用只安装实际需要的基础功能包；默认终端交互
适合产品时，再增加同一行的预设命令包。

## 两类 Package

| 类型       | 提供什么                                                                  |
| ---------- | ------------------------------------------------------------------------- |
| 基础功能包 | 结构化 TypeScript API；不依赖 Commander，不决定命令名称、输出和退出行为   |
| 预设命令包 | 基于基础功能包创建原生 Commander `Command`；提供默认参数、help 与终端交互 |

预设命令包通常以 `-command` 结尾。并不是每个基础功能包都需要对应的预设命令包。

## 如何选择

1. 先按业务需求找到基础功能包。
2. 需要默认 Commander 交互时，再增加对应的预设命令包。
3. CLI、Web 与 Server 共享 Unit 时，使用 Collaboration Runtime，而不是直接访问协同数据库。
4. 需要高频复用、跨进程访问或浏览器渲染时，再引入 pool、daemon 或 Render Runtime。
5. 查看目标 package README，确认公共 API、资源所有权和释放方式。

具体概念和核心用法分别见[文档内容加载与读写](/ai/content-operations)、
