AI SDK 目前提供 25 个独立的 package。安装应用所需的基础功能包；当同一行的预设命令包默认终端交互符合产品需求时，再加入该预设命令包。

## 两类 Package

| 类型       | 提供内容                                                                      |
| ---------- | ----------------------------------------------------------------------------- |
| 基础功能包 | 结构化 TypeScript API，不依赖 Commander，也不规定命令名称、输出和退出行为     |
| 预设命令包 | 基于基础功能包封装一个原生 Commander `Command`，提供默认参数、help 和终端交互 |

预设命令包通常以 `-command` 结尾。并非每个基础功能包都需要预设命令包。

## 如何选择

1. 先按业务需求找到对应的基础功能包。
2. 默认的 Commander 交互符合产品需求时，再加入对应的预设命令包。
3. CLI、Web 和 Server 共享同一个 Unit 时，使用 Collaboration Runtime，而不是直接访问协同数据库。
4. 应用需要复用、跨进程访问或浏览器渲染时，再引入 pool、daemon 或 Render Runtime。
5. 阅读目标 package 的 README，确认其公共 API、资源所有权和释放方式。

具体概念和核心用法见[文档内容加载与读写](/ai/content-operations)、[视觉检查](/ai/visual-inspection)和 [Runtime 复用与 Daemon](/ai/runtime-architecture)。
