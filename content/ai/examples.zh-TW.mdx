[`univer-cli-examples`](https://github.com/dream-num/univer-cli-examples) 提供四個獨立且可執行的教學應用程式。每個目錄都有自己的 `package.json` 與鎖定檔。每個範例保留前一個的能力，再加入一個主題。

## 學習順序

| 範例 | 學習內容 | 新增能力 |
| --- | --- | --- |
| `01-content-operations` | 讀取、編輯與檢視 Sheet、Doc、Slide 單元 | CLI、Server、Web、Collaboration Runtime |
| `02-file-exchange` | 匯入與匯出 Office 檔案 | Exchange、UnitData、原生繫結 |
| `03-visual-inspection` | 檢查實際渲染的單元 | 渲染頁面、截圖、版面檢查 |
| `04-worktree` | 隔離 AI Agent 修改並交由人類審閱 | Worktree、Ready、Merge、Reopen |

## 執行範例

在任一範例目錄中，使用相同的啟動順序：

```bash
pnpm install
pnpm build
pnpm link-cli
pnpm start-server
```

伺服器啟動後，在另一個終端機執行 `univer-example-cli`。各範例 README 都包含完整、可複製的操作流程與 AI Agent 技能提示詞。

這些是最小化的教學組合，並非完整產品。命令、目標、身分與授權、輸出及部署仍由應用程式負責。
