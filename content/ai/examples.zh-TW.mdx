[`univer-cli-examples`](https://github.com/dream-num/univer-cli-examples) 包含四個可獨立執行的教學應用。每個目錄各有自己的 `package.json` 和 lockfile；每個範例保留前一個範例的能力，並增加一個主題。

## 學習順序

| 範例 | 學什麼 | 新增能力 |
| --- | --- | --- |
| `01-content-operations` | 讀取、修改並檢視 Sheet、Doc、Slide 三種 Unit | CLI、Server、Web、Collaboration Runtime |
| `02-file-exchange` | 匯入與匯出 Office 檔案 | Exchange、UnitData、原生繫結 |
| `03-visual-inspection` | 檢查 Unit 的實際渲染效果 | 渲染頁面、截圖、版面檢查 |
| `04-worktree` | 隔離 Agent 的編輯，再交給人審閱 | Worktree、Ready、Merge、Reopen |

## 執行範例

每個範例使用相同的啟動步驟。在任意範例目錄中依次執行以下命令：

```bash
pnpm install
pnpm build
pnpm link-cli
pnpm start-server
```

Server 啟動後，在另一個終端中執行 `univer-example-cli`。每個範例的 README 都包含完整的操作流程，可直接複製，並附有一段 Agent skill prompt。

這些範例是用於教學的最小組合，不是完整產品。命令的名稱、命令所作用的 target、身分與權限校驗、輸出格式以及部署位置，仍由應用自行決定。
