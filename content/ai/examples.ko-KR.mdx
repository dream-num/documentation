[`univer-cli-examples`](https://github.com/dream-num/univer-cli-examples)는 실행할 수 있는 4개의 독립 가르침 신청을 포함합니다. 각 디렉토리에는 그것의 자신의 `package.json` 및 lockfile가 있습니다. 각 보기는 preceding 예의 기능을 유지하고 1개의 주제를 추가합니다.

## 학습 순서

| 예제 | 그것은 무엇을 덮는 | 추가 기능 |
| --- | --- | --- |
| `01-content-operations` | Sheet, Doc, Slide 단위 읽기, 편집, 보기 | CLI, Server, Web, Collaboration Runtime |
| `02-file-exchange` | Office 파일 가져오기 및 내보내기 | Exchange, UnitData, 네이티브 바인딩 |
| `03-visual-inspection` | Unit이 실제로 렌더링하는 방법을 확인하십시오. | 렌더 페이지, 스크린샷, 레이아웃 검사 |
| `04-worktree` | Isolate 대리인은, 그 후에 인간적인 검토에 그(것)들을 수 있습니다 | Worktree, Ready, Merge, Reopen |

## 예제 실행

모든 예제는 동일한 시작 순서를 사용합니다:

```bash
pnpm install
pnpm build
pnpm link-cli
pnpm start-server
```

서버가 시작되면, 두 번째 터미널에서 `univer-example-cli`를 실행합니다. 각 예제 README는 직접 복사 할 수있는 완전한 흐름을 포함하고 에이전트 기술 프롬프트.

이 예제는 완전한 제품보다 최소한의 가르침 집합입니다. 이 응용 프로그램은 명령에 대한 책임이 유지되며, 해당 명령은, 정체성 및 권한 부여, 출력 및 배포를 운영합니다.
