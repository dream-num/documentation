[`univer-cli-examples`](https://github.com/dream-num/univer-cli-examples)는 독립적으로 실행 가능한 네 가지 학습용 애플리케이션을 제공합니다. 각 디렉터리는 자체 `package.json`과 잠금 파일을 가지며, 이전 예제의 기능을 유지하면서 한 가지 주제를 추가합니다.

## 학습 순서

| 예제 | 학습 내용 | 추가 기능 |
| --- | --- | --- |
| `01-content-operations` | Sheet, Doc, Slide 단위 읽기, 편집, 보기 | CLI, Server, Web, Collaboration Runtime |
| `02-file-exchange` | Office 파일 가져오기 및 내보내기 | Exchange, UnitData, 네이티브 바인딩 |
| `03-visual-inspection` | 실제 렌더링된 단위 검사 | 렌더 페이지, 스크린샷, 레이아웃 검사 |
| `04-worktree` | AI Agent의 변경을 격리하고 사람이 검토하도록 전달 | Worktree, Ready, Merge, Reopen |

## 예제 실행

어느 예제 디렉터리에서든 같은 순서로 시작하세요.

```bash
pnpm install
pnpm build
pnpm link-cli
pnpm start-server
```

서버가 시작되면 다른 터미널에서 `univer-example-cli`를 실행하세요. 각 예제 README에는 복사해 사용할 수 있는 전체 흐름과 AI Agent 스킬 프롬프트가 포함되어 있습니다.

이 예제들은 최소 학습용 구성이며 완성된 제품이 아닙니다. 명령, 대상, 신원과 권한 부여, 출력, 배포는 계속 애플리케이션에서 책임집니다.
