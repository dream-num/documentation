[`univer-cli-examples`](https://github.com/dream-num/univer-cli-examples)には、4つのスタンドアローンの学習アプリケーションが含まれています。各ディレクトリには独自の`package.json`とロックファイルがあります。各例では、前例の機能を保持し、1つのトピックを追加します。

## 学習順序

| サンプル | カバーするもの | 追加される機能 |
| --- | --- | --- |
| `01-content-operations` | Sheet、Doc、Slide ユニットの読み取り、編集、表示 | CLI、Server、Web、Collaboration Runtime |
| `02-file-exchange` | Office ファイルのインポートとエクスポート | Exchange、UnitData、ネイティブバインディング |
| `03-visual-inspection` | 実際にユニットがレンダリングする方法を確認してください。 | レンダリングページ、スクリーンショット、レイアウト検査 |
| `04-worktree` | エージェントの編集を分離し、人間のレビューにそれらを手渡します | Worktree、Ready、Merge、Reopen |

## サンプルの実行

すべての例では、同じ起動シーケンスを使用します。

```bash
pnpm install
pnpm build
pnpm link-cli
pnpm start-server
```

サーバが起動した後、`univer-example-cli`を2つ目のターミナルから実行します。各例のREADMEには、直接コピーできる完全なフローと、エージェントのスキルプロンプトが含まれます。

これらの例は、完全な製品ではなく、最小限の教育アセンブリです。アプリケーションは、そのコマンドの責任を負い、対象のコマンドは、IDと認証、出力、およびデプロイメントで動作します。
