## Requisitos de ejecución

AI SDK funciona en Node.js. Las capacidades que renderizan o inspeccionan una página también requieren un navegador.

| SDK / función | Requisito |
| --- | --- |
| AI SDK | Node.js 22.12+ |
| Capturas, renderizado y revisión del diseño de la CLI | Chrome, Chromium o Edge |

Las aplicaciones pueden utilizar npm, pnpm, Yarn u otro gestor de paquetes. En todos los casos, los requisitos de dependencia nativa `engines` del paquete instalado determinan la compatibilidad.

<Callout title="Ajuste de la versión">
  Esta documentación corresponde a `1.0.0-rc.0`. Cada paquete `@univerjs/*`, `@univerjs-pro/*` y `@univer-cli/*` en una aplicación debe utilizar esta versión.
</Callout>

Para la lista completa de paquetes, vea [Paquetes CLI](/ai/packages).
