[`univer-cli-examples`](https://github.com/dream-num/univer-cli-examples) содержит четыре автономных обучающих приложения, которые можно запустить. Каждый каталог имеет свои `package.json` и файл блокировки. Каждый пример сохраняет возможности предыдущего примера и добавляет одну тему.

## Порядок изучения

| Пример | Что покрывает | Добавленная возможность |
| --- | --- | --- |
| `01-content-operations` | Чтение, редактирование и просмотр единиц Sheet, Doc и Slide | CLI, Server, Web, Collaboration Runtime |
| `02-file-exchange` | Импорт и экспорт файлов Office | Exchange, UnitData, нативная привязка |
| `03-visual-inspection` | Проверьте, как устройство на самом деле отображает | Страница рендеринга, снимок экрана, проверка макета |
| `04-worktree` | Изолируйте редактирование агентов, а затем передайте их в человеческий обзор. | Worktree, Ready, Merge, Reopen |

## Запуск примера

Все примеры используют одну и ту же последовательность запуска:

```bash
pnpm install
pnpm build
pnpm link-cli
pnpm start-server
```

После запуска сервера запустите `univer-example-cli` со второго терминала. Каждый пример README содержит полный поток, который можно скопировать напрямую, и подсказку навыка Агента.

Эти примеры представляют собой минимальные обучающие ассамблеи, а не полные продукты.Приложение по-прежнему отвечает за свои команды, цели, на которых работают эти команды, идентификацию и авторизацию, вывод и развертывание.
