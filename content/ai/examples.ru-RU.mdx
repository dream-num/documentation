[`univer-cli-examples`](https://github.com/dream-num/univer-cli-examples) содержит четыре независимых запускаемых учебных приложения. В каждом каталоге есть собственные `package.json` и файл блокировки. Каждый пример сохраняет предыдущие возможности и добавляет одну тему.

## Порядок изучения

| Пример | Что изучается | Добавленная возможность |
| --- | --- | --- |
| `01-content-operations` | Чтение, редактирование и просмотр единиц Sheet, Doc и Slide | CLI, Server, Web, Collaboration Runtime |
| `02-file-exchange` | Импорт и экспорт файлов Office | Exchange, UnitData, нативная привязка |
| `03-visual-inspection` | Проверка фактического отображения единицы | Страница рендеринга, снимок экрана, проверка макета |
| `04-worktree` | Изоляция изменений AI Agent и передача на проверку человеку | Worktree, Ready, Merge, Reopen |

## Запуск примера

В любом каталоге примера используйте одинаковую последовательность запуска:

```bash
pnpm install
pnpm build
pnpm link-cli
pnpm start-server
```

После запуска сервера выполните `univer-example-cli` в другом терминале. README каждого примера содержит полный сценарий для копирования и промпт навыка для AI Agent.

Это минимальные учебные сборки, а не готовые продукты. Приложение по-прежнему отвечает за команды, цели, идентификацию и авторизацию, вывод и развёртывание.
