AI SDK는 현재 25개 독립 패키지를 배포합니다. 필요한 기본 패키지만 설치하고, 기본 터미널 상호작용이 제품에 맞으면 같은 행의 명령 프리셋을 추가하세요.

## 두 가지 패키지 역할

| 역할                   | 제공 기능                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| 기본 패키지           | Commander에 의존하거나 명령 이름, 출력, 종료 동작을 결정하지 않는 구조화된 TypeScript API |
| 명령 프리셋 패키지 | 기본 패키지를 사용하는 네이티브 Commander `Command`로 기본 인수, 도움말, 터미널 상호작용 제공  |

명령 프리셋은 보통 이름이 `-command`로 끝납니다. 모든 기본 패키지에 대응하는 명령 프리셋이 필요한 것은 아닙니다.

## 선택 방법

1. 업무에 맞는 기본 패키지부터 시작하세요.
2. 기본 Commander 상호작용이 제품에 맞을 때만 명령 프리셋을 추가하세요.
3. CLI, Web, Server가 Unit을 공유하면 공동 편집 데이터베이스에 직접 접근하지 말고 공동 편집 런타임을 사용하세요.
4. 재사용, 프로세스 간 접근, 브라우저 렌더링이 필요할 때만 풀, 데몬, Render Runtime을 추가하세요.
5. 대상 패키지 README에서 공개 API, 소유권, 해제 동작을 확인하세요.

개념과 핵심 사용법은 [문서 로드 및 콘텐츠 작업](/ai/content-operations), [시각적 검사](/ai/visual-inspection), [런타임 재사용 및 Daemon](/ai/runtime-architecture)을 참고하세요.
