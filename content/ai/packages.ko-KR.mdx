AI SDK는 현재 25개의 독립 패키지를 발행합니다. 애플리케이션이 필요로 하는 기본 패키지를 설치하고, 기본 터미널 상호 작용이 제품에 맞을 때 동일한 행에서 명령을 미리 설치합니다.

## 두 가지 패키지 역할

| 역할                   | 제공 기능                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| 기본 패키지 | Commander에 의존하지 않고 TypeScript API를 구조화하고 명령 이름, 출력 또는 종료 동작에 대한 의견이 없습니다. |
| 명령 프리셋 패키지 | 기본 패키지를 사용하는 네이티브 Commander `Command`로 기본 인수, 도움말, 터미널 상호작용 제공  |

명령 presets는 보통 `-command`에서 끝납니다. 각 기본적인 포장이 미리 설치를 필요로 하지 않습니다.

## 콘텐츠 및 공동 편집 런타임

여기에서 설명된 표준 headless Univer는 Web SDK 콘텐츠 플러그인에서 조립됩니다. [Headless 패키지 경계](/overview/features/shared/server-calculation#headless-packages)은 콘텐츠 패키지, UI 패키지, `engine-render` 사이의 분할을 설명합니다. 협업 및 렌더링 실행 시간은 그 내용 실행 시간의 상단에 선택적 기능을 추가합니다.

## 선택 방법

1. 업무에 맞는 기본 패키지부터 시작하세요.
2. 기본 Commander 상호작용이 제품에 맞을 때만 명령 프리셋을 추가하세요.
3. CLI, Web 및 Server가 Unit을 공유할 때, 협업 데이터베이스를 직접 읽는 대신 협업 런타임을 사용합니다.
4. 재사용, 프로세스 간 접근, 브라우저 렌더링이 필요할 때만 풀, 데몬, Render Runtime을 추가하세요.
5. public APIs에 대한 대상 패키지 README를 읽고 소유권 및 처리에 대한 세부 정보를 읽어보십시오.
