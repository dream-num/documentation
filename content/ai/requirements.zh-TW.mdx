## 執行環境要求

AI SDK 執行在 Node.js 上。使用渲染或檢查頁面的能力時，還需要瀏覽器。

| SDK／功能 | 要求 |
| --- | --- |
| AI SDK | Node.js 22.12+ |
| CLI 截圖、渲染、版面檢查 | Chrome、Chromium 或 Edge |

應用可以使用 npm、pnpm、Yarn 或其他包管理器。具體以所安裝 package 的 `engines` 和原生依賴要求為準。

<Callout title="版本統一要求">
  本頁文件對應 `1.0.0-rc.0`。同一個應用裡，所有 `@univerjs/*`、`@univerjs-pro/*` 和 `@univer-cli/*` package 都要使用這個版本。
</Callout>

完整的 package 列表見 [CLI Package 概覽](/ai/packages)。
