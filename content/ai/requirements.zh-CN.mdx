## 运行环境

AI SDK 运行在 Node.js 上。使用渲染或检查页面的能力时，还需要浏览器。

| SDK / 能力                          | 要求                     |
| ----------------------------------- | ------------------------ |
| AI SDK                              | Node.js 22.12+           |
| CLI Screenshot、Render、Layout Lint | Chrome、Chromium 或 Edge |

应用可以使用 npm、pnpm、Yarn 或其他包管理器。具体以所安装 package 的 `engines` 和原生依赖要求为准。

<Callout title="版本统一要求">
  本页文档对应 `1.0.0-rc.0`。同一个应用里，所有 `@univerjs/*`、`@univerjs-pro/*` 和 `@univer-cli/*` package 都要使用这个版本。
</Callout>

完整的 package 列表见 [CLI Package 概览](/ai/packages)。
