Инспекция может проверять значения, абзацы и структуру страницы. Она не может полностью описать текст, который переполняется, элементы, которые перекрываются, положение графики или окончательную компоновку страницы. После того, как операции структурированного контента будут выполнены, добавьте рендеринг браузера, чтобы агент мог проверить фактический визуальный результат.

```text
актуальные UnitData
→ Render Runtime
├── Screenshot → PNG → визуальная проверка AI Agent
└── Layout Lint → структурированное замечание → исправление AI Agent
```

## Шаг 1: явное состояние содержимого

Скриншот и Layout Lint работают на материализованном UnitData. Они не загружают удаленные цели, и они не интерпретируют изменения. Для совместного блока сначала синхронизируйте его и экспортируйте полное текущее состояние:

```ts
await runtime.pull();
const unitData = await runtime.exportUnitData();
```

В Worktree экспортировать UnitData из проекта-цели. Локальное приложение может использовать UnitData, который оно уже загрузило или импортировало. В обоих случаях визуальный осмотр работает против одного явного состояния контента.

## Шаг 2: сборка Render Page

`@univer-cli/univer-render-page` собирает страницу Render на стороне браузера. Приложение выбирает, какие плагины Univer включить и создает статичную страницу:

```ts
import { createPresetRenderUniver, mountUniverRenderPage } from "@univer-cli/univer-render-page";

const container = document.querySelector<HTMLElement>("#app");
if (container === null) throw new Error("#app is required");

await mountUniverRenderPage({
  container,
  createUniver: createPresetRenderUniver,
});
```

Страница Рендера - это точка входа браузера, а не страница для человеческого обзора. Она принимает UnitData от Node.js и возвращает PNG или факты макета.

## Шаг 3: создание Render Runtime

`@univer-cli/univer-render-runtime` размещает страницу в Node.js, запускает браузер и управляет протоколом:

```ts
import { createUniverRenderRuntime } from "@univer-cli/univer-render-runtime";

const renderRuntime = await createUniverRenderRuntime({
  renderPageRoot,
});
```

Один Render Runtime может выполнять несколько операций в последовательности. Повторно использовать его на внешней границе жизненного цикла, а не запускать браузер для каждого изображения.

## Шаг 4: снимок экрана

`@univer-cli/unit-screenshot` является точкой входа высокого уровня для скриншотов Sheet, Doc, Slide, Board и Base. Он обрабатывает выбор цели, пагинацию, масштаб, именование и ограничения ресурсов:

```ts
import { createUnitScreenshot } from "@univer-cli/unit-screenshot";

const screenshot = createUnitScreenshot({ runtime: renderRuntime });
const result = await screenshot.capture({
  unitType: "sheet",
  unitData,
  target: {
    kind: "sheet-range",
    sheetName: "Data",
    range: "B2:H40",
    scale: 2,
  },
});
```

Результат может содержать несколько изображений. Каждое изображение несет байты PNG, его размеры, страницу или цель, к которой оно принадлежит, и предложенное имя файла. Пакет не записывает файлы. Приложение определяет, где хранятся изображения и как агент их получает.

Без цели Screenshot выбирает контент по умолчанию для типа Unit, например, используемый диапазон активной рабочей таблицы, каждую страницу Doc или каждую страницу Slide.

## Шаг 5: диагностика макета Slide

`@univer-cli/unit-layout-lint` работает с фактами макета, которые производит настоящий браузер, и возвращает структурированные результаты с доказательствами:

```ts
import { createUnitLayoutLint } from "@univer-cli/unit-layout-lint";

const lint = createUnitLayoutLint({ runtime: renderRuntime });
const report = await lint.lint({
  unitType: "slide",
  unitData,
  pages: [1, "closing-slide"],
});
```

Действующими правилами являются:

- `text-off-page`: фактические текстовые чернила выходят за пределы страницы.
- `text-escapes-container`: текст видимо выходит за меньший непрозрачный контейнер.
- `text-overlaps-text`: две области реально нарисованного текста существенно перекрываются.

Находка — это предложение обзора, подкрепленное доказательствами, и оно не всегда требует изменения. Агент может комбинировать результаты со скриншотами, сделать еще один редактирование Фасада и снова запустить визуальный осмотр.

## Шаг 6: команды Commander

Скриншот и Layout Lint оба обеспечивают нативные предустановки Commander. Передайте возможности, построенные выше, и загрузчики UnitData приложения, а затем добавьте команды к тому же `program`, созданному в [Операции загрузки документов и контента](/ai/content-operations):

```ts
import type { UnitScreenshotCommandDependencies } from "@univer-cli/unit-screenshot-command";
import { createUnitScreenshotCommand } from "@univer-cli/unit-screenshot-command";
import type { UnitLayoutLintCommandDependencies } from "@univer-cli/unit-layout-lint-command";
import { createUnitLayoutLintCommand } from "@univer-cli/unit-layout-lint-command";
import type { Command } from "commander";

function addVisualCommands(
  program: Command,
  dependencies: {
    loadUnit: UnitScreenshotCommandDependencies["loadUnit"];
    writeImages: UnitScreenshotCommandDependencies["writeImages"];
    loadSlide: UnitLayoutLintCommandDependencies["loadUnit"];
  },
): void {
  program.addCommand(
    createUnitScreenshotCommand({
      screenshot,
      loadUnit: dependencies.loadUnit,
      writeImages: dependencies.writeImages,
    }),
  );

  program.addCommand(
    createUnitLayoutLintCommand({
      lint,
      loadUnit: dependencies.loadSlide,
    }),
  );
}
```

Предустановки владеют селекторами скриншотов, селектором страниц Slide, `--json`, выводом текста по умолчанию и выходом ошибки Commander. Параметры функции вводят отображение из идентификатора блока в состояние содержимого и PNG-писателя. Приложению также принадлежит жизненный цикл Render Runtime.

Предустановка Screenshot также может включать в себя подкоманду для установки и зондирования браузера. Браузер не загружается неявно для каждого захвата.

## Шаг 7: освобождение ресурсов

Создатель закрывает Render Runtime на самой внешней границе жизненного цикла Commander:

```ts
try {
  await program.parseAsync();
} finally {
  await renderRuntime.close();
}
```

Для ввода и вывода пользовательского агента обойдите предустановки и вызовите базовые пакеты напрямую. Не делайте ненадежный UnitData непосредственно на общем хосте с высокой привилегией. Используйте ограниченного пользователя, контейнер или другую границу изоляции процесса.

После того, как визуальные проверки доступны, добавьте тот же контент и возможности проверки в поток [Worktree: редактирование агентов и человеческий обзор](/ai/worktree).
