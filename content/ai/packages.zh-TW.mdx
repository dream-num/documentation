AI SDK 目前發布 25 個獨立套件。只安裝應用程式需要的基礎套件；若同一列的命令預設集之預設終端機互動符合產品需求，再加入它。

## 兩種套件角色

| 角色                   | 提供內容                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| 基礎套件           | 結構化 TypeScript API，不依賴 Commander，也不決定命令名稱、輸出或結束行為 |
| 命令預設集套件 | 由基礎套件支援的原生 Commander `Command`，提供預設參數、說明與終端機互動  |

命令預設集名稱通常以 `-command` 結尾。並非每個基礎套件都需要對應的命令預設集。

## 如何選擇

1. 先選擇符合業務任務的基礎套件。
2. 只有預設 Commander 互動符合產品需求時，才加入命令預設集。
3. CLI、Web 與 Server 共用 Unit 時，請使用協同執行環境，不要直接存取協同資料庫。
4. 只有需要重用、跨程序存取或瀏覽器渲染時，才加入集區、Daemon 或 Render Runtime。
5. 閱讀目標套件 README，了解公開 API、所有權與釋放行為。

概念與核心用法請參閱[文件載入與內容操作](/ai/content-operations)、[視覺檢查](/ai/visual-inspection)及[執行環境重用與 Daemon](/ai/runtime-architecture)。
