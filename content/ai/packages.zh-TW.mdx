AI SDK 目前提供 25 個獨立的 package。安裝應用所需的基礎功能包；當同一行的預設命令包預設終端互動符合產品需求時，再加入該預設命令包。

## 兩種套件角色

| 角色 | 提供內容 |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| 基礎套件 | 結構化 TypeScript API，不依賴 Commander，也不規定命令名稱、輸出和退出行為 |
| 命令預設集套件 | 基於基礎功能包封裝一個原生 Commander `Command`，提供預設參數、help 和終端互動 |

預設命令包通常以 `-command` 結尾。並非每個基礎功能包都需要預設命令包。

## 如何選擇

1. 先按業務需求找到對應的基礎功能包。
2. 預設的 Commander 互動符合產品需求時，再加入對應的預設命令包。
3. CLI、Web 和 Server 共享同一個 Unit 時，使用 Collaboration Runtime，而不是直接訪問協同資料庫。
4. 應用需要複用、跨程序訪問或瀏覽器渲染時，再引入 pool、daemon 或 Render Runtime。
5. 閱讀目標 package 的 README，確認其公共 API、資源所有權和釋放方式。

具體概念和核心用法見[文件內容載入與讀寫](/ai/content-operations)、[視覺檢查](/ai/visual-inspection)和 [Runtime 複用與 Daemon](/ai/runtime-architecture)。
