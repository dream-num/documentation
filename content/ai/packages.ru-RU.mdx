AI SDK в настоящее время публикует 25 независимых пакетов.Установите базовые пакеты, которые нужны приложению, а затем добавьте предустановленную команду из той же строки, когда ее взаимодействие по умолчанию с терминалом соответствует продукту.

## Две роли пакетов

| Роль                   | Предоставляет                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| Базовый пакет | Структурированные API TypeScript, не зависящие от Commander и не имеющие мнения об именах команд, выходе или поведении выхода |
| Пакет пресета команды | Нативный Commander `Command` на основе базового пакета со стандартными аргументами, справкой и взаимодействием в терминале  |

Командные пресеты обычно заканчиваются на `-command`. Не каждый базовый пакет нуждается в предустановке.

## Как выбрать

1. Начните с базового пакета для вашей задачи.
2. Добавляйте пресет только если стандартное взаимодействие Commander подходит продукту.
3. Когда CLI, Web и Server совместно используют блок, используйте время выполнения совместной работы вместо непосредственного чтения базы данных совместной работы.
4. Добавляйте пул, daemon или Render Runtime лишь при необходимости повторного использования, межпроцессного доступа или браузерного рендеринга.
5. Прочитайте целевой пакет README для его общедоступных API и для получения подробной информации о собственности и утилизации.

Для концепций и основного использования см. [Операции загрузки документов и контента](/ai/content-operations), [Визуальный осмотр](/ai/visual-inspection) и [Повторное использование и Daemon](/ai/runtime-architecture).
