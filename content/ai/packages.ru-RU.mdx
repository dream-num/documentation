AI SDK сейчас публикует 25 независимых пакетов. Установите лишь нужные базовые пакеты, затем добавьте пресет команды из той же строки, если его стандартное взаимодействие в терминале подходит продукту.

## Две роли пакетов

| Роль                   | Предоставляет                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| Базовый пакет           | Структурированные TypeScript API без зависимости от Commander и без определения имён команд, вывода и поведения при завершении |
| Пакет пресета команды | Нативный Commander `Command` на основе базового пакета со стандартными аргументами, справкой и взаимодействием в терминале  |

Имена пресетов команд обычно заканчиваются на `-command`. Не каждому базовому пакету нужен соответствующий пресет.

## Как выбрать

1. Начните с базового пакета для вашей задачи.
2. Добавляйте пресет только если стандартное взаимодействие Commander подходит продукту.
3. Когда CLI, Web и Server разделяют Unit, используйте совместную среду вместо прямого доступа к базе совместного редактирования.
4. Добавляйте пул, daemon или Render Runtime лишь при необходимости повторного использования, межпроцессного доступа или браузерного рендеринга.
5. Прочитайте README пакета о публичных API, владении и освобождении ресурсов.

Основные понятия и использование описаны в [Загрузке и операциях с содержимым](/ai/content-operations), [Визуальной проверке](/ai/visual-inspection) и [Повторном использовании Runtime и Daemon](/ai/runtime-architecture).
