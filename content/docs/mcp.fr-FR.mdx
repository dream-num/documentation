Univer SDK MCP permet à votre agent de rechercher la documentation officielle, de lire les références API et de générer l’initialisation d’un éditeur navigateur avec le même catalogue que le [générateur d’initialisation](/tools/initialization-generator).

## Connecter l’agent

Ajoutez ce serveur distant dans un agent compatible avec MCP Streamable HTTP :

| Paramètre | Valeur |
| --- | --- |
| Nom | `univer-docs` |
| Transport | Streamable HTTP |
| URL | `https://docs.univer.ai/mcp/docs` |
| Authentification | Aucune clé API requise |

Après activation, vérifiez que l’agent dispose des outils suivants :

| Outil | Fonction |
| --- | --- |
| `search_docs` | Rechercher des guides, exemples et API par sujet ou nom d’API, avec filtres de section et de langue |
| `get_doc` | Lire une page Markdown avec code, source et version ; poursuivre les longues pages avec `nextLine` |
| `list_features` | Consulter les identifiants des fonctionnalités navigateur, leur disponibilité et leurs exigences de licence |
| `generate_setup` | Générer les dépendances et l’initialisation : plugins, presets, langues et styles |

## Décrire la tâche

> Utilise Univer SDK MCP pour intégrer un tableur dans cette application React. Vérifie d’abord la version SDK installée et l’initialisation existante. Lis le guide d’intégration, ajoute l’édition des cellules et la sauvegarde de snapshots, puis compile et vérifie l’application.

> Utilise Univer SDK MCP pour trouver l’API Facade qui modifie le format numérique d’une cellule. Vérifie les plugins et imports nécessaires avant de modifier mon intégration Node.js existante.

Précisez le produit, le framework, l’environnement et le comportement souhaité. Les extraits de recherche servent à trouver les sources : l’agent doit lire les guides et API avant d’implémenter. Pour les icônes, connectez [Univer Icons MCP](/guides/icons/ai).

Le service lit la documentation publiée avec ce site. Comparez la version indiquée dans les réponses avec les paquets installés. Les fichiers générés ciblent les éditeurs navigateur ; certaines fonctions nécessitent une licence ou une configuration backend. Consultez les guides pour le cycle de vie, Headless Univer, la collaboration et la conversion de fichiers. Le serveur renvoie le contenu des fichiers, que l’agent applique et teste dans votre projet.
