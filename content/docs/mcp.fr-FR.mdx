Univer SDK MCP est un serveur MCP distant pour les agents de codage. Il recherche la documentation officielle, lit les références API et génère le code d'initialisation pour les éditeurs de navigateurs, en utilisant le même catalogue que le [générateur d'initialisation](/tools/initialization-generator).

## Connecter l’agent

Ajouter le serveur à un agent qui prend en charge le MCP HTTP Streamable :

| Paramètre | Valeur |
| --- | --- |
| Nom | `univer-docs` |
| Transport | Streamable HTTP |
| URL | `https://docs.univer.ai/mcp/docs` |
| Authentification | Aucune clé API requise |

Une fois le serveur activé, confirmez que l'agent peut voir ses outils :

| Outil | Fonction |
| --- | --- |
| `search_docs` | Guides de recherche, exemples et références d'API par sujet ou nom d'API, filtrés par section et langue |
| `get_doc` | Lire une page comme Markdown, avec des informations sur le code, la source et la version; utiliser `nextLine` pour continuer une longue page |
| `list_features` | Consultez les identifiants de fonctionnalités du navigateur qu'un produit supporte, ainsi que les exigences de disponibilité et de licence |
| `generate_setup` | Générer des fichiers de dépendance et d'initialisation avec des plugins, préréglages, locaux et styles |

## Décrire la tâche

> Utilisez Univer SDK MCP pour ajouter un tableur à cette application React. Vérifiez d'abord la version SDK installée et la configuration actuelle, lisez le guide d'intégration, ajoutez l'édition de cellules et l'enregistrement instantané, puis construisez et vérifiez l'application.

> Utilisez Univer SDK MCP pour trouver le Facade API qui modifie le format de nombre d'une cellule. Vérifiez le plugin de fonctionnalité et importez qu'il nécessite avant de modifier mon intégration Node.js existante.

Fournissez à l'agent le produit, le cadre, l'exécution et le comportement souhaité. Les résultats de recherche ne sont que des points d'entrée, de sorte que l'agent devrait lire le guide et la page API pertinents avant d'écrire un code. [Icônes Univer MCP](/guides/icons/ai).

Le service lit la documentation publiée sur ce site. Chaque réponse identifie la documentation ou la version du générateur qu'elle provient, qui peut être comparée avec les paquets installés dans le projet. Les éditeurs de navigateurs cibles sont créés, et certaines fonctionnalités nécessitent une licence ou une configuration sur le moteur. Le cycle de vie du cadre, Headless Univer, la collaboration et la conversion de fichiers ont chacun un guide dédié. Le serveur renvoie le contenu du fichier; l'agent les applique et les teste dans le projet
