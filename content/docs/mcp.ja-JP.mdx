Univer SDK MCP を使うと、コーディング Agent が公式ドキュメントと API リファレンスを検索・参照し、[初期化ジェネレーター](/tools/initialization-generator)と同じ機能カタログからブラウザーエディターの初期化コードを生成できます。

## Agent を接続する

Streamable HTTP MCP に対応する Agent にリモートサーバーを追加します。

| 設定 | 値 |
| --- | --- |
| 名前 | `univer-docs` |
| トランスポート | Streamable HTTP |
| サーバー URL | `https://docs.univer.ai/mcp/docs` |
| 認証 | API キー不要 |

有効にした後、Agent に次のツールが表示されることを確認してください。

| ツール | 用途 |
| --- | --- |
| `search_docs` | トピックや API 名でガイド、例、API リファレンスを検索。セクションと言語で絞り込み可能 |
| `get_doc` | コード、出典、バージョンを含む Markdown ページを取得。長いページは `nextLine` から続けて取得 |
| `list_features` | 製品のブラウザー機能 ID、利用可否、ライセンス要件を確認 |
| `generate_setup` | プラグイン、プリセット、ロケール、スタイルを含む依存関係と初期化ファイルを生成 |

## 開発タスクを伝える

> Univer SDK MCP を使い、この React アプリにスプレッドシートを組み込んでください。まずインストール済み SDK のバージョンと既存の初期化を確認し、統合ガイドを読んでください。セル編集とスナップショット保存を実装し、ビルドと動作検証を行ってください。

> Univer SDK MCP でセルの数値書式を変更する Facade API を調べてください。必要な機能プラグインとインポートを確認してから、既存の Node.js 統合を変更してください。

製品、フレームワーク、実行環境、期待する動作を伝えてください。検索結果の抜粋だけで実装せず、関連するガイドと API ページを読みます。アイコンには [Univer Icons MCP](/guides/icons/ai) を利用できます。

サービスはこのサイトとともに公開されたドキュメントを参照します。応答のドキュメントまたはジェネレーターのバージョンを、プロジェクトのインストール済みパッケージと照合してください。生成する初期化コードはブラウザー向けで、一部の機能にはライセンスやバックエンド設定が必要です。ライフサイクル、Headless Univer、共同編集、ファイル変換は各ガイドを参照してください。サービスはファイル内容を返し、Agent がプロジェクトに適用して検証します。
