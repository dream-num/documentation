Univer SDK MCP は、コーディングエージェント用のリモート MCP サーバーです。公式のドキュメントを検索し、API リファレンスを読み込み、ブラウザーエディタの初期化コードを生成し、[初期化ジェネレーター](/tools/initialization-generator) と同じカタログを使用します。

## Agent を接続する

ストリーム可能な HTTP MCP をサポートするエージェントにサーバーを追加します。

| 設定 | 値 |
| --- | --- |
| 名前 | `univer-docs` |
| トランスポート | Streamable HTTP |
| サーバー URL | `https://docs.univer.ai/mcp/docs` |
| 認証 | API キー不要 |

サーバが有効化した後、エージェントがそのツールを見ることができることを確認します。

| ツール | 用途 |
| --- | --- |
| `search_docs` | セクションと言語でフィルタリングされたトピックまたはAPI名でガイド、例、API参照を検索します。 |
| `get_doc` | コード、ソース、バージョン情報でMarkdownのページを読んでください。 `nextLine`を使用して長いページを継続します。 |
| `list_features` | 製品がサポートするブラウザ機能 ID を、可用性とライセンスの要件とともに調べる |
| `generate_setup` | 依存性および初期化ファイルをプラグイン、プリセット、ローカル、スタイルで生成します。 |

## 開発タスクを伝える

> Univer SDK MCP を使用して、この React アプリケーションにスプレッドシートを追加します。インストールされた SDK バージョンと現在の設定を最初に確認し、統合ガイドを読み、セルの編集とスナップショットの保存を追加し、アプリケーションをビルドおよび検証します。

> Univer SDK MCP を使用して、セルの数値形式を変更する Facade API を検索します。 機能プラグインをチェックし、既存の Node.js インテグレーションを変更する前に、それをインポートします。

エージェントを製品、フレームワーク、ランタイム、および目的の行動で提供してください。検索結果はエントリポイントのみです。そのため、エージェントは関連するガイドとAPIページを読んで、任意のコードを記述する必要があります。アイコンを使用するには、[Univer アイコン MCP](/guides/icons/ai)を接続します。

サービスは、このサイトで公開されたドキュメントを読み込みます。各応答は、プロジェクトにインストールされたパッケージと比較して、そこから来たドキュメントまたはジェネレータのバージョンを識別します。セットアップ対象ブラウザエディタを生成し、一部の機能は、バックエンドのライセンスまたは構成を必要とします。フレームワークのライフサイクル、Headless Univer、コラボレーション、およびファイル変換は、それぞれ専用のガイドを持っています。サーバーはファイルの内容を返します。エージェントは、プロジェクトでそれらを適用し、テストします。
