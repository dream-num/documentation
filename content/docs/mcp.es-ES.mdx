Univer SDK MCP es un servidor remoto de MCP para los agentes de codificación. Busca la documentación oficial, lee las referencias de API y genera código de inicialización para los editores del navegador, utilizando el mismo catálogo que el [generador de inicialización](/tools/initialization-generator).

## Conectar el agente

Agregue el servidor a un agente que admite el MCP de HTTP Streamable:

| Ajuste | Valor |
| --- | --- |
| Nombre | `univer-docs` |
| Transporte | Streamable HTTP |
| URL | `https://docs.univer.ai/mcp/docs` |
| Autenticación | No requiere clave API |

Después de que el servidor esté habilitado, confirme que el agente puede ver sus herramientas:

| Herramienta | Función |
| --- | --- |
| `search_docs` | Guías de búsqueda, ejemplos y referencias de API por tema o nombre de API, filtrados por sección e idioma |
| `get_doc` | Lea una página como Markdown, con código, fuente e información de la versión; use `nextLine` para continuar una página larga |
| `list_features` | Busque los IDs de características del navegador que un producto soporta, junto con los requisitos de disponibilidad y licencia |
| `generate_setup` | Generar archivos de dependencia e inicialización con plugins, presets, locales y estilos |

## Describir la tarea

> Utilice Univer SDK MCP para agregar una hoja de cálculo a esta aplicación React. Compruebe la versión SDK instalada y la configuración actual primero, lea la guía de integración, agregue la edición de celdas y el ahorro de instantáneas, luego construir y verificar la aplicación.

> Utilice Univer SDK MCP para encontrar el Facade API que cambia el formato número de una célula. Compruebe el plugin de función e importaciones que requiere antes de cambiar mi integración Node.js existente.

Proporcione al agente con el producto, el marco, el tiempo de ejecución y el comportamiento deseado. Los resultados de búsqueda son puntos de entrada solamente, por lo que el agente debe leer la guía y página de API pertinentes antes de escribir cualquier código. Para trabajar con iconos, conecte [Univer Icons MCP](/guides/icons/ai).

El servicio lee la documentación publicada en este sitio. Cada respuesta identifica la documentación o la versión del generador de la que provenía, que puede compararse con los paquetes instalados en el proyecto. Generado los editores del navegador de destino, y algunas características requieren una licencia o configuración en el backend.
