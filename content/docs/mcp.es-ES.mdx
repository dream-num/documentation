Univer SDK MCP permite que tu agente busque documentación oficial, consulte las API y genere código de inicialización para editores de navegador con el mismo catálogo del [generador de inicialización](/tools/initialization-generator).

## Conectar el agente

Añade este servidor remoto en un agente compatible con MCP Streamable HTTP:

| Ajuste | Valor |
| --- | --- |
| Nombre | `univer-docs` |
| Transporte | Streamable HTTP |
| URL | `https://docs.univer.ai/mcp/docs` |
| Autenticación | No requiere clave API |

Tras activarlo, comprueba que el agente dispone de estas herramientas:

| Herramienta | Función |
| --- | --- |
| `search_docs` | Buscar guías, ejemplos y API por tema o nombre, filtrando por sección e idioma |
| `get_doc` | Leer una página Markdown con código, fuente y versión; continuar páginas largas con `nextLine` |
| `list_features` | Consultar los ID de funciones del navegador, su disponibilidad y requisitos de licencia |
| `generate_setup` | Generar dependencias e inicialización con plugins, presets, idiomas y estilos |

## Describir la tarea

> Usa Univer SDK MCP para integrar una hoja de cálculo en esta aplicación React. Revisa primero la versión SDK instalada y la inicialización existente. Lee la guía de integración, añade edición de celdas y guardado de snapshots, y compila y verifica la aplicación.

> Usa Univer SDK MCP para encontrar la API Facade que cambia el formato numérico de una celda. Comprueba los plugins e imports necesarios antes de modificar mi integración Node.js existente.

Indica el producto, el framework, el entorno y el comportamiento esperado. Los fragmentos de búsqueda ayudan a encontrar fuentes; el agente debe leer las guías y API antes de implementar. Para iconos, conecta [Univer Icons MCP](/guides/icons/ai).

El servicio consulta la documentación publicada con este sitio. Compara la versión indicada en las respuestas con los paquetes instalados. Los archivos generados son para editores de navegador; algunas funciones requieren licencia o configuración del backend. Consulta las guías de ciclo de vida, Headless Univer, colaboración y conversión de archivos. El servidor devuelve el contenido de los archivos y tu agente lo aplica y prueba en el proyecto.
