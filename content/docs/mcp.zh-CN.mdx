Univer SDK MCP 是一个面向编程 Agent 的远程 MCP 服务。它可以搜索官方文档、读取 API 参考，并生成浏览器编辑器的接入代码，所用目录与[初始化生成器](/tools/initialization-generator)一致。

## 连接 Agent

在支持 Streamable HTTP MCP 的 Agent 中添加该服务：

| 设置 | 值 |
| --- | --- |
| 名称 | `univer-docs` |
| 传输方式 | Streamable HTTP |
| 服务地址 | `https://docs.univer.ai/mcp/docs` |
| 认证 | 无需 API Key |

启用服务后，确认 Agent 可以看到以下工具：

| 工具 | 用途 |
| --- | --- |
| `search_docs` | 按主题或 API 名称搜索指南、示例和 API 参考，并可按章节和语言筛选 |
| `get_doc` | 以 Markdown 形式读取页面，包含代码、来源和版本信息；长页面可使用 `nextLine` 继续读取 |
| `list_features` | 查询某个产品支持的浏览器功能 ID，以及可用性和许可证要求 |
| `generate_setup` | 生成依赖文件和初始化文件，包含插件、预设、语言包和样式 |

## 描述开发需求

> 使用 Univer SDK MCP，为此 React 应用添加电子表格。先检查已安装的 SDK 版本和现有的初始化方式，阅读集成指南，添加单元格编辑和快照保存，然后构建并验证应用。

> 使用 Univer SDK MCP，找到修改单元格数字格式的 Facade API。在修改现有的 Node.js 集成之前，先确认所需的功能插件和导入。

向 Agent 说明所用的产品、框架、运行环境和期望的行为。搜索结果只是入口，Agent 在编写代码前应先阅读相关指南和 API 页面。如需使用图标，可连接 [Univer Icons MCP](/guides/icons/ai)。

服务读取本站发布的文档。每个结果都会标明其来自哪个文档版本或生成器版本，可与项目中已安装的包进行比对。生成的接入代码面向浏览器编辑器，部分功能需要许可证，或需要在业务后端进行配置。框架生命周期、Headless Univer、协同和文件转换各有对应的指南。服务只返回文件内容，由 Agent 在项目中应用并测试。
