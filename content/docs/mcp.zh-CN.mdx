Univer SDK MCP 让编程 Agent 搜索官方文档、读取 API 参考，并使用与[初始化生成器](/tools/initialization-generator)相同的功能目录生成浏览器编辑器接入代码。

## 连接 Agent

在支持 Streamable HTTP MCP 的 Agent 中添加远程服务：

| 设置 | 值 |
| --- | --- |
| 名称 | `univer-docs` |
| 传输方式 | Streamable HTTP |
| 服务地址 | `https://docs.univer.ai/mcp/docs` |
| 认证 | 无需 API Key |

启用服务后，确认 Agent 能看到以下工具：

| 工具 | 用途 |
| --- | --- |
| `search_docs` | 按主题或 API 名称搜索指南、示例和 API 参考，可筛选章节与语言 |
| `get_doc` | 读取包含代码、来源和版本信息的 Markdown 页面，使用 `nextLine` 继续读取长页面 |
| `list_features` | 查询产品可用的浏览器功能 ID、可用性和许可证要求 |
| `generate_setup` | 生成依赖和初始化文件，包含插件、预设、语言包和样式 |

## 描述开发需求

> 使用 Univer SDK MCP，在这个 React 应用中接入电子表格。先检查已安装的 SDK 版本和现有初始化方式，阅读集成指南，实现单元格编辑与快照保存，然后构建并验证应用。

> 使用 Univer SDK MCP，查找修改单元格数字格式的 Facade API。先确认所需功能插件和导入，再修改现有的 Node.js 集成。

告诉 Agent 产品类型、框架、运行环境和期望行为。搜索摘要用于定位资料，编写代码前应读取相关指南和 API 页面。需要图标时，可以连接 [Univer Icons MCP](/guides/icons/ai)。

服务读取随本站发布的文档，结果包含文档或生成器版本，应与项目已安装版本核对。初始化代码面向浏览器编辑器，部分功能需要许可证或业务后端配置。框架生命周期、Headless Univer、协同与文件转换应参考对应指南。服务返回文件内容，由 Agent 在你的项目中应用并测试。
