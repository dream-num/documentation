Эти открытые проекты превращают **[Univer Office SDK](/docs/overview)** в приложения: автоматизируйте локальные Office-файлы с агентом, редактируйте вместе с командой или создавайте, просматривайте и проверяйте результаты прямо в существующем чате.

Они объединяют движок содержимого, редакторы, расчёты, совместную работу, версии, Worktree и операции создания и проверки для агентов из Office SDK. CLI, Workspace и Workspace Desktop — готовые приложения. Примеры DeepSeek Harness, WorkBuddy и OpenClaw — плагины интеграции Univer Office для соответствующих сред.

## Workspace [#univer-workspace]

Разверните Server и Web и подключите агентов через Workspace CLI и Skills для работы с общим содержимым.

[Подробнее о проекте](/docs/examples/workspace) · [Попробовать онлайн](https://space.univer.ai) · [Исходный код](https://github.com/dream-num/univer-workspace)

## Workspace Desktop [#univer-workspace-desktop]

Агент, нативный Office, боковой просмотр и ревью Worktree в одном приложении. Office SDK и готовый runtime показывают Office-среду с процессом, похожим на Codex или Claude Code.

[О Desktop](/docs/examples/workspace-desktop) · [Десктопные версии](https://github.com/dream-num/univer-workspace/releases) · [Исходный код](https://github.com/dream-num/univer-workspace/tree/main/apps/agent)

## CLI [#univer-cli]

Подключите локальные Office-возможности к OpenCode, Claude Code, OpenClaw, Hermes, Codex, WorkBuddy, Kimi Work и другим агентам. Установите CLI и Skill, откройте официальный пример, затем создавайте и проверяйте свои результаты.

[Подробнее о проекте](/docs/examples/cli) · [Быстрый старт](https://github.com/dream-num/univer-cli#quick-start) · [Исходный код](https://github.com/dream-num/univer-cli)

## Плагин DeepSeek Harness [#deepseek-harness]

Для Office-работы в разговоре: опишите задачу, наблюдайте за живым окном, затем проверяйте, дорабатывайте и передавайте результат в том же чате.

[Подробнее о проекте](/docs/examples/deepseek-harness) · [Смотреть демонстрацию](https://www.youtube.com/watch?v=k-2zW_CMiew) · [Исходный код](https://github.com/dream-num/dsh-univer-office)

## Плагин WorkBuddy [#workbuddy]

Для MCP-интеграции с агентным хостом: локальные Office-файлы, предпросмотр только для чтения и проверка версий в браузере. Пока предварительная версия.

[Подробнее о проекте](/docs/examples/workbuddy) · [Посмотреть процесс](https://github.com/dream-num/workbuddy-univer-office#workflow) · [Исходный код](https://github.com/dream-num/workbuddy-univer-office)

## Плагин OpenClaw [#openclaw]

Для существующих процессов OpenClaw: запускайте задачи с командными файлами из чата, редактируйте и проверяйте черновик Workspace и возвращайте результат для телефона и компьютера.

[Подробнее о проекте](/docs/examples/openclaw) · [Посмотреть процесс](https://github.com/dream-num/openclaw-univer-office#typical-request) · [Исходный код](https://github.com/dream-num/openclaw-univer-office)
