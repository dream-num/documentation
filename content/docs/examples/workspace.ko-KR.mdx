Univer Workspace는 사람과 에이전트의 공동 작업을 위해 **[Univer Office SDK](/docs/overview)**로 구축한 오픈 소스 Office 앱입니다. **Server와 Web** 온라인 버전을 배포하고 **Workspace CLI + Skills**로 기존 에이전트를 연결합니다.

## 공유 파일을 작업 맥락으로 활용 [#workspace-context]

![공유 파일을 작업 맥락으로 활용](/assets/examples/workspace-desktop/workspace-overview.jpg)

Aurora Space에는 수식 기반 운영 모델, 의사결정 문서, 프레젠테이션, 업무 목록, 전략 캔버스가 함께 있습니다. Web과 Desktop은 동일한 공유 파일에 연결됩니다. Agent는 자료를 읽고 Worktree에서 변경을 준비하며, 새 문서는 검토자가 병합할 때까지 초안으로 유지됩니다. 같은 예제의 생성과 수정 과정은 [Desktop 대화와 미리보기](/docs/examples/workspace-desktop#conversation-preview)에서 확인할 수 있습니다.

[Space 조작 과정](/docs/examples/workspace-desktop#space-walkthrough)과 [Web + Desktop 공동 편집](/docs/examples/workspace-desktop#cross-device-collaboration)을 확인하세요. 같은 계정으로 두 클라이언트에서 같은 문서를 편집하는 예제입니다.

## Workspace CLI: 모든 에이전트를 작업 공간에 연결 [#cli-start]

온라인 버전을 배포한 후 에이전트마다 Office 통합을 개발할 필요가 없습니다. 에이전트 실행 환경에 CLI와 Skill을 설치하면 명령을 실행할 수 있는 에이전트가 파일 검색, 편집, 계산, 스크린샷, 검증, 검토 링크 전달을 수행합니다. 모델과 대화는 선택한 에이전트가 계속 제공합니다.

Node.js 22.12 이상을 사용하며 24를 권장합니다. npm 패키지는 `univer-workspace-cli`이고 같은 프로그램에 `uvw`와 `univer-workspace-cli` 두 명령을 제공합니다.

```bash
npm install --global univer-workspace-cli@latest
npx skills add dream-num/univer-workspace --skill univer-workspace-cli -g
uvw --version
```

기본 연결 대상은 온라인 데모입니다. 자체 배포 환경은 서비스 주소를 설정하세요.

```bash
uvw config set workspace.origin https://space.univer.ai
```

처음 연결할 때 CLI 안내에 따라 한 번 로그인하면 CLI가 세션을 관리해 다음 작업에서도 재사용합니다. 에이전트별 로그인 페이지, OAuth 콜백, 인증 통합을 만들 필요가 없습니다.

<details>

<summary>최초 연결: 브라우저에서 한 번 로그인</summary>

유효한 세션이 있으면 생략하세요. 로그인이 필요할 때 실행합니다.

```bash
uvw auth login
```

반환된 링크에서 로그인하고 코드를 확인하세요. 사용자가 완료했다고 확인한 후 다음을 실행합니다.

```bash
uvw auth login --complete
```

세션을 설정할 때 필요한 절차입니다. 자세한 명령과 인증은 [Workspace CLI 가이드](https://github.com/dream-num/univer-workspace/blob/main/apps/cli/README.md)를 참조하세요.

</details>

## Skills: 작업 공간 이해부터 작업 완료까지 [#skills]

기존 에이전트에 설치하는 [`univer-workspace-cli` Skill](https://github.com/dream-num/univer-workspace/blob/main/skills/univer-workspace-cli/SKILL.md)은 연결, 대상 찾기, 가이드 로딩을 안내하는 진입점입니다. 전체 런타임 Skills는 CLI와 함께 배포되어 명령과 Facade API 버전에 맞습니다. Desktop의 내장 플러그인도 작업별 가이드와 도구를 제공합니다.

| 가이드 | 범위 |
| --- | --- |
| `core` | 공간·파일 찾기, 작업 초안, 콘텐츠 검증, 검토 전달. |
| `sheet` · `doc` · `slide` · `base` · `board` | 스프레드시트, 문서, 프레젠테이션, Relational Table, Canvases. SDK/API 이름은 Base와 Board입니다. |
| `blob` | 원본 파일 업로드, 다운로드, 교체. |
| `html-view` | 실시간 HTML 페이지를 생성·관리해 대화형 Web App 구축. |
| `embed` · `cross-unit-formula` | 콘텐츠 임베드 및 콘텐츠 간 데이터·수식 참조. |

```bash
uvw skills list
uvw skills get core
uvw skills get sheet
uvw skills get html-view
```

먼저 `core`, 다음으로 필요한 제품·주제를 불러옵니다. `skills get`은 참조 경로를 나열하고 `uvw skills read <name> <path>`는 개별 문서를, `--full`은 전체를 읽습니다. 기존 에이전트는 CLI를 사용하고 Desktop은 도구와 가이드를 대화에 통합합니다.

## Office 문서에서 Web App으로 [#web-apps]

스프레드시트, 문서, 프레젠테이션, 관계형 테이블, 캔버스 외에도 해당 콘텐츠를 활용하는 대시보드, 대화형 보고서, 예산 시뮬레이터, 업무 Web App을 생성할 수 있습니다. HTML View와 양방향 바인딩으로 지표, 차트, 입력, 슬라이더를 표에 연결합니다. 화면 조작은 데이터를 갱신하고 데이터 변경은 화면에 반영되며 협업과도 연결할 수 있습니다.

## 요청·변경·검토 연결

Workspace CLI는 `uvw issue`와 `uvw pr`도 제공합니다. Issue는 팀 요청과 토론을, PR은 검토할 변경을 담으며 기반은 Worktree입니다. 에이전트가 작업을 읽고 네이티브 콘텐츠를 편집·검사해 사람에게 변경을 전달하므로 팀 요청과 Office 결과물을 연결할 수 있습니다.

## 실제 초안을 확인한 뒤 병합 결정 [#agent-review]

Desktop의 네이티브 검토 화면은 공유 원본과 제안된 변경을 나란히 보여 줍니다. 같은 초안을 Workspace에서 열어 Ready 상태, 변경 파일 목록, 네이티브 문서 화면을 확인할 수도 있습니다. View와 Compare로 결과를 검토한 뒤 병합 여부를 결정합니다. Agent가 작업을 완료해도 공유 원본 파일이 자동으로 변경되지는 않습니다.

## Office SDK가 담당하는 부분 [#sdk-integration]

Web SDK는 공통 모델, 편집기, 렌더링, 헤드리스 처리를, Server SDK는 협업·버전·Worktree를, AI SDK는 에이전트 작업·검증을 제공합니다. Workspace는 이를 배포 가능한 Server와 온라인 앱으로 구성합니다. CLI는 기존 에이전트에 기능을 제공하고 Desktop은 에이전트 Office 앱으로 통합합니다.
