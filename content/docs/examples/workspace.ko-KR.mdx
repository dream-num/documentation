**Univer Workspace**는 **[Univer Office SDK](/overview)**로 만든 오픈 소스 Office 작업 공간입니다. 편집 가능한 Office 콘텐츠와 데이터에 연결된 Web App을 개인 및 팀 Space에 모아 공유, 협업, 버전 및 변경 검토를 연결합니다. [저장소](https://github.com/dream-num/univer-workspace)에 앱, 배포 구성, CLI와 데스크톱 클라이언트가 있습니다.

직접 배포하거나 [클라우드 체험](https://space.univer.ai)으로 시작할 수 있습니다. 기존 Agent는 Workspace CLI로 연결하고, Workspace Desktop은 Agent 대화와 같은 작업 공간을 로컬 앱에 통합합니다. 모두 같은 서비스와 파일을 사용합니다.

## 클라우드에서 Workspace 먼저 체험하기 [#entry-points]

<span id="web-start" />

[클라우드 체험](https://space.univer.ai)에 로그인하고 개인 Space나 접근 가능한 팀 Space를 엽니다. 문서 생성, 편집, 정리와 공유를 체험하세요. 아래 CLI로 이 서비스에 Agent도 연결할 수 있습니다. 체험에는 샘플 데이터를 사용하세요. 데이터가 초기화될 수 있습니다.

**Workspace Server**는 ID, Space, 권한, 저장소, 협업과 버전을 관리하고, **Web**은 편집 및 검토용 브라우저 화면을 제공합니다. 자체 배포에서도 같은 Server와 Web 앱을 사용합니다.

## 기존 Agent를 클라우드 Workspace에 연결하기 [#cli-start]

Agent 실행 환경에 CLI와 탐색용 Skill을 설치합니다. Node.js 22.12 이상이 필요하며 24를 권장합니다. 명령을 실행할 수 있는 Agent라면 자체 모델과 대화를 유지하면서 도구를 사용할 수 있습니다. 브라우저와 Agent가 같은 Workspace를 사용하도록 클라우드 주소를 지정합니다:

```bash
npm install --global univer-workspace-cli@latest
npx skills add dream-num/univer-workspace --skill univer-workspace-cli -g
uvw --version
uvw config set workspace.origin https://space.univer.ai
```

<details>

<summary>최초 연결: 브라우저에서 한 번 로그인</summary>

유효한 세션이 있으면 생략하세요. 로그인이 필요할 때 실행합니다.

```bash
uvw auth login
```

반환된 링크에서 로그인하고 코드를 확인하세요. 사용자가 완료했다고 확인한 후 다음을 실행합니다.

```bash
uvw auth login --complete
```

세션을 설정할 때 필요한 절차입니다. 자세한 명령과 인증은 [Workspace CLI 가이드](https://github.com/dream-num/univer-workspace/blob/main/apps/cli/README.md)를 참조하세요.

</details>

최초 브라우저 승인 후 CLI가 세션을 재사용합니다. Agent마다 로그인 화면이나 인증 연동을 만들 필요가 없습니다. 연결된 Agent에 작업을 요청하고 반환된 링크를 Web에서 열어 같은 콘텐츠와 병합 전 Office 변경을 검토합니다.

## 같은 흐름을 자체 배포로 옮기기 [#self-host]

[오픈 소스 저장소](https://github.com/dream-num/univer-workspace)에는 Server와 Web이 포함됩니다. [배포 가이드](https://github.com/dream-num/univer-workspace/blob/main/apps/workspace/README.md#docker)에 따라 도메인, 로그인, 영구 저장소와 실행 설정을 구성하세요. 소스 개발은 Node.js 24와 pnpm 11을 사용합니다.

같은 CLI를 자체 서비스로 연결하고 해당 서비스 계정을 승인합니다. 아래 예시를 실제 서비스 주소로 바꾸세요:

```bash
uvw config set workspace.origin https://workspace.example.com
uvw auth login
```

Agent의 도구와 Skills는 그대로 유지되며 자체 서비스의 파일과 권한을 사용합니다. Desktop도 연결할 수 있습니다. 클라이언트 등록과 콜백 구성은 [Agent 연결 가이드](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#connect-to-a-local-workspace)를 참고하세요.

## Workspace를 로컬 Desktop 클라이언트로 가져오기 [#desktop-start]

**Workspace Desktop**은 Workspace, Agent 런타임, Office 도구와 콘텐츠 미리보기를 로컬 앱에 통합합니다. Codex나 Cowork처럼 목표를 설명하고, 대화 옆의 문서나 Web App을 보면서 수정을 요청하고 결과를 검토합니다.

체험한 클라우드, 자체 배포 또는 로컬 Workspace 서비스에 연결할 수 있습니다. 모델과 대화는 설정한 Agent 호스트에서 실행되고, 파일과 접근 권한은 연결된 Workspace가 관리합니다. 아래 실제 데스크톱 사례로 생성, 관리와 협업 흐름을 살펴보세요.

[설치하고 연결하기](#desktop-install) · [첫 작업: 두 문서로 예산 검토](#desktop-first-task)

### 일상적인 Office 작업으로 확장되는 에이전트 경험 [#why-desktop]

Office 결과물은 계속 편집하고 수식을 계산하며 팀과 협업하고 변경을 검토할 수 있어야 합니다. Desktop은 이 과정을 하나의 환경에 연결합니다.

- **맥락 유지:** 대화, 파일, Workspace 자료와 로컬 참조를 함께 사용합니다.
- **Office 콘텐츠와 Web App 생성:** 편집 가능한 스프레드시트, 문서, 프레젠테이션, Relational Table, Canvases와 해당 데이터를 활용하는 대화형 페이지를 만듭니다.
- **확인하며 수정:** 옆에서 결과와 수식, 레이아웃을 확인한 뒤 구체적인 수정을 요청합니다.
- **검토 후 전달:** Office 변경은 Worktree에 보관하고 사람이 차이를 확인한 뒤 공유 공간에 병합합니다.

### 요청에서 검토 가능한 결과물까지 [#workflow]

### 데스크톱이 연결하는 기능

| 기능 | 경험 |
| --- | --- |
| 에이전트 세션 | 대화와 작업 맥락을 유지하고 모델 제공자와 자격 증명을 로컬에서 설정합니다. |
| 파일과 참조 | 접근 가능한 Space를 탐색하고 @로 Workspace 파일, 폴더와 로컬 자료를 참조합니다. |

### 실제 화면으로 보는 Workspace와 Agent의 협업 [#workspace-and-agent]

다음 화면과 조작 과정은 새 로컬 Workspace에 연결한 macOS 데스크톱 앱에서 직접 캡처했습니다. 계정, Space, 파일명, 본문, Agent 대화는 모두 영어로 된 가상 데모 자료를 사용합니다.

#### 일반 대화에서 콘텐츠를 만들고 결과 확인 [#conversation-creation]

**Build Five-File Launch Demo**는 스프레드시트, 문서, 프레젠테이션, Relational Table, 캔버스를 만든 일반 에이전트 대화입니다. 실제 대화의 결과 전달과 Desktop 브라우저 패널에서 편집 가능한 **02 Launch Brief**를 함께 보여 줍니다. 대화에서 수정을 요청하고 생성된 파일은 Space에서 관리·공유할 수 있습니다.

![일반 대화에서 콘텐츠를 만들고 결과 확인](/assets/examples/workspace-desktop/local-chat-creation.jpg)

<span id="web-apps" className="block scroll-m-24" />

Agent는 일반 대화에서 대화형 보고서, 업무 페이지, 대시보드도 만들 수 있습니다. 후속 대화에서는 게시된 예산표를 바탕으로 **06 Launch Dashboard**를 만들었습니다. 세 지표 카드가 예산·실제 지출·차이를 보여 주고 비교 차트는 HTML View 실시간 바인딩으로 여섯 업무 영역의 데이터를 따릅니다. 이 예제는 같은 기본 스프레드시트를 읽기만 하며 데이터를 쓰지 않습니다. [양방향 바인딩](/overview/features/shared/binding)은 실험 단계이며 변경될 수 있습니다.

![Launch Dashboard](/assets/examples/workspace-desktop/local-web-app.jpg)

#### Space에서 결과를 관리하고 공유하며 협업 [#workspace-context]

대화에서 만든 기본 출시 파일 다섯 개와 **06 Launch Dashboard**를 **Aurora Launch Studio**에 모았습니다. 같은 Space에서 예산표, 브리프, 3장짜리 발표 자료, 업무 목록, 프로세스 캔버스, Web App을 정리하고 접근 권한을 관리하며 팀과 공유합니다. 팀은 기본 Office 콘텐츠를 공동 편집하고 연결된 페이지는 원본 데이터를 따라 갱신됩니다. Web과 Desktop은 같은 파일을 사용하며 Agent의 후속 수정은 독립된 Worktree에서 검토를 기다립니다.

![Space에서 결과를 관리하고 공유하며 협업](/assets/examples/workspace-desktop/local-space-overview.jpg)

#### Desktop에서 공유 콘텐츠 공동 편집 [#cross-device-collaboration]

Web과 Desktop이 같은 로컬 계정으로 **01 Launch Budget**을 엽니다. Web에서 입력한 메모가 실제 Desktop 편집기에 나타나고, Desktop의 확인 메모도 Web으로 동기화됩니다. 화면은 두 메모와 동기화 상태를 보여 줍니다. 같은 계정의 클라이언트 간 동기화 예제이며 Agent 초안은 Worktree에 격리됩니다.

#### 대화로 생성하고 수정한 뒤 검토 요청 [#conversation-preview]

### 하나의 데스크톱에서 다섯 가지 네이티브 콘텐츠 사용 [#desktop-tour]

영문 Aurora 프로젝트는 가상 데이터로 예산, 브리프, 발표 자료, 업무 목록, 프로세스 캔버스를 연결합니다. 화면은 Desktop 안의 기본 Office 편집기이며 사람이 Agent가 조작하는 동일한 콘텐츠를 계속 편집할 수 있습니다.

스크린샷은 데스크톱 통합 미리보기입니다. 호스트 확장 지점으로 Univer 브랜드 UI를 적용했습니다. 확장 가능한 Agent 호스트와 Space 기능 플러그인을 조합한 것으로, 미리보기 플러그인 배포 상태는 프로젝트 릴리스를 따릅니다.

#### Sheets: 계산 가능한 비즈니스 모델 [#desktop-sheets]

예산표는 여섯 업무 영역의 Budget, Actual, Variance를 수식으로 계산하고 기본 비교 차트를 표시합니다. 예산 합계는 USD 102,000, 실제 지출은 USD 100,000, 유리한 차이는 USD 2,000입니다. Agent는 Facade API로 계산 결과를 검증합니다.

### 설치하고 연결하기 [#desktop-install]

확장 가능한 Agent 데스크톱에 Space 기능 플러그인을 설치하고 활성화한 뒤 Space에서 서비스에 연결하고 모델과 브랜드 UI를 설정할 수도 있습니다. 본문의 화면은 이 구성입니다. 완성형 Desktop과 미리보기 플러그인은 배포 경로가 다르므로 설치할 버전의 릴리스 또는 저장소 지침을 따르세요.

1. [GitHub Releases](https://github.com/dream-num/univer-workspace/releases)에서 agent-v 태그의 Desktop을 선택합니다. Windows x64, macOS Apple Silicon, Linux x64를 대상으로 하며 실험 단계이므로 실제 공개 버전을 확인하세요.

2. **Settings → Workspace**에서 서비스를 선택하고 브라우저에서 로그인해 권한을 승인합니다. 기존 서비스나 [로컬 환경](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#connect-to-a-local-workspace)을 사용할 수 있습니다.

3. Models에서 지원하는 제공자, 모델과 자격 증명을 설정합니다. Workspace 로그인과 별도이며 [모델 설정](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#model-credentials)을 참고하세요.

4. 접근 가능한 개인 또는 팀 Space를 추가하고 대화를 시작해 @로 자료를 참조합니다. 아래 작업으로 미리 보기와 변경 검토를 체험하세요.

설치 프로그램은 에이전트 앱과 Office 도구를 포함합니다. Workspace 서비스는 로컬 또는 서버에서 별도로 실행하며 모델 접근도 설정해야 합니다.

### Skills: 작업 공간 이해부터 작업 완료까지 [#skills]

#### 기존 Agent를 위한 Skills

기존 에이전트에 설치하는 [`univer-workspace-cli` Skill](https://github.com/dream-num/univer-workspace/blob/main/skills/univer-workspace-cli/SKILL.md)은 연결, 대상 찾기, 가이드 로딩을 안내하는 진입점입니다. 전체 런타임 Skills는 CLI와 함께 배포되어 명령과 Facade API 버전에 맞습니다. Desktop의 내장 플러그인도 작업별 가이드와 도구를 제공합니다.

| 가이드 | 범위 |
| --- | --- |
| `core` | 공간·파일 찾기, 작업 초안, 콘텐츠 검증, 검토 전달. |
| `sheet` · `doc` · `slide` · `base` · `board` | 스프레드시트, 문서, 프레젠테이션, Relational Table, Canvases. SDK/API 이름은 Base와 Board입니다. |
| `blob` | 원본 파일 업로드, 다운로드, 교체. |
| `html-view` | 실시간 HTML 페이지를 생성·관리해 대화형 Web App 구축. |
| `embed` · `cross-unit-formula` | 콘텐츠 임베드 및 콘텐츠 간 데이터·수식 참조. |

```bash
uvw skills list
uvw skills get core
uvw skills get sheet
uvw skills get html-view
```

먼저 `core`, 다음으로 필요한 제품·주제를 불러옵니다. `skills get`은 참조 경로를 나열하고 `uvw skills read <name> <path>`는 개별 문서를, `--full`은 전체를 읽습니다. 기존 에이전트는 CLI를 사용하고 Desktop은 도구와 가이드를 대화에 통합합니다.

<span id="작업별로-필요한-조작-지침-읽기" />

#### Desktop의 작업 지침 [#desktop-skills]

기능 플러그인은 **univer** Skill과 참조 자료를 포함합니다. Space와 문서 찾기, Office API, Worktree 생성·검증·전달을 안내합니다. 에이전트는 API를 찾아 기본 콘텐츠에 실행하고 결과를 검사합니다.

[기능 플러그인](https://github.com/dream-num/univer-workspace/blob/main/packages/dsh-univer-workspace-plugin/README.md)은 파일 탐색, Headless Facade 편집, 구조화된 검사, 가져오기·내보내기, Worktree 관리 도구를 연결합니다. 현재 미리 보기는 검토 가능한 초안을 준비하며, 게시는 배포한 앱의 검토·병합 절차를 사용합니다. 같은 Office 런타임에 업무 Skills, 템플릿, 도구를 추가할 수 있습니다.

미리보기 플러그인에는 9개의 Skills가 포함됩니다. 공통 Skill은 검색, ID, 납품 흐름을, 제품별 Skill은 API와 검증 방법을 설명합니다. Agent는 현재 작업에 필요한 지침을 읽습니다.

| Skill | 작업 지침 |
| --- | --- |
| `univer` | Space, 파일, 초안 수명주기와 납품 |
| `univer-sheet` | 수식, 스타일, 차트, 스프레드시트 검증 |
| `univer-doc` | 문서 구조, 문단, 표 |
| `univer-slide` | 슬라이드 작성과 시각적 레이아웃 검사 |
| `univer-base` | 필드, 레코드, 보기 |
| `univer-board` | 도형, 연결선, 캔버스 배치 |
| `univer-embed` | Office 제품 안에 다른 제품 임베드 |
| `univer-cross-unit-formula` | Unit 간 참조와 계산 |
| `univer-html-view` | Office 데이터에 바인딩한 HTML 페이지 작성과 검사 |

### Agent 실행 루프와 Office 기능을 나누어 조립 [#desktop-architecture]

Skills는 작업을 안내하고 도구는 Headless 런타임으로 구조화된 콘텐츠를 조작하며 네이티브 편집기는 사람을 위한 표시와 편집을 담당합니다. Workspace는 파일과 협업 문맥을 제공합니다. 따라서 Office 엔진을 다시 만들지 않고 모델, 업무 도구, 브랜드 UI를 바꿀 수 있습니다.
