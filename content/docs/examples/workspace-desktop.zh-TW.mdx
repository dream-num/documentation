**Univer Workspace Desktop** 將 Codex、Claude Code 等工具中熟悉的 Agent 工作方式帶到辦公情境：描述需求、引用資料，讓 Agent 操作文檔，在側邊查看結果，再審閱變更。它以 **[Univer Office SDK](/docs/overview)** 與現成的 Agent 執行環境建構，提供開發自有 Agent 辦公協作空間的完整應用參考。

## 把 Agent 工作方式帶進日常辦公 [#why-desktop]

辦公成果需要持續編輯、公式計算、團隊協作與變更審閱。Desktop 將這些環節放在同一工作環境，讓對話圍繞可編輯、可計算、可協作的內容展開。

- **連貫的上下文：** 隨時使用對話、檔案、工作區資料與本機引用。
- **原生成果：** 建立可持續編輯的試算表、文件、簡報、Relational Table（關聯式表格）與 Canvases（畫布）。
- **邊看邊改：** 在側邊預覽內容、檢查公式與版面，再透過對話要求具體修改。
- **審閱後交付：** 原生 Office 變更留在 Worktree，由人查看差異並確認合入共享空間。

## 桌面應用整合的能力

| 能力 | 使用體驗 |
| --- | --- |
| Agent 工作階段 | 保留對話與任務上下文，在本機設定模型服務商、模型及憑證。 |
| 檔案與資料引用 | 瀏覽有權限的空間，透過 @ 引用 Workspace 檔案、資料夾與本機資料。 |
| 原生 Office 預覽 | 在側邊開啟 Office 內容，切換成果與變更檢視。 |
| 審閱與交付 | 檢查 Worktree 新增、修改、刪除的文件，繼續調整，或合入、放棄草稿。 |
| 本機與線上空間 | 連接團隊部署的服務或本機執行的 Workspace。 |

## 在同一個桌面中使用五種原生內容 [#desktop-tour]

英文 Aurora 發布專案以虛構資料串聯營運模型、決策簡報、簡報投影片、任務清單與策略畫布。以下展示桌面應用內的原生 Office 編輯器；人類可以繼續編輯 Agent 讀取和修改的同一份內容。

截圖來自桌面整合預覽，Univer 品牌介面透過宿主擴充點接入。預覽由可擴充的 Agent 宿主與 Space 能力外掛組合；預覽外掛的交付狀態以專案發布內容為準。

截圖使用英文示範資料，並為展示隱藏了預覽浮水印。

### Sheets：可計算的業務模型 [#desktop-sheets]

將假設、公式、情境工作表與圖表保存在一起。Agent 透過 Facade API 檢查儲存格值與公式、執行計算並解釋結果。範例中的通路輸入驅動營收、利潤與訂單彙總。

![Sheets：可計算的業務模型](/assets/examples/workspace-desktop/sheets.jpg)

### Docs：從證據到決策 [#desktop-docs]

以標題、段落樣式、清單和表格保留決策依據。Aurora 文件將模型數字轉為行動優先順序與驗收條件；後續對話可以只修改特定段落，本文始終可以繼續編輯。

![Docs：從證據到決策](/assets/examples/workspace-desktop/docs.jpg)

### Slides：清楚呈現業務邏輯 [#desktop-slides]

以可編輯的文字、圖形與圖表構建多頁敘事。Aurora 從關鍵指標展開到通路策略、交付里程碑與待確認決策；人類可在同一應用中調整版面並播放簡報。

![Slides：清楚呈現業務邏輯](/assets/examples/workspace-desktop/slides.jpg)

### Relational Table：組織協作與交付 [#desktop-relational-table]

欄位型別、負責人、優先順序與狀態將計畫變成共享任務系統。範例提供看板、任務清單、時間軸與行事曆檢視。此產品在 SDK/API 中對應 `Base`。

![Relational Table：組織協作與交付](/assets/examples/workspace-desktop/relational-table.jpg)

### Canvases：連接策略與執行 [#desktop-canvases]

使用原生圖形、文字與連接線說明流程和系統。Aurora 將策略、證據與交付串聯，展示試算表、文件、簡報與任務之間的關係。SDK/API 中對應 `Board`。

![Canvases：連接策略與執行](/assets/examples/workspace-desktop/canvases.jpg)

## 安裝並連接工作區 [#quick-start]

已有可擴充 Agent 桌面時，也可以安裝並啟用 Space 能力外掛，從 Space 連接服務、設定模型，再接入品牌外觀。本頁截圖採用此組合。完整 Workspace Desktop 發行版與外掛預覽的交付路徑不同，請依所安裝版本的發布內容或儲存庫說明操作。

1. 從 [GitHub Releases](https://github.com/dream-num/univer-workspace/releases) 選擇 Desktop 安裝程式。桌面版本使用 agent-v 標籤，支援 Windows x64、macOS Apple Silicon 與 Linux x64。此交付方式仍為實驗性，版本與平台以實際發佈為準。

2. 在 **Settings → Workspace** 選擇服務位址，透過瀏覽器登入並授權。可連接既有服務，或依[本機執行說明](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#connect-to-a-local-workspace)準備本機服務。

3. 在 Models 設定支援的模型服務商、模型與憑證。Workspace 登入與模型存取分開設定，詳見[模型設定](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#model-credentials)。

4. 新增可存取的個人或團隊空間，建立對話並透過 @ 引用資料，再嘗試下方任務及變更審閱。

安裝程式包含 Agent 應用與 Office 工具；Workspace 服務另行在本機或伺服器執行，模型使用你設定的服務商。

## Skills 將需求連接到可執行的 Office 操作 [#skills]

Desktop 能力外掛內建 **univer** Skill 與參考資料，指引 Agent 定位空間和文件、使用 Office API、建立與檢查 Worktree。Agent 可查詢 API，在原生內容上執行並驗證結果。

[能力外掛](https://github.com/dream-num/univer-workspace/blob/main/packages/dsh-univer-workspace-plugin/README.md)整合文件探索與建立、Headless Facade 編輯、結構化檢查、匯入匯出及 Worktree 工具。合入與放棄請求經宿主審批。可在相同 Office 執行環境上加入產業 Skills、範本與業務工具。

### 依任務載入對應的操作指引

預覽外掛內建九個 Skills。通用 Skill 說明內容探索、身分與交付流程；各產品 Skill 提供 API 與驗證指引，Agent 依目前任務讀取需要的內容。

| Skill | 操作指引 |
| --- | --- |
| `univer` | 空間、檔案、草稿生命週期與交付 |
| `univer-sheet` | 公式、樣式、圖表與試算表驗證 |
| `univer-doc` | 文件結構、段落與表格 |
| `univer-slide` | 簡報製作與視覺版面檢查 |
| `univer-base` | 欄位、記錄與檢視 |
| `univer-board` | 圖形、連接線與畫布版面 |
| `univer-embed` | 在一個 Office 產品內嵌入另一個產品 |
| `univer-cross-unit-formula` | 跨 Unit 引用與計算 |
| `univer-html-view` | 構建及檢查綁定 Office 資料的 HTML 頁面 |

## 從辦公內容延伸到 Web App [#web-apps]

同一工作區可承載互動報告、業務頁面與預算看板。HTML View 將輸入控制項與圖表連接至試算表資料，讓 Office 模型成為 Web App 的資料和計算基礎。[雙向綁定](/docs/features/shared/binding)仍為實驗性能力，後續可能變更。

HTML 發佈與綁定寫回使用各自的儲存與授權流程；原生 Office 草稿透過 Worktree 審閱。

Project Summit 展示桌面中的這種組合：客製收購決策儀表板讀取包含 19 張工作表的共享模型。成長率、報價與現金比例關聯至來源儲存格，預測卡片和圖表展示影響；頁面還能引用審閱文件與簡報，讓業務應用和原生 Office 資料共處一個工作區。

## 復用這套結構，建構自有 Agent 辦公空間 [#build-your-own]

Workspace Desktop 展示如何組合現成模組成為完整產品。復用 Agent 宿主與 Workspace 應用，按需組裝 Office 能力，便可聚焦產業資料、業務工具、範本與交付流程。

### 將 Agent 執行循環與 Office 能力分開組裝 [#desktop-architecture]

Skills 提供任務指引，工具透過 Headless 執行環境操作結構化內容，原生編輯器負責供人類展示和編輯。Workspace 提供檔案與協同脈絡，因此可以更換模型、加入業務工具或替換品牌介面，而不必重新實作 Office 引擎。

<Mermaid chart={"flowchart LR\nA[\"Agent 與模型\"]\nB[\"Skills 與工具\"]\nC[\"Office SDK<br/>Headless 操作與驗證\"]\nD[\"Workspace 服務<br/>檔案、協同與版本\"]\nE[\"桌面預覽<br/>原生編輯器與 Web App\"]\nF[\"Worktree 與內容比較<br/>人類審閱\"]\nA --> B --> C --> D\nD <--> E\nD --> F\nF --> E"} />

| 組成部分 | 職責 |
| --- | --- |
| [Web SDK](/guides/sheets) | 統一內容模型、Office 編輯介面、渲染、公式與 Headless Facade 操作。 |
| [Server SDK](/server) | 協同、版本與 Worktree 等能力，整合應用後端。 |
| [AI SDK](/ai) | 面向 Agent 的內容操作、檢查與驗證。 |
| Agent 執行環境與 Skills | DSH 提供對話、模型呼叫、工具編排與審批；Workspace 外掛接入 Office 工具與指引。 |
| Workspace 與 Desktop | 應用提供空間、檔案、身分整合及審閱介面；Electron 將這些能力交付為桌面應用。 |

可復用的是完整鏈路：需求 → 工具 → 可編輯內容 → 預覽 → 審閱 → 共享交付。Office SDK 提供辦公能力層，Agent 宿主提供對話與執行循環。可擴充現有[應用與外掛](https://github.com/dream-num/univer-workspace/tree/main/apps/agent)，或接入自有宿主與服務。
