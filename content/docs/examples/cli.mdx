Univer CLI is a local Office automation application built with **[Univer Office SDK](/docs/overview)**. It gives your existing agent content commands and Skills for working with Excel, Word, and PowerPoint files, or creating spreadsheets, documents, presentations, relational tables, and canvases. Results stay on your machine.

[Install and try](#quick-start) · [How Skills work](#skills) · [Skills directory](#skills-catalog)

## Use the agent you already work with

You can use Univer CLI with these agents:

**OpenCode** · **Claude Code** · **OpenClaw** · **Hermes** · **Codex** · **WorkBuddy** · **Kimi Work**

The shared interface is the `univer` command and version-matched operational guidance. Hosts with Agent Skills support can load the official Skill; agents with command execution can also call it through their own tool layer. For host-specific experiences such as conversation preview cards, explore the [integration projects](https://univer.ai/ecosystem).

## See your first result [#quick-start]

Use Node.js 24 or newer and install in the environment used by your agent:

```bash
npm install --global univer-cli@latest
npx skills add dream-num/skills -s univer-cli -g
univer doctor
```

`univer doctor` checks the local runtime. The Skill helps the agent discover commands, load product-specific guidance, inspect content, and deliver results.

### Open the official sample

In a new empty directory, send this to your agent:

```text
Use Univer CLI to explore the official sample.
Download https://univer.ai/cli-assets/hello.univer to hello.univer in the current directory.
List its contents, give me the local Viewer link, and explain what I can try.
```

Opening existing content gives you an immediate look at the native editors. Next, ask the agent to revise it or try the creation task below.

## Skills: operational guidance for agents [#skills]

Skills organize the content model, editing workflow, Facade API discovery, and verification requirements into guidance an agent can read. They help it find the capabilities needed for a task, from editing through review and delivery.

**Discovery entry:** The [`univer-cli` Skill](https://github.com/dream-num/skills/blob/main/skills/univer-cli/SKILL.md) installed in your agent helps it recognize Office tasks, then load full guidance from the local CLI.

**Runtime Skills:** These ship with the CLI and match its installed commands and Facade APIs. Load `core` first, then the target product; add the relevant topic for embeds or cross-content formulas.

### Load guidance for the task [#load-skills]

The agent usually reads this guidance itself; developers can also inspect it directly:

```bash
univer skills list
univer skills get core
univer skills get sheet
univer skills path sheet
```

`list` shows installed Skills, `get` reads guidance, and `path` returns the local directory. Use `univer skills get core --full` to include references and templates. Look up specific APIs as needed with `univer api find` and `univer api show`.

### Skills directory [#skills-catalog]

Follow a name to browse its source guide. For actual tasks, use the version returned by your local `univer skills get <name>`.

| Skill | When to use it |
| --- | --- |
| [`core`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/core/SKILL.md) | Shared workflow: understand Units and Worktrees, locate content, edit, verify, and hand off for review. |
| [`sheet`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/sheet/SKILL.md) | Spreadsheets (Sheet): data, formulas, formatting, charts, and result verification. |
| [`doc`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/doc/SKILL.md) | Documents (Doc): paragraphs, rich text, tables, charts, and page layout. |
| [`slide`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/slide/SKILL.md) | Presentations (Slide): pages, shapes, text, images, and visual verification. |
| [`base`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/base/SKILL.md) | Relational Table: tables, fields, records, and views; called Base in the SDK/API. |
| [`board`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/board/SKILL.md) | Canvases: canvas elements, charts, and layout verification; called Board in the SDK/API. |
| [`embed`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/embed/SKILL.md) | Embeds: place content from one Unit inside another and connect chart data sources. |
| [`cross-unit-formula`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/cross-unit-formula/SKILL.md) | Cross-content formulas: read Sheet ranges or Base fields for calculations in Sheet cells or formula-driven shapes. |

For example, to embed a spreadsheet in a document, load `core → doc + sheet → embed`. Add `cross-unit-formula` when a Sheet cell or shape references data from other content. There is no need to load every guide upfront. After updating the CLI, reload `core` and the relevant product and topic Skills.

## What you can build

- **Turn data into deliverables:** Clean spreadsheets, write formulas, add charts and pivots, lay out reports with headers and footers, or build a presentation from an outline.
- **Keep content connected:** One `.univer` file can hold multiple content types linked through formulas, chart references, and embeds.
- **Verify the result:** Read the actual content model through Facade, then use screenshots and presentation layout checks to find overflowing, overlapping, or off-page text.
- **Review before delivery:** The agent works in an isolated Worktree and returns a local Viewer link. Inspect differences, request revisions, merge or discard, and export supported Office formats. Canvas file import and export are not currently available.

## Try a task like this

> Use Univer CLI to create a monthly expense sheet with date, category, amount, and five sample rows. Add a total formula and a chart summarized by category. Check the data and rendered result, give me the Viewer link, and do not merge before my review.

## How Office SDK powers it

Office SDK supplies the Headless content runtime, Facade API, calculation, rendering, versions, and Worktrees. The CLI assembles these into terminal commands and version-matched Skills, and owns local `.univer` storage, the Gateway, and the Viewer. Agent-authored content can move directly into editor previews and standard file delivery.
