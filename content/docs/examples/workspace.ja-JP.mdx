Univer Workspace は人とエージェントの共同作業に向けて **[Univer Office SDK](/docs/overview)** で構築したオープンソースの Office アプリです。**Server と Web** のオンライン版を配置し、**Workspace CLI + Skills** で既存のエージェントを接続できます。

[Workspace と Agent](#workspace-context) · [オンライン版](#entry-points) · [エージェントを接続](#cli-start) · [Desktop](/docs/examples/workspace-desktop) · [Skills](#skills)

## 共有ファイルを作業のコンテキストにする [#workspace-context]

![共有ファイルを作業のコンテキストにする](/assets/examples/workspace-desktop/workspace-overview.jpg)

Aurora Space には、数式を使う運用モデル、意思決定メモ、プレゼンテーション、タスク台帳、戦略キャンバスがあります。Web と Desktop は同じ共有ファイルに接続します。Agent は資料を読み、Worktree で変更を準備します。新しい文書は、レビュー担当者がマージするまで下書きに残ります。 同じ例の生成と修正は、[Desktop の対話とプレビュー](/docs/examples/workspace-desktop#conversation-preview)でも確認できます。

## Workspace CLI：任意のエージェントを接続 [#cli-start]

オンライン版の配置後、エージェントごとに Office 連携を開発する必要はありません。実行環境に CLI と Skill を入れると、コマンド実行可能なエージェントがファイル検索、編集、計算、撮影、検証、レビューリンクの受け渡しを行えます。モデルと会話は選択したエージェントが担います。

Node.js 22.12 以降、推奨は24です。npm パッケージ `univer-workspace-cli` は同じプログラムのコマンド名として `uvw` と `univer-workspace-cli` を提供します。

```bash
npm install --global univer-workspace-cli@latest
npx skills add dream-num/univer-workspace --skill univer-workspace-cli -g
uvw --version
```

既定の接続先はオンラインデモです。自分の環境にはサービス URL を設定します。

```bash
uvw config set workspace.origin https://space.univer.ai
```

初回は CLI の案内で一度ログインすると、CLI がセッションを管理し、以降のタスクで再利用できます。エージェント専用のログイン画面、OAuth コールバック、認証連携を実装する必要はありません。

<details>

<summary>初回接続：ブラウザで一度ログイン</summary>

有効なセッションがあれば省略できます。ログインが必要な場合は次を実行します。

```bash
uvw auth login
```

返された URL を開き、ブラウザでログインしてコードを確認します。ユーザーが完了を伝えてから次を実行します。

```bash
uvw auth login --complete
```

セッションを確立する場合の手順です。詳細は [Workspace CLI ガイド](https://github.com/dream-num/univer-workspace/blob/main/apps/cli/README.md)をご覧ください。

</details>

## Skills：作業環境の理解からタスクの完了まで [#skills]

既存のエージェントに入れる [`univer-workspace-cli` Skill](https://github.com/dream-num/univer-workspace/blob/main/skills/univer-workspace-cli/SKILL.md) は、接続、対象の特定、ガイドの読み込みを案内する入口です。完全なランタイム Skills は CLI に同梱され、コマンドと Facade API のバージョンに対応します。Desktop の内蔵プラグインもタスク向けガイドとツールを提供します。

| ガイド | 対象 |
| --- | --- |
| `core` | Space・ファイルの特定、タスク下書き、検証、レビューへの受け渡し。 |
| `sheet` · `doc` · `slide` · `base` · `board` | 表計算、文書、プレゼンテーション、Relational Table、Canvases。SDK/API 名は Base・Board のままです。 |
| `blob` | 元ファイルのアップロード、ダウンロード、置き換え。 |
| `html-view` | ライブ HTML ページを生成・管理し、対話型 Web App を作成。 |
| `embed` · `cross-unit-formula` | 別コンテンツの埋め込みとコンテンツ間のデータ・数式参照。 |

```bash
uvw skills list
uvw skills get core
uvw skills get sheet
uvw skills get html-view
```

まず `core`、次に対象製品やトピックを読み込みます。`skills get` に参考パスが表示され、`uvw skills read <name> <path>` で個別に、`--full` でまとめて読めます。既存エージェントは CLI、Desktop は会話に統合したツールとガイドを使います。

## Office 文書から Web App へ [#web-apps]

表計算、文書、プレゼンテーション、関係テーブル、キャンバスに加え、その内容を使う Web App も生成できます。経営ダッシュボード、対話型レポート、予算シミュレーター、業務画面などです。HTML View と双方向バインディングで指標、グラフ、入力、スライダーを表に接続し、画面操作とデータ変更を双方向に反映して共同編集にもつなげられます。

## 依頼・変更・レビューをつなぐ

Workspace CLI は `uvw issue` と `uvw pr` も提供します。Issue は依頼や議論、PR はレビュー対象の変更を扱い、PR の基盤は Worktree です。エージェントが依頼を読み、ネイティブ内容を編集・検査して人にレビューを渡すことで、チームの依頼と Office 成果物をつなげられます。

## 実際の下書きを確認してからマージを判断する [#agent-review]

Desktop のネイティブレビューでは、共有の元文書と提案された変更を並べて確認できます。同じ下書きを Workspace で開き、Ready 状態、変更ファイル一覧、ネイティブ文書ビューを確認することもできます。View と Compare で結果を確認してから、マージを判断します。Agent のタスク完了だけでは共有の元ファイルは変更されません。

## Office SDK が担う部分 [#sdk-integration]

Web SDK は共有モデル、エディター、描画、ヘッドレス処理、Server SDK は共同編集・バージョン・Worktree、AI SDK はエージェント向け操作・検証を提供します。Workspace が配置可能な Server とオンライン版に構成し、CLI が既存エージェントに公開、Desktop がエージェント Office アプリに統合します。
