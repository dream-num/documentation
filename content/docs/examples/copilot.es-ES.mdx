**Univer Office Copilot** es una aplicación web de referencia de código abierto construida con **[Univer Office SDK](/overview)**, LangChain, React y TypeScript. Coloca hojas de cálculo editables, documentos, diapositivas, tablas relacionales y lienzos junto a un asistente de conversación. La muestra de código funciona sin modificaciones y puede servir como punto de partida para su propio copiloto de Office.

[Ejecutar en local](#quick-start) · [Ejemplos editables](https://github.com/dream-num/univer-office-copilot#included-examples) · [Repositorio](https://github.com/dream-num/univer-office-copilot)

| Producto | Aplicaciones que puedes crear |
| --- | --- |

| Docs | Informes de investigación y memorandos en Modern Docs o Paged Docs. |

| Base | Registros vinculados, seguimiento operativo y paneles actualizados. |
| Board | Mapas de decisiones, flujos de trabajo y diagramas conectados. |

## Ejecutar la aplicación de referencia en local [#quick-start]

La aplicación de referencia requiere **Node.js 24+** y **pnpm 10.33.4**:

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

Abrir [http://127.0.0.1:5173](http://127.0.0.1:5173). Una nueva cuenta demo local comienza con seis ejemplos privados editables que cubren los cinco productos y ambos modos de documento. La navegación y la edición manual no requieren una clave modelo, Docker, o una base de datos externa.

Para utilizar Copilot, abra el menú modelo en el chat y seleccione **Añadir modelo** o **Modelos de gestión**. Establezca el proveedor, ID modelo y clave API. La aplicación admite OpenAI, Anthropic, Google Gemini, DeepSeek, OpenRouter y puntos finales HTTPS compatibles con OpenAI personalizados. Elija **Pregunta** para inspeccionar un archivo, o **Editar** para cambiar el archivo actual directamente.

La medición de texto AI y los cheques renderizados requieren Chrome, Chromium, o Edge instalado localmente. Configuración modelo, accesorios, importación y exportación, y configuración del navegador se describen en el [guía local para el desarrollo](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md).

## Cómo lo hace posible Office SDK [#sdk-integration]

El espacio de trabajo React mantiene a los editores y la interfaz de chat. El backend de Node ejecuta el bucle de herramientas de LangChain, Habilidades de producto y scripts de edición enmarcados contra un cliente headless Univer. Las ediciones confirmadas llegan al navegador sobre el mismo canal de colaboración que las personas usan, y la devolución nativa junto con los cheques renderizados proporcionan la retroalimentación de verificación.

Los Docs modernos usan Markdown, Paged Docs utilizan Typst y Slides utilizan SVG compilados en elementos editables. La aplicación también admite múltiples conversaciones por archivo, contexto de apego, inspección de cambio por turno, historia de archivos nativos, restauración controlada por el propietario, y compartir separadamente para archivos y conversaciones.

Construya en el [arquitectura](https://github.com/dream-num/univer-office-copilot/blob/main/docs/architecture.md) y [Guía de extensión](https://github.com/dream-num/univer-office-copilot/blob/main/docs/extending.md), o explore las capacidades [operaciones de](/ai/content-operations) , [colaboración](/overview/features/shared/collaboration) Y [historia](/overview/features/shared/history) que lo sustentan.
