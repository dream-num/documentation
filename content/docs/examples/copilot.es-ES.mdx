**Univer Office Copilot** es una aplicación web de referencia de código abierto creada con **[Univer Office SDK](/overview)**, LangChain, React y TypeScript. Sitúa hojas de cálculo, documentos, diapositivas, tablas relacionales y lienzos editables junto a un asistente conversacional. Usa este ejemplo ejecutable para crear tu propio Office Copilot.

[Ejecutar en local](#quick-start) · [Ejemplos editables](https://github.com/dream-num/univer-office-copilot#included-examples) · [Repositorio](https://github.com/dream-num/univer-office-copilot)

![Un libro financiero editable junto a la conversación Copilot y seis archivos de ejemplo en el espacio de trabajo](/assets/examples/office-copilot/overview.webp)

## Qué puedes crear

| Producto | Aplicaciones que puedes crear |
| --- | --- |
| Sheets | Modelos financieros, análisis de escenarios, fórmulas y gráficos. |
| Docs | Informes de investigación y memorandos en Modern Docs o Paged Docs. |
| Slides | Presentaciones editables para inversores y proyectos. |
| Base | Registros vinculados, seguimiento operativo y paneles actualizados. |
| Board | Mapas de decisiones, flujos de trabajo y diagramas conectados. |

## Ejecutar la aplicación de referencia en local [#quick-start]

Usa **Node.js 24+** y **pnpm 10.33.4**:

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

Abre **http://127.0.0.1:5173**. Cada nueva cuenta de demostración local recibe seis ejemplos privados y editables que cubren los cinco productos y ambos modos de documento. Explorar y editar manualmente no requiere clave de modelo, Docker ni base de datos externa.

Para usar Copilot, abre el menú de modelos del chat y elige **Add model** o **Manage models**. Configura el proveedor, el ID del modelo y tu clave API. La aplicación admite OpenAI, Anthropic, Google Gemini, DeepSeek, OpenRouter y endpoints HTTPS personalizados compatibles con OpenAI. Usa **Ask** para examinar un archivo o **Edit** para modificar directamente el archivo actual.

La medición de texto de IA y las comprobaciones del renderizado requieren Chrome, Chromium o Edge instalado localmente. La [guía de desarrollo local](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md) explica la configuración de modelos, adjuntos, importación/exportación y navegador.

## Cómo lo hace posible Office SDK [#sdk-integration]

El espacio React aporta los editores y el chat. El backend Node ejecuta el bucle de herramientas LangChain, los Skills de producto y scripts de edición acotados sobre un cliente Univer sin interfaz. Los cambios confirmados llegan al navegador por el mismo canal colaborativo que las ediciones humanas; la lectura nativa y las comprobaciones del renderizado aportan validación.

Modern Docs usa Markdown, Paged Docs usa Typst y Slides compila SVG en elementos editables. La aplicación incluye varias conversaciones por archivo, contexto de adjuntos, cambios por turno, historial nativo, restauración por el propietario y uso compartido independiente de archivos y conversaciones.

Parte de la [arquitectura](https://github.com/dream-num/univer-office-copilot/blob/main/docs/architecture.md) y la [guía de extensión](https://github.com/dream-num/univer-office-copilot/blob/main/docs/extending.md), o explora las [operaciones de contenido](/ai/content-operations), la [colaboración](/overview/features/shared/collaboration) y el [historial](/overview/features/shared/history).
