**Univer CLI** 是基于 **[Univer Office SDK](/overview)** 构建的本地 Office 自动化应用。它为你正在使用的 Agent 提供一组内容命令和 Skills，使该 Agent 能够处理已有的 Excel、Word 和 PowerPoint 文件，也能创建电子表格、文档、演示文稿、关系型表格和画布。处理结果保留在本机。

**CLI（Command-Line Interface，命令行界面）目前是操作 Univer 的主要方式**，取代了此前以 MCP 为主的 Agent 接入方式。Univer CLI 提供 `univer` 命令和 Skills：Agent 使用自己已有的命令执行工具编辑、检查并交付内容，预览和审阅则在本地 Viewer 中完成。

[安装与体验](#quick-start) · [Skills 工作方式](#skills) · [Skills 目录](#skills-catalog)

## 适配你正在使用的 Agent

Univer CLI 支持以下 Agent：

**OpenCode** · **Claude Code** · **OpenClaw** · **Hermes** · **Codex** · **WorkBuddy** · **Kimi Work**

这些 Agent 共用同一个接口：`univer` 命令，以及与所安装版本对应的操作指引。宿主支持 Agent Skills 时，可以加载官方 Skill；Agent 能够执行命令时，也可以通过自己的工具层调用 Univer。对话内预览卡片这类宿主专属体验，由对应的[集成项目](https://univer.ai/ecosystem)负责实现。

## 先看到第一个成果 [#quick-start]

使用前需要 Node.js 24 或更新版本。请安装在 Agent 运行的环境中：

```bash
npm install --global univer-cli@latest
npx skills add dream-num/skills -s univer-cli -g
univer doctor
```

`univer doctor` 检查本地的运行环境。借助 Skill，Agent 可以找到命令、加载具体产品的操作指引、检查内容并交付结果。

### 打开官方样例

新建一个空目录，把下面的指令发给 Agent：

```text
使用 Univer CLI 体验官方样例。
把 https://univer.ai/cli-assets/hello.univer 下载到当前目录的 hello.univer，
列出文件中的内容，然后给我本地 Viewer 链接，并介绍我可以体验哪些功能。
```

打开已有内容后，原生编辑器会立即显示。接下来可以让 Agent 修改这份内容，也可以尝试下面的新建任务。

## Skills：Agent 的操作指南 [#skills]

这些 Skills 让已有的 Agent 能够通过 Univer CLI 创建、编辑和检查 Office 内容。请先[安装 CLI 和发现入口 Skill](#quick-start)，再按任务加载下面的指引。

Skill 把产品的部分用法整理成 Agent 可以阅读的指引：内容模型、编辑流程、查找 Facade API 的方法，以及验证需要满足的条件。Agent 依据这些指引判断任务需要哪些能力，从首次编辑一直到审阅和交付。

**发现入口：** 安装到 Agent 中的 [`univer-cli` Skill](https://github.com/dream-num/skills/blob/main/skills/univer-cli/SKILL.md) 帮助它识别 Office 任务，再从本机 CLI 加载完整指引。

**运行时 Skills：** 随 CLI 一起发布，与所安装版本的命令和 Facade API 对应。先加载 `core`，再加载目标产品；任务涉及嵌入或跨内容公式时，再补上对应主题的 Skill。

### 按任务加载 [#load-skills]

这些指引通常由 Agent 自行读取，开发者也可以直接查看：

```bash
univer skills list
univer skills get core
univer skills get sheet
univer skills path sheet
```

`list` 列出已安装的 Skills，`get` 读取其中一个，`path` 返回它在本地的目录。`univer skills get core --full` 会一并给出参考资料和模板。如需查询具体 API，可使用 `univer api find` 和 `univer api show`。

### Skills 目录 [#skills-catalog]

点击名称可以浏览源码仓库中的指引。实际执行任务时，以本机 `univer skills get <name>` 返回的版本为准。

| Skill | 何时使用 |
| --- | --- |
| [`core`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/core/SKILL.md) | 通用流程：理解 Unit 与 Worktree，定位并编辑内容，验证后提交审阅。 |
| [`sheet`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/sheet/SKILL.md) | 电子表格（Sheet）：数据、公式、格式、图表与结果检查。 |
| [`doc`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/doc/SKILL.md) | 文档（Doc）：段落、富文本、表格、图表与页面布局。 |
| [`slide`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/slide/SKILL.md) | 演示文稿（Slide）：页面、形状、文本、图片与视觉检查。 |
| [`base`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/base/SKILL.md) | 关系型表格（Relational Table）：表、字段、记录与视图。 |
| [`board`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/board/SKILL.md) | 画布（Canvases）：画布元素、图表与布局检查。 |
| [`embed`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/embed/SKILL.md) | 嵌入内容：把一个 Unit 的内容放入另一个 Unit，并连接图表数据源。 |
| [`cross-unit-formula`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/cross-unit-formula/SKILL.md) | 跨内容公式：从 Sheet 区域或 Relational Table 字段读取数据，在 Sheet 单元格或公式驱动的形状中计算。 |

例如，要在文档中嵌入表格，加载顺序为 `core → doc + sheet → embed`；当 Sheet 单元格或形状引用其他内容的数据时，再加上 `cross-unit-formula`。不需要一开始加载全部指引。更新 CLI 后，请重新加载 `core` 以及你用到的产品和主题 Skills。

## 你可以用它做什么

- 把数据转化为交付物：清洗表格、编写公式、添加图表和透视表，为报告排版页眉页脚，或者按提纲制作一份演示文稿。
- 让内容彼此关联：一个 `.univer` 文件可以容纳多种内容，并通过公式、图表引用和嵌入将它们连接起来。
- 验证结果：通过 Facade 读回真实的内容模型，再用截图和演示稿布局检查，找出溢出、重叠或超出页面的文字。
- 审阅后再交付：Agent 在隔离的 Worktree 中工作，完成后返回本地 Viewer 链接。你可以查看差异、要求修改、合并或丢弃，并导出支持的 Office 格式。画布目前不支持文件导入导出。

## 试试这样一个任务

> 用 Univer CLI 创建一个月度开销表，包含日期、类别、金额和 5 条示例数据，加上总额公式和一张按类别汇总的图表。检查数据和渲染结果后把 Viewer 链接给我，我审阅之前不要合并。

## Office SDK 如何支撑

Office SDK 提供 Headless 内容运行时、Facade API，以及计算、渲染、版本和 Worktree 能力。CLI 将这些能力组织成终端命令和与版本配套的 Skills，并负责本地 `.univer` 存储、Gateway 和 Viewer。Agent 写入的内容可以直接进入编辑器预览，也能按标准格式交付文件。
