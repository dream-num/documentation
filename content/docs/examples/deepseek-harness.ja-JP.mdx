**DeepSeekハーネスのUniverオフィス**(`dsh-univer-office`)は、**[Univer Office SDK](/overview)**で構築されたDSHプラグインです。 これは、自然な言語でタスクの説明を受け入れ、エージェントは、現在の会話で視覚的な結果を維持しながら、スプレッドシート、文書、プレゼンテーション、リレーショナルテーブル、およびキャンバスを作成または変更することができます。

[インストールと接続](#quick-start) · [タスクを試す](#first-task) · [Skills とツール](#skills)

## インストールと接続 [#quick-start]

DeepSeekハーネス、設定されたモデル、およびNode.js 22.19またはnewerを用意します。 プラグインをインストールする前に、検証済みのDSHバージョンのリポジトリで[互換性の要件](https://github.com/dream-num/dsh-univer-office#requirements-and-current-limits)を確認してください。

### プラグインをインストール

DSH が実行されている場合は、起動した端末の Ctrl + C で停止し、プラグインを Web プロファイルにインストールします。

```bash
dsh plugin --profile web add dsh-univer-office
```

DSH を再起動します。

```bash
dsh web
```

DSHが起動したら、ブラウザでDSHページを更新し、エージェントがアクセスできるプロジェクトディレクトリに新しい会話を開始します。プラグインには、独自のランタイム、ツール、スキルが含まれているため、別のUniver CLIインストールは不要です。スクリーンショットとレイアウトチェックには、クローム、またはローカルマシンのエッジが必要です。

## すぐに試せるタスク [#first-task]

```text
独立した下書きで編集し、各ページのはみ出し、重なり、表示を検証して、この会話にライブプレビューとレビューカードを表示してください。私が承認するまでマージせず、PowerPoint は依頼した場合にのみ書き出してください。
```

### 確認できる結果

フローティングウィンドウは、エージェントが動作している間にデッキを表示し、レビューカードはその後の会話に残ります。結果は編集可能な3スライドプレゼンテーションです。 「スライド2をタイムラインに」などのリビジョンを要求し、ドラフトを承認または破棄することができます。

## Skills とツールの連携 [#skills]

プラグインは、[共有およびプロダクト スキル](https://github.com/dream-num/dsh-univer-office/tree/main/skills) をバンドルし、DSH は与えられたタスクが要求するサブセットをロードします。エージェントは、マッチングファサード API を `univer_api`、`univer_execute`を介してコンテンツを編集し、読み返し、スクリーンショット、および `univer_lint`の結果を確認します。 Office SDK は、計算、レンダリング、バージョン管理されたコンテンツを提供します。 DSH プラグインはプレビューと会話レビューカードをフローティングします。

## できること

- ビルドされていると結果が表示されます。 エージェントの編集中に、移動、再サイズ、折り畳み、最大化をサポートするライブプレビューウィンドウが開きます。
- 会話で確認します。各ファイルは、後から利用可能な独自のプレビューカードを持っています。コンテンツを見直し、ドラフトを承認するか、それを破棄することができます。
- 実際のOfficeコンテンツを提供します。既存のExcel、Word、PowerPointファイルと連携し、式、チャート、豊富なレイアウトを作成し、マッチングフォーマットをエクスポートします。
- エージェントは独自の作業を検査します。モデルの読み戻し、スクリーンショット、およびプレゼンテーションのレイアウトチェックを組み合わせます。複数のコンテンツタイプは、ファイルを共有し、式と埋め込みを介して接続することができます。

## Office SDK が担う部分 [#sdk-integration]

DSH は、会話、セッション、およびツールコールを所有しています。プラグインは、Office SDK のオーサリング、計算、レンダリング、および Worktree のワークフローをそれらの表面に接続します。エージェントは、実際のコンテンツモデル、SDK のパワープレビューとレビューを編集し、プラグインはウィンドウ、会話カード、セッション状態をフローティングします。この組み合わせは、Office の機能が既存のエージェント製品内で表示される方法を示しています。
