**Univer Office for DeepSeek Harness**（`dsh-univer-office`）は **[Univer Office SDK](/overview)** で構築された DSH プラグインです。自然言語で要望を伝えると、エージェントが表、文書、プレゼンテーション、リレーショナルテーブル、キャンバスを作成・修正し、結果を現在の対話に表示します。

[インストールと接続](#quick-start) · [タスクを試す](#first-task) · [Skills とツール](#skills)

## インストールと接続 [#quick-start]

DeepSeek Harness、設定済みモデル、Node.js 22.19 以降を用意します。インストール前に、リポジトリの[互換性要件](https://github.com/dream-num/dsh-univer-office#requirements-and-current-limits)で検証済み DSH バージョンを確認してください。

### プラグインをインストール

DSH が動作中の場合、起動したターミナルで Ctrl+C を押して終了してから、Web プロファイルにインストールします。

```bash
dsh plugin --profile web add dsh-univer-office
```

DSH を再起動します。

```bash
dsh web
```

起動後に DSH のブラウザページを更新し、アクセス可能なプロジェクトフォルダーで新しい会話を始めます。実行環境、ツール、Skills はプラグインに同梱されており、Univer CLI の別途インストールは不要です。スクリーンショットとレイアウト検証にはローカルの Chrome、Chromium、Edge が必要です。

## すぐに試せるタスク [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Univer Office で、新メンバー向けに Project Northstar を紹介する英語の3枚のスライドを作成してください。1枚目は表紙と一文の目標、2枚目は3つのサンプルマイルストーン、3枚目は3つの次の行動です。青と緑の統一配色、明確な見出し、編集可能なテキストを使ってください。
独立した下書きで編集し、各ページのはみ出し、重なり、表示を検証して、この会話にライブプレビューとレビューカードを表示してください。私が承認するまでマージせず、PowerPoint は依頼した場合にのみ書き出してください。
```

</div>

### 確認できる結果

作業中は浮動ウィンドウでスライドの変化を追え、完了後も会話にレビューカードが残ります。成果は編集可能な3枚のスライドです。「2枚目をタイムラインに変更して」などと修正を頼んだ後、承認または破棄を選べます。

## Skills とツールの連携 [#skills]

[共通・製品別 Skills](https://github.com/dream-num/dsh-univer-office/tree/main/skills) を DSH がタスクに応じて読み込みます。エージェントは `univer_api` で対応する Facade API を調べ、`univer_execute` で編集し、読み戻し、スクリーンショット、`univer_lint` で検証します。Office SDK が計算・描画・バージョンを担い、プラグインが浮動プレビューと会話内レビューカードを提供します。

## できること

- **作成過程を追う：** ライブプレビューは移動、サイズ変更、折りたたみ、最大化に対応します。
- **対話の中でレビュー：** ファイルごとのプレビューカードを後から開き直し、修正の継続、ドラフトの承認、破棄を行えます。
- **Office 成果物を受け渡す：** Excel・Word・PowerPoint を扱い、数式、グラフ、豊かなレイアウトを作成して対応形式に出力できます。
- **エージェント自身が検査：** モデルの読み戻し、スクリーンショット、レイアウト検査を組み合わせます。複数の内容を同じファイルに置き、数式や埋め込みでつなげられます。

## Office SDK が担う部分 [#sdk-integration]

DSH が対話、セッション、ツール呼び出しを担当し、プラグインが Office SDK の内容操作、計算、描画、Worktree を接続します。エージェントは実際のモデルを編集し、SDK がプレビューとレビューを支えます。プラグインはフローティングウィンドウ、対話カード、セッション状態を実装します。
