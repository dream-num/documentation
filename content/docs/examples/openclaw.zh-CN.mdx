**Univer Office for OpenClaw**（`openclaw-univer-office`）把基于 **[Univer Office SDK](/docs/overview)** 构建的 Workspace 能力接入 OpenClaw。Agent 可以查找个人和团队空间里的文件，在任务草稿中编辑与检查，再把审阅链接、预览图或导出文件交给用户。

[安装与接入](#quick-start) · [直接体验](#first-task) · [Skills 与工具](#skills)

## 安装与接入 [#quick-start]

准备 OpenClaw 2026.5.17 或更新版本、Node.js 22.22.3 或更新版本，以及可访问的 Univer Workspace 服务。在运行 OpenClaw Gateway 的机器上安装下面的依赖。此示例固定 Workspace CLI 0.5.3，与当前插件的命令接口配套。

### 1. 安装 CLI 与插件

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

插件使用 ClawHub 的 `@dr-univer/openclaw-univer-office`；不需要单独安装本地 `univer-cli`。

### 2. 启用工具并连接服务

在 OpenClaw 配置中合入以下设置，保留已有工具授权；若已有 `tools.allow`，把 `univer-office` 追加到原列表：

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

将 CLI 指向要使用的 Workspace。下面以在线体验服务为例；自部署时替换为自己的服务地址。配置完成后重启 Gateway。

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. 在对话中登录

向 OpenClaw 发送：

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
请连接 Univer Workspace，检查登录状态；若需要登录，请给我浏览器授权链接和验证码，等我完成后再继续。
```

</div>

在手机或电脑中打开返回的链接，登录并确认验证码，然后告诉 OpenClaw 已完成，并确认宿主的登录完成操作。插件不会通过反复轮询代替你的授权。在线服务仅供体验，请使用示例数据。

## 直接体验一个任务 [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
使用 Univer Office，在我的 Workspace 个人空间中创建一张 Project Northstar 英文周计划表，包含 5 项示例任务：Task、Owner、Estimated Hours、Status，并用公式汇总总工时。
在独立 Worktree 中编辑，读回数据并检查截图，标记为可审阅后，把同一个可在手机和电脑打开的审阅链接给我。不要合入，也不要发送给其他人，等我确认。
```

</div>

### 你会看到什么

聊天中收到结果说明和审阅链接，手机与电脑打开同一个 Workspace 草稿。原生编辑器和完整审阅界面位于 Workspace，聊天渠道可以交付进度、预览图和导出文件。标记就绪不会修改主版本。

### 继续体验

需要多人共同编辑时，再选择已有团队空间并明确要求团队可见草稿。OpenClaw 会请求相应批准；协作者须是该空间成员并登录，分享链接本身不会授予访问权限。

## Skills 与工具如何协作 [#skills]

插件自带 [`univer-office` Skill](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md)。Agent 使用 `univer_office_connect` 与 `univer_office_files` 定位空间，再通过内容工具的 `guidance` 加载通用和产品指引，查询 Facade 后编辑并检查。Workspace 承载 Office SDK 的内容、权限、协同和 Worktree；OpenClaw 负责聊天渠道、工具审批与文件交付。

## 你可以用它做什么

- **从聊天进入团队资料：** 查找并浏览有权访问的空间与文件，继续处理已有电子表格、文档、演示文稿、关系型表格和画布。
- **把任务变成协作草稿：** 在隔离 Worktree 中修改；需要团队共同审阅时，可以创建对空间成员可见的草稿。
- **检查后跨设备交付：** 验证内容结构、截图和布局，再返回可在手机或电脑浏览器打开的 Workspace 审阅链接。
- **保留人的决策入口：** 标记就绪后仍由人决定是否合并或丢弃；预览图和导出文件通过 OpenClaw 的消息与文件渠道交付。

## Office SDK 如何支撑 [#sdk-integration]

插件通过 Workspace CLI 调用 Office 内容操作和检查能力，Workspace 服务承载 Office SDK 的内容、协同、版本与 Worktree，并处理身份和权限。OpenClaw 负责对话、渠道和工具审批；完整编辑器与审阅界面位于 Workspace。Agent 终端可以在本地运行，团队通过同一个服务协作。
