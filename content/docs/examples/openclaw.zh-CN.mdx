**Univer Office for OpenClaw**（`openclaw-univer-office`）将基于 **[Univer Office SDK](/overview)** 构建的 Workspace 能力接入 OpenClaw。Agent 可以查找个人空间和团队空间中的文件，在任务草稿中编辑和检查，最后返回审阅链接、预览图或导出文件。

[安装与接入](#quick-start) · [直接体验](#first-task) · [Skills 与工具](#skills)

## 安装与接入 [#quick-start]

需要 OpenClaw 2026.5.17 或更新版本、Node.js 22.22.3 或更新版本，以及可访问的 Univer Workspace 服务。以下命令均在运行 OpenClaw Gateway 的主机上执行。本示例将 Workspace CLI 固定在 0.5.3，以匹配当前插件的命令接口。

### 1. 安装 CLI 与插件

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

插件由 ClawHub 以 `@dr-univer/openclaw-univer-office` 的形式分发，本地不需要单独安装 `univer-cli`。

### 2. 启用工具并连接服务

将以下配置合并到 OpenClaw 配置文件中，并保留已有的工具权限。如果已有 `tools.allow`，请将 `univer-office` 追加到该列表：

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

将 CLI 指向 Workspace 服务。下面的示例使用在线体验环境，自部署时需替换为实际地址。修改配置后重启 Gateway。

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. 在对话中登录

将以下消息发送给 OpenClaw：

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
请连接 Univer Workspace，检查登录状态；若需要登录，请给我浏览器授权链接和验证码，等我完成后再继续。
```

</div>

在手机或电脑上打开返回的链接，登录并确认验证码，然后告知 OpenClaw 登录已完成，并批准其登录完成操作。插件不会以轮询代替该确认，确认必须由你完成。在线体验环境请使用示例数据。

## 直接体验一个任务 [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
使用 Univer Office，在我的 Workspace 个人空间中创建一张 Project Northstar 英文周计划表，包含 5 项示例任务：Task、Owner、Estimated Hours、Status，并用公式汇总总工时。
在独立 Worktree 中编辑，读回数据并检查截图，标记为可审阅后，把同一个可在手机和电脑打开的审阅链接给我。不要合入，也不要发送给其他人，等我确认。
```

</div>

### 你会看到什么

聊天中会返回结果说明和审阅链接，手机和电脑打开的是同一个 Workspace 草稿。原生编辑器和完整审阅界面保留在 Workspace 中，聊天渠道负责传递进度、预览图和导出文件。将草稿标记为就绪不会改动当前文件。

### 继续体验

如需多人实时协作，请选择一个已有的团队空间，并明确要求创建对该空间可见的草稿。OpenClaw 会申请所需的批准。协作者必须是该空间中已登录的成员；仅有分享链接不会获得访问权限。

## Skills 与工具如何协作 [#skills]

插件内置一个 [`univer-office` Skill](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md)。Agent 使用 `univer_office_connect` 和 `univer_office_files` 定位空间，通过内容工具的 `guidance` 操作加载核心指引和产品指引，然后查询 Facade API、编辑并验证。Workspace 承载 Office SDK 的内容、权限、协同和 Worktree，OpenClaw 负责聊天渠道、工具审批和文件交付。

## 你可以用它做什么

- 从聊天中访问团队内容：查找并浏览你有权限的空间和文件，然后处理已有的电子表格、文档、演示文稿、关系型表格和画布。
- 协作处理任务：在隔离的 Worktree 中编辑，需要团队共同审阅时创建对该空间可见的草稿。
- 跨设备检查与交付：检查结构、截图和布局，然后返回可在手机或电脑浏览器中打开的 Workspace 审阅链接。
- 由人保留决策权：标记为就绪的结果仍需要由人选择合并或丢弃。预览图和导出文件通过 OpenClaw 的消息与文件渠道交付。

## Office SDK 如何支撑 [#sdk-integration]

插件通过 Workspace CLI 调用内容操作和检查能力。Workspace Server 承载 Office SDK 的内容、协同、版本和 Worktree，并负责身份与权限校验。OpenClaw 负责对话、渠道和工具审批；完整的编辑和审阅仍在 Workspace 中完成。Agent 终端可以在本地运行，团队通过同一个服务协作。
