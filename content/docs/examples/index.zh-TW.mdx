這些開源專案把 **[Univer Office SDK](/docs/overview)** 變成可以直接使用的應用：在本機交給 Agent 自動處理 Office 檔案，在團隊空間共同編輯，或從已有的 Agent 對話中建立、預覽和審閱成果。

Workspace 與 CLI 是完整應用；DeepSeek Harness、WorkBuddy 與 OpenClaw 三項是接入對應 Agent 宿主的 Office 整合外掛。

## Workspace [#univer-workspace]

<span id="univer-workspace-desktop" />

以 Office SDK 建構的開源辦公空間。先使用雲端試用或私有部署，再以 Workspace CLI 接入既有 Agent，也能在 Desktop 完成對話、預覽與協作審閱。

[查看專案說明](/docs/examples/workspace) · [在線體驗](https://space.univer.ai) · [原始碼儲存庫](https://github.com/dream-num/univer-workspace) · [Desktop 體驗](/docs/examples/workspace#desktop-start)

## Office Lab [#office-lab]

類似 GitHub 的辦公協作案例：以需求、Issue、Worktree PR、內容比較、互動原型與排程推進同一專案。

[查看協作案例](/docs/examples/office-lab) · [原始碼儲存庫](https://github.com/dream-num/univer-workspace)

## CLI [#univer-cli]

給 OpenCode、Claude Code、OpenClaw、Hermes、Codex、WorkBuddy、Kimi Work 等 Agent 接入本機 Office 能力。安裝 CLI 和 Skill 後，先打開官方樣例，再讓 Agent 建立與檢查自己的成果。

[查看專案說明](/docs/examples/cli) · [快速體驗指南](https://github.com/dream-num/univer-cli#quick-start) · [原始碼儲存庫](https://github.com/dream-num/univer-cli)

## DeepSeek Harness 外掛 [#deepseek-harness]

適合觀察對話式 Office 的完整體驗：一句話發起任務，實時視窗跟隨產生過程，最後在同一對話中審閱、修改和交付。

[查看專案說明](/docs/examples/deepseek-harness) · [觀看示範](https://www.youtube.com/watch?v=k-2zW_CMiew) · [原始碼儲存庫](https://github.com/dream-num/dsh-univer-office)

## WorkBuddy 外掛 [#workbuddy]

適合參考 MCP 與 Agent 宿主集成：本機 Office 內容、宿主內唯讀預覽和瀏覽器版本審閱組成一條工作流程。目前為開發預覽。

[查看專案說明](/docs/examples/workbuddy) · [查看工作流程程](https://github.com/dream-num/workbuddy-univer-office#workflow) · [原始碼儲存庫](https://github.com/dream-num/workbuddy-univer-office)

## OpenClaw 外掛 [#openclaw]

適合已有的 OpenClaw 工作流程：從聊天發起團隊檔案任務，經 Workspace 草稿與檢查後，把可跨手機和電腦審閱的結果交付回來。

[查看專案說明](/docs/examples/openclaw) · [查看工作流程程](https://github.com/dream-num/openclaw-univer-office#typical-request) · [原始碼儲存庫](https://github.com/dream-num/openclaw-univer-office)
