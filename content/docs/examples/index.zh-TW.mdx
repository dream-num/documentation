下列開源專案都是基於 **[Univer Office SDK](/overview)** 建置的應用與整合：它們可以用 Agent 自動處理本地 Office 檔案，在團隊空間中協同編輯，或在已有的 Agent 對話中建立、預覽和審閱成果。

Workspace 和 CLI 是完整應用。Office Copilot 是一個可執行的參考應用，用於建置應用內辦公助手。DeepSeek Harness、WorkBuddy 和 OpenClaw 是接入對應 Agent 宿主的 Office 整合外掛。

## Workspace [#univer-workspace]

<span id="univer-workspace-desktop" />

該專案是一個使用 Office SDK 建置的開源辦公空間。你可以使用雲端服務，也可以私有部署。已有 Agent 透過 Workspace CLI 接入；如需對話、即時預覽和協作審閱，可使用 Desktop。

[查看專案說明](/overview/examples/workspace) · [在線體驗](https://space.univer.ai) · [原始碼儲存庫](https://github.com/dream-num/univer-workspace) · [Desktop 體驗](/overview/examples/workspace#desktop-start)

## Office Lab [#office-lab]

Office Lab 是一個類似 GitHub 的辦公協作案例。產品與研發透過需求文件、Issue、Worktree PR、原生內容比較、可互動原型和排期，共同推進同一個專案。

[查看協作案例](/overview/examples/office-lab) · [原始碼儲存庫](https://github.com/dream-num/univer-workspace)

## Office Copilot [#office-copilot]

Office Copilot 是一個編輯器與聊天並排的開源 Web 應用，可作為建置自有 Office Copilot 的起點。它提供六個可編輯範例；接入模型後，可針對五類產品調整直接編輯、協作、歷史和分享。

[查看專案說明](/overview/examples/copilot) · [快速開始](https://github.com/dream-num/univer-office-copilot#quick-start) · [原始碼儲存庫](https://github.com/dream-num/univer-office-copilot)

## CLI [#univer-cli]

CLI 為 OpenCode、Claude Code、OpenClaw、Hermes、Codex、WorkBuddy、Kimi Work 等 Agent 提供本地 Office 能力。安裝 CLI 和 Skill 並開啟官方樣例後，即可建立自己的結果並檢查。

[查看專案說明](/overview/examples/cli) · [快速體驗指南](https://github.com/dream-num/univer-cli#quick-start) · [原始碼儲存庫](https://github.com/dream-num/univer-cli)

## DeepSeek Harness 外掛 [#deepseek-harness]

該外掛提供對話式 Office 體驗。你說明要完成的任務，即時視窗展示工作過程，最後可以在同一個對話中審閱、修改並交付結果。

[查看專案說明](/overview/examples/deepseek-harness) · [觀看示範](https://www.youtube.com/watch?v=k-2zW_CMiew) · [原始碼儲存庫](https://github.com/dream-num/dsh-univer-office)

## WorkBuddy 外掛 [#workbuddy]

該外掛涵蓋 MCP 與 Agent 宿主整合，將本地 Office 檔案、宿主內的只讀預覽和瀏覽器中的版本審閱串聯為一條工作流。目前該外掛為開發預覽。

[查看專案說明](/overview/examples/workbuddy) · [查看工作流程程](https://github.com/dream-num/workbuddy-univer-office#workflow) · [原始碼儲存庫](https://github.com/dream-num/workbuddy-univer-office)

## OpenClaw 外掛 [#openclaw]

該外掛可接入已有的 OpenClaw 工作流。你從聊天中發起團隊檔案任務，在 Workspace 草稿上編輯和檢查，最後返回一個可在手機和電腦上審閱的結果。

[查看專案說明](/overview/examples/openclaw) · [查看工作流程程](https://github.com/dream-num/openclaw-univer-office#typical-request) · [原始碼儲存庫](https://github.com/dream-num/openclaw-univer-office)
