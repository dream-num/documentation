**Univer Office for OpenClaw**(`openclaw-univer-office`)는 **[Univer Office SDK](/docs/overview)**로 만든 Workspace 기능을 OpenClaw에 연결합니다. 에이전트는 개인·팀 파일을 찾고 작업 초안을 편집·검사한 뒤 검토 링크, 미리 보기 이미지나 내보낸 파일을 반환합니다.

[설치 및 연결](#quick-start) · [작업 체험](#first-task) · [Skills와 도구](#skills)

## 설치 및 연결 [#quick-start]

OpenClaw 2026.5.17 이상, Node.js 22.22.3 이상, 접근 가능한 Univer Workspace를 준비하세요. 아래 패키지는 Gateway 호스트에 설치합니다. 이 예제는 현재 플러그인의 명령 인터페이스에 맞춰 Workspace CLI 0.5.3을 고정합니다.

### 1. CLI와 플러그인 설치

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

ClawHub의 `@dr-univer/openclaw-univer-office`를 사용합니다. 별도의 로컬 `univer-cli` 설치는 필요 없습니다.

### 2. 도구 활성화 및 서비스 연결

기존 도구 권한을 유지하면서 아래 설정을 OpenClaw에 병합하세요. `tools.allow` 목록이 이미 있으면 `univer-office`를 추가합니다.

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

CLI를 사용할 Workspace 서비스에 연결합니다. 아래는 온라인 데모 예제이며 자체 호스팅이면 주소를 바꾸세요. 설정 후 Gateway를 다시 시작합니다.

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. 대화에서 로그인

OpenClaw에 다음을 보내세요.

휴대폰이나 컴퓨터로 링크를 열고 로그인한 뒤 코드를 확인하세요. OpenClaw에 완료했다고 알리고 로그인 완료 동작을 승인합니다. 플러그인은 반복 조회로 승인을 대신하지 않습니다. 온라인 데모에는 예시 데이터를 사용하세요.


</div>

### 확인할 수 있는 결과

채팅에 결과 설명과 검토 링크가 표시됩니다. 휴대폰과 컴퓨터 브라우저는 같은 Workspace 초안을 엽니다. 기본 편집기와 전체 검토 화면은 Workspace에 있고 채팅은 진행 상황, 미리 보기 이미지, 내보낸 파일을 전달할 수 있습니다. 준비 완료 표시는 현재 파일을 변경하지 않습니다.

### 계속 체험하기

실시간 팀 작업이 필요하면 기존 Team Space를 선택하고 팀원에게 보이는 초안을 명시적으로 요청하세요. OpenClaw가 필요한 승인을 요청합니다. 협업자는 로그인한 공간 구성원이어야 하며 링크 자체는 접근 권한을 부여하지 않습니다.

## Skills와 도구의 연동 [#skills]

플러그인에 [`univer-office` Skill](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md)이 포함됩니다. 에이전트는 `univer_office_connect`와 `univer_office_files`로 공간을 찾고 콘텐츠 도구의 `guidance`로 공통 및 제품 가이드를 읽은 뒤 Facade를 조회하고 편집·검증합니다. Workspace가 Office SDK 콘텐츠, 권한, 협업, Worktree를 호스팅하고 OpenClaw는 채팅 채널, 승인, 파일 전달을 담당합니다.

## 무엇을 만들 수 있나요

- **채팅에서 팀 자료에 접근:** 권한이 있는 공간과 파일을 찾고 기존 표, 문서, 프레젠테이션, 관계형 테이블, 캔버스를 처리합니다.
- **협업 초안으로 작업:** 격리된 Worktree에서 편집하며 팀 검토가 필요하면 공간 구성원에게 공개된 초안을 만듭니다.
- **여러 기기에서 검토:** 구조, 스크린샷과 레이아웃을 검사한 뒤 휴대폰·데스크톱 브라우저에서 열리는 Workspace 링크를 반환합니다.
- **사람이 최종 결정:** 준비 완료 후에도 사람이 병합·폐기를 선택합니다. 이미지와 내보낸 파일은 OpenClaw의 메시지·파일 채널로 전달합니다.

## Office SDK가 담당하는 부분 [#sdk-integration]

플러그인은 Workspace CLI를 통해 콘텐츠 조작과 검사를 호출합니다. Workspace Server는 Office SDK 콘텐츠, 협업, 버전, Worktree와 사용자·권한을 관리합니다. OpenClaw는 대화, 채널, 도구 승인을 담당하고 전체 편집·검토 화면은 Workspace에 있습니다. 로컬 에이전트와 팀이 같은 서비스로 협업할 수 있습니다.
