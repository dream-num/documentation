**OpenClaw를 위한 Univer 사무실** (`openclaw-univer-office`)는 **[Univer Office SDK](/overview)**로 건설된 Workspace 특징에 OpenClaw를 연결합니다. 대리인은 개인과 팀 공간에 있는 파일을 찾아내고, 편집하고 검사합니다 일 초안을, 검토 연결, 시사 이미지, 또는 수출한 파일을 돌려보낼 수 있습니다.

[설치 및 연결](#quick-start) · [작업 체험](#first-task) · [Skills와 도구](#skills)

## 설치 및 연결 [#quick-start]

OpenClaw 2026.5.17 또는 newer, Node.js 22.22.3 또는 newer가 필요하며 Univer Workspace 서비스에 액세스합니다. OpenClaw Gateway 호스트의 다음 명령을 실행하십시오. 이 예제는 현재 플러그인의 명령 인터페이스와 일치하기 위해 Workspace CLI 0.5.3을 핀으로 꼿습니다.

### 1. CLI와 플러그인 설치

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

플러그인은 `@dr-univer/openclaw-univer-office`로 ClawHub에 게시됩니다. 별도의 로컬 `univer-cli` 설치가 필요하지 않습니다.

### 2. 도구 활성화 및 서비스 연결

OpenClaw 설정에 다음 설정을 추가하고 기존 도구 권한을 유지하십시오. `tools.allow`가 이미 존재하면 `univer-office`를 해당 목록에 추가하십시오.

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

Workspace 서비스에서 CLI를 포인트합니다. 아래 예제는 온라인 데모를 사용하므로 자체 호스팅 배포는 다른 주소를 요구합니다. 설정 변경 후 게이트웨이를 다시 시작하십시오.

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. 대화에서 로그인

OpenClaw에 다음 메시지 보내기:

전화 또는 컴퓨터에서 반품 된 링크를 열고 로그인하고 코드를 확인합니다. 그런 다음 Sign-in이 완료되고 서명 인 완료 작업을 승인하는 OpenClaw를 알려줍니다. 플러그인은 그 승인의 장소에 오염되지 않습니다. 온라인 데모에서 샘플 데이터를 사용하십시오.


### 확인할 수 있는 결과

채팅은 결과 및 리뷰 링크 요약을 반환합니다. 링크는 전화 브라우저 및 데스크톱에서 동일한 작업 공간 초안을 엽니 다. 기본 편집기와 전체 리뷰 인터페이스는 작업 공간에 남아 있으며 채팅 채널이 진행, 미리보기 이미지 및 수출 된 파일을 제공합니다. 초안 준비를 표시하면 현재 파일이 변경되지 않습니다.

### 계속 체험하기

라이브 팀웍을 위해 기존 팀 스페이스를 선택하고 스페이스에 가해지는 초안을 명시적으로 요청하십시오. OpenClaw는이 요구 사항을 충족하는 승인을 요청합니다. Collaborators는 해당 스페이스의 회원을 서명해야합니다. 공유 링크는 혼자 액세스 권한을 부여하지 않습니다.

## Skills와 도구의 연동 [#skills]

플러그인은 [`univer-office` 기술](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md)를 묶습니다. 이 에이전트는 `univer_office_connect` 및 `univer_office_files`와 스페이스를 배치하고, 콘텐츠 도구의 `guidance` 액션을 통해 코어 및 제품 가이드를 읽고, Facade API를 볼 수 있으며, 편집하고 결과를 검증합니다. Workspace는 Office SDK 콘텐츠, 권한, 협업 및 워크 트리를 호스팅합니다. OpenClaw는 채팅 채널, 도구 승인, 파일 및 파일 전송을 관리합니다.

## 무엇을 만들 수 있나요

- 채팅에서 액세스 팀 내용 : 당신이 허가 된 공간과 파일을 찾아, 다음 기존 스프레드 시트, 문서, 프리젠 테이션, 관계 테이블, 캔버스에 작업을.
- 작업에 대한 협업 : 격리 된 Worktree에서 편집하고 팀메이트가 함께 검토해야 할 때 스페이스에 표시 된 초안을 만듭니다.
- Inspect and deliver throughout devices: 구조, 스크린 샷, 및 레이아웃을 확인, 다음 전화 또는 데스크탑 브라우저에서 열 작업 공간 검토 링크를 반환.
- 사람들이 결정을 유지하십시오. 결과 표시된 준비는 여전히 병합 또는 디스패드를 선택하는 사람이 필요합니다. 미리보기 이미지 및 내보내기 파일은 OpenClaw의 메시지 및 파일 채널을 통해 전달됩니다.

## Office SDK가 담당하는 부분 [#sdk-integration]

Workspace CLI를 통한 플러그인 호출 권한 및 검사. Workspace Server는 Office SDK 콘텐츠, 협업, 버전 및 Worktrees를 호스팅하며 정체성과 권한을 부여합니다. OpenClaw는 대화, 채널 및 도구 승인 관리합니다. 전체 편집 및 검토는 Workspace에 남아 있습니다. 에이전트 터미널은 로컬로 실행할 수 있으며, 팀은 하나의 서비스를 통해 협력합니다.
