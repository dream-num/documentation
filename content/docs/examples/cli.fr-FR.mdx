**CLI Univer** est une application bureautique locale construite sur le **[Univer Office SDK](/overview)**. Elle ajoute des commandes de contenu et des compétences à l'agent que vous utilisez déjà. Avec ces ajouts, l'agent peut travailler avec les fichiers Excel, Word et PowerPoint existants et peut créer des tableurs, des documents, des présentations, des tables relationnelles et des toiles. Les résultats restent sur votre machine.

**CLI (Command-Line Interface) est actuellement la principale façon d'exploiter Univer.** Il remplace l'ancienne approche MCP-first pour l'intégration des agents. Univer CLI fournit la commande et les compétences `univer`. Les agents utilisent leurs propres outils d'exécution de commandes pour éditer, inspecter et livrer le contenu, et l'aperçu et la révision ont lieu dans le Viewer local.

## Utiliser votre agent habituel

Univer CLI prend en charge les agents suivants:

**OpenCode** · **Claude Code** · **OpenClaw** · **Hermes** · **Codex** · **WorkBuddy** · **Kimi Work**

Ces agents partagent une interface unique : `univer` un host avec le support Agent Skills peut charger la compétence officielle, et un agent qui peut exécuter des commandes peut aussi appeler Univer à travers sa propre couche d'outil. Les fonctionnalités spécifiques à l'hôte telles que les cartes de prévisualisation de conversation sont couvertes par le [projets d'intégration](https://univer.ai/ecosystem).

## Voir votre premier résultat [#quick-start]

Univer CLI nécessite Node.js 24 ou plus récent. Installez-le dans l'environnement où votre agent fonctionne :

```bash
npm install --global univer-cli@latest
npx skills add dream-num/univer-cli -g
univer doctor
```

`univer doctor` vérifie l'exécution locale. Grâce à la compétence, l'agent découvre les commandes, charge les conseils pour un produit spécifique, inspecte le contenu et produit des résultats.

### Ouvrir l’exemple officiel

Dans un nouveau répertoire vide, envoyez les instructions suivantes à l'agent :

```text
Explore l’exemple officiel avec Univer CLI.
Télécharge https://univer.ai/cli-assets/hello.univer sous hello.univer dans le dossier actuel.
Liste son contenu, donne-moi le lien Viewer local et explique ce que je peux essayer.
```

Ouverture du contenu existant affiche immédiatement les éditeurs natifs. Vous pouvez ensuite demander à l'agent de réviser ce contenu, ou essayer la tâche de création ci-dessous.

## Skills : des guides de travail pour les agents [#skills]

Ces compétences permettent à un agent existant de créer, modifier et vérifier le contenu Office via Univer CLI. D'abord [installer le CLI et sa découverte Compétence](#quick-start), puis charger les instructions spécifiques aux tâches décrites ci-dessous.

Une compétence présente une partie du produit comme guide qu'un agent peut lire : le modèle de contenu, le flux de travail d'édition, comment trouver les API Facade, et les exigences de vérification. Sur cette base, l'agent détermine quelles capacités une tâche a besoin, de la première édition à l'examen et à la livraison.

**Entrée découverte :** Le [Compétence `univer-cli`](https://github.com/dream-num/univer-cli/blob/main/skills/univer-cli/SKILL.md) installé dans l'agent l'aide à reconnaître les tâches Office, puis charger le guide complet depuis le CLI local.

**Compétences en matière de temps de course :** Ces données sont envoyées avec le CLI et correspondent à ses commandes installées et aux API Facade. Chargez d'abord `core`, puis le produit cible. Ajoutez le sujet Skill lorsque la tâche implique des formules d'intégration ou de contenu croisé.

### Charger les guides selon la tâche [#load-skills]

Dans la plupart des cas, l'agent lit ce guide seul. Les développeurs peuvent également l'inspecter directement:

```bash
univer skills list
univer skills get core
univer skills get sheet
univer skills path sheet
```

`list` montre les Skills installés, `get` lit guidance, et `path` retourne le répertoire local. `univer skills get core --full` comprend des références et des modèles. Utilisez `univer api find` et `univer api show` pour rechercher des API spécifiques.

### Répertoire des Skills [#skills-catalog]

Suivez un nom pour parcourir le guide dans son dépôt source. Pour les tâches réelles, utilisez la version retournée par la commande locale `univer skills get <name>`.

| Skill | Quand l’utiliser |
| --- | --- |
| [`core`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/core/SKILL.md) | Travail partagé : comprendre les unités et les worktrees, localiser et modifier le contenu, le vérifier et le soumettre pour examen. |
| [`sheet`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/sheet/SKILL.md) | Feuilles de calcul (Sheet) : données, formules, mise en forme, graphiques et vérification des résultats. |
| [`doc`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/doc/SKILL.md) | Documents (Doc) : paragraphes, texte enrichi, tableaux, graphiques et mise en page. |
| [`slide`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/slide/SKILL.md) | Présentations (Slide): pages, formes, texte, images et contrôles visuels. |
| [`base`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/base/SKILL.md) | Relational Table : tables, champs, enregistrements et vues. |
| [`board`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/board/SKILL.md) | Toiles: éléments de toile, graphiques, et vérification de la mise en page. |
| [`embed`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/embed/SKILL.md) | Embeds : placez le contenu d'une unité dans une autre, et connectez les sources de données du graphique. |

Par exemple, pour intégrer un tableur dans un document, chargez `core → doc + sheet → embed`. Ajoutez `cross-unit-formula` lorsqu'une cellule de feuille ou une référence de forme à partir d'autres contenus. Chargez chaque guide à l'avance est inutile. Après la mise à jour de la CLI, rechargez `core` et le produit et le sujet Compétences que vous utilisez.

## Ce que vous pouvez créer

- Transformez les données en un produit livrable : nettoyez la feuille, écrivez des formules, ajoutez des diagrammes et des tables de pivot, dressez un rapport avec les en-têtes et les pied de page, ou créez une présentation à partir d'un schéma.
- Garder le contenu connecté : un fichier `.univer` peut contenir plusieurs types de contenu liés par des formules, des références graphiques et des intégrations.
- Vérifiez le résultat : lisez le modèle de contenu réel à travers Facade, puis utilisez des captures d'écran et des vérifications de mise en page de présentation pour trouver le texte qui déborde, se chevauche ou s'enfuit.
- Examen avant livraison : l'agent fonctionne dans un Worktree isolé et retourne un lien local Viewer. Inspectez les différences, demandez des révisions, fusionnez ou jetez le résultat, et exportez les formats Office supportés. L'importation et l'exportation de fichiers Canvas ne sont pas encore disponibles.

## Essayez une tâche comme celle-ci

> Utilisez Univer CLI pour créer une feuille de dépenses mensuelle avec la date, la catégorie et le montant, et cinq lignes d'échantillon. Ajoutez une formule totale et un graphique résumé par catégorie. Vérifiez les données et le résultat rendu, donnez-moi le lien Affichage, et ne fusionnez pas avant mon examen.

## Le rôle d’Office SDK

Office SDK fournit le contenu Headless runtime, le Facade API, calcul, rendu, versions et Worktrees. Le CLI assemble ces capacités en commandes de terminal et compétences jumelées version, et il possède le stockage local `.univer` , la passerelle , et le spectateur . Contenu que l'agent écrit peut passer directement dans les prévisualisations de l'éditeur et la livraison de fichiers standard .
