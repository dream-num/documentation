Univer CLI est une application Office locale construite avec **[Univer Office SDK](/docs/overview)**. Elle fournit commandes et Skills à votre agent pour traiter Excel, Word et PowerPoint ou créer feuilles de calcul, documents, présentations, tables relationnelles et canevas. Les résultats restent sur votre machine.

[Installer et essayer](#quick-start) · [Fonctionnement des Skills](#skills) · [Répertoire des Skills](#skills-catalog)

## Utiliser votre agent habituel

Vous pouvez utiliser Univer CLI avec ces agents :

**OpenCode** · **Claude Code** · **OpenClaw** · **Hermes** · **Codex** · **WorkBuddy** · **Kimi Work**

L’interface commune est la commande `univer` et ses instructions adaptées à la version. Les hôtes compatibles Agent Skills chargent la Skill officielle ; les agents capables d’exécuter des commandes peuvent aussi l’intégrer à leurs outils. Pour les cartes d’aperçu et autres expériences propres à l’hôte, consultez les [projets d’intégration](https://univer.ai/ecosystem).

## Voir votre premier résultat [#quick-start]

Utilisez Node.js 24 ou ultérieur et installez dans l’environnement de votre agent :

```bash
npm install --global univer-cli@latest
npx skills add dream-num/skills -s univer-cli -g
univer doctor
```

`univer doctor` vérifie l’environnement local. La Skill aide l’agent à découvrir les commandes, charger les instructions du produit, inspecter le contenu et livrer le résultat.

### Ouvrir l’exemple officiel

Dans un nouveau dossier vide, envoyez ceci à l’agent :

```text
Explore l’exemple officiel avec Univer CLI.
Télécharge https://univer.ai/cli-assets/hello.univer sous hello.univer dans le dossier actuel.
Liste son contenu, donne-moi le lien Viewer local et explique ce que je peux essayer.
```

Le contenu existant permet de découvrir immédiatement les éditeurs natifs. Demandez ensuite une modification ou essayez la tâche ci-dessous.

## Skills : des guides de travail pour les agents [#skills]

Les Skills regroupent le modèle de contenu, les étapes de modification, la recherche d’API Facade et les exigences de vérification dans des guides lisibles par l’agent. Ils l’aident à trouver les capacités utiles à chaque tâche, de la modification à la revue et à la livraison.

**Point de découverte :** Le [Skill `univer-cli`](https://github.com/dream-num/skills/blob/main/skills/univer-cli/SKILL.md) installé dans l’agent lui permet de reconnaître les tâches Office, puis de charger les guides complets depuis la CLI locale.

**Skills d’exécution :** Ils sont livrés avec la CLI et correspondent aux commandes et API Facade de la version installée. Chargez d’abord `core`, puis le produit cible ; ajoutez le sujet adapté pour les contenus intégrés ou les formules entre contenus.

### Charger les guides selon la tâche [#load-skills]

L’agent les lit généralement lui-même ; les développeurs peuvent aussi les consulter directement :

```bash
univer skills list
univer skills get core
univer skills get sheet
univer skills path sheet
```

`list` affiche les Skills installés, `get` lit le guide et `path` renvoie le répertoire local. Utilisez `univer skills get core --full` pour inclure les références et modèles. Recherchez les API précises au besoin avec `univer api find` et `univer api show`.

### Répertoire des Skills [#skills-catalog]

Cliquez sur un nom pour consulter le guide dans le code source. Pour une tâche réelle, utilisez la version renvoyée par votre commande locale `univer skills get <name>`.

| Skill | Quand l’utiliser |
| --- | --- |
| [`core`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/core/SKILL.md) | Processus commun : comprendre les Units et Worktrees, repérer le contenu, modifier, vérifier et soumettre à la revue. |
| [`sheet`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/sheet/SKILL.md) | Feuilles de calcul (Sheet) : données, formules, mise en forme, graphiques et vérification des résultats. |
| [`doc`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/doc/SKILL.md) | Documents (Doc) : paragraphes, texte enrichi, tableaux, graphiques et mise en page. |
| [`slide`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/slide/SKILL.md) | Présentations (Slide) : pages, formes, texte, images et vérification visuelle. |
| [`base`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/base/SKILL.md) | Relational Table : tables, champs, enregistrements et vues ; Base dans le SDK/API. |
| [`board`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/board/SKILL.md) | Canvases : éléments du canevas, graphiques et vérification de la disposition ; Board dans le SDK/API. |
| [`embed`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/embed/SKILL.md) | Contenus intégrés : insérer le contenu d’une Unit dans une autre et relier les sources de données des graphiques. |
| [`cross-unit-formula`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/cross-unit-formula/SKILL.md) | Formules entre contenus : lire des plages Sheet ou des champs Base pour calculer dans des cellules Sheet ou des formes pilotées par une formule. |

Par exemple, pour intégrer une feuille de calcul dans un document, chargez `core → doc + sheet → embed`. Ajoutez `cross-unit-formula` lorsqu’une cellule Sheet ou une forme référence des données d’un autre contenu. Il n’est pas nécessaire de charger tous les guides au départ. Après une mise à jour de la CLI, rechargez `core` et les Skills des produits et sujets concernés.

## Ce que vous pouvez créer

- **Des données aux livrables :** Nettoyez des feuilles, écrivez des formules, ajoutez graphiques et tableaux croisés, composez des rapports avec en-têtes et pieds de page ou des présentations à partir d’un plan.
- **Des contenus reliés :** Un fichier `.univer` peut contenir plusieurs types de contenu reliés par formules, références de graphiques et blocs intégrés.
- **Vérifier le résultat :** Relisez le modèle réel via Facade et utilisez captures et contrôles de mise en page pour repérer texte débordant, superposé ou hors page.
- **Réviser avant de livrer :** L’agent travaille dans un Worktree isolé et retourne un lien Viewer local. Examinez les différences, demandez des modifications, fusionnez ou abandonnez, puis exportez les formats Office pris en charge. L’import/export de fichiers de canevas n’est pas encore disponible.

## Essayez une tâche comme celle-ci

> Avec Univer CLI, crée une feuille de dépenses mensuelles avec date, catégorie, montant et cinq lignes d’exemple. Ajoute une formule de total et un graphique par catégorie. Vérifie données et affichage, donne-moi le lien Viewer et ne fusionne pas avant ma révision.

## Le rôle d’Office SDK

Office SDK fournit le runtime Headless, Facade, le calcul, le rendu, les versions et les Worktrees. CLI les assemble en commandes et Skills adaptées à la version et gère stockage `.univer`, Gateway et Viewer locaux. Le contenu produit par l’agent peut être prévisualisé dans l’éditeur et livré dans des formats standards.
