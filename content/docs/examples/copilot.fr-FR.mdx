**Copilote de bureau Univer** est une application web de référence open-source construite avec les **[Univer Office SDK](/overview)**, LangChain, React et TypeScript. Elle place des feuilles de calcul modifiables, des documents, des diapositives, des tables relationnelles et des toiles à côté d'un assistant de conversation. L'échantillon de code fonctionne sans modification et peut servir de point de départ pour votre propre copilote Office.

[Exécuter en local](#quick-start) · [Exemples éditables](https://github.com/dream-num/univer-office-copilot#included-examples) · [Dépôt source](https://github.com/dream-num/univer-office-copilot)

## Exécuter l’application de référence en local [#quick-start]

L'application de référence nécessite **Node.js 24+** et **pnpm 10,33.4** :

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

Ouvrir [http://127.0.0.1:5173](http://127.0.0.1:5173). Un nouveau compte de démonstration local commence par six exemples de démonstration privée et modifiable qui couvrent les cinq produits et les deux modes de document. La navigation et l'édition manuelle ne nécessitent pas de clé de modèle, Docker, ou une base de données externe.

Pour utiliser Copilot, ouvrez le menu modèle dans le chat et sélectionnez **Ajouter un modèle** ou **Gérer les modèles**. Définissez le fournisseur, le modèle ID et la clé API. L'application prend en charge OpenAI, Anthropic, Google Gemini, DeepSeek, OpenRouter et les paramètres HTTPS compatibles OpenAI personnalisés. Choisissez **Demande** pour inspecter un fichier, ou **Modifier** pour modifier le fichier actuel directement.

La mesure de texte AI et les vérifications rendues nécessitent Chrome, Chrome, ou Edge installés localement. La configuration du modèle, les pièces jointes, l'importation et l'exportation, et la configuration du navigateur sont décrites dans le [guide du développement local](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md).

## Le rôle d’Office SDK [#sdk-integration]

L'espace de travail React contient les éditeurs et l'interface de chat. Le moteur Node exécute la boucle d'outil LangChain, les compétences de produit et les scripts d'édition limités contre un client headless Univer. Les modifications confirmées atteignent le navigateur par le biais du même canal de collaboration que les gens utilisent, et la lecture native ainsi que les vérifications rendues fournissent la rétroaction de vérification.

Les Docs modernes utilisent Markdown, Paged Docs utilisent Typst, et les Diapositives utilisent SVG compilé en éléments modifiables. L'application prend également en charge plusieurs conversations par fichier, contexte de pièce jointe, inspection de changement par tour, historique de fichier natif, restauration contrôlée par le propriétaire, et partage séparé pour les fichiers et les conversations.
