**Univer Office Copilot** est une application web de référence open source construite avec **[Univer Office SDK](/overview)**, LangChain, React et TypeScript. Elle place des feuilles de calcul, documents, diapositives, tables relationnelles et canevas éditables à côté d’un assistant conversationnel. Utilisez cet exemple exécutable pour créer votre propre Office Copilot.

[Exécuter en local](#quick-start) · [Exemples éditables](https://github.com/dream-num/univer-office-copilot#included-examples) · [Dépôt source](https://github.com/dream-num/univer-office-copilot)

## Ce que vous pouvez construire

| Produit | Applications à créer |
| --- | --- |
| Sheets | Modèles financiers, analyses de scénarios, formules et graphiques. |
| Docs | Rapports de recherche et notes dans Modern Docs ou Paged Docs. |
| Slides | Présentations éditables pour investisseurs et projets. |
| Base | Enregistrements liés, suivi opérationnel et tableaux de bord actualisés. |
| Board | Cartes de décision, processus et diagrammes connectés. |

## Exécuter l’application de référence en local [#quick-start]

Utilisez **Node.js 24+** et **pnpm 10.33.4** :

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

Ouvrez **http://127.0.0.1:5173**. Chaque nouveau compte de démonstration local reçoit six exemples privés et éditables couvrant les cinq produits et les deux modes de document. Leur consultation et modification manuelle ne nécessitent ni clé de modèle, ni Docker, ni base de données externe.

Pour utiliser Copilot, ouvrez le menu des modèles dans le chat et choisissez **Add model** ou **Manage models**. Configurez le fournisseur, l’ID du modèle et votre clé API. L’application prend en charge OpenAI, Anthropic, Google Gemini, DeepSeek, OpenRouter et des points d’accès HTTPS personnalisés compatibles OpenAI. Utilisez **Ask** pour examiner un fichier ou **Edit** pour modifier directement le fichier courant.

La mesure du texte par l’IA et les vérifications du rendu nécessitent Chrome, Chromium ou Edge installé localement. Le [guide de développement local](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md) détaille les modèles, pièces jointes, imports/exports et paramètres du navigateur.

## Le rôle d’Office SDK [#sdk-integration]

L’espace React fournit les éditeurs et le chat. Le backend Node exécute la boucle d’outils LangChain, les Skills par produit et des scripts d’édition bornés sur un client Univer sans interface. Les modifications confirmées rejoignent le navigateur par le même canal collaboratif que les éditions humaines ; la relecture native et les vérifications du rendu alimentent la validation.

Modern Docs utilise Markdown, Paged Docs utilise Typst et Slides compile le SVG en éléments éditables. L’application inclut aussi plusieurs conversations par fichier, le contexte des pièces jointes, les changements par tour, l’historique natif, la restauration par le propriétaire et le partage séparé des fichiers et conversations.
