**Univer CLI** es una aplicación local de automatización de oficinas construida en el **[Univer Office SDK](/overview)**. Añade comandos de contenido y habilidades al agente que ya usas. Con estas adiciones, el agente puede trabajar con archivos Excel, Word y PowerPoint existentes, y puede crear hojas de cálculo, documentos, presentaciones, tablas relacionales y lienzos.

**CLI (Command-Line Interface) es actualmente la forma principal de operar Univer.** Sustituye el anterior enfoque MCP-primero a la integración de agentes. Univer CLI proporciona el comando `univer` y habilidades. Los agentes utilizan sus propias herramientas de ejecución de comandos para editar, inspeccionar y entregar contenido, y previsualizar y revisar tiene lugar en el Viewer local.

## Usa el agente con el que ya trabajas

Univer CLI soporta los siguientes agentes:

**OpenCode** · **Claude Code** · **OpenClaw** · **Hermes** · **Codex** · **WorkBuddy** · **Kimi Work**

Estos agentes comparten una única interfaz: el comando `univer` y la guía operacional que coincide con la versión instalada. Un host con el soporte de Agent Skills puede cargar la Habilidad oficial, y un agente que puede ejecutar comandos también puede llamar Univer a través de su propia capa de herramientas. Características específicas para el anfitrión, como las tarjetas de vista previa de conversación están cubiertas por el [proyectos de integración](https://univer.ai/ecosystem).

## Obtén tu primer resultado [#quick-start]

Univer CLI requiere Node.js 24 o más reciente. Instala en el ambiente donde tu agente corre:

```bash
npm install --global univer-cli@latest
npx skills add dream-num/skills -s univer-cli -g
univer doctor
```

`univer doctor` comprueba la hora local de ejecución. A través de la Habilidad, el agente descubre comandos, carga guía para un producto específico, inspecciona el contenido y ofrece resultados.

### Abre el ejemplo oficial

En un directorio nuevo y vacío, envía la siguiente instrucción al agente:

```text
Usa Univer CLI para explorar el ejemplo oficial.
Descarga https://univer.ai/cli-assets/hello.univer como hello.univer en el directorio actual.
Enumera su contenido, dame el enlace al Viewer local y explica qué puedo probar.
```

La apertura del contenido existente muestra inmediatamente a los editores nativos. A continuación, puede pedirle al agente que revise ese contenido, o pruebe la tarea de creación a continuación.

## Skills: guías de trabajo para agentes [#skills]

Estas Habilidades permiten a un agente existente crear, editar y revisar contenido de Office a través de Univer CLI. Primero [instalar el CLI y su Skill descubrimiento](#quick-start), luego cargar la guía específica de la tarea descrita a continuación.

Una Habilidad presenta parte del producto como guía que un agente puede leer: el modelo de contenido, el flujo de trabajo de edición, cómo encontrar las API de Facade, y los requisitos de verificación. Sobre esa base, el agente determina qué capacidades necesita una tarea, desde la primera edición a través de revisión y entrega.

**Entrada de descubrimiento:** El [`univer-cli` Habilidad](https://github.com/dream-num/skills/blob/main/skills/univer-cli/SKILL.md) instalado en el agente le ayuda a reconocer las tareas de Office, luego cargar la guía completa del CLI local.

**Habilidades de tiempo de ejecución:** Estos barcos con el CLI y coinciden con sus comandos instalados y APIs Facade. Carga `core` primero, luego el producto objetivo. Añadir el tema Habilidad cuando la tarea involucra embeds o fórmulas de contenido cruzado.

### Cargar las guías según la tarea [#load-skills]

En la mayoría de los casos el agente lee esta guía por su cuenta. Los desarrolladores también pueden inspeccionarla directamente:

```bash
univer skills list
univer skills get core
univer skills get sheet
univer skills path sheet
```

`list` muestra las Habilidades instaladas, `get` lee orientación, y `path` devuelve el directorio local. `univer skills get core --full` incluye referencias y plantillas. Use `univer api find` y `univer api show` para buscar APIs específicas.

### Directorio de Skills [#skills-catalog]

Siga un nombre para navegar por la guía en su repositorio de origen. Para tareas reales, utilice la versión devuelta por el comando `univer skills get <name>` local.

| Skill | Cuándo usarlo |
| --- | --- |
| [`core`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/core/SKILL.md) | Flujo de trabajo compartido: entender Unidades y Worktrees, localizar y editar contenido, verificarlo y someterlo para su revisión. |
| [`sheet`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/sheet/SKILL.md) | Hojas de cálculo (Sheet): datos, fórmulas, formato, gráficos y verificación de resultados. |
| [`doc`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/doc/SKILL.md) | Documentos (Doc): párrafos, texto enriquecido, tablas, gráficos y diseño de página. |
| [`slide`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/slide/SKILL.md) | Presentaciones (Slide): páginas, formas, texto, imágenes y cheques visuales. |
| [`base`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/base/SKILL.md) | Relational Table: tablas, campos, registros y vistas. |
| [`board`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/board/SKILL.md) | Canvases: elementos de tela, gráficos y cheques de diseño. |
| [`embed`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/embed/SKILL.md) | Embeds: colocar contenido de una unidad dentro de otra, y conectar fuentes de datos de gráficos. |
| [`cross-unit-formula`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/cross-unit-formula/SKILL.md) | Fórmulas entre contenidos: leer rangos de Sheet o campos de Relational Table para calcular en celdas de Sheet o formas controladas por fórmulas. |

Por ejemplo, para incrustar una hoja de cálculo en un documento, cargar `core → doc + sheet → embed`. Añadir `cross-unit-formula` cuando una célula de hoja o una forma hace referencia a datos de otro contenido. Carga cada guía por adelantado es innecesario. Después de actualizar el CLI, vuelva a cargar el `core` y el producto y tema Habilidades que utilice.

## Qué puedes crear

- Convierta los datos en una entrega: limpie la hoja, escriba fórmulas, agregue gráficos y tablas de pivote, establezca un informe con cabeceras y calzados, o construya una presentación de un esquema.
- Mantenga el contenido conectado: un archivo `.univer` puede contener múltiples tipos de contenido vinculados a través de fórmulas, referencias de gráficos y embeds.
- Verifique el resultado: lea el modelo de contenido real a través de Facade, luego utilice capturas de pantalla y cheques de presentación para encontrar texto que desborda, superpone o se escapa de la página.
- Revisión antes de la entrega: el agente trabaja en un Worktree aislado y devuelve un enlace local de Viewer. Inspeccione las diferencias, solicite revisiones, fusione o descarte el resultado, y exporte los formatos de Office soportados.

## Prueba una tarea como esta

> Utilice Univer CLI para crear una hoja de gastos mensuales con fecha, categoría y cantidad, y cinco filas de muestra. Agregue una fórmula total y una tabla resumida por categoría. Compruebe los datos y el resultado renderizado, dame el enlace Viewer, y no se fusionen antes de mi revisión.

## Cómo lo hace posible Office SDK

Office SDK suministra el tiempo de ejecución de contenidos sin cabeza, el Facade API, cálculo, renderizado, versiones y Worktrees. El CLI reúne estas capacidades en comandos terminales y Habilidades de edición de versiones, y posee el almacenamiento `.univer` local, el Gateway y el Viewer. Contenido que el agente escribe puede pasar directamente a previsiones de editor y entrega de archivos estándar.
