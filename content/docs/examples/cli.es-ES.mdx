**Univer CLI** es una aplicación Office local creada con **[Univer Office SDK](/overview)**. Aporta comandos y Skills a tu agente para trabajar con Excel, Word y PowerPoint o crear hojas de cálculo, documentos, presentaciones, tablas relacionales y lienzos. Los resultados quedan en tu equipo.

**CLI (Command-Line Interface, interfaz de línea de comandos) es actualmente la vía principal para operar Univer**, en sustitución del enfoque anterior de integración de agentes centrado en MCP. Univer CLI ofrece el comando `univer` y Skills: los agentes editan, inspeccionan y entregan contenido mediante sus herramientas de ejecución de comandos, y el Viewer local permite previsualizar y revisar los resultados.

## Usa el agente con el que ya trabajas

Puedes utilizar Univer CLI con estos agentes:

**OpenCode** · **Claude Code** · **OpenClaw** · **Hermes** · **Codex** · **WorkBuddy** · **Kimi Work**

La interfaz común es el comando `univer` y la guía vinculada a su versión. Los anfitriones con Agent Skills pueden cargar la Skill oficial; los agentes que ejecutan comandos también pueden integrarla en sus herramientas. Para tarjetas de vista previa y otras experiencias del anfitrión, consulta los [proyectos de integración](https://univer.ai/ecosystem).

## Obtén tu primer resultado [#quick-start]

Usa Node.js 24 o posterior e instala en el entorno de tu agente:

```bash
npm install --global univer-cli@latest
npx skills add dream-num/skills -s univer-cli -g
univer doctor
```

`univer doctor` comprueba el entorno local. La Skill ayuda al agente a descubrir comandos, cargar instrucciones del producto, inspeccionar contenido y entregar resultados.

### Abre el ejemplo oficial

En un directorio nuevo y vacío, envía esto al agente:

```text
Usa Univer CLI para explorar el ejemplo oficial.
Descarga https://univer.ai/cli-assets/hello.univer como hello.univer en el directorio actual.
Enumera su contenido, dame el enlace al Viewer local y explica qué puedo probar.
```

Abre contenido existente para ver los editores nativos de inmediato. Después puedes pedir cambios o probar la tarea siguiente.

## Skills: guías de trabajo para agentes [#skills]

Estos Skills permiten a tu agente crear, editar y comprobar contenido Office con Univer CLI. Primero [instala la CLI y su Skill de descubrimiento](#quick-start) y después carga las guías correspondientes a la tarea.

Los Skills reúnen el modelo de contenido, el flujo de edición, la búsqueda de API Facade y los requisitos de verificación en guías que el agente puede leer. Le ayudan a encontrar las capacidades necesarias para cada tarea, desde la edición hasta la revisión y entrega.

**Punto de descubrimiento:** El [Skill `univer-cli`](https://github.com/dream-num/skills/blob/main/skills/univer-cli/SKILL.md) instalado en el agente le ayuda a reconocer tareas de Office y a cargar las guías completas desde la CLI local.

**Skills de ejecución:** Se distribuyen con la CLI y corresponden a sus comandos y API Facade instalados. Carga primero `core`, después el producto de destino y, para inserciones o fórmulas entre contenidos, el tema correspondiente.

### Cargar las guías según la tarea [#load-skills]

Normalmente el agente las lee por su cuenta; los desarrolladores también pueden consultarlas directamente:

```bash
univer skills list
univer skills get core
univer skills get sheet
univer skills path sheet
```

`list` muestra los Skills instalados, `get` lee la guía y `path` devuelve el directorio local. Usa `univer skills get core --full` para incluir referencias y plantillas. Consulta las API concretas con `univer api find` y `univer api show` cuando las necesites.

### Directorio de Skills [#skills-catalog]

Pulsa un nombre para consultar su guía en el código fuente. Para las tareas reales, usa la versión que devuelve tu comando local `univer skills get <name>`.

| Skill | Cuándo usarlo |
| --- | --- |
| [`core`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/core/SKILL.md) | Flujo común: comprender Units y Worktrees, localizar contenido, editar, verificar y entregar para revisión. |
| [`sheet`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/sheet/SKILL.md) | Hojas de cálculo (Sheet): datos, fórmulas, formato, gráficos y verificación de resultados. |
| [`doc`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/doc/SKILL.md) | Documentos (Doc): párrafos, texto enriquecido, tablas, gráficos y diseño de página. |
| [`slide`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/slide/SKILL.md) | Presentaciones (Slide): páginas, formas, texto, imágenes y verificación visual. |
| [`base`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/base/SKILL.md) | Relational Table: tablas, campos, registros y vistas. |
| [`board`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/board/SKILL.md) | Canvases: elementos del lienzo, gráficos y verificación del diseño. |
| [`embed`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/embed/SKILL.md) | Inserciones: colocar contenido de una Unit dentro de otra y conectar fuentes de datos de gráficos. |
| [`cross-unit-formula`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/cross-unit-formula/SKILL.md) | Fórmulas entre contenidos: leer rangos de Sheet o campos de Relational Table para calcular en celdas de Sheet o formas controladas por fórmulas. |

Por ejemplo, para insertar una hoja de cálculo en un documento, carga `core → doc + sheet → embed`. Añade `cross-unit-formula` cuando una celda de Sheet o una forma haga referencia a datos de otro contenido. No hace falta cargar todas las guías al principio. Tras actualizar la CLI, vuelve a cargar `core` y los Skills de los productos y temas pertinentes.

## Qué puedes crear

- **De datos a entregables:** Limpia hojas, escribe fórmulas, añade gráficos y tablas dinámicas, compón informes con encabezados y pies o crea presentaciones desde un esquema.
- **Contenido conectado:** Un archivo `.univer` puede contener varios tipos de contenido enlazados mediante fórmulas, referencias de gráficos e inserciones.
- **Comprueba el resultado:** Lee el modelo real mediante Facade y utiliza capturas y comprobaciones de presentaciones para detectar texto desbordado, superpuesto o fuera de página.
- **Revisa antes de entregar:** El agente trabaja en un Worktree aislado y devuelve un enlace al Viewer local. Examina diferencias, pide cambios, fusiona o descarta y exporta formatos Office compatibles. La importación y exportación de archivos de lienzo aún no están disponibles.

## Prueba una tarea como esta

> Usa Univer CLI para crear una hoja de gastos mensuales con fecha, categoría, importe y cinco filas de ejemplo. Añade una fórmula de total y un gráfico por categoría. Comprueba datos y resultado visual, dame el enlace al Viewer y no fusiones antes de mi revisión.

## Cómo lo hace posible Office SDK

Office SDK aporta el entorno Headless, Facade, cálculo, renderizado, versiones y Worktrees. CLI los organiza en comandos y Skills vinculadas a la versión, y gestiona almacenamiento `.univer`, Gateway y Viewer locales. El contenido creado por el agente puede previsualizarse en el editor y entregarse en formatos estándar.
