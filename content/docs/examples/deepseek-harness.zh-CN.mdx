**Univer Office for DeepSeek Harness**（`dsh-univer-office`）是一个基于 **[Univer Office SDK](/overview)** 开发的 DSH 插件。它接受以自然语言描述的任务，由 Agent 创建或修改电子表格、文档、演示文稿、关系型表格和画布，并将可视化结果保留在当前对话中。

[安装与接入](#quick-start) · [直接体验](#first-task) · [Skills 与工具](#skills)

## 安装与接入 [#quick-start]

需要准备 DeepSeek Harness、一个已配置的模型，以及 Node.js 22.19 或更新版本。安装插件前，请先在插件仓库的[兼容要求](https://github.com/dream-num/dsh-univer-office#requirements-and-current-limits)中核对已验证的 DSH 版本。

### 安装插件

如果 DSH 正在运行，先在启动它的终端中按 Ctrl+C 停止，再安装到 Web 配置：

```bash
dsh plugin --profile web add dsh-univer-office
```

重新启动 DSH：

```bash
dsh web
```

DSH 启动后，刷新浏览器中的 DSH 页面，并在 Agent 可访问的项目目录中新建一个对话。插件自带运行时、工具和 Skills，无需另外安装 Univer CLI。截图和布局检查要求本机安装 Chrome、Chromium 或 Edge。

## 直接体验一个任务 [#first-task]

```text
使用 Univer Office，为新同事制作一份 3 页英文项目介绍，项目名为 Project Northstar。第 1 页是封面和一句话目标，第 2 页列出 3 个示例里程碑，第 3 页列出 3 项下一步行动。使用统一的蓝绿配色、清晰的标题和可编辑文本。
在独立草稿中完成，逐页检查溢出、重叠和显示效果，在当前对话中展示实时预览和审阅卡片。等我确认后再合入；需要 PowerPoint 时再导出。
```

</div>

### 你会看到什么

Agent 工作时，浮动窗口会显示这份演示稿；完成后，对话中会保留一张审阅卡片，之后仍可打开。最终得到的是一份可编辑的三页演示稿。你可以继续提出修改要求，例如“把第 2 页改成时间线”，然后批准或丢弃草稿。

## Skills 与工具如何协作 [#skills]

插件自带[通用 Skill 与产品指引](https://github.com/dream-num/dsh-univer-office/tree/main/skills)，DSH 会按任务需要加载其中的一部分。Agent 用 `univer_api` 查找匹配的 Facade API，用 `univer_execute` 修改内容，再检查读回结果、截图和 `univer_lint` 结果。Office SDK 负责计算、渲染和带版本的内容，DSH 插件负责浮动预览和对话中的审阅卡片。

## 你可以用它做什么

- 边生成边查看结果。实时预览窗口支持移动、缩放、折叠和最大化，Agent 编辑期间可以一直看到。
- 在对话中审阅。每个文件都有独立的预览卡片，之后仍可打开。你可以继续修改、批准草稿或丢弃草稿。
- 交付真实的 Office 内容。可处理已有的 Excel、Word 和 PowerPoint 文件，创建公式、图表和复杂版式，并导出对应格式。
- 让 Agent 检查自己的成果。结合模型读回、截图和演示稿布局检查。多种内容类型可以共用一个文件，并通过公式和嵌入相互连接。

## Office SDK 如何支撑 [#sdk-integration]

DSH 负责对话、会话和工具调用。插件将 Office SDK 的内容创作、计算、渲染和 Worktree 工作流接入这些入口。Agent 修改的是真实的内容模型，SDK 支撑预览和审阅，插件提供浮动窗口、对话卡片和会话状态。这一组合展示了 Office 能力在现有 Agent 产品中的呈现方式。
