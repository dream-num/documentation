**Univer Office for DeepSeek Harness**（`dsh-univer-office`）是基于 **[Univer Office SDK](/docs/overview)** 构建的 DSH 插件。用自然语言描述需求，Agent 就能创建或修改电子表格、文档、演示文稿、关系型表格和画布，并把可视化成果留在当前对话中。

[安装与接入](#quick-start) · [直接体验](#first-task) · [Skills 与工具](#skills)

## 安装与接入 [#quick-start]

先准备 DeepSeek Harness、可用模型和 Node.js 22.19 或更新版本。插件仓库列出了已验证的 DSH 版本，安装前请核对[兼容要求](https://github.com/dream-num/dsh-univer-office#requirements-and-current-limits)。

### 安装插件

若 DSH 正在运行，先在启动它的终端中按 Ctrl+C 停止，再安装到 Web 配置：

```bash
dsh plugin --profile web add dsh-univer-office
```

重新启动 DSH：

```bash
dsh web
```

启动成功后刷新 DSH 浏览器页面，并在可访问的项目目录中开始一个新对话。插件已包含运行时、工具和 Skills，无需另装 Univer CLI。截图与页面布局检查需要本机 Chrome、Chromium 或 Edge。

```text

在独立草稿中完成，逐页检查溢出、重叠和显示效果，在当前对话中展示实时预览和审阅卡片。等我确认后再合入；需要 PowerPoint 时再导出。
```

### 你会看到什么

Agent 工作时，浮动窗口展示演示稿变化；完成后，对话中保留可重新打开的审阅卡片。你得到的是可编辑的三页演示稿，可以继续要求“把第 2 页改成时间线”，再决定批准或丢弃草稿。

## Skills 与工具如何协作 [#skills]

插件随包提供[通用 Skill 与产品指引](https://github.com/dream-num/dsh-univer-office/tree/main/skills)。DSH 按任务加载，Agent 通过 `univer_api` 查询配套 Facade API，通过 `univer_execute` 操作内容，再用读回、截图和 `univer_lint` 检查结果。Office SDK 负责真实内容的计算、渲染和版本；DSH 插件负责对话中的浮动预览与审阅卡片。

## 你可以用它做什么

- **边生成，边看结果：** 实时预览窗口可拖动、缩放、折叠或最大化，让你在 Agent 工作时跟进内容变化。
- **在对话中完成审阅：** 每个文件有自己的预览卡片，后续仍可打开查看；草稿支持继续修改、批准或丢弃。
- **交付真实 Office 内容：** 可以处理已有 Excel、Word 和 PowerPoint 文件，生成带公式、图表和丰富排版的内容，再导出相应格式。
- **让 Agent 检查自己的成果：** 结合结构读回、截图和演示稿布局检查验证结果；多种内容可以放在同一个文件中，通过公式和嵌入相互关联。

## Office SDK 如何支撑 [#sdk-integration]

DSH 提供对话、会话和工具调用；插件把 Office SDK 的内容操作、计算、渲染及 Worktree 工作流接入这些入口。Agent 操作真实内容模型，SDK 支撑预览与审阅，插件负责浮动窗口、对话卡片和会话状态。它展示了如何把 Office 能力融入已有 Agent 产品。
