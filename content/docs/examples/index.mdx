The projects below are open-source applications and integrations built on **[Univer Office SDK](/overview)**. They automate local Office files with an agent, support co-editing in a team workspace, and create, preview, and review deliverables inside an existing agent conversation.

Workspace and CLI are complete applications. Office Copilot is a runnable reference app for building an in-app assistant, and the DeepSeek Harness, WorkBuddy, and OpenClaw entries are Office integration plugins for those agent hosts.

## Workspace [#univer-workspace]

<span id="univer-workspace-desktop" />

The project is an open-source Office workspace built with Office SDK. You can use the cloud service or deploy it privately. Existing agents connect through Workspace CLI, and Desktop provides conversations, live previews, and collaborative review.

[Explore the project](/overview/examples/workspace) · [Try online](https://space.univer.ai) · [Source repository](https://github.com/dream-num/univer-workspace) · [Desktop experience](/overview/examples/workspace#desktop-start)

## Office Lab [#office-lab]

Office Lab is a GitHub-style collaboration case for Office work. It connects requirements, Issues, Worktree PRs, native Compare, interactive prototypes, and delivery schedules across product and engineering.

[Read the collaboration case](/overview/examples/office-lab) · [Source repository](https://github.com/dream-num/univer-workspace)

## Office Copilot [#office-copilot]

Office Copilot is an open-source web application that places editors next to chat and can serve as the starting point for your own Office copilot. It provides six editable examples. Connect your model, then adapt direct editing, collaboration, history, and sharing to all five products.

[Explore the project](/overview/examples/copilot) · [Quick start](https://github.com/dream-num/univer-office-copilot#quick-start) · [Source repository](https://github.com/dream-num/univer-office-copilot)

## CLI [#univer-cli]

The CLI provides local Office capabilities to OpenCode, Claude Code, OpenClaw, Hermes, Codex, WorkBuddy, Kimi Work, and other agents. Install the CLI and the Skill, open the official sample, and then create and inspect your own results.

[Explore the project](/overview/examples/cli) · [Quick start](https://github.com/dream-num/univer-cli#quick-start) · [Source repository](https://github.com/dream-num/univer-cli)

## DeepSeek Harness plugin [#deepseek-harness]

This plugin provides a conversational Office experience. You describe a task, follow the work in the live window, and review, revise, and deliver the result in the same conversation.

[Explore the project](/overview/examples/deepseek-harness) · [Watch the demo](https://www.youtube.com/watch?v=k-2zW_CMiew) · [Source repository](https://github.com/dream-num/dsh-univer-office)

## WorkBuddy plugin [#workbuddy]

This plugin handles MCP and agent-host integration: local Office files, read-only previews inside the host, and version review in the browser. It is currently a development preview.

[Explore the project](/overview/examples/workbuddy) · [Explore the workflow](https://github.com/dream-num/workbuddy-univer-office#workflow) · [Source repository](https://github.com/dream-num/workbuddy-univer-office)

## OpenClaw plugin [#openclaw]

This plugin integrates with existing OpenClaw workflows. You start a team file task from chat, edit and inspect a Workspace draft, and return a result that can be reviewed on phones and computers.

[Explore the project](/overview/examples/openclaw) · [Explore the workflow](https://github.com/dream-num/openclaw-univer-office#typical-request) · [Source repository](https://github.com/dream-num/openclaw-univer-office)
