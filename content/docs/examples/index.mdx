These open-source projects turn **[Univer Office SDK](/docs/overview)** into applications you can use: automate local Office files with an agent, co-edit in a team workspace, or create, preview, and review deliverables inside an existing agent conversation.

Workspace and CLI are complete applications. The DeepSeek Harness, WorkBuddy, and OpenClaw entries are Office integration plugins for those agent hosts.

## Workspace [#univer-workspace]

<span id="univer-workspace-desktop" />

An open-source Office workspace built with Office SDK. Try the cloud service or deploy it privately; connect existing agents through Workspace CLI, or use Desktop for conversations, live previews, and collaborative review.

[Explore the project](/docs/examples/workspace) · [Try online](https://space.univer.ai) · [Source repository](https://github.com/dream-num/univer-workspace) · [Desktop experience](/docs/examples/workspace#desktop-start)

## Office Lab [#office-lab]

A GitHub-style Office collaboration case: product and engineering connect requirements, Issues, Worktree PRs, native Compare, interactive prototypes and delivery schedules.

[Explore Workspace](/docs/examples/office-lab) · [Source repository](https://github.com/dream-num/univer-workspace)

## CLI [#univer-cli]

Bring local Office capabilities to OpenCode, Claude Code, OpenClaw, Hermes, Codex, WorkBuddy, Kimi Work, and other agents. Install the CLI and Skill, open the official sample, then create and inspect your own results.

[Explore the project](/docs/examples/cli) · [Quick start](https://github.com/dream-num/univer-cli#quick-start) · [Source repository](https://github.com/dream-num/univer-cli)

## DeepSeek Harness Plugin [#deepseek-harness]

For a conversational Office experience: describe a task, follow the live window, then review, revise, and deliver the result in the same conversation.

[Explore the project](/docs/examples/deepseek-harness) · [Watch the demo](https://www.youtube.com/watch?v=k-2zW_CMiew) · [Source repository](https://github.com/dream-num/dsh-univer-office)

## WorkBuddy Plugin [#workbuddy]

For MCP and agent-host integration: combine local Office files, read-only host previews, and browser-based version review. Currently a development preview.

[Explore the project](/docs/examples/workbuddy) · [Explore the workflow](https://github.com/dream-num/workbuddy-univer-office#workflow) · [Source repository](https://github.com/dream-num/workbuddy-univer-office)

## OpenClaw Plugin [#openclaw]

For existing OpenClaw workflows: start a team-file task from chat, edit and inspect a Workspace draft, and return a result people can review on phones and computers.

[Explore the project](/docs/examples/openclaw) · [Explore the workflow](https://github.com/dream-num/openclaw-univer-office#typical-request) · [Source repository](https://github.com/dream-num/openclaw-univer-office)
