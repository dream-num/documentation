Univer Workspace es una aplicación Office de código abierto construida con **[Univer Office SDK](/docs/overview)** para personas y agentes. Despliega **Server y Web** en línea y conecta tus agentes mediante **Workspace CLI + Skills**.

## Los archivos compartidos aportan el contexto de trabajo [#workspace-context]

![Los archivos compartidos aportan el contexto de trabajo](/assets/examples/workspace-desktop/workspace-overview.jpg)

El Space de Aurora reúne un modelo operativo con fórmulas, un informe de decisión, una presentación, un registro de tareas y un lienzo estratégico. Web y Desktop se conectan a los mismos archivos compartidos. El agente lee las fuentes y prepara los cambios en un Worktree; un documento nuevo permanece en el borrador hasta que una persona aprueba la fusión. Consulta la [conversación y vista previa en Desktop](/docs/examples/workspace-desktop#conversation-preview) del mismo ejemplo.

## Workspace CLI: conecta cualquier agente al espacio [#cli-start]

Tras desplegar la edición en línea, no necesitas desarrollar una integración Office distinta por agente. Instala la CLI y el Skill donde se ejecuta tu agente. Con ejecución de comandos puede buscar archivos, crear y editar contenido, calcular, capturar pantallas, verificar y entregar enlaces de revisión. Tu agente sigue aportando el modelo y la conversación.

Usa Node.js 22.12 o posterior, preferiblemente 24. El paquete npm es `univer-workspace-cli` y ofrece los comandos `uvw` y `univer-workspace-cli` para el mismo programa.

```bash
npm install --global univer-workspace-cli@latest
npx skills add dream-num/univer-workspace --skill univer-workspace-cli -g
uvw --version
```

La conexión predeterminada es la demo. Para tu propio despliegue, configura la dirección del servicio:

```bash
uvw config set workspace.origin https://space.univer.ai
```

Completa una vez el inicio de sesión indicado por la CLI. Después, esta gestiona la sesión para reutilizarla entre tareas. No necesitas crear una página de acceso, un callback OAuth ni una integración de autenticación para cada agente.

<details>

<summary>Primera conexión: iniciar sesión una vez en el navegador</summary>

Omite este paso si ya existe una sesión válida. Si necesitas iniciar sesión, ejecuta:

```bash
uvw auth login
```

Abre el enlace, inicia sesión y confirma el código en el navegador. Solo después de que el usuario confirme que ha terminado, ejecuta:

```bash
uvw auth login --complete
```

Este paso sirve para establecer la sesión. Consulta los comandos y detalles en la [guía de Workspace CLI](https://github.com/dream-num/univer-workspace/blob/main/apps/cli/README.md).

</details>

## Skills: entender el espacio y completar tareas [#skills]

El [Skill `univer-workspace-cli`](https://github.com/dream-num/univer-workspace/blob/main/skills/univer-workspace-cli/SKILL.md) instalado en tu agente es el punto de descubrimiento: explica la conexión, la localización del objetivo y la carga de guías. Los Skills completos se distribuyen con la CLI y corresponden a sus comandos y API Facade. El complemento integrado de Desktop también proporciona guías y herramientas por tarea.

| Guía | Cobertura |
| --- | --- |
| `core` | Espacios y archivos, borradores de tarea, verificación y entrega para revisión. |
| `sheet` · `doc` · `slide` · `base` · `board` | Hojas de cálculo, documentos, presentaciones, Relational Table y Canvases; Base y Board siguen siendo los nombres SDK/API. |
| `blob` | Subir, descargar y reemplazar archivos originales. |
| `html-view` | Crear y gestionar páginas HTML activas para Web Apps interactivas. |
| `embed` · `cross-unit-formula` | Insertar contenido y conectar datos y fórmulas entre contenidos. |

```bash
uvw skills list
uvw skills get core
uvw skills get sheet
uvw skills get html-view
```

Carga primero `core` y después el producto o tema necesario. `skills get` enumera referencias; `uvw skills read <name> <path>` lee una concreta y `--full` las incluye juntas. Los agentes existentes acceden mediante la CLI; Desktop integra herramientas y guías en la conversación.

## De documentos Office a Web Apps [#web-apps]

Además de hojas, documentos, presentaciones, tablas relacionales y lienzos, pide Web Apps basadas en ese contenido: paneles de negocio, informes interactivos, simuladores de presupuesto o páginas operativas. HTML Views y la vinculación bidireccional conectan métricas, gráficos, entradas y deslizadores con las hojas. La página actualiza datos, los cambios vuelven a la página y pueden conectarse a la colaboración.

```text
Con la hoja de gastos recién creada, construye un panel de presupuesto Web App con total, gráfico por categoría y entrada de presupuesto. Vincula la visualización y la entrada a la hoja, verifica ambas direcciones y dame acceso a la vista previa y revisión.
```

## Conecta solicitud, cambios y revisión

Workspace CLI incluye `uvw issue` y `uvw pr`: las Issues contienen solicitudes y discusión; las PR contienen cambios para revisar, respaldados por Worktrees. El agente puede leer la tarea, editar contenido nativo, comprobarlo y entregar los cambios a una persona, conectando necesidades del equipo con resultados Office.

## Inspecciona el borrador antes de fusionarlo [#agent-review]

La revisión nativa de Desktop muestra el contenido compartido y los cambios propuestos en paralelo. Abre el mismo borrador en Workspace para comprobar su estado Ready, los archivos modificados y la vista nativa del documento. Usa View y Compare antes de decidir si fusionas los cambios. Completar una tarea del agente no modifica automáticamente los archivos originales compartidos.

## Cómo lo hace posible Office SDK [#sdk-integration]

Web SDK aporta modelo compartido, editores, renderizado y procesamiento sin interfaz; Server SDK, colaboración, versiones y Worktrees; AI SDK, operaciones y verificación para agentes. Workspace los convierte en Server y aplicación en línea desplegables. La CLI abre estas capacidades a agentes existentes y Desktop las integra en una aplicación Office con agente.
