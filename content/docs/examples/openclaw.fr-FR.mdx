**Office Univer pour OpenClaw** (`openclaw-univer-office`) connecte OpenClaw aux fonctions Workspace construites avec le **[Univer Office SDK](/overview)**. Un agent peut localiser des fichiers dans des espaces personnels et d'équipe, modifier et inspecter un avant-projet de tâche, et retourner un lien de revue, des images de prévisualisation ou des fichiers exportés.

[Installer et connecter](#quick-start) · [Essayer une tâche](#first-task) · [Skills et outils](#skills)

## Installer et connecter [#quick-start]

Vous avez besoin d'OpenClaw 2026.5.17 ou plus récent, Node.js 22.22.3 ou plus récent et d'un accès à un service d'espace de travail Univer. Exécutez les commandes suivantes sur l'hôte OpenClaw Gateway. Cet exemple pins Workspace CLI 0.5.3 pour correspondre à l'interface de commande du plugin actuel.

### 1. Installer la CLI et le plugin

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

Le plugin est publié sur ClawHub sous la forme de `@dr-univer/openclaw-univer-office`. Une installation locale séparée `univer-cli` n'est pas requise.

### 2. Activer les outils et connecter le service

Ajouter les paramètres suivants à la configuration OpenClaw et conserver les autorisations d'outils existantes. Si `tools.allow` existe déjà, ajouter `univer-office` à cette liste :

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

Pointez l'ICL au service Workspace. L'exemple ci-dessous utilise la démo en ligne, donc un déploiement auto-organisé nécessite une adresse différente. Redémarrez la passerelle après avoir modifié la configuration.

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. Se connecter depuis la conversation

Envoyer le message suivant à OpenClaw :

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Connecte-toi à Univer Workspace et vérifie mon état de connexion. Si nécessaire, donne-moi le lien d’autorisation du navigateur et le code, puis attends que je termine.
```

</div>

Ouvrez le lien retourné sur un téléphone ou un ordinateur, connectez-vous et confirmez le code. Puis informez OpenClaw que la connexion est complète et approuvez son action de fin de connexion. Le plugin ne s'interroge pas à la place de cette approbation, qui doit venir de vous. Sur la démo en ligne, utilisez des exemples de données.

## Essayez une tâche immédiatement [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Avec Univer Office, crée dans mon espace personnel Workspace un planning hebdomadaire en anglais pour Project Northstar avec cinq tâches : Task, Owner, Estimated Hours et Status. Calcule le total des heures par formule.
Modifie dans un Worktree isolé, relis les données, vérifie une capture, marque le résultat prêt pour revue et donne-moi un seul lien ouvrable sur téléphone et ordinateur. Ne fusionne rien et ne l’envoie à personne d’autre ; attends ma confirmation.
```

</div>

### Ce que vous verrez

Le chat renvoie un résumé du résultat et un lien de révision. Le lien ouvre le même brouillon Workspace dans un navigateur de téléphone et sur un bureau. L'éditeur natif et l'interface de révision complète restent dans Workspace, tandis que le canal de chat livre des progrès, prévisualiser des images et des fichiers exportés.

### Poursuivre l’essai

Pour le travail d'équipe en direct, sélectionnez un espace d'équipe existant et demandez explicitement une ébauche visible pour l'espace. OpenClaw demande l'approbation nécessaire. Les collaborateurs doivent être signés dans les membres de cet espace; le lien partagé ne donne à lui seul aucun accès.

## Comment les Skills et les outils coopèrent [#skills]

Le plugin regroupe un [Compétence `univer-office`](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md). L'agent localise des espaces avec `univer_office_connect` et `univer_office_files`, charge les conseils de base et de produit à travers l'action `guidance` de l'outil de contenu, puis recherche les API Facade, fait des modifications, et vérifie le résultat. Workspace héberge le contenu de SDK Office, l'autorisation, la collaboration et Worktrees. OpenClaw gère les canaux de chat, les approbations d'outils et la livraison de fichiers.

## Ce que vous pouvez créer

- Accédez au contenu de l'équipe du chat : trouvez et parcourez les Espaces et les fichiers pour lesquels vous êtes autorisé, puis travaillez sur des feuilles de calcul, des documents, des présentations, des tableaux relationnels et des toiles.
- Collaborer sur les tâches : éditer dans un Worktree isolé, et créer un projet visible pour l'Espace lorsque les coéquipiers devraient examiner ensemble.
- Inspecter et livrer à travers les appareils : vérifier la structure, les captures d'écran et la mise en page, puis retourner un lien de révision Workspace qui s'ouvre dans un navigateur de téléphone ou de bureau.
- Garder les décisions avec les gens : un résultat marqué prêt nécessite toujours qu'une personne choisisse de fusionner ou de jeter. Prévisualiser les images et les fichiers exportés sont livrés par le biais du message et des canaux de fichiers d'OpenClaw.

## Le rôle d’Office SDK [#sdk-integration]

Le plugin appelle auteur et inspection par le biais de Workspace CLI. Workspace Server héberge Office SDK contenu, collaboration, versions, et Worktrees, et fait respecter l'identité et les autorisations. OpenClaw gère la conversation, les canaux et les approbations d'outils; l'édition complète et la révision restent dans Workspace. Le terminal agent peut fonctionner localement pendant que l'équipe collabore à travers un service.
