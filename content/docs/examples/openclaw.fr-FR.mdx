**Univer Office for OpenClaw** (`openclaw-univer-office`) relie OpenClaw aux capacités Workspace construites avec **[Univer Office SDK](/overview)**. L’agent trouve des fichiers personnels ou d’équipe, modifie et inspecte des brouillons et renvoie liens de révision, images ou fichiers exportés.

[Installer et connecter](#quick-start) · [Essayer une tâche](#first-task) · [Skills et outils](#skills)

## Installer et connecter [#quick-start]

Préparez OpenClaw 2026.5.17 ou ultérieur, Node.js 22.22.3 ou ultérieur et un accès à Univer Workspace. Installez les éléments suivants sur la machine du Gateway. L’exemple fixe Workspace CLI 0.5.3 pour correspondre aux commandes du plugin actuel.

### 1. Installer la CLI et le plugin

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

Le plugin utilisé est `@dr-univer/openclaw-univer-office` sur ClawHub. L’installation séparée de la CLI locale `univer-cli` n’est pas nécessaire.

### 2. Activer les outils et connecter le service

Fusionnez ces paramètres avec votre configuration OpenClaw en conservant les autorisations existantes. Si `tools.allow` existe déjà, ajoutez `univer-office` à sa liste :

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

Pointez la CLI vers votre service Workspace. L’exemple utilise la démonstration en ligne ; remplacez l’adresse pour un déploiement autonome. Redémarrez le Gateway après configuration.

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. Se connecter depuis la conversation

Envoyez à OpenClaw :

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Connecte-toi à Univer Workspace et vérifie mon état de connexion. Si nécessaire, donne-moi le lien d’autorisation du navigateur et le code, puis attends que je termine.
```

</div>

Ouvrez le lien sur téléphone ou ordinateur, connectez-vous et confirmez le code. Indiquez à OpenClaw que c’est fait, puis approuvez l’action de finalisation. Le plugin ne remplace pas votre autorisation par des interrogations répétées. Utilisez des données d’exemple dans la démonstration en ligne.

## Essayez une tâche immédiatement [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Avec Univer Office, crée dans mon espace personnel Workspace un planning hebdomadaire en anglais pour Project Northstar avec cinq tâches : Task, Owner, Estimated Hours et Status. Calcule le total des heures par formule.
Modifie dans un Worktree isolé, relis les données, vérifie une capture, marque le résultat prêt pour revue et donne-moi un seul lien ouvrable sur téléphone et ordinateur. Ne fusionne rien et ne l’envoie à personne d’autre ; attends ma confirmation.
```

</div>

### Ce que vous verrez

Le chat renvoie un résumé et un lien. Les navigateurs du téléphone et de l’ordinateur ouvrent le même brouillon Workspace. L’éditeur natif et la revue complète restent dans Workspace ; le chat peut transmettre l’avancement, les aperçus et les fichiers exportés. Le statut prêt ne modifie pas la version actuelle.

### Poursuivre l’essai

Pour collaborer en direct, choisissez un espace d’équipe existant et demandez explicitement un brouillon visible par ses membres. OpenClaw demandera l’approbation correspondante. Les collaborateurs doivent être membres de cet espace et connectés ; le lien seul ne donne aucun accès.

## Comment les Skills et les outils coopèrent [#skills]

Le plugin inclut un [Skill `univer-office`](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md). L’agent repère les espaces avec `univer_office_connect` et `univer_office_files`, charge les guides communs et produit via `guidance`, consulte Facade, modifie et vérifie. Workspace héberge contenu, droits, collaboration et Worktrees d’Office SDK ; OpenClaw gère les canaux, approbations et livraisons de fichiers.

## Ce que vous pouvez créer

- **Accéder aux documents depuis le chat :** Recherchez les espaces et fichiers autorisés, puis travaillez sur feuilles, documents, présentations, tables relationnelles et canevas existants.
- **Rendre les tâches collaboratives :** Modifiez un Worktree isolé et rendez le brouillon visible à l’espace lorsque l’équipe doit réviser ensemble.
- **Vérifier et livrer sur plusieurs appareils :** Contrôlez structure, captures et mise en page, puis renvoyez un lien Workspace ouvrable sur téléphone ou ordinateur.
- **Garder la décision humaine :** Le statut prêt laisse à une personne le choix de fusionner ou d’abandonner. Aperçus et exports passent par les canaux de messages et fichiers d’OpenClaw.

## Le rôle d’Office SDK [#sdk-integration]

Le plugin utilise Workspace CLI pour les opérations et inspections. Workspace Server héberge contenu, collaboration, versions et Worktrees d’Office SDK et applique identité et permissions. OpenClaw gère conversation, canaux et approbations ; l’édition et la révision complètes restent dans Workspace. L’agent peut s’exécuter localement tandis que l’équipe partage un service.
