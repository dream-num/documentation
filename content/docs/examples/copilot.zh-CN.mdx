**Univer Office Copilot** 是一个开源参考 Web 应用，使用 **[Univer Office SDK](/overview)**、LangChain、React 和 TypeScript 构建。表格、文档、幻灯片、多维表格和画板与对话助手并排显示，且均可直接编辑。该代码样例无需修改即可运行，也可作为自建 Office Copilot 的起点。

[本地运行](#quick-start) · [可编辑案例](https://github.com/dream-num/univer-office-copilot#included-examples) · [源码仓库](https://github.com/dream-num/univer-office-copilot)

![财务工作簿与 Copilot 对话并排显示，工作空间中包含六个案例文件](/assets/examples/office-copilot/overview.webp)

## 可以构建什么

| 产品 | 可构建的应用 |
| --- | --- |
| Sheets | 财务模型、情景分析、公式与图表。 |
| Docs | 用现代文档或分页文档撰写研究报告与备忘录。 |
| Slides | 可编辑的投资者演示与项目汇报。 |
| Base | 关联记录、业务跟踪与实时仪表盘。 |
| Board | 决策地图、工作流程与连线图。 |

## 在本地运行参考应用 [#quick-start]

运行参考应用需要 **Node.js 24+** 和 **pnpm 10.33.4**：

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。新建的本地演示账户自带六个私有且可编辑的案例，覆盖全部五类产品和两种文档模式；浏览和手动编辑均不需要模型 Key、Docker 或外部数据库。

要使用 Copilot，请打开聊天中的模型菜单，选择 **Add model** 或 **Manage models**，并填写提供商、模型 ID 和 API Key。应用支持 OpenAI、Anthropic、Google Gemini、DeepSeek、OpenRouter 以及自定义的 OpenAI 兼容 HTTPS 接口。选择 **Ask** 可查看文件，选择 **Edit** 可直接修改当前文件。

AI 文本测量和渲染检查需要本机安装 Chrome、Chromium 或 Edge。模型配置、附件、导入导出和浏览器设置参见[本地开发指南](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md)。

<Callout type="info">
应用源码采用 Apache-2.0 协议。内嵌的 Univer Pro 功能适用单独的 SDK 授权条款，本应用不授予 Pro 授权。详见 [SDK 授权说明](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md#univer-licensing)。

## Office SDK 如何支撑这个应用 [#sdk-integration]

React 工作空间提供编辑器和聊天界面。Node 后端针对无界面的 Univer 客户端运行 LangChain 工具循环、产品 Skills 和受限的编辑脚本。确认后的修改经由用户使用的同一条协同通道送达浏览器，原生读回与渲染检查则提供验证反馈。

现代文档使用 Markdown，分页文档使用 Typst，幻灯片则先将 SVG 编译为可编辑元素。应用还支持单个文件开启多个会话、附件上下文、逐轮查看修改、原生文件历史、由所有者恢复版本，以及文件和会话各自独立分享。

如需继续开发，可参阅[架构说明](https://github.com/dream-num/univer-office-copilot/blob/main/docs/architecture.md)和[扩展指南](https://github.com/dream-num/univer-office-copilot/blob/main/docs/extending.md)，也可以了解支撑该应用的[内容操作](/ai/content-operations)、[协作](/overview/features/shared/collaboration)和[历史版本](/overview/features/shared/history)能力。
