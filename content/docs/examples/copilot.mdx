**Univer Office Copilot** is an open-source reference web app built with **[Univer Office SDK](/overview)**, LangChain, React, and TypeScript. It places editable spreadsheets, documents, slides, relational tables, and canvases beside a conversation assistant. Use the runnable code sample to build your own Office copilot.

[Run locally](#quick-start) · [Editable examples](https://github.com/dream-num/univer-office-copilot#included-examples) · [Source repository](https://github.com/dream-num/univer-office-copilot)

## Run the reference app locally [#quick-start]

Use **Node.js 24+** and **pnpm 10.33.4**:

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173). A new local demo account receives six private, editable examples covering all five products and both document modes. Browsing and manual editing require no model key, Docker, or external database.

To use Copilot, open the model menu in chat and choose **Add model** or **Manage models**. Configure your provider, model ID, and API key. The app supports OpenAI, Anthropic, Google Gemini, DeepSeek, OpenRouter, and custom OpenAI-compatible HTTPS endpoints. Choose **Ask** to inspect a file or **Edit** to change the current file directly.

AI text measurement and rendered checks require local Chrome, Chromium, or Edge. See the [local development guide](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md) for model configuration, attachments, import/export, and browser setup.

## How Office SDK powers it [#sdk-integration]

The React workspace provides the editors and chat interface. The Node backend runs the LangChain tool loop, product Skills, and bounded editing scripts against a headless Univer client. Confirmed edits reach the browser through the same collaboration channel used by people; native readback and rendered checks provide verification feedback.

Modern Docs use Markdown, Paged Docs use Typst, and Slides use SVG compiled into editable elements. The app also includes multiple conversations per file, attachment context, per-turn change inspection, native file history, owner-controlled restore, and separate file/conversation sharing.
