**Univer Office for DeepSeek Harness**（`dsh-univer-office`）是一個基於 **[Univer Office SDK](/overview)** 開發的 DSH 外掛。它接受以自然語言描述的任務，由 Agent 建立或修改電子表格、文件、簡報、關係型表格和畫布，並將視覺化結果保留在當前對話中。

[安裝與接入](#quick-start) · [直接體驗](#first-task) · [Skills 與工具](#skills)

## 安裝與接入 [#quick-start]

需要準備 DeepSeek Harness、一個已配置的模型，以及 Node.js 22.19 或更新版本。安裝外掛前，請先在外掛倉庫的[相容要求](https://github.com/dream-num/dsh-univer-office#requirements-and-current-limits)中核對已驗證的 DSH 版本。

### 安裝外掛

如果 DSH 正在執行，先在啟動它的終端中按 Ctrl+C 停止，再安裝到 Web 配置：

```bash
dsh plugin --profile web add dsh-univer-office
```

重新啟動 DSH：

```bash
dsh web
```

DSH 啟動後，重新整理瀏覽器中的 DSH 頁面，並在 Agent 可訪問的專案目錄中新建一個對話。外掛自帶執行時、工具和 Skills，無需另外安裝 Univer CLI。截圖和版面配置檢查要求本機安裝 Chrome、Chromium 或 Edge。

## 直接體驗一個任務 [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
使用 Univer Office，為新同事製作一份 3 頁英文專案介紹，名稱為 Project Northstar。第 1 頁是封面與一句話目標，第 2 頁列出 3 個示例里程碑，第 3 頁列出 3 項下一步行動。使用一致的藍綠配色、清晰標題與可編輯文字。
在獨立草稿中完成，逐頁檢查溢出、重疊與顯示效果，在目前對話展示即時預覽與審閱卡片。等我確認後再合入；需要 PowerPoint 時再匯出。
```

</div>

### 你會看到什麼

Agent 工作時，浮動視窗會顯示這份演示稿；完成後，對話中會保留一張審閱卡片，之後仍可開啟。最終得到的是一份可編輯的三頁演示稿。你可以繼續提出修改要求，例如“把第 2 頁改成時間線”，然後批准或丟棄草稿。

## Skills 與工具如何協作 [#skills]

外掛自帶[通用 Skill 與產品指引](https://github.com/dream-num/dsh-univer-office/tree/main/skills)，DSH 會按任務需要載入其中的一部分。Agent 用 `univer_api` 查詢匹配的 Facade API，用 `univer_execute` 修改內容，再檢查讀回結果、截圖和 `univer_lint` 結果。Office SDK 負責計算、渲染和帶版本的內容，DSH 外掛負責浮動預覽和對話中的審閱卡片。

## 你可以用它做什麼

- 邊生成邊檢視結果。即時預覽視窗支援移動、縮放、摺疊和最大化，Agent 編輯期間可以一直看到。
- 在對話中審閱。每個檔案都有獨立的預覽卡片，之後仍可開啟。你可以繼續修改、批准草稿或丟棄草稿。
- 交付真實的 Office 內容。可處理已有的 Excel、Word 和 PowerPoint 檔案，建立公式、圖表和複雜版式，並匯出對應格式。
- 讓 Agent 檢查自己的成果。結合模型讀回、截圖和演示稿版面配置檢查。多種內容型別可以共用一個檔案，並透過公式和嵌入相互連線。

## Office SDK 如何支撐 [#sdk-integration]

DSH 負責對話、會話和工具呼叫。外掛將 Office SDK 的內容創作、計算、渲染和 Worktree 工作流接入這些入口。Agent 修改的是真實的內容模型，SDK 支撐預覽和審閱，外掛提供浮動視窗、對話卡片和會話狀態。這一組合展示了 Office 能力在現有 Agent 產品中的呈現方式。
