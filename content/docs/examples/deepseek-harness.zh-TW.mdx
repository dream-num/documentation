**Univer Office for DeepSeek Harness**（`dsh-univer-office`）是基於 **[Univer Office SDK](/overview)** 建置的 DSH 外掛程式。用自然語言描述需求，Agent 就能建立或修改試算表、文件、簡報、關聯式表格和畫布，並把可視化成果留在目前對話中。

[安裝與接入](#quick-start) · [直接體驗](#first-task) · [Skills 與工具](#skills)

## 安裝與接入 [#quick-start]

先準備 DeepSeek Harness、可用模型與 Node.js 22.19 或更新版本。安裝前請核對倉庫的[相容要求](https://github.com/dream-num/dsh-univer-office#requirements-and-current-limits)，確認已驗證的 DSH 版本。

### 安裝外掛

若 DSH 正在執行，先在啟動終端機按 Ctrl+C 停止，再安裝至 Web 設定檔：

```bash
dsh plugin --profile web add dsh-univer-office
```

重新啟動 DSH：

```bash
dsh web
```

啟動後重新整理 DSH 瀏覽器頁面，在可存取的專案目錄開始新對話。外掛已包含執行環境、工具與 Skills，不必另裝 Univer CLI。截圖與版面檢查需要本機 Chrome、Chromium 或 Edge。

## 直接體驗一個任務 [#first-task]

```text
使用 Univer Office，為新同事製作一份 3 頁英文專案介紹，名稱為 Project Northstar。第 1 頁是封面與一句話目標，第 2 頁列出 3 個示例里程碑，第 3 頁列出 3 項下一步行動。使用一致的藍綠配色、清晰標題與可編輯文字。
在獨立草稿中完成，逐頁檢查溢出、重疊與顯示效果，在目前對話展示即時預覽與審閱卡片。等我確認後再合入；需要 PowerPoint 時再匯出。
```

</div>

### 你會看到什麼

Agent 工作時，浮動視窗顯示簡報變化；完成後，對話中保留可重新開啟的審閱卡片。成果是可編輯的三頁簡報，可繼續要求「將第 2 頁改成時間軸」，再決定批准或捨棄草稿。

## Skills 與工具如何協作 [#skills]

外掛隨包提供[通用 Skill 與產品指引](https://github.com/dream-num/dsh-univer-office/tree/main/skills)，由 DSH 依任務載入。Agent 透過 `univer_api` 查詢配套 Facade API，以 `univer_execute` 編輯，再以讀回、截圖與 `univer_lint` 檢查。Office SDK 提供計算、繪製與內容版本；DSH 外掛提供浮動預覽與對話審閱卡片。

## 你可以用它做什麼

- **邊產生，邊看結果：** 實時預覽視窗可拖動、縮放、折疊或最大化，讓你在 Agent 工作時跟進內容變化。
- **在對話中完成審閱：** 每個檔案有自己的預覽卡片，後續仍可打開查看；草稿支援繼續修改、批准或捨棄。
- **交付真實 Office 內容：** 可以處理已有 Excel、Word 和 PowerPoint 檔案，產生帶公式、圖表和豐富排版的內容，再匯出相應格式。
- **讓 Agent 檢查自己的成果：** 結合結構讀回、截圖和簡報版面配置檢查驗證結果；多種內容可以放在同一個檔案中，透過公式和嵌入相互關聯。

## Office SDK 如何支撐 [#sdk-integration]

DSH 提供對話、會話和工具調用；外掛程式把 Office SDK 的內容操作、計算、渲染及 Worktree 工作流程接入這些入口。Agent 操作真實內容模型，SDK 支撐預覽與審閱，外掛程式負責浮動視窗、對話卡片和會話狀態。它展示了如何把 Office 能力融入已有 Agent 產品。
