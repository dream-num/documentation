**Univer Office Copilot** 是以 **[Univer Office SDK](/overview)**、LangChain、React 與 TypeScript 建構的開源參考 Web 應用。試算表、文件、簡報、多維表格與畫布和對話助手並排顯示，可直接編輯。你可以執行這個程式碼範例，再改造成自己的辦公 Copilot。

[本機執行](#quick-start) · [可編輯範例](https://github.com/dream-num/univer-office-copilot#included-examples) · [原始碼儲存庫](https://github.com/dream-num/univer-office-copilot)

![財務工作簿與 Copilot 對話並排顯示，工作空間中包含六個範例檔案](/assets/examples/office-copilot/overview.webp)

## 可以建置什麼

| 產品 | 可建置的應用 |
| --- | --- |
| Sheets | 財務模型、情境分析、公式與圖表。 |
| Docs | 以現代文件或分頁文件撰寫研究報告與備忘錄。 |
| Slides | 可編輯的投資人簡報與專案報告。 |
| Base | 關聯記錄、業務追蹤與即時儀表板。 |
| Board | 決策地圖、工作流程與連線圖。 |

## 在本機執行參考應用 [#quick-start]

使用 **Node.js 24+** 與 **pnpm 10.33.4**：

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

開啟 **http://127.0.0.1:5173**。新的本機示範帳戶會取得六個私有、可編輯的範例，涵蓋五類產品與兩種文件模式。瀏覽與手動編輯不需要模型 Key、Docker 或外部資料庫。

使用 Copilot 時，在聊天視窗的模型選單選擇 **Add model** 或 **Manage models**，設定供應商、模型 ID 與 API Key。應用支援 OpenAI、Anthropic、Google Gemini、DeepSeek、OpenRouter 與自訂 OpenAI 相容 HTTPS 介面。選擇 **Ask** 檢視檔案，或選擇 **Edit** 直接修改目前檔案。

AI 文字測量與渲染檢查需要本機安裝 Chrome、Chromium 或 Edge。模型設定、附件、匯入匯出與瀏覽器設定請參閱[本機開發指南](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md)。

## Office SDK 如何支援這個應用 [#sdk-integration]

React 工作空間提供編輯器與聊天介面；Node 後端透過 LangChain 工具迴圈、產品 Skills 與受限編輯腳本操作無介面的 Univer 用戶端。已確認的修改沿著與真人相同的協同通道同步到瀏覽器，原生內容回讀與渲染檢查提供驗證回饋。

現代文件使用 Markdown，分頁文件使用 Typst，簡報透過 SVG 編譯為可編輯元素。應用也包含單一檔案多個對話、附件上下文、每輪修改檢視、原生檔案歷史、擁有者還原版本，以及分別分享檔案與對話。

可以從[架構說明](https://github.com/dream-num/univer-office-copilot/blob/main/docs/architecture.md)與[擴充指南](https://github.com/dream-num/univer-office-copilot/blob/main/docs/extending.md)繼續開發，也可以了解底層的[內容操作](/ai/content-operations)、[協作](/overview/features/shared/collaboration)與[歷史版本](/overview/features/shared/history)能力。
