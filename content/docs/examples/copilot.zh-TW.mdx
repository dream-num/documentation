**Univer Office Copilot** 是一個開源參考 Web 應用，使用 **[Univer Office SDK](/overview)**、LangChain、React 和 TypeScript 建置。表格、文件、幻燈片、多維表格和畫板與對話助手並排顯示，且均可直接編輯。該程式碼樣例無需修改即可執行，也可作為自建 Office Copilot 的起點。

[本機執行](#quick-start) · [可編輯範例](https://github.com/dream-num/univer-office-copilot#included-examples) · [原始碼儲存庫](https://github.com/dream-num/univer-office-copilot)

![財務工作簿與 Copilot 對話並排顯示，工作空間中包含六個範例檔案](/assets/examples/office-copilot/overview.webp)

## 可以建置什麼

| 產品 | 可建置的應用 |
| --- | --- |
| Sheets | 財務模型、情境分析、公式與圖表。 |
| Docs | 用現代文件或分頁文件撰寫研究報告與備忘錄。 |
| Slides | 可編輯的投資人簡報與專案報告。 |
| Base | 關聯記錄、業務追蹤與即時儀表板。 |
| Board | 決策地圖、工作流程與連線圖。 |

## 在本機執行參考應用 [#quick-start]

執行參考應用需要 **Node.js 24+** 和 **pnpm 10.33.4**：

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

開啟 [http://127.0.0.1:5173](http://127.0.0.1:5173)。新建的本地演示賬戶自帶六個私有且可編輯的案例，覆蓋全部五類產品和兩種文件模式；瀏覽和手動編輯均不需要模型 Key、Docker 或外部資料庫。

要使用 Copilot，請開啟聊天中的模型選單，選擇 **Add model** 或 **Manage models**，並填寫提供商、模型 ID 和 API Key。應用支援 OpenAI、Anthropic、Google Gemini、DeepSeek、OpenRouter 以及自定義的 OpenAI 相容 HTTPS 介面。選擇 **Ask** 可檢視檔案，選擇 **Edit** 可直接修改當前檔案。

AI 文字測量和渲染檢查需要本機安裝 Chrome、Chromium 或 Edge。模型配置、附件、匯入匯出和瀏覽器設定參見[本地開發指南](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md)。

<Callout type="info">
應用原始碼採用 Apache-2.0 協議。內嵌的 Univer Pro 功能適用單獨的 SDK 授權條款，本應用不授予 Pro 授權。詳見 [SDK 授權說明](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md#univer-licensing)。

## Office SDK 如何支援這個應用 [#sdk-integration]

React 工作空間提供編輯器和聊天介面。Node 後端針對無介面的 Univer 客戶端執行 LangChain 工具迴圈、產品 Skills 和受限的編輯指令碼。確認後的修改經由使用者使用的同一條協同通道送達瀏覽器，原生讀回與渲染檢查則提供驗證反饋。

現代文件使用 Markdown，分頁文件使用 Typst，幻燈片則先將 SVG 編譯為可編輯元素。應用還支援單個檔案開啟多個會話、附件上下文、逐輪檢視修改、原生檔案歷史、由所有者恢復版本，以及檔案和會話各自獨立分享。

如需繼續開發，可參閱[架構說明](https://github.com/dream-num/univer-office-copilot/blob/main/docs/architecture.md)和[擴充套件指南](https://github.com/dream-num/univer-office-copilot/blob/main/docs/extending.md)，也可以瞭解支撐該應用的[內容操作](/ai/content-operations)、[協作](/overview/features/shared/collaboration)和[歷史版本](/overview/features/shared/history)能力。
