**Univer Workspace** — открытое рабочее пространство на **[Univer Office SDK](/overview)** для людей и агентов. Редактируемые документы Office и Web Apps с привязкой к данным объединены в личных и командных Spaces с совместной работой, доступом, версиями и проверкой изменений. [Репозиторий](https://github.com/dream-num/univer-workspace) содержит приложение, средства развёртывания, CLI и настольный клиент.

Разверните Workspace у себя или начните с [облачной пробы](https://space.univer.ai). Существующий агент подключается через Workspace CLI, а Workspace Desktop объединяет диалог и то же пространство в локальном приложении. Все варианты работают с одним сервисом и файлами.

## Начните с облачного Workspace [#entry-points]

<span id="web-start" />

Откройте [облачную пробу](https://space.univer.ai), войдите и выберите личный или доступный командный Space. Создавайте, редактируйте, организуйте и публикуйте документы. К этому работающему сервису можно подключить агента через CLI ниже. Используйте тестовые данные: содержимое пробного сервиса может сбрасываться.

**Workspace Server** управляет пользователями, Spaces, правами, хранением, совместной работой и версиями. **Web** предоставляет браузерный интерфейс редактирования и проверки. Частное развёртывание использует те же Server и Web.

## Подключите своего агента к облачному Workspace [#cli-start]

Установите CLI и вводную Skill в среде агента. Нужен Node.js 22.12 или новее; рекомендуется 24. Агент с выполнением команд использует эти инструменты со своей моделью и диалогом. Явно задайте облачный сервис, чтобы браузер и агент работали в одном Workspace:

```bash
npm install --global univer-workspace-cli@latest
npx skills add dream-num/univer-workspace --skill univer-workspace-cli -g
uvw --version
uvw config set workspace.origin https://space.univer.ai
```

<details>

<summary>Первое подключение: один вход в браузере</summary>

Пропустите при наличии действующей сессии. Если нужен вход, выполните:

```bash
uvw auth login
```

Откройте ссылку, войдите и подтвердите код в браузере. Только после подтверждения пользователем выполните:

```bash
uvw auth login --complete
```

Этот шаг устанавливает сессию. Команды и подробности — в [руководстве Workspace CLI](https://github.com/dream-num/univer-workspace/blob/main/apps/cli/README.md).

</details>

После первого подтверждения в браузере CLI повторно использует сеанс. Не нужно создавать отдельный вход или интеграцию авторизации для каждого агента. Дайте агенту задачу и откройте возвращённую ссылку в Web, чтобы проверить то же содержимое и изменения Office перед слиянием.

Отправьте задачу подключённому агенту или используйте Desktop. Агент создаёт и проверяет, а вы запрашиваете правки, проводите ревью и решаете об объединении. То же содержимое можно открыть в онлайн-версии.

## Перенесите тот же процесс в свою инфраструктуру [#self-host]

[Открытый репозиторий](https://github.com/dream-num/univer-workspace) включает Server и Web. По [инструкции развёртывания](https://github.com/dream-num/univer-workspace/blob/main/apps/workspace/README.md#docker) настройте домен, вход, постоянное хранение и окружение. Для разработки используются Node.js 24 и pnpm 11.

Укажите свой сервис в той же CLI и авторизуйте учётную запись в нём. Замените пример адреса реальным:

```bash
uvw config set workspace.origin https://workspace.example.com
uvw auth login
```

Инструменты и Skills агента остаются прежними, но действуют на файлы и права вашего сервиса. Desktop тоже может подключаться к нему. Регистрация клиента и обратные вызовы описаны в [руководстве Agent](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#connect-to-a-local-workspace).

## Откройте Workspace в локальном клиенте Desktop [#desktop-start]

**Workspace Desktop** объединяет Workspace, среду агента, инструменты Office и предпросмотр в локальном приложении. Это офисный процесс в духе Codex или Cowork: опишите цель, откройте документ или Web App рядом с диалогом, попросите исправления и проверьте результат.

Подключите Desktop к облаку, своему развёртыванию или локальному сервису Workspace. Модель и диалог предоставляет выбранный хост агента; файлы и доступ управляются подключённым Workspace. Ниже показан реальный настольный процесс создания, управления и совместной работы.

[Установка и подключение](#desktop-install) · [Первая задача: ревью бюджета в двух документах](#desktop-first-task)

### Агентный процесс для повседневной Office-работы [#why-desktop]

Результаты Office требуют дальнейшего редактирования, вычислений, совместной работы и ревью. Desktop объединяет эти этапы вокруг редактируемого общего содержимого.

- **Сохранение контекста:** диалог, файлы, материалы Workspace и локальные ссылки под рукой.
- **Нативный Office-контент и Web Apps:** создавайте, просматривайте и редактируйте таблицы, документы, презентации, Relational Tables и Canvases, а также интерактивные страницы на основе данных Office.
- **Просмотр и уточнение:** откройте результат рядом с диалогом, проверьте формулы и оформление, запросите правку.
- **Публикация после ревью:** изменения Office остаются в Worktree до проверки и слияния в общее пространство.

### От запроса к результату для ревью [#workflow]

Создавайте и меняйте документы Office и Web Apps в обычных диалогах, затем управляйте ими и делитесь доступом в Space. Нативные правки Office проверяются в Worktree перед слиянием. Публикация HTML и связанные записи используют собственные процессы сохранения и авторизации. Следующие диалоги могут обращаться к тем же файлам и данным.

### Что объединяет приложение

| Возможность | Работа пользователя |
| --- | --- |
| Сессии агента | Диалог и контекст задачи; локальная настройка провайдера, модели и ключей. |
| Файлы и ссылки | Доступные Spaces; @ для файлов и папок Workspace и локальных материалов. |
| Просмотр содержимого | Открывайте нативные Office-файлы или Web Apps рядом с диалогом для проверки содержимого, действий и данных. |

### Установка и подключение [#desktop-install]

В расширяемом агентском приложении можно установить и включить плагин Space, подключить сервис из Space, настроить модель и добавить оформление. Здесь показана такая композиция. Полное приложение Desktop и предварительный плагин распространяются по-разному; следуйте релизу или инструкции репозитория для своей версии.

1. Выберите Desktop в [GitHub Releases](https://github.com/dream-num/univer-workspace/releases): теги agent-v, Windows x64, macOS Apple Silicon или Linux x64. Поставка экспериментальная; ориентируйтесь на опубликованные версии.

2. В **Settings → Workspace** задайте сервис, войдите через браузер и разрешите доступ. Используйте готовый сервис или [локальную установку](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#connect-to-a-local-workspace).

3. В Models настройте поддерживаемого провайдера, модель и ключи. Это отдельно от входа Workspace: см. [настройку моделей](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#model-credentials).

4. Добавьте доступный Personal или Team Space, начните диалог и укажите материалы через @. Выполните задачу ниже и откройте просмотр и ревью.

Установщик содержит агентное приложение и Office-инструменты. Workspace запускается отдельно локально или на сервере; доступ к модели настраивается отдельно.

### Skills: от понимания пространства до выполнения задачи [#skills]

Эти Skills помогают вашему агенту создавать и редактировать содержимое Office и Web Apps в подключённом Workspace, затем передавать изменения на проверку. Сначала [подключите агента к Workspace](#cli-start); инструкции ниже работают с файлами и правами доступа этого сервиса.

#### Skills для вашего агента

Установленный в агенте [Skill `univer-workspace-cli`](https://github.com/dream-num/univer-workspace/blob/main/skills/univer-workspace-cli/SKILL.md) служит точкой обнаружения: подключение, поиск цели и загрузка инструкций. Полные Skills поставляются с CLI и соответствуют её командам и Facade API. Встроенный плагин Desktop также предоставляет инструкции и инструменты для задач.

| Инструкция | Охват |
| --- | --- |
| `core` | Поиск пространств и файлов, черновики задач, проверка и передача на ревью. |
| `sheet` · `doc` · `slide` · `base` · `board` | Таблицы, документы, презентации, Relational Table и Canvases. |
| `blob` | Загрузка, скачивание и замена исходных файлов. |
| `html-view` | Создание и управление живыми HTML-страницами для интерактивных Web Apps. |
| `embed` · `cross-unit-formula` | Встраивание содержимого и ссылки на данные и формулы между объектами. |

```bash
uvw skills list
uvw skills get core
uvw skills get sheet
uvw skills get html-view
```

Сначала загрузите `core`, затем нужный продукт или тему. `skills get` перечисляет пути, `uvw skills read <name> <path>` читает выбранный документ, `--full` включает их вместе. Существующие агенты используют CLI, а Desktop встраивает инструменты и инструкции в диалог.

#### Инструкции внутри Desktop [#desktop-skills]

Плагин включает Skill **univer** и справочники: поиск Spaces и документов, Office API, создание, проверка и передача Worktree. Агент может найти API, выполнить его над нативным содержимым и проверить результат.

[Плагин возможностей](https://github.com/dream-num/univer-workspace/blob/main/packages/dsh-univer-workspace-plugin/README.md) объединяет поиск файлов, редактирование через Headless Facade, структурную проверку, импорт/экспорт и управление Worktree. Эта предварительная версия готовит черновики к проверке; публикация использует процесс проверки и слияния развёрнутого приложения. На том же Office runtime можно добавлять отраслевые Skills, шаблоны и бизнес-инструменты.

Предварительный плагин включает девять Skills. Общая инструкция описывает поиск, идентификацию и передачу результата; инструкции продуктов содержат API и способы проверки. Агент читает материалы для текущей задачи.

| Skill | Инструкции |
| --- | --- |
| `univer` | Spaces, файлы, жизненный цикл черновика и передача |
| `univer-sheet` | Формулы, стили, диаграммы и проверка таблиц |
| `univer-doc` | Структура документа, абзацы и таблицы |
| `univer-slide` | Создание слайдов и визуальная проверка |
| `univer-base` | Поля, записи и представления |
| `univer-board` | Фигуры, соединители и компоновка холста |
| `univer-embed` | Встраивание одного продукта Office в другой |
| `univer-cross-unit-formula` | Ссылки и вычисления между Units |
| `univer-html-view` | Создание и проверка HTML-страниц, связанных с данными Office |

### Разделить цикл агента и возможности Office [#desktop-architecture]

Skills направляют агента, инструменты изменяют структурированный контент через Headless, а нативные редакторы отображают его людям. Workspace предоставляет файлы и контекст совместной работы. Можно сменить модель, добавить бизнес-инструменты или оформление, не создавая движок Office заново.

<Mermaid chart={"flowchart LR\nA[\"Агент и модель\"]\nB[\"Skills и инструменты\"]\nC[\"Office SDK<br/>Headless-операции и проверка\"]\nD[\"Сервис Workspace<br/>Файлы, совместная работа и версии\"]\nE[\"Просмотр на компьютере<br/>Редакторы и Web Apps\"]\nF[\"Worktree и Compare<br/>Проверка человеком\"]\nA --> B --> C --> D\nD <--> E\nD --> F\nF --> E"} />

| Компонент | Ответственность |
| --- | --- |
| [Web SDK](/guides/sheets) | Общие модели, Office-редакторы, рендеринг, формулы и headless Facade. |
| [Server SDK](/server) | Совместная работа, версии и Worktree, подключённые к backend приложения. |
| [AI SDK](/ai) | Операции с содержимым, инспекция и проверка для агентов. |
| Runtime и Skills | DSH предоставляет сессии, модели, оркестрацию и согласование; плагин подключает Office. |
| Workspace и Desktop | Приложение предоставляет Spaces, файлы, идентификацию и ревью; Electron — десктопную поставку. |

Повторно используемый путь: запрос → инструменты → редактируемое содержимое → просмотр → ревью → общий результат. Office SDK даёт Office-слой, хост — диалог и цикл выполнения. Расширяйте [приложение и плагины](https://github.com/dream-num/univer-workspace/tree/main/apps/agent) или подключайте свой хост.
