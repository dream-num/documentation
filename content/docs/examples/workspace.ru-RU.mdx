## Общие файлы задают контекст работы [#workspace-context]

![Общие файлы задают контекст работы](/assets/examples/workspace-desktop/workspace-overview.jpg)

В Space Aurora собраны операционная модель с формулами, записка для принятия решения, презентация, реестр задач и стратегическая схема. Web и Desktop подключаются к одним и тем же общим файлам. Агент читает исходные материалы и готовит изменения в Worktree; новый документ остаётся черновиком до одобренного человеком слияния. Создание и правки этого же примера показаны в разделе [диалога и предпросмотра Desktop](/docs/examples/workspace-desktop#conversation-preview).

## Workspace CLI: подключение любого агента [#cli-start]

После развёртывания онлайн-версии не нужна отдельная Office-интеграция для каждого агента. Установите CLI и Skill в его среду. Агент с выполнением команд сможет искать файлы, создавать и изменять содержимое, вычислять, делать снимки, проверять и передавать ссылки на ревью. Модель и диалог по-прежнему предоставляет выбранный агент.

Используйте Node.js 22.12 или новее, рекомендуется 24. npm-пакет `univer-workspace-cli` предоставляет команды `uvw` и `univer-workspace-cli` для одной программы.

```bash
npm install --global univer-workspace-cli@latest
npx skills add dream-num/univer-workspace --skill univer-workspace-cli -g
uvw --version
```

По умолчанию используется онлайн-демо. Для своего развёртывания задайте адрес сервиса:

```bash
uvw config set workspace.origin https://space.univer.ai
```

При первом подключении один раз выполните вход по указаниям CLI. Затем CLI управляет сессией и позволяет повторно использовать её между задачами. Не нужно создавать страницу входа, OAuth callback или отдельную интеграцию аутентификации для агента.

<details>

<summary>Первое подключение: один вход в браузере</summary>

Пропустите при наличии действующей сессии. Если нужен вход, выполните:

```bash
uvw auth login
```

Откройте ссылку, войдите и подтвердите код в браузере. Только после подтверждения пользователем выполните:

```bash
uvw auth login --complete
```

Этот шаг устанавливает сессию. Команды и подробности — в [руководстве Workspace CLI](https://github.com/dream-num/univer-workspace/blob/main/apps/cli/README.md).

</details>

## Skills: от понимания пространства до выполнения задачи [#skills]

Установленный в агенте [Skill `univer-workspace-cli`](https://github.com/dream-num/univer-workspace/blob/main/skills/univer-workspace-cli/SKILL.md) служит точкой обнаружения: подключение, поиск цели и загрузка инструкций. Полные Skills поставляются с CLI и соответствуют её командам и Facade API. Встроенный плагин Desktop также предоставляет инструкции и инструменты для задач.

| Инструкция | Охват |
| --- | --- |
| `core` | Поиск пространств и файлов, черновики задач, проверка и передача на ревью. |
| `sheet` · `doc` · `slide` · `base` · `board` | Таблицы, документы, презентации, Relational Table и Canvases; имена SDK/API остаются Base и Board. |
| `blob` | Загрузка, скачивание и замена исходных файлов. |
| `html-view` | Создание и управление живыми HTML-страницами для интерактивных Web Apps. |
| `embed` · `cross-unit-formula` | Встраивание содержимого и ссылки на данные и формулы между объектами. |

```bash
uvw skills list
uvw skills get core
uvw skills get sheet
uvw skills get html-view
```

Сначала загрузите `core`, затем нужный продукт или тему. `skills get` перечисляет пути, `uvw skills read <name> <path>` читает выбранный документ, `--full` включает их вместе. Существующие агенты используют CLI, а Desktop встраивает инструменты и инструкции в диалог.

## От Office-документов к Web Apps [#web-apps]

Помимо таблиц, документов, презентаций, реляционных таблиц и холстов можно создавать Web Apps на их данных: бизнес-панели, интерактивные отчёты, бюджетные симуляторы и рабочие страницы. HTML View и двусторонняя привязка связывают показатели, диаграммы, поля и ползунки с таблицами. Страница обновляет данные, их изменения возвращаются на страницу, возможно подключение совместной работы.

## Связать запрос, изменения и проверку

Workspace CLI также предоставляет `uvw issue` и `uvw pr`. Issues содержат запросы команды и обсуждения; PR содержат изменения для проверки и основаны на Worktree. Агент может прочитать задачу, изменить родное содержимое, проверить его и передать изменения человеку, связывая запросы команды с Office-результатами.

## Проверьте черновик перед слиянием [#agent-review]

Эту же записку можно открыть в Workspace: видны состояние Ready, список изменённых файлов и нативное представление документа. Переключайтесь между View и Compare, чтобы проверить результат и изменения, а затем решить, выполнять ли слияние. Завершение задачи агента не изменяет общие исходные файлы автоматически.

## Роль Office SDK [#sdk-integration]

Web SDK даёт общую модель, редакторы, отрисовку и безынтерфейсную обработку; Server SDK — совместную работу, версии и Worktree; AI SDK — операции и проверку для агентов. Workspace собирает их в развёртываемый Server и онлайн-приложение. CLI открывает возможности существующим агентам, Desktop объединяет их в Office-приложение с агентом.
