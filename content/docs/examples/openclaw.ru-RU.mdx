**Univer Office for OpenClaw** (`openclaw-univer-office`) подключает OpenClaw к возможностям Workspace на **[Univer Office SDK](/docs/overview)**. Агент находит личные и командные файлы, редактирует и проверяет черновики и возвращает ссылки для проверки, изображения или экспортированные файлы.

[Установка и подключение](#quick-start) · [Пробная задача](#first-task) · [Skills и инструменты](#skills)

## Установка и подключение [#quick-start]

Подготовьте OpenClaw 2026.5.17 или новее, Node.js 22.22.3 или новее и доступ к Univer Workspace. Установите следующее на машине Gateway. В примере закреплена Workspace CLI 0.5.3, совместимая с командами текущего плагина.

### 1. Установите CLI и плагин

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

Используется `@dr-univer/openclaw-univer-office` из ClawHub. Отдельная установка локальной `univer-cli` не нужна.

### 2. Включите инструменты и подключите сервис

Объедините эти параметры с конфигурацией OpenClaw, сохранив существующие разрешения. Если `tools.allow` уже задан, добавьте `univer-office` к его списку:

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

Укажите CLI адрес вашего Workspace. Ниже используется онлайн-демо; при собственном развёртывании замените адрес. После настройки перезапустите Gateway.

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. Войдите из разговора

Отправьте OpenClaw:

```text
Подключись к Univer Workspace и проверь, выполнен ли вход. Если нужен вход, дай ссылку браузерного подтверждения и код, затем дождись, пока я закончу.
```

Откройте ссылку на телефоне или компьютере, войдите и подтвердите код. Сообщите OpenClaw о завершении и одобрите действие завершения входа. Плагин не заменяет ваше подтверждение повторными запросами. Используйте в онлайн-демо примерные данные.

### Что вы увидите

В чате появятся описание результата и ссылка. Браузеры телефона и компьютера откроют один черновик Workspace. Редактор и полное ревью остаются в Workspace, а чат может передавать ход работы, изображения и экспортированные файлы. Отметка готовности не меняет текущую версию файла.

### Продолжить знакомство

Для совместной работы выберите существующее Team Space и явно запросите черновик, видимый его участникам. OpenClaw запросит нужное одобрение. Участники должны войти в систему и состоять в этом пространстве; ссылка сама по себе не даёт доступа.

## Как работают Skills и инструменты [#skills]

Плагин включает [Skill `univer-office`](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md). Агент находит пространства через `univer_office_connect` и `univer_office_files`, загружает общие и продуктовые инструкции действием `guidance`, изучает Facade, редактирует и проверяет. Workspace размещает содержимое, права, совместную работу и Worktree Office SDK; OpenClaw отвечает за каналы, одобрения и передачу файлов.

## Что можно создавать

- **Командные материалы из чата:** Находите разрешённые пространства и файлы и работайте с существующими таблицами, документами, презентациями, реляционными таблицами и холстами.
- **Совместные черновики:** Редактируйте изолированный Worktree. При командной проверке создайте черновик, видимый участникам пространства.
- **Проверка и передача между устройствами:** Проверьте структуру, снимки и макет, затем верните ссылку Workspace для мобильного или настольного браузера.
- **Решение остаётся за людьми:** После готовности человек выбирает слияние или отклонение. Изображения и экспортированные файлы передаются через каналы сообщений и файлов OpenClaw.

## Роль Office SDK [#sdk-integration]

Плагин вызывает операции и проверки через Workspace CLI. Workspace Server содержит контент, совместную работу, версии и Worktree Office SDK и применяет идентификацию и разрешения. OpenClaw отвечает за разговоры, каналы и подтверждения; полное редактирование и проверка остаются в Workspace. Агент может работать локально, пока команда использует один сервис.
