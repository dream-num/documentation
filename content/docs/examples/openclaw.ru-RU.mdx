**Univer Office для OpenClaw** (`openclaw-univer-office`) соединяет OpenClaw с функциями Workspace, встроенными в **[Univer Office SDK](/overview)**. Агент может находить файлы в Личном и Командном Пространствах, редактировать и проверять черновик задач, а также возвращать ссылку на обзор, предварительный просмотр изображений или экспортированные файлы.

## Установка и подключение [#quick-start]

Вам нужен OpenClaw 2026.5.17 или новее, Node.js 22.22.3 или новеее, и доступ к службе Univer Workspace. Запустите следующие команды на хосте OpenClaw Gateway. Этот пример выводит Workspace CLI 0,5.3 в соответствие с командным интерфейсом текущего плагина.

### 1. Установите CLI и плагин

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

Плагин опубликован на ClawHub под названием `@dr-univer/openclaw-univer-office`. Отдельная локальная установка `univer-cli` не требуется.

### 2. Включите инструменты и подключите сервис

Добавьте следующие настройки в конфигурацию OpenClaw и сохраните существующие разрешения на использование инструмента.Если `tools.allow` уже существует, добавьте `univer-office` в этот список:

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

Направьте CLI на сервис Workspace. В приведенном ниже примере используется онлайн-демоверсия, поэтому для самостоятельного развертывания требуется другой адрес. Перезагрузите шлюз после изменения конфигурации.

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. Войдите из разговора

Отправьте следующее сообщение OpenClaw:

```text
Подключись к Univer Workspace и проверь, выполнен ли вход. Если нужен вход, дай ссылку браузерного подтверждения и код, затем дождись, пока я закончу.
```

Откройте обратную ссылку на телефоне или компьютере, войдите и подтвердите код. Затем сообщите OpenClaw, что вход завершен и одобрите его действие по завершению входа. Плагин не проводит опрос вместо того одобрения, которое должно прийти от вас. На онлайн-демо используйте данные выборки.

### Что вы увидите

Чат возвращает резюме результата и ссылку на обзор. Ссылка открывает тот же проект Workspace в браузере телефона и на рабочем столе. Нативный редактор и полный интерфейс обзора остаются в Workspace, а канал чата доставляет прогресс, предварительные изображения и экспортированные файлы. Маркировка готового черновика оставляет текущий файл без изменений.

### Продолжить знакомство

Для совместной работы в режиме реального времени выберите существующее командное пространство и явно запросите проект, который виден в пространстве. OpenClaw запрашивает одобрение, которое этого требует. Сотрудники должны быть подписаны членами этого пространства; одна общая ссылка не дает доступа.

## Как работают Skills и инструменты [#skills]

Плагин объединяет [Навыки `univer-office`](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md). Агент находит Пространства с `univer_office_connect` и `univer_office_files`, загружает ядро и руководство по продукту через действие `guidance` инструмента контента, затем просматривает API-интерфейсы Facade, делает правки и проверяет результат. Workspace размещает контент Office SDK, авторизацию, сотрудничество и Worktrees. OpenClaw управляет каналами чата, одобрениями инструментов и доставкой файлов.

## Что можно создавать

- Доступ к командному контенту из чата: найдите и просмотрите Пространства и файлы, для которых вы авторизованы, а затем работайте над существующими таблицами, документами, презентациями, реляционными таблицами и холстами.
- Сотрудничайте над задачами: редактируйте в изолированном Worktree и создайте черновик, видимый Пространству, когда товарищи по команде должны просматривать вместе.
- Проверяйте и доставляйте на разных устройствах: проверяйте структуру, скриншоты и макет, а затем возвращайте ссылку на обзор рабочего пространства, которая открывается в браузере телефона или рабочего стола.
- Сохраняйте решения с людьми: помеченный результат по-прежнему требует, чтобы человек выбрал слияние или отбрасывание.Предварительные изображения и экспортируемые файлы доставляются через сообщения OpenClaw и файловые каналы.

## Роль Office SDK [#sdk-integration]

Плагин вызывает авторизацию и проверку через Workspace CLI. Workspace Server размещает контент Office SDK, совместную работу, версии и Worktrees и обеспечивает идентификацию и разрешения. OpenClaw управляет разговором, каналами и одобрениями инструментов; полное редактирование и обзор остаются в Workspace. Терминал агента может работать локально, в то время как команда сотрудничает через одну службу.
