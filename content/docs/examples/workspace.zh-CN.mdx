Univer Workspace 是基于 **[Univer Office SDK](/docs/overview)** 构建的开源办公应用，面向人类与 Agent 共同工作的场景。你可以部署包含 **Server 与 Web** 的在线版本，让团队直接在浏览器中办公，再通过 **Workspace CLI + Skills** 接入自己正在使用的 Agent；也可以使用 **Workspace Desktop**，在一个应用中获得 Agent 对话、内容生成、预览和审阅体验。

## 在线版：Server 与 Web 组成完整工作区 [#entry-points]

<span id="web-start" />

**Workspace Server** 管理个人与团队空间、文件目录、权限、内容存储、协同和版本；**Web 是它的在线办公界面**，让团队在浏览器中编辑、共同工作和审阅 Agent 的修改。将这一套应用部署好，人和 Agent 就能围绕同一份内容工作。

## Workspace CLI：让任意 Agent 进入工作区 [#cli-start]

在线版部署后，不需要再为每一种 Agent 开发一套 Office 集成。把 Workspace CLI 与 Skill 安装到 Agent 的运行环境，具备命令执行能力的 Agent 就可以查找文件、创建和修改内容、计算、截图、检查结果，并交付审阅链接。模型与对话仍由你选择的 Agent 提供。

使用 Node.js 22.12 或更新版本，推荐 24。npm 包名为 `univer-workspace-cli`，同时提供 `uvw` 和 `univer-workspace-cli` 两个命令名。

```bash
npm install --global univer-workspace-cli@latest
npx skills add dream-num/univer-workspace --skill univer-workspace-cli -g
uvw --version
```

默认连接在线体验服务。接入自己部署的 Workspace 时，只需设置服务地址：

```bash
uvw config set workspace.origin https://space.univer.ai
```

首次连接按 CLI 提示完成一次登录，之后由 CLI 管理会话，Agent 可以在后续任务中复用。你不需要为 Agent 编写登录页面、OAuth 回调或单独的鉴权集成。

<details>

<summary>首次连接：完成一次浏览器登录</summary>

已有有效会话时可跳过。需要登录时执行：

```bash
uvw auth login
```

打开返回的链接，在浏览器中登录并确认验证码。用户确认完成后，再执行：

```bash
uvw auth login --complete
```

这一步只在需要建立会话时进行。完整命令与认证说明见 [Workspace CLI 指南](https://github.com/dream-num/univer-workspace/blob/main/apps/cli/README.md)。

</details>

## Workspace Desktop：开箱即用的 Agent 办公环境 [#desktop-start]

Desktop 将 **Agent + Workspace** 整合到一个桌面应用中：对话、文件目录、资料引用、Office 预览和变更审阅在同一个界面完成。你不必先选择并配置另一个 Agent 宿主，再把 Office 工具接进去。

- **连接在线工作区：** 连接团队已经部署的 Workspace 服务，让 Agent 使用共享资料并生成可共同审阅的成果。
- **本地使用：** 连接本机运行的 Workspace 服务，在自己的电脑上组织内容、生成文档和审阅修改。本机服务的启动方式见[本地部署说明](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#connect-to-a-local-workspace)。

[Windows x64](https://github.com/dream-num/univer-workspace/releases/download/agent-v0.1.0/Univer-Workspace-Agent-0.1.0-win-x64.exe) · [macOS Apple Silicon](https://github.com/dream-num/univer-workspace/releases/download/agent-v0.1.0/Univer-Workspace-Agent-0.1.0-mac-arm64.dmg) · [Linux x64](https://github.com/dream-num/univer-workspace/releases/download/agent-v0.1.0/Univer-Workspace-Agent-0.1.0-linux-x86_64.AppImage)

下载安装后，在设置中选择 Workspace 服务，并按引导连接账户。用 `@` 引用本地资料或工作区中的文件、目录，再描述需要的成果。

**模型由你选择。** 在 Models 设置中配置所需模型服务、模型和凭据，让它驱动内容生成与自动化。模型配置与 Workspace 连接分别管理；同一个办公环境可以按任务使用合适的模型。详见[模型配置说明](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#model-credentials)。

## Skills：让 Agent 理解工作区并完成任务 [#skills]

安装给已有 Agent 的 [`univer-workspace-cli` Skill](https://github.com/dream-num/univer-workspace/blob/main/skills/univer-workspace-cli/SKILL.md) 是发现入口，告诉它如何连接 Workspace、定位目标并加载操作指引。完整的运行时 Skills 随 CLI 发布，与命令和 Facade API 版本配套；Desktop 的内置能力插件也提供面向任务的指引和工具。

| 指引 | 覆盖内容 |
| --- | --- |
| `core` | 空间与文件定位、任务草稿、内容检查和审阅交付。 |
| `sheet` · `doc` · `slide` · `base` · `board` | 电子表格、文档、演示文稿、关系型表格（Relational Table）与画布（Canvases）；SDK/API 保留 Base、Board。 |
| `blob` | 原始文件上传、下载与替换。 |
| `html-view` | 生成并管理实时 HTML 页面，构建可交互的 Web App。 |
| `embed` · `cross-unit-formula` | 嵌入其他内容，以及跨内容的数据引用与公式。 |

```bash
uvw skills list
uvw skills get core
uvw skills get sheet
uvw skills get html-view
```

先加载 `core`，再按任务读取产品或主题。`skills get` 会列出参考路径，使用 `uvw skills read <name> <path>` 读取所需文档，或用 `--full` 一并读取。已有 Agent 通过 CLI 使用这些能力，Desktop 则把相关工具和指引整合进对话流程。

## 从一份可计算、可审阅的文档开始 [#first-task]

```text
在我的 Workspace 个人空间中创建一个英文月度开销表，包含日期、类别、金额和 5 条示例数据，添加总额公式及分类图表。
把修改放在独立草稿中，检查数据、公式和显示效果，给我预览或审阅链接，在我确认前不要合入。
```

## 从办公文档到 Web App [#web-apps]

除电子表格、文档、演示文稿、关系型表格和画布外，还可以让 Agent 生成基于这些内容的 Web App：经营看板、交互式报告、预算模拟器或业务操作页面。通过 HTML View 和双向绑定，把指标、图表、输入框或滑块连接到表格；页面操作更新数据，数据变化也反馈到页面，并可接入协同。

```text
基于刚才的开销表，生成一个简洁的预算看板 Web App：显示总额、分类图表和一个预算输入框，把显示与输入绑定到表格数据。检查页面与表格的联动，给我预览和审阅入口。
```

## 把需求、修改和审阅串起来

Workspace CLI 还提供 `uvw issue` 和 `uvw pr`：Issue 承载团队需求与讨论，PR 承载待审阅的变更，其底层是 Worktree。Agent 可以读取任务、操作原生内容、检查结果，再交付供人审阅的变更。这个过程可以连接团队任务与办公成果。

## Office SDK 如何支撑 [#sdk-integration]

Web SDK 提供统一内容模型、编辑器、渲染与 Headless 处理；Server SDK 支撑协同、版本和 Worktree；AI SDK 提供面向 Agent 的操作与检查能力。Workspace 将这些能力组成可部署的 Server 与在线版，CLI 将它们开放给已有 Agent，Desktop 则整合成可以直接使用的 Agent 办公应用。
