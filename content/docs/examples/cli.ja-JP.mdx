**Univer クリップ**は、**[Univer Office SDK](/overview)**上に構築されたローカルオフィスオートメーションアプリケーションです。 既に使用しているエージェントにコンテンツコマンドとスキルを追加します。 これらの追加では、エージェントは、既存のExcel、Word、PowerPointファイルと連携し、スプレッドシート、文書、プレゼンテーション、リレーショナルテーブル、キャンバスを作成することができます。 結果はあなたのマシンに残ります。

**CLI (Command-Line Interface) は、現在 Univer を操作するための主要な方法です。** これは、エージェントの統合に以前のMCP-firstアプローチを置き換えます。 Univer CLIは、`univer`コマンドとスキルを提供します。 エージェントは、独自のコマンド実行ツールを使用して、コンテンツを編集、検査、および配信し、ローカルビューアで実行およびレビューを行います。

## 使い慣れたエージェントで利用する

Univer CLIは、以下のエージェントをサポートしています。

**OpenCode** · **Claude Code** · **OpenClaw** · **Hermes** · **Codex** · **WorkBuddy** · **Kimi Work**

これらのエージェントは、インストールされたバージョンにマッチする`univer`コマンドと操作ガイドを共有します。Agent Skillsのサポートを持つホストは、公式のスキルをロードし、コマンドを実行できるエージェントは、独自のツールレイヤーを介してUniverを呼び出すこともできます。会話プレビューカードなどのホスト固有の機能は、[統合プロジェクト](https://univer.ai/ecosystem)で覆われています。

## 最初の成果物を開く [#quick-start]

Univer CLIはNode.js 24またはnewerが必要です。エージェントが実行する環境にインストールしてください。

```bash
npm install --global univer-cli@latest
npx skills add dream-num/skills -s univer-cli -g
univer doctor
```

`univer doctor`はローカルランタイムをチェックします。 スキルを通して、エージェントはコマンドを発見し、特定の製品に対するガイダンスをロードし、コンテンツを検査し、結果を配信します。

### 公式サンプルを開く

新しい空のディレクトリでは、次の指示をエージェントに送信します。

```text
Univer CLI で公式サンプルを試してください。
https://univer.ai/cli-assets/hello.univer を現在のフォルダーの hello.univer に保存してください。
内容を一覧にし、ローカル Viewer のリンクと試せる機能を教えてください。
```

既存のコンテンツを開くと、ネイティブエディタがすぐに表示されます。エージェントにそのコンテンツを修正したり、以下の作成タスクを試すことができます。

## Skills：エージェント向け操作ガイド [#skills]

これらのスキルは、既存のエージェントがUniver CLIを通じてOfficeコンテンツを作成、編集、およびチェックできるようにします。 まず、[CLIとその発見スキルをインストール](#quick-start)は、以下のタスク固有のガイダンスをロードします。

スキルは、エージェントが読むことができるガイダンスとして製品の一部を提示します。コンテンツモデル、編集ワークフロー、ファサード API の検索方法、検証の要件。それに基づいて、エージェントは、最初の編集からレビューと配信まで、タスクのニーズを機能するかを決定します。

**ディスカバリーエントリー:** エージェントにインストールされた[`univer-cli` スキル](https://github.com/dream-num/skills/blob/main/skills/univer-cli/SKILL.md)は、オフィスタスクを認識し、ローカル CLIからの完全なガイダンスをロードするのに役立ちます。

**ランタイムスキル:** これらは、CLI で出荷し、インストールされたコマンドとファサード API と一致します。`core`を最初にロードし、ターゲット製品。タスクが埋め込むか、クロスコンテンツの式を伴うときにトピックスキルを追加します。

### タスクに合わせて読み込む [#load-skills]

ほとんどの場合、エージェントはこのガイダンスを自分で読みます。 開発者はまた、直接それを検査することができます。

```bash
univer skills list
univer skills get core
univer skills get sheet
univer skills path sheet
```

`list`は、インストールされたスキル、`get`読み取りガイダンス、`path`がローカルディレクトリを返します。 `univer skills get core --full`には、参照とテンプレートが含まれています。 `univer api find`と`univer api show`を使用して、特定のAPIを調べます。

### Skills 一覧 [#skills-catalog]

ソースリポジトリでガイドを参照する名前に従ってください。 実際のタスクでは、ローカル`univer skills get <name>`コマンドで返されたバージョンを使用します。

| Skill | 用途 |
| --- | --- |
| [`core`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/core/SKILL.md) | 共有ワークフロー:ユニットとワークツリーを理解し、コンテンツを見つけて編集し、それを検証し、それをレビューのために提出します。 |
| [`sheet`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/sheet/SKILL.md) | スプレッドシート（Sheet）：データ、数式、書式、グラフ、結果の検証。 |
| [`doc`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/doc/SKILL.md) | ドキュメント（Doc）：段落、リッチテキスト、表、グラフ、ページレイアウト。 |
| [`slide`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/slide/SKILL.md) | プレゼンテーション(スライド):ページ、図形、テキスト、画像、およびビジュアルチェック。 |
| [`base`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/base/SKILL.md) | Relational Table：テーブル、フィールド、レコード、ビュー。 |
| [`board`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/board/SKILL.md) | キャンバス:キャンバス要素、チャート、レイアウトチェック。 |
| [`embed`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/embed/SKILL.md) | Embeds: 1つのユニットからコンテンツを別のユニットに配置し、チャートのデータソースを接続します。 |
| [`cross-unit-formula`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/cross-unit-formula/SKILL.md) | コンテンツ間数式：Sheet の範囲や Relational Table のフィールドを参照し、Sheet セルや数式を持つ図形で計算。 |

たとえば、スプレッドシートを文書に埋め込むには、`core → doc + sheet → embed`をロードします。 シートセルまたはその他のコンテンツからのデータを参照する際`cross-unit-formula`を追加します。 事前にすべてのガイドを読み込みます。 クリップを更新した後、`core`をリロードし、使用する製品とトピックのスキルをリロードします。

## できること

- データを配信可能にします。シートを清掃し、式を書き、チャートとピボットテーブルを追加し、ヘッダとフッターでレポートをレイアウトしたり、輪郭からプレゼンテーションを作成したりします。
- コンテンツが接続されているまま: 1 つの `.univer` ファイルは、数式、チャートの参照、および埋め込むことによってリンクされた複数のコンテンツタイプを保持することができます。
- 結果を確認します: ファサードを介して実際のコンテンツモデルを読み、スクリーンショットとプレゼンテーションのレイアウトチェックを使用して、オーバーフロー、重複、またはページをオフにテキストを検索します。
- 配信前のレビュー: エージェントは、分離したWorktreeで動作し、ローカルビューアリンクを返します。 違いを調べ、要求の修正、結果をマージまたは破棄し、サポートされているOfficeフォーマットをエクスポートします。 キャンバスファイルインポートとエクスポートはまだ使用できません。

## こんなタスクを試す

> Univer CLIを使用して、日付、カテゴリ、および量、および5つのサンプル行で毎月の費用シートを作成します。 カテゴリ別にまとめられた合計式とチャートを追加します。 データとレンダリングされた結果をチェックし、ビューアリンクを与え、私のレビューの前にマージしません。

## Office SDK が担う部分

Office SDKは、ヘッドレスコンテンツのランタイム、Facade API、計算、レンダリング、バージョン、およびWorktreesを提供します。 CLIは、これらの機能をターミナルコマンドとバージョンマッチングスキルに組み込んでおり、ローカル`.univer`ストレージ、ゲートウェイ、ビューアを所有しています。エージェントが書き込みするコンテンツは、エディタのプレビューや標準ファイル配信に直接移動できます。
