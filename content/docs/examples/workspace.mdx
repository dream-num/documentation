Univer Workspace is an open-source Office application built with **[Univer Office SDK](/docs/overview)** for people and agents working together. Deploy the online edition, consisting of **Server and Web**, let your team work in the browser, and connect your existing agents through **Workspace CLI + Skills**. Or use **Workspace Desktop** for agent conversations, content generation, previews, and review in one application.

## Workspace CLI: bring any agent into the workspace [#cli-start]

Once the online edition is deployed, you do not need a separate Office integration for every agent. Install Workspace CLI and the Skill where your agent runs. Agents with command execution can find files, author content, calculate, capture screenshots, verify results, and return review links. Your chosen agent continues to provide the model and conversation.

Use Node.js 22.12 or newer, preferably 24. The npm package is `univer-workspace-cli`; it provides both `uvw` and `univer-workspace-cli` as names for the same program.

```bash
npm install --global univer-workspace-cli@latest
npx skills add dream-num/univer-workspace --skill univer-workspace-cli -g
uvw --version
```

The default connection is the online demo. To use your own deployment, set its service address:

```bash
uvw config set workspace.origin https://space.univer.ai
```

Complete the CLI’s sign-in flow once when first connecting. The CLI manages the session so your agent can reuse it across tasks. You do not need to build an agent-specific sign-in page, OAuth callback, or authentication integration.

<details>

<summary>First connection: sign in once in the browser</summary>

Skip this when a valid session already exists. If sign-in is required, run:

```bash
uvw auth login
```

Open the returned link, sign in, and confirm the code in your browser. Only after the user confirms completion, run:

```bash
uvw auth login --complete
```

This step is needed when establishing a session. See the [Workspace CLI guide](https://github.com/dream-num/univer-workspace/blob/main/apps/cli/README.md) for full commands and authentication details.

</details>

## Workspace Desktop: an integrated agent Office environment [#desktop-start]

Desktop combines **agent + Workspace** in one desktop application: conversation, files, source references, Office previews, and change review share one interface. You can start without choosing another agent host and connecting Office tools to it first.

- **Connect to an online workspace:** Use your team’s deployed Workspace service so the agent can work with shared material and produce results for collaborative review.
- **Work locally:** Connect to a Workspace service running on your own machine to organize content, generate documents, and review changes locally. See [local setup](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#connect-to-a-local-workspace) for starting that service.

[Windows x64](https://github.com/dream-num/univer-workspace/releases/download/agent-v0.1.0/Univer-Workspace-Agent-0.1.0-win-x64.exe) · [macOS Apple Silicon](https://github.com/dream-num/univer-workspace/releases/download/agent-v0.1.0/Univer-Workspace-Agent-0.1.0-mac-arm64.dmg) · [Linux x64](https://github.com/dream-num/univer-workspace/releases/download/agent-v0.1.0/Univer-Workspace-Agent-0.1.0-linux-x86_64.AppImage)

After installation, choose your Workspace service in settings and follow the account connection flow. Use `@` to reference local material or Workspace files and folders, then describe the result you need.

**Choose your model.** Configure the desired model provider, model, and credentials in Models settings to drive generation and automation. Model configuration and the Workspace connection are managed separately, so the same Office environment can use an appropriate model for the task. See [model configuration](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#model-credentials).

## Skills: help agents understand the workspace and complete tasks [#skills]

The [`univer-workspace-cli` Skill](https://github.com/dream-num/univer-workspace/blob/main/skills/univer-workspace-cli/SKILL.md) installed in your existing agent is the discovery entry: it explains how to connect, locate the target, and load operational guidance. Full runtime Skills ship with the CLI and match its commands and Facade APIs. Desktop’s built-in capability plugin also provides task guidance and tools.

| Guidance | Coverage |
| --- | --- |
| `core` | Locate Spaces and files, work in task drafts, verify content, and hand off for review. |
| `sheet` · `doc` · `slide` · `base` · `board` | Spreadsheets, documents, presentations, Relational Table, and Canvases; Base and Board remain the SDK/API names. |
| `blob` | Upload, download, and replace original files. |
| `html-view` | Create and manage live HTML pages for interactive Web Apps. |
| `embed` · `cross-unit-formula` | Embed other content and connect data and formulas across content types. |

```bash
uvw skills list
uvw skills get core
uvw skills get sheet
uvw skills get html-view
```

Load `core` first, then the product or topic needed for the task. `skills get` lists reference paths; use `uvw skills read <name> <path>` for a selected document or `--full` to include them together. Existing agents access these capabilities through the CLI, while Desktop integrates its tools and guidance into the conversation workflow.

## From Office documents to Web Apps [#web-apps]

Beyond spreadsheets, documents, presentations, relational tables, and canvases, ask the agent to create Web Apps around that content: business dashboards, interactive reports, budget simulators, or operational pages. HTML Views and two-way binding connect metrics, charts, inputs, and sliders to spreadsheets. Page interactions update the data, data changes flow back to the page, and collaboration can keep them connected.

## Connect the request, changes, and review

Workspace CLI also exposes `uvw issue` and `uvw pr`. Issues hold team requests and discussion; PRs carry changes for review and are backed by Worktrees. An agent can read the task, edit native content, verify it, and deliver changes for a person to review, connecting team requests to Office deliverables.

## How Office SDK powers it [#sdk-integration]

Web SDK provides the shared content model, editors, rendering, and headless processing; Server SDK supports collaboration, versions, and Worktrees; AI SDK supplies agent-facing operations and verification. Workspace composes them into a deployable Server and online application. The CLI opens those capabilities to existing agents, while Desktop delivers an integrated agent Office application.
