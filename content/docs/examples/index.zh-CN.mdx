下列开源项目都是基于 **[Univer Office SDK](/overview)** 构建的应用与集成：它们可以用 Agent 自动处理本地 Office 文件，在团队空间中协同编辑，或在已有的 Agent 对话中创建、预览和审阅成果。

Workspace 和 CLI 是完整应用。Office Copilot 是一个可运行的参考应用，用于构建应用内办公助手。DeepSeek Harness、WorkBuddy 和 OpenClaw 是接入对应 Agent 宿主的 Office 集成插件。

## Workspace [#univer-workspace]

<span id="univer-workspace-desktop" />

该项目是一个使用 Office SDK 构建的开源办公空间。你可以使用云端服务，也可以私有部署。已有 Agent 通过 Workspace CLI 接入；如需对话、实时预览和协作审阅，可使用 Desktop。

[查看项目说明](/overview/examples/workspace) · [在线体验](https://space.univer.ai) · [源码仓库](https://github.com/dream-num/univer-workspace) · [Desktop 体验](/overview/examples/workspace#desktop-start)

## Office Lab [#office-lab]

Office Lab 是一个类似 GitHub 的办公协作案例。产品与研发通过需求文档、Issue、Worktree PR、原生内容比较、可交互原型和排期，共同推进同一个项目。

[查看协作案例](/overview/examples/office-lab) · [源码仓库](https://github.com/dream-num/univer-workspace)

## Office Copilot [#office-copilot]

Office Copilot 是一个编辑器与聊天并排的开源 Web 应用，可作为构建自有 Office Copilot 的起点。它提供六个可编辑示例；接入模型后，可针对五类产品调整直接编辑、协作、历史和分享。

[查看项目说明](/overview/examples/copilot) · [快速开始](https://github.com/dream-num/univer-office-copilot#quick-start) · [源码仓库](https://github.com/dream-num/univer-office-copilot)

## CLI [#univer-cli]

CLI 为 OpenCode、Claude Code、OpenClaw、Hermes、Codex、WorkBuddy、Kimi Work 等 Agent 提供本地 Office 能力。安装 CLI 和 Skill 并打开官方样例后，即可创建自己的结果并检查。

[查看项目说明](/overview/examples/cli) · [快速体验指南](https://github.com/dream-num/univer-cli#quick-start) · [源码仓库](https://github.com/dream-num/univer-cli)

## DeepSeek Harness 插件 [#deepseek-harness]

该插件提供对话式 Office 体验。你说明要完成的任务，实时窗口展示工作过程，最后可以在同一个对话中审阅、修改并交付结果。

[查看项目说明](/overview/examples/deepseek-harness) · [观看演示](https://www.youtube.com/watch?v=k-2zW_CMiew) · [源码仓库](https://github.com/dream-num/dsh-univer-office)

## WorkBuddy 插件 [#workbuddy]

该插件涵盖 MCP 与 Agent 宿主集成，将本地 Office 文件、宿主内的只读预览和浏览器中的版本审阅串联为一条工作流。目前该插件为开发预览。

[查看项目说明](/overview/examples/workbuddy) · [查看工作流程](https://github.com/dream-num/workbuddy-univer-office#workflow) · [源码仓库](https://github.com/dream-num/workbuddy-univer-office)

## OpenClaw 插件 [#openclaw]

该插件可接入已有的 OpenClaw 工作流。你从聊天中发起团队文件任务，在 Workspace 草稿上编辑和检查，最后返回一个可在手机和电脑上审阅的结果。

[查看项目说明](/overview/examples/openclaw) · [查看工作流程](https://github.com/dream-num/openclaw-univer-office#typical-request) · [源码仓库](https://github.com/dream-num/openclaw-univer-office)
