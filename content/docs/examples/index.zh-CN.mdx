这些开源项目把 **[Univer Office SDK](/docs/overview)** 变成可以直接使用的应用：在本地交给 Agent 自动处理 Office 文件，在团队空间共同编辑，或从已有的 Agent 对话中创建、预览和审阅成果。

Workspace 与 CLI 是完整应用；DeepSeek Harness、WorkBuddy 与 OpenClaw 这三项是接入对应 Agent 宿主的 Office 集成插件。

## Workspace [#univer-workspace]

<span id="univer-workspace-desktop" />

基于 Office SDK 构建的开源办公空间。先用云端试用或进行私有部署，再通过 Workspace CLI 接入已有 Agent，也可以在 Desktop 中完成对话、预览与协作审阅。

[查看项目说明](/docs/examples/workspace) · [在线体验](https://space.univer.ai) · [源码仓库](https://github.com/dream-num/univer-workspace) · [Desktop 体验](/docs/examples/workspace#desktop-start)

## Office Lab [#office-lab]

类似 GitHub 的办公协作案例：产品与研发用需求文档、Issue、Worktree PR、原生内容比较、可交互原型和排期推进同一个项目。

[了解 Workspace](/docs/examples/office-lab) · [源码仓库](https://github.com/dream-num/univer-workspace)

## CLI [#univer-cli]

给 OpenCode、Claude Code、OpenClaw、Hermes、Codex、WorkBuddy、Kimi Work 等 Agent 接入本地 Office 能力。安装 CLI 和 Skill 后，先打开官方样例，再让 Agent 创建与检查自己的成果。

[查看项目说明](/docs/examples/cli) · [快速体验指南](https://github.com/dream-num/univer-cli#quick-start) · [源码仓库](https://github.com/dream-num/univer-cli)

## DeepSeek Harness 插件 [#deepseek-harness]

适合观察对话式 Office 的完整体验：一句话发起任务，实时窗口跟随生成过程，最后在同一对话中审阅、修改和交付。

[查看项目说明](/docs/examples/deepseek-harness) · [观看演示](https://www.youtube.com/watch?v=k-2zW_CMiew) · [源码仓库](https://github.com/dream-num/dsh-univer-office)

## WorkBuddy 插件 [#workbuddy]

适合参考 MCP 与 Agent 宿主集成：本地 Office 内容、宿主内只读预览和浏览器版本审阅组成一条工作流。当前为开发预览。

[查看项目说明](/docs/examples/workbuddy) · [查看工作流程](https://github.com/dream-num/workbuddy-univer-office#workflow) · [源码仓库](https://github.com/dream-num/workbuddy-univer-office)

## OpenClaw 插件 [#openclaw]

适合已有的 OpenClaw 工作流：从聊天发起团队文件任务，经 Workspace 草稿与检查后，把可跨手机和电脑审阅的结果交付回来。

[查看项目说明](/docs/examples/openclaw) · [查看工作流程](https://github.com/dream-num/openclaw-univer-office#typical-request) · [源码仓库](https://github.com/dream-num/openclaw-univer-office)
