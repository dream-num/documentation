**OpenClawのUniverオフィス**(`openclaw-univer-office`)は、OpenClawを**[Univer Office SDK](/overview)**で構築されたワークスペース機能に接続します。 エージェントは、個人およびチームスペースのファイルを見つけ、タスクの草案を編集し、検査し、レビューリンク、プレビュー画像、またはエクスポートされたファイルを返します。

[インストールと接続](#quick-start) · [タスクを試す](#first-task) · [Skills とツール](#skills)

## インストールと接続 [#quick-start]

OpenClaw 2026.5.17 または newer、Node.js 22.22.3 以降が必要です。Univer ワークスペース サービスにアクセスします。OpenClaw Gateway ホストの次のコマンドを実行します。この例では、Workspace CLI 0.5.3 をピン化し、現在のプラグインのコマンドインターフェイスと一致させます。

### 1. CLI とプラグインをインストール

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

プラグインは、`@dr-univer/openclaw-univer-office`としてClawHubに公開されています。 別のローカル`univer-cli`インストールは必要ありません。

### 2. ツールを有効化して接続

OpenClaw の設定に次の設定を追加し、既存のツールの権限を保持します。 `tools.allow` が既に存在している場合は、`univer-office`をそのリストに追加します。

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

ワークスペース サービスで CLI をポイントします。以下の例ではオンライン デモを使用しますので、セルフ ホスト デプロイメントには異なるアドレスが必要です。設定を変更した後にゲートウェイを再始動します。

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. 会話からログイン

OpenClaw に次のメッセージを送る:

```text
Univer Workspace に接続してログイン状態を確認してください。ログインが必要ならブラウザ承認 URL とコードを渡し、私が完了するまで待ってください。
```

電話またはコンピュータに戻ってリンクを開き、サインインし、コードを確認します。 その後、サインインが完了し、署名完了アクションを承認するOpenClawに通知します。 プラグインは、その承認の代わりに投票しません。これはあなたから来なければならない。 オンラインデモでは、サンプルデータを使用します。

## すぐに試せるタスク [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Univer Office で、個人 Workspace Space に Project Northstar の英語の週間計画表を作ってください。Task、Owner、Estimated Hours、Status の列で5件のサンプルタスクを作り、合計工数を数式で計算してください。
独立した Worktree で編集し、読み戻しとスクリーンショットを確認してレビュー準備完了にしたら、携帯電話と PC で開ける同じレビューリンクを渡してください。マージや他の人への送信はせず、私の確認を待ってください。
```

</div>

### 確認できる結果

チャットは、結果とレビューリンクの要約を返します。リンクは、電話ブラウザとデスクトップ上で同じワークスペースの草案を開きます。ネイティブエディタとフルレビューインターフェイスは、ワークスペースに残り、チャットチャネルは進行、プレビュー画像、およびエクスポートされたファイルを提供します。準備完了した草案をマークすると、現在のファイルを変更解除します。

### 続けて試す

ライブチームワークでは、既存のチームスペースを選択し、スペースに表示されているドラフトを明示的に要求します。OpenClawは、この要求の承認を要求します。共同作業者は、そのスペースのメンバーに署名する必要があります。共有リンクは、アクセスを許可しません。

## Skills とツールの連携 [#skills]

プラグインは[`univer-office` スキル](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md)をバンドルします。エージェントは、`univer_office_connect`と`univer_office_files`のスペースを見つけ、コンテンツツールの`guidance`アクションを介してコアと製品ガイダンスをロードし、ファサードAPIを調べ、編集を行い、結果を検証します。ワークスペースはOffice SDKのコンテンツ、認可、コラボレーション、Worktreesをホストします。OpenClawはチャットチャネル、ツールの承認、およびファイルの配信を管理します。

## できること

- チャットからチームコンテンツにアクセス:許可されているスペースとファイルを探し、参照し、既存のスプレッドシート、文書、プレゼンテーション、リレーショナルテーブル、およびキャンバスで動作します。
- タスクの連携: 分離されたWorktreeで編集し、チームメイトが一緒に確認しなければならないときにスペースに表示されるドラフトを作成します。
- デバイスを点検して配信:構造、スクリーンショット、レイアウトをチェックし、電話またはデスクトップブラウザで開くワークスペースレビューリンクを返します。
- 人々との決定を保ちましょう: 結果は、まだ合併または廃棄を選択するために人を必要としています。 プレビュー画像とエクスポートされたファイルは、OpenClawのメッセージとファイルチャネルを介して配信されます。

## Office SDK が担う部分 [#sdk-integration]

プラグインは、Workspace CLI によるオーサリングと検査を呼びます。Workspace Server は、Office SDK のコンテンツ、コラボレーション、バージョン、Worktrees をホストし、アイデンティティと権限を強制します。OpenClaw は、会話、チャンネル、ツールの承認を管理し、ワークスペースで編集およびレビューを完全に維持します。エージェントターミナルは、チームが 1 つのサービスを通じてコラボレーションしながらローカルで実行できます。
