**Univer Office for OpenClaw**（`openclaw-univer-office`）は **[Univer Office SDK](/overview)** で構築された Workspace の機能を OpenClaw に接続します。エージェントは個人・チームのファイルを探し、タスクのドラフトを編集・検査して、レビューリンク、プレビュー画像、出力ファイルを返せます。

[インストールと接続](#quick-start) · [タスクを試す](#first-task) · [Skills とツール](#skills)

## インストールと接続 [#quick-start]

OpenClaw 2026.5.17 以降、Node.js 22.22.3 以降、接続可能な Univer Workspace を用意します。以下は OpenClaw Gateway の実行マシンにインストールします。この例では現行プラグインのコマンドに合わせ、Workspace CLI 0.5.3 を固定しています。

### 1. CLI とプラグインをインストール

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

ClawHub の `@dr-univer/openclaw-univer-office` を使用します。ローカル版 `univer-cli` の別途インストールは不要です。

### 2. ツールを有効化して接続

既存の権限を残したまま、次を OpenClaw 設定に統合します。`tools.allow` がある場合は元のリストに `univer-office` を追加してください。

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

CLI の接続先を設定します。以下はオンラインデモの例です。セルフホストでは自分のサービス URL に変更し、設定後に Gateway を再起動します。

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. 会話からログイン

OpenClaw に次を送ります。

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Univer Workspace に接続してログイン状態を確認してください。ログインが必要ならブラウザ承認 URL とコードを渡し、私が完了するまで待ってください。
```

</div>

携帯電話や PC で URL を開き、ログインしてコードを確認します。完了を OpenClaw に伝え、ログイン完了操作を承認してください。プラグインは承認の代わりに繰り返し確認を行いません。オンラインデモにはサンプルデータを使ってください。

## すぐに試せるタスク [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Univer Office で、個人 Workspace Space に Project Northstar の英語の週間計画表を作ってください。Task、Owner、Estimated Hours、Status の列で5件のサンプルタスクを作り、合計工数を数式で計算してください。
独立した Worktree で編集し、読み戻しとスクリーンショットを確認してレビュー準備完了にしたら、携帯電話と PC で開ける同じレビューリンクを渡してください。マージや他の人への送信はせず、私の確認を待ってください。
```

</div>

### 確認できる結果

チャットに説明とレビューリンクが届き、携帯電話と PC のブラウザで同じ下書きを開けます。ネイティブエディターと完全なレビュー画面は Workspace にあり、チャットは進捗、プレビュー画像、書き出したファイルを配信できます。準備完了にしても現在のファイルは変わりません。

### 続けて試す

共同編集には既存の Team Space を選び、メンバーに見える下書きを明示的に依頼します。OpenClaw が必要な承認を求めます。共同編集者はログイン済みの Space メンバーである必要があり、リンクだけでは権限は付与されません。

## Skills とツールの連携 [#skills]

プラグインに [`univer-office` Skill](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md) が同梱されます。`univer_office_connect` と `univer_office_files` で Space を特定し、コンテンツツールの `guidance` で共通・製品別ガイドを読み込み、Facade を調べて編集・検証します。Office SDK のコンテンツ、権限、共同編集、Worktree は Workspace が、チャット、承認、ファイル配信は OpenClaw が担います。

## できること

- **チャットからチームの資料へ：** 権限のあるスペースとファイルを探し、既存の表、文書、プレゼンテーション、リレーショナルテーブル、キャンバスを扱えます。
- **共同ドラフトで作業：** 独立した Worktree で編集します。チームでレビューする場合は、スペースのメンバーに公開したドラフトを作れます。
- **デバイスをまたいで受け渡す：** 構造、スクリーンショット、配置を検査し、スマートフォンや PC のブラウザーで開ける Workspace リンクを返します。
- **判断は人が行う：** 準備完了後もマージ・破棄は人が決めます。画像やファイルの送付には OpenClaw のメッセージ・ファイル経路を使います。

## Office SDK が担う部分 [#sdk-integration]

プラグインは Workspace CLI 経由で内容操作と検査を呼び出します。Workspace Server が Office SDK の内容、共同編集、バージョン、Worktree と認証・権限を扱い、OpenClaw が対話、チャネル、ツール承認を担当します。完全な編集・レビュー画面は Workspace に置かれ、ローカルのエージェントとチームが同じサービスで協働できます。
