**Univer Office for WorkBuddy** (`workbuddy-univer-office`) — локальная Office-интеграция на публичных API **[Univer Office SDK](/docs/overview)**. Локальный MCP-сервис и Skill подключают создание, проверку, предпросмотр и ревью черновиков к WorkBuddy. Файлы хранятся в локальном рабочем пространстве.

<Callout type="info">
Предварительная версия для разработки. Публичный npm-пакет доступен для локального подключения; официальная установка из каталога и полное ревью внутри хоста ещё требуют приёмочного тестирования.
</Callout>

## Установка и подключение [#quick-start]

Подготовьте WorkBuddy 5.8.3 или новее и Node.js 22, начиная с 22.12. В примере используется публичный пакет 0.1.6. По умолчанию Office-файлы хранятся локально в `~/.univer-office/workspace`.

### 1. Установите локальную среду выполнения

```bash
npm install --global --ignore-scripts workbuddy-univer-office@0.1.6 --registry=https://registry.npmjs.org/
univer-office --version
```

Завершите установку до подключения MCP, чтобы первая загрузка зависимостей не расходовала время ожидания соединения. Для локального подключения не нужны облачная учётная запись или ключ Office API.

### 2. Подключите локальный MCP

Откройте разрешённый рабочий каталог в WorkBuddy и добавьте пользовательский MCP-сервер stdio с такой конфигурацией:

```json
{
  "mcpServers": {
    "univer-office": {
      "type": "stdio",
      "command": "univer-office",
      "args": []
    }
  }
}
```

Если WorkBuddy не находит `univer-office`, замените `command` абсолютным путём к установленной команде. Узнать путь можно через `command -v univer-office` в macOS/Linux или `Get-Command univer-office` в Windows. Пусть WorkBuddy запускает stdio; не запускайте отдельный HTTP-сервис для того же каталога. Другую папку хранения можно задать абсолютным путём в `WORKBUDDY_OFFICE_WORKSPACE`.

### 3. Импортируйте Skill

Подготовьте Git и Python 3, затем создайте ZIP с инструкциями из публичного репозитория; собирать приложение не требуется:

```bash
git clone https://github.com/dream-num/workbuddy-univer-office.git
cd workbuddy-univer-office
python3 scripts/package-workbuddy-skills.py
```

Импортируйте `.data/packages/univer-office-workbuddy-skill.zip` в менеджере Skills WorkBuddy. После подключения MCP попросите помощника проверить состояние Office-сервиса и передайте задачу ниже. Skill даёт инструкции, а MCP-сервер выполняет операции; нужны оба.

## Задача для первого знакомства [#first-task]

```text
Используй Univer Office и создай локальный файл sales-review.univer с таблицей продаж на английском: пять записей и столбцы Product, Quantity, Unit Price, Revenue. Вычисляй Revenue формулами, добавь общий доход и диаграмму дохода по продуктам.
Проверь подтверждённую запись и результаты формул, покажи только эту Sheet справа и дай ссылку на ревью в браузере. Все изменения делай в отдельном черновике и не объединяй до моего одобрения.
```

### Что вы увидите

Справа WorkBuddy показывает таблицу только для чтения. Полный просмотр, Compare и подтверждение объединения открываются в браузере, а файл остаётся локально. Одна Sheet позволяет сразу увидеть формулы и диаграмму и обойти ограничение маршрутизации нескольких карточек в одном ответе хоста.

### Продолжить знакомство

После одобрения и объединения первого результата попросите: «В новом черновике той же таблицы повысь цену первой записи на 10 %, обнови общий доход и открой Compare с подтверждённой версией. Дождись моего ревью». Так можно увидеть реальное сравнение до и после изменения.

## Как работают Skills и инструменты [#skills]

Один [Skill `univer-office`](https://github.com/dream-num/workbuddy-univer-office/tree/main/skills/univer-office) управляет процессом, загружая по необходимости семь продуктовых и межконтентных справочников. Агент ищет публичный Facade через `univer_api`, затем редактирует, подтверждает запись, читает результат и показывает просмотр через MCP. Одна модель Office SDK используется для безынтерфейсной обработки и браузерной отрисовки; версии и Worktree позволяют находить, сравнивать и проверять изменения.

## Что можно создавать

- **Создавайте в привычном помощнике:** Поручайте WorkBuddy создание и обновление электронных таблиц, документов, презентаций, реляционных таблиц и холстов.
- **Следите за предпросмотром:** Просматривайте содержимое только для чтения внутри хоста или открывайте внешний браузер с полными View и Compare.
- **Понимайте изменения:** View и Compare черновика работают только для чтения. Сравнивайте фиксированные версии, изучайте семантические различия и переходите к изменённому содержимому.
- **От черновика к передаче:** Агент редактирует Worktree, человек выбирает слияние, доработку или отклонение, затем экспортирует поддерживаемый формат из выбранной подтверждённой версии.

## Роль Office SDK [#sdk-integration]

WorkBuddy отвечает за разговор и MCP-вызовы. Локальный сервис объединяет Headless-среду, Facade, совместные версии и Worktree Office SDK; браузер отображает ту же модель. Это пример сборки возможностей SDK в локальные инструменты и интерфейс проверки для агентного хоста.
