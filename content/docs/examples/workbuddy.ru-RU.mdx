**Univer Office для работы** (`workbuddy-univer-office`) - это локальная интеграция Office, построенная на общедоступных API-интерфейсах **[Univer Office SDK](/overview)**. Локальная служба MCP и Skill вносят авторство, проверку, предварительные просмотры и черновик обзора в WorkBuddy, а файлы остаются в локальном рабочем пространстве.

<Callout type="info">
Общественное время выполнения npm поддерживает локальную интеграцию; официальная установка на рынке и полный обзор хоста по-прежнему требуют приемочного тестирования.
</Callout>

## Установка и подключение [#quick-start]

Вам нужен WorkBuddy 5.8.3 или более новый и Node.js 22 (22.12 или более новый). В этом примере используется общедоступное время выполнения 0,1.6, а контент Office по умолчанию используется в локальном каталоге `~/.univer-office/workspace`.

### 1. Установите локальную среду выполнения

```bash
npm install --global --ignore-scripts workbuddy-univer-office@0.1.6 --registry=https://registry.npmjs.org/
univer-office --version
```

Завершите установку перед подключением MCP. В противном случае первая загрузка зависимости запускается, пока хост ждет рукопожатия и может превышать тайм-аут. Локальное соединение не требует ни облачной учетной записи, ни ключа Office API.

### 2. Подключите локальный MCP

Откройте авторизованный рабочий каталог в WorkBuddy, затем добавьте пользовательский сервер MCP stdio со следующей конфигурацией:

```json
{
  "mcpServers": {
    "univer-office": {
      "type": "stdio",
      "command": "univer-office",
      "args": []
    }
  }
}
```

Если WorkBuddy не может найти `univer-office`, замените `command` абсолютным путем установки. На macOS или Linux получите этот путь с `command -v univer-office`; на Windows используйте `Get-Command univer-office`. Позвольте WorkBuddi запустить сервер stdio и не запускайте независимый HTTP-сервис для одного и того же каталога хранения. Чтобы использовать другой каталог хранения, установите переменную среды `WORKBUDDY_OFFICE_WORKSPACE` на абсолютный путь.

### 3. Импортируйте Skill

С помощью Git и Python 3 можно генерировать только инструкции Skill ZIP из публичного хранилища.

```bash
git clone https://github.com/dream-num/workbuddy-univer-office.git
cd workbuddy-univer-office
python3 scripts/package-workbuddy-skills.py
```

Импорт `.data/packages/univer-office-workbuddy-skill.zip` в менеджер навыков WorkBuddy. Как только MCP подключен, попросите помощника проверить статус службы Office, затем отправьте задачу ниже. Навык предоставляет руководство, и сервер MCP выполняет выполнение, поэтому используйте их вместе.

### Что вы увидите

WorkBuddy отображает один предварительный просмотр электронной таблицы только для чтения справа. Полный просмотр, сравнение и подтверждение слияния открываются в браузере, в то время как файл Office остается локальным. Начиная с одного листа, формулы и диаграммы сразу видны и избегают ограничения маршрутизации хоста на нескольких картах предварительного просмотра в одном и том же ответе.

### Продолжить знакомство

После того, как вы одобрите и объедините первый результат, спросите: «В новом проекте того же листа продаж, поднимите цену единицы первого рекорда на 10%, обновите общую выручку и откройте Compare против подтвержденной версии. Ждите моего обзора. Это дает конкретное сравнение до и после».

## Как работают Skills и инструменты [#skills]

Один [Навыки `univer-office`](https://github.com/dream-num/workbuddy-univer-office/tree/main/skills/univer-office) определяет рабочий процесс, с семью ссылками на продукт и перекрестный контент, загруженными по мере необходимости. Агент запрашивает общедоступные API-интерфейсы Facade с `univer_api`, затем редактирует, подтверждает записи, читает содержимое и предварительные просмотры через MCP. Та же модель Office SDK приводит в действие обработку без головы и рендеринг браузера, а версии плюс Worktrees делают каждое изменение идентифицируемым, сопоставимым и просматриваемым.

## Что можно создавать

- Создайте контент в своем существующем помощнике: попросите WorkBuddy создать или обновить электронные таблицы, документы, презентации, реляционные таблицы и холсты.
- Следуйте прямым предварительным просмотрам: проверьте предварительные просмотры только для чтения на хосте или откройте внешний браузер для полного просмотра и сравнения интерфейсов.
- Просмотрите изменения, прежде чем принимать решение: Draft View and Compare только для чтения. Сравните фиксированные версии, проверьте семантические различия и перейдите к затронутому контенту.
- Перейдите от черновика к доставке: агент редактирует Worktree, человек выбирает слияние, пересмотр или отбрасывание, а поддерживаемые форматы затем экспортируются из подтвержденной версии, которую вы выбираете.

## Роль Office SDK [#sdk-integration]

WorkBuddy обрабатывает разговор и вызовы инструмента MCP. Локальный сервис составляет время выполнения Office SDK без головы, авторство Facade, версии совместной работы и Worktrees, а предварительные просмотры браузера отображают одну и ту же модель контента. Проект демонстрирует, как упаковывать возможности SDK в качестве локальных инструментов и интерфейса обзора для хоста-агента.
