**Univer Office Copilot** — открытое эталонное веб-приложение на **[Univer Office SDK](/overview)**, LangChain, React и TypeScript. Оно размещает редактируемые таблицы, документы, слайды, реляционные таблицы и холсты рядом с диалоговым помощником. Используйте запускаемый пример кода как основу собственного Office Copilot.

[Запустить локально](#quick-start) · [Редактируемые примеры](https://github.com/dream-num/univer-office-copilot#included-examples) · [Исходный код](https://github.com/dream-num/univer-office-copilot)

## Локальный запуск эталонного приложения [#quick-start]

Используйте **Node.js 24+** и **pnpm 10.33.4**:

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

Откройте **http://127.0.0.1:5173**. Новая локальная демоучётная запись получает шесть приватных редактируемых примеров для всех пяти продуктов и обоих режимов документов. Для просмотра и ручного редактирования не нужны ключ модели, Docker или внешняя база данных.

Для работы с Copilot откройте меню моделей в чате и выберите **Add model** или **Manage models**. Укажите провайдера, ID модели и API-ключ. Поддерживаются OpenAI, Anthropic, Google Gemini, DeepSeek, OpenRouter и собственные HTTPS-эндпоинты, совместимые с OpenAI. Режим **Ask** помогает изучать файл, а **Edit** напрямую изменяет текущий файл.

Для измерения текста ИИ и проверки отрисовки необходим локальный Chrome, Chromium или Edge. Настройка моделей, вложений, импорта/экспорта и браузера описана в [руководстве локальной разработки](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md).

## Роль Office SDK [#sdk-integration]

Рабочее пространство React предоставляет редакторы и чат. Сервер Node запускает цикл инструментов LangChain, продуктовые Skills и ограниченные скрипты редактирования в клиенте Univer без интерфейса. Подтверждённые изменения поступают в браузер по тому же каналу совместной работы, что и правки людей; нативное чтение результатов и проверка отрисовки дают обратную связь для валидации.

Modern Docs использует Markdown, Paged Docs — Typst, а Slides компилирует SVG в редактируемые элементы. Приложение также поддерживает несколько диалогов на файл, контекст вложений, изменения по ходам, нативную историю, восстановление владельцем и раздельную публикацию файлов и диалогов.

Используйте [описание архитектуры](https://github.com/dream-num/univer-office-copilot/blob/main/docs/architecture.md) и [руководство расширения](https://github.com/dream-num/univer-office-copilot/blob/main/docs/extending.md), а также изучите [операции с контентом](/ai/content-operations), [совместную работу](/overview/features/shared/collaboration) и [историю](/overview/features/shared/history).
