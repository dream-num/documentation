**Univer Office Copilot** — это справочное веб-приложение с открытым исходным кодом, созданное с помощью **[Univer Office SDK](/overview)**, LangChain, React и TypeScript. Он размещает редактируемые электронные таблицы, документы, слайды, реляционные таблицы и холсты рядом с помощником по разговору. Образец кода работает без модификации и может служить отправной точкой для вашего собственного Office copilot.

[Запустить локально](#quick-start) · [Редактируемые примеры](https://github.com/dream-num/univer-office-copilot#included-examples) · [Исходный код](https://github.com/dream-num/univer-office-copilot)

## Локальный запуск эталонного приложения [#quick-start]

Для использования в справочной заявке требуется **Node.js 24+** и **pnpm 10.33.4**:

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

Открыть [http://127.0.0.1:5173](http://127.0.0.1:5173). Новый локальный демо-счет начинается с шести частных, редактируемых примеров, которые охватывают все пять продуктов и оба режима документов. Для просмотра и ручного редактирования не требуется ключ модели, Docker или внешняя база данных.

Чтобы использовать Copilot, откройте меню модели в чате и выберите **Добавить модель** или **Управлять моделями**. Установите провайдер, идентификатор модели и ключ API. Приложение поддерживает OpenAI, Anthropic, Google Gemini, DeepSeek, OpenRouter и пользовательские OpenAI-совместимые конечные точки HTTPS. Выберите **Спроси.** для проверки файла или **Редактировать**, чтобы напрямую изменить текущий файл.

Измерение текста ИИ и визуализированные проверки требуют локальной установки Chrome, Chromium или Edge.Конфигурация модели, вложения, импорт и экспорт и настройка браузера описаны в [Руководство по местному развитию](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md).

## Роль Office SDK [#sdk-integration]

Рабочее пространство React удерживает редакторы и интерфейс чата. Бэкэнд Node запускает цикл инструментов LangChain, навыки продукта и ограниченные сценарии редактирования против клиента headless Univer. Подтвержденные правки достигают браузера по тому же каналу совместной работы, который используют люди, а нативная обратная связь вместе с визуализированными проверками обеспечивает обратную связь проверки.

Современные Docs используют Markdown, Paged Docs — Typst, а Slides — SVG, скомпилированный в редактируемые элементы.Приложение также поддерживает несколько разговоров на файл, контекст вложения, проверку изменения по очереди, нативную историю файлов, контролируемое владельцем восстановление и отдельный обмен файлами и разговорами.

Постройте [архитектура](https://github.com/dream-num/univer-office-copilot/blob/main/docs/architecture.md) и [Руководство по расширению](https://github.com/dream-num/univer-office-copilot/blob/main/docs/extending.md) или исследуйте возможности [контент-операции](/ai/content-operations), [сотрудничество](/overview/features/shared/collaboration) и [история](/overview/features/shared/history), которые лежат в основе этого.
