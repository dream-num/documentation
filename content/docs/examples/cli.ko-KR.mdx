**Univer 클립**는 **[Univer Office SDK](/overview)**에 내장 된 로컬 오피스 자동화 응용 프로그램입니다. 이미 사용하는 에이전트에 콘텐츠 명령과 스킬을 추가합니다. 이러한 추가 기능을 통해 에이전트는 기존 Excel, Word 및 PowerPoint 파일과 함께 작동하며 스프레드 시트, 문서, 프리젠 테이션, 관계 테이블 및 캔버스를 만들 수 있습니다. 결과는 기계에 남아 있습니다.

**CLI (Command-Line Interface)는 현재 Univer를 운영하는 기본 방법입니다.** 에이전트 통합에 이전 MCP-first 접근 방식을 대체합니다. Univer CLI는 `univer` 명령과 스킬을 제공합니다. 에이전트는 자체 명령 실행 도구를 사용하여 편집, 검사 및 콘텐츠 전달, 미리보기 및 검토는 로컬 뷰어에서 열립니다.

[설치 및 체험](#quick-start) · [Skills 작동 방식](#skills) · [Skills 목록](#skills-catalog)

## 이미 사용하는 에이전트와 연결

Univer CLI는 다음 에이전트를 지원합니다:

**OpenCode** · **Claude Code** · **OpenClaw** · **Hermes** · **Codex** · **WorkBuddy** · **Kimi Work**

이 에이전트는 하나의 인터페이스를 공유: `univer` 명령과 설치 된 버전과 일치하는 운영 지침. 에이전트 스킬 지원 호스트는 공식 스킬을로드 할 수 있으며, 명령을 실행할 수있는 에이전트는 자체 도구 레이어를 통해 Univer로 호출 할 수 있습니다. 대화 미리보기 카드와 같은 호스트 별 기능은 [통합 프로젝트](https://univer.ai/ecosystem)에 의해 덮여 있습니다.

## 첫 결과물 확인하기 [#quick-start]

Univer CLI는 Node.js 24 또는 더 새로운 것을 요구합니다. 당신의 대리인이 운영하는 환경에 설치하십시오:

```bash
npm install --global univer-cli@latest
npx skills add dream-num/skills -s univer-cli -g
univer doctor
```

`univer doctor`는 로컬 실행 시간을 확인합니다. 기술을 통해 에이전트는 명령을 발견하고 특정 제품에 대한 지침을로드하고 콘텐츠를 검사하고 결과를 제공합니다.

### 공식 예제 열기

새로운 빈 디렉토리에서 다음 명령을 다음 에이전트에 보냅니다.

```text
Univer CLI로 공식 예제를 체험해 주세요.
https://univer.ai/cli-assets/hello.univer 를 현재 폴더의 hello.univer로 내려받으세요.
파일의 콘텐츠 목록과 로컬 Viewer 링크를 주고 무엇을 체험할 수 있는지 설명해 주세요.
```

기존 콘텐츠는 즉시 네이티브 편집기를 표시합니다. 그 콘텐츠를 수정하거나 아래 생성 작업을 시도하기 위해 에이전트를 요청할 수 있습니다.

## Skills: 에이전트를 위한 작업 가이드 [#skills]

이 스킬은 기존 에이전트가 Univer CLI를 통해 Office 콘텐츠를 생성, 편집 및 확인 할 수 있습니다. 첫 번째 [CLI와 그 발견 능력을 설치](#quick-start), 다음 아래 설명 된 작업별 지침을로드합니다.

A Skill은 에이전트가 읽을 수 있는 지침으로 제품의 일부를 선물합니다. 콘텐츠 모델, 편집 워크플로우, Facade API를 찾는 방법 및 검증 요건. 그 기반에, 에이전트는 검토 및 배달을 통해 첫 번째 편집에서 작업 필요성을 결정합니다.

**검색 결과:** 에이전트에 설치 [`univer-cli` 기술](https://github.com/dream-num/skills/blob/main/skills/univer-cli/SKILL.md)는 사무실 작업을 인식하고 로컬 CLI에서 전체지도를로드하는 데 도움이됩니다.

**런타임 스킬:** 이 배는 CLI와 일치하여 설치된 명령과 Facade APIs와 일치합니다. `core`를 먼저 로드하면 대상 제품. 작업이 embeds 또는 cross-content 공식이 포함될 때 주제 기술을 추가하십시오.

### 작업에 맞게 불러오기 [#load-skills]

대부분의 경우 에이전트는이 지침을 자체에 읽습니다. 개발자는 직접 검사 할 수 있습니다.

```bash
univer skills list
univer skills get core
univer skills get sheet
univer skills path sheet
```

`list`는 설치된 기술, `get`가 지도를 읽었으며 `path`은 로컬 디렉토리를 반환합니다. `univer skills get core --full`에는 참조 및 템플릿이 포함되어 있습니다. `univer api find` 및 `univer api show`를 사용하여 특정 API를 볼 수 있습니다.

### Skills 목록 [#skills-catalog]

소스 저장소의 가이드를 검색하려면 이름을 따르십시오. 실제 작업을 위해 로컬 `univer skills get <name>` 명령으로 반환된 버전을 사용하십시오.

| Skill | 사용하는 경우 |
| --- | --- |
| [`core`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/core/SKILL.md) | 공유 워크플로우: Units and Worktrees, 위치 및 편집 컨텐츠를 이해하고, 확인, 검토를 제출하십시오. |
| [`sheet`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/sheet/SKILL.md) | 스프레드시트(Sheet): 데이터, 수식, 서식, 차트와 결과 검증. |
| [`doc`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/doc/SKILL.md) | 문서(Doc): 단락, 서식 있는 텍스트, 표, 차트와 페이지 레이아웃. |
| [`slide`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/slide/SKILL.md) | 프리젠 테이션 (Slide) : 페이지, 모양, 텍스트, 이미지 및 시각 검사. |
| [`base`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/base/SKILL.md) | Relational Table: 테이블, 필드, 레코드와 뷰. |
| [`board`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/board/SKILL.md) | 캔버스 : 캔버스 요소, 차트 및 레이아웃 체크. |
| [`embed`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/embed/SKILL.md) | Embeds: 다른 곳에서 한 단위에서 콘텐츠를 배치하고 차트 데이터 소스를 연결합니다. |
| [`cross-unit-formula`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/cross-unit-formula/SKILL.md) | 콘텐츠 간 수식: Sheet 범위나 Relational Table 필드의 데이터를 Sheet 셀 또는 수식 기반 도형에서 계산. |

예를 들어, 문서에 스프레드 시트를 삽입하기 위해 `core → doc + sheet → embed`를로드하십시오. 시트 셀 또는 모양 참조 데이터를 다른 내용으로 추가 할 때 `cross-unit-formula`을 추가하십시오. 모든 가이드를 미리로드하면 불필요합니다. CLI를 업데이트 한 후 `core` 및 제품 및 사용중인 항목 기술이 다시로드됩니다.

## 무엇을 만들 수 있나요

- 데이터 전달 가능: 시트를 청소하고, 공식을 작성하고, 차트와 피벗 테이블을 추가하고, 헤더와 발기를 사용하여 보고서를 놓거나, 개요에서 발표를 구축하십시오.
- 연결되는 내용을 지키십시오: 1개의 `.univer` 파일은 공식, 도표 참고를 통해서 연결된 다수 내용 유형을 붙들 수 있고, embeds.
- 결과 확인: Facade를 통해 실제 콘텐츠 모델을 읽거나 스크린 샷 및 프리젠 테이션 레이아웃 체크를 사용하여 오버 플로우, 오버랩 또는 페이지를 실행합니다.
- 납품의 앞에 검토: 대리인은 고립된 Worktree에서 작동하고 국부적으로 구경꾼 연결을 돌려보냅니다. 다름을 검열하고, 요구 개정, 합병하거나 결과를 표출하고, 지원되는 사무실 체재를 수출하십시오. 화포 파일 수입품과 수출은 아직 유효하지 않습니다.

## 이런 작업을 요청해 보세요

> Univer CLI를 사용하여 날짜, 범주 및 금액 및 5 개의 샘플 행으로 월간 비용 시트를 만들 수 있습니다. 카테고리별로 요약 된 총 공식 및 차트를 추가하십시오. 데이터와 렌더링 된 결과를 확인하고 Viewer 링크를주고 내 리뷰 전에 합병하지 마십시오.

## Office SDK가 담당하는 부분

Office SDK는 헤드리스 콘텐츠 실행 시간, Facade API, 계산, 렌더링, 버전 및 워크 트리를 제공합니다. CLI는 터미널 명령 및 버전 일치 기술로 이러한 기능을 조립하고 로컬 `.univer` 저장, 게이트웨이 및 뷰어를 소유합니다. 에이전트 쓰기가 편집기 미리보기 및 표준 파일 배송으로 직접 이동할 수 있다는 내용입니다.
