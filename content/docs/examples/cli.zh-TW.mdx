**Univer CLI** 是基於 **[Univer Office SDK](/overview)** 建置的本地 Office 自動化應用。它為你正在使用的 Agent 提供一組內容命令和 Skills，使該 Agent 能夠處理已有的 Excel、Word 和 PowerPoint 檔案，也能建立電子表格、文件、簡報、關係型表格和畫布。處理結果保留在本機。

**CLI（Command-Line Interface，命令列介面）目前是操作 Univer 的主要方式**，取代了此前以 MCP 為主的 Agent 接入方式。Univer CLI 提供 `univer` 命令和 Skills：Agent 使用自己已有的命令執行工具編輯、檢查並交付內容，預覽和審閱則在本地 Viewer 中完成。

[安裝與體驗](#quick-start) · [Skills 運作方式](#skills) · [Skills 目錄](#skills-catalog)

## 適配你正在使用的 Agent

Univer CLI 支援以下 Agent：

**OpenCode** · **Claude Code** · **OpenClaw** · **Hermes** · **Codex** · **WorkBuddy** · **Kimi Work**

這些 Agent 共用同一個介面：`univer` 命令，以及與所安裝版本對應的操作指引。宿主支援 Agent Skills 時，可以載入官方 Skill；Agent 能夠執行命令時，也可以透過自己的工具層呼叫 Univer。對話內預覽卡片這類宿主專屬體驗，由對應的[整合專案](https://univer.ai/ecosystem)負責實現。

## 先看到第一個成果 [#quick-start]

使用前需要 Node.js 24 或更新版本。請安裝在 Agent 執行的環境中：

```bash
npm install --global univer-cli@latest
npx skills add dream-num/skills -s univer-cli -g
univer doctor
```

`univer doctor` 檢查本地的執行環境。藉助 Skill，Agent 可以找到命令、載入具體產品的操作指引、檢查內容並交付結果。

### 打開官方樣例

新建一個空目錄，把下面的指令發給 Agent：

```text
使用 Univer CLI 體驗官方樣例。
把 https://univer.ai/cli-assets/hello.univer 下載到目前目錄的 hello.univer，
列出文件中的內容，然後給我本機 Viewer 連結，並介紹我可以體驗哪些功能。
```

開啟已有內容後，原生編輯器會立即顯示。接下來可以讓 Agent 修改這份內容，也可以嘗試下面的新建任務。

## Skills：Agent 的操作指南 [#skills]

這些 Skills 讓已有的 Agent 能夠透過 Univer CLI 建立、編輯和檢查 Office 內容。請先[安裝 CLI 和發現入口 Skill](#quick-start)，再按任務載入下面的指引。

Skill 把產品的部分用法整理成 Agent 可以閱讀的指引：內容模型、編輯流程、查詢 Facade API 的方法，以及驗證需要滿足的條件。Agent 依據這些指引判斷任務需要哪些能力，從首次編輯一直到審閱和交付。

**發現入口：** 安裝到 Agent 中的 [`univer-cli` Skill](https://github.com/dream-num/skills/blob/main/skills/univer-cli/SKILL.md) 幫助它識別 Office 任務，再從本機 CLI 載入完整指引。

**執行時 Skills：** 隨 CLI 一起釋出，與所安裝版本的命令和 Facade API 對應。先載入 `core`，再載入目標產品；任務涉及嵌入或跨內容公式時，再補上對應主題的 Skill。

### 依任務載入 [#load-skills]

這些指引通常由 Agent 自行讀取，開發者也可以直接檢視：

```bash
univer skills list
univer skills get core
univer skills get sheet
univer skills path sheet
```

`list` 列出已安裝的 Skills，`get` 讀取其中一個，`path` 返回它在本地的目錄。`univer skills get core --full` 會一併給出參考資料和模板。如需查詢具體 API，可使用 `univer api find` 和 `univer api show`。

### Skills 目錄 [#skills-catalog]

點選名稱可以瀏覽原始碼倉庫中的指引。實際執行任務時，以本機 `univer skills get <name>` 返回的版本為準。

| Skill | 何時使用 |
| --- | --- |
| [`core`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/core/SKILL.md) | 通用流程：理解 Unit 與 Worktree，定位並編輯內容，驗證後提交審閱。 |
| [`sheet`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/sheet/SKILL.md) | 試算表（Sheet）：資料、公式、格式、圖表與結果檢查。 |
| [`doc`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/doc/SKILL.md) | 文件（Doc）：段落、豐富文字、表格、圖表與頁面配置。 |
| [`slide`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/slide/SKILL.md) | 簡報（Slide）：頁面、形狀、文字、圖片與視覺檢查。 |
| [`base`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/base/SKILL.md) | 關聯式表格（Relational Table）：表格、欄位、記錄與檢視。 |
| [`board`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/board/SKILL.md) | 畫布（Canvases）：畫布元素、圖表與配置檢查。 |
| [`embed`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/embed/SKILL.md) | 嵌入內容：把一個 Unit 的內容放入另一個 Unit，並連線圖表資料來源。 |
| [`cross-unit-formula`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/cross-unit-formula/SKILL.md) | 跨內容公式：從 Sheet 區域或 Relational Table 欄位讀取資料，在 Sheet 單元格或公式驅動的形狀中計算。 |

例如，要在文件中嵌入表格，載入順序為 `core → doc + sheet → embed`；當 Sheet 單元格或形狀引用其他內容的資料時，再加上 `cross-unit-formula`。不需要一開始載入全部指引。更新 CLI 後，請重新載入 `core` 以及你用到的產品和主題 Skills。

## 你可以用它做什麼

- 把資料轉化為交付物：清洗表格、編寫公式、新增圖表和透視表，為報告排版頁首頁尾，或者按提綱製作一份簡報。
- 讓內容彼此關聯：一個 `.univer` 檔案可以容納多種內容，並透過公式、圖表引用和嵌入將它們連線起來。
- 驗證結果：透過 Facade 讀回真實的內容模型，再用截圖和演示稿版面配置檢查，找出溢位、重疊或超出頁面的文字。
- 審閱後再交付：Agent 在隔離的 Worktree 中工作，完成後返回本地 Viewer 連結。你可以檢視差異、要求修改、合併或丟棄，並匯出支援的 Office 格式。畫布目前不支援檔案匯入匯出。

## 試試這樣一個任務

> 用 Univer CLI 建立一個月度開銷表，包含日期、類別、金額和 5 條範例資料，加上總額公式和一張按類別彙總的圖表。檢查資料和渲染結果後把 Viewer 連結給我，我審閱之前不要合併。

## Office SDK 如何支撐

Office SDK 提供 Headless 內容執行時、Facade API，以及計算、渲染、版本和 Worktree 能力。CLI 將這些能力組織成終端命令和與版本配套的 Skills，並負責本地 `.univer` 儲存、Gateway 和 Viewer。Agent 寫入的內容可以直接進入編輯器預覽，也能按標準格式交付檔案。
