**Univer Office for DeepSeek Harness** (`dsh-univer-office`) est un plugin DSH construit avec **[Univer Office SDK](/docs/overview)**. Décrivez votre résultat en langage naturel : l’agent crée ou modifie feuilles, documents, présentations, tables relationnelles et canevas, avec les résultats visuels dans la conversation.

[Installer et connecter](#quick-start) · [Essayer une tâche](#first-task) · [Skills et outils](#skills)

## Installer et connecter [#quick-start]

Préparez DeepSeek Harness, un modèle configuré et Node.js 22.19 ou ultérieur. Consultez les versions de DSH vérifiées dans les [conditions de compatibilité](https://github.com/dream-num/dsh-univer-office#requirements-and-current-limits) avant l’installation.

### Installer le plugin

Si DSH fonctionne déjà, arrêtez-le avec Ctrl+C dans son terminal de lancement, puis installez le plugin dans le profil Web :

```bash
dsh plugin --profile web add dsh-univer-office
```

Redémarrez DSH :

```bash
dsh web
```

Actualisez la page DSH après le démarrage et ouvrez une conversation dans un dossier de projet accessible. Le plugin inclut son environnement d’exécution, ses outils et ses Skills ; aucune installation séparée d’Univer CLI n’est nécessaire. Les captures et contrôles de mise en page nécessitent Chrome, Chromium ou Edge en local.

## Essayez une tâche immédiatement [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Avec Univer Office, crée une présentation en anglais de 3 diapositives pour présenter Project Northstar aux nouveaux collègues. Page 1 : couverture et objectif en une phrase. Page 2 : trois jalons d’exemple. Page 3 : trois prochaines actions. Utilise une palette bleue et verte cohérente, des titres lisibles et du texte modifiable.
Travaille dans un brouillon isolé, vérifie les débordements, chevauchements et le rendu de chaque page, puis affiche l’aperçu en direct et la carte de revue dans cette conversation. Attends mon accord avant de fusionner ; exporte en PowerPoint uniquement sur demande.
```

</div>

### Ce que vous verrez

Une fenêtre flottante montre la présentation pendant le travail, et la carte reste dans la conversation. Vous obtenez trois diapositives modifiables. Demandez par exemple « transforme la page 2 en chronologie », puis approuvez ou abandonnez le brouillon.

## Comment les Skills et les outils coopèrent [#skills]

Le plugin fournit des [Skills communs et par produit](https://github.com/dream-num/dsh-univer-office/tree/main/skills), chargés par DSH selon la tâche. L’agent recherche les API Facade correspondantes avec `univer_api`, modifie avec `univer_execute`, puis vérifie par relecture, captures et `univer_lint`. Office SDK assure calcul, rendu et versions ; le plugin apporte les aperçus flottants et les cartes de revue dans la conversation.

## Ce que vous pouvez créer

- **Suivre la création :** Déplacez, redimensionnez, repliez ou agrandissez les fenêtres d’aperçu pendant le travail de l’agent.
- **Réviser dans la conversation :** Chaque fichier dispose d’une carte qui reste accessible. Poursuivez les modifications, approuvez le brouillon ou abandonnez-le.
- **Livrer du contenu Office réel :** Travaillez avec Excel, Word et PowerPoint, créez formules, graphiques et mises en page riches, puis exportez le format correspondant.
- **Faire vérifier le travail :** Combinez relecture du modèle, captures et contrôles de mise en page. Plusieurs contenus peuvent partager un fichier et être reliés par formules et blocs intégrés.

## Le rôle d’Office SDK [#sdk-integration]

DSH gère conversations, sessions et appels d’outils. Le plugin y connecte création, calcul, rendu et Worktrees d’Office SDK. L’agent modifie de vrais modèles de contenu ; le SDK assure aperçu et révision, tandis que le plugin fournit fenêtres flottantes, cartes et état de session.
