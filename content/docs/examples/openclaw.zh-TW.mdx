**Univer Office for OpenClaw**（`openclaw-univer-office`）把基於 **[Univer Office SDK](/overview)** 建置的 Workspace 能力接入 OpenClaw。Agent 可以查找個人和團隊空間里的檔案，在任務草稿中編輯與檢查，再把審閱連結、預覽圖或匯出檔案交給使用者。

[安裝與接入](#quick-start) · [直接體驗](#first-task) · [Skills 與工具](#skills)

## 安裝與接入 [#quick-start]

準備 OpenClaw 2026.5.17 或更新版本、Node.js 22.22.3 或更新版本，以及可存取的 Univer Workspace 服務。在執行 OpenClaw Gateway 的電腦上安裝以下相依套件。此範例固定 Workspace CLI 0.5.3，與目前外掛的指令介面配套。

### 1. 安裝 CLI 與外掛

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

外掛使用 ClawHub 的 `@dr-univer/openclaw-univer-office`，不必另裝本機 `univer-cli`。

### 2. 啟用工具並連接服務

將以下設定合併至 OpenClaw，保留既有工具授權；若已有 `tools.allow`，將 `univer-office` 加入原清單：

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

將 CLI 指向要使用的 Workspace。以下以線上體驗服務為例；自託管時換成自己的位址。設定後重新啟動 Gateway。

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. 在對話中登入

向 OpenClaw 傳送：

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
請連接 Univer Workspace 並檢查登入狀態；若需登入，請給我瀏覽器授權連結與驗證碼，等我完成後再繼續。
```

</div>

在手機或電腦開啟回傳連結，登入並確認驗證碼。告知 OpenClaw 已完成，再批准宿主的登入完成操作。外掛不會反覆輪詢代替你的授權。線上服務僅供體驗，請使用示例資料。

## 直接體驗一個任務 [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
使用 Univer Office，在我的 Workspace 個人空間新建 Project Northstar 英文週計畫表，包含 5 項示例任務：Task、Owner、Estimated Hours、Status，並以公式彙總總工時。
在獨立 Worktree 中編輯，讀回資料並檢查截圖，標記可審閱後，給我同一個可在手機與電腦開啟的審閱連結。不要合入，也不要傳給其他人，等我確認。
```

</div>

### 你會看到什麼

聊天中收到成果說明與審閱連結，手機和電腦開啟同一份 Workspace 草稿。原生編輯器與完整審閱介面位於 Workspace，聊天管道可交付進度、預覽圖與匯出檔案。標記就緒不會修改主版本。

### 繼續體驗

需要多人共同編輯時，再選擇既有團隊空間並明確要求團隊可見草稿。OpenClaw 會請求相應批准；協作者須為該空間成員且已登入，分享連結本身不會授予存取權。

## Skills 與工具如何協作 [#skills]

外掛內建 [`univer-office` Skill](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md)。Agent 透過 `univer_office_connect` 與 `univer_office_files` 定位空間，再以內容工具的 `guidance` 載入通用與產品指引，查詢 Facade 後編輯並檢查。Workspace 承載 Office SDK 的內容、權限、協同與 Worktree；OpenClaw 負責聊天管道、工具批准與檔案交付。

## 你可以用它做什麼

- **從聊天進入團隊資料：** 查找並瀏覽有權存取的空間與檔案，繼續處理已有試算表、文件、簡報、關聯式表格和畫布。
- **把任務變成協作草稿：** 在隔離 Worktree 中修改；需要團隊共同審閱時，可以建立對空間成員可見的草稿。
- **檢查後跨設備交付：** 驗證內容結構、截圖和版面配置，再返回可在手機或電腦瀏覽器打開的 Workspace 審閱連結。
- **保留人的決策入口：** 標記就緒後仍由人決定是否合併或捨棄；預覽圖和匯出檔案透過 OpenClaw 的消息與檔案渠道交付。

## Office SDK 如何支撐 [#sdk-integration]

外掛程式透過 Workspace CLI 調用 Office 內容操作和檢查能力，Workspace 服務承載 Office SDK 的內容、協同、版本與 Worktree，並處理身份和權限。OpenClaw 負責對話、渠道和工具審批；完整編輯器與審閱介面位於 Workspace。Agent 終端可以在本機執行，團隊透過同一個服務協作。
