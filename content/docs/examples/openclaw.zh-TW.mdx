**Univer Office for OpenClaw**（`openclaw-univer-office`）將基於 **[Univer Office SDK](/overview)** 建置的 Workspace 能力接入 OpenClaw。Agent 可以查詢個人空間和團隊空間中的檔案，在任務草稿中編輯和檢查，最後返回審閱連結、預覽圖或匯出檔案。

[安裝與接入](#quick-start) · [直接體驗](#first-task) · [Skills 與工具](#skills)

## 安裝與接入 [#quick-start]

需要 OpenClaw 2026.5.17 或更新版本、Node.js 22.22.3 或更新版本，以及可訪問的 Univer Workspace 服務。以下命令均在執行 OpenClaw Gateway 的主機上執行。本範例將 Workspace CLI 固定在 0.5.3，以匹配當前外掛的命令介面。

### 1. 安裝 CLI 與外掛

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

外掛由 ClawHub 以 `@dr-univer/openclaw-univer-office` 的形式分發，本地不需要單獨安裝 `univer-cli`。

### 2. 啟用工具並連接服務

將以下配置合併到 OpenClaw 配置檔案中，並保留已有的工具權限。如果已有 `tools.allow`，請將 `univer-office` 追加到該列表：

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

將 CLI 指向 Workspace 服務。下面的範例使用線上體驗環境，自部署時需替換為實際地址。修改配置後重啟 Gateway。

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. 在對話中登入

將以下訊息傳送給 OpenClaw：

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
請連接 Univer Workspace 並檢查登入狀態；若需登入，請給我瀏覽器授權連結與驗證碼，等我完成後再繼續。
```

</div>

在手機或電腦上開啟返回的連結，登入並確認驗證碼，然後告知 OpenClaw 登入已完成，並批准其登入完成操作。外掛不會以輪詢代替該確認，確認必須由你完成。線上體驗環境請使用範例資料。

## 直接體驗一個任務 [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
使用 Univer Office，在我的 Workspace 個人空間新建 Project Northstar 英文週計畫表，包含 5 項示例任務：Task、Owner、Estimated Hours、Status，並以公式彙總總工時。
在獨立 Worktree 中編輯，讀回資料並檢查截圖，標記可審閱後，給我同一個可在手機與電腦開啟的審閱連結。不要合入，也不要傳給其他人，等我確認。
```

</div>

### 你會看到什麼

聊天中會返回結果說明和審閱連結，手機和電腦開啟的是同一個 Workspace 草稿。原生編輯器和完整審閱介面保留在 Workspace 中，聊天渠道負責傳遞進度、預覽圖和匯出檔案。將草稿標記為就緒不會改動當前檔案。

### 繼續體驗

如需多人即時協作，請選擇一個已有的團隊空間，並明確要求建立對該空間可見的草稿。OpenClaw 會申請所需的批准。協作者必須是該空間中已登入的成員；僅有分享連結不會獲得訪問權限。

## Skills 與工具如何協作 [#skills]

外掛內建一個 [`univer-office` Skill](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md)。Agent 使用 `univer_office_connect` 和 `univer_office_files` 定位空間，透過內容工具的 `guidance` 操作載入核心指引和產品指引，然後查詢 Facade API、編輯並驗證。Workspace 承載 Office SDK 的內容、權限、協同和 Worktree，OpenClaw 負責聊天渠道、工具審批和檔案交付。

## 你可以用它做什麼

- 從聊天中訪問團隊內容：查詢並瀏覽你有權限的空間和檔案，然後處理已有的電子表格、文件、簡報、關係型表格和畫布。
- 協作處理任務：在隔離的 Worktree 中編輯，需要團隊共同審閱時建立對該空間可見的草稿。
- 跨裝置檢查與交付：檢查結構、截圖和版面配置，然後返回可在手機或電腦瀏覽器中開啟的 Workspace 審閱連結。
- 由人保留決策權：標記為就緒的結果仍需要由人選擇合併或丟棄。預覽圖和匯出檔案透過 OpenClaw 的訊息與檔案渠道交付。

## Office SDK 如何支撐 [#sdk-integration]

外掛透過 Workspace CLI 呼叫內容操作和檢查能力。Workspace Server 承載 Office SDK 的內容、協同、版本和 Worktree，並負責身分與權限校驗。OpenClaw 負責對話、渠道和工具審批；完整的編輯和審閱仍在 Workspace 中完成。Agent 終端可以在本地執行，團隊透過同一個服務協作。
