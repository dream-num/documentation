**Univer CLI** - это локальное приложение автоматизации Office, построенное на **[Univer Office SDK](/overview)**. Он добавляет команды контента и навыки к агенту, который вы уже используете. С помощью этих дополнений агент может работать с существующими файлами Excel, Word и PowerPoint и может создавать электронные таблицы, документы, презентации, реляционные таблицы и холсты. Результаты остаются на вашей машине.

**CLI (Command-Line Interface) в настоящее время является основным способом работы с Univer.** заменяет более ранний подход MCP-first к интеграции агентов. Univer CLI предоставляет команду `univer` и навыки. Агенты используют свои собственные инструменты выполнения команд для редактирования, проверки и доставки контента, а предварительный просмотр и обзор происходят в локальном Viewer.

## Используйте привычного агента

Univer CLI поддерживает следующие агенты:

**OpenCode** · **Claude Code** · **OpenClaw** · **Hermes** · **Codex** · **WorkBuddy** · **Kimi Work**

Эти агенты имеют общий интерфейс: `univer` хост с поддержкой Agent Skills может загружать официальный Skill, а агент, который может выполнять команды, также может вызывать Univer хостинг-специфические функции, такие как карты предварительного просмотра разговора, охватываются [интеграционные проекты](https://univer.ai/ecosystem).

## Увидеть первый результат [#quick-start]

Univer CLI требует Node.js 24 или новее. Установите его в среде, где работает ваш агент:

```bash
npm install --global univer-cli@latest
npx skills add dream-num/skills -s univer-cli -g
univer doctor
```

`univer doctor` проверяет локальное время выполнения. Через Skill агент обнаруживает команды, загружает руководство для конкретного продукта, проверяет контент и доставляет результаты.

### Открыть официальный пример

В новом, пустом каталоге отправьте агенту следующую инструкцию:

```text
Открой официальный пример через Univer CLI.
Скачай https://univer.ai/cli-assets/hello.univer как hello.univer в текущий каталог.
Перечисли содержимое, дай ссылку на локальный Viewer и объясни, что можно попробовать.
```

Открытие существующего контента немедленно отображает нативные редакторы. Затем вы можете попросить агента пересмотреть этот контент или попробовать задачу создания ниже.

## Skills: руководства для агентов [#skills]

Эти навыки позволяют существующему агенту создавать, редактировать и проверять содержимое Office через Univer CLI. Сначала [Установите CLI и его навыки обнаружения](#quick-start), а затем загружать руководство по конкретным задачам, описанное ниже.

Навык представляет часть продукта в качестве руководства, которое агент может прочитать: модель контента, рабочий процесс редактирования, как найти API-интерфейсы Facade и требования к проверке. На этой основе агент определяет, какие возможности требуются для задачи, от первого редактирования до обзора и доставки.

**Discovery entry:** [Навыки `univer-cli`](https://github.com/dream-num/skills/blob/main/skills/univer-cli/SKILL.md), установленный в агенте, помогает ему распознавать задачи Office, а затем загружать полное руководство от локального CLI.

**Навыки Runtime:** Эти корабли с CLI и соответствуют его установленным командам и API-интерфейсам Facade. Загрузите сначала `core`, затем целевой продукт. Добавьте тему Skill, когда задача включает в себя вставки или формулы перекрестного контента.

### Загружайте инструкции под задачу [#load-skills]

В большинстве случаев агент читает это руководство самостоятельно. Разработчики также могут проверить его непосредственно:

```bash
univer skills list
univer skills get core
univer skills get sheet
univer skills path sheet
```

`list` показывает установленные навыки, `get` читает руководство, а `path` возвращает локальный каталог. `univer skills get core --full` включает в себя ссылки и шаблоны. Используйте `univer api find` и `univer api show` для поиска конкретных API.

### Каталог Skills [#skills-catalog]

Следуйте за именем, чтобы просмотреть руководство в его исходном репозитории. Для реальных задач используйте версию, возвращенную местной командой `univer skills get <name>`.

| Skill | Когда использовать |
| --- | --- |
| [`core`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/core/SKILL.md) | Общий рабочий процесс: понять блоки и рабочие деревья, найти и отредактировать контент, проверить его и представить его для обзора. |
| [`sheet`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/sheet/SKILL.md) | Электронные таблицы (Sheet): данные, формулы, форматирование, диаграммы и проверка результатов. |
| [`doc`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/doc/SKILL.md) | Документы (Doc): абзацы, форматированный текст, таблицы, диаграммы и разметка страницы. |
| [`slide`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/slide/SKILL.md) | Презентации (слайд): страницы, формы, текст, изображения и визуальные проверки. |
| [`base`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/base/SKILL.md) | Relational Table: таблицы, поля, записи и представления. |
| [`board`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/board/SKILL.md) | Полотна: элементы холста, диаграммы и проверки макета. |
| [`embed`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/embed/SKILL.md) | Встраивания: размещают контент из одного блока в другой и соединяют источники данных диаграмм. |
| [`cross-unit-formula`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/cross-unit-formula/SKILL.md) | Формулы между объектами: чтение диапазонов Sheet или полей Relational Table для вычислений в ячейках Sheet или фигурах с формулами. |

Например, для встраивания электронной таблицы в документ, загрузите `core → doc + sheet → embed`. Добавьте `cross-unit-formula`, когда ячейка листа или форма ссылается на данные из другого контента. Загрузка каждого руководства заранее не требуется. После обновления CLI перезагрузите `core` и продукт и тему Навыки, которые вы используете.

## Что можно создавать

- Превратите данные в конечный результат: очистите лист, напишите формулы, добавьте диаграммы и таблицы поворотов, разместите отчет с заголовками и нижними колонками или создайте презентацию из контура.
- Сохраняйте контент подключенным: один файл `.univer` может содержать несколько типов контента, связанных с помощью формул, ссылок на диаграммы и встраиваемых файлов.
- Проверьте результат: прочитайте фактическую модель контента через Facade, а затем используйте скриншоты и проверки макета презентации, чтобы найти текст, который переполняется, перекрывается или запускается со страницы.
- Обзор перед доставкой: агент работает в изолированном Worktree и возвращает локальную ссылку Viewer. Проверяйте различия, запрашивайте изменения, сливайте или отбрасывайте результат, а также экспортируйте поддерживаемые форматы Office. Импорт и экспорт файлов Canvas пока недоступны.

## Роль Office SDK

Office SDK поставляет время выполнения безголового контента, Facade API, вычисление, рендеринг, версии и Worktrees. CLI собирает эти возможности в команды терминала и соответствующие версии Skills, и ему принадлежит локальное хранилище `.univer` , шлюз и зритель. Содержимое, которое пишет агент, может перемещаться непосредственно в предварительные просмотры редактора и стандартную доставку файлов.
