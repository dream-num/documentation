**Univer CLI** — локальное Office-приложение на **[Univer Office SDK](/overview)**. Оно даёт вашему агенту команды и Skills для работы с Excel, Word и PowerPoint или создания электронных таблиц, документов, презентаций, реляционных таблиц и холстов. Результаты остаются на вашем компьютере.

**Основной способ работы с Univer сейчас — CLI (Command-Line Interface, интерфейс командной строки)**, который заменяет прежний подход к интеграции агентов через MCP. Univer CLI предоставляет команду `univer` и Skills: агенты редактируют, проверяют и передают результаты через свои средства выполнения команд, а локальный Viewer позволяет просматривать и рецензировать их.

## Используйте привычного агента

Univer CLI можно использовать с этими агентами:

**OpenCode** · **Claude Code** · **OpenClaw** · **Hermes** · **Codex** · **WorkBuddy** · **Kimi Work**

Общий интерфейс — команда `univer` и инструкции для установленной версии. Хосты с Agent Skills загружают официальную Skill; агенты с исполнением команд могут вызывать CLI через свои инструменты. Карточки предпросмотра и другие возможности хоста описаны в [проектах интеграции](https://univer.ai/ecosystem).

## Увидеть первый результат [#quick-start]

Используйте Node.js 24 или новее и установите в окружении агента:

```bash
npm install --global univer-cli@latest
npx skills add dream-num/skills -s univer-cli -g
univer doctor
```

`univer doctor` проверяет локальную среду. Skill помогает агенту находить команды, загружать инструкции нужного продукта, проверять содержимое и передавать результат.

### Открыть официальный пример

В новом пустом каталоге отправьте агенту:

```text
Открой официальный пример через Univer CLI.
Скачай https://univer.ai/cli-assets/hello.univer как hello.univer в текущий каталог.
Перечисли содержимое, дай ссылку на локальный Viewer и объясни, что можно попробовать.
```

Готовое содержимое позволяет сразу увидеть настоящие редакторы. Затем запросите изменения или попробуйте задачу создания ниже.

## Skills: руководства для агентов [#skills]

Skills объединяют описание модели содержимого, порядок редактирования, поиск Facade API и требования к проверке в руководства, которые может прочитать агент. Они помогают найти нужные возможности для задачи — от редактирования до проверки и передачи результата.

**Точка обнаружения:** Установленный в агенте [Skill `univer-cli`](https://github.com/dream-num/skills/blob/main/skills/univer-cli/SKILL.md) помогает распознать задачи Office и загрузить полные инструкции из локального CLI.

**Skills среды выполнения:** Поставляются вместе с CLI и соответствуют командам и Facade API установленной версии. Сначала загрузите `core`, затем нужный продукт, а для встраивания и формул между разными объектами — соответствующую тему.

### Загружайте инструкции под задачу [#load-skills]

Обычно агент читает инструкции самостоятельно, но разработчик также может посмотреть их напрямую:

```bash
univer skills list
univer skills get core
univer skills get sheet
univer skills path sheet
```

`list` выводит установленные Skills, `get` читает руководство, а `path` возвращает локальный каталог. Команда `univer skills get core --full` также включает справочные материалы и шаблоны. Нужные API можно найти с помощью `univer api find` и `univer api show`.

### Каталог Skills [#skills-catalog]

Нажмите на название, чтобы открыть руководство в исходном коде. Для реальных задач используйте версию, которую возвращает локальная команда `univer skills get <name>`.

| Skill | Когда использовать |
| --- | --- |
| [`core`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/core/SKILL.md) | Общий процесс: понимание Unit и Worktree, поиск содержимого, редактирование, проверка и передача на ревью. |
| [`sheet`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/sheet/SKILL.md) | Электронные таблицы (Sheet): данные, формулы, форматирование, диаграммы и проверка результатов. |
| [`doc`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/doc/SKILL.md) | Документы (Doc): абзацы, форматированный текст, таблицы, диаграммы и разметка страницы. |
| [`slide`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/slide/SKILL.md) | Презентации (Slide): слайды, фигуры, текст, изображения и визуальная проверка. |
| [`base`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/base/SKILL.md) | Relational Table: таблицы, поля, записи и представления. |
| [`board`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/board/SKILL.md) | Canvases: элементы холста, диаграммы и проверка расположения. |
| [`embed`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/embed/SKILL.md) | Встраивание: размещение содержимого одного Unit внутри другого и подключение источников данных диаграмм. |
| [`cross-unit-formula`](https://github.com/dream-num/univer-cli/blob/main/apps/cli/src/skills/runtime/cross-unit-formula/SKILL.md) | Формулы между объектами: чтение диапазонов Sheet или полей Relational Table для вычислений в ячейках Sheet или фигурах с формулами. |

Например, чтобы встроить таблицу в документ, загрузите `core → doc + sheet → embed`. Добавьте `cross-unit-formula`, если ячейка Sheet или фигура ссылается на данные другого объекта. Загружать все руководства заранее не нужно. После обновления CLI повторно загрузите `core` и Skills нужных продуктов и тем.

## Что можно создавать

- **От данных к результату:** Очищайте таблицы, создавайте формулы, диаграммы и сводные таблицы, отчёты с колонтитулами или презентации по плану.
- **Связанное содержимое:** Один файл `.univer` может содержать разные типы материалов, соединённые формулами, ссылками диаграмм и встроенными блоками.
- **Проверка результата:** Читайте реальную модель через Facade и используйте снимки и проверку макета презентаций для обнаружения переполнения, наложения и выхода текста за страницу.
- **Проверка до передачи:** Агент работает в изолированном Worktree и возвращает ссылку на локальный Viewer. Изучайте различия, запрашивайте исправления, объединяйте или отклоняйте изменения и экспортируйте поддерживаемые Office-форматы. Импорт и экспорт файлов холста пока недоступны.

## Попробуйте такую задачу

> Через Univer CLI создай месячную таблицу расходов с датой, категорией, суммой и пятью строками примера. Добавь формулу итога и диаграмму по категориям. Проверь данные и отображение, дай ссылку Viewer и не объединяй изменения до моей проверки.

## Роль Office SDK

Office SDK предоставляет Headless-среду, Facade API, расчёты, рендеринг, версии и Worktree. CLI объединяет их в команды и согласованные с версией Skills, управляя локальными `.univer`, Gateway и Viewer. Содержимое, созданное агентом, можно просмотреть в редакторе и передать в стандартном формате.
