**Univer Office Copilot**은 **[Univer Office SDK](/overview)**, LangChain, React, TypeScript로 만든 오픈 소스 참조 웹 앱입니다. 대화 도우미 옆에서 스프레드시트, 문서, 슬라이드, 관계형 테이블, 캔버스를 편집합니다. 실행 가능한 코드 예제를 바탕으로 자신만의 Office Copilot을 만들 수 있습니다.

[로컬 실행](#quick-start) · [편집 가능한 예제](https://github.com/dream-num/univer-office-copilot#included-examples) · [소스 저장소](https://github.com/dream-num/univer-office-copilot)

![Copilot 대화 옆에 열린 재무 워크북과 작업 공간의 여섯 예제 파일](/assets/examples/office-copilot/overview.webp)

## 만들 수 있는 앱

| 제품 | 앱 예시 |
| --- | --- |
| Sheets | 재무 모델, 시나리오 분석, 수식과 차트. |
| Docs | Modern Docs 또는 Paged Docs 기반 리서치 보고서와 메모. |
| Slides | 편집 가능한 투자자 자료와 프로젝트 프레젠테이션. |
| Base | 연결된 레코드, 업무 추적, 실시간 대시보드. |
| Board | 의사결정 지도, 워크플로, 연결된 다이어그램. |

## 참조 앱을 로컬에서 실행 [#quick-start]

**Node.js 24+**와 **pnpm 10.33.4**를 사용합니다:

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

[http://127.0.0.1:5173](http://127.0.0.1:5173)을 엽니다. 새 로컬 데모 계정에는 다섯 제품과 두 문서 모드를 포함하는 여섯 개의 비공개 편집 예제가 생성됩니다. 탐색과 수동 편집에는 모델 키, Docker, 외부 데이터베이스가 필요하지 않습니다.

Copilot을 사용하려면 채팅의 모델 메뉴에서 **Add model** 또는 **Manage models**를 선택하고 공급자, 모델 ID, API 키를 설정하세요. OpenAI, Anthropic, Google Gemini, DeepSeek, OpenRouter, 사용자 지정 OpenAI 호환 HTTPS 엔드포인트를 지원합니다. **Ask**로 파일을 확인하고 **Edit**로 현재 파일을 직접 수정합니다.

AI 텍스트 측정과 렌더링 검증에는 로컬 Chrome, Chromium 또는 Edge가 필요합니다. 모델 설정, 첨부 파일, 가져오기·내보내기와 브라우저 설정은 [로컬 개발 가이드](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md)를 참고하세요.

<Callout type="info">
앱 소스는 Apache-2.0입니다. 포함된 Univer Pro 기능에는 별도의 SDK 라이선스 조건이 적용되며, 이 앱이 Pro 라이선스를 부여하지는 않습니다. [SDK 라이선스](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md#univer-licensing)를 확인하세요.
</Callout>

## Office SDK가 지원하는 구현 [#sdk-integration]

React 작업 공간은 편집기와 채팅 UI를 제공합니다. Node 백엔드는 LangChain 도구 루프, 제품 Skills, 제한된 편집 스크립트를 헤드리스 Univer 클라이언트에서 실행합니다. 확정된 변경은 사람의 편집과 같은 협업 채널로 브라우저에 전달되며, 네이티브 콘텐츠 재조회와 렌더링 검사가 검증 피드백을 제공합니다.

Modern Docs는 Markdown, Paged Docs는 Typst를 사용하며 Slides는 SVG를 편집 가능한 요소로 컴파일합니다. 파일별 여러 대화, 첨부 컨텍스트, 턴별 변경 확인, 네이티브 파일 기록, 소유자 복원, 파일과 대화의 개별 공유도 포함합니다.

[아키텍처](https://github.com/dream-num/univer-office-copilot/blob/main/docs/architecture.md)와 [확장 가이드](https://github.com/dream-num/univer-office-copilot/blob/main/docs/extending.md)를 기반으로 개발하고, 하위 기능인 [콘텐츠 작업](/ai/content-operations), [협업](/overview/features/shared/collaboration), [기록](/overview/features/shared/history)도 살펴보세요.
