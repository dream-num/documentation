**Univer 사무실 Copilot**는 **[Univer Office SDK](/overview)**, LangChain, React 및 TypeScript와 내장 된 오픈 소스 참조 웹 응용 프로그램입니다. 그것은 편집 가능한 스프레드 시트, 문서, 슬라이드, 관계 테이블 및 대화 조수 옆에 캔버스를 배치합니다. 코드 샘플은 수정없이 실행되며 자신의 사무실 copilot에 대한 시작점 역할을 할 수 있습니다.

[로컬 실행](#quick-start) · [편집 가능한 예제](https://github.com/dream-num/univer-office-copilot#included-examples) · [소스 저장소](https://github.com/dream-num/univer-office-copilot)

## 만들 수 있는 앱

| 제품 | 앱 예시 |
| --- | --- |
| Sheets | 재무 모델, 시나리오 분석, 수식과 차트. |
| Docs | Modern Docs 또는 Paged Docs 기반 리서치 보고서와 메모. |
| Slides | 편집 가능한 투자자 자료와 프로젝트 프레젠테이션. |
| Base | 연결된 레코드, 업무 추적, 실시간 대시보드. |
| Board | 의사결정 지도, 워크플로, 연결된 다이어그램. |

## 참조 앱을 로컬에서 실행 [#quick-start]

참고 응용 프로그램은 **Node.js 24+** 및 **오후 10.33.4**를 요구합니다:

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

[http://127.0.0.1:5173](http://127.0.0.1:5173)를 엽니다. 새로운 로컬 데모 계정은 모든 5개의 제품 및 문서 모드를 모두 포함하는 6개의 개인, 편집 가능한 예로 시작합니다. 탐색 및 수동 편집은 모델 키, Docker 또는 외부 데이터베이스가 필요하지 않습니다.

Copilot을 사용하려면 채팅에서 모델 메뉴를 열고 **모델 추가** 또는 **모델 관리**를 선택하십시오. 공급자, 모델 ID 및 API 키를 설정합니다. 이 응용 프로그램은 OpenAI, Anthropic, Google Gemini, DeepSeek, OpenRouter 및 사용자 정의 OpenAI 호환 HTTPS 엔드 포인트를 지원합니다. 파일을 검사하려면 **Ask**를, 현재 파일을 직접 변경하려면 **Edit**를 선택하십시오.

AI 텍스트 측정 및 렌더링 체크는 Chrome, Chromium 또는 Edge가 로컬로 설치해야합니다. 모델 구성, 첨부 파일, 수입 및 수출 및 브라우저 설정은 [지역 개발 가이드](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md)에 설명되어 있습니다.

<Callout type="info">
애플리케이션 소스는 Apache-2.0에서 라이센스됩니다. 임베디드 Univer Pro 기능에는 별도의 SDK 라이선스 조건이 있으며, 이 응용 프로그램은 프로 라이센스를 부여하지 않습니다. [SDK 라이센스](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md#univer-licensing)를 참조하십시오.
</Callout>

## Office SDK가 지원하는 구현 [#sdk-integration]

React 작업 공간은 편집기와 채팅 인터페이스를 보유하고 있습니다. Node 백엔드는 LangChain 도구 루프, 제품 기술 및 headless Univer 클라이언트에 대한 편집 스크립트를 실행합니다. 확인된 편집은 사용자가 사용하는 동일한 협업 채널에 브라우저에 도달하고 렌더링 된 체크와 함께 기본 읽기백은 검증 피드백을 제공합니다.

현대 Docs 사용 Markdown, Paged Docs 사용 Typst, 및 슬라이드 사용 SVG 편집 가능한 요소로 컴파일. 응용 프로그램은 또한 파일, 첨부 컨텍스트, 회전 변경 검사, 기본 파일 역사, 소유자 제어 복원 및 파일 및 대화에 대한 별도 공유 당 여러 대화를 지원합니다.

[의 특징](https://github.com/dream-num/univer-office-copilot/blob/main/docs/architecture.md)와 [관련 링크](https://github.com/dream-num/univer-office-copilot/blob/main/docs/extending.md)에 빌드하거나 [콘텐츠 운영](/ai/content-operations), [의논하기](/overview/features/shared/collaboration) 및 [- 연혁](/overview/features/shared/history) 기능을 살펴보십시오.
