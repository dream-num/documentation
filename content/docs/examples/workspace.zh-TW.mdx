Univer Workspace 是以 **[Univer Office SDK](/docs/overview)** 建構的開源辦公應用，面向人與 Agent 共同工作的情境。部署包含 **Server 與 Web** 的線上版本，讓團隊在瀏覽器中辦公，再透過 **Workspace CLI + Skills** 接入既有 Agent。

## 共享資料成為 Agent 的工作上下文 [#workspace-context]

![共享資料成為 Agent 的工作上下文](/assets/examples/workspace-desktop/space-overview.jpg)

Aurora 空間將可計算的營運模型、決策簡報、簡報投影片、任務台帳與策略畫布放在一起。Web 與 Desktop 連接同一批共享檔案，Agent 讀取資料，在 Worktree 中準備修改；新文件在審閱者確認合併前保留為草稿。 同一案例的[Desktop 對話與預覽](/docs/examples/workspace-desktop#conversation-preview)展示了具體的產生與修訂過程。

繼續查看[一般 Space 的操作片段](/docs/examples/workspace-desktop#space-walkthrough)與 [Web + Desktop 跨裝置協作](/docs/examples/workspace-desktop#cross-device-collaboration)。協作範例使用同一帳號，在兩個用戶端編輯同一份文件。

## 線上版：Server 與 Web 組成完整工作區 [#entry-points]

<span id="web-start" />

**Workspace Server** 管理個人與團隊空間、目錄、權限、內容儲存、協同與版本；**Web 是其線上辦公介面**，讓團隊在瀏覽器中編輯、協作並審閱 Agent 的變更。部署這套應用後，人與 Agent 便能圍繞同一份內容工作。

## Workspace CLI：讓任意 Agent 進入工作區 [#cli-start]

線上版部署後，不必為每種 Agent 開發一套 Office 整合。將 CLI 與 Skill 安裝到 Agent 的執行環境，具備指令執行能力的 Agent 就能尋找檔案、編輯內容、計算、截圖、驗證並交付審閱連結。模型與對話仍由你選擇的 Agent 提供。

使用 Node.js 22.12 或更新版本，建議 24。npm 套件為 `univer-workspace-cli`，提供 `uvw` 與 `univer-workspace-cli` 兩個指令名稱。

```bash
npm install --global univer-workspace-cli@latest
npx skills add dream-num/univer-workspace --skill univer-workspace-cli -g
uvw --version
```

預設連接線上體驗服務。接入自己的部署時，設定服務位址即可：

```bash
uvw config set workspace.origin https://space.univer.ai
```

首次連接依 CLI 提示完成一次登入，之後由 CLI 管理工作階段，Agent 可在後續任務重複使用。不必為 Agent 編寫登入頁面、OAuth 回呼或獨立驗證整合。

<details>

<summary>首次連接：完成一次瀏覽器登入</summary>

已有有效工作階段時可略過。需要登入時執行：

```bash
uvw auth login
```

開啟回傳連結，在瀏覽器登入並確認驗證碼。使用者確認完成後再執行：

```bash
uvw auth login --complete
```

僅在建立工作階段時需要此步驟。完整指令與驗證說明見 [Workspace CLI 指南](https://github.com/dream-num/univer-workspace/blob/main/apps/cli/README.md)。

</details>

## Skills：讓 Agent 理解工作區並完成任務 [#skills]

安裝給既有 Agent 的 [`univer-workspace-cli` Skill](https://github.com/dream-num/univer-workspace/blob/main/skills/univer-workspace-cli/SKILL.md) 是探索入口，說明如何連接、定位目標並載入指引。完整執行階段 Skills 隨 CLI 發佈，與指令和 Facade API 版本配套；Desktop 的內建能力外掛也提供任務指引與工具。

| 指引 | 涵蓋內容 |
| --- | --- |
| `core` | 空間與檔案定位、任務草稿、內容驗證與審閱交付。 |
| `sheet` · `doc` · `slide` · `base` · `board` | 試算表、文件、簡報、關聯式表格（Relational Table）與畫布（Canvases）；SDK/API 保留 Base、Board。 |
| `blob` | 原始檔案上傳、下載與替換。 |
| `html-view` | 產生及管理即時 HTML 頁面，建立可互動的 Web App。 |
| `embed` · `cross-unit-formula` | 嵌入其他內容，以及跨內容的資料參照與公式。 |

```bash
uvw skills list
uvw skills get core
uvw skills get sheet
uvw skills get html-view
```

先載入 `core`，再依任務讀取產品或主題。`skills get` 列出參考路徑，透過 `uvw skills read <name> <path>` 讀取所需文件，或用 `--full` 一起載入。既有 Agent 透過 CLI 使用這些能力，Desktop 則將工具與指引整合進對話流程。

```text
將變更放在獨立草稿，檢查資料、公式與顯示效果，提供預覽或審閱連結，在我確認前不要合入。
```

## 從辦公文件到 Web App [#web-apps]

除了試算表、文件、簡報、關聯式表格和畫布，也可讓 Agent 依內容產生 Web App，例如營運看板、互動報告、預算模擬器或業務操作頁面。HTML View 與雙向綁定將指標、圖表、輸入框和滑桿連接到試算表：頁面操作更新資料，資料變更也回到頁面，並可接入協同。

```text
依剛才的開銷試算表建立簡潔的預算看板 Web App，顯示總額、分類圖表及預算輸入框，將顯示與輸入綁定到試算表資料。檢查雙向更新，提供預覽和審閱入口。
```

## 把需求、修改和審閱串起來

Workspace CLI 還提供 `uvw issue` 和 `uvw pr`：Issue 承載團隊需求與討論，PR 承載待審閱的變更，其底層是 Worktree。Agent 可以讀取任務、操作原生內容、檢查結果，再交付供人審閱的變更。這個過程可以連接團隊任務與辦公成果。

## 檢視實際草稿，再決定是否合併 [#agent-review]

Desktop 的原生審閱畫面並排展示共享原稿與提議變更。也可以在 Workspace 中開啟同一草稿，檢視 Ready 狀態、變更檔案與原生文件畫面，透過 View 與 Compare 檢查結果後再決定是否合併。Agent 完成任務不會自動修改共享來源檔案。

## Office SDK 如何支撐 [#sdk-integration]

Web SDK 提供統一內容模型、編輯器、繪製與 Headless 處理；Server SDK 支援協同、版本及 Worktree；AI SDK 提供 Agent 操作與驗證能力。Workspace 將其組成可部署的 Server 與線上應用，CLI 對既有 Agent 開放這些能力，Desktop 則整合成可直接使用的 Agent 辦公應用。
