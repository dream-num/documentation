**Univer Office for WorkBuddy** (`workbuddy-univer-office`) integra Office local mediante las API públicas de **[Univer Office SDK](/docs/overview)**. Un servicio MCP y una Skill conectan creación, inspección, previsualización y revisión de borradores con WorkBuddy; los archivos permanecen en el espacio local.

<Callout type="info">
Versión preliminar de desarrollo. Hay un entorno de ejecución público en npm para la integración local; la instalación oficial desde el catálogo y la revisión completa dentro del anfitrión siguen pendientes de validación.
</Callout>

## Instalar y conectar [#quick-start]

Prepara WorkBuddy 5.8.3 o posterior y Node.js 22, versión 22.12 o posterior. Este ejemplo usa el paquete público 0.1.6. El contenido se guarda por defecto en el directorio local `~/.univer-office/workspace`.

### 1. Instalar el entorno local

```bash
npm install --global --ignore-scripts workbuddy-univer-office@0.1.6 --registry=https://registry.npmjs.org/
univer-office --version
```

Termina la instalación antes de conectar MCP para que la descarga inicial no consuma el tiempo de espera de conexión. La conexión local no requiere una cuenta en la nube ni una clave API de Office.

### 2. Conectar el servidor MCP local

Abre un directorio de trabajo autorizado en WorkBuddy y añade un servidor MCP stdio personalizado con esta configuración:

```json
{
  "mcpServers": {
    "univer-office": {
      "type": "stdio",
      "command": "univer-office",
      "args": []
    }
  }
}
```

Si WorkBuddy no encuentra `univer-office`, sustituye `command` por su ruta absoluta. Puedes obtenerla con `command -v univer-office` en macOS/Linux o `Get-Command univer-office` en Windows. Deja que WorkBuddy inicie stdio; no ejecutes también un servicio HTTP independiente sobre el mismo directorio. Para otro directorio de almacenamiento, configura `WORKBUDDY_OFFICE_WORKSPACE` con una ruta absoluta.

### 3. Importar el Skill operativo

Con Git y Python 3 disponibles, genera el ZIP de instrucciones desde el repositorio público, sin compilar la aplicación:

```bash
git clone https://github.com/dream-num/workbuddy-univer-office.git
cd workbuddy-univer-office
python3 scripts/package-workbuddy-skills.py
```

Importa `.data/packages/univer-office-workbuddy-skill.zip` en el gestor de Skills de WorkBuddy. Una vez conectado MCP, pide al asistente que compruebe el estado del servicio Office y envía la tarea siguiente. El Skill aporta instrucciones y MCP la ejecución; se necesitan ambos.

## Prueba una tarea de inmediato [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Usa Univer Office para crear el archivo local sales-review.univer con una hoja de ventas en inglés y cinco registros: Product, Quantity, Unit Price y Revenue. Calcula Revenue con fórmulas y añade el total y un gráfico de ingresos por producto.
Verifica las escrituras confirmadas y las fórmulas, muestra solo esta Sheet en el panel derecho y dame el enlace de revisión en el navegador. Mantén los cambios en un borrador aislado y espera mi aprobación antes de integrar.
```

</div>

### Qué verás

WorkBuddy muestra una hoja de solo lectura a la derecha. La vista completa, Compare y la confirmación de integración se abren en el navegador; el archivo permanece local. Una sola Sheet permite ver enseguida fórmulas y gráficos y evita la limitación del anfitrión al enrutar varias tarjetas en una misma respuesta.

### Sigue explorando

Tras aprobar e integrar el primer resultado, pide: «En un nuevo borrador de la misma hoja, sube un 10 % el precio unitario del primer registro, actualiza el total y abre Compare frente a la versión confirmada. Espera mi revisión». Así verás una comparación real antes y después.

## Cómo trabajan juntos los Skills y las herramientas [#skills]

Un único [Skill `univer-office`](https://github.com/dream-num/workbuddy-univer-office/tree/main/skills/univer-office) coordina el flujo con siete referencias de producto y entre contenidos cargadas según necesidad. El agente consulta Facade con `univer_api`, edita, confirma escrituras, lee resultados y muestra vistas previas mediante MCP. El mismo modelo de Office SDK sirve para el procesamiento sin interfaz y el renderizado web; las versiones y Worktrees permiten localizar, comparar y revisar cambios.

## Qué puedes crear

- **Crea desde tu asistente:** Pide a WorkBuddy crear o actualizar hojas, documentos, presentaciones, tablas relacionales y lienzos.
- **Sigue las vistas previas:** Consulta vistas de solo lectura dentro del anfitrión o abre el navegador externo para usar View y Compare completos.
- **Entiende los cambios:** View y Compare del borrador son de solo lectura. Compara versiones fijas, examina diferencias semánticas y navega al contenido afectado.
- **Del borrador a la entrega:** El agente edita un Worktree; una persona decide fusionar, revisar o descartar y exporta formatos compatibles desde una versión confirmada seleccionada.

## Cómo lo hace posible Office SDK [#sdk-integration]

WorkBuddy gestiona conversación y herramientas MCP. El servicio local combina el entorno Headless, Facade, las versiones colaborativas y los Worktrees de Office SDK; las vistas del navegador renderizan el mismo modelo. El proyecto muestra cómo empaquetar estas capacidades como herramientas locales y una interfaz de revisión.
