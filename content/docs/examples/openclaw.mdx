**Univer Office for OpenClaw** (`openclaw-univer-office`) connects OpenClaw to Workspace capabilities built with **[Univer Office SDK](/overview)**. Agents can discover Personal and Team Space files, edit and inspect task drafts, and return review links, preview images, or exported files.

[Install and connect](#quick-start) · [Try a task](#first-task) · [Skills and tools](#skills)

## Install and connect [#quick-start]

Prepare OpenClaw 2026.5.17 or newer, Node.js 22.22.3 or newer, and access to a Univer Workspace service. Install the following on the OpenClaw Gateway host. This example pins Workspace CLI 0.5.3 to match the current plugin’s command interface.

### 1. Install the CLI and plugin

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

The plugin uses `@dr-univer/openclaw-univer-office` from ClawHub. A separate local `univer-cli` installation is unnecessary.

### 2. Enable tools and connect the service

Merge this into your OpenClaw configuration, preserving existing tool permissions. If `tools.allow` already exists, append `univer-office` to that list:

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

Point the CLI at your Workspace service. This example uses the online demo; replace the address for a self-hosted deployment. Restart the Gateway after configuration.

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. Sign in from the conversation

Send this to OpenClaw:

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Connect to Univer Workspace and check my sign-in status. If sign-in is required, give me the browser approval URL and code, then wait until I finish.
```

</div>

Open the returned link on a phone or computer, sign in, and confirm the code. Tell OpenClaw you are done and approve its sign-in completion action. The plugin does not poll in place of your approval. Use sample data in the online demo.

## Try a task right away [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Use Univer Office to create an English Project Northstar weekly plan in my personal Workspace Space, with five sample tasks: Task, Owner, Estimated Hours, and Status. Use a formula to total the estimated hours.
Edit in an isolated Worktree, read back the data, check a screenshot, mark it ready for review, and give me one review link that opens on phone and computer. Do not merge or send it to anyone else; wait for my confirmation.
```

</div>

### What you will see

The chat returns a result summary and a review link. Phone and desktop browsers open the same Workspace draft. The native editor and full review interface stay in Workspace, while the chat channel can deliver progress, preview images, and exported files. Marking a draft ready leaves the current file unchanged.

### Keep exploring

For live teamwork, choose an existing Team Space and explicitly request a Space-visible draft. OpenClaw requests the relevant approval. Collaborators must be signed-in members of that Space; the shared link itself grants no access.

## How Skills and tools work together [#skills]

The plugin bundles a [`univer-office` Skill](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md). The agent locates Spaces with `univer_office_connect` and `univer_office_files`, loads core and product guidance through the content tool’s `guidance` action, then looks up Facade APIs, edits, and verifies. Workspace hosts Office SDK content, authorization, collaboration, and Worktrees; OpenClaw owns chat channels, tool approvals, and file delivery.

## What you can build

- **Reach team content from chat:** Find and browse authorized Spaces and files, then work on existing spreadsheets, documents, presentations, relational tables, and canvases.
- **Make tasks collaborative:** Edit in an isolated Worktree. Create a Space-visible draft when teammates should review together.
- **Inspect and deliver across devices:** Check structure, screenshots, and layout, then return a Workspace review link that opens in a phone or desktop browser.
- **Keep decisions with people:** Ready results still require a person to choose merge or discard. Deliver previews and exported files through OpenClaw’s message and file channels.

## How Office SDK powers it [#sdk-integration]

The plugin calls authoring and inspection through Workspace CLI. Workspace Server hosts Office SDK content, collaboration, versions, and Worktrees and enforces identity and permissions. OpenClaw owns conversation, channels, and tool approvals; full editing and review stay in Workspace. The agent terminal can run locally while the team collaborates through one service.
