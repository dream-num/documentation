**Univer Office for OpenClaw** (`openclaw-univer-office`) connects OpenClaw to the Workspace features built with the **[Univer Office SDK](/overview)**. An agent can locate files in Personal and Team Spaces, edit and inspect a task draft, and return a review link, preview images, or exported files.

[Install and connect](#quick-start) · [Try a task](#first-task) · [Skills and tools](#skills)

## Install and connect [#quick-start]

You need OpenClaw 2026.5.17 or newer, Node.js 22.22.3 or newer, and access to a Univer Workspace service. Run the following commands on the OpenClaw Gateway host. This example pins Workspace CLI 0.5.3 to match the command interface of the current plugin.

### 1. Install the CLI and plugin

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

The plugin is published on ClawHub as `@dr-univer/openclaw-univer-office`. A separate local `univer-cli` installation is not required.

### 2. Enable tools and connect the service

Add the following settings to the OpenClaw configuration and retain the existing tool permissions. If `tools.allow` already exists, append `univer-office` to that list:

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

Point the CLI at the Workspace service. The example below uses the online demo, so a self-hosted deployment requires a different address. Restart the Gateway after changing the configuration.

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. Sign in from the conversation

Send the following message to OpenClaw:

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Connect to Univer Workspace and check my sign-in status. If sign-in is required, give me the browser approval URL and code, then wait until I finish.
```

</div>

Open the returned link on a phone or computer, sign in, and confirm the code. Then inform OpenClaw that sign-in is complete and approve its sign-in completion action. The plugin does not poll in place of that approval, which must come from you. On the online demo, use sample data.

## Try a task right away [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Use Univer Office to create an English Project Northstar weekly plan in my personal Workspace Space, with five sample tasks: Task, Owner, Estimated Hours, and Status. Use a formula to total the estimated hours.
Edit in an isolated Worktree, read back the data, check a screenshot, mark it ready for review, and give me one review link that opens on phone and computer. Do not merge or send it to anyone else; wait for my confirmation.
```

</div>

### What you will see

The chat returns a summary of the result and a review link. The link opens the same Workspace draft in a phone browser and on a desktop. The native editor and the full review interface remain in Workspace, while the chat channel delivers progress, preview images, and exported files. Marking a draft ready leaves the current file unchanged.

### Keep exploring

For live teamwork, select an existing Team Space and explicitly request a draft that is visible to the Space. OpenClaw requests the approval that this requires. Collaborators must be signed-in members of that Space; the shared link alone grants no access.

## How Skills and tools work together [#skills]

The plugin bundles a [`univer-office` Skill](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md). The agent locates Spaces with `univer_office_connect` and `univer_office_files`, loads core and product guidance through the `guidance` action of the content tool, then looks up Facade APIs, makes edits, and verifies the result. Workspace hosts Office SDK content, authorization, collaboration, and Worktrees. OpenClaw manages chat channels, tool approvals, and file delivery.

## What you can build

- Access team content from chat: find and browse the Spaces and files you are authorized for, then work on existing spreadsheets, documents, presentations, relational tables, and canvases.
- Collaborate on tasks: edit in an isolated Worktree, and create a draft visible to the Space when teammates should review together.
- Inspect and deliver across devices: check structure, screenshots, and layout, then return a Workspace review link that opens in a phone or desktop browser.
- Keep decisions with people: a result marked ready still requires a person to choose merge or discard. Preview images and exported files are delivered through OpenClaw’s message and file channels.

## How Office SDK powers it [#sdk-integration]

The plugin calls authoring and inspection through Workspace CLI. Workspace Server hosts Office SDK content, collaboration, versions, and Worktrees, and enforces identity and permissions. OpenClaw manages conversation, channels, and tool approvals; full editing and review remain in Workspace. The agent terminal can run locally while the team collaborates through one service.
