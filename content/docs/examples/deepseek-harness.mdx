**Univer Office for DeepSeek Harness** (`dsh-univer-office`) is a DSH plugin built with **[Univer Office SDK](/docs/overview)**. Describe the outcome in natural language. The agent can create or revise spreadsheets, documents, presentations, relational tables, and canvases, keeping visual results in the current conversation.

[Install and connect](#quick-start) · [Try a task](#first-task) · [Skills and tools](#skills)

## Install and connect [#quick-start]

Prepare DeepSeek Harness, a configured model, and Node.js 22.19 or newer. Check the plugin repository’s [compatibility requirements](https://github.com/dream-num/dsh-univer-office#requirements-and-current-limits) for verified DSH versions before installing.

### Install the plugin

If DSH is running, stop it with Ctrl+C in its launch terminal, then install into the Web profile:

```bash
dsh plugin --profile web add dsh-univer-office
```

Restart DSH:

```bash
dsh web
```

Refresh the DSH browser page after startup and begin a new conversation in an accessible project directory. The plugin includes its runtime, tools, and Skills; a separate Univer CLI installation is unnecessary. Screenshots and layout checks require local Chrome, Chromium, or Edge.

## Try a task right away [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Use Univer Office to create a 3-slide English introduction to Project Northstar for new teammates. Slide 1: cover and a one-sentence goal. Slide 2: three sample milestones. Slide 3: three next actions. Use a consistent blue and green palette, clear headings, and editable text.
Work in an isolated draft, check every slide for overflow, overlap, and visual quality, and show the live preview and review card in this conversation. Wait for my approval before merging; export PowerPoint only when requested.
```

</div>

### What you will see

A floating window shows the deck as the agent works, and a review card remains in the conversation afterward. The result is an editable three-slide presentation. Ask for a revision such as “turn slide 2 into a timeline,” then approve or discard the draft.

## How Skills and tools work together [#skills]

The plugin bundles [shared and product Skills](https://github.com/dream-num/dsh-univer-office/tree/main/skills), which DSH loads for the task. The agent discovers matching Facade APIs with `univer_api`, edits through `univer_execute`, then checks readback, screenshots, and `univer_lint` results. Office SDK supplies calculation, rendering, and versioned content; the DSH plugin supplies floating previews and conversation review cards.

## What you can build

- **Watch work take shape:** Live preview windows can move, resize, fold, and maximize while the agent edits.
- **Review in the conversation:** Each file has its own preview card that remains available later. Continue revising, approve the draft, or discard it.
- **Deliver real Office content:** Work with existing Excel, Word, and PowerPoint files, create formulas, charts, and rich layouts, and export matching formats.
- **Have the agent inspect its work:** Combine model readback, screenshots, and presentation layout checks. Multiple content types can share a file and connect through formulas and embeds.

## How Office SDK powers it [#sdk-integration]

DSH owns conversations, sessions, and tool calls. The plugin connects Office SDK authoring, calculation, rendering, and Worktree workflows to those surfaces. Agents edit real content models; the SDK powers preview and review, while the plugin supplies floating windows, conversation cards, and session state. It demonstrates Office capabilities inside an existing agent product.
