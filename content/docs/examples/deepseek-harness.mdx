**Univer Office for DeepSeek Harness** (`dsh-univer-office`) is a DSH plugin built with the **[Univer Office SDK](/overview)**. It accepts a task description in natural language and allows the agent to create or revise spreadsheets, documents, presentations, relational tables, and canvases while keeping the visual result in the current conversation.

[Install and connect](#quick-start) · [Try a task](#first-task) · [Skills and tools](#skills)

## Install and connect [#quick-start]

Prepare DeepSeek Harness, a configured model, and Node.js 22.19 or newer. Before you install the plugin, check the [compatibility requirements](https://github.com/dream-num/dsh-univer-office#requirements-and-current-limits) in its repository for the DSH versions that have been verified.

### Install the plugin

If DSH is running, stop it with Ctrl+C in the terminal that launched it, then install the plugin into the Web profile:

```bash
dsh plugin --profile web add dsh-univer-office
```

Restart DSH:

```bash
dsh web
```

After DSH starts, refresh the DSH page in the browser and begin a new conversation in a project directory that the agent can access. The plugin includes its own runtime, tools, and Skills, so a separate Univer CLI installation is unnecessary. Screenshots and layout checks require Chrome, Chromium, or Edge on the local machine.

## Try a task right away [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Use Univer Office to create a 3-slide English introduction to Project Northstar for new teammates. Slide 1: cover and a one-sentence goal. Slide 2: three sample milestones. Slide 3: three next actions. Use a consistent blue and green palette, clear headings, and editable text.
Work in an isolated draft, check every slide for overflow, overlap, and visual quality, and show the live preview and review card in this conversation. Wait for my approval before merging; export PowerPoint only when requested.
```

</div>

### What you will see

A floating window displays the deck while the agent works, and a review card remains in the conversation afterward. The result is an editable three-slide presentation. You can request a revision such as “turn slide 2 into a timeline,” and then approve or discard the draft.

## How Skills and tools work together [#skills]

The plugin bundles [shared and product Skills](https://github.com/dream-num/dsh-univer-office/tree/main/skills), and DSH loads the subset that a given task requires. The agent locates the matching Facade APIs with `univer_api`, edits content through `univer_execute`, and then checks the readback, screenshots, and `univer_lint` results. Office SDK supplies calculation, rendering, and versioned content; the DSH plugin supplies floating previews and conversation review cards.

## What you can build

- See the result as it is built. Live preview windows support moving, resizing, folding, and maximizing while the agent edits.
- Review in the conversation. Each file has its own preview card that remains available afterward. You can continue revising the content, approve the draft, or discard it.
- Deliver real Office content. Work with existing Excel, Word, and PowerPoint files, create formulas, charts, and rich layouts, and export the matching formats.
- Have the agent inspect its own work. Combine model readback, screenshots, and presentation layout checks. Multiple content types can share a file and connect through formulas and embeds.

## How Office SDK powers it [#sdk-integration]

DSH owns conversations, sessions, and tool calls. The plugin connects Office SDK authoring, calculation, rendering, and Worktree workflows to those surfaces. Agents edit real content models, the SDK powers preview and review, and the plugin supplies floating windows, conversation cards, and session state. The combination shows how Office capabilities can appear inside an existing agent product.
