**Univerオフィスコピロット**は**[Univer Office SDK](/overview)**、LangChain、ReactおよびTypeScriptと造られるオープンソースの参照のWebアプリケーションです。それは編集可能なスプレッドシート、文書、スライド、リレーショナルテーブル、および会話アシスタントの横のキャンバスを配置します。コードサンプルは変更なしで実行され、あなた自身のオフィスのcopilotのための開始ポイントとして役立つことができます。

[ローカルで実行](#quick-start) · [編集可能なサンプル](https://github.com/dream-num/univer-office-copilot#included-examples) · [ソースリポジトリ](https://github.com/dream-num/univer-office-copilot)

## 構築できるアプリ

| 製品 | アプリの例 |
| --- | --- |
| Sheets | 財務モデル、シナリオ分析、数式、グラフ。 |
| Docs | Modern Docs または Paged Docs による調査レポートやメモ。 |
| Slides | 編集可能な投資家向け資料やプロジェクトのプレゼンテーション。 |
| Base | 関連レコード、業務管理、ライブダッシュボード。 |
| Board | 意思決定マップ、ワークフロー、接続された図。 |

## 参照アプリをローカルで実行 [#quick-start]

参照の適用は**Node.js 24+**および**午後10時～午後3時**を要求します:

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

[http://127.0.0.1:5173](http://127.0.0.1:5173)を開きます。 新しいローカルのデモアカウントは、すべての5つの製品と両方のドキュメントモードをカバーする6つのプライベートで編集可能な例から始まります。 参照とマニュアル編集は、モデルキー、ドッカー、または外部データベースを必要としません。

Copilot を使用するには、チャットでモデルメニューを開き、**モデルを追加** または **モデルの管理**. プロバイダー、モデル ID、API キーを設定します。 アプリケーションは OpenAI、Anthropic、Google Gemini、DeepSeek、OpenRouter およびカスタム OpenAI 互換 HTTPS エンドポイントをサポートしています。 **お問い合わせ** ファイルをチェックするか、 **編集する** 現在のファイルを直接変更します。

AI テキスト測定とレンダリングチェックには、Chrome、Chromium、Edge がローカルにインストールされています。モデル構成、添付ファイル、インポート、およびエクスポート、およびブラウザの設定は、[ローカル開発ガイド](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md) で記述されています。

<Callout type="info">
アプリケーションソースは、Apache-2.0 でライセンスされています。Univer Pro の組み込み機能は、別々の SDK ライセンス条件を持ち、このアプリケーションは Pro ライセンスを付与しません。[SDKライセンス](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md#univer-licensing)を参照してください。
</Callout>

## Office SDK による実装 [#sdk-integration]

React ワークスペースはエディタとチャットインターフェイスを保持しています。 Node バックエンドは、LangChain ツール ループ、プロダクト スキル、および headless Univerクライアントに対するバインドされた編集スクリプトを実行します。 確認された編集は、人々が使用している同じコラボレーション チャネル上のブラウザに到達し、レンダリングされたチェックとともにネイティブ リードバックは、検証フィードバックを提供します。

現代のドキュメントは、Markdown、Paged Docs は Typst を使用し、SVG は編集可能な要素にコンパイルされます。このアプリケーションは、ファイル、添付コンテキスト、パーターン変更検査、ネイティブファイル履歴、所有者制御復元、およびファイルと会話の共有を分ける複数の会話もサポートします。

[建築設計](https://github.com/dream-num/univer-office-copilot/blob/main/docs/architecture.md)と[エクステンションガイド](https://github.com/dream-num/univer-office-copilot/blob/main/docs/extending.md)をビルドするか、[コンテンツの操作](/ai/content-operations)、[コラボレーション](/overview/features/shared/collaboration)および[歴史・歴史](/overview/features/shared/history)機能をアンダーピンで探索するか。
