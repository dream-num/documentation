**Univer Office Copilot** は、**[Univer Office SDK](/overview)**、LangChain、React、TypeScript で構築されたオープンソースの参照 Web アプリです。スプレッドシート、ドキュメント、スライド、リレーショナルテーブル、キャンバスを対話アシスタントの横で編集できます。動作するコードサンプルを、自分の Office Copilot の出発点にできます。

[ローカルで実行](#quick-start) · [編集可能なサンプル](https://github.com/dream-num/univer-office-copilot#included-examples) · [ソースリポジトリ](https://github.com/dream-num/univer-office-copilot)

![Copilot の会話の横に財務ワークブックを表示し、ワークスペースに六つのサンプルファイルを配置した画面](/assets/examples/office-copilot/overview.webp)

## 構築できるアプリ

| 製品 | アプリの例 |
| --- | --- |
| Sheets | 財務モデル、シナリオ分析、数式、グラフ。 |
| Docs | Modern Docs または Paged Docs による調査レポートやメモ。 |
| Slides | 編集可能な投資家向け資料やプロジェクトのプレゼンテーション。 |
| Base | 関連レコード、業務管理、ライブダッシュボード。 |
| Board | 意思決定マップ、ワークフロー、接続された図。 |

## 参照アプリをローカルで実行 [#quick-start]

**Node.js 24+** と **pnpm 10.33.4** を使用します：

```bash
git clone https://github.com/dream-num/univer-office-copilot.git
cd univer-office-copilot
pnpm install --frozen-lockfile
pnpm dev
```

[http://127.0.0.1:5173](http://127.0.0.1:5173) を開きます。新しいローカルデモアカウントには、五つの製品と二つのドキュメントモードを網羅する六つの非公開・編集可能なサンプルが作成されます。閲覧と手動編集にはモデルキー、Docker、外部データベースは不要です。

Copilot を利用するには、チャットのモデルメニューから **Add model** または **Manage models** を選び、プロバイダー、モデル ID、API キーを設定します。OpenAI、Anthropic、Google Gemini、DeepSeek、OpenRouter、独自の OpenAI 互換 HTTPS エンドポイントに対応しています。**Ask** でファイルを確認し、**Edit** で現在のファイルを直接変更します。

AI のテキスト測定と描画結果の検証には、ローカルの Chrome、Chromium、Edge が必要です。モデル設定、添付資料、インポート・エクスポート、ブラウザー設定は[ローカル開発ガイド](https://github.com/dream-num/univer-office-copilot/blob/main/docs/local-development.md)を参照してください。

## Office SDK による実装 [#sdk-integration]

React のワークスペースがエディターとチャット UI を提供します。Node バックエンドは LangChain のツールループ、製品 Skills、制限付き編集スクリプトをヘッドレス Univer クライアント上で実行します。確定した変更は人の編集と同じ共同編集チャネルでブラウザーに届き、ネイティブ内容の再読込と描画結果の検証がフィードバックを提供します。

Modern Docs は Markdown、Paged Docs は Typst を使用し、Slides は SVG を編集可能な要素にコンパイルします。ファイルごとの複数会話、添付コンテキスト、各ターンの変更確認、ネイティブ履歴、所有者による復元、ファイルと会話の個別共有も含まれます。

[アーキテクチャ](https://github.com/dream-num/univer-office-copilot/blob/main/docs/architecture.md)と[拡張ガイド](https://github.com/dream-num/univer-office-copilot/blob/main/docs/extending.md)を基に開発し、基盤となる[コンテンツ操作](/ai/content-operations)、[共同編集](/overview/features/shared/collaboration)、[履歴](/overview/features/shared/history)も確認できます。
