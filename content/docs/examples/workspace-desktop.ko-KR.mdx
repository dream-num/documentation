**Univer Workspace Desktop**은 Codex와 Claude Code에서 익숙한 에이전트 작업 방식을 Office로 확장합니다. 요청과 자료를 전달하고 문서 작업을 맡긴 다음, 옆에서 결과를 확인하고 변경을 검토합니다. **[Univer Office SDK](/docs/overview)**와 기존 에이전트 런타임으로 구성한, 자체 Office 협업 공간을 위한 완성된 앱 예제입니다.

## 일상적인 Office 작업으로 확장되는 에이전트 경험 [#why-desktop]

Office 결과물은 계속 편집하고 수식을 계산하며 팀과 협업하고 변경을 검토할 수 있어야 합니다. Desktop은 이 과정을 하나의 환경에 연결합니다.

- **맥락 유지:** 대화, 파일, Workspace 자료와 로컬 참조를 함께 사용합니다.
- **기본 콘텐츠:** 편집 가능한 스프레드시트, 문서, 프레젠테이션, Relational Table과 Canvases를 만듭니다.
- **확인하며 수정:** 옆에서 결과와 수식, 레이아웃을 확인한 뒤 구체적인 수정을 요청합니다.
- **검토 후 전달:** Office 변경은 Worktree에 보관하고 사람이 차이를 확인한 뒤 공유 공간에 병합합니다.

## 데스크톱이 연결하는 기능

| 기능 | 경험 |
| --- | --- |
| 에이전트 세션 | 대화와 작업 맥락을 유지하고 모델 제공자와 자격 증명을 로컬에서 설정합니다. |
| 파일과 참조 | 접근 가능한 Space를 탐색하고 @로 Workspace 파일, 폴더와 로컬 자료를 참조합니다. |
| Office 미리 보기 | 실제 콘텐츠를 옆에서 열고 결과와 변경을 전환합니다. |
| 검토와 전달 | Worktree의 추가·수정·삭제를 검토하고 수정, 병합 또는 폐기를 선택합니다. |
| 로컬과 온라인 | 팀 서비스 또는 컴퓨터에서 실행하는 Workspace에 연결합니다. |

## 설치하고 연결하기 [#quick-start]

1. [GitHub Releases](https://github.com/dream-num/univer-workspace/releases)에서 agent-v 태그의 Desktop을 선택합니다. Windows x64, macOS Apple Silicon, Linux x64를 대상으로 하며 실험 단계이므로 실제 공개 버전을 확인하세요.

2. **Settings → Workspace**에서 서비스를 선택하고 브라우저에서 로그인해 권한을 승인합니다. 기존 서비스나 [로컬 환경](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#connect-to-a-local-workspace)을 사용할 수 있습니다.

3. Models에서 지원하는 제공자, 모델과 자격 증명을 설정합니다. Workspace 로그인과 별도이며 [모델 설정](https://github.com/dream-num/univer-workspace/blob/main/apps/agent/README.md#model-credentials)을 참고하세요.

4. 접근 가능한 개인 또는 팀 Space를 추가하고 대화를 시작해 @로 자료를 참조합니다. 아래 작업으로 미리 보기와 변경 검토를 체험하세요.

설치 프로그램은 에이전트 앱과 Office 도구를 포함합니다. Workspace 서비스는 로컬 또는 서버에서 별도로 실행하며 모델 접근도 설정해야 합니다.

## Skills가 요청을 실행 가능한 Office 작업에 연결 [#skills]

기능 플러그인은 **univer** Skill과 참조 자료를 포함합니다. Space와 문서 찾기, Office API, Worktree 생성·검증·전달을 안내합니다. 에이전트는 API를 찾아 기본 콘텐츠에 실행하고 결과를 검사합니다.

[기능 플러그인](https://github.com/dream-num/univer-workspace/blob/main/packages/dsh-univer-workspace-plugin/README.md)은 문서 검색·생성, Headless Facade 편집, 구조 검사, 가져오기·내보내기와 Worktree 도구를 연결합니다. 병합과 폐기는 호스트 승인을 거칩니다. 업무별 Skills, 템플릿과 도구를 추가할 수 있습니다.

## Office 콘텐츠를 Web App으로 확장 [#web-apps]

HTML View는 입력과 차트를 시트 데이터에 연결하여 대화형 보고서와 예산 대시보드를 구성합니다. [양방향 바인딩](/docs/features/shared/binding)은 실험 단계이며 변경될 수 있습니다.

HTML 게시와 바인딩 쓰기는 각각의 저장·권한 흐름을 따릅니다. 기본 Office 초안은 Worktree로 검토합니다.

## 자체 에이전트 Office 공간 구축 [#build-your-own]

Workspace Desktop은 기존 모듈을 완전한 제품으로 조합하는 예제입니다. 에이전트 호스트와 Workspace를 재사용하고 필요한 Office 기능을 조합하면 업무 데이터, 도구, 템플릿과 전달 흐름에 집중할 수 있습니다.

| 구성 요소 | 역할 |
| --- | --- |
| [Web SDK](/guides/sheets) | 공통 모델, Office 편집기, 렌더링, 수식과 Headless Facade 작업. |
| [Server SDK](/server) | 앱 백엔드와 연결하는 협업, 버전과 Worktree 기능. |
| [AI SDK](/ai) | 에이전트용 콘텐츠 작업, 검사와 검증. |
| 런타임과 Skills | DSH가 대화, 모델, 도구 실행과 승인을 제공하고 Workspace 플러그인이 Office를 연결합니다. |
| Workspace와 Desktop | 앱이 Space, 파일, ID 연동과 검토 UI를 제공하고 Electron이 데스크톱으로 전달합니다. |

요청 → 도구 → 편집 가능한 콘텐츠 → 미리 보기 → 검토 → 공유 전달을 재사용합니다. Office SDK는 Office 계층, 호스트는 대화와 실행 루프를 제공합니다. [기존 앱과 플러그인](https://github.com/dream-num/univer-workspace/tree/main/apps/agent)을 확장하거나 자체 호스트에 연결할 수 있습니다.
