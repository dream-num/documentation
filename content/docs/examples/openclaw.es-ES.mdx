**Oficina Univer para OpenClaw** (`openclaw-univer-office`) conecta OpenClaw con las características del espacio de trabajo construidas con el **[Univer Office SDK](/overview)**. Un agente puede localizar archivos en espacios personales y de equipo, editar e inspeccionar un borrador de tareas, y devolver un enlace de revisión, imágenes de vista previa o archivos exportados.

[Instalar y conectar](#quick-start) · [Probar una tarea](#first-task) · [Skills y herramientas](#skills)

## Instalar y conectar [#quick-start]

Necesita OpenClaw 2026.5.17 o más reciente, Node.js 22.22.3 o más reciente y acceso a un servicio de espacio de trabajo Univer. Ejecute los siguientes comandos en el host OpenClaw Gateway. Este ejemplo marca Workspace CLI 0.5.3 para que coincida con la interfaz de comando del plugin actual.

### 1. Instalar la CLI y el complemento

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

El plugin se publica en ClawHub como `@dr-univer/openclaw-univer-office`. No se requiere una instalación local separada `univer-cli` .

### 2. Activar herramientas y conectar el servicio

Añada los siguientes ajustes a la configuración OpenClaw y conserve los permisos de herramientas existentes. Si `tools.allow` ya existe, anexa `univer-office` a esa lista:

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

Apunte el CLI en el servicio Workspace. El ejemplo a continuación utiliza la demo en línea, por lo que un despliegue auto hospedado requiere una dirección diferente.

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. Iniciar sesión desde la conversación

Enviar el siguiente mensaje a OpenClaw:

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Conecta con Univer Workspace y comprueba mi sesión. Si necesito iniciar sesión, dame el enlace de autorización del navegador y el código, y espera a que termine.
```

</div>

Abra el enlace devuelto en un teléfono o computadora, inicie y confirme el código. Infórmele a OpenClaw que el registro está completo y apruebe su acción de terminación de registro. El plugin no encuesta en lugar de esa aprobación, que debe venir de usted. En la demo en línea, utilice datos de muestra.

## Prueba una tarea de inmediato [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Usa Univer Office para crear en mi espacio personal de Workspace un plan semanal en inglés de Project Northstar con cinco tareas: Task, Owner, Estimated Hours y Status. Suma las horas estimadas con una fórmula.
Edita en un Worktree aislado, lee los datos, revisa una captura, márcalo listo para revisión y dame un único enlace que funcione en móvil y ordenador. No integres ni lo envíes a otras personas; espera mi confirmación.
```

</div>

### Qué verás

El chat devuelve un resumen del resultado y un enlace de revisión. El enlace abre el mismo borrador Workspace en un navegador de teléfono y en un escritorio. El editor nativo y la interfaz de revisión completa permanecen en el espacio de trabajo, mientras que el canal de chat ofrece progreso, imágenes de vista previa y archivos exportados. Marcar un borrador listo deja el archivo actual sin cambios.

### Sigue explorando

Para el trabajo en equipo en vivo, seleccione un espacio en equipo existente y solicite explícitamente un proyecto que sea visible al espacio. OpenClaw solicita la aprobación que esto requiere. Los colaboradores deben ser firmados en miembros de ese espacio; el enlace compartido por sí solo no garantiza acceso.

## Cómo trabajan juntos los Skills y las herramientas [#skills]

El plugin agrupa un [`univer-office` Habilidad](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md). El agente localiza Espacios con `univer_office_connect` y `univer_office_files`, carga el núcleo y la orientación de producto a través de la acción `guidance` de la herramienta de contenido, luego mira Facade APIs, hace ediciones, y verifica el resultado. Workspace hosts Office contenido SDK, autorización, colaboración y Worktrees.

## Qué puedes crear

- Acceda al contenido del equipo desde el chat: encontrar y navegar por los espacios y archivos que está autorizado, luego trabajar en hojas de cálculo existentes, documentos, presentaciones, tablas relacionales y lienzos.
- Colaborar en tareas: editar en un Worktree aislado, y crear un borrador visible al Espacio cuando los compañeros de equipo deben revisar juntos.
- Inspecciona y entrega a través de dispositivos: estructura de verificación, capturas de pantalla y diseño, luego devuelve un enlace de revisión Workspace que se abre en un teléfono o navegador de escritorio.
- Mantener las decisiones con las personas: un resultado marcado aún requiere que una persona elija fusión o descarte. Previsualizar imágenes y archivos exportados se entregan a través del mensaje y los canales de archivo de OpenClaw.

## Cómo lo hace posible Office SDK [#sdk-integration]

El plugin llama a autor e inspección a través de Workspace CLI. Workspace Server acoge contenido de Office SDK, colaboración, versiones y Worktrees, y hace cumplir identidad y permisos. OpenClaw gestiona la conversación, canales y aprobaciones de herramientas; la edición y revisión completa permanecen en Workspace. El terminal agente puede funcionar localmente mientras el equipo colabora a través de un servicio.
