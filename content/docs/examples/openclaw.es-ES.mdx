**Univer Office for OpenClaw** (`openclaw-univer-office`) conecta OpenClaw con Workspace, creado con **[Univer Office SDK](/docs/overview)**. El agente puede buscar archivos personales o de equipo, editar e inspeccionar borradores y devolver enlaces de revisión, imágenes o archivos exportados.

[Instalar y conectar](#quick-start) · [Probar una tarea](#first-task) · [Skills y herramientas](#skills)

## Instalar y conectar [#quick-start]

Prepara OpenClaw 2026.5.17 o posterior, Node.js 22.22.3 o posterior y acceso a Univer Workspace. Instala lo siguiente en el equipo del Gateway. El ejemplo fija Workspace CLI 0.5.3 para corresponder a la interfaz de comandos del complemento actual.

### 1. Instalar la CLI y el complemento

```bash
npm install --global univer-workspace-cli@0.5.3
univer-workspace-cli --version
openclaw plugins install clawhub:@dr-univer/openclaw-univer-office
```

Se usa `@dr-univer/openclaw-univer-office` de ClawHub. No hace falta instalar por separado la CLI local `univer-cli`.

### 2. Activar herramientas y conectar el servicio

Combina esta configuración con la de OpenClaw, conservando los permisos existentes. Si ya hay una lista `tools.allow`, añade `univer-office` a ella:

```json
{
  "plugins": {
    "entries": {
      "univer-office": {
        "enabled": true
      }
    }
  },
  "tools": {
    "allow": [
      "univer-office"
    ]
  }
}
```

Apunta la CLI al servicio Workspace que usarás. El ejemplo utiliza la demo en línea; sustituye la dirección para un despliegue propio. Reinicia el Gateway después de configurar.

```bash
univer-workspace-cli config set workspace.origin https://space.univer.ai
openclaw gateway restart
```

### 3. Iniciar sesión desde la conversación

Envía a OpenClaw:

```text
Conecta con Univer Workspace y comprueba mi sesión. Si necesito iniciar sesión, dame el enlace de autorización del navegador y el código, y espera a que termine.
```

</div>

Abre el enlace en el móvil o el ordenador, inicia sesión y confirma el código. Indica a OpenClaw que has terminado y aprueba la acción de completar el acceso. El complemento no sustituye tu autorización por consultas repetidas. Usa datos de ejemplo en la demo en línea.

## Prueba una tarea de inmediato [#first-task]

<div className="[&_pre]:whitespace-pre-wrap [&_code]:whitespace-pre-wrap [&_code]:w-full! [&_pre]:wrap-anywhere">

```text
Usa Univer Office para crear en mi espacio personal de Workspace un plan semanal en inglés de Project Northstar con cinco tareas: Task, Owner, Estimated Hours y Status. Suma las horas estimadas con una fórmula.
Edita en un Worktree aislado, lee los datos, revisa una captura, márcalo listo para revisión y dame un único enlace que funcione en móvil y ordenador. No integres ni lo envíes a otras personas; espera mi confirmación.
```

</div>

### Qué verás

El chat devuelve un resumen y un enlace. Los navegadores del móvil y el ordenador abren el mismo borrador. El editor nativo y la revisión completa están en Workspace; el chat puede entregar progreso, imágenes y archivos exportados. Marcarlo listo no modifica la versión actual.

### Sigue explorando

Para colaborar en directo, elige un espacio de equipo existente y solicita explícitamente un borrador visible para sus miembros. OpenClaw pedirá la aprobación correspondiente. Los colaboradores deben pertenecer al espacio e iniciar sesión; el enlace no concede acceso por sí mismo.

## Cómo trabajan juntos los Skills y las herramientas [#skills]

El complemento incluye un [Skill `univer-office`](https://github.com/dream-num/openclaw-univer-office/blob/main/skills/univer-office/SKILL.md). El agente localiza espacios con `univer_office_connect` y `univer_office_files`, carga las guías generales y del producto mediante `guidance`, consulta Facade, edita y verifica. Workspace aloja el contenido, permisos, colaboración y Worktrees de Office SDK; OpenClaw gestiona canales, aprobaciones y entrega de archivos.

## Qué puedes crear

- **Accede a documentos desde el chat:** Busca espacios y archivos autorizados y trabaja con hojas, documentos, presentaciones, tablas relacionales y lienzos existentes.
- **Convierte tareas en borradores colaborativos:** Edita un Worktree aislado y hazlo visible al espacio cuando el equipo deba revisar conjuntamente.
- **Comprueba y entrega entre dispositivos:** Verifica estructura, capturas y diseño y devuelve un enlace de Workspace que se abra en móvil o escritorio.
- **Mantén la decisión en las personas:** Marcar listo no sustituye la decisión de fusionar o descartar. Las vistas y los archivos se entregan mediante los canales de mensajes y archivos de OpenClaw.

## Cómo lo hace posible Office SDK [#sdk-integration]

El plugin llama a operaciones e inspecciones mediante Workspace CLI. Workspace Server aloja contenido, colaboración, versiones y Worktrees de Office SDK y aplica identidad y permisos. OpenClaw gestiona conversación, canales y aprobaciones; la edición y revisión completas permanecen en Workspace. El agente puede ejecutarse localmente mientras el equipo comparte un servicio.
