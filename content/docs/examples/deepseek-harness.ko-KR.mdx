**Univer Office for DeepSeek Harness**(`dsh-univer-office`)는 **[Univer Office SDK](/docs/overview)**로 만든 DSH 플러그인입니다. 자연어로 원하는 결과를 설명하면 에이전트가 표, 문서, 프레젠테이션, 관계형 테이블, 캔버스를 만들거나 수정하고 대화에 시각적 결과를 남깁니다.

[설치 및 연결](#quick-start) · [작업 체험](#first-task) · [Skills와 도구](#skills)

## 설치 및 연결 [#quick-start]

DeepSeek Harness, 설정된 모델, Node.js 22.19 이상을 준비하세요. 설치 전에 저장소의 [호환성 요구 사항](https://github.com/dream-num/dsh-univer-office#requirements-and-current-limits)에서 검증된 DSH 버전을 확인하세요.

### 플러그인 설치

DSH가 실행 중이면 시작한 터미널에서 Ctrl+C로 종료한 뒤 Web 프로필에 설치합니다.

```bash
dsh plugin --profile web add dsh-univer-office
```

DSH를 다시 시작합니다.

```bash
dsh web
```

시작 후 DSH 브라우저 페이지를 새로고침하고 접근 가능한 프로젝트 폴더에서 새 대화를 시작하세요. 플러그인에 실행 환경, 도구, Skills가 포함되어 별도 Univer CLI 설치가 필요 없습니다. 스크린샷과 레이아웃 검증에는 로컬 Chrome, Chromium 또는 Edge가 필요합니다.

### 확인할 수 있는 결과

작업 중에는 플로팅 창에서 슬라이드 변화를 보고, 완료 후에도 대화에 검토 카드가 남습니다. 편집 가능한 슬라이드 3장이 생성됩니다. ‘2장을 타임라인으로 바꿔 주세요’처럼 수정한 뒤 초안을 승인하거나 폐기할 수 있습니다.

## Skills와 도구의 연동 [#skills]

DSH는 플러그인에 포함된 [공통 및 제품 Skills](https://github.com/dream-num/dsh-univer-office/tree/main/skills)를 작업에 맞게 불러옵니다. 에이전트는 `univer_api`로 해당 Facade API를 검색하고 `univer_execute`로 편집한 후 데이터 읽기, 스크린샷, `univer_lint`로 검증합니다. Office SDK가 계산, 렌더링, 버전을 제공하고 플러그인은 플로팅 미리 보기와 대화 내 검토 카드를 제공합니다.

## 무엇을 만들 수 있나요

- **만들어지는 과정을 확인:** 작업 중인 실시간 미리 보기 창을 이동·크기 조절·접기·최대화할 수 있습니다.
- **대화에서 검토:** 파일별 미리 보기 카드를 나중에 다시 열고 수정을 이어가거나 초안을 승인·폐기합니다.
- **실제 Office 파일 전달:** 기존 Excel, Word, PowerPoint를 처리하고 수식, 차트, 풍부한 레이아웃을 만든 뒤 해당 형식으로 내보냅니다.
- **에이전트가 결과 검사:** 모델 다시 읽기, 스크린샷, 슬라이드 레이아웃 검사를 조합합니다. 여러 콘텐츠를 같은 파일에 담고 수식과 임베드로 연결합니다.

## Office SDK가 담당하는 부분 [#sdk-integration]

DSH는 대화, 세션, 도구 호출을 담당합니다. 플러그인은 Office SDK의 콘텐츠 조작, 계산, 렌더링, Worktree를 여기에 연결합니다. 에이전트는 실제 모델을 편집하고 SDK는 미리 보기와 검토를 지원하며, 플러그인은 떠 있는 창, 대화 카드, 세션 상태를 구현합니다.
