Univer SDK MCP를 사용하면 코딩 Agent가 공식 문서와 API 참조를 검색하고 읽으며, [초기화 생성기](/tools/initialization-generator)와 같은 기능 카탈로그로 브라우저 편집기 초기화 코드를 생성할 수 있습니다.

## Agent 연결

Streamable HTTP MCP를 지원하는 Agent에 원격 서버를 추가하세요.

| 설정 | 값 |
| --- | --- |
| 이름 | `univer-docs` |
| 전송 방식 | Streamable HTTP |
| 서버 URL | `https://docs.univer.ai/mcp/docs` |
| 인증 | API 키 불필요 |

활성화한 뒤 Agent에서 다음 도구를 확인하세요.

| 도구 | 용도 |
| --- | --- |
| `search_docs` | 주제 또는 API 이름으로 가이드, 예제, API 참조 검색. 섹션과 언어로 필터링 가능 |
| `get_doc` | 코드, 출처, 버전 정보가 포함된 Markdown 페이지 읽기. 긴 페이지는 `nextLine`부터 계속 읽기 |
| `list_features` | 제품별 브라우저 기능 ID, 사용 가능 여부, 라이선스 요구 사항 확인 |
| `generate_setup` | 플러그인, 프리셋, 로케일, 스타일을 포함한 의존성과 초기화 파일 생성 |

## 개발 작업 설명

> Univer SDK MCP로 이 React 앱에 스프레드시트를 추가해 주세요. 먼저 설치된 SDK 버전과 기존 초기화 방식을 확인하고 통합 가이드를 읽어 주세요. 셀 편집과 스냅샷 저장을 구현한 뒤 빌드하고 동작을 검증해 주세요.

> Univer SDK MCP로 셀 숫자 형식을 변경하는 Facade API를 찾아 주세요. 필요한 기능 플러그인과 import를 확인한 뒤 기존 Node.js 통합을 수정해 주세요.

제품, 프레임워크, 실행 환경, 기대 동작을 알려 주세요. 검색 요약은 자료를 찾는 용도이며 구현 전에 관련 가이드와 API 페이지를 읽어야 합니다. 아이콘에는 [Univer Icons MCP](/guides/icons/ai)를 사용할 수 있습니다.

서비스는 이 사이트와 함께 배포된 문서를 읽습니다. 응답의 문서 또는 생성기 버전을 프로젝트에 설치된 패키지와 비교하세요. 생성 코드는 브라우저 편집기용이며 일부 기능은 라이선스나 백엔드 설정이 필요합니다. 수명 주기, Headless Univer, 협업, 파일 변환은 해당 가이드를 참고하세요. 서비스가 파일 내용을 반환하면 Agent가 프로젝트에 적용하고 테스트합니다.
