Univer SDK MCP는 코딩 대리인을 위한 먼 MCP 서버입니다. 그것은 공식 문서를 검색하고, API 참고를 읽고, [초기화 발전기](/tools/initialization-generator)와 동일한 카탈로그를 사용하여 브라우저 편집기를 위한 초기화 코드를 생성합니다.

## Agent 연결

Streamable HTTP MCP를 지원하는 에이전트에 서버를 추가:

| 설정 | 값 |
| --- | --- |
| 이름 | `univer-docs` |
| 전송 방식 | Streamable HTTP |
| 서버 URL | `https://docs.univer.ai/mcp/docs` |
| 인증 | API 키 불필요 |

서버가 활성화되면 에이전트가 도구가 볼 수 있음을 확인합니다.

| 도구 | 용도 |
| --- | --- |
| `search_docs` | 검색 가이드, 예제, 및 API 참조 주제 또는 API 이름, 섹션 및 언어에 의해 필터링 |
| `get_doc` | Markdown으로 페이지를 읽으십시오. 코드, 소스 및 버전 정보; 긴 페이지를 계속하려면 `nextLine`를 사용하십시오. |
| `list_features` | 브라우저 기능 ID를 찾아 제품 지원, 가용성 및 라이센스 요구 사항과 함께 |
| `generate_setup` | 플러그인, 사전 설정, 로컬 및 스타일로 의존성 및 초기화 파일 생성 |

## 개발 작업 설명

> Univer SDK MCP를 사용하여 스프레드 시트를 React 응용 프로그램에 추가하십시오. 설치 된 SDK 버전과 현재 설정을 먼저 확인하고 통합 가이드를 읽으면 셀 편집 및 스냅 샷 절약을 추가하고 응용 프로그램을 확인하십시오.

> Univer SDK MCP를 사용하여 세포의 수 형식을 변경하는 Facade API를 찾을 수 있습니다. 기능 플러그인을 확인하고 기존 Node.js 통합을 변경하기 전에 가져야합니다.

제품, 프레임 워크, 런타임 및 원하는 행동을 가진 에이전트를 제공합니다. 검색 결과는 항목 포인트 만이므로 에이전트는 모든 코드를 작성하기 전에 관련 가이드와 API 페이지를 읽아야 합니다. 아이콘을 사용하려면 [Univer 아이콘](/guides/icons/ai)를 연결하십시오.

이 서비스는이 사이트에 게시 된 문서를 읽습니다. 각 응답은 프로젝트에서 설치 된 패키지와 비교할 수있는 문서 또는 생성기 버전을 식별합니다. 생성 된 설정 대상 브라우저 편집기, 일부 기능은 백엔드의 라이센스 또는 구성이 필요합니다. 프레임 워크 라이프 사이클, Headless Univer, 협업 및 파일 변환은 각각 전용 가이드가 있습니다. 서버는 파일 내용을 반환합니다; 에이전트는 프로젝트에서 적용 및 테스트합니다.
