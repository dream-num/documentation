Univer SDK MCP 讓程式設計 Agent 搜尋官方文件、讀取 API 參考，並使用與[初始化產生器](/tools/initialization-generator)相同的功能目錄產生瀏覽器編輯器接入程式碼。

## 連接 Agent

在支援 Streamable HTTP MCP 的 Agent 中新增遠端服務：

| 設定 | 值 |
| --- | --- |
| 名稱 | `univer-docs` |
| 傳輸方式 | Streamable HTTP |
| 服務網址 | `https://docs.univer.ai/mcp/docs` |
| 驗證 | 不需要 API Key |

啟用服務後，確認 Agent 可以看到以下工具：

| 工具 | 用途 |
| --- | --- |
| `search_docs` | 依主題或 API 名稱搜尋指南、範例與 API 參考，可篩選章節與語言 |
| `get_doc` | 讀取包含程式碼、來源與版本資訊的 Markdown 頁面，透過 `nextLine` 繼續讀取長頁面 |
| `list_features` | 查詢產品的瀏覽器功能 ID、可用性與授權需求 |
| `generate_setup` | 產生相依套件與初始化檔案，包含外掛、預設、語言包與樣式 |

## 描述開發需求

> 使用 Univer SDK MCP，在這個 React 應用程式中接入試算表。先檢查已安裝的 SDK 版本與現有初始化方式，閱讀整合指南，實作儲存格編輯與快照儲存，然後建置並驗證應用程式。

> 使用 Univer SDK MCP，查找修改儲存格數字格式的 Facade API。先確認所需的功能外掛與匯入，再修改現有的 Node.js 整合。

請告訴 Agent 產品類型、框架、執行環境與預期行為。搜尋摘要用於定位資料，撰寫程式碼前應讀取相關指南與 API 頁面。需要圖示時，可連接 [Univer Icons MCP](/guides/icons/ai)。

服務讀取隨本站發布的文件，結果包含文件或產生器版本，應與專案已安裝版本核對。初始化程式碼適用於瀏覽器編輯器，部分功能需要授權或業務後端設定。框架生命週期、Headless Univer、協同與檔案轉換應參考對應指南。服務回傳檔案內容，由 Agent 在你的專案中套用並測試。
