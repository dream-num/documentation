Univer SDK MCP 是一個面向程式設計 Agent 的遠端 MCP 服務。它可以搜尋官方文件、讀取 API 參考，並生成瀏覽器編輯器的接入程式碼，所用目錄與[初始化生成器](/tools/initialization-generator)一致。

## 連接 Agent

在支援 Streamable HTTP MCP 的 Agent 中新增該服務：

| 設定 | 值 |
| --- | --- |
| 名稱 | `univer-docs` |
| 傳輸方式 | Streamable HTTP |
| 服務網址 | `https://docs.univer.ai/mcp/docs` |
| 驗證 | 不需要 API Key |

啟用服務後，確認 Agent 可以看到以下工具：

| 工具 | 用途 |
| --- | --- |
| `search_docs` | 按主題或 API 名稱搜尋指南、範例和 API 參考，並可按章節和語言篩選 |
| `get_doc` | 以 Markdown 形式讀取頁面，包含程式碼、來源和版本資訊；長頁面可使用 `nextLine` 繼續讀取 |
| `list_features` | 查詢某個產品支援的瀏覽器功能 ID，以及可用性和許可證要求 |
| `generate_setup` | 生成依賴檔案和初始化檔案，包含外掛、預設、語言套件和樣式 |

## 描述開發需求

> 使用 Univer SDK MCP，為此 React 應用新增電子表格。先檢查已安裝的 SDK 版本和現有的初始化方式，閱讀整合指南，新增單元格編輯和快照儲存，然後建置並驗證應用。

> 使用 Univer SDK MCP，找到修改單元格數字格式的 Facade API。在修改現有的 Node.js 整合之前，先確認所需的功能外掛和匯入。

向 Agent 說明所用的產品、框架、執行環境和期望的行為。搜尋結果只是入口，Agent 在編寫程式碼前應先閱讀相關指南和 API 頁面。如需使用圖示，可連線 [Univer Icons MCP](/guides/icons/ai)。

服務讀取本站釋出的文件。每個結果都會標明其來自哪個文件版本或生成器版本，可與專案中已安裝的包進行比對。生成的接入程式碼面向瀏覽器編輯器，部分功能需要許可證，或需要在業務後端進行配置。框架生命週期、Headless Univer、協同和檔案轉換各有對應的指南。服務只返回檔案內容，由 Agent 在專案中應用並測試。
