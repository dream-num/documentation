Univer SDK MCP позволяет агенту искать официальную документацию, читать справочник API и генерировать инициализацию браузерного редактора по тому же каталогу, что и [генератор инициализации](/tools/initialization-generator).

## Подключение агента

Добавьте удалённый сервер в агенте с поддержкой MCP Streamable HTTP:

| Параметр | Значение |
| --- | --- |
| Имя | `univer-docs` |
| Транспорт | Streamable HTTP |
| URL сервера | `https://docs.univer.ai/mcp/docs` |
| Аутентификация | Ключ API не требуется |

После включения убедитесь, что агент видит следующие инструменты:

| Инструмент | Назначение |
| --- | --- |
| `search_docs` | Поиск руководств, примеров и API по теме или имени с фильтрацией по разделу и языку |
| `get_doc` | Чтение страницы Markdown с кодом, источником и версией; продолжение длинных страниц через `nextLine` |
| `list_features` | Получение идентификаторов браузерных функций, их доступности и требований к лицензии |
| `generate_setup` | Генерация зависимостей и инициализации с плагинами, пресетами, локалями и стилями |

## Опишите задачу

> Используй Univer SDK MCP, чтобы добавить таблицу в это приложение React. Сначала проверь установленную версию SDK и существующую инициализацию. Прочитай руководство, добавь редактирование ячеек и сохранение снимков, затем собери и проверь приложение.

> Используй Univer SDK MCP, чтобы найти Facade API для изменения числового формата ячейки. Проверь необходимые плагины и импорты перед изменением существующей интеграции Node.js.

Укажите продукт, фреймворк, среду выполнения и ожидаемое поведение. Фрагменты поиска помогают найти материалы; до реализации агент должен прочитать руководства и страницы API. Для иконок подключите [Univer Icons MCP](/guides/icons/ai).

Сервис читает документацию, опубликованную вместе с сайтом. Сравнивайте версию в ответах с установленными пакетами. Генерируемые файлы предназначены для браузерных редакторов; некоторым функциям нужна лицензия или настройка backend. Жизненный цикл, Headless Univer, совместное редактирование и преобразование файлов описаны в соответствующих руководствах. Сервер возвращает содержимое файлов, а агент применяет и проверяет его в вашем проекте.
