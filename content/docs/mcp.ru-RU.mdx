Univer SDK MCP — это удаленный MCP-сервер для агентов кодирования, он осуществляет поиск официальной документации, считывает ссылки API и генерирует код инициализации для редакторов браузеров, используя тот же каталог, что и [генератор инициализации](/tools/initialization-generator).

## Подключение агента

Добавьте сервер к агенту, который поддерживает потоковый HTTP MCP:

| Параметр | Значение |
| --- | --- |
| Имя | `univer-docs` |
| Транспорт | Streamable HTTP |
| URL сервера | `https://docs.univer.ai/mcp/docs` |
| Аутентификация | Ключ API не требуется |

После того, как сервер включен, убедитесь, что агент может видеть его инструменты:

| Инструмент | Назначение |
| --- | --- |
| `search_docs` | Руководство по поиску, примеры и ссылки на API по теме или имени API, отфильтрованные по разделам и языку |
| `get_doc` | Прочитайте страницу как Markdown, с кодом, источником и информацией о версии; используйте `nextLine` для продолжения длинной страницы |
| `list_features` | Посмотрите идентификаторы функций браузера, которые поддерживает продукт, а также требования к доступности и лицензии |
| `generate_setup` | Создавайте файлы зависимости и инициализации с помощью плагинов, предустановок, локализаций и стилей |

## Опишите задачу

> Используйте Univer SDK MCP для добавления электронной таблицы в это приложение React. Сначала проверьте установленную версию SDK и текущую настройку, прочитайте руководство по интеграции, добавьте редактирование ячеек и сохранение снимков, а затем создайте и проверьте приложение.

> Используйте Univer SDK MCP, чтобы найти Facade API, который меняет формат номера ячейки. Проверьте плагин функции и импортируйте его, прежде чем менять мою существующую интеграцию Node.js.

Предоставьте агенту продукт, фреймворк, время выполнения и желаемое поведение. Результаты поиска - это только точки входа, поэтому агент должен прочитать соответствующее руководство и страницу API перед написанием любого кода. Для работы с иконками подключите [Иконки Univer MCP](/guides/icons/ai).

Служба считывает документацию, опубликованную на этом сайте. Каждый ответ идентифицирует документацию или версию генератора, из которой он вышел, что можно сравнить с пакетами, установленными в проекте. Сгенерированные настройки нацелены на редакторы браузера, а некоторые функции требуют лицензии или конфигурации на бэкэнде. Жизненный цикл Framework, Headless Univer, совместная работа и преобразование файлов имеют специальное руководство. Сервер возвращает содержимое файлов; агент применяет и тестирует их в проекте.
