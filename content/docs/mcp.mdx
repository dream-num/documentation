Univer SDK MCP is a remote MCP server for coding agents. It searches the official documentation, reads API references, and generates initialization code for browser editors, using the same catalog as the [initialization generator](/tools/initialization-generator).

## Connect your agent

Add the server to an agent that supports Streamable HTTP MCP:

| Setting | Value |
| --- | --- |
| Name | `univer-docs` |
| Transport | Streamable HTTP |
| Server URL | `https://docs.univer.ai/mcp/docs` |
| Authentication | No API key required |

After the server is enabled, confirm that the agent can see its tools:

| Tool | Purpose |
| --- | --- |
| `search_docs` | Search guides, examples, and API references by topic or API name, filtered by section and language |
| `get_doc` | Read a page as Markdown, with code, source, and version information; use `nextLine` to continue a long page |
| `list_features` | Look up the browser feature IDs that a product supports, together with availability and license requirements |
| `generate_setup` | Generate dependency and initialization files with plugins, presets, locales, and styles |

## Describe your task

> Use Univer SDK MCP to add a spreadsheet to this React application. Check the installed SDK version and the current setup first, read the integration guide, add cell editing and snapshot saving, then build and verify the application.

> Use Univer SDK MCP to find the Facade API that changes the number format of a cell. Check the feature plugin and imports it requires before changing my existing Node.js integration.

Provide the agent with the product, the framework, the runtime, and the desired behavior. Search results are entry points only, so the agent should read the relevant guide and API page before writing any code. To work with icons, connect [Univer Icons MCP](/guides/icons/ai).

The service reads the documentation published on this site. Each response identifies the documentation or generator version it came from, which can be compared with the packages installed in the project. Generated setups target browser editors, and some features require a license or configuration on the backend. Framework lifecycle, Headless Univer, collaboration, and file conversion each have a dedicated guide. The server returns file contents; the agent applies and tests them in the project.
