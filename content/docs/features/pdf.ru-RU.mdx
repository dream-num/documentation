[Руководство по интеграции](/guides/pdfs) · [Все функции](/docs/features)

<Callout title="Область сравнения">
  Сравнение платных продуктов для настольных компьютеров Acrobat Pro и Foxit PDF Editor; Расширенные функции Foxit относятся к версии Pro или соответствующей лицензионной версии. Univer включает в себя полную версию Office SDK и дополнительные модули, при этом покрытие SDK API и UI указано для каждой функции. Редактирование текста/изображений зависит от структуры PDF. Интеграция внешнего агента с OCR, инструментами сканирования или сжатия отмечена отдельно; эти инструменты должны поставляться независимо и не являются встроенными возможностями Univer. Генеративный AI исключен из этого сравнения; традиционный OCR включен в объем сравнения. Частичная поддержка описывает ее точный объем.
</Callout>

«Открытый исходный код» означает полную поддержку в версии с открытым исходным кодом. Немаркированные элементы могут включать базовые подмножества, дополнительные модули или коммерческое лицензирование; обратитесь к документации соответствующего модуля.
