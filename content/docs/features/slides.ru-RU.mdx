  Ссылочные продукты - Microsoft 365 PowerPoint для настольных компьютеров Windows и Google Slides в Интернете. Колонка Univer предполагает полный Office SDK с дополнительными модулями. Функции редактора и совместимость с PPTX в оба конца сравниваются отдельно, и каждая запись записывает требования API, шаблона, рендеринга браузера или обслуживания, которые применяются. Сравнение охватывает только собственные не-AI возможности каждого продукта; автономные внешние продукты и дополнения исключены.
</Callout>
