<Callout title="비교 범위">
  유료 데스크톱 제품 Acrobat Pro 및 Foxit PDF Editor를 비교합니다. 고급 Foxit 기능은 Pro 또는 해당 라이선스 버전을 의미합니다. Univer에는 기능별로 지정된 SDK API 및 UI 적용 범위와 함께 전체 Office SDK 및 옵션 모듈이 포함되어 있습니다. 텍스트/이미지 편집은 PDF 구조에 따라 다릅니다. OCR, 스캐닝 또는 압축 도구와의 외부 에이전트 통합은 별도로 표시됩니다. 이러한 도구는 독립적으로 제공되어야 하며 Univer 기능이 내장되어 있지 않습니다. 생성형 AI는 이 비교에서 제외됩니다. 기존 OCR는 비교 범위에 포함됩니다. 부분 지원은 정확한 범위를 설명합니다.
</Callout>

"오픈 소스"는 오픈 소스 버전에서 완전한 지원을 나타냅니다. 표시되지 않은 항목에는 기본 하위 세트, 선택적 모듈 또는 상업용 라이센스가 포함될 수 있습니다. 해당 모듈 문서를 참조하세요.
