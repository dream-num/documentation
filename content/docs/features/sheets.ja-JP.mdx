  Microsoft 365 Excel for Windows デスクトップと Web ベースの Google Sheets を比較します。 Univer には、完全な Office SDK とオプションのモジュールが含まれています。各製品自体の AI 以外の機能のみが含まれています。外部/ビジネス データ ソース、個別の外部製品、アドオンは除外されます。 JavaScript、VBA、および Apps Script は自動化を提供しますが、Univer および Google Sheets は VBA コードとプロジェクトをインポート/エクスポートしません。プラン、プラットフォーム、統合の要件は機能ごとに記載されています。
