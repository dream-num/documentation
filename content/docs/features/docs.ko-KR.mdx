[통합 가이드](/guides/docs) · [모든 기능](/docs/features)

<Callout title="비교 범위">
  Windows 데스크톱용 Microsoft 365 Word를 웹 기반 Google Docs와 비교합니다. Univer에는 전체 Office SDK 및 선택적 모듈이 포함되어 있습니다. 변경 내용 추적, 문서 비교, 현장 계산, 내역 검토는 별도의 기능입니다. 편집기 기능과 형식 호환성은 별도로 나열됩니다. 제품 자체의 AI 기능이 아닌 기능만 포함됩니다. 별도의 외부 제품 및 추가 기능은 제외됩니다. 계획, 기본 API 및 통합 요구 사항은 기능별로 명시되어 있습니다.
</Callout>

"오픈 소스"는 오픈 소스 버전에서 완전한 지원을 나타냅니다. 표시되지 않은 항목에는 기본 하위 세트, 선택적 모듈 또는 상업용 라이센스가 포함될 수 있습니다. 해당 모듈 문서를 참조하세요.
