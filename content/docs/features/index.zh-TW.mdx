## 跨產品能力 [#shared-capabilities]

每項能力都有獨立說明頁，列出能力範圍、存取方式與產品邊界。側欄的「跨產品能力」可展開查看全部入口。

| 能力 | 說明 |
| --- | --- |
| [圖表](/docs/features/charts) | 8 個分類、43 種圖表，與 Microsoft Office、Google Workspace 並列比較並保留範例。 |
| [文件導入與匯出](/docs/features/shared/file-conversion) | 將 Office 文件轉換為 Univer 內容，並將編輯結果匯出為交付文件。 |
| [無頭與伺服器端計算](/docs/features/shared/server-calculation) | 在 Node.js 中讀寫內容，結合 Rust 預計算與陣列展開，為應用程式和 Agent 提供結構化與視覺結果。 |
| [即時協同](/docs/features/shared/collaboration) | 同步分享文件內容與線上使用者狀態。 |
| [歷史記錄](/docs/features/shared/history) | 記錄已確認的修改，並查看文件歷史版本。 |
| [權限與授權](/docs/features/shared/permissions) | 將業務身分與權限策略接取文件讀寫、協同與審查操作。 |
| [評論與審閱討論](/docs/features/shared/comments) | 將討論定位到內容，支援回覆與解決審閱線程。 |
| [Worktree](/docs/features/shared/worktree) | 在隔離草稿中編輯，審閱修改後合入主文件。 |
| [內容比較](/docs/features/shared/compare) | 比較文件快照，查看內容與樣式的結構化差異。 |
| [雙向綁定](/docs/features/shared/binding) | 將自訂 Web 控制項與表格資料​​及計算規則連接起來。 |
| [跨文件嵌入（Embed block）](/docs/features/shared/embed) | 將可編輯的 Univer 內容嵌入另一種 Office 產品。 |
| [Agent 與自動化](/docs/features/shared/agents) | 將 Office 內容操作封裝為 Agent 工具與可組合指令。 |
| [截圖與視覺檢查](/docs/features/shared/visual-inspection) | 渲染內容供審閱，並結合結構化檢查驗證結果。 |
| [插件與 Facade 擴展](/docs/features/shared/customization) | 按需組合產品、擴充行為，並將 Office API 連結到業務介面。 |
| [主題與國際化](/docs/features/shared/themes-and-locales) | 配置編輯器配色、暗色模式與多語言介面資源。 |

瀏覽功能後，可返回 [Office SDK 總覽](/docs/overview)選擇接入方式，或直接開啟產品接入指南。
