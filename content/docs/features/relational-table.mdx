<Callout title="Comparison scope">
  The comparison treats Airtable and Feishu Base as paid cloud products and Univer as the complete Office SDK plus its optional modules. Only the non-AI capabilities of each product are included, and separate external products and add-ons are excluded. An external agent can call APIs to prepare, sync, and import data; where that applies, the condition is noted separately for the feature and kept distinct from built-in automation orchestration. Entry points, scheduling, and permissions that an application builds itself are also described separately from native features. Plan, mobile, and integration requirements are noted under each feature.
</Callout>
