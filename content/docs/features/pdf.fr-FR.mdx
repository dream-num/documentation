<Callout title="Portée de comparaison">
  Compare les produits de bureau payants Acrobat Pro et Foxit PDF Editor ; Les fonctionnalités avancées de Foxit font référence à Pro ou à l'édition sous licence correspondante. Univer comprend l'Office SDK complet et des modules optionnels, avec une couverture SDK API et UI spécifiée par fonctionnalité. L'édition de texte/image dépend de la structure PDF. L'intégration d'agents externes avec OCR, des outils d'analyse ou de compression est notée séparément ; ces outils doivent être fournis indépendamment et ne sont pas des capacités Univer intégrées. Le générateur AI est exclu de cette comparaison ; Le traditionnel OCR est inclus dans le champ de comparaison. Le support partiel décrit sa portée exacte.
</Callout>
