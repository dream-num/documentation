Импорт и экспорт файлов связывает внешние форматы файлов с моделями контента, которые использует Univer. Импорт анализирует файл в соответствующий снимок продукта. Экспорт сериализует снимок продукта в выбранный формат вывода.

## От файла к снимку

Офисные файлы делятся на две группы. `.xlsx`, `.docx` и `.pptx` — это пакеты OOXML, содержащие XML и ресурсы, такие как изображения. `.xls` , `.doc` а также `.ppt` используют более старые двоичные структуры. CSV и TSV — простой текст. Отправляйте исходный файл в поддерживаемом формате, а модуль преобразования обрабатывает декодирование, парсинг пакетов и отображение ресурсов.

Снимок - это состояние содержимого продукта в форме, которую можно сохранить и восстановить. [Шесть схем моментального снимка продукта перечислены ниже](#структуры-данных-snapshot).

### Импорт: файл → Snapshot

Импортирует контент, стили и ресурсы в соответствующую модель продукта, будь то лист, док, слайд, реляционная таблица или другой продукт.

### Экспорт: Snapshot → файл

Экспорт считывает текущий снимок продукта и записывает структуру и ресурсы целевого формата.Снимок представляет собой модель контента во время выполнения, обычно передаваемую или хранящуюся как JSON.

Для Sheet это означает вычисление формул, поворотов и форматов чисел по выбранной политике, затем обновление снимка. См. [вычисление на стороне сервера](/overview/features/shared/server-calculation).

### Структуры данных Snapshot

Каждый продукт определяет свой собственный контракт на моментальный снимок для постоянных ссылок на контент и ресурсы, обычно как JSON.

<div className="[&_table]:min-w-180 [&_code]:whitespace-nowrap">

| Продукт | Интерфейс Snapshot | Основное содержимое |
| --- | --- | --- |
| Электронные таблицы (Sheet) | [`IWorkbookData`](/guides/sheets/model/workbook-data#iworkbookdata) | Листы, ячейки, общие стили и ресурсы плагинов. |
| Документы (Doc) | [`IDocumentData`](/guides/docs/model/document-data#idocumentdata) | Текст, абзацы, стили, колонтитулы и ресурсы. |
| Презентации (Slide) | [`ISlideData`](/guides/slides/model/slide-data#islidedata) | Слайды, элементы, образцы, темы и ресурсы. |
| Реляционная таблица (Relational Table) | [`IBaseSnapshot`](/guides/bases/model/base-snapshot#ibasesnapshot) | Таблицы, поля, записи, представления и их порядок. |
| Холст (Canvases) | [`IBoardData`](/guides/boards/model/board-data#iboarddata) | Страницы, элементы, темы и ресурсы. |
| PDF | [`IPdfUnitData`](/guides/pdfs/model/pdf-data#ipdfunitdata) | Исходный документ, сохраняемое состояние правок и привязки ресурсов. |

</div>

Позвоните `save()` на продукт Facade, чтобы получить текущий снимок, затем используйте соответствующий API для создания, чтобы восстановить его. Контент, который уже загружен, отредактирован через API Facade. Для PDF `pdf.save()` сохраняет как исходный базовый уровень, так и `editState`.

## Форматы по продуктам

Форматы Office и таблицы ниже используют прямые маршруты Rust Exchange. PDF использует собственный модуль преобразования и поэтому указан отдельно в одной таблице.

<div className="[&_table]:min-w-180 [&_code]:whitespace-nowrap">

| Продукт | Импорт / компиляция | Экспорт | Особенности |
| --- | --- | --- | --- |
| [Электронные таблицы (Sheet)](/guides/sheets/features/import-export) | `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` | CSV/TSV содержит один рабочий лист. |
| [Документы (Doc)](/guides/docs/features/import-export) | `.doc`, `.docx` | `.docx` | Наследие DOC импортируется в модель Docs. Выход - DOCX. |
| [Презентации (Slide)](/guides/slides/features/import-export) | `.ppt`, `.pptx` | `.pptx` | Наследие ПТП импортируется в модель Слайдов. Выход - ПТПХ. |
| [Реляционная таблица (Relational Table)](/guides/bases/features/import-export) | `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` | CSV/TSV содержит одну таблицу. XLSX поддерживает отображение таблиц и полей. |
| [Холст (Canvases)](/guides/boards/features/import-export) | Mermaid (`.mmd` / исходный текст) | `.pptx` | Mermaid производит проект импорта, который применяется через Фасад Полотен до того, как снимок будет сохранен. PPTX экспортирует активную страницу. |
| [PDF](/guides/pdfs/features/import-export) | `.pdf` | `.pdf` | Требуется услуга конвертации PDF, которая отделена от Rust Exchange CLI. |

</div>

- `.xls`, `.doc` и `.ppt` являются форматами импорта, их выходными форматами являются `.xlsx` , `.docx` а также `.pptx` соответственно.
- Экспорт CSV/TSV содержит одну рабочую таблицу или одну таблицу для сравнения. Сохранить снимок продукта, когда требуется полная модель контента и его ресурсы.
- Различные точки входа SDK принимают различные расширения. Для таких форматов, как `.xlsm`, `.pptm`, `.ppsx`, `.ppsm` и `.potx`, проверьте развернутый бэкэнд и API браузера. Они не являются дополнительными прямыми именами форматов Rust CLI.

## Вычисления при преобразовании

Для поддерживаемых рабочих процессов преобразования электронных таблиц преобразование файлов может быть объединено с вычислением на стороне сервера:

- Формула расчета заполняет недостающие кэшированные результаты по импорту или пересчитывает перед экспортом в соответствии с выбранной политикой.
- Расчет Pivot происходит путем группировки и агрегирования исходных данных и конфигурации Pivot, а затем материализует результаты для снимка или экспортируемой книги.
- Расчет формата номера превращает значения в дату, процент, валюту и другой форматированный текст отображения. Экспорт CSV / TSV может записывать значения отображения или необработанные значения.

Связанный процесс описан в разделе [Headless и серверные вычисления](/overview/features/shared/server-calculation).

## Интеграция

Преобразование файлов принадлежит Server SDK. Приложение обеспечивает загрузку, обработку задач, хранение и загрузку конечных точек. Преобразование снимков может выполняться без сотрудничества. Экспорт общего документа считывает подтвержденную правку после синхронизации отложенных правок.

Начните с [Интеграции преобразования](/server/import-export) и [Преобразования в Node.js](/server/import-export/node).

Поддержка формата и сохранение отдельных функций — это отдельные вопросы.Использовать список функций каждого продукта и реальные бизнес-файлы для проверки формул, изображений, стилей и макета посредством импорта, редактирования и экспорта.
