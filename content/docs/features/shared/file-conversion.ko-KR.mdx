파일 가져 오기 및 내보내기 링크 외부 파일 형식은 Univer가 사용하는 콘텐츠 모델에. 해당 제품 스냅 샷으로 파일을 가져 오기. 선택된 출력 형식으로 제품을 스냅 샷을 직렬화합니다.

## 파일에서 스냅샷으로

Office 파일은 두 그룹으로 나뉩니다. `.xlsx`, `.docx` 및 `.pptx`는 이미지와 같은 XML 및 리소스를 보유하는 OOXML 패키지입니다. `.xls`, `.doc` 및 `.ppt` 사용 오래된 바이너리 구조. CSV 및 TSV는 일반 텍스트입니다. 지원 형식의 원본 파일을 제출하고 변환 모듈은 디코딩, 패키지 패싱 및 리소스 매핑을 처리합니다.

스냅 샷은 저장 및 복원 할 수있는 형태로 제품의 내용 상태입니다. [6개의 제품 스냅샷 스키마는 아래에 나열됩니다.](#snapshot-데이터-구조).

### 가져오기: 파일 → Snapshot

저장 파스 함량, 스타일, 및 리소스 일치 제품 모델, 시트, Doc, 슬라이드, 관계 테이블, 또는 다른 제품.

### 내보내기: Snapshot → 파일

수출은 현재 제품 스냅 샷을 읽고 대상 형식의 구조 및 리소스를 작성합니다. 스냅 샷은 runtime, 일반적으로 JSON으로 전송되거나 저장되는 내용 모델입니다.

<Mermaid chart={"flowchart LR\n    A[\"1. 현재 Snapshot<br/>편집한 콘텐츠\"]\n    B[\"2. 필요시 계산<br/>Snapshot 갱신\"]\n    C[\"3. Server SDK<br/>대상 형식으로 변환\"]\n    D[\"4. 출력 파일<br/>XLSX / DOCX / PPTX 등\"]\n    A --> B --> C --> D\n    classDef calculation stroke-dasharray:5 4\n    class B calculation"} />

시트의 경우,이는 선택된 정책에 따라 계산식, 피봇 및 번호 형식을 의미하고 스냅 샷을 업데이트합니다. [서버 측 계산](/overview/features/shared/server-calculation)를 참조하십시오.

### Snapshot 데이터 구조

각 제품은 JSON과 같은 persisting 콘텐츠 및 리소스 참조에 대한 자체 스냅 샷 계약을 정의합니다. 인터페이스 링크는 필드 정의, 유형 및 예로 이어집니다.

<div className="[&_table]:min-w-180 [&_code]:whitespace-nowrap">

| 제품 | Snapshot 인터페이스 | 주요 내용 |
| --- | --- | --- |
| 스프레드시트 (Sheet) | [`IWorkbookData`](/guides/sheets/model/workbook-data#iworkbookdata) | 워크시트, 셀, 공유 스타일, 플러그인 리소스. |
| 문서 (Doc) | [`IDocumentData`](/guides/docs/model/document-data#idocumentdata) | 본문, 문단, 스타일, 머리글, 바닥글, 리소스. |
| 슬라이드 (Slide) | [`ISlideData`](/guides/slides/model/slide-data#islidedata) | 슬라이드, 요소, 마스터, 테마, 리소스. |
| 관계형 테이블 (Relational Table) | [`IBaseSnapshot`](/guides/bases/model/base-snapshot#ibasesnapshot) | 테이블, 필드, 레코드, 뷰와 각 항목의 순서. |
| 캔버스 (Canvases) | [`IBoardData`](/guides/boards/model/board-data#iboarddata) | 페이지, 요소, 테마, 리소스. |
| PDF | [`IPdfUnitData`](/guides/pdfs/model/pdf-data#ipdfunitdata) | 원본 문서, 저장된 편집 상태, 리소스 바인딩. |

</div>

현재 스냅 샷을 얻기 위해 제품 Facade에 `save()`를 호출하면 해당 생성 API를 복원합니다. 이미로드 된 콘텐츠는 Facade API를 통해 편집됩니다. PDF의 경우 `pdf.save()`는 소스 기본 및 `editState` 모두 보존합니다.

## 제품별 지원 형식

아래 사무실 및 테이블 형식은 직접 Rust Exchange 루트를 사용합니다. PDF는 자체 변환 모듈을 사용하고 동일한 테이블에 별도로 나열됩니다.

<div className="[&_table]:min-w-180 [&_code]:whitespace-nowrap">

| 제품 | 가져오기 / 컴파일 | 내보내기 | 범위 |
| --- | --- | --- | --- |
| [스프레드시트 (Sheet)](/guides/sheets/features/import-export) | `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` | CSV/TSV는 하나의 워크시트를 보유하고 있습니다. |
| [문서 (Doc)](/guides/docs/features/import-export) | `.doc`, `.docx` | `.docx` | 레거시 DOC는 Docs 모델로 가져옵니다. 출력은 DOCX입니다. |
| [슬라이드 (Slide)](/guides/slides/features/import-export) | `.ppt`, `.pptx` | `.pptx` | Legacy PPT는 슬라이드 모델로 가져갑니다. 출력은 PPTX입니다. |
| [관계형 테이블 (Relational Table)](/guides/bases/features/import-export) | `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` | CSV/TSV는 하나의 테이블을 보유하고 있습니다. XLSX는 테이블과 필드 매핑을 지원합니다. |
| [캔버스 (Canvases)](/guides/boards/features/import-export) | Mermaid (`.mmd` / 소스 텍스트) | `.pptx` | Mermaid는 스냅샷이 저장되기 전에 캔버스 Facade를 통해 적용되는 수입 초안을 생산합니다. PPTX는 활성 페이지를 수출합니다. |
| [PDF](/guides/pdfs/features/import-export) | `.pdf` | `.pdf` | Rust Exchange CLI에서 분리되는 PDF 변환 서비스가 필요합니다. |

</div>

- `.xls`, `.doc` 및 `.ppt`는 수입품 체재입니다. 그들의 산출 체재는 `.xlsx`의 `.docx`이고, 각각 `.pptx`입니다.
- CSV/TSV 수출에는 1개의 워크시트 또는 1개의 관계 테이블이 있습니다. 제품 스냅샷을 완전한 내용 모형 및 그것의 자원이 요구될 때 저장하십시오.
- 다른 SDK 항목 포인트는 다른 확장을 허용합니다. `.xlsm`, `.pptm` 및 `.ppsx`와 같은 형식의 경우 `.ppsm` 와 `.potx`는 배포 된 백엔드 및 브라우저 API를 확인합니다. 그들은 추가 직접 Rust CLI 형식의 이름이 아닙니다.

## 변환 과정의 계산

지원된 스프레드시트 변환 워크플로우를 위해, 파일 변환은 서버 측 계산과 결합될 수 있습니다:

- 공식 계산은 수입에 대한 누락 된 결과를 채우거나 선택한 정책에 따라 수출하기 전에 재 계산합니다.
- Pivot 계산 derives 그룹화 및 소스 데이터와 피벗 구성에서 집계, 그 다음 스냅 샷 또는 수출 작업 책에 대한 결과를 지정합니다.
- 번호 형식 계산은 날짜, 비율, 통화 및 기타 포맷 된 디스플레이 텍스트로 값을 변환합니다. CSV / TSV 수출은 디스플레이 값 또는 원시값을 작성할 수 있습니다.

관련 콘텐츠 처리 과정은[헤드리스 및 서버 계산](/overview/features/shared/server-calculation)을 참고하세요.

## 연동 방법

파일 변환은 Server SDK에 속합니다. 이 응용 프로그램은 업로드, 작업 처리, 저장 및 다운로드 엔드포인트를 제공합니다. 스냅 샷 변환은 협업없이 실행할 수 있습니다. 공유 된 문서를 내보내기 시작된 편집 후 확인 된 개정을 동기화했습니다.

[파일 변환 연동](/server/import-export)과 [Node.js 파일 변환](/server/import-export/node)에서 시작하세요.

개별 기능의 형식 지원 및 보존은 별도의 질문입니다. 각 제품의 기능 목록 및 실제 비즈니스 파일을 사용하여 재료, 이미지, 스타일 및 레이아웃을 가져 오기, 편집 및 내보내기를 통해 검증합니다.
