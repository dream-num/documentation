Univer Server SDK는 일반 HTML, CSS 및 JavaScript 페이지를 시트에 연결합니다. 스프레드 시트는 데이터 및 공식을 유지하면서 페이지는 형태, 미터, 차트 및 비즈니스 상호 작용을 제공합니다. 다른 측면 업데이트에 입력으로 변경하십시오. SDK는 애플리케이션은 스프레드 시트 모델을 인용 계산기, 대쉬보드 또는 대화형 비즈니스 응용 프로그램에 전환합니다.

## 예제: 앱과 스프레드시트 연결

프로젝트 서밋 예제는 성장, 제공 가격 및 왼쪽에 통제로 현금 지불 혼합을 노출, 오른쪽에 전체 금융 작업 책. 가정 업데이트 관련 공식, 미터 카드 및 차트에 변경. 사용자는 또한 스프레드 시트를 열 수 있습니다 입력 및 계산 뒤에.

![Project Summit: 업무 컨트롤·지표·차트와 연결된 Univer Sheets 재무 모델](/assets/features/binding/project-summit-app-sheets.png)

스크린 샷은 로컬 브라우저에서 실행되는 모델을 보여줍니다. 공유 편집 및 지속은 아래의 협업 통합을 사용합니다. 전체 크기에서 이미지를 볼 수 있습니다.

## 하나의 Sheet, 여러 인터페이스

HTML보기는 페이지 실행 시간을 통해 호스트와 통신합니다. 바인딩 엔진은 자체 headless Univer 인스턴스를 통해 실제 시트 콘텐츠를 읽고 작성합니다. Univer SDK는 공식 및 협업을 처리하고 바인딩 레이어는 페이지에 변경된 값을 제공합니다.

Bound 페이지는 사용자가 스프레드 시트를 직접 편집하거나 다른 사용자가 협업적인 변경을 할 때도 새로 고침합니다. 단일 HTML보기는 공인되는 여러 단위에 액세스 할 수 있습니다. 호스트로드는 단위 당 하나의 엔진을로드하고 각 엔진은 자체 headless Univer 인스턴스를 유지합니다.

## HTML로 바인딩 선언

요소에 대한 데이터 참조는 텍스트 또는 제어 동기화를 자동으로 유지합니다. 셀 참조는 양식 `unitId:sheetId:A1`를 사용합니다. 각 ID는 `encodeURIComponent`와 별도로 인코딩되며 워크 시트 ID는 안정적으로 유지해야합니다.

| 속성 | 용도 |
| --- | --- |
| `data-univer-cell-text` | 요소의 텍스트로 세포 값을 표시합니다. |
| `data-univer-cell-model` | 셀과 폼 컨트롤을 두 방향으로 동기화합니다. |
| `data-univer-cell-subscribe` | 사용자 정의 JavaScript 렌더링에 대한 세포 가입을 선언합니다. |
| `data-univer-range-subscribe` | 도표, 명부 및 모체의 다른 소비자를 위한 직사각형 범위 구독을 선언합니다. |

예를 들어, 단위 가격은 `B2`에 있으며, 수량은 `B3`이며 `B4`는 `=B2*B3`를 보유하고 있습니다. 다음 템플릿 파편은 두 개의 입력과 그 세포에 총을 연결합니다.

```html
<label>
  단가
  <input type="number" min="0" step="0.01"
    data-univer-cell-model="book:sheet:B2" />
</label>
<label>
  수량
  <input type="number" min="0" step="1"
    data-univer-cell-model="book:sheet:B3" />
</label>
<p>합계: <span data-univer-cell-text="book:sheet:B4"></span></p>
```

`book` 및 `sheet`를 실제, 공인 ID로 대체하고 렌더링기를 통해 템플릿을로드합니다. 공식은 시트에 정의되며 페이지는 결과를 읽습니다. 텍스트 입력, 번호 입력, 범위 입력, 체크 박스, textareas 및 단일 선택 컨트롤은 값 유형에 따라 바인딩됩니다.

## JavaScript로 차트와 인터랙션 확장

페이지 실행 시간은 어떤 템플릿 스크립트 실행 전에 `window.univerBinding`를 초기화합니다. `data-univer-range-subscribe`와 차트 범위를 결정하고 `subscribeRangeById(elementId, callback)`을 호출하여 매트릭스를 수신하고 차트를 업데이트합니다. 단일 값 사용 `subscribeCellById()`의 구성 요소.

`getCellState()` / `getRangeState()`를 사용하여 한 번의 읽기, `setCellValue()`는 사기를 작성하고 `insertRowsWithValues()`가 행을 삽입하고 하나의 작업에 채우도록합니다. 구독은 현재 상태를 먼저 전달하고 모든 실제 값 변경을 제공합니다. 로컬 편집, 협업 편집 및 적용 된 공식 결과는 모두 구독을 새로 고침 할 수 있습니다.

참고는 조정 좌표를 읽고 그러므로 줄 또는 란이 삽입되거나 삭제될 때 본래 기록을 따르지 마십시오. 사기그릇 쓰기는 세포에서 어떤 공식 또는 부유한 원본든지 이미 선물합니다, 그래서 사업 입력을 붙들기 위하여 단지 세포를 묶습니다.

## 호스트와 Agent 연결

이 응용 프로그램은 컨테이너, HTML 템플릿 및 `loadEngine`를 제공합니다. 로더는 단위에 액세스 권한을 부여하고 협력을 구성하고로드 엔진을 반환합니다. 렌더링자는 격리 된 페이지를 소유하고, 그 페이지와 호스트 사이 메시징, 엔진의 수명주기는 전달합니다. 이 항목 포인트는 그 세 가지 입력을 허용합니다.

```ts
import {
  renderHtmlView,
  type RenderHtmlViewOptions,
} from '@univerjs-labs/html-view-renderer/render';

export function createPreview(
  container: HTMLElement,
  html: string,
  loadEngine: RenderHtmlViewOptions['loadEngine'],
) {
  return renderHtmlView({ container, html, loadEngine });
}
```

템플릿 생성, 소스 편집, 파일 저장 및 비즈니스 네비게이션은 응용 프로그램의 책임에 남아있다. 에이전트는 시트 데이터와 계산 규칙을 재사용하는 바인딩 선언과 HTML을 생성 할 수 있습니다. `view.inspect.open()`를 호출하여 단위, 시트, 참조 및 페이지 요소 사이의 대응을 검사합니다.

호스트는 협업 자격 증명을 보유하고 있으며 서버는 액세스 권한을 적용합니다. 시트 UI와 별도의 JavaScript 환경에서 헤드리스 엔진을 유지하며 별도의 페이지나 iframes와 같은 헤드리스 엔진이 유지됩니다. 현재 바인딩 패키지 커버 시트.

## 로컬 갱신과 저장 확인 구분

| 작업 | 의미 |
| --- | --- |
| 페이지 쓰기 완료 | 로컬 작업이 실행되었지만 서버는 아직 인정되지 않았습니다. |
| `await view.flush()` | 제어에서 초안값을 제출하고, 이전 글과 협업의 인정을 기다립니다. 그러면 계속 편집 할 수 있습니다. |
| `await view.prepareToLeave()` | Pauses 편집 및 저장합니다. 저장이 성공하거나 탐색이 취소되면 `view.resume()`로 전화하십시오. |
| `view.dispose()` | 연결, 엔진 및 구독을 릴리즈합니다. 그것은 어떤 데이터를 저장하지 않습니다. |

구독은 스크린에 값을 한 번 공식 결과를 적용하는 것입니다. 저장이 실패하면 페이지가 열리고 저장을 다시 유지하십시오. 완료 된 페이지는 자체가 저장 된 것을 의미하지 않습니다.
