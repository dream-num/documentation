Importar archivos y exportar enlaces de archivos externos a los modelos de contenido que Univer utiliza. Importar analiza un archivo en la instantánea correspondiente del producto. Exportar serializa una instantánea de producto en el formato de salida elegido.

## Del archivo al snapshot

Los archivos de la oficina caen en dos grupos. `.xlsx`, `.docx`, y `.pptx` son paquetes OOXML que contienen XML y recursos como imágenes. `.xls`, `.doc`, y `.ppt` utilizan estructuras binarias antiguas. CSV y TSV son texto simple. Presentar el archivo original en un formato compatible, y el módulo de conversión maneja decodificación, persiguiendo paquetes y mapeo de recursos.

Una instantánea es el estado de contenido de un producto en un formulario que se puede guardar y restaurar. [Los seis esquemas de instantáneas de producto se enumeran a continuación](#estructuras-de-datos-snapshot).

### Importación: archivo → snapshot

Importar el contenido, los estilos y los recursos en el modelo de producto que coincida, ya sea Hoja, Doc, Diapositiva, Tabla Relacional, u otro producto.

### Exportación: snapshot → archivo

Exportar lee la instantánea del producto actual y escribe la estructura y los recursos del formato objetivo. Una instantánea es el modelo de contenido en tiempo de ejecución, normalmente transferido o almacenado como JSON.

<Mermaid chart={"flowchart LR\n    A[\"1. Snapshot actual<br/>Contenido editado\"]\n    B[\"2. Cálculo opcional<br/>Actualizar Snapshot\"]\n    C[\"3. Para Sheet, esto significa calcular fórmulas, pivotes y formatos de números según la política seleccionada, luego actualizar la instantánea. Ver [cálculo lado del servidor](/overview/features/shared/server-calculation).

### Estructuras de datos Snapshot

Cada producto define su propio contrato de instantáneas para las referencias de contenido y recursos persistentes, generalmente como JSON. Los enlaces de interfaz conducen a definiciones, tipos y ejemplos de campo.

<div className="[&_table]:min-w-180 [&_code]:whitespace-nowrap">

| Producto | Interfaz Snapshot | Contenido principal |
| --- | --- | --- |
| Hojas de cálculo (Sheet) | [`IWorkbookData`](/guides/sheets/model/workbook-data#iworkbookdata) | Hojas, celdas, estilos compartidos y recursos de complementos. |
| Documentos (Doc) | [`IDocumentData`](/guides/docs/model/document-data#idocumentdata) | Cuerpo, párrafos, estilos, encabezados, pies de página y recursos. |
| Presentaciones (Slide) | [`ISlideData`](/guides/slides/model/slide-data#islidedata) | Diapositivas, elementos, patrones, temas y recursos. |
| Tabla relacional (Relational Table) | [`IBaseSnapshot`](/guides/bases/model/base-snapshot#ibasesnapshot) | Tablas, campos, registros, vistas y su orden. |
| Lienzo (Canvases) | [`IBoardData`](/guides/boards/model/board-data#iboarddata) | Páginas, elementos, temas y recursos. |
| PDF | [`IPdfUnitData`](/guides/pdfs/model/pdf-data#ipdfunitdata) | Documento original, estado de edición persistente y vínculos de recursos. |

</div>

Llame a `save()` en el producto Facade para obtener la instantánea actual, a continuación, utilice la API de creación correspondiente para restaurarlo. Contenido que ya está cargado se edita a través de las API de Facade. Para PDF, `pdf.save()` preserva tanto la base de referencia fuente como `editState`.

## Formatos por producto

Los formatos de oficina y tabla que aparecen a continuación utilizan las rutas directas de Rust Exchange. PDF utiliza su propio módulo de conversión y, por lo tanto, se enumeran por separado en la misma tabla.

<div className="[&_table]:min-w-180 [&_code]:whitespace-nowrap">

| Producto | Importar / compilar | Exportar | Alcance |
| --- | --- | --- | --- |
| [Hojas de cálculo (Sheet)](/guides/sheets/features/import-export) | `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` | CSV/TSV tiene una hoja de trabajo. |
| [Documentos (Doc)](/guides/docs/features/import-export) | `.doc`, `.docx` | `.docx` | Legacy DOC se importa en el modelo Docs. |
| [Presentaciones (Slide)](/guides/slides/features/import-export) | `.ppt`, `.pptx` | `.pptx` | Legacy PPT importa en el modelo Slides. Output es PPTX. |
| [Tabla relacional (Relational Table)](/guides/bases/features/import-export) | `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` | CSV/TSV tiene una tabla. XLSX soporta la cartografía de mesa y campo. |
| [Lienzo (Canvases)](/guides/boards/features/import-export) | Mermaid (`.mmd` / texto fuente) | `.pptx` | Mermaid produce un borrador de importación, que se aplica a través de la Fachada de los Canvases antes de que se guarde una instantánea. PPTX exporta la página activa. |
| [PDF](/guides/pdfs/features/import-export) | `.pdf` | `.pdf` | Requiere el servicio de conversión de PDF, que está separado del Rust Exchange CLI. |

</div>

- `.xls`, `.doc`, y `.ppt` son formatos de importación. Sus formatos de salida son `.xlsx`, `.docx`, y `.pptx` respectivamente.
- Una exportación CSV/TSV contiene una hoja de trabajo o una tabla de tablas relacionales. Ahorre la instantánea del producto cuando se requiera el modelo de contenido completo y sus recursos.
- Diferentes puntos de entrada SDK aceptan diferentes extensiones. Para formatos como `.xlsm`, `.pptm`, `.ppsx`, `.ppsm`, y `.potx`, compruebe el backend desplegado y la API del navegador. No son nombres de formato Rust CLI directos adicionales.

## Cálculo durante la conversión

Para los flujos de trabajo de conversión de hoja de cálculo soportada, la conversión de archivos se puede combinar con el cálculo lado servidor:

- El cálculo de la Fórmula llena los resultados de caché perdidos en la importación, o recalcula antes de la exportación de acuerdo con la política seleccionada.
- El cálculo de Pivot deriva agrupación y agregación de los datos fuente y la configuración de pivote, luego materializa los resultados para la instantánea o el libro de trabajo exportado.
- El cálculo de formato número convierte los valores en fecha, porcentaje, moneda y otro texto de visualización formateado. Las exportaciones CSV/TSV pueden escribir valores de visualización o valores brutos.

Consulta [Headless y cálculo en el servidor](/overview/features/shared/server-calculation) para el procesamiento de contenido relacionado.

## Integración

La conversión de archivos pertenece al Server SDK. La aplicación proporciona la carga, el manejo de tareas, el almacenamiento y los endpoints de descarga. La conversión de instantáneas puede funcionar sin colaboración. Exportar un documento compartido lee una revisión confirmada después de que las ediciones pendientes se hayan sincronizado.

Empieza por [Integración de la conversión](/server/import-export) y [Conversión en Node.js](/server/import-export/node).

El soporte de formato y la preservación de características individuales son preguntas separadas. Utilice la lista de características de cada producto y archivos de negocios reales para verificar fórmulas, imágenes, estilos y diseño a través de importación, edición y exportación.
