테마 및 국제화는 공유 실행 시간 서비스입니다. 모든 6 개의 제품은 동일한 테마 서비스, 로컬 리소스 및 지역 구성을 사용하며 사용자 정의 플러그인은 동일한 상태를 관찰 할 수 있습니다. 브랜드 외관 및 사용자 선호도는 애플리케이션이 실행되는 동안 변경할 수 있으며 컨텐츠에 저장된 데이터 및 스타일에 영향을 미치지 않습니다.

SDK에는 **[19 내장 인터페이스 언어 및 지역 옵션](#supported-locales)** 및 **7 테마 팔레트**가 포함되어 있습니다. 모든 6 제품은 외관, 로컬 및 지역 구성 및 사용자 정의 테마 및 응용 프로그램 번역을 동일한 서비스를 사용합니다.

## 같은 상태로 UI와 렌더링 구동하기 [#architecture]

`ThemeService`는 완벽한 팔레트와 어두운 모드 상태를 별도로 저장하고 `currentTheme$` 및 `darkMode$`를 통해 변경 사항을 게시합니다. UI는 `--univer-*` CSS 변수로 팔레트를 확장하고 `univer-dark` 클래스에 응답합니다. 렌더링자는 동일한 서비스에 가입하고 회선에 영향을받는 구성 요소를 표시합니다. 캔버스 색상 서비스는 토큰을 해결하고 어두운 디스플레이, 캐시 및 캐시 결과를위한지도 색상을지도합니다.

이 장의 구성과 예는 `@univerjs/*` 및 `@univerjs-pro/*` **1.2.0**에 적용됩니다. SDK 의존성 버전이 애플리케이션에 정렬됩니다.

| 설정 | 선택 항목과 범위 | 런타임 API |
| --- | --- | --- |
| `theme` | 7개의 붙박이 팔레트, 또는 완전한 관례 `Theme`. | `setTheme()` |
| `darkMode` | `true` / `false`, 기본값 `false`. 팔레트와 별개입니다. | `toggleDarkMode()` |
| `locale` | 19 내장 `LocaleType` 값; 일치하는 리소스를 먼저로드합니다. | `setLocale()` |
| `locales` | Locale 식별자에 의해 결합 된 제품, 기능 및 응용 자원. | `loadLocales()` |
| `region` | 동일한 `LocaleType` 값; UI locale를 명시적으로 설정할 때까지 따릅니다. | `setRegion()` |
| `direction` | `ltr` / `rtl`, 기본 `ltr`; 메뉴 및 유사 UI에만 적용됩니다. 캔버스 콘텐츠는 RTL을 아직 지원하지 않습니다. | `setDirection()` |

## 완전한 팔레트에서 브랜드 테마 만들기 [#brand]

`@univerjs/themes`는 `primary`, `gray`의 기능적인 색깔 가늠자, `loop-color` 및 `highlight.background`를 제공합니다. 붙박이 주제를 복사하고, 변화가 요구하는 분지를 대체하고 구조를 완료하십시오. `setTheme()`가 전체 테마를 대체합니다; 그것은 부분적인 목표를 깊 채우지 않습니다. 아래 예는 지속적인 violet 상표 가늠자를 제공합니다.

7개의 붙박이 팔레트는 `blueTheme`, `darkBlueTheme`, `greenTheme`, `orangeTheme`, `purpleTheme`, `redTheme` 및 `yellowTheme`입니다.

`defaultTheme`는 `blueTheme`의 별칭입니다. 팔레트와 어두운 모드 상태는 별도로 선택됩니다. 구성 가능한 지점은 다음과 같습니다.

| 테마 항목 | 구성 옵션 |
| --- | --- |
| `primary` | 브랜드 색상 **10단계**: `50`, `100`~`900`. |
| `gray` | 중립색 **12단계**: `0`, `50`, `100`~`900`, `1000`. |
| `blue` · `red` · `orange` · `yellow` · `green` · `jiqing` · `indigo` · `purple` · `pink` | **9개 기능색 계열**, 각 10단계. |
| `loop-color` | **12**는 팔레트 토큰을 참조하는 색상 위치를 회전. |
| `highlight.background` | `color`와 `alpha`를 각각 설정하는 **16개** 배경 강조 위치. |

```typescript title="brand-theme.ts"
import type { Theme } from '@univerjs/themes';
import { defaultTheme } from '@univerjs/themes';

export const brandTheme: Theme = {
  ...defaultTheme,
  primary: {
    ...defaultTheme.primary,
    50: '#F5F3FF', 100: '#EDE9FE', 200: '#DDD6FE', 300: '#C4B5FD',
    400: '#A78BFA', 500: '#8B5CF6', 600: '#7C3AED', 700: '#6D28D9',
    800: '#5B21B6', 900: '#4C1D95',
  },
};
```

선택한 제품 통합에 테마를 전달하십시오. 이 예제는 시트 코어 미리 설정 (`UniverSheetsCorePreset`)을 사용하고 응용 프로그램에 의해 소유 된 번역 키를 등록합니다. 다른 제품은 자체 플러그인 구성을 사용합니다. 미리 설정은 다음 옵션을 수락합니다.

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 편집기를 마운트할 DOM 요소 또는 요소 ID입니다. |

```typescript title="setup.ts"
import { LocaleType, mergeLocales } from '@univerjs/core';
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core';
import SheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US';
import { createUniver } from '@univerjs/presets';
import { brandTheme } from './brand-theme';
import '@univerjs/preset-sheets-core/lib/index.css';

export const { univer, univerAPI } = createUniver({
  theme: brandTheme,
  darkMode: false,
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(SheetsCoreEnUS, {
      'sales-report': { generate: 'Generate report', ready: 'Ready for {0}' },
    }),
  },
  presets: [UniverSheetsCorePreset({ container: 'app' })],
});
```

## 실행 중 변경하고 표시 설정 따르기 [#appearance]

`setTheme()`는 팔레트를 변경하고, `toggleDarkMode()`은 어두운 상태 상태를 변경합니다. `getCurrentTheme()` 및 `isDarkMode()` 는 현재 값을 읽습니다. 혼자 `darkBlueTheme`로 전환하면 어두운 모드 플래그를 활성화하지 않습니다. 모양을 변경하면 편집기를 파괴하고 재조정하지 않습니다.

아래의 함수는 시스템 환경설정을 따르고 정리 함수를 반환합니다. 애플리케이션이 수동 외관 설정을 제공하는 경우 대신 핸들러에서 `toggleDarkMode()`를 호출합니다.

```typescript title="appearance.ts"
import type { FUniver } from '@univerjs/core/facade';
import { brandTheme } from './brand-theme';

export function followSystemAppearance(univerAPI: FUniver): () => void {
  univerAPI.setTheme(brandTheme);
  const preference = window.matchMedia('(prefers-color-scheme: dark)');
  const update = () => univerAPI.toggleDarkMode(preference.matches);
  update();
  preference.addEventListener('change', update);
  return () => preference.removeEventListener('change', update);
}
```

편집기가 설정된 후 함수를 호출하고, 구성 요소가 없는 경우 반환된 정리 함수를 실행하거나 시스템을 종료합니다. React 및 이와 유사한 통합에서 기존 인스턴스를 유지하고 Facade를 통해 업데이트하십시오.

## 사용자 플러그인도 테마와 언어 따르기 [#extensions]

Custom DOM은 주사된 CSS 변수를 사용하고 어두운 클래스에 대한 자체 스타일을 제공합니다. 변수에는 팔레트 값이 포함되어 있으므로 구성 요소는 여전히 어두운 상태 자체를 적용해야합니다.

```css title="report-panel.css"
.report-panel {
  color: var(--univer-gray-900);
  background: var(--univer-gray-0);
  border: 1px solid var(--univer-gray-200);
}

.univer-dark .report-panel {
  color: var(--univer-gray-100);
  background: var(--univer-gray-800);
  border-color: var(--univer-gray-700);
}
```

캔버스 확장은 `ThemeService`를 통해 라이브 토큰을 읽고 `ICanvasColorService`에서 그림에 사용되는 색상을 얻을 수 있습니다. 아래 예는 테마, 어두운 모드를 결합하고 단일 관찰 가능한 상태로 로컬 변경합니다. 그것은 상표를 번역하고 국가 변경 될 때 색상을 해결합니다. 그래서 룩업 또는 할당은 모든 도면 프레임에 반복되지 않습니다.

```typescript title="report-appearance.ts"
import { Disposable, Inject, LocaleService, ThemeService, toDisposable } from '@univerjs/core';
import { ICanvasColorService } from '@univerjs/engine-render';
import { combineLatest, ReplaySubject } from 'rxjs';

export interface IReportAppearance {
  label: string;
  accent: string;
}

export class ReportAppearance extends Disposable {
  readonly state$ = new ReplaySubject<IReportAppearance>(1);

  constructor(
    @Inject(ThemeService) theme: ThemeService,
    @Inject(LocaleService) locale: LocaleService,
    @ICanvasColorService colors: ICanvasColorService,
  ) {
    super();
    this.disposeWithMe(toDisposable(() => this.state$.complete()));
    this.disposeWithMe(combineLatest([
      theme.currentTheme$, theme.darkMode$, locale.currentLocale$,
    ]).subscribe(() => {
      this.state$.next({
        label: locale.t('sales-report.generate'),
        accent: colors.getRenderColor(theme.getColorFromTheme('primary.600')),
      });
    }));
  }
}
```

DI를 통해 `ReportAppearance`를 등록하고 플러그인에서 해결하십시오. 보기 또는 그림 관제사는 `state$`에 가입하고 새로 고침합니다. 소비자는 구독을 소유하고, 서비스 소유자는 `dispose()`을 호출합니다. Node.js는 또한 테마와 로컬 서비스를 제공하지만 브라우저 CSS를 주입하지 않습니다.

## 19개 기본 언어·지역 옵션 [#supported-locales]

`LocaleType`는 단순, 전통 및 홍콩 전통 중국 변종을 포함하여 다음 19 가지 옵션을 제공합니다. 모든 6 개의 제품의 주요 UI 패키지에는 이러한 리소스가 포함됩니다. 확장 범위는 선택한 패키지에 따라 다릅니다. 번들 태그는 수입 경로에 사용되며, 매칭 enum 값은 초기화 및 Facade 구성에 사용됩니다.

<Callout type="warning">
**RTL 범위:** 아랍 (`ar-SA`) 및 다른 Locale 번들은 메뉴와 메시지와 같은 인터페이스 텍스트를 번역합니다. `direction: 'rtl'`는 현재 메뉴와 유사한 UI 만 적응시킵니다. **RTL 레이아웃 및 캔버스 콘텐츠 영역에서 편집은 구현되지 않았습니다.**
</Callout>

## 플러그인별 언어 리소스를 조합하고 로드하기 [#locales]

`LocaleService`는 로컬에 의해 리소스를 구성하고 네임스페이스와 키 경로를 통해 라벨을 해결합니다. `mergeLocales()`은 제품 사전 설정, 기능 플러그인 및 응용 프로그램 번역을 결합합니다. `loadLocales()` 는 실행 시간에 리소스를 병합하고 `setLocale()` 언어를 선택합니다. Locale를 선택하면 번들을 다운로드하지 않습니다.

다음 예제는 이전에 소개 된 시트 인스턴스에 중국 리소스를 추가하고 UI를 중국어로 전환하고 명시적으로 독일 지역 컨벤션을 유지합니다. `LocaleType.ZH_CN`는 값 `zhCN`를 가지고 있습니다. `zh-CN`은 번들 파일명 및 문서 경로에 사용되는 형태입니다.

```typescript title="locales.ts"
import type { FUniver } from '@univerjs/core/facade';
import { LocaleType, mergeLocales } from '@univerjs/core';
import SheetsCoreZhCN from '@univerjs/preset-sheets-core/locales/zh-CN';

export function switchInterface(univerAPI: FUniver): void {
  univerAPI.loadLocales(LocaleType.ZH_CN, mergeLocales(SheetsCoreZhCN, {
    'sales-report': { generate: '生成报告', ready: '已为 {0} 就绪' },
  }));
  univerAPI.setLocale(LocaleType.ZH_CN);
  univerAPI.setRegion(LocaleType.DE_DE);
  univerAPI.setDirection('ltr');
}
```

`sales-report.generate`와 같은 키는 플러그인에 속합니다. 완전한 번역 문장을 작성하고 `{0}`, `{1}` placeholders를 동적 값으로 쓰십시오. `LocaleService.t('sales-report.ready', 'Alex')`. 모듈 초기화에서 번역을 캐시하지 마십시오. 리소스가 초기화 된 후, 누락 된 키는 현재 키 자체로 돌아갑니다. 인터페이스 언어를 전환하면 콘텐츠 또는 기존 단위로 이름을 변경하지 않습니다.

## 언어, 지역, 콘텐츠 표시 형식 구분하기 [#region]

| 계층 | 실제 영향 |
| --- | --- |
| UI `locale` | 메뉴, 메시지, 플러그인 문구와 문서 단어 분리 같은 일부 언어 처리. |
| `region` | 이 설정, 코멘트 날짜 / 시간 표시 및 통계 포맷을 사용하는 통화 작업; 통화 변환 또는 타임스탬프 변경 없음. |
| 콘텐츠 숫자 형식 | Saved Sheet number/date 형식은 셀 형식과 그에 적용된 내용 locale를 따르고, 지역 변경은 모두 다시 작성하지 않습니다. |
| `direction` | 독립적 인 UI 방향; 언어를 변경하거나 지역은 자동으로 전환하지 않습니다. |

지역이 지정되지 않으면 해당 기본이 적용됩니다. 지역이 명시적으로 설정되면 인터페이스 언어의 독립적으로 선택 될 수 있습니다. `region`는 시간대 설정이 아닙니다. RTL은 현재 메뉴와 유사한 UI를 적용하고, 오른쪽 왼쪽 레이아웃과 캔버스 콘텐츠 영역에서 편집이 구현되지 않았습니다.

## 콘텐츠 테마와 앱 테마의 경계 [#content-themes]

응용 테마는 작업대와 렌더링 기본을 제어합니다. 그것은 인식 된 셀 채우기, 텍스트, 모양, PDF 표기, 또는 명시된 차트 색상을 다시 작성하지 않습니다. 범위 및 테이블 테마, 슬라이드 색상 계획 및 캔버스 콘텐츠 테마는 해당 공공 제품 기능을 통해 관리됩니다.

Pro Charts는 시트, Doc, 슬라이드, 캔버스 차트에 의해 공유 별도의 `IEchartTheme` 레지스트리를 사용합니다. 응용 프로그램 `Theme`는 차트 테마가 아닙니다. 적절한 차트 플러그인이있는 호스트에서 Chart Facade를 가져 와서 완전한 정의를 등록하십시오.

```typescript title="chart-theme.ts"
import type { IEchartTheme } from '@univerjs-pro/engine-chart';
import type { FUniver } from '@univerjs/core/facade';
import { UniverTheme1 } from '@univerjs-pro/engine-chart';
import '@univerjs-pro/engine-chart/facade';

export function registerBrandChartTheme(univerAPI: FUniver): void {
  const chartTheme: IEchartTheme = {
    ...UniverTheme1,
    themeName: 'sales-brand',
    theme: {
      ...UniverTheme1.theme,
      color: ['#7C3AED', '#0EA5E9', '#10B981', '#F59E0B'],
    },
  };
  univerAPI.registerTheme('sales-brand', chartTheme);
}
```

Chart builder의 `setTheme('sales-brand')`를 통해 등록 된 이름을 선택하십시오. 명시적으로 설정된 차트 팔레트는 시리즈 색상을 무시할 수 있습니다.

외관은 현재 UI 변수와 `univer-dark` 클래스가 문서 루트에 기록되어 있기 때문에 하나의 브라우저 문서 내에서 일관성 있어야 합니다. 다중 편집기는 iframe과 같은 하나의 외관 또는 사용 별도의 문서를 공유해야 합니다. 별도의 컨테이너는 CSS 테마를 격리하지 않습니다.
