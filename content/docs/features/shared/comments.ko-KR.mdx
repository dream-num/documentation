댓글은 토론을 콘텐츠 옆에 유지합니다. 검토자는 값, 단락, 도형의 문제를 지적하고 작성자와 다른 참여자는 같은 스레드에서 답변하며 맥락을 더할 수 있습니다. 외부 채팅으로 토론을 나눌 필요가 없습니다.

## 질문에서 결론까지 [#review-workflow]

1. **콘텐츠 지정**: 셀, 선택한 텍스트, 레코드, 요소, 페이지 위치에 댓글을 달고 콘텐츠 참조를 보존합니다.
2. **스레드에서 토론**: 루트 댓글과 답글을 묶어 작성자, 시간, 본문을 표시합니다.
3. **해결 또는 다시 열기**: 수정 후 해결로 표시합니다. 추가 검토가 필요하면 기존 토론을 유지한 채 다시 엽니다.

댓글 패널은 전체, 미해결, 해결됨, 현재 사용자 관련 토론을 필터링할 수 있습니다. 해결은 삭제가 아니므로 처리 과정을 다시 확인할 수 있습니다.

## 제품별 댓글과 주석 [#product-comments]

스크린샷은 동일한 영어 Northstar 출시 프로젝트를 사용합니다. Facade API로 실제 편집기에서 만든 프런트엔드 댓글과 주석 예시입니다. 이미지를 클릭하면 확대됩니다.

### Sheets [#sheets]

셀에 토론을 연결해 예산 수치 옆에서 예측 기준, 비용, 승인을 확인합니다. 여러 스레드, 연속 답글, 해결된 토론 그룹을 보여 줍니다. 셀 댓글은 `range.addCommentAsync()`를 사용합니다. 이미지, 차트, 도형 댓글에는 해당 그리기 댓글 연동이 필요합니다.

![Sheets 댓글: 출시 예산, 셀 위치, 검토자 답글, 해결된 토론](/assets/features/comments/sheets.png)

[제품 통합 및 API](/guides/sheets/features/comments)

### Docs [#docs]

선택한 텍스트 범위에 댓글을 달아 계약 조항, 제안서, 출시일을 검토합니다. 댓글 카드에 인용문을 유지하고 텍스트 편집 시 댓글 장식이 위치를 관리합니다. 예시는 출시일, 지표 정의, 이전 절차 교체를 다룹니다. `document.getTextRange(...).createCommentAsync()`를 사용합니다.

![Docs 댓글: 출시 개요, 텍스트 인용, 세 개의 검토 스레드](/assets/features/comments/docs.png)

[제품 통합 및 API](/guides/docs/features/comments)

### Slides [#slides]

개별 슬라이드 요소나 자유로운 페이지 위치에 댓글을 추가합니다. 요소 댓글은 텍스트 상자, 이미지, 차트 등의 안정적인 ID를 참조하며 위치 댓글은 정규화된 페이지 좌표를 사용합니다. 예시는 출시 목표와 배치를 검토합니다. `slide.createElementCommentAsync()`와 `slide.createPositionCommentAsync()`를 사용합니다.

![Slides 댓글: 출시 검토, 요소 위치, 여러 검토자의 답글](/assets/features/comments/slides.png)

[제품 통합 및 API](/guides/slides/features/comments)

### Relational Table [#bases]

댓글은 레코드 ID에 연결되며 현재 뷰의 표시 행 번호에 의존하지 않습니다. 업무 인계, 고객 후속 대응, 검수에 적합합니다. 출시 추적 표에 담당자 토론, 승인 대기 사항, 레코드별 댓글 표시를 보여 줍니다. `record.createCommentAsync()`를 사용합니다.

![Relational Table 댓글: 출시 레코드, 댓글 표시, 업무 인계 토론](/assets/features/comments/bases.png)

[제품 통합 및 API](/guides/bases/features/thread-comment)

### Canvases [#boards]

도형 같은 요소나 보드의 지정 위치에 댓글을 추가합니다. 요소 댓글은 객체를 참조하고 위치 댓글은 보드 좌표를 저장합니다. 예시는 고객 조사, 개발 인계, 출시 위험을 흐름 안에서 논의합니다. `board.createElementCommentAsync()`와 `board.createPositionCommentAsync()`를 사용합니다.

![Canvases 댓글: 컬러 출시 흐름, 요소 및 위치 댓글, 답글](/assets/features/comments/boards.png)

[제품 통합 및 API](/guides/boards/features/comments)

### PDF: 페이지 주석 [#pdfs]

PDF는 현재 강조 표시, 밑줄, 취소선, 물결선, 잉크의 페이지 주석을 제공합니다. 저장 가능한 PDF 주석 객체이며 앞의 답글·해결 가능한 댓글 스레드와 다릅니다. 예시는 출시일과 검수 지표를 표시하고 이전 승인 단계를 취소합니다. `page.insertAnnotation()`을 사용합니다.

![PDF 주석: 출시 검토 문서의 강조, 밑줄, 취소선, 잉크](/assets/features/comments/pdfs.png)

## 통합 방법 [#integration]

**프런트엔드**: 제품의 댓글 및 UI 플러그인을 등록하고 공통·제품별 댓글 `/facade` 진입점을 가져옵니다. 제품 메서드는 앵커를 생성하고 `replyCommentAsync()`, `updateCommentAsync()`, `resolveCommentAsync()` 같은 공통 API는 이후 토론을 처리합니다. `resolved: false`로 스레드를 다시 엽니다. PDF는 별도 주석 API를 사용합니다.

**공유 토론**: 핵심 협업과 함께 Comment Service, Comment Endpoint, 독립 데이터베이스 어댑터를 추가하고 프런트엔드 원격 데이터 소스를 구성합니다. 주 문서는 콘텐츠에 따라 변하는 앵커를 유지하고 Comment Service는 본문, 답글, 해결 상태를 저장하며 문서 방에 댓글 갱신을 게시합니다. [댓글 패키지](/server/collaboration/packages#thread-comment)와 [Comments 예제](/server/collaboration/examples#comments)를 참고하세요.

댓글 권한은 본문 편집과 독립적으로 설정할 수 있습니다. 애플리케이션 신원과 서버 인가는 [권한과 인가](/overview/features/shared/permissions)를 참고하세요.
