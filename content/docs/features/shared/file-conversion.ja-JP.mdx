ファイルのインポートとエクスポートは、Univerが使用するコンテンツモデルに外部ファイル形式をリンクします。 インポートは、ファイルを対応する製品スナップショットに解析します。 シリアルエクスポートは、選択した出力フォーマットに製品スナップショットをスナップショットを出力します。

## ファイルからスナップショットへ

オフィスファイルは2つのグループに分類されます。 `.xlsx`、`.docx`および`.pptx`はXMLおよびイメージのような資源を保持するOOXMLのパッケージです。 `.xls`の`.doc`そして`.ppt`の使用は古いバイナリ構造です。 CSVおよびTSVは明白なテキストです。支えられたフォーマットで元のファイルを、転換モジュールは解読、パッケージの解析および資源のマッピングを扱います。

スナップショットは、保存して復元できるフォームで製品のコンテンツ状態です。 [6つの製品スナップショットスキーマは以下のとおりです。](#snapshot-のデータ構造).

### インポート：ファイル → Snapshot

シート、Doc、スライド、リレーショナルテーブル、またはその他の製品モデルにコンテンツ、スタイル、リソースをインポートします。

<Mermaid chart={"flowchart LR\n    A[\"1. 元ファイル<br/>XLSX / DOCX / PPTX など\"]\n    B[\"2. Snapshot に解析<br/>Server SDK\"]\n    C[\"3. 必要時に計算<br/>Snapshot を更新\"]\n    D[\"4. Web SDK<br/>内容を編集・処理\"]\n    A --> B --> C --> D\n    classDef calculation stroke-dasharray:5 4\n    class C calculation"} />

### エクスポート：Snapshot → ファイル

エクスポートは、現在の製品スナップショットを読み込み、ターゲットフォーマットの構造とリソースを記述します。スナップショットは、実行時にコンテンツモデルで、通常はJSONとして転送または保存されます。

<Mermaid chart={"flowchart LR\n    A[\"1. 現在の Snapshot<br/>編集後の内容\"]\n    B[\"2. 必要時に計算<br/>Snapshot を更新\"]\n    C[\"3. Server SDK<br/>出力形式に変換\"]\n    D[\"4. 出力ファイル<br/>XLSX / DOCX / PPTX など\"]\n    A --> B --> C --> D\n    classDef calculation stroke-dasharray:5 4\n    class B calculation"} />

シートの場合、これは、選択したポリシーに従って計算式、ピボット、および番号フォーマットを意味し、スナップショットを更新します。 [サーバ側計算](/overview/features/shared/server-calculation)を参照してください。

### Snapshot のデータ構造

各製品は、通常、JSON として、コンテンツやリソースの参照を主張するための独自のスナップショット契約を定義します。インターフェイスリンクは、フィールドの定義、タイプ、および例につながります。

<div className="[&_table]:min-w-180 [&_code]:whitespace-nowrap">

| 製品 | Snapshot インターフェース | 主な内容 |
| --- | --- | --- |
| スプレッドシート (Sheet) | [`IWorkbookData`](/guides/sheets/model/workbook-data#iworkbookdata) | ワークシート、セル、共有スタイル、プラグインリソース。 |
| ドキュメント (Doc) | [`IDocumentData`](/guides/docs/model/document-data#idocumentdata) | 本文、段落、スタイル、ヘッダー、フッター、リソース。 |
| スライド (Slide) | [`ISlideData`](/guides/slides/model/slide-data#islidedata) | スライド、要素、マスター、テーマ、リソース。 |
| リレーショナルテーブル (Relational Table) | [`IBaseSnapshot`](/guides/bases/model/base-snapshot#ibasesnapshot) | テーブル、フィールド、レコード、ビューとそれぞれの順序。 |
| キャンバス (Canvases) | [`IBoardData`](/guides/boards/model/board-data#iboarddata) | ページ、要素、テーマ、リソース。 |
| PDF | [`IPdfUnitData`](/guides/pdfs/model/pdf-data#ipdfunitdata) | 元文書、永続編集状態、リソースのバインディング。 |

</div>

`save()` を製品ファサードで呼び、現在のスナップショットを取得してから、対応する作成 API を使用して復元します。既にロードされているコンテンツはファサード API を介して編集されます。PDF では、`pdf.save()`はソースベースラインと `editState`の両方を保存します。

## 製品別の対応形式

下のオフィスおよびテーブルのフォーマットは直接Rust Exchangeのルートを使用します。PDFは独自の変換モジュールを使用しており、同じテーブルに別々にリストされています。

<div className="[&_table]:min-w-180 [&_code]:whitespace-nowrap">

| 製品 | インポート / コンパイル | エクスポート | 範囲 |
| --- | --- | --- | --- |
| [スプレッドシート (Sheet)](/guides/sheets/features/import-export) | `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` | CSV/TSV は 1 つのワークシートを保持します。 |
| [ドキュメント (Doc)](/guides/docs/features/import-export) | `.doc`, `.docx` | `.docx` | レガシーDOCはDocsモデルにインポートします。 出力はDOCXです。 |
| [スライド (Slide)](/guides/slides/features/import-export) | `.ppt`, `.pptx` | `.pptx` | スライドモデルにレガシーPPTの輸入。出力はPPTXです。 |
| [リレーショナルテーブル (Relational Table)](/guides/bases/features/import-export) | `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` | CSV/TSV は 1 つのテーブルを保持します。XLSX はテーブルとフィールドマッピングをサポートしています。 |
| [キャンバス (Canvases)](/guides/boards/features/import-export) | Mermaid (`.mmd` / ソーステキスト) | `.pptx` | Mermaidは、スナップショットが保存される前にキャンバスファサードを介して適用されるインポートドラフトを生成します。 PPTXは、アクティブなページをエクスポートします。 |
| [PDF](/guides/pdfs/features/import-export) | `.pdf` | `.pdf` | Rust Exchange CLIとは別々のPDF変換サービスが必要です。 |

</div>

- `.xls`、`.doc`および`.ppt`は輸入のフォーマットです。出力フォーマットはそれぞれ`.xlsx`、`.docx`、`.pptx`です。
- CSV/TSV エクスポートには、1 つのワークシートまたは 1 つのリレーショナルテーブルテーブルが含まれています。完全なコンテンツモデルとリソースが要求されると、製品スナップショットを保存します。
- 異なるSDKエントリポイントは、異なる拡張子を受け入れます。 などのフォーマット `.xlsm`, `.pptm`, `.ppsx`, `.ppsm`, と `.potx`、デプロイされたバックエンドとブラウザ API を確認します。 Rust CLI の形式名は追加ではありません。

## 変換時の計算

サポートされているスプレッドシート変換ワークフローでは、ファイル変換はサーバー側の計算と組み合わせることができます。

- 式計算は、選択したポリシーに従ってエクスポートする前に、インポートのキャッシュされた結果が不足しているか、または再計算を記入します。
- ピボット計算は、ソースデータとピボット設定からグループ化と集計を導き、スナップショットまたはエクスポートされたワークブックの結果を材料化します。
- 数値形式計算は、日付、パーセンテージ、通貨、およびその他のフォーマット表示テキストに値が変わります。 CSV/TSVエクスポートは、表示値または生の値を書き込むことができます。

関連する処理は[ヘッドレス実行とサーバー側計算](/overview/features/shared/server-calculation)を参照してください。

## 導入方法

ファイルの変換は、Server SDKに属しています。アプリケーションは、アップロード、タスク処理、ストレージ、およびダウンロードエンドポイントを提供します。スナップショット変換は、コラボレーションなしで実行できます。共有文書のエクスポートは、バックエンドの編集が同期した後に確認されたリビジョンを読みます。

[ファイル変換の統合](/server/import-export)と [Node.js ファイル変換](/server/import-export/node)から始めてください。

個々の機能のサポートと保存のフォーマットは別々の質問です。各製品の機能リストと実際のビジネスファイルを使用して、式、画像、スタイル、およびレイアウトをインポート、編集、およびエクスポートで確認します。
