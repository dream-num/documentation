Headless Univer は、対話型エディター UI を持たない Univer の内容ランタイムです。ブラウザー版と内容モデル、コマンド、計算、Facade API を共有します。Node.js での内容処理やブラウザー内の UI を使わない処理に利用でき、登録する製品・機能プラグインによって利用可能な機能が決まります。

ここで扱う JavaScript/TypeScript の内容ランタイムと `univer-rs` は別の実装です。後者はサーバー側計算とファイル変換を担い、同じスナップショットを使う Headless ワークフローと組み合わせられます。

## Headless でできること [#headless-capabilities]

- **内容と構造の読み書き**：Univer スナップショットを作成・読み込みし、Facade API でセル、段落、ページ、図形、レコードを操作して更新後のスナップショットを保存します。バッチ処理、データ生成、内容検査、Agent 自動化に利用できます。
- **登録したロジックの実行**：数式、並べ替え、フィルター、入力規則、ピボットを処理し、画像、グラフ、図形、コメントのリソースを変更します。利用範囲は製品・機能プラグインと依存関係で決まります。
- **サービス連携**：Node.js 共同編集クライアントを追加すると、共同編集 Unit の読み込み、変更送信、同期確認ができます。Office ファイルの入出力には Server SDK の変換モジュールを組み合わせます。

Headless 自体にメニュー、ツールバー、ダイアログ、マウス・キーボード操作、スクリーンショット、印刷は含まれません。永続化、認証、共同編集サーバー、ファイル変換も別途必要です。`save()` は Univer スナップショットを返す処理であり、DB 保存や XLSX・DOCX・PDF 出力ではありません。画像と視覚的なレイアウト検査には[レンダリングランタイム](/ai/visual-inspection)を接続します。ヘッドレスブラウザーもレンダリング層を実行します。

### 通信・計算プロセス・共同編集

必要に応じて `@univerjs/network`、`@univerjs/rpc-node` で通信と Node.js 計算プロセスを、`@univerjs-pro/license` でライセンスを接続します。`@univerjs-pro/collaboration`、`@univerjs-pro/collaboration-client`、`@univerjs-pro/collaboration-client-node` は Headless 共同編集クライアントを構成し、サーバーそのものではありません。ローカルスナップショットの処理には共同編集サービスは不要です。

### 内容処理のみのランタイムに含めないパッケージ

- `@univerjs/ui`、`@univerjs/design`、製品・機能の `*-ui` パッケージ（`@univerjs/sheets-ui`、`@univerjs/docs-ui`、`@univerjs-pro/slides-ui` など）は UI、描画連携、操作を提供するため、純粋な Node.js 内容処理には登録しません。
- `@univerjs/sheets-find-replace`、`@univerjs/sheets-crosshair-highlight` は名前に `-ui` がなくても `@univerjs/sheets-ui` に依存します。
- `@univerjs/preset-sheets-core`、`@univerjs/preset-docs-core` の標準プリセットは UI を登録します。Node.js Headless 用プリセットではないため、プラグインモードで内容層を選択します。

**`@univerjs/engine-render` は個別に判断します。** 現行の Node.js サンプルでも共有の描画管理などを提供するために登録しますが、登録だけでは Canvas の作成やエディターのマウントは行いません。Headless 構成に含められても、描画、フォント計測、画像出力には対応する描画環境が必要です。全 API が純粋な Node.js で動くわけではありません。

**Facade は操作 API であり、環境の適配機能ではありません。** 内容プラグインの `/facade` 拡張を読み込み、実装元のプラグインも登録します。`@univerjs/ui/facade`、`@univerjs/sheets-ui/facade` のメニュー、スクロール、選択範囲の視覚操作には UI が必要です。名前や Facade の有無だけでなく、依存関係と実際の呼び出し経路で判断してください。

実行可能な構成は [Sheets Headless 入門](/guides/sheets/getting-started/node)と [Docs Headless 入門](/guides/docs/getting-started/node)を参照してください。

## 編集時の即時計算と、サーバーのバージョン別計算 [#サーバーで事前計算しブラウザーに素早く表示]

フロントエンドとサーバーの両方に数式エンジンがあります。フロントエンドは編集に応答し、サーバーは Snapshot の生成やファイル処理時に、確定した内容のリビジョンを計算します。

- **編集中**：ブラウザーが影響を受ける数式を差分計算し、結果をすぐに表示します。Worker での実行も可能です。共同編集は内容の変更を記録・同期します。
- **Snapshot 生成時**：サーバーのスナップショット保存ポリシーに応じて保存処理を開始し、その処理の対象リビジョンを取得します。`univer-rs` で計算した後、同じリビジョンの内容と結果をまとめて保存します。
- **再度開くとき**：Snapshot 内の有効な計算結果を再利用し、その後の変更を適用して計算を続けることで、全体の重複計算を減らします。

<Mermaid chart={"flowchart LR\n    F[\"フロントエンド編集<br/>即時計算\"]\n    C[\"内容の同期<br/>確定した変更\"]\n    R[\"Rust 計算<br/>リビジョン N\"]\n    S[\"Snapshot 保存<br/>saveSnapshot\"]\n    F <--> C\n    C -->|\"Snapshot 生成時\"| R\n    R --> S"} />

**変更は継続的に同期します。サーバー計算は Snapshot の生成時に実行し、対応する内容のリビジョンとともに結果を保存します。**

保存済み結果に合わせて初期計算を設定します。

- `WHEN_EMPTY`：保存済みの値を再利用し、不足する結果だけ計算します。
- `NO_CALCULATION`：初期計算を省き、アプリが結果を提供します。
- `FORCED`：保存済み結果を更新するため全数式を再計算します。

これらは初回読み込みの設定です。その後の編集はフロントエンドで計算を続け、サーバーはリビジョン別の Snapshot 生成やファイル処理時に必要に応じて計算します。[数式設定](/guides/sheets/features/core/formula)、[共同編集の概要](/server/collaboration/overview)、[ファイル変換](/overview/features/shared/file-conversion)を参照してください。

## 配列数式の計算と展開

対応する関数と形式の範囲で、Rust は Excel の配列数式とスピル規則に従います。アンカー、展開範囲、各セルの結果を返し、動的配列と従来の配列数式の指定範囲を扱います。

例えば空の `A1` に `=SEQUENCE(3,2)` を入力すると、次の結果になります。

| A | B |
| --- | --- |
| 1 | 2 |
| 3 | 4 |
| 5 | 6 |

数式は `A1` に残り、結果は `A1:B3` に展開します。配列が縮むと古い展開値を消去し、展開先が塞がれている場合は `#SPILL!` を返します。ブラウザー、Agent、ファイル出力で計算済み Snapshot を再利用できます。

[関数の対応範囲](/guides/sheets/features/core/formula)と [Excel の配列動作](https://support.microsoft.com/en-us/excel/dynamic-array-formulas-and-spilled-array-behavior)を参照してください。

## Agent の実行と検証につなぐ

既存 Agent のモデル、会話、ツール制御を利用し、AI SDK から Office 操作を提供します。

1. 構造と対象の内容を読み取ります。
2. ヘッドレス環境で Facade による編集と必要な計算を実行します。
3. 計算とコミット完了を待ち、最新状態を読み戻します。
4. 値と構造を検証し、必要なら画像とレイアウトも確認します。

[内容操作](/ai/content-operations)と[視覚的検証](/ai/visual-inspection)を組み合わせられます。人によるレビューには [Worktree](/ai/worktree) で変更を隔離し、比較後にマージします。[Univer CLI](/overview/examples/cli)は Agent 向けアプリへの組み立て例です。
