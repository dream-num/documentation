評論把討論保留在內容旁邊。審閱者可以就數值、段落或圖形提出問題，作者在同一執行緒內回覆，其他參與者補充上下文，討論因此不必分散到外部聊天工具中。

## 從問題到結論 [#review-workflow]

1. **定位問題**：將評論掛載到單元格、選中文字、記錄、元素或頁面位置上，錨點會保留對相應內容的引用。
2. **線上程中討論**：執行緒由一條根評論和若干回覆組成，每條評論都包含作者、時間和正文。
3. **解決或重新開啟**：修改完成後將執行緒標記為已解決；需要跟隨時重新開啟，此前的討論仍完整保留。

評論面板支援按全部、未解決、已解決或與當前使用者有關的討論篩選。已解決並不表示刪除，處理結論仍可供查閱。

## 各產品的留言與批註 [#product-comments]

下文截圖均來自同一個英文 Northstar 釋出專案。截圖透過 Facade API 在真實編輯器中生成，用於展示前端的評論與批註效果。點選圖片可放大。

### 試算表（Sheet） [#sheets]

將討論錨定到具體單元格，即可在預算數字旁確認預測、費用明細或審批結論。範例中包含多條討論、連續的多條回覆，以及一個已解決分組。單元格評論透過 `range.addCommentAsync()` 新增；圖片、圖表和形狀上的評論需要對應的繪圖評論整合。

### 文件（Doc） [#docs]

審閱合同條款、方案措辭或釋出日期時，可以選中一段文字並新增評論。評論卡片會保留引用的文字，編輯周邊文字時由評論裝飾維持錨點。範例討論的是釋出日期、指標定義以及舊流程的替換。呼叫 `document.getTextRange(...).createCommentAsync()`。

[查看產品接入與 API](/guides/docs/features/comments)

### 簡報（Slide） [#slides]

評論可以針對單個元素，也可以放在幻燈片的任意位置。元素評論透過穩定 ID 關聯文字框、圖片、圖表等物件；位置評論使用頁面歸一化座標。範例討論的是釋出目標和版式。呼叫 `slide.createElementCommentAsync()` 和 `slide.createPositionCommentAsync()`。

![Slides 留言：發布審閱投影片、元素定位與多角色回覆](/assets/features/comments/slides.png)

[查看產品接入與 API](/guides/slides/features/comments)

### 關聯式表格（Relational Table） [#bases]

評論引用記錄 ID，因此討論始終繫結到某條業務記錄，而與它在檢視中的行號無關。評論可用於任務交接、客戶跟進和驗收確認。範例的釋出跟蹤表展示了負責人相關的討論、待審批事項，以及記錄旁的評論標記。呼叫 `record.createCommentAsync()`。

![Relational Table 留言：發布追蹤記錄、留言標記與交接討論](/assets/features/comments/bases.png)

[查看產品接入與 API](/guides/bases/features/thread-comment)

### 畫布（Canvases） [#boards]

評論可以附加到圖形等元素上，也可以在畫布的特定位置單獨留一條。元素評論關聯物件；位置評論儲存畫布座標。範例中，客戶研究、開發交接和釋出風險等討論都位於對應的內容旁。呼叫 `board.createElementCommentAsync()` 和 `board.createPositionCommentAsync()`。

### PDF：頁面批註 [#pdfs]

PDF 目前提供頁面批註：高亮、下劃線、刪除線、波浪線和墨跡。這些是可持久儲存的 PDF 批註物件，不同於上文支援回覆和解決的評論執行緒。範例高亮了釋出日期，標出了驗收指標，並劃掉了一箇舊的審批步驟。呼叫 `page.insertAnnotation()`。

## 接入方式 [#integration]

**前端**：註冊對應產品的評論外掛和 UI 外掛，並匯入通用評論與產品評論的 `/facade` 入口。產品方法負責建立錨點，`replyCommentAsync()`、`updateCommentAsync()`、`resolveCommentAsync()` 等通用 API 負責後續的討論操作。重新開啟執行緒時傳入 `resolved: false`。PDF 使用獨立的批註 API。

**共享討論**：在核心協同之外接入 Comment Service、Comment Endpoint 和獨立的資料庫介面卡，再配置前端的遠端評論資料來源。主文件儲存隨內容變化的錨點；Comment Service 儲存評論正文、回覆和解決狀態，並將評論更新發布到文件房間。參見[評論擴充套件包](/server/collaboration/packages#thread-comment)和 [Comments 範例](/server/collaboration/examples#comments)。

評論權限可以與正文編輯權限分開配置。應用身分和伺服器端授權參見[權限與授權](/overview/features/shared/permissions)。
