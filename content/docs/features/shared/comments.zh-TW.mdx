留言把討論留在內容旁邊。審閱者可以指出數值、段落或圖形的問題，作者在同一討論串回覆，其他參與者繼續補充脈絡，無須把討論分散到外部聊天。

**產品名稱：** [Relational Table（關聯式表格）](/docs/features/relational-table) 對應 SDK/API 中的 `Base`；[Canvases（畫布）](/docs/features/canvas) 對應 `Board`。

## 從問題到結論 [#review-workflow]

1. **定位內容**：對儲存格、選取文字、記錄、元素或頁面位置發起留言，保留內容引用。
2. **回覆討論**：一則根留言與後續回覆組成討論串，顯示作者、時間與留言正文。
3. **解決或重新開啟**：完成修改後將討論串標為已解決；仍需追蹤時可重新開啟，保留原有討論。

留言面板可篩選全部、未解決、已解決或與目前使用者相關的討論。已解決不等於刪除，仍可回顧處理過程。

## 各產品的留言與批註 [#product-comments]

以下使用同一組 Northstar 英文發布專案。截圖透過 Facade API 在真實編輯器中建立，展示前端留言與批註效果；點擊圖片可放大。

### 試算表（Sheet） [#sheets]

將討論定位到特定儲存格，在預算數字旁確認預測定義、費用明細與審批結論。範例同時展示多個討論串、連續回覆和已解決分組。儲存格留言使用 `range.addCommentAsync()`；圖片、圖表和圖形的物件留言需要相應的繪圖留言外掛。

[查看產品接入與 API](/guides/sheets/features/comments)

### 文件（Doc） [#docs]

對選取的文字範圍留言，適合合約條款、方案敘述或發布日期的審閱。留言卡片保留引用片段，文字編輯透過留言裝飾維護定位。範例討論發布日期、指標定義和舊流程替換；入口為 `document.getTextRange(...).createCommentAsync()`。

![Docs 留言：英文發布說明、文字引用與三個審閱討論串](/assets/features/comments/docs.png)

[查看產品接入與 API](/guides/docs/features/comments)

### 簡報（Slide） [#slides]

可以留言於單一頁面元素，也可以在投影片自由位置放置留言。元素留言透過穩定 ID 關聯文字方塊、圖片、圖表等物件；位置留言使用頁面內的正規化座標。範例在發布目標與版面旁展開討論；入口為 `slide.createElementCommentAsync()` 和 `slide.createPositionCommentAsync()`。

![Slides 留言：發布審閱投影片、元素定位與多角色回覆](/assets/features/comments/slides.png)

[查看產品接入與 API](/guides/slides/features/comments)

### 多維表格（Base） [#bases]

留言綁定記錄 ID，討論圍繞一筆業務記錄展開，不依賴目前檢視中的顯示列號。適合任務交接、客戶追蹤或驗收確認。範例在發布追蹤表中討論負責人與待審批事項，並在記錄旁顯示留言標記；入口為 `record.createCommentAsync()`。

![Base 留言：發布追蹤記錄、留言標記與交接討論](/assets/features/comments/bases.png)

[查看產品接入與 API](/guides/bases/features/thread-comment)

### 畫板（Board） [#boards]

將留言附在圖形等元素上，或在畫板指定位置留下註解。元素留言關聯物件，位置留言保留畫板座標，適合流程、架構和設計審閱。範例圍繞客戶研究、開發交接與發布風險展開討論；入口為 `board.createElementCommentAsync()` 和 `board.createPositionCommentAsync()`。

![Board 留言：彩色發布流程、元素與位置留言及連續回覆](/assets/features/comments/boards.png)

[查看產品接入與 API](/guides/boards/features/comments)

### PDF：頁面批註 [#pdfs]

PDF 目前展示的是頁面批註：螢光標示、底線、刪除線、波浪線和墨跡。它們是可儲存的 PDF 批註物件，與前述可回覆、可解決的留言討論串不同。範例標示發布日期、驗收指標，並劃去舊審批流程；入口為 `page.insertAnnotation()`。

## 接入方式 [#integration]

**前端**：註冊相應產品的留言功能與 UI 外掛，呼叫 Facade 時匯入通用留言和產品留言的 `/facade` 入口。產品方法負責建立錨點，通用 `replyCommentAsync()`、`updateCommentAsync()`、`resolveCommentAsync()` 等方法負責後續討論操作；`resolved: false` 可重新開啟討論串。PDF 使用獨立批註 API。

**多人共享**：在核心協同之外接入 Comment Service、Comment Endpoint 與獨立資料庫轉接器，並設定前端遠端留言資料來源。主文件保留隨內容變化的錨點，Comment Service 儲存正文、回覆與解決狀態，透過文件房間發布留言更新。參見[留言擴充套件](/server/collaboration/packages#thread-comment)和 [Comments 範例](/server/collaboration/examples#comments)。

留言權限可獨立於正文編輯權限設定。業務身分與伺服器端授權的接入方式見[權限與授權](/docs/features/shared/permissions)。
