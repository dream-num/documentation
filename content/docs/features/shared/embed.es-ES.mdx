Los bloques incrustados sitúan un producto Univer dentro de otro: presupuestos y tareas en un documento de proyecto, hojas calculables en una diapositiva o planes y notas en un lienzo. El contenido hijo conserva su modelo de datos y editor nativo; al activarlo, cambian el foco y los menús.

**Nombres de producto:** [Relational Table (tabla relacional)](/docs/features/relational-table) se denomina `Base` en el SDK y las API; [Canvases (lienzos)](/docs/features/canvas) se denomina `Board`.

## Principio: Unit anfitriona y Unit hija [#principle]

La **Unit anfitriona** guarda posición, tamaño, referencia a la hija y vista inicial. La **Unit hija** guarda las celdas, párrafos o registros reales. Embed resuelve la referencia, carga la Unit hija y coloca su editor en el anfitrión. Una [Unit](/guides/sheets/getting-started/quickstart#unit) puede ser un libro, documento, presentación, tabla relacional o lienzo.

<Mermaid chart={"flowchart LR\n    A[\"Unit anfitriona<br/>Documento, página o lienzo\"]\n    B[\"Descriptor Embed<br/>Posición + referencia hija\"]\n    C[\"Resolver referencia<br/>Cargar Unit hija\"]\n    D[\"Editor nativo hijo<br/>Visualización e interacción\"]\n    E[\"Editar / guardar<br/>Actualizar Unit hija\"]\n    A --> B --> C --> D --> E"} />

La relación y el contenido se guardan por separado. Editar una celda incrustada actualiza la Sheet hija; mover o redimensionar el bloque actualiza su anclaje en el anfitrión.

## Ubicaciones compatibles [#locations]

| Producto anfitrión | Ubicación | Uso habitual |
| --- | --- | --- |
| Sheet | Objeto flotante o pestaña del libro | Añadir un informe junto al modelo de cálculo o abrir una base de tareas. |
| Doc | Bloque del cuerpo | Reunir texto, presupuestos y tareas en una página de proyecto. |
| Slide | Objeto flotante o página independiente | Revisar datos fuente editables junto a las conclusiones. |
| Relational Table (Base) | Entrada de la lista de tablas | Acceder a la documentación desde la base de negocio. |
| Canvases (Board) | Objeto flotante en el lienzo | Reunir datos, propuestas y debate en un lienzo. |

El panel resume el gasto a la izquierda e incrusta un Doc completo a la derecha. La pestaña Launch tracker abre una Base. Launch brief aparece como Doc junto a la tabla de tareas. Permite alternar entre registros y explicación en un CRM, seguimiento de proyectos o base operativa. Es una entrada de la lista; no crea automáticamente un documento por registro.

## Cómo se conectan las fórmulas [#formulas]

**La incrustación aporta visualización y edición; las referencias aportan cálculo.** Insertar un bloque no crea una fórmula de resumen. Con referencias entre Units, las celdas de Sheet y las Shapes con fórmula de Doc, Slide y Board pueden leer rangos de Sheet o campos de Base. Los campos de fórmula de Base también pueden referenciar Sheet. Si los datos fuente y las notificaciones están disponibles, los cambios pertinentes disparan el recálculo.

<Mermaid chart={"flowchart LR\n    A[\"Editar Sheet / Base incrustada\"]\n    B[\"Cambiar datos de Unit hija\"]\n    C[\"Actualizar referencias y dependencias\"]\n    D[\"Recalcular fórmula\"]\n    E[\"Actualizar celda / Shape\"]\n    A --> B --> C --> D --> E"} />

| Escenario y fórmula | Resultado verificado |
| --- | --- |
| Presupuesto en Slide: `=SUM('[Leadership Budget]Budget'!C5:C8)` | Cambiar `C7` de 17,100 a 18,000 actualiza el total de **61,200 → 62,100**. |
| Total de Base en Sheet: `=SUM([Control Tasks]!Launch_tasks[Cost])` | Cambiar un Cost de 4,000 a 4,500 actualiza el total de **18,000 → 18,500**. |

Además del nombre legible, persista el ID estable de la Unit. Use `getFormula().buildReference()` para generar la referencia y su asociación externa en el anfitrión. Para una tabla Base, use `table.getFormulaName()` en vez de concatenar su nombre visible o ID. Las Shapes calculadas usan `shape.setFormula({ formula, externalReferences })`; lea los resultados tras completar el cálculo. Consulte [Formula Facade](/reference/facade/formula#buildreference), [Shape Facade](/reference/facade/shape#setformula) y [fórmulas de Base](/guides/bases/features/core/formulas).

## Creación e integración [#integration]

Registre los productos anfitrión e hijo y sus interfaces en la misma instancia Univer; añada Embed y Embed UI. El ejemplo inserta una Sheet existente en un Doc; `hostDocument` y `budgetWorkbook` son sus Facades.

```ts
import '@univerjs-pro/embed/facade'

const block = univerAPI.createEmbed({
  host: {
    unitId: hostDocument.getId(),
    surface: univerAPI.Enum.FEmbedHostSurface.DocBlock,
  },
  content: {
    unitType: univerAPI.Enum.UniverInstanceType.UNIVER_SHEET,
    ref: `#unit=${encodeURIComponent(budgetWorkbook.getId())}&type=sheet`,
  },
})

const embeddedWorkbook = await block.loadAsync()
```

`createEmbed()` crea la relación y el anclaje; `loadAsync()` carga la Unit hija y devuelve su Facade. Use `displayTarget` para elegir la hoja, página de Slide o vista de Base inicial. Consulte la [guía de incrustación](/guides/fundamentals/features/embed) para plugins, estilos, idiomas y cargadores, y [Embed Facade](/reference/facade/embed) para otras ubicaciones y métodos.

## Persistencia, colaboración y alcance [#scope]

- **Guardar por separado:** el Snapshot anfitrión conserva referencias, posición y ajustes de visualización; no empaqueta automáticamente el contenido hijo actualizado. Eliminar el bloque no elimina el documento hijo.
- **Carga colaborativa:** Server SDK proporciona los snapshots y servicios de colaboración de la hija. Con `@univerjs-pro/collaboration-embed`, el navegador la carga y se une a su sesión. Ambas Units conservan sus propios cambios y versiones.
- **Acceso y permisos:** la aplicación resuelve referencias, carga datos y autoriza el acceso. Poder acceder al anfitrión no concede automáticamente edición sobre la hija.
- **Alcance actual:** admite tipos distintos de Sheet, Doc, Slide, Base y Board. No incluye PDF, incrustación del mismo tipo ni anidación adicional. En un entorno Univer, cada Unit hija solo puede pertenecer a una incrustación activa.

Use [enlace bidireccional](/docs/features/shared/binding) para controlar entradas, métricas y gráficos propios de su aplicación desde una hoja. Use Embed Block cuando necesite conservar el editor del producto hijo.
