Univer Charts covers **8 categories and 43 features**, all of which it supports in full. No feature is partially supported, and no feature is missing.

[Integration guide](/guides/sheets/features/charts) · [All features](/overview/features)

<Callout title="Comparison scope">
  This page compares the Univer Charts SDK with Microsoft 365 Excel for Windows desktop and Google Sheets, including the official chart APIs. Only chart types are compared; styling, axes, and interaction details are out of scope. Images, cell color scales, and standalone add-ons do not count as built-in charts. Where support is partial, the note states which combinations are available or how the chart is approximated. All previews use demonstration data.
</Callout>

“Open source” marks full support in the open-source edition. An unmarked item may provide only a basic subset, may be available as an optional module, or may require a commercial license. For details, consult the documentation for the corresponding module.
