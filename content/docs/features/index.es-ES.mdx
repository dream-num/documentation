## Navegar por producto [#browse-by-product]

Los seis productos cubren **76 categorías y 405 funciones**. Abra un producto y utilice su índice para encontrar una categoría. Cada producto se muestra junto con productos como Microsoft Office y Google Workspace, incluido soporte, disponibilidad de código abierto, notas de alcance y filtros.

## Capacidades compartidas [#shared-capabilities]

Cada capacidad tiene su propia página que cubre el comportamiento, la integración y los límites del producto. Expanda Capacidades compartidas en la barra lateral para explorar cada entrada.

| Capacidad | Descripción |
| --- | --- |
| [Gráficos](/docs/features/charts) | 8 categorías y 43 tipos de gráficos, en comparación con Microsoft Office y Google Workspace, incluidas las vistas previas. |
| [Importación y exportación de archivos](/docs/features/shared/file-conversion) | Convierta archivos de Office a contenido Univer y exporte los resultados editados. |
| [Headless y cálculo del lado del servidor](/docs/features/shared/server-calculation) | Ejecute operaciones de contenido en Node.js, utilice Rust para el cálculo previo y brinde a los agentes resultados estructurados y visuales. |
| [Colaboración en tiempo real](/docs/features/shared/collaboration) | Sincronice el contenido de los documentos compartidos y la presencia en línea. |
| [Historial de versiones](/docs/features/shared/history) | Realice un seguimiento de los cambios confirmados y explore las versiones de los documentos. |
| [Permisos y autorización](/docs/features/shared/permissions) | Conecte la identidad y autorización de la aplicación para documentar las operaciones. |
| [Comentarios e hilos de revisión](/docs/features/shared/comments) | Ancle las discusiones al contenido, responda y resuelva hilos de revisión. |
| [Worktree](/docs/features/shared/worktree) | Aísle ediciones en borradores, revise cambios y fusione en el documento principal. |
| [Comparación de contenido](/docs/features/shared/compare) | Compare instantáneas de documentos e inspeccione las diferencias de contenido estructurado. |
| [Enlace de datos bidireccional](/docs/features/shared/binding) | Conecte controles web personalizados a datos y cálculos de hojas de cálculo. |
| [Incrustación de documentos cruzados](/docs/features/shared/embed) | Incruste contenido editable Univer dentro de otro producto de Office. |
| [Agentes y automatización](/docs/features/shared/agents) | Exponga las operaciones de contenido de Office como herramientas de agente y comandos componibles. |
| [Inspección visual](/docs/features/shared/visual-inspection) | Presente contenido para su revisión y combine comprobaciones visuales con inspección estructurada. |
| [Complementos y Facade APIs](/docs/features/shared/customization) | Cree productos, amplíe el comportamiento y conecte las API de Office a la aplicación UI. |
| [Temas y localización](/docs/features/shared/themes-and-locales) | Configure los colores del editor, el modo oscuro y los recursos de la interfaz localizados. |

Después de explorar las funciones, regrese a [Descripción de Office SDK](/docs/overview) para elegir su ruta de integración o abra una guía de integración de productos.
