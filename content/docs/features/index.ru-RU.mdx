## Просмотр по продукту [#browse-by-product]

Каталог охватывает шесть продуктов с **76 категорий и 405 функций** в общей сложности. Каждая страница продукта сравнивает поддержку продукта с такими продуктами, как Microsoft Office и Google Workspace. Можно фильтровать по категориям, по статусу с открытым исходным кодом или по различиям между продуктами, что сужает результаты до требуемой функции.

| [Импорт и экспорт файлов](/overview/features/shared/file-conversion) | Преобразуйте файлы Office в контент Univer, а затем экспортируйте отредактированный результат. |

| [Сотрудничество в режиме реального времени](/overview/features/shared/collaboration) | Синхронизируйте содержимое общего документа и присутствие в Интернете. |
| [История версий](/overview/features/shared/history) | Отслеживайте подтвержденные изменения и просматривайте более ранние версии документа. |

| [Worktree](/overview/features/shared/worktree) | Храните правки в изолированном проекте, просматривайте изменения и объединяйте их в основной документ. |
| [Сравнение контента](/overview/features/shared/compare) | Сравните снимки документов и проверьте различия в структурированном контенте. |
| [Двусторонняя привязка данных](/overview/features/shared/binding) | Подключайте пользовательские веб-элементы управления к данным и расчетам электронных таблиц. |
| [Встраивание между документами](/overview/features/shared/embed) | Встраивайте редактируемый контент Univer в другой продукт Office. |
| [Агенты и автоматизация](/overview/features/shared/agents) | Операции с контентом в офисе как инструменты, которые агент может вызывать, и как композитные команды. |
| [Визуальный осмотр](/overview/features/shared/visual-inspection) | Отображайте контент для просмотра и сочетайте визуальные проверки со структурированной проверкой. |
| [Плагины и Facade APIs](/overview/features/shared/customization) | Составляйте продукты, расширяйте поведение и подключайте Office API к пользовательскому интерфейсу вашего приложения. |
| [Темы и локализация](/overview/features/shared/themes-and-locales) | Настройте цвета редактора, темный режим и ресурсы локализованного интерфейса. |

После определения требуемых функций вернитесь в [Обзор Office SDK](/overview), чтобы выбрать путь интеграции, или откройте руководство по интеграции для конкретного продукта.
