## Просмотр по продукту [#browse-by-product]

Каждый продукт показан рядом с такими продуктами, как Microsoft Office и Google Workspace, включая поддержку, доступность открытого исходного кода, примечания по объему и фильтры.

## Общие возможности [#shared-capabilities]

У каждой возможности есть своя страница, описывающая поведение, интеграцию и границы продукта. Разверните «Общие возможности» на боковой панели, чтобы просмотреть каждую запись.

| Возможность | Описание |
| --- | --- |
| [Графики](/docs/features/charts) | 8 категорий и 43 типа диаграмм по сравнению с Microsoft Office и Google Workspace, включая предварительный просмотр. |
| [Импорт и экспорт файлов](/docs/features/shared/file-conversion) | Преобразуйте файлы Office в содержимое Univer и экспортируйте отредактированные результаты. |
| [Headless и расчет на стороне сервера](/docs/features/shared/server-calculation) | Выполняйте операции с контентом в Node.js, используйте Rust для предварительных вычислений и предоставляйте агентам структурированные и наглядные результаты. |
| [Сотрудничество в режиме реального времени](/docs/features/shared/collaboration) | Синхронизируйте содержимое общего документа и присутствие в Интернете. |
| [История версий](/docs/features/shared/history) | Отслеживайте подтвержденные изменения и просматривайте версии документов. |
| [Разрешения и авторизация](/docs/features/shared/permissions) | Подключите идентификацию и авторизацию приложения к операциям с документами. |
| [Комментарии и обзоры тем](/docs/features/shared/comments) | Привязывайте обсуждения к контенту, отвечайте и решайте темы отзывов. |
| [Worktree](/docs/features/shared/worktree) | Изолируйте изменения в черновиках, просматривайте изменения и объединяйте их с основным документом. |
| [Сравнение контента](/docs/features/shared/compare) | Сравните снимки документов и проверьте различия в структурированном контенте. |
| [Двусторонняя привязка данных](/docs/features/shared/binding) | Подключайте пользовательские веб-элементы управления к данным и расчетам электронных таблиц. |
| [Встраивание между документами](/docs/features/shared/embed) | Встраивайте редактируемый контент Univer в другой продукт Office. |
| [Агенты и автоматизация](/docs/features/shared/agents) | Предоставляйте операции с содержимым Office в виде инструментов агента и составных команд. |
| [Визуальный осмотр](/docs/features/shared/visual-inspection) | Отображайте контент для просмотра и сочетайте визуальные проверки со структурированной проверкой. |
| [Плагины и Facade APIs](/docs/features/shared/customization) | Создавайте продукты, расширяйте возможности и подключайте API Office к приложению UI. |
| [Темы и локализация](/docs/features/shared/themes-and-locales) | Настройте цвета редактора, темный режим и ресурсы локализованного интерфейса. |

После изучения функций вернитесь к [Обзор Office SDK](/docs/overview), чтобы выбрать путь интеграции, или откройте руководство по интеграции продукта.
