<Callout title="比較スコープ">
  比較は、AirtableとFeishu Baseを有料クラウド製品として扱い、Univerは、Office SDKとオプションのモジュールとして機能します。各製品の非AI機能のみが含まれ、外部製品とアドオンは除外されます。外部エージェントはAPIを呼び出して、データを準備、同期、およびインポートすることができます。その場合、条件は、機能ごとに通知され、組み込みの自動化オーケストレーションから明確に保ちます。エントリポイント、スケジューリング、および許可は、各アプリケーションが機能と別々に記述されていない機能です。
</Callout>
