## 跨产品能力

每项能力都有独立说明页，列出能力范围、接入方式与产品边界。侧栏的“跨产品能力”可展开查看全部入口。

| 能力 | 说明 |
| --- | --- |
| [图表](/docs/features/charts) | 8 个分类、43 种图表，与 Microsoft Office、Google Workspace 并列对比并保留示例。 |
| [文件导入与导出](/docs/features/shared/file-conversion) | 将 Office 文件转换为 Univer 内容，并将编辑结果导出为交付文件。 |
| [无头与服务端计算](/docs/features/shared/server-calculation) | 在 Node.js 中读写内容，结合 Rust 预计算与数组展开，为应用和 Agent 提供结构化与视觉结果。 |
| [实时协同](/docs/features/shared/collaboration) | 同步共享文档内容与在线用户状态。 |
| [历史记录](/docs/features/shared/history) | 记录已确认的修改，并查看文档历史版本。 |
| [权限与授权](/docs/features/shared/permissions) | 将业务身份与权限策略接入文档读写、协同和审阅操作。 |
| [评论与审阅讨论](/docs/features/shared/comments) | 将讨论定位到内容，支持回复与解决审阅线程。 |
| [Worktree](/docs/features/shared/worktree) | 在隔离草稿中编辑，审阅修改后合入主文档。 |
| [内容比较](/docs/features/shared/compare) | 比较文档快照，查看内容与样式的结构化差异。 |
| [双向绑定](/docs/features/shared/binding) | 将自定义 Web 控件与表格数据及计算规则连接起来。 |
| [跨文档嵌入（Embed block）](/docs/features/shared/embed) | 将可编辑的 Univer 内容嵌入另一种 Office 产品。 |
| [Agent 与自动化](/docs/features/shared/agents) | 将 Office 内容操作封装为 Agent 工具与可组合命令。 |
| [截图与视觉检查](/docs/features/shared/visual-inspection) | 渲染内容供审阅，并结合结构化检查验证结果。 |
| [插件与 Facade 扩展](/docs/features/shared/customization) | 按需组合产品、扩展行为，并将 Office API 接入业务界面。 |
| [主题与国际化](/docs/features/shared/themes-and-locales) | 配置编辑器配色、暗色模式与多语言界面资源。 |

浏览功能后，可返回 [Office SDK 总览](/docs/overview)选择接入方式，或直接打开产品接入指南。
