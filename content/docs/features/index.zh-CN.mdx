## 按产品浏览

功能目录涵盖六个产品，共 **76 个分类、405 项功能**，每个产品各有一个页面。产品页将支持情况与 Microsoft Office、Google Workspace 等产品逐项对比。你可以按分类、是否开源或产品之间的差异筛选，直接定位所需功能。

## 跨产品能力

| 能力 | 说明 |
| --- | --- |
| [图表](/overview/features/charts) | 8 个分类、43 种图表，每种图表都提供预览，并与 Microsoft Office、Google Workspace 逐项对比。 |
| [文件导入与导出](/overview/features/shared/file-conversion) | 将 Office 文件转换为 Univer 内容，编辑完成后再导出结果。 |
| [无头与服务端计算](/overview/features/shared/server-calculation) | 在 Node.js 中执行内容操作，用 Rust 完成预计算与数组展开，再把结构化和视觉结果提供给应用和 Agent。 |
| [实时协同](/overview/features/shared/collaboration) | 同步共享文档的内容与在线用户状态。 |
| [历史记录](/overview/features/shared/history) | 记录已确认的修改，并可浏览文档的历史版本。 |
| [权限与授权](/overview/features/shared/permissions) | 将业务身份与权限策略接入文档读写、协同与审阅操作。 |
| [评论与审阅讨论](/overview/features/shared/comments) | 将讨论关联到具体内容，可回复，也可将讨论标记为已解决。 |
| [Worktree](/overview/features/shared/worktree) | 在隔离草稿中编辑，审阅修改后再合入主文档。 |
| [内容比较](/overview/features/shared/compare) | 比较文档快照，以结构化形式查看内容与样式的差异。 |
| [双向绑定](/overview/features/shared/binding) | 将自定义 Web 控件接入表格数据与计算规则。 |
| [跨文档嵌入（Embed block）](/overview/features/shared/embed) | 将可编辑的 Univer 内容嵌入另一种 Office 产品。 |
| [Agent 与自动化](/overview/features/shared/agents) | 将 Office 内容操作封装为 Agent 可调用的工具与可组合的命令。 |
| [截图与视觉检查](/overview/features/shared/visual-inspection) | 渲染内容供审阅，并将视觉检查与结构化检查结合使用。 |
| [插件与 Facade 扩展](/overview/features/shared/customization) | 按需组合产品、扩展行为，并将 Office API 接入业务界面。 |
| [主题与国际化](/overview/features/shared/themes-and-locales) | 配置编辑器配色、暗色模式与多语言界面资源。 |

找到所需功能后，返回 [Office SDK 总览](/overview)，选择接入路径，或者打开对应产品的接入指南。
