[Руководство по интеграции](/guides/sheets/features/charts) · [Все функции](/overview/features)

<Callout title="Объем сопоставления">
  Эта страница сравнивает Univer Charts SDK с Microsoft 365 Excel для настольных компьютеров Windows и Google Sheets, включая официальные API-интерфейсы диаграмм. Сопоставляются только типы диаграмм; стилистика, топоры и детали взаимодействия выходят за рамки. Изображения, цветовые шкалы ячеек и автономные надстройки не считаются встроенными диаграммами. Где поддержка частичная, в примечании указывается, какие комбинации доступны или как приближена диаграмма. Все предварительные просмотры используют демонстрационные данные.
</Callout>

"Открытый источник" означает полную поддержку в издании с открытым исходным кодом. Немаркированный элемент может предоставлять только базовое подмножество, может быть доступен в качестве дополнительного модуля или может требовать коммерческой лицензии.
