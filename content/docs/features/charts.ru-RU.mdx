<Callout title="Область сравнения">
  Сравнивается Univer Charts SDK с Microsoft 365 Excel для рабочего стола Windows и Google Sheets, включая официальные API диаграмм. Сравниваются только типы диаграмм, исключая стиль, оси и детали взаимодействия. Изображения, цветовые шкалы ячеек и независимые надстройки не считаются встроенными диаграммами. Частичная поддержка отмечает доступные комбинации или приближения. Во всех превью используются демонстрационные данные.
</Callout>

«Открытый исходный код» означает полную поддержку в версии с открытым исходным кодом. Немаркированные элементы могут включать базовые подмножества, дополнительные модули или коммерческое лицензирование; обратитесь к документации соответствующего модуля.
