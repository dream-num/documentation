<Callout title="Portée de la comparaison">
  Cette page compare les graphiques Univer SDK avec Microsoft 365 Excel pour le bureau de Windows et les feuilles Google, y compris les API de graphique officiel. Seuls les types de graphiques sont comparés; le style, les axes et les détails d'interaction sont hors de portée. Les images, les échelles de couleurs cellulaires et les add-ons autonomes ne comptent pas comme des graphiques intégrés. Lorsque le support est partiel, la note indique quelles combinaisons sont disponibles ou comment le graphique est approximatif.
</Callout>
