**製品名：** キャンバスという名前は `Board` SDK および API で。

[統合ガイド](/guides/boards) · [すべての機能](/overview/features)

<Callout title="比較範囲">
  Univer には、完全な Office SDK とオプションのモジュールが含まれています。 Miro は、プラン固有の可用性を持つ有料クラウド プランを使用します。 Excalidraw とは、Plus を除く、無料のオープンソース アプリケーションおよび Excalidraw.com を意味します。コラボレーション、履歴、変換には、対応するモジュールとサービスが必要です。 Univer 製品間のネイティブ埋め込みは、必要なモジュールを記載した上で、関連する機能にカウントされます。外部アプリによって提供される編集/計算は、キャンバスネイティブの機能ではありません。製品自体の非 AI 機能のみが含まれています。個別の外部製品やアドオンは除外されます。
</Callout>

「オープンソース」は、オープンソース版での完全なサポートを示します。マークのない項目には、基本サブセット、オプションのモジュール、または商用ライセンスが含まれる場合があります。対応するモジュールのドキュメントを参照してください。
