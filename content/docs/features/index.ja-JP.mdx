## 共有機能 [#shared-capabilities]

| 能力 | 説明 |
| --- | --- |
| [チャート](/overview/features/charts) | Microsoft Office および Google Workspace と比較した 8 カテゴリと 43 のグラフ タイプ (プレビューを含む)。 |
| [ファイルのインポートとエクスポート](/overview/features/shared/file-conversion) | Office ファイルを Univer コンテンツに変換し、編集結果をエクスポートします。 |
| [Headless とサーバー側の計算](/overview/features/shared/server-calculation) | Node.js でコンテンツ操作を実行し、事前計算に Rust を使用して、エージェントに構造化された視覚的な結果を提供します。 |
| [リアルタイムのコラボレーション](/overview/features/shared/collaboration) | 共有ドキュメントのコンテンツとオンライン プレゼンスを同期します。 |
| [バージョン履歴](/overview/features/shared/history) | 確認された変更を追跡し、ドキュメントのバージョンを参照します。 |
| [許可と認可](/overview/features/shared/permissions) | アプリケーションの ID と認可をドキュメント操作に結び付けます。 |
| [コメントとレビューのスレッド](/overview/features/shared/comments) | ディスカッションをコンテンツに固定し、返信し、レビュー スレッドを解決します。 |
| [Worktree](/overview/features/shared/worktree) | 下書き内の編集を分離し、変更を確認して、メイン文書にマージします。 |
| [内容比較](/overview/features/shared/compare) | ドキュメントのスナップショットを比較し、構造化されたコンテンツの違いを検査します。 |
| [双方向のデータバインディング](/overview/features/shared/binding) | カスタム Web コントロールをスプレッドシートのデータと計算に接続します。 |
| [クロスドキュメント埋め込み](/overview/features/shared/embed) | 編集可能な Univer コンテンツを別の Office 製品内に埋め込みます。 |
| [エージェントと自動化](/overview/features/shared/agents) | Office コンテンツの操作をエージェント ツールおよび構成可能なコマンドとして公開します。 |
| [目視検査](/overview/features/shared/visual-inspection) | レビュー用にコンテンツをレンダリングし、視覚的なチェックと構造化された検査を組み合わせます。 |
| [プラグインとFacade APIs](/overview/features/shared/customization) | 製品を構成し、動作を拡張し、Office API をアプリケーション UI に接続します。 |
| [テーマとローカリゼーション](/overview/features/shared/themes-and-locales) | エディターの色、ダーク モード、およびローカライズされたインターフェイス リソースを構成します。 |

機能を調べた後、[Office SDK の概要](/overview) に戻って統合パスを選択するか、製品統合ガイドを開きます。
