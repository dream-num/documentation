**製品名:** [リレーショナルテーブル](/docs/features/relational-table) は、SDK および API では `Base` という名前です。 [キャンバス](/docs/features/canvas) は `Board` という名前になります。

## 製品別に見る [#browse-by-product]

6つの製品がカバーするのは、 **76のカテゴリと405の機能**。製品を開き、その目次を使用してカテゴリを見つけます。各製品は、サポート、オープンソースの可用性、スコープノート、フィルターを含め、Microsoft Office や Google Workspace などの製品と並べて表示されます。

## 共有機能 [#shared-capabilities]

各機能には、動作、統合、製品の境界をカバーする独自のページがあります。サイドバーの共有機能を展開して、すべてのエントリを参照します。

| 能力 | 説明 |
| --- | --- |
| [チャート](/docs/features/charts) | Microsoft Office および Google Workspace と比較した 8 カテゴリと 43 のグラフ タイプ (プレビューを含む)。 |
| [ファイルのインポートとエクスポート](/docs/features/shared/file-conversion) | Office ファイルを Univer コンテンツに変換し、編集結果をエクスポートします。 |
| [Headless とサーバー側の計算](/docs/features/shared/server-calculation) | Node.js でコンテンツ操作を実行し、事前計算に Rust を使用して、エージェントに構造化された視覚的な結果を提供します。 |
| [リアルタイムのコラボレーション](/docs/features/shared/collaboration) | 共有ドキュメントのコンテンツとオンライン プレゼンスを同期します。 |
| [バージョン履歴](/docs/features/shared/history) | 確認された変更を追跡し、ドキュメントのバージョンを参照します。 |
| [許可と認可](/docs/features/shared/permissions) | アプリケーションの ID と認可をドキュメント操作に結び付けます。 |
| [コメントとレビューのスレッド](/docs/features/shared/comments) | ディスカッションをコンテンツに固定し、返信し、レビュー スレッドを解決します。 |
| [Worktree](/docs/features/shared/worktree) | 下書き内の編集を分離し、変更を確認して、メイン文書にマージします。 |
| [内容比較](/docs/features/shared/compare) | ドキュメントのスナップショットを比較し、構造化されたコンテンツの違いを検査します。 |
| [双方向のデータバインディング](/docs/features/shared/binding) | カスタム Web コントロールをスプレッドシートのデータと計算に接続します。 |
| [クロスドキュメント埋め込み](/docs/features/shared/embed) | 編集可能な Univer コンテンツを別の Office 製品内に埋め込みます。 |
| [エージェントと自動化](/docs/features/shared/agents) | Office コンテンツの操作をエージェント ツールおよび構成可能なコマンドとして公開します。 |
| [目視検査](/docs/features/shared/visual-inspection) | レビュー用にコンテンツをレンダリングし、視覚的なチェックと構造化された検査を組み合わせます。 |
| [プラグインとFacade APIs](/docs/features/shared/customization) | 製品を構成し、動作を拡張し、Office API をアプリケーション UI に接続します。 |
| [テーマとローカリゼーション](/docs/features/shared/themes-and-locales) | エディターの色、ダーク モード、およびローカライズされたインターフェイス リソースを構成します。 |

機能を調べた後、[Office SDK の概要](/docs/overview) に戻って統合パスを選択するか、製品統合ガイドを開きます。
