## 製品別に見る [#browse-by-product]

カタログは、**76のカテゴリと405の機能**で6つの製品をカバーしています。各製品ページは、Microsoft OfficeやGoogle Workspaceなどの製品に対する製品のサポートを比較します。カテゴリ、オープンソースのステータス、または製品の違いによってフィルタリングできます。これにより、必要な機能に結果が狭くなります。

## 共有機能 [#shared-capabilities]

| 能力 | 説明 |
| --- | --- |
| [チャート](/overview/features/charts) | Microsoft Office と Google のワークスペースと比較して、8 のカテゴリと 43 のグラフタイプ、それぞれプレビュー付き。 |
| [ファイルのインポートとエクスポート](/overview/features/shared/file-conversion) | Office ファイルを Univer コンテンツに変換し、編集した結果をエクスポートします。 |
| [Headless とサーバー側の計算](/overview/features/shared/server-calculation) | Node.js でコンテンツ操作を実行し、Rust とプリコンプトし、構造化された視覚的な結果を持つエージェントを提供します。 |
| [リアルタイムのコラボレーション](/overview/features/shared/collaboration) | 共有ドキュメントのコンテンツとオンライン プレゼンスを同期します。 |
| [バージョン履歴](/overview/features/shared/history) | 確認された変更を追跡し、文書の以前のバージョンを閲覧します。 |
| [許可と認可](/overview/features/shared/permissions) | アプリケーションのアイデンティティと権限をドキュメント操作に接続します。 |
| [コメントとレビューのスレッド](/overview/features/shared/comments) | 特定のコンテンツに対する議論をアンカーし、スレッド内で応答し、スレッドを解決します。 |
| [Worktree](/overview/features/shared/worktree) | 分離された草案で編集し、変更を見直し、それらを主要な文書にマージして下さい。 |
| [内容比較](/overview/features/shared/compare) | ドキュメントのスナップショットを比較し、構造化されたコンテンツとしての違いを調べます。 |
| [双方向のデータバインディング](/overview/features/shared/binding) | カスタム Web コントロールをスプレッドシートのデータと計算に接続します。 |
| [クロスドキュメント埋め込み](/overview/features/shared/embed) | 編集可能な Univer コンテンツを別の Office 製品内に埋め込みます。 |
| [エージェントと自動化](/overview/features/shared/agents) | エージェントがコールできるツールとしてOfficeのコンテンツ操作を露光し、コマンドを合成できるツールとして機能します。 |
| [目視検査](/overview/features/shared/visual-inspection) | レビュー用にコンテンツをレンダリングし、視覚的なチェックと構造化された検査を組み合わせます。 |
| [プラグインとFacade APIs](/overview/features/shared/customization) | 製品をコンパイルし、動作を拡張し、Office API をアプリケーションの UI に接続します。 |
| [テーマとローカリゼーション](/overview/features/shared/themes-and-locales) | エディターの色、ダーク モード、およびローカライズされたインターフェイス リソースを構成します。 |

必要な機能を識別した後、[オフィスSDKの概要](/overview)に戻り、統合パスを選択するか、特定の製品に統合ガイドを開きます。
