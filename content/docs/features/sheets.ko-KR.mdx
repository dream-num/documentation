  Windows 데스크톱용 Microsoft 365 Excel을 웹 기반 Google Sheets와 비교합니다. Univer에는 전체 Office SDK 및 선택적 모듈이 포함되어 있습니다. 각 제품 자체의 AI가 아닌 기능만 포함됩니다. 외부/비즈니스 데이터 소스, 별도의 외부 제품, Add-On은 제외됩니다.
