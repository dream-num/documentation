## 공유 기능 [#shared-capabilities]

| 능력 | 설명 |
| --- | --- |
| [차트](/overview/features/charts) | 미리보기를 포함하여 Microsoft Office 및 Google Workspace와 비교한 8개 범주 및 43개 차트 유형입니다. |
| [파일 가져오기 및 내보내기](/overview/features/shared/file-conversion) | Office 파일을 Univer 콘텐츠로 변환하고 편집된 결과를 내보냅니다. |
| [Headless 및 서버측 계산](/overview/features/shared/server-calculation) | Node.js에서 콘텐츠 작업을 실행하고, Rust를 사전 계산에 사용하고, 에이전트에 구조화된 시각적 결과를 제공하세요. |
| [실시간 협업](/overview/features/shared/collaboration) | 공유 문서 콘텐츠와 온라인 활동을 동기화하세요. |
| [버전 기록](/overview/features/shared/history) | 확인된 변경 사항을 추적하고 문서 버전을 찾아보세요. |
| [권한 및 승인](/overview/features/shared/permissions) | 애플리케이션 ID와 인증을 문서 작업에 연결합니다. |
| [댓글 및 리뷰 스레드](/overview/features/shared/comments) | 토론을 콘텐츠에 고정하고, 답변하고, 검토 스레드를 해결하세요. |
| [Worktree](/overview/features/shared/worktree) | 초안에서 편집 내용을 분리하고, 변경 사항을 검토하고, 기본 문서에 병합합니다. |
| [내용 비교](/overview/features/shared/compare) | 문서 스냅샷을 비교하고 구조화된 콘텐츠의 차이점을 검사합니다. |
| [양방향 데이터 바인딩](/overview/features/shared/binding) | 사용자 정의 웹 컨트롤을 스프레드시트 데이터 및 계산에 연결합니다. |
| [문서 간 삽입](/overview/features/shared/embed) | 편집 가능한 Univer 콘텐츠를 다른 Office 제품에 포함하세요. |
| [에이전트 및 자동화](/overview/features/shared/agents) | Office 콘텐츠 작업을 에이전트 도구 및 구성 가능한 명령으로 노출합니다. |
| [육안검사](/overview/features/shared/visual-inspection) | 검토할 콘텐츠를 렌더링하고 시각적 검사와 구조화된 검사를 결합합니다. |
| [플러그인 및 Facade APIs](/overview/features/shared/customization) | 제품을 구성하고, 동작을 확장하고, Office API를 애플리케이션 UI에 연결하세요. |
| [테마 및 현지화](/overview/features/shared/themes-and-locales) | 편집기 색상, 어두운 모드, 현지화된 인터페이스 리소스를 구성합니다. |

기능을 탐색한 후 [Office SDK 개요](/overview)로 돌아가 통합 경로를 선택하거나 제품 통합 가이드를 엽니다.
