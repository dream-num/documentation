  Compare Microsoft 365 Excel pour ordinateur de bureau Windows avec Google Sheets basé sur le Web. Univer comprend l'Office SDK complet et des modules optionnels. Seules les fonctionnalités non AI de chaque produit lui-même sont incluses ; Les sources de données externes/professionnelles, les produits externes distincts et les modules complémentaires sont exclus. JavaScript, VBA et Apps Script fournissent l'automatisation, mais Univer et Google Sheets n'importent/exportent pas le code et les projets VBA. Les exigences en matière de plan, de plate-forme et d'intégration sont indiquées par fonctionnalité.
