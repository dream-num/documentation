<Callout title="Comparison scope">
  The reference products are Microsoft 365 PowerPoint for Windows desktop and Google Slides on the web. The Univer column assumes the complete Office SDK with the optional modules. Editor features and PPTX round-trip compatibility are compared separately, and each entry records the API, template, browser-rendering, or service requirements that apply. The comparison covers only each product's own non-AI capabilities; standalone external products and add-ons are excluded.
</Callout>

"Open source" marks a feature that is fully supported in the open-source edition. An item without the mark may be a basic subset, an optional module, or a feature that requires a commercial license. The documentation for the relevant module describes the details.
