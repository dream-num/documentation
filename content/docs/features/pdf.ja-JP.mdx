<Callout title="比較範囲">
  Acrobat Pro と Foxit PDF Editor の有料デスクトップ版を比較します。Foxit の高度な機能は、Pro または該当するライセンス版を対象とします。Univer には Office SDK 全体と追加モジュールを含め、SDK API と UI の対応範囲を機能ごとに示します。文字・画像の編集可否は PDF の構造に依存します。外部 Agent と OCR・スキャン・圧縮ツールの連携は個別に記載しています。これらのツールは利用者が別途用意する必要があり、Univer の組み込み機能ではありません。生成 AI は比較対象に含めず、従来型 OCR は比較範囲に含めます。一部対応の項目では、対応範囲を説明します。
</Callout>

「オープンソース」は、オープンソース版での完全なサポートを示します。マークのない項目には、基本サブセット、オプションのモジュール、または商用ライセンスが含まれる場合があります。対応するモジュールのドキュメントを参照してください。
