## Univer Slides 是什么

Univer Slides 是 Univer Pro 中的演示文稿产品能力。它用于构建幻灯片编辑器、播放视图、导入导出流程，以及基于 Univer runtime 的服务端幻灯片处理能力。

Slides 是独立的 Univer unit type。运行时需要创建 `UniverInstanceType.UNIVER_SLIDE` unit，然后按需注册 Pro 侧的模型、UI 和可选功能插件。

<Callout type="info">
  Univer Slides 现在位于 `@univerjs-pro` 包作用域下。集成前请先阅读 [Univer Pro](/guides/pro) 中的授权和部署说明。
</Callout>

## 包含能力

- 幻灯片数据模型、页面顺序、母版、版式、占位符、形状、图片和 drawing 集成
- 浏览器编辑器 UI，包括缩略图、画布编辑、插入工具、右键菜单和播放能力
- 可选的表格、图表元素集成
- 面向 Pro 部署的打印与导入导出能力
- 用于创建演示文稿和操作幻灯片内容的 Facade API

## 安装包

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
pnpm add @univerjs-pro/slides-print @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui @univerjs-pro/slides-exchange-client
```
