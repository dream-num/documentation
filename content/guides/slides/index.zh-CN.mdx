## Univer Slides 是什么

Univer Slides 是 Univer Office SDK 中的演示文稿产品。它可以用于构建幻灯片编辑器、演示文稿查看器和导入导出流程，也可以通过 Web SDK runtime 在服务端处理幻灯片。

Slides 运行在 [Web SDK](/guides/sheets) 之上，由它提供浏览器端编辑器和服务器端无界面处理能力。[Server SDK](/server) 提供协同与文件交换，[AI SDK](/ai) 负责 Agent 工作流。

Slides 是独立的 Web SDK unit type。运行时先创建类型为 `UniverInstanceType.UNIVER_SLIDE` 的 unit，再注册与所需能力对应的模型、UI 和可选功能插件。

<Callout type="info">
  Univer Slides 位于 `@univerjs-pro` 包作用域下。需要授权的功能需配置[客户端许可证](/server/license)。当应用需要协同或文件转换时，再接入 [Univer Server SDK](/server)。
</Callout>

## 浏览器兼容性

Web SDK 的编译目标是 Chrome 88，但仅凭编译目标无法保证覆盖所有主流环境。Web SDK 计划支持以下浏览器和 Node.js 版本：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK 依赖 `Intl.Segmenter`。如果浏览器或运行时环境不支持该 API，请先补充对应的 polyfill。推荐使用 `@formatjs/intl-segmenter`。
</Callout>

遇到兼容性问题时，请先应用对应的 polyfill。如果问题仍未解决，可以[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 兼容性

<Callout type="warning">
  本节只涉及直接在 Node.js 中运行 Web SDK 的情况。使用基于 Node.js 的构建工具将 Web SDK 打包到浏览器运行的场景不在此列。
</Callout>

Web SDK 支持在 Node.js v18.17.0 及之后的版本中运行。

## 主要功能

- 演示文稿模型负责管理演示文稿标识、页面尺寸、幻灯片顺序、幻灯片、母版页、版式页、主题、切换效果和资源。
- 渲染与编辑涵盖幻灯片画布、缩略图、选区、剪贴板、文本与形状编辑、对齐参考线和放映。
- 页面和元素的改动通过命令和变更生效，模型更新、渲染以及撤销重做保持同步。
- Facade API 通过面向应用的对象创建和查找演示文稿、保存快照，并对外提供幻灯片和元素操作。
- 表格、图表、打印、导入导出等可选功能独立于核心插件栈。

## 前置知识

这套文档面向初次接触的读者，但假定读者具备一定基础，以便把内容集中在 Web SDK 上。读者应了解 JavaScript 及其生态；如果计划在 Node.js 上运行 Web SDK，具备 Node.js 基础知识也会有所帮助。

需要多人共同编辑幻灯片，或者需要共享历史、评论和文件转换时，请把 [Univer Server SDK](/server) 中的对应模块接入后端。身份认证、权限、存储和部署仍由应用负责。仅在浏览器中编辑时，不需要这些服务。
