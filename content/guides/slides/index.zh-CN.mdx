## Univer Slides 是什么

Univer Slides 是 Univer SDK Pro 中的演示文稿产品能力。它用于构建幻灯片编辑器、播放视图、导入导出流程，以及基于 Univer SDK runtime 的服务端幻灯片处理能力。

Slides 是独立的 Univer SDK unit type。运行时需要创建 `UniverInstanceType.UNIVER_SLIDE` unit，然后按需注册 Pro 侧的模型、UI 和可选功能插件。

<Callout type="info">
  Univer Slides 现在位于 `@univerjs-pro` 包作用域下。集成前请先阅读 [Univer SDK Pro](/guides/pro) 中的授权和部署说明。
</Callout>


## 浏览器兼容性

Univer SDK 的编译目标是 Chrome 88，但这并不意味着 Univer SDK 能够完全支持所有主流环境。我们会尽力确保 Univer SDK 在以下浏览器和 Node.js 环境中能够正常运行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK 依赖 `Intl.Segmenter`，如果你的浏览器或运行时环境暂不支持它，请先补充对应的 polyfill。我们推荐使用
  `@formatjs/intl-segmenter`。
</Callout>

如果遇到无法兼容的情况，请先借助对应的 polyfill 来解决，如果仍然无法解决，请[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 兼容性

<Callout type="warning">
  以下仅适用于在 Node.js 环境中运行 Univer SDK 的情况，并不适用于那些基于 Node.js 使用构建工具在浏览器中运行 Univer SDK 的情况。
</Callout>

Univer SDK 可以在 Node.js 环境中运行，支持的版本为 v18.17.0 及之后的版本。

## 主要功能

- **演示文稿模型**：管理演示文稿标识、页面尺寸、幻灯片顺序、幻灯片、母版页、版式页、主题、切换效果和资源。
- **渲染与编辑**：提供幻灯片画布、缩略图、选择、剪贴板、文本与形状编辑、对齐参考线和放映能力。
- **命令管线**：通过命令和变更应用页面与元素更新，使模型、渲染以及撤销和重做保持同步。
- **Facade API**：通过面向应用的对象创建和查找演示文稿、保存快照，并操作幻灯片和元素。
- **插件架构**：表格、图表、打印和导入导出等可选功能与核心插件栈相互独立。
