## ISlideData

`ISlideData` は Univer Slides が使用するスナップショット形式です。プレゼンテーション unit の ID、タイトル、ページサイズ、スライドページ、マスターやレイアウトなどの再利用可能な参照ページを表します。

### プロパティ

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| id | `string` | Univer Slides unit の一意な ID。 |
| locale? | `LocaleType` | プレゼンテーションのロケール。 |
| title | `string` | プレゼンテーションのタイトル。 |
| pageSize | `ISize` | スライドで使用する既定のページサイズ。 |
| body? | `ISlidePageBody` | スライドページとその順序。 |
| master? | `{ [id: string]: ISlidePage }` | スライドとレイアウトで共有されるマスターページ。 |
| layouts? | `{ [id: string]: ISlidePage }` | 通常のスライドが参照するレイアウトページ。 |
| handoutMaster? | `{ [id: string]: ISlidePage }` | 配布資料マスターページ。 |
| notesMaster? | `{ [id: string]: ISlidePage }` | ノートマスターページ。 |
| lists? | `ILists` | リッチテキスト要素で使用するリスト定義。 |

### Body

`body.pages` はページ ID ごとにスライドページを保存し、`body.pageOrder` は表示順を保存します。スナップショットを手動で構築する場合は、両方を同期させてください。

```typescript
const slideData: ISlideData = {
  id: 'deck-1',
  title: 'Product roadmap',
  pageSize: { width: 960, height: 540 },
  body: {
    pageOrder: ['slide-1'],
    pages: {
      'slide-1': {
        id: 'slide-1',
        pageType: PageType.SLIDE,
        zIndex: 10,
        title: 'Opening',
        description: '',
        pageBackgroundFill: { rgb: 'rgb(255,255,255)' },
        pageElements: {},
      },
    },
  },
}
```

### 使用シーン

`ISlideData` は主に以下に使用します：

1. `UniverInstanceType.UNIVER_SLIDE` unit の作成。
2. プレゼンテーションスナップショットの永続化または復元。
3. インポート、エクスポート、印刷、サーバー側処理のためのデータ準備。
4. `SlideDataModel` が利用するソーススナップショット。

<Callout type="warning">
  スナップショットは永続化用のデータ構造です。プレゼンテーションの実行後は、スナップショットオブジェクトを直接変更せず、Facade API を使用してください。
</Callout>
