## ISlideData

`ISlideData` — формат снимка, используемый в Univer Slides. Он описывает одну презентацию, включая её идентификатор, название, размер страницы, слайды и повторно используемые страницы, на которые ссылается презентация, например образцы и макеты.

### Свойства

| Свойство | Тип | Описание |
| --- | --- | --- |
| id | `string` | Уникальный идентификатор презентации Univer Slides. |
| locale? | `LocaleType` | Локаль презентации. |
| title | `string` | Название презентации. |
| pageSize | `ISize` | Размер страницы по умолчанию для слайдов презентации. |
| body? | `ISlidePageBody` | Слайды и порядок их следования. |
| master? | `{ [id: string]: ISlidePage }` | Страницы образцов, общие для слайдов и макетов. |
| layouts? | `{ [id: string]: ISlidePage }` | Страницы макетов, на которые ссылаются обычные слайды. |
| handoutMaster? | `{ [id: string]: ISlidePage }` | Страницы образцов выдач. |
| notesMaster? | `{ [id: string]: ISlidePage }` | Страницы образцов заметок. |
| lists? | `ILists` | Определения списков, используемые элементами форматированного текста. |

### Тело презентации

`body.pages` хранит слайды по идентификаторам страниц, а `body.pageOrder` — порядок их отображения. При создании снимка поддерживайте эти данные в согласованном состоянии.

```typescript
const slideData: ISlideData = {
  id: 'deck-1',
  title: 'Product roadmap',
  pageSize: { width: 960, height: 540 },
  body: {
    pageOrder: ['slide-1'],
    pages: {
      'slide-1': {
        id: 'slide-1',
        pageType: PageType.SLIDE,
        zIndex: 10,
        title: 'Opening',
        description: '',
        pageBackgroundFill: { rgb: 'rgb(255,255,255)' },
        pageElements: {},
      },
    },
  },
}
```

### Использование

`ISlideData` в основном используется для следующих задач:

1. Создание презентации типа `UniverInstanceType.UNIVER_SLIDE`.
2. Сохранение и восстановление снимка презентации.
3. Подготовка данных для импорта, экспорта, печати или обработки на стороне сервера.
4. Предоставление исходного снимка для `SlideDataModel`.

<Callout type="warning">
  Объекты снимков предназначены для постоянного хранения данных. После запуска презентации используйте Facade API вместо непосредственного изменения объекта снимка.
</Callout>
