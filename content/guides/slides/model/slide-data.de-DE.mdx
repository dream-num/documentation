## ISlideData

`ISlideData` ist das von Univer Slides verwendete Snapshot-Format. Es beschreibt eine Präsentationseinheit, einschließlich der Präsentations-ID, des Titels, der Seitengröße, der Folienseiten und wiederverwendbarer Referenzseiten wie Master und Layouts.

### Eigenschaften

| Eigenschaft | Typ | Beschreibung |
| --- | --- | --- |
| id | `string` | Eindeutige ID der Univer Slides-Einheit. |
| locale? | `LocaleType` | Ort der Präsentation. |
| title | `string` | Präsentationstitel. |
| pageSize | `ISize` | Standardseitengröße, die von Folien in der Präsentation verwendet wird. |
| body? | `ISlidePageBody` | Folienseiten und ihre Reihenfolge. |
| master? | `{ [id: string]: ISlidePage }` | Von Folien und Layouts gemeinsam genutzte Masterseiten. |
| layouts? | `{ [id: string]: ISlidePage }` | Layoutseiten, auf die von normalen Folien verwiesen wird. |
| handoutMaster? | `{ [id: string]: ISlidePage }` | Handout-Masterseiten. |
| notesMaster? | `{ [id: string]: ISlidePage }` | Notizen-Masterseiten. |
| lists? | `ILists` | Von Rich-Text-Elementen verwendete Definitionen auflisten. |

### Körper

`body.pages` speichert Folienseiten nach Seiten-ID, während `body.pageOrder` die sichtbare Reihenfolge speichert. Halten Sie beide beim Erstellen eines Snapshots synchron.

```typescript
const slideData: ISlideData = {
  id: 'deck-1',
  title: 'Product roadmap',
  pageSize: { width: 960, height: 540 },
  body: {
    pageOrder: ['slide-1'],
    pages: {
      'slide-1': {
        id: 'slide-1',
        pageType: PageType.SLIDE,
        zIndex: 10,
        title: 'Opening',
        description: '',
        pageBackgroundFill: { rgb: 'rgb(255,255,255)' },
        pageElements: {},
      },
    },
  },
}
```

### Verwendung

`ISlideData` wird hauptsächlich verwendet, um:

1. eine `UniverInstanceType.UNIVER_SLIDE`-Einheit zu erstellen.
2. einen Präsentations-Snapshot beizubehalten oder wiederherzustellen.
3. Daten für den Import, Export, Druck oder die serverseitige Verarbeitung vorzubereiten.
4. Bereitstellen des Quell-Snapshots verbraucht von `SlideDataModel`.

<Callout type="warning">
Snapshot-Objekte sind Persistenzdaten. Nachdem die Präsentation ausgeführt wurde, bevorzugen Sie Facade-APIs, anstatt das Snapshot-Objekt direkt zu ändern.
</Callout>
