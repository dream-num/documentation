## ISlideData

`ISlideData` es el formato de instantánea utilizado por Univer Slides. Describe una unidad de presentación, incluida la identificación de la presentación, el título, el tamaño de la página, las páginas de diapositivas y las páginas de referencia reutilizables, como patrones y diseños.

### Propiedades

| Propiedad | Tipo | Descripción |
| --- | --- | --- |
| id | `string` | Identificación única de la unidad Univer Slides. |
| locale? | `LocaleType` | Configuración regional de la presentación. |
| title | `string` | Título de la presentación. |
| pageSize | `ISize` | Tamaño de página predeterminado utilizado por las diapositivas en la presentación. |
| body? | `ISlidePageBody` | Páginas de diapositivas y sus orden. |
| master? | `{ [id: string]: ISlidePage }` | Páginas maestras compartidas por diapositivas y diseños. |
| layouts? | `{ [id: string]: ISlidePage }` | Páginas de diseño a las que hacen referencia las diapositivas normales. |
| handoutMaster? | `{ [id: string]: ISlidePage }` | Páginas maestras de folletos. |
| notesMaster? | `{ [id: string]: ISlidePage }` | Páginas maestras de notas. |
| lists? | `ILists` | Definiciones de listas utilizadas por elementos de texto enriquecido. |

### Cuerpo

`body.pages` almacena las páginas de diapositivas por identificación de página, mientras que `body.pageOrder` almacena el orden visible. Mantenga ambos sincronizados al crear una instantánea.

```typescript
const slideData: ISlideData = {
  id: 'deck-1',
  title: 'Product roadmap',
  pageSize: { width: 960, height: 540 },
  body: {
    pageOrder: ['slide-1'],
    pages: {
      'slide-1': {
        id: 'slide-1',
        pageType: PageType.SLIDE,
        zIndex: 10,
        title: 'Opening',
        description: '',
        pageBackgroundFill: { rgb: 'rgb(255,255,255)' },
        pageElements: {},
      },
    },
  },
}
```

### Uso

`ISlideData` se utiliza principalmente para:

1. Crear una unidad `UniverInstanceType.UNIVER_SLIDE`.
2. Conservar o restaurar una instantánea de presentación.
3. Preparar datos para importar, exportar, imprimir o procesar en el lado del servidor.
4. Proporcionar la instantánea de origen consumida por `SlideDataModel`.

<Callout type="warning">
Los objetos de instantánea son datos de persistencia. Después de ejecutar la presentación, prefiera las API de Facade en lugar de mutar el objeto de instantánea directamente.
</Callout>
