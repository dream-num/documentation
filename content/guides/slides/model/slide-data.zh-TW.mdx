## ISlideData

`ISlideData` 是 Univer Slides 使用的快照格式。它描述一個簡報 unit，包括簡報 ID、標題、頁面尺寸、投影片頁面，以及母片和版面配置等可重用引用頁面。

### 屬性

| 屬性 | 類型 | 描述 |
| --- | --- | --- |
| id | `string` | Univer Slides unit 的唯一 ID。 |
| locale? | `LocaleType` | 簡報語言環境。 |
| title | `string` | 簡報標題。 |
| pageSize | `ISize` | 簡報中投影片使用的預設頁面尺寸。 |
| body? | `ISlidePageBody` | 投影片頁面和頁面順序。 |
| master? | `{ [id: string]: ISlidePage }` | 被投影片和版面配置重用的母片頁面。 |
| layouts? | `{ [id: string]: ISlidePage }` | 普通投影片引用的版面配置頁面。 |
| handoutMaster? | `{ [id: string]: ISlidePage }` | 講義母片頁面。 |
| notesMaster? | `{ [id: string]: ISlidePage }` | 備註母片頁面。 |
| lists? | `ILists` | 富文字元素使用的清單定義。 |

### Body

`body.pages` 按頁面 ID 儲存投影片頁面，`body.pageOrder` 儲存可見頁面順序。手動建構快照時需要保持兩者一致。

```typescript
const slideData: ISlideData = {
  id: 'deck-1',
  title: '產品路線圖',
  pageSize: { width: 960, height: 540 },
  body: {
    pageOrder: ['slide-1'],
    pages: {
      'slide-1': {
        id: 'slide-1',
        pageType: PageType.SLIDE,
        zIndex: 10,
        title: '開場頁',
        description: '',
        pageBackgroundFill: { rgb: 'rgb(255,255,255)' },
        pageElements: {},
      },
    },
  },
}
```

### 使用場景

`ISlideData` 主要用於：

1. 建立 `UniverInstanceType.UNIVER_SLIDE` unit。
2. 持久化或還原簡報快照。
3. 為匯入、匯出、列印或服務端處理準備資料。
4. 作為 `SlideDataModel` 消費的來源快照。

<Callout type="warning">
  快照是用於持久化的資料結構。簡報運行後，優先透過 Facade API 修改內容，不要直接修改快照物件。
</Callout>
