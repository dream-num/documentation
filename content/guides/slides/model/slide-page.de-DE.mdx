## ISlidePage

`ISlidePage` beschreibt ein einzelnes seitenartiges Objekt in Univer Slides. Normale Folien, Master, Layouts, Handout-Master und Notizmaster verwenden alle diese Struktur und unterscheiden sich durch `pageType` und ihren optionalen Eigenschaftsblock.

### Seiteneigenschaften

| Eigenschaft | Typ | Beschreibung |
| --- | --- | --- |
| id | `string` | Eindeutige Seiten-ID. |
| pageType | `PageType` | Seitentyp, z. B `SLIDE`, `MASTER` oder `LAYOUT`. |
| zIndex | `number` | Renderreihenfolge der Seite. |
| title | `string` | Seitentitel. |
| description | `string` | Seitenbeschreibung. |
| pageBackgroundFill | `IColorStyle` | Seitenhintergrundfüllung. |
| colorScheme? | `ThemeColorType` | Themenfarbschema, das von der Seite verwendet wird. |
| pageElements | `{ [elementId: string]: IPageElement }` | Elemente auf dieser Seite, codiert nach Element-ID. |
| slideProperties? | `ISlideProperties` | Eigenschaften für normale Folienseiten. |
| layoutProperties? | `ILayoutProperties` | Eigenschaften für Layoutseiten. |
| masterProperties? | `IMasterProperties` | Eigenschaften für Masterseiten. |

## IPageElement

`IPageElement` ist der gemeinsame Elementcontainer. Jedes Element verfügt über Transformationsfelder wie `left`, `top`, `width`, `height`, `angle`, `scaleX`, `scaleY`, `flipX` und `flipY` sowie eine von `type` ausgewählte Inhaltsnutzlast.

| Elementtyp | Nutzlast | Beschreibung |
| --- | --- | --- |
| `PageElementType.SHAPE` | `shape` | Voreingestellte oder benutzerdefinierte Form, einschließlich Formtext und Formeigenschaften. |
| `PageElementType.IMAGE` | `image` | Bildeigenschaften und optionale Platzhalter-/Link-Metadaten. |
| `PageElementType.TEXT` | `richText` | Rich-Text-Element. Das Feld `rich` kann `IDocumentData` speichern. |
| `PageElementType.SPREADSHEET` | `spreadsheet` | Veraltete Nutzlast für eingebettete Arbeitsblätter. |
| `PageElementType.DOCUMENT` | `document` | Veraltete Nutzlast für eingebettete Dokumente. |
| `PageElementType.SLIDE` | `slide` | Veraltete Nutzlast für eingebettete Folien. |

### Beispiel

```typescript
const page: ISlidePage = {
  id: 'slide-1',
  pageType: PageType.SLIDE,
  zIndex: 10,
  title: 'Agenda',
  description: '',
  pageBackgroundFill: { rgb: 'rgb(255,255,255)' },
  pageElements: {
    title: {
      id: 'title',
      zIndex: 1,
      left: 72,
      top: 64,
      width: 600,
      height: 80,
      title: 'Title',
      description: '',
      type: PageElementType.TEXT,
      richText: {
        text: 'Quarterly Review',
      },
    },
  },
}
```

### Notizen

- `pageOrder` steuert die Reihenfolge der sichtbaren Folien; `zIndex` steuert die Zeichnungsreihenfolge.
- Textelemente können einfache `text` oder umfangreichere Dokumentdaten über `richText.rich` speichern.
- Verwenden Sie `customBlock` für Plugin-eigene Elementnutzlasten, anstatt veraltete eingebettete Nutzlasten zu überlasten.
