## ISlideData

`ISlideData`는 Univer Slides에서 사용하는 스냅샷 형식입니다. 프레젠테이션 ID, 제목, 페이지 크기, 슬라이드 페이지, 마스터와 레이아웃 같은 재사용 가능한 참조 페이지를 포함하는 하나의 프레젠테이션 단위를 설명합니다.

### 속성

| 속성 | 타입 | 설명 |
| --- | --- | --- |
| id | `string` | Univer Slides 단위의 고유 ID입니다. |
| locale? | `LocaleType` | 프레젠테이션의 로케일입니다. |
| title | `string` | 프레젠테이션 제목입니다. |
| pageSize | `ISize` | 프레젠테이션의 슬라이드에서 사용하는 기본 페이지 크기입니다. |
| body? | `ISlidePageBody` | 슬라이드 페이지와 그 순서입니다. |
| master? | `{ [id: string]: ISlidePage }` | 슬라이드와 레이아웃에서 공유하는 마스터 페이지입니다. |
| layouts? | `{ [id: string]: ISlidePage }` | 일반 슬라이드에서 참조하는 레이아웃 페이지입니다. |
| handoutMaster? | `{ [id: string]: ISlidePage }` | 유인물 마스터 페이지입니다. |
| notesMaster? | `{ [id: string]: ISlidePage }` | 노트 마스터 페이지입니다. |
| lists? | `ILists` | 서식 있는 텍스트 요소에서 사용하는 목록 정의입니다. |

### Body

`body.pages`는 페이지 ID별로 슬라이드 페이지를 저장하고, `body.pageOrder`는 표시 순서를 저장합니다. 스냅샷을 구성할 때 두 항목을 일치시켜야 합니다.

```typescript
const slideData: ISlideData = {
  id: 'deck-1',
  title: 'Product roadmap',
  pageSize: { width: 960, height: 540 },
  body: {
    pageOrder: ['slide-1'],
    pages: {
      'slide-1': {
        id: 'slide-1',
        pageType: PageType.SLIDE,
        zIndex: 10,
        title: 'Opening',
        description: '',
        pageBackgroundFill: { rgb: 'rgb(255,255,255)' },
        pageElements: {},
      },
    },
  },
}
```

### 용도

`ISlideData`는 주로 다음 용도로 사용합니다.

1. `UniverInstanceType.UNIVER_SLIDE` 단위를 생성합니다.
2. 프레젠테이션 스냅샷을 영구 저장하거나 복원합니다.
3. 가져오기, 내보내기, 인쇄 또는 서버 측 처리에 사용할 데이터를 준비합니다.
4. `SlideDataModel`에서 사용하는 원본 스냅샷을 제공합니다.

<Callout type="warning">
  스냅샷 객체는 영속성 데이터입니다. 프레젠테이션이 실행된 후에는 스냅샷 객체를 직접 변경하지 말고 Facade API를 사용하는 것이 좋습니다.
</Callout>
