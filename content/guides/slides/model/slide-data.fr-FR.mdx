## ISlideData

`ISlideData` est le format d’instantané utilisé par Univer Slides. Il décrit une unité de présentation, notamment son identifiant, son titre, la taille de ses pages, ses diapositives et ses pages de référence réutilisables, telles que les masques et les dispositions.

### Propriétés

| Propriété | Type | Description |
| --- | --- | --- |
| id | `string` | Identifiant unique de l’unité Univer Slides. |
| locale? | `LocaleType` | Paramètres régionaux de la présentation. |
| title | `string` | Titre de la présentation. |
| pageSize | `ISize` | Taille de page par défaut des diapositives de la présentation. |
| body? | `ISlidePageBody` | Diapositives et ordre dans lequel elles apparaissent. |
| master? | `{ [id: string]: ISlidePage }` | Masques partagés par les diapositives et les dispositions. |
| layouts? | `{ [id: string]: ISlidePage }` | Dispositions référencées par les diapositives standard. |
| handoutMaster? | `{ [id: string]: ISlidePage }` | Masques des documents à distribuer. |
| notesMaster? | `{ [id: string]: ISlidePage }` | Masques des pages de notes. |
| lists? | `ILists` | Définitions de listes utilisées par les éléments de texte enrichi. |

### Corps

`body.pages` stocke les diapositives par identifiant de page, tandis que `body.pageOrder` enregistre leur ordre d’affichage. Veillez à maintenir ces deux propriétés synchronisées lorsque vous créez un instantané.

```typescript
const slideData: ISlideData = {
  id: 'deck-1',
  title: 'Product roadmap',
  pageSize: { width: 960, height: 540 },
  body: {
    pageOrder: ['slide-1'],
    pages: {
      'slide-1': {
        id: 'slide-1',
        pageType: PageType.SLIDE,
        zIndex: 10,
        title: 'Opening',
        description: '',
        pageBackgroundFill: { rgb: 'rgb(255,255,255)' },
        pageElements: {},
      },
    },
  },
}
```

### Utilisation

`ISlideData` sert principalement à :

1. Créer une unité `UniverInstanceType.UNIVER_SLIDE`.
2. Enregistrer ou restaurer l’instantané d’une présentation.
3. Préparer des données pour l’importation, l’exportation, l’impression ou le traitement côté serveur.
4. Fournir l’instantané source utilisé par `SlideDataModel`.

<Callout type="warning">
  Les objets d’instantané sont des données persistantes. Une fois la présentation en cours d’exécution, utilisez de préférence les API Facade plutôt que de modifier directement l’objet d’instantané.
</Callout>
