## ISlideData

`ISlideData` is the snapshot format used by Univer Slides. It describes one presentation unit, including the presentation id, title, page size, slide pages, and reusable reference pages such as masters and layouts.

### Properties

| Property | Type | Description |
| --- | --- | --- |
| id | `string` | Unique id of the Univer Slides unit. |
| locale? | `LocaleType` | Locale of the presentation. |
| title | `string` | Presentation title. |
| pageSize | `ISize` | Default page size used by slides in the presentation. |
| body? | `ISlidePageBody` | Slide pages and their order. |
| master? | `{ [id: string]: ISlidePage }` | Master pages shared by slides and layouts. |
| layouts? | `{ [id: string]: ISlidePage }` | Layout pages referenced by normal slides. |
| handoutMaster? | `{ [id: string]: ISlidePage }` | Handout master pages. |
| notesMaster? | `{ [id: string]: ISlidePage }` | Notes master pages. |
| lists? | `ILists` | List definitions used by rich-text elements. |

### Body

`body.pages` stores slide pages by page id, while `body.pageOrder` stores the visible order. Keep both in sync when constructing a snapshot.

```typescript
const slideData: ISlideData = {
  id: 'deck-1',
  title: 'Product roadmap',
  pageSize: { width: 960, height: 540 },
  body: {
    pageOrder: ['slide-1'],
    pages: {
      'slide-1': {
        id: 'slide-1',
        pageType: PageType.SLIDE,
        zIndex: 10,
        title: 'Opening',
        description: '',
        pageBackgroundFill: { rgb: 'rgb(255,255,255)' },
        pageElements: {},
      },
    },
  },
}
```

### Usage

`ISlideData` is mainly used to:

1. Create a `UniverInstanceType.UNIVER_SLIDE` unit.
2. Persist or restore a presentation snapshot.
3. Prepare data for import, export, print, or server-side processing.
4. Provide the source snapshot consumed by `SlideDataModel`.

<Callout type="warning">
  Snapshot objects are persistence data. After the presentation is running, prefer Facade APIs instead of mutating the snapshot object directly.
</Callout>
