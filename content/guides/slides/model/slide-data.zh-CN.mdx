## ISlideData

`ISlideData` 是 Univer Slides 使用的快照格式。它描述一个演示文稿 unit，包括演示文稿 ID、标题、页面尺寸、幻灯片页面，以及母版和版式等可复用引用页面。

### 属性

| 属性 | 类型 | 描述 |
| --- | --- | --- |
| id | `string` | Univer Slides unit 的唯一 ID。 |
| locale? | `LocaleType` | 演示文稿语言环境。 |
| title | `string` | 演示文稿标题。 |
| pageSize | `ISize` | 演示文稿中幻灯片使用的默认页面尺寸。 |
| body? | `ISlidePageBody` | 幻灯片页面和页面顺序。 |
| master? | `{ [id: string]: ISlidePage }` | 被幻灯片和版式复用的母版页面。 |
| layouts? | `{ [id: string]: ISlidePage }` | 普通幻灯片引用的版式页面。 |
| handoutMaster? | `{ [id: string]: ISlidePage }` | 讲义母版页面。 |
| notesMaster? | `{ [id: string]: ISlidePage }` | 备注母版页面。 |
| lists? | `ILists` | 富文本元素使用的列表定义。 |

### Body

`body.pages` 按页面 ID 存储幻灯片页面，`body.pageOrder` 存储可见页面顺序。手动构造快照时需要保持两者一致。

```typescript
const slideData: ISlideData = {
  id: 'deck-1',
  title: '产品路线图',
  pageSize: { width: 960, height: 540 },
  body: {
    pageOrder: ['slide-1'],
    pages: {
      'slide-1': {
        id: 'slide-1',
        pageType: PageType.SLIDE,
        zIndex: 10,
        title: '开场页',
        description: '',
        pageBackgroundFill: { rgb: 'rgb(255,255,255)' },
        pageElements: {},
      },
    },
  },
}
```

### 使用场景

`ISlideData` 主要用于：

1. 创建 `UniverInstanceType.UNIVER_SLIDE` unit。
2. 持久化或恢复演示文稿快照。
3. 为导入、导出、打印或服务端处理准备数据。
4. 作为 `SlideDataModel` 消费的源快照。

<Callout type="warning">
  快照是用于持久化的数据结构。演示文稿运行后，优先通过 Facade API 修改内容，不要直接修改快照对象。
</Callout>
