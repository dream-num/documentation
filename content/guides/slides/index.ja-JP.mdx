## Univer Slides とは

Univer Slides は Univer Pro のプレゼンテーション製品です。Univer runtime の上で、スライドデッキエディター、プレゼンテーションビューアー、インポート/エクスポートフロー、サーバーサイドのスライド処理を構築するために使います。

Slides は独立した Univer unit type です。実行時には `UniverInstanceType.UNIVER_SLIDE` unit を作成し、必要な機能に合わせて Pro 側のモデル、UI、任意の機能プラグインを登録します。

<Callout type="info">
  Univer Slides は現在 `@univerjs-pro` package scope で提供されています。アプリケーションへ組み込む前に、ライセンスとデプロイ要件について [Univer Pro](/guides/pro) を確認してください。
</Callout>

## 含まれる機能

- スライドデータモデル、ページ順序、マスター、レイアウト、プレースホルダー、図形、画像、drawing 連携
- サムネイル、キャンバス編集、挿入ツール、コンテキストメニュー、プレゼンテーション再生のためのブラウザー編集 UI
- スライド要素として使う表とグラフの任意連携
- Pro デプロイ向けの印刷、インポート/エクスポート連携
- プレゼンテーションの作成やスライド内容の操作に使う Facade API

## パッケージのインストール

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
pnpm add @univerjs-pro/slides-print @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui @univerjs-pro/slides-exchange-client
```
