## Univer Slides とは

Univer SlidesはUniver Office SDKのプレゼンテーション製品です。 建物のスライドデッキエディタ、プレゼンテーションビューア、インポートとエクスポートフローをサポートし、Web SDKランタイムを介してサーバー上でスライドを処理できます。

[Web SDK](/guides/sheets) 上で動作するスライドは、ブラウザエディタとヘッドレス処理の両方をサーバー上で提供します。 [Server SDK](/server)はコラボレーションとファイル交換を追加し、[AI SDK](/ai)がエージェントのワークフローをカバーします。

スライドは独立したWeb SDKユニットタイプです。ランタイムでは、`UniverInstanceType.UNIVER_SLIDE`のユニットを作成して、必要な機能に合ったモデル、UI、オプション機能プラグインを登録します。

<Callout type="info">
  Univer Slidesは`@univerjs-pro`パッケージスコープで公開されています。ライセンス機能には[クライアントライセンス](/server/license)が必要です。アプリケーションがコラボレーションやファイル変換を必要とするときに[Univer Server SDK](/server)を追加します。
</Callout>

## ブラウザ互換性

Web SDKはChrome 88ターゲットとコンパイルしますが、コンパイルだけですべての主流環境のサポートは保証されません。 Web SDK は、以下のブラウザとNode.jsバージョンで動作するように意図されています。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDKは`Intl.Segmenter`に依存しています。ブラウザやランタイム環境がサポートされていない場合は、最初に一致するポリフィルを追加します。 `@formatjs/intl-segmenter`をお勧めします。
</Callout>

互換性の問題が発生した場合は、まずマッチングポリフィルを適用します。問題が主張している場合は、[問題を開く](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 互換性

<Callout type="warning">
  Node.jsで直接Web SDKを実行しているだけをカバーしています。 Node.jsベースのビルドツールがブラウザ用のWeb SDKをバンドルしたときには適用されません。
</Callout>

Web SDKはNode.js v18.17.0以降で動作します。

## 主な機能

- プレゼンテーションモデルは、プレゼンテーションのアイデンティティ、ページサイズ、スライドオーダー、スライド、マスターページ、レイアウトページ、テーマ、移行、リソースを追跡します。
- レンダリングおよび編集はスライドのキャンバス、サムネイル、選択、クリップボード、テキストおよび形の編集、直線ガイドおよびプレーバックをカバーします。
- ページと要素の変更は、モデルの更新、レンダリング、および undo および redo の同期を保ち、コマンドとミューテーションを経由します。
- Facade APIは、プレゼンテーションの作成と発見、スナップショットの保存、およびアプリケーション面のオブジェクトを介してスライドと要素の操作を公開します。
- テーブル、チャート、印刷、インポート/エクスポートなどのオプション機能がコアスタックの外にとどまります。

## ドキュメントの読み方

サイドバーは、基本から上級までのページをリストします。そのため、アプリケーションを構築したり、任意の順序でそれらを読み、使用例に適用するページをスキップしたりすることができます。 Univerスライドを含む製品間のサイドバースイッチのトップ。

現在のページのセクション間で右上のコンテンツの表を移動します。ページをすばやく見つけるには、検索バーをトップまたは検索ショートカット(Ctrl + KまたはCmd + K)で使用してください。

[クイックスタート](/guides/slides/getting-started/installation) ガイドを読んでください。
