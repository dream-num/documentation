## Univer Slides とは

Univer Slides は Univer Pro のプレゼンテーション製品です。Univer runtime の上で、スライドデッキエディター、プレゼンテーションビューアー、インポート/エクスポートフロー、サーバーサイドのスライド処理を構築するために使います。

Slides は独立した Univer unit type です。実行時には `UniverInstanceType.UNIVER_SLIDE` unit を作成し、必要な機能に合わせて Pro 側のモデル、UI、任意の機能プラグインを登録します。

<Callout type="info">
  Univer Slides は現在 `@univerjs-pro` package scope
  で提供されています。アプリケーションへ組み込む前に、ライセンスとデプロイ要件について [Univer Pro](/guides/pro)
  を確認してください。
</Callout>


## ブラウザ互換性

Univer は Chrome 88 をターゲットとしてコンパイルされていますが、これはすべての主流環境を完全にサポートすることを保証するものではありません。Univer が以下のブラウザおよび Node.js 環境で問題なく動作するよう努めています。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer は `Intl.Segmenter`
  に依存しています。お使いのブラウザまたはランタイム環境でこれがサポートされていない場合は、先に対応するポリフィルを追加してください。`@formatjs/intl-segmenter`
  の利用を推奨します。
</Callout>

互換性に関する問題が発生した場合、まずは適切なポリフィルを使用して解決を試みてください。それでも問題が解決しない場合は、[Issue の提出](https://github.com/dream-num/univer/issues/new/choose) をご検討ください。

## Node.js 互換性

<Callout type="注意事項">
  注意：これは Univer を Node.js 環境で実行する場合にのみ適用され、Node.js
  ベースのビルドツールを使ってブラウザで実行する場合には該当しません。
</Callout>

Univer は Node.js 環境でも動作可能で、v18.17.0 以降のバージョンをサポートしています。


## 含まれる機能

- スライドデータモデル、ページ順序、マスター、レイアウト、プレースホルダー、図形、画像、drawing 連携
- サムネイル、キャンバス編集、挿入ツール、コンテキストメニュー、プレゼンテーション再生のためのブラウザー編集 UI
- スライド要素として使う表とグラフの任意連携
- Pro デプロイ向けの印刷、インポート/エクスポート連携
- プレゼンテーションの作成やスライド内容の操作に使う Facade API

## パッケージのインストール

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
pnpm add @univerjs-pro/slides-print @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui @univerjs-pro/slides-exchange-client
```
