## Univer Slides とは

Univer Slides は Univer Office SDK のプレゼンテーション製品です。Web SDK runtime の上で、スライドデッキエディター、プレゼンテーションビューアー、インポート/エクスポートフロー、サーバーサイドのスライド処理を構築するために使います。

Univer Office SDK は、埋め込みエディターとヘッドレスのコンテンツ処理を提供する [Web SDK](/guides/sheets)、共同編集とファイルのインポート・エクスポートを提供する [Server SDK](/server)、エージェントのワークフローを提供する [AI SDK](/ai) で構成されます。

Slides は独立した Web SDK unit type です。実行時には `UniverInstanceType.UNIVER_SLIDE` unit を作成し、必要な機能に合わせて 側のモデル、UI、任意の機能プラグインを登録します。

<Callout type="info">
  Univer Slides は `@univerjs-pro` パッケージで提供されます。ライセンスが必要な機能には[クライアントライセンス](/server/license)を設定し、共同編集やファイル変換が必要な場合は [Univer Server SDK](/server) を組み込みます。
</Callout>


## ブラウザ互換性

Web SDK は Chrome 88 をターゲットとしてコンパイルされていますが、これはすべての主流環境を完全にサポートすることを保証するものではありません。Web SDK が以下のブラウザおよび Node.js 環境で問題なく動作するよう努めています。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK は `Intl.Segmenter`
  に依存しています。お使いのブラウザまたはランタイム環境でこれがサポートされていない場合は、先に対応するポリフィルを追加してください。`@formatjs/intl-segmenter`
  の利用を推奨します。
</Callout>

互換性に関する問題が発生した場合、まずは適切なポリフィルを使用して解決を試みてください。それでも問題が解決しない場合は、[Issue の提出](https://github.com/dream-num/univer/issues/new/choose) をご検討ください。

## Node.js 互換性

<Callout type="注意事項">
  注意：これは Web SDK を Node.js 環境で実行する場合にのみ適用され、Node.js
  ベースのビルドツールを使ってブラウザで実行する場合には該当しません。
</Callout>

Web SDK は Node.js 環境でも動作可能で、v18.17.0 以降のバージョンをサポートしています。

## 主な機能

- **プレゼンテーションモデル**：プレゼンテーション ID、ページサイズ、スライド順、スライド、マスター、レイアウト、テーマ、トランジション、リソースを管理します。
- **描画と編集**：スライドキャンバス、サムネイル、選択、クリップボード、テキストと図形の編集、配置ガイド、スライドショーを提供します。
- **コマンドパイプライン**：ページと要素の変更をコマンドとミューテーションで適用し、モデル、描画、元に戻す／やり直しを同期します。
- **Facade API**：アプリケーション向けオブジェクトからプレゼンテーションの作成、検索、保存と、スライドや要素の操作を行えます。
- **プラグイン構成**：表、グラフ、印刷、インポート／エクスポートなどの任意機能をコア構成から分離します。

## ドキュメントの読み方

画面左側にドキュメントのナビゲーションがあります。ページは基礎から応用へ順に構成されているため、その順で進めてもよいですし、必要な章だけを選んで読むこともできます。サイドバー上部で Univer Slides のドキュメントに切り替えることもできます。

画面右側には現在ページの目次が表示されます。目的のページを素早く見つけたい場合は、上部の検索バーや検索ショートカット（Ctrl+K または Cmd+K）を利用してください。

まずは [クイックスタート](/guides/slides/getting-started/installation) から始めることをおすすめします。

## 前提知識

ドキュメントは初心者にも分かりやすく設計していますが、Web SDK に集中できるよう、読み始める前にいくつかの基礎知識があることを前提としています。

効率よく理解するために、JavaScript とそのエコシステムの基本的な理解をおすすめします。

Node.js 上で Web SDK を動かしたい場合は、Node.js の基礎知識も必要です。

共同編集、共有履歴やコメント、ファイル変換が必要な場合は、[Univer Server SDK](/server) の必要なモジュールをアプリのバックエンドに組み込みます。認証、権限、ストレージ、デプロイはアプリ側で用意します。ブラウザー内の編集だけなら、これらのサービスは不要です。
