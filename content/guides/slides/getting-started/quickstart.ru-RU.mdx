Перед установкой слайдов Univer просмотрите четыре концепции, которые формируют каждую интеграцию слайда:

- Плагин
- Снимок и модель данных
- Команда
- Facade API

## Основные понятия [#basic-concepts]

### Плагины

Univer Slides собирается из плагинов. `UniverSlidesPlugin` регистрирует модель презентации `UNIVER_SLIDE` и ее основные команды, а `UniverSlidesUIPlugin` предоставляет пользовательский интерфейс редактора браузера. Пакеты для печати, таблиц, диаграмм или импорта и экспорта являются необязательными и добавляются только тогда, когда приложение требует их.

UI Slides использует службы Docs, Drawing и Shape внутри для редактирования текста и графики.Эти службы являются техническими зависимостями стека плагинов Slides, и предварительный опыт работы с другим продуктом Univer не требуется.

### Снимок и модель данных

Представление сохраняется в виде одного [Скриншоты `ISlideData`](/guides/slides/model/slide-data). `name` и `defaultPageSize` описывают представление, `slideOrder` определяет порядок записей в `slides`, а дополнительные слои многоразового использования хранятся в `masterPages` и `layoutPages`.

Используйте `presentation.save()` для чтения текущего снимка. Снимок - это данные о стойкости, а не модель времени выполнения, поэтому изменение объекта снимка после начала презентации не обновляет редактор.

### Команда

Изменения времени выполнения применяются через команды. Команда сохраняет проверку модели, просматривает обновления, а также отменяет и переделывает в одном конвейере изменений. Методы Slides Facade подготавливают параметры команды и выполняют команды.

<Callout type="warning" title="Осторожно">
  Не изменяйте снимок запущенной презентации напрямую. Используйте методы Slides Facade или зарегистрированные команды.
</Callout>

### Facade API

Импорт `@univerjs-pro/slides/facade` после базовой записи Facade для добавления API Slides в `FUniver`. Эта запись предоставляет такие методы, как `createPresentation()`, `getActivePresentation()` и `getPresentation()` .

Полная настройка и примеры приведены в разделе [Использование Slides Facade API](/guides/slides/getting-started/facade).

Далее следует [Установка и базовое использование](/guides/slides/getting-started/installation).
