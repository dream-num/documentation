Перед установкой Univer Slides познакомьтесь с четырьмя понятиями, на которых строится любая интеграция Slides:

- Плагин
- Снимок и модель данных
- Команда
- Facade API

## Основные понятия [#basic-concepts]

### Плагины

Univer Slides собирается из плагинов. `UniverSlidesPlugin` регистрирует модель презентации `UNIVER_SLIDE` и основные команды, а `UniverSlidesUIPlugin` добавляет интерфейс редактора в браузере. Подключайте дополнительные пакеты для печати, таблиц, диаграмм, импорта и экспорта только при необходимости.

Интерфейс Slides использует внутри сервисы Docs, Drawing и Shape для редактирования текста и графики. Это технические зависимости стека Slides; опыт работы с другими продуктами Univer не требуется.

### Снимок и модель данных

Каждая презентация сохраняется как [снимок `ISlideData`](/guides/slides/model/slide-data). `name` и `defaultPageSize` описывают презентацию, `slideOrder` задаёт порядок записей в `slides`, а необязательные переиспользуемые слои хранятся в `masterPages` и `layoutPages`.

Текущий снимок возвращает `presentation.save()`. Снимок предназначен для хранения, а не является активной моделью: его изменение после запуска презентации не обновляет редактор.

### Команда

Изменения во время работы выполняются командами. Благодаря этому проверка модели, обновление представления, отмена и повтор проходят через единый поток изменений. Методы Facade для Slides подготавливают параметры и выполняют эти команды.

<Callout type="warning" title="Внимание">
  Не изменяйте снимок запущенной презентации напрямую. Используйте методы Slides Facade или зарегистрированные команды.
</Callout>

### Facade API

Импортируйте `@univerjs-pro/slides/facade` после основного Facade-входа, чтобы добавить API Slides в `FUniver`. Этот вход предоставляет `createPresentation()`, `getActivePresentation()`, `getPresentation()` и другие методы.

Полная настройка и примеры приведены в разделе [Использование Slides Facade API](/guides/slides/getting-started/facade).

Далее перейдите к разделу [Установка и основы использования](/guides/slides/getting-started/installation).
