---
title: Importar Web SDK a través de CDN
---

El UMD construye las siguientes entradas específicas de diapositivas. Cada URL `@univerjs/*` y `@univerjs-pro/*` debe usar la misma versión.

| Ruta UMD | Espacio de nombres global |
| --- | --- |
| `@univerjs-pro/slides/lib/umd/index.js` | `UniverProSlides` |
| `@univerjs-pro/slides/lib/umd/facade.js` | `UniverProSlidesFacade` |
| `@univerjs-pro/slides/lib/umd/locale/en-US.js` | `UniverProSlidesEnUS` |
| `@univerjs-pro/slides-ui/lib/umd/index.js` | `UniverProSlidesUi` |
| `@univerjs-pro/slides-ui/lib/umd/locale/en-US.js` | `UniverProSlidesUiEnUS` |

Cargar primero las dependencias de pares y el tiempo de ejecución compartido, luego cargar cada paquete dependencia en orden manifiesto. `slides` debe venir antes de `slides-ui`, cada local debe venir después del paquete que lo posee, y `@univerjs/core/facade` más `@univerjs-pro/engine-shape/facade` deben venir antes de la entrada de Diapositivas Facade. UMD no resuelve este gráfico de dependencia automáticamente.

Para ver la lista de paquetes, los estilos, el registro de complementos y la licencia, vuelve a [Instalación y uso básico](/guides/slides/getting-started/installation).
