이 장에서는 Univer Slides의 설치 방법과 기본 사용법을 소개합니다. 이 가이드에서는 Web SDK의 Slides 패키지를 사용합니다. 현재 Slides preset은 제공되지 않으므로 애플리케이션을 plugin mode로 만드세요.

Univer의 핵심 개념에 익숙하지 않다면 먼저 [빠른 시작](/guides/slides/getting-started/quickstart)을 읽어 보세요.

## 플러그인 모드로 설정하기

Univer는 Slides 기능을 플러그인 세트로 제공합니다. 브라우저 편집기에서는 일반적으로 공용 Univer runtime, 라이선스 플러그인, Docs 및 Drawing 의존성을 먼저 등록한 다음 Slides 모델과 UI 플러그인을 등록합니다.

### 패키지 관리자 사용

ES Modules와 `package.json`의 `exports` 필드를 지원하는 빌드 도구를 사용하세요.

#### 설치

Univer는 UI에 React를, 데이터 스트림에 RxJS를 사용하며 Vue나 Angular 앱에도 통합할 수 있습니다. peer dependencies인 `react`, `react-dom`, `rxjs`가 설치되어 있는지 확인하세요. 아래 Yarn 명령에는 이 패키지들이 명시적으로 포함되어 있습니다.

모든 `@univerjs/*` 및 `@univerjs-pro/*` 패키지의 버전을 동일하게 유지하세요.

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/slides @univerjs-pro/slides-ui"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}

#### 사용법

Univer를 초기화하기 전에 컨테이너를 만들고 높이를 명시하세요:

```html
<div id="app" style="height: 600px"></div>
```

`FUniver.newAPI(univer)`를 호출하기 전에 아래 예제에서 사용하는 facade 진입점을 가져오세요. CSS는 `@univerjs/design`, `@univerjs/ui`, 제품 CSS 순서로 가져오세요.

<Callout type="warning" title="주의">
  - Slides 플러그인을 등록하기 전에 `UniverLicensePlugin`을 등록하세요.
  - 공용 UI CSS를 제품 UI CSS보다 먼저 가져오세요.
  - 인쇄, 표, 차트, 가져오기/내보내기 같은 선택적 기능 패키지는 제품에 해당 기능이 필요할 때만 추가하세요.
</Callout>

<Steps>
  <Step>
    스타일, locale pack, 필수 플러그인을 가져옵니다.

    ```typescript
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverSlidesPlugin } from '@univerjs-pro/slides'
    import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
    import SlidesUIEnUS from '@univerjs-pro/slides-ui/locale/en-US'
    import SlidesEnUS from '@univerjs-pro/slides/locale/en-US'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs-pro/slides-ui/lib/index.css'
    ```
  </Step>
  <Step>
    Facade API를 사용하려면 관련 facade 진입점을 가져옵니다.

    ```typescript
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/slides/facade'
    ```
  </Step>
  <Step>
    Univer 인스턴스를 만들고 플러그인을 등록한 다음 Slides unit을 만듭니다.

    ```typescript
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          DocsUIEnUS,
          SlidesEnUS,
          SlidesUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
    })

    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)

    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })

    univer.registerPlugin(UniverSlidesPlugin)
    univer.registerPlugin(UniverSlidesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

`FUniver.newAPI(univer)`가 반환하는 `univerAPI` 객체는 Univer의 Facade API입니다. 이 객체로 프레젠테이션을 만들고 Slides API를 호출할 수 있습니다.

#### `univer.registerPlugin` 및 `univer.registerPlugins` 메서드 [#registerPlugin]

`univer.registerPlugin` 메서드는 Univer 인스턴스에 플러그인을 등록하는 데 사용합니다. Univer 인스턴스를 만든 뒤 이 메서드를 호출하여 플러그인을 등록할 수 있습니다.

`univer.registerPlugin(Plugin, options)` 메서드로 플러그인을 등록할 수 있습니다. 여기서 `Plugin`은 등록할 플러그인이고, `options`는 선택적 구성 항목입니다. 플러그인마다 구성 항목은 다를 수 있습니다.

`univer.registerPlugins`에 배열을 전달하여 여러 플러그인을 한 번에 등록할 수도 있습니다. 플러그인을 중앙에서 관리해야 할 때 유용합니다.

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, {
    container: 'app',
  }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverDrawingPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverSlidesPlugin,
  UniverSlidesUIPlugin,
])
```

#### 선택적 기능 패키지

편집기에 해당 기능이 필요할 때 기능 패키지를 추가합니다.

```shell
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

기능 등록 예제는 [인쇄](/guides/slides/features/print), [표](/guides/slides/features/tables), [차트](/guides/slides/features/charts), [가져오기 및 내보내기](/guides/slides/features/import-export)를 참조하세요.

#### 선택적 플러그인 지연 로드

plugin mode에서는 제품에 실제로 필요할 때까지 기능 플러그인의 로드를 미룰 수 있습니다.

```typescript
univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

import('@univerjs-pro/slides-chart').then(({ UniverSlidesChartPlugin }) => {
  univer.registerPlugin(UniverSlidesChartPlugin)
})
```

### 서버 측 사용법

Node.js에서는 모델 플러그인을 등록하고 브라우저 UI 플러그인은 등록하지 않습니다.

```typescript
univer.registerPlugin(UniverSlidesPlugin)
```

이 구성은 스냅샷 처리, 서버 측 가져오기/내보내기, 협업 서비스에 적합합니다.

## 기타 릴리스

Univer는 안정 릴리스 외에도 alpha / beta 및 nightly 채널을 제공합니다. 이러한 버전에서는 아직 정식 출시되지 않은 최신 기능을 미리 사용할 수 있습니다. 하지만 기능이 많아지는 만큼 위험도 커진다는 점에 유의하세요. 버그, 미완성 기능 또는 불안정한 기능이 포함될 수 있으므로 가능한 한 프로덕션 환경에서는 사용하지 마세요.

### Alpha / Beta 릴리스

Univer 개발팀이 새 기능이나 중요한 변경을 완료하면 alpha 또는 beta 채널에 사전 출시할 수 있습니다. 다음 명령으로 Univer 패키지의 alpha / beta 버전을 설치할 수 있습니다.

```package-install
npm install @univerjs-pro/slides@alpha # Alpha version
npm install @univerjs-pro/slides@beta # Beta version
```

alpha / beta 버전을 사용하면서 문제가 발생하거나 의견이 있다면 [GitHub Issues](https://github.com/dream-num/univer/issues)를 통해 Univer 개발팀에 알려 주세요.

이러한 초기 릴리스에 대한 의견을 환영합니다.
