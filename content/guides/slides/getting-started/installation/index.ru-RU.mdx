title: Установка и основы использования
---

На этой странице описано, как установить Univer Slides и отобразить редактор на странице. В примерах используются пакеты Web SDKSlides. Univer еще не предоставляет предустановленный Slides, поэтому приложение собирается в режиме плагина.

Если вы не знакомы с основными концепциями Univer, сначала прочитайте [Быстрый старт](/guides/slides/getting-started/quickstart).

Univer обеспечивает два режима интеграции: *Preset Mode* и *Plugin Mode*. Preset Mode поставляет предварительно настроенные пакеты плагинов, что удаляет большую часть работы по сборке. Приложения, которым нужен **Глубокая настройка или расширения**, используют режим плагина, в котором каждый плагин выбирается и настраивается индивидуально.

## Настройка в режиме плагинов

Univer распространяет Slides как набор плагинов. Редактор браузера обычно регистрирует совместно используемое время выполнения Univer, плагин лицензии, зависимости от документов и рисования, а затем модель Slides и плагины пользовательского интерфейса.

### Использование менеджера пакетов

Инструмент сборки должен поддерживать модули ES и поле `exports` в `package.json`.

#### Установка

Univer использует React для своего пользовательского интерфейса и RxJS для потоков данных, а также может быть встроен в приложения Vue или Angular.Должна быть установлена зависимость `react`, `react-dom` и `rxjs` одноранговых устройств [^peer-dependency]; команда Yarn ниже включает их явно.

Все пакеты `@univerjs/*` и `@univerjs-pro/*` должны оставаться на **той же версии**.

#### Использование

Создайте контейнер и дайте ему явную высоту перед инициализацией Univer:

```html
<div id="app" style="height: 600px"></div>
```

Импортировать элементы фасада, используемые на следующих этапах, прежде чем звонить `FUniver.newAPI(univer)`. Импортировать `@univerjs/design` CSS сначала, затем `@univerjs/ui` и продукт CSS последним.

<Callout type="warning" title="Внимание">
  - Зарегистрируйте `UniverLicensePlugin` перед любым плагином Slides.
  - Импорт общего пользовательского интерфейса CSS перед продуктом UI CSS.
  - Добавляйте дополнительные пакеты, такие как печать, таблицы, диаграммы и импорт / экспорт только тогда, когда продукт требует их.
  - `UniverSlidesUIPlugin` загружает `UniverProFormulaEnginePlugin` самостоятельно для форм. Если тот же экземпляр `Univer` также регистрирует `UniverFormulaEnginePlugin`, установите `@univerjs-pro/engine-formula` и замените импорт и регистрацию этого двигателя на `UniverProFormulaEnginePlugin` в коде инициализации. Не регистрируйте оба двигателя формулы.
</Callout>

<Steps>
  <Step>
    Импорт таблиц стилей, локальных пакетов и необходимых плагинов:

    ```typescript
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverSlidesPlugin } from '@univerjs-pro/slides'
    import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
    import SlidesUIEnUS from '@univerjs-pro/slides-ui/locale/en-US'
    import SlidesEnUS from '@univerjs-pro/slides/locale/en-US'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs-pro/slides-ui/lib/index.css'
    ```
  </Step>
  <Step>
    Чтобы использовать Facade API[^facade-entry], импортируйте элементы фасада:

    ```typescript
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/slides/facade'
    ```
  </Step>
  <Step>
    Создайте экземпляр Univer, зарегистрируйте плагины и создайте блок Слайдов:

    ```typescript
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          DocsUIEnUS,
          SlidesEnUS,
          SlidesUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
    })

    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)

    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })

    univer.registerPlugin(UniverSlidesPlugin)
    univer.registerPlugin(UniverSlidesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

Объект `univerAPI`, который возвращает `FUniver.newAPI(univer)` — Univer Facade API. Приложение использует его для создания презентаций и вызова API Slides.

#### Настройка плагинов [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для редактора или его идентификатор. |

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое клиентского файла лицензии. |

#### Методы `univer.registerPlugin` и `univer.registerPlugins` [#registerPlugin]

Позвоните `univer.registerPlugin` после создания экземпляра Univer для регистрации одного плагина.

Подпись `univer.registerPlugin(Plugin, options)`. `Plugin` является классом плагинов, и `options` поддерживает конфигурацию этого плагина.

`univer.registerPlugins` принимает массив и регистрирует несколько плагинов в одном вызове. Эта форма удобна, когда список плагинов должен поддерживаться в одном месте.

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, {
    container: 'app',
  }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverDrawingPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverSlidesPlugin,
  UniverSlidesUIPlugin,
])
```

#### Необязательные пакеты функций

Установите пакет функций, когда редактору требуется соответствующая возможность:

```shell
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

Примеры регистрации приведены в [печать](/guides/slides/features/print), [Столик](/guides/slides/features/tables), [Диаграммы](/guides/slides/features/charts) и [Импорт и экспорт](/guides/slides/features/import-export).

#### Отложенная загрузка необязательных плагинов

Режим плагина также позволяет загружать плагин только тогда, когда продукт нуждается в нем:

```typescript
univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

import('@univerjs-pro/slides-chart').then(({ UniverSlidesChartPlugin }) => {
  univer.registerPlugin(UniverSlidesChartPlugin)
})
```

### Использование на сервере

В Node.js зарегистрируйте плагины модели и опустите плагины пользовательского интерфейса браузера:

```typescript
univer.registerPlugin(UniverSlidesPlugin)
```

Плагин модели выполняет обработку снимков без головы. Для раскрытия API-интерфейсов совместной работы или преобразования файлов требуется соответствующий [Модули Server SDK](/server). Регистрация этого плагина сама по себе не создает эти услуги.

## Поддержка мобильных устройств [#mobile-support]

<Callout type="warning">
  Эти примеры требуют пакетов SDK, которые экспортируют мобильные плагины, перечисленные ниже. Все зависимости `@univerjs/*` и `@univerjs-pro/*` должны оставаться на **той же версии**.

  `1.0.0-rc.0` не экспортирует `UniverSlidesMobileUIPlugin`. Выберите сборку, которая включает эту мобильную запись, прежде чем следовать примеру.
</Callout>

Сенсорные элементы управления в Univer Slides требуют, чтобы **Мобильные плагины UI**.[^mobile-ui-mode] определял режим пользовательского интерфейса перед созданием редактора.

В примере с плагин-режимом, приведенном выше, **заменить** импортирует пользовательский интерфейс и регистрации с теми, которые ниже, до `createUnit()`. Не добавляйте их в настольный редактор, который уже был инициализирован. Держите плагины модели, движки, локальные файлы, CSS и импорт Facade. Настольные и мобильные классы называются экспортом из **та же самая упаковка** .

`UniverMobileUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для редактора или его идентификатор. |
| `disableAutoFocus` | `true` | `true` | Отключает автоматический фокус редактора при запуске. |

```typescript
import { UniverSlidesMobileUIPlugin } from '@univerjs-pro/slides-ui'
import { UniverDocsMobileUIPlugin } from '@univerjs/docs-ui'
import { UniverMobileUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverMobileUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsMobileUIPlugin)
univer.registerPlugin(UniverSlidesMobileUIPlugin)
```

### Соответствие плагинов

Зарегистрируйте только используемые функции и сохраните их плагины моделей и требуемые зависимости. Экспорт мобильного интерфейса не означает, что настольные и мобильные устройства предлагают одинаковые элементы управления. Функции Pro по-прежнему требуют соответствующей лицензии. Функции с бэкэндом требуют интеграции на стороне приложения с [Univer Server SDK](/server).

| Пакет | Настольная регистрация | Мобильная регистрация |
| --- | --- | --- |
| `@univerjs/ui` | `UniverUIPlugin` | `UniverMobileUIPlugin` |
| `@univerjs/docs-ui` | `UniverDocsUIPlugin` | `UniverDocsMobileUIPlugin` |
| `@univerjs-pro/slides-ui` | `UniverSlidesUIPlugin` | `UniverSlidesMobileUIPlugin` |
| `@univerjs/drawing-ui` | `UniverDrawingUIPlugin` | `UniverDrawingMobileUIPlugin` |
| `@univerjs/thread-comment-ui` | `UniverThreadCommentUIPlugin` | `UniverThreadCommentMobileUIPlugin` |
| `@univerjs-pro/shape-editor-ui` | `UniverShapeEditorUIPlugin` | `UniverShapeEditorMobileUIPlugin` |
| `@univerjs-pro/chart-ui` | `UniverChartUIPlugin` | `UniverChartMobileUIPlugin` |
| `@univerjs-pro/exchange-client` | `UniverExchangeClientPlugin` | `UniverExchangeClientMobileUIPlugin` |

### Контейнер и сенсорное управление

Контейнеру нужна явная высота, а порт просмотра страницы должен быть сконфигурирован. `100dvh` следует за динамической высотой просмотра. Прокрутка теста, щипковый зум, выбор текста, доступ к буферу обмена и экранная клавиатура в целевых мобильных браузерах. Изменение размера редактора рабочего стола не переключает его на мобильные плагины.

`UniverMobileUIPlugin` по умолчанию выполняется `disableAutoFocus: true`, поэтому редактор не фокусируется автоматически во время инициализации.

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
<div id="app" style="height: 100dvh"></div>
```

## Другие каналы выпуска

Univer публикует альфа/бета-каналы наряду с его стабильными релизами. Они делают новые функции доступными до их официального выпуска, ценой более высокого риска. Эти версии могут содержать ошибки, неполную функциональность или нестабильные функции, поэтому их следует избегать в производстве, где это возможно.

### Выпуски Alpha / Beta

Когда команда Univer завершает новую функцию или существенное изменение, она может предварительно выпустить работу на альфа- или бета-канал.Установить альфа/бета-версию пакета Univer следующим образом:

```package-install
npm install @univerjs-pro/slides@alpha # Alpha version
npm install @univerjs-pro/slides@beta # Beta version
```

Сообщите о проблемах и отзывах на альфа- / бета-версию команде Univer через [Обсуждение GitHub](https://github.com/dream-num/univer/issues).

[^peer-dependency]: `peerDependencies` — зависимости, совместимые версии которых предоставляет основное приложение. Это позволяет Univer и приложению использовать общую копию библиотек, например React.

[^facade-entry]: Facade — прикладной API зарегистрированных плагинов. Импорт точки входа Facade добавляет методы API, но не регистрирует сам функциональный плагин.

[^mobile-ui-mode]: Мобильный UI-плагин выбирает сенсорные элементы управления и мобильные сервисы при инициализации. Он не определяет устройство автоматически и не переключает существующий экземпляр при изменении размера окна. Чтобы сменить режим, сохраните состояние документа, уничтожьте старый экземпляр и инициализируйте выбранный набор плагинов.
