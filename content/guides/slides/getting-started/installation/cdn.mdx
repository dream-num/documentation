title: Import Web SDK via CDN
---

The UMD builds expose the following Slides-specific entries. Every `@univerjs/*` and `@univerjs-pro/*` URL must use the same version.

| UMD path | Global namespace |
| --- | --- |
| `@univerjs-pro/slides/lib/umd/index.js` | `UniverProSlides` |
| `@univerjs-pro/slides/lib/umd/facade.js` | `UniverProSlidesFacade` |
| `@univerjs-pro/slides/lib/umd/locale/en-US.js` | `UniverProSlidesEnUS` |
| `@univerjs-pro/slides-ui/lib/umd/index.js` | `UniverProSlidesUi` |
| `@univerjs-pro/slides-ui/lib/umd/locale/en-US.js` | `UniverProSlidesUiEnUS` |

Load the peer dependencies and the shared runtime first, then load each package dependency in manifest order. `slides` must come before `slides-ui`, each locale must come after the package that owns it, and `@univerjs/core/facade` plus `@univerjs-pro/engine-shape/facade` must come before the Slides Facade entry. UMD does not resolve this dependency graph automatically.

For the package list, CSS imports, plugin registration, and license configuration, return to [Installation & Basic Usage](/guides/slides/getting-started/installation).
