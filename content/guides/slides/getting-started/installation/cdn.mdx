---
title: Import Univer Slides via CDN
---

UMD builds expose the following Slides-specific entries. Keep every `@univerjs/*` and `@univerjs-pro/*` URL on the same version.

| UMD path | Global namespace |
| --- | --- |
| `@univerjs-pro/slides/lib/umd/index.js` | `UniverProSlides` |
| `@univerjs-pro/slides/lib/umd/facade.js` | `UniverProSlidesFacade` |
| `@univerjs-pro/slides/lib/umd/locale/en-US.js` | `UniverProSlidesEnUS` |
| `@univerjs-pro/slides-ui/lib/umd/index.js` | `UniverProSlidesUi` |
| `@univerjs-pro/slides-ui/lib/umd/locale/en-US.js` | `UniverProSlidesUiEnUS` |

Load peer and shared runtime dependencies first, then each package dependency in manifest order. Load `slides` before `slides-ui`, each locale after its owning package, and `@univerjs/core/facade` plus `@univerjs-pro/engine-shape/facade` before the Slides Facade entry. UMD does not resolve this dependency graph automatically.

For the package list, CSS imports, plugin registration, and license configuration, return to [Installation & Basic Usage](/guides/slides/getting-started/installation).
