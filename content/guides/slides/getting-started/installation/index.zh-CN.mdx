---
title: 安装和基本使用
---

本文介绍如何安装 Univer Slides，以及如何将编辑器渲染到页面上。示例使用 Web SDK 的 Slides 包。Univer 目前尚未提供 Slides 预设，因此应用需要通过插件模式构建。

如果你不熟悉 Univer 的基础概念，请先阅读[快速开始](/guides/slides/getting-started/quickstart)。

Univer 提供*预设模式*和*插件模式*两种集成方式。预设模式提供预先组合好的插件包，省去大部分装配工作。如果需要**深度定制或扩展**，请使用插件模式，逐个选择和配置插件。

## 通过插件模式创建

Slides 以一组插件的形式发布。浏览器端编辑器通常先注册 Univer 通用运行时、授权插件、Docs 和 Drawing 依赖，最后注册 Slides 的模型插件和 UI 插件。

### 使用包管理器

构建工具必须支持 ES Module 和 `package.json` 中的 `exports` 字段。

#### 安装

Univer 使用 React 构建界面，使用 RxJS 处理数据流，也可以嵌入 Vue 或 Angular 应用。必须先安装 `react`、`react-dom` 和 `rxjs` 这些 peer dependencies[^peer-dependency]，下面的 Yarn 命令已显式包含它们。

所有 `@univerjs/*` 和 `@univerjs-pro/*` 包必须保持**同一个版本**。

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/slides @univerjs-pro/slides-ui"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}
/>

#### 使用

初始化 Univer 之前，先创建容器并为其设置明确的高度：

```html
<div id="app" style="height: 600px"></div>
```

调用 `FUniver.newAPI(univer)` 之前，先导入后续步骤中用到的 facade 入口。CSS 按 `@univerjs/design`、`@univerjs/ui` 和产品样式的顺序引入。

<Callout type="warning" title="注意事项">
  - 先注册 `UniverLicensePlugin`，再注册 Slides 插件。
  - 先引入通用 UI 样式，再引入产品 UI 样式。
  - 打印、表格、图表、导入导出等可选功能包只在产品需要时安装。
  - `UniverSlidesUIPlugin` 会为形状功能自动加载 `UniverProFormulaEnginePlugin`。如果同一个 `Univer` 实例还注册了 `UniverFormulaEnginePlugin`，请安装 `@univerjs-pro/engine-formula`，并在初始化代码中把该公式引擎的导入和注册替换为 `UniverProFormulaEnginePlugin`。不要同时注册两个公式引擎。
</Callout>

<Steps>
  <Step>
    导入样式文件、语言包和必需的插件：

    ```typescript
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverSlidesPlugin } from '@univerjs-pro/slides'
    import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
    import SlidesUIZhCN from '@univerjs-pro/slides-ui/locale/zh-CN'
    import SlidesZhCN from '@univerjs-pro/slides/locale/zh-CN'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignZhCN from '@univerjs/design/locale/zh-CN'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIZhCN from '@univerjs/docs-ui/locale/zh-CN'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIZhCN from '@univerjs/ui/locale/zh-CN'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs-pro/slides-ui/lib/index.css'
    ```
  </Step>
  <Step>
    如需使用 Facade API[^facade-entry]，还应导入对应的 facade 入口：

    ```typescript
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/slides/facade'
    ```
  </Step>
  <Step>
    创建 Univer 实例、注册插件，然后创建一个 Slides unit：

    ```typescript
    const univer = new Univer({
      locale: LocaleType.ZH_CN,
      locales: {
        [LocaleType.ZH_CN]: mergeLocales(
          DesignZhCN,
          UIZhCN,
          DocsUIZhCN,
          SlidesZhCN,
          SlidesUIZhCN,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
    })

    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)

    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })

    univer.registerPlugin(UniverSlidesPlugin)
    univer.registerPlugin(UniverSlidesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

返回的 `univerAPI` 对象是 Univer 的 Facade API，用于创建演示文稿和调用 Slides 接口。

#### 插件配置 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 编辑器挂载的 DOM 元素或元素 ID。 |

`UniverLicensePlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 客户端许可证文件的内容。 |

#### `univer.registerPlugin` 与 `univer.registerPlugins` 方法 [#registerPlugin]

创建 Univer 实例之后，调用 `univer.registerPlugin` 可以注册单个插件。

签名为 `univer.registerPlugin(Plugin, options)`，其中 `Plugin` 是插件类，`options` 是该插件自身的配置。

`univer.registerPlugins` 接收一个数组，可在一次调用中注册多个插件。需要在同一处维护插件清单时，适合使用这种形式。

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, {
    container: 'app',
  }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverDrawingPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverSlidesPlugin,
  UniverSlidesUIPlugin,
])
```

#### 可选功能包

编辑器需要某项能力时，再安装对应的功能包：

```shell
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

注册示例参见[打印](/guides/slides/features/print)、[表格](/guides/slides/features/tables)、[图表](/guides/slides/features/charts)和[导入导出](/guides/slides/features/import-export)。

#### 懒加载部分插件

插件模式还允许把功能插件推迟到产品实际需要时再加载：

```typescript
univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

import('@univerjs-pro/slides-chart').then(({ UniverSlidesChartPlugin }) => {
  univer.registerPlugin(UniverSlidesChartPlugin)
})
```

### 服务端使用

在 Node.js 中，只注册模型插件，不注册浏览器端 UI 插件：

```typescript
univer.registerPlugin(UniverSlidesPlugin)
```

模型插件负责无头快照处理。对外提供协同或文件转换接口需要接入对应的 [Server SDK 模块](/server)；只注册该插件不会创建这些服务。

## 移动端适配 [#mobile-support]

<Callout type="warning">
  这些示例要求 SDK 包导出下列移动端插件。所有 `@univerjs/*` 和 `@univerjs-pro/*` 依赖必须保持**同一个版本**。

  `1.0.0-rc.0` 未导出 `UniverSlidesMobileUIPlugin`，请先选择一个包含该移动端入口的构建版本，再按示例操作。
</Callout>

Univer Slides 的触摸操作需要使用**移动端 UI 插件**。[^mobile-ui-mode] 创建编辑器之前必须确定 UI 模式。

在上面的插件模式示例中，要在 `createUnit()` 之前用下面的导入和注册**替换** UI 插件的导入和注册，不要追加到已经初始化完成的桌面端编辑器上。模型插件、引擎、语言包、CSS 和 Facade 导入均需保留。桌面端和移动端的类是**同一个包入口**中的具名导出。

`UniverMobileUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 编辑器挂载的 DOM 元素或元素 ID。 |
| `disableAutoFocus` | `true` | `true` | 防止编辑器在启动时自动获得焦点。 |

```typescript
import { UniverSlidesMobileUIPlugin } from '@univerjs-pro/slides-ui'
import { UniverDocsMobileUIPlugin } from '@univerjs/docs-ui'
import { UniverMobileUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverMobileUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsMobileUIPlugin)
univer.registerPlugin(UniverSlidesMobileUIPlugin)
```

### 插件对照

只注册实际使用的功能，同时保留它们的模型插件和必要依赖。有移动端 UI 导出，不代表桌面端和移动端提供相同的控件。Pro 功能仍然需要对应的许可证；需要后端的功能，要在业务应用中接入 [Univer Server SDK](/server)。

| `@univerjs/drawing-ui` | `UniverDrawingUIPlugin` | `UniverDrawingMobileUIPlugin` |

### 容器与触摸交互

容器必须设置明确的高度，页面 viewport 也必须配置。`100dvh` 会随动态视口高度变化。滚动、双指缩放、文本选择、剪贴板访问和软键盘都需要在目标移动浏览器中测试。只调整桌面端编辑器的尺寸不会切换到移动端插件。

`UniverMobileUIPlugin` 默认使用 `disableAutoFocus: true`，因此编辑器在初始化时不会自动获得焦点。

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
<div id="app" style="height: 100dvh"></div>
```

## 其他发布版本

除稳定版本外，Univer 还提供 alpha / beta 通道。这些通道可以在新功能正式发布前试用，但风险更高。这些版本可能存在 bug、功能不完整或不稳定的情况，应尽量避免用于生产环境。

### Alpha / Beta 版本

Univer 团队完成新功能或较大改动后，可能会先将其预发布到 alpha 或 beta 通道。安装某个 Univer 包的 alpha / beta 版本使用以下命令：

```package-install
npm install @univerjs-pro/slides@alpha # Alpha 版本
npm install @univerjs-pro/slides@beta # Beta 版本
```

使用 alpha / beta 版本时遇到的问题和反馈，请通过 [GitHub Issues](https://github.com/dream-num/univer/issues) 提交给 Univer 团队。

[^peer-dependency]: `peerDependencies` 表示需要由宿主项目提供兼容版本的依赖。这样 Univer 可以与应用共享 React 等库，而不是各自携带一份。

[^facade-entry]: Facade 是面向应用的 API，封装已注册插件的能力。导入 Facade 入口会扩展 API 方法，但不会代替功能插件的注册。

[^mobile-ui-mode]: 移动端 UI 插件在初始化时选择触摸控件和移动端服务，不会自动判断设备，也不会在窗口尺寸变化时切换已有实例。若要切换模式，应先保留文档状态，销毁旧实例，再使用所选插件组合初始化。
