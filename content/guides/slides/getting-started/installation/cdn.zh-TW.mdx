---
title: 透過 CDN 引入 Univer Slides
icon: 'CloudDownload'
---

UMD 建置會公開以下 Slides 專用入口。所有 `@univerjs/*` 與 `@univerjs-pro/*` URL 必須使用相同版本。

| UMD 路徑 | 全域命名空間 |
| --- | --- |
| `@univerjs-pro/slides/lib/umd/index.js` | `UniverProSlides` |
| `@univerjs-pro/slides/lib/umd/facade.js` | `UniverProSlidesFacade` |
| `@univerjs-pro/slides/lib/umd/locale/en-US.js` | `UniverProSlidesEnUS` |
| `@univerjs-pro/slides-ui/lib/umd/index.js` | `UniverProSlidesUi` |
| `@univerjs-pro/slides-ui/lib/umd/locale/en-US.js` | `UniverProSlidesUiEnUS` |

先載入 peer 依賴與共用執行環境，再依照清單順序載入每個套件的依賴。`slides` 應早於 `slides-ui`，locale 應位於所屬套件之後，Slides Facade 入口應位於 `@univerjs/core/facade` 和 `@univerjs-pro/engine-shape/facade` 之後。UMD 不會自動解析這張依賴圖。

套件清單、CSS、外掛註冊和授權設定請返回[安裝與基本使用](/guides/slides/getting-started/installation)查看。
