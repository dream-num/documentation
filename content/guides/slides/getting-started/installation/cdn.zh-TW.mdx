---
title: 透過 CDN 使用 Web SDK
---

UMD 建置會暴露以下 Slides 專用入口。所有 `@univerjs/*` 和 `@univerjs-pro/*` URL 必須使用同一版本。

| UMD 路徑 | 全域命名空間 |
| --- | --- |
| `@univerjs-pro/slides/lib/umd/index.js` | `UniverProSlides` |
| `@univerjs-pro/slides/lib/umd/facade.js` | `UniverProSlidesFacade` |
| `@univerjs-pro/slides/lib/umd/locale/en-US.js` | `UniverProSlidesEnUS` |
| `@univerjs-pro/slides-ui/lib/umd/index.js` | `UniverProSlidesUi` |
| `@univerjs-pro/slides-ui/lib/umd/locale/en-US.js` | `UniverProSlidesUiEnUS` |

先載入 peer 依賴和共享執行時，再按清單順序逐個載入每個包的依賴。`slides` 必須位於 `slides-ui` 之前，locale 必須位於所屬包之後，Slides Facade 入口必須位於 `@univerjs/core/facade` 和 `@univerjs-pro/engine-shape/facade` 之後。UMD 不會自動解析這張依賴圖。

包列表、CSS 匯入、外掛註冊和許可證配置，請返回[安裝和基本使用](/guides/slides/getting-started/installation)檢視。
