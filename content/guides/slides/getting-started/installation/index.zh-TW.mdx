---
title: 安裝與基本使用
---

本文介紹如何安裝 Univer Slides，以及如何將編輯器渲染到頁面上。範例使用 Web SDK 的 Slides 包。Univer 目前尚未提供 Slides 預設，因此應用需要透過外掛模式建置。

如果你不熟悉 Univer 的基礎概念，請先閱讀[快速開始](/guides/slides/getting-started/quickstart)。

Univer 提供*預設模式*和*外掛模式*兩種整合方式。預設模式提供預先組合好的外掛套件，省去大部分裝配工作。如果需要**深度定製或擴充套件**，請使用外掛模式，逐個選擇和配置外掛。

## 透過外掛模式建立

Slides 以一組外掛的形式釋出。瀏覽器端編輯器通常先註冊 Univer 通用執行時、授權外掛、Docs 和 Drawing 依賴，最後註冊 Slides 的模型外掛和 UI 外掛。

### 使用套件管理器

建置工具必須支援 ES Module 和 `package.json` 中的 `exports` 欄位。

#### 安裝

Univer 使用 React 建置介面，使用 RxJS 處理資料流，也可以嵌入 Vue 或 Angular 應用。必須先安裝 `react`、`react-dom` 和 `rxjs` 這些 peer dependencies[^peer-dependency]，下面的 Yarn 命令已顯式包含它們。

所有 `@univerjs/*` 和 `@univerjs-pro/*` 包必須保持**同一個版本**。

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/slides @univerjs-pro/slides-ui"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}

#### 使用

初始化 Univer 之前，先建立容器併為其設定明確的高度：

```html
<div id="app" style="height: 600px"></div>
```

呼叫 `FUniver.newAPI(univer)` 之前，先匯入後續步驟中用到的 facade 入口。CSS 按 `@univerjs/design`、`@univerjs/ui` 和產品樣式的順序引入。

<Callout type="warning" title="注意事項">
  - 先註冊 `UniverLicensePlugin`，再註冊 Slides 外掛。
  - 先引入通用 UI 樣式，再引入產品 UI 樣式。
  - 列印、表格、圖表、匯入匯出等可選功能包只在產品需要時安裝。
  - `UniverSlidesUIPlugin` 會為形狀功能自動載入 `UniverProFormulaEnginePlugin`。如果同一個 `Univer` 例項還註冊了 `UniverFormulaEnginePlugin`，請安裝 `@univerjs-pro/engine-formula`，並在初始化程式碼中把該公式引擎的匯入和註冊替換為 `UniverProFormulaEnginePlugin`。不要同時註冊兩個公式引擎。
</Callout>

<Steps>
  <Step>
    匯入樣式檔案、語言套件和必需的外掛：

    ```typescript
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverSlidesPlugin } from '@univerjs-pro/slides'
    import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
    import SlidesUIZhTW from '@univerjs-pro/slides-ui/locale/zh-TW'
    import SlidesZhTW from '@univerjs-pro/slides/locale/zh-TW'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignZhTW from '@univerjs/design/locale/zh-TW'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIZhTW from '@univerjs/docs-ui/locale/zh-TW'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIZhTW from '@univerjs/ui/locale/zh-TW'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs-pro/slides-ui/lib/index.css'
    ```
  </Step>
  <Step>
    如需使用 Facade API[^facade-entry]，還應匯入對應的 facade 入口：

    ```typescript
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/slides/facade'
    ```
  </Step>
  <Step>
    建立 Univer 例項、註冊外掛，然後建立一個 Slides unit：

    ```typescript
    const univer = new Univer({
      locale: LocaleType.ZH_TW,
      locales: {
        [LocaleType.ZH_TW]: mergeLocales(
          DesignZhTW,
          UIZhTW,
          DocsUIZhTW,
          SlidesZhTW,
          SlidesUIZhTW,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
    })

    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)

    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })

    univer.registerPlugin(UniverSlidesPlugin)
    univer.registerPlugin(UniverSlidesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

返回的 `univerAPI` 物件是 Univer 的 Facade API，用於建立簡報和呼叫 Slides 介面。

#### 外掛設定 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 編輯器掛載的 DOM 元素或元素 ID。 |

`UniverLicensePlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 用戶端授權檔的內容。 |

#### `univer.registerPlugin` 與 `univer.registerPlugins` 方法 [#registerPlugin]

建立 Univer 例項之後，呼叫 `univer.registerPlugin` 可以註冊單個外掛。

簽名為 `univer.registerPlugin(Plugin, options)`，其中 `Plugin` 是外掛類，`options` 是該外掛自身的配置。

`univer.registerPlugins` 接收一個陣列，可在一次呼叫中註冊多個外掛。需要在同一處維護外掛清單時，適合使用這種形式。

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, {
    container: 'app',
  }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverDrawingPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverSlidesPlugin,
  UniverSlidesUIPlugin,
])
```

#### 可選功能套件

編輯器需要某項能力時，再安裝對應的功能包：

```shell
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

註冊範例參見[列印](/guides/slides/features/print)、[表格](/guides/slides/features/tables)、[圖表](/guides/slides/features/charts)和[匯入匯出](/guides/slides/features/import-export)。

#### 懶載入部分外掛

外掛模式還允許把功能外掛推遲到產品實際需要時再載入：

```typescript
univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

import('@univerjs-pro/slides-chart').then(({ UniverSlidesChartPlugin }) => {
  univer.registerPlugin(UniverSlidesChartPlugin)
})
```

### 服務端使用

在 Node.js 中，只註冊模型外掛，不註冊瀏覽器端 UI 外掛：

```typescript
univer.registerPlugin(UniverSlidesPlugin)
```

模型外掛負責無頭快照處理。對外提供協同或檔案轉換介面需要接入對應的 [Server SDK 模組](/server)；只註冊該外掛不會建立這些服務。

## 行動裝置支援 [#mobile-support]

<Callout type="warning">
  這些範例要求 SDK 包匯出下列行動版外掛。所有 `@univerjs/*` 和 `@univerjs-pro/*` 依賴必須保持**同一個版本**。

  `1.0.0-rc.0` 未匯出 `UniverSlidesMobileUIPlugin`，請先選擇一個包含該行動版入口的建置版本，再按範例操作。
</Callout>

Univer Slides 的觸控操作需要使用**行動版 UI 外掛**。[^mobile-ui-mode] 建立編輯器之前必須確定 UI 模式。

在上面的外掛模式範例中，要在 `createUnit()` 之前用下面的匯入和註冊**替換** UI 外掛的匯入和註冊，不要追加到已經初始化完成的桌面版編輯器上。模型外掛、引擎、語言套件、CSS 和 Facade 匯入均需保留。桌面版和行動版的類是**同一套件入口**中的具名匯出。

`UniverMobileUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 編輯器掛載的 DOM 元素或元素 ID。 |
| `disableAutoFocus` | `true` | `true` | 防止編輯器在啟動時自動取得焦點。 |

```typescript
import { UniverSlidesMobileUIPlugin } from '@univerjs-pro/slides-ui'
import { UniverDocsMobileUIPlugin } from '@univerjs/docs-ui'
import { UniverMobileUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverMobileUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsMobileUIPlugin)
univer.registerPlugin(UniverSlidesMobileUIPlugin)
```

### 外掛對照

只註冊實際使用的功能，同時保留它們的模型外掛和必要依賴。有行動版 UI 匯出，不代表桌面版和行動版提供相同的控制元件。Pro 功能仍然需要對應的許可證；需要後端的功能，要在業務應用中接入 [Univer Server SDK](/server)。

| 套件 | 桌面版註冊 | 行動版註冊 |
| --- | --- | --- |
| `@univerjs/ui` | `UniverUIPlugin` | `UniverMobileUIPlugin` |
| `@univerjs/docs-ui` | `UniverDocsUIPlugin` | `UniverDocsMobileUIPlugin` |
| `@univerjs-pro/slides-ui` | `UniverSlidesUIPlugin` | `UniverSlidesMobileUIPlugin` |
| `@univerjs/drawing-ui` | `UniverDrawingUIPlugin` | `UniverDrawingMobileUIPlugin` |
| `@univerjs/thread-comment-ui` | `UniverThreadCommentUIPlugin` | `UniverThreadCommentMobileUIPlugin` |
| `@univerjs-pro/shape-editor-ui` | `UniverShapeEditorUIPlugin` | `UniverShapeEditorMobileUIPlugin` |
| `@univerjs-pro/chart-ui` | `UniverChartUIPlugin` | `UniverChartMobileUIPlugin` |
| `@univerjs-pro/exchange-client` | `UniverExchangeClientPlugin` | `UniverExchangeClientMobileUIPlugin` |
| `@univerjs-pro/slides-chart-ui` | `UniverSlidesChartUIPlugin` | `UniverSlidesChartMobileUIPlugin` |
| `@univerjs-pro/slides-print` | `UniverSlidesPrintPlugin` | `UniverSlidesPrintMobilePlugin` |
| `@univerjs-pro/slides-table-ui` | `UniverSlidesTableUIPlugin` | `UniverSlidesTableMobileUIPlugin` |
| `@univerjs-pro/slides-thread-comment-ui` | `UniverSlidesThreadCommentUIPlugin` | `UniverSlidesThreadCommentMobileUIPlugin` |

### 容器與觸控互動

容器必須設定明確的高度，頁面 viewport 也必須配置。`100dvh` 會隨動態視口高度變化。滾動、雙指縮放、文字選擇、剪貼簿訪問和軟鍵盤都需要在目標移動瀏覽器中測試。只調整桌面版編輯器的尺寸不會切換到行動版外掛。

`UniverMobileUIPlugin` 預設使用 `disableAutoFocus: true`，因此編輯器在初始化時不會自動獲得焦點。

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
<div id="app" style="height: 100dvh"></div>
```

## 其他發佈版本

除穩定版本外，Univer 還提供 alpha / beta 通道。這些通道可以在新功能正式釋出前試用，但風險更高。這些版本可能存在 bug、功能不完整或不穩定的情況，應儘量避免用於生產環境。

### Alpha / Beta 版本

Univer 團隊完成新功能或較大改動後，可能會先將其預釋出到 alpha 或 beta 通道。安裝某個 Univer 包的 alpha / beta 版本使用以下命令：

```package-install
npm install @univerjs-pro/slides@alpha # Alpha 版本
npm install @univerjs-pro/slides@beta # Beta 版本
```

使用 alpha / beta 版本時遇到的問題和反饋，請透過 [GitHub Issues](https://github.com/dream-num/univer/issues) 提交給 Univer 團隊。

[^peer-dependency]: `peerDependencies` 表示需要由宿主專案提供相容版本的相依套件，讓 Univer 與應用程式共用 React 等函式庫，而不是各自攜帶一份。

[^facade-entry]: Facade 是面向應用程式的 API，封裝已註冊外掛的能力。匯入 Facade 入口會擴充 API 方法，但不會取代功能外掛的註冊。

[^mobile-ui-mode]: 行動版 UI 外掛在初始化時選擇觸控元件與行動版服務，不會自動判斷裝置，也不會在視窗大小改變時切換既有實例。如需切換模式，請先保留文件狀態、銷毀舊實例，再以選定的外掛組合初始化。
