UMD 빌드는 다음 Slides 전용 엔트리를 전역으로 노출합니다. 모든 `@univerjs/*` 및 `@univerjs-pro/*` URL에 같은 버전을 지정하세요.

| UMD 경로 | 전역 네임스페이스 |
| --- | --- |
| `@univerjs-pro/slides/lib/umd/index.js` | `UniverProSlides` |
| `@univerjs-pro/slides/lib/umd/facade.js` | `UniverProSlidesFacade` |
| `@univerjs-pro/slides/lib/umd/locale/en-US.js` | `UniverProSlidesEnUS` |
| `@univerjs-pro/slides-ui/lib/umd/index.js` | `UniverProSlidesUi` |
| `@univerjs-pro/slides-ui/lib/umd/locale/en-US.js` | `UniverProSlidesUiEnUS` |

peer 및 공용 런타임 의존성을 먼저 불러온 뒤 각 패키지 의존성을 매니페스트 순서로 불러오세요. `slides`는 `slides-ui`보다 먼저, locale은 해당 패키지 다음에, Slides Facade 엔트리는 `@univerjs/core/facade`와 `@univerjs-pro/engine-shape/facade` 다음에 불러와야 합니다. UMD는 의존성 그래프를 자동으로 해결하지 않습니다.

패키지 목록, CSS, 플러그인 등록 및 라이선스 설정은 [설치 및 기본 사용법](/guides/slides/getting-started/installation)으로 돌아가 확인하세요.
