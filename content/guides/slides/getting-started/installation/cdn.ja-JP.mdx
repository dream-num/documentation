---
title: CDN から Univer Slides を読み込む
---

UMD ビルドは、次の Slides 固有エントリをグローバルに公開します。すべての `@univerjs/*` と `@univerjs-pro/*` の URL で同じバージョンを指定してください。

| UMD パス | グローバル名前空間 |
| --- | --- |
| `@univerjs-pro/slides/lib/umd/index.js` | `UniverProSlides` |
| `@univerjs-pro/slides/lib/umd/facade.js` | `UniverProSlidesFacade` |
| `@univerjs-pro/slides/lib/umd/locale/en-US.js` | `UniverProSlidesEnUS` |
| `@univerjs-pro/slides-ui/lib/umd/index.js` | `UniverProSlidesUi` |
| `@univerjs-pro/slides-ui/lib/umd/locale/en-US.js` | `UniverProSlidesUiEnUS` |

peer 依存関係と共通ランタイムを先に読み込み、その後に各パッケージの依存関係をマニフェスト順で読み込みます。`slides` は `slides-ui` より先、locale は対応するパッケージの後、Slides Facade は `@univerjs/core/facade` と `@univerjs-pro/engine-shape/facade` の後に読み込みます。UMD は依存グラフを自動解決しません。

パッケージ一覧、CSS、プラグイン登録、ライセンス設定は[インストールと基本使用](/guides/slides/getting-started/installation)に戻って確認してください。
