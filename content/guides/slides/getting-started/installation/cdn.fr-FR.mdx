---
title: Importer Univer Slides via un CDN
---

Les builds UMD exposent les entrées propres à Slides ci-dessous. Utilisez la même version dans toutes les URL `@univerjs/*` et `@univerjs-pro/*`.

| Chemin UMD | Espace de noms global |
| --- | --- |
| `@univerjs-pro/slides/lib/umd/index.js` | `UniverProSlides` |
| `@univerjs-pro/slides/lib/umd/facade.js` | `UniverProSlidesFacade` |
| `@univerjs-pro/slides/lib/umd/locale/en-US.js` | `UniverProSlidesEnUS` |
| `@univerjs-pro/slides-ui/lib/umd/index.js` | `UniverProSlidesUi` |
| `@univerjs-pro/slides-ui/lib/umd/locale/en-US.js` | `UniverProSlidesUiEnUS` |

Chargez d’abord les dépendances peer et du runtime partagé, puis celles de chaque package dans l’ordre du manifeste. Chargez `slides` avant `slides-ui`, chaque locale après son package, et `@univerjs/core/facade` ainsi que `@univerjs-pro/engine-shape/facade` avant l’entrée Facade de Slides. UMD ne résout pas ce graphe automatiquement.

Pour la liste des packages, les styles, l’enregistrement des plugins et la licence, revenez à [Installation et utilisation de base](/guides/slides/getting-started/installation).
