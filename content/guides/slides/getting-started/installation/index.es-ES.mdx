title: Instalación y uso básico

Este capítulo presenta la instalación y el uso básico de Univer Slides. Esta guía utiliza los paquetes de Univer SDK Pro para Slides. Actualmente no hay un preset de Slides, por lo que debe crear la aplicación en modo plugin.

Si no está familiarizado con los conceptos básicos de Univer, lea primero [Inicio rápido](/guides/slides/getting-started/quickstart).

## Crear con el modo complemento

Univer expone Presentaciones como un conjunto de complementos. Un editor de navegador generalmente registra el tiempo de ejecución compartido de Univer, el complemento de licencia Pro, las dependencias de Docs y Drawing, y luego el modelo de Slides y los complementos de UI.

### Utilice un administrador de paquetes

Si su proyecto ya utiliza herramientas de interfaz modernas, le recomendamos Vite, esbuild o Webpack 5. Los paquetes de Slides dependen de los puntos de entrada de ESM, por lo que los paquetes más antiguos pueden requerir una configuración adicional.

#### Instalación

Instale los paquetes mínimos para un Editor de diapositivas del navegador:

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab>
    ```shell
    npm install @univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/slides @univerjs-pro/slides-ui
    ```
  </Tab>
  <Tab>
    ```shell

    ```

</Tabs>

#### Uso

<Callout type="warning" title="Caution">
  - Registre `UniverLicensePlugin` antes de registrar los complementos de Presentaciones.
  - Importe el CSS de la interfaz de usuario compartido antes que el CSS de la interfaz de usuario del producto.
  - Los paquetes de funciones opcionales, como impresión, tablas, gráficos e importación/exportación, deben agregarse solo cuando el producto los necesite.
</Callout>

<Steps>
  <Step>
Importe estilos, paquetes de configuración regional y los complementos necesarios:

    ```typescript
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverSlidesPlugin } from '@univerjs-pro/slides'
    import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
    import SlidesUIEnUS from '@univerjs-pro/slides-ui/locale/en-US'
    import SlidesEnUS from '@univerjs-pro/slides/locale/en-US'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs-pro/slides-ui/lib/index.css'
    ```
  </Step>
  <Step>
Importe entradas de fachada si desea utilizar Facade API:

    ```typescript
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/slides/facade'
    ```
  </Step>
  <Step>
Cree una instancia de Univer, registre complementos y cree una unidad de Diapositivas:

    ```typescript
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          DocsUIEnUS,
          SlidesEnUS,
          SlidesUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
    })

    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)

    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })

    univer.registerPlugin(UniverSlidesPlugin)
    univer.registerPlugin(UniverSlidesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

El objeto `univerAPI` devuelto por `FUniver.newAPI(univer)` es la API de Facade de Univer. Úselo para crear presentaciones y llamar a las API de Presentaciones.

#### `univer.registerPlugin` y `univer.registerPlugins`

`univer.registerPlugin` registra un complemento en la instancia de Univer. Use `univer.registerPlugins` para pasar una matriz y registrar varios complementos en un solo lugar.

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, {
    container: 'app',
  }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverDrawingPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverSlidesPlugin,
  UniverSlidesUIPlugin,
])
```

#### Paquetes de funciones opcionales

Agregue paquetes de funciones cuando el editor necesite la capacidad correspondiente:

```shell
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

Para ver ejemplos de registro de funciones, consulte [Impresión](/guides/slides/features/print), [Tablas](/guides/slides/features/tables), [Gráficos](/guides/slides/features/charts) e [Importación y exportación](/guides/slides/features/import-export).

#### Complementos opcionales de carga diferida

El modo de complemento le permite retrasar los complementos de funciones hasta que el producto realmente los necesite:

```typescript
univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

import('@univerjs-pro/slides-chart').then(({ UniverSlidesChartPlugin }) => {
  univer.registerPlugin(UniverSlidesChartPlugin)
})
```

### Uso del lado del servidor

En Node.js, registre los complementos del modelo y omita la interfaz de usuario del navegador. complementos:

```typescript
univer.registerPlugin(UniverSlidesPlugin)
```

Esta configuración es adecuada para el procesamiento de instantáneas, la importación/exportación del lado del servidor y servicios de colaboración.

## Otros canales de lanzamiento

Además de las versiones estables, Univer ofrece canales alfa, beta y nocturnos. Estos canales le permiten probar las próximas capacidades antes, pero pueden contener un comportamiento incompleto o inestable. Evite usarlos en producción a menos que tenga un plan de validación claro.

```package-install
npm install @univerjs-pro/slides@alpha
npm install @univerjs-pro/slides@beta
```
