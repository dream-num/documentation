title: インストールと基本的な使い方
---

このページでは、Univer Slides をインストールし、ページ上のエディタをレンダリングする方法について説明します。 この例では、Web SDK Slides パッケージを使用します。 Univer はまだ Slides プリセットを提供していません。そのため、プラグインモードでアプリケーションが組み込まれています。

Univerのコアコンセプトに慣れていない場合は、[クイックスタート](/guides/slides/getting-started/quickstart)を最初に読みます。

Univerは、*Preset Mode*と*Plugin Mode*の2つの統合モードを提供します。 Preset Modeは、構成済みのプラグインバンドを供給します。これにより、アセンブリ作業の大部分が削除されます。 **深いカスタム化か延長**を使用するプラグインモードが必要です。各プラグインが選択され、個別に設定されます。

## プラグインモードでのセットアップ

Univerは、プラグインのセットとしてスライドを配布します。 ブラウザエディタは、通常、共有されたUniverランタイム、ライセンスプラグイン、DocsおよびDraw dependenciesを登録し、SlidesモデルとUIプラグインを登録します。

### パッケージマネージャーの使用

ビルドツールは、`package.json`のESモジュールと`exports`フィールドをサポートする必要があります。

#### インストール

Univerは、データストリーム用のUIとRxJS用のReactを使用しており、VueまたはAngularアプリケーションにも埋め込むことができます。 `react`、`react-dom`および`rxjs`ピア依存[^peer-dependency]をインストールする必要があります。 下記のYarnコマンドには明示的に含まれています。

`@univerjs/*`と`@univerjs-pro/*`パッケージは**同じバージョン**にご滞在いただく必要があります。

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/slides @univerjs-pro/slides-ui"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}
/>

#### 使い方

Univerを初期化する前にコンテナを作成し、それを明示的な高さにします。

```html
<div id="app" style="height: 600px"></div>
```

`FUniver.newAPI(univer)`を呼び出す前に、次の手順で使用されているファサードエントリをインポートします。 `@univerjs/design`CSSを最初にインポートし、`@univerjs/ui` CSS、および製品CSSが最後に続きます。

<Callout type="warning" title="注意">
  - 任意のスライドプラグインの前に `UniverLicensePlugin` を登録します。
  - 共有 UI CSS をインポートして、製品 UI CSS の前にインポートします。
  - プリント、テーブル、チャート、およびインポート/エクスポートなどのオプションパッケージを製品が必要とする場合にのみ追加します。
  - `UniverSlidesUIPlugin`は、形のために`UniverProFormulaEnginePlugin`を独自にロードします。同じ`Univer`インスタンスも`UniverFormulaEnginePlugin`を登録し、`@univerjs-pro/engine-formula`をインストールし、そのエンジンのインポートと登録を初期化コードで`UniverProFormulaEnginePlugin`に置き換えます。両方の式エンジンを登録しないでください。
</Callout>

<Steps>
  <Step>
    スタイルシート、ロケールパック、および必要なプラグインをインポートします。

    ```typescript
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverSlidesPlugin } from '@univerjs-pro/slides'
    import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
    import SlidesUIJaJP from '@univerjs-pro/slides-ui/locale/ja-JP'
    import SlidesJaJP from '@univerjs-pro/slides/locale/ja-JP'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignJaJP from '@univerjs/design/locale/ja-JP'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIJaJP from '@univerjs/docs-ui/locale/ja-JP'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIJaJP from '@univerjs/ui/locale/ja-JP'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs-pro/slides-ui/lib/index.css'
    ```
  </Step>
  <Step>
    Facade API[^facade-entry]を使用するには、ファサードエントリをインポートします。

    ```typescript
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/slides/facade'
    ```
  </Step>
  <Step>
    Univerインスタンスを作成し、プラグインを登録し、スライドユニットを作成します。

    ```typescript
    const univer = new Univer({
      locale: LocaleType.JA_JP,
      locales: {
        [LocaleType.JA_JP]: mergeLocales(
          DesignJaJP,
          UIJaJP,
          DocsUIJaJP,
          SlidesJaJP,
          SlidesUIJaJP,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
    })

    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)

    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })

    univer.registerPlugin(UniverSlidesPlugin)
    univer.registerPlugin(UniverSlidesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

`FUniver.newAPI(univer)`が返す`univerAPI`オブジェクトはUniverのFacade APIです。アプリケーションは、プレゼンテーションを作成したり、Slide APIを呼び出すために使用します。

#### プラグイン設定 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターを配置する DOM 要素またはその ID。 |

`UniverLicensePlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `license` | `string` |  | クライアントライセンスファイルの内容。 |

#### `univer.registerPlugin` と `univer.registerPlugins` メソッド [#registerPlugin]

Univerインスタンスを作成した後、`univer.registerPlugin`を呼び出して、単一のプラグインを登録します。

署名は`univer.registerPlugin(Plugin, options)`です。`Plugin`はプラグインクラスで、`options`はそのプラグインの設定を保持しています。

`univer.registerPlugins`は配列を受け入れ、1つの呼び出しで複数のプラグインを登録します。このフォームは、プラグインリストが1か所に維持されるべきときに便利です。

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, {
    container: 'app',
  }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverDrawingPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverSlidesPlugin,
  UniverSlidesUIPlugin,
])
```

#### 追加機能パッケージ

エディタが対応する機能を必要とするときに機能パッケージをインストールします。

```shell
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

[印刷・印刷](/guides/slides/features/print)、[テーブル](/guides/slides/features/tables),[チャート](/guides/slides/features/charts)および[輸入および輸出](/guides/slides/features/import-export)で登録例が記載されています。

#### 一部プラグインの遅延読み込み

プラグインモードは、製品が必要とする場合にのみ、機能プラグインをロードすることができます。

```typescript
univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

import('@univerjs-pro/slides-chart').then(({ UniverSlidesChartPlugin }) => {
  univer.registerPlugin(UniverSlidesChartPlugin)
})
```

### サーバーサイドでの使用

Node.jsでは、モデルプラグインを登録し、ブラウザUIプラグインを省略します。

```typescript
univer.registerPlugin(UniverSlidesPlugin)
```

モデルプラグインは、ヘッドレススナップショット処理を実行します。コラボレーションやファイルコンバージョン API を公開するには、対応する [Server SDKモジュール](/server) が必要です。このプラグインを単独で登録することは、これらのサービスを作成していません。

## モバイル対応 [#mobile-support]

<Callout type="warning">
  これらの例では、以下のモバイルプラグインをエクスポートするSDKパッケージが必要です。 `@univerjs/*`と`@univerjs-pro/*`の依存関係は、**同じバージョン**に残さなければなりません。

  `1.0.0-rc.0`は`UniverSlidesMobileUIPlugin`をエクスポートしません。このモバイルエントリーを含むビルドを選択し、次の例にしたがってください。
</Callout>

Univerスライドのタッチコントロールには、**モバイルUIプラグイン**.[^mobile-ui-mode]は、エディタを作成する前にUIモードを決定します。

上記のプラグインモードの例では、**交換する** では、UI のインポートと登録を `createUnit()`. 既に初期化されているデスクトップエディタにそれらを追加しないでください。 モデルプラグイン、エンジン、ローカファイル、CSS、ファサードのインポートをキープします。 デスクトップとモバイルクラスは、**同じパッケージエントリ**からエクスポートの名前が付けられています。

`UniverMobileUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターを配置する DOM 要素またはその ID。 |
| `disableAutoFocus` | `true` | `true` | 起動時にエディターへの自動フォーカスを抑止します。 |

```typescript
import { UniverSlidesMobileUIPlugin } from '@univerjs-pro/slides-ui'
import { UniverDocsMobileUIPlugin } from '@univerjs/docs-ui'
import { UniverMobileUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverMobileUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsMobileUIPlugin)
univer.registerPlugin(UniverSlidesMobileUIPlugin)
```

### プラグイン対応表

### コンテナーとタッチ操作

コンテナは明示的な高さを必要とし、ページビューポートは設定する必要があります。 `100dvh`は、ダイナミックビューポートの高さに従います。 スクロール、ピンチズーム、テキスト選択、クリップボードアクセス、およびターゲットのモバイルブラウザの画面上のキーボードをテストします。 デスクトップエディタを再サイズすると、モバイルプラグインに切り替えません。

`UniverMobileUIPlugin` のデフォルトは `disableAutoFocus: true`、従って編集者は初期化の間に自動的に焦点を合わせません。

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
<div id="app" style="height: 100dvh"></div>
```

## その他のリリース

Univerは、安定したリリースとともにアルファ/ベータチャネルを公開しています。 彼らは、より高いリスクのコストで、公式リリースの前に利用可能な新機能を作成します。 これらのバージョンには、バグ、不完全な機能、または不安定な機能が含まれている可能性があるため、可能な限り生産で回避する必要があります。

### Alpha/Beta リリース

Univer チームが新しい機能または重要な変更を完了すると、アルファまたはベータチャネルに作業をプレリリースできます。Univer パッケージのアルファ/ベータ版を次のようにインストールします。

```package-install
npm install @univerjs-pro/slides@alpha # Alpha バージョン
npm install @univerjs-pro/slides@beta # Beta バージョン
```

[GitHubの問題](https://github.com/dream-num/univer/issues)によるUniverチームへのアルファ/ベータ版の問題を報告し、フィードバックを報告して下さい。

[^peer-dependency]: `peerDependencies` は、ホストアプリケーションが互換性のあるバージョンを用意する依存パッケージです。Univer とアプリケーションが React などのライブラリを共有できます。

[^facade-entry]: Facade は、登録済みプラグインの機能をアプリケーションから操作する API です。Facade のエントリをインポートすると API メソッドが追加されますが、機能プラグイン自体は登録されません。

[^mobile-ui-mode]: モバイル UI プラグインは初期化時にタッチ用の部品とサービスを選択します。端末の自動判定や、ウィンドウサイズ変更による既存インスタンスの切り替えは行いません。モードを変更する場合は文書の状態を保存し、旧インスタンスを破棄してから選択したプラグインで初期化します。
