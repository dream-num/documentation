---
title: Подключение Web SDK через CDN
---

UMD строит следующие записи, специфичные для слайдов. Каждый URL-адрес `@univerjs/*` и `@univerjs-pro/*` должен использовать одну и ту же версию.

| Путь UMD | Глобальное пространство имён |
| --- | --- |
| `@univerjs-pro/slides/lib/umd/index.js` | `UniverProSlides` |
| `@univerjs-pro/slides/lib/umd/facade.js` | `UniverProSlidesFacade` |
| `@univerjs-pro/slides/lib/umd/locale/en-US.js` | `UniverProSlidesEnUS` |
| `@univerjs-pro/slides-ui/lib/umd/index.js` | `UniverProSlidesUi` |
| `@univerjs-pro/slides-ui/lib/umd/locale/en-US.js` | `UniverProSlidesUiEnUS` |

Сначала загрузите одноранговые зависимости и совместно используемое время выполнения, затем загрузите каждую зависимость от пакета в явном порядке. `slides` должен прийти до `slides-ui`, каждая локализация должна прийти после принадлежащего ей пакета, а `@univerjs/core/facade` плюс `@univerjs-pro/engine-shape/facade` должны прийти до входа в Фасад слайдов. UMD не разрешает этот граф зависимости автоматически.

Список пакетов, стили, регистрацию плагинов и настройку лицензии смотрите в разделе [Установка и основы использования](/guides/slides/getting-started/installation).
