---
title: 通过 CDN 使用 Web SDK
---

UMD 构建会暴露以下 Slides 专用入口。所有 `@univerjs/*` 和 `@univerjs-pro/*` URL 必须使用同一版本。

| UMD 路径 | 全局命名空间 |
| --- | --- |
| `@univerjs-pro/slides/lib/umd/index.js` | `UniverProSlides` |
| `@univerjs-pro/slides/lib/umd/facade.js` | `UniverProSlidesFacade` |
| `@univerjs-pro/slides/lib/umd/locale/en-US.js` | `UniverProSlidesEnUS` |
| `@univerjs-pro/slides-ui/lib/umd/index.js` | `UniverProSlidesUi` |
| `@univerjs-pro/slides-ui/lib/umd/locale/en-US.js` | `UniverProSlidesUiEnUS` |

先加载 peer 依赖和共享运行时，再按清单顺序逐个加载每个包的依赖。`slides` 必须位于 `slides-ui` 之前，locale 必须位于所属包之后，Slides Facade 入口必须位于 `@univerjs/core/facade` 和 `@univerjs-pro/engine-shape/facade` 之后。UMD 不会自动解析这张依赖图。

包列表、CSS 导入、插件注册和许可证配置，请返回[安装和基本使用](/guides/slides/getting-started/installation)查看。
