---
title: 通过 CDN 引入 Univer Slides
---

UMD 构建会暴露以下 Slides 专用入口。所有 `@univerjs/*` 与 `@univerjs-pro/*` URL 必须使用相同版本。

| UMD 路径 | 全局命名空间 |
| --- | --- |
| `@univerjs-pro/slides/lib/umd/index.js` | `UniverProSlides` |
| `@univerjs-pro/slides/lib/umd/facade.js` | `UniverProSlidesFacade` |
| `@univerjs-pro/slides/lib/umd/locale/en-US.js` | `UniverProSlidesEnUS` |
| `@univerjs-pro/slides-ui/lib/umd/index.js` | `UniverProSlidesUi` |
| `@univerjs-pro/slides-ui/lib/umd/locale/en-US.js` | `UniverProSlidesUiEnUS` |

先加载 peer 依赖与共用运行时，再按清单顺序加载每个包的依赖。`slides` 应早于 `slides-ui`，locale 应位于所属包之后，Slides Facade 入口应位于 `@univerjs/core/facade` 和 `@univerjs-pro/engine-shape/facade` 之后。UMD 不会自动解析这张依赖图。

包列表、CSS、插件注册和许可证配置请返回[安装和基本使用](/guides/slides/getting-started/installation)查看。
