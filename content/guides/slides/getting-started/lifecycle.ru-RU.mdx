## Глобальный жизненный цикл

- **Начинать**: Инициализация продолжается, и бизнес-единицы пока нет.
- **Готовы**: Создано первое бизнес-подразделение. Созданные позднее подразделения не запускают этот этап снова.
- **отданный**: Стандартный пользовательский интерфейс завершил свой первый переключатель рендеринга. Это не означает, что весь асинхронный контент готов.
- **стойкий**: Стандартный пользовательский интерфейс входит в этот этап через некоторое время после Rendered. Он не ждет каждой асинхронной задачи.

### Facade API

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="Что сообщает событие">

`LifeCycleChanged` сообщает о глобальном этапе Univer. Например, когда плагин B загружается после того, как глобальный этап достиг `Ready`, B запускает свой `onReady()`, но второе глобальное событие `Ready` не испускается.

При добавлении слушателя его обратный вызов может сразу же получить текущий этап, в том числе `Starting`. Для получения только текущего этапа звоните `univerAPI.getCurrentLifecycleStage()` напрямую.

</Callout>

Чтобы удалить слушателя, используйте возвращенный объект `disposable`:

```typescript
disposable.dispose()
```

## Хуки жизненного цикла плагинов

Плагин запускает `onStarting()`, когда он загружается, а затем догоняет текущую глобальную стадию. Контролируйте стадию, на которой загружается B, чтобы сравнить свои крючковые вызовы с вызовами A.

<LifecycleDemo />

Общие плагины загружаются при регистрации. Плагины бизнес-типа обычно загружаются до того, как построен первый блок этого типа. Новые плагины для типа, который уже начал загружаться в отложенной партии. Явные зависимости могут вызвать более раннюю загрузку.

Крючки в одной и той же партии называются синхронно, поэтапно и в порядке зависимостей, а Univer не ждет внутри них асинхронных задач.Подтверждают, что конкретный блок, DOM-элемент или ресурс готов перед доступом к нему.
