La arquitectura plugin de Univer expone los servicios de bajo nivel y los modelos de unidad, y Facade API proporciona un punto de entrada más simple que las aplicaciones utilizan directamente. Esta página solo cubre cómo habilitar esa capa en una aplicación de diapositivas; las páginas Core Features describen cómo operar presentaciones y diapositivas.

<Callout type="warning" title="Precaución">
  Algunos métodos Facade son asincrónicos. Cuando el siguiente paso depende del cambio, espere el cambio antes de leer el resultado.
</Callout>

## Modo plugin

### Instalación

Importe la entrada principal de Slides Facade antes de crear el objeto API:

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
```

Paquetes de diapositivas opcionales tales como Tablas, Gráficos, Importación &amp; Exportación, e Impresión documentan sus propias entradas Facade en sus páginas de características.

### Uso

Crear el objeto API después de la instancia Univer y los plugins necesarios se han registrado:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Modo preestablecido

Univer Las diapositivas no proporcionan un modo preestablecido todavía. Las diapositivas se distribuyen como plugins Web SDK, por lo que Facade API está habilitado a través del modo plugin.
