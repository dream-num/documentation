Univer tiene una arquitectura de complementos flexible, pero los servicios internos y los modelos de unidades pueden ser detallados para el código de la aplicación. Facade API proporciona una capa de aplicación más simple para operaciones comunes.

Esta sección explica cómo habilitar Facade API en una aplicación Univer Slides. Las páginas de funciones posteriores describen las principales API de Facade para cada capacidad de Diapositivas. Para obtener la superficie API completa, consulte la referencia de API a nivel de paquete.

<Callout type="warning" title="Caution">
  Algunas API de Facade son asíncronas, especialmente las API que modifican datos. Si necesita leer datos inmediatamente
  después de cambiarlos, use `await` o `.then()`; de lo contrario, es posible que lea el estado obsoleto.
</Callout>

## Modo preestablecido

Univer Slides no proporciona actualmente un modo preestablecido. Slides se distribuye como complementos de Univer Pro, por lo que debe habilitar Facade API a través del modo complemento.

## Modo complemento

### Instalación

En el modo complemento, las implementaciones de Facade API se proporcionan mediante paquetes individuales y se montan en la raíz global de Facade API. Importe la entrada de fachada para cada capacidad de Presentaciones utilizada por su aplicación.

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
import '@univerjs-pro/slides-chart/facade'
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
import '@univerjs-pro/slides-print/facade'
import '@univerjs-pro/slides-table/facade'
```

<Callout type="warning" title="Caution">
  No todos los complementos proporcionan una entrada de fachada. Las páginas de características enumeran la entrada de
  fachada cuando el paquete incluye una.
</Callout>

### Uso

La API de fachada envuelve una instancia de Univer. Cree el objeto API después de registrar la instancia de Univer y los complementos necesarios:

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## API de Diapositivas

### Crear una presentación

Utilice `createPresentation` para crear una unidad de Diapositivas a través de la capa de fachada:

```typescript
const presentation = univerAPI.createPresentation({
  id: 'slide-demo',
  name: 'Slide Demo',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

### Guardar una instantánea

La fachada de la presentación puede guardar la instantánea de Diapositivas actual. Almacene instantáneas como datos persistentes y actualice las presentaciones en ejecución a través de las API de Facade.

```typescript
const snapshot = presentation.save()
```

## Notas sobre el ciclo de vida

No todas las API de Facade se pueden llamar inmediatamente después de la inicialización. Algunas API necesitan que el editor alcance una etapa específica del ciclo de vida:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Run code after the first render.
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Run code after the editor becomes steady.
  }
})
```

## Entradas de fachada relacionadas

- `@univerjs-pro/slides/facade` agrega API de presentación y fachada de diapositivas.
- `@univerjs-pro/slides-table/facade` agrega API de diapositivas relacionadas con tablas.
- `@univerjs-pro/slides-chart/facade` agrega API de diapositivas relacionadas con gráficos.
- `@univerjs-pro/slides-print/facade` agrega API de diapositivas relacionadas con la impresión.
- `@univerjs-pro/exchange-client/facade` agrega API de importación/exportación PPTX utilizadas por los flujos de trabajo de intercambio de diapositivas.
