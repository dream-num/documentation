La arquitectura de plugins de Univer expone servicios y modelos de unidad de bajo nivel, mientras que Facade API ofrece un punto de entrada más sencillo para la aplicación. Esta página solo explica cómo habilitar esa capa en una aplicación de Slides; las páginas de Funciones principales explican cómo operar presentaciones y diapositivas.

<Callout type="warning" title="Precaución">
  Algunos métodos de Facade son asíncronos. Espere una mutación antes de leer el resultado cuando el siguiente paso
  dependa de ese cambio.
</Callout>

## Modo preestablecido

Univer Slides no ofrece actualmente un modo preestablecido. Slides se distribuye como plugins de Univer SDK Pro, por lo que debe habilitar Facade API mediante el modo plugin.

## Modo plugin

### Instalación

Importe la entrada principal de Slides Facade antes de crear el objeto API:

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
```

Los paquetes opcionales de Slides, como Tablas, Gráficos, Importación y exportación e Impresión, documentan sus propias entradas de Facade en sus páginas de funciones.

### Uso

Cree el objeto API después de registrar la instancia de Univer y los plugins necesarios:

```ts
const univerAPI = FUniver.newAPI(univer)
```
