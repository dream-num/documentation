Univer has a flexible plugin architecture, but internal services and unit models can be verbose for application code. Facade API provides a simpler application-facing layer for common operations.

This section explains how to enable Facade API in a Univer Slides application. Later feature pages describe the main Facade APIs for each Slides capability. For the complete API surface, see the package-level API reference.

<Callout type="warning" title="Caution">
  Some Facade APIs are asynchronous, especially APIs that modify data. If you need to read data immediately after
  changing it, use `await` or `.then()`; otherwise you may read stale state.
</Callout>

## Preset mode

Univer Slides does not currently provide a preset mode. Slides is distributed as Univer Pro plugins, so you need to enable Facade API through plugin mode.

## Plugin mode

### Installation

In plugin mode, Facade API implementations are provided by individual packages and mounted onto the global Facade API root. Import the facade entry for every Slides capability used by your application.

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
import '@univerjs-pro/slides-chart/facade'
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
import '@univerjs-pro/slides-print/facade'
import '@univerjs-pro/slides-table/facade'
```

<Callout type="warning" title="Caution">
  Not every plugin provides a facade entry. Feature pages list the facade entry when the package includes one.
</Callout>

### Usage

Facade API wraps a Univer instance. Create the API object after the Univer instance and required plugins are registered:

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Slides APIs

### Create a presentation

Use `createPresentation` to create a Slides unit through the facade layer:

```typescript
const presentation = univerAPI.createPresentation({
  id: 'slide-demo',
  name: 'Slide Demo',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

### Save a snapshot

The presentation facade can save the current Slides snapshot. Store snapshots as persisted data and update running presentations through Facade APIs.

```typescript
const snapshot = presentation.save()
```

## Lifecycle notes

Not every Facade API can be called immediately after initialization. Some APIs need the editor to reach a specific lifecycle stage:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Run code after the first render.
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Run code after the editor becomes steady.
  }
})
```

## Related facade entries

- `@univerjs-pro/slides/facade` adds presentation and slide facade APIs.
- `@univerjs-pro/slides-table/facade` adds table-related slide APIs.
- `@univerjs-pro/slides-chart/facade` adds chart-related slide APIs.
- `@univerjs-pro/slides-print/facade` adds print-related slide APIs.
- `@univerjs-pro/exchange-client/facade` adds PPTX import/export APIs used by Slides exchange workflows.
