Antes de instalar Univer Slides, conoce los cuatro conceptos que estructuran cualquier integración de Slides:

- Complemento
- Instantánea y modelo de datos
- Comando
- API de Facade

## Conceptos básicos [#basic-concepts]

### Complementos

Univer Slides se compone de complementos. `UniverSlidesPlugin` registra el modelo de presentación `UNIVER_SLIDE` y sus comandos principales, mientras que `UniverSlidesUIPlugin` añade la interfaz del editor en el navegador. Añade paquetes opcionales de impresión, tablas, gráficos o importación y exportación solo cuando tu aplicación los necesite.

La interfaz de Slides utiliza internamente servicios de Docs, Drawing y Shape para editar texto y gráficos. Son dependencias técnicas de la pila de Slides; no necesitas experiencia previa con otro producto de Univer.

### Instantánea y modelo de datos

Cada presentación se conserva como una [instantánea `ISlideData`](/guides/slides/model/slide-data). `name` y `defaultPageSize` describen la presentación, `slideOrder` ordena las entradas de `slides`, y las capas reutilizables opcionales se guardan en `masterPages` y `layoutPages`.

Usa `presentation.save()` para obtener la instantánea actual. Una instantánea es un dato persistente, no un modelo activo; modificarla después de iniciar la presentación no actualiza el editor.

### Comando

Los cambios en tiempo de ejecución se ejecutan mediante comandos. Así, la validación del modelo, la actualización de la vista y deshacer y rehacer forman parte del mismo flujo. Los métodos de Facade de Slides preparan los parámetros y ejecutan esos comandos.

<Callout type="warning" title="Precaución">
  No modifiques directamente la instantánea de una presentación activa. Usa los métodos de Facade de Slides o comandos registrados.
</Callout>

### API de Facade

Importa `@univerjs-pro/slides/facade` después de la entrada Facade del núcleo para añadir las API de Slides a `FUniver`. Esta entrada proporciona métodos como `createPresentation()`, `getActivePresentation()` y `getPresentation()`.

Consulta [Uso de la API Facade de Slides](/guides/slides/getting-started/facade) para ver la configuración y los ejemplos completos.

A continuación, continúa con [Instalación y uso básico](/guides/slides/getting-started/installation).
