Antes de instalar Univer Slides, revise los cuatro conceptos que conforman cada integración de diapositivas:

- Complemento
- Instantánea y modelo de datos
- Comando
- API de Facade

## Conceptos básicos [#basic-concepts]

### Complementos

Univer Slides se monta desde plugins. `UniverSlidesPlugin` registra el modelo de presentación `UNIVER_SLIDE` y sus comandos centrales, y `UniverSlidesUIPlugin` proporciona el editor del navegador UI. Los paquetes para impresión, tablas, gráficos, o importación y exportación son opcionales, y se añaden sólo cuando la aplicación los requiere.

Las diapositivas UI utiliza los servicios de Docs, Dibujo y Forma internamente para editar texto y gráficos. Estos servicios son dependencias técnicas de la pila de plugin de diapositivas, y no se requiere experiencia previa con otro producto Univer.

### Instantánea y modelo de datos

Se mantiene una presentación como una sola [instantánea `ISlideData`](/guides/slides/model/slide-data). `name` y `defaultPageSize` describen la presentación, `slideOrder` determina el orden de las entradas en `slides`, y las capas reutilizables opcionales se almacenan en `masterPages` y `layoutPages`.

Use `presentation.save()` para leer la instantánea actual. Una instantánea es datos de persistencia en lugar de un modelo de tiempo de ejecución, por lo que cambiar el objeto de instantánea después de la presentación no actualiza el editor.

### Comando

Los cambios de tiempo de ejecución se aplican a través de comandos. Un comando mantiene la validación del modelo, ver actualizaciones, y deshacer y rehacer en un solo oleoducto de cambio.

<Callout type="warning" title="Precaución">
  No modifique la instantánea de una presentación en ejecución directamente. Use Diapositivas Métodos de fachada o comandos registrados.
</Callout>

### API de Facade

Importe `@univerjs-pro/slides/facade` después de la entrada central de Facade para añadir las APIs de diapositivas a `FUniver`. Esta entrada proporciona métodos como `createPresentation()`, `getActivePresentation()` y `getPresentation()` .

Consulta [Uso de la API Facade de Slides](/guides/slides/getting-started/facade) para ver la configuración y los ejemplos completos.
