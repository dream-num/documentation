Univer Slides wird als Teil von Univer Pro vertrieben. Im Gegensatz zu Univer Sheets und Univer Docs verfügt Slides über keinen separaten Community-Paketsatz: Das Kernmodell, die Benutzeroberfläche und die Funktionspakete befinden sich alle unter dem Geltungsbereich `@univerjs-pro`.

Die Teile der Dokumentation, die sich auf Univer Pro beziehen, sind mit <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} /> gekennzeichnet.

## Was zu installieren ist

Beginnen Sie mit dem Slides-Modell und den UI-Paketen:

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
```

Fügen Sie dann die freigegebenen hinzu Univer-Laufzeit- und Pro-Lizenzpaket, das von einem Browser-Editor verwendet wird:

```bash
pnpm add @univerjs/core @univerjs/engine-render @univerjs/ui
pnpm add @univerjs/docs @univerjs/docs-ui @univerjs/drawing
pnpm add @univerjs-pro/license
```

Optionale Slides-Funktionen können nur hinzugefügt werden, wenn das Produkt sie benötigt:

```bash
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

## Lizenz-Plugin

Registrieren Sie `UniverLicensePlugin`, bevor Sie Slides-Plugins registrieren:

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
```

## Serverintegration

Einige Pro-Funktionen erfordern eine Univer Pro Server-Bereitstellung, insbesondere Import/Export, Speicherung, Konvertierung und kollaborationsbezogene Arbeitsabläufe. Lesen Sie [Univer Pro Server](/guides/pro/server), bevor Sie diese Funktionen mit dem Produktionsverkehr verbinden.

## Nicht lizenzierte Einschränkungen

Wenn Univer Pro nicht lizenziert ist, sind die Slides-Funktionen möglicherweise eingeschränkt:

| Funktion | Nicht lizenzierte Einschränkungen |
| --- | --- |
| Folieneditor | Watermark |
| Printing | Wasserzeichen<br />Nicht mehr als 3 Seiten pro Druck |
| Charts | Wasserzeichen<br />Nur grundlegende Diagrammtypen verfügbar |
| Tables | Watermark |
| Importieren und Exportieren | Wasserzeichen<br />Serverseitige Konvertierung und Dateigrößenbeschränkungen hängen von der Pro-Bereitstellung ab. |

Informationen zur Lizenzierung von Univer Pro finden Sie auf der [Univer Pro-Preisseite](/guides/pro).
