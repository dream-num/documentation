Univer Slides는 Univer Pro의 일부로 배포됩니다. Univer Sheets 및 Univer Docs와 달리 Slides에는 별도의 커뮤니티 패키지 세트가 없습니다. 핵심 모델, UI 및 기능 패키지가 모두 `@univerjs-pro` 범위에 포함됩니다.

문서에서 Univer Pro와 관련된 부분은 <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} /> 아이콘으로 표시됩니다.

## 설치할 항목

먼저 Slides 모델과 UI 패키지를 설치합니다.

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
```

그런 다음 브라우저 편집기에서 사용하는 공통 Univer 런타임과 Pro 라이선스 패키지를 추가합니다.

```bash
pnpm add @univerjs/core @univerjs/engine-render @univerjs/ui
pnpm add @univerjs/docs @univerjs/docs-ui @univerjs/drawing
pnpm add @univerjs-pro/license
```

선택적 Slides 기능은 제품에서 필요할 때만 추가할 수 있습니다.

```bash
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

## 라이선스 플러그인

Slides 플러그인보다 먼저 `UniverLicensePlugin`을 등록하세요.

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
```

## 서버 통합

일부 Pro 기능, 특히 가져오기/내보내기, 저장소, 변환 및 협업 관련 워크플로에는 Univer Pro Server 배포가 필요합니다. 이러한 기능을 프로덕션 트래픽에 연결하기 전에 [Univer Pro Server](/guides/pro/server)를 참고하세요.

## 라이선스가 없을 때의 제한 사항

Univer Pro 라이선스가 없으면 Slides 기능이 제한될 수 있습니다.

| 기능 | 라이선스가 없을 때의 제한 사항 |
| --- | --- |
| Slides 편집기 | 워터마크 |
| 인쇄 | 워터마크<br />한 번에 최대 3페이지만 인쇄 가능 |
| 차트 | 워터마크<br />기본 차트 유형만 사용 가능 |
| 표 | 워터마크 |
| 가져오기 및 내보내기 | 워터마크<br />서버 측 변환 및 파일 크기 제한은 Pro 배포 환경에 따라 다름 |

Univer Pro 라이선스에 대한 자세한 내용은 [Univer Pro 가격 페이지](/guides/pro)를 참고하세요.
