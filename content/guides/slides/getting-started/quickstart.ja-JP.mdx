Univer Slides をインストールする前に、すべての Slides の統合を形作る 4 つのコンセプトを確認します。

- プラグイン
- スナップショットとデータモデル
- コマンド
- Facade API

## 基本概念 [#basic-concepts]

### プラグイン

Univerスライドはプラグインから組み立てられます。`UniverSlidesPlugin`は`UNIVER_SLIDE`プレゼンテーションモデルとそのコアコマンドを登録し、`UniverSlidesUIPlugin`ではブラウザエディタUIを提供します。印刷、テーブル、チャート、またはインポートとエクスポートのパッケージはオプションで、アプリケーションがそれらを必要とする場合にのみ追加されます。

Slides UI は、テキストやグラフィックを編集するために内部で Docs, Drawing, Shape を内部で使用しています。これらのサービスは、Slides プラグインのスタックの技術的依存性であり、別の Univer 製品で以前の経験は必要ありません。

### スナップショットとデータモデル

プレゼンテーションは単一として主張されます [`ISlideData` スナップショット](/guides/slides/model/slide-data). `name` そして、 `defaultPageSize` プレゼンテーションを記述して下さい、 `slideOrder` エントリの順序を決定する `slides`、および任意再使用可能な層はで貯えられます `masterPages` そして、 `layoutPages`.

`presentation.save()` を使用して、現在のスナップショットを読み取ります。スナップショットはランタイムモデルではなく、持続的なデータなので、プレゼンテーションが開始した後のスナップショットオブジェクトを変更してもエディタを更新しません。

### コマンド

コマンドでランタイムの変更が適用されます。 コマンドはモデルの検証、ビューの更新、および undo と redo を 1 つの変更パイプラインで保持します。 コマンドのパラメータをスライドし、コマンドを実行します。

<Callout type="warning" title="キューション">
  実行中のプレゼンテーションのスナップショットを直接変更しないでください。Slides Facadeメソッドまたは登録されたコマンドを使用してください。
</Callout>

### Facade API

`FUniver` に Slides API を追加するには、コアファサードエントリの後に `@univerjs-pro/slides/facade`。 このエントリは、`createPresentation()`、`getActivePresentation()`, `getPresentation()`などのメソッドを提供します。

完全な設定と例は [Slides Facade API の使用](/guides/slides/getting-started/facade)を参照してください。

その後、[インストールと基本的な使い方](/guides/slides/getting-started/installation)を続行します。
