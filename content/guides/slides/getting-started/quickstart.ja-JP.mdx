Univer Slides をインストールする前に、Slides 統合の基礎となる 4 つの概念を確認します。

- プラグイン
- スナップショットとデータモデル
- コマンド
- Facade API

## 基本概念 [#basic-concepts]

### プラグイン

Univer Slides はプラグインを組み合わせて構成します。`UniverSlidesPlugin` は `UNIVER_SLIDE` プレゼンテーションモデルと主要なコマンドを登録し、`UniverSlidesUIPlugin` はブラウザー用エディター UI を追加します。印刷、表、グラフ、インポート・エクスポートのパッケージは、必要な機能だけを追加してください。

Slides UI は、テキストや図形の編集に Docs、Drawing、Shape のサービスを内部で利用します。これらは Slides のプラグインスタックに必要な技術的依存関係であり、ほかの Univer 製品を使用した経験は必要ありません。

### スナップショットとデータモデル

1 つのプレゼンテーションは [`ISlideData` スナップショット](/guides/slides/model/slide-data)として保存されます。`name` と `defaultPageSize` がプレゼンテーションを表し、`slideOrder` が `slides` のエントリを並べ、任意の再利用可能な層は `masterPages` と `layoutPages` に保存されます。

現在のスナップショットは `presentation.save()` で取得します。スナップショットは永続化用データであり、実行中のモデルではありません。プレゼンテーション開始後にオブジェクトを変更しても、エディターは更新されません。

### コマンド

実行中の変更はコマンドを通して行います。これにより、モデルの検証、ビューの更新、元に戻す・やり直す操作が同じ変更フローに入ります。Slides の Facade メソッドはパラメーターを準備してコマンドを実行します。

<Callout type="warning" title="注意">
  実行中のプレゼンテーションのスナップショットを直接変更しないでください。Slides の Facade メソッドまたは登録済みコマンドを使用してください。
</Callout>

### Facade API

コアの Facade エントリの後で `@univerjs-pro/slides/facade` をインポートすると、`FUniver` に Slides API が追加されます。このエントリは `createPresentation()`、`getActivePresentation()`、`getPresentation()` などを提供します。

完全な設定と例は [Slides Facade API の使用](/guides/slides/getting-started/facade)を参照してください。
