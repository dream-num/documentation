## 全域生命週期

- **Starting**：初始化正在進行，尚未建立任何業務例項。
- **Ready**：第一個業務例項已建立。之後建立的例項不會再次觸發該階段。
- **Rendered**：標準 UI 已完成首次渲染切換，但這不代表所有非同步內容都已就緒。
- **Steady**：標準 UI 在 Rendered 之後一段時間進入該階段，不會等待所有非同步任務完成。

### Facade API

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="事件監聽的範圍">

`LifeCycleChanged` 報告的是 Univer 的全域性階段。例如，全域性階段已經到達 `Ready` 之後再載入外掛 B，B 會執行自身的 `onReady()`，但不會再次發出全域性 `Ready` 事件。

新增監聽器時，回撥可能立即收到當前階段，`Starting` 也包含在內。如果只需要取得當前階段，直接呼叫 `univerAPI.getCurrentLifecycleStage()`。

</Callout>

要移除監聽器，使用返回的 `disposable` 物件：

```typescript
disposable.dispose()
```

## 外掛生命週期鉤子

外掛載入時執行 `onStarting()`，隨後同步至當前全域性階段。控制 B 的載入階段，即可對比它與 A 的鉤子呼叫。

<LifecycleDemo />

通用外掛在註冊時載入。業務型別外掛通常在首次構造該型別的例項之前載入。型別已經啟動後新增的外掛會延遲批次載入。顯式依賴可能使載入提前。

同一批外掛的鉤子按依賴順序逐階段同步呼叫，Univer 不會等待其中的非同步任務。訪問具體的例項、DOM 元素或資源之前，應先確認其已就緒。
