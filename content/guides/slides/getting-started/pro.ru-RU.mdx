Univer Slides распространяется как часть Univer Pro. В отличие от Univer Sheets и Univer Docs, для Slides нет отдельного набора пакетов Community Edition: модель, интерфейс и все функциональные пакеты находятся в пространстве имён `@univerjs-pro`.

Разделы документации, относящиеся к Univer Pro, отмечены значком <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} />.

## Что установить

Сначала установите пакеты модели и интерфейса Slides:

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
```

Затем добавьте общую среду выполнения Univer и пакет лицензии Pro, необходимые для редактора в браузере:

```bash
pnpm add @univerjs/core @univerjs/engine-render @univerjs/ui
pnpm add @univerjs/docs @univerjs/docs-ui @univerjs/drawing
pnpm add @univerjs-pro/license
```

Дополнительные возможности Slides можно подключать только тогда, когда они нужны вашему продукту:

```bash
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

## Плагин лицензии

Зарегистрируйте `UniverLicensePlugin` до регистрации плагинов Slides:

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
```

## Интеграция с сервером

Для некоторых возможностей Pro требуется развёртывание Univer Pro Server. В первую очередь это касается импорта и экспорта, хранения данных, преобразования файлов и совместной работы. Прежде чем использовать эти возможности в рабочей среде, ознакомьтесь с разделом [Univer Pro Server](/guides/pro/server).

## Ограничения без лицензии

Без лицензии Univer Pro возможности Slides могут быть ограничены:

| Возможность | Ограничения без лицензии |
| --- | --- |
| Редактор Slides | Водяной знак |
| Печать | Водяной знак<br />Не более 3 страниц за одну печать |
| Диаграммы | Водяной знак<br />Доступны только основные типы диаграмм |
| Таблицы | Водяной знак |
| Импорт и экспорт | Водяной знак<br />Ограничения на преобразование на стороне сервера и размер файла зависят от конфигурации Pro |

Подробнее о лицензировании Univer Pro см. на [странице с тарифами Univer Pro](/guides/pro).
