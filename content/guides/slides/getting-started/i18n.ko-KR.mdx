## 인터페이스 언어

`locale`는 메뉴, 도구 팁, 대화 상자 및 기타 번역 UI에 대한 언어 팩을 선택합니다. `locales`은 하나를 선택하지 않고 언어 팩을 등록합니다. 이 설정은 Univer 인스턴스에 속하며 인스턴스의 모든 단위에 의해 공유됩니다. `LocaleType` 값을 `LocaleType.EN_US`와 같은 사용하십시오.

- **모든 제품: UI**: `locale`은 메뉴, 도구 설명, 대화 상자와 플러그인 레이블의 번역을 바꿉니다. 사용자 콘텐츠나 기존 단위 이름은 바꾸지 않습니다.
- **장: 세포 체재 및 공식** : 셀이 숫자 또는 날짜를 렌더링 할 때 Univer는 먼저 번호 형식 로컬 오버라이드를 확인하고 작업 책 스냅 샷 `locale`, 그리고 마지막으로 `locale`를 확인합니다. `region`은 이러한 모든 것을 대체하지 않습니다. `DOLLAR`와 같은 공식은 금융 결과에 적용되는 통화 형식과 함께 여전히 `locale`XZ를 따르십시오. CJK는 동일한 방식으로 동작합니다.
- **Docs: 통계**: `locale`는 단어 세그먼트와 계산을 결정합니다.

### 실행 중 언어 변경

모든 언어 팩을 설치 플러그인 또는 전환하기 전에 미리 설정. `loadLocales()`는 현재 언어를 변경하지 않고 번역을 병합; `setLocale()`은 어떤 데이터를 다운로드하지 않고 언어를 선택. 누락 된 번역 키는 키 자체로 표시됩니다. 공유 UI 팩을로드 아래의 예. 다른 플러그인이 설치되어 있다면, 동일한 통화로 대상 언어 팩을 병합하십시오.

```typescript
import { LocaleType, mergeLocales } from '@univerjs/core'
import UIEnUS from '@univerjs/ui/locale/en-US'

univerAPI.loadLocales(LocaleType.EN_US, mergeLocales(UIEnUS))
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentLocale()) // enUS
```

### 사용자 지정 언어 팩

Univer는 또한 주문 언어 팩을 지원합니다. 필요한 언어 팩 객체를 조립하고 `Univer` 인스턴스로 전달하십시오. 미리 설정 언어 팩은 `<rootDir>/packages/<PLUGIN_NAME>/locale` 디렉토리에 일반적으로 저장됩니다.

```typescript
import { LocaleType, Univer } from '@univerjs/core'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: {
      ui: {
        shortcut: {
          undo: '元に戻す',
          redo: 'やり直す',
        },
      },
    },
  },
})
```

### 번역 기여하기

Univer는 다음과 같은 내장 언어 팩을 제공합니다:

- `zh-CN`: 중국어 간체
- `en-US`: 영어
- `zh-TW`: 중국어 번체
- `zh-HK`: 중국어 번체(홍콩)
- `ru-RU`: 러시아어
- `vi-VN`: 베트남어
- `fa-IR`: 페르시아어
- `fr-FR`: 프랑스어
- `ja-JP`: 일본어
- `ko-KR`: 한국어
- `es-ES`: 스페인어
- `ca-ES`: 카탈루냐어
- `sk-SK`: 슬로바키아어
- `ar-SA`: 아랍어
- `de-DE`: 독일어
- `id-ID`: 인도네시아어
- `it-IT`: 이탈리아어
- `pl-PL`: 폴란드어
- `pt-BR`: 포르투갈어(브라질)

다른 언어는 아직 지원되지 않습니다. Univer는 오픈 소스 프로젝트이며, 모든 지역에서 개발자는 언어 팩을 추가하거나 개선할 수 있습니다.

## 지역 설정

`region`는 지역 기능에 의해 사용되는 지역 협약을 선택합니다. `locale` 처럼, 그것은 Univer 인스턴스에 속하고 인스턴스에 있는 모든 단위에 의해 공유됩니다.

둘 다 조정은 `LocaleType` 가치를 가지고 갑니다. 예를 들면, `LocaleType.EN_US`의 가치는 `enUS`이고, `en-US`는 언어 팩 파일 이름과 BCP 47 꼬리표입니다. `region`로 `US` `SG`와 같은 국가 코드를 통과하지 마십시오. UI가 다른 언어를 사용하는 경우, 지역은 그것의 자신의 언어 팩을 요구하지 않습니다.

`region`가 명시적으로 설정되지 않을 때, `locale`를 다음과 같은 `setLocale()` 통화를 포함합니다. `region`는 초기화 또는 `setRegion()`에서 설정된 경우, 자동 다음의 중지 및 나중에 언어가 선택한 지역을 변경합니다. 공개 API가 자동을 복구하지 않습니다. 두 값이 변경되면 둘 다 설정됩니다.

독일 지역 컨벤션을 사용하는 동안 UI 언어를 유지하려면 `locale` 또는 `new Univer()`의 `createUniver()` 옆에 `region: LocaleType.DE_DE`를 추가하십시오.

```typescript
import { LocaleType } from '@univerjs/core'

univerAPI.setRegion(LocaleType.DE_DE)
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentRegion()) // deDE
```

여기에 UI는 영어 및 지역 형식은 독일어 남아 있습니다. `getCurrentLocale()` 및 `getCurrentRegion()`는 효과적인 식별자를 반환합니다. 한 번에 변경하려면 동일한 `LocaleType` 값을 두 개의 설정기를 호출하십시오.

- **시트: 통화 통제**: `region`는 통화 도구 모음 아이콘, 통화 및 회계 옵션 및 미리보기를 선택하고 통화 명령에 의해 적용된 형식을 선택합니다. 지역 변경은 기존의 셀 형식을 다시 작성하거나 통화 값을 변환하지 않습니다.
- **Docs: 통계**: `region`는 통계 대화 상자 및 상태 표시 줄에 표시된 숫자를 그룹화 분리기를 예로 지정합니다. `region`를 변경하는 것은 계산 규칙을 변경하지 않습니다.
- **스레드 의견, 활성화시**: `region`는 날짜와 시간을 24 시간 시간 시간 및 라틴 손가락을 사용하여 표시하는 방법을 결정합니다; `locale`은 코멘트 UI 텍스트를 결정합니다. 더 적은 변화는 타임스탬프를 저장하고, `region`에는 시간대 조정이 아닙니다.
- **보드, 슬라이드,베이스, PDF**: `locale`는 번역된 UI를 통제합니다. `region`은 통합될 때 실 의견과 같은 그것을, 사용하는 공유한 특징에 유효합니다. 그것은 자동적으로 자료표 또는 활주 원본, 기본적인 분야, 또는 PDF 내용이 아닙니다.

</Callout>

```typescript
univerAPI.setDirection('rtl')
```
