Ce guide couvre les packages Univer Pro pour Slides. Les packages de modèle, d’interface utilisateur et de fonctionnalités décrits ici sont publiés sous l’espace de noms `@univerjs-pro`.

Les parties de la documentation consacrées à Univer Pro sont signalées par <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} />.

## Packages à installer

Commencez par les packages du modèle et de l’interface utilisateur de Slides :

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
```

Ajoutez ensuite l’environnement d’exécution partagé d’Univer ainsi que le package de licence Pro utilisés par l’éditeur dans le navigateur :

```bash
pnpm add @univerjs/core @univerjs/engine-render @univerjs/ui
pnpm add @univerjs/docs @univerjs/docs-ui @univerjs/drawing
pnpm add @univerjs-pro/license
```

Vous pouvez ajouter les fonctionnalités facultatives de Slides uniquement lorsque votre produit en a besoin :

```bash
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

## Plugin de licence

Enregistrez `UniverLicensePlugin` avant les plugins Slides :

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
```

## Intégration au serveur

Certaines fonctionnalités Pro nécessitent un déploiement d’Univer Pro Server, en particulier pour les workflows d’importation et d’exportation, de stockage, de conversion et de collaboration. Consultez la page [Univer Pro Server](/guides/pro/server) avant d’utiliser ces fonctionnalités en production.

## Limitations sans licence

Sans licence Univer Pro, certaines fonctionnalités de Slides peuvent être limitées :

| Fonctionnalité | Limitations sans licence |
| --- | --- |
| Éditeur Slides | Filigrane |
| Impression | Filigrane<br />3 pages maximum par impression |
| Graphiques | Filigrane<br />Seuls les types de graphiques de base sont disponibles |
| Tableaux | Filigrane |
| Importation et exportation | Filigrane<br />Les limites de conversion côté serveur et de taille de fichier dépendent du déploiement Pro |

Pour savoir comment obtenir une licence Univer Pro, consultez la [page des tarifs d’Univer Pro](/guides/pro).
