安裝 Univer Slides 前，請先了解構成 Slides 整合基礎的四個概念：

- 外掛 Plugin
- 快照與資料模型 Snapshot and Data Model
- 命令 Command
- Facade API

## 基本概念 [#basic-concepts]

### 外掛

Univer Slides 由外掛組合而成。`UniverSlidesPlugin` 註冊 `UNIVER_SLIDE` 簡報模型及其核心命令，`UniverSlidesUIPlugin` 則提供瀏覽器編輯器介面。列印、表格、圖表、匯入匯出等選用套件，只需依產品需求加入。

Slides UI 在內部使用 Docs、Drawing 和 Shape 服務來編輯文字與圖形。它們是 Slides 外掛堆疊的技術依賴，不要求你使用過其他 Univer 品類。

### 快照與資料模型

一份簡報以 [`ISlideData` 快照](/guides/slides/model/slide-data)持久化。`name` 與 `defaultPageSize` 描述簡報，`slideOrder` 規定 `slides` 中項目的順序，選用的重複使用層則儲存在 `masterPages` 和 `layoutPages` 中。

使用 `presentation.save()` 取得目前快照。快照是持久化資料，不是執行時模型；簡報啟動後直接修改快照物件不會更新編輯器。

### 命令

執行時的資料變更透過命令執行，讓模型驗證、檢視更新、復原與重做進入同一條變更流程。Slides Facade 方法會替你準備參數並執行對應命令。

<Callout type="warning" title="注意">
  不要直接修改執行中簡報的快照。請使用 Slides Facade 方法或已註冊的命令。
</Callout>

### Facade API

在核心 Facade 入口之後匯入 `@univerjs-pro/slides/facade`，即可把 Slides API 擴充到 `FUniver`。該入口提供 `createPresentation()`、`getActivePresentation()` 和 `getPresentation()` 等方法。

完整設定與範例請參閱[使用 Slides Facade API](/guides/slides/getting-started/facade)。
