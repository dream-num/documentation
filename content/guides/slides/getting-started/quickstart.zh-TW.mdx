安裝 Univer Slides 之前，先了解構成 Slides 整合基礎的四個概念：

- 外掛（Plugin）
- 快照與資料模型（Snapshot and data model）
- 命令（Command）
- Facade API

## 基本概念 [#basic-concepts]

### 外掛

Univer Slides 由外掛組合而成。`UniverSlidesPlugin` 註冊 `UNIVER_SLIDE` 簡報模型及其核心命令，`UniverSlidesUIPlugin` 提供瀏覽器中的編輯器介面。列印、表格、圖表和匯入匯出等包均為可選，僅在應用需要時新增。

Slides UI 在內部使用 Docs、Drawing 和 Shape 服務編輯文字和圖形。這些服務是 Slides 外掛棧的技術依賴，不要求開發者具備其他 Univer 產品的使用經驗。

### 快照與資料模型

一份簡報持久化為一個 [`ISlideData` 快照](/guides/slides/model/slide-data)。`name` 和 `defaultPageSize` 描述這份簡報，`slideOrder` 決定 `slides` 中各條目的順序，可選的複用層儲存在 `masterPages` 和 `layoutPages` 中。

使用 `presentation.save()` 讀取當前快照。快照是持久化資料，不是執行時模型，簡報啟動後修改快照物件不會更新編輯器。

### 命令

執行時變更透過命令完成。模型校驗、檢視更新和撤銷重做由同一條變更鏈路處理。Slides Facade 方法會準備命令參數並執行相應命令。

<Callout type="warning" title="注意">
  不要直接修改執行中簡報的快照。請使用 Slides Facade 方法或已註冊的命令。
</Callout>

### Facade API

在核心 Facade 入口之後匯入 `@univerjs-pro/slides/facade`，即可將 Slides API 新增到 `FUniver`。該入口提供 `createPresentation()`、`getActivePresentation()` 和 `getPresentation()` 等方法。

完整的配置與範例見[使用 Slides Facade API](/guides/slides/getting-started/facade)。
