Before installing Univer Slides, review the four concepts that shape every Slides integration:

- Plugin
- Snapshot and data model
- Command
- Facade API

## Basic concepts [#basic-concepts]

### Plugins

Univer Slides is assembled from plugins. `UniverSlidesPlugin` registers the `UNIVER_SLIDE` presentation model and its core commands, and `UniverSlidesUIPlugin` provides the browser editor UI. Packages for printing, tables, charts, or import and export are optional, and are added only when the application requires them.

The Slides UI uses the Docs, Drawing, and Shape services internally to edit text and graphics. These services are technical dependencies of the Slides plugin stack, and prior experience with another Univer product is not required.

### Snapshot and data model

A presentation is persisted as a single [`ISlideData` snapshot](/guides/slides/model/slide-data). `name` and `defaultPageSize` describe the presentation, `slideOrder` determines the order of the entries in `slides`, and the optional reusable layers are stored in `masterPages` and `layoutPages`.

Use `presentation.save()` to read the current snapshot. A snapshot is persistence data rather than a runtime model, so changing the snapshot object after the presentation has started does not update the editor.

### Command

Runtime changes are applied through commands. A command keeps model validation, view updates, and undo and redo in a single change pipeline. Slides Facade methods prepare the command parameters and execute the commands.

<Callout type="warning" title="Caution">
  Do not modify the snapshot of a running presentation directly. Use Slides Facade methods or registered commands.
</Callout>

### Facade API

Import `@univerjs-pro/slides/facade` after the core Facade entry to add the Slides APIs to `FUniver`. This entry provides methods such as `createPresentation()`, `getActivePresentation()`, and `getPresentation()`.

See [Using the Slides Facade API](/guides/slides/getting-started/facade) for the complete setup and examples.

Then continue with [Installation & Basic Usage](/guides/slides/getting-started/installation).
