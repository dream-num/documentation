Архитектура плагинов Univer раскрывает низкоуровневые сервисы и модели блоков, а Facade API обеспечивает более простую точку входа, которую приложения используют напрямую. Эта страница охватывает только то, как включить этот уровень в приложении Slides; страницы Основные функции описывают, как управлять презентациями и слайдами.

<Callout type="warning" title="Осторожно">
  Некоторые методы Фасада асинхронны.Когда следующий шаг зависит от изменения, дождитесь изменения, прежде чем читать результат.
</Callout>

## Режим плагинов

### Установка

Импортируйте основную точку входа Slides Facade до создания объекта API:

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
```

Дополнительные пакеты слайдов, такие как таблицы, диаграммы, импорт и экспорт и печать, документируют свои собственные записи на страницах с функциями.

### Использование

Создайте объект API после регистрации экземпляра Univer и необходимых плагинов:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Режим предустановки

Univer Slides пока не предоставляет заданный режим. Slides распространяется как плагины Web SDK, поэтому Facade API включен через режим плагина.

## Дальнейшие действия

Продолжайте с [Univer Slides API](/guides/slides/features/core/slides-api) для презентационных блоков и точек входа в общий домен. Добавьте дополнительные API от [Столик](/guides/slides/features/tables), [Диаграммы](/guides/slides/features/charts), [печать](/guides/slides/features/print) и [Импорт и экспорт](/guides/slides/features/import-export) только тогда, когда приложение использует эти пакеты.
