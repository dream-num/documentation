Архитектура плагинов Univer предоставляет низкоуровневые сервисы и модели модулей, а Facade API — более простой вход для приложения. Эта страница описывает только подключение этого слоя в приложении Slides; работа с презентациями и слайдами рассматривается на страницах основных возможностей.

<Callout type="warning" title="Внимание">
  Некоторые методы Facade асинхронны. Если следующий шаг зависит от изменения, дождитесь завершения операции перед
  чтением результата.
</Callout>

## Режим предустановки

Univer Slides пока не предоставляет режим предустановки. Slides распространяется как плагины Univer Pro, поэтому Facade API подключается в режиме плагинов.

## Режим плагинов

### Установка

Импортируйте основную точку входа Slides Facade до создания объекта API:

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
```

Необязательные пакеты Slides, такие как таблицы, диаграммы, импорт и экспорт и печать, описывают собственные точки входа Facade на соответствующих страницах возможностей.

### Использование

Создайте объект API после регистрации экземпляра Univer и необходимых плагинов:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Дальнейшие действия

Перейдите к [Univer Slides API](/guides/slides/features/core/slides-api), чтобы работать с модулями презентаций и общими точками входа предметной области. Подключайте необязательные API [таблиц](/guides/slides/features/tables), [диаграмм](/guides/slides/features/charts), [печати](/guides/slides/features/print), [импорта и экспорта](/guides/slides/features/import-export) только если приложение использует эти пакеты.
