Univer использует гибкую архитектуру плагинов, однако работа с внутренними сервисами и моделями документов может сделать прикладной код громоздким. Facade API предоставляет более простой интерфейс для выполнения распространённых операций в приложении.

В этом разделе описано, как включить Facade API в приложении Univer Slides. На следующих страницах, посвящённых отдельным возможностям Slides, рассматриваются их основные Facade API. Полный перечень API приведён в справочнике соответствующего пакета.

<Callout type="warning" title="Внимание">
  Некоторые методы Facade API работают асинхронно — в особенности те, которые изменяют данные. Если данные нужно прочитать сразу после изменения, используйте `await` или `.then()`, иначе можно получить устаревшее состояние.
</Callout>

## Режим предустановки

В настоящее время Univer Slides не поддерживает режим предустановки. Slides распространяется в виде плагинов Univer Pro, поэтому Facade API необходимо подключать в режиме плагинов.

## Режим плагинов

### Установка

В режиме плагинов реализации Facade API предоставляются отдельными пакетами и подключаются к общему корневому объекту Facade API. Импортируйте точку входа facade для каждой возможности Slides, которую использует ваше приложение.

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
import '@univerjs-pro/slides-chart/facade'
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-print/facade'
import '@univerjs-pro/slides-table/facade'
import '@univerjs-pro/slides-table-ui/facade'
```

<Callout type="warning" title="Внимание">
  Точка входа facade есть не у каждого плагина. Если пакет её предоставляет, она указана на странице соответствующей возможности.
</Callout>

### Использование

Facade API служит оболочкой для экземпляра Univer. Создайте объект API после экземпляра Univer и регистрации необходимых плагинов:

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## API Slides

### Создание презентации

Используйте `createPresentation`, чтобы создать документ Slides через слой facade:

```typescript
const presentation = univerAPI.createPresentation({
  id: 'slide-demo',
  name: 'Slide Demo',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

### Сохранение снимка

Facade презентации позволяет сохранить текущий снимок Slides. Храните снимки как постоянные данные, а открытые презентации обновляйте через Facade API.

```typescript
const snapshot = presentation.save()
```

## Особенности жизненного цикла

Не все методы Facade API можно вызывать сразу после инициализации. Для работы некоторых методов редактор должен достичь определённого этапа жизненного цикла:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Run code after the first render.
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Run code after the editor becomes steady.
  }
})
```

## Связанные точки входа facade

- `@univerjs-pro/slides/facade` добавляет facade API для презентаций и слайдов.
- `@univerjs-pro/slides-table/facade` добавляет API для работы с таблицами на слайдах.
- `@univerjs-pro/slides-table-ui/facade` добавляет вспомогательные API интерфейса для редактирования таблиц.
- `@univerjs-pro/slides-chart/facade` добавляет API для работы с диаграммами на слайдах.
- `@univerjs-pro/slides-print/facade` добавляет API для печати слайдов.
- `@univerjs-pro/exchange-client/facade` добавляет API импорта и экспорта PPTX, используемые в сценариях обмена Slides.
