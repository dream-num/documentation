L'architecture plugin de Univer expose les modèles de services et d'unités de bas niveau, et Facade API fournit un point d'entrée plus simple que les applications utilisent directement. Cette page ne couvre que la façon d'activer ce calque dans une application Slides; les pages Fonctions de base décrivent comment faire fonctionner les présentations et les diapositives.

<Callout type="warning" title="Attention">
  Certaines méthodes Facade sont asynchrones. Lorsque la prochaine étape dépend du changement, attendez le changement avant de lire le résultat.
</Callout>

## Mode plugin

### Installation

Importez le point d'entrée principal de Slides Facade avant de créer l'objet API :

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
```

Les paquets de diapositives optionnels tels que les tableaux, les graphiques, l'importation et l'exportation, et l'impression documentent leurs propres entrées Facade sur leurs pages de fonctionnalités.

### Utilisation

Créer l'objet API après l'instance Univer et les plugins requis ont été enregistrés :

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Mode prédéfini

Univer Slides ne fournit pas encore de mode prédéfini. Slides est distribué sous forme de plugins Web SDK, de sorte que Facade API est activé par le mode plugin.
