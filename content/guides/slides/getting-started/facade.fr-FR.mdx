Univer dispose d’une architecture de plugins flexible, mais l’utilisation des services internes et des modèles d’unités peut alourdir le code d’une application. Facade API fournit une couche plus simple, destinée aux applications, pour les opérations courantes.

Cette section explique comment activer Facade API dans une application Univer Slides. Les pages consacrées aux différentes fonctionnalités présentent ensuite les principales Facade API disponibles pour chacune d’elles. Pour consulter l’intégralité de l’API, reportez-vous à la référence API de chaque package.

<Callout type="warning" title="Attention">
  Certaines Facade API sont asynchrones, notamment celles qui modifient des données. Si vous devez lire les données
  immédiatement après les avoir modifiées, utilisez `await` ou `.then()` ; sinon, vous risquez de lire un état obsolète.
</Callout>

## Mode prédéfini

Univer Slides ne propose actuellement aucun mode prédéfini. Slides étant distribué sous forme de plugins Univer Pro, vous devez activer Facade API en mode avec plugins.

## Mode avec plugins

### Installation

En mode avec plugins, les implémentations de Facade API sont fournies par les différents packages et rattachées à la racine globale de Facade API. Importez le point d’entrée de la façade pour chaque fonctionnalité Slides utilisée par votre application.

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
import '@univerjs-pro/slides-chart/facade'
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
import '@univerjs-pro/slides-print/facade'
import '@univerjs-pro/slides-table/facade'
import '@univerjs-pro/slides-table-ui/facade'
```

<Callout type="warning" title="Attention">
  Tous les plugins ne fournissent pas de point d’entrée pour la façade. Les pages des fonctionnalités indiquent ce point
  d’entrée lorsque le package en contient un.
</Callout>

### Utilisation

Facade API encapsule une instance d’Univer. Créez l’objet API après avoir enregistré l’instance d’Univer et les plugins requis :

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## API Slides

### Créer une présentation

Utilisez `createPresentation` pour créer une unité Slides par l’intermédiaire de la couche de façade :

```typescript
const presentation = univerAPI.createPresentation({
  id: 'slide-demo',
  name: 'Slide Demo',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

### Enregistrer un instantané

La façade de présentation permet d’enregistrer l’instantané actuel de Slides. Stockez les instantanés en tant que données persistantes et mettez à jour les présentations ouvertes au moyen des Facade API.

```typescript
const snapshot = presentation.save()
```

## Remarques sur le cycle de vie

Toutes les Facade API ne peuvent pas être appelées immédiatement après l’initialisation. Certaines nécessitent que l’éditeur atteigne une étape précise de son cycle de vie :

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Run code after the first render.
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Run code after the editor becomes steady.
  }
})
```

## Points d’entrée de façade associés

- `@univerjs-pro/slides/facade` ajoute les API de façade pour les présentations et les diapositives.
- `@univerjs-pro/slides-table/facade` ajoute les API de diapositives liées aux tableaux.
- `@univerjs-pro/slides-table-ui/facade` ajoute les API utilitaires de l’interface de modification des tableaux.
- `@univerjs-pro/slides-chart/facade` ajoute les API de diapositives liées aux graphiques.
- `@univerjs-pro/slides-print/facade` ajoute les API de diapositives liées à l’impression.
- `@univerjs-pro/exchange-client/facade` ajoute les API d’importation et d’exportation PPTX utilisées par les workflows d’échange de Slides.
