L'architecture de plugins d'Univer expose des services et modèles d'unité de bas niveau, tandis que Facade API fournit un point d'entrée plus simple pour l'application. Cette page explique uniquement comment activer cette couche dans une application Slides ; les pages Fonctionnalités principales décrivent les opérations sur les présentations et les diapositives.

<Callout type="warning" title="Attention">
  Certaines méthodes de Facade sont asynchrones. Attendez la fin d'une mutation avant de lire son résultat lorsque
  l'étape suivante dépend de cette modification.
</Callout>

## Mode prédéfini

Univer Slides ne propose pas actuellement de mode prédéfini. Slides est distribué sous forme de plugins Univer Pro ; activez donc Facade API en mode plugin.

## Mode plugin

### Installation

Importez le point d'entrée principal de Slides Facade avant de créer l'objet API :

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
```

Les packages Slides facultatifs, tels que Tableaux, Graphiques, Importation et exportation et Impression, documentent leurs propres points d'entrée Facade dans leurs pages de fonctionnalité.

### Utilisation

Créez l'objet API après avoir enregistré l'instance Univer et les plugins nécessaires :

```ts
const univerAPI = FUniver.newAPI(univer)
```
