Univer 的插件架构提供底层服务和单元模型，Facade API 则为应用提供更简洁的操作入口。本页只介绍如何在 Slides 应用中启用这一层；演示文稿和幻灯片操作由核心功能页面说明。

<Callout type="warning" title="注意">
  部分 Facade 方法是异步的。如果下一步依赖本次变更，请等待变更完成后再读取结果。
</Callout>

## 预设模式

Univer Slides 暂未提供预设模式。Slides 以 Univer SDK Pro 插件形式分发，因此需要通过插件模式启用 Facade API。

## 插件模式

### 安装

创建 API 对象前，先导入 Slides 核心 Facade 入口：

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
```

表格、图表、导入导出和打印等可选 Slides 包会在各自的功能页面说明专用 Facade 入口。

### 使用

注册 Univer 实例和所需插件后，再创建 API 对象：

```ts
const univerAPI = FUniver.newAPI(univer)
```
