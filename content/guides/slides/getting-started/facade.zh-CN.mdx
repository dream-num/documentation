Univer 的插件架构非常灵活，但内部服务和 unit 模型对业务代码来说会显得比较繁琐。Facade API 提供了一层更适合应用侧使用的简化接口。

本小节将介绍如何在 Univer Slides 应用中启用 Facade API。后续的功能章节会列出每个 Slides 能力主要使用的 Facade API；如果你想查看完整 API，请参考对应包的 API 参考文档。

<Callout type="warning" title="注意事项">
  部分 Facade API 是异步的，特别是修改数据的 API。如果你需要在修改数据后立即读取结果，请使用 `await` 或
  `.then()`，否则可能会读取到旧状态。
</Callout>

## 预设模式

Univer Slides 目前不提供预设模式。Slides 作为 Univer Pro 插件提供，因此需要通过插件模式引入 Facade API。

## 插件模式

### 安装

在插件模式下，Facade API 的实现由各个包提供，并挂载到全局的 Facade API 根对象上。应用使用了哪些 Slides 能力，就引入对应的 facade 入口。

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
import '@univerjs-pro/slides-chart/facade'
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
import '@univerjs-pro/slides-print/facade'
import '@univerjs-pro/slides-table/facade'
```

<Callout type="warning" title="注意事项">
  并非所有插件都包含 facade 入口。功能文档会在对应包包含 facade 时说明它的引入方式。
</Callout>

### 使用

Facade API 是对 Univer 实例的封装。你需要在创建 Univer 实例并注册必要插件之后，再用 `FUniver` 包裹该实例：

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Slides API

### 创建演示文稿

使用 `createPresentation` 通过 facade 层创建 Slides unit：

```typescript
const presentation = univerAPI.createPresentation({
  id: 'slide-demo',
  name: 'Slide Demo',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

### 保存快照

presentation facade 可以保存当前 Slides 快照。快照适合作为持久化数据，运行中的演示文稿应通过 Facade API 修改。

```typescript
const snapshot = presentation.save()
```

## 生命周期注意事项

并非所有 Facade API 都可以在初始化后立即调用。有些 API 需要编辑器进入特定生命周期阶段后才能稳定执行：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // 在首次渲染后执行的代码
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // 在编辑器进入稳定状态后执行的代码
  }
})
```

## 相关 facade 入口

- `@univerjs-pro/slides/facade` 增加演示文稿和 slide facade API。
- `@univerjs-pro/slides-table/facade` 增加表格相关 slide API。
- `@univerjs-pro/slides-chart/facade` 增加图表相关 slide API。
- `@univerjs-pro/slides-print/facade` 增加打印相关 slide API。
- `@univerjs-pro/exchange-client/facade` 增加 Slides exchange 流程使用的 PPTX 导入导出 API。
