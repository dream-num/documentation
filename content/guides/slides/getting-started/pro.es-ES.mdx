Univer Slides se distribuye como parte de Univer Pro. A diferencia de Univer Sheets y Univer Docs, Slides no tiene un conjunto de paquetes comunitarios separado: el modelo principal, la interfaz de usuario y los paquetes de funciones se encuentran bajo el alcance `@univerjs-pro`.

Las partes de la documentación relacionadas con Univer Pro están marcadas con <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} />.

## Qué instalar

Comience con el modelo de Slides y los paquetes de UI:

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
```

Luego agregue el Univer compartido tiempo de ejecución y paquete de licencia Pro utilizado por un editor de navegador:

```bash
pnpm add @univerjs/core @univerjs/engine-render @univerjs/ui
pnpm add @univerjs/docs @univerjs/docs-ui @univerjs/drawing
pnpm add @univerjs-pro/license
```

Las capacidades opcionales de Slides se pueden agregar solo cuando el producto las necesita:

```bash
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

## Complemento de licencia

Registrar `UniverLicensePlugin` antes de registrar los complementos de Slides:

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
```

## Integración del servidor

Algunas capacidades Pro requieren una implementación de Univer Pro Server, especialmente flujos de trabajo relacionados con importación/exportación, almacenamiento, conversión y colaboración. Consulte [Univer Pro Server](/guides/pro/server) antes de conectar estas capacidades al tráfico de producción.

## Limitaciones sin licencia

Cuando Univer Pro no tiene licencia, las capacidades de Presentaciones pueden estar restringidas:

| Función | Limitaciones sin licencia |
| --- | --- |
| Editor de diapositivas | Watermark |
| Printing | Marca de agua<br />No más de 3 páginas por impresión |
| Charts | Marca de agua<br />Solo tipos de gráficos básicos están disponibles |
| Tables | Watermark |
| Importar y Exportar | Marca de agua<br />La conversión del lado del servidor y los límites de tamaño de archivo dependen de la implementación Pro |

Para obtener información sobre cómo obtener una licencia de Univer Pro, consulte la [página de precios de Univer Pro](/guides/pro).
