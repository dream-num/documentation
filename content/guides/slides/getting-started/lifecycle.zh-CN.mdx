## 全局生命周期

- **Starting**：初始化正在进行，尚未创建任何业务实例。
- **Ready**：第一个业务实例已创建。之后创建的实例不会再次触发该阶段。
- **Rendered**：标准 UI 已完成首次渲染切换，但这不代表所有异步内容都已就绪。
- **Steady**：标准 UI 在 Rendered 之后一段时间进入该阶段，不会等待所有异步任务完成。

### Facade API

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="事件监听的范围">

`LifeCycleChanged` 报告的是 Univer 的全局阶段。例如，全局阶段已经到达 `Ready` 之后再加载插件 B，B 会执行自身的 `onReady()`，但不会再次发出全局 `Ready` 事件。

添加监听器时，回调可能立即收到当前阶段，`Starting` 也包含在内。如果只需要获取当前阶段，直接调用 `univerAPI.getCurrentLifecycleStage()`。

</Callout>

要移除监听器，使用返回的 `disposable` 对象：

```typescript
disposable.dispose()
```

## 插件生命周期钩子

插件加载时执行 `onStarting()`，随后同步至当前全局阶段。控制 B 的加载阶段，即可对比它与 A 的钩子调用。

<LifecycleDemo />

通用插件在注册时加载。业务类型插件通常在首次构造该类型的实例之前加载。类型已经启动后新增的插件会延迟批量加载。显式依赖可能使加载提前。

同一批插件的钩子按依赖顺序逐阶段同步调用，Univer 不会等待其中的异步任务。访问具体的实例、DOM 元素或资源之前，应先确认其已就绪。
