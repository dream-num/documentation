Univer의 플러그인 아키텍처는 저수준 서비스와 유닛 모델을 제공하고, Facade API는 애플리케이션을 위한 간결한 진입점을 제공합니다. 이 페이지에서는 Slides 애플리케이션에서 해당 계층을 활성화하는 방법만 다룹니다. 프레젠테이션과 슬라이드 작업은 핵심 기능 페이지에서 설명합니다.

<Callout type="warning" title="주의">
  일부 Facade 메서드는 비동기입니다. 다음 단계가 변경 결과에 의존한다면 결과를 읽기 전에 변경 작업이
  끝날 때까지 기다리세요.
</Callout>

## 프리셋 모드

Univer Slides는 현재 프리셋 모드를 제공하지 않습니다. Slides는 Univer Pro 플러그인으로 배포되므로 플러그인 모드에서 Facade API를 활성화하세요.

## 플러그인 모드

### 설치

API 객체를 만들기 전에 Slides 핵심 Facade 진입점을 가져옵니다.

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
```

표, 차트, 가져오기 및 내보내기, 인쇄 같은 선택적 Slides 패키지는 각 기능 페이지에서 전용 Facade 진입점을 설명합니다.

### 사용법

Univer 인스턴스와 필요한 플러그인을 등록한 뒤 API 객체를 만듭니다.

```ts
const univerAPI = FUniver.newAPI(univer)
```
