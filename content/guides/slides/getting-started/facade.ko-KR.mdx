Univer의 플러그인 아키텍처는 저수준 서비스와 단위 모델을 노출하고 Facade API는 응용 프로그램이 직접 사용하는 간단한 항목 포인트를 제공합니다. 이 페이지는 슬라이드 응용 프로그램에 레이어를 활성화하는 방법을 다룹니다. 핵심 기능 페이지는 프레젠테이션과 슬라이드를 작동시키는 방법을 설명합니다.

<Callout type="warning" title="주 메뉴">
  일부 Facade 방법은 비동기입니다. 다음 단계가 변경에 따라 결과의 읽기 전에 변화를 기다립니다.
</Callout>

## 플러그인 모드

### 설치

API 객체를 만들기 전에 Slides 핵심 Facade 진입점을 가져옵니다.

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
```

테이블, 차트, 수입 및 수출 및 인쇄와 같은 옵션 슬라이드 패키지는 자신의 기능 페이지에 자신의 Facade 항목을 인쇄합니다.

### 사용법

Univer 인스턴스 이후 API 객체를 생성하고 필요한 플러그인이 등록되었습니다.

```ts
const univerAPI = FUniver.newAPI(univer)
```

## 프리셋 모드

Univer 슬라이드는 미리 설정 모드를 아직 제공하지 않습니다. 슬라이드는 Web SDK 플러그인으로 배포되므로 Facade API는 플러그인 모드를 통해 활성화됩니다.
