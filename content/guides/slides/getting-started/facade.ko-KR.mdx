Univer는 유연한 플러그인 아키텍처를 제공하지만, 애플리케이션 코드에서 내부 서비스와 유닛 모델을 사용하면 코드가 장황해질 수 있습니다. Facade API는 일반적인 작업을 위한 더 간단한 애플리케이션용 계층을 제공합니다.

이 섹션에서는 Univer Slides 애플리케이션에서 Facade API를 활성화하는 방법을 설명합니다. 뒤에 나오는 기능 페이지에서는 각 Slides 기능의 주요 Facade API를 설명합니다. 전체 API는 패키지별 API 레퍼런스를 참고하세요.

<Callout type="warning" title="주의">
  일부 Facade API, 특히 데이터를 수정하는 API는 비동기 방식으로 작동합니다. 데이터를 변경한 직후 읽어야 한다면 `await`
  또는 `.then()`을 사용하세요. 그렇지 않으면 이전 상태를 읽을 수 있습니다.
</Callout>

## 프리셋 모드

Univer Slides는 현재 프리셋 모드를 제공하지 않습니다. Slides는 Univer Pro 플러그인으로 배포되므로 플러그인 모드에서 Facade API를 활성화해야 합니다.

## 플러그인 모드

### 설치

플러그인 모드에서는 개별 패키지가 Facade API 구현을 제공하며, 이 구현은 전역 Facade API 루트에 연결됩니다. 애플리케이션에서 사용하는 각 Slides 기능의 facade 진입점을 가져오세요.

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
import '@univerjs-pro/slides-chart/facade'
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
import '@univerjs-pro/slides-print/facade'
import '@univerjs-pro/slides-table/facade'
import '@univerjs-pro/slides-table-ui/facade'
```

<Callout type="warning" title="주의">
  모든 플러그인이 facade 진입점을 제공하는 것은 아닙니다. 패키지에 facade 진입점이 포함된 경우 기능 페이지에 해당
  진입점이 안내되어 있습니다.
</Callout>

### 사용법

Facade API는 Univer 인스턴스를 래핑합니다. Univer 인스턴스와 필수 플러그인을 등록한 후 API 객체를 생성하세요.

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Slides API

### 프레젠테이션 만들기

facade 계층을 통해 Slides 유닛을 만들려면 `createPresentation`을 사용하세요.

```typescript
const presentation = univerAPI.createPresentation({
  id: 'slide-demo',
  name: 'Slide Demo',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

### 스냅샷 저장

프레젠테이션 facade는 현재 Slides 스냅샷을 저장할 수 있습니다. 스냅샷을 영구 데이터로 저장하고 Facade API를 통해 실행 중인 프레젠테이션을 업데이트하세요.

```typescript
const snapshot = presentation.save()
```

## 생명 주기 참고 사항

모든 Facade API를 초기화 직후 호출할 수 있는 것은 아닙니다. 일부 API는 편집기가 특정 생명 주기 단계에 도달해야 사용할 수 있습니다.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Run code after the first render.
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Run code after the editor becomes steady.
  }
})
```

## 관련 facade 진입점

- `@univerjs-pro/slides/facade`는 프레젠테이션 및 슬라이드 facade API를 추가합니다.
- `@univerjs-pro/slides-table/facade`는 표 관련 슬라이드 API를 추가합니다.
- `@univerjs-pro/slides-table-ui/facade`는 표 편집 UI 도우미 API를 추가합니다.
- `@univerjs-pro/slides-chart/facade`는 차트 관련 슬라이드 API를 추가합니다.
- `@univerjs-pro/slides-print/facade`는 인쇄 관련 슬라이드 API를 추가합니다.
- `@univerjs-pro/exchange-client/facade`는 Slides 교환 워크플로에서 사용하는 PPTX 가져오기/내보내기 API를 추가합니다.
