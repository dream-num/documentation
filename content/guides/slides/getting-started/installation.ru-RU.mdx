В этой главе описаны установка и основы использования Univer Slides. В отличие от Univer Sheets и Univer Docs, Slides сейчас распространяется как продукт Univer Pro и не поддерживает режим пресетов. Приложение Slides необходимо создавать в режиме плагинов.

Если вы ещё не знакомы с основными концепциями Univer, сначала прочитайте раздел [«Быстрый старт»](/guides/slides/getting-started/quickstart).

## Создание в режиме плагинов

Univer предоставляет Slides в виде набора плагинов. В браузерном редакторе обычно регистрируют общую среду выполнения Univer, плагин лицензии Pro, зависимости Docs и Drawing, а затем плагины модели и интерфейса Slides.

### Использование менеджера пакетов

Если в вашем проекте уже применяются современные инструменты фронтенд-разработки, рекомендуем Vite, esbuild или Webpack 5. Пакеты Slides используют точки входа ESM, поэтому старым сборщикам может потребоваться дополнительная настройка.

#### Установка

Установите минимальный набор пакетов для браузерного редактора Slides:

#### Использование

<Callout type="warning" title="Внимание">
  - Регистрируйте `UniverLicensePlugin` до регистрации плагинов Slides.
  - Импортируйте общие стили интерфейса до стилей интерфейса продукта.
  - Добавляйте необязательные пакеты функций, например печать, таблицы, диаграммы, импорт и экспорт, только тогда, когда они нужны продукту.
</Callout>

<Steps>
  <Step>
    Импортируйте стили, пакеты локализации и необходимые плагины:

    ```typescript
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverSlidesPlugin } from '@univerjs-pro/slides'
    import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
    import SlidesUIEnUS from '@univerjs-pro/slides-ui/locale/en-US'
    import SlidesEnUS from '@univerjs-pro/slides/locale/en-US'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs-pro/slides-ui/lib/index.css'
    ```
  </Step>
  <Step>
    Если вы хотите использовать Facade API, импортируйте его точки входа:

    ```typescript
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/slides/facade'
    ```
  </Step>
  <Step>
    Создайте экземпляр Univer, зарегистрируйте плагины и создайте юнит Slides:

    ```typescript
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          DocsUIEnUS,
          SlidesEnUS,
          SlidesUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
    })

    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)

    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })

    univer.registerPlugin(UniverSlidesPlugin)
    univer.registerPlugin(UniverSlidesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

Объект `univerAPI`, возвращаемый методом `FUniver.newAPI(univer)`, представляет собой Facade API Univer. Используйте его для создания презентаций и вызова API Slides.

#### `univer.registerPlugin`

Метод `univer.registerPlugin` регистрирует плагин в экземпляре Univer. Его можно вызывать отдельно для каждого плагина или передать массив, чтобы зарегистрировать несколько плагинов в одном месте.

```typescript
univer.registerPlugin([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, {
    container: 'app',
  }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverDrawingPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverSlidesPlugin,
  UniverSlidesUIPlugin,
])
```

#### Необязательные пакеты функций

Добавляйте пакеты функций, когда редактору требуются соответствующие возможности:

```shell
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

Примеры регистрации функций приведены в разделах [«Печать»](/guides/slides/features/print), [«Таблицы»](/guides/slides/features/tables), [«Диаграммы»](/guides/slides/features/charts) и [«Импорт и экспорт»](/guides/slides/features/import-export).

#### Отложенная загрузка необязательных плагинов

В режиме плагинов можно отложить загрузку функциональных плагинов до момента, когда они действительно понадобятся продукту:

```typescript
univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

import('@univerjs-pro/slides-chart').then(({ UniverSlidesChartPlugin }) => {
  univer.registerPlugin(UniverSlidesChartPlugin)
})
```

### Использование на сервере

В Node.js регистрируйте плагины модели без плагинов браузерного интерфейса:

```typescript
univer.registerPlugin(UniverSlidesPlugin)
```

Такая конфигурация подходит для обработки снимков состояния, импорта и экспорта на стороне сервера, а также сервисов совместной работы.

## Другие каналы выпуска

Помимо стабильных выпусков, Univer предоставляет каналы alpha, beta и nightly. Они позволяют раньше опробовать будущие возможности, но могут содержать незавершённые или нестабильные функции. Не используйте их в рабочей среде без чёткого плана проверки.

```package-install
npm install @univerjs-pro/slides@alpha
npm install @univerjs-pro/slides@beta
```
