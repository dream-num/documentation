Univer のプラグインアーキテクチャは低レベルのサービスとユニットモデルを提供し、Facade API はアプリケーション向けの簡潔な入口を提供します。このページでは Slides アプリケーションでそのレイヤーを有効にする方法だけを扱います。プレゼンテーションとスライドの操作はコア機能の各ページで説明します。

<Callout type="warning" title="注意">
  一部の Facade メソッドは非同期です。次の処理が変更結果に依存する場合は、結果を読む前に変更処理の
  完了を待ってください。
</Callout>

## プリセットモード

Univer Slides は現在プリセットモードを提供していません。Slides は Univer Pro プラグインとして配布されるため、プラグインモードで Facade API を有効にします。

## プラグインモード

### インストール

API オブジェクトを作成する前に、Slides のコア Facade エントリをインポートします。

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
```

テーブル、グラフ、インポートとエクスポート、印刷などの任意の Slides パッケージについては、それぞれの機能ページで専用の Facade エントリを説明しています。

### 使用方法

Univer インスタンスと必要なプラグインを登録した後で API オブジェクトを作成します。

```ts
const univerAPI = FUniver.newAPI(univer)
```
