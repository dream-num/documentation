Univer のプラグインアーキテクチャは柔軟ですが、内部の service や unit model をそのまま扱うと、アプリケーションコードは複雑になりがちです。Facade API は、よく使う操作をアプリケーション側から扱いやすくするための簡潔な API layer です。

この章では、Univer Slides アプリケーションで Facade API を有効にする方法を説明します。各機能ページでは、その機能で主に使う Facade API を紹介します。完全な API surface は、各パッケージの API reference を参照してください。

<Callout type="warning" title="注意">
  一部の Facade API は非同期です。特にデータを変更する API は Promise を返すことがあります。変更直後にデータを読む場合は `await` または `.then()` を使ってください。そうしないと古い状態を読む可能性があります。
</Callout>

## Preset mode

Univer Slides は現在 preset mode を提供していません。Slides は Univer Pro プラグインとして配布されるため、Facade API は plugin mode で有効にします。

## Plugin mode

### インストール

plugin mode では、Facade API の実装は各パッケージから提供され、グローバルな Facade API root に追加されます。アプリケーションで使う Slides 機能に対応する facade entry を import してください。

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
import '@univerjs-pro/slides-chart/facade'
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-print/facade'
import '@univerjs-pro/slides-table/facade'
```

<Callout type="warning" title="注意">
  すべてのプラグインが facade entry を提供するわけではありません。各機能ページでは、パッケージに facade が含まれる場合に import 方法を示します。
</Callout>

### 使用

Facade API は Univer インスタンスをラップします。Univer インスタンスを作成し、必要なプラグインを登録した後に `FUniver` でラップします。

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Slides API

### プレゼンテーションを作成する

`createPresentation` を使って facade layer から Slides unit を作成します。

```typescript
const presentation = univerAPI.createPresentation({
  id: 'slide-demo',
  name: 'Slide Demo',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

### Snapshot を保存する

presentation facade は現在の Slides snapshot を保存できます。snapshot は永続化データとして保存し、実行中の presentation は Facade API で更新してください。

```typescript
const snapshot = presentation.save()
```

## ライフサイクルの注意点

すべての Facade API が初期化直後に呼び出せるわけではありません。一部の API は、editor が特定の lifecycle stage に到達してから実行する必要があります。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // 初回 render 後に実行するコード
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // editor が steady になった後に実行するコード
  }
})
```

## 関連する facade entry

- `@univerjs-pro/slides/facade` は presentation と slide の facade API を追加します。
- `@univerjs-pro/slides-table/facade` は table 関連の slide API を追加します。
- `@univerjs-pro/slides-chart/facade` は chart 関連の slide API を追加します。
- `@univerjs-pro/slides-print/facade` は print 関連の slide API を追加します。
- `@univerjs-pro/exchange-client/facade` は Slides exchange workflow で使う PPTX import/export API を追加します。
