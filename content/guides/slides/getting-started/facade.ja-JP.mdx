Univerのプラグインアーキテクチャは、低レベルのサービスとユニットモデルを公開し、Facade APIは、アプリケーションが直接使用する簡単なエントリポイントを提供します。このページでは、そのレイヤーをSlidesアプリケーションで有効化する方法のみについて説明します。Core Featuresのページでは、プレゼンテーションやスライドの操作方法について説明します。

<Callout type="warning" title="キューション">
  いくつかのファサードメソッドは非同期です。次のステップが変更に依存すると、結果を読む前に変更が待っています。
</Callout>

## プラグインモード

### インストール

API オブジェクトを作成する前に、Slides のコア Facade エントリをインポートします。

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
```

オプションは、テーブル、チャート、インポート&エクスポート、および印刷文書などのパッケージを機能ページ上に表示します。

### 使用方法

Univerインスタンスと必要なプラグインを登録した後にAPIオブジェクトを作成します。

```ts
const univerAPI = FUniver.newAPI(univer)
```

## プリセットモード

Univer Slidesはプリセットモードをまだ提供していません。スライドはWeb SDKプラグインとして配布されているため、プラグインモードによりFacade APIが有効になっています。
