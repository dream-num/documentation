Univer Slides를 설치하기 전에 Slides 통합의 기반이 되는 네 가지 개념을 알아봅니다.

- 플러그인
- 스냅샷과 데이터 모델
- 명령
- Facade API

## 기본 개념 [#basic-concepts]

### 플러그인

Univer Slides는 플러그인을 조합해 구성합니다. `UniverSlidesPlugin`은 `UNIVER_SLIDE` 프레젠테이션 모델과 핵심 명령을 등록하고, `UniverSlidesUIPlugin`은 브라우저 편집기 UI를 추가합니다. 인쇄, 표, 차트, 가져오기 및 내보내기 패키지는 애플리케이션에 필요한 경우에만 추가하세요.

Slides UI는 텍스트와 그래픽을 편집하기 위해 Docs, Drawing, Shape 서비스를 내부적으로 사용합니다. 이는 Slides 플러그인 스택의 기술적 의존성이며 다른 Univer 제품을 사용해 본 경험은 필요하지 않습니다.

### 스냅샷과 데이터 모델

하나의 프레젠테이션은 [`ISlideData` 스냅샷](/guides/slides/model/slide-data)으로 저장됩니다. `name`과 `defaultPageSize`가 프레젠테이션을 설명하고, `slideOrder`가 `slides` 항목의 순서를 정하며, 선택적 재사용 계층은 `masterPages`와 `layoutPages`에 저장됩니다.

현재 스냅샷은 `presentation.save()`로 가져옵니다. 스냅샷은 영속화 데이터이지 실행 중인 모델이 아니므로 프레젠테이션이 시작된 뒤 스냅샷 객체를 변경해도 편집기는 갱신되지 않습니다.

### 명령

실행 중인 변경은 명령을 통해 수행됩니다. 그러면 모델 검증, 뷰 갱신, 실행 취소 및 다시 실행이 같은 변경 흐름에 참여합니다. Slides Facade 메서드는 매개변수를 준비하고 해당 명령을 실행합니다.

<Callout type="warning" title="주의">
  실행 중인 프레젠테이션의 스냅샷을 직접 변경하지 마세요. Slides Facade 메서드나 등록된 명령을 사용하세요.
</Callout>

### Facade API

코어 Facade 엔트리 다음에 `@univerjs-pro/slides/facade`를 가져오면 `FUniver`에 Slides API가 추가됩니다. 이 엔트리는 `createPresentation()`, `getActivePresentation()`, `getPresentation()` 등의 메서드를 제공합니다.

전체 설정과 예제는 [Slides Facade API 사용](/guides/slides/getting-started/facade)을 참고하세요.

다음으로 [설치 및 기본 사용법](/guides/slides/getting-started/installation)을 진행하세요.
