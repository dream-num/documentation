Univer 슬라이드를 설치하기 전에 모든 슬라이드 통합을 형성하는 4 가지 개념을 검토하십시오.

- 플러그인
- 스냅샷과 데이터 모델
- 명령
- Facade API

## 기본 개념 [#basic-concepts]

### 플러그인

Univer 슬라이드는 플러그인에서 조립됩니다. `UniverSlidesPlugin`는 `UNIVER_SLIDE` 프레젠테이션 모델과 핵심 명령을 등록하고 `UniverSlidesUIPlugin`은 브라우저 편집기 UI를 제공합니다. 인쇄, 테이블, 차트 또는 수입 및 수출을위한 패키지는 선택 사항이며 응용 프로그램이 필요할 때만 추가됩니다.

슬라이드 UI는 텍스트 및 그래픽을 편집하기 위해 내부적으로 Docs, Drawing 및 Shape 서비스를 사용합니다. 이 서비스는 슬라이드 플러그인 스택의 기술 의존성이며 다른 Univer 제품으로 이전 경험은 필요하지 않습니다.

### 스냅샷과 데이터 모델

프레젠테이션은 단일 [`ISlideData` 스냅 샷](/guides/slides/model/slide-data)로 지속됩니다. `name` 및 `defaultPageSize`는 프레젠테이션을 설명하고 `slideOrder`은 `slides`의 항목의 순서를 결정하고, 옵션 재사용 레이어는 `masterPages`와 `layoutPages`에 저장됩니다.

`presentation.save()`를 사용하여 현재 스냅 샷을 읽습니다. 스냅 샷은 실행 모델보다 적성 데이터이므로 프레젠테이션이 시작된 후 스냅 샷 객체를 변경하면 편집기를 업데이트하지 않습니다.

### 명령

실행 시간은 명령을 통해 적용됩니다. 명령은 단일 변경 파이프 라인에서 모델 검증,보기 업데이트 및 undo 및 redo를 유지합니다. 슬라이드 Facade 방법은 명령 매개 변수를 준비하고 명령을 실행합니다.

<Callout type="warning" title="주 메뉴">
  실행 프레젠테이션의 스냅 샷을 직접 수정하지 마십시오. 슬라이드 Facade 방법 또는 등록 명령을 사용하십시오.
</Callout>

### Facade API

`FUniver`에 슬라이드 API를 추가하기 위해 코어 Facade 항목 후 `@univerjs-pro/slides/facade`를 가져 오기. 이 항목은 `createPresentation()`, `getActivePresentation()` 및 `getPresentation()`와 같은 방법을 제공합니다.

전체 설정과 예제는 [Slides Facade API 사용](/guides/slides/getting-started/facade)을 참고하세요.

그런 다음 [설치 및 기본 사용](/guides/slides/getting-started/installation)로 계속됩니다.
