Univer 的外掛架構提供底層服務和單元模型，Facade API 則是應用直接使用的簡化入口。本頁只說明如何在 Slides 應用中啟用這一層；簡報和幻燈片的具體操作由核心功能頁面介紹。

<Callout type="warning" title="注意">
  部分 Facade 方法是非同步的。如果下一步依賴本次變更，應先等待變更完成，再讀取結果。
</Callout>

## 外掛程式模式

### 安裝

建立 API 物件前，先匯入 Slides 核心 Facade 入口：

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
```

表格、圖表、匯入匯出和列印等可選 Slides 包會在各自的功能頁面說明其 Facade 入口。

### 使用

註冊 Univer 執行個體和所需外掛程式後，再建立 API 物件：

```ts
const univerAPI = FUniver.newAPI(univer)
```

## 預設模式

Univer Slides 暫未提供預設模式。Slides 以 Web SDK 外掛的形式分發，因此 Facade API 需要透過外掛模式啟用。
