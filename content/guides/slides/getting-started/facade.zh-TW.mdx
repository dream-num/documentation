Univer 的外掛程式架構提供底層服務和單元模型，Facade API 則為應用程式提供更簡潔的操作入口。本頁只介紹如何在 Slides 應用程式中啟用這一層；簡報和投影片操作由核心功能頁面說明。

<Callout type="warning" title="注意">
  部分 Facade 方法是非同步的。如果下一步依賴本次變更，請等待變更完成後再讀取結果。
</Callout>

## 預設模式

Univer Slides 暫未提供預設模式。Slides 以 Univer Pro 外掛程式形式發佈，因此需要透過外掛程式模式啟用 Facade API。

## 外掛程式模式

### 安裝

建立 API 物件前，先匯入 Slides 核心 Facade 入口：

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
```

表格、圖表、匯入匯出和列印等選用 Slides 套件會在各自的功能頁面說明專用 Facade 入口。

### 使用

註冊 Univer 執行個體和所需外掛程式後，再建立 API 物件：

```ts
const univerAPI = FUniver.newAPI(univer)
```
