Univer Slides は Univer Pro に含まれる製品です。Univer Sheets や Univer Docs と異なり、Slides には独立したコミュニティ版パッケージはありません。Slides のモデル、UI、機能パッケージはすべて `@univerjs-pro` スコープで提供されます。

Univer Pro に関連するドキュメントの部分は、<IconWrapper className="inline-flex" type="pro" size="sm" icon={null} /> でマークされています。

## インストールするパッケージ

まず Slides のモデルと UI パッケージをインストールします。

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
```

ブラウザーエディターでは、共通の Univer runtime と Pro ライセンスパッケージも必要です。

```bash
pnpm add @univerjs/core @univerjs/engine-render @univerjs/ui
pnpm add @univerjs/docs @univerjs/docs-ui @univerjs/drawing
pnpm add @univerjs-pro/license
```

追加機能は、製品で必要になったときだけインストールします。

```bash
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

## ライセンスプラグイン

Slides プラグインを登録する前に、`UniverLicensePlugin` を登録します。

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
```

## サーバー連携

一部の Pro 機能は Univer Pro Server との連携が必要です。特にインポート、エクスポート、ストレージ、変換、共同編集に関わるフローでは事前に [Univer Pro サーバー](/guides/pro/server) を確認してください。

## ライセンス未取得時の制限

ライセンス未取得の場合、Slides 関連の機能には制限がかかることがあります。

| 機能 | ライセンス未取得時の制限 |
| --- | --- |
| Slides エディター | 透かし |
| 印刷 | 透かし<br />1 回の印刷は最大 3 ページ |
| チャート | 透かし<br />基本的なチャートタイプのみ利用可能 |
| テーブル | 透かし |
| インポート & エクスポート | 透かし<br />サーバー側の変換とファイルサイズ制限は Pro デプロイに依存 |

Univer Pro のライセンスについては [Univer Pro 購入ページ](https://univer.ai/pricing) を参照してください。
