安装 Univer Slides 之前，请先了解构成 Slides 集成基础的四个概念：

- 插件 Plugin
- 快照与数据模型 Snapshot and Data Model
- 命令 Command
- Facade API

## 基本概念 [#basic-concepts]

### 插件

Univer Slides 由插件组合而成。`UniverSlidesPlugin` 注册 `UNIVER_SLIDE` 演示文稿模型及其核心命令，`UniverSlidesUIPlugin` 则提供浏览器编辑器界面。打印、表格、图表、导入导出等可选包只需按产品需求添加。

Slides UI 在内部使用 Docs、Drawing 和 Shape 服务来编辑文本与图形。它们是 Slides 插件栈的技术依赖，不要求你使用过其他 Univer 品类。

### 快照与数据模型

一份演示文稿以 [`ISlideData` 快照](/guides/slides/model/slide-data)持久化。`name` 与 `defaultPageSize` 描述演示文稿，`slideOrder` 规定 `slides` 中条目的顺序，可选的复用层则存储在 `masterPages` 和 `layoutPages` 中。

使用 `presentation.save()` 获取当前快照。快照是持久化数据，不是运行时模型；演示文稿启动后直接修改快照对象不会更新编辑器。

### 命令

运行时的数据变更通过命令执行，使模型校验、视图更新、撤销与重做进入同一条变更链路。Slides Facade 方法会为你准备参数并执行对应命令。

<Callout type="warning" title="注意">
  不要直接修改运行中演示文稿的快照。请使用 Slides Facade 方法或已注册的命令。
</Callout>

### Facade API

在核心 Facade 入口之后导入 `@univerjs-pro/slides/facade`，即可把 Slides API 扩展到 `FUniver`。该入口提供 `createPresentation()`、`getActivePresentation()` 和 `getPresentation()` 等方法。

完整配置与示例请参阅 [使用 Slides Facade API](/guides/slides/getting-started/facade)。
