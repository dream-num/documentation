安装 Univer Slides 之前，先了解构成 Slides 集成基础的四个概念：

- 插件（Plugin）
- 快照与数据模型（Snapshot and data model）
- 命令（Command）
- Facade API

## 基本概念 [#basic-concepts]

### 插件

Univer Slides 由插件组合而成。`UniverSlidesPlugin` 注册 `UNIVER_SLIDE` 演示文稿模型及其核心命令，`UniverSlidesUIPlugin` 提供浏览器中的编辑器界面。打印、表格、图表和导入导出等包均为可选，仅在应用需要时添加。

Slides UI 在内部使用 Docs、Drawing 和 Shape 服务编辑文字和图形。这些服务是 Slides 插件栈的技术依赖，不要求开发者具备其他 Univer 产品的使用经验。

### 快照与数据模型

一份演示文稿持久化为一个 [`ISlideData` 快照](/guides/slides/model/slide-data)。`name` 和 `defaultPageSize` 描述这份演示文稿，`slideOrder` 决定 `slides` 中各条目的顺序，可选的复用层存储在 `masterPages` 和 `layoutPages` 中。

使用 `presentation.save()` 读取当前快照。快照是持久化数据，不是运行时模型，演示文稿启动后修改快照对象不会更新编辑器。

### 命令

运行时变更通过命令完成。模型校验、视图更新和撤销重做由同一条变更链路处理。Slides Facade 方法会准备命令参数并执行相应命令。

<Callout type="warning" title="注意">
  不要直接修改运行中演示文稿的快照。请使用 Slides Facade 方法或已注册的命令。
</Callout>

### Facade API

在核心 Facade 入口之后导入 `@univerjs-pro/slides/facade`，即可将 Slides API 添加到 `FUniver`。该入口提供 `createPresentation()`、`getActivePresentation()` 和 `getPresentation()` 等方法。

完整的配置与示例见[使用 Slides Facade API](/guides/slides/getting-started/facade)。
