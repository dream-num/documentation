Avant d'installer Univer Slides, examinez les quatre concepts qui façonnent chaque intégration de Slides :

- Plugin
- Snapshot et modèle de données
- Commande
- Facade API

## Concepts de base [#basic-concepts]

### Plugins

Univer Slides est assemblé à partir de plugins. `UniverSlidesPlugin` enregistre le modèle de présentation `UNIVER_SLIDE` et ses commandes de base, et `UniverSlidesUIPlugin` fournit l'interface de l'éditeur de navigateur. Les paquets pour l'impression, les tables, les graphiques ou l'importation et l'exportation sont optionnels et ne sont ajoutés que lorsque l'application les nécessite.

L'interface utilisateur de Slides utilise les services Docs, Dessin et Forme en interne pour éditer le texte et les graphiques. Ces services sont des dépendances techniques de la pile de plugins de Sliles, et une expérience préalable avec un autre produit Univer n'est pas requise.

### Snapshot et modèle de données

[Snapshot `ISlideData`](/guides/slides/model/slide-data). `name` et `defaultPageSize` décrivent la présentation, `slideOrder` détermine l'ordre des entrées en `slides`, et les couches réutilisables optionnelles sont stockées en `masterPages` et `layoutPages`.

Utilisez `presentation.save()` pour lire l'instantané actuel. Un instantané est des données de persistance plutôt qu'un modèle d'exécution, donc changer l'objet snapshot après le début de la présentation ne met pas à jour l'éditeur.

### Commande

Une commande maintient la validation du modèle, affiche les mises à jour, et annule et refait dans un seul pipeline de changement. Les méthodes Diapositives Facade préparent les paramètres de commande et exécutent les commandes.

<Callout type="warning" title="Attention">
  Ne modifiez pas directement l'instantané d'une présentation en cours d'exécution. Utilisez les méthodes de diapositives Facade ou les commandes enregistrées.
</Callout>

### Facade API

Importez `@univerjs-pro/slides/facade` après l'entrée de base Facade pour ajouter les API Diapositives à `FUniver`. Cette entrée fournit des méthodes telles que `createPresentation()`, `getActivePresentation()` et `getPresentation()` .

Consultez [Utiliser la Facade API de Slides](/guides/slides/getting-started/facade) pour la configuration complète et des exemples.

Puis continuer avec [Installation et utilisation de base](/guides/slides/getting-started/installation).
