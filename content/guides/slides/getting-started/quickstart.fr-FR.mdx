Avant d’installer Univer Slides, découvrez les quatre concepts qui structurent toute intégration Slides :

- Plugin
- Snapshot et modèle de données
- Commande
- Facade API

## Concepts de base [#basic-concepts]

### Plugins

Univer Slides est assemblé à partir de plugins. `UniverSlidesPlugin` enregistre le modèle de présentation `UNIVER_SLIDE` et ses commandes principales, tandis que `UniverSlidesUIPlugin` ajoute l’interface de l’éditeur dans le navigateur. Ajoutez les packages optionnels d’impression, de tableaux, de graphiques ou d’import-export uniquement si votre application en a besoin.

L’interface Slides utilise en interne les services Docs, Drawing et Shape pour modifier le texte et les éléments graphiques. Il s’agit de dépendances techniques de la pile Slides ; aucune expérience préalable avec un autre produit Univer n’est nécessaire.

### Snapshot et modèle de données

Chaque présentation est persistée sous la forme d’un [snapshot `ISlideData`](/guides/slides/model/slide-data). `name` et `defaultPageSize` décrivent la présentation, `slideOrder` ordonne les entrées de `slides`, et les couches réutilisables optionnelles sont stockées dans `masterPages` et `layoutPages`.

Utilisez `presentation.save()` pour obtenir le snapshot actuel. Un snapshot est une donnée de persistance, pas un modèle actif : le modifier après le démarrage de la présentation ne met pas l’éditeur à jour.

### Commande

Les modifications à l’exécution passent par des commandes. La validation du modèle, la mise à jour de la vue et les opérations d’annulation et de rétablissement suivent ainsi le même flux. Les méthodes Facade de Slides préparent les paramètres et exécutent ces commandes.

<Callout type="warning" title="Attention">
  Ne modifiez pas directement le snapshot d’une présentation active. Utilisez les méthodes Facade de Slides ou des commandes enregistrées.
</Callout>

### Facade API

Importez `@univerjs-pro/slides/facade` après l’entrée Facade du noyau pour ajouter les API Slides à `FUniver`. Cette entrée fournit notamment `createPresentation()`, `getActivePresentation()` et `getPresentation()`.

Consultez [Utiliser la Facade API de Slides](/guides/slides/getting-started/facade) pour la configuration complète et des exemples.

Continuez avec [Installation et utilisation de base](/guides/slides/getting-started/installation).
