Univer Slides 屬於 Univer Pro。它和 Univer Sheets、Univer Docs 不同，沒有獨立的社群版套件：Slides 的模型、UI 和功能套件都位於 `@univerjs-pro` scope 下。

文件中與 Univer Pro 相關的部分會以 <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} /> 進行標識。

## 安裝哪些套件

先安裝 Slides 的模型和 UI 套件：

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
```

瀏覽器編輯器還需要通用 Univer runtime 和 Pro 授權套件：

```bash
pnpm add @univerjs/core @univerjs/engine-render @univerjs/ui
pnpm add @univerjs/docs @univerjs/docs-ui @univerjs/drawing
pnpm add @univerjs-pro/license
```

可選能力只在產品需要時再安裝：

```bash
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

## 授權外掛

註冊 Slides 外掛前，先註冊 `UniverLicensePlugin`：

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
```

## 服務端整合

部分 Pro 能力需要配合 Univer Pro Server 使用，尤其是匯入匯出、儲存、轉換和協同相關流程。接入正式流量前，請先參考 [Univer Pro 服務端](/guides/pro/server)。

## 未授權限制

在未獲得許可證的情況下，Slides 相關能力可能會受到限制：

| 功能 | 未授權限制 |
| --- | --- |
| Slides 編輯器 | 水印 |
| 列印 | 水印<br />每次列印不超過 3 頁 |
| 圖表 | 水印<br />僅開放基礎圖表類型 |
| 表格 | 水印 |
| 匯入 & 匯出 | 水印<br />服務端轉換和檔案大小限制取決於 Pro 部署 |

關於 Univer Pro 的授權方式，請參考 [Univer Pro 購買頁面](https://univer.ai/pricing)。
