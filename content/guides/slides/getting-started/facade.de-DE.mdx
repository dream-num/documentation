Univer verfügt über eine flexible Plugin-Architektur, aber interne Dienste und Einheitenmodelle können für Anwendungscode ausführlich sein. Die Facade-API bietet eine einfachere anwendungsorientierte Ebene für allgemeine Vorgänge.

In diesem Abschnitt wird erläutert, wie Sie die Facade-API in einer Univer Slides-Anwendung aktivieren. Auf späteren Funktionsseiten werden die wichtigsten Facade-APIs für jede Slides-Funktion beschrieben. Die vollständige API-Oberfläche finden Sie in der API-Referenz auf Paketebene.

<Callout type="warning" title="Caution">
  Einige Facade-APIs sind asynchron, insbesondere APIs, die Daten ändern. Wenn Sie Daten sofort nach der Änderung lesen
  müssen, verwenden Sie `await` oder `.then()`; Andernfalls wird möglicherweise ein veralteter Status angezeigt.
</Callout>

## Voreingestellter Modus

Univer Slides bietet derzeit keinen voreingestellten Modus. Slides wird als Univer Pro-Plugins vertrieben, daher müssen Sie die Facade-API über den Plugin-Modus aktivieren.

## Plugin-Modus

### Installation

Im Plugin-Modus werden Facade-API-Implementierungen von einzelnen Paketen bereitgestellt und im globalen Facade-API-Stammverzeichnis bereitgestellt. Importieren Sie den Fassadeneintrag für jede Slides-Funktion, die von Ihrer Anwendung verwendet wird.

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'
import '@univerjs-pro/slides-chart/facade'
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
import '@univerjs-pro/slides-print/facade'
import '@univerjs-pro/slides-table/facade'
import '@univerjs-pro/slides-table-ui/facade'
```

<Callout type="warning" title="Caution">
  Nicht jedes Plugin bietet einen Fassadeneintrag. Auf den Funktionsseiten wird der Fassadeneintrag aufgeführt, wenn das
  Paket einen enthält.
</Callout>

### Verwendung

Die Fassaden-API umschließt eine Univer-Instanz. Erstellen Sie das API-Objekt, nachdem die Univer-Instanz und die erforderlichen Plugins registriert sind:

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Slides-APIs

### Erstellen Sie eine Präsentation

Verwenden Sie `createPresentation`, um eine Slides-Einheit über die Fassadenebene zu erstellen:

```typescript
const presentation = univerAPI.createPresentation({
  id: 'slide-demo',
  name: 'Slide Demo',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

### Speichern Sie einen Snapshot

Die Präsentationsfassade kann den aktuellen Slides-Snapshot speichern. Speichern Sie Snapshots als persistente Daten und aktualisieren Sie laufende Präsentationen über Facade-APIs.

```typescript
const snapshot = presentation.save()
```

## Hinweise zum Lebenszyklus

Nicht jede Facade-API kann unmittelbar nach der Initialisierung aufgerufen werden. Bei einigen APIs muss der Editor eine bestimmte Lebenszyklusphase erreichen:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Run code after the first render.
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Run code after the editor becomes steady.
  }
})
```

## Verwandte Fassadeneinträge

- `@univerjs-pro/slides/facade` fügt Präsentations- und Folienfassaden-APIs hinzu.
- `@univerjs-pro/slides-table/facade` fügt tabellenbezogene Folien-APIs hinzu.
- `@univerjs-pro/slides-table-ui/facade` fügt Tabellenbearbeitungs-UI-Hilfs-APIs hinzu.
- `@univerjs-pro/slides-chart/facade` fügt diagrammbezogene Folien-APIs hinzu.
- `@univerjs-pro/slides-print/facade` fügt druckbezogene Folien-APIs hinzu.
- `@univerjs-pro/exchange-client/facade` fügt PPTX-Import-/Export-APIs hinzu, die von Folienaustausch-Workflows verwendet werden.
