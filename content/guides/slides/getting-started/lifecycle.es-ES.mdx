## Ciclo de vida global

- **Comenzar**: La inicialización está en marcha, y no existe aún una unidad de negocio.
- **Listo**: La primera unidad de negocio ha sido creada. Unidades creadas más tarde no activan esta etapa de nuevo.
- **Rendered**: La interfaz de usuario estándar ha completado su primer interruptor de renderizado. Esto no significa que todo el contenido asincrónico esté listo.
- **Tranquila.**: La interfaz de usuario estándar entra en esta etapa algún tiempo después de Rendered. No espera por cada tarea asincrónica.

### API de Facade

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="Qué comunica el evento">

`LifeCycleChanged` reporta la etapa global de Univer. Por ejemplo, cuando el plugin B carga después de la etapa global ha llegado a `Ready`, B ejecuta su `onReady()` pero no se emite un segundo evento global `Ready` .

Cuando se agrega un oyente, su callback puede recibir la etapa actual inmediatamente, incluyendo `Starting`. Para obtener sólo la etapa actual, llame directamente a `univerAPI.getCurrentLifecycleStage()` .

</Callout>

Para eliminar un oyente, utilice el objeto `disposable` devuelto:

```typescript
disposable.dispose()
```

## Hooks del ciclo de vida de plugins

Un plugin funciona `onStarting()` cuando se carga, luego se alcanza hasta la etapa global actual. Controla la etapa en la que se carga B para comparar sus llamadas de gancho con las de A.

<LifecycleDemo />

Los plugins generales cargan en el registro. Los plugins de tipo empresarial suelen cargar antes de que se construya la primera unidad de ese tipo. Nuevos plugins para un tipo que ya ha comenzado a cargar en un lote diferido.

Los ganchos en el mismo lote se llaman sincrónicamente, etapa por etapa y en orden de dependencia, y Univer no espera tareas asincrónicas dentro de ellos. Confirme que la unidad específica, elemento DOM, o recurso está listo antes de acceder a él.
