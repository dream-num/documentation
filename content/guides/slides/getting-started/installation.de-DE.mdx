In diesem Kapitel wird die Installation und grundlegende Verwendung von Univer Slides vorgestellt. Im Gegensatz zu Univer Sheets und Univer Docs wird Slides derzeit als Univer Pro-Produkt vertrieben und bietet keinen voreingestellten Modus. Sie müssen eine Slides-Anwendung mit Plugin-Modus erstellen.

Wenn Sie mit den Kernkonzepten von Univer nicht vertraut sind, lesen Sie zuerst [Schnellstart](/guides/slides/getting-started/quickstart).

## Mit Plugin-Modus erstellen

Univer stellt Slides als eine Reihe von Plugins zur Verfügung. Ein Browser-Editor registriert normalerweise die freigegebene Univer-Laufzeit, das Pro-Lizenz-Plugin, Docs- und Drawing-Abhängigkeiten und dann das Slides-Modell und die UI-Plugins.

### Verwenden Sie einen Paketmanager

Wenn Ihr Projekt bereits moderne Frontend-Tools verwendet, empfehlen wir Vite, esbuild oder Webpack 5. Slides-Pakete basieren auf ESM-Einstiegspunkten, daher erfordern ältere Bundler möglicherweise eine zusätzliche Konfiguration.

#### Installation

Installieren Sie die Minimalpakete für einen Browser Folieneditor:

#### Verwendung

<Callout type="warning" title="Caution">
  - Registrieren Sie `UniverLicensePlugin`, bevor Sie Slides-Plugins registrieren.
  - Importieren Sie das gemeinsame UI-CSS vor dem Produkt-UI-CSS.
  - Optionale Funktionspakete wie Drucken, Tabellen, Diagramme und Import/Export sollten nur hinzugefügt werden, wenn das Produkt sie benötigt.
</Callout>

<Steps>
  <Step>
Importieren Sie Stile, Gebietsschemapakete und die erforderlichen Plugins:

    ```typescript
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverSlidesPlugin } from '@univerjs-pro/slides'
    import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
    import SlidesUIEnUS from '@univerjs-pro/slides-ui/locale/en-US'
    import SlidesEnUS from '@univerjs-pro/slides/locale/en-US'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs-pro/slides-ui/lib/index.css'
    ```
  </Step>
  <Step>
Importieren Sie Fassadeneinträge, wenn Sie Facade verwenden möchten API:

    ```typescript
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/slides/facade'
    ```
  </Step>
  <Step>
Erstellen Sie eine Univer-Instanz, registrieren Sie Plugins und erstellen Sie eine Slides-Einheit:

    ```typescript
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          DocsUIEnUS,
          SlidesEnUS,
          SlidesUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
    })

    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)

    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })

    univer.registerPlugin(UniverSlidesPlugin)
    univer.registerPlugin(UniverSlidesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

Das von `FUniver.newAPI(univer)` zurückgegebene Objekt `univerAPI` ist die Facade-API von Univer. Verwenden Sie es, um Präsentationen zu erstellen und Slides-APIs aufzurufen.

#### `univer.registerPlugin`

`univer.registerPlugin` registriert ein Plugin auf der Univer-Instanz. Sie können es einmal pro Plugin aufrufen oder ein Array übergeben, um mehrere Plugins an einer Stelle zu registrieren.

```typescript
univer.registerPlugin([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, {
    container: 'app',
  }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverDrawingPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverSlidesPlugin,
  UniverSlidesUIPlugin,
])
```

#### Optionale Funktionspakete

Fügen Sie Funktionspakete hinzu, wenn der Editor die entsprechende Funktion benötigt:

```shell
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

Beispiele für die Funktionsregistrierung finden Sie unter [Drucken](/guides/slides/features/print), [Tabellen](/guides/slides/features/tables), [Diagramme](/guides/slides/features/charts) und [Importieren und Exportieren](/guides/slides/features/import-export).

#### Lazy Load optionaler Plugins

Im Plugin-Modus können Sie Feature-Plugins verzögern, bis das Produkt sie tatsächlich benötigt:

```typescript
univer.createUnit(UniverInstanceType.UNIVER_SLIDE, {})

import('@univerjs-pro/slides-chart').then(({ UniverSlidesChartPlugin }) => {
  univer.registerPlugin(UniverSlidesChartPlugin)
})
```

### Serverseitige Nutzung

Registrieren Sie in Node.js die Modell-Plugins und überspringen Sie die Browser-Benutzeroberfläche Plugins:

```typescript
univer.registerPlugin(UniverSlidesPlugin)
```

Dieses Setup eignet sich für die Snapshot-Verarbeitung, den serverseitigen Import/Export und Kollaborationsdienste.

## Andere Release-Kanäle

Neben stabilen Veröffentlichungen bietet Univer Alpha-, Beta- und Nightly-Kanäle an. Mit diesen Kanälen können Sie kommende Funktionen früher testen, sie weisen jedoch möglicherweise unvollständiges oder instabiles Verhalten auf. Vermeiden Sie die Verwendung in der Produktion, es sei denn, Sie haben einen klaren Validierungsplan.

```package-install
npm install @univerjs-pro/slides@alpha
npm install @univerjs-pro/slides@beta
```
