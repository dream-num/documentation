Univer Slides 属于 Univer Pro。它和 Univer Sheets、Univer Docs 不同，没有独立的社区版包：Slides 的模型、UI 和功能包都位于 `@univerjs-pro` 作用域下。

文档中与 Univer Pro 相关的部分会以 <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} /> 进行标识。

## 安装哪些包

先安装 Slides 的模型和 UI 包：

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
```

浏览器编辑器还需要通用 Univer runtime 和 Pro 授权包：

```bash
pnpm add @univerjs/core @univerjs/engine-render @univerjs/ui
pnpm add @univerjs/docs @univerjs/docs-ui @univerjs/drawing
pnpm add @univerjs-pro/license
```

可选能力只在产品需要时再安装：

```bash
pnpm add @univerjs-pro/slides-print
pnpm add @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui
pnpm add @univerjs-pro/slides-exchange-client
```

## 授权插件

注册 Slides 插件前，先注册 `UniverLicensePlugin`：

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
```

## 服务端集成

部分 Pro 能力需要配合 Univer Pro Server 使用，尤其是导入导出、存储、转换和协同相关流程。接入生产流量前，请先参考 [Univer Pro 服务端](/guides/pro/server)。

## 未授权限制

在未获得许可证的情况下，Slides 相关能力可能会受到限制：

| 功能 | 未授权限制 |
| --- | --- |
| Slides 编辑器 | 水印 |
| 打印 | 水印<br />每次打印不超过 3 页 |
| 图表 | 水印<br />仅开放基础图表类型 |
| 表格 | 水印 |
| 导入 & 导出 | 水印<br />服务端转换和文件大小限制取决于 Pro 部署 |

关于 Univer Pro 的授权方式，请参考 [Univer Pro 购买页面](/guides/pro)。
