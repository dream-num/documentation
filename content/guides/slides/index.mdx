## What is Univer Slides

Univer Slides is the presentation product in Univer Pro. It is used to build slide deck editors, presentation viewers, import/export flows, and server-side slide processing on top of the Univer runtime.

Slides is an independent Univer unit type. At runtime you create a `UniverInstanceType.UNIVER_SLIDE` unit, then register the Pro model, UI, and optional feature plugins that match the capabilities you need.

<Callout type="info">
  Univer Slides now lives in the `@univerjs-pro` package scope. Use [Univer Pro](/guides/pro) for license and deployment
  requirements before integrating it into an application.
</Callout>


## Browser Compatibility

Univer is compiled with a target of Chrome 88, but this does not mean it fully supports all mainstream environments. We strive to ensure Univer works well in the following browsers and Node.js environments:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer relies on `Intl.Segmenter`. If your browser or runtime environment does not support it, please add a
  corresponding polyfill first. We recommend using `@formatjs/intl-segmenter`.
</Callout>

If you encounter compatibility issues, please first try to resolve them using the appropriate polyfills. If the issue persists, feel free to [submit an issue](https://github.com/dream-num/univer/issues/new/choose).

## Node.js Compatibility

<Callout type="warning">
  Note: This only applies to running Univer in a Node.js environment and does not apply to cases where Univer is run in
  a browser using build tools based on Node.js.
</Callout>

Univer can run in a Node.js environment, supporting versions v18.17.0 and later.


## What it includes

- Slide data model, page order, masters, layouts, placeholders, shapes, images, and drawing integration
- Browser editor UI for thumbnails, canvas editing, insert tools, context menus, and presentation playback
- Optional table and chart integrations for slide elements
- Print and import/export integrations for Pro deployments
- Facade APIs for creating presentations and operating on slide content

## Install packages

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
pnpm add @univerjs-pro/slides-print @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui @univerjs-pro/slides-exchange-client
```
