## Univer Slides란

Univer Slides는 Univer Pro의 프레젠테이션 제품입니다. Univer 런타임을 기반으로 slide deck 편집기, 프레젠테이션 뷰어, 가져오기/내보내기 흐름, 서버 측 slide 처리를 구축하는 데 사용됩니다.

Slides는 독립적인 Univer unit 유형입니다. 런타임에서 `UniverInstanceType.UNIVER_SLIDE` unit을 만든 다음 필요한 기능에 맞는 Pro 모델, UI, 선택적 기능 플러그인을 등록합니다.

<Callout type="info">
  Univer Slides는 이제 `@univerjs-pro` 패키지 범위에 속합니다. 애플리케이션에 통합하기 전에 [Univer
  Pro](/guides/pro)에서 라이선스 및 배포 요구 사항을 확인하세요.
</Callout>


## 브라우저 호환성

Univer는 Chrome 88을 대상으로 컴파일되지만, 이것이 모든 주요 환경을 완벽하게 지원한다는 의미는 아닙니다. Univer가 다음 브라우저 및 Node.js 환경에서 원활하게 작동하도록 최선을 다하고 있습니다.

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer는 `Intl.Segmenter`에 의존합니다. 브라우저 또는 런타임 환경에서 이를 지원하지 않는다면 먼저 해당 polyfill을
  추가하세요. `@formatjs/intl-segmenter` 사용을 권장합니다.
</Callout>

호환성 문제가 발생하면 먼저 적절한 polyfill을 사용해 해결해 보세요. 문제가 계속되면 언제든지 [이슈를 제출해 주세요](https://github.com/dream-num/univer/issues/new/choose).

## Node.js 호환성

<Callout type="warning">
  참고: 이 내용은 Node.js 환경에서 Univer를 실행하는 경우에만 적용되며, Node.js 기반 빌드 도구를 사용해 브라우저에서
  Univer를 실행하는 경우에는 적용되지 않습니다.
</Callout>

Univer는 Node.js 환경에서 실행할 수 있으며 v18.17.0 이상 버전을 지원합니다.


## 포함된 기능

- Slide 데이터 모델, 페이지 순서, 마스터, 레이아웃, 자리표시자, 도형, 이미지, drawing 통합
- 썸네일, 캔버스 편집, 삽입 도구, 컨텍스트 메뉴, 프레젠테이션 재생을 위한 브라우저 편집기 UI
- Slide 요소를 위한 선택적 표 및 차트 통합
- Pro 배포 환경을 위한 인쇄 및 가져오기/내보내기 통합
- 프레젠테이션을 만들고 slide 콘텐츠를 조작하기 위한 Facade API

## 패키지 설치

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
pnpm add @univerjs-pro/slides-print @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui @univerjs-pro/slides-exchange-client
```
