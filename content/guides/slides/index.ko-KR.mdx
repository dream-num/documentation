## Univer Slides란?

Univer 슬라이드는 Univer Office SDK의 프리젠 테이션 제품입니다. 그것은 건물 슬라이드 데크 편집기, 프리젠 테이션 뷰어 및 수입 및 수출 흐름을 지원하며 Web SDK 런타임을 통해 서버에 슬라이드를 처리 할 수 있습니다.

슬라이드는 [Web SDK](/guides/sheets)에서 실행되며 브라우저 편집기와 서버에서 헤드리스 처리를 제공합니다. [Server SDK](/server)는 협업 및 파일 교환을 추가하고 [AI SDK](/ai)은 에이전트 워크플로우를 다룹니다.

슬라이드는 독립적 인 Web SDK 단위 유형입니다. 런타임에서 당신은 유형 `UniverInstanceType.UNIVER_SLIDE`의 단위를 만들고 그 후에 당신이 필요로 하는 기능 일치 모형, UI 및 선택적인 특징 플러그인을 등록하십시오.

<Callout type="info">
  Univer 슬라이드는 `@univerjs-pro` 패키지 범위에서 발행됩니다. 라이센스 된 기능은 [고객 라이센스](/server/license)가 필요합니다. 응용 프로그램이 협업 또는 파일 변환을 필요로 할 때 [Univer Server SDK](/server)를 추가하십시오.
</Callout>

## 브라우저 호환성

Web SDK는 크롬 88 대상과 컴파일하지만 혼자 컴파일은 모든 주류 환경에 대한 지원을 보장하지 않습니다. Web SDK은 브라우저와 Node.js 버전에서 작동하도록 예정되어 있습니다.

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK는 `Intl.Segmenter`에 의존합니다. 브라우저 또는 실행 환경이 그것을 지원하지 않는 경우, 일치하는 polyfill을 먼저 추가하십시오. `@formatjs/intl-segmenter`가 권장됩니다.
</Callout>

호환성 문제가 발생하면 일치하는 polyfill을 먼저 적용하십시오. 문제가 지속되면 [자주 묻는 질문](https://github.com/dream-num/univer/issues/new/choose).

## Node.js 호환성

<Callout type="warning">
  Node.js에서 직접 Web SDK를 실행하는 유일한 덮개. 그것은 브라우저를 위해 Node.js 기반 빌드 도구 번들 Web SDK가 적용되지 않습니다.
</Callout>

Web SDK는 Node.js v18.17.0 이상에서 실행됩니다.

## 주요 기능

- 발표 모델은 프레젠테이션 정체성, 페이지 크기, 슬라이드 주문, 슬라이드, 마스터 페이지, 레이아웃 페이지, 테마, 전환 및 리소스를 추적합니다.
- 렌더링 및 편집 커버 슬라이드 캔버스, 엄밀, 선택, 클립 보드, 텍스트 및 모양 편집, 정렬 가이드, 및 재생.
- 페이지 및 요소 변경 명령 및 mutations를 통해 이동, 모델 업데이트를 유지, 렌더링, 및 undo 및 redo 동기화.
- Facade API는 프레젠테이션을 만들고, 스냅샷을 저장하고, 응용 프로그램을 통해 슬라이드 및 요소 작업을 노출합니다.
- 테이블, 차트, 인쇄 및 수입 / 수출과 같은 옵션 기능 코어 스택 밖에 유지.

## 문서 읽는 방법

Sidebar는 기본적으로 고급으로 페이지를 나열하므로 응용 프로그램을 구축하면서 주문을 따라갈 수 있습니다. 주문 및 사용 사례에 적용되는 페이지로 이동합니다. Univer 슬라이드를 포함한 제품 사이에 사이드바 스위치의 상단.

오른쪽의 내용의 테이블은 현재 페이지의 섹션 사이에 탐색합니다. 페이지를 신속하게 찾기 위해 상단 또는 검색 단축키 (Ctrl + K 또는 Cmd + K)에서 검색 바를 사용하십시오.

시작하려면 [빠른 시작](/guides/slides/getting-started/installation) 가이드를 읽으십시오.

## 사전 지식

문서는 newcomers에 작성되었지만, 내용이 Web SDK에 집중할 수 있다는 것을 기본으로 가정합니다. 독자는 JavaScript와 생태계를 알아야합니다. 기본 Node.js 지식은 Web SDK가 Node.js에서 실행될 때도 유용합니다.

여러 사람들이 같은 슬라이드를 편집해야 할 때, 또는 응용 프로그램은 공유 역사, 의견, 또는 파일 변환을 필요로하고 [Univer Server SDK](/server)에서 백엔드에 해당 모듈을 추가합니다. 인증, 권한, 저장 및 배포는 응용 프로그램의 책임에 남아 있습니다. 브라우저에서 편집은 혼자 이러한 서비스의 아무도를 필요로한다.
