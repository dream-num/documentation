## Univer Slides란?

Univer Slides는 Univer SDK Pro의 프레젠테이션 제품입니다. Univer SDK 런타임을 기반으로 slide deck 편집기, 프레젠테이션 뷰어, 가져오기/내보내기 흐름, 서버 측 slide 처리를 구축하는 데 사용됩니다.

Slides는 독립적인 Univer SDK unit 유형입니다. 런타임에서 `UniverInstanceType.UNIVER_SLIDE` unit을 만든 다음 필요한 기능에 맞는 Pro 모델, UI, 선택적 기능 플러그인을 등록합니다.

<Callout type="info">
  Univer Slides는 이제 `@univerjs-pro` 패키지 범위에 속합니다. 애플리케이션에 통합하기 전에 [Univer SDK
  Pro](/guides/pro)에서 라이선스 및 배포 요구 사항을 확인하세요.
</Callout>


## 브라우저 호환성

Univer SDK는 Chrome 88을 대상으로 컴파일되지만, 이것이 모든 주요 환경을 완벽하게 지원한다는 의미는 아닙니다. Univer SDK가 다음 브라우저 및 Node.js 환경에서 원활하게 작동하도록 최선을 다하고 있습니다.

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK는 `Intl.Segmenter`에 의존합니다. 브라우저 또는 런타임 환경에서 이를 지원하지 않는다면 먼저 해당 polyfill을
  추가하세요. `@formatjs/intl-segmenter` 사용을 권장합니다.
</Callout>

호환성 문제가 발생하면 먼저 적절한 polyfill을 사용해 해결해 보세요. 문제가 계속되면 언제든지 [이슈를 제출해 주세요](https://github.com/dream-num/univer/issues/new/choose).

## Node.js 호환성

<Callout type="warning">
  참고: 이 내용은 Node.js 환경에서 Univer SDK를 실행하는 경우에만 적용되며, Node.js 기반 빌드 도구를 사용해 브라우저에서
  Univer SDK를 실행하는 경우에는 적용되지 않습니다.
</Callout>

Univer SDK는 Node.js 환경에서 실행할 수 있으며 v18.17.0 이상 버전을 지원합니다.

## 주요 기능

- **프레젠테이션 모델**: 프레젠테이션 ID, 페이지 크기, 슬라이드 순서, 슬라이드, 마스터, 레이아웃, 테마, 전환 효과 및 리소스를 관리합니다.
- **렌더링 및 편집**: 슬라이드 캔버스, 미리 보기, 선택, 클립보드, 텍스트와 도형 편집, 맞춤 안내선 및 슬라이드 쇼를 제공합니다.
- **명령 파이프라인**: 페이지와 요소 변경을 명령과 변형으로 적용하여 모델, 렌더링, 실행 취소 및 다시 실행을 동기화합니다.
- **Facade API**: 애플리케이션용 객체를 통해 프레젠테이션을 생성, 조회, 저장하고 슬라이드와 요소를 조작합니다.
- **플러그인 아키텍처**: 표, 차트, 인쇄, 가져오기 및 내보내기 같은 선택 기능을 핵심 스택과 분리합니다.

## 문서 읽는 방법

화면 왼쪽에는 문서 탐색 메뉴가 있습니다. 문서 페이지는 기초부터 고급 내용까지 순서대로 구성되어 있어 애플리케이션을 만들 때 단계별로 따라갈 수 있습니다. 필요에 따라 원하는 순서로 읽거나 사용 사례에 해당하는 페이지로 바로 이동해도 됩니다. 사이드바 상단에서 Univer Slides를 확인할 수도 있습니다.

화면 오른쪽에는 페이지의 각 섹션으로 쉽게 이동할 수 있는 목차가 있습니다. 페이지를 빠르게 찾으려면 상단 검색창이나 검색 단축키(Ctrl+K 또는 Cmd+K)를 사용하세요.

시작하려면 [빠른 시작](/guides/slides/getting-started/quickstart) 가이드를 확인하세요.

## 사전 지식

이 문서는 초보자도 쉽게 읽을 수 있도록 작성했지만, Univer SDK에 집중해 설명하려면 몇 가지 기본 지식이 필요합니다.

문서를 최대한 활용하려면 JavaScript와 관련 생태계에 대한 기본적인 이해가 있는 것이 좋습니다.

Node.js에서 Univer SDK를 실행하려면 Node.js에 대한 기본적인 이해도 필요합니다.

Univer SDK Pro를 사용하고 Univer Server를 배포하려면 Linux, Docker, Docker Compose(또는 Kubernetes)에 대한 기본적인 이해가 있는 것이 좋습니다.
