## Что такое Univer Slides

Univer Slides — продукт для работы с презентациями в составе Univer Pro. На базе среды выполнения Univer он позволяет создавать редакторы слайдов, средства просмотра презентаций, процессы импорта и экспорта, а также решения для серверной обработки слайдов.

Slides — самостоятельный тип объекта Univer. Во время выполнения вы создаёте объект `UniverInstanceType.UNIVER_SLIDE`, а затем регистрируете плагины модели и интерфейса из состава Pro, а также необязательные функциональные плагины в соответствии с необходимыми возможностями.

<Callout type="info">
  Univer Slides теперь распространяется в пространстве имён пакетов `@univerjs-pro`. Перед интеграцией в приложение
  ознакомьтесь с требованиями к лицензированию и развёртыванию в разделе [Univer Pro](/guides/pro).
</Callout>


## Совместимость с браузерами

Univer компилируется для Chrome 88, но это не означает полной поддержки всех распространённых сред. Мы стремимся обеспечить стабильную работу Univer в следующих браузерах и средах Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer использует `Intl.Segmenter`. Если ваш браузер или среда выполнения не поддерживает этот API, сначала добавьте
  соответствующий полифил. Мы рекомендуем `@formatjs/intl-segmenter`.
</Callout>

Если возникли проблемы с совместимостью, сначала попробуйте устранить их с помощью подходящих полифилов. Если проблема сохраняется, [создайте issue](https://github.com/dream-num/univer/issues/new/choose).

## Совместимость с Node.js

<Callout type="warning">
  Примечание: это относится только к запуску Univer в среде Node.js и не относится к случаям, когда Univer запускается в
  браузере с помощью инструментов сборки на базе Node.js.
</Callout>

Univer может работать в среде Node.js и поддерживает версии v18.17.0 и выше.


## Возможности

- Модель данных слайдов, порядок страниц, образцы, макеты, заполнители, фигуры, изображения и интеграция с графическими объектами
- Интерфейс браузерного редактора с миниатюрами, редактированием на холсте, инструментами вставки, контекстными меню и воспроизведением презентаций
- Необязательная интеграция таблиц и диаграмм в качестве элементов слайдов
- Интеграция печати, импорта и экспорта для развёртываний Pro
- Facade API для создания презентаций и работы с содержимым слайдов

## Установка пакетов

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
pnpm add @univerjs-pro/slides-print @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui @univerjs-pro/slides-exchange-client
```
