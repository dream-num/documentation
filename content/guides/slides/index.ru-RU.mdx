## Что такое Univer Slides

Univer Slides - это продукт для презентации в Univer Office SDK. Он поддерживает создание редакторов слайд-палуб, зрителей презентации, а также импорт и экспорт потоков, и он может обрабатывать слайды на сервере через время выполнения Web SDK .

Слайды работают на [Web SDK](/guides/sheets), который обеспечивает как редактор браузера, так и безголовую обработку на сервере. [Server SDK](/server) добавляет совместную работу и обмен файлами, а [AI SDK](/ai) охватывает рабочие процессы агентов.

Slides - это независимый тип Web SDK. Во время выполнения вы создаете блок типа `UniverInstanceType.UNIVER_SLIDE`, а затем регистрируете модель, пользовательский интерфейс и дополнительные плагины функций, которые соответствуют необходимым вам возможностям.

<Callout type="info">
  Слайды Univer публикуются в рамках пакета `@univerjs-pro`. Лицензируемые функции требуют [клиентская лицензия](/server/license)... Добавьте [Univer Server SDK](/server), когда вашему приложению требуется совместная работа или преобразование файлов.
</Callout>

## Совместимость с браузерами

Web SDK компилируется с целью Chrome 88, но сама по себе компиляция не гарантирует поддержку для каждой основной среды. Web SDK предназначен для работы в браузерах и версиях Node.js, перечисленных ниже:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK полагается на `Intl.Segmenter`. Если браузер или среда выполнения не поддерживает его, сначала добавьте соответствующий полифилл. `@formatjs/intl-segmenter` рекомендуется.
</Callout>

Если возникает проблема совместимости, сначала нанесите соответствующий полифилл. Если проблема сохраняется, [Открыть вопрос](https://github.com/dream-num/univer/issues/new/choose).

## Совместимость с Node.js

<Callout type="warning">
  Это касается только запуска Web SDK непосредственно в Node.js. Он не применяется, когда инструмент сборки на основе Node.js объединяет Web SDK для браузера.
</Callout>

Web SDK работает в Node.js v18.17.0 и позже.

## Основные возможности

- Модель презентации отслеживает идентичность презентации, размер страницы, порядок слайдов, слайды, основные страницы, страницы макета, темы, переходы и ресурсы.
- Рендеринг и редактирование охватывают холст слайда, миниатюры, выбор, буфер обмена, редактировать текст и форму, руководства по выравниванию и воспроизведению.
- Изменения страниц и элементов проходят через команды и мутации, которые поддерживают синхронизацию обновлений моделей, рендеринга и отмены и переделки.
- Facade API создает и находит презентации, сохраняет снимки и раскрывает операции слайдов и элементов через объекты, обращенные к приложениям.
- Дополнительные функции, такие как таблицы, диаграммы, печать и импорт / экспорт, остаются за пределами основного стека.

## Как читать документацию

На боковой панели перечислены страницы от базовых до расширенных, поэтому вы можете следовать им в порядке при создании приложения или читать их в любом порядке и переходить на страницы, которые применяются к вашему варианту использования. Верхняя часть боковой панели переключается между продуктами, включая Univer Slides.

Таблица содержимого справа перемещается между разделами текущей страницы.Чтобы быстро найти страницу, используйте строку поиска вверху или ярлык поиска (Ctrl+K или Cmd+K).

Чтобы начать, прочитайте руководство [Быстрый старт](/guides/slides/getting-started/installation).

## Необходимые знания

Документация написана для новичков, но она предполагает базовый уровень, чтобы контент мог оставаться сосредоточенным на Web SDK. Читатели должны знать JavaScript и его экосистему; базовые знания Node.js также полезны, когда Web SDK будет работать на Node.js .

Когда нескольким людям нужно редактировать одни и те же слайды, или приложение нуждается в общей истории, комментариях или конвертации файлов, добавьте соответствующие модули из [Univer Server SDK](/server) в бэкэнд. Аутентификация, разрешения, хранение и развертывание остаются ответственностью приложения. Редактирование в браузере само по себе не требует ни одной из этих услуг.
