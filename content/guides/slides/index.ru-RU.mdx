## Что такое Univer Slides

Univer Slides — продукт для работы с презентациями в составе Univer SDK Pro. На базе среды выполнения Univer SDK он позволяет создавать редакторы слайдов, средства просмотра презентаций, процессы импорта и экспорта, а также решения для серверной обработки слайдов.

Slides — самостоятельный тип объекта Univer SDK. Во время выполнения вы создаёте объект `UniverInstanceType.UNIVER_SLIDE`, а затем регистрируете плагины модели и интерфейса из состава Pro, а также необязательные функциональные плагины в соответствии с необходимыми возможностями.

<Callout type="info">
  Univer Slides теперь распространяется в пространстве имён пакетов `@univerjs-pro`. Перед интеграцией в приложение
  ознакомьтесь с требованиями к лицензированию и развёртыванию в разделе [Univer SDK Pro](/guides/pro).
</Callout>


## Совместимость с браузерами

Univer SDK компилируется для Chrome 88, но это не означает полной поддержки всех распространённых сред. Мы стремимся обеспечить стабильную работу Univer SDK в следующих браузерах и средах Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK использует `Intl.Segmenter`. Если ваш браузер или среда выполнения не поддерживает этот API, сначала добавьте
  соответствующий полифил. Мы рекомендуем `@formatjs/intl-segmenter`.
</Callout>

Если возникли проблемы с совместимостью, сначала попробуйте устранить их с помощью подходящих полифилов. Если проблема сохраняется, [создайте issue](https://github.com/dream-num/univer/issues/new/choose).

## Совместимость с Node.js

<Callout type="warning">
  Примечание: это относится только к запуску Univer SDK в среде Node.js и не относится к случаям, когда Univer SDK запускается в
  браузере с помощью инструментов сборки на базе Node.js.
</Callout>

Univer SDK может работать в среде Node.js и поддерживает версии v18.17.0 и выше.

## Основные возможности

- **Модель презентации**: управляет идентификатором, размером страницы, порядком слайдов, слайдами, образцами, макетами, темами, переходами и ресурсами.
- **Отображение и редактирование**: предоставляет холст, миниатюры, выделение, буфер обмена, редактирование текста и фигур, направляющие выравнивания и показ слайдов.
- **Конвейер команд**: применяет изменения страниц и элементов через команды и мутации, синхронизируя модель, отображение, отмену и повтор.
- **Facade API**: создаёт, находит и сохраняет презентации, а также предоставляет прикладные объекты для работы со слайдами и элементами.
- **Архитектура плагинов**: отделяет от ядра дополнительные функции — таблицы, диаграммы, печать, импорт и экспорт.

## Как читать документацию

Слева на экране находится панель навигации по документации. Страницы расположены последовательно — от базовых тем к более сложным, поэтому при создании приложения их можно изучать шаг за шагом. При этом вы можете читать их в любом порядке или сразу переходить к тем страницам, которые относятся к вашему сценарию. В верхней части боковой панели также можно выбрать Univer Slides.

Справа на экране находится оглавление, с помощью которого удобно переходить между разделами страницы. Чтобы быстро найти нужную страницу, воспользуйтесь строкой поиска вверху или сочетанием клавиш для поиска (Ctrl+K или Cmd+K).

Для начала ознакомьтесь с руководством [«Быстрый старт»](/guides/slides/getting-started/quickstart).

## Необходимые знания

Хотя наша документация рассчитана на начинающих, для её ясности и сосредоточенности на Univer SDK мы предполагаем некоторый базовый уровень знаний.

Чтобы получить от документации максимум пользы, рекомендуем знать основы JavaScript и его экосистемы.

Если вы хотите запускать Univer SDK в Node.js, также потребуется базовое понимание Node.js.

Если вы хотите попробовать Univer SDK Pro и развернуть Univer Server, рекомендуем знать основы Linux, Docker и Docker Compose (или Kubernetes).
