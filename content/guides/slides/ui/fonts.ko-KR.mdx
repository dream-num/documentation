Slides 텍스트 편집기의 글꼴 패밀리 드롭다운은 Univer 공유 글꼴 목록을 사용합니다. 이 애플리케이션 수준 목록은 `UniverUIPlugin`에서 구성하세요.

## 글꼴 옵션 설정

```ts
import { UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      { value: 'Inter', label: 'Inter', category: 'sans-serif' },
      { value: 'Noto Serif', label: 'Noto Serif', category: 'serif' },
    ],
    override: false,
  },
})
```

`value`는 텍스트 런의 글꼴 패밀리로 기록되고, `label`은 표시 텍스트 또는 i18n 키이며, `category`는 선택 항목을 그룹화할 때 사용합니다.

브라우저 글꼴은 `@font-face`나 스타일시트로 직접 로드하세요. 목록에 이름을 추가해도 글꼴 파일이 다운로드되지 않으며, 사용할 수 없으면 브라우저가 대체 글꼴을 사용합니다.

## Facade API

UI Facade를 로드한 뒤 `addFonts`로 런타임에 옵션을 추가할 수 있습니다.

```ts
univerAPI.addFonts([
  { value: 'Inter', label: 'Inter', category: 'sans-serif' },
])
```

공유 드롭다운은 즉시 업데이트되지만 해당 글꼴 바이트는 로드되지 않습니다.
