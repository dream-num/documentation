Univer n'accepte pas les composants comme arguments pour les fonctions de rendu. Enregistrez un composant via le Facade API, et Univer peut ensuite le trouver à chaque point de montage.

Si vous n'avez pas encore d'instance Facade API, consultez [Facade API](/guides/slides/getting-started/facade).

## Enregistrer des composants personnalisés

```typescript
// [!code word:componentKey]
// [!code word:CustomComponent]
// [!code word:options]
univerAPI.registerComponent(componentKey, CustomComponent, options)
```

`univerAPI.registerComponent` accepte trois paramètres :

- `componentKey`: identifiant unique du composant, utilisé pour le référencer à l'intérieur de Univer.
- `CustomComponent` : le composant lui-même, en tant que composant React, un composant Vue ou un composant Web.
- `options`: paramètres optionnels, tels que le cadre sur lequel dépend le composant.

### Composants React [#react]

Les composants React ne nécessitent aucune configuration supplémentaire. La seule exigence est que le composant est un composant valide React:

```tsx
function ReactComponent(props: Record<string, any>) {
  return <div>Hello Univer!</div>
}

univerAPI.registerComponent('MyReactComponent', ReactComponent)
```

### Composants Vue [#vue]

#### Vue 3.x

Pour enregistrer les composants Vue, installez et enregistrez `UniverVue3AdapterPlugin` à partir du paquet `@univerjs/ui-adapter-vue3` :

```package-install
npm install @univerjs/ui-adapter-vue3
```

```typescript
import { UniverVue3AdapterPlugin } from '@univerjs/ui-adapter-vue3'

univer.registerPlugin(UniverVue3AdapterPlugin)
```

Lors de l'enregistrement d'un composant Vue, définissez l'option `framework` à `'vue3'` :

```tsx
const Vue3Component = defineComponent({
  setup(props) {
    return () => <div>Hello Univer!</div>
  },
})

univerAPI.registerComponent('MyVue3Component', Vue3Component, {
  // [!code word:vue3]
  framework: 'vue3',
})
```

#### Vue 2.x

Vue 2.x est EOL (Fin de vie) et n'est plus entretenu, donc Univer ne fournit pas de plugin d'adaptateur d'interface utilisateur pour lui. Vous pouvez en implémenter un comme plugin personnalisé. L'exemple ci-dessous construit un adaptateur Vue 2x:

```typescript title="ui-adapter-vue2.ts"
import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
import { ComponentManager, UniverUIPlugin } from '@univerjs/ui'
import Vue from 'vue'

/**
 * The plugin that allows Univer to use Vue 2 components as UI components.
 */
@DependentOn(UniverUIPlugin)
export class UniverVue2AdapterPlugin extends Plugin {
  static override pluginName = 'UNIVER_UI_VUE2_ADAPTER_PLUGIN'

  constructor(
    private readonly _config = {},
    @Inject(Injector) protected readonly _injector: Injector,
    @Inject(ComponentManager) protected readonly _componentManager: ComponentManager,
  ) {
    super()
  }

  override onStarting(): void {
    const { createElement, useEffect, useRef } = this._componentManager.reactUtils

    this._componentManager.setHandler('vue2', (component: any) => {
      return (props: Record<string, any>) =>
        createElement(VueComponentWrapper, {
          component,
          props: Object.keys(props).reduce<Record<string, any>>((acc, key) => {
            if (key !== 'key') {
              acc[key] = props[key]
            }
            return acc
          }, {}),
          reactUtils: { createElement, useEffect, useRef },
        })
    })
  }
}

export function VueComponentWrapper(options: {
  component: any
  props: Record<string, any>
  reactUtils: typeof ComponentManager.prototype.reactUtils
}) {
  const { component, props, reactUtils } = options
  const { createElement, useEffect, useRef } = reactUtils

  const domRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!domRef.current) return

    const Constructor = Vue.extend(component)

    const instance = new Constructor({
      data: props,
    })
    instance.$mount()

    domRef.current.appendChild(instance.$el)

    return () => {
      instance.$destroy()
    }
  }, [props])

  return createElement('div', { ref: domRef })
}
```

Enregistrez-le ensuite :

```typescript
import { UniverVue2AdapterPlugin } from './ui-adapter-vue2' // [!code ++]

univer.registerPlugin(UniverUIPlugin)
univer.registerPlugin(UniverVue2AdapterPlugin) // [!code ++]
```

Lors de l'enregistrement d'un composant Vue 2.x, définissez l'option `framework` sur `'vue2'` :

```tsx
const Vue2Component = Vue.component('MyVue2Component', {
  template: '<div>Hello, Univer!</div>',
})

univerAPI.registerComponent('MyVue2Component', Vue2Component, {
  // [!code word:vue2]
  framework: 'vue2',
})
```

### Web Components [#web-component]

Un composant Web doit être conforme à la norme des composants Web. Installez et enregistrez `UniverWebComponentAdapterPlugin` à partir du paquet `@univerjs/ui-adapter-web-component` :

```package-install
npm install @univerjs/ui-adapter-web-component
```

```typescript
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

univer.registerPlugin(UniverWebComponentAdapterPlugin)
```

Lors de l'enregistrement d'un composant Web, définissez l'option `framework` sur `'web-component'` :

```tsx
class WebComponent extends HTMLElement {
  constructor() {
    super()
    const shadow = this.attachShadow({ mode: 'open' })
    const div = document.createElement('div')
    div.textContent = 'Hello Univer!'
    shadow.appendChild(div)
  }
}

univerAPI.registerComponent('my-web-component', WebComponent, {
  // [!code word:web-component]
  framework: 'web-component',
})
```

## Utiliser des composants personnalisés

Les méthodes ci-dessous montent des composants personnalisés dans la propre interface utilisateur de Univer.

<Callout type="warning" title="Attention">
  1. Assurez-vous que Univer a terminé le rendu avant d'appeler l'une de ces méthodes. 2. Enregistrez un composant avant de l'utiliser. 3. Appelez `dispose()` pour nettoyer et supprimer les composants ajoutés; sinon, ils causent des fuites de mémoire.
</Callout>

### Ajouter des éléments de menu personnalisés

La barre de menu supérieure (Ribbon) et le menu à clic droit (Context Menu) peuvent tous deux contenir des composants personnalisés. Fournissez ces éléments de menu à partir de votre propre plugin, enregistrez leurs composants avant d'utiliser, et disposer les enregistrements avec le plugin.

### Remplacer des composants intégrés

<Callout type="error" title="Avertissement">
  Le remplacement des composants intégrés peut entraîner l'arrêt de certaines fonctions. Lisez le code source et la documentation du composant que vous comptez remplacer et procédez avec prudence.
</Callout>

`univerAPI.registerComponent` enregistre par défaut une redéfinition (`override: true`). La redéfinition a priorité sur le composant intégré, que le plugin enregistre sa valeur par défaut avant ou après votre appel. Seule une redéfinition peut être active pour chaque `componentKey`, donc disposer de l'enregistrement précédent avant d'en enregistrer un autre. Appeler `dispose()` sur l'enregistrement retourné restaure la valeur par défaut intégrée, si l'un est enregistré. Passez `{ override: false }` pour enregistrer une valeur par défaut.

Enregistrez une redéfinition avant que la vue correspondante ne s'ouvre pour la première fois. Modifier une inscription ne renverra pas les vues déjà montées.

Par exemple, le code suivant remplace le composant ColorPicker intégré :

```tsx
// Following code only replaces the UI of the built-in ColorPicker component, not its functionality
univerAPI.registerComponent('UI_COLOR_PICKER_COMPONENT', () => <input type="color" />)
```

### Utiliser des composants comme contenu

#### Dans la barre latérale

`univerAPI.openSidebar` ouvre une barre latérale dans l'interface Univer et rend un composant personnalisé à l'intérieur.

```tsx
// [!code word:MyCustomSidebarComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomSidebarComponent', () => <div>Hello Univer!</div>)

const sidebar = univerAPI.openSidebar({
  header: { title: 'My Sidebar' },
  children: { label: 'MyCustomSidebarComponent' },
  onClose: () => {
    console.log('close')
  },
  width: 360,
})

// Later close the sidebar
sidebar.dispose()
```

Référence : [`univerAPI.openSidebar`](/reference/facade/univer#opensidebar)

#### Dans une boîte de dialogue

`univerAPI.openDialog` ouvre une boîte de dialogue qui rend un composant personnalisé.

```tsx
// [!code word:MyCustomDialogComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomDialogComponent', () => <div>Hello Univer!</div>)

const dialog = univerAPI.openDialog({
  id: 'unique-dialog-id', // The unique identifier for the dialog
  draggable: true,
  width: 300,
  title: { title: 'My Dialog' },
  children: {
    label: 'MyCustomDialogComponent',
  },
  destroyOnClose: true,
  preservePositionOnDestroy: true,
  onClose: () => {},
})

// Later close the dialog
dialog.dispose()
```

Référence : [`univerAPI.openDialog`](/reference/facade/univer#opendialog)
