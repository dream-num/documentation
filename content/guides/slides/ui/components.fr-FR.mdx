---
title: Composants personnalisés
description: Univer propose plusieurs méthodes pour intégrer des composants personnalisés, ce qui vous permet d'étendre et d'adapter ses fonctionnalités. Ce guide présente plusieurs méthodes courantes.
icon: '#pro/Component'
---

Univer ne transmet pas directement les composants en tant que paramètres aux fonctions de rendu. Vous devez d'abord les enregistrer dans Univer à l'aide de la Facade API avant de pouvoir les utiliser aux différents points de montage.

Si vous ne savez pas comment obtenir une instance de la Facade API, consultez la page [Facade API](/guides/slides/getting-started/facade).
