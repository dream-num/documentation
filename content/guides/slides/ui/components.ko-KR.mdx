description: Univer는 사용자 정의 컴포넌트를 통합하는 여러 방법을 제공하여 기능을 확장하고 맞춤 설정할 수 있도록 합니다. 이 가이드에서는 자주 사용하는 몇 가지 방법을 소개합니다.
icon: '#pro/Component'

Univer는 컴포넌트를 렌더링 함수에 매개변수로 직접 전달하지 않습니다. 다양한 마운트 지점에서 컴포넌트를 사용하려면 먼저 Facade API를 통해 Univer에 등록해야 합니다.

Facade API 인스턴스를 가져오는 방법을 잘 모르는 경우 [Facade API](/guides/slides/getting-started/facade)를 참고하세요.
