Univer не принимает компоненты в качестве аргументов для рендеринга функций.Зарегистрируйте компонент через Facade API, и Univer затем может найти его в каждой точке монтажа.

Если у вас еще нет экземпляра Facade API, см. [Facade API](/guides/slides/getting-started/facade).

## Регистрация пользовательских компонентов

```typescript
// [!code word:componentKey]
// [!code word:CustomComponent]
// [!code word:options]
univerAPI.registerComponent(componentKey, CustomComponent, options)
```

`univerAPI.registerComponent` принимает три параметра:

- `componentKey`: уникальный идентификатор компонента, используемый для ссылки на него внутри Univer.
- `CustomComponent`: сам компонент, как компонент React, компонент Vue или веб-компонент.
- `options`: дополнительные настройки, например, от какой структуры зависит компонент.

### Компоненты React [#react]

Компоненты React не требуют дополнительной конфигурации.Единственным требованием является то, что компонент является действительным компонентом React:

```tsx
function ReactComponent(props: Record<string, any>) {
  return <div>Hello Univer!</div>
}

univerAPI.registerComponent('MyReactComponent', ReactComponent)
```

### Компоненты Vue [#vue]

#### Vue 3.x

Для регистрации компонентов Vue установите и зарегистрируйте `UniverVue3AdapterPlugin` из пакета `@univerjs/ui-adapter-vue3`:

```package-install
npm install @univerjs/ui-adapter-vue3
```

```typescript
import { UniverVue3AdapterPlugin } from '@univerjs/ui-adapter-vue3'

univer.registerPlugin(UniverVue3AdapterPlugin)
```

При регистрации компонента Vue установите опцию `framework` на `'vue3'`:

```tsx
const Vue3Component = defineComponent({
  setup(props) {
    return () => <div>Hello Univer!</div>
  },
})

univerAPI.registerComponent('MyVue3Component', Vue3Component, {
  // [!code word:vue3]
  framework: 'vue3',
})
```

#### Vue 2.x

Vue 2.x - это EOL (конец жизни) и больше не поддерживается, поэтому Univer не предоставляет для него плагин адаптера пользовательского интерфейса. Вы можете реализовать его в качестве пользовательского плагина. В приведенном ниже примере создается адаптер Vue2.x:

```typescript title="ui-adapter-vue2.ts"
import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
import { ComponentManager, UniverUIPlugin } from '@univerjs/ui'
import Vue from 'vue'

/**
 * The plugin that allows Univer to use Vue 2 components as UI components.
 */
@DependentOn(UniverUIPlugin)
export class UniverVue2AdapterPlugin extends Plugin {
  static override pluginName = 'UNIVER_UI_VUE2_ADAPTER_PLUGIN'

  constructor(
    private readonly _config = {},
    @Inject(Injector) protected readonly _injector: Injector,
    @Inject(ComponentManager) protected readonly _componentManager: ComponentManager,
  ) {
    super()
  }

  override onStarting(): void {
    const { createElement, useEffect, useRef } = this._componentManager.reactUtils

    this._componentManager.setHandler('vue2', (component: any) => {
      return (props: Record<string, any>) =>
        createElement(VueComponentWrapper, {
          component,
          props: Object.keys(props).reduce<Record<string, any>>((acc, key) => {
            if (key !== 'key') {
              acc[key] = props[key]
            }
            return acc
          }, {}),
          reactUtils: { createElement, useEffect, useRef },
        })
    })
  }
}

export function VueComponentWrapper(options: {
  component: any
  props: Record<string, any>
  reactUtils: typeof ComponentManager.prototype.reactUtils
}) {
  const { component, props, reactUtils } = options
  const { createElement, useEffect, useRef } = reactUtils

  const domRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!domRef.current) return

    const Constructor = Vue.extend(component)

    const instance = new Constructor({
      data: props,
    })
    instance.$mount()

    domRef.current.appendChild(instance.$el)

    return () => {
      instance.$destroy()
    }
  }, [props])

  return createElement('div', { ref: domRef })
}
```

Затем зарегистрируйте его:

```typescript
import { UniverVue2AdapterPlugin } from './ui-adapter-vue2' // [!code ++]

univer.registerPlugin(UniverUIPlugin)
univer.registerPlugin(UniverVue2AdapterPlugin) // [!code ++]
```

При регистрации компонента Vue 2.x установите опцию `framework` на `'vue2'`:

```tsx
const Vue2Component = Vue.component('MyVue2Component', {
  template: '<div>Hello, Univer!</div>',
})

univerAPI.registerComponent('MyVue2Component', Vue2Component, {
  // [!code word:vue2]
  framework: 'vue2',
})
```

### Web Components [#web-component]

Веб-компонент должен соответствовать стандарту Web Components.Установите и зарегистрируйте `UniverWebComponentAdapterPlugin` из пакета `@univerjs/ui-adapter-web-component`:

```package-install
npm install @univerjs/ui-adapter-web-component
```

```typescript
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

univer.registerPlugin(UniverWebComponentAdapterPlugin)
```

При регистрации веб-компонента установите опцию `framework` на `'web-component'`:

```tsx
class WebComponent extends HTMLElement {
  constructor() {
    super()
    const shadow = this.attachShadow({ mode: 'open' })
    const div = document.createElement('div')
    div.textContent = 'Hello Univer!'
    shadow.appendChild(div)
  }
}

univerAPI.registerComponent('my-web-component', WebComponent, {
  // [!code word:web-component]
  framework: 'web-component',
})
```

## Использование пользовательских компонентов

Способы, приведенные ниже, устанавливают пользовательские компоненты в собственном пользовательском интерфейсе Univer.

<Callout type="warning" title="Внимание">
  1. Убедитесь, что Univer завершил рендеринг, прежде чем вызывать любой из этих методов. 2. Зарегистрируйте компонент перед его использованием. 3. Позвоните `dispose()`, чтобы очистить и удалить добавленные компоненты; в противном случае они вызывают утечки памяти.
</Callout>

### Добавление пользовательских пунктов меню

Верхняя панель меню (Ribbon) и меню правого клика (Context Menu) могут содержать пользовательские компоненты.Предоставьте эти элементы меню из своего собственного плагина, зарегистрируйте их компоненты перед использованием и удалите регистрации вместе с плагином.

### Замена встроенных компонентов

<Callout type="error" title="Предупреждение">
  Замена встроенных компонентов может привести к тому, что некоторые функции перестанут работать должным образом.Прочитайте исходный код и документацию компонента, который вы собираетесь заменить, и действуйте с осторожностью.
</Callout>

`univerAPI.registerComponent` регистрирует оверрайд по умолчанию (`override: true`). Оверрайд имеет приоритет над встроенным компонентом независимо от того, регистрирует ли плагин свой дефолт до или после вашего звонка. Для каждого `componentKey` может быть активен только один оверрайдер, поэтому удалите предыдущую регистрацию перед регистрацией другого. Звонок `dispose()` на возвращенной регистрации восстанавливает встроенный по умолчанию, если он зарегистрирован. Перейдите `{ override: false }` для регистрации по умолчанию.

Зарегистрируйте оверрайд до того, как соответствующий вид откроется впервые.Изменение регистрации не переоформляет уже смонтированные виды.

Например, следующий код заменяет встроенный компонент ColorPicker:

```tsx
// Following code only replaces the UI of the built-in ColorPicker component, not its functionality
univerAPI.registerComponent('UI_COLOR_PICKER_COMPONENT', () => <input type="color" />)
```

### Использование в качестве компонентов содержимого

#### На боковой панели

`univerAPI.openSidebar` открывает боковую панель в интерфейсе Univer и визуализирует пользовательский компонент внутри него.

```tsx
// [!code word:MyCustomSidebarComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomSidebarComponent', () => <div>Hello Univer!</div>)

const sidebar = univerAPI.openSidebar({
  header: { title: 'My Sidebar' },
  children: { label: 'MyCustomSidebarComponent' },
  onClose: () => {
    console.log('close')
  },
  width: 360,
})

// Later close the sidebar
sidebar.dispose()
```

Справочник: [`univerAPI.openSidebar`](/reference/facade/univer#opensidebar)

#### В диалоговом окне

`univerAPI.openDialog` открывает диалог, который отображает пользовательский компонент.

```tsx
// [!code word:MyCustomDialogComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomDialogComponent', () => <div>Hello Univer!</div>)

const dialog = univerAPI.openDialog({
  id: 'unique-dialog-id', // The unique identifier for the dialog
  draggable: true,
  width: 300,
  title: { title: 'My Dialog' },
  children: {
    label: 'MyCustomDialogComponent',
  },
  destroyOnClose: true,
  preservePositionOnDestroy: true,
  onClose: () => {},
})

// Later close the dialog
dialog.dispose()
```

Справочник: [`univerAPI.openDialog`](/reference/facade/univer#opendialog)
