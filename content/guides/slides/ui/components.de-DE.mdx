---
title: Benutzerdefiniert Komponenten
description: Univer provides multiple ways to integrate custom components, allowing you to extend and customize its functionality. This guide will introduce several common methods.
icon: '#pro/Component'
---

Univer übergibt Komponenten nicht direkt als Parameter an Rendering-Funktionen. Sie müssen die Komponenten über die Facade-API bei Univer registrieren, bevor Sie sie an verschiedenen Montagepunkten verwenden können.

Wenn Sie nicht wissen, wie Sie eine Instanz der Facade-API erhalten, können Sie auf [Facade API](/guides/slides/getting-started/facade).
