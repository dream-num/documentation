## 디자인 시스템

Univer의 디자인 시스템은 테일 윈드 CSS에 내장되어 디자인 토큰의 세트를 정의합니다. 렌더링 엔진은 렌더링 엔진을 유지하고 시각적으로 일관성있는 뷰 레이어를 유지합니다. 이 토큰을 수정하여 애플리케이션의 스타일을 사용자 정의 할 수 있습니다. `@univerjs/themes` 패키지에 저장됩니다.

## 컴포넌트

Univer는 React 성분을 가진 전망 층을 건설합니다. 당신의 신청이 또한 React를 이용하는 경우에, 당신은 Univer의 성분을 직접 사용하거나 당신의 자신의 등록할 수 있습니다. 주문 성분은 React에 제한되지 않습니다; Univer에는 또한 Vue (version 3.x)와 웹 성분과 같은 다른 기구를 지원합니다.

모든 기본 구성 요소는 `@univerjs/design` 패키지에 있으며, 아이콘 구성 요소는`@univerjs/icons` 포장에 있습니다. 두 패키지는 Univer의 독립적으로 사용할 수 있습니다.

주문 성분은 보통 이 목적의 한을 봉사합니다:

- Ribbon / Context Menu에 사용자 지정 버튼 추가
- Sidebar / Popup 및 기타 용기에 사용자 정의 구성
- 기본 제공 컴포넌트 교체

다음 페이지는 등록 및 사용자 정의 구성 요소를 사용하는 방법을 설명합니다.
