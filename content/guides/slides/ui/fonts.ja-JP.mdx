Slides のテキストエディターは、フォントファミリーのドロップダウンに Univer の共有フォントリストを使います。このアプリケーションレベルのリストは `UniverUIPlugin` で設定します。

## フォントの選択肢を設定する

`UniverUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターを配置する DOM 要素またはその ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | ドロップダウンにフォントを追加します。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | ドロップダウンにフォントを追加します。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS で使うフォント名。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 表示名または翻訳キー。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 分類。`sans-serif`、`serif`、`monospace`、`display`、`handwriting` を指定できます。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 既定のフォント一覧を指定した一覧に置き換えます。 |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'Inter',
        label: 'Inter',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Noto Serif',
        label: 'Noto Serif',
        category: FontCategory.SERIF,
      },
    ],
    override: false,
  },
})
```

`value` はテキストランのフォントファミリーとして書き込まれます。`label` は表示文字列または i18n キー、`category` は任意のグループです。

ブラウザーフォントは `@font-face` やスタイルシートで別途読み込んでください。リストに名前を追加してもフォントファイルはダウンロードされず、利用できない場合はブラウザーの代替フォントが使われます。

## Facade API

UI Facade の読み込み後は、`addFonts` で実行時に選択肢を追加できます。

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  {
    value: 'Inter',
    label: 'Inter',
    category: FontCategory.SANS_SERIF,
  },
])
```

共有ドロップダウンはすぐに更新されますが、対応するフォントバイトは読み込まれません。
