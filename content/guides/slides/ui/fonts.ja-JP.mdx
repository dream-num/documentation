Slides テキストエディタは、Univer の共有フォントリストを使用して、フォントファミリーのドロップダウンを行います。このリストはアプリケーションに属し、`UniverUIPlugin`で設定します。

## フォントの選択肢を設定する

`UniverUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターのマウント先となる DOM 要素、またはその ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | ドロップダウンにフォントを追加します。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | ドロップダウンにフォントを追加します。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS で使うフォント名。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 表示名、または翻訳キー。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 分類。`sans-serif`、`serif`、`monospace`、`display`、`handwriting` を指定できます。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 既定のフォント一覧を指定した一覧に置き換えます。 |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'Inter',
        label: 'Inter',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Noto Serif',
        label: 'Noto Serif',
        category: FontCategory.SERIF,
      },
    ],
    override: false,
  },
})
```

`value`はテキストランのフォントファミリーとして書かれています。 `label` は、ドロップダウンディスプレイ、または i18n キーのテキストです。 `category` オプションで、選択をグループ化します。

各フォントは`@font-face`またはスタイルシートでロードする必要があります。リストに名前を追加すると、フォントファイルをダウンロードしません。家族が利用できない場合は、ブラウザはフォールバックを使用します。

## Facade API

UIファサードが読み込まれた後、`addFonts` を呼び出して、ランタイムでフォントの選択肢を追加してください。

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  {
    value: 'Inter',
    label: 'Inter',
    category: FontCategory.SANS_SERIF,
  },
])
```

ドロップダウンはすぐに更新されますが、対応するフォントバイトは読み込まれません。
