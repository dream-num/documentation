---
title: 自定义字体列表
icon: BookType
---

Slides 文本编辑器的字体下拉框使用 Univer 共享的字体列表。这份列表属于整个应用，在 `UniverUIPlugin` 上配置。

## 配置字体选项

`UniverUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 编辑器挂载到的元素，或元素的 DOM ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | 向字体下拉框添加这些字体选项。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | 向字体下拉框添加这些字体选项。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS 中使用的字体族名称。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 下拉框显示的名称，或国际化键。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 字体分组，可选 `sans-serif`、`serif`、`monospace`、`display` 或 `handwriting`。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 用传入的列表替换内置选项。 |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'Inter',
        label: 'Inter',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Noto Serif',
        label: 'Noto Serif',
        category: FontCategory.SERIF,
      },
    ],
    override: false,
  },
})
```

`value` 会作为文本片段的字体族写入。`label` 是下拉框显示的文字，或一个国际化键。`category` 可选，用于对选项分组。

字体需要自行加载，可以使用 `@font-face` 或样式表。向列表添加名称不会下载字体文件。字体族不可用时，浏览器会使用回退字体。

## Facade API

UI Facade 加载完成后，调用 `addFonts` 在运行时追加字体选项：

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  {
    value: 'Inter',
    label: 'Inter',
    category: FontCategory.SANS_SERIF,
  },
])
```

下拉框会立即更新，但对应的字体二进制不会加载。
