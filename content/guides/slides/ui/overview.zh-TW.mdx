## 設計系統

Univer 的設計系統基於 Tailwind CSS 建置，定義了一套設計 Tokens。渲染引擎會複用這些 Tokens，從而保證渲染引擎與檢視層的樣式一致。可以透過修改這些 Tokens 定製應用樣式，它們存放在 `@univerjs/themes` 包中。

## 元件

Univer 使用 React 元件建置檢視層。如果應用同樣使用 React，可以直接使用 Univer 的元件，也可以註冊自己的元件。自定義元件並不限於 React，Univer 還支援其他框架，例如 Vue（3.x 版本）和 Web Components。

基礎元件位於 `@univerjs/design` 包中，圖示元件位於 `@univerjs/icons` 包中。這兩個包都可以脫離 Univer 單獨使用。

自定義元件通常有以下用途：

- 在 Ribbon / Context Menu 中添加自訂按鈕
- 在 Sidebar / Popup 等容器中整合自定義元件
- 替換內建元件
