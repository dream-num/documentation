## Sistema de diseño

El sistema de diseño de Univer está construido sobre Tailwind CSS y define un conjunto de fichas de diseño. El motor de renderizado reutiliza esas fichas, que mantiene el motor de renderización y la capa de vista visualmente consistente. Puede personalizar los estilos de la aplicación modificando estas fichas; se almacenan en el paquete `@univerjs/themes`.

## Componentes

Univer construye la capa de vista con componentes React. Si su aplicación también utiliza React, puede utilizar los componentes de Univer directamente o registrar su propio. Los componentes personalizados no se limitan a React; Univer también admite otros marcos, como Vue (versión 3.x) y componentes Web.

Todos los componentes básicos están en el paquete `@univerjs/design`, y los componentes de iconos están en el envase `@univerjs/icons`. Ambos paquetes se pueden utilizar independientemente de Univer .

Los componentes personalizados suelen servir a uno de estos propósitos:

- Agregar botones personalizados en la cinta/menú contextual
- Integración de componentes personalizados en Sidebar / Popup y otros contenedores
- Reemplazar componentes integrados
