Текстовый редактор Slides использует общий список шрифтов Univer для выпадения семейства шрифтов. Этот список принадлежит приложению, и вы настраиваете его на `UniverUIPlugin`.

## Настройка вариантов шрифта

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для размещения редактора или его идентификатор. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Добавляет шрифты в раскрывающийся список. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Добавляет шрифты в раскрывающийся список. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Имя шрифта в CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Имя дисплея или ключ перевода. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Группа шрифтов: `sans-serif`, `serif`, `monospace`, `display` или `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Заменяет встроенный список указанными шрифтами. |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
      { value: 'Noto Serif', label: 'Noto Serif', category: FontCategory.SERIF },
    ],
    override: false,
  },
})
```

`value` пишется как семейство шрифтов текстового запуска. `label` - это текст, который отображается в выпадающем списке, или ключ i18n. `category` является необязательным и группирует выбор.

Каждый шрифт должен быть загружен `@font-face` или таблицей стилей. Добавление имени в список не скачивает файл шрифта. Если семейство недоступно, браузер использует запасной вариант.

## Facade API

После загрузки UI Facade позвоните в `addFonts`, чтобы добавить варианты шрифтов во время выполнения:

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
])
```

Выпадающие обновления сразу же, но соответствующие байты шрифта не загружаются.
