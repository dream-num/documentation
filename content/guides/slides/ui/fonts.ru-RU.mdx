---
title: Список пользовательских шрифтов
icon: BookType
---

Текстовый редактор Slides использует общий список шрифтов Univer для выбора семейства. Настройте этот список приложения в `UniverUIPlugin`.

## Настройка вариантов шрифта

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
      { value: 'Noto Serif', label: 'Noto Serif', category: FontCategory.SERIF },
    ],
    override: false,
  },
})
```

`value` записывается как семейство текстового фрагмента, `label` задаёт отображаемый текст или ключ i18n, а `category` позволяет группировать вариант.

Загрузите браузерный шрифт через `@font-face` или таблицу стилей. Добавление имени в список не загружает файл; если семейство недоступно, браузер использует резервный шрифт.

## Facade API

После загрузки UI Facade добавляйте варианты во время выполнения с помощью `addFonts`:

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
])
```

Общий список обновится сразу, но данные соответствующего шрифта не будут загружены.
