L’éditeur de texte de Slides utilise la liste de polices partagée d’Univer pour son sélecteur de familles. Configurez cette liste applicative dans `UniverUIPlugin`.

## Configurer les choix de police

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Élément DOM où monter l’éditeur, ou son identifiant. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Ajoute ces polices à la liste déroulante. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Ajoute ces polices à la liste déroulante. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Nom de la police utilisé en CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Nom affiché ou clé de traduction. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Catégorie parmi `sans-serif`, `serif`, `monospace`, `display` ou `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Remplace les polices intégrées par la liste fournie. |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
      { value: 'Noto Serif', label: 'Noto Serif', category: FontCategory.SERIF },
    ],
    override: false,
  },
})
```

`value` est écrit comme famille du segment de texte, `label` est le texte affiché ou une clé i18n et `category` permet de regrouper le choix.

Chargez chaque police du navigateur avec `@font-face` ou une feuille de style. Ajouter un nom à la liste ne télécharge pas la police ; si elle est indisponible, le navigateur utilise une police de remplacement.

## Facade API

Après le chargement de la Facade UI, ajoutez des choix à l’exécution avec `addFonts` :

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
])
```

Cette opération met à jour le sélecteur partagé, mais ne charge pas les octets de la police.
