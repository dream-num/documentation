title: Liste de polices personnalisée

L'éditeur de texte de Slides utilise la liste de polices partagée de Univer pour son menu déroulant de la famille de polices. Cette liste appartient à l'application, et vous la configurez sur `UniverUIPlugin`.

## Configurer les choix de police

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Élément DOM de montage de l’éditeur ou son identifiant. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Ajoute ces polices à la liste déroulante. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Ajoute ces polices à la liste déroulante. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Nom de la police utilisé en CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Affichez le nom, ou une clé de traduction. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Catégorie parmi `sans-serif`, `serif`, `monospace`, `display` ou `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Remplace les polices intégrées par la liste fournie. |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
      { value: 'Noto Serif', label: 'Noto Serif', category: FontCategory.SERIF },
    ],
    override: false,
  },
})
```

`value` est écrit comme la famille de polices de l'exécution de texte. `label` est le texte que le menu déroulant affiche, ou une clé i18n. `category` est optionnel et groupe le choix.

Chaque police doit être chargée de `@font-face` ou d'une feuille de style. L'ajout d'un nom à la liste ne télécharge pas un fichier de police. Si la famille n'est pas disponible, le navigateur utilise un retour.

## Facade API

Après le chargement de l'interface utilisateur Facade, appelez `addFonts` pour ajouter les choix de polices à l'exécution :

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
])
```

Les mises à jour du menu déroulant immédiatement, mais les octets de police correspondants ne sont pas chargés.
