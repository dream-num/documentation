Univer no acepta componentes como argumentos para funciones de renderización. Registrar un componente a través de Facade API, y Univer puede encontrarlo en cada punto de montaje.

Si todavía no tiene una instancia Facade API, consulte [Facade API](/guides/slides/getting-started/facade).

## Registro de componentes personalizados

```typescript
// [!code word:componentKey]
// [!code word:CustomComponent]
// [!code word:options]
univerAPI.registerComponent(componentKey, CustomComponent, options)
```

`univerAPI.registerComponent` acepta tres parámetros:

- `componentKey`: identificador único del componente, utilizado para referenciarlo dentro de Univer.
- `CustomComponent`: el componente en sí mismo, como componente React, un componente Vue o un componente Web.
- `options`: Ajustes opcionales, tales como el marco del componente depende.

### Componentes de React [#react]

Los componentes React no requieren ninguna configuración adicional. El único requisito es que el componente es un componente React válido:

```tsx
function ReactComponent(props: Record<string, any>) {
  return <div>Hello Univer!</div>
}

univerAPI.registerComponent('MyReactComponent', ReactComponent)
```

### Componentes de Vue [#vue]

#### Vue 3.x

Para registrar los componentes Vue, instale y registre `UniverVue3AdapterPlugin` del paquete `@univerjs/ui-adapter-vue3`:

```package-install
npm install @univerjs/ui-adapter-vue3
```

```typescript
import { UniverVue3AdapterPlugin } from '@univerjs/ui-adapter-vue3'

univer.registerPlugin(UniverVue3AdapterPlugin)
```

Al registrar un componente Vue, configure la opción `framework` a `'vue3'`:

```tsx
const Vue3Component = defineComponent({
  setup(props) {
    return () => <div>Hello Univer!</div>
  },
})

univerAPI.registerComponent('MyVue3Component', Vue3Component, {
  // [!code word:vue3]
  framework: 'vue3',
})
```

#### Vue 2.x

Vue 2.x es EOL (End of Life) y ya no se mantiene, por lo que Univer no proporciona un plugin de adaptador UI para él. Usted puede implementar uno como plugin personalizado. El ejemplo a continuación construye un adaptador Vue2.x:

```typescript title="ui-adapter-vue2.ts"
import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
import { ComponentManager, UniverUIPlugin } from '@univerjs/ui'
import Vue from 'vue'

/**
 * The plugin that allows Univer to use Vue 2 components as UI components.
 */
@DependentOn(UniverUIPlugin)
export class UniverVue2AdapterPlugin extends Plugin {
  static override pluginName = 'UNIVER_UI_VUE2_ADAPTER_PLUGIN'

  constructor(
    private readonly _config = {},
    @Inject(Injector) protected readonly _injector: Injector,
    @Inject(ComponentManager) protected readonly _componentManager: ComponentManager,
  ) {
    super()
  }

  override onStarting(): void {
    const { createElement, useEffect, useRef } = this._componentManager.reactUtils

    this._componentManager.setHandler('vue2', (component: any) => {
      return (props: Record<string, any>) =>
        createElement(VueComponentWrapper, {
          component,
          props: Object.keys(props).reduce<Record<string, any>>((acc, key) => {
            if (key !== 'key') {
              acc[key] = props[key]
            }
            return acc
          }, {}),
          reactUtils: { createElement, useEffect, useRef },
        })
    })
  }
}

export function VueComponentWrapper(options: {
  component: any
  props: Record<string, any>
  reactUtils: typeof ComponentManager.prototype.reactUtils
}) {
  const { component, props, reactUtils } = options
  const { createElement, useEffect, useRef } = reactUtils

  const domRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!domRef.current) return

    const Constructor = Vue.extend(component)

    const instance = new Constructor({
      data: props,
    })
    instance.$mount()

    domRef.current.appendChild(instance.$el)

    return () => {
      instance.$destroy()
    }
  }, [props])

  return createElement('div', { ref: domRef })
}
```

Luego regístrelo:

```typescript
import { UniverVue2AdapterPlugin } from './ui-adapter-vue2' // [!code ++]

univer.registerPlugin(UniverUIPlugin)
univer.registerPlugin(UniverVue2AdapterPlugin) // [!code ++]
```

Al registrar un componente Vue 2.x, configure la opción `framework` a `'vue2'`:

```tsx
const Vue2Component = Vue.component('MyVue2Component', {
  template: '<div>Hello, Univer!</div>',
})

univerAPI.registerComponent('MyVue2Component', Vue2Component, {
  // [!code word:vue2]
  framework: 'vue2',
})
```

### Componentes web [#web-component]

Un componente web debe ajustarse al estándar de componentes web. Instalar y registrar `UniverWebComponentAdapterPlugin` desde el paquete `@univerjs/ui-adapter-web-component`:

```package-install
npm install @univerjs/ui-adapter-web-component
```

```typescript
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

univer.registerPlugin(UniverWebComponentAdapterPlugin)
```

Al registrar un componente web, configure la opción `framework` a `'web-component'`:

```tsx
class WebComponent extends HTMLElement {
  constructor() {
    super()
    const shadow = this.attachShadow({ mode: 'open' })
    const div = document.createElement('div')
    div.textContent = 'Hello Univer!'
    shadow.appendChild(div)
  }
}

univerAPI.registerComponent('my-web-component', WebComponent, {
  // [!code word:web-component]
  framework: 'web-component',
})
```

## Usar componentes personalizados

Los métodos abajo montan componentes personalizados dentro de la propia interfaz de usuario de Univer.

<Callout type="warning" title="Caution">
  1. Asegúrate de que Univer haya completado la renderización antes de llamar a cualquiera de estos métodos. 2. Registra un componente antes de utilizarlo. 3. Llame a `dispose()` para limpiar y eliminar componentes añadidos; de lo contrario, causan fugas de memoria.
</Callout>

### Agregar elementos de menú personalizados

La barra de menú superior (Ribbon) y el menú de clic derecho (Context Menu) pueden contener componentes personalizados. Proporcionar estos elementos de menú de su propio plugin, registrar sus componentes antes de usar, y disponer los registros junto con el plugin.

### Reemplazo de componentes integrados

<Callout type="error" title="Advertencia">
  La reorganización de componentes incorporados puede causar algunas características para dejar de funcionar correctamente. Lea el código fuente y la documentación del componente que usted tiene la intención de reemplazar, y proceder con precaución.
</Callout>

`univerAPI.registerComponent` registra una anulación por defecto (`override: true`). La anulación tiene precedencia sobre el componente incorporado independientemente de si el plugin registra su predeterminación antes o después de su llamada. Sólo una anulación puede ser activa para cada `componentKey`, por lo que disponer el registro anterior antes de registrar otro. Llamar `dispose()` en el registro devuelto restaura el predeterminado incorporado, si se registra. Pase `{ override: false }` para registrar un predeterminado.

Registrar una anulación antes de que la vista correspondiente se abra por primera vez. Cambiar un registro no reenvia las vistas que ya están montadas.

Por ejemplo, el siguiente código reemplaza el componente ColorPicker incorporado:

```tsx
// Following code only replaces the UI of the built-in ColorPicker component, not its functionality
univerAPI.registerComponent('UI_COLOR_PICKER_COMPONENT', () => <input type="color" />)
```

### Usar como componentes de contenido

#### En la barra lateral

`univerAPI.openSidebar` abre una barra lateral en la interfaz Univer y renderiza un componente personalizado dentro de ella.

```tsx
// [!code word:MyCustomSidebarComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomSidebarComponent', () => <div>Hello Univer!</div>)

const sidebar = univerAPI.openSidebar({
  header: { title: 'My Sidebar' },
  children: { label: 'MyCustomSidebarComponent' },
  onClose: () => {
    console.log('close')
  },
  width: 360,
})

// Later close the sidebar
sidebar.dispose()
```

Referencia: [`univerAPI.openSidebar`](/reference/facade/univer#opensidebar)

#### En un cuadro de diálogo

`univerAPI.openDialog` abre un diálogo que hace un componente personalizado.

```tsx
// [!code word:MyCustomDialogComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomDialogComponent', () => <div>Hello Univer!</div>)

const dialog = univerAPI.openDialog({
  id: 'unique-dialog-id', // The unique identifier for the dialog
  draggable: true,
  width: 300,
  title: { title: 'My Dialog' },
  children: {
    label: 'MyCustomDialogComponent',
  },
  destroyOnClose: true,
  preservePositionOnDestroy: true,
  onClose: () => {},
})

// Later close the dialog
dialog.dispose()
```

Referencia: [`univerAPI.openDialog`](/reference/facade/univer#opendialog)
