## Design System

Univer's design system is built on Tailwind CSS and defines a set of design tokens. The rendering engine reuses those tokens, which keeps the rendering engine and the view layer visually consistent. You can customize the application's styles by modifying these tokens; they are stored in the `@univerjs/themes` package.

## Components

Univer builds the view layer with React components. If your application also uses React, you can use Univer's components directly or register your own. Custom components are not limited to React; Univer also supports other frameworks, such as Vue (version 3.x) and Web Components.

All basic components are in the `@univerjs/design` package, and icon components are in the `@univerjs/icons` package. Both packages can be used independently of Univer.

Custom components usually serve one of these purposes:

- Adding custom buttons in Ribbon / Context Menu
- Integrating custom components in Sidebar / Popup and other containers
- Replacing built-in components
