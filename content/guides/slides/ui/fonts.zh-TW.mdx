title: 自訂字型列表

Slides 文字編輯器的字型下拉框使用 Univer 共享的字型列表。這份列表屬於整個應用，在 `UniverUIPlugin` 上配置。

## 設定字型選項

`UniverUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 編輯器掛載到的元素，或元素的 DOM ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | 向字型下拉框新增這些字型選項。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | 向字型下拉框新增這些字型選項。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS 中使用的字型族名稱。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 下拉框顯示的名稱，或國際化鍵。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 字型群組，可選 `sans-serif`、`serif`、`monospace`、`display` 或 `handwriting`。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 用傳入的列表替換內建選項。 |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'Inter',
        label: 'Inter',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Noto Serif',
        label: 'Noto Serif',
        category: FontCategory.SERIF,
      },
    ],
    override: false,
  },
})
```

`value` 會作為文字片段的字型族寫入。`label` 是下拉框顯示的文字，或一個國際化鍵。`category` 可選，用於對選項分組。

字型需要自行載入，可以使用 `@font-face` 或樣式表。向列表新增名稱不會下載字型檔案。字型族不可用時，瀏覽器會使用回退字型。

## Facade API

UI Facade 載入完成後，呼叫 `addFonts` 在執行時追加字型選項：

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  {
    value: 'Inter',
    label: 'Inter',
    category: FontCategory.SANS_SERIF,
  },
])
```

下拉框會立即更新，但對應的字型二進位制不會載入。
