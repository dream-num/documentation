---
title: 自訂字型列表
icon: BookType
---

Slides 文字編輯器的字型下拉選單使用 Univer 共用字型清單。請在 `UniverUIPlugin` 上設定這項應用程式層級清單。

## 設定字型選項

```ts
import { UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'Inter',
        label: 'Inter',
        category: 'sans-serif',
      },
      {
        value: 'Noto Serif',
        label: 'Noto Serif',
        category: 'serif',
      },
    ],
    override: false,
  },
})
```

`value` 會作為文字片段的字型家族寫入；`label` 是顯示文字或國際化鍵；`category` 可用來將選項分組。

請透過 `@font-face` 或樣式表自行載入瀏覽器字型。在清單加入名稱不會下載字型檔案；字型家族無法使用時，瀏覽器會採用替代字型。

## Facade API

載入 UI Facade 後，可以用 `addFonts` 在執行階段追加字型選項：

```ts
univerAPI.addFonts([
  {
    value: 'Inter',
    label: 'Inter',
    category: 'sans-serif',
  },
])
```

此方法會立即更新共用下拉選單，但不會載入對應的字型二進位資料。
