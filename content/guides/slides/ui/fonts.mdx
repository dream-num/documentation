The Slides text editor uses Univer’s shared font list for its font-family dropdown. Configure that application-level list on `UniverUIPlugin`.

## Configure font choices

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Default | What it does |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Mount element or its DOM ID. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Adds these font choices to the dropdown. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Adds these font choices to the dropdown. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Font family name used in CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Display name or translation key. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Font group. Use `sans-serif`, `serif`, `monospace`, `display`, or `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Replaces the built-in choices with the supplied list. |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'Inter',
        label: 'Inter',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Noto Serif',
        label: 'Noto Serif',
        category: FontCategory.SERIF,
      },
    ],
    override: false,
  },
})
```

`value` is written as the text run’s font family. `label` is the displayed text or an i18n key, and `category` optionally groups the choice.

Load each browser font yourself with `@font-face` or a stylesheet. Adding a name to the list does not download a font file; if the family is unavailable, the browser uses a fallback.

## Facade API

After the UI Facade has loaded, append font choices at runtime with `addFonts`:

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  {
    value: 'Inter',
    label: 'Inter',
    category: FontCategory.SANS_SERIF,
  },
])
```

This updates the shared dropdown immediately and does not load the corresponding font bytes.
