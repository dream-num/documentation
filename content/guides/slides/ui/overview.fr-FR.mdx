## Système de design

Le système de conception de Univer est construit sur Tailwind CSS et définit un ensemble de jetons de conception. Le moteur de rendu réutilise ces jetons, qui maintient la cohérence visuelle du moteur de rendu et de la couche de vue. Vous pouvez personnaliser les styles de l'application en modifiant ces jetons; ils sont stockés dans le paquet `@univerjs/themes`.

## Composants

Univer construit le calque de vue avec React composants. Si votre application utilise également React, vous pouvez utiliser Univer's composants directement ou d'enregistrer vos propres. React; Univer soutient également d'autres cadres, tels que Vue (version 3.x) et composants Web.

Tous les composants de base sont dans le paquet `@univerjs/design`, et les composants icônes sont dans le pack `@univerjs/icons`. Les deux paquets peuvent être utilisés indépendamment de Univer .

Les composants personnalisés servent généralement à l'une de ces fins :

- Ajout de boutons personnalisés dans le Ribbon / Context Menu
- Intégrer des composants personnalisés dans Sidebar / Popup et autres conteneurs
- Remplacement des composants intégrés

Les pages suivantes décrivent comment enregistrer et utiliser des composants personnalisés.
