## 设计系统

Univer 的设计系统基于 Tailwind CSS 构建，定义了一套设计 Tokens。渲染引擎会复用这些 Tokens，从而保证渲染引擎与视图层的样式一致。可以通过修改这些 Tokens 定制应用样式，它们存放在 `@univerjs/themes` 包中。

## 组件

Univer 使用 React 组件构建视图层。如果应用同样使用 React，可以直接使用 Univer 的组件，也可以注册自己的组件。自定义组件并不限于 React，Univer 还支持其他框架，例如 Vue（3.x 版本）和 Web Components。

基础组件位于 `@univerjs/design` 包中，图标组件位于 `@univerjs/icons` 包中。这两个包都可以脱离 Univer 单独使用。

自定义组件通常有以下用途：

- 在 Ribbon / Context Menu 中添加自定义按钮
- 在 Sidebar / Popup 等容器中集成自定义组件
- 替换内置组件

后续页面将详细介绍如何注册和使用自定义组件。
