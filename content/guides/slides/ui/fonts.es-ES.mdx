El editor de texto de diapositivas utiliza la lista de fuentes compartidas de Univer para su desplegable de fuentes familiares. Esa lista pertenece a la aplicación y la configura en `UniverUIPlugin`.

## Configurar las opciones de fuente

`UniverUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Elemento DOM donde se monta el editor o su ID. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Añade estas fuentes al menú desplegable. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Añade estas fuentes al menú desplegable. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Nombre de la fuente en CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Apellido o clave de traducción. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Categoría: `sans-serif`, `serif`, `monospace`, `display` o `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Sustituye las fuentes integradas por la lista indicada. |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
      { value: 'Noto Serif', label: 'Noto Serif', category: FontCategory.SERIF },
    ],
    override: false,
  },
})
```

`value` se escribe como la familia de fuentes de la ejecución de texto. `label` es el texto que la pantalla desplegable, o una tecla i18n. `category` es opcional y agrupa la elección.

Cada fuente debe ser cargada con `@font-face` o una hoja de estilo. Agregar un nombre a la lista no descarga un archivo de fuente. Si la familia no está disponible, el navegador utiliza un inconveniente.

## API de Facade

Después de que la UI Facade haya cargado, llame a `addFonts` para que acabe las opciones de fuentes en tiempo de ejecución:

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
])
```

Las actualizaciones desplegables inmediatamente, pero los bytes de fuentes correspondientes no están cargados.
