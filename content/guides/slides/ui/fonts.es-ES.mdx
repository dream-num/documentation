El editor de texto de Slides utiliza la lista de fuentes compartida de Univer para su selector de familias. Configura esta lista de aplicación en `UniverUIPlugin`.

## Configurar las opciones de fuente

`UniverUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Elemento DOM donde se monta el editor, o su ID. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Añade estas fuentes al menú desplegable. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Añade estas fuentes al menú desplegable. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Nombre de la fuente en CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Nombre visible o clave de traducción. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Categoría: `sans-serif`, `serif`, `monospace`, `display` o `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Sustituye las fuentes integradas por la lista indicada. |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
      { value: 'Noto Serif', label: 'Noto Serif', category: FontCategory.SERIF },
    ],
    override: false,
  },
})
```

`value` se escribe como familia del fragmento de texto, `label` es el texto visible o una clave de i18n y `category` permite agrupar la opción.

Carga cada fuente del navegador mediante `@font-face` o una hoja de estilos. Añadir un nombre a la lista no descarga la fuente; si no está disponible, el navegador usa una alternativa.

## API de Facade

Después de cargar la Facade de UI, añade opciones durante la ejecución con `addFonts`:

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
])
```

Esto actualiza el selector compartido, pero no carga los bytes de la fuente.
