## Система дизайна

Система проектирования Univer построена на Tailwind CSS и определяет набор дизайнерских токенов. Движок рендеринга повторно использует эти токены, что сохраняет визуально согласованным движок рендера и уровень обзора. Вы можете настроить стили приложения, изменив эти токенов; они хранятся в пакете `@univerjs/themes`.

## Компоненты

Univer строит уровень просмотра с помощью компонентов React. Если ваше приложение также использует React, вы можете использовать компоненты Univer напрямую или зарегистрировать свои собственные. Пользовательские компоненты не ограничиваются React; Univer также поддерживает другие фреймворки, такие как Vue (версия 3.x) и Web Components.

Все основные компоненты находятся в пакете `@univerjs/design`, а компоненты значков — в пакете`@univerjs/icons`.Оба пакета могут использоваться независимо от Univer

Компоненты обычно служат одной из этих целей:

- Добавление пользовательских кнопок в Ribbon / Context Menu
- Интеграция пользовательских компонентов в Sidebar / Popup и другие контейнеры
- Замена встроенных компонентов

Следующие страницы описывают, как зарегистрировать и использовать пользовательские компоненты.
