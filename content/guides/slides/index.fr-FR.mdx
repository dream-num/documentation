## Présentation d’Univer Slides

Univer Slides est le produit de présentation d’Univer Pro. Il permet de créer des éditeurs de diaporamas, des visionneuses de présentations, des processus d’importation et d’exportation, ainsi que des traitements de diapositives côté serveur reposant sur l’environnement d’exécution Univer.

Slides est un type d’unité Univer indépendant. Dans l’environnement d’exécution, créez une unité `UniverInstanceType.UNIVER_SLIDE`, puis enregistrez le modèle Pro, l’interface utilisateur et les plugins de fonctionnalités facultatifs correspondant à vos besoins.

<Callout type="info">
  Univer Slides se trouve désormais dans l’espace de noms de packages `@univerjs-pro`. Consultez [Univer Pro](/guides/pro) pour connaître les exigences en matière de licence et de déploiement avant de l’intégrer à une application.
</Callout>

## Fonctionnalités incluses

- Modèle de données des diapositives, ordre des pages, masques, dispositions, espaces réservés, formes, images et intégration des éléments graphiques
- Interface d’édition dans le navigateur avec miniatures, édition sur canevas, outils d’insertion, menus contextuels et lecture des présentations
- Intégrations facultatives des tableaux et des graphiques pour les éléments de diapositives
- Intégrations de l’impression, de l’importation et de l’exportation pour les déploiements Pro
- API Facade pour créer des présentations et manipuler le contenu des diapositives

## Installer les packages

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
pnpm add @univerjs-pro/slides-print @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui @univerjs-pro/slides-exchange-client
```
