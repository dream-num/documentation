## Qu’est-ce qu’Univer Slides ?

Univer Slides est le produit de présentation d’Univer SDK Pro. Il permet de créer des éditeurs de diaporamas, des visionneuses de présentations, des processus d’importation et d’exportation, ainsi que des traitements de diapositives côté serveur reposant sur l’environnement d’exécution Univer SDK.

Slides est un type d’unité Univer SDK indépendant. Dans l’environnement d’exécution, créez une unité `UniverInstanceType.UNIVER_SLIDE`, puis enregistrez le modèle Pro, l’interface utilisateur et les plugins de fonctionnalités facultatifs correspondant à vos besoins.

<Callout type="info">
  Univer Slides se trouve désormais dans l’espace de noms de packages `@univerjs-pro`. Consultez [Univer SDK
  Pro](/guides/pro) pour connaître les exigences en matière de licence et de déploiement avant de l’intégrer à une
  application.
</Callout>


## Compatibilité avec les navigateurs

Univer SDK est compilé avec Chrome 88 comme cible, mais cela ne signifie pas qu’il prend entièrement en charge tous les environnements courants. Nous nous efforçons d’assurer son bon fonctionnement dans les navigateurs et environnements Node.js suivants :

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK s’appuie sur `Intl.Segmenter`. Si votre navigateur ou votre environnement d’exécution ne le prend pas en
  charge, ajoutez d’abord un polyfill adapté. Nous vous recommandons d’utiliser `@formatjs/intl-segmenter`.
</Callout>

Si vous rencontrez des problèmes de compatibilité, essayez d’abord de les résoudre à l’aide des polyfills appropriés. Si le problème persiste, n’hésitez pas à [ouvrir une issue](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilité avec Node.js

<Callout type="warning">
  Remarque : ces informations concernent uniquement l’exécution d’Univer SDK dans un environnement Node.js. Elles ne
  s’appliquent pas lorsqu’Univer SDK s’exécute dans un navigateur avec des outils de build basés sur Node.js.
</Callout>

Univer SDK peut s’exécuter dans un environnement Node.js à partir de la version v18.17.0.

## Points forts

- **Modèle de présentation** : gère l’identité, le format des pages, l’ordre des diapositives, les diapositives, les masques, les dispositions, les thèmes, les transitions et les ressources.
- **Affichage et édition** : fournit le canevas, les miniatures, la sélection, le presse-papiers, l’édition du texte et des formes, les repères d’alignement et le diaporama.
- **Pipeline de commandes** : applique les changements de page et d’élément par des commandes et mutations afin de synchroniser le modèle, l’affichage, l’annulation et le rétablissement.
- **Facade API** : permet de créer, retrouver et enregistrer des présentations, puis de manipuler les diapositives et leurs éléments avec des objets destinés à l’application.
- **Architecture à plugins** : sépare du noyau les fonctions facultatives telles que les tableaux, les graphiques, l’impression et l’import-export.

## Comment lire la documentation

La barre de navigation de la documentation se trouve à gauche de l’écran. Les pages sont classées du niveau débutant au niveau avancé afin que vous puissiez les suivre pas à pas pendant la création de votre application. Vous pouvez cependant les consulter dans l’ordre de votre choix ou accéder directement aux pages correspondant à votre cas d’utilisation. Vous pouvez également sélectionner Univer Slides en haut de la barre latérale.

À droite de l’écran, une table des matières facilite la navigation entre les différentes sections de la page. Pour trouver rapidement une page, utilisez la barre de recherche située en haut ou le raccourci de recherche (Ctrl+K ou Cmd+K).

Pour commencer, consultez le guide de [démarrage rapide](/guides/slides/getting-started/quickstart).

## Connaissances préalables

Bien que notre documentation soit conçue pour les débutants, il nous faut établir quelques prérequis afin qu’elle puisse rester centrée sur Univer SDK.

Pour en tirer pleinement parti, il est recommandé de posséder des notions de base en JavaScript et de connaître son écosystème.

Si vous souhaitez exécuter Univer SDK sur Node.js, des notions de base sur Node.js sont également nécessaires.

Si vous souhaitez essayer Univer SDK Pro et déployer Univer Server, nous vous recommandons de posséder des connaissances de base sur Linux, Docker et Docker Compose (ou Kubernetes).
