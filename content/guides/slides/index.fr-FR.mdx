## Qu’est-ce qu’Univer Slides ?

Univer Slides est le produit de présentation dans Univer Office SDK. Il prend en charge les éditeurs de diapos de construction, les téléspectateurs de présentation, et les flux d'importation et d'exportation, et il peut traiter les diapositives sur le serveur à travers le Web SDK runtime.

Les diapositives fonctionnent sur [Web SDK](/guides/sheets), qui fournit à la fois l'éditeur de navigateur et le traitement sans tête sur le serveur. [Server SDK](/server) ajoute la collaboration et l'échange de fichiers, et [AI SDK](/ai) couvre les workflows d'agents.

Slides est un type d'unité Web SDK indépendant. Au moment de l'exécution, vous créez une unité de type `UniverInstanceType.UNIVER_SLIDE` puis enregistrez le modèle, l'interface utilisateur et les plugins optionnels qui correspondent aux capacités dont vous avez besoin.

<Callout type="info">
  Les diapositives Univer sont publiées sous la portée du paquet `@univerjs-pro`. Les fonctionnalités autorisées nécessitent un [licence client](/server/license) . Ajoutez [Univer Server SDK](/server) lorsque votre application a besoin de collaboration ou de conversion de fichiers.
</Callout>

## Compatibilité avec les navigateurs

Web SDK compile avec une cible Chrome 88, mais compilation seule ne garantit pas le support pour chaque environnement courant. Web SDK est destiné à fonctionner dans les navigateurs et les versions Node.js listées ci-dessous:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK utilise `Intl.Segmenter`. Si le navigateur ou l'environnement d'exécution ne le supporte pas, ajoutez d'abord le polyfill correspondant. `@formatjs/intl-segmenter` est recommandé.
</Callout>

Si un problème de compatibilité survient, appliquez d'abord le polyfill correspondant. Si le problème persiste, [ouvrir un numéro](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilité avec Node.js

<Callout type="warning">
  Cela ne couvre que l'exécution de Web SDK directement dans Node.js. Il ne s'applique pas lorsqu'un outil de compilation basé sur Node.js regroupe Web SDK pour le navigateur.
</Callout>

Web SDK fonctionne dans Node.js v18.17.0 et plus tard.

## Points forts

- Le modèle de présentation suit l'identité de la présentation, la taille de la page, l'ordre des diapositives, les diapositives, pages de gestion, pages de mise en page, thèmes, transitions et ressources.
- Le rendu et l'édition couvrent la toile de diapositives, les vignettes, la sélection, le presse-papier, l'édition de texte et de forme, les guides d'alignement et la lecture.
- Les changements de page et d'élément passent par les commandes et les mutations, qui permettent de synchroniser les mises à jour, le rendu et le rendu des modèles.
- Le Facade API crée et trouve des présentations, enregistre des instantanés et expose les opérations de diapositives et d'éléments à travers des objets orientés vers l'application.
- Les fonctions optionnelles telles que les tableaux, les graphiques, l'impression et l'importation/exportation restent en dehors de la pile de base.

## Connaissances préalables

La documentation est écrite pour les nouveaux arrivants, mais elle suppose une base de référence pour que le contenu puisse rester concentré sur Web SDK. Les lecteurs doivent connaître JavaScript et son écosystème; les connaissances de base Node.js sont également utiles lorsque Web SDK fonctionnera sur Node.js.

Lorsque plusieurs personnes ont besoin d'éditer les mêmes diapositives, ou qu'une application a besoin d'historiques partagés, de commentaires ou de conversion de fichiers, ajoutez les modules correspondants de [Univer Server SDK](/server) à l'arrière-plan. L'authentification, les permissions, le stockage et le déploiement restent la responsabilité de l'application.

## Étendre Univer Slides

Web SDK est conçu pour être étendu, de sorte qu'il peut être façonné autour des besoins d'une application.
