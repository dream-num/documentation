## Qué es Univer Slides

Univer Slides es el producto de presentación en Univer Pro. Se utiliza para crear editores de presentaciones de diapositivas, visores de presentaciones, flujos de importación/exportación y procesamiento de diapositivas del lado del servidor además del tiempo de ejecución de Univer.

Las diapositivas son un tipo de unidad independiente de Univer. En tiempo de ejecución, crea una unidad `UniverInstanceType.UNIVER_SLIDE`, luego registra el modelo Pro, la interfaz de usuario y los complementos de funciones opcionales que coincidan con las capacidades que necesita.

<Callout type="info">
  Univer Slides ahora se encuentra en el alcance del paquete `@univerjs-pro`. Utilice [Univer Pro](/guides/pro) para
  conocer los requisitos de licencia e implementación antes de integrarlo en una aplicación.
</Callout>


## Compatibilidad del navegador

Univer está compilado con un objetivo de Chrome 88, pero esto no significa que sea totalmente compatible con todos los entornos principales. Nos esforzamos por garantizar que Univer funcione bien en los siguientes navegadores y entornos Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer depende de `Intl.Segmenter`. Si su navegador o entorno de ejecución no lo admite, primero agregue el polyfill
  correspondiente. Recomendamos usar `@formatjs/intl-segmenter`.
</Callout>

Si encuentra problemas de compatibilidad, primero intente resolverlos utilizando los polyfills adecuados. Si el problema persiste, no dude en [enviar un problema](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilidad con Node.js

<Callout type="warning">
  Nota: Esto solo se aplica a la ejecución de Univer en un entorno Node.js y no se aplica a los casos en los que Univer
  se ejecuta en un navegador usando herramientas de compilación basadas en Node.js.
</Callout>

Univer puede ejecutarse en un entorno Node.js, con versiones compatibles v18.17.0 y posteriores.


## Qué incluye

- Modelo de datos de diapositivas, orden de páginas, patrones, diseños, marcadores de posición, formas, imágenes e integración de dibujos
- UI del editor del navegador para miniaturas, edición de lienzos, herramientas de inserción, menús contextuales y reproducción de presentaciones
- Integraciones opcionales de tablas y gráficos para elementos de diapositivas
- Imprimir e importar/exportar integraciones para implementaciones Pro
- API de Facade para crear presentaciones y operar con contenido de diapositivas

## Instalar paquetes

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
pnpm add @univerjs-pro/slides-print @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui @univerjs-pro/slides-exchange-client
```
