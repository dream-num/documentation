## Qué es Univer Slides

Univer Slides es el producto de presentación en Univer Office SDK. Admite editores de cubiertas de diapositivas de construcción, visores de presentación, y flujos de importación y exportación, y puede procesar diapositivas en el servidor a través de la duración de ejecución Web SDK .

Las diapositivas se ejecutan en [Web SDK](/guides/sheets), que proporciona tanto el editor del navegador como el procesamiento sin cabeza en el servidor. [Server SDK](/server) añade colaboración e intercambio de archivos, y [AI SDK](/ai) cubre los flujos de trabajo de los agentes.

Las diapositivas es un tipo de unidad Web SDK independiente. En el tiempo de ejecución crea una unidad de tipo `UniverInstanceType.UNIVER_SLIDE` y luego registra el modelo, UI y plugins opcionales de características que coinciden con las capacidades que necesita.

<Callout type="info">
  Univer Las diapositivas se publican bajo el alcance del paquete `@univerjs-pro`. Las características con licencia requieren un [licencia cliente](/server/license) . Añadir [Univer Server SDK](/server) cuando su aplicación necesita colaboración o conversión de archivos.
</Callout>

## Compatibilidad del navegador

Web SDK compila con un objetivo Chrome 88, pero la compilación por sí sola no garantiza soporte para cada entorno principal. Web SDK está destinado a trabajar en los navegadores y versiones Node.js que se enumeran a continuación:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK se basa en `Intl.Segmenter`. Si el navegador o el entorno de tiempo de ejecución no lo soporta, agregue primero el polífilo coincidente. `@formatjs/intl-segmenter` se recomienda.
</Callout>

Si se produce un problema de compatibilidad, aplique primero el polífilo que coincida. Si el problema persiste, [abrir una cuestión](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilidad con Node.js

<Callout type="warning">
  Esto solo cubre la ejecución de Web SDK directamente en Node.js. No se aplica cuando un paquete de herramientas de construcción basado en Node.js Web SDK para el navegador.
</Callout>

Web SDK funciona en Node.js v18.17.0 y más tarde.

## Aspectos destacados

- El modelo de presentación rastrea la identidad de presentación, tamaño de página, orden de diapositivas, diapositivas, páginas maestras, páginas de diseño, temas, transiciones y recursos.
- Rendering y edición cubren el lienzo de diapositivas, miniaturas, selección, portapapeles, edición de texto y forma, guías de alineación y reproducción.
- Los cambios de página y elemento pasan por comandos y mutaciones, que mantiene actualizaciones de modelos, renderizado y deshacer y redonar sincronizados.
- El Facade API crea y encuentra presentaciones, guarda instantáneas, y expone las operaciones de diapositivas y elementos a través de objetos de aplicación.
- Características opcionales como tablas, gráficos, impresión e importación/exportación permanecen fuera de la pila de núcleo.

## Cómo leer la documentación

La barra lateral enumera las páginas de base a avanzada, por lo que puede seguirlas en orden mientras construye una aplicación, o leerlas en cualquier orden y saltar a las páginas que se aplican a su caso de uso. La parte superior de la barra lateral cambia entre los productos, incluyendo Univer Diapositivas.

La tabla de contenidos en las barras derechas entre secciones de la página actual. Para encontrar una página rápidamente, utilice la barra de búsqueda en la parte superior o el acceso directo de búsqueda (Ctrl+K o Cmd+K).

Para empezar, lea la guía [Inicio rápido](/guides/slides/getting-started/installation).

## Conocimientos previos requeridos

La documentación está escrita para los recién llegados, pero asume una base de referencia para que el contenido pueda mantenerse enfocado en Web SDK. Los lectores deben conocer JavaScript y su ecosistema; el conocimiento básico Node.js también es útil cuando Web SDK se ejecutará en Node.js.

Cuando varias personas necesitan editar las mismas diapositivas, o una aplicación necesita historia compartida, comentarios, o conversión de archivos, añadir los módulos correspondientes de [Univer Server SDK](/server) al backend. Autenticación, permisos, almacenamiento y despliegue siguen siendo la responsabilidad de la aplicación. Editar solo en el navegador no requiere ninguno de estos servicios.
