## Univer Slides 是什麼

Univer Slides 是 Univer SDK Pro 中的簡報產品能力。它用來建構投影片編輯器、播放檢視、匯入匯出流程，以及基於 Univer SDK runtime 的服務端投影片處理能力。

Slides 是獨立的 Univer SDK unit type。執行時需要建立 `UniverInstanceType.UNIVER_SLIDE` unit，然後依需求註冊 Pro 側的模型、UI 和可選功能外掛。

<Callout type="info">
  Univer Slides 現在位於 `@univerjs-pro` package scope 下。整合前請先閱讀 [Univer SDK Pro](/guides/pro) 中的授權與部署說明。
</Callout>


## 瀏覽器相容性

Univer SDK 的編譯目標是 Chrome 88，但這並不意味著 Univer SDK 能夠完全支援所有主流環境。我們會盡力確保 Univer SDK 在以下瀏覽器和 Node.js 環境中能夠正常運行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK 依賴 `Intl.Segmenter`，如果你的瀏覽器或執行環境暫不支援它，請先補上對應的 polyfill。我們推薦使用
  `@formatjs/intl-segmenter`。
</Callout>

如果遇到無法相容的情況，請先借助對應的 polyfill 來解決，如果仍然無法解決，請[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 相容性

<Callout type="warning">
  以下僅適用於在 Node.js 環境中運行 Univer SDK 的情況，並不適用於那些基於 Node.js 使用建構工具在瀏覽器中運行 Univer SDK 的情況。
</Callout>

Univer SDK 可以在 Node.js 環境中運行，支援的版本為 v18.17.0 及之後的版本。

## 主要功能

- **簡報模型**：管理簡報識別、頁面尺寸、投影片順序、投影片、母片頁、版面配置頁、主題、轉場效果和資源。
- **算繪與編輯**：提供投影片畫布、縮圖、選取、剪貼簿、文字與圖形編輯、對齊參考線和播放功能。
- **命令管線**：透過命令和變更套用頁面與元素更新，使模型、算繪以及復原和重做保持同步。
- **Facade API**：透過面向應用程式的物件建立和尋找簡報、儲存快照，並操作投影片和元素。
- **外掛程式架構**：表格、圖表、列印和匯入匯出等選用功能與核心外掛程式堆疊相互獨立。

## 前置知識

儘管我們已經盡力使得文件對新手也易於理解，但是我們必須假設你在開始閱讀之前已經瞭解了一些基礎知識，以便我們的文件可以專注於 Univer SDK。

為了充分利用我們的文件，建議你對 JavaScript 及其生態系統有基本的瞭解。

如果你有興趣在 Node.js 上執行 Univer SDK，你還應該對 Node.js 有基本的瞭解。

如果你想嘗試高階功能並部署 Univer Server，我們建議你對 Linux、Docker 和 Docker Compose（或 Kubernetes）有基本的瞭解。
