## Univer Slides 是什麼

Univer Slides 是 Univer Pro 中的簡報產品能力。它用來建構投影片編輯器、播放檢視、匯入匯出流程，以及基於 Univer runtime 的服務端投影片處理能力。

Slides 是獨立的 Univer unit type。執行時需要建立 `UniverInstanceType.UNIVER_SLIDE` unit，然後依需求註冊 Pro 側的模型、UI 和可選功能外掛。

<Callout type="info">
  Univer Slides 現在位於 `@univerjs-pro` package scope 下。整合前請先閱讀 [Univer Pro](/guides/pro) 中的授權與部署說明。
</Callout>


## 瀏覽器相容性

Univer 的編譯目標是 Chrome 88，但這並不意味著 Univer 能夠完全支援所有主流環境。我們會盡力確保 Univer 在以下瀏覽器和 Node.js 環境中能夠正常運行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer 依賴 `Intl.Segmenter`，如果你的瀏覽器或執行環境暫不支援它，請先補上對應的 polyfill。我們推薦使用
  `@formatjs/intl-segmenter`。
</Callout>

如果遇到無法相容的情況，請先借助對應的 polyfill 來解決，如果仍然無法解決，請[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 相容性

<Callout type="warning">
  以下僅適用於在 Node.js 環境中運行 Univer 的情況，並不適用於那些基於 Node.js 使用建構工具在瀏覽器中運行 Univer 的情況。
</Callout>

Univer 可以在 Node.js 環境中運行，支援的版本為 v18.17.0 及之後的版本。


## 包含能力

- 投影片資料模型、頁面順序、母版、版面、佔位符、形狀、圖片和 drawing 整合
- 瀏覽器編輯器 UI，包括縮圖、畫布編輯、插入工具、右鍵選單和播放能力
- 可選的表格、圖表元素整合
- 面向 Pro 部署的列印與匯入匯出能力
- 用於建立簡報和操作投影片內容的 Facade API

## 安裝套件

```bash
pnpm add @univerjs-pro/slides @univerjs-pro/slides-ui
pnpm add @univerjs-pro/slides-print @univerjs-pro/slides-table @univerjs-pro/slides-table-ui
pnpm add @univerjs-pro/chart-ui @univerjs-pro/slides-chart @univerjs-pro/slides-chart-ui @univerjs-pro/slides-exchange-client
```
