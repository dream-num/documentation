## Univer Slides 是什麼

Univer Slides 是 Univer Office SDK 中的簡報產品。它可以用於建置幻燈片編輯器、簡報檢視器和匯入匯出流程，也可以透過 Web SDK runtime 在伺服器端處理幻燈片。

Slides 執行在 [Web SDK](/guides/sheets) 之上，由它提供瀏覽器端編輯器和伺服器端無介面處理能力。[Server SDK](/server) 提供協同與檔案交換，[AI SDK](/ai) 負責 Agent 工作流。

Slides 是獨立的 Web SDK unit type。執行時先建立型別為 `UniverInstanceType.UNIVER_SLIDE` 的 unit，再註冊與所需能力對應的模型、UI 和可選功能外掛。

<Callout type="info">
  Univer Slides 位於 `@univerjs-pro` 包作用域下。需要授權的功能需配置[客戶端許可證](/server/license)。當應用需要協同或檔案轉換時，再接入 [Univer Server SDK](/server)。
</Callout>

## 瀏覽器相容性

Web SDK 的編譯目標是 Chrome 88，但僅憑編譯目標無法保證覆蓋所有主流環境。Web SDK 計劃支援以下瀏覽器和 Node.js 版本：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK 依賴 `Intl.Segmenter`。如果瀏覽器或執行時環境不支援該 API，請先補充對應的 polyfill。推薦使用 `@formatjs/intl-segmenter`。
</Callout>

遇到相容性問題時，請先應用對應的 polyfill。如果問題仍未解決，可以[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 相容性

<Callout type="warning">
  本節只涉及直接在 Node.js 中執行 Web SDK 的情況。使用基於 Node.js 的建置工具將 Web SDK 打包到瀏覽器執行的場景不在此列。
</Callout>

Web SDK 支援在 Node.js v18.17.0 及之後的版本中執行。

## 主要功能

- 簡報模型負責管理簡報標識、頁面尺寸、幻燈片順序、幻燈片、母版頁、版式頁、主題、切換效果和資源。
- 渲染與編輯涵蓋幻燈片畫布、縮圖、選區、剪貼簿、文字與形狀編輯、對齊參考線和放映。
- 頁面和元素的改動透過命令和變更生效，模型更新、渲染以及撤銷重做保持同步。
- Facade API 透過面向應用的物件建立和查詢簡報、儲存快照，並對外提供幻燈片和元素操作。
- 表格、圖表、列印、匯入匯出等可選功能獨立於核心外掛棧。

## 如何使用這些文件

左側邊欄按從基礎到高階的順序列出各頁，可以在建置應用的過程中按順序閱讀，也可以按任意順序閱讀，或直接跳轉到與當前場景相關的頁面。側邊欄頂部可以在不同產品之間切換，其中包括 Univer Slides。

右側目錄用於在當前頁面的各小節之間導航。如需快速找到某一頁，可以使用頂部的搜尋框，或使用搜尋快捷鍵（Ctrl+K 或 Cmd+K）。

入門請從[快速開始](/guides/slides/getting-started/installation)讀起。

## 前置知識

這套文件面向初次接觸的讀者，但假定讀者具備一定基礎，以便把內容集中在 Web SDK 上。讀者應瞭解 JavaScript 及其生態；如果計劃在 Node.js 上執行 Web SDK，具備 Node.js 基礎知識也會有所幫助。

需要多人共同編輯幻燈片，或者需要共享歷史、評論和檔案轉換時，請把 [Univer Server SDK](/server) 中的對應模組接入後端。身分認證、權限、儲存和部署仍由應用負責。僅在瀏覽器中編輯時，不需要這些服務。
