## Übersicht

Der Folienimport und -export ist eine Pro-Funktion. Der Browser-Client registriert den Shared Exchange-Client und den Slides-Exchange-Client, während Konvertierung, Aufgabenabfrage, Speicherung und signierte Download-URLs von Ihrer Pro-Bereitstellung bereitgestellt werden.

```ts
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client'
import ExchangeClientEnUS from '@univerjs-pro/exchange-client/locale/en-US'
import { UniverSlidesExchangeClientPlugin } from '@univerjs-pro/slides-exchange-client'
import SlidesExchangeClientEnUS from '@univerjs-pro/slides-exchange-client/locale/en-US'

import '@univerjs-pro/exchange-client/lib/index.css'
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'

univer.registerPlugin(UniverExchangeClientPlugin)
univer.registerPlugin(UniverSlidesExchangeClientPlugin)
```

## Installation

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/slides-exchange-client
```

## Endpunkte konfigurieren

`@univerjs-pro/slides-exchange-client` hängt von `@univerjs-pro/exchange-client` ab. Konfigurieren Sie die Server-URLs im gemeinsamen Client und registrieren Sie dann den Slides-Client. Importieren Sie für die Facade API das gemeinsame CSS und `@univerjs-pro/slides-exchange-client/facade`.

```ts
univer.registerPlugin(UniverExchangeClientPlugin, {
  uploadFileServerUrl: '/universer-api/stream/file/upload',
  importServerUrl: '/universer-api/exchange/{type}/import',
  exportServerUrl: '/universer-api/exchange/{type}/export',
  getTaskServerUrl: '/universer-api/exchange/task/{taskID}',
  signUrlServerUrl: '/universer-api/file/{fileID}/sign-url',
  downloadEndpointUrl: location.origin,
  maxTimeoutTime: 120000,
})

univer.registerPlugin(UniverSlidesExchangeClientPlugin)
```

Der Platzhalter `{type}` wird mit `UniverInstanceType.UNIVER_SLIDE` gefüllt. Der Import kann entweder eine serverseitige Einheiten-ID oder einen Snapshot-JSON zurückgeben. Export lädt einen Folien-Snapshot zum Austauschdienst hoch, wartet auf das Aufgabenergebnis, signiert die zurückgegebene Datei-ID und lädt die PPTX-Datei herunter.

## Fassaden-API

Importieren Sie das Fassadenpaket einmal im Plugin-Modus:

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
```

Importieren Sie ein PPTX in eine serverseitige Einheit:

```ts
const unitId = await univerAPI.importSlideToUnitIdAsync(file)
```

Importieren Sie ein PPTX als lokale Foliendaten:

```ts
const slideData = await univerAPI.importSlideToSnapshotAsync(file)

if (slideData) {
  univerAPI.createPresentation(slideData)
}
```

Exportieren Sie das aktuelle Foliendeck:

```ts
const presentation = univerAPI.getActivePresentation()
const file = await univerAPI.exportSlideBySnapshotAsync(presentation.save())
```

Exportieren Sie eine serverseitige Folie Einheit:

```ts
const file = await univerAPI.exportSlideByUnitIdAsync(unitId)
```

## Menüverhalten

Der Slides-Exchange-Client trägt PPTX-Menüaktionen bei:

- `ImportPPTXOperation` importiert in eine vorhandene Einheit, wenn die aktuelle URL einen Abfrageparameter `unit` hat; andernfalls wird es in einen lokalen Schnappschuss importiert.
- `ExportPPTXOperation` exportiert den aktuellen Folienstapel nach Schnappschuss.

Sie können eine `menu`-Konfiguration an `UniverSlidesExchangeClientPlugin` übergeben, wenn Sie die Sichtbarkeit oder Reihenfolge benutzerdefinierter Menüs zusammenführen müssen.

## Zugehörige Einrichtung

- Registrieren Sie `UniverSlidesPlugin` vor dem Exchange-Client, damit Slides-Einheiten verfügbar sind.
- Verwenden Sie Pro-Server-APIs für Authentifizierung, Speicherung, Konvertierung, Aufgabenabfrage und signierten Download URLs.
- Lassen Sie die Druck-, Tabellen- und Diagrammpakete aktiviert, wenn importierte PPTX-Dateien diese Elemente enthalten könnten.
