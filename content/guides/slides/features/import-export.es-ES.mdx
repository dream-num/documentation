Las API de esta página requieren un backend de conversión. Siga [integración del intercambio de archivos](/server/import-export) para conectar cargas, conversión, consultas de tareas y descargas, y luego configurar los plugins del navegador. Las APIs de instantánea también requieren que backend pero no requieren un documento de colaboración. El ejemplo de Exchange muestra hojas, así que compruebe que la versión de destino soporta los tipos de archivo que necesita.

Para errores de exportación, consulte [los códigos de licencia y fallos de tareas](/server/import-export#export-errors).

## Formatos compatibles

La tabla describe los formatos que aceptan las API del navegador en esta página. Convertir archivos de Office también requiere un backend que soporta el mismo tipo de documento y formato.

| Importación | Exportación |
| --- | --- |
| `.ppt`, `.pptx` | `.pptx` |

Tanto `.ppt` como `.pptx` utilizan las API de importación a continuación y exportan siempre produce `.pptx`. El navegador API no acepta `.pptm`, `.ppsx` y `.ppsm` o `.potx` . El soporte de backend para estos formatos por sí solo no los hace trabajar en el navegador.

## API de fachada

En modo plugin, importar los paquetes de fachada una vez:

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
```

Importa un PPTX a una unidad del lado del servidor:

```ts
const unitId = await univerAPI.importSlideToUnitIdAsync(file)
```

Importa un PPTX como datos de diapositiva local:

```ts
const slideData = await univerAPI.importSlideToSnapshotAsync(file)

if (slideData) {
  univerAPI.createPresentation(slideData)
}
```

Exporta el conjunto de diapositivas actual:

```ts
const presentation = univerAPI.getActivePresentation()
const file = await univerAPI.exportSlideBySnapshotAsync(presentation.save())
```

Exporta una diapositiva del lado del servidor unidad:

```ts
const file = await univerAPI.exportSlideByUnitIdAsync(unitId)
```

## Eliminación de los menús y las interacciones de UI de importación y exportación integrados [#import-export-ui-migration]

<Callout type="warning" title="Nota">
  A partir de la versión **1.2.0**, Univer ya no incluye menús integrados de importación/exportación e interacciones UI. Los servicios subyacentes y las API de Facade permanecen disponibles.
</Callout>

Si la aplicación todavía necesita esos menús e interacciones de la interfaz de usuario, el [ejemplo de migración para menús integrados de importación/exportación e interacciones de la UI](https://office.univer.ai/showcase/slides/custom-import-export) explica cómo migrarlos a un plugin personalizado. El ejemplo incluye código fuente completo que usted puede ver en línea o descargar.
