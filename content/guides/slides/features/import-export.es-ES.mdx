## Formatos compatibles

La tabla describe las API del navegador de esta página. La conversión de archivos Office requiere un backend compatible con el mismo tipo de documento y formato.

| Importación | Exportación |
| --- | --- |
| `.ppt`, `.pptx` | `.pptx` |

## API de fachada

Importa el paquete de fachada una vez en modo complemento:

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
```

Importa un PPTX a una unidad del lado del servidor:

```ts
const unitId = await univerAPI.importSlideToUnitIdAsync(file)
```

Importa un PPTX como datos de diapositiva local:

```ts
const slideData = await univerAPI.importSlideToSnapshotAsync(file)

if (slideData) {
  univerAPI.createPresentation(slideData)
}
```

Exporta el conjunto de diapositivas actual:

```ts
const presentation = univerAPI.getActivePresentation()
const file = await univerAPI.exportSlideBySnapshotAsync(presentation.save())
```

Exporta una diapositiva del lado del servidor unidad:

```ts
const file = await univerAPI.exportSlideByUnitIdAsync(unitId)
```

## Eliminación de los menús y las interacciones de UI de importación y exportación integrados [#import-export-ui-migration]

<Callout type="warning" title="Nota">
  A partir de la versión **1.2.0**, Univer eliminó los menús y las interacciones de UI de importación y exportación integrados. Los servicios subyacentes y las API de Facade siguen disponibles.
</Callout>

Si tu aplicación necesita conservar los menús y las interacciones de UI de importación y exportación existentes, consulta el [ejemplo de migración de los menús y las interacciones de UI de importación y exportación integrados](https://office.univer.ai/showcase/slides/custom-import-export) para migrar mediante un plugin personalizado. El ejemplo incluye el código fuente completo para consultarlo en línea y descargarlo.
