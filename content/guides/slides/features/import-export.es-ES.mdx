## Descripción general

La importación y exportación de diapositivas es una capacidad Pro. El cliente del navegador registra el cliente de intercambio compartido más el cliente de intercambio de Presentaciones, mientras que su implementación Pro proporciona la conversión, el sondeo de tareas, el almacenamiento y las URL de descarga firmadas.

```ts
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client'
import ExchangeClientEnUS from '@univerjs-pro/exchange-client/locale/en-US'
import { UniverSlidesExchangeClientPlugin } from '@univerjs-pro/slides-exchange-client'
import SlidesExchangeClientEnUS from '@univerjs-pro/slides-exchange-client/locale/en-US'

import '@univerjs-pro/exchange-client/lib/index.css'
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'

univer.registerPlugin(UniverExchangeClientPlugin)
univer.registerPlugin(UniverSlidesExchangeClientPlugin)
```

## Instalación

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/slides-exchange-client
```

## Configurar puntos finales

`@univerjs-pro/slides-exchange-client` depende de `@univerjs-pro/exchange-client`. Configure las URL en el cliente compartido y registre el cliente de Presentaciones. Para la API de fachada, importe el CSS compartido y `@univerjs-pro/slides-exchange-client/facade`.

```ts
univer.registerPlugin(UniverExchangeClientPlugin, {
  uploadFileServerUrl: '/universer-api/stream/file/upload',
  importServerUrl: '/universer-api/exchange/{type}/import',
  exportServerUrl: '/universer-api/exchange/{type}/export',
  getTaskServerUrl: '/universer-api/exchange/task/{taskID}',
  signUrlServerUrl: '/universer-api/file/{fileID}/sign-url',
  downloadEndpointUrl: location.origin,
  maxTimeoutTime: 120000,
})

univer.registerPlugin(UniverSlidesExchangeClientPlugin)
```

El marcador de posición `{type}` se completa con `UniverInstanceType.UNIVER_SLIDE`. La importación puede devolver una identificación de unidad del lado del servidor o una instantánea JSON. Exportar carga una instantánea de diapositiva al servicio Exchange, espera el resultado de la tarea, firma la identificación del archivo devuelto y descarga el archivo PPTX.

## API de fachada

Importa el paquete de fachada una vez en modo complemento:

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
```

Importa un PPTX a una unidad del lado del servidor:

```ts
const unitId = await univerAPI.importSlideToUnitIdAsync(file)
```

Importa un PPTX como datos de diapositiva local:

```ts
const slideData = await univerAPI.importSlideToSnapshotAsync(file)

if (slideData) {
  univerAPI.createPresentation(slideData)
}
```

Exporta el conjunto de diapositivas actual:

```ts
const presentation = univerAPI.getActivePresentation()
const file = await univerAPI.exportSlideBySnapshotAsync(presentation.save())
```

Exporta una diapositiva del lado del servidor unidad:

```ts
const file = await univerAPI.exportSlideByUnitIdAsync(unitId)
```

## Comportamiento del menú

El cliente de intercambio de Presentaciones aporta acciones de menú PPTX:

- `ImportPPTXOperation` importa a una unidad existente cuando la URL actual tiene un parámetro de consulta `unit`; de lo contrario, importa a una instantánea local.
- `ExportPPTXOperation` exporta la presentación de diapositivas actual por instantánea.

Puedes pasar una configuración `menu` a `UniverSlidesExchangeClientPlugin` cuando necesites fusionar la visibilidad del menú personalizado o realizar pedidos.

## Configuración relacionada

- Registra `UniverSlidesPlugin` antes del cliente Exchange para que las unidades de Presentaciones estén disponibles.
- Utiliza las API del servidor Pro para autenticación, almacenamiento, conversión, sondeo de tareas y descarga firmada. URL.
- Mantenga habilitados los paquetes de impresión, tablas y gráficos si los archivos PPTX importados pueden contener esos elementos.
