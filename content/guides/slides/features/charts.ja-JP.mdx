## チャート機能を登録する

Slides のチャートサポートは、モデルパッケージと UI パッケージで構成されています。 `@univerjs-pro/chart-ui` は、共有エディタのコントロール、ローカルエントリー、スタイルを提供します。

```ts
import ChartUIJaJP from '@univerjs-pro/chart-ui/locale/ja-JP'
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'
import { UniverSlidesChartUIPlugin } from '@univerjs-pro/slides-chart-ui'
import SlidesChartUIJaJP from '@univerjs-pro/slides-chart-ui/locale/ja-JP'
import { LocaleType, mergeLocales } from '@univerjs/core'
import '@univerjs-pro/chart-ui/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart/facade'

univerAPI.loadLocales(LocaleType.JA_JP, mergeLocales(ChartUIJaJP, SlidesChartUIJaJP))
univer.registerPlugin(UniverSlidesChartPlugin)
univer.registerPlugin(UniverSlidesChartUIPlugin)
```

チャートの要素を含むプレゼンテーションを開くか、またはインポートする前にチャートのサポートを登録します。

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/slides/getting-started/installation#mobile-support)を最初に構成します。 このページに記載されているプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換え、**ドキュメントを開く前に**の置換を行います。 モデルプラグイン、スタイル、ロケール、ファサードのインポートをキープし、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/slides-chart-ui` | `UniverSlidesChartUIPlugin` | `UniverSlidesChartMobileUIPlugin` |

## グラフデータ用プラグインの登録 [#chart-data-setup]

参照から来るチャートデータには、[`UniverChartEmbedPlugin`](/reference/packages/plugins/univerjs-pro/chart-embed)が必要です。 プラグインをインストールし、プレゼンテーションを開く前に、初期化中に一度登録します。 `UniverEmbedPlugin`が明示的に設定されている場合は、プラグインを最初に登録します。 モバイルセットアップは同一であり、インライン配列はこのプラグインを必要としません。

```package-install
npm install @univerjs-pro/chart-embed
```

```ts
import { UniverChartEmbedPlugin } from '@univerjs-pro/chart-embed'

univer.registerPlugin(UniverChartEmbedPlugin)
```

## チャートを作成・更新する

`slide.newChart(type)`は、離脱したビルダーを返します。 ビルドされたチャート情報は`slide.insertChart(info)`に渡されるまで、チャートはスライドに表示されません。

```ts
const presentation = univerAPI.getActivePresentation()
if (!presentation) throw new Error('No active presentation')

const slide = presentation.getActiveSlide()
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Month', 'Revenue', 'Cost'],
    ['Jan', 120, 80],
    ['Feb', 180, 96],
    ['Mar', 240, 132],
  ])
  .setTitle('Quarterly revenue')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .setZOrder(1)
  .build()

const chart = await slide.insertChart(info)
chart.setLegend({ visible: true }).bringToFront()

const updatedInfo = chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setSubtitle('FY 2026').build()
await chart.update(updatedInfo)

const svg = await chart.exportImage({ format: 'svg' })
```

インサートされた`chart`のセッターは、すぐにチャートを更新します。`toBuilder(type)`を`update(info)`で使用し、完全な切り離されたコピーやタイプ変更が必要な場合は、`exportImage()`は、UIレンダラーが画像を提供できないときに`undefined`を返します。

`slide.getCharts()`と`slide.getChart(id)`を使用してライブチャートを解決し、チャートを削除するために`await chart.remove()`を呼び出します。 スライドビルダーは`setPlaceholder()`、`setStroke()`および`setZOrder()`を提供します。

## 誤差範囲 [#error-bars]

ビルダーまたはライブチャートで`setErrorBars()`を呼び出します。 基本的な2Dカラム、バー、ライン、スキャッターチャートはエラーバーをサポートします。 `seriesIndex`はゼロベースで、ソースデータにカテゴリフィールドが含まれています。 列と行、`x`バー、およびスキャッターの数値軸の`y`を使用します。

```ts
chart.setErrorBars([
  { seriesIndex: 1, direction: 'y', type: 'both', valueType: 'percentage', value: 20 },
])
```

[`FChart.setErrorBars()`](/reference/facade/chart#seterrorbars)

## 複数レベルのカテゴリ軸

階層的なインラインデータの場合、root-to-leaf の順番でカテゴリフィールドを選択し、複数のレベルのレンダリングを有効にします。

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Region', 'Quarter', 'Revenue'],
    ['North', 'Q1', 120],
    ['North', 'Q2', 148],
    ['South', 'Q1', 98],
    ['South', 'Q2', 132],
  ])
  .setCategoryFields([0, 1])
  .setMultiLevelCategoryAxis(true)
  .setValueFields([2])
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .build()

await slide.insertChart(info)
```

## グラフを Sheets のデータに連携する [#bind-sheet-data]

チャートが値のコピーを格納するのではなく、シート範囲に従うべきなら、リソースリファレンスを `setSource()` に渡します。

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    unit: { selector: 'sales-workbook', type: 'sheet' },
    part: {
      kind: 'range',
      sheetName: 'Data',
      range: 'A1:B20',
      ref: 'Data!A1:B20',
    },
  })
  .setAbsolutePosition(120, 80)
  .setSize(640, 360)
  .build()

const chart = await slide.insertChart(info)
```

[チャートファサード参照](/reference/facade/chart)は、すべてのチャートタイプが共有する設定を文書化します。

共有ビルダーも[3Dチャート構成](/guides/sheets/features/charts#three-dimensional-charts)と[logarithmic 値軸](/guides/sheets/features/charts#logarithmic-axes)をサポートしています。 スライドでは、このページに示すように、`slide.newChart()`を使用してインラインまたは参照されたデータを使用します。
