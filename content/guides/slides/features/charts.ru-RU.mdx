## Регистрация поддержки диаграмм

Поддержка диаграмм Slides состоит из пакета модели и пакета интерфейса. `@univerjs-pro/chart-ui` предоставляет общие элементы редактирования, локали и стили.

```ts
import ChartUIRuRU from '@univerjs-pro/chart-ui/locale/ru-RU'
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'
import { UniverSlidesChartUIPlugin } from '@univerjs-pro/slides-chart-ui'
import SlidesChartUIRuRU from '@univerjs-pro/slides-chart-ui/locale/ru-RU'

import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart/facade'

univer.registerPlugin(UniverSlidesChartPlugin)
univer.registerPlugin(UniverSlidesChartUIPlugin)
```

Зарегистрируйте поддержку диаграмм до открытия или импорта презентации, которая может содержать такие элементы.

## Создание и обновление диаграмм

Управляйте диаграммами через коллекцию `charts` слайда. `create()` возвращает ещё не вставленный конструктор, а `insert()` добавляет его на текущий слайд.

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation.getActiveSlide()

const builder = slide.charts
  .create()
  .setType(univerAPI.Enum.ChartTypeString.Column)
  .setData([
    ['Месяц', 'Выручка', 'Затраты'],
    ['Янв.', 120, 80],
    ['Фев.', 180, 96],
    ['Мар.', 240, 132],
  ])
  .setTitle('Квартальная выручка')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)

const chart = await slide.charts.insert(builder)

chart.setType(univerAPI.Enum.ChartTypeString.Line).setLegend({ visible: true }).commit()
```

Для существующих диаграмм используйте `slide.charts.list()`, `slide.charts.get(id)` и `await slide.charts.remove(chartOrId)`. Конструктор Slides также поддерживает `setData`, `getData`, `setPlaceholder`, `setStroke` и `setZOrder`.

Общие настройки описаны в [справочнике Chart Facade](/reference/facade/chart).

## Привязка данных Sheet

Ссылка на ресурс связывает диаграмму с диапазоном Sheet; `refreshDataSource()` обновляет данные:

```ts
const chart = await slide.charts.insert(
  slide.charts.create().setDataSource({
    unit: { selector: 'sales-workbook', type: 'sheet' },
    part: { kind: 'range', sheetName: 'Data', range: 'A1:B20', ref: 'Data!A1:B20' },
  }),
)
await chart.refreshDataSource()
```
