## Регистрация поддержки диаграмм

Поддержка графиков в Slides состоит из пакета моделей и пакета пользовательского интерфейса. `@univerjs-pro/chart-ui` предоставляет общие элементы управления редактором, записи в локальной сети и стили.

```ts
import ChartUIRuRU from '@univerjs-pro/chart-ui/locale/ru-RU'
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'
import { UniverSlidesChartUIPlugin } from '@univerjs-pro/slides-chart-ui'
import SlidesChartUIRuRU from '@univerjs-pro/slides-chart-ui/locale/ru-RU'
import { LocaleType, mergeLocales } from '@univerjs/core'
import '@univerjs-pro/chart-ui/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart/facade'

univerAPI.loadLocales(LocaleType.RU_RU, mergeLocales(ChartUIRuRU, SlidesChartUIRuRU))
univer.registerPlugin(UniverSlidesChartPlugin)
univer.registerPlugin(UniverSlidesChartUIPlugin)
```

Регистрируйте поддержку диаграмм перед открытием или импортом презентации, которая может содержать элементы диаграммы.

## Поддержка мобильных устройств [#mobile-support]

Сначала настройте [Мобильный редактор](/guides/slides/getting-started/installation#mobile-support). В настройках плагин-режима, описанных на этой странице, замените регистрацию рабочего стола ниже на мобильный экспорт из тех же пакетов и сделайте замену **Перед тем, как открыть документ**, сохраните плагины модели, стили, локализации и импорт Facade и не регистрируйте оба варианта.

| Пакет | Настольная регистрация | Мобильная регистрация |
| --- | --- | --- |
| `@univerjs-pro/slides-chart-ui` | `UniverSlidesChartUIPlugin` | `UniverSlidesChartMobileUIPlugin` |

## Регистрация плагинов данных диаграмм [#chart-data-setup]

Данные диаграммы, которые исходят из ссылки, требуют [`UniverChartEmbedPlugin`](/reference/packages/plugins/univerjs-pro/chart-embed). Установите плагин и зарегистрируйте его один раз во время инициализации, прежде чем открывать презентацию. Если `UniverEmbedPlugin` настроен явно, зарегистрируй этот плагин первым. Мобильная настройка идентична, и встроенные массивы не требуют этого плагина.

```package-install
npm install @univerjs-pro/chart-embed
```

```ts
import { UniverChartEmbedPlugin } from '@univerjs-pro/chart-embed'

univer.registerPlugin(UniverChartEmbedPlugin)
```

## Создание и обновление диаграмм

`slide.newChart(type)` возвращает отсоединённый конструктор.Карта не появляется на слайде до тех пор, пока встроенная информация о графике не будет передана `slide.insertChart(info)`.

```ts
const presentation = univerAPI.getActivePresentation()
if (!presentation) throw new Error('No active presentation')

const slide = presentation.getActiveSlide()
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Month', 'Revenue', 'Cost'],
    ['Jan', 120, 80],
    ['Feb', 180, 96],
    ['Mar', 240, 132],
  ])
  .setTitle('Quarterly revenue')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .setZOrder(1)
  .build()

const chart = await slide.insertChart(info)
chart.setLegend({ visible: true }).bringToFront()

const updatedInfo = chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setSubtitle('FY 2026').build()
await chart.update(updatedInfo)

const svg = await chart.exportImage({ format: 'svg' })
```

Сеттеры на вставленном `chart` обновляют график немедленно. Используйте `toBuilder(type)` с `update(info)`, когда требуется полная отсоединенная копия или изменение типа. `exportImage()` возвращает `undefined` когда ни один UI-рендер не может предоставить изображение.

Используйте `slide.getCharts()` и `slide.getChart(id)` для разрешения живых графиков и звоните `await chart.remove()`, чтобы удалить диаграмму. Слайдеры также предоставляют `setPlaceholder()` , `setStroke()` а также `setZOrder()`.

## Пределы погрешностей [#error-bars]

Звоните `setErrorBars()` на конструкторе или на живом графике. Базовые 2D колонки, бары, линии и диаграммы рассеяния поддерживают бары ошибок. `seriesIndex` основан на нуле и включает поле категорий в исходные данные. Используйте `y` для столбцов и линий, `x` — для баров, и либо числовую ось — для рассеяния.

```ts
chart.setErrorBars([
  { seriesIndex: 1, direction: 'y', type: 'both', valueType: 'percentage', value: 20 },
])
```

[`FChart.setErrorBars()`](/reference/facade/chart#seterrorbars)

## Многоуровневые оси категорий

Для иерархических встроенных данных выберите поля категорий в порядке от корня до листа и включите многоуровневую визуализацию:

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Region', 'Quarter', 'Revenue'],
    ['North', 'Q1', 120],
    ['North', 'Q2', 148],
    ['South', 'Q1', 98],
    ['South', 'Q2', 132],
  ])
  .setCategoryFields([0, 1])
  .setMultiLevelCategoryAxis(true)
  .setValueFields([2])
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .build()

await slide.insertChart(info)
```

## Привязка диаграммы к данным Sheets [#bind-sheet-data]

Если диаграмма должна следовать диапазону листов вместо хранения копии значений, передайте ссылку на ресурс `setSource()`:

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    unit: { selector: 'sales-workbook', type: 'sheet' },
    part: {
      kind: 'range',
      sheetName: 'Data',
      range: 'A1:B20',
      ref: 'Data!A1:B20',
    },
  })
  .setAbsolutePosition(120, 80)
  .setSize(640, 360)
  .build()

const chart = await slide.insertChart(info)
```

[Ссылка на Chart Facade](/reference/facade/chart) документирует конфигурацию, которую разделяют все типы графиков.

Общие конструкторы также поддерживают [3D диаграмма конфигурации](/guides/sheets/features/charts#three-dimensional-charts), [логарифмические оси значений](/guides/sheets/features/charts#logarithmic-axes) и [подписи шкалы радарных диаграмм](/guides/sheets/features/charts#radar-charts). В Slides используйте `slide.newChart()` с встроенными или ссылающимися данными, как показано на этой странице.
