## Подключение поддержки диаграмм

Поддержка диаграмм в Slides разделена на пакет модели и пакет пользовательского интерфейса:

`@univerjs-pro/chart-ui` — это общая зависимость с компонентами интерфейса диаграмм, которую использует пакет интерфейса диаграмм Slides.

```ts
import ChartUIEnUS from '@univerjs-pro/chart-ui/locale/en-US'
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'
import { UniverSlidesChartUIPlugin } from '@univerjs-pro/slides-chart-ui'
import SlidesChartUIEnUS from '@univerjs-pro/slides-chart-ui/locale/en-US'

import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart/facade'

univer.registerPlugin(UniverSlidesChartPlugin)
univer.registerPlugin(UniverSlidesChartUIPlugin)
```

## Назначение пакетов

- `@univerjs-pro/slides-chart` интегрирует элементы диаграмм с моделью слайдов и движком диаграмм.
- `@univerjs-pro/chart-ui` предоставляет общие элементы управления редактора диаграмм, локализации и файл `@univerjs-pro/chart-ui/lib/index.css` для пакетов Pro с интерфейсом диаграмм.
- `@univerjs-pro/slides-chart-ui` добавляет интерфейс редактирования диаграмм, интеграцию с системой рендеринга, панели вставки и редактирование источников данных. Пакет также предоставляет локализации `@univerjs-pro/slides-chart-ui/locale/*` и файл `@univerjs-pro/slides-chart-ui/lib/index.css` для браузерных редакторов.

## Выбор среды выполнения

В браузерном редакторе используйте оба пакета. Для серверной обработки снимков зарегистрируйте пакет модели вместе с основной моделью Slides:

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesChartPlugin)
```

Подключите поддержку диаграмм до открытия или импорта презентаций, в которых могут быть элементы диаграмм.

## Создание диаграммы

В диаграммах Slides источником данных служат встроенные двумерные массивы. Они не считывают данные напрямую из диапазонов листа.

```ts
const fPresentation = univerAPI.getActivePresentation()
const fSlide = fPresentation.getSlideById('slide-1')

const chartInfo = fSlide.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .setData([
    ['Month', 'Revenue', 'Cost'],
    ['Jan', 120, 80],
    ['Feb', 180, 96],
    ['Mar', 240, 132],
  ])
  .setUseFirstRowAsHeaders(true)
  .setUseFirstColumnAsDomain(true)
  .setTitle('Quarterly revenue')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .build()

const chart = fSlide.insertChart(chartInfo)
```

## Обновление диаграммы

Чтобы найти существующие диаграммы, используйте `getCharts()` или `getChartById()`. Метод `updateDataSource()` обновляет встроенные данные, не перемещая элемент диаграммы.

```ts
const chart = fSlide.getCharts()[0]

chart?.updateDataSource(
  [
    ['Month', 'Revenue', 'Cost'],
    ['Apr', 260, 140],
    ['May', 300, 168],
  ],
  {
    useFirstRowAsHeaders: true,
    useFirstColumnAsDomain: true,
  },
)
```

Для более значительных изменений преобразуйте диаграмму обратно в построитель и вызовите `updateChart()`:

```ts
if (chart) {
  const nextChartInfo = chart.toBuilder()
    .setChartType(univerAPI.Enum.ChartType.Line)
    .setOptions('legend.position', univerAPI.Enum.ChartLegendPositionEnum.Right)
    .setSeriesStyle(0, { color: '#2F80ED' })
    .build()

  fSlide.updateChart(nextChartInfo)
}
```

## Удаление диаграммы

```ts
chart?.remove()
// or
if (chart) {
  fSlide.removeChart(chart)
}
```
