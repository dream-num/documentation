## Подключение поддержки печати

Используйте `@univerjs-pro/slides-print`, если в редакторе Slides нужны предварительный просмотр перед печатью или связанные с печатью facade API. Пакет также предоставляет `@univerjs-pro/slides-print/locale/*`; отдельно импортировать CSS не требуется.

```ts
import { UniverSlidesPrintPlugin } from '@univerjs-pro/slides-print'
import SlidesPrintEnUS from '@univerjs-pro/slides-print/locale/en-US'
import '@univerjs-pro/slides-print/facade'

univer.registerPlugin(UniverSlidesPrintPlugin)
```

## Требования

Зарегистрируйте основную модель Slides до плагина печати:

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
univer.registerPlugin(UniverSlidesPrintPlugin)
```

В браузерном редакторе оставьте зарегистрированными движок рендеринга, UI-плагин, Docs, Drawing и плагины лицензирования, как показано в [кратком руководстве](/guides/slides/getting-started/quickstart).

## Facade API

Импортируйте точку входа facade, чтобы добавить `printSlidesAsync` в `FUniver`:

```ts
import '@univerjs-pro/slides-print/facade'
```

Печать всех слайдов активной презентации:

```ts
const univerAPI = FUniver.newAPI(univer)

await univerAPI.printSlidesAsync()
```

Печать выбранных диапазонов слайдов по номерам страниц, начиная с 1:

```ts
await univerAPI.printSlidesAsync({
  range: [
    { from: 1, to: 3 },
    { from: 6, to: 6 },
  ],
})
```

`range` принимает диапазоны страниц, включающие обе границы. Если параметр не указан, печатаются все слайды. Повторы в пересекающихся диапазонах удаляются, а слайды печатаются в исходном порядке. Диапазоны, выходящие за пределы презентации, ограничиваются доступными слайдами, а некорректные диапазоны с обратным порядком границ игнорируются.

## Примечания

Результат печати зависит от текущего снимка слайдов, размера страницы, графических элементов, а также необязательных таблиц и диаграмм. Если презентация может содержать таблицы или диаграммы, зарегистрируйте соответствующие плагины до печати.

## Макет и предварительный просмотр

```ts
univerAPI.openSlidesPrintDialog({
  layout: univerAPI.Enum.SlidePrintLayoutType.Handout,
  slidesPerPage: 6,
  handoutOrder: univerAPI.Enum.SlidePrintHandoutOrder.Horizontal,
  frameSlides: true,
  showSlideNumber: true,
})
```

Доступны полноэкранный макет, раздаточный материал и страницы заметок, а также параметры бумаги, ориентации и полей.
