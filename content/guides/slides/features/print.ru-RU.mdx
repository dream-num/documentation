## Подключение поддержки печати

Добавьте `@univerjs-pro/slides-print`, когда редактор Slides требует предварительного просмотра печати или API фасада печати. Пакет также предоставляет локализации под `@univerjs-pro/slides-print/locale/*`.

```ts
import { UniverSlidesPrintPlugin } from '@univerjs-pro/slides-print'
import SlidesPrintEnUS from '@univerjs-pro/slides-print/locale/en-US'
import '@univerjs-pro/slides-print/facade'

univer.registerPlugin(UniverSlidesPrintPlugin)
```

## Поддержка мобильных устройств [#mobile-support]

Сначала настройте [Мобильный редактор](/guides/slides/getting-started/installation#mobile-support). В настройке плагин-режима на этой странице замените регистрацию рабочего стола ниже на мобильный экспорт из тех же пакетов, и сделайте это **Перед тем, как открыть документ**, сохраните плагины модели, стили, локализации и импорт Facade и зарегистрируйте только один вариант.

| Пакет | Настольная регистрация | Мобильная регистрация |
| --- | --- | --- |
| `@univerjs-pro/slides-print` | `UniverSlidesPrintPlugin` | `UniverSlidesPrintMobilePlugin` |

## Требования

Зарегистрируйте основную модель Slides до плагина печати:

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
univer.registerPlugin(UniverSlidesPrintPlugin)
```

Редактор браузера также требует движка рендеринга, плагина пользовательского интерфейса, Docs, Drawing и лицензионных плагинов, как показано в [Быстрый старт](/guides/slides/getting-started/quickstart).

## Facade API

Импортируйте точку входа facade, чтобы добавить `printSlidesAsync` в `FUniver`:

```ts
import '@univerjs-pro/slides-print/facade'
```

Печать каждого слайда в активной презентации:

```ts
const univerAPI = FUniver.newAPI(univer)

await univerAPI.printSlidesAsync()
```

Распечатайте выбор по номеру страницы на 1 основе:

```ts
await univerAPI.printSlidesAsync({
  range: [
    { from: 1, to: 3 },
    { from: 6, to: 6 },
  ],
})
```

## Примечания

Результат печати зависит от текущего снимка слайдов, размера страницы, графических элементов, а также необязательных таблиц и диаграмм. Если презентация может содержать таблицы или диаграммы, зарегистрируйте соответствующие плагины до печати.

```ts
import { SlidePrintHandoutOrder, SlidePrintLayoutType } from '@univerjs-pro/slides-print'

univerAPI.openSlidesPrintDialog({
  layout: SlidePrintLayoutType.Handout,
  slidesPerPage: 6,
  handoutOrder: SlidePrintHandoutOrder.Horizontal,
  frameSlides: true,
  showSlideNumber: true,
})
```

Варианты также включают `paperSize`, `direction`, `margin` и `marginCustom`.Раздаточный материал поддерживает 1, 2, 3, 4, 6 или 9 слайдов на странице.

`range` принимает включающие диапазоны страниц. Если параметр опущен, каждый слайд-принтер отпечатывается. Перекрывающиеся диапазоны раздуваются и печатаются в порядке слайд. Диапазон, который выходит за пределы конца колоды, обрезается до существующих слайдов, а обратный диапазон игнорируется.

## Заметки

Выход печати зависит от текущего слайд-снимка, размера страницы, заметок динамика, элементов рисунка и любых элементов таблицы или диаграммы.Если колода может содержать таблицы или графики, зарегистрируйте эти плагины перед печатью.
