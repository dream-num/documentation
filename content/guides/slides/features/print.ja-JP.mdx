## 印刷機能の登録

Slides エディターで印刷プレビュー、または印刷関連の facade API が必要な場合は、`@univerjs-pro/slides-print` を使用します。この package は `@univerjs-pro/slides-print/locale/*` も提供し、追加の CSS import は不要です。

```ts
import { UniverSlidesPrintPlugin } from '@univerjs-pro/slides-print'
import SlidesPrintEnUS from '@univerjs-pro/slides-print/locale/en-US'
import '@univerjs-pro/slides-print/facade'

univer.registerPlugin(UniverSlidesPrintPlugin)
```

## 依存関係

印刷プラグインは、コアの Slides モデルの後に登録します：

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
univer.registerPlugin(UniverSlidesPrintPlugin)
```

ブラウザーエディターでは、[クイックスタート](/guides/slides/getting-started/quickstart) に示されている render engine、UI、Docs、Drawing、license プラグインも登録したままにしてください。

## Facade API

facade エントリをインポートすると、`FUniver` に `printSlidesAsync` メソッドが追加されます：

```ts
import '@univerjs-pro/slides-print/facade'
```

現在アクティブなプレゼンテーションのすべてのスライドを印刷します：

```ts
const univerAPI = FUniver.newAPI(univer)

await univerAPI.printSlidesAsync()
```

1 から始まるページ範囲を指定して印刷することもできます：

```ts
await univerAPI.printSlidesAsync({
  range: [
    { from: 1, to: 3 },
    { from: 6, to: 6 },
  ],
})
```

`range` は両端を含むページ範囲です。省略した場合はすべてのスライドを印刷します。重複する範囲は重複排除され、元のスライド順で印刷されます。deck の範囲を超える指定は利用可能なページに切り詰められ、開始と終了が逆の無効な範囲は無視されます。

## 注意事項

印刷出力は、現在の slide snapshot、ページサイズ、drawing 要素、および任意の table/chart 要素に依存します。deck に table や chart が含まれる可能性がある場合は、印刷前に対応する機能プラグインを登録してください。

## レイアウトとプレビュー

```ts
univerAPI.openSlidesPrintDialog({
  layout: univerAPI.Enum.SlidePrintLayoutType.Handout,
  slidesPerPage: 6,
  handoutOrder: univerAPI.Enum.SlidePrintHandoutOrder.Horizontal,
  frameSlides: true,
  showSlideNumber: true,
})
```

フルページ、配布資料、ノートページの各レイアウトと、用紙・向き・余白設定に対応します。
