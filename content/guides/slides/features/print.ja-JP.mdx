## 印刷機能の登録

Slidesエディタで`@univerjs-pro/slides-print`を追加すると、プリントプレビューやプリントファサードAPIが必要です。パッケージは`@univerjs-pro/slides-print/locale/*`の下にローカルも提供しているため、別々のCSSインポートは必要ありません。

```ts
import { UniverSlidesPrintPlugin } from '@univerjs-pro/slides-print'
import SlidesPrintEnUS from '@univerjs-pro/slides-print/locale/en-US'
import '@univerjs-pro/slides-print/facade'

univer.registerPlugin(UniverSlidesPrintPlugin)
```

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/slides/getting-started/installation#mobile-support)を最初に構成します。 このページのプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換え、**ドキュメントを開く前に**を実行します。 モデルプラグイン、スタイル、ロケール、ファサードのインポートを保存し、1つのバリアントだけを登録します。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/slides-print` | `UniverSlidesPrintPlugin` | `UniverSlidesPrintMobilePlugin` |

## 依存関係

印刷プラグインは、コアの Slides モデルの後に登録します：

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
univer.registerPlugin(UniverSlidesPrintPlugin)
```

ブラウザエディタでは、[クイックスタート](/guides/slides/getting-started/quickstart) に示すように、レンダリングエンジン、UI プラグイン、Docs、Drawing、およびライセンスプラグインも必要です。

## Facade API

facade エントリをインポートすると、`FUniver` に `printSlidesAsync` メソッドが追加されます：

```ts
import '@univerjs-pro/slides-print/facade'
```

アクティブなプレゼンテーションですべてのスライドを印刷します。

```ts
const univerAPI = FUniver.newAPI(univer)

await univerAPI.printSlidesAsync()
```

1ページ番号で選択を印刷します。

```ts
await univerAPI.printSlidesAsync({
  range: [
    { from: 1, to: 3 },
    { from: 6, to: 6 },
  ],
})
```

## 注意事項

印刷出力は、現在の slide snapshot、ページサイズ、drawing 要素、および任意の table/chart 要素に依存します。deck に table や chart が含まれる可能性がある場合は、印刷前に対応する機能プラグインを登録してください。

```ts
import { SlidePrintHandoutOrder, SlidePrintLayoutType } from '@univerjs-pro/slides-print'

univerAPI.openSlidesPrintDialog({
  layout: SlidePrintLayoutType.Handout,
  slidesPerPage: 6,
  handoutOrder: SlidePrintHandoutOrder.Horizontal,
  frameSlides: true,
  showSlideNumber: true,
})
```

オプションには`paperSize`、`direction`, `margin`、`marginCustom`も含まれます。 ハンドアウトは、1ページあたり 1, 2, 3, 4, 6, または 9 のスライドをサポートしています。

`range`は、包括的なページ範囲を受け入れます。 パラメータが省略された場合、すべてのスライドプリント。 オーバーラップ範囲は、スライドオーダーで重複して印刷されます。 デッキの端を超えて拡張する範囲は、存在するスライドにクリップされ、逆にされた範囲は無視されます。

## インフォメーション

プリントアウトプットは、現在のスライドスナップショット、ページサイズ、スピーカーノート、描画要素、およびテーブルまたはチャート要素によって異なります。 デッキにテーブルやチャートが含まれている場合は、印刷する前にそれらの機能プラグインを登録します。
