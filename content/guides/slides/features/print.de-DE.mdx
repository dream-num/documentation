## Druckunterstützung registrieren

Verwenden Sie `@univerjs-pro/slides-print`, wenn ein Folieneditor eine Druckvorschau oder druckbezogene Fassaden-APIs benötigt. Das Paket bietet außerdem `@univerjs-pro/slides-print/locale/*`; Es ist kein separater CSS-Import erforderlich.

```ts
import { UniverSlidesPrintPlugin } from '@univerjs-pro/slides-print'
import SlidesPrintEnUS from '@univerjs-pro/slides-print/locale/en-US'
import '@univerjs-pro/slides-print/facade'

univer.registerPlugin(UniverSlidesPrintPlugin)
```

## Anforderungen

Registrieren Sie das Slides-Kernmodell vor dem Druck-Plugin:

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
univer.registerPlugin(UniverSlidesPrintPlugin)
```

Lassen Sie bei einem Browser-Editor die Render-Engine, das UI-Plugin, Dokumente, Zeichnungen und Lizenz-Plugins registriert, wie in [Schnellstart](/guides/slides/getting-started/quickstart) gezeigt.

## Fassaden-API

Importieren Sie den hinzuzufügenden Fassadeneintrag `printSlidesAsync` bis `FUniver`:

```ts
import '@univerjs-pro/slides-print/facade'
```

Alle Folien in der aktiven Präsentation drucken:

```ts
const univerAPI = FUniver.newAPI(univer)

await univerAPI.printSlidesAsync()
```

Ausgewählte Folienbereiche nach 1-basierter Seitenzahl drucken:

```ts
await univerAPI.printSlidesAsync({
  range: [
    { from: 1, to: 3 },
    { from: 6, to: 6 },
  ],
})
```

`range` akzeptiert inklusive Seitenbereiche. Wenn es weggelassen wird, werden alle Folien gedruckt. Überlappende Bereiche werden dedupliziert und in der ursprünglichen Folienreihenfolge gedruckt. Bereiche außerhalb des Decks werden auf die verfügbaren Folien zugeschnitten und ungültige umgekehrte Bereiche werden ignoriert.

## Hinweise

Die Druckausgabe hängt vom aktuellen Folienschnappschuss, der Seitengröße, den Zeichnungselementen und optionalen Tabellen- oder Diagrammelementen ab. Wenn Ihr Deck Tabellen oder Diagramme enthalten kann, registrieren Sie diese Funktions-Plugins vor dem Drucken.

## Layout und Vorschau

```ts
univerAPI.openSlidesPrintDialog({
  layout: univerAPI.Enum.SlidePrintLayoutType.Handout,
  slidesPerPage: 6,
  handoutOrder: univerAPI.Enum.SlidePrintHandoutOrder.Horizontal,
  frameSlides: true,
  showSlideNumber: true,
})
```

Unterstützt werden Ganzseiten-, Handout- und Notizseitenlayout sowie Papier-, Ausrichtungs- und Randeinstellungen.
