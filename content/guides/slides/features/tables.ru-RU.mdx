## Подключение поддержки таблиц

Поддержка таблицы слайдов состоит из двух пакетов, один для модели и один для пользовательского интерфейса:

```ts
import { UniverSlidesTablePlugin } from '@univerjs-pro/slides-table'
import { UniverSlidesTableUIPlugin } from '@univerjs-pro/slides-table-ui'
import SlidesTableUIEnUS from '@univerjs-pro/slides-table-ui/locale/en-US'

import '@univerjs-pro/slides-table-ui/lib/index.css'
import '@univerjs-pro/slides-table/facade'

univer.registerPlugin(UniverSlidesTablePlugin)
univer.registerPlugin(UniverSlidesTableUIPlugin)
```

## Поддержка мобильных устройств [#mobile-support]

Сначала настройте [Мобильный редактор](/guides/slides/getting-started/installation#mobile-support). В настройке плагин-режима на этой странице замените регистрацию рабочего стола ниже на мобильный экспорт из тех же пакетов, и сделайте это **Перед тем, как открыть документ**, сохраните плагины модели, стили, локализации и импорт Facade и зарегистрируйте только один вариант.

| Пакет | Настольная регистрация | Мобильная регистрация |
| --- | --- | --- |
| `@univerjs-pro/slides-table-ui` | `UniverSlidesTableUIPlugin` | `UniverSlidesTableMobileUIPlugin` |

## Назначение пакетов

- `@univerjs-pro/slides-table` хранит элементы таблицы в слайд-модели и предоставляет фасадные API для операций с таблицами.
- `@univerjs-pro/slides-table-ui` обеспечивает пользовательский интерфейс редактирования браузера, включая интеграцию рендеринга, поведение выбора и действия контекстного меню. Пакет также предоставляет `@univerjs-pro/slides-table-ui/locale/*` и `@univerjs-pro/slides-table-ui/lib/index.css`.

## Выбор среды выполнения

В процессе Node.js импортировать только модельный пакет, если рендеринг браузера также не требуется.

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesTablePlugin)
```

Зарегистрируйте поддержку таблицы перед открытием или импортом колоды, которая может содержать элементы таблицы, иначе время выполнения не может полностью интерпретировать эти элементы.

## Стабильные цвета таблиц

При вставке таблицы или изменении ее стиля плагин разрешает текущую палитру тем в снимок, которым владеет таблица. Существующие таблицы сохраняют эти цвета после изменения глобальной темы Univer, а выбор другого стиля таблицы создает новый снимок. Стандартные операции Facade обрабатывают это автоматически.

## Facade API

Импортируйте точку входа facade, чтобы добавить методы таблиц в `FSlide`:

```ts
import '@univerjs-pro/slides-table/facade'
```

Создание таблицы из обычных текстовых данных:

```ts
const fPresentation = univerAPI.getActivePresentation()
const fSlide = fPresentation.getSlideById('slide-1')

const table = fSlide.insertTableFromData(
  [
    ['Quarter', 'Owner', 'Status'],
    ['Q1', 'Sales', 'Done'],
    ['Q2', 'Marketing', 'In progress'],
  ],
  {
    id: 'status-table',
    rowHeight: 42,
    columnWidth: 160,
  },
)
```

Используйте конструктор таблиц, когда требуется явный контроль положения и размера:

```ts
const tableInfo = fSlide.newTable()
  .setValues([
    ['Metric', 'Value'],
    ['Revenue', '$120K'],
  ])
  .setRows(2)
  .setColumns(2)
  .setAbsolutePosition(80, 120)
  .setSize(420, 180)
  .build()

const table = fSlide.insertTable(tableInfo)
```

Чтение и изменение ячеек таблицы:

```ts
const table = fSlide.getTableById('status-table') ?? fSlide.getTableAt(0)

if (table) {
  console.log(table.describe())
  console.log(table.getCellText(0, 0))

  table.getCell(1, 2)?.setText('Blocked')
  table.getCell(0, 0)?.setBackgroundColor('#E8F1FF')
}
```

Изменение или удаление существующей таблицы:

```ts
const table = fSlide.getTableById('status-table')

if (table) {
  const nextTableInfo = table.toBuilder()
    .setValues([
      ['Quarter', 'Owner', 'Status'],
      ['Q1', 'Sales', 'Done'],
      ['Q2', 'Marketing', 'Blocked'],
    ])
    .setSize(480, 200)
    .build()

  fSlide.updateTable(nextTableInfo)
  fSlide.removeTable(table)
}
```

Индексы строк таблицы и столбцов основаны на нуле. Строитель увеличивает свой ряд и столбец, чтобы соответствовать значениям, переданным ему, поэтому для простой таблицы `setValues()` может служить источником истины.
