## 注册图表支持

Slides 的图表能力由一个模型包和一个 UI 包组成。`@univerjs-pro/chart-ui` 提供共享的编辑器控件、语言包和样式。

```ts
import ChartUIZhCN from '@univerjs-pro/chart-ui/locale/zh-CN'
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'
import { UniverSlidesChartUIPlugin } from '@univerjs-pro/slides-chart-ui'
import SlidesChartUIZhCN from '@univerjs-pro/slides-chart-ui/locale/zh-CN'
import { LocaleType, mergeLocales } from '@univerjs/core'
import '@univerjs-pro/chart-ui/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart/facade'

univerAPI.loadLocales(LocaleType.ZH_CN, mergeLocales(ChartUIZhCN, SlidesChartUIZhCN))
univer.registerPlugin(UniverSlidesChartPlugin)
univer.registerPlugin(UniverSlidesChartUIPlugin)
```

图表支持必须在打开或导入可能包含图表元素的演示文稿之前注册。

## 移动端适配 [#mobile-support]

请先配置[移动端编辑器](/guides/slides/getting-started/installation#mobile-support)。在本页介绍的插件模式初始化代码中，将下面列出的桌面端注册替换为同一个包导出的移动端插件，并且必须在**打开文档前**完成替换。模型插件、样式、语言包和 Facade 导入均需保留，不要同时注册两个版本。

| 来源包 | 桌面端注册 | 移动端注册 |
| --- | --- | --- |
| `@univerjs-pro/slides-chart-ui` | `UniverSlidesChartUIPlugin` | `UniverSlidesChartMobileUIPlugin` |

## 注册图表数据插件 [#chart-data-setup]

图表数据来自引用时，需要 [`UniverChartEmbedPlugin`](/reference/packages/plugins/univerjs-pro/chart-embed)。安装后应在初始化阶段注册一次，注册位置在打开演示文稿之前。如需显式配置 `UniverEmbedPlugin`，应先注册该插件。移动端配置相同；内联数组数据不需要此插件。

```package-install
npm install @univerjs-pro/chart-embed
```

```ts
import { UniverChartEmbedPlugin } from '@univerjs-pro/chart-embed'

univer.registerPlugin(UniverChartEmbedPlugin)
```

## 创建和更新图表

`slide.newChart(type)` 返回一个独立的构建器，图表不会自动出现在幻灯片上。只有把 `build()` 的结果传给 `slide.insertChart(info)` 之后，图表才会插入幻灯片。

```ts
const presentation = univerAPI.getActivePresentation()
if (!presentation) throw new Error('No active presentation')

const slide = presentation.getActiveSlide()
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Month', 'Revenue', 'Cost'],
    ['Jan', 120, 80],
    ['Feb', 180, 96],
    ['Mar', 240, 132],
  ])
  .setTitle('Quarterly revenue')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .setZOrder(1)
  .build()

const chart = await slide.insertChart(info)
chart.setLegend({ visible: true }).bringToFront()

const updatedInfo = chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setSubtitle('FY 2026').build()
await chart.update(updatedInfo)

const svg = await chart.exportImage({ format: 'svg' })
```

对已插入的 `chart` 调用 setter 会立即更新该图表。需要完整的独立副本或更改图表类型时，请使用 `toBuilder(type)` 配合 `update(info)`。当没有 UI 渲染器能生成图片时，`exportImage()` 返回 `undefined`。

使用 `slide.getCharts()` 和 `slide.getChart(id)` 获取实时图表，删除图表时调用 `await chart.remove()`。Slides 的构建器还提供 `setPlaceholder()`、`setStroke()` 和 `setZOrder()`。

## 误差线 [#error-bars]

在构建器或已有图表上均可调用 `setErrorBars()`。基础二维柱形图、条形图、折线图和散点图支持误差线。`seriesIndex` 从 0 开始计数，并且包含源数据中的分类字段。柱形图和折线图使用 `y`，条形图使用 `x`，散点图可以使用任一数值轴。

```ts
chart.setErrorBars([
  { seriesIndex: 1, direction: 'y', type: 'both', valueType: 'percentage', value: 20 },
])
```

[`FChart.setErrorBars()`](/reference/facade/chart#seterrorbars)

## 多级分类轴

对于内联的层级数据，按从根到叶的顺序选择分类字段，并启用多级渲染：

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Region', 'Quarter', 'Revenue'],
    ['North', 'Q1', 120],
    ['North', 'Q2', 148],
    ['South', 'Q1', 98],
    ['South', 'Q2', 132],
  ])
  .setCategoryFields([0, 1])
  .setMultiLevelCategoryAxis(true)
  .setValueFields([2])
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .build()

await slide.insertChart(info)
```

## 将图表绑定到 Sheets 数据 [#bind-sheet-data]

如果图表需要跟随 Sheet 区域，而不是保存数值副本，请将资源引用传给 `setSource()`：

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    unit: { selector: 'sales-workbook', type: 'sheet' },
    part: {
      kind: 'range',
      sheetName: 'Data',
      range: 'A1:B20',
      ref: 'Data!A1:B20',
    },
  })
  .setAbsolutePosition(120, 80)
  .setSize(640, 360)
  .build()

const chart = await slide.insertChart(info)
```

各类图表共用的配置请参阅[图表 Facade 参考](/reference/facade/chart)。

共享构建器也支持[三维图表配置](/guides/sheets/features/charts#three-dimensional-charts)和[对数数值轴](/guides/sheets/features/charts#logarithmic-axes)。在 Slides 中，使用本页示例的 `slide.newChart()`，传入内联数据或文档数据引用。
