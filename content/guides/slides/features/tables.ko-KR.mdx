## 표 기능 등록

슬라이드 테이블 지원은 모델과 UI에 대한 두 가지 패키지로 구성되어 있습니다.

```ts
import { UniverSlidesTablePlugin } from '@univerjs-pro/slides-table'
import { UniverSlidesTableUIPlugin } from '@univerjs-pro/slides-table-ui'
import SlidesTableUIEnUS from '@univerjs-pro/slides-table-ui/locale/en-US'

import '@univerjs-pro/slides-table-ui/lib/index.css'
import '@univerjs-pro/slides-table/facade'

univer.registerPlugin(UniverSlidesTablePlugin)
univer.registerPlugin(UniverSlidesTableUIPlugin)
```

## 모바일 지원 [#mobile-support]

[모바일 편집기](/guides/slides/getting-started/installation#mobile-support)를 먼저 구성하십시오. 이 페이지의 플러그인 모드 설정에서 동일한 패키지에서 모바일 내보내기로 아래 데스크탑 등록을 대체하고 **문서 열기**을 수행하십시오. 모델 플러그인, 스타일, 로컬 및 Facade 가져 오기를 유지하고 하나의 변형 만 등록하십시오.

| 패키지 | 데스크톱 등록 | 모바일 등록 |
| --- | --- | --- |
| `@univerjs-pro/slides-table-ui` | `UniverSlidesTableUIPlugin` | `UniverSlidesTableMobileUIPlugin` |

## 패키지 역할

- `@univerjs-pro/slides-table`는 슬라이드 모델의 테이블 요소를 저장하고 테이블 작업을위한 정면 API를 제공합니다.
- `@univerjs-pro/slides-table-ui`는 렌더링 통합, 선택 행동 및 컨텍스트 메뉴 작업을 포함하여 브라우저 편집 UI를 제공합니다. 패키지는 `@univerjs-pro/slides-table-ui/locale/*` 및 `@univerjs-pro/slides-table-ui/lib/index.css`를 제공합니다.

## 런타임 선택

브라우저 편집기는 패키지를 모두 필요로 합니다. Node.js 프로세스에서 브라우저 렌더링이 필요한 경우 모델 패키지만 가져올 수 있습니다.

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesTablePlugin)
```

테이블 요소를 포함 할 수있는 데크를 열거나 가져 오기 전에 테이블 지원을 등록하십시오. 그렇지 않으면 런타임은 그 요소를 완전히 해석 할 수 없습니다.

## 안정적인 표 색상

테이블이 삽입되거나 스타일 변경 될 때 플러그인은 테이블이 소유 한 스냅 샷으로 현재 테마 팔레트를 해결합니다. 기존 테이블은 글로벌 Univer 테마 변경 후 그 색상을 유지하고 다른 테이블 스타일을 선택하면 새로운 스냅 샷을 만듭니다. 표준 Facade 작업은 자동으로 처리됩니다.

## Facade API

facade 항목을 가져와 `FSlide`에 표 메서드를 추가합니다.

```ts
import '@univerjs-pro/slides-table/facade'
```

일반 텍스트 데이터로 표를 만듭니다.

```ts
const fPresentation = univerAPI.getActivePresentation()
const fSlide = fPresentation.getSlideById('slide-1')

const table = fSlide.insertTableFromData(
  [
    ['Quarter', 'Owner', 'Status'],
    ['Q1', 'Sales', 'Done'],
    ['Q2', 'Marketing', 'In progress'],
  ],
  {
    id: 'status-table',
    rowHeight: 42,
    columnWidth: 160,
  },
)
```

위치와 크기에 명시된 제어가 필요한 경우 테이블 빌더를 사용하십시오:

```ts
const tableInfo = fSlide.newTable()
  .setValues([
    ['Metric', 'Value'],
    ['Revenue', '$120K'],
  ])
  .setRows(2)
  .setColumns(2)
  .setAbsolutePosition(80, 120)
  .setSize(420, 180)
  .build()

const table = fSlide.insertTable(tableInfo)
```

표 셀을 읽고 업데이트합니다.

```ts
const table = fSlide.getTableById('status-table') ?? fSlide.getTableAt(0)

if (table) {
  console.log(table.describe())
  console.log(table.getCellText(0, 0))

  table.getCell(1, 2)?.setText('Blocked')
  table.getCell(0, 0)?.setBackgroundColor('#E8F1FF')
}
```

기존 표를 업데이트하거나 제거합니다.

```ts
const table = fSlide.getTableById('status-table')

if (table) {
  const nextTableInfo = table.toBuilder()
    .setValues([
      ['Quarter', 'Owner', 'Status'],
      ['Q1', 'Sales', 'Done'],
      ['Q2', 'Marketing', 'Blocked'],
    ])
    .setSize(480, 200)
    .build()

  fSlide.updateTable(nextTableInfo)
  fSlide.removeTable(table)
}
```

테이블 행과 열 색인은 0 근거한입니다. 건축업자는 그것의 줄을 성장하고 그것의 열 조사는 그것의 간단한 테이블을 위해, `setValues()`는 진실의 근원으로 봉사할 수 있습니다.
