## 인쇄 지원 등록

슬라이드 편집기가 인쇄 미리보기 또는 인쇄 정면 API를 필요로 할 때 `@univerjs-pro/slides-print`를 추가하십시오. 패키지는 `@univerjs-pro/slides-print/locale/*`에서 로컬을 제공하므로 별도의 CSS 가져 오기가 필요하지 않습니다.

```ts
import { UniverSlidesPrintPlugin } from '@univerjs-pro/slides-print'
import SlidesPrintEnUS from '@univerjs-pro/slides-print/locale/en-US'
import '@univerjs-pro/slides-print/facade'

univer.registerPlugin(UniverSlidesPrintPlugin)
```

## 모바일 지원 [#mobile-support]

[모바일 편집기](/guides/slides/getting-started/installation#mobile-support)를 먼저 구성하십시오. 이 페이지의 플러그인 모드 설정에서 동일한 패키지에서 모바일 내보내기로 아래 데스크탑 등록을 대체하고 **문서 열기**을 수행하십시오. 모델 플러그인, 스타일, 로컬 및 Facade 가져 오기를 유지하고 하나의 변형 만 등록하십시오.

| 패키지 | 데스크톱 등록 | 모바일 등록 |
| --- | --- | --- |
| `@univerjs-pro/slides-print` | `UniverSlidesPrintPlugin` | `UniverSlidesPrintMobilePlugin` |

## 요구 사항

인쇄 플러그인보다 먼저 핵심 Slides 모델을 등록하세요.

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
univer.registerPlugin(UniverSlidesPrintPlugin)
```

브라우저 편집기는 렌더링 엔진, UI 플러그인, Docs, 그림 및 라이센스 플러그인을 [퀵스타트](/guides/slides/getting-started/quickstart)에 표시된 것과 같이 필요합니다.

## Facade API

facade 진입점을 가져와 `FUniver`에 `printSlidesAsync`를 추가하세요.

```ts
import '@univerjs-pro/slides-print/facade'
```

모든 슬라이드를 활성화 프리젠 테이션에 인쇄:

```ts
const univerAPI = FUniver.newAPI(univer)

await univerAPI.printSlidesAsync()
```

1기반 페이지 번호로 선택 인쇄:

```ts
await univerAPI.printSlidesAsync({
  range: [
    { from: 1, to: 3 },
    { from: 6, to: 6 },
  ],
})
```

## 참고 사항

인쇄 결과는 현재 슬라이드 스냅샷, 페이지 크기, 그리기 요소 및 선택적 표 또는 차트 요소에 따라 달라집니다. 슬라이드 자료에 표나 차트가 포함될 수 있다면 인쇄하기 전에 해당 기능 플러그인을 등록하세요.

```ts
import { SlidePrintHandoutOrder, SlidePrintLayoutType } from '@univerjs-pro/slides-print'

univerAPI.openSlidesPrintDialog({
  layout: SlidePrintLayoutType.Handout,
  slidesPerPage: 6,
  handoutOrder: SlidePrintHandoutOrder.Horizontal,
  frameSlides: true,
  showSlideNumber: true,
})
```

선택권은 또한 `paperSize`, `direction`, `margin` 및 `marginCustom`를 포함합니다. handout는 1, 2, 3, 4, 6, 또는 페이지 당 9개의 활주를 지원합니다.

`range`는 포함한 페이지 범위를 받아들입니다. 모수가 omitted인 경우에, 각 활주는 인쇄합니다. 범위를 겹쳐 씌우는 것은 활주 순서에서 de-duplicated 그리고 인쇄됩니다. 갑판의 끝을 초과하는 범위는 존재하는 활주로에 입힙니다, 그리고 반전한 범위는 무시됩니다.
