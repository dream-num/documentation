## 차트 지원 등록

슬라이드의 차트 지원은 모델 패키지와 UI 패키지로 구성되어 있습니다. `@univerjs-pro/chart-ui`는 공유 편집기 컨트롤, Locale 항목 및 스타일을 제공합니다.

```ts
import ChartUIKoKR from '@univerjs-pro/chart-ui/locale/ko-KR'
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'
import { UniverSlidesChartUIPlugin } from '@univerjs-pro/slides-chart-ui'
import SlidesChartUIKoKR from '@univerjs-pro/slides-chart-ui/locale/ko-KR'
import { LocaleType, mergeLocales } from '@univerjs/core'
import '@univerjs-pro/chart-ui/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart/facade'

univerAPI.loadLocales(LocaleType.KO_KR, mergeLocales(ChartUIKoKR, SlidesChartUIKoKR))
univer.registerPlugin(UniverSlidesChartPlugin)
univer.registerPlugin(UniverSlidesChartUIPlugin)
```

차트 요소가 포함될 수 있는 프레젠테이션을 열거나 가져오기 전에 차트 지원을 등록하십시오.

## 모바일 지원 [#mobile-support]

[모바일 편집기](/guides/slides/getting-started/installation#mobile-support)를 먼저 구성하십시오. 이 페이지에서 설명 된 플러그인 모드 설정에서 동일한 패키지에서 모바일 수출과 함께 바탕 화면 등록을 대체하고 **문서 열기** 교체하십시오. 모델 플러그인, 스타일, 로컬 및 Facade 가져 오기를 유지하고 두 가지 변형을 등록하지 마십시오.

| 패키지 | 데스크톱 등록 | 모바일 등록 |
| --- | --- | --- |
| `@univerjs-pro/slides-chart-ui` | `UniverSlidesChartUIPlugin` | `UniverSlidesChartMobileUIPlugin` |

## 차트 데이터 플러그인 등록 [#chart-data-setup]

참고에서 제공되는 차트 데이터는 [`UniverChartEmbedPlugin`](/reference/packages/plugins/univerjs-pro/chart-embed)가 필요합니다. 플러그인을 설치하고 초기화 중에 등록하십시오. `UniverEmbedPlugin`이 명시적으로 구성되면 플러그인을 먼저 등록하십시오. 모바일 설정은 동일하며 인라인 배열은이 플러그인을 필요로하지 않습니다.

```package-install
npm install @univerjs-pro/chart-embed
```

```ts
import { UniverChartEmbedPlugin } from '@univerjs-pro/chart-embed'

univer.registerPlugin(UniverChartEmbedPlugin)
```

## 차트 만들기와 업데이트

`slide.newChart(type)`는 분리된 빌더를 반환합니다. 차트는 `slide.insertChart(info)`로 전달될 때까지 슬라이드에 나타나지 않습니다.

```ts
const presentation = univerAPI.getActivePresentation()
if (!presentation) throw new Error('No active presentation')

const slide = presentation.getActiveSlide()
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Month', 'Revenue', 'Cost'],
    ['Jan', 120, 80],
    ['Feb', 180, 96],
    ['Mar', 240, 132],
  ])
  .setTitle('Quarterly revenue')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .setZOrder(1)
  .build()

const chart = await slide.insertChart(info)
chart.setLegend({ visible: true }).bringToFront()

const updatedInfo = chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setSubtitle('FY 2026').build()
await chart.update(updatedInfo)

const svg = await chart.exportImage({ format: 'svg' })
```

삽입된 `chart`에 Setters는 즉시 도표를 업데이트합니다. 완전한 분리된 사본 또는 유형 변화가 요구될 때 `update(info)`를 가진 `toBuilder(type)`을 사용하십시오. `exportImage()`는 UI 연출자가 이미지를 제공할 수 없는 경우에 `undefined` 반환합니다.

`slide.getCharts()` 및 `slide.getChart(id)`를 사용하여 라이브 차트를 해결하고 `await chart.remove()`을 호출하여 차트를 삭제합니다. 슬라이드 빌더는 `setPlaceholder()`, `setStroke()`와 `setZOrder()`도 제공합니다.

## 오차 막대 [#error-bars]

`setErrorBars()`를 빌더 또는 라이브 차트에 호출하십시오. 기본 2D 열, 바, 라인 및 분산 차트 지원 오류 막대. `seriesIndex`는 0 기반이며 소스 데이터의 범주 필드가 포함되어 있습니다. 열 및 라인, `x`의 `y`을 사용하여 막대기에 대한, 그리고 흩어지기위한 숫자 축.

```ts
chart.setErrorBars([
  { seriesIndex: 1, direction: 'y', type: 'both', valueType: 'percentage', value: 20 },
])
```

[`FChart.setErrorBars()`](/reference/facade/chart#seterrorbars)

## 다단계 범주 축

hierarchical 인라인 데이터의 경우, root-to-leaf 주문의 범주 필드를 선택하고 멀티 레벨 렌더링을 활성화하십시오.

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Region', 'Quarter', 'Revenue'],
    ['North', 'Q1', 120],
    ['North', 'Q2', 148],
    ['South', 'Q1', 98],
    ['South', 'Q2', 132],
  ])
  .setCategoryFields([0, 1])
  .setMultiLevelCategoryAxis(true)
  .setValueFields([2])
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .build()

await slide.insertChart(info)
```

## 차트를 Sheets 데이터에 연결 [#bind-sheet-data]

차트가 값의 복사본을 저장하는 대신 시트 범위를 따르려면 `setSource()`에 리소스 참조를 전달하십시오.

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    unit: { selector: 'sales-workbook', type: 'sheet' },
    part: {
      kind: 'range',
      sheetName: 'Data',
      range: 'A1:B20',
      ref: 'Data!A1:B20',
    },
  })
  .setAbsolutePosition(120, 80)
  .setSize(640, 360)
  .build()

const chart = await slide.insertChart(info)
```

[차트 Facade 참조](/reference/facade/chart) 문서는 모든 차트 유형의 공유를 구성합니다.

공유 빌더는 또한 [3D 차트 구성](/guides/sheets/features/charts#three-dimensional-charts), [logarithmic 값 axes](/guides/sheets/features/charts#logarithmic-axes) 및 [레이더 차트 눈금 레이블](/guides/sheets/features/charts#radar-charts)을 지원합니다. 슬라이드에서 `slide.newChart()`을 인라인으로 사용하거나 이 페이지에서 표시된 데이터를 참조합니다.
