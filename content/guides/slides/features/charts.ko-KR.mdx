## 차트 지원 등록

슬라이드 차트는 모델 패키지와 UI 패키지로 구성됩니다. `@univerjs-pro/chart-ui`는 공용 편집 컨트롤, 로캘, 스타일을 제공합니다.

```ts
import ChartUIKoKR from '@univerjs-pro/chart-ui/locale/ko-KR'
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'
import { UniverSlidesChartUIPlugin } from '@univerjs-pro/slides-chart-ui'
import SlidesChartUIKoKR from '@univerjs-pro/slides-chart-ui/locale/ko-KR'

import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart/facade'

univer.registerPlugin(UniverSlidesChartPlugin)
univer.registerPlugin(UniverSlidesChartUIPlugin)
```

차트 요소를 포함할 수 있는 프레젠테이션을 열거나 가져오기 전에 차트 지원을 등록하세요.

## 차트 만들기와 업데이트

슬라이드의 `charts` 컬렉션으로 차트를 관리합니다. `create()`는 아직 삽입되지 않은 빌더를 반환하고 `insert()`는 현재 슬라이드에 삽입합니다.

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation.getActiveSlide()

const builder = slide.charts
  .create()
  .setType(univerAPI.Enum.ChartTypeString.Column)
  .setData([
    ['월', '수익', '비용'],
    ['1월', 120, 80],
    ['2월', 180, 96],
    ['3월', 240, 132],
  ])
  .setTitle('분기 수익')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)

const chart = await slide.charts.insert(builder)

chart.setType(univerAPI.Enum.ChartTypeString.Line).setLegend({ visible: true }).commit()
```

기존 차트는 `slide.charts.list()`, `slide.charts.get(id)`, `await slide.charts.remove(chartOrId)`로 관리합니다. 슬라이드 빌더는 `setData`, `getData`, `setPlaceholder`, `setStroke`, `setZOrder`도 지원합니다.

공통 차트 설정은 [차트 Facade 참조](/reference/facade/chart)를 확인하세요.

## Sheet 데이터 연결

리소스 참조로 차트를 Sheet 범위에 연결하고 `refreshDataSource()`로 다시 불러옵니다:

```ts
const chart = await slide.charts.insert(
  slide.charts.create().setDataSource({
    unit: { selector: 'sales-workbook', type: 'sheet' },
    part: { kind: 'range', sheetName: 'Data', range: 'A1:B20', ref: 'Data!A1:B20' },
  }),
)
await chart.refreshDataSource()
```
