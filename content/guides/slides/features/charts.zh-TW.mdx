## 註冊圖表能力

Slides 圖表能力拆分為模型套件和 UI 套件：

```ts
import ChartUIZhTW from '@univerjs-pro/chart-ui/locale/zh-TW'
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'
import { UniverSlidesChartUIPlugin } from '@univerjs-pro/slides-chart-ui'
import SlidesChartUIZhTW from '@univerjs-pro/slides-chart-ui/locale/zh-TW'

import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart/facade'

univer.registerPlugin(UniverSlidesChartPlugin)
univer.registerPlugin(UniverSlidesChartUIPlugin)
```

## 套件職責

- `@univerjs-pro/slides-chart` 將圖表元素接入 slide 模型和圖表引擎。
- `@univerjs-pro/chart-ui` 提供 Pro 圖表 UI 套件共用的編輯控制項、多語言入口和 `@univerjs-pro/chart-ui/lib/index.css`。
- `@univerjs-pro/slides-chart-ui` 提供圖表編輯 UI、渲染整合、插入面板和資料來源編輯能力。

## Runtime 選擇

瀏覽器編輯器使用兩個套件。服務端快照處理場景可以只把模型套件和核心 Slides 模型一起註冊：

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesChartPlugin)
```

如果需要開啟或匯入可能包含圖表元素的 deck，請在處理前註冊圖表能力。

## 建立圖表

Slides 圖表使用二維陣列作為內聯資料來源，不會直接讀取 sheet range。

```ts
const fPresentation = univerAPI.getActivePresentation()
const fSlide = fPresentation.getSlideById('slide-1')

const chartInfo = fSlide.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .setData([
    ['月份', '收入', '成本'],
    ['一月', 120, 80],
    ['二月', 180, 96],
    ['三月', 240, 132],
  ])
  .setUseFirstRowAsHeaders(true)
  .setUseFirstColumnAsDomain(true)
  .setTitle('季度收入')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .build()

const chart = fSlide.insertChart(chartInfo)
```

## 更新圖表

透過 `getCharts()` 或 `getChartById()` 找到既有圖表。`updateDataSource()` 可以更新內聯資料，同時保留圖表元素的位置和尺寸。

```ts
const chart = fSlide.getCharts()[0]

chart?.updateDataSource(
  [
    ['月份', '收入', '成本'],
    ['四月', 260, 140],
    ['五月', 300, 168],
  ],
  {
    useFirstRowAsHeaders: true,
    useFirstColumnAsDomain: true,
  },
)
```

如果要修改圖表類型或樣式，可以把圖表轉回 builder，再呼叫 `updateChart()`：

```ts
if (chart) {
  const nextChartInfo = chart.toBuilder()
    .setChartType(univerAPI.Enum.ChartType.Line)
    .setOptions('legend.position', univerAPI.Enum.ChartLegendPositionEnum.Right)
    .setSeriesStyle(0, { color: '#2F80ED' })
    .build()

  fSlide.updateChart(nextChartInfo)
}
```

## 刪除圖表

```ts
chart?.remove()
// 或
if (chart) {
  fSlide.removeChart(chart)
}
```
