## 註冊圖表支援

Slides 的圖表能力由一個模型包和一個 UI 包組成。`@univerjs-pro/chart-ui` 提供共享的編輯器控制元件、語言套件和樣式。

```ts
import ChartUIZhTW from '@univerjs-pro/chart-ui/locale/zh-TW'
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'
import { UniverSlidesChartUIPlugin } from '@univerjs-pro/slides-chart-ui'
import SlidesChartUIZhTW from '@univerjs-pro/slides-chart-ui/locale/zh-TW'
import { LocaleType, mergeLocales } from '@univerjs/core'
import '@univerjs-pro/chart-ui/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart/facade'

univerAPI.loadLocales(LocaleType.ZH_TW, mergeLocales(ChartUIZhTW, SlidesChartUIZhTW))
univer.registerPlugin(UniverSlidesChartPlugin)
univer.registerPlugin(UniverSlidesChartUIPlugin)
```

圖表支援必須在開啟或匯入可能包含圖表元素的簡報之前註冊。

## 行動裝置支援 [#mobile-support]

請先配置[行動版編輯器](/guides/slides/getting-started/installation#mobile-support)。在本頁介紹的外掛模式初始化程式碼中，將下面列出的桌面版註冊替換為同一套件匯出的行動版外掛，並且必須在**開啟文件前**完成替換。模型外掛、樣式、語言套件和 Facade 匯入均需保留，不要同時註冊兩個版本。

| 套件 | 桌面版註冊 | 行動版註冊 |
| --- | --- | --- |
| `@univerjs-pro/slides-chart-ui` | `UniverSlidesChartUIPlugin` | `UniverSlidesChartMobileUIPlugin` |

## 註冊圖表資料外掛 [#chart-data-setup]

圖表資料來自引用時，需要 [`UniverChartEmbedPlugin`](/reference/packages/plugins/univerjs-pro/chart-embed)。安裝後應在初始化階段註冊一次，註冊位置在開啟簡報之前。如需顯式配置 `UniverEmbedPlugin`，應先註冊該外掛。行動版配置相同；內聯陣列資料不需要此外掛。

```package-install
npm install @univerjs-pro/chart-embed
```

```ts
import { UniverChartEmbedPlugin } from '@univerjs-pro/chart-embed'

univer.registerPlugin(UniverChartEmbedPlugin)
```

## 建立及更新圖表

`slide.newChart(type)` 返回一個獨立的建置器，圖表不會自動出現在幻燈片上。只有把 `build()` 的結果傳給 `slide.insertChart(info)` 之後，圖表才會插入幻燈片。

```ts
const presentation = univerAPI.getActivePresentation()
if (!presentation) throw new Error('No active presentation')

const slide = presentation.getActiveSlide()
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Month', 'Revenue', 'Cost'],
    ['Jan', 120, 80],
    ['Feb', 180, 96],
    ['Mar', 240, 132],
  ])
  .setTitle('Quarterly revenue')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .setZOrder(1)
  .build()

const chart = await slide.insertChart(info)
chart.setLegend({ visible: true }).bringToFront()

const updatedInfo = chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setSubtitle('FY 2026').build()
await chart.update(updatedInfo)

const svg = await chart.exportImage({ format: 'svg' })
```

對已插入的 `chart` 呼叫 setter 會立即更新該圖表。需要完整的獨立副本或更改圖表型別時，請使用 `toBuilder(type)` 配合 `update(info)`。當沒有 UI 渲染器能生成圖片時，`exportImage()` 返回 `undefined`。

使用 `slide.getCharts()` 和 `slide.getChart(id)` 取得即時圖表，刪除圖表時呼叫 `await chart.remove()`。Slides 的建置器還提供 `setPlaceholder()`、`setStroke()` 和 `setZOrder()`。

## 誤差線 [#error-bars]

在建置器或已有圖表上均可呼叫 `setErrorBars()`。基礎二維柱形圖、條形圖、折線圖和散點圖支援誤差線。`seriesIndex` 從 0 開始計數，並且包含源資料中的分類欄位。柱形圖和折線圖使用 `y`，條形圖使用 `x`，散點圖可以使用任一數值軸。

```ts
chart.setErrorBars([
  { seriesIndex: 1, direction: 'y', type: 'both', valueType: 'percentage', value: 20 },
])
```

[`FChart.setErrorBars()`](/reference/facade/chart#seterrorbars)

## 多層級分類軸

對於內聯的層級資料，按從根到葉的順序選擇分類欄位，並啟用多級渲染：

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Region', 'Quarter', 'Revenue'],
    ['North', 'Q1', 120],
    ['North', 'Q2', 148],
    ['South', 'Q1', 98],
    ['South', 'Q2', 132],
  ])
  .setCategoryFields([0, 1])
  .setMultiLevelCategoryAxis(true)
  .setValueFields([2])
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .build()

await slide.insertChart(info)
```

## 將圖表繫結至 Sheets 資料 [#bind-sheet-data]

如果圖表需要跟隨 Sheet 區域，而不是儲存數值副本，請將資源引用傳給 `setSource()`：

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    unit: { selector: 'sales-workbook', type: 'sheet' },
    part: {
      kind: 'range',
      sheetName: 'Data',
      range: 'A1:B20',
      ref: 'Data!A1:B20',
    },
  })
  .setAbsolutePosition(120, 80)
  .setSize(640, 360)
  .build()

const chart = await slide.insertChart(info)
```

各類圖表共用的配置請參閱[圖表 Facade 參考](/reference/facade/chart)。

共享建置器也支援[三維圖表配置](/guides/sheets/features/charts#three-dimensional-charts)和[對數數值軸](/guides/sheets/features/charts#logarithmic-axes)。在 Slides 中，使用本頁範例的 `slide.newChart()`，傳入內聯資料或文件資料引用。
