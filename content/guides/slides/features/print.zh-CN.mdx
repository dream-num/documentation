## 注册打印能力

当 Slides 编辑器需要打印预览或打印相关的 facade API 时，使用 `@univerjs-pro/slides-print`。该包同时提供语言包，路径为 `@univerjs-pro/slides-print/locale/*`，因此不需要单独引入 CSS。

```ts
import { UniverSlidesPrintPlugin } from '@univerjs-pro/slides-print'
import SlidesPrintEnUS from '@univerjs-pro/slides-print/locale/en-US'
import '@univerjs-pro/slides-print/facade'

univer.registerPlugin(UniverSlidesPrintPlugin)
```

## 移动端适配 [#mobile-support]

先配置[移动端编辑器](/guides/slides/getting-started/installation#mobile-support)。在本页插件模式的初始化代码中，将下述桌面端注册替换为同一个包导出的移动端插件，并且必须在**打开文档前**完成替换。模型插件、样式、语言包和 Facade 导入均需保留，两个版本只注册其中一个。

| 来源包 | 桌面端注册 | 移动端注册 |
| --- | --- | --- |
| `@univerjs-pro/slides-print` | `UniverSlidesPrintPlugin` | `UniverSlidesPrintMobilePlugin` |

## 依赖

打印插件必须在核心 Slides 模型之后注册：

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
univer.registerPlugin(UniverSlidesPrintPlugin)
```

浏览器编辑器还需要按[快速开始](/guides/slides/getting-started/quickstart)注册 render engine、UI 插件、Docs、Drawing 和授权插件。

## Facade API

导入 facade 入口后，`FUniver` 会增加 `printSlidesAsync` 方法：

```ts
import '@univerjs-pro/slides-print/facade'
```

打印当前演示文稿中的全部幻灯片：

```ts
const univerAPI = FUniver.newAPI(univer)

await univerAPI.printSlidesAsync()
```

按从 1 开始的页码打印指定范围：

```ts
await univerAPI.printSlidesAsync({
  range: [
    { from: 1, to: 3 },
    { from: 6, to: 6 },
  ],
})
```

`range` 使用闭区间页码，省略该参数时打印全部幻灯片。重叠的范围会去重，并按幻灯片顺序打印。超出 deck 末尾的范围会裁剪到实际存在的幻灯片，起止顺序颠倒的范围会被忽略。

## 注意事项

打印输出取决于当前幻灯片快照、页面尺寸、演讲者备注、drawing 元素，以及可能存在的表格或图表元素。如果 deck 中可能包含表格或图表，请在打印前注册对应的功能插件。

## 打印布局与预览

布局支持整页、讲义和备注页，调用后会打开内置预览：

```ts
import { SlidePrintHandoutOrder, SlidePrintLayoutType } from '@univerjs-pro/slides-print'

univerAPI.openSlidesPrintDialog({
  layout: SlidePrintLayoutType.Handout,
  slidesPerPage: 6,
  handoutOrder: SlidePrintHandoutOrder.Horizontal,
  frameSlides: true,
  showSlideNumber: true,
})
```

还可设置 `paperSize`、`direction`、`margin` 和 `marginCustom`。讲义每页支持 1、2、3、4、6、9 张幻灯片，备注页会使用当前幻灯片的演讲者备注。
