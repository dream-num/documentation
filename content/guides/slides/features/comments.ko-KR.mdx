제품 편집기와 라이센스가 설정된 후 코멘트 플러그인을 등록하십시오. 공유 및 제품 UI 스타일과 로컬 리소스를로드하십시오. 제품 플러그인은 댓글 리소스를 소유하므로 스냅 샷은 해당 플러그인이 등록 된 후에만 복원 할 수 있습니다.

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs-pro/slides-thread-comment @univerjs-pro/slides-thread-comment-ui
```

```ts
import { UniverSlidesThreadCommentPlugin } from '@univerjs-pro/slides-thread-comment'
import { UniverSlidesThreadCommentUIPlugin } from '@univerjs-pro/slides-thread-comment-ui'
import ProductLocale from '@univerjs-pro/slides-thread-comment-ui/locale/ko-KR'
import { LocaleType, mergeLocales } from '@univerjs/core'
import SharedLocale from '@univerjs/thread-comment-ui/locale/ko-KR'

import '@univerjs/thread-comment-ui/lib/index.css'
import '@univerjs-pro/slides-thread-comment-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.KO_KR, mergeLocales(SharedLocale, ProductLocale))
univer.registerPlugin(UniverSlidesThreadCommentPlugin)
univer.registerPlugin(UniverSlidesThreadCommentUIPlugin)
```

## 모바일 지원 [#mobile-support]

[모바일 편집기](/guides/slides/getting-started/installation#mobile-support)를 먼저 구성하십시오. 이 페이지에서 설명 된 플러그인 모드 설정에서 동일한 패키지에서 모바일 수출과 함께 바탕 화면 등록을 대체하고 **문서 열기** 교체하십시오. 모델 플러그인, 스타일, 로컬 및 Facade 가져 오기를 유지하고 두 가지 변형을 등록하지 마십시오.

| 패키지 | 데스크톱 등록 | 모바일 등록 |
| --- | --- | --- |
| `@univerjs-pro/slides-thread-comment-ui` | `UniverSlidesThreadCommentUIPlugin` | `UniverSlidesThreadCommentMobileUIPlugin` |

## 댓글 Facade [#comment-facade]

이 메소드를 호출하기 전에 공유 된 코멘트 Facade 및 제품 Facade를 가져옵니다. 제품 도우미는 안정적인 앵커를 만들고 공유 된 API 핸들은 응답, 업데이트, 해결 및 삭제를 처리합니다. `getComments()`는 로컬 상태를 읽습니다. `listCommentsAsync()`가 나사를 동기화하여 구성 된 데이터 소스를 통해 이미 알고 있지만 서버의 모든 스레드를 발견하지 않습니다.

```ts
import '@univerjs/thread-comment/facade'
import '@univerjs-pro/slides-thread-comment/facade'

const element = univerAPI.getActivePresentation()?.getSlideByIndex(0)?.getElements()[0]
if (element) {
  await element.createCommentAsync('Please review this element.')
  console.log(await element.listCommentsAsync())
}
```

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## 공유 토론 [#shared-discussions]

공유 토론은 [Server SDK](/server/collaboration/extensions)를 통해 연결되는 주석 서비스 및 엔드포인트가 필요합니다. 협업 및 라이센스 설정 후 `UniverThreadCommentDataSourcePlugin`을 `@univerjs-pro/thread-comment-datasource`로 등록하십시오. 공급된 데이터 소스는 `/universer-api/comment/unit/{unitId}/...`와 `/universer-api/user/list`라고 부릅니다. 응용 프로그램은 해당 루트를 노출해야합니다. 코멘트를 읽고 작성하면 자신의 서버 권한을 필요로합니다. 문서 편집 권한은 커버하지 않습니다.
