---
title: Разрешения
---

Разрешения на слайды применяются через команды и могут быть установлены для всей презентации, для одного слайда или для одного элемента. Разрешение на редактирование на ребенке никогда не перевешивает родитель, только читающий.

## Разрешения презентации

```ts
import { UnitAction } from '@univerjs/protocol'

const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const permission = presentation.getPermission()

await permission.setPoint(UnitAction.Export, false)
await permission.setPoint(UnitAction.Print, true)

console.log(permission.getPoint(UnitAction.Print))
```

На уровне презентации можно управлять редактированием, копированием, печатью, экспортом и комментированием. `setReadOnly()` отключает редактировать всю презентацию, а `setEditable()` позволяет снова.

## Разрешения слайда и элемента

```ts
const slide = presentation.getSlideByIndex(0)
const element = slide?.getElements()[0]

if (slide && element) {
  await slide.getPermission().setEditable(false)
  await slide.getElementPermission(element.getId()).setEditable(true)

  console.log(slide.getElementPermission(element.getId()).canEdit())
}
```

Конечный результат `canEdit()` применяет потолок разрешений всех трех уровней: презентации, слайда и элемента. Если разрешения должны сохраняться при снимке, сохраняйте идентификаторы слайдов и элементов стабильными.
