---
title: Imágenes y grupos
---

Las imágenes son elementos de diapositiva de primera clase. Use el asistente asíncrono para una URL o un blob, o el constructor cuando ya conozca todas las propiedades.

## Insertar una imagen

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const image = await slide.insertImageAsync(
  'https://example.com/assets/diagram.png',
  {
    imageSourceType: univerAPI.Enum.ImageSourceType.URL,
    left: 80,
    top: 120,
    width: 320,
    height: 180,
  }
)
```

`getImages()` devuelve las imágenes de la diapositiva actual. Use `setSource()`, `setCrop()`, `setClipShape()` o `toBuilder()` para actualizar una imagen y `removeImage()` para eliminarla.

## Agrupar elementos

```ts
const shape = slide.getShapes()[0]

if (shape) {
  const group = slide.group([shape, image])
  const children = group.getChildren()

  // Restaure los hijos en la diapositiva.
  slide.ungroup(group)
}
```

Los grupos conservan el orden de sus hijos y exponen los mismos métodos de transformación, visibilidad, nombre y descripción. `getGroups()` enumera los grupos de nivel superior.
