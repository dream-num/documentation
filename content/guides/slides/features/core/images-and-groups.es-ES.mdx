---
title: Imágenes y grupos
---

Las imágenes son elementos de diapositivas de primera clase. Utilice el ayudante asincrónico para una URL o un bloque, o use el constructor cuando todas las propiedades de la imagen ya se conocen.

## Insertar una imagen

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const image = await slide.insertImageAsync(
  'https://example.com/assets/diagram.png',
  {
    imageSourceType: univerAPI.Enum.ImageSourceType.URL,
    left: 80,
    top: 120,
    width: 320,
    height: 180,
  }
)
```

`getImages()` enumera las imágenes en la diapositiva actual. Use `setSource()`, `setCrop()`, `setClipShape()`, o `toBuilder()` para actualizar una imagen existente, y use `removeImage()` para borrarla.

## Agrupar elementos

```ts
const shape = slide.getShapes()[0]

if (shape) {
  const group = slide.group([shape, image])
  const children = group.getChildren()

  // Restaure los hijos en la diapositiva.
  slide.ungroup(group)
}
```

Un grupo conserva el orden del niño y proporciona los mismos métodos de transformación, visibilidad, nombre y descripción como otros elementos de la página. `getGroups()` lista los grupos de nivel superior en una diapositiva.
