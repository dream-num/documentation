---
title: Mode présentation
---

`UniverSlidesUIPlugin` enregistre la lecture du diaporama actif. La lecture suit l’ordre, ignore les diapositives marquées comme masquées et applique la transition résolue à chaque déplacement.

## Démarrer la lecture

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  await univerAPI.executeCommand('slide.operation.presentation.start', {
    unitId: presentation.getId(),
    fromBeginning: true,
  })
}
```

Utilisez `fromBeginning: false` pour partir de la diapositive active ou fournissez `startSlideId` pour désigner une diapositive visible.

## Naviguer et arrêter

```ts
await univerAPI.executeCommand('slide.operation.presentation.next')
await univerAPI.executeCommand('slide.operation.presentation.previous')

await univerAPI.executeCommand('slide.operation.presentation.go-to-slide', {
  slideId: 'summary-slide',
})

await univerAPI.executeCommand('slide.operation.presentation.stop')
```

L’opération suivante arrête la lecture après la dernière diapositive visible. L’opération précédente renvoie `false` sur la première.

## Comportement du navigateur

Le plein écran et le mode double écran dépendent des API du navigateur. Ouvrez la fenêtre d’audience depuis une action utilisateur afin d’éviter son blocage. Une interface en lecture seule peut aussi lancer la présentation lorsque le plugin UI est enregistré avec l’édition désactivée.
