---
title: Mode présentation
---

`UniverSlidesUIPlugin` ajoute la lecture de présentation au jeu courant. La lecture passe dans l'ordre des diapositives, saute toutes les diapositives marquées comme décrochées et applique la transition résolue pour chaque déplacement.

## Démarrer la lecture

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  await univerAPI.executeCommand('slide.operation.presentation.start', {
    unitId: presentation.getId(),
    fromBeginning: true,
  })
}
```

Passer `fromBeginning: false` pour démarrer à partir de la diapositive actuellement active, ou passer `startSlideId` afin de spécifier une diapositive visible comme point de départ.

## Naviguer et arrêter

```ts
await univerAPI.executeCommand('slide.operation.presentation.next')
await univerAPI.executeCommand('slide.operation.presentation.previous')

await univerAPI.executeCommand('slide.operation.presentation.go-to-slide', {
  slideId: 'summary-slide',
})

await univerAPI.executeCommand('slide.operation.presentation.stop')
```

La commande suivante, qui consiste à invoquer la commande suivante sur la dernière diapositive visible, arrête la lecture. La commande précédente renvoie `false` sur la première diapositive.

## Comportement du navigateur

Les commandes de présentation en plein écran et double écran dépendent des API du navigateur. La fenêtre d'audience doit être ouverte directement dans un geste de l'utilisateur; sinon un bloqueur popup le rejette. Une interface Slides uniquement peut toujours exécuter le mode de présentation lorsque le plugin UI est enregistré avec l'édition désactivée.
