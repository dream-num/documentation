---
title: Фигуры и текст
---

Слайды рисуют редактируемые формы, разъемы и текст формы с общим двигателем Shape. `FSlide.insertShape()` возвращает фасад формы, и каждая операция на нем проходит через командный конвейер Slides.

## Настройка шрифтов для объединения текста [#merge-shape-font-configuration]

`UniverSlidesUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `mergeShapeFontResolver` | `(font: string, unitId: string, text: string) => ArrayBuffer \| Promise<ArrayBuffer \| undefined> \| undefined` |  | Возвращает данные точного шрифта отрисовки. |

Плагин Slides UI может считывать поддерживаемые веб-шрифты, которые уже загружены. Если приложение загружает свои собственные шрифты, установите `mergeShapeFontResolver(font, unitId, text)` в `UniverSlidesUIPlugin`. Верните байты точного лица, которое будет использоваться, с весом, стилем и запасом, уже согласованным, как `ArrayBuffer` или обещание. Верните `undefined`, когда это точное лицо недоступно.

## Вставка фигуры

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const shape = slide.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 64, width: 320, height: 120 },
  visible: true,
  selectable: true,
  shapeData: {
    fill: {
      fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
      color: '#dbeafe',
    },
  },
})
```

`insertShape()` возвращает `null`, когда адаптер хоста Shape недоступен или вход не может быть создан. Зарегистрируйте зависимости от формы, требуемые установкой Slides перед вставкой форм.

## Добавление форматированного текста

```ts
if (shape) {
  const richText = univerAPI.newRichText()
    .text('Quarterly ')
    .bold('review')

  shape.getText()
    .setRichText(richText)
    .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
    .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
}
```

Фасады формы доступны от `slide.getShape(id)` или `slide.getShapes()`. Общие методы элементов устанавливают положение, размер, видимость, имя и описание, а `slide.deleteElement(shape)` удаляет форму.

## Редактирование текста фигуры

В следующем примере используется объект формы, который `insertShape()` возвратил ранее. `getText()` возвращает живую рукоятку [FShapeText](/reference/facade/shape-text). Прочитайте простой текст с `getPlainText()`, замените все это `setText()` и применяйте форматирование с помощью шрифта, цвета и методов выравнивания.

```ts
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()` заменяет существующий текст. Используйте `setRichText()`, когда для одной формы требуется несколько стилей текста. Чтобы изменить существующий богатый текст, позвоните `getRichText()?.copy()` , отредактируйте конструктор и передайте его `setRichText()`; редактирование отдельного конструктора само по себе не записывает никаких изменений. Больше опций описано в [Текстовый стиль](/reference/facade/shape-text#settextstyle) и [текстовая обшивка и макет](/reference/facade/shape-text#settextboxoptions).

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## Копирование формата фигур [#format-painter]

Выберите исходную форму, активируйте форматиста, затем выберите целевую форму. Художник копирует наполнение, штрих, эффекты и поддерживаемое форматирование текста, и оставляет идентичность цели, геометрию, текстовое содержимое и связывание формулы неизменными. Четкое форматирование восстанавливает по умолчанию из вставки. SmartArt исключен. Плагин UI соответствующей формы автоматически регистрирует это поведение.

## Объединение фигур [#merge-shapes]

Выберите 2-10 поддерживаемых объектов на том же слайде, затем используйте **Слияние форм**. Операции `union` (все области), `combine`(исключены перекрытия), `intersect` ("общая область"), `subtract` («удаляет другие объекты из основного объекта») и `fragment` (“расщепление на области”) Форматирование происходит из основного объекта. Слияние заменяет выбранные объекты и поддерживает отмену, редо и совместную работу.

На текущий отбор действует следующая команда. `merged` — `false`, когда отбор или операция не могут быть применены. Объекты должны быть редактируемыми и в пределах одной группы. Коннекторы, SmartArt, объекты OLE, диаграммы и таблицы не могут быть слиты операнды, а некоторые эффекты, анимации и сложные текстовые макеты также препятствуют слиянию.

Текстовый ящик, принимающий участие в слиянии, преобразуется в контуры, и его текст больше не может быть отредактирован как текст после этого. Если шрифт, используемый для его рендеринга, не может быть прочитан, слияние останавливается, а оригинальные формы остаются неизменными. См. [конфигурация шрифта](#merge-shape-font-configuration).

```ts
import { MergeSlideShapesCommand } from '@univerjs-pro/slides-ui'

const merged = await univerAPI.executeCommand(MergeSlideShapesCommand.id, {
  operation: 'union',
})
```
