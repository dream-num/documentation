---
title: 講者備忘稿與轉場效果
---

演講者備註和切換效果都儲存在 Slides 快照中，並透過命令更新，因此與撤銷、重做保持同步。

## 講者備忘稿

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

呼叫 `setSpeakerNotes(undefined)` 可以清空備註。一條備註只屬於一張幻燈片，不會被作為頁面元素渲染。

## 投影片轉場效果

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()` 返回該幻燈片解析後的切換效果。只有支援方向的切換型別才會保留所設定的 `direction`。

如果所有幻燈片都使用同一個效果，可以統一應用一次：

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

呼叫 `slide.setTransition(undefined)` 可以清除單張幻燈片上設定的切換效果。播放時使用[演示模式](/guides/slides/features/core/presentation-mode)中說明的解析後切換效果。
