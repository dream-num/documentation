---
title: 講者備忘稿與轉場效果
---

講者備忘稿和轉場效果儲存在 Slides 快照中，並透過命令更新，因此會與復原和重做保持同步。

## 講者備忘稿

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

呼叫 `setSpeakerNotes(undefined)` 可清除備忘稿。備忘稿只屬於一張投影片，不會作為頁面元素算繪。

## 投影片轉場效果

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()` 傳回為該投影片解析後的轉場效果。只有支援方向的效果類型才會保留 `direction`。

需要統一效果時，可以套用到全部投影片：

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

呼叫 `slide.setTransition(undefined)` 可清除單頁轉場效果。播放時會使用[簡報模式](/guides/slides/features/core/presentation-mode)中介紹的解析後效果。
