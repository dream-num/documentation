---
title: 一般 API
---

ルートFacade APIは、アプリケーションが登録するスライドプラグインと共通Univerランタイムを組み合わせています。このページでは、コマンド、イベント、履歴、およびユニットのライフサイクルをカバーしており、別のUniverドキュメントタイプでは経験を想定していません。 プレゼンテーションオブジェクトについては、[UniverスライドAPI](/guides/slides/features/core/slides-api)を参照してください。

## API オブジェクトを作成する

Univerインスタンスの後に単一の`FUniver`ラッパーを作成し、必要なプラグインを登録します。

```ts
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

このコールの前にインポートされたファサードエントリは、同じオブジェクトにスライドメソッドを追加します。

## コマンド

`executeCommand()` は、登録済みのコマンドを非同期的に実行します。コマンドが同期実行を明示的にサポートする場合のみ、`syncExecuteCommand()`を使用してください。一般的なスライド操作では、ファサードメソッドを好みます。

## イベント

```ts
const commandLog = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ id }) => console.log('Executed:', id)
)

// 不要になったリスナーを解除します。
commandLog.dispose()
```

アプリケーションがコマンドを検査またはキャンセルする必要がある場合は、`BeforeCommandExecute`に耳を傾けます。`Rendered`や`Steady`などのステージにエディタが入るときに`LifeCycleChanged`が火災します。

## 元に戻す／やり直す

undo と redo は、集中した Univer ユニットで動作し、約束を返します。

```ts
await univerAPI.undo()
await univerAPI.redo()
```

コマンドパイプラインを介してファサードのミューテーションが通過するので、サポートされている変更は、同じ履歴を入力します。

## システムクリップボード

`UniverSlidesUIPlugin` が登録され、Slides のキャンバスは焦点を合わせています。`copy()`は現在の選択をコピーし、`paste()`がスライド UI コマンドを通してクリップボードの内容を差し込みます。

```ts
import '@univerjs/ui/facade'

await univerAPI.copy()
await univerAPI.paste()
```

キャンバスコンテキストメニューは、通常のペースト、テキストとして貼り付け、画像を貼り付けます。テキストモードは、クリップボードテキストから編集可能なテキストボックスを作成します。画像モードは、画像ファイルやクリップボードHTMLの画像リソースを使用しています。任意のコンテンツを画像に変換しません。

形状やテーブルでテキストを編集する一方で、エディタは、貼り付け後のフォーマットメニューとともに、**ソースのフォーマットを保持する**、**マッチ先のフォーマット**および**テキストのみを保持する**を提供します。

これらの操作は、フォーカスされたブラウザエディタとクリップボードの権限を必要とするため、モデルのみのNode.jsランタイムで利用できなくなります。 ブラウザがクリップボードの読み込みをブロックする場合、システムペーストのショートカットを使用します。

## UI

UIファサードは、メッセージを表示し、ダイアログまたはサイドバーを開き、コンポーネントを登録し、組み込みのUIパーツを制御します。

```ts
univerAPI
  .showMessage({ content: 'Presentation saved', type: 'success' })
  .setUIVisible(univerAPI.Enum.BuiltInUIPart.TOOLBAR, true)
```

これらの方法は、`UniverUIPlugin` が必要です。スライド編集制御も `UniverSlidesUIPlugin`. が必要です。

## WebSocket

WebSocketのサポートは、ネットワークファサードのオプションおよび提供可能です。

```ts
import { UniverNetworkPlugin } from '@univerjs/network'

import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)

const socket = univerAPI.createSocket('wss://example.com/slides')
socket.open$.subscribe(() => socket.send('ready'))
```

メッセージプロトコル、認証、再接続、およびコラボレーションの競合処理は、ホストアプリケーションの責任を保ちます。

## 列挙型

`univerAPI.Enum`は、一般的なランタイム列とスライドの列が追加します。

```ts
const lifecycle = univerAPI.Enum.LifecycleStages.Steady
const transition = univerAPI.Enum.SlideTransitionTypeEnum.Fade
const elementType = univerAPI.Enum.SlidePageElementTypeEnum.Shape
```

## ユーティリティ

`univerAPI.Util`は、数値のフォーマット、矩形操作、一般的なツールなどの共有ヘルパーを提供します。

```ts
const payload = univerAPI.Util.tools.deepClone({
  slideId: 'slide-1',
  selectedElementIds: ['element-1'],
})
```
