---
title: スライドとレイアウト
---

`FPresentation` はスライド順と共通のページサイズを管理します。`FSlide` は、解決済みのページレイアウトと各スライドの背景を公開します。

## スライド順を管理する

```ts
const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const agenda = presentation.appendSlide({ name: 'Agenda' })
const summary = presentation.insertSlide(1, { name: 'Summary' })

presentation.moveSlide(summary, 0)
presentation.setActiveSlide(agenda)
```

現在の順序は `getSlides()`、`getSlideById()`、`getSlideByIndex()` で取得します。`deleteSlide()` はコマンドパイプラインを通じてスライドを削除します。

## ページサイズを設定する

```ts
presentation.setPageSize({
  preset: univerAPI.Enum.SlidePageSizePresetEnum.WideScreen16By9,
})
```

`slide.getPageLayout()` は、解決済みページサイズと要素の境界・順序を返します。座標は Slides モデルの座標系です。

## スライド背景を設定する

```ts
agenda.setBackground({
  type: univerAPI.Enum.SlideBackgroundTypeEnum.Solid,
  color: '#1d4ed8',
})
```

明示的な背景を削除するには `undefined` を設定します。`setShowMasterBackground(false)` は、マスター背景グラフィックをスナップショットから削除せず、そのスライドで非表示にします。
