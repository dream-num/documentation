---
title: スライドとレイアウト
---

`FPresentation`は、スライドオーダーとデッキ全体で共有されるページサイズを管理します。 `FSlide` は、単一のスライドの解決されたレイアウトと背景を提供します。

## スライド順を管理する

```ts
const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const agenda = presentation.appendSlide({ name: 'Agenda' })
const summary = presentation.insertSlide(1, { name: 'Summary' })

presentation.moveSlide(summary, 0)
presentation.setActiveSlide(agenda)
```

現在の順序は、`getSlides()`、`getSlideById()`、または `getSlideByIndex()`. コマンドパイプラインを介してスライドを削除 `deleteSlide()`。

## ページサイズを設定する

```ts
presentation.setPageSize({
  preset: univerAPI.Enum.SlidePageSizePresetEnum.WideScreen16By9,
})
```

`slide.getPageLayout()`は、各要素の境界と順序とともに、解決されたページサイズを返します。 座標は、Slidesモデル座標システムを使用します。

## スライド背景を設定する

```ts
agenda.setBackground({
  type: univerAPI.Enum.SlideBackgroundTypeEnum.Solid,
  color: '#1d4ed8',
})
```

`undefined` を渡すと、明示的にスライドの背景をセットします。`setShowMasterBackground(false)`は、そのスライドによって継承されたマスターの背景グラフィックスを隠します。それはプレゼンテーションスナップショットからそれらを削除しません。
