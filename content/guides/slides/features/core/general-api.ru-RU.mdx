title: Общий API
---

Корень Facade API объединяет общее время выполнения Univer с плагинами Slides, которые регистрирует приложение. Эта страница охватывает команды, события, историю и жизненный цикл устройства и не предполагает опыта работы с другим типом документа Univer. Для объектов презентации см. [Univer Slides API](/guides/slides/features/core/slides-api) .

## Создание объекта API

Создайте одну обертку `FUniver` после регистрации экземпляра Univer и необходимых плагинов:

```ts
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

Фасадные записи, импортированные до этого вызова, добавляют методы слайдов к тому же объекту.

## Команды

`executeCommand()` запускает зарегистрированную команду асинхронно. Используйте `syncExecuteCommand()` только тогда, когда команда явно поддерживает синхронное выполнение. Для обычных операций Slides отдают предпочтение методам Facade.

## События

```ts
const commandLog = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ id }) => console.log('Executed:', id)
)

// Удалите слушатель, когда он больше не нужен.
commandLog.dispose()
```

Прослушивайте `BeforeCommandExecute`, когда приложение должно проверить или отменить команду. `LifeCycleChanged` загорается, когда редактор входит в этапы, такие как `Rendered` и `Steady`.

## Отмена и повтор

Отмените и переделайте действие на сфокусированном устройстве Univer и верните обещания:

```ts
await univerAPI.undo()
await univerAPI.redo()
```

Мутации Slides Facade проходят через командный конвейер, поэтому поддерживаемые изменения входят в ту же историю.

## Системный буфер обмена

После того, как `UniverSlidesUIPlugin` зарегистрирован и холст Slides имеет фокус, `copy()` копирует текущий выбор и `paste()` вставляет содержимое буфера обмена через команды пользовательского интерфейса Slides.

```ts
import '@univerjs/ui/facade'

await univerAPI.copy()
await univerAPI.paste()
```

Контекстное меню холста поддерживает обычную пасту, вставку в виде текста и вставку как изображение. Режим текста создает редактируемый текстовый ящик из текста буфера обмена. Режим изображения использует файлы изображений или ресурсы изображений в буфере обмена HTML; он не преобразует произвольный контент в изображение.

При редактировании текста в форме или таблице редактор предоставляет **Сохраняйте формат источника**, **Форматирование пункта назначения матча** и **Храните только текст** вместе с меню форматирования после вставки.

Эти операции требуют специального редактора браузера и разрешения буфера обмена, поэтому они недоступны только для модели Node.js. Если браузер блокирует чтение буфера сжатия, используйте ярлык системной пасты.

## UI

Фасад пользовательского интерфейса отображает сообщения, открывает диалоги или боковые панели, регистрирует компоненты и управляет встроенными частями пользовательского интерфейсов:

```ts
univerAPI
  .showMessage({ content: 'Presentation saved', type: 'success' })
  .setUIVisible(univerAPI.Enum.BuiltInUIPart.TOOLBAR, true)
```

Эти методы требуют `UniverUIPlugin`; средства управления редактированием слайдов также требуют `UniverSlidesUIPlugin`.

## WebSocket

Поддержка WebSocket является необязательной и обеспечивается Network Facade:

```ts
import { UniverNetworkPlugin } from '@univerjs/network'

import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)

const socket = univerAPI.createSocket('wss://example.com/slides')
socket.open$.subscribe(() => socket.send('ready'))
```

Протоколы сообщений, аутентификация, повторное подключение и обработка конфликтов в сотрудничестве остаются ответственностью хост-приложения.

## Перечисления

`univerAPI.Enum` раскрывает общие перечни времени выполнения и перечни, которые добавляет Slides:

```ts
const lifecycle = univerAPI.Enum.LifecycleStages.Steady
const transition = univerAPI.Enum.SlideTransitionTypeEnum.Fade
const elementType = univerAPI.Enum.SlidePageElementTypeEnum.Shape
```

## Утилиты

`univerAPI.Util` предоставляет общие помощники, такие как форматирование чисел, операции с прямоугольником и общие инструменты:

```ts
const payload = univerAPI.Util.tools.deepClone({
  slideId: 'slide-1',
  selectedElementIds: ['element-1'],
})
```
