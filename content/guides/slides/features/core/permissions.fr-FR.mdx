---
title: Autorisations
---

Les permissions de diapositives sont appliquées à travers des commandes et peuvent être définies pour toute la présentation, pour une seule diapositive ou pour un seul élément. Une autorisation de modification sur un enfant ne remplace jamais un parent en lecture seule.

## Autorisations de présentation

```ts
import { UnitAction } from '@univerjs/protocol'

const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const permission = presentation.getPermission()

await permission.setPoint(UnitAction.Export, false)
await permission.setPoint(UnitAction.Print, true)

console.log(permission.getPoint(UnitAction.Print))
```

Au niveau de la présentation, Editer, Copier, Imprimer, Exporter et Commentaire peuvent être contrôlés. `setReadOnly()` désactive l'édition pour toute la présentation, et `setEditable()` l'autorise à nouveau.

## Autorisations de diapositive et d’élément

```ts
const slide = presentation.getSlideByIndex(0)
const element = slide?.getElements()[0]

if (slide && element) {
  await slide.getPermission().setEditable(false)
  await slide.getElementPermission(element.getId()).setEditable(true)

  console.log(slide.getElementPermission(element.getId()).canEdit())
}
```

Le résultat final `canEdit()` applique le plafond de permission des trois niveaux : la présentation, la diapositive et l'élément. Si les permissions doivent persister avec l'instantané, gardez la diapositive et les identifiants de l'élément stables.
