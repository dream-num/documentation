---
title: Autorisations
---

Les autorisations Slides sont mises à jour par des commandes et peuvent cibler la présentation, une diapositive ou un élément. Une autorisation enfant ne contourne jamais un parent en lecture seule.

## Autorisations de présentation

```ts
import { UnitAction } from '@univerjs/protocol'

const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const permission = presentation.getPermission()

await permission.setPoint(UnitAction.Export, false)
await permission.setPoint(UnitAction.Print, true)

console.log(permission.getPoint(UnitAction.Print))
```

Les actions prises en charge sont Edit, Copy, Print, Export et Comment. `setReadOnly()` désactive toute modification et `setEditable()` la réactive.

## Autorisations de diapositive et d’élément

```ts
const slide = presentation.getSlideByIndex(0)
const element = slide?.getElements()[0]

if (slide && element) {
  await slide.getPermission().setEditable(false)
  await slide.getElementPermission(element.getId()).setEditable(true)

  console.log(slide.getElementPermission(element.getId()).canEdit())
}
```

Le résultat final de `canEdit()` applique les plafonds de la présentation, de la diapositive et de l’élément. Conservez des identifiants stables si les autorisations doivent persister dans les instantanés.
