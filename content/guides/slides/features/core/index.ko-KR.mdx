Univer 슬라이드 코어는 프리젠 테이션 모델과 브라우저 편집 UI로 구성되어 있습니다. 모델은 `ISlideData` 스냅 샷으로 프레젠테이션을 저장하고 UI는 모델이 렌더링되며 Univer 명령을 통해 수정합니다.

## 기능

- 발표 모델은 프레젠테이션 정체성, 페이지 크기, 슬라이드 주문, 슬라이드, 마스터 페이지, 레이아웃 페이지, 테마, 전환 및 리소스를 유지합니다.
- 렌더링 및 편집 커버 슬라이드 캔버스, 썸네일, 선택, 클립보드, 텍스트 및 모양 편집, 정렬 가이드, 및 프리젠 테이션 재생.
- 페이지와 요소의 변경은 명령과 mutations를 통해 적용되며, 모델 업데이트, 렌더링 및 undo 및 redo는 동기화됩니다.
- Facade API는 프레젠테이션을 만들고, 스냅샷을 저장하고, 응용 프로그램이 호출 할 수있는 객체로 슬라이드 및 요소 작업을 노출합니다.
- 테이블, 차트, 인쇄 및 수입 / 수출과 같은 옵션 기능은 플러그인으로 핵심 스택 밖에 남아 있습니다.

## 플러그인 모드

### 설치

```package-install
npm install @univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/slides @univerjs-pro/slides-ui
```

### 사용법

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
import SlidesUIEnUS from '@univerjs-pro/slides-ui/locale/en-US'
import SlidesEnUS from '@univerjs-pro/slides/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
import { UniverDrawingPlugin } from '@univerjs/drawing'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/slides/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'
import '@univerjs-pro/slides-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, DocsUIEnUS, SlidesEnUS, SlidesUIEnUS),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const presentation = univerAPI.createPresentation({ name: 'Quarterly review' })
```

기존 `UniverUIPlugin` 등록에서 `menu` 및 `ribbonType`를 설정하십시오. 둘 다 공유 UI 옵션이며 `UniverSlidesUIPlugin`에 속하지 않습니다. 다음 예제는 슬라이드에서 메뉴 ID를 사용합니다.

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'slide.menu.insert.text': {
    order: 1,
    gridLayout: { row: 1, column: 2, rowSpan: 2, showLabel: true, width: 96 },
  },
  'slide.menu.insert.shape': {
    order: 0,
    gridLayout: { row: 1, column: 1, rowSpan: 2, showLabel: true },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order`는 명령 명령에 있는 탭, 그룹, 또는 메뉴 품목을 sibling 분류합니다. 그것은 다른 그룹으로 품목을 이동하지 않습니다. `data-u-command` 속성에서 유효한 실제 메뉴 품목 ID를 사용하십시오, 오히려 명령 ID도 일치하는 assuming 보다는.

## 프리셋 모드

Univer 슬라이드는 미리 설치 패키지를 아직 제공하지 않습니다. 플러그인 모드를 사용하여 혼자 모델을 실행하고 브라우저 편집기를 구축하십시오.

## 리본 구성 [#ribbon-controls]

시작 탭에는 테마, 전환, 배경 및 스피커 노트 컨트롤이 포함되어 있습니다. 삽입 탭은 콘텐츠 삽입 및 객체 목록을 수집합니다. View 탭은 페이지 크기, 줌 및 전체 화면을 제공합니다. 컨텍스트 형식 탭은 선택 사항을 따릅니다. 선택한 모양은 모양 형식을 보여줍니다. 선택한 이미지는 이미지 형식을 표시하고 선택한 차트 형식을 표시하며 이미지 또는 차트가 공통 객체 제어를 포함합니다. 이미지 탭은 작물과 클립 모양, 크기, 위치, 조정 및 단일 이미지 형식을 포함합니다. 이 플러그인은 다음과 같은 선택이 필요합니다.

## Facade API로 메뉴 업데이트 [#menu-facade]

### 실행 중 업데이트

`univerAPI`를 `FUniver.newAPI(univer)`로 만들기 전에 `@univerjs/ui/facade` 가져 오기. [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig)는 기존 구성으로 변경을 병합하고 지정되지 않은 필드를 보존하고 메뉴를 새로 고침합니다. 오버라이드는 나중에 메뉴에 적용됩니다.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'slide.menu.insert.text': { gridLayout: { row: 1, column: 2, width: 120 } },
})
```

`gridLayout`는 그리드 리본에만 영향을줍니다. 각 그룹에는 두 개의 행 및 `row` 및 `column` 시작이 있습니다. 명시된 위치는 `order`의 시각적 주문에 대해 우선적으로 진행되므로 두 개의 점유 셀이 교체되면 두 항목이 업데이트되어야합니다. 선택 필드는 기존 구성 또는 스키마를 상속합니다. 스팬, 라벨, 너비 및 아이콘 크기는 [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout)에 속합니다.

`UniverSlidesUIPlugin`에서 활성화된 편집을 계속하십시오. `editor.enabled: false`로, 이 제품을 위한 리본은 결코 등록되지 않으며, 메뉴 overrides는 누락된 단추를 추가할 수 없습니다.

사용자 정의 버튼 및 서브 우 트리는 동일한 규칙을 따릅니다. [`createMenu()` 및 `createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem)는 또한 `order` 및 `gridLayout`를 받아 `appendTo()`가 그들을 등록합니다. 팝업의 내용은 리본 그리드 레이아웃을 사용하지 않습니다.

## 저장 전 텍스트 확정 [#commit-text-before-saving]

`@univerjs-pro/slides-ui/facade`가 로드될 때, 사용자 정의 도구 모음 또는 대화 상자는 스냅 샷을 저장하기 전에 `await presentation.endTextEditingAsync()`를 호출해야 합니다. 전화가 `true`로 해결한 후만 저장하십시오. `false`의 반환 값은 초안이 계속되거나 그 IME 구성이 진행 중임을 의미합니다.
