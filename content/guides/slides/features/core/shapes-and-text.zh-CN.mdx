---
title: 形状与文本
---

Slides 使用共享的 Shape 引擎处理可编辑形状、连接线和形状文字。`FSlide.insertShape()` 返回一个形状 Facade，对其执行的所有操作都通过 Slides 命令管线完成。

## 为文本合并提供字体 [#merge-shape-font-configuration]

`UniverSlidesUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `mergeShapeFontResolver` | `(font: string, unitId: string, text: string) => ArrayBuffer \| Promise<ArrayBuffer \| undefined> \| undefined` |  | 返回绘制这段文字所用的确切字体数据。 |

Slides UI 插件可以读取已加载的受支持 Web 字体。如果字体由应用自行加载，请在 `UniverSlidesUIPlugin` 中设置 `mergeShapeFontResolver(font, unitId, text)`。返回值应为实际使用的那一款字体的字节数据，字重、样式和回退均已匹配，类型可以是 `ArrayBuffer` 或 Promise。该字体不可用时，返回 `undefined`。

## 插入形状

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const shape = slide.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 64, width: 320, height: 120 },
  visible: true,
  selectable: true,
  shapeData: {
    fill: {
      fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
      color: '#dbeafe',
    },
  },
})
```

当 Shape 宿主适配器不可用，或传入的参数无法创建形状时，`insertShape()` 返回 `null`。在插入形状之前，请先注册 Slides 配置所需的 Shape 依赖。

## 添加富文本

```ts
if (shape) {
  const richText = univerAPI.newRichText()
    .text('Quarterly ')
    .bold('review')

  shape.getText()
    .setRichText(richText)
    .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
    .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
}
```

形状 Facade 可通过 `slide.getShape(id)` 或 `slide.getShapes()` 获取。通用的元素方法可以设置位置、尺寸、可见性、名称和描述，`slide.deleteElement(shape)` 用于删除形状。

## 编辑形状文字

下面的示例沿用前面 `insertShape()` 返回的形状对象。`getText()` 返回一个实时的 [FShapeText](/reference/facade/shape-text) 句柄：用 `getPlainText()` 读取纯文本，用 `setText()` 替换全部文字，并通过字体、颜色和对齐方法设置格式。

```ts
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()` 会替换已有文字。一个形状需要多种文字样式时，请使用 `setRichText()`。要修改已有的富文本，请先调用 `getRichText()?.copy()`，修改构建器后再传给 `setRichText()`；只修改这个脱离的构建器不会写回任何内容。更多选项见[文字样式](/reference/facade/shape-text#settextstyle)和[文本框内边距与布局](/reference/facade/shape-text#settextboxoptions)。

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## 智能图形 SmartArt

智能图形（SmartArt）是一种复合形状，包含逻辑节点树和可独立编辑的呈现形状。`FSlide.insertSmartArt(layoutId, transform?)` 返回 `FShape` 或 `FConnectorShape` Facade。布局或 Shape 宿主不可用时返回 `null`。在编辑器中，可从插入工具栏插入智能图形，并通过“SmartArt 设计”选项卡和文本窗格编辑同一组节点。

```ts
const smartArt = slide.insertSmartArt(
  'urn:microsoft.com/office/officeart/2005/8/layout/default',
  { left: 120, top: 90, width: 720, height: 360 },
)
if (!smartArt) throw new Error('Cannot insert SmartArt')
```

`isSmartArt()` 用于判断形状是否为智能图形。`getSmartArtData()` 返回布局、节点和呈现形状的独立副本。在传给 `setSmartArtData()` 之前，修改该副本不会影响幻灯片。

```ts
const data = smartArt.getSmartArtData()
const nodeId = data?.rootNodeIds[0]
if (nodeId && data) {
  smartArt.updateSmartArtNode(nodeId, {
    text: { ...data.nodes[nodeId].text, text: 'Discovery' },
    fontSizeMode: univerAPI.Enum.SmartArtTextFontSizeModeEnum.Auto,
  })
}
```

使用 `insertSmartArtNode()`、`deleteSmartArtNode()`、`moveSmartArtNode()`、`promoteSmartArtNode()` 和 `demoteSmartArtNode()` 调整节点树。`setSmartArtLayout(id, category?)` 在保留逻辑节点的同时切换布局，`setSmartArtDirection()` 设置阅读方向。

```ts
smartArt.setSmartArtLayout(
  'urn:microsoft.com/office/officeart/2005/8/layout/lProcess2',
  univerAPI.Enum.SmartArtCategoryEnum.Process,
)
```

`univerAPI.Enum` 提供五个智能图形枚举：`SmartArtCategoryEnum`、`SmartArtDirectionEnum`、`SmartArtInsertPositionEnum`、`SmartArtNodeRoleEnum` 和 `SmartArtTextFontSizeModeEnum`。

`convertSmartArtToShapes()` 在一个可撤销步骤中返回转换后的普通形状 Facade。转换成功后，这些形状会替换原来的智能图形。

## 形状格式刷 [#format-painter]

先选中源形状，启用格式刷，再选中目标形状。格式刷会复制填充、描边、效果和受支持的文字格式，目标的标识、几何信息、文字内容和公式绑定保持不变。清除格式会恢复到插入时的默认样式。SmartArt 不参与。对应的形状 UI 插件会自动注册这一行为。

## 合并形状 [#merge-shapes]

在同一张幻灯片上选中 2–10 个受支持的对象，然后使用 **合并形状**。支持的操作包括 `union`（全部区域）、`combine`（去掉重叠部分）、`intersect`（只保留公共区域）、`subtract`（从主对象中减去其他对象）和 `fragment`（拆分为若干区域）。格式取自主对象。合并会替换选中的对象，并支持撤销、重做和协同。

下面的命令作用于当前选区；选区或操作无法应用时，`merged` 返回 `false`。参与合并的对象必须可编辑，并且处于同一分组范围内。连接线、SmartArt、OLE 对象、图表和表格不能作为合并对象，部分效果、动画和复杂的文本排版同样会阻止合并。

文本框参与合并后会转换为轮廓，其中的文字不能再作为文字编辑。如果无法读取渲染它所用的字体，合并会中止，原形状保持不变。参见[字体配置](#merge-shape-font-configuration)。

```ts
import { MergeSlideShapesCommand } from '@univerjs-pro/slides-ui'

const merged = await univerAPI.executeCommand(MergeSlideShapesCommand.id, {
  operation: 'union',
})
```
