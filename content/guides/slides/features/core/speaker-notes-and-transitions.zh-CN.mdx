---
title: 演讲者备注与切换效果
---

演讲者备注和切换效果存储在 Slides 快照中，并通过命令更新，因此会与撤销和重做保持同步。

## 演讲者备注

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

调用 `setSpeakerNotes(undefined)` 可清除备注。备注只属于一张幻灯片，不会作为页面元素渲染。

## 幻灯片切换效果

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()` 返回为该幻灯片解析后的切换效果。只有支持方向的效果类型才会保留 `direction`。

需要统一效果时，可以应用到全部幻灯片：

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

调用 `slide.setTransition(undefined)` 可清除单页切换效果。播放时会使用[演示模式](/guides/slides/features/core/presentation-mode)中介绍的解析后效果。
