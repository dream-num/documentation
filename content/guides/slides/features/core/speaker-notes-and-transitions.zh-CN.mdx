---
title: 演讲者备注与切换效果
---

演讲者备注和切换效果都保存在 Slides 快照中，并通过命令更新，因此与撤销、重做保持同步。

## 演讲者备注

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

调用 `setSpeakerNotes(undefined)` 可以清空备注。一条备注只属于一张幻灯片，不会被作为页面元素渲染。

## 幻灯片切换效果

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()` 返回该幻灯片解析后的切换效果。只有支持方向的切换类型才会保留所设置的 `direction`。

如果所有幻灯片都使用同一个效果，可以统一应用一次：

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

调用 `slide.setTransition(undefined)` 可以清除单张幻灯片上设置的切换效果。播放时使用[演示模式](/guides/slides/features/core/presentation-mode)中说明的解析后切换效果。
