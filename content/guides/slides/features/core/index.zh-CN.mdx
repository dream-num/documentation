Univer Slides 核心由演示文稿模型和浏览器编辑界面两部分组成。模型把演示文稿保存为 `ISlideData` 快照，界面根据这份模型渲染，并通过 Univer 命令修改它。

## 功能

- 演示文稿模型维护演示文稿的标识、页面尺寸、幻灯片顺序、幻灯片、母版页、版式页、主题、切换效果和资源。
- 渲染与编辑涵盖幻灯片画布、缩略图、选择、剪贴板、文本与形状编辑、对齐参考线和放映。
- 页面和元素的改动都通过命令和变更完成，模型更新、渲染以及撤销重做因此保持同步。
- Facade API 创建和查找演示文稿、保存快照，并把幻灯片和元素操作暴露为应用可以调用的对象。
- 表格、图表、打印、导入导出等可选功能以插件形式留在核心栈之外。

## 插件模式

### 安装

```package-install
npm install @univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/slides @univerjs-pro/slides-ui
```

### 使用

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
import SlidesUIEnUS from '@univerjs-pro/slides-ui/locale/en-US'
import SlidesEnUS from '@univerjs-pro/slides/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
import { UniverDrawingPlugin } from '@univerjs/drawing'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/slides/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'
import '@univerjs-pro/slides-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, DocsUIEnUS, SlidesEnUS, SlidesUIEnUS),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const presentation = univerAPI.createPresentation({ name: 'Quarterly review' })
```

### 插件配置 [#plugin-configuration]

`UniverLicensePlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 客户端许可证文件的内容。 |

#### `UniverSlidesUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | 启用编辑界面。设为 `false` 时可以只显示内容。 |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | 启用编辑界面。设为 `false` 时可以只显示内容。 |

如果浏览器只需要渲染演示文稿而不显示编辑控件，请把 `UniverSlidesUIPlugin` 配置为 `{ editor: { enabled: false } }`。在 Node.js 进程中，只注册 `UniverSlidesPlugin`，不注册界面插件。

| <ConfigKey depth={2}>label</ConfigKey> | `string \| object` |  | 指定标签或自定义标签组件。 |
| <ConfigKey depth={2}>params</ConfigKey> | `Record<string, unknown> \| (() => Record<string, unknown> \| undefined)` |  | 传给命令的参数，或用于生成参数的函数。 |
| <ConfigKey depth={2}>gridLayout</ConfigKey> | `object` |  | 在网格功能区中的位置。 |
| <ConfigKey depth={3}>row</ConfigKey> | `1 \| 2` |  | 组内第 1 行或第 2 行。 |
| <ConfigKey depth={3}>column</ConfigKey> | `number` |  | 组内的列号，从 1 开始。 |
| <ConfigKey depth={3}>rowSpan</ConfigKey> | `1 \| 2` | `1` | 占用的行数。 |
| <ConfigKey depth={3}>columnSpan</ConfigKey> | `number` | `1` | 占用的列数。 |
| <ConfigKey depth={3}>showLabel</ConfigKey> | `boolean` | `false` | 在图标旁显示标题。 |

| `ribbonType` | `RibbonType` | `classic` | 选择 Ribbon 布局。 |

`menu` 和 `ribbonType` 应写在现有的 `UniverUIPlugin` 注册配置中。这两项是共享的 UI 配置，不属于 `UniverSlidesUIPlugin`。下面的示例使用 Slides 实际的菜单项 ID：

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'slide.menu.insert.text': {
    order: 1,
    gridLayout: { row: 1, column: 2, rowSpan: 2, showLabel: true, width: 96 },
  },
  'slide.menu.insert.shape': {
    order: 0,
    gridLayout: { row: 1, column: 1, rowSpan: 2, showLabel: true },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order` 按数值从小到大排列同级的页签、分组或菜单项，不会把菜单项移动到其他分组。菜单项 ID 应从其 `data-u-command` 属性中获取，不能假定它与命令 ID 相同。

## 预设模式

Univer Slides 目前尚未提供预设包。无论只运行模型还是构建浏览器编辑器，都应使用插件模式。

## 工具栏分组 [#ribbon-controls]

开始选项卡包含主题、切换、背景和演讲者备注控件。插入选项卡集中放置内容插入和对象列表。视图选项卡提供页面尺寸、缩放和全屏。上下文格式选项卡随选区变化：选中形状时显示形状格式，选中图片时显示图片格式，选中图表时显示图表格式，包含图片或图表的混合选区则显示通用的对象控件。图片格式选项卡包括裁剪和裁剪形状、尺寸、位置、旋转，其中部分控件仅对单张图片有效。选中表格时使用表格 UI 插件提供的控件。形状格式另有独立的浮动工具栏开关。

## 用 Facade API 更新菜单 [#menu-facade]

### 运行时更新

请先导入 `@univerjs/ui/facade`，再使用 `FUniver.newAPI(univer)` 创建 `univerAPI`。[`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) 会把改动合并到现有配置中，未指定的字段保持原样，然后刷新菜单。覆盖配置对之后注册的菜单同样生效。

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'slide.menu.insert.text': { gridLayout: { row: 1, column: 2, width: 120 } },
})
```

`gridLayout` 仅对网格 Ribbon 生效。每个分组固定两行，`row` 和 `column` 都从 1 开始。显式指定的位置优先于按 `order` 排出的视觉顺序，因此交换两个已占用的单元格时，需要同时更新两个菜单项。未指定的可选字段沿用现有配置或 Schema。跨行、跨列、标签、宽度和图标尺寸定义在 [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout) 上。

`UniverSlidesUIPlugin` 中的编辑功能必须保持开启。一旦设为 `editor.enabled: false`，该产品的 Ribbon 就不会注册，菜单覆盖也无法补出缺失的按钮。

自定义按钮和子菜单入口遵循相同的规则：[`createMenu()`、`createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem) 同样接受 `order` 和 `gridLayout`，并通过 `appendTo()` 注册。弹窗中的内容不使用 Ribbon 的网格布局。

## 保存前提交文本 [#commit-text-before-saving]

加载 `@univerjs-pro/slides-ui/facade` 之后，自定义工具栏或对话框应在保存快照前调用 `await presentation.endTextEditingAsync()`。只有在调用返回 `true` 后才保存。返回 `false` 表示草稿未能提交，或者输入法仍在组词。
