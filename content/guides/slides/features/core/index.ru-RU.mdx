Ядро Univer Slides состоит из модели презентации и пользовательского интерфейса для редактирования браузера. Модель хранит презентацию в виде снимка `ISlideData`, а пользовательский интерфейс визуализирует эту модель и модифицирует ее с помощью команд Univer.

## Возможности

- Модель презентации поддерживает идентичность презентации, размер страницы, порядок слайдов, слайды, основные страницы, страницы макета, темы, переходы и ресурсы.
- Рендеринг и редактирование охватывают холст слайда, миниатюры, выбор, буфер обмена, редактировать текст и форму, руководства по выравниванию и воспроизведению презентации.
- Изменения на страницах и элементах применяются через команды и мутации, поэтому обновления моделей, рендеринг и отмена и переделка остаются синхронизированными.
- Facade API создает и находит презентации, сохраняет снимки и раскрывает операции слайдов и элементов в качестве объектов, которые приложение может вызывать.
- Дополнительные функции, такие как таблицы, диаграммы, печать и импорт / экспорт, остаются за пределами основного стека в виде плагинов.

## Режим плагинов

### Установка

```package-install
npm install @univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/slides @univerjs-pro/slides-ui
```

### Использование

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
import SlidesUIEnUS from '@univerjs-pro/slides-ui/locale/en-US'
import SlidesEnUS from '@univerjs-pro/slides/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
import { UniverDrawingPlugin } from '@univerjs/drawing'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/slides/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'
import '@univerjs-pro/slides-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, DocsUIEnUS, SlidesEnUS, SlidesUIEnUS),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const presentation = univerAPI.createPresentation({ name: 'Quarterly review' })
```

Установите `menu` и `ribbonType` в существующей регистрации `UniverUIPlugin`. Оба являются общими параметрами пользовательского интерфейса и не принадлежат `UniverSlidesUIPlugin`, в следующем примере используются идентификаторы меню от Slides:

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'slide.menu.insert.text': {
    order: 1,
    gridLayout: { row: 1, column: 2, rowSpan: 2, showLabel: true, width: 96 },
  },
  'slide.menu.insert.shape': {
    order: 0,
    gridLayout: { row: 1, column: 1, rowSpan: 2, showLabel: true },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order` сортирует родственные вкладки, группы или пункты меню в порядке возрастания. Он не перемещает элемент в другую группу. Используйте фактический идентификатор пункта меню, который доступен из атрибута `data-u-command`, вместо того, чтобы предполагать, что он соответствует идентификатору команды.

## Режим Preset

Univer Slides пока не предоставляет предустановленного пакета. Используйте режим плагина как для запуска одной модели, так и для создания редактора браузера.

## Организация ленты [#ribbon-controls]

Вкладка «Пуск» содержит элементы управления темой, переходом, фоном и динамиком. Вкладка Insert собирает вставку контента и список объектов. Вкладку «Вид» обеспечивает размер страницы, масштабирование и полноэкран. Вкладки контекстного формата следуют выбору: выбранная форма показывает форматирование формы, выбранное изображение показывает форматирование изображения, выбранная диаграмма показывает форматирование диаграммы и смешанный выбор, который включает изображения или диаграммы, показывает общие элементы управления объектом. Вкладке изображения охватывает форму урожая и клипа, размер, положение и вращение, а некоторые из этих элементов управления требуют единого изображения. Выборы таблицы используют элементы управления, поставляемые плагином пользовательского интерфейса таблицы. Форма форматирования также имеет отдельное плавающее переключение панели инструментов.

## Обновление меню через Facade API [#menu-facade]

### Обновление во время работы

Импорт `@univerjs/ui/facade` перед созданием `univerAPI` с `FUniver.newAPI(univer)`. [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) объединяет изменения в существующую конфигурацию, сохраняет поля, которые не указаны, и обновляет меню. Переопределения также применяются к меню, зарегистрированным позже.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'slide.menu.insert.text': { gridLayout: { row: 1, column: 2, width: 120 } },
})
```

`gridLayout` влияет только на сетку Ribbon. Каждая группа имеет два ряда, а `row` и `column` начинаются с 1. Эксплицитная позиция имеет приоритет над визуальным заказом `order`, поэтому при замене двух занятых ячеек оба элемента должны быть обновлены. Дополнительные поля наследуют существующую конфигурацию или схему. Отрезки, метки, ширины и размеры значков принадлежат [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout).

Продолжайте редактировать в `UniverSlidesUIPlugin`.С `editor.enabled: false` лента для этого продукта никогда не регистрируется, и переопределение меню не может добавить недостающие кнопки.

Пользовательские кнопки и триггеры подменю следуют тем же правилам. [`createMenu()` и `createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem) также принимает `order` и `gridLayout`, а `appendTo()` регистрирует их. Содержимое всплывающего окна не использует раскладку сетки Ribbon.

## Подтверждение текста перед сохранением [#commit-text-before-saving]

При загрузке `@univerjs-pro/slides-ui/facade` пользовательская панель инструментов или диалог должен позвонить `await presentation.endTextEditingAsync()`, прежде чем сохранить снимок. Сохранить только после того, как вызов решится на `true`. Возвратное значение `false` означает, что проект не может быть выполнен или что состав IME все еще находится в процессе разработки.
