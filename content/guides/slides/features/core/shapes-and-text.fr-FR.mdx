---
title: Formes et texte
---

Slides dessine des formes modifiables, des connecteurs et du texte de forme avec le moteur de forme partagée. `FSlide.insertShape()` retourne une Facade de forme, et chaque opération sur elle passe à travers le pipeline de commande Slides.

## Fournir les polices pour la fusion de texte [#merge-shape-font-configuration]

`UniverSlidesUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `mergeShapeFontResolver` | `(font: string, unitId: string, text: string) => ArrayBuffer \| Promise<ArrayBuffer \| undefined> \| undefined` |  | Renvoie les données exactes de la police utilisée pour le rendu. |

Si l'application charge ses propres polices, définissez `mergeShapeFontResolver(font, unitId, text)` dans `UniverSlidesUIPlugin`. Retournez les octets de la face exacte qui sera utilisée, avec le poids, le style et le retour déjà appariés, comme `ArrayBuffer` ou une promesse. Retournez `undefined` lorsque cette face exacte n'est pas disponible.

## Insérer une forme

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const shape = slide.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 64, width: 320, height: 120 },
  visible: true,
  selectable: true,
  shapeData: {
    fill: {
      fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
      color: '#dbeafe',
    },
  },
})
```

`insertShape()` retourne `null` lorsque l'adaptateur hôte Forme n'est pas disponible ou que l'entrée ne peut pas être créée. Enregistrez les dépendances de Forme requises par la configuration de Diapositives avant d'insérer des formes.

## Ajouter du texte enrichi

```ts
if (shape) {
  const richText = univerAPI.newRichText()
    .text('Quarterly ')
    .bold('review')

  shape.getText()
    .setRichText(richText)
    .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
    .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
}
```

Les Façades de forme sont disponibles à partir de `slide.getShape(id)` ou `slide.getShapes()`. Les méthodes d'éléments communs définissent la position, la taille, la visibilité, le nom et la description, et `slide.deleteElement(shape)` supprime la forme.

## Modifier le texte d’une forme

L'exemple suivant utilise l'objet de forme que `insertShape()` a retourné plus tôt. `getText()` retourne une poignée [Texte en forme de texte](/reference/facade/shape-text) en direct. Lisez le texte clair avec `getPlainText()`, remplacez-le par `setText()` et appliquez le formatage à travers les méthodes de police, de couleur et d'alignement.

```ts
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()` remplace le texte existant. Utilisez `setRichText()` lorsqu'une seule forme nécessite plusieurs styles de texte. Pour modifier le texte riche existant, appelez `getRichText()?.copy()`, modifiez le constructeur et passez-le à `setRichText()`; l'édition du constructeur détaché ne réécrit aucun changement. D'autres options sont décrites dans [Style de texte](/reference/facade/shape-text#settextstyle) et [Rembourrage et mise en page de la boîte de texte](/reference/facade/shape-text#settextboxoptions).

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## Reproduire la mise en forme des formes [#format-painter]

Sélectionnez une forme source, activez le formateur, puis sélectionnez la forme cible. Le peintre copie le remplissage, la course, les effets et le formatage de texte supporté, et laisse inchangé l'identité de la cible, la géométrie, le contenu texte et les fixations de formule. Le formatage clair restaure les valeurs par défaut de l'insertion. SmartArt est exclu. Le plugin UI de forme correspondant enregistre automatiquement ce comportement.

## Fusionner les formes [#merge-shapes]

Sélectionnez 2–10 objets pris en charge sur la même diapositive, puis utilisez **Fusionner les formes**. Les opérations sont `union` (toutes les zones), `combine` (suppléments exclus), `intersect` (espace partagé), `subtract` (supprime les autres objets de l'objet primaire) et `fragment` (splited into regions). Le formatage provient de l'article primaire. La fusion remplace les objets sélectionnés et prend en charge l'annulation, le redécoupage et la collaboration.

La commande suivante agit sur la sélection courante. `merged` est `false` lorsque la sélection ou l'opération ne peut pas être appliquée. Les objets doivent être modifiables et dans le même champ de groupe. Les connecteurs, SmartArt, les objets OLE, les graphiques et les tables ne peuvent pas être fusionner les opérandes, et certains effets, animations et mises en page de texte complexes empêchent également la fusion.

Une boîte de texte qui participe à une fusion est convertie en contours, et son texte ne peut plus être édité comme texte après. Si la police utilisée pour la rendre ne peut pas être lue, la fusion s'arrête et les formes originales restent inchangées. Voir [Configuration des polices](#merge-shape-font-configuration).

```ts
import { MergeSlideShapesCommand } from '@univerjs-pro/slides-ui'

const merged = await univerAPI.executeCommand(MergeSlideShapesCommand.id, {
  operation: 'union',
})
```
