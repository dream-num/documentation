Univer Slides core は、プレゼンテーションモデルとブラウザ編集 UI で構成されます。このモデルは、`ISlideData` スナップショットとしてプレゼンテーションを保存し、そのモデルをレンダリングし、Univerコマンドでそれを修正します。

## 機能

- プレゼンテーションモデルは、プレゼンテーションのアイデンティティ、ページサイズ、スライドオーダー、スライド、マスターページ、レイアウトページ、テーマ、移行、リソースを維持します。
- スライド・キャンバス、サムネイル、選択、クリップボード、テキスト、形状編集、アライメント・ガイド、およびプレゼンテーション再生のレンダリングおよび編集カバー。
- ページや要素の変更は、コマンドやミューテーションによって適用されます。そのため、モデルの更新、レンダリング、および undo および redo は同期化されます。
- Facade APIは、プレゼンテーションの作成と配置、スナップショットを保存し、アプリケーションが呼び出すことができるオブジェクトとしてスライドと要素の操作を公開します。
- テーブル、チャート、印刷、およびインポート/エクスポートなどのオプション機能は、プラグインとしてコアスタックの外に残っています。

## プラグインモード

### インストール

```package-install
npm install @univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/slides @univerjs-pro/slides-ui
```

### 使用方法

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
import SlidesUIEnUS from '@univerjs-pro/slides-ui/locale/en-US'
import SlidesEnUS from '@univerjs-pro/slides/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
import { UniverDrawingPlugin } from '@univerjs/drawing'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/slides/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'
import '@univerjs-pro/slides-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, DocsUIEnUS, SlidesEnUS, SlidesUIEnUS),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const presentation = univerAPI.createPresentation({ name: 'Quarterly review' })
```

#### `UniverSlidesUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | 編集 UI を有効にします。`false` では表示専用になります。 |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | 編集 UI を有効にします。`false` では表示専用になります。 |

`menu`と`ribbonType`を既存の`UniverUIPlugin`登録で設定します。どちらも共有UIオプションであり、`UniverSlidesUIPlugin`に属していません。以下の例では、スライドからメニューIDを使用します。

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'slide.menu.insert.text': {
    order: 1,
    gridLayout: { row: 1, column: 2, rowSpan: 2, showLabel: true, width: 96 },
  },
  'slide.menu.insert.shape': {
    order: 0,
    gridLayout: { row: 1, column: 1, rowSpan: 2, showLabel: true },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order` は、昇順のタブ、グループ、またはメニュー項目をソートします。項目を別のグループに移動しません。 実際のメニュー項目 ID を使用してください。これは、コマンド ID にマッチするのではなく、`data-u-command`属性から入手可能です。

## プリセットモード

Univer Slidesはプリセットパッケージを提供していません。 プラグインモードを使用して、モデルを単独で実行し、ブラウザエディタを構築します。

## リボンの構成 [#ribbon-controls]

[スタート]タブには、テーマ、トランジション、背景、およびスピーカーノートコントロールが含まれています。 Insertタブは、コンテンツのインサートとオブジェクトリストを収集します。 [ビュー]タブは、ページサイズ、ズーム、フルスクリーンを提供します。 コンテキスト形式タブは、選択された形状は、形状のフォーマット、選択した画像はイメージのフォーマットを表示し、選択したチャートは、一般的なオブジェクトコントロールを含む混合された選択を提供します。 画像タブは、cropとクリップをカバーし、図形を並べ替え、図形は、図形と図形をそれぞれに制御する必要があります。

## Facade API でメニューを更新する [#menu-facade]

### 実行時の更新

`univerAPI`を`FUniver.newAPI(univer)`で作成する前に、`@univerjs/ui/facade` をインポートします。 [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig)は、既存の設定の変更をマージし、指定されていないフィールドを保存し、メニューをリフレッシュします。 オーバーライドは、後で登録されたメニューにも適用されます。

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'slide.menu.insert.text': { gridLayout: { row: 1, column: 2, width: 120 } },
})
```

`gridLayout`はグリッドリボンのみに影響を与えます。各グループには2列、`row`と`column`が1で始まります。明示的な位置は`order`の視覚的な命令に優先されます。そのため、2つの占有セルが交換されると、両方の項目が更新されなければなりません。オプションフィールドは既存の構成またはスキーマを継承します。スパン、ラベル、幅、およびアイコンサイズは[`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout)に属します。

`UniverSlidesUIPlugin`で編集を有効にしてください。 `editor.enabled: false`では、この製品のリボンが登録されず、メニューオーバーライドは欠けているボタンを追加することはできません。

カスタムボタンとサブメニューは同じルールに従います。[`createMenu()`および`createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem)は`order`と`gridLayout`も受け付けており、`appendTo()`がそれらを登録します。ポップアップの内容はリボングリッドレイアウトを使用しません。

## 保存前にテキストを確定する [#commit-text-before-saving]

`@univerjs-pro/slides-ui/facade`がロードされると、カスタムツールバーまたはダイアログは、スナップショットを保存する前に`await presentation.endTextEditingAsync()`を呼び出す必要があります。 コールが`true`に解決した後にのみ保存します。 `false`の戻り値は、ドラフトがコミットされていないか、IME構成が進行中であることを意味します。
