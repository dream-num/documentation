---
title: Univer Slides API
---

슬라이드 Facade는 `FUniver`에 프레젠테이션 및 슬라이드 객체를 추가합니다. API 객체를 만들기 전에 부작용 항목을 가져 오기 :

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 프레젠테이션 만들기와 찾기

```ts
const presentation = univerAPI.createPresentation({
  id: 'quarterly-review',
  name: 'Quarterly review',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

`createPresentation()`는 부분적인 `ISlideData` 스냅 샷을 받아들입니다. 이전에 저장된 프레젠테이션을 복원하려면 `save()`로 돌아오는 스냅 샷을 통과하십시오.

## 프레젠테이션 Unit 다루기

`FPresentation`는 단위 정체성, 이름, 페이지 크기, 활주, 활동적인 활주, 전환, 허가 및 분리되는 스냅샷을 드러냅니다:

```ts
presentation.setName('FY 2027 review')

const opening = presentation.getSlideByIndex(0) ?? presentation.appendSlide({
  name: 'Opening',
})

presentation.setActiveSlide(opening)
const snapshot = presentation.save()
```

`snapshot`를 mutate하지 마십시오. 실행 프레젠테이션을 업데이트하십시오. Facade 방법이나 명령을 사용하여 렌더링 및 undo 역사가 동기화됩니다.

## 슬라이드로 들어가기

`FSlide`를 사용하여 배경, 스피커 노트, 전환 및 슬라이드의 요소와 함께 작업하십시오.

```ts
const slide = presentation.getActiveSlide()

if (slide) {
  const elements = slide.getElements()
  const notes = slide.getSpeakerNotes()
}
```

특정 작업에 대해서는 [슬라이드 및 레이아웃](/guides/slides/features/core/slides-and-layouts), [모양과 텍스트](/guides/slides/features/core/shapes-and-text) 및 [이미지 및 그룹](/guides/slides/features/core/images-and-groups)를 참조하십시오.

## 명령 대상 확인

명령 이벤트 매개 변수는 프리젠 테이션 식별자 및 슬라이드 식별자를 수행 할 수 있습니다. 현재 선택에 의존하는 매개 변수에서 해결 :

```ts
const listener = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ params }) => {
    const target = univerAPI.getSlideCommandTarget(params)
    console.log(target?.presentation.getId(), target?.slide.getId())
  }
)
```

제거된 구성품을 소유할 때 청취자를 처분합니다.

## 프레젠테이션 언로드

더 이상 필요하지 않을 때 ID로 슬라이드 유닛을로드하십시오. 전체 응용 프로그램이 파괴 될 때 루트 `univer` 인스턴스를 해제하십시오.

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  univerAPI.disposeUnit(presentation.getId())
}
```
