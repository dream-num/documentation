---
title: 프레젠테이션 모드
---

`UniverSlidesUIPlugin`은 현재 덱의 프레젠테이션 재생 기능을 등록합니다. 재생은 슬라이드 순서를 따르고 건너뛰기로 표시된 슬라이드를 제외하며 이동할 때마다 계산된 전환을 적용합니다.

## 재생 시작

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  await univerAPI.executeCommand('slide.operation.presentation.start', {
    unitId: presentation.getId(),
    fromBeginning: true,
  })
}
```

활성 슬라이드에서 시작하려면 `fromBeginning: false`를 사용하고, 특정 표시 슬라이드에서 시작하려면 `startSlideId`를 전달합니다.

## 이동과 중지

```ts
await univerAPI.executeCommand('slide.operation.presentation.next')
await univerAPI.executeCommand('slide.operation.presentation.previous')

await univerAPI.executeCommand('slide.operation.presentation.go-to-slide', {
  slideId: 'summary-slide',
})

await univerAPI.executeCommand('slide.operation.presentation.stop')
```

마지막 표시 슬라이드에서 다음 작업을 실행하면 재생이 종료됩니다. 첫 슬라이드에서 이전 작업은 `false`를 반환합니다.

## 브라우저 동작

전체 화면과 듀얼 스크린 프레젠테이션은 브라우저 API에 의존합니다. 팝업 차단을 피하도록 청중 창은 사용자 동작에서 직접 여세요. 편집을 끈 보기 전용 UI도 UI 플러그인이 등록되어 있으면 재생할 수 있습니다.
