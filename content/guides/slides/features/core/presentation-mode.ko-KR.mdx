---
title: 프레젠테이션 모드
---

`UniverSlidesUIPlugin`는 현재 갑판에 발표 재생을 추가합니다. 재생은 슬라이드를 통해 이동하고 건너 뛰기로 표시된 슬라이드를 건너, 각 이동을 위해 해결된 전환을 적용합니다.

## 재생 시작

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  await univerAPI.executeCommand('slide.operation.presentation.start', {
    unitId: presentation.getId(),
    fromBeginning: true,
  })
}
```

`fromBeginning: false`를 전달하여 현재 활성 슬라이드에서 시작하거나 `startSlideId`을 통과하여 시작점으로 눈에 보이는 슬라이드를 지정합니다.

## 이동과 중지

```ts
await univerAPI.executeCommand('slide.operation.presentation.next')
await univerAPI.executeCommand('slide.operation.presentation.previous')

await univerAPI.executeCommand('slide.operation.presentation.go-to-slide', {
  slideId: 'summary-slide',
})

await univerAPI.executeCommand('slide.operation.presentation.stop')
```

마지막 눈에 보이는 슬라이드에서 다음 명령을 호출하면 재생을 중지합니다. 이전 명령은 첫 번째 슬라이드에서 `false`를 반환합니다.

## 브라우저 동작

풀스크린과 듀얼스크린 프레젠테이션 명령은 브라우저 API에 따라 달라집니다. 청중 창은 사용자 제스처에서 직접 열어야 합니다. 그렇지 않으면 팝업 차단제가 거부됩니다. 시청자 전용 슬라이드 UI는 여전히 UI 플러그인이 편집 장애로 등록될 때 발표 모드를 실행할 수 있습니다.
