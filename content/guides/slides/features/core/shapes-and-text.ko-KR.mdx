---
title: 도형과 텍스트
---

슬라이드는 편집 가능한 모양, 커넥터 및 공유 모양 엔진과 텍스트를 형성합니다. `FSlide.insertShape()`는 모양 Facade를 반환하고 슬라이드 명령 파이프라인을 통과합니다.

## 텍스트 병합에 사용할 글꼴 설정 [#merge-shape-font-configuration]

`UniverSlidesUIPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `mergeShapeFontResolver` | `(font: string, unitId: string, text: string) => ArrayBuffer \| Promise<ArrayBuffer \| undefined> \| undefined` |  | 텍스트를 그릴 때 사용한 정확한 글꼴 데이터를 반환합니다. |

슬라이드 UI 플러그인은 이미 로드 된 지원된 웹 글꼴을 읽을 수 있습니다. 응용 프로그램은 자체 글꼴을로드하면 `UniverSlidesUIPlugin`에서 `mergeShapeFontResolver(font, unitId, text)`를 설정합니다. 사용 될 정확한 얼굴의 바이트를 반환하고 무게, 스타일, 그리고 미백이 이미 일치, `ArrayBuffer` 또는 약속으로. `undefined`을 반환하면 정확한 얼굴을 사용할 수 없습니다.

## 도형 삽입

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const shape = slide.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 64, width: 320, height: 120 },
  visible: true,
  selectable: true,
  shapeData: {
    fill: {
      fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
      color: '#dbeafe',
    },
  },
})
```

`insertShape()`는 모양 주인 접합기가 유효하지 않거나 입력은 창조될 수 없는 경우에 `null`를 반환합니다. 모양을 삽입하기 전에 활주 체제에 의해 요구되는 모양 의존성을 기록하십시오.

## 서식 있는 텍스트 추가

```ts
if (shape) {
  const richText = univerAPI.newRichText()
    .text('Quarterly ')
    .bold('review')

  shape.getText()
    .setRichText(richText)
    .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
    .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
}
```

모양 Facades는 `slide.getShape(id)` 또는 `slide.getShapes()`에서 유효합니다. 일반적인 성분 방법은 위치, 크기, 시정, 이름 및 묘사를 놓고, `slide.deleteElement(shape)`는 모양을 제거합니다.

## 도형 텍스트 편집

다음 예제는 `insertShape()`가 이전을 반환 한 모양 객체를 사용합니다. `getText()`는 라이브 [FShape텍스](/reference/facade/shape-text) 핸들을 반환합니다. `getPlainText()`와 일반 텍스트를 읽고 `setText()`로 모두 교체하고 글꼴, 색상 및 정렬 방법을 통해 포맷을 적용합니다.

```ts
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()`는 기존 텍스트를 대체합니다. 단일 모양이 여러 텍스트 스타일을 필요로 할 때 `setRichText()`를 사용하십시오. 기존의 풍부한 텍스트를 변경하려면 `getRichText()?.copy()`을 호출하고 빌더를 편집하고 `setRichText()`로 전달하십시오. 분리 된 빌더를 편집하면 변경 사항을 다시 작성하지 않습니다. 추가 옵션은 [텍스트 스타일](/reference/facade/shape-text#settextstyle) 및 [텍스트 상자 패딩 및 레이아웃](/reference/facade/shape-text#settextboxoptions)에서 설명됩니다.

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## SmartArt

SmartArt는 논리적 노드 트리와 독립적으로 편집할 수 있는 표시 도형으로 구성된 복합 도형입니다. `FSlide.insertSmartArt(layoutId, transform?)`는 `FShape` 또는 `FConnectorShape` 파사드를 반환하며, 레이아웃이나 Shape 호스트를 사용할 수 없으면 `null`을 반환합니다. 편집기에서는 삽입 도구 모음에서 SmartArt를 삽입하며, SmartArt 디자인 탭과 텍스트 창에서 동일한 노드를 편집합니다.

```ts
const smartArt = slide.insertSmartArt(
  'urn:microsoft.com/office/officeart/2005/8/layout/default',
  { left: 120, top: 90, width: 720, height: 360 },
)
if (!smartArt) throw new Error('Cannot insert SmartArt')
```

`isSmartArt()`는 SmartArt 도형을 식별합니다. `getSmartArtData()`는 레이아웃, 노드, 표시 도형의 분리된 복사본을 반환하며, 이 복사본을 `setSmartArtData()`에 전달하기 전까지 수정해도 슬라이드에 영향을 주지 않습니다.

```ts
const data = smartArt.getSmartArtData()
const nodeId = data?.rootNodeIds[0]
if (nodeId && data) {
  smartArt.updateSmartArtNode(nodeId, {
    text: { ...data.nodes[nodeId].text, text: 'Discovery' },
    fontSizeMode: univerAPI.Enum.SmartArtTextFontSizeModeEnum.Auto,
  })
}
```

`insertSmartArtNode()`, `deleteSmartArtNode()`, `moveSmartArtNode()`, `promoteSmartArtNode()`, `demoteSmartArtNode()`를 사용하여 노드 트리를 변경합니다. `setSmartArtLayout(id, category?)`는 논리적 노드를 유지하면서 레이아웃을 전환하고, `setSmartArtDirection()`은 읽기 방향을 설정합니다.

```ts
smartArt.setSmartArtLayout(
  'urn:microsoft.com/office/officeart/2005/8/layout/lProcess2',
  univerAPI.Enum.SmartArtCategoryEnum.Process,
)
```

`univerAPI.Enum`은 다섯 가지 SmartArt 열거형을 제공합니다: `SmartArtCategoryEnum`, `SmartArtDirectionEnum`, `SmartArtInsertPositionEnum`, `SmartArtNodeRoleEnum`, `SmartArtTextFontSizeModeEnum`.

`convertSmartArtToShapes()`는 변환된 일반 도형 파사드를 한 번의 실행 취소 가능한 단계로 반환합니다. 변환이 성공하면 해당 도형이 원래 SmartArt 도형을 대체합니다.

## 도형 서식 복사 [#format-painter]

소스 모양을 선택, 형식 화가를 활성화, 다음 대상 모양을 선택. 화가 사본을 복사, 스트로크, 효과, 및 지원 텍스트 포맷, 그리고 대상의 정체성, 기하학, 텍스트 콘텐츠, 및 공식 바인딩 unchanged. 명확한 포맷은 삽입에서 기본을 복원. SmartArt는 제외됩니다. 일치 모양 UI 플러그인은 자동으로이 동작을 등록합니다.

## 도형 병합 [#merge-shapes]

동일한 활주에 2-10 지원한 목표를, 그 후에 **Merge 모양**를 사용하십시오. 가동은 `union` (모든 지역), `combine`(overlaps 제외), `intersect`, `subtract`입니다 (주요한 목표에서 다른 목표를 제거하십시오), 및 `fragment`는 (지역으로 나누십시오). 체재는 1 차적인 목표에서 옵니다. Merdoging는 목표의, 상호 작용 및 상호작용하고, 협력을 대체합니다.

`merged`는 `false`가 선택 또는 작업이 적용될 수 없을 때 다음과 같은 명령을 사용합니다. 오브젝트는 편집 가능해야하며 동일한 그룹 범위 내에서 가능합니다. 커넥터, SmartArt, OLE 객체, 차트 및 테이블은 오페라와 일부 효과, 애니메이션 및 복잡한 텍스트 레이아웃을 병합할 수 없습니다.

병합에 참여하는 텍스트 상자는 윤곽으로 변환되며 텍스트는 나중에 텍스트로 편집 할 수 없습니다. 렌더링하는 글꼴이 읽을 수없는 경우, 병합 정지 및 원래 모양은 변경되지 않습니다. [글꼴 구성](#merge-shape-font-configuration)를 참조하십시오.

```ts
import { MergeSlideShapesCommand } from '@univerjs-pro/slides-ui'

const merged = await univerAPI.executeCommand(MergeSlideShapesCommand.id, {
  operation: 'union',
})
```
