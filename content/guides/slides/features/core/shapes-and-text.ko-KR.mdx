---
title: 도형과 텍스트
---

Slides는 공유 Shape 엔진으로 편집 가능한 도형, 연결선, 도형 텍스트를 제공합니다. `FSlide.insertShape()`는 Slides 명령 파이프라인에 연결된 도형 Facade를 반환합니다.

## 도형 삽입

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const shape = slide.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 64, width: 320, height: 120 },
  visible: true,
  selectable: true,
  shapeData: {
    fill: {
      fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
      color: '#dbeafe',
    },
  },
})
```

Shape 호스트 어댑터를 사용할 수 없거나 입력을 만들 수 없으면 `insertShape()`가 `null`을 반환할 수 있습니다. 도형을 삽입하기 전에 Slides 구성에 필요한 Shape 의존성을 등록하세요.

## 서식 있는 텍스트 추가

```ts
if (shape) {
  const richText = univerAPI.newRichText()
    .text('Quarterly ')
    .bold('review')

  shape.getText()
    .setRichText(richText)
    .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
    .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
}
```

`slide.getShape(id)` 또는 `slide.getShapes()`로 도형을 가져옵니다. 공통 요소 메서드로 위치, 크기, 표시 여부, 이름, 설명을 바꾸고 `slide.deleteElement(shape)`로 삭제할 수 있습니다.


## 도형 텍스트 편집

아래 또는 앞의 예제에서 `insertShape()`가 반환한 도형을 사용합니다. `getText()`는 실시간 [FShapeText](/reference/facade/shape-text) 객체를 반환합니다. `getPlainText()`로 텍스트를 읽고, `setText()`로 전체 텍스트를 바꾸며 글꼴, 색상, 정렬을 설정할 수 있습니다.

```ts
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()`는 기존 텍스트를 대체합니다. 여러 서식을 사용하려면 `setRichText()`를 사용하세요. 기존 서식 있는 텍스트를 편집하려면 `getRichText()?.copy()`로 빌더를 얻고 수정한 뒤 `setRichText()`에 전달합니다. 빌더를 수정하는 것만으로는 반영되지 않습니다. [텍스트 스타일](/reference/facade/shape-text#settextstyle)과 [텍스트 상자 여백 및 레이아웃](/reference/facade/shape-text#settextboxoptions)도 참고하세요.

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## 도형 서식 복사 [#format-painter]

원본 도형을 선택하고 서식 복사를 활성화한 뒤 대상 도형을 선택하세요. 채우기, 선, 효과 및 지원되는 텍스트 서식을 복사하고 대상 ID, 기하 정보, 텍스트 내용 및 수식 연결은 유지합니다. 서식 지우기는 삽입 기본값을 복원합니다. SmartArt는 제외되며 해당 도형 UI 플러그인이 기능을 자동 등록합니다.

## 도형 병합 [#merge-shapes]

같은 슬라이드에서 지원되는 개체 2–10개를 선택한 뒤 도형 병합을 실행합니다. `union`(모든 영역 합치기), `combine`(겹침 제외), `intersect`(공통 영역), `subtract`(기본 개체에서 다른 개체 빼기), `fragment`(영역 분할)를 지원합니다. 결과는 기본 개체의 서식을 사용합니다. 선택한 개체를 대체하며 실행 취소, 다시 실행, 공동 편집을 지원합니다.

아래 명령은 현재 선택 영역을 사용하며 적용할 수 없으면 `merged`가 `false`입니다. 개체는 편집 가능하고 같은 그룹 범위에 있어야 합니다. 연결선, SmartArt, OLE, 차트, 표는 대상이 아니며 일부 효과, 애니메이션, 복잡한 텍스트 배치도 병합을 막습니다.

텍스트 상자는 윤곽선으로 변환되므로 병합 후 텍스트로 편집할 수 없습니다. 실제 렌더링 글꼴 데이터가 필요합니다. `UniverSlidesUIPlugin`은 지원되는 로드된 Web 글꼴을 찾을 수 있습니다. 다른 소스는 설정의 `mergeShapeFontResolver(font, unitId, text)`에서 정확한 굵기, 스타일, 대체 글꼴에 맞는 `ArrayBuffer` 또는 Promise를 반환하세요. 정확히 일치하지 않으면 `undefined`를 반환합니다. 글꼴이 없으면 원본을 변경하지 않고 병합을 거부합니다.

```ts
import { MergeSlideShapesCommand } from '@univerjs-pro/slides-ui'

const merged = await univerAPI.executeCommand(MergeSlideShapesCommand.id, {
  operation: 'union',
})
```
