---
title: Univer Slides API
---

Las diapositivas Facade añade objetos de presentación y diapositivas a `FUniver`. Importar la entrada de efectos secundarios antes de crear el objeto API:

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Crear y buscar presentaciones

```ts
const presentation = univerAPI.createPresentation({
  id: 'quarterly-review',
  name: 'Quarterly review',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

`createPresentation()` acepta una instantánea `ISlideData` parcial. Para restaurar una presentación previamente guardada, pase la instantánea devuelta por `save()`.

## Trabajar con la unidad de presentación

`FPresentation` expone la identidad de la unidad, nombre, tamaño de la página, diapositivas, diapositivas activas, transiciones, permisos y una instantánea desprendida:

```ts
presentation.setName('FY 2027 review')

const opening = presentation.getSlideByIndex(0) ?? presentation.appendSlide({
  name: 'Opening',
})

presentation.setActiveSlide(opening)
const snapshot = presentation.save()
```

No mutar `snapshot` para actualizar una presentación en ejecución. Utilice métodos o comandos de Facade para que la renderización y la historia del deshacer se sincronice.

## Entrar en una diapositiva

Utilice `FSlide` para trabajar con el fondo, notas de altavoces, transición y elementos de una diapositiva:

```ts
const slide = presentation.getActiveSlide()

if (slide) {
  const elements = slide.getElements()
  const notes = slide.getSpeakerNotes()
}
```

Para operaciones específicas, consulte [Diapositivas y diseños](/guides/slides/features/core/slides-and-layouts), [Forma y texto](/guides/slides/features/core/shapes-and-text) y [Imágenes y grupos](/guides/slides/features/core/images-and-groups).

## Resolver destinos de comandos

Los parámetros del evento de comando pueden llevar un identificador de presentación y un identificador deslizante. Resolverlos de los parámetros en lugar de confiar en la selección actual:

```ts
const listener = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ params }) => {
    const target = univerAPI.getSlideCommandTarget(params)
    console.log(target?.presentation.getId(), target?.slide.getId())
  }
)
```

Disponer al oyente cuando el componente que posee se elimina.

## Descargar una presentación

Descargue una unidad de diapositivas por ID cuando ya no sea necesario. Desarrolle la instancia raíz `univer` sólo cuando toda la aplicación está siendo destruida.

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  univerAPI.disposeUnit(presentation.getId())
}
```
