---
title: Formas y texto
---

Diapositivas dibuja formas editables, conectores y texto de forma con el motor compartido de Forma. `FSlide.insertShape()` devuelve una forma Facade, y cada operación en ella pasa a través de la tubería de comandos.

## Configurar fuentes para combinar texto [#merge-shape-font-configuration]

`UniverSlidesUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `mergeShapeFontResolver` | `(font: string, unitId: string, text: string) => ArrayBuffer \| Promise<ArrayBuffer \| undefined> \| undefined` |  | Devuelve los bytes de la fuente exacta con la que se dibuja el texto. |

El plugin de diapositivas UI puede leer fuentes web compatibles que ya están cargadas. Si la aplicación carga sus propias fuentes, establece `mergeShapeFontResolver(font, unitId, text)` en `UniverSlidesUIPlugin`. Devuelve los bytes de la cara exacta que se utilizará, con el peso, el estilo y el retroceso ya emparejado, como un `ArrayBuffer` o una promesa. Volver `undefined` cuando esa cara exacta no está disponible.

## Insertar una forma

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const shape = slide.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 64, width: 320, height: 120 },
  visible: true,
  selectable: true,
  shapeData: {
    fill: {
      fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
      color: '#dbeafe',
    },
  },
})
```

`insertShape()` devuelve `null` cuando el adaptador Shape host no está disponible o la entrada no se puede crear. Registrar las dependencias de Forma requeridas por la configuración de diapositivas antes de insertar formas.

## Añadir texto enriquecido

```ts
if (shape) {
  const richText = univerAPI.newRichText()
    .text('Quarterly ')
    .bold('review')

  shape.getText()
    .setRichText(richText)
    .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
    .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
}
```

Las Facades de Forma están disponibles desde `slide.getShape(id)` o `slide.getShapes()`. Los métodos de elementos comunes establecen la posición, el tamaño, la visibilidad, el nombre y la descripción, y `slide.deleteElement(shape)` elimina la forma.

## Editar el texto de una forma

El siguiente ejemplo utiliza el objeto de forma que `insertShape()` regresó antes. `getText()` devuelve un mango en vivo [FShapeText](/reference/facade/shape-text). Lea el texto llano con `getPlainText()`, reemplace todo con `setText()`, y aplique el formato a través de los métodos de fuente, color y alineación.

```ts
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()` reemplaza el texto existente. Utilice `setRichText()` cuando una forma única requiere varios estilos de texto. Para cambiar el texto rico existente, llame a `getRichText()?.copy()`, edite el constructor, y pasarlo a `setRichText()`; editar el constructor separado por sí solo no escribe ningún cambio. Más opciones se describen en [estilo de texto](/reference/facade/shape-text#settextstyle) y [texto caja de relleno y diseño](/reference/facade/shape-text#settextboxoptions).

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## Copiar formato de formas [#format-painter]

Seleccione una forma de origen, active el pintor de formato, luego seleccione la forma de destino. El pintor copia el relleno, trazo, efectos, y el formato de texto compatible, y deja la identidad del objetivo, geometría, contenido de texto y unión de fórmula sin cambios. El formato claro restaura los defectos de la inserción. SmartArt está excluido. El plugin UI de forma de combinación registra este comportamiento automáticamente.

## Combinar formas [#merge-shapes]

Seleccione 2–10 objetos soportados en la misma diapositiva, luego utilice **Formas de fusión**. Las operaciones son `union` (todas las áreas), `combine` (excluidas superposiciones), `intersect` (zona dividida), `subtract` (remove los otros objetos del objeto primario), y `fragment` (split en regiones). El formato viene del objeto primario. La fusión reemplaza los objetos seleccionados y soporta el deshacer, redo y colaboración.

El siguiente comando actúa sobre la selección actual. `merged` es `false` cuando la selección o la operación no se puede aplicar. Los objetos deben ser editables y dentro del mismo alcance de grupo. Los conectores, SmartArt, OLE objetos, gráficos y tablas no pueden combinarse operados, y algunos efectos, animaciones y diseños de texto complejos también evitan la fusión.

Una caja de texto que participa en una fusión se convierte en contornos, y su texto ya no puede ser editado como texto después. Si la fuente utilizada para renderizarla no puede ser leída, las paradas de fusión y las formas originales permanecen inalteradas. [configuración de fuentes](#merge-shape-font-configuration).

```ts
import { MergeSlideShapesCommand } from '@univerjs-pro/slides-ui'

const merged = await univerAPI.executeCommand(MergeSlideShapesCommand.id, {
  operation: 'union',
})
```
