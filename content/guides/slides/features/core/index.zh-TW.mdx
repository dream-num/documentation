Univer Slides 核心由簡報模型和瀏覽器編輯介面兩部分組成。模型把簡報儲存為 `ISlideData` 快照，介面根據這份模型渲染，並透過 Univer 命令修改它。

## 功能

- 簡報模型維護簡報的標識、頁面尺寸、幻燈片順序、幻燈片、母版頁、版式頁、主題、切換效果和資源。
- 渲染與編輯涵蓋幻燈片畫布、縮圖、選擇、剪貼簿、文字與形狀編輯、對齊參考線和放映。
- 頁面和元素的改動都透過命令和變更完成，模型更新、渲染以及撤銷重做因此保持同步。
- Facade API 建立和查詢簡報、儲存快照，並把幻燈片和元素操作暴露為應用可以呼叫的物件。
- 表格、圖表、列印、匯入匯出等可選功能以外掛形式留在核心棧之外。

## 外掛程式模式

### 安裝

```package-install
npm install @univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/slides @univerjs-pro/slides-ui
```

### 使用

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
import SlidesUIEnUS from '@univerjs-pro/slides-ui/locale/en-US'
import SlidesEnUS from '@univerjs-pro/slides/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
import { UniverDrawingPlugin } from '@univerjs/drawing'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/slides/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'
import '@univerjs-pro/slides-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, DocsUIEnUS, SlidesEnUS, SlidesUIEnUS),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const presentation = univerAPI.createPresentation({ name: 'Quarterly review' })
```

### 外掛設定 [#plugin-configuration]

`UniverLicensePlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 用戶端授權檔的內容。 |

#### `UniverSlidesUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | 啟用編輯介面。設為 `false` 時可以只顯示內容。 |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | 啟用編輯介面。設為 `false` 時可以只顯示內容。 |

如果瀏覽器只需要渲染簡報而不顯示編輯控制元件，請把 `UniverSlidesUIPlugin` 配置為 `{ editor: { enabled: false } }`。在 Node.js 程序中，只註冊 `UniverSlidesPlugin`，不註冊介面外掛。

| <ConfigKey depth={2}>params</ConfigKey> | `Record<string, unknown> \| (() => Record<string, unknown> \| undefined)` |  | 傳給指令的參數，或提供參數的函式。 |
| <ConfigKey depth={2}>gridLayout</ConfigKey> | `object` |  | 在格線功能區中的位置。 |

| <ConfigKey depth={3}>column</ConfigKey> | `number` |  | 群組內的欄號，從 1 開始。 |
| <ConfigKey depth={3}>rowSpan</ConfigKey> | `1 \| 2` | `1` | 占用的列數。 |

| `ribbonType` | `RibbonType` | `classic` | 選擇 Ribbon 版面。 |

`menu` 和 `ribbonType` 應寫在現有的 `UniverUIPlugin` 註冊配置中。這兩項是共享的 UI 配置，不屬於 `UniverSlidesUIPlugin`。下面的範例使用 Slides 實際的選單項 ID：

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'slide.menu.insert.text': {
    order: 1,
    gridLayout: { row: 1, column: 2, rowSpan: 2, showLabel: true, width: 96 },
  },
  'slide.menu.insert.shape': {
    order: 0,
    gridLayout: { row: 1, column: 1, rowSpan: 2, showLabel: true },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order` 按數值從小到大排列同級的頁籤、分組或選單項，不會把選單項移動到其他分組。選單項 ID 應從其 `data-u-command` 屬性中取得，不能假定它與命令 ID 相同。

## 預設模式

Univer Slides 目前尚未提供預設套件。無論只執行模型還是建置瀏覽器編輯器，都應使用外掛模式。

## 工具列分組 [#ribbon-controls]

開始選項卡包含主題、切換、背景和演講者備註控制元件。插入選項卡集中放置內容插入和物件列表。檢視選項卡提供頁面尺寸、縮放和全屏。上下文格式選項卡隨選區變化：選中形狀時顯示形狀格式，選中圖片時顯示圖片格式，選中圖表時顯示圖表格式，包含圖片或圖表的混合選區則顯示通用的物件控制元件。圖片格式選項卡包括裁剪和裁剪形狀、尺寸、位置、旋轉，其中部分控制元件僅對單張圖片有效。選中表格時使用表格 UI 外掛提供的控制元件。形狀格式另有獨立的浮動工具欄開關。

## 用 Facade API 更新選單 [#menu-facade]

### 執行階段更新

請先匯入 `@univerjs/ui/facade`，再使用 `FUniver.newAPI(univer)` 建立 `univerAPI`。[`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) 會把改動合併到現有配置中，未指定的欄位保持原樣，然後重新整理選單。覆蓋配置對之後註冊的選單同樣生效。

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'slide.menu.insert.text': { gridLayout: { row: 1, column: 2, width: 120 } },
})
```

`gridLayout` 僅對網格 Ribbon 生效。每個分組固定兩行，`row` 和 `column` 都從 1 開始。顯式指定的位置優先於按 `order` 排出的視覺順序，因此交換兩個已佔用的單元格時，需要同時更新兩個選單項。未指定的可選欄位沿用現有配置或 Schema。跨行、跨列、標籤、寬度和圖示尺寸定義在 [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout) 上。

`UniverSlidesUIPlugin` 中的編輯功能必須保持開啟。一旦設為 `editor.enabled: false`，該產品的 Ribbon 就不會註冊，選單覆蓋也無法補出缺失的按鈕。

自定義按鈕和子選單入口遵循相同的規則：[`createMenu()`、`createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem) 同樣接受 `order` 和 `gridLayout`，並透過 `appendTo()` 註冊。彈窗中的內容不使用 Ribbon 的網格版面配置。

## 儲存前提交文字 [#commit-text-before-saving]

載入 `@univerjs-pro/slides-ui/facade` 之後，自定義工具欄或對話方塊應在儲存快照前呼叫 `await presentation.endTextEditingAsync()`。只有在呼叫返回 `true` 後才儲存。返回 `false` 表示草稿未能提交，或者輸入法仍在組詞。
