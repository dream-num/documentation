---
title: Notes du présentateur et transitions
---

Les notes et les transitions des haut-parleurs sont stockées dans l'instantané de Diapositives, et elles sont mises à jour à travers les commandes.

## Notes du présentateur

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

Appelez `setSpeakerNotes(undefined)` pour effacer les notes. Une note appartient à une seule diapositive et n'est jamais rendue en tant qu'élément de page.

## Transitions

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()` retourne la transition résolue pour cette diapositive. Seuls les types de transition qui prennent en charge une direction préservent la direction configurée.

Pour appliquer le même effet à chaque diapositive, définissez une transition pour toutes les diapositives :

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

Appelez `slide.setTransition(undefined)` pour effacer une transition définie sur une seule diapositive. Playback utilise la transition résolue décrite dans [Mode de présentation](/guides/slides/features/core/presentation-mode).
