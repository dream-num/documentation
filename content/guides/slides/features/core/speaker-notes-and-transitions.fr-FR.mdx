---
title: Notes du présentateur et transitions
---

Les notes et les transitions sont stockées dans l’instantané Slides et mises à jour par des commandes. Elles restent donc synchronisées avec l’annulation et le rétablissement.

## Notes du présentateur

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

Appelez `setSpeakerNotes(undefined)` pour effacer les notes. Elles appartiennent à une seule diapositive et ne sont pas rendues comme éléments de page.

## Transitions

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()` renvoie la transition résolue pour la diapositive. La direction n’est conservée que par les types qui la prennent en charge.

Appliquez une transition à toutes les diapositives pour obtenir un effet cohérent :

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

Appelez `slide.setTransition(undefined)` pour supprimer une transition propre à une diapositive. La lecture utilise la transition résolue décrite dans [Mode présentation](/guides/slides/features/core/presentation-mode).
