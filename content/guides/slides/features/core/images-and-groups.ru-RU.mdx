---
title: Изображения и группы
---

Изображения являются полноценными элементами слайда. Для URL или Blob используйте асинхронный метод, а если все свойства уже известны — builder.

## Вставка изображения

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const image = await slide.insertImageAsync(
  'https://example.com/assets/diagram.png',
  {
    imageSourceType: univerAPI.Enum.ImageSourceType.URL,
    left: 80,
    top: 120,
    width: 320,
    height: 180,
  }
)
```

`getImages()` возвращает изображения текущего слайда. Обновляйте изображение через `setSource()`, `setCrop()`, `setClipShape()` или `toBuilder()`, а удаляйте через `removeImage()`.

## Группировка элементов

```ts
const shape = slide.getShapes()[0]

if (shape) {
  const group = slide.group([shape, image])
  const children = group.getChildren()

  // Верните дочерние элементы на слайд.
  slide.ungroup(group)
}
```

Группы сохраняют порядок дочерних элементов и предоставляют общие методы преобразования, видимости, имени и описания. `getGroups()` перечисляет группы верхнего уровня.
