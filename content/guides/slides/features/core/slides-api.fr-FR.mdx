---
title: Univer Slides API
---

La Facade de diapositives ajoute des objets de présentation et de diapositive à `FUniver`. Importez l'entrée d'effet latéral avant de créer l'objet API :

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Créer et rechercher des présentations

```ts
const presentation = univerAPI.createPresentation({
  id: 'quarterly-review',
  name: 'Quarterly review',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

`createPresentation()` accepte un instantané partiel de `ISlideData`. Pour restaurer une présentation enregistrée précédemment, passez l'instantané retourné par `save()` .

## Manipuler l’unité de présentation

`FPresentation` expose l'identité de l'unité, le nom, la taille de la page, les diapositives, la diapositive active, les transitions, les permissions et un instantané détaché :

```ts
presentation.setName('FY 2027 review')

const opening = presentation.getSlideByIndex(0) ?? presentation.appendSlide({
  name: 'Opening',
})

presentation.setActiveSlide(opening)
const snapshot = presentation.save()
```

Ne mutez pas `snapshot` pour mettre à jour une présentation en cours d'exécution. Utilisez des méthodes ou des commandes Facade de sorte que le rendu et l'historique de défaire restent synchronisés.

## Accéder à une diapositive

Utilisez `FSlide` pour travailler avec l'arrière-plan, les notes de haut-parleur, la transition et les éléments d'une diapositive :

```ts
const slide = presentation.getActiveSlide()

if (slide) {
  const elements = slide.getElements()
  const notes = slide.getSpeakerNotes()
}
```

Pour les opérations spécifiques, voir [Diapositives et mises en page](/guides/slides/features/core/slides-and-layouts), [Formes et texte](/guides/slides/features/core/shapes-and-text) et [Images et groupes](/guides/slides/features/core/images-and-groups).

## Résoudre les cibles de commandes

Les paramètres d'événement de commande peuvent porter un identifiant de présentation et un identifiant de diapositive. Résolvez-les des paramètres au lieu de compter sur la sélection actuelle :

```ts
const listener = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ params }) => {
    const target = univerAPI.getSlideCommandTarget(params)
    console.log(target?.presentation.getId(), target?.slide.getId())
  }
)
```

Jetez l'auditeur lorsque le composant qui le possède est retiré.

## Décharger une présentation

Déchargez une unité de diapositives par ID lorsqu'elle n'est plus nécessaire. Jetez l'instance root `univer` seulement lorsque l'application entière est détruite.

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  univerAPI.disposeUnit(presentation.getId())
}
```
