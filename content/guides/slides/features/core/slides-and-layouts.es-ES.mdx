---
title: Diapositivas y diseños
---

`FPresentation` administra el orden de las diapositivas y el tamaño de página compartido. `FSlide` expone el diseño resuelto y el fondo de una diapositiva.

## Administrar el orden

```ts
const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const agenda = presentation.appendSlide({ name: 'Agenda' })
const summary = presentation.insertSlide(1, { name: 'Summary' })

presentation.moveSlide(summary, 0)
presentation.setActiveSlide(agenda)
```

Use `getSlides()`, `getSlideById()` y `getSlideByIndex()` para leer el orden actual. `deleteSlide()` elimina una diapositiva mediante la canalización de comandos.

## Definir el tamaño de página

```ts
presentation.setPageSize({
  preset: univerAPI.Enum.SlidePageSizePresetEnum.WideScreen16By9,
})
```

`slide.getPageLayout()` devuelve el tamaño resuelto y los límites y el orden de sus elementos. Las coordenadas usan el sistema del modelo de Slides.

## Definir el fondo

```ts
agenda.setBackground({
  type: univerAPI.Enum.SlideBackgroundTypeEnum.Solid,
  color: '#1d4ed8',
})
```

Pase `undefined` para quitar un fondo explícito. `setShowMasterBackground(false)` oculta los gráficos heredados del patrón sin borrarlos de la instantánea.
