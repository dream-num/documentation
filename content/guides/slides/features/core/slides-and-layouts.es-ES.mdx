---
title: Diapositivas y diseños
---

`FPresentation` gestiona el orden de diapositivas y el tamaño de la página compartido por toda la cubierta. `FSlide` proporciona el diseño resuelto y el fondo de una sola diapositiva.

## Administrar el orden

```ts
const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const agenda = presentation.appendSlide({ name: 'Agenda' })
const summary = presentation.insertSlide(1, { name: 'Summary' })

presentation.moveSlide(summary, 0)
presentation.setActiveSlide(agenda)
```

El orden actual se puede leer con `getSlides()`, `getSlideById()` o `getSlideByIndex()`. `deleteSlide()` elimina una diapositiva a través del oleoducto de comandos.

## Definir el tamaño de página

```ts
presentation.setPageSize({
  preset: univerAPI.Enum.SlidePageSizePresetEnum.WideScreen16By9,
})
```

`slide.getPageLayout()` devuelve el tamaño de página resuelto junto con los límites y el orden de cada elemento. Las coordenadas utilizan el sistema de coordenadas del modelo Slides.

## Definir el fondo

```ts
agenda.setBackground({
  type: univerAPI.Enum.SlideBackgroundTypeEnum.Solid,
  color: '#1d4ed8',
})
```

Pase `undefined` para eliminar un fondo de diapositiva explícitamente establecido. `setShowMasterBackground(false)` esconde los gráficos de fondo maestro heredados por esa diapositiva; no los quita de la instantánea de presentación.
