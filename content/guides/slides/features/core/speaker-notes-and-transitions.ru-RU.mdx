---
title: Заметки докладчика и переходы
---

Заметки спикера и переходы хранятся в слайд-снимке, и они обновляются с помощью команд, что позволяет синхронизировать их с отменой и переделкой.

## Заметки докладчика

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

Позвоните `setSpeakerNotes(undefined)`, чтобы очистить заметки. Заметка принадлежит к одному слайду и никогда не отображается как элемент страницы.

## Переходы

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()` возвращает разрешенный переход для этого слайда. Только типы переходов, которые поддерживают направление, сохраняют настроенное направление.

Чтобы применить один и тот же эффект к каждому слайду, установите один переход для всех слайдов:

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

Позвоните `slide.setTransition(undefined)`, чтобы очистить набор переходов на одном слайде. Воспроизведение использует разрешенный переход, описанный в [Режим представления](/guides/slides/features/core/presentation-mode).
