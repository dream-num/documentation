---
title: Заметки докладчика и переходы
---

Заметки и переходы хранятся в снимке Slides и обновляются командами, поэтому синхронизированы с отменой и повтором.

## Заметки докладчика

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

Вызовите `setSpeakerNotes(undefined)`, чтобы удалить заметки. Они относятся к одному слайду и не отображаются как элементы страницы.

## Переходы

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()` возвращает переход, рассчитанный для слайда. Направление сохраняется только для поддерживающих его типов.

Примените один переход ко всем слайдам, если нужен единый эффект:

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

Вызовите `slide.setTransition(undefined)`, чтобы убрать переход слайда. Воспроизведение использует рассчитанный переход, описанный в [Режиме презентации](/guides/slides/features/core/presentation-mode).
