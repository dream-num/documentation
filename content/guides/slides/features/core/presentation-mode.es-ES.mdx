---
title: Modo presentación
---

`UniverSlidesUIPlugin` añade reproducción de presentación a la cubierta actual. Playback se mueve a través de las diapositivas en orden, salta cualquier diapositiva marcada como saltada, y aplica la transición resuelta para cada movimiento.

## Iniciar la reproducción

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  await univerAPI.executeCommand('slide.operation.presentation.start', {
    unitId: presentation.getId(),
    fromBeginning: true,
  })
}
```

Pase `fromBeginning: false` para comenzar desde la diapositiva activa actualmente, o pasar `startSlideId` a especificar una diapositiva visible como el punto de partida.

## Navegar y detener

```ts
await univerAPI.executeCommand('slide.operation.presentation.next')
await univerAPI.executeCommand('slide.operation.presentation.previous')

await univerAPI.executeCommand('slide.operation.presentation.go-to-slide', {
  slideId: 'summary-slide',
})

await univerAPI.executeCommand('slide.operation.presentation.stop')
```

Invocando el siguiente comando en la última diapositiva visible detiene la reproducción. El comando anterior devuelve `false` en la primera diapositiva.

## Comportamiento del navegador

Los comandos de presentación de pantalla completa y de pantalla dual dependen de las APIs del navegador. La ventana de audiencia debe abrirse directamente en un gesto de usuario; de lo contrario un bloqueador popup lo rechaza. Un lector solo de imágenes UI puede ejecutar el modo de presentación cuando el plugin UI está registrado con la edición deshabilitado.
