---
title: Modo presentación
---

`UniverSlidesUIPlugin` registra la reproducción de la presentación actual. La reproducción sigue el orden, omite las diapositivas marcadas y aplica la transición resuelta en cada avance.

## Iniciar la reproducción

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  await univerAPI.executeCommand('slide.operation.presentation.start', {
    unitId: presentation.getId(),
    fromBeginning: true,
  })
}
```

Use `fromBeginning: false` para comenzar en la diapositiva activa o pase `startSlideId` para indicar una diapositiva visible.

## Navegar y detener

```ts
await univerAPI.executeCommand('slide.operation.presentation.next')
await univerAPI.executeCommand('slide.operation.presentation.previous')

await univerAPI.executeCommand('slide.operation.presentation.go-to-slide', {
  slideId: 'summary-slide',
})

await univerAPI.executeCommand('slide.operation.presentation.stop')
```

La operación siguiente detiene la reproducción después de la última diapositiva visible. Anterior devuelve `false` en la primera.

## Comportamiento del navegador

La pantalla completa y la presentación en dos pantallas dependen de API del navegador. Abra la ventana de audiencia desde un gesto del usuario para evitar el bloqueo de ventanas emergentes. Una interfaz de solo lectura también puede reproducir cuando el plugin UI está registrado con la edición desactivada.
