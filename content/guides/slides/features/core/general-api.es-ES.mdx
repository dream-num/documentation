La raíz Facade API combina el tiempo de ejecución Univer común con los plugins de diapositivas que la aplicación se registra. Esta página cubre comandos, eventos, historia, y el ciclo de vida de la unidad, y no asume experiencia con otro tipo de documento Univer. Para los objetos de presentación, vea [Univer Slides API](/guides/slides/features/core/slides-api) .

## Crear el objeto API

Crear un solo envoltorio `FUniver` después de la instancia Univer y los plugins necesarios están registrados:

```ts
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

Facade entries imported before this call add Slides methods to the same object.

## Comandos

`executeCommand()` ejecuta un comando registrado asincrónicamente. Usar `syncExecuteCommand()` sólo cuando el comando explícitamente soporta la ejecución sincronizada. Para operaciones comunes de diapositivas, prefiera los métodos Facade.

## Eventos

```ts
const commandLog = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ id }) => console.log('Executed:', id)
)

// Elimine el listener cuando ya no sea necesario.
commandLog.dispose()
```

Escucha `BeforeCommandExecute` cuando la aplicación necesita inspeccionar o cancelar un comando. `LifeCycleChanged` dispara cuando el editor entra en etapas como `Rendered` y `Steady`.

## Deshacer y rehacer

Deshacer y rehacer actuar en la unidad Univer enfocada y devolver promesas:

```ts
await univerAPI.undo()
await univerAPI.redo()
```

Diapositivas Las mutaciones de fachada pasan por el oleoducto de comandos, así que los cambios soportados entran en la misma historia.

## Portapapeles del sistema

Después de que `UniverSlidesUIPlugin` esté registrado y el lienzo de diapositivas se ha concentrado, `copy()` copia la selección actual y los insertos `paste()` clipboard contenidos a través de los comandos UI Slides.

```ts
import '@univerjs/ui/facade'

await univerAPI.copy()
await univerAPI.paste()
```

El menú contextual de lienzo admite pasta normal, pega como texto y pega como imagen. El modo texto crea una caja de texto editable del texto de portapapeles. El modo de imagen utiliza archivos de imagen o recursos de imagen en el HTML de portapatillas; no convierte contenido arbitrario en una imagen.

Al editar texto en forma o tabla, el editor proporciona **Mantener el formato fuente**, **Formato de destino de coincidencia** y **Mantenga el texto solo** junto con un menú de formato después del pegado.

Estas operaciones requieren un editor de navegador enfocado y permiso de portapapeles, por lo que no están disponibles en un tiempo de ejecución Node.js solo modelo. Si el navegador bloquea el clipboard lee, utilice el acceso directo del sistema.

## UI

La UI Facade muestra mensajes, abre diálogos o barras laterales, registra componentes y controla las partes de la UI incorporadas:

```ts
univerAPI
  .showMessage({ content: 'Presentation saved', type: 'success' })
  .setUIVisible(univerAPI.Enum.BuiltInUIPart.TOOLBAR, true)
```

Estos métodos requieren `UniverUIPlugin`; los controles de edición de diapositivas requieren también `UniverSlidesUIPlugin`.

## WebSocket

El soporte WebSocket es opcional y es proporcionado por la Network Facade:

```ts
import { UniverNetworkPlugin } from '@univerjs/network'

import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)

const socket = univerAPI.createSocket('wss://example.com/slides')
socket.open$.subscribe(() => socket.send('ready'))
```

Los protocolos de mensaje, autenticación, reconexión y manejo de conflictos de colaboración siguen siendo responsabilidad de la aplicación host.

## Enumeraciones

`univerAPI.Enum` expone los enums comunes de tiempo de ejecución y los enumes que Slides añade:

```ts
const lifecycle = univerAPI.Enum.LifecycleStages.Steady
const transition = univerAPI.Enum.SlideTransitionTypeEnum.Fade
const elementType = univerAPI.Enum.SlidePageElementTypeEnum.Shape
```

## Utilidades

`univerAPI.Util` ofrece ayudantes compartidos como el formato de números, las operaciones de rectángulo y las herramientas generales:

```ts
const payload = univerAPI.Util.tools.deepClone({
  slideId: 'slide-1',
  selectedElementIds: ['element-1'],
})
```
