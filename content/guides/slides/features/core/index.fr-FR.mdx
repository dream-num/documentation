Univer Slides core se compose d'un modèle de présentation et de l'interface d'édition du navigateur. Le modèle stocke une présentation sous forme d'un instantané `ISlideData`, et l'interface utilisateur rend ce modèle et le modifie à travers les commandes Univer.

## Fonctionnalités

- Le modèle de présentation maintient l'identité de la présentation, la taille de la page, l'ordre des diapositives, les diapositives, pages de gestion, pages de mise en page, thèmes, transitions et ressources.
- Le rendu et l'édition couvrent la toile de diapositives, les vignettes, la sélection, le presse-papier, l'édition de texte et de forme, les guides d'alignement et la lecture de présentation.
- Les modifications apportées aux pages et aux éléments sont appliquées par le biais de commandes et de mutations, de sorte que les mises à jour du modèle, le rendu, et la désactivation et le redémarrage restent synchronisés.
- Le Facade API crée et localise des présentations, enregistre des instantanés et expose les opérations de diapositives et d'éléments en tant qu'objets que l'application peut appeler.
- Les fonctionnalités optionnelles telles que les tableaux, les graphiques, l'impression et l'importation/exportation restent en dehors de la pile de noyau comme plugins.

## Mode plugin

### Installation

```package-install
npm install @univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/slides @univerjs-pro/slides-ui
```

### Utilisation

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
import SlidesUIEnUS from '@univerjs-pro/slides-ui/locale/en-US'
import SlidesEnUS from '@univerjs-pro/slides/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
import { UniverDrawingPlugin } from '@univerjs/drawing'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/slides/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'
import '@univerjs-pro/slides-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, DocsUIEnUS, SlidesEnUS, SlidesUIEnUS),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const presentation = univerAPI.createPresentation({ name: 'Quarterly review' })
```

| --- | --- | --- | --- |

Définissez `menu` et `ribbonType` dans l'enregistrement `UniverUIPlugin` existant. Les deux sont des options d'interface utilisateur partagées et n'appartiennent pas à `UniverSlidesUIPlugin`. L'exemple suivant utilise les identifiants de menu des diapositives :

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'slide.menu.insert.text': {
    order: 1,
    gridLayout: { row: 1, column: 2, rowSpan: 2, showLabel: true, width: 96 },
  },
  'slide.menu.insert.shape': {
    order: 0,
    gridLayout: { row: 1, column: 1, rowSpan: 2, showLabel: true },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order` trie des onglets, des groupes ou des éléments de menu dans l'ordre croissant. Il ne déplace pas un élément dans un autre groupe. Utilisez l'identifiant de l'élément de menu réel, qui est disponible à partir de l'attribut `data-u-command`, plutôt que de supposer qu'il correspond à l'identificateur de commande.

## Mode prédéfini

Univer Slides ne fournit pas encore un paquet prédéfini. Utilisez le mode Plugin à la fois pour exécuter le modèle seul et pour construire l'éditeur de navigateur.

## Organisation du ruban [#ribbon-controls]

L'onglet Démarrer contient les commandes thème, transition, arrière-plan et haut-parleur. L'onglet Insérer rassemble l'insertion de contenu et la liste des objets. L' onglet Affichage fournit la taille de la page, le zoom et le plein écran. L'intercalaire contextuel suit la sélection : une forme sélectionnée montre le formatage de la forme, une image sélectionnée montre le Formatage d'image, un graphique sélectionné montre le formating de la carte, et une sélection mixte comprenant des images ou des graphiques montre les commandes communes d'objets. L'onglette d'image couvre la forme de crop et de clip, la taille, la position et la rotation, et certaines de ces commandes nécessitent une image unique.

## Mettre à jour les menus avec l’API Facade [#menu-facade]

### Mise à jour à l’exécution

Importez `@univerjs/ui/facade` avant de créer `univerAPI` avec `FUniver.newAPI(univer)`. [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) fusionne les modifications dans la configuration existante, conserve les champs qui ne sont pas spécifiés et rafraîchit les menus. Les dépassements s'appliquent également aux menus enregistrés plus tard.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'slide.menu.insert.text': { gridLayout: { row: 1, column: 2, width: 120 } },
})
```

`gridLayout` n'affecte que la grille Ribbon. Chaque groupe a deux lignes, et `row` et `column` 1. Une position explicite a priorité sur l'ordre visuel par `order`, donc lorsque deux cellules occupées sont échangées, les deux éléments doivent être mis à jour. Les champs optionnels héritent de la configuration ou du schéma existant. [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout).

Gardez l'édition activée dans `UniverSlidesUIPlugin`. Avec `editor.enabled: false`, le Ribbon de ce produit n'est jamais enregistré, et les surcharges de menu ne peuvent pas ajouter les boutons manquants.

Les boutons personnalisés et les déclencheurs du sous-menu suivent les mêmes règles. [`createMenu()` et `createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem) accepte également les numéros `order` et `gridLayout`, et `appendTo()` les enregistre. Le contenu du popup n'utilise pas la disposition de la grille Ribbon.

## Valider le texte avant l’enregistrement [#commit-text-before-saving]

Lorsque `@univerjs-pro/slides-ui/facade` est chargé, une barre d'outils ou une boîte de dialogue personnalisée doit appeler `await presentation.endTextEditingAsync()` avant d'enregistrer un instantané. Enregistrer seulement après que l'appel résout `true`. Une valeur de retour de `false` signifie que le projet ne peut pas être engagé ou que la composition IME est toujours en cours.
