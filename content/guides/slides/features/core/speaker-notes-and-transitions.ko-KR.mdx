---
title: 발표자 노트와 전환
---

발표자 노트와 전환은 Slides 스냅샷에 저장되고 명령을 통해 업데이트되므로 실행 취소 및 다시 실행과 동기화됩니다.

## 발표자 노트

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

노트를 지우려면 `setSpeakerNotes(undefined)`를 호출합니다. 노트는 한 슬라이드에 속하며 페이지 요소로 렌더링되지 않습니다.

## 슬라이드 전환

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()`은 해당 슬라이드에 계산된 전환을 반환합니다. 방향은 이를 지원하는 전환 유형에서만 유지됩니다.

덱 전체에 일관된 효과를 적용하려면 모든 슬라이드에 한 번에 설정합니다.

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

슬라이드 고유 전환을 지우려면 `slide.setTransition(undefined)`를 호출합니다. 재생은 [프레젠테이션 모드](/guides/slides/features/core/presentation-mode)에 설명된 계산된 전환을 사용합니다.
