---
title: 발표자 노트와 전환
---

스피커 노트와 전환은 슬라이드 스냅 샷에 저장되며 명령을 통해 업데이트됩니다. 이것은 undo와 redo와 동기화를 유지합니다.

## 발표자 노트

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

`setSpeakerNotes(undefined)`를 호출하여 메모를 지우십시오. 메모는 단일 슬라이드에 속하며 페이지 요소로 렌더링되지 않습니다.

## 슬라이드 전환

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()`는 그 슬라이드에 대한 해결 전환을 반환합니다. 방향을 지원하는 전환 유형 만 구성 방향을 보존합니다.

각 활주에 동일한 효력을 적용하기 위하여, 모든 활주를 위한 1개의 전환을 놓으십시오:

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

`slide.setTransition(undefined)`를 호출하여 단일 슬라이드에서 전환 설정을 취소합니다. 재생은 [발표 모드](/guides/slides/features/core/presentation-mode)에 설명 된 해결 전환을 사용합니다.
