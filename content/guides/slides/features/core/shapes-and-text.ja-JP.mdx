---
title: 図形とテキスト
---

Slides は共有 Shape エンジンを使って、編集可能な図形、コネクタ、図形内テキストを提供します。`FSlide.insertShape()` は Slides のコマンドパイプラインに接続された Shape Facade を返します。

## 図形を挿入する

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const shape = slide.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 64, width: 320, height: 120 },
  visible: true,
  selectable: true,
  shapeData: {
    fill: {
      fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
      color: '#dbeafe',
    },
  },
})
```

Shape ホストアダプターが利用できない場合や入力を作成できない場合、`insertShape()` は `null` を返します。図形を挿入する前に Slides 構成の Shape 依存関係を登録してください。

## リッチテキストを追加する

```ts
if (shape) {
  const richText = univerAPI.newRichText()
    .text('Quarterly ')
    .bold('review')

  shape.getText()
    .setRichText(richText)
    .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
    .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
}
```

図形の取得には `slide.getShape(id)` または `slide.getShapes()` を使用します。共通要素メソッドで位置、サイズ、表示、名前、説明を更新でき、`slide.deleteElement(shape)` で削除できます。
