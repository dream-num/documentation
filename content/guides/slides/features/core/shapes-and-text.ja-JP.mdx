---
title: 図形とテキスト
---

スライドは、共有型エンジンで編集可能な形状、コネクタ、および形状のテキストを描画します。 `FSlide.insertShape()`は、形状ファサードを返し、すべての操作は、スライドコマンドパイプラインを通過します。

## テキストの結合に使うフォントの設定 [#merge-shape-font-configuration]

`UniverSlidesUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `mergeShapeFontResolver` | `(font: string, unitId: string, text: string) => ArrayBuffer \| Promise<ArrayBuffer \| undefined> \| undefined` |  | 描画に使用した正確なフォントデータを返します。 |

Slides UI プラグインは、既にロードされているサポートされた Web フォントを読み込みます。アプリケーションが独自のフォントをロードする場合、設定します。 `mergeShapeFontResolver(font, unitId, text)` サインイン `UniverSlidesUIPlugin`. 使用される厳密な表面のバイトを、重量、様式およびフォールバックと既に一致した、として戻して下さい `ArrayBuffer` または約束。 戻り `undefined` 正確な顔が利用できなくなったとき。

## 図形を挿入する

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const shape = slide.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 64, width: 320, height: 120 },
  visible: true,
  selectable: true,
  shapeData: {
    fill: {
      fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
      color: '#dbeafe',
    },
  },
})
```

`insertShape()`は、Shapeホストアダプタが利用できなくなったり、入力が作成できないときに`null`を返します。 図形を差し込む前に、Slidesの設定で必要な形状の依存関係を登録します。

## リッチテキストを追加する

```ts
if (shape) {
  const richText = univerAPI.newRichText()
    .text('Quarterly ')
    .bold('review')

  shape.getText()
    .setRichText(richText)
    .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
    .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
}
```

形状ファサードは、`slide.getShape(id)` または `slide.getShapes()`. から利用できます。一般的な要素メソッドは、位置、サイズ、可視性、名前、説明を設定し、`slide.deleteElement(shape)`は形状を削除します。

## 図形のテキストを編集する

次の例では、`insertShape()` が以前の返した形状オブジェクトを使用します。 `getText()`は、ライブ [FShapeText(ファシェプテキスト)](/reference/facade/shape-text)ハンドルを返します。 `getPlainText()`でプレーンテキストを読み、`setText()`とすべてのものを交換し、フォント、色、アライメントメソッドを通してフォーマットを適用します。

```ts
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()`は既存のテキストを置き換えます。 `setRichText()`を1つの形状にすると、複数のテキストスタイルが必要です。 既存のリッチテキストを変更するには、`getRichText()?.copy()`を呼び出すと、ビルダーを編集し、`setRichText()`に渡します。 分離されたビルダーを編集しても、変更バックは書きません。 その他のオプションは、[テキストスタイル](/reference/facade/shape-text#settextstyle)と[テキスト ボックスのパディングとレイアウト](/reference/facade/shape-text#settextboxoptions)で記述されています。

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## 図形の書式コピー [#format-painter]

ソースの形状を選択し、フォーマットの画家をアクティブにし、ターゲットの形状を選択します。画家は、塗りつぶし、ストローク、エフェクト、およびサポートされているテキストのフォーマットをコピーし、対象のアイデンティティ、幾何学、テキストコンテンツ、および式結合を変更しません。 クリアフォーマットは、インサートからデフォルトを復元します。 SmartArtは除外されます。 マッチング形状のUIプラグインは、この動作を自動的に登録します。

## 図形の結合 [#merge-shapes]

同じスライドで2〜10のサポートされているオブジェクトを選択し、**マージ形状**を使用します。 操作は`union`(すべての領域)、`combine` (オーバーラップを除く)、`intersect`、(共有領域)、 `subtract`です(プライマリオブジェクトから他のオブジェクトを削除)、および`fragment`は(領域に分割)。 フォーマットは、プライマリオブジェクトからの来ます。 オブジェクトをマージし、選択されたオブジェクトを交換し、コラボレーションを交換します。

次のコマンドは、現在の選択で動作します。`merged`は、選択または操作が適用できない場合、`false`です。オブジェクトは編集可能で、同じグループスコープ内で動作します。コネクタ、SmartArt、OLEオブジェクト、チャート、およびテーブルは、オペランドをマージすることができません。また、いくつかのエフェクト、アニメーション、および複雑なテキストレイアウトは、マージを防ぎます。

合併するテキストボックスは、輪郭に変換され、テキストはテキストとして後で編集することはできません。 フォントが読み込まれることができない場合は、マージストップと元の形状は変更されません。 [フォント構成](#merge-shape-font-configuration)を参照してください。

```ts
import { MergeSlideShapesCommand } from '@univerjs-pro/slides-ui'

const merged = await univerAPI.executeCommand(MergeSlideShapesCommand.id, {
  operation: 'union',
})
```
