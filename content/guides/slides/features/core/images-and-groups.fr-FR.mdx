---
title: Images et groupes
---

Les images sont des éléments de diapositive à part entière. Utilisez l’assistant asynchrone pour une URL ou un blob, ou le builder lorsque toutes les propriétés sont connues.

## Insérer une image

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const image = await slide.insertImageAsync(
  'https://example.com/assets/diagram.png',
  {
    imageSourceType: univerAPI.Enum.ImageSourceType.URL,
    left: 80,
    top: 120,
    width: 320,
    height: 180,
  }
)
```

`getImages()` renvoie les images de la diapositive active. Utilisez `setSource()`, `setCrop()`, `setClipShape()` ou `toBuilder()` pour modifier une image, et `removeImage()` pour la supprimer.

## Grouper des éléments

```ts
const shape = slide.getShapes()[0]

if (shape) {
  const group = slide.group([shape, image])
  const children = group.getChildren()

  // Replacez les enfants sur la diapositive.
  slide.ungroup(group)
}
```

Les groupes conservent l’ordre des enfants et proposent les mêmes méthodes de transformation, visibilité, nom et description. `getGroups()` énumère les groupes de premier niveau.
