---
title: Images et groupes
---

Les images sont des éléments de diapositives de première classe. Utilisez l'aide asynchrone pour une URL ou un blob, ou utilisez le constructeur lorsque toutes les propriétés de l'image sont déjà connues.

## Insérer une image

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const image = await slide.insertImageAsync(
  'https://example.com/assets/diagram.png',
  {
    imageSourceType: univerAPI.Enum.ImageSourceType.URL,
    left: 80,
    top: 120,
    width: 320,
    height: 180,
  }
)
```

`getImages()` liste les images sur la diapositive actuelle. Utilisez `setSource()`, `setCrop()`, `setClipShape()` ou `toBuilder()` pour mettre à jour une image existante, et utilisez `removeImage()` pour la supprimer.

## Grouper des éléments

```ts
const shape = slide.getShapes()[0]

if (shape) {
  const group = slide.group([shape, image])
  const children = group.getChildren()

  // Replacez les enfants sur la diapositive.
  slide.ungroup(group)
}
```

Un groupe préserve l'ordre des enfants et fournit les mêmes méthodes de transformation, de visibilité, de nom et de description que les autres éléments de page. `getGroups()` liste les groupes de haut niveau sur une diapositive.
