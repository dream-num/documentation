---
title: Univer Slides API
---

Фасад слайдов добавляет объекты представления и слайда в `FUniver`. Импортируйте вход с побочным эффектом перед созданием объекта API:

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Создание и поиск презентаций

```ts
const presentation = univerAPI.createPresentation({
  id: 'quarterly-review',
  name: 'Quarterly review',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

`createPresentation()` принимает частичный снимок `ISlideData`. Чтобы восстановить ранее сохраненную презентацию, передайте снимок, возвращенный `save()`

## Работа с Unit презентации

`FPresentation` раскрывает идентификатор устройства, имя, размер страницы, слайды, активный слайд, переходы, разрешения и отдельный снимок:

```ts
presentation.setName('FY 2027 review')

const opening = presentation.getSlideByIndex(0) ?? presentation.appendSlide({
  name: 'Opening',
})

presentation.setActiveSlide(opening)
const snapshot = presentation.save()
```

Не мутируйте `snapshot` для обновления запущенной презентации. Используйте методы или команды Facade, чтобы рендеринг и история отмены оставались синхронизированными.

## Работа со слайдом

Используйте `FSlide` для работы с фоном, заметками динамика, переходом и элементами слайда:

```ts
const slide = presentation.getActiveSlide()

if (slide) {
  const elements = slide.getElements()
  const notes = slide.getSpeakerNotes()
}
```

Для конкретных операций см. [Слайды и слайды](/guides/slides/features/core/slides-and-layouts), [Форма и текст](/guides/slides/features/core/shapes-and-text) и [Изображения и группы](/guides/slides/features/core/images-and-groups).

## Определение цели команды

Параметры командных событий могут нести идентификатор представления и идентификатор слайда. Решите их из параметров вместо того, чтобы полагаться на текущий выбор:

```ts
const listener = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ params }) => {
    const target = univerAPI.getSlideCommandTarget(params)
    console.log(target?.presentation.getId(), target?.slide.getId())
  }
)
```

Утилизируйте слушателя, когда компонент, которым он владеет, удаляется.

## Выгрузка презентации

Выгрузите блок Slides по ID, когда он больше не нужен. Удалите экземпляр root `univer` только тогда, когда все приложение разрушается.

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  univerAPI.disposeUnit(presentation.getId())
}
```
