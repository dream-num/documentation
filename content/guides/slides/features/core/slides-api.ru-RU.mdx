---
title: Univer Slides API
---

Facade Slides добавляет объекты презентации и слайда в `FUniver`. Импортируйте модуль с побочным эффектом до создания объекта API:

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Создание и поиск презентаций

```ts
const presentation = univerAPI.createPresentation({
  id: 'quarterly-review',
  name: 'Quarterly review',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

`createPresentation()` принимает частичный снимок `ISlideData`. Передайте снимок из `save()`, чтобы восстановить презентацию.

## Работа с Unit презентации

`FPresentation` предоставляет идентификатор, имя, размер страницы, слайды, активный слайд, переходы, права и отделённый снимок:

```ts
presentation.setName('FY 2027 review')

const opening = presentation.getSlideByIndex(0) ?? presentation.appendSlide({
  name: 'Opening',
})

presentation.setActiveSlide(opening)
const snapshot = presentation.save()
```

Не изменяйте `snapshot`, чтобы обновить работающую презентацию. Используйте методы Facade или команды, чтобы синхронизировать отрисовку и историю.

## Работа со слайдом

`FSlide` служит точкой входа к фону, заметкам докладчика, переходу и элементам слайда:

```ts
const slide = presentation.getActiveSlide()

if (slide) {
  const elements = slide.getElements()
  const notes = slide.getSpeakerNotes()
}
```

Подробнее см. [Слайды и макеты](/guides/slides/features/core/slides-and-layouts), [Фигуры и текст](/guides/slides/features/core/shapes-and-text) и [Изображения и группы](/guides/slides/features/core/images-and-groups).

## Определение цели команды

Параметры события команды могут содержать идентификаторы презентации и слайда. Определите цель без зависимости от текущего выделения:

```ts
const listener = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ params }) => {
    const target = univerAPI.getSlideCommandTarget(params)
    console.log(target?.presentation.getId(), target?.slide.getId())
  }
)
```

Удалите слушатель вместе с его компонентом-хозяином.

## Выгрузка презентации

Выгрузите ненужный модуль Slides по его идентификатору. Корневой экземпляр `univer` следует освобождать только при уничтожении всего приложения.

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  univerAPI.disposeUnit(presentation.getId())
}
```
