---
title: Режим презентации
---

`UniverSlidesUIPlugin` регистрирует воспроизведение текущей презентации. Оно следует порядку слайдов, пропускает отмеченные слайды и применяет рассчитанный переход при каждом перемещении.

## Запуск воспроизведения

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  await univerAPI.executeCommand('slide.operation.presentation.start', {
    unitId: presentation.getId(),
    fromBeginning: true,
  })
}
```

Укажите `fromBeginning: false`, чтобы начать с активного слайда, или передайте `startSlideId` для конкретного видимого слайда.

## Навигация и остановка

```ts
await univerAPI.executeCommand('slide.operation.presentation.next')
await univerAPI.executeCommand('slide.operation.presentation.previous')

await univerAPI.executeCommand('slide.operation.presentation.go-to-slide', {
  slideId: 'summary-slide',
})

await univerAPI.executeCommand('slide.operation.presentation.stop')
```

Переход вперёд после последнего видимого слайда останавливает воспроизведение. Переход назад на первом слайде возвращает `false`.

## Поведение браузера

Полноэкранный и двухэкранный режимы зависят от API браузера. Открывайте окно аудитории непосредственно из действия пользователя, чтобы его не заблокировали. Интерфейс только для просмотра также может воспроизводить презентацию, если UI-плагин зарегистрирован с отключённым редактированием.
