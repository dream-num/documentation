---
title: Режим презентации
---

`UniverSlidesUIPlugin` добавляет воспроизведение презентации к текущей колоде. Воспроизведение перемещается по слайдам в порядке, пропускает любой слайд, отмеченный как пропущенный, и применяет разрешенный переход для каждого хода.

## Запуск воспроизведения

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  await univerAPI.executeCommand('slide.operation.presentation.start', {
    unitId: presentation.getId(),
    fromBeginning: true,
  })
}
```

Перейдите `fromBeginning: false`, чтобы начать с текущего активного слайда, или перейдите `startSlideId` для указания видимого слайдов в качестве отправной точки.

## Навигация и остановка

```ts
await univerAPI.executeCommand('slide.operation.presentation.next')
await univerAPI.executeCommand('slide.operation.presentation.previous')

await univerAPI.executeCommand('slide.operation.presentation.go-to-slide', {
  slideId: 'summary-slide',
})

await univerAPI.executeCommand('slide.operation.presentation.stop')
```

Вызов следующей команды на последнем видимом слайде останавливает воспроизведение.Предыдущая команда возвращает `false` на первом слайде.

## Поведение браузера

Полноэкранные и двухэкранные команды представления зависят от API-интерфейсов браузера. Окно аудитории должно быть открыто непосредственно в жесте пользователя; в противном случае всплывающий блокатор отклоняет его. Пользовательский интерфейс Slides все еще может запускать режим презентации, когда плагин пользовательского интерфейса зарегистрирован с отключенным редактированием.
