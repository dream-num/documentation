---
title: 画像とグループ
---

イメージは一流のスライド要素です。非同期ヘルパーを URL や blob に使用したり、すべてのイメージプロパティが既に知られているときにビルダーを使用します。

## 画像を挿入する

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const image = await slide.insertImageAsync(
  'https://example.com/assets/diagram.png',
  {
    imageSourceType: univerAPI.Enum.ImageSourceType.URL,
    left: 80,
    top: 120,
    width: 320,
    height: 180,
  }
)
```

`getImages()`は、現在のスライド上の画像を表示します。 `setSource()`、`setCrop()`、`setClipShape()`, `toBuilder()`を使用して、既存の画像を更新し、`removeImage()`を使って削除します。

## 要素をグループ化する

```ts
const shape = slide.getShapes()[0]

if (shape) {
  const group = slide.group([shape, image])
  const children = group.getChildren()

  // 子要素をスライドに戻します。
  slide.ungroup(group)
}
```

グループは、子供の注文を保存し、他のページ要素と同じ変換、可視性、名前、および説明メソッドを提供します。 `getGroups()`は、スライド上のトップレベルのグループをリストします。
