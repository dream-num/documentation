---
title: Univer Slides API
---

Slides Facade は、プレゼンテーションとスライドオブジェクトを `FUniver` に追加します。 API オブジェクトを作成する前に、副作用のエントリをインポートします。

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/slides/facade'

const univerAPI = FUniver.newAPI(univer)
```

## プレゼンテーションを作成・取得する

```ts
const presentation = univerAPI.createPresentation({
  id: 'quarterly-review',
  name: 'Quarterly review',
})

const activePresentation = univerAPI.getActivePresentation()
const samePresentation = univerAPI.getPresentation(presentation.getId())
```

`createPresentation()`は部分的な`ISlideData`のスナップショットを受け入れます。 以前に保存されたプレゼンテーションを復元するには、`save()`によって返されたスナップショットを渡します。

## プレゼンテーション Unit を操作する

`FPresentation`は、ユニットのアイデンティティ、名前、ページサイズ、スライド、アクティブスライド、トランジション、パーミッション、および分離されたスナップショットを露出します。

```ts
presentation.setName('FY 2027 review')

const opening = presentation.getSlideByIndex(0) ?? presentation.appendSlide({
  name: 'Opening',
})

presentation.setActiveSlide(opening)
const snapshot = presentation.save()
```

`snapshot`をミュートし、実行中のプレゼンテーションを更新しないでください。 レンダリングとundoの履歴が同期されるように、ファサードメソッドまたはコマンドを使用します。

## スライドを操作する

`FSlide` を使用して、スライドの背景、スピーカーのノート、移行、および要素を操作します。

```ts
const slide = presentation.getActiveSlide()

if (slide) {
  const elements = slide.getElements()
  const notes = slide.getSpeakerNotes()
}
```

特定の操作については、[スライドとレイアウト](/guides/slides/features/core/slides-and-layouts)、[形状とテキスト](/guides/slides/features/core/shapes-and-text)および[画像とグループ](/guides/slides/features/core/images-and-groups)を参照してください。

## コマンドの対象を解決する

コマンドイベントパラメータは、プレゼンテーション識別子とスライド識別子を運ぶことができます。現在の選択に依存する代わりに、パラメータからそれらを解決します。

```ts
const listener = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ params }) => {
    const target = univerAPI.getSlideCommandTarget(params)
    console.log(target?.presentation.getId(), target?.slide.getId())
  }
)
```

削除したコンポーネントを保有する時にリスナーを消します。

## プレゼンテーションをアンロードする

不要になったときに、IDでスライドユニットをアンロードします。アプリケーション全体が破壊される場合にのみ、root `univer`インスタンスをディスポースします。

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  univerAPI.disposeUnit(presentation.getId())
}
```
