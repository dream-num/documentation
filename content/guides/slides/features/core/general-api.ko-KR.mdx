---
title: 일반 API
---

루트 Facade API는 응용 프로그램 등록자 인 슬라이드 플러그인과 공통 Univer 실행 시간을 결합합니다. 이 페이지는 명령, 이벤트, 역사 및 단위 수명주기를 커버하고 다른 Univer 문서 유형과 경험을 가정하지 않습니다. 프리젠 테이션 개체의 경우 [Univer 슬라이드 API](/guides/slides/features/core/slides-api)를 참조하십시오.

## API 객체 만들기

Univer 인스턴스 이후 단일 `FUniver` 래퍼를 만들고 필요한 플러그인이 등록되어 있습니다.

```ts
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

Facade 항목이 호출하기 전에 가져온 슬라이드 방법 같은 개체에 추가.

## 명령

`executeCommand()`는 비동기적으로 등록 된 명령을 실행합니다. 명령이 비동기 실행을 명시적으로 지원할 때 `syncExecuteCommand()` 만 사용하십시오. 일반적인 슬라이드 작업의 경우 Facade 방법을 선호합니다.

## 이벤트

```ts
const commandLog = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ id }) => console.log('Executed:', id)
)

// 더 이상 필요하지 않은 리스너를 제거합니다.
commandLog.dispose()
```

`BeforeCommandExecute`를 사용하려면 응용 프로그램을 검사하거나 명령을 취소해야합니다. 편집기가 `Rendered` 및 `Steady`와 같은 단계를 입력 할 때 `LifeCycleChanged` 화재.

## 실행 취소와 다시 실행

집중된 Univer 단위에 대한 Undo와 redo 행위 및 반환 약속:

```ts
await univerAPI.undo()
await univerAPI.redo()
```

슬라이드 Facade mutations는 명령 파이프라인을 통과하므로 지원된 변경은 동일한 역사를 입력합니다.

## 시스템 클립보드

`UniverSlidesUIPlugin`가 등록되고 슬라이드 캔버스는 초점이 있습니다. `copy()`는 현재 선택과 `paste()` 삽입 클립 보드 콘텐츠를 슬라이드 UI 명령을 통해 복사합니다.

```ts
import '@univerjs/ui/facade'

await univerAPI.copy()
await univerAPI.paste()
```

캔버스 컨텍스트 메뉴는 일반 페이스트를 지원하며 텍스트로 붙여넣고 이미지로 붙여 넣습니다. 텍스트 모드는 클립보드 텍스트에서 편집 가능한 텍스트 박스를 만듭니다. 이미지 모드는 클립 보드 HTML의 이미지 파일 또는 이미지 리소스를 사용합니다. 이미지로 임의 콘텐츠를 변환하지 않습니다.

형태 또는 테이블에 텍스트를 편집하는 동안 편집기는 **소스 형식을 유지**, **일치 대상 형식** 및 **본문 바로가기**를 붙여넣기 후 형식 메뉴와 함께 제공합니다.

이 작업은 집중된 브라우저 편집기와 클립 보드 권한을 필요로하므로 모델 전용 Node.js 실행 시간에서 사용할 수 없습니다. 브라우저 블록 클립 보드가 읽기가면 시스템 풀 단축키를 사용하십시오.

## UI

UI Facade는 메시지, 열린 대화 상자 또는 사이드 바를 표시하고 구성 요소를 등록하고 내장 UI 부품을 제어합니다.

```ts
univerAPI
  .showMessage({ content: 'Presentation saved', type: 'success' })
  .setUIVisible(univerAPI.Enum.BuiltInUIPart.TOOLBAR, true)
```

이 방법은 `UniverUIPlugin`가 필요합니다. 슬라이드 편집 컨트롤은 `UniverSlidesUIPlugin`도 필요합니다.

## WebSocket

WebSocket 지원은 Network Facade에 의해 선택되고 제공됩니다:

```ts
import { UniverNetworkPlugin } from '@univerjs/network'

import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)

const socket = univerAPI.createSocket('wss://example.com/slides')
socket.open$.subscribe(() => socket.send('ready'))
```

메시지 프로토콜, 인증, 재연결 및 협업 충돌 처리는 호스트 애플리케이션의 책임에 남아 있습니다.

## 열거형

`univerAPI.Enum`는 일반적인 런타임 enums 및 슬라이드가 추가되는 enums를 노출시킵니다.

```ts
const lifecycle = univerAPI.Enum.LifecycleStages.Steady
const transition = univerAPI.Enum.SlideTransitionTypeEnum.Fade
const elementType = univerAPI.Enum.SlidePageElementTypeEnum.Shape
```

## 유틸리티

`univerAPI.Util`는 번호 포맷, 정각 작업 및 일반 도구와 같은 공유 헬퍼를 제공합니다:

```ts
const payload = univerAPI.Util.tools.deepClone({
  slideId: 'slide-1',
  selectedElementIds: ['element-1'],
})
```
