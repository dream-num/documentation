---
title: Слайды и макеты
---

`FPresentation` управляет порядком слайдов и размером страницы, общим для всей колоды. `FSlide` обеспечивает разрешенную компоновку и фон одного слайда.

## Управление порядком

```ts
const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const agenda = presentation.appendSlide({ name: 'Agenda' })
const summary = presentation.insertSlide(1, { name: 'Summary' })

presentation.moveSlide(summary, 0)
presentation.setActiveSlide(agenda)
```

Текущий порядок можно прочитать с помощью `getSlides()`, `getSlideById()` или `getSlideByIndex()`. `deleteSlide()` удаляет слайд через командный конвейер.

## Настройка размера страницы

```ts
presentation.setPageSize({
  preset: univerAPI.Enum.SlidePageSizePresetEnum.WideScreen16By9,
})
```

`slide.getPageLayout()` возвращает разрешенный размер страницы вместе с границами и порядком каждого элемента. Координаты используют систему координат модели Слайдов.

## Настройка фона

```ts
agenda.setBackground({
  type: univerAPI.Enum.SlideBackgroundTypeEnum.Solid,
  color: '#1d4ed8',
})
```

Передайте `undefined`, чтобы удалить явно заданный фон слайда. `setShowMasterBackground(false)` скрывает основную фоновую графику, унаследованную этим слайдом; он не удаляет их из снимка презентации.
