---
title: Слайды и макеты
---

`FPresentation` управляет порядком слайдов и общим размером страницы. `FSlide` предоставляет рассчитанный макет страницы и фон отдельного слайда.

## Управление порядком

```ts
const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const agenda = presentation.appendSlide({ name: 'Agenda' })
const summary = presentation.insertSlide(1, { name: 'Summary' })

presentation.moveSlide(summary, 0)
presentation.setActiveSlide(agenda)
```

Текущий порядок можно прочитать через `getSlides()`, `getSlideById()` и `getSlideByIndex()`. `deleteSlide()` удаляет слайд через командный конвейер.

## Настройка размера страницы

```ts
presentation.setPageSize({
  preset: univerAPI.Enum.SlidePageSizePresetEnum.WideScreen16By9,
})
```

`slide.getPageLayout()` возвращает рассчитанный размер, границы и порядок элементов. Координаты относятся к системе координат модели Slides.

## Настройка фона

```ts
agenda.setBackground({
  type: univerAPI.Enum.SlideBackgroundTypeEnum.Solid,
  color: '#1d4ed8',
})
```

Передайте `undefined`, чтобы убрать собственный фон. `setShowMasterBackground(false)` скрывает унаследованную графику мастера на этом слайде, не удаляя её из снимка.
