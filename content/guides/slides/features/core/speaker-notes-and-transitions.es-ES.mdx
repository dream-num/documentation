---
title: Notas del presentador y transiciones
---

Las notas y las transiciones se guardan en la instantánea de Slides y se actualizan mediante comandos, por lo que permanecen sincronizadas con deshacer y rehacer.

## Notas del presentador

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

Llame a `setSpeakerNotes(undefined)` para borrar las notas. Pertenecen a una sola diapositiva y no se renderizan como elementos de página.

## Transiciones

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()` devuelve la transición resuelta para la diapositiva. La dirección solo se conserva en los tipos que la admiten.

Aplique una transición a todas las diapositivas para usar un efecto uniforme:

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

Use `slide.setTransition(undefined)` para quitar una transición específica. La reproducción consume la transición resuelta descrita en [Modo presentación](/guides/slides/features/core/presentation-mode).
