---
title: Notas del presentador y transiciones
---

Notas de altavoz y transiciones se almacenan en la instantánea de diapositivas, y se actualizan a través de comandos. Esto los mantiene sincronizados con deshacer y redo.

## Notas del presentador

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

Llame a `setSpeakerNotes(undefined)` para aclarar las notas. Una nota pertenece a una sola diapositiva y nunca se renderiza como elemento de página.

## Transiciones

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()` devuelve la transición resuelta para esa diapositiva. Sólo los tipos de transición que soportan una dirección preservan la dirección configurada.

Para aplicar el mismo efecto a cada diapositiva, establece una transición para todas las diapositivas:

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

Llame a `slide.setTransition(undefined)` para despejar una transición establecida en una sola diapositiva. Playback utiliza la transición resuelta descrita en [Modo de presentación](/guides/slides/features/core/presentation-mode).
