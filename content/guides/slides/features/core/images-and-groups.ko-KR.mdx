---
title: 이미지와 그룹
---

이미지는 일류 슬라이드 요소입니다. URL 또는 blob에 대한 비동기 헬퍼를 사용하거나 모든 이미지 속성이 이미 알려져있을 때 빌더를 사용합니다.

## 이미지 삽입

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const image = await slide.insertImageAsync(
  'https://example.com/assets/diagram.png',
  {
    imageSourceType: univerAPI.Enum.ImageSourceType.URL,
    left: 80,
    top: 120,
    width: 320,
    height: 180,
  }
)
```

`getImages()`는 현재 활주에 이미지를 목록으로 만듭니다. `setSource()`, `setCrop()`의 `setClipShape()` 또는 `toBuilder()`를 사용하여 기존 이미지를 업데이트하고 `removeImage()`을 사용하여 삭제합니다.

## 요소 그룹화

```ts
const shape = slide.getShapes()[0]

if (shape) {
  const group = slide.group([shape, image])
  const children = group.getChildren()

  // 자식 요소를 슬라이드로 되돌립니다.
  slide.ungroup(group)
}
```

그룹은 어린이 순서를 보존하고 다른 페이지 요소와 동일한 변형, 가시성, 이름 및 설명 방법을 제공합니다. `getGroups()`는 슬라이드에서 최상위 그룹을 나열합니다.
