---
title: 이미지와 그룹
---

이미지는 일급 슬라이드 요소입니다. URL이나 Blob에는 비동기 도우미를 사용하고, 모든 이미지 속성을 알고 있다면 빌더를 사용합니다.

## 이미지 삽입

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const image = await slide.insertImageAsync(
  'https://example.com/assets/diagram.png',
  {
    imageSourceType: univerAPI.Enum.ImageSourceType.URL,
    left: 80,
    top: 120,
    width: 320,
    height: 180,
  }
)
```

`getImages()`는 현재 슬라이드의 이미지를 반환합니다. 기존 이미지는 `setSource()`, `setCrop()`, `setClipShape()`, `toBuilder()`로 업데이트하고 `removeImage()`로 제거합니다.

## 요소 그룹화

```ts
const shape = slide.getShapes()[0]

if (shape) {
  const group = slide.group([shape, image])
  const children = group.getChildren()

  // 자식 요소를 슬라이드로 되돌립니다.
  slide.ungroup(group)
}
```

그룹은 자식 순서를 유지하며 다른 페이지 요소와 같은 변환, 표시 여부, 이름, 설명 메서드를 제공합니다. `getGroups()`는 최상위 그룹을 나열합니다.
