---
title: Permisos
---

Los permisos de diapositivas se aplican a través de comandos y se pueden configurar para toda la presentación, para una sola diapositiva, o para un solo elemento. Un permiso de edición en un niño nunca supera a un padre solo lectura.

## Permisos de presentación

```ts
import { UnitAction } from '@univerjs/protocol'

const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const permission = presentation.getPermission()

await permission.setPoint(UnitAction.Export, false)
await permission.setPoint(UnitAction.Print, true)

console.log(permission.getPoint(UnitAction.Print))
```

En el nivel de presentación, Editar, Copiar, Imprimir, Exportar y Comentario se puede controlar. `setReadOnly()` deshabilita la edición para toda la presentación, y `setEditable()` la habilita de nuevo.

## Permisos de diapositiva y elemento

```ts
const slide = presentation.getSlideByIndex(0)
const element = slide?.getElements()[0]

if (slide && element) {
  await slide.getPermission().setEditable(false)
  await slide.getElementPermission(element.getId()).setEditable(true)

  console.log(slide.getElementPermission(element.getId()).canEdit())
}
```

El resultado final `canEdit()` aplica el límite máximo de permiso de los tres niveles: la presentación, la diapositiva y el elemento. Si los permisos deben persistir con la instantánea, mantenga la diapositiva y los IDs de elementos estables.
