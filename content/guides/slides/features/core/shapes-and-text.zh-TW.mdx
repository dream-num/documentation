---
title: 圖案與文字
---

Slides 使用共享的 Shape 引擎處理可編輯形狀、連線線和形狀文字。`FSlide.insertShape()` 返回一個形狀 Facade，對其執行的所有操作都透過 Slides 命令管線完成。

## 為文字合併提供字型 [#merge-shape-font-configuration]

`UniverSlidesUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `mergeShapeFontResolver` | `(font: string, unitId: string, text: string) => ArrayBuffer \| Promise<ArrayBuffer \| undefined> \| undefined` |  | 返回繪製這段文字所用的確切字型資料。 |

Slides UI 外掛可以讀取已載入的受支援 Web 字型。如果字型由應用自行載入，請在 `UniverSlidesUIPlugin` 中設定 `mergeShapeFontResolver(font, unitId, text)`。返回值應為實際使用的那一款字型的位元組資料，字重、樣式和回退均已匹配，型別可以是 `ArrayBuffer` 或 Promise。該字型不可用時，返回 `undefined`。

## 插入圖案

```ts
const slide = univerAPI.getActivePresentation()?.getActiveSlide()

if (!slide) {
  throw new Error('No active slide')
}

const shape = slide.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 64, width: 320, height: 120 },
  visible: true,
  selectable: true,
  shapeData: {
    fill: {
      fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
      color: '#dbeafe',
    },
  },
})
```

當 Shape 宿主介面卡不可用，或傳入的參數無法建立形狀時，`insertShape()` 返回 `null`。在插入形狀之前，請先註冊 Slides 配置所需的 Shape 依賴。

## 新增富文字

```ts
if (shape) {
  const richText = univerAPI.newRichText()
    .text('Quarterly ')
    .bold('review')

  shape.getText()
    .setRichText(richText)
    .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
    .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
}
```

形狀 Facade 可透過 `slide.getShape(id)` 或 `slide.getShapes()` 取得。通用的元素方法可以設定位置、尺寸、可見性、名稱和描述，`slide.deleteElement(shape)` 用於刪除形狀。

## 編輯形狀文字

下面的範例沿用前面 `insertShape()` 返回的形狀物件。`getText()` 返回一個即時的 [FShapeText](/reference/facade/shape-text) 控制代碼：用 `getPlainText()` 讀取純文字，用 `setText()` 替換全部文字，並透過字型、顏色和對齊方法設定格式。

```ts
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()` 會替換已有文字。一個形狀需要多種文字樣式時，請使用 `setRichText()`。要修改已有的富文字，請先呼叫 `getRichText()?.copy()`，修改建置器後再傳給 `setRichText()`；只修改這個脫離的建置器不會寫回任何內容。更多選項見[文字樣式](/reference/facade/shape-text#settextstyle)和[文字框內邊距與版面配置](/reference/facade/shape-text#settextboxoptions)。

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## 圖案格式刷 [#format-painter]

先選中源形狀，啟用格式刷，再選中目標形狀。格式刷會複製填充、描邊、效果和受支援的文字格式，目標的標識、幾何資訊、文字內容和公式繫結保持不變。清除格式會恢復到插入時的預設樣式。SmartArt 不參與。對應的形狀 UI 外掛會自動註冊這一行為。

## 合併圖案 [#merge-shapes]

在同一張幻燈片上選中 2–10 個受支援的物件，然後使用 **合併形狀**。支援的操作包括 `union`（全部區域）、`combine`（去掉重疊部分）、`intersect`（只保留公共區域）、`subtract`（從主物件中減去其他物件）和 `fragment`（拆分為若干區域）。格式取自主物件。合併會替換選中的物件，並支援撤銷、重做和協同。

下面的命令作用於當前選區；選區或操作無法應用時，`merged` 返回 `false`。參與合併的物件必須可編輯，並且處於同一分組範圍內。連線線、SmartArt、OLE 物件、圖表和表格不能作為合併物件，部分效果、動畫和複雜的文字排版同樣會阻止合併。

文字框參與合併後會轉換為輪廓，其中的文字不能再作為文字編輯。如果無法讀取渲染它所用的字型，合併會中止，原形狀保持不變。參見[字型配置](#merge-shape-font-configuration)。

```ts
import { MergeSlideShapesCommand } from '@univerjs-pro/slides-ui'

const merged = await univerAPI.executeCommand(MergeSlideShapesCommand.id, {
  operation: 'union',
})
```
