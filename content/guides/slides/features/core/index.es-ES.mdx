Univer El núcleo de diapositivas consiste en un modelo de presentación y el navegador de edición UI. El modelo almacena una presentación como una instantánea `ISlideData`, y la UI renderiza ese modelo y lo modifica a través de comandos Univer.

## Funciones

- El modelo de presentación mantiene la identidad de presentación, tamaño de página, orden de diapositivas, diapositivas, páginas maestras, páginas de diseño, temas, transiciones y recursos.
- Rendering y edición cubren el lienzo de diapositivas, miniaturas, selección, portapapeles, edición de texto y forma, guías de alineación y reproducción de presentación.
- Los cambios en las páginas y elementos se aplican a través de comandos y mutaciones, por lo que las actualizaciones de modelos, renderizado y deshacer y redo permanecer sincronizado.
- El Facade API crea y localiza presentaciones, guarda instantáneas, y expone las operaciones de diapositivas y elementos como objetos que la aplicación puede llamar.
- Características opcionales como tablas, gráficos, impresión e importación/export permanecen fuera de la pila de núcleo como plugins.

## Modo plugin

### Instalación

```package-install
npm install @univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/slides @univerjs-pro/slides-ui
```

### Uso

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
import SlidesUIEnUS from '@univerjs-pro/slides-ui/locale/en-US'
import SlidesEnUS from '@univerjs-pro/slides/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
import { UniverDrawingPlugin } from '@univerjs/drawing'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/slides/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'
import '@univerjs-pro/slides-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, DocsUIEnUS, SlidesEnUS, SlidesUIEnUS),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const presentation = univerAPI.createPresentation({ name: 'Quarterly review' })
```

#### `UniverSlidesUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | Activa la interfaz de edición. Usa `false` para solo lectura. |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | Activa la interfaz de edición. Usa `false` para solo lectura. |

Para realizar una presentación sin controles de edición, configure `UniverSlidesUIPlugin` a `{ editor: { enabled: false } }`. En un proceso Node.js, registre `UniverSlidesPlugin` sin el plugin UI.

Establecer `menu` y `ribbonType` en el registro `UniverUIPlugin` existente. Ambos son opciones UI compartidas y no pertenecen a `UniverSlidesUIPlugin`. El siguiente ejemplo utiliza IDs de menú de diapositivas:

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'slide.menu.insert.text': {
    order: 1,
    gridLayout: { row: 1, column: 2, rowSpan: 2, showLabel: true, width: 96 },
  },
  'slide.menu.insert.shape': {
    order: 0,
    gridLayout: { row: 1, column: 1, rowSpan: 2, showLabel: true },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order` clasifica fichas de hermano, grupos o elementos de menú en orden ascendente. No mueve un elemento en otro grupo. Utilice el ID de elemento de menú real, que está disponible desde el atributo `data-u-command`, en lugar de asumir que coincide con el ID de comando.

## Modo preestablecido

Univer Slides no proporciona un paquete preestablecido todavía. Use Plugin Mode para ejecutar el modelo solo y para construir el editor del navegador.

## Organización de la cinta [#ribbon-controls]

La pestaña Inicio contiene el tema, la transición, el fondo y los controles de notas de altavoces. La pestaña Insertar recoge la inserción de contenido y la lista de objetos. La pestaña Ver proporciona tamaño de página, zoom y pantalla completa. La pestaña formato contextual sigue la selección: una forma seleccionada muestra el formato de forma, una imagen seleccionada muestra formato de imagen, un gráfico seleccionado muestra formato de gráficos y una selección mixta que incluye imágenes o gráficos muestra los controles de objetos comunes.

## Actualizar los menús con la API Facade [#menu-facade]

### Actualizaciones en ejecución

Importar `@univerjs/ui/facade` antes de crear `univerAPI` con `FUniver.newAPI(univer)`. [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) fusiona los cambios en la configuración existente, preserva los campos que no están especificados y actualiza los menús. Los overrides también se aplican a los menús registrados más adelante.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'slide.menu.insert.text': { gridLayout: { row: 1, column: 2, width: 120 } },
})
```

`gridLayout` afecta sólo la cinta de la cuadrícula. Cada grupo tiene dos filas, y `row` y `column` 1. Una posición explícita tiene precedencia sobre el orden visual por `order`, por lo que cuando se intercambian dos celdas ocupadas, ambos elementos deben ser actualizados. Los campos opcionales heredan la configuración o esquema existente. Spans, etiquetas, anchos y tamaños de icono pertenecen a [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout).

Mantenga la edición activada en `UniverSlidesUIPlugin`. Con `editor.enabled: false`, la cinta para este producto nunca se registra, y los overrides del menú no pueden añadir los botones faltantes.

Los botones personalizados y los disparadores submenú siguen las mismas reglas. [`createMenu()` y `createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem) también acepta `order` y `gridLayout`, y `appendTo()` los registra. Los contenidos del popup no utilizan el diseño de la rejilla de la cinta.

## Confirmar el texto antes de guardar [#commit-text-before-saving]

Cuando `@univerjs-pro/slides-ui/facade` está cargado, una barra de herramientas personalizada o diálogo debe llamar `await presentation.endTextEditingAsync()` antes de guardar una instantánea. Ahorre sólo después de la llamada se resuelve a `true`. Un valor de retorno de `false` significa que el borrador no puede ser cometido o que la composición de IME todavía está en progreso.
