El núcleo de Univer Slides combina un modelo de presentación con la interfaz de edición del navegador. El modelo guarda la presentación como una instantánea `ISlideData`, mientras que la interfaz la renderiza y edita mediante comandos de Univer.

## Funciones

- **Modelo de presentación**: administra la identidad, el tamaño de página, el orden de las diapositivas, las diapositivas, los patrones, los diseños, los temas, las transiciones y los recursos.
- **Renderizado y edición**: ofrece el lienzo, las miniaturas, la selección, el portapapeles, la edición de texto y formas, las guías de alineación y la presentación de diapositivas.
- **Canal de comandos**: aplica los cambios de páginas y elementos mediante comandos y mutaciones para sincronizar el modelo, el renderizado, deshacer y rehacer.
- **Facade API**: crea, busca y guarda presentaciones, y expone objetos orientados a la aplicación para trabajar con diapositivas y elementos.
- **Arquitectura de plugins**: mantiene fuera del núcleo las funciones opcionales, como tablas, gráficos, impresión e importación y exportación.

## Modo plugin

### Instalación

```package-install
npm install @univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/slides @univerjs-pro/slides-ui
```

### Uso

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverSlidesPlugin } from '@univerjs-pro/slides'
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'
import SlidesUIEnUS from '@univerjs-pro/slides-ui/locale/en-US'
import SlidesEnUS from '@univerjs-pro/slides/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
import { UniverDrawingPlugin } from '@univerjs/drawing'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/slides/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'
import '@univerjs-pro/slides-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, DocsUIEnUS, SlidesEnUS, SlidesUIEnUS),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const presentation = univerAPI.createPresentation({ name: 'Quarterly review' })
```

### Configuración de plugins [#plugin-configuration]

`UniverLicensePlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenido del archivo de licencia del cliente. |

#### `UniverSlidesUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | Activa la interfaz de edición. Usa `false` para solo lectura. |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | Activa la interfaz de edición. Usa `false` para solo lectura. |

Para renderizar una presentación sin controles de edición, pasa `{ editor: { enabled: false } }` a `UniverSlidesUIPlugin`. En Node.js, registra únicamente `UniverSlidesPlugin`, sin el plugin de interfaz.

#### Orden de menús y disposición en cuadrícula [#menu-order-and-grid-layout]

`UniverUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Elemento DOM donde se monta el editor, o su ID. |

| <ConfigKey depth={1}>[id]</ConfigKey> | `object` |  | Ajuste para un elemento del menú, pestaña o grupo de la cinta. |
| <ConfigKey depth={2}>order</ConfigKey> | `number` |  | Orden entre elementos del mismo nivel. Los valores menores van primero. |
| <ConfigKey depth={2}>hidden</ConfigKey> | `boolean` |  | Oculta el elemento. |
| <ConfigKey depth={2}>disabled</ConfigKey> | `boolean` |  | Deshabilita el elemento. |
| <ConfigKey depth={2}>activated</ConfigKey> | `boolean` |  | Muestra el elemento como activo. |
| <ConfigKey depth={2}>title</ConfigKey> | `string` |  | Título o clave de traducción. |
| <ConfigKey depth={2}>tooltip</ConfigKey> | `string` |  | Texto emergente o clave de traducción. |
| <ConfigKey depth={2}>icon</ConfigKey> | `string \| Observable<string>` |  | Nombre del icono, también disponible mediante un Observable. |
| <ConfigKey depth={2}>type</ConfigKey> | `MenuItemType` |  | Botón, selector, botón con selector o submenú. |
| <ConfigKey depth={2}>commandId</ConfigKey> | `string` |  | Comando que ejecuta el elemento. |
| <ConfigKey depth={2}>description</ConfigKey> | `string` |  | Descripción del elemento. |
| <ConfigKey depth={2}>slot</ConfigKey> | `boolean` |  | Reserva un espacio para la representación personalizada. |
| <ConfigKey depth={2}>label</ConfigKey> | `string \| object` |  | Etiqueta o componente de etiqueta personalizado. |
| <ConfigKey depth={2}>params</ConfigKey> | `Record<string, unknown> \| (() => Record<string, unknown> \| undefined)` |  | Parámetros del comando o función que los proporciona. |
| <ConfigKey depth={2}>gridLayout</ConfigKey> | `object` |  | Posición en la cinta con cuadrícula. |
| <ConfigKey depth={3}>row</ConfigKey> | `1 \| 2` |  | Primera o segunda fila del grupo. |
| <ConfigKey depth={3}>column</ConfigKey> | `number` |  | Número de columna en el grupo, a partir de 1. |
| <ConfigKey depth={3}>rowSpan</ConfigKey> | `1 \| 2` | `1` | Número de filas ocupadas. |
| <ConfigKey depth={3}>columnSpan</ConfigKey> | `number` | `1` | Número de columnas ocupadas. |
| <ConfigKey depth={3}>showLabel</ConfigKey> | `boolean` | `false` | Muestra el título junto al icono. |
| <ConfigKey depth={3}>width</ConfigKey> | `number` |  | Ancho del control en píxeles. |
| <ConfigKey depth={3}>minWidth</ConfigKey> | `number` |  | Ancho mínimo en píxeles antes de mover el grupo a Más. |
| <ConfigKey depth={3}>iconSize</ConfigKey> | `number` |  | Tamaño del icono en píxeles. |
| `ribbonType` | `RibbonType` | `classic` | Selecciona el diseño de la cinta. |

Configura `menu` y `ribbonType` en el registro existente de `UniverUIPlugin`. Son opciones de la interfaz compartida, no de `UniverSlidesUIPlugin`. El ejemplo utiliza los identificadores reales de los menús de Slides:

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'slide.menu.insert.text': {
    order: 1,
    gridLayout: { row: 1, column: 2, rowSpan: 2, showLabel: true, width: 96 },
  },
  'slide.menu.insert.shape': {
    order: 0,
    gridLayout: { row: 1, column: 1, rowSpan: 2, showLabel: true },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order` ordena de menor a mayor las pestañas, grupos o elementos del mismo nivel; no mueve elementos a otro grupo. El identificador del elemento se obtiene de su atributo `data-u-command` y no tiene por qué coincidir con el de la orden.

## Modo preestablecido

Univer Slides no ofrece actualmente un paquete de preset. Utiliza el modo plugin tanto para un entorno que solo use el modelo como para el editor del navegador.

## Organización de la cinta [#ribbon-controls]

Inicio contiene tema, transición, fondo y notas; Insertar agrupa contenido y lista de objetos; Vista ofrece tamaño de página, zoom y pantalla completa. La pestaña contextual depende de la selección: formas, imágenes, gráficos o controles comunes para selecciones mixtas con imágenes o gráficos. El formato de imagen incluye recorte y forma de recorte, tamaño, posición y rotación; algunos controles requieren una sola imagen. Las tablas usan los controles del plugin UI de tablas. El formato de forma incluye un interruptor independiente para la barra flotante.

## Actualizar los menús con la API Facade [#menu-facade]

### Actualizaciones en ejecución

Importa `@univerjs/ui/facade` antes de crear `univerAPI` con `FUniver.newAPI(univer)`. [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) combina los cambios, conserva los campos no especificados y actualiza los menús. La configuración también se aplica a los menús registrados posteriormente.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'slide.menu.insert.text': { gridLayout: { row: 1, column: 2, width: 120 } },
})
```

`gridLayout` solo afecta al Ribbon en cuadrícula. Cada grupo tiene dos filas y `row` y `column` empiezan en 1. Las coordenadas explícitas determinan la posición: al intercambiar celdas ocupadas, actualiza ambos elementos y no solo `order`. Los campos opcionales omitidos conservan la configuración o el Schema existente. Consulta [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout) para los tamaños de celda, etiquetas, anchuras y tamaños de icono.

Mantén habilitada la edición en `UniverSlidesUIPlugin`: `editor.enabled: false` impide registrar el Ribbon del producto. Las modificaciones de menú no crean botones que no estén registrados.

Los botones personalizados y las entradas de submenú también aceptan `order` y `gridLayout` en [`createMenu()` y `createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem); llama a `appendTo()` para registrarlos. El contenido del menú emergente no utiliza la cuadrícula del Ribbon.

## Confirmar el texto antes de guardar [#commit-text-before-saving]

Con `@univerjs-pro/slides-ui/facade` cargado, llama a `await presentation.endTextEditingAsync()` antes de guardar una instantánea desde una barra de herramientas o un diálogo personalizado. Guarda al recibir `true`. Si devuelve `false`, no se ha podido confirmar el borrador o la composición del IME sigue en curso.
