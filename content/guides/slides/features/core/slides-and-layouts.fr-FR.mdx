---
title: Diapositives et mises en page
---

`FPresentation` gère l'ordre des diapositives et la taille de la page partagée par l'ensemble du jeu. `FSlide` fournit la mise en page et l'arrière-plan résolus d'une seule diapositive.

## Gérer l’ordre

```ts
const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const agenda = presentation.appendSlide({ name: 'Agenda' })
const summary = presentation.insertSlide(1, { name: 'Summary' })

presentation.moveSlide(summary, 0)
presentation.setActiveSlide(agenda)
```

L'ordre actuel peut être lu avec `getSlides()`, `getSlideById()` ou `getSlideByIndex()`. `deleteSlide()` supprime une diapositive dans le pipeline de commande.

## Définir la taille de page

```ts
presentation.setPageSize({
  preset: univerAPI.Enum.SlidePageSizePresetEnum.WideScreen16By9,
})
```

`slide.getPageLayout()` retourne la taille de la page résolue avec les limites et l'ordre de chaque élément. Coordonnées utiliser le système de coordonnées de modèle de diapositives.

## Définir l’arrière-plan

```ts
agenda.setBackground({
  type: univerAPI.Enum.SlideBackgroundTypeEnum.Solid,
  color: '#1d4ed8',
})
```

Passer `undefined` pour supprimer un fond de diapositive défini explicitement. `setShowMasterBackground(false)` cache les graphiques de fond maîtres hérités de cette diapositive; il ne les supprime pas de l'instantané de présentation.
