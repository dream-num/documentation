---
title: Diapositives et mises en page
---

`FPresentation` gère l’ordre des diapositives et la taille de page commune. `FSlide` expose la mise en page résolue et l’arrière-plan d’une diapositive.

## Gérer l’ordre

```ts
const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const agenda = presentation.appendSlide({ name: 'Agenda' })
const summary = presentation.insertSlide(1, { name: 'Summary' })

presentation.moveSlide(summary, 0)
presentation.setActiveSlide(agenda)
```

Utilisez `getSlides()`, `getSlideById()` et `getSlideByIndex()` pour lire l’ordre actuel. `deleteSlide()` supprime une diapositive via le pipeline de commandes.

## Définir la taille de page

```ts
presentation.setPageSize({
  preset: univerAPI.Enum.SlidePageSizePresetEnum.WideScreen16By9,
})
```

`slide.getPageLayout()` renvoie la taille résolue ainsi que les limites et l’ordre des éléments. Les coordonnées utilisent le repère du modèle Slides.

## Définir l’arrière-plan

```ts
agenda.setBackground({
  type: univerAPI.Enum.SlideBackgroundTypeEnum.Solid,
  color: '#1d4ed8',
})
```

Passez `undefined` pour retirer un arrière-plan explicite. `setShowMasterBackground(false)` masque les graphismes hérités du masque sans les supprimer de l’instantané.
