---
title: プレゼンテーションモード
---

`UniverSlidesUIPlugin`は、現在のデッキにプレゼンテーション再生を追加します。 再生バックは、順番にスライドを移動し、スキップされるようにマークされた任意のスライドをスキップし、各移動のために解決された移行を適用します。

## 再生を開始する

```ts
const presentation = univerAPI.getActivePresentation()

if (presentation) {
  await univerAPI.executeCommand('slide.operation.presentation.start', {
    unitId: presentation.getId(),
    fromBeginning: true,
  })
}
```

`fromBeginning: false` を現在のアクティブ スライドから始めるか、`startSlideId`を渡すと、開始点として表示可能なスライドを指定します。

## 移動と停止

```ts
await univerAPI.executeCommand('slide.operation.presentation.next')
await univerAPI.executeCommand('slide.operation.presentation.previous')

await univerAPI.executeCommand('slide.operation.presentation.go-to-slide', {
  slideId: 'summary-slide',
})

await univerAPI.executeCommand('slide.operation.presentation.stop')
```

最後の表示されたスライドの次のコマンドを呼び出して、再生を停止します。前のコマンドは、最初のスライドの`false`を返します。

## ブラウザー動作

フルスクリーンとデュアルスクリーンのプレゼンテーションコマンドは、ブラウザ API に依存します。 オーディエンスウィンドウは、直接ユーザージェスチャーで開く必要があります。 それ以外の場合は、ポップアップブロッカーが拒否します。 UI プラグインが編集障害者に登録されている場合、ビューアのみのスライド UI は、プレゼンテーションモードを実行できます。
