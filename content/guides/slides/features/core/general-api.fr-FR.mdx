title: API générale
---

La racine Facade API combine le runtime commun Univer avec les plugins Slides que l'application enregistre. Cette page couvre les commandes, les événements, l'historique et le cycle de vie de l'unité, et ne suppose pas l'expérience avec un autre type de document Univer. Pour les objets de présentation, voir [API de diapositives Univer](/guides/slides/features/core/slides-api).

## Créer l’objet API

Créer un seul wrapper `FUniver` après l'instance Univer et les plugins requis sont enregistrés :

```ts
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

Les entrées Facade importées avant cet appel ajoutent des méthodes Slides au même objet.

## Commandes

`executeCommand()` exécute une commande enregistrée de manière asynchrone. Utilisez `syncExecuteCommand()` uniquement lorsque la commande prend explicitement en charge l'exécution synchrone. Pour les opérations courantes de Slides, préférez les méthodes Facade.

## Événements

```ts
const commandLog = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ id }) => console.log('Executed:', id)
)

// Supprimez ensuite l’écouteur.
commandLog.dispose()
```

Écoutez `BeforeCommandExecute` lorsque l'application doit inspecter ou annuler une commande. `LifeCycleChanged` s'allume lorsque l'éditeur entre dans des étapes telles que `Rendered` et `Steady`.

## Annuler et rétablir

Défaire et refaire agir sur l'unité Univer concentrée et les promesses de retour:

```ts
await univerAPI.undo()
await univerAPI.redo()
```

Diapositives Les mutations Facade passent par le pipeline de commande, donc les changements pris en charge entrent dans la même histoire.

## Presse-papiers système

Après l'enregistrement de `UniverSlidesUIPlugin` et le focus de la toile de diapositives, `copy()` copie la sélection actuelle et `paste()` insère du contenu de presse-papiers à travers les commandes de l'interface utilisateur de diapositives.

```ts
import '@univerjs/ui/facade'

await univerAPI.copy()
await univerAPI.paste()
```

Le menu contextuel de la toile prend en charge la pâte normale, coller comme texte et coller comme image. Le mode texte crée une boîte de texte modifiable à partir du texte du presse-papier. Le mode image utilise des fichiers d'image ou des ressources d'image dans le presse-papier HTML; il ne convertit pas le contenu arbitraire en image.

Lors de l'édition du texte sous forme ou sous forme de table, l'éditeur fournit **Continuer à formater les sources**, **Correspond au formatage de destination** et **Conserver le texte seulement** avec un menu de formatage après le collage.

Ces opérations nécessitent un éditeur de navigateur ciblé et une permission de presse-papiers, de sorte qu'ils ne sont pas disponibles dans un modèle seulement Node.js runtime. Si le navigateur bloque les lectures de presse-notes, utilisez le raccourci de pâte système.

## UI

L'interface utilisateur Facade affiche des messages, ouvre des dialogues ou des barres latérales, enregistre des composants et contrôle les parties intégrées de l'interface utilisateur :

```ts
univerAPI
  .showMessage({ content: 'Presentation saved', type: 'success' })
  .setUIVisible(univerAPI.Enum.BuiltInUIPart.TOOLBAR, true)
```

Ces méthodes nécessitent `UniverUIPlugin`; les contrôles d'édition des diapositives nécessitent également `UniverSlidesUIPlugin`.

## WebSocket

Le support WebSocket est facultatif et fourni par la Façade Réseau :

```ts
import { UniverNetworkPlugin } from '@univerjs/network'

import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)

const socket = univerAPI.createSocket('wss://example.com/slides')
socket.open$.subscribe(() => socket.send('ready'))
```

Les protocoles de message, l'authentification, la reconnexion et le traitement des conflits de collaboration restent la responsabilité de l'application hôte.

## Énumérations

`univerAPI.Enum` expose les enums d'exécution courants et les enum que Slide ajoute:

```ts
const lifecycle = univerAPI.Enum.LifecycleStages.Steady
const transition = univerAPI.Enum.SlideTransitionTypeEnum.Fade
const elementType = univerAPI.Enum.SlidePageElementTypeEnum.Shape
```

## Utilitaires

`univerAPI.Util` fournit des aides partagées telles que le formatage de nombres, les opérations rectangles et les outils généraux:

```ts
const payload = univerAPI.Util.tools.deepClone({
  slideId: 'slide-1',
  selectedElementIds: ['element-1'],
})
```
