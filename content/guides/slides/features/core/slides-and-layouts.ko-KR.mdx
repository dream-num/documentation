---
title: 슬라이드와 레이아웃
---

`FPresentation`은 슬라이드 순서와 공통 페이지 크기를 관리합니다. `FSlide`는 계산된 페이지 레이아웃과 개별 슬라이드 배경을 제공합니다.

## 슬라이드 순서 관리

```ts
const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const agenda = presentation.appendSlide({ name: 'Agenda' })
const summary = presentation.insertSlide(1, { name: 'Summary' })

presentation.moveSlide(summary, 0)
presentation.setActiveSlide(agenda)
```

현재 순서는 `getSlides()`, `getSlideById()`, `getSlideByIndex()`로 읽습니다. `deleteSlide()`는 명령 파이프라인을 통해 슬라이드를 제거합니다.

## 페이지 크기 설정

```ts
presentation.setPageSize({
  preset: univerAPI.Enum.SlidePageSizePresetEnum.WideScreen16By9,
})
```

`slide.getPageLayout()`은 계산된 페이지 크기와 요소의 경계 및 순서를 반환합니다. 좌표는 Slides 모델 좌표계를 사용합니다.

## 슬라이드 배경 설정

```ts
agenda.setBackground({
  type: univerAPI.Enum.SlideBackgroundTypeEnum.Solid,
  color: '#1d4ed8',
})
```

명시적 배경을 제거하려면 `undefined`를 설정합니다. `setShowMasterBackground(false)`는 마스터 배경 그래픽을 스냅샷에서 삭제하지 않고 해당 슬라이드에서 숨깁니다.
