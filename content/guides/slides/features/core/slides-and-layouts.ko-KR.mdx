---
title: 슬라이드와 레이아웃
---

`FPresentation`는 슬라이드 순서를 관리하고 전체적인 갑판에 의해 공유된 페이지 크기. `FSlide` 단일 슬라이드의 해결된 레이아웃과 배경을 제공합니다.

## 슬라이드 순서 관리

```ts
const presentation = univerAPI.getActivePresentation()

if (!presentation) {
  throw new Error('No active presentation')
}

const agenda = presentation.appendSlide({ name: 'Agenda' })
const summary = presentation.insertSlide(1, { name: 'Summary' })

presentation.moveSlide(summary, 0)
presentation.setActiveSlide(agenda)
```

현재 순서는 `getSlides()`, `getSlideById()` 또는 `getSlideByIndex()`로 읽을 수 있습니다. `deleteSlide()`는 명령 파이프라인을 통해 활주를 제거합니다.

## 페이지 크기 설정

```ts
presentation.setPageSize({
  preset: univerAPI.Enum.SlidePageSizePresetEnum.WideScreen16By9,
})
```

`slide.getPageLayout()`는 각 요소의 경계와 순서와 함께 해결 된 페이지 크기를 반환합니다. 좌표는 슬라이드 모델 좌표 시스템을 사용합니다.

## 슬라이드 배경 설정

```ts
agenda.setBackground({
  type: univerAPI.Enum.SlideBackgroundTypeEnum.Solid,
  color: '#1d4ed8',
})
```

`undefined`를 통과하여 명시적으로 설정된 슬라이드 배경을 제거하십시오. `setShowMasterBackground(false)`는 슬라이드에 의해 상속된 마스터 배경 그래픽을 숨깁니다. 프레젠테이션 스냅 샷에서 제거하지 않습니다.
