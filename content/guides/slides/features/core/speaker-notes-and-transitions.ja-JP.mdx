---
title: 発表者ノートとトランジション
---

スピーカーのメモとトランジションは、Slidesスナップショットに保存され、コマンドによって更新されます。これにより、それらはundoとredoで同期します。

## 発表者ノート

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

`setSpeakerNotes(undefined)`を呼び出して、ノートをクリアします。ノートは単一のスライドに属し、ページ要素としてレンダリングされることはありません。

## スライドトランジション

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()`は、そのスライドに対する解決されたトランジションを返します。 方向をサポートするトランジションタイプのみが、設定された方向を保存します。

すべてのスライドに同じ効果を適用するには、すべてのスライドに1つのトランジションを設定してください。

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

`slide.setTransition(undefined)` を呼び出して、単一のスライドにセットされたトランジションをクリアします。再生バックは、[プレゼンテーションモード](/guides/slides/features/core/presentation-mode)で記述された解決されたトランジテーションを使用します。
