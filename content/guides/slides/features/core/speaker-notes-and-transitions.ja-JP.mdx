---
title: 発表者ノートとトランジション
---

発表者ノートとトランジションは Slides スナップショットに保存され、コマンドを通じて更新されるため、元に戻す／やり直すと同期します。

## 発表者ノート

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

if (slide) {
  slide.setSpeakerNotes('Emphasize the year-over-year change.')
  console.log(slide.getSpeakerNotes())
}
```

ノートを消去するには `setSpeakerNotes(undefined)` を呼び出します。ノートは一つのスライドに属し、ページ要素として描画されません。

## スライドトランジション

```ts
slide?.setTransition({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Push,
  direction: univerAPI.Enum.SlideTransitionDirectionEnum.Right,
  duration: 700,
})
```

`getTransition()` はスライドに解決されたトランジションを返します。方向は対応するトランジションタイプでのみ保持されます。

デッキ全体で同じ効果を使う場合は、すべてのスライドに適用します。

```ts
presentation?.applyTransitionToAll({
  type: univerAPI.Enum.SlideTransitionTypeEnum.Fade,
  duration: 500,
})
```

固有のトランジションを消去するには `slide.setTransition(undefined)` を呼び出します。再生は[プレゼンテーションモード](/guides/slides/features/core/presentation-mode)で説明する解決済みトランジションを使用します。
