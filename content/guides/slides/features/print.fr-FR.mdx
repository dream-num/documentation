## Enregistrer la prise en charge de l’impression

Ajoutez `@univerjs-pro/slides-print` quand un éditeur de diapositives nécessite un aperçu d'impression ou les API de façade d'impression. Le paquet fournit également des locaux sous `@univerjs-pro/slides-print/locale/*`, donc aucune importation CSS séparée n'est nécessaire.

```ts
import { UniverSlidesPrintPlugin } from '@univerjs-pro/slides-print'
import SlidesPrintEnUS from '@univerjs-pro/slides-print/locale/en-US'
import '@univerjs-pro/slides-print/facade'

univer.registerPlugin(UniverSlidesPrintPlugin)
```

## Prise en charge mobile [#mobile-support]

Configurez d'abord le [éditeur mobile](/guides/slides/getting-started/installation#mobile-support). Dans la configuration en mode plugin de cette page, remplacez les enregistrements de bureau ci-dessous par les exportations mobiles des mêmes paquets, et faites-le **avant d'ouvrir un document** . Gardez les plugins modèles, styles, locales et importations de Facade, et enregistrez une seule variante.

| Paquet | Inscription de bureau | Inscription mobile |
| --- | --- | --- |
| `@univerjs-pro/slides-print` | `UniverSlidesPrintPlugin` | `UniverSlidesPrintMobilePlugin` |

## Prérequis

Enregistrez le modèle Slides principal avant le plugin d’impression :

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
univer.registerPlugin(UniverSlidesPrintPlugin)
```

Un éditeur de navigateur nécessite également le moteur de rendu, le plugin UI, Docs, Dessin et les plugins de licence, comme indiqué dans le [Démarrage rapide](/guides/slides/getting-started/quickstart).

## API facade

Importez le point d’entrée facade pour ajouter `printSlidesAsync` à `FUniver` :

```ts
import '@univerjs-pro/slides-print/facade'
```

Imprimer chaque diapositive dans la présentation active :

```ts
const univerAPI = FUniver.newAPI(univer)

await univerAPI.printSlidesAsync()
```

Imprimer une sélection par numéro de page 1 :

```ts
await univerAPI.printSlidesAsync({
  range: [
    { from: 1, to: 3 },
    { from: 6, to: 6 },
  ],
})
```

## Remarques

Le résultat de l’impression dépend de l’instantané actuel des diapositives, du format de page, des éléments de dessin et des éventuels éléments de tableau ou de graphique. Si votre présentation peut contenir des tableaux ou des graphiques, enregistrez les plugins correspondants avant l’impression.

```ts
import { SlidePrintHandoutOrder, SlidePrintLayoutType } from '@univerjs-pro/slides-print'

univerAPI.openSlidesPrintDialog({
  layout: SlidePrintLayoutType.Handout,
  slidesPerPage: 6,
  handoutOrder: SlidePrintHandoutOrder.Horizontal,
  frameSlides: true,
  showSlideNumber: true,
})
```

Les options comprennent également les diapositives `paperSize`, `direction`, `margin` et `marginCustom`. Une fiche supporte 1, 2, 3, 4, 6 ou 9 diapositives par page.

`range` accepte des plages de pages inclusives. Si le paramètre est omis, chaque diapositive est imprimée. Les plages de chevauchement sont dé-duplicées et imprimées dans l'ordre de diapositives. Une plage qui s'étend au-delà de la fin du paquet est clipsée aux diapositives existantes, et une plage inversée est ignorée.

## Remarques

La sortie d'impression dépend de l'instantané courant de la diapositive, de la taille de la page, des notes d'enceinte, des éléments de dessin et de tout élément de table ou de graphique.
