## Enregistrer la prise en charge de l’impression

Utilisez `@univerjs-pro/slides-print` lorsqu’un éditeur Slides a besoin d’un aperçu avant impression ou des API facade liées à l’impression. Le package fournit également `@univerjs-pro/slides-print/locale/*` et ne nécessite aucun import CSS distinct.

```ts
import { UniverSlidesPrintPlugin } from '@univerjs-pro/slides-print'
import SlidesPrintEnUS from '@univerjs-pro/slides-print/locale/en-US'
import '@univerjs-pro/slides-print/facade'

univer.registerPlugin(UniverSlidesPrintPlugin)
```

## Prérequis

Enregistrez le modèle Slides principal avant le plugin d’impression :

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
univer.registerPlugin(UniverSlidesPrintPlugin)
```

Pour un éditeur dans le navigateur, conservez le moteur de rendu ainsi que les plugins UI, Docs, Drawing et de licence enregistrés comme indiqué dans le [guide de démarrage rapide](/guides/slides/getting-started/quickstart).

## API facade

Importez le point d’entrée facade pour ajouter `printSlidesAsync` à `FUniver` :

```ts
import '@univerjs-pro/slides-print/facade'
```

Imprimez toutes les diapositives de la présentation active :

```ts
const univerAPI = FUniver.newAPI(univer)

await univerAPI.printSlidesAsync()
```

Imprimez les plages de diapositives sélectionnées en utilisant des numéros de page commençant à 1 :

```ts
await univerAPI.printSlidesAsync({
  range: [
    { from: 1, to: 3 },
    { from: 6, to: 6 },
  ],
})
```

`range` accepte des plages de pages dont les bornes sont incluses. Si cette option est omise, toutes les diapositives sont imprimées. Les chevauchements entre les plages sont supprimés et les diapositives sont imprimées dans leur ordre d’origine. Les plages qui dépassent la présentation sont limitées aux diapositives disponibles, et les plages inversées non valides sont ignorées.

## Remarques

Le résultat de l’impression dépend de l’instantané actuel des diapositives, du format de page, des éléments de dessin et des éventuels éléments de tableau ou de graphique. Si votre présentation peut contenir des tableaux ou des graphiques, enregistrez les plugins correspondants avant l’impression.

## Mise en page et aperçu

```ts
univerAPI.openSlidesPrintDialog({
  layout: univerAPI.Enum.SlidePrintLayoutType.Handout,
  slidesPerPage: 6,
  handoutOrder: univerAPI.Enum.SlidePrintHandoutOrder.Horizontal,
  frameSlides: true,
  showSlideNumber: true,
})
```

Les mises en page pleine page, document et page de notes sont disponibles, avec réglages du papier, de l’orientation et des marges.
