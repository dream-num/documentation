## Register chart support

Slides chart support is split into a model package and a UI package:

```ts
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'
import { UniverSlidesChartUIPlugin } from '@univerjs-pro/slides-chart-ui'
import '@univerjs-pro/slides-chart/facade'

univer.registerPlugin(UniverSlidesChartPlugin)
univer.registerPlugin(UniverSlidesChartUIPlugin)
```

## Package responsibilities

- `@univerjs-pro/slides-chart` integrates chart elements with the slide model and chart engine.
- `@univerjs-pro/slides-chart-ui` adds chart editing UI, render integration, insert panels, and data-source editing.

## Runtime choices

Use both packages in a browser editor. For server-side snapshot processing, register the model package with the core Slides model:

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesChartPlugin)
```

Register chart support before opening or importing decks that may contain chart elements.

## Create a chart

Slides charts use inline two-dimensional arrays as the data source. They do not read directly from sheet ranges.

```ts
const fPresentation = univerAPI.getActivePresentation()
const fSlide = fPresentation.getSlideById('slide-1')

const chartInfo = fSlide.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .setData([
    ['Month', 'Revenue', 'Cost'],
    ['Jan', 120, 80],
    ['Feb', 180, 96],
    ['Mar', 240, 132],
  ])
  .setUseFirstRowAsHeaders(true)
  .setUseFirstColumnAsDomain(true)
  .setTitle('Quarterly revenue')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .build()

const chart = fSlide.insertChart(chartInfo)
```

## Update a chart

Use `getCharts()` or `getChartById()` to find existing charts. `updateDataSource()` updates the inline data while keeping the chart element in place.

```ts
const chart = fSlide.getCharts()[0]

chart?.updateDataSource(
  [
    ['Month', 'Revenue', 'Cost'],
    ['Apr', 260, 140],
    ['May', 300, 168],
  ],
  {
    useFirstRowAsHeaders: true,
    useFirstColumnAsDomain: true,
  },
)
```

For larger changes, convert the chart back to a builder and call `updateChart()`:

```ts
if (chart) {
  const nextChartInfo = chart.toBuilder()
    .setChartType(univerAPI.Enum.ChartType.Line)
    .setOptions('legend.position', univerAPI.Enum.ChartLegendPositionEnum.Right)
    .setSeriesStyle(0, { color: '#2F80ED' })
    .build()

  fSlide.updateChart(nextChartInfo)
}
```

## Remove a chart

```ts
chart?.remove()
// or
if (chart) {
  fSlide.removeChart(chart)
}
```
