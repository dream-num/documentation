## Tabellenunterstützung registrieren

Die Tabellenunterstützung für Folien ist in ein Modellpaket und ein UI-Paket unterteilt:

```ts
import { UniverSlidesTablePlugin } from '@univerjs-pro/slides-table'
import { UniverSlidesTableUIPlugin } from '@univerjs-pro/slides-table-ui'
import SlidesTableUIEnUS from '@univerjs-pro/slides-table-ui/locale/en-US'

import '@univerjs-pro/slides-table-ui/lib/index.css'
import '@univerjs-pro/slides-table/facade'
import '@univerjs-pro/slides-table-ui/facade'

univer.registerPlugin(UniverSlidesTablePlugin)
univer.registerPlugin(UniverSlidesTableUIPlugin)
```

## Paketverantwortlichkeiten

- `@univerjs-pro/slides-table` speichert Tabellenelemente im Folienmodell und stellt Fassaden-APIs für Tabellenoperationen bereit.
- `@univerjs-pro/slides-table-ui` fügt eine Benutzeroberfläche für die Browserbearbeitung, Renderintegration, Auswahlverhalten und Kontextmenüoperationen hinzu. Es bietet außerdem `@univerjs-pro/slides-table-ui/locale/*`, `@univerjs-pro/slides-table-ui/facade` und `@univerjs-pro/slides-table-ui/lib/index.css`.

## Laufzeitoptionen

Verwenden Sie beide Pakete in einem Browser-Editor. Importieren Sie für die Node.js-Verarbeitung nur das Modellpaket, es sei denn, Sie benötigen auch Browser-Rendering.

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesTablePlugin)
```

Registrieren Sie die Tabellenunterstützung, bevor Sie Decks öffnen oder importieren, die Tabellenelemente enthalten können, da diese Elemente sonst von der Laufzeit nicht vollständig interpretiert werden können.

## Fassaden-API

Importieren Sie den Fassadeneintrag, um Tabellenmethoden zu `FSlide` hinzuzufügen:

```ts
import '@univerjs-pro/slides-table/facade'
```

Erstellen Sie eine Tabelle aus Nur-Text-Daten:

```ts
const fPresentation = univerAPI.getActivePresentation()
const fSlide = fPresentation.getSlideById('slide-1')

const table = fSlide.insertTableFromData(
  [
    ['Quarter', 'Owner', 'Status'],
    ['Q1', 'Sales', 'Done'],
    ['Q2', 'Marketing', 'In progress'],
  ],
  {
    id: 'status-table',
    rowHeight: 42,
    columnWidth: 160,
  },
)
```

Verwenden Sie die Tabellenersteller, wenn Sie eine explizite Layoutsteuerung benötigen:

```ts
const tableInfo = fSlide.newTable()
  .setValues([
    ['Metric', 'Value'],
    ['Revenue', '$120K'],
  ])
  .setRows(2)
  .setColumns(2)
  .setAbsolutePosition(80, 120)
  .setSize(420, 180)
  .build()

const table = fSlide.insertTable(tableInfo)
```

Tabellenzellen lesen und aktualisieren:

```ts
const table = fSlide.getTableById('status-table') ?? fSlide.getTableAt(0)

if (table) {
  console.log(table.describe())
  console.log(table.getCellText(0, 0))

  table.getCell(1, 2)?.setText('Blocked')
  table.getCell(0, 0)?.setBackgroundColor('#E8F1FF')
}
```

Vorhandene Tabelle aktualisieren oder entfernen:

```ts
const table = fSlide.getTableById('status-table')

if (table) {
  const nextTableInfo = table.toBuilder()
    .setValues([
      ['Quarter', 'Owner', 'Status'],
      ['Q1', 'Sales', 'Done'],
      ['Q2', 'Marketing', 'Blocked'],
    ])
    .setSize(480, 200)
    .build()

  fSlide.updateTable(nextTableInfo)
  fSlide.removeTable(table)
}
```

Tabellenzeilen- und -spaltenindizes sind nullbasiert. Die Anzahl der Builder-Zeilen und -Spalten wird entsprechend den von Ihnen bereitgestellten Werten erweitert, sodass `setValues()` als Quelle der Wahrheit für einfache Tabellen verwendet werden kann.
