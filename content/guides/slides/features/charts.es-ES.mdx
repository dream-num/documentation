## Registrar compatibilidad con gráficos

El soporte de carga en diapositivas consiste en un paquete modelo y un paquete UI. `@univerjs-pro/chart-ui` proporciona los controles de editor compartidos, entradas locales y estilos.

```ts
import ChartUIEsES from '@univerjs-pro/chart-ui/locale/es-ES'
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'
import { UniverSlidesChartUIPlugin } from '@univerjs-pro/slides-chart-ui'
import SlidesChartUIEsES from '@univerjs-pro/slides-chart-ui/locale/es-ES'
import { LocaleType, mergeLocales } from '@univerjs/core'
import '@univerjs-pro/chart-ui/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart/facade'

univerAPI.loadLocales(LocaleType.ES_ES, mergeLocales(ChartUIEsES, SlidesChartUIEsES))
univer.registerPlugin(UniverSlidesChartPlugin)
univer.registerPlugin(UniverSlidesChartUIPlugin)
```

Apúntate el soporte de gráficos antes de abrir o importar una presentación que pueda contener elementos de gráficos.

## Compatibilidad móvil [#mobile-support]

Configure el [editor móvil](/guides/slides/getting-started/installation#mobile-support) primero. En la configuración de modo plugin descrito en esta página, sustitúyase los registros de escritorio a continuación con las exportaciones móviles de los mismos paquetes, y haga el reemplazo **antes de abrir un documento**. Mantenga los plugins modelo, estilos, locales y las importaciones Facade, y no registre ambas variantes.

| Paquete | Registro de escritorio | Registro móvil |
| --- | --- | --- |
| `@univerjs-pro/slides-chart-ui` | `UniverSlidesChartUIPlugin` | `UniverSlidesChartMobileUIPlugin` |

## Registrar los plugins de datos de gráficos [#chart-data-setup]

Los datos de carga que provienen de una referencia requiere [`UniverChartEmbedPlugin`](/reference/packages/plugins/univerjs-pro/chart-embed). Instalar el plugin y registrarlo una vez durante la inicialización, antes de abrir la presentación. Si `UniverEmbedPlugin` está configurado explícitamente, regístrese que plugin primero. Configuración móvil es idéntico, y los arrays de inline no requieren este plugin.

```package-install
npm install @univerjs-pro/chart-embed
```

```ts
import { UniverChartEmbedPlugin } from '@univerjs-pro/chart-embed'

univer.registerPlugin(UniverChartEmbedPlugin)
```

## Crear y actualizar gráficos

`slide.newChart(type)` devuelve un constructor separado. El gráfico no aparece en la diapositiva hasta que la información de la gráfica construida se pasa a `slide.insertChart(info)`.

```ts
const presentation = univerAPI.getActivePresentation()
if (!presentation) throw new Error('No active presentation')

const slide = presentation.getActiveSlide()
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Month', 'Revenue', 'Cost'],
    ['Jan', 120, 80],
    ['Feb', 180, 96],
    ['Mar', 240, 132],
  ])
  .setTitle('Quarterly revenue')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .setZOrder(1)
  .build()

const chart = await slide.insertChart(info)
chart.setLegend({ visible: true }).bringToFront()

const updatedInfo = chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setSubtitle('FY 2026').build()
await chart.update(updatedInfo)

const svg = await chart.exportImage({ format: 'svg' })
```

Los sellos en el `chart` insertado actualizan el gráfico inmediatamente. Utilice `toBuilder(type)` con `update(info)` cuando se requiere una copia desprendida completa o un cambio de tipo. `exportImage()` devuelve `undefined` si ningún renderizador de interfaz puede proporcionar una imagen.

Utilice `slide.getCharts()` y `slide.getChart(id)` para resolver gráficos en vivo, y llame a `await chart.remove()` a eliminar una gráfica. Los constructores de diapositivas también proporcionan `setPlaceholder()`, `setStroke()` e `setZOrder()`.

## Barras de error [#error-bars]

Llame a `setErrorBars()` en un constructor o en un gráfico en vivo. La columna básica 2D, la barra, la línea y los diagramas de dispersión soportan barras de error. `seriesIndex` es basado en cero e incluye el campo de categoría en los datos de origen. Utilice `y` para columnas y líneas, `x` para barras, y ya sea eje numérico para dispersión.

```ts
chart.setErrorBars([
  { seriesIndex: 1, direction: 'y', type: 'both', valueType: 'percentage', value: 20 },
])
```

[`FChart.setErrorBars()`](/reference/facade/chart#seterrorbars)

## Ejes de categorías multinivel

Para los datos jerárquicos en línea, seleccione los campos de categoría en orden root-to-leaf y active la renderización multinivel:

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Region', 'Quarter', 'Revenue'],
    ['North', 'Q1', 120],
    ['North', 'Q2', 148],
    ['South', 'Q1', 98],
    ['South', 'Q2', 132],
  ])
  .setCategoryFields([0, 1])
  .setMultiLevelCategoryAxis(true)
  .setValueFields([2])
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .build()

await slide.insertChart(info)
```

## Vincular un gráfico con datos de Sheets [#bind-sheet-data]

Si el gráfico debe seguir un rango de hoja en lugar de almacenar una copia de los valores, pasar una referencia de recurso a `setSource()`:

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    unit: { selector: 'sales-workbook', type: 'sheet' },
    part: {
      kind: 'range',
      sheetName: 'Data',
      range: 'A1:B20',
      ref: 'Data!A1:B20',
    },
  })
  .setAbsolutePosition(120, 80)
  .setSize(640, 360)
  .build()

const chart = await slide.insertChart(info)
```

El [Chart Facade reference](/reference/facade/chart) documenta la configuración que comparten todos los tipos de gráficos.

Los constructores compartidos también admiten [Configuración de gráficos 3D](/guides/sheets/features/charts#three-dimensional-charts) y [logaritmic value axes](/guides/sheets/features/charts#logarithmic-axes). En diapositivas, utilice `slide.newChart()` con datos en línea o referenciados como se muestra en esta página.
