讓多位使用者編輯同一份 簡報，並即時看到彼此的修改。先完成[協同整合](/server/collaboration/browser-integration)，接入後端、身分驗證、權限與儲存，再設定[授權](/guides/license)。

## 設定與載入文件

參考 [Office 快速開始](/server/collaboration/quick-start)，為現有的 Slides 編輯器加入 Collaboration Client 設定。該範例使用 Sheets；你的後端必須建立並儲存 Slides 文件，再將其 ID 傳回瀏覽器。

```ts
import '@univerjs-pro/slides/facade'
import '@univerjs-pro/collaboration-client/facade'

const document = await univerAPI.getCollaboration().loadSlideAsync('your-document-id')
if (!document) throw new Error('Document could not be loaded')
```

重新開啟或分享文件時，請使用相同的 ID。不要以建立本機空白文件取代載入伺服器文件。

## 驗證同步與權限

在兩個獨立的瀏覽器工作階段中開啟相同的 ID。在其中一個工作階段編輯文字或移動元素，並確認另一個收到修改。驗證重新整理頁面、重新連線與重啟服務後，內容仍然保留。使用檢視者與未授權帳號，確認伺服器會拒絕未獲允許的寫入與讀取。

[編輯歷史](/guides/slides/features/edit-history)與[匯入匯出](/guides/slides/features/import-export)需要另外設定，協同編輯不會自動啟用這些功能。
