Les API de cette page nécessitent un moteur de conversion. Suivez [intégration d'échange de fichiers](/server/import-export) pour connecter les téléchargements, conversions, requêtes de tâches et téléchargements, puis configurez les plugins du navigateur. Les API snapshots nécessitent également que le moteur, mais ne nécessitent pas de document collaboratif. L'exemple de collaboration Exchange démontre Feuilles, donc vérifiez que la version cible supporte les types de fichiers dont vous avez besoin.

En cas d’échec d’export, consultez [les erreurs de licence et de tâche](/server/import-export#export-errors).

## Formats pris en charge

Le tableau décrit les formats que les API du navigateur sur cette page acceptent. La conversion des fichiers Office nécessite également un moteur qui prend en charge le même type de document et le même format.

| Importation | Exportation |
| --- | --- |
| `.ppt`, `.pptx` | `.pptx` |

`.ppt` et `.pptx` utilisent les API d'importation ci-dessous, et exportent toujours `.pptx`. L'API du navigateur n'accepte pas `.pptm`, `.ppsx` ou `.ppsm` ni `.potx` . La prise en charge de ces formats seuls ne les rend pas fonctionner dans le navigateur.

## API facade

En mode plugin, importez les paquets de façade une fois:

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
```

Importez un fichier PPTX dans une unité côté serveur :

```ts
const unitId = await univerAPI.importSlideToUnitIdAsync(file)
```

Importez un fichier PPTX sous forme de données de diapositives locales :

```ts
const slideData = await univerAPI.importSlideToSnapshotAsync(file)

if (slideData) {
  univerAPI.createPresentation(slideData)
}
```

Exportez la présentation actuelle :

```ts
const presentation = univerAPI.getActivePresentation()
const file = await univerAPI.exportSlideBySnapshotAsync(presentation.save())
```

Exportez une unité de diapositives côté serveur :

```ts
const file = await univerAPI.exportSlideByUnitIdAsync(unitId)
```

## Suppression des menus et des interactions UI d’importation et d’exportation intégrés [#import-export-ui-migration]

<Callout type="warning" title="Remarque">
  En commençant par la version **1.2.0**, Univer n'inclut plus les menus d'importation/exportation intégrés et les interactions UI. Les services sous-jacents et les API Facade restent disponibles.
</Callout>

Si l'application a encore besoin de ces menus et interactions d'interface utilisateur, le [exemple de migration pour les menus d'importation/exportation intégrés et les interactions d'assurance-chômage](https://office.univer.ai/showcase/slides/custom-import-export) explique comment les migrer vers un plugin personnalisé. L'exemple inclut le code source complet que vous pouvez consulter en ligne ou télécharger.
