Permite que varios usuarios editen el mismo documento de presentación y vean los cambios de los demás. Completa la [integración de colaboración](/server/collaboration/browser-integration) para conectar el backend, la autenticación, los permisos y el almacenamiento; después configura la [licencia](/server/license).

## Configurar y cargar un documento

Añade la configuración del cliente Collaboration a tu editor Slides existente siguiendo el [inicio rápido de Office](/server/collaboration/quick-start). Ese ejemplo usa Sheets; tu backend debe crear y guardar un documento Slides y devolver su ID al navegador.

```ts
import '@univerjs-pro/slides/facade'
import '@univerjs-pro/collaboration-client/facade'

const document = await univerAPI.getCollaboration().loadSlideAsync('your-document-id')
if (!document) throw new Error('Document could not be loaded')
```

Reutiliza el mismo ID al volver a abrir o compartir el documento. No crees un documento local vacío en lugar de cargar el documento del servidor.

## Verificar la sincronización y los permisos

Abre el mismo ID en dos sesiones independientes del navegador. Edita texto o mueve un elemento en una sesión y comprueba la otra. Verifica que el contenido persista tras recargar la página, reconectar y reiniciar el servicio. Usa cuentas de solo lectura y sin autorización para comprobar que el servidor rechaza las lecturas y escrituras no permitidas.

El [historial de edición](/guides/slides/features/edit-history) y la [importación y exportación](/guides/slides/features/import-export) requieren una configuración independiente; la colaboración no los activa automáticamente.
