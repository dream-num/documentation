## Registrar soporte para tablas

El soporte de mesa de diapositivas consta de dos paquetes, uno para el modelo y otro para la interfaz de usuario:

```ts
import { UniverSlidesTablePlugin } from '@univerjs-pro/slides-table'
import { UniverSlidesTableUIPlugin } from '@univerjs-pro/slides-table-ui'
import SlidesTableUIEnUS from '@univerjs-pro/slides-table-ui/locale/en-US'

import '@univerjs-pro/slides-table-ui/lib/index.css'
import '@univerjs-pro/slides-table/facade'

univer.registerPlugin(UniverSlidesTablePlugin)
univer.registerPlugin(UniverSlidesTableUIPlugin)
```

## Compatibilidad móvil [#mobile-support]

Configure el [editor móvil](/guides/slides/getting-started/installation#mobile-support) primero. En la configuración de modo plugin en esta página, sustitúyase los registros de escritorio a continuación con las exportaciones móviles de los mismos paquetes, y lo haga **antes de abrir un documento**. Mantenga los plugins modelo, estilos, locales y las importaciones Facade, y regístrese sólo una variante.

| Paquete | Registro de escritorio | Registro móvil |
| --- | --- | --- |
| `@univerjs-pro/slides-table-ui` | `UniverSlidesTableUIPlugin` | `UniverSlidesTableMobileUIPlugin` |

## Responsabilidades del paquete

- `@univerjs-pro/slides-table` almacena elementos de mesa en el modelo de diapositivas y proporciona las API de fachada para las operaciones de mesa.
- `@univerjs-pro/slides-table-ui` proporciona la interfaz de usuario de edición del navegador, incluyendo integración de renderizado, comportamiento de selección y acciones de menú contextual. El paquete también proporciona `@univerjs-pro/slides-table-ui/locale/*` y `@univerjs-pro/slides-table-ui/lib/index.css`.

## Opciones de tiempo de ejecución

Un editor del navegador requiere ambos paquetes. En un proceso Node.js, importar sólo el paquete modelo a menos que el renderizado del navegador también sea necesario.

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesTablePlugin)
```

Inscribir soporte de mesa antes de abrir o importar una cubierta que pueda contener elementos de tabla. De lo contrario, el tiempo de ejecución no puede interpretar plenamente esos elementos.

## Colores de tabla estables

Cuando se inserta una tabla o su estilo cambia, el plugin resuelve la paleta de tema actual en una instantánea que la tabla posee. Las tablas existentes mantienen esos colores después de los cambios globales de tema Univer, y seleccionar otro estilo de mesa crea una nueva instantánea.

## API de Facade

Importe la entrada de fachada para agregar métodos de tabla a `FSlide`:

```ts
import '@univerjs-pro/slides-table/facade'
```

Cree una tabla a partir de datos de texto sin formato:

```ts
const fPresentation = univerAPI.getActivePresentation()
const fSlide = fPresentation.getSlideById('slide-1')

const table = fSlide.insertTableFromData(
  [
    ['Quarter', 'Owner', 'Status'],
    ['Q1', 'Sales', 'Done'],
    ['Q2', 'Marketing', 'In progress'],
  ],
  {
    id: 'status-table',
    rowHeight: 42,
    columnWidth: 160,
  },
)
```

Utilice el constructor de tablas cuando se requiere el control explícito sobre la posición y el tamaño:

```ts
const tableInfo = fSlide.newTable()
  .setValues([
    ['Metric', 'Value'],
    ['Revenue', '$120K'],
  ])
  .setRows(2)
  .setColumns(2)
  .setAbsolutePosition(80, 120)
  .setSize(420, 180)
  .build()

const table = fSlide.insertTable(tableInfo)
```

Leer y actualizar celdas de la tabla:

```ts
const table = fSlide.getTableById('status-table') ?? fSlide.getTableAt(0)

if (table) {
  console.log(table.describe())
  console.log(table.getCellText(0, 0))

  table.getCell(1, 2)?.setText('Blocked')
  table.getCell(0, 0)?.setBackgroundColor('#E8F1FF')
}
```

Actualizar o eliminar una tabla existente:

```ts
const table = fSlide.getTableById('status-table')

if (table) {
  const nextTableInfo = table.toBuilder()
    .setValues([
      ['Quarter', 'Owner', 'Status'],
      ['Q1', 'Sales', 'Done'],
      ['Q2', 'Marketing', 'Blocked'],
    ])
    .setSize(480, 200)
    .build()

  fSlide.updateTable(nextTableInfo)
  fSlide.removeTable(table)
}
```

Los índices de filas y columnas son de base cero. El constructor crece su fila y cuenta de columna para adaptarse a los valores que se le pasaron, por lo que para una tabla simple, `setValues()` puede servir como la fuente de la verdad.
