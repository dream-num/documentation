## テーブル機能の登録

スライドテーブルのサポートは、モデルとUIの1つの2つのパッケージで構成されます。

```ts
import { UniverSlidesTablePlugin } from '@univerjs-pro/slides-table'
import { UniverSlidesTableUIPlugin } from '@univerjs-pro/slides-table-ui'
import SlidesTableUIEnUS from '@univerjs-pro/slides-table-ui/locale/en-US'

import '@univerjs-pro/slides-table-ui/lib/index.css'
import '@univerjs-pro/slides-table/facade'

univer.registerPlugin(UniverSlidesTablePlugin)
univer.registerPlugin(UniverSlidesTableUIPlugin)
```

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/slides/getting-started/installation#mobile-support)を最初に構成します。 このページのプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換え、**ドキュメントを開く前に**を実行します。 モデルプラグイン、スタイル、ロケール、ファサードのインポートを保存し、1つのバリアントだけを登録します。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/slides-table-ui` | `UniverSlidesTableUIPlugin` | `UniverSlidesTableMobileUIPlugin` |

## パッケージの役割

- `@univerjs-pro/slides-table`はスライド モデルの表要素を貯え、テーブル操作のための正面APIを提供します。
- `@univerjs-pro/slides-table-ui`は、レンダリングの統合、選択の動作、コンテキストメニューのアクションを含むUIを編集するブラウザを提供します。パッケージは、`@univerjs-pro/slides-table-ui/locale/*`と`@univerjs-pro/slides-table-ui/lib/index.css`も提供します。

## Runtime の選択

ブラウザエディタはパッケージを両方必要とします。Node.jsプロセスでは、ブラウザのレンダリングが要求される場合を除き、モデルパッケージのみをインポートします。

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesTablePlugin)
```

テーブル要素を含むデッキを開くか、またはインポートする前にテーブルサポートを登録します。それ以外の場合は、ランタイムはこれらの要素を完全に解釈できません。

## テーブル色を固定する

テーブルが入れられたり、そのスタイルの変更をするとき、プラグインはテーブルが所有するスナップショットに現在のテーマパレットを解決します。既存のテーブルは、グローバルUniverテーマの変更後にそれらの色を保持し、別のテーブルスタイルを選択すると、新しいスナップショットが作成されます。標準ファサード操作はこれを自動的に処理します。

## Facade API

facade エントリをインポートすると、`FSlide` にテーブル関連メソッドが追加されます：

```ts
import '@univerjs-pro/slides-table/facade'
```

プレーンテキストの二次元配列からテーブルを作成します：

```ts
const fPresentation = univerAPI.getActivePresentation()
const fSlide = fPresentation.getSlideById('slide-1')

const table = fSlide.insertTableFromData(
  [
    ['Quarter', 'Owner', 'Status'],
    ['Q1', 'Sales', 'Done'],
    ['Q2', 'Marketing', 'In progress'],
  ],
  {
    id: 'status-table',
    rowHeight: 42,
    columnWidth: 160,
  },
)
```

ポジションとサイズを上回る明示的な制御が必要な場合は、テーブルビルダーを使用してください。

```ts
const tableInfo = fSlide.newTable()
  .setValues([
    ['Metric', 'Value'],
    ['Revenue', '$120K'],
  ])
  .setRows(2)
  .setColumns(2)
  .setAbsolutePosition(80, 120)
  .setSize(420, 180)
  .build()

const table = fSlide.insertTable(tableInfo)
```

テーブルセルを読み取り、更新します：

```ts
const table = fSlide.getTableById('status-table') ?? fSlide.getTableAt(0)

if (table) {
  console.log(table.describe())
  console.log(table.getCellText(0, 0))

  table.getCell(1, 2)?.setText('Blocked')
  table.getCell(0, 0)?.setBackgroundColor('#E8F1FF')
}
```

既存のテーブルを更新、または削除します：

```ts
const table = fSlide.getTableById('status-table')

if (table) {
  const nextTableInfo = table.toBuilder()
    .setValues([
      ['Quarter', 'Owner', 'Status'],
      ['Q1', 'Sales', 'Done'],
      ['Q2', 'Marketing', 'Blocked'],
    ])
    .setSize(480, 200)
    .build()

  fSlide.updateTable(nextTableInfo)
  fSlide.removeTable(table)
}
```

テーブル行と列インデックスはゼロベースです。ビルダーは行と列数を成長させ、値がそれに渡されるように、単純なテーブルでは、`setValues()`は真理のソースとして機能することができます。
