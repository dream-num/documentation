## Activer la prise en charge des tableaux

Le support de table de diapositives se compose de deux paquets, l'un pour le modèle et l'autre pour l'interface utilisateur :

```ts
import { UniverSlidesTablePlugin } from '@univerjs-pro/slides-table'
import { UniverSlidesTableUIPlugin } from '@univerjs-pro/slides-table-ui'
import SlidesTableUIEnUS from '@univerjs-pro/slides-table-ui/locale/en-US'

import '@univerjs-pro/slides-table-ui/lib/index.css'
import '@univerjs-pro/slides-table/facade'

univer.registerPlugin(UniverSlidesTablePlugin)
univer.registerPlugin(UniverSlidesTableUIPlugin)
```

## Prise en charge mobile [#mobile-support]

Configurez d'abord le [éditeur mobile](/guides/slides/getting-started/installation#mobile-support). Dans la configuration en mode plugin de cette page, remplacez les enregistrements de bureau ci-dessous par les exportations mobiles des mêmes paquets, et faites-le **avant d'ouvrir un document** . Gardez les plugins modèles, styles, locales et importations de Facade, et enregistrez une seule variante.

| Paquet | Inscription de bureau | Inscription mobile |
| --- | --- | --- |
| `@univerjs-pro/slides-table-ui` | `UniverSlidesTableUIPlugin` | `UniverSlidesTableMobileUIPlugin` |

## Rôle des packages

- `@univerjs-pro/slides-table` stocke les éléments de table dans le modèle de diapositives et fournit les API de façade pour les opérations de table.
- `@univerjs-pro/slides-table-ui` fournit l'interface d'édition du navigateur, y compris l'intégration de rendu, le comportement de sélection et les actions de menu contextuel. Le paquet fournit également `@univerjs-pro/slides-table-ui/locale/*` et `@univerjs-pro/slides-table-ui/lib/index.css`.

## Choix selon l’environnement d’exécution

Dans un processus Node.js, n'importez que le paquet modèle à moins que le rendu du navigateur ne soit également nécessaire.

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesTablePlugin)
```

Enregistrer le support de table avant d'ouvrir ou d'importer un pont qui peut contenir des éléments de table. Sinon, l'exécution ne peut pas interpréter pleinement ces éléments.

## Couleurs de tableau stables

Lorsqu'une table est insérée ou que son style change, le plugin résout la palette de thèmes en cours dans un instantané que la table possède. Les tables existantes conservent ces couleurs après les changements de thèmes globaux Univer, et la sélection d'un autre style de table crée un nouvel instantané.

## API Facade

Importez le point d’entrée Facade pour ajouter les méthodes de tableau à `FSlide` :

```ts
import '@univerjs-pro/slides-table/facade'
```

Créez un tableau à partir de données textuelles simples :

```ts
const fPresentation = univerAPI.getActivePresentation()
const fSlide = fPresentation.getSlideById('slide-1')

const table = fSlide.insertTableFromData(
  [
    ['Quarter', 'Owner', 'Status'],
    ['Q1', 'Sales', 'Done'],
    ['Q2', 'Marketing', 'In progress'],
  ],
  {
    id: 'status-table',
    rowHeight: 42,
    columnWidth: 160,
  },
)
```

Utilisez le constructeur de table quand un contrôle explicite de la position et de la taille est nécessaire:

```ts
const tableInfo = fSlide.newTable()
  .setValues([
    ['Metric', 'Value'],
    ['Revenue', '$120K'],
  ])
  .setRows(2)
  .setColumns(2)
  .setAbsolutePosition(80, 120)
  .setSize(420, 180)
  .build()

const table = fSlide.insertTable(tableInfo)
```

Lisez et mettez à jour les cellules d’un tableau :

```ts
const table = fSlide.getTableById('status-table') ?? fSlide.getTableAt(0)

if (table) {
  console.log(table.describe())
  console.log(table.getCellText(0, 0))

  table.getCell(1, 2)?.setText('Blocked')
  table.getCell(0, 0)?.setBackgroundColor('#E8F1FF')
}
```

Mettez à jour ou supprimez un tableau existant :

```ts
const table = fSlide.getTableById('status-table')

if (table) {
  const nextTableInfo = table.toBuilder()
    .setValues([
      ['Quarter', 'Owner', 'Status'],
      ['Q1', 'Sales', 'Done'],
      ['Q2', 'Marketing', 'Blocked'],
    ])
    .setSize(480, 200)
    .build()

  fSlide.updateTable(nextTableInfo)
  fSlide.removeTable(table)
}
```

Les index des lignes et des colonnes de tableau sont basés sur zéro. Le constructeur augmente ses nombres de lignes et de colonnes pour s'adapter aux valeurs qui lui ont été transmises, de sorte que pour une table simple, `setValues()` peut servir de source de vérité.
