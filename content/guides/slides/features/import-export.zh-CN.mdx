## 支持的格式

下表列出本页浏览器 API 支持的格式。Office 文件转换还需要后端支持相同的文档类型和格式。

| 导入 | 导出 |
| --- | --- |
| `.ppt`, `.pptx` | `.pptx` |

`.ppt` 和 `.pptx` 都使用下方的导入 API，导出统一生成 `.pptx`。浏览器 API 不接受 `.pptm`、`.ppsx`、`.ppsm`、`.potx`。后端支持这些格式，并不意味着浏览器 API 可以使用它们。

## Facade API

插件模式下，请先引入 facade 包：

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
```

将 PPTX 导入到服务端 unit：

```ts
const unitId = await univerAPI.importSlideToUnitIdAsync(file)
```

将 PPTX 导入为本地 slide 数据：

```ts
const slideData = await univerAPI.importSlideToSnapshotAsync(file)

if (slideData) {
  univerAPI.createPresentation(slideData)
}
```

导出当前 slide deck：

```ts
const presentation = univerAPI.getActivePresentation()
const file = await univerAPI.exportSlideBySnapshotAsync(presentation.save())
```

导出服务端 slide unit：

```ts
const file = await univerAPI.exportSlideByUnitIdAsync(unitId)
```

## 移除内置导入导出菜单和 UI 交互 [#import-export-ui-migration]

<Callout type="warning" title="注意事项">
  从 **1.2.0** 版本开始，Univer 不再内置导入导出菜单和 UI 交互，底层服务和 Facade API 仍然可用。
</Callout>

如果应用仍需保留这些菜单和 UI 交互，可以参考[内置导入导出菜单和 UI 交互迁移方案](https://office.univer.ai/zh-CN/showcase/slides/custom-import-export)，通过自定义插件完成迁移。示例包含完整源码，可以在线查看或下载。
