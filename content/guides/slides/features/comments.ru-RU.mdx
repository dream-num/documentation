Зарегистрируйте плагины комментариев после установки редактора продукта и лицензии. Загрузите общие и пользовательские стили продукта и ресурсы локализации. Плагин продукта владеет ресурсами комментариев, поэтому снимок может быть восстановлен только после регистрации этого плагина.

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs-pro/slides-thread-comment @univerjs-pro/slides-thread-comment-ui
```

```ts
import { UniverSlidesThreadCommentPlugin } from '@univerjs-pro/slides-thread-comment'
import { UniverSlidesThreadCommentUIPlugin } from '@univerjs-pro/slides-thread-comment-ui'
import ProductLocale from '@univerjs-pro/slides-thread-comment-ui/locale/ru-RU'
import { LocaleType, mergeLocales } from '@univerjs/core'
import SharedLocale from '@univerjs/thread-comment-ui/locale/ru-RU'

import '@univerjs/thread-comment-ui/lib/index.css'
import '@univerjs-pro/slides-thread-comment-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.RU_RU, mergeLocales(SharedLocale, ProductLocale))
univer.registerPlugin(UniverSlidesThreadCommentPlugin)
univer.registerPlugin(UniverSlidesThreadCommentUIPlugin)
```

## Поддержка мобильных устройств [#mobile-support]

Сначала настройте [Мобильный редактор](/guides/slides/getting-started/installation#mobile-support). В настройках плагин-режима, описанных на этой странице, замените регистрацию рабочего стола ниже на мобильный экспорт из тех же пакетов и сделайте замену **Перед тем, как открыть документ**, сохраните плагины модели, стили, локализации и импорт Facade и не регистрируйте оба варианта.

| Пакет | Настольная регистрация | Мобильная регистрация |
| --- | --- | --- |
| `@univerjs-pro/slides-thread-comment-ui` | `UniverSlidesThreadCommentUIPlugin` | `UniverSlidesThreadCommentMobileUIPlugin` |

## Facade комментариев [#comment-facade]

Импортировать общий комментарий Facade и продукт Facade перед вызовом этих методов. Помощники продукта создают стабильные якоря, а общий API обрабатывает ответы, обновления, разрешение и удаление. `getComments()` читает локальное состояние. `listCommentsAsync()` синхронизирует потоки, о которых он уже знает, через настроенный источник данных, но не обнаруживает каждый поток на сервере.

```ts
import '@univerjs/thread-comment/facade'
import '@univerjs-pro/slides-thread-comment/facade'

const element = univerAPI.getActivePresentation()?.getSlideByIndex(0)?.getElements()[0]
if (element) {
  await element.createCommentAsync('Please review this element.')
  console.log(await element.listCommentsAsync())
}
```

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## Общие обсуждения [#shared-discussions]

Общие обсуждения требуют, чтобы сервис комментариев и конечная точка были подключены через [Server SDK](/server/collaboration/extensions). После настройки совместной работы и лицензии зарегистрируйте `UniverThreadCommentDataSourcePlugin` от `@univerjs-pro/thread-comment-datasource`... Поставляемый источник данных вызывает `/universer-api/comment/unit/{unitId}/...` и `/universer-api/user/list`, поэтому приложение должно раскрыть эти маршруты. Комментарии читают и пишут требуют собственных разрешений сервера; разрешение на редактирование документов не распространяется на них.
