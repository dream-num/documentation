## Enregistrer la prise en charge des graphiques

La prise en charge des graphiques dans les diapositives consiste en un paquet modèle et un paquet UI. `@univerjs-pro/chart-ui` fournit les commandes d'éditeurs partagés, les entrées locales et les styles.

```ts
import ChartUIFrFR from '@univerjs-pro/chart-ui/locale/fr-FR'
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'
import { UniverSlidesChartUIPlugin } from '@univerjs-pro/slides-chart-ui'
import SlidesChartUIFrFR from '@univerjs-pro/slides-chart-ui/locale/fr-FR'
import { LocaleType, mergeLocales } from '@univerjs/core'
import '@univerjs-pro/chart-ui/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart/facade'

univerAPI.loadLocales(LocaleType.FR_FR, mergeLocales(ChartUIFrFR, SlidesChartUIFrFR))
univer.registerPlugin(UniverSlidesChartPlugin)
univer.registerPlugin(UniverSlidesChartUIPlugin)
```

Enregistrer le support du graphique avant d'ouvrir ou d'importer une présentation qui peut contenir des éléments du graphique.

## Prise en charge mobile [#mobile-support]

Configurez d'abord le [éditeur mobile](/guides/slides/getting-started/installation#mobile-support). Dans la configuration en mode plugin décrite sur cette page, remplacez les enregistrements de bureau ci-dessous avec les exportations mobiles des mêmes paquets, et faites le remplacement **avant d'ouvrir un document** . Gardez les plugins modèles, styles, locaux et importations Facade, et ne enregistrez pas les deux variantes.

| Paquet | Inscription de bureau | Inscription mobile |
| --- | --- | --- |
| `@univerjs-pro/slides-chart-ui` | `UniverSlidesChartUIPlugin` | `UniverSlidesChartMobileUIPlugin` |

## Enregistrer les plugins de données des graphiques [#chart-data-setup]

Les données du graphique qui proviennent d'une référence nécessitent [`UniverChartEmbedPlugin`](/reference/packages/plugins/univerjs-pro/chart-embed). Installez le plugin et enregistrez-le une fois pendant l'initialisation, avant d'ouvrir la présentation. Si `UniverEmbedPlugin` est configuré explicitement, enregistrez ce plugin d'abord. La configuration mobile est identique, et les tableaux en ligne ne nécessitent pas ce plugin.

```package-install
npm install @univerjs-pro/chart-embed
```

```ts
import { UniverChartEmbedPlugin } from '@univerjs-pro/chart-embed'

univer.registerPlugin(UniverChartEmbedPlugin)
```

## Créer et mettre à jour un graphique

`slide.newChart(type)` retourne un constructeur détaché. Le graphique n'apparaît pas sur la diapositive tant que les informations du graphique intégré ne sont pas transmises à `slide.insertChart(info)`.

```ts
const presentation = univerAPI.getActivePresentation()
if (!presentation) throw new Error('No active presentation')

const slide = presentation.getActiveSlide()
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Month', 'Revenue', 'Cost'],
    ['Jan', 120, 80],
    ['Feb', 180, 96],
    ['Mar', 240, 132],
  ])
  .setTitle('Quarterly revenue')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .setZOrder(1)
  .build()

const chart = await slide.insertChart(info)
chart.setLegend({ visible: true }).bringToFront()

const updatedInfo = chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setSubtitle('FY 2026').build()
await chart.update(updatedInfo)

const svg = await chart.exportImage({ format: 'svg' })
```

Setters sur l'insert `chart` Mettre à jour le graphique immédiatement. `toBuilder(type)` avec `update(info)` lorsqu'une copie séparée complète ou un changement de type est nécessaire. `exportImage()` retours `undefined` quand aucun lecteur d'interface utilisateur ne peut fournir une image.

Utilisez `slide.getCharts()` et `slide.getChart(id)` pour résoudre les graphiques en direct et appelez `await chart.remove()` afin de supprimer un graphique. Les constructeurs de diapositives fournissent également `setPlaceholder()`, `setStroke()` ainsi que `setZOrder()`.

## Barres d’erreur [#error-bars]

Appeler `setErrorBars()` sur un constructeur ou sur un graphique en direct. Les barres d'erreur de base 2D colonne, barre, ligne et diagrammes de dispersion supportent les barres. `seriesIndex` est basé sur zéro et comprend le champ de catégorie dans les données source. Utilisez `y` pour les colonnes et lignes, `x` dans les barres et soit l'axe numérique pour la diffusion.

```ts
chart.setErrorBars([
  { seriesIndex: 1, direction: 'y', type: 'both', valueType: 'percentage', value: 20 },
])
```

[`FChart.setErrorBars()`](/reference/facade/chart#seterrorbars)

## Axes de catégories multiniveaux

Pour les données hiérarchiques en ligne, sélectionnez les champs de catégorie dans l'ordre root-to-leaf et activez le rendu multi-niveaux:

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource([
    ['Region', 'Quarter', 'Revenue'],
    ['North', 'Q1', 120],
    ['North', 'Q2', 148],
    ['South', 'Q1', 98],
    ['South', 'Q2', 132],
  ])
  .setCategoryFields([0, 1])
  .setMultiLevelCategoryAxis(true)
  .setValueFields([2])
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .build()

await slide.insertChart(info)
```

## Lier un graphique aux données de Sheets [#bind-sheet-data]

Si le graphique doit suivre une plage de feuilles au lieu de stocker une copie des valeurs, passez une référence de ressource à `setSource()`:

```ts
const info = slide
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    unit: { selector: 'sales-workbook', type: 'sheet' },
    part: {
      kind: 'range',
      sheetName: 'Data',
      range: 'A1:B20',
      ref: 'Data!A1:B20',
    },
  })
  .setAbsolutePosition(120, 80)
  .setSize(640, 360)
  .build()

const chart = await slide.insertChart(info)
```

Le [Référence de la figure](/reference/facade/chart) documente la configuration que tous les types de graphiques partagent.

Les constructeurs partagés prennent également en charge [Configuration du graphique 3D](/guides/sheets/features/charts#three-dimensional-charts) et [axes de valeur logarithmique](/guides/sheets/features/charts#logarithmic-axes). Dans les diapositives, utilisez `slide.newChart()` avec des données en ligne ou référencées comme indiqué sur cette page.
