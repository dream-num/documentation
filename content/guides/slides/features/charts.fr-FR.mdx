## Activer la prise en charge des graphiques

La prise en charge des graphiques dans Slides est répartie entre un package de modèle et un package d’interface utilisateur :

`@univerjs-pro/chart-ui` est la dépendance d’interface utilisateur commune utilisée par le package d’interface des graphiques de Slides.

```ts
import ChartUIEnUS from '@univerjs-pro/chart-ui/locale/en-US'
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'
import { UniverSlidesChartUIPlugin } from '@univerjs-pro/slides-chart-ui'
import SlidesChartUIEnUS from '@univerjs-pro/slides-chart-ui/locale/en-US'

import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart-ui/lib/index.css'
import '@univerjs-pro/slides-chart/facade'

univer.registerPlugin(UniverSlidesChartPlugin)
univer.registerPlugin(UniverSlidesChartUIPlugin)
```

## Rôle des packages

- `@univerjs-pro/slides-chart` intègre les éléments graphiques au modèle de diapositive et au moteur de graphiques.
- `@univerjs-pro/chart-ui` fournit les commandes communes de l’éditeur de graphiques, les fichiers de paramètres régionaux et `@univerjs-pro/chart-ui/lib/index.css` aux packages d’interface graphique Pro.
- `@univerjs-pro/slides-chart-ui` ajoute l’interface d’édition des graphiques, l’intégration au rendu, les panneaux d’insertion et la modification des sources de données. Pour les éditeurs exécutés dans le navigateur, il fournit également `@univerjs-pro/slides-chart-ui/locale/*` et `@univerjs-pro/slides-chart-ui/lib/index.css`.

## Choix selon l’environnement d’exécution

Utilisez les deux packages dans un éditeur exécuté dans le navigateur. Pour le traitement d’instantanés côté serveur, enregistrez le package de modèle avec le modèle Slides principal :

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesChartPlugin)
```

Activez la prise en charge des graphiques avant d’ouvrir ou d’importer des présentations susceptibles d’en contenir.

## Créer un graphique

Les graphiques Slides utilisent des tableaux bidimensionnels intégrés comme source de données. Ils ne lisent pas directement les plages de feuilles de calcul.

```ts
const fPresentation = univerAPI.getActivePresentation()
const fSlide = fPresentation.getSlideById('slide-1')

const chartInfo = fSlide.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .setData([
    ['Month', 'Revenue', 'Cost'],
    ['Jan', 120, 80],
    ['Feb', 180, 96],
    ['Mar', 240, 132],
  ])
  .setUseFirstRowAsHeaders(true)
  .setUseFirstColumnAsDomain(true)
  .setTitle('Quarterly revenue')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)
  .build()

const chart = fSlide.insertChart(chartInfo)
```

## Mettre à jour un graphique

Utilisez `getCharts()` ou `getChartById()` pour rechercher les graphiques existants. `updateDataSource()` met à jour les données intégrées tout en conservant l’élément graphique à sa place.

```ts
const chart = fSlide.getCharts()[0]

chart?.updateDataSource(
  [
    ['Month', 'Revenue', 'Cost'],
    ['Apr', 260, 140],
    ['May', 300, 168],
  ],
  {
    useFirstRowAsHeaders: true,
    useFirstColumnAsDomain: true,
  },
)
```

Pour apporter des modifications plus importantes, reconvertissez le graphique en générateur, puis appelez `updateChart()` :

```ts
if (chart) {
  const nextChartInfo = chart.toBuilder()
    .setChartType(univerAPI.Enum.ChartType.Line)
    .setOptions('legend.position', univerAPI.Enum.ChartLegendPositionEnum.Right)
    .setSeriesStyle(0, { color: '#2F80ED' })
    .build()

  fSlide.updateChart(nextChartInfo)
}
```

## Supprimer un graphique

```ts
chart?.remove()
// or
if (chart) {
  fSlide.removeChart(chart)
}
```
