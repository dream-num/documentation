製品エディタとライセンスが設定された後にコメントプラグインを登録します。 共有された製品 UI スタイルとローカライズリソースをロードします。 製品プラグインはコメントリソースを所有しているため、プラグインが登録された後にスナップショットを復元できます。

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs-pro/slides-thread-comment @univerjs-pro/slides-thread-comment-ui
```

```ts
import { UniverSlidesThreadCommentPlugin } from '@univerjs-pro/slides-thread-comment'
import { UniverSlidesThreadCommentUIPlugin } from '@univerjs-pro/slides-thread-comment-ui'
import ProductLocale from '@univerjs-pro/slides-thread-comment-ui/locale/ja-JP'
import { LocaleType, mergeLocales } from '@univerjs/core'
import SharedLocale from '@univerjs/thread-comment-ui/locale/ja-JP'

import '@univerjs/thread-comment-ui/lib/index.css'
import '@univerjs-pro/slides-thread-comment-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.JA_JP, mergeLocales(SharedLocale, ProductLocale))
univer.registerPlugin(UniverSlidesThreadCommentPlugin)
univer.registerPlugin(UniverSlidesThreadCommentUIPlugin)
```

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/slides/getting-started/installation#mobile-support)を最初に構成します。 このページに記載されているプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換え、**ドキュメントを開く前に**の置換を行います。 モデルプラグイン、スタイル、ロケール、ファサードのインポートをキープし、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/slides-thread-comment-ui` | `UniverSlidesThreadCommentUIPlugin` | `UniverSlidesThreadCommentMobileUIPlugin` |

## コメント Facade [#comment-facade]

これらのメソッドを呼び出す前に、共有コメントファサードと製品ファサードをインポートします。製品ヘルパーは安定したアンカーを作成し、共有された API は応答、更新、解像度、削除を処理します。 `getComments()` はローカルの状態を読み込みます。 `listCommentsAsync()`は、設定されたデータソースを通して既に知っているスレッドを同期させますが、サーバー上のすべてのスレッドは発見しません。

```ts
import '@univerjs/thread-comment/facade'
import '@univerjs-pro/slides-thread-comment/facade'

const element = univerAPI.getActivePresentation()?.getSlideByIndex(0)?.getElements()[0]
if (element) {
  await element.createCommentAsync('Please review this element.')
  console.log(await element.listCommentsAsync())
}
```

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## 共有ディスカッション [#shared-discussions]

共有された議論では、コメントサービスとエンドポイントが[Server SDK](/server/collaboration/extensions)を介して接続される必要があります。 コラボレーションとライセンス設定の後、`UniverThreadCommentDataSourcePlugin`から`@univerjs-pro/thread-comment-datasource`を登録します。 提供されたデータソースは`/universer-api/comment/unit/{unitId}/...`と`/universer-api/user/list`を呼び出します。 そのため、アプリケーションはこれらのルートを明示する必要があります。 コメントの読み込みと書き込みには、独自のサーバー権限が必要です。 ドキュメント編集権限はそれらをカバーしません。
