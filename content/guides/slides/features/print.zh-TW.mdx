## 註冊列印能力

當 Slides 編輯器需要列印預覽或列印相關的 facade API 時，使用 `@univerjs-pro/slides-print`。該包同時提供語言套件，路徑為 `@univerjs-pro/slides-print/locale/*`，因此不需要單獨引入 CSS。

```ts
import { UniverSlidesPrintPlugin } from '@univerjs-pro/slides-print'
import SlidesPrintEnUS from '@univerjs-pro/slides-print/locale/en-US'
import '@univerjs-pro/slides-print/facade'

univer.registerPlugin(UniverSlidesPrintPlugin)
```

## 行動裝置支援 [#mobile-support]

先配置[行動版編輯器](/guides/slides/getting-started/installation#mobile-support)。在本頁外掛模式的初始化程式碼中，將下述桌面版註冊替換為同一套件匯出的行動版外掛，並且必須在**開啟文件前**完成替換。模型外掛、樣式、語言套件和 Facade 匯入均需保留，兩個版本只註冊其中一個。

| 套件 | 桌面版註冊 | 行動版註冊 |
| --- | --- | --- |
| `@univerjs-pro/slides-print` | `UniverSlidesPrintPlugin` | `UniverSlidesPrintMobilePlugin` |

## 依賴

列印外掛必須在核心 Slides 模型之後註冊：

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
univer.registerPlugin(UniverSlidesPrintPlugin)
```

瀏覽器編輯器還需要按[快速開始](/guides/slides/getting-started/quickstart)註冊 render engine、UI 外掛、Docs、Drawing 和授權外掛。

## Facade API

匯入 facade 入口後，`FUniver` 會增加 `printSlidesAsync` 方法：

```ts
import '@univerjs-pro/slides-print/facade'
```

列印當前簡報中的全部幻燈片：

```ts
const univerAPI = FUniver.newAPI(univer)

await univerAPI.printSlidesAsync()
```

按從 1 開始的頁碼列印指定範圍：

```ts
await univerAPI.printSlidesAsync({
  range: [
    { from: 1, to: 3 },
    { from: 6, to: 6 },
  ],
})
```

`range` 使用閉區間頁碼，省略該參數時列印全部幻燈片。重疊的範圍會去重，並按幻燈片順序列印。超出 deck 末尾的範圍會裁剪到實際存在的幻燈片，起止順序顛倒的範圍會被忽略。

## 注意事項

列印輸出取決於當前幻燈片快照、頁面尺寸、演講者備註、drawing 元素，以及可能存在的表格或圖表元素。如果 deck 中可能包含表格或圖表，請在列印前註冊對應的功能外掛。

## 列印版面與預覽

版面配置支援整頁、講義和備註頁，呼叫後會開啟內建預覽：

```ts
import { SlidePrintHandoutOrder, SlidePrintLayoutType } from '@univerjs-pro/slides-print'

univerAPI.openSlidesPrintDialog({
  layout: SlidePrintLayoutType.Handout,
  slidesPerPage: 6,
  handoutOrder: SlidePrintHandoutOrder.Horizontal,
  frameSlides: true,
  showSlideNumber: true,
})
```

還可設定 `paperSize`、`direction`、`margin` 和 `marginCustom`。講義每頁支援 1、2、3、4、6、9 張幻燈片，備註頁會使用當前幻燈片的演講者備註。
