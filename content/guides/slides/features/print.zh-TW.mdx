## 註冊列印能力

當 Slides 編輯器需要列印預覽或列印相關 facade API 時，使用 `@univerjs-pro/slides-print`。

```ts
import { UniverSlidesPrintPlugin } from '@univerjs-pro/slides-print'
import '@univerjs-pro/slides-print/facade'

univer.registerPlugin(UniverSlidesPrintPlugin)
```

## 依賴

列印外掛需要在核心 Slides 模型之後註冊：

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
univer.registerPlugin(UniverSlidesPrintPlugin)
```

瀏覽器編輯器還需要保持 [快速開始](/guides/slides/getting-started/quickstart) 中的 render engine、UI、Docs、Drawing 和授權外掛註冊。

## Facade API

匯入 facade 入口後，`FUniver` 會增加 `printSlidesAsync` 方法：

```ts
import '@univerjs-pro/slides-print/facade'
```

列印目前啟用簡報中的全部投影片：

```ts
const univerAPI = FUniver.newAPI(univer)

await univerAPI.printSlidesAsync()
```

也可以使用從 1 開始的頁碼範圍列印指定投影片：

```ts
await univerAPI.printSlidesAsync({
  range: [
    { from: 1, to: 3 },
    { from: 6, to: 6 },
  ],
})
```

`range` 使用閉區間頁碼。不傳時會列印全部投影片。重疊範圍會被去重，並按照原始投影片順序列印；超出 deck 的範圍會裁剪到可用頁碼，起止順序反轉的無效範圍會被忽略。

## 注意事項

列印輸出依賴目前投影片快照、頁面尺寸、drawing 元素，以及可選的表格或圖表元素。如果你的 deck 可能包含表格或圖表，請在列印前註冊對應功能外掛。
