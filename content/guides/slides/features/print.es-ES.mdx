## Registrar soporte de impresión

Añadir `@univerjs-pro/slides-print` cuando un editor de diapositivas requiere vista previa de impresión o APIs de fachada de impresión. El paquete también proporciona locales bajo `@univerjs-pro/slides-print/locale/*`, por lo que no se requiere ninguna importación CSS separada.

```ts
import { UniverSlidesPrintPlugin } from '@univerjs-pro/slides-print'
import SlidesPrintEnUS from '@univerjs-pro/slides-print/locale/en-US'
import '@univerjs-pro/slides-print/facade'

univer.registerPlugin(UniverSlidesPrintPlugin)
```

## Compatibilidad móvil [#mobile-support]

Configure el [editor móvil](/guides/slides/getting-started/installation#mobile-support) primero. En la configuración de modo plugin en esta página, sustitúyase los registros de escritorio a continuación con las exportaciones móviles de los mismos paquetes, y lo haga **antes de abrir un documento**. Mantenga los plugins modelo, estilos, locales y las importaciones Facade, y regístrese sólo una variante.

| Paquete | Registro de escritorio | Registro móvil |
| --- | --- | --- |
| `@univerjs-pro/slides-print` | `UniverSlidesPrintPlugin` | `UniverSlidesPrintMobilePlugin` |

## Requisitos

Registra el modelo principal de Slides antes del complemento de impresión:

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
univer.registerPlugin(UniverSlidesPrintPlugin)
```

Un editor del navegador también requiere el motor renderizado, plugin UI, Docs, Dibujo y plugins de licencia, como se muestra en el [Quickstart](/guides/slides/getting-started/quickstart).

## API de fachada

Importa la entrada de fachada para agregar `printSlidesAsync` a `FUniver`:

```ts
import '@univerjs-pro/slides-print/facade'
```

Imprima cada diapositiva en la presentación activa:

```ts
const univerAPI = FUniver.newAPI(univer)

await univerAPI.printSlidesAsync()
```

Imprima una selección por número de página basado en 1:

```ts
await univerAPI.printSlidesAsync({
  range: [
    { from: 1, to: 3 },
    { from: 6, to: 6 },
  ],
})
```

## Notas

La salida de impresión depende de la instantánea de la diapositiva actual, el tamaño de página, los elementos de dibujo y los elementos opcionales de tabla o gráfico. Si su presentación puede contener tablas o gráficos, registre esos complementos de funciones antes de imprimir.

```ts
import { SlidePrintHandoutOrder, SlidePrintLayoutType } from '@univerjs-pro/slides-print'

univerAPI.openSlidesPrintDialog({
  layout: SlidePrintLayoutType.Handout,
  slidesPerPage: 6,
  handoutOrder: SlidePrintHandoutOrder.Horizontal,
  frameSlides: true,
  showSlideNumber: true,
})
```

Las opciones también incluyen `paperSize`, `direction`, `margin`, y `marginCustom`. Un folleto soporta 1, 2, 3, 4, 6, o 9 diapositivas por página.

`range` acepta rangos de página inclusivos. Si el parámetro se omite, cada impresión de diapositivas. Los rangos superpuestos son des-duplicados e impresos en orden de diapositivas . Una gama que se extiende más allá del extremo de la cubierta se corta a los toboganes que existen, y un rango revertido es ignorado.

## Notas

La salida de impresión depende de la instantánea de diapositivas actual, el tamaño de la página, las notas de altavoces, los elementos de dibujo y cualquier elemento de tabla o gráfico. Si una cubierta puede contener tablas o gráficos, regístrese esos plugins de características antes de imprimir.
