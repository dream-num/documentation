## Registrar soporte de impresión

Utilice `@univerjs-pro/slides-print` cuando un editor de Presentaciones necesite una vista previa de impresión o API de fachada relacionadas con la impresión. El paquete también proporciona `@univerjs-pro/slides-print/locale/*`; no requiere una importación de CSS por separado.

```ts
import { UniverSlidesPrintPlugin } from '@univerjs-pro/slides-print'
import SlidesPrintEnUS from '@univerjs-pro/slides-print/locale/en-US'
import '@univerjs-pro/slides-print/facade'

univer.registerPlugin(UniverSlidesPrintPlugin)
```

## Requisitos

Registra el modelo principal de Slides antes del complemento de impresión:

```ts
univer.registerPlugin(UniverSlidesPlugin)
univer.registerPlugin(UniverSlidesUIPlugin)
univer.registerPlugin(UniverSlidesPrintPlugin)
```

Para un editor de navegador, mantén el motor de renderizado, el complemento de interfaz de usuario, los documentos, el dibujo y los complementos de licencia registrados como se muestra en [Inicio rápido](/guides/slides/getting-started/quickstart).

## API de fachada

Importa la entrada de fachada para agregar `printSlidesAsync` a `FUniver`:

```ts
import '@univerjs-pro/slides-print/facade'
```

Imprimir todas las diapositivas de la presentación activa:

```ts
const univerAPI = FUniver.newAPI(univer)

await univerAPI.printSlidesAsync()
```

Imprimir rangos de diapositivas seleccionados por número de página basado en 1:

```ts
await univerAPI.printSlidesAsync({
  range: [
    { from: 1, to: 3 },
    { from: 6, to: 6 },
  ],
})
```

`range` acepta rangos de páginas inclusivos. Si se omite, se imprimen todas las diapositivas. Los rangos superpuestos se eliminan los duplicados y se imprimen en el orden de diapositivas original. Los rangos fuera de la plataforma se recortan en las diapositivas disponibles y los rangos invertidos no válidos se ignoran.

## Notas

La salida de impresión depende de la instantánea de la diapositiva actual, el tamaño de página, los elementos de dibujo y los elementos opcionales de tabla o gráfico. Si su presentación puede contener tablas o gráficos, registre esos complementos de funciones antes de imprimir.
