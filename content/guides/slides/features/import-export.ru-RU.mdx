API-интерфейсы на этой странице требуют конвертации бэкэнда. Следуйте [Обмен файлами интеграция](/server/import-export) для подключения загрузок, конверсии, запросов к задачам и загрузок. Затем настройте плагины браузера. API-интерференции для моментальных снимков также требуют этого бэкэнд, но не требуют совместного документа. Пример обмена данными о совместной работе демонстрирует листы, поэтому проверьте, поддерживает ли целевой выпуск нужные вам типы файлов.

При сбое экспорта см. [коды лицензии и обработку ошибок задач](/server/import-export#export-errors).

## Поддерживаемые форматы

В таблице описаны форматы, которые принимают API-интерфейсы браузера на этой странице. Для преобразования файлов Office также требуется бэкэнд, поддерживающий тот же тип и формат документа.

| Импорт | Экспорт |
| --- | --- |
| `.ppt`, `.pptx` | `.pptx` |

Как `.ppt`, так и `.pptx` используют импортные API ниже, а экспорт всегда производит `.pptx`. Браузерный API не принимает `.pptm` , `.ppsx` `.ppsm` или `.potx` Бэкенд-поддержка только этих форматов не заставляет их работать в браузере.

## Facade API

В режиме плагина ввозите пакеты фасадов один раз:

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
```

Импорт PPTX в серверный юнит:

```ts
const unitId = await univerAPI.importSlideToUnitIdAsync(file)
```

Импорт PPTX в виде локальных данных слайдов:

```ts
const slideData = await univerAPI.importSlideToSnapshotAsync(file)

if (slideData) {
  univerAPI.createPresentation(slideData)
}
```

Экспорт текущей презентации:

```ts
const presentation = univerAPI.getActivePresentation()
const file = await univerAPI.exportSlideBySnapshotAsync(presentation.save())
```

Экспорт серверного юнита со слайдами:

```ts
const file = await univerAPI.exportSlideByUnitIdAsync(unitId)
```
