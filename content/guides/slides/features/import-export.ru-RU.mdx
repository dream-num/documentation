Перед использованием API браузера выполните [интеграцию импорта и экспорта](/server/import-export). Приложение реализует загрузку, конвертацию, опрос задач и скачивание с проверкой доступа. API снимков также требуют сервера конвертации. [Пример Exchange](/server/collaboration/examples#exchange) предназначен для Sheets; поддержку других продуктов и форматов проверяйте отдельно.

## Facade API

В режиме плагинов один раз импортируйте пакет facade:

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
```

Импорт PPTX в серверный юнит:

```ts
const unitId = await univerAPI.importSlideToUnitIdAsync(file)
```

Импорт PPTX в виде локальных данных слайдов:

```ts
const slideData = await univerAPI.importSlideToSnapshotAsync(file)

if (slideData) {
  univerAPI.createPresentation(slideData)
}
```

Экспорт текущей презентации:

```ts
const presentation = univerAPI.getActivePresentation()
const file = await univerAPI.exportSlideBySnapshotAsync(presentation.save())
```

Экспорт серверного юнита со слайдами:

```ts
const file = await univerAPI.exportSlideByUnitIdAsync(unitId)
```
