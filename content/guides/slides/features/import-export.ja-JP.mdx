このページの API は、変換バックエンドが必要です。[ファイル交換統合](/server/import-export) に従って、アップロード、変換、タスクのクエリ、ダウンロードを接続し、ブラウザプラグインの設定を行います。スナップショット API はバックエンドも必要ですが、共同ドキュメントを必要としません。コラボレーション Exchange の例では、Sheet が示すので、ターゲットリリースが必要なファイルタイプをサポートすることを確認してください。

エクスポート失敗時は[ライセンスエラーとタスク失敗の処理](/server/import-export#export-errors)を参照してください。

## 対応形式

このページでは、ブラウザ API が受け入れる形式について説明します。Office ファイルを変換するには、同じドキュメントタイプとフォーマットをサポートするバックエンドが必要です。

| インポート | エクスポート |
| --- | --- |
| `.ppt`, `.pptx` | `.pptx` |

`.ppt`と`.pptx`は、以下のインポートAPIを使用しており、エクスポートは常に`.pptx`を生成します。 ブラウザAPIは`.pptm`、`.ppsx`の、`.ppsm`または`.potx`を受け入れません。 これらのフォーマットのバックエンドサポートは、ブラウザで動作しません。

## Facade API

プラグインモードでは、ファサードパッケージを一度インポートします。

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
```

PPTX をサーバー側 unit としてインポートします。

```ts
const unitId = await univerAPI.importSlideToUnitIdAsync(file)
```

PPTX をローカルの slide データとしてインポートします。

```ts
const slideData = await univerAPI.importSlideToSnapshotAsync(file)

if (slideData) {
  univerAPI.createPresentation(slideData)
}
```

現在の slide deck をエクスポートします。

```ts
const presentation = univerAPI.getActivePresentation()
const file = await univerAPI.exportSlideBySnapshotAsync(presentation.save())
```

サーバー側の slide unit をエクスポートします。

```ts
const file = await univerAPI.exportSlideByUnitIdAsync(unitId)
```

## 組み込みのインポート・エクスポートメニューと UI 操作の削除 [#import-export-ui-migration]

<Callout type="warning" title="注意:">
  バージョン**1.2.0**から、Univerは、組み込みのインポート/エクスポートメニューとUIのインタラクションが不要です。 アンダーリングサービスとファサードAPIは利用できます。
</Callout>

アプリケーションがこれらのメニューとUIインタラクションを必要としている場合、[組み込みのインポート/エクスポートメニューとUIインタラクションのマイグレーション例](https://office.univer.ai/showcase/slides/custom-import-export)は、それらをカスタムプラグインに移行する方法を説明しています。 例には、オンラインで閲覧したりダウンロードしたりできる完全なソースコードが含まれています。
