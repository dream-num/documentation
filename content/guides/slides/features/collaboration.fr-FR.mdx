Plusieurs personnes peuvent éditer la même présentation et voir les changements les uns des autres au fur et à mesure qu'ils se produisent. Compléter [l'intégration de la collaboration](/server/collaboration/browser-integration) pour le moteur, l'authentification, les permissions et le stockage d'abord, puis configurer le [licence](/server/license).

## Configurer et charger un document

Ajouter la configuration Collaboration Client à un éditeur de diapositives existant, après le [Début rapide de la collaboration](/server/collaboration/quick-start). Cet exemple utilise des feuilles, donc le moteur doit créer et persister un document de diapositives et retourner son ID dans le navigateur.

Définissez l’utilisateur courant avant de charger le document. Voir [Intégration collaborative](/server/collaboration/browser-integration).

```ts
import '@univerjs-pro/slides/facade'
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const document = await univerAPI.getCollaboration().loadSlideAsync('your-document-id')
if (!document) throw new Error('Document could not be loaded')
```

Utilisez le même ID lors de la réouverture ou du partage du document. Ne créez jamais un document local vierge à la place du document serveur.

Utilisez [l'état de synchronisation, les relevés et le rétablissement des conflits](/server/collaboration/browser-integration#sync-status) pour construire des indicateurs de sauvegarde et protéger les modifications non reconnues avant un rechargement.

## Suppression du chargement intégré par URL des documents collaboratifs [#url-unit-loader-migration]

<Callout type="warning" title="Remarque">
  La version **1.2.0** a supprimé le chargement intégré d'URL pour les documents collaboratifs. Les paramètres d'URL `unit` et `type` ne sont plus lus automatiquement lorsqu'un document collaboratif se charge.
</Callout>

Si l'application compte sur ce comportement, un plugin personnalisé peut le restaurer.

### Intégrer le plugin personnalisé

Copiez les quatre fichiers ci-dessous dans le projet, en préservant la structure de répertoire suivante :

```text
custom-url-load/
├── plugin.ts
├── controllers/
│   └── data-loader.controller.ts
└── services/
    ├── url.service.ts
    └── web-url.service.ts
```

Après avoir initialisé l'éditeur et les plugins de collaboration, définissez l'utilisateur actuel puis enregistrez `CustomUrlLoadPlugin`.

```ts
import { UserManagerService } from '@univerjs/core'
import { CustomUrlLoadPlugin } from './custom-url-load/plugin'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

univer.registerPlugin(CustomUrlLoadPlugin)
```

Une fois le plugin enregistré, il charge le document, donc appeler `loadSlideAsync()` pour le même document n'est pas nécessaire. Si l'application charge déjà des documents à travers la Facade, gardez l'approche de la section précédente et manipulez les URL comme l'exige l'application.

    ```ts
    import { UniverCollaborationClientPlugin } from '@univerjs-pro/collaboration-client'
    import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
    import { CollaborationDataLoaderController } from './controllers/data-loader.controller'
    import { IURLService } from './services/url.service'
    import { WebURLService } from './services/web-url.service'

    @DependentOn(UniverCollaborationClientPlugin)
    export class CustomUrlLoadPlugin extends Plugin {
      static override pluginName = 'CUSTOM_URL_LOAD_PLUGIN'

      constructor(
        _config: undefined,
        @Inject(Injector) protected override readonly _injector: Injector
      ) {
        super()
      }

      override onStarting(): void {
        this._injector.add([IURLService, { useClass: WebURLService }])
        this._injector.add([CollaborationDataLoaderController])

        this.disposeWithMe(this._injector.get(IURLService))
        this.disposeWithMe(this._injector.get(CollaborationDataLoaderController))
      }
    }
    ```

    ```ts
    import { DataLoaderService } from '@univerjs-pro/collaboration-client'
    import { ILogService, Inject, RxDisposable } from '@univerjs/core'
    import { IURLService } from '../services/url.service'

    /**
     * Charge un document collaboratif à partir des paramètres de l’URL.
     */
    export class CollaborationDataLoaderController extends RxDisposable {
      constructor(
        @IURLService private readonly _urlService: IURLService,
        @ILogService private readonly _logService: ILogService,
        @Inject(DataLoaderService) private readonly _dataLoaderService: DataLoaderService
      ) {
        super()

        const unitId = this._urlService.getParam('unit')
        const type = this._urlService.getParam('type')
        if (!unitId || !type) {
          return
        }

        this._dataLoaderService.loadUnit(unitId, Number(type))
          .catch((error: unknown) => {
            this._logService.error('[CollaborationDataLoaderController]', error)
          })
      }
    }
    ```

    ```ts
      setParam: (key: string, value: string, useReplace?: boolean) => void
      removeParam: (key: string, useReplace?: boolean) => void
    ```

    ```ts
    import type { IURLService } from './url.service'
    import { RxDisposable } from '@univerjs/core'
    import { fromEvent, map, shareReplay, takeUntil } from 'rxjs'

    export class WebURLService extends RxDisposable implements IURLService {
      readonly urlChange$ = fromEvent(window, 'popstate').pipe(
        map(() => undefined),
        takeUntil(this.dispose$),
        shareReplay({ bufferSize: 1, refCount: true })
      )

      getParam(key: string): string | undefined {
        return new URL(window.location.href).searchParams.get(key) ?? undefined
      }

      setParam(key: string, value: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.set(key, value)
        this._updateUrl(url, useReplace)
      }

      removeParam(key: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.delete(key)
        this._updateUrl(url, useReplace)
      }

      private _updateUrl(url: URL, useReplace: boolean): void {
        if (useReplace) {
          window.history.replaceState(window.history.state, '', url.toString())
        } else {
          window.history.pushState(window.history.state, '', url.toString())
        }
      }
    }
    ```

## Vérifier la synchronisation et les autorisations

Ouvrez le même ID dans deux sessions de navigateur indépendantes. Editez du texte ou déplacez un élément dans une session, puis vérifiez l'autre session. Confirmez que le contenu survit aux rechargements de page, aux reconnections et au redémarrage d'un service. Utilisez un compte de visionneur et un compte sans autorisation pour confirmer que le serveur rejette les lectures interdites et écrit.

[Éditer l'historique](/guides/slides/features/edit-history) et [Importation et exportation](/guides/slides/features/import-export) nécessitent une configuration séparée; la collaboration ne les active pas.
