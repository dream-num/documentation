이 페이지의 API는 변환 백엔드가 필요합니다. [파일 교환 통합](/server/import-export)를 따라 업로드, 변환, 작업 쿼리 및 다운로드를 연결하고 브라우저 플러그인을 구성합니다. 스냅 샷 API는 또한 백엔드이 필요하지만 협업 문서가 필요하지 않습니다. 협업 교환 예제는 시트를 보여 주므로 대상 릴리스가 필요한 파일 형식을 지원한다는 것을 확인하십시오.

내보내기 실패는 [라이선스 오류 코드와 작업 실패 처리](/server/import-export#export-errors)를 참고하세요.

## 지원 형식

테이블은이 페이지에 브라우저 API가 허용되는 형식을 설명합니다. Office 파일을 변환하는 것은 동일한 문서 유형과 형식을 지원하는 백엔드가 필요합니다.

| 가져오기 | 내보내기 |
| --- | --- |
| `.ppt`, `.pptx` | `.pptx` |

모두 `.ppt` 및 `.pptx` 아래의 가져 오기 API를 사용하고 항상 `.pptx`을 생산합니다. 브라우저 API는 `.pptm`, `.ppsx`, `.ppsm` 또는 `.potx`을 수용하지 않습니다. 그 형식의 백엔드 지원은 브라우저에서 작동하지 않습니다.

## Facade API

플러그인 모드에서, 한 번의 정면 패키지를 가져 오기 :

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
```

PPTX를 서버 측 unit으로 가져옵니다.

```ts
const unitId = await univerAPI.importSlideToUnitIdAsync(file)
```

PPTX를 로컬 slide 데이터로 가져옵니다.

```ts
const slideData = await univerAPI.importSlideToSnapshotAsync(file)

if (slideData) {
  univerAPI.createPresentation(slideData)
}
```

현재 slide deck을 내보냅니다.

```ts
const presentation = univerAPI.getActivePresentation()
const file = await univerAPI.exportSlideBySnapshotAsync(presentation.save())
```

서버 측 slide unit을 내보냅니다.

```ts
const file = await univerAPI.exportSlideByUnitIdAsync(unitId)
```
