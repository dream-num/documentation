## 支援的格式

下表列出本頁前端 API 支援的格式。Office 檔案轉換還需要後端支援對應的文件類型和格式。

| 匯入 | 匯出 |
| --- | --- |
| `.ppt`, `.pptx` | `.pptx` |

## Facade API

插件模式下需要匯入 facade 套件：

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/slides-exchange-client/facade'
```

將 PPTX 匯入到服務端 unit：

```ts
const unitId = await univerAPI.importSlideToUnitIdAsync(file)
```

將 PPTX 匯入為本地 slide 資料：

```ts
const slideData = await univerAPI.importSlideToSnapshotAsync(file)

if (slideData) {
  univerAPI.createPresentation(slideData)
}
```

匯出目前的 slide deck：

```ts
const presentation = univerAPI.getActivePresentation()
const file = await univerAPI.exportSlideBySnapshotAsync(presentation.save())
```

匯出服務端 slide unit：

```ts
const file = await univerAPI.exportSlideByUnitIdAsync(unitId)
```

## 移除內建匯入匯出選單和 UI 互動 [#import-export-ui-migration]

<Callout type="warning" title="注意事項">
  從 **1.2.0** 版本開始，Univer 移除了內建的匯入匯出選單和 UI 互動，底層服務及 Facade API 繼續保留。
</Callout>

如果你的應用程式需要保留原有的匯入匯出選單和 UI 互動，可以參考[內建匯入匯出選單和 UI 互動遷移方案](https://office.univer.ai/zh-CN/showcase/slides/custom-import-export)，透過自訂外掛完成遷移。範例提供完整原始碼，支援線上檢視和下載。
