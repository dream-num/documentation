Embed permite editar un documento Univer dentro de otro. Una hoja de cálculo se puede colocar en un documento, diapositivas en una tabla, o una base en una pestaña de libro de trabajo. El **documento anfitrión** contiene la incrustación, y el **documento del niño** es el contenido que se refiere. Cada documento mantiene su propio modelo de datos.

## Ubicaciones compatibles

| Anfitrión | Ubicación | Hijos compatibles |
| --- | --- | --- |
| Sheets | Objeto flotante en una hoja, pestaña del libro | Docs, Slides, Boards, Bases |
| Docs | Bloque en el cuerpo del documento | Sheets, Slides, Boards, Bases |
| Slides | Objeto flotante en una página, lista de páginas | Sheets, Docs, Boards, Bases |
| Boards | Objeto flotante en el lienzo | Sheets, Docs, Slides, Bases |
| Bases | Lista de tablas | Sheets, Docs, Slides, Boards |

Los objetos flotantes y los bloques corporales muestran al niño dentro del host, y la edición utiliza las capacidades del producto del niño. Las pestañas y las entradas de la lista convierten al niño en una página a la que se puede cambiar; cuando esa página se activa, el área del menú se transfiere al niño.

<Callout type="warning">
  Las capacidades incorporadas no admiten PDF, incrustando el mismo tipo de producto, o incrustando otro documento dentro de un niño incrustado.
</Callout>

## Registrar los plugins

Ambos productos y su interfaz de usuario deben ejecutarse primero en la misma instancia `Univer`. Embed no reemplaza sus plugins básicos: embedding Docs in Sheets requiere tanto Hojas y Docs. Mantenga las versiones de dependencia alineadas y configura `UniverLicensePlugin` como se describe en [Configuración de la licencia](/server/license) .

```package-install
npm install @univerjs-pro/embed @univerjs-pro/embed-ui
```

Añadir estas importaciones a la aplicación existente y registrar los plugins antes de crear documentos. `univer` es la instancia `Univer` existente.

```ts
import { UniverEmbedPlugin } from '@univerjs-pro/embed'
import { UniverEmbedUIPlugin } from '@univerjs-pro/embed-ui'

import '@univerjs-pro/embed/facade'
import '@univerjs-pro/embed-ui/lib/index.css'

univer.registerPlugin(UniverEmbedPlugin)
univer.registerPlugin(UniverEmbedUIPlugin)
```

Combina la exportación predeterminada de `@univerjs-pro/embed-ui/locale/en-US` en la configuración `locales` existente. Otros idiomas usan su propio paquete local; vea [Internacionalización](/guides/sheets/getting-started/i18n).

`@univerjs-pro/embed` proporciona la relación incrustada, la resolución de referencia y el Facade API. `@univerjs-pro/embed-ui` proporciona los contenedores, la conmutación de enfoque y los menús. `@univerjs-pro/embed-unit-ui` proporciona un visor independiente para un documento de referencia y no es necesario para la incrustación básica.

### Vistas previas de unidades referenciadas

Los presets como `preset-sheets-advanced` no incluyen la vista previa de la unidad referenciada. La selección de referencias de fórmulas y el `ReferencedDataSelector` que usan los datos referenciados requieren `UniverEmbedUIPlugin` de `@univerjs-pro/embed-ui`, registrado con su hoja de estilo y su idioma. Cuando la aplicación se ensambla a partir de un preset, registre el plugin de forma explícita:

```ts
import { UniverEmbedUIPlugin } from '@univerjs-pro/embed-ui'

import '@univerjs-pro/embed-ui/lib/index.css'

univer.registerPlugin(UniverEmbedUIPlugin)
```

Combina `@univerjs-pro/embed-ui/locale/en-US` en la configuración `locales` existente como se describe más arriba. El plugin registra tanto el selector de referencias de fórmulas como el selector de datos referenciados. Sin él, una unidad referenciada no se puede previsualizar ni seleccionar desde las referencias de fórmulas.

## Incrustar un documento en una hoja de cálculo

La siguiente función lleva un cuaderno de trabajo y un documento que ya están cargados en la misma instancia `Univer` e inserta un documento flotante en la hoja de trabajo activa. Utilice el ID real del niño en `ref`; `type=doc` debe coincidir con `unitType`.

```ts
import type { FUniver } from '@univerjs/core/facade'
import type { FDocument } from '@univerjs/docs/facade'
import type { FWorkbook } from '@univerjs/sheets/facade'

import '@univerjs-pro/embed/facade'
import '@univerjs/docs/facade'
import '@univerjs/sheets/facade'

async function embedDocument(
  univerAPI: FUniver,
  workbook: FWorkbook,
  document: FDocument,
) {
  const embed = univerAPI.createEmbed<FDocument>({
    host: {
      unitId: workbook.getId(),
      surface: univerAPI.Enum.FEmbedHostSurface.SheetFloating,
      context: { subUnitId: workbook.getActiveSheet().getSheetId() },
    },
    content: {
      unitType: univerAPI.Enum.UniverInstanceType.UNIVER_DOC,
      ref: `#unit=${encodeURIComponent(document.getId())}&type=doc`,
    },
  })

  await embed.loadAsync()
  return embed
}
```

`createEmbed()` crea la relación y establece su posición en el host. `loadAsync()` carga al niño y devuelve su Facade. Los calentadores deben `await` esta función y manejar fallos de carga. Una referencia local requiere que el documento de destino exista en la instancia actual; un ID por sí solo no crea o descarga el documento.

### Elegir la ubicación

Seleccione `host.surface` de `univerAPI.Enum.FEmbedHostSurface`. `host.context` describe dónde se coloca el contenido en el host.

| Ubicación | Miembro de la enumeración | Parámetros |
| --- | --- | --- |
| Objeto flotante en una hoja | `SheetFloating` | `subUnitId` selecciona la hoja de trabajo; `placement` elige el modo de anclaje, que predetermina a la posición |
| Pestaña del libro | `SheetTab` | `sheetIndex`, `sheetName` |
| Bloque del documento | `DocBlock` | `startIndex`: UTF-16 offset in the `dataStream` of the body; omit it to append to the editable body |
| Objeto flotante de diapositiva | `SlideFloating` | `subUnitId` selecciona la página; `left`, `top`, `width`, `height` definen posición y tamaño |
| Lista de páginas | `SlidePage` | `pageIndex`, `pageName` |
| Objeto flotante de pizarra | `BoardFloating` | `subUnitId` selecciona la página; `left`, `top`, `width`, `height` definen posición y tamaño |
| Lista de tablas | `BaseTable` | `tableIndex`, `tableName` |

Los índices de inserción de las listas son de base cero, y omitiendo un índice apéndice al final. Los límites flotantes utilizan coordenadas modelo de documento en lugar de coordenadas de navegador viewport. No escriba desplazamiento o zoom offsets directamente en estos valores.

### Elegir la vista inicial del hijo

`displayTarget` establece lo que el niño muestra primero, independientemente de dónde el niño se sienta en el host. Pásalo cuando se crea la embajada, o cámbiala más tarde con `embed.setDisplayTarget()`.

| Hijo | Parámetros de la vista inicial |
| --- | --- |
| Sheets | `{ subUnitId: 'sheet-id' }` |
| Slides | `{ pageId: 'page-id' }` |
| Bases | `{ tableId: 'table-id', viewId: 'view-id' }`; también admite `dashboardId` |

Si el objetivo ya no existe, el niño vuelve a su primera vista disponible. La navegación dentro del niño no sobrescribe este defecto. Los doctores y las Juntas no aceptan `displayTarget`.

## Guardar y retirar incrustaciones

Una instantánea de host debe conservar los datos del plugin Embed en `resources` y las posiciones incrustadas en el cuerpo, dibujos o listas del host. La relación almacena una referencia al niño y una vista predeterminada; **no fusiona automáticamente el contenido actual del niño en la instantánea del host**. Las aplicaciones que utilizan el almacenamiento local deben guardar a los niños por separado y asegurar que sus referencias se pueden resolver después de la restauración.

`univerAPI.listEmbeds({ hostUnitId })` enumera las incrustaciones de un host, y `univerAPI.getEmbed({ hostUnitId, embedId })` recupera una sola incrustación. `embed.remove()` elimina la incrustación del host; no elimina los datos persistentes del niño.

## Cargar documentos colaborativos

Para los documentos del servidor, complete [Integración de la colaboración del navegador](/server/collaboration/browser-integration) primero, luego registre el puente de colaboración:

```package-install
npm install @univerjs-pro/collaboration-embed
```

```ts
import { UniverCollaborationEmbedPlugin } from '@univerjs-pro/collaboration-embed'

univer.registerPlugin(UniverCollaborationEmbedPlugin)
```

Este plugin depende de `UniverCollaborationPlugin`, `UniverCollaborationClientPlugin` y `UniverEmbedPlugin`. Carga al niño a través del servicio de instantáneas de colaboración y luego se une a la sesión de colaboración de ese niño. Pase el ID de documento de servidor real en `#unit=...&type=...`; el acceso permanece regulado por la configuración [identidad y autorización](/server/collaboration/identity-and-authorization) existente.

Para utilizar almacenamiento personalizado en lugar del servicio de colaboración, configure `resourceRefUnitProviderRegistrations` en `UniverEmbedPlugin` para que las referencias resuelvan a los casos de documentos.

Las opciones y métodos adicionales se documentan en el [FEmbed API](/reference/facade/embed), [FUniver API](/reference/facade/univer) y [API de plugin de Insertar](/reference/packages/plugins/univerjs-pro/embed).
