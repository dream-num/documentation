Embed позволяет редактировать один документ Univer внутри другого. Электронная таблица может быть помещена в документ, слайды на доске или на базе во вкладке книги. **принимающий документ** содержит вставку, а **Детский документ** - это контент, на который он ссылается. Каждый документ сохраняет свою собственную модель данных.

## Поддерживаемые места вставки

| Родитель | Место вставки | Поддерживаемые дочерние документы |
| --- | --- | --- |
| Sheets | Плавающий объект на листе, вкладка книги | Docs, Slides, Boards, Bases |
| Docs | Блок в теле документа | Sheets, Slides, Boards, Bases |
| Slides | Плавающий объект на странице, список страниц | Sheets, Docs, Boards, Bases |
| Boards | Плавающий объект на холсте | Sheets, Docs, Slides, Bases |
| Bases | Список таблиц | Sheets, Docs, Slides, Boards |

Плавающие объекты и блоки тела отображают ребенка внутри хоста, а редактирование использует возможности детского продукта.Вкладки и записи списка превращают ребенка в страницу, на которую можно переключиться; при активации этой страницы область меню переносится на ребенка.

<Callout type="warning">
  Встроенные возможности не поддерживают PDF, встраивая тот же тип продукта или встраиваясь в другой документ внутри встроенного ребенка.
</Callout>

## Регистрация плагинов

Оба продукта и их пользовательский интерфейс должны сначала работать в одном экземпляре `Univer`. Embed не заменяет их основные плагины: для встраивания Docs в Sheets требуются как Sheets, так и Docs. Поддерживайте согласованность версий зависимостей и настройте `UniverLicensePlugin`, как описано в [Конфигурация лицензии](/server/license) .

```package-install
npm install @univerjs-pro/embed @univerjs-pro/embed-ui
```

Добавьте эти импортные приложения в существующее приложение и зарегистрируйте плагины перед созданием документов. `univer` - существующий экземпляр `Univer`.

```ts
import { UniverEmbedPlugin } from '@univerjs-pro/embed'
import { UniverEmbedUIPlugin } from '@univerjs-pro/embed-ui'

import '@univerjs-pro/embed/facade'
import '@univerjs-pro/embed-ui/lib/index.css'

univer.registerPlugin(UniverEmbedPlugin)
univer.registerPlugin(UniverEmbedUIPlugin)
```

Объединение экспорта `@univerjs-pro/embed-ui/locale/en-US` по умолчанию в существующую конфигурацию `locales`. Другие языки используют свой собственный локальный пакет; см. [Интернационализация](/guides/sheets/getting-started/i18n) .

`@univerjs-pro/embed` обеспечивает встраиваемые отношения, разрешение ссылки и Facade API. `@univerjs-pro/embed-ui` предоставляет контейнеры, переключение фокуса и меню. `@univerjs-pro/embed-unit-ui` предлагает автономный просмотрщик для справочного документа и не требуется для базового встраивания.

### Предпросмотр ссылочного документа

Предустановленные наборы, такие как `preset-sheets-advanced`, не включают предпросмотр ссылочного документа. Для выбора ссылок в формулах и `ReferencedDataSelector`, который используется ссылочными данными, требуется `UniverEmbedUIPlugin` из `@univerjs-pro/embed-ui`, зарегистрированный вместе со своей таблицей стилей и локализацией. Если приложение собирается из предустановленного набора, зарегистрируйте плагин явно:

```ts
import { UniverEmbedUIPlugin } from '@univerjs-pro/embed-ui'

import '@univerjs-pro/embed-ui/lib/index.css'

univer.registerPlugin(UniverEmbedUIPlugin)
```

Объедините `@univerjs-pro/embed-ui/locale/en-US` с существующей конфигурацией `locales`, как описано выше. Плагин регистрирует и средство выбора ссылок в формулах, и селектор ссылочных данных. Без него ссылочный документ нельзя ни просмотреть, ни выбрать из ссылок в формулах.

## Встраивание документа в таблицу

Следующая функция берет рабочую тетрадь и документ, которые уже загружены в тот же экземпляр `Univer` и вставляет плавающий документ в активный рабочий лист.Использовать фактический идентификатор ребенка в `ref`; `type=doc` должен соответствовать `unitType`.

```ts
import type { FUniver } from '@univerjs/core/facade'
import type { FDocument } from '@univerjs/docs/facade'
import type { FWorkbook } from '@univerjs/sheets/facade'

import '@univerjs-pro/embed/facade'
import '@univerjs/docs/facade'
import '@univerjs/sheets/facade'

async function embedDocument(
  univerAPI: FUniver,
  workbook: FWorkbook,
  document: FDocument,
) {
  const embed = univerAPI.createEmbed<FDocument>({
    host: {
      unitId: workbook.getId(),
      surface: univerAPI.Enum.FEmbedHostSurface.SheetFloating,
      context: { subUnitId: workbook.getActiveSheet().getSheetId() },
    },
    content: {
      unitType: univerAPI.Enum.UniverInstanceType.UNIVER_DOC,
      ref: `#unit=${encodeURIComponent(document.getId())}&type=doc`,
    },
  })

  await embed.loadAsync()
  return embed
}
```

`createEmbed()` создает отношения и устанавливает свое положение в хосте. `loadAsync()` загружает ребенка и возвращает его Фасад. Звонящие должны `await` эту функцию и обрабатывать сбои загрузки. Локальная ссылка требует, чтобы целевой документ существовал в текущем случае; один только идентификатор не создает или не загружает документ.

### Выбор места вставки

Выберите `host.surface` из `univerAPI.Enum.FEmbedHostSurface`. `host.context` описывает, где контент размещается в хосте.

| Место | Элемент перечисления | Параметры |
| --- | --- | --- |
| Плавающий объект на листе | `SheetFloating` | `subUnitId` выбирает рабочую таблицу; `placement` выбирает режим якоря, который по умолчанию устанавливается в положение |
| Вкладка книги | `SheetTab` | `sheetIndex`, `sheetName` |
| Блок документа | `DocBlock` | `startIndex`: смещение UTF-16 в `dataStream` тела; опустить его, чтобы добавить к редактируемому телу |
| Плавающий объект на слайде | `SlideFloating` | `subUnitId` выбирает страницу; `left`, `top`, `width`, `height` задают позицию и размер |
| Список страниц слайдов | `SlidePage` | `pageIndex`, `pageName` |
| Плавающий объект на доске | `BoardFloating` | `subUnitId` выбирает страницу; `left`, `top`, `width`, `height` задают позицию и размер |
| Список таблиц базы | `BaseTable` | `tableIndex`, `tableName` |

Индексы вставки для списков основаны на нуле, и опущение индекса прилагается к концу. Плавающие границы используют координаты модели документа, а не координаты порта просмотра браузера. Не записывайте прокрутку или смещение масштаба непосредственно в эти значения.

### Выбор начального представления

`displayTarget` устанавливает то, что ребенок показывает первым, независимо от того, где ребенок сидит в хосте. Передайте его при создании вставки или измените его позже с `embed.setDisplayTarget()`.

| Дочерний документ | Параметры представления |
| --- | --- |
| Sheets | `{ subUnitId: 'sheet-id' }` |
| Slides | `{ pageId: 'page-id' }` |
| Bases | `{ tableId: 'table-id', viewId: 'view-id' }`; также поддерживается `dashboardId` |

Используйте стабильные идентификаторы, а не отображаемые имена. Если цель больше не существует, ребенок возвращается к своему первому доступному виду. Навигация внутри ребенка не перезаписывает этот по умолчанию. Документы и доски не принимают `displayTarget`.

## Сохранение и удаление

Снимок хоста должен сохранять данные плагина Embed в `resources` и положения вставки в корпусе, чертежах или списках хоста. В отношениях хранится ссылка на ребенка и вид по умолчанию; **Он не автоматически объединяет текущее содержимое ребенка в снимок хозяина.**. Приложения, использующие локальное хранилище, должны сохранять детей отдельно и обеспечивать, чтобы их ссылки могли быть решены после восстановления.

`univerAPI.listEmbeds({ hostUnitId })` перечисляет вставки хоста, а `univerAPI.getEmbed({ hostUnitId, embedId })` извлекает одну вставку. `embed.remove()` удаляет вставку из хоста; он не удаляет сохраненные данные ребенка.

## Загрузка совместных документов

Для серверных документов сначала заполните [Интеграция Браузерного Сотрудничества](/server/collaboration/browser-integration), а затем зарегистрируйте мост сотрудничества:

```package-install
npm install @univerjs-pro/collaboration-embed
```

```ts
import { UniverCollaborationEmbedPlugin } from '@univerjs-pro/collaboration-embed'

univer.registerPlugin(UniverCollaborationEmbedPlugin)
```

Этот плагин зависит от `UniverCollaborationPlugin`, `UniverCollaborationClientPlugin` и `UniverEmbedPlugin`. Он загружает ребенка через службу моментального снимка совместной работы, а затем присоединяется к сеансу совместной работы этого ребенка. Передайте реальный идентификатор документа сервера в `#unit=...&type=...`; доступ остается регулируемым существующей настрокой [удостоверение личности и разрешение](/server/collaboration/identity-and-authorization) .

Чтобы использовать пользовательское хранилище вместо службы совместной работы, настройте `resourceRefUnitProviderRegistrations` на `UniverEmbedPlugin`, чтобы ссылки разрешались для документирования экземпляров.

Дополнительные опции и методы задокументированы в [FEmbed API](/reference/facade/embed), [Факультет API](/reference/facade/univer) и [Встроенный плагин API](/reference/packages/plugins/univerjs-pro/embed).
