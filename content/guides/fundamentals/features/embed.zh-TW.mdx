Embed 允許在一種 Univer 文件中編輯另一種 Univer 文件。可以在文件正文中插入表格，在白板上放置幻燈片，或者把多維表格置於工作簿的標籤頁中。承載嵌入的是**父文件**，被引用的是**子文件**，兩者各自保留自己的資料模型。

## 支援的嵌入位置

| 父文件 | 位置 | 支援的子文件 |
| --- | --- | --- |
| Sheets | 工作表浮動物件、活頁簿分頁 | Docs、Slides、Boards、Bases |
| Docs | 正文內容區塊 | Sheets、Slides、Boards、Bases |
| Slides | 頁面浮動物件、頁面清單 | Sheets、Docs、Boards、Bases |
| Boards | 畫布浮動物件 | Sheets、Docs、Slides、Bases |
| Bases | 資料表清單 | Sheets、Docs、Slides、Boards |

浮動物件和正文內容塊在父文件內展示子文件，編輯能力由子文件對應的產品提供。標籤頁和列表入口把子文件變成可切換的頁面；啟用該頁面後，選單區域交由子文件接管。

<Callout type="warning">
  內建能力不支援 PDF、同類產品互嵌，也不支援在嵌入的子文件中再嵌入其他文件。
</Callout>

## 接入外掛

父、子兩種產品及其 UI 必須首先執行在同一個 `Univer` 例項中。Embed 不替代這些產品的基礎外掛：在 Sheets 中嵌入 Docs 時，Sheets 和 Docs 都需要接入。所有依賴版本應保持一致，並按[許可證配置](/server/license)配置 `UniverLicensePlugin`。

```package-install
npm install @univerjs-pro/embed @univerjs-pro/embed-ui
```

在現有應用中新增這些匯入，並在建立文件之前註冊外掛。`univer` 是現有的 `Univer` 例項。

```ts
import { UniverEmbedPlugin } from '@univerjs-pro/embed'
import { UniverEmbedUIPlugin } from '@univerjs-pro/embed-ui'

import '@univerjs-pro/embed/facade'
import '@univerjs-pro/embed-ui/lib/index.css'

univer.registerPlugin(UniverEmbedPlugin)
univer.registerPlugin(UniverEmbedUIPlugin)
```

將 `@univerjs-pro/embed-ui/locale/zh-CN` 的預設匯出合併到現有的 `locales` 配置中。其他語言使用對應的語言套件，參見[國際化](/guides/sheets/getting-started/i18n)。

`@univerjs-pro/embed` 提供嵌入關係、引用解析和 Facade API；`@univerjs-pro/embed-ui` 提供嵌入容器、焦點切換和選單；`@univerjs-pro/embed-unit-ui` 提供獨立的引用文件檢視器，基礎嵌入不需要它。

### 引用文件預覽

`preset-sheets-advanced` 等預設不包含引用文件預覽。公式引用選擇和引用資料使用的 `ReferencedDataSelector` 需要 `@univerjs-pro/embed-ui` 的 `UniverEmbedUIPlugin`，並引入其樣式表和語言套件。應用由預設組裝時，需要明確註冊該外掛：

```ts
import { UniverEmbedUIPlugin } from '@univerjs-pro/embed-ui'

import '@univerjs-pro/embed-ui/lib/index.css'

univer.registerPlugin(UniverEmbedUIPlugin)
```

按上文所述，將 `@univerjs-pro/embed-ui/locale/zh-TW` 合併到現有的 `locales` 配置中。該外掛會同時註冊公式引用選擇器和引用資料選擇器。未註冊時，引用文件無法預覽，也無法在公式引用中選擇。

## 在試算表中嵌入文件

以下函式接收已在同一個 `Univer` 例項中載入的工作簿和文件，並在當前工作表中插入一個浮動文件。`ref` 使用子文件的真實 ID，`type=doc` 必須與 `unitType` 一致。

```ts
import type { FUniver } from '@univerjs/core/facade'
import type { FDocument } from '@univerjs/docs/facade'
import type { FWorkbook } from '@univerjs/sheets/facade'

import '@univerjs-pro/embed/facade'
import '@univerjs/docs/facade'
import '@univerjs/sheets/facade'

async function embedDocument(
  univerAPI: FUniver,
  workbook: FWorkbook,
  document: FDocument,
) {
  const embed = univerAPI.createEmbed<FDocument>({
    host: {
      unitId: workbook.getId(),
      surface: univerAPI.Enum.FEmbedHostSurface.SheetFloating,
      context: { subUnitId: workbook.getActiveSheet().getSheetId() },
    },
    content: {
      unitType: univerAPI.Enum.UniverInstanceType.UNIVER_DOC,
      ref: `#unit=${encodeURIComponent(document.getId())}&type=doc`,
    },
  })

  await embed.loadAsync()
  return embed
}
```

`createEmbed()` 建立嵌入關係，並確定嵌入在父文件中的位置；`loadAsync()` 載入子文件並返回其 Facade。呼叫方應 `await` 該函式，並處理載入失敗。本地引用要求目標文件已存在於當前例項中；僅提供 ID 不會建立或下載文件。

### 選擇嵌入位置

`host.surface` 從 `univerAPI.Enum.FEmbedHostSurface` 中選擇。`host.context` 描述內容在父文件中的插入位置。

| 位置 | 列舉成員 | 位置參數 |
| --- | --- | --- |
| 工作表浮動物件 | `SheetFloating` | `subUnitId` 指定工作表；`placement` 指定錨定方式，預設為 Position |
| 活頁簿分頁 | `SheetTab` | `sheetIndex`、`sheetName` |
| 文件正文區塊 | `DocBlock` | `startIndex` 為正文 `dataStream` 的 UTF-16 偏移量，省略則附加至可編輯正文末尾 |
| 簡報浮動物件 | `SlideFloating` | `subUnitId` 指定頁面；`left`、`top`、`width`、`height` 指定位置與尺寸 |
| 簡報頁面清單 | `SlidePage` | `pageIndex`、`pageName` |
| 白板浮動物件 | `BoardFloating` | `subUnitId` 指定頁面；`left`、`top`、`width`、`height` 指定位置與尺寸 |
| 多維表格資料表清單 | `BaseTable` | `tableIndex`、`tableName` |

列表的插入索引從 0 開始，省略索引則追加到末尾。浮動物件使用文件模型座標，而不是瀏覽器視口座標，不要將滾動或縮放偏移直接寫入這些值。

### 指定子文件的預設檢視

`displayTarget` 決定子文件初始顯示的內容，與子文件在父文件中的位置無關。可在建立嵌入時傳入，也可稍後透過 `embed.setDisplayTarget()` 更改。

| 子文件 | 預設檢視參數 |
| --- | --- |
| Sheets | `{ subUnitId: 'sheet-id' }` |
| Slides | `{ pageId: 'page-id' }` |
| Bases | `{ tableId: 'table-id', viewId: 'view-id' }`，也支援 `dashboardId` |

應使用穩定的 ID，而不是顯示名稱。目標不存在時，子文件會回退到第一個可用的檢視。在子文件內部的導航不會覆蓋該預設值。Docs 和 Boards 不接受 `displayTarget`。

## 儲存與移除

父文件快照必須保留 `resources` 中的 Embed 外掛資料，以及正文、繪圖或列表中的嵌入位置。嵌入關係只記錄子文件引用和預設檢視，**不會把子文件的最新內容自動合併進父文件快照**。資料儲存在本地時，應用必須單獨儲存子文件，並確保恢復後引用仍可解析。

`univerAPI.listEmbeds({ hostUnitId })` 列出父文件的所有嵌入，`univerAPI.getEmbed({ hostUnitId, embedId })` 取得其中一條。`embed.remove()` 將嵌入從父文件移除，但不會刪除子文件已持久化的資料。

## 載入協同文件

引用伺服器端文件時，請先完成[協同瀏覽器接入](/server/collaboration/browser-integration)，再註冊協同橋接外掛：

```package-install
npm install @univerjs-pro/collaboration-embed
```

```ts
import { UniverCollaborationEmbedPlugin } from '@univerjs-pro/collaboration-embed'

univer.registerPlugin(UniverCollaborationEmbedPlugin)
```

該外掛依賴 `UniverCollaborationPlugin`、`UniverCollaborationClientPlugin` 和 `UniverEmbedPlugin`。它透過協同快照服務載入子文件，然後加入該子文件的協同會話。`#unit=...&type=...` 中應填寫伺服器端的真實文件 ID；能否訪問仍取決於現有的[身分與授權](/server/collaboration/identity-and-authorization)配置。

如果資料來自自建儲存而不是協同服務，可在 `UniverEmbedPlugin` 上配置 `resourceRefUnitProviderRegistrations`，使引用解析為對應的文件例項。

更多配置和方法請參閱 [FEmbed API](/reference/facade/embed)、[FUniver API](/reference/facade/univer) 和 [Embed 外掛 API](/reference/packages/plugins/univerjs-pro/embed)。
