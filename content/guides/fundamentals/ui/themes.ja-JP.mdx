## 公式テーマの使用

`@univerjs/themes` は `defaultTheme`（`blueTheme` としても利用可能）、`darkBlueTheme`、`greenTheme`、`orangeTheme`、`purpleTheme`、`redTheme`、`yellowTheme` をエクスポートします。

<Callout>テーマが通過しない場合、Univerは`defaultTheme`に戻って落ちます。</Callout>

### テーマプラグインのインストール

#### プリセットモード

プリセットモードでは、`@univerjs/presets` からテーマをインポートします。

```typescript
// import { defaultTheme } from "@univerjs/presets";
import { yellowTheme } from '@univerjs/presets'

const { univer } = createUniver({
  theme: yellowTheme,
  // theme: defaultTheme,
})
```

#### プラグインモード

プラグインモードでは、テーマは`@univerjs/themes`によって提供されます。そのパッケージを最初にインストールします。

```package-install
npm install @univerjs/themes
```

```typescript
import { yellowTheme } from '@univerjs/themes'
// import { defaultTheme } from "@univerjs/themes";

const univer = new Univer({
  theme: yellowTheme,
  // theme: defaultTheme,
})
```

## テーマのカスタマイズ

テーマは、`Theme`インターフェイスに準拠するオブジェクトです。 `defaultTheme`から始まり、変更が必要なフィールドをオーバーライドし、結果をUniverに渡します。 [テーマ型参照](https://docs.univer.ai/reference/types/theme)は、デフォルトの変数が定義される方法の文書を文書化します。

```typescript title="custom-theme.ts"
import type { Theme } from '@univerjs/themes';
import { defaultTheme } from '@univerjs/themes';

export const customTheme: Theme = {
  ...defaultTheme,
  primary: {
    ...defaultTheme.primary,
    50: '#F5F3FF', 100: '#EDE9FE', 200: '#DDD6FE', 300: '#C4B5FD',
    400: '#A78BFA', 500: '#8B5CF6', 600: '#7C3AED', 700: '#6D28D9',
    800: '#5B21B6', 900: '#4C1D95',
  },
};
```

```typescript
// ここでカスタムテーマをインポートします
import { customTheme } from './custom-theme'

const univer = new Univer({
  theme: customTheme,
})
```

## ダークモード

`darkMode`を`true`にセットして、ダークモードでUniverを起動します。

```typescript
new Univer({
  darkMode: true,
})
```

### Facade API

Facade APIは、実行時にダークモードを切り替えることもできます。

```typescript
import { darkBlueTheme } from '@univerjs/themes'

univerAPI.setTheme(darkBlueTheme)
univerAPI.toggleDarkMode(true)
const currentTheme = univerAPI.getCurrentTheme()
console.log(univerAPI.isDarkMode(), currentTheme)

univerAPI.toggleDarkMode(false)
```
