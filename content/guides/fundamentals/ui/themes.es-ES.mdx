## Uso de Official Temas

`@univerjs/themes` exporta `defaultTheme` (también como `blueTheme`), `darkBlueTheme`, `greenTheme`, `orangeTheme`, `purpleTheme`, `redTheme` y `yellowTheme`.

<Callout>Si no se pasa ningún tema, Univer vuelve a `defaultTheme`.</Callout>

### Instalación de complementos de tema

#### Modo preestablecido

En modo preestablecido, importar temas desde `@univerjs/presets`:

```typescript
// import { defaultTheme } from "@univerjs/presets";
import { yellowTheme } from '@univerjs/presets'

const { univer } = createUniver({
  theme: yellowTheme,
  // theme: defaultTheme,
})
```

#### Modo complemento

En modo plugin, los temas son proporcionados por `@univerjs/themes`. Instalar el paquete primero.

```package-install
npm install @univerjs/themes
```

```typescript
import { yellowTheme } from '@univerjs/themes'
// import { defaultTheme } from "@univerjs/themes";

const univer = new Univer({
  theme: yellowTheme,
  // theme: defaultTheme,
})
```

## Personalizar temas

Un tema es un objeto que se ajusta a la interfaz `Theme`. Comienza desde `defaultTheme`, anula los campos que necesitan cambiar, y pasa el resultado a Univer . El [tipo de referencia](https://docs.univer.ai/reference/types/theme) documenta cómo se definen las variables predeterminadas.

```typescript title="custom-theme.ts"
import type { Theme } from '@univerjs/themes';
import { defaultTheme } from '@univerjs/themes';

export const customTheme: Theme = {
  ...defaultTheme,
  primary: {
    ...defaultTheme.primary,
    50: '#F5F3FF', 100: '#EDE9FE', 200: '#DDD6FE', 300: '#C4B5FD',
    400: '#A78BFA', 500: '#8B5CF6', 600: '#7C3AED', 700: '#6D28D9',
    800: '#5B21B6', 900: '#4C1D95',
  },
};
```

```typescript
// Import your custom theme here
import { customTheme } from './custom-theme'

const univer = new Univer({
  theme: customTheme,
})
```

## Modo oscuro

Establecer `darkMode` a `true` para iniciar Univer en modo oscuro.

```typescript
new Univer({
  darkMode: true,
})
```

### API de Facade

El Facade API también puede cambiar el modo oscuro en tiempo de ejecución.

```typescript
import { darkBlueTheme } from '@univerjs/themes'

univerAPI.setTheme(darkBlueTheme)
univerAPI.toggleDarkMode(true)
const currentTheme = univerAPI.getCurrentTheme()
console.log(univerAPI.isDarkMode(), currentTheme)

univerAPI.toggleDarkMode(false)
```
