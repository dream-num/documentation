## Utiliser les thèmes officiels

`@univerjs/themes` exporte `defaultTheme` (également sous le nom `blueTheme`), `darkBlueTheme`, `greenTheme`, `orangeTheme`, `purpleTheme`, `redTheme` et `yellowTheme`.

<Callout>Si aucun thème n'est passé, Univer revient à `defaultTheme`.</Callout>

### Installer les plugins de thème

#### Mode preset

En mode préréglé, importer les thèmes de `@univerjs/presets` :

```typescript
// import { defaultTheme } from "@univerjs/presets";
import { yellowTheme } from '@univerjs/presets'

const { univer } = createUniver({
  theme: yellowTheme,
  // theme: defaultTheme,
})
```

#### Mode plugin

En mode plugin, les thèmes sont fournis par `@univerjs/themes`. Installez ce paquet d'abord.

```package-install
npm install @univerjs/themes
```

```typescript
import { yellowTheme } from '@univerjs/themes'
// import { defaultTheme } from "@univerjs/themes";

const univer = new Univer({
  theme: yellowTheme,
  // theme: defaultTheme,
})
```

## Personnaliser les thèmes

Un thème est un objet qui se conforme à l'interface `Theme`. Démarrez à partir de `defaultTheme`, remplacez les champs qui doivent changer et passez le résultat à Univer . Le [type de thème référence](https://docs.univer.ai/reference/types/theme) documente comment les variables par défaut sont définies.

```typescript title="custom-theme.ts"
import type { Theme } from '@univerjs/themes';
import { defaultTheme } from '@univerjs/themes';

export const customTheme: Theme = {
  ...defaultTheme,
  primary: {
    ...defaultTheme.primary,
    50: '#F5F3FF', 100: '#EDE9FE', 200: '#DDD6FE', 300: '#C4B5FD',
    400: '#A78BFA', 500: '#8B5CF6', 600: '#7C3AED', 700: '#6D28D9',
    800: '#5B21B6', 900: '#4C1D95',
  },
};
```

```typescript
// Import your custom theme here
import { customTheme } from './custom-theme'

const univer = new Univer({
  theme: customTheme,
})
```

## Mode sombre

Définissez `darkMode` à `true` pour démarrer Univer en mode sombre.

```typescript
new Univer({
  darkMode: true,
})
```

### Facade API

Le Facade API peut également basculer en mode noir au moment de l'exécution.

```typescript
import { darkBlueTheme } from '@univerjs/themes'

univerAPI.setTheme(darkBlueTheme)
univerAPI.toggleDarkMode(true)
const currentTheme = univerAPI.getCurrentTheme()
console.log(univerAPI.isDarkMode(), currentTheme)

univerAPI.toggleDarkMode(false)
```
