## 공식 테마 사용

`@univerjs/themes`는 `defaultTheme`(`blueTheme` 별칭), `darkBlueTheme`, `greenTheme`, `orangeTheme`, `purpleTheme`, `redTheme`, `yellowTheme`를 내보냅니다.

<Callout>테마가 통과되지 않은 경우, Univer는 `defaultTheme`로 돌아갑니다.</Callout>

### 테마 플러그인 설치

#### 프리셋 모드

미리 설정 모드에서는 `@univerjs/presets`에서 테마를 가져옵니다.

```typescript
// import { defaultTheme } from "@univerjs/presets";
import { yellowTheme } from '@univerjs/presets'

const { univer } = createUniver({
  theme: yellowTheme,
  // theme: defaultTheme,
})
```

#### 플러그인 모드

플러그인 모드에서, 테마는 `@univerjs/themes`에 의해 제공됩니다. 먼저 패키지를 설치.

```package-install
npm install @univerjs/themes
```

```typescript
import { yellowTheme } from '@univerjs/themes'
// import { defaultTheme } from "@univerjs/themes";

const univer = new Univer({
  theme: yellowTheme,
  // theme: defaultTheme,
})
```

## 테마 맞춤 설정

테마는 `Theme` 인터페이스를 준수하는 객체입니다. `defaultTheme`에서 시작하면 변경해야 할 필드를 무시하고 Univer로 결과를 전달합니다. [테마 유형 참고](https://docs.univer.ai/reference/types/theme) 문서는 기본 변수가 정의되는 방식입니다.

```typescript title="custom-theme.ts"
import type { Theme } from '@univerjs/themes';
import { defaultTheme } from '@univerjs/themes';

export const customTheme: Theme = {
  ...defaultTheme,
  primary: {
    ...defaultTheme.primary,
    50: '#F5F3FF', 100: '#EDE9FE', 200: '#DDD6FE', 300: '#C4B5FD',
    400: '#A78BFA', 500: '#8B5CF6', 600: '#7C3AED', 700: '#6D28D9',
    800: '#5B21B6', 900: '#4C1D95',
  },
};
```

```typescript
// Import your custom theme here
import { customTheme } from './custom-theme'

const univer = new Univer({
  theme: customTheme,
})
```

## 다크 모드

`darkMode`를 `true`로 설정하여 어두운 모드에서 Univer을 시작합니다.

```typescript
new Univer({
  darkMode: true,
})
```

### Facade API

Facade API는 또한 런타임에 어두운 모드를 전환할 수 있습니다.

```typescript
import { darkBlueTheme } from '@univerjs/themes'

univerAPI.setTheme(darkBlueTheme)
univerAPI.toggleDarkMode(true)
const currentTheme = univerAPI.getCurrentTheme()
console.log(univerAPI.isDarkMode(), currentTheme)

univerAPI.toggleDarkMode(false)
```
