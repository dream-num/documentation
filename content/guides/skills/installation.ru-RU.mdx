---
title: Установка Skill для Agent
icon: Download
---

Дайте вашему Agent доступ к актуальной документации Office SDK при подключении редактора, совместной работы и преобразования файлов. Начните с `build-with-univer` из официального репозитория Skills.

## Установить в проект

```bash
npx skills add dream-num/skills --skill build-with-univer
```

Запускайте команду в проекте, открытом Agent. Установка локальная; добавляйте `-g` только для всех проектов. Выберите Agent через `-a codex` или `-a claude-code`; `-y` отключает интерактивные вопросы.

## Проверить установку

```bash
npx skills list
```

В списке должен быть `build-with-univer`. После установки при необходимости перезапустите сеанс Agent и поручите ему задачу с этим Skill:

```text
Используй build-with-univer и добавь в этот проект редактируемую таблицу Univer. Внеси пять строк продаж, вычисли суммы строк и общий итог формулами и объясни запуск и проверку. Прочитай актуальную документацию SDK и используй одинаковую версию всех пакетов Univer.
```

## Если Agent не находит Skill

Устанавливайте в проект, открытый Agent. Проверьте наличие `SKILL.md` по пути из вывода установщика и поддержку Skills вашим Agent. Используйте команду выше вместо старого репозитория `univer-sdk-skills`.

[Исходный код и ручная установка](https://github.com/dream-num/skills#install)
