## Установка через skills.sh (рекомендуется)

Установите все навыки одной командой:

```bash
npx skills add dream-num/univer-sdk-skills
```

Чтобы установить определённый навык:

```bash
npx skills add dream-num/univer-sdk-skills --skill univer-integrate
npx skills add dream-num/univer-sdk-skills --skill univer-plugin-dev
npx skills add dream-num/univer-sdk-skills --skill univer-pro-integrate
npx skills add dream-num/univer-sdk-skills --skill univer-node-backend
```

Чтобы установить навыки глобально (для всех проектов):

```bash
npx skills add dream-num/univer-sdk-skills --global
```

При локальной установке в проект `skills.sh` автоматически определяет агента и копирует навыки в нужный каталог.

## Установка вручную

Клонируйте репозиторий, затем создайте символические ссылки на каталоги навыков в каталоге навыков вашего агента или скопируйте их туда:

```bash
git clone https://github.com/dream-num/univer-sdk-skills.git
cd univer-sdk-skills

# Symlink (recommended for development)
ln -s $(pwd)/skills/univer-integrate ~/.agents/skills/univer-integrate
ln -s $(pwd)/skills/univer-plugin-dev ~/.agents/skills/univer-plugin-dev
ln -s $(pwd)/skills/univer-pro-integrate ~/.agents/skills/univer-pro-integrate
ln -s $(pwd)/skills/univer-node-backend ~/.agents/skills/univer-node-backend

# Or copy
# cp -r skills/univer-integrate ~/.agents/skills/
# cp -r skills/univer-plugin-dev ~/.agents/skills/
# cp -r skills/univer-pro-integrate ~/.agents/skills/
# cp -r skills/univer-node-backend ~/.agents/skills/
```

### Каталоги навыков агентов

| Агент | Каталог навыков |
|---|---|
| Claude Code | `~/.claude/skills/` |
| Cursor | `~/.cursor/skills/` |
| Gemini CLI | `~/.gemini/skills/` |
| Kimi Code CLI | `~/.kimi/skills/` |
| Универсальный (для любого агента) | `~/.agents/skills/` |

Для локальной установки в проект используйте каталог соответствующего агента в корне проекта (например, `.claude/skills/` или `.agents/skills/`).

## Проверка

После установки навыков запустите проверку:

```bash
python3 scripts/validate.py skills/univer-integrate
python3 scripts/validate.py skills/univer-plugin-dev
python3 scripts/validate.py skills/univer-pro-integrate
python3 scripts/validate.py skills/univer-node-backend
```

## Проверка на реальных задачах

Чтобы убедиться, что навык работает на задачах, приближённых к реальным:

```bash
cd ~/univer-sdk-skills
# Test scaffold script
npx tsx skills/univer-plugin-dev/scripts/scaffold-plugin.ts test-plugin --path /tmp
```
