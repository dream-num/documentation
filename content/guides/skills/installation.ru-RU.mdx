Для подключения Web SDK, инициализации редактора и работы с Facade API в существующем приложении установите `univer-integrate`. Команда ниже сохраняет имя Skill и использует текущий официальный репозиторий `dream-num/skills`.

## Установить в проект

```bash
npx skills add dream-num/skills --skill univer-integrate
```

Запускайте команду в проекте, открытом Agent. Установка локальная; добавляйте `-g` только для всех проектов. Выберите Agent через `-a codex` или `-a claude-code`; `-y` отключает интерактивные вопросы.

## Проверить установку

```bash
npx skills list
```

В списке должен быть `univer-integrate`. После установки при необходимости перезапустите сеанс Agent и поручите ему задачу с этим Skill:

```text
Используй univer-integrate и добавь в этот проект редактируемую таблицу Univer. Внеси пять строк продаж, вычисли суммы строк и общий итог формулами и объясни запуск и проверку. Прочитай актуальную документацию SDK и используй одинаковую версию всех пакетов Univer.
```

## Для нового приложения Office

Если вы начинаете с требований и выбираете сочетание Web SDK, Server SDK и AI SDK, можно также установить `build-with-univer`. Оно охватывает планирование и создание приложения Office в целом.

```bash
npx skills add dream-num/skills --skill build-with-univer
```

## Если Agent не находит Skill

Устанавливайте в проект, открытый Agent. Проверьте наличие `SKILL.md` по пути из вывода установщика и поддержку Skills вашим Agent.

Если старое руководство использует `dream-num/univer-sdk-skills`, команда текущего репозитория выше установит тот же Skill `univer-integrate`. Проверьте его базовую версию SDK и следуйте актуальной документации и версиям, установленным в проекте.

[Исходный код univer-integrate](https://github.com/dream-num/skills/tree/main/skills/univer-integrate)
