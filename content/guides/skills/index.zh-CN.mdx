## 什么是 univer-sdk-skills

`univer-sdk-skills` 是一组面向 AI Agent 的 [Univer](https://github.com/dream-num/univer) 开发技能。这些技能帮助 AI Agent 协助开发者将 Univer 嵌入到 Web 应用中、集成企业级功能、在 Node.js 后端运行 Univer，以及开发自定义插件。

每个技能遵循标准技能格式，包含带有 frontmatter 触发器的 `SKILL.md` 文件、详细说明、参考文档和可复用的代码示例。

## 目标受众

- **外部应用开发者**：将 Univer 电子表格/文档嵌入到自己的前端项目中
- **Pro 用户**：集成 Univer Pro 企业级功能（协作、导入/导出、打印、数据透视表）
- **后端开发者**：在 Node.js 中运行 Univer，进行无头报表生成和服务端数据处理
- **插件开发者**：为 Univer 构建自定义功能扩展
- **AI Agent**：需要准确理解 Univer 架构和 API 以协助开发者

## 版本兼容性

这些技能专为 Univer 开源版本（`@univerjs/*` 包）设计。随着 Univer 版本迭代，部分 API 可能会发生变化。建议将这些技能与 [Univer 官方文档](https://docs.univer.ai/) 一起使用。

所有 `@univerjs/*` 和 `@univerjs-pro/*` 包必须保持**相同版本**。切勿混用不同版本——这是最常见的运行时错误来源。
