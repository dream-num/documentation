에디터, 협업 또는 파일 변환을 통합할 때 코딩 Agent가 현재 Office SDK 문서를 참조하도록 설정합니다. 공식 Skills 저장소의 `build-with-univer`로 시작하세요.

## 프로젝트에 설치

```bash
npx skills add dream-num/skills --skill build-with-univer
```

Agent가 작업 중인 프로젝트에서 실행하세요. 기본적으로 현재 프로젝트에 설치합니다. 모든 프로젝트에서 사용할 때만 `-g`를 추가하세요. `-a codex` 또는 `-a claude-code`로 Agent를 선택하고 `-y`로 비대화형 설치를 할 수 있습니다.

## 설치 확인

```bash
npx skills list
```

목록에 `build-with-univer`가 표시되어야 합니다. 필요한 경우 설치 후 Agent 세션을 다시 열고 이 Skill로 다음 작업을 요청하세요.

```text
build-with-univer를 사용해 현재 프로젝트에 편집 가능한 Univer 시트를 추가하세요. 판매 샘플 데이터 5행을 넣고 각 행의 금액과 총합을 수식으로 계산하세요. 실행 및 검증 방법도 알려 주세요. 현재 SDK 문서를 읽고 모든 Univer 패키지 버전을 동일하게 유지하세요.
```

## Agent가 Skill을 찾지 못하는 경우

Agent가 연 프로젝트와 설치 위치가 같은지, 설치 프로그램이 출력한 경로에 `SKILL.md`가 있는지, Agent가 Skills를 지원하는지 확인하세요. 기존 `univer-sdk-skills` 저장소보다 위 명령을 권장합니다.

[소스 및 수동 설치](https://github.com/dream-num/skills#install)
