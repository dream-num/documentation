기존 앱에 Web SDK를 통합하고 에디터를 초기화하거나 Facade API를 사용하려면 `univer-integrate`를 설치하세요. 아래 명령은 Skill 이름을 유지하면서 현재 공식 저장소 `dream-num/skills`를 사용합니다.

## 프로젝트에 설치

```bash
npx skills add dream-num/skills --skill univer-integrate
```

Agent가 작업 중인 프로젝트에서 실행하세요. 기본적으로 현재 프로젝트에 설치합니다. 모든 프로젝트에서 사용할 때만 `-g`를 추가하세요. `-a codex` 또는 `-a claude-code`로 Agent를 선택하고 `-y`로 비대화형 설치를 할 수 있습니다.

## 설치 확인

```bash
npx skills list
```

목록에 `univer-integrate`가 표시되어야 합니다. 필요한 경우 설치 후 Agent 세션을 다시 열고 이 Skill로 다음 작업을 요청하세요.

```text
univer-integrate를 사용해 현재 프로젝트에 편집 가능한 Univer 시트를 추가하세요. 판매 샘플 데이터 5행을 넣고 각 행의 금액과 총합을 수식으로 계산하세요. 실행 및 검증 방법도 알려 주세요. 현재 SDK 문서를 읽고 모든 Univer 패키지 버전을 동일하게 유지하세요.
```

## 요구 사항부터 새 앱을 만드는 경우

요구 사항을 정리하거나 Web SDK, Server SDK, AI SDK의 조합을 선택하는 단계라면 `build-with-univer`도 설치할 수 있습니다. Office 앱의 계획과 구축을 더 폭넓게 안내합니다.

```bash
npx skills add dream-num/skills --skill build-with-univer
```

## Agent가 Skill을 찾지 못하는 경우

Agent가 연 프로젝트와 설치 위치가 같은지, 설치 프로그램이 출력한 경로에 `SKILL.md`가 있는지, Agent가 Skills를 지원하는지 확인하세요.

기존 튜토리얼의 `dream-num/univer-sdk-skills` 명령을 사용했다면 위의 현재 저장소 명령으로 같은 `univer-integrate`를 설치할 수 있습니다. Skill의 SDK 기준 버전을 확인하고 현재 문서와 프로젝트에 설치된 버전을 따르세요.
