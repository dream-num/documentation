## 什麼是 univer-sdk-skills

`univer-sdk-skills` 是一組面向 AI Agent 的 [Univer](https://github.com/dream-num/univer) 開發技能。這些技能幫助 AI Agent 協助開發者將 Univer 嵌入到 Web 應用中、整合企業級功能、在 Node.js 後端運行 Univer，以及開發自訂外掛。

每個技能遵循標準技能格式，包含帶有 frontmatter 觸發器的 `SKILL.md` 檔案、詳細說明、參考文件和可複用的程式碼範例。

## 目標受眾

- **外部應用開發者**：將 Univer 試算表/文件嵌入到自己的前端專案中
- **Pro 使用者**：整合 Univer Pro 企業級功能（協作、匯入/匯出、列印、樞紐分析表）
- **後端開發者**：在 Node.js 中運行 Univer，進行無頭報表生成和伺服器端資料處理
- **外掛開發者**：為 Univer 建構自訂功能擴展
- **AI Agent**：需要準確理解 Univer 架構和 API 以協助開發者

## 版本相容性

這些技能專為 Univer 開源版本（`@univerjs/*` 套件）設計。隨著 Univer 版本迭代，部分 API 可能會發生變化。建議將這些技能與 [Univer 官方文件](https://docs.univer.ai/) 一起使用。

所有 `@univerjs/*` 和 `@univerjs-pro/*` 套件必須保持**相同版本**。切勿混用不同版本——這是最常見的執行階段錯誤來源。
