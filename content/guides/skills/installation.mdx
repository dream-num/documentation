icon: Download
---

For embedding Web SDK and using its Facade API in an existing application, install `univer-integrate`. The current command below keeps that Skill name and uses the official `dream-num/skills` repository.

## Install in your project

```bash
npx skills add dream-num/skills --skill univer-integrate
```

Run this in the project where the agent works. It installs the Skill locally; add `-g` only if you want it available across projects. Use `-a codex` or `-a claude-code` to select an agent, and `-y` for a non-interactive install.

## Confirm the installation

```bash
npx skills list
```

The command lists `univer-integrate`. After installation, restart the agent session if needed and ask it to use the Skill for this task:

```text
Using univer-integrate, add an editable Univer spreadsheet to this project. Fill five rows of sample sales data, calculate each row total and the grand total with formulas, and tell me how to run and verify it. Read the current SDK documentation and keep all Univer packages on the same version.
```

## For a new Office application

If you are starting from a requirement and need help choosing how Web SDK, Server SDK and AI SDK work together, you can also install `build-with-univer`. It provides broader guidance for planning and building an Office application.

```bash
npx skills add dream-num/skills --skill build-with-univer
```

## If the agent cannot find the Skill

Install in the same project the agent has open. Check that `SKILL.md` exists in the installation path printed by the installer, and that your agent supports Skills.

For older tutorials that use `dream-num/univer-sdk-skills`, use the current repository command above to install the same `univer-integrate` Skill. Check its documented SDK baseline and follow the current docs and your project’s installed versions.
