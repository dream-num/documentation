---
title: Install an Agent Skill
icon: Download
---

Let your coding agent use current Office SDK documentation when integrating an editor, connecting collaboration or adding file conversion. Start with `build-with-univer` from the official Skills repository.

## Install in your project

```bash
npx skills add dream-num/skills --skill build-with-univer
```

Run this in the project where the agent works. It installs the Skill locally; add `-g` only if you want it available across projects. Use `-a codex` or `-a claude-code` to select an agent, and `-y` for a non-interactive install.

## Confirm the installation

```bash
npx skills list
```

The command lists `build-with-univer`. After installation, restart the agent session if needed and ask it to use the Skill for this task:

```text
Using build-with-univer, add an editable Univer spreadsheet to this project. Fill five rows of sample sales data, calculate each row total and the grand total with formulas, and tell me how to run and verify it. Read the current SDK documentation and keep all Univer packages on the same version.
```

## If the agent cannot find the Skill

Install in the same project the agent has open. Check that `SKILL.md` exists in the installation path printed by the installer, and that your agent supports Skills. The older `univer-sdk-skills` repository is not the recommended starting point; use the command above.
