## univer-sdk-skills とは

`univer-sdk-skills` は、AI Agent 向けの [Univer](https://github.com/dream-num/univer) 開発スキル集です。これらのスキルは、AI Agent が開発者を支援して、Univer を Web アプリケーションに埋め込んだり、エンタープライズ機能を統合したり、Node.js バックエンドで Univer を実行したり、カスタムプラグインを開発したりするのに役立ちます。

各スキルは標準的なスキル形式に従っており、frontmatter トリガー、詳細な説明、参考ドキュメント、再利用可能なコード例を含む `SKILL.md` ファイルが含まれています。

## 対象ユーザー

- **外部アプリケーション開発者**: 独自のフロントエンドプロジェクトに Univer スプレッドシート/ドキュメントを埋め込む
- **Pro ユーザー**: Univer Pro のエンタープライズ機能（コラボレーション、インポート/エクスポート、印刷、ピボットテーブル）を統合する
- **バックエンド開発者**: Node.js で Univer を実行し、ヘッドレスレポート生成とサーバーサイドデータ処理を行う
- **プラグイン開発者**: Univer のカスタム機能拡張を構築する
- **AI Agent**: Univer のアーキテクチャと API を正確に理解して開発者を支援する必要がある

## バージョン互換性

これらのスキルは、Univer のオープンソースバージョン（`@univerjs/*` パッケージ）向けに設計されています。Univer のバージョンが更新されるにつれて、一部の API は変更される可能性があります。これらのスキルは [Univer 公式ドキュメント](https://docs.univer.ai/) と併用することをお勧めします。

すべての `@univerjs/*` および `@univerjs-pro/*` パッケージは**同じバージョン**で保持する必要があります。異なるバージョンを混在させないでください。これは最も一般的な実行時エラーの原因です。
