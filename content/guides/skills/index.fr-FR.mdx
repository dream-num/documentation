## Qu'est-ce que univer-sdk-skills ?

`univer-sdk-skills` est un ensemble de compétences de développement pour [Univer](https://github.com/dream-num/univer), destiné aux agents d'IA. Ces compétences permettent aux agents d'IA d'aider les développeurs à intégrer Univer dans des applications web, à ajouter des fonctionnalités d'entreprise, à exécuter Univer dans des backends Node.js et à développer des plugins personnalisés.

Chaque compétence respecte le format standard et comprend un fichier `SKILL.md` avec des déclencheurs dans le frontmatter, des instructions détaillées, des documents de référence et des exemples de code réutilisables.

## Public cible

- **Développeurs d'applications externes** : intégration de feuilles de calcul et de documents Univer dans leurs propres projets frontend
- **Utilisateurs Pro** : intégration des fonctionnalités d'entreprise d'Univer Pro (collaboration, import-export, impression et tableaux croisés dynamiques)
- **Développeurs backend** : exécution d'Univer dans Node.js pour générer des rapports sans interface graphique et traiter des données côté serveur
- **Développeurs de plugins** : création d'extensions fonctionnelles personnalisées pour Univer
- **Agents d'IA** : compréhension précise de l'architecture et des API d'Univer afin d'aider les développeurs

## Compatibilité des versions

Ces compétences sont conçues pour la version open source d'Univer (packages `@univerjs/*`). Certaines API peuvent évoluer au fil des versions d'Univer. Il est recommandé d'utiliser ces compétences avec la [documentation officielle d'Univer](https://docs.univer.ai/).

Tous les packages `@univerjs/*` et `@univerjs-pro/*` doivent impérativement utiliser la **même version**. Ne mélangez jamais des versions différentes : c'est la cause la plus fréquente d'erreurs d'exécution.
