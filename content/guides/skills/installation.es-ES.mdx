---
title: Instalar un Skill para Agent
icon: Download
---

Permite que tu Agent de programación consulte la documentación actual de Office SDK al integrar un editor, colaboración o conversión de archivos. Empieza por `build-with-univer` del repositorio oficial de Skills.

## Instalar en el proyecto

```bash
npx skills add dream-num/skills --skill build-with-univer
```

Ejecuta el comando en el proyecto abierto por el Agent. La instalación es local; añade `-g` solo para todos los proyectos. Selecciona el Agent con `-a codex` o `-a claude-code` y usa `-y` para instalar sin interacción.

## Comprobar la instalación

```bash
npx skills list
```

La lista debe incluir `build-with-univer`. Tras instalar, reinicia la sesión del Agent si hace falta y pídele que use el Skill para esta tarea:

```text
Usa build-with-univer para añadir una hoja Univer editable a este proyecto. Introduce cinco filas de ventas, calcula los importes y el total general mediante fórmulas e indica cómo ejecutar y verificar el resultado. Consulta la documentación actual del SDK y mantén todos los paquetes Univer en la misma versión.
```

## Si el Agent no encuentra el Skill

Instala en el proyecto abierto por el Agent. Comprueba que exista `SKILL.md` en la ruta indicada y que el Agent admita Skills. Usa el comando anterior en lugar del antiguo repositorio `univer-sdk-skills`.
