---
title: Instalar un Skill para Agent
icon: Download
---

Para integrar Web SDK, inicializar un editor y usar Facade API en una aplicación existente, instala `univer-integrate`. El comando siguiente conserva ese nombre y usa el repositorio oficial actual `dream-num/skills`.

## Instalar en el proyecto

```bash
npx skills add dream-num/skills --skill univer-integrate
```

Ejecuta el comando en el proyecto abierto por el Agent. La instalación es local; añade `-g` solo para todos los proyectos. Selecciona el Agent con `-a codex` o `-a claude-code` y usa `-y` para instalar sin interacción.

## Comprobar la instalación

```bash
npx skills list
```

La lista debe incluir `univer-integrate`. Tras instalar, reinicia la sesión del Agent si hace falta y pídele que use el Skill para esta tarea:

```text
Usa univer-integrate para añadir una hoja Univer editable a este proyecto. Introduce cinco filas de ventas, calcula los importes y el total general mediante fórmulas e indica cómo ejecutar y verificar el resultado. Consulta la documentación actual del SDK y mantén todos los paquetes Univer en la misma versión.
```

## Para una nueva aplicación Office

Si partes de un requisito y necesitas elegir cómo combinar Web SDK, Server SDK y AI SDK, también puedes instalar `build-with-univer`. Ofrece una guía más general para planificar y construir una aplicación Office.

```bash
npx skills add dream-num/skills --skill build-with-univer
```

## Si el Agent no encuentra el Skill

Instala en el proyecto abierto por el Agent. Comprueba que exista `SKILL.md` en la ruta indicada y que el Agent admita Skills.

Si un tutorial antiguo usa `dream-num/univer-sdk-skills`, el comando del repositorio actual instala el mismo Skill `univer-integrate`. Comprueba su versión de referencia del SDK y sigue la documentación actual y las versiones instaladas en tu proyecto.

[Ver el código de univer-integrate](https://github.com/dream-num/skills/tree/main/skills/univer-integrate)
