---
title: 安装 Agent Skill
icon: Download
---

在现有应用中接入 Web SDK、初始化编辑器和使用 Facade API，可以安装 `univer-integrate`。下面保留这个 Skill 名称，使用官方当前仓库 `dream-num/skills` 的安装命令。

## 在项目中安装

```bash
npx skills add dream-num/skills --skill univer-integrate
```

在 Agent 正在工作的项目目录中运行。默认安装到当前项目；只有需要跨项目使用时才加 `-g`。可用 `-a codex` 或 `-a claude-code` 指定 Agent，用 `-y` 完成非交互安装。

## 确认安装成功

```bash
npx skills list
```

命令应列出 `univer-integrate`。安装后，必要时重新打开 Agent 会话，再让它使用 Skill 完成下面的任务：

```text
使用 univer-integrate，在当前项目中加入一张可编辑的 Univer 表格。填入 5 行销售示例数据，用公式计算每行金额和总计，告诉我如何运行和验证。先读取当前 SDK 文档，并让所有 Univer 包保持同一版本。
```

## 从需求开始构建新应用

如果你还在描述需求、选择 Web SDK、Server SDK 与 AI SDK 的组合方式，也可以安装 `build-with-univer`。它提供更通用的 Office 应用构建入门指南。

```bash
npx skills add dream-num/skills --skill build-with-univer
```

## Agent 找不到 Skill 时

确认安装目录与 Agent 打开的项目相同，检查安装器输出路径中是否存在 `SKILL.md`，以及 Agent 是否支持 Skills。

参考旧教程中的 `dream-num/univer-sdk-skills` 命令时，可改用上方当前仓库的命令，安装同名 `univer-integrate`。同时核对 Skill 声明的 SDK 版本基线，接入时以当前文档和项目已安装版本为准。

[查看 univer-integrate 源码](https://github.com/dream-num/skills/tree/main/skills/univer-integrate)
