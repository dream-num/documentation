---
title: 安装 Agent Skill
icon: Download
---

让编码 Agent 在接入编辑器、协同或文件转换时，使用当前 Office SDK 文档。推荐从官方 Skills 仓库的 `build-with-univer` 开始。

## 在项目中安装

```bash
npx skills add dream-num/skills --skill build-with-univer
```

在 Agent 正在工作的项目目录中运行。默认安装到当前项目；只有需要跨项目使用时才加 `-g`。可用 `-a codex` 或 `-a claude-code` 指定 Agent，用 `-y` 完成非交互安装。

## 确认安装成功

```bash
npx skills list
```

命令应列出 `build-with-univer`。安装后，必要时重新打开 Agent 会话，再让它使用 Skill 完成下面的任务：

```text
使用 build-with-univer，在当前项目中加入一张可编辑的 Univer 表格。填入 5 行销售示例数据，用公式计算每行金额和总计，告诉我如何运行和验证。先读取当前 SDK 文档，并让所有 Univer 包保持同一版本。
```

## Agent 找不到 Skill 时

确认安装目录与 Agent 打开的项目相同，检查安装器输出路径中是否存在 `SKILL.md`，以及 Agent 是否支持 Skills。旧 `univer-sdk-skills` 仓库不再作为推荐入门入口，请使用上方命令。

[源码与手动安装](https://github.com/dream-num/skills#install)
