## Что такое univer-sdk-skills

`univer-sdk-skills` — это набор навыков разработки с [Univer](https://github.com/dream-num/univer) для ИИ-агентов. С их помощью ИИ-агенты могут помогать разработчикам встраивать Univer в веб-приложения, интегрировать корпоративные функции, запускать Univer в серверных приложениях на Node.js и создавать собственные плагины.

Каждый навык соответствует стандартному формату и содержит файл `SKILL.md` с триггерами во frontmatter, подробными инструкциями, справочной документацией и переиспользуемыми примерами кода.

## Для кого предназначены навыки

- **Разработчики внешних приложений**: встраивают электронные таблицы и документы Univer в собственные фронтенд-проекты
- **Пользователи Pro**: интегрируют корпоративные функции Univer Pro (совместную работу, импорт и экспорт, печать и сводные таблицы)
- **Бэкенд-разработчики**: запускают Univer в Node.js для создания отчётов без графического интерфейса и обработки данных на сервере
- **Разработчики плагинов**: создают собственные функциональные расширения для Univer
- **ИИ-агенты**: должны точно понимать архитектуру и API Univer, чтобы помогать разработчикам

## Совместимость версий

Эти навыки предназначены для версии Univer с открытым исходным кодом (пакетов `@univerjs/*`). По мере выхода новых версий Univer некоторые API могут меняться. Рекомендуется использовать эти навыки вместе с [официальной документацией Univer](https://docs.univer.ai/).

Все пакеты `@univerjs/*` и `@univerjs-pro/*` должны иметь **одинаковую версию**. Не смешивайте разные версии — это наиболее частая причина ошибок во время выполнения.
