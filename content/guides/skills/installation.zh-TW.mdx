---
title: 安裝 Agent Skill
icon: Download
---

讓編碼 Agent 在整合編輯器、協同或檔案轉換時，使用目前的 Office SDK 文件。建議從官方 Skills 儲存庫的 `build-with-univer` 開始。

## 在專案中安裝

```bash
npx skills add dream-num/skills --skill build-with-univer
```

在 Agent 正在工作的專案目錄執行。預設安裝至目前專案；需要跨專案使用時才加 `-g`。可用 `-a codex` 或 `-a claude-code` 指定 Agent，以 `-y` 非互動安裝。

## 確認安裝成功

```bash
npx skills list
```

命令應列出 `build-with-univer`。安裝後，必要時重新開啟 Agent 工作階段，再讓它使用 Skill 完成以下任務：

```text
使用 build-with-univer，在目前專案加入可編輯的 Univer 試算表。填入 5 列銷售範例資料，以公式計算每列金額與總計，並說明如何執行與驗證。先閱讀目前 SDK 文件，讓所有 Univer 套件保持相同版本。
```

## Agent 找不到 Skill 時

確認安裝目錄與 Agent 開啟的專案相同，檢查安裝器顯示路徑是否存在 `SKILL.md`，以及 Agent 是否支援 Skills。舊 `univer-sdk-skills` 儲存庫不再作為建議入門入口，請使用上方命令。

[原始碼與手動安裝](https://github.com/dream-num/skills#install)
