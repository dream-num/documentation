---
title: 安裝 Agent Skill
icon: Download
---

在現有應用整合 Web SDK、初始化編輯器和使用 Facade API，可安裝 `univer-integrate`。以下保留相同 Skill 名稱，使用官方目前的 `dream-num/skills` 儲存庫安裝命令。

## 在專案中安裝

```bash
npx skills add dream-num/skills --skill univer-integrate
```

在 Agent 正在工作的專案目錄執行。預設安裝至目前專案；需要跨專案使用時才加 `-g`。可用 `-a codex` 或 `-a claude-code` 指定 Agent，以 `-y` 非互動安裝。

## 確認安裝成功

```bash
npx skills list
```

命令應列出 `univer-integrate`。安裝後，必要時重新開啟 Agent 工作階段，再讓它使用 Skill 完成以下任務：

```text
使用 univer-integrate，在目前專案加入可編輯的 Univer 試算表。填入 5 列銷售範例資料，以公式計算每列金額與總計，並說明如何執行與驗證。先閱讀目前 SDK 文件，讓所有 Univer 套件保持相同版本。
```

## 從需求開始建立新應用

若仍在描述需求、選擇 Web SDK、Server SDK 與 AI SDK 的組合方式，也可安裝 `build-with-univer`。它提供較通用的 Office 應用建置入門指南。

```bash
npx skills add dream-num/skills --skill build-with-univer
```

## Agent 找不到 Skill 時

確認安裝目錄與 Agent 開啟的專案相同，檢查安裝器顯示路徑是否存在 `SKILL.md`，以及 Agent 是否支援 Skills。

若參考舊教學中的 `dream-num/univer-sdk-skills` 命令，可改用上方目前儲存庫的命令安裝同名 `univer-integrate`。請核對 Skill 的 SDK 版本基線，整合時以目前文件和專案已安裝版本為準。
