---
title: Installer un Skill pour Agent
icon: Download
---

Permettez à votre Agent de programmation de consulter la documentation actuelle d’Office SDK pour intégrer un éditeur, la collaboration ou la conversion de fichiers. Commencez par `build-with-univer` dans le dépôt officiel des Skills.

## Installer dans votre projet

```bash
npx skills add dream-num/skills --skill build-with-univer
```

Exécutez la commande dans le projet ouvert par l’Agent. L’installation est locale ; ajoutez `-g` seulement pour tous les projets. Sélectionnez un Agent avec `-a codex` ou `-a claude-code`, et utilisez `-y` pour installer sans interaction.

## Vérifier l’installation

```bash
npx skills list
```

La liste doit contenir `build-with-univer`. Après installation, rouvrez la session de l’Agent si nécessaire, puis demandez-lui d’utiliser le Skill :

```text
Utilise build-with-univer pour ajouter une feuille Univer modifiable à ce projet. Insère cinq lignes de ventes, calcule les montants et le total général par des formules, puis indique comment exécuter et vérifier le résultat. Consulte la documentation SDK actuelle et conserve la même version pour tous les paquets Univer.
```

## Si l’Agent ne trouve pas le Skill

Installez dans le projet ouvert par l’Agent. Vérifiez la présence de `SKILL.md` dans le chemin indiqué et la prise en charge des Skills par l’Agent. Préférez la commande ci-dessus à l’ancien dépôt `univer-sdk-skills`.
