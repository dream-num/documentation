title: Installer un Skill pour Agent
icon: Download
---

Pour intégrer Web SDK, initialiser un éditeur et utiliser Facade API dans une application existante, installez `univer-integrate`. La commande ci-dessous conserve ce nom et utilise le dépôt officiel actuel `dream-num/skills`.

## Installer dans votre projet

```bash
npx skills add dream-num/skills --skill univer-integrate
```

Exécutez la commande dans le projet ouvert par l’Agent. L’installation est locale ; ajoutez `-g` seulement pour tous les projets. Sélectionnez un Agent avec `-a codex` ou `-a claude-code`, et utilisez `-y` pour installer sans interaction.

## Vérifier l’installation

```bash
npx skills list
```

La liste doit contenir `univer-integrate`. Après installation, rouvrez la session de l’Agent si nécessaire, puis demandez-lui d’utiliser le Skill :

```text
Utilise univer-integrate pour ajouter une feuille Univer modifiable à ce projet. Insère cinq lignes de ventes, calcule les montants et le total général par des formules, puis indique comment exécuter et vérifier le résultat. Consulte la documentation SDK actuelle et conserve la même version pour tous les paquets Univer.
```

## Pour une nouvelle application Office

Si vous partez d’un besoin et souhaitez choisir comment combiner Web SDK, Server SDK et AI SDK, vous pouvez aussi installer `build-with-univer`. Il propose un accompagnement plus général pour concevoir et construire une application Office.

```bash
npx skills add dream-num/skills --skill build-with-univer
```

## Si l’Agent ne trouve pas le Skill

Installez dans le projet ouvert par l’Agent. Vérifiez la présence de `SKILL.md` dans le chemin indiqué et la prise en charge des Skills par l’Agent.

Pour les anciens tutoriels utilisant `dream-num/univer-sdk-skills`, la commande du dépôt actuel ci-dessus installe le même Skill `univer-integrate`. Vérifiez sa version SDK de référence et suivez la documentation actuelle ainsi que les versions installées dans votre projet.

[Voir le code de univer-integrate](https://github.com/dream-num/skills/tree/main/skills/univer-integrate)
