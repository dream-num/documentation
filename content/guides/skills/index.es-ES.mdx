## ¿Qué es univer-sdk-skills?

`univer-sdk-skills` es una colección de habilidades de desarrollador para [Univer](https://github.com/dream-num/univer) dirigido a agentes de IA. Estas habilidades ayudan a los agentes de IA a ayudar a los desarrolladores a integrar Univer en aplicaciones web, integrar funciones empresariales, ejecutar Univer en backends de Node.js y desarrollar complementos personalizados.

Cada habilidad sigue el formato de habilidad estándar e incluye un archivo `SKILL.md` con activadores de front-matter, instrucciones detalladas, documentos de referencia y ejemplos de código reutilizables.

## Público objetivo

- **Desarrolladores de aplicaciones externas**: integrar hojas de cálculo/documentos de Univer en sus propios proyectos frontend
- **Usuarios Pro**: integrar funciones empresariales de Univer Pro (colaboración, importación/exportación, impresión, tablas dinámicas)
- **Desarrolladores backend**: ejecutar Univer en Node.js para generación de informes sin cabeza y datos del lado del servidor procesamiento
- **Desarrolladores de complementos**: creación de extensiones funcionales personalizadas para Univer
- **Agentes de IA**: se necesita una comprensión precisa de la arquitectura y las API de Univer para ayudar a los desarrolladores

## Compatibilidad de versiones

Estas habilidades están diseñadas para la versión de código abierto de Univer (paquetes `@univerjs/*`). A medida que las versiones de Univer se repiten, algunas API pueden cambiar. Se recomienda utilizar estas habilidades junto con la [documentación oficial de Univer](https://docs.univer.ai/).

Todos los paquetes `@univerjs/*` y `@univerjs-pro/*` deben mantenerse en la **misma versión**. Nunca mezcle diferentes versiones: esta es la fuente más común de errores de tiempo de ejecución.
