title: Agent Skill のインストール

既存アプリへの Web SDK 導入、エディター初期化、Facade API の操作には `univer-integrate` をインストールします。以下では Skill 名を維持し、現在の公式リポジトリ `dream-num/skills` を使用します。

## プロジェクトにインストール

```bash
npx skills add dream-num/skills --skill univer-integrate
```

Agent が作業するプロジェクト内で実行します。既定ではプロジェクトにインストールします。全プロジェクトで使う場合だけ `-g` を追加してください。`-a codex` または `-a claude-code` で Agent を選び、`-y` で非対話インストールできます。

## インストールを確認する

```bash
npx skills list
```

`univer-integrate` が一覧に表示されることを確認します。必要なら Agent のセッションを開き直し、この Skill を使って次のタスクを依頼してください。

```text
univer-integrate を使い、このプロジェクトに編集可能な Univer シートを追加してください。売上のサンプルデータを 5 行入力し、各行の金額と総額を数式で計算してください。実行方法と確認方法も示してください。現在の SDK ドキュメントを読み、すべての Univer パッケージを同じバージョンにそろえてください。
```

## 要件から新しいアプリを作る場合

要件の整理や Web SDK、Server SDK、AI SDK の組み合わせ選びから始める場合は、`build-with-univer` も利用できます。Office アプリの計画と構築を幅広く案内するガイドです。

```bash
npx skills add dream-num/skills --skill build-with-univer
```

## Agent が Skill を見つけられない場合

Agent が開いているプロジェクト内にインストールし、インストーラーが示すパスに `SKILL.md` があることと、Agent の Skills 対応を確認してください。

古いチュートリアルの `dream-num/univer-sdk-skills` コマンドを使っていた場合は、上の現行リポジトリから同名の `univer-integrate` をインストールできます。Skill の SDK 基準バージョンを確認し、現在のドキュメントとプロジェクトの導入済みバージョンに従ってください。
