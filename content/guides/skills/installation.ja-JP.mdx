エディター、共同編集、ファイル変換を組み込む際に、コーディング Agent が現在の Office SDK ドキュメントを参照できるようにします。公式 Skills リポジトリの `build-with-univer` から始めてください。

## プロジェクトにインストール

```bash
npx skills add dream-num/skills --skill build-with-univer
```

Agent が作業するプロジェクト内で実行します。既定ではプロジェクトにインストールします。全プロジェクトで使う場合だけ `-g` を追加してください。`-a codex` または `-a claude-code` で Agent を選び、`-y` で非対話インストールできます。

## インストールを確認する

```bash
npx skills list
```

`build-with-univer` が一覧に表示されることを確認します。必要なら Agent のセッションを開き直し、この Skill を使って次のタスクを依頼してください。

```text
build-with-univer を使い、このプロジェクトに編集可能な Univer シートを追加してください。売上のサンプルデータを 5 行入力し、各行の金額と総額を数式で計算してください。実行方法と確認方法も示してください。現在の SDK ドキュメントを読み、すべての Univer パッケージを同じバージョンにそろえてください。
```

## Agent が Skill を見つけられない場合

Agent が開いているプロジェクト内にインストールし、インストーラーが示すパスに `SKILL.md` があることと、Agent の Skills 対応を確認してください。旧 `univer-sdk-skills` リポジトリではなく上のコマンドを推奨します。
