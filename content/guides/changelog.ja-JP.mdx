Univer は [セマンティック バージョニング](https://semver.org/lang/ja/)（`MAJOR.MINOR.PATCH`）に従います。

- **MAJOR**：互換性のない API 変更
- **MINOR**：新機能、後方互換性あり
- **PATCH**：バグ修正、後方互換性あり

## リリース チャンネル

| チャンネル | 安定性 | 用途 |
|-----------|--------|------|
| 安定版 (`latest`) | 本番環境対応 | 本番デプロイ |
| ベータ版 (`beta`) | 機能完了、テスト中 | 本番前の検証 |
| アルファ版 (`alpha`) | 開発中 | 早期アクセス、フィードバック |
| ナイトリー版 (`nightly`) | 最新コミット | 最先端のテスト |

npm タグを使用して特定のチャンネルをインストールできます：

```bash
npm install @univerjs/core@latest
npm install @univerjs/core@beta
npm install @univerjs/core@alpha
npm install @univerjs/core@nightly
```

> **重要**：アルファ版、ベータ版、ナイトリー版にはバグや不完全な機能が含まれる可能性があります。本番環境での使用は避けてください。

## バージョン履歴

すべてのバージョンのリリースノートは [GitHub Releases](https://github.com/dream-num/univer/releases) で公開されています。

### アップグレード方法

1. 破壊的変更について [リリースノート](https://github.com/dream-num/univer/releases) を確認する
2. すべての `@univerjs/*` パッケージを同じターゲット バージョンに更新する
3. テスト スイートを実行する
4. 問題が発生した場合は、[トラブルシューティング](/guides/troubleshooting) ガイドを参照する

### 非推奨ポリシー

- 非推奨としてマークされた機能は、少なくとも 1 つのマイナー バージョンは引き続き動作します
- 非推奨の API は、開発ビルドで警告をログ出力します
- 移行パスはリリースノートに記載されます
