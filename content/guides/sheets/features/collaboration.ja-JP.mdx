[共同編集の統合](/server/collaboration/browser-integration)に沿って、サンプルの実行、アプリへの組み込み、永続化と権限の検証を進めてください。実装と Web/Server サンプルは [共同編集クイックスタート](/server/collaboration/quick-start) を参照してください。

認証済みの業務 API から Collaboration Service を呼び出して Unit を作成し、返された ID をブラウザーで読み込みます。[共同編集クイックスタート](/server/collaboration/quick-start) で HTTP、Session Ticket、WebSocket を設定し、Database Adapter で永続化します。読み取り、JOIN、編集は[サーバー側の権限](/server/collaboration/identity-and-authorization)で個別に保護してください。

## 文書の読み込み方法 [#document-loading]

文書を読み込む前に現在のユーザーを設定してください。推奨は明示的な読み込みです。現在のユーザーを設定してから下の Facade メソッドを呼び出し、初期化時に `enableUrlUnitLoader: false` を設定します。プリセットや `createUniver()` を使う場合はこの方法が必須です。既定で有効な URL 自動読み込みは `UniverCollaborationClientUIPlugin` の起動時に `unit` と `type` クエリを読んで文書を開くため、その場合は共同編集プラグインを登録する前に現在のユーザーを設定しておく必要があります。

以下の設定を既存のプラグイン登録または共同編集プリセット呼び出しに統合します。プリセットモードでは、`collaborationPreset` を既存の `createUniver()` のプリセット一覧に追加します。

<Tabs items={['プラグインモード', 'プリセットモード']}>
  <Tab>
    ```ts
    import { UniverCollaborationClientUIPlugin } from '@univerjs-pro/collaboration-client-ui'

    univer.registerPlugin(UniverCollaborationClientUIPlugin, {
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverSheetsCollaborationPreset } from '@univerjs/preset-sheets-collaboration'

    const collaborationPreset = UniverSheetsCollaborationPreset({
      universerEndpoint: 'https://your-backend.example.com',
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
</Tabs>

URL からの自動読み込みを止めても、共同編集と Facade による明示的な読み込みは利用できます。

## Facade API [#loading-collaborative-documents]

```ts
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadSheetAsync('your-unit-id')
```
