<Callout type="warning">
  **0.25.x** を使用している場合は[旧版 Pro ドキュメント](https://dream-num.github.io/documentation/v0.25/zh-CN/guides/pro/)を参照してください。新規統合にはセルフホストの Collaboration SDK を使用します。旧 Univer Server のデプロイ手順と API は適用されません。
</Callout>

[共同編集の統合](/guides/server-integration/collaboration)に沿って、サンプルの実行、アプリへの組み込み、永続化と権限の検証を進めてください。実装と Web/Server サンプルは [Univer Office](https://office.univer.ai/collaboration/quick-start) を参照してください。

認証済みの業務 API から Collaboration Service を呼び出して Unit を作成し、返された ID をブラウザーで読み込みます。[Quick Start](https://office.univer.ai/collaboration/quick-start) で HTTP、Session Ticket、WebSocket を設定し、Database Adapter で永続化します。読み取り、JOIN、編集は[サーバー側の権限](https://office.univer.ai/collaboration/identity-and-authorization)で個別に保護してください。

## Facade API [#loading-collaborative-documents]

```ts
import '@univerjs-pro/collaboration-client/facade'

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadSheetAsync('your-unit-id')
```
