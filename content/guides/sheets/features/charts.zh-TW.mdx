圖表會將工作表資料視覺化，並使用圖表模型及 UI 套件。

<PlaygroundFrame lang="zh-TW" slug="sheets/charts" clickToShow />

## 預設模式

圖表功能包含在 `@univerjs/preset-sheets-advanced`，執行時需要繪圖預設。

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

## 外掛模式

```package-install
npm install @univerjs-pro/chart-ui @univerjs-pro/sheets-chart @univerjs-pro/sheets-chart-ui
```

```ts
import ChartUIZhTW from '@univerjs-pro/chart-ui/locale/zh-TW'
import { UniverSheetsChartPlugin } from '@univerjs-pro/sheets-chart'
import { UniverSheetsChartUIPlugin } from '@univerjs-pro/sheets-chart-ui'
import SheetsChartUIZhTW from '@univerjs-pro/sheets-chart-ui/locale/zh-TW'
import SheetsChartZhTW from '@univerjs-pro/sheets-chart/locale/zh-TW'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-chart/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/sheets-chart-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(ChartUIZhTW, SheetsChartZhTW, SheetsChartUIZhTW),
  },
})

univer.registerPlugin(UniverSheetsChartPlugin)
univer.registerPlugin(UniverSheetsChartUIPlugin)
```

## 建立及更新圖表

透過工作表的 `charts` 集合管理圖表。`create()` 會回傳未插入的建構器，`insert()` 則將它插入工作表。

```ts
const worksheet = univerAPI.getActiveWorkbook().getActiveSheet()

const builder = worksheet.charts.create()
  .setType(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D6',
    orientation: univerAPI.Enum.ChartSourceOrientation.Column,
  })
  .setTitle('季度收入')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)

const chart = await worksheet.charts.insert(builder)

chart
  .setType(univerAPI.Enum.ChartTypeString.Line)
  .setLegend({ visible: true })
  .setSeries({ index: 0 }, { color: '#2F80ED' })
  .commit()
```

使用 `worksheet.charts.list()`、`worksheet.charts.get(id)` 與 `await worksheet.charts.remove(chartOrId)` 管理既有圖表。使用 `worksheet.charts.registerTheme(name, theme)` 註冊在目前 Univer 執行環境中共用的 ECharts 主題。

## 支援的圖表類型

透過 `univerAPI.Enum.ChartTypeString` 使用 `Line`、`Column`、`ColumnStacked`、`ColumnPercentStacked`、`Bar`、`BarStacked`、`BarPercentStacked`、`Pie`、`Donut`、`Area`、`AreaStacked`、`AreaPercentStacked`、`Radar`、`Scatter`、`Combination`、`WordCloud`、`Funnel`、`Bubble`、`Relation`、`Waterfall`、`Pareto`、`Sankey`、`Heatmap`、`Boxplot`、`Candlestick`、`Histogram`、`Treemap`、`Sunburst`、`Gauge` 與 `Chord`。

共用建構器設定請參閱[圖表 Facade 參考](/reference/facade/chart)。
