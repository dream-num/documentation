圖表是資料視覺化的重要工具，可以幫助使用者更直觀地理解和分析資料。在 Univer Sheets 中，圖表功能提供了多種類型的圖表，包括柱狀圖、折線圖、圓餅圖等，使用者可以根據需要選擇合適的圖表類型來展示資料。

## 預設模式

圖表功能被包含在 `@univerjs/preset-sheets-advanced` 預設中。

### 安裝

<Callout>
  @univerjs/preset-sheets-advanced 的 `UniverSheetsAdvancedPreset` 預設在執行時依賴 `UniverSheetsDrawingPreset` 預設，請先安裝 @univerjs/preset-sheets-drawing。
</Callout>

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
```

## Facade API

完整 Facade API 類型定義，請查看 [FacadeAPI](https://reference.univer.ai/zh-TW)。

在 Univer Sheets 中，你可以使用 Facade API 來建立、配置和管理圖表。Facade API 是一種圖表的程式介面，可以幫助你更方便地使用圖表功能。

### 導入

```typescript
import '@univerjs-pro/sheets-chart-ui/facade'
```

### 插入圖表

[`FWorksheet.newChart()`](https://reference.univer.ai/zh-TW/classes/FWorksheet#newchart) 方法用於建立一個圖表建構器，回傳一個 `FChartBuilderBase` 實例，你可以透過鏈式呼叫方法來設定圖表的各種屬性。

然後呼叫 `build()` 產生 `IChartBuilderInfo` 物件，透過 [`FWorksheet.insertChart(chartBuildInfo: IChartBuilderInfo)`](https://reference.univer.ai/zh-TW/classes/FWorksheet#insertchart) 方法將圖表插入到表格中。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 建立一個柱狀圖，資料來源為 A1:D6。
// 開始位置為儲存格 B2 的左上角。
// 圖表的寬度為 600，高度為 400。
const chartInfo = fWorksheet.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
  .setWidth(600)
  .setHeight(400)
  .build()
await fWorksheet.insertChart(chartInfo)
```

以下是 [`FChartBuilderBase`](https://reference.univer.ai/zh-TW/classes/FChartBuilderBase) 上的一些成員方法：

| 方法 | 描述 |
| --- | --- |
| addRange | 指定圖表資料來源範圍 |
| setPosition | 以 row，col 錨點方式設定圖表位置 |
| setAbsolutePosition | 以像素方式設定圖表位置 |
| setChartType | 設定圖表類型 |
| setWidth | 設定圖表寬度 |
| setHeight | 設定圖表高度 |
| setOptions | 設定圖表配置項 |
| setTransposeRowsAndColumns | 行列轉換 |
| setTheme | 設定主題 |
| setXAxisTitle | 設定X軸標題 |
| setYAxisTitle | 設定Y軸標題 |
| setRightYAxisTitle | 設定右軸標題 |
| setXAxisTextStyle | 設定X軸標題樣式 |
| setYAxisTextStyle | 設定Y軸標題樣式 |
| setRightYAxisTextStyle | 設定右軸標題樣式 |
| setInvalidValueStrategy | 設定空儲存格顯示方式 |
| setAxisPointerStyle | 設定指示線樣式 |
| setALLSeriesStyle | 設定所有系列樣式 |
| setSeriesStyle | 設定系列樣式 |
| build | 產生 builder info，用於插入/更新圖表 |

目前我們支援以下的配置項，你可以透過查閱 IChartBuildOptions 來獲取對應的配置：

配置項透過 setOptions 方法來設定，有以下兩種方式：
  - `setOptions(optionPath, optionVal)`: `setOptions('legend.color', '#ff0000')`
  - `setOptions('', IChartBuildOptions)`: `setOptions('', { legend: { color: '#ff0000', bold: true } })`

  ```typescript
        .setSeriesStyle(first.index, {

    }
  }, 3000)
  ```

### 獲取圖表

[`FWorksheet.getCharts()`](https://reference.univer.ai/zh-TW/classes/FWorksheet#getcharts) 方法用於獲取目前工作表中的所有圖表，回傳一個 `FChart[]` 陣列。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 獲取目前工作表中的所有圖表
const charts = fWorksheet.getCharts()
```

以下是 [`FChart`](https://reference.univer.ai/zh-TW/classes/FChart) 上的一些成員方法：

| 方法 | 描述 |

| getSeriesData | 獲取圖表系列資料 |

### 更新圖表

[`FWorksheet.updateChart(chartBuildInfo: IChartBuilderInfo)`](https://reference.univer.ai/zh-TW/classes/FWorksheet#updatechart) 方法用於更新圖表，傳入一個 `IChartBuilderInfo` 物件，用於更新圖表的配置。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 建立一個柱狀圖，資料來源為 A1:D6.
// 起始位置為儲存格 B2 的左上角.
const chartInfo = fWorksheet.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
  .build()
await fWorksheet.insertChart(chartInfo)

// 獲取目前工作表中的所有圖表
const charts = fWorksheet.getCharts()

// 3 秒後更新第一個圖表
setTimeout(() => {
  const newChartInfo = fWorksheet.newChart(charts[0])
    .asLineChart()
    .setOptions('legend.position', univerAPI.Enum.LegendPositionEnum.Right)
    .build()
  fWorksheet.updateChart(newChartInfo)
}, 3000)
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 建立一個柱狀圖，資料來源為 A1:D6.
// 起始位置為儲存格 B2 的左上角.
const chartInfo = fWorksheet.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
  .build()
await fWorksheet.insertChart(chartInfo)

// 獲取目前工作表中的所有圖表

// 3 秒後刪除第一個圖表
setTimeout(async () => {

```

### 圖表主題

[`FWorksheet.registerChartTheme(themeName: string, theme: IEchartTheme)`](https://reference.univer.ai/zh-TW/classes/FWorksheet#registercharttheme) 方法用於註冊圖表主題，傳入一個主題名稱和主題物件，用於註冊自訂主題。

Univer chart 是基於 echarts 的圖表庫實作的，因此可以借助 echart 的主題建構工具來建構你的[自訂主題](https://echarts.apache.org/zh/theme-builder.html)。
你可以在該網站建構你自己的主題並下載成為配置檔案，使用以下 API 來使用你的自訂主題：

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 註冊你的主題
const theme = { // 你的主題配置
  version: 1,
  themeName: 'myTheme',
  theme: {
    // ... 為了簡潔，省略了一些程式碼
    color: [
      '#893448',
      '#d95850',
      '#eb8146',
      '#ffb248',
      '#f2d643',
      '#ebdba4',
    ],
    // ... 為了簡潔，省略了一些程式碼
    visualMapColor: [
      '#893448',
      '#d95850',
      '#eb8146',
      '#ffb248',
      '#f2d643',
      'rgb(247,238,173)',
    ],
    // ... 為了簡潔，省略了一些程式碼
    axes: [],
    // ... 為了簡潔，省略了一些程式碼
  },
}
fWorksheet.registerChartTheme('myTheme', theme)

// 使用你的主題建立一個折線圖
const chartInfo = fWorksheet.newChart()
  .asLineChart()
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
  .setTheme('myTheme')
  .build()
await fWorksheet.insertChart(chartInfo)
```
