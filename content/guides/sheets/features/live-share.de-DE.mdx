Die Live Share-Funktion erfordert Univer Server-Unterstützung. Bitte stellen Sie sicher, dass Sie den Univer Server korrekt installiert und konfiguriert haben. Weitere Informationen finden Sie unter: [Upgrade auf Pro](/guides/sheets/getting-started/pro)

Mit der Live Share-Funktion können Benutzer ihre Ansichtsvorgänge (z. B. Scrollen und Auswahländerungen) während der Zusammenarbeit mit mehreren Personen in Echtzeit mit anderen Followern synchronisieren oder der Perspektive anderer Benutzer folgen. Dies ist sehr nützlich in Szenarien wie Besprechungspräsentationen und Unterrichtserklärungen.

## Plugin-Modus

### Installation

```package-install
npm install @univerjs-pro/live-share
```

### Verwendung

```typescript
import { UniverLiveSharePlugin } from '@univerjs-pro/live-share' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/live-share/lib/index.css' // [!code ++]

import '@univerjs-pro/live-share/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverLiveSharePlugin)
```

Wenn Sie über eine kommerzielle Univer-Lizenz verfügen, lesen Sie bitte die Konfiguration unter [Lizenz im Client verwenden](/guides/pro/license#using-license-in-plugin-mode).

## Facade API

Die Live Share-Funktion erweitert relevante Schnittstellen in der Facade API, die Sie direkt über `univerAPI` aufrufen können.

### Importieren

<Callout type="info" title="Plugin mode note">
Nur im Plugin-Modus ist ein manueller Import erforderlich Fassadenpaket. Der Voreinstellungsmodus enthält bereits das entsprechende Facade-Paket, sodass kein zusätzlicher Import erforderlich ist.
</Callout>

```typescript
import '@univerjs-pro/live-share/facade'
```

### Status Enum

```typescript
export enum LiveShareStatus {
  IDLE = 'idle',
  FOLLOWING = 'following',
  PRESENTING = 'presenting',
}
```

### Verwendungsbeispiel

```typescript
// Get current status
const status = univerAPI.getLiveShareStatus()

if (status === LiveShareStatus.IDLE) {
  // If currently idle, start presenting
  univerAPI.startPresenting()
} else if (status === LiveShareStatus.PRESENTING) {
  // If presenting, stop presenting
  univerAPI.stopPresenting()
}

// Start following
univerAPI.startFollowing()

// Stop following
univerAPI.stopFollowing()
```
