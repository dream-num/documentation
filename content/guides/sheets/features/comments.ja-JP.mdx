ユーザーはコメントを残し、文書に返信することができます。そのため、チームは1つの場所でコンテンツを議論することができます。

## プラグインモード [#plugin-mode]

### インストール [#installation]

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs/sheets-thread-comment @univerjs/sheets-thread-comment-ui
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsThreadCommentPlugin } from '@univerjs/sheets-thread-comment' // [!code ++]
import { UniverSheetsThreadCommentUIPlugin } from '@univerjs/sheets-thread-comment-ui' // [!code ++]
import SheetsThreadCommentJaJP from '@univerjs/sheets-thread-comment/locale/ja-JP' // [!code ++]
import SheetsThreadCommentUIJaJP from '@univerjs/sheets-thread-comment-ui/locale/ja-JP' // [!code ++]
import { UniverThreadCommentPlugin } from '@univerjs/thread-comment' // [!code ++]
import { UniverThreadCommentUIPlugin } from '@univerjs/thread-comment-ui' // [!code ++]
import ThreadCommentUIJaJP from '@univerjs/thread-comment-ui/locale/ja-JP' // [!code ++]
import '@univerjs/sheets-thread-comment-ui/lib/index.css'
import '@univerjs/thread-comment-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-thread-comment/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      ThreadCommentUIJaJP, // [!code ++]
      SheetsThreadCommentJaJP, // [!code ++]
      SheetsThreadCommentUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverThreadCommentPlugin) // [!code ++]
univer.registerPlugin(UniverThreadCommentUIPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsThreadCommentPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsThreadCommentUIPlugin) // [!code ++]
```

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/sheets/getting-started/installation#mobile-support)を最初に構成します。 このページのプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換えて、**ドキュメントを開く前に**を実行します。 モデルプラグイン、スタイル、ロケール、ファサードのインポートを保存し、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs/sheets-thread-comment-ui` | `UniverSheetsThreadCommentUIPlugin` | `UniverSheetsThreadCommentMobileUIPlugin` |
| `@univerjs/thread-comment-ui` | `UniverThreadCommentUIPlugin` | `UniverThreadCommentMobileUIPlugin` |

import '@univerjs/sheets-thread-comment/facade'

### セルへのコメント作成

`univerAPI.newTheadComment()`は、新しいコメントのために`FTheadCommentBuilder`を返します。 ビルダーのチェーンメソッドは、コメントのプロパティを設定します。

以下は [`FTheadCommentBuilder`](/reference/facade/thead-comment-builder) の主なメソッドです:

| メソッド | 説明 |
| ---- | ---- |
| setContent | コメントコンテンツを設定する |
| setPersonId | コメントの人 ID を設定します |
| setDateTime | コメントの日時を設定します。 |
| setId | コメント ID を設定する |
| setThreadId | コメントのスレッド ID を設定します |

```typescript
// 新しいコメントを作成します
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)

console.log(commentBuilder.content.toPlainText())

// コメントをセル A1 に追加します
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const cell = fWorksheet.getRange('A1')
const result = await cell.addCommentAsync(commentBuilder)
```

### セルのコメントを取得

これらのメソッドは、更新、削除、または解決できる `FThreadComment` を返します。

- `FWorkbook.getComments()`:ワークブックですべてのコメントを取得します
- `FfWorksheet.getComments()`:ワークシートのすべてのコメントを取得します
- `FRange.getComment()`: 範囲の左上セルのコメントを取得します。
- `FRange.getComments()`:範囲内のすべてのコメントを取得します

以下は [`FThreadComment`](https://docs.univer.ai/reference/facade/thread-comment) の主なメソッドです:

| メソッド | 説明 |
| ---- | ---- |
| getIsRoot | コメントがルートコメントかどうかを返します |
| getCommentData | コメントデータを取得する |
| getReplies | コメントへの返信のリストを取得します。 |
| getRange | コメントの範囲を取得します。 |
| getRichText | コメントの豊富なテキストコンテンツを取得する |
| deleteAsync | コメントとその返信を削除します。 |
| updateAsync | コメントコンテンツを更新する |
| resolveAsync | コメントを解決する |
| replyAsync | コメントへの返信 |

```typescript
// ワークブック内のすべてのコメントを取得します
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.getComments()

// アクティブなワークシート内のすべてのコメントを取得します
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.getComments()

const fRange = fWorksheet.getRange('A1:B2')
// セル A1 のコメントを取得します
fRange.getComment()

// 範囲 A1:B2 のすべてのコメントを取得します
fRange.getComments()
```

### コメントのクリア

- `FWorkbook.clearComments()`:ワークブックのすべてのコメントをクリア
- `FWorksheet.clearComments()`:ワークシートのすべてのコメントをクリア
- `FRange.clearCommentAsync()`:範囲の左上セルのコメントをクリアします
- `FRange.clearCommentsAsync()`:範囲内のすべてのコメントをクリア

```typescript
// ワークブック内のすべてのコメントをクリアします
const fWorkbook = univerAPI.getActiveWorkbook()
await fWorkbook.clearComments()

// アクティブなワークシート内のすべてのコメントをクリアします
const fWorksheet = fWorkbook.getActiveSheet()
await fWorksheet.clearComments()

const fRange = fWorksheet.getRange('A1:B2')

// セル A1 のコメントをクリアします
await fRange.clearCommentAsync()

// 範囲 A1:B2 のすべてのコメントをクリアします
await fRange.clearCommentsAsync()
```

### コメント返信リストの取得

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// ワークシート内のすべてのコメントを取得します
const comments = fWorksheet.getComments()
comments.forEach((comment) => {
  // コメントがルートコメントの場合、その返信を取得します
  if (comment.getIsRoot()) {
    const replies = comment.getReplies()
    replies.forEach((reply) => {
      console.log(reply.getCommentData())
    })
  }
})
```

### コメントの更新 / 削除 / 解決 / 返信

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 新しいコメントを作成し、セル A1 に追加します
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)
  .setId('mock-comment-id')
const cell = fWorksheet.getRange('A1')
await cell.addCommentAsync(commentBuilder)

// 3 秒後にコメントを更新し、返信を追加します
setTimeout(async () => {
  // ID でコメントを取得して内容を更新します
  const comment = fWorksheet.getCommentById('mock-comment-id')
  const newRichText = univerAPI.newRichText().insertText('Hello Univer AI')
  await comment.updateAsync(newRichText)

  // 新しい返信コメントを作成して内容を設定します
  const replyText = univerAPI.newRichText().insertText('Hello Univer AI! GO! GO! GO!')
  const reply = univerAPI.newTheadComment().setContent(replyText)
  await comment.replyAsync(reply)
}, 3000)

// コメントを解決し、6 秒後に削除します
setTimeout(async () => {
  const comment = fWorksheet.getCommentById('mock-comment-id')
  await comment.resolveAsync()
  await comment.deleteAsync()
}, 6000)
```

### イベントリスナー [#event-listeners]

イベントの型定義については、[Events](https://docs.univer.ai/reference/facade/events) を参照してください。

コメントモジュールは、コメントの追加、更新、削除、および解像度の状態の変更のためのイベントを送信します。 `univerAPI.addEvent()`でこれらのイベントのいずれかを購読します。

#### コメント追加イベント

`univerAPI.Event.CommentAdded`はコメントを追加した後に火をつけます。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentAdded, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// イベントリスナーを削除するには `disposable.dispose()` を使用してください
```

`univerAPI.Event.BeforeCommentAdd`はコメントを追加する前に火災します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentAdd, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // コメント追加操作をキャンセルします
  params.cancel = true
})

// イベントリスナーを削除するには `disposable.dispose()` を使用してください
```

#### コメント更新イベント

`univerAPI.Event.CommentUpdated`はコメントが更新された後に火を発します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentUpdated, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// イベントリスナーを削除するには `disposable.dispose()` を使用してください
```

`univerAPI.Event.BeforeCommentUpdate`はコメントが更新される前に火を発します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentUpdate, (params) => {
  const { comment, workbook, worksheet, row, col, newContent } = params

  // コメント更新操作をキャンセルします
  params.cancel = true
})

// イベントリスナーを削除するには `disposable.dispose()` を使用してください
```

#### コメント削除イベント

`univerAPI.Event.CommentDeleted` はコメントが削除された後に消火します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentDeleted, (params) => {
  const { commentId, workbook, worksheet } = params
})

// イベントリスナーを削除するには `disposable.dispose()` を使用してください
```

コメントが削除される前に `univerAPI.Event.BeforeCommentDelete` 火災.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentDelete, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // コメント削除操作をキャンセルします
  params.cancel = true
})

// イベントリスナーを削除するには `disposable.dispose()` を使用してください
```

#### コメント解決ステータスイベント

`univerAPI.Event.CommentResolved`はコメントの変更の解像度の状態の後に火をつけます。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentResolved, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params
})

// イベントリスナーを削除するには `disposable.dispose()` を使用してください
```

`univerAPI.Event.BeforeCommentResolve`はコメントの変更の解像度の状態の前に火を発します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentResolve, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params

  // コメント解決操作をキャンセルします
  params.cancel = true
})

// イベントリスナーを削除するには `disposable.dispose()` を使用してください
```

すべてのイベントは、次の共通パラメータを運びます。

- `workbook`: 現在のワークブック
- `worksheet`: 現在のワークシート
- `row`:コメントの行インデックス
- `col`:コメントの列インデックス
- `comment`:コメントオブジェクト(削除イベントのみ`commentId`)

いくつかのイベントは、自分のパラメータを追加します。

- `BeforeCommentUpdate`は`newContent`、新しいコメントコンテンツ(RichTextValueタイプ)も運びます。
- `CommentResolved`および`BeforeCommentResolve`はまた`resolved`、コメントの決断の状態を運びます

`Before`のコールバックは、`params.cancel = true`を設定して動作を停止することができます。

## 共通のコメント操作 [#shared-comment-api]

これらのメソッドを呼び出す前に、共有コメントファサードと製品ファサードの両方をインポートします。 製品のヘルパーは安定したアンカーを作成し、共有された API は、応答、更新、解像度、削除を処理します。 `getComments()` はローカルの状態のみを読みます。 `listCommentsAsync()`は、構成されたデータソースを通して既に知っているスレッドを同期させます。 サーバーのすべてのスレッドは検出されません。

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## 共有ディスカッション [#shared-discussions]

共有された議論では、コメントサービスとエンドポイントが[Server SDK](/server/collaboration/extensions)によって統合されます。 コラボレーションとライセンスが構成されると、`UniverThreadCommentDataSourcePlugin`から`@univerjs-pro/thread-comment-datasource`を登録します。 提供されたデータソースは`/universer-api/comment/unit/{unitId}/...`と`/universer-api/user/list`を使用します。 そのため、アプリケーションはこれらのルートを明示する必要があります。

## 画像とチャートへのコメント [#object-comments]

ホストの描画やチャートプラグインの設定後、ユニットを開く前に、ファサードのエントリと一致する統合を追加します。 プラグインモードとプリセットモードの両方が、これらの統合を明示的に登録する必要があります。 追加のスタイルやロケールを追加しません。

```package-install
npm install @univerjs-pro/sheets-drawing-thread-comment @univerjs-pro/sheets-chart-thread-comment
```

```typescript
import { UniverSheetsDrawingThreadCommentPlugin } from '@univerjs-pro/sheets-drawing-thread-comment'
import { UniverSheetsChartThreadCommentPlugin } from '@univerjs-pro/sheets-chart-thread-comment'
import '@univerjs-pro/sheets-drawing-thread-comment/facade'
import '@univerjs-pro/sheets-chart-thread-comment/facade'

univer.registerPlugin(UniverSheetsDrawingThreadCommentPlugin)
univer.registerPlugin(UniverSheetsChartThreadCommentPlugin)
```

ユニットが開いていると、既存の画像やチャートにコメントを追加できます。 `getComments()`は、ローカルにロードされたスレッドを返します。 `listCommentsAsync()` は、それらを返す前に知っているスレッドを同期させます。

```typescript
const host = univerAPI.getActiveWorkbook()?.getActiveSheet()
const image = host?.getImages()[0]
const chart = host?.getCharts()[0]
await image?.createCommentAsync('Review this image.')
await chart?.createCommentAsync('Verify the chart source.')
```
