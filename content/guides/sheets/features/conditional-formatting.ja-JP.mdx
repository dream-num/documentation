条件付き書式は、条件が保持されると自動的にセルの形式を変更します。重要なデータと傾向が際立っています。複数の条件と書式設定オプションをサポートし、データを一目で読みやすくなります。

## プラグインモード

### インストール

```package-install
npm install @univerjs/sheets-conditional-formatting @univerjs/sheets-conditional-formatting-ui
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsConditionalFormattingPlugin } from '@univerjs/sheets-conditional-formatting' // [!code ++]
import { UniverSheetsConditionalFormattingUIPlugin } from '@univerjs/sheets-conditional-formatting-ui' // [!code ++]
import SheetsConditionalFormattingUIJaJP from '@univerjs/sheets-conditional-formatting-ui/locale/ja-JP' // [!code ++]
import '@univerjs/sheets-conditional-formatting-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-conditional-formatting/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      SheetsConditionalFormattingUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsConditionalFormattingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsConditionalFormattingUIPlugin) // [!code ++]
```

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/sheets/getting-started/installation#mobile-support)を最初に構成します。 このページのプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換え、**ドキュメントを開く前に**の置換を完了します。 モデルプラグイン、スタイル、ロケール、ファサードのインポートを保持し、両方のバリアントを登録しないでください。

### 条件付き書式ルールの作成

[`FWorksheet.newConditionalFormattingRule()`](https://docs.univer.ai/reference/facade/worksheet#newconditionalformattingrule)は`FConditionalFormattingBuilder`を返します。 ルールを定義するためにチェーン内のメソッドを呼び出します。

[`FConditionalFormattingBuilder`](/reference/facade/conditional-formatting-builder)の会員方法は次のとおりです。

| Method | Description |
| ---- | ---- |
| build | ルールの構築 |
| copy | 現在のビルダーを深くクローンする |
| createCfId | 条件付きフォーマット ID を作成する |
| getRanges | 現在の条件形式の範囲を取得します。 |
| setRanges | ルールが適用される範囲を設定します。 |
| setAverage | 平均値ルールを設定する |
| setUniqueValues | ユニークな値ルールを設定する |
| setDuplicateValues | 重複値ルールを設定する |
| setRank | ランクルールを設定する |
| setIconSet | アイコン設定ルールを設定する |
| setColorScale | カラースケールルールを設定する |
| setDataBar | データバールールを設定する |
| setBackground | 背景色を設定 |
| setBold | 太字のテキストを設定する |
| setFontColor | フォントの色を設定する |
| setItalic | テキストの整形テキストを設定する |
| setStrikethrough | ストライクルーセット |
| setUnderline | アンダーラインの設定 |
| whenCellEmpty | 細胞が空いているときの火 |
| whenCellNotEmpty | 細胞が空でないときの火 |
| whenDate | 日付が特定の期間に落ちるときの火 |
| whenFormulaSatisfied | 式が真に評価されるときの火 |
| whenNumberBetween | 数字が2つの値の間に、またはそれらのいずれかに等しいときの火 |
| whenNumberEqualTo | 数値が与えられた値に等しいときの火 |
| whenNumberGreaterThan | 指定した値よりも数字が大きい場合の火 |
| whenNumberGreaterThanOrEqualTo | 指定した値よりも、または等しい数値が発火した場合 |
| whenNumberLessThan | 指定した値よりも数が少ない場合の火 |
| whenNumberLessThanOrEqualTo | 指定した値に数が少ないか等しい場合の火 |
| whenNumberNotBetween | 数値が2つの値とどちらかに等しくないときの火 |
| whenNumberNotEqualTo | 数値が与えられた値に等しくないときの火 |
| whenTextContains | テキストに指定された値が含まれているときの火 |
| whenTextDoesNotContain | テキストに指定された値が含まれていないときの火 |
| whenTextEndsWith | 指定された値でテキストが終了したときに火をつけます。 |
| whenTextEqualTo | テキストが与えられた値に等しいときの火 |
| whenTextStartsWith | テキストが指定された値で始まるときの火 |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// セルが空でない場合に、イタリック、赤背景、緑のフォント色を設定する条件付き書式ルールを作成します。
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)
```

### 条件付き書式ルールの取得

- `FWorksheet.getConditionalFormattingRules()` はワークシートのすべての条件付き書式ルールを取得します
- `FRange.getConditionalFormattingRules()` は範囲のすべての条件付き書式ルールを取得します

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// アクティブなワークシートのすべての条件付き書式ルールを取得します
const fWorksheet = fWorkbook.getActiveSheet()
const rulesOfSheet = fWorksheet.getConditionalFormattingRules()

// 範囲 A1:T100 のすべての条件付き書式ルールを取得します
const fRange = fWorksheet.getRange('A1:T100')
const rulesOfRange = fRange.getConditionalFormattingRules()
```

### 条件付き書式ルールの削除

`FWorksheet.deleteConditionalFormattingRule(cfId)`はワークシートからルールを削除します。 `cfId` はルールの ID です。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// 最初の条件付き書式ルールを削除します
fWorksheet.deleteConditionalFormattingRule(rules[0]?.cfId)
```

### 条件付き書式ルールの更新

`FWorksheet.setConditionalFormattingRule(cfId, rule)`は、ワークシートのルールを置き換えます。 `cfId` は、ルールの ID であり、`rule` 新しいルールです。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// セルが空でない場合に、イタリック、赤背景、緑のフォント色を設定する条件付き書式ルールを作成します。
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)

// 最初のルールを新しい範囲に適用するように変更します
const rules = fWorksheet.getConditionalFormattingRules()
const newRuleRange = fWorksheet.getRange('A1:D10')
fWorksheet.setConditionalFormattingRule(rules[0]?.cfId, { ...rules[0], ranges: [newRuleRange.getRange()] })
```

### 条件付き書式ルールの優先度の変更

`FWorksheet.moveConditionalFormattingRule(cfId, toCfId, type)`は、優先順位でルールの位置を変更します。 `cfId` は移動するルールであり、`toCfId`とは相対的に動くルールであり、 `type`が移動タイプ(例えば、'before'、'after')です。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// 3 番目のルールを 1 番目のルールの前に移動します
const rule = rules[2]
const targetRule = rules[0]
fWorksheet.moveConditionalFormattingRule(rule?.cfId, targetRule?.cfId, 'before')
```

### すべての条件付き書式ルールをクリア

- `FWorksheet.clearConditionalFormatRules()` はワークシートのすべての条件付き書式ルールをクリアします
- `FRange.clearConditionalFormatRules()` は範囲のすべての条件付き書式ルールをクリアします

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// アクティブなワークシートのすべての条件付き書式ルールをクリアします
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.clearConditionalFormatRules()

// 範囲 A1:T100 のすべての条件付き書式ルールをクリアします
const fRange = fWorksheet.getRange('A1:T100')
fRange.clearConditionalFormatRules()
```

## ルールの説明とプレビューを再利用する [#custom-rule-ui]

`@univerjs/sheets-conditional-formatting-ui`からカスタムルールリストを作成するには、`getRuleDescribe`と`ConditionalFormattingRulePreview`をインポートします。 ルール全体を`getRuleDescribe(rule, localeService)`に渡し、その構成(`rule.rule`)だけをプレビューに渡します。 プレビューは、構成された外観をレンダリングし、ワークシートセルを評価することはありません。 UniverのZのReactコンテキスト内でレンダリングします。

`CF_PANEL_KEY` は組み込みパネルを識別するため、[コンポーネントオーバーライド](/guides/sheets/ui/components)はそれをターゲティングすることができます。その `IConditionFormattingPanelProps.onEditorExit`コールバックは、編集が終了したときに実行されます: 送信後、キャンセル後、またはワークシートが有効化または削除されたとき。 保存が成功するか、サイドバーが閉鎖したかどうかを示すことはありません。

```tsx
import type { IConditionFormattingRule } from '@univerjs/sheets-conditional-formatting'
import { LocaleService } from '@univerjs/core'
import { ConditionalFormattingRulePreview, getRuleDescribe } from '@univerjs/sheets-conditional-formatting-ui'
import { useDependency } from '@univerjs/ui'

interface IRuleSummaryProps {
  rule: IConditionFormattingRule
}

function RuleSummary({ rule }: IRuleSummaryProps) {
  const localeService = useDependency(LocaleService)

  return (
    <div>
      <span>{getRuleDescribe(rule, localeService)}</span>
      <ConditionalFormattingRulePreview rule={rule.rule} />
    </div>
  )
}
```

## ルールの優先順位と「条件を満たす場合は停止」 [#stop-if-true]

ルールは優先順位で適用されます。特定のセルでは、一致するハイライトルールは、`stopIfTrue: true`を運ぶことで、マッチングルールがスタイルをセットしない場合でも、優先順位ルールを抑制します。ルールが一致しない場合は、評価は継続します。より高い優先ルールから結果が有効です。ルールエディタは、ハイライトルールのみにこのオプションを提供します。カラースケール、データバー、アイコンセットはそれを持っていません。

この例では、リストの一番上に新しく追加されたルールが配置されているため、優先度が低い背景ルールが最初に追加されます。 ストップが有効になっていると、90は緑色の背景なしで大胆に現れ、60は背景がまだ受けます。 `stopIfTrue`は、`rule`にない、外部ルールオブジェクトに属しています。

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

const ranges = [sheet.getRange('B2:B10').getRange()]
const backgroundRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(50)
  .setBackground('#DCFCE7')
  .setRanges(ranges)
  .build()
const priorityRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(80)
  .setBold(true)
  .setRanges(ranges)
  .build()

sheet.addConditionalFormattingRule(backgroundRule)
sheet.addConditionalFormattingRule({ ...priorityRule, stopIfTrue: true })
```
