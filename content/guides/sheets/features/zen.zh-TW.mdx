禪模式允許使用者在一個簡潔的介面中專注於單元格內容的編輯。

## 預設模式

禪模式並未提供預設模式，但支援與其外掛混用。

### 安裝

```package-install
npm install @univerjs/sheets-zen-editor
```

### 使用

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreZhTW from '@univerjs/preset-sheets-core/locales/zh-TW'
import { UniverSheetsZenEditorPlugin } from '@univerjs/sheets-zen-editor'
import SheetsZenEditorZhTW from '@univerjs/sheets-zen-editor/locale/zh-TW' // [!code ++]

import '@univerjs/sheets-zen-editor/facade' // [!code ++]

import '@univerjs/sheets-zen-editor/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      UniverPresetSheetsCoreZhTW,
      SheetsZenEditorZhTW, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    UniverSheetsZenEditorPlugin, // [!code ++]
  ],
})
```

## 外掛模式

### 安裝

```package-install
npm install @univerjs/sheets-zen-editor
```

### 使用

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsZenEditorPlugin } from '@univerjs/sheets-zen-editor' // [!code ++]
import SheetsZenEditorZhTW from '@univerjs/sheets-zen-editor/locale/zh-TW' // [!code ++]

import '@univerjs/sheets-zen-editor/lib/index.css' // [!code ++]

import '@univerjs/sheets-zen-editor/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      SheetsZenEditorZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsZenEditorPlugin) // [!code ++]
```

## Facade API

完整 Facade API 型別定義，請檢視 [FacadeAPI](https://reference.univer.ai/zh-TW)。

### 引入

<Callout type="info" title="外掛模式提示">
  僅外掛模式需要手動引入 Facade 套件。預設模式已內建對應的 Facade 套件，無需額外引入。
</Callout>

```typescript
import '@univerjs/sheets-zen-editor/facade'
```

### 進入禪編輯模式

`FWorkbook.startZenEditingAsync()` 可以進入禪編輯模式，此時會開啟一個全屏編輯器，可以編輯當前活動單元格的內容。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const success = await fWorkbook.startZenEditingAsync()
```

### 退出禪編輯模式

`FWorkbook.endZenEditingAsync(save)` 可以退出禪編輯模式，此時會關閉全屏編輯器，如果 `save` 為 `true`，則會儲存編輯器中更改的內容。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const success = await fWorkbook.endZenEditingAsync(true)
```

### 事件監聽

禪編輯器可以使用[單元格的編輯事件](http://localhost:3000/zh-TW/guides/sheets/features/core/range-selection#%E5%BC%80%E5%A7%8B%E7%BC%96%E8%BE%91%E4%BA%8B%E4%BB%B6)達到監聽編輯器的變化：

- `univerAPI.Event.BeforeSheetEditStart`：進入禪編輯模式前
- `univerAPI.Event.SheetEditStarted`：進入禪編輯模式後
- `univerAPI.Event.BeforeSheetEditEnd`：退出禪編輯模式前
- `univerAPI.Event.SheetEditEnded`：退出禪編輯模式後
