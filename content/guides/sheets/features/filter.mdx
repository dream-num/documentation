A filter hides the rows that do not match the specified criteria, so only the data of interest remains visible. The feature supports a range of filtering conditions and operations, and each column can have its own criteria.

## Plugin mode

### Installation

```package-install
npm install @univerjs/sheets-filter @univerjs/sheets-filter-ui
```

### Usage

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsFilterPlugin } from '@univerjs/sheets-filter' // [!code ++]
import { UniverSheetsFilterUIPlugin } from '@univerjs/sheets-filter-ui' // [!code ++]
import SheetsFilterUIEnUS from '@univerjs/sheets-filter-ui/locale/en-US' // [!code ++]
import '@univerjs/sheets-filter-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-filter/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsFilterUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsFilterPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsFilterUIPlugin) // [!code ++]
```

### Plugin configuration [#plugin-configuration]

`UniverSheetsFilterPlugin`

| <span data-config-options="">Option</span> | Type | Default | What it does |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>enableSyncSwitch</ConfigKey> | `boolean \| object` | `false` | Shows a switch for collaborative filter sync. Pass an object to set its initial state. |
| <ConfigKey depth={1}>defaultValue</ConfigKey> | `boolean` |  | The switch's initial state when it is shown. |

## Facade API

The full Facade API type definitions are in [FacadeAPI](/reference/facade).

### Importing

<Callout type="info" title="Plugin mode note">
  The Facade package requires a manual import only in plugin mode. Preset mode already bundles the matching Facade package.
</Callout>

```typescript
import '@univerjs/sheets-filter/facade'
```

### Get filter

Returns an [`FFilter`](https://docs.univer.ai/reference/facade/filter) object, or `null` if the sheet has no filter.

- On an `FWorksheet`, call [`getFilter()`](https://docs.univer.ai/reference/facade/worksheet#getfilter)
- On an `FRange`, call [`getFilter()`](https://docs.univer.ai/reference/facade/range#getfilter)

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Get filter from FWorksheet
const fWorksheet = fWorkbook.getActiveSheet()
const fFilter = fWorksheet.getFilter()
fFilter?.getRange().getA1Notation()

// Get filter from FRange
const fRange = fWorksheet.getRange('A1:D14')
const fFilter2 = fRange.getFilter()
fFilter2?.getRange().getA1Notation()
```

### Create filter

Creates an [`FFilter`](https://docs.univer.ai/reference/facade/filter) object. If the sheet already has a filter, it returns `null`.

- On an `FRange`, call [`createFilter()`](https://docs.univer.ai/reference/facade/range#createfilter)

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:D14')
let fFilter = fRange.createFilter()

// If the worksheet already has a filter, remove it and create a new filter.
if (!fFilter) {
  fWorksheet.getFilter().remove()
  fFilter = fRange.createFilter()
}
fFilter.getRange().getA1Notation()
```

### Remove filter

Call [`FFilter.remove()`](https://docs.univer.ai/reference/facade/filter#remove) to remove the filter from the worksheet.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.getFilter()?.remove()
```

### Get column filter criteria

[`FFilter.getColumnFilterCriteria(column)`](https://docs.univer.ai/reference/facade/filter#getcolumnfiltercriteria) returns the filter criteria set on a column.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set some values of the range C1:F10
const fRange = fWorksheet.getRange('C1:F10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// Create a filter on the range C1:F10
let fFilter = fRange.createFilter()

// If the filter already exists, remove it and create a new one
if (!fFilter) {
  fRange.getFilter().remove()
  fFilter = fRange.createFilter()
}

// Set the filter criteria of the column C, filter out the rows that are not 1, 5, 9
const column = fWorksheet.getRange('C:C').getColumn()
fFilter.setColumnFilterCriteria(column, {
  colId: 0,
  filters: {
    filters: ['1', '5', '9'],
  },
})

// Print the filter criteria of the column C and D
fFilter.getColumnFilterCriteria(column) // { colId: 0, filters: { filters: ['1', '5', '9'] } }
fFilter.getColumnFilterCriteria(column + 1) // undefined
```

```typescript
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],

// Create a filter on the range C1:F10

// If the filter already exists, remove it and create a new one

```

### Remove column filter criteria

- [`FFilter.removeColumnFilterCriteria(column)`](https://docs.univer.ai/reference/facade/filter#removecolumnfiltercriteria) clears the criteria on one column.
- [`FFilter.removeFilterCriteria()`](https://docs.univer.ai/reference/facade/filter#removefiltercriteria) clears the criteria on every column.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set some values of the range C1:F10
const fRange = fWorksheet.getRange('C1:F10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// Create a filter on the range C1:F10
let fFilter = fRange.createFilter()

// If the filter already exists, remove it and create a new one
if (!fFilter) {
  fRange.getFilter().remove()
  fFilter = fRange.createFilter()
}

// Set the filter criteria of the column C, filter out the rows that are not 1, 5, 9
const column = fWorksheet.getRange('C:C').getColumn()
fFilter.setColumnFilterCriteria(column, {
  colId: 0,
  filters: {
    filters: ['1', '5', '9'],
  },
})

// Clear the filter criteria of the column C after 3 seconds
setTimeout(() => {
  fFilter.removeColumnFilterCriteria(column)
  // Or use fFilter.removeFilterCriteria() to remove all column filter criteria
}, 3000)
```

### Get filtered out rows

### Event listeners

The full event type definitions are in the [Events](https://docs.univer.ai/reference/facade/events).

`SheetRangeFiltered` fires when a column's filter criteria change.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetRangeFiltered, (params) => {
  const { workbook, worksheet, col, criteria } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`SheetBeforeRangeFilter` fires before that change is applied.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetBeforeRangeFilter, (params) => {
  const { workbook, worksheet, col, criteria } = params

  // Cancel the filter criteria change operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`SheetRangeFilterCleared` fires when criteria are cleared.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetRangeFilterCleared, (params) => {
  const { workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`SheetBeforeRangeFilterClear` fires before criteria are cleared.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetBeforeRangeFilterClear, (params) => {
  const { workbook, worksheet } = params

  // Cancel the filter clear operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```
