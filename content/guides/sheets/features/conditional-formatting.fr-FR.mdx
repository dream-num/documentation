Le formatage conditionnel modifie automatiquement le format d'une cellule lorsqu'une condition se présente, de sorte que les données et les tendances importantes se distinguent. Il prend en charge plusieurs conditions et options de formatage, ce qui facilite la lecture des données en un coup d'oeil.

## Mode plugin

### Installation

```package-install
npm install @univerjs/sheets-conditional-formatting @univerjs/sheets-conditional-formatting-ui
```

### Utilisation

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsConditionalFormattingPlugin } from '@univerjs/sheets-conditional-formatting' // [!code ++]
import { UniverSheetsConditionalFormattingUIPlugin } from '@univerjs/sheets-conditional-formatting-ui' // [!code ++]
import SheetsConditionalFormattingUIEnUS from '@univerjs/sheets-conditional-formatting-ui/locale/en-US' // [!code ++]
import '@univerjs/sheets-conditional-formatting-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-conditional-formatting/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsConditionalFormattingUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsConditionalFormattingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsConditionalFormattingUIPlugin) // [!code ++]
```

### Créer des règles de mise en forme conditionnelle

[`FWorksheet.newConditionalFormattingRule()`](https://docs.univer.ai/reference/facade/worksheet#newconditionalformattingrule) retourne un `FConditionalFormattingBuilder`. Appelez ses méthodes dans une chaîne pour définir la règle.

Les méthodes des membres sur [`FConditionalFormattingBuilder`](/reference/facade/conditional-formatting-builder) comprennent:

| Méthode | Description |
| ---- | ---- |
| build | Construit la règle |
| copy | Clones profondes du constructeur actuel |
| createCfId | Crée un ID de format conditionnel |
| getRanges | Obtient les gammes du format conditionnel actuel |
| setRanges | Définit l'intervalle auquel la règle s'applique |
| setAverage | Définit une règle de valeur moyenne |
| setUniqueValues | Définit une règle de valeurs uniques |
| setDuplicateValues | Définit une règle des valeurs dupliquées |
| setRank | Définit une règle de rang |
| setIconSet | Définit une règle de jeu d'icône |
| setColorScale | Définit une règle d'échelle de couleurs |
| setDataBar | Définit une règle de barre de données |
| setBackground | Définit la couleur de l'arrière-plan |
| setBold | Définit le texte en caractères gras |
| setFontColor | Définit la couleur de la police |
| setItalic | Définit le texte en italique |
| setStrikethrough | Définit la frappe |
| setUnderline | Les ensembles soulignent |
| whenCellEmpty | Feu quand la cellule est vide |
| whenCellNotEmpty | Feu quand la cellule n'est pas vide |
| whenDate | Incendie lorsque la date tombe dans une période donnée |
| whenFormulaSatisfied | Feu quand la formule évalue à vrai |
| whenNumberBetween | Feu lorsque le nombre est entre deux valeurs, ou égal à l'une d'entre elles |
| whenNumberEqualTo | Feu lorsque le nombre est égal à la valeur donnée |
| whenNumberGreaterThan | Feu lorsque le nombre est supérieur à la valeur donnée |
| whenNumberGreaterThanOrEqualTo | Feu lorsque le nombre est supérieur ou égal à la valeur donnée |
| whenNumberLessThan | Feu lorsque le nombre est inférieur à la valeur donnée |
| whenNumberLessThanOrEqualTo | Feu lorsque le nombre est inférieur ou égal à la valeur donnée |
| whenNumberNotBetween | Feu lorsque le nombre n'est pas entre deux valeurs et n'est égal à aucun des deux |
| whenNumberNotEqualTo | Feu lorsque le nombre n'est pas égal à la valeur donnée |
| whenTextContains | Feu lorsque le texte contient la valeur spécifiée |
| whenTextDoesNotContain | Feu lorsque le texte ne contient pas la valeur spécifiée |
| whenTextEndsWith | Fait feu lorsque le texte se termine avec la valeur spécifiée |
| whenTextEqualTo | Feu lorsque le texte est égal à la valeur donnée |
| whenTextStartsWith | Feu lorsque le texte commence par la valeur spécifiée |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)
```

### Obtenir les règles de mise en forme conditionnelle

- `FWorksheet.getConditionalFormattingRules()` obtient toutes les règles de mise en forme conditionnelle de la feuille de calcul
- `FRange.getConditionalFormattingRules()` obtient toutes les règles de mise en forme conditionnelle de la plage

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Get all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
const rulesOfSheet = fWorksheet.getConditionalFormattingRules()

// Get all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
const rulesOfRange = fRange.getConditionalFormattingRules()
```

### Supprimer des règles de mise en forme conditionnelle

`FWorksheet.deleteConditionalFormattingRule(cfId)` supprime une règle de la feuille de travail. `cfId` est l'ID de la règle.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Remove the first conditional formatting rule
fWorksheet.deleteConditionalFormattingRule(rules[0]?.cfId)
```

### Mettre à jour des règles de mise en forme conditionnelle

`FWorksheet.setConditionalFormattingRule(cfId, rule)` remplace une règle dans la feuille de travail. `cfId` est l'ID de la règle à remplacer et `rule` la nouvelle règle.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)

// Modify the first rule to apply to a new range
const rules = fWorksheet.getConditionalFormattingRules()
const newRuleRange = fWorksheet.getRange('A1:D10')
fWorksheet.setConditionalFormattingRule(rules[0]?.cfId, { ...rules[0], ranges: [newRuleRange.getRange()] })
```

### Modifier la priorité des règles de mise en forme conditionnelle

`FWorksheet.moveConditionalFormattingRule(cfId, toCfId, type)` modifie la position d'une règle dans l'ordre de priorité. `cfId` est la règle à déplacer, `toCfId` la règle à laquelle il se déplace, et `type` le type de déplacement (p. ex. « avant », « après »).

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Move the third rule before the first rule
const rule = rules[2]
const targetRule = rules[0]
fWorksheet.moveConditionalFormattingRule(rule?.cfId, targetRule?.cfId, 'before')
```

### Effacer toutes les règles de mise en forme conditionnelle

- `FWorksheet.clearConditionalFormatRules()` efface toutes les règles de mise en forme conditionnelle de la feuille de calcul
- `FRange.clearConditionalFormatRules()` efface toutes les règles de mise en forme conditionnelle de la plage

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Clear all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.clearConditionalFormatRules()

// Clear all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
fRange.clearConditionalFormatRules()
```

## Réutiliser les descriptions et aperçus de règles [#custom-rule-ui]

Pour construire une liste de règles personnalisées, importez `getRuleDescribe` et `ConditionalFormattingRulePreview` de `@univerjs/sheets-conditional-formatting-ui`. Passez la règle entière à `getRuleDescribe(rule, localeService)`, et passez seulement sa configuration (`rule.rule`) à l'aperçu. L'aperçu rend l'apparence configurée et n'évalue pas les cellules de feuille de travail. Renvoyez-la dans le contexte Univer de React.

`CF_PANEL_KEY` identifie le panneau intégré, de sorte que [les dépassements des composants](/guides/sheets/ui/components) peut le cibler. Son callback `IConditionFormattingPanelProps.onEditorExit` s'exécute lorsque l'édition se termine : après une soumission, après une annulation, ou lorsque la feuille de travail est activée ou supprimée. Elle n'indique pas si la sauvegarde a réussi ou si la barre latérale s'est fermée.

```tsx
import type { IConditionFormattingRule } from '@univerjs/sheets-conditional-formatting'
import { LocaleService } from '@univerjs/core'
import { ConditionalFormattingRulePreview, getRuleDescribe } from '@univerjs/sheets-conditional-formatting-ui'
import { useDependency } from '@univerjs/ui'

interface IRuleSummaryProps {
  rule: IConditionFormattingRule
}

function RuleSummary({ rule }: IRuleSummaryProps) {
  const localeService = useDependency(LocaleService)

  return (
    <div>
      <span>{getRuleDescribe(rule, localeService)}</span>
      <ConditionalFormattingRulePreview rule={rule.rule} />
    </div>
  )
}
```

## Priorité des règles et arrêt si vrai [#stop-if-true]

Les règles s'appliquent dans l'ordre de priorité. Pour une cellule donnée, une règle de surlignement qui porte `stopIfTrue: true` supprime les règles de priorité inférieure, même lorsque la règle de surenchère ne définit pas de style. Si la règle ne correspond pas, l'évaluation continue. Les résultats des règles de priorité supérieure restent en vigueur. L'éditeur de règles fournit cette option pour les règles de surligner seulement; les échelles de couleurs, les barres de données et les ensembles d'icônes ne l'ont pas.

L'exemple ajoute d'abord la règle d'arrière-plan de priorité inférieure parce qu'une nouvelle règle ajoutée est placée en haut de la liste. Lorsque l'arrêt est activé, 90 apparaît en gras sans arrière-plan vert, tandis que 60 reçoit encore l'arrière-fond. `stopIfTrue` appartient à l'objet de la règle extérieure, et non à `rule`.

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

const ranges = [sheet.getRange('B2:B10').getRange()]
const backgroundRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(50)
  .setBackground('#DCFCE7')
  .setRanges(ranges)
  .build()
const priorityRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(80)
  .setBold(true)
  .setRanges(ranges)
  .build()

sheet.addConditionalFormattingRule(backgroundRule)
sheet.addConditionalFormattingRule({ ...priorityRule, stopIfTrue: true })
```
