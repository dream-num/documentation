Функция водяных знаков предоставляет гибкое и безопасное решение для электронных таблиц. Разработчики могут добавлять в таблицы текстовые или графические водяные знаки и настраивать их внешний вид и поведение с помощью различных параметров.

<Callout type="info">
  Используйте [Генератор водяных знаков](/tools/watermark-generator) для предварительного просмотра стилей и скачивания конфигурации плагина в формате JSON.
</Callout>

## Режим плагинов

### Установка

```package-install
npm install @univerjs/watermark
```

### Использование

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

## Режим предустановок

Для водяных знаков нет отдельной предустановки, но плагин можно использовать вместе с другими предустановками.

### Установка

```package-install
npm install @univerjs/watermark
```

### Использование

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## Facade API

### Импорт

<Callout type="info" title="Примечание о режиме плагинов">
  Импортировать пакет Facade вручную нужно только в режиме плагинов. В режиме предустановок соответствующий пакет Facade уже включён, поэтому дополнительный импорт не требуется.
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### Установка водяного знака

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### Удаление водяного знака

```typescript
univerAPI.deleteWatermark()
```
