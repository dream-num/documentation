Пользователи могут оставлять комментарии и ответы на документе, поэтому команда может обсуждать контент в одном месте.

## Режим плагинов

### Установка

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs/sheets-thread-comment @univerjs/sheets-thread-comment-ui
```

### Использование

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsThreadCommentPlugin } from '@univerjs/sheets-thread-comment' // [!code ++]
import { UniverSheetsThreadCommentUIPlugin } from '@univerjs/sheets-thread-comment-ui' // [!code ++]
import SheetsThreadCommentUIEnUS from '@univerjs/sheets-thread-comment-ui/locale/en-US' // [!code ++]
import { UniverThreadCommentPlugin } from '@univerjs/thread-comment' // [!code ++]
import { UniverThreadCommentUIPlugin } from '@univerjs/thread-comment-ui' // [!code ++]
import ThreadCommentUIEnUS from '@univerjs/thread-comment-ui/locale/en-US' // [!code ++]
import '@univerjs/sheets-thread-comment-ui/lib/index.css'
import '@univerjs/thread-comment-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-thread-comment/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      ThreadCommentUIEnUS, // [!code ++]
      SheetsThreadCommentUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverThreadCommentPlugin) // [!code ++]
univer.registerPlugin(UniverThreadCommentUIPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsThreadCommentPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsThreadCommentUIPlugin) // [!code ++]
```

Если [Сотрудничество](/guides/sheets/features/collaboration) также используется, зарегистрируйте плагин источника данных:

### Создание комментария к ячейке

`univerAPI.newTheadComment()` возвращает `FTheadCommentBuilder` для нового комментария.Цепные методы на конструкторе для установки свойств комментария.

Ниже перечислены некоторые методы [`FTheadCommentBuilder`](/reference/facade/thead-comment-builder):

| Метод | Описание |
| ---- | ---- |
| setContent | Устанавливает содержание комментария |
| setPersonId | Устанавливает ID человека комментария |
| setDateTime | Устанавливает дату и время комментария |
| setId | Устанавливает ID комментария |
| setThreadId | Устанавливает идентификатор потока комментария |

```typescript
// Create a new comment
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)

console.log(commentBuilder.content.toPlainText())

// Add the comment to cell A1
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const cell = fWorksheet.getRange('A1')
const result = await cell.addCommentAsync(commentBuilder)
```

### Получение комментариев к ячейкам

Эти методы возвращают `FThreadComment`, который затем может быть обновлен, удален или разрешен.

- `FWorkbook.getComments()`: получает все комментарии в трудовой книжке
- `FfWorksheet.getComments()`: все комментарии в таблице
- `FRange.getComment()`: получает комментарий левой верхней ячейки в диапазоне
- `FRange.getComments()`: получает все комментарии в ассортименте

Ниже перечислены некоторые методы [`FThreadComment`](https://docs.univer.ai/reference/facade/thread-comment):

| Метод | Описание |
| ---- | ---- |
| getIsRoot | Проверяет, является ли комментарий корневым |
| getCommentData | Получает данные комментариев |
| getReplies | Получает список ответов на комментарий |
| getRange | Получает диапазон комментария |
| getRichText | Получает богатый текстовый контент комментария |
| deleteAsync | Исключает комментарий и его ответы |
| updateAsync | Обновление содержания комментария |
| resolveAsync | Отклоняет комментарий |
| replyAsync | Ответы на комментарий |

```typescript
// Get all comments in the workbook
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.getComments()

// Get all comments in the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.getComments()

const fRange = fWorksheet.getRange('A1:B2')
// Get the comment of cell A1
fRange.getComment()

// Get all comments in the range A1:B2
fRange.getComments()
```

### Очистка комментариев к ячейкам

- `FWorkbook.clearComments()`: проясняет все комментарии в трудовой книжке
- `FWorksheet.clearComments()`: очищает все комментарии в рабочем листе
- `FRange.clearCommentAsync()`: проясняет комментарий левой верхней ячейки в диапазоне
- `FRange.clearCommentsAsync()`: очищает все комментарии в ассортименте

```typescript
// Clear all comments in the workbook
const fWorkbook = univerAPI.getActiveWorkbook()
await fWorkbook.clearComments()

// Clear all comments in the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
await fWorksheet.clearComments()

const fRange = fWorksheet.getRange('A1:B2')

// Clear the comment of cell A1
await fRange.clearCommentAsync()

// Clear all comments in the range A1:B2
await fRange.clearCommentsAsync()
```

### Получение списка ответов на комментарий

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all comments in the worksheet
const comments = fWorksheet.getComments()
comments.forEach((comment) => {
  // If the comment is a root comment, get its replies
  if (comment.getIsRoot()) {
    const replies = comment.getReplies()
    replies.forEach((reply) => {
      console.log(reply.getCommentData())
    })
  }
})
```

### Обновление, удаление, завершение и ответы на комментарии

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new comment and add it to cell A1
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)
  .setId('mock-comment-id')
const cell = fWorksheet.getRange('A1')
await cell.addCommentAsync(commentBuilder)

// Update the comment and reply after 3 seconds
setTimeout(async () => {
  // Get the comment by ID and update its content
  const comment = fWorksheet.getCommentById('mock-comment-id')
  const newRichText = univerAPI.newRichText().insertText('Hello Univer AI')
  await comment.updateAsync(newRichText)

  // Create a new reply comment and set its content
  const replyText = univerAPI.newRichText().insertText('Hello Univer AI! GO! GO! GO!')
  const reply = univerAPI.newTheadComment().setContent(replyText)
  await comment.replyAsync(reply)
}, 3000)

// Resolve the comment and delete it after 6 seconds
setTimeout(async () => {
  const comment = fWorksheet.getCommentById('mock-comment-id')
  await comment.resolveAsync()
  await comment.deleteAsync()
}, 6000)
```

### Обработчики событий

Полные определения типов событий приведены в разделе [Events](https://docs.univer.ai/reference/facade/events).

Модуль комментариев испускает события для добавлений комментариев, обновлений, удалений и изменений статуса разрешения.Подписаться на любое из этих событий с `univerAPI.addEvent()`.

#### События добавления комментариев

`univerAPI.Event.CommentAdded` загорается после добавления комментария.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentAdded, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentAdd` загорается до добавления комментария.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentAdd, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // Cancel the comment addition operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### События обновления комментариев

`univerAPI.Event.CommentUpdated` загорается после обновления комментария.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentUpdated, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentUpdate` загорается до обновления комментария.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentUpdate, (params) => {
  const { comment, workbook, worksheet, row, col, newContent } = params

  // Cancel the comment update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### События удаления комментариев

`univerAPI.Event.CommentDeleted` загорается после удаления комментария.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentDeleted, (params) => {
  const { commentId, workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentDelete` загорается до удаления комментария.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentDelete, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // Cancel the comment deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### События изменения статуса комментария

`univerAPI.Event.CommentResolved` увольняется после изменения статуса комментария.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentResolved, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentResolve` загорается до изменения статуса комментария.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentResolve, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params

  // Cancel the comment resolution operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

Все события имеют следующие общие параметры:

- `workbook`: текущая книга
- `worksheet`: текущий рабочий лист
- `row`: индекс строки комментария
- `col`: индекс столбца комментария
- `comment`: объект комментария (`commentId` только в событиях удаления)

Некоторые события добавляют свои параметры:

- `BeforeCommentUpdate` также содержит `newContent`, новый контент комментариев (тип RichTextValue)
- `CommentResolved` и `BeforeCommentResolve` также имеют статус разрешения `resolved`.

Каждый обратный вызов `Before` может установить `params.cancel = true`, чтобы остановить операцию.

## Общие операции [#shared-comment-api]

Импортируйте как общий комментарий Facade, так и продукт Facade, прежде чем вызывать эти методы. Помощники продукта создают стабильные якоря, а общий API обрабатывает ответы, обновления, разрешение и удаление. `getComments()` читает только локальное состояние. `listCommentsAsync()` синхронизирует потоки, о которых он уже знает, через настроенный источник данных; он не обнаруживает каждый поток на сервере.

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## Общие обсуждения [#shared-discussions]

Общие обсуждения требуют службы комментариев и конечной точки, интегрированной через [Server SDK](/server/collaboration/extensions). После настройки совместной работы и лицензии регистрируйте `UniverThreadCommentDataSourcePlugin` от `@univerjs-pro/thread-comment-datasource`... Поставляемый источник данных использует `/universer-api/comment/unit/{unitId}/...` и `/universer-api/user/list`, поэтому приложение должно разоблачать эти маршруты. Комментарии читаются и пишут требуют отдельных разрешений на сервере; разрешения на редактирование документов их не покрывают.

## Комментарии к изображениям и диаграммам [#object-comments]

После настройки хост-чертежа или плагина диаграммы добавьте соответствующую интеграцию ниже вместе с входом в Facade перед открытием режима Unit. Режим плагина и заданный режим требуют, чтобы эти интеграции были зарегистрированы явно. Они не добавляют дополнительных стилей или локализаций.

```package-install
npm install @univerjs-pro/sheets-drawing-thread-comment @univerjs-pro/sheets-chart-thread-comment
```

```typescript
import { UniverSheetsDrawingThreadCommentPlugin } from '@univerjs-pro/sheets-drawing-thread-comment'
import { UniverSheetsChartThreadCommentPlugin } from '@univerjs-pro/sheets-chart-thread-comment'
import '@univerjs-pro/sheets-drawing-thread-comment/facade'
import '@univerjs-pro/sheets-chart-thread-comment/facade'

univer.registerPlugin(UniverSheetsDrawingThreadCommentPlugin)
univer.registerPlugin(UniverSheetsChartThreadCommentPlugin)
```

С открытым блоком комментарии могут быть добавлены к существующим изображениям или диаграммам. `getComments()` возвращает потоки, загруженные локально; `listCommentsAsync()` синхронизирует потоки, о которых он знает, прежде чем возвращать их.

```typescript
const host = univerAPI.getActiveWorkbook()?.getActiveSheet()
const image = host?.getImages()[0]
const chart = host?.getCharts()[0]
await image?.createCommentAsync('Review this image.')
await chart?.createCommentAsync('Verify the chart source.')
```
