アノテーションは、セルにコメントを添付するので、説明するデータの隣に追加情報やコンテキストが残されます。このページでは、Facade APIを通してアノテーションを読み、作成、更新、削除する方法を説明し、それらが発生したイベントをリストします。

## プラグインモード

### インストール

```package-install
npm install @univerjs/sheets-note @univerjs/sheets-note-ui
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsNotePlugin } from '@univerjs/sheets-note' // [!code ++]
import { UniverSheetsNoteUIPlugin } from '@univerjs/sheets-note-ui' // [!code ++]
import SheetsNoteJaJP from '@univerjs/sheets-note/locale/ja-JP' // [!code ++]
import SheetsNoteUIJaJP from '@univerjs/sheets-note-ui/locale/ja-JP' // [!code ++]
import '@univerjs/sheets-note-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-note/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      SheetsNoteJaJP, // [!code ++]
      SheetsNoteUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsNotePlugin) // [!code ++]
univer.registerPlugin(UniverSheetsNoteUIPlugin) // [!code ++]
```

## プリセットモード

### インストール

```package-install
npm install @univerjs/preset-sheets-note
```

### 使い方

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreJaJP from '@univerjs/preset-sheets-core/locales/ja-JP'
import { UniverSheetsNotePreset } from '@univerjs/preset-sheets-note' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetSheetsCoreJaJP,

  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsNotePreset(), // [!code ++]
  ],
})
```

## Facade API

完全なFacade APIタイプ定義は[FacadeAPI](/reference/facade)にあります。

### インポート

<Callout type="info" title="プラグインモードノート">
  ファサードパッケージは、プラグインモードでのみ手動でインポートされます。プリセットモードには、対応するパッケージが含まれています。
</Callout>

```typescript
import '@univerjs/sheets-note/facade'
```

### 備考の取得

`FWorksheet.getNotes`はワークシート内のすべてのアノテーションを返します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const notes = fWorksheet.getNotes()

notes.forEach((item) => {
  const { row, col, note } = item
  console.log(`Cell ${fWorksheet.getRange(row, col).getA1Notation()} has note: ${note}`)
})
```

`FRange.getNote`は、範囲の左上にあるセル上のアノテーションを返します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:D10')
const note = fRange.getNote()
```

### 備考の追加または更新

`FRange.createOrUpdateNote`は、範囲の左上にあるセル上のアノテーションを作成または更新します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1')
fRange.createOrUpdateNote({
  note: 'This is an annotation',
  width: 160,
  height: 100,
  show: true,
})
```

### 備考の削除

`FRange.deleteNote`は、範囲の左上にあるセル上のアノテーションを削除します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const notes = fWorksheet.getNotes()

if (notes.length > 0) {
  // ワークシート内の最初の備考を削除する
  const { row, col } = notes[0]
  fWorksheet.getRange(row, col).deleteNote()
}

// セル C1 の備考を削除する
const fRange = fWorksheet.getRange('C1')
fRange.deleteNote()
```

### イベントリスナー

[イベント](https://docs.univer.ai/reference/facade/events) では、完全なイベント型定義が定義されています。

| イベント名 | 説明 |
| ---------- | ---- |
| `SheetNoteAdd` | アノテーション後の火炎を追加 |
| `SheetNoteDelete` | アノテーション後の火は削除されます |
| `SheetNoteUpdate` | アノテーション後の火が更新されます |
| `SheetNoteShow` | アノテーションが示されるときの火 |
| `SheetNoteHide` | アノテーションが隠されると火 |
| `BeforeSheetNoteAdd` | アノテーション前の火薬を追加 |
| `BeforeSheetNoteDelete` | 注釈が削除される前の火 |
| `BeforeSheetNoteUpdate` | 注釈が更新される前の火 |
| `BeforeSheetNoteShow` | アノテーション前の火は示されます |
| `BeforeSheetNoteHide` | アノテーション前の火は隠されます |

##### イベントリスナーの例

```typescript
// 備考を追加した後にトリガーされる
const disposable = univerAPI.addEvent(univerAPI.Event.SheetNoteAdd, (params) => {
  const { workbook, worksheet, row, col, note } = params
})

// `disposable.dispose()` を使ってイベントリスナーを削除します
```

```typescript
// 備考を削除する前にトリガーされ、キャンセル可能です
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetNoteDelete, (params) => {
  const { workbook, worksheet, row, col, oldNote } = params

  // 備考の削除操作をキャンセルする
  params.cancel = true
})

// `disposable.dispose()` を使ってイベントリスナーを削除します
```
