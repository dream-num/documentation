十字高亮將使用者選中的單元格所在行列突出顯示，以便使用者更容易地識別當前選中的單元格。

<PlaygroundFrame lang="zh-TW" slug="sheets/crosshair-highlighting" clickToShow />

## 預設模式

十字高亮並未提供預設模式，但支援與其外掛混用。

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### 使用

```typescript
import UniverPresetSheetsCoreZhTW from '@univerjs/preset-sheets-core/locales/zh-TW'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight' // [!code ++]

import '@univerjs/sheets-crosshair-highlight/facade' // [!code ++]

import '@univerjs/sheets-crosshair-highlight/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      UniverPresetSheetsCoreZhTW,
      SheetsCrosshairHighlightZhTW, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    UniverSheetsCrosshairHighlightPlugin, // [!code ++]
  ],
})
```

## 外掛模式

### 安裝

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### 使用

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight'
import SheetsCrosshairHighlightZhTW from '@univerjs/sheets-crosshair-highlight/locale/zh-TW'

import '@univerjs/sheets-crosshair-highlight/lib/index.css'

import '@univerjs/sheets-crosshair-highlight/facade'

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      SheetsCrosshairHighlightZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsCrosshairHighlightPlugin) // [!code ++]
```

## Facade API

完整 Facade API 型別定義，請檢視 [FacadeAPI](https://reference.univer.ai/zh-TW)。

### 引入

<Callout type="info" title="外掛模式提示">
  僅外掛模式需要手動引入 Facade 套件。預設模式已內建對應的 Facade 套件，無需額外引入。
</Callout>

```typescript
import '@univerjs/sheets-crosshair-highlight/facade'
```

### 切換十字高亮開關

```typescript
univerAPI.setCrosshairHighlightEnabled(true)

univerAPI.setCrosshairHighlightEnabled(false)
```

### 獲取十字高亮開關狀態

```typescript
univerAPI.getCrosshairHighlightEnabled()
```

### 設定十字高亮顏色

```typescript
univerAPI.setCrosshairHighlightColor('red')
```

### 獲取十字高亮顏色

```typescript
univerAPI.getCrosshairHighlightColor()
```

### 事件監聽

完整事件型別定義，請檢視 [Events](https://reference.univer.ai/zh-TW/classes/FEventName)。

`CrosshairHighlightEnabledChanged` 事件將在十字高亮開關狀態發生變化時觸發。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CrosshairHighlightEnabledChanged, (params) => {
  const { enabled, workbook, worksheet } = params
})

// 移除事件監聽器，使用 `disposable.dispose()`
```

`CrosshairHighlightColorChanged` 事件將在十字高亮顏色發生變化時觸發。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CrosshairHighlightColorChanged, (params) => {
  const { color, workbook, worksheet } = params
})

// 移除事件監聽器，使用 `disposable.dispose()`
```
