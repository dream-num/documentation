Сначала зарегистрируйте зависимости [поворотный стол](/guides/sheets/features/pivot-table) и [диаграмма](/guides/sheets/features/charts), затем добавьте два плагина ниже перед созданием рабочей книги. объедините локализацию пользовательского интерфейса в конфигурацию `locales` и загрузите соответствующую таблицу стилей. Требуется лицензия Pro.

```package-install
npm install @univerjs-pro/sheets-pivot-chart @univerjs-pro/sheets-pivot-chart-ui
```

```ts
import { UniverSheetsPivotChartPlugin } from '@univerjs-pro/sheets-pivot-chart'
import { UniverSheetsPivotChartUIPlugin } from '@univerjs-pro/sheets-pivot-chart-ui'
import SheetsPivotChartLocale from '@univerjs-pro/sheets-pivot-chart-ui/locale/ru-RU'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/sheets-pivot-chart/facade'
import '@univerjs-pro/sheets-pivot-chart-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.RU_RU, SheetsPivotChartLocale)

univer.registerPlugin(UniverSheetsPivotChartPlugin)
univer.registerPlugin(UniverSheetsPivotChartUIPlugin)
```

Предварительный набор расширенных листов уже включает в себя оба плагина. Используйте его вместе с ядром и предварительными наборами рисования и импортируйте `@univerjs-pro/sheets-pivot-chart/facade` явно для API на этой странице.

## Настройка Worker [#worker-configuration]

### Настройка пресетов

Эти параметры относятся к `UniverSheetsAdvancedPreset`:

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `useWorker` | `boolean` | `false` | Включает расширенные возможности в Worker вычислений. |

Если вы используете [рабочий](/guides/sheets/getting-started/worker), передайте `UniverSheetsAdvancedPreset({ useWorker: true })` на главную нить и `UniverSheetsAdvancedWorkerPreset()` внутри Рабочего. детали плагин-режима находятся в [пакетная ссылка](/reference/packages/plugins/univerjs-pro/sheets-pivot-chart#worker-calculation).

## Независимый отчёт [#owned-report]

Независимая диаграмма владеет своим отчетом. После вставки добавьте поле строк и поле значений. В примере используются первые два столбца источника.

```ts
const workbook = univerAPI.getActiveWorkbook()
const sheet = workbook?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

sheet.getRange('A1:B4').setValues([
  ['Region', 'Sales'], ['East', 100], ['West', 200], ['East', 50],
])
const chart = await sheet.insertPivotChart(
  sheet.newPivotChart(univerAPI.Enum.ChartTypeString.Column)
    .setSource('A1:B4').setPosition('D2').setSize(640, 360).build(),
)
const fields = chart.getSourceFieldsInfo()
await chart.addField(fields[0].id, univerAPI.Enum.PivotTableFiledAreaEnum.Row, 0)
await chart.addField(fields[1].id, univerAPI.Enum.PivotTableFiledAreaEnum.Value, 0)
```

## Связь со сводной таблицей [#linked-report]

Редактирование поля, фильтра, сортировки и коллапса совместно с упоминаемой PivotTable и другими связанными графиками, при этом внешний вид и положение остаются независимыми.Удаление диаграммы не удаляет таблицу; удаление таблицы делает диаграмму недоступной до тех пор, пока та же таблица не будет восстановлена.

```ts
const pivotTable = workbook.getPivotTableById('pivot-table-1')
if (!pivotTable) throw new Error('PivotTable not found')

const linkedChart = await sheet.insertPivotChart(
  pivotTable.newChart(univerAPI.Enum.ChartTypeString.Line).setPosition('D22').build(),
)
linkedChart.setFieldButtonsVisible(true).setExpandCollapseButtonsVisible(true)
```

## Поддерживаемые типы диаграмм [#types-and-worker]

Поддерживаются линии, столбцы, бары, площадь, пирог, пончик и комбинированные диаграммы, в том числе сложенные варианты, где они доступны. Не поддерживаются разброс, пузырь, радар и водопад. Пирог использует первую серию значений; пончик сохраняет несколько серий. Субтоты и общие суммы исключаются из категорий диаграмм.

[Источник: PivotChart](/reference/facade/sheet-pivot-chart) для поля, фильтра, стиля и API жизненного цикла.

## Копирование и удаление листов [#copy-and-delete-sheets]

Копирование рабочего листа также копирует его PivotCharts и присваивает им новые идентификаторы. Независимый отчет, источник которого находится на скопированном листе, использует новый лист и независимый кэш. Связанная диаграмма следует за скопированной PivotTable, когда эта таблица копируется с листом, и ссылки на другие листы остаются неизменными. Удаление рабочего листа удаляет его PivodCharts, а также ресурсы, связанные с ними; отменяет их определения и исходные данные.

## Фильтры отчёта [#report-filters]

`getOptions()`, `setOptions({ allowMultipleFilters: true })` и `setDateFilter(fieldId, condition)` действуют в авторитетном отчете графика. На связанном графике они обновляют PivotTable и другие связанные графики; на независимом графике они обновляет только отчет этого графика. Omit `condition` для очистки только условия даты. Для серий дат и сравнений на целый день см. [Несколько фильтров и условия даты](/guides/sheets/features/pivot-table#multiple-filters).
