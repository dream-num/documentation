Les utilisateurs peuvent laisser des commentaires et des réponses sur un document, afin qu'une équipe puisse discuter du contenu en un seul endroit.

## Mode plugin

### Installation

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs/sheets-thread-comment @univerjs/sheets-thread-comment-ui
```

### Utilisation

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsThreadCommentPlugin } from '@univerjs/sheets-thread-comment' // [!code ++]
import { UniverSheetsThreadCommentUIPlugin } from '@univerjs/sheets-thread-comment-ui' // [!code ++]
import SheetsThreadCommentUIEnUS from '@univerjs/sheets-thread-comment-ui/locale/en-US' // [!code ++]
import { UniverThreadCommentPlugin } from '@univerjs/thread-comment' // [!code ++]

import '@univerjs/sheets-thread-comment-ui/lib/index.css'
import '@univerjs/thread-comment-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-thread-comment/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
```

### Créer un commentaire de cellule

`univerAPI.newTheadComment()` retourne un `FTheadCommentBuilder` pour un nouveau commentaire. Méthodes de chaîne sur le constructeur pour définir les propriétés du commentaire.

Voici quelques méthodes membres de [`FTheadCommentBuilder`](/reference/facade/thead-comment-builder) :

| Méthode | Description |
| ---- | ---- |
| setContent | Définit le contenu du commentaire |
| setPersonId | Définit l'identifiant de la personne du commentaire |
| setDateTime | Définit la date et l'heure du commentaire |
| setId | Définit l'identifiant du commentaire |
| setThreadId | Définit l'ID du thread du commentaire |

```typescript
// Create a new comment
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)

console.log(commentBuilder.content.toPlainText())

// Add the comment to cell A1
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const cell = fWorksheet.getRange('A1')
const result = await cell.addCommentAsync(commentBuilder)
```

### Obtenir les commentaires des cellules

Ces méthodes renvoient un `FThreadComment`, qui peut ensuite être mis à jour, supprimé ou résolu.

- `FWorkbook.getComments()`: obtient tous les commentaires dans le cahier
- `FfWorksheet.getComments()`: obtient tous les commentaires dans la feuille de travail
- `FRange.getComment()`: obtient le commentaire de la cellule supérieure gauche dans la plage
- `FRange.getComments()`: obtient tous les commentaires dans la gamme

Voici quelques méthodes membres de [`FThreadComment`](https://docs.univer.ai/reference/facade/thread-comment) :

| Méthode | Description |
| ---- | ---- |
| getIsRoot | Indique si le commentaire est un commentaire racine |
| getCommentData | Obtient les données de commentaires |
| getReplies | Obtient la liste des réponses au commentaire |
| getRange | Obtient la gamme du commentaire |
| getRichText | Obtient le contenu texte riche du commentaire |
| deleteAsync | Supprime le commentaire et ses réponses |
| updateAsync | Mettre à jour le contenu des commentaires |
| resolveAsync | Résoudre le commentaire |
| replyAsync | Réponses au commentaire |

```typescript
// Get all comments in the workbook
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.getComments()

// Get all comments in the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.getComments()

const fRange = fWorksheet.getRange('A1:B2')
// Get the comment of cell A1
fRange.getComment()

// Get all comments in the range A1:B2
fRange.getComments()
```

### Effacer les commentaires des cellules

- `FWorkbook.clearComments()`: efface tous les commentaires dans le cahier
- `FWorksheet.clearComments()`: efface tous les commentaires dans la feuille de travail
- `FRange.clearCommentAsync()`: efface le commentaire de la cellule supérieure gauche dans la plage
- `FRange.clearCommentsAsync()`: efface tous les commentaires dans la gamme

```typescript
// Clear all comments in the workbook
const fWorkbook = univerAPI.getActiveWorkbook()
await fWorkbook.clearComments()

// Clear all comments in the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
await fWorksheet.clearComments()

const fRange = fWorksheet.getRange('A1:B2')

// Clear the comment of cell A1
await fRange.clearCommentAsync()

// Clear all comments in the range A1:B2
await fRange.clearCommentsAsync()
```

### Obtenir la liste des réponses à un commentaire

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all comments in the worksheet
const comments = fWorksheet.getComments()
comments.forEach((comment) => {
  // If the comment is a root comment, get its replies
  if (comment.getIsRoot()) {
    const replies = comment.getReplies()
    replies.forEach((reply) => {
      console.log(reply.getCommentData())
    })
  }
})
```

### Mettre à jour, supprimer, résoudre des commentaires ou y répondre

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new comment and add it to cell A1
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)
  .setId('mock-comment-id')
const cell = fWorksheet.getRange('A1')
await cell.addCommentAsync(commentBuilder)

// Update the comment and reply after 3 seconds
setTimeout(async () => {
  // Get the comment by ID and update its content
  const comment = fWorksheet.getCommentById('mock-comment-id')
  const newRichText = univerAPI.newRichText().insertText('Hello Univer AI')
  await comment.updateAsync(newRichText)

  // Create a new reply comment and set its content
  const replyText = univerAPI.newRichText().insertText('Hello Univer AI! GO! GO! GO!')
  const reply = univerAPI.newTheadComment().setContent(replyText)
  await comment.replyAsync(reply)
}, 3000)

// Resolve the comment and delete it after 6 seconds
setTimeout(async () => {
  const comment = fWorksheet.getCommentById('mock-comment-id')
  await comment.resolveAsync()
  await comment.deleteAsync()
}, 6000)
```

### Écouteurs d’événements

Consultez les définitions complètes des types d’événements dans [Events](https://docs.univer.ai/reference/facade/events).

Le module de commentaires émet des événements pour les ajouts de commentaires, les mises à jour, les suppressions et les changements d'état de résolution. `univerAPI.addEvent()`.

#### Événements d’ajout de commentaire

`univerAPI.Event.CommentAdded` allume après l'ajout d'un commentaire.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentAdded, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentAdd` allume avant qu'un commentaire ne soit ajouté.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentAdd, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // Cancel the comment addition operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Événements de mise à jour de commentaire

`univerAPI.Event.CommentUpdated` allume après la mise à jour d'un commentaire.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentUpdated, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentUpdate` allume avant qu'un commentaire ne soit mis à jour.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentUpdate, (params) => {
  const { comment, workbook, worksheet, row, col, newContent } = params

  // Cancel the comment update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Événements de suppression de commentaire

`univerAPI.Event.CommentDeleted` allume après la suppression d'un commentaire.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentDeleted, (params) => {
  const { commentId, workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentDelete` allume avant qu'un commentaire ne soit supprimé.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentDelete, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // Cancel the comment deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Événements de changement de l’état de résolution

`univerAPI.Event.CommentResolved` s'allume après que l'état de résolution d'un commentaire change.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentResolved, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentResolve` s'allume avant que l'état de résolution d'un commentaire ne change.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentResolve, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params

  // Cancel the comment resolution operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

Tous les événements comportent les paramètres communs suivants:

- `workbook` : le cahier de travail actuel
- `worksheet` : la feuille de travail actuelle
- `row`: l'index des lignes du commentaire
- `col`: l'index de colonne du commentaire
- `comment`: l'objet commentaire (`commentId` uniquement dans les événements de suppression)

Certains événements ajoutent leurs propres paramètres :

- `BeforeCommentUpdate` transporte également `newContent`, le nouveau contenu de commentaire (Type RichTextValue)
- `CommentResolved` et `BeforeCommentResolve` portent également `resolved`, le statut de résolution du commentaire

Chaque callback `Before` peut définir `params.cancel = true` pour arrêter l'opération.

## Opérations communes [#shared-comment-api]

Importez à la fois le commentaire partagé Facade et le produit Facade avant d'appeler ces méthodes. Les helpers de produit créent des ancres stables, et l'API partagée gère les réponses, les mises à jour, la résolution et la suppression. `getComments()` lit seulement l'état local. `listCommentsAsync()` synchronise les threads qu'il connaît déjà à travers la source de données configurée; il ne découvre pas chaque thread sur le serveur.

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## Discussions partagées [#shared-discussions]

Les discussions partagées nécessitent le service de commentaires et l'Endpoint, intégrés par [Server SDK](/server/collaboration/extensions). Après la collaboration et la licence sont configurées, enregistrez `UniverThreadCommentDataSourcePlugin` depuis `@univerjs-pro/thread-comment-datasource` . La source de données fournie utilise `/universer-api/comment/unit/{unitId}/...` et `/universer-api/user/list`, de sorte que l'application doit exposer ces routes.

## Commentaires sur les images et graphiques [#object-comments]

Après avoir configuré le plugin host dessin ou graphique, ajoutez l'intégration correspondante ci-dessous avec son entrée Facade avant d'ouvrir l'unité. Le mode Plugin et le mode préréglé exigent tous deux que ces intégrations soient enregistrées explicitement. Ils n'ajoutent pas de styles ou de localisations supplémentaires.

```package-install
npm install @univerjs-pro/sheets-drawing-thread-comment @univerjs-pro/sheets-chart-thread-comment
```

```typescript
import { UniverSheetsDrawingThreadCommentPlugin } from '@univerjs-pro/sheets-drawing-thread-comment'
import { UniverSheetsChartThreadCommentPlugin } from '@univerjs-pro/sheets-chart-thread-comment'
import '@univerjs-pro/sheets-drawing-thread-comment/facade'
import '@univerjs-pro/sheets-chart-thread-comment/facade'

univer.registerPlugin(UniverSheetsDrawingThreadCommentPlugin)
univer.registerPlugin(UniverSheetsChartThreadCommentPlugin)
```

Avec l'unité ouverte, des commentaires peuvent être ajoutés aux images ou aux graphiques existants. `getComments()` retourne les threads chargés localement; `listCommentsAsync()` synchronise les threades qu'il connaît avant de les renvoyer.

```typescript
const host = univerAPI.getActiveWorkbook()?.getActiveSheet()
const image = host?.getImages()[0]
const chart = host?.getCharts()[0]
await image?.createCommentAsync('Review this image.')
await chart?.createCommentAsync('Verify the chart source.')
```
