La fonctionnalité d’impression permet d’imprimer le contenu d’une feuille de calcul sur papier ou de l’exporter au format PDF pour le consulter hors ligne et le partager.

<PlaygroundFrame lang="fr-FR" slug="sheets/print" clickToShow />

## Mode prédéfini

La fonctionnalité d’impression est incluse dans le préréglage `@univerjs/preset-sheets-advanced`.

### Installation

<Callout>
  À l’exécution, le préréglage `UniverSheetsAdvancedPreset` de `@univerjs/preset-sheets-advanced` dépend du préréglage
  `UniverSheetsDrawingPreset`. Installez d’abord `@univerjs/preset-sheets-drawing`.
</Callout>

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

### Utilisation

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
import UniverPresetSheetsAdvancedEnUS from '@univerjs/preset-sheets-advanced/locales/en-US' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]
import UniverPresetSheetsDrawingEnUS from '@univerjs/preset-sheets-drawing/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-advanced/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsDrawingEnUS, // [!code ++]
      UniverPresetSheetsAdvancedEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsDrawingPreset(), // [!code ++]
    UniverSheetsAdvancedPreset(), // [!code ++]
  ],
})
```

Si vous disposez d’une licence commerciale Univer, consultez la section [Utiliser une licence côté client](/guides/pro/license#in-preset-mode) pour effectuer la configuration.

## Mode extension

### Installation

```package-install
npm install @univerjs-pro/sheets-print
```

### Utilisation

```typescript
import { UniverSheetsPrintPlugin } from '@univerjs-pro/sheets-print' // [!code ++]
import SheetsPrintPluginEnUS from '@univerjs-pro/sheets-print/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-print/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      SheetsPrintPluginEnUS, // [!code ++]

  },
})

```

## Facade API

### Ouvrir la boîte de dialogue de configuration de l’impression

Utilisez `FWorkbook.openPrintDialog` pour ouvrir la boîte de dialogue de configuration de l’impression.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

fWorkbook.openPrintDialog()
```

### Fermer la boîte de dialogue de configuration de l’impression

Utilisez la méthode `FWorkbook.closePrintDialog` pour fermer la boîte de dialogue de configuration de l’impression.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.openPrintDialog()

// Close the print configuration dialog after 3 seconds
setTimeout(() => {
  fWorkbook.closePrintDialog()
}, 3000)
```

### Mettre à jour la configuration de la mise en page

Utilisez la méthode [`FWorkbook.updatePrintConfig(config: ISheetPrintLayoutConfig)`](https://docs.univer.ai/reference/facade/workbook#updateprintconfig) pour mettre à jour la configuration de la mise en page.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const subUnitId = fWorksheet.getSheetId()

// Update print layout config
fWorkbook.updatePrintConfig({
  area: univerAPI.Enum.PrintArea.CurrentSheet, // print current sheet
  subUnitIds: [subUnitId],
  paperSize: univerAPI.Enum.PrintPaperSize.A4, // A4 paper size
  scale: univerAPI.Enum.PrintScale.FitPage, // fit content to page
  freeze: [univerAPI.Enum.PrintFreeze.Row], // freeze row headers
  margin: univerAPI.Enum.PrintPaperMargin.Normal, // normal margin
  // ... other settings
})

// Start printing with the updated configuration
fWorkbook.print()
```

### Mettre à jour la configuration du rendu d’impression

Utilisez la méthode [`FWorkbook.updatePrintRenderConfig(config: ISheetPrintRenderConfig)`](https://docs.univer.ai/reference/facade/workbook#updateprintrenderconfig) pour mettre à jour la configuration du rendu d’impression.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Update print layout config by default
fWorkbook.updatePrintConfig({})

// Update print render config
fWorkbook.updatePrintRenderConfig({
gridlines: true, // show gridlines
hAlign: univerAPI.Enum.PrintAlign.Middle, // horizontal align middle
vAlign: univerAPI.Enum.PrintAlign.Middle, // vertical align middle
headerFooter: [ // the array of header and footer elements to include, here is page numbers and worksheet name
  univerAPI.Enum.PrintHeaderFooter.PageSize,
  univerAPI.Enum.PrintHeaderFooter.WorksheetTitle,
],
// ... other settings
})

// Start print
fWorkbook.print()
````

### Imprimer

La méthode `FWorkbook.print` permet d’ouvrir directement la boîte de dialogue d’impression.

```typescript
// Using the default configuration you can pass in an empty object
workbook.updatePrintConfig({
// ... Print layout configuration
})
workbook.updatePrintRenderConfig({
// ... Print render configuration
})
workbook.print()
````

### Enregistrer une capture d’écran dans le presse-papiers

La méthode `FWorkbook.saveScreenshotToClipboard` permet d’enregistrer dans le presse-papiers l’image des données à imprimer.

Cette fonctionnalité est uniquement disponible avec une [licence](/guides/pro/license). Sans licence, son utilisation est restreinte et l’opération d’enregistrement renvoie `false`.

L’image est enregistrée dans le presse-papiers à l’aide de l’API Clipboard. L’opération peut échouer dans un environnement réseau non sécurisé ou dans un navigateur non compatible. Si elle réussit, elle renvoie `true`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const result = await fWorkbook.saveScreenshotToClipboard()
```

### Obtenir une capture d’écran de la plage sélectionnée

La méthode `FRange.getScreenshot` permet d’obtenir une capture d’écran des données à imprimer dans la plage sélectionnée.

Cette fonctionnalité est uniquement disponible avec une [licence](/guides/pro/license). Sans licence, son utilisation est restreinte. L’opération d’enregistrement renvoie `false` en cas d’échec, ou une chaîne base64 contenant l’image en cas de réussite.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:D10')
fRange.getScreenshot()
fRange.getScreenshot({ includeHeaders: true }) // Include row and column headers
```

### Écouteurs d’événements

Les événements suivants sont disponibles pour la fonctionnalité d’impression :

L’événement `univerAPI.Event.BeforeSheetPrintOpen` est déclenché avant l’ouverture de la boîte de dialogue de configuration de l’impression.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetPrintOpen, (params) => {
  const { workbook, worksheet } = params

  // Cancel open print configuration dialog operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`.
```

L’événement `univerAPI.Event.SheetPrintOpen` est déclenché après l’ouverture de la boîte de dialogue de configuration de l’impression.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetPrintOpen, (params) => {
  const { workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`.
```

L’événement `univerAPI.Event.BeforeSheetPrintConfirm` est déclenché avant l’ouverture de la boîte de dialogue de confirmation de l’impression.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetPrintConfirm, (params) => {
  const { renderConfig, layoutConfig } = params

  // Cancel the print confirmation operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`.
```
