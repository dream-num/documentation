<Callout type="warning" title="Remarque">
  Le partage en direct réutilise la connexion collaborative. Intégrez [Univer Server SDK](/server/collaboration/browser-integration), puis implémentez le [protocole Live Share](/server/collaboration/extensions#live-share) dans votre backend. **L’Endpoint de collaboration `1.0.0-rc.0` ne traite pas les messages `liveshare.*` ; le démarrage rapide seul n’active pas cette fonctionnalité.** Configurez la [licence client](/server/license) séparément.
</Callout>

Le partage en direct permet aux utilisateurs de synchroniser en temps réel les actions effectuées dans leur vue, telles que le défilement et les changements de sélection, avec les autres participants qui les suivent pendant une session collaborative. Il permet également de suivre la vue d’un autre utilisateur. Cette fonctionnalité est particulièrement utile pour les présentations en réunion et les démonstrations pédagogiques.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/live-share
```

### Utilisation

```typescript
import { UniverLiveSharePlugin } from '@univerjs-pro/live-share' // [!code ++]
import { Univer } from '@univerjs/core'

import '@univerjs-pro/live-share/lib/index.css' // [!code ++]

import '@univerjs-pro/live-share/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverLiveSharePlugin)
```

Si vous disposez d’une licence commerciale Univer, consultez la page [Utiliser une licence côté client](/server/license#in-plugin-mode) pour effectuer la configuration.

## API Facade

Le partage en direct étend les interfaces correspondantes de l’API Facade, que vous pouvez appeler directement via `univerAPI`.

### Importation

```typescript
import '@univerjs-pro/live-share/facade'
```

### Énumération des états

```typescript
export enum LiveShareStatus {
  OFFLINE = 'offline',
  IDLE = 'idle',
  FOLLOWING = 'following',
  NOT_FOLLOWING = 'not-following',
  PRESENTING = 'presenting',
}
```

### Exemple d’utilisation

```typescript
import { LiveShareStatus } from '@univerjs-pro/live-share'

// Get current status
const status = univerAPI.getLiveShareStatus()

if (status === LiveShareStatus.IDLE) {
  // If currently idle, start presenting
  univerAPI.startPresenting()
} else if (status === LiveShareStatus.PRESENTING) {
  // If presenting, stop presenting
  univerAPI.stopPresenting()
}

// Start following
univerAPI.startFollowing()

// Stop following
univerAPI.stopFollowing()
```
