La fonctionnalité Rechercher et remplacer permet de rechercher rapidement un contenu précis dans une feuille de calcul et de le remplacer. Plusieurs options de correspondance facilitent le traitement efficace des données.

<PlaygroundFrame lang="fr-FR" slug="sheets/find-replace" clickToShow />

## Mode prédéfini

### Installation

```package-install
npm install @univerjs/preset-sheets-find-replace
```

### Utilisation

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsFindReplacePreset } from '@univerjs/preset-sheets-find-replace' // [!code ++]
import UniverPresetSheetsFindReplaceEnUS from '@univerjs/preset-sheets-find-replace/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-find-replace/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsFindReplaceEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsFindReplacePreset(), // [!code ++]
  ],
})
```

## Mode plugin

### Installation

```package-install
npm install @univerjs/find-replace @univerjs/sheets-find-replace
```

### Utilisation

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverFindReplacePlugin } from '@univerjs/find-replace' // [!code ++]
import FindReplaceEnUS from '@univerjs/find-replace/locale/en-US' // [!code ++]
import { UniverSheetsFindReplacePlugin } from '@univerjs/sheets-find-replace' // [!code ++]

import '@univerjs/find-replace/lib/index.css' // [!code ++]

import '@univerjs/sheets-find-replace/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      FindReplaceEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverFindReplacePlugin) // [!code ++]
univer.registerPlugin(UniverSheetsFindReplacePlugin) // [!code ++]
```

### Créer un outil de recherche de texte

`univerAPI.createTextFinderAsync()` crée un outil de recherche de texte et renvoie une instance de `FTextFinder`.

Voici quelques méthodes de [`FTextFinder`](https://docs.univer.ai/reference/facade/find-replace) :

| Méthode | Description |
| ------ | ----------- |
| findAll | Récupère toutes les cellules correspondantes de la feuille active ; la cellule actuellement sélectionnée est la dernière correspondance. |
| findNext | Récupère la correspondance suivante dans la feuille active. Si elle existe, la méthode la renvoie et en fait la correspondance active. |
| findPrevious | Récupère la correspondance précédente dans la feuille active. Si elle existe, la méthode la renvoie et en fait la correspondance active. |
| getCurrentMatch | Récupère la correspondance active dans la feuille active. |
| matchCaseAsync | Définit l’option de respect de la casse. Si elle vaut true, la recherche respecte la casse ; sinon, elle l’ignore. |
| matchEntireCellAsync | Définit l’option de correspondance avec la cellule entière. Si elle vaut true, la recherche porte sur toute la valeur de la cellule ; sinon, elle peut correspondre à une partie de cette valeur. |
| matchFormulaTextAsync | Définit l’option de correspondance avec le texte des formules. Si elle vaut true, la recherche porte sur le texte des formules ; sinon, elle porte sur les valeurs. |
| replaceAllWithAsync | Remplace toutes les occurrences correspondantes par le texte indiqué. |
| replaceWithAsync | Remplace l’occurrence active par le texte indiqué. |
| ensureCompleteAsync | Vérifie que la recherche est terminée. Utilisez notamment cette méthode après un changement de feuille active. |

```typescript
// Assume the current sheet is empty sheet.
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set some values to the range A1:D10.
const fRange = fWorksheet.getRange('A1:D10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// Create a text-finder to find the text '5'.
const textFinder = await univerAPI.createTextFinderAsync('5')

// Find all cells that contain the text '5'.
const matchCells = textFinder.findAll()
matchCells.forEach((cell) => {
  cell.getA1Notation() // D2, C3, B4, A5
})
```
