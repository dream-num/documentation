Trouver et remplacer les recherches de texte dans une feuille et les remplacer. Les options de correspondance contrôlent la manière dont la recherche correspond strictement.

Utilisez le panneau de recherche et de remplacement dans l'exemple complet de plugin ci-dessous pour essayer la fonctionnalité.

<PlaygroundFrame lang="fr-FR" slug="sheets/basic-via-plugin" clickToShow />

## Mode plugin

### Installation

```package-install
npm install @univerjs/find-replace @univerjs/sheets-find-replace
```

### Utilisation

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverFindReplacePlugin } from '@univerjs/find-replace' // [!code ++]
import FindReplaceEnUS from '@univerjs/find-replace/locale/en-US' // [!code ++]
import { UniverSheetsFindReplacePlugin } from '@univerjs/sheets-find-replace' // [!code ++]
import '@univerjs/find-replace/lib/index.css' // [!code ++]
import '@univerjs/sheets-find-replace/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      FindReplaceEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverFindReplacePlugin) // [!code ++]
univer.registerPlugin(UniverSheetsFindReplacePlugin) // [!code ++]
```

## Prise en charge mobile [#mobile-support]

Configurez d'abord le [éditeur mobile](/guides/sheets/getting-started/installation#mobile-support). Dans la configuration en mode plugin sur cette page, remplacez les enregistrements de bureau ci-dessous par les exportations mobiles des mêmes paquets, et faites-le **avant d'ouvrir un document** . Gardez les plugins modèles, styles, locales et les importations de Facade comme ils sont, et ne enregistrez pas les deux variantes.

| Paquet | Inscription de bureau | Inscription mobile |
| --- | --- | --- |
| `@univerjs/find-replace` | `UniverFindReplacePlugin` | `UniverFindReplaceMobileUIPlugin` |
| `@univerjs/sheets-find-replace` | `UniverSheetsFindReplacePlugin` | `UniverSheetsFindReplaceMobileUIPlugin` |

## Mode prédéfini

### Installation

```package-install
npm install @univerjs/preset-sheets-find-replace
```

### Utilisation

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsFindReplacePreset } from '@univerjs/preset-sheets-find-replace' // [!code ++]
import UniverPresetSheetsFindReplaceEnUS from '@univerjs/preset-sheets-find-replace/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-find-replace/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsFindReplaceEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsFindReplacePreset(), // [!code ++]
  ],
})
```

### Créer un outil de recherche de texte

Appelez `univerAPI.createTextFinderAsync()` pour créer un rechercheur de texte. Il retourne une instance `FTextFinder`.

Le tableau ci-dessous énumère certaines des méthodes sur [`FTextFinder`](/reference/facade/text-finder).

| Méthode | Description |
| ------ | ----------- |
| findAll | Retourne chaque match dans la feuille courante. La correspondance courante se déplace vers la dernière correspondance. |
| findNext | Se déplace vers la prochaine correspondance dans la feuille courante et la renvoie si elle existe. |
| findPrevious | Se déplace vers la précédente correspondance dans la feuille courante et la renvoie si elle existe. |
| getCurrentMatch | Renvoie la correspondance courante dans la feuille courante. |
| matchCaseAsync | Définit l'option match-case. Lorsque c'est vrai, la recherche est sensible à la casse; sinon, elle ignore la casse. |
| matchEntireCellAsync | Définit l'option de la cellule entière. Lorsqu'elle est vraie, la recherche ne correspond qu'à la valeur de la cellule complète; sinon, elle peut correspondre à une partie de la valeur. |
| matchFormulaTextAsync | Définit l'option formula-text. Lorsque c'est vrai, la recherche examine le texte de la formule; sinon, elle examine les valeurs. |
| replaceAllWithAsync | Remplace chaque match par le texte donné. |
| replaceWithAsync | Remplace la correspondance actuelle par le texte donné. |
| ensureCompleteAsync | S'assure que l'opération de recherche est terminée, ce qui importe après les changements apportés à la feuille actuelle. |

```typescript
// Assume the current sheet is empty sheet.
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set some values to the range A1:D10.
const fRange = fWorksheet.getRange('A1:D10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// Create a text-finder to find the text '5'.
const textFinder = await univerAPI.createTextFinderAsync('5')

// Find all cells that contain the text '5'.
const matchCells = textFinder.findAll()
matchCells.forEach((cell) => {
  cell.getA1Notation() // D2, C3, B4, A5
})
```
