Find & Replace searches for text in a sheet and replaces it. Matching options control how strictly the search matches.

Use the find and replace panel in the complete plugin example below to try the feature.

<PlaygroundFrame lang="en-US" slug="sheets/basic-via-plugin" clickToShow />

## Plugin mode

### Installation

```package-install
npm install @univerjs/find-replace @univerjs/sheets-find-replace
```

### Usage

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverFindReplacePlugin } from '@univerjs/find-replace' // [!code ++]
import FindReplaceEnUS from '@univerjs/find-replace/locale/en-US' // [!code ++]
import { UniverSheetsFindReplacePlugin } from '@univerjs/sheets-find-replace' // [!code ++]
import '@univerjs/find-replace/lib/index.css' // [!code ++]
import '@univerjs/sheets-find-replace/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      FindReplaceEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverFindReplacePlugin) // [!code ++]
univer.registerPlugin(UniverSheetsFindReplacePlugin) // [!code ++]
```

## Mobile support [#mobile-support]

Set up the [mobile editor](/guides/sheets/getting-started/installation#mobile-support) first. ## Preset mode

### Installation

```package-install
npm install @univerjs/preset-sheets-find-replace
```

### Usage

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsFindReplacePreset } from '@univerjs/preset-sheets-find-replace' // [!code ++]
import UniverPresetSheetsFindReplaceEnUS from '@univerjs/preset-sheets-find-replace/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-find-replace/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsFindReplaceEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsFindReplacePreset(), // [!code ++]
  ],
})
```

### Create text finder

Call `univerAPI.createTextFinderAsync()` to create a text finder. It returns an `FTextFinder` instance.

The table below lists some of the methods on [`FTextFinder`](/reference/facade/text-finder).

| Method | Description |
| ------ | ----------- |
| findAll | Returns every match in the current sheet. The current match moves to the last match. |
| findNext | Moves to the next match in the current sheet and returns it if one exists. |
| findPrevious | Moves to the previous match in the current sheet and returns it if one exists. |
| getCurrentMatch | Returns the current match in the current sheet. |
| matchCaseAsync | Sets the match-case option. When true, the search is case-sensitive; otherwise it ignores case. |
| matchEntireCellAsync | Sets the whole-cell option. When true, the search matches only the complete cell value; otherwise it can match part of the value. |
| matchFormulaTextAsync | Sets the formula-text option. When true, the search examines formula text; otherwise it examines values. |
| replaceAllWithAsync | Replaces every match with the given text. |
| replaceWithAsync | Replaces the current match with the given text. |
| ensureCompleteAsync | Ensures that the find operation has completed. This matters after the current sheet changes. |

```typescript
// Assume the current sheet is empty sheet.
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set some values to the range A1:D10.
const fRange = fWorksheet.getRange('A1:D10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// Create a text-finder to find the text '5'.
const textFinder = await univerAPI.createTextFinderAsync('5')

// Find all cells that contain the text '5'.
const matchCells = textFinder.findAll()
matchCells.forEach((cell) => {
  cell.getA1Notation() // D2, C3, B4, A5
})
```
