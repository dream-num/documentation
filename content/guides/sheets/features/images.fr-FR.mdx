Univer prend en charge deux types d'images : les images flottantes, qui sont placées au-dessus de la grille, et les images cellulaires, qui sont liées à une seule cellule.

<PlaygroundFrame lang="fr-FR" slug="sheets/images" clickToShow />

## Mode plugin

### Installation

```package-install
npm install @univerjs/docs-drawing @univerjs/drawing @univerjs/drawing-ui @univerjs/sheets-drawing @univerjs/sheets-drawing-ui
```

### Utilisation

```typescript
import { IImageIoService, LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsDrawingPlugin } from '@univerjs/docs-drawing' // [!code ++]
import { UniverDrawingPlugin } from '@univerjs/drawing' // [!code ++]
import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui' // [!code ++]
import DrawingUIEnUS from '@univerjs/drawing-ui/locale/en-US' // [!code ++]
import { UniverSheetsDrawingPlugin } from '@univerjs/sheets-drawing' // [!code ++]
import { UniverSheetsDrawingUIPlugin } from '@univerjs/sheets-drawing-ui' // [!code ++]
import SheetsDrawingUIEnUS from '@univerjs/sheets-drawing-ui/locale/en-US' // [!code ++]
import '@univerjs/drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing/facade' // [!code ++]
import '@univerjs/sheets-drawing-ui/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DrawingUIEnUS, // [!code ++]
      SheetsDrawingUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverDrawingUIPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingUIPlugin) // [!code ++]
```

Si vous utilisez [Collaboration](/guides/docs/features/collaboration), ajoutez la configuration `override` :

```typescript
univer.registerPlugin(UniverDrawingPlugin, {
  override: [[IImageIoService, null]], // [!code ++]
  // allowImageSize: 20 * 1024 * 1024, // set the maximum allowed size of uploaded images to 20MB, optional
})
```

### Ajouter un élément DOM flottant

`FWorksheet.addFloatDomToPosition(layer)` ajoute un élément DOM flottant à la position spécifiée.

```tsx
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()

// You should register components at an appropriate time (e.g., when Univer is loaded)
// This is a React component. For Vue3 components, the third parameter should be `{ framework: 'vue3' }`
univerAPI.registerComponent(
  'myFloatDom',
  ({ data }) => (
    <div style={{ width: '100%', height: '100%', background: '#fff', border: '1px solid #ccc', boxSizing: 'border-box' }}>
      popup content:
      {' '}
      {data?.label}
    </div>
  ),
)

// Add a floating DOM
// If disposable is null, floating DOM addition failed
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'myFloatDom',
  initPosition: {
    startX: 100,
    endX: 300,
    startY: 100,
    endY: 200,
  },

  // Component data
  data: {
    label: 'hahah',
  },
})

// 2 秒后移除浮动 DOM
setTimeout(() => {
  disposable?.dispose()
}, 2000)
```

`FWorksheet.addFloatDomToRange(range, layer, domLayout)` ajoute un élément DOM flottant sur la plage spécifiée.

```tsx
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()

    display: 'flex',
    justifyContent: 'center',
    alignItems: 'center',

    transformOrigin: 'top left',
  }

    <div style={divStyle}>
      Loading...
    </div>

// Remove the floating DOM after 2 seconds
```

### Insérer des images flottantes

[`FWorksheet.newOverGridImage()`](https://docs.univer.ai/reference/facade/worksheet#newovergridimage) retourne un constructeur pour une image flottante, une instance de `FOverGridImageBuilder`. Chaining des setters produit un objet `ISheetImage` qui peut être inséré dans la feuille.

Le constructeur, [`FOverGridImageBuilder`](/reference/facade/over-grid-image-builder), fournit les méthodes suivantes:

| Méthode | Description |
| ------ | ----------- |
| buildAsync | Construisez l'image et retournez un objet `ISheetImage` |
| setSource | Définir la source de l'image |
| setColumn | Définir la position horizontale de l'image |
| setRow | Régler la position verticale de l'image |
| setColumnOffset | Définir le décalage horizontal de l'image |
| setRowOffset | Définissez le décalage vertical de l'image |
| setWidth | Définir la largeur de l'image |
| setHeight | Régler la hauteur de l'image |
| setAnchorType | Régler le type d'ancre, qui détermine si la position et la taille changent avec la cellule |
| setCropTop | Définir le bord supérieur de la région de culture de sorte que seule la partie désirée de l'image soit affichée |
| setCropLeft | Régler le bord gauche de la région de culture de sorte que seule la partie désirée de l'image soit affichée |
| setCropBottom | Régler le bord inférieur de la région de culture de sorte que seule la partie désirée de l'image soit affichée |
| setCropRight | Régler le bord droit de la région de culture de sorte que seule la partie désirée de l'image soit affichée |
| setRotate | Définit l’angle de rotation de l’image. |

```typescript
// create a new image builder and set image source.
// then build `ISheetImage` and insert it into the sheet, position is start from F6 cell, width is 500px, height is 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])
```

Une image peut également être insérée avec la méthode `FWorksheet.insertImage(url, column, row, offsetX, offsetY)`.

```typescript
// Insert an image to the sheet, position is F6, offset is 10px
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const result = await fWorksheet.insertImage('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', 5, 5, 10, 10)
```

### Récupérer les images flottantes

`FWorksheet.getImages()` retourne toutes les images flottantes de la feuille de travail sous forme d'un tableau d'instances [`FOverGridImage[]`](https://docs.univer.ai/reference/facade/chart).

```typescript
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const images = fWorksheet.getImages()
images.forEach((image) => {
  image.getId()
})
```

Pour obtenir une image flottante par son ID, utilisez la méthode `FWorksheet.getImageById(id)`.

### Mettre à jour les images flottantes

`FWorksheet.updateImages(sheetImages)` met à jour les images flottantes en place : position, taille et autres propriétés.

```typescript
// create a new image builder and set image source.
// then build `ISheetImage` and insert it into the sheet, position is start from F6 cell, width is 500px, height is 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])

// update the image width to 100px and height to 50px after 4 seconds
setTimeout(async () => {
  const imageBuilder = fWorksheet.getImageById(image.drawingId).toBuilder()
  const newImage = await imageBuilder.setWidth(100).setHeight(50).buildAsync()
  fWorksheet.updateImages([newImage])
}, 4000)
```

### Supprimer des images flottantes

`FWorksheet.deleteImages(sheetImages)` supprime les images flottantes.

```typescript
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const image = fWorksheet.getImages()[0]

// Delete the first image of the sheet
fWorksheet.deleteImages([image])
```

## Image de fond de feuille [#worksheet-background]

Une feuille de travail peut également avoir une image de fond carrelée, dessinée derrière les cellules. L'image est stockée dans `IWorksheetData.backgroundImage` et est indépendante des images flottantes et cellulaires. Le préréglage de dessin inclut cette fonctionnalité. En mode plugin, les paquets requis sont `@univerjs/sheets-drawing`, son entrée Facade, et l'interface utilisateur de dessin, qui fournit des contrôles de rendu et de téléchargement.

```ts
import '@univerjs/sheets-drawing/facade'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

sheet.setBackgroundImage('https://example.com/background.png')
console.log(sheet.getBackgroundImage())
sheet.deleteBackgroundImage()
```

`setBackgroundImage()` utilise `ImageSourceType.URL` par défaut et remplace tout arrière-plan existant; `deleteBackgroundImage()` le supprime. Les deux opérations sont implémentées en tant que commandes, donc défaire et refaire s'appliquent. Les images téléchargées sont résolues par l'interface utilisateur via le service d'E/S d'image configuré. L'arrière-plan est affiché à l'écran seulement et est exclu de l'impression.

## Opacité des images [#image-opacity]

Les images flottantes utilisent une seule valeur d'opacité pour l'ensemble de l'image. `setOpacity()` accepte un nombre fini de `0` (transparent) à `1`(opaque); la valeur par défaut est `1`, et toute autre valeur lance `RangeError`. Réglez-le sur `FOverGridImageBuilder` avant de construire, ou sur un `FOverGridImage` déjà dans la feuille. Les deux exposent `getOpacity()` . Le panneau des propriétés de l' image fournit également un contrôle de transparence.

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
const image = sheet?.getImages()[0]
if (image) {
  image.setOpacity(0.5)
  console.log(image.getOpacity())
}
```

## Taille et ancrage des images [#image-sizing-and-anchors]

Les images insérées dans le sélecteur de fichiers intégré conservent leur rapport d'aspect et sont réduites pour s'adapter à l'intérieur de 500 × 500 pixels lorsqu'elles sont trop grandes; les petites images ne sont pas agrandies. Cette taille d'affichage est indépendante de la limite d'octet `allowImageSize` sur les téléchargements.

Les ancres déterminent ce qui se passe lorsque les cellules se déplacent ou se redimensionnent. `SheetDrawingAnchorType.Position` déplace l'image avec les cellules tout en gardant sa taille, `Both` se déplace et la redimensionne avec la plage ancrée, et `None` conserve une position et une taille fixes. Cacher ou afficher des lignes ou des colonnes préserve la définition de l'ancre : une image dimensionnée à une plage peut s'effondrer avec cette plage et récupérer lorsque la plage est montrée à nouveau. La géométrie temporaire de la rangée cachée ne doit pas être réécrite sur les ancres sauvegardées.
