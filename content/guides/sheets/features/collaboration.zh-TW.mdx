請從[協同整合](/server/collaboration/browser-integration)開始，依序執行範例、接入業務、驗證持久化和權限。實作細節與可執行的 Web/Server 範例請見 [Univer Office 文件](/zh-CN/server/collaboration/quick-start)。

先由經過認證的業務 API 呼叫 Collaboration Service 建立 Unit，再於瀏覽器載入回傳的識別碼。依[快速開始](/zh-CN/server/collaboration/quick-start)一起設定 HTTP、Session Ticket 和 WebSocket，以 Database Adapter 持久化，並透過[伺服器端 Middleware](/zh-CN/server/collaboration/identity-and-authorization)分別檢查讀取、JOIN 和修改權限。

## Facade API [#loading-collaborative-documents]

```ts
import '@univerjs-pro/collaboration-client/facade'

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadSheetAsync('your-unit-id')
```
