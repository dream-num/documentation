Los comentarios permiten a los usuarios agregar comentarios y respuestas dentro de los documentos, facilitando la comunicación y la colaboración entre los miembros del equipo.

## Modo predeterminado

### Instalación

```package-install
npm install @univerjs/preset-sheets-thread-comment
```

### Uso

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsThreadCommentPreset } from '@univerjs/preset-sheets-thread-comment' // [!code ++]
import UniverPresetSheetsThreadCommentEnUS from '@univerjs/preset-sheets-thread-comment/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-thread-comment/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsThreadCommentEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsThreadCommentPreset(), // [!code ++]
  ],
})
```

#### Uso con la función de colaboración <IconWrapper className="inline-flex" type="pro" size="xs" icon={null} />

Si está utilizando el Función de [colaboración](/guides/sheets/features/collaboration) con `UniverSheetsCollaborationPreset`, asegúrese de pasar la opción `collaboration: true` en `UniverSheetsThreadCommentPreset`:

```typescript
UniverSheetsThreadCommentPreset({
  collaboration: true, // [!code ++]
})
```

### Crear comentario de celda

Puedes crear un nuevo generador de comentarios usando `univerAPI.newTheadComment()`, que devuelve una instancia de `FTheadCommentBuilder`. Puede encadenar métodos para establecer varias propiedades del comentario.

Los siguientes son algunos métodos miembros de [`FTheadCommentBuilder`](https://docs.univer.ai/reference/facade/thread-comment):

| Método | Descripción |
| ---- | ---- |
| setContent | Establecer el contenido del comentario |
| setPersonId | Establecer el ID de persona para el comentario |
| setDateTime | Establecer la fecha y hora del comentario |
| setId | Establecer el ID del comentario |
| setThreadId | Establecer el ID del hilo del comentario |

```typescript
// Create a new comment
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)

console.log(commentBuilder.content.toPlainText())

// Add the comment to cell A1
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const cell = fWorksheet.getRange('A1')
const result = await cell.addCommentAsync(commentBuilder)
```

### Obtener comentarios de celda

Puede recuperar comentarios utilizando los siguientes métodos, que devuelven una instancia de `FThreadComment`. Luego puede realizar operaciones como actualizar, eliminar o resolver el comentario.

- `FWorkbook.getComments()`: obtener todos los comentarios en el libro de trabajo
- `FWorksheet.getComments()`: obtener todos los comentarios en la hoja de trabajo
- `FRange.getComment()`: obtener el comentario de la celda superior izquierda en el rango
- `FRange.getComments()`: Obtener todos los comentarios en el rango

Los siguientes son algunos métodos de miembros de [`FThreadComment`](https://docs.univer.ai/reference/facade/thread-comment):

| Método | Descripción |
| ---- | ---- |
| getIsRoot | Si el comentario es un comentario raíz |
| getCommentData | Obtener el comentario datos |
| getReplies | Obtener la lista de respuestas al comentario |
| getRange | Obtener el rango del comentario |
| getRichText | Obtener el contenido de texto enriquecido del comentario |
| deleteAsync | Eliminar el comentario y sus respuestas |
| updateAsync | Actualizar el contenido del comentario |
| resolveAsync | Resolver el comentario |
| replyAsync | Responder al comentario |

```typescript
// Get all comments in the workbook
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.getComments()

// Get all comments in the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
Worksheet.getComments()

const fRange = fWorksheet.getRange('A1:B2')
// Get the comment of cell A1
fRange.getComment()

// Get all comments in the range A1:B2
fRange.getComments()
```

### Borrar comentarios de celda

- `FWorkbook.clearComments()`: borrar todos los comentarios en el libro
- `FWorksheet.clearComments()`: borrar todos los comentarios en el hoja de trabajo
- `FRange.clearCommentAsync()`: borrar el comentario de la celda superior izquierda en el rango
- `FRange.clearCommentsAsync()`: borrar todos los comentarios en el rango

```typescript
// Clear all comments in the workbook
const fWorkbook = univerAPI.getActiveWorkbook()
await fWorkbook.clearComments()

// Clear all comments in the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
await fWorksheet.clearComments()

const fRange = fWorksheet.getRange('A1:B2')

// Clear the comment of cell A1
await fRange.clearCommentAsync()

// Clear all comments in the range A1:B2
await fRange.clearCommentsAsync()
```

### Obtener lista de respuestas a comentarios

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all comments in the worksheet
const comments = fWorksheet.getComments()
comments.forEach((comment) => {
  // If the comment is a root comment, get its replies
  if (comment.getIsRoot()) {
    const replies = comment.getReplies()
    replies.forEach((reply) => {
      console.log(reply.getCommentData())
    })
  }
})
```

### Actualizar/eliminar/resolver/responder a comentarios

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new comment and add it to cell A1
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)
  .setId('mock-comment-id')
const cell = fWorksheet.getRange('A1')
await cell.addCommentAsync(commentBuilder)

// Update the comment and reply after 3 seconds
setTimeout(async () => {
  // Get the comment by ID and update its content
  const comment = fWorksheet.getCommentById('mock-comment-id')
  const newRichText = univerAPI.newRichText().insertText('Hello Univer AI')
  await comment.updateAsync(newRichText)

  // Create a new reply comment and set its content
  const replyText = univerAPI.newRichText().insertText('Hello Univer AI! GO! GO! GO!')
  const reply = univerAPI.newTheadComment().setContent(replyText)
  await comment.replyAsync(reply)
}, 3000)

// Resolve the comment and delete it after 6 seconds
setTimeout(async () => {
  const comment = fWorksheet.getCommentById('mock-comment-id')
  await comment.resolveAsync()
  await comment.deleteAsync()
}, 6000)
```

### Escuchas de eventos

Las definiciones completas de tipos de eventos se pueden encontrar en [Eventos](https://docs.univer.ai/reference/facade/events).

El módulo de comentarios proporciona una serie de eventos para escuchar adiciones, actualizaciones, eliminaciones y cambios de estado de resolución de comentarios. Todos los eventos se pueden escuchar usando `univerAPI.addEvent()`.

#### Eventos de adición de comentarios

`univerAPI.Event.CommentAdded`: Se activa después de agregar un comentario

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentAdded, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentAdd`: Se activa antes de agregar un comentario

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentAdd, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // Cancel the comment addition operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Eventos de actualización de comentarios

`univerAPI.Event.CommentUpdated`: Se activa después de que se actualiza un comentario

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentUpdated, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentUpdate`: Se activa antes de que se agregue un comentario actualizado

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentUpdate, (params) => {
  const { comment, workbook, worksheet, row, col, newContent } = params

  // Cancel the comment update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Eventos de eliminación de comentarios

`univerAPI.Event.CommentDeleted`: se activa después de que se elimina un comentario

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentDeleted, (params) => {
  const { commentId, workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentDelete`: se activa antes de que se elimine un comentario

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentDelete, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // Cancel the comment deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Eventos de estado de resolución de comentarios

`univerAPI.Event.CommentResolved`: se activa después del estado de resolución de un comentario cambios

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentResolved, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentResolve`: desencadenado antes de que cambie el estado de resolución de un comentario

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentResolve, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params

  // Cancel the comment resolution operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

Todos los eventos contienen los siguientes parámetros comunes:

- `workbook`: instancia del libro de trabajo actual
- `worksheet`: instancia de la hoja de trabajo actual
- `row`: índice de fila del comentario
- `col`: Índice de columna del comentario
- `comment`: Objeto de comentario (solo `commentId` se incluye en los eventos de eliminación)

Parámetros especiales:

- El evento `BeforeCommentUpdate` incluye `newContent`: Nuevo contenido del comentario (Tipo RichTextValue)
- Los eventos `CommentResolved` y `BeforeCommentResolve` incluyen `resolved`: estado de resolución del comentario

Todas las funciones de devolución de llamada de eventos con prefijo `Before` pueden devolver `params.cancel = true` para evitar el correspondiente operación.
