Los usuarios pueden dejar comentarios y respuestas sobre un documento, por lo que un equipo puede discutir el contenido en un solo lugar.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs/sheets-thread-comment @univerjs/sheets-thread-comment-ui
```

### Uso

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsThreadCommentPlugin } from '@univerjs/sheets-thread-comment' // [!code ++]
import { UniverSheetsThreadCommentUIPlugin } from '@univerjs/sheets-thread-comment-ui' // [!code ++]
import SheetsThreadCommentEnUS from '@univerjs/sheets-thread-comment/locale/en-US' // [!code ++]
import SheetsThreadCommentUIEnUS from '@univerjs/sheets-thread-comment-ui/locale/en-US' // [!code ++]
import { UniverThreadCommentPlugin } from '@univerjs/thread-comment' // [!code ++]
import { UniverThreadCommentUIPlugin } from '@univerjs/thread-comment-ui' // [!code ++]

import '@univerjs/sheets-thread-comment-ui/lib/index.css'
import '@univerjs/thread-comment-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,

      ThreadCommentUIEnUS, // [!code ++]
```

### Crear comentario de celda

`univerAPI.newTheadComment()` devuelve un `FTheadCommentBuilder` para un nuevo comentario. Métodos de cadena en el constructor para establecer las propiedades del comentario.

Los siguientes son algunos métodos miembros de [`FTheadCommentBuilder`](/reference/facade/thead-comment-builder):

| Método | Descripción |
| ---- | ---- |
| setContent | Establece el contenido de comentarios |
| setPersonId | Establece la identificación de la persona del comentario |
| setDateTime | Establece la fecha y hora del comentario |
| setId | Establece el ID de comentario |
| setThreadId | Establece la identificación del hilo del comentario |

```typescript
// Create a new comment
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)

console.log(commentBuilder.content.toPlainText())

// Add the comment to cell A1
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const cell = fWorksheet.getRange('A1')
const result = await cell.addCommentAsync(commentBuilder)
```

### Obtener comentarios de celda

Estos métodos devuelven un `FThreadComment`, que puede ser actualizado, eliminado o resuelto.

- `FWorkbook.getComments()`: consigue todos los comentarios en el libro de trabajo
- `FfWorksheet.getComments()`: consigue todos los comentarios en la hoja de trabajo
- `FRange.getComment()`: consigue el comentario de la célula superior izquierda en el rango
- `FRange.getComments()`: consigue todos los comentarios en el rango

Los siguientes son algunos métodos de miembros de [`FThreadComment`](https://docs.univer.ai/reference/facade/thread-comment):

| Método | Descripción |
| ---- | ---- |
| getIsRoot | Si el comentario es un comentario raíz |
| getCommentData | Obtiene los datos de comentarios |
| getReplies | Obtiene la lista de respuestas al comentario |
| getRange | Consigue el rango del comentario |
| getRichText | Consigue el contenido de texto rico del comentario |
| deleteAsync | Elimina el comentario y sus respuestas |
| updateAsync | Actualiza el contenido de comentarios |
| resolveAsync | Resuelve el comentario |
| replyAsync | Respuestas al comentario |

```typescript
// Get all comments in the workbook
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.getComments()

// Get all comments in the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.getComments()

const fRange = fWorksheet.getRange('A1:B2')
// Get the comment of cell A1
fRange.getComment()

// Get all comments in the range A1:B2
fRange.getComments()
```

### Borrar comentarios de celda

- `FWorkbook.clearComments()`: aclara todos los comentarios en el libro de trabajo
- `FWorksheet.clearComments()`: aclara todos los comentarios en la hoja de trabajo
- `FRange.clearCommentAsync()`: aclara el comentario de la célula superior izquierda en el rango
- `FRange.clearCommentsAsync()`: aclara todos los comentarios en el rango

```typescript
// Clear all comments in the workbook
const fWorkbook = univerAPI.getActiveWorkbook()
await fWorkbook.clearComments()

// Clear all comments in the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
await fWorksheet.clearComments()

const fRange = fWorksheet.getRange('A1:B2')

// Clear the comment of cell A1
await fRange.clearCommentAsync()

// Clear all comments in the range A1:B2
await fRange.clearCommentsAsync()
```

### Obtener lista de respuestas a comentarios

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all comments in the worksheet
const comments = fWorksheet.getComments()
comments.forEach((comment) => {
  // If the comment is a root comment, get its replies
  if (comment.getIsRoot()) {
    const replies = comment.getReplies()
    replies.forEach((reply) => {
      console.log(reply.getCommentData())
    })
  }
})
```

### Actualizar/eliminar/resolver/responder a comentarios

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new comment and add it to cell A1
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)
  .setId('mock-comment-id')
const cell = fWorksheet.getRange('A1')
await cell.addCommentAsync(commentBuilder)

// Update the comment and reply after 3 seconds
setTimeout(async () => {
  // Get the comment by ID and update its content
  const comment = fWorksheet.getCommentById('mock-comment-id')
  const newRichText = univerAPI.newRichText().insertText('Hello Univer AI')
  await comment.updateAsync(newRichText)

  // Create a new reply comment and set its content
  const replyText = univerAPI.newRichText().insertText('Hello Univer AI! GO! GO! GO!')
  const reply = univerAPI.newTheadComment().setContent(replyText)
  await comment.replyAsync(reply)
}, 3000)

// Resolve the comment and delete it after 6 seconds
setTimeout(async () => {
  const comment = fWorksheet.getCommentById('mock-comment-id')
  await comment.resolveAsync()
  await comment.deleteAsync()
}, 6000)
```

### Escuchas de eventos

Consulta las definiciones completas de tipos de eventos en [Events](https://docs.univer.ai/reference/facade/events).

El módulo de comentarios emite eventos para adiciones de comentarios, actualizaciones, eliminaciones y cambios de estado de resolución. Suscribirse a cualquiera de estos eventos con `univerAPI.addEvent()`.

#### Eventos de adición de comentarios

`univerAPI.Event.CommentAdded` dispara después de que se añada un comentario.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentAdded, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentAdd` dispara antes de añadir un comentario.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentAdd, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // Cancel the comment addition operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Eventos de actualización de comentarios

`univerAPI.Event.CommentUpdated` dispara después de que se actualice un comentario.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentUpdated, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentUpdate` dispara antes de que se actualice un comentario.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentUpdate, (params) => {
  const { comment, workbook, worksheet, row, col, newContent } = params

  // Cancel the comment update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Eventos de eliminación de comentarios

`univerAPI.Event.CommentDeleted` dispara después de que se elimina un comentario.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentDeleted, (params) => {
  const { commentId, workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentDelete` dispara antes de que se suprima un comentario.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentDelete, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // Cancel the comment deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Eventos de estado de resolución de comentarios

`univerAPI.Event.CommentResolved` dispara después de que el estado de resolución de un comentario cambie.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentResolved, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentResolve` dispara antes de que el estado de resolución de un comentario cambie.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentResolve, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params

  // Cancel the comment resolution operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

Todos los eventos llevan los siguientes parámetros comunes:

- `workbook`: el libro de trabajo actual
- `worksheet`: la hoja de trabajo actual
- `row`: el índice de filas del comentario
- `col`: el índice de columna del comentario
- `comment`: el objeto de comentario (`commentId` sólo en eventos de eliminación)

Algunos eventos añaden parámetros propios:

- `BeforeCommentUpdate` también lleva `newContent`, el nuevo contenido de comentarios (tipo RichTextValue)
- `CommentResolved` y `BeforeCommentResolve` también llevan `resolved`, el estado de resolución del comentario

Cada llamada de `Before` puede configurar `params.cancel = true` para detener la operación.

## Operaciones comunes [#shared-comment-api]

Importar tanto el comentario compartido Facade como el producto Facade antes de llamar estos métodos. Los ayudantes del producto crean anclas estables, y la API compartida maneja respuestas, actualizaciones, resolución y eliminación. `getComments()` lee el estado local solamente. `listCommentsAsync()` sincroniza los hilos que ya sabe a través de la fuente de datos configurada; no descubre cada hilo en el servidor.

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## Conversaciones compartidas [#shared-discussions]

Los debates compartidos requieren el servicio de comentarios y el punto final, integrado a través de [Server SDK](/server/collaboration/extensions). Después de la colaboración y la licencia están configurados, regístrese `UniverThreadCommentDataSourcePlugin` desde `@univerjs-pro/thread-comment-datasource` . La fuente de datos suministrada utiliza `/universer-api/comment/unit/{unitId}/...` y `/universer-api/user/list`, por lo que la aplicación debe exponer esas rutas.

## Comentarios en imágenes y gráficos [#object-comments]

Después de configurar el dibujo host o el plugin de gráfico, agregue la integración que coincide a continuación junto con su entrada Facade antes de abrir la Unidad. Modo de plugin y modo preset ambos requieren que estas integraciones sean registradas explícitamente.

```package-install
npm install @univerjs-pro/sheets-drawing-thread-comment @univerjs-pro/sheets-chart-thread-comment
```

```typescript
import { UniverSheetsDrawingThreadCommentPlugin } from '@univerjs-pro/sheets-drawing-thread-comment'
import { UniverSheetsChartThreadCommentPlugin } from '@univerjs-pro/sheets-chart-thread-comment'
import '@univerjs-pro/sheets-drawing-thread-comment/facade'
import '@univerjs-pro/sheets-chart-thread-comment/facade'

univer.registerPlugin(UniverSheetsDrawingThreadCommentPlugin)
univer.registerPlugin(UniverSheetsChartThreadCommentPlugin)
```

Con la Unidad abierta, los comentarios se pueden añadir a las imágenes o gráficos existentes. `getComments()` devuelve los hilos cargados localmente; `listCommentsAsync()` sincroniza los hilos que sabe antes de devolverlos.

```typescript
const host = univerAPI.getActiveWorkbook()?.getActiveSheet()
const image = host?.getImages()[0]
const chart = host?.getCharts()[0]
await image?.createCommentAsync('Review this image.')
await chart?.createCommentAsync('Verify the chart source.')
```
