<Callout type="warning">
  **0.25.x** 사용자는 [이전 Pro 문서](https://dream-num.github.io/documentation/v0.25/zh-CN/guides/pro/)를 참고하세요. 새 통합에는 자체 호스팅 Collaboration SDK를 사용하며, 이전 Univer Server 배포 방법과 API는 적용되지 않습니다.
</Callout>

[공동 편집 통합](/guides/server-integration/collaboration)에 따라 예제 실행, 앱 연결, 영속성과 권한 검증을 진행하세요. 구현 세부 정보와 Web/Server 예제는 [Univer Office](https://office.univer.ai/collaboration/quick-start)를 참고하세요.

인증된 비즈니스 API에서 Collaboration Service로 Unit을 생성한 뒤 반환된 ID를 브라우저에서 로드하세요. [Quick Start](https://office.univer.ai/collaboration/quick-start)에 따라 HTTP, Session Ticket, WebSocket을 설정하고 Database Adapter로 저장하세요. 읽기, JOIN, 수정은 [서버 권한](https://office.univer.ai/collaboration/identity-and-authorization)으로 각각 보호해야 합니다.

## Facade API [#loading-collaborative-documents]

```ts
import '@univerjs-pro/collaboration-client/facade'

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadSheetAsync('your-unit-id')
```
