La validation des données applique des règles aux cellules et vérifie les valeurs saisies contre elles. Elle capture les erreurs d'entrée tôt et maintient les données dans une feuille précise et cohérente.

Univer prend en charge les types de validation suivants:
- Nombre
- Nombre entier
- Longueur du texte
- Date
- Case à cocher
- Liste déroulante (sélection simple ou multiple)
- Formule personnalisée

## Mode extension

### Installation

```package-install
npm install @univerjs/data-validation @univerjs/sheets-data-validation @univerjs/sheets-data-validation-ui
```

### Utilisation

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDataValidationPlugin } from '@univerjs/data-validation' // [!code ++]
```

### Ajouter une règle de validation des données

[`univerAPI.newDataValidation()`](https://docs.univer.ai/reference/facade/univer#newdatavalidation) crée un constructeur et renvoie un `FDataValidationBuilder`. Appelez ses méthodes dans une chaîne pour construire la règle.

Les principales méthodes sur [`FDataValidationBuilder`](/reference/facade/data-validation-builder) sont:

| Méthode | Description |
| ------ | ----------- |
| build | Construisez la règle. |
| requireCheckbox | Nécessite une valeur booléenne, que la cellule affiche comme case à cocher. |
| requireDateAfter | Définissez le type à DATE et demandez une date après la date donnée. |
| requireDateBefore | Définissez le type à DATE et demandez une date avant la date donnée. |
| requireDateBetween | Définissez le type à DATE et demandez une date dans la plage donnée. |
| requireDateEqualTo | Définissez le type à DATE et demandez une date égale à la date donnée. |
| requireDateNotBetween | Définissez le type à DATE et demandez une date en dehors de la plage donnée. |
| requireDateOnOrAfter | Définissez le type à DATE et demandez une date à la date indiquée ou après. |
| requireDateOnOrBefore | Définissez le type à DATE et demandez une date au plus tard à la date indiquée. |
| requireFormulaSatisfied | Exiger la formule donnée pour évaluer `true`. |
| requireNumberBetween | Exiger un nombre entre les deux nombres donnés, inclusivement. |
| requireNumberEqualTo | Nécessite un nombre égal à la valeur donnée. |
| requireNumberGreaterThan | Nécessite un nombre supérieur à la valeur donnée. |
| requireNumberGreaterThanOrEqualTo | Exiger un nombre supérieur ou égal à la valeur donnée. |
| requireNumberLessThan | Nécessite un nombre inférieur à la valeur donnée. |
| requireNumberLessThanOrEqualTo | Nécessite un nombre inférieur ou égal à la valeur donnée. |
| requireNumberNotBetween | Exiger un nombre qui n'est pas entre les deux nombres donnés et qui ne correspond pas à l'un ou l'autre. |
| requireNumberNotEqualTo | Exiger un nombre non égal à la valeur donnée. |
| requireValueInList | Nécessite une valeur à partir d'une liste de valeurs spécifiques. Prend en charge la sélection simple/multiple et montre ou cache la liste déroulante. |
| requireValueInRange | Nécessite une valeur dans une plage spécifique. Prend en charge la sélection simple/multiple et montre ou cache le menu déroulant. |
| setOptions | Définissez les options pour la règle. |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new data validation rule that requires a number between 1 and 10 for the range A1:B10
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: 'Please enter a number between 1 and 10',
  })
  .build()
fRange.setDataValidation(rule)
```

### Récupérer les validations d’une plage ou d’une feuille de calcul

L'objet de la règle renvoyée est une instance `FDataValidation`, qui expose les critères, options et autres paramètres de la règle.

Les principales méthodes sur [`FDataValidation`](https://docs.univer.ai/reference/facade/data-validation) sont:

| Méthode | Description |
| ---- | ---- |
| copy | Créez une nouvelle instance FDataValidationBuilder à partir de l'objet de la règle courante. |
| getCriteriaType | Obtenez le type de validation de la règle. |
| getCriteriaValues | Obtenez les valeurs utilisées pour évaluer les critères. |
| getHelpText | Obtenez le texte d'aide, qui fournit des conseils aux utilisateurs. |
| getRanges | Obtenez les fourchettes auxquelles la règle s'applique. |
| setCriteria | Définir les critères de la règle. |
| setOptions | Définir les options de la règle. |
| setRanges | Définissez les intervalles auxquels la règle s'applique. |
| delete | Supprimer la règle de la feuille de travail. |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all data validation rules in current sheet.
const rulesOfSheet = fWorksheet.getDataValidations()

// Get a data validation rule by rule ID.
const ruleById = fWorksheet.getDataValidation(rulesOfSheet[0]?.rule?.uid)

const fRange = fWorksheet.getRange('A1:B10')

// Get first data validation rule in current range.
const ruleOfRange = fRange.getDataValidation()
console.log('ruleOfRange:', ruleOfRange, ruleOfRange?.getCriteriaValues())

// Get all data validation rules in current range.
const rulesOfRange = fRange.getDataValidations()
```

### Mettre à jour ou supprimer une validation des données

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new data validation rule that requires a number equal to 20 for the range A1:B10
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberEqualTo(20)
  .build()
fRange.setDataValidation(rule)

const newRuleRange = fWorksheet.getRange('C1:D10')

// Update the rule after 3 seconds
setTimeout(() => {
  fRange.getDataValidation()
    // Change the range to C1:D10
    .setRanges([newRuleRange])
    // Change the criteria to require a number between 1 and 10
    .setCriteria(
      univerAPI.Enum.DataValidationType.DECIMAL,
      [univerAPI.Enum.DataValidationOperator.BETWEEN, '1', '10'],
    )
    // Change option to stop input on validation errors and show error message
    .setOptions({
      allowBlank: true,
      showErrorMessage: true,
      error: 'Please enter a valid value',
      errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
    })
}, 3000)

// Delete the rule after 6 seconds
setTimeout(() => {
  newRuleRange.getDataValidation().delete()
}, 6000)
```

### Récupérer les erreurs de validation

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all data validation errors for current workbook.
const workbookErrors = await fWorkbook.getAllDataValidationErrorAsync()
console.log('workbookErrors:', workbookErrors)

// Get all data validation errors for current sheet.
const worksheetErrors = await fWorksheet.getAllDataValidationErrorAsync()
console.log('worksheetErrors:', worksheetErrors)

// Get data validation errors for current range.
const fRange = fWorksheet.getRange('A1:B10')
const rangeErrors = await fRange.getDataValidationErrorAsync()
console.log('rangeErrors:', rangeErrors)
```

Chaque objet d’erreur contient les champs suivants :
- `sheetName`: Nom de la feuille de travail où l'erreur s'est produite
- `row`: Indice de ligne de la cellule qui a déclenché l'erreur
- `column` : Indice de colonne de la cellule qui a déclenché l'erreur
- `ruleId` : ID de la règle qui a déclenché l'erreur
- `inputValue` : Valeur d'entrée qui a déclenché l'erreur
- `rule`: Capture instantanée du contenu de la règle

### Récupérer l’état du validateur

L'état de validation est une valeur de l'enum `DataValidationStatus` :
- `valid` : la valeur de la cellule est valide
- `invalid` : la valeur de la cellule n’est pas valide
- `validating` : la validation de la cellule est en cours

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get data validation validator status for current workbook.
fWorkbook.getValidatorStatus().then((status) => {
  console.log('===statusOfWorkbook', status)
})

// Get data validation validator status for current sheet.
fWorksheet.getValidatorStatusAsync().then((status) => {
})

// Get data validation validator status for current range.
const fRange = fWorksheet.getRange('A1:B10')
fRange.getValidatorStatus().then((status) => {
  console.log('===tatusOfRange', status)
})
```

### Écouteurs d’événements

Les définitions complètes du type d'événement sont dans [Événements](https://docs.univer.ai/reference/facade/events).

Le module de validation de données émet des événements lorsque des règles sont ajoutées, mises à jour ou supprimées, et lorsque l'état de validation change. Utilisez `univerAPI.addEvent()` pour écouter l'un de ces événements.

#### Événements de modification des règles de validation

`univerAPI.Event.SheetDataValidationChanged` s'allume après une règle de validation change.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidationChanged, (params) => {
  const { origin, worksheet, workbook, changeType, oldRule, rule } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationAdd` s'allume avant qu'une règle ne soit ajoutée.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationAdd, (params) => {
  const { worksheet, workbook, rule } = params

  // Cancel the data validation rule addition operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationDelete` allume avant qu'une règle ne soit supprimée.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDelete, (params) => {
  const { worksheet, workbook, ruleId, rule } = params

  // Cancel the data validation rule deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationDeleteAll` allume avant que toutes les règles ne soient supprimées.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDeleteAll, (params) => {
  const { worksheet, workbook, rules } = params

  // Cancel the data validation rule deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Événements de mise à jour des règles de validation

`univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate` s'allume avant que les critères d'une règle ne changent.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newCriteria } = params

  // Cancel the data validation rule criteria update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationRangeUpdate` s'allume avant que les plages d'une règle ne changent.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationRangeUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newRanges } = params

  // Cancel the data validation rule range update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationOptionsUpdate` s'allume avant que les options d'une règle ne changent.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationOptionsUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newOptions } = params

  // Cancel the data validation rule options update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Événements d’état de validation

`univerAPI.Event.SheetDataValidatorStatusChanged` s'allume lorsque l'état de validation d'une cellule change.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidatorStatusChanged, (params) => {
  const { worksheet, workbook, row, column, status, rule } = params
})

// Remove the event listener, use `disposable.dispose()`
```

Chaque événement comprend les paramètres communs suivants:
- `workbook` : instance du classeur actuel
- `worksheet` : instance de la feuille de calcul actuelle

Voici quelques-uns des événements qui ont eu lieu :
- `rule` : objet de la règle de validation concernée
- `ruleId`: Identifiant unique de la règle
- `status`: Statut de validation (seulement dans `SheetDataValidatorStatusChanged`)
- `newCriteria`: Nouveaux critères de validation (seulement dans `BeforeSheetDataValidationCriteriaUpdate`)
- `newRanges`: Nouvelles plages de validation (seulement dans `BeforeSheetDataValidationRangeUpdate`)
- `newOptions`: Nouvelles options de validation (seulement dans `BeforeSheetDataValidationOptionsUpdate`)

Pour tout événement dont le nom commence par `Before`, définissez `params.cancel = true` dans le callback pour arrêter l'opération.

### Style d’erreur

`errorStyle` contrôle ce qui se passe lorsque des données non valides sont saisies. Il accepte une valeur `DataValidationErrorStyle` :
- `STOP` : rejette l'entrée invalide
- `WARNING`: Accepte l'entrée invalide et affiche un avertissement
- `INFO`: Accepte l'entrée invalide et affiche un message d'information

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B10')

const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: 'Please enter a number between 1 and 10',
    errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
  })
  .build()
fRange.setDataValidation(rule)
```

### Modifier le mode d’affichage des listes

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B10')

fRange.getDataValidation()?.setOptions({
```
