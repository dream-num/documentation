Enregistrez d'abord les dépendances [Table pivotante](/guides/sheets/features/pivot-table) et [graphique](/guides/sheets/features/charts), puis ajoutez les deux plugins ci-dessous avant de créer le cahier de travail. Fusionnez la locale de l'interface utilisateur dans votre configuration `locales` pour charger la feuille de style correspondante. Une licence Pro est requise.

```package-install
npm install @univerjs-pro/sheets-pivot-chart @univerjs-pro/sheets-pivot-chart-ui
```

```ts
import { UniverSheetsPivotChartPlugin } from '@univerjs-pro/sheets-pivot-chart'
import { UniverSheetsPivotChartUIPlugin } from '@univerjs-pro/sheets-pivot-chart-ui'
import SheetsPivotChartLocale from '@univerjs-pro/sheets-pivot-chart-ui/locale/fr-FR'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/sheets-pivot-chart/facade'
import '@univerjs-pro/sheets-pivot-chart-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.FR_FR, SheetsPivotChartLocale)

univer.registerPlugin(UniverSheetsPivotChartPlugin)
univer.registerPlugin(UniverSheetsPivotChartUIPlugin)
```

Le preset de feuilles avancé comprend déjà les deux plugins. Utilisez-le avec le noyau et les préréglages de dessin, et importez `@univerjs-pro/sheets-pivot-chart/facade` explicitement pour les API de cette page.

## Configurer le Worker [#worker-configuration]

### Configuration des préréglages

Ces options appartiennent à `UniverSheetsAdvancedPreset` :

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `useWorker` | `boolean` | `false` | Active les fonctions avancées dans le Worker de calcul. |

Si vous utilisez un [Travailleur](/guides/sheets/getting-started/worker), passez `UniverSheetsAdvancedPreset({ useWorker: true })` sur le fil principal et `UniverSheetsAdvancedWorkerPreset()` à l'intérieur du Worker. Les détails en mode plugin sont dans le [référence de l'emballage](/reference/packages/plugins/univerjs-pro/sheets-pivot-chart#worker-calculation).

## Rapport indépendant [#owned-report]

Un graphique indépendant possède son rapport. Après insertion, ajoutez un champ ligne et un champ valeur. L'exemple utilise les deux premières colonnes sources.

```ts
const workbook = univerAPI.getActiveWorkbook()
const sheet = workbook?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

sheet.getRange('A1:B4').setValues([
  ['Region', 'Sales'], ['East', 100], ['West', 200], ['East', 50],
])
const chart = await sheet.insertPivotChart(
  sheet.newPivotChart(univerAPI.Enum.ChartTypeString.Column)
    .setSource('A1:B4').setPosition('D2').setSize(640, 360).build(),
)
const fields = chart.getSourceFieldsInfo()
await chart.addField(fields[0].id, univerAPI.Enum.PivotTableFiledAreaEnum.Row, 0)
await chart.addField(fields[1].id, univerAPI.Enum.PivotTableFiledAreaEnum.Value, 0)
```

## Lier un tableau croisé dynamique [#linked-report]

Les modifications de champ, de filtre, de tri et d'effondrement sont partagées avec la table pivotée référencée et avec ses autres graphiques liés, tandis que l'apparence et la position restent indépendantes. La suppression du graphique ne supprime pas la table; la suppression du tableau rend le graphique indisponible jusqu'à ce que la même table soit restaurée.

```ts
const pivotTable = workbook.getPivotTableById('pivot-table-1')
if (!pivotTable) throw new Error('PivotTable not found')

const linkedChart = await sheet.insertPivotChart(
  pivotTable.newChart(univerAPI.Enum.ChartTypeString.Line).setPosition('D22').build(),
)
linkedChart.setFieldButtonsVisible(true).setExpandCollapseButtonsVisible(true)
```

## Types de graphiques pris en charge [#types-and-worker]

Les graphiques linéaires, colonnes, barres, surfaces, tartes, beignets et combinaisons sont pris en charge, y compris les variantes empilées là où elles sont disponibles. L'éparpillement, la bulle, le radar et la cascade ne sont pas pris en charge. Pie utilise la première série de valeurs; les beignets conservent plusieurs séries.

Voir [FSheetPivotChart](/reference/facade/sheet-pivot-chart) pour les API de champ, filtre, style et cycle de vie.

## Copier et supprimer des feuilles [#copy-and-delete-sheets]

Copier une feuille de travail copie également ses PivotCharts et leur attribue de nouveaux ID. Un rapport indépendant dont la source est sur la feuille copiée utilise la nouvelle feuille et un cache indépendant. Un graphique lié suit la table de pivot copiée lorsque cette table est copiée avec la feuille, et les références à d'autres feuilles restent inchangées. Supprimer une feuille de calcul supprime ses PivoTarts et les ressources qui leur sont associées; annuler restaure leurs définitions et données sources.

## Filtres du rapport [#report-filters]

`getOptions()`, `setOptions({ allowMultipleFilters: true })` et `setDateFilter(fieldId, condition)` agissent sur le rapport faisant autorité du graphique. Sur un graphique lié, ils mettent à jour le PivotTable et ses autres graphiques liés; sur un graphique indépendant, ils ne mettent à jour que le rapport du graphique. Omit `condition` pour effacer seulement la condition de date. Pour les séries de dates et les comparaisons d'une journée entière, voir [plusieurs filtres et conditions de date](/guides/sheets/features/pivot-table#multiple-filters).
