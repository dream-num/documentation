<Callout type="warning">
  Vous utilisez **0.25.x** ? Consultez la [documentation Pro archivée](https://dream-num.github.io/documentation/v0.25/zh-CN/guides/pro/). Les nouvelles intégrations utilisent le Collaboration SDK auto-hébergé ; les procédures et API de l’ancien Univer Server ne s’appliquent pas.
</Callout>

Suivez l’[Intégration collaborative](/guides/server-integration/collaboration) pour exécuter l’exemple, connecter votre application et vérifier la persistance et les autorisations. Les détails et exemples Web/Server sont disponibles sur [Univer Office](https://office.univer.ai/collaboration/quick-start).

Créez le Unit via une API métier authentifiée appelant Collaboration Service, puis chargez son identifiant dans le navigateur. Configurez HTTP, Session Ticket et WebSocket selon le [Quick Start](https://office.univer.ai/collaboration/quick-start), puis la persistance et les [autorisations serveur](https://office.univer.ai/collaboration/identity-and-authorization) pour la lecture, JOIN et les modifications.

## Facade API [#loading-collaborative-documents]

```ts
import '@univerjs-pro/collaboration-client/facade'

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadSheetAsync('your-unit-id')
```
