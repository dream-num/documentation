Mit der Gliederungsfunktion (auch als Gruppierung oder Dimensionsgliederung bezeichnet) können Sie gruppieren Zeilen oder Spalten in einem Arbeitsblatt. Dies ist nützlich, um große Datensätze zu organisieren und zusammenzufassen, indem Sie zusammenklappbare Abschnitte erstellen.

## Einführung

In Univer Sheets können Sie mit der Gliederungsfunktion Folgendes tun:

- **Zeilen oder Spalten gruppieren**: Hierarchische Gruppen von Zeilen oder Spalten erstellen, um Daten zu organisieren.
- **Gruppen reduzieren und erweitern**: Gruppierte Zeilen oder Spalten mit einem einzigen Klick anzeigen oder ausblenden.
- **Verschachtelte Gruppen**: Mehrere Ebenen von Gruppen erstellen für komplexe Datenhierarchien.

Gliederungsgruppen werden häufig in den folgenden Szenarien verwendet:

- Zusammenfassen detaillierter Daten: Gruppieren Sie detaillierte Zeilen unter Zusammenfassungszeilen, um eine übersichtlichere Ansicht zu erstellen.
- Organisieren großer Datensätze: Gruppieren Sie verwandte Spalten oder Zeilen zur einfacheren Navigation.
- Erstellen von zusammenklappbaren Berichten: Ermöglichen Sie Benutzern das Erweitern oder Reduzieren von Abschnitten eines Berichts nach Bedarf.

## Voreinstellungsmodus

Die Gliederungsfunktion ist im enthalten `@univerjs/preset-sheets-advanced` voreingestellt.

### Installation

```package-install
npm install @univerjs/preset-sheets-advanced
```

### Nutzung

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
import UniverPresetSheetsAdvancedEnUS from '@univerjs/preset-sheets-advanced/locales/en-US' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-advanced/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsAdvancedEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsAdvancedPreset(), // [!code ++]
  ],
})
```

Wenn Sie eine kommerzielle Lizenz für Univer haben, finden Sie Informationen zur Konfiguration unter [Lizenz im Client verwenden](/guides/pro/license#in-preset-mode).

## Plugin-Modus

### Installation

```package-install
npm install @univerjs-pro/sheets-outline @univerjs-pro/sheets-outline-ui
```

### Nutzung

```typescript
import { UniverSheetsOutlinePlugin } from '@univerjs-pro/sheets-outline' // [!code ++]
import { UniverSheetsOutlineUIPlugin } from '@univerjs-pro/sheets-outline-ui' // [!code ++]

import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-outline/facade' // [!code ++]

import '@univerjs-pro/sheets-outline-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      SheetsOutlineUIEnUS, // [!code ++]

  },

univer.registerPlugin(UniverSheetsOutlinePlugin)
univer.registerPlugin(UniverSheetsOutlineUIPlugin)
```

Wenn Sie eine kommerzielle Lizenz für Univer haben, finden Sie Informationen zur Konfiguration unter [Lizenz im Client verwenden](/guides/pro/license#in-plugin-mode).

## Facade-API

Vollständige Facade-API-Typdefinitionen finden Sie im [FacadeAPI](/reference/facade/univer).

### Importieren

<Callout type="info" title="Plugin mode note">
Nur im Plugin-Modus muss das Facade-Paket manuell importiert werden. Der Voreinstellungsmodus enthält bereits das entsprechende Facade-Paket, sodass kein zusätzlicher Import erforderlich ist.
</Callout>

```typescript
import '@univerjs-pro/sheets-outline/facade'
```

### Zeilenumrisse erstellen

Sie können eine Zeilenumrissgruppe mit der Facade-API erstellen:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Group rows 2 to 6 (0-based index: startRow=1, numRows=5)
fWorksheet.addRowOutline(1, 5)
```

### Spaltenumrisse erstellen

Ähnlich können Sie eine Spaltenumrissgruppe erstellen:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Group columns B to E (0-based index: startColumn=1, numColumns=4)
fWorksheet.addColumnOutline(1, 4)
```

### Umrisse reduzieren und erweitern

Sie können eine Umrissgruppe programmgesteuert reduzieren oder erweitern:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

const rowOutlines = fWorksheet.getDimensionOutlines(univerAPI.Enum.DimensionOutlineAxis.ROW)
if (rowOutlines.length > 0) {
  // Collapse the first row outline group
  fWorksheet.setDimensionOutlineCollapsed(rowOutlines[0].id, true)

  // Expand it later
  fWorksheet.setDimensionOutlineCollapsed(rowOutlines[0].id, false)
}
```

### Entfernen Gliederungen

Sie können eine bestimmte Gliederungsgruppe anhand ihrer ID entfernen:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

const rowOutlines = fWorksheet.getDimensionOutlines(univerAPI.Enum.DimensionOutlineAxis.ROW)
if (rowOutlines.length > 0) {
  fWorksheet.removeDimensionOutline(rowOutlines[0].id)
}
```

### Löschen von Gliederungen in einem Bereich

Sie können alle Gliederungsgruppen innerhalb eines bestimmten Bereichs löschen:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Remove all row outline groups fully contained in rows 2 to 10
fWorksheet.clearDimensionOutlines(univerAPI.Enum.DimensionOutlineAxis.ROW, 1, 9)
```

### Abfragen von Gliederungen

Sie können alle Gliederungsgruppen in einem Arbeitsblatt abrufen:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all row outlines
const rowOutlines = fWorksheet.getDimensionOutlines(univerAPI.Enum.DimensionOutlineAxis.ROW)
rowOutlines.forEach((outline) => {
  console.log(outline.id, outline.start, outline.end, outline.collapsed)
})

// Get all outlines (both row and column)
const allOutlines = fWorksheet.getDimensionOutlines()
```

## Gliederungsdatenstruktur

Jede Gliederungsgruppe hat die folgenden Eigenschaften:

| Eigenschaft | Typ | Beschreibung |
|----------|------|-------------|
| `id` | `string` | Eindeutige Kennung für die Gliederungsgruppe |
| `unitId` | `string` | Die Arbeitsmappen-Einheits-ID |
| `subUnitId` | `string` | Die Arbeitsblatt-Blatt-ID |
| `axis` | `DimensionOutlineAxis` | Die Achse der Gliederung (`row` oder `column`) |
| `start` | `number` | Nullbasierter inklusiver Startindex |
| `end` | `number` | Nullbasierter inklusiver Endindex |
| `collapsed` | `boolean` | Gibt an, ob die Gruppe derzeit minimiert ist |

## Validierung und Fehler

Beim Erstellen von Gliederungsgruppen gilt Folgendes Validierungen werden durchgeführt:

- **Ungültiger Bereich**: Der Bereich muss gültig sein (nicht negativ, Anzahl ungleich Null).
- **Außerhalb der Grenzen**: Der Bereich muss innerhalb der Arbeitsblattgrenzen liegen.
- **Gruppenübergreifend**: Neue Gruppen können bestehende Gruppen nicht überqueren.
- **Maximale Tiefe**: Es gibt eine maximale Verschachtelungstiefe für Gliederungsgruppen.

Der Bereich zum Aufheben der Gruppierung muss die Gliederungsgruppe vollständig enthalten Bereich, andernfalls schlägt die Validierung fehl.

Wenn eine Validierung fehlschlägt, wird der Befehl nicht ausgeführt und ein Fehler wird über `SheetsOutlineErrorService` ausgegeben.
