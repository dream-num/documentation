Users can leave comments and replies on a document, so a team can discuss the content in one place.

## Plugin Mode

### Installation

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs/sheets-thread-comment @univerjs/sheets-thread-comment-ui
```

### Usage

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsThreadCommentPlugin } from '@univerjs/sheets-thread-comment' // [!code ++]
import { UniverSheetsThreadCommentUIPlugin } from '@univerjs/sheets-thread-comment-ui' // [!code ++]
import SheetsThreadCommentUIEnUS from '@univerjs/sheets-thread-comment-ui/locale/en-US' // [!code ++]
import { UniverThreadCommentPlugin } from '@univerjs/thread-comment' // [!code ++]
import { UniverThreadCommentUIPlugin } from '@univerjs/thread-comment-ui' // [!code ++]
import ThreadCommentUIEnUS from '@univerjs/thread-comment-ui/locale/en-US' // [!code ++]
import '@univerjs/sheets-thread-comment-ui/lib/index.css'
import '@univerjs/thread-comment-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-thread-comment/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      ThreadCommentUIEnUS, // [!code ++]
      SheetsThreadCommentUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverThreadCommentPlugin) // [!code ++]
univer.registerPlugin(UniverThreadCommentUIPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsThreadCommentPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsThreadCommentUIPlugin) // [!code ++]
```

### Create Cell Comment

`univerAPI.newTheadComment()` returns an `FTheadCommentBuilder` for a new comment. Chain methods on the builder to set the properties of the comment.

The following are some member methods of [`FTheadCommentBuilder`](/reference/facade/thead-comment-builder):

| Method | Description |
| ---- | ---- |
| setContent | Sets the comment content |
| setPersonId | Sets the person ID of the comment |
| setDateTime | Sets the date and time of the comment |
| setId | Sets the comment ID |
| setThreadId | Sets the thread ID of the comment |

```typescript
// Create a new comment
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)

console.log(commentBuilder.content.toPlainText())

// Add the comment to cell A1
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const cell = fWorksheet.getRange('A1')
const result = await cell.addCommentAsync(commentBuilder)
```

### Get Cell Comments

These methods return an `FThreadComment`, which can then be updated, deleted, or resolved.

- `FWorkbook.getComments()`: gets all comments in the workbook
- `FfWorksheet.getComments()`: gets all comments in the worksheet
- `FRange.getComment()`: gets the comment of the top-left cell in the range
- `FRange.getComments()`: gets all comments in the range

The following are some member methods of [`FThreadComment`](https://docs.univer.ai/reference/facade/thread-comment):

| Method | Description |
| ---- | ---- |
| getIsRoot | Whether the comment is a root comment |
| getCommentData | Gets the comment data |
| getReplies | Gets the list of replies to the comment |
| getRange | Gets the range of the comment |
| getRichText | Gets the rich text content of the comment |
| deleteAsync | Deletes the comment and its replies |
| updateAsync | Updates the comment content |
| resolveAsync | Resolves the comment |
| replyAsync | Replies to the comment |

```typescript
// Get all comments in the workbook
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.getComments()

// Get all comments in the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.getComments()

const fRange = fWorksheet.getRange('A1:B2')
// Get the comment of cell A1
fRange.getComment()

// Get all comments in the range A1:B2
fRange.getComments()
```

### Clear Cell Comments

- `FWorkbook.clearComments()`: clears all comments in the workbook
- `FWorksheet.clearComments()`: clears all comments in the worksheet
- `FRange.clearCommentAsync()`: clears the comment of the top-left cell in the range
- `FRange.clearCommentsAsync()`: clears all comments in the range

```typescript
// Clear all comments in the workbook
const fWorkbook = univerAPI.getActiveWorkbook()
await fWorkbook.clearComments()

// Clear all comments in the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
await fWorksheet.clearComments()

const fRange = fWorksheet.getRange('A1:B2')

// Clear the comment of cell A1
await fRange.clearCommentAsync()

// Clear all comments in the range A1:B2
await fRange.clearCommentsAsync()
```

### Get Comment Replies List

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all comments in the worksheet
const comments = fWorksheet.getComments()
comments.forEach((comment) => {
  // If the comment is a root comment, get its replies
  if (comment.getIsRoot()) {
    const replies = comment.getReplies()
    replies.forEach((reply) => {
      console.log(reply.getCommentData())
    })
  }
})
```

### Update/Delete/Resolve/Reply to Comments

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new comment and add it to cell A1
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)
  .setId('mock-comment-id')
const cell = fWorksheet.getRange('A1')
await cell.addCommentAsync(commentBuilder)

// Update the comment and reply after 3 seconds
setTimeout(async () => {
  // Get the comment by ID and update its content
  const comment = fWorksheet.getCommentById('mock-comment-id')
  const newRichText = univerAPI.newRichText().insertText('Hello Univer AI')
  await comment.updateAsync(newRichText)

  // Create a new reply comment and set its content
  const replyText = univerAPI.newRichText().insertText('Hello Univer AI! GO! GO! GO!')
  const reply = univerAPI.newTheadComment().setContent(replyText)
  await comment.replyAsync(reply)
}, 3000)

// Resolve the comment and delete it after 6 seconds
setTimeout(async () => {
  const comment = fWorksheet.getCommentById('mock-comment-id')
  await comment.resolveAsync()
  await comment.deleteAsync()
}, 6000)
```

### Event Listeners

The full event type definitions are in [Events](https://docs.univer.ai/reference/facade/events).

The comment module emits events for comment additions, updates, deletions, and resolution status changes. Subscribe to any of these events with `univerAPI.addEvent()`.

#### Comment Addition Events

`univerAPI.Event.CommentAdded` fires after a comment is added.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentAdded, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentAdd` fires before a comment is added.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentAdd, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // Cancel the comment addition operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Comment Update Events

`univerAPI.Event.CommentUpdated` fires after a comment is updated.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentUpdated, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentUpdate` fires before a comment is updated.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentUpdate, (params) => {
  const { comment, workbook, worksheet, row, col, newContent } = params

  // Cancel the comment update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Comment Deletion Events

`univerAPI.Event.CommentDeleted` fires after a comment is deleted.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentDeleted, (params) => {
  const { commentId, workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentDelete` fires before a comment is deleted.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentDelete, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // Cancel the comment deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Comment Resolution Status Events

`univerAPI.Event.CommentResolved` fires after the resolution status of a comment changes.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentResolved, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentResolve` fires before the resolution status of a comment changes.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentResolve, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params

  // Cancel the comment resolution operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

All events carry the following common parameters:

- `workbook`: the current workbook
- `worksheet`: the current worksheet
- `row`: the row index of the comment
- `col`: the column index of the comment
- `comment`: the comment object (`commentId` only in deletion events)

Some events add parameters of their own:

- `BeforeCommentUpdate` also carries `newContent`, the new comment content (RichTextValue type)
- `CommentResolved` and `BeforeCommentResolve` also carry `resolved`, the comment's resolution status

Every `Before` callback can set `params.cancel = true` to stop the operation.

## Shared comment operations [#shared-comment-api]

Import both the shared comment Facade and the product Facade before calling these methods. The product helpers create stable anchors, and the shared API handles replies, updates, resolution, and deletion. `getComments()` reads local state only. `listCommentsAsync()` synchronizes the threads it already knows about through the configured data source; it does not discover every thread on the server.

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## Shared discussions [#shared-discussions]

Shared discussions require the Comment Service and Endpoint, integrated through [Server SDK](/server/collaboration/extensions). After collaboration and the license are configured, register `UniverThreadCommentDataSourcePlugin` from `@univerjs-pro/thread-comment-datasource`. The supplied data source uses `/universer-api/comment/unit/{unitId}/...` and `/universer-api/user/list`, so the application must expose those routes. Comment reads and writes require separate permissions on the server; document editing permissions do not cover them.

## Comments on images and charts [#object-comments]

After configuring the host drawing or chart plugin, add the matching integration below together with its Facade entry before opening the Unit. Plugin mode and preset mode both require these integrations to be registered explicitly. They add no extra styles or locales.

```package-install
npm install @univerjs-pro/sheets-drawing-thread-comment @univerjs-pro/sheets-chart-thread-comment
```

```typescript
import { UniverSheetsDrawingThreadCommentPlugin } from '@univerjs-pro/sheets-drawing-thread-comment'
import { UniverSheetsChartThreadCommentPlugin } from '@univerjs-pro/sheets-chart-thread-comment'
import '@univerjs-pro/sheets-drawing-thread-comment/facade'
import '@univerjs-pro/sheets-chart-thread-comment/facade'

univer.registerPlugin(UniverSheetsDrawingThreadCommentPlugin)
univer.registerPlugin(UniverSheetsChartThreadCommentPlugin)
```

With the Unit open, comments can be added to existing images or charts. `getComments()` returns the threads loaded locally; `listCommentsAsync()` synchronizes the threads it knows about before returning them.

```typescript
const host = univerAPI.getActiveWorkbook()?.getActiveSheet()
const image = host?.getImages()[0]
const chart = host?.getCharts()[0]
await image?.createCommentAsync('Review this image.')
await chart?.createCommentAsync('Verify the chart source.')
```
