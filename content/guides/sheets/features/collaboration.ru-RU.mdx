Следуйте руководству по [Интеграция совместного редактирования](/server/collaboration/browser-integration): запустите пример, подключите приложение и проверьте хранение данных и права доступа. Реализация и примеры Web/Server находятся в [Быстрый старт совместного редактирования](/server/collaboration/quick-start).

Создайте Unit через бизнес-API с аутентификацией, вызывающий Collaboration Service, затем загрузите полученный ID в браузере. Настройте HTTP, Session Ticket и WebSocket по [Быстрый старт совместного редактирования](/server/collaboration/quick-start), хранение через Database Adapter и отдельные [проверки прав](/server/collaboration/identity-and-authorization) на чтение, JOIN и изменение.

## Выбор способа загрузки документа [#document-loading]

Задайте текущего пользователя до загрузки документа. Рекомендуется явная загрузка: задайте текущего пользователя, затем вызовите метод Facade ниже, установив при инициализации `enableUrlUnitLoader: false`; это обязательно при использовании пресетов или `createUniver()`. Автоматическая загрузка по URL, включённая по умолчанию, читает параметры `unit` и `type` при старте `UniverCollaborationClientUIPlugin`, поэтому в этом случае текущего пользователя нужно задать до регистрации плагинов совместной работы.

Объедините эти параметры с существующей регистрацией плагина или вызовом пресета совместной работы. В режиме пресетов добавьте `collaborationPreset` в текущий список пресетов `createUniver()` вместе с пресетами редактора.

<Tabs items={['Режим плагинов', 'Режим пресетов']}>
  <Tab>
    ```ts
    import { UniverCollaborationClientUIPlugin } from '@univerjs-pro/collaboration-client-ui'

    univer.registerPlugin(UniverCollaborationClientUIPlugin, {
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverSheetsCollaborationPreset } from '@univerjs/preset-sheets-collaboration'

    const collaborationPreset = UniverSheetsCollaborationPreset({
      universerEndpoint: 'https://your-backend.example.com',
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
</Tabs>

Отключение автоматической загрузки из URL сохраняет совместное редактирование и явную загрузку через Facade.

## Facade API [#loading-collaborative-documents]

```ts
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadSheetAsync('your-unit-id')
```
