Buscar &quot; Reemplaza búsquedas de texto en una hoja y lo reemplaza. Opciones de emparejamiento controlan lo estrictamente que coincide con la búsqueda.

Utilice el panel encontrar y reemplazar en el ejemplo de plugin completo a continuación para probar la característica.

<PlaygroundFrame lang="en-US" slug="sheets/basic-via-plugin" clickToShow />

## Complemento Modo

### Instalación

```package-install
npm install @univerjs/find-replace @univerjs/sheets-find-replace
```

### Uso

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverFindReplacePlugin } from '@univerjs/find-replace' // [!code ++]
import FindReplaceEnUS from '@univerjs/find-replace/locale/en-US' // [!code ++]
import { UniverSheetsFindReplacePlugin } from '@univerjs/sheets-find-replace' // [!code ++]
import '@univerjs/find-replace/lib/index.css' // [!code ++]
import '@univerjs/sheets-find-replace/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      FindReplaceEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverFindReplacePlugin) // [!code ++]
univer.registerPlugin(UniverSheetsFindReplacePlugin) // [!code ++]
```

## Compatibilidad móvil [#mobile-support]

Configurar el [editor móvil](/guides/sheets/getting-started/installation#mobile-support) primero. En la configuración de modo plugin en esta página, sustitúyase los registros de escritorio a continuación con las exportaciones móviles de los mismos paquetes, y lo haga **antes de abrir un documento**. Mantenga los plugins modelo, estilos, locales y las importaciones Facade como son, y no registre ambas variantes.

| Paquete | Registro de escritorio | Registro móvil |
| --- | --- | --- |
| `@univerjs/find-replace` | `UniverFindReplacePlugin` | `UniverFindReplaceMobileUIPlugin` |
| `@univerjs/sheets-find-replace` | `UniverSheetsFindReplacePlugin` | `UniverSheetsFindReplaceMobileUIPlugin` |

## Modo preestablecido

### Instalación

```package-install
npm install @univerjs/preset-sheets-find-replace
```

### Uso

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsFindReplacePreset } from '@univerjs/preset-sheets-find-replace' // [!code ++]
import UniverPresetSheetsFindReplaceEnUS from '@univerjs/preset-sheets-find-replace/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-find-replace/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsFindReplaceEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsFindReplacePreset(), // [!code ++]
  ],
})
```

### Crear buscador de texto

Llame a `univerAPI.createTextFinderAsync()` para crear un buscador de texto. Devuelve una instancia `FTextFinder`.

En la tabla siguiente se enumeran algunos de los métodos en [`FTextFinder`](/reference/facade/text-finder).

| Método | Descripción |
| ------ | ----------- |
| findAll | Devuelve cada partido en la hoja actual. El partido actual se mueve al último partido. |
| findNext | Se mueve al siguiente partido en la hoja actual y lo devuelve si existe. |
| findPrevious | Se mueve al partido anterior en la hoja actual y lo devuelve si existe. |
| getCurrentMatch | Devuelve el partido actual en la hoja actual. |
| matchCaseAsync | Establece la opción de caso de coincidencia. Cuando es cierto, la búsqueda es sensible a los casos; de lo contrario ignora el caso. |
| matchEntireCellAsync | Establece la opción de la célula entera. Cuando es cierto, la búsqueda coincide con el valor de la célula completa; de lo contrario puede coincidir con una parte del valor. |
| matchFormulaTextAsync | Establece la opción de texto de fórmula. Cuando es cierto, la búsqueda examina el texto de fórmula; de lo contrario, examina los valores. |
| replaceAllWithAsync | Reemplaza cada partido con el texto dado. |
| replaceWithAsync | Reemplaza el partido actual con el texto dado. |
| ensureCompleteAsync | Se asegura de que la operación del hallazgo haya finalizado, lo que importa después de los cambios actuales de la hoja. |

```typescript
// Assume the current sheet is empty sheet.
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set some values to the range A1:D10.
const fRange = fWorksheet.getRange('A1:D10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// Create a text-finder to find the text '5'.
const textFinder = await univerAPI.createTextFinderAsync('5')

// Find all cells that contain the text '5'.
const matchCells = textFinder.findAll()
matchCells.forEach((cell) => {
  cell.getA1Notation() // D2, C3, B4, A5
})
```
