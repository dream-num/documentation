La función Buscar y reemplazar permite a los usuarios buscar rápidamente contenido específico en hojas de cálculo y reemplazarlo, admitiendo varias opciones de coincidencia para ayudar a los usuarios a procesar datos de manera eficiente.

<PlaygroundFrame lang="en-US" slug="sheets/find-replace" clickToShow />

## Modo preestablecido

### Instalación

```package-install
npm install @univerjs/preset-sheets-find-replace
```

### Uso

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsFindReplacePreset } from '@univerjs/preset-sheets-find-replace' // [!code ++]
import UniverPresetSheetsFindReplaceEnUS from '@univerjs/preset-sheets-find-replace/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-find-replace/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsFindReplaceEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsFindReplacePreset(), // [!code ++]
  ],
})
```

## Complemento Modo

### Instalación

```package-install
npm install @univerjs/find-replace @univerjs/sheets-find-replace
```

### Uso

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverFindReplacePlugin } from '@univerjs/find-replace' // [!code ++]
import FindReplaceEnUS from '@univerjs/find-replace/locale/en-US' // [!code ++]
import { UniverSheetsFindReplacePlugin } from '@univerjs/sheets-find-replace' // [!code ++]

import '@univerjs/find-replace/lib/index.css' // [!code ++]

import '@univerjs/sheets-find-replace/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      FindReplaceEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverFindReplacePlugin) // [!code ++]
univer.registerPlugin(UniverSheetsFindReplacePlugin) // [!code ++]
```

### Crear buscador de texto

`univerAPI.createTextFinderAsync()` crea un buscador de texto y devuelve una instancia `FTextFinder`.

Aquí se muestran algunos métodos de miembros [`FTextFinder`](https://docs.univer.ai/reference/facade/find-replace):

| Método | Descripción |
| ------ | ----------- |
| findAll | Obtener todas las celdas coincidentes de la hoja actual, la celda coincidente actual es la última celda coincidente |
| findNext | Obtener la siguiente celda coincidente de la hoja actual, si existe, devolver la siguiente celda coincidente y mover la celda coincidente actual a la siguiente celda coincidente |
| findPrevious | Obtener la celda coincidente anterior de la hoja actual, si existe, devolver la celda coincidente anterior y mover la celda coincidente actual a la celda coincidente anterior celda |
| getCurrentMatch | Obtener la celda coincidente actual de la hoja actual |
| matchCaseAsync | Establezca la opción de coincidencia de mayúsculas y minúsculas; si es verdadero, la operación de búsqueda coincidirá con mayúsculas y minúsculas; de lo contrario, la operación de búsqueda ignorará las mayúsculas y minúsculas |
| matchEntireCellAsync | Establezca la opción de coincidir con toda la celda; si es verdadero, la operación de búsqueda coincidirá con el valor completo de la celda; de lo contrario, la operación de búsqueda coincidirá con parte del valor de la celda |
| matchFormulaTextAsync | Establezca la opción de coincidir con el texto de la fórmula; si es verdadero, la operación de búsqueda coincidirá con el texto de la fórmula; de lo contrario, la operación de búsqueda coincidirá valor |
| replaceAllWithAsync | Reemplazar todo el texto coincidente con el texto dado |
| replaceWithAsync | Reemplazar el texto coincidente actual con el texto dado |
| ensureCompleteAsync | Asegúrese de que se complete la operación de búsqueda. Especialmente cuando se cambia la hoja actual, utilice este método para garantizar que se complete la operación de búsqueda |

```typescript
// Assume the current sheet is empty sheet.
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set some values to the range A1:D10.
const fRange = fWorksheet.getRange('A1:D10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// Create a text-finder to find the text '5'.
const textFinder = await univerAPI.createTextFinderAsync('5')

// Find all cells that contain the text '5'.
const matchCells = textFinder.findAll()
matchCells.forEach((cell) => {
  cell.getA1Notation() // D2, C3, B4, A5
})
```
