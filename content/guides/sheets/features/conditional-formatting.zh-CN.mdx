条件格式在条件成立时自动改变单元格的格式，使重要的数据和趋势更醒目。它支持多种条件和格式设置，可让数据更易于阅读。

## 插件模式

### 安装

```package-install
npm install @univerjs/sheets-conditional-formatting @univerjs/sheets-conditional-formatting-ui
```

### 使用

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsConditionalFormattingPlugin } from '@univerjs/sheets-conditional-formatting' // [!code ++]
import { UniverSheetsConditionalFormattingUIPlugin } from '@univerjs/sheets-conditional-formatting-ui' // [!code ++]
import SheetsConditionalFormattingUIZhCN from '@univerjs/sheets-conditional-formatting-ui/locale/zh-CN' // [!code ++]
import '@univerjs/sheets-conditional-formatting-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-conditional-formatting/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_CN,
  locales: {
    [LocaleType.ZH_CN]: mergeLocales(
      SheetsConditionalFormattingUIZhCN, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsConditionalFormattingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsConditionalFormattingUIPlugin) // [!code ++]
```

### 创建条件格式规则

[`FWorksheet.newConditionalFormattingRule()`](https://docs.univer.ai/reference/facade/worksheet#newconditionalformattingrule) 返回一个 `FConditionalFormattingBuilder`。通过链式调用其方法定义规则。

[`FConditionalFormattingBuilder`](/reference/facade/conditional-formatting-builder) 的常用成员方法如下：

| 方法 | 描述 |
| ---- | ---- |
| build | 构建规则 |
| copy | 深拷贝当前构建器 |
| createCfId | 创建条件格式 ID |
| getRanges | 获取当前条件格式的范围 |
| setRanges | 设置规则应用的范围 |
| setAverage | 设置平均值规则 |
| setUniqueValues | 设置唯一值规则 |
| setDuplicateValues | 设置重复值规则 |
| setRank | 设置排名规则 |
| setIconSet | 设置图标集规则 |
| setColorScale | 设置色阶规则 |
| setDataBar | 设置数据条规则 |
| setBackground | 设置背景色 |
| setBold | 设置字体加粗 |
| setFontColor | 设置字体颜色 |
| setItalic | 设置字体斜体 |
| setStrikethrough | 设置字体删除线 |
| setUnderline | 设置字体下划线 |
| whenCellEmpty | 单元格为空时触发 |
| whenCellNotEmpty | 单元格非空时触发 |
| whenDate | 日期落在指定时间段内时触发 |
| whenFormulaSatisfied | 公式计算结果为 true 时触发 |
| whenNumberBetween | 数字介于两个值之间，或等于其中一个时触发 |
| whenNumberEqualTo | 数字等于给定值时触发 |
| whenNumberGreaterThan | 数字大于给定值时触发 |
| whenNumberGreaterThanOrEqualTo | 数字大于或等于给定值时触发 |
| whenNumberLessThan | 数字小于给定值时触发 |
| whenNumberLessThanOrEqualTo | 数字小于或等于给定值时触发 |
| whenNumberNotBetween | 数字不在两个值之间、也不等于这两个值时触发 |
| whenNumberNotEqualTo | 数字不等于给定值时触发 |
| whenTextContains | 文本包含指定值时触发 |
| whenTextDoesNotContain | 文本不包含指定值时触发 |
| whenTextEndsWith | 文本以指定值结尾时触发 |
| whenTextEqualTo | 文本等于给定值时触发 |
| whenTextStartsWith | 文本以指定值开头时触发 |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 创建一个条件格式规则，使范围 A1:T100 中的非空单元格字体变为斜体，背景色为红色，字体颜色为绿色
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)
```

### 获取条件格式规则

- `FWorksheet.getConditionalFormattingRules()` 获取工作表的所有条件格式规则
- `FRange.getConditionalFormattingRules()` 获取范围的所有条件格式规则

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// 获取活动工作表的所有条件格式规则
const fWorksheet = fWorkbook.getActiveSheet()
const rulesOfSheet = fWorksheet.getConditionalFormattingRules()

// 获取范围 A1:T100 的所有条件格式规则
const fRange = fWorksheet.getRange('A1:T100')
const rulesOfRange = fRange.getConditionalFormattingRules()
```

### 删除条件格式规则

`FWorksheet.deleteConditionalFormattingRule(cfId)` 从工作表中删除一条规则。`cfId` 是该规则的 ID。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// 删除第一个规则
fWorksheet.deleteConditionalFormattingRule(rules[0]?.cfId)
```

### 更新条件格式规则

`FWorksheet.setConditionalFormattingRule(cfId, rule)` 替换工作表中的一条规则。`cfId` 是要替换的规则 ID，`rule` 是新规则。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 创建一个条件格式规则，使非空单元格字体变为斜体，背景色为红色，字体颜色为绿色
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)

// 修改第一个规则应用到新的范围
const rules = fWorksheet.getConditionalFormattingRules()
const newRuleRange = fWorksheet.getRange('A1:D10')
fWorksheet.setConditionalFormattingRule(rules[0]?.cfId, { ...rules[0], ranges: [newRuleRange.getRange()] })
```

### 修改条件格式规则的优先级

`FWorksheet.moveConditionalFormattingRule(cfId, toCfId, type)` 改变规则在优先级顺序中的位置。`cfId` 是要移动的规则，`toCfId` 是作为参照的规则，`type` 是移动类型（例如 'before'、'after'）。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// 移动第三个规则到第一个规则之前
const rule = rules[2]
const targetRule = rules[0]
fWorksheet.moveConditionalFormattingRule(rule?.cfId, targetRule?.cfId, 'before')
```

### 清除所有条件格式规则

- `FWorksheet.clearConditionalFormatRules()` 清除工作表的所有条件格式规则
- `FRange.clearConditionalFormatRules()` 清除范围的所有条件格式规则

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// 清除活动工作表的所有条件格式规则
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.clearConditionalFormatRules()

// 清除范围 A1:T100 的所有条件格式规则
const fRange = fWorksheet.getRange('A1:T100')
fRange.clearConditionalFormatRules()
```

## 复用规则描述与预览 [#custom-rule-ui]

如需自行构建规则列表，从 `@univerjs/sheets-conditional-formatting-ui` 导入 `getRuleDescribe` 和 `ConditionalFormattingRulePreview`。完整规则传给 `getRuleDescribe(rule, localeService)`，预览只接收规则配置 `rule.rule`。预览显示配置后的外观，不计算工作表单元格的实际结果。预览需要在 Univer 的 React 上下文中渲染。

`CF_PANEL_KEY` 标识内置面板，[组件覆盖](/guides/sheets/ui/components)可通过它指定目标面板。`IConditionFormattingPanelProps.onEditorExit` 在编辑结束时触发，包括提交后、取消后，以及工作表被激活或被移除时。它不表示保存成功，也不表示侧边栏已关闭。

```tsx
import type { IConditionFormattingRule } from '@univerjs/sheets-conditional-formatting'
import { LocaleService } from '@univerjs/core'
import { ConditionalFormattingRulePreview, getRuleDescribe } from '@univerjs/sheets-conditional-formatting-ui'
import { useDependency } from '@univerjs/ui'

interface IRuleSummaryProps {
  rule: IConditionFormattingRule
}

function RuleSummary({ rule }: IRuleSummaryProps) {
  const localeService = useDependency(LocaleService)

  return (
    <div>
      <span>{getRuleDescribe(rule, localeService)}</span>
      <ConditionalFormattingRulePreview rule={rule.rule} />
    </div>
  )
}
```

## 文本规则匹配 [#text-rules]

文本规则比较时不区分大小写：包含、开头是、结尾是、等于和不等于都忽略大小写。重复值和唯一值规则也把 `Apple` 与 `apple` 视为同一个值。

## 规则优先级与“为真则停止” [#stop-if-true]

规则按优先级顺序应用。对于同一个单元格，命中的高亮规则如果带有 `stopIfTrue: true`，会抑制优先级更低的规则，即使该规则本身未设置样式。规则未命中时，继续向下评估。优先级更高的规则结果仍然有效。规则编辑器仅在高亮规则上提供此选项，色阶、数据条和图标集没有该选项。

示例先添加低优先级的背景规则，因为新添加的规则会排在列表最前面。启用停止选项后，90 仅加粗，不显示绿色背景；60 仍然带有背景。`stopIfTrue` 位于规则对象外层，而不在 `rule` 内。

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

const ranges = [sheet.getRange('B2:B10').getRange()]
const backgroundRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(50)
  .setBackground('#DCFCE7')
  .setRanges(ranges)
  .build()
const priorityRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(80)
  .setBold(true)
  .setRanges(ranges)
  .build()

sheet.addConditionalFormattingRule(backgroundRule)
sheet.addConditionalFormattingRule({ ...priorityRule, stopIfTrue: true })
```
