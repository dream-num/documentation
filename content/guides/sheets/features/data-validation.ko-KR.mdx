Data validation은 세포에 대한 규칙을 적용하고 그들에 대한 입력 값을 확인합니다. 입력 오류를 일찍 잡고 정확한 시트의 데이터를 유지하고 일관성.

Univer는 다음과 같은 유효성 검사 유형을 지원합니다:
- 숫자
- 정수
- 텍스트 길이
- 날짜
- 체크박스
- 드롭다운 목록(단일/다중 선택)
- 사용자 지정 수식

## 플러그인 모드

### 설치

```package-install
npm install @univerjs/data-validation @univerjs/sheets-data-validation @univerjs/sheets-data-validation-ui
```

### 사용법

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDataValidationPlugin } from '@univerjs/data-validation' // [!code ++]
import { UniverSheetsDataValidationPlugin } from '@univerjs/sheets-data-validation' // [!code ++]

  locale: LocaleType.EN_US,
```

## 값 일치 [#value-matching]

목록 유효성 검사는 대소문자를 구분하지 않으므로, `green`은 `Green`으로 작성된 옵션을 통과하며 범위 참조 목록도 같은 규칙을 따릅니다. 숫자 및 정수 규칙은 숫자 텍스트만 허용하며, 부울 값과 빈 텍스트는 이를 충족하지 않습니다.

### 데이터 유효성 검사 규칙 추가

[`univerAPI.newDataValidation()`](https://docs.univer.ai/reference/facade/univer#newdatavalidation)는 빌더를 만들고 `FDataValidationBuilder`를 반환합니다. 규칙을 건설하기 위해 체인의 방법을 호출합니다.

[`FDataValidationBuilder`](/reference/facade/data-validation-builder)의 주요 방법은 다음과 같습니다.

| 메서드 | 설명 |
| ------ | ----------- |
| build | 규칙을 구축하십시오. |
| requireCheckbox | boolean 값이 필요합니다. 셀은 체크 박스로 표시되어 있습니다. |
| requireDateAfter | DATE 유형을 설정하고 주어진 날짜 이후에 날짜를 요구합니다. |
| requireDateBefore | DATE 유형을 설정하고 주어진 날짜 전에 날짜를 요구합니다. |
| requireDateBetween | DATE 유형을 설정하고 주어진 범위 내에서 날짜를 요구합니다. |
| requireDateEqualTo | DATE에 유형을 설정하고 주어진 날짜와 동등한 날짜를 요구합니다. |
| requireDateNotBetween | DATE에 유형을 설정하고 주어진 범위 밖에 날짜를 요구합니다. |
| requireDateOnOrAfter | DATE 유형을 설정하고 주어진 날짜 후 날짜를 요구합니다. |
| requireDateOnOrBefore | DATE 유형을 설정하고 주어진 날짜 전에 날짜를 요구합니다. |
| requireFormulaSatisfied | `true`에 대한 평가에 주어진 공식을 요구합니다. |
| requireNumberBetween | 2개의 주어진 숫자 사이 수를, 포함해 요구합니다. |
| requireNumberEqualTo | 주어진 값과 동일한 숫자를 요구합니다. |
| requireNumberGreaterThan | 주어진 값보다 더 큰 숫자를 요구합니다. |
| requireNumberGreaterThanOrEqualTo | 주어진 값보다 더 큰 숫자를 요구합니다. |
| requireNumberLessThan | 주어진 값 보다는 더 적은 수를 요구합니다. |
| requireNumberLessThanOrEqualTo | 주어진 값과 같거나 같지 않는 수를 요구합니다. |
| requireNumberNotBetween | 두 가지 주어진 숫자와 같지 않는 숫자를 요구합니다. |
| requireNumberNotEqualTo | 주어진 값과 동일하지 않는 숫자를 요구합니다. |
| requireValueInList | 특정 값의 목록에서 값을 요구합니다. 단일/다중 선택 지원 및 표시 또는 드롭다운을 숨깁니다. |
| requireValueInRange | 특정 범위 내에서 값을 요구합니다. 단일 / 다중 선택 지원 및 표시 또는 드롭다운을 숨깁니다. |
| setOptions | 규칙에 대한 옵션을 설정합니다. |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new data validation rule that requires a number between 1 and 10 for the range A1:B10
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: 'Please enter a number between 1 and 10',
  })
  .build()
fRange.setDataValidation(rule)
```

### 범위/워크시트의 데이터 유효성 검사 가져오기

반환된 규칙 객체는 규칙의 표준, 옵션 및 기타 설정을 노출하는 `FDataValidation` 인스턴스입니다.

[`FDataValidation`](https://docs.univer.ai/reference/facade/data-validation)의 주요 방법은 다음과 같습니다.

| 메서드 | 설명 |
| ---- | ---- |
| copy | 현재 규칙 객체의 새로운 FDataValidationBuilder 인스턴스를 만듭니다. |
| getCriteriaType | 규칙의 유효성 검사 유형을 얻으십시오. |
| getCriteriaValues | 기준을 평가하는 데 사용되는 값을 가져옵니다. |
| getHelpText | 사용자에 대한 지도를 제공하는 도움말 텍스트를 가져옵니다. |
| getRanges | 규칙이 적용된 범위를 가져옵니다. |
| setCriteria | 규칙의 기준을 설정한다. |
| setOptions | 규칙의 옵션을 설정합니다. |
| setRanges | 규칙을 설정한다. |
| delete | worksheet에서 규칙을 삭제합니다. |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all data validation rules in current sheet.
const rulesOfSheet = fWorksheet.getDataValidations()

// Get a data validation rule by rule ID.
const ruleById = fWorksheet.getDataValidation(rulesOfSheet[0]?.rule?.uid)

const fRange = fWorksheet.getRange('A1:B10')

// Get first data validation rule in current range.
const ruleOfRange = fRange.getDataValidation()
console.log('ruleOfRange:', ruleOfRange, ruleOfRange?.getCriteriaValues())

// Get all data validation rules in current range.
const rulesOfRange = fRange.getDataValidations()
```

### 데이터 유효성 검사 업데이트/삭제

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new data validation rule that requires a number equal to 20 for the range A1:B10
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberEqualTo(20)
  .build()
fRange.setDataValidation(rule)

const newRuleRange = fWorksheet.getRange('C1:D10')

// Update the rule after 3 seconds
setTimeout(() => {
  fRange.getDataValidation()
    // Change the range to C1:D10
    .setRanges([newRuleRange])
    // Change the criteria to require a number between 1 and 10
    .setCriteria(
      univerAPI.Enum.DataValidationType.DECIMAL,
      [univerAPI.Enum.DataValidationOperator.BETWEEN, '1', '10'],
    )
    // Change option to stop input on validation errors and show error message
    .setOptions({
      allowBlank: true,
      showErrorMessage: true,
      error: 'Please enter a valid value',
      errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
    })
}, 3000)

// Delete the rule after 6 seconds
setTimeout(() => {
  newRuleRange.getDataValidation().delete()
}, 6000)
```

### 유효성 검사 오류 가져오기

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all data validation errors for current workbook.
const workbookErrors = await fWorkbook.getAllDataValidationErrorAsync()
console.log('workbookErrors:', workbookErrors)

// Get all data validation errors for current sheet.
const worksheetErrors = await fWorksheet.getAllDataValidationErrorAsync()
console.log('worksheetErrors:', worksheetErrors)

// Get data validation errors for current range.
const fRange = fWorksheet.getRange('A1:B10')
const rangeErrors = await fRange.getDataValidationErrorAsync()
console.log('rangeErrors:', rangeErrors)
```

각 오류 객체에는 다음 필드가 포함됩니다.
- `sheetName`: 오류가 발생한 워크시트의 이름
- `row` : 오류를 유발하는 세포의 행 인덱스
- `column` : 오류를 유발하는 세포의 열 색인
- `ruleId` : 오류를 유발하는 규칙의 ID
- `inputValue`: 오류를 유발하는 입력 값
- `rule`: 규칙 내용의 스냅샷

### 유효성 검사기 상태 가져오기

Validator 상태는 `DataValidationStatus` enum의 가치입니다:

- `validating`: 셀을 검사하는 중

```typescript
fWorkbook.getValidatorStatus().then((status) => {

// Get data validation validator status for current sheet.
fWorksheet.getValidatorStatusAsync().then((status) => {
})
```

### 이벤트 리스너

완전한 사건 유형 정의는 [* 이름 *](https://docs.univer.ai/reference/facade/events)에 있습니다.

데이터 검증 모듈은 규칙이 추가되고 업데이트되거나 삭제될 때 이벤트를 방출하며 유효성 검사 상태가 변경될 때. 이러한 이벤트의 모든 것을 듣고 `univerAPI.addEvent()`를 사용하십시오.

#### 유효성 검사 규칙 변경 이벤트

`univerAPI.Event.SheetDataValidationChanged`는 유효성 규칙이 변경된 후에 불을 붙입니다.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidationChanged, (params) => {
  const { origin, worksheet, workbook, changeType, oldRule, rule } = params
})

// Remove the event listener, use `disposable.dispose()`
```

규칙이 추가되기 전에 `univerAPI.Event.BeforeSheetDataValidationAdd` 화재.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationAdd, (params) => {
  const { worksheet, workbook, rule } = params

  // Cancel the data validation rule addition operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

규칙이 삭제되기 전에 `univerAPI.Event.BeforeSheetDataValidationDelete` 화재.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDelete, (params) => {
  const { worksheet, workbook, ruleId, rule } = params

  // Cancel the data validation rule deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationDeleteAll`는 모든 규칙의 앞에 불을 삭제합니다.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDeleteAll, (params) => {
  const { worksheet, workbook, rules } = params

  // Cancel the data validation rule deletion operation
  params.cancel = true
```

```typescript
// Remove the event listener, use `disposable.dispose()`
```

각 이벤트에는 다음과 같은 일반적인 매개 변수가 포함되어 있습니다.
- `workbook`: 현재 통합 문서 인스턴스
- `worksheet`: 현재 워크시트 인스턴스

일부 이벤트는 다음과 같습니다 :
- `rule`: 관련 유효성 검사 규칙 객체
- `ruleId`: 규칙의 유일한 식별자
- `status`: 검증 상태 (`SheetDataValidatorStatusChanged`에서만)
- `newCriteria`: 새로운 검증 기준 (`BeforeSheetDataValidationCriteriaUpdate`에서만)
- `newRanges`: 새로운 검증 범위 (`BeforeSheetDataValidationRangeUpdate`에서만)
- `newOptions`: 새로운 검증 옵션 (`BeforeSheetDataValidationOptionsUpdate`에서만)

`Before`로 시작하는 모든 이벤트에 대해서는, `params.cancel = true`를 호출하여 작동을 중지합니다.

### 오류 스타일

`errorStyle`는 잘못된 데이터가 입력될 때 무슨 일이 일어나는 것을 통제합니다. 그것은 `DataValidationErrorStyle` 가치를 받아들입니다:
- `STOP`: 잘못된 항목을 거부
- `WARNING`: 잘못된 입력을 받아들이고 경고를 보여줍니다
- `INFO`: 잘못된 입력을 허용하고 정보 메시지를 보여줍니다

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B10')

const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: 'Please enter a number between 1 and 10',
    errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
  })
  .build()
fRange.setDataValidation(rule)
```

### 목록 렌더링 모드 변경

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B10')

fRange.getDataValidation()?.setOptions({
  // support TEXT, ARROW, CUSTOM
  // default is `CUSTOM`
  renderMode: univerAPI.Enum.DataValidationRenderMode.TEXT,
})
```
