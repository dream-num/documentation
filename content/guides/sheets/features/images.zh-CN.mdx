图片可以表达用文字不易说明的信息。Univer 的图片分为两种：浮动图片显示在表格上方，单元格图片绑定到单个单元格。

## 插件模式

### 安装

```package-install
npm install @univerjs/docs-drawing @univerjs/drawing @univerjs/drawing-ui @univerjs/sheets-drawing @univerjs/sheets-drawing-ui
```

### 使用

```typescript
import { IImageIoService, LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsDrawingPlugin } from '@univerjs/docs-drawing' // [!code ++]
import { UniverDrawingPlugin } from '@univerjs/drawing' // [!code ++]
import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui' // [!code ++]
import DrawingUIZhCN from '@univerjs/drawing-ui/locale/zh-CN' // [!code ++]
import { UniverSheetsDrawingPlugin } from '@univerjs/sheets-drawing' // [!code ++]
import { UniverSheetsDrawingUIPlugin } from '@univerjs/sheets-drawing-ui' // [!code ++]
import SheetsDrawingUIZhCN from '@univerjs/sheets-drawing-ui/locale/zh-CN' // [!code ++]
import '@univerjs/drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing/facade' // [!code ++]
import '@univerjs/sheets-drawing-ui/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_CN,
  locales: {
    [LocaleType.ZH_CN]: mergeLocales(
      DrawingUIZhCN, // [!code ++]
      SheetsDrawingUIZhCN, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverDrawingUIPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingUIPlugin) // [!code ++]
```

如果使用[协同编辑](/guides/docs/features/collaboration)，需要添加 `override` 配置：

```typescript
univer.registerPlugin(UniverDrawingPlugin, {
  override: [[IImageIoService, null]], // [!code ++]
  // allowImageSize: 20 * 1024 * 1024, // 设置上传图片的最大允许大小为 20MB，非必需
})
```

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreZhCN from '@univerjs/preset-sheets-core/locales/zh-CN'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]

import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.ZH_CN,
  locales: {
    [LocaleType.ZH_CN]: mergeLocales(
      UniverPresetSheetsCoreZhCN,
      UniverPresetSheetsDrawingZhCN, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsDrawingPreset(), // [!code ++]
  ],
})
```

```typescript
  collaboration: true, // [!code ++]
})
```

### 添加浮动 DOM

`FWorksheet.addFloatDomToPosition(layer)` 在指定位置添加一个浮动 DOM 元素。

```tsx
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 你应该在合适的时机注册组件（例如 Univer 加载完成时）
// 这是一个 React 组件。对于 Vue3 组件，第三个参数应该是 `{ framework: 'vue3' }`
univerAPI.registerComponent(
  'myFloatDom',
  ({ data }) => (
    <div style={{ width: '100%', height: '100%', background: '#fff', border: '1px solid #ccc', boxSizing: 'border-box' }}>
      popup content:
      {' '}
      {data?.label}
    </div>
  ),
)

// 添加浮动 DOM
// 如果 disposable 为 null，则浮动 DOM 添加失败
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'myFloatDom',
  initPosition: {
    startX: 100,
    endX: 300,
    startY: 100,
    endY: 200,
  },

  // 组件数据
  data: {
    label: 'hahah',
  },
})

// 2 秒后移除浮动 DOM
setTimeout(() => {
  disposable?.dispose()
}, 2000)
```

`FWorksheet.addFloatDomToRange(range, layer, domLayout)` 在指定范围上方添加一个浮动 DOM 元素。


### 插入浮动图片

[`FWorksheet.newOverGridImage()`](https://docs.univer.ai/reference/facade/worksheet#newovergridimage) 返回一个浮动图片构建器，即 `FOverGridImageBuilder` 实例。在构建器上链式调用，可得到用于插入浮动图片的 `ISheetImage` 对象。

[`FOverGridImageBuilder`](/reference/facade/over-grid-image-builder) 提供以下方法：

| 方法 | 描述 |
| ---- | ---- |
| buildAsync | 构建图片并返回 `ISheetImage` 对象 |
| setSource | 设置图片来源 |
| setColumn | 设置图片的水平位置 |
| setRow | 设置图片的垂直位置 |
| setColumnOffset | 设置图片的水平偏移 |
| setRowOffset | 设置图片的垂直偏移 |
| setWidth | 设置图片宽度 |
| setHeight | 设置图片高度 |
| setAnchorType | 设置锚点类型，决定位置和尺寸是否随单元格变化 |
| setCropTop | 设置裁剪区域的上边缘，只显示图片所需部分 |
| setCropLeft | 设置裁剪区域的左边缘，只显示图片所需部分 |
| setCropBottom | 设置裁剪区域的下边缘，只显示图片所需部分 |
| setCropRight | 设置裁剪区域的右边缘，只显示图片所需部分 |
| setRotate | 设置图片的旋转角度 |

```typescript
// 创建一个新的图片构建器并设置图片来源。
// 然后构建 `ISheetImage` 并插入到工作表中，位置从 F6 单元格开始，宽度为 500px，高度为 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])
```

也可以使用 `FWorksheet.insertImage(url, column, row, offsetX, offsetY)` 方法插入图片。

```typescript
// 插入一个图片到工作表，位置为 F6，偏移为 10px
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const result = await fWorksheet.insertImage('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', 5, 5, 10, 10)
```

### 获取浮动图片

`FWorksheet.getImages()` 返回工作表中的所有浮动图片，结果为 [`FOverGridImage[]`](https://docs.univer.ai/reference/facade/chart) 实例数组。

```typescript
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const images = fWorksheet.getImages()
images.forEach((image) => {
  image.getId()
})
```

如需按 ID 获取单张浮动图片，可使用 `FWorksheet.getImageById(id)` 方法。

### 更新浮动图片

`FWorksheet.updateImages(sheetImages)` 更新浮动图片的位置、大小等属性。

```typescript
// 创建一个新的图片构建器并设置图片来源。
// 然后构建 `ISheetImage` 并插入到工作表中，位置从 F6 单元格开始，宽度为 500px，高度为 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])

// 4 秒后更新图片宽度为 100px，高度为 50px
setTimeout(async () => {
  const imageBuilder = fWorksheet.getImageById(image.drawingId).toBuilder()
  const newImage = await imageBuilder.setWidth(100).setHeight(50).buildAsync()
  fWorksheet.updateImages([newImage])
}, 4000)
```

### 删除浮动图片

`FWorksheet.deleteImages(sheetImages)` 删除浮动图片。

```typescript
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
```

## 工作表背景图 [#worksheet-background]

工作表还可以包含一张平铺背景图，绘制在单元格下方。该图保存在 `IWorksheetData.backgroundImage` 中，与浮动图片和单元格图片相互独立。绘图预设已包含此功能。插件模式需要 `@univerjs/sheets-drawing` 及其 Facade 入口，以及负责渲染和上传控件的绘图 UI。

```ts
import '@univerjs/sheets-drawing/facade'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

sheet.setBackgroundImage('https://example.com/background.png')
console.log(sheet.getBackgroundImage())
sheet.deleteBackgroundImage()
```

`setBackgroundImage()` 默认使用 `ImageSourceType.URL`，并替换已有背景；`deleteBackgroundImage()` 删除背景。两者均以命令实现，因此支持撤销和重做。上传的图片由 UI 通过配置好的图片 I/O 服务解析。背景仅用于屏幕显示，不参与打印。

## 图片不透明度 [#image-opacity]

浮动图片的不透明度作用于整张图片，只使用一个取值。`setOpacity()` 接受 `0`（完全透明）到 `1`（完全不透明）之间的有限数值，默认值为 `1`，其他值会抛出 `RangeError`。可在构建前通过 `FOverGridImageBuilder` 设置，也可修改工作表中已有的 `FOverGridImage`，两者均提供 `getOpacity()`。图片属性面板也提供透明度控件。

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
const image = sheet?.getImages()[0]
if (image) {
  image.setOpacity(0.5)
  console.log(image.getOpacity())
}
```

## 图片尺寸与锚点 [#image-sizing-and-anchors]

使用内置文件选择器插入图片时，图片保持原始宽高比，尺寸过大时会缩小到 500 × 500 像素以内，小图不会放大。该显示尺寸与 `allowImageSize` 限制的上传字节数相互独立。通过 Facade 插入图片时，尺寸由调用方提供。

锚点决定单元格移动或调整大小时图片的行为。`SheetDrawingAnchorType.Position` 使图片随单元格移动并保持尺寸，`Both` 使图片随锚定范围移动并缩放，`None` 保持位置和尺寸固定。隐藏或显示行列不会破坏锚点定义：尺寸随范围缩放的图片可能随之收缩，范围重新显示后恢复。不得将隐藏行列期间的临时几何尺寸写回已保存的锚点。
