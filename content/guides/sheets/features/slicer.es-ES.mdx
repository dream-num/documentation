Filtros de rebanado Tablas, PivotTables y PivotCharts por los miembros de una fuente. Un cronograma filtra los campos de fecha originales de un Pivot que pueden servir como fuente. Columnas de tabla, campos de texto, campos calculados y campos de agrupación derivados no pueden ser fuentes de cronograma.

## Modo de complemento [#plugin-mode]

### Instalación

```package-install
npm install @univerjs-pro/sheets-slicer @univerjs-pro/sheets-slicer-ui
```

### Uso

Añada lo siguiente a su [Configuración de hojas de cálculo](/guides/sheets/getting-started/installation) existente, con [apoyo a los dibujos](/guides/sheets/features/images) y una fuente [Cuadro](/guides/sheets/features/table) o [PivotTable](/guides/sheets/features/pivot-table) ya configurada. Cargue el local y registre estos plugins antes de crear el libro de trabajo.

```ts
import { UniverSheetsSlicerPlugin } from '@univerjs-pro/sheets-slicer'
import { UniverSheetsSlicerUIPlugin } from '@univerjs-pro/sheets-slicer-ui'
import SheetsSlicerUILocale from '@univerjs-pro/sheets-slicer-ui/locale/es-ES'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/sheets-slicer/facade'
import '@univerjs-pro/sheets-slicer-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.ES_ES, SheetsSlicerUILocale)
univer.registerPlugin(UniverSheetsSlicerPlugin)
univer.registerPlugin(UniverSheetsSlicerUIPlugin)
```

## Modo preestablecido [#preset-mode]

### Instalación

```package-install
npm install @univerjs/presets @univerjs/preset-sheets-core @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

### Uso

El preset avanzado incluye el modelo de rebanado y cronograma y los plugins UI, junto con sus APIs Facade. Combinelo con los presets de núcleo y dibujo y combinar los paquetes de locale. Si el preset avanzado ya está en uso, agregue `slicer` a ese registro en lugar de registrarlo por segunda vez. Configure la licencia de cliente como se describe en [usando una licencia](/server/license).

```ts
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'
import AdvancedLocale from '@univerjs/preset-sheets-advanced/locales/es-ES'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import CoreLocale from '@univerjs/preset-sheets-core/locales/es-ES'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing'
import DrawingLocale from '@univerjs/preset-sheets-drawing/locales/es-ES'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css'
import '@univerjs/preset-sheets-advanced/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.ES_ES,
  locales: {
    [LocaleType.ES_ES]: mergeLocales(CoreLocale, DrawingLocale, AdvancedLocale),
  },
  presets: [
    UniverSheetsCorePreset({ container: 'app' }),
    UniverSheetsDrawingPreset(),
    UniverSheetsAdvancedPreset({ slicer: { maxMemberWindowSize: 200 } }),
  ],
})
```

Cuando utilice un [Trabajador](/guides/sheets/getting-started/worker), configure `useWorker: true` en el preset avanzado y regístrese `UniverSheetsAdvancedWorkerPreset()` del Worker. Ese preset también incluye el plugin de cálculo de rebanadas.

## Crear una segmentación [#create-slicer]

El ejemplo a continuación utiliza un PivotTable en I1 en la hoja activa y un campo de origen llamado `Region`. Llame a `getSourceFieldsInfo()` para obtener el ID original estable del campo. No se pueden transmitir nombres de visualización e identificación de campo de reporte a `newSlicer()`.

```ts
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook?.getActiveSheet()
if (!fWorkbook || !fWorksheet) throw new Error('No active worksheet')

const pivotTable = fWorkbook.getPivotTableByCell(
  fWorkbook.getId(),
  fWorksheet.getSheetId(),
  0,
  8,
)
const regionField = pivotTable?.getSourceFieldsInfo().find((field) => field.name === 'Region')
if (!pivotTable || !regionField) throw new Error('Region source field not found')

const slicer = await fWorksheet.insertSlicer(
  pivotTable.newSlicer(regionField.id)
    .setCaption(regionField.name)
    .setPosition('N2')
    .build(),
)
```

`pivotTable.newSlicer()` une el constructor a esa fuente. `build()` sólo monta la configuración; `insertSlicer()` crea el control. La hoja de host y la hoja de fuente pueden diferir, pero ambos deben estar en el mismo libro de trabajo. Para una fuente de tabla, llame a `fWorksheet.newSlicer(columnId).setTableReference({ subUnitId, tableId })`, donde `columnId` es el ID estable de la columna de la tabla.

## Crear una línea de tiempo [#create-timeline]

Este ejemplo utiliza el mismo PivotTable y requiere un campo de fecha original llamado `Date`. `newTimeline()` valida la fuente y rechaza campos no soportados. API de rango de tiempo toman Excel valores de serie en el sistema de fecha del libro de trabajo, no JavaScript `Date` objetos.

```ts
const dateField = pivotTable.getSourceFieldsInfo().find((field) => field.name === 'Date')
if (!dateField) throw new Error('Date source field not found')

const timeline = await fWorksheet.insertTimeline(
  pivotTable.newTimeline(dateField.id)
    .setCaption(dateField.name)
    .setLevel(univerAPI.Enum.TimelineLevel.Month)
    .setPosition('N18')
    .build(),
)
```

## Buscar controles y observar cambios [#controls-and-events]

En la hoja de trabajo de host, `getSlicer(viewId)` / `getSlicers()` y `getTimeline(viewId)`/ `getTimelines()` localizar los controles. `viewId` es el ID de negocio que el control de `getId()` devuelve, no su ID de dibujo.

Registro `SlicerAdded`, `SlicerChanged`, `SlicerRemoved`, `TimelineAdded`, `TimelineChanged`, y `TimelineRemoved` a `univerAPI.addEvent()`. Un evento indica que se cometió un cambio local. No indica que el cambio se guardó a distancia o que la renderización ha terminado. Desembolsar la suscripción devuelta cuando ya no es necesario.

## Consultar miembros y compartir filtros [#shared-filters]

`setSelection()` espera valores de origen tipo. El número `1`, la cadena `'1'`, y un blanco son tres miembros diferentes, por lo que no pase etiquetas de visualización o índices de la lista visible. Cada vista del mismo caché, y cada informe conectado a él, comparte el filtro. Con una fuente de tabla, la selección reemplaza el filtro de esa columna y deja las otras columnas sin cambios. Llame `clearFilter()` para limpiar el filtro.

```ts
import { FilterSelectionMode, RecordValueType } from '@univerjs/core'

const accepted = await slicer.setSelection({
  mode: FilterSelectionMode.Include,
  values: [{ type: RecordValueType.String, value: 'EMEA' }],
})
```

`getItems({ start, count })` lee una ventana de elementos en lugar de toda la fuente, y la lectura no cambia la selección. Una solicitud predeterminada a 100 elementos y es capped por `maxMemberWindowSize` (por defecto 200, un entero positivo). Se conservan las selecciones que caen fuera de la ventana visible. `setConnections()` reemplaza las conexiones del informe Pivot; uso `getConnectionCandidates()` para descubrir los informes que pueden conectarse. La edición requiere los permisos de hoja de trabajo pertinentes. [FSheetSlicer](/reference/facade/sheet-slicer).

## Condiciones de fecha de la línea de tiempo [#date-conditions]

`setSelection({ startDate, endDate, useWholeDay: true })` amplía los límites fraccionados a días enteros, mientras que un extremo entero sigue siendo exclusivo. Sin `useWholeDay`, el intervalo es exactamente `[startDate, endDate)`. Una condición de fecha fija compartida de un PivotTable puede ser no contiguo; `getDateCondition()` lo lee en ese caso. Para tal condición, `getSelection()` devuelve `undefined`, por lo que el resultado por sí solo no indica que la línea de tiempo está infiltrada.
