Функция печати позволяет выводить содержимое электронной таблицы на бумагу или экспортировать его в PDF для просмотра без подключения к интернету и совместного использования.

## Режим пресетов

Функция печати входит в пресет `@univerjs/preset-sheets-advanced`.

### Установка

<Callout>
  Во время выполнения пресету `UniverSheetsAdvancedPreset` из `@univerjs/preset-sheets-advanced` требуется пресет
  `UniverSheetsDrawingPreset`. Сначала установите `@univerjs/preset-sheets-drawing`.
</Callout>

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

### Использование

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
import UniverPresetSheetsAdvancedEnUS from '@univerjs/preset-sheets-advanced/locales/en-US' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]
import UniverPresetSheetsDrawingEnUS from '@univerjs/preset-sheets-drawing/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-advanced/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsDrawingEnUS, // [!code ++]
      UniverPresetSheetsAdvancedEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsDrawingPreset(), // [!code ++]
    UniverSheetsAdvancedPreset(), // [!code ++]
  ],
})
```

Если у вас есть коммерческая лицензия Univer, инструкции по настройке см. в разделе [Использование лицензии на клиенте](/guides/pro/license#in-preset-mode).

### Открытие диалогового окна настройки печати

Метод `FWorkbook.openPrintDialog` открывает диалоговое окно настройки печати.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

fWorkbook.openPrintDialog()
```

### Закрытие диалогового окна настройки печати

Метод `FWorkbook.closePrintDialog` закрывает диалоговое окно настройки печати.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.openPrintDialog()

// Close the print configuration dialog after 3 seconds
setTimeout(() => {
  fWorkbook.closePrintDialog()
}, 3000)
```

### Обновление конфигурации макета печати

Метод [`FWorkbook.updatePrintConfig(config: ISheetPrintLayoutConfig)`](https://docs.univer.ai/reference/facade/workbook#updateprintconfig) обновляет конфигурацию макета печати.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const subUnitId = fWorksheet.getSheetId()

// Update print layout config
fWorkbook.updatePrintConfig({
  area: univerAPI.Enum.PrintArea.CurrentSheet, // print current sheet
  subUnitIds: [subUnitId],
  paperSize: univerAPI.Enum.PrintPaperSize.A4, // A4 paper size
  scale: univerAPI.Enum.PrintScale.FitPage, // fit content to page
  freeze: [univerAPI.Enum.PrintFreeze.Row], // freeze row headers
  margin: univerAPI.Enum.PrintPaperMargin.Normal, // normal margin
  // ... other settings
})

// Start printing with the updated configuration
fWorkbook.print()
```

### Обновление конфигурации рендеринга печати

Метод [`FWorkbook.updatePrintRenderConfig(config: ISheetPrintRenderConfig)`](https://docs.univer.ai/reference/facade/workbook#updateprintrenderconfig) обновляет конфигурацию рендеринга печати.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Update print layout config by default
fWorkbook.updatePrintConfig({})

// Update print render config
fWorkbook.updatePrintRenderConfig({
gridlines: true, // show gridlines
hAlign: univerAPI.Enum.PrintAlign.Middle, // horizontal align middle
vAlign: univerAPI.Enum.PrintAlign.Middle, // vertical align middle
headerFooter: [ // the array of header and footer elements to include, here is page numbers and worksheet name
  univerAPI.Enum.PrintHeaderFooter.PageSize,
  univerAPI.Enum.PrintHeaderFooter.WorksheetTitle,
],
// ... other settings
})

// Start print
fWorkbook.print()
````

### Печать

Метод `FWorkbook.print` позволяет напрямую открыть диалоговое окно печати.

```typescript
// Using the default configuration you can pass in an empty object
workbook.updatePrintConfig({
// ... Print layout configuration
})
workbook.updatePrintRenderConfig({
// ... Print render configuration
})
workbook.print()
````

### Сохранение снимка экрана в буфер обмена

Метод `FWorkbook.saveScreenshotToClipboard` сохраняет изображение данных для печати в буфер обмена.

Эта возможность доступна только при наличии [лицензии](/guides/pro/license). Для пользователей без лицензии действуют ограничения, а операция сохранения возвращает `false`.

Для сохранения изображения в буфер обмена используется Clipboard API. В небезопасной сетевой среде или неподдерживаемом браузере операция может завершиться ошибкой. При успешном сохранении возвращается `true`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const result = await fWorkbook.saveScreenshotToClipboard()
```

### Получение снимка выбранного диапазона

Метод `FRange.getScreenshot` позволяет получить снимок выбранного диапазона данных для печати.

Эта возможность доступна только при наличии [лицензии](/guides/pro/license). Для пользователей без лицензии действуют ограничения. При ошибке операция сохранения возвращает `false`, а при успехе — строку изображения в формате base64.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:D10')
fRange.getScreenshot()
fRange.getScreenshot({ includeHeaders: true }) // Include row and column headers
```

### Обработчики событий

Для функции печати доступны следующие события:

Событие `univerAPI.Event.BeforeSheetPrintOpen` срабатывает перед открытием диалогового окна настройки печати.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetPrintOpen, (params) => {
  const { workbook, worksheet } = params

  // Cancel open print configuration dialog operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`.
```

Событие `univerAPI.Event.SheetPrintOpen` срабатывает после открытия диалогового окна настройки печати.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetPrintOpen, (params) => {
  const { workbook, worksheet } = params

```
