Un filigrane est un texte ou une superposition d'image dessiné sur un tableur. Le contenu, la position de départ, l'espacement répété, la rotation et l'opacité sont configurables.

<Callout type="info">
  Le [Générateur de filigrane](/tools/watermark-generator) prévisualise les styles de filigrane et télécharge la configuration du plugin sous JSON.
</Callout>

<PlaygroundFrame lang="fr-FR" slug="sheets/watermark" clickToShow />

## Mode plugin

### Installation

```package-install
npm install @univerjs/watermark
```

### Utilisation

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

## Mode prédéfini

Watermark n'a pas de préréglage propre, mais le plugin fonctionne toujours avec les presets.

### Installation

```package-install
npm install @univerjs/watermark
```

### Utilisation

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## API Facade

### Importation

<Callout type="info" title="Note du mode greffon">
  Seul le mode plugin nécessite l'importation manuelle du paquet Facade. Le mode Preset inclut déjà le paquet Facade correspondant, donc aucune importation supplémentaire n'est nécessaire.
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### Ajouter un filigrane

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### Supprimer un filigrane

```typescript
univerAPI.deleteWatermark()
```
