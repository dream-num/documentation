La fonctionnalité de filigrane offre une solution flexible et sécurisée pour les feuilles de calcul. Elle permet aux développeurs d’ajouter des filigranes textuels ou graphiques et propose différentes options pour personnaliser leur apparence et leur comportement.

<PlaygroundFrame lang="fr-FR" slug="sheets/watermark" clickToShow />

## Mode prédéfini

La fonctionnalité de filigrane ne fournit pas de préréglage, mais son plugin peut être associé à des préréglages.

### Installation

```package-install
npm install @univerjs/watermark
```

### Utilisation

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## Mode plugin

### Installation

```package-install
npm install @univerjs/watermark
```

### Utilisation

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

### Plugins et configuration

#### @univerjs/watermark

Ce plugin fournit l’implémentation principale de la fonctionnalité de filigrane. Il permet aux développeurs d’ajouter des filigranes textuels ou graphiques aux applications et propose différentes options pour personnaliser leur apparence et leur comportement. Il fournit le plugin `UniverWatermarkPlugin`.

Référence : [@univerjs/watermark](https://docs.univer.ai/reference/packages/plugins/univerjs/watermark)

## API Facade

### Importation

<Callout type="info" title="Remarque sur le mode plugin">
  Seul le mode plugin nécessite d’importer manuellement le package Facade. Le mode prédéfini inclut déjà le package Facade correspondant : aucun import supplémentaire n’est nécessaire.
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### Ajouter un filigrane

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### Supprimer un filigrane

```typescript
univerAPI.deleteWatermark()
```
