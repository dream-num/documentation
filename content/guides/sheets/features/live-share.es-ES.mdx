<Callout type="warning" title="Note">
  Live Share reutiliza la conexión colaborativa. Integra [Univer Server SDK](/server/collaboration/browser-integration) e implementa el [protocolo Live Share](/server/collaboration/extensions#live-share) en tu backend. **El Endpoint de colaboración `1.0.0-rc.0` no procesa mensajes `liveshare.*`; el inicio rápido por sí solo no activa esta función.** Configura la [licencia del cliente](/server/license) por separado.
</Callout>

La función Live Share permite a los usuarios sincronizar sus operaciones de visualización (como desplazamiento y cambios de selección) con otros seguidores en tiempo real durante la colaboración entre varias personas, o seguir la perspectiva de otros usuarios. Esto es muy útil en escenarios como presentaciones de reuniones y explicaciones didácticas.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/live-share
```

### Uso

```typescript
import { UniverLiveSharePlugin } from '@univerjs-pro/live-share' // [!code ++]
import { Univer } from '@univerjs/core'

import '@univerjs-pro/live-share/lib/index.css' // [!code ++]

import '@univerjs-pro/live-share/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverLiveSharePlugin)
```

Si tiene una licencia comercial de Univer, consulte [Uso de la licencia en el cliente](/server/license#in-plugin-mode) para la configuración.

## API de Facade

La función Live Share amplía las interfaces relevantes en la API de Facade, a las que puede llamar directamente a través de `univerAPI`.

### Importar

```typescript
import '@univerjs-pro/live-share/facade'
```

### Enumeración de estado

```typescript
export enum LiveShareStatus {
  OFFLINE = 'offline',
  IDLE = 'idle',
  FOLLOWING = 'following',
  NOT_FOLLOWING = 'not-following',
  PRESENTING = 'presenting',
}
```

### Ejemplo de uso

```typescript
import { LiveShareStatus } from '@univerjs-pro/live-share'

// Get current status
const status = univerAPI.getLiveShareStatus()

if (status === LiveShareStatus.IDLE) {
  // If currently idle, start presenting
  univerAPI.startPresenting()
} else if (status === LiveShareStatus.PRESENTING) {
  // If presenting, stop presenting
  univerAPI.stopPresenting()
}

// Start following
univerAPI.startFollowing()

// Stop following
univerAPI.stopFollowing()
```
