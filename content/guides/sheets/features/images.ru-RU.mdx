Изображения передают информацию, которую легче проиллюстрировать, чем описать. Univer поддерживает два типа изображений: плавающие изображения, которые размещены над сеткой, и изображения ячеек, которые связаны с одной ячейкой.

## Режим плагина

### Установка

```package-install
npm install @univerjs/docs-drawing @univerjs/drawing @univerjs/drawing-ui @univerjs/sheets-drawing @univerjs/sheets-drawing-ui
```

### Использование

```typescript
import { IImageIoService, LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsDrawingPlugin } from '@univerjs/docs-drawing' // [!code ++]
import { UniverDrawingPlugin } from '@univerjs/drawing' // [!code ++]
import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui' // [!code ++]
import DrawingUIEnUS from '@univerjs/drawing-ui/locale/en-US' // [!code ++]
import { UniverSheetsDrawingPlugin } from '@univerjs/sheets-drawing' // [!code ++]
import { UniverSheetsDrawingUIPlugin } from '@univerjs/sheets-drawing-ui' // [!code ++]
import SheetsDrawingUIEnUS from '@univerjs/sheets-drawing-ui/locale/en-US' // [!code ++]
import '@univerjs/drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing/facade' // [!code ++]
import '@univerjs/sheets-drawing-ui/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DrawingUIEnUS, // [!code ++]
      SheetsDrawingUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverDrawingUIPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingUIPlugin) // [!code ++]
```

Если вы используете [Сотрудничество](/guides/docs/features/collaboration), добавьте конфигурацию `override`:

```typescript
univer.registerPlugin(UniverDrawingPlugin, {
  override: [[IImageIoService, null]], // [!code ++]
  // allowImageSize: 20 * 1024 * 1024, // set the maximum allowed size of uploaded images to 20MB, optional
})
```

### Добавление плавающего DOM-элемента

`FWorksheet.addFloatDomToPosition(layer)` добавляет плавающий DOM-элемент в указанном положении.

```tsx
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()

// You should register components at an appropriate time (e.g., when Univer is loaded)
// This is a React component. For Vue3 components, the third parameter should be `{ framework: 'vue3' }`
univerAPI.registerComponent(
  'myFloatDom',
  ({ data }) => (
    <div style={{ width: '100%', height: '100%', background: '#fff', border: '1px solid #ccc', boxSizing: 'border-box' }}>
      popup content:
      {' '}
      {data?.label}
    </div>
  ),
)

// Add a floating DOM
// If disposable is null, floating DOM addition failed
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'myFloatDom',
  initPosition: {
    startX: 100,
    endX: 300,
    startY: 100,
    endY: 200,
  },

  // Component data
  data: {
    label: 'hahah',
  },
})

// 2 秒后移除浮动 DOM
setTimeout(() => {
  disposable?.dispose()
}, 2000)
```

### Вставка плавающих изображений

[`FWorksheet.newOverGridImage()`](https://docs.univer.ai/reference/facade/worksheet#newovergridimage) возвращает конструктор для плавающего изображения, экземпляр `FOverGridImageBuilder`. Цепочка сеттеров создает объект `ISheetImage`, который может быть вставлен в лист.

Строитель, [`FOverGridImageBuilder`](/reference/facade/over-grid-image-builder), предоставляет следующие методы:

| Метод | Описание |
| ------ | ----------- |
| buildAsync | Создайте изображение и верните объект `ISheetImage` |
| setSource | Установите источник изображения |
| setColumn | Установите горизонтальное положение изображения |
| setRow | Установите вертикальное положение изображения |
| setColumnOffset | Установите горизонтальное смещение изображения |
| setRowOffset | Установите вертикальное смещение изображения |
| setWidth | Установите ширину изображения |
| setHeight | Установите высоту изображения |
| setAnchorType | Установите тип якоря, который определяет, изменяется ли положение и размер с ячейкой. |
| setCropTop | Установите верхнюю кромку посевной области так, чтобы отображалась только желаемая часть изображения. |
| setCropLeft | Установите левый край посевной области так, чтобы была показана только желаемая часть изображения. |
| setCropBottom | Установите нижний край области урожая так, чтобы была показана только желаемая часть изображения. |
| setCropRight | Установите правый край посевной области так, чтобы отображалась только желаемая часть изображения. |
| setRotate | Задаёт угол поворота изображения |

```typescript
// create a new image builder and set image source.
// then build `ISheetImage` and insert it into the sheet, position is start from F6 cell, width is 500px, height is 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])
```

Изображение также может быть вставлено с помощью метода `FWorksheet.insertImage(url, column, row, offsetX, offsetY)`.

```typescript
// Insert an image to the sheet, position is F6, offset is 10px
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const result = await fWorksheet.insertImage('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', 5, 5, 10, 10)
```

### Получение плавающих изображений

`FWorksheet.getImages()` возвращает все плавающие изображения в таблице в виде массива экземпляров [`FOverGridImage[]`] (https://docs.univer.ai/reference/facade/chart).

```typescript
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const images = fWorksheet.getImages()
images.forEach((image) => {
  image.getId()
})
```

Чтобы получить одно плавающее изображение по его идентификатору, используйте метод `FWorksheet.getImageById(id)`.

### Обновление плавающих изображений

`FWorksheet.updateImages(sheetImages)` обновляет плавающие изображения: положение, размер и другие свойства.

```typescript
// create a new image builder and set image source.
// then build `ISheetImage` and insert it into the sheet, position is start from F6 cell, width is 500px, height is 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])

// update the image width to 100px and height to 50px after 4 seconds
setTimeout(async () => {
  const imageBuilder = fWorksheet.getImageById(image.drawingId).toBuilder()
  const newImage = await imageBuilder.setWidth(100).setHeight(50).buildAsync()
  fWorksheet.updateImages([newImage])
}, 4000)
```

## Фоновое изображение листа [#worksheet-background]

Рабочий лист также может иметь одно черепичное фоновое изображение, нарисованное за ячейками. Изображение хранится в `IWorksheetData.backgroundImage` и не зависит от плавающих и сотовых изображений. Предустановленный рисунок включает в себя эту функцию. В режиме плагина необходимыми пакетами являются `@univerjs/sheets-drawing`, его вход в Facade и пользовательский интерфейс рисунка, который обеспечивает управление рендерингом и загрузкой.

```ts
import '@univerjs/sheets-drawing/facade'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

sheet.setBackgroundImage('https://example.com/background.png')
console.log(sheet.getBackgroundImage())
sheet.deleteBackgroundImage()
```

`setBackgroundImage()` использует `ImageSourceType.URL` по умолчанию и заменяет любой существующий фон; `deleteBackgroundImage()` удаляет его. Обе операции реализованы в виде команд, поэтому отменяются и переделываются. Загруженные изображения разрешаются пользовательским интерфейсом через настроенный сервис ввода/вывода изображения. Фон отображается только на экране и исключается из печати.

## Непрозрачность изображений [#image-opacity]

Плавающие изображения используют одно значение непрозрачности для всего изображения. `setOpacity()` принимает конечное число от `0` (прозрачное) до `1`(непрозрачный); по умолчанию `1`, а любое другое значение бросает `RangeError`. Установите его на `FOverGridImageBuilder` перед постройкой, или на `FOverGridImage` который уже находится в листе. Оба выставляют `getOpacity()` . Панель свойств изображения также обеспечивает контроль прозрачности.

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
const image = sheet?.getImages()[0]
if (image) {
  image.setOpacity(0.5)
  console.log(image.getOpacity())
}
```

## Размер и привязка изображений [#image-sizing-and-anchors]

Изображения, вставленные через встроенный сборщик файлов, сохраняют свое соотношение сторон и масштабируются вниз, чтобы поместиться внутри 500 × 500 пикселей, когда они слишком велики; маленькие изображения не увеличены. Этот размер дисплея не зависит от предела байта `allowImageSize` на загрузках. Когда изображение вставляется через Фасад, вызывающий абонент поставляет размеры.

Якоря определяют, что происходит, когда ячейки перемещаются или изменяют размер. `SheetDrawingAnchorType.Position` перемещает изображение с ячейками, сохраняя при этом его размер, `Both` движется и изменяет его размер с заякоренным диапазоном, а `None` сохраняет фиксированное положение и размер. Скрытие или отображение строк или столбцов сохраняет определение якоря: изображение, размером с диапазон, может сжиматься с этим диапазоном и восстанавливаться, когда диапазон отображается снова. Временная геометрия скрытого ряда не должна записываться обратно по сохраненным якорям.
