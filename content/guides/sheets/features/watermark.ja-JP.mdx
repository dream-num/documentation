透かしは、スプレッドシートの上に描かれたテキストまたは画像のオーバーレイです。 コンテンツ、開始位置、繰り返し間隔、回転、および不透明度は構成可能です。

<Callout type="info">
  [透かし発生器](/tools/watermark-generator)は透かしスタイルをプレビューし、プラグインの設定をJSONとしてダウンロードします。
</Callout>

## プラグインモード

### インストール

```package-install
npm install @univerjs/watermark
```

### 使い方

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

## プリセットモード

ウォーターマークには独自のプリセットはありませんが、プラグインはまだプリセットと一緒に動作します。

### インストール

```package-install
npm install @univerjs/watermark
```

### 使い方

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## Facade API

### インポート

<Callout type="info" title="プラグインモードノート">
  プラグインモードのみ、Facadeパッケージを手動でインポートする必要があります。プリセットモードには、対応するファサードパッケージが含まれているため、追加のインポートは必要ありません。
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### ウォーターマークを設定

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### ウォーターマークを削除

```typescript
univerAPI.deleteWatermark()
```
