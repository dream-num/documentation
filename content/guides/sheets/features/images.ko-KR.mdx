이미지는 설명하는 것보다 쉽게 설명하는 정보를 전달합니다. Univer는 두 가지 이미지 유형을 지원합니다: 그리드 위에 배치되는 플로팅 이미지, 단일 셀에 바인딩되는 셀 이미지.

## 플러그인 모드

### 설치

```package-install
npm install @univerjs/docs-drawing @univerjs/drawing @univerjs/drawing-ui @univerjs/sheets-drawing @univerjs/sheets-drawing-ui
```

### 사용법

```typescript
import { IImageIoService, LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsDrawingPlugin } from '@univerjs/docs-drawing' // [!code ++]
import { UniverDrawingPlugin } from '@univerjs/drawing' // [!code ++]
import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui' // [!code ++]
import DrawingUIEnUS from '@univerjs/drawing-ui/locale/en-US' // [!code ++]
import { UniverSheetsDrawingPlugin } from '@univerjs/sheets-drawing' // [!code ++]
import { UniverSheetsDrawingUIPlugin } from '@univerjs/sheets-drawing-ui' // [!code ++]
import SheetsDrawingUIEnUS from '@univerjs/sheets-drawing-ui/locale/en-US' // [!code ++]
import '@univerjs/drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing/facade' // [!code ++]
import '@univerjs/sheets-drawing-ui/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DrawingUIEnUS, // [!code ++]
      SheetsDrawingUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverDrawingUIPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingUIPlugin) // [!code ++]
```

[회사연혁](/guides/docs/features/collaboration)를 사용하는 경우 `override` 구성을 추가하십시오.

```typescript
univer.registerPlugin(UniverDrawingPlugin, {
  override: [[IImageIoService, null]], // [!code ++]
  // allowImageSize: 20 * 1024 * 1024, // set the maximum allowed size of uploaded images to 20MB, optional
})
```

### 플로팅 DOM 추가

`FWorksheet.addFloatDomToPosition(layer)`는 지정된 위치에 뜨 DOM 성분을 추가합니다.

```tsx
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()

// You should register components at an appropriate time (e.g., when Univer is loaded)
// This is a React component. For Vue3 components, the third parameter should be `{ framework: 'vue3' }`
univerAPI.registerComponent(
  'myFloatDom',
  ({ data }) => (
    <div style={{ width: '100%', height: '100%', background: '#fff', border: '1px solid #ccc', boxSizing: 'border-box' }}>
      popup content:
      {' '}
      {data?.label}
    </div>
  ),
)

// Add a floating DOM
// If disposable is null, floating DOM addition failed
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'myFloatDom',
  initPosition: {
    startX: 100,
    endX: 300,
    startY: 100,
    endY: 200,
  },

  // Component data
  data: {
    label: 'hahah',
  },
})

// 2 秒后移除浮动 DOM
setTimeout(() => {
  disposable?.dispose()
}, 2000)
```

`FWorksheet.addFloatDomToRange(range, layer, domLayout)`는 지정된 범위에 떠 있는 DOM 요소를 추가합니다.

### 플로팅 이미지 삽입

[`FWorksheet.newOverGridImage()`](https://docs.univer.ai/reference/facade/worksheet#newovergridimage)는 뜨 이미지, `FOverGridImageBuilder`의 인스턴스를 위한 제작자를 반환합니다. setters를 사슬로 운반하는 것은 장으로 삽입될 수 있는 `ISheetImage` 목표를 일으킵니다.

빌더, [`FOverGridImageBuilder`](/reference/facade/over-grid-image-builder), 다음 방법을 제공합니다:

| 메서드 | 설명 |
| ------ | ----------- |
| buildAsync | 이미지를 구축하고 `ISheetImage` 개체를 반환 |
| setSource | 이미지 소스 설정 |
| setColumn | 이미지의 수평한 위치를 놓으십시오 |
| setRow | 이미지의 수직 위치 설정 |
| setColumnOffset | 이미지의 수평 오프셋 설정 |
| setRowOffset | 이미지의 수직 오프셋 설정 |
| setWidth | 이미지 너비 설정 |
| setHeight | 이미지 높이 설정 |
| setAnchorType | 닻 유형을 놓으십시오, 위치를 결정하고 세포로 크기 변화 |
| setCropTop | 작물의 상단 가장자리를 설정하여 이미지의 원하는 부분을 표시 |
| setCropLeft | 작물의 왼쪽 가장자리를 설정하여 이미지의 원하는 부분 만 표시됩니다. |
| setCropBottom | 작물의 바닥 가장자리를 설정하여 이미지의 원하는 부분 만 표시됩니다. |
| setCropRight | 작물의 오른쪽 가장자리를 설정하여 이미지의 원하는 부분 만 표시됩니다. |
| setRotate | 이미지의 회전 각도를 설정합니다. |

```typescript
// create a new image builder and set image source.
// then build `ISheetImage` and insert it into the sheet, position is start from F6 cell, width is 500px, height is 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])
```

이미지는 또한 `FWorksheet.insertImage(url, column, row, offsetX, offsetY)` 방법으로 삽입될 수 있습니다.

```typescript
// Insert an image to the sheet, position is F6, offset is 10px
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const result = await fWorksheet.insertImage('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', 5, 5, 10, 10)
```

### 플로팅 이미지 가져오기

`FWorksheet.getImages()`는 워크 시트의 모든 플로팅 이미지를 [`FOverGridImage[]`](https://docs.univer.ai/reference/facade/chart) 인스턴스의 배열로 반환합니다.

```typescript
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const images = fWorksheet.getImages()
images.forEach((image) => {
  image.getId()
})
```

ID로 한 플로팅 이미지를 얻으려면 `FWorksheet.getImageById(id)` 메소드를 사용하십시오.

### 플로팅 이미지 업데이트

`FWorksheet.updateImages(sheetImages)` 업데이트 플로팅 이미지 위치 : 위치, 크기 및 기타 속성.

```typescript
// create a new image builder and set image source.
// then build `ISheetImage` and insert it into the sheet, position is start from F6 cell, width is 500px, height is 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])

// update the image width to 100px and height to 50px after 4 seconds
setTimeout(async () => {
  const imageBuilder = fWorksheet.getImageById(image.drawingId).toBuilder()
  const newImage = await imageBuilder.setWidth(100).setHeight(50).buildAsync()
  fWorksheet.updateImages([newImage])
}, 4000)
```

## 워크시트 배경 이미지 [#worksheet-background]

작업 시트는 셀 뒤에 그려진 한 타일 배경 이미지가있을 수 있습니다. 이미지는 `IWorksheetData.backgroundImage`에 저장되며 부동 및 셀 이미지의 독립적입니다. 그림 미리 설정은이 기능을 포함합니다. 플러그인 모드에서 필요한 패키지는 `@univerjs/sheets-drawing`, Facade 항목 및 그림 UI이며 렌더링 및 업로드 컨트롤을 제공합니다.

```ts
import '@univerjs/sheets-drawing/facade'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

sheet.setBackgroundImage('https://example.com/background.png')
console.log(sheet.getBackgroundImage())
sheet.deleteBackgroundImage()
```

`setBackgroundImage()`는 기본적으로 `ImageSourceType.URL`를 사용하고 기존의 배경을 대체합니다. `deleteBackgroundImage()`가 제거됩니다. 두 작업은 명령으로 구현되므로 취소 및 재도가 적용됩니다. 업로드 이미지는 구성 된 이미지 I/O 서비스를 통해 UI에 의해 해결됩니다. 배경은 스크린에 표시되어 있으며 인쇄에서 제외됩니다.

## 이미지 불투명도 [#image-opacity]

플로팅 이미지는 전체 이미지에 대한 단일 불투명 값을 사용합니다. `setOpacity()`은 `1` (투명)에 `0` (투명한)에서 무한한 수를 받아들입니다; 기본은 `1`이고, 다른 어떤 가치는 `RangeError`를 던졌습니다. 건물, 또는 `FOverGridImage`에서 건축하기 전에 `FOverGridImageBuilder`에 놓으십시오. 둘 다 `getOpacity()`를 드러냅니다. 이미지 재산 패널은 또한 투명성 통제를 제공합니다.

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
const image = sheet?.getImages()[0]
if (image) {
  image.setOpacity(0.5)
  console.log(image.getOpacity())
}
```

## 이미지 크기와 앵커 [#image-sizing-and-anchors]

내장 파일 피커를 통해 삽입 된 이미지는 종횡비를 유지하고 500 × 500 픽셀 내부에 적합하기 위해 축소됩니다. 작은 이미지는 확대되지 않습니다. 디스플레이 크기는 `allowImageSize` 바이트 제한의 독립적으로입니다. 이미지가 Facade를 통해 삽입되면 콜러는 크기를 공급합니다.

`SheetDrawingAnchorType.Position`는 세포 이동 또는 크기를 언제 일어나는지 결정합니다. `Both`가 고정된 범위로 이동하고 크기를 조정하는 동안 세포를 가진 이미지를 이동하고, `None`에는 조정 위치 및 크기를 지킵니다. 줄 또는 열을 보여주는 것은 앵커 정의를 보존합니다: 범위에 크기가 그 범위로 붕괴하고 범위를 다시 보일 때 재기할 수 있습니다. 숨겨지은 위치는 저장한 기하학에 기록되어야 합니다.
