[ピボットテーブル](/guides/sheets/features/pivot-table)と[チャート](/guides/sheets/features/charts)の依存関係を最初に登録し、ワークブックを作成する前に、以下の2つのプラグインを追加します。 `locales`の設定にUIのロケールをマージし、対応するスタイルシートをロードします。 Proのライセンスが必要です。

```package-install
npm install @univerjs-pro/sheets-pivot-chart @univerjs-pro/sheets-pivot-chart-ui
```

```ts
import { UniverSheetsPivotChartPlugin } from '@univerjs-pro/sheets-pivot-chart'
import { UniverSheetsPivotChartUIPlugin } from '@univerjs-pro/sheets-pivot-chart-ui'
import SheetsPivotChartLocale from '@univerjs-pro/sheets-pivot-chart-ui/locale/ja-JP'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/sheets-pivot-chart/facade'
import '@univerjs-pro/sheets-pivot-chart-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.JA_JP, SheetsPivotChartLocale)

univer.registerPlugin(UniverSheetsPivotChartPlugin)
univer.registerPlugin(UniverSheetsPivotChartUIPlugin)
```

高度なスプレッドシートプリセットには、プラグインが既に含まれています。コアと描画プリセットと一緒に使用し、このページのAPIに明示的に`@univerjs-pro/sheets-pivot-chart/facade`をインポートします。

## Worker の設定 [#worker-configuration]

### プリセット設定

これらのオプションは、`UniverSheetsAdvancedPreset` に属しています。

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `useWorker` | `boolean` | `false` | 数式 Worker の高度な機能を有効にします。 |

[ワーカー](/guides/sheets/getting-started/worker)を使うと、Worker内のメインスレッドと`UniverSheetsAdvancedWorkerPreset()`に`UniverSheetsAdvancedPreset({ useWorker: true })`を渡します。プラグインモードの詳細は[パッケージの参照](/reference/packages/plugins/univerjs-pro/sheets-pivot-chart#worker-calculation)です。

## 独立したレポート [#owned-report]

独立したグラフは、レポートを所有しています。 インサート後、行フィールドと値フィールドを追加します。 例では、最初の2つのソース列を使用します。

```ts
const workbook = univerAPI.getActiveWorkbook()
const sheet = workbook?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

sheet.getRange('A1:B4').setValues([
  ['Region', 'Sales'], ['East', 100], ['West', 200], ['East', 50],
])
const chart = await sheet.insertPivotChart(
  sheet.newPivotChart(univerAPI.Enum.ChartTypeString.Column)
    .setSource('A1:B4').setPosition('D2').setSize(640, 360).build(),
)
const fields = chart.getSourceFieldsInfo()
await chart.addField(fields[0].id, univerAPI.Enum.PivotTableFiledAreaEnum.Row, 0)
await chart.addField(fields[1].id, univerAPI.Enum.PivotTableFiledAreaEnum.Value, 0)
```

## ピボットテーブルとの連携 [#linked-report]

フィールド、フィルタ、ソート、および崩壊の編集は、参照されたPivotTableと他のリンクされたチャートと共有され、外観と位置は独立しています。 チャートを削除してもテーブルを削除しません。 表を削除すると、同じテーブルが復元されるまでチャートが利用できなくなります。

```ts
const pivotTable = workbook.getPivotTableById('pivot-table-1')
if (!pivotTable) throw new Error('PivotTable not found')

const linkedChart = await sheet.insertPivotChart(
  pivotTable.newChart(univerAPI.Enum.ChartTypeString.Line).setPosition('D22').build(),
)
linkedChart.setFieldButtonsVisible(true).setExpandCollapseButtonsVisible(true)
```

## 対応するグラフの種類 [#types-and-worker]

ライン、コラム、バー、エリア、パイ、ドーナッツ、コンビネーションチャートは、利用可能なスタックされたバリアントを含むサポートされます。 散布、バブル、レーダー、および滝はサポートされていません。 パイは最初の値シリーズを使用します。 ドーナッツは複数のシリーズを保持します。 サブトータルとグランド合計はチャートのカテゴリから除外されます。

フィールド、フィルタ、スタイル、およびライフサイクル API の [FSheetPivotChartの特長](/reference/facade/sheet-pivot-chart) を参照してください。

## ワークシートのコピーと削除 [#copy-and-delete-sheets]

ワークシートをコピーすると、PivotChartsをコピーし、新しいIDを割り当てます。コピーされたシートにある独立したレポートは、新しいシートと独立したキャッシュを使用します。リンクされたチャートは、そのテーブルがシートにコピーされたとき、コピーされたPivotTableに従っており、他のシートへの参照は変更されません。ワークシートを削除すると、それらに関連するリソースが削除されます。undoは、その定義とソースデータを復元します。

## レポートのフィルター [#report-filters]

`getOptions()`、`setOptions({ allowMultipleFilters: true })`および`setDateFilter(fieldId, condition)`は、チャートの承認レポート上で動作します。リンクされたチャートでは、PivotTableとその他のリンクされたチャートを更新します。独立したチャートでは、チャートのレポートのみを更新します。 Omit `condition`が日付条件だけをクリアします。日付シリアルと終日比較については、[複数のフィルタと日付条件](/guides/sheets/features/pivot-table#multiple-filters)を参照してください。
