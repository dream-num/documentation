Примечания позволяют добавлять к ячейкам электронной таблицы комментарии с дополнительной информацией или пояснениями. Поддержка различных стилей примечаний и операций с ними упрощает понимание данных и совместную работу.

## Режим предустановок

### Установка

```package-install
npm install @univerjs/preset-sheets-note
```

### Использование

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsNotePreset } from '@univerjs/preset-sheets-note' // [!code ++]
import UniverPresetSheetsNoteEnUS from '@univerjs/preset-sheets-note/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-note/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsNoteEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsNotePreset(), // [!code ++]
  ],
})
```

## Режим плагинов

### Установка

```package-install
npm install @univerjs/sheets-note @univerjs/sheets-note-ui
```

### Использование

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsNotePlugin } from '@univerjs/sheets-note' // [!code ++]
import { UniverSheetsNoteUIPlugin } from '@univerjs/sheets-note-ui' // [!code ++]
import SheetsNoteUIEnUS from '@univerjs/sheets-note-ui/locale/en-US' // [!code ++]

import '@univerjs/sheets-note-ui/lib/index.css' // [!code ++]

import '@univerjs/sheets-note/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      SheetsNoteUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsNotePlugin) // [!code ++]
univer.registerPlugin(UniverSheetsNoteUIPlugin) // [!code ++]
```

## Facade API

Полные определения типов Facade API приведены в [справочнике FacadeAPI](https://reference.univer.ai/en-US).

### Импорт

<Callout type="info" title="Примечание для режима плагинов">
  Импортировать пакет Facade вручную требуется только в режиме плагинов. В режиме предустановок соответствующий пакет Facade уже включен, поэтому дополнительный импорт не нужен.
</Callout>

```typescript
import '@univerjs/sheets-note/facade'
```

### Получение примечаний

Метод `FWorksheet.getNotes` возвращает все примечания на листе.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const notes = fWorksheet.getNotes()

notes.forEach((item) => {
  const { row, col, note } = item
  console.log(`Cell ${fWorksheet.getRange(row, col).getA1Notation()} has note: ${note}`)
})
```

Метод `FRange.getNote` возвращает примечание из верхней левой ячейки диапазона.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:D10')
const note = fRange.getNote()
```

### Добавление и изменение примечаний

Метод `FRange.createOrUpdateNote` создает или изменяет примечание в верхней левой ячейке диапазона.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1')
fRange.createOrUpdateNote({
  note: 'This is an annotation',
  width: 160,
  height: 100,
  show: true,
})
```

### Удаление примечаний

Метод `FRange.deleteNote` удаляет примечание из верхней левой ячейки диапазона.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const notes = fWorksheet.getNotes()

if (notes.length > 0) {
  // Remove the first annotation in the worksheet
  const { row, col } = notes[0]
  fWorksheet.getRange(row, col).deleteNote()
}

// Remove the annotation in cell C1
const fRange = fWorksheet.getRange('C1')
fRange.deleteNote()
```

### Обработчики событий

Полные определения типов событий приведены в разделе [События](https://docs.univer.ai/reference/facade/events).

| Название события | Описание |
| ---------- | ----------- |
| `SheetNoteAdd` | Срабатывает после добавления примечания |
| `SheetNoteDelete` | Срабатывает после удаления примечания |
| `SheetNoteUpdate` | Срабатывает после изменения примечания |
| `SheetNoteShow` | Срабатывает при отображении примечания |
| `SheetNoteHide` | Срабатывает при скрытии примечания |
| `BeforeSheetNoteAdd` | Срабатывает перед добавлением примечания |
| `BeforeSheetNoteDelete` | Срабатывает перед удалением примечания |
| `BeforeSheetNoteUpdate` | Срабатывает перед изменением примечания |
| `BeforeSheetNoteShow` | Срабатывает перед отображением примечания |
| `BeforeSheetNoteHide` | Срабатывает перед скрытием примечания |

##### Примеры обработчиков событий

```typescript
// Triggered after adding an annotation
const disposable = univerAPI.addEvent(univerAPI.Event.SheetNoteAdd, (params) => {
  const { workbook, worksheet, row, col, note } = params
})

// Remove event listener using `disposable.dispose()`
```

```typescript
// Triggered before removing an annotation, can be canceled
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetNoteDelete, (params) => {
  const { workbook, worksheet, row, col, oldNote } = params

  // Cancel the annotation deletion operation
  params.cancel = true
})

// Remove event listener using `disposable.dispose()`
```
