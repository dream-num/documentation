수식은 Univer가 제공하는 핵심 기능 중 하나로, 셀에서 수식을 사용해 값을 계산할 수 있습니다. 수식에서 지원하는 함수는 수학, 논리, 텍스트, 날짜 함수 등을 포함하여 Excel과 호환됩니다.

통합 문서에 수식이 많으면 수식 계산이 메인 스레드를 점유해 페이지 응답성이 저하될 수 있습니다. 렌더링과 사용자 상호 작용에 미치는 영향을 줄이려면 Worker 프로세스에서 수식 계산을 실행하는 것이 좋습니다. 구성 방법은 [Web Workers](/guides/sheets/getting-started/worker)를 참고하세요.

## 구성

수식 플러그인과 관련된 구성 항목은 다음 링크에서 확인할 수 있습니다.

| 플러그인                   | 구성 항목                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------- |
| `@univerjs/engine-formula` | [IUniverEngineFormulaConfig](/reference/packages/plugins/univerjs/engine-formula)     |
| `@univerjs/sheets-formula` | [IUniverSheetsFormulaBaseConfig](/reference/packages/plugins/univerjs/sheets-formula) |

### 프리셋 구성

```typescript
import type { CalculationMode } from '@univerjs/preset-sheets-core'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'

interface IUniverSheetsCorePresetConfig {
  formula?: {
    // Custom formula functions
    function?: Array<[Ctor<BaseFunction>, IFunctionNames]>
    // Custom formula descriptions
    description?: IFunctionInfo[]
    // Defines the calculation mode for formulas during data initialization, default is `WHEN_EMPTY`
    initialFormulaComputing?: CalculationMode
  }
}
```

### 플러그인 구성

```typescript
import type { CalculationMode } from '@univerjs/sheets-formula'
import { UniverSheetsFormulaPlugin } from '@univerjs/sheets-formula'

interface IUniverSheetsFormulaConfig {
  // Custom formula functions
  function?: Array<[Ctor<BaseFunction>, IFunctionNames]>
  // Custom formula descriptions
  description?: IFunctionInfo[]
  // Defines the calculation mode for formulas during data initialization, default is `WHEN_EMPTY`
  initialFormulaComputing?: CalculationMode
}
```

`CalculationMode`의 정의는 다음과 같습니다.

```typescript
enum CalculationMode {
  /**
   * Force calculation of all formulas
   */
  FORCED,

  /**
   * Partial calculation, only calculates cells with formulas but no value
   */
  WHEN_EMPTY,

  /**
   * No calculation for all formulas
   */
  NO_CALCULATION,
}
```

> 수식이 포함된 셀에 예상치 못한 값이 있으면 `initialFormulaComputing`을 `CalculationMode.FORCED`로 설정하여 모든 수식을 강제로 계산할 수 있습니다. 또는 초기화 전에 셀의 `v` 값을 지울 수 있습니다.

## 통합 문서 간 참조

통합 문서 간 수식으로 `Report`에서 `Sales.xlsx`의 매출을 집계할 수 있습니다. 같은 문서의 다른 시트를 참조할 때와 달리 원본 통합 문서도 지정합니다.

### 참조 구문

| 용도 | 예시 | 대상 |
| --- | --- | --- |
| 같은 문서의 다른 시트 | `=SUM(Data!A1:A10)` | 현재 문서의 Data 시트 |
| 다른 문서의 셀 범위 | `=SUM('[Sales.xlsx]Data'!A1:A10)` | Sales.xlsx의 Data 시트 |
| 다른 문서의 테이블 | `=SUM(Sales.xlsx!SalesTable[Amount])` | 기존 SalesTable의 Amount 열 |

`Sales.xlsx`는 문서 이름이며 파일 경로나 URL이 아닙니다. 수식을 작성해도 파일을 읽거나 Excel을 다운로드하거나 다른 브라우저 페이지에 연결하지 않습니다. 구조화 참조를 사용하려면 해당 [테이블](/guides/sheets/features/table)을 먼저 만드세요.

### 같은 인스턴스에 로드된 통합 문서 참조

기본 수식 엔진에서는 두 문서를 동일한 Univer 인스턴스와 계산 환경에 로드해야 합니다. 다음 코드는 Sheets 초기화 후 실행합니다. 플러그인 모드에서는 이 페이지에 설명된 Facade 확장도 가져오세요.

```typescript
const source = univerAPI.createWorkbook({
  id: 'sales-workbook',
  name: 'Sales.xlsx',
  sheetOrder: ['sales-data'],
  sheets: {
    'sales-data': {
      id: 'sales-data',
      name: 'Data',
      rowCount: 100,
      columnCount: 20,
      cellData: {
        0: { 0: { v: 100 } },
        1: { 0: { v: 200 } },
      },
    },
  },
}, { makeCurrent: false })

const report = univerAPI.createWorkbook({ id: 'report-workbook', name: 'Report' })
const resultCell = report.getActiveSheet().getRange('A1')
resultCell.setFormula("=SUM('[Sales.xlsx]Data'!A1:A2)")

const formula = univerAPI.getFormula()
formula.executeCalculation()
await formula.onCalculationResultApplied()
console.log(resultCell.getValue()) // 300
```

`makeCurrent: false`는 현재 문서를 바꾸지 않고 원본을 로드합니다. `source`와 `report`를 보관하면 활성 문서가 바뀌어도 잘못된 문서에 쓰지 않습니다.

이름 비교는 대소문자를 구분하지 않으며 전체 이름 일치를 우선합니다. 없을 때만 `.xlsx`, `.xlsm` 같은 확장자를 무시합니다. 이름이 없거나 여러 문서와 일치하면 `#REF!`가 되므로 고유한 이름을 사용하세요.

### 고정 원본 ID에 참조 바인딩

수식 이름을 안정적인 문서 ID에 연결하려면 Pro 확장인 `@univerjs-pro/engine-formula`를 사용합니다. [클라이언트 라이선스](/guides/license)를 설정하고 초기화 시 `UniverFormulaEnginePlugin`을 `UniverProFormulaEnginePlugin`으로 교체한 뒤 Pro Facade를 가져오세요. 두 엔진을 동시에 등록하지 마세요. Facade import만으로 플러그인이 등록되지는 않습니다.

Pro 엔진이 설정된 환경에서 위 문서를 사용합니다.

```typescript
import '@univerjs-pro/engine-formula/facade'

const reference = univerAPI.getFormula().buildReference({
  hostUnitId: report.getId(),
  unit: {
    unitId: source.getId(),
    formulaQualifier: 'Sales Source',
  },
  target: {
    kind: univerAPI.Enum.FormulaReferenceType.SHEET_RANGE,
    sheetName: 'Data',
    range: { startRow: 0, endRow: 1, startColumn: 0, endColumn: 0 },
  },
})

resultCell.setFormula(`=SUM(${reference})`)
```

`hostUnitId`는 수식을 저장하는 문서 ID, `unit.unitId`는 원본의 고정 ID, `formulaQualifier`는 수식에 표시되는 이름입니다. 범위 좌표는 0부터 시작하며 끝 좌표를 포함합니다.

`buildReference()`는 `=` 없는 참조 문자열을 반환하고 바인딩을 저장합니다. 원본 로드나 계산은 수행하지 않습니다. 데이터는 계산 환경에 로드된 문서 또는 설정된 데이터 공급자가 제공해야 합니다. 직접 작성하거나 앱에서 생성한 수식은 먼저 바인딩하세요.

```typescript
const formula = univerAPI.getFormula()
const bound = formula.upsertExternalReference({
  unitId: report.getId(),
  qualifier: 'Sales Source',
  sourceUnitId: source.getId(),
  sourceUnitType: univerAPI.Enum.UniverInstanceType.UNIVER_SHEET,
})
if (!bound) throw new Error('Could not bind Sales Source')

resultCell.setFormula("=SUM('[Sales Source]Data'!A1:A2)")
```

동일 바인딩을 반복해도 결과는 같습니다. `qualifier`에는 괄호나 따옴표를 넣지 마세요. `1`, `2` 같은 양의 정수는 Excel 외부 링크 슬롯이므로 문서 ID로 사용하지 않습니다. 외부 링크를 가져올 때는 링크 리소스도 유지해야 하며 수식 문자열만 복사해서는 안 됩니다.

### 업데이트, 저장 및 언로드

Facade로 원본을 변경한 뒤 명시적으로 계산하고 결과 반영을 기다린 후 값을 읽으세요. `setFormula()`나 `setValue()` 직후 비동기 계산이 완료되었다고 가정하지 마세요.

```typescript
const sourceSheet = source.getSheetBySheetId('sales-data')
if (!sourceSheet) throw new Error('Source sheet not found')
sourceSheet.getRange('A1').setValue(150)
formula.executeCalculation()
await formula.onCalculationResultApplied()
console.log(resultCell.getValue()) // 350
```

`report.save()`로 바인딩 리소스를 포함한 전체 스냅샷을 저장합니다. 수식만 저장하면 이름과 원본 ID의 연결이 사라집니다. 원본 데이터는 별도로 저장하고 로드해야 합니다.

원본을 언로드하면 일반적인 로드된 문서 참조는 데이터를 읽을 수 없습니다. Pro 참조의 계산 지속 여부는 데이터 공급자와 캐시에 달려 있습니다. 바인딩은 데이터를 포함하지 않으며 오프라인 계산을 보장하지 않습니다. 이전 표시 값을 최신 결과로 간주하지 마세요.

더 이상 필요하지 않은 Pro 바인딩은 제거할 수 있습니다.

```typescript
univerAPI.getFormula().removeExternalReference({
  unitId: report.getId(),
  qualifier: 'Sales Source',
})
```

바인딩 제거는 수식을 삭제하거나 다시 쓰지 않습니다. 다음 계산에서 이름을 다시 해석하므로 같은 이름의 로드된 문서가 있으면 계속 참조할 수도 있고, 없으면 `#REF!`가 됩니다. 참조를 중단하려면 수식도 수정하거나 지우세요. 전체 매개변수는 [FFormula 참조 API](/reference/facade/formula#cross-unit-reference-authoring)를 참고하세요.

## 3D 참조

3D 참조는 같은 통합 문서 안의 연속된 시트를 대상으로 하며 문서 간 참조와는 다릅니다.

```text
=SUM(Jan:Mar!B2:C3)
=SUM('Jan':'Mar'!B2)
```

Jan, Mar 및 그 사이의 모든 시트를 문서 내 순서대로 포함합니다. 이름순이 아닙니다. 시트 순서를 변경할 때 집계 범위도 확인하세요.

### 범위 선택기 대화 상자 표시

`@univerjs/sheets-formula-ui/facade`는 `univerAPI.showRangeSelectorDialog`를 추가합니다. 사용자 지정 UI에서 수식 관련 패널과 동일한 선택기를 사용해 사용자가 하나 이상의 범위를 선택하도록 할 때 사용하세요.

```typescript
const workbook = univerAPI.getActiveWorkbook()
const worksheet = workbook?.getActiveSheet()

if (workbook && worksheet) {
  await univerAPI.showRangeSelectorDialog({
    unitId: workbook.getId(),
    subUnitId: worksheet.getSheetId(),
    initialValue: [
      {
        unitId: workbook.getId(),
        sheetName: worksheet.getSheetName(),
        range: worksheet.getRange('A1:B2').getRange(),
      },
    ],
    maxRangeCount: 2,
    supportAcrossSheet: true,
    callback: (ranges, isCancel) => {
      console.log(ranges, isCancel)
    },
  })
}
```

### 수식 계산 실행

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.executeCalculation()
```

### 수식 계산 중지

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.stopCalculation()
```

### 수식 계산 시작

```typescript
// Listening to formula calculation start event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationStart((forceCalculate) => {
  console.log(forceCalculate)
})
```

### 수식 계산 진행

```typescript
// Listening to formula calculation processing event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationProcessing((stageInfo) => {
  console.log(stageInfo)
})
```

### 수식 계산 종료

```typescript
// Listening to formula calculation end event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationEnd((functionsExecutedState) => {
  console.log(functionsExecutedState)
})
```

### 수식 계산 결과 적용

```typescript
// Listening to formula calculation result applied event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationResultApplied((result) => {
  console.log(result)
})

// Wait for formula calculation result to be applied
await formulaEngine.onCalculationResultApplied()
```

### 데이터 초기화 시 수식 계산 모드 설정

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.setInitialFormulaComputing(CalculationMode.FORCED)
```

이 API를 `Starting` 수명 주기 이후에 호출하면 다음에 Univer Sheet를 만들 때 적용됩니다.

현재 Univer Sheet 초기화 중에 적용하려면 다음 예와 같이 `Ready` 수명 주기 전에 호출할 수 있습니다.

```typescript
univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === LifecycleStages.Starting) {
    const formulaEngine = univerAPI.getFormula()
    formulaEngine.setInitialFormulaComputing(CalculationMode.FORCED)
  }
})
```

### 최대 반복 횟수 설정

수식에 순환 참조가 있을 때 이 API를 사용하여 수식 계산의 최대 반복 횟수를 설정할 수 있습니다. 기본값은 1입니다.

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.setMaxIteration(10)
```

### 수식 문자열 실행 결과 가져오기

여러 수식을 비동기로 실행하고 계산 결과를 받습니다.

```typescript
const formulaEngine = univerAPI.getFormula()
const formulas = {
  Book1: {
    Sheet1: {
      2: {
        3: [
          // Full formula:
          '=SUM(A1:A10) + SQRT(D7)',

          // Decomposed sub-formulas (each one can be evaluated independently):
          'SUM(A1:A10)', // sub-formula 1
          'SQRT(D7)', // sub-formula 2
          'A1:A10', // range reference
          'D7', // single-cell reference
        ],
      },
      4: {
        5: ['=A2 + B2 + SQRT(C5)', 'A2', 'B2', 'SQRT(C5)'],
      },
    },
  },
}
const result = await formulaEngine.executeFormulas(formulas)
console.log(result)
```
