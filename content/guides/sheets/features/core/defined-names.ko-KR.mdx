정의된 이름은 세포, 범위 또는 공식에 사용자 정의 이름을 할당합니다. 공식은 그 이름을 대신 원시 주소 대신 참조 할 수 있으며, 쉽게 읽고 유지하기 위해 쉽게 만들 수 있습니다.

- 공식은 그들이 의미하는 것에 더 가까이 읽습니다. `Amount`는 `A1 + A2 + A3` 보다는 더 명확하게 intent를 표현합니다.
- 몇몇 세포 또는 복잡한 범위는 단 하나 이름에 의해 대표될 수 있습니다. `A1:A10`를 위한 `SalesData` 및 공식에 있는 `SalesData` 사용을 정의하십시오.
- 데이터 영역은 한 곳에서 유지됩니다. 범위가 변경되면 사용 된 모든 수식 대신 이름을 참조하십시오.

## 사용법

Name Manager 항목은 시트의 왼쪽 상단 모서리에있는 이름 상자 옆에 있습니다. 각 정의 된 이름을 표시하고 Name Manager를 열고, 볼 수 있습니다, 편집 및 정의 된 이름을 삭제합니다.

<DefinedNamesDemo />

공식에서 직접 이름을 입력합니다. 범위가 `TotalSales`, `=TotalSales` 참조로 이름을 지정하면 범위입니다.

## 참고 사항

- 정의된 이름은 동일한 워크 시트 내에서 고유해야하며 다른 이름이나 내장 함수와 충돌할 수 없습니다.
- 이름은 숫자로 시작할 수 없으며 `!`, `@` 또는 `#`와 같은 공간이나 특수 문자를 포함 할 수 없습니다. 입력된 이름이 이러한 규칙을 위반하면 시스템은 오류를 보여줍니다.
- 이름을 변경하려면 "Define Name" 편집 패널을 다시 열고 이름을 선택하고 편집하고 "OK"를 클릭하십시오.
- 이름을 삭제하려면 "Define Name" 편집 패널에서 선택하고 "Delete"를 클릭하십시오. 이름을 참조하는 공식은 유효하지 않습니다.
- 이름은 동일한 워크북에 있는 다른 워크시트의 맞은편에 공유될 수 있습니다, 그러나 유일한 규칙은 아직도 적용합니다: 다른 워크시트에 동일한 이름을 정의하는 것은 참조에게 주위를 만들 수 있습니다.
- 의미있는 이름을 사용 하 고 매우 짧은 또는 vague 하나를 방지, 그래서 다른 사람들이 이해 하 고 시트를 유지 수 있습니다.
- 정의 된 이름을 사용하는 경우 문제가 발생하면 이름이 정확하고 참조 범위가 정확하며 다른 이름의 충돌이 없습니다.
- 네임은 워크북 레벨 또는 워크시트 레벨에서 설정할 수 있습니다. 워크북 레벨 이름은 특정 워크시트에서만 사용할 수 있는 워크북을 통해 사용할 수 있습니다.

## Facade API

완전한 Facade API 유형 정의는 [Facade API](/reference/facade)에 있습니다.

### 정의된 이름 만들기

`FWorkbook.newDefinedNameBuilder()`는 정의된 이름 빌더를 생성하고 `FDefinedNameBuilder`를 반환합니다. 이름을 생성하는 데 사용되는 `ISetDefinedNameMutationParam` 개체를 생성하는 방법을 체인.

이들은 [`FDefinedNameBuilder`](/reference/facade/defined-name-builder)의 회원 방법 중 일부입니다.

| 메서드 | 설명 |
| ---- | ---- |
| build | 정의된 이름 객체를 빌드합니다 |
| setName | 정의된 이름을 설정합니다 |
| setFormula | 정의된 이름의 수식을 설정합니다 |
| setRef | 정의된 이름의 참조 범위를 설정합니다 |
| setComment | 정의된 이름의 주석을 설정합니다 |
| setScopeToWorksheet | 정의된 이름을 특정 워크시트에서 사용할 수 있도록 설정합니다 |
| setScopeToWorkbook | 정의된 이름을 통합 문서 전체에서 사용할 수 있도록 설정합니다 |

[`FWorkbook.insertDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#insertdefinednamebuilder)는 전체 워크북을 위해 사용할 수있는 정의 된 이름을 만듭니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedNameParam = fWorkbook.newDefinedNameBuilder()
  .setName('MyDefinedName')
  .setRef('Sheet1!$A$1')
  .setComment('A reference to A1 cell in Sheet1')
  .build()
fWorkbook.insertDefinedNameBuilder(definedNameParam)
```

[`FWorkbook.insertDefinedName()`](https://docs.univer.ai/reference/facade/workbook#insertdefinedname)는 이름과 참고가 이미 알려지면 정의 된 이름을 생성하기위한 단축키입니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.insertDefinedName('MyDefinedName', 'Sheet1!$A$1')
```

기타 메서드:
- [`FWorksheet.insertDefinedName()`](https://docs.univer.ai/reference/facade/worksheet#insertdefinedname): 특정 워크시트에서 사용할 수 있는 정의된 이름을 만듭니다.

### 정의된 이름 가져오기

[`FWorkbook.getDefinedName()`](https://docs.univer.ai/reference/facade/workbook#getdefinedname)는 워크북에서 정의된 이름을 얻고 `FDefinedName`를 반환합니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

if (definedName) {
  definedName.setName('NewDefinedName')
}
```

기타 메서드:
- [`FWorkbook.getDefinedNames()`](https://docs.univer.ai/reference/facade/workbook#getdefinednames)는 `FDefinedName[]` 어레이로 워크북에서 모든 정의된 이름을 반환합니다.
- [`FWorksheet.getDefinedNames()`](https://docs.univer.ai/reference/facade/worksheet#getdefinednames)는 `FDefinedName[]` 배열로 이 워크시트에 사용할 수 있는 모든 정의된 이름을 반환합니다.

### 정의된 이름 수정하기

[`FWorkbook.updateDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#updatedefinednamebuilder)는 워크북에 정의된 이름을 지정합니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Modify the defined name
if (definedName) {
  const newDefinedNameParam = definedName.toBuilder()
    .setName('NewDefinedName')
    .setRef('Sheet1!$A$2')
    .build()
  fWorkbook.updateDefinedNameBuilder(newDefinedNameParam)
}
```

반환된 [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name) 인스턴스에서 직접 구성을 변경할 수 있습니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Modify the defined name
if (definedName) {
  definedName.setName('NewDefinedName')
  definedName.setRef('Sheet1!$A$2')
}
```

### 정의된 이름 삭제하기

[`FWorkbook.deleteDefinedName()`](https://docs.univer.ai/reference/facade/workbook#deletedefinedname)는 워크북에서 정의된 이름을 삭제합니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.deleteDefinedName('MyDefinedName')
```

반환된 [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name) 인스턴스를 통해 이름을 삭제할 수 있습니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Delete the defined name
if (definedName) {
  definedName.delete()
}
```
