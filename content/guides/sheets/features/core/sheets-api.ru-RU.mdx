Univer Sheets обеспечивает полный движок электронных таблиц, и его концепции разработаны так, чтобы оставаться как можно ближе к Microsoft Excel.

## Импорт

```typescript
import '@univerjs/sheets/facade'
import '@univerjs/sheets-ui/facade'
```

## Книга

Рабочая тетрадь содержит один или несколько рабочих листов и соответствует файлу Excel.

`unitId` – это уникальный идентификатор книги.

### Создание книги

[`univerAPI.createWorkbook(data, options)`](https://docs.univer.ai/reference/facade/univer#createworkbook) создает рабочую тетрадь и возвращает объект `FWorkbook`.

[`IWorkbookData`](/guides/sheets/model/workbook-data) описывает конфигурацию книги.

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' })
console.log(fWorkbook)
```

Если новая рабочая тетрадь не должна стать активной, передайте объект опций:

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' }, { makeCurrent: false })
console.log(fWorkbook)

// If you want to switch to this workbook after 3 seconds
setTimeout(() => {
  univerAPI.setCurrent(fWorkbook.getId())
}, 3000)
```

### Получение данных книги [#get-workbook-data]

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
console.log(snapshot)
```

### Выгрузка книги

Когда `Workbook` больше не нужен, позвоните в `disposeUnit` на экземпляре API, чтобы разгрузить его.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook?.getId()
if (unitId) {
  univerAPI.disposeUnit(unitId)
}
```

<Callout type="warning">
  Когда страница, на которой размещается экземпляр Univer, уничтожена или маршрут разгружен, позвоните `univer.dispose()` для очистки, а не `univerAPI.disposeUnit`. `univer` и `univerAPI` являются двумя отдельными экземплярами; см. [Установка и базовое использование](/guides/sheets/getting-started/installation) о том, как получить каждый из них.
</Callout>

### Получение идентификатора книги

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook?.getId()
```

## Лист

Рабочие листы хранят данные таблицы, и каждый рабочий лист принадлежит трудовой книжке.

Рабочая тетрадь может содержать несколько рабочих листов, а имена рабочих листов должны быть уникальными в одной рабочей тетради.

`subUnitId` идентифицирует лист уникально в рабочей книге.

### Получение листов

Извлеките все рабочие листы из трудовой книжки:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const sheets = fWorkbook.getSheets()
```

Возврат к активному рабочему листу:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
```

### Получение данных листа

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const sheetSnapshot = fWorksheet.getSheet().getSnapshot()
```

### Создание листа [#create-worksheet]

Следующий пример создает рабочие листы с помощью метода [`FWorkbook.create`](https://docs.univer.ai/reference/facade/workbook#create).

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Create a worksheet named 'Sheet2' with 10 rows and 10 columns
const newSheet = fWorkbook.create('Sheet2', 10, 10)

// Create a new sheet named 'MyNewSheetWithData' with 10 rows and 10 columns and some data, and set it as the first sheet
const sheetData = {
  // ... Omit other properties
  cellData: {
    0: {
      0: {
        v: 'Hello Univer!',
      },
    },
  },
  // ... Omit other properties
}
const newSheetWithData = fWorkbook.create('MyNewSheetWithData', 10, 10, {
  index: 0,
  sheet: sheetData,
})
console.log(newSheetWithData)
```

### Удаление листа

Передайте экземпляр рабочего листа или идентификатор рабочего листа, чтобы удалить рабочий лист.

```typescript
// Delete the second worksheet
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.deleteSheet(sheet)

// The code below deletes the specified worksheet by id
// fWorkbook.deleteSheet(sheet.getSheetId());
```

### Активация листа

Чтобы активировать рабочий лист, передайте экземпляр рабочего листа или идентификатор рабочего листа, или позвоните по методу `FWorksheet.activate()`.

```typescript
// Activate the second worksheet
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.setActiveSheet(sheet)

// Activates the specified worksheet by id
// fWorkbook.setActiveSheet(sheet.getSheetId());

// Activate the worksheet using the FWorksheet.activate() method
// sheet.activate();
```

### Копирование листа

```typescript
// The code below duplicates the given worksheet
const fWorkbook = univerAPI.getActiveWorkbook()
const activeSheet = fWorkbook.getActiveSheet()
const duplicatedSheet = fWorkbook.duplicateSheet(activeSheet)
console.log(duplicatedSheet)
```

### Получение идентификатора листа

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet?.getSheetId()
```

### Цвет вкладки листа [#tab-color]

Нажмите правой кнопкой мыши на вкладку рабочего листа, чтобы открыть его цветовое меню. Выберите цвет, или выберите цвет сброса, чтобы удалить пользовательский цвет и восстановить внешний вид по умолчанию. Цветоискатель показывает текущий цвет рабочего листа. Через Facade API перейдите пустую строку в `setTabColor()`, чтобы сбросить цвет; изменение поддерживает удаление и переделку.

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
sheet?.setTabColor('')
```

### Установка количества строк и столбцов листа

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
// Set row count to 100000
fWorksheet.setRowCount(100000)
// Set column count to 30
fWorksheet.setColumnCount(30)
```

### Обновление листа

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.refreshCanvas()
```

### Масштаб листа

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set zoom ratio to 200%
fWorksheet.zoom(2)
const zoomRatio = fWorksheet.getZoom()
```

### Прокрутка до ячейки

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Scroll to cell D10
const fRange = fWorksheet.getRange('D10')
const row = fRange.getRow()
const column = fRange.getColumn()
fWorksheet.scrollToCell(row, column)

// Add scroll animation duration
fWorksheet.scrollToCell(row, column, 1000)

// Get scroll state
const scrollState = fWorksheet.getScrollState()
const { offsetX, offsetY, sheetViewStartColumn, sheetViewStartRow } = scrollState
console.log(scrollState) // sheetViewStartRow: 9, sheetViewStartColumn: 3, offsetX: 0, offsetY: 0
```
