数字格式决定单元格中数字的显示方式，可以控制小数位数、千位分隔符，也可以把数值显示为百分比或带货币符号的形式，并支持其他显示选项。设置格式之后，数据更易于阅读。

工具栏中的货币操作根据 Univer 的 `region` 确定货币符号和格式。如果未显式配置 `region`，它会跟随 `locale`：

```typescript
const univer = new Univer({
  locale: LocaleType.ZH_CN,
  region: LocaleType.DE_DE,
})
```

<Callout type="warning" title="注意事项">
  不支持 **DBNum** 语法。
</Callout>

## 使用方法 [#usage]

在界面中，可以通过菜单栏设置单元格的数字格式。在代码中，则设置单元格数据 [`ICellData`](/guides/sheets/model/cell-data) 对象的 [`s.n.pattern`](/guides/sheets/model/cell-data#number-format)[^number-format-value] 字段。

```typescript
const data = {
  v: 123456.789,
  s: {
    n: {
      pattern: '#,##0.00',
    },
  },
}
```

**默认情况下，以 0 开头的文本以及可以识别为日期的数字，会自动转换为对应的数字格式。**

如果不希望进行自动转换，可以采用以下两种方式之一：

1. 将单元格的数字格式设置为文本。

```typescript
import { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

const data = {
  v: '012.0',
  s: {
    n: {
      pattern: DEFAULT_TEXT_FORMAT_EXCEL, // 文本格式
    },
  },
}
```

也可以通过 Facade API 设置单元格格式：

```typescript
fRange.setNumberFormat(DEFAULT_TEXT_FORMAT_EXCEL)
```

2. 在数字前输入一个单引号 `'`，这种方式称为[强制文本](/guides/sheets/model/cell-data#cell-type)。

`UniverSheetsNumfmtPlugin` 插件提供 `disableTextFormatAlert` 和 `disableTextFormatMark` 两个配置项，分别关闭单元格文本格式的警告和标记。

根据所采用的接入方式，将这些选项合并到已有的初始化配置中。其他插件、语言、主题、容器配置保持不变，同一个插件不要注册两次。

## 插件配置 [#plugin-configuration]

`UniverSheetsNumfmtPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | 关闭单元格文本格式警告。 |
| `disableTextFormatMark` | `boolean` | `false` | 关闭单元格文本格式标记。 |

```typescript
import { UniverSheetsNumfmtPlugin } from '@univerjs/sheets-numfmt'

univer.registerPlugin(UniverSheetsNumfmtPlugin, {
  disableTextFormatAlert: true,
  disableTextFormatMark: true,
})
```

## 预设配置 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | 关闭单元格文本格式警告。 |
| `disableTextFormatMark` | `boolean` | `false` | 关闭单元格文本格式标记。 |

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import { createUniver } from '@univerjs/presets'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      disableTextFormatAlert: true,
      disableTextFormatMark: true,
    }),
  ],
})
```

## Facade API

### 引入

<Callout type="info" title="插件模式提示">
  插件模式需要单独引入 Facade 包。预设模式已包含对应的 Facade 包，无需额外引入。
</Callout>

```typescript
import '@univerjs/sheets-numfmt/facade'
```

### 设置数字格式

格式代码的具体写法见 https://support.microsoft.com/zh-cn/office/%E6%95%B0%E5%AD%97%E6%A0%BC%E5%BC%8F%E4%BB%A3%E7%A0%81-5026bbd6-04bc-48cd-bf33-80f18b4eae68

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 将 A1 单元格的数字格式设置为 '#,##0.00'
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')
fRange.getDisplayValue() // 1,234.57
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 设置 A1:B2 范围的数字格式
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues([
  [1234.567, 0.1234],
  [45658, 0.9876],
]).setNumberFormats([
  ['#,##0.00', '0.00%'],
  ['yyyy-MM-DD', ''],
])
fRange.getDisplayValues() // [['1,234.57', '12.34%'], ['2025-01-01', 0.9876]]
```

### 获取数字格式

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 获取 A1:B2 范围左上角单元格的数字格式
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormat()
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 获取 A1:B2 范围的数字格式
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormats()
```

### 设置数字格式的区域设置

使用 [`FWorkbook.setNumfmtLocal(local)`](https://docs.univer.ai/reference/facade/workbook#setnumfmtlocal) 设置格式化数字时使用的区域。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')

// 设置数字格式的区域设置为 en
fWorkbook.setNumfmtLocal('en')
fRange.getDisplayValue() // 1,234.57

// 设置数字格式的区域设置为 de
fWorkbook.setNumfmtLocal('de')
fRange.getDisplayValue() // 1.234,57
```

[^number-format-value]: 数字格式只改变显示，不改变存储的数值。例如将 `0.25` 设置为 `0%` 会显示 `25%`，公式仍使用 `0.25` 参与计算。

## 本地化日期预设 [#localized-date-presets]

日期格式面板的预设格式和预览均取自 Univer 当前的 `locale`。已有的自定义日期格式仍然可以选择。切换选区后，面板会刷新，使其控件与当前单元格一致。
