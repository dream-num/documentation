title: Univer Sheets API

Univer Sheets 提供完整的電子表格引擎，其概念設計儘可能與 Microsoft Excel 保持一致。

## 導入

```typescript
import '@univerjs/sheets/facade'
import '@univerjs/sheets-ui/facade'
```

## 工作簿 Workbook

一個工作簿包含一個或多個工作表，相當於一個 Excel 檔案。

`unitId` 是工作簿的唯一標識。

### 建立工作簿

[`univerAPI.createWorkbook(data, options)`](https://docs.univer.ai/reference/facade/univer#createworkbook) 會建立並返回 `FWorkbook` 物件。

[`IWorkbookData`](/guides/sheets/model/workbook-data) 描述工作簿的配置資訊。

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' })
console.log(fWorkbook)
```

如果新建的工作簿不應成為活動工作簿，可以傳入選項物件：

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' }, { makeCurrent: false })
console.log(fWorkbook)

// 3s 後如果想切換到此工作簿
setTimeout(() => {
  univerAPI.setCurrent(fWorkbook.getId())
}, 3000)
```

### 獲取工作簿資料 [#get-workbook-data]

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
console.log(snapshot)
```

### 銷毀工作簿

不再需要某個工作簿時，呼叫 `FUniver` 上的 `disposeUnit` 方法即可將其解除安裝。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook?.getId()
if (unitId) {
  univerAPI.disposeUnit(unitId)
}
```

<Callout type="warning">
  承載 Univer 例項的頁面被銷燬或路由被解除安裝時，應呼叫 `univer.dispose()` 進行清理，而不是呼叫 `univerAPI.disposeUnit`。`univer` 和 `univerAPI` 是兩個不同的例項，如何取得這兩個例項見 [安裝和基本使用](/guides/sheets/getting-started/installation)。
</Callout>

### 獲取工作簿 ID

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook?.getId()
```

## 工作表 Worksheet

工作表用於存放表格資料，每個工作表都屬於一個工作簿。

一個工作簿可以包含多個工作表，同一工作簿中的工作表名稱必須唯一。

`subUnitId` 在工作簿內唯一標識一個工作表。

### 獲取工作表

取得工作簿中的全部工作表：

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const sheets = fWorkbook.getSheets()
```

取得當前啟用的工作表：

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
```

### 獲取工作表資料

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const sheetSnapshot = fWorksheet.getSheet().getSnapshot()
```

### 建立工作表 [#create-worksheet]

下面的範例使用 [`FWorkbook.create`](https://docs.univer.ai/reference/facade/workbook#create) 方法建立工作表。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// 建立一個名為 'Sheet2' 的工作表，包含 10 行和 10 列
const newSheet = fWorkbook.create('Sheet2', 10, 10)

// 建立一個名為 'MyNewSheetWithData' 的新工作表，包含 10 行和 10 列，並帶有一些資料，且將其設置為第一個工作表
const sheetData = {
  // ... 省略其他屬性
  cellData: {
    0: {
      0: {
        v: 'Hello Univer!',
      },
    },
  },
  // ... 省略其他屬性
}
const newSheetWithData = fWorkbook.create('MyNewSheetWithData', 10, 10, {
  index: 0,
  sheet: sheetData,
})
console.log(newSheetWithData)
```

### 刪除工作表

傳入工作表例項或工作表 ID 即可刪除對應的工作表。

```typescript
// 刪除第二個工作表
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.deleteSheet(sheet)

// 下面的程式碼透過 id 刪除指定的工作表
// fWorkbook.deleteSheet(sheet.getSheetId());
```

### 啟用工作表

可以傳入工作表例項或工作表 ID 來啟用工作表，也可以直接呼叫 `FWorksheet.activate()` 方法。

```typescript
// 啟用第二個工作表
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.setActiveSheet(sheet)

// 透過 id 啟用指定的工作表
// fWorkbook.setActiveSheet(sheet.getSheetId());

// 透過 FWorksheet.activate() 方法啟用工作表
// sheet.activate();
```

### 複製工作表

```typescript
// 以下代碼用於複製指定的工作表
const fWorkbook = univerAPI.getActiveWorkbook()
const activeSheet = fWorkbook.getActiveSheet()
const duplicatedSheet = fWorkbook.duplicateSheet(activeSheet)
console.log(duplicatedSheet)
```

### 獲取工作表 ID

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet?.getSheetId()
```

### 工作表標籤色彩 [#tab-color]

右鍵單擊工作表標籤可開啟顏色選單，選擇一種顏色，或選擇“重置顏色”以移除自定義顏色並恢復預設外觀。顏色選擇器顯示當前工作表的顏色。透過 Facade API 重置時，向 `setTabColor()` 傳入空字串；該修改支援撤銷和重做。

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
sheet?.setTabColor('')
```

### 設定工作表行列數

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
// 設定行數為 100000
fWorksheet.setRowCount(100000)
// 設定列數為 30
fWorksheet.setColumnCount(30)
```

### 刷新工作表

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.refreshCanvas()
```

### 工作表縮放

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 200% 設定縮放比例為 200%
fWorksheet.zoom(2)
const zoomRatio = fWorksheet.getZoom()
```

### 捲動到指定位置

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 捲動到 D10 儲存格
const fRange = fWorksheet.getRange('D10')
const row = fRange.getRow()
const column = fRange.getColumn()
fWorksheet.scrollToCell(row, column)

// 新增捲動動畫持續時間
fWorksheet.scrollToCell(row, column, 1000)

// 獲取捲動狀態
const scrollState = fWorksheet.getScrollState()
const { offsetX, offsetY, sheetViewStartColumn, sheetViewStartRow } = scrollState
console.log(scrollState) // sheetViewStartRow: 9, sheetViewStartColumn: 3, offsetX: 0, offsetY: 0
```
