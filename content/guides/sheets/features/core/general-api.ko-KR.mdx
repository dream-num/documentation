Univer에서 사용할 수있는 Facade API는 문서 유형에 따라 다릅니다. 이 페이지는 모든 문서 유형에서 동일한 방식으로 행동하는 일반적인 API를 다룹니다.

## 가져오기

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 개념

### 명령

Univer의 대부분의 작업은 명령 시스템에 등록되어 이를 통해 실행됩니다. 모든 작업은 동일한 경로에 따라 Univer는 undo, redo 및 협업을 지원할 수 있습니다.

<Callout>디자인 합리적 인 경우 [Univer 명령 체계](/blog/univer#command-system)를 참조하십시오.</Callout>

### 명령

Univer의 거의 모든 작업은 명령 시스템에 등록되어 그것을 통해 트리거됩니다. 한 곳에서 모든 작업을 중앙 집중시키는 것은 undo, redo 및 공동 작업과 같은 기능을 만드는 것입니다.

<Callout>
  명령은 Univer 내부의 독특한 "event"로 이해할 수 있습니다. 디자인 세부 사항에 대해서는 [명령 시스템](/blog/univer#command-system)를 참조하십시오.
</Callout>

### 명령 수신

Univer는 명령을 듣는 두 가지 포인트를 제공합니다. 실행하기 전에 실행하고 실행 후.

- `Event.BeforeCommandExecute`는 명령이 실행하기 전에 사용자 정의 논리를 실행합니다.
- `Event.CommandExecuted`는 명령이 실행한 후 사용자 정의 논리를 실행합니다.

#### 실행 전 명령 수신

`Event.BeforeCommandExecute`를 `FUniver.addEvent`로 전달하여 사전 처리 청취자를 등록합니다. 청취자의 코드는 명령이 실행되기 전에 실행됩니다.

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, type, params }) => {
  // Custom logic executed before the command is executed
})
```

실행에서 명령을 방지하려면 `event.cancel`를 호출백에 `true`로 설정하십시오.

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  event.cancel = true
})
```

#### 실행 후 명령 수신

`Event.CommandExecuted`를 `FUniver.addEvent`로 전달하여 포스트 처리 청취를 등록합니다. 명령이 실행된 후 코드가 실행됩니다.

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type, params }) => {
  // Custom logic executed after the command is executed
})
```

### 수신 취소

명령을 등록 청취자는 `IDisposable` 객체를 반환합니다. `IDisposable.dispose`를 호출하여 파괴하십시오.

더 이상 사용되지 않는 파괴적인 청취자. 그들은 안정 프로그램을 유지하는 데 도움이됩니다.

```typescript
const univerAPI = FUniver.newAPI(univer)

// Register a listener
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, () => {
  // custom preprocessing logic before the command is executed
})

// Example: Destroy the listener after 1 second
setTimeout(() => {
  // Destroy the listener
  disposable.dispose()
}, 1000)
```

### 명령 실행

이미 명령 ID와 매개 변수를 알고 있다면, `FUniver.executeCommand`로 명령을 직접 실행할 수 있습니다.

예를 들어, 다음 코드는 `sheet.command.set-range-values` 명령을 사용하여 셀 A1의 값을 설정합니다.

```typescript
const univerAPI = FUniver.newAPI(univer)

// Execute the command
univerAPI.executeCommand('sheet.command.set-range-values', {
  value: { v: 'Hello, Univer!' },
  range: { startRow: 0, startColumn: 0, endRow: 0, endColumn: 0 },
})
```

## 이벤트 API

Univer는 스프레드 시트 내에서 발생하는 변경 사항에 대한 이벤트를 파견하므로 응용 프로그램은 그들과 반응 할 수 있습니다. 이 이벤트는 클립 보드 운영, 선택 변경, 셀 상호 작용, 시트 수정 및 몇 가지 다른 그룹으로 나뉩니다.

### 이벤트 범주

전체 이벤트 목록: /reference/facade/events

1. **클립보드 이벤트**
   - `BeforeClipboardChange`: 클립보드 내용 변화의 앞에 불; 변화를 막기 위하여 `params.cancel = true`를 놓으십시오
   - `BeforeClipboardPaste`: 내용의 앞에 불은 풀립니다; 풀을 막기 위하여 `params.cancel = true`를 놓으십시오
   - `ClipboardChanged`: 새로운 내용과 더불어 클립보드 내용 변화 후에 불
   - `ClipboardPasted`: 내용이 과거의 내용과 더불어 과거의 불

2. **선택 영역 이벤트**
   - `SelectionChanged` : 새로운 선택 범위와 함께 선택 변경 될 때 화재
   - `SelectionMoveStart`: 선택이 움직이는 때 불, 주문 선택 효력을 허용하는
   - `SelectionMoveEnd`: 선택이 움직이는 때 불, 마지막 범위와 더불어
   - `SelectionMoving`: 선택 이동 동안 화재, 이는 라이브 UI 업데이트를 지원
   - `DragOver`: 불 동안 내용이 세포를 떨어뜨리는 동안
   - `Drop` : 드래프트 컨텐츠가 떨어질 때 불

3. **셀 이벤트**
   - `CellClicked`: 세포가 클릭될 때 불, 그것의 위치 및 내용과 더불어
   - `CellHover` : 도구 팁을 지원하는 셀을 통해 포인터가 파괴 될 때 화재
   - `CellPointerDown`: 포인터가 셀에 눌러지면 불; 드래그 또는 선택 시작에 사용
   - `CellPointerUp`: 포인터가 셀에 출시 될 때 화재; 작업 완료에 사용
   - `CellPointerMove`: 포인터가 세포를 넘어갈 때 불

4. **시트 이벤트**
   - `SheetValueChanged`: 시트 값 변경 시 화재, 변경된 범위와 새로운 값
   - `SheetZoomChanged`: 새로운 급상승 비율과 더불어 급상승 수준 변화 때 불
   - `SheetSkeletonChanged`: 시트 구조가 변경 될 때 불, 예를 들어 행 또는 열이 삽입되거나 삭제 될 때
   - `BeforeSheetEditStart` : 셀 편집 시작 전에 화재; 편집이 허용 여부를 제어하는 데 사용
   - `SheetEditStarted` : 셀 편집이 시작될 때 화재; 사용자 정의 편집기 동작에 사용됩니다.
   - `BeforeSheetEditEnd`: 세포 편집 끝의 앞에 불; 내용을 검증하기 위하여 사용해
   - `SheetEditEnded`: 편집된 값과 더불어 세포 편집 끝이 끝날 때 불
   - `SheetEditChanging`: 세포 편집 도중 불; 살아있는 validation 또는 체재를 위해 사용해
   - `Scroll` : 시트 스크롤과 함께 시트 스크롤 할 때 불
   - `CrosshairHighlightEnabledChanged` : 크로스헤드 하이라이트가 활성화되거나 비활성화 될 때 불

5. **헤더 이벤트**
   - `RowHeaderClick`: 행 헤더가 클릭될 때 불
   - `RowHeaderHover`: 점퍼가 행 헤더를 넘어서는 불
   - `ColumnHeaderClick`: 열 헤더가 클릭될 때 불
   - `ColumnHeaderHover`: 기둥 헤더를 통해 포인터가 닿을 때 불

6. **데이터 유효성 검사 이벤트**
   - `BeforeSheetDataValidationAdd`: 데이터 검증 규칙의 앞에 화재가 추가됩니다.
   - `SheetDataValidationChanged`: 데이터 검증 규칙 변경 시 화재
   - `SheetDataValidatorStatusChanged`: 데이터 검증 상태 변경 시 화재

7. **댓글 이벤트**
   - `BeforeCommentAdd`: 코멘트가 추가되기 전에 화재
   - `CommentAdded`: 코멘트가 추가된 후 화재
   - `BeforeCommentUpdate` : 코멘트를 남겨주세요 전에 화재가 업데이트됩니다.
   - `CommentUpdated` : 코멘트가 업데이트 된 후 화재
   - `BeforeCommentDeleted`: 코멘트가 삭제되기 전에 화재
   - `CommentDeleted`: 코멘트가 삭제된 후 화재

8. **데이터 처리 이벤트**
   - `SheetBeforeRangeSort`: 범위의 앞에 불은 분류됩니다
   - `SheetRangeSorted` : 범위가 정렬 된 후 화재
   - `SheetBeforeRangeFilter`: 범위의 앞에 불은 거르는
   - `SheetRangeFiltered`: 범위가 거르는 후에 불
   - `BeforePivotTableAdd`: 피벗 테이블의 앞에 불은 추가됩니다
   - `PivotTableAdded`: 피벗 테이블 후에 불은 추가됩니다

### 이벤트 사용

`univerAPI`에 `addEvent`를 호출하여 청취자를 등록하십시오. 패턴은 모든 이벤트에 동일합니다.

```typescript
univerAPI.addEvent(univerAPI.Event.EventName, (params) => {
  // Handle event parameters
})
```

#### 예시: 셀 클릭 수신

```typescript
univerAPI.addEvent(univerAPI.Event.CellClicked, (params) => {
  const { worksheet, workbook, row, column } = params
  console.log(`Cell clicked at row ${row}, column ${column}`)
})
```

#### 예시: 클립보드 작업 모니터링

```typescript
univerAPI.addEvent(univerAPI.Event.BeforeClipboardPaste, (params) => {
  const { text, html } = params
  // If you want to cancel the clipboard paste
  params.cancel = true
})
```

#### 예시: 선택 영역 변경 추적

```typescript
univerAPI.addEvent(univerAPI.Event.SelectionChanged, (params) => {
  const { worksheet, workbook, selections } = params
  console.log('Selection changed:', selections)
})
```

### 이벤트 리스너 취소

Event listeners는 `IDisposable` 객체를 반환합니다. 더 이상 필요하지 않을 때 청취자를 제거하려면 사용하십시오.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetValueChanged, (params) => {
  // Handle value changes
})

// Later, when you want to remove the listener:
disposable.dispose()
```

### 모범 사례

1. 더 이상 필요로하지 않는 사건 청취자의 처분; 그렇지 않으면 그들은 기억을 새깁니다.
2. 사용 사례를 일치시키는 이벤트를 선택하고 일반 이벤트를 선호합니다.
3. 이벤트 핸들러를 라이트급 선수 유지, 그들은 매번 이벤트 화재를 실행하기 때문에.
4. 기본 동작을 차단하려면 `BeforeClipboardChange` 또는 다른 "before" 이벤트를 사용하십시오.

## 시스템 클립보드

`FUniver.copy()` 및 `FUniver.paste()`는 시스템 클립 보드에 읽고 쓰기.

<Callout>
  브라우저의 네이티브 API에 복사 및 붙여넣기. 환경이나 권한이 허용되지 않는 경우, 작동이 작동하지 않습니다. [MDN 문서](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/writeText)를 참조하십시오.
</Callout>

다음 예제 복사 및 시트 범위를 붙여 넣기.

```typescript
// Prevent failure due to loss of focus when executing copy and paste code in the console,
// this example listens for the cell click event and executes the copy and paste code.
univerAPI.addEvent(univerAPI.Event.CellClicked, async (params) => {
  const fWorkbook = univerAPI.getActiveWorkbook()
  const fWorksheet = fWorkbook.getActiveSheet()

  // Copy the range A1:B2 to the clipboard
  const fRange = fWorksheet.getRange('A1:B2')
  fRange.activate().setValues([
    [1, 2],
    [3, 4],
  ])
  await univerAPI.copy()

  // Paste the copied content to the range C1:D2
  const fRange2 = fWorksheet.getRange('C1')
  fRange2.activate()
  await univerAPI.paste()

  // Check the pasted content
  console.log(fWorksheet.getRange('C1:D2').getValues()) // [[1, 2], [3, 4]]
})
```

클립보드 명령은 명령 시스템을 통해 실행할 수 있습니다:

```typescript
import { CopyCommand, PasteCommand } from '@univerjs/ui'

// Copy
univerAPI.executeCommand(CopyCommand.id)
// Paste
univerAPI.executeCommand(PasteCommand.id)
```

## WebSocket

Facade API는 `createSocket`를 제공합니다. URL을 주면 WebSocket 연결을 엽니다. 연결은 오픈, 메시지, 닫기 및 오류 이벤트를 노출합니다. 메시지는 `send` 메소드로 전송되며 연결은 `close` 메서드로 닫힙니다.

미리 설치에서, `univerAPI.createSocket(url)`는 직접 호출될 수 있습니다. 조각 임명에서는, [`@univerjs/network`](/reference/packages/plugins/univerjs/network) 포장을 설치하고 `UniverNetworkPlugin`를 등록하십시오.

```typescript
// ... Omits other plugin imports
import { UniverNetworkPlugin } from '@univerjs/network'

// ... Omits other facade imports
import '@univerjs/network/facade'

// ... Omits other plugin registrations
univer.registerPlugin(UniverNetworkPlugin)
```

다음은 최소 예입니다.

```typescript
// Replace the URL with the address of your own WebSocket service
const ws = univerAPI.createSocket('ws://47.100.177.253:8449/ws')

ws.open$.subscribe(() => {
  console.log('websocket opened')
  ws.send('hello')
})

ws.message$.subscribe((message) => {
  console.log('websocket message', message)
  const content = JSON.parse(message.data).content
  if (!content.includes('command')) {
    return
  }

  const commandInfo = JSON.parse(content)
  const { command, options } = commandInfo
  const { id, params } = command

  // Upon receiving collaborative data, it is locally saved
  univerAPI.executeCommand(id, params, options)
})

ws.close$.subscribe(() => {
  console.log('websocket closed')
})

ws.error$.subscribe((error) => {
  console.log('websocket error', error)
})

univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type, params, options }) => {
  // Only synchronize local mutations
  if (
    type !== univerAPI.Enum.CommandType.MUTATION ||
    options?.fromCollab ||
    options?.onlyLocal ||
    id === 'doc.mutation.rich-text-editing'
  ) {
    return
  }

  const commandInfo = JSON.stringify({ command: { id, type, params }, options: { fromCollab: true } })
  ws.send(commandInfo)
})
```

Univer는 UnitID로 시작해야 합니다; 협력은 아무도 없이 작동하지 않습니다.

## 수식 등록

Facade API를 통해 현재 Univer 인스턴스에 등록할 수 있습니다.

다음 예제는 [`registerFunction`](https://docs.univer.ai/reference/facade/formula#registerfunction)를 호출하여 알고리즘, 이름 및 `CUSTOMSUM` 공식이 공식 플러그인에 필요합니다. 공식은 다음을 사용할 수 있습니다 : 공백 셀에 `=CUSTOMSUM`을 입력하면 프롬프트를 표시합니다.

```typescript
// Registered formulas support lambda functions
const formulaEngine = univerAPI.getFormula()
formulaEngine.registerFunction(
  'CUSTOMSUM',
  (...variants) => {
    let sum = 0
    const last = variants[variants.length - 1]

    if (last.isLambda && last.isLambda()) {
      variants.pop()
      const variantsList = variants.map((variant) => (Array.isArray(variant) ? variant[0][0] : variant))
      sum += last.executeCustom(...variantsList).getValue()
    }

    for (const variant of variants) {
      sum += Number(variant) || 0
    }

    return sum
  },
  'Adds its arguments',
)

// Use the function in a cell
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const cellA1 = fWorksheet.getRange('A1')
cellA1.setValue(1)
const cellA2 = fWorksheet.getRange('A2')
cellA2.setValue(2)
const cellA3 = fWorksheet.getRange('A3')
cellA3.setValue({ f: '=CUSTOMSUM(A1,A2,LAMBDA(x,y,x*y))' })

// A3 will display: 5
formulaEngine.calculationEnd((functionsExecutedState) => {
  if (functionsExecutedState === 3) {
    console.log(cellA3.getValue()) // 5
  }
})
```

`dispose`를 호출하여 공식을 등록하십시오.

```typescript
const functionDisposable = formulaEngine.registerFunction({
  // calculate
})

// Unregister the function
functionDisposable.dispose()
```

더 완전한 국제화된 내용 및 설명을 제공하기 위하여는, `locales`와 `description` 분야를 뿐 아니라 놓습니다:

```typescript
formulaEngine.registerFunction(
  'CUSTOMSUM',
  (...variants) => {
    let sum = 0
    const last = variants[variants.length - 1]

    if (last.isLambda && last.isLambda()) {
      variants.pop()
      const variantsList = variants.map((variant) => (Array.isArray(variant) ? variant[0][0] : variant))
      sum += last.executeCustom(...variantsList).getValue()
    }

    for (const variant of variants) {
      sum += Number(variant) || 0
    }

    return sum
  },
  {
    description: {
      functionName: 'CUSTOMSUM',
      description: 'formulaCustom.CUSTOMSUM.description',
      abstract: 'formulaCustom.CUSTOMSUM.abstract',
      functionParameter: [
        {
          name: 'formulaCustom.CUSTOMSUM.functionParameter.number1.name',
          detail: 'formulaCustom.CUSTOMSUM.functionParameter.number1.detail',
          example: 'A1:A20',
          require: 1,
          repeat: 0,
        },
        {
          name: 'formulaCustom.CUSTOMSUM.functionParameter.number2.name',
          detail: 'formulaCustom.CUSTOMSUM.functionParameter.number2.detail',
          example: 'B2:B10',
          require: 0,
          repeat: 1,
        },
      ],
    },
    locales: {
      zhCN: {
        formulaCustom: {
          CUSTOMSUM: {
            description: '将单个值、单元格引用或是区域相加，或者将三者的组合相加。',
            abstract: '求参数的和',
            functionParameter: {
              number1: {
```

옵션은 아래에 설명되어 있습니다.

- `func`는 알고리즘을 보유하고 있으며 공식에 대한 이름 매핑을 보유하고 있습니다. 입력은 숫자, 문자열, Boolean 값 또는 배열이 될 수있는 공식을 사용할 때 사용자가 입력하는 것입니다.
- `description`은 사용자 지정 수식의 설명을 설정합니다.
- `locales`는 몇몇 언어를 붙들 수 있습니다; naming 규칙은 [언어 선택](/reference/enums/locale-type)에서 설명됩니다. `functionList`에는 1개의 공식을 위한 번역을 붙들 수 있었습니다. 분야 세부사항을 위해, [공식 엔진에서 공식을 추가하는 방법](/blog/custom-formula#how-to-add-formulas-in-formula-engine) 단면도를 보십시오.

<Callout>
  공식 시스템이 이미 제공하는 알고리즘을 재사용하고 확장하려면 플러그인 구성을 통해 사용자 정의 공식을 등록하십시오. Walkthrough를 위해 [공급 능력](/blog/custom-formula)를 참조하십시오.
</Callout>

## 열거형 API

Facade API는 개발 중에 사용되는 enum 유형이 포함되어 있습니다. 예를 들어:

```typescript
console.log(univerAPI.Enum)
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_SHEET)
console.log(univerAPI.Enum.LifecycleStages.Rendered)
```

## 유틸리티 메서드 API

Facade API는 다음과 같은 유틸리티 방법 세트를 포함합니다.

```typescript
console.log(univerAPI.Util)
console.log(univerAPI.Util.tools.chatAtABC(10))
console.log(univerAPI.Util.tools.ABCatNum('K'))
```
