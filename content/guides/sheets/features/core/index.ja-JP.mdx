Univerシートのコアは、スプレッドシートエディタとエディタが必要とするコンポーネントで構成されています:フォーミュラエンジン、レンダリングエンジン、数フォーマットエンジン、設計システム、UIコンポーネントライブラリ。これらのコンポーネントは、幅広いスプレッドシートフォーマットと実際のワークブックが関与する複雑な操作をサポートしています。

## 機能一覧

コア機能セットカバー:

- **スプレッドシートレンダリング**:シートのコンテンツ、カーソル、および選択を引く。
- **セルスタイリング**: 細胞にフォント、色、境界、アライメントを設定します。
- **式計算**:数学、統計的、テキスト、日付機能を含むほぼすべてのExcel機能のサポートで、式を追加および計算します。
- **数値フォーマット**: 値に通貨、パーセンテージ、日付、およびその他の番号フォーマットを適用します。
- **グリッドと冷凍パン**:大きなデータセットを簡単に読み、編集するグリッドと冷凍パンを表示します。
- **デフォルトスタイル**: スプレッドシートのデフォルトフォント、サイズ、色、その他のスタイルを設定します。
- **プラグインシステム**: 式、イメージ、チャートプラグインなどのカスタムプラグインの追加を許可します。 プラグインシステムは、Univerのコアアーキテクチャ機能の1つです。

## プラグインモード

### インストール

```package-install
npm install @univerjs/core @univerjs/design @univerjs/engine-render @univerjs/engine-formula @univerjs/ui @univerjs/docs @univerjs/docs-ui @univerjs/sheets @univerjs/sheets-ui @univerjs/sheets-formula @univerjs/sheets-formula-ui @univerjs/sheets-numfmt @univerjs/sheets-numfmt-ui
```

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/sheets/getting-started/installation#mobile-support)を最初に構成します。このページのプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換え、**ドキュメントを開く前に**を実行します。モデルプラグイン、スタイル、ロケール、ファサードのインポートを保持し、両方のバリアントを登録しません。

| パッケージ | デスクトップの登録 | モバイルの登録 |

## ツールバーレイアウトと `RibbonType`

`IUniverSheetsCorePresetConfig`または`IUniverUIConfig`で`ribbonType`を設定し、ツールバーのレイアウトを選択します。

4つのモードがあります:

- `classic`: デフォルトのレイアウト。グループでは、上列とツールバーが実行され、従来のレイアウトのどのユーザーが期待しているかにマッチします。
- `grid`: タブを保ち、各グループのツールを2列グリッドで配置します。デスクトップレイアウトに適しており、複数のツールを一度に表示できます。
- `collapsed`: グループとツールバーを同じ行に配置し、それが限られているとき、垂直スペースを節約します。
- `simple`:グループ化を解除し、すべてのツールを単一のフラットリストに配置します。, 既に各ボタンが何を知っているユーザーのために.

`grid`のリボンが不十分な幅を持っているとき、グループ全体が**もっと詳しく**に移動し、その制御はコンパクトなレイアウトに切り替えます。 コンテナが広まったときに戻ります。 これにより、利用可能な幅が自動的に続くため、メインリボンの既存の`gridLayout`を維持します。 オーバーフローメニューは、同じコマンド、無効な状態、およびパーミッションチェックを保持します。

## メニューの順序とグリッド配置 [#menu-order-and-grid-layout]

`menu`のキーは、`ribbon.start.format`などのグループである`ribbon.insert`、またはメニュー項目IDなどのリボンタブになります。

`order`は、リボン内のタブ、タブ内のグループ、およびグループまたはサブメニュー内のアイテムのタブから、低から高:タブから高まで兄弟をソートします。メニュー項目を別のグループに移動しません。文字列キーの代わりに、`RibbonPosition`と`@univerjs/ui`によってエクスポートされたグループ列を使用できます。

これらのオプションを現在のモードの既存の初期化にマージします。他のプラグイン、ロケール、テーマ、コンテナの設定を保ち、同じプラグインを2回登録しないでください。

```ts
import type { MenuConfig } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.insert': { order: -1 },
  'ribbon.start.format': { order: -1 },
  'sheet.command.set-range-font-family': {
    order: 0,
    gridLayout: { row: 1, column: 1, width: 160 },
  },
}
```

## 選択とドラッグ [#selection-interaction]

### シート端でのキーボード移動 [#keyboard-navigation]

`allowArrowKeyWrapOnSheetBoundary`は、矢印キーがワークシートエッジの次の行または列にラップするかどうかを決定します。 `true`にデフォルトで設定します。 `false`に設定して、エッジで停止します。 選択した範囲内の入力/タブのサイクリングは影響を受けません。 プリセットモードでは、`sheets`で設定します; プラグインモードでは、直接`UniverSheetsUIPlugin`を通過します。

`selectionAnimation: false`は、選択がセル間で移動したときに選択アウトラインアニメーションを無効にします。システム減少感情の優先順位は優先されます。`enableFillHandle: false`は、コマンドとファサードAPIを埋めながら、充填ハンドルを非表示にします。`warnBeforeDragOverwrite: false`は、既存のコンテンツを上書きする前に確認プロンプトをスキップします。検証を移動し、まだ削除します。すべての3つのオプションは`true`にデフォルトです。`UniverSheetsCorePreset`で`sheets`の下にそれらを渡すか、`UniverSheetsUIPlugin`に直接渡します。

## Facade API でメニューを更新する [#menu-facade]

### 実行時の更新

パブリックファサードは変更をマージし、すぐにUIをリフレッシュします。省略されたプロパティは、以前の値またはスキーマのデフォルトを保持し、オーバーライドは後で登録されたメニューにも適用されます。プラグインモードでは、`@univerjs/ui/facade`を最初にインポートします。

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'sheet.command.set-range-bold': {
    order: 0,
    gridLayout: { row: 2, column: 2 },
  },
  'sheet.command.set-range-italic': {
    gridLayout: { row: 2, column: 1 },
  },
})
```

`gridLayout`は`ribbonType: 'grid'`でのみ効果があります。各グループには2つの行があり、`row`と`column`は1で始まります。座標は明示的であるため、`order`のみの変更は明示的に配置されたボタンを移動しません。2つのボタンが交換されると、両方が更新されなければならない、または重複する必要があります。オプションのフィールドは`rowSpan`、`columnSpan`、`showLabel`、`width`、および`iconSize`で、ピクセルのサイズ。[`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout)は制約とデフォルトをリストします。

### カスタムメニューの配置

`createMenu()`と`createSubmenu()`は`order`および`gridLayout`も受け入れます。サブメニューでは、これらのフィールドはポップアップのコンテンツではなくリボントリガーを配置します。次の例では、履歴グループの3番目の列にボタンを追加します。

```ts
univerAPI
  .createMenu({
    id: 'custom-action',
    title: 'Custom action',
    action: () => console.log('Custom action clicked'),
    order: 4,
    gridLayout: { row: 1, column: 3, showLabel: true, width: 96 },
  })
  .appendTo('ribbon.start.history')
```
