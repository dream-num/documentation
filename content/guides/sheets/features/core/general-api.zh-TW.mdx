在 Univer 中，可呼叫的 Facade API 取決於文件型別。本頁介紹所有文件型別都通用的 Facade API。

## 導入

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 概念

### 命令

Univer 中的大部分操作都註冊在命令系統上，並由命令系統觸發。所有操作經由同一條路徑，因此撤銷、重做和協同等功能得以實現。

<Callout>設計細節參見 [Univer 命令系統](/blog/univer#command-system)。</Callout>

## 命令系統

Univer 中的幾乎所有操作都註冊在命令系統上，並透過命令系統觸發。將所有操作集中於一處，是實現撤銷、重做和協同等功能的前提。

Univer 只有這一套命令系統，各類定製功能都基於它實現。

<Callout>
  每個命令對應一個唯一的 ID。查詢具體命令 ID 的方法參見 [如何查詢命令 ID](/blog/find-the-command-id)。
</Callout>

### 監聽命令

Univer 提供兩個時機監聽命令：執行前與執行後。

- `Event.BeforeCommandExecute`：在命令執行前執行自訂邏輯。
- `Event.CommandExecuted`：在命令執行後執行自訂邏輯。

#### 監聽命令執行前

將 `Event.BeforeCommandExecute` 傳給 `FUniver.addEvent`，即可註冊預處理監聽器。監聽器中的邏輯會在命令執行前執行。

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, type, params }) => {
  // 在命令執行前執行自訂邏輯
})
```

如需阻止命令執行，可在監聽器中將 `event.cancel` 設為 `true`。

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  event.cancel = true
})
```

#### 監聽命令執行後

將 `Event.CommandExecuted` 傳給 `FUniver.addEvent`，即可註冊後處理監聽器。命令執行完畢後，監聽器中的邏輯再執行。

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type, params }) => {
  // 在命令執行後執行自訂邏輯
})
```

### 取消監聽

註冊命令監聽器的方法返回一個 `IDisposable` 物件，呼叫 `IDisposable.dispose` 即可銷燬。

不再使用的監聽器應及時銷燬，以保持程式穩定。

```typescript
const univerAPI = FUniver.newAPI(univer)

// 註冊監聽器
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, () => {
  // 在命令執行前執行自訂邏輯
})

// 示例：1 秒後取消監聽
setTimeout(() => {
  // 取消監聽
  disposable.dispose()
}, 1000)
```

### 執行命令

如果已知命令 ID 和所需參數，也可以直接使用 `FUniver.executeCommand` 執行命令。

例如，使用 `sheet.command.set-range-values` 設定 A1 單元格的值：

```typescript
const univerAPI = FUniver.newAPI(univer)

// 執行命令
univerAPI.executeCommand('sheet.command.set-range-values', {
  value: { v: 'Hello, Univer!' },
  range: { startRow: 0, startColumn: 0, endRow: 0, endColumn: 0 },
})
```

## 事件系統

Univer 的事件系統覆蓋電子表格中的各類變化，可供監聽和響應。事件大致分為剪貼簿操作、選區變化、單元格互動、表格修改等幾類。

### 事件類別

完整事件列表見：/reference/facade/events#%E5%B1%9E%E6%80%A7

1. **剪貼板事件**
   - `BeforeClipboardChange`：在剪貼簿內容改變前觸發，設定 `params.cancel = true` 可阻止該改變
   - `BeforeClipboardPaste`：在貼上內容前觸發，設定 `params.cancel = true` 可阻止貼上
   - `ClipboardChanged`：在剪貼簿內容改變後觸發，可取得新的剪貼簿內容
   - `ClipboardPasted`：在內容貼上後觸發，可取得貼上的內容

2. **選區事件**
   - `SelectionChanged`：在選區改變時觸發，給出新的選區範圍
   - `SelectionMoveStart`：在選區開始移動時觸發，可用於實現自定義選區效果
   - `SelectionMoveEnd`：在選區結束移動時觸發，給出最終的選區範圍
   - `SelectionMoving`：在選區移動過程中觸發，可用於即時更新 UI
   - `DragOver`：在拖動經過單元格時觸發
   - `Drop`：在放下拖動的選區內容時觸發

3. **儲存格事件**
   - `CellClicked`：在單元格被點選時觸發，給出單元格的位置和內容
   - `CellHover`：在滑鼠懸停於單元格上時觸發，可用於顯示提示資訊
   - `CellPointerDown`：在指標於單元格上按下時觸發，用於開始拖動或選擇
   - `CellPointerUp`：在指標於單元格上抬起時觸發，用於結束操作
   - `CellPointerMove`：在指標於單元格上移動時觸發

4. **表格事件**
   - `SheetValueChanged`：在表格的值改變時觸發，給出變更的範圍和新值
   - `SheetZoomChanged`：在縮放級別改變時觸發，給出新的縮放比例
   - `SheetSkeletonChanged`：在表格結構改變時觸發，例如插入或刪除行列
   - `BeforeSheetEditStart`：在單元格開始編輯前觸發，可用於控制是否允許編輯
   - `SheetEditStarted`：在單元格開始編輯時觸發，可用於實現自定義編輯器行為
   - `BeforeSheetEditEnd`：在單元格結束編輯前觸發，可用於校驗內容
   - `SheetEditEnded`：在單元格結束編輯時觸發，給出編輯後的值
   - `SheetEditChanging`：在單元格編輯過程中觸發，可用於即時校驗或格式化
   - `Scroll`：在表格滾動時觸發，給出滾動位置
   - `CrosshairHighlightEnabledChanged`：在十字游標高亮開啟或關閉時觸發

5. **表頭事件**
   - `RowHeaderClick`：在行表頭被點選時觸發
   - `RowHeaderHover`：在滑鼠懸停於行表頭上時觸發
   - `ColumnHeaderClick`：在列表頭被點選時觸發
   - `ColumnHeaderHover`：在滑鼠懸停於列表頭上時觸發

6. **資料驗證事件**
   - `BeforeSheetDataValidationAdd`：在新增資料驗證規則前觸發
   - `SheetDataValidationChanged`：在資料驗證規則改變時觸發
   - `SheetDataValidatorStatusChanged`：在資料驗證狀態改變時觸發

7. **評論事件**
   - `BeforeCommentAdd`：在新增評論前觸發
   - `CommentAdded`：在評論新增後觸發
   - `BeforeCommentUpdate`：在更新評論前觸發
   - `CommentUpdated`：在評論更新後觸發
   - `BeforeCommentDeleted`：在刪除評論前觸發
   - `CommentDeleted`：在評論刪除後觸發

8. **資料處理事件**
   - `SheetBeforeRangeSort`：在範圍排序前觸發
   - `SheetRangeSorted`：在範圍排序後觸發
   - `SheetBeforeRangeFilter`：在範圍篩選前觸發
   - `SheetRangeFiltered`：在範圍篩選後觸發
   - `BeforePivotTableAdd`：在新增資料透視表前觸發
   - `PivotTableAdded`：在資料透視表新增後觸發

### 使用事件

監聽事件使用 `univerAPI` 的 `addEvent` 方法，寫法一致：

```typescript
univerAPI.addEvent(univerAPI.Event.事件名稱, (params) => {
  // 處理事件參數
})
```

#### 示例：監聽儲存格點擊

```typescript
univerAPI.addEvent(univerAPI.Event.CellClicked, (params) => {
  const { worksheet, workbook, row, column } = params
  console.log(`儲存格被點擊，行：${row}，列：${column}`)
})
```

#### 示例：監控剪貼板操作

```typescript
univerAPI.addEvent(univerAPI.Event.BeforeClipboardPaste, (params) => {
  const { text, html } = params
  // 如果要取消貼上操作
  params.cancel = true
})
```

#### 示例：追蹤選區變化

```typescript
univerAPI.addEvent(univerAPI.Event.SelectionChanged, (params) => {
  const { worksheet, workbook, selections } = params
  console.log('選區已改變:', selections)
})
```

### 取消事件監聽

事件監聽器返回一個 `IDisposable` 物件，不再需要時可用它移除監聽器：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetValueChanged, (params) => {
  // 處理值變化
})

// 之後，當你想要移除監聽器時：
disposable.dispose()
```

### 最佳實踐

1. 不再需要的監聽器應及時銷燬，否則會造成記憶體洩漏。
2. 根據場景選擇最合適的事件，優先使用具體事件而非通用事件。
3. 事件處理函式應保持輕量，因為事件每次觸發都會執行它。
4. 需要阻止預設行為時，使用 `BeforeClipboardChange` 等前置事件。

## 系統剪貼板

使用 [`FUniver.copy()`](https://docs.univer.ai/reference/facade/univer#copy) 和 [`FUniver.paste()`](https://docs.univer.ai/reference/facade/univer#paste) 讀寫系統剪貼簿。

<Callout>
  複製和貼上依賴瀏覽器原生 API，[環境條件或權限](https://developer.mozilla.org/zh-CN/docs/Web/API/Clipboard/writeText)不滿足時無法使用。
</Callout>

以下範例演示覆制和貼上 Sheet 區域。

```typescript
// 防止在控制台中執行複製貼上程式碼時因失去焦點而失敗，
// 此示例監聽儲存格點擊事件並執行複製貼上程式碼。
univerAPI.addEvent(univerAPI.Event.CellClicked, async (params) => {
  const fWorkbook = univerAPI.getActiveWorkbook()
  const fWorksheet = fWorkbook.getActiveSheet()

  // 將範圍 A1:B2 複製到剪貼板
  const fRange = fWorksheet.getRange('A1:B2')
  fRange.activate().setValues([
    [1, 2],
    [3, 4],
  ])
  await univerAPI.copy()

  // 將複製的內容貼到範圍 C1:D2
  const fRange2 = fWorksheet.getRange('C1')
  fRange2.activate()
  await univerAPI.paste()

  // 檢查貼上的內容
  console.log(fWorksheet.getRange('C1:D2').getValues()) // [[1, 2], [3, 4]]
})
```

剪貼簿操作也可以透過[命令系統](#命令系統)執行：

```typescript
import { CopyCommand, PasteCommand } from '@univerjs/ui'

// 複製
univerAPI.executeCommand(CopyCommand.id)
// 貼上
univerAPI.executeCommand(PasteCommand.id)
```

## WebSocket

Facade API 透過 `createSocket` 建立 WebSocket，傳入 URL 即可建立連線。之後可監聽 open、message、close、error 事件，也可用 send 方法主動傳送訊息、用 close 方法主動斷開連線。

使用 Presets 安裝時，可直接呼叫 `univerAPI.createSocket(url)`。使用手動組合安裝時，需先安裝 [`@univerjs/network`](/reference/packages/plugins/univerjs/network) 依賴包，再註冊 `UniverNetworkPlugin` 外掛。

```typescript
// ... 省略其他插件引入
import { UniverNetworkPlugin } from '@univerjs/network'

// ... 省略其他 facade 引入
import '@univerjs/network/facade'

// ... 省略其他插件註冊
univer.registerPlugin(UniverNetworkPlugin)
```

以下是一個簡單範例：

```typescript
// URL 換成你自己 WebSocket 服務的地址
const ws = univerAPI.createSocket('ws://47.100.177.253:8449/ws')

ws.open$.subscribe(() => {
  console.log('websocket opened')
  ws.send('hello')
})

ws.message$.subscribe((message) => {
  console.log('websocket message', message)
  const content = JSON.parse(message.data).content
  if (!content.includes('command')) {
    return
  }

  const commandInfo = JSON.parse(content)
  const { command, options } = commandInfo
  const { id, params } = command

  // 接收到協同數據，本地落盤
  univerAPI.executeCommand(id, params, options)
})

ws.close$.subscribe(() => {
  console.log('websocket closed')
})

ws.error$.subscribe((error) => {
  console.log('websocket error', error)
})

univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type, params, options }) => {
  // 僅同步本地 mutation
  if (
    type !== univerAPI.Enum.CommandType.MUTATION ||
    options?.fromCollab ||
    options?.onlyLocal ||
    id === 'doc.mutation.rich-text-editing'
  ) {
    return
  }

  const commandInfo = JSON.stringify({ command: { id, type, params }, options: { fromCollab: true } })
  ws.send(commandInfo)
})
```

啟動 Univer 時必須指定 unitID，否則無法協同。

## 註冊公式

透過 Facade API 可在當前 Univer 例項中註冊自定義公式。

以下範例呼叫 [`registerFunction`](https://docs.univer.ai/reference/facade/formula#registerfunction) 一次，將 `CUSTOMSUM` 公式所需的演算法、名稱和描述註冊到公式外掛中，之後該公式即可使用。在任一空白單元格輸入 `=CUSTOMSUM`，即可看到提示。

```typescript
// 註冊公式支援 lambda 函數
const formulaEngine = univerAPI.getFormula()
formulaEngine.registerFunction(
  'CUSTOMSUM',
  (...variants) => {
    let sum = 0
    const last = variants[variants.length - 1]

    if (last.isLambda && last.isLambda()) {
      variants.pop()
      const variantsList = variants.map((variant) => (Array.isArray(variant) ? variant[0][0] : variant))
      sum += last.executeCustom(...variantsList).getValue()
    }

    for (const variant of variants) {
      sum += Number(variant) || 0
    }

    return sum
  },
  '求參數的和',
)

// Use the function in a cell
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const cellA1 = fWorksheet.getRange('A1')
cellA1.setValue(1)
const cellA2 = fWorksheet.getRange('A2')
cellA2.setValue(2)
const cellA3 = fWorksheet.getRange('A3')
cellA3.setValue({ f: '=CUSTOMSUM(A1,A2,LAMBDA(x,y,x*y))' })

// A3 will display: 5
formulaEngine.calculationEnd((functionsExecutedState) => {
  if (functionsExecutedState === 3) {
    console.log(cellA3.getValue()) // 5
  }
})
```

呼叫 `dispose` 方法可解除安裝已註冊的公式。

```typescript
const functionDisposable =
  formulaEngine.registerFunction(
    // calculate
  )

// 卸載所註冊的公式
functionDisposable.dispose()
```

如需更完整的國際化內容和描述，還可配置 `locales` 和 `description` 欄位，如下所示。

```typescript
    },

          CUSTOMSUM: {

              },

```

各欄位說明如下：

- `func` 指定公式的演算法和名稱對映。其入參是使用者使用公式時輸入的內容，可以是數字、字串、布林值或陣列。
- `description` 設定自訂公式的描述。
- `locales` 下可配置多種語言，命名規則參見 [LocaleType](/reference/enums/locale-type)。多個公式的翻譯可放在 `functionList` 下。欄位的詳細說明參見 [如何在 Formula Engine 中新增公式](/blog/custom-formula#how-to-add-formulas-in-formula-engine)。

<Callout>
  如需複用公式系統已有的演算法並在其基礎上擴充套件公式能力，可透過外掛配置註冊自定義公式。詳細教程參見 [自定義公式](/blog/custom-formula/)。
</Callout>
