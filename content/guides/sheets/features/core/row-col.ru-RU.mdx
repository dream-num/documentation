## Facade API

Полные определения типов Facade API доступны в [справочнике Facade API](https://reference.univer.ai/en-US).

### Строки

#### Вставка строки после заданной позиции

[`insertRowAfter(afterPosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowafter): вставляет строку после заданной позиции строки.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row after the first row position
sheet.insertRowAfter(0)
```

#### Вставка строки перед заданной позицией

[`insertRowBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowbefore): вставляет строку перед заданной позицией строки.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row before the first row position
sheet.insertRowBefore(0)
```

#### Вставка нескольких строк в заданной позиции

[`insertRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#insertrows): вставляет на листе одну или несколько последовательных пустых строк, начиная с заданной позиции.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Shifts all rows down by three
sheet.insertRows(0, 3)
```

#### Вставка нескольких строк после заданной позиции

[`insertRowsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsafter): вставляет указанное количество строк после заданной позиции строки.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows after the first row
sheet.insertRowsAfter(0, 5)
```

#### Вставка нескольких строк перед заданной позицией

[`insertRowsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsbefore): вставляет указанное количество строк перед заданной позицией строки.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows before the first row
sheet.insertRowsBefore(0, 5)
```

#### Удаление строки в заданной позиции

[`deleteRow(rowPosition)`](https://docs.univer.ai/reference/facade/worksheet#deleterow): удаляет строку в заданной позиции.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first row
sheet.deleteRow(0)
```

#### Удаление нескольких строк, начиная с заданной позиции

[`deleteRows(rowPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deleterows): удаляет указанное количество строк, начиная с заданной позиции.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first two rows
sheet.deleteRows(0, 2)
```

#### Удаление нескольких строк в заданных позициях

[`deleteRowsByPoints(rowPoints)`](https://docs.univer.ai/reference/facade/worksheet#deleterowsbypoints): удаляет несколько строк, не обязательно последовательных, заданных массивом позиций.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the 3rd row and rows 5 to 7
fWorksheet.deleteRowsByPoints([2, [4, 6]])
```

#### Перемещение строк в новую позицию

[`moveRows(rowSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#moverows): перемещает строки, выбранные заданным диапазоном, в позицию с индексом `destinationIndex`. Диапазон `rowSpec` не обязан в точности представлять целую строку или группу строк: метод выбирает все строки, которые охватывает диапазон.

```typescript
// The code below moves rows 1-2 to destination index 5
// This results in those rows becoming rows 3-4
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Selects row 1 and row 2 to be moved
const rowSpec = sheet.getRange('1:2')
sheet.moveRows(rowSpec, 5)
```

#### Скрытие строк в заданном диапазоне

[`hideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#hiderow): скрывает строки в заданном диапазоне.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This hides the first row
const range = sheet.getRange('1:1')
sheet.hideRow(range)
```

#### Скрытие нескольких последовательных строк

[`hideRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#hiderows): скрывает одну или несколько последовательных строк, начиная с заданного индекса. В этом методе используется индексация с нуля.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Hides the first three rows
sheet.hideRows(0, 3)
```

#### Отображение строки в заданном диапазоне

[`unhideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#unhiderow): отображает скрытую строку в заданном диапазоне.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This unhides the first row if it was previously hidden
const range = sheet.getRange('1:1')
sheet.unhideRow(range)
```

#### Отображение нескольких последовательных строк

[`showRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#showrows): отображает одну или несколько последовательных скрытых строк, начиная с заданного индекса. В этом методе используется индексация с нуля.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Unhides the first three rows
sheet.showRows(0, 3)
```

#### Установка высоты строки

[`setRowHeight(rowPosition, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheight): задаёт высоту строки в пикселях. По умолчанию высота строк увеличивается под содержимое ячеек. Чтобы принудительно задать определённую высоту, используйте `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first row to a height of 200 pixels
sheet.setRowHeight(0, 200)
```

#### Установка высоты нескольких строк

[`setRowHeights(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheights): задаёт высоту указанных строк в пикселях. По умолчанию высота строк увеличивается под содержимое ячеек. Чтобы принудительно задать определённую высоту, используйте `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 200 pixels
sheet.setRowHeights(0, 3, 200)
```

#### Принудительная установка высоты нескольких строк

[`setRowHeightsForced(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheightsforced): задаёт высоту указанных строк в пикселях. При использовании `setRowHeightsForced` заданная высота применяется принудительно, даже если содержимое ячейки выше строки.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 5 pixels
sheet.setRowHeightsForced(0, 3, 5)
```

#### Автоматическая настройка высоты строк

[`autoResizeRows(startRow, numRows)`](https://docs.univer.ai/reference/facade/worksheet#autoresizerows): автоматически подбирает высоту указанных строк под их текстовое содержимое.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set the first 3 rows to a height that fits their text.
sheet.autoResizeRows(0, 3)
```

#### Установка пользовательских свойств строк

[`setRowCustom(custom)`](https://docs.univer.ai/reference/facade/worksheet#setrowcustom): задаёт пользовательские свойства строк. В строке сохраняется объект `custom`, в который можно поместить любые данные в формате JSON для хранения дополнительной информации.
При обновлении данных `custom` исходные данные `custom` перезаписываются. Если при обновлении необходимо сохранить исходные данные `custom`, заранее получите данные `custom`, объедините их с новыми, а затем выполните обновление.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set custom properties for the first and third rows
sheet.setRowCustom({
  0: { color: 'red' },
  2: { size: 16 },
})
```

#### Перемещение столбцов в новую позицию

[`moveColumns(columnSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#movecolumns): перемещает столбцы, выбранные заданным диапазоном, в позицию с индексом `destinationIndex`. Диапазон `columnSpec` не обязан в точности представлять целый столбец или группу столбцов: метод выбирает все столбцы, которые охватывает диапазон.

```typescript
// The code below moves rows A-B to destination index 5.
// This results in those columns becoming columns C-D.
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Selects column A and column B to be moved.
const columnSpec = sheet.getRange('A:B')
sheet.moveColumns(columnSpec, 5)
```
