## Facade API

Ссылка [Facade API](/reference/facade) содержит полные определения типов.

### Строки

#### Вставка строки после заданной позиции

[`insertRowAfter(afterPosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowafter): Вставляет новую строку после строки в заданной позиции.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row after the first row position
sheet.insertRowAfter(0)
```

#### Вставка строки перед заданной позицией

[`insertRowBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowbefore): Вставляет новую строку перед строкой в данной позиции.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row before the first row position
sheet.insertRowBefore(0)
```

#### Вставка нескольких строк в заданной позиции

[`insertRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#insertrows): Вставляет один или несколько последовательных пустых рядов, начиная с заданной позиции.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Shifts all rows down by three
sheet.insertRows(0, 3)
```

#### Вставка нескольких строк после заданной позиции

[`insertRowsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsafter): Вставляет заданное число строк после строки в заданном положении.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows after the first row
sheet.insertRowsAfter(0, 5)
```

#### Вставка нескольких строк перед заданной позицией

[`insertRowsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsbefore): Вставляет заданное число строк перед строкой в заданном положении.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows before the first row
sheet.insertRowsBefore(0, 5)
```

#### Удаление строки в заданной позиции

[`deleteRow(rowPosition)`](https://docs.univer.ai/reference/facade/worksheet#deleterow): удаляет строку в заданной позиции.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first row
sheet.deleteRow(0)
```

#### Удаление нескольких строк, начиная с заданной позиции

[`deleteRows(rowPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deleterows): удаляет заданное число строк, начиная с заданной позиции.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first two rows
sheet.deleteRows(0, 2)
```

#### Удаление нескольких строк в заданных позициях

[`deleteRowsByPoints(rowPoints)`](https://docs.univer.ai/reference/facade/worksheet#deleterowsbypoints): Удаляет несколько строк в одной операции, учитывая массив позиций строк.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the 3rd row and rows 5 to 7
fWorksheet.deleteRowsByPoints([2, [4, 6]])
```

#### Перемещение строк в новую позицию

[`moveRows(rowSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#moverows): Переносит строки, выбранные `rowSpec`, в `destinationIndex`. Диапазону не нужно выравниваться с одной строкой или группой строк: выбирается каждая строка, которую он охватывает.

```typescript
// The code below moves rows 1-2 to destination index 5
// This results in those rows becoming rows 3-4
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Selects row 1 and row 2 to be moved
const rowSpec = sheet.getRange('1:2')
sheet.moveRows(rowSpec, 5)
```

#### Скрытие строк в заданном диапазоне

[`hideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#hiderow): Скрывает строки в заданном диапазоне.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This hides the first row
const range = sheet.getRange('1:1')
sheet.hideRow(range)
```

#### Скрытие нескольких последовательных строк

[`hideRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#hiderows): Скрывает одну или несколько последовательных строк, начинающихся с заданного индекса. Метод использует индекс на основе 0.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Hides the first three rows
sheet.hideRows(0, 3)
```

#### Отображение строки в заданном диапазоне

[`unhideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#unhiderow): Скрывает строку в заданном диапазоне.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This unhides the first row if it was previously hidden
const range = sheet.getRange('1:1')
sheet.unhideRow(range)
```

#### Отображение нескольких последовательных строк

[`showRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#showrows): Открывает одну или несколько последовательных строк, начинающихся с заданного индекса. Метод использует индекс на основе 0.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Unhides the first three rows
sheet.showRows(0, 3)
```

#### Установка высоты строки

[`setRowHeight(rowPosition, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheight): Устанавливает высоту заданного ряда в пикселях. По умолчанию ряд вырастает, чтобы соответствовать содержимому его ячейки. Чтобы заставить конкретную высоту, используйте `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first row to a height of 200 pixels
sheet.setRowHeight(0, 200)
```

#### Установка высоты нескольких строк

[`setRowHeights(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheights): Устанавливает высоту заданных строк в пикселях. По умолчанию строки растут, чтобы соответствовать содержимому их ячейки. Чтобы заставить конкретную высоту, используйте `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 200 pixels
sheet.setRowHeights(0, 3, 200)
```

#### Принудительная установка высоты нескольких строк

[`setRowHeightsForced(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheightsforced): Устанавливает высоту заданных строк в пикселях. По умолчанию строки растут, чтобы соответствовать содержимому их ячейки. С `setRowHeightsForced` каждая строка сохраняет заданную высоту, даже когда ее содержимое выше.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 5 pixels
sheet.setRowHeightsForced(0, 3, 5)
```

#### Автоматическая настройка высоты строк

[`autoResizeRows(startRow, numRows)`](https://docs.univer.ai/reference/facade/worksheet#autoresizerows): устанавливает высоту заданных строк в соответствии с их текстовым содержанием.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set the first 3 rows to a height that fits their text.
sheet.autoResizeRows(0, 3)
```

#### Установка пользовательских свойств строк

[`setRowCustom(custom)`](https://docs.univer.ai/reference/facade/worksheet#setrowcustom): Устанавливает пользовательские свойства на заданных строках. Каждая строка получает объект `custom`, который может хранить любые данные JSON для хранения дополнительной информации. Написание `custom` перезаписывает ранее сохраненные данные `custom`. Чтобы сохранить существующие данные `custom`, сначала прочитайте объект `custom`, объедините его в новые данные, а затем запишите его.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set custom properties for the first and third rows
sheet.setRowCustom({
  0: { color: 'red' },
  2: { size: 16 },
})
```

[`deleteColumns(columnPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deletecolumns): Удаляет заданное число столбцов, начиная с заданной позиции.

#### Удаление нескольких столбцов в заданных позициях

[`deleteColumnsByPoints(columnPoints)`](https://docs.univer.ai/reference/facade/worksheet#deletecolumnsbypoints): Удаляет несколько столбцов в одной операции, учитывая массив позиций столбцов. Колонки не должны быть последовательными.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Columns start at "0" - this deletes the Column C and Columns E-G
```

#### Перемещение столбцов в новую позицию

[`moveColumns(columnSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#movecolumns): Переносит столбцы, выбранные `columnSpec`, в `destinationIndex`. Диапазон не должен выровняться с одной колонкой или группой столбцов: выбирается каждая колонка, которую он охватывает.

```typescript
// The code below moves rows A-B to destination index 5.
// This results in those columns becoming columns C-D.
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Selects column A and column B to be moved.
const columnSpec = sheet.getRange('A:B')
sheet.moveColumns(columnSpec, 5)
```

## Проверка размеров и нулевые строки или столбцы [#dimension-validation]

Высота рядов и ширина столбца должны быть конечными, неотрицательными числами. Команды измерения отвергают числовые строки, отрицательные значения, `NaN` и `Infinity`. Ноль допускается для отдельной строки или столбца, в то время как `defaultRowHeight` или `defaultColumnWidth` должны быть строго положительными. При создании листа Univer нормализует недействительные размеры на снимке.

Ряд или столбец с нулевым размером отличается от скрытого через его флаг видимости. Скрывая видимый нулевой размер строки или столбца, восстанавливает его до размера листа по умолчанию, а отмена/редо покрывает изменение. Проверяйте внешние размеры с помощью общедоступных валидаторов ниже, прежде чем передавать их редактору.

```ts
import { isValidColumnDimensions, isValidRowDimensions, isValidSheetDimension } from '@univerjs/core'

isValidSheetDimension(24) // true
isValidSheetDimension(0, false) // false: default dimensions must be positive
isValidRowDimensions({ h: 24, ah: 32 }) // true
isValidColumnDimensions({ w: -1 }) // false
```
