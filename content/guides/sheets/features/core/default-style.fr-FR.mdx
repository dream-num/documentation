Les styles par défaut existent à deux niveaux :
1. Le style par défaut de la feuille de calcul
2. Le style par défaut d'une colonne ou d'une ligne

Vous pouvez en définir un via l'interface [`IWorksheetData`](/reference/types/worksheet-data) ou Facade API.

## Configuration des plugins [#plugin-configuration]

`UniverSheetsPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `isRowStylePrecedeColumnStyle` | `boolean` | `false` | Fait le style de ligne ont priorité sur le style de colonne. |
| `textLineGap` | `number` | `0` | Interligne supplémentaire dans les cellules, en pixels. |

## Configuration des préréglages [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>sheets</ConfigKey> | `object` |  | Configuration pour la fonction sélectionnée. |
| <ConfigKey depth={1}>isRowStylePrecedeColumnStyle</ConfigKey> | `boolean` | `false` | Fait le style de ligne ont priorité sur le style de colonne. |
| <ConfigKey depth={1}>textLineGap</ConfigKey> | `number` | `0` | Interligne supplémentaire dans les cellules, en pixels. |

## Priorité des styles de ligne et de colonne

Par défaut, le style colonne a priorité sur le style ligne. Définissez `isRowStylePrecedeColumnStyle` lors de l'enregistrement pour inverser cette commande.

Sélectionnez l'onglet qui correspond à votre configuration Univer et fusionnez ces options dans l'initialisation existante. Gardez les autres plugins, local, thème et paramètres de conteneur inchangés, et n'enregistrez pas le même plugin deux fois.

<Tabs items={['Mode plugin', 'Mode prédéfini']}>
  <Tab>
    ```typescript
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, {
      isRowStylePrecedeColumnStyle: true,
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          sheets: {
            isRowStylePrecedeColumnStyle: true,
          },
        }),
      ],
    })
    ```
  </Tab>
</Tabs>

## Espacement du texte des cellules [#text-line-gap]

`textLineGap` ajoute de l'espace supplémentaire en pixels entre les lignes de texte cellulaire, y compris le texte riche et les éditeurs de cellules. Réglez-le lors de l'initialisation; il s'applique à chaque cahier de travail dans l'instance Univer. La valeur par défaut est `0`, et la valeur doit être finie et non négative.

<Tabs items={['Mode plugin', 'Mode preset']}>
  <Tab>
    ```ts
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, { textLineGap: 6 })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [UniverSheetsCorePreset({ sheets: { textLineGap: 6 } })],
    })
    ```
  </Tab>
</Tabs>

Un écart plus grand ne redimensionne pas les lignes existantes. Recalculer la hauteur automatique des lignes lorsque l'espace supplémentaire est nécessaire; les cellules à hauteur fixe peuvent couper leur texte. Il s'agit d'un réglage par instance, et non d'un style de paragraphe par cellule.

## Définir le style par défaut

Vous pouvez définir le style par défaut d'une feuille de travail de deux façons :

1. Au moyen de l’interface [`IWorksheetData`](/reference/types/worksheet-data)

```typescript
interface IWorksheetData {
  // other
  /**
   * @property {Nullable<IStyleData>} [defaultStyle] - Default style data of Worksheet.
   */
  defaultStyle?: Nullable<IStyleData>
}

interface IRowData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}

interface IColumnData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}
```

2. Par l'intermédiaire du Facade API

```typescript
const fworkbook = univerAPI.getActiveWorkbook()
const fworksheet = fworkbook.getActiveSheet()
const defaultStyle = {
  bg: {
    rgb: 'red',
  },
}
const defaultColumnStyle = {
  bg: {
    rgb: 'blue',
  },
}
const defaultRowStyle = {
  bg: {
    rgb: 'green',
  },
}

// set default style
fworksheet.setDefaultStyle(defaultStyle)
// set column D default style
fworksheet.setColumnDefaultStyle(3, defaultColumnStyle)
// reset column D the default style
fworksheet.setColumnDefaultStyle(3, undefined)

// set row default style
fworksheet.setRowDefaultStyle(1, defaultRowStyle)
```

## Réduire le texte pour l’ajuster

`FRange` peut réduire le texte qui est plus large que sa cellule. Le réglage s'applique à chaque cellule dans la plage, et `getShrinkToFit()` retourne l'état de la cellule supérieure gauche.

```ts
const range = univerAPI.getActiveWorkbook().getActiveSheet().getRange('A1:C3')

range.setShrinkToFit(true)
const enabled = range.getShrinkToFit()
```

L'emballage de texte permet de désactiver l'emballage de rétractation, et l'emballage des cellules qui enveloppent actuellement est désactivé.
