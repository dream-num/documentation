Nous proposons deux niveaux de styles par défaut :
1. Le style par défaut de la feuille de calcul
2. Le style par défaut d’une colonne ou d’une ligne

Tous deux peuvent être définis au moyen de l’interface [`IWorksheetData`](/reference/types/worksheet-data) ou de l’API Facade.

## Configuration

Par défaut, le style de colonne est prioritaire sur le style de ligne. Vous pouvez modifier ce comportement en définissant `isRowStylePrecedeColumnStyle` lors de l’enregistrement.

Choisissez votre mode et ajoutez ces options à votre initialisation existante. Conservez les autres plugins et les paramètres de langue, de thème et de conteneur ; ne réenregistrez pas le même plugin.

<Tabs items={['Mode plugin', 'Mode prédéfini']}>
  <Tab>
    ```typescript
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, {
      isRowStylePrecedeColumnStyle: true,
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          sheets: {
            isRowStylePrecedeColumnStyle: true,
          },
        }),
      ],
    })
    ```
  </Tab>
</Tabs>

## Définir le style par défaut

Il existe deux façons de définir le style par défaut d’une feuille de calcul :

1. Au moyen de l’interface [`IWorksheetData`](/reference/types/worksheet-data)

```typescript
interface IWorksheetData {
  // other
  /**
   * @property {Nullable<IStyleData>} [defaultStyle] - Default style data of Worksheet.
   */
  defaultStyle?: Nullable<IStyleData>
}

interface IRowData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}

interface IColumnData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}
```

2. Au moyen de l’API Facade

```typescript
const fworkbook = univerAPI.getActiveWorkbook()
const fworksheet = fworkbook.getActiveSheet()
const defaultStyle = {
  bg: {
    rgb: 'red',
  },
}
const defaultColumnStyle = {
  bg: {
    rgb: 'blue',
  },
}
const defaultRowStyle = {
  bg: {
    rgb: 'green',
  },
}

// set default style
fworksheet.setDefaultStyle(defaultStyle)
// set column D default style
fworksheet.setColumnDefaultStyle(3, defaultColumnStyle)
// reset column D the default style
fworksheet.setColumnDefaultStyle(3, undefined)

// set row default style
fworksheet.setRowDefaultStyle(1, defaultRowStyle)
```

## Réduire le texte pour l’ajuster

Lorsque le texte est plus large que la cellule, utilisez `FRange` pour réduire la taille de la police. Ce réglage s’applique à toutes les cellules de la plage ; `getShrinkToFit()` lit l’état de la cellule en haut à gauche.

```ts
const range = univerAPI.getActiveWorkbook().getActiveSheet().getRange('A1:C3')

range.setShrinkToFit(true)
const enabled = range.getShrinkToFit()
```

La réduction du texte et le renvoi à la ligne sont mutuellement exclusifs. Activer le renvoi désactive la réduction ; activer la réduction supprime le renvoi déjà appliqué aux cellules.
