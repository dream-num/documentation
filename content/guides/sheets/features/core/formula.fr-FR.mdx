Les formules constituent l’une des fonctionnalités principales d’Univer. Elles permettent de calculer des valeurs à partir de formules saisies dans les cellules. Les fonctions prises en charge sont compatibles avec Excel et comprennent notamment les fonctions mathématiques, logiques, textuelles et de date.

Lorsqu’un classeur contient un grand nombre de formules, leur calcul peut mobiliser le thread principal et réduire la réactivité de la page. Nous vous recommandons d’exécuter le calcul des formules dans un processus Worker afin de limiter son incidence sur le rendu et les interactions utilisateur. Pour en savoir plus sur la configuration, consultez la page [Web Workers](/guides/sheets/getting-started/worker).

### Configuration des préréglages

```typescript
import type { CalculationMode } from '@univerjs/preset-sheets-core'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'

interface IUniverSheetsCorePresetConfig {
  formula?: {
    // Custom formula functions
    function?: Array<[Ctor<BaseFunction>, IFunctionNames]>
    // Custom formula descriptions
    description?: IFunctionInfo[]
    // Defines the calculation mode for formulas during data initialization, default is `WHEN_EMPTY`
    initialFormulaComputing?: CalculationMode
  }
}
```

### Configuration du plugin

```typescript
import type { CalculationMode } from '@univerjs/sheets-formula'
import { UniverSheetsFormulaPlugin } from '@univerjs/sheets-formula'

interface IUniverSheetsFormulaConfig {
  // Custom formula functions
  function?: Array<[Ctor<BaseFunction>, IFunctionNames]>
  // Custom formula descriptions
  description?: IFunctionInfo[]
  // Defines the calculation mode for formulas during data initialization, default is `WHEN_EMPTY`
  initialFormulaComputing?: CalculationMode
}
```

`CalculationMode` est défini comme suit :

```typescript
enum CalculationMode {
  /**
   * Force calculation of all formulas
   */
  FORCED,

  /**
   * Partial calculation, only calculates cells with formulas but no value
   */
  WHEN_EMPTY,

  /**
   * No calculation for all formulas
   */
  NO_CALCULATION,
}
```

> Si la cellule contenant la formule présente une valeur inattendue, vous pouvez définir `initialFormulaComputing` sur `CalculationMode.FORCED` afin de forcer le calcul de toutes les formules. Vous pouvez également effacer la valeur `v` de la cellule avant l’initialisation.

## Références entre classeurs

Une formule peut agréger dans `Report` les ventes de `Sales.xlsx`. Contrairement à une référence vers une autre feuille du même classeur, elle identifie aussi le classeur source.

### Syntaxe des références

| Cas | Exemple | Cible |
| --- | --- | --- |
| Autre feuille du même classeur | `=SUM(Data!A1:A10)` | Feuille Data du classeur courant |
| Plage d’un autre classeur | `=SUM('[Sales.xlsx]Data'!A1:A10)` | Feuille Data de Sales.xlsx |
| Tableau d’un autre classeur | `=SUM(Sales.xlsx!SalesTable[Amount])` | Colonne Amount du tableau SalesTable existant |

`Sales.xlsx` est un nom de classeur, pas un chemin ni une URL. Écrire une formule ne lit aucun fichier, ne télécharge pas Excel et ne connecte pas un éditeur dans une autre page. Créez le [tableau](/guides/sheets/features/table) avant d’utiliser une référence structurée.

### Référencer des classeurs chargés dans la même instance

Avec le moteur de base, chargez les deux classeurs dans la même instance Univer et le même environnement de calcul. Exécutez cet exemple après l’initialisation de Sheets. En mode plugin, importez aussi les extensions Facade indiquées sur cette page.

```typescript
const source = univerAPI.createWorkbook({
  id: 'sales-workbook',
  name: 'Sales.xlsx',
  sheetOrder: ['sales-data'],
  sheets: {
    'sales-data': {
      id: 'sales-data',
      name: 'Data',
      rowCount: 100,
      columnCount: 20,
      cellData: {
        0: { 0: { v: 100 } },
        1: { 0: { v: 200 } },
      },
    },
  },
}, { makeCurrent: false })

const report = univerAPI.createWorkbook({ id: 'report-workbook', name: 'Report' })
const resultCell = report.getActiveSheet().getRange('A1')
resultCell.setFormula("=SUM('[Sales.xlsx]Data'!A1:A2)")

const formula = univerAPI.getFormula()
formula.executeCalculation()
await formula.onCalculationResultApplied()
console.log(resultCell.getValue()) // 300
```

`makeCurrent: false` charge la source sans changer le classeur actif. Conservez `source` et `report` pour éviter d’écrire au mauvais endroit après un changement de classeur actif.

La recherche ignore la casse et privilégie le nom complet. À défaut, elle ignore les extensions Excel usuelles telles que `.xlsx` et `.xlsm`. Un nom absent ou ambigu produit `#REF!` : utilisez un nom unique.

### Associer une référence à un ID source stable

Pour associer un nom de formule à un ID de document stable, utilisez l’extension Pro `@univerjs-pro/engine-formula`. Configurez une [licence client](/guides/license), remplacez `UniverFormulaEnginePlugin` par `UniverProFormulaEnginePlugin` à l’initialisation et importez la Facade Pro. N’enregistrez pas les deux moteurs. L’import de la Facade seul n’enregistre pas le plugin.

Cet exemple reprend les classeurs précédents dans un environnement configuré avec le moteur Pro :

```typescript
import '@univerjs-pro/engine-formula/facade'

const reference = univerAPI.getFormula().buildReference({
  hostUnitId: report.getId(),
  unit: {
    unitId: source.getId(),
    formulaQualifier: 'Sales Source',
  },
  target: {
    kind: univerAPI.Enum.FormulaReferenceType.SHEET_RANGE,
    sheetName: 'Data',
    range: { startRow: 0, endRow: 1, startColumn: 0, endColumn: 0 },
  },
})

resultCell.setFormula(`=SUM(${reference})`)
```

`hostUnitId` désigne le classeur contenant la formule, `unit.unitId` l’ID stable de la source et `formulaQualifier` son nom public dans la formule. Les coordonnées commencent à zéro et incluent la borne finale.

`buildReference()` renvoie un fragment sans `=` et enregistre l’association. Il ne charge pas la source et ne lance pas le calcul. Les données doivent provenir d’un classeur chargé dans l’environnement de calcul ou d’un fournisseur configuré. Pour une formule écrite à la main ou générée par l’application, créez d’abord l’association :

```typescript
const formula = univerAPI.getFormula()
const bound = formula.upsertExternalReference({
  unitId: report.getId(),
  qualifier: 'Sales Source',
  sourceUnitId: source.getId(),
  sourceUnitType: univerAPI.Enum.UniverInstanceType.UNIVER_SHEET,
})
if (!bound) throw new Error('Could not bind Sales Source')

resultCell.setFormula("=SUM('[Sales Source]Data'!A1:A2)")
```

Répéter la même association est idempotent. `qualifier` ne contient ni crochets ni guillemets. Les entiers positifs comme `1` et `2` sont réservés aux emplacements de liens externes Excel, pas aux ID métier. Conservez les ressources de liens lors d’un import : le texte de la formule seul ne suffit pas.

### Mettre à jour, enregistrer et décharger

Après une modification de la source via la Facade, lancez le calcul et attendez l’application des résultats avant de lire la cible. Le calcul asynchrone n’est pas nécessairement terminé au retour de `setFormula()` ou `setValue()`.

```typescript
const sourceSheet = source.getSheetBySheetId('sales-data')
if (!sourceSheet) throw new Error('Source sheet not found')
sourceSheet.getRange('A1').setValue(150)
formula.executeCalculation()
await formula.onCalculationResultApplied()
console.log(resultCell.getValue()) // 350
```

Utilisez `report.save()` pour enregistrer le snapshot complet avec les ressources d’association. Sauvegarder uniquement les formules perd la correspondance nom/ID. Enregistrez et chargez les données source séparément.

Une fois la source déchargée, une référence ordinaire à un classeur chargé ne peut plus la lire. Les références Pro ne peuvent poursuivre le calcul que si les fournisseurs ou caches disponibles apportent les données. Une association ne contient pas les données et ne garantit pas le calcul hors ligne. Une ancienne valeur affichée ne prouve pas que le résultat est à jour.

Supprimez une association Pro devenue inutile :

```typescript
univerAPI.getFormula().removeExternalReference({
  unitId: report.getId(),
  qualifier: 'Sales Source',
})
```

La suppression ne modifie ni n’efface les formules. Le calcul suivant résout à nouveau le nom : un classeur chargé portant ce nom peut encore être trouvé ; sinon, la référence renvoie `#REF!`. Modifiez ou effacez aussi les formules pour arrêter la référence. Voir les [API de référence FFormula](/reference/facade/formula#cross-unit-reference-authoring).

## Références 3D

Une référence 3D couvre des feuilles consécutives du même classeur. Elle est distincte d’une référence entre classeurs.

```text
=SUM(Jan:Mar!B2:C3)
=SUM('Jan':'Mar'!B2)
```

La plage comprend Jan, Mar et toutes les feuilles intermédiaires dans l’ordre du classeur, et non par ordre alphabétique. Vérifiez la plage d’agrégation lorsque vous réordonnez les feuilles.

### Afficher la boîte de dialogue de sélection de plages

`@univerjs/sheets-formula-ui/facade` ajoute `univerAPI.showRangeSelectorDialog`. Utilisez cette méthode lorsque votre interface personnalisée doit permettre aux utilisateurs de sélectionner une ou plusieurs plages avec le même sélecteur que celui des panneaux liés aux formules.

```typescript
const workbook = univerAPI.getActiveWorkbook()
const worksheet = workbook?.getActiveSheet()

if (workbook && worksheet) {
  await univerAPI.showRangeSelectorDialog({
    unitId: workbook.getId(),
    subUnitId: worksheet.getSheetId(),
    initialValue: [
      {
        unitId: workbook.getId(),
        sheetName: worksheet.getSheetName(),
        range: worksheet.getRange('A1:B2').getRange(),
      },
    ],
    maxRangeCount: 2,
    supportAcrossSheet: true,
    callback: (ranges, isCancel) => {
      console.log(ranges, isCancel)
    },
  })
}
```

### Exécuter le calcul des formules

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.executeCalculation()
```

### Arrêter le calcul des formules

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.stopCalculation()
```

### Début du calcul des formules

```typescript
// Listening to formula calculation start event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationStart((forceCalculate) => {
  console.log(forceCalculate)
})
```

### Progression du calcul des formules

```typescript
// Listening to formula calculation processing event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationProcessing((stageInfo) => {
  console.log(stageInfo)
})
```

### Fin du calcul des formules

```typescript
// Listening to formula calculation end event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationEnd((functionsExecutedState) => {
  console.log(functionsExecutedState)
})
```

### Application du résultat du calcul des formules

```typescript
// Listening to formula calculation result applied event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationResultApplied((result) => {
  console.log(result)
})

// Wait for formula calculation result to be applied
await formulaEngine.onCalculationResultApplied()
```

### Définir le mode de calcul des formules lors de l’initialisation des données

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.setInitialFormulaComputing(CalculationMode.FORCED)
```

Si cette API est appelée après le cycle de vie `Starting`, elle prendra effet lors de la prochaine création d’une feuille Univer Sheet.

Pour qu’elle prenne effet pendant l’initialisation en cours de la feuille Univer Sheet, vous pouvez l’appeler avant le cycle de vie `Ready`, par exemple :

```typescript
univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === LifecycleStages.Starting) {
    const formulaEngine = univerAPI.getFormula()
    formulaEngine.setInitialFormulaComputing(CalculationMode.FORCED)
  }
})
```

### Définir le nombre maximal d’itérations

Lorsque des formules contiennent des références circulaires, vous pouvez utiliser cette API pour définir le nombre maximal d’itérations du calcul. La valeur par défaut est 1.

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.setMaxIteration(10)
```

### Obtenir le résultat de l’exécution de chaînes de formule

Exécutez un ensemble de formules de façon asynchrone et récupérez les résultats des calculs :

```typescript
const formulaEngine = univerAPI.getFormula()
const formulas = {
  Book1: {
    Sheet1: {
      2: {
        3: [
          // Full formula:
          '=SUM(A1:A10) + SQRT(D7)',

          // Decomposed sub-formulas (each one can be evaluated independently):
          'SUM(A1:A10)', // sub-formula 1
          'SQRT(D7)', // sub-formula 2
          'A1:A10', // range reference
          'D7', // single-cell reference
        ],
      },
      4: {
        5: ['=A2 + B2 + SQRT(C5)', 'A2', 'B2', 'SQRT(C5)'],
      },
    },
  },
}
const result = await formulaEngine.executeFormulas(formulas)
console.log(result)
```
