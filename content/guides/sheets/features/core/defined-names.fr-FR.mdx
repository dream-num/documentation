Un nom défini assigne un nom personnalisé à une cellule, une plage ou une formule. Les formules peuvent alors se référer à ce nom au lieu de l'adresse brute, ce qui les rend plus faciles à lire et à maintenir.

- Les formules se lisent plus près de ce qu'elles signifient. `Amount` exprime l'intention plus clairement que `A1 + A2 + A3`.
- Plusieurs cellules ou une gamme complexe peuvent être représentées par un seul nom. Définissez `SalesData` pour `A1:A10` et utilisez `SalesData` dans des formules.
- Une zone de données est maintenue en un seul endroit. Lorsque la plage change, mettez à jour la référence du nom au lieu de chaque formule qui l'utilise.

## Utilisation

L'entrée Nom Manager est à côté de la boîte de noms dans le coin supérieur gauche de la feuille. Cliquer dessus affiche chaque nom défini et ouvre le Gestionnaire de noms, où vous pouvez afficher, modifier et supprimer les noms définis.

Dans une formule, saisissez le nom directement. Si une plage s'appelle `TotalSales`, `=TotalSales` fait référence à cette plage.

## Remarques

- Un nom défini doit être unique dans la même feuille de travail, et il ne peut pas entrer en conflit avec un autre nom ou une fonction intégrée.
- Un nom ne peut pas commencer par un nombre, et il ne peut pas contenir d'espaces ou de caractères spéciaux tels que `!`, `@` ou `#`. Si un nom entré viole ces règles, le système signale une erreur.
- Pour changer un nom, rouvrez le panneau d'édition "Define Name", sélectionnez le nom, modifiez-le et cliquez sur "OK".
- Pour supprimer un nom, sélectionnez-le dans le panneau d'édition "Définir le nom" et cliquez sur "Supprimer".
- Les noms peuvent être partagés sur différentes feuilles de travail dans le même cahier, mais la règle de l'unicité s'applique toujours : définir le même nom sur différentes feuilles peut rendre les références ambiguës.
- Utilisez des noms significatifs et évitez les noms très courts ou vagues, afin que d'autres personnes puissent comprendre et maintenir la feuille.
- Si l'utilisation d'un nom défini pose des problèmes, vérifiez que le nom est correct, que la plage de référence est exacte et qu'aucun autre nom ne l'est.
- Un nom peut être défini au niveau du cahier de travail ou au niveau de la feuille de travail. Les noms de classe sont disponibles dans le cahier de travail, tandis que les noms de classe de la feuille sont disponibles uniquement sur la feuille de calcul spécifique.

## API Facade

Les définitions de type Facade API complètes sont dans le [Facade API](/reference/facade).

### Créer des noms définis

`FWorkbook.newDefinedNameBuilder()` crée un constructeur de nom défini et renvoie un `FDefinedNameBuilder`. Chaîne ses méthodes pour produire l'objet `ISetDefinedNameMutationParam` utilisé pour créer le nom.

Ce sont quelques-unes des méthodes des membres sur [`FDefinedNameBuilder`](/reference/facade/defined-name-builder):

| Méthode | Description |
| ---- | ---- |
| build | Construit l’objet du nom défini |
| setName | Définit le nom |
| setFormula | Définit la formule du nom défini |
| setRef | Définit la plage de référence du nom défini |
| setComment | Définit le commentaire |
| setScopeToWorksheet | Rend le nom défini disponible pour une feuille de calcul donnée |
| setScopeToWorkbook | Rend le nom défini disponible pour l’ensemble du classeur |

[`FWorkbook.insertDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#insertdefinednamebuilder) crée un nom défini qui est disponible pour l'ensemble du cahier.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedNameParam = fWorkbook.newDefinedNameBuilder()
  .setName('MyDefinedName')
  .setRef('Sheet1!$A$1')
  .setComment('A reference to A1 cell in Sheet1')
  .build()
fWorkbook.insertDefinedNameBuilder(definedNameParam)
```

[`FWorkbook.insertDefinedName()`](https://docs.univer.ai/reference/facade/workbook#insertdefinedname) est un raccourci pour créer un nom défini lorsque le nom et la référence sont déjà connus.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.insertDefinedName('MyDefinedName', 'Sheet1!$A$1')
```

Autre méthode :
- [`FWorksheet.insertDefinedName()`](https://docs.univer.ai/reference/facade/worksheet#insertdefinedname) : crée un nom défini disponible pour une feuille de calcul donnée.

### Obtenir des noms définis

[`FWorkbook.getDefinedName()`](https://docs.univer.ai/reference/facade/workbook#getdefinedname) obtient un nom défini dans le cahier et renvoie un `FDefinedName`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

if (definedName) {
  definedName.setName('NewDefinedName')
}
```

Autres méthodes :
- [`FWorkbook.getDefinedNames()`](https://docs.univer.ai/reference/facade/workbook#getdefinednames) retourne chaque nom défini dans le cahier d'exercices sous la forme d'un tableau `FDefinedName[]`.
- [`FWorksheet.getDefinedNames()`](https://docs.univer.ai/reference/facade/worksheet#getdefinednames) retourne chaque nom défini disponible sur cette feuille de travail sous forme d'un tableau `FDefinedName[]`.

### Modifier des noms définis

[`FWorkbook.updateDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#updatedefinednamebuilder) modifie un nom défini dans le cahier.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Modify the defined name
if (definedName) {
  const newDefinedNameParam = definedName.toBuilder()
    .setName('NewDefinedName')
    .setRef('Sheet1!$A$2')
    .build()
  fWorkbook.updateDefinedNameBuilder(newDefinedNameParam)
}
```

Vous pouvez également modifier la configuration directement sur l'instance [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name) retournée.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Modify the defined name
if (definedName) {
  definedName.setName('NewDefinedName')
  definedName.setRef('Sheet1!$A$2')
}
```

### Supprimer des noms définis

[`FWorkbook.deleteDefinedName()`](https://docs.univer.ai/reference/facade/workbook#deletedefinedname) supprime un nom défini dans le cahier.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.deleteDefinedName('MyDefinedName')
```

Vous pouvez également supprimer le nom par l'intermédiaire de l'instance [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name) retournée.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Delete the defined name
if (definedName) {
  definedName.delete()
}
```
