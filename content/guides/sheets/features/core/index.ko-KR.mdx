Univer Sheets의 핵심 기능에는 스프레드시트 편집기, 수식 엔진, 렌더링 엔진, 숫자 서식 엔진, 디자인 시스템, UI 컴포넌트 라이브러리가 포함됩니다. 이 기능들은 다양한 형식과 복잡한 작업을 지원하는 강력한 스프레드시트 처리 플랫폼을 구성합니다.

## 기능

Univer Sheets의 핵심 기능은 다음과 같습니다.

- **스프레드시트 렌더링**: 커서와 선택 영역 표시를 포함하여 Univer Sheets 렌더링을 지원합니다.
- **셀 스타일**: 글꼴, 색상, 테두리, 맞춤 등 스프레드시트 셀의 스타일을 지정할 수 있습니다.
- **수식 계산**: 수학, 통계, 텍스트, 날짜 함수를 비롯한 거의 모든 Excel 함수를 추가하고 계산할 수 있습니다.
- **숫자 서식**: 통화, 백분율, 날짜 등 스프레드시트의 숫자 서식을 지정할 수 있습니다.
- **눈금선 및 틀 고정**: 눈금선 표시와 틀 고정을 지원하여 대규모 데이터도 쉽게 보고 편집할 수 있습니다.
- **기본 스타일**: 기본 글꼴, 크기, 색상 등 스프레드시트의 기본 스타일을 설정할 수 있습니다.
- **플러그인 시스템**: 수식, 이미지, 차트 등의 사용자 지정 플러그인을 지원합니다. 이는 Univer 핵심 아키텍처의 주요 기능이기도 합니다.

### 플러그인 및 구성

#### @univerjs/core

이 플러그인은 Univer의 핵심 라이브러리로, Univer 인스턴스 생성, 테마, 언어 등의 기본 기능을 제공합니다.

```typescript
interface UniverParameter {
  // Univer instance theme, default is `defaultTheme`
  theme: IStyleSheet
  // Whether to use dark mode, default is false
  darkMode?: boolean
  // The locale of the Univer instance
  locale: LocaleType
  // The locale objects to use, with keys as locale types and values as corresponding locale objects
  locales: ILocales
  // The log level of the Univer instance
  logLevel?: LogLevel
}
```

참고: [`Univer`](https://docs.univer.ai/reference/classes/univer)

참고: [@univerjs/engine-render](https://docs.univer.ai/reference/packages/plugins/univerjs/engine-render)

참고: [@univerjs/engine-formula](https://docs.univer.ai/reference/packages/plugins/univerjs/engine-formula)

#### @univerjs/design

참고: [UI 장](/guides/docs/ui/overview)

#### @univerjs/ui

이 플러그인은 Univer의 UI 기반이며 `UniverUIPlugin`을 제공합니다.

`UniverUIPlugin`은 기본 레이아웃을 구성하는 데 사용할 수 있는 여러 옵션을 제공합니다.

```typescript
interface IUniverUIConfig {
  // Container element, can be a string or a DOM element
  container?: string | HTMLElement
  // Whether to show the header
  header?: boolean
  // Whether to show the header toolbar
  toolbar?: boolean
  // The type of the header toolbar. 'classic': default classic mode; 'grid': two-row grid mode; 'collapsed': compact mode; 'simple': ungrouped mode
  ribbonType?: RibbonType
  // Whether to show the context menu
  contextMenu?: boolean
  // Whether to disable auto focus
  disableAutoFocus?: true
  // Dependency injection override configuration
  override?: DependencyOverride
  // Menu configuration
  menu?: MenuConfig
}
```

`menu` 구성 옵션을 사용하면 특정 메뉴 항목의 표시 또는 숨김 상태를 간단히 설정할 수 있습니다.

```typescript
univer.registerPlugin(UniverSheetsUIPlugin, {
  menu: {
    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

여기서 `'sheet.command.set-range-bold'`와 `'sheet.command.set-range-italic'`은 해당 메뉴 항목의 ID입니다. 아래의 [메뉴 항목 ID 목록](#menu-item-id-list)을 참고하세요.

참고: [@univerjs/ui](https://docs.univer.ai/reference/packages/plugins/univerjs/ui)

## 도구 모음 레이아웃과 `RibbonType`

`IUniverSheetsCorePresetConfig` 또는 `IUniverUIConfig`의 `ribbonType` 속성을 구성하여 도구 모음 레이아웃을 설정할 수 있습니다.

`ribbonType`은 다음 네 가지 모드를 지원합니다.

- `classic`: 기본 클래식 모드입니다. 그룹은 위쪽에, 도구 모음은 아래쪽에 배치되며 기존 레이아웃에 익숙한 사용자에게 적합합니다.
- `grid`: 그리드 모드입니다. 위쪽 탭을 유지하고 아래쪽의 각 도구 그룹을 2행 그리드로 배치하며, 더 많은 도구를 한 번에 표시해야 하는 데스크톱 레이아웃에 적합합니다.
- `collapsed`: 컴팩트 모드입니다. 그룹과 도구 모음이 같은 행에 배치되며 세로 공간이 제한된 환경에 적합합니다.
- `simple`: 그룹 없는 모드입니다. 모든 도구가 평면 목록으로 배치되며 도구 모음 기능에 익숙한 사용자에게 적합합니다.

`grid` Ribbon이 컨테이너 너비에 맞지 않으면 그룹 전체가 더 보기 메뉴로 이동해 간결한 배치로 표시됩니다. 너비가 넓어지면 그룹이 돌아옵니다. 가용 너비에 따라 자동 적용되며 기본 Ribbon의 `gridLayout` 설정을 그대로 사용합니다. 메뉴에서도 같은 명령, 비활성 상태, 권한 검사를 유지합니다.

## 메뉴 순서와 그리드 배치 [#menu-order-and-grid-layout]

초기 설정과 런타임 [`univerAPI.updateMenuConfig()`](/reference/facade/univer#updatemenuconfig)는 같은 `menu` 구조를 사용합니다. 키는 Ribbon 탭 키(예: `ribbon.insert`), 그룹 키(예: `ribbon.start.format`) 또는 메뉴 항목 ID입니다.

`order`는 같은 수준의 항목을 오름차순으로 정렬합니다. 탭, 탭 안의 그룹, 그룹이나 하위 메뉴 안의 항목에 적용되며 다른 그룹으로 이동시키지는 않습니다. 탭과 그룹 키에는 `@univerjs/ui`에서 내보내는 `RibbonPosition`과 그룹 열거형도 사용할 수 있습니다.

### 초기 설정

사용 중인 모드를 선택하고 기존 초기화 설정에 아래 옵션을 병합하세요. 다른 플러그인, 언어, 테마 및 컨테이너 설정은 유지하고 같은 플러그인을 중복 등록하지 마세요.

```ts
import type { MenuConfig } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.insert': { order: -1 },
  'ribbon.start.format': { order: -1 },
  'sheet.command.set-range-font-family': {
    order: 0,
    gridLayout: { row: 1, column: 1, width: 160 },
  },
}
```

    import { UniverUIPlugin } from '@univerjs/ui'

### 런타임 업데이트

공개 Facade는 변경 사항을 병합하고 UI를 즉시 갱신합니다. 지정하지 않은 속성은 기존 설정이나 Schema 기본값을 유지하며, 나중에 등록되는 메뉴에도 설정이 적용됩니다. 플러그인 모드에서는 먼저 `@univerjs/ui/facade`를 가져와야 합니다.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'sheet.command.set-range-bold': {
    order: 0,
    gridLayout: { row: 2, column: 2 },
  },
  'sheet.command.set-range-italic': {
    gridLayout: { row: 2, column: 1 },
  },
})
```

`gridLayout`은 `ribbonType: 'grid'`일 때만 적용됩니다. 각 그룹은 두 행이며 `row`와 `column`은 1부터 시작합니다. 명시한 좌표가 위치를 결정하므로 `order`만 바꿔서는 좌표가 지정된 버튼을 이동할 수 없습니다. 위치를 교환할 때는 겹치지 않도록 두 버튼을 함께 업데이트하세요. 선택적 필드는 `rowSpan`, `columnSpan`, `showLabel`, `width`, `iconSize`이며 크기의 단위는 픽셀입니다. 제약 조건과 기본값은 [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout)을 참고하세요.

### 사용자 정의 메뉴 배치

`createMenu()`와 `createSubmenu()`도 `order`와 `gridLayout`을 지원합니다. 하위 메뉴에서는 Ribbon 트리거의 위치를 지정하며 팝업 내부 배치는 바꾸지 않습니다. 다음 예제는 기록 그룹의 세 번째 열에 버튼을 추가합니다.

```ts
univerAPI
  .createMenu({
    id: 'custom-action',
    title: 'Custom action',
    action: () => console.log('Custom action clicked'),
    order: 4,
    gridLayout: { row: 1, column: 3, showLabel: true, width: 96 },
  })
  .appendTo('ribbon.start.history')
```

애플리케이션 및 플러그인 예제는 [메뉴 확장 경로](/guides/sheets/ui/components#menu-extension-paths)를 참조하세요.
