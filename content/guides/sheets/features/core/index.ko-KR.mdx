Univer 시트의 핵심은 스프레드 시트 편집기와 편집기가 필요한 구성 요소로 구성되어 있습니다 : 공식 엔진, 렌더링 엔진, 번호 포맷 엔진, 디자인 시스템 및 UI 구성 요소 라이브러리. 이 부품은 광범위한 스프레드 시트 형식과 실제 작업 책이 포함 된 복잡한 작업을 지원합니다.

## 기능

핵심 특징 세트 덮개:

- **스프레드시트 렌더링**: 시트 콘텐츠, 커서 및 선택을 그리십시오.
- **셀 스타일링**: 폰트, 색상, 국경 및 세포의 정렬을 설정합니다.
- **공식 계산**: 수학, 통계, 텍스트 및 날짜 기능을 포함하여 거의 모든 Excel 기능에 대한 지원과 함께 공식을 추가하고 계산합니다.
- **번호 포맷**: 통화, 비율, 날짜 및 값에 다른 번호 형식을 적용합니다.
- **격자판과 언 팬**: 큰 datasets를 읽고 편집하게 쉬운 만드는 격자판 및 언 팬을 보여주십시오.
- **기본 스타일**: 스프레드 시트에 기본 글꼴, 크기, 색상 및 기타 스타일을 설정합니다.
- **플러그인 시스템**: 수식, 이미지 및 차트 플러그인과 같은 사용자 정의 플러그인의 추가를 허용한다. 플러그인 시스템은 Univer의 핵심 건축 기능 중 하나입니다.

### 플러그인 설정 [#plugin-configuration]

#### @univerjs/core

이 패키지는 Univer 코어 라이브러리입니다. 그것은 Univer 인스턴스를 생성하고 테마와 로컬과 같은 기본 기능을 관리합니다.

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 제품정보 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>theme</ConfigKey> | `Theme` | `defaultTheme` | 편집기 테마입니다. |
| <ConfigKey depth={1}>[palette]</ConfigKey> | `object` |  |  |
| <ConfigKey depth={2}>[shade]</ConfigKey> | `string` |  | 색상 이름과 농도를 키로 사용하는 팔레트입니다. `defaultTheme`을 참고하세요. |
| `darkMode` | `boolean` | `false` | 시작할 때 다크 모드를 사용합니다. |
| `locale` | `LocaleType` |  | 메뉴와 대화상자의 언어입니다. |
| `region` | `LocaleType` | `locale` | 서식에 사용하는 지역입니다. |
| <ConfigKey depth={0}>locales</ConfigKey> | `Record<string, ILanguagePack>` |  | 언어별 번역 리소스입니다. |
| <ConfigKey depth={1}>[locale]</ConfigKey> | `ILanguagePack` |  | 로캘 값을 키로 사용하는 번역 팩입니다. |
| `logLevel` | `LogLevel` | `LogLevel.INFO` | 로그 상세 수준입니다. |

참고: [`Univer`](https://docs.univer.ai/reference/classes/univer)

#### @univerjs/engine-render

연출 엔진은 장 내용, scrollbars, 커서 및 선택을 그립니다. 그것은 `UniverRenderEnginePlugin`를 수출합니다.

특정 메뉴 항목의 가시성을 제어하기 위해 `menu`를 사용합니다.

```typescript
univer.registerPlugin(UniverUIPlugin, {
  menu: {
    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

키, `'sheet.command.set-range-bold'` 및 `'sheet.command.set-range-italic'` 모두, 메뉴 항목 ID입니다; [메뉴 항목 ID 목록](#menu-item-id-list)는 아래 전체 목록을 포함합니다.

## 도구 모음 레이아웃과 `RibbonType`

`IUniverSheetsCorePresetConfig` 또는 `IUniverUIConfig`에서 `ribbonType`를 설정하여 툴바 레이아웃을 선택합니다.

4개의 형태가 있습니다:

- `classic`: 기본 레이아웃. 그룹은 위 줄을 차지하고 도구 모음은 아래에서 실행되며, 기존 레이아웃의 사용자가 예상되는 것을 일치시킵니다.
- `grid`: 탭을 유지하고 두 줄 그리드에서 각 그룹의 도구를 배치합니다. 한 번에 더 많은 도구를 볼 수있는 데스크탑 레이아웃을 적합합니다.
- `collapsed`: 그룹과 툴바를 동시에 배치할 때 수직 공간을 절약할 수 있습니다.
- `simple`: 그룹을 제거하고 단일 평면 목록에 모든 도구를 배치, 이미 각 버튼을 수행하는 것을 알고 사용자.

`grid` 리본은 충분한 폭을 가지고있을 때, 전체 그룹은 **더 보기**로 이동하고 그들의 통제는 조밀한 배치로 전환합니다. 그들은 콘테이너가 폭 넓게 할 때 돌려보냅니다. 이것은 유효한 폭을 자동적으로 따르고, 그래서 주요 리본을 위한 기존하는 `gridLayout` 유지합니다. 과잉 메뉴는 동일한 명령, 무능한 상태 및 허가 체크를 유지합니다.

## 메뉴 순서와 그리드 배치 [#menu-order-and-grid-layout]

`menu`의 핵심은 `ribbon.insert`, `ribbon.start.format` 또는 메뉴 항목 ID와 같은 그룹과 같은 리본 탭이 될 수 있습니다.

`order`는 낮은에서 높은까지 siblings를 분류합니다: 탭 내의 탭, 그룹 내의 그룹, 그리고 그룹 내의 품목 또는 submenu. 그것은 다른 그룹으로 메뉴 항목을 이동하지 않습니다. 문자열 키의 경우 `RibbonPosition` 및 `@univerjs/ui`에 의해 수출된 그룹 enums를 사용할 수 있습니다.

현재 모드에 대한 기존 초기화에 이러한 옵션이 있습니다. 다른 플러그인, Locale, 테마, 컨테이너 설정 유지, 같은 플러그인을 두 번 등록하지 마십시오.

```ts
import type { MenuConfig } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.insert': { order: -1 },
  'ribbon.start.format': { order: -1 },
  'sheet.command.set-range-font-family': {
    order: 0,
    gridLayout: { row: 1, column: 1, width: 160 },
  },
}
```

## 선택 및 드래그 [#selection-interaction]

### 워크시트 경계에서 키보드 이동 [#keyboard-navigation]

`allowArrowKeyWrapOnSheetBoundary`는 워크 시트 가장자리에서 다음 행 또는 열에 화살표 키 랩을 결정합니다. 그것은 `true`에 기본적으로 설정; 가장자리에 정지 `false`로 설정. 입력 / 트랙 사이클링 선택 범위 내에서 영향을받지 않습니다. 미리 설정 모드에서, `sheets` 아래 설정; 플러그인 모드에서, `UniverSheetsUIPlugin`에서 직접 전달.

`selectionAnimation: false`는 셀 사이의 선택 이동 할 때 선택 개요 애니메이션을 비활성화합니다. 시스템 감소 모션 선호도가 우선합니다. `enableFillHandle: false`는 명령과 Facade API를 채우면서 채우기 핸들을 숨깁니다. `warnBeforeDragOverwrite: false`는 기존 콘텐츠를 드래그하기 전에 확인 프롬프트를 건너 뛸 수 있습니다. 유효성 및 undo/redo를 여전히 적용하십시오. `true`의 모든 세 가지 옵션 기본값으로 전달하십시오. `sheets`에서 `UniverSheetsCorePreset` 또는 `UniverSheetsUIPlugin`에 직접 전달하십시오.

## Facade API로 메뉴 업데이트 [#menu-facade]

### 런타임 업데이트

공개 Facade는 변경 사항을 병합하고 UI를 즉시 새로 고침합니다. 이전 값 또는 스키마 기본값을 유지하고, 오버라이드는 나중에 등록 된 메뉴에 적용됩니다. 플러그인 모드에서 `@univerjs/ui/facade`를 먼저 가져 가라.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'sheet.command.set-range-bold': {
    order: 0,
    gridLayout: { row: 2, column: 2 },
  },
  'sheet.command.set-range-italic': {
    gridLayout: { row: 2, column: 1 },
  },
})
```

`gridLayout`는 단지 `ribbonType: 'grid'`를 가진 효력이 있습니다. 각 그룹에는 2개의 줄 및 `row` 및 `column` 시작이 있습니다 1. 협조는 명시되어 있습니다, 그래서 단지 `order`만 바꾸는 것은 명시적으로 두는 단추를 이동하지 않습니다. 2개의 단추가 교환될 때, 둘 다 개정되어야 합니다, 또는 그들은 오버랩. 선택적인 분야는 화소에 있는 크기와 더불어 `rowSpan`, `columnSpan`, `showLabel`, `width` 및 `iconSize`입니다. [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout)는 constraints 및 과태를 목록으로 만듭니다.

### 사용자 정의 메뉴 배치

`createMenu()`와 `createSubmenu()`는 또한 `order` 및 `gridLayout`를 받아들입니다. submenu에, 이 분야는 팝업의 내용 보다는 오히려 리본 방아쇠를 둡니다. 뒤에 오는 예는 역사 그룹의 제 3의 란에 있는 단추를 추가합니다:

```ts
univerAPI
  .createMenu({
    id: 'custom-action',
    title: 'Custom action',
    action: () => console.log('Custom action clicked'),
    order: 4,
    gridLayout: { row: 1, column: 3, showLabel: true, width: 96 },
  })
  .appendTo('ribbon.start.history')
```
