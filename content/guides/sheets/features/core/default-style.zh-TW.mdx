預設樣式分為兩級：
1. 工作表的預設樣式
2. 列或行的預設樣式

兩種預設樣式都可以透過 [`IWorksheetData`](/reference/types/worksheet-data) 介面或 Facade API 設定。

## 外掛設定 [#plugin-configuration]

`UniverSheetsPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `isRowStylePrecedeColumnStyle` | `boolean` | `false` | 使行樣式優先於列樣式。 |
| `textLineGap` | `number` | `0` | 單元格文字的額外行距，單位為畫素。 |

## 預設設定 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>sheets</ConfigKey> | `object` |  | 所選功能的配置項。 |
| <ConfigKey depth={1}>isRowStylePrecedeColumnStyle</ConfigKey> | `boolean` | `false` | 使行樣式優先於列樣式。 |
| <ConfigKey depth={1}>textLineGap</ConfigKey> | `number` | `0` | 單元格文字的額外行距，單位為畫素。 |

## 列欄樣式優先順序

預設情況下，列樣式優先於行樣式。在註冊時設定 `isRowStylePrecedeColumnStyle` 可以反轉這一順序。

請根據接入方式選擇對應的標籤頁，並將這些選項合併到現有的初始化配置中。其他外掛、語言、主題和容器配置保持不變，不要重複註冊同一個外掛。

<Tabs items={['外掛模式', '預設模式']}>
  <Tab>
    ```typescript
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, {
      isRowStylePrecedeColumnStyle: true,
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          sheets: {
            isRowStylePrecedeColumnStyle: true,
          },
        }),
      ],
    })
    ```
  </Tab>
</Tabs>

## 儲存格文字行距 [#text-line-gap]

`textLineGap` 用於設定單元格文字的行距，單位為畫素，富文字和單元格編輯器同樣適用。該選項只能在初始化時設定，作用於該 Univer 例項中的所有工作簿。預設值為 `0`，取值必須是有限的非負數。

<TextLineGapDemo />

<Tabs items={['外掛模式', '預設模式']}>
  <Tab>
    ```ts
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, { textLineGap: 6 })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [UniverSheetsCorePreset({ sheets: { textLineGap: 6 } })],
    })
    ```
  </Tab>
</Tabs>

增大行距不會改變已有的行高。需要額外空間時，應重新計算自動行高；固定行高的單元格可能裁剪文字。該選項是例項級配置，不是單個單元格的段落樣式。

## 設定預設樣式

工作表的預設樣式有兩種設定方式：

1. 透過 [`IWorksheetData`](/guides/sheets/model/worksheet-data) 介面

```typescript
interface IWorksheetData {
  // other
  /**
   * @property {Nullable<IStyleData>} [defaultStyle] - Default style data of Worksheet.
   */
  defaultStyle?: Nullable<IStyleData>
}

interface IRowData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}

interface IColumnData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}
```

2. 透過 Facade API

```typescript
const fworkbook = univerAPI.getActiveWorkbook()
const fworksheet = fworkbook.getActiveSheet()
const defaultStyle = {
  bg: {
    rgb: 'red',
  },
}
const defaultColumnStyle = {
  bg: {
    rgb: 'blue',
  },
}
const defaultRowStyle = {
  bg: {
    rgb: 'green',
  },
}

// 設定預設樣式
fworksheet.setDefaultStyle(defaultStyle)
// 設定列 D 的預設樣式
fworksheet.setColumnDefaultStyle(3, defaultColumnStyle)
// 重置列 D 的預設樣式
fworksheet.setColumnDefaultStyle(3, undefined)

// 設定行預設樣式
fworksheet.setRowDefaultStyle(1, defaultRowStyle)
```

## 縮小字型以符合儲存格

當文字寬度超過單元格寬度時，可以使用 `FRange` 縮小字型。該設定作用於範圍內的每個單元格；`getShrinkToFit()` 返回左上角單元格的狀態。

```ts
const range = univerAPI.getActiveWorkbook().getActiveSheet().getRange('A1:C3')

range.setShrinkToFit(true)
const enabled = range.getShrinkToFit()
```

縮小字型填充與自動換行互斥：啟用自動換行會禁用縮小字型填充，啟用縮小字型填充會清除這些單元格原有的自動換行。
