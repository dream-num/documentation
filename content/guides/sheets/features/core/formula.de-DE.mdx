Formeln sind eine der Kernfunktionen von Univer und ermöglichen Ihnen die Verwendung von Formeln in Zellen zur Berechnung von Werten. Die von Formeln unterstützten Funktionen sind mit Excel konsistent, einschließlich mathematischer, logischer, Text-, Datumsfunktionen und mehr.

Wenn eine Arbeitsmappe eine große Anzahl von Formeln enthält, belegt die Formelberechnung möglicherweise den Hauptthread und führt dazu, dass die Seite weniger reagiert. Wir empfehlen, die Formelberechnung in einem Worker-Prozess auszuführen, um deren Auswirkungen auf das Rendering und die Benutzerinteraktion zu reduzieren. Einzelheiten zur Konfiguration finden Sie unter [Web Workers](/guides/sheets/features/core/worker).

## Konfiguration

Es folgen die Links zu den Konfigurationselementen im Zusammenhang mit dem Formel-Plugin:

| Plugin | Konfigurationselement |
| --- | --- |
| `@univerjs/engine-formula` | [IUniverEngineFormulaConfig](/reference/packages/plugins/univerjs/engine-formula) |
| `@univerjs/sheets-formula` | [IUniverSheetsFormulaBaseConfig](/reference/packages/plugins/univerjs/sheets-formula) |

### Voreinstellungskonfiguration

```typescript
import type { CalculationMode } from '@univerjs/preset-sheets-core'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'

interface IUniverSheetsCorePresetConfig {
  formula?: {
    // Custom formula functions
    function?: Array<[Ctor<BaseFunction>, IFunctionNames]>
    // Custom formula descriptions
    description?: IFunctionInfo[]
    // Defines the calculation mode for formulas during data initialization, default is `WHEN_EMPTY`
    initialFormulaComputing?: CalculationMode
  }
}
```

### Plugin-Konfiguration

```typescript
import type { CalculationMode } from '@univerjs/sheets-formula'
import { UniverSheetsFormulaPlugin } from '@univerjs/sheets-formula'

interface IUniverSheetsFormulaConfig {
  // Custom formula functions
  function?: Array<[Ctor<BaseFunction>, IFunctionNames]>
  // Custom formula descriptions
  description?: IFunctionInfo[]
  // Defines the calculation mode for formulas during data initialization, default is `WHEN_EMPTY`
  initialFormulaComputing?: CalculationMode
}
```

Die Definition von `CalculationMode` lautet wie folgt:

```typescript
enum CalculationMode {
  /**
   * Force calculation of all formulas
   */
  FORCED,

  /**
   * Partial calculation, only calculates cells with formulas but no value
   */
  WHEN_EMPTY,

  /**
   * No calculation for all formulas
   */
  NO_CALCULATION,
}
```

> Wenn die Zelle, die die Formel enthält, einen unerwarteten Wert hat, haben Sie kann `initialFormulaComputing` auf `CalculationMode.FORCED` setzen, um die Berechnung aller Formeln zu erzwingen. Alternativ können Sie den Wert `v` der Zelle vor der Initialisierung löschen.

## Arbeitsmappenübergreifende und 3D-Bezüge

Formeln können eine geladene Arbeitsmappe über ihren Anzeigenamen oder einen einschließlich beider Enden definierten Blattbereich in Arbeitsmappenreihenfolge referenzieren:

```text
=SUM('[Sales.xlsx]Data'!A1:A10)
=SUM(Sales.xlsx!SalesTable[Amount])
=SUM(Jan:Mar!B2:C3)
=SUM('Jan':'Mar'!B2)
```

Arbeitsmappennamen werden ohne Beachtung der Groß-/Kleinschreibung abgeglichen; beim Ersatzabgleich werden übliche Excel-Erweiterungen ignoriert. Ein fehlender oder mehrdeutiger Name ergibt `#REF!`.

### Importieren

<Callout type="info" title="Plugin mode note">
Nur im Plugin-Modus muss das Facade-Paket manuell importiert werden. Der Voreinstellungsmodus enthält bereits das entsprechende Facade-Paket, sodass kein zusätzlicher Import erforderlich ist.
</Callout>

```typescript
import '@univerjs/engine-formula/facade'
import '@univerjs/sheets-formula/facade'
import '@univerjs/sheets-formula-ui/facade'
```

### Bereichsauswahldialog anzeigen

`@univerjs/sheets-formula-ui/facade` fügt `univerAPI.showRangeSelectorDialog` hinzu. Verwenden Sie es, wenn Ihre benutzerdefinierte Benutzeroberfläche erfordert, dass Benutzer einen oder mehrere Bereiche mit demselben Selektor auswählen, der von formelbezogenen Bedienfeldern verwendet wird.

```typescript
const workbook = univerAPI.getActiveWorkbook()
const worksheet = workbook?.getActiveSheet()

if (workbook && worksheet) {
  await univerAPI.showRangeSelectorDialog({
    unitId: workbook.getId(),
    subUnitId: worksheet.getSheetId(),
    initialValue: [
      {
        unitId: workbook.getId(),
        sheetName: worksheet.getSheetName(),
        range: worksheet.getRange('A1:B2').getRange(),
      },
    ],
    maxRangeCount: 2,
    supportAcrossSheet: true,
    callback: (ranges, isCancel) => {
      console.log(ranges, isCancel)
    },
  })
}
```

### Formelberechnung ausführen

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.executeCalculation()
```

### Formelberechnung stoppen

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.stopCalculation()
```

### Formelberechnung starten

```typescript
// Listening to formula calculation start event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationStart((forceCalculate) => {
  console.log(forceCalculate)
})
```

### Verarbeitung der Formelberechnung

```typescript
// Listening to formula calculation processing event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationProcessing((stageInfo) => {
  console.log(stageInfo)
})
```

### Ende der Formelberechnung

```typescript
// Listening to formula calculation end event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationEnd((functionsExecutedState) => {
  console.log(functionsExecutedState)
})
```

### Ergebnis der Formelberechnung angewendet

```typescript
// Listening to formula calculation result applied event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationResultApplied((result) => {
  console.log(result)
})

// Wait for formula calculation result to be applied
await formulaEngine.onCalculationResultApplied()
```

### Formelberechnungsmodus beim Initialisieren von Daten festlegen

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.setInitialFormulaComputing(CalculationMode.FORCED)
```

Wenn Diese API wird nach dem `Starting`-Lebenszyklus aufgerufen und wird beim nächsten Erstellen eines Univer Sheet wirksam.

Wenn Sie möchten, dass sie während der aktuellen Initialisierung des Univer Sheet wirksam wird, können Sie erwägen, sie vor dem `Ready`-Lebenszyklus aufzurufen, zum Beispiel:

```typescript
univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === LifecycleStages.Starting) {
    const formulaEngine = univerAPI.getFormula()
    formulaEngine.setInitialFormulaComputing(CalculationMode.FORCED)
  }
})
```

### Maximale Iteration festlegen

Wenn Zirkelverweise in Formeln vorhanden sind, können Sie diese API zum Festlegen verwenden die maximale Anzahl von Iterationen für Formelberechnungen. Der Standardwert ist 1.

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.setMaxIteration(10)
```

### Ausführungsergebnis der Formelzeichenfolgen abrufen

Führen Sie einen Stapel von Formeln asynchron aus und erhalten Sie Berechnungsergebnisse:

```typescript
const formulaEngine = univerAPI.getFormula()
const formulas = {
  Book1: {
    Sheet1: {
      2: {
        3: [
          // Full formula:
          '=SUM(A1:A10) + SQRT(D7)',

          // Decomposed sub-formulas (each one can be evaluated independently):
          'SUM(A1:A10)', // sub-formula 1
          'SQRT(D7)', // sub-formula 2
          'A1:A10', // range reference
          'D7', // single-cell reference
        ],
      },
      4: {
        5: [
          '=A2 + B2 + SQRT(C5)',
          'A2',
          'B2',
          'SQRT(C5)',
        ],
      },
    },
  },
}
const result = await formulaEngine.executeFormulas(formulas)
console.log(result)
```
