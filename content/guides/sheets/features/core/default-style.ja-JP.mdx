デフォルトスタイルは2つのレベルに存在します。
1. ワークシート全体の既定スタイル
2. 列または行のデフォルトスタイル

[`IWorksheetData`](/reference/types/worksheet-data)インターフェイスまたはFacade APIを介していずれかを設定できます。

## プラグイン設定 [#plugin-configuration]

`UniverSheetsPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `isRowStylePrecedeColumnStyle` | `boolean` | `false` | 列スタイルを列スタイルで優先する行スタイルを作る。 |
| `textLineGap` | `number` | `0` | セル内の追加行間（ピクセル）。 |

## プリセット設定 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>sheets</ConfigKey> | `object` |  | 選択された機能の構成。 |
| <ConfigKey depth={1}>isRowStylePrecedeColumnStyle</ConfigKey> | `boolean` | `false` | 列スタイルを列スタイルで優先する行スタイルを作る。 |
| <ConfigKey depth={1}>textLineGap</ConfigKey> | `number` | `0` | セル内の追加行間（ピクセル）。 |

## 行と列のスタイルの優先順位

デフォルトでは、列のスタイルは行のスタイルに優先されます。登録時に`isRowStylePrecedeColumnStyle`を設定して、この順序を逆転させます。

Univer 設定にマッチするタブを選択し、これらのオプションを既存の初期化にマージします。他のプラグイン、ローカライズ、テーマ、およびコンテナの設定は変更されず、同じプラグインを2回登録しないでください。

<Tabs items={['プラグインモード', 'プリセットモード']}>
  <Tab>
    ```typescript
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, {
      isRowStylePrecedeColumnStyle: true,
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          sheets: {
            isRowStylePrecedeColumnStyle: true,
          },
        }),
      ],
    })
    ```
  </Tab>
</Tabs>

## セルのテキスト行間 [#text-line-gap]

`textLineGap`は、リッチテキストとセルエディタを含む、セルテキストの行間をピクセル単位で追加スペースを追加します。 初期化中に設定します。 Univerインスタンス内のすべてのワークブックに適用されます。 デフォルトは`0`であり、値は有限かつ非負である必要があります。

<Tabs items={['プラグインモード', 'プリセットモード']}>
  <Tab>
    ```ts
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, { textLineGap: 6 })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [UniverSheetsCorePreset({ sheets: { textLineGap: 6 } })],
    })
    ```
  </Tab>
</Tabs>

より大きなギャップは、既存の行のサイズを変更しません。 追加のスペースが必要である場合、自動行の高さを再計算します。 固定高さのあるセルはテキストをクリップすることができます。 これは、インスタンスレベルの設定であり、セルパラグラフスタイルではありません。

## 既定スタイルの設定方法

ワークシートのデフォルトスタイルを2つの方法で設定できます。

1. [`IWorksheetData`](/reference/types/worksheet-data) インターフェイス経由

```typescript
interface IWorksheetData {
  // その他
  /**
   * @property {Nullable<IStyleData>} [defaultStyle] - ワークシート全体の既定スタイル。
   */
  defaultStyle?: Nullable<IStyleData>
}

interface IRowData {
  // その他
  /**
   * 行スタイルデータ
   */
  s?: Nullable<IStyleData>
}

interface IColumnData {
  // その他
  /**
   * 列スタイルデータ
   */
  s?: Nullable<IStyleData>
}
```

2. Facade APIを通して

```typescript
const fworkbook = univerAPI.getActiveWorkbook()
const fworksheet = fworkbook.getActiveSheet()
const defaultStyle = {
  bg: {
    rgb: 'red',
  },
}
const defaultColumnStyle = {
  bg: {
    rgb: 'blue',
  },
}
const defaultRowStyle = {
  bg: {
    rgb: 'green',
  },
}

// ワークシート既定スタイルを設定
fworksheet.setDefaultStyle(defaultStyle)
// 列 D (インデックス 3) の既定スタイルを設定
fworksheet.setColumnDefaultStyle(3, defaultColumnStyle)
// 列 D の既定スタイルをリセット
fworksheet.setColumnDefaultStyle(3, undefined)

// 行 (インデックス 1) の既定スタイルを設定
fworksheet.setRowDefaultStyle(1, defaultRowStyle)
```

## テキストを縮小してセルに合わせる

`FRange`は、そのセルよりも広いテキストを縮小することができます。設定は、範囲内のすべてのセルに適用され、`getShrinkToFit()`が左上のセルの状態を返します。

```ts
const range = univerAPI.getActiveWorkbook().getActiveSheet().getRange('A1:C3')

range.setShrinkToFit(true)
const enabled = range.getShrinkToFit()
```

収縮対フィットとテキストのラッピングは、相互に排他的です。テキストラッピングを有効にすると、縮小対フィットが無効になり、現在ラップしている任意のセルでラッピングを縮小対フィットすることを可能にします。
