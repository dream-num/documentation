title: Copiar y pegar
---

<Callout type="warning" title="Nota de compatibilidad de Firefox">
  Firefox no admite `clipboard.readText()`. Ver [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText) para más detalles. En ese caso Univer lee el portapapeles del evento de pasta, por lo que el pegado funciona sólo con el acceso directo del teclado.
</Callout>

Univer implementa copia y pega con la API de Clipboard. El contenido se puede copiar de aplicaciones externas a Univer, desde Univer a aplicaciones externas, y entre las hojas Univer.

<Callout type="warning" title="Requisitos de Contexto de Seguridad">
  Las políticas modernas de seguridad del navegador permiten a la API de Clipboard sólo en un contexto seguro, como HTTPS.
</Callout>

Univer admite las siguientes funciones de copiar y pegar operaciones:

- Copia y pega de aplicaciones externas en Univer
- Copiado desde Univer en aplicaciones externas
- Copiar y pegar entre las hojas Univer

La pasta selectiva cubre estos casos:

- Pegar solo valores
- Pegar solo formatos
- Pegar solo anchos de columna
- Contenido de sabor sin fronteras
- Pegar solo fórmulas

En la cinta de escritorio, la desplegable **Paste** junto a deshacer y redo proporciona pasta normal, valores de pasta, formatos de pasta, anchos de columna de pasta y pasta sin fronteras. Su ID de menú es `sheet.menu.paste`; la entrada context-menu **Pegado especial** utiliza `sheet.menu.paste-special`. La desplegación de cinta está oculta mientras se edita texto de forma.

## Desactivar copia

**Control de las misiones** puede deshabilitar la copia para un libro de trabajo completo o para hojas de trabajo específicas.

El siguiente código desactiva la copia del libro de trabajo actual:

```typescript
const workbookPermission = univerAPI.getActiveWorkbook()?.getWorkbookPermission()
const WorkbookCopyPermission = univerAPI.Enum.WorkbookPermissionPoint.CopyContent

if (workbookPermission) {
  workbookPermission.setPoint(WorkbookCopyPermission, false)
}
```

Para obtener más información sobre los permisos, consulte [Control de permisos](/guides/sheets/features/core/permission).
