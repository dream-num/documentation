title: Copiar y pegar
---

<Callout type="warning" title="Firefox Compatibility Note">
Firefox no admite `clipboard.readText()`, consulte [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText). En este caso, Univer solo puede recuperar el contenido del portapapeles del evento de pegado, por lo que solo admite el pegado de métodos abreviados de teclado.
</Callout>

Univer usa la API del Portapapeles para implementar la funcionalidad de copiar y pegar, lo que permite copiar y pegar desde aplicaciones externas a Univer, de Univer a aplicaciones externas y entre Univer Sheets.

<Callout type="warning" title="Security Context Requirement">
Debido a las políticas de seguridad modernas del navegador, la API del Portapapeles solo se puede usar en contextos seguros (como HTTPS).
</Callout>

Univer admite las siguientes funciones de copiar y pegar operaciones:

- Copiar y pegar desde aplicaciones externas a Univer
- Copiar desde Univer a aplicaciones externas
- Copiar y pegar entre hojas de Univer

Y admite las siguientes capacidades de pegado selectivo:

- Pegar solo valores
- Pegar solo formatos
- Pegar solo anchos de columna
- Pegar contenido excluyendo bordes únicamente
- Pegar solo fórmulas

## Desactivar copia

Univer permite a los desarrolladores desactivar la función de copia para los usuarios en un libro de trabajo o en hojas específicas mediante **permiso control**.

Por ejemplo, el siguiente código deshabilita la función de copia para los usuarios en el libro actual:

```typescript
const workbookPermission = univerAPI.getActiveWorkbook()?.getWorkbookPermission()
const WorkbookCopyPermission = univerAPI.Enum.WorkbookPermissionPoint.CopyContent

if (workbookPermission) {
  workbookPermission.setPoint(WorkbookCopyPermission, false)
}
```

Para obtener más información sobre el control de permisos, consulte la documentación [Control de permisos](/guides/sheets/features/core/permission).
