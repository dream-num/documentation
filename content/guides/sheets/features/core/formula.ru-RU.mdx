Формулы — одна из ключевых возможностей Univer. Они позволяют выполнять вычисления в ячейках. Поддерживаемые функции совместимы с Excel и включают математические, логические, текстовые функции, функции для работы с датами и многие другие.

Если книга содержит много формул, их вычисление может занять основной поток и снизить отзывчивость страницы. Рекомендуется выполнять вычисления формул в процессе Worker, чтобы уменьшить влияние на отрисовку и взаимодействие с пользователем. Подробнее о настройке см. в разделе [Web Workers](/guides/sheets/getting-started/worker).

## Настройка

Ниже приведены ссылки на параметры конфигурации плагинов формул:

| Плагин                     | Параметр конфигурации                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------- |
| `@univerjs/engine-formula` | [IUniverEngineFormulaConfig](/reference/packages/plugins/univerjs/engine-formula)     |
| `@univerjs/sheets-formula` | [IUniverSheetsFormulaBaseConfig](/reference/packages/plugins/univerjs/sheets-formula) |

### Настройка предустановки

```typescript
import type { CalculationMode } from '@univerjs/preset-sheets-core'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'

interface IUniverSheetsCorePresetConfig {
  formula?: {
    // Custom formula functions
    function?: Array<[Ctor<BaseFunction>, IFunctionNames]>
    // Custom formula descriptions
    description?: IFunctionInfo[]
    // Defines the calculation mode for formulas during data initialization, default is `WHEN_EMPTY`
    initialFormulaComputing?: CalculationMode
  }
}
```

### Настройка плагина

```typescript
import type { CalculationMode } from '@univerjs/sheets-formula'
import { UniverSheetsFormulaPlugin } from '@univerjs/sheets-formula'

interface IUniverSheetsFormulaConfig {
  // Custom formula functions
  function?: Array<[Ctor<BaseFunction>, IFunctionNames]>
  // Custom formula descriptions
  description?: IFunctionInfo[]
  // Defines the calculation mode for formulas during data initialization, default is `WHEN_EMPTY`
  initialFormulaComputing?: CalculationMode
}
```

Перечисление `CalculationMode` определено следующим образом:

```typescript
enum CalculationMode {
  /**
   * Force calculation of all formulas
   */
  FORCED,

  /**
   * Partial calculation, only calculates cells with formulas but no value
   */
  WHEN_EMPTY,

  /**
   * No calculation for all formulas
   */
  NO_CALCULATION,
}
```

> Если ячейка с формулой содержит неожиданное значение, задайте для `initialFormulaComputing` значение `CalculationMode.FORCED`, чтобы принудительно вычислить все формулы. Другой вариант — очистить значение `v` этой ячейки перед инициализацией.

## Ссылки между книгами

Формула может суммировать в `Report` продажи из `Sales.xlsx`. В отличие от ссылки на другой лист той же книги, здесь указывается и книга-источник.

### Синтаксис ссылок

| Сценарий | Пример | Источник |
| --- | --- | --- |
| Другой лист той же книги | `=SUM(Data!A1:A10)` | Лист Data текущей книги |
| Диапазон другой книги | `=SUM('[Sales.xlsx]Data'!A1:A10)` | Лист Data книги Sales.xlsx |
| Таблица другой книги | `=SUM(Sales.xlsx!SalesTable[Amount])` | Столбец Amount существующей таблицы SalesTable |

`Sales.xlsx` — имя книги, а не путь или URL. Запись формулы не читает файл, не скачивает Excel и не подключается к редактору на другой странице. Для структурированной ссылки сначала создайте соответствующую [таблицу](/guides/sheets/features/table).

### Ссылки на книги в одном экземпляре

При использовании базового движка загрузите обе книги в один экземпляр Univer и одну среду вычислений. Выполните пример после инициализации Sheets. В режиме плагинов также импортируйте расширения Facade, указанные на этой странице.

```typescript
const source = univerAPI.createWorkbook({
  id: 'sales-workbook',
  name: 'Sales.xlsx',
  sheetOrder: ['sales-data'],
  sheets: {
    'sales-data': {
      id: 'sales-data',
      name: 'Data',
      rowCount: 100,
      columnCount: 20,
      cellData: {
        0: { 0: { v: 100 } },
        1: { 0: { v: 200 } },
      },
    },
  },
}, { makeCurrent: false })

const report = univerAPI.createWorkbook({ id: 'report-workbook', name: 'Report' })
const resultCell = report.getActiveSheet().getRange('A1')
resultCell.setFormula("=SUM('[Sales.xlsx]Data'!A1:A2)")

const formula = univerAPI.getFormula()
formula.executeCalculation()
await formula.onCalculationResultApplied()
console.log(resultCell.getValue()) // 300
```

`makeCurrent: false` загружает источник, не меняя активную книгу. Сохраняйте `source` и `report`, чтобы не записать формулу в другую книгу после переключения.

Имена сравниваются без учёта регистра. Полное совпадение имеет приоритет; если его нет, игнорируются расширения Excel, например `.xlsx` и `.xlsm`. Отсутствующее или неоднозначное имя даёт `#REF!`. Используйте уникальные имена.

### Привязка к постоянному ID источника

Чтобы связать имя в формуле с постоянным ID документа, используйте Pro-расширение `@univerjs-pro/engine-formula`. Настройте [клиентскую лицензию](/guides/license), замените `UniverFormulaEnginePlugin` на `UniverProFormulaEnginePlugin` при инициализации и импортируйте Pro Facade. Не регистрируйте оба движка. Один импорт Facade не регистрирует плагин.

Пример использует книги выше в среде с настроенным Pro-движком:

```typescript
import '@univerjs-pro/engine-formula/facade'

const reference = univerAPI.getFormula().buildReference({
  hostUnitId: report.getId(),
  unit: {
    unitId: source.getId(),
    formulaQualifier: 'Sales Source',
  },
  target: {
    kind: univerAPI.Enum.FormulaReferenceType.SHEET_RANGE,
    sheetName: 'Data',
    range: { startRow: 0, endRow: 1, startColumn: 0, endColumn: 0 },
  },
})

resultCell.setFormula(`=SUM(${reference})`)
```

`hostUnitId` — ID книги с формулой, `unit.unitId` — постоянный ID источника, `formulaQualifier` — его публичное имя в формуле. Координаты начинаются с нуля и включают конечную границу.

`buildReference()` возвращает фрагмент без `=` и сохраняет привязку. Он не загружает источник и не запускает вычисления. Данные должны поступать из книги, загруженной в среду вычислений, или настроенного поставщика данных. Для написанной вручную или сгенерированной формулы сначала создайте привязку:

```typescript
const formula = univerAPI.getFormula()
const bound = formula.upsertExternalReference({
  unitId: report.getId(),
  qualifier: 'Sales Source',
  sourceUnitId: source.getId(),
  sourceUnitType: univerAPI.Enum.UniverInstanceType.UNIVER_SHEET,
})
if (!bound) throw new Error('Could not bind Sales Source')

resultCell.setFormula("=SUM('[Sales Source]Data'!A1:A2)")
```

Повторная запись той же привязки идемпотентна. В `qualifier` не нужны скобки или кавычки. Положительные целые числа вроде `1` и `2` зарезервированы для слотов внешних ссылок Excel, а не ID документов. При импорте сохраняйте ресурсы внешних ссылок: одного текста формулы недостаточно.

### Обновление, сохранение и выгрузка

После изменения источника через Facade запустите вычисления и дождитесь применения результатов перед чтением. Возврат из `setFormula()` или `setValue()` не означает завершения асинхронного расчёта.

```typescript
const sourceSheet = source.getSheetBySheetId('sales-data')
if (!sourceSheet) throw new Error('Source sheet not found')
sourceSheet.getRange('A1').setValue(150)
formula.executeCalculation()
await formula.onCalculationResultApplied()
console.log(resultCell.getValue()) // 350
```

Используйте `report.save()` для сохранения полного снимка с ресурсами привязок. Сохранение только формул теряет соответствие имён и ID. Данные источника сохраняются и загружаются отдельно.

После выгрузки источника обычная ссылка на загруженную книгу больше не может его читать. Продолжение расчётов Pro-ссылок зависит от поставщиков данных и доступного кеша. Привязка не содержит данных и не гарантирует автономный расчёт. Старое значение на экране не доказывает актуальность результата.

Ненужную Pro-привязку можно удалить:

```typescript
univerAPI.getFormula().removeExternalReference({
  unitId: report.getId(),
  qualifier: 'Sales Source',
})
```

Удаление не стирает и не переписывает формулы. При следующем расчёте имя разрешается заново: может найтись загруженная книга с таким именем, иначе вернётся `#REF!`. Чтобы прекратить ссылку, измените или очистите и саму формулу. Полные параметры приведены в [API ссылок FFormula](/reference/facade/formula#cross-unit-reference-authoring).

## Трёхмерные ссылки

Трёхмерная ссылка охватывает последовательные листы одной книги и отличается от ссылки между книгами.

```text
=SUM(Jan:Mar!B2:C3)
=SUM('Jan':'Mar'!B2)
```

Диапазон включает Jan, Mar и все листы между ними в порядке книги, а не по алфавиту. После перестановки листов проверьте диапазон суммирования.

### Открытие диалогового окна выбора диапазона

Пакет `@univerjs/sheets-formula-ui/facade` добавляет метод `univerAPI.showRangeSelectorDialog`. Используйте его, если в вашем интерфейсе пользователю нужно выбрать один или несколько диапазонов с помощью того же инструмента, который применяется в панелях для работы с формулами.

```typescript
const workbook = univerAPI.getActiveWorkbook()
const worksheet = workbook?.getActiveSheet()

if (workbook && worksheet) {
  await univerAPI.showRangeSelectorDialog({
    unitId: workbook.getId(),
    subUnitId: worksheet.getSheetId(),
    initialValue: [
      {
        unitId: workbook.getId(),
        sheetName: worksheet.getSheetName(),
        range: worksheet.getRange('A1:B2').getRange(),
      },
    ],
    maxRangeCount: 2,
    supportAcrossSheet: true,
    callback: (ranges, isCancel) => {
      console.log(ranges, isCancel)
    },
  })
}
```

### Запуск вычисления формул

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.executeCalculation()
```

### Остановка вычисления формул

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.stopCalculation()
```

### Начало вычисления формул

```typescript
// Listening to formula calculation start event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationStart((forceCalculate) => {
  console.log(forceCalculate)
})
```

### Процесс вычисления формул

```typescript
// Listening to formula calculation processing event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationProcessing((stageInfo) => {
  console.log(stageInfo)
})
```

### Завершение вычисления формул

```typescript
// Listening to formula calculation end event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationEnd((functionsExecutedState) => {
  console.log(functionsExecutedState)
})
```

### Применение результатов вычисления формул

```typescript
// Listening to formula calculation result applied event
const formulaEngine = univerAPI.getFormula()
formulaEngine.calculationResultApplied((result) => {
  console.log(result)
})

// Wait for formula calculation result to be applied
await formulaEngine.onCalculationResultApplied()
```

### Установка режима вычисления формул при инициализации данных

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.setInitialFormulaComputing(CalculationMode.FORCED)
```

Если вызвать этот API после этапа жизненного цикла `Starting`, настройка вступит в силу при следующем создании Univer Sheet.

Чтобы применить её во время текущей инициализации Univer Sheet, вызовите API до этапа жизненного цикла `Ready`, например:

```typescript
univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === LifecycleStages.Starting) {
    const formulaEngine = univerAPI.getFormula()
    formulaEngine.setInitialFormulaComputing(CalculationMode.FORCED)
  }
})
```

### Установка максимального количества итераций

Если в формулах есть циклические ссылки, с помощью этого API можно задать максимальное количество итераций вычисления. По умолчанию выполняется одна итерация.

```typescript
const formulaEngine = univerAPI.getFormula()
formulaEngine.setMaxIteration(10)
```

### Получение результатов выполнения строковых формул

Метод асинхронно выполняет пакет формул и возвращает результаты вычислений:

```typescript
const formulaEngine = univerAPI.getFormula()
const formulas = {
  Book1: {
    Sheet1: {
      2: {
        3: [
          // Full formula:
          '=SUM(A1:A10) + SQRT(D7)',

          // Decomposed sub-formulas (each one can be evaluated independently):
          'SUM(A1:A10)', // sub-formula 1
          'SQRT(D7)', // sub-formula 2
          'A1:A10', // range reference
          'D7', // single-cell reference
        ],
      },
      4: {
        5: ['=A2 + B2 + SQRT(C5)', 'A2', 'B2', 'SQRT(C5)'],
      },
    },
  },
}
const result = await formulaEngine.executeFormulas(formulas)
console.log(result)
```
