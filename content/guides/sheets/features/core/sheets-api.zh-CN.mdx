title: Univer Sheets API
---

Univer Sheets 提供完整的电子表格引擎，其概念设计尽可能与 Microsoft Excel 保持一致。

## 引入

```typescript
import '@univerjs/sheets/facade'
import '@univerjs/sheets-ui/facade'
```

## 工作簿 Workbook

一个工作簿包含一个或多个工作表，相当于一个 Excel 文件。

`unitId` 是工作簿的唯一标识。

### 创建工作簿

[`univerAPI.createWorkbook(data, options)`](https://docs.univer.ai/reference/facade/univer#createworkbook) 会创建并返回 `FWorkbook` 对象。

[`IWorkbookData`](/guides/sheets/model/workbook-data) 描述工作簿的配置信息。

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' })
console.log(fWorkbook)
```

如果新建的工作簿不应成为活动工作簿，可以传入选项对象：

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' }, { makeCurrent: false })
console.log(fWorkbook)

// 3s 后如果想切换到此工作簿
setTimeout(() => {
  univerAPI.setCurrent(fWorkbook.getId())
}, 3000)
```

### 获取工作簿数据 [#get-workbook-data]

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
console.log(snapshot)
```

### 销毁工作簿

不再需要某个工作簿时，调用 `FUniver` 上的 `disposeUnit` 方法即可将其卸载。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook?.getId()
if (unitId) {
  univerAPI.disposeUnit(unitId)
}
```

<Callout type="warning">
  承载 Univer 实例的页面被销毁或路由被卸载时，应调用 `univer.dispose()` 进行清理，而不是调用 `univerAPI.disposeUnit`。`univer` 和 `univerAPI` 是两个不同的实例，如何获取这两个实例见 [安装和基本使用](/guides/sheets/getting-started/installation)。
</Callout>

### 获取工作簿 ID

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook?.getId()
```

## 工作表 Worksheet

工作表用于存放表格数据，每个工作表都属于一个工作簿。

一个工作簿可以包含多个工作表，同一工作簿中的工作表名称必须唯一。

`subUnitId` 在工作簿内唯一标识一个工作表。

### 获取工作表

获取工作簿中的全部工作表：

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const sheets = fWorkbook.getSheets()
```

获取当前激活的工作表：

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
```

### 获取工作表数据

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const sheetSnapshot = fWorksheet.getSheet().getSnapshot()
```

### 创建工作表 [#create-worksheet]

下面的示例使用 [`FWorkbook.create`](https://docs.univer.ai/reference/facade/workbook#create) 方法创建工作表。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// 创建一个名为 'Sheet2' 的工作表，包含 10 行和 10 列
const newSheet = fWorkbook.create('Sheet2', 10, 10)

// 创建一个名为 'MyNewSheetWithData' 的新工作表，包含 10 行和 10 列，并带有一些数据，且将其设置为第一个工作表
const sheetData = {
  // ... 省略其他属性
  cellData: {
    0: {
      0: {
        v: 'Hello Univer!',
      },
    },
  },
  // ... 省略其他属性
}
const newSheetWithData = fWorkbook.create('MyNewSheetWithData', 10, 10, {
  index: 0,
  sheet: sheetData,
})
console.log(newSheetWithData)
```

### 删除工作表

传入工作表实例或工作表 ID 即可删除对应的工作表。

```typescript
// 删除第二个工作表
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.deleteSheet(sheet)

// 下面的代码通过 id 删除指定的工作表
// fWorkbook.deleteSheet(sheet.getSheetId());
```

### 激活工作表

可以传入工作表实例或工作表 ID 来激活工作表，也可以直接调用 `FWorksheet.activate()` 方法。

```typescript
// 激活第二个工作表
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.setActiveSheet(sheet)

// 通过 id 激活指定的工作表
// fWorkbook.setActiveSheet(sheet.getSheetId());

// 通过 FWorksheet.activate() 方法激活工作表
// sheet.activate();
```

### 复制工作表

```typescript
// 以下代码用于复制指定的工作表
const fWorkbook = univerAPI.getActiveWorkbook()
const activeSheet = fWorkbook.getActiveSheet()
const duplicatedSheet = fWorkbook.duplicateSheet(activeSheet)
console.log(duplicatedSheet)
```

### 获取工作表 ID

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet?.getSheetId()
```

### 工作表标签颜色 [#tab-color]

右键单击工作表标签可打开颜色菜单，选择一种颜色，或选择“重置颜色”以移除自定义颜色并恢复默认外观。颜色选择器显示当前工作表的颜色。通过 Facade API 重置时，向 `setTabColor()` 传入空字符串；该修改支持撤销和重做。

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
sheet?.setTabColor('')
```

### 设置工作表行列数

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
// 设置行数为 100000
fWorksheet.setRowCount(100000)
// 设置列数为 30
fWorksheet.setColumnCount(30)
```

### 刷新工作表

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.refreshCanvas()
```

### 工作表缩放

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 200% 设置缩放比例为 200%
fWorksheet.zoom(2)
const zoomRatio = fWorksheet.getZoom()
```

### 滚动到指定位置

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 滚动到 D10 单元格
const fRange = fWorksheet.getRange('D10')
const row = fRange.getRow()
const column = fRange.getColumn()
fWorksheet.scrollToCell(row, column)

// 添加滚动动画持续时间
fWorksheet.scrollToCell(row, column, 1000)

// 获取滚动状态
const scrollState = fWorksheet.getScrollState()
const { offsetX, offsetY, sheetViewStartColumn, sheetViewStartRow } = scrollState
console.log(scrollState) // sheetViewStartRow: 9, sheetViewStartColumn: 3, offsetX: 0, offsetY: 0
```
