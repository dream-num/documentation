Univer Sheets 的核心功能包含了電子表格編輯器、公式引擎、渲染引擎、數字格式化引擎、設計系統和 UI 組件庫等。它們共同構成了一個強大的電子表格處理平台，支持多種電子表格格式和複雜的電子表格操作。

## 特性

Univer Sheets 的核心功能包括：

- **電子表格渲染**：支持 Univer Sheets 的渲染和游標、選區的繪製。
- **儲存格樣式**：支持對電子表格中的儲存格進行樣式設置，包括字體、顏色、邊框、對齊等。
- **公式計算**：支持在電子表格中添加和計算公式，支持幾乎所有的 Excel 公式，包括數學、統計、文本、日期等函數。
- **數字格式化**：支持對電子表格中的數字進行格式化，包括貨幣、百分比、日期等格式。
- **格線和凍結窗格**：支持顯示格線和凍結窗格功能，方便用戶查看和編輯大數據量的電子表格。
- **默認樣式**：支持對電子表格的默認樣式進行設置，包括默認字體、字號、顏色等。
- **插件系統**：支持插件系統，可以自定義插件，這也是 Univer 核心架構能力之一。

## 預設模式

### 安裝

```package-install
npm install @univerjs/presets @univerjs/preset-sheets-core
```

### 使用

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreZhCN from '@univerjs/preset-sheets-core/locales/zh-CN'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.ZH_CN,
  locales: {
    [LocaleType.ZH_CN]: mergeLocales(
      UniverPresetSheetsCoreZhCN,
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
  ],
})

univerAPI.createWorkbook({})
```

### 預設與配置

#### @univerjs/presets

本預設提供了創建 Univer 應用所需的 `createUniver` 方法，以及暴露了 **@univerjs/core** 和 **@univerjs/design** 的所有方法和對象。

`createUniver` 方法接受一個配置對象，包含主題、語言、預設等選項，返回一個 `Univer` 實例 `univer` 和用於調用 Facade API 的 `FUniver` 實例 `univerAPI`。

```typescript
interface CreateUniverParameter {
  // Univer 實例的主題，默認使用 defaultTheme
  theme: IStyleSheet
  // 是否使用暗黑模式，默認為 false。
  darkMode?: boolean
  // Univer 實例的語言環境
  locale: LocaleType
  // 要使用的語言環境對象，鍵為語言環境類型，值為對應的語言環境對象
  locales: ILocales
  // Univer 實例的日誌級別
  logLevel?: LogLevel
  // 要使用的預設列表。
  presets: IPresets[]
  // 要使用的插件列表。
  plugins: IPlugins[]
}
```

參考：[`createUniver`](/reference/methods/create-univer)

#### @univerjs/preset-sheets-core

本預設是 Univer Sheets 的核心預設，包含了文件編輯器、公式引擎、渲染引擎等電子文件必要的核心功能。

```typescript
interface IUniverSheetsCorePresetConfig {
  // 容器元素，可以是字串或者 DOM 元素
  container?: string | HTMLElement
  // 是否顯示頭部
  header?: boolean
  // 是否顯示頭部工具列
  toolbar?: boolean
  // 頭部工具列的類型。default: 默認緊湊模式；classic: 經典模式；simple：不分組模式
  ribbonType?: RibbonType
  // 是否顯示底部。
  footer?: false | {
    // Sheet bar 是子表管理器，包括添加/切換/刪除子表。
    sheetBar?: boolean
    // 統計欄包括当前選區的統計信息，如計數、總和、平均值等。
    statisticBar?: boolean
    // 在底部的菜單，包括高亮、格線等。
    menus?: boolean
    // 底部的縮放滑塊。
    zoomSlider?: boolean
  }
  // 是否顯示右鍵菜單
  contextMenu?: boolean
  // 是否禁用自動聚焦
  disableAutoFocus?: true
  // 依賴注入的覆蓋配置
  override?: DependencyOverride
  // 菜單配置
  menu?: MenuConfig

  sheets?: {
    // 如果行樣式和列樣式都設置了，行樣式是否優先於列樣式
    isRowStylePrecedeColumnStyle?: boolean
    // 自動高度是否適用於合併儲存格
    autoHeightForMergedCells?: boolean
    /**
     * 是否將凍結狀態同步到實時協作中的其他用戶。
     * @default true
     */
    freezeSync?: boolean

    clipboardConfig?: {
      // 在貼上操作後是否顯示貼上選項按鈕
      hidePasteOptions?: boolean
    }
    // 滾動條配置
    scrollConfig?: IScrollBarProps
    /**
     * 權限保護範圍陰影顯示策略。
     * - true 或 'always'：顯示所有受保護範圍的陰影（默認行為）
     * - 'non-editable'：僅顯示無法編輯的範圍的陰影（編輯權限為 false）
     * - 'non-viewable'：僅顯示無法查看的範圍的陰影（查看權限為 false）
     * - false 或 'none'：從不顯示受保護範圍的陰影
     * @default true
     */
    protectedRangeShadow?: boolean | 'always' | 'non-editable' | 'non-viewable' | 'none'
    // 是否禁用強制字串警告。
    disableForceStringAlert?: boolean
    // 是否禁用強制字串標記。
    disableForceStringMark?: boolean
  }

  // ... 更多配置項
}
```

其中，`menu` 配置項可以用於簡單地設置某些特定菜單項的顯示或隱藏等狀態：

```typescript
UniverSheetsCorePreset({
  menu: {
    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

這裡的 `'sheet.command.set-range-bold'` 和 `'sheet.command.set-range-italic'` 是命令的名稱，表示對應的菜單項。可參考下方的 [菜單項 ID 列表](#menu-item-id-list)。

參考：[@univerjs/preset-sheets-core](/reference/packages/presets/univerjs/preset-sheets-core)

## 工具列佈局與 `RibbonType`

通過配置 `IUniverSheetsCorePresetConfig` 或 `IUniverUIConfig` 的 `ribbonType` 屬性，可以設置工具列的佈局。

`ribbonType` 支持設置為以下三種模式：

- `default`：默認緊湊模式，分組與工具列平鋪在同一行，適合垂直屏幕空間有限的場景。
- `classic`：經典模式，分組在上方，工具列平鋪在下方，適合習慣傳統佈局的用戶。
- `simple`：不分組模式，將所有工具放在一個平鋪的列表中，適合熟悉工具列功能的用戶。
