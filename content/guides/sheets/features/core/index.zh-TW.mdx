Univer Sheets 的核心功能包含了電子表格編輯器、公式引擎、渲染引擎、數字格式化引擎、設計系統和 UI 組件庫等。它們共同構成了一個強大的電子表格處理平台，支援多種電子表格格式和複雜的電子表格操作。

## 特性

Univer Sheets 的核心功能包括：

- **電子表格渲染**：支援 Univer Sheets 的渲染和游標、選區的繪製。
- **儲存格樣式**：支援對電子表格中的儲存格進行樣式設置，包括字體、顏色、邊框、對齊等。
- **公式計算**：支援在電子表格中添加和計算公式，支援幾乎所有的 Excel 公式，包括數學、統計、文本、日期等函數。
- **數字格式化**：支援對電子表格中的數字進行格式化，包括貨幣、百分比、日期等格式。
- **格線和凍結窗格**：支援顯示格線和凍結窗格功能，方便用戶查看和編輯大數據量的電子表格。
- **默認樣式**：支援對電子表格的默認樣式進行設置，包括默認字體、字號、顏色等。
- **外掛系統**：支援外掛系統，可以自訂外掛，這也是 Univer 核心架構能力之一。

## 工具列佈局與 `RibbonType`

通過配置 `IUniverSheetsCorePresetConfig` 或 `IUniverUIConfig` 的 `ribbonType` 屬性，可以設置工具列的佈局。

`ribbonType` 支援設置為以下四種模式：

- `classic`：默認經典模式，分組在上方，工具列平鋪在下方，適合習慣傳統佈局的用戶。
- `grid`：網格模式，保留頂部頁籤，下方各工具群組以兩行網格排列，適合需要同時顯示更多工具的桌面佈局。
- `collapsed`：緊湊模式，分組與工具列平鋪在同一行，適合垂直屏幕空間有限的場景。
- `simple`：不分組模式，將所有工具放在一個平鋪的列表中，適合熟悉工具列功能的用戶。

`grid` Ribbon 寬度不足時，放不下的完整群組會移入「更多」選單，以精簡配置顯示；容器變寬後會恢復。此行為依可用寬度自動調整，主工具列仍使用原有的 `gridLayout` 設定。溢出選單保留相同命令、停用狀態與權限檢查。

## 選單順序與網格佈局 [#menu-order-and-grid-layout]

`menu` 的鍵可以是 Ribbon 頁籤識別碼（如 `ribbon.insert`）、群組識別碼（如 `ribbon.start.format`）或選單項目 ID。

`order` 依數值由小到大排列同層節點：Ribbon 中的頁籤、頁籤內的群組，以及群組或子選單內的項目。它不會將選單移至其他群組。頁籤與群組也可以使用 `@univerjs/ui` 匯出的 `RibbonPosition` 及各群組列舉作為鍵。

## 選取與拖曳 [#selection-interaction]

### 工作表邊界的鍵盤導覽 [#keyboard-navigation]

`allowArrowKeyWrapOnSheetBoundary` 用來控制方向鍵到達工作表邊界後是否可換到另一列或欄。預設值為 `true`，設為 `false` 時停留在邊界；不影響選取範圍內 Enter/Tab 的循環移動。預設模式下放在 `sheets` 中，外掛模式下直接傳給 `UniverSheetsUIPlugin`。

設定 `selectionAnimation: false` 可關閉點選不同儲存格時的選取動畫。系統的減少動態效果設定優先。設定 `enableFillHandle: false` 可隱藏填滿控點，填滿命令與 Facade API 仍可使用。設定 `warnBeforeDragOverwrite: false` 可略過拖曳覆寫確認，移動驗證與復原重做仍會生效。三個選項預設皆為 `true`，請在 `UniverSheetsCorePreset` 的 `sheets` 中設定，或直接傳給 `UniverSheetsUIPlugin`。

## 用 Facade API 更新選單 [#menu-facade]

### 執行時更新

公開 Facade 會合併變更並立即更新 UI。未指定的屬性保留既有設定或 Schema 預設值，設定也會套用至後續註冊的選單。外掛模式下，請先匯入 `@univerjs/ui/facade`。

```ts
import '@univerjs/ui/facade'

  'sheet.command.set-range-bold': {
    order: 0,
    gridLayout: { row: 2, column: 2 },

  'sheet.command.set-range-italic': {
    gridLayout: { row: 2, column: 1 },
  },
})
```

`gridLayout` 僅在 `ribbonType: 'grid'` 時生效。每個群組固定兩列，`row` 與 `column` 皆從 1 開始。明確指定的座標決定按鈕位置，因此只修改 `order` 不會移動已指定座標的按鈕；交換位置時應同時修改兩個按鈕，避免重疊。選用欄位包括 `rowSpan`、`columnSpan`、`showLabel`、`width` 與 `iconSize`，尺寸單位為像素。限制與預設值請見 [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout)。

### 自訂選單的位置

`createMenu()` 與 `createSubmenu()` 也支援 `order` 及 `gridLayout`。對子選單而言，這兩個欄位控制 Ribbon 上的觸發入口，不會改變彈出選單的內部佈局。例如，在歷史操作群組的第三欄新增按鈕：

```ts
univerAPI
  .createMenu({
    id: 'custom-action',
    title: 'Custom action',
    action: () => console.log('Custom action clicked'),
    order: 4,
    gridLayout: { row: 1, column: 3, showLabel: true, width: 96 },
  })
  .appendTo('ribbon.start.history')
```
