---
title: Standardstil
---

Wir bieten zwei Ebenen von Standardstilen:
1. Der Standardstil des Arbeitsblatts
2. Der Standardstil der Spalte oder Zeile

Beide können über die Schnittstelle [`IWorksheetData`](https://reference.univer.ai/en-US/interfaces/IWorksheetData) oder die Facade-API festgelegt werden.

## Konfiguration

Standardmäßig hat der Spaltenstil Vorrang vor dem Zeilenstil. Sie können dieses Verhalten ändern, indem Sie bei der Registrierung `isRowStylePrecedeColumnStyle` festlegen.

```typescript
univer.registerPlugin(UniverSheetsPlugin, {
  isRowStylePrecedeColumnStyle: true,
})
```

## Standardstil festlegen

Es gibt zwei Möglichkeiten, den Standardstil eines Arbeitsblatts festzulegen:

1. Über die Schnittstelle [`IWorksheetData`](https://reference.univer.ai/en-US/interfaces/IWorksheetData)

```typescript
interface IWorksheetData {
  // other
  /**
   * @property {Nullable<IStyleData>} [defaultStyle] - Default style data of Worksheet.
   */
  defaultStyle?: Nullable<IStyleData>
}

interface IRowData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}

interface IColumnData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}
```

2. Eingestellt über die Facade-API

```typescript
const fworkbook = univerAPI.getActiveWorkbook()
const fworksheet = fworkbook.getActiveSheet()
const defaultStyle = {
  bg: {
    rgb: 'red',
  },
}
const defaultColumnStyle = {
  bg: {
    rgb: 'blue',
  },
}
const defaultRowStyle = {
  bg: {
    rgb: 'green',
  },
}

// set default style
fworksheet.setDefaultStyle(defaultStyle)
// set column D default style
fworksheet.setColumnDefaultStyle(3, defaultColumnStyle)
// reset column D the default style
fworksheet.setColumnDefaultStyle(3, undefined)

// set row default style
fworksheet.setRowDefaultStyle(1, defaultRowStyle)
```

## Text verkleinern auf Anpassen

Verwenden Sie `FRange`, um Text zu verkleinern, wenn er breiter als seine Zelle ist. Die Einstellung gilt für jede Zelle im Bereich; `getShrinkToFit()` liest die Zelle oben links.

```ts
const range = univerAPI.getActiveWorkbook().getActiveSheet().getRange('A1:C3')

range.setShrinkToFit(true)
const enabled = range.getShrinkToFit()
```
