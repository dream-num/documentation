## Bereich [#range]

Ein Bereich bezieht sich auf einen rechteckigen Bereich in einem Arbeitsblatt, der durch die Startzeilennummer, Startspaltennummer, Länge und Breite oder Endzeilennummer und Endspaltennummer bestimmt wird.

Die meisten Vorgänge in einer Tabelle können über die Bereichs-API ausgeführt werden, z. B. das Festlegen von Werten, das Abrufen von Werten, das Festlegen von Stilen, das Abrufen von Stilen usw.

### Fassaden-API

Eine vollständige Definition der bereichsbezogenen Fassaden-API finden Sie unter [FRange FacadeAPI](https://docs.univer.ai/reference/facade/range).

#### Bereich erstellen

Um einen Bereich zu erhalten, müssen Sie die Startzeilennummer, Startspaltennummer, Länge und Länge kennen Breite.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a range of A1 cell:
const fRange = fWorksheet.getRange(0, 0)
console.log(fRange, fRange.getA1Notation())

// Creates a range of A1:B2:
const fRange2 = fWorksheet.getRange(0, 0, 2, 2)
console.log(fRange2, fRange2.getA1Notation())
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get the A1:B2 range on named Sheet1
const fRange1 = fWorksheet.getRange('Sheet1!A1:B2')
console.log(fRange1, fRange1.getA1Notation())

// Get a single cell A1
const fRange2 = fWorksheet.getRange('A1')
console.log(fRange2, fRange2.getA1Notation())

// Get the A1:B2 range
const fRange3 = fWorksheet.getRange('A1:B2')
console.log(fRange3, fRange3.getA1Notation())

// Get the range of column A
const fRange4 = fWorksheet.getRange('A:A')
console.log(fRange4, fRange4.getA1Notation())

// Get the range of row 1
const fRange5 = fWorksheet.getRange('1:1')
console.log(fRange5, fRange5.getA1Notation())
```

#### Bereichsdaten abrufen

Den Wert der ersten Zelle im Bereich abrufen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

console.log(fRange.getValue()) // The value of the top-left cell in the range
console.log(fRange.getRawValue()) // The raw value of the top-left cell in the range
console.log(fRange.getDisplayValue()) // The displayed value of the top-left cell in the range
console.log(fRange.getCellData()) // The cell data of the top-left cell in the range
console.log(fRange.getRichTextValue()) // The rich text value of the top-left cell in the range
console.log(fRange.getRichTextValue().toPlainText()) // The plain text of the rich text value of the top-left cell in the range
```

Alle Zellwerte im Bereich abrufen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

console.log(fRange.getValues()) // The values of all cells in the range
console.log(fRange.getRawValues()) // The raw values of all cells in the range
console.log(fRange.getDisplayValues()) // The displayed values of all cells in the range
console.log(fRange.getCellDatas()) // The cell data of all cells in the range
console.log(fRange.getRichTextValues()) // The rich text values of all cells in the range
```

Alle Formeln im Bereich abrufen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

console.log(fRange.getFormula()) // The formula of the top-left cell in the range
console.log(fRange.getFormulas()) // The formulas of all cells in the range
```

#### Bereichswert festlegen

##### Einen einzelnen Wert festlegen

Wenn ein Wert oder ein Zellenobjekt übergeben wird, werden alle Zellen im Bereich überschrieben. Wenn es mit `=` beginnt, wird es als Formel interpretiert.

So setzen Sie beispielsweise den Wert von A1:B2 auf `Hello, Univer`:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValue('Hello, Univer')
```

Setzen Sie den Wert von A1+B1 auf die Formel:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValue('=A1+B1')
```

Setzen Sie den Wert von A1:B2 auf das Zellobjekt:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValue({
  v: 'Hello, Univer',
  custom: {
    key: 'value',
  },
})
```

Wenn Sie nur den Wert oben links festlegen möchten Zelle im Bereich können Sie die Methode [`FRange.setValueForCell`](https://docs.univer.ai/reference/facade/range#setvalueforcell) verwenden:

```typescript
fRange.setValueForCell('Hello, Univer')
```

##### Mehrere Werte mit einem Array festlegen

Die Länge und Breite des Arrays muss mit der Länge und Breite des Bereichs übereinstimmen.

Sie können Zellwerte oder Zellobjekte übergeben.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues([
  ['A1', 'B1'],
  ['A2', 'B2'],
])

fRange.setValues([
  [{ v: 'A1' }, { v: 'B1' }],
  [{ v: 'A2' }, { v: 'B2' }],
])
```

##### Mehrere Werte mit einem Objekt festlegen

Wenn ein Objekt übergeben wird, der Primärindex des Objekts stellt die Zeilennummer dar, und der Sekundärindex stellt die Spaltennummer dar, und die Länge und Breite des Bereichs müssen nicht übereinstimmen.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues({
  0: {
    0: 'A1',
    1: 'B1',
  },
  1: {
    0: 'A2',
    1: 'B2',
  },
})
```

#### Bereichsdaten löschen

- Die Methode [`FRange.clear`](https://docs.univer.ai/reference/facade/range#clear) kann die Inhalts- und Formatinformationen des Bereichs löschen.
- Die Methode [`FRange.clearContent`](https://docs.univer.ai/reference/facade/range#clearcontent) kann die Inhaltsinformationen des Bereichs löschen Bereich.
- [`FRange.clearFormat`](https://docs.univer.ai/reference/facade/range#clearformat) Methode kann die Formatinformationen des Bereichs löschen.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorkSheet = fWorkbook.getActiveSheet()
const fRange = fWorkSheet.getRange('A1:D10')

// Clears content and formatting information of the range.
fRange.clear()
```

#### Zellen einfügen

[`FRange.insertCells`](https://docs.univer.ai/reference/facade/range#insertcells) Methode can fügt leere Zellen in diesen Bereich ein. Vorhandene Daten im Blatt entlang der angegebenen Dimension werden aus dem eingefügten Bereich verschoben.

```typescript
// Assume the active sheet empty sheet.
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const values = [
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
]

// Set the range A1:D5 with some values, the range A1:D5 will be:
// 1 | 2 | 3 | 4
// 2 | 3 | 4 | 5
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
const fRange = fWorksheet.getRange('A1:D5')
fRange.setValues(values)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[1, 2, 3, 4], [2, 3, 4, 5], [3, 4, 5, 6], [4, 5, 6, 7], [5, 6, 7, 8]]

// Insert the empty cells into the range A1:B2 along the columns dimension, the range A1:D5 will be:
//   |   | 1 | 2
//   |   | 2 | 3
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
const fRange2 = fWorksheet.getRange('A1:B2')
fRange2.insertCells(univerAPI.Enum.Dimension.COLUMNS)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[null, null, 1, 2], [null, null, 2, 3], [3, 4, 5, 6], [4, 5, 6, 7], [5, 6, 7, 8]]

// Set the range A1:D5 values again, the range A1:D5 will be:
// 1 | 2 | 3 | 4
// 2 | 3 | 4 | 5
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
fRange.setValues(values)

// Insert the empty cells into the range A1:B2 along the rows dimension, the range A1:D5 will be:
//   |   | 3 | 4
//   |   | 4 | 5
// 1 | 2 | 5 | 6
// 2 | 3 | 6 | 7
// 3 | 4 | 7 | 8
const fRange3 = fWorksheet.getRange('A1:B2')
fRange3.insertCells(univerAPI.Enum.Dimension.ROWS)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[null, null, 3, 4], [null, null, 4, 5], [1, 2, 5, 6], [2, 3, 6, 7], [3, 4, 7, 8]]
```

#### Zellen löschen

[`FRange.deleteCells`](https://docs.univer.ai/reference/facade/range#deletecells) kann diesen Zellbereich löschen. Vorhandene Daten im Blatt entlang der angegebenen Dimension werden in Richtung des gelöschten Bereichs verschoben.

```typescript
// Assume the active sheet empty sheet.
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const values = [
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
]

// Set the range A1:D5 with some values, the range A1:D5 will be:
// 1 | 2 | 3 | 4
// 2 | 3 | 4 | 5
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
const fRange = fWorksheet.getRange('A1:D5')
fRange.setValues(values)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[1, 2, 3, 4], [2, 3, 4, 5], [3, 4, 5, 6], [4, 5, 6, 7], [5, 6, 7, 8]]

// Delete the range A1:B2 along the columns dimension, the range A1:D5 will be:
// 3 | 4 |   |
// 4 | 5 |   |
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
const fRange2 = fWorksheet.getRange('A1:B2')
fRange2.deleteCells(univerAPI.Enum.Dimension.COLUMNS)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[3, 4, null, null], [4, 5, null, null], [3, 4, 5, 6], [4, 5, 6, 7], [5, 6, 7, 8]]

// Set the range A1:D5 values again, the range A1:D5 will be:
// 1 | 2 | 3 | 4
// 2 | 3 | 4 | 5
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
fRange.setValues(values)

// Delete the range A1:B2 along the rows dimension, the range A1:D5 will be:
// 3 | 4 | 3 | 4
// 4 | 5 | 4 | 5
// 5 | 6 | 5 | 6
//   |   | 6 | 7
//   |   | 7 | 8
const fRange3 = fWorksheet.getRange('A1:B2')
fRange3.deleteCells(univerAPI.Enum.Dimension.ROWS)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[3, 4, 3, 4], [4, 5, 4, 5], [5, 6, 5, 6], [null, null, 6, 7], [null, null, 7, 8]]
```

#### Zellen zusammenführen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Merge B1:B2
const fRange = fWorksheet.getRange('B1:B2')
fRange.merge()
console.log(fRange.isMerged()) // true

// A1:B2 is merged
const fRange2 = fWorksheet.getRange('A1:B2')

console.log(fRange2.isPartOfMerge()) // true

// Break apart the merged range
fRange2.breakApart()

// merge horizontally: fRange2.mergeAcross();
// merge vertically: fRange2.mergeVertically();
// Get all merged ranges in the worksheet: fWorksheet.getMergedRanges();
```

#### Bereich hervorheben

[`FRange.highlight`](https://docs.univer.ai/reference/facade/range#highlight) kann den Bereich mit dem angegebenen Stil und der angegebenen Primärzelle hervorheben.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Highlight the range C3:E5 with default style
const fRange = fWorksheet.getRange('C3:E5')
fRange.highlight()

// Highlight the range C7:E9 with custom style and primary cell D8
const fRange2 = fWorksheet.getRange('C7:E9')
const primaryCell = fWorksheet.getRange('D8').getRange()
const disposable = fRange2.highlight(
  {
    stroke: 'red',
    fill: 'yellow',
  },
  {
    ...primaryCell,
    actualRow: primaryCell.startRow,
    actualColumn: primaryCell.startColumn,
  },
)

// Remove the range C7:E9 highlight after 5 seconds
setTimeout(() => {
  disposable.dispose()
}, 5000)
```

#### Text aufteilen columns

[`FRange.splitTextToColumns`](https://docs.univer.ai/reference/facade/range#splittexttocolumns) Methode kann den Text im Bereich entsprechend dem angegebenen Trennzeichen in Spalten aufteilen.

Beispiel für Standardtrennzeichen:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1:A3 has following values:
//  A      |
//  1,2,3  |
//  4,,5,6 |
const fRange = fWorksheet.getRange('A1:A3')
fRange.setValues([
  ['A'],
  ['1,2,3'],
  ['4,,5,6'],
])

// After calling splitTextToColumns(true), the range will be:
//  A |   |
//  1 | 2 | 3
//  4 | 5 | 6
fRange.splitTextToColumns(true)

// After calling splitTextToColumns(false), the range will be:
//  A |   |   |
//  1 | 2 | 3 |
//  4 |   | 5 | 6
fRange.splitTextToColumns(false)
```

Beispiel für angegebenes Trennzeichen:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1:A3 has following values:
//     A   |
//  1;;2;3 |
//  1;,2;3 |
const fRange = fWorksheet.getRange('A1:A3')
fRange.setValues([
  ['A'],
  ['1;;2;3'],
  ['1;,2;3'],
])

// After calling splitTextToColumns(false, univerAPI.Enum.SplitDelimiterType.Semicolon|univerAPI.Enum.SplitDelimiterType.Comma), the range will be:
//  A |   |   |
//  1 |   | 2 | 3
//  1 |   | 2 | 3
fRange.splitTextToColumns(false, univerAPI.Enum.SplitDelimiterType.Semicolon | univerAPI.Enum.SplitDelimiterType.Comma)

// After calling splitTextToColumns(true, univerAPI.Enum.SplitDelimiterType.Semicolon|univerAPI.Enum.SplitDelimiterType.Comma), the range will be:
//  A |   |
//  1 | 2 | 3
//  1 | 2 | 3
fRange.splitTextToColumns(true, univerAPI.Enum.SplitDelimiterType.Semicolon | univerAPI.Enum.SplitDelimiterType.Comma)
```

Beispiel für benutzerdefiniertes Trennzeichen:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1:A3 has following values:
//     A   |
//  1#2#3  |
//  4##5#6 |
const fRange = fWorksheet.getRange('A1:A3')
fRange.setValues([
  ['A'],
  ['1#2#3'],
  ['4##5#6'],
])

// After calling splitTextToColumns(false, univerAPI.Enum.SplitDelimiterType.Custom, '#'), the range will be:
//  A |   |   |
//  1 | 2 | 3 |
//  4 |   | 5 | 6
fRange.splitTextToColumns(false, univerAPI.Enum.SplitDelimiterType.Custom, '#')

// After calling splitTextToColumns(true, univerAPI.Enum.SplitDelimiterType.Custom, '#'), the range will be:
//  A |   |
//  1 | 2 | 3
//  4 | 5 | 6
fRange.splitTextToColumns(true, univerAPI.Enum.SplitDelimiterType.Custom, '#')
```

## Auswahl [#selection]

Univer Sheets unterstützt mehrere Wahlkreise, sodass ein Wahlkreis ein Array von Bereichen ist und Sie die Wahlkreisdaten über die Bereichs-API manipulieren können.

Wir stellen auch APIs bereit, um die aktuelle Auswahl abzurufen, die Auswahl festzulegen und auf Änderungen an der Auswahl zu warten.

### Fassaden-API

Eine vollständige Definition der auswahlbezogenen Fassaden-API finden Sie unter [FSelection FacadeAPI](https://docs.univer.ai/reference/facade/selection)

#### Aktive Auswahl abrufen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Activate the new selection of A1:B2
const fRange = fWorksheet.getRange('A1:B2')
fRange.activate()

// Get the current active selection
const fSelection = fWorksheet.getSelection()
console.log(fSelection)
const activeRange = fSelection.getActiveRange()
console.log(activeRange.getA1Notation()) // A1:B2
```

#### Auswahl festlegen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set the selection to A1:B2 by FRange
const fRange = fWorksheet.getRange('A1:B2')
fRange.activate()

// Set the selection to C1:D2 by FWorksheet
fWorksheet.setActiveSelection(fWorksheet.getRange('C1:D2'))
```

#### Aktuelle Zelle abrufen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Activate the new selection of A10:B11
const fRange = fWorksheet.getRange('A10:B11')
fRange.activate()

// Get the current active cell
let fSelection = fWorksheet.getSelection()
const { actualRow, actualColumn } = fSelection.getCurrentCell()
console.log(fWorksheet.getRange(actualRow, actualColumn).getA1Notation()) // A10

// Update the new active cell to B11
fSelection = fSelection.updatePrimaryCell(fWorksheet.getRange('B11'))
const { actualRow: newRow, actualColumn: newColumn } = fSelection.getCurrentCell()
console.log(fWorksheet.getRange(newRow, newColumn).getA1Notation()) // B11
```

#### Deaktivieren/Aktivieren/Ausblenden/Anzeigen Auswahl

Wenn die Option deaktiviert ist, reagiert die Auswahl nicht mehr. `hideSelection` macht die Auswahl unsichtbar – im Gegensatz zu `disableSelection` funktioniert die Auswahl weiterhin; Sie können es einfach nicht sehen.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Disable selection
fWorkbook.disableSelection()

// Enable selection
fWorkbook.enableSelection()

// Hide selection
fWorkbook.transparentSelection()

// Show selection
fWorkbook.showSelection()
```

#### Auf Auswahländerungen achten

```typescript
univerAPI.addEvent(univerAPI.Event.SelectionChanged, (params) => {
  const { worksheet, workbook, selections } = params
  console.log(params)
})
```

## Zelle [#Zelle]

Zellendaten werden im Arbeitsblatt als zweidimensionale Karte gespeichert, wobei der erste und zweite Index die Zeilennummer bzw. Spaltennummer darstellen.

Das Folgende ist ein typisches Zellenobjekt:

```typescript
const data = {
  v: 'Hello, Univer',
  s: 'styleId',
  t: CellValueType.STRING,
}
```

Detaillierte Feldbeschreibungen finden Sie unter [Zelle konfigurieren Daten](/guides/sheets/model/cell-data).

### Gut zu wissen

1. Zellenoperationen können als Operationen für einen Bereich von Zeilen und Spalten mit einer Höhe von 1 und einer Breite von 1 betrachtet werden. Den Operationsbereich finden Sie unter [Bereich](/guides/sheets/features/core/range-selection#range).
2. Das Univer API-Plugin speichert auch die erweiterten Zellattribute im `resources`-Eigenschaft von `Workbook`, siehe [Plugin Custom Model](/guides/recipes/tutorials/custom-model).

| `SheetEditChanging` | Ausgelöst, wenn der Zelleninhalt geändert wird | `ISheetEditChangingEventParams` | `const { worksheet, workbook, row, column, value } = params` |

| `SheetEditEnded` | Ausgelöst, nachdem die Zellenbearbeitung endet | `ISheetEditEndedEventParams` | `const { worksheet, workbook, row, column, eventType, keycode, isConfirm } = params` |

### Verwendungsbeispiel

```typescript
  // Event handling logic
})
```

### Zellenrenderereignis

`registerCellCustomRender` registriert benutzerdefinierte Renderer für die Zellendarstellung.

Beispiel 1: Rendern mit fester Position – Zeilenhinzufügungen wirken sich nicht auf das Rendern aus Position

```typescript
// Fixed position rendering
univerAPI.registerCellCustomRender([{
  drawWith: (ctx, info, skeleton, spreadsheets) => {
    const { row, col } = info
    // Render a checkmark at position (1,1)
    if (row === 1 && col === 1) {
      const { primaryWithCoord } = info
      const { startX, startY } = primaryWithCoord
      ctx.fillText('✅', startX, startY + 10)
    }
  },
}])

// Refresh canvas to apply rendering
univerAPI.getActiveWorkbook().getActiveSheet().refreshCanvas()
```

Beispiel 2: Markierungsbasiertes Rendern – Positionsänderungen mit Zeilen-/Spaltenänderungen rendern

```typescript
// Set marker
univerAPI.getActiveWorkbook().getActiveSheet().getRange('B2').setValue({ custom: { key: 'needCheck' } })

// Render based on marker
univerAPI.registerCellCustomRender([{
  drawWith: (ctx, info, skeleton, spreadsheets) => {
    const { row, col, data } = info
    // Render checkmark at marked position
    if (data?.custom?.key === 'needCheck') {
      const { primaryWithCoord } = info
      const { startX, startY } = primaryWithCoord
      ctx.fillText('✅', startX, startY + 10)
    }
  },
}])

// Refresh canvas to apply rendering
univerAPI.getActiveWorkbook().getActiveSheet().refreshCanvas()
```

### Anleitung die Daten im Zelleneditor in Echtzeit?

Der Univer Sheets-Zelleneditor basiert auf der Univer Docs-Editor-Engine und ermöglicht Ihnen die Verwendung der Facade-API, um die Snapshot-Daten des aktuell aktiven Univer Docs-Editors abzurufen. Dies ermöglicht das Abrufen und Verarbeiten des bearbeiteten Inhalts in Echtzeit.

```typescript
univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'doc.command.insert-text' || id === 'doc.command.delete-text') {
    const doc = univerAPI.getActiveDocument()
    if (doc) {
      const snapshot = doc.save()
      console.log(snapshot.body?.dataStream)
    }
  }
})
```

Referenz: https://github.com/dream-num/univer/discussions/2261

### Wenn der Zelleneditor fokussiert ist und auf eine externe Schaltfläche geklickt wird, um ein Ereignis auszulösen, enthält der erhaltene Schnappschuss nicht die Daten der fokussierten Zelle.

Die Zelldaten werden mit dem Schnappschuss synchronisiert, wenn der Zelleneditor den Fokus verliert (d. h. wenn die Bearbeitung endet). Stellen Sie daher vor dem Versuch, die Snapshot-Daten abzurufen, sicher, dass die Zelle den Fokus verloren hat. Sie können die Bearbeitung wie folgt aktiv beenden:

```typescript
import '@univerjs/sheets-ui/facade'

$btn.addEventListener('click', () => {
  univerAPI.getActiveWorkbook().endEditingAsync(true)
})
```

Referenz: https://github.com/dream-num/univer/issues/1314

### Wenn Sie die Facade-API zum Erstellen einer Arbeitsmappe verwenden, funktionieren einige APIs möglicherweise nicht sofort nach der Erstellung der Arbeitsmappe. Dies liegt daran, dass einige APIs darauf angewiesen sind, dass die Schnittstelle vollständig gerendert wird, bevor sie ordnungsgemäß funktionieren können. Es wird empfohlen, verwandte Vorgänge in der Phase `Rendered` oder `Steady` des Lebenszyklus auszuführen.

Viele APIs sind darauf angewiesen, dass die Schnittstelle vollständig gerendert wird, bevor sie ordnungsgemäß funktionieren können. Wenn Sie verwandte APIs unmittelbar nach dem Erstellen einer Arbeitsmappe aufrufen, funktionieren diese möglicherweise nicht, da die Schnittstelle noch nicht vollständig gerendert ist. Es wird empfohlen, verwandte Vorgänge in der Phase `Rendered` oder `Steady` des Lebenszyklus auszuführen:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // code...
  }
})

// To remove the event listener, you can call `disposable.dispose()`
```

Referenz: [Lebenszyklus](/guides/sheets/getting-started/lifecycle)
