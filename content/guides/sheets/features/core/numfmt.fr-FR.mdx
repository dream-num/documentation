Les formats de nombre contrôlent comment un nombre apparaît dans une cellule. Le format détermine le nombre de décimales, si des milliers de séparateurs sont utilisés, et si la valeur est affichée en pourcentage ou avec un symbole de monnaie, entre autres options. Une fois qu'un format est défini, les données sont plus faciles à lire.

L'action de monnaie dans la barre d'outils prend son symbole de monnaie et son motif de Univer `region`. Si `region` n'est pas configuré explicitement, il suit `locale` :

```typescript
const univer = new Univer({
  locale: LocaleType.FR_FR,
  region: LocaleType.DE_DE,
})
```

<Callout type="warning" title="Attention">
  **Syntaxe DBNum** n'est pas pris en charge.
</Callout>

## Utilisation [#usage]

Dans l'interface utilisateur, définissez le format du numéro d'une cellule à partir de la barre de menus. Dans le code, définissez la zone [`s.n.pattern`](/guides/sheets/model/cell-data#number-format)[^number-format-value] de l'objet [`ICellData`](/guides/sheets/model/cell-data).

```typescript
const data = {
  v: 123456.789,
  s: {
    n: {
      pattern: '#,##0.00',
    },
  },
}
```

**Par défaut, le texte qui commence par 0 et les nombres qui peuvent être interprétés comme des dates sont automatiquement convertis au format de nombre correspondant.**

Pour éviter la conversion automatique, utilisez l'une des deux options suivantes :

1. Définissez le format numéro de la cellule au texte.

```typescript
import { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

const data = {
  v: '012.0',
  s: {
    n: {
      pattern: DEFAULT_TEXT_FORMAT_EXCEL, // Text format
    },
  },
}
```

Le format peut également être défini par le Facade API:

```typescript
fRange.setNumberFormat(DEFAULT_TEXT_FORMAT_EXCEL)
```

2. Saisissez une seule cote `'` avant le nombre. Ceci s'appelle [forcer le texte](/guides/sheets/model/cell-data#cell-type).

`UniverSheetsNumfmtPlugin` fournit deux options, `disableTextFormatAlert` et `disableTextFormatMark`, pour désactiver l'avertissement et le marqueur pour les cellules formatées en texte.

Fusionnez ces options dans l'initialisation existante pour le mode d'intégration en cours d'utilisation. Conservez l'autre plugin, local, thème et paramètres de conteneur, et ne enregistrez pas le même plugin deux fois.

## Analyse des nombres et décimales [#number-parsing]

La notation comptable est lue comme un nombre : `=VALUE("(5)")` renvoie `-5`, et `(1,000)` ou `($1,000)` devient `-1000`. Les actions **Augmenter le nombre de décimales** et **Réduire le nombre de décimales** ne modifient que les sections numériques d'un format, donc les modèles de date et d'heure conservent leurs chiffres.

## Configuration des plugins [#plugin-configuration]

`UniverSheetsNumfmtPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | Désactive l'avertissement de format texte. |
| `disableTextFormatMark` | `boolean` | `false` | Désactive le marqueur de format texte. |

```typescript
import { UniverSheetsNumfmtPlugin } from '@univerjs/sheets-numfmt'

univer.registerPlugin(UniverSheetsNumfmtPlugin, {
  disableTextFormatAlert: true,
  disableTextFormatMark: true,
})
```

## Configuration des préréglages [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | Désactive l'avertissement de format texte. |
| `disableTextFormatMark` | `boolean` | `false` | Désactive le marqueur de format texte. |

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import { createUniver } from '@univerjs/presets'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      disableTextFormatAlert: true,
      disableTextFormatMark: true,
    }),
  ],
})
```

## API Facade

### Importation

<Callout type="info" title="Note du mode greffon">
  En mode plugin, le paquet Facade est importé séparément. Le mode Preset inclut le paquet Façade correspondant, donc aucune importation supplémentaire n'est requise.
</Callout>

```typescript
import '@univerjs/sheets-numfmt/facade'
```

### Définir le format des nombres

Pour la syntaxe des motifs, voir https://support.microsoft.com/en-us/office/number-format-codes-5026bbd6-04bc-48cd-bf33-80f18b4eae68

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set the number format of the A1 cell to '#,##0.00'.
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')
fRange.getDisplayValue() // 1,234.57
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set the number formats of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues([
  [1234.567, 0.1234],
  [45658, 0.9876],
]).setNumberFormats([
  ['#,##0.00', '0.00%'],
  ['yyyy-MM-DD', ''],
])
fRange.getDisplayValues() // [['1,234.57', '12.34%'], ['2025-01-01', 0.9876]]
```

### Obtenir le format des nombres

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get the number format of the top-left cell of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormat()
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get the number formats of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormats()
```

### Définir les paramètres régionaux du format des nombres

[`FWorkbook.setNumfmtLocal(local)`](https://docs.univer.ai/reference/facade/workbook#setnumfmtlocal) définit la locale utilisée pour formater les numéros.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')

// Set the locale en for number formatting.
fWorkbook.setNumfmtLocal('en')
fRange.getDisplayValue() // 1,234.57

// Set the locale de for number formatting.
fWorkbook.setNumfmtLocal('de')
fRange.getDisplayValue() // 1.234,57
```

[^number-format-value]: Le format numérique change l’affichage, pas la valeur stockée. Le format `0%` affiche `0.25` comme `25%`, mais les formules utilisent toujours `0.25`.
