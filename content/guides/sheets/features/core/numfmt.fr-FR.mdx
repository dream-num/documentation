---
title: Format des nombres
---

La fonctionnalité de format des nombres des feuilles de calcul permet de contrôler l’affichage des nombres. Elle permet de personnaliser leur format d’affichage, notamment le nombre de décimales, les séparateurs de milliers, les pourcentages, les symboles monétaires, etc. En définissant le format des nombres, les utilisateurs peuvent rendre les données plus faciles à lire et à comprendre.

L’action de devise de la barre d’outils utilise la propriété `region` d’Univer pour choisir le symbole et le format monétaires. Sans configuration explicite, `region` suit `locale` :

```typescript
const univer = new Univer({
  locale: LocaleType.FR_FR,
  region: LocaleType.DE_DE,
})
```

<Callout type="warning" title="Attention">
  La syntaxe **DBNum** n’est pas prise en charge.
</Callout>

## Utilisation

Dans l’interface utilisateur, vous pouvez définir le format des nombres d’une cellule depuis la barre de menus. Vous pouvez également définir le champ [`s.n.pattern`](/guides/sheets/model/cell-data#number-format) dans l’objet de données de cellule [`ICellData`](/guides/sheets/model/cell-data).

```typescript
const data = {
  v: 123456.789,
  s: {
    n: {
      pattern: '#,##0.00',
    },
  },
}
```

**Par défaut, les textes commençant par 0 et les nombres pouvant être convertis en dates sont automatiquement convertis dans le format de nombre correspondant.**

Si vous ne souhaitez pas appliquer cette conversion automatique, utilisez l’une des méthodes suivantes :

1. Définissez le format des nombres de la cellule sur le format texte.

```typescript
import { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

const data = {
  v: '012.0',
  s: {
    n: {
      pattern: DEFAULT_TEXT_FORMAT_EXCEL, // Text format
    },
  },
}
```

Vous pouvez aussi utiliser l’API Facade pour définir le format de la cellule :

```typescript
fRange.setNumberFormat(DEFAULT_TEXT_FORMAT_EXCEL)
```

2. Ajoutez une apostrophe simple `'` avant de saisir le nombre (cette opération est appelée [forçage du texte](/guides/sheets/model/cell-data#cell-type)).

## API Facade

### Importation

<Callout type="info" title="Remarque sur le mode plugin">
  Seul le mode plugin nécessite d’importer manuellement le package Facade. Le mode prédéfini inclut déjà le package Facade correspondant ; aucune importation supplémentaire n’est donc nécessaire.
</Callout>

```typescript
import '@univerjs/sheets-numfmt/facade'
```

### Définir le format des nombres

Pour en savoir plus sur les paramètres, consultez : https://support.microsoft.com/en-us/office/number-format-codes-5026bbd6-04bc-48cd-bf33-80f18b4eae68

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set the number format of the A1 cell to '#,##0.00'.
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')
fRange.getDisplayValue() // 1,234.57
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set the number formats of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues([
  [1234.567, 0.1234],
  [45658, 0.9876],
]).setNumberFormats([
  ['#,##0.00', '0.00%'],
  ['yyyy-MM-DD', ''],
])
fRange.getDisplayValues() // [['1,234.57', '12.34%'], ['2025-01-01', 0.9876]]
```

### Obtenir le format des nombres

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get the number format of the top-left cell of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormat()
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get the number formats of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormats()
```

### Définir les paramètres régionaux du format des nombres

Vous pouvez utiliser la méthode [`FWorkbook.setNumfmtLocal(local)`](https://docs.univer.ai/reference/facade/workbook#setnumfmtlocal) pour définir les paramètres régionaux du format des nombres.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')

// Set the locale en_US for number formatting.
fWorkbook.setNumfmtLocal('en_US')
fRange.getDisplayValue() // 1,234.57

// Set the locale de_DE for number formatting.
fWorkbook.setNumfmtLocal('de_DE')
fRange.getDisplayValue() // 1.234,57
```

## Désactiver l’alerte et le marqueur du format texte

Le plugin `UniverSheetsNumfmtPlugin` fournit les deux options de configuration `disableTextFormatAlert` et `disableTextFormatMark`, qui permettent de désactiver respectivement l’alerte et le marqueur du format texte des cellules.

```typescript
// presets configuration
const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverSheetsCorePreset({
      disableTextFormatAlert: true,
      disableTextFormatMark: true,
    }),
  ],
})
```

```typescript
// Plugin configuration
univer.registerPlugin(UniverSheetsNumfmtPlugin, {
  disableTextFormatAlert: true,
  disableTextFormatMark: true,
})
```
