定義名稱用於給單元格、單元格區域或公式指定一個自定義名稱。公式可以直接引用該名稱，不必再寫出原始地址，因此更易讀，也更易維護。

- 公式更接近其實際含義。`销售总额` 比 `A1 + A2 + A3` 表達得更清楚。
- 多個單元格或複雜的區域可以用一個名稱表示。把 `A1:A10` 定義為 `销售数据`，然後在公式中使用 `销售数据`。
- 資料區域只需在一個地方維護。區域發生變化時，更新名稱的引用，而不必逐個修改使用該名稱的公式。

## 使用方法

名稱管理器的入口是工作表左上角名稱框旁邊的下拉箭頭。點選後可以看到所有已定義的名稱，並開啟名稱管理器，檢視、編輯和刪除定義名稱均在此完成。

在公式裡可以直接寫名稱。例如名稱是 `销售总额`，寫 `=销售总额` 就會引用它指向的範圍。

## 注意事項

- 在同一工作表中，定義名稱必須唯一，不能與其他名稱或內建函式衝突。
- 名稱不能以數字開頭，不能包含空格或 `!`、`@`、`#` 這類特殊字元。輸入的名稱不符合規則時，系統會提示錯誤。
- 要修改名稱，重新開啟“定義名稱”編輯面板，選中名稱並完成修改，再點選“確定”儲存。
- 要刪除名稱，在“定義名稱”編輯面板裡選中它，點選“刪除”。刪除後，引用該名稱的公式將失效。
- 定義名稱可以在同一工作簿的不同工作表之間共用，但唯一性規則仍然適用：在不同工作表上定義相同的名稱，會使引用產生歧義。
- 名稱應具有明確含義，避免過短或含義模糊的名稱，以便其他人理解和維護工作表。
- 使用定義名稱的公式出現問題時，可以檢查名稱是否正確、引用範圍是否準確、是否有其他名稱與它衝突。名稱管理器面板會列出所有已定義的名稱及其引用範圍。
- 定義名稱可以設在工作簿級別或工作表級別。工作簿級別的名稱在整個工作簿中可用，工作表級別的名稱僅在對應的工作表上可用。

## Facade API

完整的 Facade API 型別定義見 [Facade API](/reference/facade)。

### 建立定義名稱

`FWorkbook.newDefinedNameBuilder()` 建立一個定義名稱建置器，並返回 `FDefinedNameBuilder`。鏈式呼叫它的方法，可以生成用於建立定義名稱的 `ISetDefinedNameMutationParam` 物件。

以下是 [`FDefinedNameBuilder`](/reference/facade/defined-name-builder) 的部分成員方法：

| 方法 | 描述 |
| ---- | ---- |
| build | 構建定義名稱物件 |
| setName | 設定定義名稱 |
| setFormula | 設定定義名稱的公式 |
| setRef | 設定定義名稱的引用範圍 |
| setComment | 設定定義名稱的註釋 |
| setScopeToWorksheet | 設定定義名稱為某個工作表可用 |
| setScopeToWorkbook | 設定定義名稱為整個工作簿可用 |

[`FWorkbook.insertDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#insertdefinednamebuilder) 建立整個工作簿可用的定義名稱。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedNameParam = fWorkbook.newDefinedNameBuilder()
  .setName('MyDefinedName')
  .setRef('Sheet1!$A$1')
  .setComment('A reference to A1 cell in Sheet1')
  .build()
fWorkbook.insertDefinedNameBuilder(definedNameParam)
```

也可以用 [`FWorkbook.insertDefinedName()`](https://docs.univer.ai/reference/facade/workbook#insertdefinedname) 快速建立定義名稱。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.insertDefinedName('MyDefinedName', 'Sheet1!$A$1')
```

其他方法：
- [`FWorksheet.insertDefinedName()`](https://docs.univer.ai/reference/facade/worksheet#insertdefinedname)：建立某個工作表可用的定義名稱。

### 獲取定義名稱

[`FWorkbook.getDefinedName()`](https://docs.univer.ai/reference/facade/workbook#getdefinedname) 從工作簿中取得一個定義名稱，返回 `FDefinedName` 例項。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

if (definedName) {
  definedName.setName('NewDefinedName')
}
```

其他方法：
- [`FWorkbook.getDefinedNames()`](https://docs.univer.ai/reference/facade/workbook#getdefinednames) 取得工作簿裡所有已定義的名稱，返回 `FDefinedName[]` 陣列。
- [`FWorksheet.getDefinedNames()`](https://docs.univer.ai/reference/facade/worksheet#getdefinednames) 取得這個工作表可用的所有定義名稱，返回 `FDefinedName[]` 陣列。

### 修改定義名稱

`FWorkbook.updateDefinedNameBuilder()` 修改工作簿中的定義名稱。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// 更新定義名稱
if (definedName) {
  const newDefinedNameParam = definedName.toBuilder()
    .setName('NewDefinedName')
    .setRef('Sheet1!$A$2')
    .build()
  fWorkbook.updateDefinedNameBuilder(newDefinedNameParam)
}
```

也可以直接在返回的 [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name) 例項上修改配置。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// 更新定義名稱
if (definedName) {
  definedName.setName('NewDefinedName')
  definedName.setRef('Sheet1!$A$2')
}
```

### 刪除定義名稱

[`FWorkbook.deleteDefinedName()`](https://docs.univer.ai/reference/facade/workbook#deletedefinedname) 刪除工作簿中的定義名稱。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.deleteDefinedName('MyDefinedName')
```

也可以透過返回的 [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name) 例項刪除。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// 刪除定義名稱
if (definedName) {
  definedName.delete()
}
```
