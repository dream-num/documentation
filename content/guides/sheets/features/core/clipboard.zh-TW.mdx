title: 複製貼上
---

<Callout type="warning" title="Firefox 相容性說明">
  Firefox 尚未支援 `clipboard.readText()`，詳見 [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText)。在這種情況下，Univer 只能從貼上事件中讀取剪貼簿內容，因此只支援透過快捷鍵貼上。
</Callout>

Univer 的複製貼上功能基於 Clipboard API，支援將內容從外部應用複製到 Univer、從 Univer 複製到外部應用，也支援在 Univer Sheets 之間複製貼上。

<Callout type="warning" title="安全上下文要求">
  現代瀏覽器的安全策略要求 Clipboard API 僅在安全上下文中使用，例如 HTTPS。
</Callout>

Univer 支援以下複製貼上操作：

- 從外部應用複製貼上到 Univer
- 從 Univer 複製到外部應用
- 在 Univer Sheets 之間複製貼上

選擇性貼上包括以下情況：

- 僅貼上值
- 僅貼上格式
- 僅貼上列寬
- 僅貼上邊框之外的內容
- 僅貼上公式

桌面版 Ribbon 在撤銷、重做按鈕旁提供**貼上**下拉選單，包含普通貼上、貼上值、貼上格式、貼上列寬和貼上時不帶邊框。該選單的 ID 為 `sheet.menu.paste`；右鍵選單中的**選擇性貼上**使用 `sheet.menu.paste-special`。編輯形狀文字時，Ribbon 上的貼上下拉選單會隱藏。

## 禁用複製

開發者可以透過**權限控制（permission control）**禁用整個工作簿或特定工作表的複製功能。

下面的程式碼禁用當前工作簿的複製功能：

```typescript
const workbookPermission = univerAPI.getActiveWorkbook()?.getWorkbookPermission()
const WorkbookCopyPermission = univerAPI.Enum.WorkbookPermissionPoint.CopyContent

if (workbookPermission) {
  workbookPermission.setPoint(WorkbookCopyPermission, false)
}
```

關於權限控制的更多內容，見[權限控制](/guides/sheets/features/core/permission)。
