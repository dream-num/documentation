---
title: 複製貼上
---

<Callout type="warning" title="Firefox 相容性說明">
  Firefox 尚不支援 `clipboard.readText()`，詳見 [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText)，在這種情況下，Univer 只能從貼上事件中獲取剪貼簿內容，因此只能支援快捷鍵貼上。
</Callout>

Univer 使用 Clipboard API 實現了複製貼上功能，支援從外部應用複製貼上到 Univer、從 Univer 複製到外部應用以及 Univer Sheets 之間的複製貼上。

<Callout type="warning" title="安全上下文要求">
  受限於現代瀏覽器的安全策略，Clipboard API 僅可在安全上下文（如 HTTPS 協議）中使用。
</Callout>

Univer 支援的複製貼上操作有：

- 從外部應用複製貼上到 Univer
- 從 Univer 複製到外部應用
- Univer Sheets 之間的複製貼上

並支援如下選擇性貼上能力：

- 僅貼上值
- 僅貼上格式
- 僅貼上列寬
- 僅貼上邊框之外的內容
- 僅貼上公式

## 禁用複製

Univer 允許開發者透過 **權限控制（permission control）** 來禁止使用者在工作簿或特定的工作表中使用複製功能。

例如，以下程式碼將禁止使用者在當前工作簿中使用複製功能：

```typescript
const workbookPermission = univerAPI.getActiveWorkbook()?.getWorkbookPermission()
const WorkbookCopyPermission = univerAPI.Enum.WorkbookPermissionPoint.CopyContent

if (workbookPermission) {
  workbookPermission.setPoint(WorkbookCopyPermission, false)
}
```

關於權限控制的更多資訊，請參閱[權限控制](/guides/sheets/features/core/permission)文件。
