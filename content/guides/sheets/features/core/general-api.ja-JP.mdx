title: 一般 API
---

Univer で利用可能なファサード API は、ドキュメントタイプに依存します。このページでは、すべてのドキュメントタイプと同じ方法で動作する一般的な API について説明します。

## インポート

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 概念

### コマンド

Univerのほとんどの操作は、コマンドシステムに登録して実行します。すべての操作は同じパスに従うので、Univerは、undo、redo、およびコラボレーションをサポートできます。

<Callout>設計の合理性については、[Univerコマンドシステム](/blog/univer#command-system)を参照してください。</Callout>

### コマンド

Univerのほぼすべての操作は、コマンドシステムに登録され、それを介してトリガーされます。 1つの場所ですべての操作を一元化することは、undo、redo、およびコラボレーションなどの機能を作るものです。

<Callout>
  Univer内のユニークな「event」としてコマンドを理解できます。設計の詳細については、[コマンドシステム](/blog/univer#command-system)を参照してください。
</Callout>

### コマンドのリスニング

Univerは、実行前に、実行後にコマンドを listen する2つのポイントを提供します。

- `Event.BeforeCommandExecute` はコマンドが実行する前にカスタムロジックを実行します。
- `Event.CommandExecuted` はコマンド実行後にカスタムロジックを実行します。

#### 実行前のコマンドリスニング

`Event.BeforeCommandExecute`を`FUniver.addEvent`に渡して、プリプロセッサーを登録します。 コマンドが実行される前にリスナーのコードが実行されます。

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, type, params }) => {
  // コマンド実行前に実行されるカスタムロジック
})
```

コマンド実行を防ぐため、コールバックで`event.cancel`を`true`に設定します。

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  event.cancel = true
})
```

#### 実行後のコマンドリスニング

`Event.CommandExecuted`を`FUniver.addEvent`に渡し、後処理リスナーを登録します。そのコードはコマンドが実行した後に実行されます。

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type, params }) => {
  // コマンド実行後に実行されるカスタムロジック
})
```

### リスニングのキャンセル

コマンドリスナーを登録すると、`IDisposable`オブジェクトが返されます。`IDisposable.dispose`を呼び出して破壊します。

使わなくなったリスナーを破壊し、プログラムを安定させるのに役立ちます。

```typescript
const univerAPI = FUniver.newAPI(univer)

// リスナーを登録
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, () => {
  // コマンド実行前のカスタム前処理ロジック
})

// 例：1 秒後にリスナーを破棄
setTimeout(() => {
  // リスナーを破棄
  disposable.dispose()
}, 1000)
```

### コマンドの実行

コマンド ID とそのパラメーターを既に知っている場合は、`FUniver.executeCommand` で直接コマンドを実行できます。

例えば、次のコードでは、`sheet.command.set-range-values` コマンドでセル A1 の値を設定します。

```typescript
const univerAPI = FUniver.newAPI(univer)

// コマンドを実行
univerAPI.executeCommand('sheet.command.set-range-values', {
  value: { v: 'Hello, Univer!' },
  range: { startRow: 0, startColumn: 0, endRow: 0, endColumn: 0 },
})
```

## イベント API

Univerは、スプレッドシート内で起こる変更のためのイベントをディスパッチします。そのため、アプリケーションはそれらを聞き取り、応答することができます。イベントは、クリップボードの操作、選択の変更、セルの相互作用、シートの変更などのグループに分類されます。

### イベントカテゴリ

完全なイベントリスト: /reference/facade/events

1. **クリップボードイベント**
   - `BeforeClipboardChange`: クリップボードのコンテンツの変更前の火炎;変更を妨げるために`params.cancel = true`を置く
   - `BeforeClipboardPaste`: コンテンツが貼り付けられる前に火を発火します。 ペーストをブロックするために`params.cancel = true`を設定
   - `ClipboardChanged`:新しい内容のクリップボードの内容の変更の後で火を、防いで下さい
   - `ClipboardPasted`:過去のコンテンツでコンテンツが貼り付けられた後の火災

2. **選択イベント**
   - `SelectionChanged`:選択が変更されたとき、新しい選択範囲の火を始動させました
   - `SelectionMoveStart`:選択が移動を始めるとき火は、カスタム選択の効果を可能にします
   - `SelectionMoveEnd`:選択が動き、最終的な範囲と動かす停止するとき火
   - `SelectionMoving`:選択が動く間、火をつけて下さい、生きているUIの更新を支えます
   - `DragOver`: コンテンツがセル上にドラッグされている間に火をつける
   - `Drop`: ドラッグされたコンテンツが削除されたときに火をつけます

3. **セルイベント**
   - `CellClicked`:細胞がクリックされたとき、その位置および内容の火を発します
   - `CellHover`:ツールチップをサポートするポインタがセルの上にホバーするときに火をつけます
   - `CellPointerDown`:ポインタがセルに押下されると火を発火し、ドラッグまたは選択を開始するために使用されます
   - `CellPointerUp`: ポインタが細胞に解放されるとき火;操作を終えるのに使用される
   - `CellPointerMove`: ポインタが細胞上を移動するときに火を発します

4. **シートイベント**
   - `SheetValueChanged`:シート値が変更された範囲および新しい値と変わるとき火を発します
   - `SheetZoomChanged`:新しいズーム比でズームレベルが変わるとき火を発します
   - `SheetSkeletonChanged`: シート構造が変更されたとき、例えば行や列がインサートまたは削除されるときの火災
   - `BeforeSheetEditStart`: 細胞編集が始まる前の火炎; 編集が許可されるかどうかを制御するために使用される
   - `SheetEditStarted`: 細胞の編集が始まるとき火を始動させます; 注文の編集者の行動のために使用される
   - `BeforeSheetEditEnd`: 細胞の編集の端の前の火炎; コンテンツの検証に使用される
   - `SheetEditEnded`:編集された価値の細胞の編集の端、時火を消して下さい
   - `SheetEditChanging`: 細胞の編集の間に火を発します; ライブ検証またはフォーマットのために使用される
   - `Scroll`: シートがスクロールすると、スクロール位置で火が鳴ります
   - `CrosshairHighlightEnabledChanged`: 十字架のハイライトが有効または無効になったときの火

5. **ヘッダーイベント**
   - `RowHeaderClick`:行ヘッダーがクリックされたときに火をつけます
   - `RowHeaderHover`: ポインタが行ヘッダの上にホバーするときに火をつけます
   - `ColumnHeaderClick`: 列のヘッダーがクリックされたときに火をつけます
   - `ColumnHeaderHover`: カラムヘッダの上にポインタがホバーする場合の火

6. **データ検証イベント**
   - `BeforeSheetDataValidationAdd`:データ検証ルールが追加された前に火をつけます
   - `SheetDataValidationChanged`:データ検証ルールが変更されたときに火をつけます
   - `SheetDataValidatorStatusChanged`:データ検証状況が変化する際の火災

7. **コメントイベント**
   - `BeforeCommentAdd`:コメントが加えられる前に火をつけて下さい
   - `CommentAdded`:コメントが加えられた後の火
   - `BeforeCommentUpdate`:コメントが更新される前に火をつけて下さい
   - `CommentUpdated`:コメントが更新された後の火災
   - `BeforeCommentDeleted`: コメントが削除される前に火をつけます
   - `CommentDeleted`: コメントが削除された後の火災

8. **データ処理イベント**
   - `SheetBeforeRangeSort`: 範囲がソートされる前の火
   - `SheetRangeSorted`: 範囲がソートされた後の火災
   - `SheetBeforeRangeFilter`:範囲がろ過される前に火を発します
   - `SheetRangeFiltered`:範囲がろ過されるの後で火を始動させます
   - `BeforePivotTableAdd`: ピボットテーブルの前に火が加えられます
   - `PivotTableAdded`: ピボットテーブルが追加された後の火

### イベントの使用

リスナーを登録するために`univerAPI`で`addEvent`を呼び出します。 パターンは、すべてのイベントで同じです。

```typescript
univerAPI.addEvent(univerAPI.Event.EventName, (params) => {
  // イベントパラメータを処理
})
```

#### 例：セルクリックのリスニング

```typescript
univerAPI.addEvent(univerAPI.Event.CellClicked, (params) => {
  const { worksheet, workbook, row, column } = params
  console.log(`セルがクリックされました：行 ${row}、列 ${column}`)
})
```

#### 例：クリップボード操作の監視

```typescript
univerAPI.addEvent(univerAPI.Event.BeforeClipboardPaste, (params) => {
  const { text, html } = params
  // クリップボード貼り付けをキャンセルしたい場合
  params.cancel = true
})
```

#### 例：選択変更の追跡

```typescript
univerAPI.addEvent(univerAPI.Event.SelectionChanged, (params) => {
  const { worksheet, workbook, selections } = params
  console.log('選択が変更されました:', selections)
})
```

### イベントリスナーのキャンセル

イベントリスナーは、`IDisposable`オブジェクトを返します。不要になったときにリスナーを削除するために使用します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetValueChanged, (params) => {
  // 値変更を処理
})

// 後でリスナーを削除したい場合：
disposable.dispose()
```

### ベストプラクティス

1. 不要になったイベントリスナーの処分。そうしないとメモリを漏らす。
2. ユースケースにマッチするイベントを選択し、一般的なイベントを優先します。
3. イベントの火災を毎回実行するので、イベントハンドラを軽量に保ちます。
4. デフォルトの動作をブロックするには、`BeforeClipboardChange` または別の "before" イベントを使用します。

## システムクリップボード

`FUniver.copy()`と`FUniver.paste()`は、システムクリップボードに読み書きします。

<Callout>
  ブラウザのネイティブ API に依存してコピーして貼り付けます。環境や権限が許可されていない場合は、操作は行いません。 [MDN ドキュメント](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/writeText) を参照してください。
</Callout>

以下の例では、シート範囲をコピーして貼り付けます。

```typescript
// コンソールでコピーと貼り付けコードを実行する際のフォーカス失失による失敗を防ぐため、
// この例ではセルクリックイベントをリスニングしてコピーと貼り付けコードを実行します。
univerAPI.addEvent(univerAPI.Event.CellClicked, async (params) => {
  const fWorkbook = univerAPI.getActiveWorkbook()
  const fWorksheet = fWorkbook.getActiveSheet()

  // 範囲 A1:B2 をクリップボードにコピー
  const fRange = fWorksheet.getRange('A1:B2')
  fRange.activate().setValues([
    [1, 2],
    [3, 4],
  ])
  await univerAPI.copy()

  // コピーした内容を範囲 C1:D2 に貼り付け
  const fRange2 = fWorksheet.getRange('C1')
  fRange2.activate()
  await univerAPI.paste()

  // 貼り付けた内容を確認
  console.log(fWorksheet.getRange('C1:D2').getValues()) // [[1, 2], [3, 4]]
})
```

コマンドは、コマンドシステムで実行することもできます。

```typescript
import { CopyCommand, PasteCommand } from '@univerjs/ui'

// コピー
univerAPI.executeCommand(CopyCommand.id)
// 貼り付け
univerAPI.executeCommand(PasteCommand.id)
```

## WebSocket

Facade API は `createSocket` を提供します。 URL を付与し、WebSocket 接続を開きます。 接続は、オープン、メッセージ、クローズ、エラーイベントを明示します。 メッセージは `send` メソッドで送信され、接続は `close` メソッドで終了します。

プリセットのインストールでは、`univerAPI.createSocket(url)` を直接呼び出すことができます。 部分的なインストールでは、[`@univerjs/network`](/reference/packages/plugins/univerjs/network) パッケージをインストールし、`UniverNetworkPlugin` を登録します。

```typescript
// ... 他のプラグインインポートを省略
import { UniverNetworkPlugin } from '@univerjs/network'

// ... 他のファサードインポートを省略
import '@univerjs/network/facade'

// ... 他のプラグイン登録を省略
univer.registerPlugin(UniverNetworkPlugin)
```

以下は最小限の例です。

```typescript
// URLを独自のWebSocketサービスのアドレスに置き換えてください
const ws = univerAPI.createSocket('ws://47.100.177.253:8449/ws')

ws.open$.subscribe(() => {
  console.log('websocket opened')
  ws.send('hello')
})

ws.message$.subscribe((message) => {
  console.log('websocket message', message)
  const content = JSON.parse(message.data).content
  if (!content.includes('command')) {
    return
  }

  const commandInfo = JSON.parse(content)
  const { command, options } = commandInfo
  const { id, params } = command

  // コラボレーションデータを受信すると、ローカルに保存される
  univerAPI.executeCommand(id, params, options)
})

ws.close$.subscribe(() => {
  console.log('websocket closed')
})

ws.error$.subscribe((error) => {
  console.log('websocket error', error)
})

univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type, params, options }) => {
  // ローカル変更のみを同期
  if (
    type !== univerAPI.Enum.CommandType.MUTATION ||
    options?.fromCollab ||
    options?.onlyLocal ||
    id === 'doc.mutation.rich-text-editing'
  ) {
    return
  }

  const commandInfo = JSON.stringify({ command: { id, type, params }, options: { fromCollab: true } })
  ws.send(commandInfo)
})
```

Univer は unitID で起動しなければなりません。コラボレーションは 1 つなしで動作しません。

## 数式の登録

Facade API を介して現在の Univerインスタンスにカスタム式を登録できます。

次の例では、`CUSTOMSUM`の式が式プラグインに要求するアルゴリズム、名前、および説明を登録するために[`registerFunction`](https://docs.univer.ai/reference/facade/formula#registerfunction)を呼び出します。式は、任意の空白のセルに`=CUSTOMSUM`を入力すると、プロンプトが表示されます。

```typescript
// 登録された数式はラムダ関数をサポート
const formulaEngine = univerAPI.getFormula()
formulaEngine.registerFunction(
  'CUSTOMSUM',
  (...variants) => {
    let sum = 0
    const last = variants[variants.length - 1]

    if (last.isLambda && last.isLambda()) {
      variants.pop()
      const variantsList = variants.map((variant) => (Array.isArray(variant) ? variant[0][0] : variant))
      sum += last.executeCustom(...variantsList).getValue()
    }

    for (const variant of variants) {
      sum += Number(variant) || 0
    }

    return sum
  },
  'Adds its arguments',
)

// セル内で関数を使用
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const cellA1 = fWorksheet.getRange('A1')
cellA1.setValue(1)
const cellA2 = fWorksheet.getRange('A2')
cellA2.setValue(2)
const cellA3 = fWorksheet.getRange('A3')
cellA3.setValue({ f: '=CUSTOMSUM(A1,A2,LAMBDA(x,y,x*y))' })

// A3 は表示されます：5
formulaEngine.calculationEnd((functionsExecutedState) => {
  if (functionsExecutedState === 3) {
    console.log(cellA3.getValue()) // 5
  }
})
```

`dispose` を呼び出して、式を未登録します。

```typescript
const functionDisposable = formulaEngine.registerFunction({
  // 計算
})

// 関数の登録を解除
functionDisposable.dispose()
```


オプションは以下に記載されています。

- `func` は、アルゴリズムと式の名前のマッピングを保持しています。その入力は、数、文字列、ブール値、または配列であることができる式を使用するときにユーザーが入力するものです。
- `description` はカスタム数式の説明を設定します。
- `locales`は複数の言語を保持することができます。ネーミングルールは[ローカルタイプ](/reference/enums/locale-type)で記述されています。`functionList`は、1つの式以上のための翻訳を保持することができます。フィールドの詳細については、[フォーミュラエンジンで式を追加する方法](/blog/custom-formula#how-to-add-formulas-in-formula-engine)セクションを参照してください。

<Callout>
  式システムを既に提供し、それを拡張するアルゴリズムを再利用するには、プラグインの設定でカスタム式を登録します。 ウォークスルーの[カスタムフォーミュラ](/blog/custom-formula)を参照してください。
</Callout>
