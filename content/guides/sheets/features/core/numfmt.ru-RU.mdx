Форматы чисел контролируют, как число появляется в ячейке. Формат определяет число десятичных мест, используются ли тысячи разделителей, и показано ли значение в процентах или с символом валюты, среди других опций. После того, как формат установлен, данные легче читать.

Валютное действие на панели инструментов берет свой символ валюты и рисунок из Univer `region`. Если `region` не настроен явно, то следует `locale`:

```typescript
const univer = new Univer({
  locale: LocaleType.RU_RU,
  region: LocaleType.DE_DE,
})
```

<Callout type="warning" title="Осторожно">
  **Синтаксис DBNum** не поддерживается.
</Callout>

## Использование [#usage]

В пользовательском интерфейсе установите формат номера ячейки из строки меню. В коде установите поле [`s.n.pattern`](/guides/sheets/model/cell-data#number-format)[^number-format-value] объекта ячейки [`ICellData`](/guides/sheets/model/cell-data).

```typescript
const data = {
  v: 123456.789,
  s: {
    n: {
      pattern: '#,##0.00',
    },
  },
}
```

**По умолчанию текст, начинающийся с 0, и числа, которые могут быть интерпретированы как даты, автоматически преобразуются в соответствующий формат чисел.**

Чтобы предотвратить автоматическое преобразование, используйте один из следующих двух вариантов:

1. Установите формат номера ячейки для текста.

```typescript
import { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

const data = {
  v: '012.0',
  s: {
    n: {
      pattern: DEFAULT_TEXT_FORMAT_EXCEL, // Text format
    },
  },
}
```

Формат также может быть установлен через Facade API:

```typescript
fRange.setNumberFormat(DEFAULT_TEXT_FORMAT_EXCEL)
```

2. Введите одну цитату `'` перед номером. Это называется [Навязывание текста](/guides/sheets/model/cell-data#cell-type).

`UniverSheetsNumfmtPlugin` предоставляет два варианта, `disableTextFormatAlert` и `disableTextFormatMark`, чтобы отключить предупреждение и маркер для ячеек, отформатированных в виде текста.

Объединение этих опций в существующую инициализацию для используемого режима интеграции.Сохраняйте другой плагин, локализацию, тему и настройки контейнера и не регистрируйте один и тот же плагин дважды.

## Настройка плагинов [#plugin-configuration]

`UniverSheetsNumfmtPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | Отключает текстовое предупреждение. |
| `disableTextFormatMark` | `boolean` | `false` | Отключает маркер текстового формата. |

```typescript
import { UniverSheetsNumfmtPlugin } from '@univerjs/sheets-numfmt'

univer.registerPlugin(UniverSheetsNumfmtPlugin, {
  disableTextFormatAlert: true,
  disableTextFormatMark: true,
})
```

## Настройка пресетов [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | Отключает текстовое предупреждение. |
| `disableTextFormatMark` | `boolean` | `false` | Отключает маркер текстового формата. |

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import { createUniver } from '@univerjs/presets'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      disableTextFormatAlert: true,
      disableTextFormatMark: true,
    }),
  ],
})
```

## Facade API

### Импорт

</Callout>

```typescript
import '@univerjs/sheets-numfmt/facade'
```

### Установка числового формата

Для синтаксиса шаблонов см. https://support.microsoft.com/en-us/office/number-format-codes-5026bbd6-04bc-48cd-bf33-80f18b4eae68

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set the number format of the A1 cell to '#,##0.00'.
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')
fRange.getDisplayValue() // 1,234.57
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set the number formats of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues([
  [1234.567, 0.1234],
  [45658, 0.9876],
]).setNumberFormats([
  ['#,##0.00', '0.00%'],
  ['yyyy-MM-DD', ''],
])
fRange.getDisplayValues() // [['1,234.57', '12.34%'], ['2025-01-01', 0.9876]]
```

### Получение числового формата

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get the number format of the top-left cell of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormat()
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get the number formats of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormats()
```

### Установка локали числового формата

[`FWorkbook.setNumfmtLocal(local)`](https://docs.univer.ai/reference/facade/workbook#setnumfmtlocal) устанавливает местоположение, используемое для форматирования чисел.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')

// Set the locale en for number formatting.
fWorkbook.setNumfmtLocal('en')
fRange.getDisplayValue() // 1,234.57

// Set the locale de for number formatting.
fWorkbook.setNumfmtLocal('de')
fRange.getDisplayValue() // 1.234,57
```

[^number-format-value]: Числовой формат меняет отображение, но не сохранённое значение. Формат `0%` показывает `0.25` как `25%`, но формулы используют `0.25`.

## Локализованные форматы дат [#localized-date-presets]

Панель формата даты извлекает свои заданные шаблоны и предварительные просмотры из текущего Univer `locale`. Существующие пользовательские шаблоны дат остаются доступными. Изменение выбранного диапазона обновляет панель, чтобы ее элементы управления соответствовали текущим ячейкам.
