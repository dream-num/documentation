숫자 형식은 셀에 어떻게 나타나는지 제어합니다. 형식은 수천 개의 구분이 사용되는지, 수천 개의 구분자가 사용되는지, 값이 비율 또는 통화 기호로 표시되는지 여부를 결정합니다. 형식이 설정되면 데이터가 읽기가 쉽습니다.

도구 모음의 통화 행동은 Univer의 `region`에서 통화 기호와 패턴을 취합니다. `region`가 명시적으로 구성되지 않은 경우 `locale`를 다음과 같습니다.

```typescript
const univer = new Univer({
  locale: LocaleType.KO_KR,
  region: LocaleType.DE_DE,
})
```

<Callout type="warning" title="주 메뉴">
  **DBNum 구문**는 지원되지 않습니다.
</Callout>

## 사용법 [#usage]

UI에서, 메뉴 막대기에서 세포의 수 체재를 놓으십시오. 부호에서는, 세포의 [`ICellData`](/guides/sheets/model/cell-data) 목표의 [`s.n.pattern`](/guides/sheets/model/cell-data#number-format)[^number-format-value] 분야를 놓습니다.

```typescript
const data = {
  v: 123456.789,
  s: {
    n: {
      pattern: '#,##0.00',
    },
  },
}
```

**기본적으로 날짜로 해석할 수 있는 0과 숫자로 시작하는 텍스트는 해당 번호 형식으로 자동 변환됩니다.**

자동 변환을 방지하려면 다음 두 가지 옵션 중 하나를 사용하십시오.

1. 텍스트에 셀의 수 형식을 설정합니다.

```typescript
import { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

const data = {
  v: '012.0',
  s: {
    n: {
      pattern: DEFAULT_TEXT_FORMAT_EXCEL, // Text format
    },
  },
}
```

체재는 또한 Facade API를 통해서 놓일 수 있습니다:

```typescript
fRange.setNumberFormat(DEFAULT_TEXT_FORMAT_EXCEL)
```

2. 번호 앞에 단 하나 따옴표 `'`를 타자를 치십시오. 이것은 [본문 바로가기](/guides/sheets/model/cell-data#cell-type)에게 불립니다.

`UniverSheetsNumfmtPlugin`는 두 가지 옵션을 제공합니다, `disableTextFormatAlert` 및 `disableTextFormatMark`, 경고를 비활성화하고 텍스트로 포맷 된 셀에 대한 마커.

이 옵션은 사용중인 통합 모드에 대한 기존 초기화에 해당합니다. 다른 플러그인, Locale, 테마 및 컨테이너 설정을 유지하고 같은 플러그인을 두 번 등록하지 마십시오.

## 플러그인 설정 [#plugin-configuration]

`UniverSheetsNumfmtPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | 텍스트 형식 경고를 비활성화. |
| `disableTextFormatMark` | `boolean` | `false` | 텍스트 형식 마커를 비활성화합니다. |

```typescript
import { UniverSheetsNumfmtPlugin } from '@univerjs/sheets-numfmt'

univer.registerPlugin(UniverSheetsNumfmtPlugin, {
  disableTextFormatAlert: true,
  disableTextFormatMark: true,
})
```

## 프리셋 설정 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | 텍스트 형식 경고를 비활성화. |
| `disableTextFormatMark` | `boolean` | `false` | 텍스트 형식 마커를 비활성화합니다. |

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import { createUniver } from '@univerjs/presets'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      disableTextFormatAlert: true,
      disableTextFormatMark: true,
    }),
  ],
})
```

## Facade API

### 가져오기

<Callout type="info" title="플러그인 모드 참고">
  플러그인 모드에서 Facade 패키지는 별도로 수입됩니다. 미리 설정 모드는 일치하는 Facade 포장을 포함하므로 추가 수입이 필요하지 않습니다.
</Callout>

```typescript
import '@univerjs/sheets-numfmt/facade'
```

### 숫자 형식 설정

패턴 문법은 https://support.microsoft.com/en-us/office/number-format-codes-5026bbd6-04bc-48cd-bf33-80f18b4eae68를 참조하십시오.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set the number format of the A1 cell to '#,##0.00'.
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')
fRange.getDisplayValue() // 1,234.57
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set the number formats of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues([
  [1234.567, 0.1234],
  [45658, 0.9876],
]).setNumberFormats([
  ['#,##0.00', '0.00%'],
  ['yyyy-MM-DD', ''],
])
fRange.getDisplayValues() // [['1,234.57', '12.34%'], ['2025-01-01', 0.9876]]
```

### 숫자 형식의 로캘 설정

[`FWorkbook.setNumfmtLocal(local)`](https://docs.univer.ai/reference/facade/workbook#setnumfmtlocal)는 형식 번호에 사용되는 Locale를 설정합니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')

// Set the locale en for number formatting.
fWorkbook.setNumfmtLocal('en')
fRange.getDisplayValue() // 1,234.57

// Set the locale de for number formatting.
fWorkbook.setNumfmtLocal('de')
fRange.getDisplayValue() // 1.234,57
```

[^number-format-value]: 숫자 서식은 표시만 바꾸고 저장된 값은 바꾸지 않습니다. `0.25`에 `0%` 서식을 적용하면 `25%`로 표시되지만 수식은 `0.25`로 계산합니다.

## 지역별 날짜 프리셋 [#localized-date-presets]

날짜 형식 패널은 Univer의 현재 `locale`에서 미리 설치 패턴과 미리보기를 파생합니다. 사용자 정의 날짜 패턴을 기존하는 것은 사용할 수 있습니다. 선택한 범위를 변경하면 현재 셀과 일치하도록 패널을 새로 고침합니다.
