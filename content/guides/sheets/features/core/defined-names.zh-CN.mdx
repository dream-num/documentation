定义名称用于给单元格、单元格区域或公式指定一个自定义名称。公式可以直接引用该名称，不必再写出原始地址，因此更易读，也更易维护。

- 公式更接近其实际含义。`销售总额` 比 `A1 + A2 + A3` 表达得更清楚。
- 多个单元格或复杂的区域可以用一个名称表示。把 `A1:A10` 定义为 `销售数据`，然后在公式中使用 `销售数据`。
- 数据区域只需在一个地方维护。区域发生变化时，更新名称的引用，而不必逐个修改使用该名称的公式。

## 使用方法

名称管理器的入口是工作表左上角名称框旁边的下拉箭头。点击后可以看到所有已定义的名称，并打开名称管理器，查看、编辑和删除定义名称均在此完成。

<DefinedNamesDemo />

在公式里可以直接写名称。例如名称是 `销售总额`，写 `=销售总额` 就会引用它指向的范围。

## 注意事项

- 在同一工作表中，定义名称必须唯一，不能与其他名称或内置函数冲突。
- 名称不能以数字开头，不能包含空格或 `!`、`@`、`#` 这类特殊字符。输入的名称不符合规则时，系统会提示错误。
- 要修改名称，重新打开“定义名称”编辑面板，选中名称并完成修改，再点击“确定”保存。
- 要删除名称，在“定义名称”编辑面板里选中它，点击“删除”。删除后，引用该名称的公式将失效。
- 定义名称可以在同一工作簿的不同工作表之间共用，但唯一性规则仍然适用：在不同工作表上定义相同的名称，会使引用产生歧义。
- 名称应具有明确含义，避免过短或含义模糊的名称，以便其他人理解和维护工作表。
- 使用定义名称的公式出现问题时，可以检查名称是否正确、引用范围是否准确、是否有其他名称与它冲突。名称管理器面板会列出所有已定义的名称及其引用范围。
- 定义名称可以设在工作簿级别或工作表级别。工作簿级别的名称在整个工作簿中可用，工作表级别的名称仅在对应的工作表上可用。

## Facade API

完整的 Facade API 类型定义见 [Facade API](/reference/facade)。

### 创建定义名称

`FWorkbook.newDefinedNameBuilder()` 创建一个定义名称构建器，并返回 `FDefinedNameBuilder`。链式调用它的方法，可以生成用于创建定义名称的 `ISetDefinedNameMutationParam` 对象。

以下是 [`FDefinedNameBuilder`](/reference/facade/defined-name-builder) 的部分成员方法：

| 方法 | 描述 |
| ---- | ---- |
| build | 构建定义名称对象 |
| setName | 设置定义名称 |
| setFormula | 设置定义名称的公式 |
| setRef | 设置定义名称的引用范围 |
| setComment | 设置定义名称的注释 |
| setScopeToWorksheet | 设置定义名称为某个工作表可用 |
| setScopeToWorkbook | 设置定义名称为整个工作簿可用 |

[`FWorkbook.insertDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#insertdefinednamebuilder) 创建整个工作簿可用的定义名称。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedNameParam = fWorkbook.newDefinedNameBuilder()
  .setName('MyDefinedName')
  .setRef('Sheet1!$A$1')
  .setComment('A reference to A1 cell in Sheet1')
  .build()
fWorkbook.insertDefinedNameBuilder(definedNameParam)
```

也可以用 [`FWorkbook.insertDefinedName()`](https://docs.univer.ai/reference/facade/workbook#insertdefinedname) 快速创建定义名称。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.insertDefinedName('MyDefinedName', 'Sheet1!$A$1')
```

其他方法：
- [`FWorksheet.insertDefinedName()`](https://docs.univer.ai/reference/facade/worksheet#insertdefinedname)：创建某个工作表可用的定义名称。

### 获取定义名称

[`FWorkbook.getDefinedName()`](https://docs.univer.ai/reference/facade/workbook#getdefinedname) 从工作簿中获取一个定义名称，返回 `FDefinedName` 实例。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

if (definedName) {
  definedName.setName('NewDefinedName')
}
```

其他方法：
- [`FWorkbook.getDefinedNames()`](https://docs.univer.ai/reference/facade/workbook#getdefinednames) 获取工作簿里所有已定义的名称，返回 `FDefinedName[]` 数组。
- [`FWorksheet.getDefinedNames()`](https://docs.univer.ai/reference/facade/worksheet#getdefinednames) 获取这个工作表可用的所有定义名称，返回 `FDefinedName[]` 数组。

### 修改定义名称

`FWorkbook.updateDefinedNameBuilder()` 修改工作簿中的定义名称。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// 更新定义名称
if (definedName) {
  const newDefinedNameParam = definedName.toBuilder()
    .setName('NewDefinedName')
    .setRef('Sheet1!$A$2')
    .build()
  fWorkbook.updateDefinedNameBuilder(newDefinedNameParam)
}
```

也可以直接在返回的 [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name) 实例上修改配置。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// 更新定义名称
if (definedName) {
  definedName.setName('NewDefinedName')
  definedName.setRef('Sheet1!$A$2')
}
```

### 删除定义名称

[`FWorkbook.deleteDefinedName()`](https://docs.univer.ai/reference/facade/workbook#deletedefinedname) 删除工作簿中的定义名称。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.deleteDefinedName('MyDefinedName')
```

也可以通过返回的 [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name) 实例删除。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// 删除定义名称
if (definedName) {
  definedName.delete()
}
```
