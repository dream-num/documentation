## Facade API

完整的类型定义见 [Facade API](/reference/facade)。

### 行 Row

#### 在指定行后插入行

[`insertRowAfter(afterPosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowafter): 在指定行后插入一行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 这将在第一行位置后插入一行
sheet.insertRowAfter(0)
```

#### 在指定行前插入行

[`insertRowBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowbefore): 在指定行前插入一行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 这将在第一行位置前插入一行
sheet.insertRowBefore(0)
```

#### 插入多行

[`insertRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#insertrows): 从指定位置开始插入一行或多行连续的空白行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 将所有行向下移动三位
sheet.insertRows(0, 3)
```

#### 在指定行后插入多行

[`insertRowsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsafter): 在指定行后插入指定数量的行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 这将在第一行后插入五行
sheet.insertRowsAfter(0, 5)
```

#### 在指定行前插入多行

[`insertRowsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsbefore): 在指定行前插入指定数量的行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 这在第一行之前插入五行
sheet.insertRowsBefore(0, 5)
```

#### 删除指定行

[`deleteRow(rowPosition)`](https://docs.univer.ai/reference/facade/worksheet#deleterow): 删除指定位置上的行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 行从 0 开始 - 这将删除第一行
sheet.deleteRow(0)
```

#### 删除多行

[`deleteRows(rowPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deleterows): 从指定位置开始删除指定数量的行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 行从 0 开始 - 这将删除前两行
sheet.deleteRows(0, 2)
```

#### 删除多行（不连续）

[`deleteRowsByPoints(rowPoints)`](https://docs.univer.ai/reference/facade/worksheet#deleterowsbypoints): 按一组行位置一次删除多行，这些行不必连续。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 行从 0 开始 - 这将删除第 3 行和第 5-7 行
fWorksheet.deleteRowsByPoints([2, [4, 6]])
```

#### 移动行

[`moveRows(rowSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#moverows): 将 `rowSpec` 选中的行移动到 `destinationIndex` 指定的位置。该范围不必与单行或一组行对齐，它跨过的每一行都会被选中。

```typescript
// 以下代码将行 1-2 移动到目标索引 5
// 这会导致这些行变为行 3-4
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 选择要移动的第 1 行和第 2 行
const rowSpec = sheet.getRange('1:2')
sheet.moveRows(rowSpec, 5)
```

#### 隐藏行

[`hideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#hiderow): 隐藏指定范围内的行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 这将隐藏第一行
const range = sheet.getRange('1:1')
sheet.hideRow(range)
```

#### 隐藏多行

[`hideRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#hiderows): 从指定索引开始隐藏连续的一行或多行。索引从 0 开始。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 隐藏前三行
sheet.hideRows(0, 3)
```

#### 取消隐藏行

[`unhideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#unhiderow): 取消隐藏指定范围内的行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 如果第一行之前被隐藏，则取消隐藏第一行
const range = sheet.getRange('1:1')
sheet.unhideRow(range)
```

#### 显示多行

[`showRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#showrows): 从指定索引开始取消隐藏连续的一行或多行。索引从 0 开始。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 取消隐藏前三行
sheet.showRows(0, 3)
```

#### 设置行高

[`setRowHeight(rowPosition, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheight): 设置指定行的行高，单位为像素。默认情况下，行会随单元格内容自动增高。要将高度固定为指定值，请使用 `setRowHeightsForced(startRow, numRows, height)`。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 将第一行的高度设置为 200 像素
sheet.setRowHeight(0, 200)
```

#### 设置多行高度

[`setRowHeights(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheights): 设置指定行的高度，单位为像素。默认情况下，行会随单元格内容自动增高。要将高度固定为指定值，请使用 `setRowHeightsForced(startRow, numRows, height)`。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 将前三行的高度设置为 200 像素
sheet.setRowHeights(0, 3, 200)
```

#### 强制设置多行高度

[`setRowHeightsForced(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheightsforced): 设置指定行的高度，单位为像素。默认情况下，行会随单元格内容自动增高。使用 `setRowHeightsForced` 后，即使内容高于行高，行也会保持设定的固定高度。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 将前三行的高度设置为 5 像素
sheet.setRowHeightsForced(0, 3, 5)
```

#### 设置行高自动调整

[`autoResizeRows(startRow, numRows)`](https://docs.univer.ai/reference/facade/worksheet#autoresizerows): 将指定行的高度调整为适应文字内容。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 设置前三行的高度自动调整以适应单元格内容
sheet.autoResizeRows(0, 3)
```

#### 设置行自定义属性

[`setRowCustom(custom)`](https://docs.univer.ai/reference/facade/worksheet#setrowcustom): 为指定行设置自定义属性。每行会保存一个 `custom` 对象，其中可以存放任意符合 JSON 格式的数据，用于存储额外信息。写入 `custom` 会覆盖原有的 `custom` 数据。若要保留已有的 `custom` 数据，应先读取 `custom` 对象，将其合并到新数据中，然后再写回。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 设置第一行和第三行的自定义属性
sheet.setRowCustom({
  0: { color: 'red' },
  2: { size: 16 },
})
```

## 尺寸校验与零尺寸行列 [#dimension-validation]

行高和列宽必须是有限且非负的数值。尺寸相关命令会拒绝数字字符串、负数、`NaN` 和 `Infinity`。单行或单列的尺寸可以为 0，而 `defaultRowHeight` 和 `defaultColumnWidth` 必须严格大于 0。创建工作表时，Univer 会规范化快照中的无效尺寸。

尺寸为 0 的行或列不同于通过可见性标记隐藏的行或列。对可见但尺寸为 0 的行或列取消隐藏，会将其恢复为工作表的默认尺寸，该操作可撤销、可重做。将外部尺寸传给编辑器之前，应先用下列公开的校验函数检查。

```ts
import { isValidColumnDimensions, isValidRowDimensions, isValidSheetDimension } from '@univerjs/core'

isValidSheetDimension(24) // true
isValidSheetDimension(0, false) // false: default dimensions must be positive
isValidRowDimensions({ h: 24, ah: 32 }) // true
isValidColumnDimensions({ w: -1 }) // false
```
