## Fassaden-API

Vollständige Fassaden-API-Typdefinitionen finden Sie in der [Fassaden-API](https://reference.univer.ai/en-US).

### Zeile

#### Zeile nach gegebener Position einfügen

[`insertRowAfter(afterPosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowafter): Fügt eine Zeile nach der angegebenen Zeile ein Position.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row after the first row position
sheet.insertRowAfter(0)
```

#### Zeile vor der angegebenen Position einfügen

[`insertRowBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowbefore): Fügt eine Zeile vor der angegebenen Zeilenposition ein.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row before the first row position
sheet.insertRowBefore(0)
```

#### Mehrere Zeilen an der angegebenen Position einfügen

[`insertRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#insertrows): Fügt eine oder mehrere aufeinanderfolgende leere Zeilen ein ein Blatt, das an der angegebenen Position beginnt.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Shifts all rows down by three
sheet.insertRows(0, 3)
```

#### Mehrere Zeilen nach der angegebenen Position einfügen

[`insertRowsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsafter): Fügt eine angegebene Anzahl von Zeilen nach der angegebenen Zeilenposition ein.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows after the first row
sheet.insertRowsAfter(0, 5)
```

#### Fügt mehrere Zeilen vor der angegebenen Position ein Position

[`insertRowsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsbefore): Fügt eine angegebene Anzahl von Zeilen vor der angegebenen Zeilenposition ein.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows before the first row
sheet.insertRowsBefore(0, 5)
```

#### Zeile an angegebener Position löschen

[`deleteRow(rowPosition)`](https://docs.univer.ai/reference/facade/worksheet#deleterow): Löscht die Zeile an der angegebenen Zeilenposition.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first row
sheet.deleteRow(0)
```

#### Löschen Sie mehrere Zeilen beginnend an der angegebenen Position

[`deleteRows(rowPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deleterows): Löscht eine angegebene Anzahl von Zeilen beginnend an der angegebenen Zeilenposition.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first two rows
sheet.deleteRows(0, 2)
```

#### Löschen mehrerer Zeilen an angegebenen Positionen

[`deleteRowsByPoints(rowPoints)`](https://docs.univer.ai/reference/facade/worksheet#deleterowsbypoints): Löscht mehrere Zeilen (nicht unbedingt aufeinanderfolgend), die durch ein Array von angegeben sind Zeilenpositionen.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the 3rd row and rows 5 to 7
fWorksheet.deleteRowsByPoints([2, [4, 6]])
```

#### Zeilen an neue Position verschieben

[`moveRows(rowSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#moverows): Verschiebt die vom angegebenen Bereich ausgewählten Zeilen an die durch `destinationIndex` angegebene Position. Der `rowSpec` selbst muss nicht genau eine ganze Zeile oder Gruppe von Zeilen darstellen, die verschoben werden sollen – er wählt alle Zeilen aus, die der Bereich umfasst.

```typescript
// The code below moves rows 1-2 to destination index 5
// This results in those rows becoming rows 3-4
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Selects row 1 and row 2 to be moved
const rowSpec = sheet.getRange('1:2')
sheet.moveRows(rowSpec, 5)
```

#### Zeilen im angegebenen Bereich ausblenden

[`hideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#hiderow): Versteckt die Zeilen im angegebenen Bereich.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This hides the first row
const range = sheet.getRange('1:1')
sheet.hideRow(range)
```

#### Mehrere aufeinanderfolgende Zeilen ausblenden

[`hideRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#hiderows): Versteckt eine oder mehrere aufeinanderfolgende Zeilen beginnend beim angegebenen Index. Verwenden Sie für diese Methode den 0-Index.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Hides the first three rows
sheet.hideRows(0, 3)
```

#### Zeile im angegebenen Bereich einblenden

[`unhideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#unhiderow): Blendet die Zeile im angegebenen Bereich ein.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This unhides the first row if it was previously hidden
const range = sheet.getRange('1:1')
sheet.unhideRow(range)
```

#### Mehrere aufeinanderfolgende Zeilen einblenden

[`showRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#showrows): Blendet eine oder mehrere aufeinanderfolgende Zeilen beginnend beim angegebenen Index ein. Verwenden Sie für diese Methode den 0-Index.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Unhides the first three rows
sheet.showRows(0, 3)
```

#### Zeilenhöhe festlegen

[`setRowHeight(rowPosition, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheight): Legt die Zeilenhöhe der angegebenen Zeile in Pixel fest. Standardmäßig werden Zeilen so vergrößert, dass sie in den Zelleninhalt passen. Wenn Sie Zeilen auf eine bestimmte Höhe erzwingen möchten, verwenden Sie `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first row to a height of 200 pixels
sheet.setRowHeight(0, 200)
```

#### Höhe für mehrere Zeilen festlegen

[`setRowHeights(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheights): Legt die Höhe der angegebenen Zeilen in Pixel fest. Standardmäßig werden Zeilen so vergrößert, dass sie in den Zelleninhalt passen. Wenn Sie Zeilen auf eine bestimmte Höhe erzwingen möchten, verwenden Sie `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 200 pixels
sheet.setRowHeights(0, 3, 200)
```

#### Festgelegte Höhe für mehrere Zeilen erzwingen

[`setRowHeightsForced(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheightsforced): Legt die Höhe der angegebenen Zeilen in Pixel fest. Standardmäßig werden Zeilen so vergrößert, dass sie in den Zelleninhalt passen. Wenn Sie `setRowHeightsForced` verwenden, werden Zeilen auf die angegebene Höhe gezwungen, auch wenn der Zellinhalt höher als die Zeilenhöhe ist.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 5 pixels
sheet.setRowHeightsForced(0, 3, 5)
```

#### Zeilengröße automatisch ändern

[`autoResizeRows(startRow, numRows)`](https://docs.univer.ai/reference/facade/worksheet#autoresizerows): Passt die Höhe der angegebenen Zeilen automatisch an ihren Textinhalt an.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set the first 3 rows to a height that fits their text.
sheet.autoResizeRows(0, 3)
```

#### Zeilen benutzerdefiniert festlegen Eigenschaften

[`setRowCustom(custom)`](https://docs.univer.ai/reference/facade/worksheet#setrowcustom): Legen Sie benutzerdefinierte Eigenschaften für bestimmte Zeilen fest, speichern Sie ein Objekt `custom` in der Zeile, in das Sie beliebige Daten einfügen können, die dem JSON-Format entsprechen, um einige zusätzliche Informationen benutzerdefinierte zu speichern.
Die Aktualisierung der `custom`-Daten erfolgt Überschreiben Sie die ursprünglichen `custom`-Daten. Wenn Sie beim Aktualisieren von Daten die ursprünglichen `custom`-Daten beibehalten müssen, rufen Sie bitte die `custom`-Daten im Voraus ab und führen Sie sie vor der Aktualisierung mit neuen Daten zusammen.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set custom properties for the first and third rows
sheet.setRowCustom({
  0: { color: 'red' },
  2: { size: 16 },
})
```

### Spalte

#### Spalte nach angegebener Position einfügen

[`insertColumnAfter(afterPosition)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumnafter): Fügt a ein Spalte nach der angegebenen Spaltenposition.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a column after the first column position
sheet.insertColumnAfter(0)
```

#### Spalte vor der angegebenen Position einfügen

[`insertColumnBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumnbefore): Fügt eine Spalte vor der angegebenen Spaltenposition ein.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a column in the first column position
sheet.insertColumnBefore(0)
```

#### Mehrere Spalten an der angegebenen Position einfügen

[`insertColumns(columnIndex, numColumns)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumns): Fügt ein eine oder mehrere aufeinanderfolgende leere Spalten in einem Blatt, beginnend an der angegebenen Position.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Shifts all columns by three
sheet.insertColumns(0, 3)
```

#### Fügen Sie mehrere Spalten nach der angegebenen Position ein

[`insertColumnsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumnsafter): Fügt eine bestimmte Anzahl von Spalten nach der angegebenen Spaltenposition ein.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Inserts two columns after the first column
sheet.insertColumnsAfter(0, 2)
```

#### Mehrere Spalten vor der angegebenen Position einfügen

[`insertColumnsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumnsbefore): Fügt eine Anzahl von Spalten vor der angegebenen Spalte ein Position.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five columns before the first column
sheet.insertColumnsBefore(0, 5)
```

#### Spalte an gegebener Position löschen

[`deleteColumn(columnPosition)`](https://docs.univer.ai/reference/facade/worksheet#deletecolumn): Löscht die Spalte an der gegebenen Spaltenposition.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Columns start at "0" - this deletes the first column
sheet.deleteColumn(0)
```

#### Mehrere Spalten beginnend an gegebener Position löschen

[`deleteColumns(columnPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deletecolumns): Löscht eine Reihe von Spalten beginnend an der angegebenen Spaltenposition.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Columns start at "0" - this deletes the first two columns
sheet.deleteColumns(0, 2)
```

#### Mehrere Spalten an angegebenen Positionen löschen

[`deleteColumnsByPoints(columnPoints)`](https://docs.univer.ai/reference/facade/worksheet#deletecolumnsbypoints): Löscht mehrere Spalten (nicht unbedingt aufeinanderfolgend), die durch ein Array von Spaltenpositionen angegeben sind.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Columns start at "0" - this deletes the Column C and Columns E-G
fWorksheet.deleteColumnsByPoints([2, [4, 6]])
```

#### Spalten nach neu verschieben position

[`moveColumns(columnSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#movecolumns): Verschiebt die vom angegebenen Bereich ausgewählten Spalten an die durch `destinationIndex` angegebene Position. Der `columnSpec` selbst muss nicht genau eine ganze Spalte oder eine Gruppe von Spalten darstellen, um sie zu verschieben – er wählt alle Spalten aus, die der Bereich umfasst.

```typescript
// The code below moves rows A-B to destination index 5.
// This results in those columns becoming columns C-D.
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Selects column A and column B to be moved.
const columnSpec = sheet.getRange('A:B')
sheet.moveColumns(columnSpec, 5)
```

#### Spalten im angegebenen Bereich ausblenden

[`hideColumn(column)`](https://docs.univer.ai/reference/facade/worksheet#hidecolumn): Blendet die Spalte oder Spalten im angegebenen Bereich aus.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This hides the first column
const range = sheet.getRange('A:A')
sheet.hideColumn(range)
```

#### Mehrere aufeinanderfolgende ausblenden columns

[`hideColumns(columnIndex, numColumns)`](https://docs.univer.ai/reference/facade/worksheet#hidecolumns): Versteckt eine oder mehrere aufeinanderfolgende Spalten beginnend beim angegebenen Index. Verwenden Sie für diese Methode den 0-Index.

```typescript

```

#### Spalte im angegebenen Bereich einblenden

```typescript

// This unhides the first column if it was previously hidden

sheet.unhideColumn(range)
```

#### Mehrere aufeinanderfolgende Spalten einblenden

[`showColumns(columnIndex, numColumns)`](https://docs.univer.ai/reference/facade/worksheet#showcolumns): Blendet eine oder mehrere aufeinanderfolgende Spalten ab dem angegebenen Index ein. Verwenden Sie für diese Methode den 0-Index.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Unhides the first three columns
sheet.showColumns(0, 3)
```

#### Spaltenbreite festlegen

[`setColumnWidth(columnPosition, width)`](https://docs.univer.ai/reference/facade/worksheet#setcolumnwidth): Legt die Breite der angegebenen Spalte in Pixel fest.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first column to a width of 200 pixels
sheet.setColumnWidth(0, 200)
```

#### Breite für mehrere Spalten festlegen

[`setColumnWidths(startColumn, numColumns, width)`](https://docs.univer.ai/reference/facade/worksheet#setcolumnwidths): Legt die Breite der Spalte fest angegebene Spalten in Pixeln.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three columns to a width of 200 pixels
sheet.setColumnWidths(0, 3, 200)
```

#### Größe der Spalten automatisch ändern

[`autoResizeColumns(startColumn, numColumns)`](https://docs.univer.ai/reference/facade/worksheet#autoresizecolumns): Legt die Breite der angegebenen Spalten so fest, dass sie automatisch an ihren Textinhalt angepasst werden.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set the A:C columns to a width that fits their text.
sheet.autoResizeColumns(0, 3)
```

#### Benutzerdefinierte Spalteneigenschaften festlegen

[`setColumnCustom(custom)`](https://docs.univer.ai/reference/facade/worksheet#setcolumncustom): Benutzerdefinierte Eigenschaften für gegebene festlegen Speichern Sie in den Spalten ein Objekt `custom` in der Spalte, in das Sie alle Daten einfügen können, die dem JSON-Format entsprechen, um einige zusätzliche Informationen benutzerdefinierte zu speichern.
Durch das Aktualisieren der `custom`-Daten werden die ursprünglichen `custom`-Daten überschrieben. Wenn Sie beim Aktualisieren von Daten die ursprünglichen `custom`-Daten beibehalten müssen, besorgen Sie sich bitte vorab die `custom`-Daten und führen Sie sie vor der Aktualisierung mit neuen Daten zusammen.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set custom properties for the first and third columns
sheet.setColumnCustom({
  0: { color: 'red' },
  2: { size: 16 },
})
```
