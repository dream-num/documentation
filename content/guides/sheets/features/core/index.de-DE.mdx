Zu den Kernfunktionen von Univer Sheets gehören ein Tabellenkalkulationseditor, eine Formel-Engine, eine Rendering-Engine, eine Zahlenformatierungs-Engine, ein Designsystem und eine UI-Komponentenbibliothek. Zusammen bilden sie eine leistungsstarke Plattform für die Handhabung von Tabellenkalkulationen und unterstützen verschiedene Formate und komplexe Vorgänge.

## Funktionen

Zu den Kernfunktionen von Univer Sheets gehören:

- **Spreadsheet-Rendering**: Unterstützt das Rendern von Univer Sheets, einschließlich Cursor- und Auswahlzeichnung.
- **Zellenstil**: Ermöglicht die Gestaltung von Zellen in der Tabelle, einschließlich Schriftart, Farbe, Rahmen und Ausrichtung.
- **Formelberechnung**: Unterstützt das Hinzufügen und Berechnen von Formeln in der Tabelle und deckt nahezu alle Excel-Funktionen ab, einschließlich mathematischer, statistischer, Text- und Datumsfunktionen.
- **Zahlenformatierung**: Ermöglicht die Formatierung von Zahlen in der Tabelle, einschließlich Währung, Prozentsatz, Datumsformate usw.
- **Gitternetzlinien und eingefroren Bereiche**: Unterstützt die Anzeige von Gitternetzlinien und eingefrorenen Bereichen und erleichtert Benutzern das Anzeigen und Bearbeiten großer Datensätze.
- **Standardstile**: Ermöglicht das Festlegen von Standardstilen für die Tabelle, einschließlich Standardschriftart, -größe, -farbe usw.
- **Plugin-System**: Unterstützt ein Plugin-System, das benutzerdefinierte Plugins wie Formel-Plugins, Bild-Plugins, Diagramm-Plugins usw. ermöglicht. Dies ist auch eine der zentralen Architekturfunktionen von Univer.

## Voreinstellungsmodus

### Installation

```package-install
npm install @univerjs/presets @univerjs/preset-sheets-core
```

### Verwendung

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
  ],
})

univerAPI.createWorkbook({})
```

### Voreinstellungen und Konfiguration

#### @univerjs/presets

Diese Voreinstellung stellt die Methode `createUniver` zum Erstellen einer Univer-Anwendung bereit und macht alle Methoden und Objekte von **@univerjs/core** und **@univerjs/design** verfügbar.

Die Die Methode `createUniver` akzeptiert ein Konfigurationsobjekt, das Optionen für Thema, Sprache, Voreinstellungen usw. enthält. Sie gibt eine `Univer`-Instanz `univer` und eine `FUniver`-Instanz `univerAPI` zum Aufrufen der Facade-API zurück.

```typescript
interface CreateUniverParameter {
  // Univer instance theme, default is `defaultTheme`
  theme: IStyleSheet
  // Whether to use dark mode, default is false
  darkMode?: boolean
  // The locale of the Univer instance
  locale: LocaleType
  region?: LocaleType
  // The locale objects to use, with keys as locale types and values as corresponding locale objects
  locales: ILocales
  // The log level of the Univer instance
  logLevel?: LogLevel
  // The list of presets to use.
  presets: IPresets[]
  // The list of plugins to use.
  plugins: IPlugins[]
}
```

Referenz: [`createUniver`(https://docs.univer.ai/reference/methods/create-univer)

#### @univerjs/preset-sheets-core

Diese Voreinstellung ist die Kernvoreinstellung von Univer Sheets, die die notwendigen Kernfunktionen für die Dokumentbearbeitung, die Formel-Engine, die Rendering-Engine usw. enthält.

```typescript
interface IUniverSheetsCorePresetConfig {
  // Container element, can be a string or a DOM element
  container?: string | HTMLElement
  // Whether to show the header
  header?: boolean
  // Whether to show the header toolbar
  toolbar?: boolean
  // The type of the header toolbar. 'classic': default classic mode; 'collapsed': compact mode; 'simple': ungrouped mode
  ribbonType?: RibbonType
  // Whether to show the footer
  footer?: false | {
    // Sheet bar is the sub-sheet manager, including adding/switching/deleting sub-sheets.
    sheetBar?: boolean
    // Statistic bar includes statistics of the current selection, such as count, sum, average, etc.
    statisticBar?: boolean
    // The bottom menu includes options like highlight, gridlines, etc.
    menus?: boolean
    // The zoom slider at the bottom.
    zoomSlider?: boolean
    /**
     * The config of the add sheet button in the sheet bar.
     */
    addSheetButtonConfig?: {
      /**
       * Whether to show the add sheet button in the sheet bar.
       * When `footer` or `footer.sheetBar` is false, this config will not work because the sheet bar will not be rendered.
       * @default true
       */
      show?: boolean
      /**
       * The default row count of the new sheet created by the add sheet button.
       * @default 1000
       */
      defaultRowCount?: number
      /**
       * The default column count of the new sheet created by the add sheet button.
       * @default 20
       */
      defaultColumnCount?: number
    }
  }
  // Whether to show the context menu
  contextMenu?: boolean
  // Whether to disable auto focus
  disableAutoFocus?: true
  // Dependency injection override configuration
  override?: DependencyOverride
  // Menu configuration
  menu?: MenuConfig

  sheets?: {
    // If both row style and column style are set, whether row style precedes column style
    isRowStylePrecedeColumnStyle?: boolean
    // Whether auto height applies to merged cells
    autoHeightForMergedCells?: boolean
    /**
     * Whether synchronize the frozen state to other users in real-time collaboration.
     * @default true
     */
    freezeSync?: boolean

    clipboardConfig?: {
      // Whether to show the paste options button after paste operation
      hidePasteOptions?: boolean
    }
    // The configuration for the scroll bar
    scrollConfig?: IScrollBarProps
    /**
     * Strategy for showing the protected range shadow.
     * - true or 'always': Show shadow for all protected ranges (default behavior)
     * - 'non-editable': Only show shadow for ranges that cannot be edited (Edit permission is false)
     * - 'non-viewable': Only show shadow for ranges that cannot be viewed (View permission is false)
     * - false or 'none': Never show shadow for protected ranges
     * @default true
     */
    protectedRangeShadow?: boolean | 'always' | 'non-editable' | 'non-viewable' | 'none'
    // Whether to disable the force string alert.
    disableForceStringAlert?: boolean
    // Whether to disable the force string mark.
    disableForceStringMark?: boolean
  }

  // ... More configuration options
}
```

Mit der Konfigurationsoption `menu` können Sie einfach den Anzeige- oder Ausblendungsstatus bestimmter spezifischer Menüelemente festlegen:

```typescript
UniverSheetsCorePreset({
  menu: {
    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

Hier sind `'sheet.command.set-range-bold'` und `'sheet.command.set-range-italic'` die Namen der Befehle. Anzeige der entsprechenden Menüpunkte. Sie können sich auf die [Menüelement-ID-Liste](#menu-item-id-list) unten beziehen.

Referenz: [@univerjs/preset-sheets-core(https://docs.univer.ai/reference/packages/presets/univerjs/preset-sheets-core)

## Symbolleistenlayout und `RibbonType`

Durch die Konfiguration des `ribbonType`-Eigenschaft in `IUniverSheetsCorePresetConfig` oder `IUniverUIConfig` können Sie das Layout der Symbolleiste festlegen.

`ribbonType` unterstützt die folgenden drei Modi:

- `classic`: Standardmäßiger klassischer Modus, mit Gruppen oben und der Symbolleiste gelegt siehe unten, geeignet für Benutzer, die mit herkömmlichen Layouts vertraut sind.
- `collapsed`: Kompakter Modus, in dem Gruppen und die Symbolleiste in derselben Zeile angeordnet sind, geeignet für Szenarien mit begrenztem vertikalen Bildschirmbereich.
- `simple`: Ungruppierter Modus, in dem alle Werkzeuge in einer flachen Liste platziert sind, geeignet für Benutzer, die mit Symbolleistenfunktionen vertraut sind.
