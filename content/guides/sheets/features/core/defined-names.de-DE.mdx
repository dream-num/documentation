---
title: Definierte Namen
---

Definierte Namen sind eine Funktion, mit der Benutzer Zellen, Zellbereichen oder Formeln benutzerdefinierte Namen zuweisen können. Durch die Benennung können Benutzer Daten intuitiver referenzieren, Formeln vereinfachen und die Lesbarkeit, Wartbarkeit und Professionalität des Arbeitsblatts verbessern.

- **Verbessert die Lesbarkeit von Formeln**: Die Verwendung definierter Namen kann das Verständnis von Formeln erleichtern. Wenn Sie beispielsweise `Amount` anstelle von `A1 + A2 + A3` verwenden, wird die Bedeutung der Formel klarer.
- **Vereinfacht komplexe Referenzen**: Bei der Referenzierung mehrerer Zellen oder komplexer Bereiche können definierte Namen diese Referenzen vereinfachen. Sie können beispielsweise `SalesData` für `A1:A10` definieren und `SalesData` direkt in Formeln verwenden.
- **Erleichtert die einheitliche Verwaltung von Datenbereichen**: Definierte Namen können Benutzern dabei helfen, Datenbereiche besser zu verwalten. Wenn sich der Datenbereich ändert, müssen Sie nur die definierte Namensreferenz aktualisieren, anstatt alle Formeln einzeln zu ändern.

## Verwendung

Der Namensmanager-Eintrag befindet sich neben dem Namensfeld in der oberen linken Ecke des Blatts, wo Sie eine Liste aller definierten Namen sehen und auf den Namensmanager zugreifen können. Über den Namensmanager können Benutzer definierte Namen anzeigen, bearbeiten und löschen.

![Definierte Namen](./defined-names/defined-names.png)

Wenn Sie definierte Namen in Formeln verwenden, können Sie den Namen einfach direkt eingeben. Wenn Sie beispielsweise einen Namen als `TotalSales` definiert haben, können Sie `=TotalSales` in Ihrer Formel verwenden, um auf diesen Bereich zu verweisen.

## Hinweise

- **Eindeutigkeit von Namen**: Definierte Namen müssen innerhalb desselben Arbeitsblatts eindeutig sein und dürfen nicht mit anderen Namen oder integrierten Funktionen in Konflikt geraten.
- **Gültigkeit von Namen**: Definierte Namen dürfen nicht mit beginnen eine Zahl und darf keine Leerzeichen oder Sonderzeichen enthalten (z. B. `!`, `@`, `#` usw.). Wenn der eingegebene Name nicht den Regeln entspricht, gibt das System eine Fehlermeldung aus.
- **Aktualisieren definierter Namen**: Wenn Sie einen vorhandenen definierten Namen ändern müssen, können Sie das Bearbeitungsfeld „Name definieren“ erneut öffnen, den Namen auswählen, den Sie ändern möchten, und ihn bearbeiten. Nachdem Sie Änderungen vorgenommen haben, klicken Sie auf „OK“, um die Änderungen zu speichern.
- **Definierte Namen löschen**: Wenn ein definierter Name nicht mehr benötigt wird, können Sie ihn im Bearbeitungsfeld „Name definieren“ auswählen und auf die Schaltfläche „Löschen“ klicken, um ihn zu löschen. Nach dem Löschen sind die zugehörigen Formeln nicht mehr gültig.
- **Arbeitsblattübergreifende Verwendung**: Definierte Namen können in verschiedenen Arbeitsblättern innerhalb derselben Arbeitsmappe verwendet werden, Sie müssen jedoch auf die Eindeutigkeit der Namen achten. Wenn derselbe Name in verschiedenen Arbeitsblättern definiert ist, kann es zu Referenzverwirrungen kommen.
- **Namenskonventionen**: Es wird empfohlen, aussagekräftige Namen zu verwenden und zu kurze oder vage Namen zu vermeiden, um anderen Benutzern das Verständnis und die Wartung zu erleichtern.
- **Formeln debuggen**: Wenn bei der Verwendung definierter Namen Probleme auftreten, können Sie überprüfen, ob die Namen korrekt sind, ob die Referenzbereiche korrekt sind und ob Namenskonflikte vorliegen.
- **Nutzungsumfang**: Definierte Namen können auf Arbeitsmappenebene oder Arbeitsblattebene festgelegt werden. Namen auf Arbeitsmappenebene können in der gesamten Arbeitsmappe verwendet werden, während Namen auf Arbeitsblattebene nur innerhalb bestimmter Arbeitsblätter verwendet werden können.

## Fassaden-API

Vollständige Facade-API-Typdefinitionen finden Sie im [Fassaden-API](https://reference.univer.ai/en-US).

### Definierte Namen erstellen

`FWorkbook.newDefinedNameBuilder()` erstellt einen definierten Namensgenerator und gibt einen zurück `FDefinedNameBuilder` Instanz. Mithilfe der Methodenverkettung können Sie ein `ISetDefinedNameMutationParam`-Objekt zum Erstellen definierter Namen generieren.

Im Folgenden sind einige Mitgliedsmethoden von [`FDefinedNameBuilder`](https://docs.univer.ai/reference/facade/defined-name) aufgeführt:

| Methode | Beschreibung |
| ---- | ---- |
| build | Erstellt das definierte Namensobjekt |
| setName | Legt den definierten Namen fest |
| setFormula | Legt die Formel für den definierten fest Name |
| setRef | Legt den Referenzbereich für den definierten Namen fest |
| setComment | Legt den Kommentar für den definierten Namen fest |
| setScopeToWorksheet | Legt den definierten Namen so fest, dass er für ein bestimmtes Arbeitsblatt verfügbar ist |
| setScopeToWorkbook | Legt den definierten Namen so fest, dass er für die gesamte Arbeitsmappe verfügbar ist |

[`FWorkbook.insertDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#insertdefinednamebuilder) kann ein definierter Name erstellt werden, der für die gesamte Arbeitsmappe verfügbar ist.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedNameParam = fWorkbook.newDefinedNameBuilder()
  .setName('MyDefinedName')
  .setRef('Sheet1!$A$1')
  .setComment('A reference to A1 cell in Sheet1')
  .build()
fWorkbook.insertDefinedNameBuilder(definedNameParam)
```

[`FWorkbook.insertDefinedName()`](https://docs.univer.ai/reference/facade/workbook#insertdefinedname) kann schnell ein definierter Name erstellt werden.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.insertDefinedName('MyDefinedName', 'Sheet1!$A$1')
```

Sonstiges Methoden:
- [`FWorksheet.insertDefinedName()`](https://docs.univer.ai/reference/facade/worksheet#insertdefinedname): Erstellt einen definierten Namen, der für ein bestimmtes Arbeitsblatt verfügbar ist.

### Definierte Namen abrufen

Die Methode [`FWorkbook.getDefinedName()`](https://docs.univer.ai/reference/facade/workbook#getdefinedname) kann verwendet werden, um einen definierten Namen in der Arbeitsmappe abzurufen und eine `FDefinedName`-Instanz zurückzugeben.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

if (definedName) {
  definedName.setName('NewDefinedName')
}
```

Andere Methoden:
- [`FWorkbook.getDefinedNames()`](https://docs.univer.ai/reference/facade/workbook#getdefinednames) kann verwendet werden, um alle definierten Namen in der Arbeitsmappe abzurufen und ein Array von `FDefinedName[]` zurückzugeben.
- [`FWorksheet.getDefinedNames()`](https://docs.univer.ai/reference/facade/worksheet#getdefinednames) kann verwendet werden, um alle für dieses Arbeitsblatt verfügbaren definierten Namen abzurufen und ein Array von `FDefinedName[]` zurückzugeben.

### Definiert ändern Namen

Die Methode [`FWorkbook.updateDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#updatedefinednamebuilder) kann verwendet werden, um einen definierten Namen im zu ändern Arbeitsmappe.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Modify the defined name
if (definedName) {
  const newDefinedNameParam = definedName.toBuilder()
    .setName('NewDefinedName')
    .setRef('Sheet1!$A$2')
    .build()
  fWorkbook.updateDefinedNameBuilder(newDefinedNameParam)
}
```

[`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name)-Instanz kann auch verwendet werden, um die definierte Namenskonfiguration direkt zu ändern.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Modify the defined name
if (definedName) {
  definedName.setName('NewDefinedName')
  definedName.setRef('Sheet1!$A$2')
}
```

### Definiert löschen Namen

[`FWorkbook.deleteDefinedName()`](https://docs.univer.ai/reference/facade/workbook#deletedefinedname)-Methode kann verwendet werden, um einen definierten Namen in der Arbeitsmappe zu löschen Arbeitsmappe.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.deleteDefinedName('MyDefinedName')
```

Sie können den definierten Namen auch direkt mithilfe der zurückgegebenen [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name)-Instanz löschen.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Delete the defined name
if (definedName) {
  definedName.delete()
}
```
