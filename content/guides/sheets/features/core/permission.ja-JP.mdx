ブック全体の編集やコメントを制御するには、ブックのモードを設定します。特定の共同編集者にシートやセル範囲の編集を許可するには、対象に保護ルールを作成します。共同編集では、読み取り、セッションへの参加、文書の変更をサーバー側でも認可してください。[認証と認可](/server/collaboration/identity-and-authorization)を参照してください。

## よく使う操作 [#permission-tasks]

### ブックを読み取り専用にする、またはコメントを許可する

`viewer` モードでは閲覧と印刷ができます。セルは読み取り専用のままコメントも許可するには、下の引数を `'commenter'` にします。モードはブックの権限を一括で設定します。特定のユーザーのロールを変更するには[共同編集者の管理](#collaborators)を参照してください。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
if (!fWorkbook) throw new Error('No active workbook')
const permission = fWorkbook.getWorkbookPermission()
await permission.setMode('viewer')
```

個別の権限を変更するには `setPoint` を使います。例えば `await permission.setPoint(univerAPI.Enum.WorkbookPermissionPoint.Edit, false)` はブックの編集を無効にします。値が変わると SDK は `IAuthzIoService.update` を呼び出し、ポリシーのロールに `true` なら `Editor`、`false` なら `Owner` を渡します。再度開いたときにも設定を適用するには[認可サービスを接続](#authorization-service)してください。

### 指定した共同編集者にシートの編集を許可する

`user1` と `user2` はブックに登録済みの共同編集者の ID に置き換えてください。シートの権限を個別に設定する前に `protect()` で保護ルールを作成します。シートの保護を解除するには `worksheetPermission.unprotect()` を呼び出します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
if (!fWorkbook) throw new Error('No active workbook')
const fWorksheet = fWorkbook.getActiveSheet()
const worksheetPermission = fWorksheet.getWorksheetPermission()

await worksheetPermission.protect({
  allowedUsers: ['user1', 'user2'],
  name: 'My Worksheet Protection',
})
```

### A1:B2 の閲覧と編集を指定した共同編集者に限定する

`allowedUsers` に編集を許可する共同編集者を指定します。`allowViewByOthers: false` で他のユーザーによる閲覧も制限します。このルールだけを削除するには、戻り値の `rule.remove()` を呼び出します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
if (!fWorkbook) throw new Error('No active workbook')
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
const rangePermission = fRange.getRangePermission()

const rule = await rangePermission.protect({
  name: 'My protected range',
  allowViewByOthers: false,
  allowedUsers: ['user1', 'user2'],
})
```

範囲と交差するルールを取得するには `rangePermission.listRules()` を使います。`rangePermission.unprotect()` は交差するルールをすべて削除します。

### 保護範囲を管理する

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
if (!fWorkbook) throw new Error('No active workbook')
const fWorksheet = fWorkbook.getActiveSheet()
const permission = fWorksheet.getWorksheetPermission()

const createdRules = await permission.protectRanges([
  {
    ranges: [fWorksheet.getRange('D1:D4')],
    options: { name: 'Public area', allowViewByOthers: true },
  },
  {
    ranges: [fWorksheet.getRange('E1:E4')],
    options: { name: 'Private area', allowViewByOthers: false, allowedUsers: ['user1'] },
  },
])

await createdRules[0].updateRanges([fWorksheet.getRange('D1:D5')])
```

### A1 に値を入力できない原因を調べる

次の例は通常のセル値の入力に必要な権限を表示します。いずれかが `false` なら入力できません。`debugCellPermission(0, 0)` は A1 を含む保護ルールを返し、該当するルールがない場合は `undefined` を返します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
if (!fWorkbook) throw new Error('No active workbook')
const worksheet = fWorkbook.getActiveSheet().getWorksheetPermission()
const rule = await worksheet.debugCellPermission(0, 0)

console.table({
  workbookEdit: fWorkbook.getWorkbookPermission().canEdit(),
  worksheetEdit: worksheet.canEdit(),
  setCellValue: worksheet.getPoint(univerAPI.Enum.WorksheetPermissionPoint.SetCellValue),
  rangeEdit: rule?.canEdit() ?? true,
})
```

## 権限ポイントビット一覧 [#point-list]

### ワークシート操作とその権限ポイント

各操作は自身の権限ポイントを確認します。ワークブックのポイントは同じ行のワークシートと範囲のポイントとともに適用され、範囲のポイントは操作が交差する各保護範囲の編集ポイントを意味します。行または列を非表示にする場合、確認は行または列全体に広がります。

| 操作 | 必要な権限ポイント |
| --- | --- |
| セル値の入力（数式を除く） | `WorkbookEditablePermission`、`WorksheetEditPermission`、`WorksheetSetCellValuePermission`、`RangeProtectionPermissionEditPoint` |
| ワークシートを挿入 | `WorkbookEditablePermission`、`WorkbookCreateSheetPermission` |
| ワークシートをコピー | `WorkbookEditablePermission`、`WorkbookCopySheetPermission` |
| ワークシートを移動 | `WorkbookEditablePermission`、`WorkbookMoveSheetPermission` |
| ワークシートの名前を変更 | `WorkbookEditablePermission`、`WorkbookRenameSheetPermission` |
| ワークシートを非表示または表示 | `WorkbookEditablePermission`、`WorkbookHideSheetPermission` |
| ワークシートを削除 | `WorkbookEditablePermission`、`WorkbookDeleteSheetPermission` |
| 行または列を非表示または表示 | `WorkbookEditablePermission`、`WorksheetEditPermission`、`WorksheetSetRowStylePermission` または `WorksheetSetColumnStylePermission`、および交差する各保護範囲の編集ポイント |
| 行または列のサイズ変更、または内容に合わせる | `WorksheetSetRowStylePermission` または `WorksheetSetColumnStylePermission` |
| セルの結合または結合解除 | `WorkbookEditablePermission`、`WorksheetEditPermission`、`WorksheetSetCellValuePermission`、`WorksheetSetCellStylePermission`、および交差する各保護範囲の編集ポイント |
| 範囲を並べ替え | `WorkbookEditablePermission`、`WorksheetEditPermission`、`WorksheetSortPermission`、および交差する各保護範囲の編集ポイント |
| ウィンドウ枠を固定または固定解除 | `WorkbookEditablePermission`、`WorksheetEditPermission` |
| グリッド線の表示/非表示、または色の変更 | `WorkbookEditablePermission`、`WorksheetEditPermission` |
| 備考の追加、更新、削除 | `WorkbookEditablePermission`、`WorksheetEditPermission`、およびセルを含む各保護範囲の編集ポイント |
| 行または列のグループ化/グループ解除 | `WorkbookEditablePermission`、`WorksheetEditPermission`、`WorksheetSetRowStylePermission` または `WorksheetSetColumnStylePermission`、および交差する各保護範囲の編集ポイント |
| 保護ルールを作成 | `WorkbookCreateProtectPermission` |
| 保護ルールの共同編集者を管理 | `WorksheetManageCollaboratorPermission` または `RangeProtectionPermissionManageCollaPoint` |
| 保護ルールを削除 | `WorksheetDeleteProtectionPermission` または `RangeProtectionPermissionDeleteProtectionPoint` |

必要なポイントが `false` の場合、コマンドはドキュメントを変更する前に拒否されます。

備考はセルの編集ポイントに従います。備考の読み取りは権限チェックされません。

### コメントの権限

シートのコメントを読むにはブックの `View`、投稿するにはブックの `Comment` が必要です。どちらにもシートの `View` が必要です。セルに付いたコメントでは、そのセルに適用される保護ルールでも閲覧が許可されている必要があります。投稿者は自分のコメントを編集、削除できます。

## 権限保護範囲シャドウ戦略 [#permission-ui]

`non-editable` を使用して、保護された領域を区別するために、現在のユーザーはそれらから編集することができます。 編集可能な領域は影を受け取り、無効に編集された領域は影を保持し、非閲覧可能な範囲はマスクされたままです。

設定は、範囲とワークシートの保護が表示される方法だけに影響します。 保護ルールを作成せず、編集やビュー権限を変更せず、保護されていない領域に影を追加しません。 上記のように、保護ルールと現在のユーザーの許可を設定します。

| 戦略 | 表示動作 |
| --- | --- |
| `true` / `'always'` | すべての保護領域にシャドウを表示します（デフォルト）。 |
| `'non-editable'` | 編集可能な保護領域のシャドウを非表示にし、編集不可の領域では維持します。 |
| `'non-viewable'` | 閲覧できない保護領域にのみシャドウを表示します。 |
| `false` / `'none'` | すべての保護シャドウを非表示にします。権限チェックは引き続き有効です。 |

## Facade API で権限 UI を更新する [#permission-ui-api]

### 権限保護範囲シャドウ戦略 [#protected-range-shadow-api]

Facade API は、現在の Univerインスタンスの既存のワークブックを変更します。プラグインモードでは、`@univerjs/sheets-ui/facade`を最初にインポートします。シートコアプリセットには、そのモジュールが含まれています。

```typescript
// 編集不可範囲の影のみ表示に設定
univerAPI.setProtectedRangeShadowStrategy('non-editable')

// 現在の保護範囲影表示戦略を取得
console.log(univerAPI.getProtectedRangeShadowStrategy())

// 保護範囲影表示戦略の変更を監視
const subscription = univerAPI.getProtectedRangeShadowStrategy$().subscribe((strategy) => {
  console.log('Global strategy changed to:', strategy)
  // UIの更新や他のアクションを実行
})

// 後で購読解除
subscription.unsubscribe()
```

## 権限サービスの統合 [#permission-integration]

### サードパーティ認可サービスの統合（高度な利用） [#authorization-service]

ブックを作成する前に [`IAuthzIoService`](https://github.com/dream-num/univer/blob/v1.6.0/packages/core/src/services/authz-io/type.ts) の実装を登録します。サービスは保護ルールと共同編集者の変更を保存し、現在のユーザーの権限を返します。リクエストが失敗した場合は呼び出し元にエラーを返してください。

```typescript
import { IAuthzIoService, Univer } from '@univerjs/core'
import { YourAuthzService } from './authorization-service'

const univer = new Univer({
  override: [[IAuthzIoService, { useClass: YourAuthzService }]],
})
```

### 共同編集者管理 [#collaborators]

- コラボレーターリストを取得する

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
if (!fWorkbook) throw new Error('No active workbook')
const workbookPermission = fWorkbook.getWorkbookPermission()

const collaborators = await workbookPermission.listCollaborators()
console.log(collaborators)
```

- 共同編集者の追加

1 人追加するには `addCollaborator` を使います。`setCollaborators` は一覧全体を置き換えるため、アクセスを維持する共同編集者を全員含めてください。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
if (!fWorkbook) throw new Error('No active workbook')
const workbookPermission = fWorkbook.getWorkbookPermission()

await workbookPermission.addCollaborator(
  { userID: 'user1', name: 'John Doe', avatar: '' },
  univerAPI.Enum.UnitRole.Editor,
)
```

- 共同編集者の一覧を置き換える

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
if (!fWorkbook) throw new Error('No active workbook')
const workbookPermission = fWorkbook.getWorkbookPermission()

await workbookPermission.setCollaborators([
  {
    user: { userID: 'user1', name: 'John Doe', avatar: '' },
```

## プラグインで権限を拡張する

### 拡張利用

自分のプラグイン内のパーミッションを確認するには、パーミッションポイントを直接使用してください。

以下の例では、`WorkbookEditablePermission` を使用します。その他の許可ポイントは同じパターンに従います。

```typescript
import { IPermissionService } from '@univerjs/core'
import { WorkbookEditablePermission } from '@univerjs/sheets'

class YourService {
  constructor(@IPermissionService private _permissionService: IPermissionService) {
  }

  setWorkbookNotEditable() {
    this._permissionService.updatePermissionPoint(new WorkbookEditablePermission('unitId').id, false)
  }

  setWorkbookEditable() {
    this._permissionService.updatePermissionPoint(new WorkbookEditablePermission('unitId').id, true)
  }
}
```

[権限ポイントビット一覧](#point-list)

`SheetPermissionCheckController.permissionCheckByPoints(points)` は、明示的な権限ポイントのリストを確認し、いずれかが無効になっている場合は `false` を返します。特定の保護ルールのポイントなど、コマンドが必要なポイントをすでに把握している場合に使用します。

### 権限ポイントの拡張方法

カスタムのパーミッションポイントのために、`IPermissionPoint`を実装し、許可サービスに登録します。

```typescript
import type { IPermissionPoint } from '@univerjs/core'
import { IPermissionService, PermissionStatus } from '@univerjs/core'
import { UnitAction, UnitObject } from '@univerjs/protocol'

export class CustomPermissionPoint implements IPermissionPoint {
  type = UnitObject.Unkonwn // 任意のタイプ
  subType = UnitAction.View // 任意のサブタイプ
  status = PermissionStatus.INIT
  value = true // 初期値
  id: string
  constructor(unitId: string, subUnitId: string, customId: string) {
    // id は IPermissionService 全体で一意である必要がある
    this.id = `${unitId}.${subUnitId}.${customId}`
  }
}

class YourService {
  constructor(@IPermissionService private _permissionService: IPermissionService) {
    this._init()
  }

  _init() {
    this._permissionService.addPermissionPoint(new CustomPermissionPoint('unitId', 'subUnitId', 'my-id'))
  }
}

// 他所での利用例
class ConsumeService {
  constructor(@IPermissionService private _permissionService: IPermissionService) {
  }

  doSomething() {
    const point = this._permissionService.getPermissionPoint(new CustomPermissionPoint('unitId', 'subUnitId', 'my-id').id)
    console.log(point?.value)
  }

  bindEvent() {
    // これは Rx オブジェクトを取得し、権限変更を監視したりリストを更新したりできる
    const point$ = this._permissionService.getPermissionPoint$(new CustomPermissionPoint('unitId', 'subUnitId', 'my-id').id)
    console.log(point$)
  }
}
```
