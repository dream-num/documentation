Um die Anzeigeeffekte von Tabellen zu bereichern, stellen wir einige voreingestellte Bereichsthemen bereit und eröffnen die Möglichkeit, Themen für Univer anzupassen Benutzer.

## Integrierte Designs

Wir bieten ein dem `Excel Table default style` ähnliches Design als Standarddesign mit dem Namen `default` an, das über das Attribut `theme` festgelegt werden kann. Wir bieten auch eine Reihe von Farbthemen an, die Sie über die folgende Facade-API abrufen können, um die aktuell unterstützten Themen anzuzeigen.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const themes = fWorkbook.getRegisteredRangeThemes()
console.log(themes) // ['default', 'light-blue', 'light-grey', 'light-red', 'light-orange', 'light-yellow', 'light-green', 'light-azure', 'light-indigo', 'light-purple', 'light-magenta', 'middle-blue', 'middle-grey', 'middle-red', 'middle-orange', 'middle-yellow', 'middle-green', 'middle-azure', 'middle-indigo', 'middle-purple', 'middle-magenta', 'dark-blue', 'dark-grey', 'dark-red', 'dark-orange', 'dark-yellow', 'dark-green', 'dark-azure', 'dark-indigo', 'dark-purple', 'dark-magenta']
```

## Themen festlegen

In Univer können Sie Themen auf die folgenden zwei Arten festlegen:
- Themen durch Festlegen von Snapshots unterstützen
- Themen über die Facade-API unterstützen

### Einstellung Themen nach Snapshots

Die Themen in Univer werden in der Snapshot-Ressource mit dem Schlüssel `SHEET_RANGE_THEME_MODEL_PLUGIN` gespeichert. Die Datenstruktur ist wie folgt:

```typescript
interface IRangeThemeRangeInfo {
  range: IRange
  unitId: string
  subUnitId: string
}

interface IRangeThemeStyleRule {
  rangeInfo: IRangeThemeRangeInfo
  themeName: string
}

interface ISheetRangeThemeModelJSON {
  // JSON storing the range and theme information for setting themes, the key is the id, please ensure it is not repeated, the value is the corresponding range information and template name.
  rangeThemeStyleRuleMap: Record<string, IRangeThemeStyleRule>
  // JSON storing the themes, the key is the theme name, and the value is the serialized JSON of the theme.
  rangeThemeStyleMapJson: Record<string, IRangeThemeStyleJSON>
}
```

### Festlegen von Themen über die Facade-API

Wir empfehlen, die Facade-API zum Festlegen von Themen zu verwenden und dann die von Univer bereitgestellten Serialisierungs- und Deserialisierungsmethoden zum Speichern von Themeninformationen zu verwenden.

Hier sind einige API-Einführungen zu Themen:

```typescript
// Get the currently supported themes
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const themes = fWorkbook.getRegisteredRangeThemes()

// Set the default theme for A1:E20
const fRange = fWorksheet.getRange('A1:E20')
fRange.useThemeStyle('default') // 使用默认主题

// Get the currently used theme
const currentTheme = fRange.getUsedThemeStyle()

// Clear the theme style
fRange.useThemeStyle(undefined)
fRange.removeThemeStyle(currentTheme)
```

## Benutzerdefinierte Themen

Univer bietet zusätzlich zu den integrierten Themen die Möglichkeit, Themen anzupassen. Sie können Designs mithilfe der folgenden API anpassen:

```typescript
// Create a custom theme
const fWorkbook = univerAPI.getActiveWorkbook()
const rangeThemeStyle = fWorkbook.createRangeThemeStyle('MyTheme', {
  secondRowStyle: {
    bg: {
      rgb: 'rgb(214,231,241)',
    },
  },
})
fWorkbook.registerRangeTheme(rangeThemeStyle)

// Use the custom theme for A1:E20
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:E20')
// Make sure the theme is registered, otherwise it will throw an error.
fRange.useThemeStyle('MyTheme')
```

Univer bietet auch eine API zum Löschen registrierter Designs:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.unregisterRangeTheme('MyTheme')
```

### `RangeThemeStyle`-Klasse

Die Kernklasse der Univer-Designs, [`RangeThemeStyle`](https://github.com/dream-num/univer/blob/dev/packages/sheets/src/models/range-theme-util.ts#L110), stellt die folgenden Eigenschaften bereit, die Benutzer anpassen können Themen:

- `name`: Themenname
- `wholeStyle`: Stil für den gesamten Bereich
- `firstRowStyle`: Stil für die erste Reihe
- `secondRowStyle`: Stil für die zweite Reihe
- `headerRowStyle`: Stil für die Kopfzeile
- `lastRowStyle`: Stil für die letzte Zeile
- `firstColumnStyle`: Stil für die erste Spalte
- `secondColumnStyle`: Stil für die zweite Spalte
- `headerColumnStyle`: Stil für die Kopfzeile Spalte
- `lastColumnStyle`: Stil für die letzte Spalte

Sie können die Methoden `getXXX/setXXX` in der Klasse `RangeThemeStyle` verwenden, um Stile abzurufen/festzulegen, zum Beispiel:

```typescript
const rangeThemeStyle = new RangeThemeStyle('MyTheme')
rangeThemeStyle.setSecondRowStyle({
  bg: {
    rgb: 'rgb(214,231,241)',
  },
})
```

Alternativ können Sie ihn direkt mit optionalen Parametern während der Instanziierung erstellen:

```typescript
/**
 * @constructor
 * @param {string} name The name of the range theme style, it used to identify the range theme style.
 * @param {IRangeThemeStyleJSON} [options] The options to initialize the range theme style.
 */
class RangeThemeStyle {};

// For example:
const rangeThemeStyle = new RangeThemeStyle('MyTheme', {
  secondRowStyle: {
    bg: {
      rgb: 'rgb(214,231,241)',
    },
  },
})
```

Wenn Sie mehrere Stile definieren, werden diese in der folgenden Prioritätsreihenfolge angewendet:

`lastRowStyle` > `headerRowStyle` > `lastColumnStyle` > `headerColumnStyle` > `secondRowStyle` > `firstRowStyle` > `secondColumnStyle` > `firstColumnStyle` > `wholeStyle`

Wenn der definierte Stil einer Zelle mit dem Stil in `range theme` in Konflikt steht, hat der Stil der Zelle Vorrang. Ein Konflikt bezieht sich hier auf die Definition derselben Stileigenschaft sowohl in den Stildaten der Zelle als auch in `range theme`. Wenn der Stil der Zelle beispielsweise eine Hintergrundfarbe von `red` definiert, während `range theme` sie als `blue` definiert, lautet die Hintergrundfarbe der Zelle `red`.
