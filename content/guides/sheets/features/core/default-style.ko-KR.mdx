기본 스타일은 두 가지 수준에서 존재합니다.
1. 워크시트의 기본 스타일
2. 열 또는 행의 기본 스타일

[`IWorksheetData`](/reference/types/worksheet-data) 인터페이스 또는 Facade API를 통해 하나를 설정할 수 있습니다.

<StylePriorityDemo />

## 플러그인 설정 [#plugin-configuration]

`UniverSheetsPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `isRowStylePrecedeColumnStyle` | `boolean` | `false` | 행 스타일은 컬럼 스타일에 우선합니다. |
| `textLineGap` | `number` | `0` | 셀 안의 추가 줄 간격(픽셀)입니다. |

## 프리셋 설정 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>sheets</ConfigKey> | `object` |  | 선택된 기능에 대한 구성. |
| <ConfigKey depth={1}>isRowStylePrecedeColumnStyle</ConfigKey> | `boolean` | `false` | 행 스타일은 컬럼 스타일에 우선합니다. |
| <ConfigKey depth={1}>textLineGap</ConfigKey> | `number` | `0` | 셀 안의 추가 줄 간격(픽셀)입니다. |

## 행과 열의 스타일 우선순위

기본적으로, 열 스타일은 행 스타일에 대한 선행을 취합니다. 등록시 `isRowStylePrecedeColumnStyle`를 설정하여이 순서를 반전합니다.

Univer 설정과 기존 초기화에 이러한 옵션을 병합하는 탭을 선택합니다. 다른 플러그인, Locale, 테마, 컨테이너 설정 변경되지 않고 같은 플러그인을 두 번 등록하지 마십시오.

<Tabs items={['플러그인 모드', '프리셋 모드']}>
  <Tab>
    ```typescript
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, {
      isRowStylePrecedeColumnStyle: true,
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          sheets: {
            isRowStylePrecedeColumnStyle: true,
          },
        }),
      ],
    })
    ```
  </Tab>
</Tabs>

## 셀 텍스트 줄 간격 [#text-line-gap]

`textLineGap`는 풍부한 텍스트 및 셀 편집기를 포함한 셀 텍스트의 라인 사이의 픽셀에 여분의 공간을 추가합니다. 초기화 동안 설정; Univer 인스턴스의 모든 워크북에 적용. 기본값은 `0`이며, 값은 finite 및 non-negative이어야합니다.

<TextLineGapDemo />

<Tabs items={['플러그인 모드', '프리셋 모드']}>
  <Tab>
    ```ts
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, { textLineGap: 6 })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [UniverSheetsCorePreset({ sheets: { textLineGap: 6 } })],
    })
    ```
  </Tab>
</Tabs>

더 큰 간격은 기존의 줄을 크기를 조정하지 않습니다. 여분 공간이 요구될 때 자동적인 줄 고도를 바꾸십시오; 조정 고도를 가진 세포는 그들의 원본을 입을지도 모릅니다. 이것은 예를들면 수준 조정, per-cell 단락 작풍 아닙니다입니다.

## 기본 스타일 설정

두 가지 방법으로 워크 시트의 기본 스타일을 설정할 수 있습니다.

1. [`IWorksheetData`](/reference/types/worksheet-data) 인터페이스를 통해 설정

```typescript
interface IWorksheetData {
  // other
  /**
   * @property {Nullable<IStyleData>} [defaultStyle] - Default style data of Worksheet.
   */
  defaultStyle?: Nullable<IStyleData>
}

interface IRowData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}

interface IColumnData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}
```

2. Facade API를 통해

```typescript
const fworkbook = univerAPI.getActiveWorkbook()
const fworksheet = fworkbook.getActiveSheet()
const defaultStyle = {
  bg: {
    rgb: 'red',
  },
}
const defaultColumnStyle = {
  bg: {
    rgb: 'blue',
  },
}
const defaultRowStyle = {
  bg: {
    rgb: 'green',
  },
}

// set default style
fworksheet.setDefaultStyle(defaultStyle)
// set column D default style
fworksheet.setColumnDefaultStyle(3, defaultColumnStyle)
// reset column D the default style
fworksheet.setColumnDefaultStyle(3, undefined)

// set row default style
fworksheet.setRowDefaultStyle(1, defaultRowStyle)
```

## 셀에 맞게 텍스트 축소

`FRange`는 세포보다 더 넓은 텍스트를 축소 할 수 있습니다. 설정은 범위의 모든 세포에 적용되며 `getShrinkToFit()`가 왼쪽 셀의 상태를 반환합니다.

```ts
const range = univerAPI.getActiveWorkbook().getActiveSheet().getRange('A1:C3')

range.setShrinkToFit(true)
const enabled = range.getShrinkToFit()
```

수축-to-fit 및 텍스트 래핑은 상호적으로 독점적입니다. 텍스트 래핑을 비활성화하여 수축-투-액을 제거하고, 현재 랩을 감싸는 모든 세포에서 수축-투액 장애를 가능하게 합니다.
