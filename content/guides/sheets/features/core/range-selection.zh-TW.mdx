## 範圍 Range [#range]

範圍指工作表中的一塊矩形區域，有起始行號、起始列號、長寬或者結束行號、結束列號來確定。

表格中的大部分操作都可以透過範圍 API 來操作，如設定值、獲取值、設定樣式、獲取樣式等。

### Facade API

範圍完整 Facade API 型別定義，請檢視 [FRange Facade API](https://reference.univer.ai/zh-TW/classes/FRange)

#### 建立範圍

獲得一個範圍需要知道起始行號、起始列號、長寬。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 獲取 A1 單元格的範圍：
const fRange = fWorksheet.getRange(0, 0)
console.log(fRange, fRange.getA1Notation())

// 獲取 A1:B2 的範圍：
const fRange2 = fWorksheet.getRange(0, 0, 2, 2)
console.log(fRange2, fRange2.getA1Notation())
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 獲取名稱是 Sheet1 的工作表的 A1:B2 範圍
const fRange1 = fWorksheet.getRange('Sheet1!A1:B2')
console.log(fRange1, fRange1.getA1Notation())

// 獲取單個單元格 A1
const fRange2 = fWorksheet.getRange('A1')
console.log(fRange2, fRange2.getA1Notation())

// 獲取 A1:B2 範圍
const fRange3 = fWorksheet.getRange('A1:B2')
console.log(fRange3, fRange3.getA1Notation())

// 獲取 A 列的範圍
const fRange4 = fWorksheet.getRange('A:A')
console.log(fRange4, fRange4.getA1Notation())

// 獲取第 1 行的範圍
const fRange5 = fWorksheet.getRange('1:1')
console.log(fRange5, fRange5.getA1Notation())
```

#### 獲取範圍資料

獲取範圍第一個單元格的值

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

console.log(fRange.getValue()) // 範圍左上角單元格值
console.log(fRange.getRawValue()) // 範圍左上角單元格原始值
console.log(fRange.getDisplayValue()) // 範圍左上角單元格顯示值
console.log(fRange.getCellData()) // 範圍左上角單元格 ICellData 物件
console.log(fRange.getRichTextValue()) // 範圍左上角單元格富文字值
console.log(fRange.getRichTextValue().toPlainText()) // 範圍左上角單元格富文字值的純文字
```

獲取範圍的所有值

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

console.log(fRange.getValues()) // 範圍所有單元格值
console.log(fRange.getRawValues()) // 範圍所有單元格原始值
console.log(fRange.getDisplayValues()) // 範圍所有單元格顯示值
console.log(fRange.getCellDatas()) // 範圍所有單元格 ICellData 物件
console.log(fRange.getRichTextValues()) // 範圍所有單元格富文字值
```

獲取範圍的所有公式

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

console.log(fRange.getFormula()) // 範圍左上角單元格公式
console.log(fRange.getFormulas()) // 範圍所有單元格公式
```

#### 設定範圍資料

##### 設定單一值

傳入一個值或者單元格物件，將會覆蓋範圍內所有單元格，如果以 `=` 開頭，將被解釋為公式。

比如，設定 A1:B2 的值為 `Hello, Univer`：

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValue('Hello, Univer')
```

設定 A1+B1 的值為公式：

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValue('=A1+B1')
```

設定 A1:B2 的值為單元格物件：

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValue({
  v: 'Hello, Univer',
  custom: {
    key: 'value',
  },
})
```

如果只想設定範圍左上角的單元格值，可以使用 [`FRange.setValueForCell`](https://reference.univer.ai/zh-TW/classes/FRange#setvalueforcell) 方法：

```typescript
fRange.setValueForCell('Hello, Univer')
```

##### 透過陣列設定多個值

陣列的長度和寬度必須和範圍的長寬一致。

可以傳入單元格值也可以傳入單元格物件。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues([
  ['A1', 'B1'],
  ['A2', 'B2'],
])

fRange.setValues([
  [{ v: 'A1' }, { v: 'B1' }],
  [{ v: 'A2' }, { v: 'B2' }],
])
```

##### 透過物件設定多個值

則物件的一級索引代表行號，二級索引代表列號，與範圍的長寬無需一致。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues({
  0: {
    0: 'A1',
    1: 'B1',
  },
  1: {
    0: 'A2',
    1: 'B2',
  },
})
```

#### 清理範圍資料

- [`FRange.clear`](https://reference.univer.ai/zh-TW/classes/FRange#clear) 方法可以清理範圍的內容和格式資訊。
- [`FRange.clearContent`](https://reference.univer.ai/zh-TW/classes/FRange#clearcontent) 方法可以清理範圍的內容資訊。
- [`FRange.clearFormat`](https://reference.univer.ai/zh-TW/classes/FRange#clearformat) 方法可以清理範圍的格式資訊。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorkSheet = fWorkbook.getActiveSheet()
const fRange = fWorkSheet.getRange('A1:D10')

// 清除範圍的內容和格式資訊。
fRange.clear()
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

console.log(fRange.getCellStyleData()) // 範圍左上角單元格樣式資料
console.log(fRange.getCellStyle()) // 範圍左上角單元格樣式
console.log(fRange.getCellStyles()) // 範圍所有單元格樣式
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
```

#### 插入單元格

[`FRange.insertCells`](https://reference.univer.ai/zh-TW/classes/FRange#insertcells) 方法可以在此範圍內插入空單元格。工作表中沿指定維度的現有資料將移離插入的範圍。

```typescript
// 假設當前工作表是空工作表
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const values = [
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
]

// A1:D5 範圍設定值如下：
// 1 | 2 | 3 | 4
// 2 | 3 | 4 | 5
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
const fRange = fWorksheet.getRange('A1:D5')
fRange.setValues(values)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[1, 2, 3, 4], [2, 3, 4, 5], [3, 4, 5, 6], [4, 5, 6, 7], [5, 6, 7, 8]]

// 沿著列維度在範圍 A1:B2 中插入空單元格，範圍 A1:D5 將變為：
//   |   | 1 | 2
//   |   | 2 | 3
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
const fRange2 = fWorksheet.getRange('A1:B2')
fRange2.insertCells(univerAPI.Enum.Dimension.COLUMNS)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[null, null, 1, 2], [null, null, 2, 3], [3, 4, 5, 6], [4, 5, 6, 7], [5, 6, 7, 8]]

// 再次設定範圍 A1:D5 的值，範圍 A1:D5 將變為：
// 1 | 2 | 3 | 4
// 2 | 3 | 4 | 5
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
fRange.setValues(values)

// 沿著行維度在範圍 A1:B2 中插入空單元格，範圍 A1:D5 將變為：
//   |   | 3 | 4
//   |   | 4 | 5
// 1 | 2 | 5 | 6
// 2 | 3 | 6 | 7
// 3 | 4 | 7 | 8
const fRange3 = fWorksheet.getRange('A1:B2')
fRange3.insertCells(univerAPI.Enum.Dimension.ROWS)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[null, null, 3, 4], [null, null, 4, 5], [1, 2, 5, 6], [2, 3, 6, 7], [3, 4, 7, 8]]
```

#### 刪除單元格

[`FRange.deleteCells`](https://reference.univer.ai/zh-TW/classes/FRange#deletecells) 方法可以在範圍內刪除單元格。工作表中沿指定維度的現有資料將向已刪除的範圍移動。

```typescript
// 假設當前工作表是空工作表
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const values = [
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
]

// A1:D5 範圍設定值如下：
// 1 | 2 | 3 | 4
// 2 | 3 | 4 | 5
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
const fRange = fWorksheet.getRange('A1:D5')
fRange.setValues(values)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[1, 2, 3, 4], [2, 3, 4, 5], [3, 4, 5, 6], [4, 5, 6, 7], [5, 6, 7, 8]]

// 沿著列維度刪除範圍 A1:B2，範圍 A1:D5 將變為：
// 3 | 4 |   |
// 4 | 5 |   |
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
const fRange2 = fWorksheet.getRange('A1:B2')
fRange2.deleteCells(univerAPI.Enum.Dimension.COLUMNS)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[3, 4, null, null], [4, 5, null, null], [3, 4, 5, 6], [4, 5, 6, 7], [5, 6, 7, 8]]

// 再次設定範圍 A1:D5 的值，範圍 A1:D5 將變為：
// 1 | 2 | 3 | 4
// 2 | 3 | 4 | 5
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
fRange.setValues(values)

// 沿著行維度刪除範圍 A1:B2，範圍 A1:D5 將變為：
// 3 | 4 | 3 | 4
// 4 | 5 | 4 | 5
// 5 | 6 | 5 | 6
//   |   | 6 | 7
//   |   | 7 | 8
const fRange3 = fWorksheet.getRange('A1:B2')
fRange3.deleteCells(univerAPI.Enum.Dimension.ROWS)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[3, 4, 3, 4], [4, 5, 4, 5], [5, 6, 5, 6], [null, null, 6, 7], [null, null, 7, 8]]
```

#### 合併單元格

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 合併 B1:B2
const fRange = fWorksheet.getRange('B1:B2')
fRange.merge()
console.log(fRange.isMerged()) // true

// A1:B2 是否合併
const fRange2 = fWorksheet.getRange('A1:B2')
console.log(fRange2.isMerged()) // false
console.log(fRange2.isPartOfMerge()) // true

// 取消合併
fRange2.breakApart()

// 水平合併：fRange2.mergeAcross();
// 垂直合併：fRange2.mergeVertically();
// 獲取表格中所有合併單元格範圍：fWorksheet.getMergedRanges();
```

#### 高亮範圍

[`FRange.highlight`](https://reference.univer.ai/en-US/classes/FRange#highlight) 方法可以使用指定樣式和主單元格高亮範圍。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Highlight the range C3:E5 with default style
const fRange = fWorksheet.getRange('C3:E5')
fRange.highlight()

// Highlight the range C7:E9 with custom style and primary cell D8
const fRange2 = fWorksheet.getRange('C7:E9')
const primaryCell = fWorksheet.getRange('D8').getRange()
const disposable = fRange2.highlight(
  {
    stroke: 'red',
    fill: 'yellow',
  },
  {
    ...primaryCell,
    actualRow: primaryCell.startRow,
    actualColumn: primaryCell.startColumn,
  },
)

// Remove the range C7:E9 highlight after 5 seconds
setTimeout(() => {
  disposable.dispose()
}, 5000)
```

#### 資料分列

[`FRange.splitTextToColumns`](https://reference.univer.ai/zh-TW/classes/FRange#splittexttocolumns) 方法可以將單元格中的文字按指定分隔符分列。

預設分隔符示例：

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1:A3 包含以下值：
//  A      |
//  1,2,3  |
//  4,,5,6 |
const fRange = fWorksheet.getRange('A1:A3')
fRange.setValues([
  ['A'],
  ['1,2,3'],
  ['4,,5,6'],
])

// 呼叫 splitTextToColumns(true) 後，範圍值將變為：
//  A |   |
//  1 | 2 | 3
//  4 | 5 | 6
fRange.splitTextToColumns(true)

// 呼叫 splitTextToColumns(false) 後，範圍值將變為：
//  A |   |   |
//  1 | 2 | 3 |
//  4 |   | 5 | 6
fRange.splitTextToColumns(false)
```

指定分隔符示例：

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1:A3 包含以下值：
//     A   |
//  1;;2;3 |
//  1;,2;3 |
const fRange = fWorksheet.getRange('A1:A3')
fRange.setValues([
  ['A'],
  ['1;;2;3'],
  ['1;,2;3'],
])

// 呼叫 splitTextToColumns(false, univerAPI.Enum.SplitDelimiterType.Semicolon|univerAPI.Enum.SplitDelimiterType.Comma) 後，範圍值將變為：
//  A |   |   |
//  1 |   | 2 | 3
//  1 |   | 2 | 3
fRange.splitTextToColumns(false, univerAPI.Enum.SplitDelimiterType.Semicolon | univerAPI.Enum.SplitDelimiterType.Comma)

// 呼叫 splitTextToColumns(true, univerAPI.Enum.SplitDelimiterType.Semicolon|univerAPI.Enum.SplitDelimiterType.Comma) 後，範圍值將變為：
//  A |   |
//  1 | 2 | 3
//  1 | 2 | 3
fRange.splitTextToColumns(true, univerAPI.Enum.SplitDelimiterType.Semicolon | univerAPI.Enum.SplitDelimiterType.Comma)
```

自定義分隔符示例：

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1:A3 包含以下值：
//     A   |
//  1#2#3  |
//  4##5#6 |
const fRange = fWorksheet.getRange('A1:A3')
fRange.setValues([
  ['A'],
  ['1#2#3'],
  ['4##5#6'],
])

// 呼叫 splitTextToColumns(false, univerAPI.Enum.SplitDelimiterType.Custom, '#') 後，範圍值將變為：
//  A |   |   |
//  1 | 2 | 3 |
//  4 |   | 5 | 6
fRange.splitTextToColumns(false, univerAPI.Enum.SplitDelimiterType.Custom, '#')

// 呼叫 splitTextToColumns(true, univerAPI.Enum.SplitDelimiterType.Custom, '#') 後，範圍值將變為：
//  A |   |
//  1 | 2 | 3
//  4 | 5 | 6
fRange.splitTextToColumns(true, univerAPI.Enum.SplitDelimiterType.Custom, '#')
```

## 選區 Selection [#selection]

Univer 表格支援多選區，所以選區是一個範圍陣列，可以透過範圍 API 來操作選區資料。

我們還提供 API 來獲取當前選區、設定選區和監聽選區變化。

### Facade API

選區完整 Facade API 型別定義，請檢視 [FSelection Facade API](https://reference.univer.ai/zh-TW/classes/FSelection)

#### 獲取啟用選區的範圍

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 啟用新的選區
const fRange = fWorksheet.getRange('A1:B2')
fRange.activate()

// 獲取啟用選區的範圍
const fSelection = fWorksheet.getSelection()
console.log(fSelection)
const activeRange = fSelection.getActiveRange()
console.log(activeRange.getA1Notation()) // A1:B2
```

#### 設定選區

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 透過 FRange 設定選區 A1:B2
const fRange = fWorksheet.getRange('A1:B2')
fRange.activate()

// 透過 FWorksheet 設定選區 C1:D2
fWorksheet.setActiveSelection(fWorksheet.getRange('C1:D2'))
```

#### 獲取當前啟用的單元格

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 啟用選區 A10:B11
const fRange = fWorksheet.getRange('A10:B11')
fRange.activate()

// 獲取當前啟用的單元格
let fSelection = fWorksheet.getSelection()
const { actualRow, actualColumn } = fSelection.getCurrentCell()
console.log(fWorksheet.getRange(actualRow, actualColumn).getA1Notation()) // A10

// 更新新的啟用單元格 B11
fSelection = fSelection.updatePrimaryCell(fWorksheet.getRange('B11'))
const { actualRow: newRow, actualColumn: newColumn } = fSelection.getCurrentCell()
console.log(fWorksheet.getRange(newRow, newColumn).getA1Notation()) // B11
```

#### 禁用/啟用/隱藏/顯示選區

禁用後，選區將不會響應。設定選區不可見，與禁用選區不同，選區仍然有效，只是看不到它們。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// 禁用選區
fWorkbook.disableSelection()

// 啟用選區
fWorkbook.enableSelection()

// 隱藏選區
fWorkbook.transparentSelection()

// 顯示選區
fWorkbook.showSelection()
```

#### 監聽選區變化

```typescript
univerAPI.addEvent(univerAPI.Event.SelectionChanged, (params) => {
  const { worksheet, workbook, selections } = params
  console.log(params)
})
```

## 單元格 Cell [#cell]

單元格資料以二維 Map 的形式儲存在工作表中，一二級索引分別代表行號和列號。

以下是一個典型的單元格物件：

```typescript
const data = {
  v: 'Hello, Univer',
  s: 'styleId',
  t: CellValueType.STRING,
}
```

詳細的欄位說明請參考 [單元格資訊](/guides/sheets/model/cell-data)。

### 注意事項

1. 對單元格的操作可以看作對行高 1 、列寬 1 的範圍進行操作，操作範圍請閱讀 [範圍-range](/guides/sheets/features/core/range-selection#range)。
2. 外掛還會將拓展的單元格屬性儲存在 `Workbook` 的 `resources` 屬性中，詳細請閱讀 [外掛自定義模型](/guides/recipes/tutorials/custom-model/)。

| `CellPointerDown` | 滑鼠按下時觸發 | `ICellEventParam` | `const { worksheet, workbook, row, column } = params` |
| `CellPointerUp` | 滑鼠釋放時觸發 | `ICellEventParam` | `const { worksheet, workbook, row, column } = params` |
| `CellHover` | 滑鼠懸停在單元格上時觸發 | `ICellEventParam` | `const { worksheet, workbook, row, column } = params` |
| `DragOver` | 拖動元素經過單元格時觸發 | `ICellEventParam` | `const { worksheet, workbook, row, column } = params` |

### 使用示例

所有事件都可以透過 `addEvent` 方法進行監聽。基本格式如下：

```typescript
univerAPI.addEvent(univerAPI.Event.事件名稱, (params) => {
  // 事件處理邏輯
})
```

### 單元格 PointerMove 事件

`CellPointerMove` 事件在滑鼠移動到單元格上時觸發。透過此事件可以獲取當前滑鼠指向的單元格資訊。

```typescript
univerAPI.addEvent(univerAPI.Event.CellPointerMove, (params) => {
  // 獲取事件引數
```

### 單元格渲染事件

`onCellRender` 事件在單元格渲染時觸發，可用於自定義單元格渲染。

案例 1：固定位置渲染，新增行不會影響渲染位置

```typescript
// 固定位置渲染
univerAPI.getSheetHooks().onCellRender([{
  drawWith: (ctx, info, skeleton, spreadsheets) => {
    const { row, col } = info
    // 在指定位置(1,1)渲染勾選標記
    if (row === 1 && col === 1) {
      const { primaryWithCoord } = info
      const { startX, startY } = primaryWithCoord
      ctx.fillText('✅', startX, startY + 10)
    }
  },
}])

// 重新整理畫布以應用渲染
univerAPI.getActiveWorkbook().getActiveSheet().refreshCanvas()
```

案例 2：按標記渲染，標記位置會隨著行列變化而變化

```typescript
// 設定標記
univerAPI.getActiveWorkbook().getActiveSheet().getRange('B2').setValue({ custom: { key: 'needCheck' } })

// 按標記渲染
univerAPI.getSheetHooks().onCellRender([{
  drawWith: (ctx, info, skeleton, spreadsheets) => {
    const { row, col, data } = info
    // 在標記的位置渲染勾選標記
    if (data?.custom?.key === 'needCheck') {
      const { primaryWithCoord } = info
      const { startX, startY } = primaryWithCoord
      ctx.fillText('✅', startX, startY + 10)
    }
  },
}])

// 重新整理畫布以應用渲染
univerAPI.getActiveWorkbook().getActiveSheet().refreshCanvas()
```

## 雜項

### 如何實時獲取單元格編輯器內的資料？

Univer Sheets 的單元格編輯器底層採用了 Univer Docs 的編輯器引擎，因此可以透過 Facade API 獲取當前啟用的 Univer Docs 編輯器的快照（snapshot）資料，實現對編輯內容的實時獲取和處理。

```typescript
univerAPI.onCommandExecuted((command) => {
  const { id } = command
  if (id === 'doc.command.insert-text' || id === 'doc.command.delete-text') {
    const doc = univerAPI.getActiveDocument()
    if (doc) {
      const snapshot = doc.getSnapshot()
      console.log(snapshot.body?.dataStream)
    }
  }
})
```

參考：https://github.com/dream-num/univer/discussions/2261

### 單元格編輯器聚焦時，點選外部按鈕觸發事件，獲取的 snapshot 未包含當前單元格資料

單元格資料會在編輯器失焦（即編輯狀態結束）時同步到 snapshot。因此，在嘗試獲取 snapshot 資料前，應確保單元格已經失去焦點。可以透過如下方式主動結束編輯：

```typescript
import '@univerjs/sheets-ui/facade'

$btn.addEventListener('click', () => {
  univerAPI.getActiveWorkbook().endEditingAsync(true)
})
```

參考：https://github.com/dream-num/univer/issues/1314

### 使用 Facade API 建立 Workbook 後，立即呼叫其它 API 不生效的情況

部分 API 依賴於介面渲染完成後才能正常工作。如果在 Workbook 建立後立即呼叫相關 API，可能因尚未完成渲染而失效。建議在生命週期的 `Rendered` 或 `Steady` 階段再進行相關操作：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // 程式碼...
  }
})

// 需要移除事件監聽時，可呼叫 disposable.dispose()
```

參考：[生命週期](/guides/sheets/getting-started/lifecycle)
