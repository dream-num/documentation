---
title: 复制粘贴
---

<Callout type="warning" title="Firefox 兼容性说明">
  Firefox 尚未支持 `clipboard.readText()`，详见 [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText)。在这种情况下，Univer 只能从粘贴事件中读取剪贴板内容，因此只支持通过快捷键粘贴。
</Callout>

Univer 的复制粘贴功能基于 Clipboard API，支持将内容从外部应用复制到 Univer、从 Univer 复制到外部应用，也支持在 Univer Sheets 之间复制粘贴。

<Callout type="warning" title="安全上下文要求">
  现代浏览器的安全策略要求 Clipboard API 仅在安全上下文中使用，例如 HTTPS。
</Callout>

Univer 支持以下复制粘贴操作：

- 从外部应用复制粘贴到 Univer
- 从 Univer 复制到外部应用
- 在 Univer Sheets 之间复制粘贴

选择性粘贴包括以下情况：

- 仅粘贴值
- 仅粘贴格式
- 仅粘贴列宽
- 仅粘贴边框之外的内容
- 仅粘贴公式

桌面端 Ribbon 在撤销、重做按钮旁提供**粘贴**下拉菜单，包含普通粘贴、粘贴值、粘贴格式、粘贴列宽和粘贴时不带边框。该菜单的 ID 为 `sheet.menu.paste`；右键菜单中的**选择性粘贴**使用 `sheet.menu.paste-special`。编辑形状文本时，Ribbon 上的粘贴下拉菜单会隐藏。

## 禁用复制

开发者可以通过**权限控制（permission control）**禁用整个工作簿或特定工作表的复制功能。

下面的代码禁用当前工作簿的复制功能：

```typescript
const workbookPermission = univerAPI.getActiveWorkbook()?.getWorkbookPermission()
const WorkbookCopyPermission = univerAPI.Enum.WorkbookPermissionPoint.CopyContent

if (workbookPermission) {
  workbookPermission.setPoint(WorkbookCopyPermission, false)
}
```

关于权限控制的更多内容，见[权限控制](/guides/sheets/features/core/permission)。
