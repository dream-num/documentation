## Facade API

전체 Facade API 타입 정의는 [Facade API](https://reference.univer.ai/en-US)에서 확인할 수 있습니다.

### 행

#### 지정한 위치 뒤에 행 삽입

[`insertRowAfter(afterPosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowafter): 지정한 행 위치 뒤에 행을 삽입합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row after the first row position
sheet.insertRowAfter(0)
```

#### 지정한 위치 앞에 행 삽입

[`insertRowBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowbefore): 지정한 행 위치 앞에 행을 삽입합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row before the first row position
sheet.insertRowBefore(0)
```

#### 지정한 위치에 여러 행 삽입

[`insertRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#insertrows): 시트의 지정한 위치부터 하나 이상의 연속된 빈 행을 삽입합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Shifts all rows down by three
sheet.insertRows(0, 3)
```

#### 지정한 위치 뒤에 여러 행 삽입

[`insertRowsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsafter): 지정한 행 위치 뒤에 지정한 수의 행을 삽입합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows after the first row
sheet.insertRowsAfter(0, 5)
```

#### 지정한 위치 앞에 여러 행 삽입

[`insertRowsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsbefore): 지정한 행 위치 앞에 지정한 수의 행을 삽입합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows before the first row
sheet.insertRowsBefore(0, 5)
```

#### 지정한 위치의 행 삭제

[`deleteRow(rowPosition)`](https://docs.univer.ai/reference/facade/worksheet#deleterow): 지정한 행 위치의 행을 삭제합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first row
sheet.deleteRow(0)
```

#### 지정한 위치부터 여러 행 삭제

[`deleteRows(rowPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deleterows): 지정한 행 위치부터 지정한 수의 행을 삭제합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first two rows
sheet.deleteRows(0, 2)
```

#### 지정한 여러 위치의 행 삭제

[`deleteRowsByPoints(rowPoints)`](https://docs.univer.ai/reference/facade/worksheet#deleterowsbypoints): 행 위치 배열로 지정한 여러 행을 삭제합니다. 행은 연속되지 않아도 됩니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the 3rd row and rows 5 to 7
fWorksheet.deleteRowsByPoints([2, [4, 6]])
```

#### 행을 새 위치로 이동

[`moveRows(rowSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#moverows): 지정한 범위가 선택한 행을 `destinationIndex`가 가리키는 위치로 이동합니다. `rowSpec` 자체가 이동할 전체 행 또는 행 그룹을 정확히 나타낼 필요는 없으며, 범위에 걸쳐 있는 모든 행을 선택합니다.

```typescript
// The code below moves rows 1-2 to destination index 5
// This results in those rows becoming rows 3-4
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Selects row 1 and row 2 to be moved
const rowSpec = sheet.getRange('1:2')
sheet.moveRows(rowSpec, 5)
```

#### 지정한 범위의 행 숨기기

[`hideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#hiderow): 지정한 범위의 행을 숨깁니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This hides the first row
const range = sheet.getRange('1:1')
sheet.hideRow(range)
```

#### 연속된 여러 행 숨기기

[`hideRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#hiderows): 지정한 인덱스부터 하나 이상의 연속된 행을 숨깁니다. 이 메서드는 0부터 시작하는 인덱스를 사용합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Hides the first three rows
sheet.hideRows(0, 3)
```

#### 지정한 범위의 행 숨기기 해제

[`unhideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#unhiderow): 지정한 범위의 행 숨기기를 해제합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This unhides the first row if it was previously hidden
const range = sheet.getRange('1:1')
sheet.unhideRow(range)
```

#### 연속된 여러 행 숨기기 해제

[`showRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#showrows): 지정한 인덱스부터 하나 이상의 연속된 행 숨기기를 해제합니다. 이 메서드는 0부터 시작하는 인덱스를 사용합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Unhides the first three rows
sheet.showRows(0, 3)
```

#### 행 높이 설정

[`setRowHeight(rowPosition, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheight): 지정한 행의 높이를 픽셀 단위로 설정합니다. 기본적으로 행은 셀 내용에 맞게 늘어납니다. 행을 지정한 높이로 고정하려면 `setRowHeightsForced(startRow, numRows, height)`를 사용하세요.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first row to a height of 200 pixels
sheet.setRowHeight(0, 200)
```

#### 여러 행의 높이 설정

[`setRowHeights(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheights): 지정한 행들의 높이를 픽셀 단위로 설정합니다. 기본적으로 행은 셀 내용에 맞게 늘어납니다. 행을 지정한 높이로 고정하려면 `setRowHeightsForced(startRow, numRows, height)`를 사용하세요.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 200 pixels
sheet.setRowHeights(0, 3, 200)
```

#### 여러 행의 높이 강제 설정

[`setRowHeightsForced(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheightsforced): 지정한 행들의 높이를 픽셀 단위로 설정합니다. `setRowHeightsForced`를 사용하면 셀 내용이 행 높이보다 크더라도 행이 지정한 높이로 강제 설정됩니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 5 pixels
sheet.setRowHeightsForced(0, 3, 5)
```

#### 행 크기 자동 조정

[`autoResizeRows(startRow, numRows)`](https://docs.univer.ai/reference/facade/worksheet#autoresizerows): 지정한 행의 높이를 텍스트 내용에 맞게 자동 조정합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set the first 3 rows to a height that fits their text.
sheet.autoResizeRows(0, 3)
```

#### 행 사용자 지정 속성 설정

[`setRowCustom(custom)`](https://docs.univer.ai/reference/facade/worksheet#setrowcustom): 지정한 행에 사용자 지정 속성을 설정합니다. 행에 `custom` 객체를 저장하며, 추가 정보를 저장하기 위해 JSON 형식을 따르는 모든 데이터를 넣을 수 있습니다.
`custom` 데이터를 업데이트하면 기존 `custom` 데이터를 덮어씁니다. 업데이트할 때 기존 데이터를 유지해야 한다면 먼저 `custom` 데이터를 가져와 새 데이터와 병합한 후 업데이트하세요.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set custom properties for the first and third rows
sheet.setRowCustom({
  0: { color: 'red' },
  2: { size: 16 },
})
```

### 열

#### 지정한 위치 뒤에 열 삽입

[`insertColumnAfter(afterPosition)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumnafter): 지정한 열 위치 뒤에 열을 삽입합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a column after the first column position
sheet.insertColumnAfter(0)
```

#### 지정한 위치 앞에 열 삽입

[`insertColumnBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumnbefore): 지정한 열 위치 앞에 열을 삽입합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a column in the first column position
sheet.insertColumnBefore(0)
```

#### 지정한 위치에 여러 열 삽입

[`insertColumns(columnIndex, numColumns)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumns): 시트의 지정한 위치부터 하나 이상의 연속된 빈 열을 삽입합니다.


#### 지정한 위치 뒤에 여러 열 삽입

[`insertColumnsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumnsafter): 지정한 열 위치 뒤에 지정한 수의 열을 삽입합니다.


#### 지정한 위치 앞에 여러 열 삽입

[`insertColumnsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumnsbefore): 지정한 열 위치 앞에 지정한 수의 열을 삽입합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Columns start at "0" - this deletes the first column
sheet.deleteColumn(0)
```

#### 지정한 위치부터 여러 열 삭제

[`deleteColumns(columnPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deletecolumns): 지정한 열 위치부터 여러 열을 삭제합니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

sheet.deleteColumns(0, 2)
```

#### 지정한 여러 위치의 열 삭제

[`deleteColumnsByPoints(columnPoints)`](https://docs.univer.ai/reference/facade/worksheet#deletecolumnsbypoints): 열 위치 배열로 지정한 여러 열을 삭제합니다. 열은 연속되지 않아도 됩니다.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Columns start at "0" - this deletes the Column C and Columns E-G
fWorksheet.deleteColumnsByPoints([2, [4, 6]])
```

#### 열을 새 위치로 이동

[`moveColumns(columnSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#movecolumns): 지정한 범위가 선택한 열을 `destinationIndex`가 가리키는 위치로 이동합니다. `columnSpec` 자체가 이동할 전체 열 또는 열 그룹을 정확히 나타낼 필요는 없으며, 범위에 걸쳐 있는 모든 열을 선택합니다.

```typescript
// The code below moves rows A-B to destination index 5.
// This results in those columns becoming columns C-D.
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Selects column A and column B to be moved.
const columnSpec = sheet.getRange('A:B')
sheet.moveColumns(columnSpec, 5)
```
