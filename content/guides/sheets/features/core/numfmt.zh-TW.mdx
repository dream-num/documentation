數字格式決定單元格中數字的顯示方式，可以控制小數位數、千位分隔符，也可以把數值顯示為百分比或帶貨幣符號的形式，並支援其他顯示選項。設定格式之後，資料更易於閱讀。

工具欄中的貨幣操作根據 Univer 的 `region` 確定貨幣符號和格式。如果未顯式配置 `region`，它會跟隨 `locale`：

```typescript
const univer = new Univer({
  locale: LocaleType.ZH_TW,
  region: LocaleType.DE_DE,
})
```

<Callout type="warning" title="注意事項">
  不支援 **DBNum** 語法。
</Callout>

## 使用方法 [#usage]

在介面中，可以透過選單欄設定單元格的數字格式。在程式碼中，則設定單元格資料 [`ICellData`](/guides/sheets/model/cell-data) 物件的 [`s.n.pattern`](/guides/sheets/model/cell-data#number-format)[^number-format-value] 欄位。

```typescript
const data = {
  v: 123456.789,
  s: {
    n: {
      pattern: '#,##0.00',
    },
  },
}
```

**預設情況下，以 0 開頭的文字以及可以識別為日期的數字，會自動轉換為對應的數字格式。**

如果不希望進行自動轉換，可以採用以下兩種方式之一：

1. 將單元格的數字格式設定為文字。

```typescript
import { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

const data = {
  v: '012.0',
  s: {
    n: {
      pattern: DEFAULT_TEXT_FORMAT_EXCEL, // 文字格式
    },
  },
}
```

也可以透過 Facade API 設定單元格格式：

```typescript
fRange.setNumberFormat(DEFAULT_TEXT_FORMAT_EXCEL)
```

2. 在數字前輸入一個單引號 `'`，這種方式稱為[強制文字](/guides/sheets/model/cell-data#cell-type)。

`UniverSheetsNumfmtPlugin` 外掛提供 `disableTextFormatAlert` 和 `disableTextFormatMark` 兩個配置項，分別關閉單元格文字格式的警告和標記。

根據所採用的接入方式，將這些選項合併到已有的初始化配置中。其他外掛、語言、主題、容器配置保持不變，同一個外掛不要註冊兩次。

## 數值解析與小數位 [#number-parsing]

會計寫法可以按數字讀取：`=VALUE("(5)")` 返回 `-5`，輸入 `(1,000)` 或 `($1,000)` 會得到 `-1000`。增加小數位和減少小數位只修改格式中的數字段，日期和時間格式保留原有位數。

## 外掛設定 [#plugin-configuration]

`UniverSheetsNumfmtPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | 關閉單元格文字格式警告。 |
| `disableTextFormatMark` | `boolean` | `false` | 關閉單元格文字格式標記。 |

```typescript
import { UniverSheetsNumfmtPlugin } from '@univerjs/sheets-numfmt'

univer.registerPlugin(UniverSheetsNumfmtPlugin, {
  disableTextFormatAlert: true,
  disableTextFormatMark: true,
})
```

## 預設設定 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | 關閉單元格文字格式警告。 |
| `disableTextFormatMark` | `boolean` | `false` | 關閉單元格文字格式標記。 |

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import { createUniver } from '@univerjs/presets'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      disableTextFormatAlert: true,
      disableTextFormatMark: true,
    }),
  ],
})
```

## Facade API

### 引入

<Callout type="info" title="外掛模式提示">
  外掛模式需要單獨引入 Facade 包。預設模式已包含對應的 Facade 包，無需額外引入。
</Callout>

```typescript
import '@univerjs/sheets-numfmt/facade'
```

### 設定數字格式

格式程式碼的具體寫法見 https://support.microsoft.com/zh-cn/office/%E6%95%B0%E5%AD%97%E6%A0%BC%E5%BC%8F%E4%BB%A3%E7%A0%81-5026bbd6-04bc-48cd-bf33-80f18b4eae68

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 將 A1 單元格的數字格式設定為 '#,##0.00'
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')
fRange.getDisplayValue() // 1,234.57
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 設定 A1:B2 範圍的數字格式
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues([
  [1234.567, 0.1234],
  [45658, 0.9876],
]).setNumberFormats([
  ['#,##0.00', '0.00%'],
  ['yyyy-MM-DD', ''],
])
fRange.getDisplayValues() // [['1,234.57', '12.34%'], ['2025-01-01', 0.9876]]
```

### 獲取數字格式

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 獲取 A1:B2 範圍左上角單元格的數字格式
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormat()
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 獲取 A1:B2 範圍的數字格式
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormats()
```

### 設定數字格式的區域設定

使用 [`FWorkbook.setNumfmtLocal(local)`](https://docs.univer.ai/reference/facade/workbook#setnumfmtlocal) 設定格式化數字時使用的區域。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')

// 設定數字格式的區域設定為 en
fWorkbook.setNumfmtLocal('en')
fRange.getDisplayValue() // 1,234.57

// 設定數字格式的區域設定為 de
fWorkbook.setNumfmtLocal('de')
fRange.getDisplayValue() // 1.234,57
```

[^number-format-value]: 數字格式只改變顯示，不改變儲存的數值。例如將 `0.25` 設為 `0%` 會顯示 `25%`，公式仍使用 `0.25` 計算。

## 本地化日期預設 [#localized-date-presets]

日期格式面板的預設格式和預覽均取自 Univer 當前的 `locale`。已有的自定義日期格式仍然可以選擇。切換選區後，面板會重新整理，使其控制元件與當前單元格一致。
