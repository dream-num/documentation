---
title: 數字格式
---

數字格式是電子表格中用於控制數字顯示方式的功能。它允許使用者自訂數字的顯示格式，包括小數點位數、千位分隔符、百分比、貨幣符號等。透過設定數字格式，使用者可以使資料更易於閱讀和理解。

<Callout type="warning" title="注意事項">
  不支援 **DBNum** 語法
</Callout>

## 使用方法

UI 介面中，可以透過選單欄設定單元格的數字格式。或者在單元格資料 [`ICellData`](/guides/sheets/model/cell-data) 物件中設定 [`s.n.pattern`](/guides/sheets/model/cell-data#number-format) 欄位。

```typescript
const data = {
  v: 123456.789,
  s: {
    n: {
      pattern: '#,##0.00',
    },
  },
}
```

**預設情況下，以 0 開頭的文字以及可被轉換為日期格式的數字會被自動轉換成對應的數字格式。**

如果不希望這種自動轉換，可以選擇以下方式進行設定：

1. 將單元格數字格式設定為文字格式。

```typescript
import { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/engine-numfmt'

const data = {
  v: '012.0',
  s: {
    n: {
      pattern: DEFAULT_TEXT_FORMAT_EXCEL, // 文字格式
    },
  },
}
```

或使用 Facade API 設定單元格格式：

```typescript
fRange.setNumberFormat(DEFAULT_TEXT_FORMAT_EXCEL)
```

2. 在輸入數字前加上單引號 `'`（[強制文字](/guides/sheets/model/cell-data#cell-type)）

## Facade API

### 引入

<Callout type="info" title="外掛模式提示">
  僅外掛模式需要手動引入 Facade 套件。預設模式已內建對應的 Facade 套件，無需額外引入。
</Callout>

```typescript
import '@univerjs/sheets-numfmt/facade'
```

### 設定數字格式

具體參數請參考 https://support.microsoft.com/zh-cn/office/%E6%95%B0%E5%AD%97%E6%A0%BC%E5%BC%8F%E4%BB%A3%E7%A0%81-5026bbd6-04bc-48cd-bf33-80f18b4eae68

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 將 A1 單元格的數字格式設定為 '#,##0.00'
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')
fRange.getDisplayValue() // 1,234.57
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 設定 A1:B2 範圍的數字格式
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues([
  [1234.567, 0.1234],
  [45658, 0.9876],
]).setNumberFormats([
  ['#,##0.00', '0.00%'],
  ['yyyy-MM-DD', ''],
])
fRange.getDisplayValues() // [['1,234.57', '12.34%'], ['2025-01-01', 0.9876]]
```

### 獲取數字格式

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 獲取 A1:B2 範圍左上角單元格的數字格式
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormat()
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 獲取 A1:B2 範圍的數字格式
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormats()
```

### 設定數字格式的區域設定

使用 [`FWorkbook.setNumfmtLocal(local)`](https://docs.univer.ai/reference/facade/workbook#setnumfmtlocal) 方法設定數字格式的區域設定。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')

// 設定數字格式的區域設定為 en_US
fWorkbook.setNumfmtLocal('en_US')
fRange.getDisplayValue() // 1,234.57

// 設定數字格式的區域設定為 de_DE
fWorkbook.setNumfmtLocal('de_DE')
fRange.getDisplayValue() // 1.234,57
```

## 禁用單元格文字格式警告和標記

`UniverSheetsNumfmtPlugin` 外掛提供了 `disableTextFormatAlert` 和 `disableTextFormatMark` 兩個配置項，用於禁用單元格文字格式的警告和標記。

```typescript
// presets 配置
const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverSheetsCorePreset({
      disableTextFormatAlert: true,
      disableTextFormatMark: true,
    }),
  ],
})
```

```typescript
// Plugin 配置
univer.registerPlugin(UniverSheetsNumfmtPlugin, {
  disableTextFormatAlert: true,
  disableTextFormatMark: true,
})
```
