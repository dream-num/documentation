Proporcionamos dos niveles de estilos predeterminados:
1. El estilo predeterminado de la hoja de trabajo
2. El estilo predeterminado de la columna o fila

Ambos se pueden configurar a través de la interfaz [`IWorksheetData`](/reference/types/worksheet-data) o la API de Facade.

## Configuración

De forma predeterminada, el estilo de la columna tiene prioridad sobre la fila. estilo. Puede cambiar este comportamiento configurando `isRowStylePrecedeColumnStyle` durante el registro.

Elija su modo e incorpore estas opciones a la inicialización existente. Conserve los demás complementos y la configuración de idioma, tema y contenedor; no registre dos veces el mismo complemento.

<Tabs items={['Modo de complemento', 'Modo preestablecido']}>
  <Tab>
    ```typescript
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, {
      isRowStylePrecedeColumnStyle: true,
    })
    ```
  </Tab>

    ```typescript
      presets: [
        UniverSheetsCorePreset({
          sheets: {
            isRowStylePrecedeColumnStyle: true,
          },
        }),
      ],
    })
    ```

## Establecer estilo predeterminado

Hay dos formas de configurar el estilo predeterminado de una hoja de trabajo:

1. A través de la interfaz [`IWorksheetData`](/reference/types/worksheet-data)

```typescript
interface IWorksheetData {
  // other
  /**
   * @property {Nullable<IStyleData>} [defaultStyle] - Default style data of Worksheet.
   */
  defaultStyle?: Nullable<IStyleData>
}

interface IRowData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}

interface IColumnData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}
```

2. Establecer a través de la API de Facade

```typescript
const fworkbook = univerAPI.getActiveWorkbook()
const fworksheet = fworkbook.getActiveSheet()
const defaultStyle = {
  bg: {
    rgb: 'red',
  },
}
const defaultColumnStyle = {
  bg: {
    rgb: 'blue',
  },
}
const defaultRowStyle = {
  bg: {
    rgb: 'green',
  },
}

// set default style
fworksheet.setDefaultStyle(defaultStyle)
// set column D default style
fworksheet.setColumnDefaultStyle(3, defaultColumnStyle)
// reset column D the default style
fworksheet.setColumnDefaultStyle(3, undefined)

// set row default style
fworksheet.setRowDefaultStyle(1, defaultRowStyle)
```

## Reducir texto para ajustar

Usar `FRange` para reducir el texto cuando es más ancho que su celda. La configuración se aplica a todas las celdas del rango; `getShrinkToFit()` lee la celda superior izquierda.

```ts
const range = univerAPI.getActiveWorkbook().getActiveSheet().getRange('A1:C3')

range.setShrinkToFit(true)
const enabled = range.getShrinkToFit()
```

Reducir para ajustar y ajustar texto son mutuamente excluyentes. Activar el ajuste de líneas desactiva la reducción; activar la reducción elimina el ajuste de líneas de las celdas que lo usan.
