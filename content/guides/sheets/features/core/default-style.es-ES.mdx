Los estilos predeterminados existen en dos niveles:
1. El estilo predeterminado de la hoja de trabajo
2. El estilo predeterminado de una columna o fila

Puede configurar uno a través de la interfaz [`IWorksheetData`](/reference/types/worksheet-data) o el Facade API.

## Configuración de plugins [#plugin-configuration]

`UniverSheetsPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `isRowStylePrecedeColumnStyle` | `boolean` | `false` | Hace que el estilo de fila tome precedencia sobre el estilo de la columna. |
| `textLineGap` | `number` | `0` | Espaciado adicional entre líneas de una celda, en píxeles. |

## Configuración de preajustes [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>sheets</ConfigKey> | `object` |  | Configuración para la función seleccionada. |
| <ConfigKey depth={1}>isRowStylePrecedeColumnStyle</ConfigKey> | `boolean` | `false` | Hace que el estilo de fila tome precedencia sobre el estilo de la columna. |
| <ConfigKey depth={1}>textLineGap</ConfigKey> | `number` | `0` | Espaciado adicional entre líneas de una celda, en píxeles. |

## Prioridad de los estilos de filas y columnas

Por defecto, el estilo de columna tiene precedencia sobre el estilo de fila. Establecer `isRowStylePrecedeColumnStyle` durante el registro para revertir este pedido.

Seleccione la pestaña que coincida con su configuración Univer, y fusione estas opciones en la inicialización existente. Mantenga los otros plugins, locale, tema y configuración de contenedores sin cambios, y no registre el mismo plugin dos veces.

  <Tab>
    ```typescript
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, {
      isRowStylePrecedeColumnStyle: true,

  </Tab>

      presets: [
        UniverSheetsCorePreset({
          sheets: {
            isRowStylePrecedeColumnStyle: true,
          },
        }),
      ],
    })
    ```
  </Tab>
</Tabs>

## Espaciado del texto de las celdas [#text-line-gap]

`textLineGap` añade espacio extra en píxeles entre líneas de texto celular, incluyendo editores de texto y celular ricos. Establecelo durante la inicialización; se aplica a cada libro de trabajo en la instancia Univer. El valor predeterminado es `0`, y el valor debe ser finito y no negativo.

<Tabs items={['Modo de complemento', 'Modo preestablecido']}>
  <Tab>
    ```ts
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, { textLineGap: 6 })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [UniverSheetsCorePreset({ sheets: { textLineGap: 6 } })],
    })
    ```
  </Tab>
</Tabs>

Una brecha más grande no redimensiona las filas existentes. Recalcula las alturas de fila automática cuando se requiere el espacio extra; las células con una altura fija pueden cortar su texto. Esto es un ajuste de instancia, no un estilo de párrafo por celda.

## Establecer estilo predeterminado

Puede configurar el estilo predeterminado de una hoja de trabajo de dos maneras:

1. A través de la interfaz [`IWorksheetData`](/reference/types/worksheet-data)

```typescript
interface IWorksheetData {
  // other
  /**
   * @property {Nullable<IStyleData>} [defaultStyle] - Default style data of Worksheet.
   */
  defaultStyle?: Nullable<IStyleData>
}

interface IRowData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}

interface IColumnData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}
```

2. A través de Facade API

```typescript
const fworkbook = univerAPI.getActiveWorkbook()
const fworksheet = fworkbook.getActiveSheet()
const defaultStyle = {
  bg: {
    rgb: 'red',
  },
}
const defaultColumnStyle = {
  bg: {
    rgb: 'blue',
  },
}
const defaultRowStyle = {
  bg: {
    rgb: 'green',
  },
}

// set default style
fworksheet.setDefaultStyle(defaultStyle)
// set column D default style
fworksheet.setColumnDefaultStyle(3, defaultColumnStyle)
// reset column D the default style
fworksheet.setColumnDefaultStyle(3, undefined)

// set row default style
fworksheet.setRowDefaultStyle(1, defaultRowStyle)
```

## Reducir texto para ajustar

`FRange` puede reducir el texto que es más amplio que su célula. El ajuste se aplica a cada célula en el rango, y `getShrinkToFit()` devuelve el estado de la célula superior izquierda.

```ts
const range = univerAPI.getActiveWorkbook().getActiveSheet().getRange('A1:C3')

range.setShrinkToFit(true)
const enabled = range.getShrinkToFit()
```

El envoltorio de texto se excluye mutuamente. El envolvimiento de texto permite reducir las deshabilitaciones en función y permitir que las desactivaciones de la psiquiatra en función se envuelven en cualquier célula que actualmente se envuelve.
