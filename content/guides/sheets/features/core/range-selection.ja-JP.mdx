## 範囲 [#range]

範囲は、ワークシートの長方形の領域です。 開始行と列と行数と列の番号、または開始行と行列をエンディング行と列で定義できます。

ほとんどのスプレッドシート操作は、Vege API の設定と読み込み値、設定、読み込みスタイルなどを通して行われます。

範囲 API の完全なタイプ定義については、[フランジ FacadeAPI](/reference/facade/range) を参照してください。

### 範囲の生成

範囲は、開始行、開始列、およびサイズを必要とします。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// セル A1 の範囲を生成
const fRange = fWorksheet.getRange(0, 0)
console.log(fRange, fRange.getA1Notation())

// セル A1:B2 の範囲を生成
const fRange2 = fWorksheet.getRange(0, 0, 2, 2)
console.log(fRange2, fRange2.getA1Notation())
```

A1 の表記で、フロントのオプションのワークシート名で、範囲を記述することもできます。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Sheet1 シート上の A1:B2 範囲を取得
const fRange1 = fWorksheet.getRange('Sheet1!A1:B2')
console.log(fRange1, fRange1.getA1Notation())

// 単一セル A1 を取得
const fRange2 = fWorksheet.getRange('A1')
console.log(fRange2, fRange2.getA1Notation())

// A1:B2 範囲を取得
const fRange3 = fWorksheet.getRange('A1:B2')
console.log(fRange3, fRange3.getA1Notation())

// 列 A 全体を取得
const fRange4 = fWorksheet.getRange('A:A')
console.log(fRange4, fRange4.getA1Notation())

// 行 1 全体を取得
const fRange5 = fWorksheet.getRange('1:1')
console.log(fRange5, fRange5.getA1Notation())
```

### 範囲データの取得

範囲の左のセルを読んで下さい:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
if (!fWorkbook) throw new Error('No active workbook')
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

console.log(fRange.getValue()) // 範囲左上セルの値
console.log(fRange.getRawValue()) // 範囲左上セルの生値
console.log(fRange.getDisplayValue()) // 範囲左上セルの表示値
console.log(fRange.getCellData()) // 範囲左上セルのセルデータ
const value = fRange.getValue(true)
console.log(value)
if (value !== null && typeof value === 'object') {
  console.log(value.toPlainText())
}
```

`getValue(true)`はリッチテキストオブジェクトを返します。空のセルは`null`または`undefined`を返します。普通のセルは文字列、番号、またはブール値を返します。リッチテキストオブジェクトのみで`toPlainText()`を呼び出します。

範囲内のすべての値を読みます。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
if (!fWorkbook) throw new Error('No active workbook')
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

console.log(fRange.getValues()) // 全セルの値
console.log(fRange.getRawValues()) // 全セルの生値
console.log(fRange.getDisplayValues()) // 全セルの表示値
console.log(fRange.getCellDataGrid()) // 全セルのセルデータ
console.log(fRange.getValues(true))
```

範囲内のすべての式を読んで下さい:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

console.log(fRange.getFormula()) // 範囲左上セルの数式
console.log(fRange.getFormulas()) // 範囲内全セルの数式
```

### 範囲への値設定

#### 単一値の設定

値またはセルオブジェクトを渡すと、範囲内のすべてのセルを上書きします。 `=` から始まる文字列は、式として解釈されます。

たとえば、次のコードは、A1:B2 から `Hello, Univer` まですべてセットします。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValue('Hello, Univer')
```

次のコードでは、C1 を `=A1+B1` に設定します。そのため、入力セルの外に結果が表示されます。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
if (!fWorkbook) throw new Error('No active workbook')
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('C1')
fRange.setValue('=A1+B1')
```

セルオブジェクトは、代わりに渡すことができます。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValue({
  v: 'Hello, Univer',
  custom: {
    key: 'value',
  },
})
```

サインイン `ICellData` 供給するオブジェクト `v` または `p` なし `f` そして、 `si` 既存の式とその共有形式を置き換えます。 供給 `f` なし `si` また、前回の共有式からセルを外します。スタイルまたはカスタムフィールドのみを運ぶパッチは、式を保存します。書き込み `v` リッチテキストをクリアしないので、 `p: null` 値がリッチテキストを置き換えるとき。同じルールはセルオブジェクトに渡されます。 `setValues()`.

範囲の一番左のセルだけを設定するには、[`FRange.setValueForCell`](/reference/facade/range#setvalueforcell) を使用します。

```typescript
fRange.setValueForCell('Hello, Univer')
```

#### 配列による複数値設定

配列は、範囲の高さと幅に一致しなければなりません。

エントリは、値やセルオブジェクトをプレーンすることができます。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues([
  ['A1', 'B1'],
  ['A2', 'B2'],
])

fRange.setValues([
  [{ v: 'A1' }, { v: 'B1' }],
  [{ v: 'A2' }, { v: 'B2' }],
])
```

#### オブジェクトによる複数値設定

オブジェクトが渡されると、トップレベルのキーは行番号であり、ネストされたキーは列番号です。範囲はオブジェクトのサイズに一致する必要はありません。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues({
  0: {
    0: 'A1',
    1: 'B1',
  },
  1: {
    0: 'A2',
    1: 'B2',
  },
})
```

### 範囲データのクリア

- [`FRange.clear`](/reference/facade/range#clear)は、範囲のコンテンツとフォーマットをクリアします。
- [`FRange.clearContent`](/reference/facade/range#clearcontent)はコンテンツだけをクリアします。
- [`FRange.clearFormat`](/reference/facade/range#clearformat)はフォーマットだけをクリアします。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorkSheet = fWorkbook.getActiveSheet()
const fRange = fWorkSheet.getRange('A1:D10')

// コンテンツと書式をクリア
fRange.clear()
```

### 範囲スタイルの取得

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
console.log(fRange.getCellStyleData()) // 左上セルのスタイルデータ
console.log(fRange.getCellStyle()) // 左上セルのスタイル
console.log(fRange.getCellStyles()) // 全セルのスタイル
```

### 範囲スタイルの設定

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange
  .setValues([
    [1, 2],
    [3, 4],
  ])
  .setFontWeight('bold')
  .setFontLine('underline')
  .setFontFamily('Arial')
  .setFontSize(24)
  .setFontColor('red')
```

### 範囲スタイルのリセット

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
fRange.setFontWeight(null).setFontLine(null).setFontFamily(null).setFontSize(null).setFontColor(null)
```

### 行と列への書式のコピー [#format-painter]

コピーするフォーマットを運ぶセルを選択し、形式画家をアクティブにし、ターゲット行ヘッダーまたは列ヘッダーをクリックして、行または列全体にフォーマットを適用します。グリッド内のターゲットセルも選択できます。

## 選択 [#selection]

矢印キーナビゲーション、選択アニメーション、充填ハンドル、およびドラッグオーバーライトプロンプトは、[選択とドラッグの設定](/guides/sheets/features/core#selection-interaction)で記述されています。

Univer シートは複数の選択領域をサポートしているので、選択は範囲の配列であり、これらの範囲は Range API を介して操作されます。

API は、現在の選択を取得したり、選択を設定したり、選択の変更をリスニングしたりすることもできます。

選択 API の完全なタイプ定義については、[Fセレクション FacadeAPI](/reference/facade/selection) を参照してください。

### アクティブ選択の取得

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1:B2 を新たにアクティブ選択にする
const fRange = fWorksheet.getRange('A1:B2')
fRange.activate()

// 現在のアクティブ選択を取得
const fSelection = fWorksheet.getSelection()
console.log(fSelection)
const activeRange = fSelection.getActiveRange()
console.log(activeRange.getA1Notation()) // A1:B2
```

### 選択の設定

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// FRange で A1:B2 を選択
const fRange = fWorksheet.getRange('A1:B2')
fRange.activate()

// FWorksheet で C1:D2 に切替
fWorksheet.setActiveSelection(fWorksheet.getRange('C1:D2'))
```

### 現在セルの取得

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A10:B11 をアクティブ選択
const fRange = fWorksheet.getRange('A10:B11')
fRange.activate()

// 現在のアクティブセル
let fSelection = fWorksheet.getSelection()
const { actualRow, actualColumn } = fSelection.getCurrentCell()
console.log(fWorksheet.getRange(actualRow, actualColumn).getA1Notation()) // A10

// アクティブセルを B11 に更新
fSelection = fSelection.updatePrimaryCell(fWorksheet.getRange('B11'))
const { actualRow: newRow, actualColumn: newColumn } = fSelection.getCurrentCell()
console.log(fWorksheet.getRange(newRow, newColumn).getA1Notation()) // B11
```

### 選択の無効化／有効化／非表示／再表示

無効な選択は、入力に応答を停止します。 `transparentSelection`は、代わりに選択を非表示にします。`disableSelection`とは異なり、選択は機能的に残ります。それは見えないだけです。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// 無効化
fWorkbook.disableSelection()

// 有効化
fWorkbook.enableSelection()

// 非表示
fWorkbook.transparentSelection()

// 再表示
fWorkbook.showSelection()
```

### 選択変更の監視

```typescript
univerAPI.addEvent(univerAPI.Event.SelectionChanged, (params) => {
  const { worksheet, workbook, selections } = params
  console.log(params)
})
```

## セル [#cell]

セルデータはワークシートに1番目のインデックスが行番号で2次元のマップとして保存され、2つ目は列番号です。

典型的なセルオブジェクトは以下のとおりです。

```typescript
const data = {
  v: 'Hello, Univer',
  s: 'styleId',
  t: CellValueType.STRING,
}
```

完全なフィールドの説明については、[セルデータの設定](/guides/sheets/model/cell-data) を参照してください。

### 補足

1. セル操作は、範囲1列の高さと1列幅の範囲で動作する範囲です。 範囲の機能は、[レンジ](/guides/sheets/features/core/range-selection#range)で記述されています。
2. Univer APIプラグインは、`Workbook`の`resources`プロパティーに拡張セル属性も保存します。 [プラグインカスタムモデル](/blog/custom-model)を参照してください。

## 範囲の応用操作 [#range-operations]

### セル挿入

[`FRange.insertCells`](/reference/facade/range#insertcells)は空のセルを範囲に差し込みます。シート内のデータを既存の範囲から所定の寸法に沿って離します。

```typescript
// アクティブシートは空と仮定
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const values = [
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
]

// A1:D5 を初期化
// 1 | 2 | 3 | 4
// 2 | 3 | 4 | 5
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
const fRange = fWorksheet.getRange('A1:D5')
fRange.setValues(values)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[1, 2, 3, 4], [2, 3, 4, 5], [3, 4, 5, 6], [4, 5, 6, 7], [5, 6, 7, 8]]

// A1:B2 に列方向で空セルを挿入
//   |   | 1 | 2
//   |   | 2 | 3
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
const fRange2 = fWorksheet.getRange('A1:B2')
fRange2.insertCells(univerAPI.Enum.Dimension.COLUMNS)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[null, null, 1, 2], [null, null, 2, 3], [3, 4, 5, 6], [4, 5, 6, 7], [5, 6, 7, 8]]

// 再度 A1:D5 を元に戻す
// 1 | 2 | 3 | 4
// 2 | 3 | 4 | 5
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
fRange.setValues(values)

// A1:B2 に行方向で空セルを挿入
//   |   | 3 | 4
//   |   | 4 | 5
// 1 | 2 | 5 | 6
// 2 | 3 | 6 | 7
// 3 | 4 | 7 | 8
const fRange3 = fWorksheet.getRange('A1:B2')
fRange3.insertCells(univerAPI.Enum.Dimension.ROWS)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[null, null, 3, 4], [null, null, 4, 5], [1, 2, 5, 6], [2, 3, 6, 7], [3, 4, 7, 8]]
```

### セル削除

[`FRange.deleteCells`](/reference/facade/range#deletecells)は範囲内のセルを削除します。シート内のデータを既存のデータが指定された寸法に沿って削除された範囲に向かってシフトされます。

```typescript
// アクティブシートは空と仮定
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const values = [
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
]

// 初期状態
// 1 | 2 | 3 | 4
// 2 | 3 | 4 | 5
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
const fRange = fWorksheet.getRange('A1:D5')
fRange.setValues(values)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[1, 2, 3, 4], [2, 3, 4, 5], [3, 4, 5, 6], [4, 5, 6, 7], [5, 6, 7, 8]]

// A1:B2 を列方向で削除
// 3 | 4 |   |
// 4 | 5 |   |
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
const fRange2 = fWorksheet.getRange('A1:B2')
fRange2.deleteCells(univerAPI.Enum.Dimension.COLUMNS)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[3, 4, null, null], [4, 5, null, null], [3, 4, 5, 6], [4, 5, 6, 7], [5, 6, 7, 8]]

// 再設定
// 1 | 2 | 3 | 4
// 2 | 3 | 4 | 5
// 3 | 4 | 5 | 6
// 4 | 5 | 6 | 7
// 5 | 6 | 7 | 8
fRange.setValues(values)

// A1:B2 を行方向で削除
// 3 | 4 | 3 | 4
// 4 | 5 | 4 | 5
// 5 | 6 | 5 | 6
//   |   | 6 | 7
//   |   | 7 | 8
const fRange3 = fWorksheet.getRange('A1:B2')
fRange3.deleteCells(univerAPI.Enum.Dimension.ROWS)
console.log(fWorksheet.getRange('A1:D5').getValues()) // [[3, 4, 3, 4], [4, 5, 4, 5], [5, 6, 5, 6], [null, null, 6, 7], [null, null, 7, 8]]
```

### セル結合

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// B1:B2 を結合
const fRange = fWorksheet.getRange('B1:B2')
fRange.merge()
console.log(fRange.isMerged()) // true

// A1:B2 について
const fRange2 = fWorksheet.getRange('A1:B2')
console.log(fRange2.isMerged()) // false
console.log(fRange2.isPartOfMerge()) // true

// 結合解除
fRange2.breakApart()

// 水平結合：fRange2.mergeAcross();
// 垂直結合：fRange2.mergeVertically();
// シート内の全結合範囲取得：fWorksheet.getMergedRanges();
```

### 範囲のハイライト

[`FRange.highlight`](/reference/facade/range#highlight)は、指定されたスタイルとプライマリセルで範囲を強調します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 既定スタイルで C3:E5 をハイライト
const fRange = fWorksheet.getRange('C3:E5')
fRange.highlight()

// カスタムスタイル＋主セル D8 で C7:E9 をハイライト
const fRange2 = fWorksheet.getRange('C7:E9')
const primaryCell = fWorksheet.getRange('D8').getRange()
const disposable = fRange2.highlight(
  {
    stroke: 'red',
    fill: 'yellow',
  },
  {
    ...primaryCell,
    actualRow: primaryCell.startRow,
    actualColumn: primaryCell.startColumn,
  },
)

// 5 秒後に C7:E9 のハイライト解除
setTimeout(() => {
  disposable.dispose()
}, 5000)
```

### テキストを列に分割

[`FRange.splitTextToColumns`](/reference/facade/range#splittexttocolumns)は、指定した区切り文字を使用して範囲内のテキストを列に分割します。

最初の例ではデフォルトの区切り文字を使用します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1:A3 の値:
//  A      |
//  1,2,3  |
//  4,,5,6 |
const fRange = fWorksheet.getRange('A1:A3')
fRange.setValues([['A'], ['1,2,3'], ['4,,5,6']])

// splitTextToColumns(true) 呼び出し後:
//  A |   |
//  1 | 2 | 3
//  4 | 5 | 6
fRange.splitTextToColumns(true)

// splitTextToColumns(false) 呼び出し後:
//  A |   |   |
//  1 | 2 | 3 |
//  4 |   | 5 | 6
fRange.splitTextToColumns(false)
```

2番目の例はセミコロンとコンマを渡します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1:A3：
//     A   |
//  1;;2;3 |
//  1;,2;3 |
const fRange = fWorksheet.getRange('A1:A3')
fRange.setValues([['A'], ['1;;2;3'], ['1;,2;3']])

// セミコロン + カンマで分割（空要素保持 = false），結果：
//  A |   |   |
//  1 |   | 2 | 3
//  1 |   | 2 | 3
fRange.splitTextToColumns(false, univerAPI.Enum.SplitDelimiterType.Semicolon | univerAPI.Enum.SplitDelimiterType.Comma)

// 空要素圧縮 = true，結果：
//  A |   |
//  1 | 2 | 3
//  1 | 2 | 3
fRange.splitTextToColumns(true, univerAPI.Enum.SplitDelimiterType.Semicolon | univerAPI.Enum.SplitDelimiterType.Comma)
```

3番目の例はカスタム区切り文字を渡します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1:A3：
//     A   |
//  1#2#3  |
//  4##5#6 |
const fRange = fWorksheet.getRange('A1:A3')
fRange.setValues([['A'], ['1#2#3'], ['4##5#6']])

// カスタム '#'、空要素保持 = false
//  A |   |   |
//  1 | 2 | 3 |
//  4 |   | 5 | 6
fRange.splitTextToColumns(false, univerAPI.Enum.SplitDelimiterType.Custom, '#')

// 空要素圧縮 = true
//  A |   |
//  1 | 2 | 3
//  4 | 5 | 6
fRange.splitTextToColumns(true, univerAPI.Enum.SplitDelimiterType.Custom, '#')
```

## セルのイベントと編集 [#events]

次の例では、カバーポインタ、レンダリング、編集、クリップボードのインタラクションをカバーします。すべてのイベントとペイロードタイプについては、[イベントの参照](/reference/facade/events#univerjssheets-ui)を参照してください。プラグインモードでは、サブスクライブの前に`@univerjs/sheets-ui/facade`をインポートします。シートコアプリセットには、それが含まれています。独自のコンポーネントやページが削除されたときにサブスクリプションを消去します。

### 使用パターン

`addEvent`は、どんなイベントでもリスナーを登録します。 基本的なフォームは次のとおりです。

```typescript
import '@univerjs/sheets-ui/facade'

const subscription = univerAPI.addEvent(univerAPI.Event.CellClicked, ({ row, column }) => {
  console.log(row, column)
})

// Call subscription.dispose() when the owning component or page is removed.
```

### Cell Render イベント

`registerCellCustomRender`は、セルが描画されるときに使用されるカスタムレンダラーをインストールします。

例1 は固定位置レンダリングを使用します。行を追加すると、描画されたコンテンツを移動しません。

```typescript
// 固定位置レンダリング
univerAPI.registerCellCustomRender([
  {
    drawWith: (ctx, info, skeleton, spreadsheets) => {
      const { row, col } = info
      // 位置 (1,1) にチェックマークを描画
      if (row === 1 && col === 1) {
        const { primaryWithCoord } = info
        const { startX, startY } = primaryWithCoord
        ctx.fillText('✅', startX, startY + 10)
      }
    },
  },
])

// 再描画反映
univerAPI.getActiveWorkbook().getActiveSheet().refreshCanvas()
```

例2はマーカーベースのレンダリングを使用します。描画は行と列で移動します。

```typescript
// マーカー設定
univerAPI
  .getActiveWorkbook()
  .getActiveSheet()
  .getRange('B2')
  .setValue({ custom: { key: 'needCheck' } })

// マーカーに基づき描画
univerAPI.registerCellCustomRender([
  {
    drawWith: (ctx, info, skeleton, spreadsheets) => {
      const { row, col, data } = info
      // マーカーを持つセルにチェックマークを描画
      if (data?.custom?.key === 'needCheck') {
        const { primaryWithCoord } = info
        const { startX, startY } = primaryWithCoord
        ctx.fillText('✅', startX, startY + 10)
      }
    },
  },
])

// 再描画
univerAPI.getActiveWorkbook().getActiveSheet().refreshCanvas()
```

## セル編集のトラブルシューティング [#troubleshooting]

### セルエディタ内の内容をリアルタイム取得するには？

`SheetEditChanging`に登録して、セルが編集されている間に現在のリッチテキスト値を読みます。 値はエディタに残り、編集が完了したときにのみワークシートに書かれています。

```typescript
import '@univerjs/sheets-ui/facade'

const subscription = univerAPI.addEvent(univerAPI.Event.SheetEditChanging, ({ value }) => {
  console.log(value.toPlainText())
})

// Call subscription.dispose() when the owning component or page is removed.
```

### セルエディタがフォーカス中に外部ボタン操作でイベントをトリガーされも、スナップショットに編集中セルの内容が含まれない

セル・エディターがフォーカスを失いたときに、セル・データはスナップショットに同期されます。つまり、編集が終了するときです。したがって、スナップショットが読み込まれる前に、セルはフォーカスを失わなければなりません。編集は次のように明示的に終了することができます。

```typescript
import '@univerjs/sheets-ui/facade'

async function saveWorkbook() {
  const fWorkbook = univerAPI.getActiveWorkbook()
  if (!fWorkbook) return

  await fWorkbook.endEditingAsync(true)
  const snapshot = fWorkbook.save()
  console.log(snapshot)
}

$btn.addEventListener('click', () => {
  saveWorkbook().catch(console.error)
})
```

参考：https://github.com/dream-num/univer/issues/1314

### Facade API で Workbook を生成直後に一部 API が動作しない

多くの API は、作業前にインターフェイスを完全にレンダリングする必要があります。Workbook が作成される直後に行われた呼び出しは、効果が取れない場合があります。このような呼び出しを `Rendered` または `Steady` (ライフサイクルの該当ステージ) で実行します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // 実行コード
  }
})

// disposable.dispose() で解除
```

参考：[Lifecycle](/guides/sheets/getting-started/lifecycle)
