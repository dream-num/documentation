title: API de Univer Sheets

Univer Sheets proporciona un motor de hoja de cálculo completo, y sus conceptos están diseñados para permanecer tan cerca de Microsoft Excel como es razonable.

## Importación

```typescript
import '@univerjs/sheets/facade'
import '@univerjs/sheets-ui/facade'
```

## Libro de trabajo

Un libro de trabajo contiene una o más hojas de trabajo, y corresponde a un archivo Excel.

`unitId` es el identificador único del libro de trabajo.

### Crear un libro

[`univerAPI.createWorkbook(data, options)`](https://docs.univer.ai/reference/facade/univer#createworkbook) crea un libro de trabajo y devuelve el objeto `FWorkbook`.

[`IWorkbookData`](/guides/sheets/model/workbook-data) describe la configuración de un libro de trabajo.

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' })
console.log(fWorkbook)
```

Si el nuevo libro de trabajo no debe convertirse en el libro de trabajo activo, pasar un objeto de opciones:

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' }, { makeCurrent: false })
console.log(fWorkbook)

// If you want to switch to this workbook after 3 seconds
setTimeout(() => {
  univerAPI.setCurrent(fWorkbook.getId())
}, 3000)
```

### Obtener datos del libro [#get-workbook-data]

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
console.log(snapshot)
```

### Descargar libro

Cuando un `Workbook` ya no es necesario, llame a `disposeUnit` en la instancia API para descargarlo.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook?.getId()
if (unitId) {
  univerAPI.disposeUnit(unitId)
}
```

<Callout type="warning">
  Cuando la página que acoge la instancia Univer se destruye, o la ruta se descarga, llame a `univer.dispose()` para limpiar en lugar de `univerAPI.disposeUnit`. `univer` y `univerAPI` son dos casos distintos; vea [Instalación &quot; Usage básico](/guides/sheets/getting-started/installation) por cómo obtener cada uno de ellos.
</Callout>

### Obtener ID del libro de trabajo

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook?.getId()
```

## Hoja de trabajo

Las hojas de trabajo almacenan los datos de la tabla, y cada hoja de trabajo pertenece a un libro de trabajo.

Un libro de trabajo puede contener múltiples hojas de trabajo, y los nombres de hoja de trabajo deben ser únicos dentro de un libro de trabajo.

`subUnitId` identifica una hoja de trabajo única dentro de un libro de trabajo.

### Obtener hojas de trabajo

Recuperar todas las hojas de trabajo en el libro de trabajo:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const sheets = fWorkbook.getSheets()
```

Recuperar la hoja de trabajo activa:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
```

### Obtener datos de la hoja de trabajo

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const sheetSnapshot = fWorksheet.getSheet().getSnapshot()
```

### Crear una hoja de trabajo [#create-worksheet]

El siguiente ejemplo crea hojas de trabajo con el método [`FWorkbook.create`](https://docs.univer.ai/reference/facade/workbook#create).

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Create a worksheet named 'Sheet2' with 10 rows and 10 columns
const newSheet = fWorkbook.create('Sheet2', 10, 10)

// Create a new sheet named 'MyNewSheetWithData' with 10 rows and 10 columns and some data, and set it as the first sheet
const sheetData = {
  // ... Omit other properties
  cellData: {
    0: {
      0: {
        v: 'Hello Univer!',
      },
    },
  },
  // ... Omit other properties
}
const newSheetWithData = fWorkbook.create('MyNewSheetWithData', 10, 10, {
  index: 0,
  sheet: sheetData,
})
console.log(newSheetWithData)
```

### Eliminar hoja de trabajo

Pase una instancia de hoja de trabajo o una identificación de hoja de cálculo para eliminar una hoja de trabajo.

```typescript
// Delete the second worksheet
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.deleteSheet(sheet)

// The code below deletes the specified worksheet by id
// fWorkbook.deleteSheet(sheet.getSheetId());
```

### Activar hoja de cálculo

Para activar una hoja de trabajo, pasar una instancia de hoja de trabajo o un ID de hoja de cálculo, o llamar al método `FWorksheet.activate()`.

```typescript
// Activate the second worksheet
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.setActiveSheet(sheet)

// Activates the specified worksheet by id
// fWorkbook.setActiveSheet(sheet.getSheetId());

// Activate the worksheet using the FWorksheet.activate() method
// sheet.activate();
```

### Copiar hoja de cálculo

```typescript
// The code below duplicates the given worksheet
const fWorkbook = univerAPI.getActiveWorkbook()
const activeSheet = fWorkbook.getActiveSheet()
const duplicatedSheet = fWorkbook.duplicateSheet(activeSheet)
console.log(duplicatedSheet)
```

### Obtener ID de la hoja de cálculo

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet?.getSheetId()
```

### Color de la pestaña de hoja [#tab-color]

Haga clic con el botón derecho en una pestaña de hoja de trabajo para abrir su menú de color. Seleccione un color, o elija Reiniciar el color para eliminar el color personalizado y restaurar el aspecto predeterminado. El selector de color muestra el color actual de la hoja de trabajo. A través de Facade API, pasar una cadena vacía a `setTabColor()` para restablecer el color; el cambio admite deshacer y rehacer.

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
sheet?.setTabColor('')
```

### Establecer el recuento de filas y columnas de la hoja de cálculo

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
// Set row count to 100000
fWorksheet.setRowCount(100000)
// Set column count to 30
fWorksheet.setColumnCount(30)
```

### Actualizar la hoja de cálculo

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.refreshCanvas()
```

### Ampliación de la hoja de cálculo

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set zoom ratio to 200%
fWorksheet.zoom(2)
const zoomRatio = fWorksheet.getZoom()
```

### Desplazarse a la celda

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Scroll to cell D10
const fRange = fWorksheet.getRange('D10')
const row = fRange.getRow()
const column = fRange.getColumn()
fWorksheet.scrollToCell(row, column)

// Add scroll animation duration
fWorksheet.scrollToCell(row, column, 1000)

// Get scroll state
const scrollState = fWorksheet.getScrollState()
const { offsetX, offsetY, sheetViewStartColumn, sheetViewStartRow } = scrollState
console.log(scrollState) // sheetViewStartRow: 9, sheetViewStartColumn: 3, offsetX: 0, offsetY: 0
```
