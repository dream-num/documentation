<Callout type="warning" title="Firefox 호환성 참고">
  Firefox는 `clipboard.readText()`를 지원하지 않습니다. 자세한 내용은 [MDN 소개](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText)을 참조하십시오. 그런 경우 Univer는 페이스트 이벤트에서 클립 보드를 읽습니다. 키보드 단축키에서만 작동합니다.
</Callout>

Univer는 클립보드 API로 복사 및 붙여 넣기를 구현합니다. Univer에서 외부 애플리케이션으로 외부 애플리케이션에서 Univer로 복사할 수 있으며, Univer 시트 사이로 복사할 수도 있습니다.

<Callout type="warning" title="보안 Context 요구 사항">
  현대 브라우저 보안 정책은 HTTPS와 같은 보안 상황에만 클립보드 API를 허용합니다.
</Callout>

Univer는 다음 복사 및 붙여넣기 작업을 지원합니다.

- 외부 애플리케이션에서 Univer로 복사 및 붙여넣기
- Univer에서 외부 애플리케이션으로 복사
- Univer 시트 사이 복사 및 붙여넣기

선택적인 풀은 이 케이스를 덮습니다:

- 값만 붙여넣기
- 서식만 붙여넣기
- 열 너비만 붙여넣기
- 국경 없는 과거 내용만
- 수식만 붙여넣기

데스크톱 리본에서, **팟캐스트** 드롭다운 언도 옆에 정상적인 풀, 페이스트 값, 페이스트 형식, 페이스트 컬럼 폭, 국경없이 페이스트를 제공합니다. 그것의 메뉴 ID는 `sheet.menu.paste`입니다; 컨텍스트-menu **페이스 북** 항목은 `sheet.menu.paste-special`를 사용합니다. 리본 드롭다운은 모양 텍스트를 편집하는 동안 숨겨집니다.

## 복사 비활성화

**공급 능력**는 전체 워크북 또는 특정 워크 시트에 대해 복사 할 수 있습니다.

다음 코드는 현재의 작업 책에 대한 복사를 비활성화합니다 :

```typescript
const workbookPermission = univerAPI.getActiveWorkbook()?.getWorkbookPermission()
const WorkbookCopyPermission = univerAPI.Enum.WorkbookPermissionPoint.CopyContent

if (workbookPermission) {
  workbookPermission.setPoint(WorkbookCopyPermission, false)
}
```

허가에 대한 자세한 내용은 [공급 능력](/guides/sheets/features/core/permission)를 참조하십시오.
