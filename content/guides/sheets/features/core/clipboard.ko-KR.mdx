<Callout type="warning" title="Firefox 호환성 안내">
  Firefox는 `clipboard.readText()`를 지원하지 않습니다. 자세한 내용은 [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText)을 참고하세요. 이 경우 Univer는 붙여넣기 이벤트에서만 클립보드 내용을 가져올 수 있으므로 키보드 단축키를 사용한 붙여넣기만 지원합니다.
</Callout>

Univer는 Clipboard API로 복사 및 붙여넣기 기능을 구현합니다. 외부 애플리케이션에서 Univer로 붙여넣기, Univer에서 외부 애플리케이션으로 복사하기, Univer Sheets 간 복사 및 붙여넣기를 지원합니다.

<Callout type="warning" title="보안 컨텍스트 요구 사항">
  최신 브라우저 보안 정책에 따라 Clipboard API는 HTTPS와 같은 보안 컨텍스트에서만 사용할 수 있습니다.
</Callout>

Univer는 다음 복사 및 붙여넣기 작업을 지원합니다.

- 외부 애플리케이션에서 Univer로 복사 및 붙여넣기
- Univer에서 외부 애플리케이션으로 복사
- Univer Sheets 간 복사 및 붙여넣기

다음과 같은 선택하여 붙여넣기 기능도 지원합니다.

- 값만 붙여넣기
- 서식만 붙여넣기
- 열 너비만 붙여넣기
- 테두리를 제외한 내용만 붙여넣기
- 수식만 붙여넣기

## 복사 비활성화

Univer에서는 개발자가 **권한 제어(permission control)**를 통해 통합 문서 전체 또는 특정 워크시트에서 사용자의 복사 기능을 비활성화할 수 있습니다.

예를 들어 다음 코드는 현재 통합 문서에서 사용자의 복사 기능을 비활성화합니다.

```typescript
const workbookPermission = univerAPI.getActiveWorkbook()?.getWorkbookPermission()
const WorkbookCopyPermission = univerAPI.Enum.WorkbookPermissionPoint.CopyContent

if (workbookPermission) {
  workbookPermission.setPoint(WorkbookCopyPermission, false)
}
```

권한 제어에 대한 자세한 내용은 [권한 제어](/guides/sheets/features/core/permission) 문서를 참고하세요.
