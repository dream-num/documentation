---
title: Rich Text-Nutzungsleitfaden
---

Univer bietet leistungsstarke Rich Text-Funktionen, die in verschiedenen Bereichen verwendet werden können Szenarien, einschließlich Zellinhalt, Kommentare und Hyperlinks. In diesem Leitfaden wird die Verwendung der Rich-Text-Funktionalität vorgestellt.

## Fassaden-API

Die Fassaden-API bietet eine Reihe von Methoden zum Erstellen von Rich-Text-bezogenen Objekten:

```typescript
// Create rich text
const richText = univerAPI.newRichText()
const richTextValue = univerAPI.newRichTextValue({ body: { dataStream: 'Hello Univer\r\n' } })

// Create paragraph style
const paragraphStyle = univerAPI.newParagraphStyle()
const paragraphStyleValue = univerAPI.newParagraphStyleValue()

// Create text style
const textStyle = univerAPI.newTextStyle()
const textStyleValue = univerAPI.newTextStyleValue()

// Create text decoration
const decoration = univerAPI.newTextDecoration()
```

Jede Erstellungsmethode verfügt über entsprechende Builder- und Wertversionen:
- Builder-Versionen (wie `newRichText`) werden zum Erstellen und Ändern von Stilen verwendet
- Wertversionen (wie `newRichTextValue`). wird zum Erstellen schreibgeschützter Stilobjekte verwendet

## Grundkonzepte

Das Rich-Text-System besteht hauptsächlich aus zwei Kernkomponenten:

1. **TextStyle (Textstil)**: Steuert das Erscheinungsbild von Text, wie Schriftart, Größe, Farbe usw.
2. **ParagraphStyle (Absatzstil)**: Steuert die Formatierung auf Absatzebene, wie Ausrichtung, Einrückung, Zeilenabstand usw.

## Textstileinstellungen

### Textstile erstellen

```typescript
// Create a basic text style
const textStyle = univerAPI.newTextStyle()
  .setFontFamily('Arial')
  .setFontSize(12)
  .setItalic(true)
  .setBold(true)
  .build()

// Create a text style with colors
const coloredStyle = univerAPI.newTextStyle()
  .setColor({ rgb: '#FF0000' }) // Set red text
  .setBackground({ rgb: '#FFFF00' }) // Set yellow background
  .build()
```

### Textdekorationen

```typescript
// Add underline
const underlineStyle = univerAPI.newTextStyle()
  .setUnderline(
    univerAPI.newTextDecoration()
      .setShow(true)
      .setColor({ rgb: '#0000FF' })
      .setLineType(univerAPI.Enum.TextDecoration.SINGLE),
  )
  .build()

// Add strikethrough
const strikethroughStyle = univerAPI.newTextStyle()
  .setStrikethrough(
    univerAPI.newTextDecoration()
      .setShow(true),
  )
  .build()
```

## Absatzstileinstellungen

### Absatzstile erstellen

```typescript
// Create a basic paragraph style
const paragraphStyle = univerAPI.newParagraphStyle()
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER) // Center alignment
  .setLineSpacing(1.5) // 1.5 line spacing
  .build()

// Set paragraph indentation
const indentedStyle = univerAPI.newParagraphStyle()
  .setIndentFirstLine({ value: 2, unit: 'cm' }) // First line indent 2cm
  .setIndentStart({ value: 1, unit: 'cm' }) // Left indent 1cm
  .build()
```

## Anwendungsfälle

### 1. Zell-Rich-Text

Es gibt zwei Möglichkeiten, Rich-Text für Zellen festzulegen: [`setRichTextValueForCell`](https://docs.univer.ai/reference/facade/range#setrichtextvalueforcell) und [`setRichTextValues`](https://docs.univer.ai/reference/facade/range#setrichtextvalues).

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')
console.log(fRange.getValue(true))

// Set A1 cell value to rich text
const richText = univerAPI.newRichText()
  .insertText('Hello World')
  .setStyle(0, 1, { bl: 1, cl: { rgb: '#c81e1e' } })
  .setStyle(6, 7, { bl: 1, cl: { rgb: '#c81e1e' } })
fRange.setRichTextValueForCell(richText)
console.log(fRange.getValue(true).toPlainText()) // Hello World

// Set A1:B2 cell value to rich text
fRange.setRichTextValues([
  [richText, richText],
  [null, null],
])
console.log(fRange.getValue(true).toPlainText()) // Hello World
```

### 2. Kommentar-Rich-Text

```typescript
// Add formatted comments
const range = univerAPI.getActiveWorkbook()
  .getActiveSheet()
  .getActiveRange()

// Create comment content
const comment = univerAPI.newTheadComment()
  .setContent(
    univerAPI.newRichText()
      .insertText('Please check the data in this cell'),
  )

// Add comment asynchronously
const success = await range.addCommentAsync(comment)
if (success) {
  console.log('Comment added successfully')
}
```

### 3. Hyperlink-Rich-Text

```typescript
// Create rich text with hyperlink
const range = univerAPI.getActiveWorkbook()
  .getActiveSheet()
  .getActiveRange()

// Create hyperlink using newRichText().insertLink
const richText = univerAPI.newRichText()
  .insertLink('Visit Univer', '/')

// Set to cell
range.setRichTextValueForCell(richText)
```
