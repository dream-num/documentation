数値フォーマットは、数値がセルにどのように表示されるかを制御します。 フォーマットは、数千の区切り文字が使用されるか、値がパーセンテージまたは通貨記号で示されているかどうか、他のオプションで小数点数を決定します。 フォーマットが設定されると、データは読みやすくなります。

ツールバーの通貨アクションは、Univerの`region`から通貨記号とパターンを取ります。 `region`が明示的に設定されていない場合は、`locale`に従います。

```typescript
const univer = new Univer({
  locale: LocaleType.JA_JP,
  region: LocaleType.DE_DE,
})
```

<Callout type="warning" title="キューション">
  **DBNumの構文**はサポートされていません。
</Callout>

## 使い方 [#usage]

UI では、メニューバーからセルの番号形式を設定します。コードでは、[`ICellData`](/guides/sheets/model/cell-data) オブジェクトの [`s.n.pattern`](/guides/sheets/model/cell-data#number-format)[^number-format-value] フィールドを設定します。

```typescript
const data = {
  v: 123456.789,
  s: {
    n: {
      pattern: '#,##0.00',
    },
  },
}
```

**デフォルトでは、日付として解釈できる 0 と数字で始まるテキストが自動的に対応する番号形式に変換されます。**

自動変換を防ぐには、次の2つのオプションのいずれかを使用します。

1. テキストにセルの番号形式を設定します。

```typescript
import { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

const data = {
  v: '012.0',
  s: {
    n: {
      pattern: DEFAULT_TEXT_FORMAT_EXCEL, // テキスト形式
    },
  },
}
```

フォーマットは、Facade API で設定することもできます。

```typescript
fRange.setNumberFormat(DEFAULT_TEXT_FORMAT_EXCEL)
```

2. 数値の前に単一の引用符`'`をタイプして下さい。これは[テキストの強制](/guides/sheets/model/cell-data#cell-type)と呼ばれます。

`UniverSheetsNumfmtPlugin` は、`disableTextFormatAlert`と`disableTextFormatMark`の2つのオプションを提供し、テキストとしてフォーマットされたセルの警告とマーカーを無効にします。

これらのオプションを、使用中の統合モードの既存の初期化にマージします。他のプラグイン、ロケール、テーマ、およびコンテナの設定を保存し、同じプラグインを2回登録しないでください。

## 数値の解析と小数桁 [#number-parsing]

会計表記は数値として読み取られます。`=VALUE("(5)")` は `-5` を返し、`(1,000)` や `($1,000)` は `-1000` になります。小数桁の増加と減少は書式の数値セクションのみを変更するため、日付と時刻のパターンは桁を保持します。

## プラグイン設定 [#plugin-configuration]

`UniverSheetsNumfmtPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | テキスト形式の警告を無効にします。 |
| `disableTextFormatMark` | `boolean` | `false` | テキスト形式マーカーを無効にします。 |

```typescript
import { UniverSheetsNumfmtPlugin } from '@univerjs/sheets-numfmt'

univer.registerPlugin(UniverSheetsNumfmtPlugin, {
  disableTextFormatAlert: true,
  disableTextFormatMark: true,
})
```

## プリセット設定 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | テキスト形式の警告を無効にします。 |
| `disableTextFormatMark` | `boolean` | `false` | テキスト形式マーカーを無効にします。 |

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import { createUniver } from '@univerjs/presets'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      disableTextFormatAlert: true,
      disableTextFormatMark: true,
    }),
  ],
})
```

## Facade API

### インポート

<Callout type="info" title="プラグインモードノート">
  プラグインモードでは、ファサードパッケージは別々にインポートされます。プリセットモードには、マッチングファサードのパッケージが含まれているため、追加のインポートは必要ありません。
</Callout>

```typescript
import '@univerjs/sheets-numfmt/facade'
```

### 数値書式の設定

パターンの構文については、https://support.microsoft.com/en-us/office/number-format-codes-5026bbd6-04bc-48cd-bf33-80f18b4eae68を参照してください。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1 セルの数値書式を '#,##0.00' に設定
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')
fRange.getDisplayValue() // 1,234.57
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1:B2 範囲の数値書式をまとめて設定
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues([
  [1234.567, 0.1234],
  [45658, 0.9876],
]).setNumberFormats([
  ['#,##0.00', '0.00%'],
  ['yyyy-MM-DD', ''],
])
fRange.getDisplayValues() // [['1,234.57', '12.34%'], ['2025-01-01', 0.9876]]
```

### 数値書式の取得

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1:B2 範囲の左上セルの数値書式を取得
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormat()
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// A1:B2 範囲内の各セルの数値書式を取得
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormats()
```

### 数値書式のロケール設定

[`FWorkbook.setNumfmtLocal(local)`](https://docs.univer.ai/reference/facade/workbook#setnumfmtlocal)は、数値をフォーマットするために使用されるロケールを設定します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')

// ja ロケールを適用
fWorkbook.setNumfmtLocal('ja')
fRange.getDisplayValue() // 1,234.57

// de ロケールを適用
fWorkbook.setNumfmtLocal('de')
fRange.getDisplayValue() // 1.234,57
```

[^number-format-value]: 数値書式は表示だけを変え、保存値は変えません。`0.25` に `0%` を適用すると `25%` と表示されますが、数式は `0.25` で計算します。

## 地域に合わせた日付プリセット [#localized-date-presets]

日付のフォーマットパネルは、Univerの現在の`locale`からプリセットパターンとプレビューを導きます。 既存のカスタム日付パターンが利用できなくなります。 選択した範囲を変更すると、その制御は現在のセルに一致させます。
