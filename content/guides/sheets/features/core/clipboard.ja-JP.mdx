---
title: コピーと貼り付け
---

<Callout type="warning" title="Firefoxの互換性ノート">
  Firefoxは`clipboard.readText()`をサポートしていません。詳細は[MDNの特長](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText)を参照してください。この場合、Univerはペーストイベントからクリップボードを読み込むので、キーボードショートカットでのみ作業を貼り付けます。
</Callout>

UniverはクリップボードAPIでコピー&ペーストを実行します。 コンテンツは、外部アプリケーションからUniver、Univerから外部アプリケーション、Univerシート間でコピーすることができます。

<Callout type="warning" title="セキュリティコンテキスト要件">
  現代のブラウザのセキュリティポリシーにより、Clipboard API は HTTPS などの安全なコンテキストでのみ許可されます。
</Callout>

Univer は次のコピー／貼り付け操作をサポートします:

- 外部アプリケーションからUniverへのコピーとペースト
- Univerから外部アプリケーションへのコピー
- Univerシート間のコピーとペースト

選択的なペーストは、これらのケースをカバーします。

- 値のみ貼り付け
- 書式のみ貼り付け
- 列幅のみ貼り付け
- 境界線のないコンテンツを貼り付けるだけ
- 数式のみ貼り付け

デスクトップのリボンでは、undo と redo の横にある **ペースト** のドロップダウンは、通常のペースト、ペースト値、ペースト形式、ペーストの列幅、および境界線のないペーストを提供します。 そのメニュー ID は `sheet.menu.paste` です。 コンテキストメニュー **スペシャルペースト** エントリは `sheet.menu.paste-special` を使用します。 リボンのドロップダウンは、形状のテキストを編集するときに隠されます。

## コピー機能の無効化

**パーミッション制御**は、ワークブック全体または特定のワークシートのコピーを無効にすることができます。

次のコードは、現在のワークブックのコピーを無効にします。

```typescript
const workbookPermission = univerAPI.getActiveWorkbook()?.getWorkbookPermission()
const WorkbookCopyPermission = univerAPI.Enum.WorkbookPermissionPoint.CopyContent

if (workbookPermission) {
  workbookPermission.setPoint(WorkbookCopyPermission, false)
}
```

許可の詳細については、[パーミッション制御](/guides/sheets/features/core/permission)を参照してください。
