## Facade API

完整的型別定義見 [Facade API](/reference/facade)。

### 行 Row

#### 在指定行後插入行

[`insertRowAfter(afterPosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowafter): 在指定行後插入一行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 這將在第一行位置後插入一行
sheet.insertRowAfter(0)
```

#### 在指定行前插入行

[`insertRowBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowbefore): 在指定行前插入一行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 這將在第一行位置前插入一行
sheet.insertRowBefore(0)
```

#### 插入多行

[`insertRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#insertrows): 從指定位置開始插入一行或多行連續的空白行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 將所有行向下移動三位
sheet.insertRows(0, 3)
```

#### 在指定行後插入多行

[`insertRowsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsafter): 在指定行後插入指定數量的行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 這將在第一行後插入五行
sheet.insertRowsAfter(0, 5)
```

#### 在指定行前插入多行

[`insertRowsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsbefore): 在指定行前插入指定數量的行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 這在第一行之前插入五行
sheet.insertRowsBefore(0, 5)
```

#### 刪除指定行

[`deleteRow(rowPosition)`](https://docs.univer.ai/reference/facade/worksheet#deleterow): 刪除指定位置上的行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 行從 0 開始 - 這將刪除第一行
sheet.deleteRow(0)
```

#### 刪除多行

[`deleteRows(rowPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deleterows): 從指定位置開始刪除指定數量的行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 行從 0 開始 - 這將刪除前兩行
sheet.deleteRows(0, 2)
```

#### 刪除多行 (不連續)

[`deleteRowsByPoints(rowPoints)`](https://docs.univer.ai/reference/facade/worksheet#deleterowsbypoints): 按一組行位置一次刪除多行，這些行不必連續。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 行從 0 開始 - 這將刪除第 3 行和第 5-7 行
fWorksheet.deleteRowsByPoints([2, [4, 6]])
```

#### 移動行

[`moveRows(rowSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#moverows): 將 `rowSpec` 選中的行移動到 `destinationIndex` 指定的位置。該範圍不必與單行或一組行對齊，它跨過的每一行都會被選中。

```typescript
// 以下程式碼將行 1-2 移動到目標索引 5
// 這會導致這些行變為行 3-4
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 選擇要移動的第 1 行和第 2 行
const rowSpec = sheet.getRange('1:2')
sheet.moveRows(rowSpec, 5)
```

#### 隱藏行

[`hideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#hiderow): 隱藏指定範圍內的行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 這將隱藏第一行
const range = sheet.getRange('1:1')
sheet.hideRow(range)
```

#### 隱藏多行

[`hideRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#hiderows): 從指定索引開始隱藏連續的一行或多行。索引從 0 開始。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 隱藏前三行
sheet.hideRows(0, 3)
```

#### 取消隱藏行

[`unhideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#unhiderow): 取消隱藏指定範圍內的行。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 如果第一行之前被隱藏，則取消隱藏第一行
const range = sheet.getRange('1:1')
sheet.unhideRow(range)
```

#### 顯示多行

[`showRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#showrows): 從指定索引開始取消隱藏連續的一行或多行。索引從 0 開始。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 取消隱藏前三行
sheet.showRows(0, 3)
```

#### 設定行高

[`setRowHeight(rowPosition, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheight): 設定指定行的行高，單位為畫素。預設情況下，行會隨單元格內容自動增高。要將高度固定為指定值，請使用 `setRowHeightsForced(startRow, numRows, height)`。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 將第一行的高度設定為 200 畫素
sheet.setRowHeight(0, 200)
```

#### 設定多行高度

[`setRowHeights(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheights): 設定指定行的高度，單位為畫素。預設情況下，行會隨單元格內容自動增高。要將高度固定為指定值，請使用 `setRowHeightsForced(startRow, numRows, height)`。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 將前三行的高度設定為 200 畫素
sheet.setRowHeights(0, 3, 200)
```

#### 強制設定多行高度

[`setRowHeightsForced(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheightsforced): 設定指定行的高度，單位為畫素。預設情況下，行會隨單元格內容自動增高。使用 `setRowHeightsForced` 後，即使內容高於行高，行也會保持設定的固定高度。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 將前三行的高度設定為 5 畫素
sheet.setRowHeightsForced(0, 3, 5)
```

#### 設定行高自動調整

[`autoResizeRows(startRow, numRows)`](https://docs.univer.ai/reference/facade/worksheet#autoresizerows): 將指定行的高度調整為適應文字內容。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 設定前三行的高度自動調整以適應單元格內容
sheet.autoResizeRows(0, 3)
```

#### 設定行自訂屬性

[`setRowCustom(custom)`](https://docs.univer.ai/reference/facade/worksheet#setrowcustom): 為指定行設定自定義屬性。每行會儲存一個 `custom` 物件，其中可以存放任意符合 JSON 格式的資料，用於儲存額外資訊。寫入 `custom` 會覆蓋原有的 `custom` 資料。若要保留已有的 `custom` 資料，應先讀取 `custom` 物件，將其合併到新資料中，然後再寫回。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 設定第一行和第三行的自訂屬性
sheet.setRowCustom({
  0: { color: 'red' },
  2: { size: 16 },
})
```

## 尺寸驗證與零尺寸列欄 [#dimension-validation]

行高和列寬必須是有限且非負的數值。尺寸相關命令會拒絕數字字串、負數、`NaN` 和 `Infinity`。單行或單列的尺寸可以為 0，而 `defaultRowHeight` 和 `defaultColumnWidth` 必須嚴格大於 0。建立工作表時，Univer 會規範化快照中的無效尺寸。

尺寸為 0 的行或列不同於透過可見性標記隱藏的行或列。對可見但尺寸為 0 的行或列取消隱藏，會將其恢復為工作表的預設尺寸，該操作可撤銷、可重做。將外部尺寸傳給編輯器之前，應先用下列公開的校驗函式檢查。

```ts
import { isValidColumnDimensions, isValidRowDimensions, isValidSheetDimension } from '@univerjs/core'

isValidSheetDimension(24) // true
isValidSheetDimension(0, false) // false: default dimensions must be positive
isValidRowDimensions({ h: 24, ah: 32 }) // true
isValidColumnDimensions({ w: -1 }) // false
```
