title: Kopieren und Einfügen
---

<Callout type="warning" title="Firefox Compatibility Note">
Firefox unterstützt `clipboard.readText()` nicht, siehe [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText). In diesem Fall kann Univer den Inhalt der Zwischenablage nur aus dem Einfügeereignis abrufen und unterstützt daher nur das Einfügen von Tastaturkürzeln.
</Callout>

Univer verwendet die Clipboard-API, um die Funktionalität zum Kopieren und Einfügen zu implementieren und das Kopieren und Einfügen von externen Anwendungen nach Univer, von Univer zu externen Anwendungen und zwischen Univer Sheets zu unterstützen.

<Callout type="warning" title="Security Context Requirement">
Aufgrund moderner Browser-Sicherheitsrichtlinien kann die Clipboard-API nur in sicheren Kontexten (z. B. HTTPS) verwendet werden.
</Callout>

Univer unterstützt das folgende Kopieren und Einfügen Vorgänge:

- Kopieren und Einfügen von externen Anwendungen in Univer
- Kopieren von Univer in externe Anwendungen
- Kopieren und Einfügen zwischen Univer-Blättern

Und unterstützt die folgenden selektiven Einfügefunktionen:

- Nur Werte einfügen
- Nur Formate einfügen
- Nur Spaltenbreiten einfügen
- Inhalt nur ohne Ränder einfügen
- Nur Formeln einfügen

## Kopieren deaktivieren

Univer ermöglicht Entwicklern, die Kopierfunktion für Benutzer in einer Arbeitsmappe oder bestimmten Blättern durch **Berechtigung zu deaktivieren Steuerung**.

Der folgende Code deaktiviert beispielsweise die Kopierfunktion für Benutzer in der aktuellen Arbeitsmappe:

```typescript
const workbookPermission = univerAPI.getActiveWorkbook()?.getWorkbookPermission()
const WorkbookCopyPermission = univerAPI.Enum.WorkbookPermissionPoint.CopyContent

if (workbookPermission) {
  workbookPermission.setPoint(WorkbookCopyPermission, false)
}
```

Weitere Informationen zur Berechtigungssteuerung finden Sie in der Dokumentation zur [Berechtigungssteuerung](/guides/sheets/features/core/permission).
