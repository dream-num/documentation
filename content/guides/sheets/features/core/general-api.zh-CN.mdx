在 Univer 中，可调用的 Facade API 取决于文档类型。本页介绍所有文档类型都通用的 Facade API。

## 引入

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 概念

### 命令

Univer 中的大部分操作都注册在命令系统上，并由命令系统触发。所有操作经由同一条路径，因此撤销、重做和协同等功能得以实现。

<Callout>设计细节参见 [Univer 命令系统](/blog/univer#command-system)。</Callout>

## 命令系统

Univer 中的几乎所有操作都注册在命令系统上，并通过命令系统触发。将所有操作集中于一处，是实现撤销、重做和协同等功能的前提。

Univer 只有这一套命令系统，各类定制功能都基于它实现。

<Callout>
  每个命令对应一个唯一的 ID。查询具体命令 ID 的方法参见 [如何查找命令 ID](/blog/find-the-command-id)。
</Callout>

### 监听命令

Univer 提供两个时机监听命令：执行前与执行后。

- `Event.BeforeCommandExecute`：在命令执行前执行自定义逻辑。
- `Event.CommandExecuted`：在命令执行后执行自定义逻辑。

#### 监听命令执行前

将 `Event.BeforeCommandExecute` 传给 `FUniver.addEvent`，即可注册预处理监听器。监听器中的逻辑会在命令执行前执行。

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, type, params }) => {
  // 在命令执行前执行自定义逻辑
})
```

如需阻止命令执行，可在监听器中将 `event.cancel` 设为 `true`。

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  event.cancel = true
})
```

#### 监听命令执行后

将 `Event.CommandExecuted` 传给 `FUniver.addEvent`，即可注册后处理监听器。命令执行完毕后，监听器中的逻辑再执行。

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type, params }) => {
  // 在命令执行后执行自定义逻辑
})
```

### 取消监听

注册命令监听器的方法返回一个 `IDisposable` 对象，调用 `IDisposable.dispose` 即可销毁。

不再使用的监听器应及时销毁，以保持程序稳定。

```typescript
const univerAPI = FUniver.newAPI(univer)

// 注册监听器
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, () => {
  // 在命令执行前执行自定义逻辑
})

// 示例：1 秒后取消监听
setTimeout(() => {
  // 取消监听
  disposable.dispose()
}, 1000)
```

### 执行命令

如果已知命令 ID 和所需参数，也可以直接使用 `FUniver.executeCommand` 执行命令。

例如，使用 `sheet.command.set-range-values` 设置 A1 单元格的值：

```typescript
const univerAPI = FUniver.newAPI(univer)

// 执行命令
univerAPI.executeCommand('sheet.command.set-range-values', {
  value: { v: 'Hello, Univer!' },
  range: { startRow: 0, startColumn: 0, endRow: 0, endColumn: 0 },
})
```

## 事件系统

Univer 的事件系统覆盖电子表格中的各类变化，可供监听和响应。事件大致分为剪贴板操作、选区变化、单元格交互、表格修改等几类。

### 事件类别

完整事件列表见：/reference/facade/events#%E5%B1%9E%E6%80%A7

1. **剪贴板事件**
   - `BeforeClipboardChange`：在剪贴板内容改变前触发，设置 `params.cancel = true` 可阻止该改变
   - `BeforeClipboardPaste`：在粘贴内容前触发，设置 `params.cancel = true` 可阻止粘贴
   - `ClipboardChanged`：在剪贴板内容改变后触发，可获取新的剪贴板内容
   - `ClipboardPasted`：在内容粘贴后触发，可获取粘贴的内容

2. **选区事件**
   - `SelectionChanged`：在选区改变时触发，给出新的选区范围
   - `SelectionMoveStart`：在选区开始移动时触发，可用于实现自定义选区效果
   - `SelectionMoveEnd`：在选区结束移动时触发，给出最终的选区范围
   - `SelectionMoving`：在选区移动过程中触发，可用于实时更新 UI
   - `DragOver`：在拖动经过单元格时触发
   - `Drop`：在放下拖动的选区内容时触发

3. **单元格事件**
   - `CellClicked`：在单元格被点击时触发，给出单元格的位置和内容
   - `CellHover`：在鼠标悬停于单元格上时触发，可用于显示提示信息
   - `CellPointerDown`：在指针于单元格上按下时触发，用于开始拖动或选择
   - `CellPointerUp`：在指针于单元格上抬起时触发，用于结束操作
   - `CellPointerMove`：在指针于单元格上移动时触发

4. **表格事件**
   - `SheetValueChanged`：在表格的值改变时触发，给出变更的范围和新值
   - `SheetZoomChanged`：在缩放级别改变时触发，给出新的缩放比例
   - `SheetSkeletonChanged`：在表格结构改变时触发，例如插入或删除行列
   - `BeforeSheetEditStart`：在单元格开始编辑前触发，可用于控制是否允许编辑
   - `SheetEditStarted`：在单元格开始编辑时触发，可用于实现自定义编辑器行为
   - `BeforeSheetEditEnd`：在单元格结束编辑前触发，可用于校验内容
   - `SheetEditEnded`：在单元格结束编辑时触发，给出编辑后的值
   - `SheetEditChanging`：在单元格编辑过程中触发，可用于实时校验或格式化
   - `Scroll`：在表格滚动时触发，给出滚动位置
   - `CrosshairHighlightEnabledChanged`：在十字光标高亮开启或关闭时触发

5. **表头事件**
   - `RowHeaderClick`：在行表头被点击时触发
   - `RowHeaderHover`：在鼠标悬停于行表头上时触发
   - `ColumnHeaderClick`：在列表头被点击时触发
   - `ColumnHeaderHover`：在鼠标悬停于列表头上时触发

6. **数据验证事件**
   - `BeforeSheetDataValidationAdd`：在添加数据验证规则前触发
   - `SheetDataValidationChanged`：在数据验证规则改变时触发
   - `SheetDataValidatorStatusChanged`：在数据验证状态改变时触发

7. **评论事件**
   - `BeforeCommentAdd`：在添加评论前触发
   - `CommentAdded`：在评论添加后触发
   - `BeforeCommentUpdate`：在更新评论前触发
   - `CommentUpdated`：在评论更新后触发
   - `BeforeCommentDeleted`：在删除评论前触发
   - `CommentDeleted`：在评论删除后触发

8. **数据处理事件**
   - `SheetBeforeRangeSort`：在范围排序前触发
   - `SheetRangeSorted`：在范围排序后触发
   - `SheetBeforeRangeFilter`：在范围筛选前触发
   - `SheetRangeFiltered`：在范围筛选后触发
   - `BeforePivotTableAdd`：在添加数据透视表前触发
   - `PivotTableAdded`：在数据透视表添加后触发

### 使用事件

监听事件使用 `univerAPI` 的 `addEvent` 方法，写法一致：

```typescript
univerAPI.addEvent(univerAPI.Event.事件名称, (params) => {
  // 处理事件参数
})
```

#### 示例：监听单元格点击

```typescript
univerAPI.addEvent(univerAPI.Event.CellClicked, (params) => {
  const { worksheet, workbook, row, column } = params
  console.log(`单元格被点击，行：${row}，列：${column}`)
})
```

#### 示例：监控剪贴板操作

```typescript
univerAPI.addEvent(univerAPI.Event.BeforeClipboardPaste, (params) => {
  const { text, html } = params
  // 如果要取消粘贴操作
  params.cancel = true
})
```

#### 示例：跟踪选区变化

```typescript
univerAPI.addEvent(univerAPI.Event.SelectionChanged, (params) => {
  const { worksheet, workbook, selections } = params
  console.log('选区已改变:', selections)
})
```

### 取消事件监听

事件监听器返回一个 `IDisposable` 对象，不再需要时可用它移除监听器：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetValueChanged, (params) => {
  // 处理值变化
})

// 之后，当你想要移除监听器时：
disposable.dispose()
```

### 最佳实践

1. 不再需要的监听器应及时销毁，否则会造成内存泄漏。
2. 根据场景选择最合适的事件，优先使用具体事件而非通用事件。
3. 事件处理函数应保持轻量，因为事件每次触发都会执行它。
4. 需要阻止默认行为时，使用 `BeforeClipboardChange` 等前置事件。

## 系统剪切板

使用 [`FUniver.copy()`](https://docs.univer.ai/reference/facade/univer#copy) 和 [`FUniver.paste()`](https://docs.univer.ai/reference/facade/univer#paste) 读写系统剪贴板。

<Callout>
  复制和粘贴依赖浏览器原生 API，[环境条件或权限](https://developer.mozilla.org/zh-CN/docs/Web/API/Clipboard/writeText)不满足时无法使用。
</Callout>

以下示例演示复制和粘贴 Sheet 区域。

```typescript
// 防止在控制台中执行复制粘贴代码时因失去焦点而失败，
// 此示例监听单元格点击事件并执行复制粘贴代码。
univerAPI.addEvent(univerAPI.Event.CellClicked, async (params) => {
  const fWorkbook = univerAPI.getActiveWorkbook()
  const fWorksheet = fWorkbook.getActiveSheet()

  // 将范围 A1:B2 复制到剪贴板
  const fRange = fWorksheet.getRange('A1:B2')
  fRange.activate().setValues([
    [1, 2],
    [3, 4],
  ])
  await univerAPI.copy()

  // 将复制的内容粘贴到范围 C1:D2
  const fRange2 = fWorksheet.getRange('C1')
  fRange2.activate()
  await univerAPI.paste()

  // 检查粘贴的内容
  console.log(fWorksheet.getRange('C1:D2').getValues()) // [[1, 2], [3, 4]]
})
```

剪贴板操作也可以通过[命令系统](#命令系统)执行：

```typescript
import { CopyCommand, PasteCommand } from '@univerjs/ui'

// 复制
univerAPI.executeCommand(CopyCommand.id)
// 粘贴
univerAPI.executeCommand(PasteCommand.id)
```

## WebSocket

Facade API 通过 `createSocket` 创建 WebSocket，传入 URL 即可建立连接。之后可监听 open、message、close、error 事件，也可用 send 方法主动发送消息、用 close 方法主动断开连接。

使用 Presets 安装时，可直接调用 `univerAPI.createSocket(url)`。使用手动组合安装时，需先安装 [`@univerjs/network`](/reference/packages/plugins/univerjs/network) 依赖包，再注册 `UniverNetworkPlugin` 插件。

```typescript
// ... 省略其他插件引入
import { UniverNetworkPlugin } from '@univerjs/network'

// ... 省略其他 facade 引入
import '@univerjs/network/facade'

// ... 省略其他插件注册
univer.registerPlugin(UniverNetworkPlugin)
```

以下是一个简单示例：

```typescript
// URL 换成你自己 WebSocket 服务的地址
const ws = univerAPI.createSocket('ws://47.100.177.253:8449/ws')

ws.open$.subscribe(() => {
  console.log('websocket opened')
  ws.send('hello')
})

ws.message$.subscribe((message) => {
  console.log('websocket message', message)
  const content = JSON.parse(message.data).content
  if (!content.includes('command')) {
    return
  }

  const commandInfo = JSON.parse(content)
  const { command, options } = commandInfo
  const { id, params } = command

  // 接受到协同数据，本地落盘
  univerAPI.executeCommand(id, params, options)
})

ws.close$.subscribe(() => {
  console.log('websocket closed')
})

ws.error$.subscribe((error) => {
  console.log('websocket error', error)
})

univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type, params, options }) => {
  // 仅同步本地 mutation
  if (
    type !== univerAPI.Enum.CommandType.MUTATION ||
    options?.fromCollab ||
    options?.onlyLocal ||
    id === 'doc.mutation.rich-text-editing'
  ) {
    return
  }

  const commandInfo = JSON.stringify({ command: { id, type, params }, options: { fromCollab: true } })
  ws.send(commandInfo)
})
```

启动 Univer 时必须指定 unitID，否则无法协同。

## 注册公式

通过 Facade API 可在当前 Univer 实例中注册自定义公式。

以下示例调用 [`registerFunction`](https://docs.univer.ai/reference/facade/formula#registerfunction) 一次，将 `CUSTOMSUM` 公式所需的算法、名称和描述注册到公式插件中，之后该公式即可使用。在任一空白单元格输入 `=CUSTOMSUM`，即可看到提示。

```typescript
// 注册公式支持 lambda 函数
const formulaEngine = univerAPI.getFormula()
formulaEngine.registerFunction(
  'CUSTOMSUM',
  (...variants) => {
    let sum = 0
    const last = variants[variants.length - 1]

    if (last.isLambda && last.isLambda()) {
      variants.pop()
      const variantsList = variants.map((variant) => (Array.isArray(variant) ? variant[0][0] : variant))
      sum += last.executeCustom(...variantsList).getValue()
    }

    for (const variant of variants) {
      sum += Number(variant) || 0
    }

    return sum
  },
  '求参数的和',
)

// Use the function in a cell
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const cellA1 = fWorksheet.getRange('A1')
cellA1.setValue(1)
const cellA2 = fWorksheet.getRange('A2')
cellA2.setValue(2)
const cellA3 = fWorksheet.getRange('A3')
cellA3.setValue({ f: '=CUSTOMSUM(A1,A2,LAMBDA(x,y,x*y))' })

// A3 will display: 5
formulaEngine.calculationEnd((functionsExecutedState) => {
  if (functionsExecutedState === 3) {
    console.log(cellA3.getValue()) // 5
  }
})
```

调用 `dispose` 方法可卸载已注册的公式。

```typescript
const functionDisposable =
  formulaEngine.registerFunction(
    // calculate
  )

// 卸载所注册的公式
functionDisposable.dispose()
```

如需更完整的国际化内容和描述，还可配置 `locales` 和 `description` 字段，如下所示。


各字段说明如下：

- `func` 指定公式的算法和名称映射。其入参是用户使用公式时输入的内容，可以是数字、字符串、布尔值或数组。
- `description` 设置自定义公式的描述。
- `locales` 下可配置多种语言，命名规则参见 [LocaleType](/reference/enums/locale-type)。多个公式的翻译可放在 `functionList` 下。字段的详细说明参见 [如何在 Formula Engine 中添加公式](/blog/custom-formula#how-to-add-formulas-in-formula-engine)。

<Callout>
  如需复用公式系统已有的算法并在其基础上扩展公式能力，可通过插件配置注册自定义公式。详细教程参见 [自定义公式](/blog/custom-formula/)。
</Callout>
