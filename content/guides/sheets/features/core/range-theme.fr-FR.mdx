Un thème de gamme contrôle la façon dont une table est affichée. Univer fournit un ensemble de thèmes prédéfinis, et vous pouvez également définir un thème de votre propre.

## Thèmes intégrés

Le thème par défaut s'appelle `default` et suit le `Excel Table default style`. Vous l'appliquez par l'intermédiaire de l'attribut `theme` . Univer fournit également un ensemble de thèmes de couleurs. Le Facade API ci-dessous liste les thèmes actuellement pris en charge.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const themes = fWorkbook.getRegisteredRangeThemes()
console.log(themes) // ['default', 'light-blue', 'light-grey', 'light-red', 'light-orange', 'light-yellow', 'light-green', 'light-azure', 'light-indigo', 'light-purple', 'light-magenta', 'middle-blue', 'middle-grey', 'middle-red', 'middle-orange', 'middle-yellow', 'middle-green', 'middle-azure', 'middle-indigo', 'middle-purple', 'middle-magenta', 'dark-blue', 'dark-grey', 'dark-red', 'dark-orange', 'dark-yellow', 'dark-green', 'dark-azure', 'dark-indigo', 'dark-purple', 'dark-magenta']
```

## Définir des thèmes

Un thème de plage peut être défini de deux façons : dans l'instantané, ou via le Facade API.

### Définir des thèmes à l'aide d'instantanés

Univer stocke des thèmes de gamme dans la ressource snapshot sous la clé `SHEET_RANGE_THEME_MODEL_PLUGIN`. La structure des données est la suivante :

```typescript
interface IRangeThemeRangeInfo {
  range: IRange
  unitId: string
  subUnitId: string
}

interface IRangeThemeStyleRule {
  rangeInfo: IRangeThemeRangeInfo
  themeName: string
}

interface ISheetRangeThemeModelJSON {
  // JSON storing the range and theme information for setting themes, the key is the id, please ensure it is not repeated, the value is the corresponding range information and template name.
  rangeThemeStyleRuleMap: Record<string, IRangeThemeStyleRule>
  // JSON storing the themes, the key is the theme name, and the value is the serialized JSON of the theme.
  rangeThemeStyleMapJson: Record<string, IRangeThemeStyleJSON>
}
```

### Définir des thèmes à l'aide de l'API Facade

L'approche recommandée consiste à définir les thèmes à travers le Facade API, puis à stocker l'information thématique avec les méthodes de sérialisation et de désactivation que Univer fournit.

Les API suivantes couvrent le workflow thématique:

```typescript
// Get the currently supported themes
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const themes = fWorkbook.getRegisteredRangeThemes()

// Set the default theme for A1:E20
const fRange = fWorksheet.getRange('A1:E20')
fRange.useThemeStyle('default') // 使用默认主题

// Get the currently used theme
const currentTheme = fRange.getUsedThemeStyle()

// Clear the theme style
fRange.useThemeStyle(undefined)
fRange.removeThemeStyle(currentTheme)
```

## Thèmes personnalisés

Au-delà des thèmes intégrés, Univer prend également en charge des thèmes personnalisés :

```typescript
// Create a custom theme
const fWorkbook = univerAPI.getActiveWorkbook()
const rangeThemeStyle = fWorkbook.createRangeThemeStyle('MyTheme', {
  secondRowStyle: {
    bg: {
      rgb: 'rgb(214,231,241)',
    },
  },
})
fWorkbook.registerRangeTheme(rangeThemeStyle)

// Use the custom theme for A1:E20
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:E20')
// Make sure the theme is registered, otherwise it will throw an error.
fRange.useThemeStyle('MyTheme')
```

L'appel suivant supprime un thème enregistré :

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.unregisterRangeTheme('MyTheme')
```

### Classe `RangeThemeStyle`

Les thèmes de gamme sont construits sur la classe [`RangeThemeStyle`](https://github.com/dream-num/univer/blob/dev/packages/sheets/src/models/range-theme-util.ts#L110), qui expose les propriétés suivantes pour la personnalisation:

- `name` : le nom du thème
- `wholeStyle` : le style pour toute la gamme
- `firstRowStyle` : le style de la première ligne
- `secondRowStyle` : le style de la deuxième ligne
- `headerRowStyle` : le style de la ligne d'en-tête
- `lastRowStyle` : le style de la dernière ligne
- `firstColumnStyle` : le style de la première colonne
- `secondColumnStyle` : le style de la deuxième colonne
- `headerColumnStyle` : le style de la colonne d'en-tête
- `lastColumnStyle` : le style de la dernière colonne

Chaque style a une paire de méthodes `getXXX/setXXX` correspondantes dans la classe RangeThemeStyle, par exemple:

```typescript
const rangeThemeStyle = new RangeThemeStyle('MyTheme')
rangeThemeStyle.setSecondRowStyle({
  bg: {
    rgb: 'rgb(214,231,241)',
  },
})
```

Vous pouvez également passer les options au constructeur:

```typescript
/**
 * @constructor
 * @param {string} name The name of the range theme style, it used to identify the range theme style.
 * @param {IRangeThemeStyleJSON} [options] The options to initialize the range theme style.
 */
class RangeThemeStyle {};

// For example:
const rangeThemeStyle = new RangeThemeStyle('MyTheme', {
  secondRowStyle: {
    bg: {
      rgb: 'rgb(214,231,241)',
    },
  },
})
```

Lorsque plusieurs styles sont définis, ils s'appliquent dans l'ordre de priorité suivant:

`lastRowStyle` > `headerRowStyle` > `lastColumnStyle` > `headerColumnStyle` > `secondRowStyle` > `firstRowStyle` > `secondColumnStyle` > `firstColumnStyle` > `wholeStyle`

Lorsque le style d'une cellule est en conflit avec le `range theme`, le style cellulaire a priorité. Un conflit survient lorsque les deux définissent la même propriété de style. Par exemple, si la cellule fixe son arrière-plan à `red` et que le `range theme` la fixe à `blue`, la cellule reste `red`.
