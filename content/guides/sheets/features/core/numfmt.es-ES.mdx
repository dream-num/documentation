Los formatos de números controlan cómo aparece un número en una celda. El formato determina el número de lugares decimales, si se utilizan miles de separadores, y si el valor se muestra como porcentaje o con un símbolo de moneda, entre otras opciones. Una vez que se establece un formato, los datos son más fáciles de leer.

La acción monetaria en la barra de herramientas toma su símbolo de moneda y patrón de Univer `region`. Si `region` no está configurado explícitamente, sigue `locale`:

```typescript
const univer = new Univer({
  locale: LocaleType.ES_ES,
  region: LocaleType.DE_DE,
})
```

<Callout type="warning" title="Precaución">
  **Sintaxis DBNum** no es compatible.
</Callout>

## Uso [#usage]

En la interfaz de usuario, establece el formato número de celda de la barra de menú. En código, establece el campo [`s.n.pattern`](/guides/sheets/model/cell-data#number-format)[^number-format-value] del objeto [`ICellData`](/guides/sheets/model/cell-data) de la célula.

```typescript
const data = {
  v: 123456.789,
  s: {
    n: {
      pattern: '#,##0.00',
    },
  },
}
```

**Por defecto, el texto que comienza con 0 y los números que se pueden interpretar como fechas se convierten al formato número correspondiente automáticamente.**

Para evitar la conversión automática, utilice una de las dos opciones siguientes:

1. Establecer el formato número de la celda a texto.

```typescript
import { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

const data = {
  v: '012.0',
  s: {
    n: {
      pattern: DEFAULT_TEXT_FORMAT_EXCEL, // Text format
    },
  },
}
```

El formato también se puede configurar a través de Facade API:

```typescript
fRange.setNumberFormat(DEFAULT_TEXT_FORMAT_EXCEL)
```

2. Escriba una sola cita `'` antes del número. Esto se llama [forcing text](/guides/sheets/model/cell-data#cell-type).

`UniverSheetsNumfmtPlugin` ofrece dos opciones, `disableTextFormatAlert` y `disableTextFormatMark`, para desactivar la advertencia y el marcador para las células formateadas como texto.

Combina estas opciones en la inicialización existente para el modo de integración en uso. Mantenga el otro plugin, locale, tema y configuración de contenedores, y no registre el mismo plugin dos veces.

## Análisis de números y decimales [#number-parsing]

La notación contable se lee como un número: `=VALUE("(5)")` devuelve `-5`, y `(1,000)` o `($1,000)` se convierte en `-1000`. Aumentar y Disminuir decimales cambian solo las secciones numéricas de un formato, así que los patrones de fecha y hora conservan sus dígitos.

## Configuración de plugins [#plugin-configuration]

`UniverSheetsNumfmtPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | Deshabilita la advertencia del formato de texto. |
| `disableTextFormatMark` | `boolean` | `false` | Desactiva el marcador de formato de texto. |

```typescript
import { UniverSheetsNumfmtPlugin } from '@univerjs/sheets-numfmt'

univer.registerPlugin(UniverSheetsNumfmtPlugin, {
  disableTextFormatAlert: true,
  disableTextFormatMark: true,
})
```

## Configuración de preajustes [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | `false` | Deshabilita la advertencia del formato de texto. |
| `disableTextFormatMark` | `boolean` | `false` | Desactiva el marcador de formato de texto. |

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import { createUniver } from '@univerjs/presets'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      disableTextFormatAlert: true,
      disableTextFormatMark: true,
    }),
  ],
})
```

## Facade API

### Importación

<Callout type="info" title="Nota del modo Plugin">
  En modo plugin, el paquete Facade es importado por separado. El modo Preset incluye el paquete Facado que coincide, por lo que no se requiere ninguna importación adicional.
</Callout>

```typescript
import '@univerjs/sheets-numfmt/facade'
```

### Establecer formato de número

Para la sintaxis del patrón, vea https://support.microsoft.com/en-us/office/number-format-codes-5026bbd6-04bc-48cd-bf33-80f18b4eae68

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set the number format of the A1 cell to '#,##0.00'.
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')
fRange.getDisplayValue() // 1,234.57
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set the number formats of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues([
  [1234.567, 0.1234],
  [45658, 0.9876],
]).setNumberFormats([
  ['#,##0.00', '0.00%'],
  ['yyyy-MM-DD', ''],
])
fRange.getDisplayValues() // [['1,234.57', '12.34%'], ['2025-01-01', 0.9876]]
```

### Obtener formato de número

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get the number format of the top-left cell of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormat()
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get the number formats of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormats()
```

### Establecer la configuración regional para el formato de número

[`FWorkbook.setNumfmtLocal(local)`](https://docs.univer.ai/reference/facade/workbook#setnumfmtlocal) establece el local utilizado para los números de formato.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')

// Set the locale en for number formatting.
fWorkbook.setNumfmtLocal('en')
fRange.getDisplayValue() // 1,234.57

// Set the locale de for number formatting.
fWorkbook.setNumfmtLocal('de')
fRange.getDisplayValue() // 1.234,57
```

[^number-format-value]: El formato numérico cambia la visualización, no el valor almacenado. El formato `0%` muestra `0.25` como `25%`, pero las fórmulas siguen calculando con `0.25`.

## Formatos de fecha localizados [#localized-date-presets]

El panel de formato de fecha deriva sus patrones de preestablecidos y previsualizaciones de Univer actual `locale`. Los patrones de fecha personalizada existentes permanecen disponibles. Cambiar el rango seleccionado refresca el panel para que sus controles coincidan con las células actuales.
