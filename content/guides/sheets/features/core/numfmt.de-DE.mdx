---
title: Zahlenformat
---

Die Zahlenformatfunktion in Tabellenkalkulationen wird verwendet, um zu steuern, wie Zahlen angezeigt werden. Es ermöglicht Benutzern, das Anzeigeformat von Zahlen anzupassen, einschließlich Dezimalstellen, Tausendertrennzeichen, Prozentsätze, Währungssymbole und mehr. Durch Festlegen des Zahlenformats können Benutzer das Lesen und Verstehen von Daten erleichtern.

Die Währungsaktion in der Symbolleiste wählt Symbol und Format anhand der Univer-Eigenschaft `region`. Ohne explizite Konfiguration folgt `region` dem Wert von `locale`:

```typescript
const univer = new Univer({
  locale: LocaleType.DE_DE,
  region: LocaleType.DE_DE,
})
```

<Callout type="warning" title="Caution">
Die **DBNum-Syntax** wird nicht unterstützt.
</Callout>

## Verwendung

In der Benutzeroberfläche können Sie das Zahlenformat der Zelle über die Menüleiste festlegen. Oder legen Sie das Feld [`s.n.pattern`](/guides/sheets/model/cell-data#number-format) im Zelldatenobjekt [`ICellData`](/guides/sheets/model/cell-data) fest.

```typescript
const data = {
  v: 123456.789,
  s: {
    n: {
      pattern: '#,##0.00',
    },
  },
}
```

**Standardmäßig werden Text, der mit 0 beginnt, und Zahlen, die in Datumsformate konvertiert werden können, automatisch in das entsprechende Zahlenformat konvertiert.**

Wenn Sie dies nicht automatisch wünschen Bei der Konvertierung können Sie eine der folgenden Methoden wählen:

1. Stellen Sie das Zellennummernformat auf Textformat ein.

```typescript
import { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

const data = {
  v: '012.0',
  s: {
    n: {
      pattern: DEFAULT_TEXT_FORMAT_EXCEL, // Text format
    },
  },
}
```

Oder verwenden Sie die Facade-API, um das Zellenformat festzulegen:

```typescript
fRange.setNumberFormat(DEFAULT_TEXT_FORMAT_EXCEL)
```

2. Fügen Sie ein einfaches Anführungszeichen `'` hinzu, bevor Sie die Zahl eingeben (dies wird als [Erzwingen von Text](/guides/sheets/model/cell-data#cell-type) bezeichnet).

## Facade API

### Importieren

<Callout type="info" title="Plugin mode note">
Nur im Plugin-Modus muss das Facade-Paket manuell importiert werden. Der Voreinstellungsmodus enthält bereits das entsprechende Facade-Paket, sodass kein zusätzlicher Import erforderlich ist.
</Callout>

```typescript
import '@univerjs/sheets-numfmt/facade'
```

### Zahlenformat festlegen

Spezifische Parameter finden Sie unter: https://support.microsoft.com/en-us/office/number-format-codes-5026bbd6-04bc-48cd-bf33-80f18b4eae68

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set the number format of the A1 cell to '#,##0.00'.
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')
fRange.getDisplayValue() // 1,234.57
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set the number formats of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.setValues([
  [1234.567, 0.1234],
  [45658, 0.9876],
]).setNumberFormats([
  ['#,##0.00', '0.00%'],
  ['yyyy-MM-DD', ''],
])
fRange.getDisplayValues() // [['1,234.57', '12.34%'], ['2025-01-01', 0.9876]]
```

### Zahlenformat abrufen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get the number format of the top-left cell of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormat()
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get the number formats of the A1:B2 range.
const fRange = fWorksheet.getRange('A1:B2')
fRange.getNumberFormats()
```

### Gebietsschema für die Zahlenformatierung festlegen

Sie können die Methode [`FWorkbook.setNumfmtLocal(local)`](https://docs.univer.ai/reference/facade/workbook#setnumfmtlocal) verwenden, um das Gebietsschema für die Zahlenformatierung festzulegen.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1')
fRange.setValue(1234.567).setNumberFormat('#,##0.00')

// Set the locale en_US for number formatting.
fWorkbook.setNumfmtLocal('en_US')
fRange.getDisplayValue() // 1,234.57

// Set the locale de_DE for number formatting.
fWorkbook.setNumfmtLocal('de_DE')
fRange.getDisplayValue() // 1.234,57
```

## Textformatwarnung und -markierung deaktivieren

Das `UniverSheetsNumfmtPlugin`-Plugin bietet `disableTextFormatAlert` und `disableTextFormatMark` zwei Konfigurationselemente zum Deaktivieren Warnung und Markierung des Zellentextformats.

```typescript
// presets configuration
const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverSheetsCorePreset({
      disableTextFormatAlert: true,
      disableTextFormatMark: true,
    }),
  ],
})
```

```typescript
// Plugin configuration
univer.registerPlugin(UniverSheetsNumfmtPlugin, {
  disableTextFormatAlert: true,
  disableTextFormatMark: true,
})
```
