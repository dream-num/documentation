Предусмотрено два уровня стилей по умолчанию:
1. Стиль листа по умолчанию
2. Стиль столбца или строки по умолчанию

Оба уровня можно настроить через интерфейс [`IWorksheetData`](/reference/types/worksheet-data) или Facade API.

## Настройка

По умолчанию стиль столбца имеет приоритет над стилем строки. Чтобы изменить это поведение, включите параметр `isRowStylePrecedeColumnStyle` при регистрации.

Выберите свой режим и добавьте эти параметры в существующую инициализацию. Сохраните остальные плагины, язык, тему и контейнер; не регистрируйте один плагин дважды.

<Tabs items={['Режим плагинов', 'Режим предустановок']}>
  <Tab>
    ```typescript
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, {
      isRowStylePrecedeColumnStyle: true,
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          sheets: {
            isRowStylePrecedeColumnStyle: true,
          },
        }),
      ],
    })
    ```
  </Tab>
</Tabs>

## Установка стиля по умолчанию

Задать стиль листа по умолчанию можно двумя способами:

1. Через интерфейс [`IWorksheetData`](/reference/types/worksheet-data)

```typescript
interface IWorksheetData {
  // other
  /**
   * @property {Nullable<IStyleData>} [defaultStyle] - Default style data of Worksheet.
   */
  defaultStyle?: Nullable<IStyleData>
}

interface IRowData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}

interface IColumnData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}
```

2. Через Facade API

```typescript
const fworkbook = univerAPI.getActiveWorkbook()
const fworksheet = fworkbook.getActiveSheet()
const defaultStyle = {
  bg: {
    rgb: 'red',
  },
}
const defaultColumnStyle = {
  bg: {
    rgb: 'blue',
  },
}
const defaultRowStyle = {
  bg: {
    rgb: 'green',
  },
}

// set default style
fworksheet.setDefaultStyle(defaultStyle)
// set column D default style
fworksheet.setColumnDefaultStyle(3, defaultColumnStyle)
// reset column D the default style
fworksheet.setColumnDefaultStyle(3, undefined)

// set row default style
fworksheet.setRowDefaultStyle(1, defaultRowStyle)
```

## Сжатие текста по ширине ячейки

Если текст шире ячейки, уменьшите размер шрифта через `FRange`. Настройка применяется ко всем ячейкам диапазона, а `getShrinkToFit()` возвращает состояние верхней левой ячейки.

```ts
const range = univerAPI.getActiveWorkbook().getActiveSheet().getRange('A1:C3')

range.setShrinkToFit(true)
const enabled = range.getShrinkToFit()
```

Уменьшение текста и перенос по строкам несовместимы. Включение переноса отключает уменьшение; включение уменьшения снимает перенос у ячеек, где он был задан.
