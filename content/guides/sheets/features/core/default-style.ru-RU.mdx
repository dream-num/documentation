Стили по умолчанию существуют на двух уровнях:
1. Стиль листа по умолчанию
2. Стиль по умолчанию столбца или строки

Вы можете установить один из них через интерфейс [`IWorksheetData`](/reference/types/worksheet-data) или Facade API.

## Настройка плагинов [#plugin-configuration]

`UniverSheetsPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `isRowStylePrecedeColumnStyle` | `boolean` | `false` | Заставляет стиль строки иметь приоритет над стилем колонки. |
| `textLineGap` | `number` | `0` | Дополнительный межстрочный интервал в ячейке в пикселях. |

## Настройка пресетов [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>sheets</ConfigKey> | `object` |  | Конфигурация для выбранной функции. |
| <ConfigKey depth={1}>isRowStylePrecedeColumnStyle</ConfigKey> | `boolean` | `false` | Заставляет стиль строки иметь приоритет над стилем колонки. |
| <ConfigKey depth={1}>textLineGap</ConfigKey> | `number` | `0` | Дополнительный межстрочный интервал в ячейке в пикселях. |

## Приоритет стилей строк и столбцов

По умолчанию стиль столбцов имеет приоритет над стилем строк. Установите `isRowStylePrecedeColumnStyle` во время регистрации, чтобы отменить этот порядок.

Выберите вкладку, которая соответствует вашей настройке Univer, и объедините эти параметры в существующую инициализацию.Сохраните другие плагины, локализацию, тему и настройки контейнера неизменными и не регистрируйте один и тот же плагин дважды.

<Tabs items={['Режим плагинов', 'Режим предустановок']}>
  <Tab>
    ```typescript
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, {
      isRowStylePrecedeColumnStyle: true,
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          sheets: {
            isRowStylePrecedeColumnStyle: true,
          },
        }),
      ],
    })
    ```
  </Tab>
</Tabs>

## Межстрочный интервал в ячейках [#text-line-gap]

`textLineGap` добавляет дополнительное пространство в пикселях между строками текста ячейки, включая богатый текст и редакторы ячеек. Установите его во время инициализации; это относится к каждой книге в экземпляре Univer. По умолчанию `0`, и значение должно быть конечным и неотрицательным.

<TextLineGapDemo />

<Tabs items={['Режим плагинов', 'Режим пресетов']}>
  <Tab>
    ```ts
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, { textLineGap: 6 })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [UniverSheetsCorePreset({ sheets: { textLineGap: 6 } })],
    })
    ```
  </Tab>
</Tabs>

Более крупный зазор не изменяет размер существующих рядов. Пересчет автоматических высот рядов, когда требуется дополнительное пространство; ячейки с фиксированной высотой могут обрезать свой текст. Это настройка уровня экземпляра, а не стиль абзаца на ячейку.

## Установка стиля по умолчанию

Вы можете установить стиль рабочего листа по умолчанию двумя способами:

1. Через интерфейс [`IWorksheetData`](/reference/types/worksheet-data)

```typescript
interface IWorksheetData {
  // other
  /**
   * @property {Nullable<IStyleData>} [defaultStyle] - Default style data of Worksheet.
   */
  defaultStyle?: Nullable<IStyleData>
}

interface IRowData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}

interface IColumnData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}
```

2. Сквозь Facade API

```typescript
const fworkbook = univerAPI.getActiveWorkbook()
const fworksheet = fworkbook.getActiveSheet()
const defaultStyle = {
  bg: {
    rgb: 'red',
  },
}
const defaultColumnStyle = {
  bg: {
    rgb: 'blue',
  },
}
const defaultRowStyle = {
  bg: {
    rgb: 'green',
  },
}

// set default style
fworksheet.setDefaultStyle(defaultStyle)
// set column D default style
fworksheet.setColumnDefaultStyle(3, defaultColumnStyle)
// reset column D the default style
fworksheet.setColumnDefaultStyle(3, undefined)

// set row default style
fworksheet.setRowDefaultStyle(1, defaultRowStyle)
```

## Сжатие текста по ширине ячейки

`FRange` может сжимать текст, который шире, чем его ячейка.Настройка применяется к каждой ячейке в диапазоне, и `getShrinkToFit()` возвращает состояние верхней левой ячейки.

```ts
const range = univerAPI.getActiveWorkbook().getActiveSheet().getRange('A1:C3')

range.setShrinkToFit(true)
const enabled = range.getShrinkToFit()
```

Уплотнение-в-приспособление и обертывание текста взаимоисключающие. Включение обертывания текста отключает сокращение-в-подгонку и позволяет отключать сокращение-в пристройку на любых ячейках, которые в настоящее время обертывают.
