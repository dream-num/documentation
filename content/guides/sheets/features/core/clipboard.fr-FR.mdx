---
title: Copier-coller
---

<Callout type="warning" title="Note de compatibilité Firefox">
  Firefox ne prend pas en charge `clipboard.readText()`. Voir [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText) pour plus de détails. Dans ce cas, Univer lit le presse-papiers de l'événement de collage, de sorte que le collage ne fonctionne qu'avec le raccourci clavier.
</Callout>

Univer implémente copier et coller avec l'API Clipboard. Le contenu peut être copié à partir d'applications externes dans Univer, Univer vers des applications externes et entre Univer Sheets.

<Callout type="warning" title="Contexte de la sécurité">
  Les politiques modernes de sécurité du navigateur permettent l'API Clipboard uniquement dans un contexte sécurisé, comme HTTPS.
</Callout>

Univer prend en charge les opérations de copier-coller suivantes :

- Copier et coller des applications externes dans Univer
- Copie de Univer vers des applications externes
- Copier et coller entre les feuilles Univer

La pâte sélective couvre ces cas:

- Coller uniquement les valeurs
- Coller uniquement les formats
- Coller uniquement les largeurs de colonnes
- Coller le contenu sans frontières seulement
- Coller uniquement les formules

Dans le Ribbon de bureau, le menu déroulant **Pâte** à côté de la désactivation et redo fournit une pâte normale, des valeurs de collage, des formats de collage et des largeurs de colonnes et de coller sans bordures. Son ID de menu est `sheet.menu.paste`; l'entrée contextuelle **Pâte spéciale** utilise `sheet.menu.paste-special`. Le menu déroulant Ribbon est caché pendant que vous modifiez le texte de forme.

## Désactiver la copie

**Contrôle des autorisations** peut désactiver la copie d'un cahier de travail entier ou de feuilles de travail spécifiques.

Le code suivant désactive la copie du cahier de travail actuel :

```typescript
const workbookPermission = univerAPI.getActiveWorkbook()?.getWorkbookPermission()
const WorkbookCopyPermission = univerAPI.Enum.WorkbookPermissionPoint.CopyContent

if (workbookPermission) {
  workbookPermission.setPoint(WorkbookCopyPermission, false)
}
```

Pour plus d'informations sur les permissions, voir [Contrôle des autorisations](/guides/sheets/features/core/permission).
