title: Copier-coller
---

<Callout type="warning" title="Compatibilité avec Firefox">
  Firefox ne prend pas en charge `clipboard.readText()` ; consultez [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText). Dans ce cas, Univer ne peut récupérer le contenu du presse-papiers qu'à partir de l'événement de collage et ne prend donc en charge que le collage au moyen d'un raccourci clavier.
</Callout>

Univer utilise l'API Clipboard pour proposer la fonctionnalité de copier-coller. Il est possible de copier et coller du contenu depuis des applications externes vers Univer, de le copier depuis Univer vers des applications externes et de le copier-coller entre des feuilles Univer Sheets.

<Callout type="warning" title="Contexte sécurisé requis">
  En raison des politiques de sécurité des navigateurs modernes, l'API Clipboard ne peut être utilisée que dans un contexte sécurisé, par exemple en HTTPS.
</Callout>

Univer prend en charge les opérations de copier-coller suivantes :

- Copier et coller du contenu depuis des applications externes vers Univer
- Copier du contenu depuis Univer vers des applications externes
- Copier et coller du contenu entre des feuilles Univer Sheets

Il propose également les options de collage spécial suivantes :

- Coller uniquement les valeurs
- Coller uniquement les formats
- Coller uniquement les largeurs de colonnes
- Coller uniquement le contenu sans les bordures
- Coller uniquement les formules

## Désactiver la copie

Univer permet aux développeurs de désactiver la copie pour les utilisateurs dans un classeur ou dans certaines feuilles à l'aide du **contrôle des autorisations**.

Par exemple, le code suivant désactive la copie pour les utilisateurs dans le classeur actif :

```typescript
const workbookPermission = univerAPI.getActiveWorkbook()?.getWorkbookPermission()
const WorkbookCopyPermission = univerAPI.Enum.WorkbookPermissionPoint.CopyContent

if (workbookPermission) {
  workbookPermission.setPoint(WorkbookCopyPermission, false)
}
```

Pour en savoir plus sur le contrôle des autorisations, consultez la documentation [Contrôle des autorisations](/guides/sheets/features/core/permission).
