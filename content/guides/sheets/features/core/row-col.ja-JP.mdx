## Facade API

[Facade API](/reference/facade) リファレンスには、完全なタイプ定義が含まれています。

### 行（Row）

#### 指定位置の直後に行を挿入

[`insertRowAfter(afterPosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowafter): 与えられた位置の行の後に新しい行をインサートします。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭行（位置 0）の直後に 1 行挿入
sheet.insertRowAfter(0)
```

#### 指定位置の直前に行を挿入

[`insertRowBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowbefore):与えられた位置の行の前に新しい行をインサートします。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭行（位置 0）の直前に 1 行挿入
sheet.insertRowBefore(0)
```

#### 指定位置から複数行を挿入

[`insertRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#insertrows): 与えられた位置から始まる1つ以上の連続空白行をインサートします。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭から 3 行分下方にシフト
sheet.insertRows(0, 3)
```

#### 指定行の直後に複数行を挿入

[`insertRowsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsafter):指定された位置の行の後に指定した行数を入力します。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭行の直後に 5 行挿入
sheet.insertRowsAfter(0, 5)
```

#### 指定行の直前に複数行を挿入

[`insertRowsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsbefore):指定された位置の行の前に指定した行数を入力します。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭行の直前に 5 行挿入
sheet.insertRowsBefore(0, 5)
```

#### 指定位置の行を削除

[`deleteRow(rowPosition)`](https://docs.univer.ai/reference/facade/worksheet#deleterow): 指定した位置で行を削除します。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 行は 0 から始まる - 先頭行を削除
sheet.deleteRow(0)
```

#### 指定位置から複数行を削除

[`deleteRows(rowPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deleterows):指定された位置から始まる行の指定した数を削除します。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭 2 行を削除
sheet.deleteRows(0, 2)
```

#### 複数行（不連続）を削除

[`deleteRowsByPoints(rowPoints)`](https://docs.univer.ai/reference/facade/worksheet#deleterowsbypoints): 行の位置の配列を与えられた単一の操作で複数の行を削除します。行は連続する必要はありません。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 行は 0 から始まる - これにより、3 行目と 5～7 行目が削除されます
fWorksheet.deleteRowsByPoints([2, [4, 6]])
```

#### 行を新しい位置へ移動

[`moveRows(rowSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#moverows): `rowSpec`から`destinationIndex`に選択した行を移動します。範囲は単一の行または行のグループと整列する必要はありません。各行が選択されます。

```typescript
// 下記コードは行 1-2 (表示上 2-3 行目) を宛先インデックス 5 に移動
// 結果としてそれらは行 3-4 となる
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 移動対象として行 1 および行 2 を選択
const rowSpec = sheet.getRange('1:2')
sheet.moveRows(rowSpec, 5)
```

#### 範囲内の行を非表示

[`hideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#hiderow): 指定した範囲の行を非表示にします。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭行を非表示
const range = sheet.getRange('1:1')
sheet.hideRow(range)
```

#### 連続する複数行を非表示

[`hideRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#hiderows): 与えられたインデックスで始まる1つ以上連続した行を非表示にします。このメソッドは 0 ベースのインデックスを使用します。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭 3 行を非表示
sheet.hideRows(0, 3)
```

#### 範囲内の行を再表示

[`unhideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#unhiderow):与えられた範囲の行を非表示にします。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 非表示だった先頭行を再表示
const range = sheet.getRange('1:1')
sheet.unhideRow(range)
```

#### 連続する複数行を再表示

[`showRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#showrows): 与えられたインデックスで始まる1つ以上の連続行を非表示にします。このメソッドは0ベースのインデックスを使用します。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭 3 行を再表示
sheet.showRows(0, 3)
```

#### 行の高さを設定

[`setRowHeight(rowPosition, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheight): ピクセル内の指定した行の高さを設定します。デフォルトでは、行はセルのコンテンツに合わせて成長します。特定の高さを強制するには、`setRowHeightsForced(startRow, numRows, height)`を使用します。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭行の高さを 200px に設定
sheet.setRowHeight(0, 200)
```

#### 複数行の高さを設定

[`setRowHeights(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheights): ピクセル内の指定した行の高さを設定します。デフォルトでは、行はセルのコンテンツに合わせて成長します。特定の高さを強制するには、`setRowHeightsForced(startRow, numRows, height)`を使用します。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭 3 行を 200px に設定
sheet.setRowHeights(0, 3, 200)
```

#### 複数行の高さを強制固定

[`setRowHeightsForced(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheightsforced): ピクセル内の指定した行の高さを設定します。デフォルトでは、行はセルのコンテンツに合わせて成長します。`setRowHeightsForced`では、各行は、そのコンテンツが背が高い場合でも、割り当てられた高さを保持します。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭 3 行を 5px に強制固定
sheet.setRowHeightsForced(0, 3, 5)
```

#### 行の自動高さ調整

[`autoResizeRows(startRow, numRows)`](https://docs.univer.ai/reference/facade/worksheet#autoresizerows): テキストコンテンツに合わせて指定した行の高さを設定します。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭 3 行を内容に合わせて自動調整
sheet.autoResizeRows(0, 3)
```

#### 行のカスタムプロパティ設定

[`setRowCustom(custom)`](https://docs.univer.ai/reference/facade/worksheet#setrowcustom): 与えられた行にカスタムプロパティを設定します。各行は、追加情報を保存するための任意のJSONデータを保持できる `custom`オブジェクトを受け取ります。 `custom`を書くことは、以前に保存された`custom`データを上書きします。既存の`custom`データを保持するには、`custom`のオブジェクトを最初に読み、新しいデータにマージし、それを書きます。

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 1 行目と 3 行目にカスタム属性を設定
sheet.setRowCustom({
  0: { color: 'red' },
  2: { size: 16 },
})
```

#### 指定位置の直前に列を挿入

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 先頭 2 列を削除
sheet.deleteColumns(0, 2)
```

#### 複数列（不連続）を削除

[`deleteColumnsByPoints(columnPoints)`](https://docs.univer.ai/reference/facade/worksheet#deletecolumnsbypoints): 列の位置の配列を与えられた単一の操作で複数の列を削除します。 列は連続する必要はありません。

```typescript

// 列は 0 起算 - これにより、列 C と列 E〜G が削除されます

```

#### 列を新しい位置へ移動

[`moveColumns(columnSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#movecolumns): `columnSpec`から`destinationIndex`に選択した列を移動します。範囲は単一の列または列のグループと整列する必要はありません。各列が選択されます。

```typescript

const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 移動対象として列 A と列 B を選択
const columnSpec = sheet.getRange('A:B')
sheet.moveColumns(columnSpec, 5)
```


[`setColumnCustom(custom)`](https://docs.univer.ai/reference/facade/worksheet#setcolumncustom): 与えられた列にカスタムプロパティを設定します。各列は、追加情報を保存するための任意のJSONデータを保持できる`custom`オブジェクトを受け取ります。 `custom`を書くことは、以前に保存された`custom`データを上書きします。既存の`custom`データを保持するには、`custom`のオブジェクトを最初に読み、新しいデータにマージし、それを書きます。

## サイズの検証とゼロサイズの行・列 [#dimension-validation]

列の高さと列の幅は、有限、負の数字でなければなりません。 寸法コマンドは、数値文字列、負の値、`NaN`、`Infinity`を拒否します。 ゼロは、個々の行または列に許可され、`defaultRowHeight`と`defaultColumnWidth`は厳密に正当でなければなりません。 シートが作成されると、Univerはスナップショットの無効な寸法を正規化します。

サイズゼロの行列または列は、その可視フラグを介して隠されているものと異なる。 目に見えるゼロサイズの行や列を非表示にすると、シートのデフォルトサイズに戻り、変更を解除します。 エディタにそれらを渡す前に、以下のパブリックバリデータで外部の寸法を検証します。

```ts
import { isValidColumnDimensions, isValidRowDimensions, isValidSheetDimension } from '@univerjs/core'

isValidSheetDimension(24) // true
isValidSheetDimension(0, false) // false: default dimensions must be positive
isValidRowDimensions({ h: 24, ah: 32 }) // true
isValidColumnDimensions({ w: -1 }) // false
```
