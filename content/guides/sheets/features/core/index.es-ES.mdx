Las características principales de Univer Sheets incluyen un editor de hojas de cálculo, un motor de fórmulas, un motor de renderizado, un motor de formato de números, un sistema de diseño y una biblioteca de componentes de interfaz de usuario. Juntos, forman una poderosa plataforma para manejar hojas de cálculo, admitiendo varios formatos y operaciones complejas.

## Características

Las características principales de Univer Sheets incluyen:

- **Representación de hojas de cálculo**: admite la representación de Univer Sheets, incluido el cursor y el dibujo de selección.
- **Estilo de celda**: permite aplicar estilo a las celdas en la hoja de cálculo, incluida la fuente, el color, los bordes y la alineación.
- **Cálculo de fórmulas**: admite agregar y calcular fórmulas en la hoja de cálculo, cubriendo casi todas las funciones de Excel, incluidas funciones matemáticas, estadísticas, de texto y de fecha.
- **Formato de números**: permite el formato de números en la hoja de cálculo, incluidos formatos de moneda, porcentaje, fecha, etc.
- **Cuadrículas y Paneles congelados**: admite la visualización de líneas de cuadrícula y paneles congelados, lo que facilita a los usuarios ver y editar grandes conjuntos de datos.
- **Estilos predeterminados**: permite configurar estilos predeterminados para la hoja de cálculo, incluida la fuente, el tamaño, el color predeterminados, etc.
- **Sistema de complementos**: admite un sistema de complementos que permite complementos personalizados, como complementos de fórmulas, complementos de imágenes, complementos de gráficos, etc. Esta es también una de las capacidades arquitectónicas principales de Univer.

```typescript
univer.registerPlugin(UniverUIPlugin, {
  menu: {
    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})

Aquí, `'sheet.command.set-range-bold'` y `'sheet.command.set-range-italic'` son los ID de los elementos de menú correspondientes. Puede consultar la [Lista de ID de elementos del menú](#menu-item-id-list) a continuación.

import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'

univerAPI.createWorkbook({})

## Diseño de la barra de herramientas y `RibbonType`

Configurando el `ribbonType` propiedad en `IUniverSheetsCorePresetConfig` o `IUniverUIConfig`, puede configurar el diseño de la barra de herramientas.

`ribbonType` admite los siguientes cuatro modos:

- `classic`: modo clásico predeterminado, con grupos en la parte superior y la barra de herramientas dispuesta debajo, adecuado para los usuarios acostumbrado a los diseños tradicionales.
- `grid`: modo de cuadrícula, que conserva las pestañas en la parte superior y organiza debajo las herramientas de cada grupo en una cuadrícula de dos filas, adecuado para diseños de escritorio que necesitan mostrar más herramientas a la vez.
- `collapsed`: modo compacto, donde los grupos y la barra de herramientas se colocan en la misma fila, adecuado para escenarios con espacio de pantalla vertical limitado.
- `simple`: modo desagrupado, donde todas las herramientas se colocan en una lista plana, adecuado para usuarios familiarizados con las funciones de la barra de herramientas.

Cuando el Ribbon `grid` no cabe en el contenedor, los grupos completos pasan a **Más** con una disposición compacta. Al aumentar la anchura, vuelven a su lugar. El ajuste es automático; conserve el `gridLayout` del Ribbon principal. El menú mantiene los mismos comandos, estados deshabilitados y comprobaciones de permisos.

## Orden de menús y disposición en cuadrícula [#menu-order-and-grid-layout]

En `menu`, usa la clave de una pestaña del Ribbon, como `ribbon.insert`, la clave de un grupo, como `ribbon.start.format`, o el ID de un elemento.

`order` ordena de menor a mayor los elementos del mismo nivel: pestañas, grupos dentro de una pestaña y elementos dentro de un grupo o submenú. No mueve un elemento a otro grupo. También puede usar `RibbonPosition` y las enumeraciones de grupos exportadas por `@univerjs/ui`.

Elija su modo e incorpore estas opciones a la inicialización existente. Conserve los demás complementos y la configuración de idioma, tema y contenedor; no registre dos veces el mismo complemento.

const menu: MenuConfig = {

  'ribbon.start.format': { order: -1 },
  'sheet.command.set-range-font-family': {
    order: 0,
    gridLayout: { row: 1, column: 1, width: 160 },
  },
}
```

## Selección y arrastre [#selection-interaction]

### Navegación en los bordes de la hoja [#keyboard-navigation]

`allowArrowKeyWrapOnSheetBoundary` controla si las flechas pueden continuar en otra fila o columna al llegar al borde de la hoja. Su valor predeterminado es `true`; con `false`, se detienen en el borde. No afecta al recorrido con Intro/Tab dentro de una selección. En modo preset se configura bajo `sheets`; en modo plugin se pasa directamente a `UniverSheetsUIPlugin`.

`selectionAnimation: false` desactiva la animación al hacer clic en otra celda. La preferencia del sistema de reducir el movimiento tiene prioridad. `enableFillHandle: false` oculta el controlador de relleno. Los comandos y las API Facade de relleno siguen disponibles. `warnBeforeDragOverwrite: false` omite la confirmación de sobrescritura al arrastrar. La validación, deshacer y rehacer siguen activos. Las tres opciones valen `true` de forma predeterminada. Configúralas en `sheets` de `UniverSheetsCorePreset` o directamente en `UniverSheetsUIPlugin`.

## Actualizar los menús con la API Facade [#menu-facade]

### Actualizaciones en tiempo de ejecución

La Facade pública combina los cambios y actualiza la interfaz inmediatamente. Las propiedades omitidas conservan su configuración anterior o los valores predeterminados del esquema. La configuración también se aplica a los menús registrados posteriormente. En modo de complemento, importe primero `@univerjs/ui/facade`.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'sheet.command.set-range-bold': {
    order: 0,
    gridLayout: { row: 2, column: 2 },
  },
  'sheet.command.set-range-italic': {
    gridLayout: { row: 2, column: 1 },
  },
})
```

`gridLayout` solo se aplica a `ribbonType: 'grid'`. Cada grupo tiene dos filas; `row` y `column` comienzan en 1. Las coordenadas explícitas determinan la posición, por lo que cambiar solo `order` no mueve un botón ya posicionado. Al intercambiar posiciones, actualice ambos botones para evitar solapamientos. Los campos opcionales son `rowSpan`, `columnSpan`, `showLabel`, `width` e `iconSize`; los tamaños se expresan en píxeles. Consulte [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout) para conocer las restricciones y los valores predeterminados.

### Posición de un menú personalizado

`createMenu()` y `createSubmenu()` también aceptan `order` y `gridLayout`. Para un submenú, estas opciones controlan su activador en el Ribbon, no el contenido del menú desplegable. Este ejemplo añade un botón en la tercera columna del grupo Historial:

```ts
univerAPI
  .createMenu({
    id: 'custom-action',
    title: 'Custom action',
    action: () => console.log('Custom action clicked'),
    order: 4,
    gridLayout: { row: 1, column: 3, showLabel: true, width: 96 },
  })
  .appendTo('ribbon.start.history')
```
