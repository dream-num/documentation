Las características principales de Univer Sheets incluyen un editor de hojas de cálculo, un motor de fórmulas, un motor de renderizado, un motor de formato de números, un sistema de diseño y una biblioteca de componentes de interfaz de usuario. Juntos, forman una poderosa plataforma para manejar hojas de cálculo, admitiendo varios formatos y operaciones complejas.

## Características

Las características principales de Univer Sheets incluyen:

- **Representación de hojas de cálculo**: admite la representación de Univer Sheets, incluido el cursor y el dibujo de selección.
- **Estilo de celda**: permite aplicar estilo a las celdas en la hoja de cálculo, incluida la fuente, el color, los bordes y la alineación.
- **Cálculo de fórmulas**: admite agregar y calcular fórmulas en la hoja de cálculo, cubriendo casi todas las funciones de Excel, incluidas funciones matemáticas, estadísticas, de texto y de fecha.
- **Formato de números**: permite el formato de números en la hoja de cálculo, incluidos formatos de moneda, porcentaje, fecha, etc.
- **Cuadrículas y Paneles congelados**: admite la visualización de líneas de cuadrícula y paneles congelados, lo que facilita a los usuarios ver y editar grandes conjuntos de datos.
- **Estilos predeterminados**: permite configurar estilos predeterminados para la hoja de cálculo, incluida la fuente, el tamaño, el color predeterminados, etc.
- **Sistema de complementos**: admite un sistema de complementos que permite complementos personalizados, como complementos de fórmulas, complementos de imágenes, complementos de gráficos, etc. Esta es también una de las capacidades arquitectónicas principales de Univer.

## Modo preestablecido

### Instalación

```package-install
npm install @univerjs/presets @univerjs/preset-sheets-core
```

### Uso

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(UniverPresetSheetsCoreEnUS),
  },
  presets: [UniverSheetsCorePreset()],
})

univerAPI.createWorkbook({})
```

### Preajustes y configuración

#### @univerjs/presets

Este ajuste preestablecido proporciona el método `createUniver` para crear una aplicación Univer y expone todos los métodos y objetos de **@univerjs/core** y **@univerjs/design**.

El El método `createUniver` acepta un objeto de configuración que incluye opciones de tema, idioma, ajustes preestablecidos, etc. Devuelve una instancia `Univer` `univer` y una instancia `FUniver` `univerAPI` para llamar a la API de Facade.

```typescript
interface CreateUniverParameter {
  // Univer instance theme, default is `defaultTheme`
  theme: IStyleSheet
  // Whether to use dark mode, default is false
  darkMode?: boolean
  // The locale of the Univer instance
  locale: LocaleType
  region?: LocaleType
  // The locale objects to use, with keys as locale types and values as corresponding locale objects
  locales: ILocales
  // The log level of the Univer instance
  logLevel?: LogLevel
  // The list of presets to use.
  presets: IPresets[]
  // The list of plugins to use.
  plugins: IPlugins[]
}
```

Referencia: [`createUniver`](https://docs.univer.ai/reference/methods/create-univer)

#### @univerjs/preset-sheets-core

Este ajuste preestablecido es el ajuste preestablecido principal de Univer Sheets, que incluye las funciones principales necesarias para la edición de documentos, motor de fórmulas, motor de renderizado, etc.

```typescript
interface IUniverSheetsCorePresetConfig {
  // Container element, can be a string or a DOM element
  container?: string | HTMLElement
  // Whether to show the header
  header?: boolean
  // Whether to show the header toolbar
  toolbar?: boolean
  // The type of the header toolbar. 'classic': default classic mode; 'collapsed': compact mode; 'simple': ungrouped mode
  ribbonType?: RibbonType
  // Whether to show the footer
  footer?:
    | false
    | {
        // Sheet bar is the sub-sheet manager, including adding/switching/deleting sub-sheets.
        sheetBar?: boolean
        // Statistic bar includes statistics of the current selection, such as count, sum, average, etc.
        statisticBar?: boolean
        // The bottom menu includes options like highlight, gridlines, etc.
        menus?: boolean
        // The zoom slider at the bottom.
        zoomSlider?: boolean
        /**
         * The config of the add sheet button in the sheet bar.
         */
        addSheetButtonConfig?: {
          /**
           * Whether to show the add sheet button in the sheet bar.
           * When `footer` or `footer.sheetBar` is false, this config will not work because the sheet bar will not be rendered.
           * @default true
           */
          show?: boolean
          /**
           * The default row count of the new sheet created by the add sheet button.
           * @default 1000
           */
          defaultRowCount?: number
          /**
           * The default column count of the new sheet created by the add sheet button.
           * @default 20
           */
          defaultColumnCount?: number
        }
      }
  // Whether to show the context menu
  contextMenu?: boolean
  // Whether to disable auto focus
  disableAutoFocus?: true
  // Dependency injection override configuration
  override?: DependencyOverride
  // Menu configuration
  menu?: MenuConfig

  sheets?: {
    // If both row style and column style are set, whether row style precedes column style
    isRowStylePrecedeColumnStyle?: boolean
    // Whether auto height applies to merged cells
    autoHeightForMergedCells?: boolean
    /**
     * Whether synchronize the frozen state to other users in real-time collaboration.
     * @default true
     */
    freezeSync?: boolean

    clipboardConfig?: {
      // Whether to show the paste options button after paste operation
      hidePasteOptions?: boolean
    }
    // The configuration for the scroll bar
    scrollConfig?: IScrollBarProps
    /**
     * Strategy for showing the protected range shadow.
     * - true or 'always': Show shadow for all protected ranges (default behavior)
     * - 'non-editable': Only show shadow for ranges that cannot be edited (Edit permission is false)
     * - 'non-viewable': Only show shadow for ranges that cannot be viewed (View permission is false)
     * - false or 'none': Never show shadow for protected ranges
     * @default true
     */
    protectedRangeShadow?: boolean | 'always' | 'non-editable' | 'non-viewable' | 'none'
    // Whether to disable the force string alert.
    disableForceStringAlert?: boolean
    // Whether to disable the force string mark.
    disableForceStringMark?: boolean
  }

  // ... More configuration options
}
```

La opción de configuración `menu` se puede usar para establecer simplemente la visualización o el estado oculto de ciertos elementos de menú específicos:

```typescript
UniverSheetsCorePreset({
  menu: {
    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

Aquí, `'sheet.command.set-range-bold'` y `'sheet.command.set-range-italic'` son los nombres de los comandos, que indican el menú correspondiente artículos. Puede consultar la [Lista de ID de elementos del menú](#menu-item-id-list) a continuación.

## Diseño de la barra de herramientas y `RibbonType`

Configurando el `ribbonType` propiedad en `IUniverSheetsCorePresetConfig` o `IUniverUIConfig`, puede configurar el diseño de la barra de herramientas.

`ribbonType` admite los siguientes tres modos:

- `classic`: modo clásico predeterminado, con grupos en la parte superior y la barra de herramientas dispuesta debajo, adecuado para los usuarios acostumbrado a los diseños tradicionales.
- `collapsed`: modo compacto, donde los grupos y la barra de herramientas se colocan en la misma fila, adecuado para escenarios con espacio de pantalla vertical limitado.
- `simple`: modo desagrupado, donde todas las herramientas se colocan en una lista plana, adecuado para usuarios familiarizados con las funciones de la barra de herramientas.
