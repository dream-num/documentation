El núcleo de las hojas Univer consiste en un editor de hojas de cálculo y los componentes que el editor requiere: el motor de fórmulas, el motor de renderización, el motor del número de formato, el sistema de diseño y la biblioteca de componentes UI. Juntos estas piezas soportan una amplia gama de formatos de hoja de cálculo y las operaciones complejas que implica un libro de trabajo real.

## Características

El conjunto de características principales cubre:

- **Rendición de hoja de cálculo**: Dibuja el contenido de la hoja, el cursor y la selección.
- **Estilismo celular**: Establece fuentes, colores, fronteras y alineación en las celdas.
- **Cálculo de fórmulas**: Agrega y calcula fórmulas, con soporte para casi todas las funciones de Excel, incluyendo funciones matemáticas, estadísticas, texto y fecha.
- **Formato de número**: Aplica la moneda, porcentaje, fecha y otros formatos de números a los valores.
- **Gridlines y sartenes congelados**: Muestra líneas de rejilla y paneles congelados, lo que hace que los conjuntos de datos grandes sean más fáciles de leer y editar.
- **Estilos predeterminados**: Establece la fuente predeterminada, tamaño, color y otros estilos para una hoja de cálculo.
- **Sistema de enchufe**: Permite la adición de plugins personalizados, como fórmula, imagen y plugins de gráficos. El sistema de plugins es también una de las capacidades arquitectónicas básicas de Univer.

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'

univerAPI.createWorkbook({})
```

## Diseño de la barra de herramientas y `RibbonType`

Establecer `ribbonType` en `IUniverSheetsCorePresetConfig` o `IUniverUIConfig` para elegir el diseño de la barra de herramientas.

Hay cuatro modos:

- `classic`: El diseño predeterminado. Los grupos ocupan la fila superior y la barra de herramientas se ejecuta debajo de ellos, coincidiendo con lo que los usuarios de diseños tradicionales esperan.
- `grid`: Mantiene las pestañas y arregla las herramientas de cada grupo debajo de ellas en una cuadrícula de dos hojas. Se adapta a los diseños de escritorio que necesitan más herramientas visibles a la vez.
- `collapsed`: Coloca los grupos y la barra de herramientas en la misma fila, que conserva el espacio vertical cuando es limitado.
- `simple`: Elimina la agrupación y coloca cada herramienta en una sola lista plana, para los usuarios que ya saben lo que hace cada botón.

Cuando un `grid` Ribbon tiene un ancho insuficiente, grupos enteros se mueven a **Más** y sus controles se cambian a un diseño compacto. Regresan cuando el contenedor se ensancha. Esto sigue el ancho disponible automáticamente, así que mantenga el `gridLayout` existente para la cinta principal. El menú de desbordamiento conserva los mismos comandos, estados deshabilitados y cheques de permiso.

## Orden de menús y disposición en cuadrícula [#menu-order-and-grid-layout]

Una clave en `menu` puede ser una pestaña de la cinta como `ribbon.insert`, un grupo como `ribbon.start.format`, o un ID del elemento del menú.

`order` clasifica a los hermanos de bajo a alto: pestañas dentro de la cinta, grupos dentro de una pestaña, y elementos dentro de un grupo o submenú. No mueve un elemento de menú en otro grupo. En lugar de las teclas de cadena, puede utilizar `RibbonPosition` y los enums de grupo exportados por `@univerjs/ui`.

Combina estas opciones en la inicialización existente para el modo actual. Mantenga los otros plugins, locale, tema y configuración de contenedores, y no registre el mismo plugin dos veces.

```ts
import type { MenuConfig } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.insert': { order: -1 },
  'ribbon.start.format': { order: -1 },
  'sheet.command.set-range-font-family': {
    order: 0,
    gridLayout: { row: 1, column: 1, width: 160 },
  },
}
```

## Selección y arrastre [#selection-interaction]

### Navegación en los bordes de la hoja [#keyboard-navigation]

`allowArrowKeyWrapOnSheetBoundary` determina si las teclas de flecha envuelven a la siguiente fila o columna en un borde de hoja de trabajo. Predetermina a `true`; establece a `false` para parar en el borde. Enter/Tab ciclismo dentro de un rango seleccionado no está afectado. En modo preestablecido, establecerlo bajo `sheets`; en modo plugin, pasar directamente a `UniverSheetsUIPlugin`.

`selectionAnimation: false` deshabilita la animación del esquema de selección cuando la selección se mueve entre las células; la preferencia de reducción del sistema tiene precedencia. `enableFillHandle: false` oculta el mango de relleno mientras llena los comandos y las API de Facade permanecen disponibles. `warnBeforeDragOverwrite: false` salta el aviso de confirmación antes de que un arrastre sobrescribe el contenido existente; mueva validación y deshacer/redo todavía se aplican. `true`. Pásalos debajo `sheets` dentro `UniverSheetsCorePreset`, o directamente a `UniverSheetsUIPlugin`.

## Actualizar los menús con la API Facade [#menu-facade]

### Actualizaciones en tiempo de ejecución

El público Facade fusiona los cambios y actualiza la interfaz de usuario de inmediato. Las propiedades que se omiten mantienen sus valores anteriores o los defectos del esquema, y los overrides también se aplican a los menús registrados más adelante. En modo plugin, importa `@univerjs/ui/facade` primero.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'sheet.command.set-range-bold': {
    order: 0,
    gridLayout: { row: 2, column: 2 },
  },
  'sheet.command.set-range-italic': {
    gridLayout: { row: 2, column: 1 },
  },
})
```

`gridLayout` sólo tiene un efecto `ribbonType: 'grid'`. Cada grupo tiene dos filas y `row` y `column` 1. Las coordenadas son explícitas, por lo que cambiar sólo `order` no mueve un botón que fue colocado explícitamente. Cuando se intercambian dos botones, ambos deben ser actualizados, o se superponen. Los campos opcionales son `rowSpan`, `columnSpan`, `showLabel`, `width`, y `iconSize`, con tamaños en píxeles. [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout) enumera las limitaciones y los defectos.

### Posición de un menú personalizado

`createMenu()` y `createSubmenu()` también aceptan `order` o `gridLayout`. En un submenú, estos campos posicionan el gatillo de la cinta en lugar de los contenidos del popup. El siguiente ejemplo añade un botón en la tercera columna del grupo Historial:

```ts
univerAPI
  .createMenu({
    id: 'custom-action',
    title: 'Custom action',
    action: () => console.log('Custom action clicked'),
    order: 4,
    gridLayout: { row: 1, column: 3, showLabel: true, width: 96 },
  })
  .appendTo('ribbon.start.history')
```
