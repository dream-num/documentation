Univer Sheets bietet professionelle Tabellenkalkulationsfunktionen, deren Konzepte so konzipiert sind, dass sie so konsistent wie möglich mit Microsoft Excel sind.

## Importieren

```typescript
import '@univerjs/sheets/facade'
import '@univerjs/sheets-ui/facade'
```

## Arbeitsmappe

Eine Arbeitsmappe enthält mehrere Arbeitsblätter und kann als Excel-Datei betrachtet werden.

Der `unitId` kann als eindeutige Kennung für die Arbeitsmappe verwendet werden.

### Erstellen Sie eine Arbeitsmappe

Die Methode [`univerAPI.createWorkbook(data, options)`](https://docs.univer.ai/reference/facade/univer#createworkbook) erstellt die und gibt sie zurück `FWorkbook`-Objekt.

Das [`IWorkbookData`](/guides/sheets/model/workbook-data) ist ein Objekt, das die Konfigurationsinformationen der Arbeitsmappe enthält.

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' })
console.log(fWorkbook)
```

Hinzufügen: Sie können die Arbeitsmappe nicht als aktive Arbeitsmappe festlegen, indem Sie folgende Optionen festlegen:

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' }, { makeCurrent: false })
console.log(fWorkbook)

// If you want to switch to this workbook after 3 seconds
setTimeout(() => {
  univerAPI.setCurrent(fWorkbook.getId())
}, 3000)
```

### Arbeitsmappendaten abrufen [#get-workbook-data]

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
console.log(snapshot)
```

### Entladen Arbeitsmappe

Wenn Sie eine `Workbook` nicht mehr benötigen, können Sie die Methode `disposeUnit` auf der API-Instanz aufrufen, um sie zu entladen.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook?.getId()
if (unitId) {
  univerAPI.disposeUnit(unitId)
}
```

<Callout type="warning">
Wenn die gesamte Seite, auf der die Univer-Instanz gehostet wird, zerstört oder die Route entladen wird, rufen Sie zur Bereinigung unbedingt die Methode `univer.dispose()` auf, anstatt sie zu verwenden `univerAPI.disposeUnit`.
Bitte beachten Sie außerdem, dass `univer` und `univerAPI` unterschiedliche Instanzen sind. Anweisungen zum Abrufen dieser Instanzen finden Sie unter [Installation & grundlegende Verwendung](/guides/sheets/getting-started/installation).
</Callout>

### Arbeitsmappen-ID abrufen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook?.getId()
```

## Arbeitsblatt

Arbeitsblätter speichern Tabellendaten, Arbeitsblätter gehören zur Arbeitsmappe.

Eine Arbeitsmappe kann mehrere Arbeitsblätter enthalten und die Namen von Arbeitsblättern in derselben Arbeitsmappe können nicht dupliziert werden.

Die `subUnitId` kann verwendet werden, um ein Blatt in einer Arbeitsmappe eindeutig zu identifizieren.

### Arbeitsblätter abrufen

Alle Blätter in einem Blatt abrufen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const sheets = fWorkbook.getSheets()
```

Aktives Arbeitsblatt abrufen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
```

### Arbeitsblattdaten abrufen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const sheetSnapshot = fWorksheet.getSheet().getSnapshot()
```

### Ein Arbeitsblatt erstellen [#create-worksheet]

Das folgende Beispiel zeigt, wie ein Arbeitsblatt mit der Methode [`FWorkbook.create`](https://docs.univer.ai/reference/facade/workbook#create) erstellt wird.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Create a worksheet named 'Sheet2' with 10 rows and 10 columns
const newSheet = fWorkbook.create('Sheet2', 10, 10)

// Create a new sheet named 'MyNewSheetWithData' with 10 rows and 10 columns and some data, and set it as the first sheet
const sheetData = {
  // ... Omit other properties
  cellData: {
    0: {
      0: {
        v: 'Hello Univer!',
      },
    },
  },
  // ... Omit other properties
}
const newSheetWithData = fWorkbook.create('MyNewSheetWithData', 10, 10, {
  index: 0,
  sheet: sheetData,
})
console.log(newSheetWithData)
```

### Arbeitsblatt entfernen

Arbeitsblatt durch Übergabe der Arbeitsblattinstanz oder der Arbeitsblatt-ID entfernen

```typescript
// Delete the second worksheet
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.deleteSheet(sheet)

// The code below deletes the specified worksheet by id
// fWorkbook.deleteSheet(sheet.getSheetId());
```

### Aktivieren Arbeitsblatt

Aktivieren Sie das Arbeitsblatt, indem Sie die Arbeitsblattinstanz oder die Arbeitsblatt-ID übergeben, oder verwenden Sie die Methode `FWorksheet.activate()`.

```typescript
// Activate the second worksheet
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.setActiveSheet(sheet)

// Activates the specified worksheet by id
// fWorkbook.setActiveSheet(sheet.getSheetId());

// Activate the worksheet using the FWorksheet.activate() method
// sheet.activate();
```

### Arbeitsblatt kopieren

```typescript
// The code below duplicates the given worksheet
const fWorkbook = univerAPI.getActiveWorkbook()
const activeSheet = fWorkbook.getActiveSheet()
const duplicatedSheet = fWorkbook.duplicateSheet(activeSheet)
console.log(duplicatedSheet)
```

### Arbeitsblatt-ID abrufen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet?.getSheetId()
```

### Zeilen- und Spaltenanzahl des Arbeitsblatts festlegen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
// Set row count to 100000
fWorksheet.setRowCount(100000)
// Set column count to 30
fWorksheet.setColumnCount(30)
```

### Arbeitsblatt aktualisieren

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.refreshCanvas()
```

### Arbeitsblatt-Zoom

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set zoom ratio to 200%
fWorksheet.zoom(2)
const zoomRatio = fWorksheet.getZoom()
```

### Zur Zelle scrollen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Scroll to cell D10
const fRange = fWorksheet.getRange('D10')
const row = fRange.getRow()
const column = fRange.getColumn()
fWorksheet.scrollToCell(row, column)

// Add scroll animation duration
fWorksheet.scrollToCell(row, column, 1000)

// Get scroll state
const scrollState = fWorksheet.getScrollState()
const { offsetX, offsetY, sheetViewStartColumn, sheetViewStartRow } = scrollState
console.log(scrollState) // sheetViewStartRow: 9, sheetViewStartColumn: 3, offsetX: 0, offsetY: 0
```
