Les fonctionnalités principales d'Univer Sheets comprennent un éditeur de feuilles de calcul, un moteur de formules, un moteur de rendu, un moteur de formatage des nombres, un système de design et une bibliothèque de composants d'interface. Ensemble, ces éléments forment une plateforme puissante pour manipuler des feuilles de calcul dans différents formats et effectuer des opérations complexes.

## Fonctionnalités

Les fonctionnalités principales d'Univer Sheets sont les suivantes :

- **Rendu des feuilles de calcul** : affiche les feuilles Univer Sheets, notamment le curseur et les sélections.
- **Mise en forme des cellules** : permet de définir la police, la couleur, les bordures et l'alignement des cellules.
- **Calcul des formules** : permet d'ajouter et de calculer des formules. La quasi-totalité des fonctions Excel sont prises en charge, notamment les fonctions mathématiques, statistiques, textuelles et de date.
- **Formatage des nombres** : permet de formater les nombres, notamment en devise, en pourcentage ou en date.
- **Quadrillage et volets figés** : affiche le quadrillage et permet de figer des volets afin de faciliter la consultation et la modification de grands jeux de données.
- **Styles par défaut** : permet de définir les styles par défaut de la feuille de calcul, notamment la police, la taille et la couleur.
- **Système de plugins** : permet d'utiliser des plugins personnalisés, par exemple pour les formules, les images ou les graphiques. Il s'agit également de l'une des fonctions essentielles de l'architecture d'Univer.

```package-install
npm install @univerjs/core @univerjs/design @univerjs/engine-render @univerjs/engine-formula @univerjs/ui @univerjs/docs @univerjs/docs-ui @univerjs/sheets @univerjs/sheets-ui @univerjs/sheets-formula @univerjs/sheets-formula-ui @univerjs/sheets-numfmt @univerjs/sheets-numfmt-ui
```

```typescript

    'sheet.command.set-range-bold': {
      hidden: true,

    'sheet.command.set-range-italic': {
      hidden: true,
```

Ici, `'sheet.command.set-range-bold'` et `'sheet.command.set-range-italic'` sont les identifiants des éléments de menu correspondants. Consultez la [liste des identifiants des éléments de menu](#menu-item-id-list) ci-dessous.

## Disposition de la barre d'outils et `RibbonType`

La propriété `ribbonType` de `IUniverSheetsCorePresetConfig` ou de `IUniverUIConfig` permet de définir la disposition de la barre d'outils.

`ribbonType` prend en charge les quatre modes suivants :

- `classic` : mode classique par défaut, avec les groupes en haut et la barre d'outils en dessous. Il convient aux utilisateurs habitués aux dispositions traditionnelles.
- `grid` : mode grille, qui conserve les onglets en haut et organise en dessous les outils de chaque groupe dans une grille à deux lignes. Il convient aux dispositions de bureau qui doivent afficher davantage d'outils à la fois.
- `collapsed` : mode compact dans lequel les groupes et la barre d'outils sont placés sur la même ligne. Il convient lorsque l'espace vertical à l'écran est limité.
- `simple` : mode sans groupes, dans lequel tous les outils figurent dans une liste à plat. Il convient aux utilisateurs qui connaissent déjà les fonctions de la barre d'outils.

Lorsque le Ribbon `grid` ne tient plus dans le conteneur, des groupes entiers passent dans **Plus**, avec une disposition compacte. Ils reviennent lorsque la largeur augmente. Ce comportement est automatique ; conservez le `gridLayout` du Ribbon principal. Les commandes, états désactivés et contrôles de permissions sont identiques dans ce menu.

## Ordre des menus et disposition en grille [#menu-order-and-grid-layout]

Dans `menu`, utilisez la clé d’un onglet du Ribbon comme `ribbon.insert`, la clé d’un groupe comme `ribbon.start.format` ou l’identifiant d’un élément de menu.

`order` trie les éléments de même niveau par ordre croissant : les onglets, les groupes dans un onglet et les éléments dans un groupe ou sous-menu. Il ne déplace pas un élément vers un autre groupe. Vous pouvez aussi utiliser `RibbonPosition` et les énumérations de groupes exportées par `@univerjs/ui`.

Choisissez votre mode et ajoutez ces options à votre initialisation existante. Conservez les autres plugins et les paramètres de langue, de thème et de conteneur ; ne réenregistrez pas le même plugin.

```ts
import type { MenuConfig } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.insert': { order: -1 },
  'ribbon.start.format': { order: -1 },
  'sheet.command.set-range-font-family': {
    order: 0,
    gridLayout: { row: 1, column: 1, width: 160 },
  },
}
```

## Sélection et déplacement [#selection-interaction]

### Navigation au bord de la feuille [#keyboard-navigation]

`allowArrowKeyWrapOnSheetBoundary` contrôle le passage à une autre ligne ou colonne lorsque les flèches atteignent le bord de la feuille. La valeur par défaut est `true` ; `false` arrête le déplacement au bord. Le parcours cyclique avec Entrée/Tab dans une sélection reste inchangé. Avec un preset, placez cette option dans `sheets` ; avec les plugins, passez-la directement à `UniverSheetsUIPlugin`.

`selectionAnimation: false` désactive l’animation de sélection lors d’un clic sur une autre cellule. Le réglage système de réduction des animations est prioritaire. `enableFillHandle: false` masque la poignée de recopie. Les commandes et API Facade de recopie restent disponibles. `warnBeforeDragOverwrite: false` supprime la confirmation d’écrasement pendant le glisser-déposer. La validation, l’annulation et le rétablissement restent actifs. Les options valent `true` par défaut. Configurez-les dans `sheets` de `UniverSheetsCorePreset` ou dans `UniverSheetsUIPlugin`.

## Mettre à jour les menus avec l’API Facade [#menu-facade]

### Mise à jour à l’exécution

La Facade publique fusionne les modifications et actualise immédiatement l’interface. Les propriétés omises conservent leurs valeurs précédentes ou les valeurs par défaut du schéma. La configuration s’applique aussi aux menus enregistrés ultérieurement. En mode plugin, importez d’abord `@univerjs/ui/facade`.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'sheet.command.set-range-bold': {
    order: 0,
    gridLayout: { row: 2, column: 2 },
  },
  'sheet.command.set-range-italic': {
    gridLayout: { row: 2, column: 1 },
  },
})
```

`gridLayout` ne s’applique qu’à `ribbonType: 'grid'`. Chaque groupe comporte deux lignes ; `row` et `column` commencent à 1. Les coordonnées explicites déterminent la position : modifier uniquement `order` ne déplace pas un bouton déjà positionné. Pour échanger deux boutons, modifiez les deux positions afin d’éviter les chevauchements. Les champs facultatifs sont `rowSpan`, `columnSpan`, `showLabel`, `width` et `iconSize` ; les tailles sont en pixels. Consultez [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout) pour les contraintes et valeurs par défaut.

### Positionner un menu personnalisé

`createMenu()` et `createSubmenu()` acceptent aussi `order` et `gridLayout`. Pour un sous-menu, ces options positionnent son déclencheur dans le Ribbon, sans modifier le contenu du menu déroulant. Cet exemple ajoute un bouton dans la troisième colonne du groupe Historique :

```ts
univerAPI
  .createMenu({
    id: 'custom-action',
    title: 'Custom action',
    action: () => console.log('Custom action clicked'),
    order: 4,
    gridLayout: { row: 1, column: 3, showLabel: true, width: 96 },
  })
  .appendTo('ribbon.start.history')
```
