## API de Facade

La referencia [Facade API](/reference/facade) contiene las definiciones de tipo completo.

### Fila

#### Insertar fila después de la posición dada

[`insertRowAfter(afterPosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowafter): Inserta una nueva fila después de la fila en la posición dada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row after the first row position
sheet.insertRowAfter(0)
```

#### Insertar fila antes de la posición dada

[`insertRowBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowbefore): Inserta una nueva fila antes de la fila en la posición dada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row before the first row position
sheet.insertRowBefore(0)
```

#### Inserta varias filas en la ubicación especificada

[`insertRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#insertrows): Inserta una o más filas en blanco consecutivas, comenzando en la posición dada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Shifts all rows down by three
sheet.insertRows(0, 3)
```

#### Insertar varias filas después de la posición dada

[`insertRowsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsafter): Inserta el número dado de filas después de la fila en la posición dada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows after the first row
sheet.insertRowsAfter(0, 5)
```

#### Inserta varias filas antes de la posición dada

[`insertRowsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsbefore): Inserta el número dado de filas antes de la fila en la posición dada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows before the first row
sheet.insertRowsBefore(0, 5)
```

#### Eliminar fila en la posición dada

[`deleteRow(rowPosition)`](https://docs.univer.ai/reference/facade/worksheet#deleterow): Elimina la fila en la posición dada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first row
sheet.deleteRow(0)
```

#### Elimina varias filas comenzando en la posición dada

[`deleteRows(rowPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deleterows): Elimina el número dado de filas, comenzando en la posición dada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first two rows
sheet.deleteRows(0, 2)
```

#### Eliminar varias filas por posiciones especificadas

[`deleteRowsByPoints(rowPoints)`](https://docs.univer.ai/reference/facade/worksheet#deleterowsbypoints): Elimina varias filas en una sola operación, dada una gran variedad de posiciones de fila. Las filas no necesitan ser consecutivas.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the 3rd row and rows 5 to 7
fWorksheet.deleteRowsByPoints([2, [4, 6]])
```

#### Mover filas a una nueva posición

[`moveRows(rowSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#moverows): Mueva las filas seleccionadas por `rowSpec` a `destinationIndex`. La gama no necesita alinearse con una sola fila o un grupo de filas: cada fila que abarca se selecciona.

```typescript
// The code below moves rows 1-2 to destination index 5
// This results in those rows becoming rows 3-4
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Selects row 1 and row 2 to be moved
const rowSpec = sheet.getRange('1:2')
sheet.moveRows(rowSpec, 5)
```

#### Ocultar filas en un rango determinado

[`hideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#hiderow): Oculta las filas en el rango dado.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This hides the first row
const range = sheet.getRange('1:1')
sheet.hideRow(range)
```

#### Ocultar varias filas consecutivas

[`hideRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#hiderows): Oculta una o más filas consecutivas que comienzan en el índice dado. El método utiliza un índice de 0 basado.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Hides the first three rows
sheet.hideRows(0, 3)
```

#### Mostrar fila en un rango determinado

[`unhideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#unhiderow): Unhides la fila en el rango dado.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This unhides the first row if it was previously hidden
const range = sheet.getRange('1:1')
sheet.unhideRow(range)
```

#### Mostrar varias filas consecutivas

[`showRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#showrows): Unhides una o más filas consecutivas que comienzan en el índice dado. El método utiliza un índice de 0 basado.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Unhides the first three rows
sheet.showRows(0, 3)
```

#### Establecer altura de fila

[`setRowHeight(rowPosition, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheight): Establece la altura de la fila dada en píxeles. Por defecto, una fila crece para adaptarse a su contenido celular. Para forzar una altura específica, utilice `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first row to a height of 200 pixels
sheet.setRowHeight(0, 200)
```

#### Establecer altura para varias filas

[`setRowHeights(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheights): Establece la altura de las filas dadas en píxeles. Por defecto, las filas crecen para adaptarse a su contenido celular. Para forzar una altura específica, utilice `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 200 pixels
sheet.setRowHeights(0, 3, 200)
```

#### Forzar ajuste de altura para varias filas

[`setRowHeightsForced(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheightsforced): Establece la altura de las filas dadas en píxeles. Por defecto, las filas crecen para adaptarse a su contenido celular. Con `setRowHeightsForced`, cada fila mantiene la altura asignada incluso cuando su contenido es más alto.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 5 pixels
sheet.setRowHeightsForced(0, 3, 5)
```

#### Cambio de tamaño de filas automático

[`autoResizeRows(startRow, numRows)`](https://docs.univer.ai/reference/facade/worksheet#autoresizerows): Establece la altura de las filas dadas para adaptarse a su contenido de texto.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set the first 3 rows to a height that fits their text.
sheet.autoResizeRows(0, 3)
```

#### Establecer fila personalizada properties

[`setRowCustom(custom)`](https://docs.univer.ai/reference/facade/worksheet#setrowcustom): Establece propiedades personalizadas en las filas dadas. Cada fila recibe un objeto `custom` que puede contener cualquier dato JSON para almacenar información adicional. Escribir `custom` sobrescribe los datos `custom` almacenados previamente. Para guardar los datos actuales `custom`, leer primero el objeto `custom`, fusionarlo en los nuevos datos, y luego escribirlo.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set custom properties for the first and third rows
sheet.setRowCustom({
  0: { color: 'red' },
  2: { size: 16 },
})
```

## Validación de dimensiones y tamaños cero [#dimension-validation]

Las alturas de fila y los anchos de columna deben ser números finitos y no negativos. Los comandos de dimensión rechazan cadenas numéricas, valores negativos, `NaN` y `Infinity`. Se permite cero para una fila o columna individual, mientras que `defaultRowHeight` y `defaultColumnWidth` deben ser estrictamente positivos. Cuando se crea una hoja, Univer normaliza las dimensiones inválidas en la instantánea.

Una fila o columna con el tamaño cero difiere de una oculta a través de su bandera de visibilidad. Desconectar una fila o columna de tamaño cero visible lo restaura al tamaño predeterminado de la hoja, y deshacer/redo cubre el cambio. Validar las dimensiones externas con los validadores públicos de abajo antes de pasarlos al editor.

```ts
import { isValidColumnDimensions, isValidRowDimensions, isValidSheetDimension } from '@univerjs/core'

isValidSheetDimension(24) // true
isValidSheetDimension(0, false) // false: default dimensions must be positive
isValidRowDimensions({ h: 24, ah: 32 }) // true
isValidColumnDimensions({ w: -1 }) // false
```
