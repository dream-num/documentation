## API de Facade

Las definiciones completas del tipo de API de Facade se pueden encontrar en [API de Facade](https://reference.univer.ai/en-US).

### Fila

#### Insertar fila después de la posición dada

[`insertRowAfter(afterPosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowafter): inserta una fila después de la fila especificada posición.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row after the first row position
sheet.insertRowAfter(0)
```

#### Insertar fila antes de la posición dada

[`insertRowBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowbefore): inserta una fila antes de la posición de fila especificada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row before the first row position
sheet.insertRowBefore(0)
```

#### Inserta varias filas en la ubicación especificada

[`insertRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#insertrows): inserta una o más filas en blanco consecutivas en una hoja comenzando en la ubicación especificada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Shifts all rows down by three
sheet.insertRows(0, 3)
```

#### Insertar varias filas después de la posición dada

[`insertRowsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsafter): inserta un número específico de filas después de la posición de la fila dada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows after the first row
sheet.insertRowsAfter(0, 5)
```

#### Inserta varias filas antes de la posición dada

[`insertRowsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsbefore): inserta un número específico de filas antes de la posición de fila dada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows before the first row
sheet.insertRowsBefore(0, 5)
```

#### Eliminar fila en la posición dada

[`deleteRow(rowPosition)`](https://docs.univer.ai/reference/facade/worksheet#deleterow): elimina la fila en la posición de fila especificada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first row
sheet.deleteRow(0)
```

#### Elimina varias filas comenzando en la posición dada

[`deleteRows(rowPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deleterows): elimina un número específico de filas comenzando en la posición de fila dada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first two rows
sheet.deleteRows(0, 2)
```

#### Eliminar varias filas por posiciones especificadas

[`deleteRowsByPoints(rowPoints)`](https://docs.univer.ai/reference/facade/worksheet#deleterowsbypoints): elimina varias filas (no necesariamente consecutivas) especificadas por una matriz de posiciones de fila.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the 3rd row and rows 5 to 7
fWorksheet.deleteRowsByPoints([2, [4, 6]])
```

#### Mover filas a una nueva posición

[`moveRows(rowSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#moverows): Mueve las filas seleccionadas por el rango dado a la posición indicada por `destinationIndex`. El `rowSpec` en sí no tiene que representar exactamente una fila completa o un grupo de filas para mover: selecciona todas las filas que abarca el rango.

```typescript
// The code below moves rows 1-2 to destination index 5
// This results in those rows becoming rows 3-4
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Selects row 1 and row 2 to be moved
const rowSpec = sheet.getRange('1:2')
sheet.moveRows(rowSpec, 5)
```

#### Ocultar filas en un rango determinado

[`hideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#hiderow): Oculta las filas en el rango especificado.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This hides the first row
const range = sheet.getRange('1:1')
sheet.hideRow(range)
```

#### Ocultar varias filas consecutivas

[`hideRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#hiderows): Oculta una o más filas consecutivas comenzando en el índice dado. Utilice el índice 0 para este método.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Hides the first three rows
sheet.hideRows(0, 3)
```

#### Mostrar fila en un rango determinado

[`unhideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#unhiderow): muestra la fila en el rango especificado.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This unhides the first row if it was previously hidden
const range = sheet.getRange('1:1')
sheet.unhideRow(range)
```

#### Mostrar varias filas consecutivas

[`showRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#showrows): muestra una o más filas consecutivas comenzando en el índice dado. Utilice el índice 0 para este método.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Unhides the first three rows
sheet.showRows(0, 3)
```

#### Establecer altura de fila

[`setRowHeight(rowPosition, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheight): establece la altura de la fila dada en píxeles. De forma predeterminada, las filas crecen para ajustarse al contenido de las celdas. Si desea forzar las filas a una altura específica, use `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first row to a height of 200 pixels
sheet.setRowHeight(0, 200)
```

#### Establecer altura para varias filas

[`setRowHeights(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheights): establece la altura de las filas dadas en píxeles. De forma predeterminada, las filas crecen para ajustarse al contenido de las celdas. Si desea forzar las filas a una altura específica, use `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 200 pixels
sheet.setRowHeights(0, 3, 200)
```

#### Forzar ajuste de altura para varias filas

[`setRowHeightsForced(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheightsforced): establece la altura de las filas dadas en píxeles. De forma predeterminada, las filas crecen para ajustarse al contenido de las celdas. Cuando usa `setRowHeightsForced`, las filas se fuerzan a la altura especificada incluso si el contenido de la celda es más alto que la altura de la fila.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 5 pixels
sheet.setRowHeightsForced(0, 3, 5)
```

#### Cambio de tamaño de filas automático

[`autoResizeRows(startRow, numRows)`](https://docs.univer.ai/reference/facade/worksheet#autoresizerows): cambia automáticamente el tamaño de la altura de las filas dadas para que se ajusten a su contenido de texto.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set the first 3 rows to a height that fits their text.
sheet.autoResizeRows(0, 3)
```

#### Establecer fila personalizada properties

[`setRowCustom(custom)`](https://docs.univer.ai/reference/facade/worksheet#setrowcustom): establezca propiedades personalizadas para filas determinadas, almacene un objeto `custom` en la fila, en el que puede colocar cualquier dato que se ajuste al formato JSON, para el almacenamiento personalizado de información adicional.
La actualización de los datos `custom` sobrescribirá los originales `custom` datos. Si necesita conservar los datos `custom` originales al actualizar los datos, obtenga los datos `custom` con anticipación y combínelos en datos nuevos antes de actualizar.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set custom properties for the first and third rows
sheet.setRowCustom({
  0: { color: 'red' },
  2: { size: 16 },
})
```

```typescript

```

#### Insertar columna antes de la posición dada

[`insertColumnBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumnbefore): inserta una columna antes de la posición de columna dada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a column in the first column position
sheet.insertColumnBefore(0)
```

#### Inserta varias columnas en la ubicación especificada

[`insertColumns(columnIndex, numColumns)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumns): inserta uno o más espacios en blanco consecutivos columnas en una hoja comenzando en la ubicación especificada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Shifts all columns by three
sheet.insertColumns(0, 3)
```

#### Insertar varias columnas después de la posición dada

[`insertColumnsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumnsafter): Inserta un número determinado de columnas después de la posición de la columna dada.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Inserts two columns after the first column
sheet.insertColumnsAfter(0, 2)
```

#### Inserta varias columnas antes de la posición dada

[`insertColumnsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertcolumnsbefore): Inserta una cantidad de columnas antes de la posición de la columna dada.

```typescript

sheet.insertColumnsBefore(0, 5)
```

```typescript
sheet.deleteColumns(0, 2)
```

#### Eliminar varias columnas por posiciones especificadas

[`deleteColumnsByPoints(columnPoints)`](https://docs.univer.ai/reference/facade/worksheet#deletecolumnsbypoints): elimina varias columnas (no necesariamente consecutivas) especificadas por una matriz de posiciones de columnas.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Columns start at "0" - this deletes the Column C and Columns E-G

```

#### Mover columnas a una nueva posición

[`moveColumns(columnSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#movecolumns): mueve las columnas seleccionadas por el rango dado a la posición indicada por el `destinationIndex`. El `columnSpec` en sí no tiene que representar exactamente una columna completa o un grupo de columnas para mover: selecciona todas las columnas que abarca el rango.

```typescript
// The code below moves rows A-B to destination index 5.
// This results in those columns becoming columns C-D.
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Selects column A and column B to be moved.
const columnSpec = sheet.getRange('A:B')
sheet.moveColumns(columnSpec, 5)
```

#### Ocultar columnas en un rango dado

[`hideColumn(column)`](https://docs.univer.ai/reference/facade/worksheet#hidecolumn): oculta la columna o columnas en el rango dado.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This hides the first column
const range = sheet.getRange('A:A')
sheet.hideColumn(range)
```

#### Ocultar varias columnas consecutivas columnas

[`hideColumns(columnIndex, numColumns)`](https://docs.univer.ai/reference/facade/worksheet#hidecolumns): Oculta una o más columnas consecutivas comenzando en el índice dado. Utilice el índice 0 para este método.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Hides the first three columns
sheet.hideColumns(0, 3)
```

#### Mostrar columna en el rango dado

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This unhides the first column if it was previously hidden

sheet.unhideColumn(range)
```

#### Mostrar varias columnas consecutivas

[`showColumns(columnIndex, numColumns)`](https://docs.univer.ai/reference/facade/worksheet#showcolumns): muestra una o más columnas consecutivas comenzando en el índice dado. Utilice el índice 0 para este método.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Unhides the first three columns
sheet.showColumns(0, 3)
```

```typescript

```

#### Establece ancho para múltiples columnas

[`setColumnWidths(startColumn, numColumns, width)`](https://docs.univer.ai/reference/facade/worksheet#setcolumnwidths): establece el ancho de la columna dada columnas en píxeles.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three columns to a width of 200 pixels
sheet.setColumnWidths(0, 3, 200)
```

#### Cambiar automáticamente el tamaño de las columnas

[`autoResizeColumns(startColumn, numColumns)`](https://docs.univer.ai/reference/facade/worksheet#autoresizecolumns): establece el ancho de las columnas dadas para que se ajusten automáticamente a su contenido de texto.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set the A:C columns to a width that fits their text.
```
