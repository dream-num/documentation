---
title: Nombres definidos
---

Nombres definidos es una función que permite a los usuarios asignar nombres personalizados a celdas, rangos de celdas o fórmulas. Al nombrar, los usuarios pueden hacer referencia a los datos de manera más intuitiva, simplificar las fórmulas y mejorar la legibilidad, el mantenimiento y el profesionalismo de la hoja de cálculo.

- **Mejora la legibilidad de las fórmulas**: el uso de nombres definidos puede hacer que las fórmulas sean más fáciles de entender. Por ejemplo, usar `Amount` en lugar de `A1 + A2 + A3` aclara el significado de la fórmula.
- **Simplifica las referencias complejas**: al hacer referencia a varias celdas o rangos complejos, los nombres definidos pueden simplificar estas referencias. Por ejemplo, puede definir `SalesData` para `A1:A10` y usar `SalesData` directamente en las fórmulas.
- **Facilita la gestión unificada de áreas de datos**: los nombres definidos pueden ayudar a los usuarios a gestionar mejor las áreas de datos. Cuando cambia el rango de datos, solo necesita actualizar la referencia del nombre definido, en lugar de modificar todas las fórmulas una por una.

## Uso

La entrada del Administrador de nombres se encuentra junto al cuadro de nombre en la esquina superior izquierda de la hoja, donde puede ver una lista de todos los nombres definidos y acceder al Administrador de nombres. A través del Administrador de nombres, los usuarios pueden ver, editar y eliminar nombres definidos.

![Nombres definidos](./defined-names/defined-names.png)

Al usar nombres definidos en fórmulas, simplemente puede ingresar el nombre directamente. Por ejemplo, si ha definido un nombre como `TotalSales`, puede usar `=TotalSales` en su fórmula para hacer referencia a ese rango.

## Notas

- **Singularidad de los nombres**: los nombres definidos deben ser únicos dentro de la misma hoja de cálculo y no pueden entrar en conflicto con otros nombres o funciones integradas.
- **Validez de los nombres**: los nombres definidos no pueden comenzar con un número, y no puede contener espacios ni caracteres especiales (como `!`, `@`, `#`, etc.). Si el nombre ingresado no cumple con las reglas, el sistema generará un error.
- **Actualización de nombres definidos**: si necesita modificar un nombre definido existente, puede volver a abrir el panel de edición "Definir nombre", seleccionar el nombre que desea modificar y editarlo. Después de realizar cambios, haga clic en "Aceptar" para guardar los cambios.
- **Eliminar nombres definidos**: si ya no necesita un nombre definido, puede seleccionarlo en el panel de edición "Definir nombre" y hacer clic en el botón "Eliminar" para eliminarlo. Después de la eliminación, las fórmulas relacionadas ya no serán válidas.
- **Uso entre hojas de trabajo**: los nombres definidos se pueden usar en diferentes hojas de trabajo dentro del mismo libro, pero debe prestar atención a la singularidad de los nombres. Si el mismo nombre se define en diferentes hojas de trabajo, puede generar confusión en las referencias.
- **Convenciones de nomenclatura**: se recomienda utilizar nombres significativos y evitar nombres demasiado cortos o vagos para facilitar la comprensión y el mantenimiento por parte de otros usuarios.
- **Fórmulas de depuración**: si encuentra problemas al usar nombres definidos, puede verificar si los nombres son correctos, si los rangos de referencia son precisos y si hay algún conflicto de nombres.
- **Ámbito de uso**: Los nombres definidos se pueden establecer a nivel de libro o de hoja de trabajo. Los nombres a nivel de libro de trabajo se pueden usar en todo el libro de trabajo, mientras que los nombres a nivel de hoja de trabajo solo se pueden usar dentro de hojas de trabajo específicas.

## API de Facade

Las definiciones completas del tipo de API de Facade se pueden encontrar en [API de Facade](https://reference.univer.ai/en-US).

### Crear nombres definidos

`FWorkbook.newDefinedNameBuilder()` crea un generador de nombres definidos y devuelve un `FDefinedNameBuilder` instancia. Puede utilizar el encadenamiento de métodos para generar un objeto `ISetDefinedNameMutationParam` para crear nombres definidos.

A continuación se muestran algunos métodos de miembros de [`FDefinedNameBuilder`](https://docs.univer.ai/reference/facade/defined-name):

| Método | Descripción |
| ---- | ---- |
| build | Crea el objeto de nombre definido |
| setName | Establece el nombre definido |
| setFormula | Establece la fórmula para el nombre definido |
| setRef | Establece el rango de referencia para el nombre definido |
| setComment | Establece el comentario para el nombre definido |
| setScopeToWorksheet | Establece el nombre definido para que esté disponible para una hoja de trabajo específica |
| setScopeToWorkbook | Establece el nombre definido para que esté disponible para todo el libro de trabajo |

El método [`FWorkbook.insertDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#insertdefinednamebuilder) se puede utilizar para crear un nombre definido que esté disponible para todo el libro.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedNameParam = fWorkbook.newDefinedNameBuilder()
  .setName('MyDefinedName')
  .setRef('Sheet1!$A$1')
  .setComment('A reference to A1 cell in Sheet1')
  .build()
fWorkbook.insertDefinedNameBuilder(definedNameParam)
```

El método [`FWorkbook.insertDefinedName()`](https://docs.univer.ai/reference/facade/workbook#insertdefinedname) se puede utilizar para crear rápidamente un nombre definido nombre.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.insertDefinedName('MyDefinedName', 'Sheet1!$A$1')
```

Otro métodos:
- [`FWorksheet.insertDefinedName()`](https://docs.univer.ai/reference/facade/worksheet#insertdefinedname): crea un nombre definido que está disponible para una hoja de trabajo específica.

### Obtener nombres definidos

El método [`FWorkbook.getDefinedName()`](https://docs.univer.ai/reference/facade/workbook#getdefinedname) se puede utilizar para obtener un nombre definido en el libro de trabajo, devolviendo un `FDefinedName` instancia.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

if (definedName) {
  definedName.setName('NewDefinedName')
}
```

Otros métodos:
- El método [`FWorkbook.getDefinedNames()`](https://docs.univer.ai/reference/facade/workbook#getdefinednames) se puede usar para obtener todos los nombres definidos en el libro de trabajo, devolviendo una matriz de `FDefinedName[]`.
- El método [`FWorksheet.getDefinedNames()`](https://docs.univer.ai/reference/facade/worksheet#getdefinednames) se puede usar para obtener todos los nombres definidos disponibles para este hoja de trabajo, que devuelve una matriz de `FDefinedName[]`.

### Modificar definido Nombres

El método [`FWorkbook.updateDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#updatedefinednamebuilder) se puede utilizar para modificar un nombre definido en el libro de trabajo.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Modify the defined name
if (definedName) {
  const newDefinedNameParam = definedName.toBuilder()
    .setName('NewDefinedName')
    .setRef('Sheet1!$A$2')
    .build()
  fWorkbook.updateDefinedNameBuilder(newDefinedNameParam)
}
```

La instancia [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name) también se puede utilizar para modificar directamente la configuración de nombre definido.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Modify the defined name
if (definedName) {
  definedName.setName('NewDefinedName')
  definedName.setRef('Sheet1!$A$2')
}
```

### Eliminar definido Nombres

El método [`FWorkbook.deleteDefinedName()`](https://docs.univer.ai/reference/facade/workbook#deletedefinedname) se puede utilizar para eliminar un nombre definido en el libro de trabajo.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.deleteDefinedName('MyDefinedName')
```

También puede eliminar directamente el nombre definido utilizando la instancia [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name) devuelta.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Delete the defined name
if (definedName) {
  definedName.delete()
}
```
