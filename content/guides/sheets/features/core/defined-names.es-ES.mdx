Un nombre definido asigna un nombre personalizado a una célula, un rango o una fórmula. Las fórmulas pueden referirse a ese nombre en lugar de la dirección cruda, lo que hace que sean más fáciles de leer y más fáciles de mantener.

- Fórmulas leen más cerca de lo que significan. `Amount` expresa la intención más claramente que `A1 + A2 + A3`.
- Varias células o un rango complejo pueden ser representados por un solo nombre. Define `SalesData` para `A1:A10` y utilice `SalesData` en fórmulas.
- Un área de datos se mantiene en un solo lugar. Cuando el rango cambia, actualice la referencia del nombre en lugar de cada fórmula que lo usa.

## Uso

La entrada del Administrador de Nombres está junto al cuadro de nombre en la esquina superior izquierda de la hoja. Al hacer clic en ella se muestra cada nombre definido y se abre el Administrador de Nombre, donde se puede ver, editar y eliminar nombres definidos.

En una fórmula, ingrese el nombre directamente. Si un rango se llama `TotalSales`, `=TotalSales` referencias que van.

## Notas

- Un nombre definido debe ser único dentro de la misma hoja de trabajo, y no puede entrar en conflicto con otro nombre o una función integrada.
- Un nombre no puede comenzar con un número, y no puede contener espacios o caracteres especiales como `!`, `@` o `#`. Si un nombre introducido viola estas reglas, el sistema informa de un error.
- Para cambiar un nombre, vuelva a abrir el panel de edición "Define Name", seleccione el nombre, edite y haga clic en "OK".
- Para eliminar un nombre, seleccione en el panel de edición "Define Name" y haga clic en "Delete". Fórmulas que referencian el nombre se vuelven inválidas.
- Los nombres se pueden compartir a través de diferentes hojas de trabajo en el mismo libro de trabajo, pero la regla de singularidad sigue siendo aplicable: definir el mismo nombre en diferentes hojas de cálculo puede hacer referencias ambiguas.
- Use nombres significativos y evite unos muy cortos o vagos, para que otras personas puedan entender y mantener la hoja.
- Si el uso de un nombre definido causa problemas, compruebe que el nombre es correcto, que el rango de referencia es exacto, y que ningún otro nombre conflictos con él.
- Se puede establecer un nombre en el nivel de los libros de trabajo o en la hoja de trabajo. Los nombres de nivel de los cuaderno están disponibles en todo el libro de trabajo, mientras que los nombres de los niveles de hoja de trabajo sólo están disponibles en la hoja informativa específica.

## API de Facade

Las definiciones completas del tipo Facade API están en el [Facade API](/reference/facade).

### Crear nombres definidos

`FWorkbook.newDefinedNameBuilder()` crea un constructor de nombres definido y devuelve un `FDefinedNameBuilder`. Encadena sus métodos para producir el objeto `ISetDefinedNameMutationParam` utilizado para crear el nombre.

Estos son algunos de los métodos miembros en [`FDefinedNameBuilder`](/reference/facade/defined-name-builder):

| Método | Descripción |
| ---- | ---- |
| build | Crea el objeto de nombre definido |
| setName | Establece el nombre definido |
| setFormula | Establece la fórmula para el nombre definido |
| setRef | Establece el rango de referencia para el nombre definido |
| setComment | Establece el comentario para el nombre definido |
| setScopeToWorksheet | Establece el nombre definido para que esté disponible para una hoja de trabajo específica |
| setScopeToWorkbook | Establece el nombre definido para que esté disponible para todo el libro de trabajo |

[`FWorkbook.insertDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#insertdefinednamebuilder) crea un nombre definido que está disponible para todo el libro de trabajo.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedNameParam = fWorkbook.newDefinedNameBuilder()
  .setName('MyDefinedName')
  .setRef('Sheet1!$A$1')
  .setComment('A reference to A1 cell in Sheet1')
  .build()
fWorkbook.insertDefinedNameBuilder(definedNameParam)
```

[`FWorkbook.insertDefinedName()`](https://docs.univer.ai/reference/facade/workbook#insertdefinedname) es un atajo para crear un nombre definido cuando el nombre y la referencia ya se conocen.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.insertDefinedName('MyDefinedName', 'Sheet1!$A$1')
```

Otro métodos:
- [`FWorksheet.insertDefinedName()`](https://docs.univer.ai/reference/facade/worksheet#insertdefinedname): crea un nombre definido que está disponible para una hoja de trabajo específica.

### Obtener nombres definidos

[`FWorkbook.getDefinedName()`](https://docs.univer.ai/reference/facade/workbook#getdefinedname) obtiene un nombre definido del libro de trabajo y devuelve un `FDefinedName`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

if (definedName) {
  definedName.setName('NewDefinedName')
}
```

Otros métodos:
- [`FWorkbook.getDefinedNames()`](https://docs.univer.ai/reference/facade/workbook#getdefinednames) devuelve cada nombre definido en el libro de trabajo como un array `FDefinedName[]`.
- [`FWorksheet.getDefinedNames()`](https://docs.univer.ai/reference/facade/worksheet#getdefinednames) devuelve todos los nombres definidos disponibles en esta hoja de trabajo como un array `FDefinedName[]`.

### Modificar nombres definidos

[`FWorkbook.updateDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#updatedefinednamebuilder) modifica un nombre definido en el libro de trabajo.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Modify the defined name
if (definedName) {
  const newDefinedNameParam = definedName.toBuilder()
    .setName('NewDefinedName')
    .setRef('Sheet1!$A$2')
    .build()
  fWorkbook.updateDefinedNameBuilder(newDefinedNameParam)
}
```

También puede cambiar la configuración directamente en la instancia [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name) devuelta.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Modify the defined name
if (definedName) {
  definedName.setName('NewDefinedName')
  definedName.setRef('Sheet1!$A$2')
}
```

### Eliminar nombres definidos

[`FWorkbook.deleteDefinedName()`](https://docs.univer.ai/reference/facade/workbook#deletedefinedname) elimina un nombre definido en el libro de trabajo.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.deleteDefinedName('MyDefinedName')
```

También puede eliminar el nombre a través de la instancia [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name) devuelta.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Delete the defined name
if (definedName) {
  definedName.delete()
}
```
