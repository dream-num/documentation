API Фасада, доступные в Univer, зависят от типа документа. Эта страница охватывает общие API, которые ведут себя одинаково в каждом типе документа.

## Импорт

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Основные понятия

### Команды

Большинство операций в Univer регистрируются в системе команд и проходят через неё.Поскольку каждая операция следует по одному и тому же пути, Univer может поддерживать отмену, переделку и совместную работу.

<Callout>Для обоснования дизайна см. [Система управления Univer](/blog/univer#command-system).</Callout>

### Команды

Почти каждая операция в Univer регистрируется в системе команд и запускается через нее. Централизация всех операций в одном месте - это то, что делает такие функции, как отмена, переделка и совместная работа, практичными.

<Callout>
  Команда может быть понята как уникальное «событие» внутри Univer. Для деталей дизайна см. [командная система](/blog/univer#command-system) .
</Callout>

### Прослушивание команд

Univer предоставляет две точки для прослушивания команды: до и после выполнения.

- `Event.BeforeCommandExecute` запускает пользовательскую логику перед выполнением команды.
- `Event.CommandExecuted` запускает пользовательскую логику после выполнения команды.

#### Прослушивание команд до выполнения

Передайте `Event.BeforeCommandExecute` в `FUniver.addEvent` для регистрации слушателя предварительной обработки. Код слушателя запускается до выполнения команды.

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, type, params }) => {
  // Custom logic executed before the command is executed
})
```

Чтобы предотвратить выполнение команды, установите `event.cancel` на `true` в обратном вызове.

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  event.cancel = true
})
```

#### Прослушивание команд после выполнения

Передайте `Event.CommandExecuted` в `FUniver.addEvent` для регистрации слушателя после обработки. Его код запускается после выполнения команды.

```typescript
const univerAPI = FUniver.newAPI(univer)

univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type, params }) => {
  // Custom logic executed after the command is executed
})
```

### Отмена прослушивания

Зарегистрировав команду, слушатель возвращает объект `IDisposable`. Позвоните `IDisposable.dispose`, чтобы уничтожить его.

Уничтожить слушателей, которые больше не используются. Выпустить их помогает сохранить программу стабильной.

```typescript
const univerAPI = FUniver.newAPI(univer)

// Register a listener
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, () => {
  // custom preprocessing logic before the command is executed
})

// Example: Destroy the listener after 1 second
setTimeout(() => {
  // Destroy the listener
  disposable.dispose()
}, 1000)
```

### Выполнение команд

Если вы уже знаете идентификатор команды и ее параметры, вы можете выполнить команду напрямую с помощью `FUniver.executeCommand`.

Например, следующий код устанавливает значение ячейки A1 с помощью команды `sheet.command.set-range-values`:

```typescript
const univerAPI = FUniver.newAPI(univer)

// Execute the command
univerAPI.executeCommand('sheet.command.set-range-values', {
  value: { v: 'Hello, Univer!' },
  range: { startRow: 0, startColumn: 0, endRow: 0, endColumn: 0 },
})
```

## API событий

Univer отправляет события для изменений, которые происходят внутри электронной таблицы, поэтому приложение может слушать их и отвечать.События делятся на группы, такие как операции буфера обмена, изменения выбора, взаимодействия ячеек, модификации листов и некоторые другие.

### Категории событий

Полный список событий: /reference/facade/events

1. **События буфера обмена**
   - `BeforeClipboardChange`: возгорается до изменения содержимого буфера обмена; установите `params.cancel = true` для блокировки изменения
   - `BeforeClipboardPaste`: возгорание перед вставкой контента; установите `params.cancel = true` для блокировки пасты
   - `ClipboardChanged`: возгорание после изменения содержимого буфера обмена, с новым контентом
   - `ClipboardPasted`: возгорание после вставки контента, с вставкой контента

2. **События выделения**
   - `SelectionChanged`: возгорание при изменении выбора, с новым диапазоном выбора
   - `SelectionMoveStart`: возгорается, когда селекция начинает двигаться, что позволяет использовать пользовательские эффекты отбора
   - `SelectionMoveEnd`: возгорается, когда выбор перестает двигаться, с финальным диапазоном
   - `SelectionMoving`: загорается, пока идет выбор, который поддерживает обновления пользовательского интерфейса в реальном времени
   - `DragOver`: огонь, когда содержимое перетаскивается через ячейки
   - `Drop`: пожары, когда тянущийся контент сбрасывается

3. **События ячеек**
   - `CellClicked`: возгорается при щелчке ячейки, с ее положением и содержанием
   - `CellHover`: возгорается, когда указатель парит над ячейкой, которая поддерживает подсказки
   - `CellPointerDown`: возгорается, когда указатель нажимается на ячейку; используется для запуска сопротивления или выбора
   - `CellPointerUp`: возгорается, когда указатель выпускается на ячейку; используется для завершения операции
   - `CellPointerMove`: возгорается, когда указатель перемещается по ячейкам

4. **События листа**
   - `SheetValueChanged`: возгорание при изменении значений листа, с изменением диапазона и новых значений
   - `SheetZoomChanged`: возгорается при изменении уровня зума, с новым соотношением зума
   - `SheetSkeletonChanged`: возгорается при изменении структуры листа, например, при вставке или удалении строк или столбцов.
   - `BeforeSheetEditStart`: загорается до начала редактирования ячейки; используется для контроля того, разрешено ли редактирование
   - `SheetEditStarted`: возгорается при начале редактирования ячеек; используется для пользовательского поведения редактора
   - `BeforeSheetEditEnd`: возгорается до окончания редактирования ячеек; используется для проверки содержимого
   - `SheetEditEnded`: возгорается, когда заканчивается редактирование ячеек, с отредактированным значением
   - `SheetEditChanging`: пожары во время редактирования ячеек; используется для валидации или форматирования в реальном времени
   - `Scroll`: огонь, когда лист прокручивается, с положением прокрутки
   - `CrosshairHighlightEnabledChanged`: пожары при включении или отключении перекрестного освещения

5. **События заголовков**
   - `RowHeaderClick`: возгорается при щелчке заголовка строки
   - `RowHeaderHover`: возгорание, когда указатель зависает над заголовком строки
   - `ColumnHeaderClick`: возгорается при щелчке заголовка колонки
   - `ColumnHeaderHover`: возгорание, когда указатель зависает над заголовком колонки

6. **События проверки данных**
   - `BeforeSheetDataValidationAdd`: возгорание перед добавлением правила проверки данных
   - `SheetDataValidationChanged`: Пожары при изменении правил проверки данных
   - `SheetDataValidatorStatusChanged`: возгорание при изменении статуса валидации данных

7. **События комментариев**
   - `BeforeCommentAdd`: возгорание перед добавлением комментария
   - `CommentAdded`: пожары после добавления комментария
   - `BeforeCommentUpdate`: возгорание перед обновлением комментария
   - `CommentUpdated`: пожары после обновления комментария
   - `BeforeCommentDeleted`: возгорание перед удалением комментария
   - `CommentDeleted`: возгорание после удаления комментария

8. **События обработки данных**
   - `SheetBeforeRangeSort`: пожары перед сортировкой
   - `SheetRangeSorted`: пожары после сортировки
   - `SheetBeforeRangeFilter`: пожары перед фильтрацией
   - `SheetRangeFiltered`: пожары после фильтрации
   - `BeforePivotTableAdd`: пожары до добавления стола поворотов
   - `PivotTableAdded`: пожары после добавления стола поворотов

### Использование событий

Позвоните `addEvent` на `univerAPI`, чтобы записать слушателя.

```typescript
univerAPI.addEvent(univerAPI.Event.EventName, (params) => {
  // Handle event parameters
})
```

#### Пример: отслеживание щелчков по ячейкам

```typescript
univerAPI.addEvent(univerAPI.Event.CellClicked, (params) => {
  const { worksheet, workbook, row, column } = params
  console.log(`Cell clicked at row ${row}, column ${column}`)
})
```

#### Пример: отслеживание операций с буфером обмена

```typescript
univerAPI.addEvent(univerAPI.Event.BeforeClipboardPaste, (params) => {
  const { text, html } = params
  // If you want to cancel the clipboard paste
  params.cancel = true
})
```

#### Пример: отслеживание изменения выделения

```typescript
univerAPI.addEvent(univerAPI.Event.SelectionChanged, (params) => {
  const { worksheet, workbook, selections } = params
  console.log('Selection changed:', selections)
})
```

### Отмена подписки на события

Слушатели события возвращают объект `IDisposable`; используйте его для удаления слушателя, когда он больше не нужен:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetValueChanged, (params) => {
  // Handle value changes
})

// Later, when you want to remove the listener:
disposable.dispose()
```

### Рекомендации

1. Избавьтесь от слушателей событий, которые больше не нужны; в противном случае утечка памяти.
2. Выберите событие, которое соответствует случаю использования, и предпочтите конкретное событие общему.
3. Держите обработчиков событий легкими, потому что они работают каждый раз, когда событие горит.
4. Чтобы заблокировать поведение по умолчанию, используйте `BeforeClipboardChange` или другое событие «до».

## Системный буфер обмена

`FUniver.copy()` и `FUniver.paste()` читают и пишут в системный буфер обмена.

<Callout>
  Копирование и вставка основаны на нативном API браузера. Если среда или ее разрешения не позволяют их, ни операция не работает. См. [Документация MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/writeText).
</Callout>

Следующий пример копирует и вставляет диапазон листов.

```typescript
// Prevent failure due to loss of focus when executing copy and paste code in the console,
// this example listens for the cell click event and executes the copy and paste code.
univerAPI.addEvent(univerAPI.Event.CellClicked, async (params) => {
  const fWorkbook = univerAPI.getActiveWorkbook()
  const fWorksheet = fWorkbook.getActiveSheet()

  // Copy the range A1:B2 to the clipboard
  const fRange = fWorksheet.getRange('A1:B2')
  fRange.activate().setValues([
    [1, 2],
    [3, 4],
  ])
  await univerAPI.copy()

  // Paste the copied content to the range C1:D2
  const fRange2 = fWorksheet.getRange('C1')
  fRange2.activate()
  await univerAPI.paste()

  // Check the pasted content
  console.log(fWorksheet.getRange('C1:D2').getValues()) // [[1, 2], [3, 4]]
})
```

Команды буфера обмена также могут выполняться через систему команд:

```typescript
import { CopyCommand, PasteCommand } from '@univerjs/ui'

// Copy
univerAPI.executeCommand(CopyCommand.id)
// Paste
univerAPI.executeCommand(PasteCommand.id)
```

## WebSocket

Facade API предоставляет `createSocket`. Учитывая URL, он открывает соединение WebSocket. Соединение выявляет события открытия, сообщения, закрытия и ошибки; сообщения отправляются с помощью метода `send`, а соединение закрывается методом `close` .

В установке Presets `univerAPI.createSocket(url)` можно вызвать напрямую.В частичную установку установить пакет [`@univerjs/network`](/reference/packages/plugins/univerjs/network) и зарегистрировать `UniverNetworkPlugin`.

```typescript
// ... Omits other plugin imports
import { UniverNetworkPlugin } from '@univerjs/network'

// ... Omits other facade imports
import '@univerjs/network/facade'

// ... Omits other plugin registrations
univer.registerPlugin(UniverNetworkPlugin)
```

Ниже приведен минимальный пример:

```typescript
// Replace the URL with the address of your own WebSocket service
const ws = univerAPI.createSocket('ws://47.100.177.253:8449/ws')

ws.open$.subscribe(() => {
  console.log('websocket opened')
  ws.send('hello')
})

ws.message$.subscribe((message) => {
  console.log('websocket message', message)
  const content = JSON.parse(message.data).content
  if (!content.includes('command')) {
    return
  }

  const commandInfo = JSON.parse(content)
  const { command, options } = commandInfo
  const { id, params } = command

  // Upon receiving collaborative data, it is locally saved
  univerAPI.executeCommand(id, params, options)
})

ws.close$.subscribe(() => {
  console.log('websocket closed')
})

ws.error$.subscribe((error) => {
  console.log('websocket error', error)
})

univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type, params, options }) => {
  // Only synchronize local mutations
  if (
    type !== univerAPI.Enum.CommandType.MUTATION ||
    options?.fromCollab ||
    options?.onlyLocal ||
    id === 'doc.mutation.rich-text-editing'
  ) {
    return
  }

  const commandInfo = JSON.stringify({ command: { id, type, params }, options: { fromCollab: true } })
  ws.send(commandInfo)
})
```

Univer должен начинаться с UnitID; сотрудничество не работает без него.

## Регистрация формулы

Пользовательские формулы могут быть зарегистрированы в текущем экземпляре Univer через Facade API.

Следующий пример вызывает [`registerFunction`](https://docs.univer.ai/reference/facade/formula#registerfunction) один раз, чтобы зарегистрировать алгоритм, имя и описание, которые формула `CUSTOMSUM` требует в плагин формулы. Затем формула доступна: ввод `=CUSTOMSUM` в любой пустой ячейке отображает подсказку.

```typescript
// Registered formulas support lambda functions
const formulaEngine = univerAPI.getFormula()
formulaEngine.registerFunction(
  'CUSTOMSUM',
  (...variants) => {
    let sum = 0
    const last = variants[variants.length - 1]

    if (last.isLambda && last.isLambda()) {
      variants.pop()
      const variantsList = variants.map((variant) => (Array.isArray(variant) ? variant[0][0] : variant))
      sum += last.executeCustom(...variantsList).getValue()
    }

    for (const variant of variants) {
      sum += Number(variant) || 0
    }

    return sum
  },
  'Adds its arguments',
)

// Use the function in a cell
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const cellA1 = fWorksheet.getRange('A1')
cellA1.setValue(1)
const cellA2 = fWorksheet.getRange('A2')
cellA2.setValue(2)
const cellA3 = fWorksheet.getRange('A3')
cellA3.setValue({ f: '=CUSTOMSUM(A1,A2,LAMBDA(x,y,x*y))' })

// A3 will display: 5
formulaEngine.calculationEnd((functionsExecutedState) => {
  if (functionsExecutedState === 3) {
    console.log(cellA3.getValue()) // 5
  }
})
```

Позвоните `dispose`, чтобы отменить регистрацию формулы.

```typescript
const functionDisposable = formulaEngine.registerFunction({
  // calculate
})

// Unregister the function
functionDisposable.dispose()
```

Чтобы обеспечить более полный интернационализированный контент и описания, установите поля `locales` и `description`:

Варианты описаны ниже.

- `func` удерживает алгоритм и отображение имени для формулы.Его ввод — это то, что пользователь вводит при использовании формулы, которая может быть числом, строкой, булевым значением или массивом.
- `description` задаёт описание пользовательской формулы.
- `locales` может содержать несколько языков; правила именования описаны в [Локальный тип](/reference/enums/locale-type). `functionList` может содержать переводы для более чем одной формулы. Для деталей поля см. [Как добавить формулы в двигатель](/blog/custom-formula#how-to-add-formulas-in-formula-engine) Раздел.

<Callout>
  Чтобы повторно использовать алгоритм, который уже предоставляет система формул, и расширить его, зарегистрируйте пользовательскую формулу через конфигурацию плагина. См. [Обычная формула](/blog/custom-formula) для прохождения.
</Callout>
