## Facade API

La définition complète des types de l’API Facade est disponible dans la [documentation de l’API Facade](https://reference.univer.ai/en-US).

### Lignes

#### Insérer une ligne après une position donnée

[`insertRowAfter(afterPosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowafter) : insère une ligne après la position de ligne indiquée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row after the first row position
sheet.insertRowAfter(0)
```
#### Insérer une ligne avant une position donnée

[`insertRowBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowbefore) : insère une ligne avant la position de ligne indiquée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row before the first row position
sheet.insertRowBefore(0)
```

#### Insérer plusieurs lignes à l’emplacement indiqué

[`insertRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#insertrows) : insère dans une feuille une ou plusieurs lignes vides consécutives à partir de l’emplacement indiqué.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Shifts all rows down by three
sheet.insertRows(0, 3)
```

#### Insérer plusieurs lignes après une position donnée

[`insertRowsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsafter) : insère le nombre de lignes indiqué après la position de ligne donnée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows after the first row
sheet.insertRowsAfter(0, 5)
```

#### Insérer plusieurs lignes avant une position donnée

[`insertRowsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsbefore) : insère le nombre de lignes indiqué avant la position de ligne donnée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows before the first row
sheet.insertRowsBefore(0, 5)
```

#### Supprimer la ligne à une position donnée

[`deleteRow(rowPosition)`](https://docs.univer.ai/reference/facade/worksheet#deleterow) : supprime la ligne située à la position indiquée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first row
sheet.deleteRow(0)
```

#### Supprimer plusieurs lignes à partir d’une position donnée

[`deleteRows(rowPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deleterows) : supprime le nombre de lignes indiqué à partir de la position de ligne donnée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first two rows
sheet.deleteRows(0, 2)
```

#### Supprimer plusieurs lignes aux positions indiquées

[`deleteRowsByPoints(rowPoints)`](https://docs.univer.ai/reference/facade/worksheet#deleterowsbypoints) : supprime plusieurs lignes, pas nécessairement consécutives, désignées par un tableau de positions.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the 3rd row and rows 5 to 7
fWorksheet.deleteRowsByPoints([2, [4, 6]])
```

#### Déplacer des lignes vers une nouvelle position

[`moveRows(rowSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#moverows) : déplace les lignes sélectionnées par la plage donnée vers la position indiquée par `destinationIndex`. `rowSpec` ne doit pas nécessairement représenter avec exactitude une ligne entière ou un groupe de lignes à déplacer : toutes les lignes traversées par la plage sont sélectionnées.

```typescript
// The code below moves rows 1-2 to destination index 5
// This results in those rows becoming rows 3-4
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Selects row 1 and row 2 to be moved
const rowSpec = sheet.getRange('1:2')
sheet.moveRows(rowSpec, 5)
```

#### Masquer les lignes d’une plage donnée

[`hideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#hiderow) : masque les lignes de la plage indiquée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This hides the first row
const range = sheet.getRange('1:1')
sheet.hideRow(range)
```

#### Masquer plusieurs lignes consécutives

[`hideRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#hiderows) : masque une ou plusieurs lignes consécutives à partir de l’indice donné. Cette méthode utilise des indices commençant à 0.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Hides the first three rows
sheet.hideRows(0, 3)
```

#### Réafficher une ligne dans une plage donnée

[`unhideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#unhiderow) : réaffiche la ligne de la plage indiquée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This unhides the first row if it was previously hidden
const range = sheet.getRange('1:1')
sheet.unhideRow(range)
```

#### Réafficher plusieurs lignes consécutives

[`showRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#showrows) : réaffiche une ou plusieurs lignes consécutives à partir de l’indice donné. Cette méthode utilise des indices commençant à 0.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Unhides the first three rows
sheet.showRows(0, 3)
```

#### Définir la hauteur d’une ligne

[`setRowHeight(rowPosition, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheight) : définit en pixels la hauteur de la ligne donnée. Par défaut, les lignes s’agrandissent pour s’adapter au contenu des cellules. Pour imposer une hauteur précise, utilisez `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first row to a height of 200 pixels
sheet.setRowHeight(0, 200)
```

#### Définir la hauteur de plusieurs lignes

[`setRowHeights(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheights) : définit en pixels la hauteur des lignes données. Par défaut, les lignes s’agrandissent pour s’adapter au contenu des cellules. Pour imposer une hauteur précise, utilisez `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 200 pixels
sheet.setRowHeights(0, 3, 200)
```

#### Imposer la hauteur de plusieurs lignes

[`setRowHeightsForced(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheightsforced) : définit en pixels la hauteur des lignes données. Par défaut, les lignes s’agrandissent pour s’adapter au contenu des cellules. Avec `setRowHeightsForced`, les lignes conservent la hauteur indiquée même si le contenu des cellules est plus haut.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 5 pixels
sheet.setRowHeightsForced(0, 3, 5)
```

#### Ajuster automatiquement la hauteur des lignes

[`autoResizeRows(startRow, numRows)`](https://docs.univer.ai/reference/facade/worksheet#autoresizerows) : ajuste automatiquement la hauteur des lignes données à leur contenu textuel.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set the first 3 rows to a height that fits their text.
sheet.autoResizeRows(0, 3)
```

#### Définir des propriétés personnalisées pour les lignes

[`setRowCustom(custom)`](https://docs.univer.ai/reference/facade/worksheet#setrowcustom) : définit des propriétés personnalisées pour les lignes données. Un objet `custom` est enregistré sur la ligne et peut contenir toute donnée conforme au format JSON afin de stocker des informations supplémentaires.
La mise à jour des données `custom` écrase les données `custom` d’origine. Pour conserver les données `custom` d’origine lors d’une mise à jour, récupérez au préalable les données `custom` et fusionnez-les avec les nouvelles données avant d’effectuer la mise à jour.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set custom properties for the first and third rows
sheet.setRowCustom({
  0: { color: 'red' },
  2: { size: 16 },
})
```
