## Facade API

La référence [Facade API](/reference/facade) contient les définitions complètes du type.

### Lignes

#### Insérer une ligne après une position donnée

[`insertRowAfter(afterPosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowafter): Insère une nouvelle ligne après la ligne à la position donnée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row after the first row position
sheet.insertRowAfter(0)
```

#### Insérer une ligne avant une position donnée

[`insertRowBefore(beforePosition)`](https://docs.univer.ai/reference/facade/worksheet#insertrowbefore): Insère une nouvelle ligne avant la ligne à la position donnée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts a row before the first row position
sheet.insertRowBefore(0)
```

#### Insérer plusieurs lignes à l’emplacement indiqué

[`insertRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#insertrows): Insère une ou plusieurs lignes blanches consécutives, à partir de la position donnée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Shifts all rows down by three
sheet.insertRows(0, 3)
```

#### Insérer plusieurs lignes après une position donnée

[`insertRowsAfter(afterPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsafter): Insère le nombre de lignes indiqué après la ligne à la position donnée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows after the first row
sheet.insertRowsAfter(0, 5)
```

#### Insérer plusieurs lignes avant une position donnée

[`insertRowsBefore(beforePosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#insertrowsbefore): Insère le nombre de lignes indiqué avant la ligne à la position donnée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This inserts five rows before the first row
sheet.insertRowsBefore(0, 5)
```

#### Supprimer la ligne à une position donnée

[`deleteRow(rowPosition)`](https://docs.univer.ai/reference/facade/worksheet#deleterow): Supprime la ligne à la position donnée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first row
sheet.deleteRow(0)
```

#### Supprimer plusieurs lignes à partir d’une position donnée

[`deleteRows(rowPosition, howMany)`](https://docs.univer.ai/reference/facade/worksheet#deleterows): Supprime le nombre de lignes indiqué, à partir de la position donnée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the first two rows
sheet.deleteRows(0, 2)
```

#### Supprimer plusieurs lignes aux positions indiquées

[`deleteRowsByPoints(rowPoints)`](https://docs.univer.ai/reference/facade/worksheet#deleterowsbypoints): Supprime plusieurs lignes en une seule opération, étant donné un tableau de positions de lignes. Les lignes n'ont pas besoin d'être consécutives.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Rows start at "0" - this deletes the 3rd row and rows 5 to 7
fWorksheet.deleteRowsByPoints([2, [4, 6]])
```

#### Déplacer des lignes vers une nouvelle position

[`moveRows(rowSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#moverows) : Déplace les lignes sélectionnées par `rowSpec` vers `destinationIndex`. La plage n'a pas besoin de s'aligner sur une seule ligne ou un groupe de lignes : chaque ligne qu'elle s'étend est sélectionnée.

```typescript
// The code below moves rows 1-2 to destination index 5
// This results in those rows becoming rows 3-4
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Selects row 1 and row 2 to be moved
const rowSpec = sheet.getRange('1:2')
sheet.moveRows(rowSpec, 5)
```

#### Masquer les lignes d’une plage donnée

[`hideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#hiderow): Cacher les lignes dans la plage donnée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This hides the first row
const range = sheet.getRange('1:1')
sheet.hideRow(range)
```

#### Masquer plusieurs lignes consécutives

[`hideRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#hiderows): Cacher une ou plusieurs lignes consécutives commençant à l'index donné. La méthode utilise un indice basé sur 0.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Hides the first three rows
sheet.hideRows(0, 3)
```

#### Réafficher une ligne dans une plage donnée

[`unhideRow(row)`](https://docs.univer.ai/reference/facade/worksheet#unhiderow): Débranche la ligne dans la plage donnée.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// This unhides the first row if it was previously hidden
const range = sheet.getRange('1:1')
sheet.unhideRow(range)
```

#### Réafficher plusieurs lignes consécutives

[`showRows(rowIndex, numRows)`](https://docs.univer.ai/reference/facade/worksheet#showrows): Débranche une ou plusieurs lignes consécutives commençant à l'index donné. La méthode utilise un indice basé sur 0.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Unhides the first three rows
sheet.showRows(0, 3)
```

#### Définir la hauteur d’une ligne

[`setRowHeight(rowPosition, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheight): Définit la hauteur de la ligne donnée en pixels. Par défaut, une ligne grandit pour s'adapter à son contenu cellulaire. Pour forcer une hauteur spécifique, utilisez `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first row to a height of 200 pixels
sheet.setRowHeight(0, 200)
```

#### Définir la hauteur de plusieurs lignes

[`setRowHeights(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheights): Définit la hauteur des lignes données en pixels. Par défaut, les lignes grandissent pour s'adapter à leur contenu cellulaire. Pour forcer une hauteur spécifique, utilisez `setRowHeightsForced(startRow, numRows, height)`.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 200 pixels
sheet.setRowHeights(0, 3, 200)
```

#### Imposer la hauteur de plusieurs lignes

[`setRowHeightsForced(startRow, numRows, height)`](https://docs.univer.ai/reference/facade/worksheet#setrowheightsforced): Définit la hauteur des lignes données en pixels. Par défaut, les lignes grandissent pour s'adapter à leur contenu cellulaire. Avec `setRowHeightsForced`, chaque ligne garde la hauteur attribuée même lorsque son contenu est plus grand.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Sets the first three rows to a height of 5 pixels
sheet.setRowHeightsForced(0, 3, 5)
```

#### Ajuster automatiquement la hauteur des lignes

[`autoResizeRows(startRow, numRows)`](https://docs.univer.ai/reference/facade/worksheet#autoresizerows): Définit la hauteur des lignes données pour correspondre à leur contenu texte.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set the first 3 rows to a height that fits their text.
sheet.autoResizeRows(0, 3)
```

#### Définir des propriétés personnalisées pour les lignes

[`setRowCustom(custom)`](https://docs.univer.ai/reference/facade/worksheet#setrowcustom): Définit les propriétés personnalisées sur les lignes données. Chaque ligne reçoit un objet `custom` qui peut contenir n'importe quelles données JSON pour stocker des informations supplémentaires. L'écriture `custom` écrase les données `custom` précédemment stockées. Pour conserver les données existantes `custom`, lisez d'abord l'objet `custom` et fusionnez-les dans les nouvelles données, puis écrivez-les.

```typescript
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set custom properties for the first and third rows
sheet.setRowCustom({
  0: { color: 'red' },
  2: { size: 16 },
})
```

#### Déplacer des colonnes vers une nouvelle position

[`moveColumns(columnSpec, destinationIndex)`](https://docs.univer.ai/reference/facade/worksheet#movecolumns) : Déplace les colonnes sélectionnées par `columnSpec` vers `destinationIndex`. La plage n'a pas besoin de s'aligner sur une seule colonne ou un groupe de colonnes : chaque colonne qu'elle s'étend est sélectionnée.

```typescript

```

## Validation des dimensions et tailles nulles [#dimension-validation]

Les hauteurs des lignes et les largeurs des colonnes doivent être finies, les nombres non négatifs. `NaN`et `Infinity`. Zéro est autorisé pour une ligne ou une colonne individuelle, pendant `defaultRowHeight` et `defaultColumnWidth` doit être strictement positif. Quand une feuille est créée, Univer normalise les dimensions non valides dans l'instantané.

Une ligne ou une colonne avec la taille zéro diffère d'une cachée à travers son drapeau de visibilité. Dénuder une ligne ou colonne visible de taille zéro la restaure à la taille par défaut de la feuille, et annuler/refaire couvre le changement. Valider les dimensions externes avec les validateurs publics ci-dessous avant de les transmettre à l'éditeur.

```ts
import { isValidColumnDimensions, isValidRowDimensions, isValidSheetDimension } from '@univerjs/core'

isValidSheetDimension(24) // true
isValidSheetDimension(0, false) // false: default dimensions must be positive
isValidRowDimensions({ h: 24, ah: 32 }) // true
isValidColumnDimensions({ w: -1 }) // false
```
