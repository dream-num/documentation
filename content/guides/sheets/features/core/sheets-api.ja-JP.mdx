Univerシートは、完全なスプレッドシートエンジンを提供し、そのコンセプトは、Microsoft Excelを適度に保つように設計されています。

## インポート

```typescript
import '@univerjs/sheets/facade'
import '@univerjs/sheets-ui/facade'
```

## ワークブック

ワークブックには複数のワークシートが含まれており、Excelファイルに対応しています。

`unitId`は、ワークブックのユニークな識別子です。

### ワークブックの作成

[`univerAPI.createWorkbook(data, options)`](https://docs.univer.ai/reference/facade/univer#createworkbook)はワークブックを作成し、`FWorkbook`オブジェクトを返します。

[`IWorkbookData`](/guides/sheets/model/workbook-data)は、ワークブックの構成について説明しています。

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' })
console.log(fWorkbook)
```

新しいワークブックがアクティブなワークブックになっていなければ、オプションオブジェクトを渡します。

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' }, { makeCurrent: false })
console.log(fWorkbook)

// 3 秒後にこのワークブックに切り替えたい場合
setTimeout(() => {
  univerAPI.setCurrent(fWorkbook.getId())
}, 3000)
```

### ワークブックデータの取得 [#get-workbook-data]

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
console.log(snapshot)
```

### ワークブックのアンロード

`Workbook`が不要になった場合は、APIインスタンスに`disposeUnit`を呼び出してアンロードします。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook?.getId()
if (unitId) {
  univerAPI.disposeUnit(unitId)
}
```

<Callout type="warning">
  Univerインスタンスをホストするページが破壊されるか、ルートがアンロードされると、`univer.dispose()`ではなく`univerAPI.disposeUnit`をクリーンアップする呼び出します。 `univer`と`univerAPI`は2つの異なるインスタンスです。 [インストールと基本的な使い方](/guides/sheets/getting-started/installation)がそれぞれ取得する方法については、ZXqXZを参照してください。
</Callout>

### ワークブック ID の取得

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook?.getId()
```

## ワークシート

ワークシートはテーブルデータを格納し、ワークシートはワークブックに所属しています。

ワークブックには複数のワークシートが含まれており、ワークシート名は1つのワークブック内で一意である必要があります。

`subUnitId`は、ワークブック内のワークシートを一意に識別します。

### ワークシートの取得

ワークブック内のすべてのワークシートを取得します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const sheets = fWorkbook.getSheets()
```

アクティブなワークシートを取得する:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
```

### ワークシートデータの取得

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const sheetSnapshot = fWorksheet.getSheet().getSnapshot()
```

### ワークシートの作成 [#create-worksheet]

以下の例では、[`FWorkbook.create`](https://docs.univer.ai/reference/facade/workbook#create)メソッドでワークシートを作成します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// 10 行 10 列の 'Sheet2' という名前のワークシートを作成
const newSheet = fWorkbook.create('Sheet2', 10, 10)

// 10 行 10 列の 'MyNewSheetWithData' という名前の新しいシートを作成し、いくつかのデータを含め、最初のシートとして設定します
const sheetData = {
  // ... その他のプロパティは省略
  cellData: {
    0: {
      0: {
        v: 'Hello Univer!',
      },
    },
  },
  // ... その他のプロパティは省略
}
const newSheetWithData = fWorkbook.create('MyNewSheetWithData', 10, 10, {
  index: 0,
  sheet: sheetData,
})
console.log(newSheetWithData)
```

### ワークシートの削除

ワークシートインスタンスまたはワークシート ID を渡すと、ワークシートを削除できます。

```typescript
// 2 番目のワークシートを削除
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.deleteSheet(sheet)

// 以下のコードは ID で指定されたワークシートを削除します
// fWorkbook.deleteSheet(sheet.getSheetId());
```

### ワークシートのアクティブ化

ワークシートをアクティブにするには、ワークシートインスタンスまたはワークシートIDを渡すか、`FWorksheet.activate()`メソッドを呼び出します。

```typescript
// 2 番目のワークシートをアクティブ化
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.setActiveSheet(sheet)

// ID で指定されたワークシートをアクティブ化
// fWorkbook.setActiveSheet(sheet.getSheetId());

// FWorksheet.activate() メソッドを使用してワークシートをアクティブ化
// sheet.activate();
```

### ワークシートの複製

```typescript
// 次のコードは、指定されたワークシートを複製します
const fWorkbook = univerAPI.getActiveWorkbook()
const activeSheet = fWorkbook.getActiveSheet()
const duplicatedSheet = fWorkbook.duplicateSheet(activeSheet)
console.log(duplicatedSheet)
```

### ワークシート ID の取得

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet?.getSheetId()
```

### シートタブの色 [#tab-color]

ワークシートタブを右クリックして、カラーメニューを開きます。 色を選択したり、カスタムカラーを削除したり、デフォルトの外観を復元したりします。 カラーピッカーは、ワークシートの現在の色を表示します。 Facade APIを介して、空の文字列を`setTabColor()`に渡して色をリセットします。 変更は、undoとredoをサポートしています。

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
sheet?.setTabColor('')
```

### ワークシートの行列数の設定

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
// 行数を 100000 に設定
fWorksheet.setRowCount(100000)
// 列数を 30 に設定
fWorksheet.setColumnCount(30)
```

### ワークシートの更新

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.refreshCanvas()
```

### ワークシートズーム

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// ズーム比率を 200% に設定
fWorksheet.zoom(2)
const zoomRatio = fWorksheet.getZoom()
```

### セルへのスクロール

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// セル D10 にスクロール
const fRange = fWorksheet.getRange('D10')
const row = fRange.getRow()
const column = fRange.getColumn()
fWorksheet.scrollToCell(row, column)

// スクロールアニメーションの継続時間を追加
fWorksheet.scrollToCell(row, column, 1000)

// スクロール状態を取得
const scrollState = fWorksheet.getScrollState()
const { offsetX, offsetY, sheetViewStartColumn, sheetViewStartRow } = scrollState
console.log(scrollState) // sheetViewStartRow: 9, sheetViewStartColumn: 3, offsetX: 0, offsetY: 0
```
