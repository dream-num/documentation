---
title: Einfrieren
---

[`IWorksheetData.freeze`](/guides/sheets/model/workbook-data) kann verwendet werden, um den Einfrierstatus eines Arbeitsblatts zu konfigurieren. Seine Schnittstellendefinition lautet wie folgt:

```typescript
interface IFreeze {
  /**
   * The number of frozen columns
   */
  xSplit: number
  /**
   * The number of frozen rows
   */
  ySplit: number
  /**
   * The starting row that can be scrolled (the starting row of the main view area)
   */
  startRow: number
  /**
   * The starting column that can be scrolled (the starting column of the main view area)
   */
  startColumn: number
}
```

Wenn ich beispielsweise Spalte B und Zeile 2 einfrieren möchte, kann ich es wie folgt konfigurieren:

```json
{
  "xSplit": 1, // Freeze 1 column, which is column B
  "ySplit": 1, // Freeze 1 row, which is row 2
  "startRow": 2, // The starting row that can be scrolled is row 3
  "startColumn": 2 // The starting column that can be scrolled is column C
}
```

## Fassaden-API

Die Klasse `FWorksheet` bietet mehrere Methoden zum Verwalten des Einfrierstatus von Zeilen und Spalten in einem Arbeitsblatt. Mit diesen Methoden können Sie eingefrorene Bereiche festlegen, abrufen und aufheben.

### Einfrieren festlegen

```typescript
const worksheet = univerAPI.getActiveWorkbook().getActiveSheet()
worksheet.setFreeze({
  xSplit: 1, // Freeze 1 column, which is column B
  ySplit: 1, // Freeze 1 row, which is row 2
  startRow: 2, // The starting row that can be scrolled is row 3
  startColumn: 2, // The starting column that can be scrolled is column C
})
console.log('The current freeze state:', worksheet.getFreeze())
```

### Eingefrorene Spalten festlegen

```typescript
const worksheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set freeze for columns A-B
worksheet.setFrozenColumns(2)
```

### Eingefrorene Zeilen festlegen

```typescript
const worksheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Set freeze for the first 3 rows
worksheet.setFrozenRows(3)
```

### Einfrierstatus abrufen

```typescript
const worksheet = univerAPI.getActiveWorkbook().getActiveSheet()

const freezeState = worksheet.getFreeze()
```

### Eingefrorene Spalten abrufen

```typescript
const worksheet = univerAPI.getActiveWorkbook().getActiveSheet()

const frozenColumns = worksheet.getFrozenColumns()
```

### Eingefrorene Zeilen abrufen

```typescript
const worksheet = univerAPI.getActiveWorkbook().getActiveSheet()

const frozenRows = worksheet.getFrozenRows()
```

### Einfrieren aufheben

```typescript
const worksheet = univerAPI.getActiveWorkbook().getActiveSheet()

// Cancel all freezes
worksheet.cancelFreeze()
```
