默认样式分为两级：
1. 工作表的默认样式
2. 列或行的默认样式

两种默认样式都可以通过 [`IWorksheetData`](/reference/types/worksheet-data) 接口或 Facade API 设置。

## 插件配置 [#plugin-configuration]

`UniverSheetsPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `isRowStylePrecedeColumnStyle` | `boolean` | `false` | 使行样式优先于列样式。 |
| `textLineGap` | `number` | `0` | 单元格文字的额外行距，单位为像素。 |

## 预设配置 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>sheets</ConfigKey> | `object` |  | 所选功能的配置项。 |
| <ConfigKey depth={1}>isRowStylePrecedeColumnStyle</ConfigKey> | `boolean` | `false` | 使行样式优先于列样式。 |
| <ConfigKey depth={1}>textLineGap</ConfigKey> | `number` | `0` | 单元格文字的额外行距，单位为像素。 |

## 行列样式优先级

默认情况下，列样式优先于行样式。在注册时设置 `isRowStylePrecedeColumnStyle` 可以反转这一顺序。

请根据接入方式选择对应的标签页，并将这些选项合并到现有的初始化配置中。其他插件、语言、主题和容器配置保持不变，不要重复注册同一个插件。

<Tabs items={['插件模式', '预设模式']}>
  <Tab>
    ```typescript
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, {
      isRowStylePrecedeColumnStyle: true,
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          sheets: {
            isRowStylePrecedeColumnStyle: true,
          },
        }),
      ],
    })
    ```
  </Tab>
</Tabs>

## 单元格文字行距 [#text-line-gap]

`textLineGap` 用于设置单元格文字的行距，单位为像素，富文本和单元格编辑器同样适用。该选项只能在初始化时设置，作用于该 Univer 实例中的所有工作簿。默认值为 `0`，取值必须是有限的非负数。

<TextLineGapDemo />

<Tabs items={['插件模式', '预设模式']}>
  <Tab>
    ```ts
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, { textLineGap: 6 })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [UniverSheetsCorePreset({ sheets: { textLineGap: 6 } })],
    })
    ```
  </Tab>
</Tabs>

增大行距不会改变已有的行高。需要额外空间时，应重新计算自动行高；固定行高的单元格可能裁剪文字。该选项是实例级配置，不是单个单元格的段落样式。

## 设置默认样式

工作表的默认样式有两种设置方式：

1. 通过 [`IWorksheetData`](/reference/types/worksheet-data) 接口

```typescript
interface IWorksheetData {
  // other
  /**
   * @property {Nullable<IStyleData>} [defaultStyle] - Default style data of Worksheet.
   */
  defaultStyle?: Nullable<IStyleData>
}

interface IRowData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}

interface IColumnData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}
```

2. 通过 Facade API

```typescript
const fworkbook = univerAPI.getActiveWorkbook()
const fworksheet = fworkbook.getActiveSheet()
const defaultStyle = {
  bg: {
    rgb: 'red',
  },
}
const defaultColumnStyle = {
  bg: {
    rgb: 'blue',
  },
}
const defaultRowStyle = {
  bg: {
    rgb: 'green',
  },
}

// 设置默认样式
fworksheet.setDefaultStyle(defaultStyle)
// 设置列 D 的默认样式
fworksheet.setColumnDefaultStyle(3, defaultColumnStyle)
// 重置列 D 的默认样式
fworksheet.setColumnDefaultStyle(3, undefined)

// 设置行默认样式
fworksheet.setRowDefaultStyle(1, defaultRowStyle)
```

## 缩小字体填充

当文字宽度超过单元格宽度时，可以使用 `FRange` 缩小字体。该设置作用于范围内的每个单元格；`getShrinkToFit()` 返回左上角单元格的状态。

```ts
const range = univerAPI.getActiveWorkbook().getActiveSheet().getRange('A1:C3')

range.setShrinkToFit(true)
const enabled = range.getShrinkToFit()
```

缩小字体填充与自动换行互斥：启用自动换行会禁用缩小字体填充，启用缩小字体填充会清除这些单元格原有的自动换行。
