Ядро Univer Sheets состоит из редактора электронных таблиц и компонентов, которые требуются редактору: движок формулы, движок рендеринга, движка форматирования чисел, системы проектирования и библиотеки компонентов пользовательского интерфейса.Вместе эти части поддерживают широкий спектр форматов электронных таблиц и сложные операции, которые включает в себя настоящая рабочая книга.

## Возможности

Основной набор функций охватывает:

- **Отображение электронных таблиц**: рисует содержимое листа, курсор и выбор.
- **Стиль ячейки**: устанавливает шрифты, цвета, границы и выравнивание на ячейках.
- **Расчет формулы**: Добавляет и вычисляет формулы с поддержкой почти каждой функции Excel, включая математические, статистические, текстовые и датированные функции.
- **Форматирование номеров**: Применяет валюту, процент, дату и другие форматы чисел к значениям.
- **Сетки и замороженные стекла**: показывает линии сетки и замороженные панели, что облегчает чтение и редактирование больших наборов данных.
- **Стили по умолчанию**: устанавливает шрифт по умолчанию, размер, цвет и другие стили для электронной таблицы.
- **Система плагинов**: позволяет добавлять пользовательские плагины, такие как плагины формул, изображений и диаграмм. Система плагинов также является одной из основных архитектурных возможностей Univer.

### Настройка плагинов [#plugin-configuration]

#### @univerjs/core

Этот пакет представляет собой базовую библиотеку Univer. Он создает экземпляры Univer и управляет базовыми функциями, такими как темы и локализации.

| --- | --- | --- | --- |
| <ConfigKey depth={0}>theme</ConfigKey> | `Theme` | `defaultTheme` | Тема редактора. |
| <ConfigKey depth={1}>[palette]</ConfigKey> | `object` |  |  |
| <ConfigKey depth={2}>[shade]</ConfigKey> | `string` |  | Палитра с ключами по имени цвета и оттенку. Используйте `defaultTheme` как шаблон. |

Используйте `menu` для контроля видимости определенных пунктов меню:

```typescript
univer.registerPlugin(UniverUIPlugin, {
  menu: {
    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

Оба ключа, `'sheet.command.set-range-bold'` и `'sheet.command.set-range-italic'`, являются идентификаторами пунктов меню; [Меню Пункт ID Список](#menu-item-id-list) ниже содержит полный список.

## Макет панели инструментов и `RibbonType`

Установите `ribbonType` в `IUniverSheetsCorePresetConfig` или `IUniverUIConfig`, чтобы выбрать макет панели инструментов.

Существует четыре режима:

- `classic`: макет по умолчанию. Группы занимают верхний ряд, а панель инструментов работает ниже них, соответствуя ожиданиям пользователей традиционных макетов.
- `grid`: Сохраняет вкладки и расположил инструменты каждой группы под ними в двухрядной сетке. Он подходит для макетов рабочего стола, которым нужно больше инструментов, видимых одновременно.
- `collapsed`: Помещает группы и панель инструментов в один ряд, что сохраняет вертикальное пространство, когда оно ограничено.
- `simple`: удаляет группировку и помещает каждый инструмент в один плоский список для пользователей, которые уже знают, что делает каждая кнопка.

Когда лента `grid` имеет недостаточную ширину, целые группы переходят в **Больше** и их элементы управления переключаются на компактную компоновку. Они возвращаются, когда контейнер расширяется. Это автоматически следует за доступной шириной, поэтому сохраняйте существующую `gridLayout` для основной ленты. Меню переполнения сохраняет те же команды, состояния с отключением и проверки разрешений.

## Порядок меню и размещение в сетке [#menu-order-and-grid-layout]

Ключом в `menu` может быть вкладка Ribbon, такая как `ribbon.insert`, группа, такая как`ribbon.start.format` или идентификатор пункта меню.

`order` сортирует братьев и сестер от низких до высоких: вкладки в ленте, группы в вкладке и элементы в группе или подменю. Он не перемещает пункт меню в другую группу. Вместо клавиш строк можно использовать `RibbonPosition` и групповые перечни, экспортируемые `@univerjs/ui`.

Объединение этих опций в существующую инициализацию для текущего режима.Сохраняйте другие плагины, локализацию, тему и настройки контейнера и не регистрируйте один и тот же плагин дважды.

```ts
import type { MenuConfig } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.insert': { order: -1 },
  'ribbon.start.format': { order: -1 },
  'sheet.command.set-range-font-family': {
    order: 0,
    gridLayout: { row: 1, column: 1, width: 160 },
  },
}
```

## Выделение и перетаскивание [#selection-interaction]

### Навигация на границах листа [#keyboard-navigation]

`allowArrowKeyWrapOnSheetBoundary` определяет, заворачиваются ли клавиши со стрелками в следующий ряд или столбец на краю рабочей таблицы. Он по умолчанию `true`; установите его на `false`, чтобы остановиться на крае. Ввод/ввод циклов внутри выбранного диапазона не затрагивается. В заданном режиме установите его под `sheets` ; в режиме плагина передайте его непосредственно `UniverSheetsUIPlugin`.

`selectionAnimation: false` отключает анимацию схемы выбора при перемещении выбора между ячейками; предпочтение системы с пониженным движением имеет приоритет. `enableFillHandle: false` скрывает ручку заполнения, в то время как команды заполнения и API Facade остаются доступными. `warnBeforeDragOverwrite: false` пропускает подсказку подтверждения до перезаписи существующего контента; проверка перемещения и отмена / перезапись по-прежнему применяются. Все три опции по умолчанию для `true`. Передайте их под `sheets` в `UniverSheetsCorePreset` или непосредственно в `UniverSheetsUIPlugin` .

## Обновление меню через Facade API [#menu-facade]

### Обновление во время работы

Публичный Facade немедленно объединяет изменения и обновляет пользовательский интерфейс. Свойства, которые опущены, сохраняют свои предыдущие значения или схемы по умолчанию, а переопределения также применяются к меню, зарегистрированным позже. В режиме плагина сначала импортируйте `@univerjs/ui/facade`.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'sheet.command.set-range-bold': {
    order: 0,
    gridLayout: { row: 2, column: 2 },
  },
  'sheet.command.set-range-italic': {
    gridLayout: { row: 2, column: 1 },
  },
})
```

`gridLayout` имеет эффект только с `ribbonType: 'grid'`. Каждая группа имеет два ряда, а `row` и `column` начинаются с 1. Координаты являются явными, поэтому изменение только `order` не перемещает кнопку, которая была размещена явно. При замене двух кнопок оба должны быть обновлены, или они перекрываются. Дополнительными полями являются `rowSpan`, `columnSpan` , `showLabel` `width` а также `iconSize` с размерами в пикселях. [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout) перечисляет ограничения и по умолчанию.

### Размещение пользовательского меню

`createMenu()` и `createSubmenu()` также принимают `order`, `gridLayout`. На подменю эти поля позиционируют триггер ленты, а не содержимое всплывающего окна. Следующий пример добавляет кнопку в третьем столбце группы History:

```ts
univerAPI
  .createMenu({
    id: 'custom-action',
    title: 'Custom action',
    action: () => console.log('Custom action clicked'),
    order: 4,
    gridLayout: { row: 1, column: 3, showLabel: true, width: 96 },
  })
  .appendTo('ribbon.start.history')
```
