Основные возможности Univer Sheets включают редактор электронных таблиц, движок формул, движок рендеринга, движок форматирования чисел, дизайн-систему и библиотеку UI-компонентов. Вместе они образуют мощную платформу для работы с электронными таблицами, которая поддерживает различные форматы и сложные операции.

## Возможности

Основные возможности Univer Sheets:

- **Рендеринг электронных таблиц**: поддерживает рендеринг Univer Sheets, включая отрисовку курсора и выделения.
- **Стилизация ячеек**: позволяет настраивать шрифт, цвет, границы, выравнивание и другие параметры ячеек.
- **Вычисление формул**: позволяет добавлять и вычислять формулы и поддерживает почти все функции Excel, включая математические, статистические, текстовые функции и функции для работы с датами.
- **Форматирование чисел**: позволяет применять к числам денежный, процентный формат, формат даты и другие форматы.
- **Линии сетки и закреплённые области**: поддерживает отображение линий сетки и закрепление областей, упрощая просмотр и редактирование больших наборов данных.
- **Стили по умолчанию**: позволяет задать для электронной таблицы шрифт, размер, цвет и другие параметры по умолчанию.
- **Система плагинов**: позволяет создавать собственные плагины, например для формул, изображений и диаграмм. Это одна из ключевых архитектурных возможностей Univer.

## Режим предустановок

### Установка

```package-install
npm install @univerjs/presets @univerjs/preset-sheets-core
```

### Использование

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(UniverPresetSheetsCoreEnUS),
  },
  presets: [UniverSheetsCorePreset()],
})

univerAPI.createWorkbook({})
```

### Предустановки и настройка

#### @univerjs/presets

Эта предустановка предоставляет метод `createUniver` для создания приложения Univer, а также экспортирует все методы и объекты из **@univerjs/core** и **@univerjs/design**.

Метод `createUniver` принимает объект конфигурации с параметрами темы, языка, предустановок и другими настройками. Он возвращает экземпляр `Univer` в переменной `univer` и экземпляр `FUniver` в переменной `univerAPI`, через который можно вызывать Facade API.

```typescript
interface CreateUniverParameter {
  // Univer instance theme, default is `defaultTheme`
  theme: IStyleSheet
  // Whether to use dark mode, default is false
  darkMode?: boolean
  // The locale of the Univer instance
  locale: LocaleType
  region?: LocaleType
  // The locale objects to use, with keys as locale types and values as corresponding locale objects
  locales: ILocales
  // The log level of the Univer instance
  logLevel?: LogLevel
  // The list of presets to use.
  presets: IPresets[]
  // The list of plugins to use.
  plugins: IPlugins[]
}
```

Справка: [`createUniver`](https://docs.univer.ai/reference/methods/create-univer)

#### @univerjs/preset-sheets-core

Это основная предустановка Univer Sheets. В неё входят необходимые базовые возможности для редактирования документов, движок формул, движок рендеринга и другие компоненты.

```typescript
interface IUniverSheetsCorePresetConfig {
  // Container element, can be a string or a DOM element
  container?: string | HTMLElement
  // Whether to show the header
  header?: boolean
  // Whether to show the header toolbar
  toolbar?: boolean
  // The type of the header toolbar. 'classic': default classic mode; 'collapsed': compact mode; 'simple': ungrouped mode
  ribbonType?: RibbonType
  // Whether to show the footer
  footer?:
    | false
    | {
        // Sheet bar is the sub-sheet manager, including adding/switching/deleting sub-sheets.
        sheetBar?: boolean
        // Statistic bar includes statistics of the current selection, such as count, sum, average, etc.
        statisticBar?: boolean
        // The bottom menu includes options like highlight, gridlines, etc.
        menus?: boolean
        // The zoom slider at the bottom.
        zoomSlider?: boolean
        /**
         * The config of the add sheet button in the sheet bar.
         */
        addSheetButtonConfig?: {
          /**
           * Whether to show the add sheet button in the sheet bar.
           * When `footer` or `footer.sheetBar` is false, this config will not work because the sheet bar will not be rendered.
           * @default true
           */
          show?: boolean
          /**
           * The default row count of the new sheet created by the add sheet button.
           * @default 1000
           */
          defaultRowCount?: number
          /**
           * The default column count of the new sheet created by the add sheet button.
           * @default 20
           */
          defaultColumnCount?: number
        }
      }
  // Whether to show the context menu
  contextMenu?: boolean
  // Whether to disable auto focus
  disableAutoFocus?: true
  // Dependency injection override configuration
  override?: DependencyOverride
  // Menu configuration
  menu?: MenuConfig

  sheets?: {
    // If both row style and column style are set, whether row style precedes column style
    isRowStylePrecedeColumnStyle?: boolean
    // Whether auto height applies to merged cells
    autoHeightForMergedCells?: boolean
    /**
     * Whether synchronize the frozen state to other users in real-time collaboration.
     * @default true
     */
    freezeSync?: boolean

    clipboardConfig?: {
      // Whether to show the paste options button after paste operation
      hidePasteOptions?: boolean
    }
    // The configuration for the scroll bar
    scrollConfig?: IScrollBarProps
    /**
     * Strategy for showing the protected range shadow.
     * - true or 'always': Show shadow for all protected ranges (default behavior)
     * - 'non-editable': Only show shadow for ranges that cannot be edited (Edit permission is false)
     * - 'non-viewable': Only show shadow for ranges that cannot be viewed (View permission is false)
     * - false or 'none': Never show shadow for protected ranges
     * @default true
     */
    protectedRangeShadow?: boolean | 'always' | 'non-editable' | 'non-viewable' | 'none'
    // Whether to disable the force string alert.
    disableForceStringAlert?: boolean
    // Whether to disable the force string mark.
    disableForceStringMark?: boolean
  }

  // ... More configuration options
}
```

Параметр конфигурации `menu` позволяет задать видимость отдельных пунктов меню:

```typescript
UniverSheetsCorePreset({
  menu: {
    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

Здесь `'sheet.command.set-range-bold'` и `'sheet.command.set-range-italic'` — имена команд, соответствующих определённым пунктам меню. Их можно найти ниже в [списке идентификаторов пунктов меню](#menu-item-id-list).

## Макет панели инструментов и `RibbonType`

Свойство `ribbonType` в `IUniverSheetsCorePresetConfig` или `IUniverUIConfig` определяет макет панели инструментов.

`ribbonType` поддерживает три режима:

- `classic`: классический режим по умолчанию. Группы расположены сверху, а панель инструментов — под ними. Подходит пользователям, привыкшим к традиционному макету.
- `collapsed`: компактный режим, в котором группы и панель инструментов расположены в одной строке. Подходит для экранов с ограниченным пространством по вертикали.
- `simple`: режим без группировки, в котором все инструменты представлены одним плоским списком. Подходит пользователям, знакомым с функциями панели инструментов.
