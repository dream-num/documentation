Основные возможности Univer Sheets включают редактор электронных таблиц, движок формул, движок рендеринга, движок форматирования чисел, дизайн-систему и библиотеку UI-компонентов. Вместе они образуют мощную платформу для работы с электронными таблицами, которая поддерживает различные форматы и сложные операции.

## Возможности

Основные возможности Univer Sheets:

- **Рендеринг электронных таблиц**: поддерживает рендеринг Univer Sheets, включая отрисовку курсора и выделения.
- **Стилизация ячеек**: позволяет настраивать шрифт, цвет, границы, выравнивание и другие параметры ячеек.
- **Вычисление формул**: позволяет добавлять и вычислять формулы и поддерживает почти все функции Excel, включая математические, статистические, текстовые функции и функции для работы с датами.
- **Форматирование чисел**: позволяет применять к числам денежный, процентный формат, формат даты и другие форматы.
- **Линии сетки и закреплённые области**: поддерживает отображение линий сетки и закрепление областей, упрощая просмотр и редактирование больших наборов данных.
- **Стили по умолчанию**: позволяет задать для электронной таблицы шрифт, размер, цвет и другие параметры по умолчанию.
- **Система плагинов**: позволяет создавать собственные плагины, например для формул, изображений и диаграмм. Это одна из ключевых архитектурных возможностей Univer.

Этот плагин — основа пользовательского интерфейса Univer. Он предоставляет `UniverUIPlugin`.

`UniverUIPlugin` предоставляет параметры для базовой настройки макета.


Параметр конфигурации `menu` позволяет задать видимость отдельных пунктов меню:

```typescript
univer.registerPlugin(UniverSheetsUIPlugin, {

    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

Здесь `'sheet.command.set-range-bold'` и `'sheet.command.set-range-italic'` — идентификаторы соответствующих пунктов меню. Их можно найти ниже в [списке идентификаторов пунктов меню](#menu-item-id-list).

## Макет панели инструментов и `RibbonType`

Свойство `ribbonType` в `IUniverSheetsCorePresetConfig` или `IUniverUIConfig` определяет макет панели инструментов.

`ribbonType` поддерживает четыре режима:

- `classic`: классический режим по умолчанию. Группы расположены сверху, а панель инструментов — под ними. Подходит пользователям, привыкшим к традиционному макету.
- `grid`: режим сетки, сохраняющий вкладки сверху и располагающий инструменты каждой группы под ними в сетке из двух строк. Подходит для настольных макетов, где нужно одновременно видеть больше инструментов.
- `collapsed`: компактный режим, в котором группы и панель инструментов расположены в одной строке. Подходит для экранов с ограниченным пространством по вертикали.
- `simple`: режим без группировки, в котором все инструменты представлены одним плоским списком. Подходит пользователям, знакомым с функциями панели инструментов.

Если Ribbon `grid` не помещается в контейнер, целые группы переходят в меню «Ещё» с компактной раскладкой. При увеличении ширины группы возвращаются. Это происходит автоматически; сохраните прежний `gridLayout` основной панели. Команды, отключённые состояния и проверки прав в меню остаются теми же.

## Порядок меню и размещение в сетке [#menu-order-and-grid-layout]

При инициализации и при вызове [`univerAPI.updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) используется одна структура `menu`. Ключом может быть вкладка Ribbon (например, `ribbon.insert`), группа (например, `ribbon.start.format`) или ID пункта меню.

`order` сортирует элементы одного уровня по возрастанию: вкладки, группы внутри вкладки и пункты внутри группы или подменю. Он не переносит пункт в другую группу. Для ключей вкладок и групп можно использовать `RibbonPosition` и перечисления групп из `@univerjs/ui`.

### Начальная конфигурация

Выберите свой режим и добавьте эти параметры в существующую инициализацию. Сохраните остальные плагины, язык, тему и контейнер; не регистрируйте один плагин дважды.

```ts
import type { MenuConfig } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.insert': { order: -1 },
  'ribbon.start.format': { order: -1 },
  'sheet.command.set-range-font-family': {
    order: 0,
    gridLayout: { row: 1, column: 1, width: 160 },
  },
}
```

### Обновление во время работы

Публичный Facade объединяет изменения и сразу обновляет интерфейс. Неуказанные свойства сохраняют прежние значения или значения схемы по умолчанию. Настройки также применяются к меню, зарегистрированным позже. В режиме плагинов сначала импортируйте `@univerjs/ui/facade`.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'sheet.command.set-range-bold': {
    order: 0,
    gridLayout: { row: 2, column: 2 },
  },
  'sheet.command.set-range-italic': {
    gridLayout: { row: 2, column: 1 },
  },
})
```

`gridLayout` действует только при `ribbonType: 'grid'`. В каждой группе две строки; `row` и `column` начинаются с 1. Явные координаты определяют положение, поэтому изменение только `order` не перемещает кнопку с заданными координатами. При перестановке обновляйте обе кнопки, чтобы избежать перекрытия. Необязательные поля: `rowSpan`, `columnSpan`, `showLabel`, `width` и `iconSize`; размеры задаются в пикселях. Ограничения и значения по умолчанию описаны в [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout).

### Размещение пользовательского меню

`createMenu()` и `createSubmenu()` также принимают `order` и `gridLayout`. Для подменю они задают положение кнопки в Ribbon, а не расположение элементов всплывающего меню. Пример добавляет кнопку в третий столбец группы истории:

```ts
univerAPI
  .createMenu({
    id: 'custom-action',
    title: 'Custom action',
    action: () => console.log('Custom action clicked'),
    order: 4,
    gridLayout: { row: 1, column: 3, showLabel: true, width: 96 },
  })
  .appendTo('ribbon.start.history')
```
