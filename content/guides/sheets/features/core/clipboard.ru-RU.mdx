title: Копирование и вставка

<Callout type="warning" title="Совместимость Firefox Note">
  Firefox не поддерживает `clipboard.readText()`. См. [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText) для деталей. В этом случае Univer считывает буфер обмена из события пасты, поэтому вставка работает только с ярлыком клавиатуры.
</Callout>

Univer реализует копирование и вставку с помощью API Clipboard. Контент может быть скопирован из внешних приложений в Univer, из Univer во внешние приложения и между таблицами Univer.

<Callout type="warning" title="Требования к контексту безопасности">
  Современные политики безопасности браузера позволяют использовать API Clipboard только в безопасном контексте, таком как HTTPS.
</Callout>

Univer поддерживает следующие операции копирования и вставки:

- Копирование и вставка из внешних приложений в Univer
- Копирование Univer во внешние приложения
- Копирование и вставка между листами Univer

Селективная паста охватывает эти случаи:

- Только значения
- Только форматы
- Только ширина столбцов
- Содержимое без границ только
- Только формулы

В настольной Ribbon выпадение **паста** рядом с отменой и переделкой обеспечивает нормальную пасту, значения пасты, форматы пасты, ширину столбца пасты и вставку без границ. Его идентификатор меню `sheet.menu.paste`; запись контекст-меню **Специальный паст** использует `sheet.menu.paste-special`. Выпадение ленты скрыто при редактировании текста формы.

## Отключение копирования

**Контроль разрешений** может отключить копирование для всей книги или для конкретных рабочих листов.

Следующий код отключает копирование для текущей книги:

```typescript
const workbookPermission = univerAPI.getActiveWorkbook()?.getWorkbookPermission()
const WorkbookCopyPermission = univerAPI.Enum.WorkbookPermissionPoint.CopyContent

if (workbookPermission) {
  workbookPermission.setPoint(WorkbookCopyPermission, false)
}
```

Для получения дополнительной информации о разрешениях см. [Контроль разрешений](/guides/sheets/features/core/permission).
