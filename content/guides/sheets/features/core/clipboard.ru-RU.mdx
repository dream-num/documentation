---
title: Копирование и вставка
---

<Callout type="warning" title="Совместимость с Firefox">
  Firefox не поддерживает `clipboard.readText()`. Подробнее см. в [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText). В этом случае Univer может получить содержимое буфера обмена только из события вставки, поэтому вставка доступна лишь по сочетанию клавиш.
</Callout>

Для копирования и вставки Univer использует Clipboard API. Можно копировать и вставлять данные из внешних приложений в Univer, из Univer во внешние приложения и между таблицами Univer Sheets.

<Callout type="warning" title="Требование к безопасному контексту">
  Согласно современным политикам безопасности браузеров, Clipboard API можно использовать только в безопасном контексте, например по HTTPS.
</Callout>

Univer поддерживает следующие операции копирования и вставки:

- Копирование и вставка из внешних приложений в Univer
- Копирование из Univer во внешние приложения
- Копирование и вставка между таблицами Univer Sheets

Также доступна выборочная вставка:

- Только значения
- Только форматы
- Только ширина столбцов
- Содержимое без границ
- Только формулы

## Отключение копирования

С помощью **управления разрешениями** разработчики могут запретить пользователям копирование во всей книге или на отдельных листах.

Например, следующий код запрещает пользователям копировать данные из текущей книги:

```typescript
const workbookPermission = univerAPI.getActiveWorkbook()?.getWorkbookPermission()
const WorkbookCopyPermission = univerAPI.Enum.WorkbookPermissionPoint.CopyContent

if (workbookPermission) {
  workbookPermission.setPoint(WorkbookCopyPermission, false)
}
```

Подробнее см. в документации по [управлению разрешениями](/guides/sheets/features/core/permission).
