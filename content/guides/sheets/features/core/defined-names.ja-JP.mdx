定義された名前は、セル、範囲、または式にカスタム名を割り当てます。 式は、その名前を生のアドレスの代わりに参照することができます。これにより、簡単に読みやすく、維持が容易になります。

- `Amount`は、`A1 + A2 + A3`よりも、より明確に意図を表明しています。
- 複数のセルまたは複雑な範囲は、単一の名前で表すことができます。 `A1:A10` の `SalesData`を定義し、式で `SalesData` 使用してください。
- データ領域は1つの場所で維持されます。範囲が変更されると、使用するすべての数式ではなく、名前の参照を更新します。

## 使い方

Name Manager エントリは、シートの左上隅にある名前ボックスの横にあります。 クリックすると、すべての定義された名前を表示し、名前マネージャを開き、定義された名前を閲覧、編集、削除することができます。

式で、名前を直接入力します。範囲が`TotalSales`、`=TotalSales`の参照と名付けられます。

## 注意事項

- 定義された名前は、同じワークシート内で一意でなければならず、別の名前や組み込み関数と衝突することができません。
- 名前は数値で始まりません。`!`や`@`、`#`などのスペースや特殊文字は含まれません。入力された名前がこれらの規則に違反した場合、システムがエラーを報告します。
- 名前を変更するには、「Define Name」の編集パネルを再オープンし、名前を選択し、それを編集し、「OK」をクリックします。
- 名前を削除するには、「名前の定義」編集パネルでそれを選択し、「削除」をクリックします。 名前を参照した式は無効になります。
- 名前は同じワークブックで異なるワークシート間で共有することができますが、ユニークネスルールはまだ適用されます。異なるワークシート上の同じ名前を定義すると、参照があいまいになります。
- 意味のある名前を使用して、非常に短いものや漠然としたものを避けるため、他の人がシートを理解し、維持することができます。
- 定義された名前を使うと問題が起きた場合、名前が正しいことを確認し、参照範囲が正確であり、他の名前がそれに矛盾しないことを確認してください。
- ワークブックレベルまたはワークシートレベルに名前を設定できます。ワークブックレベルの名前はワークブック全体で利用できます。ワークシートレベルの名前は特定のワークシートのみで利用できます。

## Facade API

完全なFacade APIタイプ定義は[Facade API](/reference/facade)にあります。

### 定義名を作成する [#create-defined-names]

`FWorkbook.newDefinedNameBuilder()`は、定義された名前のビルダーを作成し、`FDefinedNameBuilder`を返します。そのメソッドをチェーンして、名前を作成するために使用される`ISetDefinedNameMutationParam`オブジェクトを生成します。

これらは、[`FDefinedNameBuilder`](/reference/facade/defined-name-builder)の会員方法の一部です。

| メソッド | 説明 |
| ---- | ---- |
| build | 定義名オブジェクトを構築 |
| setName | 定義名を設定 |
| setFormula | 数式を設定 |
| setRef | 参照範囲を設定 |
| setComment | コメントを設定 |
| setScopeToWorksheet | 特定ワークシート限定スコープに設定 |
| setScopeToWorkbook | ブック全体スコープに設定 |

[`FWorkbook.insertDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#insertdefinednamebuilder)は、ワークブック全体で利用可能な定義された名前を作成します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedNameParam = fWorkbook.newDefinedNameBuilder()
  .setName('MyDefinedName')
  .setRef('Sheet1!$A$1')
  .setComment('Sheet1 の A1 セル参照')
  .build()
fWorkbook.insertDefinedNameBuilder(definedNameParam)
```

[`FWorkbook.insertDefinedName()`](https://docs.univer.ai/reference/facade/workbook#insertdefinedname)は、名前と参照が既に知られているときに定義された名前を作成するためのショートカットです。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.insertDefinedName('MyDefinedName', 'Sheet1!$A$1')
```

その他:
- [`FWorksheet.insertDefinedName()`](https://docs.univer.ai/reference/facade/worksheet#insertdefinedname): 特定ワークシートのみ有効な定義名を作成。

### 定義名の取得

[`FWorkbook.getDefinedName()`](https://docs.univer.ai/reference/facade/workbook#getdefinedname)は、ワークブックから1つの定義された名前を取得し、`FDefinedName`を返します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

if (definedName) {
  definedName.setName('NewDefinedName')
}
```

その他:
- [`FWorkbook.getDefinedNames()`](https://docs.univer.ai/reference/facade/workbook#getdefinednames)は、ワークブック内の定義された名前を`FDefinedName[]`配列として返します。
- [`FWorksheet.getDefinedNames()`](https://docs.univer.ai/reference/facade/worksheet#getdefinednames)は、このワークシートに利用可能なすべての定義された名前を`FDefinedName[]`配列として返します。

### 定義名の変更

[`FWorkbook.updateDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#updatedefinednamebuilder)は、ワークブックに定義された名前を変更します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// 定義名を更新
if (definedName) {
  const newDefinedNameParam = definedName.toBuilder()
    .setName('NewDefinedName')
    .setRef('Sheet1!$A$2')
    .build()
  fWorkbook.updateDefinedNameBuilder(newDefinedNameParam)
}
```

また、返された[`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name)インスタンスに直接設定を変更することもできます。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// 直接更新
if (definedName) {
  definedName.setName('NewDefinedName')
  definedName.setRef('Sheet1!$A$2')
}
```

### 定義名の削除

[`FWorkbook.deleteDefinedName()`](https://docs.univer.ai/reference/facade/workbook#deletedefinedname) は、ワークブックの定義された名前を削除します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.deleteDefinedName('MyDefinedName')
```

また、返された[`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name)インスタンスを介して名前を削除することもできます。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// 削除
if (definedName) {
  definedName.delete()
}
```
