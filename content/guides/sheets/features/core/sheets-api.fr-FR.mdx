title: API d’Univer Sheets
---

Univer Sheets fournit un moteur de tableur complet, et ses concepts sont conçus pour rester aussi près de Microsoft Excel que raisonnable.

## Importation

```typescript
import '@univerjs/sheets/facade'
import '@univerjs/sheets-ui/facade'
```

## Classeur

Un cahier de travail contient une ou plusieurs feuilles de travail, et il correspond à un fichier Excel.

`unitId` est l'identificateur unique du cahier de cours.

### Créer un classeur

[`univerAPI.createWorkbook(data, options)`](https://docs.univer.ai/reference/facade/univer#createworkbook) crée un cahier de travail et renvoie l'objet `FWorkbook`.

[`IWorkbookData`](/guides/sheets/model/workbook-data) décrit la configuration d'un cahier de cours.

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' })
console.log(fWorkbook)
```

Si le nouveau cahier de travail ne devrait pas devenir le cahier de travail actif, passez un objet options:

```typescript
const fWorkbook = univerAPI.createWorkbook({ id: 'Sheet1', name: 'Sheet1' }, { makeCurrent: false })
console.log(fWorkbook)

// If you want to switch to this workbook after 3 seconds
setTimeout(() => {
  univerAPI.setCurrent(fWorkbook.getId())
}, 3000)
```

### Obtenir les données du classeur [#get-workbook-data]

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
console.log(snapshot)
```

### Décharger un classeur

Lorsqu'un `Workbook` n'est plus nécessaire, appelez `disposeUnit` sur l'instance API pour le décharger.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook?.getId()
if (unitId) {
  univerAPI.disposeUnit(unitId)
}
```

<Callout type="warning">
  Lorsque la page qui héberge l'instance Univer est détruite ou que l'itinéraire est déchargé, appelez `univer.dispose()` pour nettoyer plutôt que `univerAPI.disposeUnit`. `univer` et `univerAPI` sont deux instances distinctes; voir [Installation et utilisation de base](/guides/sheets/getting-started/installation) comment obtenir chacune d'elles.
</Callout>

### Obtenir l’ID du classeur

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook?.getId()
```

## Feuille de calcul

Les feuilles de travail stockent les données de la table, et chaque feuille de travail appartient à un cahier de travail.

Un cahier de travail peut contenir plusieurs feuilles de travail, et les noms de feuilles de travail doivent être uniques dans un seul cahier de travail.

`subUnitId` identifie une feuille de travail unique dans un cahier.

### Obtenir les feuilles de calcul

Récupérer toutes les feuilles de travail du cahier :

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const sheets = fWorkbook.getSheets()
```

Récupérer la feuille de travail active :

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
```

### Obtenir les données d’une feuille de calcul

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const sheetSnapshot = fWorksheet.getSheet().getSnapshot()
```

### Créer une feuille de calcul [#create-worksheet]

L'exemple suivant crée des feuilles de travail avec la méthode [`FWorkbook.create`](https://docs.univer.ai/reference/facade/workbook#create).

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Create a worksheet named 'Sheet2' with 10 rows and 10 columns
const newSheet = fWorkbook.create('Sheet2', 10, 10)

// Create a new sheet named 'MyNewSheetWithData' with 10 rows and 10 columns and some data, and set it as the first sheet
const sheetData = {
  // ... Omit other properties
  cellData: {
    0: {
      0: {
        v: 'Hello Univer!',
      },
    },
  },
  // ... Omit other properties
}
const newSheetWithData = fWorkbook.create('MyNewSheetWithData', 10, 10, {
  index: 0,
  sheet: sheetData,
})
console.log(newSheetWithData)
```

### Supprimer une feuille de calcul

Passez une instance de feuille de travail ou un ID de feuille de calcul pour supprimer une feuille de travail.

```typescript
// Delete the second worksheet
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.deleteSheet(sheet)

// The code below deletes the specified worksheet by id
// fWorkbook.deleteSheet(sheet.getSheetId());
```

### Activer une feuille de calcul

Pour activer une feuille de travail, passez une instance de feuille de travail ou un ID de feuille de calcul, ou appelez la méthode `FWorksheet.activate()`.

```typescript
// Activate the second worksheet
const fWorkbook = univerAPI.getActiveWorkbook()
const sheet = fWorkbook.getSheets()[1]
fWorkbook.setActiveSheet(sheet)

// Activates the specified worksheet by id
// fWorkbook.setActiveSheet(sheet.getSheetId());

// Activate the worksheet using the FWorksheet.activate() method
// sheet.activate();
```

### Copier une feuille de calcul

```typescript
// The code below duplicates the given worksheet
const fWorkbook = univerAPI.getActiveWorkbook()
const activeSheet = fWorkbook.getActiveSheet()
const duplicatedSheet = fWorkbook.duplicateSheet(activeSheet)
console.log(duplicatedSheet)
```

### Obtenir l’ID de la feuille de calcul

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet?.getSheetId()
```

### Couleur de l’onglet de feuille [#tab-color]

Faites un clic droit sur un onglet de feuille de travail pour ouvrir son menu couleur. Sélectionnez une couleur, ou choisissez Réinitialiser la couleur pour supprimer la couleur personnalisée et restaurer l'apparence par défaut. Le sélectionneur de couleurs affiche la couleur actuelle de la feuille de travail. Par le biais de Facade API, passez une chaîne vide à `setTabColor()` pour réinitialiser la couleur; le changement prend en charge la désactivation et le redémarrage.

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
sheet?.setTabColor('')
```

### Définir le nombre de lignes et de colonnes

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
// Set row count to 100000
fWorksheet.setRowCount(100000)
// Set column count to 30
fWorksheet.setColumnCount(30)
```

### Actualiser une feuille de calcul

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.refreshCanvas()
```

### Zoom de la feuille de calcul

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set zoom ratio to 200%
fWorksheet.zoom(2)
const zoomRatio = fWorksheet.getZoom()
```

### Faire défiler jusqu’à une cellule

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Scroll to cell D10
const fRange = fWorksheet.getRange('D10')
const row = fRange.getRow()
const column = fRange.getColumn()
fWorksheet.scrollToCell(row, column)

// Add scroll animation duration
fWorksheet.scrollToCell(row, column, 1000)

// Get scroll state
const scrollState = fWorksheet.getScrollState()
const { offsetX, offsetY, sheetViewStartColumn, sheetViewStartRow } = scrollState
console.log(scrollState) // sheetViewStartRow: 9, sheetViewStartColumn: 3, offsetX: 0, offsetY: 0
```
