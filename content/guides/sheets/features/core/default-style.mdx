Default styles exist at two levels:
1. The default style of the worksheet
2. The default style of a column or row

You can set either one through the [`IWorksheetData`](/reference/types/worksheet-data) interface or the Facade API.

## Plugin configuration [#plugin-configuration]

`UniverSheetsPlugin`

| <span data-config-options="">Option</span> | Type | Default | What it does |
| --- | --- | --- | --- |
| `isRowStylePrecedeColumnStyle` | `boolean` | `false` | Makes row style take precedence over column style. |
| `textLineGap` | `number` | `0` | Extra line spacing inside cells, in pixels. |

## Preset configuration [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Option</span> | Type | Default | What it does |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>sheets</ConfigKey> | `object` |  | Configuration for the selected feature. |
| <ConfigKey depth={1}>isRowStylePrecedeColumnStyle</ConfigKey> | `boolean` | `false` | Makes row style take precedence over column style. |
| <ConfigKey depth={1}>textLineGap</ConfigKey> | `number` | `0` | Extra line spacing inside cells, in pixels. |

## Row and column style priority

By default, column style takes precedence over row style. Set `isRowStylePrecedeColumnStyle` during registration to reverse this order.

Select the tab that matches your Univer setup, and merge these options into the existing initialization. Keep the other plugins, locale, theme, and container settings unchanged, and do not register the same plugin twice.

<Tabs items={['Plugin Mode', 'Preset Mode']}>
  <Tab>
    ```typescript
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, {
      isRowStylePrecedeColumnStyle: true,
    })
    ```
  </Tab>
  <Tab>
    ```typescript

    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          sheets: {
            isRowStylePrecedeColumnStyle: true,
          },
        }),
      ],
    })
    ```
  </Tab>
</Tabs>

## Cell text line spacing [#text-line-gap]

`textLineGap` adds extra space in pixels between lines of cell text, including rich text and cell editors. Set it during initialization; it applies to every workbook in the Univer instance. The default is `0`, and the value must be finite and non-negative.

<TextLineGapDemo />

<Tabs items={['Plugin Mode', 'Preset Mode']}>
  <Tab>
    ```ts
    import { UniverSheetsPlugin } from '@univerjs/sheets'

    univer.registerPlugin(UniverSheetsPlugin, { textLineGap: 6 })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [UniverSheetsCorePreset({ sheets: { textLineGap: 6 } })],
    })
    ```
  </Tab>
</Tabs>

A larger gap does not resize existing rows. Recalculate automatic row heights when the extra space is required; cells with a fixed height may clip their text. This is an instance-level setting, not a per-cell paragraph style.

## Set Default Style

You can set a worksheet's default style in two ways:

1. Through the [`IWorksheetData`](/reference/types/worksheet-data) interface

```typescript
interface IWorksheetData {
  // other
  /**
   * @property {Nullable<IStyleData>} [defaultStyle] - Default style data of Worksheet.
   */
  defaultStyle?: Nullable<IStyleData>
}

interface IRowData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}

interface IColumnData {
  // other
  /**
   * style data
   */
  s?: Nullable<IStyleData>
}
```

2. Through the Facade API

```typescript
const fworkbook = univerAPI.getActiveWorkbook()
const fworksheet = fworkbook.getActiveSheet()
const defaultStyle = {
  bg: {
    rgb: 'red',
  },
}
const defaultColumnStyle = {
  bg: {
    rgb: 'blue',
  },
}
const defaultRowStyle = {
  bg: {
    rgb: 'green',
  },
}

// set default style
fworksheet.setDefaultStyle(defaultStyle)
// set column D default style
fworksheet.setColumnDefaultStyle(3, defaultColumnStyle)
// reset column D the default style
fworksheet.setColumnDefaultStyle(3, undefined)

// set row default style
fworksheet.setRowDefaultStyle(1, defaultRowStyle)
```

## Shrink text to fit

`FRange` can shrink text that is wider than its cell. The setting applies to every cell in the range, and `getShrinkToFit()` returns the state of the top-left cell.

```ts
const range = univerAPI.getActiveWorkbook().getActiveSheet().getRange('A1:C3')

range.setShrinkToFit(true)
const enabled = range.getShrinkToFit()
```

Shrink-to-fit and text wrapping are mutually exclusive. Enabling text wrapping disables shrink-to-fit, and enabling shrink-to-fit disables wrapping on any cells that currently wrap.
