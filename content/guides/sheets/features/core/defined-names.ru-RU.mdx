Определенное имя присваивает пользовательское имя ячейке, диапазону или формуле. Формулы могут затем ссылаться на это имя вместо необработанного адреса, что облегчает их чтение и упрощает обслуживание.

- Формулы читаются ближе к тому, что они означают. `Amount` выражает намерение более четко, чем `A1 + A2 + A3`.
- Несколько ячеек или комплексный диапазон могут быть представлены одним именем.Определить `SalesData` для `A1:A10` и использовать `SalesData` в формулах.
- Область данных поддерживается в одном месте. При изменении диапазона обновляйте ссылку на имя вместо каждой используемой формулы.

## Использование

Ввод менеджера имен находится рядом с окном имен в верхнем левом углу листа. Нажатие на него отображает каждое определенное имя и открывает менеджер имен, где вы можете просматривать, редактировать и удалять определенные имена.

В формуле введите имя напрямую. Если диапазон называется `TotalSales`, `=TotalSales` ссылается на этот диапазон.

## Примечания

- Определенное имя должно быть уникальным в пределах одной и той же таблицы, и оно не может противоречить другому имени или встроенной функции.
- Имя не может начинаться с числа, и оно не может содержать пробелы или специальные символы, такие как `!`, `@` или `#`. Если введенное имя нарушает эти правила, система сообщает об ошибке.
- Чтобы изменить имя, откройте панель редактирования «Определить имя», выберите имя, отредактируйте его и нажмите «ОК».
- Чтобы удалить имя, выберите его в панели редактирования «Определить имя» и нажмите «Удалить». Формулы, которые ссылались на имя, становятся недействительными.
- Имена могут быть распределены по разным рабочим листам в одной и той же книге, но правило уникальности все еще применяется: определение одного и того же имени на разных рабочих листах может сделать ссылки двусмысленными.
- Используйте значимые имена и избегайте очень коротких или расплывчатых, чтобы другие люди могли понимать и поддерживать лист.
- Если использование определенного имени вызывает проблемы, проверьте, что имя правильное, что диапазон отсчета точный, и что никакое другое имя не противоречит ему.
- Имена на уровне книги могут быть установлены на уровне книги или на уровне рабочего листа. Названия на уровне книги доступны на протяжении всей книги, в то время как имена на уровне рабочего стола доступны только на конкретном рабочем листе.

## Facade API

Полные определения типов Facade API приведены в [Facade API](/reference/facade).

### Создание именованных диапазонов

`FWorkbook.newDefinedNameBuilder()` создает определенный конструктор и возвращает `FDefinedNameBuilder`. Цепочка его методов для создания объекта `ISetDefinedNameMutationParam`, используемого для создания имени.

Вот некоторые из методов, используемых в [`FDefinedNameBuilder`](/reference/facade/defined-name-builder):

| Метод | Описание |
| ---- | ---- |
| build | Создаёт объект именованного диапазона |
| setName | Задаёт имя |
| setFormula | Задаёт формулу именованного диапазона |
| setRef | Задаёт ссылку на диапазон |
| setComment | Задаёт комментарий |
| setScopeToWorksheet | Делает имя доступным на указанном листе |
| setScopeToWorkbook | Делает имя доступным во всей книге |

[`FWorkbook.insertDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#insertdefinednamebuilder) создает определенное имя, доступное для всей книги.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedNameParam = fWorkbook.newDefinedNameBuilder()
  .setName('MyDefinedName')
  .setRef('Sheet1!$A$1')
  .setComment('A reference to A1 cell in Sheet1')
  .build()
fWorkbook.insertDefinedNameBuilder(definedNameParam)
```

[`FWorkbook.insertDefinedName()`](https://docs.univer.ai/reference/facade/workbook#insertdefinedname) - это ярлык для создания определенного имени, когда имя и ссылка уже известны.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.insertDefinedName('MyDefinedName', 'Sheet1!$A$1')
```

Другие методы:
- [`FWorksheet.insertDefinedName()`](https://docs.univer.ai/reference/facade/worksheet#insertdefinedname): создаёт именованный диапазон, доступный на указанном листе.

### Получение именованных диапазонов

[`FWorkbook.getDefinedName()`](https://docs.univer.ai/reference/facade/workbook#getdefinedname) получает одно определенное имя из книги и возвращает `FDefinedName`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

if (definedName) {
  definedName.setName('NewDefinedName')
}
```

Другие методы:
- [`FWorkbook.getDefinedNames()`](https://docs.univer.ai/reference/facade/workbook#getdefinednames) возвращает каждое определенное имя в книге в виде массива `FDefinedName[]`.
- [`FWorksheet.getDefinedNames()`](https://docs.univer.ai/reference/facade/worksheet#getdefinednames) возвращает каждое заданное имя, доступное для этой таблицы, в виде массива `FDefinedName[]`.

### Изменение именованных диапазонов

[`FWorkbook.updateDefinedNameBuilder()`](https://docs.univer.ai/reference/facade/workbook#updatedefinednamebuilder) модифицирует определенное имя в рабочей книге.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Modify the defined name
if (definedName) {
  const newDefinedNameParam = definedName.toBuilder()
    .setName('NewDefinedName')
    .setRef('Sheet1!$A$2')
    .build()
  fWorkbook.updateDefinedNameBuilder(newDefinedNameParam)
}
```

Вы также можете изменить конфигурацию непосредственно на возвращаемом экземпляре [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name).

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Modify the defined name
if (definedName) {
  definedName.setName('NewDefinedName')
  definedName.setRef('Sheet1!$A$2')
}
```

### Удаление именованных диапазонов

[`FWorkbook.deleteDefinedName()`](https://docs.univer.ai/reference/facade/workbook#deletedefinedname) удаляет определенное имя в книге.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.deleteDefinedName('MyDefinedName')
```

Вы также можете удалить имя через возвращенный экземпляр [`FDefinedName`](https://docs.univer.ai/reference/facade/defined-name).

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const definedName = fWorkbook.getDefinedName('MyDefinedName')
console.log(definedName?.getFormulaOrRefString())

// Delete the defined name
if (definedName) {
  definedName.delete()
}
```
