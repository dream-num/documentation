このページの API はコンバージョンのバックエンドが必要です。[ファイル交換統合](/server/import-export) を最初に設定して、アップロード、変換、タスクのクエリ、および作業をダウンロードし、ブラウザのプラグインを構成します。スナップショット API は同じバックエンドが必要ですが、共同ドキュメントを必要としません。

エクスポート失敗時は[ライセンスエラーとタスク失敗の処理](/server/import-export#export-errors)を参照してください。

## 対応形式

表は、このページのブラウザ API でサポートされている形式をリストします。 Office ファイルの変換には、同じドキュメントタイプとフォーマットをサポートするバックエンドが必要です。

| インポート | エクスポート |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV と TSV は、ワークブックの書式や他のワークシートなしで単一のワークシートをエクスポートします。 `ExchangeFormat.CSV` または `ExchangeFormat.TSV`をエクスポート API に `sheetId`; XLSX はデフォルトです。 変換バックエンドがサポートしている場合でも、ブラウザ API は `.xlsm`を受け入れません。

## Facade API [#facade-api]

### インポート

<Callout type="info" title="プラグインモードノート">
  プラグインモードのみ、Facadeパッケージを手動でインポートする必要があります。プリセットモードには、既にマッチしたパッケージが含まれています。
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/sheets-exchange-client/facade'
```

### `.xlsx` インポート

#### `.xlsx` ファイルをインポートして `unitId` を取得

<Callout type="warning" title="キューション">
  このメソッドはコラボレーションが必要です。サーバー上でドキュメントを作成し、`unitId`を返します。コラボレーションが有効になっていない場合、代わりにスナップショットのインポートを使用します。
</Callout>

共同編集が有効になっている場合、すべてのドキュメントは`unitId`です。`file`を`univerAPI.importSheetToUnitIdAsync`に渡し、このメソッドは`unitId`を返し、ドキュメントを開くために使用されます。`file`は`File`オブジェクトまたはリモートファイルURLです。

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importSheetToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadSheetAsync(unitId)
}
```

#### `.xlsx` ファイルをインポートして `IWorkbookData` を取得

<Callout>スナップショットのインポートは共同編集不要です。共同編集ドキュメントは `unitId` を使用してください。</Callout>

`univerAPI.importSheetToSnapshotAsync`は`.xlsx`ファイルをインポートし、`IWorkbookData`としてドキュメントデータを返します。

```typescript
// File オブジェクトを受け取る
const snapshot = await univerAPI.importSheetToSnapshotAsync(file)
// またはリモート ファイル URL を受け取る
// const snapshot = await univerAPI.importSheetToSnapshotAsync('https://example.com/filename.xlsx');

// スナップショットから新しいワークブックを作成
if (snapshot) univerAPI.createWorkbook(snapshot)
```

### `.xlsx` エクスポート

#### `unitId` を使って `.xlsx` ファイルをエクスポート

<Callout type="warning" title="キューション">
  `unitId`でエクスポートするには、コラボレーションが必要です。コラボレーションが有効になっていない場合、スナップショットエクスポートを使用してください。
</Callout>

共同編集を有効にすると、すべてのドキュメントは独自の`unitId`を持っています。 `unitId`に`univerAPI.exportSheetByUnitIdAsync`を渡すと、メソッドは`File`オブジェクトを返します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook.getId()
const file = await univerAPI.exportSheetByUnitIdAsync(unitId)

// Facade API でファイルをダウンロード
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

#### `IWorkbookData` を使って `.xlsx` ファイルをエクスポート

<Callout>スナップショットエクスポートはコラボレーションを必要としません。ローカルのみのワークフローに適しています。</Callout>

`IWorkbookData`を`univerAPI.exportSheetBySnapshotAsync`に渡し、メソッドは`File`オブジェクトを返します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
const file = await univerAPI.exportSheetBySnapshotAsync(snapshot)

// Facade API でファイルをダウンロード
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

## 組み込みのインポート・エクスポートメニューと UI 操作の削除 [#import-export-ui-migration]

<Callout type="warning" title="注意:">
  バージョン**1.2.0**では、Univerには、組み込みのインポート/エクスポートメニューとUIのインタラクションが組み込まれていません。 アンダーリングサービスとファサードAPIは利用できます。
</Callout>

アプリケーションがこれらのメニューとインタラクションを必要としている場合、[組み込みのインポート/エクスポートメニューとUIインタラクションのマイグレーション例](https://office.univer.ai/showcase/sheets/custom-import-export)は、カスタムプラグインでそれらを復元する方法を示しています。 完全なソースコードは、オンライン読書やダウンロードのために利用可能です。
