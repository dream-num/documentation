The APIs on this page require a conversion backend. Configure [file exchange integration](/server/import-export) first so that uploads, conversion, task queries, and downloads work, and then configure the browser plugins. Snapshot APIs require the same backend but do not require a collaborative document.

For export failures, see [license error codes and task failure handling](/server/import-export#export-errors).

## Supported formats

The table lists the formats supported by the browser APIs on this page. Office file conversion additionally requires a backend that supports the same document type and format.

| Import | Export |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV and TSV export a single worksheet, without workbook formatting or the other worksheets. Pass `ExchangeFormat.CSV` or `ExchangeFormat.TSV` together with the `sheetId` to the export API; XLSX is the default. The browser API does not accept `.xlsm`, even when the conversion backend supports it.

## Facade API [#facade-api]

### Importing

<Callout type="info" title="Plugin mode note">
  Only plugin mode requires importing the Facade package manually. Preset mode already includes the matching package.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/sheets-exchange-client/facade'
```

### Importing `.xlsx`

#### Import `.xlsx` file and get `unitId`

<Callout type="warning" title="Caution">
  This method requires collaboration: it creates a document on the server and returns a `unitId`. If collaboration is not enabled, use snapshot import instead.
</Callout>

When collaborative editing is enabled, every document has a unique `unitId`. Pass a `file` to `univerAPI.importSheetToUnitIdAsync`, and the method returns that `unitId`, which is used to open the document. `file` can be a `File` object or a remote file URL.

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importSheetToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadSheetAsync(unitId)
}
```

#### Import `.xlsx` file and get `IWorkbookData` [#import-snapshot]

<Callout>Snapshot import does not require collaboration. Use `unitId` import for collaborative documents.</Callout>

`univerAPI.importSheetToSnapshotAsync` imports a `.xlsx` file and returns the document data as `IWorkbookData`.

```typescript
// Accept a File object
const snapshot = await univerAPI.importSheetToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importSheetToSnapshotAsync('https://example.com/filename.xlsx');

// Create a new workbook via snapshot
if (snapshot) univerAPI.createWorkbook(snapshot)
```

### Exporting `.xlsx`

#### Export `.xlsx` file using `unitId`

<Callout type="warning" title="Caution">
  Exporting by `unitId` requires collaboration. If collaboration is not enabled, use snapshot export.
</Callout>

When collaborative editing is enabled, every document has a unique `unitId`. Pass that `unitId` to `univerAPI.exportSheetByUnitIdAsync`, and the method returns a `File` object.

The `unitId` must identify a document persisted in the configured backend and accessible to the current session. `createWorkbook(snapshot)` creates a browser-local workbook; calling `getId()` does not upload it. Exporting that local ID can return `PERMISSION_DENIED` (`code=3`). For a local workbook, use `exportSheetBySnapshotAsync(fWorkbook.save())` as shown below.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook.getId()
const file = await univerAPI.exportSheetByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

#### Export `.xlsx` file using `IWorkbookData`

<Callout>Snapshot export does not require collaboration and is suitable for local-only workflows.</Callout>

Pass the `IWorkbookData` to `univerAPI.exportSheetBySnapshotAsync`, and the method returns a `File` object.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
const file = await univerAPI.exportSheetBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

## Removal of built-in import/export menus and UI interactions [#import-export-ui-migration]

<Callout type="warning" title="Note">
  As of version **1.2.0**, Univer no longer includes built-in import/export menus and UI interactions. The underlying services and Facade APIs remain available.
</Callout>

If the application still needs those menus and interactions, the [migration example for built-in import/export menus and UI interactions](https://office.univer.ai/showcase/sheets/custom-import-export) shows how to restore them with a custom plugin. The full source code is available for online reading or download.
