Проверка данных применяет правила к ячейкам и проверяет введенные значения на их основе. Она улавливает ошибки ввода на ранней стадии и сохраняет данные в листе точными и последовательными.

Univer поддерживает следующие типы валидации:
- Число
- Целое число
- Длина текста
- Дата
- Флажок
- Раскрывающийся список (одиночный или множественный выбор)
- Пользовательская формула

## Режим плагинов


## Сопоставление значений [#value-matching]

Проверка списка игнорирует регистр, поэтому `green` удовлетворяет варианту, записанному как `Green`, и ссылочный список подчиняется тому же правилу. Правила чисел и целых чисел принимают только числовой текст. Логические значения и пустой текст им не удовлетворяют.

### Добавление правила проверки данных

[`univerAPI.newDataValidation()`](https://docs.univer.ai/reference/facade/univer#newdatavalidation) создает конструктор и возвращает `FDataValidationBuilder`. Назовите его методы в цепочке для построения правила.

Основными методами на [`FDataValidationBuilder`](/reference/facade/data-validation-builder) являются:

| Метод | Описание |
| ------ | ----------- |
| build | Постройте правило. |
| requireCheckbox | Требуется булево значение, которое ячейка отображает в качестве чекбокса. |
| requireDateAfter | Установите тип даты и требуйте дату после указанной даты. |
| requireDateBefore | Установите тип даты и потребуйте дату до указанной даты. |
| requireDateBetween | Установите тип для датировки и потребуйте дату в пределах заданного диапазона. |
| requireDateEqualTo | Установите тип даты и потребуйте дату, равную данной дате. |
| requireDateNotBetween | Установите тип даты и потребуйте дату за пределами заданного диапазона. |
| requireDateOnOrAfter | Установите тип даты и требуйте дату на или после указанной даты. |
| requireDateOnOrBefore | Установите тип даты и требуйте дату на или до указанной даты. |
| requireFormulaSatisfied | Требуйте данную формулу для оценки `true`. |
| requireNumberBetween | Требуется число между двумя заданными числами, включительно. |
| requireNumberEqualTo | Требуется число, равное заданному значению. |
| requireNumberGreaterThan | Требуется число, превышающее заданную величину. |
| requireNumberGreaterThanOrEqualTo | Требуется число, превышающее или равное заданному значению. |
| requireNumberLessThan | Требуется число меньше заданного значения. |
| requireNumberLessThanOrEqualTo | Требуется число, меньшее или равное данному значению. |
| requireNumberNotBetween | Требуется число, которое не находится между двумя заданными числами и не равно ни одному из них. |
| requireNumberNotEqualTo | Требуется число, не равное заданному значению. |
| requireValueInList | Требуется значение из списка конкретных значений. Поддерживает одиночный/многократный выбор и показывает или скрывает выпадающее. |
| requireValueInRange | Требуется значение в пределах определенного диапазона. Поддерживает однократный/многократный выбор и показывает или скрывает выпадающее выпадение. |
| setOptions | Установите варианты для правила. |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new data validation rule that requires a number between 1 and 10 for the range A1:B10
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: 'Please enter a number between 1 and 10',
  })
  .build()
fRange.setDataValidation(rule)
```

### Получение правил проверки данных для диапазона или листа

Возвращенный объект правил представляет собой экземпляр `FDataValidation`, который раскрывает критерии, параметры и другие настройки правила.

Основными методами на [`FDataValidation`](https://docs.univer.ai/reference/facade/data-validation) являются:

| Метод | Описание |
| ---- | ---- |
| copy | Создайте новый экземпляр FDataValidationBuilder из объекта текущего правила. |
| getCriteriaType | Получите тип проверки правила. |
| getCriteriaValues | Получите значения, используемые для оценки критериев. |
| getHelpText | Получите текст справки, который дает рекомендации пользователям. |
| getRanges | Получите диапазоны, к которым применяется правило. |
| setCriteria | Установите критерии правила. |
| setOptions | Установите варианты правила. |
| setRanges | Установите диапазоны, к которым применяется правило. |
| delete | Исключить правило из рабочего листа. |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all data validation rules in current sheet.
const rulesOfSheet = fWorksheet.getDataValidations()

// Get a data validation rule by rule ID.
const ruleById = fWorksheet.getDataValidation(rulesOfSheet[0]?.rule?.uid)

const fRange = fWorksheet.getRange('A1:B10')

// Get first data validation rule in current range.
const ruleOfRange = fRange.getDataValidation()
console.log('ruleOfRange:', ruleOfRange, ruleOfRange?.getCriteriaValues())

// Get all data validation rules in current range.
const rulesOfRange = fRange.getDataValidations()
```

### Обновление и удаление проверки данных

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new data validation rule that requires a number equal to 20 for the range A1:B10
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberEqualTo(20)
  .build()
fRange.setDataValidation(rule)

const newRuleRange = fWorksheet.getRange('C1:D10')

// Update the rule after 3 seconds
setTimeout(() => {
  fRange.getDataValidation()
    // Change the range to C1:D10
    .setRanges([newRuleRange])
    // Change the criteria to require a number between 1 and 10
    .setCriteria(
      univerAPI.Enum.DataValidationType.DECIMAL,
      [univerAPI.Enum.DataValidationOperator.BETWEEN, '1', '10'],
    )
    // Change option to stop input on validation errors and show error message
    .setOptions({
      allowBlank: true,
      showErrorMessage: true,
      error: 'Please enter a valid value',
      errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
    })
}, 3000)

// Delete the rule after 6 seconds
setTimeout(() => {
  newRuleRange.getDataValidation().delete()
}, 6000)
```

### Получение ошибок проверки

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all data validation errors for current workbook.
const workbookErrors = await fWorkbook.getAllDataValidationErrorAsync()
console.log('workbookErrors:', workbookErrors)

// Get all data validation errors for current sheet.
const worksheetErrors = await fWorksheet.getAllDataValidationErrorAsync()
console.log('worksheetErrors:', worksheetErrors)

// Get data validation errors for current range.
const fRange = fWorksheet.getRange('A1:B10')
const rangeErrors = await fRange.getDataValidationErrorAsync()
console.log('rangeErrors:', rangeErrors)
```

Каждый объект ошибки содержит следующие поля:
- `sheetName`: название рабочего листа, в котором произошла ошибка
- `row`: индекс ячейки, вызвавший ошибку
- `column`: индекс столбца, который вызвал ошибку
- `ruleId`: идентификатор правила, вызвавшего ошибку
- `inputValue`: значение ввода, вызвавшее ошибку
- `rule`: Снимок содержимого правила

### Получение состояния валидатора

Статус валидатора является значением числа `DataValidationStatus`:
- `valid`: значение ячейки прошло проверку;
- `invalid`: значение ячейки не прошло проверку;
- `validating`: значение ячейки проверяется.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get data validation validator status for current workbook.
fWorkbook.getValidatorStatus().then((status) => {
  console.log('===statusOfWorkbook', status)

// Get data validation validator status for current sheet.
fWorksheet.getValidatorStatusAsync().then((status) => {
```

### Обработчики событий

Полные определения типов событий приведены в [События](https://docs.univer.ai/reference/facade/events).

Модуль валидации данных испускает события, когда правила добавляются, обновляются или удаляются, и когда статус валидирования изменяется. Используйте `univerAPI.addEvent()` для прослушивания любого из этих событий.

#### События изменения правил проверки

`univerAPI.Event.SheetDataValidationChanged` загорается после изменения правил проверки.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidationChanged, (params) => {
  const { origin, worksheet, workbook, changeType, oldRule, rule } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationAdd` загорается до добавления правила.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationAdd, (params) => {
  const { worksheet, workbook, rule } = params

  // Cancel the data validation rule addition operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationDelete` загорается до того, как правило будет удалено.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDelete, (params) => {
  const { worksheet, workbook, ruleId, rule } = params

  // Cancel the data validation rule deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationDeleteAll` загорается до того, как все правила будут удалены.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDeleteAll, (params) => {
  const { worksheet, workbook, rules } = params

  // Cancel the data validation rule deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### События обновления правил проверки

`univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate` загорается до того, как меняются критерии.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newCriteria } = params

  // Cancel the data validation rule criteria update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationRangeUpdate` загорается до изменения диапазона правил.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationRangeUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newRanges } = params

  // Cancel the data validation rule range update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationOptionsUpdate` загорается до того, как изменяются параметры правила.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationOptionsUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newOptions } = params

  // Cancel the data validation rule options update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### События состояния проверки

`univerAPI.Event.SheetDataValidatorStatusChanged` загорается при изменении статуса валидации ячейки.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidatorStatusChanged, (params) => {
  const { worksheet, workbook, row, column, status, rule } = params
})

// Remove the event listener, use `disposable.dispose()`
```

Каждое событие включает в себя следующие общие параметры:
- `workbook`: текущий экземпляр книги;
- `worksheet`: текущий экземпляр листа.

Некоторые события также включают:
- `rule`: связанный объект правила проверки;
- `ruleId`: уникальный идентификатор правила
- `status`: статус валидации (только в `SheetDataValidatorStatusChanged`)
- `newCriteria`: новые критерии валидации (только в `BeforeSheetDataValidationCriteriaUpdate`)
- `newRanges`: новые диапазоны валидации (только в `BeforeSheetDataValidationRangeUpdate`)
- `newOptions`: новые варианты валидации (только в `BeforeSheetDataValidationOptionsUpdate`)

Для любого события, название которого начинается с `Before`, установите `params.cancel = true` в обратном вызове, чтобы остановить операцию.

### Стиль ошибки

`errorStyle` контролирует, что происходит при вводе недействительных данных. Он принимает значение `DataValidationErrorStyle`:
- `STOP`: Отклоняет недействительный вход
- `WARNING`: принимает недействительный вход и показывает предупреждение
- `INFO`: принимает недействительный вход и показывает информационное сообщение

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B10')

const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: 'Please enter a number between 1 and 10',
    errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
  })
  .build()
fRange.setDataValidation(rule)
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
```
