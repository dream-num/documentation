워터 마크는 스프레드 시트의 상단에 텍스트 또는 이미지 오버레이입니다. 콘텐츠, 시작 위치, 반복 간격, 회전, 불투명은 구성이 가능합니다.

<Callout type="info">
  [Watermark 발전기](/tools/watermark-generator)는 워터 마크 스타일을 미리 보여 JSON으로 플러그인 구성을 다운로드합니다.
</Callout>

## 플러그인 모드

### 설치

```package-install
npm install @univerjs/watermark
```

### 사용법

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

### 플러그인 설정 [#plugin-configuration]

## 프리셋 모드

Watermark는 자체의 사전 설정이 없지만 플러그인은 여전히 사전 설정과 함께 작동합니다.

### 설치

```package-install
npm install @univerjs/watermark
```

### 사용법

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## Facade API

### 가져오기

<Callout type="info" title="플러그인 모드 참고">
  플러그인 모드는 수동으로 Facade 패키지를 가져야 합니다. 미리 설정 모드는 이미 해당 Facade 포장을 포함하므로 추가 수입이 필요하지 않습니다.
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### 워터마크 설정

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### 워터마크 제거

```typescript
univerAPI.deleteWatermark()
```
