워터마크 기능은 스프레드시트에 유연하고 안전한 워터마크 솔루션을 제공합니다. 개발자는 스프레드시트에 텍스트 또는 이미지 워터마크를 추가하고, 다양한 구성 옵션으로 워터마크의 모양과 동작을 맞춤 설정할 수 있습니다.

<PlaygroundFrame lang="en-US" slug="sheets/watermark" clickToShow />

## 프리셋 모드

워터마크는 프리셋을 제공하지 않지만 다른 프리셋과 플러그인 형태로 함께 사용할 수 있습니다.

### 설치

```package-install
npm install @univerjs/watermark
```

### 사용법

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## 플러그인 모드

### 설치

```package-install
npm install @univerjs/watermark
```

### 사용법

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

### 플러그인 및 구성

#### @univerjs/watermark

이 플러그인은 워터마크 기능의 핵심 구현을 제공합니다. 개발자는 애플리케이션에 텍스트 또는 이미지 워터마크를 추가하고, 다양한 구성 옵션으로 워터마크의 모양과 동작을 맞춤 설정할 수 있습니다. 이 패키지는 `UniverWatermarkPlugin` 플러그인을 제공합니다.

참고: [@univerjs/watermark](https://docs.univer.ai/reference/packages/plugins/univerjs/watermark)

## Facade API

### 가져오기

<Callout type="info" title="플러그인 모드 참고">
  Facade 패키지를 수동으로 가져와야 하는 것은 플러그인 모드뿐입니다. 프리셋 모드에는 해당 Facade 패키지가 이미 포함되어 있으므로 추가로 가져올 필요가 없습니다.
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### 워터마크 설정

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### 워터마크 제거

```typescript
univerAPI.deleteWatermark()
```
