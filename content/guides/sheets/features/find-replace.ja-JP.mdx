シート内のテキストを検索して置換し、それを置き換えます。 一致オプションは、厳密に検索マッチの比較を制御します。

機能を試してみるには、以下のプラグインの例で、検索とパネルを交換します。

<PlaygroundFrame lang="ja-JP" slug="sheets/basic-via-plugin" clickToShow />

## プラグインモード

### インストール

```package-install
npm install @univerjs/find-replace @univerjs/sheets-find-replace
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverFindReplacePlugin } from '@univerjs/find-replace' // [!code ++]
import FindReplaceJaJP from '@univerjs/find-replace/locale/ja-JP' // [!code ++]
import { UniverSheetsFindReplacePlugin } from '@univerjs/sheets-find-replace' // [!code ++]
import '@univerjs/find-replace/lib/index.css' // [!code ++]
import '@univerjs/sheets-find-replace/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      FindReplaceJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverFindReplacePlugin) // [!code ++]
univer.registerPlugin(UniverSheetsFindReplacePlugin) // [!code ++]
```

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/sheets/getting-started/installation#mobile-support)を最初にセットアップします。このページのプラグインモード設定では、同じパッケージからモバイルエクスポートでデスクトップ登録を交換し、**ドキュメントを開く前に**を実行します。モデルプラグイン、スタイル、ロケール、ファサードのインポートをそのまま保存し、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs/find-replace` | `UniverFindReplacePlugin` | `UniverFindReplaceMobileUIPlugin` |
| `@univerjs/sheets-find-replace` | `UniverSheetsFindReplacePlugin` | `UniverSheetsFindReplaceMobileUIPlugin` |

## プリセットモード

### インストール

```package-install
npm install @univerjs/preset-sheets-find-replace
```

### 使い方

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreJaJP from '@univerjs/preset-sheets-core/locales/ja-JP'
import { UniverSheetsFindReplacePreset } from '@univerjs/preset-sheets-find-replace' // [!code ++]
import UniverPresetSheetsFindReplaceJaJP from '@univerjs/preset-sheets-find-replace/locales/ja-JP' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-find-replace/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetSheetsCoreJaJP,
      UniverPresetSheetsFindReplaceJaJP, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsFindReplacePreset(), // [!code ++]
  ],
})
```

### テキスト検索器の作成

`univerAPI.createTextFinderAsync()` を呼び出してテキストファインダーを作成します。`FTextFinder`インスタンスを返します。

下の表は、[`FTextFinder`](/reference/facade/text-finder)のメソッドの一部をリストします。

| メソッド | 説明 |
| ------ | ----------- |
| findAll | 現在のシートにマッチする全てのマッチを返します。現在のマッチは最後のマッチに移動します。 |
| findNext | 現在のシートの次のマッチに移動し、ある場合は返します。 |
| findPrevious | 現在のシートの前のマッチに移動し、ある場合は返します。 |
| getCurrentMatch | 現在のシートの現在のマッチを返します。 |
| matchCaseAsync | マッチケースオプションを設定します。true の場合、検索はケースに敏感です。そうしないとケースを無視します。 |
| matchEntireCellAsync | 全セルオプションを設定します。true の場合、検索は完全なセル値のみにマッチします。それ以外の場合は、値の一部にマッチできます。 |
| matchFormulaTextAsync | 式テキストオプションを設定します。true の場合、検索は式テキストを調べます。そうしないと値が調べられます。 |
| replaceAllWithAsync | 与えられたテキストと一致するすべてのマッチを置換します。 |
| replaceWithAsync | 指定したテキストで現在のマッチを置換します。 |
| ensureCompleteAsync | 見つかる操作が完了していることを確認します。この問題は、現在のシートが変更された後に行われます。 |

```typescript
// 現在のシートが空であると仮定します。
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 範囲 A1:D10 に値を設定します。
const fRange = fWorksheet.getRange('A1:D10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// テキスト '5' を検索するテキストファインダーを作成します。
const textFinder = await univerAPI.createTextFinderAsync('5')

// テキスト '5' を含むすべてのセルを見つけます。
const matchCells = textFinder.findAll()
matchCells.forEach((cell) => {
  cell.getA1Notation() // 例: D2, C3, B4, A5
})
```
