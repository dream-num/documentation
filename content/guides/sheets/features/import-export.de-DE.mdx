<Callout type="warning" title="Caution">
Die Import- und Exportfunktion erfordert Unterstützung vom Univer-Server. Bitte stellen Sie sicher, dass Sie den Univer-Server korrekt installiert und konfiguriert haben. Einzelheiten finden Sie unter: [Upgrade auf Pro](/guides/pro)
</Callout>

Mit der Import- und Exportfunktion können Benutzer `.xlsx`-Dateien in Univer-Dokumente importieren oder Dokumentinhalte als `.xlsx`-Dateien über den Univer-Server exportieren und so die Interaktion mit anderer Office-Software oder Plattformen erleichtern.

<PlaygroundFrame lang="en-US" slug="sheets/univer-pro-import-export" clickToShow />

<Callout title="Why does Univer implement import and export through backend services?">
Ein Import und Export, der ausschließlich über das Frontend implementiert wird, kann die Unternehmensanforderungen in Bezug auf Leistung und Ergebnisse nicht erfüllen. Daher bieten wir Backend-Dienste zur Implementierung von Import- und Exportfunktionen an. Sie können Open-Source-DOCX-Parsing-Bibliotheken verwenden, um Dateien in Datenstrukturen zu analysieren, die der `IDocumentData`-Schnittstelle entsprechen, und dann die Facade-API verwenden, um Daten in Univer zu importieren.
</Callout>

Nach dem erfolgreichen Import über den Importeintrag in der Menüleiste erscheint in der unteren linken Ecke der Seite eine Benachrichtigung mit Informationen zum erfolgreichen Import und einem Link zum Zugriff auf das importierte Dokument. Wenn das standardmäßige Import- und Exportverhalten nicht Ihren Anforderungen entspricht, lesen Sie bitte [Benutzerdefinierte Importdokumente](/guides/recipes/tutorials/custom-import), um zu erfahren, wie Sie das Importverhalten anpassen können.

## So wählen Sie Import/Export

Es gibt zwei Pfade, je nachdem, ob eine Zusammenarbeit erforderlich ist:

| Pfad | Erfordert Zusammenarbeit | Am besten geeignet für | API |
| --- | --- | --- | --- |
| By `unitId` | Yes | Gemeinschaftliche Dokumente, die auf dem Server gespeichert werden | `importXLSXToUnitIdAsync` / `exportXLSXByUnitIdAsync` |
| Nach Schnappschuss | No | Lokale oder Offline-Workflows oder nur Formatkonvertierung | `importXLSXToSnapshotAsync` / `exportXLSXBySnapshotAsync` |

Wenn Ihr Projekt Zusammenarbeit verwendet (serverbasierte Dokumente, die über `unitId` geöffnet werden), wählen Sie den Pfad `unitId`. Andernfalls verwenden Sie den Snapshot-Pfad.

## Voreinstellungsmodus

### Installation

<Callout>
Die Voreinstellung `UniverSheetsAdvancedPreset` von `@univerjs/preset-sheets-advanced` hängt von der Voreinstellung `UniverSheetsDrawingPreset` zur Laufzeit ab. Bitte installieren Sie zuerst `@univerjs/preset-sheets-drawing`.
</Callout>

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

### Nutzung

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
import UniverPresetSheetsAdvancedEnUS from '@univerjs/preset-sheets-advanced/locales/en-US' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]
import UniverPresetSheetsDrawingEnUS from '@univerjs/preset-sheets-drawing/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-advanced/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsDrawingEnUS, // [!code ++]
      UniverPresetSheetsAdvancedEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsDrawingPreset(), // [!code ++]
    UniverSheetsAdvancedPreset({ // [!code ++]
      universerEndpoint: 'http://localhost:3010', // [!code ++]
    }), // [!code ++]
  ],
})
```

Wenn Sie eine kommerzielle Lizenz für Univer haben, lesen Sie bitte [Lizenz im Client verwenden](/guides/pro/license#in-preset-mode) für die Konfiguration.

### Voreinstellungen und Konfiguration

Die Konfigurationsoptionen für `UniverSheetsAdvancedPreset` sind wie folgt:

```typescript
interface IUniverSheetsAdvancedPresetConfig {
  // This is the endpoint for the Univer server
  universerEndpoint?: string
  exchangeClientOptions?: {
    // The minimum number of rows in the imported worksheet
    minSheetRowCount?: number
    // The minimum number of columns in the imported worksheet
    minSheetColumnCount?: number
    /**
     * Export whether to enable server-side formula calculation. When enabled, each export will trigger server-side formula calculation, addressing the following issues:
     * 1. Formulas have no default values when opening files in office software like WPS
     * 2. Excel does not show formula results unless editing is enabled
     * 3. Array formulas with the @ prefix cannot expand calculation results
     * Note: This configuration needs to be used in a collaborative editing environment, and the server configuration file needs to set `SSC_SERVER_ENABLED=true`.
     */
    enableServerSideComputing?: boolean
    /**
     * Whether to disable converting cell images to link on export.
     * If the cell image source is a URL, the default behavior is to convert the url to the cell value on export.
     * Because the server will download all the resource files, when there are many images, it will consume a lot of resources and take a long time.
     * @default true
     */
    disableCellImageConversion?: boolean
    /**
     * Whether to ignore Table when exporting.
     * @default false
     */
    ignoreTableExport?: boolean
  }
}
```

## Fassaden-API [#facade-api]

### Importieren

<Callout type="info" title="Plugin mode note">
Nur im Plugin-Modus muss das Facade-Paket manuell importiert werden. Der Voreinstellungsmodus enthält bereits das entsprechende Facade-Paket, sodass kein zusätzlicher Import erforderlich ist.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
```

### `.xlsx` importieren

#### Datei `.xlsx` importieren und `unitId` abrufen

<Callout type="warning" title="Caution">
Diese Methode erfordert Zusammenarbeit: Sie erstellt ein Serverdokument und gibt ein `unitId` zurück. Verwenden Sie den Snapshot-Import, wenn die Zusammenarbeit nicht aktiviert ist.
</Callout>

Wenn die gemeinsame Bearbeitung aktiviert ist, hat jedes Dokument einen eindeutigen `unitId`. Wenn Sie `univerAPI.importXLSXToUnitIdAsync` mit dem Parameter `file` verwenden, wird `unitId` zurückgegeben, das für den Zugriff auf das Dokument verwendet werden kann. Der Parameter `file` kann ein `File`-Objekt oder eine Remote-Datei-URL sein.

```typescript
// Accept a File object
const unitId = await univerAPI.importXLSXToUnitIdAsync(file)
// Or accept a remote file URL
// const unitId = await univerAPI.importXLSXToUnitIdAsync('https://example.com/filename.xlsx');

// Using with collaborative editing to automatically load data https://docs.univer.ai/en-US/guides/docs/features/collaboration#loading-collaborative-documents
const url = new URL(window.location.href)
url.searchParams.set('unit', unitId)
url.searchParams.set('type', '2') // The meaning of 2 is UniverInstanceType.UNIVER_SHEET

window.location.href = url.toString()

// Or call the API: univerAPI.loadServerUnit(unitId, 2) to load the document, refer to /reference/facade/univer#loadserverunit for specific parameters
```

#### Importieren Sie die Datei `.xlsx` und erhalten Sie `IWorkbookData`

<Callout>
Der Snapshot-Import erfordert keine Zusammenarbeit. Verwenden Sie den `unitId`-Import für kollaborative Dokumente.
</Callout>

Wenn Sie `univerAPI.importXLSXToSnapshotAsync` zum Importieren einer `.xlsx`-Datei verwenden, werden die Dokumentdaten im Format `IWorkbookData` zurückgegeben.

```typescript
// Accept a File object
const snapshot = await univerAPI.importXLSXToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importXLSXToSnapshotAsync('https://example.com/filename.xlsx');

// Create a new workbook via snapshot
univerAPI.createWorkbook(snapshot)
```

### Exportieren von `.xlsx`

#### Exportieren `.xlsx`-Datei mit `unitId`

<Callout type="warning" title="Caution">
Der `unitId`-Export erfordert Zusammenarbeit. Wenn die Zusammenarbeit nicht aktiviert ist, verwenden Sie den Snapshot-Export.
</Callout>

Wenn die gemeinsame Bearbeitung aktiviert ist, hat jedes Dokument einen eindeutigen `unitId`. Die Verwendung von `univerAPI.exportXLSXByUnitIdAsync` mit dem Parameter `unitId` gibt ein `File`-Objekt zurück.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook.getId()
const file = await univerAPI.exportXLSXByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

#### Exportieren Sie die Datei `.xlsx` mit `IWorkbookData`

<Callout>
Der Snapshot-Export erfordert keine Zusammenarbeit und ist für den lokalen Einsatz geeignet Workflows.
</Callout>

Die Verwendung von `univerAPI.exportXLSXBySnapshotAsync` mit dem `IWorkbookData` gibt ein `File`-Objekt zurück.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.getSnapshot()
const file = await univerAPI.exportXLSXBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

## Konvertieren von Daten auf dem Node.js-Server [#server-side-data-conversion]

Der Univer-Server stellt APIs für den Import und Export bereit, aber das auf dem Server konvertierte Datenformat stimmt nicht mit dem Univer-Format überein. Nachdem Sie Univer initialisiert und `@univerjs-pro/exchange-client` im Node.js-Prozess registriert haben, verwenden Sie die Facade-API, um die Daten zu transformieren.

<Callout type="warning" title="Migration note">
Die Paket-Root-Helfer `transformSnapshotJsonToWorkbookData` und `transformWorkbookDataToSnapshotJson` bleiben aus Kompatibilitätsgründen verfügbar, sind jedoch veraltet und sollen in Version 1.1.0 entfernt werden. Verwenden Sie die Facade-APIs unten im neuen Code.
</Callout>

### Snapshot in `IWorkbookData` umwandeln

Nach dem Import müssen die Snapshot-JSON-Daten in das Format `IWorkbookData` umgewandelt werden, um in Univer verwendet zu werden.

```typescript
// The json data contains snapshot and sheetBlocks
const workbookData = await univerAPI.transformSnapshotJsonToWorkbookDataAsync(json)
```

### Transformieren Sie `IWorkbookData` in Snapshot JSON

Vorher Beim Exportieren müssen die Daten im `IWorkbookData`-Format in Snapshot-JSON-Daten umgewandelt werden, die dann zum Export an den Server gesendet werden können.

```typescript
const snapshotJson = await univerAPI.transformWorkbookDataToSnapshotJsonAsync(workbookData)
```
