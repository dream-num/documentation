Условное форматирование автоматически меняет формат ячейки, когда удерживает условие, так что выделяются важные данные и тенденции. Он поддерживает несколько условий и вариантов форматирования, что облегчает чтение данных с первого взгляда.

## Режим плагинов

### Установка

```package-install
npm install @univerjs/sheets-conditional-formatting @univerjs/sheets-conditional-formatting-ui
```

### Использование

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsConditionalFormattingPlugin } from '@univerjs/sheets-conditional-formatting' // [!code ++]
import { UniverSheetsConditionalFormattingUIPlugin } from '@univerjs/sheets-conditional-formatting-ui' // [!code ++]
import SheetsConditionalFormattingUIEnUS from '@univerjs/sheets-conditional-formatting-ui/locale/en-US' // [!code ++]
import '@univerjs/sheets-conditional-formatting-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-conditional-formatting/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsConditionalFormattingUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsConditionalFormattingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsConditionalFormattingUIPlugin) // [!code ++]
```

### Создание правил условного форматирования

[`FWorksheet.newConditionalFormattingRule()`](https://docs.univer.ai/reference/facade/worksheet#newconditionalformattingrule) возвращает `FConditionalFormattingBuilder`. Назовите его методы в цепочке, чтобы определить правило.

Методы членов [`FConditionalFormattingBuilder`](/reference/facade/conditional-formatting-builder) включают в себя:

| Метод | Описание |
| ---- | ---- |
| build | Построить правило |
| copy | Глубокоугольный нынешний строитель |
| createCfId | Создает условный формат ID |
| getRanges | Получает диапазоны текущего условного формата |
| setRanges | Устанавливает диапазон, к которому применяется правило |
| setAverage | Устанавливает правило средней стоимости |
| setUniqueValues | Устанавливает правило уникальных значений |
| setDuplicateValues | Устанавливает правило двойных значений |
| setRank | Устанавливает правило ранга |
| setIconSet | Устанавливает правило набора значков |
| setColorScale | Устанавливает правило цветовой шкалы |
| setDataBar | Устанавливает правило data-bar |
| setBackground | Устанавливает цвет фона |
| setBold | Настройка жирного текста |
| setFontColor | Устанавливает цвет шрифта |
| setItalic | Устанавливает курсив текст |
| setStrikethrough | Настройка сквозняка |
| setUnderline | Подчеркнуть |
| whenCellEmpty | Пожар, когда клетка пуста |
| whenCellNotEmpty | Пожар, когда клетка не пуста |
| whenDate | Пожары, когда дата выпадает на определенный период |
| whenFormulaSatisfied | Пожары, когда формула оценивает истинность |
| whenNumberBetween | Огонь, когда число находится между двумя значениями, или равно одному из них. |
| whenNumberEqualTo | Пожары, когда число равно заданному значению |
| whenNumberGreaterThan | Пожары, когда число больше заданного значения |
| whenNumberGreaterThanOrEqualTo | Пожары, когда число больше или равно заданному значению |
| whenNumberLessThan | Пожары, когда число меньше заданного значения |
| whenNumberLessThanOrEqualTo | Пожары, когда число меньше или равно заданному значению |
| whenNumberNotBetween | Огонь, когда число не находится между двумя значениями и не равно ни одному из них. |
| whenNumberNotEqualTo | Пожары, когда число не равняется заданному значению |
| whenTextContains | Пожары, когда текст содержит указанное значение |
| whenTextDoesNotContain | Пожары, когда текст не содержит заданного значения |
| whenTextEndsWith | Пожар, когда текст заканчивается указанным значением |
| whenTextEqualTo | Пожары, когда текст равен заданному значению |
| whenTextStartsWith | Пожар, когда текст начинается с заданного значения |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)
```

### Получение правил условного форматирования

- `FWorksheet.getConditionalFormattingRules()` возвращает все правила условного форматирования листа
- `FRange.getConditionalFormattingRules()` возвращает все правила условного форматирования диапазона

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Get all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
const rulesOfSheet = fWorksheet.getConditionalFormattingRules()

// Get all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
const rulesOfRange = fRange.getConditionalFormattingRules()
```

### Удаление правил условного форматирования

`FWorksheet.deleteConditionalFormattingRule(cfId)` удаляет правило из рабочего листа. `cfId` - это идентификатор правила.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Remove the first conditional formatting rule
fWorksheet.deleteConditionalFormattingRule(rules[0]?.cfId)
```

### Обновление правил условного форматирования

`FWorksheet.setConditionalFormattingRule(cfId, rule)` заменяет правило в рабочем листе. `cfId` является идентификатором правила для замены, а `rule` - новым правилом.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)

// Modify the first rule to apply to a new range
const rules = fWorksheet.getConditionalFormattingRules()
const newRuleRange = fWorksheet.getRange('A1:D10')
fWorksheet.setConditionalFormattingRule(rules[0]?.cfId, { ...rules[0], ranges: [newRuleRange.getRange()] })
```

### Изменение приоритета правил условного форматирования

`FWorksheet.moveConditionalFormattingRule(cfId, toCfId, type)` изменяет положение правила в порядке приоритета. `cfId` - это правило перемещения, `toCfId` является правилом, по которому он перемещается относительно, а `type` представляет собой тип перемещения (например, "до", "после").

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Move the third rule before the first rule
const rule = rules[2]
const targetRule = rules[0]
fWorksheet.moveConditionalFormattingRule(rule?.cfId, targetRule?.cfId, 'before')
```

### Очистка всех правил условного форматирования

- `FWorksheet.clearConditionalFormatRules()` удаляет все правила условного форматирования с листа
- `FRange.clearConditionalFormatRules()` удаляет все правила условного форматирования из диапазона

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Clear all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.clearConditionalFormatRules()

// Clear all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
fRange.clearConditionalFormatRules()
```

## Повторное использование описаний и предпросмотра правил [#custom-rule-ui]

Чтобы создать пользовательский список правил, импортируйте `getRuleDescribe` и `ConditionalFormattingRulePreview` из `@univerjs/sheets-conditional-formatting-ui`. Передайте все правило `getRuleDescribe(rule, localeService)`, и передайте только его конфигурацию (`rule.rule`) в предварительный просмотр. Предварительный просмотр отображает сконфигурированный внешний вид и не оценивает ячейки рабочих листов. Отображайте его в контексте Univer React .

`CF_PANEL_KEY` идентифицирует встроенную панель, поэтому [переопределение компонентов](/guides/sheets/ui/components) может нацеливаться на нее. Его обратный вызов `IConditionFormattingPanelProps.onEditorExit` запускается при завершении редактирования: после отправки, после отмены или при активации или удалении рабочего листа. Он не указывает, удалось ли сохранить или закрылась ли боковая панель.

```tsx
import type { IConditionFormattingRule } from '@univerjs/sheets-conditional-formatting'
import { LocaleService } from '@univerjs/core'
import { ConditionalFormattingRulePreview, getRuleDescribe } from '@univerjs/sheets-conditional-formatting-ui'
import { useDependency } from '@univerjs/ui'

interface IRuleSummaryProps {
  rule: IConditionFormattingRule
}

function RuleSummary({ rule }: IRuleSummaryProps) {
  const localeService = useDependency(LocaleService)

  return (
    <div>
      <span>{getRuleDescribe(rule, localeService)}</span>
      <ConditionalFormattingRulePreview rule={rule.rule} />
    </div>
  )
}
```

## Приоритет правил и остановка при совпадении [#stop-if-true]

Правила применяются в порядке приоритета. Для данной ячейки правило подбора выделений, несущее `stopIfTrue: true`, подавляет правила более низкого приоритета, даже когда правило подборов не устанавливает стиль. Если правило не совпадает, оценка продолжается. Результаты правил более высокого приоритета остаются в силе. Редактор правил предоставляет эту опцию только для выделения правил; цветовые шкалы, полосы данных и наборы значков не имеют его.

В примере сначала добавляется правило фона с более низким приоритетом, поскольку вновь добавленное правило находится в верхней части списка. При включенной остановке 90 отображается жирным шрифтом без зеленого фона, в то время как 60 все еще получает фон. `stopIfTrue` принадлежит внешнему объекту правила, а не `rule`.

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

const ranges = [sheet.getRange('B2:B10').getRange()]
const backgroundRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(50)
  .setBackground('#DCFCE7')
  .setRanges(ranges)
  .build()
const priorityRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(80)
  .setBold(true)
  .setRanges(ranges)
  .build()

sheet.addConditionalFormattingRule(backgroundRule)
sheet.addConditionalFormattingRule({ ...priorityRule, stopIfTrue: true })
```
