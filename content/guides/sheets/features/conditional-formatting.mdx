Conditional formatting changes the format of a cell automatically when a condition holds, so that important data and trends stand out. It supports multiple conditions and formatting options, which makes the data easier to read at a glance.

## Plugin mode

### Installation

```package-install
npm install @univerjs/sheets-conditional-formatting @univerjs/sheets-conditional-formatting-ui
```

### Usage

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsConditionalFormattingPlugin } from '@univerjs/sheets-conditional-formatting' // [!code ++]
import { UniverSheetsConditionalFormattingUIPlugin } from '@univerjs/sheets-conditional-formatting-ui' // [!code ++]
import SheetsConditionalFormattingUIEnUS from '@univerjs/sheets-conditional-formatting-ui/locale/en-US' // [!code ++]
import '@univerjs/sheets-conditional-formatting-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-conditional-formatting/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsConditionalFormattingUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsConditionalFormattingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsConditionalFormattingUIPlugin) // [!code ++]
```

### Create conditional formatting rules

[`FWorksheet.newConditionalFormattingRule()`](https://docs.univer.ai/reference/facade/worksheet#newconditionalformattingrule) returns an `FConditionalFormattingBuilder`. Call its methods in a chain to define the rule.

Member methods on [`FConditionalFormattingBuilder`](/reference/facade/conditional-formatting-builder) include:

| Method | Description |
| ---- | ---- |
| build | Builds the rule |
| copy | Deep-clones the current builder |
| createCfId | Creates a conditional format ID |
| getRanges | Gets the ranges of the current conditional format |
| setRanges | Sets the range the rule applies to |
| setAverage | Sets an average-value rule |
| setUniqueValues | Sets a unique-values rule |
| setDuplicateValues | Sets a duplicate-values rule |
| setRank | Sets a rank rule |
| setIconSet | Sets an icon-set rule |
| setColorScale | Sets a color-scale rule |
| setDataBar | Sets a data-bar rule |
| setBackground | Sets the background color |
| setBold | Sets bold text |
| setFontColor | Sets the font color |
| setItalic | Sets italic text |
| setStrikethrough | Sets strikethrough |
| setUnderline | Sets underline |
| whenCellEmpty | Fires when the cell is empty |
| whenCellNotEmpty | Fires when the cell is not empty |
| whenDate | Fires when the date falls in a specific period |
| whenFormulaSatisfied | Fires when the formula evaluates to true |
| whenNumberBetween | Fires when the number is between two values, or equal to one of them |
| whenNumberEqualTo | Fires when the number equals the given value |
| whenNumberGreaterThan | Fires when the number is greater than the given value |
| whenNumberGreaterThanOrEqualTo | Fires when the number is greater than or equal to the given value |
| whenNumberLessThan | Fires when the number is less than the given value |
| whenNumberLessThanOrEqualTo | Fires when the number is less than or equal to the given value |
| whenNumberNotBetween | Fires when the number is not between two values and not equal to either |
| whenNumberNotEqualTo | Fires when the number does not equal the given value |
| whenTextContains | Fires when the text contains the specified value |
| whenTextDoesNotContain | Fires when the text does not contain the specified value |
| whenTextEndsWith | Fires when the text ends with the specified value |
| whenTextEqualTo | Fires when the text equals the given value |
| whenTextStartsWith | Fires when the text starts with the specified value |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)
```

### Get conditional formatting rules

- `FWorksheet.getConditionalFormattingRules()` gets all conditional formatting rules of the worksheet
- `FRange.getConditionalFormattingRules()` gets all conditional formatting rules of the range

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Get all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
const rulesOfSheet = fWorksheet.getConditionalFormattingRules()

// Get all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
const rulesOfRange = fRange.getConditionalFormattingRules()
```

### Remove conditional formatting rules

`FWorksheet.deleteConditionalFormattingRule(cfId)` removes a rule from the worksheet. `cfId` is the ID of the rule.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Remove the first conditional formatting rule
fWorksheet.deleteConditionalFormattingRule(rules[0]?.cfId)
```

### Update conditional formatting rules

`FWorksheet.setConditionalFormattingRule(cfId, rule)` replaces a rule in the worksheet. `cfId` is the ID of the rule to replace, and `rule` is the new rule.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)

// Modify the first rule to apply to a new range
const rules = fWorksheet.getConditionalFormattingRules()
const newRuleRange = fWorksheet.getRange('A1:D10')
fWorksheet.setConditionalFormattingRule(rules[0]?.cfId, { ...rules[0], ranges: [newRuleRange.getRange()] })
```

### Modify the priority of conditional formatting rules

`FWorksheet.moveConditionalFormattingRule(cfId, toCfId, type)` changes the position of a rule in the priority order. `cfId` is the rule to move, `toCfId` is the rule it moves relative to, and `type` is the move type (e.g., 'before', 'after').

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Move the third rule before the first rule
const rule = rules[2]
const targetRule = rules[0]
fWorksheet.moveConditionalFormattingRule(rule?.cfId, targetRule?.cfId, 'before')
```

### Clear all conditional formatting rules

- `FWorksheet.clearConditionalFormatRules()` clears all conditional formatting rules of the worksheet
- `FRange.clearConditionalFormatRules()` clears all conditional formatting rules of the range

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Clear all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.clearConditionalFormatRules()

// Clear all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
fRange.clearConditionalFormatRules()
```

## Reuse rule descriptions and previews [#custom-rule-ui]

To build a custom rule list, import `getRuleDescribe` and `ConditionalFormattingRulePreview` from `@univerjs/sheets-conditional-formatting-ui`. Pass the entire rule to `getRuleDescribe(rule, localeService)`, and pass only its configuration (`rule.rule`) to the preview. The preview renders the configured appearance and does not evaluate worksheet cells. Render it within Univer's React context.

`CF_PANEL_KEY` identifies the built-in panel, so [component overrides](/guides/sheets/ui/components) can target it. Its `IConditionFormattingPanelProps.onEditorExit` callback runs when editing ends: after a submit, after a cancel, or when the worksheet is activated or removed. It does not indicate whether the save succeeded or whether the sidebar closed.

```tsx
import type { IConditionFormattingRule } from '@univerjs/sheets-conditional-formatting'
import { LocaleService } from '@univerjs/core'
import { ConditionalFormattingRulePreview, getRuleDescribe } from '@univerjs/sheets-conditional-formatting-ui'
import { useDependency } from '@univerjs/ui'

interface IRuleSummaryProps {
  rule: IConditionFormattingRule
}

function RuleSummary({ rule }: IRuleSummaryProps) {
  const localeService = useDependency(LocaleService)

  return (
    <div>
      <span>{getRuleDescribe(rule, localeService)}</span>
      <ConditionalFormattingRulePreview rule={rule.rule} />
    </div>
  )
}
```

## Text rule matching [#text-rules]

Text rules compare case-insensitively: contains, begins-with, ends-with, equal-to, and not-equal-to all ignore case. Duplicate and unique rules also treat `Apple` and `apple` as the same value.

## Rule priority and stop if true [#stop-if-true]

Rules apply in priority order. For a given cell, a matching highlight rule that carries `stopIfTrue: true` suppresses lower-priority rules, even when the matching rule sets no style. If the rule does not match, evaluation continues. Results from higher-priority rules remain in effect. The rule editor provides this option for highlight rules only; color scales, data bars, and icon sets do not have it.

The example adds the lower-priority background rule first because a newly added rule is placed at the top of the list. When stopping is enabled, 90 appears in bold without the green background, while 60 still receives the background. `stopIfTrue` belongs to the outer rule object, not to `rule`.

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

const ranges = [sheet.getRange('B2:B10').getRange()]
const backgroundRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(50)
  .setBackground('#DCFCE7')
  .setRanges(ranges)
  .build()
const priorityRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(80)
  .setBold(true)
  .setRanges(ranges)
  .build()

sheet.addConditionalFormattingRule(backgroundRule)
sheet.addConditionalFormattingRule({ ...priorityRule, stopIfTrue: true })
```
