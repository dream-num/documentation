La mise en évidence des cheveux croisés marque la ligne et la colonne de la cellule sélectionnée, ce qui facilite l'identification de la cellule active.

<PlaygroundFrame lang="fr-FR" slug="sheets/crosshair-highlighting" clickToShow />

## Mode plugin

### Installation

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### Utilisation

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight'
import SheetsCrosshairHighlightEnUS from '@univerjs/sheets-crosshair-highlight/locale/en-US'
import '@univerjs/sheets-crosshair-highlight/lib/index.css'
import '@univerjs/sheets-crosshair-highlight/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsCrosshairHighlightEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsCrosshairHighlightPlugin) // [!code ++]
```

## Prise en charge mobile [#mobile-support]

Configurez d'abord le [éditeur mobile](/guides/sheets/getting-started/installation#mobile-support). Dans la configuration en mode plugin sur cette page, remplacez les enregistrements de bureau ci-dessous par les exportations mobiles des mêmes paquets, et remplissez le remplacement **avant d'ouvrir un document** . Gardez les plugins modèles, styles, locaux et importations Facade, et ne enregistrez pas les deux variantes.

| Paquet | Inscription de bureau | Inscription mobile |
| --- | --- | --- |
| `@univerjs/sheets-crosshair-highlight` | `UniverSheetsCrosshairHighlightPlugin` | `UniverSheetsCrosshairHighlightMobileUIPlugin` |

## Mode preset

La mise en valeur des cheveux croisés ne fournit pas un preset de son propre, mais son plugin peut être ajouté à côté d'un preset.

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### Utilisation

```typescript
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight' // [!code ++]
import '@univerjs/sheets-crosshair-highlight/facade' // [!code ++]
import '@univerjs/sheets-crosshair-highlight/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      SheetsCrosshairHighlightEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    UniverSheetsCrosshairHighlightPlugin, // [!code ++]
  ],
})
```

## Facade API

Les définitions de type Facade API complètes sont dans [FacadeAPI](/reference/facade).

### Importation

<Callout type="info" title="Note du mode greffon">
  Le paquet Facade est importé manuellement seulement en mode plugin. Le mode Preset l'inclut déjà, donc aucune importation supplémentaire n'est nécessaire.
</Callout>

```typescript
import '@univerjs/sheets-crosshair-highlight/facade'
```

### Activer ou désactiver la mise en surbrillance en croix

```typescript
univerAPI.setCrosshairHighlightEnabled(true)

univerAPI.setCrosshairHighlightEnabled(false)
```

### Obtenir l’état d’activation de la mise en surbrillance en croix

```typescript
univerAPI.getCrosshairHighlightEnabled()
```

### Écouteurs d’événements

Les définitions complètes du type d'événement sont dans [Événements](https://docs.univer.ai/reference/facade/events).

`CrosshairHighlightEnabledChanged` fait feu lorsque la mise en évidence des cheveux croisés est activée ou désactivée.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CrosshairHighlightEnabledChanged, (params) => {
  const { enabled, workbook, worksheet } = params
})

// Remove the event listener using `disposable.dispose()`
```
