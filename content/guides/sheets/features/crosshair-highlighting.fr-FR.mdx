La mise en surbrillance en croix met en évidence la ligne et la colonne de la cellule sélectionnée afin de faciliter son repérage.

<PlaygroundFrame lang="fr-FR" slug="sheets/crosshair-highlighting" clickToShow />

## Mode preset

La fonctionnalité de mise en surbrillance en croix ne propose pas de mode preset, mais son plugin peut être utilisé avec un preset.

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### Utilisation

```typescript
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight' // [!code ++]

import '@univerjs/sheets-crosshair-highlight/facade' // [!code ++]

import '@univerjs/sheets-crosshair-highlight/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      SheetsCrosshairHighlightEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    UniverSheetsCrosshairHighlightPlugin, // [!code ++]
  ],
})
```

## Mode plugin

### Installation

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### Utilisation

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight'
import SheetsCrosshairHighlightEnUS from '@univerjs/sheets-crosshair-highlight/locale/en-US'

import '@univerjs/sheets-crosshair-highlight/lib/index.css'

import '@univerjs/sheets-crosshair-highlight/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsCrosshairHighlightEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsCrosshairHighlightPlugin) // [!code ++]
```

## Facade API

Les définitions de types complètes de la Facade API sont disponibles dans la [FacadeAPI](https://reference.univer.ai/en-US).

### Importation

<Callout type="info" title="Remarque sur le mode plugin">
  Seul le mode plugin nécessite d’importer manuellement le package Facade. Le mode preset inclut déjà le package Facade correspondant ; aucun import supplémentaire n’est donc nécessaire.
</Callout>

```typescript
import '@univerjs/sheets-crosshair-highlight/facade'
```

### Activer ou désactiver la mise en surbrillance en croix

```typescript
univerAPI.setCrosshairHighlightEnabled(true)

univerAPI.setCrosshairHighlightEnabled(false)
```

### Obtenir l’état d’activation de la mise en surbrillance en croix

```typescript
univerAPI.getCrosshairHighlightEnabled()
```

### Écouteurs d’événements

Les définitions de types complètes des événements sont disponibles dans la page [Events](https://docs.univer.ai/reference/facade/events).

L’événement `CrosshairHighlightEnabledChanged` est déclenché lorsque l’état d’activation de la mise en surbrillance en croix change.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CrosshairHighlightEnabledChanged, (params) => {
  const { enabled, workbook, worksheet } = params
})

// Remove the event listener using `disposable.dispose()`
```

L’événement `CrosshairHighlightColorChanged` est déclenché lorsque la couleur de la mise en surbrillance en croix change.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CrosshairHighlightColorChanged, (params) => {
  const { color, workbook, worksheet } = params
})

// Remove the event listener using `disposable.dispose()`
```
