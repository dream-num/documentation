图表功能将工作表数据渲染为图表，由图表模型包和 UI 包提供支持。

<PlaygroundFrame lang="zh-CN" slug="sheets/charts" clickToShow />

## 插件模式

```package-install
npm install @univerjs-pro/chart-ui @univerjs-pro/sheets-chart @univerjs-pro/sheets-chart-ui
```

```ts
import ChartUIZhCN from '@univerjs-pro/chart-ui/locale/zh-CN'
import { UniverSheetsChartPlugin } from '@univerjs-pro/sheets-chart'
import { UniverSheetsChartUIPlugin } from '@univerjs-pro/sheets-chart-ui'
import SheetsChartUIZhCN from '@univerjs-pro/sheets-chart-ui/locale/zh-CN'
import SheetsChartZhCN from '@univerjs-pro/sheets-chart/locale/zh-CN'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/chart-ui/facade'
import '@univerjs-pro/sheets-chart/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/sheets-chart-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.ZH_CN,
  locales: {
    [LocaleType.ZH_CN]: mergeLocales(ChartUIZhCN, SheetsChartZhCN, SheetsChartUIZhCN),
  },
})

univer.registerPlugin(UniverSheetsChartPlugin)
univer.registerPlugin(UniverSheetsChartUIPlugin)
```

## 预设模式

`@univerjs/preset-sheets-advanced` 预设已包含图表功能，但运行时仍需要绘图预设。

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

```ts
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'
import UniverPresetSheetsAdvancedZhCN from '@univerjs/preset-sheets-advanced/locales/zh-CN'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreZhCN from '@univerjs/preset-sheets-core/locales/zh-CN'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing'
import UniverPresetSheetsDrawingZhCN from '@univerjs/preset-sheets-drawing/locales/zh-CN'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-advanced/lib/index.css'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.ZH_CN,
  locales: {
    [LocaleType.ZH_CN]: mergeLocales(
      UniverPresetSheetsCoreZhCN,
      UniverPresetSheetsDrawingZhCN,
      UniverPresetSheetsAdvancedZhCN,
    ),
  },
  presets: [UniverSheetsCorePreset(), UniverSheetsDrawingPreset(), UniverSheetsAdvancedPreset()],
})
```

## 创建和更新图表

`worksheet.newChart(type)` 返回一个独立的构建器，此时工作表中还没有图表。只有将 `build()` 的结果传给 `worksheet.insertChart(info)`，图表才会插入工作表。

```ts
const workbook = univerAPI.getActiveWorkbook()
if (!workbook) throw new Error('No active workbook')

const worksheet = workbook.getActiveSheet()
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D6',
    orientation: univerAPI.Enum.ChartSourceOrientation.Columns,
  })
  .setPosition('F2')
  .setSize(640, 360)
  .setCategoryField(0)
  .setValueFields([1, 2, 3])
  .setTitle('Quarterly revenue')
  .build()

const chart = await worksheet.insertChart(info)
chart.setLegend({ visible: true }).bringToFront()

const updatedInfo = chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setSubtitle('FY 2026').build()
await chart.update(updatedInfo)

const svg = await chart.exportImage({ format: 'svg' })
```

图表插入之后，在 `chart` 上调用 setter 会立即生效。若需要完全独立的副本，或需要更改图表类型，可使用 `toBuilder(type)` 配合 `update(info)`。当没有可生成图片的 UI 渲染器时，`exportImage()` 返回 `undefined`。

`worksheet.getCharts()` 和 `worksheet.getChart(id)` 返回实时图表对象。删除图表时调用 `await chart.remove()`；ECharts 共享主题使用 `univerAPI.registerTheme(name, theme)` 注册。

## 图表工作表 [#chart-sheets]

`insertChartSheet()` 为图表单独创建一个标签页。构建图表时，需要显式指定同一工作簿中的某个网格工作表作为数据源，源单元格仍保留在该工作表中。

```ts
import '@univerjs-pro/sheets-chart/facade'

const workbook = univerAPI.getActiveWorkbook()
const data = workbook?.getSheetByName('Data')
if (!workbook || !data) throw new Error('The Data sheet is required')

const info = data
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({ sheetId: data.getSheetId(), range: 'A1:B4' })
  .build()

const chartSheet = await workbook.insertChartSheet(info, { name: 'Sales' })
const primaryChart = chartSheet.getPrimaryChart()
```

`await chart.moveTo(targetSheet)` 用于移动已有图表。图表移入图表工作表后，会成为该工作表中的另一张图表。若要将主图表移出图表工作表，该标签页中不能包含其他内容，移出后该标签页会被删除。移动操作可以撤销，也可以重做。

[`FWorkbook.insertChartSheet()`](/reference/facade/workbook#insertchartsheet) · [`FWorksheet.getPrimaryChart()`](/reference/facade/worksheet#getprimarychart)

## 误差线 [#error-bars]

`setErrorBars()` 可以在构建器或已有图表上调用。基础二维柱形图、条形图、折线图和散点图支持误差线。`seriesIndex` 从 0 开始，并将源数据中的分类字段计算在内。柱形图和折线图使用 `y`，条形图使用 `x`，散点图可以使用任一数值轴。

```ts
chart.setErrorBars([
  { seriesIndex: 1, direction: 'y', type: 'both', valueType: 'percentage', value: 20 },
])
```

[`FChart.setErrorBars()`](/reference/facade/chart#seterrorbars)

## 多级分类轴

当相邻的数据列构成层级关系时，按从根到叶的顺序将其从 0 开始的索引传给 `setCategoryFields()`，然后启用多级分类轴。

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D7',
    orientation: univerAPI.Enum.ChartSourceOrientation.Columns,
  })
  .setCategoryFields([0, 1])
  .setMultiLevelCategoryAxis(true)
  .setValueFields([2, 3])
  .setPosition('F2')
  .build()

const chart = await worksheet.insertChart(info)
chart.setCategoryFields([0, 1]).setMultiLevelCategoryAxis(true)
```

`clearCategoryFields()` 清除该有序映射。`setMultiLevelCategoryAxis(false)` 只关闭层级渲染，已选中的字段仍会保留。

## 支持的图表类型

`univerAPI.Enum.ChartTypeString` 包含以下类型：`Line`、`LineStacked`、`LinePercentStacked`、`Column`、`ColumnStacked`、`ColumnPercentStacked`、`Bar`、`BarStacked`、`BarPercentStacked`、`Pie`、`Donut`、`Area`、`AreaStacked`、`AreaPercentStacked`、`Radar`、`Scatter`、`Combination`、`WordCloud`、`Funnel`、`Bubble`、`Relation`、`Waterfall`、`Pareto`、`Sankey`、`Heatmap`、`Boxplot`、`Candlestick`、`Histogram`、`Treemap`、`Sunburst`、`Gauge` 和 `Chord`。

共享构建器的配置参见[图表 Facade 参考](/reference/facade/chart)。

`LineStacked` 和 `LinePercentStacked` 都是独立的二维图表类型，分别对应堆积折线图和百分比堆积折线图。在服务端渲染或 Office 文件转换中使用它们之前，请确认目标环境支持这两种类型。

## 隐藏数据与独立分类 [#source-mapping]

`setPlotVisibleOnly(false)` 会将隐藏行和列中的值也包含进来，当前设置可使用 `getPlotVisibleOnly()` 读取。当数据源中的值字段有各自的分类列时，`setSeriesToCategory()` 会将每个值字段索引映射到其使用的分类字段索引。这些索引指向原始数据向量，不会因筛选可见系列而重新编号。未写入映射的项沿用共享分类，传入 `{}` 会清除所有覆盖。

例如数据位于 A:D 四列时，D 列的值系列可以使用 C 列作为分类，B 列继续使用共享的 A 列分类。

```ts
const chart = worksheet.getCharts()[0]
if (!chart) throw new Error('No chart')
chart.setPlotVisibleOnly(false)
chart.setSeriesToCategory({ 3: [2] })
```

如需创建聚合的交互式报表，请参见[透视图](/guides/sheets/features/pivot-chart)。

## 三维图表 [#three-dimensional-charts]

三维图表使用相同的插件注册方式。选择三维图表类型后，在独立的构建器上配置视图。

支持的类型包括 `Line3D`、`Column3D`、`ColumnStacked3D`、`ColumnPercentStacked3D`、`Bar3D`、`BarStacked3D`、`BarPercentStacked3D`、`Pie3D`、`Area3D`、`AreaStacked3D` 和 `AreaPercentStacked3D`。

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column3D)
  .setSource('A1:C5')
  .setCategoryField(0)
  .setValueFields([1, 2])
  .setPosition('F18')
  .setSize(640, 360)
  .setThreeD({
    view: { rotX: 20, rotY: 30, rightAngleAxes: false, perspective: 30 },
    gapDepth: 120,
  })
  .build()

await worksheet.insertChart(info)
```

`perspective` 仅在 `rightAngleAxes: false` 的坐标轴图表上生效。`clearThreeD()` 会清除已配置的三维视图设置，但保留三维图表类型和深度轴；若需清除深度轴，请使用 `clearDepthAxis()`。三维坐标轴图表没有次坐标轴，也没有趋势线，`Pie3D` 绘制的是实心饼图。

## 对数数值轴 [#logarithmic-axes]

二维折线图、面积图、柱状图、条形图和组合图均受支持，并可在数值轴上设置 `scaleType: 'log'`。纵向数值轴使用 `setYAxis()`，条形图的横向数值轴使用 `setXAxis()`，已有的次级数值轴使用 `setRightYAxis()` 配置。

默认底数为 `10`。自定义 `logBase` 必须为 `2` 到 `1000` 之间的有限数，可以使用小数，例如 `2.5`；数值轴的上下界必须为正数。零和负数的数据点不会绘制在对数图中，但原始数据保持不变。百分比堆叠图和三维图表不支持对数轴。

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Line)
  .setSource('A1:B5')
  .setYAxis({ scaleType: 'log', logBase: 10 })
  .setPosition('F36')
  .setSize(640, 360)
  .build()

const chart = await worksheet.insertChart(info)

await chart.update(
  chart.toBuilder(univerAPI.Enum.ChartTypeString.Line)
    .setYAxis({ scaleType: 'linear' })
    .build(),
)
```

新图表需要先构建再插入；修改已有图表时，使用 `await chart.update(builder.build())` 应用构建器的结果。将 `scaleType: 'linear'` 设回会移除对数底数；不涉及刻度类型的轴属性修改会保留该底数。
