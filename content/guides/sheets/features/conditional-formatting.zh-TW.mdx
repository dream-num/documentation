條件格式在條件成立時自動改變單元格的格式，使重要的資料和趨勢更醒目。它支援多種條件和格式設定，可讓資料更易於閱讀。

## 外掛模式

### 安裝

```package-install
npm install @univerjs/sheets-conditional-formatting @univerjs/sheets-conditional-formatting-ui
```

### 使用

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsConditionalFormattingPlugin } from '@univerjs/sheets-conditional-formatting' // [!code ++]
import { UniverSheetsConditionalFormattingUIPlugin } from '@univerjs/sheets-conditional-formatting-ui' // [!code ++]
import SheetsConditionalFormattingUIZhTW from '@univerjs/sheets-conditional-formatting-ui/locale/zh-TW' // [!code ++]

import '@univerjs/sheets-conditional-formatting-ui/lib/index.css' // [!code ++]

import '@univerjs/sheets-conditional-formatting/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      SheetsConditionalFormattingUIZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsConditionalFormattingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsConditionalFormattingUIPlugin) // [!code ++]
```

### 建立條件格式規則

[`FWorksheet.newConditionalFormattingRule()`](https://docs.univer.ai/reference/facade/worksheet#newconditionalformattingrule) 返回一個 `FConditionalFormattingBuilder`。透過鏈式呼叫其方法定義規則。

[`FConditionalFormattingBuilder`](/reference/facade/conditional-formatting-builder) 的常用成員方法如下：

| 方法 | 描述 |
| ---- | ---- |
| build | 建置規則 |
| copy | 深拷貝目前構建器 |
| createCfId | 建立條件格式 ID |
| getRanges | 取得目前條件格式的範圍 |
| setRanges | 設定規則應用的範圍 |
| setAverage | 設定平均值規則 |
| setUniqueValues | 設定唯一值規則 |
| setDuplicateValues | 設定重複值規則 |
| setRank | 設定排名規則 |
| setIconSet | 設定圖示集規則 |
| setColorScale | 設定色階規則 |
| setDataBar | 設定資料條規則 |
| setBackground | 設定背景色 |
| setBold | 設定字型加粗 |
| setFontColor | 設定字型顏色 |
| setItalic | 設定字型斜體 |
| setStrikethrough | 設定字型刪除線 |
| setUnderline | 設定字型下劃線 |
| whenCellEmpty | 單元格為空時觸發 |
| whenCellNotEmpty | 單元格非空時觸發 |
| whenDate | 日期落在指定時間段內時觸發 |
| whenFormulaSatisfied | 公式計算結果為 true 時觸發 |
| whenNumberBetween | 數字介於兩個值之間，或等於其中一個時觸發 |
| whenNumberEqualTo | 數字等於給定值時觸發 |
| whenNumberGreaterThan | 數字大於給定值時觸發 |
| whenNumberGreaterThanOrEqualTo | 數字大於或等於給定值時觸發 |
| whenNumberLessThan | 數字小於給定值時觸發 |
| whenNumberLessThanOrEqualTo | 數字小於或等於給定值時觸發 |
| whenNumberNotBetween | 數字不在兩個值之間、也不等於這兩個值時觸發 |
| whenNumberNotEqualTo | 數字不等於給定值時觸發 |
| whenTextContains | 文字包含指定值時觸發 |
| whenTextDoesNotContain | 文字不包含指定值時觸發 |
| whenTextEndsWith | 文字以指定值結尾時觸發 |
| whenTextEqualTo | 文字等於給定值時觸發 |
| whenTextStartsWith | 文字以指定值開頭時觸發 |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 建立一個條件格式規則，使範圍 A1:T100 中的非空單元格字型變為斜體，背景色為紅色，字型顏色為綠色
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)
```

### 獲取條件格式規則

- `FWorksheet.getConditionalFormattingRules()` 獲取工作表的所有條件格式規則
- `FRange.getConditionalFormattingRules()` 獲取範圍的所有條件格式規則

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// 獲取活動工作表的所有條件格式規則
const fWorksheet = fWorkbook.getActiveSheet()
const rulesOfSheet = fWorksheet.getConditionalFormattingRules()

// 獲取範圍 A1:T100 的所有條件格式規則
const fRange = fWorksheet.getRange('A1:T100')
const rulesOfRange = fRange.getConditionalFormattingRules()
```

### 刪除條件格式規則

`FWorksheet.deleteConditionalFormattingRule(cfId)` 從工作表中刪除一條規則。`cfId` 是該規則的 ID。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// 刪除第一個規則
fWorksheet.deleteConditionalFormattingRule(rules[0]?.cfId)
```

### 更新條件格式規則

`FWorksheet.setConditionalFormattingRule(cfId, rule)` 替換工作表中的一條規則。`cfId` 是要替換的規則 ID，`rule` 是新規則。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 建立一個條件格式規則，使非空單元格字型變為斜體，背景色為紅色，字型顏色為綠色
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)

// 修改第一個規則應用到新的範圍
const rules = fWorksheet.getConditionalFormattingRules()
const newRuleRange = fWorksheet.getRange('A1:D10')
fWorksheet.setConditionalFormattingRule(rules[0]?.cfId, { ...rules[0], ranges: [newRuleRange.getRange()] })
```

### 修改條件格式規則的優先順序

`FWorksheet.moveConditionalFormattingRule(cfId, toCfId, type)` 改變規則在優先順序順序中的位置。`cfId` 是要移動的規則，`toCfId` 是作為參照的規則，`type` 是移動型別（例如 'before'、'after'）。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// 移動第三個規則到第一個規則之前
const rule = rules[2]
const targetRule = rules[0]
fWorksheet.moveConditionalFormattingRule(rule?.cfId, targetRule?.cfId, 'before')
```

### 清除所有條件格式規則

- `FWorksheet.clearConditionalFormatRules()` 清除工作表的所有條件格式規則
- `FRange.clearConditionalFormatRules()` 清除範圍的所有條件格式規則

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// 清除活動工作表的所有條件格式規則
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.clearConditionalFormatRules()

// 清除範圍 A1:T100 的所有條件格式規則
const fRange = fWorksheet.getRange('A1:T100')
fRange.clearConditionalFormatRules()
```

## 重用規則描述與預覽 [#custom-rule-ui]

如需自行建置規則列表，從 `@univerjs/sheets-conditional-formatting-ui` 匯入 `getRuleDescribe` 和 `ConditionalFormattingRulePreview`。完整規則傳給 `getRuleDescribe(rule, localeService)`，預覽只接收規則配置 `rule.rule`。預覽顯示配置後的外觀，不計算工作表單元格的實際結果。預覽需要在 Univer 的 React 上下文中渲染。

`CF_PANEL_KEY` 標識內建面板，[元件覆蓋](/guides/sheets/ui/components)可透過它指定目標面板。`IConditionFormattingPanelProps.onEditorExit` 在編輯結束時觸發，包括提交後、取消後，以及工作表被啟用或被移除時。它不表示儲存成功，也不表示側邊欄已關閉。

```tsx
import type { IConditionFormattingRule } from '@univerjs/sheets-conditional-formatting'
import { LocaleService } from '@univerjs/core'
import { ConditionalFormattingRulePreview, getRuleDescribe } from '@univerjs/sheets-conditional-formatting-ui'
import { useDependency } from '@univerjs/ui'

interface IRuleSummaryProps {
  rule: IConditionFormattingRule
}

function RuleSummary({ rule }: IRuleSummaryProps) {
  const localeService = useDependency(LocaleService)

  return (
    <div>
      <span>{getRuleDescribe(rule, localeService)}</span>
      <ConditionalFormattingRulePreview rule={rule.rule} />
    </div>
  )
}
```

## 規則優先順序與「若為真則停止」 [#stop-if-true]

規則按優先順序順序應用。對於同一個單元格，命中的高亮規則如果帶有 `stopIfTrue: true`，會抑制優先順序更低的規則，即使該規則本身未設定樣式。規則未命中時，繼續向下評估。優先順序更高的規則結果仍然有效。規則編輯器僅在高亮規則上提供此選項，色階、資料條和圖示集沒有該選項。

範例先新增低優先順序的背景規則，因為新新增的規則會排在列表最前面。啟用停止選項後，90 僅加粗，不顯示綠色背景；60 仍然帶有背景。`stopIfTrue` 位於規則物件外層，而不在 `rule` 內。

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

const ranges = [sheet.getRange('B2:B10').getRange()]
const backgroundRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(50)
  .setBackground('#DCFCE7')
  .setRanges(ranges)
  .build()
const priorityRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(80)
  .setBold(true)
  .setRanges(ranges)
  .build()

sheet.addConditionalFormattingRule(backgroundRule)
sheet.addConditionalFormattingRule({ ...priorityRule, stopIfTrue: true })
```
