La validación de datos aplica reglas a las células y los controles introducidos valores en su contra. Se detecta errores de entrada temprano y mantiene los datos en una hoja precisa y consistente.

Univer admite los siguientes tipos de validación:
- Número
- Entero
- Longitud del texto
- Fecha
- Casilla de verificación
- Lista desplegable (selección única/múltiple)
- Fórmula personalizada

## Modo de complemento

### Instalación

```package-install
npm install @univerjs/data-validation @univerjs/sheets-data-validation @univerjs/sheets-data-validation-ui
```

### Uso

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDataValidationPlugin } from '@univerjs/data-validation' // [!code ++]
import { UniverSheetsDataValidationPlugin } from '@univerjs/sheets-data-validation' // [!code ++]

import '@univerjs/sheets-data-validation-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-data-validation/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(

univer.registerPlugin(UniverDataValidationPlugin) // [!code ++]
```

## Coincidencia de valores [#value-matching]

La validación de listas no distingue mayúsculas de minúsculas, así que `green` satisface una opción escrita `Green`, y una lista referenciada sigue la misma regla. Las reglas de número y de entero solo aceptan texto numérico. Los valores booleanos y el texto en blanco no las satisfacen.

### Agregar una regla de validación de datos

[`univerAPI.newDataValidation()`](https://docs.univer.ai/reference/facade/univer#newdatavalidation) crea un constructor y devuelve un `FDataValidationBuilder`. Llame sus métodos en una cadena para construir la regla.

Los métodos principales en [`FDataValidationBuilder`](/reference/facade/data-validation-builder) son:

| Método | Descripción |
| ------ | ----------- |
| build | Construye la regla. |
| requireCheckbox | Requiere un valor booleano, que la célula muestra como una casilla de verificación. |
| requireDateAfter | Establece el tipo a DATE y requiere una fecha después de la fecha dada. |
| requireDateBefore | Establece el tipo a DATE y requiere una fecha antes de la fecha dada. |
| requireDateBetween | Establece el tipo a DATE y requiere una fecha dentro del rango dado. |
| requireDateEqualTo | Establezca el tipo a DATE y requiera una fecha igual a la fecha dada. |
| requireDateNotBetween | Establece el tipo a DATE y requiere una fecha fuera del rango dado. |
| requireDateOnOrAfter | Establezca el tipo a DATE y requiera una fecha en o después de la fecha dada. |
| requireDateOnOrBefore | Establezca el tipo a DATE y requiera una fecha en o antes de la fecha dada. |
| requireFormulaSatisfied | Requiere la fórmula dada para evaluar a `true`. |
| requireNumberBetween | Requiere un número entre los dos números dados, inclusivo. |
| requireNumberEqualTo | Requiere un número igual al valor dado. |
| requireNumberGreaterThan | Requiere un número mayor que el valor dado. |
| requireNumberGreaterThanOrEqualTo | Requiere un número mayor o igual al valor dado. |
| requireNumberLessThan | Requiere un número menos que el valor dado. |
| requireNumberLessThanOrEqualTo | Requiere un número menor o igual al valor dado. |
| requireNumberNotBetween | Requiere un número que no es entre los dos números dados y no igual a ninguno de los dos. |
| requireNumberNotEqualTo | Requiere un número que no sea igual al valor dado. |
| requireValueInList | Requiere un valor de una lista de valores específicos. Apoya la selección individual/multiple y muestra o oculta el desplegable. |
| requireValueInRange | Requiere un valor dentro de un rango específico. Apoya la selección individual/multiple y muestra o oculta la desplegable. |
| setOptions | Establecer las opciones para la regla. |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new data validation rule that requires a number between 1 and 10 for the range A1:B10
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: 'Please enter a number between 1 and 10',
  })
  .build()
fRange.setDataValidation(rule)
```

### Obtener validaciones de datos de rango/hoja de trabajo

El objeto de la regla devuelta es una instancia `FDataValidation`, que expone los criterios, opciones y otros ajustes de la regla.

Los métodos principales en [`FDataValidation`](https://docs.univer.ai/reference/facade/data-validation) son:

| Método | Descripción |
| ---- | ---- |
| copy | Cree una nueva instancia FDataValidationBuilder del objeto de regla actual. |
| getCriteriaType | Obtenga el tipo de validación de la regla. |
| getCriteriaValues | Obtenga los valores utilizados para evaluar los criterios. |
| getHelpText | Obtenga el texto de ayuda, que proporciona orientación a los usuarios. |
| getRanges | Obtenga los rangos a los que se aplica la regla. |
| setCriteria | Establezca los criterios de la regla. |
| setOptions | Establezca las opciones de la regla. |
| setRanges | Establecer los rangos a los que se aplica la regla. |
| delete | Eliminar la regla de la hoja de trabajo. |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all data validation rules in current sheet.
const rulesOfSheet = fWorksheet.getDataValidations()

// Get a data validation rule by rule ID.
const ruleById = fWorksheet.getDataValidation(rulesOfSheet[0]?.rule?.uid)

const fRange = fWorksheet.getRange('A1:B10')

// Get first data validation rule in current range.
const ruleOfRange = fRange.getDataValidation()
console.log('ruleOfRange:', ruleOfRange, ruleOfRange?.getCriteriaValues())

// Get all data validation rules in current range.
const rulesOfRange = fRange.getDataValidations()
```

### Actualizar/eliminar validación de datos

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new data validation rule that requires a number equal to 20 for the range A1:B10
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberEqualTo(20)
  .build()
fRange.setDataValidation(rule)

const newRuleRange = fWorksheet.getRange('C1:D10')

// Update the rule after 3 seconds
setTimeout(() => {
  fRange.getDataValidation()
    // Change the range to C1:D10
    .setRanges([newRuleRange])
    // Change the criteria to require a number between 1 and 10
    .setCriteria(
      univerAPI.Enum.DataValidationType.DECIMAL,
      [univerAPI.Enum.DataValidationOperator.BETWEEN, '1', '10'],
    )
    // Change option to stop input on validation errors and show error message
    .setOptions({
      allowBlank: true,
      showErrorMessage: true,
      error: 'Please enter a valid value',
      errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
    })
}, 3000)

// Delete the rule after 6 seconds
setTimeout(() => {
  newRuleRange.getDataValidation().delete()
}, 6000)
```

### Obtener errores de validación

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all data validation errors for current workbook.
const workbookErrors = await fWorkbook.getAllDataValidationErrorAsync()
console.log('workbookErrors:', workbookErrors)

// Get all data validation errors for current sheet.
const worksheetErrors = await fWorksheet.getAllDataValidationErrorAsync()
console.log('worksheetErrors:', worksheetErrors)

// Get data validation errors for current range.
const fRange = fWorksheet.getRange('A1:B10')
const rangeErrors = await fRange.getDataValidationErrorAsync()
console.log('rangeErrors:', rangeErrors)
```

Cada objeto de error contiene los siguientes campos:
- `sheetName`: Nombre de la hoja de trabajo donde se produjo el error
- `row`: Índice de fila de la célula que activa el error
- `column`: Índice de columna de la célula que activa el error
- `ruleId`: ID de la regla que activa el error
- `inputValue`: Valor de entrada que activa el error
- `rule`: Captura del contenido de la regla

### Obtener validador status

El estado del validador es un valor del enum `DataValidationStatus`:
- `valid`: el valor de la celda pasa la validación
- `invalid`: el valor de la celda no supera la validación
- `validating`: la celda se está validando

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get data validation validator status for current workbook.
fWorkbook.getValidatorStatus().then((status) => {
  console.log('===statusOfWorkbook', status)
})

// Get data validation validator status for current sheet.
fWorksheet.getValidatorStatusAsync().then((status) => {
})

fRange.getValidatorStatus().then((status) => {
  console.log('===tatusOfRange', status)

```

### Oyentes de eventos

Las definiciones completas del tipo de evento están en [Eventos](https://docs.univer.ai/reference/facade/events).

El módulo de validación de datos emite eventos cuando se agregan, actualizan o eliminan reglas, y cuando cambia el estado de validación. Utilice `univerAPI.addEvent()` para escuchar cualquiera de estos eventos.

#### Eventos de cambio de regla de validación

`univerAPI.Event.SheetDataValidationChanged` dispara después de que cambie una regla de validación.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidationChanged, (params) => {
  const { origin, worksheet, workbook, changeType, oldRule, rule } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationAdd` dispara antes de que se añada una regla.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationAdd, (params) => {
  const { worksheet, workbook, rule } = params

  // Cancel the data validation rule addition operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationDelete` dispara antes de que se elimina una regla.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDelete, (params) => {
  const { worksheet, workbook, ruleId, rule } = params

  // Cancel the data validation rule deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationDeleteAll` dispara antes de que se eliminan todas las reglas.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDeleteAll, (params) => {
  const { worksheet, workbook, rules } = params

  // Cancel the data validation rule deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Eventos de actualización de reglas de validación

`univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate` dispara antes de que cambien los criterios de una regla.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newCriteria } = params

  // Cancel the data validation rule criteria update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationRangeUpdate` dispara antes de que cambien los rangos de una regla.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationRangeUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newRanges } = params

  // Cancel the data validation rule range update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationOptionsUpdate` dispara antes de que las opciones de una regla cambien.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationOptionsUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newOptions } = params

  // Cancel the data validation rule options update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Eventos de estado de validación

`univerAPI.Event.SheetDataValidatorStatusChanged` dispara cuando el estado de validación de una célula cambia.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidatorStatusChanged, (params) => {
  const { worksheet, workbook, row, column, status, rule } = params
})

// Remove the event listener, use `disposable.dispose()`
```

Cada evento incluye los siguientes parámetros comunes:
- `workbook`: Instancia de libro de trabajo actual
- `worksheet`: Instancia de hoja de trabajo actual

Algunos eventos también incluyen:
- `rule`: El objeto de regla de validación relacionado
- `ruleId`: Unico identificador de la regla
- `status`: estado de validación (sólo en `SheetDataValidatorStatusChanged`)
- `newCriteria`: Nuevos criterios de validación (sólo en `BeforeSheetDataValidationCriteriaUpdate`)
- `newRanges`: Nuevos rangos de validación (sólo en `BeforeSheetDataValidationRangeUpdate`)
- `newOptions`: Nuevas opciones de validación (sólo en `BeforeSheetDataValidationOptionsUpdate`)

Para cualquier evento cuyo nombre comienza con `Before`, coloque `params.cancel = true` en el callback para detener la operación.

### Estilo de error

`errorStyle` controla lo que sucede cuando se introducen datos inválidos. Acepta un valor `DataValidationErrorStyle`:
- `STOP`: Rechaza la entrada inválida
- `WARNING`: Acepta la entrada inválida y muestra una advertencia
- `INFO`: Acepta la entrada inválida y muestra un mensaje de información

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B10')

const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: 'Please enter a number between 1 and 10',
    errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
  })
  .build()
fRange.setDataValidation(rule)
```

### Cambiar modo de renderizado de lista

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

const fRange = fWorksheet.getRange('A1:B10')

fRange.getDataValidation()?.setOptions({
```
