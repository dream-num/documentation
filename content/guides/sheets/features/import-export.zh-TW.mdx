## 支援的格式

下表列出本頁前端 API 支援的格式。Office 檔案轉換還需要後端支援相同的文件型別和格式。

| 匯入 | 匯出 |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV、TSV 只匯出一個工作表，不保留工作簿樣式和其他工作表。匯出時傳入 `ExchangeFormat.CSV` 或 `ExchangeFormat.TSV` 以及 `sheetId`，預設使用 XLSX。即使轉換後端支援 `.xlsm`，前端 API 也不接受該格式。

## Facade API [#facade-api]

### 匯入

<Callout type="info" title="外掛模式提示">
  僅外掛模式需要手動引入 Facade 包。預設模式已內建對應的包，無需再次匯入。
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/sheets-exchange-client/facade'
```

### 匯入 `.xlsx`

#### 匯入 `.xlsx` 檔案並獲取 `unitId`

<Callout type="warning" title="注意事項">
  該方法依賴協同服務：匯入後會在伺服器端建立文件並返回 `unitId`。未啟用協同服務時，請改用快照匯入。
</Callout>

啟用協同編輯後，每個文件都有唯一的 `unitId`。向 `univerAPI.importSheetToUnitIdAsync` 傳入 `file`，該方法返回 `unitId`，用於開啟文件。`file` 可以是 `File` 物件，也可以是遠端檔案的 URL。

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importSheetToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadSheetAsync(unitId)
}
```

#### 匯入 `.xlsx` 檔案並獲取 `IWorkbookData`

快照匯入不依賴協同服務；需要協同文件時，請改用 `unitId` 匯入。`univerAPI.importSheetToSnapshotAsync` 匯入 `.xlsx` 檔案，返回 `IWorkbookData` 格式的文件資料。

```typescript
// 接受 File 物件
const snapshot = await univerAPI.importSheetToSnapshotAsync(file)
// 或者接受遠端檔案的 URL
// const snapshot = await univerAPI.importSheetToSnapshotAsync('https://example.com/filename.xlsx');

// 透過快照建立一個新的工作簿
if (snapshot) univerAPI.createWorkbook(snapshot)
```

### 匯出 `.xlsx`

#### 透過 `unitId` 匯出 `.xlsx` 檔案

<Callout type="warning" title="注意事項">
  透過 `unitId` 匯出依賴協同服務。未啟用協同服務時，請改用快照匯出。
</Callout>

啟用協同編輯後，每個文件都有唯一的 `unitId`。將該 `unitId` 傳給 `univerAPI.exportSheetByUnitIdAsync`，該方法返回一個 `File` 物件。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook.getId()
const file = await univerAPI.exportSheetByUnitIdAsync(unitId)

// 透過 Facade API 下載檔案
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

#### 透過 `IWorkbookData` 匯出 `.xlsx` 檔案

<Callout>快照匯出不依賴協同服務，適合僅在本機處理資料的場景。</Callout>

將 `IWorkbookData` 傳給 `univerAPI.exportSheetBySnapshotAsync`，該方法返回一個 `File` 物件。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
const file = await univerAPI.exportSheetBySnapshotAsync(snapshot)

// 透過 Facade API 下載檔案
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

## 移除內建匯入匯出選單和 UI 互動 [#import-export-ui-migration]

<Callout type="warning" title="注意事項">
  從 **1.2.0** 版本開始，Univer 不再內建匯入匯出選單和 UI 互動。底層服務和 Facade API 仍然可用。
</Callout>

如果應用仍需保留這些選單和互動，可參考[內建匯入匯出選單和 UI 互動遷移方案](https://office.univer.ai/zh-CN/showcase/sheets/custom-import-export)，透過自定義外掛恢復這些功能。範例提供完整原始碼，支援線上檢視和下載。
