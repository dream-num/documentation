Расширенный механизм формул оптимизирует исходный механизм, повышая производительность вычислений и расширяя функциональность. Он поддерживает разнообразные сложные вычисления, способен обрабатывать большие наборы данных и предоставляет улучшенные средства обработки ошибок и отладки.

## Режим предустановки

Расширенный механизм формул входит в предустановку `@univerjs/preset-sheets-advanced`.

### Установка

<Callout>
  Предустановка `UniverSheetsAdvancedPreset` из пакета `@univerjs/preset-sheets-advanced` во время выполнения зависит от предустановки `UniverSheetsDrawingPreset`. Сначала установите `@univerjs/preset-sheets-drawing`.
</Callout>

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

### Использование

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
import UniverPresetSheetsAdvancedEnUS from '@univerjs/preset-sheets-advanced/locales/en-US' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]
import UniverPresetSheetsDrawingEnUS from '@univerjs/preset-sheets-drawing/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-advanced/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsDrawingEnUS, // [!code ++]
      UniverPresetSheetsAdvancedEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsDrawingPreset(), // [!code ++]
    UniverSheetsAdvancedPreset(), // [!code ++]
  ],
})
```

Если у вас есть коммерческая лицензия Univer, инструкции по настройке см. в разделе [«Использование лицензии в клиенте»](/guides/license#in-preset-mode).

## Режим плагина

### Установка

```package-install
npm install @univerjs-pro/engine-formula
```

### Использование

Чтобы использовать расширенный механизм формул, замените исходный `UniverFormulaEnginePlugin` на `UniverProFormulaEnginePlugin`.

```typescript
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula' // [!code ++]
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula' // [!code --]

univer.registerPlugin(UniverFormulaEnginePlugin) // [!code --]
univer.registerPlugin(UniverProFormulaEnginePlugin) // [!code ++]
```

Если у вас есть коммерческая лицензия Univer, инструкции по настройке см. в разделе [«Использование лицензии в клиенте»](/guides/license#in-plugin-mode).
