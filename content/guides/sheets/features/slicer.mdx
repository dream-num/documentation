Slicers filter Tables, PivotTables, and PivotCharts by source members. Timelines filter supported original Pivot date fields; Table columns, text fields, calculated fields, and derived grouping fields cannot be Timeline sources.

## Plugin setup [#plugin-mode]

Add the following to your existing [Sheets setup](/guides/sheets/getting-started/installation), with [drawing support](/guides/sheets/features/images) and the [Table](/guides/sheets/features/table) or [PivotTable](/guides/sheets/features/pivot-table) source configured. Load the locale and register these plugins before creating the workbook.

```package-install
npm install @univerjs-pro/sheets-slicer @univerjs-pro/sheets-slicer-ui
```

```ts
import { UniverSheetsSlicerPlugin } from '@univerjs-pro/sheets-slicer'
import { UniverSheetsSlicerUIPlugin } from '@univerjs-pro/sheets-slicer-ui'
import SheetsSlicerUILocale from '@univerjs-pro/sheets-slicer-ui/locale/en-US'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/sheets-slicer/facade'
import '@univerjs-pro/sheets-slicer-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.EN_US, SheetsSlicerUILocale)
univer.registerPlugin(UniverSheetsSlicerPlugin)
univer.registerPlugin(UniverSheetsSlicerUIPlugin)
```

## Create a slicer [#create-slicer]

This example uses a PivotTable at I1 on the active sheet with a source field named `Region`. Obtain its stable original field ID with `getSourceFieldsInfo()`; display names and report field IDs cannot be passed to `newSlicer()`.

```ts
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook?.getActiveSheet()
if (!fWorkbook || !fWorksheet) throw new Error('No active worksheet')

const pivotTable = fWorkbook.getPivotTableByCell(
  fWorkbook.getId(),
  fWorksheet.getSheetId(),
  0,
  8,
)
const regionField = pivotTable?.getSourceFieldsInfo().find((field) => field.name === 'Region')
if (!pivotTable || !regionField) throw new Error('Region source field not found')

const slicer = await fWorksheet.insertSlicer(
  pivotTable.newSlicer(regionField.id)
    .setCaption(regionField.name)
    .setPosition('N2')
    .build(),
)
```

`pivotTable.newSlicer()` binds the builder to its source. `build()` only prepares the configuration; `insertSlicer()` creates the control. The host and source sheets may differ, but must be in the same workbook. For a Table source, use `fWorksheet.newSlicer(columnId).setTableReference({ subUnitId, tableId })`, where `columnId` is the stable Table column ID.

## Create a timeline [#create-timeline]

Continuing with the same PivotTable, this example requires an original date field named `Date`. `newTimeline()` validates the source and rejects unsupported fields. Timeline range APIs use Excel serial values in the workbook’s date system, not JavaScript `Date` objects.

```ts
const dateField = pivotTable.getSourceFieldsInfo().find((field) => field.name === 'Date')
if (!dateField) throw new Error('Date source field not found')

const timeline = await fWorksheet.insertTimeline(
  pivotTable.newTimeline(dateField.id)
    .setCaption(dateField.name)
    .setLevel(univerAPI.Enum.TimelineLevel.Month)
    .setPosition('N18')
    .build(),
)
```

## Find controls and observe changes [#controls-and-events]

Use `getSlicer(viewId)` / `getSlicers()` and `getTimeline(viewId)` / `getTimelines()` on the host worksheet. `viewId` is the business ID returned by the control’s `getId()`, not its drawing ID.

Listen to `SlicerAdded`, `SlicerChanged`, `SlicerRemoved`, `TimelineAdded`, `TimelineChanged`, and `TimelineRemoved` through `univerAPI.addEvent()`. Events describe committed local changes, not remote saving or completed rendering. Dispose the returned subscription when it is no longer needed.
