A slicer filters Tables, PivotTables, and PivotCharts by the members of a source. A timeline filters the original date fields of a Pivot that can serve as a source. Table columns, text fields, calculated fields, and derived grouping fields cannot be timeline sources.

## Plugin Mode [#plugin-mode]

### Installation

```package-install
npm install @univerjs-pro/sheets-slicer @univerjs-pro/sheets-slicer-ui
```

### Usage

Add the following to your existing [Sheets setup](/guides/sheets/getting-started/installation), with [drawing support](/guides/sheets/features/images) and a [Table](/guides/sheets/features/table) or [PivotTable](/guides/sheets/features/pivot-table) source already configured. Load the locale and register these plugins before creating the workbook.

```ts
import { UniverSheetsSlicerPlugin } from '@univerjs-pro/sheets-slicer'
import { UniverSheetsSlicerUIPlugin } from '@univerjs-pro/sheets-slicer-ui'
import SheetsSlicerUILocale from '@univerjs-pro/sheets-slicer-ui/locale/en-US'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/sheets-slicer/facade'
import '@univerjs-pro/sheets-slicer-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.EN_US, SheetsSlicerUILocale)
univer.registerPlugin(UniverSheetsSlicerPlugin)
univer.registerPlugin(UniverSheetsSlicerUIPlugin)
```

### Installation

```package-install
npm install @univerjs/presets @univerjs/preset-sheets-core @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

### Usage

The advanced preset includes the slicer and timeline model and UI plugins, along with their Facade APIs. Combine it with the core and drawing presets and merge the locale packages. If the advanced preset is already in use, add `slicer` to that registration rather than registering it a second time. Configure the client license as described in [using a license](/server/license).

```ts
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'
import AdvancedLocale from '@univerjs/preset-sheets-advanced/locales/en-US'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import CoreLocale from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing'
import DrawingLocale from '@univerjs/preset-sheets-drawing/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css'
import '@univerjs/preset-sheets-advanced/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(CoreLocale, DrawingLocale, AdvancedLocale),
  },
  presets: [
    UniverSheetsCorePreset({ container: 'app' }),
    UniverSheetsDrawingPreset(),
    UniverSheetsAdvancedPreset({ slicer: { maxMemberWindowSize: 200 } }),
  ],
})
```

When you use a [Worker](/guides/sheets/getting-started/worker), set `useWorker: true` on the advanced preset and register `UniverSheetsAdvancedWorkerPreset()` in the Worker. That preset also includes the slicer calculation plugin.

## Create a slicer [#create-slicer]

The example below uses a PivotTable at I1 on the active sheet and a source field named `Region`. Call `getSourceFieldsInfo()` to obtain the field's stable original ID. Display names and report field IDs cannot be passed to `newSlicer()`.

```ts
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook?.getActiveSheet()
if (!fWorkbook || !fWorksheet) throw new Error('No active worksheet')

const pivotTable = fWorkbook.getPivotTableByCell(
  fWorkbook.getId(),
  fWorksheet.getSheetId(),
  0,
  8,
)
const regionField = pivotTable?.getSourceFieldsInfo().find((field) => field.name === 'Region')
if (!pivotTable || !regionField) throw new Error('Region source field not found')

const slicer = await fWorksheet.insertSlicer(
  pivotTable.newSlicer(regionField.id)
    .setCaption(regionField.name)
    .setPosition('N2')
    .build(),
)
```

`pivotTable.newSlicer()` binds the builder to that source. `build()` only assembles the configuration; `insertSlicer()` creates the control. The host sheet and the source sheet can differ, but both must be in the same workbook. For a Table source, call `fWorksheet.newSlicer(columnId).setTableReference({ subUnitId, tableId })`, where `columnId` is the Table column's stable ID.

## Create a timeline [#create-timeline]

This example uses the same PivotTable and requires an original date field named `Date`. `newTimeline()` validates the source and rejects unsupported fields. Timeline range APIs take Excel serial values in the workbook's date system, not JavaScript `Date` objects.

```ts
const dateField = pivotTable.getSourceFieldsInfo().find((field) => field.name === 'Date')
if (!dateField) throw new Error('Date source field not found')

const timeline = await fWorksheet.insertTimeline(
  pivotTable.newTimeline(dateField.id)
    .setCaption(dateField.name)
    .setLevel(univerAPI.Enum.TimelineLevel.Month)
    .setPosition('N18')
    .build(),
)
```

## Find controls and observe changes [#controls-and-events]

On the host worksheet, `getSlicer(viewId)` / `getSlicers()` and `getTimeline(viewId)` / `getTimelines()` locate the controls. `viewId` is the business ID that the control's `getId()` returns, not its drawing ID.

Register `SlicerAdded`, `SlicerChanged`, `SlicerRemoved`, `TimelineAdded`, `TimelineChanged`, and `TimelineRemoved` through `univerAPI.addEvent()`. An event indicates that a local change was committed. It does not indicate that the change was saved remotely or that rendering has finished. Dispose the returned subscription when it is no longer needed.

## Member queries and shared filters [#shared-filters]

`setSelection()` expects typed source values. The number `1`, the string `'1'`, and a blank are three different members, so do not pass display labels or indexes from the visible list. Every view of the same cache, and every report connected to it, shares the filter. With a Table source, the selection replaces that column's filter and leaves the other columns unchanged. Call `clearFilter()` to clear the filter.

```ts
import { FilterSelectionMode, RecordValueType } from '@univerjs/core'

const accepted = await slicer.setSelection({
  mode: FilterSelectionMode.Include,
  values: [{ type: RecordValueType.String, value: 'EMEA' }],
})
```

`getItems({ start, count })` reads a window of items rather than the whole source, and reading does not change the selection. A request defaults to 100 items and is capped by `maxMemberWindowSize` (default 200, a positive integer). Selections that fall outside the visible window are retained. `setConnections()` replaces the Pivot report connections; use `getConnectionCandidates()` to discover reports that can connect. Editing requires the relevant worksheet permissions. See [FSheetSlicer](/reference/facade/sheet-slicer).

## Timeline date conditions [#date-conditions]

`setSelection({ startDate, endDate, useWholeDay: true })` expands fractional bounds to whole days, while an integer end remains exclusive. Without `useWholeDay`, the interval is exactly `[startDate, endDate)`. A fixed date condition shared from a PivotTable can be non-contiguous; `getDateCondition()` reads it in that case. For such a condition, `getSelection()` returns `undefined`, so that result alone does not indicate that the timeline is unfiltered.
