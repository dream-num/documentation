Диаграммы — важный инструмент визуализации, который помогает нагляднее представлять и анализировать данные. В Univer Sheets доступны различные типы диаграмм, в том числе столбчатые, линейные и круговые. Пользователь может выбрать подходящий тип диаграммы в зависимости от того, как нужно представить данные.

## Режим предустановок

Функция диаграмм входит в предустановку `@univerjs/preset-sheets-advanced`.

### Установка

<Callout>
  Предустановка `UniverSheetsAdvancedPreset` из пакета `@univerjs/preset-sheets-advanced` во время выполнения зависит от предустановки `UniverSheetsDrawingPreset`. Сначала установите `@univerjs/preset-sheets-drawing`.

### Вставка диаграммы

Метод `FWorksheet.newChart()` создаёт построитель диаграммы и возвращает экземпляр `FChartBuilderBase`. Свойства диаграммы можно задавать с помощью цепочки вызовов методов.

Затем вызовите `build()`, чтобы создать объект `IChartBuilderInfo`, и передайте его методу `FWorksheet.insertChart(chartBuildInfo: IChartBuilderInfo)` для вставки диаграммы на лист.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a column chart with data source A1:D6.
// The starting position is upper-left corner of cell B2.
// The width of the chart is 600 and the height is 400.
const chartInfo = fWorksheet.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
  .setWidth(600)
  .setHeight(400)
  .build()
await fWorksheet.insertChart(chartInfo)
```

| Метод | Описание |

| addRange | Задаёт диапазон исходных данных диаграммы |
| setPosition | Задаёт положение диаграммы с привязкой к строке и столбцу |
| setAbsolutePosition | Задаёт положение диаграммы в пикселях |
| setChartType | Задаёт тип диаграммы |
| setWidth | Задаёт ширину диаграммы |
| setHeight | Задаёт высоту диаграммы |
| setOptions | Задаёт параметры диаграммы |
| setTransposeRowsAndColumns | Меняет строки и столбцы местами |
| setTheme | Задаёт тему |
| setXAxisTitle | Задаёт название оси X |
| setYAxisTitle | Задаёт название оси Y |
| setRightYAxisTitle | Задаёт название правой оси Y |
| setXAxisTextStyle | Задаёт стиль названия оси X |
| setYAxisTextStyle | Задаёт стиль названия оси Y |
| setRightYAxisTextStyle | Задаёт стиль названия правой оси Y |
| setInvalidValueStrategy | Задаёт режим отображения пустых ячеек |
| setAxisPointerStyle | Задаёт стиль указателя оси |
| setAllSeriesStyle | Задаёт стили всех рядов данных |
| setSeriesStyle | Задаёт стиль ряда данных по его индексу |
| build | Создаёт данные построителя для вставки или обновления диаграммы |

Параметры конфигурации задаются с помощью метода setOptions одним из двух способов:
  - `setOptions(optionPath, optionVal)`: `setOptions('legend.color', '#ff0000')`
  - `setOptions('', IChartBuildOptions)`: `setOptions('', { legend: { color: '#ff0000', bold: true } })`

  ```typescript
  const fWorkbook = univerAPI.getActiveWorkbook()

    .build()
  const fChart = await fWorksheet.insertChart(chartInfo)
  ```

```typescript
const lineChartBuilder = fWorkSheet.newChart().asLineChart()
const pieChartBuilder = fWorkSheet.newChart().asPieChart()
const radarChartBuilder = fWorkSheet.newChart().asRadarChart()

// Or you can use the following method to create a chart builder
const chartBuilder = fWorkSheet.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
```

```typescript
const fWorksheet = fWorkbook.getActiveSheet()

// Get all charts on the active sheet.

```

### Обновление диаграммы

Метод `FWorksheet.updateChart(chartBuildInfo: IChartBuilderInfo)` обновляет диаграмму. Для изменения её конфигурации передайте методу объект `IChartBuilderInfo`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a column chart with data source A1:D6.
// The starting position is upper-left corner of cell B2.
const chartInfo = fWorksheet.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
  .build()
await fWorksheet.insertChart(chartInfo)

// Get all charts on the active sheet.
const charts = fWorksheet.getCharts()

// Update the first chart after 3 seconds.
setTimeout(() => {
  const newChartInfo = fWorksheet.newChart(charts[0])
    .asLineChart()
    .setOptions('legend.position', univerAPI.Enum.LegendPositionEnum.Right)
    .build()
  fWorksheet.updateChart(newChartInfo)
}, 3000)
```

Метод `FWorksheet.removeChart(chart: FChart)` удаляет указанную диаграмму. Передайте ему соответствующий объект `FChart`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a column chart with data source A1:D6.
// The starting position is upper-left corner of cell B2.
const chartInfo = fWorksheet.newChart()
```

### Тема диаграммы

Метод `FWorksheet.registerChartTheme(themeName: string, theme: IEchartTheme)` регистрирует пользовательскую тему диаграммы. Передайте ему название темы и объект темы.

Диаграммы Univer реализованы на основе библиотеки echarts, поэтому для создания собственной темы можно использовать [конструктор тем echart](https://echarts.apache.org/en/theme-builder.html).
На этом сайте можно создать тему и скачать её в виде файла конфигурации. Чтобы применить собственную тему, используйте следующий API:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// register your theme
const theme = { // your theme object
  version: 1,
  themeName: 'myTheme',
  theme: {
    // ... Some code is omitted for brevity
    color: [
      '#893448',
      '#d95850',
      '#eb8146',
      '#ffb248',
      '#f2d643',
      '#ebdba4',
    ],
    // ... Some code is omitted for brevity
    visualMapColor: [
      '#893448',
      '#d95850',
      '#eb8146',
      '#ffb248',
      '#f2d643',
      'rgb(247,238,173)',
    ],
    // ... Some code is omitted for brevity
    axes: [],
    // ... Some code is omitted for brevity
  },
}
fWorksheet.registerChartTheme('myTheme', theme)

// use your theme for chart
const chartInfo = fWorksheet.newChart()
  .asLineChart()
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
```
