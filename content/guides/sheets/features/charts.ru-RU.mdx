Диаграммы визуализируют данные листа с помощью пакетов модели и интерфейса.

## Режим предустановок

Функция диаграмм входит в `@univerjs/preset-sheets-advanced` и требует предустановку рисования во время выполнения.

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

## Режим плагинов

```package-install
npm install @univerjs-pro/chart-ui @univerjs-pro/sheets-chart @univerjs-pro/sheets-chart-ui
```

```ts
import ChartUIRuRU from '@univerjs-pro/chart-ui/locale/ru-RU'
import { UniverSheetsChartPlugin } from '@univerjs-pro/sheets-chart'
import { UniverSheetsChartUIPlugin } from '@univerjs-pro/sheets-chart-ui'
import SheetsChartUIRuRU from '@univerjs-pro/sheets-chart-ui/locale/ru-RU'
import SheetsChartRuRU from '@univerjs-pro/sheets-chart/locale/ru-RU'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-chart/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/sheets-chart-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.RU_RU,
  locales: {
    [LocaleType.RU_RU]: mergeLocales(ChartUIRuRU, SheetsChartRuRU, SheetsChartUIRuRU),
  },
})

univer.registerPlugin(UniverSheetsChartPlugin)
univer.registerPlugin(UniverSheetsChartUIPlugin)
```

## Создание и обновление диаграмм

Управляйте диаграммами через коллекцию `charts` листа. `create()` возвращает ещё не вставленный конструктор, а `insert()` добавляет его на лист.

```ts
const worksheet = univerAPI.getActiveWorkbook().getActiveSheet()

const builder = worksheet.charts.create()
  .setType(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D6',
    orientation: univerAPI.Enum.ChartSourceOrientation.Column,
  })
  .setTitle('Квартальная выручка')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)

const chart = await worksheet.charts.insert(builder)

chart
  .setType(univerAPI.Enum.ChartTypeString.Line)
  .setLegend({ visible: true })
  .setSeries({ index: 0 }, { color: '#2F80ED' })
  .commit()
```

Для существующих диаграмм используйте `worksheet.charts.list()`, `worksheet.charts.get(id)` и `await worksheet.charts.remove(chartOrId)`. `worksheet.charts.registerTheme(name, theme)` регистрирует тему ECharts, общую для текущего runtime Univer.

## Поддерживаемые типы диаграмм

`univerAPI.Enum.ChartTypeString` предоставляет `Line`, `Column`, `ColumnStacked`, `ColumnPercentStacked`, `Bar`, `BarStacked`, `BarPercentStacked`, `Pie`, `Donut`, `Area`, `AreaStacked`, `AreaPercentStacked`, `Radar`, `Scatter`, `Combination`, `WordCloud`, `Funnel`, `Bubble`, `Relation`, `Waterfall`, `Pareto`, `Sankey`, `Heatmap`, `Boxplot`, `Candlestick`, `Histogram`, `Treemap`, `Sunburst`, `Gauge` и `Chord`.

Общие параметры конструктора описаны в [справочнике Chart Facade](/reference/facade/chart).
