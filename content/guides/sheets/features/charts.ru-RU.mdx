Диаграммы отображают данные в виде диаграммы. Модель диаграммы и пакеты пользовательского интерфейса обеспечивают эту функцию.

## Режим плагинов

```package-install
npm install @univerjs-pro/chart-ui @univerjs-pro/sheets-chart @univerjs-pro/sheets-chart-ui
```

```ts
import ChartUIRuRU from '@univerjs-pro/chart-ui/locale/ru-RU'
import { UniverSheetsChartPlugin } from '@univerjs-pro/sheets-chart'
import { UniverSheetsChartUIPlugin } from '@univerjs-pro/sheets-chart-ui'
import SheetsChartUIRuRU from '@univerjs-pro/sheets-chart-ui/locale/ru-RU'
import SheetsChartRuRU from '@univerjs-pro/sheets-chart/locale/ru-RU'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/chart-ui/facade'
import '@univerjs-pro/sheets-chart/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/sheets-chart-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.RU_RU,
  locales: {
    [LocaleType.RU_RU]: mergeLocales(ChartUIRuRU, SheetsChartRuRU, SheetsChartUIRuRU),
  },
})

univer.registerPlugin(UniverSheetsChartPlugin)
univer.registerPlugin(UniverSheetsChartUIPlugin)
```

## Режим предустановок

`@univerjs/preset-sheets-advanced` уже включает в себя функцию графика, но для этого требуется предварительный набор чертежей во время выполнения.

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

```ts
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'
import UniverPresetSheetsAdvancedRuRU from '@univerjs/preset-sheets-advanced/locales/ru-RU'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreRuRU from '@univerjs/preset-sheets-core/locales/ru-RU'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing'
import UniverPresetSheetsDrawingRuRU from '@univerjs/preset-sheets-drawing/locales/ru-RU'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-advanced/lib/index.css'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.RU_RU,
  locales: {
    [LocaleType.RU_RU]: mergeLocales(
      UniverPresetSheetsCoreRuRU,
      UniverPresetSheetsDrawingRuRU,
      UniverPresetSheetsAdvancedRuRU,
    ),
  },
  presets: [UniverSheetsCorePreset(), UniverSheetsDrawingPreset(), UniverSheetsAdvancedPreset()],
})
```

## Создание и обновление диаграмм

`worksheet.newChart(type)` возвращает отдельно стоящего строителя.Ничего не добавляется в рабочий лист до тех пор, пока информация о графике не будет построена и передана `worksheet.insertChart(info)`.

```ts
const workbook = univerAPI.getActiveWorkbook()
if (!workbook) throw new Error('No active workbook')

const worksheet = workbook.getActiveSheet()
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D6',
    orientation: univerAPI.Enum.ChartSourceOrientation.Columns,
  })
  .setPosition('F2')
  .setSize(640, 360)
  .setCategoryField(0)
  .setValueFields([1, 2, 3])
  .setTitle('Quarterly revenue')
  .build()

const chart = await worksheet.insertChart(info)
chart.setLegend({ visible: true }).bringToFront()

const updatedInfo = chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setSubtitle('FY 2026').build()
await chart.update(updatedInfo)

const svg = await chart.exportImage({ format: 'svg' })
```

Вызов сеттера на вставленный `chart` обновляет его немедленно. Используйте `toBuilder(type)` с `update(info)` для получения полностью отсоединенной копии или для изменения типа диаграммы. `exportImage()` возвращает `undefined`, когда ни один UI-рендер не может создать изображение.

`worksheet.getCharts()` и `worksheet.getChart(id)` возвращают живые диаграммы. Позвоните `await chart.remove()`, чтобы удалить диаграмму. Регистрируйте общие темы ECharts с `univerAPI.registerTheme(name, theme)`.

## Листы диаграмм [#chart-sheets]

`insertChartSheet()` дает графику свою собственную вкладку. Создатель диаграмм должен ссылаться на лист сетки в той же книге, и исходные ячейки остаются на этом листе.

```ts
import '@univerjs-pro/sheets-chart/facade'

const workbook = univerAPI.getActiveWorkbook()
const data = workbook?.getSheetByName('Data')
if (!workbook || !data) throw new Error('The Data sheet is required')

const info = data
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({ sheetId: data.getSheetId(), range: 'A1:B4' })
  .build()

const chartSheet = await workbook.insertChartSheet(info, { name: 'Sales' })
const primaryChart = chartSheet.getPrimaryChart()
```

`await chart.moveTo(targetSheet)` перемещает существующий график. График, перемещаемый в лист диаграммы, становится дополнительным графиком на этом листе. Перемещение первичного графика из листа диаграммы требует вкладки, которая не содержит ничего другого, и ход удаляет эту вкладку. Переезды могут быть отменены и переделаны.

[`FWorkbook.insertChartSheet()`](/reference/facade/workbook#insertchartsheet) · [`FWorksheet.getPrimaryChart()`](/reference/facade/worksheet#getprimarychart)

## Пределы погрешностей [#error-bars]

`setErrorBars()` можно вызвать на конструкторе или на живом графике. Базовые 2D колонки, бары, линии и диаграммы рассеяния поддерживают бары ошибок. `seriesIndex` основан на нуле и подсчитывает поле категории в исходных данных. Колонки и линии используют `y`, бары используют `x` и диаграммы рассеивания могут использовать либо числовую ось.

```ts
chart.setErrorBars([
  { seriesIndex: 1, direction: 'y', type: 'both', valueType: 'percentage', value: 20 },
])
```

[`FChart.setErrorBars()`](/reference/facade/chart#seterrorbars)

## Многоуровневые оси категорий

Когда соседние столбцы источника образуют иерархию, передайте их нулевые индексы `setCategoryFields()` в порядке от корня до листа, а затем включите многоуровневую ось.

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D7',
    orientation: univerAPI.Enum.ChartSourceOrientation.Columns,
  })
  .setCategoryFields([0, 1])
  .setMultiLevelCategoryAxis(true)
  .setValueFields([2, 3])
  .setPosition('F2')
  .build()

const chart = await worksheet.insertChart(info)
chart.setCategoryFields([0, 1]).setMultiLevelCategoryAxis(true)
```

`clearCategoryFields()` удаляет упорядоченное отображение. `setMultiLevelCategoryAxis(false)` сохраняет выбранные поля и отключает только иерархический рендеринг.

## Поддерживаемые типы диаграмм

`univerAPI.Enum.ChartTypeString` Предоставляет следующие виды: `Line`, `LineStacked`, `LinePercentStacked`, `Column`, `ColumnStacked`, `ColumnPercentStacked`, `Bar`, `BarStacked`, `BarPercentStacked`, `Pie`, `Donut`, `Area`, `AreaStacked`, `AreaPercentStacked`, `Radar`, `Scatter`, `Combination`, `WordCloud`, `Funnel`, `Bubble`, `Relation`, `Waterfall`, `Pareto`, `Sankey`, `Heatmap`, `Boxplot`, `Candlestick`, `Histogram`, `Treemap`, `Sunburst`, `Gauge`и `Chord`.

[Ссылка на Chart Facade](/reference/facade/chart) документирует общий API конфигурации конструктора.

`LineStacked` и `LinePercentStacked` являются автономными типами 2D графиков.Прежде чем использовать их в серверном рендере или в конвертации файлов Office, проверьте, что цель поддерживает их.

## Скрытые данные и отдельные категории [#source-mapping]

`setPlotVisibleOnly(false)` включает в себя значения из скрытых строк и столбцов, а `getPlotVisibleOnly()` считывает текущую настройку. Для источников с отдельными столбцами категорий `setSeriesToCategory()` отображает каждый индекс поля значений на свои индексы поля категорий. Индексы относятся к физическим векторам источника, а не к сериям, которые остаются после фильтрации. Записи, которые остались, наследуют разделяемые категории, и `{}` очищает переопределения.

Например, в столбцах A:D ряд значений в D может использовать C в качестве своей категории, в то время как B сохраняет разделяемую категорию в A.

```ts
const chart = worksheet.getCharts()[0]
if (!chart) throw new Error('No chart')
chart.setPlotVisibleOnly(false)
chart.setSeriesToCategory({ 3: [2] })
```

Для агрегированных отчётов см. [сводные диаграммы](/guides/sheets/features/pivot-chart).

## Трёхмерные диаграммы [#three-dimensional-charts]

3D-карты используют ту же регистрацию плагинов. Выберите тип 3D-чарта, а затем настройте вид на его отдельном конструкторе.

Поддерживаемые типы: `Line3D`, `Column3D`, `ColumnStacked3D`, `ColumnPercentStacked3D`, `Bar3D`, `BarStacked3D`, `BarPercentStacked3D`, `Pie3D`, `Area3D`, `AreaStacked3D` и `AreaPercentStacked3D`.

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column3D)
  .setSource('A1:C5')
  .setCategoryField(0)
  .setValueFields([1, 2])
  .setPosition('F18')
  .setSize(640, 360)
  .setThreeD({
    view: { rotX: 20, rotY: 30, rightAngleAxes: false, perspective: 30 },
    gapDepth: 120,
  })
  .build()

await worksheet.insertChart(info)
```

`perspective` применяется к диаграммам, основанным на оси, только когда `rightAngleAxes` является `false`. `clearThreeD()` очищает настроенные настройки просмотра, но сохраняет тип 3D-карты и ось глубины; используйте `clearDepthAxis()` для очистки оси глубины. 3D диаграммы оси не выставляют вторичных осей или линий тренда, а `Pie3D` рисует сплошной пирог.

## Логарифмические числовые оси [#logarithmic-axes]

Поддерживаемые 2D-линии, область, столбец, бар и комбинированные диаграммы принимают `scaleType: 'log'` на числовой оси. Используйте `setYAxis()` для вертикальных осей значений и `setXAxis()` - для горизонтальной числовой осе барной диаграммы. `setRightYAxis()` конфигурирует существующую вторичную числовую ось.

Базой по умолчанию является `10`. Пользовательский `logBase` должен быть конечным и между `2` и `1000`; допускаются дробные значения, такие как `2.5` . Численные границы должны быть положительными. Нулевые и отрицательные точки данных опускаются с логарифмического графика, но исходные данные неизменны. Процентные стекированные и 3D-карты не поддерживают логарифматические оси.

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Line)
  .setSource('A1:B5')
  .setYAxis({ scaleType: 'log', logBase: 10 })
  .setPosition('F36')
  .setSize(640, 360)
  .build()

const chart = await worksheet.insertChart(info)

await chart.update(
  chart.toBuilder(univerAPI.Enum.ChartTypeString.Line)
    .setYAxis({ scaleType: 'linear' })
    .build(),
)
```

Чтобы вставить новую диаграмму, создайте ее, а затем вставьте; чтобы применить отдельное обновление, используйте `await chart.update(builder.build())`.Настройка `scaleType: 'linear'` удаляет логарифмическую базу, а патчи оси, которые не касаются шкалы, сохраняют ее.
