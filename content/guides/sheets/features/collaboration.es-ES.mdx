Sigue la [Integración colaborativa](/guides/server-integration/collaboration) para ejecutar el ejemplo, conectar tu aplicación y verificar persistencia y permisos. Los detalles y ejemplos Web/Server están en [Univer Office](https://office.univer.ai/collaboration/quick-start).

Crea el Unit mediante una API de negocio autenticada que invoque Collaboration Service y carga el ID devuelto en el navegador. Configura HTTP, Session Ticket y WebSocket según [Quick Start](https://office.univer.ai/collaboration/quick-start), persiste con un Database Adapter y protege lectura, JOIN y edición mediante [permisos del servidor](https://office.univer.ai/collaboration/identity-and-authorization).

## Facade API [#loading-collaborative-documents]

```ts
import '@univerjs-pro/collaboration-client/facade'

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadSheetAsync('your-unit-id')
```
