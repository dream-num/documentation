Sigue la [Integración colaborativa](/server/collaboration/browser-integration) para ejecutar el ejemplo, conectar tu aplicación y verificar persistencia y permisos. Los detalles y ejemplos Web/Server están en [Inicio rápido de colaboración](/server/collaboration/quick-start).

Crea el Unit mediante una API de negocio autenticada que invoque Collaboration Service y carga el ID devuelto en el navegador. Configura HTTP, Session Ticket y WebSocket según [Inicio rápido de colaboración](/server/collaboration/quick-start), persiste con un Database Adapter y protege lectura, JOIN y edición mediante [permisos del servidor](/server/collaboration/identity-and-authorization).

## Cargar el documento [#document-loading]

Establece el usuario actual antes de cargar un documento. Identifica al colaborador y es propietario de la caché local sin conexión. Una vez establecido, carga el documento explícitamente con la Facade:

```ts
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadSheetAsync('your-unit-id')
```

<Callout type="warning">
La versión actual de `UniverCollaborationClientUIPlugin` todavía lee los parámetros `unit` y `type` al iniciar y carga ese documento. Este comportamiento está obsoleto y se eliminará en una versión posterior. Configura `enableUrlUnitLoader: false` al inicializar para desactivarlo.
</Callout>

Combine estas opciones con el registro de plugins o la llamada al preset de colaboración existente. En modo preestablecido, añada `collaborationPreset` a la lista de presets de su `createUniver()`, junto con los del editor.

<Tabs items={['Modo de complemento', 'Modo preestablecido']}>
  <Tab>
    ```ts
    import { UniverCollaborationClientUIPlugin } from '@univerjs-pro/collaboration-client-ui'

    univer.registerPlugin(UniverCollaborationClientUIPlugin, {
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverSheetsCollaborationPreset } from '@univerjs/preset-sheets-collaboration'

    const collaborationPreset = UniverSheetsCollaborationPreset({
      universerEndpoint: 'https://your-backend.example.com',
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
</Tabs>
