フィルターは指定された基準に一致しない行を非表示にします。そのため、関心のデータは表示されません。この機能は、フィルタリング条件と操作の範囲をサポートし、各列は独自の基準を持つことができます。

## プラグインモード

### インストール

```package-install
npm install @univerjs/sheets-filter @univerjs/sheets-filter-ui
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsFilterPlugin } from '@univerjs/sheets-filter' // [!code ++]
import { UniverSheetsFilterUIPlugin } from '@univerjs/sheets-filter-ui' // [!code ++]
import SheetsFilterUIJaJP from '@univerjs/sheets-filter-ui/locale/ja-JP' // [!code ++]
import '@univerjs/sheets-filter-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-filter/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      SheetsFilterUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsFilterPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsFilterUIPlugin) // [!code ++]
```

### プラグイン設定 [#plugin-configuration]

`UniverSheetsFilterPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>enableSyncSwitch</ConfigKey> | `boolean \| object` | `false` | 共同フィルタの同期のためのスイッチを表示します。オブジェクトを渡すと、初期状態を設定します。 |
| <ConfigKey depth={1}>defaultValue</ConfigKey> | `boolean` |  | スイッチの初期状態が示されているとき。 |

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/sheets/getting-started/installation#mobile-support)を最初にセットアップします。このページのプラグインモード設定では、同じパッケージからモバイルエクスポートでデスクトップ登録を交換し、**ドキュメントを開く前に**を実行します。モデルプラグイン、スタイル、ロケール、ファサードのインポートをそのまま保存し、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs/sheets-filter-ui` | `UniverSheetsFilterUIPlugin` | `UniverSheetsFilterMobileUIPlugin` |

## プリセットモード

### インストール

```package-install
npm install @univerjs/preset-sheets-filter
```

### 使い方

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreJaJP from '@univerjs/preset-sheets-core/locales/ja-JP'
import { UniverSheetsFilterPreset } from '@univerjs/preset-sheets-filter' // [!code ++]
import UniverPresetSheetsFilterJaJP from '@univerjs/preset-sheets-filter/locales/ja-JP' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-filter/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetSheetsCoreJaJP,
      UniverPresetSheetsFilterJaJP, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsFilterPreset(), // [!code ++]
  ],
})
```

## Facade API

Facade API の型定義については、[FacadeAPI](/reference/facade) を参照してください。

### インポート

<Callout type="info" title="プラグインモードノート">
  ファサードパッケージには、プラグインモードのみの手動インポートが必要です。プリセットモードは、既にマッチしたファサードパッケージをバンドルしています。
</Callout>

```typescript
import '@univerjs/sheets-filter/facade'
```

### フィルターの取得

[`FFilter`](https://docs.univer.ai/reference/facade/filter) オブジェクト、またはシートがフィルターがない場合は `null`。

- `FWorksheet`では、[`getFilter()`](https://docs.univer.ai/reference/facade/worksheet#getfilter) を呼び出す
- `FRange`では、[`getFilter()`](https://docs.univer.ai/reference/facade/range#getfilter) を呼び出す

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// FWorksheet からフィルターを取得
const fWorksheet = fWorkbook.getActiveSheet()
const fFilter = fWorksheet.getFilter()
fFilter?.getRange().getA1Notation()

// FRange からフィルターを取得
const fRange = fWorksheet.getRange('A1:D14')
const fFilter2 = fRange.getFilter()
fFilter2?.getRange().getA1Notation()
```

### フィルターの作成

[`FFilter`](https://docs.univer.ai/reference/facade/filter) オブジェクトを新規作成します。シートに既にフィルターが存在する場合は `null` を返します。

- `FRange`では、[`createFilter()`](https://docs.univer.ai/reference/facade/range#createfilter) を呼び出す

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:D14')
let fFilter = fRange.createFilter()

// 既にフィルターがある場合はいったん削除して再作成
if (!fFilter) {
  fWorksheet.getFilter().remove()
  fFilter = fRange.createFilter()
}
fFilter.getRange().getA1Notation()
```

### フィルターの削除

[`FFilter.remove()`](https://docs.univer.ai/reference/facade/filter#remove) を呼び出して、ワークシートからフィルターを外します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.getFilter()?.remove()
```

### 列フィルター条件の取得

[`FFilter.getColumnFilterCriteria(column)`](https://docs.univer.ai/reference/facade/filter#getcolumnfiltercriteria)は、列にセットされたフィルタ条件を返します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 範囲 C1:F10 に値を設定
const fRange = fWorksheet.getRange('C1:F10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// フィルター作成
let fFilter = fRange.createFilter()

// 既にあるなら削除して再作成
if (!fFilter) {
  fRange.getFilter().remove()
  fFilter = fRange.createFilter()
}

// 列 C の条件を設定（1,5,9 以外を除外）
const column = fWorksheet.getRange('C:C').getColumn()
fFilter.setColumnFilterCriteria(column, {
  colId: 0,
  filters: {
    filters: ['1', '5', '9'],
  },
})

// 列 C と D の条件を取得
fFilter.getColumnFilterCriteria(column) // { colId: 0, filters: { filters: ['1', '5', '9'] } }
fFilter.getColumnFilterCriteria(column + 1) // undefined
```

### 列フィルター条件の設定

[`FFilter.setColumnFilterCriteria(column, criteria)`](https://docs.univer.ai/reference/facade/filter#setcolumnfiltercriteria)は1つのコラムのためのフィルター条件を置きます。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 範囲 C1:F10 に値を設定
const fRange = fWorksheet.getRange('C1:F10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// フィルター作成
let fFilter = fRange.createFilter()

// 既にあるなら削除して再作成
if (!fFilter) {
  fRange.getFilter().remove()
  fFilter = fRange.createFilter()
}

// 列 C の条件を設定（1,5,9 以外を除外）
const column = fWorksheet.getRange('C:C').getColumn()
fFilter.setColumnFilterCriteria(column, {
  colId: 0,
  filters: {
    filters: ['1', '5', '9'],
  },
})
```

### 列フィルター条件の削除

- [`FFilter.removeColumnFilterCriteria(column)`](https://docs.univer.ai/reference/facade/filter#removecolumnfiltercriteria)は1つの列の基準をクリアします。
- [`FFilter.removeFilterCriteria()`](https://docs.univer.ai/reference/facade/filter#removefiltercriteria)は、すべての列の基準をクリアします。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 範囲 C1:F10 に値を設定
const fRange = fWorksheet.getRange('C1:F10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// フィルター作成
let fFilter = fRange.createFilter()

// 既にあるなら削除して再作成
if (!fFilter) {
  fRange.getFilter().remove()
  fFilter = fRange.createFilter()
}

// 列 C の条件を設定（1,5,9 以外を除外）
const column = fWorksheet.getRange('C:C').getColumn()
fFilter.setColumnFilterCriteria(column, {
  colId: 0,
  filters: {
    filters: ['1', '5', '9'],
  },
})

// 3 秒後に列 C の条件をクリア
setTimeout(() => {
  fFilter.removeColumnFilterCriteria(column)
  // すべての列条件を削除する場合: fFilter.removeFilterCriteria()
}, 3000)
```

### 除外された行の取得

[`FFilter.getFilteredOutRows()`](https://docs.univer.ai/reference/facade/filter#getfilteredoutrows)は、フィルタアウトされた行のインデックスの配列を返します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 範囲 C1:F10 に値を設定
const fRange = fWorksheet.getRange('C1:F10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// フィルター作成
let fFilter = fRange.createFilter()

// 既にあるなら削除して再作成
if (!fFilter) {
  fRange.getFilter().remove()
  fFilter = fRange.createFilter()
}

// 列 C の条件を設定（1,5,9 以外を除外）
const column = fWorksheet.getRange('C:C').getColumn()
fFilter.setColumnFilterCriteria(column, {
  colId: 0,
  filters: {
    filters: ['1', '5', '9'],
  },
})

// 除外された行を出力
fFilter.getFilteredOutRows() // [1, 2, 3, 5, 6, 7, 9]
```

### イベントリスナー

[イベント](https://docs.univer.ai/reference/facade/events) では、イベント型の完全な定義が使われています。

`SheetRangeFiltered` は、カラムのフィルター条件が変更されたときに消火します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetRangeFiltered, (params) => {
  const { workbook, worksheet, col, criteria } = params
})

// `disposable.dispose()` を使用してイベントリスナーを削除
```

`SheetBeforeRangeFilter`は変更を加える前に火を始動させます。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetBeforeRangeFilter, (params) => {
  const { workbook, worksheet, col, criteria } = params

  // 条件変更処理をキャンセル
  params.cancel = true
})

// `disposable.dispose()` を使用してイベントリスナーを削除
```

`SheetRangeFilterCleared`は、基準がクリアされたときに火災します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetRangeFilterCleared, (params) => {
  const { workbook, worksheet } = params
})

// `disposable.dispose()` を使用してイベントリスナーを削除
```

`SheetBeforeRangeFilterClear`は基準がクリアされる前に火災します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetBeforeRangeFilterClear, (params) => {
  const { workbook, worksheet } = params

  // クリア処理をキャンセル
  params.cancel = true
})

// `disposable.dispose()` を使用してイベントリスナーを削除
```
