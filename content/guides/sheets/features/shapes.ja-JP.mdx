## Plugin モード

### インストール

```package-install
npm install @univerjs-pro/engine-formula @univerjs/drawing @univerjs/drawing-ui @univerjs/sheets-drawing @univerjs/sheets-drawing-ui @univerjs-pro/sheets-shape @univerjs-pro/sheets-shape-ui
```

<Callout type="warn">
  形状は、`@univerjs-pro/engine-formula`から`UniverProFormulaEnginePlugin`も必要です。このプラグインを使用して、既存の`UniverFormulaEnginePlugin`のインポートとベース初期化の登録を置き換えます。 形状を差し込むと、欠落している依存エラーで失敗する可能性があるため、両方の式エンジンを登録しないでください。

  形状プラグインは描画プラグインに依存しているため、形状プラグインを登録する前に、`UniverDrawingPlugin`、`UniverSheetsDrawingPlugin`、`UniverDrawingUIPlugin`と`UniverSheetsDrawingUIPlugin`を登録します。
</Callout>

### 使い方

```typescript
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula' // [!code ++]
import { UniverSheetsShapePlugin } from '@univerjs-pro/sheets-shape' // [!code ++]
import { UniverSheetsShapeUIPlugin } from '@univerjs-pro/sheets-shape-ui' // [!code ++]
import SheetsShapeUIJaJP from '@univerjs-pro/sheets-shape-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDrawingPlugin } from '@univerjs/drawing' // [!code ++]
import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui' // [!code ++]
import DrawingUIJaJP from '@univerjs/drawing-ui/locale/ja-JP' // [!code ++]
import { UniverSheetsDrawingPlugin } from '@univerjs/sheets-drawing' // [!code ++]
import { UniverSheetsDrawingUIPlugin } from '@univerjs/sheets-drawing-ui' // [!code ++]
import SheetsDrawingUIJaJP from '@univerjs/sheets-drawing-ui/locale/ja-JP' // [!code ++]

import '@univerjs-pro/sheets-shape/facade' // [!code ++]

import '@univerjs/drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing-ui/lib/index.css' // [!code ++]
import '@univerjs-pro/sheets-shape-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DrawingUIJaJP, // [!code ++]
      SheetsDrawingUIJaJP, // [!code ++]
      SheetsShapeUIJaJP, // [!code ++]
    ),
  },

univer.registerPlugin(UniverProFormulaEnginePlugin) // [!code ++]
univer.registerPlugin(UniverDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverDrawingUIPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingUIPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsShapePlugin) // [!code ++]
univer.registerPlugin(UniverSheetsShapeUIPlugin) // [!code ++]
```

商用 Univer ライセンスを保持している場合は、クライアント設定の [クライアントでのライセンスの使用](/server/license#in-plugin-mode)を参照してください。

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/sheets/getting-started/installation#mobile-support)を最初にセットアップします。このページのプラグインモード設定では、同じパッケージからモバイルエクスポートに以下にリストされているデスクトップ登録を置き換え、代替**ドキュメントを開く前に**を完了します。モデルプラグイン、スタイル、ロケール、ファサードのインポートは変更されません。両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs/drawing-ui` | `UniverDrawingUIPlugin` | `UniverDrawingMobileUIPlugin` |
| `@univerjs/sheets-drawing-ui` | `UniverSheetsDrawingUIPlugin` | `UniverSheetsDrawingMobileUIPlugin` |
| `@univerjs-pro/sheets-shape-ui` | `UniverSheetsShapeUIPlugin` | `UniverSheetsShapeMobileUIPlugin` |

## Preset モード

形状は`@univerjs/preset-sheets-advanced`プリセットに含まれています。そのプリセットは既に`UniverProFormulaEnginePlugin`を登録しているので、式エンジンは手動で交換する必要はありません。

### インストール

<Callout>
  `@univerjs/preset-sheets-advanced`から`UniverSheetsAdvancedPreset`は、ランタイムで`UniverSheetsDrawingPreset`プリセットを必要とするので、`@univerjs/preset-sheets-drawing`を最初にインストールします。
</Callout>

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

### 使い方

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
import UniverPresetSheetsAdvancedJaJP from '@univerjs/preset-sheets-advanced/locales/ja-JP' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreJaJP from '@univerjs/preset-sheets-core/locales/ja-JP'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]
import UniverPresetSheetsDrawingJaJP from '@univerjs/preset-sheets-drawing/locales/ja-JP' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-advanced/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetSheetsCoreJaJP,

```

商用 Univer ライセンスを保持している場合は、クライアント設定の [クライアントでのライセンスの使用](/server/license#in-preset-mode)を参照してください。

## Facade API

完全なFacade APIタイプ定義は[FacadeAPI](/reference/facade/univer)にあります。

### インポート

<Callout type="info" title="Plugin モードの注意">
  Facade パッケージの手動インポートが必要なのは Plugin モードのみです。Preset モードでは対応する Facade がすでに含まれているため、追加インポートは不要です。
</Callout>

```typescript
import '@univerjs-pro/sheets-shape/facade'
```

### 基本図形の挿入

標準的な形状作成データを`FWorksheet.insertShape`に渡し、ライブファサードハンドルを返します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

const rectShape = fWorksheet.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.Rect,
  transform: { left: 120, top: 80, width: 240, height: 120 },
  shapeData: {
    fill: {
      fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
      color: '#e6f4ff',
    },
    stroke: {
      lineStrokeType: univerAPI.Enum.ShapeLineTypeEnum.SolidLine,
      color: '#1677ff',
      width: 2,
    },
  },
})

if (!rectShape) throw new Error('Shape could not be inserted.')
```

### 図形のテキストを編集する

以下の例では、`insertShape()` が返した形状や、下スニペットで使用される形状の形状が続いています。`getText()`は、ライブ [FShapeText(ファシェプテキスト)](/reference/facade/shape-text)ハンドルを返します。`getPlainText()`では、テキストを読み、`setText()`はそのすべてを置き換え、フォント、色、およびアライメントメソッドはフォーマットを適用します。

```ts
if (!rectShape) throw new Error('Shape is not available')
const shapeText = rectShape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()`は既存のテキストを置き換えます。 1つの形状がいくつかのスタイルを必要とするときに`setRichText()`を使用します。 既存のリッチテキストを編集するには、`getRichText()?.copy()`を呼び出し、ビルダーを変更し、`setRichText()`に渡します。 これにより、ビルダーは分離されたコピーなので、自動的に適用されません。 他のオプションについては[テキストスタイル](/reference/facade/shape-text#settextstyle)と[テキスト ボックスのパディングとレイアウト](/reference/facade/shape-text#settextboxoptions)を参照してください。

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

### コネクタ図形の挿入と接続

`FWorksheet.insertShape`でコネクターを作成し、返された`FConnectorShape`ファサードを通して両端を結合して下さい。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

const leftShape = fWorksheet.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 80, width: 180, height: 100 },
})
const rightShape = fWorksheet.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.Ellipse,
  transform: { left: 420, top: 200, width: 180, height: 100 },
})
const connectorShape = fWorksheet.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.BentConnector3,
  transform: { left: 240, top: 130, width: 240, height: 120 },
})

if (!leftShape || !rightShape || !connectorShape) {
  throw new Error('Shapes could not be inserted.')
}

const startSite = leftShape.getConnectionSites()[0]
const rightSites = rightShape.getConnectionSites()
const endSite = rightSites[2] ?? rightSites[0]

if (!startSite || !endSite) throw new Error('Connection site not found.')

connectorShape
  .bindStart(leftShape.getId(), startSite.index)
  .bindEnd(rightShape.getId(), endSite.index)
  .setEndArrow(univerAPI.Enum.ShapeArrowTypeEnum.Arrow)
```

### 図形の更新と削除

形状を上下にし、その生のファサードハンドルを操作します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

const firstShape = fWorksheet.getShapes().find(shape => !shape.isConnectorShape())

if (firstShape) {
  firstShape
    .setStrokeColor('#ff4d4f')
    .setStrokeWidth(3)
    .setSolidFill('#fff1f0')

  // 必要に応じて更新後に削除
  const removed = firstShape.remove()
  console.log(removed)
}
```

## 図形の書式コピー [#format-painter]

ソースの形状を選択し、フォーマットの画家をオンにし、ターゲットの形状を選択します。 画家は、そのアイデンティティ、幾何学、テキストのコンテンツ、および式結合を保持している間、それがサポートするテキストフォーマットを埋め、ストローク、エフェクト、およびテキストのフォーマットをコピーします。 フォーマットをクリアすると、インサートで適用されるデフォルトを復元します。 SmartArtは、この操作に参加しません。 形状 UI プラグインはこの動作を登録します。
