Registrar primero las dependencias [PivotTable](/guides/sheets/features/pivot-table) y [Gráfico](/guides/sheets/features/charts), a continuación, añadir los dos plugins abajo antes de crear el libro de trabajo. Combinar la UI locale en su configuración `locales` e cargar la hoja de estilo correspondiente. Se requiere una licencia Pro.

```package-install
npm install @univerjs-pro/sheets-pivot-chart @univerjs-pro/sheets-pivot-chart-ui
```

```ts
import { UniverSheetsPivotChartPlugin } from '@univerjs-pro/sheets-pivot-chart'
import { UniverSheetsPivotChartUIPlugin } from '@univerjs-pro/sheets-pivot-chart-ui'
import SheetsPivotChartLocale from '@univerjs-pro/sheets-pivot-chart-ui/locale/es-ES'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/sheets-pivot-chart/facade'
import '@univerjs-pro/sheets-pivot-chart-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.ES_ES, SheetsPivotChartLocale)

univer.registerPlugin(UniverSheetsPivotChartPlugin)
univer.registerPlugin(UniverSheetsPivotChartUIPlugin)
```

El preset de Hojas avanzadas ya incluye ambos plugins. Úsalo junto con los presets de núcleo y dibujo, e importar `@univerjs-pro/sheets-pivot-chart/facade` explícitamente para las APIs en esta página.

## Informe independiente [#owned-report]

Un gráfico independiente posee su informe. Después de insertar, agregue un campo de fila y un campo de valor. El ejemplo utiliza las dos primeras columnas de origen.

```ts
const workbook = univerAPI.getActiveWorkbook()
const sheet = workbook?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

sheet.getRange('A1:B4').setValues([
  ['Region', 'Sales'], ['East', 100], ['West', 200], ['East', 50],
])
const chart = await sheet.insertPivotChart(
  sheet.newPivotChart(univerAPI.Enum.ChartTypeString.Column)
    .setSource('A1:B4').setPosition('D2').setSize(640, 360).build(),
)
const fields = chart.getSourceFieldsInfo()
await chart.addField(fields[0].id, univerAPI.Enum.PivotTableFiledAreaEnum.Row, 0)
await chart.addField(fields[1].id, univerAPI.Enum.PivotTableFiledAreaEnum.Value, 0)
```

## Vincular una tabla dinámica [#linked-report]

Las ediciones de campo, filtro, tipo y colapso son compartidas con el PivotTable referenciado y con sus otros gráficos enlazados, mientras que la apariencia y la posición siguen siendo independientes. Eliminar el gráfico no elimina la tabla; eliminar la tabla hace que el gráfico no esté disponible hasta que se restablezca la misma tabla.

```ts
const pivotTable = workbook.getPivotTableById('pivot-table-1')
if (!pivotTable) throw new Error('PivotTable not found')

const linkedChart = await sheet.insertPivotChart(
  pivotTable.newChart(univerAPI.Enum.ChartTypeString.Line).setPosition('D22').build(),
)
linkedChart.setFieldButtonsVisible(true).setExpandCollapseButtonsVisible(true)
```

## Tipos de gráficos compatibles [#types-and-worker]

Línea, columna, barra, área, pie, rosquilla y tablas combinadas son compatibles, incluyendo variantes apiladas donde está disponible. Estantería, burbuja, radar y cascada no son compatibles. Pie utiliza la primera serie de valor; doughnut retiene múltiples series.

Ver [FSheetPivotChart](/reference/facade/sheet-pivot-chart) para el campo, filtro, estilo y APIs de ciclo de vida.

## Copiar y eliminar hojas [#copy-and-delete-sheets]

Copiar una hoja de trabajo también copia su PivotCharts y les asigna nuevos IDs. Un informe independiente cuya fuente está en la hoja copiada utiliza la nueva hoja y un caché independiente. Un gráfico vinculado sigue el PivotTabla copiado cuando esa tabla se copia con la hoja, y las referencias a otras hojas siguen sin cambiar. ## Filtros del informe [#report-filters]

`getOptions()`, `setOptions({ allowMultipleFilters: true })`, y `setDateFilter(fieldId, condition)` actúan en el informe autoritativo de la gráfica. En un gráfico enlazado actualizan el PivotTable y sus otros gráficos enlazados; en un gráfico independiente sólo actualizan el informe de esa gráfica. Omit `condition` para aclarar sólo la condición de la fecha. Para series de fecha y comparaciones de día completo, véase [múltiples filtros y condiciones de fecha](/guides/sheets/features/pivot-table#multiple-filters).
