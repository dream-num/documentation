[PivotTable의 특징](/guides/sheets/features/pivot-table) 및 [(주)태원](/guides/sheets/features/charts) 의존성을 먼저 등록하면 워크북을 만들기 전에 두 개의 플러그인을 추가합니다. `locales` 구성으로 UI Locale를 활용하고 해당 스타일 시트를로드하십시오. 프로 라이센스가 필요합니다.

```package-install
npm install @univerjs-pro/sheets-pivot-chart @univerjs-pro/sheets-pivot-chart-ui
```

```ts
import { UniverSheetsPivotChartPlugin } from '@univerjs-pro/sheets-pivot-chart'
import { UniverSheetsPivotChartUIPlugin } from '@univerjs-pro/sheets-pivot-chart-ui'
import SheetsPivotChartLocale from '@univerjs-pro/sheets-pivot-chart-ui/locale/ko-KR'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/sheets-pivot-chart/facade'
import '@univerjs-pro/sheets-pivot-chart-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.KO_KR, SheetsPivotChartLocale)

univer.registerPlugin(UniverSheetsPivotChartPlugin)
univer.registerPlugin(UniverSheetsPivotChartUIPlugin)
```

고급 시트 프리셋은 이미 플러그인이 포함되어 있습니다. 코어와 그림 프리셋과 함께 사용하며, `@univerjs-pro/sheets-pivot-chart/facade`를 이 페이지에서 API에 대해 명시적으로 가져 오기.

## Worker 설정 [#worker-configuration]

### 프리셋 설정

이 옵션은 `UniverSheetsAdvancedPreset`에 속합니다.

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `useWorker` | `boolean` | `false` | 수식 Worker에서 고급 기능을 활성화합니다. |

[회사 소개](/guides/sheets/getting-started/worker)를 사용하는 경우, 작업자 내부의 메인 스레드 및 `UniverSheetsAdvancedWorkerPreset()`에 `UniverSheetsAdvancedPreset({ useWorker: true })`을 통과합니다. 플러그인 모드 세부 사항은 [포장 참고](/reference/packages/plugins/univerjs-pro/sheets-pivot-chart#worker-calculation)입니다.

## 독립 보고서 [#owned-report]

독립적인 도표는 그것의 보고를 소유합니다. 삽입 후에, 줄 분야 및 가치 분야를 추가하십시오. 예는 첫번째 2개의 근원 열을 이용합니다.

```ts
const workbook = univerAPI.getActiveWorkbook()
const sheet = workbook?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

sheet.getRange('A1:B4').setValues([
  ['Region', 'Sales'], ['East', 100], ['West', 200], ['East', 50],
])
const chart = await sheet.insertPivotChart(
  sheet.newPivotChart(univerAPI.Enum.ChartTypeString.Column)
    .setSource('A1:B4').setPosition('D2').setSize(640, 360).build(),
)
const fields = chart.getSourceFieldsInfo()
await chart.addField(fields[0].id, univerAPI.Enum.PivotTableFiledAreaEnum.Row, 0)
await chart.addField(fields[1].id, univerAPI.Enum.PivotTableFiledAreaEnum.Value, 0)
```

## 피벗 테이블 연결 [#linked-report]

필드, 필터, 정렬 및 축소 편집은 참조 PivotTable과 함께 공유하고 다른 연결 차트와 함께 외관과 위치는 독립적으로 남아 있습니다. 차트 제거는 테이블을 제거하지 않습니다. 테이블 제거는 동일한 테이블이 복원 될 때까지 사용할 수없는 차트를 만듭니다.

```ts
const pivotTable = workbook.getPivotTableById('pivot-table-1')
if (!pivotTable) throw new Error('PivotTable not found')

const linkedChart = await sheet.insertPivotChart(
  pivotTable.newChart(univerAPI.Enum.ChartTypeString.Line).setPosition('D22').build(),
)
linkedChart.setFieldButtonsVisible(true).setExpandCollapseButtonsVisible(true)
```

## 지원하는 차트 유형 [#types-and-worker]

라인, 열, 바, 지역, 파이, 반죽 너트 및 조합 차트는 사용할 수있는 스택 된 변형을 포함하여 지원됩니다. Scatter, 거품, 레이더 및 폭포가 지원되지 않습니다. 파이는 첫 번째 값 시리즈를 사용합니다. 반죽 너트는 여러 시리즈를 유지합니다. 서브 총과 그랜드 총은 차트 카테고리에서 제외됩니다.

필드, 필터, 스타일, 수명주기 API에 대한 [FSheetPivotChart의 특징](/reference/facade/sheet-pivot-chart)를 참조하십시오.

## 워크시트 복사 및 삭제 [#copy-and-delete-sheets]

PivotCharts를 복사하고 새로운 ID를 할당합니다. 복사 된 시트에 소스가 새로운 시트와 독립적 인 캐시를 사용합니다. 연결된 차트는 테이블이 시트로 복사 될 때 복사 된 PivotTable을 따르고 다른 시트에 참조가 변경되지 않습니다. 워크 시트를 삭제하면 PivotCarts 및 리소스가 그들과 관련되어 있습니다. undo는 정의 및 소스를 복원합니다.

## 보고서 필터 [#report-filters]

`getOptions()`, `setOptions({ allowMultipleFilters: true })` 및 `setDateFilter(fieldId, condition)`는 차트의 권위있는 보고서에 행동합니다. 연결된 차트에서 그들은 PivotTable 및 기타 연결된 차트를 업데이트합니다. 독립적 인 차트에서는 차트의 보고서 만 업데이트합니다. Omit `condition`를 사용하여 날짜 상태를 명확하게하십시오. 날짜 serials 및 전체 일 비교를 위해 [여러 필터 및 날짜 조건](/guides/sheets/features/pivot-table#multiple-filters)을 참조하십시오.
