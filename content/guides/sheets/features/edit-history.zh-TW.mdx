<Callout type="warning" title="注意事項">
  歷史記錄功能需要 Univer 服務端支援，請確保你已經正確安裝並配置了 Univer 服務端。具體請參考：[升級到 Pro](/guides/sheets/getting-started/pro)
</Callout>

歷史記錄功能允許使用者檢視和恢復文件的歷史版本，支援多種過濾和搜尋方式，幫助使用者高效管理文件內容。

<Callout type="warning" title="注意事項">
  歷史記錄功能內部建立了一個獨立的 Univer 例項來處理歷史記錄的載入和展示。如果你需要對歷史記錄的 Univer 例項進行操作或配置（如修改介面請求頭、註冊外掛等），請參考[獲取歷史記錄的 Univer 例項](#get-edit-history-univer-instance)部分。
</Callout>

## 預設模式

### 安裝

<Callout>
  @univerjs/preset-sheets-advanced 的 `UniverSheetsAdvancedPreset` 預設在執行時依賴 `UniverSheetsDrawingPreset` 預設，請先安裝 @univerjs/preset-sheets-drawing。
</Callout>

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced @univerjs/preset-sheets-collaboration
```

### 使用

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
import UniverPresetSheetsAdvancedZhTW from '@univerjs/preset-sheets-advanced/locales/zh-TW' // [!code ++]
import { UniverSheetsCollaborationPreset } from '@univerjs/preset-sheets-collaboration' // [!code ++]
import UniverPresetSheetsCollaborationZhTW from '@univerjs/preset-sheets-collaboration/locales/zh-TW' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreZhTW from '@univerjs/preset-sheets-core/locales/zh-TW'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]
import UniverPresetSheetsDrawingZhTW from '@univerjs/preset-sheets-drawing/locales/zh-TW' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-advanced/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-collaboration/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      UniverPresetSheetsCoreZhTW,
      UniverPresetSheetsDrawingZhTW, // [!code ++]
      UniverPresetSheetsAdvancedZhTW, // [!code ++]
      UniverPresetSheetsCollaborationZhTW, // [!code ++]
    ),
  },
  collaboration: true, // [!code ++]
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsDrawingPreset({ // [!code ++]
      collaboration: true,
    }), // [!code ++]
    UniverSheetsAdvancedPreset({ // [!code ++]
      // configuration for advanced features
    }), // [!code ++]
    UniverSheetsCollaborationPreset({ // [!code ++]
      universerEndpoint: 'http://localhost:3010', // [!code ++]
    }), // [!code ++]
  ],
})
```

如果你擁有 Univer 的商業許可證，請參考[在客戶端使用許可證](/guides/pro/license#在預設模式中使用)進行配置。

### 預設與配置

`UniverSheetsCollaborationPreset` 配置項：

```typescript
interface IUniverSheetsCollaborationPresetConfig {
  // Univer Server 的埠地址
  universerEndpoint?: string
  /**
   * 如果歷史記錄裡面資料計算需要使用 Worker （例如公式），可以配置此字段。
   * 1.如果提供了 historyWorkerURL 且 historyWorkerURL 是一個 Worker 實例，它會在歷史記錄關閉時被銷毀，所以需要在歷史記錄每次打開時都提供一個新的 Worker 實例。
   * ```typescript
   * import { EDIT_HISTORY_LOADER_PLUGIN_CONFIG_KEY, ToggleEditHistoryOperation } from '@univerjs/preset-sheets-collaboration';
   * 
   * univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
   *   if (event.id === ToggleEditHistoryOperation.id) {
   *     const workerURL = new Worker(new URL('./worker.ts', import.meta.url));
   *     const configService = univer.__getInjector().get(IConfigService);
   *     configService.setConfig(EDIT_HISTORY_LOADER_PLUGIN_CONFIG_KEY, {
   *       workerURL,
   *     });
   *   }
   * });
   * 2.如果提供的 historyWorkerURL 不是一個 Worker 實例，則不需要額外進行處理。
   * ```
   */
  historyWorkerURL?: string | URL | Worker
}
```

## 外掛模式

### 安裝

```package-install
npm install @univerjs-pro/edit-history-viewer @univerjs-pro/edit-history-loader
```

### 使用

```typescript
import { UniverEditHistoryLoaderPlugin } from '@univerjs-pro/edit-history-loader' // [!code ++]
import EditHistoryViewerZhTW from '@univerjs-pro/edit-history-viewer/locale/zh-TW' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/edit-history-viewer/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      EditHistoryViewerZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverEditHistoryLoaderPlugin, { // [!code ++]
  univerContainerId: 'your-univer-container-id', // [!code ++]
}) // [!code ++]
```

如果你擁有 Univer 的商業許可證，請參考[在客戶端使用許可證](/guides/pro/license#在外掛模式中使用)進行配置。

### 外掛與配置

`UniverEditHistoryLoaderPlugin` 配置項：

```typescript
interface IUniverEditHistoryLoaderConfig {
  univerContainerId?: string
  // 歷史記錄列表的伺服器地址
  historyListServerUrl?: string
  /**
   * 如果歷史記錄裡面資料計算需要使用 Worker （例如公式），可以配置此字段。
   * 1.如果提供了 workerURL 且 workerURL 是一個 Worker實例，它會在歷史記錄關閉時被銷毀，所以需要在歷史記錄每次打開時都提供一個新的 Worker 實例。
   * ```typescript
   * import { EDIT_HISTORY_LOADER_PLUGIN_CONFIG_KEY, ToggleEditHistoryOperation } from '@univerjs-pro/edit-history-loader';
   * 
   * univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
   *   if (event.id === ToggleEditHistoryOperation.id) {
   *     const workerURL = new Worker(new URL('./worker.ts', import.meta.url));
   *     const configService = univer.__getInjector().get(IConfigService);
   *     configService.setConfig(EDIT_HISTORY_LOADER_PLUGIN_CONFIG_KEY, {
   *       workerURL,
   *     });
   *   }
   * });
   * 2.如果提供的 workerURL 不是一個 Worker 實例，則不需要額外進行處理。
   * ```
   */
  workerURL?: string | URL | Worker
}
```

啟動歷史記錄時，`UniverEditHistoryLoaderPlugin` 會載入一個新的 Univer 例項掛載指定 DOM 節點上。因此在註冊時，需要提供合適的 DOM 節點 id（如原 Univer 例項的 Container），以達到歷史記錄面板覆蓋原 Univer 面板的目的。若節點 id 未指定，則預設為  `univer-container`。

如果需要修改歷史記錄列表的伺服器地址，可以透過 `historyListServerUrl` 配置項進行設定，預設為 `/universer-api/history`。

## 獲取歷史記錄的 Univer 例項 `historyUniver` [#get-edit-history-univer-instance]

<Callout title="友情提示">
  歷史記錄的 Univer 例項只在第一次開啟歷史記錄面板時建立。
</Callout>

如果你需要對歷史記錄的 Univer 例項進行操作或配置（如修改介面請求頭、註冊外掛等），可以透過 `HistoryLoaderService` 獲取到該例項。

<Tabs items={['預設模式', '外掛模式']}>
  <Tab>
    ```typescript
    import { HistoryLoaderService } from '@univerjs/preset-sheets-collaboration'

    const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
      if (stage === univerAPI.Enum.LifecycleStages.Steady) {
        const injector = univer.__getInjector()
        const historyLoaderService = injector.get(HistoryLoaderService)

        historyLoaderService.historyUniver$.subscribe((historyUniver) => {
          if (!historyUniver) return

          // 在這裡可以使用 historyUniver 例項進行操作
        })
      }
    })

    // 移除事件監聽器，使用 `disposable.dispose()`
    ```
  </Tab>
  <Tab>
    ```typescript
    import { HistoryLoaderService } from '@univerjs-pro/edit-history-loader'

    const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
      if (stage === univerAPI.Enum.LifecycleStages.Steady) {
        const injector = univer.__getInjector()
        const historyLoaderService = injector.get(HistoryLoaderService)

        historyLoaderService.historyUniver$.subscribe((historyUniver) => {
          // 在這裡可以使用 historyUniver 例項進行操作
        })
      }
    })

    // 移除事件監聽器，使用 `disposable.dispose()`
    ```
  </Tab>
</Tabs>

### 第三方外掛適配

歷史記錄的 Univer 例項中只會預設載入官方的 Plugin。為業務需求開發的第三方 Feature Plugin 需要被註冊到 `HistoryLoaderService` 後，才會被正確的顯示在歷史記錄中。

```typescript
const injector = univer.__getInjector()
const historyLoaderService = injector.get(HistoryLoaderService)

// [!code focus:4]
// 和 PluginService 的註冊方式一致，歷史記錄的 Univer 例項在新建後會按照以下配置來註冊對應 Plugin
historyLoaderService.registerPlugin(YourPlugin, YourPluginConfig)
// 配置官方已註冊的 Plugin, 需設定 true 參數列示覆蓋原配置
historyLoaderService.registerPlugin(ExamplePlugin, ExamplePluginConfig, true)
```
