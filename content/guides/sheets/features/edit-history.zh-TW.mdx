<Callout type="warning">
  如果使用 **0.25.x**，請閱讀 [0.25.x 舊版 Pro 文件](https://dream-num.github.io/documentation/v0.25/zh-CN/guides/pro/)。新版整合使用自託管 Collaboration SDK，舊 Univer Server 的部署方式和 API 不適用。
</Callout>

請從[伺服器端整合](/guides/server-integration)開始，依序執行範例、接入業務、驗證持久化和權限。實作細節與可執行的 Web/Server 範例請見 [Univer Office 文件](https://office.univer.ai/zh-CN/collaboration/quick-start)。

歷史記錄需要獨立的 Service、Endpoint、Database Adapter 和權限策略。請依[協同擴充模組](https://office.univer.ai/zh-CN/collaboration/extensions)與 [History 範例](https://office.univer.ai/zh-CN/collaboration/examples#history)整合，確認歷史記錄在重新啟動後仍保留，且僅授權使用者可讀取。
