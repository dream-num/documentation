协同编辑需要前端编辑器和服务端共同接入。请先按[协同集成](/server/collaboration/browser-integration)运行示例，再接入业务身份、权限和数据存储。前后端的配置代码见 [Office 快速开始](/zh-CN/server/collaboration/quick-start)。

文档由经过认证的业务 API 创建。前端拿到服务端返回的 Unit 标识后，使用下面的方法加载；再次打开同一份文档时，继续使用这个标识。

## Facade API [#loading-collaborative-documents]

```ts
import '@univerjs-pro/collaboration-client/facade'

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadSheetAsync('your-unit-id')
```
