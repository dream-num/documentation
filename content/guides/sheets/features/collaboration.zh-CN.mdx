协同编辑需要前端编辑器和服务端共同接入。请先按[协同集成](/server/collaboration/browser-integration)运行示例，再接入业务身份、权限和数据存储。前后端的配置代码见 [协同快速开始](/server/collaboration/quick-start)。

文档由经过认证的业务 API 创建。前端拿到服务端返回的 Unit 标识后，使用下面的方法加载；再次打开同一份文档时，继续使用这个标识。

## 选择文档加载方式 [#document-loading]

默认情况下，`UniverCollaborationClientUIPlugin` 在启动时读取 URL 中的 `unit` 与 `type` 查询参数并加载文档。如果由业务应用选择文档并调用 Facade 加载，应在初始化时设置 `enableUrlUnitLoader: false`，让业务应用统一触发加载。

将以下选项合并到已有的插件注册或协同预设调用中。预设模式下，把 `collaborationPreset` 放入已有 `createUniver()` 的预设列表，与编辑器预设一起使用。

<Tabs items={['插件模式', '预设模式']}>
  <Tab>
    ```ts
    import { UniverCollaborationClientUIPlugin } from '@univerjs-pro/collaboration-client-ui'

    univer.registerPlugin(UniverCollaborationClientUIPlugin, {
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverSheetsCollaborationPreset } from '@univerjs/preset-sheets-collaboration'

    const collaborationPreset = UniverSheetsCollaborationPreset({
      universerEndpoint: 'https://your-backend.example.com',
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
</Tabs>

关闭 URL 自动加载后，协同编辑和显式调用 Facade 加载仍可使用。

## Facade API [#loading-collaborative-documents]

```ts
import '@univerjs-pro/collaboration-client/facade'

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadSheetAsync('your-unit-id')
```
