## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/engine-formula @univerjs/drawing @univerjs/drawing-ui @univerjs/sheets-drawing @univerjs/sheets-drawing-ui @univerjs-pro/sheets-shape @univerjs-pro/sheets-shape-ui
```

<Callout type="warn">
  Формы также требуют `UniverProFormulaEnginePlugin` от `@univerjs-pro/engine-formula`. Замените существующий импорт `UniverFormulaEnginePlugin` и регистрацию в вашей базовой инициализации этим плагином. Не регистрируйте оба движка формулы, потому что вставка формы может в противном случае выйти из строя с ошибкой отсутствия зависимости.

  Плагины формы зависят от плагинов рисования, поэтому перед регистрацией плагинов формы регистрируйте `UniverDrawingPlugin`, `UniverSheetsDrawingPlugin`, `UniverDrawingUIPlugin` и `UniverSheetsDrawingUIPlugin`.
</Callout>

## Поддержка мобильных устройств [#mobile-support]

В настройке плагин-режима на этой странице замените перечисленные ниже регистрации рабочего стола мобильным экспортом из тех же пакетов и заполните замену **Перед тем, как открыть документ**... Плагины модели, стили, локализации и импорт Facade остаются неизменными. Не регистрируйте оба варианта.

## Режим предустановок

Формы включены в предустановку `@univerjs/preset-sheets-advanced`. Тот предустанавливаемый уже регистрирует `UniverProFormulaEnginePlugin`, поэтому движок формулы не нужно заменять вручную.

### Установка

<Callout>
  `UniverSheetsAdvancedPreset` от `@univerjs/preset-sheets-advanced` требует предустановки `UniverSheetsDrawingPreset` во время выполнения, поэтому сначала установите `@univerjs/preset-sheets-drawing`.
</Callout>

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

## Facade API

Полные определения типов Facade API приведены в [FacadeAPI](/reference/facade/univer).

### Импорт

<Callout type="info" title="Примечание о режиме плагинов">
  Импортировать пакет Facade вручную нужно только в режиме плагинов. В режиме предустановок соответствующий пакет Facade уже включён, поэтому дополнительный импорт не требуется.
</Callout>

```typescript
import '@univerjs-pro/sheets-shape/facade'
```

### Вставка базовых фигур

Передайте стандартные данные о создании формы `FWorksheet.insertShape`, который возвращает живую ручку фасада.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

const rectShape = fWorksheet.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.Rect,
  transform: { left: 120, top: 80, width: 240, height: 120 },
  shapeData: {
    fill: {
      fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
      color: '#e6f4ff',
    },
    stroke: {
      lineStrokeType: univerAPI.Enum.ShapeLineTypeEnum.SolidLine,
      color: '#1677ff',
      width: 2,
    },
  },
})

if (!rectShape) throw new Error('Shape could not be inserted.')
```

### Редактирование текста фигуры

Приведенный ниже пример продолжается от формы, которую вернул `insertShape()`, либо от формы, созданной в предыдущем примере, либо от фигуры, использованной в фрагменте ниже. `getText()` возвращает живую рукоятку [FShapeText](/reference/facade/shape-text): `getPlainText()` читает текст, `setText()` заменяет все это, и применяются методы форматирования шрифта, цвета и выравнивания.

```ts
if (!rectShape) throw new Error('Shape is not available')
const shapeText = rectShape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()` заменяет существующий текст; используйте `setRichText()`, когда одна форма нуждается в нескольких стилях. Для редактирования существующего богатого текста звоните в `getRichText()?.copy()` , модифицируйте конструктор, затем передайте его `setRichText()`. Этот конструктор является отдельной копией, поэтому изменения к нему не применяются автоматически. См. [Текстовый стиль](/reference/facade/shape-text#settextstyle) и [текстовая обшивка и макет](/reference/facade/shape-text#settextboxoptions) для других вариантов.

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

### Вставка и соединение фигур линиями

Создайте разъем с `FWorksheet.insertShape`, затем свяжите оба конца через возвращенный фасад `FConnectorShape`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

const leftShape = fWorksheet.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 80, width: 180, height: 100 },
})
const rightShape = fWorksheet.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.Ellipse,
  transform: { left: 420, top: 200, width: 180, height: 100 },
})
const connectorShape = fWorksheet.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.BentConnector3,
  transform: { left: 240, top: 130, width: 240, height: 120 },
})

if (!leftShape || !rightShape || !connectorShape) {
  throw new Error('Shapes could not be inserted.')
}

const startSite = leftShape.getConnectionSites()[0]
const rightSites = rightShape.getConnectionSites()
const endSite = rightSites[2] ?? rightSites[0]

if (!startSite || !endSite) throw new Error('Connection site not found.')

connectorShape
  .bindStart(leftShape.getId(), startSite.index)
  .bindEnd(rightShape.getId(), endSite.index)
  .setEndArrow(univerAPI.Enum.ShapeArrowTypeEnum.Arrow)
```

### Изменение и удаление фигур

Обновление и удаление формы работают через его живую ручку фасада.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

const firstShape = fWorksheet.getShapes().find(shape => !shape.isConnectorShape())

if (firstShape) {
  firstShape
    .setStrokeColor('#ff4d4f')
    .setStrokeWidth(3)
    .setSolidFill('#fff1f0')

  // Remove the shape after update if needed
  const removed = firstShape.remove()
  console.log(removed)
}
```

## Копирование формата фигур [#format-painter]

Выберите исходную форму, включите форматиста, затем выберите форму-мишень. Копия живописца заполняет, штрих, эффекты и форматирование текста, которое он поддерживает, в то время как цель сохраняет свою идентичность, геометрию, текстовое содержимое и связывания формул. Очистка форматирования восстанавливает по умолчанию, применяемые при вставке. SmartArt не принимает участия в этой операции. Плагин UI формы регистрирует это поведение.
