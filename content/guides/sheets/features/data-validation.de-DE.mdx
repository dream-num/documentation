Die Datenvalidierung ist eine Funktion, mit der Sie Regeln in Zellen festlegen können, um sicherzustellen, dass die eingegebenen Daten bestimmte Anforderungen erfüllen. Es hilft Benutzern, Eingabefehler zu vermeiden und verbessert die Genauigkeit und Konsistenz der Daten.

Derzeit werden die folgenden Datenvalidierungstypen unterstützt:
- Zahl
- Ganzzahl
- Textlänge
- Datum
- Kontrollkästchen
- Dropdown-Liste (Einzel-/Mehrfachauswahl)
- Benutzerdefinierte Formel

### Eine Datenvalidierungsregel hinzufügen

[`univerAPI.newDataValidation()`](https://docs.univer.ai/reference/facade/univer#newdatavalidation) kann einen neuen Datenvalidierungs-Builder erstellen, der eine `FDataValidationBuilder`-Instanz zurückgibt, die Datenvalidierungsregeln durch verkettete Aufrufe generieren kann.

Hier sind einige Mitgliedsmethoden aufgeführt [`FDataValidationBuilder`](https://docs.univer.ai/reference/facade/data-validation):

| Methode | Beschreibung |
| ------ | ----------- |
| build | Erstellt die Datenvalidierungsregel. |
| requireCheckbox | Legt die Datenvalidierungsregel so fest, dass die Eingabe ein boolescher Wert sein muss; Dieser Wert wird als Kontrollkästchen gerendert |
| requireDateAfter | Setzen Sie den Datenvalidierungstyp auf „DATUM“ und konfigurieren Sie die Validierungsregeln so, dass sie nach einem bestimmten Datum liegen. |
| requireDateBefore | Setzen Sie den Datenvalidierungstyp auf „DATUM“ und konfigurieren Sie die Validierungsregeln so, dass sie vor einem bestimmten Datum liegen. |
| requireDateBetween | Setzen Sie den Datenvalidierungstyp auf „DATUM“ und konfigurieren Sie die Validierungsregeln so, dass sie innerhalb eines bestimmten Datumsbereichs liegen. |
| requireDateEqualTo | Setzen Sie den Datenvalidierungstyp auf DATUM und konfigurieren Sie die Validierungsregeln so, dass sie einem bestimmten Datum entsprechen |
| requireDateNotBetween | Setzen Sie den Datenvalidierungstyp auf DATUM und konfigurieren Sie die Validierungsregeln so, dass sie nicht innerhalb eines bestimmten Datumsbereichs liegen |
| requireDateOnOrAfter | Setzen Sie den Datenvalidierungstyp auf DATUM und konfigurieren Sie die Validierungsregeln so, dass sie an oder nach einem bestimmten Datum gelten |
| requireDateOnOrBefore | Setzen Sie den Datenvalidierungstyp auf DATUM und konfigurieren Sie die Validierungsregeln so, dass sie an oder vor einem bestimmten Datum gelten |
| requireFormulaSatisfied | Legt die Datenvalidierungsregel so fest, dass die gegebene Formel als `true` ausgewertet werden muss. |
| requireNumberBetween | Legt die Datenvalidierungsregel so fest, dass eine Zahl erforderlich ist, die zwischen zwei angegebenen Zahlen liegt oder eine dieser Zahlen ist |
| requireNumberEqualTo | Legt die Datenvalidierungsregel so fest, dass eine Zahl erforderlich ist, die dem angegebenen Wert entspricht |
| requireNumberGreaterThan | Legt die Datenvalidierungsregel so fest, dass eine Zahl größer als der angegebene Wert erforderlich ist |
| requireNumberGreaterThanOrEqualTo | Legt die Datenvalidierungsregel so fest, dass eine Zahl größer oder gleich dem angegebenen Wert erforderlich ist |
| requireNumberLessThan | Legt die Datenvalidierungsregel so fest, dass eine Zahl erforderlich ist, die kleiner als der angegebene Wert ist |
| requireNumberLessThanOrEqualTo | Legt die Datenvalidierungsregel so fest, dass eine Zahl kleiner oder gleich dem angegebenen Wert erforderlich ist |
| requireNumberNotBetween | Legt die Datenvalidierungsregel so fest, dass eine Zahl erforderlich ist, die nicht zwischen zwei angegebenen Zahlen liegt und keine von ihnen ist |
| requireNumberNotEqualTo | Legt die Datenvalidierungsregel so fest, dass eine Zahl ungleich dem angegebenen Wert erforderlich ist |
| requireValueInList | Legt eine Datenvalidierungsregel fest, die den Benutzer dazu verpflichtet, einen Wert aus einer Liste spezifischer Werte einzugeben. Unterstützt Einzel-/Mehrfachauswahl und Dropdown-Liste ein-/ausblenden |
| requireValueInRange | Legt eine Datenvalidierungsregel fest, die vom Benutzer die Eingabe eines Werts innerhalb eines bestimmten Bereichs erfordert. Unterstützt Einzel-/Mehrfachauswahl und Dropdown-Liste zum Anzeigen/Ausblenden. |
| setOptions | Legt die Optionen für die Datenvalidierungsregel fest. |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new data validation rule that requires a number between 1 and 10 for the range A1:B10
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: 'Please enter a number between 1 and 10',
  })
  .build()
fRange.setDataValidation(rule)
```

### Datenvalidierungen des Bereichs löschen

const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

### Datenvalidierungen des Bereichs/Arbeitsblatts abrufen

Das zurückgegebene Datenvalidierungsregelobjekt ist eine `FDataValidation`-Instanz, die zum Abrufen der Bedingungen, Optionen usw. der Validierungsregel verwendet werden kann.

Hier sind einige Mitgliedsmethoden aufgeführt [`FDataValidation`](https://docs.univer.ai/reference/facade/data-validation):

| Methode | Beschreibung |
| ---- | ---- |
| copy | Erstellt eine neue Instanz von FDataValidationBuilder mithilfe des aktuellen Regelobjekts. |
| getCriteriaType | Ruft den Datenvalidierungstyp der Regel ab. |
| getCriteriaValues | Ruft die für die Kriterienbewertung verwendeten Werte ab. |
| getHelpText | Ruft die Hilfetextinformationen ab, die Benutzern als Anleitung dienen und Unterstützung |
| getRanges | Ruft die Bereiche ab, auf die die Datenvalidierungsregel angewendet wird |
| setCriteria | Kriterien für die Datenvalidierungsregel festlegen |
| setOptions | Legen Sie die Optionen für die Datenvalidierungsregel fest |
| setRanges | Legen Sie die Bereiche für die Datenvalidierungsregel fest |
| delete | Löschen Sie die Datenvalidierungsregel aus dem Arbeitsblatt |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all data validation rules in current sheet.
const rulesOfSheet = fWorksheet.getDataValidations()

// Get a data validation rule by rule ID.
const ruleById = fWorksheet.getDataValidation(rulesOfSheet[0]?.rule?.uid)

const fRange = fWorksheet.getRange('A1:B10')

// Get first data validation rule in current range.
const ruleOfRange = fRange.getDataValidation()
console.log('ruleOfRange:', ruleOfRange, ruleOfRange?.getCriteriaValues())

// Get all data validation rules in current range.
const rulesOfRange = fRange.getDataValidations()
```

### Datenvalidierung aktualisieren/löschen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new data validation rule that requires a number equal to 20 for the range A1:B10
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberEqualTo(20)
  .build()
fRange.setDataValidation(rule)

const newRuleRange = fWorksheet.getRange('C1:D10')

// Update the rule after 3 seconds
setTimeout(() => {
  fRange.getDataValidation()
    // Change the range to C1:D10
    .setRanges([newRuleRange])
    // Change the criteria to require a number between 1 and 10
    .setCriteria(
      univerAPI.Enum.DataValidationType.DECIMAL,
      [univerAPI.Enum.DataValidationOperator.BETWEEN, '1', '10'],
    )
    // Change option to stop input on validation errors and show error message
    .setOptions({
      allowBlank: true,
      showErrorMessage: true,
      error: 'Please enter a valid value',
      errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
    })
}, 3000)

// Delete the rule after 6 seconds
setTimeout(() => {
  newRuleRange.getDataValidation().delete()
}, 6000)
```

### Validierungsfehler abrufen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all data validation errors for current workbook.
const workbookErrors = await fWorkbook.getAllDataValidationErrorAsync()
console.log('workbookErrors:', workbookErrors)

// Get all data validation errors for current sheet.
const worksheetErrors = await fWorksheet.getAllDataValidationErrorAsync()
console.log('worksheetErrors:', worksheetErrors)

// Get data validation errors for current range.
const fRange = fWorksheet.getRange('A1:B10')
const rangeErrors = await fRange.getDataValidationErrorAsync()
console.log('rangeErrors:', rangeErrors)
```

Jedes Fehlerobjekt enthält die folgenden Felder:
- `sheetName`: Der Name des Arbeitsblatts, in dem der Fehler aufgetreten ist
- `row`: Die Zeilenindex der Zelle, die den Fehler ausgelöst hat
- `column`: Der Spaltenindex der Zelle, die den Fehler ausgelöst hat
- `ruleId`: Die ID der Regel, die den Fehler ausgelöst hat
- `inputValue`: Der Eingabewert, der den Fehler ausgelöst hat
- `rule`: Der Regelinhalts-Snapshot

### Get Validator-Status

Der Validator-Status ist ein Enum-Wert von `DataValidationStatus`, der Folgendes umfasst:
- `valid`: Der Zellenwert besteht die Validierung
- `invalid`: Der Zellenwert besteht die Validierung nicht
- `validating`: Die Zelle wird bearbeitet validiert

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get data validation validator status for current workbook.
fWorkbook.getValidatorStatus().then((status) => {
  console.log('===statusOfWorkbook', status)
})

// Get data validation validator status for current sheet.
fWorksheet.getValidatorStatusAsync().then((status) => {
})

// Get data validation validator status for current range.
const fRange = fWorksheet.getRange('A1:B10')
fRange.getValidatorStatus().then((status) => {
  console.log('===tatusOfRange', status)
})
```

### Ereignis-Listener

Vollständige Definitionen von Ereignistypen finden Sie unter [Ereignisse](https://docs.univer.ai/reference/facade/events).

Das Datenvalidierungsmodul stellt eine Reihe von Ereignissen zur Überwachung von Hinzufügungen, Aktualisierungen, Löschungen und Validierungsstatusänderungen von Validierungsregeln bereit. Alle Ereignisse können mit `univerAPI.addEvent()` abgehört werden.

#### Validierungsregeländerungsereignisse

`univerAPI.Event.SheetDataValidationChanged`: Wird ausgelöst, nachdem sich eine Validierungsregel ändert

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidationChanged, (params) => {
  const { origin, worksheet, workbook, changeType, oldRule, rule } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationAdd`: Wird vor dem Hinzufügen einer Validierungsregel ausgelöst

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationAdd, (params) => {
  const { worksheet, workbook, rule } = params

  // Cancel the data validation rule addition operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationDelete`: Wird vorher ausgelöst Löschen einer Validierungsregel

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDelete, (params) => {
  const { worksheet, workbook, ruleId, rule } = params

  // Cancel the data validation rule deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationDeleteAll`: Wird vor dem Löschen aller Validierungsregeln ausgelöst

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDeleteAll, (params) => {
  const { worksheet, workbook, rules } = params

  // Cancel the data validation rule deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Validierungsregelaktualisierungsereignisse

`univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate`: Wird vor dem Aktualisieren der Validierungsregelkriterien ausgelöst

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newCriteria } = params

  // Cancel the data validation rule criteria update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationRangeUpdate`: Wird vor dem Aktualisieren der Validierungsregel ausgelöst Bereiche

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationRangeUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newRanges } = params

  // Cancel the data validation rule range update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationOptionsUpdate`: Wird vor dem Aktualisieren der Validierungsregeloptionen ausgelöst

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationOptionsUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newOptions } = params

  // Cancel the data validation rule options update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Validierungsstatusereignisse

`univerAPI.Event.SheetDataValidatorStatusChanged`: Wird ausgelöst, wenn sich der Validierungsstatus einer Zelle ändert

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidatorStatusChanged, (params) => {
  const { worksheet, workbook, row, column, status, rule } = params
})

// Remove the event listener, use `disposable.dispose()`
```

Jedes Ereignis enthält die folgenden allgemeinen Parameter:
- `workbook`: Aktuelle Arbeitsmappeninstanz
- `worksheet`: Aktuelle Arbeitsblattinstanz

Besonderes Parameter:
- `rule`: Das zugehörige Validierungsregelobjekt
- `ruleId`: Eindeutige Kennung der Validierungsregel
- `status`: Validierungsstatus (nur in `SheetDataValidatorStatusChanged` Ereignis)
- `newCriteria`: Neue Validierungskriterien (nur im Ereignis `BeforeSheetDataValidationCriteriaUpdate`)
- `newRanges`: Neue Validierungsbereiche (nur im Ereignis `BeforeSheetDataValidationRangeUpdate`)
- `newOptions`: Neue Validierungsoptionen (nur im Ereignis) `BeforeSheetDataValidationOptionsUpdate`-Ereignis)

Alle Ereignisrückrufe mit dem Präfix `Before` können `params.cancel = true` verwenden, um den entsprechenden Vorgang zu verhindern.

### Fehlerstil

Die Option `errorStyle` steuert das Verhalten, wenn ungültige Daten eingegeben werden. Es handelt sich um einen Enum-Wert von `DataValidationErrorStyle`, der Folgendes enthält:
- `STOP`: Verhindert, dass der Benutzer ungültige Daten eingibt
- `WARNING`: Ermöglicht dem Benutzer die Eingabe ungültiger Daten, zeigt jedoch eine Warnung an
- `INFO`: Ermöglicht dem Benutzer die Eingabe ungültiger Daten. zeigt aber eine Informationsmeldung an

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B10')

const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: 'Please enter a number between 1 and 10',
    errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
  })
  .build()
fRange.setDataValidation(rule)
```

const fWorkbook = univerAPI.getActiveWorkbook()
