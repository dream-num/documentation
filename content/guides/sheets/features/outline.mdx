The outline feature, also called grouping or dimension outline, groups rows or columns in a worksheet into collapsible groups, which makes large datasets easier to organize and summarize.

## Introduction

In Univer Sheets, the outline feature supports the following operations:

- **Group rows or columns**: Build hierarchical groups of rows or columns to organize the data.
- **Collapse and expand groups**: Show or hide a group of rows or columns with a single click.
- **Nested groups**: Create multiple levels of groups when the data has a deeper hierarchy.

Outline groups are commonly used in the following scenarios:

- Summarizing detailed data: Group detailed rows under summary rows to produce a clearer view.
- Organizing large datasets: Keep related columns or rows together so that they are easier to navigate.
- Creating collapsible reports: Let users expand or collapse a section of a report as needed.

## Plugin mode

### Installation

```package-install
npm install @univerjs-pro/sheets-outline @univerjs-pro/sheets-outline-ui
```

### Usage

```typescript
import { UniverSheetsOutlinePlugin } from '@univerjs-pro/sheets-outline' // [!code ++]
import { UniverSheetsOutlineUIPlugin } from '@univerjs-pro/sheets-outline-ui' // [!code ++]
import SheetsOutlineUIEnUS from '@univerjs-pro/sheets-outline-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-outline/facade' // [!code ++]

import '@univerjs-pro/sheets-outline-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsOutlineUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsOutlinePlugin)
univer.registerPlugin(UniverSheetsOutlineUIPlugin)
```

If you have a commercial license for Univer, configure it as described in [Using License in Client](/server/license#in-plugin-mode).

## Facade API

The full Facade API type definitions are in [FacadeAPI](/reference/facade/univer).

### Importing

<Callout type="info" title="Plugin mode note">
  The Facade package is imported manually only in plugin mode. Preset mode already includes the corresponding Facade package, so no additional import is required.
</Callout>

```typescript
import '@univerjs-pro/sheets-outline/facade'
```

### Creating row outlines

Create a row outline group with the Facade API:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Group rows 2 to 6 (0-based index: startRow=1, numRows=5)
fWorksheet.addRowOutline(1, 5)
```

### Creating column outlines

Column outlines are created in the same way:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Group columns B to E (0-based index: startColumn=1, numColumns=4)
fWorksheet.addColumnOutline(1, 4)
```

### Collapsing and expanding outlines

Groups can also be collapsed or expanded programmatically:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

const rowOutlines = fWorksheet.getDimensionOutlines(univerAPI.Enum.DimensionOutlineAxis.ROW)
if (rowOutlines.length > 0) {
  // Collapse the first row outline group
  fWorksheet.setDimensionOutlineCollapsed(rowOutlines[0].id, true)

  // Expand it later
  fWorksheet.setDimensionOutlineCollapsed(rowOutlines[0].id, false)
}
```

### Removing outlines

Remove a single outline group by its ID:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

const rowOutlines = fWorksheet.getDimensionOutlines(univerAPI.Enum.DimensionOutlineAxis.ROW)
if (rowOutlines.length > 0) {
  fWorksheet.removeDimensionOutline(rowOutlines[0].id)
}
```

### Clearing outlines in a range

Clear all outline groups inside a range:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Remove all row outline groups fully contained in rows 2 to 10
fWorksheet.clearDimensionOutlines(univerAPI.Enum.DimensionOutlineAxis.ROW, 1, 9)
```

### Querying outlines

Read the outline groups that exist on a worksheet:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all row outlines
const rowOutlines = fWorksheet.getDimensionOutlines(univerAPI.Enum.DimensionOutlineAxis.ROW)
rowOutlines.forEach((outline) => {
  console.log(outline.id, outline.start, outline.end, outline.collapsed)
})

// Get all outlines (both row and column)
const allOutlines = fWorksheet.getDimensionOutlines()
```

## Outline data structure

An outline group has the following properties:

| Property | Type | Description |
|----------|------|-------------|
| `id` | `string` | Unique identifier for the outline group |
| `unitId` | `string` | The workbook unit ID |
| `subUnitId` | `string` | The worksheet sheet ID |
| `axis` | `DimensionOutlineAxis` | The axis of the outline (`row` or `column`) |
| `start` | `number` | Zero-based inclusive start index |
| `end` | `number` | Zero-based inclusive end index |
| `collapsed` | `boolean` | Whether the group is currently collapsed |

## Validation and errors

Creating an outline group performs the following checks:

- **Invalid range**: The range must be valid, meaning non-negative and with a non-zero count.
- **Out of bounds**: The range must remain within the worksheet boundaries.
- **Crossing groups**: A new group cannot cross an existing group.
- **Maximum depth**: Outline groups have a maximum nesting depth.

The range passed to ungrouping must fully contain the range of the outline group; otherwise the check fails.

When a check fails, the command does not run and the error is emitted through the `SheetsOutlineErrorService`.
