クロスヘアハイライトは、現在選択されているセルの行と列を強調表示し、ユーザーがアクティブなセルを判別しやすくします。

<PlaygroundFrame lang="ja-JP" slug="sheets/crosshair-highlighting" clickToShow />

## プリセットモード

クロスヘアハイライト機能はプリセットモードを提供していませんが、プラグインと組み合わせて使用できます。

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### 使い方

```typescript
import UniverPresetSheetsCoreJaJP from '@univerjs/preset-sheets-core/locales/ja-JP'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight' // [!code ++]

import '@univerjs/sheets-crosshair-highlight/facade' // [!code ++]

import '@univerjs/sheets-crosshair-highlight/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetSheetsCoreJaJP,
      SheetsCrosshairHighlightJaJP, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    UniverSheetsCrosshairHighlightPlugin, // [!code ++]
  ],
})
```

## プラグインモード

### インストール

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight'
import SheetsCrosshairHighlightJaJP from '@univerjs/sheets-crosshair-highlight/locale/ja-JP'

import '@univerjs/sheets-crosshair-highlight/lib/index.css'

import '@univerjs/sheets-crosshair-highlight/facade'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      SheetsCrosshairHighlightJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsCrosshairHighlightPlugin) // [!code ++]
```

## Facade API

完全な Facade API の型定義は [FacadeAPI](https://reference.univer.ai/en-US) で確認できます。

### インポート

<Callout type="info" title="プラグインモード注意">
  Facade パッケージの手動 import が必要なのはプラグインモードのみです。プリセットモードには対応する Facade パッケージが内蔵されているため、追加の import は不要です。
</Callout>

```typescript
import '@univerjs/sheets-crosshair-highlight/facade'
```

### クロスヘアハイライトの切り替え

```typescript
univerAPI.setCrosshairHighlightEnabled(true)

univerAPI.setCrosshairHighlightEnabled(false)
```

### クロスヘアハイライトの有効状態の取得

```typescript
univerAPI.getCrosshairHighlightEnabled()
```

### クロスヘアハイライトの色を設定

```typescript
univerAPI.setCrosshairHighlightColor('red')
```

### クロスヘアハイライトの色を取得

```typescript
univerAPI.getCrosshairHighlightColor()
```

### イベントリスナー

イベントの型定義は [Events](https://docs.univer.ai/reference/facade/events) を参照してください。

`CrosshairHighlightEnabledChanged` イベントは、クロスヘアハイライトの有効状態が変更されたときにトリガーします。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CrosshairHighlightEnabledChanged, (params) => {
  const { enabled, workbook, worksheet } = params
})

// イベントリスナーを削除するには `disposable.dispose()` を使用します
```

`CrosshairHighlightColorChanged` イベントは、クロスヘアハイライトの色が変更されたときにトリガーします。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CrosshairHighlightColorChanged, (params) => {
  const { color, workbook, worksheet } = params
})

// イベントリスナーを削除するには `disposable.dispose()` を使用します
```
