상태 포맷은 상태가 보유할 때 자동으로 세포의 형식을 변경하므로 중요한 데이터와 추세가 눈에 띄게됩니다. 데이터가 한 눈에 쉽게 읽을 수 있도록 여러 조건과 포맷 옵션을 지원합니다.

## 플러그인 모드

### 설치

```package-install
npm install @univerjs/sheets-conditional-formatting @univerjs/sheets-conditional-formatting-ui
```

### 사용법

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsConditionalFormattingPlugin } from '@univerjs/sheets-conditional-formatting' // [!code ++]
import { UniverSheetsConditionalFormattingUIPlugin } from '@univerjs/sheets-conditional-formatting-ui' // [!code ++]
import SheetsConditionalFormattingUIEnUS from '@univerjs/sheets-conditional-formatting-ui/locale/en-US' // [!code ++]
import '@univerjs/sheets-conditional-formatting-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-conditional-formatting/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsConditionalFormattingUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsConditionalFormattingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsConditionalFormattingUIPlugin) // [!code ++]
```

### 조건부 서식 규칙 만들기

[`FWorksheet.newConditionalFormattingRule()`](https://docs.univer.ai/reference/facade/worksheet#newconditionalformattingrule)는 `FConditionalFormattingBuilder`를 반환합니다. 규칙을 정의하기 위해 체인의 방법을 호출합니다.

[`FConditionalFormattingBuilder`](/reference/facade/conditional-formatting-builder)의 회원 방법에는 다음이 포함됩니다.

| 메서드 | 설명 |
| ---- | ---- |
| build | 규칙을 짓다 |
| copy | Deep-clones 현재 빌더 |
| createCfId | 상태 형식 ID 생성 |
| getRanges | 현재 상태 형식의 범위를 가져옵니다 |
| setRanges | 규칙을 설정하면 |
| setAverage | 평균값 규칙 설정 |
| setUniqueValues | 독특한 가치 규칙을 설정 |
| setDuplicateValues | 중복값 규칙 설정 |
| setRank | 순위 규칙 설정 |
| setIconSet | 아이콘 세트 규칙 설정 |
| setColorScale | 색상 가늠자 규칙을 설정합니다 |
| setDataBar | 데이터 바 규칙 설정 |
| setBackground | 배경 색상 설정 |
| setBold | 대담한 텍스트 설정 |
| setFontColor | 글꼴 색상 설정 |
| setItalic | italic 텍스트 설정 |
| setStrikethrough | 스트라이크 |
| setUnderline | 설정 밑줄 |
| whenCellEmpty | 세포가 비어있을 때 불 |
| whenCellNotEmpty | 세포가 빈번하지 않을 때 불 |
| whenDate | 날짜가 특정 기간에 떨어질 때 불 |
| whenFormulaSatisfied | 수식이 진정한 평가 될 때 불 |
| whenNumberBetween | 숫자가 두 값 사이일 때 불, 또는 그들 중 하나에 동등 |
| whenNumberEqualTo | 숫자가 주어진 값을 동등할 때 불 |
| whenNumberGreaterThan | 숫자가 주어진 값보다 더 큰 화재 |
| whenNumberGreaterThanOrEqualTo | 숫자가 주어진 값보다 크거나 같을 때 불 |
| whenNumberLessThan | 숫자가 주어진 값 보다는 더 적은 때 불 |
| whenNumberLessThanOrEqualTo | 숫자가 주어진 값보다 작거나 같을 때 불 |
| whenNumberNotBetween | 숫자가 두 값과 같지 않을 때 불 |
| whenNumberNotEqualTo | 숫자가 주어진 값을 동등하지 않을 때 불 |
| whenTextContains | 텍스트가 지정된 값을 포함 할 때 불 |
| whenTextDoesNotContain | 텍스트가 지정된 값을 포함하지 않는 경우 불 |
| whenTextEndsWith | 텍스트가 지정된 값으로 종료 될 때 불 |
| whenTextEqualTo | 텍스트가 주어진 값과 동일 할 때 불 |
| whenTextStartsWith | 텍스트가 지정된 값으로 시작될 때 불 |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)
```

### 조건부 서식 규칙 가져오기

- `FWorksheet.getConditionalFormattingRules()`는 워크시트의 모든 조건부 서식 규칙을 가져옵니다
- `FRange.getConditionalFormattingRules()`는 범위의 모든 조건부 서식 규칙을 가져옵니다

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Get all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
const rulesOfSheet = fWorksheet.getConditionalFormattingRules()

// Get all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
const rulesOfRange = fRange.getConditionalFormattingRules()
```

### 조건부 서식 규칙 제거하기

`FWorksheet.deleteConditionalFormattingRule(cfId)`는 워크 시트에서 규칙을 제거합니다. `cfId` 규칙의 ID입니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Remove the first conditional formatting rule
fWorksheet.deleteConditionalFormattingRule(rules[0]?.cfId)
```

### 조건부 서식 규칙 업데이트하기

`FWorksheet.setConditionalFormattingRule(cfId, rule)`는 워크 시트의 규칙을 대체합니다. `cfId`은 대체 규칙의 ID이며 `rule`가 새로운 규칙입니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)

// Modify the first rule to apply to a new range
const rules = fWorksheet.getConditionalFormattingRules()
const newRuleRange = fWorksheet.getRange('A1:D10')
fWorksheet.setConditionalFormattingRule(rules[0]?.cfId, { ...rules[0], ranges: [newRuleRange.getRange()] })
```

### 조건부 서식 규칙의 우선순위 변경하기

`FWorksheet.moveConditionalFormattingRule(cfId, toCfId, type)`는 우선순위에 규칙의 위치를 변경합니다. `cfId`은 이동 규칙입니다, `toCfId` 규칙은 상대로 이동하고, `type` 이동 유형 (예를들면, 'before', 'after')입니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Move the third rule before the first rule
const rule = rules[2]
const targetRule = rules[0]
fWorksheet.moveConditionalFormattingRule(rule?.cfId, targetRule?.cfId, 'before')
```

### 모든 조건부 서식 규칙 지우기

- `FWorksheet.clearConditionalFormatRules()`는 워크시트의 모든 조건부 서식 규칙을 지웁니다
- `FRange.clearConditionalFormatRules()`는 범위의 모든 조건부 서식 규칙을 지웁니다

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Clear all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.clearConditionalFormatRules()

// Clear all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
fRange.clearConditionalFormatRules()
```

## 규칙 설명과 미리보기 재사용 [#custom-rule-ui]

`@univerjs/sheets-conditional-formatting-ui`에서 `getRuleDescribe` 및 `ConditionalFormattingRulePreview`를 사용자 정의 규칙 목록을 작성하려면 `getRuleDescribe(rule, localeService)`에 전체 규칙을 전달하고 미리보기에 구성 (`rule.rule`) 만 전달하십시오. 미리보기는 구성 된 외관을 렌더링하고 워크 시트 셀을 평가하지 않습니다. Univer의 React 컨텍스트 내에서 렌더링하십시오.

`CF_PANEL_KEY`는 내장 패널을 식별하므로 [구성 요소 overrides](/guides/sheets/ui/components)를 타겟으로 할 수 있습니다. `IConditionFormattingPanelProps.onEditorExit` 콜백은 편집 종료 후 실행됩니다. 제출 후 취소 또는 작업 시트가 활성화되거나 제거되면. 저장이 성공하거나 사이드 바가 닫을지 여부를 나타냅니다.

```tsx
import type { IConditionFormattingRule } from '@univerjs/sheets-conditional-formatting'
import { LocaleService } from '@univerjs/core'
import { ConditionalFormattingRulePreview, getRuleDescribe } from '@univerjs/sheets-conditional-formatting-ui'
import { useDependency } from '@univerjs/ui'

interface IRuleSummaryProps {
  rule: IConditionFormattingRule
}

function RuleSummary({ rule }: IRuleSummaryProps) {
  const localeService = useDependency(LocaleService)

  return (
    <div>
      <span>{getRuleDescribe(rule, localeService)}</span>
      <ConditionalFormattingRulePreview rule={rule.rule} />
    </div>
  )
}
```

## 규칙 우선순위와 조건 충족 시 중지 [#stop-if-true]

규칙은 우선순위에 적용됩니다. 주어진 세포의 경우, `stopIfTrue: true`가 낮은 선명한 규칙을 억제하는 일치하는 규칙은 스타일이 없습니다. 규칙이 일치하지 않는 경우, 평가는 계속됩니다. 더 높은 선명한 규정의 결과는 효력에서 남아 있습니다. 규칙 편집기는 강조 규칙을 위한 이 선택권을 제공합니다; 색깔 가늠자, 자료 막대기 및 아이콘 세트는 그것을 가지고 있지 않습니다.

예를 들어, 새로 추가된 규칙이 목록의 상단에 배치되기 때문에 더 낮은 선명도 배경 규칙을 추가합니다. 중지가 활성화되면 90은 녹색 배경없이 대담하게 나타납니다. 60은 여전히 배경을받습니다. `stopIfTrue`는 외부 규칙 객체에 속하며 `rule`에 속합니다.

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

const ranges = [sheet.getRange('B2:B10').getRange()]
const backgroundRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(50)
  .setBackground('#DCFCE7')
  .setRanges(ranges)
  .build()
const priorityRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(80)
  .setBold(true)
  .setRanges(ranges)
  .build()

sheet.addConditionalFormattingRule(backgroundRule)
sheet.addConditionalFormattingRule({ ...priorityRule, stopIfTrue: true })
```
