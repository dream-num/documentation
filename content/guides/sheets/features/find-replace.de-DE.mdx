Mit der Funktion „Suchen und Ersetzen“ können Benutzer schnell nach bestimmten Inhalten in Tabellenkalkulationen suchen und diese ersetzen. Dabei werden verschiedene Abgleichsoptionen unterstützt, um Benutzern bei der effizienten Verarbeitung von Daten zu helfen.

<PlaygroundFrame lang="en-US" slug="sheets/find-replace" clickToShow />

## Voreingestellter Modus

### Installation

```package-install
npm install @univerjs/preset-sheets-find-replace
```

### Nutzung

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsFindReplacePreset } from '@univerjs/preset-sheets-find-replace' // [!code ++]
import UniverPresetSheetsFindReplaceEnUS from '@univerjs/preset-sheets-find-replace/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-find-replace/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsFindReplaceEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsFindReplacePreset(), // [!code ++]
  ],
})
```

## Plugin Modus

### Installation

```package-install
npm install @univerjs/find-replace @univerjs/sheets-find-replace
```

### Verwendung

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverFindReplacePlugin } from '@univerjs/find-replace' // [!code ++]
import FindReplaceEnUS from '@univerjs/find-replace/locale/en-US' // [!code ++]
import { UniverSheetsFindReplacePlugin } from '@univerjs/sheets-find-replace' // [!code ++]

import '@univerjs/find-replace/lib/index.css' // [!code ++]

import '@univerjs/sheets-find-replace/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      FindReplaceEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverFindReplacePlugin) // [!code ++]
univer.registerPlugin(UniverSheetsFindReplacePlugin) // [!code ++]
```

### Textfinder erstellen

`univerAPI.createTextFinderAsync()` erstellt einen Textfinder und gibt eine `FTextFinder`-Instanz zurück.

Hier sind einige Mitgliedsmethoden aufgeführt [`FTextFinder`](https://docs.univer.ai/reference/facade/find-replace):

| Methode | Beschreibung |
| ------ | ----------- |
| findAll | Alle übereinstimmenden Zellen des aktuellen Blattes abrufen. Die aktuell übereinstimmende Zelle ist die letzte übereinstimmende Zelle. |
| findNext | Die nächste übereinstimmende Zelle des aktuellen Blattes abrufen. Falls vorhanden, die nächste übereinstimmende Zelle zurückgeben und die aktuell übereinstimmende Zelle in die nächste übereinstimmende Zelle verschieben. |
| findPrevious | Die vorherige übereinstimmende Zelle des aktuellen Blattes abrufen. Falls vorhanden, die vorherige übereinstimmende Zelle zurückgeben und die aktuell übereinstimmende Zelle in die vorherige übereinstimmende Zelle verschieben Zelle |
| getCurrentMatch | Rufen Sie die aktuelle übereinstimmende Zelle des aktuellen Blatts ab. |
| matchCaseAsync | Setzen Sie die Option „Groß-/Kleinschreibung abgleichen“. Wenn wahr, stimmt die Suchoperation mit der Groß-/Kleinschreibung überein, andernfalls ignoriert die Suchoperation die Groß-/Kleinschreibung. |
| matchEntireCellAsync | Setzen Sie die Option „Ganze Zelle vergleichen“, wenn wahr, stimmt die Suchoperation mit dem gesamten Zellenwert überein, andernfalls stimmt die Suchoperation mit einem Teil des Zellwerts überein. |
| matchFormulaTextAsync | Setzen Sie die Option „Formeltext vergleichen“. Wenn wahr, stimmt die Suchoperation mit dem Formeltext überein, andernfalls stimmt die Suchoperation überein Wert |
| replaceAllWithAsync | Ersetzen Sie den gesamten übereinstimmenden Text durch den angegebenen Text |
| replaceWithAsync | Ersetzen Sie den aktuell übereinstimmenden Text durch den angegebenen Text |
| ensureCompleteAsync | Stellen Sie sicher, dass der Suchvorgang abgeschlossen ist. Verwenden Sie diese Methode insbesondere, wenn sich das aktuelle Blatt geändert hat, um sicherzustellen, dass der Suchvorgang abgeschlossen ist. |

```typescript
// Assume the current sheet is empty sheet.
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set some values to the range A1:D10.
const fRange = fWorksheet.getRange('A1:D10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// Create a text-finder to find the text '5'.
const textFinder = await univerAPI.createTextFinderAsync('5')

// Find all cells that contain the text '5'.
const matchCells = textFinder.findAll()
matchCells.forEach((cell) => {
  cell.getA1Notation() // D2, C3, B4, A5
})
```
