Bedingte Formatierung ermöglicht es Benutzern, das Format von Zellen basierend auf bestimmten Bedingungen automatisch zu ändern und so wichtige Daten oder Trends hervorzuheben. Es unterstützt verschiedene Bedingungen und Formatierungsoptionen und hilft Benutzern, Daten intuitiver zu verstehen.

## Voreingestellter Modus

### Installation

```package-install
npm install @univerjs/preset-sheets-conditional-formatting
```

### Nutzung

```typescript
import { UniverSheetsConditionalFormattingPreset } from '@univerjs/preset-sheets-conditional-formatting' // [!code ++]
import UniverPresetSheetsConditionalFormattingEnUS from '@univerjs/preset-sheets-conditional-formatting/locales/en-US' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-conditional-formatting/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsConditionalFormattingEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsConditionalFormattingPreset(), // [!code ++]
  ],
})
```

### Regeln für bedingte Formatierung erstellen

[`FWorksheet.newConditionalFormattingRule()`](https://docs.univer.ai/reference/facade/worksheet#newconditionalformattingrule) erstellt einen Builder für bedingte Formatierung und gibt eine Instanz von `FConditionalFormattingBuilder` zurück, die zum Generieren von Regeln für bedingte Formatierung über die Methode verwendet werden kann Verkettung.

Hier sind einige Mitgliedsmethoden von [`FConditionalFormattingBuilder`](https://docs.univer.ai/reference/facade/conditional-formatting):

| Methode | Beschreibung |
| ---- | ---- |
| build | Erstellt die Regel für bedingte Formatierung |
| copy | Klonen Sie einen aktuellen Builder tief |
| createCfId | Erstellen Sie eine ID für ein bedingtes Format |
| getRanges | Ruft den Bereich des aktuellen bedingten Formats ab |
| setRanges | Legt den Bereich der Regel für bedingte Formatierung fest |
| setAverage | Legt die Regel für die bedingte Formatierung des Durchschnittswerts fest |
| setUniqueValues | Legt die bedingte Formatierung für den eindeutigen Wert fest Regel |
| setDuplicateValues | Legt die bedingte Formatierungsregel für doppelte Werte fest |
| setRank | Legt die bedingte Formatierungsregel für die Rangfolge fest |
| setIconSet | Legt die bedingte Formatierungsregel für den Symbolsatz fest |
| setColorScale | Legt die bedingte Formatierungsregel für die Farbskala fest |
| setDataBar | Legt die bedingte Formatierungsregel für die Datenleiste fest |
| setBackground | Legt die Hintergrundfarbe des bedingten Formats fest |
| setBold | Legt fest, ob die Schriftart des bedingten Formats fett ist |
| setFontColor | Legt die Schriftfarbe fest Bedingtes Format |
| setItalic | Legt fest, ob die Schriftart des bedingten Formats kursiv ist. |
| setStrikethrough | Legt fest, ob die Schriftart des bedingten Formats durchgestrichen ist. |
| setUnderline | Legt fest, ob die Schriftart des bedingten Formats unterstrichen ist. |
| whenCellEmpty | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn die Zelle leer ist. |
| whenCellNotEmpty | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn die Zelle nicht leer ist. |
| whenDate | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn das Datum innerhalb liegt einen bestimmten Zeitraum |
| whenFormulaSatisfied | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn das Ergebnis der Formelberechnung wahr ist. |
| whenNumberBetween | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn die Zahl zwischen zwei angegebenen Werten liegt oder einem von ihnen entspricht. |
| whenNumberEqualTo | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn die Zahl gleich dem angegebenen Wert ist. |
| whenNumberGreaterThan | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn die Zahl größer als der angegebene Wert ist. |
| whenNumberGreaterThanOrEqualTo | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn die Zahl größer ist kleiner oder gleich dem angegebenen Wert |
| whenNumberLessThan | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn die Zahl kleiner als der angegebene Wert ist |
| whenNumberLessThanOrEqualTo | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn die Zahl kleiner oder gleich dem angegebenen Wert ist. |
| whenNumberNotBetween | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn die Zahl nicht zwischen zwei angegebenen Werten liegt und diesen nicht entspricht. |
| whenNumberNotEqualTo | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn die Zahl nicht gleich dem angegebenen Wert ist. |
| whenTextContains | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn der Text den angegebenen Wert enthält. |
| whenTextDoesNotContain | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn der Text keinen Wert enthält der angegebene Wert |
| whenTextEndsWith | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn der Text mit dem angegebenen Wert endet |
| whenTextEqualTo | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn der Text dem angegebenen Wert entspricht |
| whenTextStartsWith | Legt die Regel für das bedingte Format so fest, dass sie ausgelöst wird, wenn der Text mit dem angegebenen Wert beginnt |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)
```

### Bedingte Formatierungsregeln abrufen

- `FWorksheet.getConditionalFormattingRules()` ruft alle bedingten Formatierungsregeln des Arbeitsblatts ab
- `FRange.getConditionalFormattingRules()` ruft alle bedingten Formatierungsregeln des Arbeitsblatts ab Bereich

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Get all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
const rulesOfSheet = fWorksheet.getConditionalFormattingRules()

// Get all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
const rulesOfRange = fRange.getConditionalFormattingRules()
```

### Bedingte Formatierungsregeln entfernen

`FWorksheet.deleteConditionalFormattingRule(cfId)` entfernt eine bedingte Formatierungsregel aus dem Arbeitsblatt, wobei `cfId` die ID der bedingten Formatierungsregel ist.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Remove the first conditional formatting rule
fWorksheet.deleteConditionalFormattingRule(rules[0]?.cfId)
```

### Bedingte Formatierungsregeln aktualisieren

`FWorksheet.setConditionalFormattingRule(cfId, rule)` aktualisiert eine bedingte Formatierungsregel im Arbeitsblatt, wobei `cfId` die ID der bedingten Formatierungsregel und `rule` die neue bedingte Formatierungsregel ist.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)

// Modify the first rule to apply to a new range
const rules = fWorksheet.getConditionalFormattingRules()
const newRuleRange = fWorksheet.getRange('A1:D10')
fWorksheet.setConditionalFormattingRule(rules[0]?.cfId, { ...rules[0], ranges: [newRuleRange.getRange()] })
```

### Ändern Sie die Priorität von bedingten Formatierungsregeln

`FWorksheet.moveConditionalFormattingRule(cfId, toCfId, type)` Ändert die Priorität einer bedingten Formatierungsregel im Arbeitsblatt, wobei `cfId` die ID der bedingten Formatierungsregel ist, `toCfId` die ID der Zielregel für bedingte Formatierung ist und `type` den Verschiebungstyp angibt (z. B. „vor“, „nach“).

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Move the third rule before the first rule
const rule = rules[2]
const targetRule = rules[0]
fWorksheet.moveConditionalFormattingRule(rule?.cfId, targetRule?.cfId, 'before')
```

### Alle bedingten Formatierungen löschen Regeln

- `FWorksheet.clearConditionalFormatRules()` löscht alle bedingten Formatierungsregeln des Arbeitsblatts.
- `FRange.clearConditionalFormatRules()` löscht alle bedingten Formatierungsregeln des Bereichs.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Clear all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.clearConditionalFormatRules()

// Clear all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
fRange.clearConditionalFormatRules()
```
