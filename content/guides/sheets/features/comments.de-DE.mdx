Kommentare ermöglichen Benutzern das Hinzufügen von Kommentaren und Antworten in Dokumenten und erleichtern so die Kommunikation und Zusammenarbeit zwischen Teammitgliedern.

## Voreingestellter Modus

### Installation

```package-install
npm install @univerjs/preset-sheets-thread-comment
```

### Verwendung

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsThreadCommentPreset } from '@univerjs/preset-sheets-thread-comment' // [!code ++]
import UniverPresetSheetsThreadCommentEnUS from '@univerjs/preset-sheets-thread-comment/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-thread-comment/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsThreadCommentEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsThreadCommentPreset(), // [!code ++]
  ],
})
```

#### Verwendung mit Kollaborationsfunktion <IconWrapper className="inline-flex" type="pro" size="xs" icon={null} />

Wenn Sie die Funktion [collaboration](/guides/sheets/features/collaboration) mit `UniverSheetsCollaborationPreset` verwenden, stellen Sie sicher, dass Sie die Option `collaboration: true` im `UniverSheetsThreadCommentPreset`:

```typescript
UniverSheetsThreadCommentPreset({
  collaboration: true, // [!code ++]
})
```

### Zellkommentar erstellen

Sie können einen neuen Kommentar-Generator mit `univerAPI.newTheadComment()` erstellen, der eine Instanz von `FTheadCommentBuilder` zurückgibt. Sie können Methoden verketten, um verschiedene Eigenschaften des Kommentars festzulegen.

Im Folgenden sind einige Mitgliedsmethoden von [`FTheadCommentBuilder`](https://docs.univer.ai/reference/facade/thread-comment) aufgeführt:

| Methode | Beschreibung |
| ---- | ---- |
| setContent | Inhalt des Kommentars festlegen |
| setPersonId | Personen-ID für den Kommentar festlegen |
| setDateTime | Datum und Uhrzeit des Kommentars festlegen |
| setId | ID des Kommentars festlegen |
| setThreadId | Thread-ID des Kommentars festlegen |

```typescript
// Create a new comment
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)

console.log(commentBuilder.content.toPlainText())

// Add the comment to cell A1
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const cell = fWorksheet.getRange('A1')
const result = await cell.addCommentAsync(commentBuilder)
```

### Zellenkommentare abrufen

Sie können Kommentare mit den folgenden Methoden abrufen, die eine Instanz von `FThreadComment` zurückgeben. Anschließend können Sie Vorgänge wie das Aktualisieren, Löschen oder Auflösen des Kommentars ausführen.

- `FWorkbook.getComments()`: Alle Kommentare in der Arbeitsmappe abrufen
- `FWorksheet.getComments()`: Alle Kommentare im Arbeitsblatt abrufen
- `FRange.getComment()`: Den Kommentar der Zelle oben links in der Arbeitsmappe abrufen Bereich
- `FRange.getComments()`: Alle Kommentare im Bereich abrufen

Im Folgenden sind einige Mitgliedsmethoden von [`FThreadComment`](https://docs.univer.ai/reference/facade/thread-comment) aufgeführt:

| Methode | Beschreibung |
| ---- | ---- |
| getIsRoot | Ob der Kommentar ein Root ist Kommentar |
| getCommentData | Kommentardaten abrufen |
| getReplies | Liste der Antworten auf den Kommentar abrufen |
| getRange | Bereich des Kommentars abrufen |
| getRichText | Rich-Text-Inhalt des Kommentars abrufen |
| deleteAsync | Kommentar und seine Antworten löschen |
| updateAsync | Inhalt des Kommentars aktualisieren |
| resolveAsync | Kommentar auflösen |
| replyAsync | Auf antworten Kommentar |

```typescript
// Get all comments in the workbook
const fWorkbook = univerAPI.getActiveWorkbook()
fWorkbook.getComments()

// Get all comments in the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
Worksheet.getComments()

const fRange = fWorksheet.getRange('A1:B2')
// Get the comment of cell A1
fRange.getComment()

// Get all comments in the range A1:B2
fRange.getComments()
```

### Zellenkommentare löschen

- `FWorkbook.clearComments()`: Alle Kommentare im Bereich löschen Arbeitsmappe
- `FWorksheet.clearComments()`: Alle Kommentare im Arbeitsblatt löschen
- `FRange.clearCommentAsync()`: Den Kommentar der oberen linken Zelle im Bereich löschen
- `FRange.clearCommentsAsync()`: Alle Kommentare im Bereich löschen

```typescript
// Clear all comments in the workbook
const fWorkbook = univerAPI.getActiveWorkbook()
await fWorkbook.clearComments()

// Clear all comments in the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
await fWorksheet.clearComments()

const fRange = fWorksheet.getRange('A1:B2')

// Clear the comment of cell A1
await fRange.clearCommentAsync()

// Clear all comments in the range A1:B2
await fRange.clearCommentsAsync()
```

### Liste mit Kommentarantworten abrufen

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all comments in the worksheet
const comments = fWorksheet.getComments()
comments.forEach((comment) => {
  // If the comment is a root comment, get its replies
  if (comment.getIsRoot()) {
    const replies = comment.getReplies()
    replies.forEach((reply) => {
      console.log(reply.getCommentData())
    })
  }
})
```

### Aktualisieren/Löschen/Auflösen/Antworten auf Kommentare

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a new comment and add it to cell A1
const richText = univerAPI.newRichText().insertText('hello univer')
const commentBuilder = univerAPI.newTheadComment()
  .setContent(richText)
  .setId('mock-comment-id')
const cell = fWorksheet.getRange('A1')
await cell.addCommentAsync(commentBuilder)

// Update the comment and reply after 3 seconds
setTimeout(async () => {
  // Get the comment by ID and update its content
  const comment = fWorksheet.getCommentById('mock-comment-id')
  const newRichText = univerAPI.newRichText().insertText('Hello Univer AI')
  await comment.updateAsync(newRichText)

  // Create a new reply comment and set its content
  const replyText = univerAPI.newRichText().insertText('Hello Univer AI! GO! GO! GO!')
  const reply = univerAPI.newTheadComment().setContent(replyText)
  await comment.replyAsync(reply)
}, 3000)

// Resolve the comment and delete it after 6 seconds
setTimeout(async () => {
  const comment = fWorksheet.getCommentById('mock-comment-id')
  await comment.resolveAsync()
  await comment.deleteAsync()
}, 6000)
```

### Ereignis-Listener

Vollständige Ereignistypdefinitionen finden Sie in [Ereignisse](https://docs.univer.ai/reference/facade/events).

Das Kommentarmodul stellt eine Reihe von Ereignissen bereit, um auf Hinzufügungen, Aktualisierungen, Löschungen und Änderungen des Auflösungsstatus von Kommentaren zu warten. Alle Ereignisse können mit `univerAPI.addEvent()` abgehört werden.

#### Kommentieren Sie Hinzufügungsereignisse

`univerAPI.Event.CommentAdded`: Wird ausgelöst, nachdem ein Kommentar hinzugefügt wurde.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentAdded, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentAdd`: Wird ausgelöst, bevor ein Kommentar hinzugefügt wird.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentAdd, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // Cancel the comment addition operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Kommentaraktualisierungsereignisse

`univerAPI.Event.CommentUpdated`: Wird ausgelöst, nachdem ein Kommentar aktualisiert wurde.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentUpdated, (params) => {
  const { comment, workbook, worksheet, row, col } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentUpdate`: Wird ausgelöst, bevor ein Kommentar hinzugefügt wird aktualisiert

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentUpdate, (params) => {
  const { comment, workbook, worksheet, row, col, newContent } = params

  // Cancel the comment update operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Ereignisse zum Löschen von Kommentaren

`univerAPI.Event.CommentDeleted`: Wird ausgelöst, nachdem ein Kommentar gelöscht wurde

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentDeleted, (params) => {
  const { commentId, workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentDelete`: Wird ausgelöst, bevor ein Kommentar gelöscht wird

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentDelete, (params) => {
  const { comment, workbook, worksheet, row, col } = params

  // Cancel the comment deletion operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

#### Ereignisse zum Status der Kommentarauflösung

`univerAPI.Event.CommentResolved`: Wird nach dem Auflösungsstatus eines Kommentars ausgelöst Änderungen

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommentResolved, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`univerAPI.Event.BeforeCommentResolve`: Wird ausgelöst, bevor sich der Auflösungsstatus eines Kommentars ändert

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommentResolve, (params) => {
  const { comment, row, col, resolved, workbook, worksheet } = params

  // Cancel the comment resolution operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

Alle Ereignisse enthalten die folgenden allgemeinen Parameter:

- `workbook`: Aktuelle Arbeitsmappeninstanz
- `worksheet`: Aktuelle Arbeitsblattinstanz
- `row`: Zeilenindex der Kommentar
- `col`: Spaltenindex des Kommentars
- `comment`: Kommentarobjekt (nur `commentId` ist in Löschereignissen enthalten)

Spezielle Parameter:

- `BeforeCommentUpdate` Ereignis enthält `newContent`: Neuer Kommentarinhalt (RichTextValue-Typ)
- `CommentResolved`- und `BeforeCommentResolve`-Ereignisse umfassen `resolved`: Auflösungsstatus des Kommentars

Alle `Before`-Ereignisrückruffunktionen mit Präfix können `params.cancel = true` zurückgeben, um das zu verhindern entsprechende Operation.
