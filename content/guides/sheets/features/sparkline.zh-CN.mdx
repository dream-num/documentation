迷你图是嵌入单个单元格的小图表，可以直观地展示一段数据的趋势或某个关键指标。

## 插件模式

### 安装

```package-install
npm install @univerjs-pro/sheets-sparkline @univerjs-pro/sheets-sparkline-ui
```

### 使用

```typescript
import { UniverSheetSparklinePlugin } from '@univerjs-pro/sheets-sparkline' // [!code ++]
import { UniverSheetSparklineUIPlugin } from '@univerjs-pro/sheets-sparkline-ui' // [!code ++]
import SheetsSparklineUIZhCN from '@univerjs-pro/sheets-sparkline-ui/locale/zh-CN' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-sparkline/facade' // [!code ++]

import '@univerjs-pro/sheets-sparkline-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_CN,
  locales: {
    [LocaleType.ZH_CN]: mergeLocales(
      SheetsSparklineUIZhCN, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetSparklinePlugin)
univer.registerPlugin(UniverSheetSparklineUIPlugin)
```

如果使用 Univer 商业许可证，配置方式见[在客户端使用许可证](/server/license#in-plugin-mode)。

## Facade API

### 引入

<Callout type="info" title="插件模式提示">
  只有插件模式需要手动引入 Facade 包。预设模式已内置对应的 Facade 包，无需单独引入。
</Callout>

```typescript
import '@univerjs-pro/sheets-sparkline/facade'
```

### 添加迷你图

[`FWorksheet.addSparkline`](https://docs.univer.ai/reference/facade/worksheet#addsparkline) 在指定区域添加迷你图，并返回包含这些迷你图的 [`FSparklineGroup`](/reference/facade/sparkline-group)。图表类型可选，默认为 `univerAPI.Enum.SparklineTypeEnum.LINE_CHART`。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 创建一个迷你图，数据源为 A1:A7，放置在 A10 单元格中。
const sourceRanges = [fWorksheet.getRange('A1:A7').getRange()]
const targetRanges = [fWorksheet.getRange('A10').getRange()]
const sparklineGroup = fWorksheet.addSparkline(sourceRanges, targetRanges)
```

`FSparklineGroup` 管理为目标区域创建的所有迷你图。它的方法用于修改整个迷你图组的数据源、配置和显示状态，每个组成员各需一个数据源区域和一个目标区域。如需操作单个单元格，请使用 [`getSparklineByCell`](#获取迷你图和迷你图组实例)。

```typescript
sparklineGroup?.changeDataSource([fWorksheet.getRange('B1:B7').getRange()], [fWorksheet.getRange('B10').getRange()])
sparklineGroup?.setConfig({ lineWidth: 3 })
```

迷你图组的方法作用于该组自身的单元格和工作表，因此持有迷你图组后无需切换活动工作表或选区即可更新。`setConfig()` 会合并顶层配置字段。`points`、`axis` 等嵌套对象则整体替换。

### 组合迷你图和取消组合迷你图

[`FWorksheet.composeSparkline`](https://docs.univer.ai/reference/facade/worksheet#composesparkline) 将多个迷你图合并为一个迷你图组，[`FWorksheet.unComposeSparkline`](https://docs.univer.ai/reference/facade/worksheet#uncomposesparkline) 则将迷你图组拆分为多个迷你图。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 创建一个迷你图，数据源为 A1:A7，放置在 A10 单元格中。
fWorksheet.addSparkline(
  [fWorksheet.getRange('A1:A7').getRange()],
  [fWorksheet.getRange('A10').getRange()],
)

// 创建一个迷你图，数据源为 B1:B7，放置在 B10 单元格中。
fWorksheet.addSparkline(
  [fWorksheet.getRange('B1:B7').getRange()],
  [fWorksheet.getRange('B10').getRange()],
)

// 将两个迷你图组合成一个迷你图组
fWorksheet.composeSparkline([fWorksheet.getRange('A10:B10').getRange()])
console.log(fWorksheet.getAllSubSparkline().size) // 1

// 3 秒后取消组合迷你图组
setTimeout(() => {
  fWorksheet.unComposeSparkline([fWorksheet.getRange('A10:B10').getRange()])
  console.log(fWorksheet.getAllSubSparkline().size) // 2
}, 3000)
```

### 获取迷你图和迷你图组实例

[`FWorksheet.getSparklineByCell`](https://docs.univer.ai/reference/facade/worksheet#getsparklinebycell) 返回指定单元格中的 `FSparkline` 实例。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 创建一个迷你图，数据源为 A1:A7，放置在 A10 单元格中。
const sourceRanges = [fWorksheet.getRange('A1:A7').getRange()]
const targetRanges = [fWorksheet.getRange('A10').getRange()]
fWorksheet.addSparkline(sourceRanges, targetRanges)

const sparkline = fWorksheet.getSparklineByCell(9, 0)
console.log('Cell A10: ', sparkline)
console.log('Cell A11: ', fWorksheet.getSparklineByCell(10, 0))
```

[`FWorksheet.getSparklineGroupByCell`](https://docs.univer.ai/reference/facade/worksheet#getsparklinegroupbycell) 返回指定单元格中的 `FSparklineGroup` 实例。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 创建一个迷你图，数据源为 A1:A7，放置在 A10 单元格中。
fWorksheet.addSparkline(
  [fWorksheet.getRange('A1:A7').getRange()],
  [fWorksheet.getRange('A10').getRange()],
)

// 创建一个迷你图，数据源为 B1:B7，放置在 B10 单元格中。
fWorksheet.addSparkline(
  [fWorksheet.getRange('B1:B7').getRange()],
  [fWorksheet.getRange('B10').getRange()],
)
console.log('Cell A10: ', fWorksheet.getSparklineGroupByCell(9, 0))

// 3 秒后将两个迷你图组合成一个迷你图组
setTimeout(() => {
  fWorksheet.composeSparkline([fWorksheet.getRange('A10:B10').getRange()])
  console.log('Cell A10: ', fWorksheet.getSparklineGroupByCell(9, 0))
}, 3000)
```

[`FSparkline`](https://docs.univer.ai/reference/facade/sparkline) 实例提供以下方法：

| 方法 | 描述 |
| --- | --- |
| changeDataSource | 修改当前单元格内迷你图的数据源和放置位置 |
| removeSparkline | 删除当前单元格内的迷你图 |

[`FSparklineGroup`](/reference/facade/sparkline-group) 实例提供以下方法：

| 方法 | 描述 |
| --- | --- |
| changeDataSource | 修改当前单元格内迷你图组的数据源和放置位置 |
| removeSparklineGroup | 删除当前单元格内的迷你图组 |
| setConfig | 修改当前单元格内迷你图组的配置 |

### 事件监听

完整的事件类型定义见 [Events](https://docs.univer.ai/reference/facade/events)。

迷你图发生变化时会触发 `univerAPI.Event.SheetSparklineChanged`。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetSparklineChanged, (params) => {
  const { workbook, worksheet, sparklines } = params
})

// 移除事件监听器，使用 `disposable.dispose()`
```

## 颜色与显示选项

迷你图的颜色等视觉选项通过 `FSparklineGroup.setConfig()` 设置，没有单独的 `FSparkline.setColor()` 方法，配置作用于整个迷你图组。自定义颜色需要同时设置 `seriesColor` 和 `themeType: SparklineThemeTypeEnum.CUSTOM`。完整选项和示例见[迷你图组配置](/reference/facade/sparkline-group)，涵盖标记点、坐标轴、最大/最小值、空值、隐藏单元格和线宽。
