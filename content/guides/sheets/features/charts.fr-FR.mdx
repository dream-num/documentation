Les graphiques rendent les données de la feuille de travail comme un graphique. Le modèle de graphique et les paquets d'assurance-chômage fournissent la fonctionnalité.

## Mode plugin

```package-install
npm install @univerjs-pro/chart-ui @univerjs-pro/sheets-chart @univerjs-pro/sheets-chart-ui
```

```ts
import ChartUIFrFR from '@univerjs-pro/chart-ui/locale/fr-FR'
import { UniverSheetsChartPlugin } from '@univerjs-pro/sheets-chart'
import { UniverSheetsChartUIPlugin } from '@univerjs-pro/sheets-chart-ui'
import SheetsChartUIFrFR from '@univerjs-pro/sheets-chart-ui/locale/fr-FR'
import SheetsChartFrFR from '@univerjs-pro/sheets-chart/locale/fr-FR'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/chart-ui/facade'
import '@univerjs-pro/sheets-chart/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/sheets-chart-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.FR_FR,
  locales: {
    [LocaleType.FR_FR]: mergeLocales(ChartUIFrFR, SheetsChartFrFR, SheetsChartUIFrFR),
  },
})

univer.registerPlugin(UniverSheetsChartPlugin)
univer.registerPlugin(UniverSheetsChartUIPlugin)
```

Gardez les plugins modèles, styles, locaux et importations Facade, et ne enregistrez pas les deux variantes.

## Mode preset

`@univerjs/preset-sheets-advanced` inclut déjà la fonction graphique, mais elle nécessite le préréglage du dessin à l'exécution.

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

```ts
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'
import UniverPresetSheetsAdvancedFrFR from '@univerjs/preset-sheets-advanced/locales/fr-FR'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreFrFR from '@univerjs/preset-sheets-core/locales/fr-FR'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing'
import UniverPresetSheetsDrawingFrFR from '@univerjs/preset-sheets-drawing/locales/fr-FR'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-advanced/lib/index.css'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.FR_FR,
  locales: {
    [LocaleType.FR_FR]: mergeLocales(
      UniverPresetSheetsCoreFrFR,
      UniverPresetSheetsDrawingFrFR,
      UniverPresetSheetsAdvancedFrFR,
    ),
  },
  presets: [UniverSheetsCorePreset(), UniverSheetsDrawingPreset(), UniverSheetsAdvancedPreset()],
})
```

## Créer et mettre à jour un graphique

`worksheet.newChart(type)` retourne un constructeur détaché. Rien n'est ajouté à la feuille de travail jusqu'à ce que l'information du graphique soit construite et transmise à `worksheet.insertChart(info)`.

```ts
const workbook = univerAPI.getActiveWorkbook()
if (!workbook) throw new Error('No active workbook')

const worksheet = workbook.getActiveSheet()
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D6',
    orientation: univerAPI.Enum.ChartSourceOrientation.Columns,
  })
  .setPosition('F2')
  .setSize(640, 360)
  .setCategoryField(0)
  .setValueFields([1, 2, 3])
  .setTitle('Quarterly revenue')
  .build()

const chart = await worksheet.insertChart(info)
chart.setLegend({ visible: true }).bringToFront()

const updatedInfo = chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setSubtitle('FY 2026').build()
await chart.update(updatedInfo)

const svg = await chart.exportImage({ format: 'svg' })
```

Appeler un setter sur un `chart` inséré le met à jour immédiatement. Utilisez `toBuilder(type)` avec `update(info)` pour obtenir une copie entièrement détachée ou pour changer le type de graphique. `exportImage()` retourne `undefined` quand aucun lecteur d'interface utilisateur ne peut produire une image.

`worksheet.getCharts()` et `worksheet.getChart(id)` retournent des graphiques en direct. Appelez `await chart.remove()` pour supprimer un graphique. Enregistrez des thèmes ECharts partagés avec `univerAPI.registerTheme(name, theme)`.

## Feuilles de graphique [#chart-sheets]

`insertChartSheet()` donne un graphique son propre onglet. Le constructeur de graphique doit référencer une feuille de grille dans le même cahier de travail, et les cellules sources restent sur cette feuille.

```ts
import '@univerjs-pro/sheets-chart/facade'

const workbook = univerAPI.getActiveWorkbook()
const data = workbook?.getSheetByName('Data')
if (!workbook || !data) throw new Error('The Data sheet is required')

const info = data
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({ sheetId: data.getSheetId(), range: 'A1:B4' })
  .build()

const chartSheet = await workbook.insertChartSheet(info, { name: 'Sales' })
const primaryChart = chartSheet.getPrimaryChart()
```

`await chart.moveTo(targetSheet)` déplace un graphique existant. Un graphique déplacé dans une feuille de graphique devient un graphique supplémentaire sur cette feuille. Déplacer le graphique primaire hors d'une feuille de graphique nécessite un onglet qui ne contient rien d'autre, et le déplacement supprime cet onglet. Les mouvements peuvent être annulés et refaits. Le menu contextuel du graphique primaire ouvre le panneau de graphique, copie le graphique et exporte une image, mais il ne comporte pas d'action de suppression.

[`FWorkbook.insertChartSheet()`](/reference/facade/workbook#insertchartsheet) · [`FWorksheet.getPrimaryChart()`](/reference/facade/worksheet#getprimarychart)

## Barres d’erreur [#error-bars]

`setErrorBars()` peut être appelé sur un constructeur ou sur un graphique en direct. La colonne 2D de base, la barre, la ligne, et les diagrammes de dispersion supportent les barres d'erreur. `seriesIndex` est basé sur zéro et compte le champ de catégorie dans les données sources. `y`, utilisation des barres `x`, et les diagrammes de dispersion peuvent utiliser l'un ou l'autre axe numérique.

```ts
chart.setErrorBars([
  { seriesIndex: 1, direction: 'y', type: 'both', valueType: 'percentage', value: 20 },
])
```

[`FChart.setErrorBars()`](/reference/facade/chart#seterrorbars)

## Axes de catégories multiniveaux

Lorsque les colonnes sources adjacentes forment une hiérarchie, passez leurs index zéro à `setCategoryFields()` dans l'ordre racine-feuille, puis activez l'axe multi-niveaux.

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D7',
    orientation: univerAPI.Enum.ChartSourceOrientation.Columns,
  })
  .setCategoryFields([0, 1])
  .setMultiLevelCategoryAxis(true)
  .setValueFields([2, 3])
  .setPosition('F2')
  .build()

const chart = await worksheet.insertChart(info)
chart.setCategoryFields([0, 1]).setMultiLevelCategoryAxis(true)
```

`clearCategoryFields()` supprime la cartographie ordonnée. `setMultiLevelCategoryAxis(false)` conserve les champs sélectionnés et ne désactive que le rendu hiérarchique.

## Graphiques radar [#radar-charts]

Les graphiques radar acceptent `setShape()` avec `univerAPI.Enum.ChartRadarShape.Polygon` (la valeur par défaut) ou `univerAPI.Enum.ChartRadarShape.Circle`, ainsi que `setFill(true)` pour remplir la zone de chaque série. Sans remplissage, seuls les contours sont dessinés. `setRadarAxisLabel({ visible, color, fontSize, bold, italic, family, format })` met en forme les étiquettes numériques de l'échelle, et `resetRadarAxisLabel()` rétablit les valeurs par défaut. Les étiquettes de l'échelle sont visibles par défaut, et l'échelle est divisée en cinq intervalles. Les lignes du radar reprennent la couleur, la largeur et le style de tiret de la bordure de la série, et le remplissage de la zone reprend la couleur et l'opacité de remplissage de la série.

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Radar)
  .setSource('A1:C6')
  .setCategoryField(0)
  .setValueFields([1, 2])
  .setShape(univerAPI.Enum.ChartRadarShape.Circle)
  .setFill(true)
  .setRadarAxisLabel({ visible: true, fontSize: 12, bold: true })
  .build()

await worksheet.insertChart(info)
```

[`FRadarChartBuilder.setRadarAxisLabel()`](/reference/facade/radar-chart-builder#setradaraxislabel)

## Types de graphiques pris en charge

`univerAPI.Enum.ChartTypeString` fournit les types suivants : `Line`, `LineStacked`, `LinePercentStacked`, `Column`, `ColumnStacked`, `ColumnPercentStacked`, `Bar`, `BarStacked`, `BarPercentStacked`, `Pie`, `Donut`, `Area`, `AreaStacked`, `AreaPercentStacked`, `Radar`, `Scatter`, `Combination`, `WordCloud`, `Funnel`, `Bubble`, `Relation`, `Waterfall`, `Pareto`, `Sankey`, `Heatmap`, `Boxplot`, `Candlestick`, `Histogram`, `Treemap`, `Sunburst`, `Gauge` et `Chord`.

Le [Référence de la figure](/reference/facade/chart) documente l'API de configuration du constructeur partagé.

`LineStacked` et `LinePercentStacked` sont des types de graphiques 2D autonomes. Avant de les utiliser dans un serveur de rendu ou dans la conversion de fichiers Office, vérifiez que la cible les supporte.

## Données masquées et catégories indépendantes [#source-mapping]

`setPlotVisibleOnly(false)` comprend les valeurs des lignes et colonnes cachées, et `getPlotVisibleOnly()` lit le paramètre actuel. Pour les sources avec des colonnes de catégorie distinctes, `setSeriesToCategory()` Les index se réfèrent aux vecteurs de sources physiques, et non à la série qui reste après le filtrage. Les entrées qui sont laissées en héritage héritent des catégories partagées, et `{}` Ça efface les bornes.

Avec les colonnes A:D, par exemple, les séries de valeurs en D peuvent utiliser C comme catégorie, tandis que B garde la catégorie partagée en A.

```ts
const chart = worksheet.getCharts()[0]
if (!chart) throw new Error('No chart')
chart.setPlotVisibleOnly(false)
chart.setSeriesToCategory({ 3: [2] })
```

Pour les rapports agrégés, voir les [graphiques croisés dynamiques](/guides/sheets/features/pivot-chart).

## Graphiques 3D [#three-dimensional-charts]

Les graphiques 3D utilisent le même enregistrement de plugin. Sélectionnez un type de graphique 3D, puis configurez la vue sur son constructeur détaché.

Les types supportés sont `Line3D`, `Column3D`, `ColumnStacked3D`, `ColumnPercentStacked3D`, `Bar3D`, `BarStacked3D`, `BarPercentStacked3D`, `Pie3D`, `Area3D`, `AreaStacked3D` et `AreaPercentStacked3D`.

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column3D)
  .setSource('A1:C5')
  .setCategoryField(0)
  .setValueFields([1, 2])
  .setPosition('F18')
  .setSize(640, 360)
  .setThreeD({
    view: { rotX: 20, rotY: 30, rightAngleAxes: false, perspective: 30 },
    gapDepth: 120,
  })
  .build()

await worksheet.insertChart(info)
```

`perspective` s'applique aux cartes à axe seulement lorsque `rightAngleAxes` est `false`. `clearThreeD()` efface les paramètres de vue configurés mais maintient le type de carte 3D et l'axe de profondeur; utilisez `clearDepthAxis()` pour effacer l'axe des profondeurs. Les cartes à axe 3D n'exposent aucun axe ou tendance secondaire, et `Pie3D` dessine une tarte solide.

## Axes de valeurs logarithmiques [#logarithmic-axes]

Les cartes 2D, les colonnes, les barres et les cartes combinées acceptent `scaleType: 'log'` sur l'axe numérique. Utilisez `setYAxis()` pour les axes de valeurs verticales et `setXAxis()` dans l'axe horizontal numérique d'un graphique à barres. `setRightYAxis()` configure un axe secondaire numérique existant.

La base par défaut est `10`. Une `logBase` personnalisée doit être finie et entre `2` et `1000`; des valeurs fractionnelles telles que `2.5` sont autorisées. Les limites numériques doivent être positives. Zéro et les points de données négatifs sont omis du tracé logarithmique, mais les données sources sont inchangées. Les graphiques 3D et en pourcentage ne prennent pas en charge les axes logarythmiques.

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Line)
  .setSource('A1:B5')
  .setYAxis({ scaleType: 'log', logBase: 10 })
  .setPosition('F36')
  .setSize(640, 360)
  .build()

const chart = await worksheet.insertChart(info)

await chart.update(
  chart.toBuilder(univerAPI.Enum.ChartTypeString.Line)
    .setYAxis({ scaleType: 'linear' })
    .build(),
)
```

Pour insérer un nouveau graphique, créez-le puis insérez-le; pour appliquer une mise à jour détachée, utilisez `await chart.update(builder.build())`. La configuration `scaleType: 'linear'` supprime la base logarithmique et les patchs d'axe qui ne touchent pas l'échelle le préservent.
