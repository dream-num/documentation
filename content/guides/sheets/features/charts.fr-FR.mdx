Les graphiques sont un outil essentiel de visualisation des données : ils facilitent leur compréhension et leur analyse. Dans Univer Sheets, cette fonctionnalité propose différents types de graphiques, notamment des histogrammes, des graphiques en courbes et des graphiques en secteurs. Les utilisateurs peuvent choisir le type le mieux adapté aux données qu’ils souhaitent présenter.

## Mode preset

La fonctionnalité de graphiques est incluse dans le preset `@univerjs/preset-sheets-advanced`.

### Installation

<Callout>
  Le preset `UniverSheetsAdvancedPreset` du package `@univerjs/preset-sheets-advanced` dépend du preset `UniverSheetsDrawingPreset` lors de l’exécution. Installez d’abord `@univerjs/preset-sheets-drawing`.

### Insérer un graphique

La méthode `FWorksheet.newChart()` permet de créer un générateur de graphique qui renvoie une instance de `FChartBuilderBase`. Vous pouvez chaîner les appels de méthode afin de définir les différentes propriétés du graphique.

Appelez ensuite `build()` pour générer un objet `IChartBuilderInfo`, puis utilisez la méthode `FWorksheet.insertChart(chartBuildInfo: IChartBuilderInfo)` afin d’insérer le graphique dans la feuille de calcul.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a column chart with data source A1:D6.
// The starting position is upper-left corner of cell B2.
// The width of the chart is 600 and the height is 400.
const chartInfo = fWorksheet.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
  .setWidth(600)
  .setHeight(400)
  .build()
await fWorksheet.insertChart(chartInfo)
```

Voici quelques méthodes membres de `FChartBuilderBase` :

| Méthode | Description |
| ------ | ----------- |
| addRange | Indique la plage de données source du graphique |
| setPosition | Définit la position du graphique à l’aide d’ancrages de ligne et de colonne |
| setAbsolutePosition | Définit la position du graphique en pixels |
| setChartType | Définit le type de graphique |
| setWidth | Définit la largeur du graphique |
| setHeight | Définit la hauteur du graphique |
| setOptions | Définit les options du graphique |
| setTransposeRowsAndColumns | Intervertit les lignes et les colonnes |
| setTheme | Définit le thème |
| setXAxisTitle | Définit le titre de l’axe X |
| setYAxisTitle | Définit le titre de l’axe Y |
| setRightYAxisTitle | Définit le titre de l’axe Y droit |
| setXAxisTextStyle | Définit le style du titre de l’axe X |
| setYAxisTextStyle | Définit le style du titre de l’axe Y |
| setRightYAxisTextStyle | Définit le style du titre de l’axe Y droit |
| setInvalidValueStrategy | Définit le mode d’affichage des cellules vides |
| setAxisPointerStyle | Définit le style du pointeur d’axe |
| setAllSeriesStyle | Définit les styles de toutes les séries |
| setSeriesStyle | Définit le style d’une série selon son indice |
| build | Génère les informations nécessaires à l’insertion ou à la mise à jour du graphique |

Les options de configuration se définissent avec la méthode setOptions, selon les deux formes suivantes :
  - `setOptions(optionPath, optionVal)`: `setOptions('legend.color', '#ff0000')`
  - `setOptions('', IChartBuildOptions)`: `setOptions('', { legend: { color: '#ff0000', bold: true } })`

  ```typescript
  const fWorkbook = univerAPI.getActiveWorkbook()
  const fWorksheet = fWorkbook.getActiveSheet()

  // Create a line chart
  const chartInfo = fWorksheet.newChart()
    // As a line chart
    .asLineChart()
    // Set the data source A1:D6
    .addRange('A1:D6')
    // Set the starting position to the upper-left corner of cell B2
    .setPosition(1, 1, 0, 0)
    // Set the indicator line style
    .setAxisPointerStyle({
      indicatorLabelColor: '#ff0000',
      indicatorLineType: univerAPI.Enum.ChartBorderDashType.Solid,
      indicatorLineColor: '#00ff00',
      indicatorLabelTextColor: '#0000ff',
    })
    // Set the data point size to 10
    .setDataPointSize(10)
    // Set the data point shape to circular
    .setDataPointShape(univerAPI.Enum.LinePointShape.Circle)
    // Generate builder info
    .build()
  const fChart = await fWorksheet.insertChart(chartInfo)

  // Update the chart after 3 seconds
  setTimeout(() => {
    if (fChart) {
      // Get the first series data
      const first = fChart.getSeriesData()[0]
      // Set the color of the first series to red
      const newChartInfo = fWorksheet.newChart(fChart)
        .setSeriesStyle(first.index, {
          color: '#ff0000',
        })
        .build()
      // Update the chart
      fWorksheet.updateChart(newChartInfo)
    }
  }, 3000)
  ```

Univer fournit les générateurs suivants pour créer des types de graphiques précis, à l’aide de `fWorkSheet.newChart().asLineChart()` et des méthodes analogues. Ils héritent de `FChartBuilderBase` et disposent de configurations spécifiques :

```typescript
const lineChartBuilder = fWorkSheet.newChart().asLineChart()
const pieChartBuilder = fWorkSheet.newChart().asPieChart()
const radarChartBuilder = fWorkSheet.newChart().asRadarChart()

// Or you can use the following method to create a chart builder
const chartBuilder = fWorkSheet.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
```

- `LineChartBuilder`

| Méthode | Description |
| ------ | ----------- |
| setLineStyle | Définit le style de ligne : 'line' pour une ligne droite, 'smooth' pour une ligne lissée et 'step' pour une ligne en escalier |
| setDataPointShape | Définit la forme des points de données ; consultez LinePointShape pour connaître les formes prises en charge |
| setDataPointColor | Définit la couleur des points de données |
| setDataPointSize | Définit la taille des points de données |
| build | Génère les informations nécessaires à l’insertion ou à la mise à jour du graphique |

- `PieChartBuilder`

| Méthode | Description |
| ------ | ----------- |
| setDoughnutHole | Définit la taille du trou de l’anneau, comprise entre 0 et 1 |
| setBorderColor | Définit la couleur de la bordure du graphique en secteurs |
| setHasPaddingAngle | Indique si les secteurs du graphique sont séparés par un espacement angulaire |
| setIsHalfPie | Indique s’il s’agit d’un demi-graphique en secteurs |
| setRosePie | Indique s’il s’agit d’un diagramme en rose |
| setShowLabelLine | Affiche les lignes de repère des étiquettes |
| build | Génère les informations nécessaires à l’insertion ou à la mise à jour du graphique |

- `RadarChartBuilder`

| Méthode | Description |
| ------ | ----------- |
| setShape | Définit la forme par défaut du graphique en radar ; les valeurs actuellement prises en charge sont 'polygon' pour un polygone et 'circle' pour un cercle |
| setFill | Indique si le graphique en radar doit être rempli |
| build | Génère les informations nécessaires à l’insertion ou à la mise à jour du graphique |

### Obtenir les graphiques

La méthode `FWorksheet.getCharts()` permet d’obtenir tous les graphiques de la feuille de calcul actuelle sous la forme d’un tableau d’objets `FChart`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all charts on the active sheet.
const charts = fWorksheet.getCharts()
```

### Mettre à jour un graphique

La méthode `FWorksheet.updateChart(chartBuildInfo: IChartBuilderInfo)` permet de mettre à jour un graphique en lui transmettant un objet `IChartBuilderInfo` contenant sa nouvelle configuration.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a column chart with data source A1:D6.
// The starting position is upper-left corner of cell B2.
const chartInfo = fWorksheet.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
  .build()
await fWorksheet.insertChart(chartInfo)

// Get all charts on the active sheet.
const charts = fWorksheet.getCharts()

// Update the first chart after 3 seconds.
setTimeout(() => {
  const newChartInfo = fWorksheet.newChart(charts[0])
    .asLineChart()
    .setOptions('legend.position', univerAPI.Enum.LegendPositionEnum.Right)
    .build()
  fWorksheet.updateChart(newChartInfo)
}, 3000)
```

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a column chart with data source A1:D6.

```

### Thème de graphique

La méthode `FWorksheet.registerChartTheme(themeName: string, theme: IEchartTheme)` permet d’enregistrer un thème de graphique personnalisé en lui transmettant un nom et un objet de thème.

Les graphiques Univer reposent sur la bibliothèque echarts. Vous pouvez donc utiliser son [outil de création de thèmes personnalisés](https://echarts.apache.org/en/theme-builder.html).
Vous pouvez créer votre propre thème sur ce site et le télécharger sous forme de fichier de configuration. Utilisez ensuite l’API suivante pour l’appliquer :

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// register your theme
const theme = { // your theme object
  version: 1,
  themeName: 'myTheme',
  theme: {
    // ... Some code is omitted for brevity
    color: [
      '#893448',
      '#d95850',
      '#eb8146',
      '#ffb248',
      '#f2d643',
      '#ebdba4',
    ],
    // ... Some code is omitted for brevity
    visualMapColor: [
      '#893448',
      '#d95850',
      '#eb8146',
      '#ffb248',
      '#f2d643',
      'rgb(247,238,173)',
    ],
    // ... Some code is omitted for brevity
    axes: [],
    // ... Some code is omitted for brevity
  },
}
fWorksheet.registerChartTheme('myTheme', theme)

// use your theme for chart
const chartInfo = fWorksheet.newChart()
  .asLineChart()
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
  .setTheme('myTheme')
  .build()
await fWorksheet.insertChart(chartInfo)
```
