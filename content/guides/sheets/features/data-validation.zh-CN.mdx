数据验证为单元格设置规则，用来检查输入内容是否符合要求。它能及早发现输入错误，使表格数据保持准确和一致。

目前支持以下验证类型：
- 数字
- 整数
- 文本长度
- 日期
- 复选框
- 下拉列表（单选/多选）
- 自定义公式

## 插件模式

### 安装

```package-install
npm install @univerjs/data-validation @univerjs/sheets-data-validation @univerjs/sheets-data-validation-ui
```

### 使用

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDataValidationPlugin } from '@univerjs/data-validation' // [!code ++]
```

## 值匹配 [#value-matching]

列表验证不区分大小写：输入 `green` 可以通过选项 `Green` 的校验，由区域引用得到的列表也遵循同样的规则。数字和整数规则只接受数字文本，布尔值和空白文本都不满足条件。

### 添加一个数据验证规则

[`univerAPI.newDataValidation()`](https://docs.univer.ai/reference/facade/univer#newdatavalidation) 创建一个构建器，返回 `FDataValidationBuilder` 实例。通过链式调用其方法可构造规则。

[`FDataValidationBuilder`](/reference/facade/data-validation-builder) 的主要方法如下：

| 方法 | 描述 |
| ---- | ---- |
| build | 构建规则 |
| requireCheckbox | 要求输入布尔值，在单元格中显示为复选框 |
| requireDateAfter | 把类型设为 DATE，要求日期在指定日期之后 |
| requireDateBefore | 把类型设为 DATE，要求日期在指定日期之前 |
| requireDateBetween | 把类型设为 DATE，要求日期在指定日期范围内 |
| requireDateEqualTo | 把类型设为 DATE，要求日期等于指定日期 |
| requireDateNotBetween | 把类型设为 DATE，要求日期不在指定日期范围内 |
| requireDateOnOrAfter | 把类型设为 DATE，要求日期在指定日期当天或之后 |
| requireDateOnOrBefore | 把类型设为 DATE，要求日期在指定日期当天或之前 |
| requireFormulaSatisfied | 要求给定公式的计算结果为 `true` |
| requireNumberBetween | 要求数字在给定的两个数之间（含两端） |
| requireNumberEqualTo | 要求数字等于给定值 |
| requireNumberGreaterThan | 要求数字大于给定值 |
| requireNumberGreaterThanOrEqualTo | 要求数字大于或等于给定值 |
| requireNumberLessThan | 要求数字小于给定值 |
| requireNumberLessThanOrEqualTo | 要求数字小于或等于给定值 |
| requireNumberNotBetween | 要求数字不在给定的两个数之间，也不等于其中任何一个 |
| requireNumberNotEqualTo | 要求数字不等于给定值 |
| requireValueInList | 要求用户从指定的值列表中选择，支持单选/多选，可显示或隐藏下拉框 |
| requireValueInRange | 要求用户输入指定范围内的值，支持单选/多选，可显示或隐藏下拉框 |
| setOptions | 设置规则选项 |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 创建一个新的数据验证规则，要求 A1:B10 范围内的数字在 1 到 10 之间
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: 'Please enter a number between 1 and 10',
  })
  .build()
fRange.setDataValidation(rule)
```

### 获取 Range/Worksheet 的数据验证规则

返回的规则对象是 `FDataValidation` 实例，可用于读取规则的条件、选项和其他设置。

[`FDataValidation`](https://docs.univer.ai/reference/facade/data-validation) 的主要方法如下：

| 方法 | 描述 |
| ---- | ---- |
| copy | 用当前规则对象创建一个新的 FDataValidationBuilder 实例 |
| getCriteriaType | 获取规则的验证类型 |
| getCriteriaValues | 获取参与条件判断的值 |
| getHelpText | 获取帮助文本，用来给用户提示 |
| getRanges | 获取规则应用的范围 |
| setCriteria | 设置规则的条件 |
| setOptions | 设置规则的选项 |
| setRanges | 设置规则应用的范围 |
| delete | 从工作表中删除规则 |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 获取当前工作表的所有数据验证规则
const rulesOfSheet = fWorksheet.getDataValidations()

// 通过规则 ID 获取数据验证规则
const ruleById = fWorksheet.getDataValidation(rulesOfSheet[0]?.rule?.uid)

const fRange = fWorksheet.getRange('A1:B10')

// 获取当前范围的第一个数据验证规则
const ruleOfRange = fRange.getDataValidation()
ruleOfRange?.getCriteriaValues()

// 获取当前范围的所有数据验证规则
const rulesOfRange = fRange.getDataValidations()
```

### 更新/删除数据验证

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 创建一个新的数据验证规则，要求 A1:B10 范围内的数字等于 20
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberEqualTo(20)
  .build()
fRange.setDataValidation(rule)

const newRuleRange = fWorksheet.getRange('C1:D10')

// 3 秒后更新规则
setTimeout(() => {
  fRange.getDataValidation()
    // 更改新的范围 C1:D10
    .setRanges([newRuleRange])
    // 更改新的条件，要求数字在 1 到 10 之间
    .setCriteria(
      univerAPI.Enum.DataValidationType.DECIMAL,
      [univerAPI.Enum.DataValidationOperator.BETWEEN, '1', '10'],
    )
    // 更改验证选项，当输入不符合条件时停止输入并显示错误消息
    .setOptions({
      allowBlank: true,
      showErrorMessage: true,
      error: 'Please enter a valid value',
      errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
    })
}, 3000)

// 6 秒后删除该规则
setTimeout(() => {
  newRuleRange.getDataValidation().delete()
}, 6000)
```

### 获取验证错误

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 获取当前工作簿的所有数据验证错误
const workbookErrors = await fWorkbook.getAllDataValidationErrorAsync()
console.log('workbookErrors:', workbookErrors)

// 获取当前工作表的所有数据验证错误
const worksheetErrors = await fWorksheet.getAllDataValidationErrorAsync()
console.log('worksheetErrors:', worksheetErrors)

// 获取当前范围的数据验证错误
const fRange = fWorksheet.getRange('A1:B10')
const rangeErrors = await fRange.getDataValidationErrorAsync()
console.log('rangeErrors:', rangeErrors)
```

每个错误对象包含以下字段：
- `sheetName`：发生错误的工作表名称
- `row`：触发错误的单元格行索引
- `column`：触发错误的单元格列索引
- `ruleId`：触发错误的规则 ID
- `inputValue`：触发错误的输入值
- `rule`：规则内容快照

### 查询校验状态

校验状态为 `DataValidationStatus` 枚举的取值：
- `valid`：单元格值通过验证
- `invalid`：单元格值未通过验证
- `validating`：单元格正在校验

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 获取当前工作簿的数据验证校验状态
fWorkbook.getValidatorStatus().then((status) => {
})

// 获取当前工作表的数据验证校验状态
fWorksheet.getValidatorStatusAsync().then((status) => {
})

// 获取当前范围的数据验证校验状态
const fRange = fWorksheet.getRange('A1:B10')
fRange.getValidatorStatus().then((status) => {
})
```

### 事件监听

事件类型的完整定义见 [Events](https://docs.univer.ai/reference/facade/events)。

规则被添加、更新或删除，以及校验状态发生变化时，数据验证模块都会发出事件。这些事件均可通过 `univerAPI.addEvent()` 监听。

#### 验证规则变更事件

`univerAPI.Event.SheetDataValidationChanged` 在规则变更后触发。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidationChanged, (params) => {
  const { origin, worksheet, workbook, changeType, oldRule, rule } = params
})

// 移除事件监听器，使用 `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationAdd` 在添加规则前触发。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationAdd, (params) => {
  const { worksheet, workbook, rule } = params

  // 取消添加验证规则操作
  params.cancel = true
})

// 移除事件监听器，使用 `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationDelete` 在删除规则前触发。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDelete, (params) => {
  const { worksheet, workbook, ruleId, rule } = params

  // 取消删除验证规则操作
  params.cancel = true
})

// 移除事件监听器，使用 `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationDeleteAll` 在删除所有规则前触发。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDeleteAll, (params) => {
  const { worksheet, workbook, rules } = params

  // 取消删除所有验证规则操作
  params.cancel = true
})

// 移除事件监听器，使用 `disposable.dispose()`
```

#### 验证规则更新事件

`univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate` 在更新规则条件前触发。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate, (params) => {
```

#### 验证状态事件

`univerAPI.Event.SheetDataValidatorStatusChanged` 在单元格校验状态变化时触发。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidatorStatusChanged, (params) => {
  const { worksheet, workbook, row, column, status, rule } = params
})

// 移除事件监听器，使用 `disposable.dispose()`
```

每个事件都包含以下通用参数：
- `workbook`：当前工作簿实例
- `worksheet`：当前工作表实例

部分事件还包含以下参数：
- `rule`：相关的验证规则对象
- `ruleId`：规则的唯一标识
- `status`：校验状态（仅在 `SheetDataValidatorStatusChanged` 事件中）
- `newCriteria`：新的验证条件（仅在 `BeforeSheetDataValidationCriteriaUpdate` 事件中）
- `newRanges`：新的验证范围（仅在 `BeforeSheetDataValidationRangeUpdate` 事件中）
- `newOptions`：新的验证选项（仅在 `BeforeSheetDataValidationOptionsUpdate` 事件中）

对于名称以 `Before` 开头的事件，在回调中设置 `params.cancel = true` 即可阻止对应操作。

### 错误样式

`errorStyle` 控制输入无效数据时的处理方式，可设为 `DataValidationErrorStyle` 枚举值：
- `STOP`：拒绝该输入
- `WARNING`：允许输入，但显示警告
- `INFO`：允许输入，但显示提示信息

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B10')

const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: '请输入 1 到 10 之间的数字',
    errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
  })
  .build()
fRange.setDataValidation(rule)
```
