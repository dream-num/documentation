資料透視表將大量資料彙總成一張緊湊的報表。它支援彙總、分析和視覺化資料，並提供多種資料操作和格式設定，使結果更容易理解。

## 簡介

資料透視表通常用於以下四種場景：

- 彙總大量資料，以呈現整體情況。
- 分析資料，識別其中的模式和關係。
- 探索資料，發現其中的規律和趨勢。
- 視覺化資料，使結果更容易理解。

資料透視表通常由三部分組成：

- 行標籤：按行對資料分組。
- 列標籤：按列對資料分組。
- 值：彙總每個交叉位置上的數字。

行標籤、列標籤和值均可隨時調整，以適應分析需求的變化。

### 資料來源

在 Univer Sheets 中，資料來源可以是一整張工作表（Worksheet），也可以是一個資料區域。

資料來源的第一行會成為列標籤，其餘行是資料。空行和空列會干擾這一版面配置，因此資料來源應當保持規整。

每一列的資料型別都會被自動識別，透視表據此決定該欄位可以執行哪些操作。如果一列中的資料型別不一致，整列都按字串處理。

透視表會跟蹤資料來源的變化：當資料來源中的值發生變化時，透視表會自動更新。

### 篩選

行標籤和列標籤都可以篩選。另有一個篩選欄位，它不參與報表的行列布局，但其中選中的值同樣會限定資料範圍。

篩選有兩種方式：

- 標籤篩選：作用於當前標籤維度的項（item）。例如在省份維度下，可以篩選掉部分省份。
- 值篩選：需要先指定一個值維度，再按彙總結果篩選。例如篩選掉銷售額低於 1000 的資料。

### 排序

排序僅對行欄位和列欄位生效，支援升序和降序，比較使用 localCompare 方法。後續將支援更多比較方式，例如拼音排序。

排序有兩種方式：

- 標籤排序：作用於當前標籤維度的項（item）。例如在省份維度下，可以按省份名稱排序。
- 值排序：需要先指定一個值維度，再按彙總結果排序。例如按銷售額排序。

### 彙總

資料透視表支援 Excel 提供的 11 種彙總方式：求和、計數、資料計數、平均值、最大值、最小值、階乘、標準差、方差、總體標準差、總體方差。

可以新增多個值維度，並可設定值維度所在的區域（value position）及其在該區域中的順序（value index）。

這一版面配置邏輯較為複雜，因此目前僅支援表格檢視，後續將根據需求支援更多檢視。

### 下鑽

下鑽是指在值區域中雙擊某個單元格，檢視該單元格背後的明細資料。明細資料會列出產生該數值的各行，因此可以將彙總值追溯到源資料。

### 分組

Univer Sheets 支援日期分組、數字分組和手動分組。

- 日期分組：對派生日期欄位使用 [`setDateGroupType`](/reference/facade/pivot-table#setdategrouptype) 設定。若要按日曆單位對原始日期標籤欄位分組，先將 [`setDateGroupingMode`](/reference/facade/pivot-table#setdategroupingmode) 設為 `univerAPI.Enum.PivotDateGroupingMode.ExcelLike`，再呼叫 [`setExcelDateGroup`](/reference/facade/pivot-table#setexceldategroup)。
- 數字分組：向 [`setNumberGroup`](/reference/facade/pivot-table#setnumbergroup) 傳入標籤欄位 ID 和區間設定。
- 手動分組：向 [`setManualGroups`](/reference/facade/pivot-table#setmanualgroups) 傳入原始源欄位 ID 以及按型別分組的成員。每組至少包含兩個成員；傳入空陣列會移除該欄位的全部手動分組。

[切片器和時間線](/guides/sheets/features/slicer)可以互動式篩選表格和透視報表。

### 外掛註冊

透視表外掛有兩種註冊方式，區別在於將多少計算保留在主程序上。

**只註冊在主程序**

該模式適用於輕量級任務和簡單操作：外掛 config 可以保持為空，只需引入 `UniverSheetsPivotTablePlugin` 即可。

```typescript
univer.registerPlugin(UniverSheetsPivotTablePlugin)
univer.registerPlugin(UniverSheetsPivotTableUIPlugin)
```

**主程序和 worker 程序同時註冊**

當透視表計算量較大時，可以將外掛同時註冊到主程序和 worker 程序。外掛隨後可以使用多執行緒架構完成資料分發和計算，將大部分計算從主程序移出，從而提升整體效能。

在該模式下，主程序負責資料分發、同步和渲染，worker 程序負責複雜計算。該模式在註冊時透過 config 選擇。

```typescript
// 瀏覽器主程序外掛註冊檔案
// notExecuteFormula 為 true 表示主程序不執行計算，只負責資料的分發、同步和渲染
univer.registerPlugin(UniverSheetsPivotTablePlugin, { notExecuteFormula: true })
univer.registerPlugin(UniverSheetsPivotTableUIPlugin)

// web worker 程序外掛註冊檔案
// notExecuteFormula 為 false 表示 worker 程序執行計算
univer.registerPlugin(UniverSheetsPivotTablePlugin, { notExecuteFormula: false })
```

如果你擁有 Univer 的商業許可證，客戶端側的配置方式見[在客戶端使用許可證](/server/license#in-plugin-mode)。

### 新增透視表

[`FWorkbook.addPivotTable`](https://docs.univer.ai/reference/facade/workbook#addpivottable) 用於新增透視表，成功時返回 `FPivotTable` 例項。

```typescript
// 需要確保工作表範圍 A1:G9 是非空的
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook.getId()
const fSheet = fWorkbook.getActiveSheet()
const subUnitId = fSheet.getSheetId()
const sheetName = fSheet.getSheetName()
const sourceInfo = {
  unitId,
  subUnitId,
  sheetName,
  range: {
    startRow: 0,
    startColumn: 0,
    endRow: 8,
    endColumn: 6,
  },
}
const anchorCellInfo = {
  unitId,
  subUnitId,
  row: 20,
  col: 8,
}
const fPivotTable = await fWorkbook.addPivotTable(sourceInfo, univerAPI.Enum.PositionTypeEnum.Existing, anchorCellInfo)
const pivotTableId = fPivotTable.getPivotTableId()
// 設定狀態，避免重複新增維度
let hasAdded = false
// 透視表的建立是非同步的，因此需要等待透視表渲染完成後再新增維度
univerAPI.addEvent(univerAPI.Event.PivotTableRendered, async (params) => {
  if (!hasAdded && params.pivotTableId === pivotTableId) {
    hasAdded = true
    await fPivotTable.addField(1, univerAPI.Enum.PivotTableFiledAreaEnum.Row, 0)
    await fPivotTable.addField(1, univerAPI.Enum.PivotTableFiledAreaEnum.Value, 0)
  }
})
```

### 事件監聽

完整的事件型別定義見 [Events](https://docs.univer.ai/reference/facade/events)。

`univerAPI.Event.BeforePivotTableAdd` 在新增透視表前觸發。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforePivotTableAdd, (params) => {
  const { positionType, targetCellInfo } = params
  if (positionType === univerAPI.Enum.PositionTypeEnum.Existing && targetCellInfo.sheetName === 'Sheet 1') {
    // 取消新增透視表操作
    params.cancel = true
    console.log(`無法將透視表新增到 ${targetCellInfo.sheetName} 工作表`)
  }
})

// 移除事件監聽器，使用 `disposable.dispose()`
```

`univerAPI.Event.PivotTableAdded` 在新增透視表後觸發。


報表需要預留擴充套件空間。已有的單元格內容、合併單元格或其他透視表都可能遮擋輸出區域。請清除障礙，或將報表移動到空白區域。

## 值顯示方式 [#show-values-as]

對值欄位呼叫 `setShowDataAs()` 可以改變該欄位顯示的值，例如它佔某一行、某一列或總計的百分比，或相對於基準項的差異。改變的只是顯示的計算方式，源資料不會被修改。`getShowDataAs()` 讀取當前設定，`resetShowDataAs()` 恢復常規計算。

```ts
const valueId = fPivotTable.getFieldIdsByArea(
  univerAPI.Enum.PivotTableFiledAreaEnum.Value,
)[0]
if (valueId) {
  await fPivotTable.setShowDataAs(valueId, {
    type: univerAPI.Enum.PivotShowAsTypeEnum.percentOfGrandTotal,
  })
  console.log(fPivotTable.getShowDataAs(valueId))
}
```

範例假設已有一個 `fPivotTable`。此處傳入的是值欄位 ID，而不是源列或行欄位 ID。差異和累計等模式還需要對應的基準欄位與基準項設定。

## 隨工作表複製樞紐分析表 [#copy-with-worksheet]

註冊透視表外掛後，複製工作表會一併複製該工作表上的透視表，並保留其欄位配置。每個副本都會獲得新的透視表 ID。位於被複制工作表上的資料來源範圍會改為指向新工作表；位於其他工作表或工作簿上的資料來源則保留原引用。複製出的透視表會參與工作表複製操作的撤銷和重做。

```ts
const workbook = univerAPI.getActiveWorkbook()
if (!workbook) throw new Error('No active workbook')

const copiedSheet = workbook.duplicateActiveSheet()
console.log(copiedSheet.getSheetName())
```

## 多重篩選與日期條件 [#multiple-filters]

`setOptions({ allowMultipleFilters: true })` 允許同一欄位上的成員選擇、標籤或日期條件以及值篩選共存。如果省略該選項或傳入 `false`，新篩選會替換原有篩選，而不是疊加；如果關閉該選項時存在類別衝突，則會清除報表篩選。一個欄位仍然最多只能有一個值篩選。

`setDateFilter()` 接受固定日期運算子，包括 `dateEqual`、`dateOlderThan` 和 `dateBetween`。`expected` 儲存的是工作簿日期系統中的 Excel 序列值，區間條件需要兩個這樣的值。`useWholeDay: true` 忽略一天中的具體時間，按整天比較；如果省略該選項或傳入 `false`，則按精確序列值比較。此處傳入報表欄位 ID，而不是源列索引。以下範例沿用前文的 `fPivotTable`，並要求資料來源中有一列名為 `Date`。

`getDateFilter()` 返回條件的獨立副本，`clearDateFilter()` 只清除日期條件。這兩個命令都支援撤銷和協同。請檢查它們返回的布林值：已生效的切片器可能會阻止不相容的篩選被應用。

```ts
if (!fPivotTable) throw new Error('PivotTable not found')
await fPivotTable.setOptions({ allowMultipleFilters: true })

const dateField = Object.values(fPivotTable.getConfig()?.fieldsConfig.dimension ?? {})
  .find((field) => field.sourceName === 'Date')
if (!dateField) throw new Error('Add the Date field to the report first')

await fPivotTable.setDateFilter(dateField.id, {
  operator: univerAPI.Enum.ST_PivotFilterOperatorEnum.dateEqual,
  expected: 45293,
  useWholeDay: true,
})
console.log(fPivotTable.getDateFilter(dateField.id))
await fPivotTable.clearDateFilter(dateField.id)
```

## GETPIVOTDATA [#getpivotdata]

`=GETPIVOTDATA("Sales",$I$1,"Region","East")` 從一張左上角單元格為 I1 的可見透視表中讀取聚合值。值欄位可以用顯示名稱或源欄位名指定。錨點必須是單個單元格引用，且欄位/專案對必須完整成對提供。

當前實現只讀取可見報表，從錨點向下最多掃描 200 行、向右最多掃描 50 列，不查詢隱藏的源記錄。欄位/專案對不匹配，或結果不可用時，返回 `#REF!`；參數數量不正確，或錨點不是單個單元格時，返回 `#VALUE!`。
