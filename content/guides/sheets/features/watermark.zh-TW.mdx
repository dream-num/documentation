水印功能只在為電子表格提供水印功能。它允許開發者在電子表格中新增文字或圖片水印，並提供多種配置選項來客製化水印的外觀和行為。

<Callout type="info">
  使用[浮水印設定產生器](/tools/watermark-generator)調整浮水印樣式、即時預覽效果，並下載可用於外掛的 JSON 設定。
</Callout>

## 外掛模式

### 安裝

```package-install
npm install @univerjs/watermark
```

### 使用

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

## 預設模式

水印並未提供預設模式，但支援與其外掛混用。

### 安裝

```package-install
npm install @univerjs/watermark
```

### 使用

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## Facade API

### 引入

<Callout type="info" title="外掛模式提示">
  僅外掛模式需要手動引入 Facade 套件。預設模式已內建對應的 Facade 套件，無需額外引入。
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### 設定水印

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### 移除水印

```typescript
univerAPI.deleteWatermark()
```
