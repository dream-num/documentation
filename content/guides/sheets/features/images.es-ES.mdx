Las imágenes transmiten información que es más fácil de ilustrar que describir. Univer soporta dos tipos de imagen: imágenes flotantes, que se colocan por encima de la red, e imágenes de células, que están vinculadas a una sola célula.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs/docs-drawing @univerjs/drawing @univerjs/drawing-ui @univerjs/sheets-drawing @univerjs/sheets-drawing-ui
```

### Uso

```typescript
import { IImageIoService, LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsDrawingPlugin } from '@univerjs/docs-drawing' // [!code ++]
import { UniverDrawingPlugin } from '@univerjs/drawing' // [!code ++]
import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui' // [!code ++]
import DrawingUIEnUS from '@univerjs/drawing-ui/locale/en-US' // [!code ++]
import { UniverSheetsDrawingPlugin } from '@univerjs/sheets-drawing' // [!code ++]
import { UniverSheetsDrawingUIPlugin } from '@univerjs/sheets-drawing-ui' // [!code ++]
import SheetsDrawingUIEnUS from '@univerjs/sheets-drawing-ui/locale/en-US' // [!code ++]
import '@univerjs/drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing/facade' // [!code ++]
import '@univerjs/sheets-drawing-ui/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DrawingUIEnUS, // [!code ++]
      SheetsDrawingUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverDrawingUIPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingUIPlugin) // [!code ++]
```

Si utiliza [Colaboración](/guides/docs/features/collaboration), agregue la configuración `override`:

```typescript
univer.registerPlugin(UniverDrawingPlugin, {
  override: [[IImageIoService, null]], // [!code ++]
  // allowImageSize: 20 * 1024 * 1024, // set the maximum allowed size of uploaded images to 20MB, optional
})
```

import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]

const { univerAPI } = createUniver({

    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,

### Agregar DOM flotante

`FWorksheet.addFloatDomToPosition(layer)` añade un elemento DOM flotante en la posición especificada.

```tsx
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()

// You should register components at an appropriate time (e.g., when Univer is loaded)
// This is a React component. For Vue3 components, the third parameter should be `{ framework: 'vue3' }`
univerAPI.registerComponent(
  'myFloatDom',
  ({ data }) => (
    <div style={{ width: '100%', height: '100%', background: '#fff', border: '1px solid #ccc', boxSizing: 'border-box' }}>
      popup content:
      {' '}
      {data?.label}
    </div>
  ),
)

// Add a floating DOM
// If disposable is null, floating DOM addition failed
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'myFloatDom',
  initPosition: {
    startX: 100,
    endX: 300,
    startY: 100,
    endY: 200,
  },

  // Component data
  data: {
    label: 'hahah',
  },
})

// 2 秒后移除浮动 DOM
setTimeout(() => {
  disposable?.dispose()
}, 2000)
```

`FWorksheet.addFloatDomToRange(range, layer, domLayout)` añade un elemento DOM flotante sobre el rango especificado.

### Insertar imágenes flotantes

[`FWorksheet.newOverGridImage()`](https://docs.univer.ai/reference/facade/worksheet#newovergridimage) devuelve un constructor para una imagen flotante, una instancia de `FOverGridImageBuilder`. Cadena de las máquinas produce un objeto `ISheetImage` que se puede insertar en la hoja.

El constructor, [`FOverGridImageBuilder`](/reference/facade/over-grid-image-builder), ofrece los siguientes métodos:

| Método | Descripción |
| ------ | ----------- |
| buildAsync | Construir la imagen y devolver un objeto `ISheetImage` |
| setSource | Establecer la fuente de la imagen |
| setColumn | Establecer la posición horizontal de la imagen |
| setRow | Establecer la posición vertical de la imagen |
| setColumnOffset | Establecer el offset horizontal de la imagen |
| setRowOffset | Establecer el offset vertical de la imagen |
| setWidth | Establecer el ancho de la imagen |
| setHeight | Establecer la altura de la imagen |
| setAnchorType | Establece el tipo de anclaje, que determina si la posición y el tamaño cambian con la célula |
| setCropTop | Establecer el borde superior de la región de cultivo para que sólo la parte deseada de la imagen se muestre |
| setCropLeft | Establecer el borde izquierdo de la región de cultivo para que sólo la parte deseada de la imagen se muestre |
| setCropBottom | Establecer el borde inferior de la región de cultivo para que sólo la parte deseada de la imagen se muestre |
| setCropRight | Establecer el borde derecho de la región de cultivo para que sólo la parte deseada de la imagen se muestre |
| setRotate | Establecer el ángulo de rotación de la imagen |

```typescript
// create a new image builder and set image source.
// then build `ISheetImage` and insert it into the sheet, position is start from F6 cell, width is 500px, height is 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])
```

También se puede insertar una imagen con el método `FWorksheet.insertImage(url, column, row, offsetX, offsetY)`.

```typescript
// Insert an image to the sheet, position is F6, offset is 10px
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const result = await fWorksheet.insertImage('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', 5, 5, 10, 10)
```

### Obtener imágenes flotantes

`FWorksheet.getImages()` devuelve todas las imágenes flotantes en la hoja de trabajo como una matriz de [`FOverGridImage[]`] (https://docs.univer.ai/reference/facade/chart) instancias.

```typescript
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const images = fWorksheet.getImages()
images.forEach((image) => {
  image.getId()
})
```

Para obtener una imagen flotante por su ID, utilice el método `FWorksheet.getImageById(id)`.

### Actualizar imágenes flotantes

`FWorksheet.updateImages(sheetImages)` actualiza las imágenes flotantes en su lugar: posición, tamaño y otras propiedades.

```typescript
// create a new image builder and set image source.
// then build `ISheetImage` and insert it into the sheet, position is start from F6 cell, width is 500px, height is 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])

// update the image width to 100px and height to 50px after 4 seconds
setTimeout(async () => {
  const imageBuilder = fWorksheet.getImageById(image.drawingId).toBuilder()
  const newImage = await imageBuilder.setWidth(100).setHeight(50).buildAsync()
  fWorksheet.updateImages([newImage])
}, 4000)
```

### Eliminar imágenes flotantes

`FWorksheet.deleteImages(sheetImages)` elimina imágenes flotantes.

```typescript
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const image = fWorksheet.getImages()[0]

// Delete the first image of the sheet
fWorksheet.deleteImages([image])
```

## Imagen de fondo de la hoja [#worksheet-background]

Una hoja de trabajo también puede tener una imagen de fondo de azulejos, dibujada detrás de las celdas. La imagen se almacena en `IWorksheetData.backgroundImage` y es independiente de las imágenes flotantes y celulares. El preset de dibujo incluye esta función. En modo plugin, los paquetes necesarios son `@univerjs/sheets-drawing`, su entrada Facade, y el UI de dibujo, que proporciona controles de renderización y subida.

```ts
import '@univerjs/sheets-drawing/facade'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

sheet.setBackgroundImage('https://example.com/background.png')
console.log(sheet.getBackgroundImage())
sheet.deleteBackgroundImage()
```

`setBackgroundImage()` utiliza `ImageSourceType.URL` por defecto y reemplaza cualquier fondo existente; `deleteBackgroundImage()` lo elimina. Ambas operaciones se implementan como comandos, así que deshacer y volver a aplicar. Las imágenes cargadas son resueltas por la interfaz de usuario a través del servicio I/O de imagen configurada. El fondo se muestra en pantalla solamente y se excluye de la impresión.

## Opacidad de las imágenes [#image-opacity]

Las imágenes flotantes utilizan un único valor de opacidad para toda la imagen. `setOpacity()` acepta un número finito de `0` (transparente) a `1` (opaque); el valor predeterminado es `1`, y cualquier otro valor arroja `RangeError`. Ponlo en `FOverGridImageBuilder` antes de construir, o en un `FOverGridImage` que ya está en la hoja. Ambos exponen `getOpacity()`. El panel de propiedades de la imagen también proporciona un control de transparencia.

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
const image = sheet?.getImages()[0]
if (image) {
  image.setOpacity(0.5)
  console.log(image.getOpacity())
}
```

## Tamaño y anclaje de imágenes [#image-sizing-and-anchors]

Las imágenes insertadas a través del selector de archivos incorporado mantienen su relación de aspecto y se escalan para encajar dentro de 500 × 500 píxeles cuando son demasiado grandes; las imágenes pequeñas no se agrandan. Ese tamaño de la pantalla es independiente del límite de byte `allowImageSize` en las subidas. Cuando una imagen se inserta a través de la Facade, el callador suministra las dimensiones.

Los anclas determinan lo que sucede cuando las células se mueven o redimensionan. `SheetDrawingAnchorType.Position` mueve la imagen con las células manteniendo su tamaño, `Both` se mueve y la redimensa con el rango anclado, y `None` mantiene una posición y tamaño fijos. El montaje o la visualización de filas o columnas preserva la definición del ancla: una imagen tamaño de un rango puede colapsar con ese rango de nuevo y recuperarse.
