La caractéristique de l'esquisse, également appelée le schéma de regroupement ou de dimension, regroupe des lignes ou des colonnes dans une feuille de travail en groupes pliables, ce qui facilite l'organisation et la synthèse de grands ensembles de données.

## Introduction

Dans les feuilles Univer, la fonction de contour prend en charge les opérations suivantes:

- **Lignes ou colonnes de groupe** : Construisez des groupes hiérarchiques de lignes ou de colonnes pour organiser les données.
- **Réduire et élargir les groupes**: Afficher ou masquer un groupe de lignes ou de colonnes avec un seul clic.
- **Groupes en nids** : Créer plusieurs niveaux de groupes lorsque les données ont une hiérarchie plus profonde.

Les groupes de plan sont couramment utilisés dans les cas suivants :

- Résumer les données détaillées: Grouper les lignes détaillées sous les lignes sommaires pour obtenir une vue plus claire.
- Organisation de grands ensembles de données : Conservez les colonnes ou les lignes connexes ensemble afin qu'elles soient plus faciles à naviguer.
- Création de rapports pliables : Laissez les utilisateurs élargir ou effondrer une section d'un rapport au besoin.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/sheets-outline @univerjs-pro/sheets-outline-ui
```

### Utilisation

```typescript
import { UniverSheetsOutlinePlugin } from '@univerjs-pro/sheets-outline' // [!code ++]
import { UniverSheetsOutlineUIPlugin } from '@univerjs-pro/sheets-outline-ui' // [!code ++]
import SheetsOutlineUIEnUS from '@univerjs-pro/sheets-outline-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-outline/facade' // [!code ++]

import '@univerjs-pro/sheets-outline-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsOutlineUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsOutlinePlugin)
univer.registerPlugin(UniverSheetsOutlineUIPlugin)
```

Si vous avez une licence commerciale pour Univer, configurez-la comme décrit dans [Utilisation de la licence dans le client](/server/license#in-plugin-mode).

## Mode prédéfini

La fonctionnalité de plan est incluse dans le preset `@univerjs/preset-sheets-advanced`.

### Installation

```package-install
npm install @univerjs/preset-sheets-advanced
```

### Utilisation

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
import UniverPresetSheetsAdvancedEnUS from '@univerjs/preset-sheets-advanced/locales/en-US' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-advanced/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsAdvancedEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsAdvancedPreset(), // [!code ++]
  ],
})
```

Si vous avez une licence commerciale pour Univer, configurez-la comme décrit dans [Utilisation de la licence dans le client](/server/license#in-preset-mode).

## API Facade

Les définitions de type Facade API complètes sont dans [FacadeAPI](/reference/facade/univer).

### Importation

<Callout type="info" title="Note du mode greffon">
  Le paquet Facade est importé manuellement seulement en mode plugin. Le mode Preset inclut déjà le paquet Facade correspondant, donc aucune importation supplémentaire n'est requise.
</Callout>

```typescript
import '@univerjs-pro/sheets-outline/facade'
```

### Création de plans de lignes

Créer un groupe de lignes avec le Facade API :

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Group rows 2 to 6 (0-based index: startRow=1, numRows=5)
fWorksheet.addRowOutline(1, 5)
```

### Création de plans de colonnes

Les contours des colonnes sont créés de la même manière :

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Group columns B to E (0-based index: startColumn=1, numColumns=4)
fWorksheet.addColumnOutline(1, 4)
```

### Repli et dépli des plans

Les groupes peuvent également être effondrés ou élargis sur le plan programmatique :

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

const rowOutlines = fWorksheet.getDimensionOutlines(univerAPI.Enum.DimensionOutlineAxis.ROW)
if (rowOutlines.length > 0) {
  // Collapse the first row outline group
  fWorksheet.setDimensionOutlineCollapsed(rowOutlines[0].id, true)

  // Expand it later
  fWorksheet.setDimensionOutlineCollapsed(rowOutlines[0].id, false)
}
```

### Suppression de plans

Supprimer un seul groupe de contours par son ID:

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

const rowOutlines = fWorksheet.getDimensionOutlines(univerAPI.Enum.DimensionOutlineAxis.ROW)
if (rowOutlines.length > 0) {
  fWorksheet.removeDimensionOutline(rowOutlines[0].id)
}
```

### Effacement des plans dans une plage

Effacer tous les groupes de contours à l'intérieur d'une plage :

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Remove all row outline groups fully contained in rows 2 to 10
fWorksheet.clearDimensionOutlines(univerAPI.Enum.DimensionOutlineAxis.ROW, 1, 9)
```

### Consultation des plans

Lisez les groupes de travail qui existent sur une feuille de travail :

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all row outlines
const rowOutlines = fWorksheet.getDimensionOutlines(univerAPI.Enum.DimensionOutlineAxis.ROW)
rowOutlines.forEach((outline) => {
  console.log(outline.id, outline.start, outline.end, outline.collapsed)
})

// Get all outlines (both row and column)
const allOutlines = fWorksheet.getDimensionOutlines()
```

## Structure des données d’un plan

Un groupe de contours a les propriétés suivantes:

| Propriété | Type | Description |
|----------|------|-------------|
| `id` | `string` | Identifiant unique du groupe de plan |
| `unitId` | `string` | Identifiant d’unité du classeur |
| `subUnitId` | `string` | Identifiant de la feuille de calcul |
| `axis` | `DimensionOutlineAxis` | Axe du plan (`row` ou `column`) |
| `start` | `number` | Indice de début inclusif, à partir de zéro |
| `end` | `number` | Indice de fin inclusif, à partir de zéro |
| `collapsed` | `boolean` | Indique si le groupe est actuellement replié |

## Validation et erreurs

Créer un groupe de contours effectue les vérifications suivantes :

- **Plage non valide**: La plage doit être valide, c'est-à-dire non négative et avec un nombre non nul.
- **Hors limites** : La plage doit rester dans les limites de la feuille de travail.
- **Groupes croisés**: Un nouveau groupe ne peut pas traverser un groupe existant.
- **Profondeur maximale** : Les groupes de référence ont une profondeur maximale de nidification.

La portée passée au dégroupement doit contenir la portée du groupe de contours, sinon la vérification échoue.

Lorsqu'une vérification échoue, la commande ne s'exécute pas et l'erreur est émise par le `SheetsOutlineErrorService`.
