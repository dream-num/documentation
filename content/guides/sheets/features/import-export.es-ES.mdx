## Formatos compatibles

La tabla describe las API del navegador de esta página. La conversión de archivos Office requiere un backend compatible con el mismo tipo de documento y formato.

| Importación | Exportación |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

## API de fachada [#facade-api]

### Importar

<Callout type="info" title="Plugin mode note">
  Solo el modo complemento requiere importar manualmente el paquete Facade. El modo preestablecido ya incluye el paquete
  Facade correspondiente, por lo que no se necesita ninguna importación adicional.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/sheets-exchange-client/facade'
```

### Importar `.xlsx`

#### Importar el archivo `.xlsx` y obtener `unitId`

<Callout type="warning" title="Caution">
  Este método requiere colaboración: crea un documento de servidor y devuelve un `unitId`. Utilice la importación de
  instantáneas si la colaboración no está habilitada.
</Callout>

Cuando la edición colaborativa está habilitada, cada documento tiene un `unitId` único. El uso de `univerAPI.importSheetToUnitIdAsync` con el parámetro `file` devolverá el `unitId`, que se puede utilizar para acceder al documento. El parámetro `file` puede ser un objeto `File` o una URL de archivo remoto.

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importSheetToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadSheetAsync(unitId)
}
```

#### Importe el archivo `.xlsx` y obtenga `IWorkbookData`

<Callout>
  La importación de instantáneas no requiere colaboración. Utilice la importación `unitId` para documentos
  colaborativos.
</Callout>

Usar `univerAPI.importSheetToSnapshotAsync` para importar un archivo `.xlsx` devolverá los datos del documento en el formato `IWorkbookData`.

```typescript
// Accept a File object
const snapshot = await univerAPI.importSheetToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importSheetToSnapshotAsync('https://example.com/filename.xlsx');

// Create a new workbook via snapshot
if (snapshot) univerAPI.createWorkbook(snapshot)
```

### Exportar `.xlsx`

#### Exportar `.xlsx` archivo usando `unitId`

<Callout type="warning" title="Caution">
  La exportación `unitId` requiere colaboración. Si la colaboración no está habilitada, utilice la exportación de
  instantáneas.
</Callout>

Cuando la edición colaborativa está habilitada, cada documento tiene un `unitId` único. El uso de `univerAPI.exportSheetByUnitIdAsync` con el parámetro `unitId` devolverá un objeto `File`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook.getId()
const file = await univerAPI.exportSheetByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

#### Exportar el archivo `.xlsx` usando `IWorkbookData`

<Callout>La exportación de instantáneas no requiere colaboración y es adecuada para flujos de trabajo locales.</Callout>

Usar `univerAPI.exportSheetBySnapshotAsync` con `IWorkbookData` devolverá un objeto `File`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
const file = await univerAPI.exportSheetBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```
