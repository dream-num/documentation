APIs de instantánea requieren el mismo backend pero no requieren un documento de colaboración.

## Formatos compatibles

La tabla enumera los formatos soportados por las APIs del navegador en esta página. La conversión de archivo de Office también requiere un backend que soporta el mismo tipo de documento y formato.

| Importación | Exportación |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV y TSV exportan una sola hoja de trabajo, sin formato de libro de trabajo o las otras hojas de trabajo. Pase `ExchangeFormat.CSV` o `ExchangeFormat.TSV` junto con el `sheetId` a la API de exportación; XLSX es el predeterminado. La API del navegador no acepta `.xlsm`, incluso cuando el backend de conversión lo soporta.

## API de fachada [#facade-api]

### Importar

<Callout type="info" title="Nota del modo Plugin">
  Sólo el modo plugin requiere importar manualmente el paquete Facade. El modo Preset ya incluye el paquete de coincidencia.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/sheets-exchange-client/facade'
```

### Importar `.xlsx`

#### Importar el archivo `.xlsx` y obtener `unitId`

<Callout type="warning" title="Precaución">
  Este método requiere colaboración: crea un documento en el servidor y devuelve un `unitId`. Si la colaboración no está activada, utilice la importación de instantáneas en su lugar.
</Callout>

Cuando se habilita la edición de colaboración, cada documento tiene un `unitId` único. Pase un `file` a `univerAPI.importSheetToUnitIdAsync`, y el método devuelve que `unitId` que se utiliza para abrir el documento. `file` puede ser un objeto `File` o una URL de archivo remoto.

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importSheetToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadSheetAsync(unitId)
}
```

#### Importe el archivo `.xlsx` y obtenga `IWorkbookData`

<Callout>
  La importación de instantáneas no requiere colaboración. Utilice la importación `unitId` para documentos
  colaborativos.
</Callout>

`univerAPI.importSheetToSnapshotAsync` importa un archivo `.xlsx` y devuelve los datos del documento como `IWorkbookData`.

```typescript
// Accept a File object
const snapshot = await univerAPI.importSheetToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importSheetToSnapshotAsync('https://example.com/filename.xlsx');

// Create a new workbook via snapshot
if (snapshot) univerAPI.createWorkbook(snapshot)
```

### Exportar `.xlsx`

#### Exportar `.xlsx` archivo usando `unitId`

<Callout type="warning" title="Precaución">
  Exportar por `unitId` requiere colaboración. Si la colaboración no está activada, utilice la exportación instantánea.
</Callout>

Cuando la edición colaborativa está habilitada, cada documento tiene un `unitId` único. Pase que `unitId` a `univerAPI.exportSheetByUnitIdAsync`, y el método devuelve un objeto `File`.

El `unitId` debe identificar un documento guardado en el backend configurado y accesible para la sesión actual. `createWorkbook(snapshot)` crea un libro local en el navegador; `getId()` no lo sube. Exportar ese ID local puede devolver `PERMISSION_DENIED` (`code=3`). Para un libro local, use `exportSheetBySnapshotAsync(fWorkbook.save())`, como se muestra a continuación.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook.getId()
const file = await univerAPI.exportSheetByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

#### Exportar el archivo `.xlsx` usando `IWorkbookData`

<Callout>La exportación de instantáneas no requiere colaboración y es adecuada para los flujos de trabajo locales.</Callout>

Pase el `IWorkbookData` a `univerAPI.exportSheetBySnapshotAsync`, y el método devuelve un objeto `File`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
const file = await univerAPI.exportSheetBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

## Eliminación de los menús y las interacciones de UI de importación y exportación integrados [#import-export-ui-migration]

<Callout type="warning" title="Nota">
  A partir de la versión **1.2.0**, Univer ya no incluye menús integrados de importación/exportación e interacciones UI. Los servicios subyacentes y las API de Facade permanecen disponibles.
</Callout>

Si la aplicación todavía necesita esos menús e interacciones, el [ejemplo de migración para menús integrados de importación/exportación e interacciones de la UI](https://office.univer.ai/showcase/sheets/custom-import-export) muestra cómo restaurarlos con un plugin personalizado. El código fuente completo está disponible para la lectura o descarga en línea.
