El formato condicional permite a los usuarios cambiar automáticamente el formato de las celdas según condiciones específicas, resaltando datos o tendencias importantes. Admite varias condiciones y opciones de formato, lo que ayuda a los usuarios a comprender los datos de forma más intuitiva.

## Modo preestablecido

### Instalación

```package-install
npm install @univerjs/preset-sheets-conditional-formatting
```

### Uso

```typescript
import { UniverSheetsConditionalFormattingPreset } from '@univerjs/preset-sheets-conditional-formatting' // [!code ++]
import UniverPresetSheetsConditionalFormattingEnUS from '@univerjs/preset-sheets-conditional-formatting/locales/en-US' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-conditional-formatting/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsConditionalFormattingEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsConditionalFormattingPreset(), // [!code ++]
  ],
})
```

## Modo de complemento

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
```

### Crear reglas de formato condicional

[`FWorksheet.newConditionalFormattingRule()`](https://docs.univer.ai/reference/facade/worksheet#newconditionalformattingrule) crea un generador de formato condicional, devolviendo una instancia de `FConditionalFormattingBuilder`, que se puede usar para generar reglas de formato condicional a través del encadenamiento de métodos.

Aquí hay algunos métodos miembros. de [`FConditionalFormattingBuilder`](https://docs.univer.ai/reference/facade/conditional-formatting):

| Método | Descripción |
| ---- | ---- |
| build | Crea el formato condicional regla |
| copy | Clonar profundamente un constructor actual |
| createCfId | Crear un ID de formato condicional |
| getRanges | Obtiene el alcance del formato condicional actual |
| setRanges | Establece el rango de la regla de formato condicional |
| setAverage | Establece la regla de formato condicional de valor promedio |
| setUniqueValues | Establece la regla de formato condicional de valor único |
| setDuplicateValues | Establece la regla de formato condicional de valor duplicado |
| setRank | Establece la regla de formato condicional de clasificación |
| setIconSet | Establece la regla de formato condicional de conjunto de iconos |
| setColorScale | Establece la regla de formato condicional de escala de color |
| setDataBar | Establece la regla de formato condicional de la barra de datos |
| setBackground | Establece el color de fondo del formato condicional |
| setBold | Establece si la fuente del formato condicional está en negrita |
| setFontColor | Establece el color de fuente del formato condicional |
| setItalic | Establece si la fuente del formato condicional es cursiva |
| setStrikethrough | Establece si la fuente del formato condicional tiene un tachado |
| setUnderline | Establece si la fuente del formato condicional tiene un subrayado |
| whenCellEmpty | Establece la regla de formato condicional para que se active cuando la celda está vacía |
| whenCellNotEmpty | Establece la regla de formato condicional para que se active cuando la celda no está vacía |
| whenDate | Establece la regla de formato condicional para que se active cuando la fecha está dentro un período de tiempo específico |
| whenFormulaSatisfied | Establece la regla de formato condicional para que se active cuando el resultado del cálculo de la fórmula sea verdadero |
| whenNumberBetween | Establece la regla de formato condicional para que se active cuando el número está entre dos valores especificados o igual a uno de ellos |
| whenNumberEqualTo | Establece la regla de formato condicional para que se active cuando el número es igual al valor dado |
| whenNumberGreaterThan | Establece la regla de formato condicional para que se active cuando el número es mayor que el valor dado |
| whenNumberGreaterThanOrEqualTo | Establece la regla de formato condicional para que se active cuando el número es mayor mayor o igual que el valor dado |
| whenNumberLessThan | Establece la regla de formato condicional para que se active cuando el número es menor que el valor dado |
| whenNumberLessThanOrEqualTo | Establece la regla de formato condicional para que se active cuando el número es menor o igual que el valor dado |
| whenNumberNotBetween | Establece la regla de formato condicional para que se active cuando el número no está entre dos valores especificados y no es igual a ellos |
| whenNumberNotEqualTo | Establece la regla de formato condicional para que se active cuando el número no es igual al valor dado |
| whenTextContains | Establece la regla de formato condicional para que se active cuando el texto contiene el valor especificado |
| whenTextDoesNotContain | Establece la regla de formato condicional para que se active cuando el texto no contiene el valor especificado |
| whenTextEndsWith | Establece la regla de formato condicional para que se active cuando el texto termina con el valor especificado |
| whenTextEqualTo | Establece la regla de formato condicional para que se active cuando el texto es igual al valor dado |
| whenTextStartsWith | Establece la regla de formato condicional para que se active cuando el texto comienza con el valor especificado |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)
```

### Obtener reglas de formato condicional

- `FWorksheet.getConditionalFormattingRules()` obtiene todas las reglas de formato condicional de la hoja de trabajo
- `FRange.getConditionalFormattingRules()` obtiene todas las reglas de formato condicional del rango

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Get all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
const rulesOfSheet = fWorksheet.getConditionalFormattingRules()

// Get all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
const rulesOfRange = fRange.getConditionalFormattingRules()
```

### Eliminar formato condicional Reglas

`FWorksheet.deleteConditionalFormattingRule(cfId)` elimina una regla de formato condicional de la hoja de trabajo, donde `cfId` es el ID de la regla de formato condicional.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Remove the first conditional formatting rule
fWorksheet.deleteConditionalFormattingRule(rules[0]?.cfId)
```

### Actualizar reglas de formato condicional

`FWorksheet.setConditionalFormattingRule(cfId, rule)` actualiza una regla de formato condicional en la hoja de trabajo, donde `cfId` es el ID de la regla de formato condicional y `rule` es la nueva regla de formato condicional.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)

// Modify the first rule to apply to a new range
const rules = fWorksheet.getConditionalFormattingRules()
const newRuleRange = fWorksheet.getRange('A1:D10')
fWorksheet.setConditionalFormattingRule(rules[0]?.cfId, { ...rules[0], ranges: [newRuleRange.getRange()] })
```

### Modificar la prioridad de las reglas de formato condicional

`FWorksheet.moveConditionalFormattingRule(cfId, toCfId, type)` modifica la prioridad de una regla de formato condicional en la hoja de trabajo, donde `cfId` es el ID de la regla de formato condicional, `toCfId` es el ID de la regla de formato condicional de destino y `type` especifica el tipo de movimiento (por ejemplo, 'antes', 'después').

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Move the third rule before the first rule
const rule = rules[2]
const targetRule = rules[0]
fWorksheet.moveConditionalFormattingRule(rule?.cfId, targetRule?.cfId, 'before')
```

### Borrar todo el formato condicional Reglas

- `FWorksheet.clearConditionalFormatRules()` borra todas las reglas de formato condicional de la hoja de trabajo.
- `FRange.clearConditionalFormatRules()` borra todas las reglas de formato condicional del rango.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Clear all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.clearConditionalFormatRules()

// Clear all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
fRange.clearConditionalFormatRules()
```
