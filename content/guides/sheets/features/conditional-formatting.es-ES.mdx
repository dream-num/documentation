El formato condicional cambia el formato de una célula automáticamente cuando una condición sostiene, de modo que se destacan los datos y tendencias importantes. Admite múltiples condiciones y opciones de formato, lo que facilita la lectura de los datos de un vistazo.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs/sheets-conditional-formatting @univerjs/sheets-conditional-formatting-ui
```

### Uso

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsConditionalFormattingPlugin } from '@univerjs/sheets-conditional-formatting' // [!code ++]
import { UniverSheetsConditionalFormattingUIPlugin } from '@univerjs/sheets-conditional-formatting-ui' // [!code ++]
import SheetsConditionalFormattingUIEnUS from '@univerjs/sheets-conditional-formatting-ui/locale/en-US' // [!code ++]
import '@univerjs/sheets-conditional-formatting-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-conditional-formatting/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsConditionalFormattingUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsConditionalFormattingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsConditionalFormattingUIPlugin) // [!code ++]
```

### Crear reglas de formato condicional

[`FWorksheet.newConditionalFormattingRule()`](https://docs.univer.ai/reference/facade/worksheet#newconditionalformattingrule) devuelve un `FConditionalFormattingBuilder`. Llame sus métodos en una cadena para definir la regla.

Los métodos de miembros de [`FConditionalFormattingBuilder`](/reference/facade/conditional-formatting-builder) incluyen:

| Método | Descripción |
| ---- | ---- |
| build | Construye la regla |
| copy | Deep-clones el constructor actual |
| createCfId | Crea un ID de formato condicional |
| getRanges | Consigue los rangos del formato condicional actual |
| setRanges | Establece el rango de la regla aplicable a |
| setAverage | Establece una regla de valor promedio |
| setUniqueValues | Establece una regla de valor único |
| setDuplicateValues | Establece una regla de valores duplicados |
| setRank | Es una regla de rango |
| setIconSet | Establece una regla de iconos |
| setColorScale | Establece una regla a escala de color |
| setDataBar | Establece una regla de barra de datos |
| setBackground | Establece el color de fondo |
| setBold | Establece texto audaz |
| setFontColor | Configura el color de la fuente |
| setItalic | Establece texto itálico |
| setStrikethrough | Sets strikethrough |
| setUnderline | Sets underline |
| whenCellEmpty | Fuegos cuando la célula está vacía |
| whenCellNotEmpty | Fuegos cuando la célula no está vacía |
| whenDate | Fuegos cuando la fecha cae en un período específico |
| whenFormulaSatisfied | Fuegos cuando la fórmula evalúa a la verdad |
| whenNumberBetween | Fuegos cuando el número es entre dos valores, o igual a uno de ellos |
| whenNumberEqualTo | Fuegos cuando el número es igual al valor dado |
| whenNumberGreaterThan | Fuegos cuando el número es mayor que el valor dado |
| whenNumberGreaterThanOrEqualTo | Fuegos cuando el número es mayor o igual al valor dado |
| whenNumberLessThan | Fuegos cuando el número es menor que el valor dado |
| whenNumberLessThanOrEqualTo | Fuegos cuando el número es inferior o igual al valor dado |
| whenNumberNotBetween | Fuegos cuando el número no es entre dos valores y no igual a ninguno |
| whenNumberNotEqualTo | Fuegos cuando el número no es igual al valor dado |
| whenTextContains | Fuegos cuando el texto contiene el valor especificado |
| whenTextDoesNotContain | Fuegos cuando el texto no contiene el valor especificado |
| whenTextEndsWith | Fuegos cuando el texto termina con el valor especificado |
| whenTextEqualTo | Fuegos cuando el texto es igual al valor dado |
| whenTextStartsWith | Fuegos cuando el texto comienza con el valor especificado |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)
```

### Obtener reglas de formato condicional

- `FWorksheet.getConditionalFormattingRules()` obtiene todas las reglas de formato condicional de la hoja de trabajo
- `FRange.getConditionalFormattingRules()` obtiene todas las reglas de formato condicional del rango

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Get all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
const rulesOfSheet = fWorksheet.getConditionalFormattingRules()

// Get all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
const rulesOfRange = fRange.getConditionalFormattingRules()
```

### Eliminar formato condicional Reglas

`FWorksheet.deleteConditionalFormattingRule(cfId)` elimina una regla de la hoja de trabajo. `cfId` es el ID de la regla.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Remove the first conditional formatting rule
fWorksheet.deleteConditionalFormattingRule(rules[0]?.cfId)
```

### Actualizar reglas de formato condicional

`FWorksheet.setConditionalFormattingRule(cfId, rule)` reemplaza una regla en la hoja de trabajo. `cfId` es el ID de la regla para reemplazar, y `rule` la nueva regla.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a conditional formatting rule that sets the cell format to italic, red background, and green font color when the cell is not empty.
const fRange = fWorksheet.getRange('A1:T100')
const rule = fWorksheet.newConditionalFormattingRule()
  .whenCellNotEmpty()
  .setRanges([fRange.getRange()])
  .setItalic(true)
  .setBackground('red')
  .setFontColor('green')
  .build()
fWorksheet.addConditionalFormattingRule(rule)

// Modify the first rule to apply to a new range
const rules = fWorksheet.getConditionalFormattingRules()
const newRuleRange = fWorksheet.getRange('A1:D10')
fWorksheet.setConditionalFormattingRule(rules[0]?.cfId, { ...rules[0], ranges: [newRuleRange.getRange()] })
```

### Modificar la prioridad de las reglas de formato condicional

`FWorksheet.moveConditionalFormattingRule(cfId, toCfId, type)` cambia la posición de una regla en el orden de prioridad. `cfId` es la regla para moverse, `toCfId` Es la regla que se mueve en relación con, y `type` el tipo de movimiento (por ejemplo, 'antes', 'después').

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const rules = fWorksheet.getConditionalFormattingRules()

// Move the third rule before the first rule
const rule = rules[2]
const targetRule = rules[0]
fWorksheet.moveConditionalFormattingRule(rule?.cfId, targetRule?.cfId, 'before')
```

### Borrar todo el formato condicional Reglas

- `FWorksheet.clearConditionalFormatRules()` borra todas las reglas de formato condicional de la hoja de trabajo
- `FRange.clearConditionalFormatRules()` borra todas las reglas de formato condicional del rango

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Clear all conditional formatting rules of the active worksheet
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.clearConditionalFormatRules()

// Clear all conditional formatting rules of the range A1:T100
const fRange = fWorksheet.getRange('A1:T100')
fRange.clearConditionalFormatRules()
```

## Reutilizar descripciones y vistas previas de reglas [#custom-rule-ui]

Para construir una lista de reglas personalizadas, importar `getRuleDescribe` y `ConditionalFormattingRulePreview` de `@univerjs/sheets-conditional-formatting-ui`. Pase toda la regla a `getRuleDescribe(rule, localeService)`, y pasar sólo su configuración (`rule.rule`) a la vista previa. La vista previa renderiza la apariencia configurada y no evalúa células de hoja de trabajo. Renderla dentro del contexto Univer de React.

`CF_PANEL_KEY` identifica el panel incorporado, por lo que [componente anula](/guides/sheets/ui/components) puede apuntarlo. Su callback `IConditionFormattingPanelProps.onEditorExit` funciona cuando finaliza la edición: después de un envío, después de una cancelación, o cuando la hoja de trabajo se activa o se elimina. No indica si el ahorro tuvo éxito o si la barra lateral se cerró.

```tsx
import type { IConditionFormattingRule } from '@univerjs/sheets-conditional-formatting'
import { LocaleService } from '@univerjs/core'
import { ConditionalFormattingRulePreview, getRuleDescribe } from '@univerjs/sheets-conditional-formatting-ui'
import { useDependency } from '@univerjs/ui'

interface IRuleSummaryProps {
  rule: IConditionFormattingRule
}

function RuleSummary({ rule }: IRuleSummaryProps) {
  const localeService = useDependency(LocaleService)

  return (
    <div>
      <span>{getRuleDescribe(rule, localeService)}</span>
      <ConditionalFormattingRulePreview rule={rule.rule} />
    </div>
  )
}
```

## Prioridad de reglas y detener si es verdadero [#stop-if-true]

Las reglas se aplican en orden prioritario. Para una celda determinada, una regla de referencia que coincide con la que `stopIfTrue: true` suprime reglas de menor prioridad, incluso cuando la regla de juego no establece estilo. Si la regla no coincide, la evaluación continúa. Los resultados de reglas de mayor prioridad permanecen en vigor. El editor de reglas proporciona esta opción para reglas de resaltar solamente; escalas de color, barras de datos y conjuntos de iconos no lo tienen.

El ejemplo añade la regla de fondo de baja prioridad primero porque una regla recién agregada se coloca en la parte superior de la lista. Cuando se activa la parada, 90 aparece en negrita sin el fondo verde, mientras que 60 todavía recibe el fondo. `stopIfTrue` pertenece al objeto de regla exterior, no a `rule`.

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

const ranges = [sheet.getRange('B2:B10').getRange()]
const backgroundRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(50)
  .setBackground('#DCFCE7')
  .setRanges(ranges)
  .build()
const priorityRule = sheet.newConditionalFormattingRule()
  .whenNumberGreaterThanOrEqualTo(80)
  .setBold(true)
  .setRanges(ranges)
  .build()

sheet.addConditionalFormattingRule(backgroundRule)
sheet.addConditionalFormattingRule({ ...priorityRule, stopIfTrue: true })
```
