圖片可以表達用文字不易說明的資訊。Univer 的圖片分為兩種：浮動圖片顯示在表格上方，單元格圖片繫結到單個單元格。

## 外掛模式

### 安裝

```package-install
npm install @univerjs/docs-drawing @univerjs/drawing @univerjs/drawing-ui @univerjs/sheets-drawing @univerjs/sheets-drawing-ui
```

### 使用

```typescript
import { IImageIoService, LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsDrawingPlugin } from '@univerjs/docs-drawing' // [!code ++]
import { UniverDrawingPlugin } from '@univerjs/drawing' // [!code ++]
import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui' // [!code ++]
import DrawingUIZhTW from '@univerjs/drawing-ui/locale/zh-TW' // [!code ++]
import { UniverSheetsDrawingPlugin } from '@univerjs/sheets-drawing' // [!code ++]
import { UniverSheetsDrawingUIPlugin } from '@univerjs/sheets-drawing-ui' // [!code ++]
import SheetsDrawingUIZhTW from '@univerjs/sheets-drawing-ui/locale/zh-TW' // [!code ++]

import '@univerjs/drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing-ui/lib/index.css' // [!code ++]

import '@univerjs/sheets-drawing/facade' // [!code ++]
import '@univerjs/sheets-drawing-ui/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      DrawingUIZhTW, // [!code ++]
      SheetsDrawingUIZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverDrawingUIPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingUIPlugin) // [!code ++]
```

如果使用[協同編輯](/guides/docs/features/collaboration)，需要新增 `override` 配置：

```typescript
univer.registerPlugin(UniverDrawingPlugin, {
  override: [[IImageIoService, null]], // [!code ++]
  // allowImageSize: 20 * 1024 * 1024, // 設定上傳圖片的最大允許大小為 20MB，非必要
})
```

### 新增浮動 DOM

`FWorksheet.addFloatDomToPosition(layer)` 在指定位置新增一個浮動 DOM 元素。

```tsx
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 你應該在合適的時機註冊元件（例如 Univer 載入完成時）
// 這是一個 React 元件。對於 Vue3 元件，第三個參數應該是 `{ framework: 'vue3' }`
univerAPI.registerComponent(
  'myFloatDom',
  ({ data }) => (
    <div style={{ width: '100%', height: '100%', background: '#fff', border: '1px solid #ccc', boxSizing: 'border-box' }}>
      popup content:
      {' '}
      {data?.label}
    </div>
  ),
)

// 新增浮動 DOM
// 如果 disposable 為 null，則浮動 DOM 新增失敗
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'myFloatDom',
  initPosition: {
    startX: 100,
    endX: 300,
    startY: 100,
    endY: 200,
  },

  // 元件資料
  data: {
    label: 'hahah',
  },
})

// 2 秒後移除浮動 DOM
setTimeout(() => {
  disposable?.dispose()
}, 2000)
```

### 插入浮動圖片

[`FWorksheet.newOverGridImage()`](https://docs.univer.ai/reference/facade/worksheet#newovergridimage) 返回一個浮動圖片建置器，即 `FOverGridImageBuilder` 例項。在建置器上鍊式呼叫，可得到用於插入浮動圖片的 `ISheetImage` 物件。

[`FOverGridImageBuilder`](/reference/facade/over-grid-image-builder) 提供以下方法：

| 方法 | 描述 |
| ---- | ---- |
| buildAsync | 建置圖片並返回 `ISheetImage` 物件 |
| setSource | 設定圖片來源 |
| setColumn | 設定圖片的水平位置 |
| setRow | 設定圖片的垂直位置 |
| setColumnOffset | 設定圖片的水平偏移 |
| setRowOffset | 設定圖片的垂直偏移 |
| setWidth | 設定圖片寬度 |
| setHeight | 設定圖片高度 |
| setAnchorType | 設定錨點型別，決定位置和尺寸是否隨單元格變化 |
| setCropTop | 設定裁剪區域的上邊緣，只顯示圖片所需部分 |
| setCropLeft | 設定裁剪區域的左邊緣，只顯示圖片所需部分 |
| setCropBottom | 設定裁剪區域的下邊緣，只顯示圖片所需部分 |
| setCropRight | 設定裁剪區域的右邊緣，只顯示圖片所需部分 |
| setRotate | 設定圖片的旋轉角度 |

```typescript
// 建立一個新的圖片構建器並設定圖片來源。
// 然後構建 `ISheetImage` 並插入到工作表中，位置從 F6 單元格開始，寬度為 500px，高度為 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])
```

也可以使用 `FWorksheet.insertImage(url, column, row, offsetX, offsetY)` 方法插入圖片。

```typescript
// 插入一個圖片到工作表，位置為 F6，偏移為 10px
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const result = await fWorksheet.insertImage('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', 5, 5, 10, 10)
```

### 獲取浮動圖片

`FWorksheet.getImages()` 返回工作表中的所有浮動圖片，結果為 [`FOverGridImage[]`](https://docs.univer.ai/reference/facade/chart) 例項陣列。

```typescript
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const images = fWorksheet.getImages()
images.forEach((image) => {
  image.getId()
})
```

如需按 ID 取得單張浮動圖片，可使用 `FWorksheet.getImageById(id)` 方法。

### 更新浮動圖片

`FWorksheet.updateImages(sheetImages)` 更新浮動圖片的位置、大小等屬性。

```typescript
// 建立一個新的圖片構建器並設定圖片來源。
// 然後構建 `ISheetImage` 並插入到工作表中，位置從 F6 單元格開始，寬度為 500px，高度為 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])

// 4 秒後更新圖片寬度為 100px，高度為 50px
setTimeout(async () => {
  const imageBuilder = fWorksheet.getImageById(image.drawingId).toBuilder()
  const newImage = await imageBuilder.setWidth(100).setHeight(50).buildAsync()
  fWorksheet.updateImages([newImage])
}, 4000)
```

## 工作表背景圖 [#worksheet-background]

工作表還可以包含一張平鋪背景圖，繪製在單元格下方。該圖儲存在 `IWorksheetData.backgroundImage` 中，與浮動圖片和單元格圖片相互獨立。繪圖預設已包含此功能。外掛模式需要 `@univerjs/sheets-drawing` 及其 Facade 入口，以及負責渲染和上傳控制元件的繪圖 UI。

```ts
import '@univerjs/sheets-drawing/facade'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

sheet.setBackgroundImage('https://example.com/background.png')
console.log(sheet.getBackgroundImage())
sheet.deleteBackgroundImage()
```

`setBackgroundImage()` 預設使用 `ImageSourceType.URL`，並替換已有背景；`deleteBackgroundImage()` 刪除背景。兩者均以命令實現，因此支援撤銷和重做。上傳的圖片由 UI 透過配置好的圖片 I/O 服務解析。背景僅用於螢幕顯示，不參與列印。

## 圖片不透明度 [#image-opacity]

浮動圖片的不透明度作用於整張圖片，只使用一個取值。`setOpacity()` 接受 `0`（完全透明）到 `1`（完全不透明）之間的有限數值，預設值為 `1`，其他值會丟擲 `RangeError`。可在建置前透過 `FOverGridImageBuilder` 設定，也可修改工作表中已有的 `FOverGridImage`，兩者均提供 `getOpacity()`。圖片屬性面板也提供透明度控制元件。

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
const image = sheet?.getImages()[0]
if (image) {
  image.setOpacity(0.5)
  console.log(image.getOpacity())
}
```

## 圖片尺寸與錨點 [#image-sizing-and-anchors]

使用內建檔案選擇器插入圖片時，圖片保持原始寬高比，尺寸過大時會縮小到 500 × 500 畫素以內，小圖不會放大。該顯示尺寸與 `allowImageSize` 限制的上傳位元組數相互獨立。透過 Facade 插入圖片時，尺寸由呼叫方提供。

錨點決定單元格移動或調整大小時圖片的行為。`SheetDrawingAnchorType.Position` 使圖片隨單元格移動並保持尺寸，`Both` 使圖片隨錨定範圍移動並縮放，`None` 保持位置和尺寸固定。隱藏或顯示行列不會破壞錨點定義：尺寸隨範圍縮放的圖片可能隨之收縮，範圍重新顯示後恢復。不得將隱藏行列期間的臨時幾何尺寸寫回已儲存的錨點。
