圖片功能允許使用者在電子表格中插入和管理圖片，以便更好地展示資料和資訊。它支援多種圖片格式和操作，幫助使用者建立更豐富的文件。

目前支援插入的圖片型別為：浮動圖片、單元格圖片

## 預設模式

### 安裝

```package-install
npm install @univerjs/preset-sheets-drawing
```

### 使用

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreZhTW from '@univerjs/preset-sheets-core/locales/zh-TW'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]
import UniverPresetSheetsDrawingZhTW from '@univerjs/preset-sheets-drawing/locales/zh-TW' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      UniverPresetSheetsCoreZhTW,
      UniverPresetSheetsDrawingZhTW, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsDrawingPreset(), // [!code ++]
  ],
})
```

如使用[協同編輯](/guides/sheets/features/collaboration)功能，請確保在 `UniverSheetsDrawingPreset` 中傳入 `collaboration: true` 選項。

```typescript
UniverSheetsDrawingPreset({
  collaboration: true, // [!code ++]
})
```

## 外掛模式

### 安裝

```package-install
npm install @univerjs/docs-drawing @univerjs/drawing @univerjs/drawing-ui @univerjs/sheets-drawing @univerjs/sheets-drawing-ui
```

### 使用

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsDrawingPlugin } from '@univerjs/docs-drawing' // [!code ++]
import { IImageIoService, UniverDrawingPlugin } from '@univerjs/drawing' // [!code ++]
import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui' // [!code ++]
import DrawingUIZhTW from '@univerjs/drawing-ui/locale/zh-TW' // [!code ++]
import { UniverSheetsDrawingPlugin } from '@univerjs/sheets-drawing' // [!code ++]
import { UniverSheetsDrawingUIPlugin } from '@univerjs/sheets-drawing-ui' // [!code ++]
import SheetsDrawingUIZhTW from '@univerjs/sheets-drawing-ui/locale/zh-TW' // [!code ++]

import '@univerjs/drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing-ui/lib/index.css' // [!code ++]

import '@univerjs/sheets-drawing-ui/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      DrawingUIZhTW, // [!code ++]
      SheetsDrawingUIZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverDrawingUIPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingUIPlugin) // [!code ++]
```

如使用[協同編輯](/guides/docs/features/collaboration)功能，需要新增 `override` 配置：

```typescript
univer.registerPlugin(UniverDrawingPlugin, {
  override: [[IImageIoService, null]], // [!code ++]
})
```

### 新增浮動 DOM

`FWorksheet.addFloatDomToPosition(layer)` 方法可以新增一個浮動的 DOM 元素到指定位置。

```tsx
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 你應該在合適的時機註冊元件（例如 Univer 載入完成時）
// 這是一個 React 元件。對於 Vue3 元件，第三個引數應該是 `{ framework: 'vue3' }`
univerAPI.registerComponent(
  'myFloatDom',
  ({ data }) => (
    <div style={{ width: '100%', height: '100%', background: '#fff', border: '1px solid #ccc', boxSizing: 'border-box' }}>
      popup content:
      {' '}
      {data?.label}
    </div>
  ),
)

// 新增浮動 DOM
// 如果 disposable 為 null，則浮動 DOM 新增失敗
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'myFloatDom',
  initPosition: {
    startX: 100,
    endX: 300,
    startY: 100,
    endY: 200,
  },

  // 元件資料
  data: {
    label: 'hahah',
  },
})

// 2 秒後移除浮動 DOM
setTimeout(() => {
  disposable?.dispose()
}, 2000)
```

`FWorksheet.addFloatDomToRange(range, layer, domLayout)` 方法可以新增一個浮動的 DOM 元素到指定範圍。

```tsx
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()

// 註冊一個範圍載入元件
function RangeLoading() {
  const divStyle = {
    width: '100%',
    height: '100%',
    backgroundColor: '#fff',
    border: '1px solid #ccc',
    boxSizing: 'border-box' as const,
    display: 'flex',
    justifyContent: 'center',
    alignItems: 'center',
    textAlign: 'center' as const,
    transformOrigin: 'top left',
  }

  return (
    <div style={divStyle}>
      Loading...
    </div>
  )
}
univerAPI.registerComponent('RangeLoading', RangeLoading)

// 新增範圍載入元件覆蓋範圍 A1:C3
const fRange = fWorksheet.getRange('A1:C3')
const disposable = fWorksheet.addFloatDomToRange(fRange, { componentKey: 'RangeLoading' }, {}, 'myRangeLoading')

// 2 秒後移除浮動 DOM
setTimeout(() => {
  disposable?.dispose()
}, 2000)

// 另外一個示例 -------------------

function FloatButton() {
```

### 插入浮動圖片

[`FWorksheet.newOverGridImage()`](https://reference.univer.ai/zh-TW/classes/FWorksheet#newovergridimage) 建立一個浮動圖片構建器，返回一個 `FOverGridImageBuilder` 例項，可以透過鏈式呼叫生成 `ISheetImage` 物件用於插入浮動圖片。

以下是 [`FOverGridImageBuilder`](https://reference.univer.ai/zh-TW/classes/FOverGridImageBuilder) 上的一些成員方法：

| 方法 | 描述 |
| ---- | ---- |
| buildAsync | 構建 `ISheetImage` 物件用於插入浮動圖片 |
| setSource | 設定 image 的來源 |
| setColumn | 設定 image 的水平方向位置 |
| setRow | 設定 image 的垂直方向位置 |
| setColumnOffset | 設定 image 的水平方向偏移 |
| setRowOffset | 設定 image 的垂直方向偏移 |
| setWidth | 設定 image 的寬度 |
| setHeight | 設定 image 的高度 |
| setAnchorType | 設定 image 的錨點型別，是否隨單元格位置和大小變化 |
| setCropTop | 設定 image 的裁剪區域，定義頂部邊緣，從而顯示你想要的影象的特定部分 |
| setCropLeft | 設定 image 的裁剪區域，定義左邊緣，從而顯示你想要的影象的特定部分 |
| setCropBottom | 設定 image 的裁剪區域，定義底部邊緣，從而顯示你想要的影象的特定部分 |
| setCropRight | 設定 image 的裁剪區域，定義右邊緣，從而顯示你想要的影象的特定部分 |
| setRotate | 設定 image 的旋轉角度 |

```typescript
// 建立一個新的圖片構建器並設定圖片來源。
// 然後構建 `ISheetImage` 並插入到工作表中，位置從 F6 單元格開始，寬度為 500px，高度為 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])
```

亦可以透過 `FWorksheet.insertImage(url, column, row, offsetX, offsetY)` 方法插入圖片。

```typescript
// 插入一個圖片到工作表，位置為 F6，偏移為 10px
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const result = await fWorksheet.insertImage('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', 5, 5, 10, 10)
```

### 獲取浮動圖片

`FWorksheet.getImages()` 方法可以獲取工作表中的所有浮動圖片，返回一個 [`FOverGridImage[]`](https://reference.univer.ai/zh-TW/classes/FOverGridImage) 例項陣列。

```typescript
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const images = fWorksheet.getImages()
images.forEach((image) => {
  image.getId()
})
```

亦可以透過 `FWorksheet.getImageById(id)` 方法獲取指定 id 的浮動圖片。

### 更新浮動圖片

`FWorksheet.updateImages(sheetImages)` 方法可以更新浮動圖片的位置和大小等屬性。

```typescript
// 建立一個新的圖片構建器並設定圖片來源。
// 然後構建 `ISheetImage` 並插入到工作表中，位置從 F6 單元格開始，寬度為 500px，高度為 300px
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])

// 4 秒後更新圖片寬度為 100px，高度為 50px
setTimeout(async () => {
  const imageBuilder = fWorksheet.getImageById(image.drawingId).toBuilder()
  const newImage = await imageBuilder.setWidth(100).setHeight(50).buildAsync()
  fWorksheet.updateImages([newImage])
}, 4000)
```

### 刪除浮動圖片

`FWorksheet.deleteImages(sheetImages)` 方法可以刪除浮動圖片。

```typescript
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const image = fWorksheet.getImages()[0]

// 刪除工作表中的第一個圖片
fWorksheet.deleteImages([image])
```

### 插入單元格圖片

`FRange.insertCellImageAsync(file)` 方法可以插入單元格圖片。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 在 A10 單元格插入一個圖片
const fRange = fWorksheet.getRange('A10')
const result = await fRange.insertCellImageAsync('https://avatars.githubusercontent.com/u/61444807?s=48&v=4')
```
