切片器按資料來源中的成員篩選表格、資料透視表和透檢視。時間線篩選資料透視表中可作為資料來源的原始日期欄位；表格列、文字欄位、計算欄位和派生分組欄位都不能作為時間線的資料來源。

選取資料來源後，可在「資料」索引標籤的「分析」群組中插入交叉分析篩選器或時間表。

## 外掛模式 [#plugin-mode]

### 安裝

```package-install
npm install @univerjs-pro/sheets-slicer @univerjs-pro/sheets-slicer-ui
```

### 使用

將以下內容新增到現有的 [Sheets 配置](/guides/sheets/getting-started/installation)中，前提是已經配置好[繪圖支援](/guides/sheets/features/images)以及[表格](/guides/sheets/features/table)或[資料透視表](/guides/sheets/features/pivot-table)資料來源。語言套件的載入和外掛註冊都必須在建立工作簿之前完成。

```ts
import { UniverSheetsSlicerPlugin } from '@univerjs-pro/sheets-slicer'
import { UniverSheetsSlicerUIPlugin } from '@univerjs-pro/sheets-slicer-ui'
import SheetsSlicerUILocale from '@univerjs-pro/sheets-slicer-ui/locale/zh-TW'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/sheets-slicer/facade'
import '@univerjs-pro/sheets-slicer-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.ZH_TW, SheetsSlicerUILocale)
univer.registerPlugin(UniverSheetsSlicerPlugin)
univer.registerPlugin(UniverSheetsSlicerUIPlugin)
```

### 外掛設定 [#plugin-configuration]

`UniverSheetsSlicerPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `maxMemberWindowSize` | `number` | `200` | 單次查詢最多返回的成員數。 |

## 預設模式 [#preset-mode]

### 安裝

```package-install
npm install @univerjs/presets @univerjs/preset-sheets-core @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

### 使用

高階預設已包含切片器和時間線的模型外掛、UI 外掛以及對應的 Facade API。使用該預設時，需要與核心預設和繪圖預設組合，併合並相應的語言套件。如果已經在使用高階預設，請在原有註冊中加入 `slicer` 選項，不要重複註冊。客戶端許可證的配置見[使用許可證](/server/license)。

```ts
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'
import AdvancedLocale from '@univerjs/preset-sheets-advanced/locales/zh-TW'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import CoreLocale from '@univerjs/preset-sheets-core/locales/zh-TW'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing'
import DrawingLocale from '@univerjs/preset-sheets-drawing/locales/zh-TW'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css'
import '@univerjs/preset-sheets-advanced/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(CoreLocale, DrawingLocale, AdvancedLocale),
  },
  presets: [
    UniverSheetsCorePreset({ container: 'app' }),
    UniverSheetsDrawingPreset(),
    UniverSheetsAdvancedPreset({ slicer: { maxMemberWindowSize: 200 } }),
  ],
})
```

使用 [Worker](/guides/sheets/getting-started/worker) 時，請在高階預設上設定 `useWorker: true`，並在 Worker 中註冊 `UniverSheetsAdvancedWorkerPreset()`。該預設同樣包含切片器計算外掛。

## 建立交叉分析篩選器 [#create-slicer]

以下範例使用活動工作表中 I1 處的資料透視表，以及資料來源中名為 `Region` 的欄位。原始欄位的穩定 ID 需要透過 `getSourceFieldsInfo()` 取得；顯示名稱和報表欄位 ID 都不能傳給 `newSlicer()`。

```ts
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook?.getActiveSheet()
if (!fWorkbook || !fWorksheet) throw new Error('No active worksheet')

const pivotTable = fWorkbook.getPivotTableByCell(
  fWorkbook.getId(),
  fWorksheet.getSheetId(),
  0,
  8,
)
const regionField = pivotTable?.getSourceFieldsInfo().find((field) => field.name === 'Region')
if (!pivotTable || !regionField) throw new Error('Region source field not found')

const slicer = await fWorksheet.insertSlicer(
  pivotTable.newSlicer(regionField.id)
    .setCaption(regionField.name)
    .setPosition('N2')
    .build(),
)
```

`pivotTable.newSlicer()` 將建置器繫結到該資料來源。`build()` 只組裝配置，實際建立控制元件的是 `insertSlicer()`。控制元件所在的工作表可以與源資料工作表不同，但兩者必須屬於同一個工作簿。使用表格資料來源時，請呼叫 `fWorksheet.newSlicer(columnId).setTableReference({ subUnitId, tableId })`，其中 `columnId` 是表格列的穩定 ID。

## 建立時間軸 [#create-timeline]

以下範例仍使用同一個資料透視表，並需要一個名為 `Date` 的原始日期欄位。`newTimeline()` 會校驗資料來源，並拒絕不支援的欄位。時間線的範圍 API 使用工作簿日期系統中的 Excel 序列值，不接受 JavaScript 的 `Date` 物件。

```ts
const dateField = pivotTable.getSourceFieldsInfo().find((field) => field.name === 'Date')
if (!dateField) throw new Error('Date source field not found')

const timeline = await fWorksheet.insertTimeline(
  pivotTable.newTimeline(dateField.id)
    .setCaption(dateField.name)
    .setLevel(univerAPI.Enum.TimelineLevel.Month)
    .setPosition('N18')
    .build(),
)
```

## 尋找控制項與監聽變更 [#controls-and-events]

在控制元件所在的工作表上，使用 `getSlicer(viewId)` / `getSlicers()` 和 `getTimeline(viewId)` / `getTimelines()` 查詢控制元件。`viewId` 是控制元件 `getId()` 返回的業務 ID，不是繪圖 ID。

透過 `univerAPI.addEvent()` 監聽 `SlicerAdded`、`SlicerChanged`、`SlicerRemoved`、`TimelineAdded`、`TimelineChanged` 和 `TimelineRemoved`。事件只表示本地改動已提交，不表示改動已儲存到遠端，也不表示渲染已完成。不再需要時，請呼叫返回的訂閱物件上的 `dispose()`。

API 參考：

- [FSheetSlicer](/reference/facade/sheet-slicer)
- [FSheetSlicerBuilder](/reference/facade/sheet-slicer-builder)
- [FSheetTimeline](/reference/facade/sheet-timeline)
- [FSheetTimelineBuilder](/reference/facade/sheet-timeline-builder)
- [FEventName](/reference/facade/events#univerjs-prosheets-slicer)

## 成員查詢與共用篩選 [#shared-filters]

`setSelection()` 需要傳入有型別的源值。數字 `1`、字串 `'1'` 和空白是三個不同的成員，因此不要傳入顯示標籤或可見列表中的下標。同一快取的所有檢視以及連線到該快取的報表共用這份篩選。使用表格資料來源時，篩選會替換該列的篩選條件，其他列保持不變。清除篩選請呼叫 `clearFilter()`。

```ts
import { FilterSelectionMode, RecordValueType } from '@univerjs/core'

const accepted = await slicer.setSelection({
  mode: FilterSelectionMode.Include,
  values: [{ type: RecordValueType.String, value: 'EMEA' }],
})
```

`getItems({ start, count })` 只讀取一個視窗，而不是整個資料來源，讀取操作也不會改變選擇。每次請求預設返回 100 項，上限由 `maxMemberWindowSize` 決定（預設值 200，必須是正整數）。視窗之外已經選中的成員會被保留。`setConnections()` 會替換透視報表連線；如需查詢可連線的報表，請使用 `getConnectionCandidates()`。參見 [FSheetSlicer](/reference/facade/sheet-slicer)。

## 時間軸日期條件 [#date-conditions]

`setSelection({ startDate, endDate, useWholeDay: true })` 會將帶小數的邊界擴充套件到整日，而整數形式的結束值仍然不包含在區間內。不設定 `useWholeDay` 時，區間精確為 `[startDate, endDate)`。從資料透視表共享下來的固定日期條件可能不連續，此時應透過 `getDateCondition()` 讀取。對於這類條件，`getSelection()` 返回 `undefined`，因此僅憑該返回值不能判斷時間線沒有篩選。
