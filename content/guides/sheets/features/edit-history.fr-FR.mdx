<Callout type="warning">
  Vous utilisez **0.25.x** ? Consultez la [documentation Pro archivée](https://dream-num.github.io/documentation/v0.25/zh-CN/guides/pro/). Les nouvelles intégrations utilisent le Collaboration SDK auto-hébergé ; les procédures et API de l’ancien Univer Server ne s’appliquent pas.
</Callout>

Suivez l’[intégration serveur](/guides/server-integration) pour exécuter l’exemple, connecter votre application et vérifier la persistance et les autorisations. Les détails et exemples Web/Server sont disponibles sur [Univer Office](https://office.univer.ai/collaboration/quick-start).

L’historique nécessite ses propres Service, Endpoint, Database Adapter et autorisations. Suivez les [modules d’extension](https://office.univer.ai/collaboration/extensions) et l’[exemple History](https://office.univer.ai/collaboration/examples#history). Vérifiez la conservation après redémarrage et les droits de lecture.
