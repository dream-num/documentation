<Callout type="warning">
  Используете **0.25.x**? Откройте [архив документации Pro](https://dream-num.github.io/documentation/v0.25/zh-CN/guides/pro/). Для новых интеграций используется самостоятельно размещаемый Collaboration SDK; инструкции и API прежнего Univer Server не применяются.
</Callout>

Следуйте руководству по [интеграции сервера](/guides/server-integration): запустите пример, подключите приложение и проверьте хранение данных и права доступа. Реализация и примеры Web/Server находятся в [Univer Office](https://office.univer.ai/collaboration/quick-start).

Истории нужны отдельные Service, Endpoint, Database Adapter и правила доступа. Следуйте [руководству по расширениям](https://office.univer.ai/collaboration/extensions) и [примеру History](https://office.univer.ai/collaboration/examples#history). Проверьте сохранность после перезапуска и права на чтение.
