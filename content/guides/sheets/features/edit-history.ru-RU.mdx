<Callout type="warning" title="Внимание">
  Для работы истории изменений требуется сервер Univer. Убедитесь, что сервер Univer правильно установлен и настроен. Подробности см. в разделе [Переход на Pro](/guides/pro).
</Callout>

История изменений позволяет просматривать и восстанавливать предыдущие версии документов. Различные способы фильтрации и поиска помогают эффективно управлять содержимым документов.

<Callout type="warning" title="Внимание">
  Функция истории изменений создаёт отдельный экземпляр Univer для загрузки и отображения предыдущих версий. Если вам нужно управлять этим экземпляром или настраивать его, например изменять заголовки запросов к API или регистрировать плагины, см. раздел [Получение экземпляра Univer для истории изменений](#get-edit-history-univer-instance).
</Callout>

## Режим предустановок

### Установка

<Callout>
  Во время выполнения предустановка `UniverSheetsAdvancedPreset` из `@univerjs/preset-sheets-advanced` зависит от предустановки `UniverSheetsDrawingPreset`. Сначала установите `@univerjs/preset-sheets-drawing`.
</Callout>

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced @univerjs/preset-sheets-collaboration
```

### Использование

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
import UniverPresetSheetsAdvancedEnUS from '@univerjs/preset-sheets-advanced/locales/en-US' // [!code ++]
import { UniverSheetsCollaborationPreset } from '@univerjs/preset-sheets-collaboration' // [!code ++]
import UniverPresetSheetsCollaborationEnUS from '@univerjs/preset-sheets-collaboration/locales/en-US' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]
import UniverPresetSheetsDrawingEnUS from '@univerjs/preset-sheets-drawing/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-advanced/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-collaboration/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsDrawingEnUS, // [!code ++]
      UniverPresetSheetsAdvancedEnUS, // [!code ++]
      UniverPresetSheetsCollaborationEnUS, // [!code ++]
    ),
  },
  collaboration: true, // [!code ++]
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsDrawingPreset({ // [!code ++]
      collaboration: true,
    }), // [!code ++]
    UniverSheetsAdvancedPreset({ // [!code ++]
      // configuration for advanced features
    }), // [!code ++]
    UniverSheetsCollaborationPreset({ // [!code ++]
      universerEndpoint: 'http://localhost:3010', // [!code ++]
    }), // [!code ++]
  ],
})
```

Если у вас есть коммерческая лицензия Univer, инструкции по настройке см. в разделе [Использование лицензии в клиенте](/guides/pro/license#in-preset-mode).

### Предустановки и конфигурация

Параметры конфигурации `UniverSheetsCollaborationPreset`:

```typescript
interface IUniverSheetsCollaborationPresetConfig {
  // The endpoint of the Univer Server
  universerEndpoint?: string
  /**
   * If the data calculation in the history requires the use of Worker (such as formulas), you can configure this field.
   * 1. If historyWorkerURL is provided and historyWorkerURL is a Worker instance, it will be destroyed when the history is closed, so a new Worker instance needs to be provided each time the history is opened.
   * ```typescript
   * import { EDIT_HISTORY_LOADER_PLUGIN_CONFIG_KEY, ToggleEditHistoryOperation } from '@univerjs/preset-sheets-collaboration';
   *
   * univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
   *   if (event.id === ToggleEditHistoryOperation.id) {
   *     const workerURL = new Worker(new URL('./worker.ts', import.meta.url));
   *     const configService = univer.__getInjector().get(IConfigService);
   *     configService.setConfig(EDIT_HISTORY_LOADER_PLUGIN_CONFIG_KEY, {
   *       workerURL,
   *     });
   *   }
   * });
   * 2.If the provided historyWorkerURL is not a Worker instance, no additional processing is required.
   * ```
   */
  historyWorkerURL?: string | URL | Worker
}
```

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/edit-history-viewer @univerjs-pro/edit-history-loader
```

### Использование

```typescript
import { UniverEditHistoryLoaderPlugin } from '@univerjs-pro/edit-history-loader' // [!code ++]
import EditHistoryViewerEnUS from '@univerjs-pro/edit-history-viewer/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/edit-history-viewer/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      EditHistoryViewerEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverEditHistoryLoaderPlugin, { // [!code ++]
  univerContainerId: 'your-univer-container-id', // [!code ++]
}) // [!code ++]
```

Если у вас есть коммерческая лицензия Univer, инструкции по настройке см. в разделе [Использование лицензии в клиенте](/guides/pro/license#in-plugin-mode).

### Плагины и конфигурация

Параметры конфигурации `UniverEditHistoryLoaderPlugin`:

```typescript
interface IUniverEditHistoryLoaderConfig {
  univerContainerId?: string
  // The server url of the history list
  historyListServerUrl?: string
  /**
   * If the data calculation in the history requires the use of Worker (such as formulas), you can configure this field.
   * 1. If workerURL is provided and workerURL is a Worker instance, it will be destroyed when the history is closed, so a new Worker instance needs to be provided each time the history is opened.
   * ```typescript
   * import { EDIT_HISTORY_LOADER_PLUGIN_CONFIG_KEY, ToggleEditHistoryOperation } from '@univerjs-pro/edit-history-loader';
   *
   * univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
   *   if (event.id === ToggleEditHistoryOperation.id) {
   *     const workerURL = new Worker(new URL('./worker.ts', import.meta.url));
   *     const configService = univer.__getInjector().get(IConfigService);
   *     configService.setConfig(EDIT_HISTORY_LOADER_PLUGIN_CONFIG_KEY, {
   *       workerURL,
   *     });
   *   }
   * });
   * 2.If the provided workerURL is not a Worker instance, no additional processing is required.
   * ```
   */
  workerURL?: string | URL | Worker
}
```

При включении истории изменений `UniverEditHistoryLoaderPlugin` загружает новый экземпляр Univer и монтирует его в указанный DOM-узел. Поэтому при регистрации необходимо передать идентификатор подходящего DOM-узла, например контейнера исходного экземпляра Univer, чтобы панель истории перекрывала исходную панель Univer. Если идентификатор узла не указан, используется значение `univer-container`.

Адрес сервера для списка версий можно изменить с помощью параметра конфигурации `historyListServerUrl`. По умолчанию используется `/universer-api/history`.

## Получение экземпляра Univer для истории изменений [#get-edit-history-univer-instance]

<Callout title="Полезно знать">
  Экземпляр Univer для истории изменений создаётся только при первом открытии панели истории.
</Callout>

Если вам нужно управлять экземпляром Univer для истории изменений или настраивать его, например изменять заголовки запросов к API или регистрировать плагины, экземпляр можно получить через `HistoryLoaderService`.

<Tabs items={['Режим предустановок', 'Режим плагинов']}>
  <Tab>
    ```typescript
    import { HistoryLoaderService } from '@univerjs/preset-sheets-collaboration'

    const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
      if (stage === univerAPI.Enum.LifecycleStages.Steady) {
        const injector = univer.__getInjector()
        const historyLoaderService = injector.get(HistoryLoaderService)

        historyLoaderService.historyUniver$.subscribe((historyUniver) => {
          // 在这里可以使用 historyUniver 实例进行操作
        })
      }
    })

    // Remove the event listener using `disposable.dispose()`
    ```
  </Tab>
  <Tab>
    ```typescript
    import { HistoryLoaderService } from '@univerjs-pro/edit-history-loader'

    const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
      if (stage === univerAPI.Enum.LifecycleStages.Steady) {
        const injector = univer.__getInjector()
        const historyLoaderService = injector.get(HistoryLoaderService)

        historyLoaderService.historyUniver$.subscribe((historyUniver) => {
          if (!historyUniver) return

          // You can perform operations on the historyUniver instance here
        })
      }
    })

    // Remove the event listener using `disposable.dispose()`
    ```
  </Tab>
</Tabs>

### Адаптация сторонних плагинов

По умолчанию экземпляр Univer для истории изменений загружает только официальные плагины. Чтобы сторонние функциональные плагины, разработанные для бизнес-задач, правильно отображались в истории, их необходимо зарегистрировать в `HistoryLoaderService`.

```typescript
const injector = univer.__getInjector()
const historyLoaderService = injector.get(HistoryLoaderService)

// [!code focus:4]
// The registration method is the same as that of PluginService. The Univer instance for edit history will register the corresponding plugins according to the following configuration after creation.
historyLoaderService.registerPlugin(YourPlugin, YourPluginConfig)
// Configure the officially registered plugin, set the true parameter to indicate that the original configuration should be overridden
historyLoaderService.registerPlugin(ExamplePlugin, ExamplePluginConfig, true)
```
