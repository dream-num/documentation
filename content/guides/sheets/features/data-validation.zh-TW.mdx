資料驗證為單元格設定規則，用來檢查輸入內容是否符合要求。它能及早發現輸入錯誤，使表格資料保持準確和一致。

目前支援以下驗證型別：
- 數字
- 整數
- 文字長度
- 日期
- 核取方塊
- 下拉選單（單選/多選）
- 自訂公式

## 外掛模式

### 安裝

```package-install
npm install @univerjs/data-validation @univerjs/sheets-data-validation @univerjs/sheets-data-validation-ui
```

### 使用

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDataValidationPlugin } from '@univerjs/data-validation' // [!code ++]
import { UniverSheetsDataValidationPlugin } from '@univerjs/sheets-data-validation' // [!code ++]

import '@univerjs/sheets-data-validation-ui/lib/index.css' // [!code ++]

import '@univerjs/sheets-data-validation/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
```

## 值匹配 [#value-matching]

列表驗證不區分大小寫：輸入 `green` 可以通過選項 `Green` 的檢查，由範圍引用得到的列表也遵循相同規則。數字和整數規則只接受數字文字，布林值和空白文字都不符合條件。

### 新增一個資料驗證規則

[`univerAPI.newDataValidation()`](https://docs.univer.ai/reference/facade/univer#newdatavalidation) 建立一個建置器，返回 `FDataValidationBuilder` 例項。透過鏈式呼叫其方法可構造規則。

[`FDataValidationBuilder`](/reference/facade/data-validation-builder) 的主要方法如下：

| 方法 | 描述 |
| ---- | ---- |
| build | 建置規則 |
| requireCheckbox | 要求輸入布林值，在單元格中顯示為核取方塊 |
| requireDateAfter | 把型別設為 DATE，要求日期在指定日期之後 |
| requireDateBefore | 把型別設為 DATE，要求日期在指定日期之前 |
| requireDateBetween | 把型別設為 DATE，要求日期在指定日期範圍內 |
| requireDateEqualTo | 把型別設為 DATE，要求日期等於指定日期 |
| requireDateNotBetween | 把型別設為 DATE，要求日期不在指定日期範圍內 |
| requireDateOnOrAfter | 把型別設為 DATE，要求日期在指定日期當天或之後 |
| requireDateOnOrBefore | 把型別設為 DATE，要求日期在指定日期當天或之前 |
| requireFormulaSatisfied | 要求給定公式的計算結果為 `true` |
| requireNumberBetween | 要求數字在給定的兩個數之間（含兩端） |
| requireNumberEqualTo | 要求數字等於給定值 |
| requireNumberGreaterThan | 要求數字大於給定值 |
| requireNumberGreaterThanOrEqualTo | 要求數字大於或等於給定值 |
| requireNumberLessThan | 要求數字小於給定值 |
| requireNumberLessThanOrEqualTo | 要求數字小於或等於給定值 |
| requireNumberNotBetween | 要求數字不在給定的兩個數之間，也不等於其中任何一個 |
| requireNumberNotEqualTo | 要求數字不等於給定值 |
| requireValueInList | 要求使用者從指定的值列表中選擇，支援單選/多選，可顯示或隱藏下拉框 |
| requireValueInRange | 要求使用者輸入指定範圍內的值，支援單選/多選，可顯示或隱藏下拉框 |
| setOptions | 設定規則選項 |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 建立一個新的資料驗證規則，要求 A1:B10 範圍內的數字在 1 到 10 之間
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: 'Please enter a number between 1 and 10',
  })
  .build()
fRange.setDataValidation(rule)
```

### 獲取 Range/Worksheet 的資料驗證規則

返回的規則物件是 `FDataValidation` 例項，可用於讀取規則的條件、選項和其他設定。

[`FDataValidation`](https://docs.univer.ai/reference/facade/data-validation) 的主要方法如下：

| 方法 | 描述 |
| ---- | ---- |
| copy | 用當前規則物件建立一個新的 FDataValidationBuilder 例項 |
| getCriteriaType | 取得規則的驗證型別 |
| getCriteriaValues | 取得參與條件判斷的值 |
| getHelpText | 取得幫助文字，用來給使用者提示 |
| getRanges | 取得規則應用的範圍 |
| setCriteria | 設定規則的條件 |
| setOptions | 設定規則的選項 |
| setRanges | 設定規則應用的範圍 |
| delete | 從工作表中刪除規則 |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 獲取當前工作表的所有資料驗證規則
const rulesOfSheet = fWorksheet.getDataValidations()

// 透過規則 ID 獲取資料驗證規則
const ruleById = fWorksheet.getDataValidation(rulesOfSheet[0]?.rule?.uid)

const fRange = fWorksheet.getRange('A1:B10')

// 獲取當前範圍的第一個資料驗證規則
const ruleOfRange = fRange.getDataValidation()
ruleOfRange?.getCriteriaValues()

// 獲取當前範圍的所有資料驗證規則
const rulesOfRange = fRange.getDataValidations()
```

### 更新/刪除資料驗證

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 建立一個新的資料驗證規則，要求 A1:B10 範圍內的數字等於 20
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberEqualTo(20)
  .build()
fRange.setDataValidation(rule)

const newRuleRange = fWorksheet.getRange('C1:D10')

// 3 秒後更新規則
setTimeout(() => {
  fRange.getDataValidation()
    // 更改新的範圍 C1:D10
    .setRanges([newRuleRange])
    // 更改新的條件，要求數字在 1 到 10 之間
    .setCriteria(
      univerAPI.Enum.DataValidationType.DECIMAL,
      [univerAPI.Enum.DataValidationOperator.BETWEEN, '1', '10'],
    )
    // 更改驗證選項，當輸入不符合條件時停止輸入並顯示錯誤訊息
    .setOptions({
      allowBlank: true,
      showErrorMessage: true,
      error: 'Please enter a valid value',
      errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
    })
}, 3000)

// 6 秒後刪除該規則
setTimeout(() => {
  newRuleRange.getDataValidation().delete()
}, 6000)
```

### 獲取驗證錯誤

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 獲取當前工作簿的所有資料驗證錯誤
const workbookErrors = await fWorkbook.getAllDataValidationErrorAsync()
console.log('workbookErrors:', workbookErrors)

// 獲取當前工作表的所有資料驗證錯誤
const worksheetErrors = await fWorksheet.getAllDataValidationErrorAsync()
console.log('worksheetErrors:', worksheetErrors)

// 獲取當前範圍的資料驗證錯誤
const fRange = fWorksheet.getRange('A1:B10')
const rangeErrors = await fRange.getDataValidationErrorAsync()
console.log('rangeErrors:', rangeErrors)
```

每個錯誤物件包含以下欄位：
- `sheetName`：發生錯誤的工作表名稱
- `row`：觸發錯誤的儲存格列索引
- `column`：觸發錯誤的儲存格欄索引
- `ruleId`：觸發錯誤的規則 ID
- `inputValue`：觸發錯誤的輸入值
- `rule`：規則內容快照

### 查詢校驗狀態

校驗狀態為 `DataValidationStatus` 列舉的取值：
- `valid`：儲存格值通過驗證
- `invalid`：儲存格值未通過驗證
- `validating`：單元格正在校驗

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 獲取當前工作簿的資料驗證校驗狀態
fWorkbook.getValidatorStatus().then((status) => {
})

// 獲取當前工作表的資料驗證校驗狀態
fWorksheet.getValidatorStatusAsync().then((status) => {
})

// 獲取當前範圍的資料驗證校驗狀態
const fRange = fWorksheet.getRange('A1:B10')
fRange.getValidatorStatus().then((status) => {
})
```

### 事件監聽

事件型別的完整定義見 [Events](https://docs.univer.ai/reference/facade/events)。

規則被新增、更新或刪除，以及校驗狀態發生變化時，資料驗證模組都會發出事件。這些事件均可透過 `univerAPI.addEvent()` 監聽。

#### 驗證規則變更事件

`univerAPI.Event.SheetDataValidationChanged` 在規則變更後觸發。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidationChanged, (params) => {
  const { origin, worksheet, workbook, changeType, oldRule, rule } = params
})

// 移除事件監聽器，使用 `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationAdd` 在新增規則前觸發。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationAdd, (params) => {
  const { worksheet, workbook, rule } = params

  // 取消新增驗證規則操作
  params.cancel = true
})

// 移除事件監聽器，使用 `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationDelete` 在刪除規則前觸發。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDelete, (params) => {
  const { worksheet, workbook, ruleId, rule } = params

  // 取消刪除驗證規則操作
  params.cancel = true
})

// 移除事件監聽器，使用 `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationDeleteAll` 在刪除所有規則前觸發。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDeleteAll, (params) => {
  const { worksheet, workbook, rules } = params

  // 取消刪除所有驗證規則操作
  params.cancel = true
})

// 移除事件監聽器，使用 `disposable.dispose()`
```

#### 驗證規則更新事件

`univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate` 在更新規則條件前觸發。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newCriteria } = params

  // 取消更新驗證規則條件操作

```

`univerAPI.Event.BeforeSheetDataValidationRangeUpdate` 在更新規則範圍前觸發。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationRangeUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newRanges } = params

  // 取消更新驗證規則範圍操作
  params.cancel = true
})

// 移除事件監聽器，使用 `disposable.dispose()`
```

`univerAPI.Event.BeforeSheetDataValidationOptionsUpdate` 在更新規則選項前觸發。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationOptionsUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newOptions } = params

  // 取消更新驗證規則選項操作
  params.cancel = true
})

// 移除事件監聽器，使用 `disposable.dispose()`
```

#### 驗證狀態事件

`univerAPI.Event.SheetDataValidatorStatusChanged` 在單元格校驗狀態變化時觸發。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidatorStatusChanged, (params) => {
  const { worksheet, workbook, row, column, status, rule } = params
})

// 移除事件監聽器，使用 `disposable.dispose()`
```

每個事件都包含以下通用參數：
- `workbook`：當前工作簿例項
- `worksheet`：當前工作表例項

部分事件還包含以下參數：
- `rule`：相關的驗證規則物件
- `ruleId`：規則的唯一標識
- `status`：校驗狀態（僅在 `SheetDataValidatorStatusChanged` 事件中）
- `newCriteria`：新的驗證條件（僅在 `BeforeSheetDataValidationCriteriaUpdate` 事件中）
- `newRanges`：新的驗證範圍（僅在 `BeforeSheetDataValidationRangeUpdate` 事件中）
- `newOptions`：新的驗證選項（僅在 `BeforeSheetDataValidationOptionsUpdate` 事件中）

對於名稱以 `Before` 開頭的事件，在回撥中設定 `params.cancel = true` 即可阻止對應操作。

### 錯誤樣式

`errorStyle` 控制輸入無效資料時的處理方式，可設為 `DataValidationErrorStyle` 列舉值：
- `STOP`：拒絕該輸入
- `WARNING`：允許輸入，但顯示警告
- `INFO`：允許輸入，但顯示提示資訊

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B10')

const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: '請輸入 1 到 10 之間的數字',
    errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
  })
  .build()
fRange.setDataValidation(rule)
```

### 變更列表型驗證的渲染模式

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B10')

fRange.getDataValidation()?.setOptions({
  // support TEXT, ARROW, CUSTOM
  // default is `CUSTOM`
  renderMode: univerAPI.Enum.DataValidationRenderMode.TEXT,
})
```
