이 페이지의 API는 변환 백엔드가 필요합니다. [파일 교환 통합](/server/import-export)를 먼저 구성하여 업로드, 변환, 작업 쿼리 및 다운로드 작업을 완료하고 브라우저 플러그인을 구성합니다. Snapshot API는 동일한 백엔드를 필요로하지만 협업 문서가 필요하지 않습니다.

내보내기 실패는 [라이선스 오류 코드와 작업 실패 처리](/server/import-export#export-errors)를 참고하세요.

## 지원 형식

이 페이지의 브라우저 API에 의해 지원되는 형식 목록. 사무실 파일 변환은 추가적으로 동일한 문서 유형과 형식을 지원하는 백엔드를 요구합니다.

| 가져오기 | 내보내기 |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV 및 TSV는 워크북 형식 또는 다른 워크 시트없이 단일 워크 시트를 내보내. `ExchangeFormat.CSV` 또는 `ExchangeFormat.TSV`를 내보내기 `sheetId`와 함께 내보내기 API; XLSX는 기본입니다. 브라우저 API는 변환 백엔드가 지원할 때 `.xlsm`을 허용하지 않습니다.

## Facade API [#facade-api]

### 가져오기

<Callout type="info" title="플러그인 모드 참고">
  플러그인 모드는 수동으로 Facade 패키지를 가져올 필요가 있습니다. 미리 설정 모드는 이미 일치하는 패키지를 포함합니다.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/sheets-exchange-client/facade'
```

### `.xlsx` 가져오기

#### `.xlsx` 파일을 가져와 `unitId` 얻기

<Callout type="warning" title="주 메뉴">
  이 방법은 협업을 필요로 합니다: 서버에서 문서를 작성하고 `unitId`를 반환합니다. 협업이 활성화되지 않은 경우, 대신 스냅 샷 가져 오기를 사용하십시오.
</Callout>

협업 편집이 활성화되면, 모든 문서에는 고유 한 `unitId`가 있습니다. `file`를 `univerAPI.importSheetToUnitIdAsync`로 전달하고, 이 방법은 `unitId`이 문서를 열 수 있도록 사용됩니다. `file`는 `File` 개체 또는 원격 파일 URL이 될 수 있습니다.

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importSheetToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadSheetAsync(unitId)
}
```

#### `.xlsx` 파일을 가져와 `IWorkbookData` 얻기

<Callout>
  스냅샷 가져오기는 공동 작업 기능이 필요하지 않습니다. 공동 작업 문서에는 `unitId` 가져오기를 사용하세요.
</Callout>

`univerAPI.importSheetToSnapshotAsync`는 `.xlsx` 파일을 가져 와서 `IWorkbookData`로 문서 데이터를 반환합니다.

```typescript
// Accept a File object
const snapshot = await univerAPI.importSheetToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importSheetToSnapshotAsync('https://example.com/filename.xlsx');

// Create a new workbook via snapshot
if (snapshot) univerAPI.createWorkbook(snapshot)
```

### `.xlsx` 내보내기

#### `unitId`를 사용하여 `.xlsx` 파일 내보내기

<Callout type="warning" title="주 메뉴">
  `unitId`에 의해 수출은 협력을 요구합니다. 협력이 활성화되지 않는 경우에, 사용 snapshot 수출.
</Callout>

협업 편집이 활성화되면 모든 문서에는 고유 한 `unitId`가 있습니다. `unitId`를 `univerAPI.exportSheetByUnitIdAsync`로 전달하고, 방법은 `File` 개체를 반환합니다.

`unitId`는 설정된 백엔드에 저장되어 있고 현재 세션에서 접근할 수 있는 문서의 ID여야 합니다. `createWorkbook(snapshot)`은 브라우저 로컬 통합 문서를 만들며, `getId()`를 호출해도 업로드되지 않습니다. 이 로컬 ID로 내보내면 `PERMISSION_DENIED`(`code=3`)가 반환될 수 있습니다. 로컬 통합 문서는 아래의 `exportSheetBySnapshotAsync(fWorkbook.save())`를 사용하세요.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook.getId()
const file = await univerAPI.exportSheetByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

#### `IWorkbookData`를 사용하여 `.xlsx` 파일 내보내기

<Callout>Snapshot 수출은 협업을 요구하지 않으며 로컬 워크플로우에 적합합니다.</Callout>

`IWorkbookData`를 `univerAPI.exportSheetBySnapshotAsync`로 전달하고, 방법은 `File` 객체를 반환합니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
const file = await univerAPI.exportSheetBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```
