A watermark is a text or image overlay drawn on top of a spreadsheet. The content, starting position, repeat spacing, rotation, and opacity are configurable.

<Callout type="info">
  The [Watermark Generator](/tools/watermark-generator) previews watermark styles and downloads the plugin configuration as JSON.
</Callout>

<PlaygroundFrame lang="en-US" slug="sheets/watermark" clickToShow />

## Plugin mode

### Installation

```package-install
npm install @univerjs/watermark
```

### Usage

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

## Preset mode

Watermark has no preset of its own, but the plugin still works alongside presets.

### Installation

```package-install
npm install @univerjs/watermark
```

### Usage

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## Facade API

### Importing

<Callout type="info" title="Plugin mode note">
  Only plugin mode requires manually importing the Facade package. Preset mode already includes the corresponding Facade package, so no additional import is required.
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### Set watermark

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### Remove watermark

```typescript
univerAPI.deleteWatermark()
```
