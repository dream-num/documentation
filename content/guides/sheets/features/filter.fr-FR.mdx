Un filtre cache les lignes qui ne correspondent pas aux critères spécifiés, de sorte que seules les données d'intérêt restent visibles. La fonction prend en charge une gamme de conditions et d'opérations de filtrage, et chaque colonne peut avoir ses propres critères.

## Mode plugin

### Installation

```package-install
npm install @univerjs/sheets-filter @univerjs/sheets-filter-ui
```

### Utilisation

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsFilterPlugin } from '@univerjs/sheets-filter' // [!code ++]
import { UniverSheetsFilterUIPlugin } from '@univerjs/sheets-filter-ui' // [!code ++]
import SheetsFilterUIEnUS from '@univerjs/sheets-filter-ui/locale/en-US' // [!code ++]
import '@univerjs/sheets-filter-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-filter/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsFilterUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsFilterPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsFilterUIPlugin) // [!code ++]
```

| <ConfigKey depth={1}>defaultValue</ConfigKey> | `boolean` |  | L'état initial de l'interrupteur lorsqu'il est affiché. |

### Obtenir le filtre

Renvoie un objet [`FFilter`](https://docs.univer.ai/reference/facade/filter) ou `null` si la feuille n'a pas de filtre.

- Sur un `FWorksheet`, appelez [`getFilter()`](https://docs.univer.ai/reference/facade/worksheet#getfilter)
- Sur un `FRange`, appelez [`getFilter()`](https://docs.univer.ai/reference/facade/range#getfilter)

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()

// Get filter from FWorksheet
const fWorksheet = fWorkbook.getActiveSheet()
const fFilter = fWorksheet.getFilter()
fFilter?.getRange().getA1Notation()

// Get filter from FRange
const fRange = fWorksheet.getRange('A1:D14')
const fFilter2 = fRange.getFilter()
fFilter2?.getRange().getA1Notation()
```

### Créer un filtre

Crée un objet [`FFilter`](https://docs.univer.ai/reference/facade/filter). Si la feuille comporte déjà un filtre, renvoie `null`.

- Sur un `FRange`, appelez [`createFilter()`](https://docs.univer.ai/reference/facade/range#createfilter)

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:D14')
let fFilter = fRange.createFilter()

// If the worksheet already has a filter, remove it and create a new filter.
if (!fFilter) {
  fWorksheet.getFilter().remove()
  fFilter = fRange.createFilter()
}
fFilter.getRange().getA1Notation()
```

### Supprimer le filtre

Appelez [`FFilter.remove()`](https://docs.univer.ai/reference/facade/filter#remove) pour supprimer le filtre de la feuille de travail.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
fWorksheet.getFilter()?.remove()
```

### Obtenir les critères de filtrage d’une colonne

[`FFilter.getColumnFilterCriteria(column)`](https://docs.univer.ai/reference/facade/filter#getcolumnfiltercriteria) retourne les critères de filtre définis sur une colonne.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set some values of the range C1:F10
const fRange = fWorksheet.getRange('C1:F10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// Create a filter on the range C1:F10
let fFilter = fRange.createFilter()

// If the filter already exists, remove it and create a new one
if (!fFilter) {
  fRange.getFilter().remove()
  fFilter = fRange.createFilter()
}

// Set the filter criteria of the column C, filter out the rows that are not 1, 5, 9
const column = fWorksheet.getRange('C:C').getColumn()
fFilter.setColumnFilterCriteria(column, {
  colId: 0,
  filters: {
    filters: ['1', '5', '9'],
  },
})

// Print the filter criteria of the column C and D
fFilter.getColumnFilterCriteria(column) // { colId: 0, filters: { filters: ['1', '5', '9'] } }
fFilter.getColumnFilterCriteria(column + 1) // undefined
```

### Supprimer les critères de filtrage d’une colonne

- [`FFilter.removeColumnFilterCriteria(column)`](https://docs.univer.ai/reference/facade/filter#removecolumnfiltercriteria) efface les critères sur une colonne.
- [`FFilter.removeFilterCriteria()`](https://docs.univer.ai/reference/facade/filter#removefiltercriteria) efface les critères de chaque colonne.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Set some values of the range C1:F10
const fRange = fWorksheet.getRange('C1:F10')
fRange.setValues([
  [1, 2, 3, 4],
  [2, 3, 4, 5],
  [3, 4, 5, 6],
  [4, 5, 6, 7],
  [5, 6, 7, 8],
  [6, 7, 8, 9],
  [7, 8, 9, 10],
  [8, 9, 10, 11],
  [9, 10, 11, 12],
  [10, 11, 12, 13],
])

// Create a filter on the range C1:F10
let fFilter = fRange.createFilter()

// If the filter already exists, remove it and create a new one
if (!fFilter) {
  fRange.getFilter().remove()
  fFilter = fRange.createFilter()
}

// Set the filter criteria of the column C, filter out the rows that are not 1, 5, 9
const column = fWorksheet.getRange('C:C').getColumn()
fFilter.setColumnFilterCriteria(column, {
  colId: 0,
  filters: {
    filters: ['1', '5', '9'],
  },
})

// Clear the filter criteria of the column C after 3 seconds
setTimeout(() => {
  fFilter.removeColumnFilterCriteria(column)
  // Or use fFilter.removeFilterCriteria() to remove all column filter criteria
}, 3000)
```

### Obtenir les lignes exclues par le filtre

[`FFilter.getFilteredOutRows()`](https://docs.univer.ai/reference/facade/filter#getfilteredoutrows) retourne un tableau des index de lignes qui sont filtrés.

```typescript
  [10, 11, 12, 13],

// Create a filter on the range C1:F10

// If the filter already exists, remove it and create a new one
if (!fFilter) {
  fRange.getFilter().remove()
  fFilter = fRange.createFilter()

```

### Écouteurs d’événements

Les définitions complètes du type d'événement sont dans le [Événements](https://docs.univer.ai/reference/facade/events).

`SheetRangeFiltered` s'allume lorsque les critères de filtre d'une colonne changent.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetRangeFiltered, (params) => {
  const { workbook, worksheet, col, criteria } = params
})

// Remove the event listener, use `disposable.dispose()`
```

`SheetBeforeRangeFilter` allume avant que cette modification ne soit appliquée.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetBeforeRangeFilter, (params) => {
  const { workbook, worksheet, col, criteria } = params

  // Cancel the filter criteria change operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```

`SheetRangeFilterCleared` fait feu lorsque les critères sont remplis.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetRangeFilterCleared, (params) => {
  const { workbook, worksheet } = params
})

// Remove the event listener, use `disposable.dispose()`
```

Les feux `SheetBeforeRangeFilterClear` avant l'élimination des critères.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetBeforeRangeFilterClear, (params) => {
  const { workbook, worksheet } = params

  // Cancel the filter clear operation
  params.cancel = true
})

// Remove the event listener, use `disposable.dispose()`
```
