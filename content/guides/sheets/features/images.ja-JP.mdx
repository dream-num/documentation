画像は、説明するよりも簡単に説明する情報を伝えることができます。 Univerは、グリッドの上に配置されているフローティング画像、およびセル画像の2つのイメージタイプをサポートしています。これは単一セルにバインドされます。

## プラグインモード

### インストール

```package-install
npm install @univerjs/docs-drawing @univerjs/drawing @univerjs/drawing-ui @univerjs/sheets-drawing @univerjs/sheets-drawing-ui
```

### 使い方

```typescript
import { IImageIoService, LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsDrawingPlugin } from '@univerjs/docs-drawing' // [!code ++]
import { UniverDrawingPlugin } from '@univerjs/drawing' // [!code ++]
import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui' // [!code ++]
import DrawingUIJaJP from '@univerjs/drawing-ui/locale/ja-JP' // [!code ++]
import { UniverSheetsDrawingPlugin } from '@univerjs/sheets-drawing' // [!code ++]
import { UniverSheetsDrawingUIPlugin } from '@univerjs/sheets-drawing-ui' // [!code ++]
import SheetsDrawingUIJaJP from '@univerjs/sheets-drawing-ui/locale/ja-JP' // [!code ++]
import '@univerjs/drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-drawing/facade' // [!code ++]
import '@univerjs/sheets-drawing-ui/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DrawingUIJaJP, // [!code ++]
      SheetsDrawingUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverDrawingUIPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsDrawingUIPlugin) // [!code ++]
```

[コラボレーション](/guides/docs/features/collaboration) を使用する場合は、`override`の設定を追加します。

```typescript
univer.registerPlugin(UniverDrawingPlugin, {
  override: [[IImageIoService, null]], // [!code ++]
  // allowImageSize: 20 * 1024 * 1024, // アップロード画像の最大許容サイズを 20MB に設定します（任意）
})
```

### Floating DOM の追加

`FWorksheet.addFloatDomToPosition(layer)`は、指定された位置で浮動小数点の DOM 要素を追加します。

```tsx
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()

// コンポーネントは適切なタイミングで登録してください（例: Univer が読み込まれたとき）
// これは React コンポーネントです。Vue3 コンポーネントの場合、3 番目の引数は `{ framework: 'vue3' }` にしてください
univerAPI.registerComponent(
  'myFloatDom',
  ({ data }) => (
    <div style={{ width: '100%', height: '100%', background: '#fff', border: '1px solid #ccc', boxSizing: 'border-box' }}>
      ポップアップ内容:
      {' '}
      {data?.label}
    </div>
  ),
)

// 浮動 DOM を追加します
// disposable が null の場合、浮動 DOM の追加に失敗しています
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'myFloatDom',
  initPosition: {
    startX: 100,
    endX: 300,
    startY: 100,
    endY: 200,
  },

  // コンポーネントのデータ
  data: {
    label: 'hahah',
  },
})

// 2 秒後に浮動 DOM を削除します
setTimeout(() => {
  disposable?.dispose()
}, 2000)
```

### 浮動画像の挿入

[`FWorksheet.newOverGridImage()`](https://docs.univer.ai/reference/facade/worksheet#newovergridimage)は、浮動小数点の画像のビルダー、`FOverGridImageBuilder`のインスタンスを返します。 チェッターをチェーンすると、シートに差し込むことができる`ISheetImage`オブジェクトが生成されます。

ビルダー、[`FOverGridImageBuilder`](/reference/facade/over-grid-image-builder)は、次のメソッドを提供します。

| メソッド | 説明 |
| ------ | ----------- |
| buildAsync | 画像をビルドし、`ISheetImage`オブジェクトを返す |
| setSource | 画像ソースを設定する |
| setColumn | 画像の水平位置を設定する |
| setRow | 画像の縦位置を設定する |
| setColumnOffset | 画像の水平オフセットを設定する |
| setRowOffset | 画像の垂直オフセットを設定する |
| setWidth | 画像幅の設定 |
| setHeight | 画像の高さを設定する |
| setAnchorType | アンカータイプを設定します。これは、位置とサイズがセルと変化するかどうかを判断します。 |
| setCropTop | 画像の目的の部分だけが示されるように、作物の領域のトップ エッジを設定します |
| setCropLeft | 画像の目的の部分だけが示されるように、作物の領域の左端を設定します |
| setCropBottom | 画像の目的の部分だけが示されるように、作物の領域の一番下端を設定します |
| setCropRight | 画像の目的の部分だけが示されるように、作物の領域の右側の端を置きます |
| setRotate | 画像の回転角度を設定します |

```typescript
// 新しい画像ビルダーを作成し、画像ソースを設定します。
// その後 `ISheetImage` をビルドしてシートに挿入します。配置は F6 セルから開始、幅 500px、高さ 300px です
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])
```

`FWorksheet.insertImage(url, column, row, offsetX, offsetY)`方式でイメージを差し込むこともできます。

```typescript
// 画像をシートに挿入します。配置は F6、オフセットは 10px です
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const result = await fWorksheet.insertImage('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', 5, 5, 10, 10)
```

### 浮動画像の取得

`FWorksheet.getImages()` は、ワークシート内のすべてのフローティング画像を [`FOverGridImage[]`](https://docs.univer.ai/reference/facade/chart) インスタンスの配列として返します。

```typescript
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()
const images = fWorksheet.getImages()
images.forEach((image) => {
  image.getId()
})
```

IDで浮動画像を取得するには、`FWorksheet.getImageById(id)`メソッドを使用します。

### 浮動画像の更新

`FWorksheet.updateImages(sheetImages)`は、位置、サイズ、およびその他のプロパティで画像のフローティングを更新します。

```typescript
// 新しい画像ビルダーを作成し、画像ソースを設定します。
// その後 `ISheetImage` をビルドしてシートに挿入します。配置は F6 セルから開始、幅 500px、高さ 300px です
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const image = await fWorksheet.newOverGridImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4', univerAPI.Enum.ImageSourceType.URL)
  .setColumn(5)
  .setRow(5)
  .setWidth(500)
  .setHeight(300)
  .buildAsync()
fWorksheet.insertImages([image])

// 4 秒後に画像の幅を 100px、高さを 50px に更新します
setTimeout(async () => {
  const imageBuilder = fWorksheet.getImageById(image.drawingId).toBuilder()
  const newImage = await imageBuilder.setWidth(100).setHeight(50).buildAsync()
  fWorksheet.updateImages([newImage])
}, 4000)
```

### 浮動画像の削除

`FWorksheet.deleteImages(sheetImages)` はフローティング画像を削除します。

```typescript
const fWorksheet = univerAPI.getActiveWorkbook().getActiveSheet()

// シートの最初の画像を削除します

```

## ワークシートの背景画像 [#worksheet-background]

ワークシートは、セルの後ろに描画された1つのタイルの背景画像を持つこともできます。 画像は`IWorksheetData.backgroundImage`に保存され、フローティングとセルイメージの独立しています。 描画プリセットには、この機能が含まれています。 プラグインモードでは、必要なパッケージは`@univerjs/sheets-drawing`、そのファサードエントリ、レンダリングおよびアップロード制御を提供する描画UIです。

```ts
import '@univerjs/sheets-drawing/facade'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')

sheet.setBackgroundImage('https://example.com/background.png')
console.log(sheet.getBackgroundImage())
sheet.deleteBackgroundImage()
```

`setBackgroundImage()`はデフォルトで`ImageSourceType.URL`を使用し、任意の既存の背景を置き換えます。 `deleteBackgroundImage()`が削除します。 どちらの操作もコマンドとして実装されているため、undoとredoが適用されます。 アップロードされた画像は、設定されたイメージI/Oサービスを介してUIによって解決されます。 背景は画面にのみ表示され、印刷から除外されます。

## 画像の不透明度 [#image-opacity]

フローティング画像は、画像全体に単一の不透明値を使用します。 `setOpacity()` は、`0` (transparent) から `1` (opaque); デフォルトは `1` であり、その他の値が `RangeError` を投げます。 ビルド前に `FOverGridImageBuilder` に設定するか、既にシートにある `FOverGridImage` で設定します。 どちらも `getOpacity()` を公開します。 画像プロパティパネルは、透明性コントロールも提供します。

```ts
const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
const image = sheet?.getImages()[0]
if (image) {
  image.setOpacity(0.5)
  console.log(image.getOpacity())
}
```

## 画像サイズとアンカー [#image-sizing-and-anchors]

組み込みファイルピッカーを介して入力された画像は、そのアスペクト比を維持し、それらが大きすぎると500ピクセル以内に収まるようにスケールダウンされています。小さな画像は拡大されません。その表示サイズは、アップロード時に`allowImageSize`バイトの制限に依存しています。画像がファサードを介してインサートされると、発信者は寸法を供給します。

アンカーは、セルが移動またはサイズを変更したときに何が起こるかを決定します。 `SheetDrawingAnchorType.Position`は、そのサイズを維持しながら、セルと画像を動かし、`Both`は固定された範囲でそれを移動し、サイズを変更し、`None`は固定位置とサイズを保持します。 列または列を非表示にするか、アンカー定義を保存します。 範囲にサイズされた画像は、その範囲で崩壊し、範囲が再び表示されたときに回復することができます。 一時的な非表示矢印ジオメトリは、保存されたアンカーの上に戻ってはいけません。
