<Callout type="warning" title="Attention">
  Les fonctionnalités d’importation et d’exportation nécessitent Univer Server. Assurez-vous d’avoir correctement
  installé et configuré Univer Server. Pour en savoir plus, consultez la page [Passer à la version Pro](/guides/pro).
</Callout>

Les fonctionnalités d’importation et d’exportation permettent aux utilisateurs d’importer des fichiers `.xlsx` dans des documents Univer ou d’exporter le contenu de documents au format `.xlsx` via Univer Server, afin de faciliter les échanges avec d’autres logiciels ou plateformes bureautiques.

<PlaygroundFrame lang="fr-FR" slug="sheets/univer-pro-import-export" clickToShow />

<Callout title="Pourquoi Univer SDK gère-t-il l’importation et l’exportation via des services backend ?">
  Une implémentation de l’importation et de l’exportation uniquement côté frontend ne peut pas répondre aux exigences
  des entreprises en matière de performances et de résultats. Nous fournissons donc des services backend pour assurer
  ces fonctionnalités. Vous pouvez utiliser des bibliothèques open source d’analyse DOCX afin de convertir les fichiers
  en structures de données conformes à l’interface `IDocumentData`, puis importer ces données dans Univer avec l’API
  Facade.
</Callout>

Une fois l’importation effectuée depuis le menu, une notification apparaît dans l’angle inférieur gauche de la page. Elle confirme la réussite de l’opération et fournit un lien vers le document importé. Si le comportement par défaut de l’importation et de l’exportation ne répond pas à vos besoins, consultez la page [Personnaliser l’importation de documents](/blog/custom-import) pour apprendre à le personnaliser.

## Choisir une méthode d’importation ou d’exportation

Deux méthodes sont disponibles selon que la collaboration est requise ou non :

| Méthode        | Collaboration requise | Cas d’usage                                                          | API                                                         |
| -------------- | --------------------- | -------------------------------------------------------------------- | ----------------------------------------------------------- |
| Par `unitId`   | Oui                   | Documents collaboratifs conservés sur le serveur                     | `importSheetToUnitIdAsync` / `exportSheetByUnitIdAsync`     |
| Par instantané | Non                   | Flux de travail locaux ou hors ligne, ou simple conversion de format | `importSheetToSnapshotAsync` / `exportSheetBySnapshotAsync` |

Si votre projet utilise la collaboration, avec des documents conservés sur le serveur et ouverts via leur `unitId`, choisissez la méthode par `unitId`. Sinon, utilisez la méthode par instantané.

## Mode prédéfini

### Installation

<Callout>
  Le preset `UniverSheetsAdvancedPreset` du package `@univerjs/preset-sheets-advanced` dépend du preset
  `UniverSheetsDrawingPreset` à l’exécution. Installez d’abord `@univerjs/preset-sheets-drawing`.
</Callout>

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

### Utilisation

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
import UniverPresetSheetsAdvancedEnUS from '@univerjs/preset-sheets-advanced/locales/en-US' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]
import UniverPresetSheetsDrawingEnUS from '@univerjs/preset-sheets-drawing/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-advanced/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsDrawingEnUS, // [!code ++]

  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsDrawingPreset(), // [!code ++]
    UniverSheetsAdvancedPreset({
      // [!code ++]
      universerEndpoint: 'http://localhost:3010', // [!code ++]

  ],

```

### Presets et configuration

Les options de configuration de `UniverSheetsAdvancedPreset` sont les suivantes :

```typescript
interface IUniverSheetsAdvancedPresetConfig {
  // This is the endpoint for the Univer server
  universerEndpoint?: string
  exchangeClientOptions?: {
    // The minimum number of rows in the imported worksheet
    minSheetRowCount?: number
    // The minimum number of columns in the imported worksheet
    minSheetColumnCount?: number
    /**
     * Export whether to enable server-side formula calculation. When enabled, each export will trigger server-side formula calculation, addressing the following issues:
     * 1. Formulas have no default values when opening files in office software like WPS
     * 2. Excel does not show formula results unless editing is enabled
     * 3. Array formulas with the @ prefix cannot expand calculation results
     * Note: This configuration needs to be used in a collaborative editing environment, and the server configuration file needs to set `SSC_SERVER_ENABLED=true`.
     */
    enableServerSideComputing?: boolean
    /**
     * Whether to disable converting cell images to link on export.
     * If the cell image source is a URL, the default behavior is to convert the url to the cell value on export.
     * Because the server will download all the resource files, when there are many images, it will consume a lot of resources and take a long time.
     * @default true
     */
    disableCellImageConversion?: boolean
    /**
     * Whether to ignore Table when exporting.
     * @default false
     */
    ignoreTableExport?: boolean
  }
}
```

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/sheets-exchange-client
```

```typescript
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client' // [!code ++]
import ExchangeClientEnUS from '@univerjs-pro/exchange-client/locale/en-US' // [!code ++]
import { UniverSheetsExchangeClientPlugin } from '@univerjs-pro/sheets-exchange-client' // [!code ++]
import SheetsExchangeClientEnUS from '@univerjs-pro/sheets-exchange-client/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/exchange-client/facade' // [!code ++]
import '@univerjs-pro/sheets-exchange-client/facade' // [!code ++]

import '@univerjs-pro/exchange-client/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      ExchangeClientEnUS, // [!code ++]
      SheetsExchangeClientEnUS, // [!code ++]
    ),
  },
})

const UNIVER_SERVER_ENDPOINT = `http://localhost:8000` // [!code ++]

univer.registerPlugin(UniverExchangeClientPlugin, {
  // [!code ++]
  uploadFileServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/stream/file/upload`, // [!code ++]
  importServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/exchange/{type}/import`, // [!code ++]
  exportServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/exchange/{type}/export`, // [!code ++]
  getTaskServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/exchange/task/{taskID}`, // [!code ++]
  signUrlServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/file/{fileID}/sign-url`, // [!code ++]
```

## API Facade [#facade-api]

### Importation

<Callout type="info" title="Remarque sur le mode plugin">
  L’importation manuelle du package Facade n’est nécessaire qu’en mode plugin. Le mode prédéfini inclut déjà le package
  Facade correspondant, aucune importation supplémentaire n’est donc requise.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/sheets-exchange-client/facade'
```

### Importation d’un fichier `.xlsx`

#### Importer un fichier `.xlsx` et obtenir son `unitId`

<Callout type="warning" title="Attention">
  Cette méthode nécessite la collaboration : elle crée un document sur le serveur et renvoie un `unitId`. Si la
  collaboration n’est pas activée, utilisez l’importation par instantané.
</Callout>

Lorsque l’édition collaborative est activée, chaque document possède un `unitId` unique. L’appel à `univerAPI.importSheetToUnitIdAsync` avec le paramètre `file` renvoie le `unitId` permettant d’accéder au document. Le paramètre `file` peut être un objet `File` ou l’URL d’un fichier distant.

```typescript
// Accept a File object
const unitId = await univerAPI.importSheetToUnitIdAsync(file)
// Or accept a remote file URL
// const unitId = await univerAPI.importSheetToUnitIdAsync('https://example.com/filename.xlsx');

// Using with collaborative editing to automatically load data https://docs.univer.ai/en-US/guides/docs/features/collaboration#loading-collaborative-documents
const url = new URL(window.location.href)
url.searchParams.set('unit', unitId)
url.searchParams.set('type', '2') // The meaning of 2 is UniverInstanceType.UNIVER_SHEET

window.location.href = url.toString()

// Or call the API: univerAPI.loadServerUnit(unitId, 2) to load the document, refer to /reference/facade/univer#loadserverunit for specific parameters
```

#### Importer un fichier `.xlsx` et obtenir un objet `IWorkbookData`

<Callout>
  L’importation par instantané ne nécessite pas la collaboration. Pour les documents collaboratifs, utilisez
  l’importation par `unitId`.
</Callout>

L’appel à `univerAPI.importSheetToSnapshotAsync` pour importer un fichier `.xlsx` renvoie les données du document au format `IWorkbookData`.

```typescript
// Accept a File object
const snapshot = await univerAPI.importSheetToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importSheetToSnapshotAsync('https://example.com/filename.xlsx');

// Create a new workbook via snapshot
univerAPI.createWorkbook(snapshot)
```

### Exportation d’un fichier `.xlsx`

#### Exporter un fichier `.xlsx` à l’aide de son `unitId`

<Callout type="warning" title="Attention">
  L’exportation par `unitId` nécessite la collaboration. Si la collaboration n’est pas activée, utilisez l’exportation
  par instantané.
</Callout>

Lorsque l’édition collaborative est activée, chaque document possède un `unitId` unique. L’appel à `univerAPI.exportSheetByUnitIdAsync` avec le paramètre `unitId` renvoie un objet `File`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook.getId()
const file = await univerAPI.exportSheetByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

#### Exporter un fichier `.xlsx` à l’aide d’un objet `IWorkbookData`

<Callout>
  L’exportation par instantané ne nécessite pas la collaboration et convient aux flux de travail locaux.
</Callout>

L’appel à `univerAPI.exportSheetBySnapshotAsync` avec les données `IWorkbookData` renvoie un objet `File`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.getSnapshot()
const file = await univerAPI.exportSheetBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

## Conversion des données sur le serveur Node.js [#server-side-data-conversion]

Univer Server fournit des API d’importation et d’exportation, mais le format des données converties sur le serveur ne correspond pas au format Univer. Après avoir initialisé Univer et enregistré `@univerjs-pro/exchange-client` dans le processus Node.js, utilisez l’API Facade pour transformer les données.

### Convertir un instantané en `IWorkbookData`

Après l’importation, les données JSON de l’instantané doivent être converties au format `IWorkbookData` pour pouvoir être utilisées dans Univer.

```typescript
// The json data contains snapshot and sheetBlocks
const workbookData = await univerAPI.transformSnapshotJsonToWorkbookDataAsync(json)
```

### Convertir un objet `IWorkbookData` en instantané JSON

Avant l’exportation, les données au format `IWorkbookData` doivent être converties en données JSON d’instantané, qui peuvent ensuite être envoyées au serveur pour l’exportation.

```typescript
const snapshotJson = await univerAPI.transformWorkbookDataToSnapshotJsonAsync(workbookData)
```
