Les API de cette page nécessitent un moteur de conversion. Configurez d'abord [intégration d'échange de fichiers](/server/import-export) afin que les téléchargements, conversions, requêtes de tâches et téléchargements fonctionnent, puis configurez les plugins du navigateur. Les API de snapshot nécessitent le même moteur, mais ne nécessitent pas de document collaboratif.

En cas d’échec d’export, consultez [les erreurs de licence et de tâche](/server/import-export#export-errors).

## Formats pris en charge

Le tableau énumère les formats pris en charge par les API du navigateur sur cette page. La conversion de fichier Office nécessite en outre un moteur qui prend en charge le même type de document et le même format.

| Importation | Exportation |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV et TSV exportent une feuille de travail unique, sans formatage du cahier de travail ou les autres feuilles de travail. Passez `ExchangeFormat.CSV` ou `ExchangeFormat.TSV` avec le `sheetId` à l'API d'exportation; XLSX est la valeur par défaut. L'API du navigateur n'accepte pas `.xlsm`, même lorsque le moteur de conversion le supporte.

## API Facade [#facade-api]

### Importation

<Callout type="info" title="Note du mode greffon">
  Seul le mode plugin nécessite l'importation du paquet Facade manuellement. Le mode Preset inclut déjà le paquet correspondant.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/sheets-exchange-client/facade'
```

### Importation d’un fichier `.xlsx`

#### Importer un fichier `.xlsx` et obtenir son `unitId`

<Callout type="warning" title="Attention">
  Cette méthode nécessite une collaboration : elle crée un document sur le serveur et renvoie un `unitId`. Si la collaboration n'est pas activée, utilisez plutôt l'import snapshot.
</Callout>

Lorsque l'édition collaborative est activée, chaque document a un `unitId` unique. Passez un `file` à `univerAPI.importSheetToUnitIdAsync`, et la méthode retourne que `unitId`, qui est utilisé pour ouvrir le document. `file` peut être un objet `File` ou une URL de fichier distant.

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importSheetToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadSheetAsync(unitId)
}
```

#### Importer un fichier `.xlsx` et obtenir un objet `IWorkbookData`

<Callout>
  L’importation par instantané ne nécessite pas la collaboration. Pour les documents collaboratifs, utilisez
  l’importation par `unitId`.
</Callout>

`univerAPI.importSheetToSnapshotAsync` importe un fichier `.xlsx` et retourne les données du document sous la forme de `IWorkbookData`.

```typescript
// Accept a File object
const snapshot = await univerAPI.importSheetToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importSheetToSnapshotAsync('https://example.com/filename.xlsx');

// Create a new workbook via snapshot
if (snapshot) univerAPI.createWorkbook(snapshot)
```

### Exportation d’un fichier `.xlsx`

#### Exporter un fichier `.xlsx` à l’aide de son `unitId`

<Callout type="warning" title="Attention">
  Exporter par `unitId` nécessite une collaboration. Si la collaboration n'est pas activée, utilisez l'export des instantanés.
</Callout>

Lorsque l'édition collaborative est activée, chaque document possède un `unitId` unique. Passez ce `unitId` à `univerAPI.exportSheetByUnitIdAsync` et la méthode renvoie un objet `File`.

Le `unitId` doit identifier un document enregistré dans le backend configuré et accessible à la session actuelle. `createWorkbook(snapshot)` crée un classeur local au navigateur ; `getId()` ne le téléverse pas. Exporter cet ID local peut renvoyer `PERMISSION_DENIED` (`code=3`). Pour un classeur local, utilisez `exportSheetBySnapshotAsync(fWorkbook.save())`, comme indiqué ci-dessous.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook.getId()
const file = await univerAPI.exportSheetByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

#### Exporter un fichier `.xlsx` à l’aide d’un objet `IWorkbookData`

<Callout>L'exportation de snapshots ne nécessite pas de collaboration et est adaptée aux flux de travail locaux seulement.</Callout>

Passez le `IWorkbookData` à `univerAPI.exportSheetBySnapshotAsync`, et la méthode renvoie un objet `File`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
const file = await univerAPI.exportSheetBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

## Suppression des menus et des interactions UI d’importation et d’exportation intégrés [#import-export-ui-migration]

<Callout type="warning" title="Remarque">
  Depuis la version **1.2.0**, Univer n'inclut plus les menus d'importation/exportation intégrés et les interactions UI. Les services sous-jacents et les API Facade restent disponibles.
</Callout>

Si l'application a encore besoin de ces menus et interactions, le [exemple de migration pour les menus d'importation/exportation intégrés et les interactions d'assurance-chômage](https://office.univer.ai/showcase/sheets/custom-import-export) montre comment les restaurer avec un plugin personnalisé. Le code source complet est disponible pour la lecture ou le téléchargement en ligne.
