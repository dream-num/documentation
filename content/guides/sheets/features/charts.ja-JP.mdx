チャートは、チャートモデルと UI パッケージを使ってワークシートのデータを可視化します。

<PlaygroundFrame lang="ja-JP" slug="sheets/charts" clickToShow />

## プリセットモード

チャート機能は `@univerjs/preset-sheets-advanced` に含まれ、実行時には描画プリセットが必要です。

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

## プラグインモード

```package-install
npm install @univerjs-pro/chart-ui @univerjs-pro/sheets-chart @univerjs-pro/sheets-chart-ui
```

```ts
import ChartUIJaJP from '@univerjs-pro/chart-ui/locale/ja-JP'
import { UniverSheetsChartPlugin } from '@univerjs-pro/sheets-chart'
import { UniverSheetsChartUIPlugin } from '@univerjs-pro/sheets-chart-ui'
import SheetsChartUIJaJP from '@univerjs-pro/sheets-chart-ui/locale/ja-JP'
import SheetsChartJaJP from '@univerjs-pro/sheets-chart/locale/ja-JP'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-chart/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/sheets-chart-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(ChartUIJaJP, SheetsChartJaJP, SheetsChartUIJaJP),
  },
})

univer.registerPlugin(UniverSheetsChartPlugin)
univer.registerPlugin(UniverSheetsChartUIPlugin)
```

## チャートを作成・更新する

チャートはワークシートの `charts` コレクションから操作します。`create()` は未挿入のビルダーを返し、`insert()` はそれをワークシートに挿入します。

```ts
const worksheet = univerAPI.getActiveWorkbook().getActiveSheet()

const builder = worksheet.charts.create()
  .setType(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D6',
    orientation: univerAPI.Enum.ChartSourceOrientation.Column,
  })
  .setTitle('四半期の売上')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)

const chart = await worksheet.charts.insert(builder)

chart
  .setType(univerAPI.Enum.ChartTypeString.Line)
  .setLegend({ visible: true })
  .setSeries({ index: 0 }, { color: '#2F80ED' })
  .commit()
```

既存のチャートは `worksheet.charts.list()`、`worksheet.charts.get(id)`、`await worksheet.charts.remove(chartOrId)` で管理します。`worksheet.charts.registerTheme(name, theme)` で Univer ランタイム全体で共有する ECharts テーマを登録できます。

## サポートされているチャート種類

`univerAPI.Enum.ChartTypeString` では、`Line`、`Column`、`ColumnStacked`、`ColumnPercentStacked`、`Bar`、`BarStacked`、`BarPercentStacked`、`Pie`、`Donut`、`Area`、`AreaStacked`、`AreaPercentStacked`、`Radar`、`Scatter`、`Combination`、`WordCloud`、`Funnel`、`Bubble`、`Relation`、`Waterfall`、`Pareto`、`Sankey`、`Heatmap`、`Boxplot`、`Candlestick`、`Histogram`、`Treemap`、`Sunburst`、`Gauge`、`Chord` を使用できます。

共通のビルダー設定は[チャート Facade リファレンス](/reference/facade/chart)を参照してください。
