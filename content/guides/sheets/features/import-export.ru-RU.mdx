## Поддерживаемые форматы

В таблице перечислены форматы, поддерживаемые API-интерфейсами браузера на этой странице.Конверсия файлов Office также требует бэкэнда, который поддерживает тот же тип и формат документа.

| Импорт | Экспорт |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV и TSV экспортируют единый рабочий лист, без форматирования рабочей книги или других рабочих листов. Передают `ExchangeFormat.CSV` или `ExchangeFormat.TSV` вместе с `sheetId` в экспортный API; XLSX — по умолчанию. API браузера не принимает `.xlsm`, даже когда его поддерживает бэкэнд конверсии.

## Facade API [#facade-api]

### Импорт

<Callout type="info" title="Заметка о режиме плагина">
  Только режим плагина требует импорта пакета Facade вручную. Предварительный режим уже включает в себя соответствующий пакет.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/sheets-exchange-client/facade'
```

### Импорт `.xlsx`

#### Импорт файла `.xlsx` с получением `unitId`

<Callout type="warning" title="Осторожно">
  Этот метод требует совместной работы: он создает документ на сервере и возвращает `unitId`. Если совместная работа не включена, вместо этого используйте импорт снимков.
</Callout>

При включенном совместном редактировании каждый документ имеет уникальный `unitId`. Передайте `file` в `univerAPI.importSheetToUnitIdAsync`, и метод возвращает, что `unitId` , который используется для открытия документа. `file` может быть объектом `File` или удаленным URL-адресом файла.

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importSheetToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadSheetAsync(unitId)
}
```

#### Импорт файла `.xlsx` с получением `IWorkbookData`

<Callout>
  Для импорта по снимку совместная работа не требуется. Для документов с совместным доступом используйте импорт по
  `unitId`.
</Callout>

`univerAPI.importSheetToSnapshotAsync` импортирует файл `.xlsx` и возвращает данные документа как `IWorkbookData`.

```typescript
// Accept a File object
const snapshot = await univerAPI.importSheetToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importSheetToSnapshotAsync('https://example.com/filename.xlsx');

// Create a new workbook via snapshot
if (snapshot) univerAPI.createWorkbook(snapshot)
```

### Экспорт `.xlsx`

#### Экспорт файла `.xlsx` по `unitId`

<Callout type="warning" title="Осторожно">
  Экспорт `unitId` требует сотрудничества. Если сотрудничество не включено, используйте моментальный экспорт.
</Callout>

При включенном совместном редактировании каждый документ имеет уникальный `unitId`. Передайте `unitId` в `univerAPI.exportSheetByUnitIdAsync`, и метод возвращает объект `File` .

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const unitId = fWorkbook.getId()
const file = await univerAPI.exportSheetByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

#### Экспорт файла `.xlsx` из `IWorkbookData`

<Callout>Экспорт снимков не требует сотрудничества и подходит только для локальных рабочих процессов.</Callout>

Передайте `IWorkbookData` в `univerAPI.exportSheetBySnapshotAsync`, и способ возвращает объект `File`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const snapshot = fWorkbook.save()
const file = await univerAPI.exportSheetBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'xlsx')
```

## Удаление встроенных меню и UI-взаимодействий для импорта и экспорта [#import-export-ui-migration]

<Callout type="warning" title="Замечание">
  По состоянию на версию **1.2.0**, Univer больше не включает встроенные меню импорта/экспорта и взаимодействия пользовательского интерфейса.Основные сервисы и API-интерфейсы Facade остаются доступными.
</Callout>

Если приложению все еще нужны эти меню и взаимодействия, [Пример миграции для встроенных меню импорта / экспорта и взаимодействия пользовательского интерфейса](https://office.univer.ai/showcase/sheets/custom-import-export) показывает, как их восстановить с помощью пользовательского плагина.Полный исходный код доступен для онлайн-чтения или загрузки.
