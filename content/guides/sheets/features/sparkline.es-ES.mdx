Una chispa es un pequeño gráfico colocado dentro de una sola célula. Muestra una tendencia o una métrica clave a un vistazo.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/sheets-sparkline @univerjs-pro/sheets-sparkline-ui
```

### Uso

```typescript
import { UniverSheetSparklinePlugin } from '@univerjs-pro/sheets-sparkline' // [!code ++]
import { UniverSheetSparklineUIPlugin } from '@univerjs-pro/sheets-sparkline-ui' // [!code ++]
import SheetsSparklineUIEnUS from '@univerjs-pro/sheets-sparkline-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-sparkline/facade' // [!code ++]

import '@univerjs-pro/sheets-sparkline-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsSparklineUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetSparklinePlugin)
univer.registerPlugin(UniverSheetSparklineUIPlugin)
```

Si su licencia Univer es comercial, consulte [Utilizando Licencia en Cliente](/server/license#in-plugin-mode) para la configuración.

<Callout>

## API de Facade

### Importación

<Callout type="info" title="Nota del modo Plugin">
  Sólo el modo plugin requiere importar manualmente el paquete Facade. El modo Preset ya incluye el paquete Facha correspondiente, por lo que no se requiere ninguna importación adicional.
</Callout>

```typescript
import '@univerjs-pro/sheets-sparkline/facade'
```

### Agregar minigráfico

[`FWorksheet.addSparkline`](https://docs.univer.ai/reference/facade/worksheet#addsparkline) añade una chispa en el rango dado y devuelve una instancia `FSparkline`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a sparkline with data source from A1:A7, placed in cell A10.
const sourceRanges = [fWorksheet.getRange('A1:A7').getRange()]
const targetRanges = [fWorksheet.getRange('A10').getRange()]
const sparkline = fWorksheet.addSparkline(sourceRanges, targetRanges, univerAPI.Enum.SparklineTypeEnum.LINE_CHART)
```

### Componer y descomponer minigráfico

Utilice [`FWorksheet.composeSparkline`](https://docs.univer.ai/reference/facade/worksheet#composesparkline) para fusionar chispas en un grupo, y [`FWorksheet.unComposeSparkline`](https://docs.univer.ai/reference/facade/worksheet#uncomposesparkline) dividir el grupo en chispas individuales.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a sparkline with data source from A1:A7, placed in cell A10.
const firstSparkline = fWorksheet.addSparkline(
  [fWorksheet.getRange('A1:A7').getRange()],
  [fWorksheet.getRange('A10').getRange()],
)

// Create a sparkline with data source from B1:B7, placed in cell B10.
const secondSparkline = fWorksheet.addSparkline(
  [fWorksheet.getRange('B1:B7').getRange()],
  [fWorksheet.getRange('B10').getRange()],
)

// Compose the two sparklines into a sparkline group
fWorksheet.composeSparkline([fWorksheet.getRange('A10:B10').getRange()])
console.log(fWorksheet.getAllSubSparkline().size) // 1

// After 3 seconds, uncompose the sparkline group
setTimeout(() => {
  fWorksheet.unComposeSparkline([fWorksheet.getRange('A10:B10').getRange()])
  console.log(fWorksheet.getAllSubSparkline().size) // 2
}, 3000)
```

### Obtener minigráfico y grupo de minigráficos. Instancias

[`FWorksheet.getSparklineByCell`](https://docs.univer.ai/reference/facade/worksheet#getsparklinebycell) devuelve la instancia `FSparkline` en una celda dada.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a sparkline with data source from A1:A7, placed in cell A10.
const sourceRanges = [fWorksheet.getRange('A1:A7').getRange()]
const targetRanges = [fWorksheet.getRange('A10').getRange()]
const sparkline = fWorksheet.addSparkline(sourceRanges, targetRanges)

console.log('Cell A10: ', fWorksheet.getSparklineByCell(9, 0))
console.log('Cell A11: ', fWorksheet.getSparklineByCell(10, 0))
```

[`FWorksheet.getSparklineGroupByCell`](https://docs.univer.ai/reference/facade/worksheet#getsparklinegroupbycell) devuelve la instancia `FSparklineGroup` en una celda dada.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a sparkline with data source from A1:A7, placed in cell A10.
const firstSparkline = fWorksheet.addSparkline(
  [fWorksheet.getRange('A1:A7').getRange()],
  [fWorksheet.getRange('A10').getRange()],
)

// Create a sparkline with data source from B1:B7, placed in cell B10.
const secondSparkline = fWorksheet.addSparkline(
  [fWorksheet.getRange('B1:B7').getRange()],
  [fWorksheet.getRange('B10').getRange()],
)
console.log('Cell A10: ', fWorksheet.getSparklineGroupByCell(9, 0))

// After 3 seconds, compose the two sparklines into a sparkline group
setTimeout(() => {
  fWorksheet.composeSparkline([fWorksheet.getRange('A10:B10').getRange()])
  console.log('Cell A10: ', fWorksheet.getSparklineGroupByCell(9, 0))
}, 3000)
```

Una instancia [`FSparkline`](https://docs.univer.ai/reference/facade/sparkline) proporciona estos métodos:

| Method | Description |
| --- | --- |
| cambioDataSource | Cambiar la fuente de datos y la colocación de la chispa en la celda actual |
| removeSparkline | Remove the sparkline in the current cell |

Una instancia [`FSparklineGroup`](/reference/facade/sparkline-group) proporciona estos métodos:

| Method | Description |
| --- | --- |
| cambioDataSource | Cambiar la fuente de datos y la colocación del grupo chispa en la celda actual |
| removeSparklineGroup | Retire el grupo de chispa en la celda actual |
| setConfig | Change the configuration of the sparkline group in the current cell |

### Evento Oyentes

Consulta las definiciones completas de tipos de eventos en [Events](https://docs.univer.ai/reference/facade/events).

`univerAPI.Event.SheetSparklineChanged` dispara cuando cambia una chispa.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetSparklineChanged, (params) => {
  const { workbook, worksheet, sparklines } = params
})

// Remove the event listener, use `disposable.dispose()`
```

## Colores y opciones de visualización

Los colores y las opciones de visualización de todo un grupo se establecen a través de `FSparklineGroup.setConfig()`. Para utilizar un color personalizado, se establece tanto `seriesColor` como `themeType: SparklineThemeTypeEnum.CUSTOM` . La página [configuración del grupo chispa](/reference/facade/sparkline-group) contiene la tabla de opciones completas y un ejemplo, marcadores de puntos de cobertura, ejes, extremas, valores vacíos, células ocultas y ancho de línea.
