Une barre de temps filtre les champs de date d'origine d'un Pivot qui peut servir de source. Les colonnes de table, les champs de texte, les champs calculés et les champs de regroupement dérivés ne peuvent pas être des sources de temps.

## Mode plugin [#plugin-mode]

### Installation

```package-install
npm install @univerjs-pro/sheets-slicer @univerjs-pro/sheets-slicer-ui
```

### Utilisation

Ajoutez ce qui suit à votre [Configuration des feuilles](/guides/sheets/getting-started/installation) existant, avec [appui au dessin](/guides/sheets/features/images) et une source [Tableau](/guides/sheets/features/table) ou [Table pivotante](/guides/sheets/features/pivot-table) déjà configurée. Chargez la locale et enregistrez ces plugins avant de créer le cahier de travail.

```ts
import { UniverSheetsSlicerPlugin } from '@univerjs-pro/sheets-slicer'
import { UniverSheetsSlicerUIPlugin } from '@univerjs-pro/sheets-slicer-ui'
import SheetsSlicerUILocale from '@univerjs-pro/sheets-slicer-ui/locale/fr-FR'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/sheets-slicer/facade'
import '@univerjs-pro/sheets-slicer-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.FR_FR, SheetsSlicerUILocale)
univer.registerPlugin(UniverSheetsSlicerPlugin)
univer.registerPlugin(UniverSheetsSlicerUIPlugin)
```

## Mode prédéfini [#preset-mode]

### Installation

```package-install
npm install @univerjs/presets @univerjs/preset-sheets-core @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

### Utilisation

Le preset avancé comprend le modèle de trancheur et de timeline et les plugins UI, ainsi que leurs API Facade. Combinez-le avec le noyau et dessinez les presets et fusionnez les paquets locaux. Si le preset avancés est déjà en cours d'utilisation, ajoutez `slicer` à cet enregistrement plutôt que de l'enregistrer une deuxième fois. Configurez la licence client comme décrit dans [utilisant une licence](/server/license).

```ts
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'
import AdvancedLocale from '@univerjs/preset-sheets-advanced/locales/fr-FR'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import CoreLocale from '@univerjs/preset-sheets-core/locales/fr-FR'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing'
import DrawingLocale from '@univerjs/preset-sheets-drawing/locales/fr-FR'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css'
import '@univerjs/preset-sheets-advanced/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.FR_FR,
  locales: {
    [LocaleType.FR_FR]: mergeLocales(CoreLocale, DrawingLocale, AdvancedLocale),
  },
  presets: [
    UniverSheetsCorePreset({ container: 'app' }),
    UniverSheetsDrawingPreset(),
    UniverSheetsAdvancedPreset({ slicer: { maxMemberWindowSize: 200 } }),
  ],
})
```

Lorsque vous utilisez un [Travailleur](/guides/sheets/getting-started/worker), définissez `useWorker: true` sur le préréglage avancé et enregistrez `UniverSheetsAdvancedWorkerPreset()` dans le Worker. Ce préréglage inclut également le plugin de calcul de trancheur.

## Créer un segment [#create-slicer]

L'exemple ci-dessous utilise une table pivotée à I1 sur la feuille active et un champ source nommé `Region`. Appelez `getSourceFieldsInfo()` pour obtenir l'ID d'origine stable du champ. Les noms d'affichage et les identifiants de champ de rapport ne peuvent pas être passés à `newSlicer()` .

```ts
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook?.getActiveSheet()
if (!fWorkbook || !fWorksheet) throw new Error('No active worksheet')

const pivotTable = fWorkbook.getPivotTableByCell(
  fWorkbook.getId(),
  fWorksheet.getSheetId(),
  0,
  8,
)
const regionField = pivotTable?.getSourceFieldsInfo().find((field) => field.name === 'Region')
if (!pivotTable || !regionField) throw new Error('Region source field not found')

const slicer = await fWorksheet.insertSlicer(
  pivotTable.newSlicer(regionField.id)
    .setCaption(regionField.name)
    .setPosition('N2')
    .build(),
)
```

`pivotTable.newSlicer()` lie le constructeur à cette source. `build()` assemble uniquement la configuration; `insertSlicer()` crée la commande. La feuille hôte et la feuille source peuvent différer, mais les deux doivent être dans le même cahier de travail. Pour une source Table, appelez `fWorksheet.newSlicer(columnId).setTableReference({ subUnitId, tableId })`, où `columnId` est l'ID stable de la colonne Table.

## Créer une chronologie [#create-timeline]

Cet exemple utilise le même PivotTable et nécessite un champ de date d'origine nommé `Date`. `newTimeline()` valide la source et rejette les champs non pris en charge. Les API de la plage de temps prennent des valeurs série Excel dans le système de date du cahier de travail, et non des objets JavaScript `Date` .

```ts
const dateField = pivotTable.getSourceFieldsInfo().find((field) => field.name === 'Date')
if (!dateField) throw new Error('Date source field not found')

const timeline = await fWorksheet.insertTimeline(
  pivotTable.newTimeline(dateField.id)
    .setCaption(dateField.name)
    .setLevel(univerAPI.Enum.TimelineLevel.Month)
    .setPosition('N18')
    .build(),
)
```

## Retrouver les contrôles et observer les changements [#controls-and-events]

Sur la feuille de travail de l'hôte, `getSlicer(viewId)` / `getSlicers()` et `getTimeline(viewId)`/`getTimelines()` localisent les commandes. `viewId` est l'ID d'affaires que le contrôle retourne `getId()`, et non son identifiant de dessin.

Inscrivez `SlicerAdded`, `SlicerChanged`, `SlicerRemoved`, `TimelineAdded`, `TimelineChanged` et `TimelineRemoved` à `univerAPI.addEvent()`. Un événement indique qu'un changement local a été commis. Il n'indique pas que le changement a été enregistré à distance ou que le rendu a terminé.

- [FSheetTimelineBuilder](/reference/facade/sheet-timeline-builder)

## Requêtes de membres et filtres partagés [#shared-filters]

`setSelection()` attend des valeurs de source dactylographiées. Le nombre `1`, la chaîne de caractères `'1'` et un blanc sont trois membres différents, de sorte que ne pas passer les étiquettes d'affichage ou les index de la liste visible. Chaque vue du même cache, et chaque rapport connecté à celui-ci, partage le filtre. Avec une source Table, la sélection remplace le filtre de cette colonne et laisse les autres colonnes inchangées. Appelez `clearFilter()` pour effacer le filtre.

```ts
import { FilterSelectionMode, RecordValueType } from '@univerjs/core'

const accepted = await slicer.setSelection({
  mode: FilterSelectionMode.Include,
  values: [{ type: RecordValueType.String, value: 'EMEA' }],
})
```

`getItems({ start, count })` lit une fenêtre d'éléments plutôt que la source entière, et la lecture ne change pas la sélection. Une requête par défaut à 100 éléments et est plafonnée par `maxMemberWindowSize` (par défaut 200, un entier positif). Les sélections qui tombent à l'extérieur de la fenêtre visible sont conservées. `setConnections()` remplace les connexions du rapport Pivot; utiliser `getConnectionCandidates()` pour découvrir les rapports qui peuvent se connecter. L'édition nécessite les autorisations de la feuille de travail pertinente. Voir [Slicateur de feuille F](/reference/facade/sheet-slicer).

## Conditions de date de la chronologie [#date-conditions]

`setSelection({ startDate, endDate, useWholeDay: true })` élargit les limites fractionnelles à des jours entiers, tandis qu'une extrémité entière reste exclusive. Sans `useWholeDay`, l'intervalle est exactement `[startDate, endDate)`. Une condition de date fixe partagée à partir d'une table pivot peut être non contiguë; `getDateCondition()` la lit dans ce cas. Pour une telle condition, `getSelection()` retourne `undefined` de sorte que le résultat seul n'indique pas que la ligne de temps est non filtrée.
