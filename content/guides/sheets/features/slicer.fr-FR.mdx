Les segments filtrent les tableaux, tableaux croisés dynamiques et graphiques croisés dynamiques selon les membres de la source. Les chronologies filtrent les champs de date d’origine compatibles des rapports croisés ; elles ne prennent pas en charge les colonnes de tableaux, les champs texte, les champs calculés ni les champs de regroupement dérivés.

## Créer un segment [#create-slicer]

Cet exemple utilise un tableau croisé dynamique en I1 de la feuille active, avec un champ source nommé `Region`. Obtenez son ID d’origine stable avec `getSourceFieldsInfo()` ; les noms affichés et les ID de champs du rapport ne conviennent pas à `newSlicer()`.

```ts
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook?.getActiveSheet()
if (!fWorkbook || !fWorksheet) throw new Error('No active worksheet')

const pivotTable = fWorkbook.getPivotTableByCell(
  fWorkbook.getId(),
  fWorksheet.getSheetId(),
  0,
  8,
)
const regionField = pivotTable?.getSourceFieldsInfo().find((field) => field.name === 'Region')
if (!pivotTable || !regionField) throw new Error('Region source field not found')

const slicer = await fWorksheet.insertSlicer(
  pivotTable.newSlicer(regionField.id)
    .setCaption(regionField.name)
    .setPosition('N2')
    .build(),
)
```

`pivotTable.newSlicer()` lie le constructeur à sa source. `build()` prépare uniquement la configuration ; `insertSlicer()` crée le contrôle. La feuille hôte peut différer de la feuille source, mais elles doivent appartenir au même classeur. Pour une source de tableau, utilisez `fWorksheet.newSlicer(columnId).setTableReference({ subUnitId, tableId })`, où `columnId` est l’ID stable de la colonne du tableau.

## Créer une chronologie [#create-timeline]

L’exemple suivant utilise le même tableau croisé dynamique et nécessite un champ de date d’origine nommé `Date`. `newTimeline()` valide la source et refuse les champs non pris en charge. Les API de plages de chronologie utilisent les numéros de série Excel du système de dates du classeur, pas des objets JavaScript `Date`.

```ts
const dateField = pivotTable.getSourceFieldsInfo().find((field) => field.name === 'Date')
if (!dateField) throw new Error('Date source field not found')

const timeline = await fWorksheet.insertTimeline(
  pivotTable.newTimeline(dateField.id)
    .setCaption(dateField.name)
    .setLevel(univerAPI.Enum.TimelineLevel.Month)
    .setPosition('N18')
    .build(),
)
```

## Retrouver les contrôles et observer les changements [#controls-and-events]

Appelez `getSlicer(viewId)` / `getSlicers()` et `getTimeline(viewId)` / `getTimelines()` sur la feuille hôte. `viewId` est l’ID métier renvoyé par `getId()` du contrôle, pas son ID de dessin.

Abonnez-vous à `SlicerAdded`, `SlicerChanged`, `SlicerRemoved`, `TimelineAdded`, `TimelineChanged` et `TimelineRemoved` via `univerAPI.addEvent()`. Ces événements décrivent des changements locaux validés, pas une sauvegarde distante ni la fin du rendu. Appelez `dispose()` sur l’abonnement lorsqu’il n’est plus nécessaire.

## Requêtes de membres et filtres partagés [#shared-filters]

Passez des valeurs sources typées à `setSelection()` : le nombre `1`, la chaîne `'1'` et une cellule vide sont distincts. N’utilisez ni libellés ni indices visibles. Le filtre est partagé par toutes les vues du même cache et les rapports connectés. Pour une Table, il remplace le filtre de cette colonne et conserve les autres. `clearFilter()` le supprime.

```ts
import { FilterSelectionMode, RecordValueType } from '@univerjs/core'

const accepted = await slicer.setSelection({
  mode: FilterSelectionMode.Include,
  values: [{ type: RecordValueType.String, value: 'EMEA' }],
})
```

`getItems({ start, count })` lit une fenêtre, sans modifier la sélection. La requête porte sur 100 membres par défaut, plafonnés par `maxMemberWindowSize` (entier positif, 200 par défaut). Conservez les sélections hors fenêtre. `setConnections()` remplace les connexions aux rapports croisés ; `getConnectionCandidates()` fournit les candidats compatibles. Les modifications nécessitent les permissions des feuilles concernées. Voir [FSheetSlicer](/reference/facade/sheet-slicer).
