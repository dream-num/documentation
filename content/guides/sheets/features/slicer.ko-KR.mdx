슬라이서 필터 테이블, PivotTables, 그리고 PivotCharts 소스의 회원. 타임 라인 필터 소스 역할을 할 수있는 피벗의 원래 날짜 필드. 테이블 열, 텍스트 필드, 계산 필드, 그리고 파생 된 그룹 필드는 타임 라인 소스가 될 수 없습니다.

데이터 원본을 선택한 다음 데이터 탭의 분석 그룹에서 슬라이서 또는 시간 표시 막대를 삽입합니다.

## 플러그인 모드 [#plugin-mode]

### 설치

```package-install
npm install @univerjs-pro/sheets-slicer @univerjs-pro/sheets-slicer-ui
```

### 사용법

기존 [시트 설정](/guides/sheets/getting-started/installation)에 다음을 추가하십시오. [그림 지원](/guides/sheets/features/images) 및 [(주)](/guides/sheets/features/table) 또는 [PivotTable의 특징](/guides/sheets/features/pivot-table) 소스가 이미 구성되었습니다. locale을로드하고 작업 책을 만들기 전에이 플러그인을 등록하십시오.

```ts
import { UniverSheetsSlicerPlugin } from '@univerjs-pro/sheets-slicer'
import { UniverSheetsSlicerUIPlugin } from '@univerjs-pro/sheets-slicer-ui'
import SheetsSlicerUILocale from '@univerjs-pro/sheets-slicer-ui/locale/ko-KR'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/sheets-slicer/facade'
import '@univerjs-pro/sheets-slicer-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.KO_KR, SheetsSlicerUILocale)
univer.registerPlugin(UniverSheetsSlicerPlugin)
univer.registerPlugin(UniverSheetsSlicerUIPlugin)
```

### 플러그인 설정 [#plugin-configuration]

`UniverSheetsSlicerPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `maxMemberWindowSize` | `number` | `200` | 한 번에 반환하는 최대 멤버 수입니다. |

## 프리셋 모드 [#preset-mode]

### 설치

```package-install
npm install @univerjs/presets @univerjs/preset-sheets-core @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

### 사용법

고급 프리셋에는 슬라이서와 타임라인 모델과 UI 플러그인이 포함되어 있으며, Facade API와 함께 제공됩니다. 코어와 그림 프리셋과 로컬 패키지를 결합합니다. 고급 프리셋이 이미 사용중인 경우 `slicer`를 등록하지 않고 두 번째 시간으로 등록하십시오. [사용방법](/server/license)에 설명된 클라이언트 라이센스를 구성하십시오.

```ts
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'
import AdvancedLocale from '@univerjs/preset-sheets-advanced/locales/ko-KR'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import CoreLocale from '@univerjs/preset-sheets-core/locales/ko-KR'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing'
import DrawingLocale from '@univerjs/preset-sheets-drawing/locales/ko-KR'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css'
import '@univerjs/preset-sheets-advanced/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.KO_KR,
  locales: {
    [LocaleType.KO_KR]: mergeLocales(CoreLocale, DrawingLocale, AdvancedLocale),
  },
  presets: [
    UniverSheetsCorePreset({ container: 'app' }),
    UniverSheetsDrawingPreset(),
    UniverSheetsAdvancedPreset({ slicer: { maxMemberWindowSize: 200 } }),
  ],
})
```

[회사 소개](/guides/sheets/getting-started/worker)를 사용할 때 고급 프리셋에 `useWorker: true`을 설정하고 Worker에서 `UniverSheetsAdvancedWorkerPreset()` 를 등록하십시오. 사전 설정은 슬라이서 계산 플러그인도 포함합니다.

### 프리셋 설정 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 편집기를 마운트할 DOM 요소 또는 요소 ID입니다. |

`UniverSheetsAdvancedPreset`

| --- | --- | --- | --- |
| <ConfigKey depth={0}>slicer</ConfigKey> | `object` |  |  |
| <ConfigKey depth={1}>maxMemberWindowSize</ConfigKey> | `number` | `200` | 한 번에 반환하는 최대 멤버 수입니다. |
| `useWorker` | `boolean` | `false` | Worker에서 고급 계산 플러그인을 활성화합니다. |

## 슬라이서 만들기 [#create-slicer]

아래 예제는 활성 시트에서 I1에서 PivotTable을 사용하고 `Region`라는 소스 필드를 사용합니다. 필드의 안정적인 원래 ID를 얻기 위해 `getSourceFieldsInfo()`를 호출하십시오. 디스플레이 이름과 보고서 필드 ID는 `newSlicer()`로 전달 될 수 없습니다.

```ts
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook?.getActiveSheet()
if (!fWorkbook || !fWorksheet) throw new Error('No active worksheet')

const pivotTable = fWorkbook.getPivotTableByCell(
  fWorkbook.getId(),
  fWorksheet.getSheetId(),
  0,
  8,
)
const regionField = pivotTable?.getSourceFieldsInfo().find((field) => field.name === 'Region')
if (!pivotTable || !regionField) throw new Error('Region source field not found')

const slicer = await fWorksheet.insertSlicer(
  pivotTable.newSlicer(regionField.id)
    .setCaption(regionField.name)
    .setPosition('N2')
    .build(),
)
```

`pivotTable.newSlicer()`는 그 근원에 건축업자를 묶습니다. `build()`만 구성을 조립합니다; `insertSlicer()`가 통제를 창조합니다. 주인 장 및 근원 장은 다를 수 있습니다, 그러나 둘 다 동일한 워크북에 있어야 합니다. 테이블 근원을 위해, `fWorksheet.newSlicer(columnId).setTableReference({ subUnitId, tableId })`를 부르십시오, `columnId`에는 테이블 란의 안정되어 있는 ID입니다.

## 타임라인 만들기 [#create-timeline]

이 예제는 동일한 PivotTable을 사용하고 `Date`라는 원래 날짜 필드를 요구합니다. `newTimeline()`는 소스를 검증하고 지원되지 않은 필드를 거부합니다. 타임 라인 범위 API는 워크북의 날짜 시스템에서 Excel 시리얼 값을 가져와 JavaScript `Date` 개체가 아닙니다.

```ts
const dateField = pivotTable.getSourceFieldsInfo().find((field) => field.name === 'Date')
if (!dateField) throw new Error('Date source field not found')

const timeline = await fWorksheet.insertTimeline(
  pivotTable.newTimeline(dateField.id)
    .setCaption(dateField.name)
    .setLevel(univerAPI.Enum.TimelineLevel.Month)
    .setPosition('N18')
    .build(),
)
```

## 컨트롤 조회 및 변경 감지 [#controls-and-events]

호스트 워크 시트에서 `getSlicer(viewId)` / `getSlicers()` 및 `getTimeline(viewId)`/`getTimelines()`는 컨트롤을 찾습니다. `viewId`은 제어의 `getId()`가 드로잉 ID가 아닌 비즈니스 ID입니다.

등록 `SlicerAdded`, `SlicerChanged`, `SlicerRemoved`, `TimelineAdded`, `TimelineChanged`, `TimelineRemoved`를 통해 `univerAPI.addEvent()`. 이벤트는 로컬 변경이 투입되었는지 나타냅니다. 변경이 원격으로 저장되었거나 렌더링이 완료되었는지 나타내지 않습니다. 더 이상 필요하지 않을 때 반환 구독을 처리하십시오.

## 멤버 조회와 공유 필터 [#shared-filters]

`setSelection()`는 유형 소스 값을 기대합니다. 번호 `1`, 문자열 `'1'` 및 공백은 3 개의 다른 멤버이므로 디스플레이 라벨 또는 인덱스를 표시하지 마십시오. 동일한 캐시의 모든 보기 및 필터를 공유합니다. 테이블 소스로 선택은 열의 필터를 교체하고 다른 열을 변경하지 않습니다. `clearFilter()`XZ를 클리어 필터로 호출하십시오.

```ts
import { FilterSelectionMode, RecordValueType } from '@univerjs/core'

const accepted = await slicer.setSelection({
  mode: FilterSelectionMode.Include,
  values: [{ type: RecordValueType.String, value: 'EMEA' }],
})
```

`getItems({ start, count })`은 전체 소스보다 오히려 항목의 창을 읽고, 독서는 선택을 변경하지 않습니다. 100 항목에 대한 요청 기본값은 `maxMemberWindowSize` (기본 200, 긍정적 인 정수)에 의해 캡핑됩니다. 눈에 보이는 창 밖에 떨어지는 선택은 유지됩니다. `setConnections()`는 피벗 보고서 연결을 대체합니다. `getConnectionCandidates()`을 사용하여 연결 할 수있는 보고서를 발견하십시오. [FSheetSlicer의 장점](/reference/facade/sheet-slicer)를 참조하십시오.

## 타임라인 날짜 조건 [#date-conditions]

`setSelection({ startDate, endDate, useWholeDay: true })`는 전일에 분수 경계를 확장하고, 정수 끝이 독점 남아있는 동안. `useWholeDay`없이, 간격은 정확히 `[startDate, endDate)`입니다. PivotTable에서 공유 된 고정 날짜 조건은 비 적합성 일 수 있습니다; `getDateCondition()`은 그 경우에 그것을 읽습니다. 그런 조건을 위해, `getSelection()`가 `undefined`를 반환하므로 그 결과 단독으로 시간을 나타내지 않습니다.
