실시간 공유 기능을 사용하면 여러 사용자가 공동 작업할 때 스크롤이나 선택 영역 변경 같은 화면 조작을 다른 참여자와 실시간으로 동기화하거나 다른 사용자의 화면을 따라갈 수 있습니다. 회의 발표나 수업 설명 같은 상황에서 매우 유용합니다.

## 플러그인 모드

### 설치

```package-install
npm install @univerjs-pro/live-share
```

### 사용법

```typescript
import { UniverLiveSharePlugin } from '@univerjs-pro/live-share' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/live-share/lib/index.css' // [!code ++]

import '@univerjs-pro/live-share/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverLiveSharePlugin)
```

Univer 상용 라이선스가 있다면 [클라이언트에서 라이선스 사용하기](/guides/pro/license#using-license-in-plugin-mode)를 참고하여 구성하세요.

## Facade API

실시간 공유 기능은 Facade API의 관련 인터페이스를 확장하며, `univerAPI`를 통해 직접 호출할 수 있습니다.

### 가져오기

<Callout type="info" title="Plugin mode note">
  플러그인 모드에서만 Facade 패키지를 직접 가져와야 합니다. 프리셋 모드에는 해당 Facade 패키지가 이미 포함되어 있으므로 별도로 가져올 필요가 없습니다.
</Callout>

```typescript
import '@univerjs-pro/live-share/facade'
```

### 상태 열거형

```typescript
export enum LiveShareStatus {
  IDLE = 'idle',
  FOLLOWING = 'following',
  PRESENTING = 'presenting',
}
```

### 사용 예시

```typescript
// Get current status
const status = univerAPI.getLiveShareStatus()

if (status === LiveShareStatus.IDLE) {
  // If currently idle, start presenting
  univerAPI.startPresenting()
} else if (status === LiveShareStatus.PRESENTING) {
  // If presenting, stop presenting
  univerAPI.stopPresenting()
}

// Start following
univerAPI.startFollowing()

// Stop following
univerAPI.stopFollowing()
```
