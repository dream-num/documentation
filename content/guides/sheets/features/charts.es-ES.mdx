Los gráficos hacen que los datos de hoja de trabajo como un gráfico. Los paquetes de modelo de gráfico y UI proporcionan la característica.

<PlaygroundFrame lang="es-ES" slug="sheets/charts" clickToShow />

## Modo de complemento

```package-install
npm install @univerjs-pro/chart-ui @univerjs-pro/sheets-chart @univerjs-pro/sheets-chart-ui
```

```ts
import ChartUIEsES from '@univerjs-pro/chart-ui/locale/es-ES'
import { UniverSheetsChartPlugin } from '@univerjs-pro/sheets-chart'
import { UniverSheetsChartUIPlugin } from '@univerjs-pro/sheets-chart-ui'
import SheetsChartUIEsES from '@univerjs-pro/sheets-chart-ui/locale/es-ES'
import SheetsChartEsES from '@univerjs-pro/sheets-chart/locale/es-ES'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/chart-ui/facade'
import '@univerjs-pro/sheets-chart/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/sheets-chart-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.ES_ES,
  locales: {
    [LocaleType.ES_ES]: mergeLocales(ChartUIEsES, SheetsChartEsES, SheetsChartUIEsES),
  },
})

univer.registerPlugin(UniverSheetsChartPlugin)
univer.registerPlugin(UniverSheetsChartUIPlugin)
```

## Modo preestablecido

`@univerjs/preset-sheets-advanced` ya incluye la función gráfica, pero requiere el preset de dibujo en el momento de ejecución.

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

```ts
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'
import UniverPresetSheetsAdvancedEsES from '@univerjs/preset-sheets-advanced/locales/es-ES'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEsES from '@univerjs/preset-sheets-core/locales/es-ES'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing'
import UniverPresetSheetsDrawingEsES from '@univerjs/preset-sheets-drawing/locales/es-ES'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-advanced/lib/index.css'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.ES_ES,
  locales: {
    [LocaleType.ES_ES]: mergeLocales(
      UniverPresetSheetsCoreEsES,
      UniverPresetSheetsDrawingEsES,
      UniverPresetSheetsAdvancedEsES,
    ),
  },
  presets: [UniverSheetsCorePreset(), UniverSheetsDrawingPreset(), UniverSheetsAdvancedPreset()],
})
```

## Crear y actualizar gráficos

`worksheet.newChart(type)` devuelve un constructor separado. Nada se añade a la hoja de trabajo hasta que se construya la información de la gráfica y se pasa a `worksheet.insertChart(info)`.

```ts
const workbook = univerAPI.getActiveWorkbook()
if (!workbook) throw new Error('No active workbook')

const worksheet = workbook.getActiveSheet()
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D6',
    orientation: univerAPI.Enum.ChartSourceOrientation.Columns,
  })
  .setPosition('F2')
  .setSize(640, 360)
  .setCategoryField(0)
  .setValueFields([1, 2, 3])
  .setTitle('Quarterly revenue')
  .build()

const chart = await worksheet.insertChart(info)
chart.setLegend({ visible: true }).bringToFront()

const updatedInfo = chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setSubtitle('FY 2026').build()
await chart.update(updatedInfo)

const svg = await chart.exportImage({ format: 'svg' })
```

Llamar a un sello en una `chart` insertada lo actualiza de inmediato. Utilice `toBuilder(type)` con `update(info)` para obtener una copia totalmente desprendida o para cambiar el tipo de gráfico. `exportImage()` devuelve `undefined` cuando ningún renderizador de interfaz puede producir una imagen.

`worksheet.getCharts()` y `worksheet.getChart(id)` vuelven gráficos en vivo. Llame a `await chart.remove()` para eliminar un gráfico. Regístrese los temas compartidos de ECharts con `univerAPI.registerTheme(name, theme)`.

## Hojas de gráfico [#chart-sheets]

`insertChartSheet()` da una tabla su propia ficha. El constructor de gráficos debe hacer referencia a una hoja de rejilla en el mismo libro de trabajo, y las células fuente permanecen en esa hoja.

```ts
import '@univerjs-pro/sheets-chart/facade'

const workbook = univerAPI.getActiveWorkbook()
const data = workbook?.getSheetByName('Data')
if (!workbook || !data) throw new Error('The Data sheet is required')

const info = data
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({ sheetId: data.getSheetId(), range: 'A1:B4' })
  .build()

const chartSheet = await workbook.insertChartSheet(info, { name: 'Sales' })
const primaryChart = chartSheet.getPrimaryChart()
```

`await chart.moveTo(targetSheet)` mueve un gráfico existente. Un gráfico se mueve en una hoja de gráficos se convierte en un gráfico adicional en esa hoja. Mover el gráfico primario de una hoja de mapa requiere una pestaña que no contiene nada más, y el movimiento elimina esa pestaña.

[`FWorkbook.insertChartSheet()`](/reference/facade/workbook#insertchartsheet) · [`FWorksheet.getPrimaryChart()`](/reference/facade/worksheet#getprimarychart)

## Barras de error [#error-bars]

`setErrorBars()` se puede llamar en un constructor o en un gráfico en vivo. La columna básica 2D, la barra, la línea y los gráficos de dispersión soportan barras de errores. `seriesIndex` es cero y cuenta el campo de categoría en los datos de origen. Las columnas y líneas utilizan `y`, las barras usan `x` y los diagramas de disperción pueden usar eje numérico.

```ts
chart.setErrorBars([
  { seriesIndex: 1, direction: 'y', type: 'both', valueType: 'percentage', value: 20 },
])
```

[`FChart.setErrorBars()`](/reference/facade/chart#seterrorbars)

## Ejes de categorías multinivel

Cuando las columnas de fuentes adyacentes forman una jerarquía, pasan sus índices de base cero a `setCategoryFields()` en orden raíz a hoja, y luego permiten el eje multinivel.

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D7',
    orientation: univerAPI.Enum.ChartSourceOrientation.Columns,
  })
  .setCategoryFields([0, 1])
  .setMultiLevelCategoryAxis(true)
  .setValueFields([2, 3])
  .setPosition('F2')
  .build()

const chart = await worksheet.insertChart(info)
chart.setCategoryFields([0, 1]).setMultiLevelCategoryAxis(true)
```

`clearCategoryFields()` elimina la asignación ordenada. `setMultiLevelCategoryAxis(false)` mantiene los campos seleccionados y deshabilita sólo la renderización jerárquica.

## Tipos de gráficos admitidos

`univerAPI.Enum.ChartTypeString` proporciona los siguientes tipos: `Line`, `LineStacked`, `LinePercentStacked`, `Column`, `ColumnStacked`, `ColumnPercentStacked`, `Bar`, `BarStacked`, `BarPercentStacked`, `Pie`, `Donut`, `Area`, `AreaStacked`, `AreaPercentStacked`, `Radar`, `Scatter`, `Combination`, `WordCloud`, `Funnel`, `Bubble`, `Relation`, `Waterfall`, `Pareto`, `Sankey`, `Heatmap`, `Boxplot`, `Candlestick`, `Histogram`, `Treemap`, `Sunburst`, `Gauge`, y `Chord`.

El [Chart Facade reference](/reference/facade/chart) documenta la configuración de constructor compartido API.

`LineStacked` y `LinePercentStacked` son tipos de gráficos 2D independientes. Antes de utilizarlos en un renderizador de servidor o en la conversión de archivo Office, verifique que el objetivo los soporta.

## Datos ocultos y categorías independientes [#source-mapping]

`setPlotVisibleOnly(false)` incluye valores de filas ocultas y columnas, y `getPlotVisibleOnly()` lee el ajuste actual. Para las fuentes con columnas de categoría separadas, `setSeriesToCategory()` mapas cada índice de campo de valor a sus índices de campo de categoría. Los índices se refieren a los vectores de origen físico, no a la serie que quedan después de filtrar. Las entradas que se dejan heredar las categorías compartidas y `{}` despeja los sobres.

Con las columnas A:D, por ejemplo, la serie de valores en D puede utilizar C como su categoría, mientras que B mantiene la categoría compartida en A.

```ts
const chart = worksheet.getCharts()[0]
if (!chart) throw new Error('No chart')
chart.setPlotVisibleOnly(false)
chart.setSeriesToCategory({ 3: [2] })
```

Para informes agregados, consulta los [gráficos dinámicos](/guides/sheets/features/pivot-chart).

## Gráficos 3D [#three-dimensional-charts]

Los gráficos 3D usan el mismo registro de plugins. Seleccione un tipo de gráfico 3D, y luego configure la vista en su constructor desprendido.

Los tipos de apoyo son `Line3D`, `Column3D`, `ColumnStacked3D`, `ColumnPercentStacked3D`, `Bar3D`, `BarStacked3D`, `BarPercentStacked3D`, `Pie3D`, `Area3D`, `AreaStacked3D` y `AreaPercentStacked3D`.

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column3D)
  .setSource('A1:C5')
  .setCategoryField(0)
  .setValueFields([1, 2])
  .setPosition('F18')
  .setSize(640, 360)
  .setThreeD({
    view: { rotX: 20, rotY: 30, rightAngleAxes: false, perspective: 30 },
    gapDepth: 120,
  })
  .build()

await worksheet.insertChart(info)
```

`perspective` se aplica a los gráficos basados en ejes sólo cuando `rightAngleAxes` es `false`. `clearThreeD()` despeja la configuración de la vista configurada pero mantiene el tipo de gráfico 3D y el eje de profundidad; utilice `clearDepthAxis()` para limpiar el eje de la profundidad. Los gráficos de eje 3D no exponen ejes secundarios o líneas de tendencia, y `Pie3D` dibuja un pie sólido.

## Ejes de valores logarítmicos [#logarithmic-axes]

La línea 2D compatible, área, columna, barra y tablas combinadas aceptan `scaleType: 'log'` en el eje numérico. Utilice `setYAxis()` para ejes de valor vertical y `setXAxis()` por el eje numerico horizontal de un gráfico de barras. `setRightYAxis()` configura un eje numrico secundario existente.

La base predeterminada es `10`. Se permite un `logBase` personalizado y entre `2` y `1000`; valores fraccionados como `2.5` están permitidos. Los límites numéricos deben ser positivos. Los puntos de datos cero y negativos se omiten de la trama logarítmica, pero los datos fuente no cambian.

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Line)
  .setSource('A1:B5')
  .setYAxis({ scaleType: 'log', logBase: 10 })
  .setPosition('F36')
  .setSize(640, 360)
  .build()

const chart = await worksheet.insertChart(info)

await chart.update(
  chart.toBuilder(univerAPI.Enum.ChartTypeString.Line)
    .setYAxis({ scaleType: 'linear' })
    .build(),
)
```

Para insertar un nuevo gráfico, construirlo y luego insertarlo; para aplicar una actualización despreocupada, utilice `await chart.update(builder.build())`. La configuración `scaleType: 'linear'` elimina la base de logarithm, y los parches de eje que no tocan la escala preservarlo.
