El resaltado en forma de cruz resalta la fila y la columna de la celda actualmente seleccionada, lo que facilita a los usuarios identificar la celda activa.

<PlaygroundFrame lang="en-US" slug="sheets/crosshair-highlighting" clickToShow />

## Modo preestablecido

La función de resaltado en forma de cruz no proporciona un modo preestablecido, pero admite la mezcla con su complemento.

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### Uso

```typescript
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight' // [!code ++]

import '@univerjs/sheets-crosshair-highlight/facade' // [!code ++]

import '@univerjs/sheets-crosshair-highlight/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      SheetsCrosshairHighlightEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    UniverSheetsCrosshairHighlightPlugin, // [!code ++]
  ],
})
```

## Modo de complemento

### Instalación

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### Uso

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight'
import SheetsCrosshairHighlightEnUS from '@univerjs/sheets-crosshair-highlight/locale/en-US'

import '@univerjs/sheets-crosshair-highlight/lib/index.css'

import '@univerjs/sheets-crosshair-highlight/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsCrosshairHighlightEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsCrosshairHighlightPlugin) // [!code ++]
```

## API de Facade

Se pueden encontrar definiciones completas del tipo de API de Facade en [FacadeAPI](https://reference.univer.ai/en-US).

### Importar

<Callout type="info" title="Plugin mode note">
Solo el modo complemento requiere importar manualmente el paquete Facade. El modo preestablecido ya incluye el paquete Fachada correspondiente, por lo que no se necesita ninguna importación adicional.
</Callout>

```typescript
import '@univerjs/sheets-crosshair-highlight/facade'
```

### Alternar resaltado en cruz

```typescript
univerAPI.setCrosshairHighlightEnabled(true)

univerAPI.setCrosshairHighlightEnabled(false)
```

### Obtener estado de resaltado en cruz activado

```typescript
univerAPI.getCrosshairHighlightEnabled()
```

### Escuchas de eventos

Las definiciones completas de tipos de eventos se pueden encontrar en [Eventos](https://docs.univer.ai/reference/facade/events).

El evento `CrosshairHighlightEnabledChanged` se activará cuando el estado de resaltado en cruz esté habilitado. cambios.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CrosshairHighlightEnabledChanged, (params) => {
  const { enabled, workbook, worksheet } = params
})

// Remove the event listener using `disposable.dispose()`
```

El evento `CrosshairHighlightColorChanged` se activará cuando cambie el color de resaltado en forma de cruz.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CrosshairHighlightColorChanged, (params) => {
  const { color, workbook, worksheet } = params
})

// Remove the event listener using `disposable.dispose()`
```
