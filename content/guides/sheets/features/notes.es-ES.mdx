Una anotación adjunta un comentario a una célula, por lo que la información adicional o el contexto sigue junto a los datos que describe. Esta página explica cómo leer, crear, actualizar y eliminar anotaciones a través de la Facade API, y enumera los eventos que emiten.

## Modo complemento

### Instalación

```package-install
npm install @univerjs/sheets-note @univerjs/sheets-note-ui
```

### Uso

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsNotePlugin } from '@univerjs/sheets-note' // [!code ++]
import { UniverSheetsNoteUIPlugin } from '@univerjs/sheets-note-ui' // [!code ++]
import SheetsNoteUIEnUS from '@univerjs/sheets-note-ui/locale/en-US' // [!code ++]
import '@univerjs/sheets-note-ui/lib/index.css' // [!code ++]
import '@univerjs/sheets-note/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsNoteUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsNotePlugin) // [!code ++]
univer.registerPlugin(UniverSheetsNoteUIPlugin) // [!code ++]
```

### Instalación

```package-install
npm install @univerjs/preset-sheets-note
```

### Uso

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsNotePreset } from '@univerjs/preset-sheets-note' // [!code ++]

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-note/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsNoteEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsNotePreset(), // [!code ++]
  ],
})
```

## API de Facade

Las definiciones completas del tipo Facade API están en el [FacadeAPI](/reference/facade).

### Importar

<Callout type="info" title="Nota del modo Plugin">
  El paquete Facade se importa manualmente sólo en modo plugin. El modo Preset ya incluye el paquete correspondiente.
</Callout>

```typescript
import '@univerjs/sheets-note/facade'
```

### Obtener anotaciones

`FWorksheet.getNotes` devuelve cada anotación en la hoja de trabajo.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const notes = fWorksheet.getNotes()

notes.forEach((item) => {
  const { row, col, note } = item
  console.log(`Cell ${fWorksheet.getRange(row, col).getA1Notation()} has note: ${note}`)
})
```

`FRange.getNote` devuelve la anotación en la célula superior izquierda de la gama.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:D10')
const note = fRange.getNote()
```

### Agregar o actualizar anotaciones

`FRange.createOrUpdateNote` crea o actualiza la anotación en la célula superior izquierda del rango.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1')
fRange.createOrUpdateNote({
  note: 'This is an annotation',
  width: 160,
  height: 100,
  show: true,
})
```

### Eliminar anotaciones

`FRange.deleteNote` elimina la anotación en la célula superior izquierda del rango.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const notes = fWorksheet.getNotes()

if (notes.length > 0) {
  // Remove the first annotation in the worksheet
  const { row, col } = notes[0]
  fWorksheet.getRange(row, col).deleteNote()
}

// Remove the annotation in cell C1
const fRange = fWorksheet.getRange('C1')
fRange.deleteNote()
```

### Escuchas de eventos

Las definiciones completas del tipo de evento están en el [Eventos](https://docs.univer.ai/reference/facade/events).

| Evento Nombre | Descripción |
| ---------- | ----------- |
| `SheetNoteAdd` | Fuegos después de que se añada una anotación |
| `SheetNoteDelete` | Fuegos después de una anotación se elimina |
| `SheetNoteUpdate` | Fuegos después de una anotación se actualiza |
| `SheetNoteShow` | Fuegos cuando se muestra una anotación |
| `SheetNoteHide` | Fuegos cuando una anotación está oculta |
| `BeforeSheetNoteAdd` | Fuegos antes de que se añada una anotación |
| `BeforeSheetNoteDelete` | Fuegos antes de que se suprima una anotación |
| `BeforeSheetNoteUpdate` | Fuegos antes de que se actualice una anotación |
| `BeforeSheetNoteShow` | Fuegos antes de que se muestre una anotación |
| `BeforeSheetNoteHide` | Fuegos antes de que se oculte una anotación |

##### Ejemplos de escuchas de eventos

```typescript
// Triggered after adding an annotation
const disposable = univerAPI.addEvent(univerAPI.Event.SheetNoteAdd, (params) => {
  const { workbook, worksheet, row, col, note } = params
})

// Remove event listener using `disposable.dispose()`
```

```typescript
// Triggered before removing an annotation, can be canceled
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetNoteDelete, (params) => {
  const { workbook, worksheet, row, col, oldNote } = params

  // Cancel the annotation deletion operation
  params.cancel = true
})

// Remove event listener using `disposable.dispose()`
```
