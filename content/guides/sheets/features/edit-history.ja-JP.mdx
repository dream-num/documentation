<Callout type="warning">
  **0.25.x** を使用している場合は[旧版 Pro ドキュメント](https://dream-num.github.io/documentation/v0.25/zh-CN/guides/pro/)を参照してください。新規統合にはセルフホストの Collaboration SDK を使用します。旧 Univer Server のデプロイ手順と API は適用されません。
</Callout>

[サーバー統合](/guides/server-integration)に沿って、サンプルの実行、アプリへの組み込み、永続化と権限の検証を進めてください。実装と Web/Server サンプルは [Univer Office](https://office.univer.ai/collaboration/quick-start) を参照してください。

履歴には独立した Service、Endpoint、Database Adapter、権限設定が必要です。[拡張モジュール](https://office.univer.ai/collaboration/extensions)と [History サンプル](https://office.univer.ai/collaboration/examples#history)を参照し、再起動後の保持と読み取り権限を検証してください。
