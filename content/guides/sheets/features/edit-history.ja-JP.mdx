  編集履歴機能には Univer サーバーのサポートが必要です。Univer サーバーが正しくインストール・設定されていることを確認してください。詳細は [Pro へのアップグレード](/guides/pro) を参照してください。

編集履歴は、ドキュメントの過去バージョンを閲覧・復元できる機能です。さまざまなフィルターや検索方法をサポートし、ドキュメント内容を効率的に管理するのに役立ちます。

## プリセットモード

### インストール

<Callout>
  `@univerjs/preset-sheets-advanced` の `UniverSheetsAdvancedPreset` は、実行時に `UniverSheetsDrawingPreset` に依存します。先に `@univerjs/preset-sheets-drawing` をインストールしてください。
</Callout>

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced @univerjs/preset-sheets-collaboration
```

### 使い方

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
import UniverPresetSheetsAdvancedJaJP from '@univerjs/preset-sheets-advanced/locales/ja-JP' // [!code ++]
import { UniverSheetsCollaborationPreset } from '@univerjs/preset-sheets-collaboration' // [!code ++]
import UniverPresetSheetsCollaborationJaJP from '@univerjs/preset-sheets-collaboration/locales/ja-JP' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreJaJP from '@univerjs/preset-sheets-core/locales/ja-JP'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]
import UniverPresetSheetsDrawingJaJP from '@univerjs/preset-sheets-drawing/locales/ja-JP' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-advanced/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-collaboration/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetSheetsCoreJaJP,
      UniverPresetSheetsDrawingJaJP, // [!code ++]
      UniverPresetSheetsAdvancedJaJP, // [!code ++]
      UniverPresetSheetsCollaborationJaJP, // [!code ++]
    ),
  },
  collaboration: true, // [!code ++]
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsDrawingPreset({ // [!code ++]
      collaboration: true,
    }), // [!code ++]
    UniverSheetsAdvancedPreset({ // [!code ++]
      // configuration for advanced features
    }), // [!code ++]
    UniverSheetsCollaborationPreset({ // [!code ++]
      universerEndpoint: 'http://localhost:3010', // [!code ++]
    }), // [!code ++]
  ],
})
```

Univer の商用ライセンスをお持ちの場合は、設定方法について [クライアントでのライセンス](/guides/pro/license#in-preset-mode) を参照してください。

### プリセットと設定

`UniverSheetsCollaborationPreset` の設定オプション:

```typescript
interface IUniverSheetsCollaborationPresetConfig {
  // Univer サーバーのエンドポイント
  universerEndpoint?: string
  /**
   * 履歴データの読み込みに Worker を使用する必要がある場合は、このフィールドを設定できます。
   * 1. historyWorkerURL が提供され、historyWorkerURL が Worker インスタンスである場合、履歴が閉じられたときに破棄されるため、履歴が開かれるたびに新しい Worker インスタンスを提供する必要があります。
   * ```typescript
   * import { SHEETS_HISTORY_UI_PLUGIN_CONFIG_KEY, ToggleEditHistoryOperation } from '@univerjs-pro/sheets-history-ui';
   *
   * univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
   *   if (event.id === ToggleEditHistoryOperation.id) {
   *     const workerURL = new Worker(new URL('./worker.ts', import.meta.url));
   *     const configService = univer.__getInjector().get(IConfigService);
   *     configService.setConfig(SHEETS_HISTORY_UI_PLUGIN_CONFIG_KEY, {
   *       workerURL,
   *     });
   *   }
   * });
   * 2.historyWorkerURL が Worker インスタンスでない場合、追加の処理は必要ありません。
   * ```
   */
  historyWorkerURL?: string | URL | Worker
}
```

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/sheets-history-ui
```

### 使い方

```typescript
import { UniverSheetsHistoryUIPlugin } from '@univerjs-pro/sheets-history-ui' // [!code ++]
import SheetsHistoryUIJaJP from '@univerjs-pro/sheets-history-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-history-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      SheetsHistoryUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsHistoryUIPlugin, { // [!code ++]
  univerContainerId: 'your-univer-container-id', // 履歴ビューをマウントする DOM コンテナー ID // [!code ++]
  historyServerUrl: '/universer-api/history', // [!code ++]
}) // [!code ++]
```

Univer の商用ライセンスをお持ちの場合は、設定方法について [クライアントでのライセンス](/guides/pro/license#in-plugin-mode) を参照してください。

### プラグインと設定

`UniverSheetsHistoryUIPlugin` の設定オプション:

```typescript
interface IUniverSheetsHistoryUIConfig {
  univerContainerId?: string
  // 履歴一覧のサーバー URL
  historyServerUrl?: string
  /**
   * 履歴データの読み込みに Worker を使用する必要がある場合は、このフィールドを設定できます。
   * 1. workerURL が提供され、workerURL が Worker インスタンスである場合、履歴が閉じられたときに破棄されるため、履歴が開かれるたびに新しい Worker インスタンスを提供する必要があります。
   * ```typescript
   * import { SHEETS_HISTORY_UI_PLUGIN_CONFIG_KEY, ToggleEditHistoryOperation } from '@univerjs-pro/sheets-history-ui';
   *
   * univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
   *   if (event.id === ToggleEditHistoryOperation.id) {
   *     const workerURL = new Worker(new URL('./worker.ts', import.meta.url));
   *     const configService = univer.__getInjector().get(IConfigService);
   *     configService.setConfig(SHEETS_HISTORY_UI_PLUGIN_CONFIG_KEY, {
   *       workerURL,
   *     });
   *   }
   * });
   * 2.workerURL が Worker インスタンスでない場合、追加の処理は必要ありません。
   * ```
   */
  workerURL?: string | URL | Worker
}
```

編集履歴を有効化すると、`UniverSheetsHistoryUIPlugin` は新しい Univer インスタンスを読み込み、指定した DOM ノードにマウントします。そのため、登録時には適切な DOM ノードの ID（既存の Univer インスタンスのコンテナーなど）を指定し、履歴パネルが元の Univer パネルの上に表示されるようにしてください。ノード ID を指定しない場合、既定値は `univer-container` です。

履歴一覧のサーバー アドレスを変更する必要がある場合は、`historyServerUrl` 設定オプションで指定できます。既定値は `/universer-api/history` です。
