Слайсер фильтрует таблицы, таблицы и таблицы PivotCharts членами источника. Сроки фильтруют исходные поля даты Pivot, которые могут служить источником. Столбцы таблиц, текстовые поля, вычисленные поля и производные поля группирования не могут быть источниками временной шкалы.

## Режим плагина [#plugin-mode]

### Установка

```package-install
npm install @univerjs-pro/sheets-slicer @univerjs-pro/sheets-slicer-ui
```

### Использование

Добавьте следующее к существующему [Настройка листов](/guides/sheets/getting-started/installation), с [поддержка](/guides/sheets/features/images) и [Столик](/guides/sheets/features/table) или [поворотный стол](/guides/sheets/features/pivot-table) источник уже настроен. Загрузите локализацию и зарегистрируйте эти плагины перед созданием рабочей книги.

```ts
import { UniverSheetsSlicerPlugin } from '@univerjs-pro/sheets-slicer'
import { UniverSheetsSlicerUIPlugin } from '@univerjs-pro/sheets-slicer-ui'
import SheetsSlicerUILocale from '@univerjs-pro/sheets-slicer-ui/locale/ru-RU'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/sheets-slicer/facade'
import '@univerjs-pro/sheets-slicer-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.RU_RU, SheetsSlicerUILocale)
univer.registerPlugin(UniverSheetsSlicerPlugin)
univer.registerPlugin(UniverSheetsSlicerUIPlugin)
```

`UniverSheetsSlicerPlugin`

| --- | --- | --- | --- |

## Режим предустановки [#preset-mode]

### Установка

```package-install
npm install @univerjs/presets @univerjs/preset-sheets-core @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

### Использование

Расширенный предустановленный набор включает в себя нарезку и временную модель и плагины пользовательского интерфейса, а также их API-интерфейсы Facade. Объедините его с ядром и рисунком предустанавливающих и объедините локальные пакеты. Если расширенный предустановский набор уже используется, добавьте `slicer` к этой регистрации, а не регистрируйте его во второй раз. Настройте клиентскую лицензию, как описано в [Использование лицензии](/server/license).

```ts
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'
import AdvancedLocale from '@univerjs/preset-sheets-advanced/locales/ru-RU'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import CoreLocale from '@univerjs/preset-sheets-core/locales/ru-RU'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing'
import DrawingLocale from '@univerjs/preset-sheets-drawing/locales/ru-RU'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css'
import '@univerjs/preset-sheets-advanced/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.RU_RU,
  locales: {
    [LocaleType.RU_RU]: mergeLocales(CoreLocale, DrawingLocale, AdvancedLocale),
  },
  presets: [
    UniverSheetsCorePreset({ container: 'app' }),
    UniverSheetsDrawingPreset(),
    UniverSheetsAdvancedPreset({ slicer: { maxMemberWindowSize: 200 } }),
  ],
})
```

Когда вы используете [рабочий](/guides/sheets/getting-started/worker), установите `useWorker: true` на расширенный предустановленный и зарегистрируйте `UniverSheetsAdvancedWorkerPreset()` в Рабочем. Этот предустанавливаемый набор также включает в себя плагин для расчета слайсера.

## Создание среза [#create-slicer]

В приведенном ниже примере используется PivotTable at I1 на активном листе и поле источника под названием `Region`. Позвоните `getSourceFieldsInfo()`, чтобы получить стабильный оригинальный идентификатор поля. Имена дисплеев и идентификаторы поля отчета не могут быть переданы `newSlicer()` .

```ts
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook?.getActiveSheet()
if (!fWorkbook || !fWorksheet) throw new Error('No active worksheet')

const pivotTable = fWorkbook.getPivotTableByCell(
  fWorkbook.getId(),
  fWorksheet.getSheetId(),
  0,
  8,
)
const regionField = pivotTable?.getSourceFieldsInfo().find((field) => field.name === 'Region')
if (!pivotTable || !regionField) throw new Error('Region source field not found')

const slicer = await fWorksheet.insertSlicer(
  pivotTable.newSlicer(regionField.id)
    .setCaption(regionField.name)
    .setPosition('N2')
    .build(),
)
```

`pivotTable.newSlicer()` связывает конструктор с этим источником. `build()` только собирает конфигурацию; `insertSlicer()` создает управление. Листовка хоста и лист источника могут отличаться, но оба должны быть в одной и той же книге. Для источника таблицы звоните `fWorksheet.newSlicer(columnId).setTableReference({ subUnitId, tableId })`, где `columnId` является стабильным идентификатором столбца таблицы.

## Создание временной шкалы [#create-timeline]

В этом примере используется та же PivotTable и требуется исходное поле даты под названием `Date`. `newTimeline()` проверяет источник и отклоняет неподдерживаемые поля. API диапазона временной шкалы принимают серийные значения Excel в системе дат книги, а не объекты JavaScript `Date` .

```ts
const dateField = pivotTable.getSourceFieldsInfo().find((field) => field.name === 'Date')
if (!dateField) throw new Error('Date source field not found')

const timeline = await fWorksheet.insertTimeline(
  pivotTable.newTimeline(dateField.id)
    .setCaption(dateField.name)
    .setLevel(univerAPI.Enum.TimelineLevel.Month)
    .setPosition('N18')
    .build(),
)
```

## Поиск элементов и отслеживание изменений [#controls-and-events]

На рабочем листе хоста `getSlicer(viewId)` / `getSlicers()` и `getTimeline(viewId)`/ `getTimelines()` находят элементы управления. `viewId` - это идентификатор бизнеса, который возвращает `getId()` управления, а не его идентификатор рисунка.

Регистр `SlicerAdded`, `SlicerChanged`, `SlicerRemoved`, `TimelineAdded`, `TimelineChanged` и `TimelineRemoved`-`univerAPI.addEvent()`. Событие указывает на то, что было совершено локальное изменение. Не указывает на то что изменение было сохранено удаленно или что рендеринг закончился. Удалите возвращенную подписку, когда она больше не нужна.

Справочник API:

- [FSheetSlicer](/reference/facade/sheet-slicer)
- [FSheetSlicerBuilder](/reference/facade/sheet-slicer-builder)
- [FSheetTimeline](/reference/facade/sheet-timeline)
- [FSheetTimelineBuilder](/reference/facade/sheet-timeline-builder)
- [FEventName](/reference/facade/events#univerjs-prosheets-slicer)

## Запрос элементов и общие фильтры [#shared-filters]

`setSelection()` ожидает набранные исходные значения. Номер `1`, строка `'1'` и пустое - это три разных члена, поэтому не пропускайте ярлыки дисплея или индексы из видимого списка. Каждый просмотр одного и того же кэша и каждый отчет, подключенный к нему, разделяет фильтр. С источником Таблицы выбор заменяет фильтр этой колонки и оставляет другие столбцы без изменений. Позвоните `clearFilter()` для очистки фильтра.

```ts
import { FilterSelectionMode, RecordValueType } from '@univerjs/core'

const accepted = await slicer.setSelection({
  mode: FilterSelectionMode.Include,
  values: [{ type: RecordValueType.String, value: 'EMEA' }],
})
```

`getItems({ start, count })` считывает окно элементов, а не весь источник, и чтение не меняет выбор. Запрос по умолчанию составляет 100 элементов и ограничен `maxMemberWindowSize` (по умолчанию 200, положительное целое число). Выборы, выходящие за пределы видимого окна, сохраняются. `setConnections()` заменяет соединения отчета Pivot; используйте `getConnectionCandidates()` для обнаружения отчетов, которые могут подключаться. Редактирование требует соответствующих разрешений на рабочие листы. См. [Слайсер FSheets](/reference/facade/sheet-slicer).

## Условия даты временной шкалы [#date-conditions]

`setSelection({ startDate, endDate, useWholeDay: true })` расширяет дробные границы до целых дней, в то время как целочисленный конец остается эксклюзивным. Без `useWholeDay` интервал точно `[startDate, endDate)`. Условие фиксированной даты, совместно используемое из PivotTable, может быть несмежным; `getDateCondition()` читает его в этом случае. Для такого условия `getSelection()` возвращает `undefined`, так что один только результат не указывает, что временная шкала нефильтрована.
