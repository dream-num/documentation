Кроссхейр выделяет знаки строки и столбца выбранной клетки, что делает активную клетку легко идентифицируемой.

<PlaygroundFrame lang="ru-RU" slug="sheets/crosshair-highlighting" clickToShow />

## Режим плагинов

### Установка

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### Использование

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight'
import SheetsCrosshairHighlightEnUS from '@univerjs/sheets-crosshair-highlight/locale/en-US'
import '@univerjs/sheets-crosshair-highlight/lib/index.css'
import '@univerjs/sheets-crosshair-highlight/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsCrosshairHighlightEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsCrosshairHighlightPlugin) // [!code ++]
```

## Режим Preset

Кроссхейр подсветка не обеспечивает собственный предустановка, но его плагин может быть добавлен вместе с предустанавливаемым.

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### Использование

```typescript
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight' // [!code ++]
import '@univerjs/sheets-crosshair-highlight/facade' // [!code ++]
import '@univerjs/sheets-crosshair-highlight/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      SheetsCrosshairHighlightEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    UniverSheetsCrosshairHighlightPlugin, // [!code ++]
  ],
})
```

## Facade API

Полные определения типов Facade API приведены в [FacadeAPI](/reference/facade).

### Импорт

<Callout type="info" title="Заметка о режиме плагина">
  Пакет Facade импортируется вручную только в режиме плагина.Предустановленный режим уже включает его, поэтому дополнительного импорта не требуется.
</Callout>

```typescript
import '@univerjs/sheets-crosshair-highlight/facade'
```

### Включение и отключение перекрёстной подсветки

```typescript
univerAPI.setCrosshairHighlightEnabled(true)

univerAPI.setCrosshairHighlightEnabled(false)
```

### Проверка состояния перекрёстной подсветки

```typescript
univerAPI.getCrosshairHighlightEnabled()
```

### Обработчики событий

Полные определения типов событий приведены в [События](https://docs.univer.ai/reference/facade/events).

`CrosshairHighlightEnabledChanged` загорается при включенном или отключенном перекрестном освещении.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CrosshairHighlightEnabledChanged, (params) => {
  const { enabled, workbook, worksheet } = params
})

// Remove the event listener using `disposable.dispose()`
```
