차트는 데이터를 시각화하는 중요한 도구로, 사용자가 데이터를 더 직관적으로 이해하고 분석할 수 있도록 도와줍니다. Univer Sheets의 차트 기능은 세로 막대형 차트, 꺾은선형 차트, 원형 차트 등 다양한 유형을 제공합니다. 사용자는 필요에 따라 적절한 차트 유형을 선택해 데이터를 표현할 수 있습니다.

## 프리셋 모드

차트 기능은 `@univerjs/preset-sheets-advanced` 프리셋에 포함되어 있습니다.

### 설치

<Callout>
  `@univerjs/preset-sheets-advanced`의 `UniverSheetsAdvancedPreset` 프리셋은 런타임에 `UniverSheetsDrawingPreset` 프리셋을 사용합니다. 먼저 `@univerjs/preset-sheets-drawing`을 설치하세요.
</Callout>

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```


### 차트 삽입

`FWorksheet.newChart()` 메서드는 차트 빌더를 만들고 `FChartBuilderBase` 인스턴스를 반환합니다. 메서드를 체이닝하여 차트의 여러 속성을 설정할 수 있습니다.

그런 다음 `build()`를 호출해 `IChartBuilderInfo` 객체를 생성하고, `FWorksheet.insertChart(chartBuildInfo: IChartBuilderInfo)` 메서드로 차트를 워크시트에 삽입합니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a column chart with data source A1:D6.
// The starting position is upper-left corner of cell B2.
// The width of the chart is 600 and the height is 400.
const chartInfo = fWorksheet.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
  .setWidth(600)
  .setHeight(400)
  .build()
await fWorksheet.insertChart(chartInfo)
```

`FChartBuilderBase`에서 사용할 수 있는 주요 메서드는 다음과 같습니다.

| 메서드 | 설명 |
| ------ | ----------- |
| addRange | 차트의 데이터 원본 범위 지정 |
| setPosition | 행과 열 앵커를 사용해 차트 위치 설정 |
| setAbsolutePosition | 픽셀 값으로 차트 위치 설정 |
| setChartType | 차트 유형 설정 |
| setWidth | 차트 너비 설정 |
| setHeight | 차트 높이 설정 |
| setOptions | 차트 옵션 설정 |
| setTransposeRowsAndColumns | 행과 열 바꾸기 |
| setTheme | 테마 설정 |
| setXAxisTitle | X축 제목 설정 |
| setYAxisTitle | Y축 제목 설정 |
| setRightYAxisTitle | 오른쪽 Y축 제목 설정 |
| setXAxisTextStyle | X축 제목 스타일 설정 |
| setYAxisTextStyle | Y축 제목 스타일 설정 |
| setRightYAxisTextStyle | 오른쪽 Y축 제목 스타일 설정 |
| setInvalidValueStrategy | 빈 셀 표시 방식 설정 |
| setAxisPointerStyle | 축 포인터 스타일 설정 |
| setAllSeriesStyle | 모든 계열의 스타일 설정 |
| setSeriesStyle | 계열 인덱스로 계열 스타일 설정 |
| build | 차트를 삽입하거나 업데이트하는 데 사용할 빌더 정보 생성 |

  - `setOptions(optionPath, optionVal)`: `setOptions('legend.color', '#ff0000')`
  - `setOptions('', IChartBuildOptions)`: `setOptions('', { legend: { color: '#ff0000', bold: true } })`

<details>
  <summary>예제: 꺾은선형 차트 만들기</summary>
  ```typescript
  const fWorkbook = univerAPI.getActiveWorkbook()
  const fWorksheet = fWorkbook.getActiveSheet()

  // Create a line chart
  const chartInfo = fWorksheet.newChart()
    // As a line chart
    .asLineChart()
    // Set the data source A1:D6
    .addRange('A1:D6')
    // Set the starting position to the upper-left corner of cell B2
    .setPosition(1, 1, 0, 0)
    // Set the indicator line style
    .setAxisPointerStyle({
      indicatorLabelColor: '#ff0000',
      indicatorLineType: univerAPI.Enum.ChartBorderDashType.Solid,
      indicatorLineColor: '#00ff00',
      indicatorLabelTextColor: '#0000ff',
    })
    // Set the data point size to 10
    .setDataPointSize(10)
    // Set the data point shape to circular
    .setDataPointShape(univerAPI.Enum.LinePointShape.Circle)
    // Generate builder info
    .build()
  const fChart = await fWorksheet.insertChart(chartInfo)

  // Update the chart after 3 seconds
  setTimeout(() => {
    if (fChart) {
      // Get the first series data
      const first = fChart.getSeriesData()[0]
      // Set the color of the first series to red
      const newChartInfo = fWorksheet.newChart(fChart)
        .setSeriesStyle(first.index, {
          color: '#ff0000',
        })
        .build()
      // Update the chart
      fWorksheet.updateChart(newChartInfo)
    }
  }, 3000)
  ```

Univer는 특정 유형의 차트를 만들 수 있도록 다음 빌더를 제공합니다. `fWorkSheet.newChart().asLineChart()`와 같은 방식으로 생성할 수 있습니다. 각 빌더는 `FChartBuilderBase`에서 파생되며 고유한 구성 옵션을 제공합니다.

```typescript
const lineChartBuilder = fWorkSheet.newChart().asLineChart()
const pieChartBuilder = fWorkSheet.newChart().asPieChart()
const radarChartBuilder = fWorkSheet.newChart().asRadarChart()

// Or you can use the following method to create a chart builder
const chartBuilder = fWorkSheet.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
```

- `LineChartBuilder`

| 메서드 | 설명 |

| setLineStyle | 선 스타일 설정: 'line'은 직선, 'smooth'는 곡선, 'step'은 계단선 |
| setDataPointShape | 데이터 요소 모양 설정. 지원되는 모양은 LinePointShape 참고 |
| setDataPointColor | 데이터 요소 색상 설정 |
| setDataPointSize | 데이터 요소 크기 설정 |
| build | 차트를 삽입하거나 업데이트하는 데 사용할 빌더 정보 생성 |

- `PieChartBuilder`

| 메서드 | 설명 |
| ------ | ----------- |
| setDoughnutHole | 도넛 구멍 크기 설정. 범위는 0~1 |
| setBorderColor | 원형 차트 테두리 색상 설정 |
| setHasPaddingAngle | 원형 차트 조각 사이에 간격을 둘지 설정 |
| setIsHalfPie | 반원형 차트로 표시할지 설정 |
| setRosePie | 장미형 차트로 표시할지 설정 |
| setShowLabelLine | 레이블 선 표시 |
| build | 차트를 삽입하거나 업데이트하는 데 사용할 빌더 정보 생성 |

- `RadarChartBuilder`

| 메서드 | 설명 |
| ------ | ----------- |
| setShape | 방사형 차트의 기본 모양 설정. 현재 지원되는 값은 'polygon'(다각형), 'circle'(원) |
| setFill | 방사형 차트를 채울지 설정 |
| build | 차트를 삽입하거나 업데이트하는 데 사용할 빌더 정보 생성 |

### 차트 가져오기

`FWorksheet.getCharts()` 메서드는 현재 워크시트의 모든 차트를 가져오며 `FChart` 객체의 배열을 반환합니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Get all charts on the active sheet.
const charts = fWorksheet.getCharts()
```

`FChart`에서 사용할 수 있는 주요 메서드는 다음과 같습니다.

| 메서드 | 설명 |
| --- | --- |
| getRange | 차트 데이터 원본 범위 가져오기 |
| getSeriesData | 계열 데이터 가져오기 |
| getCategoryData | 범주 데이터 가져오기 |
| updateRange | 차트 데이터 원본 범위 업데이트 |

### 차트 업데이트

`FWorksheet.updateChart(chartBuildInfo: IChartBuilderInfo)` 메서드는 `IChartBuilderInfo` 객체를 전달받아 차트 구성을 업데이트합니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a column chart with data source A1:D6.
// The starting position is upper-left corner of cell B2.
const chartInfo = fWorksheet.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
  .build()
await fWorksheet.insertChart(chartInfo)

// Get all charts on the active sheet.
const charts = fWorksheet.getCharts()

// Update the first chart after 3 seconds.
setTimeout(() => {
  const newChartInfo = fWorksheet.newChart(charts[0])
    .asLineChart()
    .setOptions('legend.position', univerAPI.Enum.LegendPositionEnum.Right)
    .build()
  fWorksheet.updateChart(newChartInfo)
}, 3000)
```

### 차트 제거

`FWorksheet.removeChart(chart: FChart)` 메서드는 `FChart` 객체를 전달받아 지정한 차트를 제거합니다.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a column chart with data source A1:D6.
// The starting position is upper-left corner of cell B2.
const chartInfo = fWorksheet.newChart()
  .setChartType(univerAPI.Enum.ChartType.Column)
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
  .build()
await fWorksheet.insertChart(chartInfo)

// Get all charts on the active sheet.
const charts = fWorksheet.getCharts()

// Remove the first chart after 3 seconds.
setTimeout(async () => {
  await fWorksheet.removeChart(charts[0])
  console.log(fWorksheet.getCharts())
}, 3000)
```

### 차트 테마

`FWorksheet.registerChartTheme(themeName: string, theme: IEchartTheme)` 메서드는 테마 이름과 테마 객체를 전달받아 사용자 지정 차트 테마를 등록합니다.

Univer 차트는 echarts 라이브러리를 기반으로 구현되므로 echart 테마 [빌더 도구를 사용해 사용자 지정 테마를 만들 수 있습니다](https://echarts.apache.org/en/theme-builder.html).
이 웹사이트에서 테마를 직접 만들고 구성 파일로 다운로드할 수 있습니다. 다음 API를 사용해 사용자 지정 테마를 적용하세요.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// register your theme
const theme = { // your theme object
  version: 1,
  themeName: 'myTheme',
  theme: {
    // ... Some code is omitted for brevity
    color: [
      '#893448',
      '#d95850',
      '#eb8146',
      '#ffb248',
      '#f2d643',
      '#ebdba4',
    ],
    // ... Some code is omitted for brevity
    visualMapColor: [
      '#893448',
      '#d95850',
      '#eb8146',
      '#ffb248',
      '#f2d643',
      'rgb(247,238,173)',
    ],
    // ... Some code is omitted for brevity
    axes: [],
    // ... Some code is omitted for brevity
  },
}
fWorksheet.registerChartTheme('myTheme', theme)

// use your theme for chart
const chartInfo = fWorksheet.newChart()
  .asLineChart()
  .addRange('A1:D6')
  .setPosition(1, 1, 0, 0)
  .setTheme('myTheme')
  .build()
await fWorksheet.insertChart(chartInfo)
```
