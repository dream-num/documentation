차트는 작업표 데이터를 차트로 렌더링합니다. 차트 모델과 UI 패키지는 기능을 제공합니다.

## 플러그인 모드

```package-install
npm install @univerjs-pro/chart-ui @univerjs-pro/sheets-chart @univerjs-pro/sheets-chart-ui
```

```ts
import ChartUIKoKR from '@univerjs-pro/chart-ui/locale/ko-KR'
import { UniverSheetsChartPlugin } from '@univerjs-pro/sheets-chart'
import { UniverSheetsChartUIPlugin } from '@univerjs-pro/sheets-chart-ui'
import SheetsChartUIKoKR from '@univerjs-pro/sheets-chart-ui/locale/ko-KR'
import SheetsChartKoKR from '@univerjs-pro/sheets-chart/locale/ko-KR'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/chart-ui/facade'
import '@univerjs-pro/sheets-chart/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/sheets-chart-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.KO_KR,
  locales: {
    [LocaleType.KO_KR]: mergeLocales(ChartUIKoKR, SheetsChartKoKR, SheetsChartUIKoKR),
  },
})

univer.registerPlugin(UniverSheetsChartPlugin)
univer.registerPlugin(UniverSheetsChartUIPlugin)
```

## 프리셋 모드

`@univerjs/preset-sheets-advanced`는 이미 차트 기능을 포함하지만, 런타임에서 도면 미리 설정이 필요합니다.

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

```ts
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'
import UniverPresetSheetsAdvancedKoKR from '@univerjs/preset-sheets-advanced/locales/ko-KR'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreKoKR from '@univerjs/preset-sheets-core/locales/ko-KR'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing'
import UniverPresetSheetsDrawingKoKR from '@univerjs/preset-sheets-drawing/locales/ko-KR'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-advanced/lib/index.css'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.KO_KR,
  locales: {
    [LocaleType.KO_KR]: mergeLocales(
      UniverPresetSheetsCoreKoKR,
      UniverPresetSheetsDrawingKoKR,
      UniverPresetSheetsAdvancedKoKR,
    ),
  },
  presets: [UniverSheetsCorePreset(), UniverSheetsDrawingPreset(), UniverSheetsAdvancedPreset()],
})
```

## 차트 만들기와 업데이트

`worksheet.newChart(type)`는 분리형 빌더를 반환합니다. 차트 정보가 내장되어 `worksheet.insertChart(info)`로 전달될 때까지 작업 시트에 추가되지 않습니다.

```ts
const workbook = univerAPI.getActiveWorkbook()
if (!workbook) throw new Error('No active workbook')

const worksheet = workbook.getActiveSheet()
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D6',
    orientation: univerAPI.Enum.ChartSourceOrientation.Columns,
  })
  .setPosition('F2')
  .setSize(640, 360)
  .setCategoryField(0)
  .setValueFields([1, 2, 3])
  .setTitle('Quarterly revenue')
  .build()

const chart = await worksheet.insertChart(info)
chart.setLegend({ visible: true }).bringToFront()

const updatedInfo = chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setSubtitle('FY 2026').build()
await chart.update(updatedInfo)

const svg = await chart.exportImage({ format: 'svg' })
```

삽입된 `chart`에 setter를 호출하면 즉시 업데이트됩니다. `toBuilder(type)`를 `update(info)`로 사용하여 완전히 분리된 복사본을 얻거나 차트 유형을 변경하십시오. `exportImage()`는 UI 렌더링자가 이미지를 생성 할 수 없을 때 `undefined`을 반환합니다.

`worksheet.getCharts()` 및 `worksheet.getChart(id)` 반품 라이브 차트. `await chart.remove()`를 호출하여 차트를 삭제합니다. `univerAPI.registerTheme(name, theme)`와 공유된 ECharts 테마를 등록하십시오.

## 차트 시트 [#chart-sheets]

`insertChartSheet()`는 차트 자체 탭을 제공합니다. 차트 빌더는 동일한 워크북에 그리드 시트를 참조해야하며 소스 셀은 그 시트에 남아 있습니다.

```ts
import '@univerjs-pro/sheets-chart/facade'

const workbook = univerAPI.getActiveWorkbook()
const data = workbook?.getSheetByName('Data')
if (!workbook || !data) throw new Error('The Data sheet is required')

const info = data
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({ sheetId: data.getSheetId(), range: 'A1:B4' })
  .build()

const chartSheet = await workbook.insertChartSheet(info, { name: 'Sales' })
const primaryChart = chartSheet.getPrimaryChart()
```

`await chart.moveTo(targetSheet)`는 기존 차트를 이동. 차트 시트로 이동하면 시트에 추가 차트가됩니다. 차트 시트에서 1 차 차트를 이동하면 다른 아무것도 포함되지 않은 탭이 필요하며 이동은 그 탭을 제거합니다. 이동은 undone 및 Redone이 될 수 있습니다.

[`FWorkbook.insertChartSheet()`](/reference/facade/workbook#insertchartsheet) · [`FWorksheet.getPrimaryChart()`](/reference/facade/worksheet#getprimarychart)

## 오차 막대 [#error-bars]

`setErrorBars()`는 빌더 또는 라이브 차트에 호출 할 수 있습니다. 기본 2D 컬럼, 바, 라인 및 분산 차트 지원 오류 막대. `seriesIndex`은 0 기반이며 소스 데이터의 범주 필드를 계산합니다. 열 및 라인 사용 `y`, 바 사용 `x` 및 스텐더 차트는 숫자 축을 사용할 수 있습니다.

```ts
chart.setErrorBars([
  { seriesIndex: 1, direction: 'y', type: 'both', valueType: 'percentage', value: 20 },
])
```

[`FChart.setErrorBars()`](/reference/facade/chart#seterrorbars)

## 다단계 범주 축

인접한 소스 열이 계층을 형성 할 때, 루트 - 투 - leaf 순서에 `setCategoryFields()`에 0 기반 인덱스를 통과하고, 멀티 레벨 축을 활성화합니다.

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D7',
    orientation: univerAPI.Enum.ChartSourceOrientation.Columns,
  })
  .setCategoryFields([0, 1])
  .setMultiLevelCategoryAxis(true)
  .setValueFields([2, 3])
  .setPosition('F2')
  .build()

const chart = await worksheet.insertChart(info)
chart.setCategoryFields([0, 1]).setMultiLevelCategoryAxis(true)
```

`clearCategoryFields()`는 주문 매핑을 제거합니다. `setMultiLevelCategoryAxis(false)`은 선택한 필드를 유지하고 계층 렌더링 만 비활성화합니다.

## 지원되는 차트 유형

`univerAPI.Enum.ChartTypeString`는 뒤에 오는 유형을 제공합니다: `Line`, `LineStacked`, `LinePercentStacked`, `Column`, `ColumnStacked`, `ColumnPercentStacked`, `Bar`, `BarStacked`, `BarPercentStacked`, `Pie`, `Donut`, `Area`, `AreaStacked`, `AreaPercentStacked`, `Radar`, `Scatter`, `Combination`, `WordCloud`, `Funnel`, `Bubble`, `Relation`, `Waterfall`, `Pareto`, `Sankey`, `Heatmap`, `Boxplot`, `Candlestick`, `Histogram`, `Treemap`, `Sunburst`, `Gauge`, `Chord`.

[차트 Facade 참조](/reference/facade/chart) 문서 공유 빌더 구성 API.

`LineStacked` 및 `LinePercentStacked`는 독립 2D 차트 유형입니다. 서버 렌더링기 또는 Office 파일 변환에서 사용하기 전에 대상이 지원한다는 것을 확인하십시오.

## 숨겨진 데이터와 독립 범주 [#source-mapping]

`setPlotVisibleOnly(false)`는 숨겨진 행과 열에서 값을 포함하고 `getPlotVisibleOnly()`은 현재 설정을 읽습니다. 별도의 범주 열을 가진 소스를 위해 `setSeriesToCategory()`가 범주 필드 인덱스에 각 값 필드 인덱스를 매핑합니다. 인덱스는 필터링 후 남아있는 일련의 물리적 소스 벡터를 참조합니다. 공유 카테고리를 상속하고있는 항목과 `{}`를 명확하게합니다.

열 A : D, 예를 들어, D의 값 시리즈는 C를 카테고리로 사용할 수 있으며 B는 A에서 공유 카테고리를 유지합니다.

```ts
const chart = worksheet.getCharts()[0]
if (!chart) throw new Error('No chart')
chart.setPlotVisibleOnly(false)
chart.setSeriesToCategory({ 3: [2] })
```

집계 보고서는 [피벗 차트](/guides/sheets/features/pivot-chart)를 참고하세요.

## 3D 차트 [#three-dimensional-charts]

3D 차트는 동일한 플러그인 등록을 사용합니다. 3D 차트 유형을 선택하고, 다음 분리된 빌더에 대한보기를 구성합니다.

지원되는 유형은 `Line3D`, `Column3D`, `ColumnStacked3D`, `ColumnPercentStacked3D`, `Bar3D`, `BarStacked3D`, `BarPercentStacked3D`, `Pie3D`, `Area3D`, `AreaStacked3D` 및 `AreaPercentStacked3D`입니다.

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Column3D)
  .setSource('A1:C5')
  .setCategoryField(0)
  .setValueFields([1, 2])
  .setPosition('F18')
  .setSize(640, 360)
  .setThreeD({
    view: { rotX: 20, rotY: 30, rightAngleAxes: false, perspective: 30 },
    gapDepth: 120,
  })
  .build()

await worksheet.insertChart(info)
```

`perspective`는 `rightAngleAxes`가 `false`일 때만 축 근거한 도표에 적용합니다. `clearThreeD()`은 형성한 전망 조정을 삭제하고 3D 도표 유형과 깊이 축선을 지킵니다; 깊이 축선을 명확하게 `clearDepthAxis()`를 사용하십시오. 3D 축선 도표는 이차 축 또는 동향을 노출하지 않으며, `Pie3D`에는 단단한 파이를 그립니다.

## 로그 값 축 [#logarithmic-axes]

지원되는 2D 선, 지역, 란, 막대기 및 조합 도표는 숫자 축선에 `scaleType: 'log'`를 받아들입니다. 수직값 axes를 위한 `setYAxis()` 및 막대기 도표의 수평한 숫자 축선을 위한 `setXAxis()` 사용하십시오. `setRightYAxis()`는 기존하는 이차 숫자 축선을 형성합니다.

기본 기본 기본은 `10`입니다. `logBase`는 `2`와 `1000` 사이의 무한하고 있어야 합니다. `2.5`과 같은 분수 값은 허용됩니다. 수치 경계는 긍정적이어야 합니다. Zero 및 부정적인 데이터 포인트는 논리적 인 플로트에서 omitted이지만 소스 데이터는 변경되지 않습니다. 백분율이 적고 3D 차트는 로그를 지원하지 않습니다.

```ts
const info = worksheet
  .newChart(univerAPI.Enum.ChartTypeString.Line)
  .setSource('A1:B5')
  .setYAxis({ scaleType: 'log', logBase: 10 })
  .setPosition('F36')
  .setSize(640, 360)
  .build()

const chart = await worksheet.insertChart(info)

await chart.update(
  chart.toBuilder(univerAPI.Enum.ChartTypeString.Line)
    .setYAxis({ scaleType: 'linear' })
    .build(),
)
```

새로운 차트를 삽입하려면 빌드하고 다음 삽입하십시오. 분리 된 업데이트를 적용하려면 `await chart.update(builder.build())`를 사용하십시오. `scaleType: 'linear'` 설정은 logarithm 기본 및 축 패치를 제거하여 스케일 보존을하지 않습니다.
