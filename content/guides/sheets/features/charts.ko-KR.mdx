차트는 차트 모델과 UI 패키지로 워크시트 데이터를 시각화합니다.

## 프리셋 모드

차트 기능은 `@univerjs/preset-sheets-advanced`에 포함되며 런타임에는 drawing 프리셋이 필요합니다.

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

## 플러그인 모드

```package-install
npm install @univerjs-pro/chart-ui @univerjs-pro/sheets-chart @univerjs-pro/sheets-chart-ui
```

```ts
import ChartUIKoKR from '@univerjs-pro/chart-ui/locale/ko-KR'
import { UniverSheetsChartPlugin } from '@univerjs-pro/sheets-chart'
import { UniverSheetsChartUIPlugin } from '@univerjs-pro/sheets-chart-ui'
import SheetsChartUIKoKR from '@univerjs-pro/sheets-chart-ui/locale/ko-KR'
import SheetsChartKoKR from '@univerjs-pro/sheets-chart/locale/ko-KR'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-chart/facade'
import '@univerjs-pro/chart-ui/lib/index.css'
import '@univerjs-pro/sheets-chart-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.KO_KR,
  locales: {
    [LocaleType.KO_KR]: mergeLocales(ChartUIKoKR, SheetsChartKoKR, SheetsChartUIKoKR),
  },
})

univer.registerPlugin(UniverSheetsChartPlugin)
univer.registerPlugin(UniverSheetsChartUIPlugin)
```

## 차트 만들기와 업데이트

워크시트의 `charts` 컬렉션으로 차트를 관리합니다. `create()`는 아직 삽입되지 않은 빌더를 반환하고 `insert()`는 워크시트에 삽입합니다.

```ts
const worksheet = univerAPI.getActiveWorkbook().getActiveSheet()

const builder = worksheet.charts.create()
  .setType(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D6',
    orientation: univerAPI.Enum.ChartSourceOrientation.Column,
  })
  .setTitle('분기 수익')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)

const chart = await worksheet.charts.insert(builder)

chart
  .setType(univerAPI.Enum.ChartTypeString.Line)
  .setLegend({ visible: true })
  .setSeries({ index: 0 }, { color: '#2F80ED' })
  .commit()
```

기존 차트는 `worksheet.charts.list()`, `worksheet.charts.get(id)`, `await worksheet.charts.remove(chartOrId)`로 관리합니다. `worksheet.charts.registerTheme(name, theme)`로 Univer 런타임 전체에서 공유하는 ECharts 테마를 등록할 수 있습니다.

## 지원되는 차트 유형

`univerAPI.Enum.ChartTypeString`에서 `Line`, `Column`, `ColumnStacked`, `ColumnPercentStacked`, `Bar`, `BarStacked`, `BarPercentStacked`, `Pie`, `Donut`, `Area`, `AreaStacked`, `AreaPercentStacked`, `Radar`, `Scatter`, `Combination`, `WordCloud`, `Funnel`, `Bubble`, `Relation`, `Waterfall`, `Pareto`, `Sankey`, `Heatmap`, `Boxplot`, `Candlestick`, `Histogram`, `Treemap`, `Sunburst`, `Gauge`, `Chord`를 사용할 수 있습니다.

공통 빌더 설정은 [차트 Facade 참조](/reference/facade/chart)를 확인하세요.
