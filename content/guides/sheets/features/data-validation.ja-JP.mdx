データの検証は、セルにルールを適用し、入力した値をチェックします。入力エラーを早期にキャッチし、シートを正確かつ一貫した状態でデータを保存します。

Univerは、以下のバリデーションタイプをサポートしています。
- Number
- Integer
- Text length
- Date
- Checkbox
- Dropdown list (single/multiple selection)
- Custom formula

## プラグインモード

### インストール

```package-install
npm install @univerjs/data-validation @univerjs/sheets-data-validation @univerjs/sheets-data-validation-ui
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDataValidationPlugin } from '@univerjs/data-validation' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(

univer.registerPlugin(UniverDataValidationPlugin) // [!code ++]
```

### データ検証ルールの追加

[`univerAPI.newDataValidation()`](https://docs.univer.ai/reference/facade/univer#newdatavalidation)は、ビルダーを作成し、`FDataValidationBuilder`を返します。 ルールを構築するためにチェーン内のメソッドを呼び出します。

[`FDataValidationBuilder`](/reference/facade/data-validation-builder)の主な方法は次のとおりです。

| Method | Description |
| ------ | ----------- |
| build | ルールを構築します。 |
| requireCheckbox | セルがチェックボックスとして表示するブール値が必要です。 |
| requireDateAfter | DATE にタイプを設定し、指定した日付後に日付を要求します。 |
| requireDateBefore | DATE にタイプを設定し、指定された日付の前に日付を要求します。 |
| requireDateBetween | DATE にタイプを設定し、指定した範囲内で日付を要求します。 |
| requireDateEqualTo | DATE にタイプを設定し、指定された日付に等しい日付を要求します。 |
| requireDateNotBetween | 型を DATE に設定し、指定された範囲の外側の日付を要求します。 |
| requireDateOnOrAfter | DATE にタイプを設定し、指定された日付以降に日付を要求します。 |
| requireDateOnOrBefore | DATE にタイプを設定し、指定された日付の前後に日付を要求します。 |
| requireFormulaSatisfied | `true` に評価するために与えられた式を要求して下さい。 |
| requireNumberBetween | 与えられた数字の2つの数字の間に数を要求します。 |
| requireNumberEqualTo | 与えられた値に等しい番号を要求して下さい。 |
| requireNumberGreaterThan | 指定した値よりも大きい数を要求します。 |
| requireNumberGreaterThanOrEqualTo | 指定した値よりも、または等しい数値を要求します。 |
| requireNumberLessThan | 指定した値よりも少ない数値を要求します。 |
| requireNumberLessThanOrEqualTo | 与えられた値に数以下または等しい値が要求されます。 |
| requireNumberNotBetween | 与えられた2つの数字とどちらかに等しくない番号を要求します。 |
| requireNumberNotEqualTo | 与えられた値に等しい番号を要求して下さい。 |
| requireValueInList | 特定の値のリストから値を必要とします。単一/複数の選択をサポートし、ドロップダウンを表示または非表示にします。 |
| requireValueInRange | 特定の範囲内の値が必要です。単一/複数の選択をサポートし、ドロップダウンを表示または非表示にします。 |
| setOptions | ルールのオプションを設定します。 |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 範囲 A1:B10 に対して 1 から 10 の数値を要求する新しいデータ検証ルールを作成します。
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: 'Please enter a number between 1 and 10',
  })
  .build()
fRange.setDataValidation(rule)
```

### 範囲 / ワークシート のデータ検証の取得

返された規則オブジェクトは、ルールの基準、オプション、その他の設定を明示する`FDataValidation`インスタンスです。

[`FDataValidation`](https://docs.univer.ai/reference/facade/data-validation)の主な方法は次のとおりです。

| Method | Description |
| ---- | ---- |
| copy | 現在のルールオブジェクトから新しいFDataValidationBuilderインスタンスを作成します。 |
| getCriteriaType | ルールのバリデーションタイプを取得します。 |
| getCriteriaValues | 基準を評価するために使用される値を取得します。 |
| getHelpText | ユーザーにガイダンスを提供するヘルプテキストを取得します。 |
| getRanges | ルールが適用される範囲を取得します。 |
| setCriteria | ルールの基準を設定します。 |
| setOptions | ルールのオプションを設定します。 |
| setRanges | ルールが適用される範囲を設定します。 |
| delete | ワークシートからルールを削除します。 |

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 現在のシートのすべてのデータ検証ルールを取得します
const rulesOfSheet = fWorksheet.getDataValidations()

// ルール ID でデータ検証ルールを取得します
const ruleById = fWorksheet.getDataValidation(rulesOfSheet[0]?.rule?.uid)

const fRange = fWorksheet.getRange('A1:B10')

// 現在の範囲の最初のデータ検証ルールを取得します
const ruleOfRange = fRange.getDataValidation()
console.log('ruleOfRange:', ruleOfRange, ruleOfRange?.getCriteriaValues())

// 現在の範囲のすべてのデータ検証ルールを取得します
const rulesOfRange = fRange.getDataValidations()
```

### データ検証の更新 / 削除

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 範囲 A1:B10 に対して 20 と等しい値を要求する新しいデータ検証ルールを作成します
const fRange = fWorksheet.getRange('A1:B10')
const rule = univerAPI.newDataValidation()
  .requireNumberEqualTo(20)
  .build()
fRange.setDataValidation(rule)

const newRuleRange = fWorksheet.getRange('C1:D10')

// 3 秒後にルールを更新します
setTimeout(() => {
  fRange.getDataValidation()
    // 範囲を C1:D10 に変更します
    .setRanges([newRuleRange])
    // 条件を 1 から 10 の数値を要求するように変更します
    .setCriteria(
      univerAPI.Enum.DataValidationType.DECIMAL,
      [univerAPI.Enum.DataValidationOperator.BETWEEN, '1', '10'],
    )
    // バリデーションエラー時に入力を止め、エラーメッセージを表示するようにオプションを変更します
    .setOptions({
      allowBlank: true,
      showErrorMessage: true,
      error: 'Please enter a valid value',
      errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
    })
}, 3000)

// 6 秒後にルールを削除します
setTimeout(() => {
  newRuleRange.getDataValidation().delete()
}, 6000)
```

### 検証エラーの取得

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// 現在のワークブックのすべてのデータ検証エラーを取得します
const workbookErrors = await fWorkbook.getAllDataValidationErrorAsync()
console.log('workbookErrors:', workbookErrors)

// 現在のシートのすべてのデータ検証エラーを取得します
const worksheetErrors = await fWorksheet.getAllDataValidationErrorAsync()
console.log('worksheetErrors:', worksheetErrors)

// 現在の範囲のデータ検証エラーを取得します
const fRange = fWorksheet.getRange('A1:B10')
const rangeErrors = await fRange.getDataValidationErrorAsync()
console.log('rangeErrors:', rangeErrors)
```

各エラーオブジェクトには以下のフィールドが含まれます：
- `sheetName`: エラーが発生したワークシートの名前
- `row`: エラーをトリガーしたセルの行インデックス
- `column`: エラーをトリガーしたセルのカラムのインデックス
- `ruleId`: エラーをトリガーしたルールのID
- `inputValue`: エラーをトリガーした入力値
- `rule`:ルールコンテンツのスナップショット

### バリデータの状態を取得

バリデータのステータスは、`DataValidationStatus`の列の値です。
- `valid`：セルの値が検証を通過しました
- `invalid`：セルの値が検証に失敗しました
- `validating`：セルが検証中です

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// ワークブックのデータ検証バリデータの状態を取得します
fWorkbook.getValidatorStatus().then((status) => {
  console.log('===statusOfWorkbook', status)
})

// シートのデータ検証バリデータの状態を取得します
fWorksheet.getValidatorStatusAsync().then((status) => {
})

// 範囲のデータ検証バリデータの状態を取得します
const fRange = fWorksheet.getRange('A1:B10')
fRange.getValidatorStatus().then((status) => {
  console.log('===tatusOfRange', status)
})
```

### イベントリスナー

[イベント](https://docs.univer.ai/reference/facade/events) では、イベント型の完全な定義が整っています。

データ検証モジュールは、ルールの追加、更新、削除、および検証状況の変更時にイベントを発します。これらのイベントのいずれかを聴くために、`univerAPI.addEvent()`を使用してください。

#### ルール変更イベント

`univerAPI.Event.SheetDataValidationChanged`は検証ルールの変更後に火を打ちます。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidationChanged, (params) => {
  const { origin, worksheet, workbook, changeType, oldRule, rule } = params
})

// イベントリスナーを削除するには `disposable.dispose()` を使用します
```

`univerAPI.Event.BeforeSheetDataValidationAdd`はルールが加えられる前に火を始動させます。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationAdd, (params) => {
  const { worksheet, workbook, rule } = params

  // データ検証ルールの追加をキャンセルします
  params.cancel = true
})

// イベントリスナーを削除するには `disposable.dispose()` を使用します
```

`univerAPI.Event.BeforeSheetDataValidationDelete`はルールが削除される前に火災します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDelete, (params) => {
  const { worksheet, workbook, ruleId, rule } = params

  // データ検証ルールの削除をキャンセルします
  params.cancel = true
})

// イベントリスナーを削除するには `disposable.dispose()` を使用します
```

`univerAPI.Event.BeforeSheetDataValidationDeleteAll`は、すべての規則が削除される前に火災します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationDeleteAll, (params) => {
  const { worksheet, workbook, rules } = params

  // データ検証ルールの削除をキャンセルします
  params.cancel = true
})

// イベントリスナーを削除するには `disposable.dispose()` を使用します
```

#### ルール更新イベント

`univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate`はルールの基準が変更される前に火災します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationCriteriaUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newCriteria } = params

  // データ検証ルールの条件更新をキャンセルします
  params.cancel = true
})

// イベントリスナーを削除するには `disposable.dispose()` を使用します
```

`univerAPI.Event.BeforeSheetDataValidationRangeUpdate`は規則の範囲の変更の前に消火します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationRangeUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newRanges } = params

  // データ検証ルールの範囲更新をキャンセルします
  params.cancel = true
})

// イベントリスナーを削除するには `disposable.dispose()` を使用します
```

`univerAPI.Event.BeforeSheetDataValidationOptionsUpdate`はルールのオプションが変更される前に火災します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeSheetDataValidationOptionsUpdate, (params) => {
  const { worksheet, workbook, ruleId, rule, newOptions } = params

  // データ検証ルールのオプション更新をキャンセルします
  params.cancel = true
})

// イベントリスナーを削除するには `disposable.dispose()` を使用します
```

#### バリデーション状態イベント

`univerAPI.Event.SheetDataValidatorStatusChanged`は、セルの検証ステータスが変更されたときに発火します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetDataValidatorStatusChanged, (params) => {
  const { worksheet, workbook, row, column, status, rule } = params
})

// イベントリスナーを削除するには `disposable.dispose()` を使用します
```

各イベントには、以下の共通パラメータが含まれます。
- `workbook`: 現在のワークブックインスタンス
- `worksheet`: 現在のワークシートインスタンス

いくつかのイベントも含まれます:
- `rule`: 関連するデータ検証ルールオブジェクト
- `ruleId`:ルールのユニークな識別子
- `status`:検証ステータス(`SheetDataValidatorStatusChanged`のみ)
- `newCriteria`:新しい検証基準(`BeforeSheetDataValidationCriteriaUpdate`のみ)
- `newRanges`:新しい検証範囲(`BeforeSheetDataValidationRangeUpdate`のみ)
- `newOptions`:新しい検証オプション(`BeforeSheetDataValidationOptionsUpdate`のみ)

`Before` で名前が始まっていれば、コールバックに `params.cancel = true`をセットして動作を停止します。

### エラースタイル

`errorStyle`は、無効なデータが入力されたときに何が起こるかを制御します。`DataValidationErrorStyle`値を受け入れる:
- `STOP`: 無効なエントリの拒否
- `WARNING`: 無効なエントリを受け入れ、警告を表示
- `INFO`: 無効なエントリを受け入れ、情報メッセージが表示されます

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B10')

const rule = univerAPI.newDataValidation()
  .requireNumberBetween(1, 10)
  .setOptions({
    allowBlank: true,
    showErrorMessage: true,
    error: '1 から 10 の間の数値を入力してください',
    errorStyle: univerAPI.Enum.DataValidationErrorStyle.STOP,
  })
  .build()
fRange.setDataValidation(rule)
```

### 変更リストのレンダーモード設定

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B10')

fRange.getDataValidation()?.setOptions({
  // support TEXT, ARROW, CUSTOM
  // default is `CUSTOM`
  renderMode: univerAPI.Enum.DataValidationRenderMode.TEXT,
})
```
