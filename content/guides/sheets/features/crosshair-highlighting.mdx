Crosshair highlighting marks the row and the column of the selected cell, which makes the active cell easy to identify.

<PlaygroundFrame lang="en-US" slug="sheets/crosshair-highlighting" clickToShow />

## Plugin mode

### Installation

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### Usage

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight'
import SheetsCrosshairHighlightEnUS from '@univerjs/sheets-crosshair-highlight/locale/en-US'
import '@univerjs/sheets-crosshair-highlight/lib/index.css'
import '@univerjs/sheets-crosshair-highlight/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsCrosshairHighlightEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsCrosshairHighlightPlugin) // [!code ++]
```

## Mobile support [#mobile-support]

Configure the [mobile editor](/guides/sheets/getting-started/installation#mobile-support) first. In the plugin-mode setup on this page, replace the desktop registrations below with the mobile exports from the same packages, and complete the replacement **before opening a document**. Keep the model plugins, styles, locales, and Facade imports, and do not register both variants.

## Preset mode

Crosshair highlighting does not provide a preset of its own, but its plugin can be added alongside a preset.

```package-install
npm install @univerjs/sheets-crosshair-highlight
```

### Usage

```typescript
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsCrosshairHighlightPlugin } from '@univerjs/sheets-crosshair-highlight' // [!code ++]
import '@univerjs/sheets-crosshair-highlight/facade' // [!code ++]
import '@univerjs/sheets-crosshair-highlight/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      SheetsCrosshairHighlightEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
  ],
  plugins: [
    UniverSheetsCrosshairHighlightPlugin, // [!code ++]
  ],
})
```

## Facade API

Complete Facade API type definitions are in [FacadeAPI](/reference/facade).

### Importing

<Callout type="info" title="Plugin mode note">
  The Facade package is imported manually only in plugin mode. Preset mode already includes it, so no additional import is required.
</Callout>

```typescript
import '@univerjs/sheets-crosshair-highlight/facade'
```

### Toggle crosshair highlight

```typescript
univerAPI.setCrosshairHighlightEnabled(true)

univerAPI.setCrosshairHighlightEnabled(false)
```

### Get crosshair highlight enabled status

```typescript
univerAPI.getCrosshairHighlightEnabled()
```

### Event listeners

Complete event type definitions are in [Events](https://docs.univer.ai/reference/facade/events).

`CrosshairHighlightEnabledChanged` fires when crosshair highlighting is enabled or disabled.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CrosshairHighlightEnabledChanged, (params) => {
  const { enabled, workbook, worksheet } = params
})

// Remove the event listener using `disposable.dispose()`
```
