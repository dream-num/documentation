ソートは、スプレッドシートデータを選択した順序で整理し、分析しやすくなります。 昇順、降下、カスタムソートがサポートされていますので、必要なデータは見つけやすくなります。

## プラグインモード

### インストール

```package-install
npm install @univerjs/sheets-sort @univerjs/sheets-sort-ui
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverSheetsSortPlugin } from '@univerjs/sheets-sort' // [!code ++]
import { UniverSheetsSortUIPlugin } from '@univerjs/sheets-sort-ui' // [!code ++]
import SheetsSortUIJaJP from '@univerjs/sheets-sort-ui/locale/ja-JP' // [!code ++]

import '@univerjs/sheets-sort-ui/lib/index.css' // [!code ++]

import '@univerjs/sheets-sort/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      SheetsSortUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsSortPlugin) // [!code ++]
univer.registerPlugin(UniverSheetsSortUIPlugin) // [!code ++]
```

## 並べ替え順序

昇順では、値が種類ごとにまとめられます。数値、テキスト、論理値、エラーの順です。空白セルはどちらの方向でも最後になります。テキストは `-` と `'` を無視したうえで大文字と小文字を区別せずに比較されます。`FRange.sort()` と `FWorksheet.sort()` はこの順序を使用し、すべてのエラー値は等しいものとして比較されます。

## Facade API

完全なFacade APIタイプ定義は[FacadeAPI](/reference/facade)にあります。

### インポート

<Callout type="info" title="プラグインモード注意">
  Facade パッケージの手動 import が必要なのはプラグインモードのみです。プリセットモードには対応する Facade パッケージが内蔵されているため、追加の import は不要です。
</Callout>

```typescript
import '@univerjs/sheets-sort/facade'
```

### ワークシートの並べ替え

[`FWorksheet.sort(colIndex, asc)`](https://docs.univer.ai/reference/facade/worksheet#sort) は指定した列でワークシートをソートします。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// ワークシートを第一列の昇順で並べ替え
fWorksheet.sort(0)

// ワークシートを第一列の降順で並べ替え
fWorksheet.sort(0, false)
```

### 範囲の並べ替え

[`FRange.sort(column)`](https://docs.univer.ai/reference/facade/range#sort)は、指定した列と順序で範囲内のセルをソートします。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('D1:G10')

// ワークシートを第一列の昇順で並べ替え
fRange.sort(0)

// ワークシートを第一列の降順で並べ替え
fRange.sort({ column: 0, ascending: false })

// ワークシートを第一列の降順、第二列の昇順で並べ替え
fRange.sort([{ column: 0, ascending: false }, 1])
```

### イベントリスナー

[イベント](https://docs.univer.ai/reference/facade/events) では、完全なイベント型定義が定義されています。

`SheetRangeSorted`は、範囲がソートされた後に火を発します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetRangeSorted, (params) => {
  const { workbook, worksheet, range, sortColumn } = params
})

// イベントリスナーを削除するには、`disposable.dispose()` を使用します。
```

`SheetBeforeRangeSort`は、範囲がソートされる前に火災します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetBeforeRangeSort, (params) => {
  const { workbook, worksheet, range, sortColumn } = params

  // ソート操作をキャンセル
  params.cancel = true
})

// イベントリスナーを削除するには、`disposable.dispose()` を使用します。
```
