スパークラインは、単一セルの中に置いた小さなチャートです。 これは、傾向やキーメトリックを一目で示します。

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/sheets-sparkline @univerjs-pro/sheets-sparkline-ui
```

### 使い方

```typescript
import { UniverSheetSparklinePlugin } from '@univerjs-pro/sheets-sparkline' // [!code ++]
import { UniverSheetSparklineUIPlugin } from '@univerjs-pro/sheets-sparkline-ui' // [!code ++]
import SheetsSparklineUIJaJP from '@univerjs-pro/sheets-sparkline-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-sparkline/facade' // [!code ++]

import '@univerjs-pro/sheets-sparkline-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      SheetsSparklineUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetSparklinePlugin)
univer.registerPlugin(UniverSheetSparklineUIPlugin)
```

Univer ライセンスが商用の場合、設定の [クライアントでのライセンスの使用](/server/license#in-plugin-mode)を参照してください。

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/sheets/getting-started/installation#mobile-support)を最初にセットアップします。このページのプラグインモード設定では、同じパッケージ、**ドキュメントを開く前に**からモバイルエクスポートでデスクトップ登録を置き換えます。モデルプラグイン、スタイル、ロケール、ファサードのインポートをキープし、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/sheets-sparkline-ui` | `UniverSheetSparklineUIPlugin` | `UniverSheetSparklineMobileUIPlugin` |

## プリセットモード

`@univerjs/preset-sheets-advanced`プリセットには、すでにスパークラインが含まれています。

### インストール

<Callout>
  `@univerjs/preset-sheets-advanced`から`UniverSheetsAdvancedPreset`は、ランタイムで`UniverSheetsDrawingPreset`に依存しているため、`@univerjs/preset-sheets-drawing`を最初にインストールします。

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
import UniverPresetSheetsAdvancedJaJP from '@univerjs/preset-sheets-advanced/locales/ja-JP' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreJaJP from '@univerjs/preset-sheets-core/locales/ja-JP'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]
import UniverPresetSheetsDrawingJaJP from '@univerjs/preset-sheets-drawing/locales/ja-JP' // [!code ++]

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-advanced/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetSheetsCoreJaJP,
      UniverPresetSheetsDrawingJaJP, // [!code ++]
      UniverPresetSheetsAdvancedJaJP, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsDrawingPreset(), // [!code ++]
    UniverSheetsAdvancedPreset(), // [!code ++]
  ],

```

Univer ライセンスが商用の場合、設定の [クライアントでのライセンスの使用](/server/license#in-preset-mode)を参照してください。

## Facade API

### インポート

<Callout type="info" title="プラグインモードノート">
  プラグインモードのみ、Facadeパッケージを手動でインポートする必要があります。プリセットモードには、対応するファサードパッケージが含まれているため、追加のインポートは必要ありません。
</Callout>

```typescript
import '@univerjs-pro/sheets-sparkline/facade'
```

### スパークラインの追加

[`FWorksheet.addSparkline`](https://docs.univer.ai/reference/facade/worksheet#addsparkline)は、指定した範囲にスパークラインを追加し、それらを含む[`FSparklineGroup`](/reference/facade/sparkline-group)を返します。チャートの種類は省略可能で、既定値は`univerAPI.Enum.SparklineTypeEnum.LINE_CHART`です。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// スパークラインを A1:A7 からデータソースとして作成し、セル A10 に配置します。
const sourceRanges = [fWorksheet.getRange('A1:A7').getRange()]
const targetRanges = [fWorksheet.getRange('A10').getRange()]
const sparklineGroup = fWorksheet.addSparkline(sourceRanges, targetRanges)
```

`FSparklineGroup` は、対象範囲に対して作成されたすべてのスパークラインを所有します。そのメソッドはグループ全体のデータソース、構成、表示状態を変更し、グループのメンバーごとに1つのソース範囲と1つの対象範囲を受け取ります。単一のセルを操作するには、[`getSparklineByCell`](#スパークラインおよびスパークライングループの取得) を使用します。

```typescript
sparklineGroup?.changeDataSource([fWorksheet.getRange('B1:B7').getRange()], [fWorksheet.getRange('B10').getRange()])
sparklineGroup?.setConfig({ lineWidth: 3 })
```

グループのメソッドはグループ自身のセルとワークシートに対して動作するため、アクティブなシートや選択範囲を変更せずに、保持しているグループを更新できます。`setConfig()` はトップレベルの構成フィールドをマージします。`points` や `axis` などのネストしたオブジェクトは置き換えられます。

### スパークラインの合成と分解

[`FWorksheet.composeSparkline`](https://docs.univer.ai/reference/facade/worksheet#composesparkline)を使用して、スパークラインをグループにマージし、[`FWorksheet.unComposeSparkline`](https://docs.univer.ai/reference/facade/worksheet#uncomposesparkline)はグループを個々のスパークラインに分割します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// データソースを A1:A7 として、セル A10 にスパークラインを作成します。
fWorksheet.addSparkline(
  [fWorksheet.getRange('A1:A7').getRange()],
  [fWorksheet.getRange('A10').getRange()],
)

// データソースを B1:B7 として、セル B10 にスパークラインを作成します。
fWorksheet.addSparkline(
  [fWorksheet.getRange('B1:B7').getRange()],
  [fWorksheet.getRange('B10').getRange()],
)

// スパークラインをグループ化します。
fWorksheet.composeSparkline([fWorksheet.getRange('A10:B10').getRange()])
console.log(fWorksheet.getAllSubSparkline().size) // 1

// 3 秒後にスパークラインを分解します。
setTimeout(() => {
  fWorksheet.unComposeSparkline([fWorksheet.getRange('A10:B10').getRange()])
  console.log(fWorksheet.getAllSubSparkline().size) // 2
}, 3000)
```

### スパークラインおよびスパークライングループの取得

[`FWorksheet.getSparklineByCell`](https://docs.univer.ai/reference/facade/worksheet#getsparklinebycell)は、指定したセルで`FSparkline`インスタンスを返します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// スパークラインを A1:A7 からデータソースとして作成し、セル A10 に配置します。
const sourceRanges = [fWorksheet.getRange('A1:A7').getRange()]
const targetRanges = [fWorksheet.getRange('A10').getRange()]
fWorksheet.addSparkline(sourceRanges, targetRanges)

const sparkline = fWorksheet.getSparklineByCell(9, 0)
console.log('Cell A10: ', sparkline)
console.log('Cell A11: ', fWorksheet.getSparklineByCell(10, 0))
```

[`FWorksheet.getSparklineGroupByCell`](https://docs.univer.ai/reference/facade/worksheet#getsparklinegroupbycell)は、指定したセルで`FSparklineGroup`インスタンスを返します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// データソースを A1:A7 として、セル A10 にスパークラインを作成します。
fWorksheet.addSparkline(
  [fWorksheet.getRange('A1:A7').getRange()],
  [fWorksheet.getRange('A10').getRange()],
)

// データソースを B1:B7 として、セル B10 にスパークラインを作成します。
fWorksheet.addSparkline(
  [fWorksheet.getRange('B1:B7').getRange()],
  [fWorksheet.getRange('B10').getRange()],
)
console.log('Cell A10: ', fWorksheet.getSparklineGroupByCell(9, 0))

// 3 秒後にスパークラインを分解します。
setTimeout(() => {
  fWorksheet.composeSparkline([fWorksheet.getRange('A10:B10').getRange()])
  console.log('Cell A10: ', fWorksheet.getSparklineGroupByCell(9, 0))
}, 3000)
```

[`FSparkline`](https://docs.univer.ai/reference/facade/sparkline)インスタンスは、以下のメソッドを提供します。

| Method | Description |
| --- | --- |
| 変更データソース | 現在のセルのスパークラインのデータソースと配置を変更 |
| removeSparkline | 現在のセル内のスパークラインを削除します |

[`FSparklineGroup`](/reference/facade/sparkline-group)インスタンスは、以下のメソッドを提供します。

| Method | Description |
| --- | --- |
| 変更データソース | 現在のセルのスパークライングループのデータソースと配置を変更します。 |
| removeSparklineグループ | 現在のセルのスパークライングループを削除します。 |
| setConfig | 現在のセル内のスパークライングループの構成を変更します |

### イベントリスナー

イベントの型定義については、[Events](https://docs.univer.ai/reference/facade/events) を参照してください。

`univerAPI.Event.SheetSparklineChanged`は、火花が変化する時に火を打ちます。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetSparklineChanged, (params) => {
  const { workbook, worksheet, sparklines } = params
})

// イベントリスナーを削除するには、`disposable.dispose()` を使用します。
```

## 色と表示オプション

`FSparklineGroup.setConfig()`を通してグループ全体のための色そして表示の選択は置かれます。注文色を使用するためには、`seriesColor`および`themeType: SparklineThemeTypeEnum.CUSTOM`両方を置いて下さい。[スパークライングループ構成](/reference/facade/sparkline-group)のページはフル オプションのテーブルおよび例、カバーポイント マーカー、車軸、空の価値、隠された細胞およびライン幅を含んでいます。
