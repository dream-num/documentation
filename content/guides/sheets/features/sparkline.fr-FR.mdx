Une scintillante est un petit graphique placé à l'intérieur d'une seule cellule. Il montre une tendance ou une métrique clé en un coup d'oeil.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/sheets-sparkline @univerjs-pro/sheets-sparkline-ui
```

### Utilisation

```typescript
import { UniverSheetSparklinePlugin } from '@univerjs-pro/sheets-sparkline' // [!code ++]
import { UniverSheetSparklineUIPlugin } from '@univerjs-pro/sheets-sparkline-ui' // [!code ++]
import SheetsSparklineUIEnUS from '@univerjs-pro/sheets-sparkline-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-sparkline/facade' // [!code ++]

import '@univerjs-pro/sheets-sparkline-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      SheetsSparklineUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetSparklinePlugin)
univer.registerPlugin(UniverSheetSparklineUIPlugin)
```

Si votre licence Univer est commerciale, consultez [Utilisation de la licence dans le client](/server/license#in-plugin-mode) pour la configuration.

### Ajouter un mini-graphique

[`FWorksheet.addSparkline`](https://docs.univer.ai/reference/facade/worksheet#addsparkline) ajoute des mini-graphiques dans les plages données et renvoie l'instance [`FSparklineGroup`](/reference/facade/sparkline-group) qui les contient. Le type de graphique est facultatif et vaut par défaut `univerAPI.Enum.SparklineTypeEnum.LINE_CHART`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a sparkline with data source from A1:A7, placed in cell A10.
const sourceRanges = [fWorksheet.getRange('A1:A7').getRange()]
const targetRanges = [fWorksheet.getRange('A10').getRange()]
const sparklineGroup = fWorksheet.addSparkline(sourceRanges, targetRanges)
```

Une instance `FSparklineGroup` gère tous les mini-graphiques créés pour les plages cibles. Ses méthodes modifient la source de données, la configuration ou la visibilité de tout le groupe et prennent une plage source et une plage cible par membre du groupe. Utilisez [`getSparklineByCell`](#obtenir-des-instances-de-mini-graphique-et-de-groupe-de-mini-graphiques) pour agir sur une seule cellule.

```typescript
sparklineGroup?.changeDataSource([fWorksheet.getRange('B1:B7').getRange()], [fWorksheet.getRange('B10').getRange()])
sparklineGroup?.setConfig({ lineWidth: 3 })
```

Les méthodes de groupe agissent sur les cellules et la feuille de calcul du groupe lui-même, ce qui permet de mettre à jour un groupe déjà détenu sans changer la feuille active ni la sélection. `setConfig()` fusionne les champs de configuration de premier niveau. Les objets imbriqués tels que `points` et `axis` sont remplacés.

### Regrouper et dissocier des mini-graphiques

Utilisez [`FWorksheet.composeSparkline`](https://docs.univer.ai/reference/facade/worksheet#composesparkline) pour fusionner les lignes lumineuses dans un groupe, et [`FWorksheet.unComposeSparkline`](https://docs.univer.ai/reference/facade/worksheet#uncomposesparkline), pour diviser le groupe en lignes lumineuses individuelles.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a sparkline in A10 with the data source in A1:A7.
fWorksheet.addSparkline(
  [fWorksheet.getRange('A1:A7').getRange()],
  [fWorksheet.getRange('A10').getRange()],
)

// Create a sparkline in B10 with the data source in B1:B7.
fWorksheet.addSparkline(
  [fWorksheet.getRange('B1:B7').getRange()],
  [fWorksheet.getRange('B10').getRange()],
)

// Compose the two sparklines into a sparkline group
fWorksheet.composeSparkline([fWorksheet.getRange('A10:B10').getRange()])
console.log(fWorksheet.getAllSubSparkline().size) // 1

// After 3 seconds, uncompose the sparkline group
setTimeout(() => {
  fWorksheet.unComposeSparkline([fWorksheet.getRange('A10:B10').getRange()])
  console.log(fWorksheet.getAllSubSparkline().size) // 2
}, 3000)
```

### Obtenir des instances de mini-graphique et de groupe de mini-graphiques

[`FWorksheet.getSparklineByCell`](https://docs.univer.ai/reference/facade/worksheet#getsparklinebycell) retourne l'instance `FSparkline` dans une cellule donnée.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a sparkline with data source from A1:A7, placed in cell A10.
const sourceRanges = [fWorksheet.getRange('A1:A7').getRange()]
const targetRanges = [fWorksheet.getRange('A10').getRange()]
fWorksheet.addSparkline(sourceRanges, targetRanges)

const sparkline = fWorksheet.getSparklineByCell(9, 0)
console.log('Cell A10: ', sparkline)
console.log('Cell A11: ', fWorksheet.getSparklineByCell(10, 0))
```

[`FWorksheet.getSparklineGroupByCell`](https://docs.univer.ai/reference/facade/worksheet#getsparklinegroupbycell) retourne l'instance `FSparklineGroup` dans une cellule donnée.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a sparkline in A10 with the data source in A1:A7.
fWorksheet.addSparkline(
  [fWorksheet.getRange('A1:A7').getRange()],
  [fWorksheet.getRange('A10').getRange()],
)

// Create a sparkline in B10 with the data source in B1:B7.
fWorksheet.addSparkline(
  [fWorksheet.getRange('B1:B7').getRange()],
  [fWorksheet.getRange('B10').getRange()],
)
console.log('Cell A10: ', fWorksheet.getSparklineGroupByCell(9, 0))

// After 3 seconds, compose the two sparklines into a sparkline group
setTimeout(() => {
  fWorksheet.composeSparkline([fWorksheet.getRange('A10:B10').getRange()])
  console.log('Cell A10: ', fWorksheet.getSparklineGroupByCell(9, 0))
}, 3000)
```

Une instance [`FSparkline`](https://docs.univer.ai/reference/facade/sparkline) fournit ces méthodes :

| Méthode | Description |
| --- | --- |
| changementSource des données | Modifier la source de données et l'emplacement de l'étincelle dans la cellule actuelle |
| removeSparkline | Supprime le mini-graphique de la cellule active |

Une instance [`FSparklineGroup`](/reference/facade/sparkline-group) fournit ces méthodes :

| Méthode | Description |
| --- | --- |
| changementSource des données | Modifier la source de données et l'emplacement du groupe d'étincelles dans la cellule actuelle |
| supprimerSparklineGroup | Supprimer le groupe d'étincelles dans la cellule actuelle |
| setConfig | Modifie la configuration du groupe de mini-graphiques dans la cellule active |

### Écouteurs d’événements

Consultez les définitions complètes des types d’événements dans [Events](https://docs.univer.ai/reference/facade/events).

`univerAPI.Event.SheetSparklineChanged` s'allume lorsqu'une ligne d'étincelles change.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetSparklineChanged, (params) => {
  const { workbook, worksheet, sparklines } = params
})

// Remove the event listener, use `disposable.dispose()`
```

## Couleurs et options d’affichage

Les couleurs et les options d'affichage pour un groupe entier sont définies par `FSparklineGroup.setConfig()`. Pour utiliser une couleur personnalisée, définissez à la fois `seriesColor` et `themeType: SparklineThemeTypeEnum.CUSTOM` . La page [configuration du groupe d'étincelles](/reference/facade/sparkline-group) contient la table d'option complète et un exemple, couvrant les marqueurs de points, axes, extrema, valeurs vides, cellules cachées et largeur de ligne.
