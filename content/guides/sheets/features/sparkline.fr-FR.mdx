Un mini-graphique est un graphique compact intégré qui représente visuellement les tendances des données ou des indicateurs clés, généralement dans une cellule de tableau.

## Mode prédéfini

La fonctionnalité de mini-graphiques est incluse dans le preset `@univerjs/preset-sheets-advanced`.

### Installation

<Callout>
  Le preset `UniverSheetsAdvancedPreset` de `@univerjs/preset-sheets-advanced` dépend du preset `UniverSheetsDrawingPreset` lors de l’exécution. Installez d’abord `@univerjs/preset-sheets-drawing`.
</Callout>

```package-install
npm install @univerjs/preset-sheets-drawing @univerjs/preset-sheets-advanced
```

### Utilisation

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced' // [!code ++]
import UniverPresetSheetsAdvancedEnUS from '@univerjs/preset-sheets-advanced/locales/en-US' // [!code ++]
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing' // [!code ++]
import UniverPresetSheetsDrawingEnUS from '@univerjs/preset-sheets-drawing/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-sheets-advanced/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsDrawingEnUS, // [!code ++]
      UniverPresetSheetsAdvancedEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverSheetsCorePreset(),
    UniverSheetsDrawingPreset(), // [!code ++]
    UniverSheetsAdvancedPreset(), // [!code ++]
  ],
})
```

Si vous disposez d’une licence commerciale Univer, consultez [Utiliser une licence côté client](/guides/pro/license#in-preset-mode) pour la configuration.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/sheets-graphics @univerjs-pro/sheets-sparkline @univerjs-pro/sheets-sparkline-ui
```

`@univerjs-pro/sheets-graphics` fournit la couche de rendu graphique dans les cellules utilisée par l’interface des mini-graphiques.

### Utilisation

```typescript
import { UniverSheetsGraphicsPlugin } from '@univerjs-pro/sheets-graphics' // [!code ++]
import { UniverSheetSparklinePlugin } from '@univerjs-pro/sheets-sparkline' // [!code ++]
import { UniverSheetSparklineUIPlugin } from '@univerjs-pro/sheets-sparkline-ui' // [!code ++]
import SheetsSparklineUIEnUS from '@univerjs-pro/sheets-sparkline-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/sheets-sparkline/facade' // [!code ++]

import '@univerjs-pro/sheets-sparkline-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.En_US,
  locales: {
    [LocaleType.En_US]: mergeLocales(
      SheetsSparklineUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverSheetsGraphicsPlugin)
univer.registerPlugin(UniverSheetSparklinePlugin)
univer.registerPlugin(UniverSheetSparklineUIPlugin)
```

Si vous disposez d’une licence commerciale Univer, consultez [Utiliser une licence côté client](/guides/pro/license#in-plugin-mode) pour la configuration.

## Facade API

### Importation

<Callout type="info" title="Remarque sur le mode plugin">
  Seul le mode plugin nécessite l’importation manuelle du package Facade. Le mode prédéfini inclut déjà le package Facade correspondant : aucune importation supplémentaire n’est nécessaire.
</Callout>

```typescript
import '@univerjs-pro/sheets-sparkline/facade'
```

### Ajouter un mini-graphique

La méthode [`FWorksheet.addSparkline`](https://docs.univer.ai/reference/facade/worksheet#addsparkline) ajoute un mini-graphique dans la plage indiquée et renvoie une instance de `FSparkline`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a sparkline with data source from A1:A7, placed in cell A10.
const sourceRanges = [fWorksheet.getRange('A1:A7').getRange()]
const targetRanges = [fWorksheet.getRange('A10').getRange()]
const sparkline = fWorksheet.addSparkline(sourceRanges, targetRanges, univerAPI.Enum.SparklineTypeEnum.LINE_CHART)
```

### Regrouper et dissocier des mini-graphiques

Les méthodes [`FWorksheet.composeSparkline`](https://docs.univer.ai/reference/facade/worksheet#composesparkline) et [`FWorksheet.unComposeSparkline`](https://docs.univer.ai/reference/facade/worksheet#uncomposesparkline) permettent de regrouper et de dissocier des mini-graphiques.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a sparkline with data source from A1:A7, placed in cell A10.
const firstSparkline = fWorksheet.addSparkline(
  [fWorksheet.getRange('A1:A7').getRange()],
  [fWorksheet.getRange('A10').getRange()],
)

// Create a sparkline with data source from B1:B7, placed in cell B10.
const secondSparkline = fWorksheet.addSparkline(
  [fWorksheet.getRange('B1:B7').getRange()],
  [fWorksheet.getRange('B10').getRange()],
)

// Compose the two sparklines into a sparkline group
fWorksheet.composeSparkline([fWorksheet.getRange('A10:B10').getRange()])
console.log(fWorksheet.getAllSubSparkline().size) // 1

// After 3 seconds, uncompose the sparkline group
setTimeout(() => {
  fWorksheet.unComposeSparkline([fWorksheet.getRange('A10:B10').getRange()])
  console.log(fWorksheet.getAllSubSparkline().size) // 2
}, 3000)
```

### Obtenir des instances de mini-graphique et de groupe de mini-graphiques

[`FWorksheet.getSparklineByCell`](https://docs.univer.ai/reference/facade/worksheet#getsparklinebycell) récupère le mini-graphique d’une cellule donnée et renvoie une instance de `FSparkline`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a sparkline with data source from A1:A7, placed in cell A10.
const sourceRanges = [fWorksheet.getRange('A1:A7').getRange()]
const targetRanges = [fWorksheet.getRange('A10').getRange()]
const sparkline = fWorksheet.addSparkline(sourceRanges, targetRanges)

console.log('Cell A10: ', fWorksheet.getSparklineByCell(9, 0))
console.log('Cell A11: ', fWorksheet.getSparklineByCell(10, 0))
```

[`FWorksheet.getSparklineGroupByCell`](https://docs.univer.ai/reference/facade/worksheet#getsparklinegroupbycell) récupère le groupe de mini-graphiques d’une cellule donnée et renvoie une instance de `FSparklineGroup`.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Create a sparkline with data source from A1:A7, placed in cell A10.
const firstSparkline = fWorksheet.addSparkline(
  [fWorksheet.getRange('A1:A7').getRange()],
  [fWorksheet.getRange('A10').getRange()],
)

// Create a sparkline with data source from B1:B7, placed in cell B10.
const secondSparkline = fWorksheet.addSparkline(
  [fWorksheet.getRange('B1:B7').getRange()],
  [fWorksheet.getRange('B10').getRange()],
)
console.log('Cell A10: ', fWorksheet.getSparklineGroupByCell(9, 0))

// After 3 seconds, compose the two sparklines into a sparkline group
setTimeout(() => {
  fWorksheet.composeSparkline([fWorksheet.getRange('A10:B10').getRange()])
  console.log('Cell A10: ', fWorksheet.getSparklineGroupByCell(9, 0))
}, 3000)
```

Une instance de [`FSparkline`](https://docs.univer.ai/reference/facade/sparkline) propose les méthodes suivantes pour manipuler le mini-graphique :

| Méthode | Description |
| --- | --- |
| changeDataSource | Modifie la source de données et l’emplacement du mini-graphique dans la cellule active
| removeSparkline | Supprime le mini-graphique de la cellule active |

Une instance de [`FSparklineGroup`](https://docs.univer.ai/reference/facade/sparkline) propose les méthodes suivantes pour manipuler le groupe de mini-graphiques :

| Méthode | Description |
| --- | --- |
| changeDataSource | Modifie la source de données et l’emplacement du groupe de mini-graphiques dans la cellule active
| removeSparklineGroup | Supprime le groupe de mini-graphiques de la cellule active
| setConfig | Modifie la configuration du groupe de mini-graphiques dans la cellule active |

### Écouteurs d’événements

Vous trouverez les définitions de types complètes des événements dans la documentation [Events](https://docs.univer.ai/reference/facade/events).

L’événement `univerAPI.Event.SheetSparklineChanged` est déclenché lorsqu’un mini-graphique change.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.SheetSparklineChanged, (params) => {
  const { workbook, worksheet, sparklines } = params
})

// Remove the event listener, use `disposable.dispose()`
```
