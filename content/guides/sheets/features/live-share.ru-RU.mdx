Функция совместной демонстрации позволяет во время коллективной работы синхронизировать с другими участниками действия в представлении — например, прокрутку и изменение выделения — или следить за представлением другого пользователя в реальном времени. Это особенно удобно для презентаций на встречах и учебных демонстраций.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/live-share
```

### Использование

```typescript
import { UniverLiveSharePlugin } from '@univerjs-pro/live-share' // [!code ++]
import { Univer } from '@univerjs/core'

import '@univerjs-pro/live-share/lib/index.css' // [!code ++]

import '@univerjs-pro/live-share/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverLiveSharePlugin)
```

Если у вас есть коммерческая лицензия Univer, инструкции по настройке см. в разделе [Использование лицензии в клиенте](/server/license#in-plugin-mode).

## Facade API

Функция совместной демонстрации расширяет соответствующие интерфейсы Facade API, которые можно вызывать напрямую через `univerAPI`.

### Импорт

```typescript
import '@univerjs-pro/live-share/facade'
```

### Перечисление состояний

```typescript
export enum LiveShareStatus {
  OFFLINE = 'offline',
  IDLE = 'idle',
  FOLLOWING = 'following',
  NOT_FOLLOWING = 'not-following',
  PRESENTING = 'presenting',
}
```

### Пример использования

```typescript
import { LiveShareStatus } from '@univerjs-pro/live-share'

// Get current status
const status = univerAPI.getLiveShareStatus()

if (status === LiveShareStatus.IDLE) {
  // If currently idle, start presenting
  univerAPI.startPresenting()
} else if (status === LiveShareStatus.PRESENTING) {
  // If presenting, stop presenting
  univerAPI.stopPresenting()
}

// Start following
univerAPI.startFollowing()

// Stop following
univerAPI.stopFollowing()
```
