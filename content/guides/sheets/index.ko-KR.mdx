## Univer Sheets란?

Univer Office SDK는 생산력 응용 프로그램을 구축하기위한 풀 스택 프레임 워크입니다. Univer 시트는 Web SDK에 내장 된 스프레드 시트 구성 요소입니다.

[Web SDK](/guides/sheets)는 스프레드 시트가 페이지에 내장되어 있거나 서버에서 헤드리스로 처리되는 경우 Univer 시트를 실행하는 엔진입니다. [Server SDK](/server)를 협업 및 파일 변환에 추가하고, [AI SDK](/ai)가 에이전트가 읽을 필요가 있고, 워크북을 작성할 때.

Univer 시트는 브라우저에서 실행되며 Node.js 서버에서 실행됩니다. 동일한 구성 요소는 작은 계산기와 엔터프라이즈 금융 모델을 모두 제공하며 외관과 행동은 응용 프로그램에 적용 할 수 있습니다.

## 브라우저 호환성

Web SDK는 Chrome 88에 대해 컴파일합니다. 이것은 빌드 대상입니다. 모든 주류 환경이 작동한다는 것을 보증하지 않습니다. 우리는 Web SDK를 브라우저에서 작동하도록 목표로하고 Node.js에 :

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK는 `Intl.Segmenter`에 달려 있습니다. 브라우저 또는 런타임이 제공되지 않는 경우, 해당 폴리필을 먼저 추가하십시오. `@formatjs/intl-segmenter`를 추천합니다.
</Callout>

호환성 문제가 발생하면 먼저 대응 폴 리필을 시도합니다. 문제가 발생하면 [자주 묻는 질문](https://github.com/dream-num/univer/issues/new/choose).

## Node.js 호환성

<Callout type="warning">
  이 섹션은 Node.js 내부 Web SDK를 실행합니다. 브라우저의 Node.js 기반 빌드 도구 번들 Web SDK가 적용되지 않습니다.
</Callout>

Web SDK는 Node.js v18.17.0 이상에서 실행됩니다.

## 주요 기능

Univer 시트는 다음과 같은 기능을 가장 많이 포함합니다.

- 창조, 편집, 및 deleting 세포, 줄 및 열.
- 수식과 세포의 계산 값.
- 설정 번호 형식.
- 검증된 데이터 및 적용 조건 서식.
- 필터링 및 정렬.
- 통제 권한.
- 이미지 삽입.
- 추가 기능.

[제품 설명](/guides/sheets/features/core) 페이지는 이러한 기능을 자세히 설명합니다.

## 문서 읽는 방법

왼쪽의 navbar는 기본에서 고급으로 읽는 순서에 문서를 나열합니다. 그 순서가 필요하지 않다는 것을 따르십시오: 당신은 당신의 사용 케이스에 적용하는 페이지에 똑똑하게 이동할 수 있습니다. Univer 시트 스위처는 사이드바의 상단에 있습니다.

페이지의 현재 위치를 추적 오른쪽의 내용의 테이블. 페이지를 빠르게 찾기 위해, 상단 또는 검색 단축키 (Ctrl + K 또는 Cmd + K)를 사용하여 검색 바를 사용합니다.

[빠른 시작](/guides/sheets/getting-started/installation)로 시작.

## 사전 지식

문서는 현대 JavaScript와 생태계에 익숙함을 가정합니다. Node.js에서 Web SDK를 실행하면 Node.js의 지식이 필요합니다.

브라우저에서 완전히 작동하면 백엔드 서비스가 필요하지 않습니다. 자신의 백엔드에서 [Univer Server SDK](/server)에서 필요한 모듈을 구성하여 협업, 공유 역사 또는 의견 및 파일 변환을 추가하십시오. 인증, 권한, 저장 및 배포는 응용 프로그램의 책임에 남아 있습니다.
