## Univer Sheets 是什么

Univer Office SDK 是一个用于构建生产力应用的全栈框架，Univer Sheets 是它的电子表格组件，基于 Web SDK。

[Web SDK](/guides/sheets) 是运行 Univer Sheets 的引擎，无论电子表格嵌入页面，还是在服务端无界面处理，都由它执行。需要协同与文件转换时，接入 [Server SDK](/server)；需要 Agent 读写工作簿时，使用 [AI SDK](/ai)。

Univer Sheets 可以在浏览器和 Node.js 服务端运行。同一个组件既可用于简单的计算器，也可用于企业级财务模型，其界面和行为可以按应用需要调整。

## 浏览器兼容性

Web SDK 的编译目标是 Chrome 88。这只是构建目标，并不意味着所有主流环境都受支持。我们力求让 Web SDK 在下列浏览器和 Node.js 环境中正常工作：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK 依赖 `Intl.Segmenter`。如果浏览器或运行时未提供它，请先补充对应的 polyfill，推荐使用 `@formatjs/intl-segmenter`。
</Callout>

如果遇到兼容性问题，请先尝试用对应的 polyfill 解决。如果问题仍然存在，请[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 兼容性

<Callout type="warning">
  本节介绍在 Node.js 中运行 Web SDK，不适用于使用基于 Node.js 的构建工具将 Web SDK 打包到浏览器中运行的情况。
</Callout>

Web SDK 可在 Node.js v18.17.0 及更高版本中运行。

## 主要功能

Univer Sheets 覆盖大多数应用需要的功能，包括：

- 创建、编辑和删除单元格、行、列。
- 使用公式计算单元格中的值。
- 设置数字格式。
- 数据验证和条件格式。
- 筛选和排序。
- 权限控制。
- 插入图片。
- 其他功能。

具体说明见[功能](/guides/sheets/features/core)下的各篇文档。

## 前置知识

本文档假设读者能阅读现代 JavaScript，并熟悉其生态系统。如需在 Node.js 上运行 Web SDK，还需要了解 Node.js。

完全在浏览器中编辑不需要任何后端服务。如需协同、共享历史或评论以及文件转换，请在自身的后端中组合 [Univer Server SDK](/server) 的相应模块；身份认证、权限、存储和部署仍由应用负责。

## 扩展 Univer Sheets

Web SDK 的设计目标是可扩展，而不只是提供配置项。[架构](/blog/univer)介绍了 Univer Sheets 的组成结构以及扩展点的位置。需要完整示例时，请阅读[如何编写 CSV 导入插件](/blog/csv-import-plugin)。
