## IWorksheetData

[`IWorksheetData`](/reference/types/worksheet-data) 表示 Univer Sheets 中工作表的快照。

### 屬性

| 屬性 | 類型 | 描述 |
|----------|------|-------------|
| id | `string` | 工作表的唯一識別碼。 |
| name | `string` | 工作表的名稱。 |
| tabColor | `string` | 工作表標籤的顏色。 |
| hidden | `BooleanNumber` | 工作表是否隱藏。預設值：`BooleanNumber.FALSE`。 |
| freeze | `IFreeze` | 凍結窗格設定。 |
| rowCount | `number` | 總列數。 |
| columnCount | `number` | 總欄數。 |
| defaultColumnWidth | `number` | 欄的預設寬度，單位 `px`。 |
| defaultRowHeight | `number` | 列的預設高度，單位 `px`。 |
| [mergeData](#merged-ranges) | `IRange[]` | 合併儲存格範圍的陣列。 |
| cellData | `IObjectMatrixPrimitiveType<ICellData>` | 儲存格內容的矩陣。[詳情](/guides/sheets/model/cell-data) |
| rowData | `IObjectArrayPrimitiveType<Partial<IRowData>>` | 列資料物件的陣列。 |
| columnData | `IObjectArrayPrimitiveType<Partial<IColumnData>>` | 欄資料物件的陣列。 |
| rowHeader | `{ width: number; hidden?: BooleanNumber; }` | 列標題設定。 |
| columnHeader | `{ height: number; hidden?: BooleanNumber; }` | 欄標題設定。 |
| backgroundImage? | `IWorksheetBackgroundImage` | 選用的平鋪圖片來源：`{ source: string; imageSourceType: ImageSourceType }`。參閱[背景圖](/guides/sheets/features/images#worksheet-background)。 |
| showGridlines | `BooleanNumber` | 是否顯示格線。 |
| rightToLeft | `BooleanNumber` | 工作表是否為由右至左模式。 |
| [defaultStyle](/guides/sheets/features/core/default-style)? | `Nullable<IStyleData>` | 預設工作表樣式 |

### 合併範圍：`mergeData` [#merged-ranges]

從業務資料建立活頁簿時，可用合併儲存格組織報表標題、分組表頭或跨列標籤。

`mergeData` 是 `IRange` 物件陣列。列與欄索引從 **0** 開始，結束索引都**包含在範圍內**。例如，`A1:C1` 對應 `{ startRow: 0, endRow: 0, startColumn: 0, endColumn: 2 }`；`A3:B4` 則涵蓋兩列兩欄。下方活頁簿可直接傳給 `createWorkbook()`。

```typescript
const workbook = univerAPI.createWorkbook({
  id: 'merge-demo',
  name: 'Merge demo',
  sheetOrder: ['summary'],
  sheets: {
    summary: {
      id: 'summary',
      name: 'Summary',
      rowCount: 20,
      columnCount: 8,
      mergeData: [
        { startRow: 0, endRow: 0, startColumn: 0, endColumn: 2 },
        { startRow: 2, endRow: 3, startColumn: 0, endColumn: 1 },
      ],
      cellData: {
        0: { 0: { v: 'Quarterly review' } },
        2: { 0: { v: 'Owner' } },
      },
    },
  },
})
```

顯示內容放在合併範圍的左上角儲存格。範圍不可超出工作表邊界或彼此重疊。建立後請透過[範圍合併 API](/reference/facade/range#merge)合併或取消合併，不要修改已儲存的 `mergeData` 陣列來編輯執行中的文件。

### 範例

```typescript
const worksheetData: IWorksheetData = {
  id: 'sheet1',
  name: '工作表 1',
  tabColor: '#FF0000',
  hidden: BooleanNumber.FALSE,
  freeze: { xSplit: 1, ySplit: 1, startRow: 1, startColumn: 1 },
  rowCount: 1000,
  columnCount: 26,
  defaultColumnWidth: 100,
  defaultRowHeight: 25,
  mergeData: [],
  cellData: {
    0: {
      0: {
        v: 123,
      },
    },
  },
  rowData: [],
  columnData: [],
  rowHeader: { width: 40 },
  columnHeader: { height: 20 },
  showGridlines: BooleanNumber.TRUE,
  rightToLeft: BooleanNumber.FALSE,
}
```

此結構提供了工作表資料的完整呈現，包含版面配置、內容與顯示設定。
