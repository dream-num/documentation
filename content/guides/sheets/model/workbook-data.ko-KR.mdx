## IWorkbookData

[`IWorkbookData`](/reference/types/workbook-data)는 Univer 시트의 워크북의 스냅 샷입니다.

### 속성

| 속성       | 타입                                             | 설명                                         |
| ---------- | ------------------------------------------------ | -------------------------------------------- |
| id | `string` | Workbook의 고유 식별자. |
| name | `string` | workbook의 이름. |
| appVersion | `string`                                         | Univer 모델 정의의 버전입니다.               |
| locale     | `LocaleType`                                     | 문서의 로캘입니다.                           |
| styles     | `Record<string, Nullable<IStyleData>>`           | 통합 문서의 스타일 참조입니다.               |
| sheetOrder | `string[]` | worksheet IDs, 순서에서 시트가 나타납니다. |
| sheets     | `{ [sheetId: string]: Partial<IWorksheetData> }` | 각 워크시트의 데이터를 담는 레코드입니다.    |
| resources? | `IResources` | 플러그인에 의해 소유 된 데이터. |

### 예시

```typescript
const workbookData: IWorkbookData = {
  id: 'unique-workbook-id',
  name: 'My Workbook',
  appVersion: '0.10.2',
  locale: LocaleType.EN_US,
  styles: {/* style definitions */},
  sheetOrder: ['sheet1', 'sheet2'],
  sheets: {
    sheet1: {/* sheet data */},
    sheet2: {/* sheet data */},
  },
}
```

### 사용법

Univer 시트는 IWorkbookData의 워크북 데이터를 저장합니다. 구조는 두 가지 상황에서 사용됩니다.

1. [IWorkbookData에서 워크북 만들기](/guides/sheets/features/core/sheets-api#create-worksheet)
2. [IWorkbookData로 워크북의 데이터를 저장](/guides/sheets/features/core/sheets-api#get-workbook-data)

`resources` 속성은 플러그인 소유 데이터를 보유합니다. [플러그인 사용자 정의 모델](/blog/custom-model)를 참조하십시오.
