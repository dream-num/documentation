## IWorkbookData

[`IWorkbookData`](https://reference.univer.ai/en-US/interfaces/IWorkbookData)는 Univer Sheets에서 통합 문서의 스냅샷을 나타냅니다.

### 속성

| 속성 | 타입 | 설명 |
|----------|------|-------------|
| id | `string` | Univer Sheets의 고유 식별자입니다. |
| name | `string` | Univer Sheets의 이름입니다. |
| appVersion | `string` | Univer 모델 정의의 버전입니다. |
| locale | `LocaleType` | 문서의 로캘입니다. |
| styles | `Record<string, Nullable<IStyleData>>` | 통합 문서의 스타일 참조입니다. |
| sheetOrder | `string[]` | 워크시트 순서를 나타내는 시트 ID 배열입니다. |
| sheets | `{ [sheetId: string]: Partial<IWorksheetData> }` | 각 워크시트의 데이터를 담는 레코드입니다. |
| resources? | `IResources` | 플러그인 데이터를 저장합니다. |

### 예시

```typescript
const workbookData: IWorkbookData = {
  id: 'unique-workbook-id',
  name: 'My Workbook',
  appVersion: '0.10.2',
  locale: LocaleType.EN_US,
  styles: { /* style definitions */ },
  sheetOrder: ['sheet1', 'sheet2'],
  sheets: {
    sheet1: { /* sheet data */ },
    sheet2: { /* sheet data */ },
  },
}
```

### 사용법

IWorkbookData는 Univer Sheets에서 데이터를 저장하는 데 사용하는 객체입니다. 주로 다음 용도로 사용합니다.

1. [IWorkbookData를 사용하여 Univer Sheets 만들기](/guides/sheets/features/core/sheets-api#create-worksheet)
2. [Univer Sheets에서 IWorkbookData 저장하기](/guides/sheets/features/core/sheets-api#get-workbook-data)

`resources` 속성은 플러그인 데이터를 저장하는 데 사용합니다. 자세한 내용은 [플러그인 사용자 정의 모델](/guides/recipes/tutorials/custom-model)을 참고하세요.
