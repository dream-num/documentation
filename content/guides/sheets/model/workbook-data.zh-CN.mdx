## IWorkbookData

[`IWorkbookData`](/reference/types/workbook-data) 表示 Univer Sheets 里一个工作簿的快照。

### 属性

| 属性       | 类型                                             | 描述                             |
| ---------- | ------------------------------------------------ | -------------------------------- |
| id         | `string`                                         | 工作簿的唯一标识符。             |
| name       | `string`                                         | 工作簿的名称。                   |
| appVersion | `string`                                         | Univer 模型定义的版本。          |
| locale     | `LocaleType`                                     | 文档的语言环境。                 |
| styles     | `Record<string, Nullable<IStyleData>>`           | 工作簿引用的样式。               |
| sheetOrder | `string[]`                                       | 工作表 ID 数组，按显示顺序排列。 |
| sheets     | `{ [sheetId: string]: Partial<IWorksheetData> }` | 每个工作表的数据。               |
| resources? | `IResources`                                     | 插件的数据。                     |

### 示例

```typescript
const workbookData: IWorkbookData = {
  id: 'unique-workbook-id',
  name: '我的工作簿',
  appVersion: '0.10.2',
  locale: LocaleType.ZH_CN,
  styles: {/* 样式定义 */},
  sheetOrder: ['sheet1', 'sheet2'],
  sheets: {
    sheet1: {/* 工作表数据 */},
    sheet2: {/* 工作表数据 */},
  },
}
```

### 使用

Univer Sheets 将工作簿数据存放在 IWorkbookData 中，主要用于两个场景：

1. [使用 IWorkbookData 创建工作簿](/guides/sheets/features/core/sheets-api#create-worksheet)
2. [将工作簿数据保存为 IWorkbookData](/guides/sheets/features/core/sheets-api#get-workbook-data)

`resources` 属性保存插件数据，详见[插件自定义模型](/blog/custom-model)。
