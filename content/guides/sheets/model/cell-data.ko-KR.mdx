## 셀 위치

Univer 시트는 [IWorksheet데이터](/reference/types/worksheet-data) 개체의 [셀데이터](/reference/types/worksheet-data#celldata) 필드에 세포 데이터를 저장합니다. 이 필드는 값, 스타일 및 유형을 포함하여 세포에 대한 모든 정보를 보유합니다.

아래 코드는 cellData의 모양을 보여줍니다.

```typescript
interface IWorksheetData {
  cellData: {
    // first row
    0: {
      // first column
      0: { v: 'A1' }
      // second column
      1: { v: 'B1' }
    }
    // second row
    1: {
      // first column
      0: { v: 'A2' }
      // second column
      1: { v: 'B2' }
    }
  }
}
```

## 셀 데이터

세포에는 다음과 같은 속성이 있습니다.

| 속성 | 설명 |
| --- | --- |
| v | 셀 원본 값 |
| s | 셀 스타일 ID 또는 스타일 객체 |
| t | 셀 타입 |
| p | 리치 텍스트이자 📝 Univer Docs |
| f | 수식 |
| si | 수식 ID |
| custom | 사용자 지정 필드 |

각 속성의 유형에 [ICell데이터](/reference/types/cell-data)를 참조하십시오.

### 셀 원본 값

`cellData.v`는 문자열이나 숫자 중 하나인 셀의 원래값을 보유하고 있습니다. 공식이 있는 셀에서는 `v`가 그 공식의 결과를 보유하고 있습니다.

아래 예제는 하나의 셀과 다른 숫자로 문자열을 저장합니다.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: { v: 'A1' }
      1: { v: 1 }
    }
  }
}
```

### 셀 스타일

`cellData.s`는 스타일 ID 또는 스타일 객체를 보유하고 있습니다.

`s`가 문자열이라면 스타일 ID입니다. Univer 시트는 참조로 스타일을 최적화하므로 반복 된 스타일 객체는 IWorkbookData의 [의 특징](/reference/types/workbook-data#styles) 필드에서 한 번 저장됩니다. 이 필드는 맵입니다. 각 키는 스타일 ID이며 각 값은 스타일 객체입니다.

<Callout type="warning">
  rgba와 같은 투명성을 수행하는 색상 값을 피하십시오. 그 종류의 배경이있는 세포가 편집 상태를 입력 할 때, 세포 밑단의 내용이 표시됩니다.
</Callout>

```typescript
interface IWorkbookData {
  styles: {
    random_style_id_1: {
      fs: 12
      bg: {
        rgb: '#ff0000'
      }
    }
  }
}
```

id가 아닌 셀 참조를 할 때 스타일 객체가 재사용됩니다.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        s: 'random_style_id_1'
      }
      1: {
        v: 'B1'
        s: 'random_style_id_1'
      }
    }
  }
}
```

`s`가 객체라면 완전한 스타일 객체([IStyle데이터](/reference/types/style-data))입니다.

스타일 필드는 아래에 나열되어 있습니다.

| 속성 | 설명 |
| --- | --- |
| ff | 글꼴 |
| fs | 글꼴 크기 |
| it | 기울임꼴 |
| bl | 굵게 |
| ul | 밑줄 |
| st | 취소선 |
| ol | 윗줄 |
| bg | 배경색 |
| bd | 테두리 |
| cl | 글꼴 색상 |
| va | 위 첨자 또는 아래 첨자 |
| tr | 텍스트 회전 |
| ht | 가로 맞춤 |
| vt | 세로 맞춤 |
| tb | 넘치는 텍스트 처리 |
| pd | 안쪽 여백 |
| n | 숫자 형식 |

각 필드의 유형에 [IStyle데이터](/reference/types/style-data)를 참조하십시오.

#### 글꼴

`ff`는 문자열로 글꼴 이름입니다.

```typescript
interface IStyleData {
  ff: 'Arial' // Font name is Arial
}
```

#### 글꼴 크기

`fs`는 **₢ 킹**의 번호입니다.

```typescript
interface IStyleData {
  fs: 12 // Font size is 12 pt
}
```

#### 기울임꼴

`it`는 불린 수입니다: `0`은 이탈을 의미하지 않으며 `1`가 이탈을 의미합니다.

```typescript
interface IStyleData {
  it: 1 // Italic
}
```

#### 굵게

`bl`는 불린 번호입니다: `0`은 대담하지 않으며 `1`가 대담한 것을 의미합니다.

```typescript
interface IStyleData {
  bl: 1 // Bold
}
```

#### 밑줄

`ul`는 밑줄 스타일을 설명하는 객체입니다.

```typescript
interface IStyleData {
  ul: {
    s: 1 // Whether to show underline
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Underline color
      rgb: '#ff0000'
    }
    t: 0 // Underline type
  }
}
```

#### 취소선

`st`는 획기적인 스타일을 설명하는 객체입니다.

```typescript
interface IStyleData {
  st: {
    s: 1 // Whether to show strikethrough
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Strikethrough color
      rgb: '#ff0000'
    }
    t: 0 // Strikethrough type
  }
}
```

#### 윗줄

`ol`는 오버라인 스타일을 설명하는 객체입니다.

```typescript
interface IStyleData {
  ol: {
    s: 1 // Whether to show overline
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Overline color
      rgb: '#ff0000'
    }
    t: 0 // Overline type
  }
}
```

#### 배경색

`bg`는 배경 색상을 설명하는 객체입니다.

```typescript
interface IStyleData {
  bg: {
    rgb: '#ff0000' // Background color is red
  }
}
```

#### 테두리

`bd`는 국경 스타일을 설명하는 객체입니다.

```typescript
interface IStyleData {
  bd: {
    // Top border
    t: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Bottom border
    b: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Left border
    l: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Right border
    r: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
  }
}
```

#### 글꼴 색상

`cl`는 글꼴 색상을 설명하는 객체입니다.

```typescript
interface IStyleData {
  cl: {
    rgb: '#ff0000' // Font color is red
  }
}
```

#### 위 첨자 또는 아래 첨자

`va`는 enum 수입니다: `1`는 정상적인, `2`는 subscript를 의미하고, `3`는 superscript를 의미합니다.

```typescript
interface IStyleData {
  va: 2 // Subscript
}
```

#### 텍스트 회전

`tr`는 텍스트 회전을 설명하는 객체입니다.

```typescript
interface IStyleData {
  tr: {
    a: 0 // Text rotation angle
    v: 0 // Whether it is vertical. 1 means vertical, 0 means horizontal. The default value is 0. When v is 1, a is invalid
  }
}
```

#### 가로 맞춤

`ht`는 enum 번호입니다: `1`가 왼쪽 정렬을 의미, `2`은 센터를 의미, 그리고 `3` 올바른 정렬을 의미합니다.

```typescript
interface IStyleData {
  ht: 1 // Left alignment
}
```

#### 세로 맞춤

`vt`는 enum 수입니다: `1`가 최고 정렬을 의미하는 `2`은 센터를 의미하며 `3`의 하단 정렬을 의미합니다.

```typescript
interface IStyleData {
  vt: 1 // Top alignment
}
```

#### 넘치는 텍스트 처리

`tb`는 enum 수입니다: `1`은 과잉 흐름을 의미하고, `2` 는 truncate를 의미하며, `3`가 포장을 의미합니다.

```typescript
interface IStyleData {
  tb: 1 // Overflow
}
```

#### 안쪽 여백

`pd`는 패딩을 설명하는 객체입니다.

```typescript
interface IStyleData {
  pd: {
    t: 0 // Top padding
    b: 0 // Bottom paddingAdd commentMore actions
    l: 0 // Left padding
    r: 0 // Right padding
  }
}
```

#### 숫자 형식 [#number-format]

`n`는 객체입니다. `pattern` 필드는 문자열로 번호 형식을 보유하고 있습니다. Microsoft 문서 형식 코드 [으로](https://support.microsoft.com/en-us/office/number-format-codes-5026bbd6-04bc-48cd-bf33-80f18b4eae68).

`n`가 `null` 인 경우 `pattern`는 `null`인 경우, 셀은 일반 형식을 사용합니다.

```typescript
import type { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

interface IStyleData {
  n: {
    pattern: DEFAULT_TEXT_FORMAT_EXCEL // text format
  }
}
```

0으로 시작하는 번호를 유지하려면, 또는 날짜 형식으로 변환 할 수, 변환 된에서 자동으로, [번호 포맷](/guides/sheets/features/core/numfmt#usage)를 참조하십시오.

### 셀 타입 [#cell-type]

`cellData.t`는 세포의 유형을 놓는 [CellValueType의 장점](/reference/enums/cell-value-type) enum입니다. `1` 는 문자열을 의미합니다, `2` 번호, `3` 불을 의미하고 `4` 힘 원본을 의미합니다. 필드가 설정되지 않을 때, Univer가 자동으로 유형을 인식합니다.

`0` 또는 `1` : `0`로 불린 셀 매장 `cellData.v`는 false를 의미하며 `1`가 true를 의미합니다.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        t: 1 // String
      }
      1: {
        v: 1
        t: 2 // Number
      }
      2: {
        v: 1 // TRUE
        t: 3 // Boolean
      }
      3: {
        v: '012.0'
        t: 4 // Force text
      }
    }
  }
}
```

힘 원본 경고와 표는 `disableForceStringAlert`와 `disableForceStringMark`에 의해 통제됩니다. 당신은 그(것)들을 안으로 구성할 수 있습니다:
  - [프리셋 모드](/guides/sheets/features/core#univerjspreset-sheets-core)
  - [플러그인 모드](/guides/sheets/features/core#univerjssheets-ui)

### 리치 텍스트

`cellData.p`는 풍부한 텍스트를 보유하는 객체이며, 그 객체는 Univer Doc 자체입니다. 전체 구조에 [IDocument데이터](/reference/types/document-data)를 참조하십시오.

<Callout>
  세포가 `p`와 `v` 세트 모두 있을 때, `p`의 내용만 표시됩니다.
</Callout>

`cellData.p.body.dataStream`는 풍부한 텍스트 콘텐츠입니다.

### 수식

`cellData.f`는 문자열로 저장되는 공식입니다.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // function SUM
      }
    }
  }
}
```

### 수식 ID

`cellData.si`는 공식 ID를 보유하는 문자열입니다. Univer 시트는 참고로 공식을 최적화합니다. 일단 세포는 `si`와 공식을 연결하면 다른 셀은 `si`를 통해 동일한 공식을 참조 할 수 있습니다. `si`가 참조 셀의 낮은 오른쪽 모서리에 있어야하는 세포는 그렇지 않으면 XLSX에 수출은 오류를 제기합니다.

Facade API `range.getFormulas()`를 호출하여 실제 공식을 얻을 수 있습니다. `f`가 `si` 포인트를 입력하고 현재 셀 위치와 참조 위치 사이의 오프셋에서 실제 공식을 계산합니다.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // Sum formula
        si: 'random_formula_id_1' // ID of the current formula
      }
      1: {
        si: 'random_formula_id_1' // Take the formula corresponding to this ID during calculation
      }
    }
  }
}
```

### 사용자 지정 필드

`cellData.custom`는 사용자 정의 필드 역할을 하는 객체입니다. 그것은 유효한 JSON이 있는 모든 데이터를 받아들일 수 있으므로 자신의 추가 정보를 저장할 수 있습니다.

`custom` 데이터를 업데이트하면 기존 `custom` 데이터가 merging보다 훨씬 적습니다. 기존 `custom` 자료를 유지하려면 먼저 `custom` 파일을 읽고 새로운 데이터로 병합하고 업데이트하십시오.

<Callout type="warning">
  `custom` 필드는 몇 가지 특수 시나리오에만 적용됩니다. 모든 사용자 작업이이 필드에 저장된 데이터를 삭제하거나 삭제할 수 있으므로 주의를 기울여야합니다.
</Callout>

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        custom: {
          key: 'value'
        }
      }
    }
  }
}
```
