## Положение ячейки

Univer Sheets хранит данные ячеек в поле [данные сотовой связи](/reference/types/worksheet-data#celldata) объекта [IWorksheetData](/reference/types/worksheet-data). В этом поле содержится вся информация о ячейке, включая ее значение, стиль и тип.

Приведенный ниже код показывает форму данных сотовой связи.

```typescript
interface IWorksheetData {
  cellData: {
    // first row
    0: {
      // first column
      0: { v: 'A1' }
      // second column
      1: { v: 'B1' }
    }
    // second row
    1: {
      // first column
      0: { v: 'A2' }
      // second column
      1: { v: 'B2' }
    }
  }
}
```

## Данные ячейки

Клетка обладает следующими свойствами.

| Свойство | Описание |
| --- | --- |
| v | Исходное значение ячейки |
| s | Идентификатор или объект стиля ячейки |
| t | Тип ячейки |
| p | Форматированный текст, который также является документом 📝 Univer Docs |
| f | Формула |
| si | Идентификатор формулы |
| custom | Пользовательское поле |

См. [ICellData](/reference/types/cell-data) для типа каждого объекта недвижимости.

### Исходное значение ячейки

`cellData.v` удерживает исходное значение ячейки, которая является либо строкой, либо числом.В ячейке, которая имеет формулу, `v` держит результат этой формулы.

Приведенный ниже пример хранит строку в одной ячейке и число в другой.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: { v: 'A1' }
      1: { v: 1 }
    }
  }
}
```

### Стиль ячейки

`cellData.s` содержит либо идентификатор стиля, либо объект стиля.

Когда `s` является строкой, это идентификатор стиля. Univer Sheets оптимизирует стили по ссылке, поэтому повторяющийся объект стиля хранится один раз, в поле [стили](/reference/types/workbook-data#styles) IWorkbookData. Это поле представляет собой карту: каждый ключ является идентификатором стиля, а каждое значение является объектом стиля.

<Callout type="warning">
  Избегайте цветовых значений, которые несут прозрачность, таких как rgba. Когда ячейка с таким фоном входит в состояние редактирования, содержимое ячейки под ним отображается.
</Callout>

```typescript
interface IWorkbookData {
  styles: {
    random_style_id_1: {
      fs: 12
      bg: {
        rgb: '#ff0000'
      }
    }
  }
}
```

Когда ячейка ссылается на этот идентификатор, объект стиля повторно используется.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        s: 'random_style_id_1'
      }
      1: {
        v: 'B1'
        s: 'random_style_id_1'
      }
    }
  }
}
```

Когда `s` является объектом, это объект полного стиля ([IStyleData](/reference/types/style-data)).

Поля стилей перечислены ниже.

| Свойство | Описание |
| --- | --- |
| ff | Шрифт |
| fs | Размер шрифта |
| it | Курсив |
| bl | Полужирное начертание |
| ul | Подчёркивание |
| st | Зачёркивание |
| ol | Надчёркивание |
| bg | Цвет фона |
| bd | Граница |
| cl | Цвет шрифта |
| va | Верхний или нижний индекс |
| tr | Поворот текста |
| ht | Выравнивание по горизонтали |
| vt | Выравнивание по вертикали |
| tb | Обработка текста, выходящего за границы |
| pd | Внутренние отступы |
| n | Числовой формат |

См. [IStyleData](/reference/types/style-data) для типа каждого поля.

#### Шрифт

`ff` - это название шрифта, как строка.

```typescript
interface IStyleData {
  ff: 'Arial' // Font name is Arial
}
```

#### Размер шрифта

`fs` — это число в **пт**.

```typescript
interface IStyleData {
  fs: 12 // Font size is 12 pt
}
```

#### Курсив

`it` - это булевое число: `0` означает не курсивом, а `1` значит курсивом.

```typescript
interface IStyleData {
  it: 1 // Italic
}
```

#### Полужирное начертание

`bl` — это булевое число: `0` означает не смелый, а `1` значит смелый.

```typescript
interface IStyleData {
  bl: 1 // Bold
}
```

#### Подчёркивание

`ul` — это объект, который описывает стиль подчеркивания.

```typescript
interface IStyleData {
  ul: {
    s: 1 // Whether to show underline
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Underline color
      rgb: '#ff0000'
    }
    t: 0 // Underline type
  }
}
```

#### Зачёркивание

`st` — это объект, который описывает стиль страйк-сквозняка.

```typescript
interface IStyleData {
  st: {
    s: 1 // Whether to show strikethrough
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Strikethrough color
      rgb: '#ff0000'
    }
    t: 0 // Strikethrough type
  }
}
```

#### Надчёркивание

`ol` — это объект, который описывает стиль оверлайна.

```typescript
interface IStyleData {
  ol: {
    s: 1 // Whether to show overline
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Overline color
      rgb: '#ff0000'
    }
    t: 0 // Overline type
  }
}
```

#### Цвет фона

`bg` — это объект, который описывает цвет фона.

```typescript
interface IStyleData {
  bg: {
    rgb: '#ff0000' // Background color is red
  }
}
```

#### Граница

`bd` — объект, описывающий пограничный стиль.

```typescript
interface IStyleData {
  bd: {
    // Top border
    t: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Bottom border
    b: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Left border
    l: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Right border
    r: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
  }
}
```

#### Цвет шрифта

`cl` — это объект, который описывает цвет шрифта.

```typescript
interface IStyleData {
  cl: {
    rgb: '#ff0000' // Font color is red
  }
}
```

#### Верхний или нижний индекс

`va` - это число: `1` означает нормальный, `2` обозначает подстрочный, а `3` – суперскриптовый.

```typescript
interface IStyleData {
  va: 2 // Subscript
}
```

#### Поворот текста

`tr` — объект, описывающий вращение текста.

```typescript
interface IStyleData {
  tr: {
    a: 0 // Text rotation angle
    v: 0 // Whether it is vertical. 1 means vertical, 0 means horizontal. The default value is 0. When v is 1, a is invalid
  }
}
```

#### Выравнивание по горизонтали

`ht` - это число: `1` означает левое выравнивание, `2` обозначает центр, а `3` – правое выравнивания.

```typescript
interface IStyleData {
  ht: 1 // Left alignment
}
```

#### Выравнивание по вертикали

`vt` - это число: `1` означает верхнее выравнивание, `2` обозначает центр, а `3` – нижнее выравнение.

```typescript
interface IStyleData {
  vt: 1 // Top alignment
}
```

#### Обработка текста, выходящего за границы

`tb` - это число: `1` означает переполнение, `2` – усечение, а `3` — обертывание.

```typescript
interface IStyleData {
  tb: 1 // Overflow
}
```

#### Внутренние отступы

`pd` — это объект, который описывает прокладку.

```typescript
interface IStyleData {
  pd: {
    t: 0 // Top padding
    b: 0 // Bottom paddingAdd commentMore actions
    l: 0 // Left padding
    r: 0 // Right padding
  }
}
```

#### Числовой формат [#number-format]

`n` является объектом. Его поле `pattern` содержит формат чисел в виде строки. Microsoft документирует формат кодов [здесь](https://support.microsoft.com/en-us/office/number-format-codes-5026bbd6-04bc-48cd-bf33-80f18b4eae68).

Если `n` является `null`, или если `pattern` - `null` , ячейка использует общий формат.

```typescript
import type { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

interface IStyleData {
  n: {
    pattern: DEFAULT_TEXT_FORMAT_EXCEL // text format
  }
}
```

Чтобы сохранить число, начинающееся с 0, или число, которое может быть преобразовано в формат даты, от автоматического преобразования, см. [форматирование номеров](/guides/sheets/features/core/numfmt#usage).

### Тип ячейки [#cell-type]

`cellData.t` — это [CellValueТип](/reference/enums/cell-value-type) enum, который устанавливает тип ячейки. `1` означает строку, `2` обозначает номер, `3` значит булевый, а `4` подразумевает текст силы. Когда поле не установлено, Univer распознает тип автоматически.

Булевая ячейка хранит `cellData.v` как `0` или `1`: `0` означает ложный, а `1` - истинный.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        t: 1 // String
      }
      1: {
        v: 1
        t: 2 // Number
      }
      2: {
        v: 1 // TRUE
        t: 3 // Boolean
      }
      3: {
        v: '012.0'
        t: 4 // Force text
      }
    }
  }
}
```

Текстовое предупреждение и знак силы контролируются `disableForceStringAlert` и `disableForceStringMark`. Вы можете настроить их в:
  - [Режим Preset](/guides/sheets/features/core#univerjspreset-sheets-core)
  - [Режим Plugin](/guides/sheets/features/core#univerjssheets-ui)

### Форматированный текст

`cellData.p` - это объект, который содержит богатый текст, и этот объект сам по себе является Univer Док. См. [IDocumentData](/reference/types/document-data) для полной структуры.

<Callout>
  Когда ячейка имеет набор `p` и `v`, отображается только содержимое `p`.
</Callout>

`cellData.p.body.dataStream` - это богатый текстовый контент.

### Формула

`cellData.f` - это формула, хранящаяся в виде строки.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // function SUM
      }
    }
  }
}
```

### Идентификатор формулы

`cellData.si` - строка, которая содержит формулу id. Univer Sheets оптимизирует формулы по ссылке: как только ячейка связывает свою формулу с `si`, другие ячейки могут ссылаться на ту же формулу через `si`. Ячейка, которая несет `si` должна быть в правом нижнем углу эталонной ячейки; в противном случае экспорт в XLSX вызывает ошибку.

Позвоните в Facade API `range.getFormulas()`, чтобы получить фактическую формулу. Она принимает формулу `f` на которую указывает `si` и затем вычисляет реальную формулу из смещения между текущим положением ячейки и исходным положением.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // Sum formula
        si: 'random_formula_id_1' // ID of the current formula
      }
      1: {
        si: 'random_formula_id_1' // Take the formula corresponding to this ID during calculation
      }
    }
  }
}
```

### Пользовательское поле

`cellData.custom` - это объект, который служит пользовательским полем. Он принимает любые данные, которые являются действительными для JSON, поэтому он может хранить дополнительную информацию о вас.

Обновление данных `custom` перезаписывает существующие данные `custom`, а не сливается с ними. Чтобы сохранить существующие данные `custom` считывайте сначала данные `custom` и затем обновляйте их.

<Callout type="warning">
  Поле `custom` применимо только к нескольким специальным сценариям.Любая операция пользователя может перезаписать или удалить данные, хранящиеся в этом поле, поэтому используйте его с осторожностью.
</Callout>

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        custom: {
          key: 'value'
        }
      }
    }
  }
}
```
