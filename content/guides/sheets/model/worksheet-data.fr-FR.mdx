## IWorksheetData

[`IWorksheetData`](/reference/types/worksheet-data) représente l’instantané d’une feuille de calcul dans Univer Sheet.

### Propriétés

| Propriété | Type | Description |
|----------|------|-------------|
| id | `string` | Identifiant unique de la feuille de calcul. |
| name | `string` | Nom de la feuille de calcul. |
| tabColor | `string` | Couleur de l’onglet de la feuille de calcul. |
| hidden | `BooleanNumber` | Indique si la feuille est masquée. Valeur par défaut : `BooleanNumber.FALSE`. |
| freeze | `IFreeze` | Paramètres de figement des volets. |
| rowCount | `number` | Nombre total de lignes. |
| columnCount | `number` | Nombre total de colonnes. |
| defaultColumnWidth | `number` | Largeur par défaut des colonnes, en `px`. |
| defaultRowHeight | `number` | Hauteur par défaut des lignes, en `px`. |
| [mergeData](#merged-ranges) | `IRange[]` | Tableau des plages de cellules fusionnées. |
| cellData | `IObjectMatrixPrimitiveType<ICellData>` | Matrice du contenu des cellules. [En savoir plus.](/guides/sheets/model/cell-data) |
| rowData | `IObjectArrayPrimitiveType<Partial<IRowData>>` | Tableau des objets de données de ligne. |
| columnData | `IObjectArrayPrimitiveType<Partial<IColumnData>>` | Tableau des objets de données de colonne. |
| rowHeader | `{ width: number; hidden?: BooleanNumber; }` | Configuration des en-têtes de ligne. |
| columnHeader | `{ height: number; hidden?: BooleanNumber; }` | Configuration des en-têtes de colonne. |
| backgroundImage? | `IWorksheetBackgroundImage` | Source facultative : `{ source: string; imageSourceType: ImageSourceType }`. Voir les [images de fond](/guides/sheets/features/images#worksheet-background). |
| showGridlines | `BooleanNumber` | Indique si le quadrillage est visible. |
| rightToLeft | `BooleanNumber` | Indique si la feuille de calcul est en mode de droite à gauche. |
| [defaultStyle](/guides/sheets/features/core/default-style)? | `Nullable<IStyleData>` | Style par défaut de la feuille de calcul. |

### Plages fusionnées : `mergeData` [#merged-ranges]

Lors de la création d’un classeur à partir de données métier, utilisez des cellules fusionnées pour les titres de rapport, les en-têtes groupés ou les libellés sur plusieurs lignes.

`mergeData` est un tableau d’objets `IRange`. Les indices commencent à **0** et les bornes de fin sont **incluses**. `A1:C1` correspond à `{ startRow: 0, endRow: 0, startColumn: 0, endColumn: 2 }` ; `A3:B4` couvre deux lignes et deux colonnes. Passez le classeur ci-dessous directement à `createWorkbook()`.

```typescript
const workbook = univerAPI.createWorkbook({
  id: 'merge-demo',
  name: 'Merge demo',
  sheetOrder: ['summary'],
  sheets: {
    summary: {
      id: 'summary',
      name: 'Summary',
      rowCount: 20,
      columnCount: 8,
      mergeData: [
        { startRow: 0, endRow: 0, startColumn: 0, endColumn: 2 },
        { startRow: 2, endRow: 3, startColumn: 0, endColumn: 1 },
      ],
      cellData: {
        0: { 0: { v: 'Quarterly review' } },
        2: { 0: { v: 'Owner' } },
      },
    },
  },
})
```

Placez la valeur affichée dans la cellule supérieure gauche. Les plages doivent rester dans la feuille et ne pas se chevaucher. Après création, utilisez les [API de fusion](/reference/facade/range#merge), sans modifier un tableau `mergeData` sauvegardé pour éditer le document actif.

### Exemple

```typescript
const worksheetData: IWorksheetData = {
  id: 'sheet1',
  name: 'Sheet 1',
  tabColor: '#FF0000',
  hidden: BooleanNumber.FALSE,
  freeze: { xSplit: 1, ySplit: 1, startRow: 1, startColumn: 1 },
  rowCount: 1000,
  columnCount: 26,
  defaultColumnWidth: 100,
  defaultRowHeight: 25,
  mergeData: [],
  cellData: {
    0: {
      0: {
        v: 123,
      },
    },
  },
  rowData: [],
  columnData: [],
  rowHeader: { width: 40 },
  columnHeader: { height: 20 },
  showGridlines: BooleanNumber.TRUE,
  rightToLeft: BooleanNumber.FALSE,
}
```

Cette structure offre une représentation complète des données d’une feuille de calcul, notamment de sa mise en page, de son contenu et de ses paramètres d’affichage.
