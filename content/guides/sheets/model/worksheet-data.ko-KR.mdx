## IWorksheetData

[`IWorksheetData`](/reference/types/worksheet-data)는 Univer Sheet에서 워크시트의 스냅샷을 나타냅니다.

### 속성

| 속성 | 타입 | 설명 |
|----------|------|-------------|
| id | `string` | 워크시트의 고유 식별자입니다. |
| name | `string` | 워크시트의 이름입니다. |
| tabColor | `string` | 워크시트 탭의 색상입니다. |
| hidden | `BooleanNumber` | 시트의 숨김 여부입니다. 기본값: `BooleanNumber.FALSE`. |
| freeze | `IFreeze` | 틀 고정 설정입니다. |
| rowCount | `number` | 전체 행 수입니다. |
| columnCount | `number` | 전체 열 수입니다. |
| defaultColumnWidth | `number` | 열의 기본 너비이며, 단위는 `px`입니다. |
| defaultRowHeight | `number` | 행의 기본 높이이며, 단위는 `px`입니다. |
| [mergeData](#merged-ranges) | `IRange[]` | 병합된 셀 범위의 배열입니다. |
| cellData | `IObjectMatrixPrimitiveType<ICellData>` | 셀 내용의 행렬입니다. [자세히 알아보기.](/guides/sheets/model/cell-data) |
| rowData | `IObjectArrayPrimitiveType<Partial<IRowData>>` | 행 데이터 객체의 배열입니다. |
| columnData | `IObjectArrayPrimitiveType<Partial<IColumnData>>` | 열 데이터 객체의 배열입니다. |
| rowHeader | `{ width: number; hidden?: BooleanNumber; }` | 행 머리글 설정입니다. |
| columnHeader | `{ height: number; hidden?: BooleanNumber; }` | 열 머리글 설정입니다. |
| backgroundImage? | `IWorksheetBackgroundImage` | 선택적 반복 이미지 원본: `{ source: string; imageSourceType: ImageSourceType }`. [배경 이미지](/guides/sheets/features/images#worksheet-background) 참고. |
| showGridlines | `BooleanNumber` | 눈금선 표시 여부입니다. |
| rightToLeft | `BooleanNumber` | 워크시트의 오른쪽에서 왼쪽 모드 사용 여부입니다. |
| [defaultStyle](/guides/sheets/features/core/default-style)? | `Nullable<IStyleData>` | 워크시트의 기본 스타일입니다. |

### 병합 범위: `mergeData` [#merged-ranges]

업무 데이터로 통합 문서를 만들 때 병합 셀로 보고서 제목, 그룹 머리글, 여러 행에 걸친 레이블을 구성할 수 있습니다.

`mergeData`는 `IRange` 객체 배열입니다. 행과 열 인덱스는 **0**부터 시작하며 끝 인덱스도 범위에 **포함**됩니다. `A1:C1`은 `{ startRow: 0, endRow: 0, startColumn: 0, endColumn: 2 }`, `A3:B4`는 2행 2열입니다. 다음 데이터를 `createWorkbook()`에 직접 전달할 수 있습니다.

```typescript
const workbook = univerAPI.createWorkbook({
  id: 'merge-demo',
  name: 'Merge demo',
  sheetOrder: ['summary'],
  sheets: {
    summary: {
      id: 'summary',
      name: 'Summary',
      rowCount: 20,
      columnCount: 8,
      mergeData: [
        { startRow: 0, endRow: 0, startColumn: 0, endColumn: 2 },
        { startRow: 2, endRow: 3, startColumn: 0, endColumn: 1 },
      ],
      cellData: {
        0: { 0: { v: 'Quarterly review' } },
        2: { 0: { v: 'Owner' } },
      },
    },
  },
})
```

표시할 값은 병합 범위의 왼쪽 위 셀에 저장합니다. 범위는 시트 안에 있어야 하며 서로 겹치면 안 됩니다. 생성 후에는 저장한 `mergeData`를 수정하지 말고 [범위 병합 API](/reference/facade/range#merge)를 사용하세요.

### 예시

```typescript
const worksheetData: IWorksheetData = {
  id: 'sheet1',
  name: 'Sheet 1',
  tabColor: '#FF0000',
  hidden: BooleanNumber.FALSE,
  freeze: { xSplit: 1, ySplit: 1, startRow: 1, startColumn: 1 },
  rowCount: 1000,
  columnCount: 26,
  defaultColumnWidth: 100,
  defaultRowHeight: 25,
  mergeData: [],
  cellData: {
    0: {
      0: {
        v: 123,
      },
    },
  },
  rowData: [],
  columnData: [],
  rowHeader: { width: 40 },
  columnHeader: { height: 20 },
  showGridlines: BooleanNumber.TRUE,
  rightToLeft: BooleanNumber.FALSE,
}
```

이 구조는 레이아웃, 콘텐츠, 표시 설정을 포함한 워크시트 데이터를 포괄적으로 나타냅니다.
