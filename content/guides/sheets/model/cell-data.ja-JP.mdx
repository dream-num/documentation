## セル位置

Univerシートは[セルデータ](/reference/types/worksheet-data#celldata)オブジェクトの[IWorksheetデータ](/reference/types/worksheet-data)フィールドにセルデータを保存します。そのフィールドは、その値、スタイル、およびタイプを含む、セルに関するすべての情報を保持しています。

以下のコードは、セルデータの形を示しています。

```typescript
interface IWorksheetData {
  cellData: {
    // 最初の行
    0: {
      // 最初の列
      0: { v: 'A1' }
      // 2 番目の列
      1: { v: 'B1' }
    }
    // 2 番目の行
    1: {
      // 最初の列
      0: { v: 'A2' }
      // 2 番目の列
      1: { v: 'B2' }
    }
  }
}
```

## セルデータ

セルには以下の特性があります。

| プロパティ | 説明 |
| --- | --- |
| v | セルの元の値 |
| s | セルスタイル ID またはスタイルオブジェクト |
| t | セルタイプ |
| p | リッチテキスト、Univer Docs でもある |
| f | 数式 |
| si | 数式 ID |
| custom | カスタムフィールド |

各プロパティの型については、[ICellデータ](/reference/types/cell-data)を参照してください。

### セルの元の値

`cellData.v`は、文字列または数のいずれかであるセルの元の値を保持しています。 式を持っているセルでは、`v`はその式の結果を保持します。

下の例では、1つのセルに文字列を格納し、もう1つのセルに数を格納します。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: { v: 'A1' }
      1: { v: 1 }
    }
  }
}
```

### セルスタイル

`cellData.s`はスタイルIDまたはスタイルオブジェクトのいずれかを保持します。

`s` が文字列の場合、スタイル ID です。Univer Sheets は参照によってスタイルを最適化するので、繰り返しスタイルオブジェクトは IWorkbookData の [スタイル](/reference/types/workbook-data#styles)フィールドに一度保存されます。このフィールドはマップです。各キーはスタイル ID であり、各値はスタイルオブジェクトです。

<Callout type="warning">
  rgbaなどの透明度を運ぶ色の値を避けてください。その種類の背景を持つセルが編集状態に入ると、セルの下にあるコンテンツがわかります。
</Callout>

```typescript
interface IWorkbookData {
  styles: {
    random_style_id_1: {
      fs: 12
      bg: {
        rgb: '#ff0000'
      }
    }
  }
}
```

id のセル参照時、スタイルオブジェクトが再利用されます。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        s: 'random_style_id_1'
      }
      1: {
        v: 'B1'
        s: 'random_style_id_1'
      }
    }
  }
}
```

`s` がオブジェクトの場合、完全なスタイルオブジェクト([IStyleデータ](/reference/types/style-data))です。

スタイルフィールドは以下の通りです。

| プロパティ | 説明 |
| --- | --- |
| ff | フォント |
| fs | フォントサイズ |
| it | 斜体 |
| bl | 太字 |
| ul | 下線 |
| st | 取り消し線 |
| ol | 上線 |
| bg | 背景色 |
| bd | 境界線 |
| cl | フォント色 |
| va | 上付き文字または下付き文字 |
| tr | テキスト回転 |
| ht | 水平配置 |
| vt | 垂直配置 |
| tb | オーバーフロー切り捨て |
| pd | パディング |
| n | 数値フォーマット |

各フィールドの型については、[IStyleデータ](/reference/types/style-data) を参照してください。

#### フォント

`ff`は文字列としてフォント名です。

```typescript
interface IStyleData {
  ff: 'Arial' // フォント名は Arial
}
```

#### フォントサイズ

`fs`は**プット**の数字です。

```typescript
interface IStyleData {
  fs: 12 // フォントサイズは 12 pt
}
```

#### 斜体

`it` はブール値です。`0`は、イタリックではなく、`1`がイタリックを意味します。

```typescript
interface IStyleData {
  it: 1 // 斜体
}
```

#### 太字

`bl`はボレアン番号です:`0` は太字ではなく、`1`が太字を意味します。

```typescript
interface IStyleData {
  bl: 1 // 太字
}
```

#### 下線

`ul`は、アンダーラインスタイルを記述するオブジェクトです。

```typescript
interface IStyleData {
  ul: {
    s: 1 // 下線を表示するかどうか
    c: 0 // 色がフォント色に従うかどうか。`c` が 1（TRUE）の場合、cl は機能しません。デフォルト値は 1
    cl: { // 下線の色
      rgb: '#ff0000'
    }
    t: 0 // 下線のタイプ
  }
}
```

#### 取り消し線

`st`はストライクスルーのスタイルを記述するオブジェクトです。

```typescript
interface IStyleData {
  st: {
    s: 1 // 取り消し線を表示するかどうか
    c: 0 // 色がフォント色に従うかどうか。`c` が 1（TRUE）の場合、cl は機能しません。デフォルト値は 1
    cl: { // 取り消し線の色
      rgb: '#ff0000'
    }
    t: 0 // 取り消し線のタイプ
  }
}
```

#### 上線

`ol`は、オーバーラインスタイルを記述するオブジェクトです。

```typescript
interface IStyleData {
  ol: {
    s: 1 // 上線を表示するかどうか
    c: 0 // 色がフォント色に従うかどうか。`c` が 1（TRUE）の場合、cl は機能しません。デフォルト値は 1
    cl: { // 上線の色
      rgb: '#ff0000'
    }
    t: 0 // 上線のタイプ
  }
}
```

#### 背景色

`bg`は背景色を記述する目的です。

```typescript
interface IStyleData {
  bg: {
    rgb: '#ff0000' // 背景色は赤
  }
}
```

#### 境界線

`bd`は、境界スタイルを記述するオブジェクトです。

```typescript
interface IStyleData {
  bd: {
    // 上境界線
    t: {
      s: 0 // 境界線スタイル
      cl: { // 境界線の色
        rgb: '#ff0000'
      }
    }
    // 下境界線
    b: {
      s: 0 // 境界線スタイル
      cl: { // 境界線の色
        rgb: '#ff0000'
      }
    }
    // 左境界線
    l: {
      s: 0 // 境界線スタイル
      cl: { // 境界線の色
        rgb: '#ff0000'
      }
    }
    // 右境界線
    r: {
      s: 0 // 境界線スタイル
      cl: { // 境界線の色
        rgb: '#ff0000'
      }
    }
  }
}
```

#### フォント色

`cl`は、フォントの色を記述するオブジェクトです。

```typescript
interface IStyleData {
  cl: {
    rgb: '#ff0000' // フォント色は赤
  }
}
```

#### 上付き文字または下付き文字

`va`は列数です:`1` は正常を意味します、`2`とはサブスクリプトを意味します。`3`がスーパースクリプトを意味します。

```typescript
interface IStyleData {
  va: 2 // 下付き文字
}
```

#### テキスト回転

`tr`はテキストの回転を説明するオブジェクトです。

```typescript
interface IStyleData {
  tr: {
    a: 0 // テキスト回転角度
    v: 0 // 垂直かどうか。1 は垂直、0 は水平を意味します。デフォルト値は 0。v が 1 の場合、a は無効
  }
}
```

#### 水平配置

`ht` は enum の番号です: `1` は左の直線を意味します、`2` は中心を意味し、`3` は右の直線を意味します。

```typescript
interface IStyleData {
  ht: 1 // 左揃え
}
```

#### 垂直配置

`vt` は enum の番号です: `1` は一直線を意味します、`2` は中心を意味し、`3` は最下の直線を意味します。

```typescript
interface IStyleData {
  vt: 1 // 上揃え
}
```

#### オーバーフロー切り捨て

`tb` は enum 番号です: `1` は、オーバーフローを意味し、`2` は truncate を意味し、`3` はラップを意味します。

```typescript
interface IStyleData {
  tb: 1 // オーバーフロー
}
```

#### パディング

`pd`は、パディングを記述するオブジェクトです。

```typescript
interface IStyleData {
  pd: {
    t: 0 // 上パディング
    b: 0 // 下パディング
    l: 0 // 左パディング
    r: 0 // 右パディング
  }
}
```

#### 数値フォーマット [#number-format]

`n`はオブジェクトです。`pattern`フィールドは文字列として番号形式を保持しています。Microsoftはフォーマットコード[詳しくはこちら](https://support.microsoft.com/en-us/office/number-format-codes-5026bbd6-04bc-48cd-bf33-80f18b4eae68)を文書化します。

`n`が`null`の場合、または`pattern`が`null`の場合、セルは一般的なフォーマットを使用します。

```typescript
import type { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

interface IStyleData {
  n: {
    pattern: DEFAULT_TEXT_FORMAT_EXCEL // テキストフォーマット
  }
}
```

0 から始まる番号、または日付形式に変換できる数字を 1 つに保つには、自動的に変換されるから、[数値フォーマット](/guides/sheets/features/core/numfmt#usage) を参照してください。

### セルタイプ [#cell-type]

`cellData.t` は、セルの種類をセットする [セルバリュータイプ](/reference/enums/cell-value-type) 列です。 `1` は文字列、`2` は数値、`3` はブール値、`4` は強制テキストを意味します。 フィールドが設定されていない場合、Univer はタイプを自動的に認識します。

boolean セルストア `cellData.v` として `0` または `1`: `0` は false を意味します。 `1` つまり、真の意味。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        t: 1 // 文字列
      }
      1: {
        v: 1
        t: 2 // 数値
      }
      2: {
        v: 1 // TRUE
        t: 3 // ブール
      }
      3: {
        v: '012.0'
        t: 4 // 強制テキスト
      }
    }
  }
}
```

`disableForceStringAlert`と`disableForceStringMark`で強制テキストアラートとマークが制御されます。 これらは、次の設定で設定できます。
  - [プリセットモード](/guides/sheets/features/core#univerjspreset-sheets-core)
  - [プラグインモード](/guides/sheets/features/core#univerjssheets-ui)

### リッチテキスト

`cellData.p`は豊富なテキストを保持するオブジェクトであり、そのオブジェクトはUniver Docです。完全な構造については、[IDocumentデータ](/reference/types/document-data)を参照してください。

<Callout>
  `p`と`v`セットのセルが2つある場合、`p`のコンテンツのみが表示されます。
</Callout>

`cellData.p.body.dataStream`は豊富なテキストコンテンツです。

### 数式

`cellData.f`は、文字列として保存された式です。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // SUM 関数
      }
    }
  }
}
```

### 数式 ID

`cellData.si`は、式IDを保持する文字列です。 Univerシートは、参照によって式を最適化します。 セルが`si`とその式を関連付けると、他のセルは、`si`を介して同じ式を参照することができます。 `si`を運ぶセルは、参照セルの右下隅にある必要があります。 それ以外の場合は、XLSXにエクスポートするとエラーが発生します。

実際の式を取得するには、Facade API `range.getFormulas()` を呼び出します。 式`f` `si` は、現在のセルの位置と参照位置の間のオフセットから実際の式を計算します。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // 合計数式
        si: 'random_formula_id_1' // 現在の数式の ID
      }
      1: {
        si: 'random_formula_id_1' // 計算時にこの ID に対応する数式を取得
      }
    }
  }
}
```

### カスタムフィールド

`cellData.custom`は、カスタムフィールドとして機能するオブジェクトです。 JSON が有効な任意のデータを受け入れるので、独自の追加情報を保存することができます。

`custom` のデータの更新は、既存の `custom` データを書き換えます。既存の `custom` ファイルを維持するために、`custom`データを最初に読み、新しいデータにマージし、更新します。

<Callout type="warning">
  `custom` フィールドは、いくつかの特別なシナリオのみに適用されます。このフィールドに格納されているデータを上書きまたは削除することができます。そのため、注意して使用してください。
</Callout>

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        custom: {
          key: 'value'
        }
      }
    }
  }
}
```
