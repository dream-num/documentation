## IWorksheetData

[`IWorksheetData`](https://reference.univer.ai/en-US/interfaces/IWorksheetData) stellt die Momentaufnahme eines Arbeitsblatts in Univer Sheet dar.

### Eigenschaften

| Eigenschaft | Typ | Beschreibung |
|----------|------|-------------|
| id | `string` | Eindeutige Kennung für das Arbeitsblatt. |
| name | `string` | Name des Arbeitsblatts. |
| tabColor | `string` | Farbe der Arbeitsblattregisterkarte. |
| hidden | `BooleanNumber` | Gibt an, ob das Blatt ausgeblendet ist. Standard: `BooleanNumber.FALSE`. |
| freeze | `IFreeze` | Fenstereinstellungen einfrieren. |
| rowCount | `number` | Gesamtzahl der Zeilen. |
| columnCount | `number` | Gesamtzahl der Spalten. |
| defaultColumnWidth | `number` | Standardbreite für Spalten, Einheit `px`. |
| defaultRowHeight | `number` | Standardhöhe für Zeilen, Einheit `px`. |
| mergeData | `IRange[]` | Array zusammengeführter Zellbereiche. |
| cellData | `IObjectMatrixPrimitiveType<ICellData>` | Matrix der Zellinhalte. [Weitere Details.](/guides/sheets/model/cell-data) |
| rowData | `IObjectArrayPrimitiveType<Partial<IRowData>>` | Array von Zeilendatenobjekten. |
| columnData | `IObjectArrayPrimitiveType<Partial<IColumnData>>` | Array von Spaltendatenobjekten. |
| rowHeader | `{ width: number; hidden?: BooleanNumber; }` | Zeilenkopfkonfiguration. |
| columnHeader | `{ height: number; hidden?: BooleanNumber; }` | Spaltenkopfkonfiguration. |
| showGridlines | `BooleanNumber` | Ob Gitterlinien sichtbar sind. |
| rightToLeft | `BooleanNumber` | Ob sich das Arbeitsblatt im Rechts-nach-Links-Modus befindet. |
| [defaultStyle](/guides/sheets/features/core/default-style)? | `Nullable<IStyleData>` | Der Standardstil von Arbeitsblatt|

### Beispiel

```typescript
const worksheetData: IWorksheetData = {
  id: 'sheet1',
  name: 'Sheet 1',
  tabColor: '#FF0000',
  hidden: BooleanNumber.FALSE,
  freeze: { xSplit: 1, ySplit: 1, startRow: 1, startColumn: 1 },
  rowCount: 1000,
  columnCount: 26,
  defaultColumnWidth: 100,
  defaultRowHeight: 25,
  mergeData: [],
  cellData: {
    0: {
      0: {
        v: 123,
      },
    },
  },
  rowData: [],
  columnData: [],
  rowHeader: { width: 40 },
  columnHeader: { height: 20 },
  showGridlines: BooleanNumber.TRUE,
  rightToLeft: BooleanNumber.FALSE,
}
```

Diese Struktur bietet eine umfassende Darstellung von Arbeitsblattdaten, einschließlich Layout, Inhalt und Anzeigeeinstellungen.
