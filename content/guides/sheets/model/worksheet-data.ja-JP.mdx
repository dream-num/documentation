## IWorksheetData

[`IWorksheetData`](/reference/types/worksheet-data) は Univer Sheet におけるワークシートのスナップショットを表します。

### プロパティ

| プロパティ | タイプ | 説明 |
|----------|------|-------------|
| id | `string` | ワークシートの一意識別子。 |
| name | `string` | ワークシートの名前。 |
| tabColor | `string` | ワークシートタブの色。 |
| hidden | `BooleanNumber` | シートが非表示かどうか。デフォルト: `BooleanNumber.FALSE`。 |
| freeze | `IFreeze` | フリーズペインの設定。 |
| rowCount | `number` | 行の総数。 |
| columnCount | `number` | 列の総数。 |
| defaultColumnWidth | `number` | 列のデフォルト幅、単位 `px`。 |
| defaultRowHeight | `number` | 行のデフォルト高さ、単位 `px`。 |
| [mergeData](#merged-ranges) | `IRange[]` | 結合セル範囲の配列。 |
| cellData | `IObjectMatrixPrimitiveType<ICellData>` | セル内容のマトリックス。[詳細情報。](/guides/sheets/model/cell-data) |
| rowData | `IObjectArrayPrimitiveType<Partial<IRowData>>` | 行データオブジェクトの配列。 |
| columnData | `IObjectArrayPrimitiveType<Partial<IColumnData>>` | 列データオブジェクトの配列。 |
| rowHeader | `{ width: number; hidden?: BooleanNumber; }` | 行ヘッダーの設定。 |
| columnHeader | `{ height: number; hidden?: BooleanNumber; }` | 列ヘッダーの設定。 |
| backgroundImage? | `IWorksheetBackgroundImage` | 任意のタイル画像ソース：`{ source: string; imageSourceType: ImageSourceType }`。[背景画像](/guides/sheets/features/images#worksheet-background)を参照。 |
| showGridlines | `BooleanNumber` | グリッド線が表示されるかどうか。 |
| rightToLeft | `BooleanNumber` | ワークシートが右から左モードかどうか。 |
| [defaultStyle](/guides/sheets/features/core/default-style)? | `Nullable<IStyleData>` | ワークシートのデフォルトスタイル |

### 結合範囲：`mergeData` [#merged-ranges]

業務データからブックを作成するとき、結合セルでレポートの表題、グループ見出し、複数行にまたがるラベルを配置できます。

`mergeData` は `IRange` オブジェクトの配列です。行と列のインデックスは **0** から始まり、終了インデックスも範囲に**含まれます**。`A1:C1` は `{ startRow: 0, endRow: 0, startColumn: 0, endColumn: 2 }`、`A3:B4` は2行2列です。次のデータを `createWorkbook()` に直接渡せます。

```typescript
const workbook = univerAPI.createWorkbook({
  id: 'merge-demo',
  name: 'Merge demo',
  sheetOrder: ['summary'],
  sheets: {
    summary: {
      id: 'summary',
      name: 'Summary',
      rowCount: 20,
      columnCount: 8,
      mergeData: [
        { startRow: 0, endRow: 0, startColumn: 0, endColumn: 2 },
        { startRow: 2, endRow: 3, startColumn: 0, endColumn: 1 },
      ],
      cellData: {
        0: { 0: { v: 'Quarterly review' } },
        2: { 0: { v: 'Owner' } },
      },
    },
  },
})
```

表示値は結合範囲の左上セルに格納します。範囲はシート内に収め、重複させないでください。作成後は保存済みの `mergeData` を変更せず、[範囲結合 API](/reference/facade/range#merge)で結合・解除してください。

### 例

```typescript
const worksheetData: IWorksheetData = {
  id: 'sheet1',
  name: 'Sheet 1',
  tabColor: '#FF0000',
  hidden: BooleanNumber.FALSE,
  freeze: { xSplit: 1, ySplit: 1, startRow: 1, startColumn: 1 },
  rowCount: 1000,
  columnCount: 26,
  defaultColumnWidth: 100,
  defaultRowHeight: 25,
  mergeData: [],
  cellData: {
    0: {
      0: {
        v: 123,
      },
    },
  },
  rowData: [],
  columnData: [],
  rowHeader: { width: 40 },
  columnHeader: { height: 20 },
  showGridlines: BooleanNumber.TRUE,
  rightToLeft: BooleanNumber.FALSE,
}
```

この構造は、レイアウト、内容、表示設定を含むワークシートデータの包括的な表現を提供します。
