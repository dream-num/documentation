## IWorkbookData

[`IWorkbookData`](https://reference.univer.ai/en-US/interfaces/IWorkbookData) représente l'instantané d'un classeur dans Univer Sheets.

### Propriétés

| Propriété  | Type                                             | Description                                                                    |
| ---------- | ------------------------------------------------ | ------------------------------------------------------------------------------ |
| id         | `string`                                         | Identifiant unique du classeur Univer Sheets.                                  |
| name       | `string`                                         | Nom du classeur Univer Sheets.                                                 |
| appVersion | `string`                                         | Version de la définition du modèle Univer.                                     |
| locale     | `LocaleType`                                     | Paramètres régionaux du document.                                              |
| styles     | `Record<string, Nullable<IStyleData>>`           | Références de styles du classeur.                                              |
| sheetOrder | `string[]`                                       | Tableau d'identifiants de feuilles définissant l'ordre des feuilles de calcul. |
| sheets     | `{ [sheetId: string]: Partial<IWorksheetData> }` | Enregistrement contenant les données de chaque feuille de calcul.              |
| resources? | `IResources`                                     | Données stockées par les plugins.                                              |

### Exemple

```typescript
const workbookData: IWorkbookData = {
  id: 'unique-workbook-id',
  name: 'My Workbook',
  appVersion: '0.10.2',
  locale: LocaleType.EN_US,
  styles: {/* style definitions */},
  sheetOrder: ['sheet1', 'sheet2'],
  sheets: {
    sheet1: {/* sheet data */},
    sheet2: {/* sheet data */},
  },
}
```

### Utilisation

IWorkbookData est l'objet utilisé pour stocker les données dans Univer Sheets. Il sert principalement à :

1. [Créer un classeur Univer Sheets avec IWorkbookData](/guides/sheets/features/core/sheets-api#create-worksheet)
2. [Enregistrer IWorkbookData à partir d'un classeur Univer Sheets](/guides/sheets/features/core/sheets-api#get-workbook-data)

La propriété `resources` sert à stocker les données des plugins. Consultez la page [Modèle personnalisé d'un plugin](/blog/custom-model)
