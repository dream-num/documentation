## IWorkbookData

[`IWorkbookData`](/reference/types/workbook-data) est l'instantané d'un cahier de travail dans les feuilles Univer.

### Propriétés

| Propriété  | Type                                             | Description                                                                    |
| ---------- | ------------------------------------------------ | ------------------------------------------------------------------------------ |
| id | `string` | Identificateur unique du cahier de travail. |
| name | `string` | Nom du cahier. |
| appVersion | `string`                                         | Version de la définition du modèle Univer.                                     |
| locale     | `LocaleType`                                     | Paramètres régionaux du document.                                              |
| styles     | `Record<string, Nullable<IStyleData>>`           | Références de styles du classeur.                                              |
| sheetOrder | `string[]` | Les identifiants des feuilles de travail, dans l'ordre, apparaissent. |
| sheets     | `{ [sheetId: string]: Partial<IWorksheetData> }` | Enregistrement contenant les données de chaque feuille de calcul.              |
| resources? | `IResources` | Données détenues par les plugins. |

### Exemple

```typescript
const workbookData: IWorkbookData = {
  id: 'unique-workbook-id',
  name: 'My Workbook',
  appVersion: '0.10.2',
  locale: LocaleType.EN_US,
  styles: {/* style definitions */},
  sheetOrder: ['sheet1', 'sheet2'],
  sheets: {
    sheet1: {/* sheet data */},
    sheet2: {/* sheet data */},
  },
}
```

### Utilisation

Univer Sheets stocke les données du cahier de travail dans IWorkbookData. La structure est utilisée dans deux situations:

1. [Création d'un cahier de travail à partir de IWorkbookData](/guides/sheets/features/core/sheets-api#create-worksheet)
2. [Enregistrer les données d'un cahier de travail sous forme de données IWorkbook](/guides/sheets/features/core/sheets-api#get-workbook-data)

La propriété `resources` détient des données appartenant à des plugins. Voir [Modèle personnalisé de greffon](/blog/custom-model).
