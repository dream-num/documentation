## IWorkbookData

[`IWorkbookData`](/reference/types/workbook-data) es la instantánea de un libro de trabajo en Univer Hojas.

### Propiedades

| Propiedad  | Tipo                                             | Descripción                                                             |
| ---------- | ------------------------------------------------ | ----------------------------------------------------------------------- |
| id | `string` | Un identificador único del libro de trabajo. |
| name | `string` | Nombre del libro de trabajo. |
| appVersion | `string`                                         | Versión de la definición del modelo de Univer.                          |
| locale     | `LocaleType`                                     | Configuración regional del documento.                                   |
| styles     | `Record<string, Nullable<IStyleData>>`           | Referencias de estilo para el libro de trabajo.                         |
| sheetOrder | `string[]` | Los ID de hoja de trabajo, en el orden que aparecen las hojas. |
| sheets     | `{ [sheetId: string]: Partial<IWorksheetData> }` | Registro que contiene datos para cada hoja de trabajo.                  |
| resources? | `IResources` | Datos propiedad de plugins. |

### Ejemplo

```typescript
const workbookData: IWorkbookData = {
  id: 'unique-workbook-id',
  name: 'My Workbook',
  appVersion: '0.10.2',
  locale: LocaleType.EN_US,
  styles: {/* style definitions */},
  sheetOrder: ['sheet1', 'sheet2'],
  sheets: {
    sheet1: {/* sheet data */},
    sheet2: {/* sheet data */},
  },
}
```

### Uso

Univer Hojas almacena datos del libro de trabajo en IWorkbookData. La estructura se utiliza en dos situaciones:

1. [Creación de un libro de trabajo de IWorkbookData](/guides/sheets/features/core/sheets-api#create-worksheet)
2. [Ahorro de los datos de un libro de trabajo como IWorkbookData](/guides/sheets/features/core/sheets-api#get-workbook-data)

La propiedad `resources` posee datos propiedad de plugins. Ver [Modelo personalizado de plugin](/blog/custom-model).
