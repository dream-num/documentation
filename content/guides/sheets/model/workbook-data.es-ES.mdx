## IWorkbookData

[`IWorkbookData`](https://reference.univer.ai/en-US/interfaces/IWorkbookData) representa la instantánea de un libro de trabajo en Univer Sheet.

### Propiedades

| Propiedad  | Tipo                                             | Descripción                                                             |
| ---------- | ------------------------------------------------ | ----------------------------------------------------------------------- |
| id         | `string`                                         | Identificador único de Univer Sheets.                                   |
| name       | `string`                                         | Nombre de Univer Sheets.                                                |
| appVersion | `string`                                         | Versión de la definición del modelo de Univer.                          |
| locale     | `LocaleType`                                     | Configuración regional del documento.                                   |
| styles     | `Record<string, Nullable<IStyleData>>`           | Referencias de estilo para el libro de trabajo.                         |
| sheetOrder | `string[]`                                       | Matriz de ID de hojas que representan el orden de las hojas de trabajo. |
| sheets     | `{ [sheetId: string]: Partial<IWorksheetData> }` | Registro que contiene datos para cada hoja de trabajo.                  |
| resources? | `IResources`                                     | Almacenar los datos de los complementos                                 |

### Ejemplo

```typescript
const workbookData: IWorkbookData = {
  id: 'unique-workbook-id',
  name: 'My Workbook',
  appVersion: '0.10.2',
  locale: LocaleType.EN_US,
  styles: {/* style definitions */},
  sheetOrder: ['sheet1', 'sheet2'],
  sheets: {
    sheet1: {/* sheet data */},
    sheet2: {/* sheet data */},
  },
}
```

### Uso

IWorkbookData es el objeto utilizado para almacenar datos en Univer Sheets. Se utiliza principalmente para:

1. [Crear Univer Sheets usando IWorkbookData](/guides/sheets/features/core/sheets-api#create-worksheet)
2. [Guardar IWorkbookData de Univer Sheets](/guides/sheets/features/core/sheets-api#get-workbook-data)

La propiedad `resources` se utiliza para almacenar datos del complemento. Vaya a [Complemento de modelo personalizado](/blog/custom-model)
