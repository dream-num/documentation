## IWorksheetData

[`IWorksheetData`](https://reference.univer.ai/en-US/interfaces/IWorksheetData) представляет снимок рабочего листа в Univer Sheet.

### Свойства

| Свойство | Тип | Описание |
|----------|------|-------------|
| id | `string` | Уникальный идентификатор рабочего листа. |
| name | `string` | Имя рабочего листа. |
| tabColor | `string` | Цвет вкладки рабочего листа. |
| hidden | `BooleanNumber` | Указывает, скрыт ли лист. Значение по умолчанию: `BooleanNumber.FALSE`. |
| freeze | `IFreeze` | Настройки закрепления областей. |
| rowCount | `number` | Общее количество строк. |
| columnCount | `number` | Общее количество столбцов. |
| defaultColumnWidth | `number` | Ширина столбцов по умолчанию в `px`. |
| defaultRowHeight | `number` | Высота строк по умолчанию в `px`. |
| mergeData | `IRange[]` | Массив диапазонов объединённых ячеек. |
| cellData | `IObjectMatrixPrimitiveType<ICellData>` | Матрица содержимого ячеек. [Подробнее.](/guides/sheets/model/cell-data) |
| rowData | `IObjectArrayPrimitiveType<Partial<IRowData>>` | Массив объектов с данными строк. |
| columnData | `IObjectArrayPrimitiveType<Partial<IColumnData>>` | Массив объектов с данными столбцов. |
| rowHeader | `{ width: number; hidden?: BooleanNumber; }` | Настройки заголовков строк. |
| columnHeader | `{ height: number; hidden?: BooleanNumber; }` | Настройки заголовков столбцов. |
| showGridlines | `BooleanNumber` | Указывает, отображаются ли линии сетки. |
| rightToLeft | `BooleanNumber` | Указывает, используется ли на рабочем листе направление справа налево. |
| [defaultStyle](/guides/sheets/features/core/default-style)? | `Nullable<IStyleData>` | Стиль рабочего листа по умолчанию |

### Пример

```typescript
const worksheetData: IWorksheetData = {
  id: 'sheet1',
  name: 'Sheet 1',
  tabColor: '#FF0000',
  hidden: BooleanNumber.FALSE,
  freeze: { xSplit: 1, ySplit: 1, startRow: 1, startColumn: 1 },
  rowCount: 1000,
  columnCount: 26,
  defaultColumnWidth: 100,
  defaultRowHeight: 25,
  mergeData: [],
  cellData: {
    0: {
      0: {
        v: 123,
      },
    },
  },
  rowData: [],
  columnData: [],
  rowHeader: { width: 40 },
  columnHeader: { height: 20 },
  showGridlines: BooleanNumber.TRUE,
  rightToLeft: BooleanNumber.FALSE,
}
```

Эта структура полностью описывает данные рабочего листа, включая компоновку, содержимое и настройки отображения.
