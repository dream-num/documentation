## 儲存格位置

Univer Sheets 將單元格資料儲存在 [IWorksheetData](/reference/types/worksheet-data) 的 [cellData](/reference/types/worksheet-data#celldata) 欄位中。cellData 是一個二維 Map，一級索引是行號，二級索引是列號，每個單元格是一個 [ICellData](/reference/types/cell-data) 物件，值、樣式、型別等資訊都包含在內。

cellData 的結構如下。

```typescript
interface IWorksheetData {
  cellData: {
    // 第 1 列（row）
    0: {
      // 第 1 欄（column）
      0: { v: 'A1' }
      // 第 2 欄
      1: { v: 'B1' }
    }
    // 第 2 列
    1: {
      // 第 1 欄
      0: { v: 'A2' }
      // 第 2 欄
      1: { v: 'B2' }
    }
  }
}
```

## 儲存格資訊

單元格包含以下屬性。

| 屬性 | 說明 |
| --- | --- |
| v | 儲存格的原始值 |
| s | 儲存格的樣式 id 或樣式物件 |
| t | 儲存格的型別 |
| p | 豐富文字，同時也是一個 📝 Univer Docs |
| f | 公式 |
| si | 公式 ID |
| custom | 自訂欄位 |

各欄位的型別定義見 [ICellData](/reference/types/cell-data)。

### 儲存格原始值

`cellData.v` 儲存單元格的原始值，可以是字串，也可以是數字。單元格中包含公式時，`v` 儲存公式的計算結果。

下面的範例在一個單元格中儲存字串，在另一個單元格中儲存數字。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: { v: 'A1' }
      1: { v: 1 }
    }
  }
}
```

### 儲存格樣式

`cellData.s` 儲存樣式 id 或者樣式物件。

當 `s` 為字串時，它是樣式 id。Univer Sheets 對樣式做引用最佳化，因此重複的樣式物件只儲存一份，放在 IWorkbookData 的 [styles](/reference/types/workbook-data#styles) 欄位中。該欄位是一個 Map，鍵為樣式 id，值為樣式物件。

<Callout type="warning">
  避免使用帶透明度的顏色值，例如 rgba。單元格背景使用這類顏色時，進入編輯狀態會透出下方單元格的內容。
</Callout>

```typescript
interface IWorkbookData {
  styles: {
    random_style_id_1: {
      fs: 12
      bg: {
        rgb: '#ff0000'
      }
    }
  }
}
```

在單元格樣式中引用該 id，即可複用這份樣式物件。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        s: 'random_style_id_1'
      }
      1: {
        v: 'B1'
        s: 'random_style_id_1'
      }
    }
  }
}
```

當 `s` 為物件時，它是一個完整的樣式物件 [IStyleData](/reference/types/style-data)。

樣式欄位如下。

| 屬性 | 說明 |
| --- | --- |
| ff | 字型 |
| fs | 字型大小 |
| it | 斜體 |
| bl | 粗體 |
| ul | 底線 |
| st | 刪除線 |
| ol | 上劃線 |
| bg | 背景顏色 |
| bd | 邊框 |
| cl | 字型顏色 |
| va | 上標下標 |
| tr | 文字旋转 |
| ht | 水平對齊方式 |
| vt | 垂直對齊方式 |
| tb | 截斷溢出 |
| pd | 內邊距 |
| n | 數字格式 |

各欄位的型別定義見 [IStyleData](/reference/types/style-data)。

#### 字型

`ff` 是字型名稱，型別為字串。

```typescript
interface IStyleData {
  ff: 'Arial' // 字型名稱為 Arial
}
```

#### 字型大小

`fs` 是數字，單位為 **pt**。

```typescript
interface IStyleData {
  fs: 12 // 字型大小為 12 pt
}
```

#### 斜體

`it` 是布林數字：`0` 表示不斜體，`1` 表示斜體。

```typescript
interface IStyleData {
  it: 1 // 斜體
}
```

#### 粗體

`bl` 是布林數字：`0` 表示不加粗，`1` 表示加粗。

```typescript
interface IStyleData {
  bl: 1 // 粗體
}
```

#### 底線

`ul` 是一個物件，描述下劃線樣式。

```typescript
interface IStyleData {
  ul: {
    s: 1 // 是否顯示底線
    c: 0 // 顏色是否跟隨字型顏色。當 `c` 為 1（TRUE）時，cl 不生效。預設值為 1
    cl: { // 底線顏色
      rgb: '#ff0000'
    }
    t: 0 // 底線類型
  }
}
```

#### 刪除線

`st` 是一個物件，描述刪除線樣式。

```typescript
interface IStyleData {
  st: {
    s: 1 // 是否顯示刪除線
    c: 0 // 顏色是否跟隨字型顏色。當 `c` 為 1（TRUE）時，cl 不生效。預設值為 1
    cl: { // 刪除線顏色
      rgb: '#ff0000'
    }
    t: 0 // 刪除線類型
  }
}
```

#### 上劃線

`ol` 是一個物件，描述上劃線樣式。

```typescript
interface IStyleData {
  ol: {
    s: 1 // 是否顯示上劃線
    c: 0 // 顏色是否跟隨字型顏色。當 `c` 為 1（TRUE）時，cl 不生效。預設值為 1
    cl: { // 上劃線顏色
      rgb: '#ff0000'
    }
    t: 0 // 上劃線類型
  }
}
```

#### 背景顏色

`bg` 是一個物件，描述背景顏色。

```typescript
interface IStyleData {
  bg: {
    rgb: '#ff0000' // 背景顏色為紅色
  }
}
```

#### 邊框

`bd` 是一個物件，描述邊框樣式。

```typescript
interface IStyleData {
  bd: {
    // 上邊框
    t: {
      s: 0 // 邊框樣式
      cl: { // 邊框顏色
        rgb: '#ff0000'
      }
    }
    // 下邊框
    b: {
      s: 0 // 邊框樣式
      cl: { // 邊框顏色
        rgb: '#ff0000'
      }
    }
    // 左邊框
    l: {
      s: 0 // 邊框樣式
      cl: { // 邊框顏色
        rgb: '#ff0000'
      }
    }
    // 右邊框
    r: {
      s: 0 // 邊框樣式
      cl: { // 邊框顏色
        rgb: '#ff0000'
      }
    }
  }
}
```

#### 字型顏色

`cl` 是一個物件，描述字型顏色。

```typescript
interface IStyleData {
  cl: {
    rgb: '#ff0000' // 字型顏色為紅色
  }
}
```

#### 上標下標

`va` 是數字列舉：`1` 表示正常，`2` 表示下標，`3` 表示上標。

```typescript
interface IStyleData {
  va: 2 // 下標
}
```

#### 文字旋转

`tr` 是一個物件，描述文字旋轉。

```typescript
interface IStyleData {
  tr: {
    a: 0 // 文字旋轉角度
    v: 0 // 是否垂直。1 表示垂直，0 表示水平。預設值為 0。當 v 為 1 時，a 無效
  }
}
```

#### 水平對齊方式

`ht` 是數字列舉，`1` 表示左對齊，`2` 表示居中`，3` 表示右對齊。

```typescript
interface IStyleData {
  ht: 1 // 靠左
}
```

#### 垂直對齊方式

`vt` 是數字列舉：`1` 表示頂部對齊，`2` 表示居中，`3` 表示底部對齊。

```typescript
interface IStyleData {
  vt: 1 // 頂端對齊
}
```

#### 截斷溢出

`tb` 是數字列舉：`1` 表示溢位，`2` 表示截斷，`3` 表示自動換行。

```typescript
interface IStyleData {
  tb: 1 // 溢出
}
```

#### 內邊距

`pd` 是一個物件，描述內邊距。

```typescript
interface IStyleData {
  pd: {
    t: 0 // 上邊距
    b: 0 // 下邊距
    l: 0 // 左邊距
    r: 0 // 右邊距
  }
}
```

#### 數字格式 [#number-format]

`n` 是一個物件，其 `pattern` 欄位儲存數字格式。該欄位為字串，具體寫法參見 [這裡](https://support.microsoft.com/zh-cn/office/%E6%95%B0%E5%AD%97%E6%A0%BC%E5%BC%8F%E4%BB%A3%E7%A0%81-5026bbd6-04bc-48cd-bf33-80f18b4eae68)。

當 `n` 為 `null`，或 `pattern` 為 `null` 時，單元格使用常規格式。

```typescript
import type { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

interface IStyleData {
  n: {
    pattern: DEFAULT_TEXT_FORMAT_EXCEL // 文字格式
  }
}
```

如需避免以 0 開頭或可轉換為日期格式的數字被自動轉換，參見[數字格式](/guides/sheets/features/core/numfmt#usage)。

### 儲存格型別 [#cell-type]

`cellData.t` 是 [CellValueType](/reference/enums/cell-value-type) 列舉，用於設定單元格型別。`1` 表示字串，`2` 表示數字，`3` 表示布林值，`4` 表示強制文字。未設定該欄位時，Univer 會自動識別型別。

布林型別單元格的 `cellData.v` 為 `0` 或 `1`：`0` 表示 false，`1` 表示 true。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        t: 1 // 字串
      }
      1: {
        v: 1
        t: 2 // 數字
      }
      2: {
        v: 1 // TRUE
        t: 3 // 布林值
      }
      3: {
        v: '012.0'
        t: 4 // 強制文字
      }
    }
  }
}
```

強制文字的警告和標記由 `disableForceStringAlert` 和 `disableForceStringMark` 控制，可在以下位置配置：
  - [預設模式](/guides/sheets/features/core#univerjspreset-sheets-core)
  - [外掛模式](/guides/sheets/features/core#univerjssheets-ui)

### 豐富文字

`cellData.p` 是一個物件，用於儲存富文字，該物件本身也是一個 Univer Doc。完整結構見 [IDocumentData](/reference/types/document-data)。

<Callout>
  當單元格同時設定 `p` 和 `v` 時，只顯示 `p` 的內容。
</Callout>

`cellData.p.body.dataStream` 儲存富文字內容。

### 公式

`cellData.f` 是公式，以字串形式儲存。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // 加總公式
      }
    }
  }
}
```

### 公式 ID

`cellData.si` 是字串，儲存公式 id。Univer Sheets 對公式做引用最佳化：單元格透過 `si` 關聯公式後，其他單元格可以透過同一個 `si` 引用該公式。包含 `si` 的單元格必須位於被引用單元格的右下角，否則匯出 XLSX 時會報錯。

可透過 Facade API `range.getFormulas()` 取得實際公式。該方法先取 `si` 指向的公式 `f`，再根據當前單元格位置與引用位置之間的偏移量計算實際公式。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // 加總公式
        si: 'random_formula_id_1' // 目前公式的 id
      }
      1: {
        si: 'random_formula_id_1' // 計算時取此 id 對應的公式
      }
    }
  }
}
```

### 自訂欄位

`cellData.custom` 是一個物件，用作自定義欄位。它可以存放任何符合 JSON 格式的資料，用於儲存自行定義的附加資訊。

更新 `custom` 資料會覆蓋現有的 `custom` 資料，而不會合並。如需保留現有的 `custom` 資料，請先讀取該資料，將其合併到新資料後再更新。

<Callout type="warning">
  `custom` 欄位僅適用於少數特殊場景。任何使用者操作都可能覆蓋或刪除儲存在該欄位中的資料，請謹慎使用。
</Callout>

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        custom: {
          key: 'value'
        }
      }
    }
  }
}
```
