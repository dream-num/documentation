## IWorkbookData

[`IWorkbookData`](https://reference.univer.ai/en-US/interfaces/IWorkbookData) представляет снимок книги в Univer Sheets.

### Свойства

| Свойство | Тип | Описание |
|----------|------|-------------|
| id | `string` | Уникальный идентификатор книги Univer Sheets. |
| name | `string` | Название книги Univer Sheets. |
| appVersion | `string` | Версия определения модели Univer. |
| locale | `LocaleType` | Локаль документа. |
| styles | `Record<string, Nullable<IStyleData>>` | Ссылки на стили книги. |
| sheetOrder | `string[]` | Массив идентификаторов листов, определяющий порядок листов. |
| sheets | `{ [sheetId: string]: Partial<IWorksheetData> }` | Объект с данными каждого листа. |
| resources? | `IResources` | Хранилище данных плагинов. |

### Пример

```typescript
const workbookData: IWorkbookData = {
  id: 'unique-workbook-id',
  name: 'My Workbook',
  appVersion: '0.10.2',
  locale: LocaleType.EN_US,
  styles: { /* style definitions */ },
  sheetOrder: ['sheet1', 'sheet2'],
  sheets: {
    sheet1: { /* sheet data */ },
    sheet2: { /* sheet data */ },
  },
}
```

### Использование

IWorkbookData — объект для хранения данных в Univer Sheets. В основном он используется для следующих задач:

1. [Создание книги Univer Sheets с помощью IWorkbookData](/guides/sheets/features/core/sheets-api#create-worksheet)
2. [Сохранение IWorkbookData из Univer Sheets](/guides/sheets/features/core/sheets-api#get-workbook-data)

Свойство `resources` используется для хранения данных плагинов. Подробнее см. в разделе [Пользовательская модель плагина](/guides/recipes/tutorials/custom-model).
