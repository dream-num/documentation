## IWorkbookData

[`IWorkbookData`](/reference/types/workbook-data) - это снимок рабочей книги в Univer Sheets.

### Свойства

| Свойство   | Тип                                              | Описание                                                    |
| ---------- | ------------------------------------------------ | ----------------------------------------------------------- |
| id | `string` | Уникальный идентификатор книги. |
| name | `string` | Наименование книги. |
| appVersion | `string`                                         | Версия определения модели Univer.                           |
| locale     | `LocaleType`                                     | Локаль документа.                                           |
| styles     | `Record<string, Nullable<IStyleData>>`           | Ссылки на стили книги.                                      |
| sheetOrder | `string[]` | Идентификаторы рабочих листов, в порядке появления листов. |
| sheets     | `{ [sheetId: string]: Partial<IWorksheetData> }` | Объект с данными каждого листа.                             |
| resources? | `IResources` | Данные, принадлежащие плагинам. |

### Пример

```typescript
const workbookData: IWorkbookData = {
  id: 'unique-workbook-id',
  name: 'My Workbook',
  appVersion: '0.10.2',
  locale: LocaleType.EN_US,
  styles: {/* style definitions */},
  sheetOrder: ['sheet1', 'sheet2'],
  sheets: {
    sheet1: {/* sheet data */},
    sheet2: {/* sheet data */},
  },
}
```

### Использование

Univer Sheets хранит данные книги в IWorkbookData. Структура используется в двух ситуациях:

1. [Создание книги из IWorkbookData](/guides/sheets/features/core/sheets-api#create-worksheet)
2. [Сохранение данных в виде IWorkbookData](/guides/sheets/features/core/sheets-api#get-workbook-data)

Собственность `resources` содержит данные, принадлежащие плагинам. См. [Пользовательская модель Plugin](/blog/custom-model).
