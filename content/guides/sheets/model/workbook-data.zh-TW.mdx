## IWorkbookData

[`IWorkbookData`](/reference/types/workbook-data) 表示 Univer Sheets 裡一個工作簿的快照。

### 屬性

| 屬性       | 類型                                             | 說明                             |
| ---------- | ------------------------------------------------ | -------------------------------- |
| id | `string` | 工作簿的唯一識別符號。 |
| name | `string` | 工作簿的名稱。 |
| appVersion | `string`                                         | Univer 模型定義的版本。          |
| locale     | `LocaleType`                                     | 文件的語言環境。                 |
| styles | `Record<string, Nullable<IStyleData>>` | 工作簿引用的樣式。 |
| sheetOrder | `string[]` | 工作表 ID 陣列，按顯示順序排列。 |
| sheets | `{ [sheetId: string]: Partial<IWorksheetData> }` | 每個工作表的資料。 |
| resources? | `IResources` | 外掛的資料。 |

### 範例

```typescript
const workbookData: IWorkbookData = {
  id: 'unique-workbook-id',
  name: '我的活頁簿',
  appVersion: '0.10.2',
  locale: LocaleType.ZH_TW,
  styles: {/* 樣式定義 */},
  sheetOrder: ['sheet1', 'sheet2'],
  sheets: {
    sheet1: {/* 工作表資料 */},
    sheet2: {/* 工作表資料 */},
  },
}
```

### 用法

Univer Sheets 將工作簿資料存放在 IWorkbookData 中，主要用於兩個場景：

1. [使用 IWorkbookData 建立工作簿](/guides/sheets/features/core/sheets-api#create-worksheet)
2. [將工作簿資料儲存為 IWorkbookData](/guides/sheets/features/core/sheets-api#get-workbook-data)

`resources` 屬性儲存外掛資料，詳見[外掛自定義模型](/blog/custom-model)。
