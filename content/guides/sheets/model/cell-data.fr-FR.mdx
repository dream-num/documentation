## Position d'une cellule

Univer Sheets stocke les données cellulaires dans le champ [data](/reference/types/worksheet-data#celldata) d'un objet [Données de la feuille de travail](/reference/types/worksheet-data). Ce champ contient toutes les informations sur une cellule, y compris sa valeur, son style et son type.

Le code ci-dessous montre la forme de cellData.

```typescript
interface IWorksheetData {
  cellData: {
    // first row
    0: {
      // first column
      0: { v: 'A1' }
      // second column
      1: { v: 'B1' }
    }
    // second row
    1: {
      // first column
      0: { v: 'A2' }
      // second column
      1: { v: 'B2' }
    }
  }
}
```

## Données d'une cellule

Une cellule a les propriétés suivantes.

| Propriété | Description |
| --- | --- |
| v | Valeur d'origine de la cellule |
| s | Identifiant de style ou objet de style de la cellule |
| t | Type de la cellule |
| p | Texte enrichi, également un 📝 document Univer Docs |
| f | Formule |
| si | Identifiant de formule |
| custom | Champ personnalisé |

Voir [ICellData](/reference/types/cell-data) pour le type de chaque propriété.

### Valeur d'origine d'une cellule

`cellData.v` détient la valeur originale d'une cellule, qui est soit une chaîne de caractères, soit un nombre. Dans une cellule qui a une formule, `v` conserve le résultat de cette formule.

L'exemple ci-dessous stocke une chaîne dans une cellule et un nombre dans l'autre.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: { v: 'A1' }
      1: { v: 1 }
    }
  }
}
```

### Style d'une cellule

`cellData.s` détient soit un id style, soit un objet style.

Lorsque `s` est une chaîne, c'est un id de style. Les feuilles Univer optimisent les styles par référence, de sorte qu'un objet de style répété est stocké une fois dans le champ [styles](/reference/types/workbook-data#styles) de IWorkbookData. Ce champ est une carte : chaque clé est un id du style, et chaque valeur est un objet de style.

<Callout type="warning">
  Évitez les valeurs de couleur qui portent la transparence, comme rgba. Lorsqu'une cellule avec ce type de fond entre dans l'état d'édition, le contenu de la cellule ci-dessous s'affiche.
</Callout>

```typescript
interface IWorkbookData {
  styles: {
    random_style_id_1: {
      fs: 12
      bg: {
        rgb: '#ff0000'
      }
    }
  }
}
```

Lorsqu'une cellule fait référence à cet id, l'objet style est réutilisé.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        s: 'random_style_id_1'
      }
      1: {
        v: 'B1'
        s: 'random_style_id_1'
      }
    }
  }
}
```

Lorsque `s` est un objet, c'est un objet de style complet ([IStyleData](/reference/types/style-data)).

Les champs de style sont énumérés ci-dessous.

| Propriété | Description |
| --- | --- |
| ff | Police |
| fs | Taille de police |
| it | Italique |
| bl | Gras |
| ul | Soulignement |
| st | Barré |
| ol | Trait supérieur |
| bg | Couleur d'arrière-plan |
| bd | Bordure |
| cl | Couleur de police |
| va | Exposant ou indice |
| tr | Rotation du texte |
| ht | Alignement horizontal |
| vt | Alignement vertical |
| tb | Gestion du dépassement du texte |
| pd | Marges internes |
| n | Format de nombre |

Voir [IStyleData](/reference/types/style-data) pour le type de chaque champ.

#### Police

`ff` est le nom de la police, en tant que chaîne.

```typescript
interface IStyleData {
  ff: 'Arial' // Font name is Arial
}
```

#### Taille de police

`fs` est un nombre, dans **pt**.

```typescript
interface IStyleData {
  fs: 12 // Font size is 12 pt
}
```

#### Italique

`it` est un nombre booléen : `0` signifie pas italique, et `1` veut dire italique.

```typescript
interface IStyleData {
  it: 1 // Italic
}
```

#### Gras

`bl` est un nombre booléen : `0` signifie non bold, et `1` veut dire bold.

```typescript
interface IStyleData {
  bl: 1 // Bold
}
```

#### Soulignement

`ul` est un objet qui décrit le style de soulignement.

```typescript
interface IStyleData {
  ul: {
    s: 1 // Whether to show underline
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Underline color
      rgb: '#ff0000'
    }
    t: 0 // Underline type
  }
}
```

#### Barré

`st` est un objet qui décrit le style strikethrough.

```typescript
interface IStyleData {
  st: {
    s: 1 // Whether to show strikethrough
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Strikethrough color
      rgb: '#ff0000'
    }
    t: 0 // Strikethrough type
  }
}
```

#### Trait supérieur

`ol` est un objet qui décrit le style overline.

```typescript
interface IStyleData {
  ol: {
    s: 1 // Whether to show overline
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Overline color
      rgb: '#ff0000'
    }
    t: 0 // Overline type
  }
}
```

#### Couleur d'arrière-plan

`bg` est un objet qui décrit la couleur de l'arrière-plan.

```typescript
interface IStyleData {
  bg: {
    rgb: '#ff0000' // Background color is red
  }
}
```

#### Bordure

`bd` est un objet qui décrit le style de bordure.

```typescript
interface IStyleData {
  bd: {
    // Top border
    t: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Bottom border
    b: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Left border
    l: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Right border
    r: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
  }
}
```

#### Couleur de police

`cl` est un objet qui décrit la couleur de la police.

```typescript
interface IStyleData {
  cl: {
    rgb: '#ff0000' // Font color is red
  }
}
```

#### Exposant ou indice

`va` est un numéro d'enum : `1` signifie normal, `2` veut dire sous-script, et `3` désigne superscript.

```typescript
interface IStyleData {
  va: 2 // Subscript
}
```

#### Rotation du texte

`tr` est un objet qui décrit la rotation du texte.

```typescript
interface IStyleData {
  tr: {
    a: 0 // Text rotation angle
    v: 0 // Whether it is vertical. 1 means vertical, 0 means horizontal. The default value is 0. When v is 1, a is invalid
  }
}
```

#### Alignement horizontal

`ht` est un numéro d'enum : `1` signifie alignement gauche, `2` veut dire centre, et `3` indique alignement droit.

```typescript
interface IStyleData {
  ht: 1 // Left alignment
}
```

#### Alignement vertical

`vt` est un numéro d'enum : `1` signifie alignement supérieur, `2` indique centre, et `3` désigne alignement inférieur.

```typescript
interface IStyleData {
  vt: 1 // Top alignment
}
```

#### Gestion du dépassement du texte

`tb` est un numéro d'enum : `1` signifie débordement, `2` veut dire tronquer, et `3`, c'est envelopper.

```typescript
interface IStyleData {
  tb: 1 // Overflow
}
```

#### Marges internes

`pd` est un objet qui décrit le rembourrage.

```typescript
interface IStyleData {
  pd: {
    t: 0 // Top padding
    b: 0 // Bottom paddingAdd commentMore actions
    l: 0 // Left padding
    r: 0 // Right padding
  }
}
```

#### Format de nombre [#number-format]

`n` est un objet. Son champ `pattern` contient le format de nombre en tant que chaîne. Microsoft documente les codes de format [Ici.](https://support.microsoft.com/en-us/office/number-format-codes-5026bbd6-04bc-48cd-bf33-80f18b4eae68).

Si `n` est `null`, ou si `pattern` était `null` la cellule utilise le format général.

```typescript
import type { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

interface IStyleData {
  n: {
    pattern: DEFAULT_TEXT_FORMAT_EXCEL // text format
  }
}
```

Pour conserver un nombre qui commence par 0, ou un nombre qui pourrait être converti en format date, à partir d'une conversion automatique, voir [formatage des numéros](/guides/sheets/features/core/numfmt#usage).

### Type de cellule [#cell-type]

`cellData.t` est un enum [CellValueType](/reference/enums/cell-value-type) qui définit le type de cellule. `1` signifie chaîne, `2` signifie numéro, `3` signifie booléen, et `4` signifie force texte. Lorsque le champ n'est pas défini, Univer reconnaît automatiquement le type.

Une cellule booléenne stocke `cellData.v` comme `0` ou `1`: `0` signifie false, et `1` veut dire true.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        t: 1 // String
      }
      1: {
        v: 1
        t: 2 // Number
      }
      2: {
        v: 1 // TRUE
        t: 3 // Boolean
      }
      3: {
        v: '012.0'
        t: 4 // Force text
      }
    }
  }
}
```

L'alerte et la marque de texte de force sont contrôlées par `disableForceStringAlert` et `disableForceStringMark`. Vous pouvez les configurer dans :
  - [Mode prédéfini](/guides/sheets/features/core#univerjspreset-sheets-core)
  - [Mode plugin](/guides/sheets/features/core#univerjssheets-ui)

### Texte enrichi

`cellData.p` est un objet qui contient du texte riche, et cet objet est lui-même un Doc Univer. Voir [Données sur les documents](/reference/types/document-data) pour la structure complète.

<Callout>
  Lorsqu'une cellule a à la fois `p` et `v`, seul le contenu de `p` est affiché.
</Callout>

`cellData.p.body.dataStream` est le contenu texte riche.

### Formule

`cellData.f` est une formule, stockée comme une chaîne.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // function SUM
      }
    }
  }
}
```

### Identifiant de formule

`cellData.si` est une chaîne qui détient un id de formule. Univer Sheets optimise les formules par référence : une fois qu'une cellule associe sa formule à un `si`, d'autres cellules peuvent se référer à cette même formule par l'intermédiaire de `si`. La cellule qui transporte la `si` doit être au coin inférieur droit de la cellule de référence; sinon, l'exportation vers XLSX soulève une erreur.

Appelez le Facade API `range.getFormulas()` pour obtenir la formule réelle. Il prend la formule `f` que `si` pointe et calcule ensuite la formule réelle à partir du décalage entre la position de la cellule actuelle et la position de référence.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // Sum formula
        si: 'random_formula_id_1' // ID of the current formula
      }
      1: {
        si: 'random_formula_id_1' // Take the formula corresponding to this ID during calculation
      }
    }
  }
}
```

### Champ personnalisé

`cellData.custom` est un objet qui sert de champ personnalisé. Il accepte toutes les données qui sont valides JSON, de sorte qu'il peut stocker des informations supplémentaires de votre propre.

La mise à jour des données `custom` écrase les données `custom` existantes plutôt que de les fusionner. Pour conserver les données `custom` existantes, lisez d'abord les données `custom`, fusionnez-les dans les nouvelles données, puis mettez à jour.

<Callout type="warning">
  Le champ `custom` ne s'applique qu'à quelques scénarios spéciaux. Toute opération utilisateur peut écraser ou supprimer les données stockées dans ce champ, alors utilisez-le avec prudence.
</Callout>

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        custom: {
          key: 'value'
        }
      }
    }
  }
}
```
