## IWorksheetData

[`IWorksheetData`](https://reference.univer.ai/en-US/interfaces/IWorksheetData) representa la instantánea de una hoja de trabajo en Univer Sheet.

### Propiedades

| Propiedad | Tipo | Descripción |
|----------|------|-------------|
| id | `string` | Identificador único de la hoja de trabajo. |
| name | `string` | Nombre de la hoja de trabajo. |
| tabColor | `string` | Color de la pestaña de la hoja de trabajo. |
| hidden | `BooleanNumber` | Si la hoja está oculta. Valor predeterminado: `BooleanNumber.FALSE`. |
| freeze | `IFreeze` | Configuración del panel congelado. |
| rowCount | `number` | Número total de filas. |
| columnCount | `number` | Número total de columnas. |
| defaultColumnWidth | `number` | Ancho predeterminado para columnas, unidad `px`. |
| defaultRowHeight | `number` | Alto predeterminado para filas, unidad `px`. |
| mergeData | `IRange[]` | Matriz de rangos de celdas fusionadas. |
| cellData | `IObjectMatrixPrimitiveType<ICellData>` | Matriz de contenidos de celdas. [Más detalles.](/guides/sheets/model/cell-data) |
| rowData | `IObjectArrayPrimitiveType<Partial<IRowData>>` | Matriz de objetos de datos de fila. |
| columnData | `IObjectArrayPrimitiveType<Partial<IColumnData>>` | Matriz de objetos de datos de columna. |
| rowHeader | `{ width: number; hidden?: BooleanNumber; }` | Configuración del encabezado de fila. |
| columnHeader | `{ height: number; hidden?: BooleanNumber; }` | Configuración del encabezado de columna. |
| showGridlines | `BooleanNumber` | Si las líneas de la cuadrícula son visibles. |
| rightToLeft | `BooleanNumber` | Si la hoja de cálculo está en modo de derecha a izquierda. |
| [defaultStyle](/guides/sheets/features/core/default-style)? | `Nullable<IStyleData>` | El estilo predeterminado de hoja de trabajo|

### Ejemplo

```typescript
const worksheetData: IWorksheetData = {
  id: 'sheet1',
  name: 'Sheet 1',
  tabColor: '#FF0000',
  hidden: BooleanNumber.FALSE,
  freeze: { xSplit: 1, ySplit: 1, startRow: 1, startColumn: 1 },
  rowCount: 1000,
  columnCount: 26,
  defaultColumnWidth: 100,
  defaultRowHeight: 25,
  mergeData: [],
  cellData: {
    0: {
      0: {
        v: 123,
      },
    },
  },
  rowData: [],
  columnData: [],
  rowHeader: { width: 40 },
  columnHeader: { height: 20 },
  showGridlines: BooleanNumber.TRUE,
  rightToLeft: BooleanNumber.FALSE,
}
```

Esta estructura proporciona una representación completa de la hoja de trabajo datos, incluido el diseño, el contenido y la configuración de visualización.
