## Posición de celda

Univer Sheets almacena datos de células en el campo [cellData](/reference/types/worksheet-data#celldata) de un objeto [IWorksheetData](/reference/types/worksheet-data). Ese campo contiene toda la información sobre una célula, incluyendo su valor, estilo y tipo.

El siguiente código muestra la forma de cellData.

```typescript
interface IWorksheetData {
  cellData: {
    // first row
    0: {
      // first column
      0: { v: 'A1' }
      // second column
      1: { v: 'B1' }
    }
    // second row
    1: {
      // first column
      0: { v: 'A2' }
      // second column
      1: { v: 'B2' }
    }
  }
}
```

## Datos de celda

Una célula tiene las siguientes propiedades.

| Propiedad | Descripción |
| --- | --- |
| v | Valor original de la celda |
| s | Id. de estilo de celda u objeto de estilo |
| t | Tipo de celda |
| p | Texto enriquecido, también 📝 Univer Docs |
| f | Formula |
| si | Id. de fórmula |
| custom | Campo personalizado |

Ver [ICellData](/reference/types/cell-data) para el tipo de cada propiedad.

### Valor original de la celda

`cellData.v` posee el valor original de una célula, que es una cadena o un número. En una célula que tiene una fórmula, `v` tiene el resultado de esa fórmula.

El ejemplo a continuación almacena una cadena en una celda y un número en la otra.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: { v: 'A1' }
      1: { v: 1 }
    }
  }
}
```

### Estilo de celda

`cellData.s` posee un id de estilo o un objeto de estilo.

Cuando `s` es una cadena, es un estilo id. Univer Hojas optimiza estilos por referencia, por lo que un objeto de estilo repetido se almacena una vez, en el campo [estilos](/reference/types/workbook-data#styles) de IWorkbookData. Ese campo es un mapa: cada clave es un id de estilo, y cada valor es un objeto de diseño.

<Callout type="warning">
  Evite los valores de color que llevan transparencia, como rgba. Cuando una célula con ese tipo de fondo entra en el estado de edición, el contenido de la célula debajo se muestra a través.
</Callout>

```typescript
interface IWorkbookData {
  styles: {
    random_style_id_1: {
      fs: 12
      bg: {
        rgb: '#ff0000'
      }
    }
  }
}
```

Cuando una célula referencia que id, el objeto de estilo se reutiliza.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        s: 'random_style_id_1'
      }
      1: {
        v: 'B1'
        s: 'random_style_id_1'
      }
    }
  }
}
```

Cuando `s` es un objeto, es un objeto de estilo completo ([IStyleData](/reference/types/style-data)).

Los campos de estilo se enumeran a continuación.

| Propiedad | Descripción |
| --- | --- |
| ff | Font |
| fs | Tamaño de fuente |
| it | Italic |
| bl | Bold |
| ul | Underline |
| st | Strikethrough |
| ol | Overline |
| bg | Fondo color |
| bd | Border |
| cl | Color de fuente |
| va | Superíndice o subíndice |
| tr | Rotación de texto |
| ht | Alineación horizontal |
| vt | Alineación vertical |
| tb | Truncar desbordamiento |
| pd | Padding |
| n | Formato de números |

Ver [IStyleData](/reference/types/style-data) para el tipo de cada campo.

#### Fuente

`ff` es el nombre de la fuente, como una cadena.

```typescript
interface IStyleData {
  ff: 'Arial' // Font name is Arial
}
```

#### Tamaño de fuente

`fs` es un número, en **pt**.

```typescript
interface IStyleData {
  fs: 12 // Font size is 12 pt
}
```

#### Cursiva

`it` es un número booleano: `0` no significa itálico, y `1` significa itálica.

```typescript
interface IStyleData {
  it: 1 // Italic
}
```

#### Negrita

`bl` es un número booleano: `0` significa no audaz, y `1` quiere decir negrita.

```typescript
interface IStyleData {
  bl: 1 // Bold
}
```

#### Subrayado

`ul` es un objeto que describe el estilo de línea.

```typescript
interface IStyleData {
  ul: {
    s: 1 // Whether to show underline
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Underline color
      rgb: '#ff0000'
    }
    t: 0 // Underline type
  }
}
```

#### Tachado

`st` es un objeto que describe el estilo strikethrough.

```typescript
interface IStyleData {
  st: {
    s: 1 // Whether to show strikethrough
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Strikethrough color
      rgb: '#ff0000'
    }
    t: 0 // Strikethrough type
  }
}
```

#### Sobrelínea

`ol` es un objeto que describe el estilo overline.

```typescript
interface IStyleData {
  ol: {
    s: 1 // Whether to show overline
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Overline color
      rgb: '#ff0000'
    }
    t: 0 // Overline type
  }
}
```

#### Color de fondo

`bg` es un objeto que describe el color de fondo.

```typescript
interface IStyleData {
  bg: {
    rgb: '#ff0000' // Background color is red
  }
}
```

#### Borde

`bd` es un objeto que describe el estilo fronterizo.

```typescript
interface IStyleData {
  bd: {
    // Top border
    t: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Bottom border
    b: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Left border
    l: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Right border
    r: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
  }
}
```

#### Color de fuente

`cl` es un objeto que describe el color de la fuente.

```typescript
interface IStyleData {
  cl: {
    rgb: '#ff0000' // Font color is red
  }
}
```

#### Superíndice o subíndice

`va` es un número de enum: `1` significa normal, `2` quiere decir subscript, y `3` implica superscript.

```typescript
interface IStyleData {
  va: 2 // Subscript
}
```

#### Rotación de texto

`tr` es un objeto que describe la rotación de texto.

```typescript
interface IStyleData {
  tr: {
    a: 0 // Text rotation angle
    v: 0 // Whether it is vertical. 1 means vertical, 0 means horizontal. The default value is 0. When v is 1, a is invalid
  }
}
```

#### Alineación horizontal

`ht` es un número enum: `1` significa alineación izquierda, `2` quiere decir centro, y `3` implica alineación derecha.

```typescript
interface IStyleData {
  ht: 1 // Left alignment
}
```

#### Alineación vertical

`vt` es un número enum: `1` significa alineación superior, `2` quiere decir centro, y `3` implica alineación inferior.

```typescript
interface IStyleData {
  vt: 1 // Top alignment
}
```

#### Truncar desbordamiento

`tb` es un número de enum: `1` significa desbordamiento, `2` quiere decir truncate, y `3` implica envoltura.

```typescript
interface IStyleData {
  tb: 1 // Overflow
}
```

#### Relleno

`pd` es un objeto que describe el relleno.

```typescript
interface IStyleData {
  pd: {
    t: 0 // Top padding
    b: 0 // Bottom paddingAdd commentMore actions
    l: 0 // Left padding
    r: 0 // Right padding
  }
}
```

#### Formato de número [#number-format]

`n` es un objeto. Su campo `pattern` tiene el formato número como una cadena. Microsoft documenta los códigos de formato [aquí.](https://support.microsoft.com/en-us/office/number-format-codes-5026bbd6-04bc-48cd-bf33-80f18b4eae68).

Si `n` es `null`, o si `pattern` está `null` , la célula utiliza el formato general.

```typescript
import type { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

interface IStyleData {
  n: {
    pattern: DEFAULT_TEXT_FORMAT_EXCEL // text format
  }
}
```

Para mantener un número que comienza con 0, o uno que podría ser convertido a un formato de fecha, de ser convertido automáticamente, vea [formato de número](/guides/sheets/features/core/numfmt#usage).

### Tipo de celda [#cell-type]

`cellData.t` es un enum [CellValueType](/reference/enums/cell-value-type) que establece el tipo de la célula. `1` significa cadena, `2` significa número, `3` significa booleano, y `4` significa texto de fuerza. Cuando el campo no se establece, Univer reconoce el tipo automáticamente.

Una bodega booleana `cellData.v` como `0` o `1`: `0` significa falso, y `1` es cierto.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        t: 1 // String
      }
      1: {
        v: 1
        t: 2 // Number
      }
      2: {
        v: 1 // TRUE
        t: 3 // Boolean
      }
      3: {
        v: '012.0'
        t: 4 // Force text
      }
    }
  }
}
```

La alerta y la marca de texto de la fuerza son controladas por `disableForceStringAlert` y `disableForceStringMark`. Puede configurarlas en:
  - [Modo preestablecido](/guides/sheets/features/core#univerjspreset-sheets-core)
  - [Modo complemento](/guides/sheets/features/core#univerjssheets-ui)

### Texto enriquecido

`cellData.p` es un objeto que contiene texto rico, y ese objeto es en sí mismo un Univer Doc. Ver [IDocumentData](/reference/types/document-data) para la estructura completa.

<Callout>
  Cuando una célula tiene tanto `p` como `v` conjunto, sólo se muestran los contenidos de `p`.
</Callout>

`cellData.p.body.dataStream` es el rico contenido de texto.

### Fórmula

`cellData.f` es una fórmula, almacenada como una cadena.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // function SUM
      }
    }
  }
}
```

### ID de fórmula

`cellData.si` es una cadena que sostiene una fórmula id. Univer Hojas optimiza fórmulas por referencia: una vez que una célula asocia su fórmula con un `si`, otras células pueden referirse a esa misma fórmula a través de `si`. La célula que lleva el `si` debe estar en la esquina inferior derecha de la célula de referencia; de lo contrario, exportar un error a XLS

Llame al Facade API `range.getFormulas()` para obtener la fórmula real. Se necesita la fórmula `f` que `si` indica y luego computa la fórmula real del offset entre la posición actual de la célula y la posición de referencia.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // Sum formula
        si: 'random_formula_id_1' // ID of the current formula
      }
      1: {
        si: 'random_formula_id_1' // Take the formula corresponding to this ID during calculation
      }
    }
  }
}
```

### Campo personalizado

`cellData.custom` es un objeto que sirve como un campo personalizado. Acepta cualquier dato que sea válido JSON, por lo que puede almacenar información adicional de su propio.

Actualizar los datos `custom` sobrescribe los datos `custom` existentes en lugar de fusionarse con él. Para mantener los datos existentes `custom`, leer primero los `custom` datos, fusionarlos en los nuevos datos, y luego actualizarlos.

<Callout type="warning">
  El campo `custom` se aplica sólo a algunos escenarios especiales. Cualquier operación del usuario puede sobreescribir o eliminar los datos almacenados en este campo, así que úsalo con precaución.
</Callout>

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        custom: {
          key: 'value'
        }
      }
    }
  }
}
```
