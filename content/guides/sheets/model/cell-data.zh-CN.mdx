## 单元格位置

Univer Sheets 将单元格数据存储在 [IWorksheetData](/reference/types/worksheet-data) 的 [cellData](/reference/types/worksheet-data#celldata) 字段中。cellData 是一个二维 Map，一级索引是行号，二级索引是列号，每个单元格是一个 [ICellData](/reference/types/cell-data) 对象，值、样式、类型等信息都包含在内。

cellData 的结构如下。

```typescript
interface IWorksheetData {
  cellData: {
    // 第一行
    0: {
      // 第一列
      0: { v: 'A1' }
      // 第二列
      1: { v: 'B1' }
    }
    // 第二行
    1: {
      // 第一列
      0: { v: 'A2' }
      // 第二列
      1: { v: 'B2' }
    }
  }
}
```

## 单元格信息

单元格包含以下属性。

| 属性 | 说明 |
| --- | --- |
| v | 单元格的原始值 |
| s | 单元格的样式 id 或者样式对象 |
| t | 单元格的类型 |
| p | 富文本，同时也是一个 📝 Univer Docs |
| f | 公式 |
| si | 公式 ID |
| custom | 自定义字段 |

各字段的类型定义见 [ICellData](/reference/types/cell-data)。

### 单元格原始值

`cellData.v` 存储单元格的原始值，可以是字符串，也可以是数字。单元格中包含公式时，`v` 存储公式的计算结果。

下面的示例在一个单元格中存储字符串，在另一个单元格中存储数字。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: { v: 'A1' }
      1: { v: 1 }
    }
  }
}
```

### 单元格样式

`cellData.s` 存储样式 id 或者样式对象。

当 `s` 为字符串时，它是样式 id。Univer Sheets 对样式做引用优化，因此重复的样式对象只存储一份，放在 IWorkbookData 的 [styles](/reference/types/workbook-data#styles) 字段中。该字段是一个 Map，键为样式 id，值为样式对象。

<Callout type="warning">
  避免使用带透明度的颜色值，例如 rgba。单元格背景使用这类颜色时，进入编辑状态会透出下方单元格的内容。
</Callout>

```typescript
interface IWorkbookData {
  styles: {
    random_style_id_1: {
      fs: 12
      bg: {
        rgb: '#ff0000'
      }
    }
  }
}
```

在单元格样式中引用该 id，即可复用这份样式对象。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        s: 'random_style_id_1'
      }
      1: {
        v: 'B1'
        s: 'random_style_id_1'
      }
    }
  }
}
```

当 `s` 为对象时，它是一个完整的样式对象 [IStyleData](/reference/types/style-data)。

样式字段如下。

| 属性 | 说明 |
| --- | --- |
| ff | 字体 |
| fs | 字体大小 |
| it | 是否斜体 |
| bl | 是否加粗 |
| ul | 下划线 |
| st | 删除线 |
| ol | 上划线 |
| bg | 背景颜色 |
| bd | 边框 |
| cl | 字体颜色 |
| va | 上标下标 |
| tr | 文字旋转 |
| ht | 水平对齐方式 |
| vt | 垂直对齐方式 |
| tb | 截断溢出 |
| pd | 内边距 |
| n | 数字格式 |

各字段的类型定义见 [IStyleData](/reference/types/style-data)。

#### 字体

`ff` 是字体名称，类型为字符串。

```typescript
interface IStyleData {
  ff: 'Arial' // 字体名称为 Arial
}
```

#### 字体大小

`fs` 是数字，单位为 **pt**。

```typescript
interface IStyleData {
  fs: 12 // 字体大小为 12 pt
}
```

#### 是否斜体

`it` 是布尔数字：`0` 表示不斜体，`1` 表示斜体。

```typescript
interface IStyleData {
  it: 1 // 斜体
}
```

#### 是否加粗

`bl` 是布尔数字：`0` 表示不加粗，`1` 表示加粗。

```typescript
interface IStyleData {
  bl: 1 // 加粗
}
```

#### 下划线

`ul` 是一个对象，描述下划线样式。

```typescript
interface IStyleData {
  ul: {
    s: 1 // 是否展示下划线
    c: 0 // 颜色是否跟随字体颜色。当 `c` 为 1（TRUE） 时 cl 不起作用。默认值为 1
    cl: { // 下划线颜色
      rgb: '#ff0000'
    }
    t: 0 // 下划线类型
  }
}
```

#### 删除线

`st` 是一个对象，描述删除线样式。

```typescript
interface IStyleData {
  st: {
    s: 1 // 是否展示删除线
    c: 0 // 颜色是否跟随字体颜色。当 `c` 为 1（TRUE） 时 cl 不起作用。默认值为 1
    cl: { // 删除线颜色
      rgb: '#ff0000'
    }
    t: 0 // 删除线类型
  }
}
```

#### 上划线

`ol` 是一个对象，描述上划线样式。

```typescript
interface IStyleData {
  ol: {
    s: 1 // 是否展示上划线
    c: 0 // 颜色是否跟随字体颜色。当 `c` 为 1（TRUE） 时 cl 不起作用。默认值为 1
    cl: { // 上划线颜色
      rgb: '#ff0000'
    }
    t: 0 // 上划线类型
  }
}
```

#### 背景颜色

`bg` 是一个对象，描述背景颜色。

```typescript
interface IStyleData {
  bg: {
    rgb: '#ff0000' // 背景颜色为红色
  }
}
```

#### 边框

`bd` 是一个对象，描述边框样式。

```typescript
interface IStyleData {
  bd: {
    // 上边框
    t: {
      s: 0 // 边框样式
      cl: { // 边框颜色
        rgb: '#ff0000'
      }
    }
    // 下边框
    b: {
      s: 0 // 边框样式
      cl: { // 边框颜色
        rgb: '#ff0000'
      }
    }
    // 左边框
    l: {
      s: 0 // 边框样式
      cl: { // 边框颜色
        rgb: '#ff0000'
      }
    }
    // 右边框
    r: {
      s: 0 // 边框样式
      cl: { // 边框颜色
        rgb: '#ff0000'
      }
    }
  }
}
```

#### 字体颜色

`cl` 是一个对象，描述字体颜色。

```typescript
interface IStyleData {
  cl: {
    rgb: '#ff0000' // 字体颜色为红色
  }
}
```

#### 上标下标

`va` 是数字枚举：`1` 表示正常，`2` 表示下标，`3` 表示上标。

```typescript
interface IStyleData {
  va: 2 // 下标
}
```

#### 文字旋转

`tr` 是一个对象，描述文字旋转。

```typescript
interface IStyleData {
  tr: {
    a: 0 // 文字旋转角度
    v: 0 // 是否垂直。1 表示垂直，0 表示水平。默认值为 0。当 v 为 1 时，a 无效
  }
}
```

#### 水平对齐方式

`ht` 是数字枚举，`1` 表示左对齐，`2` 表示居中`，3` 表示右对齐。

```typescript
interface IStyleData {
  ht: 1 // 左对齐
}
```

#### 垂直对齐方式

`vt` 是数字枚举：`1` 表示顶部对齐，`2` 表示居中，`3` 表示底部对齐。

```typescript
interface IStyleData {
  vt: 1 // 顶部对齐
}
```

#### 截断溢出

`tb` 是数字枚举：`1` 表示溢出，`2` 表示截断，`3` 表示自动换行。

```typescript
interface IStyleData {
  tb: 1 // 溢出
}
```

#### 内边距

`pd` 是一个对象，描述内边距。

```typescript
interface IStyleData {
  pd: {
    t: 0 // 上边距
    b: 0 // 下边距
    l: 0 // 左边距
    r: 0 // 右边距
  }
}
```

#### 数字格式 [#number-format]

`n` 是一个对象，其 `pattern` 字段存储数字格式。该字段为字符串，具体写法参见 [这里](https://support.microsoft.com/zh-cn/office/%E6%95%B0%E5%AD%97%E6%A0%BC%E5%BC%8F%E4%BB%A3%E7%A0%81-5026bbd6-04bc-48cd-bf33-80f18b4eae68)。

当 `n` 为 `null`，或 `pattern` 为 `null` 时，单元格使用常规格式。

```typescript
import type { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

interface IStyleData {
  n: {
    pattern: DEFAULT_TEXT_FORMAT_EXCEL // 文本格式
  }
}
```

如需避免以 0 开头或可转换为日期格式的数字被自动转换，参见[数字格式](/guides/sheets/features/core/numfmt#usage)。

### 单元格类型 [#cell-type]

`cellData.t` 是 [CellValueType](/reference/enums/cell-value-type) 枚举，用于设置单元格类型。`1` 表示字符串，`2` 表示数字，`3` 表示布尔值，`4` 表示强制文本。未设置该字段时，Univer 会自动识别类型。

布尔类型单元格的 `cellData.v` 为 `0` 或 `1`：`0` 表示 false，`1` 表示 true。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        t: 1 // 字符串
      }
      1: {
        v: 1
        t: 2 // 数字
      }
      2: {
        v: 1 // TRUE
        t: 3 // 布尔值
      }
      3: {
        v: '012.0'
        t: 4 // 强制文本
      }
    }
  }
}
```

强制文本的警告和标记由 `disableForceStringAlert` 和 `disableForceStringMark` 控制，可在以下位置配置：
  - [预设模式](/guides/sheets/features/core#univerjspreset-sheets-core)
  - [插件模式](/guides/sheets/features/core#univerjssheets-ui)

### 富文本

`cellData.p` 是一个对象，用于存储富文本，该对象本身也是一个 Univer Doc。完整结构见 [IDocumentData](/reference/types/document-data)。

<Callout>
  当单元格同时设置 `p` 和 `v` 时，只显示 `p` 的内容。
</Callout>

`cellData.p.body.dataStream` 存储富文本内容。

### 公式

`cellData.f` 是公式，以字符串形式存储。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // 求和公式
      }
    }
  }
}
```

### 公式 ID

`cellData.si` 是字符串，存储公式 id。Univer Sheets 对公式做引用优化：单元格通过 `si` 关联公式后，其他单元格可以通过同一个 `si` 引用该公式。包含 `si` 的单元格必须位于被引用单元格的右下角，否则导出 XLSX 时会报错。

可通过 Facade API `range.getFormulas()` 获取实际公式。该方法先取 `si` 指向的公式 `f`，再根据当前单元格位置与引用位置之间的偏移量计算实际公式。

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // 求和公式
        si: 'random_formula_id_1' // 当前公式的 id
      }
      1: {
        si: 'random_formula_id_1' // 计算时取此 id 对应的公式
      }
    }
  }
}
```

### 自定义字段

`cellData.custom` 是一个对象，用作自定义字段。它可以存放任何符合 JSON 格式的数据，用于存储自行定义的附加信息。

更新 `custom` 数据会覆盖现有的 `custom` 数据，而不会合并。如需保留现有的 `custom` 数据，请先读取该数据，将其合并到新数据后再更新。

<Callout type="warning">
  `custom` 字段仅适用于少数特殊场景。任何用户操作都可能覆盖或删除存储在该字段中的数据，请谨慎使用。
</Callout>

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        custom: {
          key: 'value'
        }
      }
    }
  }
}
```
