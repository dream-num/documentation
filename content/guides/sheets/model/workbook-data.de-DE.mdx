## IWorkbookData

[`IWorkbookData`](https://reference.univer.ai/en-US/interfaces/IWorkbookData) stellt die Momentaufnahme einer Arbeitsmappe in Univer Sheet dar.

### Eigenschaften

| Eigenschaft | Typ | Beschreibung |
|----------|------|-------------|
| id | `string` | Eindeutige Kennung der Univer Sheets. |
| name | `string` | Name der Univer Sheets. |
| appVersion | `string` | Version der Univer-Modelldefinition. |
| locale | `LocaleType` | Gebietsschema des Dokuments. |
| styles | `Record<string, Nullable<IStyleData>>` | Stilreferenzen für die Arbeitsmappe. |
| sheetOrder | `string[]` | Array von Blatt-IDs, die die Reihenfolge der Arbeitsblätter darstellen. |
| sheets | `{ [sheetId: string]: Partial<IWorksheetData> }` | Datensatz mit Daten für jedes Arbeitsblatt. |
| resources? | `IResources` | Speichern Sie die Daten von Plugins |

### Beispiel

```typescript
const workbookData: IWorkbookData = {
  id: 'unique-workbook-id',
  name: 'My Workbook',
  appVersion: '0.10.2',
  locale: LocaleType.EN_US,
  styles: { /* style definitions */ },
  sheetOrder: ['sheet1', 'sheet2'],
  sheets: {
    sheet1: { /* sheet data */ },
    sheet2: { /* sheet data */ },
  },
}
```

### Verwendung

IWorkbookData ist das Objekt, das zum Speichern von Daten in Univer Sheets verwendet wird. Es wird hauptsächlich verwendet für:

1. [Erstellen von Univer Sheets mit IWorkbookData](/guides/sheets/features/core/sheets-api#create-worksheet)
2. [Speichern von IWorkbookData aus Univer Sheets](/guides/sheets/features/core/sheets-api#get-workbook-data)

`resources` Eigenschaft ist Wird zur Speicherung von Plugin-Daten verwendet. Gehen Sie zu [Plugin Custom Model](/guides/recipes/tutorials/custom-model)
