## IWorkbookData

[`IWorkbookData`](/reference/types/workbook-data)はUniverシートのワークブックのスナップショットです。

### プロパティ

| プロパティ | タイプ                                           | 説明                                       |
| ---------- | ------------------------------------------------ | ------------------------------------------ |
| id | `string` | ワークブックのユニークな識別子。 |
| name | `string` | ワークブックの名前。 |
| appVersion | `string`                                         | Univer モデル定義のバージョン。            |
| locale     | `LocaleType`                                     | ドキュメントのロケール。                   |
| styles     | `Record<string, Nullable<IStyleData>>`           | ワークブックのスタイル参照。               |
| sheetOrder | `string[]` | シートのIDは、シートの順番に表示されます。 |
| sheets     | `{ [sheetId: string]: Partial<IWorksheetData> }` | 各ワークシートのデータを含むレコード。     |
| resources? | `IResources` | プラグインが保有するデータ。 |

### 例

```typescript
const workbookData: IWorkbookData = {
  id: 'unique-workbook-id',
  name: 'My Workbook',
  appVersion: '0.10.2',
  locale: LocaleType.JA_JP,
  styles: {/* スタイル定義 */},
  sheetOrder: ['sheet1', 'sheet2'],
  sheets: {
    sheet1: {/* シートデータ */},
    sheet2: {/* シートデータ */},
  },
}
```

### 使い方

Univerシートは、IWorkbookDataでワークブックデータを保存します。この構造は2つの状況で使用されます。

1. [IWorkbookDataからワークブックを作成する](/guides/sheets/features/core/sheets-api#create-worksheet)
2. [ワークブックのデータをIWorkbookDataとして保存する](/guides/sheets/features/core/sheets-api#get-workbook-data)

`resources` プロパティは、プラグインが所有するデータを保持しています。 [プラグインカスタムモデル](/blog/custom-model)を参照してください。
