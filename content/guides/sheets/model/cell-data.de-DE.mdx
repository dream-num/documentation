## Zellenposition

Die Zellendaten in Univer Sheets werden im Feld [cellData](https://reference.univer.ai/en-US/interfaces/IWorkbookData) des Objekts [IWorksheetData](https://reference.univer.ai/en-US/interfaces/ICellData) gespeichert, das alle enthält die Zellinformationen wie Zellwert, Stil, Typ usw.

Die Struktur von cellData ist wie folgt

```typescript
interface IWorksheetData {
  cellData: {
    // first row
    0: {
      // first column
      0: { v: 'A1' }
      // second column
      1: { v: 'B1' }
    }
    // second row
    1: {
      // first column
      0: { v: 'A2' }
      // second column
      1: { v: 'B2' }
    }
  }
}
```

## Zellendaten

Die vollständigen Zelleninformationen sind wie folgt.

| Eigenschaft | Beschreibung |
| --- | --- |
| v | Originalwert der Zelle |
| s | Zellenstil-ID oder Stilobjekt |
| t | Zellentyp |
| p | Rich-Text, auch ein 📝 Univer Docs |
| f | Formula |
| si | Formel-ID |
| custom | Benutzerdefiniertes Feld |

Sehen Sie sich die Typinformationen jedes Felds von [ICellData](https://reference.univer.ai/en-US/interfaces/ICellData) an.

### Originalwert der Zelle

`cellData.v` speichert den ursprünglichen Wert der Zelle, der eine Zeichenfolge oder eine Zahl sein kann. Für Zellen mit Formeln speichert `v` das Berechnungsergebnis der Formel.

Hier zeigen wir zwei verschiedene Zellwerte.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: { v: 'A1' }
      1: { v: 1 }
    }
  }
}
```

### Zellenstil

`cellData.s` speichert die Stil-ID oder das Stilobjekt der Zelle.

Wenn `s` eine Zeichenfolge ist, stellt sie eine Stil-ID dar. Univer Sheets unterstützt die Referenzoptimierung für Stile. Die wiederholten Stilobjekte werden im Feld [styles](https://reference.univer.ai/en-US/interfaces/IWorkbookData#styles) von IWorkbookData gespeichert, einer Map-Struktur. Jeder Schlüssel ist die Stil-ID und der Wert ist das Stilobjekt.

<Callout type="warning">
Bitte vermeiden Sie die Verwendung von Farbwerten mit Transparenz (z. B. rgba), da der Hintergrund sonst den Inhalt der darunter liegenden Zelle anzeigt, wenn der Bearbeitungsstatus aktiviert wird.
</Callout>

```typescript
interface IWorkbookData {
  styles: {
    random_style_id_1: {
      fs: 12
      bg: {
        rgb: '#ff0000'
      }
    }
  }
}
```

Speichern Sie dann die ID im Zellenstil, um den Zweck des Stils zu erreichen Wiederverwendung.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        s: 'random_style_id_1'
      }
      1: {
        v: 'B1'
        s: 'random_style_id_1'
      }
    }
  }
}
```

Wenn `s` ein Objekt ist, stellt es ein vollständiges Zellenstilobjekt dar [IStyleData](https://reference.univer.ai/en-US/interfaces/IStyleData).

Das vollständige Stilfeld sieht wie folgt aus.

| Eigenschaft | Beschreibung |
| --- | --- |
| ff | Font |
| fs | Schriftart Größe |
| it | Italic |
| bl | Bold |
| ul | Underline |
| st | Strikethrough |
| ol | Overline |
| bg | Hintergrundfarbe |
| bd | Border |
| cl | Schriftfarbe |
| va | Hochgestellt oder tiefgestellt |
| tr | Textdrehung |
| ht | Horizontale Ausrichtung |
| vt | Vertikale Ausrichtung |
| tb | Überlauf abschneiden |
| pd | Padding |
| n | Zahlenformat |

Sie können die Typinformationen jedes Felds von überprüfen [IStyleData](https://reference.univer.ai/en-US/interfaces/IStyleData).

#### Schriftart

`ff` ist eine Zeichenfolge, die den Schriftartnamen darstellt.

```typescript
interface IStyleData {
  ff: 'Arial' // Font name is Arial
}
```

#### Schriftgröße

`fs` ist eine Zahl, die Einheit ist **pt**.

```typescript
interface IStyleData {
  fs: 12 // Font size is 12 pt
}
```

#### Kursiv

`it` ist eine boolesche Zahl, `0` bedeutet nicht kursiv, `1` bedeutet kursiv.

```typescript
interface IStyleData {
  it: 1 // Italic
}
```

#### Fett

`bl` ist eine boolesche Zahl, `0` bedeutet nicht fett, `1` bedeutet Fett.

```typescript
interface IStyleData {
  bl: 1 // Bold
}
```

#### Unterstreichen

`ul` ist ein Objekt, stellt den Unterstreichungsstil dar.

```typescript
interface IStyleData {
  ul: {
    s: 1 // Whether to show underline
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Underline color
      rgb: '#ff0000'
    }
    t: 0 // Underline type
  }
}
```

#### Durchgestrichen

`st` ist ein Objekt, stellt den Durchstreichungsstil dar.

```typescript
interface IStyleData {
  st: {
    s: 1 // Whether to show strikethrough
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Strikethrough color
      rgb: '#ff0000'
    }
    t: 0 // Strikethrough type
  }
}
```

#### Überstreichen

`ol` ist ein Objekt, stellt den Überstrichstil dar.

```typescript
interface IStyleData {
  ol: {
    s: 1 // Whether to show overline
    c: 0 // Whether the color follows the font color. When `c` is 1 (TRUE), cl does not work. The default value is 1
    cl: { // Overline color
      rgb: '#ff0000'
    }
    t: 0 // Overline type
  }
}
```

#### Hintergrundfarbe

`bg` ist ein Objekt, stellt die Hintergrundfarbe dar.

```typescript
interface IStyleData {
  bg: {
    rgb: '#ff0000' // Background color is red
  }
}
```

#### Rahmen

`bd` ist ein Objekt, stellt den Rahmenstil dar.

```typescript
interface IStyleData {
  bd: {
    // Top border
    t: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Bottom border
    b: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Left border
    l: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
    // Right border
    r: {
      s: 0 // Border style
      cl: { // Border color
        rgb: '#ff0000'
      }
    }
  }
}
```

#### Schriftfarbe

`cl` ist ein Objekt, stellt Schriftart dar Farbe.

```typescript
interface IStyleData {
  cl: {
    rgb: '#ff0000' // Font color is red
  }
}
```

#### Hochgestellt oder tiefgestellt

`va` ist eine Aufzählungszahl, `1` bedeutet normal, `2` bedeutet tiefgestellt, `3` bedeutet hochgestellt.

```typescript
interface IStyleData {
  va: 2 // Subscript
}
```

#### Text Rotation

`tr` ist ein Objekt, das die Textdrehung darstellt.

```typescript
interface IStyleData {
  tr: {
    a: 0 // Text rotation angle
    v: 0 // Whether it is vertical. 1 means vertical, 0 means horizontal. The default value is 0. When v is 1, a is invalid
  }
}
```

#### Horizontale Ausrichtung

`ht` ist eine Aufzählungszahl, `1` bedeutet Linksausrichtung, `2` bedeutet Mitte, `3` bedeutet rechte Ausrichtung.

```typescript
interface IStyleData {
  ht: 1 // Left alignment
}
```

#### Vertikale Ausrichtung

`vt` ist eine Enum-Zahl, `1` bedeutet obere Ausrichtung, `2` bedeutet Mitte, `3` bedeutet unten Ausrichtung.

```typescript
interface IStyleData {
  vt: 1 // Top alignment
}
```

#### Überlauf abschneiden

`tb` ist eine Enum-Nummer, `1` bedeutet Überlauf, `2` bedeutet Abschneiden, `3` bedeutet Wrap.

```typescript
interface IStyleData {
  tb: 1 // Overflow
}
```

#### Polsterung

`pd` ist ein Objekt, das Auffüllen darstellt.

```typescript
interface IStyleData {
  pd: {
    t: 0 // Top padding
    b: 0 // Bottom paddingAdd commentMore actions
    l: 0 // Left padding
    r: 0 // Right padding
  }
}
```

#### Zahlenformat [#Zahlenformat]

`n` ist ein Objekt. Das Feld `pattern` gibt das Zahlenformat an. Das Zahlenformat ist eine Zeichenfolge, siehe [hier](https://support.microsoft.com/en-us/office/number-format-codes-5026bbd6-04bc-48cd-bf33-80f18b4eae68)。

`n` ist `null` oder `pattern` ist `null`. Gibt das allgemeine Format an.

```typescript
import type { DEFAULT_TEXT_FORMAT_EXCEL } from '@univerjs/core'

interface IStyleData {
  n: {
    pattern: DEFAULT_TEXT_FORMAT_EXCEL // text format
  }
}
```

[Ich möchte nicht, dass die Zelle standardmäßig konvertiert wird, wenn eine Zahl eingegeben wird, die mit 0 beginnt, oder eine Zahl, die in ein Datumsformat konvertiert werden kann](/guides/sheets/features/core/numfmt#qa-1)

### Zellentyp [#cell-type]

`cellData.t` ist eine Aufzählung [CellValueType](https://reference.univer.ai/en-US/globals#cellvaluetype), die den Typ der Zelle darstellt. `1` bedeutet Zeichenfolge, `2` bedeutet Zahl, `3` bedeutet Boolescher Wert, `4` bedeutet Krafttext. Univer erkennt es automatisch, wenn es nicht eingestellt ist.

Wenn die Zelle einen booleschen Typ hat, wird der Wert von `cellData.v` als `0` oder `1` gespeichert. `0` bedeutet „falsch“, `1` bedeutet „wahr“.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        v: 'A1'
        t: 1 // String
      }
      1: {
        v: 1
        t: 2 // Number
      }
      2: {
        v: 1 // TRUE
        t: 3 // Boolean
      }
      3: {
        v: '012.0'
        t: 4 // Force text
      }
    }
  }
}
```

Sie können steuern, ob die Force-Text-Warnung und -Markierung aktiviert werden soll, indem Sie `disableForceStringAlert` und `disableForceStringMark` konfigurieren. Siehe den Konfigurationsort:
  - [Voreingestellter Modus](/guides/sheets/features/core#univerjspreset-sheets-core)
  - [Plugin-Modus](/guides/sheets/features/core#univerjssheets-ui)

### Rich Text

`cellData.p` ist ein Objekt, das Rich Text darstellt und auch ein Univer-Dokument ist. Erfahren Sie mehr über [IDocumentData](https://reference.univer.ai/en-US/interfaces/IDocumentData).

<Callout>
Wenn beide Zellen `p` und `v` festgelegt sind, wird nur der Inhalt von `p` angezeigt.
</Callout>

`cellData.p.body.dataStream` ist der Inhalt von Rich Text.

### Formel

`cellData.f` ist eine Zeichenfolge, die eine Formel darstellt.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // function SUM
      }
    }
  }
}
```

### Formel-ID

`cellData.si` ist eine Zeichenfolge, die die Formel-ID darstellt. Univer Sheets unterstützt die Referenzoptimierung für Formeln. Nachdem die aktuelle Formel mit `si` in der Zelle verknüpft ist, können andere Zellen über `si` auf die aktuelle Formel verweisen. Beachten Sie, dass die Position der Zelle mit `si` in der unteren rechten Ecke der Referenzzelle liegen muss, da sonst beim Export nach XLSX ein Fehler auftritt.

Die eigentliche Formel kann über die Facade-API `range.getFormulas()` abgerufen werden. Die Regel besteht darin, die Formel `f` entsprechend `si` abzurufen und dann die tatsächliche Formel basierend auf dem Versatz von der aktuellen Zellenposition zur Referenzposition zu berechnen.

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        f: '=SUM(A1:B1)' // Sum formula
        si: 'random_formula_id_1' // ID of the current formula
      }
      1: {
        si: 'random_formula_id_1' // Take the formula corresponding to this ID during calculation
      }
    }
  }
}
```

### Benutzerdefiniertes Feld

`cellData.custom` ist ein Objekt, das ein benutzerdefiniertes Feld darstellt. Sie können alle Daten, die dem JSON-Format entsprechen, darin einfügen, um die Speicherung einiger zusätzlicher Informationen anzupassen.

Durch das Aktualisieren der `custom`-Daten werden die ursprünglichen `custom`-Daten überschrieben. Wenn Sie beim Aktualisieren von Daten die ursprünglichen `custom`-Daten beibehalten müssen, besorgen Sie sich bitte vorab die `custom`-Daten und führen Sie sie vor der Aktualisierung mit neuen Daten zusammen.

<Callout type="warning">
Das Feld `custom` ist nur für einige spezielle Szenarien geeignet und die in diesem Feld gespeicherten Daten können durch jede Benutzeroperation überschrieben oder gelöscht werden. Bitte verwenden Sie es mit Vorsicht.
</Callout>

```typescript
interface IWorksheetData {
  cellData: {
    0: {
      0: {
        custom: {
          key: 'value'
        }
      }
    }
  }
}
```
