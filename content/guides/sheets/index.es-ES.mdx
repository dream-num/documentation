## ¿Qué es Univer Sheets?

Univer Office SDK es un marco completo para las aplicaciones de la productividad de la construcción. Univer Sábanas es su componente de hoja de cálculo, construido en Web SDK.

[Web SDK](/guides/sheets) es el motor que ejecuta Univer Hojas, ya sea la hoja de cálculo incrustada en una página o procesada sin cabeza en un servidor. Añadir [Server SDK](/server) para la colaboración y conversión de archivos, y [AI SDK](/ai) cuando un agente necesita leer y escribir libros de trabajo.

Univer Hojas se ejecuta en el navegador y en un servidor Node.js. El mismo componente sirve tanto una pequeña calculadora como un modelo financiero de empresa, y su apariencia y comportamiento se pueden adaptar a la aplicación.

## Compatibilidad del navegador

Web SDK compila contra Chrome 88. Este es el objetivo de construcción; no garantiza que cada entorno principal funciona. Tenemos el objetivo de mantener Web SDK trabajando en los navegadores de abajo y en Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK depende de `Intl.Segmenter`. Si el navegador o el tiempo de ejecución no lo proporciona, agregue el polífilo correspondiente primero. Recomendamos `@formatjs/intl-segmenter` .
</Callout>

Si ocurre un problema de compatibilidad, primero pruebe el polífilo correspondiente. Si el problema persiste, [presentar una cuestión](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilidad con Node.js

<Callout type="warning">
  Esta sección cubre la ejecución Web SDK dentro de Node.js. No se aplica cuando las herramientas de construcción basadas en Node.js paquete Web SDK para el navegador.
</Callout>

Web SDK funciona en Node.js v18.17.0 y más tarde.

## Aspectos destacados

Las hojas Univer cubren las características que más aplicaciones necesitan, incluyendo:

- Creación, edición y eliminación de células, filas y columnas.
- Calculando valores en células con fórmulas.
- Configurar formatos de número.
- Validar datos y aplicar formato condicional.
- Filtrando y clasificando.
- Controlando permisos.
- Insertar imágenes.
- Características adicionales.

Las páginas [Características](/guides/sheets/features/core) describen estas características en detalle.

## Conocimientos previos requeridos

La documentación supone familiaridad con JavaScript moderno y su ecosistema. Ejecutar Web SDK en Node.js también requiere conocimiento de Node.js.

Trabajar enteramente en el navegador no necesita servicios de backend. Agregue la colaboración, historia compartida o comentarios, y la conversión de archivos mediante la composición de los módulos necesarios de [Univer Server SDK](/server) en su propio backend. Autenticación, permisos, almacenamiento y despliegue siguen siendo la responsabilidad de la aplicación.
