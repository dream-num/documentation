## ¿Qué es Univer Sheets?

Univer SDK es un marco completo para crear aplicaciones de productividad y Univer Sheets es el componente de hoja de cálculo de Univer SDK.

Univer Sheets se puede ejecutar tanto en el navegador como en el servidor (Node.js). Está diseñado para ser altamente flexible, extensible y personalizable, lo que le permite crear una amplia gama de aplicaciones, desde calculadoras simples hasta modelos financieros complejos de nivel empresarial. Ya sea que sea un desarrollador individual o parte de un equipo, Univer Sheets puede ayudarlo a crear rápida y fácilmente potentes aplicaciones basadas en hojas de cálculo.


## Compatibilidad del navegador

Univer SDK está compilado con un objetivo de Chrome 88, pero esto no significa que sea totalmente compatible con todos los entornos principales. Nos esforzamos por garantizar que Univer SDK funcione bien en los siguientes navegadores y entornos Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK depende de `Intl.Segmenter`. Si su navegador o entorno de ejecución no lo admite, primero agregue el polyfill
  correspondiente. Recomendamos usar `@formatjs/intl-segmenter`.
</Callout>

Si encuentra problemas de compatibilidad, primero intente resolverlos utilizando los polyfills adecuados. Si el problema persiste, no dude en [enviar un problema](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilidad con Node.js

<Callout type="warning">
  Nota: Esto solo se aplica a la ejecución de Univer SDK en un entorno Node.js y no se aplica a los casos en los que Univer SDK
  se ejecuta en un navegador usando herramientas de compilación basadas en Node.js.
</Callout>

Univer SDK puede ejecutarse en un entorno Node.js, con versiones compatibles v18.17.0 y posteriores.


## Aspectos destacados

Univer Sheets ahora admite una amplia gama de funciones, que incluyen:

- **Funciones básicas de hojas de cálculo**: crear, editar y eliminar celdas, filas y columnas.
- **Fórmulas**: calcula valores en celdas usando fórmulas.
- **Formato de números**
- **Validación de datos y formato condicional**
- **Filtrado y clasificación**
- **Control de permisos**
- **Imágenes**
- y más...

Para obtener más detalles, consulte las páginas de la sección [Características](/guides/sheets/features/core). Las funciones principales y principales son de código abierto en [GitHub](https://github.com/dream-num/univer) y son de uso gratuito.

## Cómo leer la documentación

En el lado izquierdo de la pantalla, encontrará la barra de navegación de documentos. Las páginas de los documentos están organizadas secuencialmente, desde lo básico hasta lo avanzado, para que pueda seguirlas paso a paso al crear su aplicación. Sin embargo, puede leerlos en cualquier orden o pasar a las páginas que se apliquen a su caso de uso. También puedes consultar Univer Sheets en la parte superior de la barra lateral.

En el lado derecho de la pantalla, verá una tabla de contenido que facilita la navegación entre las secciones de una página. Si necesita encontrar rápidamente una página, puede usar la barra de búsqueda en la parte superior o el acceso directo de búsqueda (Ctrl+K o Cmd+K).

Para comenzar, consulte la guía [Inicio rápido](/guides/sheets/getting-started/quickstart).

## Conocimientos previos requeridos

Aunque nuestros documentos están diseñados para ser amigables para principiantes, necesitamos establecer una base para que los documentos puedan manténgase enfocado en Univer SDK.

Para aprovechar al máximo nuestros documentos, se recomienda que tenga un conocimiento básico de JavaScript y su ecosistema.

Si está interesado en ejecutar Univer SDK en Node.js, también debe tener un conocimiento básico de Node.js.

Si desea probar Univer SDK Pro e implementar Univer Server, le recomendamos que tenga un conocimiento básico de Linux, Docker y Docker Compose (o Kubernetes).

## Extender Univer Sheets

Univer SDK está diseñado para ser altamente extensible para que pueda configurarlo según sus necesidades. Recomendamos leer la sección [Arquitectura](/blog/univer) para comprender la estructura de Univer Sheets y cómo ampliarla. También puede comenzar con [Cómo escribir un complemento de importación CSV](/blog/csv-import-plugin).
