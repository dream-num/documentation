## Qu’est-ce qu’Univer Sheets ?

Univer Office SDK est un cadre complet pour les applications de productivité de construction. Univer Sheets est son composant de tableur, construit sur Web SDK.

[Web SDK](/guides/sheets) est le moteur qui exécute les feuilles Univer, que le tableur soit intégré dans une page ou traité sans tête sur un serveur. Ajoutez [Server SDK](/server) pour la collaboration et la conversion de fichiers, et [AI SDK](/ai) quand un agent a besoin de lire et d'écrire des cahiers de travail.

Univer Sheets fonctionne dans le navigateur et sur un serveur Node.js. Le même composant sert à la fois une petite calculatrice et un modèle financier d'entreprise, et son apparence et son comportement peuvent être adaptés à l'application.

## Compatibilité avec les navigateurs

Web SDK compile contre Chrome 88. C'est la cible de construction; il ne garantit pas que chaque environnement courant fonctionne. Nous visons à garder Web SDK fonctionnant dans les navigateurs ci-dessous et sur Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK dépend de `Intl.Segmenter`. Si le navigateur ou l'exécution ne le fournit pas, ajoutez d'abord le polyfill correspondant. Nous recommandons `@formatjs/intl-segmenter` .
</Callout>

Si un problème de compatibilité survient, essayez d'abord le polyfill correspondant. Si le problème persiste, [soumettre un problème](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilité avec Node.js

<Callout type="warning">
  Cette section couvre l'exécution de Web SDK dans Node.js. Elle ne s'applique pas lorsque Node.js-based build tools building bundle Web SDK pour le navigateur.
</Callout>

Web SDK fonctionne sur Node.js v18.17.0 et plus tard.

## Fonctionnalités principales

Les feuilles Univer couvrent les fonctionnalités dont la plupart des applications ont besoin, notamment:

- Création, édition et suppression de cellules, lignes et colonnes.
- Calcul des valeurs dans les cellules avec des formules.
- Réglage des formats de nombre.
- Validation des données et application du formatage conditionnel.
- Filtrage et tri.
- Contrôler les autorisations.
- Insérer des images.
- Caractéristiques supplémentaires.

Les pages [Caractéristiques](/guides/sheets/features/core) décrivent ces caractéristiques en détail.

## Comment lire la documentation

Le navbar de gauche liste la documentation dans l'ordre de lecture, de basique à avancé. Suite à cet ordre n'est pas requis: vous pouvez sauter en avant ou aller directement aux pages qui s'appliquent à votre cas d'utilisation. Le commutateur de feuilles Univer est situé en haut de la barre latérale.

La table des matières de droite suit la position actuelle dans la page. Pour trouver une page rapidement, utilisez la barre de recherche en haut ou le raccourci de recherche (Ctrl+K ou Cmd+K).

Commencez par [Démarrage rapide](/guides/sheets/getting-started/installation).

## Prérequis

La documentation prend connaissance de JavaScript moderne et de son écosystème. L'exécution Web SDK sur Node.js nécessite également une connaissance de Node.js.

Travailler entièrement dans le navigateur n'a pas besoin de services de backend. Ajoutez collaboration, historique partagé ou commentaires, et conversion de fichiers en composant les modules requis de [Univer Server SDK](/server) dans votre propre backend. L'authentification, les permissions, le stockage et le déploiement restent la responsabilité de l'application.

## Étendre Univer Sheets

Web SDK est conçu pour l'extension, pas seulement pour la configuration. [Architecture](/blog/univer) explique la structure des feuilles Univer et ses points d'extension. Pour un exemple complet, voir [Comment écrire un plugin d'importation CSV](/blog/csv-import-plugin).
