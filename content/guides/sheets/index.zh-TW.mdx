## Univer Sheets 是什麼

Univer Office SDK 是一個用於建置生產力應用的全棧框架，Univer Sheets 是它的電子表格元件，基於 Web SDK。

[Web SDK](/guides/sheets) 是執行 Univer Sheets 的引擎，無論電子表格嵌入頁面，還是在伺服器端無介面處理，都由它執行。需要協同與檔案轉換時，接入 [Server SDK](/server)；需要 Agent 讀寫工作簿時，使用 [AI SDK](/ai)。

Univer Sheets 可以在瀏覽器和 Node.js 伺服器端執行。同一個元件既可用於簡單的計算器，也可用於企業級財務模型，其介面和行為可以按應用需要調整。

## 瀏覽器相容性

Web SDK 的編譯目標是 Chrome 88。這只是建置目標，並不意味著所有主流環境都受支援。我們力求讓 Web SDK 在下列瀏覽器和 Node.js 環境中正常工作：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK 依賴 `Intl.Segmenter`。如果瀏覽器或執行時未提供它，請先補充對應的 polyfill，推薦使用 `@formatjs/intl-segmenter`。
</Callout>

如果遇到相容性問題，請先嚐試用對應的 polyfill 解決。如果問題仍然存在，請[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 相容性

<Callout type="warning">
  本節介紹在 Node.js 中執行 Web SDK，不適用於使用基於 Node.js 的建置工具將 Web SDK 打包到瀏覽器中執行的情況。
</Callout>

Web SDK 可在 Node.js v18.17.0 及更高版本中執行。

## 主要功能

Univer Sheets 覆蓋大多數應用需要的功能，包括：

- 建立、編輯和刪除單元格、行、列。
- 使用公式計算單元格中的值。
- 設定數字格式。
- 資料驗證和條件格式。
- 篩選和排序。
- 權限控制。
- 插入圖片。
- 其他功能。

具體說明見[功能](/guides/sheets/features/core)下的各篇文件。

## 如何使用本文件

左側導航欄按從基礎到高階的順序排列文件。不必按此順序閱讀：可以跳過部分章節，也可以直接查閱當前用例所需的頁面。Univer Sheets 的切換器位於側邊欄頂部。

右側的目錄標出當前所在的章節。如需快速查詢頁面，可以使用頂部的搜尋欄或搜尋快捷鍵（Ctrl+K 或 Cmd+K）。

請從[快速開始](/guides/sheets/getting-started/installation)開始。

## 先備知識

本文件假設讀者能閱讀現代 JavaScript，並熟悉其生態系統。如需在 Node.js 上執行 Web SDK，還需要了解 Node.js。

完全在瀏覽器中編輯不需要任何後端服務。如需協同、共享歷史或評論以及檔案轉換，請在自身的後端中組合 [Univer Server SDK](/server) 的相應模組；身分認證、權限、儲存和部署仍由應用負責。

## 擴充 Univer Sheets

Web SDK 的設計目標是可擴充套件，而不只是提供配置項。[架構](/blog/univer)介紹了 Univer Sheets 的組成結構以及擴充套件點的位置。需要完整範例時，請閱讀[如何編寫 CSV 匯入外掛](/blog/csv-import-plugin)。
