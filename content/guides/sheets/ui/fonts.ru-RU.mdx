## Структура описания шрифта

В Univer шрифты определяются с помощью интерфейса `IFontConfig`:

| Свойство | Тип | Описание |
| --- | --- | --- |
| `value` | `string` | Уникальный идентификатор шрифта, обычно также предпочтительное значение CSS-свойства font-family. |
| `label` | `string` | Ключ перевода для интернационализации. Если при создании экземпляра Univer этот ключ не задан, значение отображается без изменений. |
| `category` | `FontCategory` | Категория шрифта, используемая для группировки в интерфейсе (необязательно). |

<Callout>
  Univer не запрещает пользователям выбирать неустановленные шрифты. Если шрифт не установлен на устройстве, браузер заменит его шрифтом по умолчанию.
</Callout>


## Использование пользовательских шрифтов

Пункты раскрывающегося списка шрифтов можно задать с помощью параметра `customFontFamily` для `UniverSheetsCorePreset` (режим предустановок) или `UniverUIPlugin` (режим плагинов).

### Настройка плагинов

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для редактора или его идентификатор. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Добавляет шрифты в раскрывающийся список. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Добавляет шрифты в раскрывающийся список. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Имя шрифта в CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Отображаемое имя или ключ перевода. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Группа шрифтов: `sans-serif`, `serif`, `monospace`, `display` или `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Заменяет встроенный список указанными шрифтами. |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // Whether to override the default font list, defaults to false
    override: true,
  },
})
```

### Настройка пресетов

`UniverSheetsCorePreset`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | DOM-элемент для редактора или его идентификатор. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Добавляет шрифты в раскрывающийся список. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Добавляет шрифты в раскрывающийся список. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Имя шрифта в CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Отображаемое имя или ключ перевода. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Группа шрифтов: `sans-serif`, `serif`, `monospace`, `display` или `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Заменяет встроенный список указанными шрифтами. |

```typescript
import { FontCategory } from '@univerjs/ui'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      container: 'app',
      customFontFamily: {
        list: [
          {
            value: 'PingFang SC',
            label: '苹方（简）',
            category: FontCategory.SANS_SERIF,
          },
          {
            value: 'Helvetica Neue',
            label: 'Helvetica Neue',
            category: FontCategory.SANS_SERIF,
          },
        ],
        // Whether to override the default font list, defaults to false
        override: true,
      },
    }),
  ],
})
```

## Facade API

Помимо настройки при инициализации, новые шрифты можно динамически регистрировать во время выполнения через Facade API. Это особенно удобно, когда файлы шрифтов необходимо загружать асинхронно.

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
