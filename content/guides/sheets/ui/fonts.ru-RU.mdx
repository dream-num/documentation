## Структура описания шрифта

Шрифт описывается интерфейсом `IFontConfig`:

| Свойство | Тип | Описание |
| --- | --- | --- |
| `value` | `string` | Уникальный идентификатор шрифта, обычно значение, используемое для семейства шрифтов CSS. |
| `label` | `string` | Если при создании экземпляра Univer ключ перевода используется для интернационализации, то поставляемое значение отображается непосредственно. |
| `category` | `FontCategory` | Категория шрифта, используемая для группирования записей в пользовательском интерфейсе. |

<Callout>
  Univer не мешает пользователям выбирать шрифт, который не установлен.Если у клиента нет этого шрифта, браузер возвращается к шрифту по умолчанию.
</Callout>

## Использование пользовательских шрифтов

Настройте `customFontFamily` в `UniverSheetsCorePreset` (режим предварительной загрузки) или `UniverUIPlugin`(режим плагина) для настройки выбора в раскрывающемся списке шрифтов.

### Настройка плагинов

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для размещения редактора или его идентификатор. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Добавляет шрифты в раскрывающийся список. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Добавляет шрифты в раскрывающийся список. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Имя шрифта в CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Отображаемое имя или ключ перевода. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Группа шрифтов: `sans-serif`, `serif`, `monospace`, `display` или `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Заменяет встроенный список указанными шрифтами. |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // Whether to override the default font list, defaults to false
    override: true,
  },
})
```

### Настройка пресетов

`UniverSheetsCorePreset`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | DOM-элемент для размещения редактора или его идентификатор. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Добавляет шрифты в раскрывающийся список. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Добавляет шрифты в раскрывающийся список. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Имя шрифта в CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Отображаемое имя или ключ перевода. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Группа шрифтов: `sans-serif`, `serif`, `monospace`, `display` или `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Заменяет встроенный список указанными шрифтами. |

```typescript
import { FontCategory } from '@univerjs/ui'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      container: 'app',
      customFontFamily: {
        list: [
          {
            value: 'PingFang SC',
            label: '苹方（简）',
            category: FontCategory.SANS_SERIF,
          },
          {
            value: 'Helvetica Neue',
            label: 'Helvetica Neue',
            category: FontCategory.SANS_SERIF,
          },
        ],
        // Whether to override the default font list, defaults to false
        override: true,
      },
    }),
  ],
})
```

## Facade API

Шрифты не нужно настраивать при запуске. Их также можно добавлять во время выполнения через Facade API, что полезно при асинхронной загрузке файлов шрифтов.

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
