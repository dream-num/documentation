## Design System

Univer's design system is built on Tailwind CSS. It defines a set of design tokens that the rendering engine reuses, so the rendering engine and the view layer stay visually consistent. The tokens are provided by the `@univerjs/themes` package, and changing them restyles the application.

## Components

Univer builds its view layer with React components. For applications that already use React, using Univer's components or registering custom ones is straightforward. React is not the only option: Univer also supports Vue (3.x) and Web Components.

Basic components are provided by the `@univerjs/design` package and icon components by `@univerjs/icons`. Both can be used independently of Univer.

Custom components are typically used in three situations:

- Adding custom buttons to the Ribbon or Context Menu
- Integrating custom components in the Sidebar, Popup, and similar surfaces
- Replacing built-in components
