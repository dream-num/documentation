## 디자인 시스템

Univer의 디자인 시스템은 테일윈드 CSS에 내장되어 있습니다. 렌더링 엔진이 재사용되는 디자인 토큰의 세트를 정의하므로 렌더링 엔진과 볼 레이어가 시각적으로 일관성 있게 유지됩니다. 토큰은 `@univerjs/themes` 패키지에 의해 제공되며 응용 프로그램을 재구성합니다.

## 컴포넌트

Univer는 React 성분을 가진 그것의 전망 층을 건설합니다. 이미 React를 사용하는 신청은, Univer의 성분을 사용하여 또는 주문 하나가 straightforward입니다. React에는 유일한 선택권이 아닙니다: Univer 또한 지원 Vue (3.x)와 웹 성분.

기본 구성 요소는 `@univerjs/icons`에 의해 `@univerjs/design` 패키지 및 아이콘 구성 요소에 의해 제공됩니다. 둘 다 Univer의 독립적으로 사용할 수 있습니다.

주문 성분은 전형적으로 3개의 상황에서 이용됩니다:

- 리본 또는 Context 메뉴에 사용자 정의 버튼을 추가
- Sidebar, Popup 및 이와 유사한 표면에서 사용자 정의 구성
- 기본 제공 컴포넌트 교체

다음 페이지는 등록 및 사용자 정의 구성 요소를 사용하는 방법을 설명합니다.
