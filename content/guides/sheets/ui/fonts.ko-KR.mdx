## 글꼴 구조 정의

글꼴은 `IFontConfig` 인터페이스에 의해 설명됩니다:

| 속성 | 타입 | 설명 |
| --- | --- | --- |
| `value` | `string` | 글꼴의 독특한 식별자, 일반적으로 CSS 글꼴 가족에 사용할 수있는 값. |
| `label` | `string` | 국제화에 사용되는 번역 키. Univer 인스턴스가 생성되면 키가 지정되지 않은 경우, 공급된 값이 직접 표시됩니다. |
| `category` | `FontCategory` | 글꼴 범주, UI에서 그룹 항목에 사용. 선택. |

<Callout>
  Univer는 설치되지 않은 글꼴을 선택하여 사용자를 방지하지 않습니다. 클라이언트가 글꼴이 없다면 브라우저는 기본 글꼴로 돌아갑니다.
</Callout>

## 사용자 지정 글꼴 사용하기

`UniverSheetsCorePreset` (Preset Mode) 또는 `UniverUIPlugin`(Plugin Mode)에 `customFontFamily`를 구성하여 글꼴 드롭다운에서 선택을 설정합니다.

### 플러그인 설정

`UniverUIPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 편집기를 마운트할 DOM 요소 또는 해당 요소의 ID입니다. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | 드롭다운에 글꼴을 추가합니다. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | 드롭다운에 글꼴을 추가합니다. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS에서 사용하는 글꼴 이름입니다. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 표시 이름 또는 번역 키입니다. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 글꼴 분류입니다. `sans-serif`, `serif`, `monospace`, `display`, `handwriting`을 사용할 수 있습니다. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 기본 글꼴 목록을 지정한 목록으로 바꿉니다. |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // Whether to override the default font list, defaults to false
    override: true,
  },
})
```

### 프리셋 설정

`UniverSheetsCorePreset`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 편집기를 마운트할 DOM 요소 또는 해당 요소의 ID입니다. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | 드롭다운에 글꼴을 추가합니다. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | 드롭다운에 글꼴을 추가합니다. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS에서 사용하는 글꼴 이름입니다. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 표시 이름 또는 번역 키입니다. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 글꼴 분류입니다. `sans-serif`, `serif`, `monospace`, `display`, `handwriting`을 사용할 수 있습니다. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 기본 글꼴 목록을 지정한 목록으로 바꿉니다. |

```typescript
import { FontCategory } from '@univerjs/ui'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      container: 'app',
      customFontFamily: {
        list: [
          {
            value: 'PingFang SC',
            label: '苹方（简）',
            category: FontCategory.SANS_SERIF,
          },
          {
            value: 'Helvetica Neue',
            label: 'Helvetica Neue',
            category: FontCategory.SANS_SERIF,
          },
        ],
        // Whether to override the default font list, defaults to false
        override: true,
      },
    }),
  ],
})
```

## Facade API

글꼴은 시작에 구성되지 않습니다. 그들은 또한 동시에 글꼴 파일로드 할 때 유용 할 Facade API를 통해 실행 시간에 추가 할 수 있습니다.

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
