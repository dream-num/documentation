## 字型結構定義

在 Univer 中，字型使用 `IFontConfig` 介面進行定義：

| 屬性 | 類型 | 說明 |
| --- | --- | --- |
| `value` | `string` | 字型的唯一識別碼，通常也是 CSS font-family 的首選值。 |
| `label` | `string` | 用於國際化的翻譯鍵，如果在 Univer 實例建立時沒有指定該鍵值時，則直接顯示傳入值。|
| `category` | `FontCategory` | 字型類別，用於 UI 分組（可選）。 |

<Callout>
  Univer 不會阻止使用者選擇未安裝的字型，如果客戶端沒有安裝某個字型，瀏覽器會直接使用預設字型進行替代顯示。
</Callout>


## 使用自訂字型

你可以透過為 `UniverSheetsCorePreset`（預設模式）或 `UniverUIPlugin`（外掛模式）配置 `customFontFamily` 參數來定義字型下拉選單中的選項。

### 外掛設定

`UniverUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 編輯器掛載的 DOM 元素或元素 ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | 在字型下拉清單中新增這些選項。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | 在字型下拉清單中新增這些選項。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS 使用的字型名稱。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 顯示名稱或翻譯鍵。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 字型群組，可選 `sans-serif`、`serif`、`monospace`、`display` 或 `handwriting`。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 以傳入的清單取代內建字型選項。 |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // 是否覆蓋預設字型列表，預設為 false
    override: true,
  },
})
```

### 預設設定

`UniverSheetsCorePreset`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 編輯器掛載的 DOM 元素或元素 ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | 在字型下拉清單中新增這些選項。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | 在字型下拉清單中新增這些選項。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS 使用的字型名稱。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 顯示名稱或翻譯鍵。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 字型群組，可選 `sans-serif`、`serif`、`monospace`、`display` 或 `handwriting`。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 以傳入的清單取代內建字型選項。 |

```typescript
import { FontCategory } from '@univerjs/ui'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      container: 'app',
      customFontFamily: {
        list: [
          {
            value: 'PingFang SC',
            label: '苹方（简）',
            category: FontCategory.SANS_SERIF,
          },
          {
            value: 'Helvetica Neue',
            label: 'Helvetica Neue',
            category: FontCategory.SANS_SERIF,
          },
        ],
        // 是否覆蓋預設字型列表，預設為 false
        override: true,
      },
    }),
  ],
})
```

## Facade API

除了在初始化時配置，你還可以透過 Facade API 在執行時動態註冊新的字型。這在需要非同步載入字型資源的場景下非常有用。

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
