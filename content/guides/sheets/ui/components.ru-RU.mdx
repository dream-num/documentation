Univer не принимает компонент в качестве аргумента для вызова рендеринга. Компонент должен быть зарегистрирован через Facade API, прежде чем на него можно будет ссылаться везде, где Univer монтирует его.

Если экземпляр Facade API еще не доступен, см. [Facade API](/guides/sheets/getting-started/facade).

## Регистрация пользовательских компонентов

```typescript
// [!code word:componentKey]
// [!code word:CustomComponent]
// [!code word:options]
univerAPI.registerComponent(componentKey, CustomComponent, options)
```

`univerAPI.registerComponent` регистрирует компонент и принимает три аргумента:

- `componentKey`: уникальный идентификатор компонента, используемый для ссылки на него внутри Univer.
- `CustomComponent`: сам компонент, который может быть компонентом React, компонентом Vue или веб-компонентом.
- `options`: дополнительные настройки, такие как фреймворк, от которого зависит компонент или другая связанная конфигурация.

### Компоненты React [#react]

Компоненты React не требуют дополнительной конфигурации. Компонент должен быть только действительным компонентом React, как в следующем примере:

```tsx
function ReactComponent(props: Record<string, any>) {
  return <div>Hello Univer!</div>
}

univerAPI.registerComponent('MyReactComponent', ReactComponent)
```

### Компоненты Vue [#vue]

#### Vue 3.x

Для компонентов Vue установите пакет `@univerjs/ui-adapter-vue3` и зарегистрируйте из него `UniverVue3AdapterPlugin`:

```package-install
npm install @univerjs/ui-adapter-vue3
```

```typescript
import { UniverVue3AdapterPlugin } from '@univerjs/ui-adapter-vue3'

univer.registerPlugin(UniverVue3AdapterPlugin)
```

Перейдите `framework` как `'vue3'`, когда вы регистрируете компонент:

```tsx
const Vue3Component = defineComponent({
  setup(props) {
    return () => <div>Hello Univer!</div>
  },
})

univerAPI.registerComponent('MyVue3Component', Vue3Component, {
  // [!code word:vue3]
  framework: 'vue3',
})
```

#### Vue 2.x

Vue 2.x достиг конца срока службы и больше не поддерживается, поэтому Univer в настоящее время не предоставляет для него плагин адаптера пользовательского интерфейса. Адаптер может быть реализован в качестве пользовательского плагина. Приведенный ниже код является плагином адаптера Vue2.x, который может служить отправной точкой:

```typescript title="ui-adapter-vue2.ts"
import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
import { ComponentManager, UniverUIPlugin } from '@univerjs/ui'
import Vue from 'vue'

/**
 * The plugin that allows Univer to use Vue 2 components as UI components.
 */
@DependentOn(UniverUIPlugin)
export class UniverVue2AdapterPlugin extends Plugin {
  static override pluginName = 'UNIVER_UI_VUE2_ADAPTER_PLUGIN'

  constructor(
    private readonly _config = {},
    @Inject(Injector) protected readonly _injector: Injector,
    @Inject(ComponentManager) protected readonly _componentManager: ComponentManager,
  ) {
    super()
  }

  override onStarting(): void {
    const { createElement, useEffect, useRef } = this._componentManager.reactUtils

    this._componentManager.setHandler('vue2', (component: any) => {
      return (props: Record<string, any>) =>
        createElement(VueComponentWrapper, {
          component,
          props: Object.keys(props).reduce<Record<string, any>>((acc, key) => {
            if (key !== 'key') {
              acc[key] = props[key]
            }
            return acc
          }, {}),
          reactUtils: { createElement, useEffect, useRef },
        })
    })
  }
}

export function VueComponentWrapper(options: {
  component: any
  props: Record<string, any>
  reactUtils: typeof ComponentManager.prototype.reactUtils
}) {
  const { component, props, reactUtils } = options
  const { createElement, useEffect, useRef } = reactUtils

  const domRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!domRef.current) return

    const Constructor = Vue.extend(component)

    const instance = new Constructor({
      data: props,
    })
    instance.$mount()

    domRef.current.appendChild(instance.$el)

    return () => {
      instance.$destroy()
    }
  }, [props])

  return createElement('div', { ref: domRef })
}
```

Затем зарегистрируйте плагин:

```typescript
import { UniverVue2AdapterPlugin } from './ui-adapter-vue2' // [!code ++]

univer.registerPlugin(UniverUIPlugin)
univer.registerPlugin(UniverVue2AdapterPlugin) // [!code ++]
```

Компоненты Vue 2.x нуждаются в наборе `framework` для `'vue2'`:

```tsx
const Vue2Component = Vue.component('MyVue2Component', {
  template: '<div>Hello, Univer!</div>',
})

univerAPI.registerComponent('MyVue2Component', Vue2Component, {
  // [!code word:vue2]
  framework: 'vue2',
})
```

### Web Components [#web-component]

Для регистрации Web-компонентов компонент должен следовать стандарту Web-компанентов.Установить пакет `@univerjs/ui-adapter-web-component` и зарегистрировать из него `UniverWebComponentAdapterPlugin`:

```package-install
npm install @univerjs/ui-adapter-web-component
```

```typescript
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

univer.registerPlugin(UniverWebComponentAdapterPlugin)
```

Пройдите `framework` как `'web-component'`:

```tsx
class WebComponent extends HTMLElement {
  constructor() {
    super()
    const shadow = this.attachShadow({ mode: 'open' })
    const div = document.createElement('div')
    div.textContent = 'Hello Univer!'
    shadow.appendChild(div)
  }
}

univerAPI.registerComponent('my-web-component', WebComponent, {
  // [!code word:web-component]
  framework: 'web-component',
})
```

### Angular [#angular]

`createCustomElement` от `@angular/elements` преобразует компонент Angular в пользовательский элемент.После того, как элемент зарегистрирован в адаптере веб-компонента Univer, компонент Angular может появиться в боковой панели или диалоге Univer.

Добавьте `@angular/elements` в ту же версию, что и `@angular/core`, и `@univerjs/ui-adapter-web-component` — в ту же самую версию, что в других пакетах Univer.

Вызовите эту функцию после инициализации Univer. Инжектор Angular поставляется хост-компонентом: получите его с `private readonly injector = inject(Injector)`, а затем позвоните `registerAngularPanel(univer, univerAPI, this.injector)`... Компонент хоста импортирует `inject` и `Injector` из `@angular/core`

```typescript title="angular-panel.ts"
import type { Injector } from '@angular/core'
import type { FUniver, Univer } from '@univerjs/presets'
import { Component } from '@angular/core'
import { createCustomElement } from '@angular/elements'
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

@Component({
  selector: 'app-angular-panel',
  standalone: true,
  template: '<p>Hello from Angular!</p>',
})
export class AngularPanelComponent {}

export function registerAngularPanel(univer: Univer, univerAPI: FUniver, injector: Injector) {
  const element = createCustomElement(AngularPanelComponent, { injector })

  univer.registerPlugin(UniverWebComponentAdapterPlugin)
  return univerAPI.registerComponent('univer-angular-panel', element, {
    framework: 'web-component',
  })
}
```

После того, как редактор отредактировал, передайте зарегистрированный ключ в качестве содержимого боковой панели:

```typescript
const sidebar = univerAPI.openSidebar({
  header: { title: 'Angular' },
  children: { label: 'univer-angular-panel' },
  width: 360,
})
```

Сохраняйте ручку регистрации и ручку боковой панели и звоните `dispose()` на каждом, когда он больше не нужен. Зарегистрируйте элемент один раз в приложении. Его название должно содержать дефис и должно отличаться от селектора компонентов Angular.

Angular Элементы отображают входы в свойства элементов и выходы в события DOM `CustomEvent`. Адаптер Univer устанавливает свойства, но не подписывается на выходы Angular самостоятельно, поэтому приложение должно соединить эти события, когда они необходимы.

## Использование пользовательских компонентов

Приведенные ниже методы размещают пользовательские компоненты в местах, которые отображает Univer, что расширяет и настраивает пользовательский интерфейс.

<Callout type="warning" title="Внимание">

1. Назовите эти методы только после того, как Univer закончил рендеринг.
2. Зарегистрируйте компонент перед его использованием.
3. Позвоните `dispose()`, чтобы очистить то, что вы добавили, и избежать утечек памяти.

</Callout>

### Добавление пользовательских пунктов меню

Лента вверху и контекстное меню на правой кнопке могут содержать пользовательские компоненты. Элементы меню регистрируются плагином, поэтому для добавления требуется пользовательский плагин. [Руководство по передовой практике для пользовательских пунктов меню](/blog/custom-plugin) доступен в качестве отправной точки.

### Замена встроенных компонентов

<Callout type="error" title="Предупреждение">
  Замена встроенного компонента может нарушить функции, которые зависят от него.Прочитайте исходный код и документацию, прежде чем пытаться заменить, и действуйте с осторожностью.
</Callout>

`univerAPI.registerComponent` регистрирует оверрайд по умолчанию (`override: true`). Оверрайд принимает приоритет над встроенным компонентом независимо от того, регистрирует ли плагин свой дефолт до или после вызова. Для каждого `componentKey` может быть активен только один оверрайдер, поэтому удалите предыдущую регистрацию перед регистрацией другого. Звонок `dispose()` на возвращенной регистрации восстанавливает встроенный по умолчанию, если он был зарегистрирован. Используйте `{ override: false }` для регистрации по умолчанию.

Зарегистрируйте оверрайд до того, как он откроется в первый раз. Изменение регистрации не переоформляет уже установленные виды.

Листы экспортируют следующие ключи из своих записей в публичной упаковке; используйте их, чтобы переопределить соответствующие встроенные компоненты:

| Компонент | Экспортируемый ключ | Пакет |
| --- | --- | --- |
| Определённые имена | `DEFINED_NAME_CONTAINER` | `@univerjs/sheets-ui` |
| Другие функции | `MORE_FUNCTIONS_COMPONENT` | `@univerjs/sheets-formula-ui` |
| Проверка данных | `DATA_VALIDATION_PANEL` | `@univerjs/sheets-data-validation-ui` |
| Условное форматирование | `CF_PANEL_KEY` | `@univerjs/sheets-conditional-formatting-ui` |

Например, следующий код заменяет встроенный компонент ColorPicker:

```tsx
// Following code only replaces the UI of the built-in ColorPicker component, not its functionality
univerAPI.registerComponent('UI_COLOR_PICKER_COMPONENT', () => <input type="color" />)
```

### Использование в качестве компонентов содержимого

#### На боковой панели

`univerAPI.openSidebar` открывает боковую панель внутри пользовательского интерфейса Univer и отображает в нем зарегистрированный компонент.

```tsx
// [!code word:MyCustomSidebarComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomSidebarComponent', () => <div>Hello Univer!</div>)

const sidebar = univerAPI.openSidebar({
  header: { title: 'My Sidebar' },
  children: { label: 'MyCustomSidebarComponent' },
  onClose: () => {
    console.log('close')
  },
  width: 360,
})

// Later close the sidebar
sidebar.dispose()
```

Справочник: [`univerAPI.openSidebar`](/reference/facade/univer#opensidebar)

#### В диалоговом окне

`univerAPI.openDialog` открывает диалог и отображает ваш зарегистрированный компонент внутри него.

```tsx
// [!code word:MyCustomDialogComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomDialogComponent', () => <div>Hello Univer!</div>)

const dialog = univerAPI.openDialog({
  id: 'unique-dialog-id', // The unique identifier for the dialog
  draggable: true,
  width: 300,
  title: { title: 'My Dialog' },
  children: {
    label: 'MyCustomDialogComponent',
  },
  destroyOnClose: true,
  preservePositionOnDestroy: true,
  onClose: () => {},
})

// Later close the dialog
dialog.dispose()
```

Справочник: [`univerAPI.openDialog`](/reference/facade/univer#opendialog)

#### Добавление всплывающего окна к ячейкам

`FRange.attachPopup` прикрепляет пользовательское всплывающее окно к определенному диапазону ячеек.

- Всплывающее окно - это временный DOM-элемент, прикрепленный к ячейке. Обычно он отображает информацию о переходном состоянии и не поддерживает постоянное хранение.
- Подпись метода [`FRange.attachPopup(popup: IFCanvasPopup)`](https://docs.univer.ai/reference/facade/range#attachpopup).
- Всплывающее окно прикрепляется к краям ячейки и регулирует ее положение и ориентацию, когда что-то мешает ей.

```tsx
// [!code word:MyCustomPopupComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent(
  'MyCustomPopupComponent',
  () => <div>Hello Univer!</div>,
)

const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:J10')

// Attach the popup to the first cell of the range
// If `disposable` is null, it indicates that the popup was not added successfully
const disposable = fRange.attachPopup({
  componentKey: 'MyCustomPopupComponent',
})

// Remove the popup
disposable.dispose()
```

#### Добавление предупреждения

`FRange.attachAlertPopup` прикрепляет всплывающее окно оповещения к стартовой ячейке определенного диапазона.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

const disposable = fRange.attachAlertPopup({
  key: 'unique-alert-key', // Unique identifier
  title: '这是一个警告！',
  message: '这是一个警告！',
  width: 300,
  height: 200,
  // 0: Information
  // 1: Warning
  // 2: Error
  type: 0,
})

// Remove the alert later
disposable.dispose()
```

#### Добавление плавающего DOM-элемента на лист

`FWorksheet.addFloatDomToPosition` добавляет в рабочий лист плавающий элемент DOM.

- Перед использованием этого метода установите плагин `@univerjs/sheets-drawing-ui` или предустановку `@univerjs/preset-sheets-drawing`.
- Плавающий DOM-элемент является перетаскивающимся компонентом, который парит над рабочим листом и поддерживает постоянное хранение.
- Назовите этот метод после того, как Univer закончил рендеринг.
- `componentKey`: уникальный идентификатор компонента, используемый для ссылки на него внутри Univer.
- [Полное описание параметров](https://github.com/dream-num/univer/blob/dev/packages/sheets-drawing-ui/src/facade/f-worksheet.ts#L32)

```tsx
// [!code word:MyCustomFloatDOMComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent(
  'MyCustomFloatDOMComponent',
  ({ data }) => (
    <div>
      Hello
      {data?.label}
      !
    </div>
  ),
)
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Add a floating DOM to the worksheet
// If `disposable` is null, it indicates that the floating DOM was not added successfully
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'MyCustomFloatDOMComponent',
  initPosition: {
    startX: 100,
    endX: 200,
    startY: 100,
    endY: 200,
  },

  // The data for the component
  data: {
    label: 'Univer',
  },
})

// Remove the floating DOM
disposable.dispose()
```
