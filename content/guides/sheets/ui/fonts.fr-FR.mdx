## Structure d’une police

Une police est décrite par l'interface `IFontConfig` :

| Propriété | Type | Description |
| --- | --- | --- |
| `value` | `string` | L'identificateur unique de la police, généralement la valeur à utiliser pour la famille de polices CSS. |
| `label` | `string` | La clé de traduction utilisée pour l'internationalisation. Si la clé n'est pas spécifiée lorsque l'instance Univer est créée, la valeur fournie s'affiche directement. |
| `category` | `FontCategory` | Catégorie de police, utilisée pour regrouper les entrées dans l'interface utilisateur. Facultatif. |

<Callout>
  Univer n'empêche pas les utilisateurs de sélectionner une police qui n'est pas installée. Si le client n'a pas cette police, le navigateur revient à la police par défaut.
</Callout>

## Utiliser des polices personnalisées

Configurez `customFontFamily` sur `UniverSheetsCorePreset` (Mode Preset) ou `UniverUIPlugin`(Mode Plugin) pour définir les choix dans le menu déroulant de la police.

### Configuration des plugins

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Élément DOM de montage de l’éditeur ou son identifiant. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Ajoute ces polices à la liste déroulante. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Ajoute ces polices à la liste déroulante. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Nom de la police utilisé en CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Nom affiché ou clé de traduction. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Catégorie parmi `sans-serif`, `serif`, `monospace`, `display` ou `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Remplace les polices intégrées par la liste fournie. |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // Whether to override the default font list, defaults to false
    override: true,
  },
})
```

### Configuration des préréglages

`UniverSheetsCorePreset`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | Élément DOM de montage de l’éditeur ou son identifiant. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Ajoute ces polices à la liste déroulante. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Ajoute ces polices à la liste déroulante. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Nom de la police utilisé en CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Nom affiché ou clé de traduction. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Catégorie parmi `sans-serif`, `serif`, `monospace`, `display` ou `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Remplace les polices intégrées par la liste fournie. |

```typescript
import { FontCategory } from '@univerjs/ui'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      container: 'app',
      customFontFamily: {
        list: [
          {
            value: 'PingFang SC',
            label: '苹方（简）',
            category: FontCategory.SANS_SERIF,
          },
          {
            value: 'Helvetica Neue',
            label: 'Helvetica Neue',
            category: FontCategory.SANS_SERIF,
          },
        ],
        // Whether to override the default font list, defaults to false
        override: true,
      },
    }),
  ],
})
```

## Facade API

Les polices n'ont pas à être configurées au démarrage. Elles peuvent également être ajoutées à l'exécution par l'intermédiaire de Facade API, ce qui est utile lorsque les fichiers font sont chargés asynchronement.

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
