## 設計系統

Univer 的設計系統基於 Tailwind CSS，定義了一組由渲染引擎複用的設計 Tokens，使渲染引擎與檢視層在視覺上保持一致。這些 Tokens 位於 `@univerjs/themes` 包中，修改這些 Tokens 即可調整應用樣式。

## 元件

Univer 的檢視層由 React 元件建置。對於已經使用 React 的應用，無論是直接使用 Univer 的元件，還是註冊自定義元件，都比較直接。React 並非唯一選擇，Univer 同樣支援 Vue（3.x）和 Web Components。

基礎元件由 `@univerjs/design` 包提供，圖示元件由 `@univerjs/icons` 包提供。這兩組元件都可以脫離 Univer 單獨使用。

自定義元件通常用於以下場景：

- 在 Ribbon 或 Context Menu 中新增自定義按鈕
- 在 Sidebar、Popup 等位置整合自定義元件
- 替換內建元件

後續章節介紹如何註冊和使用自定義元件。
