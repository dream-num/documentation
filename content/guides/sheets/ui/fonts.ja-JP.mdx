## フォント構造の定義

フォントは、`IFontConfig` インターフェイスによって記述されます。

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| `value` | `string` | フォントのユニークな識別子、通常はCSSフォント家族で使用する値です。 |
| `label` | `string` | 国際化に用いられる翻訳キー。Univerインスタンスが作成されるとキーが指定されていない場合、供給された値が直接表示されます。 |
| `category` | `FontCategory` | フォントカテゴリは、UI のエントリをグループ化するために使われます。オプション。 |

<Callout>
  Univerは、インストールされていないフォントを選択しないからユーザが選択しないようにします。クライアントがそのフォントを持っていない場合、ブラウザはデフォルトフォントに戻ります。
</Callout>

## カスタムフォントの使用

`UniverSheetsCorePreset`(プリセットモード)または`UniverUIPlugin` (プラグインモード)で`customFontFamily`を設定し、フォントのドロップダウンで選択肢を設定できます。

### プラグイン設定

`UniverUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターのマウント先となる DOM 要素、またはその ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | ドロップダウンにフォントを追加します。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | ドロップダウンにフォントを追加します。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS で使うフォント名。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 表示名または翻訳キー。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 分類。`sans-serif`、`serif`、`monospace`、`display`、`handwriting` を指定できます。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 既定のフォント一覧を指定した一覧に置き換えます。 |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // デフォルトのフォントリストを上書きするかどうか、デフォルトは false
    override: true,
  },
})
```

### プリセット設定

`UniverSheetsCorePreset`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | エディターのマウント先となる DOM 要素、またはその ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | ドロップダウンにフォントを追加します。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | ドロップダウンにフォントを追加します。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS で使うフォント名。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 表示名または翻訳キー。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 分類。`sans-serif`、`serif`、`monospace`、`display`、`handwriting` を指定できます。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 既定のフォント一覧を指定した一覧に置き換えます。 |

```typescript
import { FontCategory } from '@univerjs/ui'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      container: 'app',
      customFontFamily: {
        list: [
          {
            value: 'PingFang SC',
            label: '苹方（简）',
            category: FontCategory.SANS_SERIF,
          },
          {
            value: 'Helvetica Neue',
            label: 'Helvetica Neue',
            category: FontCategory.SANS_SERIF,
          },
        ],
        // デフォルトのフォントリストを上書きするかどうか、デフォルトは false
        override: true,
      },
    }),
  ],
})
```

## Facade API

フォントは起動時に設定する必要はありません。また、実行時に実行時間に追加することもできます。 Facade APIフォントファイルが非同期的に読み込まれるときに便利です。

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
