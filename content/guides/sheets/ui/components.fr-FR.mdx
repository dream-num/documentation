Univer n'accepte pas un composant comme argument pour un appel de rendu. Un composant doit être enregistré via le Facade API avant de pouvoir être référencé partout où Univer le monte.

Si une instance Facade API n'est pas encore disponible, consultez [Facade API](/guides/sheets/getting-started/facade).

## Enregistrer des composants personnalisés

```typescript
// [!code word:componentKey]
// [!code word:CustomComponent]
// [!code word:options]
univerAPI.registerComponent(componentKey, CustomComponent, options)
```

`univerAPI.registerComponent` enregistre un composant et prend trois arguments :

- `componentKey`: l'identifiant unique du composant, utilisé pour le référencer à l'intérieur de Univer.
- `CustomComponent` : le composant lui-même, qui peut être un composant React, un composant Vue ou un composant Web.
- `options`: paramètres optionnels, tels que le cadre dont dépend le composant ou toute autre configuration connexe.

### Composants React [#react]

Les composants React ne nécessitent aucune configuration supplémentaire. Le composant doit être un composant React valide, comme dans l'exemple suivant:

```tsx
function ReactComponent(props: Record<string, any>) {
  return <div>Hello Univer!</div>
}

univerAPI.registerComponent('MyReactComponent', ReactComponent)
```

### Composants Vue [#vue]

#### Vue 3.x

Pour les composants Vue, installez le paquet `@univerjs/ui-adapter-vue3` et enregistrez `UniverVue3AdapterPlugin` à partir de celui-ci :

```package-install
npm install @univerjs/ui-adapter-vue3
```

```typescript
import { UniverVue3AdapterPlugin } from '@univerjs/ui-adapter-vue3'

univer.registerPlugin(UniverVue3AdapterPlugin)
```

Passez `framework` en `'vue3'` lorsque vous enregistrez le composant :

```tsx
const Vue3Component = defineComponent({
  setup(props) {
    return () => <div>Hello Univer!</div>
  },
})

univerAPI.registerComponent('MyVue3Component', Vue3Component, {
  // [!code word:vue3]
  framework: 'vue3',
})
```

#### Vue 2.x

Vue 2.x a atteint la fin de vie et n'est plus entretenu, de sorte que Univer ne fournit pas actuellement un plugin d'adaptateur d'interface utilisateur pour lui. L'adaptateur peut être implémenté en tant que plugin personnalisé. Le code ci-dessous est un plugin adaptateur Vue 2x qui peut servir de point de départ:

```typescript title="ui-adapter-vue2.ts"
import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
import { ComponentManager, UniverUIPlugin } from '@univerjs/ui'
import Vue from 'vue'

/**
 * The plugin that allows Univer to use Vue 2 components as UI components.
 */
@DependentOn(UniverUIPlugin)
export class UniverVue2AdapterPlugin extends Plugin {
  static override pluginName = 'UNIVER_UI_VUE2_ADAPTER_PLUGIN'

  constructor(
    private readonly _config = {},
    @Inject(Injector) protected readonly _injector: Injector,
    @Inject(ComponentManager) protected readonly _componentManager: ComponentManager,
  ) {
    super()
  }

  override onStarting(): void {
    const { createElement, useEffect, useRef } = this._componentManager.reactUtils

    this._componentManager.setHandler('vue2', (component: any) => {
      return (props: Record<string, any>) =>
        createElement(VueComponentWrapper, {
          component,
          props: Object.keys(props).reduce<Record<string, any>>((acc, key) => {
            if (key !== 'key') {
              acc[key] = props[key]
            }
            return acc
          }, {}),
          reactUtils: { createElement, useEffect, useRef },
        })
    })
  }
}

export function VueComponentWrapper(options: {
  component: any
  props: Record<string, any>
  reactUtils: typeof ComponentManager.prototype.reactUtils
}) {
  const { component, props, reactUtils } = options
  const { createElement, useEffect, useRef } = reactUtils

  const domRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!domRef.current) return

    const Constructor = Vue.extend(component)

    const instance = new Constructor({
      data: props,
    })
    instance.$mount()

    domRef.current.appendChild(instance.$el)

    return () => {
      instance.$destroy()
    }
  }, [props])

  return createElement('div', { ref: domRef })
}
```

Puis enregistrez le plugin:

```typescript
import { UniverVue2AdapterPlugin } from './ui-adapter-vue2' // [!code ++]

univer.registerPlugin(UniverUIPlugin)
univer.registerPlugin(UniverVue2AdapterPlugin) // [!code ++]
```

Les composants Vue 2.x ont besoin de `framework` réglé sur `'vue2'` :

```tsx
const Vue2Component = Vue.component('MyVue2Component', {
  template: '<div>Hello, Univer!</div>',
})

univerAPI.registerComponent('MyVue2Component', Vue2Component, {
  // [!code word:vue2]
  framework: 'vue2',
})
```

### Web Components [#web-component]

Pour enregistrer les composants Web, le composant doit suivre la norme des composants Web. Installez le paquet `@univerjs/ui-adapter-web-component` et enregistrez `UniverWebComponentAdapterPlugin` à partir de celui-ci :

```package-install
npm install @univerjs/ui-adapter-web-component
```

```typescript
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

univer.registerPlugin(UniverWebComponentAdapterPlugin)
```

Passer `framework` en `'web-component'` :

```tsx
class WebComponent extends HTMLElement {
  constructor() {
    super()
    const shadow = this.attachShadow({ mode: 'open' })
    const div = document.createElement('div')
    div.textContent = 'Hello Univer!'
    shadow.appendChild(div)
  }
}

univerAPI.registerComponent('my-web-component', WebComponent, {
  // [!code word:web-component]
  framework: 'web-component',
})
```

### Angular [#angular]

`createCustomElement` de `@angular/elements` convertit un composant Angular en un élément personnalisé. Après l'enregistrement de l'élément avec l'adaptateur du composant Web de Univer, le composant Angular peut apparaître dans une barre latérale ou une boîte de dialogue Univer.

Ajoutez `@angular/elements` à la même version que `@angular/core` et `@univerjs/ui-adapter-web-component` dans la même version qu'avec vos autres paquets Univer.

Appelez cette fonction après que Univer soit initialisé. L'injecteur Angular est fourni par le composant hôte : l'obtenir avec `private readonly injector = inject(Injector)` puis appeler `registerAngularPanel(univer, univerAPI, this.injector)`. Le composant hôte importe `inject` et `Injector` de `@angular/core` .

```typescript title="angular-panel.ts"
import type { Injector } from '@angular/core'
import type { FUniver, Univer } from '@univerjs/presets'
import { Component } from '@angular/core'
import { createCustomElement } from '@angular/elements'
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

@Component({
  selector: 'app-angular-panel',
  standalone: true,
  template: '<p>Hello from Angular!</p>',
})
export class AngularPanelComponent {}

export function registerAngularPanel(univer: Univer, univerAPI: FUniver, injector: Injector) {
  const element = createCustomElement(AngularPanelComponent, { injector })

  univer.registerPlugin(UniverWebComponentAdapterPlugin)
  return univerAPI.registerComponent('univer-angular-panel', element, {
    framework: 'web-component',
  })
}
```

Une fois l'éditeur rendu, passez la clé enregistrée comme contenu de la barre latérale :

```typescript
const sidebar = univerAPI.openSidebar({
  header: { title: 'Angular' },
  children: { label: 'univer-angular-panel' },
  width: 360,
})
```

Conservez la poignée d'enregistrement et la poignée sidebar, et appelez `dispose()` sur chaque fois qu'il n'est plus nécessaire. Enregistrez l'élément une fois par application. Son nom doit contenir un trait d'union et doit différer du sélecteur de composants Angular.

Angular Elements map inputs to element properties and outputs to DOM `CustomEvent` events. L'adaptateur de Univer définit les propriétés mais ne s'abonne pas aux sorties Angular par lui-même, de sorte que l'application doit relier ces événements quand ils sont nécessaires.

## Utiliser des composants personnalisés

Les méthodes ci-dessous placent des composants personnalisés aux emplacements rendus par Univer, ce qui étend et personnalise l'interface utilisateur.

<Callout type="warning" title="Attention">

1. N'appelez ces méthodes qu'après que Univer ait terminé le rendu.
2. Inscrivez un composant avant de l'utiliser.
3. Appelez `dispose()` pour nettoyer ce que vous avez ajouté et éviter les fuites de mémoire.

</Callout>

### Ajouter des éléments de menu personnalisés

Le Ruban en haut et le Menu contextuel en clic droit peuvent accueillir les deux composants personnalisés. Les éléments du Menu sont enregistrés par un plugin, donc l'ajout d'un plugin nécessite un plugin personnalisé. Un [guide des meilleures pratiques pour les éléments de menu personnalisés](/blog/custom-plugin) est disponible comme point de départ.

### Remplacer des composants intégrés

<Callout type="error" title="Avertissement">
  Le remplacement d'un composant intégré peut casser les fonctionnalités qui en dépendent. Lisez le code source et la documentation avant de tenter de le remplacer et procédez avec prudence.
</Callout>

`univerAPI.registerComponent` enregistre une redéfinition par défaut (`override: true`). La redéfinition prend la priorité sur le composant intégré, que le plugin enregistre sa valeur par défaut avant ou après l'appel. Seule une redéfinition peut être active pour chaque `componentKey`, donc disposer de l'enregistrement précédent avant d'en enregistrer un autre. Appeler `dispose()` sur l'enregistrement retourné restaure la valeur par défaut intégrée, si l'un d'eux était enregistré. Utilisez `{ override: false }` pour enregistrer une valeur par défaut.

Enregistrez l'option avant que la vue qu'elle couvre ne s'ouvre pour la première fois. Modifier une inscription ne renverra pas les vues déjà montées.

Les feuilles exportent les clés suivantes à partir de leurs entrées de paquets publiques; utilisez-les pour passer outre les composants intégrés correspondants:

| Composant | Clé exportée | Package |
| --- | --- | --- |
| Noms définis | `DEFINED_NAME_CONTAINER` | `@univerjs/sheets-ui` |
| Autres fonctions | `MORE_FUNCTIONS_COMPONENT` | `@univerjs/sheets-formula-ui` |
| Validation des données | `DATA_VALIDATION_PANEL` | `@univerjs/sheets-data-validation-ui` |
| Mise en forme conditionnelle | `CF_PANEL_KEY` | `@univerjs/sheets-conditional-formatting-ui` |

Par exemple, le code suivant remplace le composant ColorPicker intégré :

```tsx
// Following code only replaces the UI of the built-in ColorPicker component, not its functionality
univerAPI.registerComponent('UI_COLOR_PICKER_COMPONENT', () => <input type="color" />)
```

### Utiliser des composants comme contenu

#### Dans la barre latérale

`univerAPI.openSidebar` ouvre une barre latérale à l'intérieur de l'interface utilisateur Univer et y rend votre composant enregistré.

```tsx
// [!code word:MyCustomSidebarComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomSidebarComponent', () => <div>Hello Univer!</div>)

const sidebar = univerAPI.openSidebar({
  header: { title: 'My Sidebar' },
  children: { label: 'MyCustomSidebarComponent' },
  onClose: () => {
    console.log('close')
  },
  width: 360,
})

// Later close the sidebar
sidebar.dispose()
```

Référence : [`univerAPI.openSidebar`](/reference/facade/univer#opensidebar)

#### Dans une boîte de dialogue

`univerAPI.openDialog` ouvre une boîte de dialogue et rend votre composant enregistré à l'intérieur.

```tsx
// [!code word:MyCustomDialogComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomDialogComponent', () => <div>Hello Univer!</div>)

const dialog = univerAPI.openDialog({
  id: 'unique-dialog-id', // The unique identifier for the dialog
  draggable: true,
  width: 300,
  title: { title: 'My Dialog' },
  children: {
    label: 'MyCustomDialogComponent',
  },
  destroyOnClose: true,
  preservePositionOnDestroy: true,
  onClose: () => {},
})

// Later close the dialog
dialog.dispose()
```

Référence : [`univerAPI.openDialog`](/reference/facade/univer#opendialog)

#### Associer une fenêtre contextuelle à des cellules

`FRange.attachPopup` attache une popup personnalisée à une gamme de cellules spécifiques.

- Un popup est un élément DOM temporaire attaché à une cellule. Il affiche habituellement des informations sur l'état transitoire et ne supporte pas le stockage persistant.
- La signature de la méthode est [`FRange.attachPopup(popup: IFCanvasPopup)`](https://docs.univer.ai/reference/facade/range#attachpopup).
- Le popup s'attache aux bords de la cellule et ajuste sa position et son orientation quand quelque chose l'obstrue.

```tsx
// [!code word:MyCustomPopupComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomPopupComponent', () => <div>Hello Univer!</div>)

const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:J10')

// Attach the popup to the first cell of the range
// If `disposable` is null, it indicates that the popup was not added successfully
const disposable = fRange.attachPopup({
  componentKey: 'MyCustomPopupComponent',
})

// Remove the popup
disposable.dispose()
```

#### Associer une fenêtre contextuelle d’alerte

`FRange.attachAlertPopup` attache une popup d'alerte à la cellule de départ d'une plage spécifique.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

const disposable = fRange.attachAlertPopup({
  key: 'unique-alert-key', // Unique identifier
  title: '这是一个警告！',
  message: '这是一个警告！',
  width: 300,
  height: 200,
  // 0: Information
  // 1: Warning
  // 2: Error
  type: 0,
})

// Remove the alert later
disposable.dispose()
```

#### Ajouter un DOM flottant à une feuille de calcul

`FWorksheet.addFloatDomToPosition` ajoute un élément DOM flottant à la feuille de travail.

- Avant d'utiliser cette méthode, installez le plugin `@univerjs/sheets-drawing-ui` ou le préréglage `@univerjs/preset-sheets-drawing`.
- Un élément DOM flottant est un composant dragable qui survole la feuille de travail et supporte le stockage persistant.
- Appelez cette méthode après que Univer ait terminé le rendu.
- `componentKey`: l'identificateur unique pour le composant, utilisé pour le référencer à l'intérieur de Univer.
- [Définition complète des paramètres](https://github.com/dream-num/univer/blob/dev/packages/sheets-drawing-ui/src/facade/f-worksheet.ts#L32)

```tsx
// [!code word:MyCustomFloatDOMComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomFloatDOMComponent', ({ data }) => (
  <div>
    Hello
    {data?.label}!
  </div>
))
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Add a floating DOM to the worksheet
// If `disposable` is null, it indicates that the floating DOM was not added successfully
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'MyCustomFloatDOMComponent',
  initPosition: {
    startX: 100,
    endX: 200,
    startY: 100,
    endY: 200,
  },

  // The data for the component
  data: {
    label: 'Univer',
  },
})

// Remove the floating DOM
disposable.dispose()
```
