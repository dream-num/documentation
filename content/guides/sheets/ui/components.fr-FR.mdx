Univer ne transmet pas directement les composants en tant que paramètres aux fonctions de rendu. Vous devez d’abord les enregistrer auprès d’Univer à l’aide de la Facade API avant de pouvoir les utiliser dans les différents points de montage.

Si vous ne savez pas comment obtenir une instance de la Facade API, consultez la page [Facade API](/guides/sheets/getting-started/facade).


## Enregistrer des composants personnalisés

```typescript
// [!code word:componentKey]
// [!code word:CustomComponent]
// [!code word:options]
univerAPI.registerComponent(componentKey, CustomComponent, options)
```

Utilisez la méthode `univerAPI.registerComponent` pour enregistrer des composants personnalisés. Cette méthode accepte trois paramètres :

- `componentKey` : identifiant unique du composant, utilisé pour le référencer dans Univer.
- `CustomComponent` : implémentation du composant, qui peut être un composant React, Vue ou Web Component.
- `options` : options de configuration facultatives permettant notamment d’indiquer le framework dont dépend le composant.

### Composants React [#react]

L’enregistrement d’un composant React ne nécessite aucune configuration supplémentaire ; assurez-vous simplement qu’il s’agit d’un composant React valide. Voici un exemple simple :

```tsx
function ReactComponent(props: Record<string, any>) {
  return <div>Hello Univer!</div>
}

univerAPI.registerComponent('MyReactComponent', ReactComponent)
```

### Composants Vue [#vue]

#### Vue 3.x

Pour enregistrer des composants Vue, installez et enregistrez le plugin `UniverVue3AdapterPlugin` du package `@univerjs/ui-adapter-vue3` :

```package-install
npm install @univerjs/ui-adapter-vue3
```

```typescript
import { UniverVue3AdapterPlugin } from '@univerjs/ui-adapter-vue3'

univer.registerPlugin(UniverVue3AdapterPlugin)
```

Lors de l’enregistrement de composants Vue, vous devez définir l’option `framework` sur `'vue3'` :

```tsx
const Vue3Component = defineComponent({
  setup(props) {
    return () => <div>Hello Univer!</div>
  },
})

univerAPI.registerComponent('MyVue3Component', Vue3Component, {
  // [!code word:vue3]
  framework: 'vue3',
})
```

#### Vue 2.x

Comme Vue 2.x est arrivé en fin de vie et n’est plus maintenu, Univer ne fournit actuellement aucun plugin d’adaptation d’interface utilisateur pour Vue 2.x. Vous pouvez toutefois créer un plugin personnalisé afin d’implémenter votre propre adaptateur Vue 2.x. Voici un exemple :

```typescript title="ui-adapter-vue2.ts"
import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
import { ComponentManager, UniverUIPlugin } from '@univerjs/ui'
import Vue from 'vue'

/**
 * The plugin that allows Univer to use Vue 2 components as UI components.
 */
@DependentOn(UniverUIPlugin)
export class UniverVue2AdapterPlugin extends Plugin {
  static override pluginName = 'UNIVER_UI_VUE2_ADAPTER_PLUGIN'

  constructor(
    private readonly _config = {},
    @Inject(Injector) protected readonly _injector: Injector,
    @Inject(ComponentManager) protected readonly _componentManager: ComponentManager,
  ) {
    super()
  }

  override onStarting(): void {
    const { createElement, useEffect, useRef } = this._componentManager.reactUtils

    this._componentManager.setHandler('vue2', (component: any) => {
      return (props: Record<string, any>) =>
        createElement(VueComponentWrapper, {
          component,
          props: Object.keys(props).reduce<Record<string, any>>((acc, key) => {
            if (key !== 'key') {
              acc[key] = props[key]
            }
            return acc
          }, {}),
          reactUtils: { createElement, useEffect, useRef },
        })
    })
  }
}

export function VueComponentWrapper(options: {
  component: any
  props: Record<string, any>
  reactUtils: typeof ComponentManager.prototype.reactUtils
}) {
  const { component, props, reactUtils } = options
  const { createElement, useEffect, useRef } = reactUtils

  const domRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!domRef.current) return

    const Constructor = Vue.extend(component)

    const instance = new Constructor({
      data: props,
    })
    instance.$mount()

    domRef.current.appendChild(instance.$el)

    return () => {
      instance.$destroy()
    }
  }, [props])

  return createElement('div', { ref: domRef })
}
```

Enregistrez-le ensuite :

```typescript
import { UniverVue2AdapterPlugin } from './ui-adapter-vue2' // [!code ++]

univer.registerPlugin(UniverUIPlugin)
univer.registerPlugin(UniverVue2AdapterPlugin) // [!code ++]
```

Lors de l’enregistrement de composants Vue 2.x, vous devez définir l’option `framework` sur `'vue2'` :

```tsx
const Vue2Component = Vue.component('MyVue2Component', {
  template: '<div>Hello, Univer!</div>',
})

univerAPI.registerComponent('MyVue2Component', Vue2Component, {
  // [!code word:vue2]
  framework: 'vue2',
})
```

### Web Components [#web-component]

Pour enregistrer des Web Components, assurez-vous qu’ils respectent le standard Web Components, puis installez et enregistrez le plugin `UniverWebComponentAdapterPlugin` du package `@univerjs/ui-adapter-web-component` :

```package-install
npm install @univerjs/ui-adapter-web-component
```

```typescript
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

univer.registerPlugin(UniverWebComponentAdapterPlugin)
```

Lors de l’enregistrement de Web Components, vous devez définir l’option `framework` sur `'web-component'` :

```tsx
class WebComponent extends HTMLElement {
  constructor() {
    super()
    const shadow = this.attachShadow({ mode: 'open' })
    const div = document.createElement('div')
    div.textContent = 'Hello Univer!'
    shadow.appendChild(div)
  }
}

univerAPI.registerComponent('my-web-component', WebComponent, {
  // [!code word:web-component]
  framework: 'web-component',
})
```

### Angular [#angular]

Convertissez un composant Angular en élément personnalisé avec `createCustomElement` de `@angular/elements`, puis enregistrez-le avec l’adaptateur Web Component de Univer. Il pourra apparaître dans une barre latérale ou un dialogue.

Ajoutez `@angular/elements` à la même version que `@angular/core`, et `@univerjs/ui-adapter-web-component` à la même version que les autres packages Univer.

Appelez cette fonction après l’initialisation de Univer. Dans le composant hôte, obtenez l’injecteur avec `private readonly injector = inject(Injector)`, puis appelez `registerAngularPanel(univer, univerAPI, this.injector)`. Importez `inject` et `Injector` depuis `@angular/core` dans ce composant.

```typescript title="angular-panel.ts"
import type { Injector } from '@angular/core'
import type { FUniver, Univer } from '@univerjs/presets'
import { Component } from '@angular/core'
import { createCustomElement } from '@angular/elements'
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

@Component({
  selector: 'app-angular-panel',
  standalone: true,
  template: '<p>Hello from Angular!</p>',
})
export class AngularPanelComponent {}

export function registerAngularPanel(univer: Univer, univerAPI: FUniver, injector: Injector) {
  const element = createCustomElement(AngularPanelComponent, { injector })

  univer.registerPlugin(UniverWebComponentAdapterPlugin)
  return univerAPI.registerComponent('univer-angular-panel', element, {
    framework: 'web-component',
  })
}
```

Une fois l’éditeur rendu, utilisez la clé enregistrée comme contenu de la barre latérale :

```typescript
const sidebar = univerAPI.openSidebar({
  header: { title: 'Angular' },
  children: { label: 'univer-angular-panel' },
  width: 360,
})
```

Conservez les handles d’enregistrement et de barre latérale, puis appelez leur méthode `dispose()` quand ils ne sont plus nécessaires. Enregistrez l’élément une seule fois dans l’application. Son nom doit contenir un trait d’union et différer du selector Angular.

Angular Elements convertit les entrées en propriétés et les sorties en événements DOM `CustomEvent`. L’adaptateur Univer transmet les propriétés sans s’abonner automatiquement aux sorties Angular : reliez explicitement les événements nécessaires.

## Utiliser des composants personnalisés

Les méthodes suivantes vous permettent d’intégrer avec souplesse différents composants personnalisés dans Univer afin d’enrichir et d’adapter ses fonctionnalités.

<Callout type="warning" title="Attention">
  1. Avant d’utiliser ces méthodes, assurez-vous qu’Univer a terminé le rendu. 2. Pour les composants qui doivent être
  enregistrés, vérifiez que leur enregistrement a bien été effectué avant de les utiliser. 3. Utilisez la méthode
  `dispose()` pour nettoyer et supprimer les composants ajoutés afin d’éviter les fuites de mémoire.
</Callout>

### Ajouter des éléments de menu personnalisés

La barre de menu supérieure (Ribbon) et le menu contextuel (Context Menu) peuvent tous deux contenir des composants personnalisés. Pour ajouter ces composants à des éléments de menu, vous devez créer un plugin personnalisé. Nous avons préparé un [guide de bonnes pratiques pour l’ajout d’éléments de menu personnalisés](/blog/custom-plugin) afin de vous aider à démarrer rapidement.

### Remplacer des composants intégrés

<Callout type="error" title="Avertissement">
  Le remplacement de composants intégrés peut empêcher certaines fonctionnalités de fonctionner correctement. Lisez
  attentivement le code source et la documentation avant de tenter de remplacer des composants, et procédez avec
  prudence.
</Callout>

`univerAPI.registerComponent` enregistre une substitution par défaut (`override: true`). Elle est prioritaire, quel que soit l’ordre d’enregistrement du composant par défaut du plugin. Une seule substitution peut être active par `componentKey` : libérez la précédente avant d’en enregistrer une autre. La méthode `dispose()` de l’objet retourné rétablit le composant par défaut, s’il est enregistré. Utilisez `{ override: false }` pour enregistrer un composant par défaut.

Enregistrez la substitution avant la première ouverture de la vue. Modifier l’enregistrement ne déclenche pas automatiquement un nouveau rendu des vues déjà montées.

Les entrées publiques des packages Sheets exposent ces clés pour remplacer les composants intégrés correspondants :

| Composant | Clé exportée | Package |
| --- | --- | --- |
| Noms définis | `DEFINED_NAME_CONTAINER` | `@univerjs/sheets-ui` |
| Autres fonctions | `MORE_FUNCTIONS_COMPONENT` | `@univerjs/sheets-formula-ui` |
| Validation des données | `DATA_VALIDATION_PANEL` | `@univerjs/sheets-data-validation-ui` |
| Mise en forme conditionnelle | `CF_PANEL_KEY` | `@univerjs/sheets-conditional-formatting-ui` |

Par exemple, pour remplacer simplement le composant ColorPicker intégré :

```tsx
// Following code only replaces the UI of the built-in ColorPicker component, not its functionality
univerAPI.registerComponent('UI_COLOR_PICKER_COMPONENT', () => <input type="color" />)
```

### Utiliser des composants comme contenu

#### Dans la barre latérale

La méthode `univerAPI.openSidebar` permet d’ouvrir dans l’interface d’Univer une barre latérale contenant un composant personnalisé.

```tsx
// [!code word:MyCustomSidebarComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomSidebarComponent', () => <div>Hello Univer!</div>)

const sidebar = univerAPI.openSidebar({
  header: { title: 'My Sidebar' },
  children: { label: 'MyCustomSidebarComponent' },
  onClose: () => {
    console.log('close')
  },
  width: 360,
})

// Later close the sidebar
sidebar.dispose()
```

Référence : [`univerAPI.openSidebar`](/reference/facade/univer#opensidebar)

#### Dans une boîte de dialogue

La méthode `univerAPI.openDialog` permet d’ouvrir une boîte de dialogue contenant un composant personnalisé.

```tsx
// [!code word:MyCustomDialogComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomDialogComponent', () => <div>Hello Univer!</div>)

const dialog = univerAPI.openDialog({
  id: 'unique-dialog-id', // The unique identifier for the dialog
  draggable: true,
  width: 300,
  title: { title: 'My Dialog' },
  children: {
    label: 'MyCustomDialogComponent',
  },
  destroyOnClose: true,
  preservePositionOnDestroy: true,
  onClose: () => {},
})

// Later close the dialog
dialog.dispose()
```

Référence : [`univerAPI.openDialog`](/reference/facade/univer#opendialog)


#### Associer une fenêtre contextuelle à des cellules

La méthode `FRange.attachPopup` permet d’associer une fenêtre contextuelle personnalisée à une plage de cellules donnée.

- Une fenêtre contextuelle est un élément DOM temporaire associé à une cellule. Elle sert généralement à afficher des informations d’état provisoires et ne prend pas en charge le stockage persistant.
- La méthode [`FRange.attachPopup(popup: IFCanvasPopup)`](https://docs.univer.ai/reference/facade/range#attachpopup) permet d’associer une fenêtre contextuelle personnalisée à une plage de cellules donnée.
- La fenêtre contextuelle se fixe sur les bords de la cellule et ajuste automatiquement sa position et son orientation si elle est masquée.

```tsx
// [!code word:MyCustomPopupComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomPopupComponent', () => <div>Hello Univer!</div>)

const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:J10')

// Attach the popup to the first cell of the range
// If `disposable` is null, it indicates that the popup was not added successfully
const disposable = fRange.attachPopup({
  componentKey: 'MyCustomPopupComponent',
})

// Remove the popup
disposable.dispose()
```

#### Associer une fenêtre contextuelle d’alerte

La méthode `FRange.attachAlertPopup` permet d’associer une fenêtre contextuelle d’alerte à la cellule de départ d’une plage donnée.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

const disposable = fRange.attachAlertPopup({
  key: 'unique-alert-key', // Unique identifier
  title: '这是一个警告！',
  message: '这是一个警告！',
  width: 300,
  height: 200,
  // 0: Information
  // 1: Warning
  // 2: Error
  type: 0,
})

// Remove the alert later
disposable.dispose()
```

#### Ajouter un DOM flottant à une feuille de calcul

La méthode `FWorksheet.addFloatDomToPosition` permet d’ajouter un DOM flottant à une feuille de calcul.

- Avant d’utiliser cette méthode, vous devez installer le plugin `@univerjs/sheets-drawing-ui` ou le preset `@univerjs/preset-sheets-drawing`.
- Le DOM flottant est un composant déplaçable qui s’affiche au-dessus de la feuille de calcul et prend en charge le stockage persistant.
- Vous devez appeler cette méthode une fois le rendu d’Univer terminé.
- `componentKey` : identifiant unique du composant, utilisé pour y faire référence dans Univer.
- [Définition complète des paramètres](https://github.com/dream-num/univer/blob/dev/packages/sheets-drawing-ui/src/facade/f-worksheet.ts#L32)

```tsx
// [!code word:MyCustomFloatDOMComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomFloatDOMComponent', ({ data }) => (
  <div>
    Hello
    {data?.label}!
  </div>
))
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Add a floating DOM to the worksheet
// If `disposable` is null, it indicates that the floating DOM was not added successfully
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'MyCustomFloatDOMComponent',
  initPosition: {
    startX: 100,
    endX: 200,
    startY: 100,
    endY: 200,
  },

  // The data for the component
  data: {
    label: 'Univer',
  },
})

// Remove the floating DOM
disposable.dispose()
```

## Extension des menus : intégration applicative et développement de plugins [#menu-extension-paths]

Choisissez selon la tâche. Les deux approches utilisent le même système de menus ; la Facade encapsule les opérations applicatives.

| Tâche | Point d’entrée | Exemple |
| --- | --- | --- |
| Ajouter des boutons métier et sous-menus | `createMenu()` / `createSubmenu()` / `appendTo()` | [Exemple applicatif](#nested-toolbar-menu) |
| Afficher, masquer ou désactiver des éléments | Configuration initiale `menu` / `updateMenuConfig()` | [Configuration dynamique](#menu-runtime-configuration) |
| Développer un plugin SDK avec ses menus, commandes et icônes | Cycle de vie `Plugin` / Schema de menu / services d’extension injectés | [Exemple de plugin](#plugin-menu-example) |

Une installation en **mode plugin** permet aussi à l’application d’utiliser les API Facade. Un plugin SDK personnalisé enregistre ses extensions par injection de dépendances et cycle de vie : `IMenuManagerService` gère le Schema des menus, `ICommandService` les commandes et `IconManager` les icônes.

## Intégration applicative : menus Vue et actions métier [#nested-toolbar-menu]

Ajoutez un raccourci de barre d’outils et un menu contextuel imbriqué avec Facade API. Les deux exécutent la même action métier : écrire `Approved` dans A1.

[Exécuter l’exemple complet](#vue-menu-example)

Terminez d’abord l’[intégration Vue](/guides/sheets/getting-started/integrations/vue). Ce projet utilise **Univer 1.3.0** ; alignez les versions des paquets Univer. L’icône `ProtectIcon` est intégrée.

Placez ce code dans `review-menu.ts` et appelez-le une fois après l’initialisation, avant de créer le classeur.

```typescript
import type { FUniver } from '@univerjs/core/facade'
import '@univerjs/sheets/facade'
import '@univerjs/ui/facade'

export function registerReviewMenus(univerAPI: FUniver) {
  const approve = () => {
    const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
    if (!sheet) return
    sheet.getRange('A1').setValue('Approved')
  }

  univerAPI.createMenu({
    id: 'review.quick-approve',
    title: 'Quick approve',
    icon: 'ProtectIcon',
    action: approve,
  }).appendTo('ribbon.start.others')

  const approveItem = univerAPI.createMenu({
    id: 'review.approve',
    title: 'Approve',
    icon: 'ProtectIcon',
    action: approve,
  })

  const actions = univerAPI.createSubmenu({
    id: 'review.actions',
    title: 'Actions',
  }).addSubmenu(approveItem)

  univerAPI.createSubmenu({
    id: 'review.root',
    title: 'Review',
  }).addSubmenu(actions)
    .appendTo(['contextMenu.mainArea', 'contextMenu.others'])
}
```

```typescript
import { registerReviewMenus } from './review-menu'

registerReviewMenus(univerAPI)
```

Le raccourci est **Start → Quick approve**. Faites un clic droit sur une cellule pour **Review → Actions → Approve**. Le menu imbriqué de cet exemple est contextuel. Voir [FMenu](/reference/facade/menu) et [FSubmenu](/reference/facade/submenu).

Téléchargez et décompressez le projet Vue complet :

[Télécharger l’exemple de menu Vue 3](/assets/examples/vue3/univer-vue3-menu-starter.zip)


## Développement de plugin : enregistrer commande, icône et menu [#plugin-menu-example]

[Exécuter l’exemple complet](#vue-menu-example)

Utilisez le mécanisme de plugin pour une extension ayant son enregistrement et son cycle de vie. Cet exemple suit le [contrôleur Sheets UI](https://github.com/dream-num/univer/blob/dev/packages/sheets-ui/src/controllers/ui.controller.ts) et l’[enregistrement des icônes](https://github.com/dream-num/univer/blob/dev/packages/ui/src/controllers/components.controller.ts) via `IconManager`. Placez le code dans `review-plugin.ts`.

```typescript
import { CommandType, DependentOn, ICommandService, Inject, Injector, Plugin, UniverInstanceType } from '@univerjs/core'
import { UniverSheetsUIPlugin } from '@univerjs/sheets-ui'
import { IconManager, IMenuManagerService, MenuItemType, RibbonStartGroup } from '@univerjs/ui'
import { createElement } from 'react'

const APPROVE_COMMAND_ID = 'review-plugin.command.approve'
const APPROVE_MENU_ID = 'review-plugin.menu.approve'
const APPROVE_ICON_ID = 'review-plugin.icon.approve'

function ReviewIcon() {
  return createElement('svg', {
    viewBox: '0 0 24 24', width: 16, height: 16,
    fill: 'none', stroke: 'currentColor', strokeWidth: 2,
    'aria-hidden': true, 'data-review-plugin-icon': true,
  }, createElement('path', { d: 'M5 12l4 4L19 6' }))
}

@DependentOn(UniverSheetsUIPlugin)
export class ReviewPlugin extends Plugin {
  static override pluginName = 'REVIEW_PLUGIN'
  static override type = UniverInstanceType.UNIVER_SHEET

  constructor(
    private readonly _config: { approve: () => boolean },
    @Inject(Injector) protected override _injector: Injector,
    @ICommandService private readonly _commands: ICommandService,
    @IMenuManagerService private readonly _menus: IMenuManagerService,
    @Inject(IconManager) private readonly _icons: IconManager,
  ) { super() }

  override onStarting() {
    this.disposeWithMe(this._commands.registerCommand({
      id: APPROVE_COMMAND_ID,
      type: CommandType.COMMAND,
      handler: () => this._config.approve(),
    }))
    this.disposeWithMe(this._icons.register(APPROVE_ICON_ID, ReviewIcon))
    this._menus.mergeMenu({
      [RibbonStartGroup.OTHERS]: {
        [APPROVE_MENU_ID]: {
          order: 0,
          menuItemFactory: () => ({
            id: APPROVE_MENU_ID,
            commandId: APPROVE_COMMAND_ID,
            type: MenuItemType.BUTTON,
            title: 'Plugin approve',
            icon: APPROVE_ICON_ID,
          }),
        },
      },
    })
  }
}
```

Enregistrez `ReviewPlugin` après l’initialisation du preset, avant de créer le classeur. Il dépend de `UniverSheetsUIPlugin` ; le projet complet inclut la même version de `@univerjs/sheets-ui`. Le menu exécute sa propre commande et la modification des données passe par la Facade.

```typescript
import { ReviewPlugin } from './review-plugin'

univer.registerPlugin(ReviewPlugin, {
  approve: () => {
    const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
    if (!sheet) return false
    sheet.getRange('A1').setValue('Approved by plugin')
    return true
  },
})
```

Dans le même projet, sélectionnez **SDK Plugin** ou ouvrez `/?example=plugin`. La coche personnalisée de **Plugin approve** apparaît ; un clic remplace `Draft` par `Approved by plugin` dans A1. Annuler restaure `Draft`. Les enregistrements des commandes et icônes sont gérés par `disposeWithMe()` ; le Schema du menu suit la durée de vie de l’éditeur.

## Configuration dynamique : ID de menu et ID de commande [#menu-runtime-configuration]

L’ID de l’élément est `review-plugin.menu.approve` et celui de la commande `review-plugin.command.approve`. Configurez l’**ID de l’élément de menu** pour modifier son état UI.

Cochez puis décochez **Disable toolbar button** pour désactiver puis activer le bouton. Faites de même avec **Hide toolbar button** pour le masquer puis l’afficher. Ces contrôles de l’hôte appellent `updateMenuConfig()` ; la désactivation correspond à :

```typescript
univerAPI.updateMenuConfig({
  'review-plugin.menu.approve': { disabled: true },
})
```

Utilisez `disabled: false` pour activer et `hidden: true` / `false` pour masquer ou restaurer. Dans l’exemple applicatif, les contrôles affectent uniquement le raccourci de la barre d’outils, pas l’action contextuelle séparée.
