## 设计系统

Univer 的设计系统基于 Tailwind CSS，定义了一组由渲染引擎复用的设计 Tokens，使渲染引擎与视图层在视觉上保持一致。这些 Tokens 位于 `@univerjs/themes` 包中，修改这些 Tokens 即可调整应用样式。

## 组件

Univer 的视图层由 React 组件构建。对于已经使用 React 的应用，无论是直接使用 Univer 的组件，还是注册自定义组件，都比较直接。React 并非唯一选择，Univer 同样支持 Vue（3.x）和 Web Components。

基础组件由 `@univerjs/design` 包提供，图标组件由 `@univerjs/icons` 包提供。这两组组件都可以脱离 Univer 单独使用。

自定义组件通常用于以下场景：

- 在 Ribbon 或 Context Menu 中添加自定义按钮
- 在 Sidebar、Popup 等位置集成自定义组件
- 替换内置组件
