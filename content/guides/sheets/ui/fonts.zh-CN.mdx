## 字体结构定义

字体用 `IFontConfig` 接口描述：

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `value` | `string` | 字体的唯一标识，通常是 CSS font-family 中要使用的值。 |
| `label` | `string` | 用于国际化的翻译键。创建 Univer 实例时如果未指定该键，则直接显示传入的值。 |
| `category` | `FontCategory` | 字体类别，用于在 UI 中分组，可选。 |

<Callout>
  Univer 不限制用户选择未安装的字体。客户端没有该字体时，浏览器会回退到默认字体。
</Callout>

## 使用自定义字体

字体下拉菜单中的选项由 `customFontFamily` 配置：预设模式下配置在 `UniverSheetsCorePreset` 上，插件模式下配置在 `UniverUIPlugin` 上。

### 插件配置

`UniverUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 编辑器挂载的 DOM 元素或元素 ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | 在字体下拉列表中添加这些选项。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | 在字体下拉列表中添加这些选项。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS 使用的字体名称。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 显示名称或翻译键。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 字体分组，可选 `sans-serif`、`serif`、`monospace`、`display` 或 `handwriting`。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 用传入的列表替换内置字体选项。 |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // 是否覆盖默认字体列表，默认为 false
    override: true,
  },
})
```

### 预设配置

`UniverSheetsCorePreset`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 编辑器挂载的 DOM 元素或元素 ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | 在字体下拉列表中添加这些选项。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | 在字体下拉列表中添加这些选项。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS 使用的字体名称。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 显示名称或翻译键。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 字体分组，可选 `sans-serif`、`serif`、`monospace`、`display` 或 `handwriting`。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 用传入的列表替换内置字体选项。 |

```typescript
import { FontCategory } from '@univerjs/ui'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      container: 'app',
      customFontFamily: {
        list: [
          {
            value: 'PingFang SC',
            label: '苹方（简）',
            category: FontCategory.SANS_SERIF,
          },
          {
            value: 'Helvetica Neue',
            label: 'Helvetica Neue',
            category: FontCategory.SANS_SERIF,
          },
        ],
        // 是否覆盖默认字体列表，默认为 false
        override: true,
      },
    }),
  ],
})
```

## Facade API

字体不必只在初始化时配置，运行时也可以通过 Facade API 添加，适用于字体文件需要异步加载的场景。

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: '苹方（简）',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
