## Definición de estructura de fuentes

Una fuente es descrita por la interfaz `IFontConfig`:

| Propiedad | Tipo | Descripción |
| --- | --- | --- |
| `value` | `string` | El identificador único de la fuente, por lo general el valor para usar para la familia de fuentes CSS. |
| `label` | `string` | La clave de traducción utilizada para la internacionalización. Si la clave no se especifica cuando se crea la instancia Univer, el valor suministrado se muestra directamente. |
| `category` | `FontCategory` | Categoría de fuentes, utilizado para agrupar entradas en la UI. Opcional. |

<Callout>
  Univer no impide que los usuarios seleccionen una fuente que no está instalada. Si el cliente no tiene esa fuente, el navegador vuelve a la fuente predeterminada.
</Callout>

## Uso de fuentes personalizadas

Configurar `customFontFamily` en `UniverSheetsCorePreset` (Modo de inicio) o `UniverUIPlugin` para configurar las opciones en el desplegable de fuentes.

### Configuración de plugins

`UniverUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Elemento DOM donde se monta el editor o su ID. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Añade estas fuentes al menú desplegable. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Añade estas fuentes al menú desplegable. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Nombre de la fuente en CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Nombre visible o clave de traducción. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Categoría: `sans-serif`, `serif`, `monospace`, `display` o `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Sustituye las fuentes integradas por la lista indicada. |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // Whether to override the default font list, defaults to false
    override: true,
  },
})
```

### Configuración de preajustes

`UniverSheetsCorePreset`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | Elemento DOM donde se monta el editor o su ID. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Añade estas fuentes al menú desplegable. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Añade estas fuentes al menú desplegable. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Nombre de la fuente en CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Nombre visible o clave de traducción. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Categoría: `sans-serif`, `serif`, `monospace`, `display` o `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Sustituye las fuentes integradas por la lista indicada. |

```typescript
import { FontCategory } from '@univerjs/ui'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsCorePreset({
      container: 'app',
      customFontFamily: {
        list: [
          {
            value: 'PingFang SC',
            label: '苹方（简）',
            category: FontCategory.SANS_SERIF,
          },
          {
            value: 'Helvetica Neue',
            label: 'Helvetica Neue',
            category: FontCategory.SANS_SERIF,
          },
        ],
        // Whether to override the default font list, defaults to false
        override: true,
      },
    }),
  ],
})
```

## API de Facade

Las fuentes no tienen que ser configuradas al iniciarse. También se pueden añadir en tiempo de ejecución a través de Facade API, que es útil cuando los archivos de fuentes se cargan de forma asincrónica.

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
