## Système de design

Le système de conception de Univer est construit sur Tailwind CSS. Il définit un ensemble de jetons de conception que le moteur de rendu réutilise, de sorte que le moteur du rendu et la couche de vue restent visuellement cohérents. Les jetons sont fournis par le paquet `@univerjs/themes`, et les changer remodele l'application.

## Composants

Univer construit sa couche de vue avec des composants React. Pour les applications qui utilisent déjà React, l'utilisation des composants de Univer ou l'enregistrement de composants personnalisés est simple. React n'est pas la seule option : Univer prend également en charge Vue (3.x) et les composants Web.

Les composants de base sont fournis par le paquet `@univerjs/design` et les composants icônes par `@univerjs/icons`. Les deux peuvent être utilisés indépendamment de Univer .

Les composants personnalisés sont généralement utilisés dans trois situations :

- Ajout de boutons personnalisés au menu Ruban ou Contexte
- Intégrer des composants personnalisés dans les surfaces latérales, popup et similaires
- Remplacement des composants intégrés
