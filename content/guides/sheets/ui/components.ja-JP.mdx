Univerは、レンダーコールの引数としてコンポーネントを受け入れません。Facade APIでは、Univerがマウントする場所を参照できる前に、コンポーネントはZXQXZから登録する必要があります。

Facade API インスタンスがまだ使用できない場合は、[Facade API](/guides/sheets/getting-started/facade)を参照してください。

## カスタムコンポーネントの登録

```typescript
// [!code word:componentKey]
// [!code word:CustomComponent]
// [!code word:options]
univerAPI.registerComponent(componentKey, CustomComponent, options)
```

`univerAPI.registerComponent`はコンポーネントを登録し、3つの引数を取ります。

- `componentKey`: コンポーネントのユニークな識別子で、Univer内で参照するために使用されます。
- `CustomComponent`:Reactコンポーネント、Vue コンポーネント、または Web コンポーネントであることができるコンポーネント自体。
- `options`: コンポーネントのフレームワークなどのオプション設定は、関連する構成に依存します。

### React コンポーネント [#react]

React コンポーネントは、追加の構成を必要としません。コンポーネントは、次の例のように、有効な Reactコンポーネントである必要があります。

```tsx
function ReactComponent(props: Record<string, any>) {
  return <div>Hello Univer!</div>
}

univerAPI.registerComponent('MyReactComponent', ReactComponent)
```

### Vue コンポーネント [#vue]

#### Vue 3.x

Vue コンポーネントでは、`@univerjs/ui-adapter-vue3` パッケージをインストールし、`UniverVue3AdapterPlugin`をそのまま登録します。

```package-install
npm install @univerjs/ui-adapter-vue3
```

```typescript
import { UniverVue3AdapterPlugin } from '@univerjs/ui-adapter-vue3'

univer.registerPlugin(UniverVue3AdapterPlugin)
```

`framework`を`'vue3'`に渡すと、コンポーネントを登録します。

```tsx
const Vue3Component = defineComponent({
  setup(props) {
    return () => <div>Hello Univer!</div>
  },
})

univerAPI.registerComponent('MyVue3Component', Vue3Component, {
  // [!code word:vue3]
  framework: 'vue3',
})
```

#### Vue 2.x

Vue 2.xは終生に達し、維持されなくなりました、従ってUniverは今それのためのUIのアダプターのプラグインを提供していません。アダプターは習慣のプラグインとして導入することができます。下のコードは開始ポイントとして役立つことができるVue 2.xのアダプターのプラグです:

```typescript title="ui-adapter-vue2.ts"
import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
import { ComponentManager, UniverUIPlugin } from '@univerjs/ui'
import Vue from 'vue'

/**
 * Univer が Vue 2 コンポーネントを UI コンポーネントとして使用できるようにするプラグイン。
 */
@DependentOn(UniverUIPlugin)
export class UniverVue2AdapterPlugin extends Plugin {
  static override pluginName = 'UNIVER_UI_VUE2_ADAPTER_PLUGIN'

  constructor(
    private readonly _config = {},
    @Inject(Injector) protected readonly _injector: Injector,
    @Inject(ComponentManager) protected readonly _componentManager: ComponentManager,
  ) {
    super()
  }

  override onStarting(): void {
    const { createElement, useEffect, useRef } = this._componentManager.reactUtils

    this._componentManager.setHandler('vue2', (component: any) => {
      return (props: Record<string, any>) =>
        createElement(VueComponentWrapper, {
          component,
          props: Object.keys(props).reduce<Record<string, any>>((acc, key) => {
            if (key !== 'key') {
              acc[key] = props[key]
            }
            return acc
          }, {}),
          reactUtils: { createElement, useEffect, useRef },
        })
    })
  }
}

export function VueComponentWrapper(options: {
  component: any
  props: Record<string, any>
  reactUtils: typeof ComponentManager.prototype.reactUtils
}) {
  const { component, props, reactUtils } = options
  const { createElement, useEffect, useRef } = reactUtils

  const domRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!domRef.current) return

    const Constructor = Vue.extend(component)

    const instance = new Constructor({
      data: props,
    })
    instance.$mount()

    domRef.current.appendChild(instance.$el)

    return () => {
      instance.$destroy()
    }
  }, [props])

  return createElement('div', { ref: domRef })
}
```

プラグインを登録します。

```typescript
import { UniverVue2AdapterPlugin } from './ui-adapter-vue2' // [!code ++]

univer.registerPlugin(UniverUIPlugin)
univer.registerPlugin(UniverVue2AdapterPlugin) // [!code ++]
```

Vue 2.xの部品は`framework`に`'vue2'`セットを必要とします:

```tsx
const Vue2Component = Vue.component('MyVue2Component', {
  template: '<div>Hello, Univer!</div>',
})

univerAPI.registerComponent('MyVue2Component', Vue2Component, {
  // [!code word:vue2]
  framework: 'vue2',
})
```

### Web Components [#web-component]

Web コンポーネントを登録するには、コンポーネントは Web コンポーネント規格に従う必要があります。`@univerjs/ui-adapter-web-component` パッケージをインストールし、`UniverWebComponentAdapterPlugin` を以下のように登録します。

```package-install
npm install @univerjs/ui-adapter-web-component
```

```typescript
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

univer.registerPlugin(UniverWebComponentAdapterPlugin)
```

`framework`を`'web-component'`として渡して下さい:

```tsx
class WebComponent extends HTMLElement {
  constructor() {
    super()
    const shadow = this.attachShadow({ mode: 'open' })
    const div = document.createElement('div')
    div.textContent = 'Hello Univer!'
    shadow.appendChild(div)
  }
}

univerAPI.registerComponent('my-web-component', WebComponent, {
  // [!code word:web-component]
  framework: 'web-component',
})
```

### Angular [#angular]

`@angular/elements`の`createCustomElement`は、Angularコンポーネントをカスタム要素に変換します。 要素がUniverのウェブサイトコンポーネントアダプタに登録されると、Angular成分はUniverサイドバーまたはダイアログに表示されます。

`@angular/core` と同じバージョンで `@angular/elements`、`@univerjs/ui-adapter-web-component`を他の Univer パッケージと同じバージョンで追加します。

Univer の初期化後にこの関数を呼び出します。Angular のインジェクタはホストコンポーネントによって供給されます。`private readonly injector = inject(Injector)` でそれを取得し、`registerAngularPanel(univer, univerAPI, this.injector)` を呼び出す。ホストコンポーネントは `inject` と `Injector` を `@angular/core` からインポートします。

```typescript title="angular-panel.ts"
import type { Injector } from '@angular/core'
import type { FUniver, Univer } from '@univerjs/presets'
import { Component } from '@angular/core'
import { createCustomElement } from '@angular/elements'
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

@Component({
  selector: 'app-angular-panel',
  standalone: true,
  template: '<p>Hello from Angular!</p>',
})
export class AngularPanelComponent {}

export function registerAngularPanel(univer: Univer, univerAPI: FUniver, injector: Injector) {
  const element = createCustomElement(AngularPanelComponent, { injector })

  univer.registerPlugin(UniverWebComponentAdapterPlugin)
  return univerAPI.registerComponent('univer-angular-panel', element, {
    framework: 'web-component',
  })
}
```

エディタがレンダリングされたら、登録キーをサイドバーのコンテンツに渡します。

```typescript
const sidebar = univerAPI.openSidebar({
  header: { title: 'Angular' },
  children: { label: 'univer-angular-panel' },
  width: 360,
})
```

登録ハンドルとサイドバーのハンドルを保持し、不要になったときにそれぞれに`dispose()`を呼び出します。 一度、アプリケーションごとに要素を登録します。 その名前にはハイフンが含まれており、Angularコンポーネントセレクターとは異なる必要があります。

Angular Elements は、要素のプロパティと出力を DOM `CustomEvent` イベントにマップします。 Univerのアダプターはプロパティを設定しますが、Angular出力を自分で購読していません。そのため、必要なときにアプリケーションはこれらのイベントをブリッジする必要があります。

## カスタムコンポーネントの使用

以下のメソッドは、Univer レンダーの場所にカスタムコンポーネントを配置し、UI を拡張しカスタマイズします。

<Callout type="warning" title="注意事項">

1. Univer がレンダリングを終えた後にのみこれらのメソッドを呼び出します。
2. 使用する前にコンポーネントを登録します。
3. `dispose()` を呼び出して、追加したものをクリーンアップし、メモリリークを回避します。

</Callout>

### カスタムメニューアイテムの追加

右クリックでリボンとコンテキストメニューは、ホストカスタムコンポーネントの両方が使用できます。メニュー項目はプラグインによって登録されるため、カスタムプラグインが必要です。 [カスタムメニュー項目のベストプラクティスガイド](/blog/custom-plugin)は開始点として利用できます。

### 組み込みコンポーネントの置き換え

<Callout type="error" title="インフォメーション">
  組み込みコンポーネントを置き換えると、それに依存する機能が壊れる可能性があります。 置換を試みる前にソースコードとドキュメントを読んで、注意を払ってください。
</Callout>

`univerAPI.registerComponent` は、デフォルトでオーバーライド (`override: true`) を登録します。オーバーライドは、プラグインがコールの前にまたは呼び出し後にデフォルトを登録するかどうかに関係なく、組み込みのコンポーネントを優先します。1つのオーバーライドはそれぞれ `componentKey` でアクティブにすることができますので、別の登録を行う前に、以前の登録を解除します。返された登録で `dispose()` を呼び出すと、組み込みのデフォルトが復元されます。代わりに、`{ override: false }` を使用してデフォルトを登録します。

最初にカバーするビューの前にオーバーライドを登録します。登録を変更すると、既にマウントされているビューは再レンダーしません。

スプレッドシートは、パブリックパッケージエントリから次のキーをエクスポートします。それらを使用して、一致する組み込みコンポーネントをオーバーライドします。

| コンポーネント | 公開キー | パッケージ |
| --- | --- | --- |
| 定義された名前 | `DEFINED_NAME_CONTAINER` | `@univerjs/sheets-ui` |
| その他の関数 | `MORE_FUNCTIONS_COMPONENT` | `@univerjs/sheets-formula-ui` |
| データの入力規則 | `DATA_VALIDATION_PANEL` | `@univerjs/sheets-data-validation-ui` |
| 条件付き書式 | `CF_PANEL_KEY` | `@univerjs/sheets-conditional-formatting-ui` |

例えば、次のコードは組み込みのColorPickerコンポーネントを置き換えます。

```tsx
// Following code only replaces the UI of the built-in ColorPicker component, not its functionality
univerAPI.registerComponent('UI_COLOR_PICKER_COMPONENT', () => <input type="color" />)
```

### コンテンツコンポーネントとしての使用

#### サイドバーで

`univerAPI.openSidebar`はUniver UIのサイドバーを開き、登録したコンポーネントをレンダーします。

```tsx
// [!code word:MyCustomSidebarComponent]
// 適切なタイミング（例：Univer が読み込まれた後）でコンポーネントを登録する必要があります
univerAPI.registerComponent('MyCustomSidebarComponent', () => <div>Hello Univer!</div>)

const sidebar = univerAPI.openSidebar({
  header: { title: 'My Sidebar' },
  children: { label: 'MyCustomSidebarComponent' },
  onClose: () => {
    console.log('close')
  },
  width: 360,
})

// 後でサイドバーを閉じる
sidebar.dispose()
```

参照：[`univerAPI.openSidebar`](/reference/facade/univer#opensidebar)

#### ダイアログで

`univerAPI.openDialog`はダイアログを開き、登録したコンポーネントを内部にレンダリングします。

```tsx
// [!code word:MyCustomDialogComponent]
// 適切なタイミング（例：Univer が読み込まれた後）でコンポーネントを登録する必要があります
univerAPI.registerComponent('MyCustomDialogComponent', () => <div>Hello Univer!</div>)

const dialog = univerAPI.openDialog({
  id: 'unique-dialog-id', // ダイアログの一意の識別子
  draggable: true,
  width: 300,
  title: { title: 'My Dialog' },
  children: {
    label: 'MyCustomDialogComponent',
  },
  destroyOnClose: true,
  preservePositionOnDestroy: true,
  onClose: () => {},
})

// 後でダイアログを閉じる
dialog.dispose()
```

参照：[`univerAPI.openDialog`](/reference/facade/univer#opendialog)

#### セルにポップアップを添付

`FRange.attachPopup`は特定のセル範囲に習慣のポップアップを付けます。

- ポップアップは、セルに付属する一時的な DOM 要素です。通常、一時的なステータス情報を表示し、永続ストレージをサポートしていません。
- メソッドのシグネチャは[`FRange.attachPopup(popup: IFCanvasPopup)`](https://docs.univer.ai/reference/facade/range#attachpopup)です。
- ポップアップは、セルのエッジに付着し、何かがそれを妨害するとき、その位置と方向を調整します。

```tsx
// [!code word:MyCustomPopupComponent]
// 適切なタイミング（例：Univer が読み込まれた後）でコンポーネントを登録する必要があります
univerAPI.registerComponent(
  'MyCustomPopupComponent',
  () => <div>Hello Univer!</div>,
)

const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:J10')

// 範囲の最初のセルにポップアップを添付
// `disposable` が null の場合、ポップアップが正常に追加されなかったことを示します
const disposable = fRange.attachPopup({
  componentKey: 'MyCustomPopupComponent',
})

// ポップアップを削除
disposable.dispose()
```

#### アラートポップアップを添付

`FRange.attachAlertPopup`は、特定の範囲の開始セルにアラートポップアップを添付します。

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

const disposable = fRange.attachAlertPopup({
  key: 'unique-alert-key', // 一意の識別子
  title: 'これは警告です！',
  message: 'これは警告です！',
  width: 300,
  height: 200,
  // 0: 情報
  // 1: 警告
  // 2: エラー
  type: 0,
})

// ポップアップを削除
disposable.dispose()
```

#### ワークシートにフローティングDOMを追加

`FWorksheet.addFloatDomToPosition`は、ワークシートに浮動小数点の DOM 要素を追加します。

- このメソッドを使用する前に、`@univerjs/sheets-drawing-ui`プラグインまたは`@univerjs/preset-sheets-drawing`プリセットをインストールします。
- DOM 要素をフローティングすることは、ワークシートを上回るドラッグ可能なコンポーネントであり、永続ストレージをサポートしています。
- Univerがレンダリングを終えた後にこのメソッドを呼び出します。
- `componentKey`: コンポーネントの固有の識別子で、Univer内で参照するために使用されます。
- [完全なパラメータ定義](https://github.com/dream-num/univer/blob/dev/packages/sheets-drawing-ui/src/facade/f-worksheet.ts#L32)

```tsx
// [!code word:MyCustomFloatDOMComponent]
// 適切なタイミング（例：Univer が読み込まれた後）でコンポーネントを登録する必要があります
univerAPI.registerComponent(
  'MyCustomFloatDOMComponent',
  ({ data }) => (
    <div>
      Hello
      {data?.label}
      !
    </div>
  ),
)
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// ワークシートにフローティング DOM を追加
// `disposable` が null の場合、フローティング DOM が正常に追加されなかったことを示します
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'MyCustomFloatDOMComponent',
  initPosition: {
    startX: 100,
    endX: 200,
    startY: 100,
    endY: 200,
  },

  // コンポーネントのデータ
  data: {
    label: 'Univer',
  },
})

// フローティング DOM を削除
disposable.dispose()
```
