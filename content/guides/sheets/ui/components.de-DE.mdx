Univer übergibt Komponenten nicht direkt als Parameter an Rendering-Funktionen. Sie müssen die Komponenten über die Facade-API bei Univer registrieren, bevor Sie sie an verschiedenen Montagepunkten verwenden können.

Wenn Sie nicht wissen, wie Sie eine Instanz der Facade-API erhalten, können Sie auf [Facade API](/guides/sheets/getting-started/facade).

#### Popup an Zellen anhängen

Mit der Methode `FRange.attachPopup` können Sie ein benutzerdefiniertes Popup an einen bestimmten Zellbereich anhängen.

- Ein Popup ist ein temporäres DOM-Element, das an eine Zelle angehängt ist, normalerweise zur Anzeige vorübergehender Statusinformationen verwendet wird und keine dauerhafte Speicherung unterstützt.
- Sie können die Methode [`FRange.attachPopup(popup: IFCanvasPopup)`](https://docs.univer.ai/reference/facade/range#attachpopup) verwenden, um ein benutzerdefiniertes Popup an einen bestimmten Zellbereich anzuhängen.
- Das Popup wird an den Rändern der Zelle angehängt und passt seine Position und Ausrichtung automatisch an, wenn blockiert.

```tsx
// [!code word:MyCustomPopupComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent(
  'MyCustomPopupComponent',
  () => <div>Hello Univer!</div>,
)

const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:J10')

// Attach the popup to the first cell of the range
// If `disposable` is null, it indicates that the popup was not added successfully
const disposable = fRange.attachPopup({
  componentKey: 'MyCustomPopupComponent',
})

// Remove the popup
disposable.dispose()
```

#### Alarm-Popup anhängen

Mit der Methode `FRange.attachAlertPopup` können Sie ein Alarm-Popup an die Startzelle eines angegebenen Bereichs anhängen.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

const disposable = fRange.attachAlertPopup({
  key: 'unique-alert-key', // Unique identifier
  title: '这是一个警告！',
  message: '这是一个警告！',
  width: 300,
  height: 200,
  // 0: Information
  // 1: Warning
  // 2: Error
  type: 0,
})

// Remove the alert later
disposable.dispose()
```

#### Floating-DOM zum Arbeitsblatt hinzufügen

Mit der Methode `FWorksheet.addFloatDomToPosition` können Sie dem Arbeitsblatt ein Floating-DOM hinzufügen.

- Bevor Sie diese Methode verwenden, müssen Sie Folgendes tun: um das Plugin `@univerjs/sheets-drawing-ui` oder die Voreinstellung `@univerjs/preset-sheets-drawing` zu installieren.
- Das schwebende DOM ist eine ziehbare Komponente, die über dem Arbeitsblatt schwebt und dauerhafte Speicherung unterstützt.
- Sie sollten diese Methode aufrufen, nachdem Univer das Rendern abgeschlossen hat.
- `componentKey`: Der eindeutige Bezeichner für die Komponente, mit dem darauf verwiesen wird Univer.
- [Vollständige Parameterdefinition](https://github.com/dream-num/univer/blob/dev/packages/sheets-drawing-ui/src/facade/f-worksheet.ts#L32)

```tsx
// [!code word:MyCustomFloatDOMComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent(
  'MyCustomFloatDOMComponent',
  ({ data }) => (
    <div>
      Hello
      {data?.label}
      !
    </div>
  ),
)
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Add a floating DOM to the worksheet
// If `disposable` is null, it indicates that the floating DOM was not added successfully
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'MyCustomFloatDOMComponent',
  initPosition: {
    startX: 100,
    endX: 200,
    startY: 100,
    endY: 200,
  },

  // The data for the component
  data: {
    label: 'Univer',
  },
})

// Remove the floating DOM
disposable.dispose()
```
