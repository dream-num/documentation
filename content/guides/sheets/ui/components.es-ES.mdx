Univer no acepta un componente como argumento a una llamada de renderizado. Un componente debe ser registrado a través de Facade API antes de que pueda ser referenciado dondequiera que Univer lo monte.

Si una instancia Facade API no está disponible todavía, consulte [Facade API](/guides/sheets/getting-started/facade).

## Registro de componentes personalizados

```typescript
// [!code word:componentKey]
// [!code word:CustomComponent]
// [!code word:options]
univerAPI.registerComponent(componentKey, CustomComponent, options)
```

`univerAPI.registerComponent` registra un componente y toma tres argumentos:

- `componentKey`: el identificador único del componente, utilizado para referenciarlo dentro de Univer.
- `CustomComponent`: el componente en sí, que puede ser un componente React, un componente Vue o un componente Web.
- `options`: Ajustes opcionales, como el marco del componente depende de u otra configuración relacionada.

### Componentes de React [#react]

Los componentes React no requieren ninguna configuración adicional. El componente sólo necesita ser un componente React válido, como en el ejemplo siguiente:

```tsx
function ReactComponent(props: Record<string, any>) {
  return <div>Hello Univer!</div>
}

univerAPI.registerComponent('MyReactComponent', ReactComponent)
```

### Componentes de Vue [#vue]

#### Vue 3.x

Para los componentes Vue, instale el paquete `@univerjs/ui-adapter-vue3` y registre `UniverVue3AdapterPlugin` de él:

```package-install
npm install @univerjs/ui-adapter-vue3
```

```typescript
import { UniverVue3AdapterPlugin } from '@univerjs/ui-adapter-vue3'

univer.registerPlugin(UniverVue3AdapterPlugin)
```

Pase `framework` como `'vue3'` cuando registre el componente:

```tsx
const Vue3Component = defineComponent({
  setup(props) {
    return () => <div>Hello Univer!</div>
  },
})

univerAPI.registerComponent('MyVue3Component', Vue3Component, {
  // [!code word:vue3]
  framework: 'vue3',
})
```

#### Vue 2.x

Vue 2.x ha llegado al final de la vida y ya no se mantiene, por lo que Univer no proporciona actualmente un plugin de adaptador UI para él. El adaptador puede ser implementado como un plugin personalizado. El código a continuación es un plugin de Adaptador Vue de 2.x que puede servir como punto de partida:

```typescript title="ui-adapter-vue2.ts"
import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
import { ComponentManager, UniverUIPlugin } from '@univerjs/ui'
import Vue from 'vue'

/**
 * The plugin that allows Univer to use Vue 2 components as UI components.
 */
@DependentOn(UniverUIPlugin)
export class UniverVue2AdapterPlugin extends Plugin {
  static override pluginName = 'UNIVER_UI_VUE2_ADAPTER_PLUGIN'

  constructor(
    private readonly _config = {},
    @Inject(Injector) protected readonly _injector: Injector,
    @Inject(ComponentManager) protected readonly _componentManager: ComponentManager,
  ) {
    super()
  }

  override onStarting(): void {
    const { createElement, useEffect, useRef } = this._componentManager.reactUtils

    this._componentManager.setHandler('vue2', (component: any) => {
      return (props: Record<string, any>) =>
        createElement(VueComponentWrapper, {
          component,
          props: Object.keys(props).reduce<Record<string, any>>((acc, key) => {
            if (key !== 'key') {
              acc[key] = props[key]
            }
            return acc
          }, {}),
          reactUtils: { createElement, useEffect, useRef },
        })
    })
  }
}

export function VueComponentWrapper(options: {
  component: any
  props: Record<string, any>
  reactUtils: typeof ComponentManager.prototype.reactUtils
}) {
  const { component, props, reactUtils } = options
  const { createElement, useEffect, useRef } = reactUtils

  const domRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!domRef.current) return

    const Constructor = Vue.extend(component)

    const instance = new Constructor({
      data: props,
    })
    instance.$mount()

    domRef.current.appendChild(instance.$el)

    return () => {
      instance.$destroy()
    }
  }, [props])

  return createElement('div', { ref: domRef })
}
```

Luego registre el plugin:

```typescript
import { UniverVue2AdapterPlugin } from './ui-adapter-vue2' // [!code ++]

univer.registerPlugin(UniverUIPlugin)
univer.registerPlugin(UniverVue2AdapterPlugin) // [!code ++]
```

Los componentes Vue 2.x necesitan `framework` fijado en `'vue2'`:

```tsx
const Vue2Component = Vue.component('MyVue2Component', {
  template: '<div>Hello, Univer!</div>',
})

univerAPI.registerComponent('MyVue2Component', Vue2Component, {
  // [!code word:vue2]
  framework: 'vue2',
})
```

### Componentes web [#web-component]

Para registrar componentes web, el componente debe seguir el estándar de componentes web. Instale el paquete `@univerjs/ui-adapter-web-component` y registre `UniverWebComponentAdapterPlugin` de él:

```package-install
npm install @univerjs/ui-adapter-web-component
```

```typescript
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

univer.registerPlugin(UniverWebComponentAdapterPlugin)
```

Pase `framework` como `'web-component'`:

```tsx
class WebComponent extends HTMLElement {
  constructor() {
    super()
    const shadow = this.attachShadow({ mode: 'open' })
    const div = document.createElement('div')
    div.textContent = 'Hello Univer!'
    shadow.appendChild(div)
  }
}

univerAPI.registerComponent('my-web-component', WebComponent, {
  // [!code word:web-component]
  framework: 'web-component',
})
```

### Angular [#angular]

`createCustomElement` de `@angular/elements` convierte un componente Angular en un elemento personalizado. Después de que el elemento está registrado con el adaptador Web Component de Univer, el componente Angular puede aparecer en una barra lateral de Univer o diálogo.

Añada `@angular/elements` a la misma versión que `@angular/core` y `@univerjs/ui-adapter-web-component` en la misma versión de sus otros paquetes Univer.

Llame a esta función después de la inicialización de Univer. El inyector de Angular es suministrado por el componente host: obtenerlo con `private readonly injector = inject(Injector)` y luego llamar a `registerAngularPanel(univer, univerAPI, this.injector)`. El componente host importa `inject` y `Injector` de `@angular/core`.

```typescript title="angular-panel.ts"
import type { Injector } from '@angular/core'
import type { FUniver, Univer } from '@univerjs/presets'
import { Component } from '@angular/core'
import { createCustomElement } from '@angular/elements'
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

@Component({
  selector: 'app-angular-panel',
  standalone: true,
  template: '<p>Hello from Angular!</p>',
})
export class AngularPanelComponent {}

export function registerAngularPanel(univer: Univer, univerAPI: FUniver, injector: Injector) {
  const element = createCustomElement(AngularPanelComponent, { injector })

  univer.registerPlugin(UniverWebComponentAdapterPlugin)
  return univerAPI.registerComponent('univer-angular-panel', element, {
    framework: 'web-component',
  })
}
```

Una vez que el editor haya dado vuelta, pase la clave registrada como el contenido de la barra lateral:

```typescript
const sidebar = univerAPI.openSidebar({
  header: { title: 'Angular' },
  children: { label: 'univer-angular-panel' },
  width: 360,
})
```

Retenga el mango de registro y el mango lateral, y llame a `dispose()` en cada uno cuando ya no sea necesario. Registre el elemento una vez por aplicación. Su nombre debe contener un hifeno y debe diferir del selector de componentes Angular.

Angular Elements mapas entradas a propiedades de elementos y salidas a eventos DOM `CustomEvent`. El adaptador de Univer establece las propiedades pero no se suscribe a las salidas Angular por su cuenta, por lo que la aplicación debe puentear esos eventos cuando se requieren.

## Usar componentes personalizados

Los métodos a continuación colocan componentes personalizados en los lugares Univer renders, que extiende y personaliza la interfaz de usuario.

<Callout type="warning" title="Caution">

1. Llame estos métodos sólo después de que Univer haya terminado de renderizar.
2. Registrar un componente antes de utilizarlo.
3. Llame a `dispose()` para limpiar lo que agregó y evitar las fugas de memoria.

</Callout>

### Agregar elementos de menú personalizados

La cinta en la parte superior y el Menú Contexto en el clic derecho pueden albergar componentes personalizados. Los elementos de menú están registrados por un plugin, por lo que añadir uno requiere un plugin personalizado. A [mejor guía de práctica para los elementos de menú personalizado](/blog/custom-plugin) está disponible como punto de partida.

### Reemplazo de componentes integrados

<Callout type="error" title="Advertencia">
  Reemplazar un componente incorporado puede romper características que dependen de él. Lea el código fuente y la documentación antes de intentar un reemplazo, y proceda con precaución.
</Callout>

`univerAPI.registerComponent` registra una anulación por defecto (`override: true`). La anulación tiene prioridad sobre el componente incorporado, independientemente de si el plugin registra su predeterminación antes o después de la llamada. Sólo una anulación puede ser activa para cada `componentKey`, así que descargue el registro anterior antes de registrar otro. Llamar `dispose()` en el registro devuelto restaura el predeterminado incorporado, si se registró uno. Use `{ override: false }` para registrar un predeterminado en lugar.

Registrar la anulación antes de la vista que cubre se abre por primera vez. Cambiar un registro no reenvia las vistas que ya están montadas.

Las hojas exportan las siguientes claves de sus entradas de paquetes públicos; utilízalas para anular los componentes integrados que coinciden:

| Componente | Clave exportada | Paquete |
| --- | --- | --- |
| Nombres definidos | `DEFINED_NAME_CONTAINER` | `@univerjs/sheets-ui` |
| Más funciones | `MORE_FUNCTIONS_COMPONENT` | `@univerjs/sheets-formula-ui` |
| Validación de datos | `DATA_VALIDATION_PANEL` | `@univerjs/sheets-data-validation-ui` |
| Formato condicional | `CF_PANEL_KEY` | `@univerjs/sheets-conditional-formatting-ui` |

Por ejemplo, el siguiente código reemplaza el componente ColorPicker incorporado:

```tsx
// Following code only replaces the UI of the built-in ColorPicker component, not its functionality
univerAPI.registerComponent('UI_COLOR_PICKER_COMPONENT', () => <input type="color" />)
```

### Usar como componentes de contenido

#### En la barra lateral

`univerAPI.openSidebar` abre una barra lateral dentro de la interfaz de usuario Univer y renderiza su componente registrado en ella.

```tsx
// [!code word:MyCustomSidebarComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomSidebarComponent', () => <div>Hello Univer!</div>)

const sidebar = univerAPI.openSidebar({
  header: { title: 'My Sidebar' },
  children: { label: 'MyCustomSidebarComponent' },
  onClose: () => {
    console.log('close')
  },
  width: 360,
})

// Later close the sidebar
sidebar.dispose()
```

Referencia: [`univerAPI.openSidebar`](/reference/facade/univer#opensidebar)

#### En un cuadro de diálogo

`univerAPI.openDialog` abre un diálogo y renderiza su componente registrado dentro de él.

```tsx
// [!code word:MyCustomDialogComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomDialogComponent', () => <div>Hello Univer!</div>)

const dialog = univerAPI.openDialog({
  id: 'unique-dialog-id', // The unique identifier for the dialog
  draggable: true,
  width: 300,
  title: { title: 'My Dialog' },
  children: {
    label: 'MyCustomDialogComponent',
  },
  destroyOnClose: true,
  preservePositionOnDestroy: true,
  onClose: () => {},
})

// Later close the dialog
dialog.dispose()
```

Referencia: [`univerAPI.openDialog`](/reference/facade/univer#opendialog)

#### Adjuntar ventana emergente a celdas

`FRange.attachPopup` adjunta un popup personalizado a un rango de celda específico.

- Un popup es un elemento DOM temporal adjunto a una célula. Normalmente muestra información de estado transitorio y no admite almacenamiento persistente.
- La firma del método es [`FRange.attachPopup(popup: IFCanvasPopup)`](https://docs.univer.ai/reference/facade/range#attachpopup).
- El popup se adhiere a los bordes de la célula y ajusta su posición y orientación cuando algo la obstruye.

```tsx
// [!code word:MyCustomPopupComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomPopupComponent', () => <div>Hello Univer!</div>)

const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:J10')

// Attach the popup to the first cell of the range
// If `disposable` is null, it indicates that the popup was not added successfully
const disposable = fRange.attachPopup({
  componentKey: 'MyCustomPopupComponent',
})

// Remove the popup
disposable.dispose()
```

#### Adjuntar ventana emergente de alerta

`FRange.attachAlertPopup` adjunta un popup de alerta a la célula de inicio de un rango específico.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

const disposable = fRange.attachAlertPopup({
  key: 'unique-alert-key', // Unique identifier
  title: '这是一个警告！',
  message: '这是一个警告！',
  width: 300,
  height: 200,
  // 0: Information
  // 1: Warning
  // 2: Error
  type: 0,
})

// Remove the alert later
disposable.dispose()
```

#### Agregar DOM flotante a la hoja de trabajo

`FWorksheet.addFloatDomToPosition` añade un elemento DOM flotante a la hoja de trabajo.

- Antes de utilizar este método, instale el plugin `@univerjs/sheets-drawing-ui` o el preset `@univerjs/preset-sheets-drawing`.
- Un elemento DOM flotante es un componente arrastrable que se agita sobre la hoja de trabajo y soporta el almacenamiento persistente.
- Llame a este método después de que Univer haya terminado de renderizar.
- `componentKey`: el identificador único para el componente, utilizado para referenciarlo dentro de Univer.
- [Parámetro completo definición](https://github.com/dream-num/univer/blob/dev/packages/sheets-drawing-ui/src/facade/f-worksheet.ts#L32)

```tsx
// [!code word:MyCustomFloatDOMComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomFloatDOMComponent', ({ data }) => (
  <div>
    Hello
    {data?.label}!
  </div>
))
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Add a floating DOM to the worksheet
// If `disposable` is null, it indicates that the floating DOM was not added successfully
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'MyCustomFloatDOMComponent',
  initPosition: {
    startX: 100,
    endX: 200,
    startY: 100,
    endY: 200,
  },

  // The data for the component
  data: {
    label: 'Univer',
  },
})

// Remove the floating DOM
disposable.dispose()
```
