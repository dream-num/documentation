Univer no pasa directamente componentes como parámetros a ninguna función de renderizado. Debe registrar los componentes con Univer a través de la API de Facade antes de poder usarlos en varios puntos de montaje.

Si no está familiarizado con cómo obtener una instancia de la API de Facade, puede consultar [Facade API](/guides/sheets/getting-started/facade).

#### Adjuntar ventana emergente a celdas

Utilizando el método `FRange.attachPopup`, puede adjuntar una ventana emergente personalizada a un rango de celdas específico.

- Una ventana emergente es un elemento DOM temporal adjunto a una celda, que generalmente se usa para mostrar información de estado transitorio y no admite almacenamiento persistente.
- Puede usar el método [`FRange.attachPopup(popup: IFCanvasPopup)`](https://docs.univer.ai/reference/facade/range#attachpopup) para adjuntar una ventana emergente personalizada a un rango de celdas específico.
- La ventana emergente se adjuntará a los bordes de la celda y ajustará automáticamente su posición y orientación si obstruido.

```tsx
// [!code word:MyCustomPopupComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent(
  'MyCustomPopupComponent',
  () => <div>Hello Univer!</div>,
)

const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:J10')

// Attach the popup to the first cell of the range
// If `disposable` is null, it indicates that the popup was not added successfully
const disposable = fRange.attachPopup({
  componentKey: 'MyCustomPopupComponent',
})

// Remove the popup
disposable.dispose()
```

#### Adjuntar ventana emergente de alerta

Usando el método `FRange.attachAlertPopup`, puede adjuntar una ventana emergente de alerta a la celda inicial de un rango específico.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

const disposable = fRange.attachAlertPopup({
  key: 'unique-alert-key', // Unique identifier
  title: '这是一个警告！',
  message: '这是一个警告！',
  width: 300,
  height: 200,
  // 0: Information
  // 1: Warning
  // 2: Error
  type: 0,
})

// Remove the alert later
disposable.dispose()
```

#### Agregar DOM flotante a la hoja de trabajo

Usando el método `FWorksheet.addFloatDomToPosition`, puede agregar un DOM flotante a la hoja de trabajo.

- Antes de usar este método, debe instalar el `@univerjs/sheets-drawing-ui` complemento o el ajuste preestablecido `@univerjs/preset-sheets-drawing`.
- El DOM flotante es un componente arrastrable que se desplaza sobre la hoja de trabajo y admite almacenamiento persistente.
- Debe llamar a este método después de que Univer haya terminado de renderizar.
- `componentKey`: el identificador único para el componente, utilizado para hacer referencia a él dentro de Univer.
- [Parámetro completo definición](https://github.com/dream-num/univer/blob/dev/packages/sheets-drawing-ui/src/facade/f-worksheet.ts#L32)

```tsx
// [!code word:MyCustomFloatDOMComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent(
  'MyCustomFloatDOMComponent',
  ({ data }) => (
    <div>
      Hello
      {data?.label}
      !
    </div>
  ),
)
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Add a floating DOM to the worksheet
// If `disposable` is null, it indicates that the floating DOM was not added successfully
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'MyCustomFloatDOMComponent',
  initPosition: {
    startX: 100,
    endX: 200,
    startY: 100,
    endY: 200,
  },

  // The data for the component
  data: {
    label: 'Univer',
  },
})

// Remove the floating DOM
disposable.dispose()
```
