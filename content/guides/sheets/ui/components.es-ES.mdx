Univer no pasa directamente componentes como parámetros a ninguna función de renderizado. Debe registrar los componentes con Univer a través de la API de Facade antes de poder usarlos en varios puntos de montaje.

Si no está familiarizado con cómo obtener una instancia de la API de Facade, puede consultar [API de Facade](/guides/sheets/getting-started/facade).


## Registro de componentes personalizados

```typescript
// [!code word:componentKey]
// [!code word:CustomComponent]
// [!code word:options]
univerAPI.registerComponent(componentKey, CustomComponent, options)
```

Utilice el método `univerAPI.registerComponent` para registrar componentes personalizados. Este método acepta tres parámetros:

- `componentKey`: un identificador único para el componente, usado para hacer referencia a él dentro de Univer.
- `CustomComponent`: la implementación del componente, que puede ser un componente React, Vue o Web.
- `options`: opciones de configuración opcionales que se pueden usar para especificar el marco del que depende el componente u otros relacionados settings.

### Componentes de React [#react]

Para registrar un componente de React, no se requiere configuración adicional; solo asegúrese de que el componente sea un componente de React válido. Aquí hay un ejemplo simple:

```tsx
function ReactComponent(props: Record<string, any>) {
  return <div>Hello Univer!</div>
}

univerAPI.registerComponent('MyReactComponent', ReactComponent)
```

### Componentes de Vue [#vue]

#### Vue 3.x

Si desea registrar componentes de Vue, asegúrese de instalar y registrar `UniverVue3AdapterPlugin` del paquete `@univerjs/ui-adapter-vue3`:

```package-install
npm install @univerjs/ui-adapter-vue3
```

```typescript
import { UniverVue3AdapterPlugin } from '@univerjs/ui-adapter-vue3'

univer.registerPlugin(UniverVue3AdapterPlugin)
```

Al registrar componentes de Vue, debe especificar la opción `framework` como `'vue3'`:

```tsx
const Vue3Component = defineComponent({
  setup(props) {
    return () => <div>Hello Univer!</div>
  },
})

univerAPI.registerComponent('MyVue3Component', Vue3Component, {
  // [!code word:vue3]
  framework: 'vue3',
})
```

#### Vue 2.x

Dado que Vue 2.x está en EOL (fin de vida útil) y ya no se mantiene, Univer actualmente no proporciona un complemento de adaptador de interfaz de usuario para Vue 2.x. Sin embargo, puede implementar un adaptador Vue 2.x creando un complemento personalizado. A continuación se muestra un ejemplo de cómo crear un complemento de adaptador Vue 2.x:

```typescript title="ui-adapter-vue2.ts"
import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
import { ComponentManager, UniverUIPlugin } from '@univerjs/ui'
import Vue from 'vue'

/**
 * The plugin that allows Univer to use Vue 2 components as UI components.
 */
@DependentOn(UniverUIPlugin)
export class UniverVue2AdapterPlugin extends Plugin {
  static override pluginName = 'UNIVER_UI_VUE2_ADAPTER_PLUGIN'

  constructor(
    private readonly _config = {},
    @Inject(Injector) protected readonly _injector: Injector,
    @Inject(ComponentManager) protected readonly _componentManager: ComponentManager,
  ) {
    super()
  }

  override onStarting(): void {
    const { createElement, useEffect, useRef } = this._componentManager.reactUtils

    this._componentManager.setHandler('vue2', (component: any) => {
      return (props: Record<string, any>) =>
        createElement(VueComponentWrapper, {
          component,
          props: Object.keys(props).reduce<Record<string, any>>((acc, key) => {
            if (key !== 'key') {
              acc[key] = props[key]
            }
            return acc
          }, {}),
          reactUtils: { createElement, useEffect, useRef },
        })
    })
  }
}

export function VueComponentWrapper(options: {
  component: any
  props: Record<string, any>
  reactUtils: typeof ComponentManager.prototype.reactUtils
}) {
  const { component, props, reactUtils } = options
  const { createElement, useEffect, useRef } = reactUtils

  const domRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!domRef.current) return

    const Constructor = Vue.extend(component)

    const instance = new Constructor({
      data: props,
    })
    instance.$mount()

    domRef.current.appendChild(instance.$el)

    return () => {
      instance.$destroy()
    }
  }, [props])

  return createElement('div', { ref: domRef })
}
```

Luego regístrelo:

```typescript
import { UniverVue2AdapterPlugin } from './ui-adapter-vue2' // [!code ++]

univer.registerPlugin(UniverUIPlugin)
univer.registerPlugin(UniverVue2AdapterPlugin) // [!code ++]
```

Al registrar componentes Vue 2.x, debe especificar la opción `framework` como `'vue2'`:

```tsx
const Vue2Component = Vue.component('MyVue2Component', {
  template: '<div>Hello, Univer!</div>',
})

univerAPI.registerComponent('MyVue2Component', Vue2Component, {
  // [!code word:vue2]
  framework: 'vue2',
})
```

### Componentes web [#web-component]

Si desea registrar componentes web, asegúrese de que el componente se adhiera a los componentes web estándar e instale y registre `UniverWebComponentAdapterPlugin` del paquete `@univerjs/ui-adapter-web-component`:

```package-install
npm install @univerjs/ui-adapter-web-component
```

```typescript
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

univer.registerPlugin(UniverWebComponentAdapterPlugin)
```

Al registrar componentes web, debe especificar la opción `framework` como `'web-component'`:

```tsx
class WebComponent extends HTMLElement {
  constructor() {
    super()
    const shadow = this.attachShadow({ mode: 'open' })
    const div = document.createElement('div')
    div.textContent = 'Hello Univer!'
    shadow.appendChild(div)
  }
}

univerAPI.registerComponent('my-web-component', WebComponent, {
  // [!code word:web-component]
  framework: 'web-component',
})
```

### Angular [#angular]

Convierte un componente Angular en un elemento personalizado con `createCustomElement` de `@angular/elements` y regístralo con el adaptador Web Component de Univer. Así podrás usarlo en una barra lateral o un diálogo.

Añade `@angular/elements` con la misma versión que `@angular/core`, y `@univerjs/ui-adapter-web-component` con la misma versión que los demás paquetes Univer.

Llama a esta función después de inicializar Univer. En el componente anfitrión, obtén el inyector con `private readonly injector = inject(Injector)` y llama a `registerAngularPanel(univer, univerAPI, this.injector)`. Importa `inject` e `Injector` desde `@angular/core` en ese componente.

```typescript title="angular-panel.ts"
import type { Injector } from '@angular/core'
import type { FUniver, Univer } from '@univerjs/presets'
import { Component } from '@angular/core'
import { createCustomElement } from '@angular/elements'
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

@Component({
  selector: 'app-angular-panel',
  standalone: true,
  template: '<p>Hello from Angular!</p>',
})
export class AngularPanelComponent {}

export function registerAngularPanel(univer: Univer, univerAPI: FUniver, injector: Injector) {
  const element = createCustomElement(AngularPanelComponent, { injector })

  univer.registerPlugin(UniverWebComponentAdapterPlugin)
  return univerAPI.registerComponent('univer-angular-panel', element, {
    framework: 'web-component',
  })
}
```

Cuando el editor se haya renderizado, usa la clave registrada como contenido de la barra lateral:

```typescript
const sidebar = univerAPI.openSidebar({
  header: { title: 'Angular' },
  children: { label: 'univer-angular-panel' },
  width: 360,
})
```

Conserva los identificadores de registro y de la barra lateral, y llama a sus métodos `dispose()` cuando ya no los necesites. Registra el elemento una sola vez por aplicación. Su nombre debe contener un guion y ser distinto del selector Angular.

Angular Elements convierte las entradas en propiedades y las salidas en eventos DOM `CustomEvent`. El adaptador de Univer transmite propiedades, pero no se suscribe automáticamente a las salidas Angular; conecta explícitamente los eventos necesarios.

## Usar componentes personalizados

Los siguientes métodos le permiten integrar de manera flexible varios componentes personalizados en Univer, mejorando y personalizando su funcionalidad.

<Callout type="warning" title="Caution">
  1. Asegúrese de que Univer haya completado el procesamiento antes de usar estos métodos. 2. Para los componentes que
  deben registrarse, asegúrese de que estén registrados correctamente antes de su uso. 3. Utilice el método `dispose()`
  para limpiar y eliminar componentes agregados para evitar pérdidas de memoria.
</Callout>

### Agregar elementos de menú personalizados

La barra de menú superior (cinta) y el menú contextual (menú contextual) pueden incluir componentes personalizados. Para agregar componentes personalizados a los elementos del menú, debe crear un complemento personalizado. Hemos preparado una [práctica recomendada para agregar elementos de menú personalizados](/blog/custom-plugin) para ayudarle a comenzar rápidamente.

### Reemplazo de componentes integrados

<Callout type="error" title="Warning">
  Reemplazar componentes integrados puede provocar que algunas funcionalidades no funcionen correctamente. Lea
  detenidamente el código fuente y la documentación antes de intentar reemplazar componentes y proceda con precaución.
</Callout>

`univerAPI.registerComponent` registra una sustitución de forma predeterminada (`override: true`). Tiene prioridad independientemente de cuándo registre el plugin su componente predeterminado. Solo puede haber una sustitución activa por `componentKey`; libere el registro anterior antes de añadir otra. El método `dispose()` del objeto devuelto restaura el componente predeterminado, si está registrado. Use `{ override: false }` para registrar un componente predeterminado.

Registre la sustitución antes de abrir la vista por primera vez. Cambiar el registro no vuelve a renderizar automáticamente las vistas ya montadas.

Las entradas públicas de los paquetes Sheets exportan estas claves para sustituir los componentes integrados correspondientes:

| Componente | Clave exportada | Paquete |
| --- | --- | --- |
| Nombres definidos | `DEFINED_NAME_CONTAINER` | `@univerjs/sheets-ui` |
| Más funciones | `MORE_FUNCTIONS_COMPONENT` | `@univerjs/sheets-formula-ui` |
| Validación de datos | `DATA_VALIDATION_PANEL` | `@univerjs/sheets-data-validation-ui` |
| Formato condicional | `CF_PANEL_KEY` | `@univerjs/sheets-conditional-formatting-ui` |

Por ejemplo, para simplemente reemplazar el componente ColorPicker integrado:

```tsx
// Following code only replaces the UI of the built-in ColorPicker component, not its functionality
univerAPI.registerComponent('UI_COLOR_PICKER_COMPONENT', () => <input type="color" />)
```

### Usar como componentes de contenido

#### En el Barra lateral

Usando el método `univerAPI.openSidebar`, puede abrir una barra lateral en la interfaz de Univer que contiene un componente personalizado.

```tsx
// [!code word:MyCustomSidebarComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomSidebarComponent', () => <div>Hello Univer!</div>)

const sidebar = univerAPI.openSidebar({
  header: { title: 'My Sidebar' },
  children: { label: 'MyCustomSidebarComponent' },
  onClose: () => {
    console.log('close')
  },
  width: 360,
})

// Later close the sidebar
sidebar.dispose()
```

Referencia: [`univerAPI.openSidebar`](/reference/facade/univer#opensidebar)

#### En un cuadro de diálogo

Usando el método `univerAPI.openDialog`, puede abrir un cuadro de diálogo que contiene un componente personalizado.

```tsx
// [!code word:MyCustomDialogComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomDialogComponent', () => <div>Hello Univer!</div>)

const dialog = univerAPI.openDialog({
  id: 'unique-dialog-id', // The unique identifier for the dialog
  draggable: true,
  width: 300,
  title: { title: 'My Dialog' },
  children: {
    label: 'MyCustomDialogComponent',
  },
  destroyOnClose: true,
  preservePositionOnDestroy: true,
  onClose: () => {},
})

// Later close the dialog
dialog.dispose()
```

Referencia: [`univerAPI.openDialog`](/reference/facade/univer#opendialog)


#### Adjuntar ventana emergente a celdas

Utilizando el método `FRange.attachPopup`, puede adjuntar una ventana emergente personalizada a un rango de celdas específico.

- Una ventana emergente es un elemento DOM temporal adjunto a una celda, que generalmente se usa para mostrar información de estado transitorio y no admite almacenamiento persistente.
- Puede usar el método [`FRange.attachPopup(popup: IFCanvasPopup)`](https://docs.univer.ai/reference/facade/range#attachpopup) para adjuntar una ventana emergente personalizada a un rango de celdas específico.
- La ventana emergente se adjuntará a los bordes de la celda y ajustará automáticamente su posición y orientación si obstruido.

```tsx
// [!code word:MyCustomPopupComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomPopupComponent', () => <div>Hello Univer!</div>)

const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:J10')

// Attach the popup to the first cell of the range
// If `disposable` is null, it indicates that the popup was not added successfully
const disposable = fRange.attachPopup({
  componentKey: 'MyCustomPopupComponent',
})

// Remove the popup
disposable.dispose()
```

#### Adjuntar ventana emergente de alerta

Usando el método `FRange.attachAlertPopup`, puede adjuntar una ventana emergente de alerta a la celda inicial de un rango específico.

```typescript
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const fRange = fWorksheet.getRange('A1:B2')

const disposable = fRange.attachAlertPopup({
  key: 'unique-alert-key', // Unique identifier
  title: '这是一个警告！',
  message: '这是一个警告！',
  width: 300,
  height: 200,
  // 0: Information
  // 1: Warning
  // 2: Error
  type: 0,
})

// Remove the alert later
disposable.dispose()
```

#### Agregar DOM flotante a la hoja de trabajo

Usando el método `FWorksheet.addFloatDomToPosition`, puede agregar un DOM flotante a la hoja de trabajo.

- Antes de usar este método, debe instalar el `@univerjs/sheets-drawing-ui` complemento o el ajuste preestablecido `@univerjs/preset-sheets-drawing`.
- El DOM flotante es un componente arrastrable que se desplaza sobre la hoja de trabajo y admite almacenamiento persistente.
- Debe llamar a este método después de que Univer haya terminado de renderizar.
- `componentKey`: el identificador único para el componente, utilizado para hacer referencia a él dentro de Univer.
- [Parámetro completo definición](https://github.com/dream-num/univer/blob/dev/packages/sheets-drawing-ui/src/facade/f-worksheet.ts#L32)

```tsx
// [!code word:MyCustomFloatDOMComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomFloatDOMComponent', ({ data }) => (
  <div>
    Hello
    {data?.label}!
  </div>
))
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()

// Add a floating DOM to the worksheet
// If `disposable` is null, it indicates that the floating DOM was not added successfully
const disposable = fWorksheet.addFloatDomToPosition({
  componentKey: 'MyCustomFloatDOMComponent',
  initPosition: {
    startX: 100,
    endX: 200,
    startY: 100,
    endY: 200,
  },

  // The data for the component
  data: {
    label: 'Univer',
  },
})

// Remove the floating DOM
disposable.dispose()
```

## Extensión de menús: integración de aplicaciones y desarrollo de plugins [#menu-extension-paths]

Elige según la tarea. Ambas rutas usan el mismo sistema de menús; Facade encapsula las operaciones de la aplicación.

| Tarea | Punto de entrada | Ejemplo |
| --- | --- | --- |
| Añadir botones de negocio y submenús | `createMenu()` / `createSubmenu()` / `appendTo()` | [Ejemplo de aplicación](#nested-toolbar-menu) |
| Mostrar, ocultar o desactivar elementos | Configuración inicial `menu` / `updateMenuConfig()` | [Configuración en ejecución](#menu-runtime-configuration) |
| Desarrollar un plugin SDK con menús, comandos e iconos propios | Ciclo de vida `Plugin` / Schema de menú / servicios de extensión inyectados | [Ejemplo de plugin](#plugin-menu-example) |

La instalación de la aplicación en **modo plugin** también permite usar Facade API. Un plugin SDK propio registra extensiones mediante inyección de dependencias y ciclo de vida: `IMenuManagerService` gestiona el Schema de menús, `ICommandService` los comandos e `IconManager` los iconos.

## Integración de aplicaciones: menús Vue y acciones de negocio [#nested-toolbar-menu]

Añade un acceso en la barra de herramientas y un menú contextual anidado con Facade API. Ambos ejecutan la misma acción: escribir `Approved` en A1.

[Ejecutar el ejemplo completo](#vue-menu-example)

Completa primero la [integración Vue](/guides/sheets/getting-started/integrations/vue). El proyecto usa **Univer 1.3.0**; alinea las versiones de los paquetes Univer. El icono `ProtectIcon` está integrado.

Guarda este código en `review-menu.ts` y llámalo una vez después de inicializar, antes de crear el libro.

```typescript
import type { FUniver } from '@univerjs/core/facade'
import '@univerjs/sheets/facade'
import '@univerjs/ui/facade'

export function registerReviewMenus(univerAPI: FUniver) {
  const approve = () => {
    const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
    if (!sheet) return
    sheet.getRange('A1').setValue('Approved')
  }

  univerAPI.createMenu({
    id: 'review.quick-approve',
    title: 'Quick approve',
    icon: 'ProtectIcon',
    action: approve,
  }).appendTo('ribbon.start.others')

  const approveItem = univerAPI.createMenu({
    id: 'review.approve',
    title: 'Approve',
    icon: 'ProtectIcon',
    action: approve,
  })

  const actions = univerAPI.createSubmenu({
    id: 'review.actions',
    title: 'Actions',
  }).addSubmenu(approveItem)

  univerAPI.createSubmenu({
    id: 'review.root',
    title: 'Review',
  }).addSubmenu(actions)
    .appendTo(['contextMenu.mainArea', 'contextMenu.others'])
}
```

```typescript
import { registerReviewMenus } from './review-menu'

registerReviewMenus(univerAPI)
```

El acceso superior es **Start → Quick approve**. Haz clic derecho en una celda para **Review → Actions → Approve**. El menú anidado de este ejemplo es contextual. Consulta [FMenu](/reference/facade/menu) y [FSubmenu](/reference/facade/submenu).

Descarga y descomprime el proyecto Vue completo:


## Desarrollo de plugins: registrar comando, icono y menú [#plugin-menu-example]

[Ejecutar el ejemplo completo](#vue-menu-example)

Usa el mecanismo de plugins para una extensión con registro y ciclo de vida propios. Este ejemplo sigue el [controlador Sheets UI](https://github.com/dream-num/univer/blob/dev/packages/sheets-ui/src/controllers/ui.controller.ts) y el [registro de iconos](https://github.com/dream-num/univer/blob/dev/packages/ui/src/controllers/components.controller.ts) con `IconManager`. Guarda el código en `review-plugin.ts`.

```typescript
import { CommandType, DependentOn, ICommandService, Inject, Injector, Plugin, UniverInstanceType } from '@univerjs/core'
import { UniverSheetsUIPlugin } from '@univerjs/sheets-ui'
import { IconManager, IMenuManagerService, MenuItemType, RibbonStartGroup } from '@univerjs/ui'
import { createElement } from 'react'

const APPROVE_COMMAND_ID = 'review-plugin.command.approve'
const APPROVE_MENU_ID = 'review-plugin.menu.approve'
const APPROVE_ICON_ID = 'review-plugin.icon.approve'

function ReviewIcon() {
  return createElement('svg', {
    viewBox: '0 0 24 24', width: 16, height: 16,
    fill: 'none', stroke: 'currentColor', strokeWidth: 2,
    'aria-hidden': true, 'data-review-plugin-icon': true,
  }, createElement('path', { d: 'M5 12l4 4L19 6' }))
}

@DependentOn(UniverSheetsUIPlugin)
export class ReviewPlugin extends Plugin {
  static override pluginName = 'REVIEW_PLUGIN'
  static override type = UniverInstanceType.UNIVER_SHEET

  constructor(
    private readonly _config: { approve: () => boolean },
    @Inject(Injector) protected override _injector: Injector,
    @ICommandService private readonly _commands: ICommandService,
    @IMenuManagerService private readonly _menus: IMenuManagerService,
    @Inject(IconManager) private readonly _icons: IconManager,
  ) { super() }

  override onStarting() {
    this.disposeWithMe(this._commands.registerCommand({
      id: APPROVE_COMMAND_ID,
      type: CommandType.COMMAND,
      handler: () => this._config.approve(),
    }))
    this.disposeWithMe(this._icons.register(APPROVE_ICON_ID, ReviewIcon))
    this._menus.mergeMenu({
      [RibbonStartGroup.OTHERS]: {
        [APPROVE_MENU_ID]: {
          order: 0,
          menuItemFactory: () => ({
            id: APPROVE_MENU_ID,
            commandId: APPROVE_COMMAND_ID,
            type: MenuItemType.BUTTON,
            title: 'Plugin approve',
            icon: APPROVE_ICON_ID,
          }),
        },
      },
    })
  }
}
```

Registra `ReviewPlugin` después de inicializar el preset, antes de crear el libro. Depende de `UniverSheetsUIPlugin`; el proyecto completo incluye la misma versión de `@univerjs/sheets-ui`. El menú ejecuta su propio comando y modifica los datos mediante Facade.

```typescript
import { ReviewPlugin } from './review-plugin'

univer.registerPlugin(ReviewPlugin, {
  approve: () => {
    const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
    if (!sheet) return false
    sheet.getRange('A1').setValue('Approved by plugin')
    return true
  },
})
```

En el mismo proyecto, selecciona **SDK Plugin** o abre `/?example=plugin`. Aparece la marca personalizada de **Plugin approve**; al pulsar, A1 pasa de `Draft` a `Approved by plugin`. Deshacer restaura `Draft`. `disposeWithMe()` gestiona los registros de comandos e iconos; el Schema del menú comparte la vida del editor.

## Configuración en ejecución: ID de elemento e ID de comando [#menu-runtime-configuration]

El ID del elemento es `review-plugin.menu.approve` y el de su comando `review-plugin.command.approve`. Configura el **ID del elemento de menú** para modificar su estado de interfaz.

Marca y desmarca **Disable toolbar button** para desactivar y activar el botón. Haz lo mismo con **Hide toolbar button** para ocultarlo y restaurarlo. Estos controles del host llaman a `updateMenuConfig()`; la desactivación corresponde a:

```typescript
univerAPI.updateMenuConfig({
  'review-plugin.menu.approve': { disabled: true },
})
```

Usa `disabled: false` para activar y `hidden: true` / `false` para ocultar o restaurar. En el ejemplo de aplicación, los controles solo afectan al botón de la barra, no a la acción contextual independiente.
