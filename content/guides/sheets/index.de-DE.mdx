## Was ist Univer Sheets

Univer ist ein Full-Stack-Framework zum Erstellen von Produktivitätsanwendungen, und Univer Sheets ist die Tabellenkalkulationskomponente von Univer.

Univer Sheets kann sowohl im Browser als auch auf dem Server (Node.js) ausgeführt werden. Es ist äußerst flexibel, erweiterbar und anpassbar und ermöglicht Ihnen die Erstellung einer breiten Palette von Anwendungen, von einfachen Taschenrechnern bis hin zu komplexen Finanzmodellen auf Unternehmensebene. Egal, ob Sie ein einzelner Entwickler oder Teil eines Teams sind, Univer Sheets kann Ihnen dabei helfen, schnell und einfach leistungsstarke Tabellenkalkulationsanwendungen zu erstellen.

## Highlights

Univer Sheets unterstützt jetzt eine breite Palette von Funktionen, darunter:

- **Grundlegende Tabellenkalkulationsfunktionen**: Zellen erstellen, bearbeiten und löschen, Zeilen und Spalten.
- **Formeln**: Berechnen Sie Werte in Zellen mithilfe von Formeln.
- **Zahlenformatierung**
- **Datenvalidierung und bedingte Formatierung**
- **Filtern und Sortieren**
- **Berechtigungskontrolle**
- **Bilder**
- und mehr...

Weitere Einzelheiten finden Sie auf den Seiten im Abschnitt [Funktionen](/guides/sheets/features/core). Die Kern- und Hauptfunktionen sind Open-Source auf [GitHub](https://github.com/dream-num/univer) und können kostenlos verwendet werden.

## So lesen Sie die Dokumentation

Auf der linken Seite des Bildschirms finden Sie die Navigationsleiste für Dokumente. Die Seiten der Dokumente sind der Reihe nach organisiert, von „einfach“ bis „erweitert“, sodass Sie ihnen beim Erstellen Ihrer Anwendung Schritt für Schritt folgen können. Sie können sie jedoch in beliebiger Reihenfolge lesen oder zu den Seiten springen, die für Ihren Anwendungsfall gelten. Sie können sich Univer Sheets auch oben in der Seitenleiste ansehen.

Auf der rechten Seite des Bildschirms sehen Sie ein Inhaltsverzeichnis, das die Navigation zwischen den Abschnitten einer Seite erleichtert. Wenn Sie eine Seite schnell finden müssen, können Sie die Suchleiste oben oder die Suchverknüpfung (Strg+K oder Befehlstaste+K) verwenden.

Um zu beginnen, schauen Sie sich den Leitfaden [Schnellstart](/guides/sheets/getting-started/quickstart) an.

## Erforderliche Kenntnisse

Obwohl unsere Dokumente anfängerfreundlich gestaltet sind, müssen wir eine Grundlage schaffen, damit die Dokumente bestehen bleiben können konzentriert sich auf Univer.

Um das Beste aus unseren Dokumenten herauszuholen, wird empfohlen, dass Sie über grundlegende Kenntnisse von JavaScript und seinem Ökosystem verfügen.

Wenn Sie daran interessiert sind, Univer auf Node.js auszuführen, sollten Sie auch über grundlegende Kenntnisse von Node.js verfügen.

Wenn Sie Univer Pro ausprobieren und Univer Server bereitstellen möchten, empfehlen wir Ihnen, über grundlegende Kenntnisse von Linux, Docker und Docker Compose (bzw Kubernetes).

## Univer Sheets erweitern

Univer ist so konzipiert, dass es hochgradig erweiterbar ist, sodass Sie es an Ihre Bedürfnisse anpassen können. Wir empfehlen, den Abschnitt [Architektur](/guides/recipes/architecture/univer) zu lesen, um die Struktur von Univer Sheets und deren Erweiterung zu verstehen. Sie können auch mit [So schreiben Sie ein CSV-Import-Plugin](/guides/recipes/practices/csv-import-plugin) beginnen.
