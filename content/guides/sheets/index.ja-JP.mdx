## Univer Sheets は何ですか

Univer Office SDKは、生産性アプリケーションの構築のためのフルスタックフレームワークです。 Univerシートは、Web SDKに構築されたスプレッドシートコンポーネントです。

[Web SDK](/guides/sheets)は、スプレッドシートがページ内に埋め込まれているか、サーバー上でヘッドレスに処理されるかにかかわらず、Univerシートを実行するエンジンです。 コラボレーションとファイル変換用の[Server SDK](/server)を追加し、エージェントがワークブックを読み書きする必要があるときに[AI SDK](/ai)を追加します。

Univerシートは、ブラウザとNode.jsサーバーで動作します。同じコンポーネントは、小さな計算機と企業金融モデルの両方を提供し、その外観と行動は、アプリケーションに適応することができます。

## ブラウザ互換性

Web SDKはChrome 88とコンパイルします。これはビルドターゲットです。すべての主流環境が動作する保証はありません。Web SDKを以下のブラウザとNode.jsで動作させ続けることを目指しています。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDKは`Intl.Segmenter`に依存します。ブラウザやランタイムが提供されていない場合は、対応するポリフィルを最初に追加します。 `@formatjs/intl-segmenter`をお勧めします。
</Callout>

互換性の問題が発生した場合は、まず対応するポリフィルを試してみてください。問題が主張している場合は、[課題を提出する](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 互換性

<Callout type="warning">
  このセクションでは、Node.js 内部でWeb SDKを実行しています。 Node.jsベースのビルドツールは、ブラウザ用のWeb SDKをバンドルしたときには適用されません。
</Callout>

Web SDKはNode.js v18.17.0以降で動作します。

## 主な機能

Univerシートは、次のようなほとんどのアプリケーションのニーズをカバーしています。

- セル、行、列の作成、編集、削除。
- 数式でセル内の値を計算する。
- 数値フォーマットの設定
- データの検証と条件付き書式の適用
- フィルタリングとソート。
- 権限の制御。
- 画像をインサートする。
- 追加機能。

[おすすめ商品](/guides/sheets/features/core)のページでは、これらの機能を詳細に説明しています。

## ドキュメントの使い方

左のnavbarは、基本的なから上級まで、読書の順番でドキュメントをリストします。 その順序が必須ではありません。 先にスキップするか、使用例に適用するページに直接移動することができます。 Univerシートのスイッチャーは、サイドバーの上部にあります。

右上のコンテンツの表は、ページ内の現在の位置を追跡します。ページをすばやく見つけるには、検索バーをトップまたは検索ショートカット(Ctrl + KまたはCmd + K)で使用してください。

[クイックスタート](/guides/sheets/getting-started/installation)から始めましょう。

## 前提知識

文書は、現代のJavaScriptとその生態系に精通していると仮定しています。Node.jsでWeb SDKを実行してもNode.jsの知識が必要です。

ブラウザで完全に動作するサービスは、バックエンドサービスを必要としません。[Univer Server SDK](/server)から必要なモジュールを独自のバックエンドに構成することで、コラボレーション、共有履歴、コメント、およびファイル変換を追加してください。認証、許可、ストレージ、およびデプロイメントは、アプリケーションの責任を保ちます。

## Univer Sheets の拡張

Web SDKは、構成だけでなく、拡張用に設計されています。 [建築設計](/blog/univer) は、Univerシートとその拡張ポイントの構造を説明しています。 完全な例については、[CSV インポート プラグインを書く方法](/blog/csv-import-plugin)を参照してください。
