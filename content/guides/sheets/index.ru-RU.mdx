## Что такое Univer Sheets

Univer Office SDK - это полнотекстовый фреймворк для создания приложений производительности. Univer Sheets - это компонент электронной таблицы, построенный на Web SDK.

[Web SDK](/guides/sheets) - это движок, который запускает Univer Sheets, независимо от того, встроена ли электронная таблица в страницу или обрабатывается без головы на сервере. Добавьте [Server SDK](/server) для совместной работы и преобразования файлов и [AI SDK](/ai), когда агенту нужно читать и писать рабочие книги.

Univer Sheets работает в браузере и на сервере Node.js.Один и тот же компонент обслуживает как небольшой калькулятор, так и корпоративную финансовую модель, а его внешний вид и поведение могут быть адаптированы к приложению.

## Совместимость с браузерами

Web SDK компилируется против Chrome 88. Это цель сборки; это не гарантирует, что все основные среды работают. Мы стремимся сохранить Web SDK в браузерах ниже и на Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK зависит от `Intl.Segmenter`. Если браузер или среда выполнения его не предоставляет, сначала добавьте соответствующий полифилл. Рекомендуем `@formatjs/intl-segmenter` .
</Callout>

Если возникает проблема совместимости, сначала попробуйте соответствующий полифиль. Если проблема сохраняется, [Представить вопрос](https://github.com/dream-num/univer/issues/new/choose).

## Совместимость с Node.js

<Callout type="warning">
  Этот раздел охватывает запуск Web SDK внутри Node.js. Он не применяется, когда инструменты сборки на основе Node.js объединяют Web SDK для браузера.
</Callout>

Web SDK работает на Node.js v18.17.0 и более поздней версии.

## Основные возможности

Univer Sheets охватывает функции, необходимые большинству приложений, включая:

- Создание, редактирование и удаление ячеек, строк и столбцов.
- Вычисление значений в клетках с формулами.
- Настройка форматов номеров.
- Проверка данных и применение условного форматирования.
- Фильтрация и сортировка.
- Контроль разрешений.
- Вставка изображений.
- Дополнительные характеристики.

Страницы [Особенности](/guides/sheets/features/core) подробно описывают эти функции.

## Как читать документацию

Навбар слева перечисляет документацию в порядке чтения, от базового до расширенного. Следовать этому порядку не требуется: можно пропустить вперед или перейти прямо на страницы, которые относятся к вашему варианту использования. Переключатель листов Univer находится в верхней части боковой панели.

Таблица содержимого на правой дорожке отслеживает текущую позицию на странице.Чтобы быстро найти страницу, используйте строку поиска вверху или ярлык поиска (Ctrl+K или Cmd+K).

Начните с [Быстрый старт](/guides/sheets/getting-started/installation).

## Необходимые знания

Документация предполагает знакомство с современным JavaScript и его экосистемой.Запуск Web SDK на Node.js также требует знания Node.js.

Работа полностью в браузере не нуждается в бэкэнд-сервисах. Добавьте совместную работу, общую историю или комментарии и преобразование файлов, составляя необходимые модули из [Univer Server SDK](/server) в вашем собственном бэкэнде. Аутентификация, разрешения, хранение и развертывание остаются ответственностью приложения.
