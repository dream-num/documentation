## What is Univer Sheets

Univer Office SDK is a full-stack framework for building productivity applications. Univer Sheets is its spreadsheet component, built on Web SDK.

[Web SDK](/guides/sheets) is the engine that runs Univer Sheets, whether the spreadsheet is embedded in a page or processed headlessly on a server. Add [Server SDK](/server) for collaboration and file conversion, and [AI SDK](/ai) when an agent needs to read and write workbooks.

Univer Sheets runs in the browser and on a Node.js server. The same component serves both a small calculator and an enterprise financial model, and its appearance and behavior can be adapted to the application.

## Browser compatibility

Web SDK compiles against Chrome 88. This is the build target; it does not guarantee that every mainstream environment works. We aim to keep Web SDK working in the browsers below and on Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK depends on `Intl.Segmenter`. If the browser or runtime does not provide it, add the corresponding polyfill first. We recommend `@formatjs/intl-segmenter`.
</Callout>

If a compatibility problem occurs, first try the corresponding polyfill. If the problem persists, [submit an issue](https://github.com/dream-num/univer/issues/new/choose).

## Node.js compatibility

<Callout type="warning">
  This section covers running Web SDK inside Node.js. It does not apply when Node.js-based build tools bundle Web SDK for the browser.
</Callout>

Web SDK runs on Node.js v18.17.0 and later.

## Highlights

Univer Sheets covers the features most applications need, including:

- Creating, editing, and deleting cells, rows, and columns.
- Calculating values in cells with formulas.
- Setting number formats.
- Validating data and applying conditional formatting.
- Filtering and sorting.
- Controlling permissions.
- Inserting images.
- Additional features.

The [Features](/guides/sheets/features/core) pages describe these features in detail.

## Pre-requisite knowledge

The documentation assumes familiarity with modern JavaScript and its ecosystem. Running Web SDK on Node.js also requires knowledge of Node.js.

Working entirely in the browser needs no backend services. Add collaboration, shared history or comments, and file conversion by composing the required modules from [Univer Server SDK](/server) in your own backend. Authentication, permissions, storage, and deployment remain the responsibility of the application.

## Extend Univer Sheets

Web SDK is designed for extension, not only for configuration. [Architecture](/blog/univer) explains the structure of Univer Sheets and its extension points. For a complete example, see [How to Write a CSV Import Plugin](/blog/csv-import-plugin).
