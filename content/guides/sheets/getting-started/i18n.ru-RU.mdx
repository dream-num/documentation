## Регистрация языковых пакетов в режиме пресетов

В пакеты пресетов уже включены языковые пакеты соответствующих плагинов — их нужно только импортировать из пресета.

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US' // [!code highlight]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS, // [!code highlight]
    ),
  },
  presets: [UniverSheetsCorePreset()],
})
```

## Регистрация языковых пакетов в режиме плагинов

Чтобы зарегистрировать языковые пакеты в режиме плагинов, импортируйте нужные пакеты из предоставляющих их плагинов, объедините в один объект и передайте его экземпляру `Univer`. Пример:

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import DesignEnUS from '@univerjs/design/locale/en-US' // [!code highlight]
import SheetsUIEnUS from '@univerjs/sheets-ui/locale/en-US' // [!code highlight]
import UIEnUS from '@univerjs/ui/locale/en-US' // [!code highlight]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DesignEnUS, // [!code highlight]
      UIEnUS, // [!code highlight]
      SheetsUIEnUS, // [!code highlight]
    ),
  },
})
```


<Callout type="warning" title="Внимание">
  Языковые пакеты доступны не для всех плагинов. Информация об их наличии приводится в документации каждой функции.
</Callout>

## Метод `mergeLocales` [#mergeLocales]

Метод `mergeLocales` объединяет языковые пакеты нескольких плагинов или пресетов в единый объект языкового пакета. Использовать его можно следующим образом:

<Tabs items={['Режим пресетов', 'Режим плагинов']}>
  <Tab>
    ```typescript
    import { mergeLocales } from '@univerjs/presets'

    // You can pass multiple language pack objects to merge
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // You can also pass an array of language pack objects
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    ])
    ```
  </Tab>
  <Tab>
    ```typescript
    import { mergeLocales } from '@univerjs/core'

    // You can pass multiple language pack objects to merge
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // You can also pass an array of language pack objects
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    ])
    ```
  </Tab>
</Tabs>

## Пользовательские языковые пакеты

Univer также поддерживает пользовательские языковые пакеты. Вы можете сформировать объект языкового пакета в соответствии со своими требованиями и передать его экземпляру `Univer`. Языковые пакеты пресетов обычно находятся в каталоге `<rootDir>/packages/<PLUGIN_NAME>/locale`.

```typescript
const univer = new Univer({
  locale: 'ja-JP',
  locales: {
    'ja-JP': {
      ui: {
        shortcut: {
          undo: '元に戻す',
          redo: 'やり直す',
        },
      },
    },
  },
})
```
