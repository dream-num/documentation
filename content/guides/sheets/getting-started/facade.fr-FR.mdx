L'architecture de Univer doit répondre à des exigences complexes, et l'API de base reflète cette complexité. Univer fournit donc également le Facade API, une couche plus simple que le code d'application appelle directement.

Cette page décrit comment ajouter le Facade API à une application. Les pages de la section Caractéristiques énumèrent les API principales de Facade pour chaque fonctionnalité; pour l'ensemble complet, voir la référence API de chaque plugin.

<Callout type="warning" title="Attention">
  Certaines API Facade sont asynchrones, et celles qui modifient les données renvoient souvent une Promise. Lorsque les données sont lues immédiatement après qu'elles ont été modifiées, `await` l'appel ou la chaîne `.then()`; sinon les résultats peuvent être inattendus. Pour déterminer si une API renvoie une Promise, consultez la référence API correspondante.
</Callout>

## Intégrer la Facade API en mode plug-in

### Installation

En mode plugin, chaque plugin expédie sa propre implémentation Facade API, et tous s'attachent à un objet global Facade API. Pour chaque plugin qui fournit un Facade API importer l'implémentation correspondante au besoin.

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs/ui/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="Attention">
  Chaque plugin n'inclut pas un paquet de façade. Chaque page de fonctionnalités indique si elle le fait.
</Callout>

### Utilisation

Le Facade API enveloppe une instance Univer. Créez d'abord l'instance, puis enveloppez-la avec `FUniver`:

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Intégration de Facade API en mode préréglage

En mode préréglé, les préréglages importent le Facade API pour les fonctionnalités qu'ils contiennent. Créer une instance Univer renvoie une instance correspondante `univerAPI`, qui peut être utilisée immédiatement.

## Points d’attention

Chaque Facade API ne peut pas être appelé immédiatement. Certains ne prennent effet qu'à un stade spécifique du cycle de vie. Lorsqu'un appel immédiat ne prend pas effet, sélectionnez l'étape appropriée comme suit:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Code to be executed when the lifecycle stage is Rendered
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Code to be executed when the lifecycle stage is Steady
  }
})
```
