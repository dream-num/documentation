Utilisez Facade API pour intégrer la lecture et l’écriture des données, la mise en forme et les événements de l’éditeur à votre application. Les opérations sont organisées par classeur, feuille et plage.

Obtenez `univerAPI` selon votre mode d’intégration ci-dessous, ou consultez directement la [recherche d’API et de commandes](#find-apis-and-commands).

<Callout type="warning" title="Attention">
  Lorsqu’une méthode renvoie une Promise, attendez avec `await` ou `.then()` avant de lire le résultat ou de lancer une étape dépendante. Les autres méthodes renvoient directement une valeur ou un objet Facade. Vérifiez le type de retour de chaque API.
</Callout>

## Intégrer la Facade API en mode prédéfini

Si vous intégrez Univer en mode prédéfini, les Facade API des fonctionnalités incluses sont automatiquement importées. Lors de la création d’une instance Univer, l’instance Facade API correspondante, `univerAPI`, est également renvoyée et peut être utilisée directement.

## Intégrer la Facade API en mode plug-in

### Installation

Lorsque vous installez Univer en mode plug-in, les différentes implémentations de la Facade API sont réparties entre plusieurs plug-ins et montées sur l’objet racine global de la Facade API. Vous pouvez donc importer, selon vos besoins, l’implémentation Facade API correspondant à chaque plug-in qui en propose une.

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs/ui/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="Attention">
  Tous les plug-ins n’incluent pas de package facade. La documentation de chaque fonctionnalité indique si celui-ci est disponible.
</Callout>

### Utilisation

La Facade API est une enveloppe autour de l’instance Univer. Après avoir créé cette dernière, vous devez donc l’envelopper avec `FUniver` :

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Points d’attention

Toutes les Facade API ne peuvent pas être appelées immédiatement : certaines doivent être utilisées à des étapes précises du cycle de vie. Si une exécution immédiate ne fonctionne pas, utilisez la méthode suivante pour choisir l’étape du cycle de vie appropriée :

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Code to be executed when the lifecycle stage is Rendered
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Code to be executed when the lifecycle stage is Steady
  }
})
```

## Trouver une API ou une commande [#find-apis-and-commands]

Partez du guide de la fonctionnalité, puis consultez la référence Facade du [classeur](/reference/facade/workbook), de la [feuille](/reference/facade/worksheet) ou de la [plage](/reference/facade/range). Enregistrez le plugin propriétaire et, en mode plugin, importez sa Facade.

Si aucune méthode Facade ne convient, cherchez la commande exportée dans le [paquet propriétaire](/reference/packages/plugins/univerjs/sheets) et utilisez son `.id`. Identifiant de menu, commande et mutation sont distincts : ne déduisez pas un ID du libellé de la barre d’outils.

```typescript
import { SetRangeValuesCommand } from '@univerjs/sheets'

console.log(SetRangeValuesCommand.id)
```

Enregistrez cet écouteur, effectuez l’action dans l’éditeur et inspectez la sortie. Il observe les commandes sans les exécuter ; toutes les mutations observées ne sont pas destinées à un appel direct.

```typescript
const commandLog = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type }) => {
  console.log(id, type)
})
```

Retirez ensuite l’écouteur. Pour les paramètres, l’enregistrement et l’annulation, consultez les [commandes personnalisées](/blog/custom-command).

```typescript
commandLog.dispose()
```
