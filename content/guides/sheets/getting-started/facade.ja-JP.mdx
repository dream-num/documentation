Facade API でブックの読み書き、書式設定、エディターイベントを業務処理に組み込めます。操作はブック・シート・範囲の各オブジェクトに整理されています。

以下で統合方式に応じて `univerAPI` を取得するか、[API・コマンドの探し方](#find-apis-and-commands)へ進んでください。

<Callout type="warning" title="注意事項">
  Promise を返すメソッドは、`await` または `.then()` で完了を待ってから結果の読み取りや後続処理を行います。他のメソッドは値や Facade オブジェクトを直接返します。各 API の戻り値の型を確認してください。
</Callout>

## プラグインモードでの Facade API の統合

### インストール

Univer をプラグインモードでインストールする場合、Facade API の実装は各プラグインに分散されており、グローバルな Facade API ルートオブジェクトにマウントされます。つまり、Facade API を提供するプラグインについては、必要に応じて対応する Facade API 実装をインポートできます。

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs/ui/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="注意事項">
  すべてのプラグインにfacade パッケージが含まれているわけではありません。各機能のドキュメントでこれを明記します。
</Callout>

### 使い方

Facade API は Univer インスタンスのラッパーであるため、Univer インスタンスを作成した後に `FUniver` を使用してそのインスタンスをラップする必要があります：

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## プリセットモードでの Facade API の統合

Univer をプリセットモードで統合する場合、対象機能の Facade API が自動的にインポートされ、Univer インスタンス作成時に対応する Facade API インスタンス univerAPI が返されます。直接利用可能です。

## 注意事項

すべての Facade API が即座に呼び出せるわけではありません。一部の API は特定のライフサイクル段階で使用する必要があります。即時実行で問題が発生した場合は、以下の方法で適切なライフサイクル段階を選択して実行してください：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // ライフサイクルが Rendered のときに実行するコード
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // ライフサイクルが Steady のときに実行するコード
  }
})
```

## API またはコマンドを探す [#find-apis-and-commands]

機能ガイドから始め、Facade リファレンスで[ブック](/reference/facade/workbook)、[シート](/reference/facade/worksheet)、[範囲](/reference/facade/range)のメソッドを探します。所有プラグインの登録と、プラグインモードでは対応する Facade のインポートが必要です。

Facade で実現できない場合は[対応パッケージ](/reference/packages/plugins/univerjs/sheets)で公開コマンドを探し、`.id` を使用します。メニュー ID、コマンド、Mutation は別の概念です。ツールバー名から ID を推測しないでください。

```typescript
import { SetRangeValuesCommand } from '@univerjs/sheets'

console.log(SetRangeValuesCommand.id)
```

次のリスナーを登録し、エディターで操作して出力を確認すると、実行されたコマンドを特定できます。リスナーはコマンドを実行せず、観測したすべての Mutation を直接使用できるわけではありません。

```typescript
const commandLog = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type }) => {
  console.log(id, type)
})
```

調査後はリスナーを解除します。登録、引数、元に戻す・やり直しについては[カスタムコマンド](/blog/custom-command)を参照してください。

```typescript
commandLog.dispose()
```
