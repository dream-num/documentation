Univerのアーキテクチャは複雑な要件に対応し、コアAPIは複雑さを反映しています。Univerは、アプリケーションコードが直接呼び出すシンプルなレイヤーであるFacade APIも提供しています。

このページでは、Facade API をアプリケーションに追加する方法について説明します。 機能セクションのページでは、各機能のメインファサード API を一覧表示します。 完全なセットについては、各プラグインの API リファレンスを参照してください。

<Callout type="warning" title="キューション">
  一部のファサード API は非同期であり、データの変更がしばしば Promise を返すものです。データが変更された直後に読み込まれると、 `await` コールまたはチェーン `.then()`; それ以外の場合、結果は予期しない可能性があります。 API が Promise を返すかどうかを判断するには、対応する API リファレンスを参照してください。
</Callout>

## プラグインモードでの Facade API の統合

### インストール

プラグインモードでは、各プラグインは独自のFacade API実装を出荷し、それぞれが一つのグローバルFacade APIオブジェクトに添付します。 Facade APIを提供するすべてのプラグインでは、必要に応じてマッチング実装をインポートします。

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs/ui/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="キューション">
  すべてのプラグインにはファサードパッケージが含まれているわけではありません。各機能ページは、それが実行するかどうかを状態にします。
</Callout>

### 使い方

Facade APIはUniverインスタンスをラップします。最初にインスタンスを作成し、`FUniver`でラップします。

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## プリセットモードでの Facade API の統合

プリセットモードでは、プリセットは、Facade API をインポートします。Univerインスタンスを作成すると、すぐに使用できるマッチング `univerAPI` 例を返します。

## 注意事項

Facade APIはすぐに呼び出せるわけではありません。特定のライフサイクルステージでのみ効果を発揮します。即時の呼び出しが効果を発揮しない場合は、次の手順で適切なステージを選択します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // ライフサイクルが Rendered のときに実行するコード
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // ライフサイクルが Steady のときに実行するコード
  }
})
```
