<Callout>
  Para utilizar los componentes Angular como componentes personalizados en el editor, consulte [componentes personalizados](/guides/sheets/ui/components#angular).
</Callout>

Antes de integrar Univer en un proyecto Angular, lea [instalación y uso básico](/guides/sheets/getting-started/installation) y familiaricese con los componentes Angular con ganchos de ciclo de vida.

### Pasos de integración

1. Inicializa Univer en `ngAfterViewInit`.
2. Libera Univer en `ngOnDestroy`.

### Configuración de preajustes [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | El elemento en el que Univer se monta, o el DOM ID de ese elemento. |

### Código de ejemplo

```typescript
import type { AfterViewInit, ElementRef, OnDestroy } from '@angular/core'
import type { Univer } from '@univerjs/presets'
import { Component, ViewChild } from '@angular/core'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreesES from '@univerjs/preset-sheets-core/locales/es-ES'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'

@Component({
  selector: 'app-univer',
  standalone: true,
  template: '<div #container style="height: 600px"></div>',
})
export class UniverComponent implements AfterViewInit, OnDestroy {
  @ViewChild('container') container!: ElementRef<HTMLDivElement>

  private univer?: Univer

  ngAfterViewInit() {
    const { univer, univerAPI } = createUniver({
      locale: LocaleType.ES_ES,
      locales: {
        [LocaleType.ES_ES]: mergeLocales(
          UniverPresetSheetsCoreesES,
        ),
      },
      presets: [
        UniverSheetsCorePreset({
          container: this.container.nativeElement,
        }),
      ],
    })

    this.univer = univer
    univerAPI.createWorkbook({})
  }

  ngOnDestroy() {
    this.univer?.dispose()
  }
}
```
