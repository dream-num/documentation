Univer를 Vue 프로젝트로 통합하기 전에 [설치 및 기본 사용](/guides/sheets/getting-started/installation)을 읽고 Vue 구성 요소 및 수명주기 후크와 익숙해졌습니다.

## Vue 3.x

### 통합 전 참고 사항

- Univer 또는 FUniver 인스턴스를 프록시하지 마십시오. Proxies는 예측 가능한 오류 또는 성능 문제를 일으킬 수 있습니다.

### 통합 단계

1. `onMounted`에 Univer를 초기화합니다.
2. `onBeforeUnmount`에서 Univer의 처리.

### 프리셋 설정 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 편집기를 마운트할 DOM 요소 또는 해당 요소의 ID입니다. |

### 예제

```vue
<script lang="ts" setup>
import type { Univer } from '@univerjs/presets'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { onBeforeUnmount, onMounted, ref } from 'vue'
import '@univerjs/preset-sheets-core/lib/index.css'

const container = ref<HTMLElement | null>(null)

let univerInstance: Univer | null = null

onMounted(() => {
  const { univer, univerAPI } = createUniver({
    locale: LocaleType.EN_US,
    locales: {
      [LocaleType.EN_US]: mergeLocales(
        UniverPresetSheetsCoreEnUS,
      ),
    },
    presets: [
      UniverSheetsCorePreset({
        container: container.value as HTMLElement,
      }),
    ],
  })

  univerAPI.createWorkbook({})

  univerInstance = univer
})

onBeforeUnmount(() => {
  univerInstance?.dispose()
  univerInstance = null
})
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

## Vue 2.x [#vue-2x]

이 단면도는 기존하는 Vue 2 신청에 적용합니다. 예는 Vue **2.7.16**, Vite **6.3.6**, `@vitejs/plugin-vue2` **2.3.3** 및 Univer **1.5.0**에 대하여 확인됩니다. 새로운 프로젝트는 Vue에 시작합니다.

빈 프로젝트에서 예제를 시도하려면 [시작자](/assets/examples/vue2/univer-vue2-starter.zip)를 다운로드하고 추출하고 `npm install` 및 `npm run dev`을 실행하고 터미널에서 인쇄 된 URL을 엽니 다. 스타터 인터페이스는 영어로되어 있습니다. 이미 Vue 2 프로젝트를 가지고 있다면 아래 단계를 따르십시오.

### 의존성 버전 맞추기

```bash
npm install @univerjs/presets@1.5.0 @univerjs/preset-sheets-core@1.5.0 react@18.3.1 react-dom@18.3.1 rxjs@7.8.2
```

### 페이지에 컴포넌트 추가

Univer 인스턴스를 유지하고 민감하는 `data`에서 객체를 Facade. `mounted`의 편집기를 생성하면 컨테이너가 존재하고 `univer.dispose()`를 `beforeDestroy`로 호출합니다. Facade를 통해 동일한 인스턴스를 해제하지 마십시오.

```vue
<script>
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'

export default {
  mounted() {
    const { univer, univerAPI } = createUniver({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          UniverPresetSheetsCoreEnUS,
        ),
      },
      presets: [
        UniverSheetsCorePreset({
          container: this.$refs.container,
        }),
      ],
    })

    this.univerInstance = univer
    this.univerAPI = univerAPI

    const workbook = univerAPI.createWorkbook({})
    workbook.getActiveSheet().getRange('A1:D3').setValues([
      ['Item', 'Quantity', 'Unit price', 'Total'],
      ['Notebook', 3, 12, '=B2*C2'],
      ['Pen', 5, 2, '=B3*C3'],
    ])
  },
  beforeDestroy() {
    this.univerInstance?.dispose()
    this.univerInstance = null
    this.univerAPI = null
  },
}
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

### 실행 결과 확인

첫 번째 행의 총은 **36**입니다. **3**에서 **4**로 양을 변경하고 총 **48**가됩니다. 그런 다음 정리 작업을 확인하기 위해 구성 요소를 제거하고 다시 마운트합니다.

### 초기화에 실패하는 경우

`setConfig` 오류가 발생하면 시작자와 설정 비교하고 아래 명령으로 의존성 트리를 검사합니다. Univer 패키지의 일치 세트를 유지하고 호환 React / ReactDOM 쌍을 호환하십시오. 혼자 스택 추적은 Vue 2가 지원되지 않습니다.

```bash
npm ls @univerjs/core @univerjs/ui @univerjs/presets @univerjs/preset-sheets-core react react-dom
```

편집기 영역만 공백이면 컨테이너가 높이가 있고 사전 설정 CSS가 가져올 수 있다는 것을 확인하십시오. Univer 인스턴스를 구성 요소에 맞게 완벽하게 반응하지 마십시오.

### Webpack 4 / Vue CLI 3–4

Starter는 Vite 및 패키지 수출을 사용하므로 성공적인 빌드는 Webpack 4를 확인하지 않습니다. 레거시 빌드가 Facade 또는 Locale 수출을 해결할 수 없다면 빌드 도구를 업그레이드하십시오. 별표의 일부를 복사하면 누락되거나 중복 모듈을 숨길 수 있습니다.
