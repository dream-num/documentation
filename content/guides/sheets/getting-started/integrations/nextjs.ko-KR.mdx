---
title: Next.js에 통합
---

시작하기 전에 [설치 및 기본 사용](/guides/sheets/getting-started/installation)를 읽으십시오. 예를 들어 Univer 시트를 컨테이너에 마운트하면 Next.js 앱 라우터를 사용하여 명시된 높이가 있습니다.

`ssr: false`[^ssr] 클라이언트 구성 요소에서 편집기를로드하십시오. `use client` 지시어는 혼자서 사전 렌더링을 비활성화하지 않습니다. 자세한 내용은 [Next.js: SSR 건너뛰기](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr)를 참조하십시오.

### 통합 단계

1. `useEffect` 안에서 Univer를 초기화합니다.
2. `useEffect`가 반환된 클린업 기능에 Univer의 처분.

### 프리셋 설정 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 편집기를 마운트할 DOM 요소 또는 해당 요소의 ID입니다. |

### 예제 코드

각 산은 그것의 자신의 아이 콘테이너를 이용합니다. React가 그것의 자신의 cleanup를 완료한 microtask에 청소 defers 처리는, 그래서 React 뿌리를 React 투입 도중 비동기적으로 배열하지 않습니다.

```tsx title="univer-editor.tsx"
'use client'

import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { useEffect, useRef } from 'react'

import '@univerjs/preset-sheets-core/lib/index.css'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          UniverPresetSheetsCoreEnUS,
        ),
      },
      presets: [
        UniverSheetsCorePreset({
          container,
        }),
      ],
    })

    univerAPI.createWorkbook({})

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return (
    <div ref={containerRef} style={{ height: 600 }} />
  )
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: 서버 사이드 렌더링(SSR)은 브라우저가 페이지를 로드하기 전에 렌더링 코드를 실행합니다. 이 환경에는 `window`와 DOM이 없습니다. Client Component도 사전 렌더링될 수 있으므로 편집기 컴포넌트의 SSR을 별도로 꺼야 합니다.
