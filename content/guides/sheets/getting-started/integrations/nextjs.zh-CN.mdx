---
title: 在 Next.js 中集成
---

开始之前，请先阅读[安装和基本使用](/guides/sheets/getting-started/installation)。下面的示例使用 Next.js App Router，将 Univer Sheets 挂载到一个具有明确高度的容器中。

编辑器需要从客户端组件中通过 `ssr: false`[^ssr] 动态加载。仅声明 `use client` 并不会关闭预渲染。具体做法见 [Next.js：跳过 SSR](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr)。

### 集成步骤

1. 在 `useEffect` 中初始化 Univer。
2. 在 `useEffect` 返回的清理函数中销毁 Univer。

### 预设配置 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 编辑器挂载的元素，或该元素的 DOM ID。 |

### 示例代码

每次挂载都使用独立的子容器，销毁操作则推迟到微任务中执行。此时 React 自身的清理已经完成，因此不会在 React 提交期间同步卸载嵌套的 React root。

```tsx title="univer-editor.tsx"
'use client'

import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreZhCN from '@univerjs/preset-sheets-core/locales/zh-CN'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { useEffect, useRef } from 'react'

import '@univerjs/preset-sheets-core/lib/index.css'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.ZH_CN,
      locales: {
        [LocaleType.ZH_CN]: mergeLocales(
          UniverPresetSheetsCoreZhCN,
        ),
      },
      presets: [
        UniverSheetsCorePreset({
          container,
        }),
      ],
    })

    univerAPI.createWorkbook({})

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return (
    <div ref={containerRef} style={{ height: 600 }} />
  )
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: 服务端渲染（SSR）会在浏览器加载页面前执行渲染代码，此时没有浏览器的 `window` 和 DOM。Client Component 仍可能被预渲染，因此需要单独关闭编辑器组件的 SSR。
