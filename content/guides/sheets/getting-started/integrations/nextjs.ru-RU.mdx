title: Интеграция с Next.js

Перед тем, как начать, прочитайте [Установка и базовое использование](/guides/sheets/getting-started/installation). В примере монтируются листы Univer в контейнере с явной высотой, используя маршрутизатор приложения Next.js .

Загрузите редактор из Компонента клиента с помощью `ssr: false`[^ssr]. Только директива `use client` не отключает предварительный рендеринг. См. [Next.js: пропуск SSR](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr) для деталей.

### Шаги интеграции

1. Инициализируйте Univer внутри `useEffect`.
2. Удалите Univer в функции очистки, возвращенной `useEffect`.

### Настройка пресетов [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | DOM-элемент для размещения редактора или его идентификатор. |

### Пример кода

Каждая установка использует свой собственный детский контейнер. Очистка отсрочивает удаление до микрозадачи, к которой React закончил свою собственную очистку, поэтому вложенные корни React никогда не синхронно не устанавливаются во время выполнения React.

```tsx title="univer-editor.tsx"
'use client'

import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { useEffect, useRef } from 'react'

import '@univerjs/preset-sheets-core/lib/index.css'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          UniverPresetSheetsCoreEnUS,
        ),
      },
      presets: [
        UniverSheetsCorePreset({
          container,
        }),
      ],
    })

    univerAPI.createWorkbook({})

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return (
    <div ref={containerRef} style={{ height: 600 }} />
  )
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: Серверный рендеринг (SSR) выполняет код отрисовки до загрузки страницы браузером, без `window` и DOM. Client Component также может предварительно отрисовываться, поэтому SSR редактора отключается отдельно.
