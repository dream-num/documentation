---
title: Intégrer dans Next.js
---

Avant de commencer, lisez [l'installation et l'utilisation de base](/guides/sheets/getting-started/installation). L'exemple monte les feuilles Univer dans un conteneur avec une hauteur explicite, en utilisant le routeur d'application Next.js .

Chargez l'éditeur à partir d'un élément client avec `ssr: false`[^ssr]. Une directive `use client` seule ne désactive pas le prérendu. Voir [Next.js: sauter SSR](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr) pour plus de détails.

### Étapes d’intégration

1. Initialisez Univer dans `useEffect`.
2. Jetez Univer dans la fonction de nettoyage retournée par `useEffect`.

### Configuration des préréglages [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | Élément DOM de montage de l’éditeur ou son identifiant. |

### Exemple de code

Chaque montage utilise son propre conteneur enfant. Le nettoyage reporte l'élimination à une microtâche, par laquelle React a terminé son propre nettoyage, de sorte que les racines imbriquées React ne sont jamais démontées synchronement lors d'un commit React.

```tsx title="univer-editor.tsx"
'use client'

import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { useEffect, useRef } from 'react'

import '@univerjs/preset-sheets-core/lib/index.css'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          UniverPresetSheetsCoreEnUS,
        ),
      },
      presets: [
        UniverSheetsCorePreset({
          container,
        }),
      ],
    })

    univerAPI.createWorkbook({})

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return (
    <div ref={containerRef} style={{ height: 600 }} />
  )
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: Le rendu côté serveur (SSR) exécute le code de rendu avant le chargement de la page dans le navigateur, sans `window` ni DOM. Un Client Component peut aussi être prérendu : il faut désactiver le SSR pour le composant de l’éditeur.
