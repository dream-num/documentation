UniverをVueプロジェクトに統合する前に、[インストールと基本的な使い方](/guides/sheets/getting-started/installation)を読み、Vueコンポーネントとライフサイクルホックに精通します。

## Vue 3.x

### 統合前の注意事項

- Univer または FUniver インスタンスをプロキシしないでください。プロキシは予測不可能なエラーやパフォーマンスの問題を引き起こす可能性があります。

### 統合手順

1. `onMounted`のUniverを初期化。
2. `onBeforeUnmount`のUniverを分解します。

### プリセット設定 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | エディターのマウント先となる DOM 要素、またはその ID。 |

### 例

```vue
<script lang="ts" setup>
import type { Univer } from '@univerjs/presets'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreJaJP from '@univerjs/preset-sheets-core/locales/ja-JP'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { onBeforeUnmount, onMounted, ref } from 'vue'
import '@univerjs/preset-sheets-core/lib/index.css'

const container = ref<HTMLElement | null>(null)

let univerInstance: Univer | null = null

onMounted(() => {
  const { univer, univerAPI } = createUniver({
    locale: LocaleType.JA_JP,
    locales: {
      [LocaleType.JA_JP]: mergeLocales(
        UniverPresetSheetsCoreJaJP,
      ),
    },
    presets: [
      UniverSheetsCorePreset({
        container: container.value as HTMLElement,
      }),
    ],
  })

  univerAPI.createWorkbook({})

  univerInstance = univer
})

onBeforeUnmount(() => {
  univerInstance?.dispose()
  univerInstance = null
})
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

## Vue 2.x [#vue-2x]

この節は既存の Vue 2 アプリケーションを対象としています。サンプルでは Vue **2.7.16**、Vite **6.3.6**、`@vitejs/plugin-vue2` **2.3.3** を使用します。新規プロジェクトでは Vue 3 を使用してください。

空のプロジェクトから例を試すには、[スターター](/assets/examples/vue2/univer-vue2-starter.zip)をダウンロードして抽出し、`npm install`と`npm run dev`を実行し、ターミナルで印刷されたURLを開きます。 始動機インターフェイスは英語です。 Vue 2プロジェクトを既に持っている場合は、以下の手順に従ってください。

### 依存関係のバージョンをそろえる

```bash
npm install @univerjs/presets @univerjs/preset-sheets-core react@18.3.1 react-dom@18.3.1 rxjs@7.8.2
```

### ページにコンポーネントを追加

Univerインスタンスとファサードオブジェクトを反応`data`から保持します。 コンテナが存在すると`mounted`でエディタを作成し、`univer.dispose()`を`beforeDestroy`で呼び出します。 ファサードを介して再び同じインスタンスを捨てないでください。

```vue
<script>
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreJaJP from '@univerjs/preset-sheets-core/locales/ja-JP'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'

export default {
  mounted() {
    const { univer, univerAPI } = createUniver({
      locale: LocaleType.JA_JP,
      locales: {
        [LocaleType.JA_JP]: mergeLocales(
          UniverPresetSheetsCoreJaJP,
        ),
      },
      presets: [
        UniverSheetsCorePreset({
          container: this.$refs.container,
        }),
      ],
    })

    this.univerInstance = univer
    this.univerAPI = univerAPI

    const workbook = univerAPI.createWorkbook({})
    workbook.getActiveSheet().getRange('A1:D3').setValues([
      ['Item', 'Quantity', 'Unit price', 'Total'],
      ['Notebook', 3, 12, '=B2*C2'],
      ['Pen', 5, 2, '=B3*C3'],
    ])
  },
  beforeDestroy() {
    this.univerInstance?.dispose()
    this.univerInstance = null
    this.univerAPI = null
  },
}
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

### 動作を確認する

最初の行の合計は**36**です。**3**から**4**に数量を変更し、合計は**48**になります。その後、コンポーネントを削除して、そのクリーンアップ作業を確認します。

### 初期化に失敗する場合

`setConfig` エラーが発生した場合は、スターターとセットアップを比較し、下のコマンドで依存ツリーを検査します。 Univer パッケージの 1 つのマッチングセットを 1 つ保持し、互換性のある React/ReactDOM ペア。 スタックトレースは、Vue 2 がサポートされていないことを証明しません。

```bash
npm ls @univerjs/core @univerjs/ui @univerjs/presets @univerjs/preset-sheets-core react react-dom
```

エディタ領域が空白の場合、そのコンテナが高さを持ち、プリセットCSSがインポートされていることを確認してください。 Univerインスタンスは、コンポーネントに保つために、反応的に反応しません。

### Webpack 4 / Vue CLI 3–4

始動機は Vite とパッケージのエクスポートを使用しており、成功したビルドでは Webpack 4. を検証しません。 従来のビルドが Facade や locale のエクスポートを解決できない場合は、ビルドツールをアップグレードします。 エイリアスリストのコピーは、欠落または重複するモジュールを隠すことができます。
