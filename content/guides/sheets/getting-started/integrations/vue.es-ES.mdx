## Vue 3.x

### Notas antes de la integración

- No proxy las instancias Univer o FUniver. Los ejes pueden causar errores impredecibles o problemas de rendimiento.

### Pasos de integración

1. Inicializar Univer en `onMounted`.
2. Desplazamiento de Univer en `onBeforeUnmount`.

### Configuración de preajustes [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | Elemento DOM donde se monta el editor o su ID. |

### Ejemplo

```vue
<script lang="ts" setup>
import type { Univer } from '@univerjs/presets'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { onBeforeUnmount, onMounted, ref } from 'vue'
import '@univerjs/preset-sheets-core/lib/index.css'

const container = ref<HTMLElement | null>(null)

let univerInstance: Univer | null = null

onMounted(() => {
  const { univer, univerAPI } = createUniver({
    locale: LocaleType.EN_US,
    locales: {
      [LocaleType.EN_US]: mergeLocales(
        UniverPresetSheetsCoreEnUS,
      ),
    },
    presets: [
      UniverSheetsCorePreset({
        container: container.value as HTMLElement,
      }),
    ],
  })

  univerAPI.createWorkbook({})

  univerInstance = univer
})

onBeforeUnmount(() => {
  univerInstance?.dispose()
  univerInstance = null
})
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

## Vue 2.x [#vue-2x]

Esta sección se aplica a una aplicación Vue 2 existente. El ejemplo se verifica en Vue **2.7.16**, Vite **6.3.6**, `@vitejs/plugin-vue2` **2.3.3**, y Univer **1.5.0**. Los nuevos proyectos deben comenzar en Vue 3.

Para probar el ejemplo de un proyecto vacío, descargue y extraiga el [starter](/assets/examples/vue2/univer-vue2-starter.zip), ejecute `npm install` y `npm run dev`; abra la URL impresa en el terminal. La interfaz de inicio está en inglés. Si ya tiene un proyecto Vue 2, siga los pasos a continuación.

### Instalar dependencias coherentes

```bash
npm install @univerjs/presets@1.5.0 @univerjs/preset-sheets-core@1.5.0 react@18.3.1 react-dom@18.3.1 rxjs@7.8.2
```

### Añadir el componente a tu página

Mantenga la instancia Univer y los objetos Facade fuera de `data`. Crear el editor en `mounted`, una vez que el contenedor existe, y llamar `univer.dispose()` en `beforeDestroy`. No deseche de nuevo la misma instancia a través de Facade.

```vue
<script>
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'

export default {
  mounted() {
    const { univer, univerAPI } = createUniver({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          UniverPresetSheetsCoreEnUS,
        ),
      },
      presets: [
        UniverSheetsCorePreset({
          container: this.$refs.container,
        }),
      ],
    })

    this.univerInstance = univer
    this.univerAPI = univerAPI

    const workbook = univerAPI.createWorkbook({})
    workbook.getActiveSheet().getRange('A1:D3').setValues([
      ['Item', 'Quantity', 'Unit price', 'Total'],
      ['Notebook', 3, 12, '=B2*C2'],
      ['Pen', 5, 2, '=B3*C3'],
    ])
  },
  beforeDestroy() {
    this.univerInstance?.dispose()
    this.univerInstance = null
    this.univerAPI = null
  },
}
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

### Comprobar el resultado

El total en la primera fila es **36**. Cambia la cantidad de **3** a **4**, y el total se convierte en **48** . Luego retira y remonta el componente para verificar que la limpieza funciona.

### Si falla la inicialización

Si se produce un error `setConfig`, compare su configuración con el starter e inspeccione el árbol de dependencia con el comando abajo. Mantenga un conjunto de paquetes Univer compatible, además de un par React/ReactDOM compatible. Un rastro de pila por sí solo no prueba que Vue 2 no es compatible.

```bash
npm ls @univerjs/core @univerjs/ui @univerjs/presets @univerjs/preset-sheets-core react react-dom
```

Si sólo el área del editor está en blanco, compruebe que su contenedor tiene una altura y que el preset CSS es importado. No haga que la instancia Univer sea reactivada únicamente para mantenerla en el componente.

### Webpack 4 / Vue CLI 3–4

El starter utiliza Vite y las exportaciones de paquetes, por lo que una construcción exitosa no verifica Webpack 4. Si su construcción heredada no puede resolver las exportaciones de Facade o locale, actualice la herramienta de construcción. Copiar parte de una lista de alias puede ocultar módulos perdidos o duplicados.
