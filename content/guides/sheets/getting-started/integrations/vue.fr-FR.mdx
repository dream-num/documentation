Avant d'intégrer Univer dans un projet Vue, lisez [l'installation et l'utilisation de base](/guides/sheets/getting-started/installation) et familiarisez-vous avec les composants Vue ainsi que les crochets de cycle de vie.

## Vue 3.x

### Remarques avant l’intégration

- Ne pas proxy les instances Univer ou FUniver. Proxies peut causer des erreurs imprévisibles ou des problèmes de performance.

### Étapes d’intégration

1. Initialiser Univer dans `onMounted`.
2. Jeter Univer dans `onBeforeUnmount`.

### Configuration des préréglages [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | Élément DOM de montage de l’éditeur ou son identifiant. |

### Exemple

```vue
<script lang="ts" setup>
import type { Univer } from '@univerjs/presets'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { onBeforeUnmount, onMounted, ref } from 'vue'
import '@univerjs/preset-sheets-core/lib/index.css'

const container = ref<HTMLElement | null>(null)

let univerInstance: Univer | null = null

onMounted(() => {
  const { univer, univerAPI } = createUniver({
    locale: LocaleType.EN_US,
    locales: {
      [LocaleType.EN_US]: mergeLocales(
        UniverPresetSheetsCoreEnUS,
      ),
    },
    presets: [
      UniverSheetsCorePreset({
        container: container.value as HTMLElement,
      }),
    ],
  })

  univerAPI.createWorkbook({})

  univerInstance = univer
})

onBeforeUnmount(() => {
  univerInstance?.dispose()
  univerInstance = null
})
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

## Vue 2.x [#vue-2x]

Cette section concerne les applications Vue 2 existantes. L’exemple utilise Vue **2.7.16**, Vite **6.3.6** et `@vitejs/plugin-vue2` **2.3.3**. Pour un nouveau projet, utilisez Vue 3.

Pour essayer l'exemple d'un projet vide, téléchargez et extrayez le [démarreur](/assets/examples/vue2/univer-vue2-starter.zip), exécutez `npm install` et `npm run dev`. Ouvrez l'URL imprimée dans le terminal. L'interface de démarrage est en anglais. Si vous avez déjà un projet Vue 2, suivez les étapes ci-dessous.

### Installer des dépendances cohérentes

```bash
npm install @univerjs/presets @univerjs/preset-sheets-core react@18.3.1 react-dom@18.3.1 rxjs@7.8.2
```

### Ajouter le composant à votre page

Gardez l'instance Univer et les objets Facade hors de `data` réactif. Créez l'éditeur en `mounted`, une fois que le conteneur existe, et appelez `univer.dispose()` en `beforeDestroy`. Ne pas disposer de nouveau de la même instance par Facade.

```vue
<script>
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'

export default {
  mounted() {
    const { univer, univerAPI } = createUniver({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          UniverPresetSheetsCoreEnUS,
        ),
      },
      presets: [
        UniverSheetsCorePreset({
          container: this.$refs.container,
        }),
      ],
    })

    this.univerInstance = univer
    this.univerAPI = univerAPI

    const workbook = univerAPI.createWorkbook({})
    workbook.getActiveSheet().getRange('A1:D3').setValues([
      ['Item', 'Quantity', 'Unit price', 'Total'],
      ['Notebook', 3, 12, '=B2*C2'],
      ['Pen', 5, 2, '=B3*C3'],
    ])
  },
  beforeDestroy() {
    this.univerInstance?.dispose()
    this.univerInstance = null
    this.univerAPI = null
  },
}
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

### Vérifier le résultat

Le total de la première ligne est **36**. Changez la quantité de **3** en **4** et le total devient **48**, puis retirez et remontez le composant pour vérifier que le nettoyage fonctionne.

### En cas d’échec d’initialisation

Si une erreur `setConfig` se produit, comparez votre configuration avec le démarreur et inspectez l'arborescence de dépendance avec la commande ci-dessous. Conservez un ensemble correspondant de paquets Univer, ainsi qu'une paire compatible React/ReactDOM. Une trace de pile seule ne prouve pas que Vue 2 n'est pas pris en charge.

```bash
npm ls @univerjs/core @univerjs/ui @univerjs/presets @univerjs/preset-sheets-core react react-dom
```

Si seule la zone de l'éditeur est vide, vérifiez que son conteneur a une hauteur et que le CSS préréglé est importé. Ne faites pas réagir l'instance Univer uniquement pour le garder sur le composant.

### Webpack 4 / Vue CLI 3–4

Le démarreur utilise les exportations de Vite et de paquets, de sorte qu'une construction réussie là ne vérifie pas Webpack 4. Si votre construction ne peut pas résoudre les exportations de Facade ou de locale, mettre à jour l'outil de construction. Copier une partie d'une liste d'alias peut masquer les modules manquants ou dupliqués.
