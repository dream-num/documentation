title: Next.js への統合

[インストールと基本的な使い方](/guides/sheets/getting-started/installation) を読んでください。 たとえば、Univerシートを明示的な高さでコンテナにマウントし、Next.js App Router を使用します。

`ssr: false`[^ssr] でクライアントコンポーネントからエディタをロードします。 `use client`ディレクティブは、プレレンダーを無効にしません。 詳細は [Next.js:SSRをスキッピング](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr)を参照してください。

### 統合手順

1. `useEffect` 内で Univer を初期化します。
2. `useEffect`で返されたクリーンアップ機能でUniverの処分。

### プリセット設定 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | エディターのマウント先となる DOM 要素、またはその ID。 |

### 事例紹介

各マウントは、独自の子コンテナを使用します。Reactが独自のクリーンアップを終えた時点から、ReactのルートはReactコミット時に同期的にマウントされていないため、マイクロタスクへのクリーンアップデフラグの処理を行います。

```tsx title="univer-editor.tsx"
'use client'

import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreJaJP from '@univerjs/preset-sheets-core/locales/ja-JP'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { useEffect, useRef } from 'react'

import '@univerjs/preset-sheets-core/lib/index.css'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.JA_JP,
      locales: {
        [LocaleType.JA_JP]: mergeLocales(
          UniverPresetSheetsCoreJaJP,
        ),
      },
      presets: [
        UniverSheetsCorePreset({
          container,
        }),
      ],
    })

    univerAPI.createWorkbook({})

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return (
    <div ref={containerRef} style={{ height: 600 }} />
  )
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: サーバーサイドレンダリング（SSR）はブラウザーがページを読み込む前に描画コードを実行します。この環境には `window` や DOM がありません。Client Component も事前描画される場合があるため、エディターの SSR を個別に無効化します。
