## Vue 3.x

### 整合前須知

- 不要為 Univer 或 FUniver 例項新增代理，否則可能出現難以預料的報錯或效能問題。

### 整合步驟

1. 在 `onMounted` 中初始化 Univer。
2. 在 `onBeforeUnmount` 中銷燬 Univer。

### 預設設定 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 編輯器掛載的元素，或該元素的 DOM ID。 |

### 範例程式碼

```vue
<script lang="ts" setup>
import type { Univer } from '@univerjs/presets'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreZhTW from '@univerjs/preset-sheets-core/locales/zh-TW'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { onBeforeUnmount, onMounted, ref } from 'vue'
import '@univerjs/preset-sheets-core/lib/index.css'

const container = ref<HTMLElement | null>(null)

let univerInstance: Univer | null = null

onMounted(() => {
  const { univer, univerAPI } = createUniver({
    locale: LocaleType.ZH_TW,
    locales: {
      [LocaleType.ZH_TW]: mergeLocales(
        UniverPresetSheetsCoreZhTW,
      ),
    },
    presets: [
      UniverSheetsCorePreset({
        container: container.value as HTMLElement,
      }),
    ],
  })

  univerAPI.createWorkbook({})

  univerInstance = univer
})

onBeforeUnmount(() => {
  univerInstance?.dispose()
  univerInstance = null
})
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

## Vue 2.x [#vue-2x]

本節適用於已有的 Vue 2 應用。範例的驗證環境為 Vue **2.7.16**、Vite **6.3.6**、`@vitejs/plugin-vue2` **2.3.3** 和 Univer **1.5.0**。新專案應從 Vue 3 開始。

如需在空專案中試用，請下載並解壓[最小專案](/assets/examples/vue2/univer-vue2-starter.zip)，執行 `npm install` 和 `npm run dev`，然後開啟終端中輸出的地址。該範例的介面為英文。已有 Vue 2 專案請按以下步驟接入。

### 安裝一致的相依套件

```bash
npm install @univerjs/presets@1.5.0 @univerjs/preset-sheets-core@1.5.0 react@18.3.1 react-dom@18.3.1 rxjs@7.8.2
```

### 將元件加入頁面

不要把 Univer 例項和 Facade 物件放入響應式 `data`。請在容器已經存在後於 `mounted` 中建立編輯器，並在 `beforeDestroy` 中呼叫 `univer.dispose()`。不要透過 Facade 再次銷燬同一個例項。

```vue
<script>
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreZhTW from '@univerjs/preset-sheets-core/locales/zh-TW'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'

export default {
  mounted() {
    const { univer, univerAPI } = createUniver({
      locale: LocaleType.ZH_TW,
      locales: {
        [LocaleType.ZH_TW]: mergeLocales(
          UniverPresetSheetsCoreZhTW,
        ),
      },
      presets: [
        UniverSheetsCorePreset({
          container: this.$refs.container,
        }),
      ],
    })

    this.univerInstance = univer
    this.univerAPI = univerAPI

    const workbook = univerAPI.createWorkbook({})
    workbook.getActiveSheet().getRange('A1:D3').setValues([
      ['Item', 'Quantity', 'Unit price', 'Total'],
      ['Notebook', 3, 12, '=B2*C2'],
      ['Pen', 5, 2, '=B3*C3'],
    ])
  },
  beforeDestroy() {
    this.univerInstance?.dispose()
    this.univerInstance = null
    this.univerAPI = null
  },
}
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

### 驗證執行結果

第一行的合計為 **36**。將數量從 **3** 改為 **4** 後，合計應變為 **48**。隨後移除並重新掛載元件，確認銷燬流程正常。

### 初始化失敗時

如果出現 `setConfig` 報錯，請先與最小專案對照，再用以下命令檢查依賴樹。Univer 各包應保持同一套版本，React 與 ReactDOM 也應相互相容。僅憑報錯堆疊不能說明 Vue 2 不受支援。

```bash
npm ls @univerjs/core @univerjs/ui @univerjs/presets @univerjs/preset-sheets-core react react-dom
```

如果只有編輯區域空白，請檢查容器是否設定了高度、預設 CSS 是否已引入。不要僅僅為了把例項儲存在元件上而使其成為響應式物件。

### Webpack 4 / Vue CLI 3–4

最小專案使用 Vite 和包匯出機制，因此它建置成功並不代表 Webpack 4 也能正常工作。如果舊建置工具無法解析 Facade 或語言套件匯出，請升級建置工具。只複製部分 alias 清單可能會掩蓋模組缺失或重複的問題。
