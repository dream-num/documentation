## Vue 3.x

### Перед интеграцией

- Не прокси-серверы Univer или FUniver. Прокси могут вызывать непредсказуемые ошибки или проблемы с производительностью.

### Этапы интеграции

1. Инициировать Univer в `onMounted`.
2. Утилизация Univer в `onBeforeUnmount`.

### Настройка пресетов [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | DOM-элемент для размещения редактора или его идентификатор. |

### Пример

```vue
<script lang="ts" setup>
import type { Univer } from '@univerjs/presets'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { onBeforeUnmount, onMounted, ref } from 'vue'
import '@univerjs/preset-sheets-core/lib/index.css'

const container = ref<HTMLElement | null>(null)

let univerInstance: Univer | null = null

onMounted(() => {
  const { univer, univerAPI } = createUniver({
    locale: LocaleType.EN_US,
    locales: {
      [LocaleType.EN_US]: mergeLocales(
        UniverPresetSheetsCoreEnUS,
      ),
    },
    presets: [
      UniverSheetsCorePreset({
        container: container.value as HTMLElement,
      }),
    ],
  })

  univerAPI.createWorkbook({})

  univerInstance = univer
})

onBeforeUnmount(() => {
  univerInstance?.dispose()
  univerInstance = null
})
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

## Vue 2.x [#vue-2x]

Этот раздел относится к существующей заявке Vue 2. Пример проверен на Vue **2.7.16**, Vite **6.3.6**, `@vitejs/plugin-vue2` **2.3.3** и Univer **1.5.0**. Новые проекты должны начинаться на Vue 3.

Чтобы попробовать пример из пустого проекта, загрузите и извлеките [стартер](/assets/examples/vue2/univer-vue2-starter.zip), запустите `npm install` и `npm run dev` , и откройте URL, напечатанный в терминале. Стартовый интерфейс на английском языке. Если у вас уже есть проект Vue 2, следуйте шагам ниже.

### Установить согласованные зависимости

```bash
npm install @univerjs/presets@1.5.0 @univerjs/preset-sheets-core@1.5.0 react@18.3.1 react-dom@18.3.1 rxjs@7.8.2
```

### Добавить компонент на страницу

Храните экземпляр Univer и объекты Facade из реактивного `data`. Создайте редактор в `mounted`, как только контейнер существует, и вызовите `univer.dispose()` в `beforeDestroy` . Не утилизируйте тот же экземпляр снова через Facade.

```vue
<script>
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'

export default {
  mounted() {
    const { univer, univerAPI } = createUniver({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          UniverPresetSheetsCoreEnUS,
        ),
      },
      presets: [
        UniverSheetsCorePreset({
          container: this.$refs.container,
        }),
      ],
    })

    this.univerInstance = univer
    this.univerAPI = univerAPI

    const workbook = univerAPI.createWorkbook({})
    workbook.getActiveSheet().getRange('A1:D3').setValues([
      ['Item', 'Quantity', 'Unit price', 'Total'],
      ['Notebook', 3, 12, '=B2*C2'],
      ['Pen', 5, 2, '=B3*C3'],
    ])
  },
  beforeDestroy() {
    this.univerInstance?.dispose()
    this.univerInstance = null
    this.univerAPI = null
  },
}
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

### Проверить результат

Итого в первом ряду **36**. Измените количество с **3** на **4**, и общее станет **48**... Затем удалите и переустановите компонент, чтобы убедиться, что очистка работает.

### Если инициализация не удалась

Если происходит ошибка `setConfig`, сравните свою настройку со стартером и проверьте дерево зависимостей с командой ниже. Сохраните один соответствующий набор пакетов Univer плюс совместимую пару React/ReactDOM. Один только след стека не доказывает, что Vue 2 не поддерживается.

```bash
npm ls @univerjs/core @univerjs/ui @univerjs/presets @univerjs/preset-sheets-core react react-dom
```

Если только область редактора пустая, проверьте, что ее контейнер имеет высоту и что заданный CSS импортирован.Не делайте экземпляр Univer реактивным исключительно для того, чтобы сохранить его на компоненте.

### Webpack 4 / Vue CLI 3–4

Стартер использует Vite и пакетный экспорт, поэтому успешная сборка там не проверяет Webpack 4. Если ваша унаследованная сборка не может решить проблему экспорта Facade или локального экспорта, обновите инструмент сборки. Копирование части списка псевдонимов может скрыть недостающие или дублирующиеся модули.
