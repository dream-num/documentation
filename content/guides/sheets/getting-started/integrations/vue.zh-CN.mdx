## Vue 3.x

### 集成前须知

- 不要为 Univer 或 FUniver 实例添加代理，否则可能出现难以预料的报错或性能问题。

### 集成步骤

1. 在 `onMounted` 中初始化 Univer。
2. 在 `onBeforeUnmount` 中销毁 Univer。

### 预设配置 [#preset-configuration]

`UniverSheetsCorePreset`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 编辑器挂载的元素，或该元素的 DOM ID。 |

### 示例代码

```vue
<script lang="ts" setup>
import type { Univer } from '@univerjs/presets'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreZhCN from '@univerjs/preset-sheets-core/locales/zh-CN'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { onBeforeUnmount, onMounted, ref } from 'vue'
import '@univerjs/preset-sheets-core/lib/index.css'

const container = ref<HTMLElement | null>(null)

let univerInstance: Univer | null = null

onMounted(() => {
  const { univer, univerAPI } = createUniver({
    locale: LocaleType.ZH_CN,
    locales: {
      [LocaleType.ZH_CN]: mergeLocales(
        UniverPresetSheetsCoreZhCN,
      ),
    },
    presets: [
      UniverSheetsCorePreset({
        container: container.value as HTMLElement,
      }),
    ],
  })

  univerAPI.createWorkbook({})

  univerInstance = univer
})

onBeforeUnmount(() => {
  univerInstance?.dispose()
  univerInstance = null
})
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

## Vue 2.x [#vue-2x]

本节适用于已有的 Vue 2 应用。示例的验证环境为 Vue **2.7.16**、Vite **6.3.6**、`@vitejs/plugin-vue2` **2.3.3** 和 Univer **1.5.0**。新项目应从 Vue 3 开始。

如需在空项目中试用，请下载并解压[最小项目](/assets/examples/vue2/univer-vue2-starter.zip)，运行 `npm install` 和 `npm run dev`，然后打开终端中输出的地址。该示例的界面为英文。已有 Vue 2 项目请按以下步骤接入。

### 安装一致的依赖

```bash
npm install @univerjs/presets@1.5.0 @univerjs/preset-sheets-core@1.5.0 react@18.3.1 react-dom@18.3.1 rxjs@7.8.2
```

### 把组件加入页面

不要把 Univer 实例和 Facade 对象放入响应式 `data`。请在容器已经存在后于 `mounted` 中创建编辑器，并在 `beforeDestroy` 中调用 `univer.dispose()`。不要通过 Facade 再次销毁同一个实例。

```vue
<script>
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreZhCN from '@univerjs/preset-sheets-core/locales/zh-CN'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'

export default {
  mounted() {
    const { univer, univerAPI } = createUniver({
      locale: LocaleType.ZH_CN,
      locales: {
        [LocaleType.ZH_CN]: mergeLocales(
          UniverPresetSheetsCoreZhCN,
        ),
      },
      presets: [
        UniverSheetsCorePreset({
          container: this.$refs.container,
        }),
      ],
    })

    this.univerInstance = univer
    this.univerAPI = univerAPI

    const workbook = univerAPI.createWorkbook({})
    workbook.getActiveSheet().getRange('A1:D3').setValues([
      ['Item', 'Quantity', 'Unit price', 'Total'],
      ['Notebook', 3, 12, '=B2*C2'],
      ['Pen', 5, 2, '=B3*C3'],
    ])
  },
  beforeDestroy() {
    this.univerInstance?.dispose()
    this.univerInstance = null
    this.univerAPI = null
  },
}
</script>

<template>
  <div ref="container" style="height: 600px" />
</template>
```

### 验证运行结果

第一行的合计为 **36**。将数量从 **3** 改为 **4** 后，合计应变为 **48**。随后移除并重新挂载组件，确认销毁流程正常。

### 初始化失败时

如果出现 `setConfig` 报错，请先与最小项目对照，再用以下命令检查依赖树。Univer 各包应保持同一套版本，React 与 ReactDOM 也应相互兼容。仅凭报错堆栈不能说明 Vue 2 不受支持。

```bash
npm ls @univerjs/core @univerjs/ui @univerjs/presets @univerjs/preset-sheets-core react react-dom
```

如果只有编辑区域空白，请检查容器是否设置了高度、预设 CSS 是否已引入。不要仅仅为了把实例保存在组件上而使其成为响应式对象。

### Webpack 4 / Vue CLI 3–4

最小项目使用 Vite 和包导出机制，因此它构建成功并不代表 Webpack 4 也能正常工作。如果旧构建工具无法解析 Facade 或语言包导出，请升级构建工具。只复制部分 alias 清单可能会掩盖模块缺失或重复的问题。
