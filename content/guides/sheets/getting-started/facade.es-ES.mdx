La arquitectura de Univer tiene que adaptarse a requisitos complejos, y la API central refleja esa complejidad. Univer por lo tanto también proporciona el Facade API, una capa más simple que el código de aplicación llama directamente.

Esta página describe cómo agregar el Facade API a una aplicación. Las páginas de la sección Características enumeran las principales API de Facade para cada función; para el conjunto completo, vea la referencia de API de cada plugin.

<Callout type="warning" title="Precaución">
  Algunas API de Facade son asincrónicas, y las que modifican datos a menudo devuelven una promesa. Cuando los datos se leen inmediatamente después de que se cambie, `await` la llamada o cadena `.then()`; de lo contrario, los resultados pueden ser inesperados. Para determinar si una API devuelve una promesa, consulte la referencia correspondiente de API.
</Callout>

## Integración de Facade API en modo complemento

### Instalación

En modo plugin, cada plugin envía su propia implementación Facade API, y todos ellos se adhieren a un objeto Facade API global. Para cada plugin que proporciona un Facade API importa la implementación que coincida según sea necesario.

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs/ui/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="Precaución">
  No todos los plugins incluyen un paquete de fachada. Cada página de características indica si lo hace.
</Callout>

### Uso

El Facade API envuelve una instancia Univer. Crea la instancia primero, luego envuélvela con `FUniver`:

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Integración de la API de Facade en modo preestablecido

En modo preestablecido, los presets importan el Facade API para las características que contienen. Creando una instancia Univer devuelve una instancia de `univerAPI` que se puede utilizar inmediatamente.

## Precauciones

No todos los Facade API se pueden llamar inmediatamente. Algunos toman efecto sólo en una etapa de ciclo de vida específica. Cuando una llamada inmediata no tiene efecto, seleccione la etapa apropiada como sigue:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Code to be executed when the lifecycle stage is Rendered
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Code to be executed when the lifecycle stage is Steady
  }
})
```
