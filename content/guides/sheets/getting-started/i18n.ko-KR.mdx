## 인터페이스 언어

`locale`는 메뉴, 도구 팁, 대화 상자 및 기타 번역 UI에 사용되는 언어 팩을 선택합니다. `locales`은 선택한하지 않고 그 팩을 등록합니다. 동일한 Univer 인스턴스의 모든 단위는이 설정을 공유합니다. `LocaleType.EN_US`와 같은 `LocaleType` 값을 전달하십시오.

- **모든 제품: UI**: `locale`은 메뉴, 도구 설명, 대화 상자와 플러그인 레이블의 번역을 바꿉니다. 사용자 콘텐츠나 기존 단위 이름은 바꾸지 않습니다.
- **장: 세포 체재 및 공식**: 셀 번호와 날짜는 숫자 체재 locale override로 첫째로, 그 후에 workbook 스냅샷 `locale`, 그 후에 `locale`. `region`는 이 조정의 무엇이든을 대체하지 않습니다. `DOLLAR`와 같은 공식적인 행동은 재정적인 결과에 적용된 통화 체재 아직도 CJK 입력 정상화와 같이 `locale`를 사용합니다.
- **Docs: 통계** : `locale`는 단어가 구분되고 계산되는 방법을 결정합니다.

### 실행 중 언어 변경

전환 언어 전에, 설치된 플러그인 또는 사전 설정에 대한 모든 언어 팩을로드합니다. `loadLocales()`는 전환없이 번역을 병합하고 `setLocale()`은 아무것도 다운로드하지 않고 언어를 선택합니다. 일치가있는 번역 키는 키 자체로 표시됩니다. 다음과 같은 예는 공유 UI 팩 만로드합니다. 다른 설치된 플러그인에 대한 대상 언어 팩을 병합하십시오.

```typescript
import { LocaleType, mergeLocales } from '@univerjs/core'
import UIEnUS from '@univerjs/ui/locale/en-US'

univerAPI.loadLocales(LocaleType.EN_US, mergeLocales(UIEnUS))
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentLocale()) // enUS
```

### 플러그인 모드에서 언어 팩 등록하기

플러그인 모드에서, 해당 플러그인에서 언어 팩을 가져 와서 단일 객체로 병합하고 `Univer` 인스턴스에 해당 객체를 전달합니다.

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import DesignEnUS from '@univerjs/design/locale/en-US' // [!code highlight]
import SheetsUIEnUS from '@univerjs/sheets-ui/locale/en-US' // [!code highlight]
import UIEnUS from '@univerjs/ui/locale/en-US' // [!code highlight]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DesignEnUS, // [!code highlight]
      UIEnUS, // [!code highlight]
      SheetsUIEnUS, // [!code highlight]
    ),
  },
})
```

<Callout type="warning" title="주 메뉴">
  모든 플러그인에는 언어 팩이 포함되어 있습니다. 각 기능 페이지는 그것이 있는지 여부를 나타냅니다.
</Callout>

### 프리셋 모드에서 언어 팩 등록하기

Preset 패키지는 이미 플러그인에 대한 언어 팩을 포함. 미리 설정에서 가져 오기 :

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US' // [!code highlight]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS, // [!code highlight]
    ),
  },
  presets: [UniverSheetsCorePreset()],
})
```

### 사용자 지정 언어 팩

사용자 정의 언어 팩도 내장 될 수 있습니다. 필요한 언어 팩 개체를 조립하고 `Univer` 인스턴스로 전달하십시오. 사전 설정 언어 팩은 일반적으로 `<rootDir>/packages/<PLUGIN_NAME>/locale` 디렉토리에 남아 있습니다.

```typescript
import { LocaleType, Univer } from '@univerjs/core'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: {
      ui: {
        shortcut: {
          undo: '元に戻す',
          redo: 'やり直す',
        },
      },
    },
  },
})
```

### 번역 기여하기

Univer는 현재 다음과 같은 기본 제공 언어 팩을 지원합니다.

- `zh-CN`: 중국어 간체
- `en-US`: 영어
- `zh-TW`: 중국어 번체
- `zh-HK`: 중국어 번체(홍콩)
- `ru-RU`: 러시아어
- `vi-VN`: 베트남어
- `fa-IR`: 페르시아어
- `fr-FR`: 프랑스어
- `ja-JP`: 일본어
- `ko-KR`: 한국어
- `es-ES`: 스페인어
- `ca-ES`: 카탈루냐어
- `sk-SK`: 슬로바키아어
- `ar-SA`: 아랍어
- `de-DE`: 독일어
- `id-ID`: 인도네시아어
- `it-IT`: 이탈리아어
- `pl-PL`: 폴란드어
- `pt-BR`: 포르투갈어(브라질)

Univer는 오픈 소스이며, 새로운 로컬을 추가하거나 기존의 것을 개선하기 위해 어디에서든지 개발자를 환영합니다.

## 지역 설정

`region`는 지역 기능 사용의 지역 협약을 선택합니다. 동일한 Univer 인스턴스의 모든 단위는 그것을 공유합니다.

설정 모두에 대한 `LocaleType` 값을 전달합니다. 예를 들어 `LocaleType.EN_US`은 `enUS`이며, `en-US`는 언어 팩 파일 이름과 BCP 47 태그입니다. `US` 또는 `SG`과 같은 국가 코드를 `region`으로 전달하지 마십시오. UI가 다른 Locale을 사용하는 경우 지역은 해당 언어 팩이 필요하지 않습니다.

`region`를 명시하지 않고 설정은 나중에 `setLocale()` 통화를 포함하여 `locale`을 따릅니다. 초기화에서 `region` 설정 또는 `setRegion()` 호출을 설정하면 자동이 다음으로 유지되고 나중에 언어가 선택한 지역을 유지한다는 것을 중지합니다. 공개 API는 다음과 같이 자동 복원하지 않기 때문에 변경할 때 두 값을 업데이트합니다.

`createUniver()` 또는 `new Univer()` 중 `locale` 옆에 `region: LocaleType.DE_DE`를 추가하여 독일 지역 컨벤션을 사용하여 UI 언어를 유지하십시오.

```typescript
import { LocaleType } from '@univerjs/core'

univerAPI.setRegion(LocaleType.DE_DE)
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentRegion()) // deDE
```

여기에서 UI는 영어로 전환합니다. 지역 형식화는 독일어입니다. `getCurrentLocale()` 및 `getCurrentRegion()`는 실제로 효과가 있는 식별자를 반환합니다. 두 설정을 모두 변경하려면, 동일한 `LocaleType` 값을 가진 setters를 모두 호출하십시오.

- **시트: 통화 통제**: `region`는 통화 툴바 아이콘, 통화 및 회계 선택 및 미리보기를 제어하고 통화 명령이 적용된 형식을 지정합니다. 기존의 셀 형식을 다시 작성하지 않거나 통화 값을 변환하지 않습니다.
- **Docs: 통계**: `region`는 통계 대화 상자 및 상태 표시 줄에 표시된 수를 그룹화 분리기와 같은 배열합니다. `region`를 바꾸는 것은 계산 규칙을 바꾸지 않습니다.
- **스레드 의견, 활성화시**: `region`는 표시된 날짜와 시간 체재를 통제합니다, 24 시간 시간 시간 및 라틴 손가락을 사용하고, `locale`은 코멘트 UI 원본을 통제합니다. 더구나 변화 저장한 타임스탬프 및 `region`에는 시간대 조정이 아닙니다.
- **보드, 슬라이드,베이스, PDF**: `locale`는 번역한 UI를 통제합니다. `region`은 통합된 실 의견과 같은 그것을, 그러나 자동적인 reformat 널 또는 활주 원본, 기본적인 분야, 또는 PDF 내용과 같은 공유한 특징에 유효합니다.

## 오른쪽에서 왼쪽으로 배치

<Callout type="warning" title="주의">
  현재 RTL은 UI 계층만 지원하며 렌더링 계층은 지원하지 않습니다.
</Callout>

레이아웃 방향은 별도 설정입니다. 초기화에 `direction`를 설정하거나 `univerAPI.setDirection('rtl')` / `setDirection('ltr')`로 전화하십시오. `locale` 또는 `region`을 변경하면 레이아웃 방향을 전환하지 않습니다.

```typescript
univerAPI.setDirection('rtl')
```
