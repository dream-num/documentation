透過 Facade API，將活頁簿資料讀寫、格式設定與編輯器事件接入業務流程。常用操作依活頁簿、工作表和範圍組織，可從對應物件找到方法。

依下方整合模式取得 `univerAPI`，或直接查看[如何尋找 API 或命令](#find-apis-and-commands)。

<Callout type="warning" title="注意事項">
  呼叫傳回 Promise 的方法時，先以 `await` 或 `.then()` 等待完成，再讀取結果或執行相依步驟。其他方法直接傳回值或 Facade 物件，請以 API 的傳回型別為準。
</Callout>

## 外掛模式引入 Facade API

### 安裝

對於透過外掛模式安裝 Univer 的情況，Facade API 的實作分散在各個外掛中，並掛載到全域的 Facade API 根物件上。這代表對於那些提供 Facade API 的外掛，你可以按需引入其對應的 Facade API 實作。

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs/ui/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="注意事項">
  並非所有外掛都包含 facade 套件；我們會在每個功能的文件中加以說明。
</Callout>

### 使用

Facade API 是對 Univer 實例的封裝，因此你需要在建立 Univer 實例之後，再用 `FUniver` 包裹該實例：

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 預設模式引入 Facade API

如果你透過預設模式安裝 Univer，它會自動引入所含功能的 Facade API，並在你建立 Univer 實例時回傳對應的 Facade API 實例 `univerAPI`，可直接使用。

## 注意事項

並非所有的 Facade API 都能即時呼叫，有些 API 需要在特定的生命週期階段才能使用。若遇到即時執行無法生效的情況，請參考以下方式在合適的生命週期中執行：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // 在生命週期 Rendered 階段執行的程式
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // 在生命週期 Steady 階段執行的程式
  }
})
```

## 尋找 API 或命令 [#find-apis-and-commands]

先從功能指南找到任務，再透過 Facade 參考定位[活頁簿](/reference/facade/workbook)、[工作表](/reference/facade/worksheet)或[範圍](/reference/facade/range)的方法。必須註冊所屬外掛；外掛模式也需匯入對應 Facade。

Facade 未涵蓋任務時，在[所屬套件參考](/reference/packages/plugins/univerjs/sheets)中尋找匯出的命令，使用其 `.id`。選單項目 ID、命令與 Mutation 是不同概念，不要依工具列文字猜測命令 ID。

```typescript
import { SetRangeValuesCommand } from '@univerjs/sheets'

console.log(SetRangeValuesCommand.id)
```

先註冊下方監聽器，再於編輯器操作並查看輸出，即可確認互動執行的命令。監聽不會執行命令，也不表示觀察到的 Mutation 都適合直接呼叫。

```typescript
const commandLog = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type }) => {
  console.log(id, type)
})
```

排查結束後移除監聽。命令註冊、參數與復原重做見[自訂命令](/blog/custom-command)。

```typescript
commandLog.dispose()
```
