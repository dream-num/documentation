Univer의 아키텍처는 복잡한 요구 사항을 수용하고 핵심 API는 복잡성을 반영합니다. Univer는 따라서 Facade API를 제공하므로 응용 코드가 직접 호출하는 간단한 레이어입니다.

이 페이지는 Facade API를 응용 프로그램에 추가하는 방법을 설명합니다. 기능 섹션의 페이지는 각 기능에 대한 주요 Facade API를 나열합니다. 완전한 세트의 경우 각 플러그인의 API 참조를 참조하십시오.

<Callout type="warning" title="주 메뉴">
  일부 Facade API는 비동기이며, 데이터를 종종 Promise로 반환하는 것을 수정하는 것은 하나입니다. 데이터가 변경된 후 즉시 읽을 때 `await` 통화 또는 체인 `.then()`; 그렇지 않으면 결과가 예상치 못한 일 수 있습니다. API가 Promise를 반환하는지 결정하려면 해당 API 참조를 참조하십시오.
</Callout>

## 플러그인 모드에서 Facade API 통합하기

### 설치

플러그인 모드에서 각 플러그인은 자체 Facade API 구현을 발송하고, 모든 것은 하나의 글로벌 Facade API 객체에 첨부됩니다. Facade API를 제공하는 모든 플러그인의 경우, 필요에 따라 일치하는 구현을 가져다줍니다.

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs/ui/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="주 메뉴">
  모든 플러그인에는 전면 패키지가 포함되어 있지 않습니다. 각 기능 페이지는 그것이 있는지 여부를 나타냅니다.
</Callout>

### 사용법

Facade API는 Univer 인스턴스를 포장합니다. 먼저 인스턴스를 만들고 `FUniver`로 포장하십시오.

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 프리셋 모드에서 Facade API 통합하기

미리 설정 모드에서, 미리 설정은 포함 된 기능을 위해 Facade API를 가져옵니다. Univer 인스턴스를 생성하면 즉시 사용할 수있는 `univerAPI` 예를 일치합니다.

## 주의 사항

모든 Facade API는 즉시 호출 할 수 없습니다. 일부 특정 라이프 사이클 단계에서만 영향을받습니다. 즉각적인 통화가 영향을받지 않으면 적절한 단계를 다음과 같이 선택하십시오.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Code to be executed when the lifecycle stage is Rendered
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Code to be executed when the lifecycle stage is Steady
  }
})
```
