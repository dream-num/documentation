Facade API로 통합 문서 데이터 읽기·쓰기, 서식 지정, 편집기 이벤트를 업무 흐름에 연결하세요. 일반 작업은 [통합 문서](/reference/facade/workbook), [워크시트](/reference/facade/worksheet), [범위](/reference/facade/range) 객체별로 정리되어 있습니다.

<Callout type="warning" title="주의">
  Promise를 반환하는 메서드는 `await` 또는 `.then()`으로 완료를 기다린 뒤 결과를 읽거나 후속 작업을 실행하세요. 다른 메서드는 값이나 Facade 객체를 바로 반환합니다. 각 API의 반환 타입을 확인하세요.
</Callout>

## 플러그인 모드에서 Facade API 통합하기

### 설치

플러그인 모드로 설치한 Univer에 Facade API를 통합할 때는 Facade API 구현이 여러 플러그인에 나뉘어 있으며 전역 Facade API 루트 객체에 마운트됩니다. 따라서 Facade API를 제공하는 플러그인은 필요에 따라 해당 Facade API 구현을 가져올 수 있습니다.

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs/ui/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="주의">
  모든 플러그인에 facade 패키지가 포함되는 것은 아닙니다. 포함 여부는 각 기능의 문서에 명시되어 있습니다.
</Callout>

### 사용법

Facade API는 Univer 인스턴스를 감싸는 래퍼이므로, Univer 인스턴스를 생성한 후 `FUniver`로 감싸야 합니다.

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 프리셋 모드에서 Facade API 통합하기

프리셋 모드로 Univer를 통합하면 포함된 기능의 Facade API를 자동으로 가져옵니다. Univer 인스턴스를 생성할 때 해당 Facade API 인스턴스인 `univerAPI`가 반환되므로 바로 사용할 수 있습니다.

## 주의 사항

모든 Facade API를 즉시 호출할 수 있는 것은 아니며, 일부 API는 특정 수명 주기 단계에서 사용해야 합니다. 즉시 실행할 때 문제가 발생한다면 다음 방법을 참고하여 실행에 적합한 수명 주기 단계를 선택하세요.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Code to be executed when the lifecycle stage is Rendered
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Code to be executed when the lifecycle stage is Steady
  }
})
```
