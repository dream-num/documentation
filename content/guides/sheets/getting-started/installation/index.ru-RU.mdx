Univer — это фреймворк для приложений электронных документов, и он собирается из плагинов. Ядро остается небольшим, а приложение добавляет только те модули, которые ему нужны. Компромисс — это более вовлеченная настройка, особенно при работе с Univer впервые.

Чтобы уменьшить это усилие, Univer предоставляет два стиля интеграции: **режим плагинов** и **заданный режим**. A **предустановленный** представляет собой набор плагинов, настроенных заранее, поэтому без пользовательских расширений оба режима обеспечивают одинаковые возможности.

<Callout type="warning" title="Внимание">
  - **Поддерживайте синхронизацию версий зависимостей.** В любом режиме каждая зависимость должна разрешаться в одной и той же версии.
  - **Смешайте плагины и предустановки с осторожностью.** Если предустановка уже включает плагин, не импортируйте этот плагин отдельно.
</Callout>

Эти два режима различаются следующим образом:

| Режим плагинов | Режим предустановок |
| --- | --- |
| Вы сами импортируете необходимые пакеты фасадов | Фасадные пакеты поставляются с предустановленным |
| Вы контролируете порядок регистрации плагинов, которые обеспечивают ту же функциональность. | Предустановленный уже обрабатывает заказ на регистрацию |
| Плагины могут быть ленивыми по требованию | Настроенные предустановки загружаются синхронно во время инициализации |

Предустановленный режим сохраняет настройку короткой: один импорт приносит в комплект предустановленных плагинов. Для **Глубокая настройка или расширения** используйте режим плагина, который позволяет комбинировать плагины и настраивать их индивидуально.

## Интеграция с помощью Agent (необязательно) [#agent-skills]

Используйте [`univer-integrate`](https://github.com/dream-num/skills/tree/main/skills/univer-integrate) при добавлении Web SDK в существующее приложение. Он направляет агент кодирования через настройку предустановленного или плагина, инициализацию редактора и использование Facade API.

```bash
npx skills add dream-num/skills --skill univer-integrate
```

Запустите эту команду в директории проекта, которую открыл агент. Добавьте `-g` для использования навыка в проектах или укажите агента с `-a codex` или `-a claude-code`. Затем перечислите установленные навыки:

```bash
npx skills list
```

Список должен включать `univer-integrate`. Если навык отсутствует, проверьте, что `SKILL.md` существует на пути установки, и при необходимости вновь откройте сеанс агента.

В более старых учебниках можно ссылаться на `dream-num/univer-sdk-skills`. Используйте текущую команду `dream-num/skills`, показанную выше; имя навыка остается `univer-integrate`; Проверьте базовую линию SDK, которую ожидает навык, и интегрируйте с текущей документацией и версиями, установленными в вашем проекте.

## Настройка в режиме плагинов

Univer предоставляет свои функции в качестве плагинов. Для функционирования продукта требуется несколько основных плагинов; остальные плагины импортируются по мере необходимости. Этот раздел создает минимальное приложение Univer Sheets вручную и регистрирует свои плагины один за другим.

В отличие от предустановленного режима, режим плагина по умолчанию не включает Facade API[^facade-entry].Связанные с Фасадом части кода ниже являются необязательными и могут быть удалены, когда в этом нет необходимости.

### Использование менеджера пакетов

#### Установка

Univer использует React для своих представлений (это не мешает использовать его в Vue или Angular) и Rxjs для потоков данных. Обе библиотеки широко используются в современной фронтенд-разработке, поэтому Univer рассматривает их как peerDependencies[^peer-dependency]. Менеджеры пакетов по-разному обрабатывают зависимости от пиров, и несколько деталей требуют внимания:

<Callout>
  - При npm используйте npm@7 или более поздней версии. npm @ 3 ~ npm_6 не устанавливайте `peerDependencies`[^1] правильно.
  - С pnpm, используйте pnpM@8 или более поздней версии.На pnpм@6 ~ pnppm@7 установка `auto-install-peers=true` [^2] может решить проблемы установки зависимостей.
  - С пряжей устанавливайте недостающие `peerDependencies`[^3] вручную.Командировки установки ниже уже включают их.
</Callout>

#### Методы `univer.registerPlugin` и `univer.registerPlugins` [#registerPlugin]

Метод `univer.registerPlugin` регистрирует плагин с экземпляром Univer. Позвоните ему после создания экземпляра.

Передайте плагин и его параметры: `univer.registerPlugin(Plugin, options)`. `Plugin` - это плагин для регистрации, а `options` - это дополнительные элементы конфигурации, которые отличаются от одного плагина к другому.

Чтобы зарегистрировать сразу несколько плагинов, передайте массив в `univer.registerPlugins`. Этот подход полезен, когда плагины управляются в одном месте.

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  UniverFormulaEnginePlugin,
  [UniverUIPlugin, {
    container: 'app',
  }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverSheetsPlugin,
  UniverSheetsUIPlugin,
  UniverSheetsFormulaPlugin,
  UniverSheetsFormulaUIPlugin,
  UniverSheetsNumfmtPlugin,
  UniverSheetsNumfmtUIPlugin,
])
```

#### Отложенная загрузка плагинов

Ключевым преимуществом режима плагина является контроль при загрузке плагинов.Обычный шаблон загружает только необходимые плагины во время инициализации и откладывает остальные до первого рендеринга.

```typescript
// ...

univer.createUnit(UniverInstanceType.UNIVER_SHEET, {})

import('@univerjs/watermark').then(({ UniverWatermarkPlugin }) => {
  univer.registerPlugin(UniverWatermarkPlugin, {
    textWatermarkSettings: {
      content: 'Hello, Univer!',
      fontSize: 36,
    },
  })
})
```

[Официальная демонстрация](https://github.com/dream-num/univer/blob/0d849012594882307186f33734b8b89d80a729e9/examples/src/sheets/main.ts) применяет ту же оптимизацию и заслуживает рассмотрения.

### Поддержка мобильных устройств [#mobile-support]

<Callout type="warning">
  Для примеров нужны пакеты SDK, экспортирующие перечисленные мобильные плагины. Все зависимости `@univerjs/*` и `@univerjs-pro/*` должны иметь **одинаковую версию**.
</Callout>

**Мобильные плагины UI** предоставляет сенсорные элементы управления в Univer Sheets.[^mobile-ui-mode] Выберите режим пользовательского интерфейса перед созданием редактора.

Мобильная поддержка Sheets остается **экспериментальный**. Проверьте функции, которые требуются вашему приложению на устройствах, на которые вы ориентируетесь.

В примере с плагин-режимом, приведенном выше, **заменить** импортирует пользовательский интерфейс и регистрации с теми, которые ниже, до `createUnit()`. Не добавляйте их к настольному редактору, который уже был инициализирован. Сохраняйте плагины модели, движки, локальные файлы, CSS и импорт Facade. Настольные и мобильные классы называются экспортом **та же самая упаковка** .

`UniverMobileUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для размещения редактора или его идентификатор. |
| `disableAutoFocus` | `true` | `true` | Отключает автоматический фокус редактора при запуске. |

```typescript
import { UniverDocsMobileUIPlugin } from '@univerjs/docs-ui'
import { UniverSheetsFormulaMobileUIPlugin } from '@univerjs/sheets-formula-ui'
import { UniverSheetsNumfmtMobileUIPlugin } from '@univerjs/sheets-numfmt-ui'
import { UniverSheetsMobileUIPlugin } from '@univerjs/sheets-ui'
import { UniverMobileUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverMobileUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsMobileUIPlugin)
univer.registerPlugin(UniverSheetsMobileUIPlugin)
univer.registerPlugin(UniverSheetsFormulaMobileUIPlugin)
univer.registerPlugin(UniverSheetsNumfmtMobileUIPlugin)
```

На мобильном телефоне также заменяйте `UniverDocsUIPlugin` на `UniverDocsMobileUIPlugin`, чтобы можно было редактировать документы внутри ячеек и регистрировать их перед `UniverSheetsMobileUIPlugin`.

`UniverSheetsCorePreset` и `UniverDocsCorePreset` в настоящее время регистрируют плагины пользовательского интерфейса рабочего стола и не имеют опции `mobile: true`. Для мобильных устройств сборка плагинов явно. Добавление мобильных плагинов после предустановки рабочего стола не заменяет пользовательский интерфейс предустанавливаемого устройства.

#### Контейнер и сенсорное управление

Установите явную высоту для контейнера и настройте порт просмотра страницы. `100dvh` отслеживает динамическую высоту порта просмотра. В целевых мобильных браузерах проверьте прокрутку, щипковый зум, выбор текста, доступ к буферу обмена и экранную клавиатуру. Изменение размера только настольного редактора не выбирает мобильные плагины.

`UniverMobileUIPlugin` по умолчанию выполняется `disableAutoFocus: true`, поэтому редактор не фокусируется автоматически во время инициализации.

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
<div id="app" style="height: 100dvh"></div>
```

## Настройка в режиме предустановок

Предустановленный режим создает запущенное приложение Univer Sheets в двадцати строках кода.

### Использование менеджера пакетов

Если в проекте уже используется современный интерфейсный инструментарий, интеграция Univer проста. Используйте инструмент сборки с поддержкой твердого модуля ES, например [Вкусно](https://vitejs.dev/), [строить](https://esbuild.github.io/) или [Webpack 5](https://webpack.js.org/). Более старые инструменты, такие как Webpack 4, могут потребовать дополнительной конфигурации.

#### Установка

Установите `@univerjs/presets` с помощью менеджера пакетов:

```package-install
npm install @univerjs/presets @univerjs/preset-sheets-core
```

#### Использование

<Callout type="warning">
  Если инструмент сборки не поддерживает поле `exports` в package.json (обычно с Webpack 4), измените отображенные пути на фактические пути вручную.
</Callout>

Этих двух файлов достаточно для запуска приложения Univer Sheets:

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'

const { univer, univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
    ),
  },
  presets: [
    UniverSheetsCorePreset({
      container: 'app',
    }),
  ],
})

univerAPI.createWorkbook({})
```

#### Метод `createUniver`

`createUniver` принимает объект конфигурации, который содержит настройки для Univer, такие как язык, тема и плагины. Он возвращает объект, который содержит экземпляр Univer и экземпляр Univer Facade API.

Основными свойствами являются:

- `locale`: языковая среда, как значение `LocaleType`.
- `locales`: объект локальных пакетов, управляемый языковой средой.
- `theme`: дополнительный объект темы.
- `presets`: предустановки для регистрации, такие как `UniverSheetsCorePreset`.
- `plugins`: плагины для регистрации в дополнение к предустановкам.

Когда плагин не принадлежит к какому-либо предустановленному пакету, или когда вы пишете свой собственный, зарегистрируйте его через свойство `plugins`. Вы также можете позвонить `univer.registerPlugin` после получения экземпляра Univer .

<Callout>
  Подробнее о `createUniver` см. в разделе [Ссылка на API / CreateUniver](https://docs.univer.ai/reference/methods/create-univer).
</Callout>

## Другие каналы выпуска

Помимо стабильных релизов, Univer предоставляет альфа-, бета- и ночные каналы. Эти сборки предлагают ранний доступ к новым функциям, прежде чем они будут выпущены как стабильные. Больше функций также приносят больше риска: эти версии могут содержать ошибки, неполную функциональность или неустойчивое поведение. Избегайте их в производстве, где это возможно.

### Выпуски Alpha / Beta

Когда команда Univer завершает новую функцию или существенное изменение, она может предварительно выпустить изменение на альфа- или бета-канал.

```package-install
npm install @univerjs/<package-name>@alpha # Alpha version
npm install @univerjs/<package-name>@beta # Beta version
```

Если вы столкнулись с проблемой или получили обратную связь при использовании альфа- или бета-версии, сообщите об этом команде Univer через [Обсуждение GitHub](https://github.com/dream-num/univer/issues).
