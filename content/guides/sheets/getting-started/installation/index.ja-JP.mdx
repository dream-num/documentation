title: インストールと基本的な使い方
---

Univerは電子文書アプリケーション用のフレームワークであり、プラグインから組み立てられます。コアは小さく、アプリケーションは必要なモジュールだけを追加します。トレードオフは、特に初めてUniverで作業するときに、より関与したセットアップです。

Univer は、**プラグインモード**と**プリセットモード**の2つの統合スタイルを提供します。 **プリセット**は、事前に設定されたプラグインのセットです。そのため、両方のモードをカスタム拡張することなく、同じ機能を提供します。

<Callout type="warning" title="注意事項">
  - **依存関係バージョンを同期に保ちます。** どちらのモードでも、すべての依存性は同じバージョンに解決しなければなりません。
  - **プラグインとプリセットをケアでミックスします。** プリセットがすでにプラグインが含まれている場合は、プラグインを別々にインポートしないでください。 それ以外のプラグインの競合や予期しない機能の動作が発生する可能性があります。
</Callout>

2つのモードは次の通りです。

| プラグインモード | プリセットモード |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 必要なファサードパッケージを自分でインポートする | ファサードパッケージにはプリセットが付属しています |
| 同じ機能を提供するプラグインの登録順を制御します。 | プリセットは既に登録順を処理します |
| プラグインは、要求に応じてレイジーロードすることができます | 初期化時に同期的にプリセットロードを設定 |

プリセットモードは、セットアップを短く保ちます。単一のインポートは、あらかじめ設定されたプラグインのバンドルをもたらします。**深いカスタム化か延長**では、プラグインモードを使用して、プラグインを個別に組み合わせて構成することができます。

## Agent による導入支援（任意） [#agent-skills]

Web SDKを既存のアプリケーションに追加するときに[`univer-integrate`](https://github.com/dream-num/skills/tree/main/skills/univer-integrate)を使用します。 これは、プリセットまたはプラグインのセットアップ、エディタの初期化、Facade APIの使用によるコーディングエージェントを導きます。

```bash
npx skills add dream-num/skills --skill univer-integrate
```

エージェントが開いているプロジェクトディレクトリでこのコマンドを実行します。 `-g` を追加して、プロジェクト全体でスキルを使用するか、`-a codex`または`-a claude-code`でエージェントを指定してください。 次に、インストールされたスキルをリストします。

```bash
npx skills list
```

リストには、`univer-integrate` を含める必要があります。 スキルが不足している場合は、インストールパスに `SKILL.md`が存在することを確認し、必要に応じてエージェントセッションを再オープンしてください。

古いチュートリアルでは、`dream-num/univer-sdk-skills`を参照することができます。 上記の現在の`dream-num/skills`コマンドを使用して、スキル名は`univer-integrate`のままです。 スキルが期待するSDKベースラインを確認し、現在のドキュメントとプロジェクトにインストールされているバージョンと統合します。

## プラグインモードでのセットアップ

Univerは、プラグインとして機能を提供します。製品の機能には、いくつかのコアプラグインが必要です。残りのプラグインは必要に応じてインポートされます。このセクションでは、Univerシートアプリケーションを手動で構築し、プラグインを1つずつ登録します。

プリセットモードとは異なり、プラグインモードにはデフォルトではFacade API[^facade-entry]は含まれません。 必要に応じて、以下のコードのファサード関連部分がオプションで削除できます。

### パッケージマネージャーの使用

#### インストール

Univerは、Reactを使用して、そのビュー(これはVueまたはAngularでの使用を防止しません)とRxjsは、データストリーム用のRxjsを使用します。 両方のライブラリは、現代のフロントエンド開発で広く使用されているため、Univerでは、ピアDepend[^peer-dependency]としてそれらを扱います。 パッケージマネージャは、異なるピアの依存関係を扱い、いくつかの詳細は注意が必要です。

<Callout>
  - npm@7以降はnpm@3〜npm@6は`peerDependencies`[^1]を正しくインストールしません。
  - pnpm では pnpm@8 以降を使用します。 pnpm @6 ～ pnpm®7 では、`auto-install-peers=true` [^2] の設定で、依存関係のインストールの問題が解決できます。
  - 糸で、欠落している`peerDependencies`[^3]を手動で取付けて下さい。 下の取付けの命令はそれらを既に含んでいます。
</Callout>

#### `univer.registerPlugin` と `univer.registerPlugins` メソッド [#registerPlugin]

`univer.registerPlugin`メソッドは、Univerインスタンスでプラグインを登録します。インスタンスが作成された後に呼び出します。

プラグインとそのオプションを渡します: `univer.registerPlugin(Plugin, options)`. `Plugin` は、登録するプラグインであり、`options`は、一つのプラグインと異なるオプションの設定項目です。

一度に複数のプラグインを登録するには、配列を `univer.registerPlugins` に渡します。プラグインが 1 つの場所で管理されると、このアプローチは便利です。

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  UniverFormulaEnginePlugin,
  [
    UniverUIPlugin,
    {
      container: 'app',
    },
  ],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverSheetsPlugin,
  UniverSheetsUIPlugin,
  UniverSheetsFormulaPlugin,
  UniverSheetsFormulaUIPlugin,
  UniverSheetsNumfmtPlugin,
  UniverSheetsNumfmtUIPlugin,
])
```

#### プラグインの遅延読み込み

プラグインモードの重要な利点は、プラグインがロードしたときに制御されます。 一般的なパターンは、初期化中に重要なプラグインのみをロードし、最初のレンダーが終わるまで残りをデフラグします。

```typescript
// ...

univer.createUnit(UniverInstanceType.UNIVER_SHEET, {})

import('@univerjs/watermark').then(({ UniverWatermarkPlugin }) => {
  univer.registerPlugin(UniverWatermarkPlugin, {
    textWatermarkSettings: {
      content: 'Hello, Univer!',
      fontSize: 36,
    },
  })
})
```

[公式デモ](https://github.com/dream-num/univer/blob/0d849012594882307186f33734b8b89d80a729e9/examples/src/sheets/main.ts)は同じ最適化を適用し、検討する価値があります。

### モバイル対応 [#mobile-support]

<Callout type="warning">
  以下のモバイルプラグインをエクスポートする SDK パッケージが必要です。すべての `@univerjs/*` と `@univerjs-pro/*` の依存関係を**同じバージョン**に揃えてください。
</Callout>

**モバイルUIプラグイン**は、Univer Sheets.[^mobile-ui-mode] エディタを作成する前に、UIモードを選択します。

シートのモバイルサポートは、**実験的**を維持します。 アプリケーションがターゲットのデバイス上で必要とする機能をテストします。

上記のプラグインモードの例では、**交換する** では、UI のインポートと登録を `createUnit()`. 既に初期化されているデスクトップエディタにそれらを追加しないでください。 モデルプラグイン、エンジン、ローカファイル、CSS、ファサードのインポートを保持します。 デスクトップとモバイルクラスは、**同じパッケージエントリ**のエクスポートと名付けられています。

`UniverMobileUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターのマウント先となる DOM 要素、またはその ID。 |
| `disableAutoFocus` | `true` | `true` | 起動時にエディターへの自動フォーカスを抑止します。 |

```typescript
import { UniverDocsMobileUIPlugin } from '@univerjs/docs-ui'
import { UniverSheetsFormulaMobileUIPlugin } from '@univerjs/sheets-formula-ui'
import { UniverSheetsNumfmtMobileUIPlugin } from '@univerjs/sheets-numfmt-ui'
import { UniverSheetsMobileUIPlugin } from '@univerjs/sheets-ui'
import { UniverMobileUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverMobileUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsMobileUIPlugin)
univer.registerPlugin(UniverSheetsMobileUIPlugin)
univer.registerPlugin(UniverSheetsFormulaMobileUIPlugin)
univer.registerPlugin(UniverSheetsNumfmtMobileUIPlugin)
```

モバイルでは、`UniverDocsUIPlugin`を`UniverDocsMobileUIPlugin`に置き換えて、セル内の文書を編集し、`UniverSheetsMobileUIPlugin`の前に登録することもできます。

`UniverSheetsCorePreset`と`UniverDocsCorePreset`は現在デスクトップUIプラグインを登録し、`mobile: true`オプションはありません。 モバイルの場合、プラグインを明示的に組み立てます。 デスクトッププリセット後にモバイルプラグインを追加すると、プリセットのUIを交換しません。

#### コンテナーとタッチ操作

コンテナの明示的な高さを設定し、ページビューポートを設定します。 `100dvh`は、動的ビューポート高さを追跡します。 ターゲットモバイルブラウザでは、スクロール、ピンチズーム、テキスト選択、クリップボードアクセス、および画面上のキーボードを確認します。 デスクトップエディタを単独で再サイズ変更することは、モバイルプラグインを選択していません。

`UniverMobileUIPlugin` のデフォルトは `disableAutoFocus: true`、従って編集者は初期化の間に自動的に焦点を合わせません。

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
<div id="app" style="height: 100dvh"></div>
```

## プリセットモードでのセットアップ

プリセットモードは、コードの20行で実行中のUniverシートアプリケーションを生成します。

### パッケージマネージャーの使用

このプロジェクトがすでに現代のフロントエンドツーリングを使用している場合は、Univerの統合は簡単です。 [ツイート](https://vitejs.dev/)、[エスビルド](https://esbuild.github.io/)などの固体ESモジュールのサポートを備えたビルドツールを使用して、または[ウェブパック 5](https://webpack.js.org/)。 Webpack 4などの古いツールは、追加の構成を必要とする場合があります。

#### インストール

パッケージマネージャで`@univerjs/presets`をインストールします。

```package-install
npm install @univerjs/presets @univerjs/preset-sheets-core
```

#### 使い方

<Callout type="warning">
  ビルドツールがpackage.json で `exports` フィールドをサポートしていない場合(Webpack 4) では、マップされたパスを手動で変更します。
</Callout>

これらの2つのファイルは、Univerシートアプリケーションを起動するのに十分です。

```html title="index.html"
<div id="app" style="height: 600px"></div>
```

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreJaJP from '@univerjs/preset-sheets-core/locales/ja-JP'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'

const { univer, univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(UniverPresetSheetsCoreJaJP),
  },
  presets: [
    UniverSheetsCorePreset({
      container: 'app',
    }),
  ],
})

univerAPI.createWorkbook({})
```

`univerAPI`オブジェクトはUniver Facade APIです。 Univerが提供する機能を呼び出すインターフェイスです。

| `container` | `string \| HTMLElement` | `'app'` | エディターのマウント先となる DOM 要素、またはその ID。 |

#### `createUniver` メソッド

`createUniver`は、言語、テーマ、プラグインなどのUniverの設定を含む構成オブジェクトを受け入れます。 UniverインスタンスとUniver Facade APIのインスタンスを含むオブジェクトを返します。

主な特性は次のとおりです。

- `locale`: `LocaleType` の値として言語環境。
- `locales`: locale パックのオブジェクト、言語環境でキードされます。
- `theme`:オプションのテーマオブジェクト。
- `presets`:`UniverSheetsCorePreset`などの登録プリセット。
- `plugins`:プリセットに加えてプラグインを登録します。

プラグインがプリセットパッケージに所属していない場合、または自分で書いた場合は、`plugins`プロパティで登録してください。 Univerインスタンスを取得した後、`univer.registerPlugin`を呼び出すこともできます。

<Callout>
  `createUniver`の詳細は、[APIリファレンス/createUniver](https://docs.univer.ai/reference/methods/create-univer)を参照してください。
</Callout>

パッケージマネージャを使いたくない、またはUniverをすぐに試したいなら、CDNからロードできます。詳細は[CDN による Univer の使用](/guides/sheets/getting-started/installation/cdn#plugin-mode)で提供されます。

## その他のリリース

Univerは、安定したリリースを超えて、アルファ、ベータ、およびナイトリーチャンネルを提供します。 これらのビルドは、安定したようにリリースされる前に、新しい機能への早期アクセスを提供します。 これらのバージョンには、バグ、不完全な機能、または不安定な動作が含まれている場合があります。 可能な限り生産でそれらを避けてください。

### Alpha/Beta リリース

Univer チームが新しい機能または重要な変更を完了すると、アルファまたはベータチャネルの変更をプレリリースできます。 alpha またはベータビルドをインストールします。

```package-install
npm install @univerjs/<package-name>@alpha # Alpha バージョン
npm install @univerjs/<package-name>@beta # Beta バージョン
```

アルファまたはベータ版を使用して問題に遭遇するか、フィードバックがあれば、それをに報告して下さい Univer チームを通して [GitHubの問題](https://github.com/dream-num/univer/issues).
