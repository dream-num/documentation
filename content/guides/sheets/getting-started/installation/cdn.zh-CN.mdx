先运行完整示例，再复制到自己的页面中。示例已经包含可编辑表格和公式计算所需的依赖、样式、语言包与 Facade 注册。

## 先体验一张可编辑的表格

1. [打开示例](/assets/examples/cdn/sheets.zh-CN.html)，或下载下方 HTML，保存为 `index.html`。
2. 使用可联网的现代浏览器打开，无需构建工具或服务端。示例界面和表格内容均为简体中文。
3. 笔记本的合计为 **36**。把数量从 **3** 改成 **4**，合计会更新为 **48**；也可以编辑其他单元格并撤销修改。

## 完整 HTML 示例 [#plugin-mode]

本例使用 **React 18.3.1 UMD**。其全局 `React` 对象未直接提供 Univer UMD 包所需的 `jsx` 和 `jsxs`，下方两行桥接通过公开的 `React.createElement` API 补齐这些入口。通过包管理器接入时，构建工具会解析 `react/jsx-runtime`，无需复制这段 UMD 桥接。

## 命名空间规范

UMD 脚本会将模块导出放在全局对象上。初始化代码通过这些名称访问插件和 Facade API：

| 包或入口 | 全局名称 |
| --- | --- |
| `@univerjs/core` | `UniverCore` |
| `@univerjs/docs-ui` | `UniverDocsUi` |
| `@univerjs/core/facade` | `UniverCoreFacade` |
| `@univerjs/docs-ui/locale/zh-CN` | `UniverDocsUiZhCN` |

## 保持版本一致 [#specifying-versions]

示例统一使用 Univer **1.3.0**、React 与 ReactDOM **18.3.1**、RxJS **7.8.2**。升级时一起更新所有 Univer URL，包括 Facade、CSS 和语言文件。接入已有应用时，避免与应用的构建产物重复加载这些依赖。

## 遇到问题时

| 现象 | 检查方法 |
| --- | --- |
| `ITelemetryService` | 在依赖它的 `@univerjs/sheets-ui` 之前加载 `@univerjs/telemetry`，并保留完整依赖列表。 |
| `FDocument` | 先加载 `@univerjs/docs/facade`，再加载 `@univerjs/docs-ui/facade`；Sheets 也使用 Docs 的文本引擎。 |
| `[redi]`, `t is not a function` | 先从完整示例开始，每个依赖只加载一份并保持版本一致；在浏览器 Network 面板检查失败的请求。 |
| 编辑器空白 | 给容器设置明确的高度。网络或 CSP 阻止 CDN 时，改用本地托管的依赖或包管理器接入。 |

已有 React 或 Vue 应用优先使用[包管理器接入](/guides/sheets/getting-started/installation)，由构建工具管理依赖，无需自己维护长脚本列表。
