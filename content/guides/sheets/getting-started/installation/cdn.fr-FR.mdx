Exécutez d’abord l’exemple complet, puis copiez-le dans votre page. Il inclut les dépendances, styles, langues et enregistrements Facade nécessaires à une feuille modifiable avec calcul des formules.

## Essayer une feuille modifiable

1. [Ouvrez l’exemple](/assets/examples/cdn/sheets.html), ou téléchargez le HTML ci-dessous sous le nom `index.html`.
2. Ouvrez-le dans un navigateur moderne connecté à Internet. Aucun outil de compilation ni serveur n’est nécessaire. L’interface de l’exemple est en anglais.
3. Le total de Notebook est **36**. Passez la quantité de **3** à **4** : le total devient **48**. Vous pouvez aussi modifier les cellules et annuler vos changements.

<a href="/assets/examples/cdn/sheets.html" download="univer-sheets.html">Télécharger le HTML</a>

## Aligner les versions [#specifying-versions]

Cet exemple fixe Univer à **1.3.0**, React et ReactDOM à **18.3.1**, et RxJS à **7.8.2**. Lors d’une mise à niveau, changez toutes les URL Univer ensemble, y compris Facade, CSS et langues. Évitez de charger une seconde copie de ces bibliothèques à côté du bundle de votre application.

## Dépannage

| Symptôme | À vérifier |
| --- | --- |
| `ITelemetryService` | Chargez `@univerjs/telemetry` avant les plugins UI. Copiez toutes les dépendances, pas seulement les plugins Sheets. |
| `FDocument` | Chargez `@univerjs/docs/facade` avant `@univerjs/docs-ui/facade` ; Sheets utilise aussi le moteur de texte Docs. |
| `[redi]`, `t is not a function` | Repartez de l’exemple complet, avec une seule copie de chaque dépendance et des versions cohérentes. Vérifiez les requêtes échouées dans Network. |
| Éditeur vide | Donnez une hauteur au conteneur. Si le réseau ou la CSP bloque le CDN, hébergez les dépendances vous-même ou utilisez un gestionnaire de paquets. |

Pour une application React ou Vue existante, privilégiez [l’installation par gestionnaire de paquets](/guides/sheets/getting-started/installation), qui gère les dépendances et évite une longue liste de scripts à maintenir.
