Exécutez l'exemple HTML complet d'abord, puis copiez-le dans votre propre page. Il comprend les dépendances, les styles, les paquets de langues et les enregistrements Facade qu'un tableur modifiable avec des formules nécessite.

## Essayer une feuille modifiable

1. [Ouvrez l’exemple](/assets/examples/cdn/sheets.fr-FR.html), ou téléchargez le HTML ci-dessous sous le nom `index.html`.
2. Ouvrez le fichier dans un navigateur moderne avec accès Internet. Aucun outil de construction ou serveur n'est nécessaire. L'interface et les données de l'échantillon sont en anglais.
3. La ligne Notebook totalise **36**. Changez sa quantité de **3** en **4**, et le total devient **48** . D'autres cellules peuvent également être modifiées, et les modifications peuvent être annulées.

## Exemple HTML complet [#plugin-mode]

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Élément DOM où monter l’éditeur, ou son identifiant. |

L'exemple charge React **18.3.1 DMU**. Cet objet global `React` ne fournit pas `jsx` ou `jsxs`, ce que les paquets UMD Univer attendent. Le pont biligne ci-dessous fournit les deux points d'entrée à travers l'API publique `React.createElement` . Lorsque vous installez via un gestionnaire de paquets, l'outil de construction résout `react/jsx-runtime` , de sorte que ce pont UMD ne doit pas être copié dans cette configuration .

Les ressources chargent depuis jsDelivr dans l'ordre de dépendance. Si une requête échoue, l'exemple récupère la même version sur unpkg et continue. Si les deux fournisseurs échouent, il arrête et indique quelle ressource ne peut pas être chargée.

```html
<!doctype html>
<html lang="fr-FR">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Exemple CDN Univer Sheets</title>
    <style>
      html,
      body,
      #root,
      #app {
        padding: 0;
        margin: 0;
        height: 100%;
      }
    </style>
  </head>
  <body>
    <div id="app"><p role="status" style="padding: 24px; font-family: system-ui">Chargement de Univer…</p></div>
    <script>
      const cdnBases = ['https://cdn.jsdelivr.net/npm/', 'https://unpkg.com/']
      const app = document.getElementById('app')

      async function loadResource(path, tag = 'script') {
        for (const base of cdnBases) {
          const element = document.createElement(tag)
          const url = base + path
          element.crossOrigin = 'anonymous'
          if (tag === 'link') {
            element.rel = 'stylesheet'
            element.href = url
          } else {
            element.src = url
          }
          try {
            await new Promise((resolve, reject) => {
              element.onload = () => resolve()
              element.onerror = () => reject(new Error(url))
              document.head.appendChild(element)
            })
            return
          } catch {
            element.remove()
          }
        }
        throw new Error(`Could not load ${path} from ${cdnBases.join(' or ')}`)
      }

      const styles = [
        '@univerjs/design@1.5.2/lib/index.css',
        '@univerjs/ui@1.5.2/lib/index.css',
        '@univerjs/docs-ui@1.5.2/lib/index.css',
        '@univerjs/sheets-ui@1.5.2/lib/index.css',
        '@univerjs/sheets-formula-ui@1.5.2/lib/index.css',
        '@univerjs/sheets-numfmt-ui@1.5.2/lib/index.css',
      ]

      const reactScripts = [
        'react@18.3.1/umd/react.production.min.js',
        'react-dom@18.3.1/umd/react-dom.production.min.js',
      ]

      const sdkScripts = [
        'rxjs@7.8.2/dist/bundles/rxjs.umd.min.js',
        '@wendellhu/redi@1.1.3/dist/umd/index.js',
        '@wendellhu/redi@1.1.3/dist/umd/react-bindings/index.js',
        '@univerjs/themes@1.5.2/lib/umd/index.js',
        '@univerjs/protocol@1.5.2/lib/umd/index.js',
        '@univerjs/core@1.5.2/lib/umd/index.js',
        '@univerjs/network@1.5.2/lib/umd/index.js',
        '@univerjs/rpc@1.5.2/lib/umd/index.js',
        '@univerjs/design@1.5.2/lib/umd/index.js',
        '@univerjs/engine-render@1.5.2/lib/umd/index.js',
        '@univerjs/engine-formula@1.5.2/lib/umd/index.js',
        '@univerjs/drawing@1.5.2/lib/umd/index.js',
        '@univerjs/telemetry@1.5.2/lib/umd/index.js',
        '@univerjs/ui@1.5.2/lib/umd/index.js',
        '@univerjs/docs@1.5.2/lib/umd/index.js',
        '@univerjs/docs-ui@1.5.2/lib/umd/index.js',
        '@univerjs/sheets@1.5.2/lib/umd/index.js',
        '@univerjs/sheets-ui@1.5.2/lib/umd/index.js',
        '@univerjs/sheets-formula@1.5.2/lib/umd/index.js',
        '@univerjs/sheets-formula-ui@1.5.2/lib/umd/index.js',
        '@univerjs/sheets-numfmt@1.5.2/lib/umd/index.js',
        '@univerjs/sheets-numfmt-ui@1.5.2/lib/umd/index.js',
        '@univerjs/core@1.5.2/lib/umd/facade.js',
        '@univerjs/engine-formula@1.5.2/lib/umd/facade.js',
        '@univerjs/ui@1.5.2/lib/umd/facade.js',
        '@univerjs/docs@1.5.2/lib/umd/facade.js',
        '@univerjs/docs-ui@1.5.2/lib/umd/facade.js',
        '@univerjs/sheets@1.5.2/lib/umd/facade.js',
        '@univerjs/sheets-ui@1.5.2/lib/umd/facade.js',
        '@univerjs/sheets-formula@1.5.2/lib/umd/facade.js',
        '@univerjs/sheets-numfmt@1.5.2/lib/umd/facade.js',
        '@univerjs/design@1.5.2/lib/umd/locale/fr-FR.js',
        '@univerjs/ui@1.5.2/lib/umd/locale/fr-FR.js',
        '@univerjs/sheets@1.5.2/lib/umd/locale/fr-FR.js',
        '@univerjs/sheets-ui@1.5.2/lib/umd/locale/fr-FR.js',
        '@univerjs/docs-ui@1.5.2/lib/umd/locale/fr-FR.js',
        '@univerjs/sheets-formula-ui@1.5.2/lib/umd/locale/fr-FR.js',
        '@univerjs/sheets-numfmt-ui@1.5.2/lib/umd/locale/fr-FR.js',
      ]

      // Fetch ahead in parallel; main() still executes scripts in dependency order.
      for (const [as, paths] of [
        ['style', styles],
        ['script', [...reactScripts, ...sdkScripts]],
      ]) {
        for (const path of paths) {
          const preload = document.createElement('link')
          preload.rel = 'preload'
          preload.as = as
          preload.crossOrigin = 'anonymous'
          preload.href = cdnBases[0] + path
          preload.onerror = () => {
            preload.onerror = null
            preload.href = cdnBases[1] + path
          }
          document.head.appendChild(preload)
        }
      }

      async function main() {
        for (const path of styles) await loadResource(path, 'link')
        for (const path of reactScripts) await loadResource(path)
        // Bridge the React 18 UMD global to the JSX runtime expected by Univer UMD bundles.
        React.jsx = (type, props, key) => React.createElement(type, key === undefined ? props : { ...props, key })
        React.jsxs = React.jsx
        for (const path of sdkScripts) await loadResource(path)
        app.textContent = ''

        const { Univer, LocaleType, mergeLocales, UniverInstanceType } = UniverCore
        const { FUniver } = UniverCoreFacade
        const { UniverRenderEnginePlugin } = UniverEngineRender
        const { UniverFormulaEnginePlugin } = UniverEngineFormula
        const { UniverUIPlugin } = UniverUi
        const { UniverSheetsPlugin } = UniverSheets
        const { UniverSheetsUIPlugin } = UniverSheetsUi
        const { UniverDocsPlugin } = UniverDocs
        const { UniverDocsUIPlugin } = UniverDocsUi
        const { UniverSheetsFormulaPlugin } = UniverSheetsFormula
        const { UniverSheetsFormulaUIPlugin } = UniverSheetsFormulaUi
        const { UniverSheetsNumfmtPlugin } = UniverSheetsNumfmt
        const { UniverSheetsNumfmtUIPlugin } = UniverSheetsNumfmtUi

        const univer = new Univer({
          locale: LocaleType.FR_FR,
          locales: {
            [LocaleType.FR_FR]: mergeLocales(
              UniverDesignFrFR,
              UniverUiFrFR,
              UniverSheetsFrFR,
              UniverSheetsUiFrFR,
              UniverDocsUiFrFR,
              UniverSheetsFormulaUiFrFR,
              UniverSheetsNumfmtUiFrFR,
            ),
          },
        })

        univer.registerPlugin(UniverRenderEnginePlugin)
        univer.registerPlugin(UniverFormulaEnginePlugin)

        univer.registerPlugin(UniverUIPlugin, {
          container: 'app',
        })

        univer.registerPlugin(UniverDocsPlugin)
        univer.registerPlugin(UniverDocsUIPlugin)

        univer.registerPlugin(UniverSheetsPlugin)
        univer.registerPlugin(UniverSheetsUIPlugin)
        univer.registerPlugin(UniverSheetsFormulaPlugin)
        univer.registerPlugin(UniverSheetsFormulaUIPlugin)
        univer.registerPlugin(UniverSheetsNumfmtPlugin)
        univer.registerPlugin(UniverSheetsNumfmtUIPlugin)

        univer.createUnit(UniverInstanceType.UNIVER_SHEET, {})

        const univerAPI = FUniver.newAPI(univer)
        window.univerAPI = univerAPI
        univerAPI
          .getActiveWorkbook()
          .getActiveSheet()
          .getRange('A1:D3')
          .setValues([
            ['Article', 'Quantité', 'Prix', 'Total'],
            ['Cahier', 3, 12, '=B2*C2'],
            ['Stylo', 5, 2, '=B3*C3'],
          ])
      }

      main().catch((error) => {
        console.error(error)
        app.setAttribute('role', 'alert')
        app.style.cssText =
          'padding: 24px; box-sizing: border-box; white-space: pre-wrap; overflow-wrap: anywhere; font: 14px/1.5 system-ui'
        app.textContent =
          'Le chargement de l’exemple a échoué. Vérifiez la connexion puis actualisez la page.' + '\n' + error.message
      })
    </script>
  </body>
</html>
```

## Conventions de nommage

Les scripts UMD exposent les exportations de modules comme des objets globaux. Initialisation code utilise ces noms pour accéder aux plugins et API Facade:

| Paquet ou point d’entrée | Nom global |
| --- | --- |
| `@univerjs/core` | `UniverCore` |
| `@univerjs/docs-ui` | `UniverDocsUi` |
| `@univerjs/core/facade` | `UniverCoreFacade` |
| `@univerjs/docs-ui/locale/en-US` | `UniverDocsUiEnUS` |

## Aligner les versions [#specifying-versions]

Chaque paquet Univer dans cet exemple est épinglé à **1.5.2**, React et ReactDOM à **18.3.1**, et RxJS à **7.8.2**. Lorsque vous mettez à jour, mettez à jour toutes les URL Univer ensemble, y compris les fichiers Facade, CSS et locale. Ne chargez pas une deuxième copie de ces bibliothèques à côté d'un paquet d'applications existant.

## Dépannage

| Symptôme | À vérifier |
| --- | --- |
| `ITelemetryService` | Chargez d'abord `@univerjs/telemetry`, puis `@univerjs/sheets-ui` qui en dépend. Ne supprimez pas les entrées de la liste des dépendances. |
| `FDocument` | Chargez `@univerjs/docs/facade` avant `@univerjs/docs-ui/facade`. Les feuilles utilisent également le moteur de texte Docs. |
| `[redi]`, `t is not a function` | Commencez à partir de l'exemple complet, conservez une copie de chaque dépendance, et conservez toutes les versions alignées. Vérifiez les requêtes échouées dans le panneau réseau du navigateur. |
| Éditeur vide | Donnez une hauteur explicite au conteneur. Si votre réseau ou CSP bloque un CDN, hébergez les dépendances vous-même ou passez à l'intégration package-manager. |

Si vous avez déjà une application React ou Vue, utilisez plutôt [intégration paquet-gestionnaire](/guides/sheets/getting-started/installation). Les gestionnaires de paquets gèrent les dépendances, ce qui évite de conserver une longue liste de scripts.
