Exécutez d’abord l’exemple complet, puis copiez-le dans votre page. Il inclut les dépendances, styles, langues et enregistrements Facade nécessaires à une feuille modifiable avec calcul des formules.

## Essayer une feuille modifiable

1. [Ouvrez l’exemple](/assets/examples/cdn/sheets.fr-FR.html), ou téléchargez le HTML ci-dessous sous le nom `index.html`.
2. Ouvrez-le dans un navigateur moderne connecté à Internet. Aucun outil de compilation ni serveur n’est nécessaire. L’interface et les données de l’exemple sont en français.
3. Le total du cahier est **36**. Passez la quantité de **3** à **4** : le total devient **48**. Vous pouvez aussi modifier les cellules et annuler vos changements.

## Exemple HTML complet [#plugin-mode]

Cet exemple utilise **React 18.3.1 UMD**. Son objet global `React` n’expose pas `jsx` et `jsxs`, attendus par les bundles UMD Univer. Les deux lignes ci-dessous fournissent ces entrées via l’API publique `React.createElement`. Avec un gestionnaire de paquets, l’outil de compilation résout `react/jsx-runtime` : ne recopiez pas ce pont UMD dans cette configuration.

## Conventions de nommage

Les scripts UMD exposent les exports des modules dans des objets globaux. Utilisez ces noms pour accéder aux plugins et aux API Facade lors de l’initialisation :

| Paquet ou point d’entrée | Nom global |
| --- | --- |
| `@univerjs/core` | `UniverCore` |
| `@univerjs/docs-ui` | `UniverDocsUi` |
| `@univerjs/core/facade` | `UniverCoreFacade` |
| `@univerjs/docs-ui/locale/fr-FR` | `UniverDocsUiFrFR` |

## Aligner les versions [#specifying-versions]

Cet exemple fixe Univer à **1.3.0**, React et ReactDOM à **18.3.1**, et RxJS à **7.8.2**. Lors d’une mise à niveau, changez toutes les URL Univer ensemble, y compris Facade, CSS et langues. Évitez de charger une seconde copie de ces bibliothèques à côté du bundle de votre application.

## Dépannage

| Symptôme | À vérifier |
| --- | --- |
| `ITelemetryService` | Chargez `@univerjs/telemetry` avant `@univerjs/sheets-ui`, qui en dépend. Conservez la liste complète des dépendances. |
| `FDocument` | Chargez `@univerjs/docs/facade` avant `@univerjs/docs-ui/facade` ; Sheets utilise aussi le moteur de texte Docs. |
| `[redi]`, `t is not a function` | Repartez de l’exemple complet, avec une seule copie de chaque dépendance et des versions cohérentes. Vérifiez les requêtes échouées dans Network. |
| Éditeur vide | Donnez une hauteur au conteneur. Si le réseau ou la CSP bloque le CDN, hébergez les dépendances vous-même ou utilisez un gestionnaire de paquets. |

Pour une application React ou Vue existante, privilégiez [l’installation par gestionnaire de paquets](/guides/sheets/getting-started/installation), qui gère les dépendances et évite une longue liste de scripts à maintenir.
