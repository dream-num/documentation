Ejecuta primero el ejemplo completo y después cópialo en tu página. Incluye las dependencias, estilos, idiomas y registros Facade necesarios para una hoja editable con cálculo de fórmulas.

## Prueba una hoja editable

1. [Abre el ejemplo](/assets/examples/cdn/sheets.html) o guarda el HTML siguiente como `index.html`.
2. Ábrelo en un navegador moderno con conexión a Internet. No necesita compilador ni servidor. La interfaz del ejemplo está en inglés.
3. El total de Notebook es **36**. Cambia la cantidad de **3** a **4**: el total pasa a **48**. También puedes editar celdas y deshacer cambios.

<a href="/assets/examples/cdn/sheets.html" download="univer-sheets.html">Descargar HTML</a>

## Mantener versiones coherentes [#specifying-versions]

El ejemplo fija Univer en **1.3.0**, React y ReactDOM en **18.3.1**, y RxJS en **7.8.2**. Al actualizar, cambia juntas todas las URL de Univer, incluidas Facade, CSS e idiomas. Evita cargar otra copia de bibliotecas que ya estén en el bundle de tu aplicación.

## Solución de problemas

| Síntoma | Qué comprobar |
| --- | --- |
| `ITelemetryService` | Carga `@univerjs/telemetry` antes de los plugins de UI. Copia todas las dependencias, no solo los plugins de Sheets. |
| `FDocument` | Carga `@univerjs/docs/facade` antes de `@univerjs/docs-ui/facade`; Sheets también usa el motor de texto de Docs. |
| `[redi]`, `t is not a function` | Parte del ejemplo completo, con una sola copia de cada dependencia y versiones coherentes. Comprueba las solicitudes fallidas en Network. |
| Editor en blanco | Asigna una altura al contenedor. Si la red o CSP bloquea el CDN, aloja las dependencias o usa un gestor de paquetes. |

Para una aplicación React o Vue existente, utiliza la [instalación mediante gestor de paquetes](/guides/sheets/getting-started/installation), que gestiona las dependencias sin mantener una larga lista de scripts.
