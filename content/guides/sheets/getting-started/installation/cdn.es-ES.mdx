Ejecute el ejemplo HTML completo primero, y luego lo copie en su propia página. Incluye las dependencias, estilos, paquetes de idiomas y registros Facade que requiere una hoja de cálculo editable con fórmulas.

## Prueba una hoja editable

1. [Abre el ejemplo](/assets/examples/cdn/sheets.es-ES.html) o guarda el HTML siguiente como `index.html`.
2. Abra el archivo en un navegador moderno con acceso a Internet. No se requiere ninguna herramienta de construcción o servidor. La interfaz y los datos de la muestra están en inglés.
3. La fila de Notebook totaliza **36**. Cambia su cantidad de **3** a **4**, y el total se convierte en **48** . Otras células también se pueden editar, y los cambios se pueden deshacer.

## Ejemplo HTML completo [#plugin-mode]

`UniverUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Elemento DOM donde se monta el editor, o su ID. |

El ejemplo carga React **18.3.1**. Ese objeto global `React` no proporciona `jsx` o `jsxs`, que esperan los Univer paquetes UMD. El puente de dos líneas debajo proporciona ambos puntos de entrada a través de la API pública `React.createElement`. Al instalar a través de un gestor de paquetes, la herramienta de construcción resuelve `react/jsx-runtime`, por lo que este puente UMD no debe ser copiado en esa configuración.

Los recursos cargados de jsDelivr en el orden de dependencia. Si una solicitud falla, el ejemplo se refiere a la misma versión de unpkg y luego continúa. Si ambos proveedores fallan, se detiene e informa qué recurso no se puede cargar.

```html
<!doctype html>
<html lang="es-ES">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Ejemplo CDN de Univer Sheets</title>
    <style>
      html,
      body,
      #root,
      #app {
        padding: 0;
        margin: 0;
        height: 100%;
      }
    </style>
  </head>
  <body>
    <div id="app"><p role="status" style="padding: 24px; font-family: system-ui">Cargando Univer…</p></div>
    <script>
      const cdnBases = ['https://cdn.jsdelivr.net/npm/', 'https://unpkg.com/']
      const app = document.getElementById('app')

      async function loadResource(path, tag = 'script') {
        for (const base of cdnBases) {
          const element = document.createElement(tag)
          const url = base + path
          element.crossOrigin = 'anonymous'
          if (tag === 'link') {
            element.rel = 'stylesheet'
            element.href = url
          } else {
            element.src = url
          }
          try {
            await new Promise((resolve, reject) => {
              element.onload = () => resolve()
              element.onerror = () => reject(new Error(url))
              document.head.appendChild(element)
            })
            return
          } catch {
            element.remove()
          }
        }
        throw new Error(`Could not load ${path} from ${cdnBases.join(' or ')}`)
      }

      const styles = [
        '@univerjs/design@1.5.0/lib/index.css',
        '@univerjs/ui@1.5.0/lib/index.css',
        '@univerjs/docs-ui@1.5.0/lib/index.css',
        '@univerjs/sheets-ui@1.5.0/lib/index.css',
        '@univerjs/sheets-formula-ui@1.5.0/lib/index.css',
        '@univerjs/sheets-numfmt-ui@1.5.0/lib/index.css',
      ]

      const reactScripts = [
        'react@18.3.1/umd/react.production.min.js',
        'react-dom@18.3.1/umd/react-dom.production.min.js',
      ]

      const sdkScripts = [
        'rxjs@7.8.2/dist/bundles/rxjs.umd.min.js',
        '@wendellhu/redi@1.1.3/dist/umd/index.js',
        '@wendellhu/redi@1.1.3/dist/umd/react-bindings/index.js',
        '@univerjs/themes@1.5.0/lib/umd/index.js',
        '@univerjs/protocol@1.5.0/lib/umd/index.js',
        '@univerjs/core@1.5.0/lib/umd/index.js',
        '@univerjs/network@1.5.0/lib/umd/index.js',
        '@univerjs/rpc@1.5.0/lib/umd/index.js',
        '@univerjs/design@1.5.0/lib/umd/index.js',
        '@univerjs/engine-render@1.5.0/lib/umd/index.js',
        '@univerjs/engine-formula@1.5.0/lib/umd/index.js',
        '@univerjs/drawing@1.5.0/lib/umd/index.js',
        '@univerjs/telemetry@1.5.0/lib/umd/index.js',
        '@univerjs/ui@1.5.0/lib/umd/index.js',
        '@univerjs/docs@1.5.0/lib/umd/index.js',
        '@univerjs/docs-ui@1.5.0/lib/umd/index.js',
        '@univerjs/sheets@1.5.0/lib/umd/index.js',
        '@univerjs/sheets-ui@1.5.0/lib/umd/index.js',
        '@univerjs/sheets-formula@1.5.0/lib/umd/index.js',
        '@univerjs/sheets-formula-ui@1.5.0/lib/umd/index.js',
        '@univerjs/sheets-numfmt@1.5.0/lib/umd/index.js',
        '@univerjs/sheets-numfmt-ui@1.5.0/lib/umd/index.js',
        '@univerjs/core@1.5.0/lib/umd/facade.js',
        '@univerjs/engine-formula@1.5.0/lib/umd/facade.js',
        '@univerjs/ui@1.5.0/lib/umd/facade.js',
        '@univerjs/docs@1.5.0/lib/umd/facade.js',
        '@univerjs/docs-ui@1.5.0/lib/umd/facade.js',
        '@univerjs/sheets@1.5.0/lib/umd/facade.js',
        '@univerjs/sheets-ui@1.5.0/lib/umd/facade.js',
        '@univerjs/sheets-formula@1.5.0/lib/umd/facade.js',
        '@univerjs/sheets-numfmt@1.5.0/lib/umd/facade.js',
        '@univerjs/design@1.5.0/lib/umd/locale/es-ES.js',
        '@univerjs/ui@1.5.0/lib/umd/locale/es-ES.js',
        '@univerjs/sheets@1.5.0/lib/umd/locale/es-ES.js',
        '@univerjs/sheets-ui@1.5.0/lib/umd/locale/es-ES.js',
        '@univerjs/docs-ui@1.5.0/lib/umd/locale/es-ES.js',
        '@univerjs/sheets-formula-ui@1.5.0/lib/umd/locale/es-ES.js',
        '@univerjs/sheets-numfmt-ui@1.5.0/lib/umd/locale/es-ES.js',
      ]

      // Fetch ahead in parallel; main() still executes scripts in dependency order.
      for (const [as, paths] of [
        ['style', styles],
        ['script', [...reactScripts, ...sdkScripts]],
      ]) {
        for (const path of paths) {
          const preload = document.createElement('link')
          preload.rel = 'preload'
          preload.as = as
          preload.crossOrigin = 'anonymous'
          preload.href = cdnBases[0] + path
          preload.onerror = () => {
            preload.onerror = null
            preload.href = cdnBases[1] + path
          }
          document.head.appendChild(preload)
        }
      }

      async function main() {
        for (const path of styles) await loadResource(path, 'link')
        for (const path of reactScripts) await loadResource(path)
        // Bridge the React 18 UMD global to the JSX runtime expected by Univer UMD bundles.
        React.jsx = (type, props, key) => React.createElement(type, key === undefined ? props : { ...props, key })
        React.jsxs = React.jsx
        for (const path of sdkScripts) await loadResource(path)
        app.textContent = ''

        const { Univer, LocaleType, mergeLocales, UniverInstanceType } = UniverCore
        const { FUniver } = UniverCoreFacade
        const { UniverRenderEnginePlugin } = UniverEngineRender
        const { UniverFormulaEnginePlugin } = UniverEngineFormula
        const { UniverUIPlugin } = UniverUi
        const { UniverSheetsPlugin } = UniverSheets
        const { UniverSheetsUIPlugin } = UniverSheetsUi
        const { UniverDocsPlugin } = UniverDocs
        const { UniverDocsUIPlugin } = UniverDocsUi
        const { UniverSheetsFormulaPlugin } = UniverSheetsFormula
        const { UniverSheetsFormulaUIPlugin } = UniverSheetsFormulaUi
        const { UniverSheetsNumfmtPlugin } = UniverSheetsNumfmt
        const { UniverSheetsNumfmtUIPlugin } = UniverSheetsNumfmtUi

        const univer = new Univer({
          locale: LocaleType.ES_ES,
          locales: {
            [LocaleType.ES_ES]: mergeLocales(
              UniverDesignEsES,
              UniverUiEsES,
              UniverSheetsEsES,
              UniverSheetsUiEsES,
              UniverDocsUiEsES,
              UniverSheetsFormulaUiEsES,
              UniverSheetsNumfmtUiEsES,
            ),
          },
        })

        univer.registerPlugin(UniverRenderEnginePlugin)
        univer.registerPlugin(UniverFormulaEnginePlugin)

        univer.registerPlugin(UniverUIPlugin, {
          container: 'app',
        })

        univer.registerPlugin(UniverDocsPlugin)
        univer.registerPlugin(UniverDocsUIPlugin)

        univer.registerPlugin(UniverSheetsPlugin)
        univer.registerPlugin(UniverSheetsUIPlugin)
        univer.registerPlugin(UniverSheetsFormulaPlugin)
        univer.registerPlugin(UniverSheetsFormulaUIPlugin)
        univer.registerPlugin(UniverSheetsNumfmtPlugin)
        univer.registerPlugin(UniverSheetsNumfmtUIPlugin)

        univer.createUnit(UniverInstanceType.UNIVER_SHEET, {})

        const univerAPI = FUniver.newAPI(univer)
        window.univerAPI = univerAPI
        univerAPI
          .getActiveWorkbook()
          .getActiveSheet()
          .getRange('A1:D3')
          .setValues([
            ['Artículo', 'Cantidad', 'Precio', 'Total'],
            ['Cuaderno', 3, 12, '=B2*C2'],
            ['Bolígrafo', 5, 2, '=B3*C3'],
          ])
      }

      main().catch((error) => {
        console.error(error)
        app.setAttribute('role', 'alert')
        app.style.cssText =
          'padding: 24px; box-sizing: border-box; white-space: pre-wrap; overflow-wrap: anywhere; font: 14px/1.5 system-ui'
        app.textContent =
          'No se pudo cargar el ejemplo. Comprueba la conexión y actualiza la página.' + '\n' + error.message
      })
    </script>
  </body>
</html>
```

## Convenciones de nombres

Los scripts UMD exponen las exportaciones de módulos como objetos globales. El código de inicialización utiliza estos nombres para acceder a plugins y API de Facade:

| Paquete o punto de entrada | Nombre global |
| --- | --- |
| `@univerjs/core` | `UniverCore` |
| `@univerjs/docs-ui` | `UniverDocsUi` |
| `@univerjs/core/facade` | `UniverCoreFacade` |
| `@univerjs/docs-ui/locale/en-US` | `UniverDocsUiEnUS` |

## Mantener versiones coherentes [#specifying-versions]

Cada paquete de Univer en este ejemplo está marcado a **1.5.0**, React y ReactDOM a **18.3.1**, y RxJS a **7.8.2**. Al actualizar, actualice todos los Univer URL juntos, incluyendo los archivos Facade, CSS y locale. No cargue una segunda copia de estas bibliotecas junto con un paquete de aplicación existente.

## Solución de problemas

| Síntoma | Qué comprobar |
| --- | --- |
| `ITelemetryService` | Cargar `@univerjs/telemetry` primero, luego `@univerjs/sheets-ui`, que depende de él. No eliminar las entradas de la lista de dependencia. |
| `FDocument` | Carga `@univerjs/docs/facade` antes de `@univerjs/docs-ui/facade`. Las hojas también utilizan el motor de texto Docs. |
| `[redi]`, `t is not a function` | Comience desde el ejemplo completo, mantenga una copia de cada dependencia y mantenga alineadas todas las versiones. Compruebe las solicitudes fallidas en el panel de red del navegador. |
| Editor en blanco | Dale al contenedor una altura explícita. Si tu red o CSP bloquea un CDN, aloja las dependencias tú mismo o cambia a la integración del administrador de paquetes. |

Si ya tiene una aplicación React o Vue, use [integración paquete-gerente](/guides/sheets/getting-started/installation) en su lugar. Los administradores de paquetes manejan las dependencias, lo que evita mantener una lista de script larga.
