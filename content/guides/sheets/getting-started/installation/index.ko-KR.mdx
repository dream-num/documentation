Univer는 전자 문서 응용 프로그램에 대한 프레임 워크이며 플러그인에서 조립됩니다. 코어는 작고, 응용 프로그램은 모듈 만 필요합니다. 거래 오프는 Univer와 처음 작업 할 때 더 많은 참여 설정입니다.

Univer는 **플러그인 모드**와 **preset 형태**의 두 가지 통합 스타일을 제공합니다. **제품 정보**가 미리 구성 된 플러그인 세트이므로 사용자 정의 확장 모드 모두 동일한 기능을 제공합니다.

<Callout type="warning" title="주의">
  - **sync에 의존성 버전을 유지하십시오.** 모드 중, 모든 의존도는 동일한 버전으로 해결해야합니다.
  - **믹스 플러그인 및 미리 설정 관리.** 사전 설정이 이미 플러그인을 포함 하는 경우, 플러그인을 별도로 가져올 수 없습니다. 그렇지 않으면 플러그인 충돌 또는 예기치 않은 기능 동작이 발생할 수 있습니다.
</Callout>

두 가지 모드는 다음과 같습니다.

| 플러그인 모드 | 프리셋 모드 |
| --- | --- |
| 필요한 정면 패키지를 직접 가져올 수 있습니다 | Facade 패키지는 미리 설치 |
| 동일한 기능을 제공하는 플러그인의 등록 순서를 제어합니다. | 이미 사전 설정은 등록 주문 처리 |
| 플러그인은 수요에 게 게으른 로드 될 수 있습니다 | 초기화 중에 미리 설정된 부하를 동시에 구성 |

미리 설정 모드는 설정 단축을 유지: 단일 가져오기는 사전 설정된 플러그인의 번들에서 가져온다. **깊은 주문화 또는 연장**의 경우 플러그인 모드를 사용하여 플러그인을 결합하고 개별적으로 구성할 수 있습니다.

## Agent의 도움으로 통합하기(선택 사항) [#agent-skills]

Web SDK를 기존 애플리케이션에 추가할 때 [`univer-integrate`](https://github.com/dream-num/skills/tree/main/skills/univer-integrate)을 사용하십시오. 미리 설정 또는 플러그인 설정, 편집기 초기화 및 Facade API 사용법을 통해 코딩 에이전트를 안내합니다.

```bash
npx skills add dream-num/skills --skill univer-integrate
```

이 명령을 실행하는 프로젝트 디렉토리에서 에이전트가 열려. `-g`를 추가하여 프로젝트 전반에 걸쳐 기술을 사용하거나 `-a codex` 또는 `-a claude-code`와 에이전트를 지정하십시오. 그런 다음 설치 된 기술을 나열하십시오.

```bash
npx skills list
```

목록은 `univer-integrate`를 포함해야 합니다. 기술이 누락되면 `SKILL.md`가 설치 경로에 존재하고 필요한 경우 에이전트 세션을 다시 엽니다.

이전 튜토리얼은 `dream-num/univer-sdk-skills`를 참조 할 수 있습니다. 위의 `dream-num/skills` 명령을 사용하십시오. 기술 이름은 `univer-integrate` 남아 있습니다. 기술이 기대하고 현재 문서와 프로젝트에 설치 된 버전에 대해 통합하는 SDK 기반을 검증합니다.

## 플러그인 모드로 설정하기

Univer는 플러그인으로 그것의 특징을 전달합니다. 몇몇 핵심 플러그인은 기능에 제품을 위해 요구됩니다; 나머지 플러그인은 필요에 따라 수입됩니다. 이 단면도는 소형 Univer 장 신청을 수동으로 건설하고 1에 의하여 그것의 플러그인을 기록합니다.

미리 설정 모드와 달리 플러그인 모드는 기본적으로 Facade API[^facade-entry]를 포함하지 않습니다. 아래 코드의 Facade 관련 부품은 옵션이며 필요할 때 제거 할 수 있습니다.

### 패키지 관리자 사용

#### 설치

Univer는 React를 사용하여 전망 (이 Vue 또는 Angular에서 그것을 사용하는 것을 방지하지 않습니다) 및 데이터 스트림을위한 Rxjs를 사용합니다. 라이브러리는 현대 프런트 엔드 개발에서 널리 사용됩니다. Univer가 피어 Dependencies[^peer-dependency]로 그들을 치료합니다. 패키지 관리자는 다른 종의 인 의존성을 처리하고 여러 세부 사항은주의해야합니다.

<Callout>
  - npm은 npm@7 이상을 사용합니다. npm@3 ~ npm@6는 `peerDependencies`[^1]를 올바르게 설치하지 않습니다.
  - pnpm을 사용하여 pnpm@8 이상을 사용하십시오. pnpm @6 ~ pnpm_7에서 `auto-install-peers=true` [^2]를 설정하면 의존성 설치 문제를 해결할 수 있습니다.
  - 원사로, 누락된 `peerDependencies`[^3]를 수동으로 설치하십시오. 설치 명령은 이미 그(것)들을 포함합니다.
</Callout>

#### `univer.registerPlugin` 및 `univer.registerPlugins` 메서드 [#registerPlugin]

`univer.registerPlugin` 메소드는 Univer 인스턴스와 플러그인을 등록합니다. 인스턴스가 생성 된 후 호출하십시오.

플러그인 및 옵션 전달: `univer.registerPlugin(Plugin, options)`. `Plugin`는 등록 플러그인이며 `options`은 하나의 플러그인과 다른 옵션 구성 항목입니다.

한 번에 여러 플러그인을 등록하려면 `univer.registerPlugins`에 배열을 통과하십시오. 이 접근법은 플러그인이 한 곳에서 관리 될 때 유용합니다.

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  UniverFormulaEnginePlugin,
  [UniverUIPlugin, {
    container: 'app',
  }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverSheetsPlugin,
  UniverSheetsUIPlugin,
  UniverSheetsFormulaPlugin,
  UniverSheetsFormulaUIPlugin,
  UniverSheetsNumfmtPlugin,
  UniverSheetsNumfmtUIPlugin,
])
```

#### 플러그인 지연 로딩

플러그인 모드의 주요 장점은 플러그인로드가 끝날 때 제어됩니다. 일반적인 패턴은 초기화 중에 필수 플러그인 만로드하고 첫 번째 렌더링 후 나머지를 무시합니다.

```typescript
// ...

univer.createUnit(UniverInstanceType.UNIVER_SHEET, {})

import('@univerjs/watermark').then(({ UniverWatermarkPlugin }) => {
  univer.registerPlugin(UniverWatermarkPlugin, {
    textWatermarkSettings: {
      content: 'Hello, Univer!',
      fontSize: 36,
    },
  })
})
```

[공식 데모](https://github.com/dream-num/univer/blob/0d849012594882307186f33734b8b89d80a729e9/examples/src/sheets/main.ts)는 동일한 최적화를 적용하고 검토 가치가 있습니다.

### 모바일 지원 [#mobile-support]

<Callout type="warning">
  아래 모바일 플러그인을 내보내는 SDK 패키지가 필요합니다. 모든 `@univerjs/*` 및 `@univerjs-pro/*` 의존성을 **같은 버전**으로 맞추세요.
</Callout>

**모바일 UI 플러그인**는 Univer 시트에서 터치 컨트롤을 제공합니다.[^mobile-ui-mode] 편집기를 만들기 전에 UI 모드를 선택하십시오.

시트에 대한 모바일 지원은 **연구분야** 남아 있습니다. 응용 프로그램을 테스트하면 대상 기기에 필요합니다.

위의 플러그인 모드 예에서 **제품 설명**는 `createUnit()` 이전에 UI 가져 오기 및 등록합니다. 이미 초기화 된 데스크톱 편집기에 추가하지 마십시오. 모델 플러그인, 엔진, 로컬 파일, CSS 및 Facade 가져 오기를 포함합니다. 데스크탑 및 모바일 클래스는 **동일한 패키지 항목**의 수출이라고합니다.

`UniverMobileUIPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 편집기를 마운트할 DOM 요소 또는 해당 요소의 ID입니다. |
| `disableAutoFocus` | `true` | `true` | 시작할 때 편집기에 자동으로 포커스를 주지 않습니다. |

```typescript
import { UniverDocsMobileUIPlugin } from '@univerjs/docs-ui'
import { UniverSheetsFormulaMobileUIPlugin } from '@univerjs/sheets-formula-ui'
import { UniverSheetsNumfmtMobileUIPlugin } from '@univerjs/sheets-numfmt-ui'
import { UniverSheetsMobileUIPlugin } from '@univerjs/sheets-ui'
import { UniverMobileUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverMobileUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsMobileUIPlugin)
univer.registerPlugin(UniverSheetsMobileUIPlugin)
univer.registerPlugin(UniverSheetsFormulaMobileUIPlugin)
univer.registerPlugin(UniverSheetsNumfmtMobileUIPlugin)
```

모바일에서 `UniverDocsUIPlugin`를 `UniverDocsMobileUIPlugin`로 교체하여 셀 내부의 문서를 편집하고 `UniverSheetsMobileUIPlugin` 이전에 등록 할 수 있습니다.

`UniverSheetsCorePreset` 및 `UniverDocsCorePreset`는 현재 데스크탑 UI 플러그인을 등록하고 `mobile: true` 옵션이 없습니다. 모바일을 위해 플러그인을 명시적으로 조립하십시오. 데스크톱 사전 설정 후 모바일 플러그인을 추가하면 미리 설정의 UI를 대체하지 않습니다.

#### 컨테이너와 터치 조작

컨테이너에 대한 명시적 높이를 설정하고 페이지 뷰포트를 구성하십시오. `100dvh`는 동적 뷰포트 높이를 추적합니다. 대상 모바일 브라우저에서 스크롤, 핀치 줌, 텍스트 선택, 클립 보드 액세스 및 온 스크린 키보드를 확인합니다. 데스크톱 편집기를 혼자서 모바일 플러그인을 선택하지 않습니다.

`UniverMobileUIPlugin`는 `disableAutoFocus: true`에 기본적으로, 그래서 편집기는 초기화 도중 자동적으로 집중하지 않습니다.

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
<div id="app" style="height: 100dvh"></div>
```

## 프리셋 모드로 설정하기

미리 설정 모드는 코드의 20 라인 아래에서 Univer 시트 응용 프로그램을 실행합니다.

### 패키지 관리자 사용

이미 프로젝트가 현대 프런트 엔드 툴링을 사용하는 경우, Univer를 통합하는 것은 바로 앞쪽입니다. [뚱 베어](https://vitejs.dev/), [esbuild의](https://esbuild.github.io/) 또는 [웹팩 5](https://webpack.js.org/)와 같은 견고한 ES 모듈 지원과 빌드 도구를 사용하여 추가 구성을 필요로 할 수 있습니다.

#### 설치

패키지 관리자와 `@univerjs/presets` 설치 :

```package-install
npm install @univerjs/presets @univerjs/preset-sheets-core
```

#### 사용법

<Callout type="warning">
  빌드 도구가 패키지에 `exports` 필드를 지원하지 않는 경우.json (Webpack 4)로 구성된 데모를 수동으로 실제 경로로 변환합니다.
</Callout>

이 두 파일은 Univer 시트 응용 프로그램을 시작하는 충분합니다.

```html title="index.html"
<div id="app" style="height: 600px"></div>
```

```typescript
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-sheets-core/lib/index.css'

const { univer, univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
    ),
  },
  presets: [
    UniverSheetsCorePreset({
      container: 'app',
    }),
  ],
})

univerAPI.createWorkbook({})
```

반환된 `univerAPI` 객체는 Univer Facade API입니다. Univer가 제공하는 기능을 호출하는 기능을 통해 인터페이스입니다.

#### `createUniver` 메서드

`createUniver`는 언어, 테마 및 플러그인과 같은 Univer에 대한 설정을 포함하는 구성 객체를 허용합니다. Univer 인스턴스와 Univer Facade API 예를 들어 포함하는 객체를 반환합니다.

주요 속성은:

- `locale`: `LocaleType` 가치로 언어 환경.
- `locales`: 로컬 팩의 객체, 언어 환경에 의해 키.
- `theme`: 옵션 테마 객체.
- `presets`: `UniverSheetsCorePreset`와 같은 등록하는 미리 설치.
- `plugins`: 플러그인은 사전 설정에 추가.

플러그인은 사전 설정 패키지에 속하지 않습니다, 또는 당신이 자신의 쓰기 때, `plugins` 속성을 통해 등록. `univer.registerPlugin` ZXZ를 얻기 후 Univer 인스턴스를 호출 할 수 있습니다.

<Callout>
  `createUniver`에 대한 자세한 내용은 [API 참조 / createUniver](https://docs.univer.ai/reference/methods/create-univer)를 참조하십시오.
</Callout>

## 기타 릴리스

Univer는 알파, 베타 및 야간 채널을 제공합니다. 이 빌드는 안정적인 출시되기 전에 새로운 기능에 일찍 액세스 할 수 있습니다. 또한 더 많은 기능을 더 많은 위험을 가져올 수 있습니다. 이 버전에는 버그, 불완전한 기능, 또는 불안정한 행동이 포함될 수 있습니다. 가능한 생산에서 그들을 피하십시오.

### Alpha / Beta 릴리스

Univer 팀은 새로운 기능 또는 중요한 변화를 완료할 때 알파 또는 베타 채널로 변경을 미리 릴리스 할 수 있습니다. 알파 또는 베타 빌드를 설치하십시오.

```package-install
npm install @univerjs/<package-name>@alpha # Alpha version
npm install @univerjs/<package-name>@beta # Beta version
```

문제가 있거나 알파 또는 베타 버전을 사용하는 동안 피드백을 가지고 있다면 Univer 팀에 [GitHub 문제](https://github.com/dream-num/univer/issues)를 통해보고하십시오.
