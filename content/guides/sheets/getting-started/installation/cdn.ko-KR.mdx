---
title: CDN으로 Univer 가져오기
---

패키지 관리자를 사용하지 않는다면 `<script>` 태그로 Univer를 가져올 수도 있습니다.

#### 네임스페이스 규칙

Univer의 전역 빌드(UMD)는 다음 명명 규칙에 따라 전역 객체에 네임스페이스를 노출합니다.

```plain
@univerjs/core -> UniverCore
@univerjs/docs-ui -> UniverDocsUi
@univerjs-pro/docs-print -> UniverProDocsPrint
@univerjs/docs-ui/locale/en-US -> UniverDocsUiEnUS
@univerjs/core/facade -> UniverCoreFacade
```

## 플러그인 모드 [#plugin-mode]

### 전역 빌드 사용

Univer는 플러그인용 UMD 빌드를 제공합니다. CDN 스크립트 태그를 사용할 때는 각 플러그인과 그 종속성의 UMD 빌드를 직접 포함해야 합니다. 이 과정은 번거로우므로 플러그인 종속성과 스타일 파일 순서를 비롯한 플러그인 메커니즘을 충분히 이해한 뒤 사용하는 것을 권장합니다.

          }
          if (type && type.defaultProps) {

            $$typeof: REACT_ELEMENT_TYPE,

            key,
            ref,
            props,
            _owner: ReactCurrentOwner.current,
          }
        }
        React.jsx = createReactElement

      }
    })(this)

## 버전 지정

unpkg와 jsDeliver 모두 리소스의 특정 버전을 지정할 수 있습니다. 예를 들어 Univer의 `x.y.z` 버전을 사용하려면 URL에 `@<version>`을 추가하면 됩니다.

```diff
- https://unpkg.com/@univerjs/core/lib/umd/index.js
+ https://unpkg.com/@univerjs/core@x.y.z/lib/umd/index.js
```
