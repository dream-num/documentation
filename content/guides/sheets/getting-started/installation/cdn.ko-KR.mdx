먼저 전체 예제를 실행한 뒤 자신의 페이지에 복사하세요. 편집 가능한 시트와 수식 계산에 필요한 의존성, 스타일, 언어 팩, Facade 등록이 포함되어 있습니다.

## 편집 가능한 시트 체험

1. [예제 열기](/assets/examples/cdn/sheets.ko-KR.html) 또는 아래 HTML을 내려받아 `index.html`로 저장하세요.
2. 인터넷에 연결된 최신 브라우저에서 여세요. 빌드 도구나 서버가 필요하지 않습니다. 예제 UI와 표의 내용은 한국어입니다.
3. 노트 합계는 **36**입니다. 수량을 **3**에서 **4**로 바꾸면 **48**이 됩니다. 셀 편집과 실행 취소도 체험할 수 있습니다.

## 전체 HTML 예제 [#plugin-mode]

이 예제는 **React 18.3.1 UMD**를 사용합니다. 전역 `React` 객체에는 Univer UMD 번들이 요구하는 `jsx`와 `jsxs`가 없으므로 아래 두 줄에서 공개 `React.createElement` API로 연결합니다. 패키지 관리자로 통합하면 빌드 도구가 `react/jsx-runtime`을 해석하므로 이 UMD 브리지를 복사할 필요가 없습니다.

## 네임스페이스 규칙

UMD 스크립트는 모듈 내보내기를 전역 객체로 제공합니다. 초기화 코드에서 다음 이름으로 플러그인과 Facade API에 접근하세요.

| 패키지 또는 진입점 | 전역 이름 |
| --- | --- |
| `@univerjs/core` | `UniverCore` |
| `@univerjs/docs-ui` | `UniverDocsUi` |
| `@univerjs/core/facade` | `UniverCoreFacade` |
| `@univerjs/docs-ui/locale/ko-KR` | `UniverDocsUiKoKR` |

## 버전 일치 [#specifying-versions]

예제는 Univer **1.3.0**, React와 ReactDOM **18.3.1**, RxJS **7.8.2**로 고정되어 있습니다. 업그레이드할 때 Facade, CSS, 언어 파일을 포함한 모든 Univer URL을 함께 바꾸세요. 기존 앱 번들에 포함된 라이브러리를 중복으로 로드하지 마세요.

## 문제 해결

| 증상 | 확인할 사항 |
| --- | --- |
| `ITelemetryService` | `@univerjs/telemetry`에 의존하는 `@univerjs/sheets-ui`보다 먼저 로드하고 전체 의존성 목록을 유지하세요. |
| `FDocument` | `@univerjs/docs-ui/facade`보다 먼저 `@univerjs/docs/facade`를 로드하세요. Sheets도 Docs 텍스트 엔진을 사용합니다. |
| `[redi]`, `t is not a function` | 전체 예제로 시작하고 각 의존성을 동일한 버전으로 한 번만 로드하세요. 브라우저 Network에서 실패한 요청을 확인하세요. |
| 빈 에디터 | 컨테이너 높이를 지정하세요. 네트워크나 CSP가 CDN을 차단하면 직접 호스팅한 의존성이나 패키지 관리자를 사용하세요. |

기존 React 또는 Vue 앱에는 의존성을 관리하는 [패키지 관리자 통합](/guides/sheets/getting-started/installation)을 권장합니다. 긴 스크립트 목록을 직접 관리할 필요가 없습니다.
