Сначала запустите полный пример HTML, а затем скопируйте его на свою собственную страницу. Он включает в себя зависимости, стили, языковые пакеты и регистрации Facade, которые требуются для редактируемой электронной таблицы с формулами.

## Попробуйте редактируемую таблицу

1. [Откройте пример](/assets/examples/cdn/sheets.ru-RU.html) или сохраните HTML ниже как `index.html`.
2. Откройте файл в современном браузере с доступом в интернет. Инструмента сборки или сервера не требуется. Интерфейс и данные выборки на английском языке.
3. Ряд Notebook составляет **36**. Измените его количество с **3** на **4**, и общее станет **48**... Другие ячейки также могут быть отредактированы, а изменения могут быть отменены.

## Полный пример HTML [#plugin-mode]

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для редактора или его идентификатор. |

Пример загружает React **18.3.1 UMD**. Этот глобальный объект `React` не обеспечивает `jsx` или `jsxs`, чего ожидают пакеты Univer UMD. Двухлинейный мост ниже поставляет обе точки входа через общедоступный API `React.createElement`. При установке через менеджер пакетов инструмент сборки разрешает `react/jsx-runtime`, поэтому этот мост UMD не должен быть скопирован в эту установку.

Ресурсы загружаются из jsDelivr в порядке зависимости. Если запрос не выполняется, пример повторно запрашивает одну и ту же версию на unpkg, а затем продолжается. Если оба провайдера не выполняют свою работу, он останавливается и сообщает, какой ресурс не может быть загружен.

```html
<!doctype html>
<html lang="ru-RU">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Пример Univer Sheets через CDN</title>
    <style>
      html,
      body,
      #root,
      #app {
        padding: 0;
        margin: 0;
        height: 100%;
      }
    </style>
  </head>
  <body>
    <div id="app"><p role="status" style="padding: 24px; font-family: system-ui">Загрузка Univer…</p></div>
    <script>
      const cdnBases = ['https://cdn.jsdelivr.net/npm/', 'https://unpkg.com/']
      const app = document.getElementById('app')

      async function loadResource(path, tag = 'script') {
        for (const base of cdnBases) {
          const element = document.createElement(tag)
          const url = base + path
          element.crossOrigin = 'anonymous'
          if (tag === 'link') {
            element.rel = 'stylesheet'
            element.href = url
          } else {
            element.src = url
          }
          try {
            await new Promise((resolve, reject) => {
              element.onload = () => resolve()
              element.onerror = () => reject(new Error(url))
              document.head.appendChild(element)
            })
            return
          } catch {
            element.remove()
          }
        }
        throw new Error(`Could not load ${path} from ${cdnBases.join(' or ')}`)
      }

      const styles = [
        '@univerjs/design@1.6.1/lib/index.css',
        '@univerjs/ui@1.6.1/lib/index.css',
        '@univerjs/docs-ui@1.6.1/lib/index.css',
        '@univerjs/sheets-ui@1.6.1/lib/index.css',
        '@univerjs/sheets-formula-ui@1.6.1/lib/index.css',
        '@univerjs/sheets-numfmt-ui@1.6.1/lib/index.css',
      ]

      const reactScripts = [
        'react@18.3.1/umd/react.production.min.js',
        'react-dom@18.3.1/umd/react-dom.production.min.js',
      ]

      const sdkScripts = [
        'rxjs@7.8.2/dist/bundles/rxjs.umd.min.js',
        '@wendellhu/redi@1.1.3/dist/umd/index.js',
        '@wendellhu/redi@1.1.3/dist/umd/react-bindings/index.js',
        '@univerjs/themes@1.6.1/lib/umd/index.js',
        '@univerjs/protocol@1.6.1/lib/umd/index.js',
        '@univerjs/core@1.6.1/lib/umd/index.js',
        '@univerjs/network@1.6.1/lib/umd/index.js',
        '@univerjs/rpc@1.6.1/lib/umd/index.js',
        '@univerjs/design@1.6.1/lib/umd/index.js',
        '@univerjs/engine-render@1.6.1/lib/umd/index.js',
        '@univerjs/engine-formula@1.6.1/lib/umd/index.js',
        '@univerjs/drawing@1.6.1/lib/umd/index.js',
        '@univerjs/telemetry@1.6.1/lib/umd/index.js',
        '@univerjs/ui@1.6.1/lib/umd/index.js',
        '@univerjs/docs@1.6.1/lib/umd/index.js',
        '@univerjs/docs-ui@1.6.1/lib/umd/index.js',
        '@univerjs/sheets@1.6.1/lib/umd/index.js',
        '@univerjs/sheets-ui@1.6.1/lib/umd/index.js',
        '@univerjs/sheets-formula@1.6.1/lib/umd/index.js',
        '@univerjs/sheets-formula-ui@1.6.1/lib/umd/index.js',
        '@univerjs/sheets-numfmt@1.6.1/lib/umd/index.js',
        '@univerjs/sheets-numfmt-ui@1.6.1/lib/umd/index.js',
        '@univerjs/core@1.6.1/lib/umd/facade.js',
        '@univerjs/engine-formula@1.6.1/lib/umd/facade.js',
        '@univerjs/ui@1.6.1/lib/umd/facade.js',
        '@univerjs/docs@1.6.1/lib/umd/facade.js',
        '@univerjs/docs-ui@1.6.1/lib/umd/facade.js',
        '@univerjs/sheets@1.6.1/lib/umd/facade.js',
        '@univerjs/sheets-ui@1.6.1/lib/umd/facade.js',
        '@univerjs/sheets-formula@1.6.1/lib/umd/facade.js',
        '@univerjs/sheets-numfmt@1.6.1/lib/umd/facade.js',
        '@univerjs/design@1.6.1/lib/umd/locale/ru-RU.js',
        '@univerjs/ui@1.6.1/lib/umd/locale/ru-RU.js',
        '@univerjs/sheets@1.6.1/lib/umd/locale/ru-RU.js',
        '@univerjs/sheets-ui@1.6.1/lib/umd/locale/ru-RU.js',
        '@univerjs/docs-ui@1.6.1/lib/umd/locale/ru-RU.js',
        '@univerjs/sheets-formula-ui@1.6.1/lib/umd/locale/ru-RU.js',
        '@univerjs/sheets-numfmt-ui@1.6.1/lib/umd/locale/ru-RU.js',
      ]

      // Fetch ahead in parallel; main() still executes scripts in dependency order.
      for (const [as, paths] of [
        ['style', styles],
        ['script', [...reactScripts, ...sdkScripts]],
      ]) {
        for (const path of paths) {
          const preload = document.createElement('link')
          preload.rel = 'preload'
          preload.as = as
          preload.crossOrigin = 'anonymous'
          preload.href = cdnBases[0] + path
          preload.onerror = () => {
            preload.onerror = null
            preload.href = cdnBases[1] + path
          }
          document.head.appendChild(preload)
        }
      }

      async function main() {
        for (const path of styles) await loadResource(path, 'link')
        for (const path of reactScripts) await loadResource(path)
        // Bridge the React 18 UMD global to the JSX runtime expected by Univer UMD bundles.
        React.jsx = (type, props, key) => React.createElement(type, key === undefined ? props : { ...props, key })
        React.jsxs = React.jsx
        for (const path of sdkScripts) await loadResource(path)
        app.textContent = ''

        const { Univer, LocaleType, mergeLocales, UniverInstanceType } = UniverCore
        const { FUniver } = UniverCoreFacade
        const { UniverRenderEnginePlugin } = UniverEngineRender
        const { UniverFormulaEnginePlugin } = UniverEngineFormula
        const { UniverUIPlugin } = UniverUi
        const { UniverSheetsPlugin } = UniverSheets
        const { UniverSheetsUIPlugin } = UniverSheetsUi
        const { UniverDocsPlugin } = UniverDocs
        const { UniverDocsUIPlugin } = UniverDocsUi
        const { UniverSheetsFormulaPlugin } = UniverSheetsFormula
        const { UniverSheetsFormulaUIPlugin } = UniverSheetsFormulaUi
        const { UniverSheetsNumfmtPlugin } = UniverSheetsNumfmt
        const { UniverSheetsNumfmtUIPlugin } = UniverSheetsNumfmtUi

        const univer = new Univer({
          locale: LocaleType.RU_RU,
          locales: {
            [LocaleType.RU_RU]: mergeLocales(
              UniverDesignRuRU,
              UniverUiRuRU,
              UniverSheetsRuRU,
              UniverSheetsUiRuRU,
              UniverDocsUiRuRU,
              UniverSheetsFormulaUiRuRU,
              UniverSheetsNumfmtUiRuRU,
            ),
          },
        })

        univer.registerPlugin(UniverRenderEnginePlugin)
        univer.registerPlugin(UniverFormulaEnginePlugin)

        univer.registerPlugin(UniverUIPlugin, {
          container: 'app',
        })

        univer.registerPlugin(UniverDocsPlugin)
        univer.registerPlugin(UniverDocsUIPlugin)

        univer.registerPlugin(UniverSheetsPlugin)
        univer.registerPlugin(UniverSheetsUIPlugin)
        univer.registerPlugin(UniverSheetsFormulaPlugin)
        univer.registerPlugin(UniverSheetsFormulaUIPlugin)
        univer.registerPlugin(UniverSheetsNumfmtPlugin)
        univer.registerPlugin(UniverSheetsNumfmtUIPlugin)

        univer.createUnit(UniverInstanceType.UNIVER_SHEET, {})

        const univerAPI = FUniver.newAPI(univer)
        window.univerAPI = univerAPI
        univerAPI
          .getActiveWorkbook()
          .getActiveSheet()
          .getRange('A1:D3')
          .setValues([
            ['Товар', 'Кол-во', 'Цена', 'Итого'],
            ['Блокнот', 3, 12, '=B2*C2'],
            ['Ручка', 5, 2, '=B3*C3'],
          ])
      }

      main().catch((error) => {
        console.error(error)
        app.setAttribute('role', 'alert')
        app.style.cssText =
          'padding: 24px; box-sizing: border-box; white-space: pre-wrap; overflow-wrap: anywhere; font: 14px/1.5 system-ui'
        app.textContent =
          'Не удалось загрузить пример. Проверьте подключение и обновите страницу.' + '\n' + error.message
      })
    </script>
  </body>
</html>
```

## Правила именования

Скрипты UMD раскрывают экспорт модулей как глобальные объекты. Код инициализации использует эти имена для доступа к плагинам и API-интерфейсам Facade:

| Пакет или точка входа | Глобальное имя |
| --- | --- |
| `@univerjs/core` | `UniverCore` |
| `@univerjs/docs-ui` | `UniverDocsUi` |
| `@univerjs/core/facade` | `UniverCoreFacade` |
| `@univerjs/docs-ui/locale/en-US` | `UniverDocsUiEnUS` |

## Согласованные версии [#specifying-versions]

Каждый пакет Univer в этом примере прикреплен к **1.6.1**, React и ReactDOM к **18.3.1**. При обновлении RxJS к **7.8.2** обновляйте все URL-адреса Univer вместе, включая файлы Facade, CSS и locale. Не загружайте вторую копию этих библиотек вместе с существующим пакетом приложений.

## Устранение неполадок

| Симптом | Что проверить |
| --- | --- |
| `ITelemetryService` | Загрузите сначала `@univerjs/telemetry`, затем `@univerjs/sheets-ui`. Не удаляйте записи из списка зависимостей. |
| `FDocument` | Загрузите `@univerjs/docs/facade` перед `@univerjs/docs-ui/facade`. В листах также используется текстовый движок Docs. |
| `[redi]`, `t is not a function` | Начните с полного примера, сохраните одну копию каждой зависимости и выровняйте все версии.Проверьте неисправные запросы на панели браузера Network. |
| Пустой редактор | Дайте контейнеру явную высоту. Если ваша сеть или CSP блокирует CDN, разместите зависимости самостоятельно или переключитесь на интеграцию пакет-менеджер. |

Если у вас уже есть приложение React или Vue, используйте вместо этого [пакетная интеграция менеджеров](/guides/sheets/getting-started/installation). Менеджеры пакетов обрабатывают зависимости, что позволяет избежать сохранения длинного списка сценариев.
