## Попробуйте редактируемую таблицу

1. [Откройте пример](/assets/examples/cdn/sheets.ru-RU.html) или сохраните HTML ниже как `index.html`.
2. Откройте его в современном браузере с доступом в Интернет. Сборщик и сервер не нужны. Интерфейс и данные примера — на русском языке.
3. Сумма в строке «Блокнот» равна **36**. Измените количество с **3** на **4** — сумма станет **48**. Также можно редактировать ячейки и отменять изменения.

## Полный пример HTML [#plugin-mode]

Пример использует **React 18.3.1 UMD**. Глобальный объект `React` не предоставляет `jsx` и `jsxs`, ожидаемые UMD-сборками Univer. Две строки ниже добавляют эти точки входа через публичный API `React.createElement`. При установке через менеджер пакетов сборщик разрешает `react/jsx-runtime`; этот UMD-мост в такой конфигурации не нужен.

## Правила именования

UMD-скрипты предоставляют экспорты модулей через глобальные объекты. Используйте эти имена для доступа к плагинам и Facade API в коде инициализации:

| Пакет или точка входа | Глобальное имя |
| --- | --- |
| `@univerjs/core` | `UniverCore` |
| `@univerjs/docs-ui` | `UniverDocsUi` |
| `@univerjs/core/facade` | `UniverCoreFacade` |
| `@univerjs/docs-ui/locale/ru-RU` | `UniverDocsUiRuRU` |

## Согласованные версии [#specifying-versions]

В примере зафиксированы Univer **1.3.0**, React и ReactDOM **18.3.1**, RxJS **7.8.2**. При обновлении меняйте все URL Univer одновременно, включая Facade, CSS и языки. Не загружайте вторую копию библиотек, уже включённых в сборку приложения.

## Устранение неполадок

| Симптом | Что проверить |
| --- | --- |
| `ITelemetryService` | Загрузите `@univerjs/telemetry` до зависящего от него `@univerjs/sheets-ui`. Сохраните полный список зависимостей. |
| `FDocument` | Загрузите `@univerjs/docs/facade` перед `@univerjs/docs-ui/facade`: Sheets также использует текстовый движок Docs. |
| `[redi]`, `t is not a function` | Начните с полного примера: одна копия каждой зависимости и согласованные версии. Проверьте неудачные запросы во вкладке Network. |
| Пустой редактор | Задайте высоту контейнера. Если сеть или CSP блокирует CDN, разместите зависимости у себя или используйте менеджер пакетов. |

Для существующего приложения React или Vue рекомендуем [установку через менеджер пакетов](/guides/sheets/getting-started/installation): он управляет зависимостями и избавляет от длинного списка скриптов.
