Приведенные ниже примеры демонстрируют, как настроить Worker[^web-worker] для вычисления формул в Univer.

В листах рабочий обычно обрабатывает вычислительные задачи, такие как вычисление формул. Запуск этой работы в процессе рабочего снижает нагрузку на основной поток, поэтому рендеринг страниц и взаимодействие остаются отзывчивыми, когда рабочая книга содержит много формул.

## Режим плагинов

Этот раздел начинается с настройки режима плагина в [установка](/guides/sheets/getting-started/installation). Плагины рендеринга и пользовательского интерфейса остаются в основном потоке. Замените регистрацию трех плагинов расчета с версиями ниже и зарегистрируйте плагин RPC главной нити перед созданием рабочей книги.

`UniverRPCMainThreadPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `workerURL` | `string \| URL \| Worker` |  | Подключает Worker для вычисления формул. |

`UniverFormulaEnginePlugin` | `UniverSheetsPlugin` | `UniverSheetsFormulaPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `notExecuteFormula` | `boolean` | `false` | Отключает вычисление формул в основном потоке, когда за них отвечает Worker. |

```typescript title="main.ts"
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRPCMainThreadPlugin } from '@univerjs/rpc'
import { UniverSheetsPlugin } from '@univerjs/sheets'
import { UniverSheetsFormulaPlugin } from '@univerjs/sheets-formula'

univer.registerPlugin(UniverRPCMainThreadPlugin, {
  workerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
univer.registerPlugin(UniverFormulaEnginePlugin, { notExecuteFormula: true })
univer.registerPlugin(UniverSheetsPlugin, { notExecuteFormula: true })
univer.registerPlugin(UniverSheetsFormulaPlugin, { notExecuteFormula: true })
```

Рабочий содержит только перечисленные ниже плагины данных и вычислений. Не регистрируйте в Рабочем интерфейс или плагины рендеринга. На главном потоке `notExecuteFormula: true` делегирует Работнику формулу расчета.

`UniverSheetsPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `onlyRegisterFormulaRelatedMutations` | `boolean` | `false` | Регистрирует в Worker только изменения, необходимые для вычисления формул. |

```typescript title="worker.ts"
import { LocaleType, Univer } from '@univerjs/core'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula/worker'
import { UniverRPCWorkerThreadPlugin } from '@univerjs/rpc/worker'
import { UniverSheetsPlugin } from '@univerjs/sheets/worker'
import { UniverRemoteSheetsFormulaPlugin } from '@univerjs/sheets-formula/worker'

const univer = new Univer({ locale: LocaleType.RU_RU })
univer.registerPlugin(UniverSheetsPlugin, { onlyRegisterFormulaRelatedMutations: true })
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverRPCWorkerThreadPlugin)
univer.registerPlugin(UniverRemoteSheetsFormulaPlugin)
```

Фильтрация требует `UniverSheetsFilterPlugin` в обоих потоках. Без этого плагина формулы, такие как `SUBTOTAL`, не могут определить, какие строки скрыла фильтрация. Импорт плагина из `@univerjs/sheets-filter` на основной поток и из `@univerjs/sheets-filter/worker` у Worker. `UniverSheetsFilterUIPlugin` остается на основном потоке.

Для дополнительных плагинов расчета в Worker используйте точки входа ниже. Основной поток импортируется из корневой записи каждого пакета. Все версии пакетов SDK должны оставаться выровненными.

```typescript title="worker.ts"
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula/worker'
import { UniverSheetsPivotChartWorkerPlugin } from '@univerjs-pro/sheets-pivot-chart/worker'
import { UniverSheetsPivotTablePlugin } from '@univerjs-pro/sheets-pivot/worker'
import { UniverSheetsSlicerPlugin } from '@univerjs-pro/sheets-slicer/worker'
import { UniverSheetsTablePlugin } from '@univerjs/sheets-table/worker'
```

Таблицы Pivot требуют иной конфигурации. Замените `UniverFormulaEnginePlugin` на `UniverProFormulaEnginePlugin` в обоих потоках, а также зарегистрируйте `UniverLicensePlugin` и `UniverSheetsPivotTablePlugin`. В основном потоке установите `notExecuteFormula: true` для движка формулы Pro и плагина PivotTable; в Worker установите его на `false`; Обе среды выполнения требуют лицензии. Опорный пользовательский интерфейс остается на основном потоке, и пользовательские реализации формул должны быть зарегистрированы в обоих движках формул.

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое клиентского файла лицензии. |

`UniverProFormulaEnginePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `notExecuteFormula` | `boolean` |  | Пропускает вычисление формул в этой среде, когда их вычисляет Worker. |

`UniverSheetsPivotTablePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `notExecuteFormula` | `boolean` |  | Передайте `true` в основном потоке и `false` в Worker. Опустите параметр при вычислении в одном потоке. |

## Режим Preset

`UniverSheetsCorePreset`

| <span data-config-options="">Option</span> | Тип | по умолчанию | Что он делает |
| --- | --- | --- | --- |
| `workerURL` | `string \| URL \| Worker` |  | Подключает редактор к Рабочему для вычисления формул. |

### Пример: простыни-ядро-с-работником

Этот пример включает в себя предустановленный пакет `sheets-filter`, потому что листы-фильтр скрывает строки, а скрытые строки влияют на то, как рассчитывается `SUBTOTAL`. Когда вычисление формулы выполняется в Рабочем, листы-файлер также должен работать в Рабочем.

```typescript title="main.ts"
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsFilterPreset } from '@univerjs/preset-sheets-filter'
import UniverPresetSheetsFilterEnUS from '@univerjs/preset-sheets-filter/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-filter/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsFilterEnUS,
    ),
  },
  presets: [
    UniverSheetsCorePreset({
      workerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
    }),
    UniverSheetsFilterPreset(),
  ],
})

univerAPI.createWorkbook({ name: 'Test Sheet' })
```

```typescript title="worker.ts"
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsCoreWorkerPreset } from '@univerjs/preset-sheets-core/worker'
import UniverPresetSheetsFilterEnUS from '@univerjs/preset-sheets-filter/locales/en-US'
import { UniverSheetsFilterWorkerPreset } from '@univerjs/preset-sheets-filter/worker'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsFilterEnUS,
    ),
  },
  presets: [
    UniverSheetsCoreWorkerPreset(),
    UniverSheetsFilterWorkerPreset(),
  ],
})
```

### Пример: листы-сотрудничество-с рабочим

`UniverSheetsDrawingPreset`

| <span data-config-options="">Option</span> | Тип | по умолчанию | Что он делает |
| --- | --- | --- | --- |
| `collaboration` | `boolean` | `false` | Включить совместное хранение изображений с помощью службы совместной работы для ввода/вывода изображений. |

`UniverSheetsAdvancedPreset`

| <span data-config-options="">Option</span> | Тип | по умолчанию | Что он делает |
| --- | --- | --- | --- |
| `useWorker` | `boolean` | `false` | Включите расширенные плагины вычислений в Рабочем. |
| `license` | `string` |  | Содержимое файла лицензии клиента. |

`UniverSheetsAdvancedWorkerPreset`

| <span data-config-options="">Option</span> | Тип | по умолчанию | Что он делает |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое файла лицензии клиента. |

```typescript title="main.ts"
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'
import UniverPresetSheetsAdvancedEnUS from '@univerjs/preset-sheets-advanced/locales/en-US'
import { UniverSheetsCollaborationPreset } from '@univerjs/preset-sheets-collaboration'
import UniverPresetSheetsCollaborationEnUS from '@univerjs/preset-sheets-collaboration/locales/en-US'
import { UniverSheetsCorePreset } from '@univerjs/preset-sheets-core'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsDrawingPreset } from '@univerjs/preset-sheets-drawing'
import UniverPresetSheetsDrawingEnUS from '@univerjs/preset-sheets-drawing/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-sheets-core/lib/index.css'
import '@univerjs/preset-sheets-drawing/lib/index.css'
import '@univerjs/preset-sheets-advanced/lib/index.css'
import '@univerjs/preset-sheets-collaboration/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsDrawingEnUS,
      UniverPresetSheetsAdvancedEnUS,
      UniverPresetSheetsCollaborationEnUS,
    ),
  },
  collaboration: true,
  presets: [
    UniverSheetsCorePreset({
      workerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
    }),
    UniverSheetsDrawingPreset({
      collaboration: true,
    }),
    UniverSheetsAdvancedPreset({
      useWorker: true,
      license: process.env.UNIVER_CLIENT_LICENSE || 'your license.txt',
    }),
    UniverSheetsCollaborationPreset({
    }),
  ],
})
```

```typescript title="worker.ts"
import UniverPresetSheetsAdvancedEnUS from '@univerjs/preset-sheets-advanced/locales/en-US'
import { UniverSheetsAdvancedWorkerPreset } from '@univerjs/preset-sheets-advanced/worker'
import UniverPresetSheetsCoreEnUS from '@univerjs/preset-sheets-core/locales/en-US'
import { UniverSheetsCoreWorkerPreset } from '@univerjs/preset-sheets-core/worker'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetSheetsCoreEnUS,
      UniverPresetSheetsAdvancedEnUS,
    ),
  },
  presets: [
    UniverSheetsCoreWorkerPreset(),
    UniverSheetsAdvancedWorkerPreset({
      license: process.env.UNIVER_CLIENT_LICENSE || 'your license.txt',
    }),
  ],
})
```

[^web-worker]: Web Worker выполняет JavaScript вне главного потока браузера и обменивается с ним сообщениями. Прямого доступа к DOM нет: перенос вычислений не переносит интерфейс редактора.
