## 全局生命周期

- **Starting**：Univer 正在初始化，尚未创建任何业务实例。
- **Ready**：第一个业务实例已创建完成，后续实例不会再次触发该阶段。
- **Rendered**：标准 UI 已完成首次渲染切换，异步内容可能尚未完成。
- **Steady**：标准 UI 在 Rendered 之后延时进入该阶段，不会等待所有异步任务完成。

### Facade API

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="事件监听的范围">

`LifeCycleChanged` 报告的是 Univer 的全局阶段。例如，在全局阶段到达 `Ready` 之后才加载插件 B，B 会执行 `onReady()`，但不会再次发出全局 `Ready` 事件。

添加监听器时，回调可能立即收到当前阶段，包括 `Starting`。如果只需确认当前阶段，可直接调用 `univerAPI.getCurrentLifecycleStage()`。

</Callout>

要移除监听器，可使用调用返回的 `disposable` 对象：

```typescript
disposable.dispose()
```

## 插件生命周期钩子

插件加载时执行 `onStarting()`，随后补齐至当前全局阶段的钩子。调整 B 的加载时机，即可比较它与 A 的钩子调用差异。

<LifecycleDemo />

通用插件在注册时加载。业务类型插件通常在创建该类型的第一个实例之前加载；对于已经启动的类型，新增插件会放入延迟批次加载。显式依赖也可能使插件提前加载。

同一批次内，钩子按依赖顺序逐阶段同步调用，不会等待钩子中的异步任务。访问业务实例、DOM 元素或资源之前，应先确认其已就绪。
