## 全域生命週期

- **Starting**：Univer 正在初始化，尚未建立任何業務例項。
- **Ready**：第一個業務例項已建立完成，後續例項不會再次觸發該階段。
- **Rendered**：標準 UI 已完成首次渲染切換，非同步內容可能尚未完成。
- **Steady**：標準 UI 在 Rendered 之後延時進入該階段，不會等待所有非同步任務完成。

### Facade API

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="事件監聽的範圍">

`LifeCycleChanged` 報告的是 Univer 的全域性階段。例如，在全域性階段到達 `Ready` 之後才載入外掛 B，B 會執行 `onReady()`，但不會再次發出全域性 `Ready` 事件。

新增監聽器時，回撥可能立即收到當前階段，包括 `Starting`。如果只需確認當前階段，可直接呼叫 `univerAPI.getCurrentLifecycleStage()`。

</Callout>

要移除監聽器，可使用呼叫返回的 `disposable` 物件：

```typescript
disposable.dispose()
```

## 外掛生命週期鉤子

外掛載入時執行 `onStarting()`，隨後補齊至當前全域性階段的鉤子。調整 B 的載入時機，即可比較它與 A 的鉤子呼叫差異。

<LifecycleDemo />

通用外掛在註冊時載入。業務型別外掛通常在建立該型別的第一個例項之前載入；對於已經啟動的型別，新增外掛會放入延遲批次載入。顯式依賴也可能使外掛提前載入。

同一批次內，鉤子按依賴順序逐階段同步呼叫，不會等待鉤子中的非同步任務。訪問業務例項、DOM 元素或資源之前，應先確認其已就緒。
