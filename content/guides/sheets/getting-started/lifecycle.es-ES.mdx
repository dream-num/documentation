## Ciclo de vida global

- **Comenzar**: Univer está inicializando, y no existe ninguna unidad de negocio todavía.
- **Listo**: La primera unidad de negocio ha sido creada. Unidades posteriores no activan esta etapa de nuevo.
- **Rendered**: La interfaz de usuario estándar ha completado su primer interruptor de renderizado. El contenido asincrónico puede no ser terminado.
- **Tranquila.**: La interfaz de usuario estándar entra en esta etapa después de un retraso después de Rendered. No espera todas las tareas asincrónicas.

### API de Facade

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="Qué comunica el evento">

`LifeCycleChanged` reporta la etapa global de Univer. Por ejemplo, si el plugin B carga después de la etapa global ha llegado a `Ready`, B's `onReady()` funciona, pero no se emite ningún evento `Ready` global adicional.

Cuando se agrega un oyente, su callback puede recibir la etapa actual inmediatamente, incluyendo `Starting`. Para determinar sólo la etapa actual, llame directamente a `univerAPI.getCurrentLifecycleStage()` .

</Callout>

Para eliminar un oyente, utilice el objeto `disposable` que la llamada devuelve:

```typescript
disposable.dispose()
```

## Hooks del ciclo de vida de plugins

Cuando un plugin se carga, se ejecuta `onStarting()` y luego se pone al día a través de los ganchos de la etapa global actual. Carga B en un punto diferente en el tiempo para comparar sus llamadas de gancho con los de A.

<LifecycleDemo />

Los plugins generales se cargan cuando se registran. Los plugins de tipo empresarial suelen cargar antes de que se construya la primera unidad de ese tipo. Un nuevo plugin para un tipo que ya ha comenzado cargas en un lote diferido.

Dentro de un lote, los ganchos se llaman sincrónicamente, etapa por etapa, en orden de dependencia. El trabajo asincrónico dentro de un gancho no se espera. Confirme que una unidad, un elemento DOM, o un recurso existe antes de acceder a él.
