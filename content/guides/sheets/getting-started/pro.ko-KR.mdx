Univer는 더욱 복잡한 애플리케이션 환경을 지원하기 위해 Pro 버전을 제공합니다. Pro 버전은 더 많은 기능과 역량을 갖추고 있어, 높은 성능과 다양한 기능이 필요한 애플리케이션에 적합합니다.

문서에서 Univer Pro와 관련된 부분은 <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} /> 아이콘으로 표시됩니다.

Univer Pro의 일부 기능을 사용하려면 Univer 서버와 연동해야 합니다. 자세한 내용은 [Univer Pro 서버](/guides/pro/server)를 참고하세요.

Univer Pro 라이선스가 없으면 일부 기능에 다음과 같은 제한이 적용됩니다.

| 기능 | 라이선스가 없을 때의 제한 사항 |
| --- | --- |
| 고급 수식 엔진 | 워터마크 |
| 인쇄 | 워터마크<br />한 번에 최대 3페이지만 인쇄 가능 |
| 차트 | 워터마크<br />선형 차트, 막대 차트, 원형 차트 및 가로 막대 차트만 지원 |
| 스파크라인 | 워터마크 |
| 도형 | 워터마크 |
| 피벗 테이블 | 워터마크<br />문서당 피벗 테이블을 하나만 생성 가능 |
| 공동 편집 | 워터마크<br />동시에 공동 편집할 수 있는 문서는 최대 5개<br />문서당 공동 작업자는 최대 3명 |
| 편집 기록 | 워터마크 |
| 가져오기 및 내보내기 | 워터마크<br />가져올 파일은 최대 1MB<br />내보낼 파일은 최대 10,000셀 |

Univer Pro 라이선스를 구매하는 방법은 [Univer Pro 구매 페이지](/guides/pro)를 참고하세요.
