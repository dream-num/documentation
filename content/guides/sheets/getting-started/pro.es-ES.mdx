Univer proporciona una versión Pro para cumplir con escenarios de aplicaciones más complejos. La versión Pro incluye más características y capacidades, adecuadas para aplicaciones que requieren mayor rendimiento y más funcionalidades.

Las partes de la documentación relacionadas con Univer SDK Pro estarán marcadas con <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} />.

Sigue la [integración del servidor](/guides/server-integration) para ejecutar el ejemplo, conectar tu aplicación y verificar persistencia y permisos. Los detalles y ejemplos Web/Server están en [Univer Office](https://office.univer.ai/collaboration/quick-start).

Univer SDK Pro tiene algunas limitaciones en ciertas funciones cuando no tiene licencia:

| Característica | Limitaciones sin licencia |
| --- | --- |
| Motor de fórmulas avanzado | Watermark |
| Printing | Marca de agua<br />No más de 3 páginas por imprimir |
| Charts | Marca de agua<br />Solo admite gráficos de líneas, gráficos de barras, gráficos circulares y gráficos de barras |
| Sparklines | Watermark |
| Shapes | Watermark |
| Tablas dinámicas | Marca de agua<br />Solo se puede crear una tabla dinámica por documento |
| Edición colaborativa | Marca de agua<br />No se pueden editar de forma colaborativa más de 5 documentos al mismo tiempo<br />No más de 3 colaboradores por documento |
| Historial de ediciones | Watermark |
| Importar y exportar | Marca de agua<br />Importar archivos de no más de 1 MB<br />Exportar archivos no más de 10.000 celdas |

Para obtener información sobre cómo obtener una licencia de Univer SDK Pro, consulte la [Univer](https://univer.ai).
