## Основные понятия [#basic-concepts]

Прежде чем углубляться в Univer, ознакомьтесь с его основными понятиями. Это поможет вам увереннее работать с системой.

К основным понятиям относятся:

- Плагин
- Снимок
- Команда
- Facade API

### Плагины

Все возможности Univer предоставляются плагинами — базовыми строительными блоками системы. Приложение Univer формируется из нескольких объединённых плагинов.

Плагины выполняют следующие задачи:

1. Реализуют функции: например, `@univerjs/sheets-filter` добавляет фильтрацию.
2. Предоставляют базовые возможности: например, `@univerjs/engine-render` отвечает за рендеринг.

Вы можете комбинировать плагины Univer, чтобы настроить приложение под свои требования и не загружать лишний код. Кроме того, вы можете создавать собственные плагины и расширять возможности Univer для конкретных задач.

### Снимок

Чтобы загрузить документ в Univer, необходимо загрузить его снимок. Для каждого типа документа предусмотрен собственный формат снимка. В документации API описано, как сформировать снимок в соответствии с требованиями формата:

1. Формат снимка электронной таблицы — [`IWorkbookData`](/guides/sheets/model/workbook-data#iworkbookdata).
2. Формат снимка документа — [`IDocumentData`](https://reference.univer.ai/en-US/interfaces/IDocumentData).

Функциональные плагины могут хранить ресурсы, например изображения, в поле `resources`. Подробнее см. в разделе [Пользовательская модель плагина](/guides/recipes/tutorials/custom-model).

<Callout type="warning" title="Внимание">
  Снимок Univer предназначен только для хранения данных. Во время выполнения он не отражает актуальное состояние документа. Чтобы сохранить текущее состояние документа как снимок, используйте соответствующий метод Facade API.
</Callout>

### Команда

В Univer любые изменения данных выполняются с помощью команд. Командный подход позволяет отслеживать изменения значений, реализовывать отмену и повтор действий, совместное редактирование, а также обрабатывать сложные взаимосвязи между функциями.

Если вы хотите изменять данные документа с помощью команд, см. раздел [Как найти идентификатор команды](/guides/recipes/practices/find-the-command-id). При изменении данных через Facade API этот API сам подготавливает параметры и выполняет команды внутри системы.

<Callout type="warning" title="Внимание">
  **Не изменяйте снимок напрямую.** Такие изменения не вступят в силу и не приведут к обновлению представлений или интерфейса. Изменяйте данные с помощью команд или Facade API.
</Callout>

### Facade API

Офисные приложения сложны, поэтому архитектура Univer также достаточно комплексна. Чтобы разработчикам было проще работать с Univer, мы предоставляем Facade API — оболочку над официальными плагинами Univer с более простыми интерфейсами.

Facade API активно развивается. Если у вас есть вопросы или пожелания, создайте issue на GitHub.

Facade API — это высокоуровневый API, скрывающий детали внутренней реализации. Он упрощает типовые задачи, однако для сложных функций может потребоваться понимание архитектуры Univer и прямое использование низкоуровневого API.
