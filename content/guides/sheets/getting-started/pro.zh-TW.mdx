為了滿足更複雜的應用情境，Univer 提供了 Univer SDK Pro 版本。Pro 版本包含更多功能與特性，適用於需要更高效能與更完整能力的場景。

文件中與 Univer SDK Pro 相關的部分會以 <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} /> 進行標示。

請從[伺服器端整合](/guides/server-integration)開始，依序執行範例、接入業務、驗證持久化和權限。實作細節與可執行的 Web/Server 範例請見 [Univer Office 文件](https://office.univer.ai/zh-CN/collaboration/quick-start)。

在未取得授權的情況下，Univer SDK Pro 的部分功能將受限：

| 功能 | 未授權限制 |
| --- | --- |
| 進階公式引擎 | 浮水印 |
| 列印 | 浮水印<br />每次列印不超過 3 頁 |
| 圖表 | 浮水印<br />僅支援折線圖、柱狀圖、圓餅圖、條形圖 |
| 迷你圖 | 浮水印 |
| 形狀 | 浮水印 |
| 資料透視表 | 浮水印<br />每個文件僅能建立一個資料透視表 |
| 協同編輯 | 浮水印<br />同時協作的文件數不超過 5 個<br />每個文件的協作者數量不超過 3 人 |
| 編輯紀錄 | 浮水印 |
| 匯入與匯出 | 浮水印<br />匯入檔案不超過 1MB<br />匯出檔案不超過 10k 個儲存格 |

關於 Univer SDK Pro 的授權方式，請參考 [Univer](https://univer.ai)。
