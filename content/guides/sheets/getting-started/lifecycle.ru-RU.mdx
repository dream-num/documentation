## Глобальный жизненный цикл

- **Начинать**: Univer является инициализацией, и бизнес-единицы пока не существует.
- **Готовы**: Создано первое бизнес-подразделение. Позднее подразделения не запускают этот этап снова.
- **отданный**: Стандартный пользовательский интерфейс завершил свой первый переключатель рендеринга. Асинхронное содержимое может быть не завершено.
- **стойкий**: Стандартный пользовательский интерфейс входит в эту стадию после задержки после Rendered. Он не ждет всех асинхронных задач.

### Facade API

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="Что сообщает событие">

`LifeCycleChanged` сообщает о глобальной стадии Univer. Например, если плагин B загружается после того, как глобальная стадия достигла `Ready`, запускается `onReady()` B, но не излучается дополнительное глобальное событие `Ready` .

При добавлении слушателя его обратный вызов может сразу же получить текущий этап, в том числе `Starting`. Для определения только текущего этапа звоните `univerAPI.getCurrentLifecycleStage()` напрямую.

</Callout>

Чтобы удалить слушателя, используйте объект `disposable`, который возвращает вызов:

```typescript
disposable.dispose()
```

## Хуки жизненного цикла плагинов

Когда плагин загружается, он запускает `onStarting()`, а затем догоняет крючки текущей глобальной стадии. Загрузите B в другой момент времени, чтобы сравнить его крючковые вызовы с вызовами A.

<LifecycleDemo />

Общие плагины загружаются при регистрации. Плагины бизнес-типа обычно загружаются до того, как построен первый блок этого типа. Новый плагин для типа, который уже начал нагрузки в отложенной партии. Явные зависимости могут вызвать более раннюю загрузку.

Внутри партии крючки называются синхронно, поэтапно, в порядке зависимости. Асинхронная работа внутри крючка не ожидается. Подтвердите, что перед доступом к нему существует блок, DOM-элемент или ресурс.
