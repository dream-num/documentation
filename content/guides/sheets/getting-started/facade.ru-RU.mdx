Через Facade API можно подключить чтение и запись данных книги, форматирование и события редактора к бизнес-процессам. Операции организованы по объектам [книги](/reference/facade/workbook), [листа](/reference/facade/worksheet) и [диапазона](/reference/facade/range).

<Callout type="warning" title="Обратите внимание">
  Для методов, возвращающих Promise, дождитесь завершения через `await` или `.then()`, прежде чем читать результат или выполнять зависимый шаг. Другие методы сразу возвращают значение или объект Facade. Проверяйте тип результата в справочнике API.
</Callout>

## Интеграция Facade API в режиме плагинов

### Установка

При установке Univer в режиме плагинов реализация Facade API распределена между разными плагинами и подключается к глобальному корневому объекту Facade API. Поэтому для плагинов, предоставляющих Facade API, можно по мере необходимости импортировать соответствующие реализации.

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs/ui/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="Обратите внимание">
  Пакет facade входит не во все плагины. Это будет указано в документации каждой возможности.
</Callout>

### Использование

Facade API служит оболочкой для экземпляра Univer, поэтому после создания экземпляра Univer его необходимо обернуть с помощью `FUniver`:

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Интеграция Facade API в режиме предустановок

Если вы интегрируете Univer в режиме предустановок, Facade API для включённых возможностей импортируется автоматически. При создании экземпляра Univer возвращается соответствующий экземпляр Facade API — `univerAPI`, который можно использовать сразу.

## Важные замечания

Не все методы Facade API можно вызывать сразу: некоторые из них должны использоваться на определённых этапах жизненного цикла. Если метод не срабатывает при немедленном вызове, выберите подходящий этап жизненного цикла следующим образом:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Code to be executed when the lifecycle stage is Rendered
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Code to be executed when the lifecycle stage is Steady
  }
})
```
