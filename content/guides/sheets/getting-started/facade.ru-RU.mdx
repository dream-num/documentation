Архитектура Univer должна соответствовать сложным требованиям, и основной API отражает эту сложность. поэтому Univer также обеспечивает Facade API, более простой уровень, который код приложения вызывает непосредственно.

На этой странице описано, как добавить Facade API в приложение. На страницах в разделе «Функции» перечислены основные API-интерфейсы Facade для каждой функции; для полного набора см. ссылку API каждого плагина.

<Callout type="warning" title="Осторожно">
  Некоторые API-интерфейсы Facade являются асинхронными, а те, которые модифицируют данные, часто возвращают Обещание. Когда данные считываются сразу после их изменения, `await` вызывает или цепочку `.then()`; в противном случае результаты могут быть неожиданными. Чтобы определить, возвращает ли API Обещание, обратитесь к соответствующей ссылке API.
</Callout>

## Интеграция Facade API в режиме плагинов

### Установка

В режиме плагина каждый плагин поставляется с собственной реализацией Facade API, и все они прикрепляются к одному глобальному объекту Facade API. Для каждого плагина, который предоставляет Facade API импортируйте соответствующую реализацию по мере необходимости.

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs/ui/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="Осторожно">
  Не каждый плагин включает в себя пакет фасада. Каждая страница функции указывает, делает ли это.
</Callout>

### Использование

Facade API обертывает экземпляр Univer. Сначала создайте экземпляр, а затем заверните его в `FUniver`:

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Интеграция Facade API в режиме предустановок

В предустановленном режиме пресеты импортируют Facade API для содержащихся в них функций.Создание экземпляра Univer возвращает соответствующий экземпляр `univerAPI`, который можно использовать немедленно.

## Важные замечания

Не каждый Facade API может быть вызван немедленно. Некоторые вступают в силу только на определенном этапе жизненного цикла. Когда немедленный вызов не вступает в силу, выберите соответствующий этап следующим образом:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Code to be executed when the lifecycle stage is Rendered
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Code to be executed when the lifecycle stage is Steady
  }
})
```
