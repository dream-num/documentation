本页介绍 Univer Sheets 的五个核心概念：Unit（内容单元）、插件、快照、命令和 Facade API。如需在编辑器中查看这些概念的实际效果，请参阅[安装和基本使用](/guides/sheets/getting-started/installation)。

## 基本概念 [#basic-concepts]

以下五个术语在 Univer 中反复出现：

- Unit（内容单元）
- Plugin（插件）
- Snapshot（快照）
- Command（命令）
- Facade API

### Unit（内容单元） [#unit]

**Unit（内容单元）** 是 Univer 管理的一份完整内容实例：工作簿、文档、演示文稿、Base、画板或 PDF。每个 Unit 都有自己的 ID（`unitId`），因此同一类型的两份文档是两个不同的 Unit。

包含多个工作表的工作簿仍然是一个 Unit。工作表、单元格区域和单元格都是它的内部对象，不是独立的 Unit。幻灯片同理，它属于所在的演示文稿 Unit。

一个 Univer 实例可以加载多个 Unit。**Snapshot（快照）** 是描述某个 Unit 内容状态的可序列化数据，与正在编辑的运行时 Unit 不是同一个对象。Unit 级权限作用于整份内容，对象级权限则细化到内部的工作表、段落或元素。

### 插件

Univer 的功能都以插件形式提供。插件是 Univer 应用的基本组成单元，注册的插件集合定义了这个应用。

插件承担两类工作：

1. 增加功能。例如 `@univerjs/sheets-filter` 提供筛选功能。
2. 提供其他插件依赖的基础能力。例如 `@univerjs/engine-render` 提供渲染能力。

按需组合插件可以构建符合需求的 Univer 应用，不必加载用不到的代码。Univer 没有提供所需插件时，也可以自行编写插件来扩展功能。

### 快照

Univer 通过加载快照来加载文档。每种文档类型有自己的快照格式，编写快照时必须与 API 类型一致：

1. 电子表格的快照格式是 [`IWorkbookData`](/guides/sheets/model/workbook-data#iworkbookdata)。
2. 文档的快照格式是 [`IDocumentData`](/reference/types/document-data)。

功能插件使用 `resources` 字段存储资源，例如图片。具体做法见[插件自定义模型](/blog/custom-model)。

<Callout type="warning" title="注意事项">
  快照只用于存储数据。Univer 运行之后，快照并不反映文档的最新状态。如需把当前状态保存为快照，请使用 Facade API 上的保存快照方法。
</Callout>

### 命令

在 Univer 中，所有对文档数据的修改都通过命令完成。命令让 Univer 在一个位置观察变化，撤销、重做和协同编辑都建立在这一机制之上，功能之间的依赖关系也由 Univer 统一处理。

如需自行发送命令，请参阅[如何查找命令 ID](/blog/find-the-command-id)。如果改为通过 Facade API 修改数据，它会准备命令参数并发送对应的命令。

<Callout type="warning" title="注意事项">
  **不要直接修改 snapshot。** 这样修改不会生效，也不会触发视图或 UI 更新。数据应通过命令或 Facade API 修改。
</Callout>

### Facade API

办公应用本身较为复杂，Univer 的架构同样如此。Facade API 在第一方插件之上提供了一层更简单的接口，因此不必先理解整套架构即可完成开发任务。

Facade API 仍在持续完善。如有建议或需求，可以在 GitHub 上提交 issue。

Facade API 属于高层 API，隐藏了底层细节。常见任务的代码因此更短；复杂功能可能仍需理解 Univer 的架构，并直接调用底层 API。

## 预设模式与插件模式

预设是一组已经配置好的插件。两种模式在插件相同时提供相同的能力，区别在于应用需要自行提供多少配置。如需快速开始，使用预设；如需明确控制插件组合和加载时机，使用插件模式。

<Callout type="warning" title="注意事项">
  所有 Univer 依赖的版本号要保持一致。如果某个预设已经包含了某个插件，就不要再单独注册它，否则可能出现插件冲突或功能异常。
</Callout>

| 插件模式 | 预设模式 |
| --- | --- |
| 需要手动引入对应的 facade 包 | facade 包已包含在预设里 |
| 需要注意同类型功能插件的注册顺序 | 预设管理它包含的插件 |
| 支持按需懒加载 | 配置好的预设在初始化时一起加载 |
