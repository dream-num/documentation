Для более сложных сценариев использования Univer предлагает версию Pro. В неё входят дополнительные возможности и функции, поэтому она подходит для приложений, которым требуется более высокая производительность и расширенная функциональность.

Разделы документации, относящиеся к Univer Pro, отмечены значком <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} />.

Некоторые возможности Univer Pro требуют интеграции с сервером Univer. Подробности приведены в разделе [«Сервер Univer Pro»](/guides/pro/server).

Без лицензии на некоторые возможности Univer Pro действуют ограничения:

| Возможность | Ограничения без лицензии |
| --- | --- |
| Расширенный движок формул | Водяной знак |
| Печать | Водяной знак<br />Не более 3 страниц за одну печать |
| Диаграммы | Водяной знак<br />Поддерживаются только линейные, столбчатые, круговые и линейчатые диаграммы |
| Спарклайны | Водяной знак |
| Фигуры | Водяной знак |
| Сводные таблицы | Водяной знак<br />В одном документе можно создать только одну сводную таблицу |
| Совместное редактирование | Водяной знак<br />Одновременно можно совместно редактировать не более 5 документов<br />Не более 3 участников на документ |
| История изменений | Водяной знак |
| Импорт и экспорт | Водяной знак<br />Размер импортируемого файла не более 1MB<br />Экспорт не более 10k ячеек |

Информация о приобретении лицензии Univer Pro приведена на [странице покупки Univer Pro](/guides/pro).
