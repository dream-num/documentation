## Cycle de vie global

- **Début**: Univer initialise, et aucune unité commerciale n'existe encore.
- **Prêt**: La première unité commerciale a été créée. Les unités ultérieures ne déclenchent pas cette étape à nouveau.
- **Rendu**: L'interface utilisateur standard a terminé son premier commutateur de rendu. Le contenu asynchrone peut ne pas être terminé.
- **Stabilité**: L'interface utilisateur standard entre dans cette étape après un délai après la soumission. Elle n'attend pas toutes les tâches asynchrones.

### API Facade

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="Ce que signale l’événement">

`LifeCycleChanged` rapporte la phase globale de Univer. Par exemple, si le plugin B se charge après que la phase globale ait atteint `Ready`, le `onReady()` de B fonctionne, mais aucun événement global supplémentaire `Ready` n'est émis.

Lorsqu'un auditeur est ajouté, son callback peut recevoir l'étape actuelle immédiatement, y compris `Starting`. Pour déterminer seulement l'étape courante, appelez directement `univerAPI.getCurrentLifecycleStage()` .

</Callout>

Pour supprimer un auditeur, utilisez l'objet `disposable` que l'appel renvoie :

```typescript
disposable.dispose()
```

## Hooks de cycle de vie des plugins

Lorsqu'un plugin charge, il exécute `onStarting()` puis rattrape à travers les crochets de la phase globale actuelle. Chargez B à un autre moment dans le temps pour comparer ses appels de crochet avec ceux de A.

<LifecycleDemo />

Les plugins de type Business chargent généralement avant la construction de la première unité de ce type. Un nouveau plugin pour un type qui a déjà commencé des chargements dans un lot différé. Les dépendances explicites peuvent déclencher un chargement plus tôt.

Dans un lot, les crochets sont appelés synchrones, étape par étape, dans l'ordre de dépendance. Le travail asynchrone à l'intérieur d'un crochet n'est pas attendu. Confirmez qu'une unité, un élément DOM, ou une ressource existe avant d'y accéder.
