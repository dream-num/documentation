Um komplexe Anforderungen zu erfüllen, ist die Architektur von Univer auch recht komplex, was zu einigen Schwierigkeiten bei der Verwendung führen kann. Um dieses Problem zu beheben, bieten wir eine einfachere und benutzerfreundlichere Facade-API.

In diesem Kapitel wird im Detail gezeigt, wie Sie Facade API zu Ihrer Anwendung hinzufügen. Im folgenden Kapitel „Funktionen“ werden wir die Haupt-Facade-API jeder Funktion auflisten. Wenn Sie die gesamte Facade-API sehen möchten, lesen Sie bitte die API-Referenz jedes Plugins.

<Callout type="warning" title="Cuation">
Einige Facade-APIs sind asynchron, insbesondere solche, die Daten ändern, die häufig ein Versprechen zurückgeben. Wenn Sie Daten unmittelbar nach der Änderung abrufen müssen, verwenden Sie bitte `await` oder `.then()`, andernfalls erhalten Sie möglicherweise unerwartete Ergebnisse. Um herauszufinden, welche spezifischen APIs Versprechen zurückgeben, lesen Sie bitte das entsprechende API-Referenzhandbuch.
</Callout>

## Integration der Facade-API im voreingestellten Modus

Wenn Sie Univer im voreingestellten Modus integrieren, importiert es automatisch die Facade-API für die enthaltenen Funktionen und gibt eine entsprechende Facade-API-Instanz `univerAPI` zurück, wenn Sie eine Univer-Instanz erstellen. Sie können es direkt verwenden.

## Integration der Facade-API im Plugin-Modus

### Installation

Um die Facade-API bei der Installation von Univer über den Plugin-Modus zu integrieren, wird die Implementierung der Facade-API auf verschiedene Plugins verteilt und im globalen Facade-API-Stammobjekt bereitgestellt. Das bedeutet, dass Sie für die Plugins, die die Facade-API bereitstellen, bei Bedarf die entsprechenden Facade-API-Implementierungen importieren können.

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs/ui/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="Cuation">
Nicht alle Plugins enthalten ein Fassadenpaket; Wir werden dies in der Dokumentation für jede Funktion angeben.
</Callout>

### Verwendung

Facade API ist ein Wrapper um die Univer-Instanz, daher müssen Sie die Univer-Instanz nach der Erstellung mit `FUniver` umschließen:

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Vorsichtsmaßnahmen

Nicht alle Facade-APIs können sofort aufgerufen werden; Einige APIs müssen in bestimmten Lebenszyklusphasen verwendet werden. Wenn bei der sofortigen Ausführung Probleme auftreten, verwenden Sie bitte die folgende Methode, um die entsprechende Lebenszyklusphase für die Ausführung auszuwählen:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Code to be executed when the lifecycle stage is Rendered
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Code to be executed when the lifecycle stage is Steady
  }
})
```
