通过 Facade API，把工作簿数据读写、格式设置和编辑器事件接入你的业务流程。常用操作按工作簿、工作表和选区组织，可以从对应对象找到需要的方法。

按下方集成模式获取 `univerAPI`，或直接查看[如何查找 API 或命令](#find-apis-and-commands)。

<Callout type="warning" title="注意事项">
  调用返回 Promise 的方法时，先用 `await` 或 `.then()` 等待完成，再读取结果或执行依赖它的下一步。其他方法会直接返回值或 Facade 对象，请以对应 API 的返回类型为准。
</Callout>

## 插件模式引入 Facade API

### 安装

对于通过插件模式安装 Univer 的情况下，Facade API 的实现被分散到各个插件中，并挂载到全局的 Facade API 根对象上，这意味着对于那些提供了 Facade API 的插件，你可以按需引入他们对应的 Facade API 实现。

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs/ui/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="注意事项">
  并非所有插件都包含了 facade 包，我们会在每个功能的文档对此进行说明。
</Callout>

### 使用

Facade API 是对 Univer 实例的封装，因此你需要在创建了 Univer 实例之后，再用 `FUniver` 包裹该实例：

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 预设模式引入 Facade API

如果你通过预设模式安装 Univer，它会自动引入所含功能的 Facade API，并在你创建 Univer 实例时返回一个对应的 Facade API 实例 `univerAPI`，直接使用即可。

## 注意事项

并非所有的 Facade API 都可以被即时调用，有些 API 需要在特定的生命周期阶段才能使用，遇到即时执行无法生效的情况，请参照以下方式选择合适的生命周期执行：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // 在生命周期阶段为 Rendered 时执行的代码
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // 在生命周期阶段为 Steady 时执行的代码
  }
})
```

## 查找 API 或命令 [#find-apis-and-commands]

先从功能指南找到任务，再沿 Facade 参考定位[工作簿](/reference/facade/workbook)、[工作表](/reference/facade/worksheet)或[选区](/reference/facade/range)上的方法。调用方法需要注册所属插件；插件模式还需要导入对应的 Facade。

Facade 未覆盖任务时，在[所属包的参考页](/reference/packages/plugins/univerjs/sheets)中查找导出的命令，使用其 `.id`。菜单项 ID、命令和 Mutation 是不同概念，不要根据工具栏文字猜测命令 ID。

```typescript
import { SetRangeValuesCommand } from '@univerjs/sheets'

console.log(SetRangeValuesCommand.id)
```

要确定某个交互执行了什么命令，可以先注册下面的监听器，再在编辑器中操作并查看输出。监听不会执行命令，也不代表观察到的 Mutation 都适合直接调用。

```typescript
const commandLog = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, type }) => {
  console.log(id, type)
})
```

排查结束后移除监听。命令注册、参数与撤销重做见[自定义命令](/blog/custom-command)。

```typescript
commandLog.dispose()
```
