Univer Office SDK включает [Web SDK](/guides/sheets) для встроенных редакторов и обработки контента без интерфейса, [Server SDK](/server) для совместной работы и импорта и экспорта файлов, а также [AI SDK](/ai) для рабочих процессов агентов.

**Univer** — набор инструментов для Office-приложений, в которых люди и AI Agents работают с одним содержимым. Приложение может предоставить Web для людей, CLI для AI Agents и общий Server либо использовать лишь нужные компоненты.

Документация разделена на [Web SDK](/guides/sheets), [Server SDK](/server) и [AI SDK](/ai): редакторы, совместные и файловые сервисы, операции с содержимым AI Agent.

AI SDK повторно использует возможности Web SDK без интерфейса. Компоненты обозначают основные входы разработки и места выполнения, а не три независимых стека или готовые продукты без прикладного кода.

## Интеграция импорта и экспорта

Модуль Server SDK `@univerjs-pro/exchange-node` преобразует Office и данные Univer. Приложение подключает его и предоставляет API загрузки, преобразования и скачивания. Web SDK управляет браузерным взаимодействием, CLI может вызывать модуль в Node.js. Браузерные настройки остаются в документации Web SDK каждого продукта.

- **Без совместной работы:** преобразуйте файл в снимок и редактируйте в браузере. Для экспорта передайте последний снимок модулю. Серверное преобразование необходимо, совместный сервис — нет.
- **С совместной работой:** сохраните импорт как совместный документ. Web и AI SDK работают с ним по ID. До экспорта синхронизируйте изменения, затем прочитайте и преобразуйте актуальные данные.

Для одной конвертации используйте Exchange в локальном Node.js или удалённом сервисе без AI SDK и совместного редактирования. Процесс описан в [Интеграции обмена файлами](/server/import-export), модуль — в [Импорте и экспорте Office](/server/import-export/node).

## Варианты развёртывания

| Вариант | Web | CLI | Server | Назначение |
| --- | --- | --- | --- | --- |
| Локальное приложение | Локальный браузер/настольный UI | Локальный процесс | Локальный процесс | Настольный Office и локальный AI Agent |
| SaaS | Браузер | Устройство пользователя/облачный AI Agent | Удалённый сервис | Несколько пользователей и централизованная эксплуатация |
| Web + Server | Браузер | — | Локальный или удалённый | Пока без входа AI Agent |
| Только Web | Браузер/настольный UI | — | — | Локальное одиночное редактирование |

Компоненты могут работать на одной машине или распределяться между клиентами и облаком. Размещение не меняет ответственность. Если есть Server, Web и CLI обращаются через него к общему содержимому и функциям.
