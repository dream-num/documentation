Univer follows [Semantic Versioning](https://semver.org/) (`MAJOR.MINOR.PATCH`).

- **MAJOR**: Incompatible API changes
- **MINOR**: New features, backwards compatible
- **PATCH**: Bug fixes, backwards compatible

## Release Channels

| Channel | Stability | Use Case |
|---------|-----------|----------|
| Stable (`latest`) | Production-ready | Production deployments |
| Beta (`beta`) | Feature-complete, testing | Pre-production validation |
| Alpha (`alpha`) | In development | Early access, feedback |
| Nightly (`nightly`) | Latest commits | Bleeding edge testing |

You can install a specific channel via npm tags:

```bash
npm install @univerjs/core@latest
npm install @univerjs/core@beta
npm install @univerjs/core@alpha
npm install @univerjs/core@nightly
```

> **Important**: Alpha, beta, and nightly versions may contain bugs or incomplete features. Avoid using them in production.

## Version History

Release notes for all versions are published on [GitHub Releases](https://github.com/dream-num/univer/releases).

### How to Upgrade

1. Review the [release notes](https://github.com/dream-num/univer/releases) for breaking changes
2. Update all `@univerjs/*` packages to the same target version
3. Run your test suite
4. Check the [Troubleshooting](/guides/troubleshooting) guide if issues arise

### Deprecation Policy

- Features marked as deprecated will continue to work for at least one minor version
- Deprecated APIs will log warnings in development builds
- Migration paths are documented in the release notes
