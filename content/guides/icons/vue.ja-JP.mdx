title: Vue への組み込み
description: Vue 3 プロジェクトに Univer アイコンをインストールして使用します。
---

Vue 3インターフェイスにアイコンを追加し、周囲のコントロールに合わせてサイズと色を調整します。

## パッケージをインストールする

Vue 3プロジェクトにアイコンパッケージをインストールします。

```package-install
npm install @univerjs/icons-vue
```

## ボタンにアイコンを追加する

[アイコンプレビュー](/guides/icons/all-icons)のコンポーネントを選択し、名前でインポートします。下のコピーボタンは、そのアイコンの横にあるテキストラベルを保持します。

```vue
<script setup lang="ts">
import { CopyIcon } from '@univerjs/icons-vue'

const emit = defineEmits<{ copy: [] }>()
</script>

<template>
  <button type="button" @click="emit('copy')">
    <CopyIcon aria-hidden="true" />
    <span>コピー</span>
  </button>
</template>
```

親コンポーネントで `copy` イベントを処理します。操作はボタンのテキストで伝わるため、アイコンは装飾として扱います。

## サイズと色を変える

アイコンは、周囲のテキストと`1em`からそのサイズから色を継承します。 アイコンの`fontSize`および`color`を設定して、どちらかの値を上書きします。

```vue
<script setup lang="ts">
import { AddImageIcon } from '@univerjs/icons-vue'
</script>

<template>
  <AddImageIcon
    aria-hidden="true"
    :style="{ fontSize: '20px', color: '#27272a' }"
  />
</template>
```

## 2 色のアイコンを調整する

2色のアイコンは、`color`をメインカラーと`extend.colorChannel1`で使用しています。以下の例では、ダークグレーのアクセントをライトグレーでペアリングします。

```vue
<script setup lang="ts">
import { PaintBucketDoubleIcon } from '@univerjs/icons-vue'
</script>

<template>
  <PaintBucketDoubleIcon
    aria-hidden="true"
    :style="{ fontSize: '20px', color: '#27272a' }"
    :extend="{ colorChannel1: '#d4d4d8' }"
  />
</template>
```

ブランドロゴを含むマルチカラーアイコンは、固定色で来るかもしれません。 これらの設定は、そのようなアイコンのすべての色を置き換えません。

## 拡大時の線幅を保つ

拡大したアイコンが重すぎる場合は、`preserveStrokeWidth`を使用してください。 16×16で持っている幅を維持するようにサポートするストロークは、埋め込まれた形状が影響を受けません。 それを適用する前に、プレビューのストローク制御で結果を確認してください。

```vue
<script setup lang="ts">
import { ShapePieIcon } from '@univerjs/icons-vue'
</script>

<template>
  <ShapePieIcon
    aria-hidden="true"
    preserve-stroke-width
    style="font-size: 48px"
  />
</template>
```

## アイコンだけのボタンに名前を付ける

ボタンが目に見えるテキストがない場合、`aria-label="Copy"`をボタンに追加し、画面リーダーがアクションをアナウンスできるように、アイコンに`aria-hidden="true"`を維持します。

AIエージェントがアイコンを見つけ、統合コードを書くには、[MCPの特長](/guides/icons/ai)を接続します。
