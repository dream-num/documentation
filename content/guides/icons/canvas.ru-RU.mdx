---
title: Рисование иконок на Canvas
---

Начиная с версии 1.48.0 пакета `@univerjs/icons-svg`, функция `drawCanvasIcon` синхронно рисует встроенные иконки в контексте Canvas 2D.

```package-install
npm install @univerjs/icons-svg
```

## Как нарисовать иконку фильтра

Добавьте на страницу элемент canvas и выполните код после создания элемента.

```html
<canvas id="toolbar-icons" width="48" height="24"></canvas>
```

```ts
import { drawCanvasIcon } from '@univerjs/icons-svg'

const canvas = document.querySelector<HTMLCanvasElement>('#toolbar-icons')
const ctx = canvas?.getContext('2d')

if (ctx) {
  drawCanvasIcon(ctx, 'filter-applied-icon', 4, 4, 16, '#2563eb')
}
```

Первые два числа задают координаты левого верхнего угла области рисования. Третье число задаёт сторону квадрата в единицах координат холста. Иконка располагается по центру с сохранением пропорций.

## Выбор имени и цветов

Экспортируемый тип `CanvasIconName` подсказывает поддерживаемые имена. Используйте имя файла без `.svg`, например `filter-applied-icon`. Для Canvas доступна часть иконок из каталога SVG.

Если опустить последний аргумент, сохранятся исходные цвета SVG. Один цвет заменяет основной и акцентный цвета. Чтобы заменить только выбранные цвета, передайте объект, в котором ключами служат исходные цвета SVG. В этом примере закрашенная половина звезды станет золотой.

```ts
if (ctx) {
  drawCanvasIcon(ctx, 'star-incomplete-double-icon', 28, 4, 16, { black: '#d97706' })
}
```

## Рисование иконки в сцене Univer

`@univerjs/engine-render` экспортирует `CanvasIconShape`, который рисует иконку Canvas как фигуру сцены. Его конструктор — `(key, icon, props)`: `key` идентифицирует фигуру, `icon` имеет тип `CanvasIconName`, а `props` — `IShapeProps`. Добавьте фигуру в сцену вызовом `scene.addObject(shape)`.

```ts
import { CanvasIconShape, IRenderManagerService } from '@univerjs/engine-render'

// Блок, в сцене которого должна находиться иконка.
const unitId = 'your-unit-id'
const render = univer.__getInjector().get(IRenderManagerService).getRenderUnitById(unitId)

if (render) {
  const shape = new CanvasIconShape('filter-icon', 'filter-applied-icon', {
    left: 24,
    top: 16,
    width: 16,
    height: 16,
    fill: '#2563eb',
  })

  render.scene.addObject(shape)
}
```

Фигура использует `Math.min(width, height)` как квадрат иконки и центрирует иконку в оставшемся пространстве. У неквадратной фигуры по длинной оси остаётся отступ.
