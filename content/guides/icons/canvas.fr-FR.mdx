---
title: Dessiner des icônes sur un canvas
---

Depuis la version 1.48.0 de `@univerjs/icons-svg`, `drawCanvasIcon` dessine une icône de manière synchrone dans un contexte Canvas 2D.

```package-install
npm install @univerjs/icons-svg
```

## Dessiner une icône de filtre

Ajoutez un canvas à la page, puis exécutez le code suivant une fois l’élément créé.

```html
<canvas id="toolbar-icons" width="48" height="24"></canvas>
```

```ts
import { drawCanvasIcon } from '@univerjs/icons-svg'

const canvas = document.querySelector<HTMLCanvasElement>('#toolbar-icons')
const ctx = canvas?.getContext('2d')

if (ctx) {
  drawCanvasIcon(ctx, 'filter-applied-icon', 4, 4, 16, '#2563eb')
}
```

Les deux premiers nombres indiquent les coordonnées du coin supérieur gauche de la zone de dessin. Le troisième fixe la longueur du côté du carré en unités du canvas. L’icône conserve ses proportions et reste centrée.

## Choisir le nom et les couleurs

Le type exporté `CanvasIconName` permet de compléter les noms pris en charge. Utilisez le nom de fichier sans `.svg`, par exemple `filter-applied-icon`. Une partie du catalogue SVG est disponible pour Canvas.

Omettez le dernier argument pour conserver les couleurs du SVG. Une couleur unique remplace la couleur principale et celle d’accent. Pour modifier une couleur précise, passez un objet dont les clés sont les couleurs d’origine du SVG. Cet exemple colore en doré la moitié pleine de l’étoile.

```ts
if (ctx) {
  drawCanvasIcon(ctx, 'star-incomplete-double-icon', 28, 4, 16, { black: '#d97706' })
}
```

## Dessiner une icône dans une scène Univer

`@univerjs/engine-render` exporte `CanvasIconShape`, qui dessine une icône Canvas comme forme de scène. Son constructeur est `(key, icon, props)` : `key` identifie la forme, `icon` est un `CanvasIconName`, et `props` est `IShapeProps`. Ajoutez la forme à la scène avec `scene.addObject(shape)`.

```ts
import { CanvasIconShape, IRenderManagerService } from '@univerjs/engine-render'

// The unit whose scene should contain the icon.
const unitId = 'your-unit-id'
const render = univer.__getInjector().get(IRenderManagerService).getRenderUnitById(unitId)

if (render) {
  const shape = new CanvasIconShape('filter-icon', 'filter-applied-icon', {
    left: 24,
    top: 16,
    width: 16,
    height: 16,
    fill: '#2563eb',
  })

  render.scene.addObject(shape)
}
```

La forme utilise `Math.min(width, height)` comme boîte de l'icône et centre l'icône dans l'espace restant. Une forme non carrée laisse une marge sur l'axe le plus long.
