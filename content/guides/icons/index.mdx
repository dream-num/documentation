Univer Icons is an icon library for toolbars, menus, and document editing interfaces. It supports React and Vue 3, and an interface imports the icons it needs.

<IconsVersion label="Icon package version:" />

## Choose your integration

Install the package that matches your framework. Both packages share the same component names, such as `CopyIcon` and `SearchIcon`.

| Framework | Package |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |

## Find an icon

The [icon preview](/guides/icons/all-icons) supports browsing by category and searching with an English keyword such as `copy` or `search`. Adjust the size and colors to check how an icon fits the interface, then click it to copy its React import.

When working with an AI Agent, connect it to [MCP](/guides/icons/ai) and describe the action the icon should represent. The agent looks up matching icons and their React or Vue usage.
