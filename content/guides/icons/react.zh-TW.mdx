---
title: 在 React 中整合
description: 在 React 專案中安裝和使用 Univer Icons。
---

將圖示加入 React 介面，然後調整尺寸和顏色，使其與周圍控制元件保持一致。

## 安裝圖示套件

在 React 專案中安裝圖示包：

```package-install
npm install @univerjs/icons
```

## 在按鈕中加入圖示

在[圖示預覽](/guides/icons/all-icons)中選擇一個元件，並按元件名匯入。下面的複製按鈕將文字標籤與圖示並排顯示。

```tsx
import { CopyIcon } from '@univerjs/icons'

export function CopyButton({ onCopy }: { onCopy: () => void }) {
  return (
    <button type="button" onClick={onCopy}>
      <CopyIcon aria-hidden="true" />
      <span>複製</span>
    </button>
  )
}
```

複製邏輯透過 `onCopy` 傳入。此處圖示僅作裝飾，因為可見文字已經說明了該操作。

## 調整尺寸和顏色

圖示預設繼承周圍文字的顏色，尺寸取自 `1em`。在圖示上設定 `fontSize` 和 `color` 即可覆蓋這兩個值：

```tsx
import { AddImageIcon } from '@univerjs/icons'

export function ImageToolIcon() {
  return (
    <AddImageIcon
      aria-hidden="true"
      style={{ fontSize: 20, color: '#27272a' }}
    />
  )
}
```

## 設定雙色圖示的配色

雙色圖示的主色由 `color` 設定，強調色由 `extend.colorChannel1` 設定。下面的範例以深灰為主色、淺灰為強調色：

```tsx
import { PaintBucketDoubleIcon } from '@univerjs/icons'

export function FillToolIcon() {
  return (
    <PaintBucketDoubleIcon
      aria-hidden="true"
      style={{ fontSize: 20, color: '#27272a' }}
      extend={{ colorChannel1: '#d4d4d8' }}
    />
  )
}
```

多色圖示（例如品牌標誌）可能自帶固定配色，這些設定不會替換此類圖示中的全部顏色。

## 放大圖示時保持描邊寬度

圖示放大後若線條顯得過粗，可以使用 `preserveStrokeWidth`。支援該屬性的描邊會保持在 16 × 16 時的粗細，填充圖形不受影響。應用前先在預覽中切換“保持描邊”控制元件，確認效果。

```tsx
import { ShapePieIcon } from '@univerjs/icons'

export function ShapeToolIcon() {
  return (
    <ShapePieIcon
      aria-hidden="true"
      preserveStrokeWidth
      style={{ fontSize: 48 }}
    />
  )
}
```

## 為純圖示按鈕加入名稱

按鈕沒有可見文字時，在按鈕上新增 `aria-label="复制"`，並在圖示上保留 `aria-hidden="true"`，螢幕閱讀器才能讀出該操作。

如需由 AI Agent 查詢圖示並編寫整合程式碼，可連線 [MCP](/guides/icons/ai)。
