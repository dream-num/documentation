title: React への組み込み
description: React プロジェクトに Univer アイコンをインストールして使用します。

Reactインターフェイスにアイコンを追加し、周囲のコントロールに合わせてサイズと色を調整します。

## パッケージをインストールする

Reactプロジェクトにアイコンパッケージをインストールします。

```package-install
npm install @univerjs/icons
```

## ボタンにアイコンを追加する

[アイコンプレビュー](/guides/icons/all-icons)のコンポーネントを選択し、名前でインポートします。下のコピーボタンは、そのアイコンの横にあるテキストラベルを保持します。

```tsx
import { CopyIcon } from '@univerjs/icons'

export function CopyButton({ onCopy }: { onCopy: () => void }) {
  return (
    <button type="button" onClick={onCopy}>
      <CopyIcon aria-hidden="true" />
      <span>コピー</span>
    </button>
  )
}
```

コピーハンドラは`onCopy`を通過します。 アイコンは、表示されたテキストが既にアクションの名前を付けるので装飾的です。

## サイズと色を変える

アイコンは、周囲のテキストと`1em`からそのサイズから色を継承します。 アイコンの`fontSize`および`color`を設定して、どちらかの値を上書きします。

```tsx
import { AddImageIcon } from '@univerjs/icons'

export function ImageToolIcon() {
  return (
    <AddImageIcon
      aria-hidden="true"
      style={{ fontSize: 20, color: '#27272a' }}
    />
  )
}
```

## 2 色のアイコンを調整する

2色のアイコンは、`color`をメインカラーと`extend.colorChannel1`で使用しています。以下の例では、ダークグレーのアクセントをライトグレーでペアリングします。

```tsx
import { PaintBucketDoubleIcon } from '@univerjs/icons'

export function FillToolIcon() {
  return (
    <PaintBucketDoubleIcon
      aria-hidden="true"
      style={{ fontSize: 20, color: '#27272a' }}
      extend={{ colorChannel1: '#d4d4d8' }}
    />
  )
}
```

ブランドロゴを含むマルチカラーアイコンは、固定色で来るかもしれません。 これらの設定は、そのようなアイコンのすべての色を置き換えません。

## 拡大時の線幅を保つ

拡大したアイコンが重すぎる場合は、`preserveStrokeWidth`を使用してください。 16×16で持っている幅を維持するようにサポートするストロークは、埋め込まれた形状が影響を受けません。 それを適用する前に、プレビューのストローク制御で結果を確認してください。

```tsx
import { ShapePieIcon } from '@univerjs/icons'

export function ShapeToolIcon() {
  return (
    <ShapePieIcon
      aria-hidden="true"
      preserveStrokeWidth
      style={{ fontSize: 48 }}
    />
  )
}
```

## アイコンだけのボタンに名前を付ける

ボタンが目に見えるテキストがない場合、`aria-label="Copy"`をボタンに追加し、画面リーダーがアクションをアナウンスできるように、アイコンに`aria-hidden="true"`を維持します。

AIエージェントがアイコンを見つけ、統合コードを書くには、[MCPの特長](/guides/icons/ai)を接続します。
