Univer Icons MCP는 아이콘을보고 구성 요소가 어떻게 사용되는지 읽을 수있는 AI 에이전트를 가능하게합니다. 인터페이스를 설명하면 선택 또는 이미지를 삽입하는 것과 같은 인터페이스를 지원해야합니다. 에이전트는 아이콘을 선택하고 React 또는 Vue 코드를 작성합니다.

## AI Agent 연결

Model Context Protocol (MCP)은 AI Agent가 외부 도구와 통신하는 프로토콜입니다. Remote MCP를 지원하는 에이전트에서 다음 설정으로 서버를 추가하십시오.

| 설정 | 값 |
| --- | --- |
| 이름 | `univer-icons` |
| 전송 방식 | Streamable HTTP |
| 서버 URL | `https://docs.univer.ai/mcp/icons` |
| 인증 | API 키 불필요 |

저장하고 서버를 활성화합니다. 에이전트는 다음 도구를 사용할 수 있습니다:

| 도구 | 용도 |
| --- | --- |
| `search_icons` | 용도에 맞는 아이콘 후보 검색 |
| `get_icon` | imports, code 예제 및 외관 설정 읽기 |

## 필요한 아이콘 설명

프레임 워크를 상태, 아이콘을 나타내는 동작, 어떤 크기 또는 색상 요구 사항. 예를 들어:

> Univer Icons MCP를 사용해 선택한 콘텐츠를 복사하는 React 도구 모음 버튼용 단색 아이콘을 골라 주세요. 크기는 20 px로 하고 버튼의 텍스트 색상을 상속하게 하며, 버튼에 접근 가능한 이름을 지정해 주세요.

Vue 프로젝트의 경우, 요청이 될 수 있습니다.

> Univer Icons MCP를 사용해 Vue 3의 채우기 색상 버튼용 두 가지 색상 아이콘을 골라 주세요. 기본 색상은 진한 회색, 강조 색상은 연한 회색으로 지정하고 가져오기 구문과 컴포넌트 코드를 생성해 주세요.

결과를 개정하려면 변경 사항을 설명하십시오. "단색 아이콘을 사용"또는 "진동을 유지하면서 32 px로 간주합니다."

## 프로젝트에서 아이콘 사용

[아이콘 미리보기](/guides/icons/all-icons)의 반환된 구성품명을 검색하고, 그 모양, 크기 및 색상이 인터페이스를 일치한다는 것을 확인합니다. 선택한 프레임 워크에 대한 패키지를 설치하고, 버튼 이벤트를 애플리케이션 로직에 연결하십시오.

구현 단계는 프레임 워크에 따라 [React와 통합](/guides/icons/react) 또는 [Vue와 통합](/guides/icons/vue)에 있습니다.
