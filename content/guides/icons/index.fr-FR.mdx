Univer Icons fournit des icônes pour les barres d’outils, les menus et les éditeurs de documents sous React, Vue 3 et Canvas 2D.

<IconsVersion label="Version du paquet d’icônes:" />

## Choisir une intégration

Installez le paquet correspondant au mode de rendu. React et Vue partagent les mêmes noms de composants, comme `CopyIcon` et `SearchIcon`.

| Intégration | Paquet |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |
| Canvas 2D | `@univerjs/icons-svg` |

## Trouver une icône

Le [aperçu de l'icône](/guides/icons/all-icons) prend en charge la navigation par catégorie et la recherche avec un mot clé anglais tel que `copy` ou `search`. Ajustez la taille et les couleurs pour vérifier comment une icône correspond à l'interface, puis cliquez dessus pour copier son importation React .

Lorsque vous travaillez avec un agent AI, connectez-le à [MCP](/guides/icons/ai) et décrivez l'action que l'icône doit représenter. L'agent recherche les icônes correspondantes et leur utilisation React ou Vue.
