Univer Icons est une bibliothèque d’icônes pour les barres d’outils, les menus et les éditeurs de documents. Utilisez-la avec React ou Vue 3 en important les icônes dont vous avez besoin.

Version du paquet d’icônes: <IconsVersion />

## Choisir une intégration

Installez le paquet adapté à votre framework. Les deux paquets utilisent les mêmes noms de composants, comme `CopyIcon` et `SearchIcon`.

| Framework | Paquet |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |

## Trouver une icône

Ouvrez l’[aperçu des icônes](/guides/icons/all-icons) pour parcourir les catégories ou chercher un mot anglais comme `copy` ou `search`. Ajustez la taille et les couleurs, puis cliquez sur une icône pour copier son import React.

Si vous utilisez un AI Agent, connectez [service MCP](/guides/icons/ai) et décrivez l’action à représenter. L’AI Agent peut chercher des icônes et consulter leur utilisation dans React ou Vue.
