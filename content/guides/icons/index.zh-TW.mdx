Univer Icons 是一個圖示庫，適用於工具欄、選單和文件編輯介面，支援 React 和 Vue 3。介面按需匯入圖示。

<IconsVersion label="圖示套件版本：" />

## 選擇整合方式

安裝與所用框架對應的包。兩個包的元件名相同，例如 `CopyIcon` 和 `SearchIcon`。

| 框架 | 套件 |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |

## 尋找合適的圖示

在[圖示預覽](/guides/icons/all-icons)中，可以按分類瀏覽，也可以輸入 `copy`、`search` 這類英文關鍵詞查詢。調整尺寸和顏色即可檢視圖示與介面是否匹配，點選圖示即可複製 React 匯入語句。

如果使用 AI Agent，可將它連線到 [MCP](/guides/icons/ai)，並描述圖示需要表達的操作。Agent 會查詢匹配的圖示及其 React 或 Vue 用法。
