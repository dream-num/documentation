Univer Icons 是適用於工具列、選單和文件編輯介面的圖示庫。你可以在 React 或 Vue 3 專案中使用，並依需求匯入圖示。

圖示套件版本： <IconsVersion />

## 選擇整合方式

依照專案使用的框架安裝對應套件。兩個套件使用相同的元件名稱，例如 `CopyIcon` 和 `SearchIcon`。

| 框架 | 套件 |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |

## 尋找合適的圖示

開啟[圖示預覽](/guides/icons/all-icons)，依分類瀏覽，或輸入 `copy`、`search` 等英文關鍵字。調整尺寸和顏色，確認效果後點選圖示，即可複製 React 匯入語句。

如果你使用 AI Agent，可以連接 [MCP 服務](/guides/icons/ai)，描述圖示需要表達的操作。AI Agent 會尋找候選圖示，並取得 React 或 Vue 的使用方式。
