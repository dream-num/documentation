---
title: Интеграция с React
description: Установка и использование Univer Icons в проектах React.
---

Добавьте значки в интерфейс React, а затем настройте их размер и цвета, чтобы соответствовать окружающим элементам управления.

## Установите пакет

Установите пакет значков в проекте React:

```package-install
npm install @univerjs/icons
```

## Добавьте иконку на кнопку

Выберите компонент в [Превью иконки](/guides/icons/all-icons) и импортируйте его по имени. Кнопка копирования внизу держит текстовую этикетку рядом со своей иконой.

```tsx
import { CopyIcon } from '@univerjs/icons'

export function CopyButton({ onCopy }: { onCopy: () => void }) {
  return (
    <button type="button" onClick={onCopy}>
      <CopyIcon aria-hidden="true" />
      <span>Копировать</span>
    </button>
  )
}
```

Обработчик копий проходит через `onCopy`. Иконка декоративная, потому что видимый текст уже называет действие.

## Настройте размер и цвет

Иконка наследует свой цвет от окружающего текста и его размер от `1em`. Установите `fontSize` и `color` на иконке, чтобы переопределить любое значение:

```tsx
import { AddImageIcon } from '@univerjs/icons'

export function ImageToolIcon() {
  return (
    <AddImageIcon
      aria-hidden="true"
      style={{ fontSize: 20, color: '#27272a' }}
    />
  )
}
```

## Настройте двухцветную иконку

Двухцветная иконка использует `color` для своего основного цвета и `extend.colorChannel1` — для своего акцента. Пример ниже сочетает темно-серый с светло-серым акцентом:

```tsx
import { PaintBucketDoubleIcon } from '@univerjs/icons'

export function FillToolIcon() {
  return (
    <PaintBucketDoubleIcon
      aria-hidden="true"
      style={{ fontSize: 20, color: '#27272a' }}
      extend={{ colorChannel1: '#d4d4d8' }}
    />
  )
}
```

Многоцветные иконки, в том числе логотипы бренда, могут поставляться с фиксированными цветами.Эти настройки не заменяют каждый цвет в таких иконках.

## Сохраните толщину линий при увеличении

Если увеличенный значок кажется слишком тяжелым, используйте `preserveStrokeWidth`. Инсульты, которые поддерживают его, сохраняют ширину, которую они имеют при 16 × 16, и заполненные формы не затрагиваются. Проверьте результат с контролем хода в предварительном просмотре перед его применением.

```tsx
import { ShapePieIcon } from '@univerjs/icons'

export function ShapeToolIcon() {
  return (
    <ShapePieIcon
      aria-hidden="true"
      preserveStrokeWidth
      style={{ fontSize: 48 }}
    />
  )
}
```

## Назовите кнопки без текста

Когда кнопка не имеет видимого текста, добавьте `aria-label="Copy"` к кнопке и сохраните `aria-hidden="true"` на значке, чтобы читатели экрана могли объявить о действии.

Чтобы агент ИИ нашел значок и написал код интеграции, подключите [MCP](/guides/icons/ai).
