---
title: Univer Icons MCP
description: Connect your AI Agent to Univer Icons MCP to find icons and generate React or Vue code.
---

Univer Icons MCP enables an AI Agent to look up icons and read how their components are used. Describe an action the interface must support, such as copying the selection or inserting an image. The agent then selects an icon and writes the React or Vue code.

## Connect your AI agent

Model Context Protocol (MCP) is the protocol through which an AI Agent communicates with external tools. In an agent that supports remote MCP, add a server with the following settings:

| Setting | Value |
| --- | --- |
| Name | `univer-icons` |
| Transport | Streamable HTTP |
| Server URL | `https://docs.univer.ai/mcp/icons` |
| Authentication | No API key required |

Save and enable the server. The agent can then use these tools:

| Tool | Use |
| --- | --- |
| `search_icons` | Find candidate icons by purpose |
| `get_icon` | Read the imports, code examples, and appearance settings |

## Describe the icon you need

State the framework, the action the icon represents, and any size or color requirement. For example:

> Use Univer Icons MCP to choose a single-color icon for a React toolbar button that copies selected content. Make the icon 20 px, inherit the button's text color, and give the button an accessible name.

For a Vue project, the request could be:

> Use Univer Icons MCP to choose a two-color icon for a fill-color button in Vue 3. Use dark gray for the main color and light gray for the accent. Generate the import and component code.

To revise the result, describe the change: “Use a single-color icon” or “Increase it to 32 px while keeping the strokes thin.”

## Use the icon in your project

Search for the returned component name in the [icon preview](/guides/icons/all-icons), and confirm that its shape, size, and colors match the interface. Install the package for the chosen framework, then connect the button events to the application logic.

The implementation steps are in [Integrate with React](/guides/icons/react) or [Integrate with Vue](/guides/icons/vue), depending on the framework.
