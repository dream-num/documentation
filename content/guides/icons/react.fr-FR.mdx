---
title: Intégration dans React
description: Installez et utilisez Univer Icons dans vos projets React.
---

Ajoutez des icônes à une interface React, puis ajustez leur taille et leurs couleurs pour correspondre aux commandes environnantes.

## Installer le paquet

Installez le paquet d'icônes dans un projet React :

```package-install
npm install @univerjs/icons
```

## Ajouter une icône à un bouton

Sélectionnez un composant dans le [aperçu de l'icône](/guides/icons/all-icons) et importez-le par son nom. Le bouton Copie ci-dessous conserve une étiquette de texte à côté de son icône.

```tsx
import { CopyIcon } from '@univerjs/icons'

export function CopyButton({ onCopy }: { onCopy: () => void }) {
  return (
    <button type="button" onClick={onCopy}>
      <CopyIcon aria-hidden="true" />
      <span>Copier</span>
    </button>
  )
}
```

Le gestionnaire de copie est passé par `onCopy`. L'icône est décorative parce que le texte visible nomme déjà l'action.

## Régler la taille et la couleur

Une icône hérite de sa couleur à partir du texte environnant et de sa taille à partir de `1em`. Définissez `fontSize` et `color` sur l'icône pour passer outre l'une ou l'autre valeur :

```tsx
import { AddImageIcon } from '@univerjs/icons'

export function ImageToolIcon() {
  return (
    <AddImageIcon
      aria-hidden="true"
      style={{ fontSize: 20, color: '#27272a' }}
    />
  )
}
```

## Régler une icône à deux couleurs

Une icône bicolore utilise `color` pour sa couleur principale et `extend.colorChannel1`, pour son accent. L'exemple ci-dessous associe gris foncé avec un accent gris clair:

```tsx
import { PaintBucketDoubleIcon } from '@univerjs/icons'

export function FillToolIcon() {
  return (
    <PaintBucketDoubleIcon
      aria-hidden="true"
      style={{ fontSize: 20, color: '#27272a' }}
      extend={{ colorChannel1: '#d4d4d8' }}
    />
  )
}
```

Les icônes multicolores, y compris les logos de marque, peuvent être livrées avec des couleurs fixes. Ces paramètres ne remplacent pas toutes les couleurs de ces icônes.

## Conserver des traits fins à l’agrandissement

Si une icône agrandie apparaît trop lourde, utilisez `preserveStrokeWidth`. Les coups qui la supportent gardent la largeur qu'ils ont à 16 × 16, et les formes remplies ne sont pas affectées. Vérifiez le résultat avec le contrôle de course dans l'aperçu avant de l'appliquer.

```tsx
import { ShapePieIcon } from '@univerjs/icons'

export function ShapeToolIcon() {
  return (
    <ShapePieIcon
      aria-hidden="true"
      preserveStrokeWidth
      style={{ fontSize: 48 }}
    />
  )
}
```

## Nommer les boutons sans texte

Lorsqu'un bouton n'a pas de texte visible, ajoutez `aria-label="Copy"` au bouton et gardez `aria-hidden="true"` sur l'icône afin que les lecteurs d'écran puissent annoncer l'action.

Pour avoir un Agent AI trouver l'icône et écrire le code d'intégration, connectez [MCP](/guides/icons/ai).
