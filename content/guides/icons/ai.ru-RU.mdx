Univer Icons MCP позволяет AI Агенту искать значки и читать, как используются их компоненты. Опишите действие, которое должен поддерживать интерфейс, например, копирование выбора или вставка изображения. Агент затем выбирает значок и пишет код React или Vue.

## Подключение AI Agent

Model Context Protocol (MCP) — протокол, посредством которого агент ИИ взаимодействует с внешними инструментами.В агенте, поддерживающем удаленный MCP, добавьте сервер со следующими настройками:

| Настройка | Значение |
| --- | --- |
| Имя | `univer-icons` |
| Транспорт | Streamable HTTP |
| URL сервера | `https://docs.univer.ai/mcp/icons` |
| Аутентификация | API-ключ не требуется |

Сохранить и включить сервер. Агент может использовать эти инструменты:

| Инструмент | Назначение |
| --- | --- |
| `search_icons` | Поиск подходящих иконок по назначению |
| `get_icon` | Прочитайте импорт, примеры кода и настройки внешнего вида |

## Описание нужной иконки

Укажите структуру, действие, которое представляет значок, и любые требования к размеру или цвету.

> Используй Univer Icons MCP, чтобы выбрать одноцветную иконку для кнопки панели инструментов React, копирующей выделенное содержимое. Размер иконки — 20 px, цвет наследуется от текста кнопки. Задай кнопке доступное имя.

Для проекта Vue запрос может быть следующим:

> Используй Univer Icons MCP, чтобы выбрать двухцветную иконку для кнопки выбора цвета заливки в Vue 3. Основной цвет — тёмно-серый, акцентный — светло-серый. Сгенерируй импорт и код компонента.

Чтобы пересмотреть результат, опишите изменение: «Используйте одноцветную иконку» или «Увеличьте ее до 32 пикселей, сохраняя при этом тонкие штрихи».

## Использование иконки в проекте

Найдите имя возвращаемого компонента в [Превью иконки](/guides/icons/all-icons) и подтвердите, что его форма, размер и цвета соответствуют интерфейсу.Установите пакет для выбранного фреймворка, затем подключите события кнопки к логике приложения.

Шаги реализации находятся в [Интеграция с React](/guides/icons/react) или [Интеграция с Vue](/guides/icons/vue), в зависимости от фреймворка.
