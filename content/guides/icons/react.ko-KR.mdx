React 인터페이스에 아이콘을 추가하면 주변 컨트롤과 일치하는 크기와 색상을 조정할 수 있습니다.

## 아이콘 패키지 설치

React 프로젝트의 아이콘 패키지 설치:

```package-install
npm install @univerjs/icons
```

## 버튼에 아이콘 추가

[아이콘 미리보기](/guides/icons/all-icons)의 구성품을 선택하고 이름을 가져다줍니다. 아래의 복사 버튼은 아이콘 옆에 텍스트 라벨을 유지합니다.

```tsx
import { CopyIcon } from '@univerjs/icons'

export function CopyButton({ onCopy }: { onCopy: () => void }) {
  return (
    <button type="button" onClick={onCopy}>
      <CopyIcon aria-hidden="true" />
      <span>복사</span>
    </button>
  )
}
```

복사 핸들러는 `onCopy`를 통해 전달됩니다. 아이콘은 이미 행동을 명명하기 때문에 장식됩니다.

## 크기와 색상 조절

아이콘은 주변 텍스트와 `1em`의 크기에서 색상을 상속합니다. 아이콘에서 `fontSize` 및 `color`를 아이콘으로 설정하여 값을 상속시킵니다.

```tsx
import { AddImageIcon } from '@univerjs/icons'

export function ImageToolIcon() {
  return (
    <AddImageIcon
      aria-hidden="true"
      style={{ fontSize: 20, color: '#27272a' }}
    />
  )
}
```

## 두 색상 아이콘 조절

두 가지 색상 아이콘은 `color`를 주요 색상과 `extend.colorChannel1`의 악센트를 사용합니다. 아래 예는 밝은 회색 악센트로 어두운 회색 아래를 보여줍니다.

```tsx
import { PaintBucketDoubleIcon } from '@univerjs/icons'

export function FillToolIcon() {
  return (
    <PaintBucketDoubleIcon
      aria-hidden="true"
      style={{ fontSize: 20, color: '#27272a' }}
      extend={{ colorChannel1: '#d4d4d8' }}
    />
  )
}
```

브랜드 로고를 포함한 멀티 컬러 아이콘은 고정 색상으로 제공 될 수 있습니다. 이러한 설정은 이러한 아이콘의 모든 색상을 대체하지 않습니다.

## 확대할 때 선 두께 유지

확대 아이콘이 너무 무거운 것처럼 보이면 `preserveStrokeWidth`를 사용하십시오. 16 × 16에 가지고있는 폭을 유지하고 채워진 모양이 비범합니다. 미리 미리보기의 스트로크 제어로 결과를 확인하십시오.

```tsx
import { ShapePieIcon } from '@univerjs/icons'

export function ShapeToolIcon() {
  return (
    <ShapePieIcon
      aria-hidden="true"
      preserveStrokeWidth
      style={{ fontSize: 48 }}
    />
  )
}
```

## 아이콘 전용 버튼에 이름 추가

버튼이 보이지 않는 텍스트가 없다면 `aria-label="Copy"`를 버튼으로 추가하고 아이콘에 `aria-hidden="true"`을 유지하므로 화면 리더가 동작을 발표 할 수 있습니다.
