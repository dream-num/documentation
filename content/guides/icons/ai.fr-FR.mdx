L'icône Univer Icons MCP permet à un agent d'IA de rechercher des icônes et de lire comment leurs composants sont utilisés. Décrivez une action que l'interface doit prendre en charge, comme copier la sélection ou insérer une image. L'agent sélectionne ensuite une icône et écrit le code React ou Vue.

## Connecter votre AI Agent

Model Context Protocol (MCP) est le protocole par lequel un agent d'IA communique avec des outils externes. Dans un agent qui prend en charge le MCP à distance, ajoutez un serveur avec les paramètres suivants:

| Paramètre | Valeur |
| --- | --- |
| Nom | `univer-icons` |
| Transport | Streamable HTTP |
| URL du serveur | `https://docs.univer.ai/mcp/icons` |
| Authentification | Aucune clé API requise |

Enregistrer et activer le serveur. L'agent peut ensuite utiliser ces outils :

| Outil | Usage |
| --- | --- |
| `search_icons` | Rechercher des icônes candidates selon leur usage |
| `get_icon` | Lire les importations, les exemples de code et les paramètres d'apparence |

## Décrire l’icône souhaitée

Indiquez le cadre, l'action que représente l'icône et toute exigence de taille ou de couleur. Par exemple :

> Utilise Univer Icons MCP pour choisir une icône monochrome destinée à un bouton de barre d’outils React qui copie le contenu sélectionné. L’icône doit mesurer 20 px et hériter de la couleur du texte du bouton. Donne au bouton un nom accessible.

Pour un projet Vue, la demande pourrait être :

> Utilise Univer Icons MCP pour choisir une icône bicolore destinée à un bouton de couleur de remplissage dans Vue 3. Utilise du gris foncé comme couleur principale et du gris clair comme accent. Génère l’import et le code du composant.

Pour réviser le résultat, décrivez le changement : -Utilisez une icône monocolore ou -Augmentez-le à 32 px tout en gardant les traits minces.

## Utiliser l’icône dans votre projet

Rechercher le nom du composant retourné dans le [aperçu de l'icône](/guides/icons/all-icons), et confirmer que sa forme, sa taille et ses couleurs correspondent à l'interface. Installez le paquet pour le cadre choisi, puis connectez les événements bouton à la logique d'application.

Les étapes d'implémentation sont en [Intégrer avec React](/guides/icons/react) ou [Intégrer avec Vue](/guides/icons/vue), selon le cadre.
