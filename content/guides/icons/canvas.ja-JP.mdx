---
title: Canvas にアイコンを描画する
---

`@univerjs/icons-svg` 1.48.0 以降の `drawCanvasIcon` を使うと、Canvas 2D コンテキストに組み込みアイコンを同期的に描画できます。

```package-install
npm install @univerjs/icons-svg
```

## フィルターアイコンを描画する

ページに canvas 要素を追加し、要素の作成後に次のコードを実行します。

```html
<canvas id="toolbar-icons" width="48" height="24"></canvas>
```

```ts
import { drawCanvasIcon } from '@univerjs/icons-svg'

const canvas = document.querySelector<HTMLCanvasElement>('#toolbar-icons')
const ctx = canvas?.getContext('2d')

if (ctx) {
  drawCanvasIcon(ctx, 'filter-applied-icon', 4, 4, 16, '#2563eb')
}
```

最初の 2 つの数値は描画領域の左上の座標、3 つ目は正方形の一辺の長さです。いずれもキャンバスの座標系で指定します。アイコンは縦横比を保ったまま中央に配置されます。

## アイコン名と色を選ぶ

エクスポートされている `CanvasIconName` 型で、対応する名前を補完できます。名前には `filter-applied-icon` のように `.svg` を除いたファイル名を使います。カタログ内の SVG の一部が Canvas に対応しています。

最後の引数を省略すると SVG の元の色が使われます。色を 1 つ指定すると主色とアクセント色の両方が変わります。特定の色だけを変えるには、元の SVG の色をキーにしたマップを渡します。次の例では星の半分を金色にします。

```ts
if (ctx) {
  drawCanvasIcon(ctx, 'star-incomplete-double-icon', 28, 4, 16, { black: '#d97706' })
}
```

## Univer のシーン内にアイコンを描画する

`@univerjs/engine-render` は `CanvasIconShape` をエクスポートします。これは Canvas アイコンをシーンの図形として描画します。コンストラクターは `(key, icon, props)` です。`key` は図形を識別し、`icon` は `CanvasIconName`、`props` は `IShapeProps` です。`scene.addObject(shape)` で図形をシーンに追加します。

```ts
import { CanvasIconShape, IRenderManagerService } from '@univerjs/engine-render'

// アイコンを配置するユニット。
const unitId = 'your-unit-id'
const render = univer.__getInjector().get(IRenderManagerService).getRenderUnitById(unitId)

if (render) {
  const shape = new CanvasIconShape('filter-icon', 'filter-applied-icon', {
    left: 24,
    top: 16,
    width: 16,
    height: 16,
    fill: '#2563eb',
  })

  render.scene.addObject(shape)
}
```

図形は `Math.min(width, height)` をアイコンのボックスとして使用し、残りのスペースでアイコンを中央に配置します。正方形でない図形では、長い方の軸に余白が残ります。
