---
title: Integración en Vue
description: Instala y usa Univer Icons en tu proyecto de Vue 3.
---

Añadir iconos a una interfaz Vue 3, luego ajustar su tamaño y colores para que coincida con los controles circundantes.

## Instala el paquete

Instalar el paquete de iconos en un proyecto Vue 3:

```package-install
npm install @univerjs/icons-vue
```

## Añade un icono a un botón

Seleccione un componente en el [icono vista previa](/guides/icons/all-icons) e importe por nombre. El botón de copia a continuación mantiene una etiqueta de texto junto a su icono.

```vue
<script setup lang="ts">
import { CopyIcon } from '@univerjs/icons-vue'

const emit = defineEmits<{ copy: [] }>()
</script>

<template>
  <button type="button" @click="emit('copy')">
    <CopyIcon aria-hidden="true" />
    <span>Copiar</span>
  </button>
</template>
```

Gestiona el evento `copy` en el componente padre. El icono es decorativo porque el texto ya describe la acción.

## Ajusta el tamaño y el color

Un icono hereda su color del texto circundante y su tamaño de `1em`. Set `fontSize` y `color` en el icono para anular cualquier valor:

```vue
<script setup lang="ts">
import { AddImageIcon } from '@univerjs/icons-vue'
</script>

<template>
  <AddImageIcon
    aria-hidden="true"
    :style="{ fontSize: '20px', color: '#27272a' }"
  />
</template>
```

## Ajusta un icono de dos colores

Un icono de dos colores utiliza `color` por su color principal y `extend.colorChannel1` para su acento. El ejemplo a continuación pares gris oscuro con un acento gris claro:

```vue
<script setup lang="ts">
import { PaintBucketDoubleIcon } from '@univerjs/icons-vue'
</script>

<template>
  <PaintBucketDoubleIcon
    aria-hidden="true"
    :style="{ fontSize: '20px', color: '#27272a' }"
    :extend="{ colorChannel1: '#d4d4d8' }"
  />
</template>
```

Los iconos multicolor, incluyendo logotipos de marca, pueden venir con colores fijos. Estas configuraciones no reemplazan cada color en tales iconos.

## Mantén el grosor al ampliar

Si un icono agrandado aparece demasiado pesado, use `preserveStrokeWidth`. Los golpes que lo soportan mantienen el ancho que tienen al 16 × 16, y las formas llenas no son afectados. Compruebe el resultado con el control de trazo en la vista previa antes de aplicarlo.

```vue
<script setup lang="ts">
import { ShapePieIcon } from '@univerjs/icons-vue'
</script>

<template>
  <ShapePieIcon
    aria-hidden="true"
    preserve-stroke-width
    style="font-size: 48px"
  />
</template>
```

## Pon nombre a los botones sin texto

Cuando un botón no tiene texto visible, agregue `aria-label="Copy"` al botón y mantenga `aria-hidden="true"` en el icono para que los lectores de pantalla puedan anunciar la acción.

Para tener un agente de inteligencia artificial encontrar el icono y escribir el código de integración, conecte [MCP](/guides/icons/ai).
