---
title: Draw icons on Canvas
---

Use `drawCanvasIcon` from `@univerjs/icons-svg` 1.48.0 or later to draw a built-in icon synchronously on a Canvas 2D context.

```package-install
npm install @univerjs/icons-svg
```

## Draw a filter icon

Add a canvas to the page and run the following code after the element exists.

```html
<canvas id="toolbar-icons" width="48" height="24"></canvas>
```

```ts
import { drawCanvasIcon } from '@univerjs/icons-svg'

const canvas = document.querySelector<HTMLCanvasElement>('#toolbar-icons')
const ctx = canvas?.getContext('2d')

if (ctx) {
  drawCanvasIcon(ctx, 'filter-applied-icon', 4, 4, 16, '#2563eb')
}
```

The first two numbers are the top-left coordinates of the drawing box. The third is its side length in canvas units. The icon is centered in the box and keeps its aspect ratio.

## Choose a name and colors

TypeScript suggests supported names through the exported `CanvasIconName` type. Use the SVG filename without `.svg`, such as `filter-applied-icon`. Only a subset of the SVG catalog supports Canvas.

Omit the last argument to preserve the SVG colors. A single color tints the main and accent paths. To change just one color, pass a map keyed by the original SVG colors. This example changes the filled half of the star to gold.

```ts
if (ctx) {
  drawCanvasIcon(ctx, 'star-incomplete-double-icon', 28, 4, 16, { black: '#d97706' })
}
```
