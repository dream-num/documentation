Библиотека Univer Icons содержит иконки для панелей инструментов, меню и редакторов документов. Используйте её в React или Vue 3 и импортируйте нужные иконки по отдельности.

Версия пакета иконок: <IconsVersion />

## Выберите способ интеграции

Установите пакет для своего фреймворка. Оба пакета используют одинаковые имена компонентов, например `CopyIcon` и `SearchIcon`.

| Фреймворк | Пакет |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |

## Найдите иконку

Откройте [предпросмотр иконок](/guides/icons/all-icons), выберите категорию или введите английское слово, например `copy` или `search`. Настройте размер и цвета, затем нажмите на иконку, чтобы скопировать импорт для React.

Если вы пишете код с AI Agent, подключите [MCP-сервер](/guides/icons/ai) и опишите нужное действие. AI Agent найдёт подходящие иконки и примеры для React или Vue.
