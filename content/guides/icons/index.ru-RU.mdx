Univer Icons - это библиотека значков для интерфейсов панели инструментов, меню и редактирования документов. Он поддерживает React и Vue 3, а интерфейс импортирует нужные ему значки.

<IconsVersion label="Версия пакета иконок:" />

## Выберите способ интеграции

Установите пакет, который соответствует вашему фреймворку. Оба пакета имеют одинаковые имена компонентов, такие как `CopyIcon` и `SearchIcon`.

| Фреймворк | Пакет |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |

## Найдите иконку

[Превью иконки](/guides/icons/all-icons) поддерживает просмотр по категориям и поиск по английскому ключевому слову, такому как `copy` или `search`. Настройте размер и цвета, чтобы проверить, как иконка соответствует интерфейсу, а затем нажмите на нее, чтобы скопировать ее импорт React .

При работе с AI Agent подключите его к [MCP](/guides/icons/ai) и опишите действие, которое должен представлять значок. Агент просматривает соответствующие значки и их использование React или Vue.
