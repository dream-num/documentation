Univer Icons MCP 讓 AI Agent 可以查詢圖示，並瞭解圖示元件的用法。你只需描述介面需要完成的操作，例如複製選中內容或插入圖片，Agent 便會選擇合適的圖示，並生成 React 或 Vue 程式碼。

## 連接 AI Agent

MCP（Model Context Protocol）是 AI Agent 與外部工具通訊的協議。在支援遠端 MCP 的 Agent 中新增一個服務，並填寫以下設定：

| 設定 | 值 |
| --- | --- |
| 名稱 | `univer-icons` |
| 傳輸方式 | Streamable HTTP |
| 伺服器 URL | `https://docs.univer.ai/mcp/icons` |
| 驗證 | 不需要 API 金鑰 |

儲存並啟用該服務後，Agent 即可使用以下工具：

| 工具 | 用途 |
| --- | --- |
| `search_icons` | 依用途尋找候選圖示 |
| `get_icon` | 檢視圖示的匯入方式、程式碼範例和外觀設定 |

## 描述所需圖示

說明所用的框架、圖示對應的動作，以及尺寸或顏色要求。例如：

> 使用 Univer Icons MCP，為 React 工具列中複製選取內容的按鈕選擇單色圖示。圖示大小為 20 px，繼承按鈕文字顏色，並為按鈕提供無障礙名稱。

如果使用 Vue，也可以按以下方式描述：

> 使用 Univer Icons MCP，為 Vue 3 的填滿顏色按鈕選擇雙色圖示。主色使用深灰色，強調色使用淺灰色。產生匯入與元件程式碼。

如需調整結果，直接描述需要修改的內容，例如“換成單色圖示”或“放大到 32 px，並保持線條粗細”。

## 在專案中使用圖示

取得程式碼後，在[圖示預覽](/guides/icons/all-icons)中搜尋返回的元件名，確認其圖形、尺寸和配色是否符合介面要求。然後安裝對應框架的圖示包，並把按鈕事件連線到業務邏輯。

具體步驟見[在 React 中整合](/guides/icons/react)或[在 Vue 中整合](/guides/icons/vue)，取決於所用的框架。
