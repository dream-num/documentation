Univer Icons MCP permite a un agente de inteligencia artificial buscar iconos y leer cómo se utilizan sus componentes. Describir una acción que la interfaz debe soportar, como copiar la selección o insertar una imagen. El agente luego selecciona un icono y escribe el código React o Vue.

## Conectar tu AI Agent

Modelo Protocolo de Contexto (MCP) es el protocolo a través del cual un Agente AI se comunica con herramientas externas. En un agente que soporta el PCM remoto, agregue un servidor con los siguientes ajustes:

| Ajuste | Valor |
| --- | --- |
| Nombre | `univer-icons` |
| Transporte | Streamable HTTP |
| URL del servidor | `https://docs.univer.ai/mcp/icons` |
| Autenticación | No requiere clave API |

Guardar y habilitar el servidor. El agente puede utilizar estas herramientas:

| Herramienta | Uso |
| --- | --- |
| `search_icons` | Buscar iconos candidatos según su finalidad |
| `get_icon` | Lea las importaciones, ejemplos de código y ajustes de apariencia |

## Describir el icono que necesitas

Establece el marco, la acción que representa el icono y cualquier requisito de tamaño o color. Por ejemplo:

> Usa Univer Icons MCP para elegir un icono de un solo color para un botón de una barra de herramientas React que copie el contenido seleccionado. El icono debe medir 20 px, heredar el color del texto del botón y el botón debe tener un nombre accesible.

Para un proyecto Vue, la solicitud podría ser:

> Usa Univer Icons MCP para elegir un icono de dos colores para un botón de color de relleno en Vue 3. Usa gris oscuro como color principal y gris claro como acento. Genera la importación y el código del componente.

Para revisar el resultado, describa el cambio: “Utilice un icono de un solo color” o “Ingréguelo a 32 px mientras mantenga los trazos delgados”.

## Usar el icono en tu proyecto

Busque el nombre de componente devuelto en el [icono vista previa](/guides/icons/all-icons) y confirme que su forma, tamaño y colores coinciden con la interfaz. Instale el paquete para el marco elegido, luego conecte los eventos de botón a la lógica de aplicación.

Los pasos de implementación están en [Integrar con React](/guides/icons/react) o [Integrar con Vue](/guides/icons/vue), dependiendo del marco.
