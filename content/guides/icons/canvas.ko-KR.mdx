---
title: Canvas에 아이콘 그리기
---

`@univerjs/icons-svg` 1.48.0 이상에서 제공하는 `drawCanvasIcon`으로 Canvas 2D 컨텍스트에 기본 아이콘을 동기적으로 그릴 수 있습니다.

```package-install
npm install @univerjs/icons-svg
```

## 필터 아이콘 그리기

페이지에 캔버스 요소를 추가하고 요소가 생성된 후 다음 코드를 실행합니다.

```html
<canvas id="toolbar-icons" width="48" height="24"></canvas>
```

```ts
import { drawCanvasIcon } from '@univerjs/icons-svg'

const canvas = document.querySelector<HTMLCanvasElement>('#toolbar-icons')
const ctx = canvas?.getContext('2d')

if (ctx) {
  drawCanvasIcon(ctx, 'filter-applied-icon', 4, 4, 16, '#2563eb')
}
```

처음 두 숫자는 그리기 영역 왼쪽 위의 좌표이고, 세 번째는 정사각형 영역의 한 변 길이입니다. 모두 캔버스 좌표 단위를 사용합니다. 아이콘은 가로세로 비율을 유지하면서 영역 중앙에 배치됩니다.

## 아이콘 이름과 색상 선택

패키지가 내보내는 `CanvasIconName` 타입으로 지원하는 이름을 자동 완성할 수 있습니다. `filter-applied-icon`처럼 파일명에서 `.svg`를 뺀 이름을 사용합니다. 카탈로그의 SVG 중 일부가 Canvas를 지원합니다.

마지막 인수를 생략하면 SVG의 원래 색상이 유지됩니다. 색상 하나를 전달하면 기본색과 강조색이 함께 바뀝니다. 특정 색상만 바꾸려면 원래 SVG 색상을 키로 하는 객체를 전달합니다. 다음 예시는 별의 채워진 절반을 금색으로 바꿉니다.

```ts
if (ctx) {
  drawCanvasIcon(ctx, 'star-incomplete-double-icon', 28, 4, 16, { black: '#d97706' })
}
```
