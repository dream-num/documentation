Univer Icons は、ツールバー、メニュー、文書編集画面で使えるアイコンライブラリです。React と Vue 3 に対応し、必要なアイコンを個別にインポートできます。

アイコンパッケージのバージョン: <IconsVersion />

## フレームワークを選ぶ

使用するフレームワークに合わせてパッケージを選びます。どちらも `CopyIcon` や `SearchIcon` など、同じコンポーネント名を使います。

| フレームワーク | パッケージ |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |

## アイコンを探す

[アイコンプレビュー](/guides/icons/all-icons)で分類から探すか、`copy` や `search` などの英語キーワードで検索します。サイズと色を調整して確認し、アイコンをクリックすると React のインポート文をコピーできます。

AI Agentを使う場合は、[MCP サービス](/guides/icons/ai)に接続して表現したい操作を伝えます。AI Agentが候補と React または Vue での使い方を調べます。
