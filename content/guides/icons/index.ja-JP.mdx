Univer Iconsは、ツールバー、メニュー、ドキュメント編集インターフェイスのアイコンライブラリです。ReactとVue 3をサポートしており、インターフェイスは必要なアイコンをインポートします。

<IconsVersion label="アイコンパッケージのバージョン:" />

## フレームワークを選ぶ

フレームワークにマッチするパッケージをインストールします。`CopyIcon`や`SearchIcon`などの同じコンポーネント名をパッケージに共有します。

| フレームワーク | パッケージ |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |

## アイコンを探す

[アイコンプレビュー](/guides/icons/all-icons)は、`copy`や`search`などの英語のキーワードで検索し、カテゴリでブラウジングをサポートしています。 アイコンがインターフェイスに合っているかを確認するためにサイズと色を調整し、それをクリックしてReactのインポートをコピーします。

AIエージェントと連携すると、[MCPの特長](/guides/icons/ai)に接続して、アイコンが表現するアクションを記述します。エージェントは、マッチングアイコンとReactまたはVueの使用状況を調べます。
