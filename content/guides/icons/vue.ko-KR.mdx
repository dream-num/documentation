Vue 3 인터페이스에 아이콘을 추가하면 주변 컨트롤과 일치하는 크기와 색상을 조정할 수 있습니다.

## 아이콘 패키지 설치

Vue 3 프로젝트의 아이콘 패키지 설치:

```package-install
npm install @univerjs/icons-vue
```

## 버튼에 아이콘 추가

[아이콘 미리보기](/guides/icons/all-icons)의 구성품을 선택하고 이름을 가져다줍니다. 아래의 복사 버튼은 아이콘 옆에 텍스트 라벨을 유지합니다.

```vue
<script setup lang="ts">
import { CopyIcon } from '@univerjs/icons-vue'

const emit = defineEmits<{ copy: [] }>()
</script>

<template>
  <button type="button" @click="emit('copy')">
    <CopyIcon aria-hidden="true" />
    <span>복사</span>
  </button>
</template>
```

부모 컴포넌트에서 `copy` 이벤트를 처리하세요. 버튼 텍스트가 동작을 설명하므로 아이콘은 장식으로 표시합니다.

## 크기와 색상 조절

아이콘은 주변 텍스트와 `1em`의 크기에서 색상을 상속합니다. 아이콘에서 `fontSize` 및 `color`를 아이콘으로 설정하여 값을 상속시킵니다.

```vue
<script setup lang="ts">
import { AddImageIcon } from '@univerjs/icons-vue'
</script>

<template>
  <AddImageIcon
    aria-hidden="true"
    :style="{ fontSize: '20px', color: '#27272a' }"
  />
</template>
```

## 두 색상 아이콘 조절

두 가지 색상 아이콘은 `color`를 주요 색상과 `extend.colorChannel1`의 악센트를 사용합니다. 아래 예는 밝은 회색 악센트로 어두운 회색 아래를 보여줍니다.

```vue
<script setup lang="ts">
import { PaintBucketDoubleIcon } from '@univerjs/icons-vue'
</script>

<template>
  <PaintBucketDoubleIcon
    aria-hidden="true"
    :style="{ fontSize: '20px', color: '#27272a' }"
    :extend="{ colorChannel1: '#d4d4d8' }"
  />
</template>
```

브랜드 로고를 포함한 멀티 컬러 아이콘은 고정 색상으로 제공 될 수 있습니다. 이러한 설정은 이러한 아이콘의 모든 색상을 대체하지 않습니다.

## 확대할 때 선 두께 유지

확대 아이콘이 너무 무거운 것처럼 보이면 `preserveStrokeWidth`를 사용하십시오. 16 × 16에 가지고있는 폭을 유지하고 채워진 모양이 비범합니다. 미리 미리보기의 스트로크 제어로 결과를 확인하십시오.

```vue
<script setup lang="ts">
import { ShapePieIcon } from '@univerjs/icons-vue'
</script>

<template>
  <ShapePieIcon
    aria-hidden="true"
    preserve-stroke-width
    style="font-size: 48px"
  />
</template>
```

## 아이콘 전용 버튼에 이름 추가

버튼이 보이지 않는 텍스트가 없다면 `aria-label="Copy"`를 버튼으로 추가하고 아이콘에 `aria-hidden="true"`을 유지하므로 화면 리더가 동작을 발표 할 수 있습니다.

AI Agent가 아이콘을 찾아 통합 코드를 작성하려면 [MCP 소개](/guides/icons/ai)를 연결하십시오.
