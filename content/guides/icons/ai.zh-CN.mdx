Univer Icons MCP 让 AI Agent 可以查找图标，并了解图标组件的用法。你只需描述界面需要完成的操作，例如复制选中内容或插入图片，Agent 便会选择合适的图标，并生成 React 或 Vue 代码。

## 连接 AI Agent

MCP（Model Context Protocol）是 AI Agent 与外部工具通信的协议。在支持远程 MCP 的 Agent 中添加一个服务，并填写以下设置：

| 设置 | 值 |
| --- | --- |
| 名称 | `univer-icons` |
| 传输方式 | Streamable HTTP |
| 服务地址 | `https://docs.univer.ai/mcp/icons` |
| 认证 | 无需 API Key |

保存并启用该服务后，Agent 即可使用以下工具：

| 工具 | 用途 |
| --- | --- |
| `search_icons` | 根据用途查找候选图标 |
| `get_icon` | 查看图标的导入方式、代码示例和外观设置 |

## 描述你需要的图标

说明所用的框架、图标对应的动作，以及尺寸或颜色要求。例如：

> 使用 Univer Icons MCP，为 React 工具栏的“复制选中内容”按钮选择一个单色图标。图标大小为 20 px，颜色跟随按钮文字，并为按钮添加可访问名称。

如果使用 Vue，也可以按以下方式描述：

> 使用 Univer Icons MCP，为 Vue 3 的填充颜色按钮选择一个双色图标。主色使用深灰，强调色使用浅灰，生成组件的导入和使用代码。

如需调整结果，直接描述需要修改的内容，例如“换成单色图标”或“放大到 32 px，并保持线条粗细”。

## 将图标用到项目中

获取代码后，在[图标预览](/guides/icons/all-icons)中搜索返回的组件名，确认其图形、尺寸和配色是否符合界面要求。然后安装对应框架的图标包，并把按钮事件连接到业务逻辑。

具体步骤见[在 React 中集成](/guides/icons/react)或[在 Vue 中集成](/guides/icons/vue)，取决于所用的框架。
