title: Univer Icons MCP
description: AI Agent を Univer Icons MCP に接続し、アイコンの検索と React・Vue コードの生成を行います。
---

Univer Icons MCP は、AI エージェントがアイコンを探し、そのコンポーネントがどのように使用されるかを読み取ります。 インターフェイスは、選択をコピーしたり、画像をインサートしたりするなどのサポートが必要です。 エージェントは、アイコンを選択し、React または Vue コードを記述します。

## AI Agent を接続する

モデルコンテキストプロトコル(MCP)は、AIエージェントが外部ツールと通信するプロトコルです。リモートMCPをサポートするエージェントでは、次の設定でサーバーを追加します。

| 設定 | 値 |
| --- | --- |
| 名前 | `univer-icons` |
| トランスポート | Streamable HTTP |
| サーバー URL | `https://docs.univer.ai/mcp/icons` |
| 認証 | API キー不要 |

サーバーを保存して有効にします。エージェントはこれらのツールを使用できます。

| ツール | 用途 |
| --- | --- |
| `search_icons` | 用途に応じてアイコンの候補を検索 |
| `get_icon` | インポート、コード例、外観設定をお読みください。 |

## 必要なアイコンを説明する

フレームワークを状態にし、アクションはアイコンが表し、任意のサイズや色要件を表現します。例えば:

> Univer Icons MCP を使い、選択した内容をコピーする React ツールバーボタン用の単色アイコンを選んでください。サイズは 20 px、色はボタンの文字色を継承し、ボタンにアクセシブルな名前を付けてください。

Vueプロジェクトの場合、リクエストは以下になります。

> Univer Icons MCP を使い、Vue 3 の塗りつぶし色ボタン用の 2 色アイコンを選んでください。主色を濃いグレー、アクセントを薄いグレーにして、インポートとコンポーネントのコードを生成してください。

結果を復活させるには、「単色アイコンを使う」または「ストロークを薄く保ちながら32pxに増やす」という変更を記述します。

## プロジェクトでアイコンを使う

[アイコンプレビュー](/guides/icons/all-icons) で返されたコンポーネント名を検索し、その形状、サイズ、色がインターフェイスに一致することを確認します。選択したフレームワークのパッケージをインストールし、ボタンイベントをアプリケーションロジックに接続します。

実装手順は、フレームワークに応じて、[Reactと統合](/guides/icons/react) または [Vueと統合](/guides/icons/vue)、です。
