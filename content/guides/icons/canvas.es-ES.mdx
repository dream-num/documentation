---
title: Dibujar iconos en Canvas
---

A partir de la versión 1.48.0 de `@univerjs/icons-svg`, `drawCanvasIcon` dibuja iconos de forma síncrona en un contexto 2D de Canvas.

```package-install
npm install @univerjs/icons-svg
```

## Dibujar un icono de filtro

Añade un lienzo a la página y ejecuta el código una vez creado el elemento.

```html
<canvas id="toolbar-icons" width="48" height="24"></canvas>
```

```ts
import { drawCanvasIcon } from '@univerjs/icons-svg'

const canvas = document.querySelector<HTMLCanvasElement>('#toolbar-icons')
const ctx = canvas?.getContext('2d')

if (ctx) {
  drawCanvasIcon(ctx, 'filter-applied-icon', 4, 4, 16, '#2563eb')
}
```

Los dos primeros números indican las coordenadas de la esquina superior izquierda del área de dibujo. El tercero indica la longitud del lado del cuadrado en unidades del lienzo. El icono se centra y conserva sus proporciones.

## Elegir el nombre y los colores

El tipo exportado `CanvasIconName` ofrece autocompletado para los nombres admitidos. Usa el nombre del archivo sin `.svg`, como `filter-applied-icon`. Solo una parte del catálogo SVG está disponible para Canvas.

Omite el último argumento para conservar los colores del SVG. Un solo color sustituye tanto el principal como el de acento. Para cambiar un color concreto, pasa un objeto cuyas claves sean los colores originales del SVG. Este ejemplo aplica un tono dorado a la mitad rellena de la estrella.

```ts
if (ctx) {
  drawCanvasIcon(ctx, 'star-incomplete-double-icon', 28, 4, 16, { black: '#d97706' })
}
```

## Dibujar un icono dentro de una escena de Univer

`@univerjs/engine-render` exporta `CanvasIconShape`, que dibuja un icono de Canvas como una forma de escena. Su constructor es `(key, icon, props)`: `key` identifica la forma, `icon` es un `CanvasIconName`, y `props` es `IShapeProps`. Añade la forma a la escena con `scene.addObject(shape)`.

```ts
import { CanvasIconShape, IRenderManagerService } from '@univerjs/engine-render'

// The unit whose scene should contain the icon.
const unitId = 'your-unit-id'
const render = univer.__getInjector().get(IRenderManagerService).getRenderUnitById(unitId)

if (render) {
  const shape = new CanvasIconShape('filter-icon', 'filter-applied-icon', {
    left: 24,
    top: 16,
    width: 16,
    height: 16,
    fill: '#2563eb',
  })

  render.scene.addObject(shape)
}
```

La forma usa `Math.min(width, height)` como caja del icono y centra el icono en el espacio restante. Una forma no cuadrada deja relleno en el eje más largo.
