Univer Icons es una biblioteca de iconos para barras de herramientas, menús y editores de documentos. Úsala en React o Vue 3 e importa los iconos que necesites.

Versión del paquete de iconos: <IconsVersion />

## Elige tu integración

Instala el paquete de tu framework. Ambos usan los mismos nombres de componentes, como `CopyIcon` y `SearchIcon`.

| Framework | Paquete |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |

## Encuentra un icono

Abre la [vista previa de iconos](/guides/icons/all-icons) para explorar categorías o buscar con palabras en inglés como `copy` o `search`. Ajusta el tamaño y los colores. Haz clic en un icono para copiar su importación de React.

Si usas un AI Agent, conecta [servicio MCP](/guides/icons/ai) y describe la acción que quieres representar. El AI Agent puede buscar candidatos y consultar su uso en React o Vue.
