Univer Icons ofrece iconos para barras de herramientas, menús y editores de documentos en React, Vue 3 y Canvas 2D.

<IconsVersion label="Versión del paquete de iconos:" />

## Elige tu integración

Instala el paquete correspondiente al modo de renderizado. React y Vue comparten nombres de componentes como `CopyIcon` y `SearchIcon`.

| Integración | Paquete |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |
| Canvas 2D | `@univerjs/icons-svg` |

## Encuentra un icono

El [icono vista previa](/guides/icons/all-icons) admite la navegación por categoría y la búsqueda con una palabra clave en inglés como `copy` o `search`. Ajusta el tamaño y los colores para comprobar cómo un icono encaja en la interfaz, y luego haz clic en él para copiar su importación React .

Al trabajar con un agente de inteligencia artificial, conéctelo a [MCP](/guides/icons/ai) y describir la acción que el icono debe representar. El agente busca los iconos que coinciden y su uso de React o Vue.
