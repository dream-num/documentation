Univer Icons 是一个图标库，适用于工具栏、菜单和文档编辑界面，支持 React 和 Vue 3。界面按需导入图标。

<IconsVersion label="图标包版本：" />

## 选择集成方式

安装与所用框架对应的包。两个包的组件名相同，例如 `CopyIcon` 和 `SearchIcon`。

| 框架 | 安装包 |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |

## 找到合适的图标

在[图标预览](/guides/icons/all-icons)中，可以按分类浏览，也可以输入 `copy`、`search` 这类英文关键词查找。调整尺寸和颜色即可查看图标与界面是否匹配，点击图标即可复制 React 导入语句。

如果使用 AI Agent，可将它连接到 [MCP](/guides/icons/ai)，并描述图标需要表达的操作。Agent 会查找匹配的图标及其 React 或 Vue 用法。
