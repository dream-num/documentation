Univer Icons는 도구 모음, 메뉴, 문서 편집 화면에 사용할 수 있는 아이콘 라이브러리입니다. React와 Vue 3를 지원하며 필요한 아이콘만 가져올 수 있습니다.

아이콘 패키지 버전: <IconsVersion />

## 프레임워크에 맞는 패키지 선택

프로젝트의 프레임워크에 맞는 패키지를 설치하세요. 두 패키지는 `CopyIcon`, `SearchIcon`처럼 같은 컴포넌트 이름을 사용합니다.

| 프레임워크 | 패키지 |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |

## 아이콘 찾기

[아이콘 미리 보기](/guides/icons/all-icons)에서 분류별로 살펴보거나 `copy`, `search` 같은 영어 키워드로 검색하세요. 크기와 색상을 조절한 뒤 아이콘을 클릭하면 React import 문을 복사할 수 있습니다.

AI Agent를 사용한다면 [MCP 서비스](/guides/icons/ai)에 연결하고 표현하려는 동작을 설명하세요. AI Agent가 후보 아이콘과 React 또는 Vue 사용법을 찾아줍니다.
