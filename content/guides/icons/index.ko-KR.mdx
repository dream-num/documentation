Univer Icons는 React, Vue 3 및 Canvas 2D에서 도구 모음, 메뉴, 문서 편집기에 사용할 아이콘을 제공합니다.

<IconsVersion label="아이콘 패키지 버전:" />

## 렌더링 방식 선택

렌더링 방식에 맞는 패키지를 설치하세요. React와 Vue는 `CopyIcon`, `SearchIcon` 같은 컴포넌트 이름을 공유합니다.

| 렌더링 방식 | 패키지 |
| --- | --- |
| React | `@univerjs/icons` |
| Vue 3 | `@univerjs/icons-vue` |
| Canvas 2D | `@univerjs/icons-svg` |

## 아이콘 찾기

[아이콘 미리보기](/guides/icons/all-icons)는 카테고리별로 검색을 지원하고 `copy` 또는 `search`와 같은 영어 키워드로 검색 할 수 있습니다. 크기와 색상을 조정하여 아이콘이 인터페이스에 맞는지 확인한 다음 React 가져 오기를 복사하려면 클릭하십시오.

AI 에이전트와 함께 작동 할 때 [MCP 소개](/guides/icons/ai)에 연결하고 아이콘을 나타내는 작업을 설명합니다. 에이전트는 일치 아이콘과 React 또는 Vue 사용을 찾습니다.
