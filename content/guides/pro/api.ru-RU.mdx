На этой странице перечислены основные API Univer Server. Базовый URL по умолчанию — `http://localhost:8000`.

> Примечание. Значения параметра `type`: `1` — Docs, `2` — Sheets.

## Управление документами

### Создание документа

<APITable
  request={{
    method: 'POST',
    url: '/universer-api/snapshot/{type}/unit/-/create',
    headers: <code>content-type: application/json</code>,
    parametersType: 'Body',
    parameters: [{
      name: 'type',
      type: 'enum(int)',
      required: true,
      description: '1 (docs), 2 (sheets) — для пути и тела запроса',
    }, {
      name: 'name',
      type: 'string',
      required: true,
      description: 'Название документа',
    }, {
      name: 'creator',
      type: 'string',
      required: true,
      description: 'Идентификатор создателя',
    }, {
      name: 'idempotencyKey',
      type: 'string',
      required: false,
      description: 'Добавлено в версии v0.20.0. Необязательный ключ идемпотентности; общий размер не должен превышать 64 байта.',
    }, {
      name: 'metaData',
      type: 'string',
      required: false,
      description: 'Добавлено в версии v0.20.0. Пользовательские данные привязываются к созданному юниту и без изменений передаются в последующих событиях синхронизации и вызовах USIP. Общий размер не должен превышать 1024 байта.',
    }],
    example: `curl http://localhost:8000/universer-api/snapshot/{type}/unit/-/create \\
    -X POST \\
    -H 'Content-Type: application/json' \\
    --data-raw '{"type":2,"name":"New Sheet By Univer","creator":"userID","idempotencyKey":"a-idgenerator-unique-id","metaData":"tenant12345"}'`,
  }}
  response={{
    type: 'application/json',
    parameters: [{
      name: 'error',
      type: 'object',
      properties: [{
        name: 'code',
        type: 'enum(int)',
        description: '1 (успешно)',
      }, {
        name: 'message',
        type: 'string',
        description: 'Сообщение об ошибке',
      }],
    }, {
      name: 'unitID',
      type: 'string',
      description: 'Идентификатор документа',
    }],
    example: JSON.stringify({
      error: {
        code: 1,
        message: 'success',
      },
      unitID: 'ETVf-B4lQqOSE_p09mcp9Q',

  }}

## Файлы, импорт и экспорт

### Загрузка файла [#upload-file]

<APITable
  request={{
    method: 'POST',
    url: '/universer-api/stream/file/upload',
    headers: <code>content-type: multipart/form-data</code>,
    parametersType: 'Body',
    parameters: [{
      name: 'size',
      type: 'int',
      required: true,
      description: 'Размер файла в байтах (параметр запроса). Должен совпадать с фактическим размером.',
    }, {
      name: 'file',
      type: 'Form.file',
      required: true,
      description: 'Файл в HTML-форме',
    }],
    example: `curl 'http://localhost:8000/universer-api/stream/file/upload?size=125466' \\
    --header 'cookie: _univer=XXXXXX' \\
    --form 'file=@"demo.xlsx"'`,
  }}
  response={{
    type: 'application/json',
    parameters: [{
      name: 'FileId',
      type: 'string',
      description: 'Идентификатор файла для импорта и экспорта',
    }],
    example: JSON.stringify({
      FileId: 'xxxx',
    }, null, 2),
  }}
/>
