title: クイックスタート：サーバーデプロイ

協調編集やインポート/エクスポートなどのサーバー機能をすぐ試したい場合はここから始めます。本番は[本番デプロイ](/guides/pro/deploy)を参照してください。

## 対象

- ローカル評価/PoC
- 小規模な社内テスト
- まだ ID/権限連携がない場合

## 環境要件

| 項目 | 要件 |
| ---- | ---- |
| OS | Linux、Mac、Windows(WSL2) |
| CPU | 1 コア以上 |
| メモリ | 2G 以上（大きなインポートは >4G 推奨） |
| ディスク | 10G 以上 |
| Docker | 23 以上 |

互換性：

- Linux カーネル 3.10.0 以上
- Docker Compose 2.21 以上
- DB: MySQL 8+、PostgreSQL 13+、互換 DB（Dameng V8 など）
- Redis 5.0+

## Docker Compose で一括デプロイ

<Callout>
  ライセンス未適用では制限付きモードです。制限解除は[ライセンス](/guides/pro/license)を参照してください。
</Callout>

### インストール

<Callout type="warning" title="注意">
  Docker が未インストールの場合、スクリプトが最新版をインストールします。
</Callout>

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

特定バージョン：

```bash
bash -c "$(curl -fsSL https://get.univer.ai/product)" -- 0.9.1
```

オフライン：

1. オフラインパッケージをダウンロード：https://univer.ai/releases/univer-server/download
2. サーバーへアップロードして展開
3. `bash load-images.sh` で Docker に読み込み

スクリプトは `univer-server` ディレクトリを作成し自動起動します。

### Demo UI

最新の Demo UI コードを [Demo UI リポジトリ](https://github.com/dream-num/univer-pro-sheet-start-kit) から取得して起動します。

サービスリンクにアクセスすると空白ドキュメントが自動作成されます。協調編集を試すには、別のブラウザやシークレットウィンドウで同じリンクを開いてください。

### USIP Demo

<Steps>
  <Step>
    `univer-server` に `.env.custom` を作成し、以下を追加：

    ```properties
    USIP_ENABLED=true
    ```
  </Step>
  <Step>
    `bash run.sh restart` で再起動
  </Step>
  <Step>
    `bash run.sh start-demo-usip` を実行
  </Step>
</Steps>

`http://localhost:8080` を開いて確認できます。

### 基本コマンド

- **停止**：`cd univer-server && bash run.sh stop`
- **起動**：`cd univer-server && bash run.sh start`
- **再起動**：`cd univer-server && bash run.sh restart`
- **アンインストール**：`cd univer-server && bash run.sh uninstall`

<Callout type="warning" title="注意">
  アンインストールは評価中に作成したデータを削除します。
</Callout>

### 更新

`univer-server` の親ディレクトリで再実行するとアップグレードできます（設定・データは保持）：

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

## K8s に一括デプロイ

```bash
helm install -n univer --create-namespace \
  --set global.istioNamespace="univer" \
  univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
kubectl rollout restart -n univer deployment/collaboration-server
kubectl rollout restart -n univer deployment/universer
```

`http://univer.example.com/sheet/` を開いて確認できます。

アンインストール：

```bash
helm uninstall univer-stack -n univer
```
