title: API
---

本文列出常用 Univer Server API，預設 Base URL 為 `http://localhost:8000`。

> 說明：`type` 參數值：`1` 表示 Docs，`2` 表示 Sheets。

## 文件管理

### 建立文件

<APITable
  request={{
    method: 'POST',
    url: '/universer-api/snapshot/{type}/unit/-/create',
    headers: <code>content-type: application/json</code>,
    parametersType: 'Body',
    parameters: [{
      name: 'type',
      type: 'enum(int)',
      required: true,
      description: '1（docs），2（sheets）路徑與請求體參數',
    }, {
      name: 'name',
      type: 'string',
      required: true,
      description: '文件名稱',
    }, {
      name: 'creator',
      type: 'string',
      required: true,
      description: '建立者 id',
    }, {
      name: 'idempotencyKey',
      type: 'string',
      required: false,
      description: 'v0.20.0開始引入，可選幂等键，字符串需要<=64字節',
    }, {
      name: 'metaData',
      type: 'string',
      required: false,
      description: 'v0.20.0開始引入，使用者自訂資訊，會綁定到建立的unit，之後的同步事件和USIP調用會透傳，字符串需要<=1024字節',
    }],
    example: `curl http://localhost:8000/universer-api/snapshot/{type}/unit/-/create \\
    -X POST \\
    -H 'Content-Type: application/json' \\
    --data-raw '{"type":2,"name":"New Sheet By Univer","creator":"userID","idempotencyKey":"a-idgenerator-unique-id","metaData":"tenant12345"}'`,
  }}
  response={{
    type: 'application/json',
    parameters: [{
      name: 'error',
      type: 'object',
      properties: [{
        name: 'code',
        type: 'enum(int)',
        description: '1（成功）',
      }, {
        name: 'message',
        type: 'string',
        description: '錯誤訊息',
      }],
    }, {
      name: 'unitID',
      type: 'string',
      description: '文件 id',
    }],
    example: JSON.stringify({
      error: {
        code: 1,
        message: 'success',
      },
      unitID: 'ETVf-B4lQqOSE_p09mcp9Q',
    }, null, 2),
  }}
/>

### 取得文件列表

<APITable
  request={{
    method: 'GET',
    url: '/universer-api/snapshot/{type}/units',
    parametersType: 'Query',
    parameters: [{
      name: 'type',
      type: 'enum(int)',
      required: true,
      description: '1（doc），2（sheet）路徑與請求體參數',
    }, {
      name: 'nextCursor',
      type: 'string',
      required: false,
      description: '分頁下一頁游標',
    }],
    example: `curl -X GET 'http://localhost:8000/universer-api/snapshot/1/units?nextCursor=100'`,
  }}
  response={{
    type: 'application/json',
    parameters: [{
      name: 'error',
      type: 'object',
      properties: [{
        name: 'code',
        type: 'enum(int)',
        description: '1（成功）',
      }, {
        name: 'message',
        type: 'string',
        description: '錯誤訊息',
      }],
    }, {
      name: 'units',
      type: 'array[object]',
      description: '文件列表',
      properties: [{
        name: 'unitID',
        type: 'string',
        description: '文件 id',
      }, {
        name: 'name',
        type: 'string',
        description: '文件名稱',
      }, {
        name: 'type',
        type: 'enum(int)',
        description: '1（doc），2（sheet）',
      }],
    }, {
      name: 'nextCursor',
      type: 'string',
      description: '下一頁游標，空值代表最後一頁',
    }],
    example: JSON.stringify({
      error: {
        code: 1,
        message: '',
      },
      units: [{
        unitID: '1',
        name: 'a',
        type: 1,
      }],
      nextCursor: '200',
    }, null, 2),
  }}
/>

## 檔案與匯入匯出

### 上傳檔案 [#upload-file]

<APITable
  request={{
    method: 'POST',
    url: '/universer-api/stream/file/upload',
    headers: <code>content-type: multipart/form-data</code>,
    parametersType: 'Body',
    parameters: [{
      name: 'size',
      type: 'int',
      required: true,
      description: '檔案大小（byte），query 參數；必須與實際大小一致，否則回傳 error',
    }, {
      name: 'file',
      type: 'Form.file',
      required: true,
      description: 'HTML form 上傳檔案',
    }],
    example: `curl 'http://localhost:8000/universer-api/stream/file/upload?size=125466' \\
    --header 'cookie: _univer=XXXXXX' \\
    --form 'file=@"demo.xlsx"'`,
  }}
  response={{
    type: 'application/json',
    parameters: [{
      name: 'FileId',
      type: 'string',
      description: '檔案 id，供後續匯入匯出使用',
    }],
    example: JSON.stringify({
      FileId: 'xxxx',
    }, null, 2),
  }}
/>
