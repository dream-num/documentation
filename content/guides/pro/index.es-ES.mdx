- Más información sobre licencias y límites: [Licencia](/guides/pro/license)

<Callout type="warning">
Las capacidades avanzadas de Univer SDK Pro requieren el servidor. Primero implemente el servidor.
</Callout>

## Licencia y límites

Univer SDK Pro se publica bajo la [Licencia comercial de Univer](/guides/pro/license). Puede usarlo sin licencia para evaluación, pero habrá límites como marca de agua, tamaño de importación y cuotas de colaboración. Consulte [Precios](/guides/pro) para obtener más detalles.

## Integración de cliente

Si necesita un iniciador listo para ejecutar, use el kit de inicio Univer SDK Pro:

<Tabs items={['npm', 'pnpm']}>
  <Tab>
Requiere `nodejs >= 18`, `npm >= 8` y `git`.

    ```bash
    npx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    npm install
    npm run dev
    ```
  </Tab>
  <Tab>
Requiere `nodejs >= 18`, `pnpm >= 7` y `git`.

    ```bash
    pnpm dlx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    pnpm install
    pnpm dev
    ```
  </Tab>
</Tabs>

<Callout>
Si el servidor se ejecuta en otra máquina, actualice `vite.config.ts` y reemplace `localhost` con la IP o el dominio del servidor.
</Callout>

Si todo funciona, visite http://localhost:5173/ para probar Pro funciones y colaboración.
