title: "빠른 시작: 서버 배포"
---

협업, 가져오기/내보내기 등 서버가 지원하는 기능을 빠르게 체험하려면 여기에서 시작하세요. 프로덕션 환경에 배포하려면 [프로덕션 배포](/guides/pro/deploy)를 참고하세요.

## 사용하기 적합한 경우

- 로컬 평가 또는 PoC
- 소규모 내부 테스트
- 아직 ID/권한 시스템을 연동하지 않은 경우

## 환경 요구 사항

| 항목 | 요구 사항 |
| ---- | ---- |
| OS | Linux, Mac, Windows (WSL2) |
| CPU | 최소 1코어 |
| 메모리 | 최소 2G, 대용량 가져오기에는 4G 초과 권장 |
| 디스크 | 최소 10G |
| Docker | 23+ |

호환성:

- Linux 커널 >= 3.10.0(이전 커널에서는 문제가 발생할 수 있음)
- Docker Compose >= 2.21
- 데이터베이스: MySQL 8+, PostgreSQL 13+, 호환되는 중국산 데이터베이스(Dameng V8 포함)
- Redis: 5.0+

## Docker Compose에 원클릭 배포

<Callout>
  라이선스가 없으면 서버가 제한 모드로 실행됩니다. 모든 기능을 사용하려면 [라이선스](/guides/pro/license)를 참고하세요.
</Callout>

### 설치

<Callout type="warning" title="참고">
  Docker가 설치되어 있지 않으면 스크립트가 최신 버전을 자동으로 설치합니다.
</Callout>

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

특정 버전 설치:

```bash
bash -c "$(curl -fsSL https://get.univer.ai/product)" -- 0.9.1
```

오프라인 설치:

1. 오프라인 패키지 다운로드: //releases/univer-server/download
2. 서버에 업로드하고 압축 해제
3. `bash load-images.sh`를 실행하여 이미지를 Docker에 로드

스크립트가 `univer-server` 디렉터리를 만들고 서비스를 자동으로 시작합니다.

### Demo UI 시작

[Demo UI 저장소](https://github.com/dream-num/univer-pro-sheet-start-kit)로 이동하여 최신 Demo UI 코드를 가져오고 서비스를 시작하세요.

서비스 링크에 접속하면 빈 문서가 자동으로 생성됩니다. 협업 기능을 체험하려면 다른 브라우저나 시크릿 창에서 같은 링크를 여세요.

### USIP Demo 시작

<Steps>
  <Step>
    `univer-server`에 `.env.custom`을 만들고 다음 내용을 추가합니다.

    ```properties
    USIP_ENABLED=true
    ```
  </Step>
  <Step>
    `bash run.sh restart`를 실행하여 서비스를 다시 시작합니다.
  </Step>
  <Step>
    `bash run.sh start-demo-usip`를 실행하여 데모를 시작합니다.
  </Step>
</Steps>

`http://localhost:8080`에 접속하여 체험해 보세요.

### 자주 사용하는 명령어

- **중지**: `cd univer-server && bash run.sh stop`
- **시작**: `cd univer-server && bash run.sh start`
- **다시 시작**: `cd univer-server && bash run.sh restart`
- **제거**: `cd univer-server && bash run.sh uninstall`

<Callout type="warning" title="참고">
  제거하면 평가 중에 생성한 모든 문서와 이미지가 삭제됩니다. 신중하게 진행하세요.
</Callout>

### 서버 업데이트

설정과 데이터를 유지하면서 업그레이드하려면 상위 디렉터리에서 설치 프로그램을 다시 실행하세요.

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

## K8s에 원클릭 배포

K8s 클러스터가 이미 있다면 Helm을 사용할 수 있습니다.

```bash
helm install -n univer --create-namespace \
  --set global.istioNamespace="univer" \
  univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
kubectl rollout restart -n univer deployment/collaboration-server
kubectl rollout restart -n univer deployment/universer
```

`http://univer.example.com/sheet/`를 열어 체험해 보세요.

제거:

```bash
helm uninstall univer-stack -n univer
```
