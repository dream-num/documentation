## Getting Started Path

- Deploy the server for testing/local: [Quick Start](/guides/pro/server)
- Learn licensing and limits: [License](/guides/pro/license)
- Integrate into your frontend project: see “Client Integration” below
- Production architecture and configuration: [Production Deployment](/guides/pro/deploy)
- Identity integration or event sync: [USIP Integration](/guides/pro/usip) and [Event Sync](/guides/pro/event-sync)

<Callout type="warning">
  Univer SDK Pro advanced capabilities require the server. Please deploy the server first.
</Callout>

## License and Limits

Univer SDK Pro is released under the [Univer Commercial License](/guides/pro/license). You can use it without a license for evaluation, but there will be limits such as watermark, import size, and collaboration quotas. See [Pricing](/guides/pro) for details.

## Client Integration

If you need a ready-to-run starter, use the Univer SDK Pro starter kit:

<Tabs items={['npm', 'pnpm']}>
  <Tab>
    Requires `nodejs >= 18`, `npm >= 8`, and `git`.

    ```bash
    npx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    npm install
    npm run dev
    ```
  </Tab>
  <Tab>
    Requires `nodejs >= 18`, `pnpm >= 7`, and `git`.

    ```bash
    pnpm dlx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    pnpm install
    pnpm dev
    ```
  </Tab>
</Tabs>

<Callout>
  If the server runs on another machine, update `vite.config.ts` and replace `localhost` with the server IP or domain.
</Callout>

If everything works, visit http://localhost:5173/ to try Pro features and collaboration.
