title: "Быстрый старт: развёртывание сервера"
---

Если вы хотите быстро опробовать совместную работу, импорт, экспорт и другие возможности, требующие сервера, начните с этой страницы. Инструкции для рабочей среды см. в разделе [«Развёртывание в рабочей среде»](/guides/pro/deploy).

## Когда использовать

- Локальное ознакомление или проверка концепции (PoC)
- Небольшое внутреннее тестирование
- Интеграция с системой идентификации и разрешений пока не требуется

## Требования к окружению

| Компонент | Требование |
| ---- | ---- |
| ОС | Linux, Mac, Windows (WSL2) |
| Процессор | Не менее 1 ядра |
| Память | Не менее 2G; для импорта больших файлов рекомендуется более 4G |
| Диск | Не менее 10G |
| Docker | 23+ |

Совместимость:

- Ядро Linux >= 3.10.0 (с более ранними версиями могут возникнуть проблемы)
- Docker Compose >= 2.21
- База данных: MySQL 8+, PostgreSQL 13+, совместимые базы данных китайского производства (включая Dameng V8)
- Redis: 5.0+

## Развёртывание в Docker Compose одной командой

<Callout>
  Без лицензии сервер работает в режиме ограниченной функциональности. Чтобы разблокировать все возможности, см. раздел [«Лицензия»](/guides/pro/license).

### Установка

<Callout type="warning" title="Примечание">
  Если Docker не установлен, скрипт автоматически установит его последнюю версию.
</Callout>

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

Установка определённой версии:

```bash
bash -c "$(curl -fsSL https://get.univer.ai/product)" -- 0.9.1
```

Автономная установка:

1. Скачайте пакет для автономной установки: //releases/univer-server/download
2. Загрузите его на сервер и распакуйте
3. Выполните `bash load-images.sh`, чтобы загрузить образы в Docker

Скрипт создаст каталог `univer-server` и автоматически запустит службы.

### Запуск демонстрационного интерфейса

Перейдите в [репозиторий демонстрационного интерфейса](https://github.com/dream-num/univer-pro-sheet-start-kit), получите последнюю версию его кода и запустите службу.

При переходе по ссылке службы автоматически создаётся пустой документ. Чтобы опробовать совместную работу, откройте ту же ссылку в другом браузере или окне в режиме инкогнито.

### Запуск демонстрационной версии USIP

<Steps>
  <Step>
    Создайте `.env.custom` в `univer-server` и добавьте:

    ```properties
    USIP_ENABLED=true
    ```
  </Step>
  <Step>
    Выполните `bash run.sh restart`, чтобы перезапустить службы
  </Step>
  <Step>
    Выполните `bash run.sh start-demo-usip`, чтобы запустить демонстрационную версию
  </Step>
</Steps>

Откройте `http://localhost:8080`, чтобы опробовать её.

### Основные команды

- **Остановка**: `cd univer-server && bash run.sh stop`
- **Запуск**: `cd univer-server && bash run.sh start`
- **Перезапуск**: `cd univer-server && bash run.sh restart`
- **Удаление**: `cd univer-server && bash run.sh uninstall`

<Callout type="warning" title="Примечание">
  При удалении будут удалены все документы и изображения, созданные во время ознакомления. Будьте осторожны.
</Callout>

### Обновление сервера

Чтобы выполнить обновление с сохранением конфигурации и данных, снова запустите установщик в родительском каталоге:

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

## Развёртывание в K8s одной командой

Если у вас уже есть кластер K8s, можно использовать Helm:

```bash
helm install -n univer --create-namespace \
  --set global.istioNamespace="univer" \
  univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
kubectl rollout restart -n univer deployment/collaboration-server
kubectl rollout restart -n univer deployment/universer
```

Откройте `http://univer.example.com/sheet/`, чтобы опробовать систему.

Удаление:

```bash
helm uninstall univer-stack -n univer
```
