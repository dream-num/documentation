title: 라이선스
---

Univer SDK Pro의 고급 기능을 온전히 활용하려면 라이선스가 필요합니다. 이 페이지에서는 라이선스를 취득하고 구성하며 확인하는 방법을 설명합니다.

## 라이선스가 필요한 경우

- 평가: 라이선스가 필요하지 않지만 기능이 제한됩니다(워터마크, 가져오기 크기, 공동 편집 할당량).
- 프로덕션: 모든 기능을 사용하려면 라이선스를 구매하는 것이 좋습니다.

아직 서버를 배포하지 않았다면 [빠른 시작](/guides/pro/server)을 참고하세요.

## 라이선스 받기

1. [라이선스 페이지](/guides/pro/license)를 방문하여 로그인합니다.
2. 라이선스 파일을 다운로드합니다.

![라이선스 다운로드](./license/new-02-cn.png)

### 무료 평가판 라이선스

30일 평가판 라이선스를 요청할 수 있습니다.

1. [라이선스 페이지](/guides/pro/license)를 방문하여 로그인합니다.
2. “평가판 라이선스 받기”를 클릭합니다.

![라이선스 받기](./license/new-01-cn.png)

## 라이선스 추가 또는 업데이트

`license-univer.zip`의 압축을 풀어 `license.txt`와 `licenseKey.txt`를 가져옵니다. 이 파일들을 수정하지 마세요.

### 클라이언트에서 라이선스 사용

#### 프리셋 모드

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsAdvancedPreset({
      license: `Content from license.txt`,
    }),
  ],
})
```

#### 플러그인 모드

Univer 인스턴스를 만든 후 `UniverLicensePlugin`을 가장 먼저 등록합니다.

```typescript
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: `Content from license.txt`,
})
```

### 서버에서 라이선스 사용

<Tabs items={['docker compose', 'K8s']}>
  <Tab>
    1. `license.txt`와 `licenseKey.txt`를 `/univer-server/configs/`에 복사합니다.
    2. `bash run.sh restart`를 `univer-server`에서 실행합니다.
  </Tab>
  <Tab>
    1. Helm을 통해 설치하거나 업그레이드합니다.

    ```bash
    helm upgrade --install -n univer --create-namespace \
    --set global.istioNamespace="univer" \
    --set-file universer.license.licenseV2=$(YOUR_LICENSE_TXT_PATH) \
    --set-file universer.license.licenseKeyV2=$(YOUR_LICENSE_KEY_TXT_PATH) \
    univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
    ```
  </Tab>
</Tabs>

## 라이선스 확인

### 프런트엔드에서 확인

- 라이선스가 없거나 유효하지 않으면 워터마크가 표시되고 기능이 제한됩니다.
- 유효한 라이선스를 적용하면 제한이 해제됩니다.

![유효하지 않은 라이선스](./license/new-06.png)

![유효한 라이선스](./license/new-07.png)

### 서버에서 확인

`host:8000/universer-api/license/key`에 접속하여 사용 권한을 확인합니다. 로컬 환경에서는 다음 주소를 사용합니다.

`http://localhost:8000/universer-api/license/key`

```json
{
  "verify": "true",
  "release_type": "COMMERCIAL"
}
```

![서버 라이선스 확인](./license/new-05.png)

## FAQ

1. 확인 실패: 라이선스 유효성, 파일 무결성 및 서비스 재시작 여부를 확인하세요.
2. 워터마크가 계속 표시됨: 클라이언트 측에 라이선스가 주입되었는지 확인하세요.
3. 기타 문제: 지원팀에 문의하세요.
