本頁介紹 Univer 後端服務的可觀測性與運維入口，包含指標、日誌與常見定位路徑。

## 可觀測入口

Univer 提供：

- Prometheus Metrics 指標
- 服務日誌（stdout + 持久化卷）

若啟用內建可觀測元件，可在 Grafana 直接查看；否則可匯出面板接入你的監控系統。

## Metrics

內建 Grafana 面板涵蓋：

- 基礎元件：RabbitMQ、Redis、RDS
- 協作服務：collaboration-server
- 主服務：universer
- 匯入匯出：exchange

可用於觀測效能、可用性與業務指標。外部系統可下載面板設定：

## 服務日誌

### Docker Compose

日誌輸出到 stdout 與持久化卷（最多保留 30 天或 1GB）。

- universer：`/logs/universer/`
- exchange：`/logs/worker-exchange/`

### K8s / Loki

啟用內建可觀測元件後，可於 Grafana -> Explore 使用 Loki 查詢：

![Loki 查詢](./sre-manual/loki-search.png)

## 常見定位路徑

1. **功能不可用**：先檢查 RDS/MQ/Redis 的 SLI
2. **API 失敗**：查看 universer API SLI 與錯誤碼分佈
3. **日誌檢索**：在 Loki 搜尋 `biz_code=xxx`
4. **容量瓶頸**：觀察 QPS、延遲、CPU/記憶體
