---
title: "Démarrage rapide : déployer le serveur"
---

Si vous souhaitez tester rapidement la collaboration, l’importation, l’exportation et d’autres fonctionnalités reposant sur le serveur, commencez ici. Pour un environnement de production, consultez la page [Déploiement en production](/guides/pro/deploy).

## Quand utiliser cette méthode

- Évaluation locale ou PoC
- Tests internes à petite échelle
- Aucune intégration à un système d’identité ou de gestion des autorisations pour le moment

## Configuration requise

| Élément | Configuration requise |
| ---- | ---- |
| Système d’exploitation | Linux, Mac, Windows (WSL2) |
| Processeur | Au moins 1 cœur |
| Mémoire | Au moins 2G ; >4G recommandés pour les importations volumineuses |
| Disque | Au moins 10G |
| Docker | 23+ |

Compatibilité :

- Noyau Linux >= 3.10.0 (les noyaux plus anciens peuvent présenter des problèmes)
- Docker Compose >= 2.21
- Base de données : MySQL 8+, PostgreSQL 13+, bases de données chinoises compatibles (notamment Dameng V8)
- Redis : 5.0+

## Déploiement en un clic avec Docker Compose

<Callout>
  Sans licence, le serveur fonctionne en mode limité. Consultez la page [Licence](/guides/pro/license) pour débloquer toutes les fonctionnalités.
</Callout>

### Installation

<Callout type="warning" title="Remarque">
  Si Docker n’est pas installé, le script installe automatiquement la dernière version.
</Callout>

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

Pour installer une version spécifique :

```bash
bash -c "$(curl -fsSL https://get.univer.ai/product)" -- 0.9.1
```

Installation hors ligne :

1. Téléchargez le package d’installation hors ligne : //releases/univer-server/download
2. Chargez-le sur le serveur et extrayez son contenu
3. Exécutez `bash load-images.sh` pour charger les images dans Docker

Le script crée un répertoire `univer-server` et démarre automatiquement les services.

### Démarrage de l’interface de démonstration

Accédez au [dépôt de l’interface de démonstration](https://github.com/dream-num/univer-pro-sheet-start-kit) pour récupérer la dernière version de son code et démarrer le service.

Ouvrez le lien du service pour créer automatiquement un document vierge. Pour tester la collaboration, ouvrez le même lien dans un autre navigateur ou dans une fenêtre de navigation privée.

### Démarrage de la démonstration USIP

<Steps>
  <Step>
    Créez `.env.custom` dans `univer-server` et ajoutez :

    ```properties
    USIP_ENABLED=true
    ```
  </Step>
  <Step>
    Exécutez `bash run.sh restart` pour redémarrer les services
  </Step>
  <Step>
    Exécutez `bash run.sh start-demo-usip` pour démarrer la démonstration
  </Step>
</Steps>

Ouvrez `http://localhost:8080` pour l’essayer.

### Commandes courantes

- **Arrêter** : `cd univer-server && bash run.sh stop`
- **Démarrer** : `cd univer-server && bash run.sh start`
- **Redémarrer** : `cd univer-server && bash run.sh restart`
- **Désinstaller** : `cd univer-server && bash run.sh uninstall`

<Callout type="warning" title="Remarque">
  La désinstallation supprime tous les documents et toutes les images créés pendant l’évaluation. Procédez avec prudence.
</Callout>

### Mise à jour du serveur

Exécutez à nouveau le programme d’installation dans le répertoire parent pour effectuer la mise à niveau tout en conservant la configuration et les données :

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

## Déploiement en un clic sur K8s

Si vous disposez déjà d’un cluster K8s, vous pouvez utiliser Helm :

```bash
helm install -n univer --create-namespace \
  --set global.istioNamespace="univer" \
  univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
kubectl rollout restart -n univer deployment/collaboration-server
kubectl rollout restart -n univer deployment/universer
```

Ouvrez `http://univer.example.com/sheet/` pour l’essayer.

Désinstallation :

```bash
helm uninstall univer-stack -n univer
```
