---
title: 內建元件設定
---

本頁僅適用於使用 Univer 內建元件（PostgreSQL、RabbitMQ、MinIO）。帳號密碼只在首次初始化時生效，部署完成後需依元件官方方式修改。

## 修改預設密碼

<Callout>
  請在首次部署前完成設定，已部署的實例不會自動變更密碼。
</Callout>

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    在安裝目錄建立 `.env.custom`，然後執行：

    ```bash
    bash run.sh
    ```
  </Tab>
  <Tab label="K8s">
    建立 `values.yaml` 後執行：

    ```shell
    helm install -n univer --create-namespace \
      --set global.istioNamespace="univer" \
      --values values.yaml \
      univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
    kubectl rollout restart -n univer deployment/collaboration-server
    kubectl rollout restart -n univer deployment/universer
    ```
  </Tab>
</Tabs>

### PostgreSQL

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    DATABASE_USERNAME=postgres
    DATABASE_PASSWORD=postgres
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    global:
      postgresql:
        auth:
          postgresPassword: postgres

    universer:
      config:
        database:
          username: postgres
          password: postgres

    temporal:
      server:
        config:
          persistence:
            default:
              sql:
                user: postgres
                password: postgres

            visibility:
              sql:
                user: postgres
                password: postgres
    ```
  </Tab>
</Tabs>

說明：

- 僅對首次初始化有效。
- K8s 僅可設定 admin 密碼，預設帳號為 `postgres`。
- `universer` 與 `temporal` 需使用相同資料庫帳號。

### RabbitMQ

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    RABBITMQ_USERNAME=guest
    RABBITMQ_PASSWORD=guest
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    rabbitmq:
      auth:
        username: guest
        password: guest

    universer:
      config:
        rabbitmq:
          username: guest
          password: guest
    ```
  </Tab>
</Tabs>

說明：

- 預設帳號為 `guest`，生產環境建議修改。
- 修改 RabbitMQ 帳號後需同步更新 `universer` 設定。

### S3 (MinIO)

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    S3_USER=minio
    S3_PASSWORD=minio123456
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    minio:
      auth:
        rootUser: admin
        rootPassword: minioadmin

    universer:
      config:
        s3:
          accessKeyID: admin
          accessKeySecret: minioadmin
    ```
  </Tab>
</Tabs>

說明：

- `rootUser/rootPassword` 為 MinIO 管理員帳號。
- `accessKeyID/accessKeySecret` 需與 MinIO 帳號一致。
