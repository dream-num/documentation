本页介绍 Univer 后端服务的可观测能力与运维入口，包含指标、日志与常见定位路径。

## 可观测入口

Univer 提供两类能力：

- Prometheus Metrics 指标
- 服务日志（stdout + 持久化卷）

如果启用了内置可观测组件，可直接在 Grafana 查看；否则可导出面板接入你的监控系统。

## Metrics

内置 Grafana 面板覆盖：

- 基础组件：RabbitMQ、Redis、RDS
- 协同服务：collaboration-server
- 主服务：universer
- 导入导出：exchange

你可从中查看服务性能、可用性与关键业务指标。自建监控系统可下载面板配置：

https://release-univer.oss-cn-shenzhen.aliyuncs.com/release/univer-grafana-dashboards.tar.gz

## 服务日志

### Docker Compose

日志输出到 stdout 与持久化卷（默认最多保留 30 天或 1GB）。

- universer：`/logs/universer/`
- exchange：`/logs/worker-exchange/`

### K8s / Loki

若启用内置可观测组件，可在 Grafana -> Explore 中选择 Loki 进行查询：

![Loki 日志搜索](./sre-manual/loki-search.png)

## 常见定位路径

1. **功能异常**：先看基础组件 SLI（RDS、MQ、Redis）是否异常
2. **接口失败**：查看 universer API SLI 与错误码分布
3. **日志检索**：通过 Loki 搜索错误码 `biz_code=xxx`
4. **容量瓶颈**：关注 QPS、响应时间与 CPU/内存使用率
