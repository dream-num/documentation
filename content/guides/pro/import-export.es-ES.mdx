title: Servicio de importación y exportación
---

La importación/exportación la proporciona el servidor y permite convertir archivos de Office a documentos de Univer o exportarlos nuevamente a formatos de Office.

## Requisitos previos

- Implementación del servidor completada (consulte [Inicio rápido](/guides/pro/server))
- Exchange Workers y Temporal se están ejecutando
- Se puede acceder al almacenamiento de objetos

## Importar Fluya

1. [Subir el archivo](/guides/pro/api#upload-file) al almacenamiento de objetos y obtenga `fileID`
2. Llame a la API [importar](/guides/pro/api#import-file) con `outputType`
   - `1`: importar como una unidad documento
   - `2`: importar como JSON
3. Encuesta [estado de la tarea](/guides/pro/api#get-task-result):
   - `pending`: seguir sondeando
   - `done`: obtener `import.unitID` o `import.jsonID`
   - `failed`: leer `error.message`
4. Carga de documentos
   - Si importa como un documento unitario, cárguelo directamente con `import.unitID`, consulte la sección [Colaboración](/guides/sheets/features/collaboration)
   - Si importa como JSON, use `import.jsonID` para descargar la URL de [Obtener archivo](/guides/pro/api#get-file), luego procese el JSON con [Datos del lado del servidor conversion](/guides/sheets/features/import-export#server-side-data-conversion) antes de cargar

## Flujo de exportación

El flujo de exportación para documentos colaborativos de la unidad:

1. Llame a la API [export](/guides/pro/api#export-file) con `unitID` para obtener `taskID`
2. Encuesta [estado de la tarea](/guides/pro/api#get-task-result):
   - `pending`: sigue sondeando
   - `done`: obtén `export.fileID`
   - `failed`: lee `error.message`
3. Utilice `export.fileID` para [Obtener archivo](/guides/pro/api#get-file) URL de descarga

![export](./import-export/export.png)

El flujo de exportación para documentos no colaborativos:

1. [Cargar](/guides/pro/api#upload-file) el archivo generado desde la instantánea JSON de la interfaz al almacenamiento de objetos y obtenga `fileID`
2. Llame a la API [export](/guides/pro/api#export-file) con `jsonID` para obtener `taskID`; `jsonID` es el `fileID` del paso anterior
3. Encuesta [estado de la tarea](/guides/pro/api#get-task-result):
   - `pending`: sigue sondeando
   - `done`: obtén `export.fileID`
   - `failed`: leer `error.message`
4. Utilice `export.fileID` para [Obtener archivo](/guides/pro/api#get-file) URL de descarga

## Ejemplo de implementación

Las llamadas API para importación/exportación ya están integradas en la interfaz; consulte [API de Facade](/guides/sheets/features/import-export#facade-api) para obtener más detalles.

Los fragmentos siguientes demuestran un flujo de trabajo completo de TypeScript utilizando `fetch`. Reemplace `BASE_URL` con el punto final de su servidor Univer e incluya el encabezado de autenticación requerido (por ejemplo, `cookie` o `Authorization`) en cada solicitud.

### 1. Sube un archivo

```typescript
async function uploadFile(file: File): Promise<string> {
  const formData = new FormData()
  formData.append('file', file)

  const res = await fetch(
    `${BASE_URL}/universer-api/stream/file/upload?size=${file.size}`,
    {
      method: 'POST',
      headers: {
        // Add your auth header here, e.g.
        // cookie: '_univer=XXXXXX',
      },
      body: formData,
    },
  )

  const data = await res.json()
  if (data.error?.code !== 1) {
    throw new Error(data.error?.message || 'Upload failed')
  }
  return data.FileId // used as fileID in the next step
}
```

### 2. Estado de la tarea de sondeo

```typescript
interface TaskResult {
  status: 'pending' | 'done' | 'failed'
  error?: { code: number, message: string }
  import?: { unitID?: string, jsonID?: string }
  export?: { fileID?: string }
}

async function pollTask(taskID: string, interval = 2000): Promise<TaskResult> {
  while (true) {
    const res = await fetch(
      `${BASE_URL}/universer-api/exchange/task/${taskID}`,
      {
        headers: {
          // cookie: '_univer=XXXXXX',
        },
      },
    )
    const data: TaskResult = await res.json()

    if (data.status === 'done' || data.status === 'failed') {
      return data
    }

    await new Promise(resolve => setTimeout(resolve, interval))
  }
}
```

### 3. Importar un archivo

```typescript
interface ImportParams {
  fileID: string
  type: 1 | 2 // 1 = doc, 2 = sheet
  outputType: 1 | 2 // 1 = unit, 2 = json
  minSheetRowCount?: number
  minSheetColumnCount?: number
}

async function importFile(params: ImportParams): Promise<string> {
  const res = await fetch(
    `${BASE_URL}/universer-api/exchange/${params.type}/import`,
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        // cookie: '_univer=XXXXXX',
      },
      body: JSON.stringify({
        fileID: params.fileID,
        outputType: params.outputType,
        minSheetRowCount: params.minSheetRowCount ?? 1000,
        minSheetColumnCount: params.minSheetColumnCount ?? 20,
      }),
    },
  )

  const data = await res.json()
  if (data.error?.code !== 1) {
    throw new Error(data.error?.message || 'Import request failed')
  }

  // Poll until the task is done or failed
  const taskResult = await pollTask(data.taskID)
  if (taskResult.status === 'failed') {
    throw new Error(taskResult.error?.message || 'Import failed')
  }

  return params.outputType === 1
    ? taskResult.import!.unitID!
    : taskResult.import!.jsonID!
}
```

### 4. Exportar un archivo

```typescript
interface ExportParams {
  unitID: string
  jsonID: string
  type: 1 | 2 // 1 = doc, 2 = sheet
  sscSwitch?: boolean
}

async function exportFile(params: ExportParams): Promise<string> {
  const res = await fetch(
    `${BASE_URL}/universer-api/exchange/${params.type}/export`,
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        // cookie: '_univer=XXXXXX',
      },
      body: JSON.stringify({
        unitID: params.unitID,
        type: params.type,
        sscSwitch: params.sscSwitch ?? false,
      }),
    },
  )

  const data = await res.json()
  if (data.error?.code !== 1) {
    throw new Error(data.error?.message || 'Export request failed')
  }

  const taskResult = await pollTask(data.taskID)
  if (taskResult.status === 'failed') {
    throw new Error(taskResult.error?.message || 'Export failed')
  }

  // Get a signed download URL
  const urlRes = await fetch(
    `${BASE_URL}/universer-api/file/${taskResult.export!.fileID!}/sign-url`,
    {
      headers: {
        // cookie: '_univer=XXXXXX',
      },
    },
  )
  const urlData = await urlRes.json()
  if (urlData.error?.code !== 1) {
    throw new Error(urlData.error?.message || 'Failed to get download URL')
  }

  return urlData.url
}
```
