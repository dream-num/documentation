---
title: トラブルシューティング
---

インストール、起動、アクセス、USIP、インポート/エクスポート、アップグレードの代表的な問題を整理します。

## 対象範囲

- Docker Compose / K8s
- USIP / イベント同期
- インポート/エクスポート

## 迅速切り分け

| 症状 | まず実行 | 次の手順 |
| --- | --- | --- |
| 一括スクリプトが停止 | `curl -I https://get.univer.ai` | オフラインパッケージ |
| Demo UI にアクセスできない | `cd univer-server && bash run.sh start` | `docker compose ps` |
| USIP Demo 8080 が 404 | `.env.custom` の `USIP_ENABLED=true` | `bash run.sh restart` |
| Helm Pod Pending | `kubectl describe pod` | イメージ/リソース/PVC 確認 |
| インポート/エクスポート Pending | temporal/exchange/universer ログ | 以降参照 |

## Docker Compose

### インストール失敗

```bash
curl -I https://get.univer.ai
dig get.univer.ai
```

```bash
systemctl status docker
ps -ef | grep dockerd
```

### 起動失敗/再起動ループ

```bash
cd univer-server
bash run.sh start
docker compose ps
docker compose logs --tail=200 <service>
```

原因例：ポート競合、`.env.custom` 未反映、リソース不足。

### Demo UI

- ポート競合：`lsof -i :3010`
- WebSocket 切断：プロキシ/CORS を確認
- 自動作成失敗：universer ログを確認

## K8s

### Pod Pending

```bash
kubectl describe pod <pod> -n univer
```

### CrashLoopBackOff

```bash
kubectl logs <pod> -n univer --previous
```

### Ingress / ドメイン

```bash
dig univer.example.com
kubectl get ingress -n univer
kubectl get endpoints -n univer
```

## USIP

| 症状 | 対応 |
| --- | --- |
| 8080 が応答しない | `bash run.sh start-demo-usip` 実行確認 |
| 401/403 | token 透過、user レスポンス確認 |
| 設定が反映されない | `.env.custom` 変更後に再起動 |

## インポート/エクスポート Pending

### 切り分け

1. VPN/プロキシを無効化 → `bash run.sh restart`
2. サービス状態 → `docker compose ps`
3. Temporal → `docker compose logs -f temporal`
4. Exchange → `docker compose logs -f univer-worker-exchange`
5. Universer → `docker compose logs -f universer`

### よくある原因

- Temporal 起動失敗：ポート競合/DB エラー
- Exchange タイムアウト：Temporal アドレス

例：`exchange/config.yaml.template` を修正後再起動：

```text
addr: no-txt:///${TEMPORAL_HOST}:${TEMPORAL_PORT}
```

## アップグレード/アンインストール

- Docker Compose：親ディレクトリで再実行
- K8s：`helm upgrade --install ... -n univer`
- データが残る：PVC/ボリューム確認

## ログ収集

| サービス | コマンド |
| --- | --- |
| temporal | `docker compose logs -f temporal` |
| exchange | `docker compose logs -f univer-worker-exchange` |
| universer | `docker compose logs -f universer` |

```bash
mkdir -p logs_collect && \
docker compose logs temporal > logs_collect/temporal.log 2>&1 && \
docker compose logs universer > logs_collect/universer.log 2>&1 && \
tar czf univer-troubleshoot-logs.tar.gz logs_collect
```

## チェックリスト

- すべて Up / Pod Ready
- temporal/exchange にエラーなし
- ポート/ドメイン疎通
- 設定変更後に再起動済み
- インポート/エクスポート完了
