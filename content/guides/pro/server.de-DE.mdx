title: 'Schnellstart: Bereitstellen des Servers'
---

Wenn Sie schnell Zusammenarbeit, Import/Export und andere servergestützte Funktionen nutzen möchten, beginnen Sie hier. Informationen zur Produktion finden Sie unter [Produktionsbereitstellung](/guides/pro/deploy).

## Wann zu verwenden

- Lokale Bewertung oder PoC
- Kleine interne Tests
- Noch keine Identitäts-/Berechtigungsintegration

## Umgebungsanforderungen

| Artikel | Anforderung                                    |
| ------- | ---------------------------------------------- |
| OS      | Linux, Mac, Windows (WSL2)                     |
| CPU     | Mindestens 1 Kern                              |
| Memory  | Mindestens 2G; >4G für große Importe empfohlen |
| Disk    | Mindestens 10G                                 |
| Docker  | 23+                                            |

Kompatibilität:

- Linux-Kernel >= 3.10.0 (ältere Kernel können Probleme haben)
- Docker Compose >= 2.21
- Datenbank: MySQL 8+, PostgreSQL 13+, kompatible inländische Datenbanken (Dameng V8 enthalten)
- Redis: 5.0+

## One-Click Deploy to Docker Compose

<Callout>
  Ohne Lizenz läuft der Server im eingeschränkten Modus. Siehe [Lizenz](/guides/pro/license), um alle Funktionen
  freizuschalten.
</Callout>

### Installieren

<Callout type="warning" title="Note">
  Wenn Docker nicht installiert ist, installiert das Skript automatisch die neueste Version.
</Callout>

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

Installieren Sie eine bestimmte Version:

```bash
bash -c "$(curl -fsSL https://get.univer.ai/product)" -- 0.9.1
```

Offline-Installation:

1. Laden Sie das Offline-Paket herunter: //releases/univer-server/download
2. Hochladen und auf den Server extrahieren
3. Ausführen `bash load-images.sh` zum Laden von Bildern in Docker

Das Skript erstellt ein `univer-server`-Verzeichnis und startet die Dienste automatisch.

### Starten Sie die Demo-Benutzeroberfläche

Gehen Sie zu [Demo-UI-Repo](https://github.com/dream-num/univer-pro-sheet-start-kit), um den neuesten Demo-UI-Code abzurufen und den Dienst zu starten.

Besuchen Sie den Dienstlink, um ihn automatisch zu erstellen ein leeres Dokument. Für die Zusammenarbeit öffnen Sie denselben Link in einem anderen Browser oder Inkognito-Fenster.

### Starten Sie die USIP-Demo

<Steps>
  <Step>
Erstellen Sie `.env.custom` in `univer-server` und fügen Sie hinzu:

    ```properties
    USIP_ENABLED=true
    ```

  </Step>
  <Step>
Führen Sie `bash run.sh restart` aus, um die Dienste neu zu starten
  </Step>
  <Step>
Führen Sie `bash run.sh start-demo-usip` aus, um die zu starten Demo
  </Step>
</Steps>

Besuchen Sie `http://localhost:8080`, um es auszuprobieren.

### Allgemeine Befehle

- **Stopp**: `cd univer-server && bash run.sh stop`
- **Start**: `cd univer-server && bash run.sh start`
- **Neustart**: `cd univer-server && bash run.sh restart`
- **Deinstallieren**: `cd univer-server && bash run.sh uninstall`

<Callout type="warning" title="Note">
  Durch die Deinstallation werden alle während der Evaluierung erstellten Dokumente und Bilder entfernt. Gehen Sie
  vorsichtig vor.
</Callout>

### Aktualisieren Sie den Server

Führen Sie das Installationsprogramm erneut im übergeordneten Verzeichnis aus, um ein Upgrade durchzuführen und dabei Konfiguration und Daten beizubehalten:

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

## Ein-Klick-Bereitstellung auf K8s

Wenn Sie bereits über einen K8s-Cluster verfügen, können Sie Helm verwenden:

```bash
helm install -n univer --create-namespace \
  --set global.istioNamespace="univer" \
  univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
kubectl rollout restart -n univer deployment/collaboration-server
kubectl rollout restart -n univer deployment/universer
```

Öffnen Sie `http://univer.example.com/sheet/`, um es auszuprobieren.

Deinstallieren:

```bash
helm uninstall univer-stack -n univer
```
