## 시작 경로

- 테스트/로컬용 서버 배포: [빠른 시작](/guides/pro/server)
- 라이선스 및 제한 사항 알아보기: [라이선스](/guides/pro/license)
- 프런트엔드 프로젝트에 연동: 아래의 '클라이언트 연동' 참고
- 프로덕션 아키텍처 및 구성: [프로덕션 배포](/guides/pro/deploy)
- ID 연동 또는 이벤트 동기화: [USIP 연동](/guides/pro/usip) 및 [이벤트 동기화](/guides/pro/event-sync)

<Callout type="warning">
  Univer SDK Pro의 고급 기능을 사용하려면 서버가 필요합니다. 먼저 서버를 배포하세요.
</Callout>

## 라이선스 및 제한 사항

Univer SDK Pro는 [Univer 상용 라이선스](/guides/pro/license)에 따라 제공됩니다. 라이선스 없이도 평가 목적으로 사용할 수 있지만 워터마크, 가져오기 용량, 협업 할당량 등의 제한이 적용됩니다. 자세한 내용은 [요금제](/guides/pro)를 참고하세요.

## 클라이언트 연동

바로 실행할 수 있는 스타터가 필요하다면 Univer SDK Pro 스타터 키트를 사용하세요.

<Tabs items={['npm', 'pnpm']}>
  <Tab>
    `nodejs >= 18`, `npm >= 8`, `git`이 필요합니다.

    ```bash
    npx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    npm install
    npm run dev
    ```
  </Tab>
  <Tab>
    `nodejs >= 18`, `pnpm >= 7`, `git`이 필요합니다.

    ```bash
    pnpm dlx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    pnpm install
    pnpm dev
    ```
  </Tab>
</Tabs>

<Callout>
  서버가 다른 컴퓨터에서 실행 중이라면 `vite.config.ts`를 업데이트하고 `localhost`를 서버 IP 또는 도메인으로 바꾸세요.
</Callout>

정상적으로 작동하면 http://localhost:5173/ 에 접속하여 Pro 기능과 협업을 체험할 수 있습니다.
