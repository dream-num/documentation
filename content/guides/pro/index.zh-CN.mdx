## 上手路径

- 先部署服务端（测试/本地）：[快速开始](/guides/pro/server)
- 了解授权与限制：[许可证](/guides/pro/license)
- 集成到你的前端项目：见下方“客户端集成”
- 面向生产的架构与配置：[生产部署](/guides/pro/deploy)
- 需要身份接入或消息同步：查看 [USIP 集成](/guides/pro/usip) 与 [事件同步](/guides/pro/event-sync)

<Callout type="warning">
  Univer Pro 的高级能力依赖服务端，请先完成服务端部署。
</Callout>

## 许可证与限制

Univer Pro 以 [Univer 商业授权协议](https://univer.ai/license) 发布。未授权可体验，但会有水印、导入体积、协作数量等限制，完整限制以[定价](https://univer.ai/pricing)为准。

## 客户端集成

如果你需要快速启动一个可用的前端项目，可以使用 Univer Pro 起步套件：

<Tabs items={['npm', 'pnpm']}>
  <Tab>
    执行以下命令需要设备安装有 `nodejs >= 18`，`npm >= 8` 和 `git`。

    ```bash
    npx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    npm install
    npm run dev
    ```
  </Tab>
  <Tab>
    执行以下命令需要设备安装有 `nodejs >= 18`，`pnpm >= 7` 和 `git`。

    ```bash
    pnpm dlx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    pnpm install
    pnpm dev
    ```
  </Tab>
</Tabs>

<Callout>
  如果服务端部署在其他机器上，请在 `vite.config.ts` 中将 `server` 配置里的 `localhost` 改为服务端 IP 或域名。
</Callout>

如果一切顺利，你会在 http://localhost:5173/ 体验到高级功能与协同能力。
