## インポート手順

1. ファイルをオブジェクトストレージにアップロードし、`fileID` の戻り値を取得します。
2. `fileID` を指定してインポート API を呼び出し、出力タイプ `outputType`（1 は unit ドキュメントとしてインポート、2 は JSON データとして取得）を設定し、`taskID` の戻り値を取得します。
3. 変換結果をポーリングし、`status` の戻り値に応じて処理します：
    - `pending`：ポーリングを継続します。
    - `done`：変換成功。`import.jsonID` または `import.unitID` の戻り値を取得します。
    - `failed`：変換失敗。`error.message` からエラー情報を取得します。
4. unit ドキュメントではなく JSON データを取得したい場合は、`import.jsonID` を使ってファイル取得 API を呼び出し、変換結果をダウンロードします。JSON データ取得後は、Univer で利用するために [変換](/guides/docs/features/import-export#server-data-transformation) が必要です。

![import](./import-export/import.png)

## エクスポート手順

1. `unitID` を指定してエクスポート API を呼び出し、`taskID` の戻り値を取得します。
2. 変換結果をポーリングし、`status` の戻り値に応じて処理します：
    - `pending`：ポーリングを継続します。
    - `done`：変換成功。`export.fileID` の戻り値を取得します。
    - `failed`：変換失敗。`error.message` からエラー情報を取得します。
3. `export.fileID` を使ってファイル取得 API を呼び出し、変換結果をダウンロードします。
