title: インポート/エクスポート
---

インポート/エクスポートはサーバーで提供され、Office ファイルを Univer 文書へ変換したり、Office 形式で出力できます。

## 前提条件

- サーバーが導入済み（[クイックスタート](/guides/pro/server)）
- exchange worker と temporal が稼働
- Object Storage が到達可能

## インポート手順

1. ファイルを Object Storage にアップロードし `fileID` を取得
2. `outputType` を指定してインポート API を呼び出す
   - `1`：unit 文書としてインポート
   - `2`：JSON としてインポート
3. タスクの状態をポーリング：
   - `pending`：継続
   - `done`：`import.unitID` または `import.jsonID`
   - `failed`：`error.message` を参照
4. JSON の場合は[サーバー側変換](/guides/docs/features/import-export#server-side-data-conversion)が必要

![import](./import-export/import.png)

## エクスポート手順

1. `unitID` でエクスポート API を呼び出し `taskID` を取得
2. ステータスをポーリング：
   - `pending`：継続
   - `done`：`export.fileID`
   - `failed`：`error.message`
3. `export.fileID` でダウンロード URL を取得

![export](./import-export/export.png)

## 実装例

以下は `fetch` を使った TypeScript の実装例です。`BASE_URL` を Univer サーバーのエンドポイントに置き換え、各リクエストに認証ヘッダー（例：`cookie` や `Authorization`）を含めてください。

### 1. ファイルをアップロードする

```typescript
async function uploadFile(file: File): Promise<string> {
  const res = await fetch(
    `${BASE_URL}/universer-api/stream/file/upload?size=${file.size}`,
    {
      method: 'POST',
      headers: {
        // 認証ヘッダーを追加してください。例：
        // cookie: '_univer=XXXXXX',
      },
      body: file,
    },
  )

  const data = await res.json()
  if (data.error?.code !== 1) {
    throw new Error(data.error?.message || 'アップロードに失敗しました')
  }
  return data.FileId // 次のステップで fileID として使用
}
```

### 2. タスク状態をポーリングする

```typescript
interface TaskResult {
  status: 'pending' | 'done' | 'failed'
  error?: { code: number, message: string }
  import?: { unitID?: string, jsonID?: string }
  export?: { fileID?: string }
}

async function pollTask(taskID: string, interval = 2000): Promise<TaskResult> {
  while (true) {
    const res = await fetch(
      `${BASE_URL}/universer-api/exchange/task/${taskID}`,
      {
        headers: {
          // cookie: '_univer=XXXXXX',
        },
      },
    )
    const data: TaskResult = await res.json()

    if (data.status === 'done' || data.status === 'failed') {
      return data
    }

    await new Promise(resolve => setTimeout(resolve, interval))
  }
}
```

### 3. ファイルをインポートする

```typescript
interface ImportParams {
  fileID: string
  type: 1 | 2 // 1 = ドキュメント, 2 = スプレッドシート
  outputType: 1 | 2 // 1 = unit 文書, 2 = JSON
  minSheetRowCount?: number
  minSheetColumnCount?: number
}

async function importFile(params: ImportParams): Promise<string> {
  const res = await fetch(
    `${BASE_URL}/universer-api/exchange/${params.type}/import`,
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        // cookie: '_univer=XXXXXX',
      },
      body: JSON.stringify({
        fileID: params.fileID,
        outputType: params.outputType,
        minSheetRowCount: params.minSheetRowCount ?? 1000,
        minSheetColumnCount: params.minSheetColumnCount ?? 20,
      }),
    },
  )

  const data = await res.json()
  if (data.error?.code !== 1) {
    throw new Error(data.error?.message || 'インポートリクエストに失敗しました')
  }

  // タスクが完了または失敗するまでポーリング
  const taskResult = await pollTask(data.taskID)
  if (taskResult.status === 'failed') {
    throw new Error(taskResult.error?.message || 'インポートに失敗しました')
  }

  return params.outputType === 1
    ? taskResult.import!.unitID!
    : taskResult.import!.jsonID!
}
```

### 4. ファイルをエクスポートする

```typescript
interface ExportParams {
  unitID: string
  type: 1 | 2 // 1 = ドキュメント, 2 = スプレッドシート
  sscSwitch?: boolean
}

async function exportFile(params: ExportParams): Promise<string> {
  const res = await fetch(
    `${BASE_URL}/universer-api/exchange/${params.type}/export`,
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        // cookie: '_univer=XXXXXX',
      },
      body: JSON.stringify({
        unitID: params.unitID,
        type: params.type,
        sscSwitch: params.sscSwitch ?? false,
      }),
    },
  )

  const data = await res.json()
  if (data.error?.code !== 1) {
    throw new Error(data.error?.message || 'エクスポートリクエストに失敗しました')
  }

  const taskResult = await pollTask(data.taskID)
  if (taskResult.status === 'failed') {
    throw new Error(taskResult.error?.message || 'エクスポートに失敗しました')
  }

  // 署名付きダウンロード URL を取得
  const urlRes = await fetch(
    `${BASE_URL}/universer-api/file/${taskResult.export!.fileID!}/sign-url`,
    {
      headers: {
        // cookie: '_univer=XXXXXX',
      },
    },
  )
  const urlData = await urlRes.json()
  if (urlData.error?.code !== 1) {
    throw new Error(urlData.error?.message || 'ダウンロード URL の取得に失敗しました')
  }

  return urlData.url
}
```
