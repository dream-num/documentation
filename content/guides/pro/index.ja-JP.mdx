## 最短ルート

- まずサーバーを用意： [クイックスタート](/guides/pro/server)
- ライセンスと制限： [ライセンス](/guides/pro/license)
- フロントエンド統合：下の「クライアント統合」
- 本番構成と設定： [本番デプロイ](/guides/pro/deploy)
- ID 連携やイベント同期： [USIP 連携](/guides/pro/usip) と [イベント同期](/guides/pro/event-sync)

<Callout type="warning">
  Univer Pro の高度な機能にはサーバーが必要です。先にサーバーをデプロイしてください。
</Callout>

## ライセンスと制限

Univer Pro は [Univer 商用ライセンス](https://univer.ai/license) で提供されます。ライセンスなしでも評価は可能ですが、透かし・インポート容量・協調編集数などの制限があります。詳細は[価格](https://univer.ai/pricing)を参照してください。

## クライアント統合

すぐに動くスターターが必要な場合は Univer Pro 起動キットを利用できます：

<Tabs items={['npm', 'pnpm']}>
  <Tab>
    `nodejs >= 18`、`npm >= 8`、`git` が必要です。

    ```bash
    npx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    npm install
    npm run dev
    ```
  </Tab>
  <Tab>
    `nodejs >= 18`、`pnpm >= 7`、`git` が必要です。

    ```bash
    pnpm dlx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    pnpm install
    pnpm dev
    ```
  </Tab>
</Tabs>

<Callout>
  サーバーが別マシンの場合は `vite.config.ts` の `server` 設定で `localhost` をサーバーの IP/ドメインに変更してください。
</Callout>

問題なければ http://localhost:5173/ で Pro 機能と協調編集を体験できます。
