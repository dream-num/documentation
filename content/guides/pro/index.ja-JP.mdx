## サーバーのデプロイ

### 環境要件 [#evironment-requirements]

| 環境 | 要件 |
| ---- | ---- |
| オペレーティングシステム | Linux / Mac / Windows (WSL) |
| CPU | 最低 1 コア |
| メモリ | 最低 2GB（大きなファイルのインポート/エクスポートを行う場合は 4GB 以上推奨） |
| ディスク | 最低 10GB |
| Docker | バージョン 23 以上 |

### 互換性

- Linux: 推奨カーネルバージョンは 3.10.0 以上（低バージョンでは互換性問題が発生する場合があります）
- Docker: バージョン 23 以上
- Docker Compose: バージョン 2.21 以上
- データベース:
  - MySQL: バージョン 8.0 以上
  - PostgreSQL: バージョン 13 以上
  - Redis: バージョン 5.0 以上
  - PostgreSQL/MySQL 互換接続の国産 DB、および DM Database V8 に対応

### ワンクリックデプロイ

上記の要件を満たしたら、次のスクリプトで Docker Compose を使って Univer Pro サーバーをワンクリックでデプロイできます:

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

詳細なデプロイ方法や設定オプションは、[サーバーのデプロイ](/guides/pro/server) を参照してください。

## クライアント統合

Univer Pro のプリセットとプラグインの使い方は Univer と同じです。対応する機能セクションで利用方法を確認できます。

### クイックスタート

素早く始められるスキャフォールドが必要な場合は、[Univer Pro Start Kit](https://github.com/dream-num/univer-pro-sheet-start-kit) を用意しています。以下のコマンドで Univer Pro プロジェクトを作成できます:

<Tabs items={['npm', 'pnpm']}>
  <Tab>
    以下のコマンドには `nodejs >= 18`、`npm >= 8`、`git` が必要です。

    ```bash
    npx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    npm install
    npm run dev
    ```
  </Tab>
  <Tab>
    以下のコマンドには `nodejs >= 18`、`pnpm >= 7`、`git` が必要です。

    ```bash
    pnpm dlx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    pnpm install
    pnpm dev
    ```
  </Tab>
</Tabs>

<Callout>
  サーバーを別マシンにデプロイしている場合は、`vite.config.ts` の `server` 設定内の `localhost` を該当マシンの IP アドレスに変更してください。
</Callout>

🎉 すべて順調なら、サーバー統合済みの Univer Pro プロジェクトが作成されています。http://localhost:5173/ にアクセスして高度な機能と共同編集を体験してください。
