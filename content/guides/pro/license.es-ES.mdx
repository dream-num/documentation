Las capacidades avanzadas de Univer Pro requieren una licencia para desbloquear todos los beneficios. Esta página explica cómo obtener, configurar y verificar una licencia.

## Cuándo se requiere una licencia

- Evaluación: no se requiere licencia, pero las funciones son limitadas (marca de agua, tamaño de importación, cuota de colaboración)
- Producción: se recomienda comprar una licencia para acceso completo

Si aún no ha implementado el servidor, consulte [Inicio rápido](/guides/pro/server).

## Obtener una licencia

1. Visite [Página de licencia](/guides/pro/license) e inicie sesión
2. Descargue el archivo de licencia

![Descargar licencia](./license/new-02-cn.png)

### Licencia de prueba gratuita

Puede solicitar una licencia de prueba de 30 días:

1. Visite la [Página de licencia](/guides/pro/license) e inicie sesión
2. Haga clic “Obtener licencia de prueba”

![Obtener licencia](./license/new-01-cn.png)

## Agregar o actualizar una licencia

Descomprima `license-univer.zip` para obtener `license.txt` y `licenseKey.txt`. No los edites.

### Usar licencia en Cliente

#### Modo predeterminado

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsAdvancedPreset({
      license: `Content from license.txt`,
    }),
  ],
})
```

#### Modo complemento

Registra `UniverLicensePlugin` primero después de crear la instancia de Univer:

```typescript
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: `Content from license.txt`,
})
```

### Usar licencia en servidor

<Tabs items={['docker compose', 'K8s']}>
  <Tab>
    1. Copia `license.txt` y `licenseKey.txt` en `/univer-server/configs/`
    2. Ejecute `bash run.sh restart` en `univer-server`
  </Tab>
  <Tab>
    1. Instalar/actualizar a través de Helm:

    ```bash
    helm upgrade --install -n univer --create-namespace \
    --set global.istioNamespace="univer" \
    --set-file universer.license.licenseV2=$(YOUR_LICENSE_TXT_PATH) \
    --set-file universer.license.licenseKeyV2=$(YOUR_LICENSE_KEY_TXT_PATH) \
    univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
    ```
  </Tab>
</Tabs>

## Verificar licencia

### Verificación de interfaz

- La licencia faltante o no válida muestra marcas de agua y límites
- ¡La licencia válida elimina los límites

![Licencia no válida](./license/new-06.png)

![Licencia válida](./license/new-07.png)

### Verificación del servidor

Visite `host:8000/universer-api/license/key` para inspeccionar los derechos. Para local:

`http://localhost:8000/universer-api/license/key`

```json
{
  "verify": "true",
  "release_type": "COMMERCIAL"
}
```

![Verificación de licencia del servidor](./license/new-05.png)

## Preguntas frecuentes

1. Error de verificación: verifique la validez de la licencia, la integridad del archivo y el reinicio del servicio
2. La marca de agua aún está presente: verifique la inyección de licencia del lado del cliente
3. Otros problemas: comuníquese con el soporte técnico
