---
title: 停機升級 SOP
---

本頁提供停機升級參考流程，可依你的生產流程調整。

## Docker Compose 升級

### 升級前準備

- 確定目標版本並檢視[生產部署](/guides/pro/deploy)的設定變更
- 準備新的 `.env.custom`（保留舊版以便回滾）
- 準備授權檔案
- 通知使用者維護窗口

### 升級流程

<Steps>
  <Step>
    #### 禁寫與下線舊版

    建議先禁寫以避免資料不一致。

    編輯 `universer-old/nginx/universer.conf`，新增：

    ```nginx
    location ~ ^/universer-api {return 403;}
    ```

    重新載入 Nginx：

    ```bash
    docker exec univer-lb nginx -s reload
    ```

    等待至少 1 分鐘後停止舊服務：

    ```bash
    cd universer-old && bash run.sh stop
    ```
  </Step>
  <Step>
    #### 資料備份

    備份 RDS 中繼資料（物件儲存為新增為主，可視需求備份）。
  </Step>
  <Step>
    #### 部署新版本

    - 下載新版本（線上或離線）
    - 複製新的 `.env.custom`
    - 將授權檔案放入 `configs/`
    - 若使用自建 RDS，執行資料庫升級腳本

    若需僅讓測試帳號可存取，請在 `nginx/universer.conf` 中加入：

    ```nginx title="/nginx/universer.conf"
    underscores_in_headers on;
    if ($http_x_request_env != "test") {
      return 403;
    }
    ```

    啟動新版本：

    ```bash
    bash run.sh start
    ```
  </Step>
</Steps>

### 升級後驗證

- 測試帳號攜帶 `x-request-env=test` 驗證流程
- 觀察日誌與監控

### 切換上線

移除限制並重新載入 Nginx：

```bash
docker exec univer-lb nginx -s reload
```

### 回滾

- 停止新版本
- 還原舊版 Nginx 設定
- 啟動舊版本

## K8s 升級

### 升級前準備

- 準備新的 `values.yaml`（保留舊版）
- 準備授權檔案
- 通知使用者維護窗口

### 升級流程

<Steps>
  <Step>
    #### 禁止舊版存取

    在舊版設定中停用 ingress：

    ```yaml title="values.yaml"
    universer:
      ingress:
        enabled: false
    ```

    用舊版 chart 進行 upgrade：

    ```bash
    helm upgrade univer-stack \
      oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack \
      --version your-current-version \
      -n univer \
      -f values-1.0.0-forbid.yaml \
      --set-file universer.license.licenseV2=your-license.txt-path \
      --set-file universer.license.licenseKeyV2=your-licenseKey.txt-path
    ```

    透過 `helm list --all-namespaces --filter univer-stack` 取得目前版本。
  </Step>
  <Step>
    #### 資料備份

    備份 RDS 中繼資料。
  </Step>
  <Step>
    #### 升級到新版本

    若需限制測試帳號可存取，於新設定加入：

    ```yaml title="values.yaml"
    universer:
      ingress:
        enabled: true
        annotations:
          nginx.ingress.kubernetes.io/configuration-snippet: |
            if ($http_x_request_env != "test") {
              return 403;
            }
    ```

    執行升級：

    ```bash
    helm upgrade --install univer-stack \
      oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack \
      --version target-version \
      -n univer \
      -f your-values.yaml-path \
      --set-file universer.license.licenseV2=your-license.txt-path \
      --set-file universer.license.licenseKeyV2=your-licenseKey.txt-path
    ```

    離線場景請使用離線包並執行 `bash load-image.sh`。
  </Step>
</Steps>

### 升級後驗證與切換

- 測試帳號驗證
- 移除 ingress 限制並重新套用

### 回滾

使用舊版 chart 與舊設定：

```bash
helm upgrade --install univer-stack \
  oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack \
  --version old-version \
  -n univer \
  -f old-values.yaml \
  --set-file universer.license.licenseV2=your-license.txt-path \
  --set-file universer.license.licenseKeyV2=your-licenseKey.txt-path
```
