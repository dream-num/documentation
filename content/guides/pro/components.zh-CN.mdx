---
title: 内置组件配置
---

本页仅适用于使用 Univer 内置基础组件的场景（PostgreSQL、RabbitMQ、MinIO）。这些账号密码只在首次初始化时生效，服务安装完成后需按组件官方方式修改。

## 修改默认密码

<Callout>
  请在首次部署前完成配置。已部署的实例不会因为修改配置而变更已初始化的密码。
</Callout>

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    在安装目录下新建 `.env.custom`，然后执行：

    ```bash
    bash run.sh
    ```
  </Tab>
  <Tab label="K8s">
    新建 `values.yaml` 后执行：

    ```shell
    helm install -n univer --create-namespace \
      --set global.istioNamespace="univer" \
      --values values.yaml \
      univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
    kubectl rollout restart -n univer deployment/collaboration-server
    kubectl rollout restart -n univer deployment/universer
    ```
  </Tab>
</Tabs>

### PostgreSQL

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    DATABASE_USERNAME=postgres
    DATABASE_PASSWORD=postgres
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    global:
      postgresql:
        auth:
          postgresPassword: postgres

    universer:
      config:
        database:
          username: postgres
          password: postgres

    temporal:
      server:
        config:
          persistence:
            default:
              sql:
                user: postgres
                password: postgres

            visibility:
              sql:
                user: postgres
                password: postgres
    ```
  </Tab>
</Tabs>

说明：

- 仅对首次初始化有效，已部署实例不会自动变更密码。
- K8s 场景下仅可设置 admin 密码，默认账号为 `postgres`。
- `universer` 与 `temporal` 的数据库账号需与 PostgreSQL 配置保持一致。

### RabbitMQ

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    RABBITMQ_USERNAME=guest
    RABBITMQ_PASSWORD=guest
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    rabbitmq:
      auth:
        username: guest
        password: guest

    universer:
      config:
        rabbitmq:
          username: guest
          password: guest
    ```
  </Tab>
</Tabs>

说明：

- 默认账号为 `guest`，生产环境建议修改。
- 修改 RabbitMQ 账号后，请同步更新 `universer` 中的配置。

### S3 (MinIO)

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    S3_USER=minio
    S3_PASSWORD=minio123456
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    minio:
      auth:
        rootUser: admin
        rootPassword: minioadmin

    universer:
      config:
        s3:
          accessKeyID: admin
          accessKeySecret: minioadmin
    ```
  </Tab>
</Tabs>

说明：

- `rootUser/rootPassword` 为 MinIO 管理员账号。
- `accessKeyID/accessKeySecret` 需与 MinIO 账号保持一致。
