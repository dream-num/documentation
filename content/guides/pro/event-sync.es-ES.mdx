---
title: Event Sync
---

Event Sync publica eventos del motor de colaboración en su sistema para que pueda reaccionar (auditoría, notificaciones, indexación, etc.).

![Event Sync](./event-sync/event-sync.png)

## Casos de uso

- Auditoría/reproducción de cambios de colaboración
- Sincronización de cambios en canalizaciones de búsqueda/indexación
- Notificaciones externas y alertas

Eventos admitidos:

- Ediciones de colaboración: conjunto de cambios persistentes

## Habilitar sincronización de eventos

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
Agregar a `.env.custom`:

    ```properties title=".env.custom"
    EVENT_SYNC=true
    ```
  </Tab>
  <Tab label="K8s">
Agregar a `values.yaml`:

    ```yaml title="values.yaml"
    universer:
      config:
        rabbitmq:
          eventSync: true
    ```
  </Tab>
</Tabs>

## Evento Esquema

```go
message EventSyncData {
  string eventId = 1;
  string eventType = 2; // type of event, now support changeset
  int32 createdAt = 3;
  oneof event {
    univer.ChangesetAck csAckEvent = 4;
    // more event types in the future.
  }
  optional string unitMetaData = 99; // Introduced since v0.20.0, customer setted metadata of the unit(created by CreateUnit request or Import request)
}

message ChangesetAck {
  univer.Changeset cs = 1;
}

message Changeset {
  string unitID = 1; // unitID of the Univer document
  univer.constants.UniverType type = 2;
  int32 baseRev = 3;
  int32 revision = 4;
  string userID = 5;
  repeated Mutation mutations = 6;
  string memberID = 7;
}

message Mutation {
  string id = 1; // ID of the mutation
  string data = 2; // serialized params
}
```
