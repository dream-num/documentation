## С чего начать

- Разверните сервер для тестирования или локальной разработки: [Быстрый старт](/guides/pro/server)
- Ознакомьтесь с лицензированием и ограничениями: [Лицензия](/guides/pro/license)
- Интегрируйте Univer SDK Pro во фронтенд-проект: см. раздел «Интеграция с клиентом» ниже
- Изучите архитектуру и конфигурацию для рабочей среды: [Развертывание в рабочей среде](/guides/pro/deploy)
- Настройте интеграцию с системой идентификации или синхронизацию событий: [Интеграция с USIP](/guides/pro/usip) и [Синхронизация событий](/guides/pro/event-sync)

<Callout type="warning">
  Для расширенных возможностей Univer SDK Pro необходим сервер. Сначала разверните его.
</Callout>

## Лицензия и ограничения

Univer SDK Pro распространяется по [коммерческой лицензии Univer](/guides/pro/license). Продукт можно оценить без лицензии, однако при этом действуют ограничения, в том числе водяной знак, лимит на размер импортируемых файлов и квоты на совместную работу. Подробнее см. на странице [Тарифы](/guides/pro).

## Интеграция с клиентом

Если вам нужен готовый к запуску начальный проект, используйте стартовый комплект Univer SDK Pro:

<Tabs items={['npm', 'pnpm']}>
  <Tab>
    Необходимы `nodejs >= 18`, `npm >= 8` и `git`.

    ```bash
    npx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    npm install
    npm run dev
    ```
  </Tab>
  <Tab>
    Необходимы `nodejs >= 18`, `pnpm >= 7` и `git`.

    ```bash
    pnpm dlx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    pnpm install
    pnpm dev
    ```
  </Tab>
</Tabs>

<Callout>
  Если сервер работает на другом компьютере, обновите `vite.config.ts`, заменив `localhost` на IP-адрес или домен сервера.
</Callout>

Если все работает, перейдите по адресу http://localhost:5173/ и попробуйте функции Pro и совместную работу.
