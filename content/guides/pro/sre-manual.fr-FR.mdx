Cette page présente les principaux points d’accès pour l’observabilité et l’exploitation des services Univer, notamment les métriques, les journaux et les diagnostics courants.

## Observabilité

Univer fournit :

- Des métriques Prometheus
- Des journaux de service (stdout + volumes persistants)

Si vous activez la pile d’observabilité intégrée, vous pouvez consulter les tableaux de bord dans Grafana. Sinon, exportez-les vers votre propre système.

## Métriques

Les tableaux de bord Grafana intégrés couvrent les éléments suivants :

- Infrastructure : RabbitMQ, Redis, RDS
- Collaboration : collaboration-server
- Service principal : universer
- Importation et exportation : exchange

Vous pouvez utiliser ces tableaux de bord pour surveiller les performances, la disponibilité et les indicateurs clés de l’activité. Pour les systèmes externes, téléchargez les tableaux de bord ici :

https://release-univer.oss-cn-shenzhen.aliyuncs.com/release/univer-grafana-dashboards.tar.gz

## Journaux des services

### Docker Compose

Les journaux sont écrits dans stdout et dans des volumes persistants. Ils sont conservés pendant 30 jours au maximum ou jusqu’à ce qu’ils atteignent 1 Go.

- universer : `/logs/universer/`
- exchange : `/logs/worker-exchange/`

### K8s / Loki

Avec l’observabilité intégrée, vous pouvez interroger les journaux avec Loki dans Grafana -> Explore :

![Recherche dans Loki](./sre-manual/loki-search.png)

## Diagnostics courants

1. **Fonctionnalité indisponible** : vérifiez les SLI de RDS, MQ et Redis
2. **Erreurs d’API** : examinez les SLI d’universer et les codes d’erreur
3. **Recherche dans les journaux** : recherchez `biz_code=xxx` dans Loki
4. **Problèmes de capacité** : surveillez le QPS, la latence, le processeur et la mémoire
