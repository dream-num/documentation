Univer SDK Pro の高度機能はライセンスで解放されます。本ページでは取得・設定・検証方法を説明します。

## ライセンスが必要なケース

- 評価：ライセンスなしで利用可能だが制限あり（透かし、インポート容量、協調人数など）
- 本番：フル機能のためにライセンス購入を推奨

サーバー未導入の場合は[クイックスタート](/guides/pro/server)を参照してください。

## ライセンスの取得

1. [ライセンスページ](/guides/pro/license)にアクセスしてログイン
2. ライセンスファイルをダウンロード

![ライセンスのダウンロード](./license/new-02-cn.png)

### 無料トライアル

30 日のトライアルライセンスを申請できます：

1. [ライセンスページ](/guides/pro/license)にアクセスしてログイン
2. 「トライアルライセンスを取得」をクリック

![トライアル取得](./license/new-01-cn.png)

## ライセンスの追加/更新

`license-univer.zip` を解凍して `license.txt` と `licenseKey.txt` を取得します。内容は編集しないでください。

### クライアントで使用

#### プリセットモード

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsAdvancedPreset({
      license: `license.txt の内容`,
    }),
  ],
})
```

#### プラグインモード

`UniverLicensePlugin` はインスタンス作成後に最初に登録してください。

```typescript
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: `license.txt の内容`,
})
```

### サーバーで使用

<Tabs items={['docker compose', 'K8s']}>
  <Tab>
    1. `license.txt` と `licenseKey.txt` を `/univer-server/configs/` にコピー
    2. `univer-server` で `bash run.sh restart`
  </Tab>
  <Tab>
    1. Helm でインストール/アップグレード：

    ```bash
    helm upgrade --install -n univer --create-namespace \
    --set global.istioNamespace="univer" \
    --set-file universer.license.licenseV2=$(YOUR_LICENSE_TXT_PATH) \
    --set-file universer.license.licenseKeyV2=$(YOUR_LICENSE_KEY_TXT_PATH) \
    univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
    ```
  </Tab>
</Tabs>

## ライセンスの検証

### フロントエンド

- ライセンス未入力または無効な場合は透かしと制限が出ます
- 有効なライセンスで制限が解除されます

![ライセンス無効](./license/new-06.png)

![ライセンス有効](./license/new-07.png)

### サーバー

`host:8000/universer-api/license/key` で権益情報を確認できます。ローカル例：

`http://localhost:8000/universer-api/license/key`

```json
{
  "verify": "true",
  "release_type": "COMMERCIAL"
}
```

![サーバー検証](./license/new-05.png)

## FAQ

1. 検証失敗：ライセンス有効期限/ファイル改ざん/再起動を確認
2. 透かしが残る：フロントに `license.txt` を注入したか確認
3. その他：サポートへ連絡
