---
title: 서비스 중단 업그레이드 표준 운영 절차
---

이 페이지에서는 서비스 중단 업그레이드를 위한 표준 운영 절차를 안내합니다. 필요한 경우 프로덕션 환경의 운영 표준에 맞게 조정하세요.

## Docker Compose 업그레이드

### 준비

- 대상 버전을 선택하고 [프로덕션 배포](/guides/pro/deploy)에서 설정 변경 사항 확인
- 새 `.env.custom` 준비(롤백을 위해 기존 파일 유지)
- 라이선스 파일 준비
- 사용자에게 유지 보수 시간 안내

### 업그레이드 단계

<Steps>
  <Step>
    #### 쓰기 차단 및 이전 버전 중지

    데이터 불일치를 방지하려면 새 요청을 차단합니다.

    `universer-old/nginx/universer.conf`를 편집하고 다음을 추가합니다.

    ```nginx
    location ~ ^/universer-api {return 403;}
    ```

    Nginx를 다시 로드합니다.

    ```bash
    docker exec univer-lb nginx -s reload
    ```

    1분 이상 기다린 후 이전 서비스를 중지합니다.

    ```bash
    cd universer-old && bash run.sh stop
    ```
  </Step>
  <Step>
    #### 데이터 백업

    RDS 메타데이터를 백업합니다. 객체 스토리지는 추가 전용이므로 필요한 경우에만 백업합니다.
  </Step>
  <Step>
    #### 새 버전 배포

    - 대상 버전 다운로드(온라인 또는 오프라인)
    - 새 `.env.custom` 복사
    - 라이선스 파일을 `configs/` 아래에 배치
    - 자체 관리형 RDS를 사용하는 경우 DB 업그레이드 스크립트 실행

    테스트 계정만 허용하려면 `nginx/universer.conf`에 다음을 추가합니다.

    ```nginx title="/nginx/universer.conf"
    underscores_in_headers on;
    if ($http_x_request_env != "test") {
      return 403;
    }
    ```

    새 버전을 시작합니다.

    ```bash
    bash run.sh start
    ```
  </Step>
</Steps>

### 업그레이드 후 검증

- `x-request-env=test`로 주요 흐름 확인
- 로그와 메트릭 모니터링

### 전환

헤더 제한을 제거하고 Nginx를 다시 로드합니다.

```bash
docker exec univer-lb nginx -s reload
```

### 롤백

- 새 버전 중지
- 이전 Nginx 설정 복원
- 이전 버전 시작

## K8s 업그레이드

### 준비

- 새 `values.yaml` 준비(기존 파일 유지)
- 라이선스 파일 준비
- 사용자에게 유지 보수 시간 안내

### 업그레이드 단계

<Steps>
  <Step>
    #### 이전 버전에 대한 접근 차단

    이전 설정에서 ingress를 비활성화합니다.

    ```yaml title="values.yaml"
    universer:
      ingress:
        enabled: false
    ```

    현재 차트 버전으로 적용합니다.

    ```bash
    helm upgrade univer-stack \
      oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack \
      --version your-current-version \
      -n univer \
      -f values-1.0.0-forbid.yaml \
      --set-file universer.license.licenseV2=your-license.txt-path \
      --set-file universer.license.licenseKeyV2=your-licenseKey.txt-path
    ```

    `helm list --all-namespaces --filter univer-stack`으로 현재 차트 버전을 확인합니다.
  </Step>
  <Step>
    #### 데이터 백업

    RDS 메타데이터를 백업합니다.
  </Step>
  <Step>
    #### 새 버전으로 업그레이드

    테스트 사용자만 허용하려면 새 설정에 다음을 추가합니다.

    ```yaml title="values.yaml"
    universer:
      ingress:
        enabled: true
        annotations:
          nginx.ingress.kubernetes.io/configuration-snippet: |
            if ($http_x_request_env != "test") {
              return 403;
            }
    ```

    업그레이드합니다.

    ```bash
    helm upgrade --install univer-stack \
      oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack \
      --version target-version \
      -n univer \
      -f your-values.yaml-path \
      --set-file universer.license.licenseV2=your-license.txt-path \
      --set-file universer.license.licenseKeyV2=your-licenseKey.txt-path
    ```

    오프라인 환경에서는 오프라인 번들을 사용하고 `bash load-image.sh`를 실행합니다.
  </Step>
</Steps>

### 업그레이드 후 검증 및 전환

- 테스트 계정으로 검증
- ingress 제한을 제거하고 다시 적용

### 롤백

이전 차트 버전과 설정을 사용합니다.

```bash
helm upgrade --install univer-stack \
  oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack \
  --version old-version \
  -n univer \
  -f old-values.yaml \
  --set-file universer.license.licenseV2=your-license.txt-path \
  --set-file universer.license.licenseKeyV2=your-licenseKey.txt-path
```
