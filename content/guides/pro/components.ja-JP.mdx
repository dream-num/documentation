---
title: 内蔵コンポーネント設定
---

本ページは内蔵コンポーネント（PostgreSQL、RabbitMQ、MinIO）を利用する場合のみ対象です。初期化時のみ有効で、既存環境には反映されません。

## デフォルトパスワードの変更

<Callout>
  初回デプロイ前に設定してください。既存環境は自動更新されません。
</Callout>

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    インストールディレクトリに `.env.custom` を作成し実行：

    ```bash
    bash run.sh
    ```
  </Tab>
  <Tab label="K8s">
    `values.yaml` を作成して実行：

    ```shell
    helm install -n univer --create-namespace \
      --set global.istioNamespace="univer" \
      --values values.yaml \
      univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
    kubectl rollout restart -n univer deployment/collaboration-server
    kubectl rollout restart -n univer deployment/universer
    ```
  </Tab>
</Tabs>

### PostgreSQL

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    DATABASE_USERNAME=postgres
    DATABASE_PASSWORD=postgres
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    global:
      postgresql:
        auth:
          postgresPassword: postgres

    universer:
      config:
        database:
          username: postgres
          password: postgres

    temporal:
      server:
        config:
          persistence:
            default:
              sql:
                user: postgres
                password: postgres

            visibility:
              sql:
                user: postgres
                password: postgres
    ```
  </Tab>
</Tabs>

補足：

- 初期化時のみ有効です。
- K8s は admin パスワードのみ設定可能で、既定ユーザーは `postgres`。
- `universer` と `temporal` は同一の DB 資格情報を使います。

### RabbitMQ

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    RABBITMQ_USERNAME=guest
    RABBITMQ_PASSWORD=guest
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    rabbitmq:
      auth:
        username: guest
        password: guest

    universer:
      config:
        rabbitmq:
          username: guest
          password: guest
    ```
  </Tab>
</Tabs>

補足：

- 既定ユーザーは `guest`。本番では変更推奨。
- RabbitMQ の変更後は `universer` 側も更新してください。

### S3 (MinIO)

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    S3_USER=minio
    S3_PASSWORD=minio123456
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    minio:
      auth:
        rootUser: admin
        rootPassword: minioadmin

    universer:
      config:
        s3:
          accessKeyID: admin
          accessKeySecret: minioadmin
    ```
  </Tab>
</Tabs>

補足：

- `rootUser/rootPassword` は MinIO 管理者アカウント。
- `accessKeyID/accessKeySecret` は MinIO の資格情報と一致させます。
