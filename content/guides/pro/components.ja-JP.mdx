## 初期パスワードの設定

初期パスワードは初回インストール時のみ有効です。インストールが成功した後は、以下の手順では変更できません。各コンポーネントの公式ガイドに従って変更してください。

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    `.env.custom` ファイルを追加した後、次のコマンドでサービスをインストールします。

    ```bash
    bash run.sh
    ```
  </Tab>
  <Tab label="K8s">
    `values.yaml` ファイルを作成した後、次のコマンドでサービスをインストールします。

    ```shell title="values.yaml"
    helm install -n univer --create-namespace \
      --set global.istioNamespace="univer" \
      --values values.yaml \
      univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
    kubectl rollout restart -n univer deployment/collaboration-server
    kubectl rollout restart -n univer deployment/universer
    ```
  </Tab>
</Tabs>

### PostgreSQL

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    .env.custom に記述します。

    ```properties title=".env.custom"
    DATABASE_USERNAME=postgres
    DATABASE_PASSWORD=postgres
    ```
  </Tab>
  <Tab label="K8s">
    変更できるのは管理者パスワードのみです。既定の管理者ユーザー名は `postgres` です。values.yaml に記述します。

    ```yaml title="values.yaml"
    global:
      postgresql:
        auth:
          postgresPassword: postgres

    universer:
      config:
        database:
          username: postgres
          password: postgres

    temporal:
      server:
        config:
          persistence:
            default:
              sql:
                user: postgres
                password: postgres

            visibility:
              sql:
                user: postgres
                password: postgres
    ```
  </Tab>
</Tabs>

### RabbitMQ

    RABBITMQ_PASSWORD=guest

  <Tab label="K8s">

    ```yaml title="values.yaml"
    rabbitmq:
      auth:
        username: guest
        password: guest

    universer:
      config:
        rabbitmq:
          username: guest
          password: guest
    ```
  </Tab>
</Tabs>

### S3

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    .env.custom に記述します。

    ```properties title=".env.custom"
    S3_USER=minio
    S3_PASSWORD=minio123456
    ```
  </Tab>
  <Tab label="K8s">
    values.yaml に記述します。

    ```yaml title="values.yaml"
    minio:
      auth:
        rootUser: admin
        rootPassword: minioadmin

    universer:
      config:
        s3:
          accessKeyID: admin
          accessKeySecret: minioadmin
    ```
  </Tab>
</Tabs>
