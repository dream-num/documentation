Für die erweiterten Funktionen von Univer Pro ist der Server erforderlich. Bitte stellen Sie zuerst den Server bereit.
</Callout>

## Lizenz und Einschränkungen

Univer Pro wird unter der [kommerziellen Univer-Lizenz](/guides/pro/license) veröffentlicht. Sie können es ohne Lizenz zur Evaluierung verwenden, es gelten jedoch Einschränkungen wie Wasserzeichen, Importgröße und Kontingente für die Zusammenarbeit. Einzelheiten finden Sie unter [Preise](/guides/pro).

## Client-Integration

Wenn Sie einen betriebsbereiten Starter benötigen, verwenden Sie das Univer Pro-Starterkit:

<Tabs items={['npm', 'pnpm']}>
  <Tab>
Erfordert `nodejs >= 18`, `npm >= 8` und `git`.

    ```bash
    npx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    npm install
    npm run dev
    ```
  </Tab>
  <Tab>
Erfordert `nodejs >= 18`, `pnpm >= 7` und `git`.

    ```bash
    pnpm dlx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    pnpm install
    pnpm dev
    ```
  </Tab>
</Tabs>

<Callout>
Wenn der Server auf einem anderen Computer ausgeführt wird, aktualisieren Sie `vite.config.ts` und ersetzen Sie `localhost` durch die Server-IP oder Domäne.
</Callout>

Wenn alles funktioniert, besuchen Sie http://localhost:5173/, um Pro-Funktionen und Zusammenarbeit auszuprobieren.
