## Bien démarrer

- Déployer le serveur pour un environnement de test ou local : [Démarrage rapide](/guides/pro/server)
- Découvrir la licence et ses limites : [Licence](/guides/pro/license)
- Intégrer Univer SDK Pro à votre projet frontend : voir « Intégration côté client » ci-dessous
- Consulter l’architecture et la configuration pour la production : [Déploiement en production](/guides/pro/deploy)
- Intégrer la gestion des identités ou synchroniser des événements : [Intégration USIP](/guides/pro/usip) et [Synchronisation des événements](/guides/pro/event-sync)

<Callout type="warning">
  Les fonctionnalités avancées d’Univer SDK Pro nécessitent le serveur. Commencez par le déployer.
</Callout>

## Licence et limites

Univer SDK Pro est distribué sous la [licence commerciale Univer](/guides/pro/license). Vous pouvez l’utiliser sans licence à des fins d’évaluation, mais certaines limites s’appliquent, notamment en matière de filigrane, de taille des importations et de quotas de collaboration. Consultez la page [Tarifs](/guides/pro) pour en savoir plus.

## Intégration côté client

Pour disposer d’un projet de démarrage prêt à l’emploi, utilisez le kit de démarrage Univer SDK Pro :

<Tabs items={['npm', 'pnpm']}>
  <Tab>
    Nécessite `nodejs >= 18`, `npm >= 8` et `git`.

    ```bash
    npx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    npm install
    npm run dev
    ```
  </Tab>
  <Tab>
    Nécessite `nodejs >= 18`, `pnpm >= 7` et `git`.

    ```bash
    pnpm dlx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    pnpm install
    pnpm dev
    ```
  </Tab>
</Tabs>

<Callout>
  Si le serveur s’exécute sur une autre machine, modifiez `vite.config.ts` et remplacez `localhost` par l’adresse IP ou le domaine du serveur.
</Callout>

Si tout fonctionne correctement, ouvrez http://localhost:5173/ pour essayer les fonctionnalités Pro et la collaboration.
