title: API
---

이 페이지에서는 자주 사용하는 Univer Server API를 소개합니다. 기본 Base URL은 `http://localhost:8000`입니다.

> 참고: `type` 매개변수 값은 Docs의 경우 `1`, Sheets의 경우 `2`입니다.

## 문서 관리

### 문서 생성

<APITable
  request={{
    method: 'POST',
    url: '/universer-api/snapshot/{type}/unit/-/create',
    headers: <code>content-type: application/json</code>,
    parametersType: 'Body',

      name: 'type',

      type: 'string',
      required: true,
      description: '문서 이름',
    }, {
      name: 'creator',
      type: 'string',
      required: true,
      description: '생성자 ID',
    }, {
      name: 'idempotencyKey',
      type: 'string',
      required: false,
      description: 'v0.20.0부터 지원하는 선택적 멱등성 키이며, 전체 바이트 크기는 64 이하여야 합니다.',
    }, {
      name: 'metaData',
      type: 'string',
      required: false,
      description: 'v0.20.0부터 지원합니다. 생성된 유닛에 연결되는 사용자 정의 정보로, 이후 동기화 이벤트와 USIP 호출에 그대로 전달됩니다. 전체 바이트 크기는 1024 이하여야 합니다.',
    }],
    example: `curl http://localhost:8000/universer-api/snapshot/{type}/unit/-/create \\

    -H 'Content-Type: application/json' \\

  }}

## 파일 및 가져오기/내보내기

### 파일 업로드 [#upload-file]

<APITable
  request={{
    method: 'POST',
    url: '/universer-api/stream/file/upload',
    headers: <code>content-type: multipart/form-data</code>,
    parametersType: 'Body',
    parameters: [{
      name: 'size',
      type: 'int',
      required: true,
      description: '바이트 단위의 파일 크기(쿼리 매개변수). 실제 크기와 일치해야 합니다.',
    }, {
      name: 'file',
      type: 'Form.file',
      required: true,
      description: 'HTML 폼의 파일',
    }],
    example: `curl 'http://localhost:8000/universer-api/stream/file/upload?size=125466' \\
    --header 'cookie: _univer=XXXXXX' \\
    --form 'file=@"demo.xlsx"'`,
  }}
  response={{
    type: 'application/json',
    parameters: [{
      name: 'FileId',
      type: 'string',
      description: '가져오기/내보내기에 사용할 파일 ID',
    }],
    example: JSON.stringify({
      FileId: 'xxxx',
    }, null, 2),
  }}
/>
