title: API
---

Esta página enumera las API comunes de Univer Server. La URL base predeterminada es `http://localhost:8000`.

> Nota: valores del parámetro `type`: `1` para Documentos, `2` para Hojas de cálculo.

## Gestión de documentos

### Crear documento

<APITable
  request={{
    method: 'POST',
    url: '/universer-api/snapshot/{type}/unit/-/create',
    headers: <code>content-type: application/json</code>,
    parametersType: 'Body',
    parameters: [
      {
        name: 'type',
        type: 'enum(int)',
        required: true,
        description: '1 (docs), 2 (hojas) para ruta y cuerpo',
      },
      {
        name: 'name',
        type: 'string',
        required: true,
        description: 'Nombre del documento',
      },
      {
        name: 'creator',
        type: 'string',
        required: true,
        description: 'Id. del creador',
      },
      {
        name: 'idempotencyKey',
        type: 'string',
        required: false,
        description:
          'Introducido desde v0.20.0. Clave de idempotencia opcional; El tamaño total de bytes debe ser ≤ 64.',
      },
      {
        name: 'metaData',
        type: 'string',
        required: false,
        description:
          'Introducido desde v0.20.0. La información definida por el usuario, vinculada a la unidad creada, se transmitirá de forma transparente en eventos de sincronización y llamadas USIP posteriores. El tamaño total de bytes debe ser ≤ 1024.',
      },
    ],
    example: `curl http://localhost:8000/universer-api/snapshot/{type}/unit/-/create \
-X POST \
-H 'Content-Type: application/json' \
--data-raw '{"type":2,"name":"Nueva hoja por Univer","creator":"userID","idempotencyKey":"a-idgenerator-unique-id","metaData":"tenant12345"}'`,
  }}
  response={{
    type: 'application/json',
    parameters: [
      {
        name: 'error',
        type: 'object',
        properties: [
          {
            name: 'code',
            type: 'enum(int)',
            description: '1 (éxito)',
          },
          {
            name: 'message',
            type: 'string',
            description: 'Mensaje de error',
          },
        ],
      },
      {
        name: 'unitID',
        type: 'string',
        description: 'Document id',
      },
    ],
    example: JSON.stringify(
      {
        error: {
          code: 1,
          message: 'éxito',
        },
        unitID: 'ETVf-B4lQqOSE_p09mcp9Q',
      },
      null,
      2,
    ),
  }}
/>

### Listar documentos

<APITable
  request={{
    method: 'GET',
    url: '/universer-api/snapshot/{type}/units',
    parametersType: 'Query',
    parameters: [
      {
        name: 'type',
        type: 'enum(int)',
        required: true,
        description: '1 (doc), 2 (sheet) for path and body',
      },
      {
        name: 'nextCursor',
        type: 'string',
        required: false,
        description: 'Next page cursor',
      },
    ],
    example: `curl -X GET 'http://localhost:8000/universer-api/snapshot/1/units?nextCursor=100'`,
  }}
  response={{
    type: 'application/json',
    parameters: [
      {
        name: 'error',
        type: 'object',
        properties: [
          {
            name: 'code',
            type: 'enum(int)',
            description: '1 (success)',
          },
          {
            name: 'message',
            type: 'string',
            description: 'Error message',
          },
        ],
      },
      {
        name: 'units',
        type: 'array[object]',
        description: 'Document list',
        properties: [
          {
            name: 'unitID',
            type: 'string',
            description: 'Document id',
          },
          {
            name: 'name',
            type: 'string',
            description: 'Document name',
          },
          {
            name: 'type',
            type: 'enum(int)',
            description: '1 (doc), 2 (sheet)',
          },
        ],
      },
      {
        name: 'nextCursor',
        type: 'string',
        description: 'Next page cursor; empty means last page',
      },
    ],
    example: JSON.stringify(
      {
        error: {
          code: 1,
          message: '',
        },
        units: [
          {
            unitID: '1',
            name: 'a',
            type: 1,
          },
        ],
        nextCursor: '200',
      },
      null,
      2,
    ),
  }}
/>

## e importar/exportar

### Subir archivo [#upload-file]

<APITable
  request={{
    method: 'POST',
    url: '/universer-api/stream/file/upload',
    headers: <code>content-type: multipart/form-data</code>,
    parametersType: 'Body',
    parameters: [
      {
        name: 'size',
        type: 'int',
        required: true,
        description: 'Tamaño de archivo en bytes (parámetro de consulta). Debe coincidir con el tamaño real.',
      },
      {
        name: 'file',
        type: 'Form.file',
        required: true,
        description: 'Archivo en formato HTML',
      },
    ],
    example: `curl 'http://localhost:8000/universer-api/stream/file/upload?size=125466' \
--header 'cookie: _univer=XXXXXX' \
--form 'file=@"demo.xlsx"'`,
  }}
  response={{
    type: 'application/json',
    parameters: [
      {
        name: 'FileId',
        type: 'string',
        description: 'Id. de archivo para importación/exportación',
      },
    ],
    example: JSON.stringify(
      {
        FileId: 'xxxx',
      },
      null,
      2,
    ),
  }}
/>
