---
title: 停止メンテナンスのアップグレード SOP
---

本ページは停止前提のアップグレード手順です。自社 SOP に合わせて調整してください。

## Docker Compose

### 事前準備

- 目標バージョンと設定変更を[本番デプロイ](/guides/pro/deploy)で確認
- 新しい `.env.custom` を用意（旧版はロールバック用に保持）
- ライセンスファイルを用意
- メンテナンス通知

### 手順

<Steps>
  <Step>
    #### 書き込み停止と旧版停止

    先に書き込みを止めてデータ不整合を防止します。

    `universer-old/nginx/universer.conf` に追加：

    ```nginx
    location ~ ^/universer-api {return 403;}
    ```

    Nginx を再読み込み：

    ```bash
    docker exec univer-lb nginx -s reload
    ```

    1 分ほど待ってから旧版停止：

    ```bash
    cd universer-old && bash run.sh stop
    ```
  </Step>
  <Step>
    #### データバックアップ

    RDS メタデータをバックアップ（Object Storage は必要に応じて）。
  </Step>
  <Step>
    #### 新版デプロイ

    - 新版を取得（オンライン/オフライン）
    - 新しい `.env.custom` を配置
    - `configs/` にライセンスを配置
    - 自前 RDS の場合は DB 更新スクリプトを実行

    テストユーザーのみ許可する場合：

    ```nginx title="/nginx/universer.conf"
    underscores_in_headers on;
    if ($http_x_request_env != "test") {
      return 403;
    }
    ```

    起動：

    ```bash
    bash run.sh start
    ```
  </Step>
</Steps>

### 検証

- `x-request-env=test` で検証
- ログ/監視の確認

### 切替

制限を削除して Nginx 再読み込み：

```bash
docker exec univer-lb nginx -s reload
```

### ロールバック

- 新版停止
- 旧版 Nginx 設定復元
- 旧版再起動

## K8s

### 事前準備

- 新しい `values.yaml` を用意（旧版保持）
- ライセンスファイル
- メンテナンス通知

### 手順

<Steps>
  <Step>
    #### 旧版アクセス停止

    旧版設定で ingress を無効化：

    ```yaml title="values.yaml"
    universer:
      ingress:
        enabled: false
    ```

    旧版 chart で upgrade：

    ```bash
    helm upgrade univer-stack \
      oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack \
      --version your-current-version \
      -n univer \
      -f values-1.0.0-forbid.yaml \
      --set-file universer.license.licenseV2=your-license.txt-path \
      --set-file universer.license.licenseKeyV2=your-licenseKey.txt-path
    ```

    `helm list --all-namespaces --filter univer-stack` で現行バージョン確認。
  </Step>
  <Step>
    #### データバックアップ

    RDS メタデータをバックアップ。
  </Step>
  <Step>
    #### 新版へアップグレード

    テストユーザーのみ許可：

    ```yaml title="values.yaml"
    universer:
      ingress:
        enabled: true
        annotations:
          nginx.ingress.kubernetes.io/configuration-snippet: |
            if ($http_x_request_env != "test") {
              return 403;
            }
    ```

    アップグレード：

    ```bash
    helm upgrade --install univer-stack \
      oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack \
      --version target-version \
      -n univer \
      -f your-values.yaml-path \
      --set-file universer.license.licenseV2=your-license.txt-path \
      --set-file universer.license.licenseKeyV2=your-licenseKey.txt-path
    ```

    オフライン環境は `bash load-image.sh` を使用。
  </Step>
</Steps>

### 検証と切替

- テストアカウントで検証
- ingress 制限を削除して再適用

### ロールバック

```bash
helm upgrade --install univer-stack \
  oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack \
  --version old-version \
  -n univer \
  -f old-values.yaml \
  --set-file universer.license.licenseV2=your-license.txt-path \
  --set-file universer.license.licenseKeyV2=your-licenseKey.txt-path
```
