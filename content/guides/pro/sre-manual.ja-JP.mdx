本ページは可観測性と運用の入口（メトリクス/ログ/基本診断）をまとめています。

## 可観測性

Univer が提供するもの：

- Prometheus メトリクス
- サービスログ（stdout + 永続ボリューム）

内蔵の可観測スタックを有効化すれば Grafana で確認できます。

## Metrics

内蔵 Grafana ダッシュボードの対象：

- 基盤：RabbitMQ、Redis、RDS
- 協調：collaboration-server
- 中核：universer
- インポート/エクスポート：exchange

外部システムで利用する場合は以下からダッシュボードを取得できます：

https://release-univer.oss-cn-shenzhen.aliyuncs.com/release/univer-grafana-dashboards.tar.gz

## ログ

### Docker Compose

stdout とボリュームに出力（最大 30 日または 1GB）。

- universer：`/logs/universer/`
- exchange：`/logs/worker-exchange/`

### K8s / Loki

Grafana -> Explore で Loki を使用：

![Loki](./sre-manual/loki-search.png)

## 基本診断

1. **機能停止**：RDS/MQ/Redis の SLI を確認
2. **API エラー**：universer の SLI とエラーコード
3. **ログ検索**：`biz_code=xxx`
4. **容量**：QPS、遅延、CPU/メモリ
