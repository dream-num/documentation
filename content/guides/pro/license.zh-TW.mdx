## 概述

完整的 Univer 高階功能需要許可證的支援，你可以透過新增許可證到你的專案中來啟用付費計劃，或者你可以透過更新你的許可證來升級到更高階別的計劃。此頁面將指導你如何獲取、配置和驗證許可證。

## 先決條件

在開始之前，請確保你：
- 在你的專案中整合 Univer 高階功能。如果你還未完成整合，請參考[整合 Univer 高階功能](/guides/pro)。
- 對於服務端部署，已完成 Docker 或 Kubernetes 環境的配置。如果你尚未完成配置，請參考 [Docker 部署文件](/guides/pro/deploy#deploy-to-docker-compose) 或 [Kubernetes 部署文件](/guides/pro/deploy#deploy-to-k8s)。
- 擁有有效的許可證。如果你還沒有，可以在透過在[許可證頁面](https://univer.ai/license)上註冊來獲取。

## 下載許可證

1. 訪問[許可證頁面](https://univer.ai/license)並登入你的賬號

2. 下載許可證檔案

### 免費申請試用許可證

如果你沒有許可證或者還在猶豫是否購買，我們為你準備了一個 30 天的試用許可證，以便於你能完整體驗 Univer 的所有高階功能。

1. 訪問[許可證頁面](https://univer.ai/license)並登入你的賬號

2. 點選“獲取試用許可證”按鈕
![獲取許可證](./license/new-01-cn.png)

## 新增或更新許可證

解壓下載好的許可證檔案 `license-univer.zip` ，你將獲得 `license.txt` 和 `licenseKey.txt` 檔案。請妥善保管這兩個檔案，並確保不要修改其格式和內容。

### 在客戶端使用許可證

#### 在預設模式中使用

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsAdvancedPreset({
      license: `你獲得的 license.txt 中的內容`,
    }),
  ],
})
```

#### 在外掛模式中使用

註冊 `UniverLicensePlugin` 外掛，這裡要保證該外掛的順序在 Univer 例項化之後最先註冊。然後將獲得 `license.txt` 中的內容貼上到外掛的 license 引數中。

```typescript
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: `你獲得的 license.txt 中的內容`,
})
```

### 在服務端使用許可證

<Tabs items={['docker compose', 'K8s']}>
  <Tab>
    1. 將 `license.txt` 和 `licenseKey.txt` 檔案複製到 `/univer-server/configs/` 目錄中。
    2. 在 univer-server 目錄下執行服務指令碼 `bash run.sh` 重啟 universer 服務。
  </Tab>
  <Tab>
    1. 執行以下命令

    ```bash
    helm upgrade --install -n univer --create-namespace \
    --set global.istioNamespace="univer" \
    --set-file universer.license.licenseV2=$(YOUR_LICENSE_TXT_PATH) \
    --set-file universer.license.licenseKeyV2=$(YOUR_LICENSE_KEY_TXT_PATH) \
    univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
    ```
  </Tab>
</Tabs>

## 驗證許可證

### 驗證 JavaScript/TypeScript 專案中的許可證

1. 前端將 License 注入後 啟動專案後即可驗證 License 是否合法以及是否被正確使用。
注：如果未輸入許可證，或輸入的許可證不合法（例如過期或內容錯誤），部分功能將受到限制，並且頁面上會顯示水印。
![前端驗證許可證失敗](./license/new-06.png)

2. 在輸入合法許可證的情況下，專案將正常執行，且不會受到限制。
![前端驗證許可證成功](./license/new-07.png)

### 驗證 Univer Server 中的許可證

訪問 `host:8000/universer-api/license/key` 檢視許可證權益資訊。 例如：若你的服務在本地執行請訪問 `http://localhost:8000/universer-api/license/key `。

```json
{
  "verify": "true", // 許可證驗證結果
  "release_type": "COMMERCIAL" // 許可證型別
}
```

![後端驗證許可證](./license/new-05.png)

## 常見問題

1. 如果許可證驗證失敗，請檢查：
   - 許可證檔案是否完整且未被修改
   - 許可證是否過期
   - 服務是否正確重啟
2. 如遇到其他問題，請聯絡我們的技術支援
