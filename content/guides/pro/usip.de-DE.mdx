title: USIP-Integration
---

Univer Pro enthält standardmäßig kein Kontosystem. Wenn Sie eine Identitätsprüfung, Berechtigungskontrolle oder Systemintegration benötigen, verwenden Sie USIP (Univer Server Integration Protocol). USIP ist ein SPI: Univer definiert die Schnittstellen und Ihr System implementiert sie.

## Anwendungsfälle

- Zugriff erfordert Anmeldung
- Rollenbasierte Bearbeitungsberechtigungen
- Mitarbeiterinformationen, Kommentare und Bearbeitungszeit synchronisieren

## Integrationsablauf

1. Implementieren Sie die USIP-APIs (siehe unten)
2. Aktivieren Sie USIP in der Bereitstellungskonfiguration
3. Weiter Authentifizierungsheader vom Client (z. B. Token)

## USIP-APIs

USIP deckt derzeit drei Kategorien ab:

- 👥 Konto: Identitätsüberprüfung, Benutzerinformationen
- 🔒 Berechtigungen: Rolle und Mitarbeiter
- 📄 Dokument: letzte Bearbeitungszeit

  response={{
    type: 'application/json',
    parameters: [],

  }}

## USIP konfigurieren [#usip-configuration]

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    USIP_ENABLED=true
    USIP_URI_CREDENTIAL=https://your-domain/usip/credential
    USIP_URI_USERINFO=https://your-domain/usip/userinfo
    USIP_URI_ROLE=https://your-domain/usip/role
    USIP_URI_COLLABORATORS=https://your-domain/usip/collaborators
    USIP_URI_UNITEDITTIME=https://your-domain/usip/unit-edit-time

    USIP_APIKEY=

    AUTH_PERMISSION_ENABLE_OBJ_INHERIT=false
    AUTH_PERMISSION_CUSTOMER_STRATEGIES=
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    universer:
      config:
        usip:
          enabled: true
          uri:
            userinfo: 'https://your-domain/usip/userinfo'
            collaborators: 'https://your-domain/usip/collaborators'
            role: 'https://your-domain/usip/role'
            credential: 'https://your-domain/usip/credential'
            unitEditTime: 'https://your-domain/usip/unit-edit-time'
          apikey: ''
        auth:
          permission:
            enableObjInherit: false
            customerStrategies: ''
    ```
  </Tab>
</Tabs>

**Hinweis**: Wenn USIP aktiviert ist, müssen alle fünf Endpunkte konfiguriert und implementiert werden.

Wenn Ihr USIP-Dienst im öffentlichen Netzwerk verfügbar gemacht wird, können wir zur Gewährleistung der API-Anforderungssicherheit einem KI-ähnlichen Mechanismus folgen API-Anfragen. Sie können einen API-Schlüssel generieren und ihn auf dem Univer-Server konfigurieren. Beim Aufruf der USIP-APIs enthält die Anfrage den Header x-api-key: API_KEY, mit dem Sie die Legitimität der Anfrage überprüfen können.

## Berechtigungsmodell

Univer verwendet RBAC mit festen Rollen: `owner`, `editor`, `reader`. Sie können Mindestrollenanforderungen für Berechtigungspunkte überschreiben.

Standardberechtigungspunkte und Mindestrollenanforderungen lauten wie folgt:

| Berechtigung | Aufzählung | Beschreibung | Mindestrolle | Rollenaufzählung |
|:-------|:---------|:-------|:-------|:-------|
| ManageCollaborator | 2 | Mitarbeiter einladen/löschen | owner | 2 |
| Copy | 6 | Inhalt kopieren | reader | 0 |
| Print | 3 | Print | editor | 1 |
| Duplicate | 4 | Dokument duplizieren | editor | 1 |
| Share | 7 | Dokument teilen | reader | 0 |
| Export | 8 | Export | editor | 1 |
| Comment | 5 | Comment | reader | 0 |
| View | 0 | View | reader | 0 |
| MoveSheet | 25 | Verschieben Arbeitsblatt | editor | 1 |
| DeleteSheet | 26 | Arbeitsblatt löschen | editor | 1 |
| HideSheet | 27 | Arbeitsblatt ausblenden | editor | 1 |
| CopySheet | 28 | Arbeitsblatt kopieren | editor | 1 |
| RenameSheet | 29 | Arbeitsblatt umbenennen | editor | 1 |
| CreateSheet | 30 | Arbeitsblatt erstellen | editor | 1 |
| SetCellStyle | 33 | Zellenstil festlegen | editor | 1 |
| SetCellValue | 34 | Zellenwert festlegen | editor | 1 |
| InsertHyperlink | 16 | Hyperlink einfügen | editor | 1 |
| Sort | 17 | Sort | editor | 1 |
| Filter | 18 | Filter | editor | 1 |
| PivotTable | 19 | Pivot-Tabelle | editor | 1 |
| RecoverHistory | 43 | Verlauf wiederherstellen | editor | 1 |
| ViewHistory | 44 | Verlauf anzeigen | reader | 0 |
| SelectProtectedCells | 31 | Geschützte Zellen auswählen | editor | 1 |
| SelectUnProtectedCells | 32 | Ungeschützte Zellen auswählen Zellen | editor | 1 |
| SetRowStyle | 35 | Zeilenstil festlegen | editor | 1 |
| SetColumnStyle | 36 | Spaltenstil festlegen | editor | 1 |
| InsertRow | 37 | Zeile einfügen | editor | 1 |
| InsertColumn | 38 | Spalte einfügen | editor | 1 |
| DeleteRow | 39 | Zeile löschen | editor | 1 |
| DeleteColumn | 40 | Spalte löschen | editor | 1 |
| Delete | 42 | Dokument löschen | owner | 2 |
| CreatePermissionObject | 45 | Geschützten Bereich/Blatt erstellen | editor | 1 |

So beschränken Sie das Kopieren/Drucken auf Eigentümer:

```properties title=".env.custom"
AUTH_PERMISSION_CUSTOMER_STRATEGIES=[{"action": 3, "role": 2}, {"action": 6, "role": 2}]
```

K8s-Konfiguration:

```yaml title="values.yaml"
universer:
  config:
    auth:
      permission:
        customerStrategies: '[ {"action": 3, "role": 2}, {"action": 6, "role": 2} ]'
```

### Objektberechtigungsvererbung

Standardmäßig verfügt der Eigentümer eines Dokuments nicht automatisch über Eigentümerberechtigungen für alle „geschützten Bereiche/Untertabellen“ innerhalb dieses Dokuments. Wenn Sie möchten, dass der Dokumenteigentümer uneingeschränkt über alle Unterobjekte im Dokument verfügt, können Sie die Berechtigungsvererbung aktivieren, indem Sie die folgenden Einstellungen konfigurieren:

```properties title=".env.custom"
AUTH_PERMISSION_ENABLE_OBJ_INHERIT=true
```

K8s-Konfiguration:

```yaml title="values.yaml"
universer:
  config:
    auth:
      permission:
        enableObjInherit: true
```

## Client-Header

Wenn Sie benutzerdefinierte Header (z. B. Autorisierungstoken) hinzufügen müssen, verwenden Sie HTTPService-Interceptoren:

<Tabs items={['Preset', 'Plugin']}>
  <Tab>
    ```typescript
    import { HTTPService } from '@univerjs/preset-sheets-core'

    const injector = univer.__getInjector()
    const httpService = injector.get(HTTPService)
    httpService.registerHTTPInterceptor({
      priority: 0,
      interceptor: (request, next) => {
        // request.headers.set('Authorization', 'Bearer your-token-here')
        return next(request)
      },
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    import { HTTPService } from '@univerjs/network'

    const injector = univer.__getInjector()
    const httpService = injector.get(HTTPService)
    httpService.registerHTTPInterceptor({
      priority: 0,
      interceptor: (request, next) => {
        // request.headers.set('Authorization', 'Bearer your-token-here')
        return next(request)
      },
    })
    ```
  </Tab>
</Tabs>

Wenn Sie [Bearbeiten Geschichte](/guides/sheets/features/edit-history) verwenden, wenden Sie denselben Interceptor auf HistoryUniver an:

```typescript
historyLoaderService.historyUniver$.subscribe((historyUniver) => {
  if (!historyUniver) return

  const injector = historyUniver.__getInjector()
  const httpService = injector.get(HTTPService)
  httpService.registerHTTPInterceptor({
    priority: 0,
    interceptor: (request, next) => {
      // request.headers.set('Authorization', 'Bearer your-token-here')
      return next(request)
    },
  })
})
```

Ein vollständiges Beispiel finden Sie im [Univer Pro Sheet-Starterkit](https://github.com/dream-num/univer-pro-sheet-start-kit/blob/main/src/setup-univer.ts).
