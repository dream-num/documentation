Für die erweiterten Funktionen von Univer Pro ist eine Lizenz erforderlich, um alle Vorteile freizuschalten. Auf dieser Seite wird erläutert, wie Sie eine Lizenz erhalten, konfigurieren und überprüfen.

## Wenn eine Lizenz erforderlich ist

- Evaluierung: Lizenz nicht erforderlich, aber die Funktionen sind begrenzt (Wasserzeichen, Importgröße, Kollaborationskontingent)
- Produktion: Es wird empfohlen, eine Lizenz für vollen Zugriff zu erwerben

Wenn Sie den Server noch nicht bereitgestellt haben, lesen Sie [Schnellstart](/guides/pro/server).

## Holen Sie sich eine Lizenz

1. Besuchen Sie die [Lizenzseite](/guides/pro/license) und melden Sie sich an
2. Laden Sie die Lizenzdatei herunter

### Kostenlose Testlizenz

Sie können eine 30-Tage-Testlizenz anfordern:

2. Klicken Sie auf „Testlizenz anfordern“

## Eine Lizenz hinzufügen oder aktualisieren

Entpacken Sie `license-univer.zip`, um `license.txt` und `licenseKey.txt` zu erhalten. Bearbeiten Sie sie nicht.

### Lizenz im Client verwenden

#### Voreingestellter Modus

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsAdvancedPreset({
      license: `Content from license.txt`,
    }),
  ],
})
```

#### Plugin-Modus

Registrieren Sie zuerst `UniverLicensePlugin`, nachdem Sie die Univer-Instanz erstellt haben:

```typescript
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: `Content from license.txt`,
})
```

### Lizenz auf Server verwenden

<Tabs items={['docker compose', 'K8s']}>
  <Tab>
    1. Kopieren Sie `license.txt` und `licenseKey.txt` hinein `/univer-server/configs/`
    2. Führen Sie `bash run.sh restart` in `univer-server` aus
  </Tab>
  <Tab>
    1. Installieren/aktualisieren Sie über Helm:

    ```bash
    helm upgrade --install -n univer --create-namespace \
    --set global.istioNamespace="univer" \
    --set-file universer.license.licenseV2=$(YOUR_LICENSE_TXT_PATH) \
    --set-file universer.license.licenseKeyV2=$(YOUR_LICENSE_KEY_TXT_PATH) \
    univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
    ```
  </Tab>
</Tabs>

## Lizenz überprüfen

### Frontend-Überprüfung

- Fehlende oder ungültige Lizenz zeigt Wasserzeichen und Einschränkungen
- Gültige Lizenz entfernt Einschränkungen

![Lizenz ungültig](./license/new-06.png)

![Lizenz gültig](./license/new-07.png)

### Serverüberprüfung

Besuchen Sie `host:8000/universer-api/license/key`, um die Berechtigungen zu überprüfen. Für lokal:

`http://localhost:8000/universer-api/license/key`

```json
{
  "verify": "true",
  "release_type": "COMMERCIAL"
}
```

![Serverlizenz Überprüfung](./license/new-05.png)

## FAQ

1. Verifizierung fehlgeschlagen: Lizenzgültigkeit, Dateiintegrität überprüfen und Dienst neu starten
2. Wasserzeichen ist immer noch vorhanden: Überprüfen Sie die clientseitige Lizenzinjektion
3. Andere Probleme: Wenden Sie sich an den Support
