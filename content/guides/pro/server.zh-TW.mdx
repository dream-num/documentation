## 一鍵部署到 docker compose

### 安裝

<Callout type="warning" title="注意事項">
  如果你沒有安裝過 Docker，以下指令碼會自動為你安裝最新版本的 Docker。
</Callout>

執行以下命令，即可在**當前目錄**自動下載安裝並執行最新版本的 Univer 後端服務：

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

如需安裝指定版本的 Univer 後端服務，可以在上述命令中新增 `-- <version>` 引數，如：

```bash
bash -c "$(curl -fsSL https://get.univer.ai/product)" -- 0.9.1
```

離線安裝：

下載離線安裝包：https://univer.ai/releases/univer-server/download

1. 將離線安裝包上傳到你的部署伺服器並解壓
2. 進入解壓後的目錄執行 `bash load-images.sh` 將 Univer 後端服務的映象載入到本機 docker

指令碼執行後服務會被安裝在當前工作目錄下名為 `univer-server` 的目錄中，安裝完成會自動啟動。

### 測試服務

如果想測試服務是否正常執行，可以執行以下命令啟動內建的 demo 服務：

```bash
cd univer-server && bash run.sh start-demo-ui`
```

成功啟動後，即可瀏覽器開啟：`http://localhost:3010` 體驗。開啟此連結後會自動建立一份新的空白文件並跳轉到此文件的連結，如果想要體驗協同編輯功能，可以在另一個瀏覽器或無痕視窗中再次開啟此文件。

### 測試 USIP

如果需要體驗與自己的系統整合以對使用者身份進行認證、許可權管理，你可以按以下步驟操作：

<Steps>
  <Step>
    在 `univer-server` 目錄下建立名為 `.env.custom` 的檔案，在其中寫入下述配置：

    ```properties
    USIP_ENABLED=true
    ```
  </Step>
  <Step>
    執行 `bash run.sh restart` 重啟後端服務
  </Step>
  <Step>
    執行 `bash run.sh start-demo-usip` 啟動 demo 服務
  </Step>
</Steps>

上述步驟都成功完成後，即可瀏覽器開啟 `http://localhost:8080` 體驗。

### 停止、啟動、重啟、解除安裝服務

另外，你可以透過 `univer-server` 目錄下的 `run.sh` 來控制 Univer 後端服務的停止、啟動、重啟和解除安裝。

<Callout type="warning" title="注意事項">
  解除安裝操作將會刪除你在體驗過程中所建立的文件及其中包含的圖片等所有資料，請謹慎操作。
</Callout>

- **停止**：`cd univer-server && bash run.sh stop`
- **啟動**：`cd univer-server && bash run.sh start`
- **重啟**：`cd univer-server && bash run.sh restart`
- **解除安裝**：`cd univer-server && bash run.sh uninstall`，

### 更新服務

在安裝目錄 `univer-server` 的父目錄下，在此執行以下命令即可覆蓋安裝最新的版本，**舊的配置和資料會被保留**：

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

## 一鍵部署到 K8s

### 環境要求

Univer 使用 Helm 來完成在 K8s 上的部署，因此需要你先安裝 Helm。請參照 Helm 的[官方安裝指南](https://helm.sh/zh/docs/intro/install/)完成安裝。

Helm 需要訪問你的 K8s 叢集，你需要確保已經有了K8s叢集，然後透過下列方式**之一**讓 Helm 能夠訪問：

- 確保在 `~/.kube/config` 配置了K8s叢集的 `kubeconfig` 檔案
- 配置了 `KUBECONFIG` 環境變數，且值為你的 `kubeconfig` 檔案路徑
- 在 Helm 命令中使用引數 `--kubeconfig`，引數值設定為你的 `kubeconfig` 檔案路徑，如：`helm install --kubeconfig your-kubeconfig-path`

### 操作說明

執行以下命令安裝 Univer 後端服務到你的 K8s

```bash
helm install -n univer --create-namespace \
  --set global.istioNamespace="univer" \
  univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
kubectl rollout restart -n univer deployment/collaboration-server
kubectl rollout restart -n univer deployment/universer
```

#### 測試服務

安裝完成後開啟 `http://univer.example.com/sheet/` 即可體驗。

#### 解除安裝服務

```bash
helm uninstall univer-stack -n univer
```

#### 更新服務

```bash
helm upgrade --install univer-stack \
  oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack \
  -n univer
```

## 進一步整合

如果你希望進一步將 Univer Pro 的服務端整合到自己的系統中，以實現類似以下功能：

- 使用者登入後才可訪問 Univer Pro 的服務
- 按角色或使用者來管理文件的訪問許可權
- 獲取文件評論的通知
- 操作文件資源（如建立、刪除、修改文件等）
