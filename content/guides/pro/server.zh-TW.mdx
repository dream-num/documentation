---
title: 快速開始：部署服務端
---

如果你想快速體驗協作、匯入匯出等需要後端支援的能力，可以從本頁開始。生產環境請使用[生產部署](/guides/pro/deploy)。

## 適用場景

- 本機體驗或 PoC
- 小規模內部測試
- 尚未接入企業身分與權限系統

## 環境需求

| 環境 | 要求 |
| ---- | ---- |
| 作業系統 | Linux、Mac、Windows(WSL) |
| CPU | 至少 1 核 |
| 記憶體 | 至少 2G；匯入匯出建議 >4G |
| 磁碟 | 至少 10G |
| Docker | 23 以上版本 |

相容性：

- Linux：核心版本不低於 3.10.0（低版本可能有相容性問題）
- Docker Compose：版本 2.21 或以上
- 資料庫：MySQL 8+、PostgreSQL 13+，及相容的國產資料庫（含達夢 V8）
- Redis：5.0 或以上

## 一鍵部署到 Docker Compose

<Callout>
  未授權的 Univer 後端服務為功能受限版本。如需解鎖限制，請前往[授權](/guides/pro/license)。
</Callout>

### 安裝

<Callout type="warning" title="注意">
  若未安裝 Docker，以下腳本將自動安裝最新版 Docker。
</Callout>

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

指定版本：

```bash
bash -c "$(curl -fsSL https://get.univer.ai/product)" -- 0.9.1
```

離線安裝：

1. 下載離線安裝包：https://univer.ai/releases/univer-server/download
2. 上傳至伺服器並解壓
3. 執行 `bash load-images.sh` 將映像載入 Docker

腳本會建立 `univer-server` 目錄並自動啟動服務。

### 啟動 Demo UI

前往 [Demo UI 倉庫](https://github.com/dream-num/univer-pro-sheet-start-kit) 拉取最新的 Demo UI 代碼並啟動服務。

開啟服務連結後會自動建立空白文件，如需協作體驗，可在另一個瀏覽器或無痕視窗開啟同一連結。

### 啟動 USIP Demo

<Steps>
  <Step>
    在 `univer-server` 目錄建立 `.env.custom`，寫入：

    ```properties
    USIP_ENABLED=true
    ```
  </Step>
  <Step>
    執行 `bash run.sh restart` 重啟服務
  </Step>
  <Step>
    執行 `bash run.sh start-demo-usip` 啟動 Demo
  </Step>
</Steps>

開啟 `http://localhost:8080` 體驗。

### 常用指令

- **停止**：`cd univer-server && bash run.sh stop`
- **啟動**：`cd univer-server && bash run.sh start`
- **重啟**：`cd univer-server && bash run.sh restart`
- **解除安裝**：`cd univer-server && bash run.sh uninstall`

<Callout type="warning" title="注意">
  解除安裝會刪除體驗過程中建立的文檔與圖片等資料，請謹慎操作。
</Callout>

### 更新服務

在 `univer-server` 的父目錄再次執行安裝命令即可升級，舊設定與資料會保留：

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

## 一鍵部署到 K8s

若你已維護 K8s 叢集，可使用 Helm：

```bash
helm install -n univer --create-namespace \
  --set global.istioNamespace="univer" \
  univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
kubectl rollout restart -n univer deployment/collaboration-server
kubectl rollout restart -n univer deployment/universer
```

開啟 `http://univer.example.com/sheet/` 即可體驗。

解除安裝：

```bash
helm uninstall univer-stack -n univer
```
