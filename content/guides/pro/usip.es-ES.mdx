---
title: Integración USIP
---

Univer Pro no incluye un sistema de cuentas de forma predeterminada. Si necesita verificación de identidad, control de permisos o integración del sistema, utilice USIP (Protocolo de integración de servidores de Univer). USIP es un SPI: Univer define las interfaces y su sistema las implementa.

## Casos de uso

- El acceso requiere inicio de sesión
- Permisos de edición basados en roles
- Sincronizar información del colaborador, comentarios y tiempo de edición

## Flujo de integración

1. Implementar las API de USIP (consulte a continuación)
2. Habilitar USIP en la configuración de implementación
3. Autenticación directa encabezados del cliente (por ejemplo, token)

## API de USIP

USIP actualmente cubre tres categorías:

- 👥 Cuenta: verificación de identidad, información de usuario
- 🔒 Permisos: rol y colaboradores
- 📄 Documento: hora de la última edición

## Configurar USIP [#usip-configuration]

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    USIP_ENABLED=true
    USIP_URI_CREDENTIAL=https://your-domain/usip/credential
    USIP_URI_USERINFO=https://your-domain/usip/userinfo
    USIP_URI_ROLE=https://your-domain/usip/role
    USIP_URI_COLLABORATORS=https://your-domain/usip/collaborators
    USIP_URI_UNITEDITTIME=https://your-domain/usip/unit-edit-time

    USIP_APIKEY=

    AUTH_PERMISSION_ENABLE_OBJ_INHERIT=false
    AUTH_PERMISSION_CUSTOMER_STRATEGIES=
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    universer:
      config:
        usip:
          enabled: true
          uri:
            userinfo: 'https://your-domain/usip/userinfo'
            collaborators: 'https://your-domain/usip/collaborators'
            role: 'https://your-domain/usip/role'
            credential: 'https://your-domain/usip/credential'
            unitEditTime: 'https://your-domain/usip/unit-edit-time'
          apikey: ''
        auth:
          permission:
            enableObjInherit: false
            customerStrategies: ''
    ```
  </Tab>
</Tabs>

**Nota**: Cuando USIP está habilitado, los cinco puntos finales deben configurarse e implementarse.

Si su servicio USIP está expuesto en la red pública, para garantizar la seguridad de las solicitudes de API, podemos seguir un mecanismo similar a las solicitudes de API de AI. Puede generar una clave API y configurarla en el servidor Univer. Al llamar a las API de USIP, la solicitud incluirá el encabezado x-api-key: API_KEY, que puede usar para verificar la legitimidad de la solicitud.

## Modelo de permiso

Univer usa RBAC con roles fijos: `owner`, `editor`, `reader`. Puede anular los requisitos mínimos de función para los puntos de permiso.

Para restringir la copia/impresión a los propietarios:

```properties title=".env.custom"
AUTH_PERMISSION_CUSTOMER_STRATEGIES=[{"action": 3, "role": 2}, {"action": 6, "role": 2}]
```

Configuración de K8s:

```yaml title="values.yaml"
universer:
  config:
    auth:
      permission:
        customerStrategies: '[ {"action": 3, "role": 2}, {"action": 6, "role": 2} ]'
```

### Herencia de permisos de objetos

De forma predeterminada, el propietario de un documento no tiene automáticamente permisos de propietario para todas las "áreas/subtablas protegidas" dentro de ese documento. Si desea que el propietario del documento tenga incondicionalmente permisos completos sobre todos los subobjetos dentro del documento, puede habilitar la herencia de permisos configurando las siguientes opciones:

```properties title=".env.custom"
AUTH_PERMISSION_ENABLE_OBJ_INHERIT=true
```

Configuración de K8s:

```yaml title="values.yaml"
universer:
  config:
    auth:
      permission:
        enableObjInherit: true
```

## Encabezados de cliente

Si necesita agregar encabezados personalizados (por ejemplo, token de autorización), use HTTPService interceptores:

<Tabs items={['Preset', 'Plugin']}>
  <Tab>
    ```typescript
    import { HTTPService } from '@univerjs/preset-sheets-core'

    const injector = univer.__getInjector()
    const httpService = injector.get(HTTPService)
    httpService.registerHTTPInterceptor({
      priority: 0,
      interceptor: (request, next) => {
        // request.headers.set('Authorization', 'Bearer your-token-here')
        return next(request)
      },
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    import { HTTPService } from '@univerjs/network'

    const injector = univer.__getInjector()
    const httpService = injector.get(HTTPService)
    httpService.registerHTTPInterceptor({
      priority: 0,
      interceptor: (request, next) => {
        // request.headers.set('Authorization', 'Bearer your-token-here')
        return next(request)
      },
    })
    ```
  </Tab>
</Tabs>

Si usa [Editar historial](/guides/sheets/features/edit-history), aplique el mismo interceptor a HistoryUniver:

```typescript
historyLoaderService.historyUniver$.subscribe((historyUniver) => {
  if (!historyUniver) return

  const injector = historyUniver.__getInjector()
  const httpService = injector.get(HTTPService)
  httpService.registerHTTPInterceptor({
    priority: 0,
    interceptor: (request, next) => {
      // request.headers.set('Authorization', 'Bearer your-token-here')
      return next(request)
    },
  })
})
```
