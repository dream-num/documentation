---
title: Konfiguration integrierter Komponenten
---

Diese Seite gilt nur, wenn Sie integrierte Univer-Komponenten (PostgreSQL, RabbitMQ, MinIO) verwenden. Diese Anmeldeinformationen werden nur bei der ersten Initialisierung wirksam. Aktualisieren Sie nach der Bereitstellung die Passwörter über das offizielle Verfahren jeder Komponente.

## Standardpasswörter ändern

<Callout>
Konfigurieren Sie diese vor der ersten Bereitstellung. Vorhandene Instanzen ändern Passwörter nicht automatisch.
</Callout>

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
Erstellen Sie `.env.custom` im Installationsverzeichnis und führen Sie dann Folgendes aus:

    ```bash
    bash run.sh
    ```
  </Tab>
  <Tab label="K8s">
Erstellen Sie `values.yaml` und führen Sie dann Folgendes aus:

    ```shell
    helm install -n univer --create-namespace \
      --set global.istioNamespace="univer" \
      --values values.yaml \
      univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
    kubectl rollout restart -n univer deployment/collaboration-server
    kubectl rollout restart -n univer deployment/universer
    ```
  </Tab>
</Tabs>

### PostgreSQL

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    DATABASE_USERNAME=postgres
    DATABASE_PASSWORD=postgres
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    global:
      postgresql:
        auth:
          postgresPassword: postgres

    universer:
      config:
        database:
          username: postgres
          password: postgres

    temporal:
      server:
        config:
          persistence:
            default:
              sql:
                user: postgres
                password: postgres

            visibility:
              sql:
                user: postgres
                password: postgres
    ```
  </Tab>
</Tabs>

Hinweise:

- Nur wirksam bei der ersten Initialisierung.
- In K8s kann nur das Administratorkennwort konfiguriert werden; Der Standard-Administratorbenutzer ist `postgres`.
- `universer` und `temporal` sollten dieselben Datenbankanmeldeinformationen verwenden.

### RabbitMQ

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    RABBITMQ_USERNAME=guest
    RABBITMQ_PASSWORD=guest
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    rabbitmq:
      auth:
        username: guest
        password: guest

    universer:
      config:
        rabbitmq:
          username: guest
          password: guest
    ```
  </Tab>
</Tabs>

Hinweise:

- Der Standardbenutzername ist `guest`. Ändern Sie es für die Produktion.
- Nach dem Aktualisieren der RabbitMQ-Anmeldeinformationen aktualisieren Sie die Konfiguration von `universer` entsprechend.

### S3 (MinIO)

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    S3_USER=minio
    S3_PASSWORD=minio123456
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    minio:
      auth:
        rootUser: admin
        rootPassword: minioadmin

    universer:
      config:
        s3:
          accessKeyID: admin
          accessKeySecret: minioadmin
    ```
  </Tab>
</Tabs>

Hinweise:

- `rootUser/rootPassword` sind MinIO-Administratoranmeldeinformationen.
- `accessKeyID/accessKeySecret` muss mit MinIO übereinstimmen Konto.
