---
title: "Inicio rápido: implementar el Servidor"
---

Si desea experimentar rápidamente la colaboración, la importación/exportación y otras capacidades respaldadas por el servidor, comience aquí. Para producción, consulte [Implementación de producción](/guides/pro/deploy).

## Cuándo utilizar

- Evaluación local o PoC
- Pruebas internas pequeñas
- Aún no hay integración de identidad/permisos

## Requisitos del entorno

| Artículo | Requisito |
| ---- | ---- |
| OS | Linux, Mac, Windows (WSL2) |
| CPU | Al menos 1 núcleo |
| Memory | Al menos 2G; >4G recomendado para importaciones grandes |
| Disk | Al menos 10G |
| Docker | 23+ |

Compatibilidad:

- Kernel de Linux >= 3.10.0 (los kernels más antiguos pueden tener problemas)
- Docker Compose >= 2,21
- Base de datos: MySQL 8+, PostgreSQL 13+, bases de datos nacionales compatibles (Dameng V8 incluido)
- Redis: 5.0+

## Implementación con un clic en Docker Compose

<Callout>
Sin una licencia, el servidor se ejecuta en modo limitado. Consulte [Licencia](/guides/pro/license) para desbloquear todas las capacidades.
</Callout>

### Instalar

<Callout type="warning" title="Note">
Si Docker no está instalado, el script instala la última versión automáticamente.
</Callout>

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

Instale una versión específica:

```bash
bash -c "$(curl -fsSL https://get.univer.ai/product)" -- 0.9.1
```

Instalación sin conexión:

1. Descargue el paquete sin conexión: //releases/univer-server/download
2. Cargue y extraiga en el servidor
3. Ejecutar `bash load-images.sh` para cargar imágenes en Docker

El script crea un directorio `univer-server` e inicia los servicios automáticamente.

### Inicie la interfaz de usuario de demostración

Vaya al [repositorio de la interfaz de usuario de demostración](https://github.com/dream-num/univer-pro-sheet-start-kit) para extraer el último código de la interfaz de usuario de demostración e iniciar el servicio.

Visite el enlace del servicio para crear automáticamente un documento en blanco. Para disfrutar de una experiencia de colaboración, abra el mismo enlace en otro navegador o ventana de incógnito.

### Inicie la demostración de USIP

<Steps>
  <Step>
Cree `.env.custom` en `univer-server` y agregue:

    ```properties
    USIP_ENABLED=true
    ```
  </Step>
  <Step>
Ejecute `bash run.sh restart` para reiniciar los servicios
  </Step>
  <Step>
Ejecute `bash run.sh start-demo-usip` para iniciar demo
  </Step>
</Steps>

Visite `http://localhost:8080` para probarlo.

### Comandos comunes

- **Detener**: `cd univer-server && bash run.sh stop`
- **Iniciar**: `cd univer-server && bash run.sh start`
- **Reiniciar**: `cd univer-server && bash run.sh restart`
- **Desinstalar**: `cd univer-server && bash run.sh uninstall`

<Callout type="warning" title="Note">
La desinstalación elimina todos los documentos e imágenes creados durante la evaluación. Proceda con cuidado.
</Callout>

### Actualice el servidor

Ejecute el instalador nuevamente en el directorio principal para actualizar manteniendo la configuración y los datos:

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

## Implementar con un clic en K8s

Si ya tiene un clúster K8s, puede usar Helm:

```bash
helm install -n univer --create-namespace \
  --set global.istioNamespace="univer" \
  univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
kubectl rollout restart -n univer deployment/collaboration-server
kubectl rollout restart -n univer deployment/universer
```

Abra `http://univer.example.com/sheet/` para probarlo.

Desinstalar:

```bash
helm uninstall univer-stack -n univer
```
