title: 许可证
---

Univer SDK Pro 的高级能力需要许可证才能解锁完整权益。本页介绍获取、配置与验证流程。

## 什么时候需要许可证

- 体验阶段：可免许可证使用，但会有水印、导入体积、协作数量等限制
- 生产/正式使用：建议购买许可证以解锁完整权益

如果你还未完成后端部署，请先阅读[快速开始](/guides/pro/server)。

## 获取许可证

1. 访问 [许可证页面](/guides/pro/license) 并登录
2. 下载许可证文件

![下载许可证](./license/new-02-cn.png)

### 免费申请试用许可证

如果你想完整体验 Univer SDK Pro，可先申请 30 天试用许可证：

1. 访问 [许可证页面](/guides/pro/license) 并登录
2. 点击“获取试用许可证”

![获取许可证](./license/new-01-cn.png)

## 添加或更新许可证

解压 `license-univer.zip`，得到 `license.txt` 与 `licenseKey.txt`。请勿修改文件内容。

### 在客户端使用许可证

#### 预设模式

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsAdvancedPreset({
      license: `你获得的 license.txt 中的内容`,
    }),
  ],
})
```

#### 插件模式

确保 `UniverLicensePlugin` 在实例化后最先注册：

```typescript
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: `你获得的 license.txt 中的内容`,
})
```

### 在服务端使用许可证

<Tabs items={['docker compose', 'K8s']}>
  <Tab>
    1. 将 `license.txt` 与 `licenseKey.txt` 拷贝到 `/univer-server/configs/`
    2. 在 `univer-server` 目录执行 `bash run.sh restart` 重启 universer 服务
  </Tab>
  <Tab>
    1. 执行以下命令安装/升级：

    ```bash
    helm upgrade --install -n univer --create-namespace \
    --set global.istioNamespace="univer" \
    --set-file universer.license.licenseV2=$(YOUR_LICENSE_TXT_PATH) \
    --set-file universer.license.licenseKeyV2=$(YOUR_LICENSE_KEY_TXT_PATH) \
    univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
    ```
  </Tab>
</Tabs>

## 验证许可证

### 在前端验证

- 若未输入或输入无效，会出现水印并限制功能
- 输入合法许可证后水印消失、功能正常

![前端验证许可证失败](./license/new-06.png)

![前端验证许可证成功](./license/new-07.png)

### 在服务端验证

访问 `http://localhost:8000/universer-api/license/key` 查看权益信息。例如本地：

```json
{
  "verify": "true", // 许可证验证结果
  "release_type": "COMMERCIAL" // 许可证类型
}
```

![后端验证许可证](./license/new-05.png)

## 常见问题

1. 验证失败：确认许可证未过期、内容未被修改、服务已重启
2. 仍有水印：检查前端是否注入了 `license.txt` 内容
3. 其他问题：请联系技术支持
