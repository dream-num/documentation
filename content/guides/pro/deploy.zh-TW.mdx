## 部署架構與元件

![部署架構及服務介紹](./deploy/deploy-arch.png)

<Callout title="版本提示">
  - v0.13.0 引入 `collaboration-helper`，用於快照等 CPU 密集任務。
  - v0.15.0 引入協作分層調度，支援依表格規模分流協作叢集。
</Callout>

### 服務清單

- **collaboration-server**：協作編輯引擎，後端實作 OT 演算法
- **collaboration-helper**：處理快照等 CPU 密集任務（v0.13.0 之後）
- **universer**：文件操作與協作訊息調度
- **exchange worker**：匯入匯出計算服務（計算與記憶體密集）

<Callout>
  collaboration-server 為有狀態服務。同一文件的編輯請求固定落在同一實例，以提升效能與穩定性。
</Callout>

### 依賴元件

- **RDS**：存放文件中繼資料與權限設定
- **Object Storage**：存放文件內容、圖片與資料塊
- **Redis**：協作者快取與限流
- **RabbitMQ**：協作訊息廣播
- **Temporal**：匯入匯出流程引擎

## 部署方式選擇

| 方式 | 適用場景 | 特性 |
| --- | --- | --- |
| Docker Compose | 規模較小、無 K8s | 單機部署，僅垂直擴展 |
| K8s | 中大型規模 | 支援水平擴展與彈性伸縮 |

## 生產前 Checklist

- **身分與權限**：是否需要接入企業帳號系統（USIP）
- **容量評估**：協作與匯入匯出服務的 CPU/記憶體規劃
- **基礎元件**：建議使用自建或雲端服務版本
- **資料安全**：RDS 與物件儲存備份策略
- **可觀測性**：是否啟用監控與日誌（見[運維手冊](/guides/pro/sre-manual)）

## 設定入口

### Docker Compose

在安裝目錄建立 `.env.custom`，覆蓋預設 `.env`。

### K8s

在自訂 `values.yaml` 中覆蓋 Helm chart 預設值，不直接修改 chart 檔案。

## 常用設定

### 啟用 USIP（身分與權限）

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    # usip
    USIP_ENABLED=true # 設為 true 以啟用 USIP
    USIP_URI_CREDENTIAL=https://your-domain/usip/credential
    USIP_URI_USERINFO=https://your-domain/usip/userinfo
    USIP_URI_ROLE=https://your-domain/usip/role
    USIP_URI_COLLABORATORS=https://your-domain/usip/collaborators
    USIP_URI_UNITEDITTIME=https://your-domain/usip/unit-edit-time

    # auth
    AUTH_PERMISSION_ENABLE_OBJ_INHERIT=false
    AUTH_PERMISSION_CUSTOMER_STRATEGIES=
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    universer:
      config:
        usip:
          enabled: true
          uri:
            userinfo: 'https://your-domain/usip/userinfo'
            collaborators: 'https://your-domain/usip/collaborators'
            role: 'https://your-domain/usip/role'
            credential: 'https://your-domain/usip/credential'
            unitEditTime: 'https://your-domain/usip/unit-edit-time'
        auth:
          permission:
            enableObjInherit: false
            customerStrategies: ''
    ```
  </Tab>
</Tabs>

欄位說明：

- `USIP_ENABLED` / `usip.enabled`：啟用 USIP 後需設定所有端點。
- `USIP_URI_*`：各 USIP API 位址（credential、userinfo、role、collaborators、unit-edit-time）。
- `AUTH_PERMISSION_*`：權限點位與物件繼承設定，見[USIP 整合](/guides/pro/usip)。

### 使用自建基礎元件

<Callout>
  建議使用自建或雲端服務版本的基礎元件，以確保穩定性與資料安全。
</Callout>

#### 相容性要求

- MQ：需相容 AMQP/AMQPS，建議 RabbitMQ。內建映像為 `rabbitmq:3-management`。
- Redis：需相容 Redis 核心指令（GET、MGET、SET、SETNX、DEL、EXISTS、EXPIRE、HSET、HGET、HDEL、HGETALL、HLEN、SCAN、Pipeline、EVAL、EVALSHA）。
- RDS：已適配 PostgreSQL 16.1、MySQL 8.0、GaussDB、DamengDB。暫不支援需分片欄位的分散式資料庫；如使用 TiDB 等相容產品，請注意 ID 遞增造成的熱點風險。
- Object Storage：需相容 AWS S3 API。內建映像為 `bitnami/minio:2024.8.3-debian-12-r1`。

#### RDS

**注意**：Temporal 不支援 GaussDB 與 DamengDB，Temporal 將使用獨立的 PostgreSQL。

##### 相容 PostgreSQL

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    DISABLE_UNIVER_RDS=true

    DATABASE_DRIVER=postgresql
    DATABASE_HOST=your-database-host
    DATABASE_PORT=your-database-port
    DATABASE_DBNAME=univer
    DATABASE_USERNAME=user-name
    DATABASE_PASSWORD=password
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    postgresql:
      enabled: false

    universer:
      config:
        database:
          driver: postgresql
          host: your-database-host
          port: your-database-port
          dbname: univer
          username: postgres
          password: postgres

    temporal:
      server:
        config:
          persistence:
            default:
              driver: sql
              sql:
                driver: postgres12
                host: your-database-host
                port: your-database-port
                database: temporal
                user: postgres
                password: postgres

            visibility:
              driver: sql
              sql:
                driver: postgres12
                host: your-database-host
                port: your-database-port
                database: temporal_visibility
                user: postgres
                password: postgres
    ```
  </Tab>
</Tabs>

欄位說明：

- `DISABLE_UNIVER_RDS`：使用自建 RDS 時需停用內建資料庫。
- `DATABASE_DBNAME`：需與初始化腳本中的資料庫名稱一致。
- `DATABASE_USERNAME`：建議具備 select/insert/update/delete 權限。
- Temporal 資料庫僅用於匯入匯出流程，不包含文件內容。
- `driver: postgres12` 代表 PostgreSQL 需為 12+。

#### Redis

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    DISABLE_UNIVER_REDIS=true

    REDIS_ADDR=host:port[,host:port]
    REDIS_USERNAME=user-name
    REDIS_PASSWORD=password
    REDIS_DB=0

    REDIS_TLS_ENABLED=false
    REDIS_TLS_INSECURE=false
    REDIS_TLS_CA=
    REDIS_TLS_CERT=
    REDIS_TLS_KEY=
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    universer:
      config:
        redis:
          poolSize: 100
          addr: 192.168.1.100:6379
          read_timeout: 1s
          write_timeout: 1s
          db: 0
          username: user_name_here
          password: password_here
          tlsConfig:
            enabled: false
            insecure: false
            ca: ''
            cert: ''
            key: ''

    worker:
      redis:
        poolSize: 10
        addr: 192.168.1.100:6379
        read_timeout: 1s
        write_timeout: 1s
        db: 0
        username: user_name_here
        password: password_here
        tlsConfig:
          enabled: false
          insecure: false
          ca: ''
          cert: ''
          key: ''

    redis:
      enabled: false
    ```
  </Tab>
</Tabs>

欄位說明：

- `DISABLE_UNIVER_REDIS`：使用自建 Redis 時需停用內建 Redis。
- `REDIS_ADDR`：叢集可用逗號分隔多個位址。
- TLS 支援不安全、僅 CA 驗證、mTLS。
- Docker Compose 中 CA/憑證/私鑰可填路徑或內容，若填路徑需為容器內掛載路徑。
- K8s 建議在 `tlsConfig` 填入憑證內容。
- `worker.redis` 建議與 `universer.config.redis` 一致。

### 協作分層調度（進階）

v0.15.0 引入分層調度，依表格規模路由到不同協作叢集，預設不啟用。

設定示例：

```yaml
unitRoutingConf:
  tiers:
    - tierName: normal
      enable: true
      upgradeCellsThreshold: 0
      downgradeCellsThreshold: 0
      upgradeImportTimeThreshold: 0
    - tierName: large
      enable: true
      upgradeCellsThreshold: 1000
      downgradeCellsThreshold: 900
      upgradeImportTimeThreshold: 10
    - tierName: huge
      enable: true
      upgradeCellsThreshold: 10000
      downgradeCellsThreshold: 9000
      upgradeImportTimeThreshold: 60
```

欄位說明：

- `tiers`：叢集等級清單。
- `enable`：是否啟用該等級。
- `upgradeCellsThreshold`：升級門檻。
- `downgradeCellsThreshold`：降級門檻，避免來回切換。
- `upgradeImportTimeThreshold`：匯入耗時門檻。
- 至少需有一個等級所有門檻為 0。

調度示例：

- 新文件 0 單元格 → normal。
- 1000 單元格 → 升級到 large。
- 降到 899 → 降回 normal。
- 匯入耗時 61s → 進入 huge。

Docker Compose 預設提供兩級（normal/large）：

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    ENABLE_LARGE_TIER_COLLABORATION_SERVER=false
    LARGE_TIER_MIN_CELLS_COUNT=2000000
    LARGE_TIER_DOWNGRADE_CELLS_COUNT=1950000
    LARGE_TIER_MIN_IMPORT_SECONDS=10
    LARGE_TIER_COLLABORATION_SERVER_REPLICATION_CNT=2
    LARGE_TIER_COLLABORATION_SERVER_MEMORY_LIMIT=8192
    ```
  </Tab>
  <Tab label="K8s">
    請自行設定多級叢集與路由規則。
  </Tab>
</Tabs>

### 網路與跨域

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    DOCKER_NETWORK_SUBNET=172.30.0.0/16
    HOST_NGINX_PORT=the-univer-server-api-port-you-wanted
    HOST_MINIO_PORT=the-minio-port-you-wanted
    HOST_GRAFANA_PORT=the-grafana-port-you-wanted

    CORS_ALLOW_ORIGINS='["domain1", "domain2"]'
    CORS_ALLOW_HEADERS='["content-type","authorization"]'
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    universer:
      config:
        server:
          http:
            corsAllowOrigins: [domain1, domain2]
            corsAllowHeaders: [content-type, authorization]
    ```
  </Tab>
</Tabs>

欄位說明：

- `DOCKER_NETWORK_SUBNET`：Docker 網段，使用 CIDR。
- `HOST_NGINX_PORT`：API 對外埠（與宿主機衝突時修改）。
- `HOST_MINIO_PORT` / `HOST_GRAFANA_PORT` 僅對內建元件生效。
- K8s 不需要上述埠映射。
- `CORS_ALLOW_ORIGINS` / `CORS_ALLOW_HEADERS`：允許的跨域網域與標頭。

## 部署流程

### Docker Compose

1. 準備 `.env.custom`（可選）
2. 準備 `license.txt` 與 `licenseKey.txt`
3. 若使用自建 RDS，下載[初始化腳本](https://release-univer.oss-cn-shenzhen.aliyuncs.com/releases/latest/univer-server-sql-latest.tar.gz)並初始化
4. 取得 Univer Server
   - 線上：`bash -c "$(curl -fsSL https://get.univer.ai/product)" [-- version]`
   - 離線：下載 All in one 包並執行 `bash load-images.sh`
5. 將 `.env.custom` 放入服務根目錄
6. 將授權檔案放入 `configs/`
7. 在根目錄執行 `bash run.sh start`
8. 完成回歸測試

### K8s

1. 準備 `values.yaml`（可選，建議版本管理）
2. 準備 `license.txt` 與 `licenseKey.txt`
3. 如使用自建 RDS，完成初始化腳本
4. 以 Helm 安裝
   - 線上安裝：

   ```shell
   helm install -n univer --create-namespace \
     -f your-own-values.yaml-path \
     --set global.istioNamespace="univer" \
     --set-file universer.license.licenseV2=your-license.txt-path \
     --set-file universer.license.licenseKeyV2=your-licenseKey.txt-path \
     univer-stack \
     oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack \
     --version target-version

   kubectl rollout restart -n univer deployment/collaboration-server
   kubectl rollout restart -n univer deployment/universer
   ```

   - 離線安裝：

   ```shell
   export REGISTER=XXXX
   export NAMESPACE=XXX
   docker login $REGISTER
   bash load-image.sh --registry $REGISTER --namespace $NAMESPACE

   helm install -n univer --create-namespace \
     -f your-own-values.yaml-path \
     --set global.istioNamespace="univer" \
     --set-file universer.license.licenseV2=your-license.txt-path \
     --set-file universer.license.licenseKeyV2=your-licenseKey.txt-path \
     univer-stack-xxxx.tgz
   ```

參數說明：

- `-n univer`：指定 namespace（後續升級需一致）。
- `univer-stack`：helm release 名稱（後續升級需一致）。
- `--version target-version`：指定目標版本，省略則使用最新。
- `-f your-own-values.yaml-path`：自訂設定檔路徑。
- `--set-file universer.license.licenseV2`：`license.txt` 檔案路徑。
- `--set-file universer.license.licenseKeyV2`：`licenseKey.txt` 檔案路徑。

如需部署內建可觀測元件：

```bash
helm upgrade --install -n univer-observability --create-namespace \
  --set global.univerNamespace="univer" \
  univer-observability \
  oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-observability
```
