이 페이지에서는 메트릭, 로그, 일반적인 진단 방법을 비롯하여 Univer 서비스의 관측성과 운영에 필요한 주요 진입점을 소개합니다.

## 관측성

Univer는 다음을 제공합니다.

- Prometheus 메트릭
- 서비스 로그(stdout + 영구 볼륨)

기본 제공 관측성 스택을 활성화하면 Grafana에서 대시보드를 볼 수 있습니다. 그렇지 않은 경우 대시보드를 사용 중인 시스템으로 내보내세요.

## 메트릭

기본 제공 Grafana 대시보드는 다음 항목을 다룹니다.

- 인프라: RabbitMQ, Redis, RDS
- 협업: collaboration-server
- 핵심 서비스: universer
- 가져오기/내보내기: exchange

이 대시보드를 사용하여 성능, 가용성, 비즈니스 KPI를 모니터링할 수 있습니다. 외부 시스템에서 사용하려면 다음 위치에서 대시보드를 다운로드하세요.

https://release-univer.oss-cn-shenzhen.aliyuncs.com/release/univer-grafana-dashboards.tar.gz

## 서비스 로그

### Docker Compose

로그는 stdout과 영구 볼륨에 기록되며 최대 30일 또는 1GB까지 보관됩니다.

- universer: `/logs/universer/`
- exchange: `/logs/worker-exchange/`

### K8s / Loki

기본 제공 관측성을 사용하면 Grafana -> Explore에서 Loki로 로그를 조회할 수 있습니다.

![Loki 검색](./sre-manual/loki-search.png)

## 일반적인 진단 방법

1. **기능 중단**: RDS/MQ/Redis의 SLI를 확인합니다.
2. **API 오류**: universer SLI와 오류 코드를 확인합니다.
3. **로그 검색**: Loki에서 `biz_code=xxx`를 조회합니다.
4. **용량 문제**: QPS, 지연 시간, CPU, 메모리를 모니터링합니다.
