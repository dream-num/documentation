---
title: API
---

本ページは Univer Server の主要 API をまとめています。デフォルトの Base URL は `http://localhost:8000` です。

> 注：`type` パラメータは `1`=Docs、`2`=Sheets。

## ドキュメント管理

### ドキュメント作成

<APITable
  request={{
    method: 'POST',
    url: '/universer-api/snapshot/{type}/unit/-/create',
    headers: <code>content-type: application/json</code>,
    parametersType: 'Body',
    parameters: [{
      name: 'type',
      type: 'enum(int)',
      required: true,
      description: '1（docs）、2（sheets）',
    }, {
      name: 'name',
      type: 'string',
      required: true,
      description: 'ドキュメント名',
    }, {
      name: 'creator',
      type: 'string',
      required: true,
      description: '作成者 ID',
    }],
    example: `curl http://localhost:8000/universer-api/snapshot/{type}/unit/-/create \\
    -X POST \\
    -H 'Content-Type: application/json' \\
    --data-raw '{"type":2,"name":"New Sheet By Univer","creator":"userID"}'`,
  }}
  response={{
    type: 'application/json',
    parameters: [{
      name: 'error',
      type: 'object',
      properties: [{
        name: 'code',
        type: 'enum(int)',
        description: '1（成功）',
      }, {
        name: 'message',
        type: 'string',
        description: 'エラーメッセージ',
      }],
    }, {
      name: 'unitID',
      type: 'string',
      description: 'ドキュメント ID',
    }],
    example: JSON.stringify({
      error: {
        code: 1,
        message: 'success',
      },
      unitID: 'ETVf-B4lQqOSE_p09mcp9Q',
    }, null, 2),
  }}
/>

### ドキュメント一覧

<APITable
  request={{
    method: 'GET',
    url: '/universer-api/snapshot/{type}/units',
    parametersType: 'Query',
    parameters: [{
      name: 'type',
      type: 'enum(int)',
      required: true,
      description: '1（doc）、2（sheet）',

  }}

    type: 'application/json',

      name: 'error',
      type: 'object',
      properties: [{
        name: 'code',
        type: 'enum(int)',

        description: 'エラーメッセージ',
      }],
    }, {
      name: 'units',
      type: 'array[object]',
      description: 'ドキュメント一覧',
      properties: [{
        name: 'unitID',
        type: 'string',
        description: 'ドキュメント ID',
      }, {
        name: 'name',
        type: 'string',
        description: 'ドキュメント名',
      }, {
        name: 'type',
        type: 'enum(int)',
        description: '1（doc）、2（sheet）',
      }],
    }, {
      name: 'nextCursor',
      type: 'string',

      },

        unitID: '1',

## ファイルとインポート/エクスポート

### ファイルアップロード

<APITable
  request={{
    method: 'POST',
    url: '/universer-api/stream/file/upload',
    headers: <code>content-type: multipart/form-data</code>,
    parametersType: 'Body',
    parameters: [{
      name: 'size',
      type: 'int',
      required: true,
      description: 'ファイルサイズ（byte）。実サイズと一致必須',
    }, {
      name: 'file',
      type: 'Form.file',
      required: true,
      description: 'HTML form の file',
    }],
    example: `curl 'http://localhost:8000/universer-api/stream/file/upload?size=125466' \\
    --header 'cookie: _univer=XXXXXX' \\
    --form 'file=@"demo.xlsx"'`,
  }}
  response={{
    type: 'application/json',
    parameters: [{
      name: 'FileId',
      type: 'string',
      description: 'ファイル ID',
    }],
    example: JSON.stringify({
      FileId: 'xxxx',
    }, null, 2),
  }}
/>

      description: '最小列数',

    example: `curl -X POST 'http://localhost:8000/universer-api/exchange/2/import' \\
    -H 'Content-Type: application/json' \\

  }}
  response={{
    type: 'application/json',
    parameters: [{
      name: 'error',
