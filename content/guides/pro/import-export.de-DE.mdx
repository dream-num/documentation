title: Import- und Exportdienst
---

Import/Export wird vom Server bereitgestellt und ermöglicht die Konvertierung von Office-Dateien in Univer-Dokumente oder den Export zurück in Office-Formate.

## Voraussetzungen

- Serverbereitstellung abgeschlossen (siehe [Schnellstart](/guides/pro/server))
- Exchange Worker und Temporal werden ausgeführt
- Objektspeicher ist erreichbar

## Importablauf

1. [Laden Sie das hoch Datei](/guides/pro/api#upload-file) in den Objektspeicher verschieben und `fileID` abrufen
2. Rufen Sie die [Importieren](/guides/pro/api#import-file)-API mit `outputType`
   - `1` auf: Import als Einheit Dokument
   - `2`: als JSON importieren
3. Abfragen [Aufgabenstatus auf](/guides/pro/api#get-task-result):
   - `pending`: Weiter abfragen
   - `done`: `import.unitID` abrufen oder `import.jsonID`
   - `failed`: lesen Sie `error.message`
4. Laden von Dokumenten
   - Beim Import als Einheitsdokument direkt mit `import.unitID` laden, siehe Abschnitt [Zusammenarbeit](/guides/sheets/features/collaboration)
   - Beim Import als JSON verwenden Sie `import.jsonID` zur [Datei abrufen](/guides/pro/api#get-file) Download-URL, dann verarbeiten Sie den JSON mit [Serverseitige Datenkonvertierung](/guides/sheets/features/import-export#server-side-data-conversion) vor dem Laden

## Exportieren Ablauf

Der Exportablauf für Einheits-Zusammenarbeitsdokumente:

1. Rufen Sie die [exportieren](/guides/pro/api#export-file) API mit `unitID` auf, um sie zu erhalten `taskID`
2. Umfrage [Aufgabenstatus](/guides/pro/api#get-task-result):
   - `pending`: Weiter abfragen
   - `done`: Holen Sie sich `export.fileID`
   - `failed`: `error.message` lesen
3. Verwenden Sie `export.fileID`, um [Datei abrufen](/guides/pro/api#get-file) herunterzuladen URL

![exportieren](./import-export/export.png)

Der Exportablauf für nicht kollaborative Dokumente:

1. [Laden](/guides/pro/api#upload-file) die aus dem Frontend-Snapshot-JSON generierte Datei in den Objektspeicher hoch und erhalten `fileID`
2. Rufen Sie die API [exportieren](/guides/pro/api#export-file) auf `jsonID`, um `taskID` zu erhalten; `jsonID` ist der `fileID` aus dem vorherigen Schritt
3. Umfrage [Aufgabenstatus](/guides/pro/api#get-task-result):
   - `pending`: Weiter abfragen
   - `done`: Holen Sie sich `export.fileID`
   - `failed`: `error.message` lesen
4. Verwenden Sie `export.fileID` zur [Datei abrufen](/guides/pro/api#get-file) Download-URL

## Implementierungsbeispiel

Die API-Aufrufe für den Import/Export sind bereits im Frontend integriert, siehe [Fassaden-API](/guides/sheets/features/import-export#facade-api) für Details.

Die folgenden Ausschnitte veranschaulichen einen vollständigen TypeScript-Workflow mit `fetch`. Ersetzen Sie `BASE_URL` durch Ihren Univer-Server-Endpunkt und fügen Sie den erforderlichen Authentifizierungsheader (z. B. `cookie` oder `Authorization`) in jede Anfrage ein.

### 1. Laden Sie eine Datei hoch

```typescript
async function uploadFile(file: File): Promise<string> {
  const formData = new FormData()
  formData.append('file', file)

  const res = await fetch(
    `${BASE_URL}/universer-api/stream/file/upload?size=${file.size}`,
    {
      method: 'POST',
      headers: {
        // Add your auth header here, e.g.
        // cookie: '_univer=XXXXXX',
      },
      body: formData,
    },
  )

  const data = await res.json()
  if (data.error?.code !== 1) {
    throw new Error(data.error?.message || 'Upload failed')
  }
  return data.FileId // used as fileID in the next step
}
```

### 2. Status der Umfrageaufgabe

```typescript
interface TaskResult {
  status: 'pending' | 'done' | 'failed'
  error?: { code: number, message: string }
  import?: { unitID?: string, jsonID?: string }
  export?: { fileID?: string }
}

async function pollTask(taskID: string, interval = 2000): Promise<TaskResult> {
  while (true) {
    const res = await fetch(
      `${BASE_URL}/universer-api/exchange/task/${taskID}`,
      {
        headers: {
          // cookie: '_univer=XXXXXX',
        },
      },
    )
    const data: TaskResult = await res.json()

    if (data.status === 'done' || data.status === 'failed') {
      return data
    }

    await new Promise(resolve => setTimeout(resolve, interval))
  }
}
```

### 3. Importieren Sie eine Datei

```typescript
interface ImportParams {
  fileID: string
  type: 1 | 2 // 1 = doc, 2 = sheet
  outputType: 1 | 2 // 1 = unit, 2 = json
  minSheetRowCount?: number
  minSheetColumnCount?: number
}

async function importFile(params: ImportParams): Promise<string> {
  const res = await fetch(
    `${BASE_URL}/universer-api/exchange/${params.type}/import`,
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        // cookie: '_univer=XXXXXX',
      },
      body: JSON.stringify({
        fileID: params.fileID,
        outputType: params.outputType,
        minSheetRowCount: params.minSheetRowCount ?? 1000,
        minSheetColumnCount: params.minSheetColumnCount ?? 20,
      }),
    },
  )

  const data = await res.json()
  if (data.error?.code !== 1) {
    throw new Error(data.error?.message || 'Import request failed')
  }

  // Poll until the task is done or failed
  const taskResult = await pollTask(data.taskID)
  if (taskResult.status === 'failed') {
    throw new Error(taskResult.error?.message || 'Import failed')
  }

  return params.outputType === 1
    ? taskResult.import!.unitID!
    : taskResult.import!.jsonID!
}
```

### 4. Eine Datei exportieren

```typescript
interface ExportParams {
  unitID: string
  jsonID: string
  type: 1 | 2 // 1 = doc, 2 = sheet
  sscSwitch?: boolean
}

async function exportFile(params: ExportParams): Promise<string> {
  const res = await fetch(
    `${BASE_URL}/universer-api/exchange/${params.type}/export`,
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        // cookie: '_univer=XXXXXX',
      },
      body: JSON.stringify({
        unitID: params.unitID,
        type: params.type,
        sscSwitch: params.sscSwitch ?? false,
      }),
    },
  )

  const data = await res.json()
  if (data.error?.code !== 1) {
    throw new Error(data.error?.message || 'Export request failed')
  }

  const taskResult = await pollTask(data.taskID)
  if (taskResult.status === 'failed') {
    throw new Error(taskResult.error?.message || 'Export failed')
  }

  // Get a signed download URL
  const urlRes = await fetch(
    `${BASE_URL}/universer-api/file/${taskResult.export!.fileID!}/sign-url`,
    {
      headers: {
        // cookie: '_univer=XXXXXX',
      },
    },
  )
  const urlData = await urlRes.json()
  if (urlData.error?.code !== 1) {
    throw new Error(urlData.error?.message || 'Failed to get download URL')
  }

  return urlData.url
}
```
