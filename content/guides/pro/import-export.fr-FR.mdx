---
title: Service d’import et d’export
---

Le serveur fournit les fonctionnalités d’import et d’export, qui permettent de convertir des fichiers Office en documents Univer ou d’exporter des documents Univer vers des formats Office.

## Prérequis

- Le déploiement du serveur est terminé (voir le [guide de démarrage rapide](/guides/pro/server))
- Le worker Exchange et Temporal sont en cours d’exécution
- Le stockage d’objets est accessible

## Processus d’import

1. [Chargez le fichier](/guides/pro/api#upload-file) dans le stockage d’objets et récupérez son `fileID`
2. Appelez l’API d’[import](/guides/pro/api#import-file) avec `outputType`
   - `1` : importer sous forme de document unit
   - `2` : importer au format JSON
3. Interrogez régulièrement l’[état de la tâche](/guides/pro/api#get-task-result) :
   - `pending` : continuer l’interrogation
   - `done` : récupérer `import.unitID` ou `import.jsonID`
   - `failed` : consulter `error.message`
4. Chargez le document
   - Pour un import sous forme de document unit, chargez-le directement avec `import.unitID`. Consultez la section [Collaboration](/guides/sheets/features/collaboration)
   - Pour un import au format JSON, utilisez `import.jsonID` afin d’[obtenir l’URL de téléchargement du fichier](/guides/pro/api#get-file), puis traitez le JSON avec la [conversion des données côté serveur](/guides/sheets/features/import-export#server-side-data-conversion) avant de le charger

## Processus d’export

Pour exporter un document unit collaboratif :

1. Appelez l’API d’[export](/guides/pro/api#export-file) avec `unitID` afin d’obtenir un `taskID`
2. Interrogez régulièrement l’[état de la tâche](/guides/pro/api#get-task-result) :
   - `pending` : continuer l’interrogation
   - `done` : récupérer `export.fileID`
   - `failed` : consulter `error.message`
3. Utilisez `export.fileID` pour [obtenir l’URL de téléchargement du fichier](/guides/pro/api#get-file)

![export](./import-export/export.png)

Pour exporter un document non collaboratif :

1. [Chargez](/guides/pro/api#upload-file) dans le stockage d’objets le fichier généré à partir du JSON de l’instantané côté client, puis récupérez son `fileID`
2. Appelez l’API d’[export](/guides/pro/api#export-file) avec `jsonID` afin d’obtenir un `taskID` ; `jsonID` correspond au `fileID` obtenu à l’étape précédente
3. Interrogez régulièrement l’[état de la tâche](/guides/pro/api#get-task-result) :
   - `pending` : continuer l’interrogation
   - `done` : récupérer `export.fileID`
   - `failed` : consulter `error.message`
4. Utilisez `export.fileID` pour [obtenir l’URL de téléchargement du fichier](/guides/pro/api#get-file)

## Exemple d’implémentation

Les appels aux API d’import et d’export sont déjà intégrés au client. Pour en savoir plus, consultez la [Facade API](/guides/sheets/features/import-export#facade-api).

Les extraits ci-dessous présentent un processus TypeScript complet utilisant `fetch`. Remplacez `BASE_URL` par le point de terminaison de votre serveur Univer et ajoutez à chaque requête l’en-tête d’authentification requis, par exemple `cookie` ou `Authorization`.

### 1. Charger un fichier

```typescript
async function uploadFile(file: File): Promise<string> {
  const formData = new FormData()
  formData.append('file', file)

  const res = await fetch(
    `${BASE_URL}/universer-api/stream/file/upload?size=${file.size}`,
    {
      method: 'POST',
      headers: {
        // Add your auth header here, e.g.
        // cookie: '_univer=XXXXXX',
      },
      body: formData,
    },
  )

  const data = await res.json()
  if (data.error?.code !== 1) {
    throw new Error(data.error?.message || 'Upload failed')
  }
  return data.FileId // used as fileID in the next step
}
```

### 2. Interroger l’état de la tâche

```typescript
interface TaskResult {
  status: 'pending' | 'done' | 'failed'
  error?: { code: number, message: string }
  import?: { unitID?: string, jsonID?: string }
  export?: { fileID?: string }
}

async function pollTask(taskID: string, interval = 2000): Promise<TaskResult> {
  while (true) {
    const res = await fetch(
      `${BASE_URL}/universer-api/exchange/task/${taskID}`,
      {
        headers: {
          // cookie: '_univer=XXXXXX',
        },
      },
    )
    const data: TaskResult = await res.json()

    if (data.status === 'done' || data.status === 'failed') {
      return data
    }

    await new Promise(resolve => setTimeout(resolve, interval))
  }
}
```

### 3. Importer un fichier

```typescript
interface ImportParams {
  fileID: string
  type: 1 | 2 // 1 = doc, 2 = sheet
  outputType: 1 | 2 // 1 = unit, 2 = json
  minSheetRowCount?: number
  minSheetColumnCount?: number
}

async function importFile(params: ImportParams): Promise<string> {
  const res = await fetch(
    `${BASE_URL}/universer-api/exchange/${params.type}/import`,
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        // cookie: '_univer=XXXXXX',
      },
      body: JSON.stringify({
        fileID: params.fileID,
        outputType: params.outputType,
        minSheetRowCount: params.minSheetRowCount ?? 1000,
        minSheetColumnCount: params.minSheetColumnCount ?? 20,
      }),
    },
  )

  const data = await res.json()
  if (data.error?.code !== 1) {
    throw new Error(data.error?.message || 'Import request failed')
  }

  // Poll until the task is done or failed
  const taskResult = await pollTask(data.taskID)
  if (taskResult.status === 'failed') {
    throw new Error(taskResult.error?.message || 'Import failed')
  }

  return params.outputType === 1
    ? taskResult.import!.unitID!
    : taskResult.import!.jsonID!
}
```

### 4. Exporter un fichier

```typescript
interface ExportParams {
  unitID: string
  jsonID: string
  type: 1 | 2 // 1 = doc, 2 = sheet
  sscSwitch?: boolean
}

async function exportFile(params: ExportParams): Promise<string> {
  const res = await fetch(
    `${BASE_URL}/universer-api/exchange/${params.type}/export`,
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        // cookie: '_univer=XXXXXX',
      },
      body: JSON.stringify({
        unitID: params.unitID,
        type: params.type,
        sscSwitch: params.sscSwitch ?? false,
      }),
    },
  )

  const data = await res.json()
  if (data.error?.code !== 1) {
    throw new Error(data.error?.message || 'Export request failed')
  }

  const taskResult = await pollTask(data.taskID)
  if (taskResult.status === 'failed') {
    throw new Error(taskResult.error?.message || 'Export failed')
  }

  // Get a signed download URL
  const urlRes = await fetch(
    `${BASE_URL}/universer-api/file/${taskResult.export!.fileID!}/sign-url`,
    {
      headers: {
        // cookie: '_univer=XXXXXX',
      },
    },
  )
  const urlData = await urlRes.json()
  if (urlData.error?.code !== 1) {
    throw new Error(urlData.error?.message || 'Failed to get download URL')
  }

  return urlData.url
}
```
