title: USIP 連携
---

Univer Pro はアカウントシステムを内蔵しません。認証・権限・業務連携が必要な場合は USIP（Univer Server Integration Protocol）を使用します。USIP は SPI で、Univer が仕様を定義し、貴社システムが実装します。

## 利用シーン

- ログイン必須のアクセス
- 役割に応じた権限制御
- 協作者情報や最終更新時刻の同期

## 連携フロー

1. USIP API を実装
2. デプロイ設定で USIP を有効化
3. クライアントから認証ヘッダーを透過

## USIP API

- 👥 アカウント：認証、ユーザー情報
- 🔒 権限：役割、協作者一覧
- 📄 ドキュメント：最終更新時刻

## USIP 設定

<Tabs items={['docker compose', 'K8s']}>
  <Tab label="docker compose">
    ```properties title=".env.custom"
    USIP_ENABLED=true
    USIP_URI_CREDENTIAL=https://your-domain/usip/credential
    USIP_URI_USERINFO=https://your-domain/usip/userinfo
    USIP_URI_ROLE=https://your-domain/usip/role
    USIP_URI_COLLABORATORS=https://your-domain/usip/collaborators
    USIP_URI_UNITEDITTIME=https://your-domain/usip/unit-edit-time

    AUTH_PERMISSION_ENABLE_OBJ_INHERIT=false
    AUTH_PERMISSION_CUSTOMER_STRATEGIES=
    ```
  </Tab>
  <Tab label="K8s">
    ```yaml title="values.yaml"
    universer:
      config:
        usip:
          enabled: true
          uri:
            userinfo: 'https://your-domain/usip/userinfo'
            collaborators: 'https://your-domain/usip/collaborators'
            role: 'https://your-domain/usip/role'
            credential: 'https://your-domain/usip/credential'
            unitEditTime: 'https://your-domain/usip/unit-edit-time'
        auth:
          permission:
            enableObjInherit: false
            customerStrategies: ''
    ```
  </Tab>
</Tabs>

**注意**：USIP を有効化する場合は 5 つの API をすべて設定・実装する必要があります。

## 権限モデル

Univer は RBAC を採用。固定ロールは `owner`、`editor`、`reader`。

既定の権限ポイント：

| 権限 | Enum | 説明 | 最低ロール | ロール値 |
|:-------|:---------|:-------|:-------|:-------|
| ManageCollaborator | 2 | 協作者の招待/削除 | owner | 2 |
| Copy | 6 | コピー | reader | 0 |
| Print | 3 | 印刷 | editor | 1 |
| Duplicate | 4 | ドキュメント複製 | editor | 1 |
| Share | 7 | 共有 | reader | 0 |
| Export | 8 | エクスポート | editor | 1 |
| Comment | 5 | コメント | reader | 0 |
| View | 0 | 閲覧 | reader | 0 |
| MoveSheet | 25 | シート移動 | editor | 1 |
| DeleteSheet | 26 | シート削除 | editor | 1 |
| HideSheet | 27 | シート非表示 | editor | 1 |
| CopySheet | 28 | シート複製 | editor | 1 |
| RenameSheet | 29 | シート名変更 | editor | 1 |
| CreateSheet | 30 | シート作成 | editor | 1 |
| SetCellStyle | 33 | セルスタイル | editor | 1 |
| SetCellValue | 34 | セル値 | editor | 1 |
| InsertHyperlink | 16 | ハイパーリンク | editor | 1 |
| Sort | 17 | ソート | editor | 1 |
| Filter | 18 | フィルタ | editor | 1 |
| PivotTable | 19 | ピボット | editor | 1 |
| RecoverHistory | 43 | 履歴復元 | editor | 1 |
| ViewHistory | 44 | 履歴閲覧 | reader | 0 |
| SelectProtectedCells | 31 | 保護範囲選択 | editor | 1 |
| SelectUnProtectedCells | 32 | 非保護範囲選択 | editor | 1 |
| SetRowStyle | 35 | 行スタイル | editor | 1 |
| SetColumnStyle | 36 | 列スタイル | editor | 1 |
| InsertRow | 37 | 行挿入 | editor | 1 |
| InsertColumn | 38 | 列挿入 | editor | 1 |
| DeleteRow | 39 | 行削除 | editor | 1 |
| DeleteColumn | 40 | 列削除 | editor | 1 |
| Delete | 42 | ドキュメント削除 | owner | 2 |
| CreatePermissionObject | 45 | 保護範囲/シート作成 | editor | 1 |

例：コピー/印刷を owner のみに制限：

```properties title=".env.custom"
AUTH_PERMISSION_CUSTOMER_STRATEGIES=[{"action": 3, "role": 2}, {"action": 6, "role": 2}]
```

K8s 設定：

```yaml title="values.yaml"
universer:
  config:
    auth:
      permission:
        customerStrategies: '[ {"action": 3, "role": 2}, {"action": 6, "role": 2} ]'
```

### オブジェクト権限の継承

既定では、ドキュメント owner が全保護範囲の owner になるわけではありません。継承を有効にする場合：

```properties title=".env.custom"
AUTH_PERMISSION_ENABLE_OBJ_INHERIT=true
```

K8s：

```yaml title="values.yaml"
universer:
  config:
    auth:
      permission:
        enableObjInherit: true
```

## クライアントヘッダー

カスタムヘッダー（Authorization など）を追加する場合は HTTPService のインターセプタを使用します：

<Tabs items={['プリセット', 'プラグイン']}>
  <Tab>
    ```typescript
    import { HTTPService } from '@univerjs/preset-sheets-core'

    const injector = univer.__getInjector()
    const httpService = injector.get(HTTPService)
    httpService.registerHTTPInterceptor({
      priority: 0,
      interceptor: (request, next) => {
        // request.headers.set('Authorization', 'Bearer your-token-here')
        return next(request)
      },
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    import { HTTPService } from '@univerjs/network'

    const injector = univer.__getInjector()
    const httpService = injector.get(HTTPService)
    httpService.registerHTTPInterceptor({
      priority: 0,
      interceptor: (request, next) => {
        // request.headers.set('Authorization', 'Bearer your-token-here')
        return next(request)
      },
    })
    ```
  </Tab>
</Tabs>

[編集履歴](/guides/sheets/features/edit-history) を使う場合は HistoryUniver にも同じ設定を適用します：

```typescript
historyLoaderService.historyUniver$.subscribe((historyUniver) => {
  if (!historyUniver) return

  const injector = historyUniver.__getInjector()
  const httpService = injector.get(HTTPService)
  httpService.registerHTTPInterceptor({
    priority: 0,
    interceptor: (request, next) => {
      // request.headers.set('Authorization', 'Bearer your-token-here')
      return next(request)
    },
  })
})
```

完全な例は [Univer Pro Sheet スターター](https://github.com/dream-num/univer-pro-sheet-start-kit/blob/main/src/setup-univer.ts) を参照してください。
