## 服務端部署

### 環境要求 [#evironment-requirements]

| 環境 | 要求 |
| ---- | ---- |
| 作業系統 | Linux、Mac、Windows(WSL) |
| CPU | 至少 1 核 |
| 記憶體 | 至少 2G，如果想支援較大檔案的匯入匯出，建議 >4G |
| 磁碟 | 至少 10G |
| Docker | 23 及以上版本 |

### 相容性

- Linux：建議核心版本 不低於 3.10.0（部分使用者在低版本核心下遇到相容性問題）
- Docker：版本 23 或更高
- Docker Compose：版本 2.21 或更高
- 資料庫：
  - MySQL：版本 8.0 或更高
  - PostgreSQL：版本 13 或更高
  - Redis：版本 5.0 或更高
  - 支援以 PostgreSQL 和 MySQL 連線方式的國產資料庫，以及達夢資料庫 V8 版本

### 一鍵部署

滿足以上要求後，你可以使用以下指令碼透過 docker compose 一鍵部署 Univer Pro 服務端：

```bash
bash -c "$(curl -fsSL https://get.univer.ai)"
```

更多詳細的部署方式和配置選項，請參考後續章節的[服務端部署](/guides/pro/server) 部分。

## 客戶端整合

Univer Pro 的預設和外掛的使用方式與 Univer 無異，你可以在對應的功能章節中找到它們的使用方式。

### 快速開始

如果你需要一個能夠快速上手的腳手架專案，我們準備了一個[Univer Pro 起步套件](https://github.com/dream-num/univer-pro-sheet-start-kit)，可以透過以下命令快速建立一個 Univer Pro 的專案：

<Tabs items={['npm', 'pnpm']}>
  <Tab>
    執行以下命令需要裝置安裝有 `nodejs >= 18`，`npm >= 8` 和 `git`。

    ```bash
    npx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    npm install
    npm run dev
    ```
  </Tab>
  <Tab>
    執行以下命令需要裝置安裝有 `nodejs >= 18`，`pnpm >= 7` 和 `git`。

    ```bash
    pnpm dlx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    pnpm install
    pnpm dev
    ```
  </Tab>
</Tabs>

<Callout>
  如果服務端部署在其他機器上，需要在 `vite.config.ts` 中把 `server` 配置中的 `localhost` 改為對應機器的 IP 地址。
</Callout>

🎉 如果一切順利，那麼恭喜你，你已成功建立整合了服務端的 Univer Pro 專案，訪問 http://localhost:5173/ 以體驗高階功能和協同編輯。
