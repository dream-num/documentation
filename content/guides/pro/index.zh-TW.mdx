## 上手路徑

- 先部署服務端（測試/本機）：[快速開始](/guides/pro/server)
- 了解授權與限制：[授權](/guides/pro/license)
- 整合到你的前端專案：見下方「用戶端整合」
- 面向生產的架構與設定：[生產部署](/guides/pro/deploy)
- 需要身分接入或事件同步：查看 [USIP 整合](/guides/pro/usip) 與 [事件同步](/guides/pro/event-sync)

<Callout type="warning">
  Univer Pro 的高級能力依賴服務端，請先完成服務端部署。
</Callout>

## 授權與限制

Univer Pro 以 [Univer 商業授權協議](https://univer.ai/license) 發佈。未授權可體驗，但會有浮水印、匯入體積、協作數量等限制，詳情以[定價](https://univer.ai/pricing)為準。

## 用戶端整合

如果你需要一個可快速啟動的專案，可以使用 Univer Pro 起步套件：

<Tabs items={['npm', 'pnpm']}>
  <Tab>
    執行以下命令需要安裝 `nodejs >= 18`、`npm >= 8` 與 `git`。

    ```bash
    npx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    npm install
    npm run dev
    ```
  </Tab>
  <Tab>
    執行以下命令需要安裝 `nodejs >= 18`、`pnpm >= 7` 與 `git`。

    ```bash
    pnpm dlx degit dream-num/univer-pro-sheet-start-kit univer-pro-sheet-start-kit
    cd univer-pro-sheet-start-kit
    pnpm install
    pnpm dev
    ```
  </Tab>
</Tabs>

<Callout>
  如果服務端部署在其他機器，請在 `vite.config.ts` 中將 `server` 設定裡的 `localhost` 改為服務端 IP 或網域。
</Callout>

如果一切順利，請打開 http://localhost:5173/ 體驗 Pro 功能與協作能力。
