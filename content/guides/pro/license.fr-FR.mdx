Les fonctionnalités avancées d’Univer Pro nécessitent une licence pour être utilisées sans restriction. Cette page explique comment obtenir, configurer et vérifier une licence.

## Quand une licence est-elle nécessaire ?

- Évaluation : aucune licence n’est requise, mais certaines fonctionnalités sont limitées (filigrane, taille des imports, quota de collaboration)
- Production : l’achat d’une licence est recommandé pour bénéficier d’un accès complet

Si vous n’avez pas encore déployé le serveur, consultez le [guide de démarrage rapide](/guides/pro/server).

## Obtenir une licence

1. Accédez à la [page des licences](/guides/pro/license) et connectez-vous
2. Téléchargez le fichier de licence

![Télécharger la licence](./license/new-02-cn.png)

### Licence d’essai gratuite

Vous pouvez demander une licence d’essai de 30 jours :

1. Accédez à la [page des licences](/guides/pro/license) et connectez-vous
2. Cliquez sur « Obtenir une licence d’essai »

![Obtenir une licence](./license/new-01-cn.png)

## Ajouter ou mettre à jour une licence

Décompressez `license-univer.zip` pour obtenir `license.txt` et `licenseKey.txt`. Ne modifiez pas ces fichiers.

### Utiliser la licence côté client

#### Mode prédéfini

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsAdvancedPreset({
      license: `Content from license.txt`,
    }),
  ],
})
```

#### Mode plugin

Après avoir créé l’instance Univer, enregistrez d’abord `UniverLicensePlugin` :

```typescript
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: `Content from license.txt`,
})
```

### Utiliser la licence côté serveur

<Tabs items={['docker compose', 'K8s']}>
  <Tab>
    1. Copiez `license.txt` et `licenseKey.txt` dans `/univer-server/configs/`
    2. Exécutez `bash run.sh restart` dans `univer-server`
  </Tab>
  <Tab>
    1. Installez ou mettez à niveau avec Helm :

    ```bash
    helm upgrade --install -n univer --create-namespace \
    --set global.istioNamespace="univer" \
    --set-file universer.license.licenseV2=$(YOUR_LICENSE_TXT_PATH) \
    --set-file universer.license.licenseKeyV2=$(YOUR_LICENSE_KEY_TXT_PATH) \
    univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
    ```
  </Tab>
</Tabs>

## Vérifier la licence

### Vérification côté client

- Une licence absente ou non valide entraîne l’affichage d’un filigrane et l’application de restrictions
- Une licence valide supprime ces restrictions

![Licence non valide](./license/new-06.png)

![Licence valide](./license/new-07.png)

### Vérification côté serveur

Accédez à `host:8000/universer-api/license/key` pour consulter les droits associés. En local :

`http://localhost:8000/universer-api/license/key`

```json
{
  "verify": "true",
  "release_type": "COMMERCIAL"
}
```

![Vérification de la licence côté serveur](./license/new-05.png)

## FAQ

1. Échec de la vérification : vérifiez la validité de la licence, l’intégrité des fichiers et le redémarrage du service
2. Le filigrane est toujours visible : vérifiez que la licence a bien été injectée côté client
3. Autres problèmes : contactez l’assistance
