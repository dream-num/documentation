## 匯入流程

1. 上傳檔案到物件儲存，獲取 `fileID` 返回值。
2. 用 `fileID` 引數呼叫匯入介面，同時設定匯出型別 `outputType`（1 匯入為 unit 文件，2 匯入以得到 json 資料），獲取 `taskID` 返回值。
3. 輪詢獲取轉換結果，根據 `status` 返回值處理：
    - `pending`：需要接著輪詢。
    - `done`：轉換成功，得到 `import.jsonID` 或 `import.unitID` 返回值。
    - `failed`：轉換失敗，根據 `error.message` 獲取錯誤資訊。
4. 如果你想得到 json 資料而不是 unit 文件，請使用 `import.jsonID` 調獲取檔案介面下載轉換結果。注意得到 json 資料後，還需要 [轉換一下](/guides/docs/features/import-export#服務端資料轉化) 才能使用到 Univer 中。

![import](./import-export/import.png)

## 匯出流程

1. 用 `unitID` 引數呼叫匯出介面，獲取 `taskID` 返回值。
2. 輪詢獲取轉換結果，根據 `status` 返回值處理：
    - `pending`：需要接著輪詢。
    - `done`：轉換成功，得到 `export.fileID` 返回值。
    - `failed`： 轉換失敗，根據 `error.message` 獲取錯誤資訊。
3. 使用 `export.fileID` 調獲取檔案介面下載轉換結果。
