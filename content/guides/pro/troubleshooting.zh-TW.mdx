---
title: 故障排查
---

本指南涵蓋安裝、啟動、存取、USIP、匯入匯出與升級等常見問題。

## 適用範圍

- Docker Compose 或 K8s 部署
- USIP 與事件同步整合
- 匯入/匯出異常

## 快速排查入口

| 症狀 | 立即執行 | 下一步 |
| --- | --- | --- |
| 一鍵腳本卡住 | `curl -I https://get.univer.ai` | 使用離線安裝包 |
| Demo UI 無法存取 | `cd univer-server && bash run.sh start` | `docker compose ps` |
| USIP Demo 8080 回 404 | 確認 `.env.custom` 有 `USIP_ENABLED=true` | `bash run.sh restart` |
| Helm 部署 Pod Pending | `kubectl describe pod` | 檢查映像/資源/PVC |
| 匯入匯出 Pending | 檢查 temporal/exchange/universer 日誌 | 見匯入匯出章節 |

## Docker Compose 常見問題

### 安裝失敗

1. 檢查網路：

```bash
curl -I https://get.univer.ai
dig get.univer.ai
```

2. Docker 安裝衝突：

```bash
systemctl status docker
ps -ef | grep dockerd
```

### 服務未啟動或反覆重啟

```bash
cd univer-server
bash run.sh start
docker compose ps
docker compose logs --tail=200 <service>
```

常見原因：埠衝突、`.env.custom` 未載入、資源不足。

### Demo UI 访问異常

- 埠衝突：`lsof -i :3010`
- WebSocket 斷線：檢查反向代理/跨域
- 自動建立文件失敗：查看 universer 日誌

## K8s 常見問題

### Pod Pending

```bash
kubectl describe pod <pod> -n univer
```

檢查：映像拉取、PVC、節點資源。

### CrashLoopBackOff

```bash
kubectl logs <pod> -n univer --previous
```

### Ingress / 網域無法存取

```bash
dig univer.example.com
kubectl get ingress -n univer
kubectl get endpoints -n univer
```

## USIP 問題

| 現象 | 說明 |
| --- | --- |
| 8080 無回應 | 確認已執行 `bash run.sh start-demo-usip` |
| 啟用 USIP 後 401/403 | 檢查 token 是否透傳、回傳 user 是否正確 |
| 設定無效 | 修改 `.env.custom` 後必須重啟 |

## 匯入/匯出 Pending

### 排查路徑

1. 關閉 VPN/代理 → `bash run.sh restart`
2. 服務狀態 → `docker compose ps`
3. Temporal 日誌 → `docker compose logs -f temporal`
4. Exchange 日誌 → `docker compose logs -f univer-worker-exchange`
5. Universer 日誌 → `docker compose logs -f universer`

### 常見錯誤

- Temporal 啟動失敗：埠衝突或資料庫異常
- Exchange 連線逾時：檢查 Temporal 位址

範例：修改 `exchange/config.yaml.template` 後重啟：

```text
addr: no-txt:///${TEMPORAL_HOST}:${TEMPORAL_PORT}
```

## 升級與解除安裝

- Docker Compose 升級：在父目錄重新執行安裝腳本
- K8s 升級：`helm upgrade --install ... -n univer`
- 解除安裝後仍有資料：檢查 PVC 回收策略或掛載卷

## 日誌與收集

| 服務 | 指令 |
| --- | --- |
| temporal | `docker compose logs -f temporal` |
| exchange | `docker compose logs -f univer-worker-exchange` |
| universer | `docker compose logs -f universer` |

打包日誌：

```bash
mkdir -p logs_collect && \
docker compose logs temporal > logs_collect/temporal.log 2>&1 && \
docker compose logs universer > logs_collect/universer.log 2>&1 && \
tar czf univer-troubleshoot-logs.tar.gz logs_collect
```

## 排查 Checklist

- 服務皆為 Up / Pod Ready
- temporal/exchange 無明顯錯誤
- 埠與網域可存取
- 設定修改已重啟生效
- 匯入匯出任務可完成
