title: Лицензия
---

Для полного доступа к расширенным возможностям Univer SDK Pro требуется лицензия. На этой странице описано, как получить, настроить и проверить лицензию.

## Когда требуется лицензия

- Оценка: лицензия не требуется, но возможности ограничены (водяной знак, размер импорта, квота на совместную работу)
- Рабочая среда: для полного доступа рекомендуется приобрести лицензию

Если вы ещё не развернули сервер, см. [Краткое руководство](/guides/pro/server).

## Получение лицензии

1. Перейдите на [страницу лицензии](/guides/pro/license) и войдите в систему
2. Скачайте файл лицензии

![Скачивание лицензии](./license/new-02-cn.png)

### Бесплатная пробная лицензия

Вы можете запросить пробную лицензию на 30 дней:

1. Перейдите на [страницу лицензии](/guides/pro/license) и войдите в систему
2. Нажмите «Получить пробную лицензию»

![Получение лицензии](./license/new-01-cn.png)

## Добавление или обновление лицензии

Распакуйте `license-univer.zip`, чтобы получить `license.txt` и `licenseKey.txt`. Не изменяйте эти файлы.

### Использование лицензии в клиенте

#### Режим предустановки

```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'

const { univerAPI } = createUniver({
  presets: [
    UniverSheetsAdvancedPreset({
      license: `Content from license.txt`,
    }),
  ],
})
```

#### Режим плагина

После создания экземпляра Univer первым зарегистрируйте `UniverLicensePlugin`:

```typescript
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: `Content from license.txt`,
})
```

### Использование лицензии на сервере

<Tabs items={['docker compose', 'K8s']}>
  <Tab>
    1. Скопируйте `license.txt` и `licenseKey.txt` в `/univer-server/configs/`
    2. Выполните `bash run.sh restart` в `univer-server`
  </Tab>
  <Tab>
    1. Установите или обновите с помощью Helm:

    ```bash
    helm upgrade --install -n univer --create-namespace \
    --set global.istioNamespace="univer" \
    --set-file universer.license.licenseV2=$(YOUR_LICENSE_TXT_PATH) \
    --set-file universer.license.licenseKeyV2=$(YOUR_LICENSE_KEY_TXT_PATH) \
    univer-stack oci://univer-acr-registry.cn-shenzhen.cr.aliyuncs.com/helm-charts/univer-stack
    ```
  </Tab>
</Tabs>

## Проверка лицензии

### Проверка на клиенте

- При отсутствии или недействительности лицензии отображается водяной знак и действуют ограничения
- Действительная лицензия снимает ограничения

![Недействительная лицензия](./license/new-06.png)

![Действительная лицензия](./license/new-07.png)

### Проверка на сервере

Перейдите по адресу `host:8000/universer-api/license/key`, чтобы проверить доступные возможности. Для локальной среды:

`http://localhost:8000/universer-api/license/key`

```json
{
  "verify": "true",
  "release_type": "COMMERCIAL"
}
```

![Проверка лицензии на сервере](./license/new-05.png)

## Часто задаваемые вопросы

1. Проверка не пройдена: проверьте срок действия лицензии, целостность файлов и перезапуск службы
2. Водяной знак не исчез: убедитесь, что лицензия передана на стороне клиента
3. Другие проблемы: обратитесь в службу поддержки
