Univer 遵循 [語義化版本控制](https://semver.org/lang/zh-TW/)（`MAJOR.MINOR.PATCH`）。

- **MAJOR（主版本）**：不相容的 API 變更
- **MINOR（次版本）**：新增功能，向後相容
- **PATCH（修訂版本）**：問題修復，向後相容

## 發布渠道

| 渠道 | 穩定性 | 適用場景 |
|------|--------|----------|
| 穩定版 (`latest`) | 生產環境可用 | 生產部署 |
| 測試版 (`beta`) | 功能完整，測試中 | 生產前驗證 |
| 預覽版 (`alpha`) | 開發中 | 早期體驗、回饋 |
| 每夜版 (`nightly`) | 最新提交 | 前沿功能測試 |

你可以透過 npm 標籤安裝特定渠道：

```bash
npm install @univerjs/core@latest
npm install @univerjs/core@beta
npm install @univerjs/core@alpha
npm install @univerjs/core@nightly
```

> **重要**：Alpha、Beta 和每夜版可能包含缺陷或未完成的功能，請避免在生產環境中使用。

## 版本歷史

所有版本的發布說明均發布在 [GitHub Releases](https://github.com/dream-num/univer/releases)。

### 如何升級

1. 查看 [發布說明](https://github.com/dream-num/univer/releases) 了解破壞性變更
2. 將所有 `@univerjs/*` 套件更新到相同的目標版本
3. 執行你的測試套件
4. 如遇到問題，請查看 [故障排查](/guides/troubleshooting) 指南

### 棄用策略

- 標記為棄用的功能至少會再維護一個次版本
- 棄用的 API 會在開發建置中輸出警告
- 遷移路徑會在發布說明中記錄
