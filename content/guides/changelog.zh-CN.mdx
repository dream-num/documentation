Univer 遵循 [语义化版本控制](https://semver.org/lang/zh-CN/)（`MAJOR.MINOR.PATCH`）。

- **MAJOR（主版本）**：不兼容的 API 变更
- **MINOR（次版本）**：新增功能，向后兼容
- **PATCH（修订版本）**：问题修复，向后兼容

## 发布渠道

| 渠道 | 稳定性 | 适用场景 |
|------|--------|----------|
| 稳定版 (`latest`) | 生产环境可用 | 生产部署 |
| 测试版 (`beta`) | 功能完整，测试中 | 生产前验证 |
| 预览版 (`alpha`) | 开发中 | 早期体验、反馈 |
| 每夜版 (`nightly`) | 最新提交 | 前沿功能测试 |

你可以通过 npm 标签安装特定渠道：

```bash
npm install @univerjs/core@latest
npm install @univerjs/core@beta
npm install @univerjs/core@alpha
npm install @univerjs/core@nightly
```

> **重要**：Alpha、Beta 和每夜版可能包含缺陷或未完成的功能，请避免在生产环境中使用。

## 版本历史

所有版本的发布说明均发布在 [GitHub Releases](https://github.com/dream-num/univer/releases)。

### 如何升级

1. 查看 [发布说明](https://github.com/dream-num/univer/releases) 了解破坏性变更
2. 将所有 `@univerjs/*` 包更新到相同的目标版本
3. 运行你的测试套件
4. 如遇到问题，请查看 [故障排查](/guides/troubleshooting) 指南

### 弃用策略

- 标记为弃用的功能至少会再维护一个次版本
- 弃用的 API 会在开发构建中输出警告
- 迁移路径会在发布说明中记录
