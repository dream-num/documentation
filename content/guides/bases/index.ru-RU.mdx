## Что такое Univer Bases

Univer Bases - это продукт структурированных данных в Univer Office SDK. Он предназначен для приложений, организованных вокруг набора записей, а не сетки рабочих листов: легкие базы данных, рабочие процессы контента, трекеры утверждения, таблицы в стиле CRM и внутренние инструменты.

Базы являются частью [Web SDK](/guides/sheets), которая обрабатывает встроенные редакторы и безголовую обработку контента. [Server SDK](/server) предоставляет модули для совместной работы и обмена файлами, а [AI SDK](/ai) дает агенту доступ к записям.

Базы - это отдельный тип блока в Web SDK. Базовый пакет владеет таблицами, полями, записями, представлениями, вычислением формул, поиском, командами и мутациями совместной работы. Пакет UI отображает автономный рабочий стол и встроенные представления.

## Совместимость с браузерами

Web SDK компилируется с целью Chrome 88, но это не означает, что все основные среды полностью поддерживаются.

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK полагается на `Intl.Segmenter`. Если ваш браузер или среда выполнения не поддерживает его, сначала добавьте соответствующий полифилл. Мы рекомендуем `@formatjs/intl-segmenter` .
</Callout>

Если возникает проблема совместимости, попробуйте сначала сопоставить полифилл. Если проблема сохраняется, [Представить вопрос](https://github.com/dream-num/univer/issues/new/choose).

## Совместимость с Node.js

<Callout type="warning">
  Этот раздел охватывает только запуск Web SDK в среде Node.js. Он не применяется, когда вы используете инструменты сборки на основе Node.js для запуска Web SDK на браузере.
</Callout>

Web SDK работает на Node.js v18.17.0 и более поздней версии.

## Как читать документацию

Навигация по документации появляется слева. Страницы заказываются от базовых до расширенных, поэтому вы можете прочитать их по порядку при создании приложения, или перейти непосредственно на страницы, которые соответствуют вашему случаю использования. Вы также можете переключиться на документацию Univer Bases в верхней части боковой панели.

Таблица содержимого справа перемещается между разделами текущей страницы. Чтобы быстро найти страницу, используйте строку поиска вверху или ярлык Ctrl+K / Cmd+K.

Начните с руководства [Быстрый старт](/guides/bases/getting-started/installation).

## Необходимые знания

Документация должна быть доступной, но она предполагает некоторые базовые знания, чтобы страницы могли сосредоточиться на Web SDK.

Страницы наиболее полезны с базовым пониманием JavaScript и его экосистемы.Если вы планируете запустить Web SDK на Node.js, базовое понимание Node.js также помогает.
