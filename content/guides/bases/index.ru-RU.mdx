## Что такое Univer Bases

Univer Bases — продукт Univer SDK Pro для работы со структурированными данными. Он предназначен для приложений, где основной объект — набор записей, а не сетка листа: например, для простых баз данных, процессов работы с контентом, трекеров согласований, таблиц в стиле CRM и внутренних инструментов.

Bases — самостоятельный тип юнита Univer SDK. Основной пакет отвечает за таблицы, поля, записи, представления, вычисление формул, поиск, команды и мутации совместного редактирования. UI-пакет отображает автономную рабочую область и встроенные представления.


## Совместимость с браузерами

Univer SDK компилируется для Chrome 88, но это не означает полной поддержки всех распространённых сред. Мы стремимся обеспечить стабильную работу Univer SDK в следующих браузерах и средах Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK использует `Intl.Segmenter`. Если ваш браузер или среда выполнения не поддерживает этот API, сначала добавьте
  соответствующий полифил. Мы рекомендуем `@formatjs/intl-segmenter`.
</Callout>

Если возникли проблемы с совместимостью, сначала попробуйте устранить их с помощью подходящих полифилов. Если проблема сохраняется, [создайте issue](https://github.com/dream-num/univer/issues/new/choose).

## Совместимость с Node.js

<Callout type="warning">
  Примечание: это относится только к запуску Univer SDK в среде Node.js и не относится к случаям, когда Univer SDK запускается в
  браузере с помощью инструментов сборки на базе Node.js.
</Callout>

Univer SDK может работать в среде Node.js и поддерживает версии v18.17.0 и выше.

## Основные возможности

- **Таблицы, поля и записи**: хранение типизированных полей и упорядоченных записей в каждой таблице.
- **Несколько представлений**: отображение одних и тех же записей в виде сетки, канбан-доски, календаря, диаграммы Ганта или галереи.
- **Редактирование через команды**: изменения модели проходят через единый слой команд с разрешениями и точками подключения для необязательной истории и совместного редактирования.
- **Поля с формулами**: подключение полей Base к конвейеру вычисления формул Univer SDK.
- **Рабочая область в браузере**: отрисовка представлений, выделение, редактирование, буфер обмена, прокрутка и панели.
- **Хранение данных**: создание, восстановление и сохранение `IBaseSnapshot` без прямого изменения работающего снимка.

## Как читать документацию

Слева на экране находится панель навигации по документации. Страницы расположены последовательно — от базовых тем к более сложным, поэтому при создании приложения их можно изучать шаг за шагом. При этом вы можете читать их в любом порядке или сразу переходить к тем страницам, которые относятся к вашему сценарию. В верхней части боковой панели также можно выбрать Univer Bases.

Справа на экране находится оглавление, с помощью которого удобно переходить между разделами страницы. Чтобы быстро найти нужную страницу, воспользуйтесь строкой поиска вверху или сочетанием клавиш для поиска (Ctrl+K или Cmd+K).

Для начала ознакомьтесь с руководством [«Быстрый старт»](/guides/bases/getting-started/quickstart).

## Необходимые знания

Хотя наша документация рассчитана на начинающих, для её ясности и сосредоточенности на Univer SDK мы предполагаем некоторый базовый уровень знаний.

Чтобы получить от документации максимум пользы, рекомендуем знать основы JavaScript и его экосистемы.

Если вы хотите запускать Univer SDK в Node.js, также потребуется базовое понимание Node.js.

Если вы хотите попробовать Univer SDK Pro и развернуть Univer Server, рекомендуем знать основы Linux, Docker и Docker Compose (или Kubernetes).
