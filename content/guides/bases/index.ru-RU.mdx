## Что такое Univer Bases

Univer Bases — продукт Univer Pro для работы со структурированными данными. Он предназначен для приложений, где основной объект — набор записей, а не сетка листа: например, для простых баз данных, процессов работы с контентом, трекеров согласований, таблиц в стиле CRM и внутренних инструментов.

Bases — самостоятельный тип юнита Univer. Основной пакет отвечает за таблицы, поля, записи, представления, вычисление формул, поиск, команды и мутации совместного редактирования. UI-пакет отображает автономную рабочую область и встроенные представления.

## Когда использовать Bases

Используйте Bases, если пользователям нужны структурированные записи с типами полей, отфильтрованными представлениями, сортировкой, группировкой и разными способами отображения одних и тех же данных. Если пользователи в основном редактируют ячейки электронной таблицы, используйте [Univer Sheets](/guides/sheets). Если им нужен холст свободной формы, используйте [Univer Boards](/guides/boards).

## Установка пакетов

```bash
pnpm add @univerjs-pro/bases @univerjs-pro/bases-ui
```

## Состав пакетов

- `@univerjs-pro/bases`: модель данных Bases, команды для таблиц, полей, записей и представлений, мутации совместного редактирования JSON1, интеграция формул, плагины полей, поиск, фасадные API и `UniverBasesPlugin`
- `@univerjs-pro/bases-ui`: автономная рабочая область, представления в виде таблицы, календаря, канбана, галереи и диаграммы Ганта, редакторы полей, панель сведений о записи, операции панели инструментов и контекстного меню, модули рендеринга и `UniverBasesUIPlugin`

## Регистрация плагинов

Ниже показана часть настройки, относящаяся к Bases. Для полноценного приложения также нужны общие плагины ядра Univer, движка рендеринга, интерфейса, лицензии и движка формул.

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/bases/facade'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```
