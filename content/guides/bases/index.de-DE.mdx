## Was ist Univer Bases

Univer Bases ist das strukturierte Datenprodukt in Univer Pro. Es ist für Anwendungen konzipiert, bei denen das primäre Objekt eine Reihe von Datensätzen und nicht ein Arbeitsblattraster ist: Einfache Datenbanken, Inhaltsworkflows, Genehmigungs-Tracker, Tabellen im CRM-Stil und interne Tools eignen sich gut.

Bases ist ein unabhängiger Univer-Einheitentyp. Das Kernpaket besitzt Tabellen, Felder, Datensätze, Ansichten, Formelberechnung, Suche, Befehle und Kollaborationsmutationen. Das UI-Paket rendert die eigenständige Workbench und die integrierten Ansichten.

## Wann Bases verwendet werden sollten

Verwenden Sie Bases, wenn Benutzer strukturierte Datensätze mit Feldtypen, gefilterten Ansichten, Sortierung, Gruppierung und verschiedenen Projektionen über dieselben Daten benötigen. Wenn Benutzer hauptsächlich Zellen in einer Tabelle bearbeiten, verwenden Sie [Univer Sheets](/guides/sheets). Wenn sie eine Freiform-Leinwand benötigen, verwenden Sie [Univer Boards](/guides/boards).

## Pakete installieren

```bash
pnpm add @univerjs-pro/bases @univerjs-pro/bases-ui
```

## Paketzuordnung

- `@univerjs-pro/bases`: Basisdatenmodell, Tabellen-/Feld-/Datensatz-/Ansichtsbefehle, JSON1-Kollaborationsmutationen, Formelintegration, Feld-Plugins, Suche, Fassaden-APIs und `UniverBasesPlugin`
- `@univerjs-pro/bases-ui`: eigenständige Workbench, Raster-/Kalender-/Kanban-/Galerie-/Gantt-Ansichten, Feldeditoren, Datensatzdetailfenster, Symbolleisten- und Kontextmenüoperationen, Rendermodule und `UniverBasesUIPlugin`

## Plugins registrieren

Das Snippet unten zeigt den Bases-spezifischen Teil des einrichten. Eine vollständige Anwendung benötigt außerdem den gemeinsamen Univer-Kern, die Render-Engine, die Benutzeroberfläche, die Lizenz und die Formel-Engine-Plugins.

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/bases/facade'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```
