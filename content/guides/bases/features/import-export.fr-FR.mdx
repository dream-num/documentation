Bases importe **XLSX, XLS, CSV et TSV** et exporte **XLSX, CSV et TSV**. Un flux commun est d'importer une liste de clients Excel, d'ajouter des champs et des vues, puis d'exporter à nouveau les données du tableau.

Ces API nécessitent un moteur de conversion. Compléter d'abord [intégration d'échange de fichiers](/server/import-export) et confirmer que le moteur prend en charge le type de document Bases et les formats requis.

## Formats pris en charge

Le tableau couvre les API du navigateur décrites sur cette page. La conversion des fichiers Office nécessite toujours un moteur de recherche qui prend en charge le même type de document et le même format.

| Import | Export |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV et TSV exportent une seule table, qui est sélectionnée avec `tableId`. Aucun format ne conserve les vues, les permissions ou toute autre ressource de base. Pour une sauvegarde complète de l'application, sauvegardez plutôt un instantané de base.

## Installer et enregistrer

Installez ces paquets dans un [Éditeur de bases initialisé](/guides/bases/getting-started/installation) :

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/bases-exchange-client
```

```ts
import { UniverBasesExchangeClientPlugin } from '@univerjs-pro/bases-exchange-client'
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client'

import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-exchange-client/facade'
import '@univerjs-pro/exchange-client/facade'

univer.registerPlugin(UniverExchangeClientPlugin, exchangeConfig)
univer.registerPlugin(UniverBasesExchangeClientPlugin)
```

`exchangeConfig` contient les paramètres de téléchargement, de conversion, de requête et de téléchargement de l'application. Le [guide d'intégration](/server/import-export) décrit comment le préparer.

`UniverExchangeClientPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `downloadEndpointUrl` | `string` | `location.origin` | URL de base pour les téléchargements de fichiers. |
| `uploadFileServerUrl` | `string` | `'/universer-api/stream/file/upload'` | Point d'arrivée qui reçoit les téléchargements. |
| `importServerUrl` | `string` | `'/universer-api/exchange/{type}/import'` | Point d'extrémité qui démarre une importation. Gardez le porte-place `{type}`. |
| `exportServerUrl` | `string` | `'/universer-api/exchange/{type}/export'` | Point d'extrémité qui démarre une exportation. Gardez le détenteur de place `{type}`. |
| `getTaskServerUrl` | `string` | `'/universer-api/exchange/task/{taskID}'` | Endpoint qui signale l'état de la tâche. Gardez le détenteur de place `{taskID}`. |
| `signUrlServerUrl` | `string` | `'/universer-api/file/{fileID}/sign-url'` | Endpoint qui signe les URLs de fichier. Gardez le porte-place `{fileID}`. |
| `maxTimeoutTime` | `number` | `120000` | Temps maximum de vote pour une tâche de conversion, en millisecondes. |

### Configurer la conversion Excel [#excel-conversion]

`UniverBasesExchangeClientPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `importSourceMode` | `ExchangeBaseImportMode` | `AUTO` | Indique s'il faut importer Excel les tableaux, les feuilles de travail ou les deux. |
| `importFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `CONVERT_THEN_VALUES` | Comment traiter les formules à l'importation. |
| `exportStructureMode` | `ExchangeBaseExportMode` | `TABLES` | Indique s'il faut exporter des tables ou des plages de feuilles de travail natives Excel. |
| `exportFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `FAIL` | Comment traiter les formules lors de l'exportation. |

Pour modifier le comportement de conversion, passez les options au plugin d'échange Bases. Les valeurs ci-dessous sont les valeurs par défaut, et cette inscription remplace celle ci-dessus:

```ts
import {
  ExchangeBaseExportMode,
  ExchangeBaseFormulaPolicy,
  ExchangeBaseImportMode,
} from '@univerjs-pro/exchange-client'

univer.registerPlugin(UniverBasesExchangeClientPlugin, {
  importSourceMode: ExchangeBaseImportMode.AUTO,
  importFormulaPolicy: ExchangeBaseFormulaPolicy.CONVERT_THEN_VALUES,
  exportStructureMode: ExchangeBaseExportMode.TABLES,
  exportFormulaPolicy: ExchangeBaseFormulaPolicy.FAIL,
})
```

- Source d'importation : `AUTO` importe automatiquement des tableaux Excel et des feuilles de travail visibles. `TABLES` importations uniquement des tableaux Excel, `SHEETS` importation des feuilles de calcul visibles et `HYBRID` importer les tables Excel plus toute feuille de travail visible qui n'a pas de tableau Excel correspondant.
- Structure d'exportation: `TABLES` convertit les tables de base non vides en tables Excel natives et laisse les tables vides comme des plages ordinaires. `RANGES` écrit chaque table comme une plage ordinaire de feuilles de travail.
- Formules: pendant l'importation, Univer convertit les formules qu'il peut et revient aux résultats mis en cache pour les formules que le moteur ne supporte pas. Pendant l'exportation, la conversion doit réussir à moins que la politique ne soit modifiée: `VALUES` écrit uniquement les résultats mis en place, et `TEXT` conserve la formule source comme texte. `CONVERT_THEN_VALUES` échoue toujours à l'exportation lorsqu'une formule ne peut pas être convertie.

## Importer pour modifier dans la page

L'argument `file` peut être un `File` sélectionné par l'utilisateur ou une URL pointant vers un fichier distant. L'appel renvoie un instantané de données de base que l'éditeur peut charger :

```ts
const snapshot = await univerAPI.importBaseToSnapshotAsync(file)
if (snapshot) {
  univerAPI.createBase(snapshot)
}
```

Importer un instantané ne nécessite pas de collaboration, mais le fichier doit encore être converti sur le serveur. Si les utilisateurs doivent revenir à la base plus tard, stocker le résultat de `base.save()` comme décrit dans [Enregistrer et restaurer des instantanés](/guides/bases/model/base-snapshot).

## Exporter un fichier

Pour exporter la base actuelle sous la forme de Excel :

```ts
import { ExchangeFormat } from '@univerjs-pro/exchange-client'

const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

const file = await univerAPI.exportBaseBySnapshotAsync(base.save(), ExchangeFormat.XLSX)
if (file) {
  univerAPI.downloadFile(file, 'database', ExchangeFormat.XLSX)
}
```

CSV et TSV ne peuvent représenter qu'une seule table, alors passez explicitement `tableId` lors de l'exportation d'une base qui a plus d'une table:

```ts
const table = base.getTables()[0]
if (!table) throw new Error('Create a table first')

const file = await univerAPI.exportBaseBySnapshotAsync(
  base.save(),
  ExchangeFormat.CSV,
  table.getId(),
)
if (file) {
  univerAPI.downloadFile(file, table.getName(), ExchangeFormat.CSV)
}
```

Pour TSV, remplacez `ExchangeFormat.CSV` par `ExchangeFormat.TSV`. L'exportation de fichiers est destinée à l'échange de données de table. Pour une sauvegarde complète, enregistrez l'instantané de base; CSV ne conserve pas les vues, les permissions ou toute autre ressource.

## Importer un document collaboratif

Configurez d'abord [Bases de collaboration](/guides/bases/features/collaboration), puis importez le document et chargez l'ID retourné par le serveur :

```ts
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importBaseToUnitIdAsync(file)
if (unitId) {
  await univerAPI.getCollaboration().loadBaseAsync(unitId)
}
```

Pour exporter un document de serveur, appelez `exportBaseByUnitIdAsync(unitId, format, tableId?)`. Attendez que les modifications du navigateur en attente finissent de synchroniser avant d'exporter.

Vérifier la conversion des champs et des formules avec des fichiers d'application réels. Ces méthodes peuvent renvoyer `undefined` et peuvent lancer des erreurs de requête ou de conversion, donc gérer les deux cas dans l'interface utilisateur.
