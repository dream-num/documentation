ベースは**XLSX、XLS、CSV、TSV**をインポートし、**XLSX、CSV、TSV**エクスポートします。 一般的なフローは、Excelの顧客リストをインポートし、[フィールドとビューを追加]、そして再びテーブルデータをエクスポートすることです。

これらの API は変換バックエンドが必要です。[ファイル交換統合](/server/import-export) を最初に完了し、バックエンドが Bases のドキュメントタイプと必要なフォーマットをサポートすることを確認します。

## 対応形式

表は、このページに記載されているブラウザ API をカバーしています。Office ファイルを変換しても、同じドキュメントタイプとフォーマットをサポートするバックエンドが必要です。

| インポート | エクスポート |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV と TSV は、`tableId` で選択した単一のテーブルをエクスポートします。各フォーマットは、ビュー、パーミッション、または他のベースリソースを保存します。アプリケーションの完全なバックアップについては、代わりにベーススナップショットを保存します。

## インストールと登録

[初期化ベースエディタ](/guides/bases/getting-started/installation)にこれらのパッケージをインストールします。

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/bases-exchange-client
```

```ts
import { UniverBasesExchangeClientPlugin } from '@univerjs-pro/bases-exchange-client'
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client'

import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-exchange-client/facade'
import '@univerjs-pro/exchange-client/facade'

univer.registerPlugin(UniverExchangeClientPlugin, exchangeConfig)
univer.registerPlugin(UniverBasesExchangeClientPlugin)
```

`exchangeConfig`には、アプリケーションのアップロード、変換、タスククエリ、およびダウンロード設定が含まれています。 [統合ガイド](/server/import-export)は、それを準備する方法について説明します。

`UniverExchangeClientPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `downloadEndpointUrl` | `string` | `location.origin` | ファイルのダウンロードのためのベースURL。 |
| `uploadFileServerUrl` | `string` | `'/universer-api/stream/file/upload'` | アップロードを受け取るエンドポイント。 |
| `importServerUrl` | `string` | `'/universer-api/exchange/{type}/import'` | インポートを開始するエンドポイント。`{type}`プレースホルダーをキープします。 |
| `exportServerUrl` | `string` | `'/universer-api/exchange/{type}/export'` | エクスポートを開始するエンドポイント。 `{type}`プレースホルダーをキープします。 |
| `getTaskServerUrl` | `string` | `'/universer-api/exchange/task/{taskID}'` | タスクの状態を報告するエンドポイント。`{taskID}`プレースホルダーをキープします。 |
| `signUrlServerUrl` | `string` | `'/universer-api/file/{fileID}/sign-url'` | ファイルURLを標識するエンドポイント。`{fileID}`プレースホルダーをキープします。 |
| `maxTimeoutTime` | `number` | `120000` | 変換タスクの最大ポーリング時間、ミリ秒単位。 |

### Excel 変換の設定 [#excel-conversion]

`UniverBasesExchangeClientPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `importSourceMode` | `ExchangeBaseImportMode` | `AUTO` | Excelテーブル、ワークシート、または両方をインポートするかどうか。 |
| `importFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `CONVERT_THEN_VALUES` | インポートの式を処理する方法。 |
| `exportStructureMode` | `ExchangeBaseExportMode` | `TABLES` | ネイティブExcelテーブルやワークシートの範囲をエクスポートするかどうか。 |
| `exportFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `FAIL` | 輸出の式を処理する方法。 |

変換動作を変更するには、ベース交換プラグインにオプションを渡します。 以下の値はデフォルトであり、この登録は上記1つを置き換えます。

```ts
import {
  ExchangeBaseExportMode,
  ExchangeBaseFormulaPolicy,
  ExchangeBaseImportMode,
} from '@univerjs-pro/exchange-client'

univer.registerPlugin(UniverBasesExchangeClientPlugin, {
  importSourceMode: ExchangeBaseImportMode.AUTO,
  importFormulaPolicy: ExchangeBaseFormulaPolicy.CONVERT_THEN_VALUES,
  exportStructureMode: ExchangeBaseExportMode.TABLES,
  exportFormulaPolicy: ExchangeBaseFormulaPolicy.FAIL,
})
```

- インポートソース: `AUTO` は、Excel テーブルと表示されるワークシートを自動的にインポートします。 `TABLES`は Excelテーブルのみをインポートします。`SHEETS` Z は、表示されたワークシートをインポートし、`HYBRID`表を Excelのテーブルと、対応するExcel卓がない任意の目に見えるワークシートを読み込みます。
- エクスポート構造: `TABLES`は、非空中ベーステーブルをネイティブExcelテーブルに変換し、通常の範囲として空のテーブルを残します。 `RANGES`は通常ワークシート範囲としてすべてのテーブルを書き込みます。
- 式:インポート中に、Univerは、エンジンがサポートしていない式のためにキャッシュされた結果に戻り、キャッシュされた結果に落ちる式を変換します。 エクスポート中に、ポリシーが変更されない限り、変換は成功しなければなりません。 `VALUES` はキャッシュされた結果だけを書き込み、 `TEXT`がソースの式をテキストとして保持します。 `CONVERT_THEN_VALUES`はまだ、式が変換できないときにエクスポートに失敗します。

## ページで編集するためにインポートする

`file` 引数は、ユーザが選択した `File`、リモートファイルへの URL のポインティングができます。このコールは、エディタがロードできる Base データのスナップショットを返します。

```ts
const snapshot = await univerAPI.importBaseToSnapshotAsync(file)
if (snapshot) {
  univerAPI.createBase(snapshot)
}
```

スナップショットのインポートはコラボレーションを必要としませんが、ファイルはサーバー上でまだ変換されなければなりません。ユーザーが後でベースに戻す必要がある場合は、[スナップショットの保存と復元](/guides/bases/model/base-snapshot)で説明されている`base.save()`の結果を保存します。

## ファイルのエクスポート

Excelとして現在の基盤を輸出するため:

```ts
import { ExchangeFormat } from '@univerjs-pro/exchange-client'

const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

const file = await univerAPI.exportBaseBySnapshotAsync(base.save(), ExchangeFormat.XLSX)
if (file) {
  univerAPI.downloadFile(file, 'database', ExchangeFormat.XLSX)
}
```

CSV と TSV は 1 つのテーブルだけを表すことができるので、`tableId` を 1 つ以上のテーブルを持つベースをエクスポートする際に明示的に渡します。

```ts
const table = base.getTables()[0]
if (!table) throw new Error('Create a table first')

const file = await univerAPI.exportBaseBySnapshotAsync(
  base.save(),
  ExchangeFormat.CSV,
  table.getId(),
)
if (file) {
  univerAPI.downloadFile(file, table.getName(), ExchangeFormat.CSV)
}
```

TSVでは、`ExchangeFormat.CSV`を`ExchangeFormat.TSV`に置き換えます。 ファイルエクスポートは、テーブルデータを交換するためのものです。 完全なバックアップのために、ベーススナップショットを保存します。 CSVは、ビュー、パーミッション、または他のリソースを保存しません。

## 共同編集ドキュメントのインポート

[ベースコラボレーション](/guides/bases/features/collaboration)を最初に構成し、ドキュメントをインポートし、サーバーで返されたIDをロードします。

```ts
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importBaseToUnitIdAsync(file)
if (unitId) {
  await univerAPI.getCollaboration().loadBaseAsync(unitId)
}
```

サーバのドキュメントをエクスポートするには、`exportBaseByUnitIdAsync(unitId, format, tableId?)` を呼び出します。 ブラウザの編集を待ち、エクスポートする前に同期を完了します。

フィールドと式変換を実際のアプリケーションファイルで確認します。 これらのメソッドは、`undefined` を返し、リクエストや変換エラーをスローすることができます。そのため、UI のどちらのケースでも処理できます。

## 組み込みのインポート・エクスポートメニューと UI 操作の削除 [#import-export-ui-migration]

<Callout type="warning" title="注意">
  **1.2.0** 以降、Univer の組み込みインポート・エクスポートメニューと UI 操作は削除されました。基盤となるサービスと Facade API は引き続き利用できます。
</Callout>

アプリケーションが以前のインポート/エクスポートメニューとUIインタラクションをまだ必要としている場合は、[組み込みのインポート/エクスポートメニューとUIインタラクションのマイグレーション例](https://office.univer.ai/showcase/bases/custom-import-export)は、カスタムプラグインに移動する方法を示しています。 完全なソースコードは、オンライン読書やダウンロードのために利用可能です。
