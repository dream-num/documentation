---
title: 協同編輯
icon: 'CloudCheck'
---

讓使用者開啟同一個 Base，共同編輯資料表、欄位、記錄與檢視。他們可以在不同檢視中工作，同時修改同一份文件。

## 整合步驟

1. 參考[協同整合](/server/collaboration/browser-integration)，執行協同範例並接入登入、權限與資料庫儲存。
2. 為現有 Bases 編輯器加入 Collaboration Client 設定。瀏覽器設定請參考 [Office 快速開始](/server/collaboration/quick-start)，但應建立並儲存 Bases 文件，不要直接複製範例中的 Sheets 資料。
3. 透過應用程式後端建立 Base，並將其 ID 傳回瀏覽器。

## 開啟伺服器上的 Base

```ts
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/collaboration-client/facade'

const base = await univerAPI.getCollaboration().loadBaseAsync('your-base-id')
if (!base) throw new Error('Base could not be loaded')
```

重新開啟或分享文件時，請重用此 ID。不要以 `createBase()` 建立新的本機空白文件來取代從伺服器載入。

## 驗證同步與儲存

在兩個獨立的瀏覽器工作階段中開啟相同 ID。在其中一個新增記錄或修改欄位，確認另一個收到變更。檢查重新整理頁面與重啟伺服器後，修改仍然保留。

請在伺服器端檢查檢視者與未授權使用者的存取權。[本機唯讀設定](/guides/bases/features/core/permissions)只控制編輯器行為。匯入匯出、留言與歷史記錄各自需要對應的後端功能，請參閱[匯入匯出](/guides/bases/features/import-export)、[留言](/guides/bases/features/thread-comment)與[歷史記錄](/guides/bases/features/edit-history)。
