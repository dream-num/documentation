Bases stellt Fassadenhelfer für Basis-, Tabellen-, Feld- und Datensatzberechtigungen bereit. Verwenden Sie Berechtigungs-APIs, um den Anwendungscode nahe an benutzerbezogenen Konzepten und nicht an internen Diensten zu halten.

## Berechtigungen lesen

```ts
const permission = base.getPermission()
const tablePermission = permission.getTablePermission(table.getId())
const fieldPermission = permission.getFieldPermission(table.getId(), field.getId())
```

## Berechtigungen aktualisieren

```ts
permission.setBasePermission({
  createTable: false,
})

permission.setTablePermission(table.getId(), {
  editable: true,
  removable: false,
})
```

## UI-Verhalten

Die Bases-Benutzeroberfläche liest den Berechtigungsstatus, um zu entscheiden, ob Aktionen sichtbar oder aktiviert sein sollen. Behalten Sie die serverseitige Autorisierung als Quelle der Wahrheit für Produktionsanwendungen bei; Client-Berechtigungen sollten widerspiegeln, was der Server zulässt.
