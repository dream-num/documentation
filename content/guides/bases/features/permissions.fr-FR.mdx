Bases fournit des utilitaires de façade pour gérer les autorisations des bases, des tables, des champs et des enregistrements. Utilisez les API d’autorisation pour structurer le code de l’application autour de concepts familiers aux utilisateurs plutôt que de services internes.

## Lire les autorisations

```ts
const permission = base.getPermission()
const tablePermission = permission.getTablePermission(table.getId())
const fieldPermission = permission.getFieldPermission(table.getId(), field.getId())
```

## Mettre à jour les autorisations

```ts
permission.setBasePermission({
  createTable: false,
})

permission.setTablePermission(table.getId(), {
  editable: true,
  removable: false,
})
```

## Comportement de l’interface utilisateur

L’interface utilisateur de Bases consulte l’état des autorisations pour déterminer si les actions doivent être visibles ou activées. Dans les applications en production, considérez l’autorisation côté serveur comme la source de référence ; les autorisations côté client doivent refléter ce que le serveur permet.
