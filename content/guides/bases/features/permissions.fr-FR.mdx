title: Autorisations
icon: '#pro/ShieldCheck'
---

Les packages Bases actuels n’exportent pas de Facade publique d’autorisation. `base.getPermission()` et les méthodes associées ont été supprimés.

L’autorisation côté serveur reste la source de vérité. L’état interne des autorisations de l’UI n’est pas une API publique.
