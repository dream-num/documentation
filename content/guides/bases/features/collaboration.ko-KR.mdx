사용자들이 같은 Base를 열고 테이블, 필드, 레코드, 뷰를 함께 편집할 수 있습니다. 서로 다른 뷰에서 작업하면서 같은 문서를 수정할 수 있습니다.

## 통합 절차

1. [공동 편집 통합](/server/collaboration/browser-integration)에 따라 예제를 실행하고 로그인, 권한, 데이터베이스 저장소를 연결하세요.
2. 기존 Bases 편집기에 Collaboration Client 설정을 추가하세요. 브라우저 설정은 [Office 빠른 시작](/server/collaboration/quick-start)을 참고하되, 예제의 Sheets 데이터를 복사하지 말고 Bases 문서를 생성하고 저장하세요.
3. 애플리케이션 백엔드에서 Base를 생성하고 ID를 브라우저에 반환하세요.

## 서버의 Base 열기

```ts
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/collaboration-client/facade'

const base = await univerAPI.getCollaboration().loadBaseAsync('your-base-id')
if (!base) throw new Error('Base could not be loaded')
```

문서를 다시 열거나 공유할 때는 이 ID를 재사용하세요. 서버에서 로드하는 대신 `createBase()`로 새로운 로컬 빈 문서를 만들면 안 됩니다.

## 동기화 및 저장 확인

독립된 두 브라우저 세션에서 같은 ID를 여세요. 한 세션에서 레코드를 추가하거나 필드를 변경하고 다른 세션이 이를 받는지 확인하세요. 새로 고침과 서버 재시작 후에도 수정 내용이 유지되는지 확인하세요.

보기 전용 사용자와 권한이 없는 사용자의 접근은 서버에서 검사하세요. [로컬 읽기 전용 설정](/guides/bases/features/core/permissions)은 편집기 동작만 제어합니다. 파일 변환, 댓글, 기록에는 각각 해당 백엔드 기능이 필요합니다. [가져오기 및 내보내기](/guides/bases/features/import-export), [댓글](/guides/bases/features/thread-comment), [기록](/guides/bases/features/edit-history)을 참고하세요.
