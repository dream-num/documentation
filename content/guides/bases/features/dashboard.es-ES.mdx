Una vista de pivote resume una tabla, por ejemplo los ingresos por región. Un panel coloca gráficos, filtros, texto e imágenes en una sola página. Ambas características son proporcionadas por plugins separados, y la pantalla local no requiere colaboración.

## Registrar los plugins

Registrar los plugins de panel después del núcleo Bases y los plugins UI:

```package-install
npm install @univerjs-pro/bases-dashboard @univerjs-pro/bases-dashboard-ui
```

```ts
import { UniverBaseDashboardPlugin } from '@univerjs-pro/bases-dashboard'
import { UniverBaseDashboardUIPlugin } from '@univerjs-pro/bases-dashboard-ui'

import '@univerjs-pro/bases-dashboard/facade'

univer.registerPlugin(UniverBaseDashboardPlugin)
univer.registerPlugin(UniverBaseDashboardUIPlugin)
```

Combina los locales de los nuevos paquetes en la aplicación. Los plugins declaran dependencias en el gráfico, el documento y la forma. Si estas dependencias requieren configuración personalizada, regístrelas primero.

## Crear una vista dinámica de ingresos

El ejemplo que figura a continuación crea una tabla y grupos de ingresos por región:

```ts
import { PivotTableFiledAreaEnum } from '@univerjs-pro/engine-pivot'

const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

const table = base.insertTable('Orders', { primaryFieldName: 'Region' })
const revenue = table.addField('Revenue', univerAPI.Enum.BaseFieldType.Number)
table.addRecords([
  { values: { [table.getPrimaryFieldId()]: 'East', [revenue.getId()]: 120 } },
  { values: { [table.getPrimaryFieldId()]: 'West', [revenue.getId()]: 80 } },
])

const pivot = base.createPivotView('Revenue by region', table.getId())
const pivotTable = pivot.getPivotTable()
pivotTable.addFieldWithSourceId(table.getPrimaryFieldId(), PivotTableFiledAreaEnum.Row)
pivotTable.addFieldWithSourceId(revenue.getId(), PivotTableFiledAreaEnum.Value)
pivot.updateConfig({ pivot: pivotTable.toJSON(), displayMode: 'chart-and-table' })

const baseUI = univerAPI.getBaseUI()
await baseUI.activateTable(table.getId())
await baseUI.activateView(pivot.getId())
```

`getPivotTable()` devuelve un modelo de cálculo separado. Modifique el modelo, luego llame a `updateConfig()` para persistir los cambios en la Base. `displayMode` acepta `table`, `chart` o `chart-and-table`.

## Añadir su gráfico a un panel

```ts
const dashboard = base.createDashboard('Sales overview')
dashboard.addPivotChart(table.getId(), pivot.getId(), {
  title: 'Revenue by region',
  layout: { column: 0, row: 0, columnSpan: 6, rowSpan: 6 },
})
```

El gráfico hace referencia a una vista de pivote existente. Los campos de agregación y los cálculos pertenecen a esa vista, y el diseño y la presentación pertenecen al panel de control. El nuevo panel se puede abrir desde la barra lateral Bases.

`addTableFilter()`, `addText()`, `addImage()`, y `addFormulaShape()` añadir filtros, texto rico, imágenes y formas de fórmula. Llame a `getWidgets()` para leer los widgets de vuelta y `removeWidget()` para eliminarlos.

## Guardado y permisos

`base.save()` escribe la instantánea completa, incluyendo los recursos de panel. Salvar sólo los registros de mesa pierde esta configuración. Registrar los plugins de panel de control antes de restaurar una instantánea.

Los paneles y las vistas de pivote exponen `getPermission()`, por lo que se puede hacer sólo lectura; véase [Permisos](/guides/bases/features/core/permissions). La API completa está documentada en [Bases Facade](/reference/facade/base) .
