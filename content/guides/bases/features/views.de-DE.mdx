Ansichten ermöglichen es Benutzern, dieselbe Tabelle durch verschiedene Projektionen zu sehen. Bases umfasst Raster-, Kanban-, Kalender-, Gantt- und Galerieansichtstypen.

## Ansichten erstellen

```ts
const grid = table.createView({
  name: 'All records',
  type: univerAPI.Enum.BaseViewTypeEnum.Grid,
})

const kanban = table.createView({
  name: 'By status',
  type: univerAPI.Enum.BaseViewTypeEnum.Kanban,
  config: {
    groupFieldId: 'status',
  },
})
```

## Ansicht in der Benutzeroberfläche aktivieren

```ts
const baseUI = univerAPI.getBaseUI(base.getId())
baseUI.activateTable(table.getId())
baseUI.activateView(kanban.getId())
```

## Ansichtsregeln konfigurieren

```ts
kanban.setGroup([
  { fieldId: 'status', direction: univerAPI.Enum.BaseSortDirectionEnum.Asc },
])

kanban.setFilter({
  conjunction: 'and',
  conditions: [
    { fieldId: 'archived', operator: 'is', operand: false },
  ],
})
```

Feldeinstellungen auf Ansichtsebene für Sichtbarkeit, Breite und Kartenanzeige verwenden, ohne das zugrunde liegende Tabellenschema zu ändern.
