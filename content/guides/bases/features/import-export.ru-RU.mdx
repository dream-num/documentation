Базовый импорт **XLSX, XLS, CSV и TSV** и экспорт **XLSX, CSV и TSV**. Общим потоком является импорт списка клиентов Excel, добавление полей и просмотров, а затем экспорт данных таблицы снова.

Эти API требуют преобразования бэкэнда. Заполните [Обмен файлами интеграция](/server/import-export) первым и подтвердите, что бэкэнд поддерживает тип документа Bases и требуемые форматы.

## Поддерживаемые форматы

Таблица охватывает API-интерфейсы браузера, описанные на этой странице. Для преобразования файлов Office по-прежнему требуется бэкэнд, поддерживающий тот же тип и формат документа.

| Импорт | Экспорт |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV и TSV экспортируют единую таблицу, которая выбирается с помощью `tableId`. Ни один формат не сохраняет просмотры, разрешения или любой другой Базовый ресурс. Для полной резервной копии приложения вместо этого сохраните снимок Базы.

## Установка и регистрация

Установите эти пакеты в [Начальный редактор Bases](/guides/bases/getting-started/installation):

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/bases-exchange-client
```

```ts
import { UniverBasesExchangeClientPlugin } from '@univerjs-pro/bases-exchange-client'
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client'

import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-exchange-client/facade'
import '@univerjs-pro/exchange-client/facade'

univer.registerPlugin(UniverExchangeClientPlugin, exchangeConfig)
univer.registerPlugin(UniverBasesExchangeClientPlugin)
```

`exchangeConfig` содержит настройки загрузки, преобразования, запроса задач и загрузки приложения. [Интеграционный справочник](/server/import-export) описывает, как его подготовить.

`UniverExchangeClientPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `downloadEndpointUrl` | `string` | `location.origin` | Базовый URL для загрузки файлов. |
| `uploadFileServerUrl` | `string` | `'/universer-api/stream/file/upload'` | Конечная точка, которая получает загрузку. |
| `importServerUrl` | `string` | `'/universer-api/exchange/{type}/import'` | Конечная точка, с которой начинается импорт. Держите заполнитель `{type}`. |
| `exportServerUrl` | `string` | `'/universer-api/exchange/{type}/export'` | Конечная точка, с которой начинается экспорт. Держите заполнитель `{type}`. |
| `getTaskServerUrl` | `string` | `'/universer-api/exchange/task/{taskID}'` | Конечная точка, которая сообщает о состоянии задачи. Держите заполнитель `{taskID}`. |
| `signUrlServerUrl` | `string` | `'/universer-api/file/{fileID}/sign-url'` | Конечная точка, которая подписывает URL-адреса файлов. Держите заполнитель `{fileID}`. |
| `maxTimeoutTime` | `number` | `120000` | Максимальное время опроса для задачи преобразования, в миллисекундах. |

### Настройка преобразования Excel [#excel-conversion]

`UniverBasesExchangeClientPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `importSourceMode` | `ExchangeBaseImportMode` | `AUTO` | Импортировать таблицы Excel, рабочие листы или и то и другое. |
| `importFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `CONVERT_THEN_VALUES` | Как обращаться с формулами на импорт. |
| `exportStructureMode` | `ExchangeBaseExportMode` | `TABLES` | Будь то экспорт родных таблиц Excel или диапазонов рабочих листов. |
| `exportFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `FAIL` | Как обращаться с формулами на экспорт. |

Чтобы изменить поведение конверсии, перейдите опции в плагин обмена Bases. Значения ниже являются по умолчанию, и эта регистрация заменяет одну из вышеперечисленных:

```ts
import {
  ExchangeBaseExportMode,
  ExchangeBaseFormulaPolicy,
  ExchangeBaseImportMode,
} from '@univerjs-pro/exchange-client'

univer.registerPlugin(UniverBasesExchangeClientPlugin, {
  importSourceMode: ExchangeBaseImportMode.AUTO,
  importFormulaPolicy: ExchangeBaseFormulaPolicy.CONVERT_THEN_VALUES,
  exportStructureMode: ExchangeBaseExportMode.TABLES,
  exportFormulaPolicy: ExchangeBaseFormulaPolicy.FAIL,
})
```

- Источник импорта: `AUTO` импорт Excel таблицы и видимые рабочие листы автоматически. `TABLES` импорт Excel только столы, `SHEETS` импортировать видимые рабочие листы и `HYBRID` импортировать Excel таблицы плюс любые видимые рабочие листы, не имеющие соответствующих Excel столик.
- Структура экспорта: `TABLES` преобразует непустые таблицы Базы в родные таблицы Excel и оставляет пустые таблицы как обычные диапазоны. `RANGES` записывает каждую таблицу как обычный диапазон рабочих листов.
- Формулы: во время импорта Univer преобразует формулы, которые он может, и возвращается к кэшированным результатам для формул, которые двигатель не поддерживает. Во время экспорта конверсия должна быть успешной, если политика не изменена: `VALUES` пишет только кэшированные результаты, а `TEXT` сохраняет исходную формулу в виде текста. `CONVERT_THEN_VALUES` по-прежнему не удается экспортировать, когда формула не может быть преобразована.

## Импорт для редактирования на странице

Аргументом `file` может быть выбранный пользователем `File` или URL-адрес, указывающий на удаленный файл.Звонок возвращает снимок Базовых данных, которые может загрузить редактор:

```ts
const snapshot = await univerAPI.importBaseToSnapshotAsync(file)
if (snapshot) {
  univerAPI.createBase(snapshot)
}
```

Импорт снимка не требует совместной работы, но файл все равно должен быть преобразован на сервере.Если пользователям нужно вернуться на Базу позже, храните результат `base.save()`, как описано в [Сохранение и восстановление снимков](/guides/bases/model/base-snapshot).

## Экспорт файла

Для экспорта текущей Базы в качестве Excel:

```ts
import { ExchangeFormat } from '@univerjs-pro/exchange-client'

const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

const file = await univerAPI.exportBaseBySnapshotAsync(base.save(), ExchangeFormat.XLSX)
if (file) {
  univerAPI.downloadFile(file, 'database', ExchangeFormat.XLSX)
}
```

CSV и TSV могут представлять только одну таблицу, поэтому при экспорте Базы, имеющей более одной таблицы, пройдите `tableId` явно:

```ts
const table = base.getTables()[0]
if (!table) throw new Error('Create a table first')

const file = await univerAPI.exportBaseBySnapshotAsync(
  base.save(),
  ExchangeFormat.CSV,
  table.getId(),
)
if (file) {
  univerAPI.downloadFile(file, table.getName(), ExchangeFormat.CSV)
}
```

Для TSV замените `ExchangeFormat.CSV` на `ExchangeFormat.TSV`. Экспорт файлов предназначен для обмена данными таблицы. Для полного резервного копирования сохраните снимок Базы; CSV не сохраняет просмотры, разрешения или любой другой ресурс.

## Импорт совместного документа

Сначала настройте [Основы сотрудничества](/guides/bases/features/collaboration), затем импортируйте документ и загрузите идентификатор, возвращенный сервером:

```ts
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importBaseToUnitIdAsync(file)
if (unitId) {
  await univerAPI.getCollaboration().loadBaseAsync(unitId)
}
```

Чтобы экспортировать серверный документ, позвоните в `exportBaseByUnitIdAsync(unitId, format, tableId?)`. Подождите, пока отложенные изменения браузера закончат синхронизацию перед экспортом.

Проверить конверсию поля и формулы с помощью реальных файлов приложений. Эти методы могут возвращать `undefined` и могут выбрасывать ошибки запроса или конверсии, поэтому обработайте оба случая в пользовательском интерфейсе.
