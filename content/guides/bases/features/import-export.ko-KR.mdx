Bases는 **XLSX, XLS, CSV 및 TSV** 및 **XLSX, CSV 및 TSV**를 수출합니다. 일반적인 유량은 Excel 고객 목록을 가져 와서 필드 및 레이아웃을 추가하고 테이블 데이터를 다시 내보내는 것입니다.

이 API는 변환 백엔드가 필요합니다. [파일 교환 통합](/server/import-export)를 먼저 완료하고 백엔드는 Bases 문서 유형과 필수 형식을 지원합니다.

## 지원 형식

테이블은이 페이지에 설명 된 브라우저 API를 다룹니다. Office 파일을 변환하는 것은 여전히 동일한 문서 유형과 형식을 지원하는 백엔드가 필요합니다.

| 가져오기 | 내보내기 |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV 및 TSV는 `tableId`로 선택된 단일 테이블을 수출합니다. 네이터 형식은 레이아웃, 권한 또는 기타 기본 리소스를 보존합니다. 응용 프로그램의 전체 백업을 위해 기본 스냅 샷을 대신 저장하십시오.

## 설치 및 등록

[초기 Bases 편집기](/guides/bases/getting-started/installation)에 이러한 패키지를 설치:

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/bases-exchange-client
```

```ts
import { UniverBasesExchangeClientPlugin } from '@univerjs-pro/bases-exchange-client'
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client'

import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-exchange-client/facade'
import '@univerjs-pro/exchange-client/facade'

univer.registerPlugin(UniverExchangeClientPlugin, exchangeConfig)
univer.registerPlugin(UniverBasesExchangeClientPlugin)
```

`exchangeConfig`는 응용 프로그램의 업로드, 변환, 작업복 및 다운로드 설정을 포함합니다. [통합 가이드](/server/import-export)은 그것을 준비하는 방법을 설명합니다.

`UniverExchangeClientPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `downloadEndpointUrl` | `string` | `location.origin` | 파일 다운로드에 대한 기본 URL. |
| `uploadFileServerUrl` | `string` | `'/universer-api/stream/file/upload'` | 업로드를 받는 엔드포인트. |
| `importServerUrl` | `string` | `'/universer-api/exchange/{type}/import'` | 수입을 시작하는 엔드포인트. `{type}` 플레이스홀더 유지. |
| `exportServerUrl` | `string` | `'/universer-api/exchange/{type}/export'` | 수출을 시작하는 엔드포인트. `{type}` 플레이스홀더 유지. |
| `getTaskServerUrl` | `string` | `'/universer-api/exchange/task/{taskID}'` | 작업 상태를 보고하는 엔드포인트. `{taskID}` 플레이스홀더 유지. |
| `signUrlServerUrl` | `string` | `'/universer-api/file/{fileID}/sign-url'` | 파일 URL을 표시하는 엔드포인트. `{fileID}` 플레이스홀더를 유지하십시오. |
| `maxTimeoutTime` | `number` | `120000` | 변환 작업의 최대 오염 시간, 밀리 초. |

### Excel 변환 설정 [#excel-conversion]

`UniverBasesExchangeClientPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `importSourceMode` | `ExchangeBaseImportMode` | `AUTO` | Excel 테이블, 워크 시트, 또는 둘 다 가져올지 여부. |
| `importFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `CONVERT_THEN_VALUES` | 수입에 공식을 치료하는 방법. |
| `exportStructureMode` | `ExchangeBaseExportMode` | `TABLES` | 네이티브 Excel 테이블 또는 워크 시트 범위를 내보내는 것. |
| `exportFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `FAIL` | 수출에 공식을 대우하는 방법. |

변환 동작을 변경하려면, 기본 교환 플러그인에 옵션을 전달합니다. 아래 값은 기본값이며, 이 등록은 위의 하나를 대체합니다.

```ts
import {
  ExchangeBaseExportMode,
  ExchangeBaseFormulaPolicy,
  ExchangeBaseImportMode,
} from '@univerjs-pro/exchange-client'

univer.registerPlugin(UniverBasesExchangeClientPlugin, {
  importSourceMode: ExchangeBaseImportMode.AUTO,
  importFormulaPolicy: ExchangeBaseFormulaPolicy.CONVERT_THEN_VALUES,
  exportStructureMode: ExchangeBaseExportMode.TABLES,
  exportFormulaPolicy: ExchangeBaseFormulaPolicy.FAIL,
})
```

- 가져 오기 소스 : `AUTO` 가져 오기 Excel 테이블과 볼 수있는 워크 시트를 자동으로 가져옵니다. `TABLES`는 Excel 표 만 `SHEETS`가 표시 된 워크 시트를 가져 오기 및 `HYBRID`은 Excel테이블을 가져와 해당 Excel 탁자가없는 눈에 보이는 워크 시트를 가져옵니다.
- 수출 구조: `TABLES`는 본래 Excel 테이블에 비empty 기본적인 테이블을 개조하고 정규적인 범위로 빈 테이블을 나눕니다. `RANGES`은 정규적인 워크시트 범위로 각 테이블을 씁니다.
- 공식: 수입 중, Univer는 엔진이 지원하지 않는 공식을 위해 다시 캐쉬드 결과에 빠질 수 있는 공식을 변환합니다. 수출 도중, 변환은 정책이 변경되지 않는 한 성공해야 합니다: `VALUES`은 캐쉬드 결과를 만 쓰고, `TEXT`에는 원본으로 소스 공식을 유지합니다. `CONVERT_THEN_VALUES` 아직도 공식이 개조될 수 없을 때 수출에 실패합니다.

## 페이지에서 편집하도록 가져오기

`file` 인수는 사용자가 선택한 `File` 또는 원격 파일에 URL 포인팅 할 수 있습니다. 호출은 편집기가로드 할 수있는 기본 데이터의 스냅 샷을 반환합니다.

```ts
const snapshot = await univerAPI.importBaseToSnapshotAsync(file)
if (snapshot) {
  univerAPI.createBase(snapshot)
}
```

스냅 샷을 가져 오는 것은 협업이 필요하지만, 파일은 여전히 서버에서 변환되어야합니다. 사용자가 나중에 Base로 돌아가려면 `base.save()`의 결과를 [저장 및 복원 스냅 샷](/guides/bases/model/base-snapshot)에 설명한대로 저장하십시오.

## 파일 내보내기

Excel로 현재 기초를 수출하기 위하여:

```ts
import { ExchangeFormat } from '@univerjs-pro/exchange-client'

const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

const file = await univerAPI.exportBaseBySnapshotAsync(base.save(), ExchangeFormat.XLSX)
if (file) {
  univerAPI.downloadFile(file, 'database', ExchangeFormat.XLSX)
}
```

CSV 및 TSV는 하나의 테이블 만 표시 할 수 있으므로 `tableId`를 명시적으로 통과하면 기본을 1 개 이상의 테이블을 수출 할 수 있습니다.

```ts
const table = base.getTables()[0]
if (!table) throw new Error('Create a table first')

const file = await univerAPI.exportBaseBySnapshotAsync(
  base.save(),
  ExchangeFormat.CSV,
  table.getId(),
)
if (file) {
  univerAPI.downloadFile(file, table.getName(), ExchangeFormat.CSV)
}
```

TSV의 경우 `ExchangeFormat.CSV`를 `ExchangeFormat.TSV`로 교체합니다. 파일 수출은 테이블 데이터를 교환하기위한 것입니다. 전체 백업을 위해 기본 스냅 샷을 저장하십시오. CSV는 레이아웃, 권한 또는 기타 리소스를 보존하지 않습니다.

## 공동 편집 문서 가져오기

[Bases 협력](/guides/bases/features/collaboration)를 먼저 구성하면 문서를 가져오고 서버가 반환된 ID를 로드합니다.

```ts
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importBaseToUnitIdAsync(file)
if (unitId) {
  await univerAPI.getCollaboration().loadBaseAsync(unitId)
}
```

서버 문서를 내보내기 위해 `exportBaseByUnitIdAsync(unitId, format, tableId?)`를 호출하십시오. 내보내기 전에 동기화를 완료하기 위해 브라우저 편집을 시작합니다.

실제 응용 파일로 필드 및 공식 변환을 검증합니다. 이 방법은 `undefined`를 반환하고 요청 또는 변환 오류를 발생시킬 수 있으므로 UI에서 두 개의 케이스를 처리 할 수 있습니다.
