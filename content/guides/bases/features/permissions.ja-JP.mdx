Bases は、Base、テーブル、フィールド、レコードの権限を扱う Facade ヘルパーを提供します。内部サービスではなく、ユーザーが認識する概念に沿ってアプリケーションコードを記述するには、権限 API を使用します。

## 権限の読み取り

```ts
const permission = base.getPermission()
const tablePermission = permission.getTablePermission(table.getId())
const fieldPermission = permission.getFieldPermission(table.getId(), field.getId())
```

## 権限の更新

```ts
permission.setBasePermission({
  createTable: false,
})

permission.setTablePermission(table.getId(), {
  editable: true,
  removable: false,
})
```

## UI の動作

Bases UI は権限の状態を読み取り、各操作を表示または有効化するかどうかを判断します。本番アプリケーションでは、サーバー側の認可を信頼できる唯一の情報源としてください。クライアント側の権限には、サーバーで許可されている内容を反映する必要があります。
