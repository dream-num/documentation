Univer Bases 핵심 기능은 구조화된 데이터 모델과 브라우저 워크벤치를 결합합니다. 모델과 UI는 두 개의 Univer Pro 패키지로 제공되며 독립적인 `UNIVER_BASE` 단위로 동작합니다.

## 기능

- **테이블, 필드, 레코드**: 각 테이블에 타입이 있는 필드와 순서가 있는 레코드를 저장합니다.
- **여러 보기**: 같은 레코드를 그리드, Kanban, 캘린더, Gantt, 갤러리 보기로 표시합니다.
- **명령 기반 편집**: 모델 변경을 하나의 명령 계층으로 전달하고 권한 및 선택적 기록·협업 통합용 훅을 제공합니다.
- **수식 필드**: Base 필드를 Univer 수식 계산 파이프라인에 연결합니다.
- **브라우저 워크벤치**: 보기를 렌더링하고 선택, 편집, 클립보드, 스크롤, 패널을 제공합니다.
- **영속화**: 실행 중인 스냅샷을 직접 변경하지 않고 `IBaseSnapshot`을 생성하고 복원하고 저장합니다.

## 프리셋 모드

현재 Univer Bases 전용 프리셋은 없습니다. 모델과 브라우저 UI 모두 플러그인 모드를 사용하세요.

## 플러그인 모드

### 설치

[설치 및 기본 사용법](/guides/bases/getting-started/installation)에 설명된 Univer 런타임에 두 Bases 제품 패키지를 추가합니다.

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### 제품 플러그인 등록

설치 가이드에 따라 공유 런타임, 수식 엔진, Pro 라이선스를 먼저 등록한 다음 Bases 플러그인을 등록합니다.

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin`은 Base 모델, 명령, 필드 및 보기 레지스트리, 수식 통합, 권한을 등록합니다. `UniverBasesUIPlugin`은 렌더링된 워크벤치와 브라우저 상호작용을 추가합니다.

## Facade API

`FUniver`를 만들기 전에 모델 및 UI Facade 진입점을 가져옵니다.

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'

const univerAPI = FUniver.newAPI(univer)
const base = univerAPI.createBase({ name: '제품 추적기' })
const snapshot = base.save()
```

모델 Facade는 `createBase`, `getActiveBase`, `getBase`와 Base, 테이블, 필드, 레코드, 보기 작업을 제공합니다. UI Facade는 활성화, 선택, 스크롤, 편집, 패널 API를 추가합니다. 이어서 [Bases Facade API 가이드](/guides/bases/getting-started/facade)와 [Base 스냅샷](/guides/bases/model/base-snapshot)을 참고하세요.
