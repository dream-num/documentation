Используйте комментарии для обсуждения задач, заказов и других записей.Комментарий остается прикрепленным к его записи в Grid, Kanban, Gallery, Calendar и Gantt views, а переключение просмотров не создает отдельной дискуссии.

## Регистрация плагинов

Зарегистрируйте следующие плагины после ядра Bases и плагинов пользовательского интерфейса:

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs-pro/bases-thread-comment @univerjs-pro/bases-thread-comment-ui
```

```ts
import { UniverBasesThreadCommentPlugin } from '@univerjs-pro/bases-thread-comment'
import { UniverBasesThreadCommentUIPlugin } from '@univerjs-pro/bases-thread-comment-ui'
import ProductLocale from '@univerjs-pro/bases-thread-comment-ui/locale/ru-RU'
import { LocaleType, mergeLocales } from '@univerjs/core'
import SharedLocale from '@univerjs/thread-comment-ui/locale/ru-RU'
import '@univerjs-pro/bases-thread-comment/facade'
import '@univerjs/thread-comment/facade'
import '@univerjs/thread-comment-ui/lib/index.css'
import '@univerjs-pro/bases-thread-comment-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.RU_RU, mergeLocales(SharedLocale, ProductLocale))
univer.registerPlugin(UniverBasesThreadCommentPlugin)
univer.registerPlugin(UniverBasesThreadCommentUIPlugin)
```

Объединение локальных ресурсов из пакетов комментариев и настройка текущего пользователя для приложения. Плагин пользовательского интерфейса добавляет элементы управления комментариями к записям, а плагин данных связывает комментарии с записями.

## Добавление и чтение комментариев

```ts
const record = univerAPI.getActiveBase()?.getTables()[0]?.getRecords()[0]
if (!record) throw new Error('Create a record first')

await record.createCommentAsync('Please confirm the delivery date.')
const comments = record.getComments()
console.log(comments.map(({ root }) => root.id))
```

`getComments()` возвращает комментарии, которые уже загружены локально. С удаленным источником данных `await record.listCommentsAsync()` синхронизирует потоки, о которых он уже знает, прежде чем вернуть их. Ответы, обновления и удаление описаны в [Комментарии к Facade](/reference/facade/thread-comment).

## Сохранение и общие обсуждения

Комментарии, созданные локально, сохраняются как часть ресурсов Базы, когда приложение вызывает `base.save()`. Зарегистрируйте плагины комментариев перед восстановлением снимка.

Общие обсуждения также требуют службы комментариев, источника данных и разрешений. Одно только сотрудничество с документами не связывает комментарии. Сначала настройте [Модули расширения Office](/server/collaboration/extensions), а затем проверьте создание, чтение, разрешения и повторное открытие с двумя учетными записями.

## Общие операции [#shared-comment-api]

Импортируйте как общий комментарий Facade, так и продукт Facade, прежде чем вызывать эти методы. Помощники продукта создают стабильные якоря, а общий API обрабатывает ответы, обновления, разрешение и удаление. `getComments()` считывает локальное состояние, в то время как `listCommentsAsync()` Синхронизирует потоки, которые он уже знает, через настроенный источник данных; он не обнаруживает каждый поток на сервере.

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## Общие обсуждения [#shared-discussions]

Чтобы включить общие обсуждения, интегрируйте Службу комментариев и конечную точку через [Server SDK](/server/collaboration/extensions), затем зарегистрируйте `UniverThreadCommentDataSourcePlugin` от `@univerjs-pro/thread-comment-datasource` после совместной работы и настройки лицензии. Комплектный источник данных вызывает `/universer-api/comment/unit/{unitId}/...` и `/universer-api/user/list`. Таким образом, приложение должно раскрыть эти маршруты. Разрешения сервера должны контролировать чтение и запись комментариев независимо от редактирования документов.
