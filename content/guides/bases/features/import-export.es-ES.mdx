Bases importa **XLSX, XLS, CSV y TSV** y exporta **XLSX, CSV y TSV**. Un flujo común es importar una lista de clientes Excel, añadir campos y vistas, y luego exportar los datos de la tabla de nuevo.

Estas API requieren un backend de conversión. Completa [integración del intercambio de archivos](/server/import-export) primero y confirma que el backend admite el tipo de documento Bases y los formatos necesarios.

## Formatos compatibles

La tabla cubre las APIs del navegador descritas en esta página. Convertir archivos de Office todavía requiere un backend que soporta el mismo tipo de documento y formato.

| Importación | Exportación |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV y TSV exportan una sola tabla, que se selecciona con `tableId`. Ninguno de los formatos conserva vistas, permisos o cualquier otro recurso Base. Para una copia de seguridad completa de la aplicación, guarde una instantánea Base en su lugar.

## Instalar y registrar

Instalar estos paquetes en un [inicializado editor de Bases](/guides/bases/getting-started/installation):

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/bases-exchange-client
```

```ts
import { UniverBasesExchangeClientPlugin } from '@univerjs-pro/bases-exchange-client'
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client'

import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-exchange-client/facade'
import '@univerjs-pro/exchange-client/facade'

univer.registerPlugin(UniverExchangeClientPlugin, exchangeConfig)
univer.registerPlugin(UniverBasesExchangeClientPlugin)
```

`exchangeConfig` contiene la carga de la aplicación, la conversión, el directorio de tareas y la configuración de descarga. El [Guía de integración](/server/import-export) describe cómo prepararla.

`UniverExchangeClientPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `downloadEndpointUrl` | `string` | `location.origin` | Base URL para descargas de archivos. |
| `uploadFileServerUrl` | `string` | `'/universer-api/stream/file/upload'` | Endpoint que recibe subidas. |
| `importServerUrl` | `string` | `'/universer-api/exchange/{type}/import'` | Endpoint que comienza una importación. Mantenga el marcador de posición `{type}`. |
| `exportServerUrl` | `string` | `'/universer-api/exchange/{type}/export'` | Endpoint que inicia una exportación. Mantenga el marcador de posición `{type}`. |
| `getTaskServerUrl` | `string` | `'/universer-api/exchange/task/{taskID}'` | Endpoint que reporta el estado de tarea. Mantenga el marcador de posición `{taskID}`. |
| `signUrlServerUrl` | `string` | `'/universer-api/file/{fileID}/sign-url'` | Punto final que firma URLs de archivo. Mantenga el marcador de posición `{fileID}`. |
| `maxTimeoutTime` | `number` | `120000` | Tiempo máximo para una tarea de conversión, en milisegundos. |

### Configurar la conversión de Excel [#excel-conversion]

`UniverBasesExchangeClientPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `importSourceMode` | `ExchangeBaseImportMode` | `AUTO` | Ya sea para importar tablas Excel, hojas de trabajo o ambas. |
| `importFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `CONVERT_THEN_VALUES` | Cómo tratar las fórmulas de importación. |
| `exportStructureMode` | `ExchangeBaseExportMode` | `TABLES` | Ya sea para exportar tablas Excel nativas o rangos de hoja de trabajo. |
| `exportFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `FAIL` | Cómo tratar las fórmulas en la exportación. |

Para cambiar el comportamiento de conversión, pasar opciones al plugin de intercambio Bases. Los valores siguientes son los predeterminados, y este registro reemplaza el anterior:

```ts
import {
  ExchangeBaseExportMode,
  ExchangeBaseFormulaPolicy,
  ExchangeBaseImportMode,
} from '@univerjs-pro/exchange-client'

univer.registerPlugin(UniverBasesExchangeClientPlugin, {
  importSourceMode: ExchangeBaseImportMode.AUTO,
  importFormulaPolicy: ExchangeBaseFormulaPolicy.CONVERT_THEN_VALUES,
  exportStructureMode: ExchangeBaseExportMode.TABLES,
  exportFormulaPolicy: ExchangeBaseFormulaPolicy.FAIL,
})
```

- Fuente de importación: `AUTO` importa tablas Excel y hojas de cálculo visibles automáticamente. `TABLES` importar tablas Excel solamente, `SHEETS` importaciones hojas de trabajo visibles, y `HYBRID` imports las tablas de Excel más cualquier hoja de trabajo visible que no tenga la tabla Excel correspondiente.
- Estructura de exportación: `TABLES` convierte tablas de base no vacías en tablas nativas Excel y deja tablas vacías como rangos ordinarios. `RANGES` escribe cada tabla como un rango de hoja de trabajo ordinario.
- Fórmulas: durante la importación, Univer convierte las fórmulas que puede y cae a resultados de caché para fórmulas que el motor no soporta. Durante la exportación, la conversión debe tener éxito a menos que la política sea cambiada: `VALUES` escribe resultados de cache solamente, y `TEXT` mantiene la fórmula fuente como texto. `CONVERT_THEN_VALUES` todavía no se puede exportar cuando una fórmula no se puede convertir.

## Importar para editar en la página

El argumento `file` puede ser un `File` seleccionado por el usuario o una URL que apunta a un archivo remoto. La llamada devuelve una instantánea de datos Base que el editor puede cargar:

```ts
const snapshot = await univerAPI.importBaseToSnapshotAsync(file)
if (snapshot) {
  univerAPI.createBase(snapshot)
}
```

Importar una instantánea no requiere colaboración, pero el archivo debe ser convertido en el servidor. Si los usuarios necesitan volver a la Base más tarde, almacene el resultado de `base.save()` como se describe en [guardar y restaurar instantáneas](/guides/bases/model/base-snapshot).

## Exportar un archivo

Para exportar la Base actual como Excel:

```ts
import { ExchangeFormat } from '@univerjs-pro/exchange-client'

const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

const file = await univerAPI.exportBaseBySnapshotAsync(base.save(), ExchangeFormat.XLSX)
if (file) {
  univerAPI.downloadFile(file, 'database', ExchangeFormat.XLSX)
}
```

CSV y TSV pueden representar sólo una tabla, por lo que pasar `tableId` explícitamente al exportar una Base que tiene más de una tabla:

```ts
const table = base.getTables()[0]
if (!table) throw new Error('Create a table first')

const file = await univerAPI.exportBaseBySnapshotAsync(
  base.save(),
  ExchangeFormat.CSV,
  table.getId(),
)
if (file) {
  univerAPI.downloadFile(file, table.getName(), ExchangeFormat.CSV)
}
```

Para TSV, sustitúyase `ExchangeFormat.CSV` por `ExchangeFormat.TSV`. La exportación de archivos está destinada a intercambiar datos de tablas. Para una copia de seguridad completa, guarde la instantánea de Base; CSV no preserva vistas, permisos o cualquier otro recurso.

## Importar un documento colaborativo

Configure [Colaboración con las bases](/guides/bases/features/collaboration) primero, luego importar el documento y cargar el ID devuelto por el servidor:

```ts
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importBaseToUnitIdAsync(file)
if (unitId) {
  await univerAPI.getCollaboration().loadBaseAsync(unitId)
}
```

Para exportar un documento de servidor, llame a `exportBaseByUnitIdAsync(unitId, format, tableId?)`. Espere a que se editen los navegadores pendientes para terminar la sincronización antes de exportar.

Verificar la conversión de campo y fórmula con archivos de aplicación reales. Estos métodos pueden devolver `undefined` y pueden lanzar errores de solicitud o conversión, así que maneje ambos casos en la interfaz de usuario.

## Eliminación de los menús y las interacciones de UI de importación y exportación integrados [#import-export-ui-migration]

<Callout type="warning" title="Nota">
  A partir de la versión **1.2.0**, Univer eliminó los menús y las interacciones de UI de importación y exportación integrados. Los servicios subyacentes y las API de Facade siguen disponibles.
</Callout>

Si la aplicación todavía requiere los menús de importación/exportación anteriores y las interacciones de la UI, el [ejemplo de migración para menús integrados de importación/exportación e interacciones de la UI](https://office.univer.ai/showcase/bases/custom-import-export) muestra cómo moverlos en un plugin personalizado. El código fuente completo está disponible allí para la lectura o descarga en línea.
