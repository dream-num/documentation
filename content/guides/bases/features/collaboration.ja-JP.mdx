ユーザーが同じ Base を開き、テーブル、フィールド、レコード、ビューを共同で編集できます。異なるビューで作業しながら、同じドキュメントを変更できます。

## 統合手順

1. [共同編集の統合](/server/collaboration/browser-integration)に従ってサンプルを実行し、ログイン、権限、データベースストレージを接続します。
2. 既存の Bases エディターに Collaboration Client の設定を追加します。ブラウザー側の設定は [Office クイックスタート](/server/collaboration/quick-start)を参照してください。ただし、サンプルの Sheets データをコピーするのではなく、Bases ドキュメントを作成して保存します。
3. アプリケーションのバックエンドで Base を作成し、その ID をブラウザーに返します。

## サーバー上の Base を開く

```ts
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/collaboration-client/facade'

const base = await univerAPI.getCollaboration().loadBaseAsync('your-base-id')
if (!base) throw new Error('Base could not be loaded')
```

再度開く場合や共有する場合は、この ID を再利用します。サーバーからの読み込みを、`createBase()` による新しいローカルの空ドキュメントの作成に置き換えないでください。

## 同期と保存の確認

独立した 2 つのブラウザーセッションで同じ ID を開きます。一方でレコードを追加するかフィールドを変更し、もう一方に届くことを確認します。ページの再読み込みとサーバーの再起動後も編集内容が保持されることを確認してください。

閲覧者や権限のないユーザーのアクセスはサーバー側で認可してください。[ローカルの読み取り専用設定](/guides/bases/features/core/permissions)はエディターの動作だけを制御します。ファイル変換、コメント、履歴にはそれぞれ対応するバックエンド機能が必要です。[インポート・エクスポート](/guides/bases/features/import-export)、[コメント](/guides/bases/features/thread-comment)、[履歴](/guides/bases/features/edit-history)を参照してください。
