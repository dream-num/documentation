Los campos definen el esquema de una tabla base. Cada campo tiene un tipo, configuración, valor predeterminado y capacidades como ordenar, filtrar, agrupar o mostrar tarjetas.

## Agregar campos

```ts
const table = base.getTable('tasks')

const title = table.addField({
  name: 'Title',
  type: univerAPI.Enum.BaseFieldTypeEnum.Text,
})

const priority = table.addField({
  name: 'Priority',
  type: univerAPI.Enum.BaseFieldTypeEnum.SingleSelect,
  config: {
    options: [
      { id: 'high', name: 'High', color: '#ef4444' },
      { id: 'low', name: 'Low', color: '#22c55e' },
    ],
  },
})
```

## Actualizar campos

```ts
priority.setName('Impact')
priority.setDescription('Business priority')
priority.setConfig({
  options: [
    { id: 'p0', name: 'P0', color: '#dc2626' },
    { id: 'p1', name: 'P1', color: '#f97316' },
  ],
})
```

## Cambiar tipo de campo

```ts
table.changeFieldType(priority.getId(), {
  type: univerAPI.Enum.BaseFieldTypeEnum.Text,
  config: {},
})
```

Cambiar un tipo de campo puede normalizar los valores existentes. Valide los datos en su aplicación antes de aplicar cambios de esquema a las tablas de producción.
