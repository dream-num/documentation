Bases exposes facade helpers for Base, table, field, and record permissions. Use permission APIs to keep application code close to user-facing concepts instead of internal services.

## Read permissions

```ts
const permission = base.getPermission()
const tablePermission = permission.getTablePermission(table.getId())
const fieldPermission = permission.getFieldPermission(table.getId(), field.getId())
```

## Update permissions

```ts
permission.setBasePermission({
  createTable: false,
})

permission.setTablePermission(table.getId(), {
  editable: true,
  removable: false,
})
```

## UI behavior

The Bases UI reads permission state to decide whether actions should be visible or enabled. Keep server-side authorization as the source of truth for production applications; client permissions should mirror what the server allows.
