Los campos de fórmula de Bases calculan valores de registros a partir de datos de tablas. `UniverBasesPlugin` registra automáticamente su dependencia del motor de fórmulas Pro.

## Registrar compatibilidad con fórmulas

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

## Crear un campo de fórmula

```ts
const total = table.addField(
  'Total',
  univerAPI.Enum.BaseFieldType.Formula,
  {
    field: {
      config: {
        formula: '=SUM([Price],[Tax])',
      },
    },
    externalReferences: [],
  },
)
```

`externalReferences` es obligatorio para cada escritura de campo de fórmula. Use `[]` solo para fórmulas que hagan referencia a campos de la Base anfitriona. Para fórmulas entre unidades, use [`buildReference`](/reference/facade/formula#buildreference) y pase todas las vinculaciones de origen estables en esta matriz.

## Notas

- Los campos de fórmula son valores derivados; evite escribir directamente en las celdas de fórmula desde el código de la aplicación.
- Las expresiones de fórmula utilizan referencias de campo estructuradas como `[Price]`.
- Recalcule las fórmulas después de importar instantáneas grandes antes de exponer los resultados a los usuarios.
