A pivot view summarizes a table, for example revenue by region. A dashboard places charts, filters, text, and images on a single page. Both features are provided by separate plugins, and local display does not require collaboration.

## Register the plugins

Register the dashboard plugins after the Bases core and UI plugins:

```package-install
npm install @univerjs-pro/bases-dashboard @univerjs-pro/bases-dashboard-ui
```

```ts
import { UniverBaseDashboardPlugin } from '@univerjs-pro/bases-dashboard'
import { UniverBaseDashboardUIPlugin } from '@univerjs-pro/bases-dashboard-ui'

import '@univerjs-pro/bases-dashboard/facade'

univer.registerPlugin(UniverBaseDashboardPlugin)
univer.registerPlugin(UniverBaseDashboardUIPlugin)
```

Merge the locales of the new packages into the application. The plugins declare dependencies on chart, document, and shape. If these dependencies require custom configuration, register them first.

## Create a revenue pivot view

The example below creates a table and groups revenue by region:

```ts
import { PivotTableFiledAreaEnum } from '@univerjs-pro/engine-pivot'

const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

const table = base.insertTable('Orders', { primaryFieldName: 'Region' })
const revenue = table.addField('Revenue', univerAPI.Enum.BaseFieldType.Number)
table.addRecords([
  { values: { [table.getPrimaryFieldId()]: 'East', [revenue.getId()]: 120 } },
  { values: { [table.getPrimaryFieldId()]: 'West', [revenue.getId()]: 80 } },
])

const pivot = base.createPivotView('Revenue by region', table.getId())
const pivotTable = pivot.getPivotTable()
pivotTable.addFieldWithSourceId(table.getPrimaryFieldId(), PivotTableFiledAreaEnum.Row)
pivotTable.addFieldWithSourceId(revenue.getId(), PivotTableFiledAreaEnum.Value)
pivot.updateConfig({ pivot: pivotTable.toJSON(), displayMode: 'chart-and-table' })

const baseUI = univerAPI.getBaseUI()
await baseUI.activateTable(table.getId())
await baseUI.activateView(pivot.getId())
```

`getPivotTable()` returns a detached calculation model. Modify the model, then call `updateConfig()` to persist the changes in the Base. `displayMode` accepts `table`, `chart`, or `chart-and-table`.

## Add its chart to a dashboard

```ts
const dashboard = base.createDashboard('Sales overview')
dashboard.addPivotChart(table.getId(), pivot.getId(), {
  title: 'Revenue by region',
  layout: { column: 0, row: 0, columnSpan: 6, rowSpan: 6 },
})
```

The chart references an existing pivot view. Aggregation fields and calculations belong to that view, and layout and presentation belong to the dashboard. The new dashboard can be opened from the Bases sidebar.

`addTableFilter()`, `addText()`, `addImage()`, and `addFormulaShape()` add filters, rich text, images, and formula shapes. Call `getWidgets()` to read the widgets back and `removeWidget()` to remove them.

## Saving and permissions

`base.save()` writes the complete snapshot, including dashboard resources. Saving only table records loses this configuration. Register the dashboard plugins before restoring a snapshot.

Dashboards and pivot views both expose `getPermission()`, so either can be made read-only; see [Permissions](/guides/bases/features/core/permissions). The complete API is documented in [Bases Facade](/reference/facade/base).
