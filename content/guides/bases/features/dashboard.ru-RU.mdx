Стержневой вид суммирует таблицу, например доход по регионам. Панель приборов размещает диаграммы, фильтры, текст и изображения на одной странице. Обе функции предоставляются отдельными плагинами, а локальный дисплей не требует совместной работы.

## Регистрация плагинов

Зарегистрируйте плагины панели инструментов после ядра Bases и плагинов пользовательского интерфейса:

```package-install
npm install @univerjs-pro/bases-dashboard @univerjs-pro/bases-dashboard-ui
```

```ts
import { UniverBaseDashboardPlugin } from '@univerjs-pro/bases-dashboard'
import { UniverBaseDashboardUIPlugin } from '@univerjs-pro/bases-dashboard-ui'

import '@univerjs-pro/bases-dashboard/facade'

univer.registerPlugin(UniverBaseDashboardPlugin)
univer.registerPlugin(UniverBaseDashboardUIPlugin)
```

Объедините в приложение локализации новых пакетов. Плагины объявляют зависимости по графику, документу и форме. Если эти зависимости требуют пользовательской настройки, зарегистрируйте их сначала.

## Создание сводного представления выручки

Приведенный ниже пример создает таблицу и группирует доходы по регионам:

```ts
import { PivotTableFiledAreaEnum } from '@univerjs-pro/engine-pivot'

const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

const table = base.insertTable('Orders', { primaryFieldName: 'Region' })
const revenue = table.addField('Revenue', univerAPI.Enum.BaseFieldType.Number)
table.addRecords([
  { values: { [table.getPrimaryFieldId()]: 'East', [revenue.getId()]: 120 } },
  { values: { [table.getPrimaryFieldId()]: 'West', [revenue.getId()]: 80 } },
])

const pivot = base.createPivotView('Revenue by region', table.getId())
const pivotTable = pivot.getPivotTable()
pivotTable.addFieldWithSourceId(table.getPrimaryFieldId(), PivotTableFiledAreaEnum.Row)
pivotTable.addFieldWithSourceId(revenue.getId(), PivotTableFiledAreaEnum.Value)
pivot.updateConfig({ pivot: pivotTable.toJSON(), displayMode: 'chart-and-table' })

const baseUI = univerAPI.getBaseUI()
await baseUI.activateTable(table.getId())
await baseUI.activateView(pivot.getId())
```

`getPivotTable()` возвращает отсоединенную модель расчета. Измените модель, затем вызовите `updateConfig()`, чтобы сохранить изменения в Базе. `displayMode` принимает `table` , `chart` или `chart-and-table`.

## Добавление графика на панель мониторинга

```ts
const dashboard = base.createDashboard('Sales overview')
dashboard.addPivotChart(table.getId(), pivot.getId(), {
  title: 'Revenue by region',
  layout: { column: 0, row: 0, columnSpan: 6, rowSpan: 6 },
})
```

На диаграмме указаны существующие поворотные поля и расчеты, а макет и представление относятся к приборной панели. Новая приборная панель может быть открыта с боковой панели Bases.

`addTableFilter()`, `addText()`, `addImage()` и `addFormulaShape()` добавьте фильтры, богатый текст, изображения и формулы, позвоните `getWidgets()`, чтобы прочитать виджеты назад и `removeWidget()`, чтобы удалить их.

## Сохранение и права доступа

`base.save()` записывает полный снимок, включая ресурсы панели инструментов. Сохранение только записей таблиц теряет эту конфигурацию. Зарегистрируйте плагины панели инструментов перед восстановлением снимка.

Панели управления и точки обзора разоблачают `getPermission()`, поэтому любой из них может быть выполнен только для чтения; см. [Разрешения](/guides/bases/features/core/permissions). Полный API документирован в [Фасад Базы](/reference/facade/base) .
