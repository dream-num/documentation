Permite que los usuarios abran la misma Base y editen juntos tablas, campos, registros y vistas. Pueden trabajar en vistas diferentes mientras modifican el mismo documento.

## Pasos de integración

1. Sigue la [integración de colaboración](/server/collaboration/browser-integration) para ejecutar el ejemplo y conectar el inicio de sesión, los permisos y el almacenamiento en la base de datos.
2. Añade la configuración del cliente Collaboration al editor Bases existente. Sigue el [inicio rápido de Office](/server/collaboration/quick-start) para configurar el navegador, pero crea y almacena documentos Bases en lugar de copiar los datos Sheets del ejemplo.
3. Crea la Base mediante el backend de tu aplicación y devuelve su ID al navegador.

## Abrir una Base del servidor

```ts
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/collaboration-client/facade'

const base = await univerAPI.getCollaboration().loadBaseAsync('your-base-id')
if (!base) throw new Error('Base could not be loaded')
```

Reutiliza el ID al volver a abrir o compartir el documento. No sustituyas la carga desde el servidor por `createBase()` y un documento local vacío nuevo.

## Verificar la sincronización y el guardado

Abre el mismo ID en dos sesiones independientes del navegador. Añade un registro o modifica un campo en una y comprueba que la otra reciba el cambio. Verifica que las modificaciones se conserven tras actualizar y reiniciar el servidor.

Controla en el servidor el acceso de lectores y usuarios sin autorización. Los [ajustes locales de solo lectura](/guides/bases/features/core/permissions) solo controlan el editor. La conversión de archivos, los comentarios y el historial necesitan sus respectivas funciones de backend; consulta [Importación y exportación](/guides/bases/features/import-export), [Comentarios](/guides/bases/features/thread-comment) e [Historial](/guides/bases/features/edit-history).
