Varios usuarios pueden abrir la misma Base y editar tablas, campos, registros y vistas juntos. Cada usuario puede trabajar en una vista diferente mientras que todos los cambios se aplican al mismo documento.

## Pasos de integración

1. Siga [Integración de la colaboración](/server/collaboration/browser-integration) para ejecutar el ejemplo de colaboración, luego conectar el login, los permisos y el almacenamiento de bases de datos.
2. Agregue la configuración del Cliente de Colaboración al editor de Bases existente. Para el lado del navegador, siga [Inicio rápido de la colaboración](/server/collaboration/quick-start), pero cree y almacene documentos Bases en lugar de copiar los datos de Hojas del ejemplo.
3. Crear la Base en el backend de la aplicación y devolver su ID al navegador.

## Abrir una Base del servidor

Establece el usuario actual antes de cargar el documento. Consulta [Integración de colaboración](/server/collaboration/browser-integration).

```ts
import '@univerjs-pro/bases/facade'
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const base = await univerAPI.getCollaboration().loadBaseAsync('your-base-id')
if (!base) throw new Error('Base could not be loaded')
```

Reutiliza el mismo ID cuando vuelva a abrir o compartir el documento. No sustituya la carga del servidor con `createBase()` y un nuevo documento en blanco local.

Utilice [estado de sincronización, registros y recuperación de conflictos](/server/collaboration/browser-integration#sync-status) para construir indicadores de ahorro, y proteger ediciones no reconocidas antes de una recarga.

## Eliminación de la carga integrada por URL de documentos colaborativos [#url-unit-loader-migration]

<Callout type="warning" title="Nota">
  Empezando con la versión **1.2.0**, Univer ya no incluye la carga de URL integrada para documentos de colaboración. Ya no lee los parámetros de URL `unit` y `type` para determinar qué documento se carga.
</Callout>

Si la aplicación depende de este comportamiento, un plugin personalizado puede restaurarlo.

### Integrar el plugin personalizado

Copie los cuatro archivos abajo en el proyecto y mantenga la siguiente estructura del directorio:

```text
custom-url-load/
├── plugin.ts
├── controllers/
│   └── data-loader.controller.ts
└── services/
    ├── url.service.ts
    └── web-url.service.ts
```

Después de que el editor y los plugins de colaboración se inicializan, establece el usuario actual, luego regístrese `CustomUrlLoadPlugin`.

```ts
import { UserManagerService } from '@univerjs/core'
import { CustomUrlLoadPlugin } from './custom-url-load/plugin'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

univer.registerPlugin(CustomUrlLoadPlugin)
```

Después del registro, el plugin carga el documento, por lo que llamar a `loadBaseAsync()` para el mismo documento ya no es necesario. Si la aplicación ya carga documentos a través de la Facade, mantenga el enfoque descrito en la sección anterior y maneje URLs como la aplicación requiere.

    import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
    import { CollaborationDataLoaderController } from './controllers/data-loader.controller'
    import { IURLService } from './services/url.service'
    import { WebURLService } from './services/web-url.service'

    @DependentOn(UniverCollaborationClientPlugin)
    export class CustomUrlLoadPlugin extends Plugin {
      static override pluginName = 'CUSTOM_URL_LOAD_PLUGIN'

      constructor(
        _config: undefined,
        @Inject(Injector) protected override readonly _injector: Injector
      ) {
        super()
      }

      override onStarting(): void {
        this._injector.add([IURLService, { useClass: WebURLService }])
        this._injector.add([CollaborationDataLoaderController])

        this.disposeWithMe(this._injector.get(IURLService))
        this.disposeWithMe(this._injector.get(CollaborationDataLoaderController))
      }
    }

    import { DataLoaderService } from '@univerjs-pro/collaboration-client'
    import { ILogService, Inject, RxDisposable } from '@univerjs/core'
    import { IURLService } from '../services/url.service'

    /**
     * Carga un documento colaborativo desde los parámetros de la URL.
     */
    export class CollaborationDataLoaderController extends RxDisposable {
      constructor(
        @IURLService private readonly _urlService: IURLService,
        @ILogService private readonly _logService: ILogService,
        @Inject(DataLoaderService) private readonly _dataLoaderService: DataLoaderService
      ) {
        super()

        const unitId = this._urlService.getParam('unit')
        const type = this._urlService.getParam('type')
        if (!unitId || !type) {
          return
        }

        this._dataLoaderService.loadUnit(unitId, Number(type))
          .catch((error: unknown) => {
            this._logService.error('[CollaborationDataLoaderController]', error)
          })
      }
    }

    import type { IURLService } from './url.service'
    import { RxDisposable } from '@univerjs/core'
    import { fromEvent, map, shareReplay, takeUntil } from 'rxjs'

    export class WebURLService extends RxDisposable implements IURLService {
      readonly urlChange$ = fromEvent(window, 'popstate').pipe(
        map(() => undefined),
        takeUntil(this.dispose$),
        shareReplay({ bufferSize: 1, refCount: true })
      )

      getParam(key: string): string | undefined {
        return new URL(window.location.href).searchParams.get(key) ?? undefined
      }

      setParam(key: string, value: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.set(key, value)
        this._updateUrl(url, useReplace)
      }

      removeParam(key: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.delete(key)
        this._updateUrl(url, useReplace)
      }

      private _updateUrl(url: URL, useReplace: boolean): void {
        if (useReplace) {
          window.history.replaceState(window.history.state, '', url.toString())
        } else {
          window.history.pushState(window.history.state, '', url.toString())
        }
      }
    }

## Verificar la sincronización y el guardado

Abra el mismo ID en dos sesiones independientes del navegador. Agregue un registro o cambie un campo en una sesión y confirme que el otro recibe el cambio. A continuación, compruebe que las ediciones persisten después de una actualización de página y un servidor reiniciar.

Los usuarios y usuarios no autorizados deben ser autorizados en el servidor. [Ajustes locales de sólo lectura](/guides/bases/features/core/permissions) sólo afectan el comportamiento del editor. Intercambio, comentarios e historia cada uno requiere sus propias características de backend; ver [Importación y exportación](/guides/bases/features/import-export), [Comentarios](/guides/bases/features/thread-comment) y [historia](/guides/bases/features/edit-history).
