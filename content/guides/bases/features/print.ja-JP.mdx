title: 印刷

---

Bases には現在、専用の印刷プラグインや Facade 印刷 API はありません。ブラウザーのページを印刷しても、テーブル全体は印刷されません。一部のレコードが未読み込み、または非表示の場合があるためです。

## エクスポートして印刷する

テーブルのデータを印刷するには、[XLSX としてエクスポート](/guides/bases/features/import-export)し、対応するアプリケーションで開いて用紙サイズ、向き、改ページを設定します。ファイル変換には対応するバックエンドサービスが必要です。

この方法で印刷できるのはテーブルのデータです。Bases のビューやダッシュボードのレイアウトが保持されるとは限りません。

## カスタム印刷ページ

業務専用の帳票レイアウトが必要な場合は、必要なレコードを読み取り、アプリケーション内で専用の印刷ページを生成してください。すべてのデータが読み込まれていること、フィールドの選択が正しいこと、ユーザーに読み取り権限と印刷権限があることを確認します。他の製品の印刷プラグインを Bases に登録しても、この機能は利用できません。
