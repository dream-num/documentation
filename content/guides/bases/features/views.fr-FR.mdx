Les vues permettent aux utilisateurs d’afficher une même table sous différentes représentations. Bases propose des vues de type grille, kanban, calendrier, diagramme de Gantt et galerie.

## Créer des vues

```ts
const grid = table.createView({
  name: 'All records',
  type: univerAPI.Enum.BaseViewTypeEnum.Grid,
})

const kanban = table.createView({
  name: 'By status',
  type: univerAPI.Enum.BaseViewTypeEnum.Kanban,
  config: {
    groupFieldId: 'status',
  },
})
```

## Activer une vue dans l’interface utilisateur

```ts
const baseUI = univerAPI.getBaseUI(base.getId())
baseUI.activateTable(table.getId())
baseUI.activateView(kanban.getId())
```

## Configurer les règles d’une vue

```ts
kanban.setGroup([
  { fieldId: 'status', direction: univerAPI.Enum.BaseSortDirectionEnum.Asc },
])

kanban.setFilter({
  conjunction: 'and',
  conditions: [
    { fieldId: 'archived', operator: 'is', operand: false },
  ],
})
```

Utilisez les paramètres de champ propres à chaque vue pour définir la visibilité, la largeur et l’affichage des cartes sans modifier le schéma de la table sous-jacente.
