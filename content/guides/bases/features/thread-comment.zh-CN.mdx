评论可用于讨论任务、订单等记录。评论始终与对应记录绑定，在网格、看板、画廊、日历和甘特图视图中都指向同一份讨论，切换视图不会新建讨论。

## 注册插件

在 Bases 核心插件和 UI 插件之后注册以下插件：

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs-pro/bases-thread-comment @univerjs-pro/bases-thread-comment-ui
```

```ts
import { UniverBasesThreadCommentPlugin } from '@univerjs-pro/bases-thread-comment'
import { UniverBasesThreadCommentUIPlugin } from '@univerjs-pro/bases-thread-comment-ui'
import ProductLocale from '@univerjs-pro/bases-thread-comment-ui/locale/zh-CN'
import { LocaleType, mergeLocales } from '@univerjs/core'
import SharedLocale from '@univerjs/thread-comment-ui/locale/zh-CN'
import '@univerjs-pro/bases-thread-comment/facade'
import '@univerjs/thread-comment/facade'
import '@univerjs/thread-comment-ui/lib/index.css'
import '@univerjs-pro/bases-thread-comment-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.ZH_CN, mergeLocales(SharedLocale, ProductLocale))
univer.registerPlugin(UniverBasesThreadCommentPlugin)
univer.registerPlugin(UniverBasesThreadCommentUIPlugin)
```

合并评论相关包提供的语言资源，并为应用配置当前用户。UI 插件为记录添加评论入口，数据插件负责将评论与记录关联起来。

## 添加和读取评论

```ts
const record = univerAPI.getActiveBase()?.getTables()[0]?.getRecords()[0]
if (!record) throw new Error('Create a record first')

await record.createCommentAsync('Please confirm the delivery date.')
const comments = record.getComments()
console.log(comments.map(({ root }) => root.id))
```

`getComments()` 返回本地已加载的评论。使用远程数据源时，`await record.listCommentsAsync()` 会先同步已知的讨论，再将其返回。回复、更新和删除的操作见[评论 Facade](/reference/facade/thread-comment)。

## 保存与多人讨论

应用调用 `base.save()` 时，本地创建的评论会随 Base 资源一同保存。恢复快照前应先注册评论插件。

多人共享评论还需要评论服务、数据源和权限。仅有文档协同并不会连接评论，应先按 [Office 协同扩展模块](/server/collaboration/extensions)配置后端，再用两个账号验证创建、读取、权限和重新打开等操作。

## 通用评论操作 [#shared-comment-api]

调用这些方法前，需要导入通用评论 Facade 和品类 Facade。品类方法负责建立稳定的锚点，通用 API 负责回复、修改、解决和删除。`getComments()` 读取本地状态；`listCommentsAsync()` 通过已配置的数据源同步已知线程，不会发现服务端上的全部线程。

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## 共享讨论 [#shared-discussions]

启用共享讨论需要先通过 [Server SDK](/server/collaboration/extensions) 接入 Comment Service 和 Endpoint，待协同和许可证配置完成后，再注册 `@univerjs-pro/thread-comment-datasource` 中的 `UniverThreadCommentDataSourcePlugin`。内置数据源会请求 `/universer-api/comment/unit/{unitId}/...` 和 `/universer-api/user/list`，这些路由需要由应用提供。服务端必须单独控制评论的读取和写入权限，不能只依据文档编辑权限。
