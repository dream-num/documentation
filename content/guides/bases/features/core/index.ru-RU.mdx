Базы Univer объединяют модель структурированных данных с рабочим столом браузера. Два пакета Web SDK обеспечивают эти компоненты, и вместе они работают как независимый блок `UNIVER_BASE`.

## Режим пресетов

| Основная особенность | Цель |
| --- | --- |
| [Поля и крепления](/guides/bases/features/core/fields) | Текст, цифры, выбор, члены, даты и вложения. |
| [Записи, ссылки и иерархия](/guides/bases/features/core/records) | Редактирование пакетов, локальная пагинация, ссылки на таблицы и записи родителей и детей. |
| [Посмотреть](/guides/bases/features/core/views) | Сетка, Канбан, Календарь, Гант, Галерея, фильтрация, сортировка, группировка и условные цвета. |
| [Формулы](/guides/bases/features/core/formulas) | Полевые вычисления и явно сконфигурированные перекрестные ссылки на документы. |
| [Разрешения](/guides/bases/features/core/permissions) | Редактирование разрешений для баз, таблиц, полей, записей и просмотров. |

Обмен, панели инструментов, комментарии и история предоставляются в виде плагинов расширения. См. [Обзор основных характеристик](/guides/bases#основные-возможности).

## Режим плагинов

### Установка

Добавьте два пакета продуктов Bases к времени выполнения, настроенному в [Установка и базовое использование](/guides/bases/getting-started/installation):

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### Регистрация плагинов продукта

Следуя руководству по установке, сначала зарегистрируйте совместно используемое время выполнения, движок формулы и лицензию, а затем зарегистраируйте плагины Bases:

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin` предоставляет Базовую модель, команды, реестры полей и просмотров, интеграцию формул и разрешения. `UniverBasesUIPlugin` добавляет визуализированную рабочую панель и взаимодействия браузера, которые ее сопровождают.

## Режим Preset

Univer Bases пока не имеет выделенного предустановленного режима. Используйте режим плагина как для модели, так и для пользовательского интерфейса браузера.
