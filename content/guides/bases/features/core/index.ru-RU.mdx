Ядро Univer Bases объединяет модель структурированных данных и рабочую область в браузере. Модель и интерфейс поставляются в двух пакетах Univer SDK Pro и работают как самостоятельный объект `UNIVER_BASE`.

## Возможности

- **Таблицы, поля и записи**: хранение типизированных полей и упорядоченных записей в каждой таблице.
- **Несколько представлений**: отображение одних и тех же записей в виде сетки, канбан-доски, календаря, диаграммы Ганта или галереи.
- **Редактирование через команды**: изменения модели проходят через единый слой команд с разрешениями и точками подключения для необязательной истории и совместного редактирования.
- **Поля с формулами**: подключение полей Base к конвейеру вычисления формул Univer.
- **Рабочая область в браузере**: отрисовка представлений, выделение, редактирование, буфер обмена, прокрутка и панели.
- **Хранение данных**: создание, восстановление и сохранение `IBaseSnapshot` без прямого изменения работающего снимка.

## Режим пресетов

В настоящее время отдельного пресета для Univer Bases нет. Для модели и браузерного интерфейса используйте режим плагинов.

## Режим плагинов

### Установка

Добавьте два пакета Bases в среду Univer, описанную в разделе [Установка и базовое использование](/guides/bases/getting-started/installation):

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### Регистрация плагинов продукта

Сначала зарегистрируйте общую среду, механизм формул и лицензию Pro, как показано в руководстве по установке, а затем плагины Bases:

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin` регистрирует модель Base, команды, реестры полей и представлений, интеграцию формул и разрешения. `UniverBasesUIPlugin` добавляет рабочую область с отрисовкой и взаимодействие в браузере.
