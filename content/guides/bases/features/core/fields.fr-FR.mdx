Les champs définissent le schéma d'une table de base. Chaque champ a un type, une configuration, une valeur par défaut, et des capacités telles que le tri, le filtrage, le regroupement ou l'affichage sur une carte.

### Téléversement des pièces jointes [#attachment-upload]

Configurer la gestion du téléchargement au même endroit où le plugin d'interface utilisateur Bases est enregistré :

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/*', '.pdf'],
    maxSize: 10 * 1024 * 1024,
    upload: uploadAttachment,
  },
})
```

`uploadAttachment` est une fonction que l'application fournit, avec la signature `(file: File) => Promise<IBaseAttachment>`, et elle retourne un objet de pièce jointe tel que celui de l'exemple ci-dessous. `maxSize` se mesure en octets. Si aucun téléchargeur n'est fourni, le plugin essaie l'image IO puis Base64, ce qui rend l'instantané plus grand. Un déploiement de production doit connecter le stockage réel des fichiers et valider le type de fichier, la taille et les permissions de téléchargement sur le moteur.

### Personnes et groupes

Passer les candidats de sélection à travers les options `personOptions` et `groupOptions` du plugin UA Bases. Chaque élément a `id`, `name` ainsi qu'une option `avatar`. Ces options ne contrôlent que ce que les sélectionneurs affichent; les permissions de connexion et d'accès restent la responsabilité de l'application.

## Types de champs

| Usage | `BaseFieldType` |
| --- | --- |
| Texte et coordonnées | `Text`, `Link`, `Phone`, `Email` |
| Nombres et progression | `Number`, `Currency`, `Progress`, `Rating` |
| Choix et membres | `Checkbox`, `SingleSelect`, `MultiSelect`, `Person`, `Group` |
| Dates et pièces jointes | `Date`, `Attachment` |
| Calculs et relations | `Formula`, `RecordLink` |
| Valeurs générées et audit | `Numbering`, `RecordId`, `CreatedBy`, `UpdatedBy`, `CreatedAt`, `UpdatedAt` |

Le système gère les champs de numérotation et de vérification. Les calculs sont décrits en [Formules](/guides/bases/features/core/formulas) et les relations en [Enregistrements, liens et hiérarchie](/guides/bases/features/core/records).

## Ajouter des champs

```ts
const table = base.getTableById('tasks')
if (!table) throw new Error('Tasks table not found')

const title = table.addField('Title', univerAPI.Enum.BaseFieldType.Text)

const priority = table.addField(
  'Priority',
  univerAPI.Enum.BaseFieldType.SingleSelect,
  {
    field: {
      config: {
        options: [
          { id: 'high', name: 'High', color: '#ef4444' },
          { id: 'low', name: 'Low', color: '#22c55e' },
        ],
      },
    },
  },
)
```

## Mettre à jour des champs

```ts
priority.setName('Impact')
priority.update({ description: 'Business priority' })
priority.setConfig({
  options: [
    { id: 'p0', name: 'P0', color: '#dc2626' },
    { id: 'p1', name: 'P1', color: '#f97316' },
  ],
})
```

## Modifier le type d’un champ

```ts
priority.changeType(univerAPI.Enum.BaseFieldType.Text, {})
```

Modifier le type de champ peut normaliser les valeurs existantes. Vérifier les données dans l'application avant d'appliquer un changement de schéma à une table de production.

## Pièces jointes

Une pièce jointe nécessite un ID stable, un nom et une source que le navigateur peut atteindre. L'exemple suppose que l'application a déjà téléchargé le fichier:

```ts
const attachments = table.addField('Files', univerAPI.Enum.BaseFieldType.Attachment)
const record = table.getRecords()[0]
if (!record) throw new Error('Create a record first')

record.setAttachments(attachments.getId(), [{
  id: 'brief-1',
  name: 'brief.pdf',
  mimeType: 'application/pdf',
  source: 'https://example.com/files/brief.pdf',
}])
```

`setAttachments()` remplace la liste complète des pièces jointes pour la cellule. Utilisez `getAttachments()` pour lire la liste et `deleteAttachments()` afin de supprimer les entrées individuelles. Remplacez l'URL de l'exemple par une adresse que les utilisateurs peuvent atteindre.
