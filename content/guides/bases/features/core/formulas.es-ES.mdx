---
title: Fórmulas
---

Un campo de fórmula Bases calcula un valor récord de los datos en su tabla. `UniverBasesPlugin` registra automáticamente la dependencia del motor de fórmulas.

## Registrar compatibilidad con fórmulas

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

## Crear un campo de fórmula

```ts
const formulaTableName = table.getFormulaName()
const total = table.addField('Total', univerAPI.Enum.BaseFieldType.Formula, {
  field: {
    config: {
      formula: `=SUM(${formulaTableName}[[#This Row],[Price]],${formulaTableName}[[#This Row],[Tax]])`,
    },
  },
  externalReferences: [],
})
```

Cada escritura a un campo de fórmula debe incluir `externalReferences`. Pase `[]` sólo cuando la fórmula referencia campos en la misma Base. Para las fórmulas de unidad cruzada, use [`buildReference`](/reference/facade/formula#buildreference) e incluya cada fuente estable en el array.

## Notas

- Un campo de fórmula tiene un valor derivado, por lo que el código de aplicación no debe escribir directamente a las células de fórmula.
- Las expresiones de la fórmula utilizan referencias de campo estructuradas, por ejemplo `Table[[#This Row],[Price]]`.
- Después de importar una gran instantánea, recalcular fórmulas antes de presentar resultados a los usuarios.
