---
title: Univer Bases API
description: Univer Bases アプリケーションで Facade API を使用する方法を説明します。
---

Facade APIは、ベースモデル上に構築されたアプリケーション・フェース・レイヤーです。ベース、テーブル、フィールド、レコード、ビューの作成、フィルタ、ソート、グループ、選択、UIナビゲーションの一般的な操作をカバーしています。

<Callout type="warning" title="キューション">
  ベースモデルの変更は同期です。UIのアクティベーションメソッドは約束を返すので、呼び出し側はそれらを待っていなければなりません。
</Callout>

## Facade エントリを有効にする

アプリケーションが使用する各ベース機能のファサードエントリをインポートします。

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Univerインスタンスと必要なプラグインが登録された後にのみAPIオブジェクトを作成します。

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Base を作成・取得する

`createBase`はファサードレイヤーを介してベースユニットを作成します。 低レベルで動作するコードは、`univer.createUnit(UniverInstanceType.UNIVER_BASE, snapshot)`で直接ユニットを作成することができます。

```ts
const base = univerAPI.createBase({
  id: 'base-demo',
  name: 'Base Demo',
})

const activeBase = univerAPI.getActiveBase()
const sameBase = univerAPI.getBase(base.getId())
```

## テーブルを作成する

```ts
const table = base.insertTable('Tasks', { primaryFieldName: 'Title' })
const status = table.addField('Status', univerAPI.Enum.BaseFieldType.SingleSelect)
```

## レコードを操作する

```ts
const record = table.addRecord({
  Title: 'Write docs',
  Status: 'In progress',
}, univerAPI.Enum.BaseFieldKeyEnum.Name)

record.setValue(status.getId(), 'Done')
```

## UI の状態を操作する

`@univerjs-pro/bases-ui/facade`は、テーブルとビューをアクティブにするためのUI APIを追加し、選択の管理、スクロール、編集、パネルを追加します。

```ts
const baseUI = univerAPI.getBaseUI()
const view = table.getViews()[0]
if (!view) throw new Error('No table view')
await baseUI.activateTable(table.getId())
await baseUI.activateView(view.getId())
baseUI.setSelection({
  type: 'grid-record',
  tableId: table.getId(),
  viewId: view.getId(),
  recordId: record.getId(),
})
```
