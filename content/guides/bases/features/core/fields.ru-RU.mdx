Поля определяют схему базовой таблицы. Каждое поле имеет тип, конфигурацию, значение по умолчанию и такие возможности, как сортировка, фильтрация, группировка или отображение на карте.

### Загрузка вложений [#attachment-upload]

Настройте обработку загрузки в том же месте, где зарегистрирован плагин пользовательского интерфейса Bases:

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/*', '.pdf'],
    maxSize: 10 * 1024 * 1024,
    upload: uploadAttachment,
  },
})
```

`uploadAttachment` — это функция, которую предоставляет приложение, с подписью `(file: File) => Promise<IBaseAttachment>`, и оно возвращает объект вложения, такой как в примере ниже. `maxSize` измеряется в байтах. Если не поставляется загрузчик, плагин пробует IO изображения, а затем Base64, что делает снимок больше. Развертывание продукта должно подключать реальное хранилище файлов и проверять тип файла, размер и разрешения на загрузку на бэкэнде.

### Пользователи и группы

Передайте кандидатам на выбор опции `personOptions` и `groupOptions` плагина пользовательского интерфейса Bases. Каждый элемент имеет `id`, `name` или `avatar`. Эти опции контролируют только то, что отображает выборщик; вход и разрешения доступа остаются ответственностью приложения.

## Типы полей

| Назначение | `BaseFieldType` |
| --- | --- |
| Текст и контакты | `Text`, `Link`, `Phone`, `Email` |
| Числа и прогресс | `Number`, `Currency`, `Progress`, `Rating` |
| Выбор и участники | `Checkbox`, `SingleSelect`, `MultiSelect`, `Person`, `Group` |
| Даты и вложения | `Date`, `Attachment` |
| Вычисления и связи | `Formula`, `RecordLink` |
| Автоматические значения и аудит | `Numbering`, `RecordId`, `CreatedBy`, `UpdatedBy`, `CreatedAt`, `UpdatedAt` |

Выберите значения, используйте идентификаторы опций, а значения Person и Group используют идентификаторы членов приложения. Система управляет нумерацией и полями аудита. Расчеты описаны в [Формулы](/guides/bases/features/core/formulas), а отношения в [Записи, ссылки и иерархия](/guides/bases/features/core/records).

## Добавление полей

```ts
const table = base.getTableById('tasks')
if (!table) throw new Error('Tasks table not found')

const title = table.addField('Title', univerAPI.Enum.BaseFieldType.Text)

const priority = table.addField(
  'Priority',
  univerAPI.Enum.BaseFieldType.SingleSelect,
  {
    field: {
      config: {
        options: [
          { id: 'high', name: 'High', color: '#ef4444' },
          { id: 'low', name: 'Low', color: '#22c55e' },
        ],
      },
    },
  },
)
```

## Обновление полей

```ts
priority.setName('Impact')
priority.update({ description: 'Business priority' })
priority.setConfig({
  options: [
    { id: 'p0', name: 'P0', color: '#dc2626' },
    { id: 'p1', name: 'P1', color: '#f97316' },
  ],
})
```

## Изменение типа поля

```ts
priority.changeType(univerAPI.Enum.BaseFieldType.Text, {})
```

Изменение типа поля может нормализовать существующие значения. Проверить данные в приложении перед применением изменения схемы к таблице производства.

## Вложения

Для вложения требуется стабильный идентификатор, имя и источник, к которому может обратиться браузер.Пример предполагает, что приложение уже загрузило файл:

```ts
const attachments = table.addField('Files', univerAPI.Enum.BaseFieldType.Attachment)
const record = table.getRecords()[0]
if (!record) throw new Error('Create a record first')

record.setAttachments(attachments.getId(), [{
  id: 'brief-1',
  name: 'brief.pdf',
  mimeType: 'application/pdf',
  source: 'https://example.com/files/brief.pdf',
}])
```

`setAttachments()` заменяет весь список вложений для ячейки. Используйте `getAttachments()` для чтения списка и `deleteAttachments()`, чтобы удалить отдельные записи. Замените примерный URL-адрес адресом, который пользователи могут получить.
