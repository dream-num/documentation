---
title: Права доступа
---

Вся База может быть выполнена только для чтения, как и отдельная таблица, поле, запись или просмотр. Это охватывает только для чтения отчеты и версии приложений, в которых пользователи могут редактировать только часть данных.

Зарегистрируйте плагин Bases и импортируйте `@univerjs-pro/bases/facade`, прежде чем звонить в любой из этих API.

## Режим только для чтения для Base

```ts
const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

await base.getPermission().setReadOnly()
console.log(base.getPermission().canEdit()) // false

await base.getPermission().setEditable()
```

## Ограничение отдельного объекта

Следующий пример ограничивает одну таблицу:

```ts
const table = base.getTables()[0]
if (!table) throw new Error('Create a table first')

await table.getPermission().setReadOnly()
await table.getPermission().setEditable()
```

Поля, записи и просмотры также выставляют `getPermission()`, как и панели инструментов и поворотные просмотры после регистрации их плагина.Создание редактируемого объекта ребенка не снимает ограничения на его родителя: если таблица читается только для чтения, создание записи внутри нее редактируемых не имеет эффекта.

`setReadOnly()` и `setEditable()` возвращают обещания, поэтому `await` им. Чтобы изменить несколько объектов за один вызов, используйте `base.getPermission().setObjectPermissions()`; [Фасад Базы](/reference/facade/base) перечисляет параметры.

## Копирование, экспорт и комментарии

Разрешения базового уровня также определяют, разрешено ли копирование, экспорт и комментирование.

```ts
import { UnitAction } from '@univerjs/protocol'

await base.getPermission().setPoint(UnitAction.Copy, false)
```

Используйте `UnitAction.Export` и `UnitAction.Comment` для экспорта и комментирования соответственно.

## Подключение прав приложения

Локальные разрешения регулируют то, что позволяет редактор. Совместное приложение также должно разрешать чтение контента, объединение совместной работы и отправку изменений на сервер; см. [Серверная интеграция](/server).

Во время тестирования используйте редактор, зрителя и пользователя без доступа, а также проверьте как действия на странице, так и прямые запросы.
