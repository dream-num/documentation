필드는 기본 테이블의 스키마를 정의합니다. 각 필드에는 유형, 구성, 기본 값, 기능, 분류, 필터링, 그룹화, 또는 카드에 표시와 같은 기능을 가지고 있습니다.

### 첨부 파일 업로드 [#attachment-upload]

Bases UI 플러그인이 등록되는 것과 동일한 장소에 업로드 처리 구성:

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/*', '.pdf'],
    maxSize: 10 * 1024 * 1024,
    upload: uploadAttachment,
  },
})
```

`uploadAttachment`는 애플리케이션이 제공하는 기능이며 서명 `(file: File) => Promise<IBaseAttachment>`와 함께 아래 예에서 첨부된 객체를 반환합니다. `maxSize`은 바이트로 측정됩니다. 업로드자가 공급되지 않은 경우 플러그인은 이미지를 IO와 그 때 Base64를 트리거합니다. 프로덕션은 실제 파일 저장 및 유효성 파일 유형, 크기 및 백엔드에 대한 다운로드 권한을 연결해야합니다.

### 사용자 및 그룹

`personOptions` 및 `groupOptions` 옵션의 Bases UI 플러그인을 통해 픽업 후보를 통과하십시오. 각 항목에는 `id`, `name`와 옵션 `avatar`가 있습니다. 이 옵션은 픽업 디스플레이 만 제어합니다. 로그인 및 액세스 권한은 응용 프로그램의 책임에 남아 있습니다.

## 필드 유형

| 용도 | `BaseFieldType` |
| --- | --- |
| 텍스트 및 연락처 | `Text`, `Link`, `Phone`, `Email` |
| 숫자 및 진행률 | `Number`, `Currency`, `Progress`, `Rating` |
| 선택 항목 및 구성원 | `Checkbox`, `SingleSelect`, `MultiSelect`, `Person`, `Group` |
| 날짜 및 첨부 파일 | `Date`, `Attachment` |
| 계산 및 관계 | `Formula`, `RecordLink` |
| 자동 생성 및 감사 | `Numbering`, `RecordId`, `CreatedBy`, `UpdatedBy`, `CreatedAt`, `UpdatedAt` |

값 사용 옵션 ID 및 사람 및 그룹 값은 응용 프로그램에서 회원 ID를 사용합니다. 시스템은 번호 및 감사 필드를 관리합니다. 계산은 [팟캐스트](/guides/bases/features/core/formulas) 및 [기록, 링크 및 계층](/guides/bases/features/core/records)의 관계에 설명됩니다.

## 필드 추가

```ts
const table = base.getTableById('tasks')
if (!table) throw new Error('Tasks table not found')

const title = table.addField('Title', univerAPI.Enum.BaseFieldType.Text)

const priority = table.addField(
  'Priority',
  univerAPI.Enum.BaseFieldType.SingleSelect,
  {
    field: {
      config: {
        options: [
          { id: 'high', name: 'High', color: '#ef4444' },
          { id: 'low', name: 'Low', color: '#22c55e' },
        ],
      },
    },
  },
)
```

## 필드 업데이트

```ts
priority.setName('Impact')
priority.update({ description: 'Business priority' })
priority.setConfig({
  options: [
    { id: 'p0', name: 'P0', color: '#dc2626' },
    { id: 'p1', name: 'P1', color: '#f97316' },
  ],
})
```

## 필드 유형 변경

```ts
priority.changeType(univerAPI.Enum.BaseFieldType.Text, {})
```

필드의 유형 변경은 기존의 값을 정상화 할 수 있습니다. 스키마 변경을 생산 테이블에 적용하기 전에 응용 프로그램에 데이터 확인.

## 첨부 파일 필드

첨부 파일에는 안정적인 ID, 이름 및 브라우저가 도달 할 수있는 소스가 필요합니다. 예를 들어 응용 프로그램이 이미 파일을 업로드 한 것으로 가정합니다.

```ts
const attachments = table.addField('Files', univerAPI.Enum.BaseFieldType.Attachment)
const record = table.getRecords()[0]
if (!record) throw new Error('Create a record first')

record.setAttachments(attachments.getId(), [{
  id: 'brief-1',
  name: 'brief.pdf',
  mimeType: 'application/pdf',
  source: 'https://example.com/files/brief.pdf',
}])
```

`setAttachments()`는 세포를 위한 전체 부착 목록을 대체합니다. `getAttachments()`를 사용하여 목록을 읽고 `deleteAttachments()`가 개별 항목을 제거하도록 합니다. 사용자가 도달 할 수있는 주소로 예를 들어 URL을 대체하십시오.
