Los campos definen el esquema de una tabla Base. Cada campo tiene un tipo, una configuración, un valor predeterminado, y capacidades como clasificar, filtrar, agrupar o mostrar en una tarjeta.

### Carga de archivos adjuntos [#attachment-upload]

Configurar el manejo de carga en el mismo lugar donde se registra el plugin Bases UI:

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/*', '.pdf'],
    maxSize: 10 * 1024 * 1024,
    upload: uploadAttachment,
  },
})
```

`uploadAttachment` es una función que la aplicación proporciona, con la firma `(file: File) => Promise<IBaseAttachment>`, y devuelve un objeto adjunto como el siguiente ejemplo. `maxSize` se mide en bytes. Si no se suministra ningún cargador, el plugin intenta la imagen IO y luego Base64, que hace que la instantánea sea más grande. Un despliegue de producción debe conectar el almacenamiento real de archivos y validar el tipo de archivo, tamaño, respaldo y descarga.

### Personas y grupos

Pase a los candidatos de picker a través de las opciones `personOptions` y `groupOptions` del plugin Bases UI. Cada artículo tiene `id`, `name`, y un `avatar` opcional. Estas opciones controlan sólo lo que los piquetes muestran; los permisos de acceso y acceso siguen siendo la responsabilidad de la aplicación.

## Tipos de campo

| Uso | `BaseFieldType` |
| --- | --- |
| Texto y datos de contacto | `Text`, `Link`, `Phone`, `Email` |
| Números y progreso | `Number`, `Currency`, `Progress`, `Rating` |
| Opciones y miembros | `Checkbox`, `SingleSelect`, `MultiSelect`, `Person`, `Group` |
| Fechas y adjuntos | `Date`, `Attachment` |
| Cálculos y relaciones | `Formula`, `RecordLink` |
| Valores generados y auditoría | `Numbering`, `RecordId`, `CreatedBy`, `UpdatedBy`, `CreatedAt`, `UpdatedAt` |

Select values use option IDs, and Person and Group values use member IDs from the application. The system manages numbering and audit fields. Calculations are described in [Formulas](/guides/bases/features/core/formulas), and relations in [Registros, enlaces y jerarquía](/guides/bases/features/core/records).

## Agregar campos

```ts
const table = base.getTableById('tasks')
if (!table) throw new Error('Tasks table not found')

const title = table.addField('Title', univerAPI.Enum.BaseFieldType.Text)

const priority = table.addField(
  'Priority',
  univerAPI.Enum.BaseFieldType.SingleSelect,
  {
    field: {
      config: {
        options: [
          { id: 'high', name: 'High', color: '#ef4444' },
          { id: 'low', name: 'Low', color: '#22c55e' },
        ],
      },
    },
  },
)
```

## Actualizar campos

```ts
priority.setName('Impact')
priority.update({ description: 'Business priority' })
priority.setConfig({
  options: [
    { id: 'p0', name: 'P0', color: '#dc2626' },
    { id: 'p1', name: 'P1', color: '#f97316' },
  ],
})
```

## Cambiar tipo de campo

```ts
priority.changeType(univerAPI.Enum.BaseFieldType.Text, {})
```

Cambiar el tipo de campo puede normalizar los valores existentes. Verificar los datos en la aplicación antes de aplicar un cambio de esquema a una tabla de producción.

## Archivos adjuntos

Un accesorio requiere un ID estable, un nombre y una fuente que el navegador puede alcanzar. El ejemplo supone que la aplicación ya ha subido el archivo:

```ts
const attachments = table.addField('Files', univerAPI.Enum.BaseFieldType.Attachment)
const record = table.getRecords()[0]
if (!record) throw new Error('Create a record first')

record.setAttachments(attachments.getId(), [{
  id: 'brief-1',
  name: 'brief.pdf',
  mimeType: 'application/pdf',
  source: 'https://example.com/files/brief.pdf',
}])
```

`setAttachments()` reemplaza toda la lista de archivos adjuntos para la celda. Utilice `getAttachments()` para leer la lista y `deleteAttachments()` a eliminar las entradas individuales. Reemplazar la URL de ejemplo con una dirección que los usuarios pueden alcanzar.
