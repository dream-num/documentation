---
title: 数式
---

ベース式フィールドは、テーブル内のデータからレコード値を計算します。 `UniverBasesPlugin`は、式エンジン依存を自動的に登録します。

## 数式機能を登録する

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

## 数式フィールドを作成する

```ts
const formulaTableName = table.getFormulaName()
const total = table.addField('Total', univerAPI.Enum.BaseFieldType.Formula, {
  field: {
    config: {
      formula: `=SUM(${formulaTableName}[[#This Row],[Price]],${formulaTableName}[[#This Row],[Tax]])`,
    },
  },
  externalReferences: [],
})
```

各書式フィールドに書き込みは、`externalReferences` を含まなければなりません。 式が同じベースでフィールドを参照するときにのみ、`[]`を渡します。 ユニット式を横断するには、[`buildReference`](/reference/facade/formula#buildreference)を使用し、配列内のすべての安定したソース結合を含みます。

## 注意事項

- 式フィールドは派生した値を保持するので、アプリケーションコードは式セルに直接書き込むべきではありません。
- 式式は、構造化されたフィールド参照を使用します。たとえば、`Table[[#This Row],[Price]]`。
- 大規模なスナップショットをインポートした後、結果をユーザーに提示する前に式を再計算します。
