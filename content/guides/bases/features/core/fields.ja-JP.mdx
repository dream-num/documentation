title: フィールド

フィールドは、ベーステーブルのスキーマを定義します。各フィールドには、タイプ、構成、デフォルト値、ソート、フィルタリング、グループ化、カード表示などの機能があります。

### 添付ファイルのアップロード [#attachment-upload]

Bases UI プラグインが登録されている場所と同じ場所にアップロード処理を設定:

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/*', '.pdf'],
    maxSize: 10 * 1024 * 1024,
    upload: uploadAttachment,
  },
})
```

`uploadAttachment`は、アプリケーションが提供する機能であり、シグネチャ`(file: File) => Promise<IBaseAttachment>`で、以下の例の1つのような添付オブジェクトを返します。 `maxSize`がバイトで測定されます。 アップロードがない場合、プラグインはイメージIOを試し、その後、Base64をスナップショットを大きくします。 生産の展開は、実際のファイルストレージを接続し、ファイルタイプ、サイズ、およびバックエンドの許可をダウンロードする必要があります。

### ユーザーとグループ

Bases UI プラグインの `personOptions` と `groupOptions` のオプションを使用して、ピッカー候補を渡す。各項目に `id`、`name`、およびオプション `avatar` があります。これらのオプションは、ピッカーの表示のみを制御します。ログインとアクセス許可は、アプリケーションに対する責任を保ちます。

## フィールドの種類

| 用途 | `BaseFieldType` |
| --- | --- |
| テキストと連絡先 | `Text`, `Link`, `Phone`, `Email` |
| 数値と進捗 | `Number`, `Currency`, `Progress`, `Rating` |
| 選択肢とメンバー | `Checkbox`, `SingleSelect`, `MultiSelect`, `Person`, `Group` |
| 日付と添付ファイル | `Date`, `Attachment` |
| 計算と関連付け | `Formula`, `RecordLink` |
| 自動生成と監査 | `Numbering`, `RecordId`, `CreatedBy`, `UpdatedBy`, `CreatedAt`, `UpdatedAt` |

値選択オプション ID と Person と Group の値は、アプリケーションからメンバー ID を使用します。このシステムは、番号と監査フィールドを管理します。計算は [フォーミュラ](/guides/bases/features/core/formulas) で記述され、[レコード、リンク、階層](/guides/bases/features/core/records)の関連性がわかります。

## フィールドを追加する

```ts
const table = base.getTableById('tasks')
if (!table) throw new Error('Tasks table not found')

const title = table.addField('Title', univerAPI.Enum.BaseFieldType.Text)

const priority = table.addField(
  'Priority',
  univerAPI.Enum.BaseFieldType.SingleSelect,
  {
    field: {
      config: {
        options: [
          { id: 'high', name: 'High', color: '#ef4444' },
          { id: 'low', name: 'Low', color: '#22c55e' },
        ],
      },
    },
  },
)
```

## フィールドを更新する

```ts
priority.setName('Impact')
priority.update({ description: 'Business priority' })
priority.setConfig({
  options: [
    { id: 'p0', name: 'P0', color: '#dc2626' },
    { id: 'p1', name: 'P1', color: '#f97316' },
  ],
})
```

## フィールドの型を変更する

```ts
priority.changeType(univerAPI.Enum.BaseFieldType.Text, {})
```

フィールドの種類を変更すると、既存の値が正規化される場合があります。スキーマの変更をプロダクションテーブルに適用する前に、アプリケーション内のデータを検証します。

## 添付ファイル

添付ファイルには、ブラウザが到達できる安定したID、名前、およびソースが必要です。 この例では、アプリケーションが既にアップロードしたファイルを仮定します。

```ts
const attachments = table.addField('Files', univerAPI.Enum.BaseFieldType.Attachment)
const record = table.getRecords()[0]
if (!record) throw new Error('Create a record first')

record.setAttachments(attachments.getId(), [{
  id: 'brief-1',
  name: 'brief.pdf',
  mimeType: 'application/pdf',
  source: 'https://example.com/files/brief.pdf',
}])
```

`setAttachments()`は、すべての添付ファイルリストをセルに置き換えます。`getAttachments()`を使用して、リストと`deleteAttachments()`を読んで、個々のエントリを削除します。 ユーザーが到達できるアドレスに例のURLを置き換えます。
