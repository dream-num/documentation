アプリケーションに利用可能なファサード API は、現在のユニットタイプと登録されたプラグインに依存します。このページでは、Univer Bases アプリケーションが一般的に使用される API について説明します。

## インポート

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs/ui/facade'

const univerAPI = FUniver.newAPI(univer)
```

## コマンド

Univerのほとんどの操作は、コマンドシステムを通過します。すべての操作は同じパス、undo、redo、およびコラボレーションがそれらすべてをカバーすることができるので。

<Callout>
  後ろのデザインについては、[Univerコマンドシステム](/blog/univer#command-system)を参照してください。
</Callout>

### コマンドの監視

`Event.BeforeCommandExecute` を使用して、コマンドが実行される前にコードを実行し、`Event.CommandExecuted`が終了した後にコードを実行します。

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('コマンド実行前:', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('コマンド実行後:', id, params)
})
```

`event.cancel`を`BeforeCommandExecute`リスナー内に`true`を設定し、コマンドの実行を防止します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'base.command.set-base-name') {
    event.cancel = true
  }
})
```

どちらのリスナーも`IDisposable`を返します。 返されたオブジェクトの削除は不要です。

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### コマンドの実行

コマンド ID とそのパラメータが知られているとき、`FUniver.executeCommand` はコマンドを直接実行します。次の Bases コマンドは、アクティブな Base の名前を変更します。

```typescript
const base = univerAPI.getActiveBase()

if (base) {
  await univerAPI.executeCommand('base.command.set-base-name', {
    unitId: base.getId(),
    name: 'プロジェクトノート',
  })
}
```

## イベント API

`univerAPI.Event`のイベントは、Univerコアから来て、現在のアプリケーションに登録されたプラグインから来ます。コアは、すべての製品が共有するコマンドとユニットイベントを提供します。ベースプラグインは、テーブル、フィールド、レコード、ビュー、その他のベースの変更のためのイベントを追加します。イベントを使用する前に、プラグインが登録されていることを確認してください。

[ファサードイベントの参照](/reference/facade/events)は、現在のリリースで利用可能なイベント名とパラメータタイプをリストします。

`addEvent` を購読し、返されたオブジェクトを退会して退会します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'base.command.set-base-name') {
    console.log('Base名が変更されました')
  }
})

// 不要になったリスナーを削除します
disposable.dispose()
```

## 元に戻すとやり直し

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## システムクリップボード

Bases UI プラグインを登録すると、`copy` と `paste` は現在のBase選択範囲とキャレット位置に対して動作します。

```typescript
await univerAPI.copy()
await univerAPI.paste()
```

<Callout>
  ブラウザのネイティブクリップボード API をコピーして貼り付けます。ユーザアクションから発信されず、クリップボードの許可が利用できなくなったときに、ページがフォーカスされていないときには失敗します。 [MDN クリップボードのドキュメント](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API) を参照してください。
</Callout>

## UI

ベースインターフェイスのメニュー、ツールバー、その他の領域を拡張するには、[ベースUIコンポーネント](/guides/bases/ui/components)を参照してください。

## WebSocket

WebSocket API を使用するには、`@univerjs/network` をインストールし、`UniverNetworkPlugin`を登録し、Facade 拡張機能をインポートします。

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

アプリケーションは、ソケットイベントを購読し、メッセージを送信し、接続を閉じることができます。

```typescript
const socket = univerAPI.createSocket('wss://example.com/bases')

socket.open$.subscribe(() => socket.send('hello'))
socket.message$.subscribe((message) => console.log('WebSocket メッセージ:', message.data))
socket.error$.subscribe((error) => console.error('WebSocket エラー:', error))
socket.close()
```

## 列挙型 API

`univerAPI.Enum`の共通列のタイプをファサードは露出します:

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_BASE)
console.log(univerAPI.Enum.BaseFieldType.Text)
```

## ユーティリティメソッド API

`univerAPI.Util`で共有ユーティリティメソッドが公開されています。

```typescript
console.log(univerAPI.Util.tools.isString('Univer Bases')) // true
```
