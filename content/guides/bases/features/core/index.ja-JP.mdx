Univerベースは、構造化されたデータモデルとブラウザのワークベンチを組み合わせています。2つのWeb SDKパッケージは、これらのコンポーネントを提供し、それらが独立した`UNIVER_BASE`ユニットとして実行されます。

## 機能

| コア機能 | 目的: |
| --- | --- |
| [フィールドと添付ファイル](/guides/bases/features/core/fields) | テキスト、数字、選択、メンバー、日付、添付ファイル。 |
| [レコード、リンク、階層](/guides/bases/features/core/records) | バッチ編集、ローカルペジネーション、テーブルリンク、親子記録。 |
| [プロフィール](/guides/bases/features/core/views) | グリッド、カンバン、カレンダー、ガント、ギャラリー、フィルタリング、ソート、グループ化、条件付き色。 |
| [フォーミュラ](/guides/bases/features/core/formulas) | フィールドの計算と明示的に設定されたクロスドキュメントの参照。 |
| [パーミッション](/guides/bases/features/core/permissions) | ベース、テーブル、フィールド、レコード、ビューの権限を編集します。 |

エクステンションプラグインとして取引所、ダッシュボード、コメント、履歴が提供されます。 [ベース機能の概要](/guides/bases#主な機能) を参照してください。

## プラグインモード

### インストール

[インストールと基本的な使い方](/guides/bases/getting-started/installation) で構成されるランタイムに 2 つの Bases 製品パッケージを追加します。

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### 製品プラグインの登録

インストールガイドの後、共有ランタイム、フォーミュラエンジン、ライセンスを最初に登録し、ベースプラグインを登録します。

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin`は、ベースモデル、コマンド、フィールド、ビューレギュレーション、式統合、およびパーミッションを提供します。 `UniverBasesUIPlugin`では、レンダリングされたワークベンチとそれに付随するブラウザのインタラクションを追加します。

## プリセットモード

Univerベースはまだ専用のプリセットはありません。モデルとブラウザUIの両方にプラグインモードを使用します。
