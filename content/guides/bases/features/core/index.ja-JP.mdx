Univer Bases のコアは、構造化データモデルとブラウザー向けワークベンチを組み合わせたものです。モデルと UI は 2 つの Univer Pro パッケージで提供され、独立した `UNIVER_BASE` ユニットとして動作します。

## 機能

- **テーブル、フィールド、レコード**：各テーブルに型付きフィールドと順序付きレコードを保存します。
- **複数のビュー**：同じレコードをグリッド、Kanban、カレンダー、Gantt、ギャラリーの各ビューで表示します。
- **コマンド駆動の編集**：モデル変更を 1 つのコマンド層に集約し、権限と、任意の履歴・コラボレーション統合用フックを提供します。
- **数式フィールド**：Base のフィールドを Univer の数式計算パイプラインに接続します。
- **ブラウザーワークベンチ**：ビューを描画し、選択、編集、クリップボード、スクロール、パネルを提供します。
- **永続化**：実行中のスナップショットを直接変更せずに `IBaseSnapshot` を作成、復元、保存します。

## プリセットモード

現在、Univer Bases 専用のプリセットはありません。モデルとブラウザー UI の両方でプラグインモードを使用してください。

## プラグインモード

### インストール

[インストールと基本的な使用方法](/guides/bases/getting-started/installation)で説明する Univer ランタイムに、2 つの Bases パッケージを追加します。

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### 製品プラグインの登録

インストールガイドに従って共有ランタイム、数式エンジン、Pro ライセンスを先に登録し、その後に Bases プラグインを登録します。

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin` は Base モデル、コマンド、フィールドとビューのレジストリ、数式統合、権限を登録します。`UniverBasesUIPlugin` は描画されたワークベンチとブラウザー操作を追加します。
