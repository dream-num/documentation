---
title: Vistas
---

Las vistas permiten a los usuarios ver la misma tabla a través de diferentes proyecciones. Las bases incluyen los tipos de vista de cuadrícula, kanban, calendario, Gantt y galería.

## Crear vistas

```ts
const grid = table.createView('All records', univerAPI.Enum.BaseViewType.Grid)

const kanban = table.createView(
  'By status',
  univerAPI.Enum.BaseViewType.Kanban,
  {
    view: {
      config: { groupFieldId: 'status' },
    },
  },
)
```

## Activar una vista en la interfaz de usuario

```ts
const baseUI = univerAPI.getBaseUI()
await baseUI.activateTable(table.getId())
await baseUI.activateView(kanban.getId())
```

## Configurar reglas de vista

```ts
kanban.setGroup([
  { fieldId: 'status', direction: univerAPI.Enum.BaseSortDirection.ASC },
])

kanban.setFilter({
  conjunction: univerAPI.Enum.BaseFilterConjunction.AND,
  conditions: [
    { fieldId: 'archived', operator: univerAPI.Enum.BaseFilterOperator.IS, operand: false },
  ],
})
```

Utilizar configuraciones de campo a nivel de vista para visibilidad, anchos y visualización de tarjetas sin cambiar el esquema de la tabla subyacente.
