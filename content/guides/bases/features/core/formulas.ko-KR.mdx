---
title: 수식
---

Bases 공식 필드는 테이블의 데이터에서 레코드 값을 계산합니다. `UniverBasesPlugin`는 공식 엔진 의존도를 자동으로 기록합니다.

## 수식 지원 등록

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

## 수식 필드 만들기

```ts
const formulaTableName = table.getFormulaName()
const total = table.addField('Total', univerAPI.Enum.BaseFieldType.Formula, {
  field: {
    config: {
      formula: `=SUM(${formulaTableName}[[#This Row],[Price]],${formulaTableName}[[#This Row],[Tax]])`,
    },
  },
  externalReferences: [],
})
```

공식 필드에 모든 쓰기는 `externalReferences`를 포함해야합니다. 동일한 기본의 공식 참조 필드가있을 때 `[]` 만 패스하십시오. 교차 단위 공식을 위해 [`buildReference`](/reference/facade/formula#buildreference)을 사용하여 배열에 모든 안정적인 소스 바인딩을 포함합니다.

## 참고 사항

- 공식 필드는 파생 된 값을 보유하므로 응용 코드는 공식 셀에 직접 작성하지 않아야합니다.
- 공식 표현식은 구조화된 필드 참조를 사용하며 예를 들어 `Table[[#This Row],[Price]]`.
- 큰 스냅 샷을 가져 오기 후, 사용자에게 결과를 제시하기 전에 공식을 재 계산합니다.
