Univer Bases combina un modelo de datos estructurado con un banco de trabajo del navegador. Dos paquetes Web SDK proporcionan estos componentes, y juntos funcionan como una unidad `UNIVER_BASE` independiente.

## Funciones

| Función básica | Propósito |
| --- | --- |
| [Campos y apegos](/guides/bases/features/core/fields) | Texto, números, opciones, miembros, fechas y apegos. |
| [Registros, enlaces y jerarquía](/guides/bases/features/core/records) | Edición de lotes, paginación local, enlaces de mesa y registros de padres e hijos. |
| [Vistas](/guides/bases/features/core/views) | Grid, Kanban, Calendario, Gantt, Galería, filtrado, clasificación, agrupación y colores condicionales. |
| [Formulas](/guides/bases/features/core/formulas) | Cálculos de campo y referencias de documentos cruzados configuradas explícitamente. |
| [Permisos](/guides/bases/features/core/permissions) | Edición de permisos para Bases, tablas, campos, registros y vistas. |

Intercambio, tableros, comentarios e historia se proporcionan como plugins de extensión. Vea el [Las bases presentan una visión general](/guides/bases#aspectos-destacados).

## Modo plugin

### Instalación

Agregue los dos paquetes de productos Bases al tiempo de ejecución configurado en [Instalación &quot; Usage básico](/guides/bases/getting-started/installation):

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### Registro de los plugins del producto

Siguiendo la guía de instalación, registre el tiempo de ejecución compartido, el motor de fórmulas y la licencia primero, a continuación, registren los plugins Bases:

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin` proporciona el modelo Base, comandos, registros de campo y vista, integración de fórmulas y permisos. `UniverBasesUIPlugin` añade el banco de trabajo renderizado y las interacciones del navegador que lo acompañan.

## Modo preset

Univer Bases todavía no tiene un preset dedicado. Utilice el modo plugin para el modelo y el navegador UI.
