El núcleo de Univer Bases combina un modelo de datos estructurados con un entorno de trabajo para el navegador. El modelo y la interfaz se distribuyen en dos paquetes de Univer SDK Pro y funcionan como una unidad `UNIVER_BASE` independiente.

## Funciones

- **Tablas, campos y registros**: almacena campos tipados y registros ordenados en cada tabla.
- **Varias vistas**: proyecta los mismos registros en vistas de cuadrícula, Kanban, calendario, Gantt y galería.
- **Edición mediante comandos**: dirige los cambios del modelo por una capa de comandos con permisos y puntos de integración para el historial y la colaboración opcionales.
- **Campos de fórmula**: conecta los campos de Base con el flujo de cálculo de fórmulas de Univer.
- **Entorno de trabajo del navegador**: renderiza vistas y ofrece selección, edición, portapapeles, desplazamiento y paneles.
- **Persistencia**: crea, restaura y guarda un `IBaseSnapshot` sin modificar directamente la instantánea en ejecución.

## Modo preset

Univer Bases no ofrece actualmente un preset específico. Usa el modo plugin tanto para el modelo como para la interfaz del navegador.

## Modo plugin

### Instalación

Añade los dos paquetes de Bases al entorno de Univer descrito en [Instalación y uso básico](/guides/bases/getting-started/installation):

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### Registro de los plugins del producto

Registra primero el entorno compartido, el motor de fórmulas y la licencia Pro como indica la guía de instalación; después registra los plugins de Bases:

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin` registra el modelo Base, los comandos, los registros de campos y vistas, la integración de fórmulas y los permisos. `UniverBasesUIPlugin` añade el entorno renderizado y las interacciones del navegador.
