Facade API는 기초 모형에 건축된 신청 직면 층입니다. 그것은 기초, 테이블, 분야, 기록 및 전망, 뿐 아니라 여과기, 종류, 그룹, 선택 및 UI 항법 창조를 위한 일반적인 가동을 포함합니다.

<Callout type="warning" title="주 메뉴">
  기본 모델로 변경은 비동기입니다. UI 활성화 방법 반환 약속, 그래서 콜러는 그들을 기다리고 있어야합니다.
</Callout>

## Facade 진입점 활성화

응용 프로그램 용도에 사용되는 각 Bases 기능에 대한 외관 항목을 가져 오기 :

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Univer 인스턴스와 필요한 플러그인이 등록된 후만 API 객체를 만듭니다:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Base 생성 및 읽기

`createBase`는 정면 층을 통해서 기본적인 단위를 창조합니다. 더 낮은 수준에서 운영하는 부호는 `univer.createUnit(UniverInstanceType.UNIVER_BASE, snapshot)`로 직접 단위를 창조할 수 있습니다.

```ts
const base = univerAPI.createBase({
  id: 'base-demo',
  name: 'Base Demo',
})

const activeBase = univerAPI.getActiveBase()
const sameBase = univerAPI.getBase(base.getId())
```

## 테이블 생성

```ts
const table = base.insertTable('Tasks', { primaryFieldName: 'Title' })
const status = table.addField('Status', univerAPI.Enum.BaseFieldType.SingleSelect)
```

## 레코드 작업

```ts
const record = table.addRecord({
  Title: 'Write docs',
  Status: 'In progress',
}, univerAPI.Enum.BaseFieldKeyEnum.Name)

record.setValue(status.getId(), 'Done')
```

## UI 상태 작업

`@univerjs-pro/bases-ui/facade`는 테이블과 레이아웃을 활성화하고 선택, 스크롤, 편집 및 패널을 관리하기위한 UI API를 추가합니다.

```ts
const baseUI = univerAPI.getBaseUI()
const view = table.getViews()[0]
if (!view) throw new Error('No table view')
await baseUI.activateTable(table.getId())
await baseUI.activateView(view.getId())
baseUI.setSelection({
  type: 'grid-record',
  tableId: table.getId(),
  viewId: view.getId(),
  recordId: record.getId(),
})
```
