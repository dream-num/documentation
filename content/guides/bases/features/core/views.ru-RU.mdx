Таблица может иметь несколько просмотров.Задачи могут быть введены в сетку и их статус отслеживается на канбане; переключение между ними не копирует никаких записей.

| Посмотреть | Случай использования | Основная конфигурация |
| --- | --- | --- |
| `Grid` | Редактирование, фильтрация и сортировка строк | Замороженные поля, высота рядов, ширина поля |
| `Kanban` | Группировка по статусу или владельцу | `groupFieldId` |
| `Calendar` | Расписание записей по датам | `startDateFieldId`, факультативная дата окончания |
| `Gantt` | Продолжительность планирования и зависимости | Даты начала и окончания, факультативные области прогресса и зависимости |
| `Gallery` | Показать изображения и контент-карты | Обложка, название и карточные поля |
| `Pivot` | Резюме и диаграммы | Требуется [плагин для приборной панели](/guides/bases/features/dashboard) |

Примеры предполагают, что `table` уже существует. Замените идентификаторы полей реальными полями и создайте любые поля даты или группировки, прежде чем настраивать вид, который их использует.

## Создание представлений

```ts
const grid = table.createView('All records', univerAPI.Enum.BaseViewType.Grid)

const kanban = table.createView(
  'By status',
  univerAPI.Enum.BaseViewType.Kanban,
  {
    view: {
      config: { groupFieldId: 'status' },
    },
  },
)
```

## Активация представления в интерфейсе

```ts
const baseUI = univerAPI.getBaseUI()
await baseUI.activateTable(table.getId())
await baseUI.activateView(kanban.getId())
```

## Настройка правил представления

```ts
kanban.setGroup([
  { fieldId: 'status', direction: univerAPI.Enum.BaseSortDirection.ASC },
])

kanban.setFilter({
  conjunction: univerAPI.Enum.BaseFilterConjunction.AND,
  conditions: [
    { fieldId: 'archived', operator: univerAPI.Enum.BaseFilterOperator.IS, operand: false },
  ],
})
```

Настройки полей на обзорной панели управления видимостью, шириной и карточным дисплеем. Они не меняют схему таблицы.

## Даты календаря

```ts
const calendar = table.createView('Schedule', univerAPI.Enum.BaseViewType.Calendar, {
  view: {
    config: { startDateFieldId: 'startDate', endDateFieldId: 'endDate', mode: 'month' },
  },
})
```

Календарь требует поля начальной даты. Гант также требует поля конечной даты и поддерживает рабочие дни, прогресс и зависимости. В галерее `card` настраивает заголовок и поля, которые отображает каждая карта.

## Сортировка и отображение полей

```ts
grid.setSort([{ fieldId: 'priority', direction: univerAPI.Enum.BaseSortDirection.DESC }])
grid.setFieldVisible('internalNotes', false)
grid.setFieldWidth('title', 280)
```

Фильтры, сортировка, группировка и отображение полей принадлежат текущему виду.Ни одна из этих настроек не удаляет базовые записи или поля.

## Условная окраска

Следующее правило выделяет записи, чей балл выше 80:

```ts
const score = table.addField('Score', univerAPI.Enum.BaseFieldType.Number)
grid.setConditionalColorRules([{
  id: 'high-score',
  target: univerAPI.Enum.BaseConditionalColorTarget.ROW,
  fieldId: score.getId(),
  operator: univerAPI.Enum.BaseConditionalColorOperator.GREATER_THAN,
  operand: 80,
  color: '#dcfce7',
}])
```

Правила имеют приоритет в порядке массива. Передайте `[]`, чтобы очистить все правила. Целью может быть ячейка, строка или столбец; окраска столбца безусловна.
