字段定义 Base 表的结构。每个字段都有类型、配置和默认值，并具备排序、筛选、分组、卡片展示等能力。

### 上传附件 [#attachment-upload]

在注册 Bases UI 插件的位置配置上传处理：

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/*', '.pdf'],
    maxSize: 10 * 1024 * 1024,
    upload: uploadAttachment,
  },
})
```

`uploadAttachment` 是业务应用提供的上传函数，签名为 `(file: File) => Promise<IBaseAttachment>`，返回的附件结构见下文示例。`maxSize` 的单位为字节。未提供上传函数时，插件会先尝试图片 IO，再回退到 Base64，这会使快照变大。生产环境应接入真实文件存储，并在后端校验文件类型、大小和下载权限。

### 人员和分组

候选项通过 `UniverBasesUIPlugin` 的 `personOptions` 和 `groupOptions` 传入，每项包含 `id`、`name` 和可选的 `avatar`。这些配置只控制选择器的显示内容，登录和访问权限仍由业务应用负责。

## 字段类型

| 用途 | `BaseFieldType` |
| --- | --- |
| 文本与联系方式 | `Text`、`Link`、`Phone`、`Email` |
| 数值与进度 | `Number`、`Currency`、`Progress`、`Rating` |
| 选择与成员 | `Checkbox`、`SingleSelect`、`MultiSelect`、`Person`、`Group` |
| 日期与附件 | `Date`、`Attachment` |
| 计算与关联 | `Formula`、`RecordLink` |
| 自动生成与审计 | `Numbering`、`RecordId`、`CreatedBy`、`UpdatedBy`、`CreatedAt`、`UpdatedAt` |

单选和多选使用选项 ID，人员和分组使用业务应用中的成员 ID。自动编号和审计字段由系统维护，不能作为普通文本字段写入。公式的用法见[公式字段](/guides/bases/features/core/formulas)，跨表关联和父子记录的用法见[记录、关联与层级](/guides/bases/features/core/records)。

## 添加字段

```ts
const table = base.getTableById('tasks')
if (!table) throw new Error('Tasks table not found')

const title = table.addField('Title', univerAPI.Enum.BaseFieldType.Text)

const priority = table.addField(
  'Priority',
  univerAPI.Enum.BaseFieldType.SingleSelect,
  {
    field: {
      config: {
        options: [
          { id: 'high', name: 'High', color: '#ef4444' },
          { id: 'low', name: 'Low', color: '#22c55e' },
        ],
      },
    },
  },
)
```

## 更新字段

```ts
priority.setName('Impact')
priority.update({ description: 'Business priority' })
priority.setConfig({
  options: [
    { id: 'p0', name: 'P0', color: '#dc2626' },
    { id: 'p1', name: 'P1', color: '#f97316' },
  ],
})
```

## 更改字段类型

```ts
priority.changeType(univerAPI.Enum.BaseFieldType.Text, {})
```

更改字段类型可能会规范化现有值。在将结构变更应用于生产表之前，应先验证应用中的数据。

## 附件字段

附件需要稳定的 ID、名称和可访问的来源。以下示例假设业务系统已上传该文件：

```ts
const attachments = table.addField('Files', univerAPI.Enum.BaseFieldType.Attachment)
const record = table.getRecords()[0]
if (!record) throw new Error('Create a record first')

record.setAttachments(attachments.getId(), [{
  id: 'brief-1',
  name: 'brief.pdf',
  mimeType: 'application/pdf',
  source: 'https://example.com/files/brief.pdf',
}])
```

`setAttachments()` 会替换整个单元格的附件列表；`getAttachments()` 用于读取列表，`deleteAttachments()` 用于删除指定项。示例中的 URL 应替换为用户实际可访问的文件地址。
