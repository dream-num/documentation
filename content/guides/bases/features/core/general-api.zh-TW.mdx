可用的 Facade API 取決於當前單元型別和已註冊的外掛。本頁介紹 Univer Bases 應用常用的 Facade API。

## 導入

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs/ui/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 命令

Univer 中的大多數操作都透過命令系統執行。由於執行路徑統一，撤銷、重做和協同都能覆蓋所有這些操作。

<Callout>
  設計思路見 [Univer 命令系統](/blog/univer#command-system)。
</Callout>

### 監聽命令

要在命令執行前執行程式碼，使用 `Event.BeforeCommandExecute`；要在命令執行完畢後執行程式碼，使用 `Event.CommandExecuted`。

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('命令執行前：', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('命令執行後：', id, params)
})
```

要阻止命令執行，可在 `BeforeCommandExecute` 監聽器中將 `event.cancel` 設為 `true`。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'base.command.set-base-name') {
    event.cancel = true
  }
})
```

兩個監聽器都返回 `IDisposable`，不再需要時應銷燬返回的物件。

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### 執行命令

已知命令 ID 和參數時，可直接使用 `FUniver.executeCommand` 執行。下面的 Bases 命令會修改當前 Base 的名稱：

```typescript
const base = univerAPI.getActiveBase()

if (base) {
  await univerAPI.executeCommand('base.command.set-base-name', {
    unitId: base.getId(),
    name: '專案筆記',
  })
}
```

## 事件 API

`univerAPI.Event` 上的事件來自 Univer Core 和當前應用已註冊的外掛。Core 提供所有產品共用的命令事件和單元事件，Bases 外掛則補充表、欄位、記錄、檢視等 Base 變更事件。使用某個事件前，應先確認提供該事件的外掛已註冊。

當前版本提供的事件名稱和參數型別見 [Facade Events 參考](/reference/facade/events)。

使用 `addEvent` 訂閱，取消訂閱時銷燬返回的物件：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'base.command.set-base-name') {
    console.log('Base名稱已變更')
  }
})

// 不再需要時移除監聽器
disposable.dispose()
```

## 復原和重做

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## 系統剪貼簿

註冊 Bases UI 外掛後，`copy` 和 `paste` 會作用於 Base 當前的選區和游標位置。

```typescript
await univerAPI.copy()
await univerAPI.paste()
```

<Callout>
  複製和貼上使用瀏覽器原生的 Clipboard API。頁面沒有焦點、呼叫不是由使用者操作觸發，或者沒有剪貼簿權限時，複製和貼上都可能失敗。詳見 [MDN 文件](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API)。
</Callout>

## WebSocket

要使用 WebSocket API，應先安裝 `@univerjs/network`、註冊 `UniverNetworkPlugin`，再引入其 Facade 擴充套件。

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

之後即可訂閱 Socket 事件、傳送訊息和關閉連線：

```typescript
const socket = univerAPI.createSocket('wss://example.com/bases')

socket.open$.subscribe(() => socket.send('hello'))
socket.message$.subscribe((message) => console.log('WebSocket 訊息：', message.data))
socket.error$.subscribe((error) => console.error('WebSocket 錯誤：', error))
socket.close()
```

## 列舉 API

Facade 在 `univerAPI.Enum` 上提供常用的列舉型別：

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_BASE)
console.log(univerAPI.Enum.BaseFieldType.Text)
```

## 工具方法 API

通用工具方法透過 `univerAPI.Util` 提供：

```typescript
console.log(univerAPI.Util.tools.isString('Univer Bases')) // true
```
