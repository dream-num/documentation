---
title: Univer Bases API
description: Découvrez comment utiliser l’API Facade dans une application Univer Bases.
---

Facade API est la couche orientée application construite sur le modèle Bases. Il couvre les opérations communes pour créer des bases, des tables, des champs, des enregistrements et des vues, ainsi que des filtres, des sortes, des groupes, des sélections, et la navigation UI.

<Callout type="warning" title="Attention">
  Les modifications au modèle de base sont synchrones. Les méthodes d'activation de l'interface utilisateur renvoient les promesses, de sorte que l'appelant doit les attendre.
</Callout>

## Activer les points d’entrée Facade

Importer l'entrée de façade pour chaque capacité Bases que l'application utilise:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Créer l'objet API seulement après l'instance Univer et les plugins requis sont enregistrés :

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Créer et lire une base

`createBase` crée une unité de base à travers la couche de façade. Code qui fonctionne à un niveau inférieur peut créer l'unité directement avec `univer.createUnit(UniverInstanceType.UNIVER_BASE, snapshot)`.

```ts
const base = univerAPI.createBase({
  id: 'base-demo',
  name: 'Base Demo',
})

const activeBase = univerAPI.getActiveBase()
const sameBase = univerAPI.getBase(base.getId())
```

## Créer une table

```ts
const table = base.insertTable('Tasks', { primaryFieldName: 'Title' })
const status = table.addField('Status', univerAPI.Enum.BaseFieldType.SingleSelect)
```

## Manipuler les enregistrements

```ts
const record = table.addRecord({
  Title: 'Write docs',
  Status: 'In progress',
}, univerAPI.Enum.BaseFieldKeyEnum.Name)

record.setValue(status.getId(), 'Done')
```

## Manipuler l’état de l’interface utilisateur

`@univerjs-pro/bases-ui/facade` ajoute des API d'interface pour activer les tables et les vues, gérer la sélection, défiler, éditer et les panneaux.

```ts
const baseUI = univerAPI.getBaseUI()
const view = table.getViews()[0]
if (!view) throw new Error('No table view')
await baseUI.activateTable(table.getId())
await baseUI.activateView(view.getId())
baseUI.setSelection({
  type: 'grid-record',
  tableId: table.getId(),
  viewId: view.getId(),
  recordId: record.getId(),
})
```
