Univer Bases 核心功能會將結構化資料模型與瀏覽器工作區組合在一起。模型與 UI 由兩個 Univer Pro 套件提供，並以獨立的 `UNIVER_BASE` 單元執行。

## 功能

- **資料表、欄位與記錄**：在每個資料表中儲存具類型的欄位與有序記錄。
- **多種檢視**：透過網格、看板、行事曆、甘特圖與圖庫檢視呈現同一組記錄。
- **命令驅動的編輯**：讓模型變更統一經過命令層，並提供權限及選用歷程與協同作業整合所需的掛鉤。
- **公式欄位**：將 Base 欄位接入 Univer 公式計算流程。
- **瀏覽器工作區**：算繪檢視，並提供選取、編輯、剪貼簿、捲動與面板功能。
- **持久化**：無需直接修改執行中的快照，即可建立、還原與儲存 `IBaseSnapshot`。

## 預設模式

Univer Bases 目前沒有專用預設。模型與瀏覽器 UI 都應使用外掛模式。

## 外掛模式

### 安裝

在[安裝與基本使用](/guides/bases/getting-started/installation)介紹的 Univer 執行環境中加入兩個 Bases 產品套件：

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### 註冊產品外掛

依照安裝指南先註冊共用執行環境、公式引擎與 Pro 授權，再註冊 Bases 外掛：

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin` 會註冊 Base 模型、命令、欄位與檢視登錄表、公式整合與權限。`UniverBasesUIPlugin` 則加入已算繪的工作區與瀏覽器互動。
