Univer Bases 將結構化資料模型與瀏覽器工作臺結合在一起。模型和 UI 由兩個 Web SDK 包提供，二者共同執行在一個獨立的 `UNIVER_BASE` 單元中。

## 功能

| 核心功能 | 用途 |
| --- | --- |
| [欄位與附件](/guides/bases/features/core/fields) | 文字、數字、選擇、成員、日期、附件等欄位。 |
| [記錄、關聯與層級](/guides/bases/features/core/records) | 批次修改、本地分頁、跨表關聯和父子記錄。 |
| [檢視](/guides/bases/features/core/views) | 網格、看板、日曆、甘特圖、畫廊，以及篩選、排序、分組和條件著色。 |
| [公式](/guides/bases/features/core/formulas) | 欄位計算，以及顯式配置的跨文件引用。 |
| [權限](/guides/bases/features/core/permissions) | Base、表、欄位、記錄和檢視的編輯權限。 |

匯入匯出、儀表盤、評論和歷史記錄由擴充套件外掛提供，見 [Bases 功能一覽](/guides/bases#主要功能)。

## 外掛模式

### 安裝

將兩個 Bases 產品包加入按[安裝與基礎使用](/guides/bases/getting-started/installation)搭建好的 Univer 執行時：

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### 註冊產品外掛

先按安裝指南註冊共享執行時、公式引擎和許可證，再註冊 Bases 外掛：

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin` 提供 Base 模型、命令、欄位與檢視登錄檔、公式整合和權限；`UniverBasesUIPlugin` 提供渲染後的工作臺及相應的瀏覽器互動。

## 預設模式

Univer Bases 目前沒有專用預設，模型和瀏覽器 UI 均使用外掛模式。
