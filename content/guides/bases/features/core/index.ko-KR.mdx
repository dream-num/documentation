Univer Bases는 브라우저 작업대와 구조화된 데이터 모델을 결합합니다. Web SDK 패키지는 이러한 구성 요소를 제공하며 독립적 인 `UNIVER_BASE` 단위로 실행됩니다.

## 기능

| 핵심 기능 | 제품정보 |
| --- | --- |
| [현장 및 첨부](/guides/bases/features/core/fields) | 텍스트, 숫자, 선택, 회원, 날짜 및 첨부 파일. |
| [기록, 링크 및 계층](/guides/bases/features/core/records) | 일괄 편집, 로컬 pagination, 테이블 링크, 및 부모 - 어린이 기록. |
| [....](/guides/bases/features/core/views) | 그리드, Kanban, 캘린더, Gantt, 갤러리, 필터링, 분류, 그룹화, 조건 색상. |
| [팟캐스트](/guides/bases/features/core/formulas) | 필드 계산 및 명시적으로 형성된 교차 문서 참조. |
| [제출하기](/guides/bases/features/core/permissions) | Bases, table, field, record 및 views에 대한 수정 권한을 편집합니다. |

Exchange, 대시보드, 의견 및 역사는 확장 플러그인으로 제공됩니다. [Bases 기능 개요](/guides/bases#주요-기능)를 참조하십시오.

## 플러그인 모드

### 설치

[설치 및 기본 사용](/guides/bases/getting-started/installation)에서 설정된 런타임에 두 개의 Bases 제품 패키지를 추가하십시오.

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### 제품 플러그인 등록

설치 가이드에 따라 공유 실행 시간, 공식 엔진 및 라이센스를 먼저 등록하고, Bases 플러그인을 등록하십시오.

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin`는 기본 모델, 명령, 필드 및 뷰 레지스트리, 공식 통합 및 권한을 제공합니다. `UniverBasesUIPlugin`은 렌더링 된 작업 벤치와 함께 브라우저 상호 작용을 추가합니다.

## 프리셋 모드

Univer Bases는 아직 전용 프리셋이 없습니다. 모델과 브라우저 UI 모두에 플러그인 모드를 사용합니다.
