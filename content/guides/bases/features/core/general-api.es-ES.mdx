Las API de Facade disponibles para una aplicación dependen del tipo de unidad actual y de los plugins que están registrados. Esta página cubre las API que una aplicación de Univer Bases utiliza comúnmente.

## Importación

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs/ui/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Comandos

La mayoría de las operaciones en Univer pasan por el sistema de comandos. Debido a que cada operación sigue el mismo camino, deshacer, redo y colaboración pueden cubrir todos ellos.

<Callout>
  Para el diseño detrás de él, vea el [Sistema de comando Univer](/blog/univer#command-system).
</Callout>

### Escuchar comandos

Utilice `Event.BeforeCommandExecute` para ejecutar código antes de ejecutar un comando, y `Event.CommandExecuted` ejecutar código después de que termine.

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('Antes del comando:', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('Comando ejecutado:', id, params)
})
```

Para evitar que un comando se ejecute, establece `event.cancel` a `true` dentro de un oyente `BeforeCommandExecute`.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'base.command.set-base-name') {
    event.cancel = true
  }
})
```

Ambos oyentes devuelven un `IDisposable`. Despose de los objetos devueltos cuando ya no son necesarios.

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### Ejecutar comandos

Cuando se conoce un ID de comando y sus parámetros, `FUniver.executeCommand` ejecuta el comando directamente. El siguiente comando Bases renombra la Base activa:

```typescript
const base = univerAPI.getActiveBase()

if (base) {
  await univerAPI.executeCommand('base.command.set-base-name', {
    unitId: base.getId(),
    name: 'Notas del proyecto',
  })
}
```

## API de eventos

Los eventos en `univerAPI.Event` provienen del núcleo Univer y de los plugins registrados en la aplicación actual. Core proporciona el comando y eventos unitarios que cada producto comparte; los plugins Bases añaden eventos para tablas, campos, registros, vistas y otros cambios Base. Antes de usar un evento, confirma que el plugin que proporciona está registrado.

El [Facade Eventos referencia](/reference/facade/events) enumera los nombres de los eventos y los tipos de parámetro disponibles en la versión actual.

Suscríbete con `addEvent`, luego deshazte del objeto devuelto para darse de baja:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'base.command.set-base-name') {
    console.log('El nombre del Base ha cambiado')
  }
})

// Elimine el listener cuando ya no sea necesario
disposable.dispose()
```

## Deshacer y rehacer

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## Portapapeles del sistema

Después de registrar el complemento de interfaz de Bases, `copy` y `paste` actúan sobre la selección y la posición del cursor actuales del Base.

```typescript
await univerAPI.copy()
await univerAPI.paste()
```

<Callout>
  Copia y pega el uso de la API de portapapeles nativa del navegador. Pueden fallar cuando la página no tiene foco, cuando la llamada no se origina de una acción del usuario, o cuando el permiso de portapapapeles no está disponible. [Documentación del portapapeles MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API).
</Callout>

## WebSocket

Para utilizar las APIs WebSocket, instale `@univerjs/network`, registre `UniverNetworkPlugin` e importe su extensión Facade.

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

La aplicación puede suscribirse a eventos de socket, enviar mensajes y cerrar la conexión:

```typescript
const socket = univerAPI.createSocket('wss://example.com/bases')

socket.open$.subscribe(() => {
  socket.send('hello')
})

socket.message$.subscribe((message) => {
  console.log('Mensaje WebSocket:', message.data)
})

socket.error$.subscribe((error) => {
  console.error('Error de WebSocket:', error)
})

socket.close()
```

## API de enumeración

Facade expone tipos de enum comunes en `univerAPI.Enum`:

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_BASE)
console.log(univerAPI.Enum.BaseFieldType.Text)
```

## API de métodos de utilidad

Los métodos de utilidad compartidos están expuestos en `univerAPI.Util`:

```typescript
console.log(univerAPI.Util.tools.isString('Univer Bases')) // true
```
