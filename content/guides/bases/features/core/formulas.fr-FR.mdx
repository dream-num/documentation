---
title: Formules
---

Un champ de formule Bases calcule une valeur record à partir des données de son tableau. `UniverBasesPlugin` enregistre automatiquement la dépendance du moteur de la formule.

## Enregistrer la prise en charge des formules

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

## Créer un champ de formule

```ts
const formulaTableName = table.getFormulaName()
const total = table.addField('Total', univerAPI.Enum.BaseFieldType.Formula, {
  field: {
    config: {
      formula: `=SUM(${formulaTableName}[[#This Row],[Price]],${formulaTableName}[[#This Row],[Tax]])`,
    },
  },
  externalReferences: [],
})
```

Chaque écriture dans un champ de formule doit inclure `externalReferences`. Passez `[]` seulement lorsque les champs de référence de formule dans la même base. Pour les formules à unités croisées, utilisez [`buildReference`](/reference/facade/formula#buildreference) et incluez chaque liaison de source stable dans le tableau.

## Remarques

- Un champ de formule contient une valeur dérivée, de sorte que le code d'application ne devrait pas écrire directement aux cellules de formule.
- Les expressions de formules utilisent des références de champs structurées, par exemple `Table[[#This Row],[Price]]`.
- Après avoir importé un grand instantané, recalculez les formules avant de présenter les résultats aux utilisateurs.
