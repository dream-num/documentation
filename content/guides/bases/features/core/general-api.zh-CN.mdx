可用的 Facade API 取决于当前单元类型和已注册的插件。本页介绍 Univer Bases 应用常用的 Facade API。

## 引入

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs/ui/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 命令

Univer 中的大多数操作都通过命令系统执行。由于执行路径统一，撤销、重做和协同都能覆盖所有这些操作。

<Callout>
  设计思路见 [Univer 命令系统](/blog/univer#command-system)。
</Callout>

### 监听命令

要在命令执行前运行代码，使用 `Event.BeforeCommandExecute`；要在命令执行完毕后运行代码，使用 `Event.CommandExecuted`。

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('命令执行前：', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('命令执行后：', id, params)
})
```

要阻止命令执行，可在 `BeforeCommandExecute` 监听器中将 `event.cancel` 设为 `true`。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'base.command.set-base-name') {
    event.cancel = true
  }
})
```

两个监听器都返回 `IDisposable`，不再需要时应销毁返回的对象。

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### 执行命令

已知命令 ID 和参数时，可直接使用 `FUniver.executeCommand` 执行。下面的 Bases 命令会修改当前 Base 的名称：

```typescript
const base = univerAPI.getActiveBase()

if (base) {
  await univerAPI.executeCommand('base.command.set-base-name', {
    unitId: base.getId(),
    name: '项目笔记',
  })
}
```

## 事件 API

`univerAPI.Event` 上的事件来自 Univer Core 和当前应用已注册的插件。Core 提供所有产品共用的命令事件和单元事件，Bases 插件则补充表、字段、记录、视图等 Base 变更事件。使用某个事件前，应先确认提供该事件的插件已注册。

当前版本提供的事件名称和参数类型见 [Facade Events 参考](/reference/facade/events)。

使用 `addEvent` 订阅，取消订阅时销毁返回的对象：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'base.command.set-base-name') {
    console.log('Base名称已更改')
  }
})

// 不再需要时移除监听器
disposable.dispose()
```

## 撤销和重做

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## 系统剪贴板

注册 Bases UI 插件后，`copy` 和 `paste` 会作用于 Base 当前的选区和光标位置。

```typescript
await univerAPI.copy()
await univerAPI.paste()
```

<Callout>
  复制和粘贴使用浏览器原生的 Clipboard API。页面没有焦点、调用不是由用户操作触发，或者没有剪贴板权限时，复制和粘贴都可能失败。详见 [MDN 文档](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API)。
</Callout>

## WebSocket

要使用 WebSocket API，应先安装 `@univerjs/network`、注册 `UniverNetworkPlugin`，再引入其 Facade 扩展。

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

之后即可订阅 Socket 事件、发送消息和关闭连接：

```typescript
const socket = univerAPI.createSocket('wss://example.com/bases')

socket.open$.subscribe(() => socket.send('hello'))
socket.message$.subscribe((message) => console.log('WebSocket 消息：', message.data))
socket.error$.subscribe((error) => console.error('WebSocket 错误：', error))
socket.close()
```

## 枚举 API

Facade 在 `univerAPI.Enum` 上提供常用的枚举类型：

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_BASE)
console.log(univerAPI.Enum.BaseFieldType.Text)
```

## 工具方法 API

通用工具方法通过 `univerAPI.Util` 提供：

```typescript
console.log(univerAPI.Util.tools.isString('Univer Bases')) // true
```
