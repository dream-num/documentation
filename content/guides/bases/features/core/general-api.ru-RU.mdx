API-интерфейсы Facade, доступные для приложения, зависят от текущего типа блока и от зарегистрированных плагинов. Эта страница охватывает API-интервенции, которые обычно использует приложение Univer Bases.

## Импорт

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs/ui/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Команды

Большинство операций в Univer проходят через систему команд. Потому что каждая операция следует одним и тем же путем, отмена, переделка и сотрудничество могут покрыть все из них.

<Callout>
  Для дизайна за ним, см. [Командная система Univer](/blog/univer#command-system).
</Callout>

### Прослушивание команд

Используйте `Event.BeforeCommandExecute` для запуска кода перед выполнением команды, а `Event.CommandExecuted` - для запуска код после его завершения.

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('Перед командой:', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('Команда выполнена:', id, params)
})
```

Чтобы предотвратить запуск команды, установите `event.cancel` в `true` внутри слушателя `BeforeCommandExecute`.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'base.command.set-base-name') {
    event.cancel = true
  }
})
```

Оба слушателя возвращают `IDisposable`. Утилизируйте возвращенные предметы, когда они больше не нужны.

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### Выполнение команд

Когда идентификатор команды и его параметры известны, `FUniver.executeCommand` запускает команду напрямую. Следующая команда Bases переименовывает активную базу:

```typescript
const base = univerAPI.getActiveBase()

if (base) {
  await univerAPI.executeCommand('base.command.set-base-name', {
    unitId: base.getId(),
    name: 'Заметки проекта',
  })
}
```

## API событий

События на `univerAPI.Event` происходят из ядра Univer и из плагинов, зарегистрированных в текущем приложении. Core предоставляет командные и единичные события, которыми делится каждый продукт; плагины Bases добавляют события для таблиц, полей, записей, просмотров и других изменений Базы. Перед использованием события подтвердите, что плагин, предоставляющий его, зарегистрирован.

[Ссылка на события Facade](/reference/facade/events) перечисляет имена событий и типы параметров, доступные в текущем выпуске.

Подписывайтесь на `addEvent`, а затем утилизируйте возвращенный объект, чтобы отказаться от подписки:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'base.command.set-base-name') {
    console.log('Имя Base изменено')
  }
})

// Удалите обработчик, когда он больше не нужен
disposable.dispose()
```

## Отмена и повтор действий

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## Системный буфер обмена

После регистрации плагина интерфейса Bases методы `copy` и `paste` работают с текущим выделением и позицией курсора в Base.

```typescript
await univerAPI.copy()
await univerAPI.paste()
```

<Callout>
  Копии и вставки используют нативный API буфера обмена. Они могут выйти из строя, когда страница не имеет фокуса, когда вызов не исходит из действия пользователя, или когда разрешение буфера доступа недоступно. См. [MDN клипборд документация](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API).
</Callout>

## WebSocket

Чтобы использовать API WebSocket, установите `@univerjs/network`, зарегистрируйте `UniverNetworkPlugin` и импортируйте расширение Facade.

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

Затем приложение может подписаться на события сокетов, отправлять сообщения и закрывать соединение:

```typescript
const socket = univerAPI.createSocket('wss://example.com/bases')

socket.open$.subscribe(() => socket.send('hello'))
socket.message$.subscribe((message) => console.log('Сообщение WebSocket:', message.data))
socket.error$.subscribe((error) => console.error('Ошибка WebSocket:', error))
socket.close()
```

## API перечислений

Facade раскрывает общие типы перечня на `univerAPI.Enum`:

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_BASE)
console.log(univerAPI.Enum.BaseFieldType.Text)
```

## API вспомогательных методов

Общие методы полезности представлены на `univerAPI.Util`:

```typescript
console.log(univerAPI.Util.tools.isString('Univer Bases')) // true
```
