---
title: Univer Bases API
description: Aprende a usar la API Facade en una aplicación Univer Bases.
---

Facade API es la capa de aplicación construida en el modelo Bases. Cubre las operaciones comunes para crear bases, tablas, campos, registros y vistas, así como filtros, clasificaciones, grupos, selecciones y navegación UI.

<Callout type="warning" title="Precaución">
  Los cambios en el modelo Base son sincronizados. Los métodos de activación de la UI devuelven las promesas, por lo que el callador debe esperarlas.
</Callout>

## Habilitar entradas de fachada

Importar la entrada de fachada para cada capacidad Bases que la aplicación utiliza:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Cree el objeto API sólo después de la instancia Univer y los plugins necesarios están registrados:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Cree y lea una base

`createBase` crea una unidad Base a través de la capa de fachada. Código que opera a un nivel inferior puede crear la unidad directamente con `univer.createUnit(UniverInstanceType.UNIVER_BASE, snapshot)`.

```ts
const base = univerAPI.createBase({
  id: 'base-demo',
  name: 'Base Demo',
})

const activeBase = univerAPI.getActiveBase()
const sameBase = univerAPI.getBase(base.getId())
```

## Crear una tabla

```ts
const table = base.insertTable('Tasks', { primaryFieldName: 'Title' })
const status = table.addField('Status', univerAPI.Enum.BaseFieldType.SingleSelect)
```

## Trabajar con registros

```ts
const record = table.addRecord({
  Title: 'Write docs',
  Status: 'In progress',
}, univerAPI.Enum.BaseFieldKeyEnum.Name)

record.setValue(status.getId(), 'Done')
```

## Trabajar con el estado de la interfaz de usuario

`@univerjs-pro/bases-ui/facade` añade APIs UI para activar tablas y vistas, gestionar selección, desplazamiento, edición y paneles.

```ts
const baseUI = univerAPI.getBaseUI()
const view = table.getViews()[0]
if (!view) throw new Error('No table view')
await baseUI.activateTable(table.getId())
await baseUI.activateView(view.getId())
baseUI.setSelection({
  type: 'grid-record',
  tableId: table.getId(),
  viewId: view.getId(),
  recordId: record.getId(),
})
```
