title: 권한
---

전체베이스는 개별 테이블, 필드, 기록, 또는보기로 읽기 전용을 만들 수 있습니다. 이 커버 읽기 전용 보고서 및 응용 프로그램 버전은 사용자가 데이터의 일부만 편집 할 수 있습니다.

Bases 플러그인을 등록하고 이 API를 호출하기 전에 `@univerjs-pro/bases/facade`를 가져옵니다.

## Base를 읽기 전용으로 설정

```ts
const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

await base.getPermission().setReadOnly()
console.log(base.getPermission().canEdit()) // false

await base.getPermission().setEditable()
```

## 개별 객체 제한

다음 예제는 단일 테이블을 제한합니다.

```ts
const table = base.getTables()[0]
if (!table) throw new Error('Create a table first')

await table.getPermission().setReadOnly()
await table.getPermission().setEditable()
```

필드, 레코드 및 레이아웃 또한 `getPermission()`를 노출, as do 대쉬보드와 피벗보기는 한 번 플러그인이 등록됩니다. 아이 객체 편집을하지 않는 것은 부모에 제한을 제거하지 않습니다 : 테이블이 읽기 전용 경우, 편집 가능한 내부의 레코드를 작성하는 것은 효과가 없습니다.

`setReadOnly()` 및 `setEditable()` 반품 약속, 그래서 `await` 그들. 하나의 호출에 여러 개체를 변경하려면 `base.getPermission().setObjectPermissions()`를 사용하십시오; [기초 Facade](/reference/facade/base) 매개 변수를 나열합니다.

## 복사, 내보내기 및 댓글

Base-level 권한은 복사, 수출 및 주석이 허용되는지 여부를 결정합니다. 복사를 비활성화하려면:

```ts
import { UnitAction } from '@univerjs/protocol'

await base.getPermission().setPoint(UnitAction.Copy, false)
```

`UnitAction.Export` 및 `UnitAction.Comment`를 사용하여 수출 및 주석을 각각 사용합니다.

## 업무 권한 연결

로컬 권한은 편집기가 허용하는 것을 관리합니다. 협업 응용 프로그램은 콘텐츠 읽기, 협업 참여 및 서버의 변경 사항을 제출해야합니다. [서버 통합](/server)를 참조하십시오.

테스트 중, 편집기, 시청자 및 액세스없이 사용자를 사용하고, 페이지 및 직접 요청의 작업을 모두 확인합니다.
