Univer Bases combine un modèle de données structuré avec un banc de travail de navigateur. Deux paquets Web SDK fournissent ces composants, et ensemble ils fonctionnent comme une unité indépendante `UNIVER_BASE`.

## Fonctionnalités

| Fonction de base | Objet |
| --- | --- |
| [Champs et pièces jointes](/guides/bases/features/core/fields) | Texte, nombres, choix, membres, dates et pièces jointes. |
| [Enregistrements, liens et hiérarchie](/guides/bases/features/core/records) | Éditions par lots, pagination locale, liens de table et enregistrements parent-enfant. |
| [Vues](/guides/bases/features/core/views) | Grille, Kanban, Calendrier, Gantt, Galerie, filtrage, tri, regroupement et couleurs conditionnelles. |
| [Formules](/guides/bases/features/core/formulas) | Calculs sur le terrain et références de documents croisés explicitement configurées. |
| [Autorisations](/guides/bases/features/core/permissions) | Modifier les permissions pour les bases, les tables, les champs, les enregistrements et les vues. |

Échange, tableaux de bord, commentaires et historique sont fournis sous forme de plugins d'extension. Voir le [Vue d'ensemble de la fonction Bases](/guides/bases#points-forts).

## Mode plugin

### Installation

Ajouter les deux paquets de produits Bases à l'exécution configurée dans [Installation et utilisation de base](/guides/bases/getting-started/installation) :

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### Enregistrement des plugins du produit

Suivant le guide d'installation, enregistrez d'abord le moteur d'exécution partagé, le moteur de formule et la licence, puis enregistrez les plugins Bases :

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin` fournit le modèle de base, les commandes, les registres de champ et de vue, l'intégration de la formule et les permissions. `UniverBasesUIPlugin` ajoute le workbench rendu et les interactions du navigateur qui l'accompagnent.

## Mode preset

Univer Bases n'a pas encore de préréglage dédié. Utilisez le mode plugin pour le modèle et l'interface utilisateur du navigateur.
