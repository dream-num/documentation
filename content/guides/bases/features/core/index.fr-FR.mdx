Le cœur d’Univer Bases associe un modèle de données structurées à un espace de travail dans le navigateur. Le modèle et l’interface sont fournis par deux packages Univer Pro et fonctionnent comme une unité `UNIVER_BASE` indépendante.

## Fonctionnalités

- **Tables, champs et enregistrements** : stockez des champs typés et des enregistrements ordonnés dans chaque table.
- **Vues multiples** : projetez les mêmes enregistrements dans des vues grille, Kanban, calendrier, Gantt et galerie.
- **Modification pilotée par des commandes** : faites passer les changements du modèle par une couche de commandes avec des autorisations et des points d’intégration pour l’historique et la collaboration facultatifs.
- **Champs de formule** : reliez les champs Base au pipeline de calcul de formules d’Univer.
- **Espace de travail du navigateur** : affichez les vues et bénéficiez de la sélection, de la modification, du presse-papiers, du défilement et des panneaux.
- **Persistance** : créez, restaurez et enregistrez un `IBaseSnapshot` sans modifier directement l’instantané en cours d’exécution.

## Mode preset

Univer Bases ne fournit actuellement aucun preset dédié. Utilisez le mode plugin pour le modèle comme pour l’interface du navigateur.

## Mode plugin

### Installation

Ajoutez les deux packages Bases à l’environnement Univer décrit dans [Installation et utilisation de base](/guides/bases/getting-started/installation) :

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### Enregistrement des plugins du produit

Enregistrez d’abord l’environnement partagé, le moteur de formules et la licence Pro comme indiqué dans le guide d’installation, puis les plugins Bases :

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin` enregistre le modèle Base, les commandes, les registres de champs et de vues, l’intégration des formules et les autorisations. `UniverBasesUIPlugin` ajoute l’espace de travail rendu et les interactions dans le navigateur.
