Univer Bases 核心功能将结构化数据模型与浏览器工作台组合在一起。模型和 UI 由两个 Univer SDK Pro 包提供，并作为独立的 `UNIVER_BASE` 单元运行。

## 功能

- **表、字段和记录**：在每张表中存储带类型的字段和有序记录。
- **多种视图**：通过网格、看板、日历、甘特图和画廊视图呈现同一组记录。
- **命令驱动的编辑**：让模型变更统一经过命令层，并提供权限及可选历史记录和协同集成所需的挂钩。
- **公式字段**：将 Base 字段接入 Univer 公式计算链路。
- **浏览器工作台**：渲染视图，并提供选择、编辑、剪贴板、滚动和面板功能。
- **持久化**：无需直接修改运行中的快照，即可创建、恢复和保存 `IBaseSnapshot`。

## 预设模式

Univer Bases 目前没有专用预设。模型和浏览器 UI 都应使用插件模式。

## 插件模式

### 安装

在[安装与基础使用](/guides/bases/getting-started/installation)介绍的 Univer 运行时中加入两个 Bases 产品包：

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### 注册产品插件

按照安装指南先注册共享运行时、公式引擎和 Pro 许可证，再注册 Bases 插件：

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin` 注册 Base 模型、命令、字段与视图注册表、公式集成和权限。`UniverBasesUIPlugin` 添加渲染工作台与浏览器交互。
