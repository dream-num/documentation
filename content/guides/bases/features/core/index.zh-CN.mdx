Univer Bases 将结构化数据模型与浏览器工作台结合在一起。模型和 UI 由两个 Web SDK 包提供，二者共同运行在一个独立的 `UNIVER_BASE` 单元中。

## 功能

| 核心功能 | 用途 |
| --- | --- |
| [字段与附件](/guides/bases/features/core/fields) | 文本、数字、选择、成员、日期、附件等字段。 |
| [记录、关联与层级](/guides/bases/features/core/records) | 批量修改、本地分页、跨表关联和父子记录。 |
| [视图](/guides/bases/features/core/views) | 网格、看板、日历、甘特图、画廊，以及筛选、排序、分组和条件着色。 |
| [公式](/guides/bases/features/core/formulas) | 字段计算，以及显式配置的跨文档引用。 |
| [权限](/guides/bases/features/core/permissions) | Base、表、字段、记录和视图的编辑权限。 |

导入导出、仪表盘、评论和历史记录由扩展插件提供，见 [Bases 功能一览](/guides/bases#主要功能)。

## 插件模式

### 安装

将两个 Bases 产品包加入按[安装与基础使用](/guides/bases/getting-started/installation)搭建好的 Univer 运行时：

```package-install
npm install @univerjs-pro/bases @univerjs-pro/bases-ui
```

### 注册产品插件

先按安装指南注册共享运行时、公式引擎和许可证，再注册 Bases 插件：

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

`UniverBasesPlugin` 提供 Base 模型、命令、字段与视图注册表、公式集成和权限；`UniverBasesUIPlugin` 提供渲染后的工作台及相应的浏览器交互。

## 预设模式

Univer Bases 目前没有专用预设，模型和浏览器 UI 均使用插件模式。
