---
title: Формулы
---

Поле формулы Bases вычисляет рекордное значение из данных в своей таблице. `UniverBasesPlugin` автоматически регистрирует зависимость двигателя формулы.

## Регистрация поддержки формул

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

## Создание поля формулы

```ts
const formulaTableName = table.getFormulaName()
const total = table.addField('Total', univerAPI.Enum.BaseFieldType.Formula, {
  field: {
    config: {
      formula: `=SUM(${formulaTableName}[[#This Row],[Price]],${formulaTableName}[[#This Row],[Tax]])`,
    },
  },
  externalReferences: [],
})
```

Каждая запись в поле формулы должна включать `externalReferences`. Пропуск `[]` только тогда, когда формула ссылается на поля в той же Базе. Для формул кросс-единицы используйте [`buildReference`](/reference/facade/formula#buildreference) и включите в массив каждое стабильное связывание с источником.

## Примечания

- Поле формулы содержит производное значение, поэтому код приложения не должен записываться непосредственно в ячейки формулы.
- Формуловые выражения используют структурированные ссылки на поля, например `Table[[#This Row],[Price]]`.
- После импорта большого снимка пересчитайте формулы перед представлением результатов пользователям.
