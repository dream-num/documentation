---
title: レコード、リンク、階層
---

レコードは、タスク、顧客、または注文などの1つのビジネスオブジェクトを表しています。 Facade APIは、レコードに適用される操作をカバーしています。バッチを書いて、ページを読んだり、別のテーブルをリンクしたり、親子のレコードを整理したりします。

## レコードの作成と読み取り

```ts
const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

const table = base.insertTable('Tasks', { primaryFieldName: 'Title' })
const titleId = table.getPrimaryFieldId()
const records = table.addRecords([
  { values: { [titleId]: 'Write documentation' } },
  { values: { [titleId]: 'Review examples' } },
])
records[0].setValue(titleId, 'Publish documentation')

const page = table.queryRecords({ offset: 0, limit: 20 })
console.log(page.total, page.records)
```

レコードの値は、デフォルトでフィールド ID によってキー化されます。 フィールド名でデータがキー化されている場合は、`univerAPI.Enum.BaseFieldKeyEnum.Name` を渡します。 `queryRecords()`は、既にローカルに読み込まれたデータのみをクエリします。 バックエンドからページを取得しません。 `viewId`を使用して、ビューの範囲内のレコードを読み込むか、 `sort`で注文を設定します。

`table.deleteRecords(recordIds)`でバッチを削除したり、`record.duplicate()`とレコードを複製したりします。どちらの操作もコマンドシステムを通過するので、undoとredoがサポートされています。

## レコードの検索

選択したフィールド内のテキストを検索します。

```ts
const matches = table.search({ query: 'documentation', fieldIds: [titleId], limit: 20 })
console.log(matches)
```

## 別のテーブルへのリンク

以下の例では、各タスクをプロジェクトにリンクします。

```ts
const projects = base.insertTable('Projects', { primaryFieldName: 'Name' })
const project = projects.addRecord({ [projects.getPrimaryFieldId()]: 'Website' })
const projectField = table.addField('Project', univerAPI.Enum.BaseFieldType.RecordLink, {
  field: { config: { targetTableId: projects.getId(), multiple: false } },
})
records[0].setLinkedRecordIds(projectField.getId(), [project.getId()])
console.log(records[0].getLinkedRecordIds(projectField.getId()))
```

リンクされたターゲットは、同じベースに属しなければなりません。 `multiple: true` を設定して、複数のリンクされたレコード、`displayFieldId`を選択して、表示されたラベル、および `pickerFieldIds`がピッカーに追加のコンテキストを供給できるようにします。 内部ストレージ文字列を直接構築するのではなく、リンク API を介して ID を読み、書きます。

## 親子レコード

次の例では、API はドキュメントタスクの子をレビューします。

```ts
const parent = records[0]
const parentFieldId = table.getHierarchyFieldId()
const child = parent.addChild(parentFieldId, { [titleId]: 'Check API examples' })
console.log(child.getParent(parentFieldId)?.getId())

child.setParent(parentFieldId, null)
```

最初の子を追加すると、必要な親リンクフィールドが作成されます。 `getChildren()`、`getAncestors()`、および `getDescendants()`を使用して、関係をバックアップします。 階層は5つのレベル深部にすることができます。 レコードは独自の親でありず、サイクルは拒否されます。 無効な操作がスローされるので、エラーをキャッチし、UIで有用なメッセージを提示してください。

Hierarchy はテーブルデータの一部なので、切り替えやフィルタリングのビューは変更されません。 [ベースファサード](/reference/facade/base) は残りのメソッドを文書化します。
