---
title: Univer Bases API
description: Узнайте, как использовать Facade API в приложении Univer Bases.
---

Facade API — это слой, обращенный к приложениям, построенный по модели Bases. Он охватывает общие операции для создания баз, таблиц, полей, записей и просмотров, а также фильтров, сортировок, групп, подборов и навигации по пользовательскому интерфейсу.

<Callout type="warning" title="Осторожно">
  Изменения в Базовой модели синхронны. Методы активации пользовательского интерфейса возвращают обещания, поэтому абонент должен их ждать.
</Callout>

## Подключение точек входа Facade

Импорт входа фасада для каждой возможности Базы, которую использует приложение:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Создать объект API можно только после регистрации экземпляра Univer и необходимых плагинов:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Создание и чтение базы

`createBase` создает базовый блок через фасадный слой.Код, работающий на более низком уровне, может создавать блок непосредственно с `univer.createUnit(UniverInstanceType.UNIVER_BASE, snapshot)`.

```ts
const base = univerAPI.createBase({
  id: 'base-demo',
  name: 'Base Demo',
})

const activeBase = univerAPI.getActiveBase()
const sameBase = univerAPI.getBase(base.getId())
```

## Создание таблицы

```ts
const table = base.insertTable('Tasks', { primaryFieldName: 'Title' })
const status = table.addField('Status', univerAPI.Enum.BaseFieldType.SingleSelect)
```

## Работа с записями

```ts
const record = table.addRecord({
  Title: 'Write docs',
  Status: 'In progress',
}, univerAPI.Enum.BaseFieldKeyEnum.Name)

record.setValue(status.getId(), 'Done')
```

## Работа с состоянием интерфейса

`@univerjs-pro/bases-ui/facade` добавляет API-интерфейсы для активации таблиц и просмотров, управления выбором, прокруткой, редактированием и панелями.

```ts
const baseUI = univerAPI.getBaseUI()
const view = table.getViews()[0]
if (!view) throw new Error('No table view')
await baseUI.activateTable(table.getId())
await baseUI.activateView(view.getId())
baseUI.setSelection({
  type: 'grid-record',
  tableId: table.getId(),
  viewId: view.getId(),
  recordId: record.getId(),
})
```
