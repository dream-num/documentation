title: 權限

---

Bases 提供 facade 輔助方法，用於管理 Base、資料表、欄位和記錄的權限。使用權限 API，可讓應用程式程式碼貼近使用者所理解的概念，而非內部服務。

## 讀取權限

```ts
const permission = base.getPermission()
const tablePermission = permission.getTablePermission(table.getId())
const fieldPermission = permission.getFieldPermission(table.getId(), field.getId())
```

## 更新權限

```ts
permission.setBasePermission({
  createTable: false,
})

permission.setTablePermission(table.getId(), {
  editable: true,
  removable: false,
})
```

## 使用者介面行為

Bases 使用者介面會讀取權限狀態，以決定是否顯示或啟用各項操作。正式環境的應用程式應以伺服器端授權為準；用戶端權限應與伺服器允許的操作一致。
