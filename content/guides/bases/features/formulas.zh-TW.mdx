title: 公式
icon: '#pro/Sigma'
---

Bases 公式欄位使用 Univer 公式引擎，根據資料表中的資料計算記錄值。當 Base 包含公式欄位，或使用者介面需要顯示公式計算進度時，請註冊公式支援所需的相依項目。

## 註冊公式支援

```ts
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverSheetsFormulaPlugin } from '@univerjs/sheets-formula'

univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

## 建立公式欄位

```ts
const total = table.addField({
  name: 'Total',
  type: univerAPI.Enum.BaseFieldTypeEnum.Formula,
  config: {
    formula: '{Price} * {Quantity}',
  },
})
```

## 注意事項

- 公式欄位是衍生值；請避免透過應用程式程式碼直接寫入公式儲存格。
- 公式運算式應使用目前 Bases 公式剖析器所要求的語法來參照欄位。
- 匯入大型快照後，請先重新計算公式，再向使用者顯示結果。
