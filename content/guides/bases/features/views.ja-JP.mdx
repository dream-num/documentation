Views let users see the same table through different projections. Bases includes grid, kanban, calendar, gantt, and gallery view types.

## Create views

```ts
const grid = table.createView({
  name: 'All records',
  type: univerAPI.Enum.BaseViewTypeEnum.Grid,
})

const kanban = table.createView({
  name: 'By status',
  type: univerAPI.Enum.BaseViewTypeEnum.Kanban,
  config: {
    groupFieldId: 'status',
  },
})
```

## Activate a view in the UI

```ts
const baseUI = univerAPI.getBaseUI(base.getId())
baseUI.activateTable(table.getId())
baseUI.activateView(kanban.getId())
```

## Configure view rules

```ts
kanban.setGroup([
  { fieldId: 'status', direction: univerAPI.Enum.BaseSortDirectionEnum.Asc },
])

kanban.setFilter({
  conjunction: 'and',
  conditions: [
    { fieldId: 'archived', operator: 'is', operand: false },
  ],
})
```

Use view-level field settings for visibility, widths, and card display without changing the underlying table schema.
