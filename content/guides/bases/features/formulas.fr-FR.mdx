Les champs de formule de Bases utilisent le moteur de formules Univer pour calculer les valeurs des enregistrements à partir des données d’une table. Enregistrez les dépendances de formules lorsque votre base contient des champs de formule ou lorsque l’interface utilisateur doit afficher la progression des calculs.

## Enregistrer la prise en charge des formules

```ts
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverSheetsFormulaPlugin } from '@univerjs/sheets-formula'

univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

## Créer un champ de formule

```ts
const total = table.addField({
  name: 'Total',
  type: univerAPI.Enum.BaseFieldTypeEnum.Formula,
  config: {
    formula: '{Price} * {Quantity}',
  },
})
```

## Remarques

- Les champs de formule contiennent des valeurs calculées ; évitez d’écrire directement dans leurs cellules depuis le code de l’application.
- Les expressions de formule doivent référencer les champs selon la syntaxe attendue par l’analyseur de formules de Bases actuellement utilisé.
- Après l’importation de captures volumineuses, recalculez les formules avant de présenter les résultats aux utilisateurs.
