Les champs de formule de Bases calculent les valeurs des enregistrements à partir des données d’une table. `UniverBasesPlugin` enregistre automatiquement sa dépendance au moteur de formules Pro.

## Enregistrer la prise en charge des formules

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

## Créer un champ de formule

```ts
const formulaTableName = table.getFormulaName()
const total = table.addField('Total', univerAPI.Enum.BaseFieldType.Formula, {
  field: {
    config: {
      formula: `=SUM(${formulaTableName}[[#This Row],[Price]],${formulaTableName}[[#This Row],[Tax]])`,
    },
  },
  externalReferences: [],
})
```

`externalReferences` est obligatoire pour chaque écriture de champ de formule. Utilisez `[]` uniquement pour les formules qui référencent des champs de la Base hôte. Pour les formules entre unités, utilisez [`buildReference`](/reference/facade/formula#buildreference) et fournissez chaque liaison de source stable dans ce tableau.

## Remarques

- Les champs de formule contiennent des valeurs calculées ; évitez d’écrire directement dans leurs cellules depuis le code de l’application.
- Les expressions de formule utilisent des références de champ structurées telles que `Table[[#This Row],[Price]]`.
- Après l’importation de captures volumineuses, recalculez les formules avant de présenter les résultats aux utilisateurs.
