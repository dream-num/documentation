Bases 支持导入 **XLSX、XLS、CSV、TSV**，导出 **XLSX、CSV、TSV**。常见流程是先将 Excel 中的客户名单导入为 Base，添加字段和视图，然后再导出表数据。

这些 API 都需要转换后端。先按[导入导出集成](/server/import-export)接入转换后端，并确认后端支持 Bases 文档类型和所需的格式。前端插件安装完成，并不表示服务端已支持对应格式。

## 支持的格式

下表列出的是本页所述前端 API 所支持的格式。实际转换 Office 文件时，后端还必须支持相同的文档类型和格式。

| 导入 | 导出 |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV、TSV 一次只能导出一张表，通过 `tableId` 指定。这两种文本格式不保留视图、权限或其他 Base 资源。如需完整的应用备份，请保存 Base 快照。

## 安装和注册

在[已初始化的 Bases 编辑器](/guides/bases/getting-started/installation)中安装以下两个包：

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/bases-exchange-client
```

```ts
import { UniverBasesExchangeClientPlugin } from '@univerjs-pro/bases-exchange-client'
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client'

import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-exchange-client/facade'
import '@univerjs-pro/exchange-client/facade'

univer.registerPlugin(UniverExchangeClientPlugin, exchangeConfig)
univer.registerPlugin(UniverBasesExchangeClientPlugin)
```

`exchangeConfig` 包含业务后端的上传、转换、任务查询和下载配置，可参照[服务端集成指南](/server/import-export)完成配置。

`UniverExchangeClientPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `downloadEndpointUrl` | `string` | `location.origin` | 下载文件的基础地址。 |
| `uploadFileServerUrl` | `string` | `'/universer-api/stream/file/upload'` | 接收文件上传的接口。 |
| `importServerUrl` | `string` | `'/universer-api/exchange/{type}/import'` | 启动导入任务的接口，`{type}` 占位符要原样保留。 |
| `exportServerUrl` | `string` | `'/universer-api/exchange/{type}/export'` | 启动导出任务的接口，`{type}` 占位符要原样保留。 |
| `getTaskServerUrl` | `string` | `'/universer-api/exchange/task/{taskID}'` | 查询任务状态的接口，`{taskID}` 占位符要原样保留。 |
| `signUrlServerUrl` | `string` | `'/universer-api/file/{fileID}/sign-url'` | 签发文件 URL 的接口，`{fileID}` 占位符要原样保留。 |
| `maxTimeoutTime` | `number` | `120000` | 轮询转换任务的最长时间，单位为毫秒。 |

### 配置 Excel 转换 [#excel-conversion]

`UniverBasesExchangeClientPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `importSourceMode` | `ExchangeBaseImportMode` | `AUTO` | 导入 Excel 表格、普通工作表，还是两者都导入。 |
| `importFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `CONVERT_THEN_VALUES` | 导入时怎么处理公式。 |
| `exportStructureMode` | `ExchangeBaseExportMode` | `TABLES` | 导出成 Excel 表格还是普通工作表区域。 |
| `exportFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `FAIL` | 导出时怎么处理公式。 |

转换行为可以在注册 Bases 导入导出插件时调整。以下配置即默认值，它会替换前面不带参数的注册：

```ts
import {
  ExchangeBaseExportMode,
  ExchangeBaseFormulaPolicy,
  ExchangeBaseImportMode,
} from '@univerjs-pro/exchange-client'

univer.registerPlugin(UniverBasesExchangeClientPlugin, {
  importSourceMode: ExchangeBaseImportMode.AUTO,
  importFormulaPolicy: ExchangeBaseFormulaPolicy.CONVERT_THEN_VALUES,
  exportStructureMode: ExchangeBaseExportMode.TABLES,
  exportFormulaPolicy: ExchangeBaseFormulaPolicy.FAIL,
})
```

- 导入来源：`AUTO` 自动选择 Excel 表格和可见工作表；`TABLES` 只导入 Excel 表格；`SHEETS` 只导入可见工作表；`HYBRID` 导入 Excel 表格，以及没有对应 Excel 表格的可见工作表。
- 导出结构：`TABLES` 将非空 Base 表转换为 Excel 表格，空表保留为普通区域；`RANGES` 将所有表导出为普通工作表区域。
- 公式：导入时先尝试转换，引擎不支持的公式退回缓存结果；导出时默认要求公式转换成功，否则失败。`VALUES` 只写入缓存结果，`TEXT` 将原公式保留为文本。导出时，`CONVERT_THEN_VALUES` 遇到无法转换的公式仍然会失败。

## 导入后在当前页面编辑

`file` 可以是用户选择的本地 `File`，也可以是指向远程文件的 URL。返回的快照是编辑器可以直接加载的 Base 数据：

```ts
const snapshot = await univerAPI.importBaseToSnapshotAsync(file)
if (snapshot) {
  univerAPI.createBase(snapshot)
}
```

通过快照导入不需要协同服务，但文件仍需在后端转换。如需用户下次继续编辑，请保存 `base.save()` 的结果，做法见[快照保存与恢复](/guides/bases/model/base-snapshot)。

## 导出文件

将当前 Base 导出为 Excel：

```ts
import { ExchangeFormat } from '@univerjs-pro/exchange-client'

const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

const file = await univerAPI.exportBaseBySnapshotAsync(base.save(), ExchangeFormat.XLSX)
if (file) {
  univerAPI.downloadFile(file, 'database', ExchangeFormat.XLSX)
}
```

CSV 和 TSV 只能表示一张表，因此从包含多张表的 Base 导出时，必须显式传入 `tableId`：

```ts
const table = base.getTables()[0]
if (!table) throw new Error('Create a table first')

const file = await univerAPI.exportBaseBySnapshotAsync(
  base.save(),
  ExchangeFormat.CSV,
  table.getId(),
)
if (file) {
  univerAPI.downloadFile(file, table.getName(), ExchangeFormat.CSV)
}
```

导出 TSV 时，将 `ExchangeFormat.CSV` 替换为 `ExchangeFormat.TSV`。文件导出用于交换表数据；如需完整备份，请保存 Base 快照，CSV 不保留视图、权限或其他资源。

## 导入为协同文档

先按[Bases 协同编辑](/guides/bases/features/collaboration)接入协同，再导入文档并加载服务端返回的文档 ID：

```ts
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importBaseToUnitIdAsync(file)
if (unitId) {
  await univerAPI.getCollaboration().loadBaseAsync(unitId)
}
```

导出服务端文档使用 `exportBaseByUnitIdAsync(unitId, format, tableId?)`。导出前需等待浏览器中尚未同步的修改完成同步。

用真实的业务文件验证字段和公式的转换结果。这些方法可能返回 `undefined`，也可能抛出请求或转换异常，界面中需要同时处理这两种情况。
