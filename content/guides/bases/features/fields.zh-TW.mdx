欄位定義 Base 資料表的結構描述。每個欄位都有各自的類型、設定、預設值，以及排序、篩選、分組或顯示於卡片等功能。

## 新增欄位

```ts
const table = base.getTable('tasks')

const title = table.addField({
  name: 'Title',
  type: univerAPI.Enum.BaseFieldTypeEnum.Text,
})

const priority = table.addField({
  name: 'Priority',
  type: univerAPI.Enum.BaseFieldTypeEnum.SingleSelect,
  config: {
    options: [
      { id: 'high', name: 'High', color: '#ef4444' },
      { id: 'low', name: 'Low', color: '#22c55e' },
    ],
  },
})
```

## 更新欄位

```ts
priority.setName('Impact')
priority.setDescription('Business priority')
priority.setConfig({
  options: [
    { id: 'p0', name: 'P0', color: '#dc2626' },
    { id: 'p1', name: 'P1', color: '#f97316' },
  ],
})
```

## 變更欄位類型

```ts
table.changeFieldType(priority.getId(), {
  type: univerAPI.Enum.BaseFieldTypeEnum.Text,
  config: {},
})
```

變更欄位類型可能會將現有值正規化。將結構變更套用至正式環境的資料表前，請先在應用程式中驗證資料。
