Bases ne fournit actuellement ni plugin d’impression dédié ni API Facade d’impression. Imprimer la page du navigateur n’imprime pas toute la table : certains enregistrements peuvent ne pas encore être chargés ou visibles.

## Exporter, puis imprimer

Pour imprimer les données d’une table, [exportez-les au format XLSX](/guides/bases/features/import-export), puis ouvrez le fichier dans une application compatible pour régler le format du papier, l’orientation et la pagination. La conversion nécessite le service backend correspondant.

Cette méthode imprime les données de la table, sans garantir la conservation de la disposition des vues ou des tableaux de bord de Bases.

## Pages d’impression personnalisées

Pour un rapport métier avec une mise en page spécifique, lisez les enregistrements nécessaires et générez une page d’impression dédiée dans votre application. Vérifiez que toutes les données sont chargées, que les champs sélectionnés sont corrects et que l’utilisateur dispose des droits de lecture et d’impression. Enregistrer dans Bases le plugin d’impression d’un autre produit ne fournit pas cette fonctionnalité.
