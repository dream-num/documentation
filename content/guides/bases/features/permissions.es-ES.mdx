Bases expone ayudas de fachada para permisos de Base, tabla, campo y registro. Utilice API de permisos para mantener el código de la aplicación cerca de conceptos orientados al usuario en lugar de servicios internos.

## Permisos de lectura

```ts
const permission = base.getPermission()
const tablePermission = permission.getTablePermission(table.getId())
const fieldPermission = permission.getFieldPermission(table.getId(), field.getId())
```

## Permisos de actualización

```ts
permission.setBasePermission({
  createTable: false,
})

permission.setTablePermission(table.getId(), {
  editable: true,
  removable: false,
})
```

## Comportamiento de la interfaz de usuario

La interfaz de usuario de Bases lee el estado de los permisos para decidir si las acciones deben ser visibles o habilitadas. Mantenga la autorización del lado del servidor como fuente de verdad para las aplicaciones de producción; los permisos del cliente deben reflejar lo que permite el servidor.
