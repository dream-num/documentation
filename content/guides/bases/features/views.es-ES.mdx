Las vistas permiten a los usuarios ver la misma tabla a través de diferentes proyecciones. Las bases incluyen los tipos de vista de cuadrícula, kanban, calendario, Gantt y galería.

## Crear vistas

```ts
const grid = table.createView({
  name: 'All records',
  type: univerAPI.Enum.BaseViewTypeEnum.Grid,
})

const kanban = table.createView({
  name: 'By status',
  type: univerAPI.Enum.BaseViewTypeEnum.Kanban,
  config: {
    groupFieldId: 'status',
  },
})
```

## Activar una vista en la interfaz de usuario

```ts
const baseUI = univerAPI.getBaseUI(base.getId())
baseUI.activateTable(table.getId())
baseUI.activateView(kanban.getId())
```

## Configurar reglas de vista

```ts
kanban.setGroup([
  { fieldId: 'status', direction: univerAPI.Enum.BaseSortDirectionEnum.Asc },
])

kanban.setFilter({
  conjunction: 'and',
  conditions: [
    { fieldId: 'archived', operator: 'is', operand: false },
  ],
})
```

Utilizar configuraciones de campo a nivel de vista para visibilidad, anchos y visualización de tarjetas sin cambiar el esquema de la tabla subyacente.
