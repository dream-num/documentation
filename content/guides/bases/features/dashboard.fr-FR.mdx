Un tableau de bord place les graphiques, les filtres, le texte et les images sur une seule page. Les deux fonctionnalités sont fournies par des plugins séparés, et l'affichage local ne nécessite pas de collaboration.

## Enregistrer les plugins

Enregistrez les plugins du tableau de bord après les plugins Bases core et UI :

```package-install
npm install @univerjs-pro/bases-dashboard @univerjs-pro/bases-dashboard-ui
```

```ts
import { UniverBaseDashboardPlugin } from '@univerjs-pro/bases-dashboard'
import { UniverBaseDashboardUIPlugin } from '@univerjs-pro/bases-dashboard-ui'

import '@univerjs-pro/bases-dashboard/facade'

univer.registerPlugin(UniverBaseDashboardPlugin)
univer.registerPlugin(UniverBaseDashboardUIPlugin)
```

Fusionner les localisations des nouveaux paquets dans l'application. Les plugins déclarent les dépendances sur le graphique, le document et la forme. Si ces dépendances nécessitent une configuration personnalisée, les enregistrer d'abord.

## Créer une vue pivot du chiffre d’affaires

L'exemple ci-dessous crée un tableau et regroupe les revenus par région :

```ts
import { PivotTableFiledAreaEnum } from '@univerjs-pro/engine-pivot'

const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

const table = base.insertTable('Orders', { primaryFieldName: 'Region' })
const revenue = table.addField('Revenue', univerAPI.Enum.BaseFieldType.Number)
table.addRecords([
  { values: { [table.getPrimaryFieldId()]: 'East', [revenue.getId()]: 120 } },
  { values: { [table.getPrimaryFieldId()]: 'West', [revenue.getId()]: 80 } },
])

const pivot = base.createPivotView('Revenue by region', table.getId())
const pivotTable = pivot.getPivotTable()
pivotTable.addFieldWithSourceId(table.getPrimaryFieldId(), PivotTableFiledAreaEnum.Row)
pivotTable.addFieldWithSourceId(revenue.getId(), PivotTableFiledAreaEnum.Value)
pivot.updateConfig({ pivot: pivotTable.toJSON(), displayMode: 'chart-and-table' })

const baseUI = univerAPI.getBaseUI()
await baseUI.activateTable(table.getId())
await baseUI.activateView(pivot.getId())
```

`getPivotTable()` retourne un modèle de calcul détaché. Modifiez le modèle, puis appelez `updateConfig()` pour persister les changements dans la Base. `displayMode` accepte `table`, `chart` ou `chart-and-table`.

## Ajouter son graphique à un tableau de bord

```ts
const dashboard = base.createDashboard('Sales overview')
dashboard.addPivotChart(table.getId(), pivot.getId(), {
  title: 'Revenue by region',
  layout: { column: 0, row: 0, columnSpan: 6, rowSpan: 6 },
})
```

Le graphique fait référence à une vue pivotante existante. Les champs d'agrégation et les calculs appartiennent à cette vue, et la disposition et la présentation appartiennent au tableau de bord. Le nouveau tableau de bord peut être ouvert à partir de la barre latérale Bases.

`addTableFilter()`, `addText()`, `addImage()` et `addFormulaShape()` ajouter des filtres, du texte riche, des images et des formes de formule. Appelez `getWidgets()` pour lire les widgets en arrière et `removeWidget()` pour les supprimer.

## Enregistrement et autorisations

`base.save()` écrit l'instantané complet, y compris les ressources du tableau de bord. L'enregistrement de seulement les enregistrements de table perd cette configuration. Enregistrez les plugins du tableau de tableau de bord avant de restaurer un instantané.

Les tableaux de bord et les vues de pivots exposent tous les deux `getPermission()`, de sorte que l'un ou l'autre peut être fait en lecture seule; voir [Autorisations](/guides/bases/features/core/permissions). L'API complète est documentée dans [Façade des bases](/reference/facade/base) .
