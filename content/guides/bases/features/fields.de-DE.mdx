Felder definieren das Schema einer Basistabelle. Jedes Feld verfügt über einen Typ, eine Konfiguration, einen Standardwert und Funktionen wie Sortieren, Filtern, Gruppieren oder Kartenanzeige.

## Felder hinzufügen

```ts
const table = base.getTableById('tasks')
if (!table) throw new Error('Tasks table not found')

const title = table.addField('Title', univerAPI.Enum.BaseFieldType.Text)

const priority = table.addField(
  'Priority',
  univerAPI.Enum.BaseFieldType.SingleSelect,
  {
    field: {
      config: {
        options: [
          { id: 'high', name: 'High', color: '#ef4444' },
          { id: 'low', name: 'Low', color: '#22c55e' },
        ],
      },
    },
  },
)
```

## Felder aktualisieren

```ts
priority.setName('Impact')
priority.update({ description: 'Business priority' })
priority.setConfig({
  options: [
    { id: 'p0', name: 'P0', color: '#dc2626' },
    { id: 'p1', name: 'P1', color: '#f97316' },
  ],
})
```

## Feldtyp ändern

```ts
priority.changeType(univerAPI.Enum.BaseFieldType.Text, {})
```

Durch das Ändern eines Feldtyps werden möglicherweise vorhandene Werte normalisiert. Validieren Sie Daten in Ihrer Anwendung, bevor Sie Schemaänderungen auf Produktionstabellen anwenden.
