작업, 주문 및 기타 기록에 대해 의견을 사용하십시오. 의견은 그리드, Kanban, Gallery, Calendar 및 Gantt보기에 기록되어 있으며 전환보기는 별도의 토론을 만들 수 없습니다.

## 플러그인 등록

Bases 코어와 UI 플러그인 이후 다음 플러그인을 등록:

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs-pro/bases-thread-comment @univerjs-pro/bases-thread-comment-ui
```

```ts
import { UniverBasesThreadCommentPlugin } from '@univerjs-pro/bases-thread-comment'
import { UniverBasesThreadCommentUIPlugin } from '@univerjs-pro/bases-thread-comment-ui'
import ProductLocale from '@univerjs-pro/bases-thread-comment-ui/locale/ko-KR'
import { LocaleType, mergeLocales } from '@univerjs/core'
import SharedLocale from '@univerjs/thread-comment-ui/locale/ko-KR'
import '@univerjs-pro/bases-thread-comment/facade'
import '@univerjs/thread-comment/facade'
import '@univerjs/thread-comment-ui/lib/index.css'
import '@univerjs-pro/bases-thread-comment-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.KO_KR, mergeLocales(SharedLocale, ProductLocale))
univer.registerPlugin(UniverBasesThreadCommentPlugin)
univer.registerPlugin(UniverBasesThreadCommentUIPlugin)
```

댓글 패키지에서 Locale 리소스를 활용하고 응용 프로그램에 대한 현재 사용자를 구성합니다. UI 플러그인은 기록에 대한 주석 컨트롤을 추가하고, 데이터 플러그인은 레코드와 코멘트를 연관시킵니다.

## 댓글 추가 및 읽기

```ts
const record = univerAPI.getActiveBase()?.getTables()[0]?.getRecords()[0]
if (!record) throw new Error('Create a record first')

await record.createCommentAsync('Please confirm the delivery date.')
const comments = record.getComments()
console.log(comments.map(({ root }) => root.id))
```

`getComments()`는 이미 로컬로로드 된 코멘트를 반환합니다. 원격 데이터 소스로 `await record.listCommentsAsync()`가 스레드를 동기화하여 이미 그들을 반환하기 전에 알고 있습니다. 답글, 업데이트 및 삭제는 [댓글 Facade](/reference/facade/thread-comment)에 설명되어 있습니다.

## 저장 및 공유 토론

응용 프로그램 호출 `base.save()`가 될 때 로컬 저장소의 일부로 저장됩니다. 스냅 샷을 복원하기 전에 주석 플러그인을 등록하십시오.

공유 토론은 또한 코멘트 서비스, 데이터 소스 및 권한이 필요합니다. 문서 협업은 단독으로 댓글을 연결하지 않습니다. [Office 확장 모듈](/server/collaboration/extensions)를 먼저 구성하고, 생성, 읽기, 권한 및 두 계정으로 다시 열 수 있습니다.

## 공통 댓글 작업 [#shared-comment-api]

이 방법을 호출하기 전에 공유 된 의견 Facade 및 제품 Facade를 모두 가져 오기. 제품 도우미는 안정적인 앵커를 만들고 공유 된 API는 응답, 업데이트, 해상도 및 삭제를 처리합니다. `getComments()`는 로컬 상태를 읽으며 `listCommentsAsync()`가 구성 된 데이터 소스를 통해 이미 알고있는 스레드를 동기화합니다. 서버에서 모든 스레드를 발견하지 않습니다.

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## 공유 토론 [#shared-discussions]

공유 토론을 활성화하려면 [Server SDK](/server/collaboration/extensions)를 통해 주석 서비스 및 엔드포인트를 통합 한 다음 `UniverThreadCommentDataSourcePlugin`을 `@univerjs-pro/thread-comment-datasource`에서 협업하고 라이센스를 구성 한 후 등록하십시오. 번들 데이터 소스는 `/universer-api/comment/unit/{unitId}/...` 및 `/universer-api/user/list`로 전화하므로 응용 프로그램은이 루트를 노출해야합니다. 서버 권한은 코멘트를 제어하고 문서 편집의 독립적으로 작성해야합니다.
