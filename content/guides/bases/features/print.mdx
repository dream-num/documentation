Bases does not include a dedicated print plugin, and it does not expose a Facade API for printing. Printing the browser page does not produce the complete table either, because some records may not be loaded or visible yet.

## Export, then print

To print table data, [export it as XLSX](/guides/bases/features/import-export) and open the file in an application that can set paper size, orientation, and pagination. The conversion requires the matching backend service.

This approach prints the table data only. It does not preserve the layout of a Bases view or dashboard.

## Custom print pages

If you need a report layout specific to your business, read the records you need and build a dedicated print page in your application. Before printing, confirm that all data has loaded, that the field selection is correct, and that the user has both read and print permission. Registering another product's print plugin on Bases does not provide this capability.
