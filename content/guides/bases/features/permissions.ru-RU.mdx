В Bases предусмотрены вспомогательные методы фасада для управления правами доступа к базе, таблицам, полям и записям. Используйте API прав доступа, чтобы код приложения опирался на понятные пользователю сущности, а не на внутренние сервисы.

## Чтение прав доступа

```ts
const permission = base.getPermission()
const tablePermission = permission.getTablePermission(table.getId())
const fieldPermission = permission.getFieldPermission(table.getId(), field.getId())
```

## Обновление прав доступа

```ts
permission.setBasePermission({
  createTable: false,
})

permission.setTablePermission(table.getId(), {
  editable: true,
  removable: false,
})
```

## Поведение интерфейса

Интерфейс Bases использует состояние прав доступа, чтобы определить, следует ли показывать или активировать те или иные действия. В рабочих приложениях источником достоверной информации об авторизации должен оставаться сервер, а права доступа на клиенте должны соответствовать разрешениям сервера.
