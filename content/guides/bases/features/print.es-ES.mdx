Bases no ofrece actualmente un plugin de impresión dedicado ni una API Facade de impresión. Imprimir la página del navegador no imprime toda la tabla: algunos registros pueden no haberse cargado o no estar visibles.

## Exportar e imprimir

Para imprimir los datos de una tabla, [expórtalos como XLSX](/guides/bases/features/import-export) y abre el archivo en una aplicación compatible para configurar el tamaño del papel, la orientación y la paginación. La conversión requiere el servicio de backend correspondiente.

Este método imprime los datos de la tabla; no garantiza conservar el diseño de las vistas o los paneles de Bases.

## Páginas de impresión personalizadas

Si necesitas un diseño de informe específico para tu negocio, lee los registros necesarios y genera una página de impresión dedicada en tu aplicación. Comprueba que todos los datos estén cargados, que la selección de campos sea correcta y que el usuario tenga permisos de lectura e impresión. Registrar en Bases el plugin de impresión de otro producto no proporciona esta función.
