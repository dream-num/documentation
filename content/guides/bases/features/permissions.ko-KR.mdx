베이스는 베이스, 테이블, 필드, 레코드 권한을 위한 퍼사드 헬퍼를 제공합니다. 내부 서비스 대신 사용자에게 익숙한 개념을 중심으로 애플리케이션 코드를 구성하려면 권한 API를 사용하세요.

## 권한 읽기

```ts
const permission = base.getPermission()
const tablePermission = permission.getTablePermission(table.getId())
const fieldPermission = permission.getFieldPermission(table.getId(), field.getId())
```

## 권한 업데이트

```ts
permission.setBasePermission({
  createTable: false,
})

permission.setTablePermission(table.getId(), {
  editable: true,
  removable: false,
})
```

## UI 동작

베이스 UI는 권한 상태를 확인하여 작업을 표시하거나 활성화할지 결정합니다. 프로덕션 애플리케이션에서는 서버 측 권한 부여를 신뢰할 수 있는 기준으로 삼고, 클라이언트 권한은 서버에서 허용하는 범위를 그대로 반영해야 합니다.
