Пользователи могут открыть одну Base и совместно редактировать таблицы, поля, записи и представления. Они могут работать в разных представлениях, изменяя один документ.

## Шаги интеграции

1. Следуйте разделу [Интеграция совместного редактирования](/server/collaboration/browser-integration), чтобы запустить пример и подключить вход, права доступа и хранение в базе данных.
2. Добавьте настройки клиента Collaboration в существующий редактор Bases. Настройте браузер по инструкции [Быстрый старт Office](/server/collaboration/quick-start), но создавайте и сохраняйте документы Bases вместо копирования данных Sheets из примера.
3. Создайте Base через серверную часть приложения и верните её ID браузеру.

## Открытие Base с сервера

```ts
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/collaboration-client/facade'

const base = await univerAPI.getCollaboration().loadBaseAsync('your-base-id')
if (!base) throw new Error('Base could not be loaded')
```

Повторно используйте ID при открытии или совместном доступе к документу. Не заменяйте загрузку с сервера вызовом `createBase()` и созданием пустого локального документа.

## Проверка синхронизации и сохранения

Откройте один ID в двух независимых сеансах браузера. В одном добавьте запись или измените поле и убедитесь, что другой получил изменение. Проверьте сохранность изменений после обновления страницы и перезапуска сервера.

Проверяйте доступ читателей и пользователей без разрешений на сервере. [Локальные настройки только для чтения](/guides/bases/features/core/permissions) управляют лишь редактором. Преобразование файлов, комментарии и история требуют соответствующих серверных функций; см. [Импорт и экспорт](/guides/bases/features/import-export), [Комментарии](/guides/bases/features/thread-comment) и [История](/guides/bases/features/edit-history).
