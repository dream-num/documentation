Несколько пользователей могут открывать одну и ту же Базу и редактировать таблицы, поля, записи и просмотры вместе.Каждый пользователь может работать в другом представлении, в то время как все изменения относятся к одному и тому же документу.

## Шаги интеграции

1. Следуйте за [Интеграция сотрудничества](/server/collaboration/browser-integration) для запуска примера совместной работы, а затем подключите логин, разрешения и хранилище базы данных.
2. Добавьте конфигурацию клиента совместной работы в существующий редактор Bases. Для браузера следуйте [Сотрудничество Quick Start](/server/collaboration/quick-start), но создайте и храните документы Bases вместо копирования данных Sheets из примера.
3. Создайте Базу на бэкэнде приложения и верните его идентификатор в браузер.

## Открытие Base с сервера

Задайте текущего пользователя до загрузки документа. См. раздел [Интеграция совместного редактирования](/server/collaboration/browser-integration).

```ts
import '@univerjs-pro/bases/facade'
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const base = await univerAPI.getCollaboration().loadBaseAsync('your-base-id')
if (!base) throw new Error('Base could not be loaded')
```

Повторное использование того же идентификатора при повторном открытии или совместном использовании документа.Не заменяйте загрузку сервера `createBase()` и новым локальным пустым документом.

Используйте [Статус синхронизации, повторы и восстановление конфликта](/server/collaboration/browser-integration#sync-status) для создания индикаторов сохранения и защиты непризнанных правок перед перезагрузкой.

## Удаление встроенной загрузки совместных документов по URL [#url-unit-loader-migration]

<Callout type="warning" title="Замечание">
  Начиная с версии **1.2.0**, Univer больше не включает встроенную загрузку URL для совместных документов. Он больше не считывает параметры URL `unit` и `type` для определения того, какой документ загружать.
</Callout>

Если приложение зависит от этого поведения, пользовательский плагин может восстановить его.

### Подключение собственного плагина

Скопируйте четыре файла ниже в проект и сохраните следующую структуру каталога:

```text
custom-url-load/
├── plugin.ts
├── controllers/
│   └── data-loader.controller.ts
└── services/
    ├── url.service.ts
    └── web-url.service.ts
```

После инициализации редактора и плагинов для совместной работы установите текущего пользователя, затем зарегистрируйте `CustomUrlLoadPlugin`.

```ts
import { UserManagerService } from '@univerjs/core'
import { CustomUrlLoadPlugin } from './custom-url-load/plugin'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

univer.registerPlugin(CustomUrlLoadPlugin)
```

После регистрации плагин загружает документ, поэтому вызов `loadBaseAsync()` для того же документа больше не нужен.Если приложение уже загружает документы через Facade, придерживайтесь подхода, описанного в предыдущем разделе, и обрабатывайте URL-адреса по мере необходимости приложения.

    ```ts
    import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
    import { CollaborationDataLoaderController } from './controllers/data-loader.controller'
    import { IURLService } from './services/url.service'
    import { WebURLService } from './services/web-url.service'

    @DependentOn(UniverCollaborationClientPlugin)
    export class CustomUrlLoadPlugin extends Plugin {
      static override pluginName = 'CUSTOM_URL_LOAD_PLUGIN'

      constructor(
        _config: undefined,
        @Inject(Injector) protected override readonly _injector: Injector
      ) {
        super()
      }

      override onStarting(): void {
        this._injector.add([IURLService, { useClass: WebURLService }])
        this._injector.add([CollaborationDataLoaderController])

        this.disposeWithMe(this._injector.get(IURLService))
        this.disposeWithMe(this._injector.get(CollaborationDataLoaderController))
      }
    }
    ```

    ```ts
    import { DataLoaderService } from '@univerjs-pro/collaboration-client'
    import { ILogService, Inject, RxDisposable } from '@univerjs/core'
    import { IURLService } from '../services/url.service'

    /**
     * Загружает совместный документ по параметрам URL.
     */
    export class CollaborationDataLoaderController extends RxDisposable {
      constructor(
        @IURLService private readonly _urlService: IURLService,
        @ILogService private readonly _logService: ILogService,
        @Inject(DataLoaderService) private readonly _dataLoaderService: DataLoaderService
      ) {
        super()

        const unitId = this._urlService.getParam('unit')
        const type = this._urlService.getParam('type')
        if (!unitId || !type) {
          return
        }

        this._dataLoaderService.loadUnit(unitId, Number(type))
          .catch((error: unknown) => {
            this._logService.error('[CollaborationDataLoaderController]', error)
          })
      }
    }
    ```

    ```ts
      getParam: (key: string) => string | undefined
      setParam: (key: string, value: string, useReplace?: boolean) => void
      removeParam: (key: string, useReplace?: boolean) => void
    ```

    ```ts
    import type { IURLService } from './url.service'
    import { RxDisposable } from '@univerjs/core'
    import { fromEvent, map, shareReplay, takeUntil } from 'rxjs'

    export class WebURLService extends RxDisposable implements IURLService {
      readonly urlChange$ = fromEvent(window, 'popstate').pipe(
        map(() => undefined),
        takeUntil(this.dispose$),
        shareReplay({ bufferSize: 1, refCount: true })
      )

      getParam(key: string): string | undefined {
        return new URL(window.location.href).searchParams.get(key) ?? undefined
      }

      setParam(key: string, value: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.set(key, value)
        this._updateUrl(url, useReplace)
      }

      removeParam(key: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.delete(key)
        this._updateUrl(url, useReplace)
      }

      private _updateUrl(url: URL, useReplace: boolean): void {
        if (useReplace) {
          window.history.replaceState(window.history.state, '', url.toString())
        } else {
          window.history.pushState(window.history.state, '', url.toString())
        }
      }
    }
    ```

## Проверка синхронизации и сохранения

Откройте один и тот же идентификатор в двух независимых сеансах браузера. Добавьте запись или измените поле в одном сеансе и подтвердите, что другой получает изменение. Затем проверьте, что изменения сохраняются после обновления страницы и перезагрузки сервера.

Зрители и неавторизованные пользователи должны быть авторизованы на сервере. [Локальные настройки Read-Only](/guides/bases/features/core/permissions) влияет только на поведение редактора. Обмен, комментарии и история требуют своих собственных функций бэкэнда; см. [Импорт и экспорт](/guides/bases/features/import-export), [Комментарий](/guides/bases/features/thread-comment) и [история](/guides/bases/features/edit-history).
