Bases 支援匯入 **XLSX、XLS、CSV、TSV**，匯出 **XLSX、CSV、TSV**。常見流程是先將 Excel 中的客戶名單匯入為 Base，新增欄位和檢視，然後再匯出表資料。

這些 API 都需要轉換後端。先按[匯入匯出整合](/server/import-export)接入轉換後端，並確認後端支援 Bases 文件型別和所需的格式。前端外掛安裝完成，並不表示伺服器端已支援對應格式。

## 支援格式

下表列出的是本頁所述前端 API 所支援的格式。實際轉換 Office 檔案時，後端還必須支援相同的文件型別和格式。

| 匯入 | 匯出 |
| --- | --- |
| `.xls`, `.xlsx`, `.csv`, `.tsv` | `.xlsx`, `.csv`, `.tsv` |

CSV、TSV 一次只能匯出一張表，透過 `tableId` 指定。這兩種文字格式不保留檢視、權限或其他 Base 資源。如需完整的應用備份，請儲存 Base 快照。

## 安裝與註冊

在[已初始化的 Bases 編輯器](/guides/bases/getting-started/installation)中安裝以下兩個包：

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/bases-exchange-client
```

```ts
import { UniverBasesExchangeClientPlugin } from '@univerjs-pro/bases-exchange-client'
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client'

import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-exchange-client/facade'
import '@univerjs-pro/exchange-client/facade'

univer.registerPlugin(UniverExchangeClientPlugin, exchangeConfig)
univer.registerPlugin(UniverBasesExchangeClientPlugin)
```

`exchangeConfig` 包含業務後端的上傳、轉換、任務查詢和下載配置，可參照[伺服器端整合指南](/server/import-export)完成配置。

`UniverExchangeClientPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `downloadEndpointUrl` | `string` | `location.origin` | 下載檔案的基礎位址。 |
| `uploadFileServerUrl` | `string` | `'/universer-api/stream/file/upload'` | 接收檔案上傳的介面。 |
| `importServerUrl` | `string` | `'/universer-api/exchange/{type}/import'` | 啟動匯入任務的介面，`{type}` 佔位符要原樣保留。 |
| `exportServerUrl` | `string` | `'/universer-api/exchange/{type}/export'` | 啟動匯出任務的介面，`{type}` 佔位符要原樣保留。 |
| `getTaskServerUrl` | `string` | `'/universer-api/exchange/task/{taskID}'` | 查詢任務狀態的介面，`{taskID}` 佔位符要原樣保留。 |
| `signUrlServerUrl` | `string` | `'/universer-api/file/{fileID}/sign-url'` | 簽發檔案 URL 的介面，`{fileID}` 佔位符要原樣保留。 |
| `maxTimeoutTime` | `number` | `120000` | 輪詢轉換工作的最長時間，單位為毫秒。 |

### 設定 Excel 轉換 [#excel-conversion]

`UniverBasesExchangeClientPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `importSourceMode` | `ExchangeBaseImportMode` | `AUTO` | 匯入 Excel 表格、普通工作表，還是兩者都匯入。 |
| `importFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `CONVERT_THEN_VALUES` | 匯入時怎麼處理公式。 |
| `exportStructureMode` | `ExchangeBaseExportMode` | `TABLES` | 匯出成 Excel 表格還是普通工作表區域。 |
| `exportFormulaPolicy` | `ExchangeBaseFormulaPolicy` | `FAIL` | 匯出時怎麼處理公式。 |

轉換行為可以在註冊 Bases 匯入匯出外掛時調整。以下配置即預設值，它會替換前面不帶參數的註冊：

```ts
import {
  ExchangeBaseExportMode,
  ExchangeBaseFormulaPolicy,
  ExchangeBaseImportMode,
} from '@univerjs-pro/exchange-client'

univer.registerPlugin(UniverBasesExchangeClientPlugin, {
  importSourceMode: ExchangeBaseImportMode.AUTO,
  importFormulaPolicy: ExchangeBaseFormulaPolicy.CONVERT_THEN_VALUES,
  exportStructureMode: ExchangeBaseExportMode.TABLES,
  exportFormulaPolicy: ExchangeBaseFormulaPolicy.FAIL,
})
```

- 匯入來源：`AUTO` 自動選擇 Excel 表格和可見工作表；`TABLES` 只匯入 Excel 表格；`SHEETS` 只匯入可見工作表；`HYBRID` 匯入 Excel 表格，以及沒有對應 Excel 表格的可見工作表。
- 匯出結構：`TABLES` 將非空 Base 錶轉換為 Excel 表格，空表保留為普通區域；`RANGES` 將所有表匯出為普通工作表區域。
- 公式：匯入時先嚐試轉換，引擎不支援的公式退回快取結果；匯出時預設要求公式轉換成功，否則失敗。`VALUES` 只寫入快取結果，`TEXT` 將原公式保留為文字。匯出時，`CONVERT_THEN_VALUES` 遇到無法轉換的公式仍然會失敗。

## 匯入並在頁面編輯

`file` 可以是使用者選擇的本地 `File`，也可以是指向遠端檔案的 URL。返回的快照是編輯器可以直接載入的 Base 資料：

```ts
const snapshot = await univerAPI.importBaseToSnapshotAsync(file)
if (snapshot) {
  univerAPI.createBase(snapshot)
}
```

透過快照匯入不需要協同服務，但檔案仍需在後端轉換。如需使用者下次繼續編輯，請儲存 `base.save()` 的結果，做法見[快照儲存與恢復](/guides/bases/model/base-snapshot)。

## 匯出檔案

將當前 Base 匯出為 Excel：

```ts
import { ExchangeFormat } from '@univerjs-pro/exchange-client'

const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')

const file = await univerAPI.exportBaseBySnapshotAsync(base.save(), ExchangeFormat.XLSX)
if (file) {
  univerAPI.downloadFile(file, 'database', ExchangeFormat.XLSX)
}
```

CSV 和 TSV 只能表示一張表，因此從包含多張表的 Base 匯出時，必須顯式傳入 `tableId`：

```ts
const table = base.getTables()[0]
if (!table) throw new Error('Create a table first')

const file = await univerAPI.exportBaseBySnapshotAsync(
  base.save(),
  ExchangeFormat.CSV,
  table.getId(),
)
if (file) {
  univerAPI.downloadFile(file, table.getName(), ExchangeFormat.CSV)
}
```

匯出 TSV 時，將 `ExchangeFormat.CSV` 替換為 `ExchangeFormat.TSV`。檔案匯出用於交換表資料；如需完整備份，請儲存 Base 快照，CSV 不保留檢視、權限或其他資源。

## 匯入協同文件

先按[Bases 協同編輯](/guides/bases/features/collaboration)接入協同，再匯入文件並載入伺服器端返回的文件 ID：

```ts
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importBaseToUnitIdAsync(file)
if (unitId) {
  await univerAPI.getCollaboration().loadBaseAsync(unitId)
}
```

匯出伺服器端文件使用 `exportBaseByUnitIdAsync(unitId, format, tableId?)`。匯出前需等待瀏覽器中尚未同步的修改完成同步。

用真實的業務檔案驗證欄位和公式的轉換結果。這些方法可能返回 `undefined`，也可能丟擲請求或轉換異常，介面中需要同時處理這兩種情況。

## 移除內建匯入匯出選單和 UI 互動 [#import-export-ui-migration]

<Callout type="warning" title="注意事項">
  從 **1.2.0** 版本開始，Univer 不再提供內建的匯入匯出選單和 UI 互動，底層服務和 Facade API 仍然保留。
</Callout>

如果應用仍需保留原有的匯入匯出選單和 UI 互動，可參考[內建匯入匯出選單和 UI 互動遷移方案](https://office.univer.ai/zh-CN/showcase/bases/custom-import-export)，透過自定義外掛完成遷移。範例中包含完整原始碼，可線上閱讀或下載。
