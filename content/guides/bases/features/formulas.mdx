Bases formula fields use the Univer formula engine to calculate record values from table data. Register formula dependencies when your Base contains formula fields or when the UI needs formula progress feedback.

## Register formula support

```ts
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverSheetsFormulaPlugin } from '@univerjs/sheets-formula'

univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

## Create a formula field

```ts
const total = table.addField({
  name: 'Total',
  type: univerAPI.Enum.BaseFieldTypeEnum.Formula,
  config: {
    formula: '{Price} * {Quantity}',
  },
})
```

## Notes

- Formula fields are derived values; avoid writing directly to formula cells from application code.
- Formula expressions should reference fields by the syntax expected by the current Bases formula parser.
- Recalculate formulas after importing large snapshots before exposing results to users.
