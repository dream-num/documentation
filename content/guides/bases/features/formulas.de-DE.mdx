Formelfelder in Bases berechnen Datensatzwerte aus Tabellendaten. `UniverBasesPlugin` registriert seine Abhängigkeit von der Pro-Formel-Engine automatisch.

## Formelunterstützung registrieren

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

## Ein Formelfeld erstellen

```ts
const total = table.addField(
  'Total',
  univerAPI.Enum.BaseFieldType.Formula,
  {
    field: {
      config: {
        formula: '=SUM([Price],[Tax])',
      },
    },
    externalReferences: [],
  },
)
```

`externalReferences` ist bei jedem Schreiben eines Formelfelds erforderlich. Verwenden Sie `[]` nur für Formeln, die Felder in der Host-Base referenzieren. Verwenden Sie für Formeln zwischen Units [`buildReference`](/reference/facade/formula#buildreference) und übergeben Sie alle stabilen Quellbindungen in diesem Array.

## Hinweise

- Formelfelder sind abgeleitete Werte; Vermeiden Sie es, direkt aus dem Anwendungscode in Formelzellen zu schreiben.
- Formelausdrücke verwenden strukturierte Feldreferenzen wie `[Price]`.
- Formeln nach dem Importieren großer Snapshots neu berechnen, bevor die Ergebnisse Benutzern angezeigt werden.
