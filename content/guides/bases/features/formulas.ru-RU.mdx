Поля формул в Bases используют механизм формул Univer, чтобы вычислять значения записей на основе данных таблицы. Зарегистрируйте зависимости для работы с формулами, если ваша база содержит поля формул или в интерфейсе нужно отображать ход вычислений.

## Регистрация поддержки формул

```ts
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverSheetsFormulaPlugin } from '@univerjs/sheets-formula'

univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

## Создание поля формулы

```ts
const total = table.addField({
  name: 'Total',
  type: univerAPI.Enum.BaseFieldTypeEnum.Formula,
  config: {
    formula: '{Price} * {Quantity}',
  },
})
```

## Примечания

- Значения полей формул вычисляются автоматически, поэтому не записывайте данные напрямую в такие ячейки из кода приложения.
- Ссылки на поля в выражениях должны соответствовать синтаксису, который поддерживает текущий парсер формул Bases.
- После импорта больших снимков данных пересчитайте формулы, прежде чем показывать результаты пользователям.
