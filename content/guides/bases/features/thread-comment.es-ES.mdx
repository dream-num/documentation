Utilice comentarios para discutir tareas, pedidos y otros registros. Un comentario sigue vinculado a su registro en las vistas Grid, Kanban, Gallery, Calendar y Gantt, y cambiar puntos de vista no crea una discusión separada.

## Registrar los plugins

Registrar los siguientes plugins después del núcleo Bases y los plugins UI:

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs-pro/bases-thread-comment @univerjs-pro/bases-thread-comment-ui
```

```ts
import { UniverBasesThreadCommentPlugin } from '@univerjs-pro/bases-thread-comment'
import { UniverBasesThreadCommentUIPlugin } from '@univerjs-pro/bases-thread-comment-ui'
import ProductLocale from '@univerjs-pro/bases-thread-comment-ui/locale/es-ES'
import { LocaleType, mergeLocales } from '@univerjs/core'
import SharedLocale from '@univerjs/thread-comment-ui/locale/es-ES'
import '@univerjs-pro/bases-thread-comment/facade'
import '@univerjs/thread-comment/facade'
import '@univerjs/thread-comment-ui/lib/index.css'
import '@univerjs-pro/bases-thread-comment-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.ES_ES, mergeLocales(SharedLocale, ProductLocale))
univer.registerPlugin(UniverBasesThreadCommentPlugin)
univer.registerPlugin(UniverBasesThreadCommentUIPlugin)
```

Combina los recursos locales de los paquetes de comentarios, y configura el usuario actual para la aplicación. El plugin UI añade controles de comentarios a los registros, y el plugin de datos asocia comentarios con los registros.

## Añadir y leer comentarios

```ts
const record = univerAPI.getActiveBase()?.getTables()[0]?.getRecords()[0]
if (!record) throw new Error('Create a record first')

await record.createCommentAsync('Please confirm the delivery date.')
const comments = record.getComments()
console.log(comments.map(({ root }) => root.id))
```

`getComments()` devuelve los comentarios que ya están cargados localmente. Con una fuente de datos remota, `await record.listCommentsAsync()` sincroniza los hilos que ya sabe antes de devolverlos. Respuestas, actualizaciones y eliminación se describen en [comentario Facade](/reference/facade/thread-comment).

## Guardado y conversaciones compartidas

Los comentarios creados localmente se guardan como parte de los recursos de Base cuando la aplicación llama `base.save()`. Registrar los plugins de comentarios antes de restaurar una instantánea.

Los debates compartidos también requieren un servicio de comentarios, una fuente de datos y permisos. La colaboración de documentos por sí sola no conecta los comentarios. Configure el [Módulos de extensión de las oficinas](/server/collaboration/extensions) primero, luego verifique la creación, lectura, permisos y reapertura con dos cuentas.

## Operaciones comunes [#shared-comment-api]

Importar tanto el comentario compartido Facade como el producto Facade antes de llamar estos métodos. Los ayudantes del producto crean anclas estables, y el API compartido maneja respuestas, actualizaciones, resolución y eliminación. `getComments()` lee el estado local, mientras que `listCommentsAsync()` sincroniza los hilos que ya conoce a través de la fuente de datos configurada; no descubre cada hilo en el servidor.

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## Conversaciones compartidas [#shared-discussions]

Para permitir discusiones compartidas, integrar el servicio de comentarios y el punto final a través de la [Server SDK](/server/collaboration/extensions), luego registrar `UniverThreadCommentDataSourcePlugin` de `@univerjs-pro/thread-comment-datasource` después de la colaboración y la licencia se configuran. La fuente de datos agrupados llama `/universer-api/comment/unit/{unitId}/...` y `/universer-api/user/list`, por lo que la aplicación debe exponer estas rutas. Los permisos del servidor deben controlar comentarios leídos y escribe independientemente de la edición de documentos.
