Comenta tareas, pedidos y otros registros. Los comentarios permanecen vinculados al registro en las vistas Cuadrícula, Kanban, Galería, Calendario y Gantt; cambiar de vista no crea una conversación independiente.

## Registrar los plugins

Añádelos después de los plugins principales y de interfaz de Bases:

```package-install
npm install @univerjs-pro/bases-thread-comment @univerjs-pro/bases-thread-comment-ui
```

```ts
import { UniverBasesThreadCommentPlugin } from '@univerjs-pro/bases-thread-comment'
import { UniverBasesThreadCommentUIPlugin } from '@univerjs-pro/bases-thread-comment-ui'

import '@univerjs-pro/bases-thread-comment/facade'
import '@univerjs/thread-comment/facade'
import '@univerjs-pro/bases-thread-comment-ui/lib/index.css'

univer.registerPlugin(UniverBasesThreadCommentPlugin)
univer.registerPlugin(UniverBasesThreadCommentUIPlugin)
```

Combina los recursos de idioma de los paquetes de comentarios y configura el usuario actual de la aplicación. El plugin UI añade los controles de comentarios de los registros; el plugin de datos vincula los comentarios a los registros.

## Añadir y leer comentarios

```ts
const record = univerAPI.getActiveBase()?.getTables()[0]?.getRecords()[0]
if (!record) throw new Error('Create a record first')

await record.createCommentAsync('Please confirm the delivery date.')
const comments = record.getComments()
console.log(comments.map(({ root }) => root.id))
```

`getComments()` lee los comentarios cargados localmente. Con una fuente de datos remota, `await record.listCommentsAsync()` sincroniza los hilos conocidos antes de devolverlos. Consulta la [Facade de comentarios](/reference/facade/thread-comment) para responder, actualizar y eliminar.

## Guardado y conversaciones compartidas

Los comentarios locales se pueden guardar como recursos de Base mediante `base.save()`. Registra los plugins de comentarios antes de restaurar una instantánea.

Las conversaciones compartidas también necesitan un servicio de comentarios, una fuente de datos y permisos. La colaboración documental por sí sola no conecta los comentarios. Sigue los [módulos de extensión de Office](/server/collaboration/extensions) y prueba la creación, lectura, permisos y reapertura con dos cuentas.
