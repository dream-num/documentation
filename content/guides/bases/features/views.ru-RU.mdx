Представления позволяют показывать одну и ту же таблицу в разных видах. Bases поддерживает таблицу, канбан, календарь, диаграмму Ганта и галерею.

## Создание представлений

```ts
const grid = table.createView({
  name: 'All records',
  type: univerAPI.Enum.BaseViewTypeEnum.Grid,
})

const kanban = table.createView({
  name: 'By status',
  type: univerAPI.Enum.BaseViewTypeEnum.Kanban,
  config: {
    groupFieldId: 'status',
  },
})
```

## Активация представления в интерфейсе

```ts
const baseUI = univerAPI.getBaseUI(base.getId())
baseUI.activateTable(table.getId())
baseUI.activateView(kanban.getId())
```

## Настройка правил представления

```ts
kanban.setGroup([
  { fieldId: 'status', direction: univerAPI.Enum.BaseSortDirectionEnum.Asc },
])

kanban.setFilter({
  conjunction: 'and',
  conditions: [
    { fieldId: 'archived', operator: 'is', operand: false },
  ],
})
```

Настройки полей на уровне представления позволяют управлять видимостью, шириной и отображением карточек, не меняя схему исходной таблицы.
