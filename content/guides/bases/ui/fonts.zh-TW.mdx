Bases 沒有品類專屬的字型登錄，也不支援為單筆記錄設定字型樣式。畫布檢視和儲存格編輯器使用內部字型堆疊 `Arial, "Microsoft YaHei", sans-serif`，以保持文字測量與編輯狀態一致。

## 可設定的內容

- Univer 共用外殼元件遵循主應用程式的主題與 UI 樣式。
- Base 欄位設定負責數字、貨幣、評分、進度和日期等值格式。
- 選項顏色和檢視顏色屬於 Base 資料，不是字型設定。

不要使用 Sheets preset 或 `customFontFamily` 範例設定 Bases 畫布。如果主頁面在工作台周圍使用 Web 字型，請在掛載 Univer 前載入字型，避免外圍 UI 發生版面位移。
