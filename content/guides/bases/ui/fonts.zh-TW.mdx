Bases 不提供產品專用的字型登錄檔，也不支援為單條記錄設定字型樣式。畫布檢視和單元格編輯器使用內部字型棧 `Arial, "Microsoft YaHei", sans-serif`，以保證文字測量和編輯結果一致。

## 可設定的內容

- Univer 通用外殼元件跟隨宿主主題和 UI 樣式。
- 欄位配置決定值的格式，包括數字、貨幣、評分、進度和日期。
- 選項顏色和檢視顏色屬於 Base 資料，不是字型設定。

不要使用 Sheets 的 preset 或 `customFontFamily` 範例來配置 Bases 畫布。如果宿主頁面在工作臺周圍使用 Web 字型，應先載入字型再掛載 Univer，以避免外圍 UI 出現版面配置偏移。
