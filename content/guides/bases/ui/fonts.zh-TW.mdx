Bases 使用共用的 Univer UI 字型管線，呈現表格文字、欄位編輯器、選單和面板。請先在宿主應用程式中載入網頁字型，再轉譯 Bases，以避免版面位移。

## 宿主字型設定

```css
:root {
  font-family: Inter, system-ui, sans-serif;
}
```

## 儲存格文字

網格、看板、行事曆、甘特圖和圖庫檢視中顯示的文字，來自欄位值及各欄位專用的格式化工具。若要設定數字、貨幣、進度、評分和日期的格式，請使用欄位設定，而不要直接為記錄中的原始文字套用樣式。
