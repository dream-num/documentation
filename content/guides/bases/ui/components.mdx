`@univerjs-pro/bases-ui` exports the components used to build the Bases workbench. They run inside an initialized Univer injector and are not standalone design-system widgets.

## Public workbench components

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

The package also exports specialized panels such as `AddViewMenu`, `FilterPanel`, and `FormulaEditorPanel`. Render these panels only when the surrounding Bases services and the unit context are available.

## Supported extension points

- `IBaseViewUIRegistryService` registers a DOM or canvas renderer for a Base view type.
- `IBaseDashboardUIExtensionRegistryService` supplies a single dashboard UI extension.
- `IBaseRecordActionService` adds record actions and supplies each action with the current unit, table, view, and record.

Each registration returns a disposable handle. Dispose the handle when the host plugin is removed so that stale actions or renderers do not remain in the workbench.
