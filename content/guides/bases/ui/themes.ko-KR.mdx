Bases는 공유 Univer 디자인 시스템과 호스트 애플리케이션 테마를 사용합니다. Bases UI 플러그인은 데이터 워크벤치 레이아웃, 필드 편집기, 패널, 뷰 렌더링에 중점을 둡니다.

## 공유 스타일 등록

Bases UI 스타일보다 먼저 공유 스타일을 불러옵니다.

```ts
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/bases-ui/lib/index.css'
```

## 애플리케이션 테마 설정

호스트 애플리케이션의 디자인 토큰과 CSS 변수를 사용하여 페이지 배경, 주변 레이아웃, 셸 수준 탐색을 제어하세요. 레코드 색상, 선택 옵션, 뷰 색상 설정은 스냅샷과 함께 유지되도록 Base 필드 또는 뷰 구성에 저장하세요.

## 필드 색상

단일 선택, 다중 선택, 그룹, 캘린더, 간트 뷰에서는 필드 또는 뷰 구성을 사용하여 의미에 맞는 색상을 렌더링할 수 있습니다.
