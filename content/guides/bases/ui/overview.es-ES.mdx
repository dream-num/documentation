`@univerjs-pro/bases-ui` proporciona el área de trabajo con licencia para Univer Bases en el navegador. Renderiza la navegación de tablas y vistas, las vistas de cuadrícula, kanban, calendario, Gantt y galería, además de editores de campos, detalles de registros, menús y selección.

## Registrar el área de trabajo

Registre la licencia y los motores de fórmulas antes de los plugins de Bases. Los campos de fórmula usan `@univerjs-pro/engine-formula`; no requieren una aplicación de Sheets.

`UniverLicensePlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenido del archivo de licencia del cliente. |

`UniverUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Elemento DOM donde se monta el editor, o su ID. |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

Consulte [Instalación y uso básico](/guides/bases/getting-started/installation) para ver las importaciones, estilos e idiomas.

## Configurar el diseño inicial

`IUniverBaseUIConfig` controla las regiones del área de trabajo y la primera tabla y vista que se muestran.

`UniverBasesUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | Desactiva los controles de edición del área de trabajo. |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | Tabla y vista que se abren al iniciar. |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | Tabla que se abre al iniciar. |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | Vista que se abre al iniciar. |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | Opciones de diseño del área de trabajo. |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | Muestra la cabecera. |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | Muestra el menú de la cabecera. |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | Muestra el área de contenido principal. |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | Muestra la barra lateral izquierda. |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | Muestra la barra lateral derecha. |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | Acopla el panel derecho o lo superpone al editor. |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

Use `disableEdit` para un área de trabajo de solo lectura. Configure `attachment`, `personOptions` o `groupOptions` únicamente cuando los campos correspondientes necesiten datos de la aplicación host.
