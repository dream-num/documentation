`@univerjs-pro/bases-ui` proporciona la interfaz de usuario del navegador para el banco de trabajo de Bases. Representa la lista de tablas, la lista de vistas, la cuadrícula, el kanban, el calendario, Gantt, la galería, los editores de campos, el panel de detalles de registros, la barra de herramientas, los menús contextuales y el estado de selección.

## Tiempo de ejecución requerido

Un editor de Bases del navegador necesita la interfaz de usuario compartida y los complementos de representación antes que el complemento de la interfaz de usuario de Bases:

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

Registrar los complementos de fórmula antes de Bases cuando se usan campos de fórmula:

```ts
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)
```

## Workbench opciones

`IUniverBaseUIConfig.workbench` controla qué partes del banco de trabajo de Bases son visibles.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
})
```

## Estado inicial

Utilice `initialState` para abrir una tabla específica y ver cuándo se inicia la interfaz de usuario de Base.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```
