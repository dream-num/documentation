`@univerjs-pro/bases-ui` es el banco de trabajo del navegador con licencia para Univer Bases. Representa la navegación de mesa y vista, la red, kanban, calendario, gantt y vistas a la galería, editores de campo, el panel de detalles de registro, menús y estado de selección.

## Registrar el área de trabajo

Registrar la licencia y el motor de fórmulas antes de los plugins Bases. Los campos de Fórmula usan `@univerjs-pro/engine-formula` y no requieren una aplicación de Hojas.

`UniverLicensePlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Descripción |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenido del archivo de licencia del cliente. |

`UniverUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Descripción |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Elemento DOM donde se monta el editor o su ID. |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

Las importaciones, estilos y datos locales se describen en [Instalación &quot; Usage básico](/guides/bases/getting-started/installation).

## Configurar el diseño inicial

`IUniverBaseUIConfig` controla las regiones del banco de trabajo y qué mesa y vista se abren al inicio.

`UniverBasesUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Descripción |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | Desactiva los controles de edición en el banco de trabajo. |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | Tabla y vista que se abren al iniciar. |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | Mesa para mostrar primero. |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | Ver para mostrar primero. |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | Opciones de diseño para el banco de trabajo. |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | Muestra el encabezado. |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | Muestra el menú del encabezado. |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | Muestra el área de contenido principal. |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | Muestra la barra lateral izquierda. |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | Muestra la barra lateral derecha. |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | Coloca el panel derecho en el diseño o flota sobre el editor. |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

Establecer `disableEdit` para construir un banco de trabajo sólo lectura. Pase `attachment`, `personOptions` o `groupOptions` sólo cuando los campos correspondientes de Base requieren valores suministrados por la aplicación host.
