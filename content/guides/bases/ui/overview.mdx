`@univerjs-pro/bases-ui` provides the browser UI for the Bases workbench. It renders the table list, view list, grid, kanban, calendar, gantt, gallery, field editors, record detail panel, toolbar, context menus, and selection state.

## Required runtime

A browser Bases editor needs the shared UI and render plugins before the Bases UI plugin:

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

Register formula plugins before Bases when formula fields are used:

```ts
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)
```

## Workbench options

`IUniverBaseUIConfig.workbench` controls which parts of the Bases workbench are visible.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
})
```

## Initial state

Use `initialState` to open a specific table and view when the Base UI starts.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```
