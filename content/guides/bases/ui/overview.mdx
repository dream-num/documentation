`@univerjs-pro/bases-ui` provides the licensed browser workbench for Univer Bases. It renders the table and view navigation, grid, kanban, calendar, gantt and gallery views, field editors, record detail panel, menus, and selection state.

## Register the workbench

Register the license and formula engines before the Bases plugins. Formula fields use `@univerjs-pro/engine-formula`; they do not require a Sheets application.

`UniverLicensePlugin`

| <span data-config-options="">Option</span> | Type | Default | What it does |
| --- | --- | --- | --- |
| `license` | `string` |  | Client license file contents. |

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Default | What it does |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Mount element or its DOM ID. |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

See [Installation & Basic Usage](/guides/bases/getting-started/installation) for imports, styles, and locale data.

## Configure the initial layout

`IUniverBaseUIConfig` controls the workbench regions and the first table and view shown after startup.

`UniverBasesUIPlugin`

| <span data-config-options="">Option</span> | Type | Default | What it does |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | Disable editing controls in the workbench. |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | Table and view to open at startup. |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | Initial table to show. |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | Initial view to show. |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | Options for the main workbench. |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | Show the header. |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | Shows the header menu. |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | Shows the main content area. |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | Show the left sidebar. |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | Show the right sidebar. |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | Display the right panel in place or over the editor. |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

Use `disableEdit` for a read-only workbench, and use `attachment`, `personOptions`, or `groupOptions` only when the corresponding Base fields need those host-provided values.
