`@univerjs-pro/bases-ui` is the licensed browser workbench for Univer Bases. It renders table and view navigation, the grid, kanban, calendar, gantt, and gallery views, field editors, the record detail panel, menus, and selection state.

## Register the workbench

Register the license and the formula engine before the Bases plugins. Formula fields use `@univerjs-pro/engine-formula` and do not require a Sheets application.

`UniverLicensePlugin`

| <span data-config-options="">Option</span> | Type | Default | Description |
| --- | --- | --- | --- |
| `license` | `string` |  | Contents of the client license file. |

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Default | Description |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | The element to mount the editor into, or its DOM ID. |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

Imports, styles, and locale data are described in [Installation & Basic Usage](/guides/bases/getting-started/installation).

## Configure the initial layout

`IUniverBaseUIConfig` controls which workbench regions appear and which table and view open at startup.

`UniverBasesUIPlugin`

| <span data-config-options="">Option</span> | Type | Default | Description |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | Disables the editing controls in the workbench. |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | Table and view to open at startup. |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | Table to display first. |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | View to display first. |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | Layout options for the workbench. |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | Displays the header. |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | Displays the header menu. |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | Displays the main content area. |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | Displays the left sidebar. |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | Displays the right sidebar. |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | Places the right panel in the layout or floats it over the editor. |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

Set `disableEdit` to build a read-only workbench. Pass `attachment`, `personOptions`, or `groupOptions` only when the corresponding Base fields require values supplied by the host application.
