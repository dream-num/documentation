Bases utiliza el sistema de diseño compartido de Univer y el tema de la aplicación host. El complemento Bases UI se centra en el diseño del banco de trabajo de datos, editores de campos, paneles y representación de vistas.

## Registrar estilos compartidos

Cargar estilos compartidos antes que los estilos Bases UI:

```ts
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/bases-ui/lib/index.css'
```

## Temas de aplicaciones

Utilice los tokens de diseño de la aplicación host y las variables CSS para controlar el fondo de la página, el diseño circundante y la navegación a nivel de shell. Mantenga los colores de registro, seleccione opciones y vea la configuración de color en el campo base o en la configuración de vista para que persistan con la instantánea.

## Colores de campo

Las vistas de selección única, selección múltiple, grupo, calendario y Gantt pueden usar la configuración de campo o vista para representar colores semánticos.
