Bases 使用 Univer 的共享设计系统和宿主应用主题。Bases UI 插件专注于数据工作台布局、字段编辑器、面板和视图渲染。

## 注册共享样式

请先加载共享样式，再加载 Bases UI 样式：

```ts
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/bases-ui/lib/index.css'
```

## 应用主题

使用宿主应用的设计令牌和 CSS 变量来控制页面背景、外围布局和应用外壳层级的导航。记录颜色、选择项和视图颜色设置应保存在 Base 字段或视图配置中，以便随快照持久化。

## 字段颜色

单选、多选、分组、日历和甘特图视图可以通过字段或视图配置来渲染语义化颜色。
