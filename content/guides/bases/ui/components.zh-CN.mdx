`@univerjs-pro/bases-ui` 导出用于构建 Bases 工作台的组件。这些组件在已初始化的 Univer 注入环境中运行，不是独立的设计系统组件。

## 公开的工作台组件

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

该包还导出 `AddViewMenu`、`FilterPanel`、`FormulaEditorPanel` 等专用面板。只有在周围的 Bases 服务和单元上下文可用时，才渲染这些面板。

## 支持的扩展点

- `IBaseViewUIRegistryService` 为一种 Base 视图类型注册 DOM 或画布渲染器。
- `IBaseDashboardUIExtensionRegistryService` 提供一个仪表盘 UI 扩展。
- `IBaseRecordActionService` 添加记录操作，并把当前单元、表、视图和记录提供给每个操作。

每次注册都会返回一个可释放的句柄。宿主插件被移除时释放该句柄，避免失效的操作或渲染器留在工作台里。
