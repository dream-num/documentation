Bases UI 由工作台面板、视图渲染、字段编辑器、记录详情面板和弹出式服务构成。大多数应用通过注册 `UniverBasesUIPlugin` 来使用默认组件。

## 自定义工作台可见区域

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'overlay',
  },
})
```

## 配置附件上传

在生产环境中使用附件字段时，需要由应用提供上传处理程序：

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/png', 'image/jpeg', 'application/pdf'],
    maxSize: 20 * 1024 * 1024,
    async upload(file) {
      const result = await uploadToServer(file)
      return {
        id: result.id,
        name: file.name,
        url: result.url,
        size: file.size,
        mimeType: file.type,
      }
    },
  },
})
```

## 人员和群组选项

提供人员和群组列表，供人员和群组字段编辑器使用。

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  personOptions: [{ id: 'u1', name: 'Ada Lovelace' }],
  groupOptions: [{ id: 'g1', name: 'Product' }],
})
```
