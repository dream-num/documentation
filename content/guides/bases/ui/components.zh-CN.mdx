`@univerjs-pro/bases-ui` 导出 Bases 工作台使用的组件。这些组件需要在已初始化的 Univer 依赖注入环境中运行，不是独立的设计系统组件。

## 公开的工作台组件

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

该包还导出 `AddViewMenu`、`FilterPanel` 和 `FormulaEditorPanel` 等专用面板。只有在周围的 Bases 服务和单元上下文可用时才渲染它们。

## 支持的扩展点

- `IBaseViewUIRegistryService` 为 Base 视图类型注册 DOM 或画布渲染器。
- `IBaseDashboardUIExtensionRegistryService` 提供一个仪表盘 UI 扩展。
- `IBaseRecordActionService` 添加带当前单元、表、视图和记录上下文的记录操作。

每次注册都会返回可释放句柄。主插件移除时请释放它，避免工作台残留失效的操作或渲染器。
