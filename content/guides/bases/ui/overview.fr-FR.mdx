`@univerjs-pro/bases-ui` est l'atelier de navigation de navigateur autorisé pour les bases Univer. Il rend la navigation de table et de vue, la grille, kanban, calendrier, gantt, et les vues de galerie, les éditeurs de champs, le panneau de détails d'enregistrement, les menus et l'état de sélection.

## Enregistrer l’espace de travail

Enregistrez la licence et le moteur de la formule avant les plugins Bases. Les champs Formule utilisent `@univerjs-pro/engine-formula` et ne nécessitent pas d'application Feuilles.

`UniverLicensePlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Désignation des marchandises |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenu du fichier de licence côté client. |

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Désignation des marchandises |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Élément DOM de montage de l’éditeur ou son identifiant. |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

Les importations, les styles et les données locales sont décrits dans [Installation et utilisation de base](/guides/bases/getting-started/installation).

## Configurer la disposition initiale

`IUniverBaseUIConfig` contrôle quelles sont les régions de workbench qui apparaissent et quelle table et quelle vue s'ouvrent au démarrage.

`UniverBasesUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Désignation des marchandises |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | Désactive les contrôles d'édition dans le banc de travail. |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | Table et vue à ouvrir au démarrage. |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | Table à afficher en premier. |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | Affichage à afficher en premier. |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | Options de mise en page pour l'atelier. |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | Affiche l'en-tête. |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | Affiche le menu d'en-tête. |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | Affiche la zone de contenu principale. |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | Affiche la barre latérale gauche. |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | Affiche la barre latérale droite. |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | Place le panneau droit dans la mise en page ou le flotte sur l'éditeur. |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

Définissez `disableEdit` pour construire un workbench en lecture seule. Passez `attachment`, `personOptions` ou `groupOptions` uniquement lorsque les champs de base correspondants nécessitent des valeurs fournies par l'application hôte.
