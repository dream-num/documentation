`@univerjs-pro/bases-ui` fournit l’interface utilisateur dans le navigateur pour l’espace de travail Bases. Il affiche la liste des tables, la liste des vues, la grille, le kanban, le calendrier, le diagramme de Gantt, la galerie, les éditeurs de champs, le panneau de détail des enregistrements, la barre d’outils, les menus contextuels et l’état de la sélection.

## Environnement d’exécution requis

Un éditeur Bases dans le navigateur nécessite les plugins partagés d’interface utilisateur et de rendu avant le plugin Bases UI :

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

Lorsque des champs de formule sont utilisés, enregistrez les plugins de formule avant Bases :

```ts
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)
```

## Options de l’espace de travail

`IUniverBaseUIConfig.workbench` détermine les parties visibles de l’espace de travail Bases.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
})
```

## État initial

Utilisez `initialState` pour ouvrir une table et une vue précises au démarrage de l’interface utilisateur de Bases.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```
