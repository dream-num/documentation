`@univerjs-pro/bases-ui` fournit l’espace de travail sous licence de Univer Bases dans le navigateur. Il affiche la navigation des tables et des vues, les vues grille, kanban, calendrier, Gantt et galerie, ainsi que les éditeurs de champs, les détails d’enregistrement, les menus et la sélection.

## Enregistrer l’espace de travail

Enregistrez la licence et les moteurs de formule avant les plugins Bases. Les champs de formule utilisent `@univerjs-pro/engine-formula` ; aucune application Sheets n’est requise.

`UniverLicensePlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenu du fichier de licence client. |

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Élément DOM où monter l’éditeur, ou son identifiant. |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

Consultez [Installation et utilisation de base](/guides/bases/getting-started/installation) pour les imports, les styles et les langues.

## Configurer la disposition initiale

`IUniverBaseUIConfig` contrôle les zones de l’espace de travail ainsi que la première table et la première vue affichées.

`UniverBasesUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | Désactive les commandes d’édition de l’espace de travail. |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | Table et vue à ouvrir au démarrage. |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | Table ouverte au démarrage. |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | Vue ouverte au démarrage. |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | Options de disposition de l’espace de travail. |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | Affiche l’en-tête. |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | Affiche le menu de l’en-tête. |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | Affiche la zone de contenu principale. |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | Affiche la barre latérale gauche. |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | Affiche la barre latérale droite. |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | Intègre le panneau droit à la disposition ou le superpose à l’éditeur. |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

Utilisez `disableEdit` pour un espace en lecture seule. Configurez `attachment`, `personOptions` ou `groupOptions` uniquement si les champs correspondants utilisent des données fournies par l’application hôte.
