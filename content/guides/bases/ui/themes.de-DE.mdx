Bases verwendet das gemeinsame Univer-Designsystem und das Host-Anwendungsthema. Das Bases-UI-Plugin konzentriert sich auf das Data Workbench-Layout, Feldeditoren, Panels und Ansichtsrendering.

## Gemeinsame Stile registrieren

Gemeinsame Stile vor Bases-UI-Stilen laden:

```ts
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/bases-ui/lib/index.css'
```

## Anwendungsdesign

Verwenden Sie die Design-Tokens und CSS-Variablen der Hostanwendung, um den Seitenhintergrund, das umgebende Layout und die Navigation auf Shell-Ebene zu steuern. Behalten Sie Datensatzfarben, Auswahloptionen und Ansichtsfarbeinstellungen in der Basisfeld- oder Ansichtskonfiguration bei, damit sie im Snapshot erhalten bleiben.

## Feldfarben

Einzelauswahl-, Mehrfachauswahl-, Gruppen-, Kalender- und Gantt-Ansichten können Feld- oder Ansichtskonfigurationen verwenden, um semantische Farben darzustellen.
