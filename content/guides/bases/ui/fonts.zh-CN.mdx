Bases 不提供产品专用的字体注册表，也不支持为单条记录设置字体样式。画布视图和单元格编辑器使用内部字体栈 `Arial, "Microsoft YaHei", sans-serif`，以保证文本测量和编辑结果一致。

## 可设置的内容

- Univer 通用外壳组件跟随宿主主题和 UI 样式。
- 字段配置决定值的格式，包括数字、货币、评分、进度和日期。
- 选项颜色和视图颜色属于 Base 数据，不是字体设置。

不要使用 Sheets 的 preset 或 `customFontFamily` 示例来配置 Bases 画布。如果宿主页面在工作台周围使用 Web 字体，应先加载字体再挂载 Univer，以避免外围 UI 出现布局偏移。
