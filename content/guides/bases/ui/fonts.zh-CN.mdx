## 字体结构定义

在 Univer 中，字体使用 `IFontConfig` 接口进行定义：

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `value` | `string` | 字体的唯一标识符，通常也是 CSS font-family 的首选值。 |
| `label` | `string` | 用于国际化的翻译键，如果在 Univer 实例创建时没有指定该键值时，则直接显示传入值。|
| `category` | `'sans-serif' \| 'serif' \| 'monospace' \| 'display' \| 'handwriting'` | 字体类别，用于 UI 分组（可选）。 |

<Callout>
  Univer 不会阻止用户选择未安装的字体，如果客户端没有安装某个字体，浏览器会直接使用默认字体进行替代显示。
</Callout>

## 使用自定义字体

你可以通过为 `UniverSheetsCorePreset`（预设模式）或 `UniverUIPlugin`（插件模式）配置 `customFontFamily` 参数来定义字体下拉菜单中的选项。

<Tabs items={['预设模式', '插件模式']}>
  <Tab>
    ```typescript
    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          container: 'app',
          customFontFamily: {
            list: [
              {
                value: 'PingFang SC',
                label: '苹方（简）',
                category: 'sans-serif',
              },
              {
                value: 'Helvetica Neue',
                label: 'Helvetica Neue',
                category: 'sans-serif',
              },
            ],
            // 是否覆盖默认字体列表，默认为 false
            override: true,
          },
        }),
      ],
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
      customFontFamily: {
        list: [
          {
            value: 'PingFang SC',
            label: '苹方（简）',
            category: 'sans-serif',
          },
          {
            value: 'Helvetica Neue',
            label: 'Helvetica Neue',
            category: 'sans-serif',
          },
        ],
        // 是否覆盖默认字体列表，默认为 false
        override: true,
      },
    })
    ```
  </Tab>
</Tabs>

### Facade API

除了在初始化时配置，你还可以通过 Facade API 在运行时动态注册新的字体。这在需要异步加载字体资源的场景下非常有用。

```typescript
univerAPI.addFonts([{
  value: 'PingFang SC',
  label: '苹方（简）',
  category: 'sans-serif',
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: 'sans-serif',
}])
```


Bases 的表格文本、字段编辑器、菜单和面板使用 Univer UI 的共享字体处理流程。请在渲染 Bases 前由宿主应用加载 Web 字体，以避免布局偏移。

## 宿主字体设置

```css
:root {
  font-family: Inter, system-ui, sans-serif;
}
```

## 单元格文本

网格、看板、日历、甘特图和画廊视图中显示的文本来自字段值及对应字段的格式化器。数字、货币、进度、评分和日期应通过字段配置进行格式化，而不要直接设置记录中原始文本的样式。
