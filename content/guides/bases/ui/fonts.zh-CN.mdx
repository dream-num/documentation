Bases 没有品类专属的字体注册表，也不支持给单条记录设置字体样式。画布视图和单元格编辑器使用内部字体栈 `Arial, "Microsoft YaHei", sans-serif`，以保持文本测量与编辑状态一致。

## 可设置的内容

- Univer 通用外壳组件遵循主应用的主题与 UI 样式。
- Base 字段配置负责数字、货币、评分、进度和日期等值格式。
- 选项颜色和视图颜色属于 Base 数据，不是字体设置。

不要用 Sheets preset 或 `customFontFamily` 示例配置 Bases 画布。如果主页面在工作台周围使用 Web 字体，请在挂载 Univer 前加载字体，避免外围 UI 发生布局偏移。
