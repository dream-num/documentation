Bases 的表格文本、字段编辑器、菜单和面板使用 Univer UI 的共享字体处理流程。请在渲染 Bases 前由宿主应用加载 Web 字体，以避免布局偏移。

## 宿主字体设置

```css
:root {
  font-family: Inter, system-ui, sans-serif;
}
```

## 单元格文本

网格、看板、日历、甘特图和画廊视图中显示的文本来自字段值及对应字段的格式化器。数字、货币、进度、评分和日期应通过字段配置进行格式化，而不要直接设置记录中原始文本的样式。
