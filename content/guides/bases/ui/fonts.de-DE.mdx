Bases verwendet die gemeinsame Univer UI-Schriftartenpipeline für Tabellentext, Feldeditoren, Menüs und Bedienfelder. Laden Sie Web-Schriftarten in der Host-Anwendung, bevor Sie Bases rendern, um Layoutverschiebungen zu vermeiden.

## Host-Schriftart einrichten

```css
:root {
  font-family: Inter, system-ui, sans-serif;
}
```

## Zellentext

In Raster-, Kanban-, Kalender-, Gantt- und Galerieansichten gerenderter Text stammt aus Feldwerten und feldspezifischen Formatierern. Verwenden Sie die Feldkonfiguration für die Zahlen-, Währungs-, Fortschritts-, Bewertungs- und Datumsformatierung, anstatt Rohtext in Datensätzen zu formatieren.
