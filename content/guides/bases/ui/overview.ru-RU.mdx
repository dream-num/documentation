`@univerjs-pro/bases-ui` предоставляет лицензируемое браузерное рабочее пространство Univer Bases. Оно отображает навигацию по таблицам и представлениям, сетку, канбан, календарь, диаграмму Ганта и галерею, а также редакторы полей, панель записи, меню и состояние выделения.

## Регистрация рабочего пространства

Зарегистрируйте лицензию и движки формул до плагинов Bases. Поля формул используют `@univerjs-pro/engine-formula`; приложение Sheets не требуется.

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое клиентского файла лицензии. |

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для редактора или его идентификатор. |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

Импорты, стили и локали приведены в разделе [Установка и основы использования](/guides/bases/getting-started/installation).

## Начальная компоновка

`IUniverBaseUIConfig` управляет областями рабочего пространства и первой отображаемой таблицей и представлением.

`UniverBasesUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | Отключает инструменты редактирования в рабочей области. |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | Таблица и представление при запуске. |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | Таблица, которая открывается при запуске. |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | Представление, которое открывается при запуске. |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | Параметры компоновки рабочей области. |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | Показывает заголовок. |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | Показывает меню в шапке. |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | Показывает основную область содержимого. |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | Показывает левую панель. |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | Показывает правую панель. |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | Закрепляет правую панель или размещает её поверх редактора. |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

Для режима только для чтения используйте `disableEdit`. Настраивайте `attachment`, `personOptions` и `groupOptions` только для полей, которым нужны данные хоста.
