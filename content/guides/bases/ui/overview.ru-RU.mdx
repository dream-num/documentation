## Система дизайна

Система дизайна Univer построена на Tailwind CSS и содержит набор дизайн-токенов, которые повторно используются движком отрисовки. Это обеспечивает единообразие стилей между движком отрисовки и слоем представления. Чтобы настроить стили приложения, можно изменить эти токены, хранящиеся в пакете `@univerjs/themes`.



## Компоненты

Univer использует компоненты React для построения слоя представления, поэтому разработчикам, которые также работают с React, очень просто использовать компоненты Univer или регистрировать собственные. При этом пользовательские компоненты не обязательно создавать только на React: Univer поддерживает и другие технологии, например Vue версии 3.x и Web Components.

Все базовые компоненты находятся в пакете `@univerjs/design`, а компоненты значков — в пакете `@univerjs/icons`. Их также можно использовать независимо от Univer.

Пользовательские компоненты часто применяются в следующих случаях:

- Добавление пользовательских кнопок в Ribbon / Context Menu
- Интеграция пользовательских компонентов в Sidebar / Popup и другие элементы
- Замена встроенных компонентов

В следующих главах подробно описано, как регистрировать и использовать пользовательские компоненты.


`@univerjs-pro/bases-ui` предоставляет браузерный интерфейс рабочего пространства Bases. В нём отображаются списки таблиц и представлений, сетка, канбан-доска, календарь, диаграмма Ганта, галерея, редакторы полей, панель сведений о записи, панель инструментов, контекстные меню и состояние выделения.

## Необходимые компоненты среды выполнения

Для работы редактора Bases в браузере перед плагином интерфейса Bases необходимо зарегистрировать общие плагины интерфейса и отрисовки:

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

Если используются поля с формулами, зарегистрируйте плагины формул перед Bases:

```ts
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)
```

## Параметры рабочего пространства

`IUniverBaseUIConfig.workbench` определяет, какие части рабочего пространства Bases будут видны.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
})
```

## Начальное состояние

Используйте `initialState`, чтобы при запуске интерфейса Base открыть определённую таблицу и представление.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```
