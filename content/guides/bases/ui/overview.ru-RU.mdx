`@univerjs-pro/bases-ui` предоставляет лицензируемое браузерное рабочее пространство Univer Bases. Оно отображает навигацию по таблицам и представлениям, сетку, канбан, календарь, диаграмму Ганта и галерею, а также редакторы полей, панель записи, меню и состояние выделения.

## Регистрация рабочего пространства

Зарегистрируйте лицензию Pro и движки формул до плагинов Bases. Поля формул используют `@univerjs-pro/engine-formula`; приложение Sheets не требуется.

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

Импорты, стили и локали приведены в разделе [Установка и основы использования](/guides/bases/getting-started/installation).

## Начальная компоновка

`IUniverBaseUIConfig` управляет областями рабочего пространства и первой отображаемой таблицей и представлением.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

Для режима только для чтения используйте `disableEdit`. Настраивайте `attachment`, `personOptions` и `groupOptions` только для полей, которым нужны данные хоста.
