`@univerjs-pro/bases-ui` - это лицензированный рабочий стол браузера для баз Univer. Он отображает навигацию по таблице и просмотру, сетку, канбан, календарь, гант и галерею, полевые редакторы, панель деталей записи, меню и состояние выбора.

## Регистрация рабочего пространства

Зарегистрируйте лицензию и движок формулы перед плагинами Bases.Поля формул используют `@univerjs-pro/engine-formula` и не требуют приложения Sheets.

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое файла клиентской лицензии. |

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для размещения редактора или его идентификатор. |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

Импорт, стили и данные о местоположении описаны в [Установка и базовое использование](/guides/bases/getting-started/installation).

## Начальная компоновка

`IUniverBaseUIConfig` контролирует, какие области рабочих столов появляются, а какие таблицы и вид открыты при запуске.

`UniverBasesUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | Отключает элементы управления редактированием в рабочем столе. |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | Таблица и представление при запуске. |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | Таблица для отображения первой. |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | Посмотреть сначала. |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | Варианты оформления рабочего стола. |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | Отображает заголовок. |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | Отображает меню заголовка. |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | Отображает основную область контента. |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | Отображает левую боковую панель. |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | Отображает правую боковую панель. |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | Помещает правильную панель в макет или плавает над редактором. |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

Установите `disableEdit` для создания рабочего стола только для чтения.Проходите `attachment`, `personOptions` или `groupOptions` только тогда, когда соответствующие поля Базы требуют значений, предоставляемых хост-приложением.
