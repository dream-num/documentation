Bases UI は、ワークベンチパネル、レンダリングされたビュー、フィールドエディター、レコード詳細パネル、ポップアップサービスで構成されています。ほとんどのアプリケーションでは、`UniverBasesUIPlugin` を登録してデフォルトのコンポーネントを使用します。

## ワークベンチの表示をカスタマイズする

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'overlay',
  },
})
```

## 添付ファイルのアップロードを設定する

本番環境で添付ファイルフィールドを使用するには、アプリケーション側のアップロードハンドラーが必要です。

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/png', 'image/jpeg', 'application/pdf'],
    maxSize: 20 * 1024 * 1024,
    async upload(file) {
      const result = await uploadToServer(file)
      return {
        id: result.id,
        name: file.name,
        url: result.url,
        size: file.size,
        mimeType: file.type,
      }
    },
  },
})
```

## ユーザーとグループの選択肢

ユーザーおよびグループのフィールドエディターで使用する、ユーザーとグループのリストを指定します。

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  personOptions: [
    { id: 'u1', name: 'Ada Lovelace' },
  ],
  groupOptions: [
    { id: 'g1', name: 'Product' },
  ],
})
```
