`@univerjs-pro/bases-ui`は、ベースワークベンチを作成するために使用されるコンポーネントをエクスポートします。 彼らは初期化されたUniverインジェクター内で実行され、スタンドアローン設計システムウィジェットではありません。

## 公開コンポーネント

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

パッケージはまた、`AddViewMenu`、`FilterPanel`および`FormulaEditorPanel`のような専門にされたパネルを輸出します。 周囲のベースサービスとユニットのコンテキストが利用可能であるときだけこれらのパネルをレンダリングします。

## 対応する拡張ポイント

- `IBaseViewUIRegistryService` はビュー種別に DOM またはキャンバスレンダラーを登録します。
- `IBaseDashboardUIExtensionRegistryService`は単一のダッシュボードUIの延長を供給します。
- `IBaseRecordActionService`は、レコードのアクションを追加し、各アクションを現在のユニット、テーブル、ビュー、レコードで供給します。

各登録は使い捨てハンドルを返します。 ホストプラグインが削除されると、アクションやレンダラーがワークベンチに残らないため、ハンドルを消します。
