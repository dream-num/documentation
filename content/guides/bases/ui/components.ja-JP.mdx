`@univerjs-pro/bases-ui` は Bases ワークベンチで使用するコンポーネントを公開します。これらは初期化済みの Univer インジェクター内で動作し、単独のデザインシステム部品ではありません。

## 公開コンポーネント

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

`AddViewMenu`、`FilterPanel`、`FormulaEditorPanel` などの専用パネルも公開されています。周囲の Bases サービスとユニットコンテキストが利用できる場合だけ描画してください。

## 対応する拡張ポイント

- `IBaseViewUIRegistryService` はビュー種別に DOM またはキャンバスレンダラーを登録します。
- `IBaseDashboardUIExtensionRegistryService` は 1 つのダッシュボード UI 拡張を提供します。
- `IBaseRecordActionService` は現在のユニット、テーブル、ビュー、レコードのコンテキストを持つ操作を追加します。

各登録は破棄可能なハンドルを返します。ホストプラグインを削除するときに破棄してください。
