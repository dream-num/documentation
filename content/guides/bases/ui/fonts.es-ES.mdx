Las bases no proporcionan un registro de fuentes específico de producto, y no admite estilos de fuente por disco. Las vistas de los lienzos y los editores de las celdas utilizan la pila de fuentes interna `Arial, "Microsoft YaHei", sans-serif`, que mantiene alineada la medición y edición de texto.

## Qué se puede configurar

- Los componentes compartidos de Univer siguen el tema y los estilos UI de la aplicación host.
- La configuración de campo determina el formato de valor, incluyendo números, moneda, calificación, progreso y fechas.
- Los colores de opción y los colores de vista pertenecen a los datos Base y no son ajustes de fuentes.

No utilice un preset de Hojas o un ejemplo `customFontFamily` para configurar el lienzo Bases. Si la página de host utiliza fuentes web alrededor del banco de trabajo, carguelas antes de montar Univer de modo que la interfaz de usuario circundante no cambie.
