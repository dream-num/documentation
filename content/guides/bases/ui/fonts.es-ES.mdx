## Definición de estructura de fuentes

En Univer, las fuentes se definen usando la interfaz `IFontConfig`:

| Propiedad | Tipo | Descripción |
| --- | --- | --- |
| `value` | `string` | El identificador único de la fuente, normalmente el valor preferido para la familia de fuentes CSS. |
| `label` | `string` | La clave de traducción para la internacionalización. Si esta clave no se especifica cuando se crea la instancia de Univer, el valor pasado se muestra directamente. |
| `category` | `'sans-serif' \| 'serif' \| 'monospace' \| 'display' \| 'handwriting'` | Categoría de fuente, utilizada para agrupar la interfaz de usuario (opcional). |

<Callout>
Univer no impide que los usuarios seleccionen fuentes desinstaladas. Si una fuente no está instalada en el cliente, el navegador la sustituirá por la fuente predeterminada.
</Callout>

## Uso de fuentes personalizadas

Puede definir las opciones en el menú desplegable de fuentes configurando el parámetro `customFontFamily` para `UniverSheetsCorePreset` (modo preestablecido) o `UniverUIPlugin` (modo complemento).

<Tabs items={['Preset Mode', 'Plugin Mode']}>
  <Tab>
    ```typescript
    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          container: 'app',
          customFontFamily: {
            list: [
              {
                value: 'PingFang SC',
                label: '苹方（简）',
                category: 'sans-serif',
              },
              {
                value: 'Helvetica Neue',
                label: 'Helvetica Neue',
                category: 'sans-serif',
              },
            ],
            // Whether to override the default font list, defaults to false
            override: true,
          },
        }),
      ],
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
      customFontFamily: {
        list: [
          {
            value: 'PingFang SC',
            label: '苹方（简）',
            category: 'sans-serif',
          },
          {
            value: 'Helvetica Neue',
            label: 'Helvetica Neue',
            category: 'sans-serif',
          },
        ],
        // Whether to override the default font list, defaults to false
        override: true,
      },
    })
    ```
  </Tab>
</Tabs>

### API de Facade

Además de la configuración durante la inicialización, también puede registrar dinámicamente nuevas fuentes en tiempo de ejecución mediante la API de fachada. Esto es muy útil en escenarios donde los recursos de fuentes deben cargarse de forma asincrónica.

```typescript
univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: 'sans-serif',
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: 'sans-serif',
}])
```


Bases utiliza la canalización de fuentes compartidas de la interfaz de usuario de Univer para texto de tablas, editores de campos, menús y paneles. Cargue fuentes web en la aplicación host antes de renderizar Bases para evitar cambios de diseño.

## Configuración de la fuente host

```css
:root {
  font-family: Inter, system-ui, sans-serif;
}
```

## Texto de celda

El texto representado en vistas de cuadrícula, kanban, calendario, Gantt y galería proviene de valores de campo y formateadores específicos de cada campo. Utilice la configuración de campo para el formato de número, moneda, progreso, calificación y fecha en lugar de aplicar estilo al texto sin formato en los registros.
