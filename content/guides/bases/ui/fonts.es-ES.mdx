Bases no expone un registro de fuentes propio ni estilos de fuente por registro. Las vistas de lienzo y los editores de celdas usan la pila interna `Arial, "Microsoft YaHei", sans-serif` para mantener alineadas la medición y la edición del texto.

## Qué se puede configurar

- Los componentes compartidos de Univer siguen el tema y los estilos UI de la aplicación host.
- La configuración de campos de Base controla formatos como números, moneda, puntuación, progreso y fechas.
- Los colores de opciones y vistas pertenecen a los datos de Base; no son ajustes tipográficos.

No use un preset de Sheets ni un ejemplo de `customFontFamily` para configurar el lienzo de Bases. Si la página host usa fuentes web alrededor del área de trabajo, cárguelas antes de montar Univer.
