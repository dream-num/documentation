`@univerjs-pro/bases-ui` は、Bases ワークベンチ用のブラウザー UI を提供します。テーブル一覧、ビュー一覧、グリッド、カンバン、カレンダー、ガントチャート、ギャラリー、フィールドエディター、レコード詳細パネル、ツールバー、コンテキストメニュー、選択状態をレンダリングします。

## 必要なランタイム

ブラウザーで動作する Bases エディターでは、Bases UI プラグインより先に共有 UI プラグインとレンダリングプラグインを登録する必要があります。

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

数式フィールドを使用する場合は、Bases より先に数式プラグインを登録します。

```ts
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)
```

## ワークベンチのオプション

`IUniverBaseUIConfig.workbench` では、Bases ワークベンチに表示する項目を制御できます。

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
})
```

## 初期状態

Base UI の起動時に特定のテーブルとビューを開くには、`initialState` を使用します。

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```
