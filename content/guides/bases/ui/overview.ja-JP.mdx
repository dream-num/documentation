`@univerjs-pro/bases-ui`はUniverの基盤のための認可されたブラウザのworkbenchです。それはテーブルおよび眺めの運行、格子、kanban、カレンダー、ganttおよびギャラリーの眺め、分野の編集者、記録の細部のパネル、メニューおよび選択の状態をレンダリングします。

## ワークベンチを登録する

Basesプラグインの前にライセンスと式エンジンを登録します。式フィールドは`@univerjs-pro/engine-formula`を使用し、シートアプリケーションを必要としません。

`UniverLicensePlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 説明: |
| --- | --- | --- | --- |
| `license` | `string` |  | クライアント用ライセンスファイルの内容。 |

`UniverUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 説明: |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターのマウント先となる DOM 要素、またはその ID。 |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

[インストールと基本的な使い方](/guides/bases/getting-started/installation)では、インポート、スタイル、ローカライズデータが記述されています。

## 初期レイアウトを設定する

`IUniverBaseUIConfig`は、作業域が出現し、起動時にテーブルとビューが開きます。

`UniverBasesUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 説明: |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | ワークベンチの編集制御を無効にします。 |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | 起動時に開くテーブルとビュー。 |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | 最初に表示するテーブル。 |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | 最初に表示するのを見る。 |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | ワークベンチのレイアウトオプション。 |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | ヘッダを表示します。 |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | ヘッダーメニューを表示します。 |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | 主なコンテンツエリアを表示します。 |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | 左側のサイドバーを表示します。 |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | 右側のサイドバーを表示します。 |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | レイアウトの右側のパネルを配置するか、エディタの上にフロートします。 |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

`disableEdit` をセットして、読み取り専用のワークベンチを作成します。 `attachment`、`personOptions`, または `groupOptions`は、対応するベースフィールドがホストアプリケーションによって供給される値を必要とする場合にのみ、 します。
