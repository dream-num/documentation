`@univerjs-pro/bases-ui` は、ライセンスが必要な Univer Bases のブラウザーワークベンチを提供します。テーブルとビューのナビゲーション、グリッド、カンバン、カレンダー、ガント、ギャラリーの各ビュー、フィールドエディター、レコード詳細、メニュー、選択状態を描画します。

## ワークベンチを登録する

Bases プラグインより先に ライセンスと数式エンジンを登録します。数式フィールドは `@univerjs-pro/engine-formula` を使用し、Sheets アプリケーションは必要ありません。

`UniverLicensePlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `license` | `string` |  | クライアントライセンスファイルの内容。 |

`UniverUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターを配置する DOM 要素またはその ID。 |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

インポート、スタイル、ロケールについては[インストールと基本的な使い方](/guides/bases/getting-started/installation)を参照してください。

## 初期レイアウトを設定する

`IUniverBaseUIConfig` はワークベンチの領域と、起動時に表示するテーブルおよびビューを制御します。

`UniverBasesUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | ワークベンチの編集操作を無効にします。 |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | 起動時に開くテーブルとビュー。 |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | 起動時に開くテーブル。 |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | 起動時に開くビュー。 |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | 作業領域のレイアウト設定。 |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | ヘッダーを表示します。 |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | ヘッダーメニューを表示します。 |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | メインコンテンツを表示します。 |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | 左サイドバーを表示します。 |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | 右サイドバーを表示します。 |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | 右パネルを配置するか、エディターに重ねます。 |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

読み取り専用にする場合は `disableEdit` を使用します。対応するフィールドがホスト提供データを必要とする場合だけ、`attachment`、`personOptions`、`groupOptions` を設定してください。
