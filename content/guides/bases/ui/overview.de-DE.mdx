`@univerjs-pro/bases-ui` stellt die Browser-Benutzeroberfläche für die Bases-Workbench bereit. Es rendert die Tabellenliste, Ansichtsliste, Tabelle, Kanban, Kalender, Gantt, Galerie, Feldeditoren, Datensatzdetailfenster, Symbolleiste, Kontextmenüs und Auswahlstatus.

## Erforderliche Laufzeit

Ein Browser-Bases-Editor benötigt die gemeinsame Benutzeroberfläche und Render-Plugins vor dem Bases-UI-Plugin:

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

Registrieren Sie Formel-Plugins vor Bases, wenn Formelfelder verwendet werden:

```ts
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)
```

## Workbench Optionen

`IUniverBaseUIConfig.workbench` steuert, welche Teile der Bases-Workbench sichtbar sind.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
})
```

## Anfangszustand

Verwenden Sie `initialState`, um eine bestimmte Tabelle zu öffnen und anzuzeigen, wenn die Base-Benutzeroberfläche gestartet wird.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```
