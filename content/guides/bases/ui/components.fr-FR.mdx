`@univerjs-pro/bases-ui` exporte les composants utilisés pour construire le banc de travail Bases. Ils fonctionnent à l'intérieur d'un injecteur initialisé Univer et ne sont pas des widgets de conception autonomes.

## Composants publics

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

Le paquet exporte également des panneaux spécialisés tels que `AddViewMenu`, `FilterPanel` et `FormulaEditorPanel`. Renvoyez ces panneaux uniquement lorsque les services de Bases environnants et le contexte de l'unité sont disponibles.

## Points d’extension pris en charge

- `IBaseViewUIRegistryService` enregistre un moteur de rendu DOM ou canevas pour un type de vue.
- `IBaseDashboardUIExtensionRegistryService` fournit une seule extension d'interface utilisateur de tableau de bord.
- `IBaseRecordActionService` ajoute des actions d'enregistrement et fournit chaque action avec l'unité, la table, la vue et l'enregistrement courant.

Chaque enregistrement retourne une poignée jetable. Jetez la poignée lorsque le plugin hôte est retiré de sorte que les actions ou les rendus stales ne restent pas dans l'atelier.
