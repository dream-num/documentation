`@univerjs-pro/bases-ui` exporte les composants de l’espace de travail Bases. Ils doivent s’exécuter dans un injecteur Univer initialisé et ne sont pas des composants autonomes du système de design.

## Composants publics

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

Le package exporte aussi des panneaux spécialisés tels que `AddViewMenu`, `FilterPanel` et `FormulaEditorPanel`. Affichez-les uniquement lorsque les services Bases et le contexte d’unité sont disponibles.

## Points d’extension pris en charge

- `IBaseViewUIRegistryService` enregistre un moteur de rendu DOM ou canevas pour un type de vue.
- `IBaseDashboardUIExtensionRegistryService` fournit une extension de tableau de bord.
- `IBaseRecordActionService` ajoute des actions avec le contexte actuel d’unité, table, vue et enregistrement.

Chaque enregistrement renvoie une ressource jetable. Libérez-la lorsque le plugin hôte est retiré.
