L’interface utilisateur de Bases repose sur des panneaux d’espace de travail, des vues affichées, des éditeurs de champs, des panneaux de détail des enregistrements et des services de fenêtres contextuelles. La plupart des applications utilisent les composants par défaut en enregistrant `UniverBasesUIPlugin`.

## Personnaliser la visibilité de l’espace de travail

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'overlay',
  },
})
```

## Configurer le téléversement des pièces jointes

En production, les champs de pièce jointe nécessitent un gestionnaire de téléversement fourni par l’application :

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/png', 'image/jpeg', 'application/pdf'],
    maxSize: 20 * 1024 * 1024,
    async upload(file) {
      const result = await uploadToServer(file)
      return {
        id: result.id,
        name: file.name,
        url: result.url,
        size: file.size,
        mimeType: file.type,
      }
    },
  },
})
```

## Options relatives aux personnes et aux groupes

Fournissez des listes de personnes et de groupes pour alimenter les éditeurs de champs correspondants.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  personOptions: [
    { id: 'u1', name: 'Ada Lovelace' },
  ],
  groupOptions: [
    { id: 'g1', name: 'Product' },
  ],
})
```
