`@univerjs-pro/bases-ui` экспортирует компоненты, используемые для сборки рабочего стола Bases. Они работают внутри инициализированного инжектора Univer и не являются автономными виджетами системы проектирования.

## Публичные компоненты

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

Пакет также экспортирует специализированные панели, такие как `AddViewMenu`, `FilterPanel` и `FormulaEditorPanel`. Оформляйте эти панели только тогда, когда доступны окружающие сервисы Bases и единичный контекст.

## Поддерживаемые точки расширения

- `IBaseViewUIRegistryService` регистрирует DOM- или canvas-рендерер для типа представления.
- `IBaseDashboardUIExtensionRegistryService` обеспечивает одно расширение пользовательского интерфейса панели инструментов.
- `IBaseRecordActionService` добавляет записи действий и поставляет каждое действие с текущим блоком, таблицей, просмотром и записью.

Каждая регистрация возвращает одноразовую ручку. Удалите ручку, когда плагин хоста удаляется, чтобы устаревшие действия или рендереры не оставались в рабочей строке.
