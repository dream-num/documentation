`@univerjs-pro/bases-ui` экспортирует компоненты рабочего пространства Bases. Они работают внутри инициализированного инжектора Univer и не являются автономными элементами дизайн-системы.

## Публичные компоненты

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

Пакет также экспортирует специализированные панели `AddViewMenu`, `FilterPanel` и `FormulaEditorPanel`. Отображайте их только при наличии сервисов Bases и контекста модуля.

## Поддерживаемые точки расширения

- `IBaseViewUIRegistryService` регистрирует DOM- или canvas-рендерер для типа представления.
- `IBaseDashboardUIExtensionRegistryService` предоставляет одно расширение интерфейса панели.
- `IBaseRecordActionService` добавляет действия с контекстом текущего модуля, таблицы, представления и записи.

Каждая регистрация возвращает освобождаемый дескриптор. Освобождайте его при удалении плагина хоста.
