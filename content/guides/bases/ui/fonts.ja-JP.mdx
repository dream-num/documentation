Bases は製品固有のフォントレジストリやレコード単位のフォントスタイルを公開していません。キャンバスビューとセルエディターは、文字の計測と編集を一致させるために内部スタック `Arial, "Microsoft YaHei", sans-serif` を使用します。

## 設定できる内容

- Univer 共通シェルのコンポーネントは、ホストのテーマと UI スタイルに従います。
- Base のフィールド設定は、数値、通貨、評価、進捗、日付などの表示形式を制御します。
- 選択肢やビューの色は Base データであり、フォント設定ではありません。

Bases キャンバスの設定に Sheets preset や `customFontFamily` の例を使用しないでください。ホストページがワークベンチ周辺で Web フォントを使う場合は、Univer のマウント前に読み込みます。
