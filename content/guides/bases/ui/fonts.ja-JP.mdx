ベースは製品固有のフォントレジストリを提供しず、レコードフォントスタイルごとにサポートしません。 キャンバスビューとセルエディタは、テキスト測定と編集の整列を保つ内部フォントスタック`Arial, "Microsoft YaHei", sans-serif`を使用します。

## 設定できる内容

- Univer 共通シェルのコンポーネントは、ホストのテーマと UI スタイルに従います。
- フィールド構成は、数値、通貨、評価、進捗状況、日付を含む値のフォーマットを決定します。
- オプションの色と色はベースデータに属しており、フォント設定ではありません。

Bases のキャンバスを構成するために、スプレッドシートプリセットや `customFontFamily` の例を使用しないでください。ホストページがワークベンチの周りの Web フォントを使用している場合は、周囲の UI がシフトしないように Univerをマウントする前に読み込みます。
