`@univerjs-pro/bases-ui` 提供 Univer Bases 的授权版浏览器工作台。它负责渲染表与视图导航、网格、看板、日历、甘特图和画廊视图，以及字段编辑器、记录详情面板、菜单和选区状态。

## 注册工作台

请在 Bases 插件前注册 许可证与公式引擎。公式字段使用 `@univerjs-pro/engine-formula`，不要求应用同时使用 Sheets。

`UniverLicensePlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 客户端许可证文件的内容。 |

`UniverUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 编辑器挂载的 DOM 元素或元素 ID。 |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

导入、样式和语言包配置请参阅[安装和基本使用](/guides/bases/getting-started/installation)。

## 配置初始布局

`IUniverBaseUIConfig` 控制工作台区域，以及启动后首先显示的表和视图。

`UniverBasesUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | 禁用工作台的编辑控件。 |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | 启动时打开的表和视图。 |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | 启动时打开的数据表。 |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | 启动时打开的视图。 |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | 工作台布局选项。 |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | 显示顶部区域。 |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | 显示顶部菜单。 |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | 显示主内容区。 |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | 显示左侧栏。 |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | 显示右侧栏。 |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | 设置右侧面板是嵌在布局中还是浮在内容上方。 |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

只读工作台可设置 `disableEdit`。只有对应 Base 字段需要主应用提供数据时，才配置 `attachment`、`personOptions` 或 `groupOptions`。
