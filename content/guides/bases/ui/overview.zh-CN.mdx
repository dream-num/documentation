`@univerjs-pro/bases-ui` 为 Bases 工作台提供浏览器端 UI。它负责渲染表列表、视图列表、网格、看板、日历、甘特图、画廊、字段编辑器、记录详情面板、工具栏、上下文菜单和选中状态。

## 必需的运行时组件

浏览器端 Bases 编辑器需要先注册共享 UI 插件和渲染插件，再注册 Bases UI 插件：

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

使用公式字段时，请先注册公式插件，再注册 Bases：

```ts
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)
```

## 工作台选项

`IUniverBaseUIConfig.workbench` 控制 Bases 工作台中哪些部分可见。

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
})
```

## 初始状态

使用 `initialState`，可在 Base UI 启动时打开指定的表和视图。

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```
