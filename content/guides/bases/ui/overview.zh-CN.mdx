`@univerjs-pro/bases-ui` 是 Univer Bases 的授权浏览器工作台。它负责渲染表和视图导航、网格、看板、日历、甘特图和画廊视图，以及字段编辑器、记录详情面板、菜单和选区状态。

## 注册工作台

许可证和公式引擎都需要在 Bases 插件之前注册。公式字段使用 `@univerjs-pro/engine-formula`，不需要 Sheets 应用。

`UniverLicensePlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `license` | `string` |  | 客户端许可证文件的内容。 |

`UniverUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 编辑器挂载的元素，或该元素的 DOM ID。 |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

导入、样式和语言包数据见[安装和基本使用](/guides/bases/getting-started/installation)。

## 配置初始布局

`IUniverBaseUIConfig` 控制工作台显示哪些区域，以及启动时打开哪张表和哪个视图。

`UniverBasesUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | 关闭工作台中的编辑控件。 |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | 启动时打开的表和视图。 |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | 启动时优先显示的表。 |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | 启动时优先显示的视图。 |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | 工作台的布局选项。 |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | 显示顶部栏。 |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | 显示顶部菜单。 |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | 显示主内容区。 |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | 显示左侧栏。 |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | 显示右侧栏。 |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | 右侧面板嵌入布局中，或覆盖在编辑器上方。 |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

设置 `disableEdit` 可构建只读工作台。只应在对应的 Base 字段需要宿主应用提供值时，传入 `attachment`、`personOptions` 或 `groupOptions`。
