Bases utilise le système de design partagé d’Univer et le thème de l’application hôte. Le plugin Bases UI se concentre sur la disposition de l’espace de travail des données, les éditeurs de champs, les panneaux et le rendu des vues.

## Enregistrer les styles partagés

Chargez les styles partagés avant ceux de Bases UI :

```ts
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/bases-ui/lib/index.css'
```

## Thème de l’application

Utilisez les design tokens et les variables CSS de l’application hôte pour contrôler l’arrière-plan de la page, la disposition environnante et la navigation au niveau de l’interface principale. Conservez les couleurs des enregistrements, les options de sélection et les paramètres de couleur des vues dans la configuration des champs ou des vues de la Base afin qu’ils persistent avec l’instantané.

## Couleurs des champs

Les vues à sélection unique, à sélection multiple, de groupe, de calendrier et de diagramme de Gantt peuvent utiliser la configuration du champ ou de la vue pour afficher des couleurs sémantiques.
