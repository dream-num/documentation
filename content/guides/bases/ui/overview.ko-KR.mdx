## 아키텍처

Univer의 UI 기반은 다음 다이어그램을 바탕으로 설계되었습니다.

<UIArchitecture />

서로 다른 플러그인을 조합해 기반에 다양한 기능과 뷰를 추가하고, 최종적으로 완전한 애플리케이션을 구성합니다.

## 디자인 시스템

Univer의 디자인 시스템은 Tailwind CSS를 기반으로 구축되며, 렌더링 엔진에서 재사용하는 일련의 디자인 토큰을 만들어 렌더링 엔진과 뷰 계층의 스타일을 일관되게 유지합니다. `@univerjs/themes` 패키지에 저장된 이 토큰을 수정해 애플리케이션의 스타일을 맞춤 설정할 수 있습니다.



## 컴포넌트

Univer는 React 컴포넌트로 뷰 계층을 구성합니다. 따라서 React를 사용하는 개발자는 Univer의 컴포넌트를 사용하거나 사용자 지정 컴포넌트를 매우 쉽게 등록할 수 있습니다. 그렇다고 사용자 지정 컴포넌트를 React로만 만들 수 있는 것은 아닙니다. Univer는 Vue(3.x 버전), Web Components 등의 다른 프레임워크도 지원합니다.

모든 기본 컴포넌트는 `@univerjs/design` 패키지에, 아이콘 컴포넌트는 `@univerjs/icons` 패키지에 들어 있습니다. 이 컴포넌트들은 Univer와 별개로 사용할 수도 있습니다.

사용자 지정 컴포넌트는 주로 다음과 같은 경우에 사용합니다.

- Ribbon / Context Menu에 사용자 지정 버튼 추가
- Sidebar / Popup 등에 사용자 지정 컴포넌트 통합
- 기본 제공 컴포넌트 교체

이어지는 장에서 사용자 지정 컴포넌트를 등록하고 사용하는 방법을 자세히 설명합니다.


`@univerjs-pro/bases-ui`는 Bases 워크벤치용 브라우저 UI를 제공합니다. 테이블 목록, 뷰 목록, 그리드, 칸반, 캘린더, 간트, 갤러리, 필드 편집기, 레코드 세부 정보 패널, 도구 모음, 컨텍스트 메뉴, 선택 상태를 렌더링합니다.

## 필수 런타임

브라우저용 Bases 편집기에서는 Bases UI 플러그인보다 먼저 공유 UI 및 렌더링 플러그인을 등록해야 합니다.

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

수식 필드를 사용할 때는 Bases보다 먼저 수식 플러그인을 등록합니다.

```ts
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)
```

## 워크벤치 옵션

`IUniverBaseUIConfig.workbench`는 Bases 워크벤치에서 표시할 부분을 제어합니다.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
})
```

## 초기 상태

Base UI가 시작될 때 특정 테이블과 뷰를 열려면 `initialState`를 사용합니다.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```
