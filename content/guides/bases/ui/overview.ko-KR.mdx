`@univerjs-pro/bases-ui`는 Univer Bases의 라이센스 브라우저 워크 벤치입니다. 테이블과 뷰 네비게이션, 그리드, kanban, 캘린더, gantt 및 갤러리 레이아웃, 필드 편집기, 레코드 세부 사항 패널, 메뉴 및 선택 상태입니다.

## 워크벤치 등록

Bases 플러그인 전에 라이센스 및 공식 엔진을 등록하십시오. 공식 필드는 `@univerjs-pro/engine-formula`를 사용하며 시트 응용 프로그램을 필요로하지 않습니다.

`UniverLicensePlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 제품 설명 |
| --- | --- | --- | --- |
| `license` | `string` |  | 클라이언트 라이선스 파일의 내용입니다. |

`UniverUIPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 제품 설명 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 편집기를 마운트할 DOM 요소 또는 해당 요소의 ID입니다. |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

수입, 스타일 및 로컬 데이터는 [설치 및 기본 사용](/guides/bases/getting-started/installation)에 설명됩니다.

## 초기 레이아웃 구성

`IUniverBaseUIConfig`는 작업대 지구가 나타나는 것을 통제하고 시작에 테이블과 전망이 열립니다.

`UniverBasesUIPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 제품 설명 |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | workbench에서 편집 컨트롤을 비활성화합니다. |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | 시작할 때 열 테이블과 보기입니다. |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | 첫째로 표시하는 테이블. |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | 첫 번째 표시보기. |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | workbench에 대한 레이아웃 옵션. |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | 헤더를 표시합니다. |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | 헤더 메뉴를 표시합니다. |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | 주요 콘텐츠 영역 표시. |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | 왼쪽 사이드바를 표시합니다. |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | 오른쪽 사이드바를 표시합니다. |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | 레이아웃에 올바른 패널을 배치하거나 편집기 위에 플로트. |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

`disableEdit` 를 설정하여 읽기 전용 워크 벤치를 구축하십시오. `attachment`, `personOptions` 또는 `groupOptions`를 활성화하면 해당 기본 필드가 호스트 응용 프로그램에 의해 공급되는 값을 요구합니다.
