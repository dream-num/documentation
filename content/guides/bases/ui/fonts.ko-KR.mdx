Bases는 테이블 텍스트, 필드 편집기, 메뉴, 패널에 공유 Univer UI 글꼴 파이프라인을 사용합니다. 레이아웃 이동을 방지하려면 Bases를 렌더링하기 전에 호스트 애플리케이션에서 웹 글꼴을 불러오세요.

## 호스트 글꼴 설정

```css
:root {
  font-family: Inter, system-ui, sans-serif;
}
```

## 셀 텍스트

그리드, 칸반, 캘린더, 간트, 갤러리 뷰에 렌더링되는 텍스트는 필드 값과 필드별 포매터에서 가져옵니다. 레코드의 원시 텍스트에 스타일을 적용하지 말고 필드 구성을 사용하여 숫자, 통화, 진행률, 평점, 날짜 형식을 지정하세요.
