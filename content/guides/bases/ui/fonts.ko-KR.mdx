Bases는 제품 전용 글꼴 레지스트리나 레코드별 글꼴 스타일을 제공하지 않습니다. 캔버스 뷰와 셀 편집기는 텍스트 측정과 편집을 일치시키기 위해 내부 스택 `Arial, "Microsoft YaHei", sans-serif`를 사용합니다.

## 설정 가능한 항목

- 공통 Univer 셸 컴포넌트는 호스트 테마와 UI 스타일을 따릅니다.
- Base 필드 설정은 숫자, 통화, 평점, 진행률, 날짜 등의 값 형식을 제어합니다.
- 선택 옵션과 뷰 색상은 Base 데이터이며 글꼴 설정이 아닙니다.

Bases 캔버스를 구성할 때 Sheets preset이나 `customFontFamily` 예제를 사용하지 마세요. 호스트 페이지가 워크벤치 주변에서 웹 글꼴을 사용한다면 Univer를 마운트하기 전에 로드하세요.
