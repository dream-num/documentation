Bases는 제품별 폰트 레지스트리를 제공하지 않으며 per-record 글꼴 스타일에 지원하지 않습니다. 캔버스 뷰와 셀 편집기는 내부 폰트 스택 `Arial, "Microsoft YaHei", sans-serif`를 사용하여 텍스트 측정 및 편집 정렬을 유지합니다.

## 설정 가능한 항목

- 공통 Univer 셸 컴포넌트는 호스트 테마와 UI 스타일을 따릅니다.
- 필드 구성은 숫자, 통화, 평가, 진행 및 날짜를 포함하여 값 포맷을 결정합니다.
- 옵션 색상과 색상은 기본 데이터에 속하며 글꼴 설정이 아닙니다.

시트 프리셋 또는 `customFontFamily` 예제를 사용하여 기본 캔버스를 구성하십시오. 호스트 페이지가 작업대 주위에 웹 글꼴을 사용한다면 Univer를 장착하기 전에로드하십시오. 주변 UI가 이동하지 않습니다.
