Bases 使用共用的 Univer 設計系統和宿主應用程式主題。Bases UI 外掛著重於資料工作台版面配置、欄位編輯器、面板和檢視轉譯。

## 註冊共用樣式

請先載入共用樣式，再載入 Bases UI 樣式：

```ts
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/bases-ui/lib/index.css'
```

## 應用程式主題設定

使用宿主應用程式的設計權杖和 CSS 變數，控制頁面背景、周邊版面配置及應用程式外殼層級的導覽。記錄顏色、選取選項和檢視顏色設定應保留在 Base 欄位或檢視設定中，讓這些設定能隨快照一併保存。

## 欄位顏色

單選、多選、群組、行事曆和甘特圖檢視可以使用欄位或檢視設定來呈現語意化色彩。
