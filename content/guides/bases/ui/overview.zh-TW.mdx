`@univerjs-pro/bases-ui` 提供 Univer Bases 的授權版瀏覽器工作台。它負責算繪資料表與檢視導覽、網格、看板、行事曆、甘特圖和圖庫檢視，以及欄位編輯器、記錄詳細資料面板、選單和選取範圍狀態。

## 註冊工作台

請在 Bases 外掛程式前註冊 授權與公式引擎。公式欄位使用 `@univerjs-pro/engine-formula`，不要求應用程式同時使用 Sheets。

`UniverLicensePlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 用戶端授權檔的內容。 |

`UniverUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 編輯器掛載的 DOM 元素或元素 ID。 |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

匯入、樣式和語言套件設定請參閱[安裝與基本使用](/guides/bases/getting-started/installation)。

## 設定初始版面配置

`IUniverBaseUIConfig` 控制工作台區域，以及啟動後首先顯示的資料表和檢視。

`UniverBasesUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | 停用工作台的編輯控制項。 |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | 啟動時開啟的表與檢視。 |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | 啟動時開啟的資料表。 |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | 啟動時開啟的檢視。 |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | 工作台版面選項。 |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | 顯示頂端區域。 |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | 顯示頂部選單。 |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | 顯示主要內容區。 |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | 顯示左側欄。 |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | 顯示右側欄。 |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | 設定右側面板是否占用版面空間。 |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

唯讀工作台可設定 `disableEdit`。只有對應 Base 欄位需要主應用程式提供資料時，才設定 `attachment`、`personOptions` 或 `groupOptions`。
