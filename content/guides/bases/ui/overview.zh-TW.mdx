`@univerjs-pro/bases-ui` 提供 Bases 工作台的瀏覽器 UI。它會呈現資料表清單、檢視清單、網格、看板、行事曆、甘特圖、圖庫、欄位編輯器、記錄詳細資料面板、工具列、內容選單及選取狀態。

## 必要的執行環境

瀏覽器版 Bases 編輯器必須先載入共用 UI 與算繪外掛程式，再載入 Bases UI 外掛程式：

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

使用公式欄位時，請先註冊公式外掛程式，再註冊 Bases：

```ts
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)
```

## 工作台選項

`IUniverBaseUIConfig.workbench` 控制 Bases 工作台中要顯示哪些部分。

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
})
```

## 初始狀態

使用 `initialState`，在 Base UI 啟動時開啟指定的資料表與檢視。

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```
