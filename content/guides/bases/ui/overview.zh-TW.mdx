`@univerjs-pro/bases-ui` 是 Univer Bases 的授權瀏覽器工作臺。它負責渲染表和檢視導航、網格、看板、日曆、甘特圖和畫廊檢視，以及欄位編輯器、記錄詳情面板、選單和選區狀態。

## 註冊工作台

許可證和公式引擎都需要在 Bases 外掛之前註冊。公式欄位使用 `@univerjs-pro/engine-formula`，不需要 Sheets 應用。

`UniverLicensePlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 說明 |
| --- | --- | --- | --- |
| `license` | `string` |  | 用戶端授權檔的內容。 |

`UniverUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 說明 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 編輯器掛載的元素，或該元素的 DOM ID。 |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
```

匯入、樣式和語言套件資料見[安裝和基本使用](/guides/bases/getting-started/installation)。

## 設定初始版面配置

`IUniverBaseUIConfig` 控制工作臺顯示哪些區域，以及啟動時開啟哪張表和哪個檢視。

`UniverBasesUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 說明 |
| --- | --- | --- | --- |
| `disableEdit` | `boolean` |  | 關閉工作臺中的編輯控制元件。 |
| <ConfigKey depth={0}>initialState</ConfigKey> | `object` |  | 啟動時開啟的表與檢視。 |
| <ConfigKey depth={1}>tableId</ConfigKey> | `string \| null` |  | 啟動時優先顯示的表。 |
| <ConfigKey depth={1}>viewId</ConfigKey> | `string \| null` |  | 啟動時優先顯示的檢視。 |
| <ConfigKey depth={0}>workbench</ConfigKey> | `object` |  | 工作臺的版面配置選項。 |
| <ConfigKey depth={1}>header</ConfigKey> | `boolean` | `true` | 顯示頂部欄。 |
| <ConfigKey depth={1}>headerMenu</ConfigKey> | `boolean` | `true` | 顯示頂部選單。 |
| <ConfigKey depth={1}>content</ConfigKey> | `boolean` | `true` | 顯示主要內容區。 |
| <ConfigKey depth={1}>leftSidebar</ConfigKey> | `boolean` | `true` | 顯示左側欄。 |
| <ConfigKey depth={1}>rightSidebar</ConfigKey> | `boolean` | `false` | 顯示右側欄。 |
| <ConfigKey depth={1}>rightPanelMode</ConfigKey> | `'dock' \| 'overlay'` | `'dock'` | 右側面板嵌入版面配置中，或覆蓋在編輯器上方。 |

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'dock',
  },
  initialState: {
    tableId: 'tasks',
    viewId: 'kanban',
  },
})
```

設定 `disableEdit` 可建置只讀工作臺。只應在對應的 Base 欄位需要宿主應用提供值時，傳入 `attachment`、`personOptions` 或 `groupOptions`。
