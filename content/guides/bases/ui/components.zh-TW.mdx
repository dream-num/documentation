`@univerjs-pro/bases-ui` 匯出用於建置 Bases 工作臺的元件。這些元件在已初始化的 Univer 注入環境中執行，不是獨立的設計系統元件。

## 公開的工作台元件

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

該包還匯出 `AddViewMenu`、`FilterPanel`、`FormulaEditorPanel` 等專用面板。只有在周圍的 Bases 服務和單元上下文可用時，才渲染這些面板。

## 支援的擴充點

- `IBaseViewUIRegistryService` 為一種 Base 檢視型別註冊 DOM 或畫布渲染器。
- `IBaseDashboardUIExtensionRegistryService` 提供一個儀表板 UI 擴充功能。
- `IBaseRecordActionService` 新增記錄操作，並把當前單元、表、檢視和記錄提供給每個操作。

每次註冊都會返回一個可釋放的控制代碼。宿主外掛被移除時釋放該控制代碼，避免失效的操作或渲染器留在工作臺裡。
