`@univerjs-pro/bases-ui` 匯出 Bases 工作台使用的元件。這些元件需要在已初始化的 Univer 相依注入環境中執行，不是獨立的設計系統元件。

## 公開的工作台元件

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

此套件也匯出 `AddViewMenu`、`FilterPanel` 和 `FormulaEditorPanel` 等專用面板。只有在周圍的 Bases 服務和單元內容可用時才算繪它們。

## 支援的擴充點

- `IBaseViewUIRegistryService` 為 Base 檢視類型註冊 DOM 或畫布算繪器。
- `IBaseDashboardUIExtensionRegistryService` 提供一個儀表板 UI 擴充功能。
- `IBaseRecordActionService` 加入包含目前單元、資料表、檢視和記錄內容的記錄動作。

每次註冊都會傳回可釋放控制代碼。移除主外掛程式時請釋放它，避免工作台殘留失效的動作或算繪器。
