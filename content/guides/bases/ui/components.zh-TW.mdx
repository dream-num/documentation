Bases UI is built from workbench panels, rendered views, field editors, record detail panels, and popup services. Most applications use the default components by registering `UniverBasesUIPlugin`.

## Customize workbench visibility

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'overlay',
  },
})
```

## Configure attachment uploads

Attachment fields need an application upload handler in production:

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/png', 'image/jpeg', 'application/pdf'],
    maxSize: 20 * 1024 * 1024,
    async upload(file) {
      const result = await uploadToServer(file)
      return {
        id: result.id,
        name: file.name,
        url: result.url,
        size: file.size,
        mimeType: file.type,
      }
    },
  },
})
```

## Person and group options

Provide people and group lists to power person and group field editors.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  personOptions: [
    { id: 'u1', name: 'Ada Lovelace' },
  ],
  groupOptions: [
    { id: 'g1', name: 'Product' },
  ],
})
```
