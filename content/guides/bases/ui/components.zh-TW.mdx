Bases UI 由工作台面板、轉譯後的檢視、欄位編輯器、記錄詳細資料面板和彈出式服務組成。大多數應用程式會註冊 `UniverBasesUIPlugin` 來使用預設元件。

## 自訂工作台的可見性

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'overlay',
  },
})
```

## 設定附件上傳

在正式環境中，附件欄位需要由應用程式提供上傳處理常式：

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/png', 'image/jpeg', 'application/pdf'],
    maxSize: 20 * 1024 * 1024,
    async upload(file) {
      const result = await uploadToServer(file)
      return {
        id: result.id,
        name: file.name,
        url: result.url,
        size: file.size,
        mimeType: file.type,
      }
    },
  },
})
```

## 人員與群組選項

請提供人員與群組清單，供人員和群組欄位編輯器使用。

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  personOptions: [{ id: 'u1', name: 'Ada Lovelace' }],
  groupOptions: [{ id: 'g1', name: 'Product' }],
})
```
