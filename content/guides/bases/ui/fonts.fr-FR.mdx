Bases utilise le système de polices partagé d’Univer UI pour le texte des tables, les éditeurs de champs, les menus et les panneaux. Chargez les polices web dans l’application hôte avant d’afficher Bases afin d’éviter tout décalage de mise en page.

## Configuration des polices de l’application hôte

```css
:root {
  font-family: Inter, system-ui, sans-serif;
}
```

## Texte des cellules

Le texte affiché dans les vues grille, kanban, calendrier, diagramme de Gantt et galerie provient des valeurs des champs et des outils de mise en forme propres à chaque champ. Pour mettre en forme les nombres, les devises, la progression, les évaluations et les dates, utilisez la configuration des champs plutôt que d’appliquer un style au texte brut des enregistrements.
