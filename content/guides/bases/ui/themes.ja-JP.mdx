Bases では、Univer 共通のデザインシステムとホストアプリケーションのテーマを使用します。Bases UI プラグインは、データワークベンチのレイアウト、フィールドエディター、パネル、ビューのレンダリングを担います。

## 共通スタイルを登録する

Bases UI のスタイルより先に共通スタイルを読み込んでください。

```ts
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/bases-ui/lib/index.css'
```

## アプリケーションのテーマ設定

ページの背景、周囲のレイアウト、アプリケーションシェルのナビゲーションを制御するには、ホストアプリケーションのデザイントークンと CSS 変数を使用します。レコードの色、選択肢、ビューの色設定は、スナップショットに保持されるよう、Base のフィールド設定またはビュー設定に保存してください。

## フィールドの色

単一選択、複数選択、グループ、カレンダー、ガントの各ビューでは、フィールド設定またはビュー設定を使用して、意味に応じた色を表示できます。
