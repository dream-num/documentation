Bases uses the shared Univer design system and host application theme. The Bases UI plugin focuses on data workbench layout, field editors, panels, and view rendering.

## Register shared styles

Load shared styles before Bases UI styles:

```ts
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/bases-ui/lib/index.css'
```

## Application theming

Use the host application's design tokens and CSS variables to control page background, surrounding layout, and shell-level navigation. Keep record colors, select options, and view color settings in Base field or view configuration so they persist with the snapshot.

## Field colors

Single-select, multi-select, group, calendar, and gantt views can use field or view config to render semantic colors.
