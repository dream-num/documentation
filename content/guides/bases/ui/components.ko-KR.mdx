Bases UI는 워크벤치 패널, 렌더링된 뷰, 필드 편집기, 레코드 세부 정보 패널, 팝업 서비스로 구성됩니다. 대부분의 애플리케이션은 `UniverBasesUIPlugin`을 등록하여 기본 컴포넌트를 사용합니다.

## 워크벤치 표시 여부 사용자 지정

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'overlay',
  },
})
```

## 첨부 파일 업로드 구성

프로덕션에서 첨부 파일 필드를 사용하려면 애플리케이션 업로드 핸들러가 필요합니다.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/png', 'image/jpeg', 'application/pdf'],
    maxSize: 20 * 1024 * 1024,
    async upload(file) {
      const result = await uploadToServer(file)
      return {
        id: result.id,
        name: file.name,
        url: result.url,
        size: file.size,
        mimeType: file.type,
      }
    },
  },
})
```

## 사용자 및 그룹 옵션

사용자 및 그룹 필드 편집기에 사용할 사용자와 그룹 목록을 제공합니다.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  personOptions: [
    { id: 'u1', name: 'Ada Lovelace' },
  ],
  groupOptions: [
    { id: 'g1', name: 'Product' },
  ],
})
```
