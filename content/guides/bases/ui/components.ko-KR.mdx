`@univerjs-pro/bases-ui`는 기본 작업대를 구축하기 위해 사용되는 구성품을 수출합니다. 초기 Univer 인젝터 내부에서 실행되며 독립 설계 시스템 위젯이 없습니다.

## 공개 워크벤치 컴포넌트

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

패키지는 또한 `AddViewMenu`, `FilterPanel` 및 `FormulaEditorPanel`와 같은 전문 패널을 수출합니다. 주변 기지 서비스와 단위 컨텍스트가 사용할 때이 패널을 렌더링합니다.

## 지원되는 확장 지점

- `IBaseViewUIRegistryService`는 뷰 유형에 DOM 또는 캔버스 렌더러를 등록합니다.
- `IBaseDashboardUIExtensionRegistryService`는 단일 대쉬보드 UI 확장을 제공합니다.
- `IBaseRecordActionService`는 기록적인 활동을 추가하고 현재 단위, 테이블, 전망 및 기록에 각 활동을 공급합니다.

각 등록은 일회용 핸들을 반환합니다. 호스트 플러그인이 제거 될 때 핸들을 해제하면 stale 작업 또는 렌더링자는 작업대에 남아 있지 않습니다.
