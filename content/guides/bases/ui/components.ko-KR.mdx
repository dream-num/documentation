`@univerjs-pro/bases-ui`는 Bases 워크벤치에서 사용하는 컴포넌트를 내보냅니다. 초기화된 Univer 인젝터 안에서 실행되며 독립적인 디자인 시스템 위젯이 아닙니다.

## 공개 워크벤치 컴포넌트

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

`AddViewMenu`, `FilterPanel`, `FormulaEditorPanel` 같은 전용 패널도 내보냅니다. 주변 Bases 서비스와 유닛 컨텍스트를 사용할 수 있을 때만 렌더링하세요.

## 지원되는 확장 지점

- `IBaseViewUIRegistryService`는 뷰 유형에 DOM 또는 캔버스 렌더러를 등록합니다.
- `IBaseDashboardUIExtensionRegistryService`는 하나의 대시보드 UI 확장을 제공합니다.
- `IBaseRecordActionService`는 현재 유닛, 테이블, 뷰, 레코드 컨텍스트를 가진 작업을 추가합니다.

각 등록은 폐기 가능한 핸들을 반환합니다. 호스트 플러그인을 제거할 때 폐기하세요.
