Bases does not provide a product-specific font registry, and it does not support per-record font styles. Canvas views and cell editors use the internal font stack `Arial, "Microsoft YaHei", sans-serif`, which keeps text measurement and editing aligned.

## What can be styled

- Shared Univer shell components follow the host theme and UI styles.
- Field configuration determines value formatting, including numbers, currency, rating, progress, and dates.
- Option colors and view colors belong to Base data and are not font settings.

Do not use a Sheets preset or a `customFontFamily` example to configure the Bases canvas. If the host page uses web fonts around the workbench, load them before mounting Univer so that the surrounding UI does not shift.
