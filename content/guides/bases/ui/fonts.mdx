Bases uses the shared Univer UI font pipeline for table text, field editors, menus, and panels. Load web fonts in the host application before rendering Bases to avoid layout shifts.

## Host font setup

```css
:root {
  font-family: Inter, system-ui, sans-serif;
}
```

## Cell text

Text rendered in grid, kanban, calendar, gantt, and gallery views comes from field values and field-specific formatters. Use field configuration for number, currency, progress, rating, and date formatting instead of styling raw text in records.
