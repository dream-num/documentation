Для текста таблиц, редакторов полей, меню и панелей Bases использует общий механизм шрифтов Univer UI. Чтобы избежать смещения макета, загрузите веб-шрифты в основном приложении до рендеринга Bases.

## Настройка шрифта в основном приложении

```css
:root {
  font-family: Inter, system-ui, sans-serif;
}
```

## Текст в ячейках

Текст в представлениях сетки, канбан-доски, календаря, диаграммы Ганта и галереи формируется из значений полей с помощью форматтеров соответствующих типов. Для форматирования чисел, валют, прогресса, рейтингов и дат используйте настройки полей, а не стилизацию исходного текста в записях.
