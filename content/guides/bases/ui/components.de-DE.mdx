Basen Die Benutzeroberfläche wird aus gerenderten Workbench-Panels erstellt Ansichten, Feldeditoren, Datensatzdetailfenster und Popup-Dienste. Die meisten Anwendungen verwenden die Standardkomponenten durch die Registrierung von `UniverBasesUIPlugin`.

## Passen Sie die Workbench-Sichtbarkeit an

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'overlay',
  },
})
```

## Konfigurieren Sie Anhang-Uploads

Anhangsfelder benötigen einen Anwendungs-Upload-Handler in der Produktion:

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/png', 'image/jpeg', 'application/pdf'],
    maxSize: 20 * 1024 * 1024,
    async upload(file) {
      const result = await uploadToServer(file)
      return {
        id: result.id,
        name: file.name,
        url: result.url,
        size: file.size,
        mimeType: file.type,
      }
    },
  },
})
```

## Personen- und Gruppenoptionen

Stellen Sie Personen- und Gruppenlisten bereit, um Feldeditoren für Personen und Gruppen zu unterstützen.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  personOptions: [
    { id: 'u1', name: 'Ada Lovelace' },
  ],
  groupOptions: [
    { id: 'g1', name: 'Product' },
  ],
})
```
