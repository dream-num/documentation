`@univerjs-pro/bases-ui` exporta los componentes del área de trabajo de Bases. Deben ejecutarse dentro de un inyector Univer inicializado; no son componentes independientes del sistema de diseño.

## Componentes públicos

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

El paquete también exporta paneles específicos como `AddViewMenu`, `FilterPanel` y `FormulaEditorPanel`. Renderícelos solo cuando estén disponibles los servicios y el contexto de unidad de Bases.

## Puntos de extensión compatibles

- `IBaseViewUIRegistryService` registra un renderizador DOM o de lienzo para un tipo de vista.
- `IBaseDashboardUIExtensionRegistryService` proporciona una extensión de panel.
- `IBaseRecordActionService` añade acciones con el contexto actual de unidad, tabla, vista y registro.

Cada registro devuelve un recurso desechable. Libérelo cuando se retire el plugin host.
