`@univerjs-pro/bases-ui` exporta los componentes utilizados para construir el banco de trabajo Bases. Corren dentro de un inyector inicializado Univer y no son widgets de diseño independientes.

## Componentes públicos

```ts
import {
  BaseTableSidebarFrame,
  BaseToolbar,
  BaseUnitCollaborationStatus,
  BaseViewIcon,
  ViewTabs,
} from '@univerjs-pro/bases-ui'
```

El paquete también exporta paneles especializados como `AddViewMenu`, `FilterPanel` y `FormulaEditorPanel`. Render estos paneles sólo cuando los servicios de Bases circundantes y el contexto de unidad están disponibles.

## Puntos de extensión compatibles

- `IBaseViewUIRegistryService` registra un renderizador DOM o de lienzo para un tipo de vista.
- `IBaseDashboardUIExtensionRegistryService` suministra una extensión UI de panel único.
- `IBaseRecordActionService` añade acciones récord y suministra cada acción con la unidad actual, mesa, vista y registro.

Cada registro devuelve un mango desechable. Despose el mango cuando se elimina el plugin de host para que las acciones de estantería o los renderizadores no permanezcan en el banco de trabajo.
