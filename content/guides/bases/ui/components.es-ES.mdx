La interfaz de usuario de bases se construye a partir de paneles de banco de trabajo, vistas renderizadas, editores de campo, paneles de detalles de registros y servicios emergentes. La mayoría de las aplicaciones utilizan los componentes predeterminados al registrar `UniverBasesUIPlugin`.

## Personalizar la visibilidad del banco de trabajo

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  workbench: {
    header: true,
    headerMenu: true,
    content: true,
    leftSidebar: true,
    rightSidebar: false,
    rightPanelMode: 'overlay',
  },
})
```

## Configurar la carga de archivos adjuntos

Los campos de archivos adjuntos necesitan un controlador de carga de aplicaciones en producción:

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  attachment: {
    accept: ['image/png', 'image/jpeg', 'application/pdf'],
    maxSize: 20 * 1024 * 1024,
    async upload(file) {
      const result = await uploadToServer(file)
      return {
        id: result.id,
        name: file.name,
        url: result.url,
        size: file.size,
        mimeType: file.type,
      }
    },
  },
})
```

## Opciones de personas y grupos

Proporcione listas de personas y grupos para potenciar los editores de campos de personas y grupos.

```ts
univer.registerPlugin(UniverBasesUIPlugin, {
  personOptions: [
    { id: 'u1', name: 'Ada Lovelace' },
  ],
  groupOptions: [
    { id: 'g1', name: 'Product' },
  ],
})
```
