## IBaseSnapshot

`IBaseSnapshot` ist das von Univer verwendete Persistenzformat Basen. Es beschreibt eine Basiseinheit, einschließlich Tabellen, Tabellenreihenfolge, Schemaversion, Zeitstempel und optionaler Revisionsmetadaten.

### Eigenschaften

| Eigenschaft | Typ | Beschreibung |
| --- | --- | --- |
| id | `string` | Eindeutige ID der Basiseinheit. |
| name | `string` | Basisname. |
| schemaVersion | `number` | Snapshot-Schemaversion. |
| tables | `Record\<string, ITableSnapshot\>` | Tabellen, kodiert nach Tabellen-ID. |
| tableOrder | `string[]` | Geordnete Liste der Tabellen ids. |
| createdAt | `number` | Erstellungszeitstempel. |
| updatedAt | `number` | Aktualisierungszeitstempel. |
| createdBy? | `string` | Ersteller-ID. |
| rev? | `number` | Optionaler Revisionswert, der von Persistenz- oder Kollaborationsebenen verwendet wird. |

## Minimaler Snapshot

```ts
const baseSnapshot = {
  id: 'base-1',
  name: 'Product tracker',
  schemaVersion: 1,
  tableOrder: ['tasks'],
  tables: {
    tasks: {
      id: 'tasks',
      name: 'Tasks',
      primaryFieldId: 'title',
      fieldOrder: ['title', 'status'],
      fields: {
        title: { id: 'title', name: 'Title', type: 'text', config: {} },
        status: { id: 'status', name: 'Status', type: 'singleSelect', config: {} },
      },
      recordOrder: ['rec-1'],
      records: {
        'rec-1': {
          id: 'rec-1',
          values: { title: 'Write docs', status: 'In progress' },
          orderKey: 'a0',
          createdAt: Date.now(),
          updatedAt: Date.now(),
        },
      },
      views: {},
      viewOrder: [],
    },
  },
  createdAt: Date.now(),
  updatedAt: Date.now(),
}
```

## Verwendung

`IBaseSnapshot` wird hauptsächlich verwendet, um:

1. eine `UniverInstanceType.UNIVER_BASE`-Einheit zu erstellen.
2. Strukturiert beibehalten und wiederherstellen Daten.
3. Bereiten Sie Daten für die serverseitige Verarbeitung vor.
4. Übertragen Sie Daten zwischen Kollaborations- und Import-/Exportdiensten.

<Callout type="warning">
Snapshot-Objekte sind Persistenzdaten. Nachdem eine Base ausgeführt wird, bevorzugen Sie Facade-APIs, anstatt das Snapshot-Objekt direkt zu ändern.
</Callout>
