## IBaseSnapshot

`IBaseSnapshot`は、Univerベースがストレージに書き込むフォーマットです。スナップショットは、そのテーブルと注文、スキーマバージョン、タイムスタンプ、オプションのリビジョンメタデータのいずれかのベースユニットについて説明します。

### プロパティ

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| id | `string` | Baseユニットの一意なID。 |
| name | `string` | ベースの名前。 |
| schemaVersion | `number` | スナップショットのスキーマバージョン。 |
| tables | `Record\<string, ITableSnapshot\>` | テーブルIDをキーとするテーブル。 |
| tableOrder | `string[]` | テーブルIDを順番に並べたリスト。 |
| createdAt | `number` | 作成時のタイムスタンプ。 |
| updatedAt | `number` | 最終更新のタイムスタンプ。 |
| createdBy? | `string` | クリエイターのID。 |
| rev? | `number` | オプションのリビジョン値、永続またはコラボレーションレイヤーで使用されます。 |

## 最小構成のスナップショット

```ts
const baseSnapshot = {
  id: 'base-1',
  name: 'Product tracker',
  schemaVersion: 1,
  tableOrder: ['tasks'],
  tables: {
    tasks: {
      id: 'tasks',
      name: 'Tasks',
      primaryFieldId: 'title',
      fieldOrder: ['title', 'status'],
      fields: {
        title: { id: 'title', name: 'Title', type: 'text', config: {} },
        status: { id: 'status', name: 'Status', type: 'singleSelect', config: {} },
      },
      recordOrder: ['rec-1'],
      records: {
        'rec-1': {
          id: 'rec-1',
          values: { title: 'Write docs', status: 'In progress' },
          orderKey: 'a0',
          createdAt: Date.now(),
          updatedAt: Date.now(),
        },
      },
      views: {},
      viewOrder: [],
    },
  },
  createdAt: Date.now(),
  updatedAt: Date.now(),
}
```

## 用途

`IBaseSnapshot`は、以下の場合に役立ちます。

1. `UniverInstanceType.UNIVER_BASE` ユニットを作成する。
2. 構造化データを永続化し、復元する。
3. サーバー側の処理に使用するデータを準備する。
4. コラボレーションサービスとインポート／エクスポートサービスの間でデータを転送する。

<Callout type="warning">
  スナップショットオブジェクトは永続データです。ベースが実行されると、スナップショットを直接ミュートする代わりに、Facade APIを使用します。
</Callout>

## 保存と復元

`save()`をFacadeで、ダッシュボードやローカルコメントなどの登録済みプラグインからリソースを含めるように呼びます。例えば、`saveToBackend`はアプリケーションの永続関数を表しています。

```ts
const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')
await saveToBackend(base.save())
```

新しいエディタインスタンスで、同じプラグインを最初に登録し、`univerAPI.createBase(savedSnapshot)`で復元します。 `tables`だけを主張しないでください。実行中のモデルのスナップショットをミュートしません。
