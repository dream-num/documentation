Una vista determina cómo se presenta una tabla a los usuarios. Puede ocultar o reordenar campos, filtrar, clasificar, y registros de grupos, y sostiene la configuración que un tipo de vista requiere para renderizar como una cuadrícula, tabla de kanban, calendario, gráfico de gantt, o galería.

## Ver instantánea

| Propiedad | Tipo | Descripción |
| --- | --- | --- |
| id | `string` | Id. de la vista. |
| tableId | `string` | Identificación de la mesa de propiedad. |
| name | `string` | Nombre de la vista. |
| type | `BaseViewType` | `grid`, `kanban`, `calendar`, `gantt`, `gallery`, `pivot`. |
| fieldOrder? | `string[]` | Orden de los campos en esta vista. |
| fieldSettings? | `Record\<string, IViewFieldSetting\>` | Visibilidad, ancho y configuración de tarjetas por campo. |
| filter? | `IFilterConfig | null` | Configuración de filtro para la vista. |
| sort? | `ISortConfig[]` | Reglas de clasificación. |
| group? | `IGroupConfig[]` | Reglas de grupo. |
| config | `ViewSpecificConfig` | Configuración específica para el tipo de vista. |

## Tipos de vista

| Tipo | Usar case |
| --- | --- |
| `grid` | Edición de hoja de cálculo de una tabla. |
| `kanban` | Tarjetas agrupadas por un campo de selección, persona, grupo, texto o fecha. |
| `calendar` | Registros colocados por campos de fecha. |
| `gantt` | Planificación de línea de tiempo con campos de fecha de inicio y finalización, comparación con el cronograma planificado, progreso y predecesores. |
| `gallery` | Diseño de tarjetas para registros que son principalmente visuales o contienen una gran cantidad de contenido. |
| `pivot` | Resúmenes y gráficos mediante el plugin de paneles. |

La configuración de Gantt usa `startDateFieldId` y `endDateFieldId` para el cronograma actual y `progressFieldId` para el progreso. `IBaseGanttViewConfig` amplía la configuración de Gantt con `showPlanComparison`, `planStartDateFieldId`, `planEndDateFieldId`, `planColor` y `remainingColor`. Establezca `dependencyFieldId` en un campo `RecordLink` de varios valores para realizar el seguimiento de los predecesores. `workingDaysOnly` y `workingDays` controlan el calendario laboral.

## Crear una vista

```ts
const view = table.createView('Kanban', univerAPI.Enum.BaseViewType.Kanban)
```

## Configurar filtrado y clasificación

```ts
view.setFilter({
  conjunction: univerAPI.Enum.BaseFilterConjunction.AND,
  conditions: [
    {
      fieldId: 'status',
      operator: univerAPI.Enum.BaseFilterOperator.IS,
      operand: 'In progress',
    },
  ],
})

view.setSort([
  { fieldId: 'dueDate', direction: univerAPI.Enum.BaseSortDirection.ASC },
])
```

## Visibilidad y ancho de campo

```ts
view.setFieldVisible('internalNotes', false)
view.setFieldWidth('title', 280)
```
