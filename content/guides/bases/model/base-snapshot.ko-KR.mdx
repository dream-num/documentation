## IBaseSnapshot

`IBaseSnapshot`는 저장에 Univer 기초가 쓴 체재입니다. 스냅샷은 1개의 기본적인 단위를 설명합니다: 그것의 테이블 및 그들의 순서, 스키마 버전, 타임스탬프 및 선택적인 개정 메타데이터.

### 속성

| 속성 | 유형 | 설명 |
| --- | --- | --- |
| id | `string` | Base 단위의 고유 ID입니다. |
| name | `string` | 자료의 이름. |
| schemaVersion | `number` | 스냅샷 스키마 버전입니다. |
| tables | `Record\<string, ITableSnapshot\>` | 테이블 ID를 키로 사용하는 테이블입니다. |
| tableOrder | `string[]` | 정렬된 테이블 ID 목록입니다. |
| createdAt | `number` | 생성 타임스탬프입니다. |
| updatedAt | `number` | 마지막 업데이트의 타임스탬프. |
| createdBy? | `string` | 제작자의 ID. |
| rev? | `number` | persistence 또는 공동 레이어에 의해 사용되는 옵션 개정 값. |

## 최소 스냅샷

```ts
const baseSnapshot = {
  id: 'base-1',
  name: 'Product tracker',
  schemaVersion: 1,
  tableOrder: ['tasks'],
  tables: {
    tasks: {
      id: 'tasks',
      name: 'Tasks',
      primaryFieldId: 'title',
      fieldOrder: ['title', 'status'],
      fields: {
        title: { id: 'title', name: 'Title', type: 'text', config: {} },
        status: { id: 'status', name: 'Status', type: 'singleSelect', config: {} },
      },
      recordOrder: ['rec-1'],
      records: {
        'rec-1': {
          id: 'rec-1',
          values: { title: 'Write docs', status: 'In progress' },
          orderKey: 'a0',
          createdAt: Date.now(),
          updatedAt: Date.now(),
        },
      },
      views: {},
      viewOrder: [],
    },
  },
  createdAt: Date.now(),
  updatedAt: Date.now(),
}
```

## 사용법

`IBaseSnapshot`는 다음과 같은 사례를 제공합니다.

1. `UniverInstanceType.UNIVER_BASE` 단위를 생성합니다.
2. 구조화된 데이터를 영속화하고 복원합니다.
3. 서버 측 처리를 위한 데이터를 준비합니다.
4. 협업 서비스와 가져오기/내보내기 서비스 간에 데이터를 전송합니다.

<Callout type="warning">
  스냅 샷 객체는 지속 데이터입니다. 기본이 실행되면 스냅 샷을 mutating 대신 Facade API를 사용하십시오.
</Callout>

## 저장 및 복원

Facade에 `save()`를 호출하여 등록된 플러그인과 같은 대쉬보드 및 로컬 주석에서 리소스를 포함하십시오. 예를 들어 `saveToBackend`는 응용 프로그램의 지속 기능을 나타냅니다.

```ts
const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')
await saveToBackend(base.save())
```

새로운 편집기 인스턴스에서, 같은 플러그인을 먼저 등록하고, `univerAPI.createBase(savedSnapshot)`로 복원하십시오. `tables`만 persist하지 말고, 실행 모델의 스냅 샷을 mutate하지 마십시오.
