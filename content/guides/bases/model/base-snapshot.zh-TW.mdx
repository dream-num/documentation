## IBaseSnapshot

`IBaseSnapshot` 是 Univer Bases 寫入儲存時使用的格式。一個快照描述一個 Base 單元：表及其順序、架構版本、時間戳，以及可選的修訂資訊。

### 屬性

| 屬性 | 類型 | 說明 |
| --- | --- | --- |
| id | `string` | Base 單元的唯一 ID。 |
| name | `string` | Base 名稱。 |
| schemaVersion | `number` | 快照結構描述版本。 |
| tables | `Record\<string, ITableSnapshot\>` | 以資料表 ID 為鍵的資料表。 |
| tableOrder | `string[]` | 按順序排好的表 ID 列表。 |
| createdAt | `number` | 建立時間戳記。 |
| updatedAt | `number` | 最後一次更新的時間戳。 |
| createdBy? | `string` | 建立者 ID。 |
| rev? | `number` | 供持久化或協作層使用的選用修訂值。 |

## 最小快照

```ts
const baseSnapshot = {
  id: 'base-1',
  name: 'Product tracker',
  schemaVersion: 1,
  tableOrder: ['tasks'],
  tables: {
    tasks: {
      id: 'tasks',
      name: 'Tasks',
      primaryFieldId: 'title',
      fieldOrder: ['title', 'status'],
      fields: {
        title: { id: 'title', name: 'Title', type: 'text', config: {} },
        status: { id: 'status', name: 'Status', type: 'singleSelect', config: {} },
      },
      recordOrder: ['rec-1'],
      records: {
        'rec-1': {
          id: 'rec-1',
          values: { title: 'Write docs', status: 'In progress' },
          orderKey: 'a0',
          createdAt: Date.now(),
          updatedAt: Date.now(),
        },
      },
      views: {},
      viewOrder: [],
    },
  },
  createdAt: Date.now(),
  updatedAt: Date.now(),
}
```

## 用途

`IBaseSnapshot` 適用於以下場景：

1. 建立 `UniverInstanceType.UNIVER_BASE` 單元。
2. 持久化及還原結構化資料。
3. 準備要在伺服器端處理的資料。
4. 在協作服務和匯入匯出服務之間傳輸資料。

<Callout type="warning">
  快照物件屬於持久化資料。Base 執行之後，應透過 Facade API 操作，不要直接修改快照物件。
</Callout>

## 儲存與還原

呼叫 Facade 的 `save()` 進行儲存，已註冊外掛的資源也會一併包含，例如儀表盤和本地評論。範例中的 `saveToBackend` 代表應用自身的儲存函式：

```ts
const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')
await saveToBackend(base.save())
```

在新的編輯器例項中，先註冊同一批外掛，再透過 `univerAPI.createBase(savedSnapshot)` 恢復。不要只儲存 `tables`，也不要直接修改執行中模型的快照。
