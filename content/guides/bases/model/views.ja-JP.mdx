ビューは、ユーザーにテーブルをどのように表示するかを定義します。ビューでは、フィールドの非表示や並べ替え、レコードの絞り込み、並べ替え、グループ化のほか、グリッド、カンバン、カレンダー、ガント、ギャラリーの各表示形式に固有の設定を定義できます。

## ビューのスナップショット

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| id | `string` | ビューID。 |
| tableId | `string` | このビューを所有するテーブルのID。 |
| name | `string` | ビュー名。 |
| type | `ViewType` | `grid`、`kanban`、`calendar`、`gantt`、`gallery` のいずれか。 |
| fieldOrder? | `string[]` | このビューでのフィールドの順序。 |
| fieldSettings? | `Record\<string, IViewFieldSetting\>` | フィールドごとの表示状態、幅、カード設定。 |
| filter? | `IFilterConfig | null` | ビューのフィルター設定。 |
| sort? | `ISortConfig[]` | 並べ替えルール。 |
| group? | `IGroupConfig[]` | グループ化ルール。 |
| config | `ViewSpecificConfig` | ビュー形式固有の設定。 |

## ビュー形式

| 形式 | 用途 |
| --- | --- |
| `grid` | スプレッドシートのような形式でテーブルを編集します。 |
| `kanban` | 選択肢、ユーザー、グループ、テキスト、日付のいずれかのフィールドに基づいてカードをグループ化します。 |
| `calendar` | 日付フィールドに基づいてレコードを配置します。 |
| `gantt` | 開始日と終了日のフィールドを使ってタイムラインを計画します。 |
| `gallery` | 画像やコンテンツの多いレコードをカード形式で配置します。 |

## ビューの作成

```ts
const view = table.createView('Kanban', univerAPI.Enum.BaseViewType.Kanban)
```

## フィルタリングと並べ替えの設定

```ts
view.setFilter({
  conjunction: univerAPI.Enum.BaseFilterConjunction.AND,
  conditions: [
    {
      fieldId: 'status',
      operator: univerAPI.Enum.BaseFilterOperator.IS,
      operand: 'In progress',
    },
  ],
})

view.setSort([
  { fieldId: 'dueDate', direction: univerAPI.Enum.BaseSortDirection.ASC },
])
```

## フィールドの表示状態と幅

```ts
view.setFieldVisible('internalNotes', false)
view.setFieldWidth('title', 280)
```
