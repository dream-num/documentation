title: ビュー

---

ビューは、テーブルがユーザーに提示される方法を決定します。フィールド、フィルタ、ソート、グループレコードを非表示または並べ替え、およびビュータイプがグリッド、カンバンボード、カレンダー、ガンットチャート、またはギャラリーとしてレンダリングする必要がある構成を保持できます。

## ビューのスナップショット

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| id | `string` | ビューID。 |
| tableId | `string` | 所有するテーブルのID。 |
| name | `string` | ビュー名。 |
| type | `BaseViewType` | `grid`, `kanban`, `calendar`, `gantt`, `gallery`, `pivot`. |
| fieldOrder? | `string[]` | このビューでのフィールドの順序。 |
| fieldSettings? | `Record\<string, IViewFieldSetting\>` | フィールドごとの可視性、幅、およびカード設定。 |
| filter? | `IFilterConfig | null` | ビューのフィルタ構成。 |
| sort? | `ISortConfig[]` | 並べ替えルール。 |
| group? | `IGroupConfig[]` | グループ化ルール。 |
| config | `ViewSpecificConfig` | ビュータイプに固有の構成。 |

## ビュー形式

| 形式 | 用途 |
| --- | --- |
| `grid` | テーブルのスプレッドシートスタイルの編集。 |
| `kanban` | 選択肢、ユーザー、グループ、テキスト、日付のいずれかのフィールドに基づいてカードをグループ化します。 |
| `calendar` | 日付フィールドにレコードを配置します。 |
| `gantt` | 開始日と終了日のフィールドを使ってタイムラインを計画します。計画スケジュールの比較、完成度、先行タスクに対応します。 |
| `gallery` | 主に視覚的または大量のコンテンツを含むレコードのカードレイアウト。 |
| `pivot` | 集計とグラフ表示にはダッシュボードプラグインが必要です。 |

ガントの構成では、現在のスケジュールに `startDateFieldId` と `endDateFieldId` を使用し、完成度に `progressFieldId` を使用します。`IBaseGanttViewConfig` はガントの構成に `showPlanComparison`、`planStartDateFieldId`、`planEndDateFieldId`、`planColor`、`remainingColor` を加えます。先行タスクを追跡するには、`dependencyFieldId` に複数値のレコードリンクフィールドを設定します。`workingDaysOnly` と `workingDays` は作業日カレンダーを制御します。

## ビューの作成

```ts
const view = table.createView('Kanban', univerAPI.Enum.BaseViewType.Kanban)
```

## フィルタリングと並べ替えの設定

```ts
view.setFilter({
  conjunction: univerAPI.Enum.BaseFilterConjunction.AND,
  conditions: [
    {
      fieldId: 'status',
      operator: univerAPI.Enum.BaseFilterOperator.IS,
      operand: 'In progress',
    },
  ],
})

view.setSort([
  { fieldId: 'dueDate', direction: univerAPI.Enum.BaseSortDirection.ASC },
])
```

## フィールドの表示状態と幅

```ts
view.setFieldVisible('internalNotes', false)
view.setFieldWidth('title', 280)
```
