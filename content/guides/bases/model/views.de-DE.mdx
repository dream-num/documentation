Ansichten beschreiben, wie eine Tabelle für Benutzer projiziert wird. Eine Ansicht kann Felder ausblenden oder neu anordnen, Datensätze filtern, Datensätze sortieren, gruppieren und typspezifische Konfigurationen für Raster-, Kanban-, Kalender-, Gantt- oder Galerie-Rendering definieren.

## Snapshot anzeigen

| Eigenschaft | Typ | Beschreibung |
| --- | --- | --- |
| id | `string` | Ansichts-ID. |
| tableId | `string` | Besitzende Tabellen-ID. |
| name | `string` | Ansichtsname. |
| type | `ViewType` | `grid`, `kanban`, `calendar`, `gantt` oder `gallery`. |
| fieldOrder? | `string[]` | Feldreihenfolge in dieser Ansicht. |
| fieldSettings? | `Record\<string, IViewFieldSetting\>` | Sichtbarkeit, Breite und Karteneinstellungen pro Feld. |
| filter? | `IFilterConfig | null` | Filterkonfiguration anzeigen. |
| sort? | `ISortConfig[]` | Sortierregeln. |
| group? | `IGroupConfig[]` | Gruppenregeln. |
| config | `ViewSpecificConfig` | Typspezifische Ansichtskonfiguration. |

## Typen anzeigen

| Typ | Anwendungsfall |
| --- | --- |
| `grid` | Tabellenbearbeitung im Tabellenformat. |
| `kanban` | Karten nach Auswahl, Person, Gruppe, Text oder Datumsfeld gruppiert. |
| `calendar` | Datensätze nach Datumsfeldern positioniert. |
| `gantt` | Zeitleistenplanung mit Start- und Enddatum Felder. |
| `gallery` | Kartenlayout für visuelle oder inhaltsintensive Datensätze. |

## Ansicht erstellen

```ts
const view = table.createView({
  name: 'Kanban',
  type: univerAPI.Enum.BaseViewTypeEnum.Kanban,
})
```

## Filterung und Sortierung konfigurieren

```ts
view.setFilter({
  conjunction: 'and',
  conditions: [
    {
      fieldId: 'status',
      operator: univerAPI.Enum.BaseFilterOperatorEnum.Is,
      operand: 'In progress',
    },
  ],
})

view.setSort([
  { fieldId: 'dueDate', direction: univerAPI.Enum.BaseSortDirectionEnum.Asc },
])
```

## Feldsichtbarkeit und -breite

```ts
view.setFieldVisible('internalNotes', false)
view.setFieldWidth('title', 280)
```
