## IBaseSnapshot

`IBaseSnapshot` es el formato que Univer Bases escribe para el almacenamiento. Una instantánea describe una unidad Base: sus tablas y su orden, la versión de esquemas, horarios y metadatos de revisión opcional.

### Propiedades

| Propiedad | Tipo | Descripción |
| --- | --- | --- |
| id | `string` | Id. único de la unidad base. |
| name | `string` | Nombre de la Base. |
| schemaVersion | `number` | Versión del esquema de instantánea. |
| tables | `Record\<string, ITableSnapshot\>` | Tablas codificadas por ID de tabla. |
| tableOrder | `string[]` | Lista ordenada de tablas ids. |
| createdAt | `number` | Marca de tiempo de creación. |
| updatedAt | `number` | Timestamp de la última actualización. |
| createdBy? | `string` | ID del creador. |
| rev? | `number` | Valor de revisión opcional, utilizado por la persistencia o capas de colaboración. |

## Instantánea mínima

```ts
const baseSnapshot = {
  id: 'base-1',
  name: 'Product tracker',
  schemaVersion: 1,
  tableOrder: ['tasks'],
  tables: {
    tasks: {
      id: 'tasks',
      name: 'Tasks',
      primaryFieldId: 'title',
      fieldOrder: ['title', 'status'],
      fields: {
        title: { id: 'title', name: 'Title', type: 'text', config: {} },
        status: { id: 'status', name: 'Status', type: 'singleSelect', config: {} },
      },
      recordOrder: ['rec-1'],
      records: {
        'rec-1': {
          id: 'rec-1',
          values: { title: 'Write docs', status: 'In progress' },
          orderKey: 'a0',
          createdAt: Date.now(),
          updatedAt: Date.now(),
        },
      },
      views: {},
      viewOrder: [],
    },
  },
  createdAt: Date.now(),
  updatedAt: Date.now(),
}
```

## Uso

`IBaseSnapshot` atiende los siguientes casos:

1. Crear una unidad `UniverInstanceType.UNIVER_BASE`.
2. Persistir y restaurar datos estructurados.
3. Preparar datos para el procesamiento del lado del servidor.
4. Transferir datos entre servicios de colaboración y de importación/exportación.

<Callout type="warning">
  Un objeto de instantánea es datos de persistencia. Una vez que una Base está funcionando, use el Facade API en lugar de mutar la instantánea directamente.
</Callout>

## Guardar y restaurar

Llame a `save()` en la Facade para incluir recursos de plugins registrados, tales como tableros y comentarios locales. En el ejemplo, `saveToBackend` representa la función de persistencia de la aplicación:

```ts
const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')
await saveToBackend(base.save())
```

En una nueva instancia de editor, registre los mismos plugins primero, luego restituya con `univerAPI.createBase(savedSnapshot)`. No persistir sólo `tables`, y no mutar la instantánea del modelo de ejecución en su lugar.
