Представления определяют, как таблица отображается для пользователей. В представлении можно скрывать поля и менять их порядок, фильтровать, сортировать и группировать записи, а также задавать конфигурацию для отрисовки в виде таблицы, канбан-доски, календаря, диаграммы Ганта или галереи.

## Снимок представления

| Свойство | Тип | Описание |
| --- | --- | --- |
| id | `string` | Идентификатор представления. |
| tableId | `string` | Идентификатор таблицы, которой принадлежит представление. |
| name | `string` | Название представления. |
| type | `ViewType` | `grid`, `kanban`, `calendar`, `gantt` или `gallery`. |
| fieldOrder? | `string[]` | Порядок полей в этом представлении. |
| fieldSettings? | `Record\<string, IViewFieldSetting\>` | Настройки видимости, ширины и карточки для каждого поля. |
| filter? | `IFilterConfig | null` | Конфигурация фильтра представления. |
| sort? | `ISortConfig[]` | Правила сортировки. |
| group? | `IGroupConfig[]` | Правила группировки. |
| config | `ViewSpecificConfig` | Конфигурация представления, зависящая от его типа. |

## Типы представлений

| Тип | Сценарий использования |
| --- | --- |
| `grid` | Редактирование таблицы в формате электронной таблицы. |
| `kanban` | Карточки, сгруппированные по полю выбора, участника, группы, текста или даты. |
| `calendar` | Записи, расположенные в соответствии с полями даты. |
| `gantt` | Планирование на временной шкале с полями даты начала и окончания. |
| `gallery` | Карточная раскладка для записей с большим объёмом визуальных материалов или содержимого. |

## Создание представления

```ts
const view = table.createView({
  name: 'Kanban',
  type: univerAPI.Enum.BaseViewTypeEnum.Kanban,
})
```

## Настройка фильтрации и сортировки

```ts
view.setFilter({
  conjunction: 'and',
  conditions: [
    {
      fieldId: 'status',
      operator: univerAPI.Enum.BaseFilterOperatorEnum.Is,
      operand: 'In progress',
    },
  ],
})

view.setSort([
  { fieldId: 'dueDate', direction: univerAPI.Enum.BaseSortDirectionEnum.Asc },
])
```

## Видимость и ширина полей

```ts
view.setFieldVisible('internalNotes', false)
view.setFieldWidth('title', 280)
```
