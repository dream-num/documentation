Вид определяет, как таблица представлена пользователям. Он может скрывать или переупорядочивать поля, фильтровать, сортировать и группировать записи, и он содержит конфигурацию, которую тип просмотра требует для отображения в виде сетки, платы канбана, календаря, диаграммы Ганта или галереи.

## Снимок представления

| Свойство | Тип | Описание |
| --- | --- | --- |
| id | `string` | Идентификатор представления. |
| tableId | `string` | Идентификатор стола владельца. |
| name | `string` | Название представления. |
| type | `BaseViewType` | `grid`, `kanban`, `calendar`, `gantt`, `gallery`, `pivot`. |
| fieldOrder? | `string[]` | Порядок полей в этом представлении. |
| fieldSettings? | `Record\<string, IViewFieldSetting\>` | Видимость, ширина и настройки карты на поле. |
| filter? | `IFilterConfig | null` | Конфигурация фильтра для просмотра. |
| sort? | `ISortConfig[]` | Правила сортировки. |
| group? | `IGroupConfig[]` | Правила группировки. |
| config | `ViewSpecificConfig` | Конфигурация, специфичная для вида. |

## Типы представлений

| Тип | Сценарий использования |
| --- | --- |
| `grid` | Редактирование таблицы в стиле таблицы. |
| `kanban` | Карточки, сгруппированные по полю выбора, участника, группы, текста или даты. |
| `calendar` | Записи, размещенные по дата полям. |
| `gantt` | Планирование на временной шкале с полями даты начала и окончания. |
| `gallery` | Макет карты для записей, которые в первую очередь визуальные или содержат большое количество контента. |
| `pivot` | Агрегация и диаграммы через плагин панелей. |

## Создание представления

```ts
const view = table.createView('Kanban', univerAPI.Enum.BaseViewType.Kanban)
```

## Настройка фильтрации и сортировки

```ts
view.setFilter({
  conjunction: univerAPI.Enum.BaseFilterConjunction.AND,
  conditions: [
    {
      fieldId: 'status',
      operator: univerAPI.Enum.BaseFilterOperator.IS,
      operand: 'In progress',
    },
  ],
})

view.setSort([
  { fieldId: 'dueDate', direction: univerAPI.Enum.BaseSortDirection.ASC },
])
```

## Видимость и ширина полей

```ts
view.setFieldVisible('internalNotes', false)
view.setFieldWidth('title', 280)
```
