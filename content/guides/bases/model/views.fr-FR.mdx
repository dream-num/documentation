Une vue détermine comment une table est présentée aux utilisateurs. Elle peut masquer ou réorganiser des champs, filtrer, trier et enregistrer des groupes, et elle détient la configuration qu'un type de vue exige de rendre comme une grille, une planche kanban, un calendrier, un graphique gantt ou une galerie.

## Instantané d’une vue

| Propriété | Type | Description |
| --- | --- | --- |
| id | `string` | Identifiant de la vue. |
| tableId | `string` | Identification de la table propriétaire. |
| name | `string` | Nom de la vue. |
| type | `BaseViewType` | `grid`, `kanban`, `calendar`, `gantt`, `gallery`, `pivot`. |
| fieldOrder? | `string[]` | Ordre des champs dans cette vue. |
| fieldSettings? | `Record\<string, IViewFieldSetting\>` | Visibilité, largeur et paramètres de la carte par champ. |
| filter? | `IFilterConfig | null` | Configuration du filtre pour la vue. |
| sort? | `ISortConfig[]` | Règles de tri. |
| group? | `IGroupConfig[]` | Règles de regroupement. |
| config | `ViewSpecificConfig` | Configuration spécifique au type de vue. |

## Types de vues

| Type | Cas d’usage |
| --- | --- |
| `grid` | Révision d'une table en forme de feuille de calcul. |
| `kanban` | Cartes regroupées selon un champ de sélection, de personne, de groupe, de texte ou de date. |
| `calendar` | Enregistrements placés par champs de date. |
| `gantt` | Planification chronologique à l’aide de champs de date de début et de fin. |
| `gallery` | Mise en page de la carte pour les documents qui sont principalement visuels ou contiennent une grande quantité de contenu. |
| `pivot` | Agrégations et graphiques via le plugin de tableau de bord. |

## Créer une vue

```ts
const view = table.createView('Kanban', univerAPI.Enum.BaseViewType.Kanban)
```

## Configurer le filtrage et le tri

```ts
view.setFilter({
  conjunction: univerAPI.Enum.BaseFilterConjunction.AND,
  conditions: [
    {
      fieldId: 'status',
      operator: univerAPI.Enum.BaseFilterOperator.IS,
      operand: 'In progress',
    },
  ],
})

view.setSort([
  { fieldId: 'dueDate', direction: univerAPI.Enum.BaseSortDirection.ASC },
])
```

## Visibilité et largeur des champs

```ts
view.setFieldVisible('internalNotes', false)
view.setFieldWidth('title', 280)
```
