---
title: 视图

---

视图决定一张表如何呈现给用户。它可以隐藏字段或调整字段顺序，也可以筛选、排序和分组记录；网格、看板、日历、甘特图和画廊等视图类型渲染所需的配置，同样存放在视图里。

## 视图快照

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| id | `string` | 视图 ID。 |
| tableId | `string` | 所属表的 ID。 |
| name | `string` | 视图名称。 |
| type | `BaseViewType` | `grid`, `kanban`, `calendar`, `gantt`, `gallery`, `pivot`. |
| fieldOrder? | `string[]` | 该视图里的字段顺序。 |
| fieldSettings? | `Record\<string, IViewFieldSetting\>` | 各字段的可见性、宽度和卡片设置。 |
| filter? | `IFilterConfig | null` | 该视图的筛选配置。 |
| sort? | `ISortConfig[]` | 排序规则。 |
| group? | `IGroupConfig[]` | 分组规则。 |
| config | `ViewSpecificConfig` | 该视图类型专用的配置。 |

## 视图类型

| 类型 | 使用场景 |
| --- | --- |
| `grid` | 以电子表格的形式编辑一张表。 |
| `kanban` | 按选择、人员、分组、文本或日期字段对卡片分组。 |
| `calendar` | 按日期字段放置记录。 |
| `gantt` | 根据开始日期和结束日期字段规划时间线。 |
| `gallery` | 用卡片布局展示以视觉内容为主或内容较多的记录。 |
| `pivot` | 通过[仪表盘插件](/guides/bases/features/dashboard)生成汇总和图表。 |

## 创建视图

```ts
const view = table.createView('Kanban', univerAPI.Enum.BaseViewType.Kanban)
```

## 配置筛选与排序

```ts
view.setFilter({
  conjunction: univerAPI.Enum.BaseFilterConjunction.AND,
  conditions: [
    {
      fieldId: 'status',
      operator: univerAPI.Enum.BaseFilterOperator.IS,
      operand: 'In progress',
    },
  ],
})

view.setSort([
  { fieldId: 'dueDate', direction: univerAPI.Enum.BaseSortDirection.ASC },
])
```

## 字段可见性与宽度

```ts
view.setFieldVisible('internalNotes', false)
view.setFieldWidth('title', 280)
```
