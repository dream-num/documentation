뷰는 사용자에게 테이블이 표시되는 방식을 설명합니다. 뷰에서는 필드를 숨기거나 순서를 바꾸고, 레코드를 필터링·정렬·그룹화하며, 그리드, 칸반, 캘린더, 간트 또는 갤러리 렌더링을 위한 유형별 구성을 정의할 수 있습니다.

## 뷰 스냅샷

| 속성 | 유형 | 설명 |
| --- | --- | --- |
| id | `string` | 뷰 ID입니다. |
| tableId | `string` | 뷰가 속한 테이블 ID입니다. |
| name | `string` | 뷰 이름입니다. |
| type | `ViewType` | `grid`, `kanban`, `calendar`, `gantt` 또는 `gallery`입니다. |
| fieldOrder? | `string[]` | 이 뷰의 필드 순서입니다. |
| fieldSettings? | `Record\<string, IViewFieldSetting\>` | 필드별 표시 여부, 너비, 카드 설정입니다. |
| filter? | `IFilterConfig | null` | 뷰 필터 구성입니다. |
| sort? | `ISortConfig[]` | 정렬 규칙입니다. |
| group? | `IGroupConfig[]` | 그룹 규칙입니다. |
| config | `ViewSpecificConfig` | 유형별 뷰 구성입니다. |

## 뷰 유형

| 유형 | 사용 사례 |
| --- | --- |
| `grid` | 스프레드시트와 유사한 테이블 편집입니다. |
| `kanban` | 선택, 사용자, 그룹, 텍스트 또는 날짜 필드를 기준으로 그룹화된 카드입니다. |
| `calendar` | 날짜 필드를 기준으로 배치된 레코드입니다. |
| `gantt` | 시작일과 종료일 필드를 사용하는 타임라인 계획입니다. |
| `gallery` | 시각 자료나 콘텐츠가 많은 레코드를 위한 카드 레이아웃입니다. |

## 뷰 생성

```ts
const view = table.createView('Kanban', univerAPI.Enum.BaseViewType.Kanban)
```

## 필터링 및 정렬 구성

```ts
view.setFilter({
  conjunction: univerAPI.Enum.BaseFilterConjunction.AND,
  conditions: [
    {
      fieldId: 'status',
      operator: univerAPI.Enum.BaseFilterOperator.IS,
      operand: 'In progress',
    },
  ],
})

view.setSort([
  { fieldId: 'dueDate', direction: univerAPI.Enum.BaseSortDirection.ASC },
])
```

## 필드 표시 여부 및 너비

```ts
view.setFieldVisible('internalNotes', false)
view.setFieldWidth('title', 280)
```
