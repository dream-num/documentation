보기는 테이블이 사용자에게 제시하는 방법을 결정합니다. 그것은 숨기고 주문 필드, 필터, 정렬 및 그룹 레코드를 숨길 수 있으며, 보기 유형이 그리드, 칸반 보드, 달력, 갠트 차트 또는 갤러리로 렌더링해야하는 구성을 보유하고 있습니다.

## 뷰 스냅샷

| 속성 | 유형 | 설명 |
| --- | --- | --- |
| id | `string` | 뷰 ID입니다. |
| tableId | `string` | 소유 테이블의 ID. |
| name | `string` | 뷰 이름입니다. |
| type | `BaseViewType` | `grid`, `kanban`, `calendar`, `gantt`, `gallery`, `pivot`. |
| fieldOrder? | `string[]` | 이 뷰의 필드 순서입니다. |
| fieldSettings? | `Record\<string, IViewFieldSetting\>` | 가시성, 폭 및 필드당 카드 설정. |
| filter? | `IFilterConfig | null` | 필터 구성을 위한 보기. |
| sort? | `ISortConfig[]` | 정렬 규칙입니다. |
| group? | `IGroupConfig[]` | 그룹 규칙입니다. |
| config | `ViewSpecificConfig` | 보기 유형에 특정한 윤곽. |

## 뷰 유형

| 유형 | 사용 사례 |
| --- | --- |
| `grid` | 스프레드 시트 스타일 테이블의 편집. |
| `kanban` | 선택, 사용자, 그룹, 텍스트 또는 날짜 필드를 기준으로 그룹화된 카드입니다. |
| `calendar` | 날짜 필드에 의해 배치된 기록. |
| `gantt` | 시작일과 종료일 필드를 사용하는 타임라인 계획입니다. |
| `gallery` | 주로 시각 또는 대량의 콘텐츠를 포함 하는 레코드에 대 한 카드 레이아웃. |
| `pivot` | 집계와 차트에 대시보드 플러그인이 필요합니다. |

## 뷰 생성

```ts
const view = table.createView('Kanban', univerAPI.Enum.BaseViewType.Kanban)
```

## 필터링 및 정렬 구성

```ts
view.setFilter({
  conjunction: univerAPI.Enum.BaseFilterConjunction.AND,
  conditions: [
    {
      fieldId: 'status',
      operator: univerAPI.Enum.BaseFilterOperator.IS,
      operand: 'In progress',
    },
  ],
})

view.setSort([
  { fieldId: 'dueDate', direction: univerAPI.Enum.BaseSortDirection.ASC },
])
```

## 필드 표시 여부 및 너비

```ts
view.setFieldVisible('internalNotes', false)
view.setFieldWidth('title', 280)
```
