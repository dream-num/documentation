## IBaseSnapshot

`IBaseSnapshot` 是 Univer Bases 写入存储时使用的格式。一个快照描述一个 Base 单元：表及其顺序、架构版本、时间戳，以及可选的修订信息。

### 属性

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| id | `string` | Base 单元的唯一 ID。 |
| name | `string` | Base 名称。 |
| schemaVersion | `number` | 快照架构版本。 |
| tables | `Record\<string, ITableSnapshot\>` | 以表 ID 为键的表。 |
| tableOrder | `string[]` | 按顺序排好的表 ID 列表。 |
| createdAt | `number` | 创建时间戳。 |
| updatedAt | `number` | 最后一次更新的时间戳。 |
| createdBy? | `string` | 创建者 ID。 |
| rev? | `number` | 持久化层或协作层使用的可选修订值。 |

## 最小快照

```ts
const baseSnapshot = {
  id: 'base-1',
  name: 'Product tracker',
  schemaVersion: 1,
  tableOrder: ['tasks'],
  tables: {
    tasks: {
      id: 'tasks',
      name: 'Tasks',
      primaryFieldId: 'title',
      fieldOrder: ['title', 'status'],
      fields: {
        title: { id: 'title', name: 'Title', type: 'text', config: {} },
        status: { id: 'status', name: 'Status', type: 'singleSelect', config: {} },
      },
      recordOrder: ['rec-1'],
      records: {
        'rec-1': {
          id: 'rec-1',
          values: { title: 'Write docs', status: 'In progress' },
          orderKey: 'a0',
          createdAt: Date.now(),
          updatedAt: Date.now(),
        },
      },
      views: {},
      viewOrder: [],
    },
  },
  createdAt: Date.now(),
  updatedAt: Date.now(),
}
```

## 用途

`IBaseSnapshot` 适用于以下场景：

1. 创建 `UniverInstanceType.UNIVER_BASE` 单元。
2. 持久化和恢复结构化数据。
3. 准备供服务器端处理的数据。
4. 在协作服务和导入导出服务之间传输数据。

<Callout type="warning">
  快照对象属于持久化数据。Base 运行之后，应通过 Facade API 操作，不要直接修改快照对象。
</Callout>

## 保存和恢复

调用 Facade 的 `save()` 进行保存，已注册插件的资源也会一并包含，例如仪表盘和本地评论。示例中的 `saveToBackend` 代表应用自身的保存函数：

```ts
const base = univerAPI.getActiveBase()
if (!base) throw new Error('Open a Base first')
await saveToBackend(base.save())
```

在新的编辑器实例中，先注册同一批插件，再通过 `univerAPI.createBase(savedSnapshot)` 恢复。不要只保存 `tables`，也不要直接修改运行中模型的快照。
