Eine Basis enthält geordnete Tabellen. Jede Tabelle enthält Felddefinitionen, Datensatzwerte, optionale Zellendatenmatrizen, Ressourcen, Ansichten und Indizes, die von der Rendering- und Suchlogik verwendet werden.

Neue Tabellen beginnen mit null Datensätzen; fügen Sie Datensätze explizit über die Facade API oder importierte Snapshot-Daten hinzu.

## Tabellen-Snapshot

| Eigenschaft | Typ | Beschreibung |
| --- | --- | --- |
| id | `string` | Tabellen-ID. |
| name | `string` | Tabellenname. |
| fields | `Record\<string, IFieldSnapshot\>` | Felddefinitionen, verschlüsselt nach Feld-ID. |
| fieldOrder | `string[]` | Sortiert Liste der Feld-IDs. |
| records | `Record\<string, IRecordSnapshot\>` | Nach Datensatz-IDs verschlüsselte Datensatzdaten. |
| recordOrder? | `string[]` | Geordnete Liste der Datensatz-IDs. |
| primaryFieldId | `string` | Primäre Feld-ID. |
| views | `Record\<string, IViewSnapshot\>` | Nach Ansichts-IDs verschlüsselte Ansichten. |
| viewOrder | `string[]` | Geordnete Liste der Ansichts-IDs. |
| resources? | `IBaseResources` | Gemeinsame Option, Mitglied und Anhang Ressourcen. |

## Feld-Snapshot

| Eigenschaft | Typ | Beschreibung |
| --- | --- | --- |
| id | `string` | Feld-ID. |
| name | `string` | Feldname. |
| description? | `string` | Feldbeschreibung. |
| type | `FieldType` | Feldtyp. |
| config | `Record\<string, unknown\>` | Typspezifische Feldkonfiguration. |
| defaultValue? | `BaseCellValue` | Standardwert für neue Datensätze. |
| system? | `boolean` | Ob das Feld vom System verwaltet wird. |
| readonly? | `boolean` | Ob Werte vorhanden sind schreibgeschützt. |

## Feldtypen

Zu den allgemeinen Feldtypen gehören `text`, `number`, `currency`, `progress`, `rating`, `checkbox`, `singleSelect`, `multiSelect`, `person`, `group`, und `updatedBy`.

Verwenden Sie beim Erstellen von Anwendungscode Fassadenaufzählungen:

```ts
const field = table.addField({
  name: 'Due date',
  type: univerAPI.Enum.BaseFieldTypeEnum.Date,
})
```

## Snapshot aufzeichnen

| Eigenschaft | Typ | Beschreibung |
| --- | --- | --- |
| id | `string` | Datensatz-ID. |
| values | `Record\<string, BaseCellValue\>` | Werte verschlüsselt durch Feld-ID. |
| orderKey | `string` | Stabiler Bestellschlüssel. |
| createdAt | `number` | Erstellungszeitstempel. |
| updatedAt | `number` | Aktualisierungszeitstempel. |
| createdBy? | `string` | Ersteller-ID. |
| updatedBy? | `string` | Letzter Aktualisierer id. |

## Fassadenbeispiel

```ts
const table = base.createTable({ name: 'Tasks' })
const title = table.addField({ name: 'Title', type: univerAPI.Enum.BaseFieldTypeEnum.Text })
const status = table.addField({ name: 'Status', type: univerAPI.Enum.BaseFieldTypeEnum.SingleSelect })

const record = table.addRecord({
  values: {
    [title.getId()]: 'Write guide',
    [status.getId()]: 'In progress',
  },
})
```
