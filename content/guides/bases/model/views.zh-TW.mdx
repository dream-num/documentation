檢視決定一張表如何呈現給使用者。它可以隱藏欄位或調整欄位順序，也可以篩選、排序和分組記錄；網格、看板、日曆、甘特圖和畫廊等檢視型別渲染所需的配置，同樣存放在檢視裡。

## 檢視快照

| 屬性 | 類型 | 說明 |
| --- | --- | --- |
| id | `string` | 檢視 ID。 |
| tableId | `string` | 所屬資料表的 ID。 |
| name | `string` | 檢視名稱。 |
| type | `BaseViewType` | `grid`, `kanban`, `calendar`, `gantt`, `gallery`, `pivot`. |
| fieldOrder? | `string[]` | 該檢視裡的欄位順序。 |
| fieldSettings? | `Record\<string, IViewFieldSetting\>` | 各欄位的可見性、寬度與卡片設定。 |
| filter? | `IFilterConfig | null` | 該檢視的篩選配置。 |
| sort? | `ISortConfig[]` | 排序規則。 |
| group? | `IGroupConfig[]` | 分組規則。 |
| config | `ViewSpecificConfig` | 此檢視類型專用的設定。 |

## 檢視類型

| 類型 | 使用情境 |
| --- | --- |
| `grid` | 以電子表格的形式編輯一張表。 |
| `kanban` | 按選擇、人員、分組、文字或日期欄位對卡片分組。 |
| `calendar` | 按日期欄位放置記錄。 |
| `gantt` | 根據開始日期和結束日期欄位規劃時間線。 |
| `gallery` | 用卡片版面配置展示以視覺內容為主或內容較多的記錄。 |
| `pivot` | 透過[儀表盤外掛](/guides/bases/features/dashboard)生成彙總和圖表。 |

## 建立檢視

```ts
const view = table.createView('Kanban', univerAPI.Enum.BaseViewType.Kanban)
```

## 設定篩選與排序

```ts
view.setFilter({
  conjunction: univerAPI.Enum.BaseFilterConjunction.AND,
  conditions: [
    {
      fieldId: 'status',
      operator: univerAPI.Enum.BaseFilterOperator.IS,
      operand: 'In progress',
    },
  ],
})

view.setSort([
  { fieldId: 'dueDate', direction: univerAPI.Enum.BaseSortDirection.ASC },
])
```

## 欄位可見性與寬度

```ts
view.setFieldVisible('internalNotes', false)
view.setFieldWidth('title', 280)
```
