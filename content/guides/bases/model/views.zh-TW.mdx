---
title: 檢視
icon: 'Kanban'
---

檢視用來描述資料表呈現給使用者的方式。檢視可以隱藏欄位或調整欄位順序、篩選記錄、排序記錄、將記錄分組，並為網格、看板、日曆、甘特圖或圖庫的呈現方式定義各類型專用的設定。

## 檢視快照

| 屬性 | 類型 | 說明 |
| --- | --- | --- |
| id | `string` | 檢視 ID。 |
| tableId | `string` | 所屬資料表的 ID。 |
| name | `string` | 檢視名稱。 |
| type | `ViewType` | `grid`、`kanban`、`calendar`、`gantt` 或 `gallery`。 |
| fieldOrder? | `string[]` | 此檢視中的欄位順序。 |
| fieldSettings? | `Record\<string, IViewFieldSetting\>` | 各欄位的可見性、寬度與卡片設定。 |
| filter? | `IFilterConfig | null` | 檢視的篩選設定。 |
| sort? | `ISortConfig[]` | 排序規則。 |
| group? | `IGroupConfig[]` | 分組規則。 |
| config | `ViewSpecificConfig` | 此檢視類型專用的設定。 |

## 檢視類型

| 類型 | 使用情境 |
| --- | --- |
| `grid` | 以類似試算表的方式編輯資料表。 |
| `kanban` | 依選項、人員、群組、文字或日期欄位將卡片分組。 |
| `calendar` | 依日期欄位安排記錄的位置。 |
| `gantt` | 使用開始與結束日期欄位規劃時間軸。 |
| `gallery` | 以卡片版面呈現著重視覺或包含大量內容的記錄。 |

## 建立檢視

```ts
const view = table.createView('Kanban', univerAPI.Enum.BaseViewType.Kanban)
```

## 設定篩選與排序

```ts
view.setFilter({
  conjunction: univerAPI.Enum.BaseFilterConjunction.AND,
  conditions: [
    {
      fieldId: 'status',
      operator: univerAPI.Enum.BaseFilterOperator.IS,
      operand: 'In progress',
    },
  ],
})

view.setSort([
  { fieldId: 'dueDate', direction: univerAPI.Enum.BaseSortDirection.ASC },
])
```

## 欄位可見性與寬度

```ts
view.setFieldVisible('internalNotes', false)
view.setFieldWidth('title', 280)
```
