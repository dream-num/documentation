## IBaseSnapshot

`IBaseSnapshot` — это формат хранения данных, который используется в Univer Bases. Он описывает один экземпляр Base, включая таблицы, порядок таблиц, версию схемы, временные метки и необязательные метаданные ревизии.

### Свойства

| Свойство | Тип | Описание |
| --- | --- | --- |
| id | `string` | Уникальный идентификатор экземпляра Base. |
| name | `string` | Название Base. |
| schemaVersion | `number` | Версия схемы снимка. |
| tables | `Record\<string, ITableSnapshot\>` | Таблицы, где ключом служит идентификатор таблицы. |
| tableOrder | `string[]` | Упорядоченный список идентификаторов таблиц. |
| createdAt | `number` | Временная метка создания. |
| updatedAt | `number` | Временная метка обновления. |
| createdBy? | `string` | Идентификатор создателя. |
| rev? | `number` | Необязательный номер ревизии, используемый уровнями хранения данных или совместной работы. |

## Минимальный снимок

```ts
const baseSnapshot = {
  id: 'base-1',
  name: 'Product tracker',
  schemaVersion: 1,
  tableOrder: ['tasks'],
  tables: {
    tasks: {
      id: 'tasks',
      name: 'Tasks',
      primaryFieldId: 'title',
      fieldOrder: ['title', 'status'],
      fields: {
        title: { id: 'title', name: 'Title', type: 'text', config: {} },
        status: { id: 'status', name: 'Status', type: 'singleSelect', config: {} },
      },
      recordOrder: ['rec-1'],
      records: {
        'rec-1': {
          id: 'rec-1',
          values: { title: 'Write docs', status: 'In progress' },
          orderKey: 'a0',
          createdAt: Date.now(),
          updatedAt: Date.now(),
        },
      },
      views: {},
      viewOrder: [],
    },
  },
  createdAt: Date.now(),
  updatedAt: Date.now(),
}
```

## Использование

`IBaseSnapshot` используется главным образом для следующих задач:

1. Создание экземпляра `UniverInstanceType.UNIVER_BASE`.
2. Сохранение и восстановление структурированных данных.
3. Подготовка данных для обработки на стороне сервера.
4. Передача данных между сервисами совместной работы и импорта/экспорта.

<Callout type="warning">
  Объекты снимков содержат данные для хранения. После запуска Base вместо непосредственного изменения объекта снимка используйте API Facade.
</Callout>
