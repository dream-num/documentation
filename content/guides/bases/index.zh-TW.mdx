## Univer Bases 是什麼

Univer Bases 是 Univer Pro 中的結構化資料產品。它適合用來做輕量資料庫、內容流程、審批台帳、CRM 表、內部營運工具等應用。這裡的核心物件不是工作表儲存格，而是一組可以按欄位、記錄和視圖組織的資料。

Bases 在執行時是獨立的 Univer unit。核心套件負責表、欄位、記錄、視圖、公式計算、搜尋、命令和協同 mutation；UI 套件負責獨立工作台和內建視圖的渲染。

## 什麼時候使用 Bases

如果使用者需要欄位類型、篩選、排序、分組，以及基於同一份資料切換不同視圖，可以從 Bases 開始。如果使用者主要編輯試算表儲存格，請看 [Univer Sheets](/guides/sheets)。如果使用者需要自由畫布，請看 [Univer Boards](/guides/boards)。

## 安裝套件

```bash
pnpm add @univerjs-pro/bases @univerjs-pro/bases-ui
```

## 套件結構

- `@univerjs-pro/bases`：Base 資料模型、表/欄位/記錄/視圖命令、JSON1 協同 mutation、公式整合、欄位外掛、搜尋、Facade API 與 `UniverBasesPlugin`
- `@univerjs-pro/bases-ui`：獨立工作台、Grid/Calendar/Kanban/Gallery/Gantt 視圖、欄位編輯器、記錄詳情面板、工具列和右鍵選單操作、渲染模組與 `UniverBasesUIPlugin`

## 註冊外掛

下面只展示 Bases 相關的註冊程式碼。完整應用還需要 Univer core、渲染引擎、UI、License、公式引擎等通用外掛。

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/bases/facade'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```
