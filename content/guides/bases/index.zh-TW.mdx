## Univer Bases 是什麼

Univer Bases 是 Univer Pro 的結構化資料產品，專為以一組記錄（而非工作表格線）為主要物件的應用程式而設計，適合用於輕量型資料庫、內容工作流程、核准追蹤工具、CRM 類型的資料表和內部工具。

Bases 是獨立的 Univer 單元類型。核心套件負責資料表、欄位、記錄、檢視、公式計算、搜尋、命令和協作變更；UI 套件則負責呈現獨立工作區和內建檢視。


## 瀏覽器相容性

Univer 的編譯目標是 Chrome 88，但這並不意味著 Univer 能夠完全支援所有主流環境。我們會盡力確保 Univer 在以下瀏覽器和 Node.js 環境中能夠正常運行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer 依賴 `Intl.Segmenter`，如果你的瀏覽器或執行環境暫不支援它，請先補上對應的 polyfill。我們推薦使用
  `@formatjs/intl-segmenter`。
</Callout>

如果遇到無法相容的情況，請先借助對應的 polyfill 來解決，如果仍然無法解決，請[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 相容性

<Callout type="warning">
  以下僅適用於在 Node.js 環境中運行 Univer 的情況，並不適用於那些基於 Node.js 使用建構工具在瀏覽器中運行 Univer 的情況。
</Callout>

Univer 可以在 Node.js 環境中運行，支援的版本為 v18.17.0 及之後的版本。

## 主要功能

- **資料表、欄位與記錄**：在每個資料表中儲存具類型的欄位與有序記錄。
- **多種檢視**：透過網格、看板、行事曆、甘特圖與圖庫檢視呈現同一組記錄。
- **命令驅動的編輯**：讓模型變更統一經過命令層，並提供權限及選用歷程與協同作業整合所需的掛鉤。
- **公式欄位**：將 Base 欄位接入 Univer 公式計算流程。
- **瀏覽器工作區**：算繪檢視，並提供選取、編輯、剪貼簿、捲動與面板功能。
- **持久化**：無需直接修改執行中的快照，即可建立、還原與儲存 `IBaseSnapshot`。

## 前置知識

儘管我們已經盡力使得文件對新手也易於理解，但是我們必須假設你在開始閱讀之前已經瞭解了一些基礎知識，以便我們的文件可以專注於 Univer。

為了充分利用我們的文件，建議你對 JavaScript 及其生態系統有基本的瞭解。

如果你有興趣在 Node.js 上執行 Univer，你還應該對 Node.js 有基本的瞭解。

如果你想嘗試高階功能並部署 Univer Server，我們建議你對 Linux、Docker 和 Docker Compose（或 Kubernetes）有基本的瞭解。
