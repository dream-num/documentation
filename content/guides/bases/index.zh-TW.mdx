## Univer Bases 是什麼

Univer Bases 是 Univer Office SDK 中的結構化資料產品。如果應用圍繞一組記錄而不是工作表網格來組織，Univer Bases 適用於輕量級資料庫、內容工作流、審批跟蹤器、CRM 風格的表格和內部工具。

Bases 屬於 [Web SDK](/guides/sheets)，嵌入式編輯器和無介面內容處理都由 Web SDK 提供。協同和檔案交換模組由 [Server SDK](/server) 提供，[AI SDK](/ai) 則讓 Agent 能夠訪問記錄。

Bases 是 Web SDK 中一種獨立的單元型別。核心包負責表、欄位、記錄、檢視、公式計算、搜尋、命令和協同變更，UI 包負責渲染獨立工作臺和內建檢視。

## 瀏覽器相容性

Web SDK 的編譯目標是 Chrome 88，但這並不意味著所有主流環境都能獲得完整支援。我們力求支援以下瀏覽器版本：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK 依賴 `Intl.Segmenter`。瀏覽器或執行時環境不支援它時，需要先新增對應的 polyfill，推薦 `@formatjs/intl-segmenter`。
</Callout>

如果遇到相容問題，請先嚐試對應的 polyfill；如果仍無法解決，請[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 相容性

<Callout type="warning">
  本節只涉及在 Node.js 環境中執行 Web SDK，不適用於使用基於 Node.js 的建置工具在瀏覽器中執行 Web SDK 的情況。
</Callout>

Web SDK 可在 Node.js v18.17.0 及更高版本中執行。

## 主要功能

| 功能 | 用途 |
| --- | --- |
| [欄位與附件](/guides/bases/features/core/fields) | 文字、數字、選擇、成員、日期、附件等欄位。 |
| [記錄、關聯與層級](/guides/bases/features/core/records) | 批次編輯、本地分頁、跨表關聯和父子記錄。 |
| [檢視](/guides/bases/features/core/views) | 網格、看板、日曆、甘特圖、畫廊，以及篩選、排序、分組和條件著色。 |
| [公式](/guides/bases/features/core/formulas) | 欄位計算，以及顯式配置的跨文件引用。 |
| [權限](/guides/bases/features/core/permissions) | Base、表、欄位、記錄和檢視的編輯權限。 |
| [匯入匯出](/guides/bases/features/import-export) | 匯入 Excel、CSV、TSV，匯出表資料；需要轉換後端。 |
| [儀表盤與透視檢視](/guides/bases/features/dashboard) | 彙總表資料，並組合圖表、篩選控制元件、文字和圖片。 |
| [評論](/guides/bases/features/thread-comment) | 圍繞記錄展開討論；共享討論需要評論服務。 |
| [協同編輯](/guides/bases/features/collaboration) | 多人編輯同一份 Base；需要協同服務。 |
| [歷史記錄](/guides/bases/features/edit-history) | 檢視伺服器端儲存的版本和差異。 |

## 如何使用這些文件

文件導航欄位於左側。頁面按從基礎到高階的順序排列，可以按順序閱讀，也可以直接跳轉到與使用場景匹配的章節。側邊欄頂部還可切換到 Univer Bases 的文件。

右側是當前頁面的大綱，可在各節之間快速跳轉。如需查詢某個頁面，可以使用頂部搜尋欄或 Ctrl+K / Cmd+K 快捷鍵。

請先閱讀[快速開始](/guides/bases/getting-started/installation)指南。

## 前置知識

文件力求易讀，但仍假設讀者具備一定的基礎知識，以便內容集中在 Web SDK 上。
