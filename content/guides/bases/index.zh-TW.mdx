## Univer Bases 是什麼

Univer Bases 是 Univer Pro 的結構化資料產品，專為以一組記錄（而非工作表格線）為主要物件的應用程式而設計，適合用於輕量型資料庫、內容工作流程、核准追蹤工具、CRM 類型的資料表和內部工具。

Bases 是獨立的 Univer 單元類型。核心套件負責資料表、欄位、記錄、檢視、公式計算、搜尋、命令和協作變更；UI 套件則負責呈現獨立工作區和內建檢視。

## 什麼時候使用 Bases

當使用者需要具備欄位類型的結構化記錄，並想要篩選、排序、分組，或以不同方式呈現同一份資料時，適合使用 Bases。如果使用者主要編輯試算表中的儲存格，請使用 [Univer Sheets](/guides/sheets)；如果需要自由形式的畫布，請使用 [Univer Boards](/guides/boards)。

## 安裝套件

```bash
pnpm add @univerjs-pro/bases @univerjs-pro/bases-ui
```

## 套件一覽

- `@univerjs-pro/bases`：Bases 資料模型、資料表/欄位/記錄/檢視命令、JSON1 協作變更、公式整合、欄位外掛程式、搜尋、Facade API，以及 `UniverBasesPlugin`
- `@univerjs-pro/bases-ui`：獨立工作區、表格/行事曆/看板/藝廊/甘特圖檢視、欄位編輯器、記錄詳細資料面板、工具列和內容功能表操作、呈現模組，以及 `UniverBasesUIPlugin`

## 註冊外掛

以下程式碼片段只顯示 Bases 相關的設定。完整的應用程式還需要共用的 Univer 核心、呈現引擎、UI、授權和公式引擎外掛程式。

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/bases/facade'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```
