## Univer Bases とは

Univerベースは、Univer Office SDKの構成されたデータ製品です。 これは、ワークシートグリッドではなく、レコードのセットの周りに整理されたアプリケーションのために意図されています:軽量データベース、コンテンツワークフロー、承認トラッカー、CRMスタイルのテーブル、内部ツール。

ベースは[Web SDK](/guides/sheets)の一部であり、組み込みエディタとヘッドレスコンテンツ処理を処理します。 [Server SDK](/server)は、コラボレーションとファイル交換用のモジュールを提供し、[AI SDK](/ai)ではレコードへのエージェントアクセスを提供します。

ベースは、Web SDKの別々のユニットタイプです。コアパッケージはテーブル、フィールド、レコード、ビュー、フォーミュラ計算、検索、コマンド、コラボレーションミューテーションを所有しています。UIパッケージはスタンドアローンのワークベンチと組み込みのビューをレンダリングします。

## ブラウザ互換性

Web SDKはChrome 88ターゲットとコンパイルしますが、すべての主流環境が完全にサポートされています。次のブラウザバージョンは、サポートを目的とするものです。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDKは`Intl.Segmenter`に依存しています。お使いのブラウザやランタイム環境がサポートされていない場合は、マッチングポリフィルを最初に追加してください。 `@formatjs/intl-segmenter`をお勧めします。
</Callout>

互換性の問題が発生した場合は、最初に一致するポリフィルを試してください。 問題が主張している場合は、[課題を提出する](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 互換性

<Callout type="warning">
  このセクションでは、ランニングのみがカバーされます。 Web SDK で、 Node.js 環境。Node.js ベースのビルドツールを使用して実行するときは適用されません。 Web SDK ブラウザで。
</Callout>

Web SDKはNode.js v18.17.0以降で動作します。

## ドキュメントの読み方

ドキュメントのナビゲーションは左に表示されます。ページは基本から上級に注文されますので、アプリケーションを構築したり、使用例に合ったページに直接アクセスしたりすることができます。また、サイドバーの上部にあるUniverベースドキュメントに切り替えることができます。

現在のページのセクション間で右上のコンテンツの表を移動します。ページをすばやく見つけるには、検索バーをトップまたはCtrl + K / Cmd + Kショートカットで使用してください。

[クイックスタート](/guides/bases/getting-started/installation)ガイドから始めましょう。

## 前提知識

ドキュメントはアプローチ可能であることを目指していますが、Web SDKにページが集中できるように、ベースラインの知識をいくつか想定しています。

JavaScriptとその生態系の基本的な理解と最も有用です。 Node.jsでWeb SDKを実行する場合は、Node.jsの基本理解も役立ちます。
