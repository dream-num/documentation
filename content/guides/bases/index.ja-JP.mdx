## Univer Bases とは

Univer Bases は Univer Pro の構造化データ製品です。軽量データベース、コンテンツワークフロー、承認台帳、CRM 風のテーブル、社内業務ツールなどに向いています。中心になるのはワークシートのセルではなく、フィールド、レコード、ビューで整理されたデータです。

Bases は実行時に独立した Univer unit として作成します。コアパッケージはテーブル、フィールド、レコード、ビュー、数式計算、検索、コマンド、協調 mutation を担当します。UI パッケージはスタンドアロンのワークベンチと組み込みビューをレンダリングします。

## Bases を使う場面

ユーザーがフィールド型、フィルター、ソート、グループ化、同じデータに対する複数ビューを必要とする場合は Bases から始めます。主な操作がスプレッドシートのセル編集であれば [Univer Sheets](/guides/sheets)、自由なキャンバスが必要であれば [Univer Boards](/guides/boards) を参照してください。

## パッケージのインストール

```bash
pnpm add @univerjs-pro/bases @univerjs-pro/bases-ui
```

## パッケージ構成

- `@univerjs-pro/bases`: Base データモデル、テーブル/フィールド/レコード/ビューのコマンド、JSON1 協調 mutation、数式統合、フィールドプラグイン、検索、Facade API、`UniverBasesPlugin`
- `@univerjs-pro/bases-ui`: スタンドアロンワークベンチ、Grid/Calendar/Kanban/Gallery/Gantt ビュー、フィールドエディター、レコード詳細パネル、ツールバーとコンテキストメニュー操作、レンダーモジュール、`UniverBasesUIPlugin`

## プラグイン登録

以下は Bases に関係する登録部分だけです。実際のアプリケーションでは Univer core、レンダーエンジン、UI、License、数式エンジンなどの共通プラグインも必要です。

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/bases/facade'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```
