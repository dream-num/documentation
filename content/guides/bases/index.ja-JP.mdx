## Univer Bases とは

Univer Bases は、Univer Office SDK の構造化データ製品です。ワークシートのグリッドではなく、一連のレコードを主に扱うアプリケーション向けに設計されています。軽量なデータベース、コンテンツワークフロー、承認管理、CRM 形式のテーブル、社内ツールなどに適しています。

Univer Office SDK は、埋め込みエディターとヘッドレスのコンテンツ処理を提供する [Web SDK](/guides/sheets)、共同編集とファイルのインポート・エクスポートを提供する [Server SDK](/server)、エージェントのワークフローを提供する [AI SDK](/ai) で構成されます。

Bases は独立した Web SDK unit type です。コアパッケージは、テーブル、フィールド、レコード、ビュー、数式計算、検索、コマンド、コラボレーション mutation を管理します。UI パッケージは、スタンドアロンのワークベンチと組み込みビューをレンダリングします。


## ブラウザ互換性

Web SDK は Chrome 88 をターゲットとしてコンパイルされていますが、これはすべての主流環境を完全にサポートすることを保証するものではありません。Web SDK が以下のブラウザおよび Node.js 環境で問題なく動作するよう努めています。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK は `Intl.Segmenter`
  に依存しています。お使いのブラウザまたはランタイム環境でこれがサポートされていない場合は、先に対応するポリフィルを追加してください。`@formatjs/intl-segmenter`
  の利用を推奨します。
</Callout>

互換性に関する問題が発生した場合、まずは適切なポリフィルを使用して解決を試みてください。それでも問題が解決しない場合は、[Issue の提出](https://github.com/dream-num/univer/issues/new/choose) をご検討ください。

## Node.js 互換性

<Callout type="注意事項">
  注意：これは Web SDK を Node.js 環境で実行する場合にのみ適用され、Node.js
  ベースのビルドツールを使ってブラウザで実行する場合には該当しません。
</Callout>

Web SDK は Node.js 環境でも動作可能で、v18.17.0 以降のバージョンをサポートしています。

## 主な機能

- **テーブル、フィールド、レコード**：各テーブルに型付きフィールドと順序付きレコードを保存します。
- **複数のビュー**：同じレコードをグリッド、Kanban、カレンダー、Gantt、ギャラリーの各ビューで表示します。
- **コマンド駆動の編集**：モデル変更を 1 つのコマンド層に集約し、権限と、任意の履歴・コラボレーション統合用フックを提供します。
- **数式フィールド**：Base のフィールドを Web SDK の数式計算パイプラインに接続します。
- **ブラウザーワークベンチ**：ビューを描画し、選択、編集、クリップボード、スクロール、パネルを提供します。
- **永続化**：実行中のスナップショットを直接変更せずに `IBaseSnapshot` を作成、復元、保存します。

## ドキュメントの読み方

画面左側にドキュメントのナビゲーションがあります。ページは基礎から応用へ順に構成されているため、その順で進めてもよいですし、必要な章だけを選んで読むこともできます。サイドバー上部で Univer Bases のドキュメントに切り替えることもできます。

画面右側には現在ページの目次が表示されます。目的のページを素早く見つけたい場合は、上部の検索バーや検索ショートカット（Ctrl+K または Cmd+K）を利用してください。

まずは [クイックスタート](/guides/bases/getting-started/installation) から始めることをおすすめします。

## 前提知識

ドキュメントは初心者にも分かりやすく設計していますが、Web SDK に集中できるよう、読み始める前にいくつかの基礎知識があることを前提としています。

効率よく理解するために、JavaScript とそのエコシステムの基本的な理解をおすすめします。

Node.js 上で Web SDK を動かしたい場合は、Node.js の基礎知識も必要です。
