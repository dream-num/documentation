## Univer Bases とは

Univer Bases は、Univer Pro の構造化データ製品です。ワークシートのグリッドではなく、一連のレコードを主に扱うアプリケーション向けに設計されています。軽量なデータベース、コンテンツワークフロー、承認管理、CRM 形式のテーブル、社内ツールなどに適しています。

Bases は独立した Univer unit type です。コアパッケージは、テーブル、フィールド、レコード、ビュー、数式計算、検索、コマンド、コラボレーション mutation を管理します。UI パッケージは、スタンドアロンのワークベンチと組み込みビューをレンダリングします。

## Bases を使う場面

フィールド型、フィルターを適用したビュー、並べ替え、グループ化、同じデータを異なる形式で表示する機能を備えた構造化レコードが必要な場合は、Bases を使用します。主にスプレッドシートのセルを編集する場合は [Univer Sheets](/guides/sheets) を使用してください。自由形式のキャンバスが必要な場合は [Univer Boards](/guides/boards) を使用してください。

## パッケージのインストール

```bash
pnpm add @univerjs-pro/bases @univerjs-pro/bases-ui
```

## パッケージ構成

- `@univerjs-pro/bases`: Base データモデル、テーブル／フィールド／レコード／ビューのコマンド、JSON1 コラボレーション mutation、数式の統合、フィールドプラグイン、検索、Facade API、`UniverBasesPlugin`
- `@univerjs-pro/bases-ui`: スタンドアロンワークベンチ、グリッド／カレンダー／カンバン／ギャラリー／ガントビュー、フィールドエディター、レコード詳細パネル、ツールバーとコンテキストメニューの操作、レンダリングモジュール、`UniverBasesUIPlugin`

## プラグイン登録

以下のスニペットは、セットアップのうち Bases 固有の部分を示しています。完全なアプリケーションには、共通の Univer core、レンダリングエンジン、UI、ライセンス、数式エンジンの各プラグインも必要です。

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/bases/facade'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```
