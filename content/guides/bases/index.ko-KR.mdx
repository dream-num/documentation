## Univer Bases란?

Univer Bases는 Univer Pro의 구조화된 데이터 제품입니다. 워크시트 그리드 대신 레코드 집합이 주요 객체인 애플리케이션을 위해 설계되었습니다. 경량 데이터베이스, 콘텐츠 워크플로, 승인 추적기, CRM 형식 테이블, 내부 도구에 적합합니다.

Bases는 독립적인 Univer 단위 유형입니다. 핵심 패키지는 테이블, 필드, 레코드, 뷰, 수식 계산, 검색, 명령, 협업 변형을 담당합니다. UI 패키지는 독립형 워크벤치와 기본 제공 뷰를 렌더링합니다.


## 브라우저 호환성

Univer는 Chrome 88을 대상으로 컴파일되지만, 이것이 모든 주요 환경을 완벽하게 지원한다는 의미는 아닙니다. Univer가 다음 브라우저 및 Node.js 환경에서 원활하게 작동하도록 최선을 다하고 있습니다.

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer는 `Intl.Segmenter`에 의존합니다. 브라우저 또는 런타임 환경에서 이를 지원하지 않는다면 먼저 해당 polyfill을
  추가하세요. `@formatjs/intl-segmenter` 사용을 권장합니다.
</Callout>

호환성 문제가 발생하면 먼저 적절한 polyfill을 사용해 해결해 보세요. 문제가 계속되면 언제든지 [이슈를 제출해 주세요](https://github.com/dream-num/univer/issues/new/choose).

## Node.js 호환성

<Callout type="warning">
  참고: 이 내용은 Node.js 환경에서 Univer를 실행하는 경우에만 적용되며, Node.js 기반 빌드 도구를 사용해 브라우저에서
  Univer를 실행하는 경우에는 적용되지 않습니다.
</Callout>

Univer는 Node.js 환경에서 실행할 수 있으며 v18.17.0 이상 버전을 지원합니다.


## Bases를 사용해야 하는 경우

필드 유형을 갖춘 구조화된 레코드, 필터링된 뷰, 정렬, 그룹화, 동일한 데이터에 대한 다양한 표현이 필요할 때 Bases를 사용하세요. 사용자가 주로 스프레드시트 셀을 편집한다면 [Univer Sheets](/guides/sheets)를 사용하세요. 자유 형식 캔버스가 필요하다면 [Univer Boards](/guides/boards)를 사용하세요.

## 패키지 설치

```bash
pnpm add @univerjs-pro/bases @univerjs-pro/bases-ui
```

## 패키지 구성

- `@univerjs-pro/bases`: Base 데이터 모델, 테이블/필드/레코드/뷰 명령, JSON1 협업 변형, 수식 통합, 필드 플러그인, 검색, Facade API, `UniverBasesPlugin`
- `@univerjs-pro/bases-ui`: 독립형 워크벤치, 그리드/캘린더/칸반/갤러리/간트 뷰, 필드 편집기, 레코드 세부 정보 패널, 도구 모음 및 컨텍스트 메뉴 작업, 렌더링 모듈, `UniverBasesUIPlugin`

## 플러그인 등록

아래 코드 조각은 Bases 관련 설정을 보여줍니다. 완전한 애플리케이션에는 공유 Univer 코어, 렌더링 엔진, UI, 라이선스, 수식 엔진 플러그인도 필요합니다.

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/bases/facade'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```
