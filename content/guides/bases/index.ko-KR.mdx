## Univer Bases란?

Univer Bases는 Univer Office SDK의 구조화된 데이터 제품입니다. 작업표 그리드보다는 기록의 집합을 구성하는 애플리케이션을 위한 것입니다: 경량 데이터베이스, 콘텐츠 워크플로우, 승인 추적기, CRM-style 테이블 및 내부 도구.

Bases는 임베디드 편집기와 헤드리스 콘텐츠 처리를 처리하는 [Web SDK](/guides/sheets)의 일부입니다. [Server SDK](/server)는 협업 및 파일 교환 모듈을 제공하며 [AI SDK](/ai)은 레코드에 대한 에이전트 액세스를 제공합니다.

Bases는 Web SDK의 별도의 단위 유형입니다. 코어 패키지는 테이블, 필드, 레코드, 레이아웃, 공식 계산, 검색, 명령 및 협업 mutations를 소유합니다. UI 패키지는 독립 작업대와 내장 된 레이아웃을 렌더링합니다.

## 브라우저 호환성

Web SDK는 크롬 88 대상과 컴파일하지만, 모든 주류 환경을 완벽하게 지원하지 않습니다. 다음 브라우저 버전은 우리가 지원하는 것을 목표로하는 것입니다:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK는 `Intl.Segmenter`에 의존합니다. 브라우저 또는 실행 환경이 그것을 지원하지 않는 경우, 일치하는 polyfill을 먼저 추가하십시오. 우리는 `@formatjs/intl-segmenter`를 추천합니다.
</Callout>

호환성 문제가 발생하면 일치하는 polyfill을 먼저 시도하십시오. 문제가 지속되면 [자주 묻는 질문](https://github.com/dream-num/univer/issues/new/choose).

## Node.js 호환성

<Callout type="warning">
  이 섹션은 Node.js 환경에서 Web SDK를 실행하는 유일한 커버입니다. 브라우저에서 Web SDK을 실행하는 Node.js 기반 빌드 도구를 사용할 때 적용되지 않습니다.
</Callout>

Web SDK는 Node.js v18.17.0 이상에서 실행됩니다.

## 문서 읽는 방법

문서 탐색은 왼쪽에 나타납니다. 페이지는 기본에서 고급으로 주문되므로 응용 프로그램을 구축하거나 사용 사례와 일치하는 페이지에 직접 이동하면서 주문을 읽을 수 있습니다. 사이드바 상단의 Univer Bases 문서로 전환 할 수도 있습니다.

오른쪽의 내용의 테이블은 현재 페이지의 섹션 사이에 탐색합니다. 페이지를 빠르게 찾기 위해 상단 또는 Ctrl + K / Cmd + K 단축키에서 검색 막대를 사용하십시오.

[빠른 시작](/guides/bases/getting-started/installation) 가이드로 시작하십시오.

## 사전 지식

문서는 접근 할 수 있지만, 페이지가 Web SDK에 집중할 수 있도록 몇 가지 기본 지식을 가정합니다.

페이지는 JavaScript 및 생태계의 기본 이해에 가장 유용합니다. Node.js에서 Web SDK를 실행하는 계획이라면 Node.js의 기본 이해도 도움이됩니다.
