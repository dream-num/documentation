Facade API is the layer that the application uses instead of working with the Bases model directly. It covers routine operations such as creating Bases, tables, fields, records, and views, as well as filters, sorts, groups, selections, and UI navigation.

<Callout type="warning" title="Caution">
  Changes to the Base model are synchronous. UI activation methods return promises and should be awaited.
</Callout>

## Enable facade entries

Import the facade entry for each Bases capability that the application uses:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Create the API object after registering the Univer instance and its required plugins:

```ts
const univerAPI = FUniver.newAPI(univer)
```
