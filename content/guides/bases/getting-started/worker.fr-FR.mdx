Les bases peuvent décharger le calcul de formule vers un Worker[^web-worker] sur RPC. Définissez `notExecuteFormula: true` dans le moteur formule du thread principal, et enregistrez le plugin Bases distant et le moteur de calcul à l'intérieur du Worker.

Cette page commence à partir de [l'installation et l'utilisation de base](/guides/bases/getting-started/installation), et les extraits ci-dessous prolongent cette configuration. Enregistrez les plugins avant de créer ou de charger du contenu, et remplacez un enregistrement existant plutôt que d'enregistrer le même plugin deux fois.

## Thread principal

`UniverRPCMainThreadPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `workerURL` | `string \| URL \| Worker` |  | Connecte l'éditeur à un worker qui effectue le calcul de la formule. |

`UniverProFormulaEnginePlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `notExecuteFormula` | `boolean` | `false` | Saute le calcul de la formule sur le thread principal lorsque le Worker l'exécute. |

```typescript title="main.ts"
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula'
import { UniverRPCMainThreadPlugin } from '@univerjs/rpc'

univer.registerPlugin(UniverRPCMainThreadPlugin, {
  workerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
univer.registerPlugin(UniverProFormulaEnginePlugin, { notExecuteFormula: true })
```

## Point d’entrée du Worker

`UniverLicensePlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenu du fichier de licence côté client. |

```typescript title="worker.ts"
import { UniverRemoteBasesPlugin } from '@univerjs-pro/bases/worker'
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula/worker'
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { LocaleType, Univer } from '@univerjs/core'
import { UniverRPCWorkerThreadPlugin } from '@univerjs/rpc/worker'

const univer = new Univer({ locale: LocaleType.FR_FR })
univer.registerPlugin(UniverLicensePlugin, { license: 'your license.txt' })
univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRemoteBasesPlugin)
univer.registerPlugin(UniverRPCWorkerThreadPlugin)
```

Utilisez un module Worker avec son propre fichier d'entrée, et gardez les versions de paquets identiques dans le Worker et sur le thread principal. Le rendu et l'interaction utilisateur restent sur le think principal.

## Vues croisées et tableaux de bord

Pour exécuter le calcul du pivot du tableau de bord dans le Worker, définissez `notExecuteCalculation: true` sur le thread principal `UniverBaseDashboardPlugin` et enregistrez `UniverRemoteBaseDashboardPlugin` dans le même Worker. Les plugins d'interface utilisateur Dashboard restent sur le thind principal.

`UniverBaseDashboardPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `notExecuteCalculation` | `boolean` |  | Déplace le calcul du pivot du tableau de bord hors du thread principal. Définissez cette option à `true` lors de l'utilisation du plugin d'un tableau de bord distant. |

```typescript title="main.ts"
import { UniverBaseDashboardPlugin } from '@univerjs-pro/bases-dashboard'

univer.registerPlugin(UniverBaseDashboardPlugin, { notExecuteCalculation: true })
```

```typescript title="worker.ts"
import { UniverRemoteBaseDashboardPlugin } from '@univerjs-pro/bases-dashboard/worker'

univer.registerPlugin(UniverRemoteBaseDashboardPlugin)
```

[^web-worker]: Un Web Worker exécute JavaScript hors du thread principal du navigateur et communique par messages. Il ne peut pas accéder directement au DOM : déplacer les calculs ne déplace pas l’interface de l’éditeur.
