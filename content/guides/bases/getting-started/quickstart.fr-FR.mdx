Quatre concepts passent par l'API Bases et sa documentation. Ils couvrent la façon dont une Base est assemblée, stockée, modifiée et contrôlée, et doivent être compris avant d'installer Univer Bases.

## Concepts de base [#basic-concepts]

### Plugins

Univer fournit des fonctionnalités en tant que plugins. `@univerjs-pro/bases` contient le modèle de base, ses commandes, et `UniverBasesPlugin`. `@univerjs-pro/bases-ui` contient le banc de travail autonome et `UniverBasesUIPlugin`. Le plugin de modèle utilise également le moteur de formule, de sorte que les champs de formule participent au pipeline de calcul de base.

Enregistrez uniquement les plugins produits requis par l'application. Le [guide d'installation](/guides/bases/getting-started/installation) fournit la configuration complète du navigateur et les dépendances techniques derrière.

### Snapshot et modèle de données

`IBaseSnapshot` est le format de persistance pour une seule unité de base. Il contient les tables et leur ordre. Chaque table contient des champs, des enregistrements, des vues et l'ordre de chaque collection. Une vue est une projection sur les mêmes enregistrements, de sorte que la commutation des vues ne crée pas une autre copie des données.

Un instantané crée, enregistre ou restaure une base. Une fois que l'unité est en cours d'exécution, ne modifiez pas directement l'objet snapshot. Le schéma est décrit dans [Capture d'image de base](/guides/bases/model/base-snapshot) et [Tableaux, champs et dossiers](/guides/bases/model/tables-fields-records).

### Commande

Les modifications au moment de l'exécution passent par les commandes. Créer une table, mettre à jour un champ, éditer un enregistrement ou modifier une vue à travers la couche de commande ou la couche Facade maintient le modèle, l'interface utilisateur, le défaire/refaire et les chemins de collaboration en synchronisation.

Le code d'application doit utiliser les API Facade. Utilisez les ID de commande directement pour une intégration de niveau inférieur que la Facade n'expose pas.

### Facade API

Facade API fournit un calque objet sur la commande Base et les calques du modèle : Base, table, champ, enregistrement et vue. Importez `@univerjs-pro/bases/facade` pour les opérations du modèle et `@univerjs-pro/bases-ui/facade` dans l'état UI, puis appelez `FUniver.newAPI(univer)` après avoir enregistré les plugins.

Ensuite, lisez [Installation et utilisation de base](/guides/bases/getting-started/installation), puis suivez le [Bases Facade API guide](/guides/bases/getting-started/facade) pour créer et modifier les données de base.
