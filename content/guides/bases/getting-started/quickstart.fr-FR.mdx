## Enregistrer Bases

L’extrait ci-dessous présente la configuration propre à Bases pour un éditeur fonctionnant dans un navigateur. Enregistrez l’environnement d’exécution partagé d’Univer, la licence Pro, les plugins de rendu et d’interface utilisateur ainsi que les dépendances de formules, puis les plugins du modèle et de l’interface utilisateur de Bases.

`@univerjs-pro/bases` crée l’unité `UNIVER_BASE`. `@univerjs-pro/bases-ui` affiche l’espace de travail de base de données autonome.

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
import BasesUIEnUS from '@univerjs-pro/bases-ui/locale/en-US'
import BasesEnUS from '@univerjs-pro/bases/locale/en-US'
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverSheetsFormulaPlugin } from '@univerjs/sheets-formula'
import { UniverUIPlugin } from '@univerjs/ui'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/bases-ui/lib/index.css'

import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(BasesEnUS, BasesUIEnUS),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
})

univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverSheetsFormulaPlugin)

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```

## Configuration minimale

Pour obtenir une version plus légère, commencez par les paquets du modèle et de l’interface utilisateur :

```ts
univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)
univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```

Enregistrez les plugins de formules lorsque vos tables contiennent des champs de formule ou lorsque l’interface utilisateur doit afficher l’état de leur calcul.

## Configuration côté serveur

Sur Node.js, enregistrez le paquet du modèle et omettez les plugins d’interface utilisateur destinés au navigateur :

```ts
univer.registerPlugin(UniverBasesPlugin)
```

Cette approche convient au traitement des instantanés, à la validation côté serveur et aux services de collaboration.
