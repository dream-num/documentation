Avant d’installer Univer Bases, découvrez les quatre concepts employés dans toute son API et sa documentation. Ils décrivent comment une Base est assemblée, enregistrée, modifiée et pilotée.

## Concepts de base [#basic-concepts]

### Plugins

Les fonctionnalités d’Univer sont fournies par des plugins. `@univerjs-pro/bases` apporte le modèle Base, les commandes et `UniverBasesPlugin` ; `@univerjs-pro/bases-ui` apporte l’espace de travail autonome et `UniverBasesUIPlugin`. Le plugin de modèle utilise aussi le moteur de formules Pro afin d’intégrer les champs de formule au calcul de Bases.

N’enregistrez que les plugins nécessaires à votre application. Le [guide d’installation](/guides/bases/getting-started/installation) présente la configuration complète pour le navigateur et ses dépendances techniques.

### Snapshot et modèle de données

`IBaseSnapshot` est le format de persistance d’une unité Base. Il contient les tables et leur ordre ; chaque table contient les champs, les enregistrements, les vues et l’ordre de chaque collection. Les vues sont des projections des mêmes enregistrements : changer de vue ne duplique donc pas les données.

Utilisez un snapshot pour créer, enregistrer ou restaurer une Base. Une fois l’unité démarrée, ne modifiez pas directement l’objet snapshot. Consultez [Base Snapshot](/guides/bases/model/base-snapshot) et [Tables, champs et enregistrements](/guides/bases/model/tables-fields-records) pour le schéma.

### Commande

Les modifications à l’exécution passent par des commandes. Créer une table, mettre à jour un champ, modifier un enregistrement ou changer de vue via les commandes ou la Facade maintient la cohérence du modèle, de l’interface, de l’annulation/rétablissement et de la collaboration.

Préférez la Facade API dans le code applicatif. Utilisez directement les identifiants de commande uniquement pour une intégration de bas niveau absente de la Facade.

### Facade API

La Facade API enveloppe les commandes et le modèle Bases avec des objets représentant une Base, une table, un champ, un enregistrement et une vue. Importez `@univerjs-pro/bases/facade` pour le modèle et `@univerjs-pro/bases-ui/facade` pour l’état de l’interface, puis créez l’API avec `FUniver.newAPI(univer)` après l’enregistrement des plugins.

Continuez avec [Installation et utilisation de base](/guides/bases/getting-started/installation), puis consultez le [guide Facade API de Bases](/guides/bases/getting-started/facade) pour créer et modifier des données.
