Перед установкой Univer Bases ознакомьтесь с четырьмя понятиями, которые используются во всём API и документации. Они описывают, как Base собирается, сохраняется, изменяется и управляется.

## Основные понятия [#basic-concepts]

### Плагины

Возможности Univer поставляются в виде плагинов. `@univerjs-pro/bases` предоставляет модель Base, команды и `UniverBasesPlugin`, а `@univerjs-pro/bases-ui` — автономное рабочее пространство и `UniverBasesUIPlugin`. Плагин модели также использует формульный движок Pro, чтобы формульные поля участвовали в вычислениях Bases.

Регистрируйте только те продуктовые плагины, которые нужны приложению. Полная конфигурация для браузера и её технические зависимости приведены в [руководстве по установке](/guides/bases/getting-started/installation).

### Снимок и модель данных

`IBaseSnapshot` — формат хранения одной единицы Base. Он содержит таблицы и их порядок; каждая таблица содержит поля, записи, представления и порядок каждой коллекции. Представления являются проекциями одних и тех же записей, поэтому переключение представления не создаёт копию данных.

Используйте снимок для создания, сохранения и восстановления Base. После запуска единицы не изменяйте объект снимка напрямую. Схема описана в разделах [Снимок Base](/guides/bases/model/base-snapshot) и [Таблицы, поля и записи](/guides/bases/model/tables-fields-records).

### Команда

Изменения во время выполнения проходят через команды. Создание таблицы, обновление поля, изменение записи или представления через команды либо Facade сохраняет согласованность модели, интерфейса, отмены/повтора и совместной работы.

В прикладном коде предпочитайте Facade API. Используйте идентификаторы команд напрямую только для низкоуровневой интеграции, которой нет в Facade.

### Facade API

Facade API представляет командный слой и модель Bases объектами Base, таблицы, поля, записи и представления. Импортируйте `@univerjs-pro/bases/facade` для операций модели и `@univerjs-pro/bases-ui/facade` для состояния интерфейса, а после регистрации плагинов создайте API через `FUniver.newAPI(univer)`.

Перейдите к разделу [Установка и основные способы использования](/guides/bases/getting-started/installation), затем используйте [руководство по Facade API Bases](/guides/bases/getting-started/facade) для создания и изменения данных.
