Четыре концепции проходят через API Bases и его документацию. Они охватывают то, как База собирается, хранится, изменяется и контролируется, и должны быть поняты перед установкой Баз Univer.

## Основные понятия [#basic-concepts]

### Плагины

Univer предоставляет функции в виде плагинов. `@univerjs-pro/bases` содержит базовую модель, ее команды и `UniverBasesPlugin`. `@univerjs-pro/bases-ui` включает в себя автономный рабочий стол и `UniverBasesUIPlugin` . Плагин модели также использует движок формулы, поэтому поля формул участвуют в конвейере вычислений Base.

Зарегистрируйте только плагины продукта, которые требуются приложению. [Руководство по установке](/guides/bases/getting-started/installation) обеспечивает полную настройку браузера и технические зависимости, стоящие за ним.

### Снимок и модель данных

`IBaseSnapshot` — формат стойкости для одного базового блока. Он содержит таблицы и их порядок. Каждая таблица содержит поля, записи, просмотры и порядок каждой коллекции. Вид — это проекция над одними и теми же записями, поэтому переключение просмотров не создает другую копию данных.

Снимок создает, сохраняет или восстанавливает Базу. Как только устройство запущено, не модифицируйте объект снимка напрямую. Схема описана в [Базовый снимок](/guides/bases/model/base-snapshot) и [Таблицы, поля и записи](/guides/bases/model/tables-fields-records).

### Команда

Изменения во время выполнения проходят через команды. Создание таблицы, обновление поля, редактирование записи или изменение представления через командный уровень или слой Facade сохраняет модель, пользовательский интерфейс, undo/redo и пути совместной работы синхронизированы.

Прикладной код должен использовать API-интерфейсы Facade. Используйте идентификаторы команд непосредственно только для интеграции более низкого уровня, которую Facade не раскрывает.

### Facade API

Facade API обеспечивает объектный слой над уровнями команд и моделей Base: Base, table, field, record, and view. Импорт `@univerjs-pro/bases/facade` для операций модели и `@univerjs-pro/bases-ui/facade` — для состояния пользовательского интерфейса, затем вызов `FUniver.newAPI(univer)` после регистрации плагинов.

Затем прочитайте [Установка и базовое использование](/guides/bases/getting-started/installation), затем следуйте за [Базы Facade API Руководство](/guides/bases/getting-started/facade) для создания и редактирования баз данных.
