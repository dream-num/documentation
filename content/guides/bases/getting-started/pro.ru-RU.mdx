Univer Bases — это возможность Univer Pro. Для рабочих приложений требуется действующая лицензия Pro. При их развертывании необходимо учитывать те же особенности, что и для других продуктов Pro.

## Плагин лицензирования

Зарегистрируйте `UniverLicensePlugin` перед регистрацией плагинов Bases:

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

Не храните текст лицензии в системе контроля версий. В браузерных приложениях передавайте его через конфигурацию сборки или среды выполнения.

## Пространство имен пакетов

Пакеты Base находятся в пространстве имен `@univerjs-pro`:

| Возможность | Пакеты |
| --- | --- |
| Основная модель Base | `@univerjs-pro/bases` |
| Интерфейс Base для браузера | `@univerjs-pro/bases-ui` |

## Особенности развертывания

- В сервисах Node.js используйте только пакеты модели.
- При использовании полей с формулами зарегистрируйте плагины формул.
- Перед включением полей с вложениями в рабочей среде настройте обработчики загрузки файлов.
- Сохраняйте снимки Base как данные приложения и переносите их при обновлении Univer.

Подробнее о лицензировании, сервере и развертывании см. в разделе [Univer Pro](/guides/pro).
