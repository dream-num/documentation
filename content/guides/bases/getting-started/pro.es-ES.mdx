Univer Bases es una capacidad de Univer SDK Pro. Las aplicaciones de producción necesitan una licencia Pro válida y las mismas consideraciones de implementación que otros productos Pro.

## Complemento de licencia

Registre `UniverLicensePlugin` antes de registrar los complementos Bases:

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

Mantenga el texto de la licencia fuera del control de código fuente. En aplicaciones de navegador, inyéctelo a través de su compilación o configuración de tiempo de ejecución.

## Alcance del paquete

Los paquetes base se encuentran en el alcance `@univerjs-pro`:

| Capacidad | Paquetes |
| --- | --- |
| Modelo base principal | `@univerjs-pro/bases` |
| UI base del navegador | `@univerjs-pro/bases-ui` |

## Notas de implementación

- Utilice paquetes de modelo solo en servicios Node.js.
- Registre complementos de fórmula cuando utilice campos de fórmula.
- Configure los controladores de carga de archivos adjuntos antes de habilitar los campos de archivos adjuntos en producción.
- Conserve las instantáneas de Base como datos de la aplicación y migrelas junto con las actualizaciones de Univer.

Para obtener detalles sobre la licencia, el servidor y la implementación, consulte [Univer SDK Pro](/guides/pro).
