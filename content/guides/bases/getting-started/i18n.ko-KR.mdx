## `mergeLocales` 메서드 [#mergeLocales]

`mergeLocales` 메서드는 여러 플러그인 또는 프리셋의 언어 팩을 하나의 완전한 언어 팩 객체로 병합하는 데 사용합니다. 다음과 같이 사용할 수 있습니다.

<Tabs items={['프리셋 모드', '플러그인 모드']}>
  <Tab>
    ```typescript
    import { mergeLocales } from '@univerjs/presets'

    // You can pass multiple language pack objects to merge
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // You can also pass an array of language pack objects
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    ])
    ```
  </Tab>
  <Tab>
    ```typescript
    import { mergeLocales } from '@univerjs/core'

    // You can pass multiple language pack objects to merge
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // You can also pass an array of language pack objects
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    ])
    ```
  </Tab>
</Tabs>

## 사용자 지정 언어 팩

Univer는 사용자 지정 언어 팩도 지원합니다. 필요에 따라 언어 팩 객체를 구성하여 `Univer` 인스턴스에 전달할 수 있습니다. 프리셋 언어 팩은 일반적으로 `<rootDir>/packages/<PLUGIN_NAME>/locale` 디렉터리에 저장됩니다.

```typescript
const univer = new Univer({
  locale: 'ja-JP',
  locales: {
    'ja-JP': {
      ui: {
        shortcut: {
          undo: '元に戻す',
          redo: 'やり直す',
        },
      },
    },
  },
})
```

## 번역 기여하기

Univer는 현재 다음과 같은 기본 제공 언어 팩을 지원합니다.

- `zh-CN`: 중국어 간체
- `en-US`: 영어
- `zh-TW`: 중국어 번체
- `zh-HK`: 중국어 번체(홍콩)
- `ru-RU`: 러시아어
- `vi-VN`: 베트남어
- `fa-IR`: 페르시아어
- `fr-FR`: 프랑스어
- `ja-JP`: 일본어
- `ko-KR`: 한국어
- `es-ES`: 스페인어
- `ca-ES`: 카탈루냐어
- `sk-SK`: 슬로바키아어
- `ar-SA`: 아랍어
- `de-DE`: 독일어
- `id-ID`: 인도네시아어
- `it-IT`: 이탈리아어
- `pl-PL`: 폴란드어
- `pt-BR`: 포르투갈어(브라질)

Univer OSS는 포용성을 중시하는 오픈 소스 프로젝트로, 전 세계 개발자가 Univer의 로케일을 추가하거나 개선하는 데 참여하는 것을 환영합니다.
