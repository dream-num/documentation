---
title: 透過 CDN 使用 Univer Bases
---

Univer Bases 沒有 preset UMD 套件。請使用外掛程式模式把它加入現有的 Univer UMD 執行環境；以下程式碼區塊並不是獨立執行環境。

## 按相依順序載入

1. 載入 React、ReactDOM 和 RxJS。
2. 載入 Univer 共用相依套件：Core、RPC、公式引擎、算繪引擎、Design、UI、Core Facade、Pro 授權、Pro 公式引擎和 Pro 協作客戶端。
3. 載入下列 Bases 檔案。所有 `@univerjs` 和 `@univerjs-pro` 套件應使用相同版本。

```html
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/locale/zh-TW.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/locale/zh-TW.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/bases-ui/lib/index.css" />
```

這些檔案分別公開 `UniverProBases`、`UniverProBasesUi`、`UniverProBasesFacade`、`UniverProBasesUiFacade`、`UniverProBasesZhTW` 和 `UniverProBasesUiZhTW`。建立 Univer 時合併兩個語言套件物件，再從前兩個命名空間註冊 `UniverBasesPlugin` 和 `UniverBasesUIPlugin`。

如需完整的套件管理器設定，請返回[安裝與基本使用](/guides/bases/getting-started/installation)。
