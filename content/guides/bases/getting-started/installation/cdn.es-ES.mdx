---
title: Importar Web SDK a través de CDN
---

Univer Bases no proporciona un paquete UMD preestablecido. Añádalo a un tiempo de ejecución Univer UMD existente en modo plugin; el bloque script a continuación no es un tiempo de funcionamiento independiente.

## Cargar en orden de dependencias

1. Cargue React, ReactDOM y RxJS.
2. Cargar las dependencias Univer compartidas: Core, RPC, el motor de fórmulas, el motor renderizado, Diseño, UI, Core Facade, la licencia, el motor fórmula, y el cliente de colaboración.
3. Cargue los archivos Bases enumerados a continuación, y mantenga cada paquete `@univerjs` y `@univerjs-pro` en la misma versión.

```html
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/locale/es-ES.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/locale/es-ES.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/bases-ui/lib/index.css" />
```

Los archivos exponen `UniverProBases`, `UniverProBasesUi`, `UniverProBasesFacade`, `UniverProBasesUiFacade`, `UniverProBasesEnUS`, y `UniverProBasesUiEnUS`. Al construir Univer, fusionan los dos objetos locales, luego registran `UniverBasesPlugin` y `UniverBasesUIPlugin` de los dos primeros espacios de nombres.

Para una configuración completa del administrador de paquetes, vea [Instalación y uso básico](/guides/bases/getting-started/installation).
