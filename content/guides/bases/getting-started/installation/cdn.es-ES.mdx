---
title: Importar Univer Bases a través de CDN
---

Univer Bases no tiene un paquete UMD preset. Use el modo plugin para añadirlo a un entorno UMD de Univer existente; el siguiente bloque no es un entorno independiente.

## Cargar en orden de dependencias

1. Cargue React, ReactDOM y RxJS.
2. Cargue las dependencias compartidas de Univer: Core, RPC, motores de fórmulas y renderizado, Design, UI, Core Facade, licencia Pro, motor de fórmulas Pro y cliente de colaboración Pro.
3. Cargue los archivos de Bases que aparecen abajo. Use la misma versión para todos los paquetes `@univerjs` y `@univerjs-pro`.

```html
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/locale/es-ES.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/locale/es-ES.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/bases-ui/lib/index.css" />
```

Estos archivos exponen `UniverProBases`, `UniverProBasesUi`, `UniverProBasesFacade`, `UniverProBasesUiFacade`, `UniverProBasesEsES` y `UniverProBasesUiEsES`. Combine los dos objetos de idioma al crear Univer y registre `UniverBasesPlugin` y `UniverBasesUIPlugin` desde los dos primeros espacios de nombres.

Para ver la configuración completa con un gestor de paquetes, vuelva a [Instalación y uso básico](/guides/bases/getting-started/installation).
