---
title: Importer Web SDK via un CDN
---

Univer Bases ne fournit pas de bundle UMD prédéfini. Ajoutez-le à un runtime UMD Univer existant en mode plugin; le bloc de script ci-dessous n'est pas un run time autonome.

## Charger dans l’ordre des dépendances

1. Chargez React, ReactDOM et RxJS.
2. Chargez les dépendances partagées Univer : Core, RPC, le moteur de formule, le moteur rendu, Design, UI, Core Facade, la licence, le moteur formule et le client de collaboration.
3. Chargez les fichiers Bases listés ci-dessous et conservez chaque paquet `@univerjs` et `@univerjs-pro` dans la même version.

```html
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/locale/fr-FR.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/locale/fr-FR.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/bases-ui/lib/index.css" />
```

Les fichiers exposent `UniverProBases`, `UniverProBasesUi`, `UniverProBasesFacade`, `UniverProBasesUiFacade`, `UniverProBasesEnUS` et `UniverProBasesUiEnUS`. Lors de la construction de Univer, fusionner les deux objets locaux, puis enregistrer `UniverBasesPlugin` et `UniverBasesUIPlugin` à partir des deux premiers espaces de noms.

Pour une configuration complète de gestion de paquets, voir [Installation et utilisation de base](/guides/bases/getting-started/installation).
