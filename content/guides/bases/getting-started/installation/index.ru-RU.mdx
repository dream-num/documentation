Эта страница описывает, как установить Univer Bases и как запустить его после установки. Базы распространяются как продукт Univer Office SDK и в настоящее время используют режим плагина.

Если основные понятия Univer незнакомы, прочитайте сначала [Быстрый старт](/guides/bases/getting-started/quickstart).

Univer поддерживает два режима интеграции: *Preset Mode* и *Plugin Mode*. Preset Mode прекомбинирует плагины и уменьшает работу конфигурации. Если вам нужен **Глубокая настройка или расширения**, используйте режим плагина, чтобы вы могли выбирать и настраивать плагины индивидуально.

## Настройка в режиме плагинов

Приложение Bases для браузера обычно регистрирует совместно используемое время выполнения Univer, движок рендеринга, оболочку пользовательского интерфейса, движитель формулы и лицензию, а затем модель Bases и плагины пользовательского интерфейсов.

### Использование менеджера пакетов

Используйте сборщик с поддержкой ES Modules и поля `exports` в `package.json`.

#### Установка

Univer строит свой пользовательский интерфейс с React и использует RxJS для потоков данных, а также может быть встроен в приложения Vue или Angular. Убедитесь, что установлены зависимости `react`, `react-dom` и `rxjs` peer[^peer-dependency]. Команда Yarn ниже добавляет их явно.

Храните все `@univerjs/*` и `@univerjs-pro/*` в **той же версии**.

#### Использование

Создайте контейнер с явной высотой перед инициализацией Univer:

```html
<div id="app" style="height: 600px"></div>
```

Импортировать элементы фасада, используемые ниже, прежде чем звонить `FUniver.newAPI(univer)`. Загрузите сначала `@univerjs/design` CSS, затем `@univerjs/ui` и продукт CSS.

<Callout type="warning" title="Внимание">
  - Зарегистрируйте `UniverLicensePlugin` перед плагинами Bases.
  - Импортируйте CSS общего интерфейса до CSS интерфейса продукта.
  - Используйте `UniverProFormulaEnginePlugin` от `@univerjs-pro/engine-formula` для баз, включая формы приборной панели. Если вы объединяете продукты в одном экземпляре `Univer`, замените любой импорт и регистрацию `UniverFormulaEnginePlugin` вместо регистрации обоих движков формул.
</Callout>

<Steps>
  <Step>
    Стили импорта, локальные пакеты и необходимые плагины:

    ```ts
    import { UniverBasesPlugin } from '@univerjs-pro/bases'
    import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
    import BasesUIEnUS from '@univerjs-pro/bases-ui/locale/en-US'
    import BasesEnUS from '@univerjs-pro/bases/locale/en-US'
    import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/bases-ui/lib/index.css'
    ```
  </Step>
  <Step>
    Импорт фасадных записей, если вы планируете использовать Facade API[^facade-entry]:

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/bases/facade'
    import '@univerjs-pro/bases-ui/facade'
    ```
  </Step>
  <Step>
    Создайте экземпляр Univer, зарегистрируйте плагины и создайте базовый блок:

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          BasesEnUS,
          BasesUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })

    univer.registerPlugin(UniverProFormulaEnginePlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBasesPlugin)
    univer.registerPlugin(UniverBasesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BASE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

#### Настройка плагинов [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для размещения редактора или его идентификатор. |

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое файла клиентской лицензии. |

#### Методы `univer.registerPlugin` и `univer.registerPlugins` [#registerPlugin]

`univer.registerPlugin` регистрирует плагин на экземпляре Univer. Позвоните ему после создания экземпляра.

Подпись `univer.registerPlugin(Plugin, options)`. `Plugin` является плагином для регистрации, а `options` — необязательным объектом конфигурации. Каждый плагин определяет свои собственные опции.

`univer.registerPlugins` берет массив и регистрирует несколько плагинов за один звонок. Используйте его, чтобы сохранить регистрацию плагина в одном месте.

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, { container: 'app' }],

  UniverProFormulaEnginePlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverBasesPlugin,
  UniverBasesUIPlugin,
])
```

## Поддержка мобильных устройств [#mobile-support]

Текущий пакет `@univerjs-pro/bases-ui` не экспортирует выделенный мобильный плагин пользовательского интерфейса. Ни импорт `MobileUIPlugin`, ни опция `mobile: true` отсутствуют, поэтому не записывайте его. Узкий контейнер не демонстрирует полную сенсорную поддержку; тестируйте существующий пользовательский интерфейс на целевых устройствах.

## Другие каналы выпуска

Помимо стабильных релизов, Univer публикует альфа- и бета-каналы. Эти каналы позволяют пробовать новые функции до их официального релиза. Новые функции также несут риск: эти сборки могут содержать ошибки, неполную функциональность или нестабильные функции, поэтому избегайте их в производстве, где это возможно.

### Выпуски Alpha / Beta

Когда команда Univer завершает новую функцию или существенное изменение, она может опубликовать предварительный релиз к альфа- или бета-каналу.Установите альфа-или бета-сборку пакета Univer с этими командами:

```package-install
npm install @univerjs-pro/bases@alpha # Alpha version
npm install @univerjs-pro/bases@beta # Beta version
```

Если вы столкнулись с проблемой или получили обратную связь при использовании альфа- или бета-сборки, сообщите об этом команде Univer через [Обсуждение GitHub](https://github.com/dream-num/univer/issues).
