title: 安裝與基本使用
---

本頁介紹 Univer Bases 的安裝方法，以及安裝完成後的執行方式。Bases 是 Univer Office SDK 的產品，目前採用外掛模式。

如果還不熟悉 Univer 的核心概念，請先閱讀[快速入門](/guides/bases/getting-started/quickstart)。

Univer 提供兩種整合方式：*預設模式*和*外掛模式*。預設模式預先組合外掛，配置過程更簡單；如果**需要深度擴充套件**，應使用外掛模式，逐個選擇和配置外掛。

## 透過外掛模式建立

瀏覽器中的 Bases 應用通常先註冊 Univer 共享執行時、渲染引擎、UI 外殼、公式引擎和許可證，再註冊 Bases 的模型外掛和 UI 外掛。

### 使用套件管理器

建置工具必須支援 ES Module 和 `package.json` 的 `exports` 欄位。

#### 安裝

Univer 的介面使用 React 建置，資料流使用 RxJS，也可以嵌入 Vue 或 Angular 應用。請先確認 `react`、`react-dom` 和 `rxjs` 這些 peer dependencies[^peer-dependency] 均已安裝；下面的 Yarn 命令已顯式包含它們。

所有 `@univerjs/*` 和 `@univerjs-pro/*` 套件應保持**相同版本**。

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/engine-render @univerjs/ui @univerjs-pro/bases @univerjs-pro/bases-ui @univerjs-pro/engine-formula @univerjs-pro/license"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}

#### 使用

先建立容器併為其指定明確的高度，再初始化 Univer：

```html
<div id="app" style="height: 600px"></div>
```

呼叫 `FUniver.newAPI(univer)` 之前，先匯入下文用到的 facade 入口。CSS 按 `@univerjs/design`、`@univerjs/ui`、產品 CSS 的順序載入。

<Callout type="warning" title="注意">
  - 先註冊 `UniverLicensePlugin`，再註冊 Bases 外掛。
  - 先匯入共享 UI CSS，再匯入產品 UI CSS。
  - Bases（包括儀表盤形狀）應使用 `@univerjs-pro/engine-formula` 中的 `UniverProFormulaEnginePlugin`。在同一個 `Univer` 例項中組合多個產品時，應替換已有的 `UniverFormulaEnginePlugin` 匯入和註冊，不要同時註冊兩個公式引擎。
</Callout>

<Steps>
  <Step>
    匯入樣式、語言套件和需要的外掛：

    ```ts
    import { UniverBasesPlugin } from '@univerjs-pro/bases'
    import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
    import BasesUIEnUS from '@univerjs-pro/bases-ui/locale/en-US'
    import BasesEnUS from '@univerjs-pro/bases/locale/en-US'
    import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/bases-ui/lib/index.css'
    ```
  </Step>
  <Step>
    如要使用 Facade API[^facade-entry]，請匯入 facade 入口：

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/bases/facade'
    import '@univerjs-pro/bases-ui/facade'
    ```
  </Step>
  <Step>
    建立 Univer 執行個體、註冊外掛，並建立 Base 單元：

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          BasesEnUS,
          BasesUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })

    univer.registerPlugin(UniverProFormulaEnginePlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBasesPlugin)
    univer.registerPlugin(UniverBasesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BASE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

#### 外掛設定 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 掛載目標的 DOM 元素或其 ID。 |

`UniverLicensePlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 用戶端授權檔的內容。 |

#### `univer.registerPlugin` 與 `univer.registerPlugins` 方法 [#registerPlugin]

`univer.registerPlugin` 在 Univer 例項上註冊一個外掛，建立例項後即可呼叫。

簽名為 `univer.registerPlugin(Plugin, options)`。`Plugin` 是要註冊的外掛，`options` 是可選配置物件，各外掛的配置項由外掛自行定義。

`univer.registerPlugins` 接收一個陣列，一次註冊多個外掛，適用於將外掛註冊集中在一處的場景。

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, { container: 'app' }],

  UniverProFormulaEnginePlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverBasesPlugin,
  UniverBasesUIPlugin,
])
```

## 行動裝置支援 [#mobile-support]

當前 `@univerjs-pro/bases-ui` 沒有匯出獨立的行動版 UI 外掛。不存在 `MobileUIPlugin` 這個匯入，也不存在 `mobile: true` 這個選項，請不要自行編寫。容器變窄並不代表觸控互動已經得到完整支援，仍需在目標裝置上驗證現有 UI。

## 其他發佈版本

除穩定版本外，Univer 還提供 alpha / beta 通道，可以提前使用尚未正式釋出的新功能。新功能也意味著風險：這些版本可能包含 bug、功能不完整或不穩定，請儘量避免在生產環境中使用。

### Alpha / Beta 版本

Univer 開發團隊完成新功能或較大改動時，可能先將其釋出到 alpha 或 beta 通道。安裝某個包的 alpha / beta 版本可使用以下命令：

```package-install
npm install @univerjs-pro/bases@alpha # Alpha 版本
npm install @univerjs-pro/bases@beta # Beta 版本
```

使用 alpha / beta 版本時如果遇到問題或有反饋，可以透過 [GitHub Issues](https://github.com/dream-num/univer/issues) 提交給 Univer 開發團隊。
