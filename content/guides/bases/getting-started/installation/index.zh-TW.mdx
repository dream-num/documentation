本章介紹 Univer Bases 的安裝方式與基本用法。Bases 以 Univer Pro 產品的形式發佈，目前採用外掛模式。

如果你還不熟悉 Univer 的核心概念，請先閱讀[快速入門](/guides/bases/getting-started/quickstart)。

## 使用外掛模式建立

瀏覽器中的 Bases 應用程式通常會先註冊共用的 Univer 執行環境、算繪引擎、UI 殼層、公式引擎與 Pro 授權，接著再註冊 Bases 模型與 UI 外掛。

### 安裝

安裝瀏覽器版 Bases 編輯器所需的最基本套件：

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab>
    ```shell
    npm install @univerjs/core @univerjs/design @univerjs/engine-formula @univerjs/engine-render @univerjs/ui @univerjs-pro/bases @univerjs-pro/bases-ui @univerjs-pro/engine-formula @univerjs-pro/license
    ```
  </Tab>
  <Tab>
    ```shell
    pnpm add @univerjs/core @univerjs/design @univerjs/engine-formula @univerjs/engine-render @univerjs/ui @univerjs-pro/bases @univerjs-pro/bases-ui @univerjs-pro/engine-formula @univerjs-pro/license
    ```
  </Tab>
  <Tab>
    ```shell
    yarn add @univerjs/core @univerjs/design @univerjs/engine-formula @univerjs/engine-render @univerjs/ui @univerjs-pro/bases @univerjs-pro/bases-ui @univerjs-pro/engine-formula @univerjs-pro/license react react-dom rxjs
    ```
  </Tab>
</Tabs>

### 用法

<Callout type="warning" title="注意">
  - 請先註冊 `UniverLicensePlugin`，再註冊 Bases 外掛。
  - 請先匯入共用 UI CSS，再匯入產品 UI CSS。
  - 使用公式欄位時，請同時註冊 `UniverFormulaEnginePlugin` 和 `UniverProFormulaEnginePlugin`。
</Callout>

<Steps>
  <Step>
    匯入樣式、語系套件與必要的外掛：

    ```ts
    import { UniverBasesPlugin } from '@univerjs-pro/bases'
    import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
    import BasesUIEnUS from '@univerjs-pro/bases-ui/locale/en-US'
    import BasesEnUS from '@univerjs-pro/bases/locale/en-US'
    import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/bases-ui/lib/index.css'
    ```
  </Step>
  <Step>
    如要使用 Facade API，請匯入 Facade 進入點：

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/bases/facade'
    import '@univerjs-pro/bases-ui/facade'
    ```
  </Step>
  <Step>
    建立 Univer 執行個體、註冊外掛，並建立 Base 單元：

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          BasesEnUS,
          BasesUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverFormulaEnginePlugin)
    univer.registerPlugin(UniverProFormulaEnginePlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBasesPlugin)
    univer.registerPlugin(UniverBasesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BASE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

## 其他發佈管道

除了穩定版本外，Univer 也提供 alpha、beta 與 nightly 發佈管道。你可以透過這些管道提早試用即將推出的功能，但其中可能包含尚未完成或不穩定的行為。除非已有驗證計畫，否則請勿在正式環境中使用。

```package-install
npm install @univerjs-pro/bases@alpha
npm install @univerjs-pro/bases@beta
```
