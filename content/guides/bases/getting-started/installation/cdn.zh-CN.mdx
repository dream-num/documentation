---
title: 通过 CDN 使用 Univer Bases
---

Univer Bases 没有 preset UMD 包。请使用插件模式把它加入已有的 Univer UMD 运行时；以下代码块并不是独立运行时。

## 按依赖顺序加载

1. 加载 React、ReactDOM 和 RxJS。
2. 加载 Univer 通用依赖：Core、RPC、公式引擎、渲染引擎、Design、UI、Core Facade、Pro 许可证、Pro 公式引擎和 Pro 协同客户端。
3. 加载下面的 Bases 文件。所有 `@univerjs` 和 `@univerjs-pro` 包应使用同一版本。

```html
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/locale/zh-CN.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/locale/zh-CN.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/bases-ui/lib/index.css" />
```

这些文件分别公开 `UniverProBases`、`UniverProBasesUi`、`UniverProBasesFacade`、`UniverProBasesUiFacade`、`UniverProBasesZhCN` 和 `UniverProBasesUiZhCN`。创建 Univer 时合并两个语言包对象，再从前两个命名空间注册 `UniverBasesPlugin` 和 `UniverBasesUIPlugin`。

如需完整的包管理器配置，请返回[安装和基本使用](/guides/bases/getting-started/installation)。
