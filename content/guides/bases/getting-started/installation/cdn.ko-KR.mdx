---
title: CDN으로 Univer Bases 가져오기
---

Univer Bases는 preset UMD 번들을 제공하지 않습니다. 플러그인 모드로 기존 Univer UMD 런타임에 추가하세요. 아래 블록만으로는 독립 실행할 수 없습니다.

## 종속성 순서로 로드

1. React, ReactDOM, RxJS를 로드합니다.
2. 공통 Univer 종속성인 Core, RPC, 수식 엔진, 렌더 엔진, Design, UI, Core Facade, Pro 라이선스, Pro 수식 엔진, Pro 협업 클라이언트를 로드합니다.
3. 아래 Bases 파일을 로드합니다. 모든 `@univerjs` 및 `@univerjs-pro` 패키지에 같은 버전을 사용하세요.

```html
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/locale/ko-KR.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/locale/ko-KR.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/bases-ui/lib/index.css" />
```

이 파일은 `UniverProBases`, `UniverProBasesUi`, `UniverProBasesFacade`, `UniverProBasesUiFacade`, `UniverProBasesKoKR`, `UniverProBasesUiKoKR`를 노출합니다. Univer를 생성할 때 두 로케일 객체를 병합하고 처음 두 네임스페이스에서 `UniverBasesPlugin`과 `UniverBasesUIPlugin`을 등록하세요.

패키지 관리자를 사용하는 전체 설정은 [설치 및 기본 사용법](/guides/bases/getting-started/installation)을 참고하세요.
