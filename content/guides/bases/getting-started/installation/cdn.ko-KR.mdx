---
title: CDN으로 Web SDK 가져오기
---

Univer Bases는 사전 설정 UMD 번들을 제공하지 않습니다. 플러그인 모드에서 기존 Univer UMD 런타임에 추가하십시오. 아래 스크립트 블록은 독립 실행 시간이 아닙니다.

## 종속성 순서로 로드

1. React, ReactDOM, RxJS를 로드합니다.
2. 공유된 Univer 의존성 적재: 핵심, RPC의 공식적인 엔진, 연출 엔진, 디자인, UI, 핵심 정면, 면허, 공식 엔진 및 협력 클라이언트.
3. 아래에 나열된 기본 파일을로드하고 모든 `@univerjs` 및 `@univerjs-pro` 패키지를 동일한 버전으로 유지하십시오.

```html
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/locale/ko-KR.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/locale/ko-KR.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/bases-ui/lib/index.css" />
```

파일은 `UniverProBases`, `UniverProBasesUi`의 `UniverProBasesFacade`를, `UniverProBasesUiFacade`는 `UniverProBasesEnUS` 및 `UniverProBasesUiEnUS`에 노출합니다. Univer 건설 시 두 개의 로컬 객체를 병합하여 `UniverBasesPlugin`와 `UniverBasesUIPlugin`을 첫 두 개의 네임스페이스에서 등록하십시오.

완전한 패키지 관리자 설정을 위해 [설치 및 기본 사용](/guides/bases/getting-started/installation)를 참조하십시오.
