이 페이지는 Univer Bases를 설치하는 방법을 설명하고 설치 후 실행하는 방법을 설명합니다. Bases는 Univer Office SDK 제품으로 배포되며 현재 플러그인 모드를 사용합니다.

Univer의 핵심 개념이 무해하다면 [퀵스타트](/guides/bases/getting-started/quickstart)를 먼저 읽습니다.

Univer는 두 개의 통합 모드를 지원합니다. *Preset Mode* 및 *Plugin Mode*. Preset Mode precombines 플러그인을 미리 설치하고 구성 작업을 줄일 수 있습니다. **깊은 주문화 또는 연장**를 필요로 하는 경우 플러그인 모드를 사용하여 개별적으로 플러그인을 선택할 수 있습니다.

## 플러그인 모드로 설정하기

브라우저 기본 응용 프로그램은 일반적으로 공유 Univer 실행 시간, 렌더링 엔진, UI 쉘, 공식 엔진 및 라이센스를 먼저 등록하고, 기본 모델 및 UI 플러그인.

### 패키지 관리자 사용

ES Modules와 `package.json`의 `exports` 필드를 지원하는 빌드 도구를 사용하세요.

#### 설치

Univer는 React와 UI를 구축하고 데이터 스트림의 RxJS를 사용하며 Vue 또는 Angular 응용 프로그램에 내장 할 수 있습니다. `react`, `react-dom` 및 `rxjs` 피어 의존성[^peer-dependency]가 설치됩니다. 아래의 원사 명령은 명시적으로 추가합니다.

**같은 버전**에 모든 `@univerjs/*` 및 `@univerjs-pro/*` 패키지를 유지하십시오.

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/engine-render @univerjs/ui @univerjs-pro/bases @univerjs-pro/bases-ui @univerjs-pro/engine-formula @univerjs-pro/license"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}
/>

#### 사용법

Univer 초기화하기 전에 명시된 높이로 컨테이너를 만듭니다.

```html
<div id="app" style="height: 600px"></div>
```

`FUniver.newAPI(univer)`를 호출하기 전에 아래의 정면 항목을 가져옵니다. `@univerjs/design` CSS를 먼저로드 한 다음 `@univerjs/ui`의 CSS 및 제품 CSS가 지속됩니다.

<Callout type="warning" title="주의">
  - Bases 플러그인의 앞에 `UniverLicensePlugin`를 등록하십시오.
  - 제품 UI CSS보다 먼저 공유 UI CSS를 가져오세요.
  - `UniverProFormulaEnginePlugin`를 `@univerjs-pro/engine-formula`에서 대쉬보드 모양을 포함하여 기본을 사용합니다. `Univer` 인스턴스에서 제품을 결합하면 `UniverFormulaEnginePlugin` 가져 오기 및 등록 대신 공식 엔진을 등록하십시오.
</Callout>

<Steps>
  <Step>
    가져오기 스타일, Locale packs, 그리고 플러그인 당신이 필요로:

    ```ts
    import { UniverBasesPlugin } from '@univerjs-pro/bases'
    import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
    import BasesUIEnUS from '@univerjs-pro/bases-ui/locale/en-US'
    import BasesEnUS from '@univerjs-pro/bases/locale/en-US'
    import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/bases-ui/lib/index.css'
    ```
  </Step>
  <Step>
    Facade API[^facade-entry]를 사용하는 계획이 있는 경우에 수입품 정면 입장:

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/bases/facade'
    import '@univerjs-pro/bases-ui/facade'
    ```
  </Step>
  <Step>
    Univer 인스턴스를 생성하고 플러그인을 등록하고 기본 단위를 만듭니다.

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          BasesEnUS,
          BasesUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })

    univer.registerPlugin(UniverProFormulaEnginePlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBasesPlugin)
    univer.registerPlugin(UniverBasesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BASE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

#### 플러그인 설정 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 편집기를 마운트할 DOM 요소 또는 해당 요소의 ID입니다. |

`UniverLicensePlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `license` | `string` |  | 클라이언트 라이선스 파일의 내용입니다. |

#### `univer.registerPlugin` 및 `univer.registerPlugins` 메서드 [#registerPlugin]

`univer.registerPlugin`는 Univer 인스턴스에 플러그인을 등록합니다. 인스턴스 생성 후 호출하십시오.

서명은 `univer.registerPlugin(Plugin, options)`입니다. `Plugin`는 등록하는 플러그인이며 `options`은 옵션 구성 객체입니다. 각 플러그인은 자체 옵션을 정의합니다.

`univer.registerPlugins`는 배열을 가지고 있으며 하나의 호출에서 여러 플러그인을 등록합니다. 플러그인 등록을 한 곳에서 유지하려면 사용하십시오.

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, { container: 'app' }],

  UniverProFormulaEnginePlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverBasesPlugin,
  UniverBasesUIPlugin,
])
```

## 모바일 지원 [#mobile-support]

현재 `@univerjs-pro/bases-ui` 패키지는 전용 모바일 UI 플러그인을 수출하지 않습니다. `MobileUIPlugin` 가져 오기 또는 `mobile: true` 옵션이 존재하므로 하나를 작성하지 마십시오. 좁은 컨테이너는 완전한 터치 지원이 입증되지 않습니다. 대상 장치에서 기존 UI를 테스트하십시오.

## 기타 릴리스

안정적인 릴리스 외에도 Univer는 알파 및 베타 채널을 게시합니다. 이 채널은 공식 출시 전에 새로운 기능을 시도 할 수 있습니다. 새로운 기능은 또한 위험을 수행 할 수 있습니다 :이 빌드는 버그, 불완전한 기능, 또는 불안정한 기능을 포함 할 수 있으므로 생산에서 불가능합니다.

### Alpha / Beta 릴리스

Univer 팀은 새로운 기능 또는 중요한 변화를 완료하면 알파 또는 베타 채널에 사전 릴리스를 게시 할 수 있습니다. 이러한 명령이있는 Univer 패키지의 알파 또는 베타 빌드를 설치하십시오.

```package-install
npm install @univerjs-pro/bases@alpha # Alpha version
npm install @univerjs-pro/bases@beta # Beta version
```

문제가 있거나 알파 또는 베타 빌드를 사용하는 동안 피드백을 가지고 있다면 Univer 팀에 [GitHub 문제](https://github.com/dream-num/univer/issues)를 통해보고하십시오.
