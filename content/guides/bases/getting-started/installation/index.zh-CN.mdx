---
title: 安装和基本使用
---

本页介绍 Univer Bases 的安装方法，以及安装完成后的运行方式。Bases 是 Univer Office SDK 的产品，目前采用插件模式。

如果还不熟悉 Univer 的核心概念，请先阅读[快速入门](/guides/bases/getting-started/quickstart)。

Univer 提供两种集成方式：*预设模式*和*插件模式*。预设模式预先组合插件，配置过程更简单；如果**需要深度扩展**，应使用插件模式，逐个选择和配置插件。

## 通过插件模式创建

浏览器中的 Bases 应用通常先注册 Univer 共享运行时、渲染引擎、UI 外壳、公式引擎和许可证，再注册 Bases 的模型插件和 UI 插件。

### 使用包管理器

构建工具必须支持 ES Module 和 `package.json` 的 `exports` 字段。

#### 安装

Univer 的界面使用 React 构建，数据流使用 RxJS，也可以嵌入 Vue 或 Angular 应用。请先确认 `react`、`react-dom` 和 `rxjs` 这些 peer dependencies[^peer-dependency] 均已安装；下面的 Yarn 命令已显式包含它们。

所有 `@univerjs/*` 和 `@univerjs-pro/*` 包应保持**相同版本**。

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/engine-render @univerjs/ui @univerjs-pro/bases @univerjs-pro/bases-ui @univerjs-pro/engine-formula @univerjs-pro/license"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}

#### 使用

先创建容器并为其指定明确的高度，再初始化 Univer：

```html
<div id="app" style="height: 600px"></div>
```

调用 `FUniver.newAPI(univer)` 之前，先导入下文用到的 facade 入口。CSS 按 `@univerjs/design`、`@univerjs/ui`、产品 CSS 的顺序加载。

<Callout type="warning" title="注意">
  - 先注册 `UniverLicensePlugin`，再注册 Bases 插件。
  - 先导入共享 UI CSS，再导入产品 UI CSS。
  - Bases（包括仪表盘形状）应使用 `@univerjs-pro/engine-formula` 中的 `UniverProFormulaEnginePlugin`。在同一个 `Univer` 实例中组合多个产品时，应替换已有的 `UniverFormulaEnginePlugin` 导入和注册，不要同时注册两个公式引擎。
</Callout>

<Steps>
  <Step>
    导入样式、语言包和需要的插件：

    ```ts
    import { UniverBasesPlugin } from '@univerjs-pro/bases'
    import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
    import BasesUIEnUS from '@univerjs-pro/bases-ui/locale/en-US'
    import BasesEnUS from '@univerjs-pro/bases/locale/en-US'
    import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/bases-ui/lib/index.css'
    ```
  </Step>
  <Step>
    如要使用 Facade API[^facade-entry]，请导入 facade 入口：

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/bases/facade'
    import '@univerjs-pro/bases-ui/facade'
    ```
  </Step>
  <Step>
    创建 Univer 实例、注册插件并创建 Base 单元：

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          BasesEnUS,
          BasesUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })

    univer.registerPlugin(UniverProFormulaEnginePlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBasesPlugin)
    univer.registerPlugin(UniverBasesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BASE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

#### 插件配置 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 挂载目标的 DOM 元素或其 ID。 |

`UniverLicensePlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 客户端许可证文件的内容。 |

#### `univer.registerPlugin` 与 `univer.registerPlugins` 方法 [#registerPlugin]

`univer.registerPlugin` 在 Univer 实例上注册一个插件，创建实例后即可调用。

签名为 `univer.registerPlugin(Plugin, options)`。`Plugin` 是要注册的插件，`options` 是可选配置对象，各插件的配置项由插件自行定义。

`univer.registerPlugins` 接收一个数组，一次注册多个插件，适用于将插件注册集中在一处的场景。

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, { container: 'app' }],

  UniverProFormulaEnginePlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverBasesPlugin,
  UniverBasesUIPlugin,
])
```

## 移动端适配 [#mobile-support]

当前 `@univerjs-pro/bases-ui` 没有导出独立的移动端 UI 插件。不存在 `MobileUIPlugin` 这个导入，也不存在 `mobile: true` 这个选项，请不要自行编写。容器变窄并不代表触摸交互已经得到完整支持，仍需在目标设备上验证现有 UI。

## 其他发布版本

除稳定版本外，Univer 还提供 alpha / beta 通道，可以提前使用尚未正式发布的新功能。新功能也意味着风险：这些版本可能包含 bug、功能不完整或不稳定，请尽量避免在生产环境中使用。

### Alpha / Beta 版本

Univer 开发团队完成新功能或较大改动时，可能先将其发布到 alpha 或 beta 通道。安装某个包的 alpha / beta 版本可使用以下命令：

```package-install
npm install @univerjs-pro/bases@alpha # Alpha 版本
npm install @univerjs-pro/bases@beta # Beta 版本
```

使用 alpha / beta 版本时如果遇到问题或有反馈，可以通过 [GitHub Issues](https://github.com/dream-num/univer/issues) 提交给 Univer 开发团队。
