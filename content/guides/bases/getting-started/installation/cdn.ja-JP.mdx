UniverベースはプリセットのUDMバンドルを提供していません。プラグインモードで既存のUniver UMDランタイムに追加します。下のスクリプトブロックはスタンドアローンランタイムではありません。

## 依存関係の順序で読み込む

1. React、ReactDOM、RxJS を読み込みます。
2. 共有のUniverの依存関係をロードします。コア、RPC、フォーミュラエンジン、レンダーエンジン、デザイン、UI、コアファサード、ライセンス、フォーミュレーションエンジン、コラボレーションクライアント。
3. 以下に示すベースファイルをロードし、すべての`@univerjs`と`@univerjs-pro`パッケージを同じバージョンで保持します。

```html
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/locale/ja-JP.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/locale/ja-JP.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/bases-ui/lib/index.css" />
```

`UniverProBases`, `UniverProBasesUi`、`UniverProBasesFacade`、 `UniverProBasesUiFacade`の `UniverProBasesEnUS`と`UniverProBasesUiEnUS`を割るファイルです。 Univerの構築時に、2つのロケールオブジェクトをマージし、最初の2つのネームスペースから`UniverBasesPlugin`および`UniverBasesUIPlugin`を登録します。

完全なパッケージマネージャーのセットアップについては、[インストールと基本的な使い方](/guides/bases/getting-started/installation)を参照してください。
