title: インストールと基本的な使い方
---

このページでは、Univerベースのインストール方法とインストール後に実行する方法について説明します。ベースはUniver Office SDK製品として配布され、現在はプラグインモードを使用しています。

Univer のコアコンセプトが不慣れな場合は、[クイックスタート](/guides/bases/getting-started/quickstart)を最初に読みます。

Univer は 2 つの統合モードをサポートしています: *Preset Mode* と *Plugin Mode*。 Preset Mode はプラグインをプレコンビネーションし、設定作業を削減します。 **深いカスタム化か延長**が必要な場合は、プラグインモードを使用して、プラグインを個別に選択および設定できます。

## プラグインモードでのセットアップ

ブラウザベースアプリケーションは、通常、共有のUniverランタイム、レンダーエンジン、UIシェル、フォーミュラエンジン、ライセンスを最初に登録し、ベースモデルとUIプラグイン。

### パッケージマネージャーの使用

ES Modules と `package.json` の `exports` フィールドに対応したビルドツールを使用してください。

#### インストール

UniverはReactとUIを造り、RxJSをデータストリームに使用し、VueかAngularの適用で埋め込むことができます。`react`、`react-dom`および`rxjs`の仲間の依存性[^peer-dependency]が取付けられていることを確かめて下さい。ヤーンの命令はそれらをexplicitly加えます。

**同じバージョン**の`@univerjs/*`と`@univerjs-pro/*`パッケージを全て保存します。

#### 使い方

Univerを初期化する前に、コンテナを明示的な高さで作成します。

```html
<div id="app" style="height: 600px"></div>
```

`FUniver.newAPI(univer)`を呼び出す前に、下で使用されるファサードエントリをインポートします。 `@univerjs/design` CSSを最初にロードし、`@univerjs/ui`CSSと製品CSSが最後に続きます。

<Callout type="warning" title="注意">
  - Bases プラグインの前に `UniverLicensePlugin` を登録します。
  - 製品固有の UI CSS より先に、共通の UI CSS をインポートしてください。
  - `UniverProFormulaEnginePlugin` を `@univerjs-pro/engine-formula` for Bases から利用します。`Univer`インスタンスを1つに組み合わせると、両方の式エンジンを登録する代わりに `UniverFormulaEnginePlugin`インポートと登録を交換します。
</Callout>

<Steps>
  <Step>
    インポートスタイル、ローカルパック、必要なプラグイン:

    ```ts
    import { UniverBasesPlugin } from '@univerjs-pro/bases'
    import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
    import BasesUIEnUS from '@univerjs-pro/bases-ui/locale/en-US'
    import BasesEnUS from '@univerjs-pro/bases/locale/en-US'
    import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/bases-ui/lib/index.css'
    ```
  </Step>
  <Step>
    Facade API[^facade-entry]を使用する予定の場合には、ファサードエントリーをインポートします。

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/bases/facade'
    import '@univerjs-pro/bases-ui/facade'
    ```
  </Step>
  <Step>
    Univerインスタンスを作成し、プラグインを登録し、ベースユニットを作成します。

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          BasesEnUS,
          BasesUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })

    univer.registerPlugin(UniverProFormulaEnginePlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBasesPlugin)
    univer.registerPlugin(UniverBasesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BASE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

#### プラグイン設定 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターのマウント先となる DOM 要素、またはその ID。 |

`UniverLicensePlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `license` | `string` |  | クライアント用ライセンスファイルの内容。 |

#### `univer.registerPlugin` と `univer.registerPlugins` メソッド [#registerPlugin]

`univer.registerPlugin`はUniverインスタンスにプラグインを登録します。インスタンスを作成した後にそれを呼び出します。

署名は`univer.registerPlugin(Plugin, options)`です。`Plugin`は登録するプラグインで、`options`にはオプションの構成オブジェクトです。各プラグインは独自のオプションを定義します。

`univer.registerPlugins`は配列をとり、1つの呼び出しで複数のプラグインを登録します。プラグインの登録を1か所に保つために使用します。

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, { container: 'app' }],

  UniverProFormulaEnginePlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverBasesPlugin,
  UniverBasesUIPlugin,
])
```

## モバイル対応 [#mobile-support]

現在の `@univerjs-pro/bases-ui` パッケージは専用のモバイル UI プラグインをエクスポートしません。 `MobileUIPlugin` のインポートや `mobile: true` オプションが存在しているので、一つは書きません。 狭いコンテナは完全なタッチ サポートを実証しません。 ターゲットデバイスに既存の UI をテストします。

## その他のリリース

Univerは、安定したリリースに加えて、アルファとベータチャネルを公開しています。 これらのチャネルは、公式リリースの前に新しい機能を試してみることを可能にします。 新しい機能もリスクを運びます。 これらのビルドには、バグ、不完全な機能、または不安定な機能が含まれている可能性があるため、可能な限り生産でそれらを避けることができます。

### Alpha/Beta リリース

Univer チームが新しい機能または重要な変更を完了すると、アルファまたはベータチャネルにプレリリースを公開することができます。 これらのコマンドで Univer パッケージのアルファまたはベータビルドをインストールします。

```package-install
npm install @univerjs-pro/bases@alpha # Alpha バージョン
npm install @univerjs-pro/bases@beta # Beta バージョン
```

アルファまたはベータビルドを使用しているときに問題が発生した場合は、[GitHubの問題](https://github.com/dream-num/univer/issues)を通じてUniverチームに報告してください。
