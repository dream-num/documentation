---
title: Import Web SDK via CDN
---

Univer Bases does not provide a preset UMD bundle. Add it to an existing Univer UMD runtime in plugin mode; the script block below is not a standalone runtime.

## Load in dependency order

1. Load React, ReactDOM, and RxJS.
2. Load the shared Univer dependencies: Core, RPC, the formula engine, the render engine, Design, UI, Core Facade, the license, and the collaboration client.
3. Load the Bases files listed below, and keep every `@univerjs` and `@univerjs-pro` package at the same version.

```html
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/locale/en-US.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/locale/en-US.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/bases-ui/lib/index.css" />
```

The files expose `UniverProBases`, `UniverProBasesUi`, `UniverProBasesFacade`, `UniverProBasesUiFacade`, `UniverProBasesEnUS`, and `UniverProBasesUiEnUS`. When constructing Univer, merge the two locale objects, then register `UniverBasesPlugin` and `UniverBasesUIPlugin` from the first two namespaces.

For a complete package-manager setup, see [Installation and Basic Usage](/guides/bases/getting-started/installation).
