title: Подключение Web SDK через CDN
---

Базы Univer не обеспечивают предустановленный пакет UMD. Добавьте его в существующую среду выполнения Univer UMD в режиме плагина; блок сценариев ниже не является автономным временем выполнения.

## Загрузка в порядке зависимостей

1. Загрузите React, ReactDOM и RxJS.
2. Загрузите общие зависимости Univer: Core, RPC, движок формулы, рендерный двигатель, дизайн, пользовательский интерфейс, Core Facade, лицензию, движитель формулы и клиент совместной работы.
3. Загрузите Базовые файлы, перечисленные ниже, и сохраните все пакеты `@univerjs` и `@univerjs-pro` в одной версии.

```html
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases/lib/umd/locale/ru-RU.js"></script>
<script src="https://unpkg.com/@univerjs-pro/bases-ui/lib/umd/locale/ru-RU.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/bases-ui/lib/index.css" />
```

Файлы обнажают `UniverProBases`, `UniverProBasesUi`, `UniverProBasesFacade`, `UniverProBasesUiFacade`, `UniverProBasesEnUS` и `UniverProBasesUiEnUS`.При построении Univer сливаются два локальных объекта, затем регистрируют `UniverBasesPlugin` и `UniverBasesUIPlugin` из первых двух пространств имен.

Для полной настройки пакета-менеджера см. [Установка и базовое использование](/guides/bases/getting-started/installation).
