## Idioma de la interfaz

`locale` selecciona el paquete de idiomas para menús, puntas de herramientas, diálogos y el resto de la UI. `locales` registra paquetes sin seleccionar uno. El ajuste es compartido por las unidades en la instancia Univer. Toma valores `LocaleType`, como `LocaleType.EN_US` .

- **Todos los productos: UI**: `locale` cambia el idioma de los menús, puntas de herramientas, diálogos y etiquetas de plugin. No traduce el contenido de usuario ni renombra las unidades existentes.
- **Hojas: formatos celulares y fórmulas**: Los números y las fechas en las células siguen una cadena de respuesta: el número-format locale override, entonces el libro de trabajo instantánea `locale`, luego la instancia `locale`. `region` no reemplaza ninguno de ellos. El comportamiento de la fórmula como `DOLLAR` y el formato de moneda de los resultados financieros sigue `locale` normal, como
- **Docs: estadística**: `locale` determina cómo se segmenta y se cuenta el texto.

### Cambiar el idioma durante la ejecución

Cargue los paquetes de idiomas para cada plugin instalado o preset antes de cambiar el idioma. `loadLocales()` fusiona las traducciones sin conmutación; `setLocale()` selecciona de lo que ya está cargado y no descarga nada. Una clave de traducción que falta se muestra como la propia clave. El ejemplo a continuación carga el paquete UI compartido; agregue los paquetes en idioma de destino para los otros plugins instalados a la misma llamada.

```typescript
import { LocaleType, mergeLocales } from '@univerjs/core'
import UIEnUS from '@univerjs/ui/locale/en-US'

univerAPI.loadLocales(LocaleType.EN_US, mergeLocales(UIEnUS))
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentLocale()) // enUS
```

### Paquetes de idiomas personalizados

También puede escribir un paquete de idiomas personalizado: ensamblar el objeto que necesita y pasarlo a la instancia `Univer`. Los paquetes de idiomas enviados por presets generalmente viven en `<rootDir>/packages/<PLUGIN_NAME>/locale` .

```typescript
import { LocaleType, Univer } from '@univerjs/core'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: {
      ui: {
        shortcut: {
          undo: '元に戻す',
          redo: 'やり直す',
        },
      },
    },
  },
})
```

### Contribución de traducciones

Univer ofrece los siguientes paquetes de idiomas incorporados:

- `zh-CN`: chino simplificado
- `en-US`: inglés
- `zh-TW`: tradicional Chino
- `zh-HK`: Chino tradicional (Hong Kong)
- `ru-RU`: Ruso
- `vi-VN`: Vietnamita
- `fa-IR`: Persa
- `fr-FR`: Francés
- `ja-JP`: japonés
- `ko-KR`: coreano
- `es-ES`: español
- `ca-ES`: catalán
- `sk-SK`: eslovaco
- `ar-SA`: Árabe
- `de-DE`: alemán
- `id-ID`: indonesio
- `it-IT`: italiano
- `pl-PL`: polaco
- `pt-BR`: portugués (brasileño)

Estos son todos los paquetes de idiomas incorporados. Univer es un proyecto de código abierto, y los desarrolladores de todo el mundo son bienvenidos a añadir o mejorar estos locales.

## Configuración regional

`region` selecciona las convenciones regionales que siguen las características regionales. La configuración es compartida por las unidades en la instancia Univer.

Ambos ajustes `LocaleType` valores, por ejemplo, `LocaleType.EN_US` es `enUS`, mientras `en-US` es un nombre de archivo de paquete de idioma y una etiqueta BCP 47. No pasar códigos de país como `US` o `SG` como tal `region`. Si la UI utiliza un local diferente, la región no requiere que su paquete de idiomas sea cargado.

Si `region` nunca está establecido, sigue `locale`, incluyendo llamadas `setLocale()` posteriores. Configurar `region` en la inicialización, o llamar `setRegion()` detiene el siguiente automático. Después de eso, cambiar el idioma mantiene la región seleccionada. Ninguna API pública restaura el siguiente automático; cuando los dos deben cambiar juntos, establece ambos explícitamente.

Agregue `region: LocaleType.DE_DE` junto a `locale` en `createUniver()` o `new Univer()` para mantener el idioma UI mientras se aplican convenios regionales alemanes.

```typescript
import { LocaleType } from '@univerjs/core'

univerAPI.setRegion(LocaleType.DE_DE)
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentRegion()) // deDE
```

Aquí la interfaz de usuario cambia a inglés mientras que el formato regional sigue siendo alemán. `getCurrentLocale()` y `getCurrentRegion()` devuelven los identificadores en realidad en efecto. Para cambiar ambos juntos, llame a ambos puntos con el mismo valor `LocaleType`.

- **Hojas: controles de divisas**: `region` determina el icono de moneda en la barra de herramientas, las opciones de divisas y contabilidad y sus previsiones, y el formato que el comando de divisas aplica. Cambiar no reescribir los formatos de celda existentes o convertir los valores monetarios.
- **Docs: estadística**: `region` formatea los recuentos mostrados en el diálogo de estadísticas y la barra de estado, incluyendo separadores de agrupación. Cambiar `region` no cambia las reglas de conteo.
- **Thread comments, when enabled**: `region` controla cómo se muestran las fechas y los tiempos, utilizando un reloj 24 horas y dígitos latinos. `locale` controles el texto UI comentario. Ni cambios horarios almacenados, y `region` no es un ajuste de la zona horaria.
- **Boards, Slides, Bases, PDFs**: `locale` controla la interfaz de usuario traducida. `region` está disponible para funciones compartidas que lo leen, tales como comentarios de hilo después de ser integrados. No se reforma automáticamente tabla o texto de diapositivas, campos de base, o contenido PDF.
