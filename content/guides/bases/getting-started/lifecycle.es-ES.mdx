## Ciclo de vida global

- **Comenzar**: Univer está inicializando, y no existe ninguna unidad de negocio todavía.
- **Listo**: La primera unidad de negocio ha sido creada. Unidades posteriores no activan esta etapa de nuevo.
- **Rendered**: La interfaz de usuario estándar ha completado su primer interruptor de renderizado. El contenido asincrono puede estar cargando.
- **Tranquila.**: La interfaz de usuario estándar llega a esta etapa después de un retraso después de Rendered. No espera todas las tareas asincrónicas.

### API de Facade

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="Qué comunica el evento">

`LifeCycleChanged` reporta la etapa global de Univer. Si el plugin B está cargado después de la etapa global ha llegado a `Ready`, B todavía funciona `onReady()` pero no se emite un segundo evento global `Ready` .

Un oyente que agregue puede recibir el estadio actual inmediatamente, incluyendo `Starting`. Para determinar en qué etapa está Univer, llame directamente a `univerAPI.getCurrentLifecycleStage()` .

</Callout>

Para eliminar un oyente, deseche el objeto `disposable` devuelto:

```typescript
disposable.dispose()
```

## Hooks del ciclo de vida de plugins

Un plugin funciona `onStarting()` cuando se carga y luego se alcanza a la etapa global actual. Cargando B en diferentes momentos muestra cómo sus llamadas de gancho se comparan con las de A.

<LifecycleDemo />

Los plugins generales cargan en el registro. Un plugin de tipo de negocio generalmente carga antes de la primera unidad de ese tipo se crea. Si un nuevo plugin se añade a un tipo que ya ha comenzado, se carga en un lote diferido. Una dependencia explícita puede causar un plugin para cargar antes.

Cada lote llama ganchos sincronizadamente, una etapa a la vez y en orden de dependencia, sin esperar a trabajo asincrónico. Confirme que la unidad requerida, elemento DOM, o recurso está listo antes de acceder a él.
