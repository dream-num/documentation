Bases API와 그 문서를 통해 실행되는 4가지 개념. Base가 조립된 방식, 저장, 변경 및 제어 방식과 Univer Base를 설치하기 전에 이해해야 합니다.

## 기본 개념 [#basic-concepts]

### 플러그인

Univer는 플러그인으로 기능을 제공합니다. `@univerjs-pro/bases`에는 기본 모델, 명령 및 `UniverBasesPlugin`가 포함되어 있습니다. `@univerjs-pro/bases-ui`은 독립 작업대와 `UniverBasesUIPlugin`를 포함합니다. 모델 플러그인은 또한 공식 엔진을 사용하여, 그래서 공식 필드는 기본 계산 파이프라인에 참여합니다.

애플리케이션이 필요한 제품 플러그인 만 등록하십시오. [설치 가이드](/guides/bases/getting-started/installation)는 완벽한 브라우저 설정 및 기술적 의존성을 제공합니다.

### 스냅샷과 데이터 모델

`IBaseSnapshot`는 단일베이스 유닛의 지속 형식입니다. 테이블과 주문이 포함되어 있습니다. 각 테이블에는 필드, 레코드, 레이아웃 및 각 컬렉션의 순서가 포함되어 있습니다. 전망은 동일한 레코드에 투영되어 있으므로 조회수는 데이터의 다른 사본을 만들 수 없습니다.

스냅 샷 생성, 저장, 또는베이스 복원. 일단 단위가 실행되면, 스냅 샷 개체를 직접 수정하지 마십시오. 스키마는 [기본 Snapshot](/guides/bases/model/base-snapshot) 및 [테이블, 필드 및 기록](/guides/bases/model/tables-fields-records)에 설명됩니다.

### 명령

runtime에서 변경 명령을 통해 이동합니다. 테이블을 만들고, 기록을 편집하거나 명령 레이어를 통해 볼을 변경하거나 Facade 레이어는 모델, UI, undo/redo 및 동기화의 협업 경로 유지.

애플리케이션 코드는 Facade API를 사용해야 합니다. Facade가 노출되지 않는 낮은 수준의 통합을 위해 명령 ID를 직접 사용하십시오.

### Facade API

Facade API는 기본 명령과 모델 레이어를 통해 객체 레이어를 제공합니다: 기본, 테이블, 필드, 기록, 그리고 보기. 모델 작업에 `@univerjs-pro/bases/facade` 가져 오기 및 UI 상태에 `@univerjs-pro/bases-ui/facade`, 다음 플러그인을 등록 한 후 `FUniver.newAPI(univer)`를 호출합니다.

다음, [설치 및 기본 사용](/guides/bases/getting-started/installation)를 읽고, 다음 [기본 Facade API 가이드](/guides/bases/getting-started/facade)을 따르고 기본 데이터를 편집합니다.
