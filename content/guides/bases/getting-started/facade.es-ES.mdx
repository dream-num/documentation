Facade API es la capa que utiliza la aplicación en lugar de trabajar directamente con el modelo Bases. Cubre operaciones rutinarias como la creación de Bases, tablas, campos, registros y vistas, así como filtros, tipos, grupos, selecciones y navegación UI.

<Callout type="warning" title="Precaución">
  Los cambios al modelo Base son sincronizados. Los métodos de activación de la UI devuelven las promesas y deben ser esperados.
</Callout>

## Habilitar entradas de fachada

Importar la entrada de fachada para cada capacidad Bases que la aplicación utiliza:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Crear el objeto API después de registrar la instancia Univer y sus plugins necesarios:

```ts
const univerAPI = FUniver.newAPI(univer)
```
