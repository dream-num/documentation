API de Facade proporciona una capa orientada a la aplicación sobre el modelo Bases. Úselo para operaciones comunes como la creación de bases, tablas, campos, registros, vistas, filtros, ordenaciones, grupos, selecciones y navegación de la interfaz de usuario.

<Callout type="warning" title="Precaución">
Las mutaciones del modelo Base son síncronas. Los métodos de activación de la UI devuelven promesas y deben usar `await`.
</Callout>

## Habilitar entradas de fachada

Importe la entrada de fachada para cada capacidad de Bases utilizada por su aplicación:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Cree el objeto API después de que se registren la instancia de Univer y los complementos requeridos:

```ts
const univerAPI = FUniver.newAPI(univer)
```
