API de Facade proporciona una capa orientada a la aplicación sobre el modelo Bases. Úselo para operaciones comunes como la creación de bases, tablas, campos, registros, vistas, filtros, ordenaciones, grupos, selecciones y navegación de la interfaz de usuario.

<Callout type="warning" title="Caution">
Las mutaciones del modelo Base son síncronas. Los métodos de activación de la UI devuelven promesas y deben usar `await`.
</Callout>

## Habilitar entradas de fachada

Importe la entrada de fachada para cada capacidad de Bases utilizada por su aplicación:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Cree el objeto API después de que se registren la instancia de Univer y los complementos requeridos:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Cree y lea una base

Usar `createBase` para crear una unidad base a través de la capa de fachada. En el código de configuración de nivel inferior, cree la unidad con `univer.createUnit(UniverInstanceType.UNIVER_BASE, snapshot)`.

```ts
const base = univerAPI.createBase({
  id: 'base-demo',
  name: 'Base Demo',
})

const activeBase = univerAPI.getActiveBase()
const sameBase = univerAPI.getBase(base.getId())
```

## Crear una tabla

```ts
const table = base.insertTable('Tasks', { primaryFieldName: 'Title' })
const status = table.addField('Status', univerAPI.Enum.BaseFieldType.SingleSelect)
```

## Trabajar con registros

```ts
const record = table.addRecord({
  Title: 'Write docs',
  Status: 'In progress',
}, univerAPI.Enum.BaseFieldKeyEnum.Name)

record.setValue(status.getId(), 'Done')
```

## Trabajar con el estado de la interfaz de usuario

`@univerjs-pro/bases-ui/facade` agrega API de interfaz de usuario para activación, selección, desplazamiento, edición y paneles de vista/tabla.

```ts
const baseUI = univerAPI.getBaseUI()
const view = table.getViews()[0]
if (!view) throw new Error('No table view')
await baseUI.activateTable(table.getId())
await baseUI.activateView(view.getId())
baseUI.setSelection({
  type: 'grid-record',
  tableId: table.getId(),
  viewId: view.getId(),
  recordId: record.getId(),
})
```
