Cuatro conceptos se ejecutan a través de la API de Bases y su documentación. Cubren cómo se monta una Base, se almacena, cambia y se controla, y deben entenderse antes de instalar las Bases Univer.

## Conceptos básicos [#basic-concepts]

### Plugins

Univer proporciona características como plugins. `@univerjs-pro/bases` contiene el modelo Base, sus comandos, y `UniverBasesPlugin`. `@univerjs-pro/bases-ui` contiene el banco de trabajo independiente y `UniverBasesUIPlugin`. El plugin del modelo también utiliza el motor de fórmula, por lo que los campos de fórmula participan en el oleoducto de cálculo Base.

Registro sólo los plugins de producto que requiere la aplicación. El [guía de instalación](/guides/bases/getting-started/installation) proporciona la configuración completa del navegador y las dependencias técnicas detrás de ella.

### Instantánea y modelo de datos

`IBaseSnapshot` es el formato de persistencia para una sola unidad Base. Contiene las tablas y su orden. Cada tabla contiene campos, registros, vistas y el orden de cada colección. Una vista es una proyección sobre los mismos registros, por lo que cambiar las vistas no crea otra copia de los datos.

Una instantánea crea, salva o restaura una Base. Una vez que la unidad se ejecuta, no modifique el objeto de instantáneas directamente. El esquema se describe en [Base Snapshot](/guides/bases/model/base-snapshot) y [Cuadros, campos y registros](/guides/bases/model/tables-fields-records).

### Comando

Los cambios en el tiempo de ejecución pasan por los comandos. Crear una tabla, actualizar un campo, editar un registro, o cambiar una vista a través de la capa de comandos o la capa Facade mantiene el modelo, UI, deshacer/redo, y caminos de colaboración en sincronización.

El código de aplicación debe utilizar las API de Facade. Utilice los IDs de comandos directamente sólo para una integración de nivel inferior que la Facade no expone.

### API de Facade

Facade API proporciona una capa de objeto sobre las capas de comando Base y modelo: Base, tabla, campo, registro, y vista. Importe `@univerjs-pro/bases/facade` para las operaciones de modelo y `@univerjs-pro/bases-ui/facade` de estado UI, luego llame a `FUniver.newAPI(univer)` después de registrar los plugins.

A continuación, lee [Instalación &quot; Usage básico](/guides/bases/getting-started/installation), luego siga el [Bases Guía Facade API](/guides/bases/getting-started/facade) para crear y editar datos Base.
