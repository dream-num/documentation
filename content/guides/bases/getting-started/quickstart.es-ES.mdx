Antes de instalar Univer Bases, conozca los cuatro conceptos que aparecen en toda su API y documentación. Explican cómo se compone, guarda, modifica y controla una Base.

## Conceptos básicos [#basic-concepts]

### Plugins

Las funciones de Univer se distribuyen como plugins. `@univerjs-pro/bases` aporta el modelo de Base, los comandos y `UniverBasesPlugin`; `@univerjs-pro/bases-ui` aporta el espacio de trabajo independiente y `UniverBasesUIPlugin`. El plugin del modelo también usa el motor de fórmulas Pro para integrar los campos de fórmula en el cálculo de Bases.

Registre solo los plugins de producto que necesite su aplicación. La [guía de instalación](/guides/bases/getting-started/installation) incluye la configuración completa para navegador y sus dependencias técnicas.

### Instantánea y modelo de datos

`IBaseSnapshot` es el formato de persistencia de una unidad Base. Contiene las tablas y su orden; cada tabla contiene campos, registros, vistas y el orden de cada colección. Las vistas son proyecciones de los mismos registros, por lo que cambiar de vista no duplica los datos.

Use una instantánea para crear, guardar o restaurar una Base. Cuando la unidad esté en ejecución, no modifique directamente el objeto de instantánea. Consulte [Instantánea de Base](/guides/bases/model/base-snapshot) y [Tablas, campos y registros](/guides/bases/model/tables-fields-records) para ver el esquema.

### Comando

Los cambios en tiempo de ejecución pasan por comandos. Crear una tabla, actualizar un campo, editar un registro o cambiar una vista mediante comandos o Facade mantiene coherentes el modelo, la interfaz, deshacer/rehacer y la colaboración.

Para el código de aplicación, prefiera Facade API. Use identificadores de comando directamente solo para integraciones de bajo nivel que Facade no exponga.

### API de Facade

Facade API envuelve los comandos y el modelo de Bases con objetos para Base, tabla, campo, registro y vista. Importe `@univerjs-pro/bases/facade` para operaciones del modelo y `@univerjs-pro/bases-ui/facade` para el estado de la interfaz; después cree la API con `FUniver.newAPI(univer)` tras registrar los plugins.

Continúe con [Instalación y uso básico](/guides/bases/getting-started/installation) y después use la [guía de Facade API de Bases](/guides/bases/getting-started/facade) para crear y editar datos.
