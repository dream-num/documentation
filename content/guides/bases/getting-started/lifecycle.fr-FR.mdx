## Cycle de vie global

- **Début**: Univer initialise, et aucune unité commerciale n'existe encore.
- **Prêt**: La première unité commerciale a été créée. Les unités ultérieures ne déclenchent pas cette étape à nouveau.
- **Rendu**: L'interface utilisateur standard a complété son premier commutateur de rendu. Le contenu asynchrone peut encore être chargé.
- **Stabilité** : L'interface utilisateur standard atteint cette étape après un délai après la soumission. Elle n'attend pas toutes les tâches asynchrones.

### API Facade

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="Ce que signale l’événement">

`LifeCycleChanged` rapporte la phase globale de Univer. Si le plugin B est chargé après que la phase globale ait atteint `Ready`, B exécute toujours `onReady()` mais aucun second événement global `Ready` n'est émis.

Un auditeur que vous ajoutez peut recevoir immédiatement l'étape courante, y compris `Starting`. Pour déterminer seulement l'étape Univer, appelez directement `univerAPI.getCurrentLifecycleStage()` .

</Callout>

Pour supprimer un auditeur, disposer de l'objet `disposable` retourné :

```typescript
disposable.dispose()
```

## Hooks de cycle de vie des plugins

Un plugin exécute `onStarting()` lorsqu'il charge puis rattrape jusqu'à la phase mondiale actuelle. Chargement B à différents moments montre comment ses appels de crochet se comparent à ceux de A.

<LifecycleDemo />

Un plugin de type business charge habituellement avant la création de la première unité de ce type. Si un nouveau plugin est ajouté à un type qui a déjà commencé, il charge dans un lot différé. Une dépendance explicite peut provoquer une charge d'un plugin plus tôt.

Chaque lot d'appels s'accroche synchronement, une étape à la fois et en ordre de dépendance, sans attendre un travail asynchrone. Confirmez que l'unité requise, l'élément DOM ou la ressource est prêt avant d'y accéder.
