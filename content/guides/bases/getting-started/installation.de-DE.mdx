In diesem Kapitel werden die Installation und die grundlegende Nutzung von Univer Bases vorgestellt. Bases wird als Univer Pro-Produkt vertrieben und verwendet derzeit den Plugin-Modus.

Wenn Sie mit den Kernkonzepten von Univer nicht vertraut sind, lesen Sie zuerst [Quickstart](/guides/bases/getting-started/quickstart).

## Mit dem Plugin-Modus erstellen

Eine Browser-Bases-Anwendung registriert normalerweise die gemeinsame Univer-Laufzeit, die Render-Engine, die UI-Shell, die Formel-Engine, die Pro-Lizenz und dann das Bases-Modell und die Benutzeroberfläche Plugins.

### Installation

Installieren Sie die Mindestpakete für einen Browser-Bases-Editor:

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab>
    ```shell
    npm install @univerjs/core @univerjs/design @univerjs/engine-formula @univerjs/engine-render @univerjs/sheets-formula @univerjs/ui @univerjs-pro/license @univerjs-pro/bases @univerjs-pro/bases-ui
    ```
  </Tab>
  <Tab>
    ```shell
    pnpm add @univerjs/core @univerjs/design @univerjs/engine-formula @univerjs/engine-render @univerjs/sheets-formula @univerjs/ui @univerjs-pro/license @univerjs-pro/bases @univerjs-pro/bases-ui
    ```
  </Tab>
  <Tab>
    ```shell
    yarn add @univerjs/core @univerjs/design @univerjs/engine-formula @univerjs/engine-render @univerjs/sheets-formula @univerjs/ui @univerjs-pro/license @univerjs-pro/bases @univerjs-pro/bases-ui react react-dom rxjs
    ```
  </Tab>
</Tabs>

### Verwendung

<Callout type="warning" title="Caution">
  - Registrieren Sie `UniverLicensePlugin`, bevor Sie Bases-Plugins registrieren.
  - Importieren Sie Shared UI CSS vor Produkt-UI-CSS.
  - Registrieren Sie Formel-Plugins, wenn Sie Formelfelder verwenden.
</Callout>

<Steps>
  <Step>
Importieren Sie Stile, Gebietsschemapakete und das Erforderliche Plugins:

    ```ts
    import { UniverBasesPlugin } from '@univerjs-pro/bases'
    import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
    import BasesUIEnUS from '@univerjs-pro/bases-ui/locale/en-US'
    import BasesEnUS from '@univerjs-pro/bases/locale/en-US'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverSheetsFormulaPlugin } from '@univerjs/sheets-formula'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/bases-ui/lib/index.css'
    ```
  </Step>
  <Step>
Importieren Sie Fassadeneinträge, wenn Sie die Facade-API verwenden möchten:

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/bases/facade'
    import '@univerjs-pro/bases-ui/facade'
    ```
  </Step>
  <Step>
Erstellen Sie eine Univer-Instanz, registrieren Sie Plugins und erstellen Sie eine Basiseinheit:

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          BasesEnUS,
          BasesUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverFormulaEnginePlugin)
    univer.registerPlugin(UniverSheetsFormulaPlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBasesPlugin)
    univer.registerPlugin(UniverBasesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BASE, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

## Andere Release-Kanäle

Neben stabilen Releases bietet Univer Alpha-, Beta- und Nightly-Kanäle. Mit diesen Kanälen können Sie kommende Funktionen früher testen, sie weisen jedoch möglicherweise unvollständiges oder instabiles Verhalten auf. Vermeiden Sie die Verwendung in der Produktion, es sei denn, Sie haben einen Validierungsplan.

```package-install
npm install @univerjs-pro/bases@alpha
npm install @univerjs-pro/bases@beta
```
