Univer Bases は Univer Pro の機能です。本番環境のアプリケーションでは、有効な Pro ライセンスが必要です。また、ほかの Pro 製品と同様にデプロイ時の考慮事項があります。

## ライセンスプラグイン

Bases プラグインより先に `UniverLicensePlugin` を登録します。

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

ライセンステキストはソース管理の対象外にしてください。ブラウザーアプリケーションでは、ビルド設定またはランタイム設定を通じて注入します。

## パッケージのスコープ

Base のパッケージは `@univerjs-pro` スコープで提供されています。

| 機能 | パッケージ |
| --- | --- |
| Base のコアモデル | `@univerjs-pro/bases` |
| ブラウザー向け Base UI | `@univerjs-pro/bases-ui` |

## デプロイ時の注意事項

- Node.js サービスでは、モデルパッケージのみを使用します。
- 数式フィールドを使用する場合は、数式プラグインを登録します。
- 本番環境で添付ファイルフィールドを有効にする前に、添付ファイルのアップロードハンドラーを設定します。
- Base のスナップショットはアプリケーションデータとして永続化し、Univer のアップグレードに合わせて移行します。

ライセンス、サーバー、デプロイについて詳しくは、[Univer Pro](/guides/pro) を参照してください。
