Facade API предоставляет прикладной уровень над моделью Bases. Используйте его для распространенных операций: создания баз, таблиц, полей, записей, представлений, фильтров, сортировок, групп и выделений, а также навигации по интерфейсу.

<Callout type="warning" title="Внимание">
  Некоторые методы Facade API асинхронны. Если данные нужно прочитать сразу после изменения, используйте `await` или `.then()`.
</Callout>

## Подключение точек входа Facade

Импортируйте точку входа Facade для каждой возможности Bases, которую использует приложение:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Создайте объект API после регистрации экземпляра Univer и необходимых плагинов:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Создание и чтение базы

Чтобы создать модуль Base через слой Facade, используйте `createBase`. В низкоуровневом коде настройки создайте модуль с помощью `univer.createUnit(UniverInstanceType.UNIVER_BASE, snapshot)`.

```ts
const base = univerAPI.createBase({
  id: 'base-demo',
  name: 'Base Demo',
})

const activeBase = univerAPI.getActiveBase()
const sameBase = univerAPI.getBase(base.getId())
```

## Создание таблицы

```ts
const table = base.createTable({
  name: 'Tasks',
  fields: [
    { name: 'Title', type: univerAPI.Enum.BaseFieldTypeEnum.Text },
    { name: 'Status', type: univerAPI.Enum.BaseFieldTypeEnum.SingleSelect },
  ],
})
```

## Работа с записями

```ts
const record = table.addRecord({
  values: {
    Title: 'Write docs',
    Status: 'In progress',
  },
}, { key: univerAPI.Enum.BaseFieldKeyEnum.Name })

record.setValue('Status', 'Done')
```

## Работа с состоянием интерфейса

`@univerjs-pro/bases-ui/facade` добавляет API интерфейса для активации таблиц и представлений, выделения, прокрутки, редактирования и работы с панелями.

```ts
const baseUI = univerAPI.getBaseUI(base.getId())
baseUI.activateTable(table.getId())
baseUI.setSelection({ tableId: table.getId(), recordId: record.getId() })
```
