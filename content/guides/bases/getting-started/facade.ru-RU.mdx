Facade API — это слой, который приложение использует вместо непосредственной работы с моделью Bases. Он охватывает рутинные операции, такие как создание Bases, таблиц, полей, записей и просмотров, а также фильтры, сортировки, группы, выборки и навигацию по пользовательскому интерфейсу.

<Callout type="warning" title="Осторожно">
  Изменения в Базовой модели синхронны. Методы активации пользовательского интерфейса возвращают обещания и их следует ждать.
</Callout>

## Подключение точек входа Facade

Импорт входа фасада для каждой возможности Базы, которую использует приложение:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Создайте объект API после регистрации экземпляра Univer и его необходимых плагинов:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Дальнейшие шаги

С включенными расширениями Фасада следующие страницы охватывают оставшиеся темы:

- [Общий API](/guides/bases/features/core/general-api) охватывает общие команды, события, отмену и переделку, расширения пользовательского интерфейса, сети, перечисления и утилиты.
- [Univer Базовый API](/guides/bases/features/core/bases-api) объясняет, как создавать и читать Базы и как работать с их моделью и состоянием пользовательского интерфейса.
- [Базовый фасадный справочник](/reference/facade/base) предоставляет полную ссылку на метод.
