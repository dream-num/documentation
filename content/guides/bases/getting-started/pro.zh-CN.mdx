title: 使用 Univer SDK Pro

---

Bases 属于 Univer SDK Pro。先按[安装指南](/guides/bases/getting-started/installation)启动编辑器，再根据需要添加扩展，不必一次安装全部插件。

## 许可证

按[许可证文档](/guides/server-integration/license#in-plugin-mode)注册 `UniverLicensePlugin`，并将它放在 Bases 和其他 Pro 插件之前。

## 选择功能包

| 功能 | 包 |
| --- | --- |
| 核心和界面 | `@univerjs-pro/bases`、`@univerjs-pro/bases-ui` |
| 导入导出 | `@univerjs-pro/exchange-client`、`@univerjs-pro/bases-exchange-client` |
| 仪表盘和透视视图 | `@univerjs-pro/bases-dashboard`、`@univerjs-pro/bases-dashboard-ui` |
| 评论 | `@univerjs-pro/bases-thread-comment`、`@univerjs-pro/bases-thread-comment-ui` |
| 历史记录 | `@univerjs-pro/bases-history`、`@univerjs-pro/bases-history-ui` |

各功能页提供注册方式和示例，见[Bases 功能一览](/guides/bases#主要功能)。所有 Univer 包使用匹配版本，并为新增 UI 插件合并语言资源。

## 哪些功能需要服务端

本地记录编辑、视图、公式和仪表盘可以直接在浏览器使用，保存方式由业务应用决定。导入导出需要文件转换后端；多人协同、共享评论和历史版本需要相应服务，按[服务端集成](/guides/server-integration)接入。

附件上传需连接业务文件存储，见[附件字段](/guides/bases/features/core/fields#附件字段)。保存 Base 时使用完整快照，保留插件资源，见[Base 快照](/guides/bases/model/base-snapshot)。
