Univer Bases 是 Univer Pro 提供的一项功能。生产环境中的应用需要有效的 Pro 许可证，并且应遵循与其他 Pro 产品相同的部署注意事项。

## 许可证插件

请先注册 `UniverLicensePlugin`，再注册 Bases 插件：

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

请勿将许可证文本纳入版本控制。在浏览器应用中，应通过构建配置或运行时配置注入许可证文本。

## 包作用域

Base 相关包位于 `@univerjs-pro` 作用域下：

| 功能 | 包 |
| --- | --- |
| Base 核心模型 | `@univerjs-pro/bases` |
| 浏览器端 Base UI | `@univerjs-pro/bases-ui` |

## 部署注意事项

- 在 Node.js 服务中只使用模型包。
- 使用公式字段时，请注册公式插件。
- 在生产环境中启用附件字段前，请先配置附件上传处理程序。
- 将 Base 快照作为应用数据持久化，并在升级 Univer 时一并迁移。

有关许可证、服务器和部署的详细信息，请参阅 [Univer Pro](/guides/pro)。
