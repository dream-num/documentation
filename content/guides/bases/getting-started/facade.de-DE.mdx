Die Fassaden-API bietet eine anwendungsorientierte Ebene über dem Bases-Modell. Verwenden Sie es für allgemeine Vorgänge wie das Erstellen von Basen, Tabellen, Feldern, Datensätzen, Ansichten, Filtern, Sortierungen, Gruppen, Auswahlen und UI-Navigation.

<Callout type="warning" title="Caution">
Base-Modelländerungen sind synchron. UI-Aktivierungsmethoden geben Promises zurück und sollten mit `await` aufgerufen werden.
</Callout>

## Fassadeneinträge aktivieren

Importieren Sie den Fassadeneintrag für jede von Ihrer Anwendung verwendete Bases-Funktion:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Erstellen Sie das API-Objekt, nachdem die Univer-Instanz und die erforderlichen Plugins registriert sind:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Erstellen und lesen Sie eine Basis

Verwenden `createBase` zum Erstellen einer Basiseinheit durch die Fassadenebene. Erstellen Sie im Setup-Code auf niedrigerer Ebene die Einheit mit `univer.createUnit(UniverInstanceType.UNIVER_BASE, snapshot)`.

```ts
const base = univerAPI.createBase({
  id: 'base-demo',
  name: 'Base Demo',
})

const activeBase = univerAPI.getActiveBase()
const sameBase = univerAPI.getBase(base.getId())
```

## Erstellen Sie eine Tabelle

```ts
const table = base.insertTable('Tasks', { primaryFieldName: 'Title' })
const status = table.addField('Status', univerAPI.Enum.BaseFieldType.SingleSelect)
```

## Arbeiten Sie mit Datensätzen

```ts
const record = table.addRecord({
  Title: 'Write docs',
  Status: 'In progress',
}, univerAPI.Enum.BaseFieldKeyEnum.Name)

record.setValue(status.getId(), 'Done')
```

## Arbeiten Sie mit dem UI-Status

`@univerjs-pro/bases-ui/facade` fügt UI-APIs für Tabellen-/Ansichtsaktivierung, Auswahl, Bildlauf, Bearbeitung und Bedienfelder hinzu.

```ts
const baseUI = univerAPI.getBaseUI()
const view = table.getViews()[0]
if (!view) throw new Error('No table view')
await baseUI.activateTable(table.getId())
await baseUI.activateView(view.getId())
baseUI.setSelection({
  type: 'grid-record',
  tableId: table.getId(),
  viewId: view.getId(),
  recordId: record.getId(),
})
```
