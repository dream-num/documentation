Facade API 是應用直接使用的一層介面，位於 Bases 模型之上。建立 Base、表格、欄位、記錄和檢視，以及篩選、排序、分組、選區和 UI 導航等日常操作，都透過這一層完成。

<Callout type="warning" title="注意">
  Base 模型的修改是同步的；UI 啟用方法返回 Promise，需要 `await`。
</Callout>

## 啟用 Facade 進入點

應用使用哪些 Bases 功能，就匯入對應的 Facade 入口：

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

先註冊 Univer 例項及其所需的外掛，再建立 API 物件：

```ts
const univerAPI = FUniver.newAPI(univer)
```
