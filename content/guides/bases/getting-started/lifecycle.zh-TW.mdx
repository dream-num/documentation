## 全域生命週期

- **Starting**：Univer 正在初始化，尚未建立任何業務例項。
- **Ready**：首個業務例項已建立完成。之後再建立例項不會重新觸發這個階段。
- **Rendered**：標準 UI 已完成第一次渲染切換。此時非同步內容可能仍在載入。
- **Steady**：標準 UI 在 Rendered 之後延遲一段時間進入這個階段，不會等待所有非同步任務結束。

### Facade API

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="事件監聽的範圍">

`LifeCycleChanged` 報告的是 Univer 的全域性階段。如果在全域性階段已經到達 `Ready` 之後再載入外掛 B，B 仍會執行 `onReady()`，但不會再觸發一次全域性 `Ready` 事件。

新增監聽器後，回撥可能立即收到當前階段，包括 `Starting`。如果只需要瞭解 Univer 當前所處的階段，可直接呼叫 `univerAPI.getCurrentLifecycleStage()`。

</Callout>

要移除監聽器，銷燬返回的 `disposable` 物件：

```typescript
disposable.dispose()
```

## 外掛生命週期鉤子

外掛載入時執行 `onStarting()`，然後追趕上 Univer 當前所處的全域性階段。在不同時機載入 B，可以對比它與 A 的鉤子呼叫順序。

<LifecycleDemo />

通用外掛在註冊時載入。業務型別外掛通常在建立該型別的第一個例項之前載入。如果某個型別已經啟動，新加入的外掛會在一個延遲批次中載入。顯式依賴可以使外掛更早載入。

每一批次都同步呼叫鉤子，按依賴順序逐階段執行，不等待鉤子中的非同步任務。訪問所需的例項、DOM 元素或資源之前，應先確認其已經就緒。
