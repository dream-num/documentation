安装 Univer Bases 前，请先了解贯穿其 API 和文档的四个基本概念。它们分别说明 Base 如何组装、持久化、修改和操作。

## 基本概念 [#basic-concepts]

### 插件

Univer 的功能以插件形式提供。`@univerjs-pro/bases` 提供 Base 模型、命令和 `UniverBasesPlugin`；`@univerjs-pro/bases-ui` 提供独立工作台和 `UniverBasesUIPlugin`。为了让公式字段接入 Bases 的计算流程，模型插件还会使用 Pro 公式引擎。

只需注册应用实际需要的产品插件。[安装和基本使用](/guides/bases/getting-started/installation)列出了完整的浏览器配置及其技术依赖。

### 快照与数据模型

`IBaseSnapshot` 是单个 Base 单元的持久化格式。它包含表及表顺序；每张表包含字段、记录、视图，以及各集合的顺序。视图只是同一批记录的不同投影，切换视图不会复制数据。

快照用于创建、保存或恢复 Base。单元运行后，不要直接修改快照对象。数据结构请参阅 [Base 快照](/guides/bases/model/base-snapshot)和[表、字段与记录](/guides/bases/model/tables-fields-records)。

### 命令

运行时变更通过命令执行。无论是创建表、更新字段、编辑记录还是更改视图，通过命令或 Facade 层操作都能让模型、UI、撤销/重做和协同链路保持一致。

应用代码应优先使用 Facade API；只有 Facade 尚未提供所需能力时，才直接调用命令 ID 完成底层集成。

### Facade API

Facade API 将 Bases 的命令和模型封装成 Base、表、字段、记录与视图对象。模型操作需要导入 `@univerjs-pro/bases/facade`，UI 状态操作需要导入 `@univerjs-pro/bases-ui/facade`；注册插件后，再通过 `FUniver.newAPI(univer)` 创建 API。

接下来请完成[安装和基本使用](/guides/bases/getting-started/installation)，然后通过 [Bases Facade API 指南](/guides/bases/getting-started/facade)创建和编辑 Base 数据。
