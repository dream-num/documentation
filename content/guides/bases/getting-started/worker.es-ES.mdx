Las bases pueden descargar el cálculo de fórmulas a un Worker[^web-worker] sobre RPC. Establecer `notExecuteFormula: true` en el motor de fórmula del hilo principal, y registrar el plugin Bases remotas y el motor de cálculo dentro del Worker.

Esta página comienza desde [instalación y uso básico](/guides/bases/getting-started/installation), y los snippets a continuación extienden esa configuración. Registrar plugins antes de crear o cargar contenido, y reemplazar un registro existente en lugar de registrar el mismo plugin dos veces.

## Hilo principal

`UniverRPCMainThreadPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `workerURL` | `string \| URL \| Worker` |  | Conecta el editor a un Worker que realiza el cálculo de fórmulas. |

`UniverProFormulaEnginePlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `notExecuteFormula` | `boolean` | `false` | Omita el cálculo de fórmulas en el hilo principal cuando el Trabajador lo realiza. |

```typescript title="main.ts"
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula'
import { UniverRPCMainThreadPlugin } from '@univerjs/rpc'

univer.registerPlugin(UniverRPCMainThreadPlugin, {
  workerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
univer.registerPlugin(UniverProFormulaEnginePlugin, { notExecuteFormula: true })
```

## Entrada del Worker

`UniverLicensePlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenido del archivo de licencia del cliente. |

```typescript title="worker.ts"
import { UniverRemoteBasesPlugin } from '@univerjs-pro/bases/worker'
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula/worker'
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { LocaleType, Univer } from '@univerjs/core'
import { UniverRPCWorkerThreadPlugin } from '@univerjs/rpc/worker'

const univer = new Univer({ locale: LocaleType.ES_ES })
univer.registerPlugin(UniverLicensePlugin, { license: 'your license.txt' })
univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRemoteBasesPlugin)
univer.registerPlugin(UniverRPCWorkerThreadPlugin)
```

Utilice un módulo Trabajador con su propio archivo de entrada, y mantenga las versiones de paquetes idénticas en el Worker y en el hilo principal. Rendering e interacción del usuario permanecen en el hilo central.

## Vistas dinámicas y paneles

Para ejecutar el cálculo de pivote de panel en el Worker, establece `notExecuteCalculation: true` en el `UniverBaseDashboardPlugin` del hilo principal y regístrese `UniverRemoteBaseDashboardPlugin` dentro del mismo Worker. Los plugins de interfaz de usuario de panel permanecen en el hilo principal.

`UniverBaseDashboardPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `notExecuteCalculation` | `boolean` |  | Mueve el cálculo de pivote de panel de control del hilo principal. Establece esta opción a `true` cuando se utiliza el plugin de panel remoto. |

```typescript title="main.ts"
import { UniverBaseDashboardPlugin } from '@univerjs-pro/bases-dashboard'

univer.registerPlugin(UniverBaseDashboardPlugin, { notExecuteCalculation: true })
```

```typescript title="worker.ts"
import { UniverRemoteBaseDashboardPlugin } from '@univerjs-pro/bases-dashboard/worker'

univer.registerPlugin(UniverRemoteBaseDashboardPlugin)
```

[^web-worker]: Un Web Worker ejecuta JavaScript fuera del hilo principal del navegador y se comunica mediante mensajes. No puede acceder directamente al DOM; mover los cálculos no mueve la interfaz del editor.
