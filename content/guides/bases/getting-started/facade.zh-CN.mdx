Facade API 是应用直接使用的一层接口，位于 Bases 模型之上。创建 Base、表格、字段、记录和视图，以及筛选、排序、分组、选区和 UI 导航等日常操作，都通过这一层完成。

<Callout type="warning" title="注意">
  Base 模型的修改是同步的；UI 激活方法返回 Promise，需要 `await`。
</Callout>

## 启用 Facade 入口

应用使用哪些 Bases 功能，就导入对应的 Facade 入口：

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

先注册 Univer 实例及其所需的插件，再创建 API 对象：

```ts
const univerAPI = FUniver.newAPI(univer)
```
