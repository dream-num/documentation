Facade API 在 Bases 模型之上提供了一个面向应用的接口层，可用于创建 Base、表格、字段、记录、视图、筛选条件、排序、分组和选区，以及进行 UI 导航等常见操作。

<Callout type="warning" title="注意">
  Base 模型变更是同步的；UI 激活方法返回 Promise，需要使用 `await`。
</Callout>

## 启用 Facade 入口

为应用使用的每项 Bases 功能导入相应的 Facade 入口：

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

注册 Univer 实例和所需插件后，再创建 API 对象：

```ts
const univerAPI = FUniver.newAPI(univer)
```
