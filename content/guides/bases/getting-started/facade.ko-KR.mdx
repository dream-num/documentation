Facade API는 기본 모델과 직접 작업하는 대신 응용 프로그램을 사용하는 레이어입니다. 그것은 기본, 테이블, 필드, 기록 및 레이아웃, 필터, 정렬, 그룹, 선택 및 UI 탐색을 생성과 같은 일상적인 작업을 다룹니다.

<Callout type="warning" title="주 메뉴">
  기본 모델로 변경은 비동기입니다. UI 활성화 방법 반환 약속을 약속하고 기다리고 있어야합니다.
</Callout>

## Facade 진입점 활성화

응용 프로그램 용도에 사용되는 각 Bases 기능에 대한 외관 항목을 가져 오기 :

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Univer 인스턴스와 필요한 플러그인을 등록한 후 API 객체를 생성합니다.

```ts
const univerAPI = FUniver.newAPI(univer)
```

## 다음 단계

Facade extensions 활성화, 다음 페이지는 나머지 주제를 다룹니다:

- [일반 API](/guides/bases/features/core/general-api)는 공유된 명령, 사건, undo 및 redo, UI 연장, 네트워킹, enums 및 유틸리티를 포함합니다.
- [Univer 기초 API](/guides/bases/features/core/bases-api)는 모델 및 UI 상태와 함께 작동하고 읽는 방법을 설명합니다.
- [기초 정면 참고](/reference/facade/base)는 완전한 방법 참고를 제공합니다.
