Facade API는 Bases 모델 위에 애플리케이션용 계층을 제공합니다. Base, 테이블, 필드, 레코드, 뷰, 필터, 정렬, 그룹, 선택 영역을 만들거나 UI를 탐색하는 등의 일반적인 작업에 사용하세요.

<Callout type="warning" title="주의">
  일부 Facade API는 비동기 방식으로 동작합니다. 데이터를 변경한 직후 읽어야 한다면 `await` 또는 `.then()`을 사용하세요.
</Callout>

## Facade 진입점 활성화

애플리케이션에서 사용하는 각 Bases 기능의 Facade 진입점을 가져옵니다.

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Univer 인스턴스와 필수 플러그인을 등록한 다음 API 객체를 만듭니다.

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Base 생성 및 읽기

Facade 계층을 통해 Base 단위를 만들려면 `createBase`를 사용합니다. 하위 수준 설정 코드에서는 `univer.createUnit(UniverInstanceType.UNIVER_BASE, snapshot)`으로 단위를 만듭니다.

```ts
const base = univerAPI.createBase({
  id: 'base-demo',
  name: 'Base Demo',
})

const activeBase = univerAPI.getActiveBase()
const sameBase = univerAPI.getBase(base.getId())
```

## 테이블 생성

```ts
const table = base.createTable({
  name: 'Tasks',
  fields: [
    { name: 'Title', type: univerAPI.Enum.BaseFieldTypeEnum.Text },
    { name: 'Status', type: univerAPI.Enum.BaseFieldTypeEnum.SingleSelect },
  ],
})
```

## 레코드 작업

```ts
const record = table.addRecord({
  values: {
    Title: 'Write docs',
    Status: 'In progress',
  },
}, { key: univerAPI.Enum.BaseFieldKeyEnum.Name })

record.setValue('Status', 'Done')
```

## UI 상태 작업

`@univerjs-pro/bases-ui/facade`는 테이블 및 뷰 활성화, 선택, 스크롤, 편집, 패널을 위한 UI API를 추가합니다.

```ts
const baseUI = univerAPI.getBaseUI(base.getId())
baseUI.activateTable(table.getId())
baseUI.setSelection({ tableId: table.getId(), recordId: record.getId() })
```
