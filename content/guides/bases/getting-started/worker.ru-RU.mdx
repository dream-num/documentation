Базы могут загружать вычисления формул в Worker[^web-worker] по RPC. Установите `notExecuteFormula: true` на движок формулы основного потока и зарегистрируйте плагин удаленных баз и вычислительный движок внутри Worker.

Эта страница начинается с [Установка и базовое использование](/guides/bases/getting-started/installation), и фрагменты ниже расширяют эту настройку. Регистрируйте плагины перед созданием или загрузкой контента и заменяйте существующую регистрацию, а не регистрируйте один и тот же плагин дважды.

## Основной поток

`UniverRPCMainThreadPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `workerURL` | `string \| URL \| Worker` |  | Подключает редактор к Работнику, который выполняет вычисление формулы. |

`UniverProFormulaEnginePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `notExecuteFormula` | `boolean` | `false` | Пропускает расчёт формулы по основной нити, когда Работник её выполняет. |

```typescript title="main.ts"
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula'
import { UniverRPCMainThreadPlugin } from '@univerjs/rpc'

univer.registerPlugin(UniverRPCMainThreadPlugin, {
  workerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
univer.registerPlugin(UniverProFormulaEnginePlugin, { notExecuteFormula: true })
```

## Точка входа Worker

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое файла клиентской лицензии. |

```typescript title="worker.ts"
import { UniverRemoteBasesPlugin } from '@univerjs-pro/bases/worker'
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula/worker'
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { LocaleType, Univer } from '@univerjs/core'
import { UniverRPCWorkerThreadPlugin } from '@univerjs/rpc/worker'

const univer = new Univer({ locale: LocaleType.RU_RU })
univer.registerPlugin(UniverLicensePlugin, { license: 'your license.txt' })
univer.registerPlugin(UniverProFormulaEnginePlugin)
univer.registerPlugin(UniverRemoteBasesPlugin)
univer.registerPlugin(UniverRPCWorkerThreadPlugin)
```

Используйте модуль Worker со своим собственным файлом ввода и сохраняйте версии пакетов идентичными в Worker и на главном потоке. Рендеринг и взаимодействие пользователей остаются на основном потоке.

## Сводные представления и панели

Для запуска расчета поворота панели управления в Worker установите `notExecuteCalculation: true` на `UniverBaseDashboardPlugin` основного потока и зарегистрируйте `UniverRemoteBaseDashboardPlugin` в том же Worker. Плагины пользовательского интерфейса панели управления остаются на основном потоке.

`UniverBaseDashboardPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `notExecuteCalculation` | `boolean` |  | Перемещает вычисление поворота панели приборов с основного потока. Установите эту опцию на `true` при использовании плагина удаленной панели приборов. |

```typescript title="main.ts"
import { UniverBaseDashboardPlugin } from '@univerjs-pro/bases-dashboard'

univer.registerPlugin(UniverBaseDashboardPlugin, { notExecuteCalculation: true })
```

```typescript title="worker.ts"
import { UniverRemoteBaseDashboardPlugin } from '@univerjs-pro/bases-dashboard/worker'

univer.registerPlugin(UniverRemoteBaseDashboardPlugin)
```

[^web-worker]: Web Worker выполняет JavaScript вне главного потока браузера и обменивается с ним сообщениями. Прямого доступа к DOM нет: перенос вычислений не переносит интерфейс редактора.
