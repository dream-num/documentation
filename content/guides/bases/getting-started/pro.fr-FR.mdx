Univer Bases est une fonctionnalité d’Univer SDK Pro. Les applications en production nécessitent une licence Pro valide et doivent respecter les mêmes considérations de déploiement que les autres produits Pro.

## Extension de licence

Enregistrez `UniverLicensePlugin` avant les extensions Bases :

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

Conservez le texte de la licence en dehors du système de gestion de versions. Dans les applications web, injectez-le au moyen de la configuration de compilation ou d’exécution.

## Espace de noms des paquets

Les paquets Base se trouvent dans l’espace de noms `@univerjs-pro` :

| Fonctionnalité | Paquets |
| --- | --- |
| Modèle Base principal | `@univerjs-pro/bases` |
| Interface Base pour navigateur | `@univerjs-pro/bases-ui` |

## Remarques sur le déploiement

- Dans les services Node.js, utilisez uniquement les paquets du modèle.
- Enregistrez les extensions de formule lorsque vous utilisez des champs de formule.
- Configurez les gestionnaires de téléversement des pièces jointes avant d’activer les champs de pièce jointe en production.
- Stockez les instantanés Base comme des données applicatives et migrez-les en même temps que les mises à niveau d’Univer.

Pour en savoir plus sur les licences, les serveurs et le déploiement, consultez [Univer SDK Pro](/guides/pro).
