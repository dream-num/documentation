---
title: Интеграция в Astro
---

Эта страница начинается с [Установка и базовое использование](/guides/bases/getting-started/installation). Пример монтирует Univer Bases на странице Astro, внутри контейнера с явной высотой.

Простой `<script>` инициализирует редактор непосредственно в браузере. Запуск инициализации на первой нагрузке и на `astro:page-load`, а также утилизация экземпляра перед `astro:before-swap` при использовании ClientRouter. Держите импорт редактора из передней панели Astro. См. [Навигационные события Astro](https://docs.astro.build/en/reference/modules/astro-transitions/) .

### Шаги интеграции

1. Инициализируйте Univer в `mount()` / `astro:page-load`.
2. Удалите экземпляр в `astro:before-swap`.

### Настройка плагинов [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для размещения редактора или его идентификатор. |

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое файла клиентской лицензии. |

### Пример кода

```astro title="src/pages/index.astro"
<div id="univer-bases" style="height: 600px"></div>

<script>
  import { UniverBasesPlugin } from '@univerjs-pro/bases'
  import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
  import BasesUIruRU from '@univerjs-pro/bases-ui/locale/ru-RU'
  import BasesruRU from '@univerjs-pro/bases/locale/ru-RU'
  import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula'
  import { UniverLicensePlugin } from '@univerjs-pro/license'
  import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
  import DesignruRU from '@univerjs/design/locale/ru-RU'
  import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
  import { UniverUIPlugin } from '@univerjs/ui'
  import UIruRU from '@univerjs/ui/locale/ru-RU'

  import '@univerjs/design/lib/index.css'
  import '@univerjs/ui/lib/index.css'
  import '@univerjs-pro/bases-ui/lib/index.css'

  let univerInstance: Univer | undefined

  function mount() {
    const container = document.getElementById('univer-bases')
    if (!container || univerInstance) return

    const univer = new Univer({
      locale: LocaleType.RU_RU,
      locales: {
        [LocaleType.RU_RU]: mergeLocales(
          DesignruRU,
          UIruRU,
          BasesruRU,
          BasesUIruRU,
        ),
      },
    })

    univer.registerPlugin(UniverLicensePlugin, {
      license: 'your license.txt',
    })
    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container })

    univer.registerPlugin(UniverProFormulaEnginePlugin)
    univer.registerPlugin(UniverBasesPlugin)
    univer.registerPlugin(UniverBasesUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
    univerInstance = univer
  }

  function dispose() {
    univerInstance?.dispose()
    univerInstance = undefined
  }

  mount()
  document.addEventListener('astro:page-load', mount)
  document.addEventListener('astro:before-swap', dispose)
</script>
```
