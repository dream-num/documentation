Univer Bases는 Univer SDK Pro 기능입니다. 프로덕션 애플리케이션에는 유효한 Pro 라이선스가 필요하며 다른 Pro 제품과 동일한 배포 사항을 고려해야 합니다.

## 라이선스 플러그인

Bases 플러그인을 등록하기 전에 `UniverLicensePlugin`을 등록합니다.

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

라이선스 텍스트는 소스 제어 외부에 보관하세요. 브라우저 애플리케이션에서는 빌드 또는 런타임 구성을 통해 주입합니다.

## 패키지 범위

Base 패키지는 `@univerjs-pro` 범위에 있습니다.

| 기능 | 패키지 |
| --- | --- |
| 핵심 Base 모델 | `@univerjs-pro/bases` |
| 브라우저 Base UI | `@univerjs-pro/bases-ui` |

## 배포 참고 사항

- Node.js 서비스에서는 모델 패키지만 사용하세요.
- 수식 필드를 사용할 때는 수식 플러그인을 등록하세요.
- 프로덕션에서 첨부 파일 필드를 활성화하기 전에 첨부 파일 업로드 핸들러를 구성하세요.
- Base 스냅샷을 애플리케이션 데이터로 영속화하고 Univer 업그레이드와 함께 마이그레이션하세요.

라이선스, 서버, 배포에 관한 자세한 내용은 [Univer SDK Pro](/guides/pro)를 참고하세요.
