Univer Bases ist eine Funktion von Univer Pro. Produktionsanwendungen benötigen eine gültige Pro-Lizenz und dieselben Überlegungen zur Bereitstellung wie andere Pro-Produkte.

## Lizenz-Plugin

Registrieren Sie `UniverLicensePlugin`, bevor Sie Bases-Plugins registrieren:

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

Bewahren Sie den Lizenztext außerhalb der Quellcodeverwaltung auf. In Browseranwendungen fügen Sie es über Ihre Build- oder Laufzeitkonfiguration ein.

## Paketumfang

Basispakete befinden sich im Bereich `@univerjs-pro`:

| Fähigkeit | Pakete |
| --- | --- |
| Kern-Basismodell | `@univerjs-pro/bases` |
| Browser-Basis-UI | `@univerjs-pro/bases-ui` |

## Bereitstellungshinweise

- Verwenden Sie Modellpakete nur in Node.js-Diensten.
- Registrieren Sie Formel-Plugins, wenn Sie Formelfelder verwenden.
- Konfigurieren Sie Anhang-Upload-Handler, bevor Sie Anhangfelder aktivieren Produktion.
- Base-Snapshots als Anwendungsdaten beibehalten und zusammen mit Univer-Upgrades migrieren.

Details zu Lizenz, Server und Bereitstellung finden Sie unter [Univer Pro](/guides/pro).
