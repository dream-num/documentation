Four concepts run through the Bases API and its documentation. They cover how a Base is assembled, stored, changed, and controlled, and should be understood before installing Univer Bases.

## Basic concepts [#basic-concepts]

### Plugins

Univer provides features as plugins. `@univerjs-pro/bases` contains the Base model, its commands, and `UniverBasesPlugin`. `@univerjs-pro/bases-ui` contains the standalone workbench and `UniverBasesUIPlugin`. The model plugin also uses the formula engine, so formula fields participate in the Base calculation pipeline.

Register only the product plugins that the application requires. The [installation guide](/guides/bases/getting-started/installation) provides the complete browser setup and the technical dependencies behind it.

### Snapshot and data model

`IBaseSnapshot` is the persistence format for a single Base unit. It contains the tables and their order. Each table contains fields, records, views, and the order of each collection. A view is a projection over the same records, so switching views does not create another copy of the data.

A snapshot creates, saves, or restores a Base. Once the unit is running, do not modify the snapshot object directly. The schema is described in [Base Snapshot](/guides/bases/model/base-snapshot) and [Tables, Fields, and Records](/guides/bases/model/tables-fields-records).

### Command

Changes at runtime go through commands. Creating a table, updating a field, editing a record, or changing a view through the command layer or the Facade layer keeps the model, UI, undo/redo, and collaboration paths in sync.

Application code should use Facade APIs. Use command IDs directly only for a lower-level integration that the Facade does not expose.

### Facade API

The Facade API provides an object layer over the Base command and model layers: Base, table, field, record, and view. Import `@univerjs-pro/bases/facade` for model operations and `@univerjs-pro/bases-ui/facade` for UI state, then call `FUniver.newAPI(univer)` after registering the plugins.

Next, read [Installation & Basic Usage](/guides/bases/getting-started/installation), then follow the [Bases Facade API guide](/guides/bases/getting-started/facade) to create and edit Base data.
