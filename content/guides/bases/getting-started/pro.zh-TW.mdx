Univer Bases 是 Univer SDK Pro 提供的功能。正式環境中的應用程式需要有效的 Pro 授權，部署時也必須考量其他 Pro 產品所需的相同事項。

## 授權外掛程式

請先註冊 `UniverLicensePlugin`，再註冊 Bases 外掛程式：

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

請勿將授權文字納入版本控制。在瀏覽器應用程式中，請透過建置或執行階段設定注入授權文字。

## 套件範圍

Base 套件位於 `@univerjs-pro` 範圍中：

| 功能 | 套件 |
| --- | --- |
| Base 核心模型 | `@univerjs-pro/bases` |
| 瀏覽器 Base UI | `@univerjs-pro/bases-ui` |

## 部署注意事項

- 在 Node.js 服務中，只使用模型套件。
- 使用公式欄位時，請註冊公式外掛程式。
- 在正式環境中啟用附件欄位前，請先設定附件上傳處理常式。
- 將 Base 快照持久化為應用程式資料，並在升級 Univer 時一併遷移。

如需授權、伺服器及部署的詳細資訊，請參閱 [Univer SDK Pro](/guides/pro)。
