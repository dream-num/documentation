Facade API は、アプリケーションから Bases モデルを操作するためのレイヤーです。Base、テーブル、フィールド、レコード、ビュー、フィルター、並べ替え、グループ、選択範囲の作成や、UI の移動といった一般的な操作に使用できます。

<Callout type="warning" title="注意">
  Base モデルの変更は同期処理です。UI のアクティブ化メソッドは Promise を返すため `await` してください。
</Callout>

## Facade エントリを有効にする

アプリケーションで使用する各 Bases 機能の Facade エントリをインポートします。

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Univer インスタンスと必要なプラグインを登録してから、API オブジェクトを作成します。

```ts
const univerAPI = FUniver.newAPI(univer)
```
