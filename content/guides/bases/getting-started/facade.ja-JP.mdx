Facade API は、アプリケーションから Bases モデルを操作するためのレイヤーです。Base、テーブル、フィールド、レコード、ビュー、フィルター、並べ替え、グループ、選択範囲の作成や、UI の移動といった一般的な操作に使用できます。

<Callout type="warning" title="注意">
  一部の Facade API は非同期です。変更後すぐにデータを読み取る必要がある場合は、`await` または `.then()` を使用してください。
</Callout>

## Facade エントリを有効にする

アプリケーションで使用する各 Bases 機能の Facade エントリをインポートします。

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Univer インスタンスと必要なプラグインを登録してから、API オブジェクトを作成します。

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Base を作成・取得する

Facade レイヤーから Base ユニットを作成するには、`createBase` を使用します。より低レベルのセットアップコードでは、`univer.createUnit(UniverInstanceType.UNIVER_BASE, snapshot)` を使用してユニットを作成します。

```ts
const base = univerAPI.createBase({
  id: 'base-demo',
  name: 'Base Demo',
})

const activeBase = univerAPI.getActiveBase()
const sameBase = univerAPI.getBase(base.getId())
```

## テーブルを作成する

```ts
const table = base.createTable({
  name: 'Tasks',
  fields: [
    { name: 'Title', type: univerAPI.Enum.BaseFieldTypeEnum.Text },
    { name: 'Status', type: univerAPI.Enum.BaseFieldTypeEnum.SingleSelect },
  ],
})
```

## レコードを操作する

```ts
const record = table.addRecord({
  values: {
    Title: 'Write docs',
    Status: 'In progress',
  },
}, { key: univerAPI.Enum.BaseFieldKeyEnum.Name })

record.setValue('Status', 'Done')
```

## UI の状態を操作する

`@univerjs-pro/bases-ui/facade` は、テーブル／ビューのアクティブ化、選択、スクロール、編集、パネル操作のための UI API を追加します。

```ts
const baseUI = univerAPI.getBaseUI(base.getId())
baseUI.activateTable(table.getId())
baseUI.setSelection({ tableId: table.getId(), recordId: record.getId() })
```
