Facade APIは、アプリケーションがベースモデルと直接動作するのではなく、使用するレイヤーです。 これは、ベース、テーブル、フィールド、レコード、ビューを作成するなどの定期的な操作、フィルタ、ソート、グループ、選択、およびUIナビゲーション。

<Callout type="warning" title="キューション">
  ベースモデルの変更は同期です。UIの活発化方法は約束を返し、待ってください。
</Callout>

## Facade エントリを有効にする

アプリケーションが使用する各ベース機能のファサードエントリをインポートします。

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Univer インスタンスとその必要なプラグインを登録した後に API オブジェクトを作成します。

```ts
const univerAPI = FUniver.newAPI(univer)
```
