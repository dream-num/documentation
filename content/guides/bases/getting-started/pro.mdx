Bases is part of Univer SDK Pro. Start with the [installation guide](/guides/bases/getting-started/installation), then add the extensions you need.

## License

Follow [license configuration](/guides/server-integration/license#in-plugin-mode) and register `UniverLicensePlugin` before Bases and other Pro plugins.

## Choose feature packages

| Feature | Packages |
| --- | --- |
| Core and UI | `@univerjs-pro/bases`, `@univerjs-pro/bases-ui` |
| Import/export | `@univerjs-pro/exchange-client`, `@univerjs-pro/bases-exchange-client` |
| Dashboards and pivot views | `@univerjs-pro/bases-dashboard`, `@univerjs-pro/bases-dashboard-ui` |
| Comments | `@univerjs-pro/bases-thread-comment`, `@univerjs-pro/bases-thread-comment-ui` |
| History | `@univerjs-pro/bases-history`, `@univerjs-pro/bases-history-ui` |

See the [feature overview](/guides/bases#highlights) for registration and examples. Keep all Univer package versions compatible and merge locale resources for added UI plugins.

## Which features need a backend?

Local record editing, views, formulas, and dashboards work in the browser; your application decides how to save them. Exchange needs a conversion backend. Shared editing, comments, and history need their respective services; follow [server integration](/guides/server-integration).

Connect attachment uploads to application file storage; see [attachment fields](/guides/bases/features/core/fields#attachment-fields). Save complete [Base snapshots](/guides/bases/model/base-snapshot) to preserve plugin resources.
