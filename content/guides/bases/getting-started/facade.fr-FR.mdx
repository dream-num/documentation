Facade API est le calque que l'application utilise au lieu de travailler directement avec le modèle Bases. Il couvre les opérations courantes telles que la création de bases, tables, champs, enregistrements et vues, ainsi que les filtres, sortes, groupes, sélections et navigation UI.

<Callout type="warning" title="Attention">
  Les modifications au modèle de base sont synchrones. Les méthodes d'activation de l'interface utilisateur rendent des promesses et doivent être attendues.
</Callout>

## Activer les points d’entrée Facade

Importer l'entrée de façade pour chaque capacité Bases que l'application utilise:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Créez l'objet API après l'enregistrement de l'instance Univer et de ses plugins requis :

```ts
const univerAPI = FUniver.newAPI(univer)
```
