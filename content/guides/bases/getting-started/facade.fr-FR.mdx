L’API Facade fournit une couche destinée aux applications au-dessus du modèle Bases. Utilisez-la pour les opérations courantes, comme la création de bases, de tables, de champs, d’enregistrements, de vues, de filtres, de tris, de groupes et de sélections, ainsi que pour la navigation dans l’interface utilisateur.

<Callout type="warning" title="Attention">
  Certaines API Facade sont asynchrones. Si vous devez lire des données immédiatement après les avoir modifiées, utilisez `await` ou `.then()`.
</Callout>

## Activer les points d’entrée Facade

Importez le point d’entrée Facade de chaque fonctionnalité Bases utilisée par votre application :

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/bases/facade'
import '@univerjs-pro/bases-ui/facade'
```

Créez l’objet API après avoir enregistré l’instance Univer et les extensions requises :

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Créer et lire une base

Utilisez `createBase` pour créer une unité Base au moyen de la couche Facade. Dans le code de configuration de plus bas niveau, créez l’unité avec `univer.createUnit(UniverInstanceType.UNIVER_BASE, snapshot)`.

```ts
const base = univerAPI.createBase({
  id: 'base-demo',
  name: 'Base Demo',
})

const activeBase = univerAPI.getActiveBase()
const sameBase = univerAPI.getBase(base.getId())
```

## Créer une table

```ts
const table = base.createTable({
  name: 'Tasks',
  fields: [
    { name: 'Title', type: univerAPI.Enum.BaseFieldTypeEnum.Text },
    { name: 'Status', type: univerAPI.Enum.BaseFieldTypeEnum.SingleSelect },
  ],
})
```

## Manipuler les enregistrements

```ts
const record = table.addRecord({
  values: {
    Title: 'Write docs',
    Status: 'In progress',
  },
}, { key: univerAPI.Enum.BaseFieldKeyEnum.Name })

record.setValue('Status', 'Done')
```

## Manipuler l’état de l’interface utilisateur

`@univerjs-pro/bases-ui/facade` ajoute des API d’interface utilisateur pour l’activation des tables et des vues, la sélection, le défilement, la modification et les panneaux.

```ts
const baseUI = univerAPI.getBaseUI(base.getId())
baseUI.activateTable(table.getId())
baseUI.setSelection({ tableId: table.getId(), recordId: record.getId() })
```
