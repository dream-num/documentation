安裝 Univer Bases 前，請先了解貫穿其 API 與文件的四個基本概念。它們分別說明 Base 如何組裝、持久化、修改及操作。

## 基本概念 [#basic-concepts]

### 外掛

Univer 的功能以外掛形式提供。`@univerjs-pro/bases` 提供 Base 模型、命令及 `UniverBasesPlugin`；`@univerjs-pro/bases-ui` 提供獨立工作台及 `UniverBasesUIPlugin`。為了讓公式欄位接入 Bases 的計算流程，模型外掛也會使用 Pro 公式引擎。

只需註冊應用程式實際需要的產品外掛。[安裝與基本使用](/guides/bases/getting-started/installation)列出完整的瀏覽器設定及其技術相依套件。

### 快照與資料模型

`IBaseSnapshot` 是單一 Base 單元的持久化格式。它包含資料表及資料表順序；每張資料表包含欄位、記錄、檢視，以及各集合的順序。檢視只是同一批記錄的不同投影，切換檢視不會複製資料。

快照用於建立、儲存或還原 Base。單元執行後，請勿直接修改快照物件。資料結構請參閱 [Base 快照](/guides/bases/model/base-snapshot)及[資料表、欄位與記錄](/guides/bases/model/tables-fields-records)。

### 命令

執行階段的變更會透過命令完成。無論是建立資料表、更新欄位、編輯記錄或變更檢視，透過命令或 Facade 層操作都能讓模型、UI、復原/重做及協作流程保持一致。

應用程式程式碼應優先使用 Facade API；只有 Facade 尚未提供所需能力時，才直接呼叫命令 ID 完成底層整合。

### Facade API

Facade API 將 Bases 的命令及模型封裝成 Base、資料表、欄位、記錄與檢視物件。模型操作需要匯入 `@univerjs-pro/bases/facade`，UI 狀態操作需要匯入 `@univerjs-pro/bases-ui/facade`；註冊外掛後，再透過 `FUniver.newAPI(univer)` 建立 API。

接下來請完成[安裝與基本使用](/guides/bases/getting-started/installation)，再透過 [Bases Facade API 指南](/guides/bases/getting-started/facade)建立及編輯 Base 資料。
