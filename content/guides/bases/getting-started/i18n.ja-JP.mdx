## インターフェースの言語

`locale`は、メニュー、ツールチップ、ダイアログ、および翻訳されたUIの残りの言語パックを選択します。 `locales`は、選択せずにパックを登録します。 設定は、Univerインスタンスのユニットによって共有されます。 `LocaleType.EN_US`などの`LocaleType`値を取ります。

- **すべての製品: UI**: `locale`はメニュー、ツールチップ、ダイアログ、プラグインラベルの言語を変更します。 ユーザーのコンテンツを翻訳したり、既存のユニットの名前を変更したりすることはありません。
- **シート: 細胞のフォーマットおよび方式**: 細胞内の数値と日付は、フォールバックチェーンに従います: 番号形式の locale オーバーライド, その後、ワークブックスナップショット `locale`, その後、インスタンス `locale`. `region` は、それらのいずれかを交換しません. 式挙動などの `DOLLAR` そして、金融結果の通貨形式はまだ `locale`に続いています, CJK 入力正規化を行います.
- **Docs: 統計**: `locale`は、テキストの分割とカウント方法を決定します。

### 実行時の言語の切り替え

言語を切り替える前に、すべてのインストールされたプラグインまたはプリセットに言語パックをロードします。 `loadLocales()`は、変換せずに翻訳をマージします。 `setLocale()` は、既にロードされているものから選択し、何もダウンロードしません。 欠落した翻訳キーは、キー自体として表示されます。 以下の例は、共有されたUIパックをロードし、他のインストールされたプラグインを同じ呼び出しにターゲット言語パックを追加します。

```typescript
import { LocaleType, mergeLocales } from '@univerjs/core'
import UIEnUS from '@univerjs/ui/locale/en-US'

univerAPI.loadLocales(LocaleType.EN_US, mergeLocales(UIEnUS))
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentLocale()) // enUS
```

### 言語パックのマージ [#mergeLocales]

`mergeLocales`は複数のプラグインやプリセットの言語パックを1つの完全な言語パックオブジェクトに結合します。

<Tabs items={['プラグインモード', 'プリセットモード']}>
  <Tab>
    ````typescript
    import { mergeLocales } from '@univerjs/core'

    // 複数の言語パックオブジェクトを引数で渡してマージできます
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // 配列としてまとめて渡すことも可能です
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    ])
    ````
  </Tab>
  <Tab>

    import { mergeLocales } from '@univerjs/presets'

### カスタム言語パック

また、カスタム言語パックを書くこともできます。必要なオブジェクトを組み立てて、`Univer`インスタンスに渡します。言語はプリセットによって出荷されます。通常は`<rootDir>/packages/<PLUGIN_NAME>/locale`に住んでいます。

````typescript
import { LocaleType, Univer } from '@univerjs/core'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: {
      ui: {
        shortcut: {
          undo: '元に戻す',
          redo: 'やり直す',
        },
      },
    },
  },
})
````

### 翻訳への貢献

Univerは、以下の組み込み言語パックを提供します。

- `zh-CN`: 中国語（簡体字）
- `en-US`: 英語
- `zh-TW`: 中国語（繁体字）
- `zh-HK`: 中国語（繁体字・香港）
- `ru-RU`: ロシア語
- `vi-VN`: ベトナム語
- `fa-IR`: ペルシャ語
- `fr-FR`: フランス語
- `ja-JP`: 日本語
- `ko-KR`: 韓国語
- `es-ES`: スペイン語
- `ca-ES`: カタルーニャ語
- `sk-SK`: スロバキア語
- `ar-SA`: アラビア語
- `de-DE`: ドイツ語
- `id-ID`: インドネシア語
- `it-IT`: イタリア語
- `pl-PL`: ポーランド語
- `pt-BR`: ポルトガル語（ブラジル）

これらはすべて組み込みの言語パックです。 Univerはオープンソースプロジェクトであり、世界中の開発者はこれらのローカルを追加または改善するために歓迎されています。

## 地域設定

`region`は、地域機能が続く地域の慣行を選択します。 この設定は、Univerインスタンスのユニットによって共有されます。

どちらの設定も`LocaleType`値を取ります。例えば`LocaleType.EN_US`は`enUS`で、`en-US`は言語パックファイル名とBCP 47タグです。`US`や`SG`などの国コードを`region`に渡さないでください。UIが異なるロケールを使用している場合は、その言語パックをロードする必要はありません。

`region`が設定されていない場合は、`locale`を後に`setLocale()`呼び出します。 `region`の初期化、または`setRegion()`を呼び出すと、その自動フォローが停止します。 その後、言語を変更すると、選択した領域が維持されます。 パブリックAPIは、自動フォローを復元しません。 2つが一緒に変更する必要がある場合は、明示的に設定します。

追加する `region: LocaleType.DE_DE` 次へ `locale` いずれかの `createUniver()` または `new Univer()` ドイツの地方慣習が適用している間UIの言語を保つため。

```typescript
import { LocaleType } from '@univerjs/core'

univerAPI.setRegion(LocaleType.DE_DE)
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentRegion()) // deDE
```

ここでは、ローカルのフォーマットがドイツ語のままであるときに英語にUIスイッチを切り替えます。 `getCurrentLocale()`と`getCurrentRegion()`は、実際に効果で識別子を返します。 一緒に変更するには、同じ`LocaleType`値で両方のセッターを呼び出します。

- **シート:通貨コントロール**: `region`は、ツールバー、通貨、会計選択とプレビューの形式、通貨コマンドが適用されるフォーマットで通貨アイコンを決定します。 変更は、既存のセルフォーマットを書き換えたり、通貨値を変更したりしません。
- **Docs: 統計**: `region`は、統計ダイアログとセパレータをグループ化を含むステータスバーに表示されているカウントをフォーマットします。 `region`を変更してもカウントルールは変更されません。
- **スレッドコメント, 有効にしたときに**:`region`は、24時間時計とラテンの数字を使用して、日付と時刻がどのように表示されるかを制御します。 `locale`では、コメントUIテキストを制御します。 保存されたタイムスタンプを変更し、`region`がタイムゾーンの設定ではありません。
- **ボード、スライド、ベース、PDF**: `locale`は、翻訳されたUIを制御します。 `region` は、統合後のスレッドコメントなど、それを読み取る機能を共有することができます。 ボードやスライドテキスト、ベースフィールド、またはPDFコンテンツを自動的に再フォーマットしません。

## 右から左へのレイアウト

<Callout type="warning" title="キューション">
  RTL は UI レイヤーのみをサポートしています。レンダリングレイヤーは RTL をサポートしていません。
</Callout>

<Callout type="warning" title="キューション">
  すべてのプラグインが言語パックを出荷するわけではありません。各機能のドキュメントには、いずれかが含まれているかが記載されています。
</Callout>

```typescript
univerAPI.setDirection('rtl')
```
