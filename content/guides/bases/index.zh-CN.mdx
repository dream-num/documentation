## Univer Bases 是什么

Univer Bases 是 Univer SDK Pro 中的结构化数据产品。它专为以记录集合（而非工作表网格）为核心对象的应用而设计，非常适合用于轻量级数据库、内容工作流、审批跟踪器、CRM 风格的表格和内部工具。

Bases 是一种独立的 Univer SDK 单元类型。核心包负责表、字段、记录、视图、公式计算、搜索、命令和协同变更；UI 包负责渲染独立工作台和内置视图。


## 浏览器兼容性

Univer SDK 的编译目标是 Chrome 88，但这并不意味着 Univer SDK 能够完全支持所有主流环境。我们会尽力确保 Univer SDK 在以下浏览器和 Node.js 环境中能够正常运行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK 依赖 `Intl.Segmenter`，如果你的浏览器或运行时环境暂不支持它，请先补充对应的 polyfill。我们推荐使用
  `@formatjs/intl-segmenter`。
</Callout>

如果遇到无法兼容的情况，请先借助对应的 polyfill 来解决，如果仍然无法解决，请[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 兼容性

<Callout type="warning">
  以下仅适用于在 Node.js 环境中运行 Univer SDK 的情况，并不适用于那些基于 Node.js 使用构建工具在浏览器中运行 Univer SDK 的情况。
</Callout>

Univer SDK 可以在 Node.js 环境中运行，支持的版本为 v18.17.0 及之后的版本。

## 主要功能

| 功能 | 用途 |
| --- | --- |
| [字段与附件](/guides/bases/features/core/fields) | 文本、数字、选择、成员、日期、附件等字段。 |
| [记录、关联与层级](/guides/bases/features/core/records) | 批量写入、分页查询、跨表关联和父子记录。 |
| [视图](/guides/bases/features/core/views) | 网格、看板、日历、甘特图、画廊，以及筛选、排序、分组和条件着色。 |
| [公式](/guides/bases/features/core/formulas) | 根据字段计算结果，支持显式配置的跨文档引用。 |
| [权限](/guides/bases/features/core/permissions) | Base、表、字段、记录和视图的编辑权限。 |
| [导入导出](/guides/bases/features/import-export) | 导入 Excel、CSV、TSV，导出表数据；需要转换后端。 |
| [仪表盘与透视视图](/guides/bases/features/dashboard) | 汇总表数据，并组合图表、筛选控件、文字和图片。 |
| [记录评论](/guides/bases/features/thread-comment) | 围绕记录讨论；多人共享需要评论服务。 |
| [协同编辑](/guides/bases/features/collaboration) | 多人编辑同一份 Base；需要协同服务。 |
| [历史记录](/guides/bases/features/edit-history) | 查看服务端保存的版本和变化。 |
