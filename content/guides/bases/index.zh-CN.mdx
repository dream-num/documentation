## Univer Bases 是什么

Univer Bases 是 Univer Office SDK 中的结构化数据产品。如果应用围绕一组记录而不是工作表网格来组织，Univer Bases 适用于轻量级数据库、内容工作流、审批跟踪器、CRM 风格的表格和内部工具。

Bases 属于 [Web SDK](/guides/sheets)，嵌入式编辑器和无界面内容处理都由 Web SDK 提供。协同和文件交换模块由 [Server SDK](/server) 提供，[AI SDK](/ai) 则让 Agent 能够访问记录。

Bases 是 Web SDK 中一种独立的单元类型。核心包负责表、字段、记录、视图、公式计算、搜索、命令和协同变更，UI 包负责渲染独立工作台和内置视图。

## 浏览器兼容性

Web SDK 的编译目标是 Chrome 88，但这并不意味着所有主流环境都能获得完整支持。我们力求支持以下浏览器版本：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK 依赖 `Intl.Segmenter`。浏览器或运行时环境不支持它时，需要先添加对应的 polyfill，推荐 `@formatjs/intl-segmenter`。
</Callout>

如果遇到兼容问题，请先尝试对应的 polyfill；如果仍无法解决，请[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 兼容性

<Callout type="warning">
  本节只涉及在 Node.js 环境中运行 Web SDK，不适用于使用基于 Node.js 的构建工具在浏览器中运行 Web SDK 的情况。
</Callout>

Web SDK 可在 Node.js v18.17.0 及更高版本中运行。

## 主要功能

| 功能 | 用途 |
| --- | --- |
| [字段与附件](/guides/bases/features/core/fields) | 文本、数字、选择、成员、日期、附件等字段。 |
| [记录、关联与层级](/guides/bases/features/core/records) | 批量编辑、本地分页、跨表关联和父子记录。 |
| [视图](/guides/bases/features/core/views) | 网格、看板、日历、甘特图、画廊，以及筛选、排序、分组和条件着色。 |
| [公式](/guides/bases/features/core/formulas) | 字段计算，以及显式配置的跨文档引用。 |
| [权限](/guides/bases/features/core/permissions) | Base、表、字段、记录和视图的编辑权限。 |
| [导入导出](/guides/bases/features/import-export) | 导入 Excel、CSV、TSV，导出表数据；需要转换后端。 |
| [仪表盘与透视视图](/guides/bases/features/dashboard) | 汇总表数据，并组合图表、筛选控件、文字和图片。 |
| [评论](/guides/bases/features/thread-comment) | 围绕记录展开讨论；共享讨论需要评论服务。 |
| [协同编辑](/guides/bases/features/collaboration) | 多人编辑同一份 Base；需要协同服务。 |
| [历史记录](/guides/bases/features/edit-history) | 查看服务端保存的版本和差异。 |
