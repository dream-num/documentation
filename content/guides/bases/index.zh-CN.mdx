## Univer Bases 是什么

Univer Bases 是 Univer Pro 中的结构化数据产品。它专为以记录集合（而非工作表网格）为核心对象的应用而设计，非常适合用于轻量级数据库、内容工作流、审批跟踪器、CRM 风格的表格和内部工具。

Bases 是一种独立的 Univer 单元类型。核心包负责表、字段、记录、视图、公式计算、搜索、命令和协同变更；UI 包负责渲染独立工作台和内置视图。


## 浏览器兼容性

Univer 的编译目标是 Chrome 88，但这并不意味着 Univer 能够完全支持所有主流环境。我们会尽力确保 Univer 在以下浏览器和 Node.js 环境中能够正常运行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer 依赖 `Intl.Segmenter`，如果你的浏览器或运行时环境暂不支持它，请先补充对应的 polyfill。我们推荐使用
  `@formatjs/intl-segmenter`。
</Callout>

如果遇到无法兼容的情况，请先借助对应的 polyfill 来解决，如果仍然无法解决，请[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 兼容性

<Callout type="warning">
  以下仅适用于在 Node.js 环境中运行 Univer 的情况，并不适用于那些基于 Node.js 使用构建工具在浏览器中运行 Univer 的情况。
</Callout>

Univer 可以在 Node.js 环境中运行，支持的版本为 v18.17.0 及之后的版本。

## 主要功能

- **表、字段和记录**：在每张表中存储带类型的字段和有序记录。
- **多种视图**：通过网格、看板、日历、甘特图和画廊视图呈现同一组记录。
- **命令驱动的编辑**：让模型变更统一经过命令层，并提供权限及可选历史记录和协同集成所需的挂钩。
- **公式字段**：将 Base 字段接入 Univer 公式计算链路。
- **浏览器工作台**：渲染视图，并提供选择、编辑、剪贴板、滚动和面板功能。
- **持久化**：无需直接修改运行中的快照，即可创建、恢复和保存 `IBaseSnapshot`。
