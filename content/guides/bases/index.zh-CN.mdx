## Univer Bases 是什么

Univer Bases 是 Univer Pro 中的结构化数据产品。它适合用来做轻量数据库、内容流程、审批台账、CRM 表、内部运营工具等应用。这里的核心对象不是工作表单元格，而是一组可以按字段、记录和视图组织的数据。

Bases 在运行时是独立的 Univer unit。核心包负责表、字段、记录、视图、公式计算、搜索、命令和协同 mutation；UI 包负责独立工作台和内置视图的渲染。

## 什么时候使用 Bases

如果用户需要字段类型、筛选、排序、分组，以及基于同一份数据切换不同视图，可以从 Bases 开始。如果用户主要编辑电子表格单元格，请看 [Univer Sheets](/guides/sheets)。如果用户需要自由画布，请看 [Univer Boards](/guides/boards)。

## 安装包

```bash
pnpm add @univerjs-pro/bases @univerjs-pro/bases-ui
```

## 包结构

- `@univerjs-pro/bases`：Base 数据模型、表/字段/记录/视图命令、JSON1 协同 mutation、公式集成、字段插件、搜索、Facade API 与 `UniverBasesPlugin`
- `@univerjs-pro/bases-ui`：独立工作台、Grid/Calendar/Kanban/Gallery/Gantt 视图、字段编辑器、记录详情面板、工具栏和右键菜单操作、渲染模块与 `UniverBasesUIPlugin`

## 注册插件

下面只展示 Bases 相关的注册代码。完整应用还需要 Univer core、渲染引擎、UI、License、公式引擎等通用插件。

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/bases/facade'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```
