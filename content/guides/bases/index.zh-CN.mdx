## Univer Bases 是什么

Univer Bases 是 Univer Pro 中的结构化数据产品。它专为以记录集合（而非工作表网格）为核心对象的应用而设计，非常适合用于轻量级数据库、内容工作流、审批跟踪器、CRM 风格的表格和内部工具。

Bases 是一种独立的 Univer 单元类型。核心包负责表、字段、记录、视图、公式计算、搜索、命令和协同变更；UI 包负责渲染独立工作台和内置视图。

## 什么时候使用 Bases

当用户需要具有不同字段类型的结构化记录，并希望对同一份数据进行筛选、排序、分组和多种形式的展示时，请使用 Bases。如果用户主要编辑电子表格中的单元格，请使用 [Univer Sheets](/guides/sheets)。如果用户需要自由画布，请使用 [Univer Boards](/guides/boards)。

## 安装包

```bash
pnpm add @univerjs-pro/bases @univerjs-pro/bases-ui
```

## 包一览

- `@univerjs-pro/bases`：Base 数据模型、表/字段/记录/视图命令、JSON1 协同变更、公式集成、字段插件、搜索、Facade API，以及 `UniverBasesPlugin`
- `@univerjs-pro/bases-ui`：独立工作台、网格/日历/看板/画廊/甘特图视图、字段编辑器、记录详情面板、工具栏和上下文菜单操作、渲染模块，以及 `UniverBasesUIPlugin`

## 注册插件

以下代码片段仅展示 Bases 相关的设置。完整的应用还需要 Univer 核心、渲染引擎、UI、许可证和公式引擎等共享插件。

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/bases/facade'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```
