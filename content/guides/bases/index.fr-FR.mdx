## Qu’est-ce qu’Univer Bases ?

Univer Bases est le produit de données structuré dans Univer Office SDK. Il est destiné aux applications organisées autour d'un ensemble d'enregistrements plutôt qu'une grille de feuille de travail: bases de données légères, flux de travail de contenu, suivi d'approbation, tables de style CRM et outils internes.

Bases fait partie de [Web SDK](/guides/sheets), qui gère les éditeurs intégrés et le traitement de contenu sans tête. [Server SDK](/server) fournit les modules pour la collaboration et l'échange de fichiers, et [AI SDK](/ai) donne un accès agent aux enregistrements.

Bases est un type d'unité distinct dans Web SDK. Le paquet de base possède des tables, des champs, des enregistrements, des vues, le calcul de la formule, la recherche, les commandes et les mutations de collaboration.

## Compatibilité avec les navigateurs

Web SDK compile avec une cible Chrome 88, mais cela ne signifie pas que chaque environnement courant est entièrement pris en charge. Les versions suivantes du navigateur sont celles que nous visons à soutenir:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK utilise `Intl.Segmenter`. Si votre navigateur ou environnement d'exécution ne le supporte pas, ajoutez d'abord le polyfill correspondant. Nous recommandons `@formatjs/intl-segmenter` .
</Callout>

Si un problème de compatibilité survient, essayez d'abord le polyfill correspondant. Si le problème persiste, [soumettre un problème](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilité avec Node.js

<Callout type="warning">
  Cette section couvre uniquement l'exécution de Web SDK dans un environnement Node.js. Elle ne s'applique pas lorsque vous utilisez des outils de construction basés sur Node.js pour exécuter Web SDK sur un navigateur.
</Callout>

Web SDK fonctionne sur Node.js v18.17.0 et plus tard.

## Comment lire la documentation

La navigation de documentation apparaît à gauche. Les pages sont commandées de base à avancée, de sorte que vous pouvez les lire dans l'ordre lors de la construction d'une application, ou aller directement aux pages qui correspondent à votre cas d'utilisation. Vous pouvez également passer à la documentation Univer Bases en haut de la barre latérale.

La table des matières de droite navigue entre les sections de la page actuelle. Pour trouver une page rapidement, utilisez la barre de recherche en haut ou le raccourci Ctrl+K / Cmd+K.

Commencez avec le guide [Démarrage rapide](/guides/bases/getting-started/installation).

## Connaissances préalables

La documentation vise à être accessible, mais elle suppose une certaine connaissance de base afin que les pages puissent rester concentrées sur Web SDK.

Les pages sont les plus utiles avec une compréhension de base de JavaScript et de son écosystème. Si vous prévoyez d'exécuter Web SDK sur Node.js, une compréhension de basique de Node.js aide également.
