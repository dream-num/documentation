## Qu’est-ce qu’Univer Bases ?

Univer Bases est le produit de données structurées d’Web SDK. Il est conçu pour les applications dont l’objet principal est un ensemble d’enregistrements plutôt qu’une grille de feuille de calcul : bases de données légères, workflows de contenu, outils de suivi des approbations, tables de type CRM et outils internes sont autant de cas d’usage adaptés.

Bases est un type d’unité Web SDK indépendant. Le package principal gère les tables, les champs, les enregistrements, les vues, le calcul des formules, la recherche, les commandes et les mutations collaboratives. Le package d’interface utilisateur affiche l’espace de travail autonome et les vues intégrées.


## Compatibilité avec les navigateurs

Web SDK est compilé avec Chrome 88 comme cible, mais cela ne signifie pas qu’il prend entièrement en charge tous les environnements courants. Nous nous efforçons d’assurer son bon fonctionnement dans les navigateurs et environnements Node.js suivants :

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK s’appuie sur `Intl.Segmenter`. Si votre navigateur ou votre environnement d’exécution ne le prend pas en
  charge, ajoutez d’abord un polyfill adapté. Nous vous recommandons d’utiliser `@formatjs/intl-segmenter`.
</Callout>

Si vous rencontrez des problèmes de compatibilité, essayez d’abord de les résoudre à l’aide des polyfills appropriés. Si le problème persiste, n’hésitez pas à [ouvrir une issue](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilité avec Node.js

<Callout type="warning">
  Remarque : ces informations concernent uniquement l’exécution d’Web SDK dans un environnement Node.js. Elles ne
  s’appliquent pas lorsqu’Web SDK s’exécute dans un navigateur avec des outils de build basés sur Node.js.
</Callout>

Web SDK peut s’exécuter dans un environnement Node.js à partir de la version v18.17.0.

## Points forts

- **Tables, champs et enregistrements** : stockez des champs typés et des enregistrements ordonnés dans chaque table.
- **Vues multiples** : projetez les mêmes enregistrements dans des vues grille, Kanban, calendrier, Gantt et galerie.
- **Modification pilotée par des commandes** : faites passer les changements du modèle par une couche de commandes avec des autorisations et des points d’intégration pour l’historique et la collaboration facultatifs.
- **Champs de formule** : reliez les champs Base au pipeline de calcul de formules d’Web SDK.
- **Espace de travail du navigateur** : affichez les vues et bénéficiez de la sélection, de la modification, du presse-papiers, du défilement et des panneaux.
- **Persistance** : créez, restaurez et enregistrez un `IBaseSnapshot` sans modifier directement l’instantané en cours d’exécution.

## Comment lire la documentation

La barre de navigation de la documentation se trouve à gauche de l’écran. Les pages sont classées du niveau débutant au niveau avancé afin que vous puissiez les suivre pas à pas pendant la création de votre application. Vous pouvez cependant les consulter dans l’ordre de votre choix ou accéder directement aux pages correspondant à votre cas d’utilisation. Vous pouvez également sélectionner Univer Bases en haut de la barre latérale.

À droite de l’écran, une table des matières facilite la navigation entre les différentes sections de la page. Pour trouver rapidement une page, utilisez la barre de recherche située en haut ou le raccourci de recherche (Ctrl+K ou Cmd+K).

Pour commencer, consultez le guide de [Démarrage rapide](/guides/bases/getting-started/installation).

## Connaissances préalables

Bien que notre documentation soit conçue pour les débutants, il nous faut établir quelques prérequis afin qu’elle puisse rester centrée sur Web SDK.

Pour en tirer pleinement parti, il est recommandé de posséder des notions de base en JavaScript et de connaître son écosystème.

Si vous souhaitez exécuter Web SDK sur Node.js, des notions de base sur Node.js sont également nécessaires.
