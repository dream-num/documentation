## Qu’est-ce qu’Univer Bases ?

Univer Bases est le produit de données structurées d’Univer Pro. Il est conçu pour les applications dont l’objet principal est un ensemble d’enregistrements plutôt qu’une grille de feuille de calcul : bases de données légères, workflows de contenu, outils de suivi des approbations, tables de type CRM et outils internes sont autant de cas d’usage adaptés.

Bases est un type d’unité Univer indépendant. Le package principal gère les tables, les champs, les enregistrements, les vues, le calcul des formules, la recherche, les commandes et les mutations collaboratives. Le package d’interface utilisateur affiche l’espace de travail autonome et les vues intégrées.

## Quand utiliser Bases

Utilisez Bases lorsque les utilisateurs ont besoin d’enregistrements structurés avec des types de champs, des vues filtrées, des fonctions de tri et de regroupement, ainsi que différentes représentations des mêmes données. Si les utilisateurs modifient principalement des cellules dans une feuille de calcul, utilisez [Univer Sheets](/guides/sheets). S’ils ont besoin d’un canevas libre, utilisez [Univer Boards](/guides/boards).

## Installer les packages

```bash
pnpm add @univerjs-pro/bases @univerjs-pro/bases-ui
```

## Présentation des packages

- `@univerjs-pro/bases` : modèle de données de base, commandes de table/champ/enregistrement/vue, mutations collaboratives JSON1, intégration des formules, plugins de champs, recherche, API de façade et `UniverBasesPlugin`
- `@univerjs-pro/bases-ui` : espace de travail autonome, vues grille/calendrier/kanban/galerie/Gantt, éditeurs de champs, panneau de détails des enregistrements, opérations de la barre d’outils et du menu contextuel, modules de rendu et `UniverBasesUIPlugin`

## Enregistrer les plugins

L’extrait ci-dessous présente la partie de la configuration propre à Bases. Une application complète nécessite également les plugins partagés du noyau Univer, du moteur de rendu, de l’interface utilisateur, de la licence et du moteur de formules.

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/bases/facade'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```
