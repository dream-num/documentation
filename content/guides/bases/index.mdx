## What is Univer Bases

Univer Bases is the structured data product in Univer Office SDK. It is intended for applications organized around a set of records rather than a worksheet grid: lightweight databases, content workflows, approval trackers, CRM-style tables and internal tools.

Bases is part of [Web SDK](/guides/sheets), which handles embedded editors and headless content processing. [Server SDK](/server) provides the modules for collaboration and file exchange, and [AI SDK](/ai) gives an agent access to records.

Bases is a separate unit type in Web SDK. The core package owns tables, fields, records, views, formula calculation, search, commands and collaboration mutations. The UI package renders the standalone workbench and the built-in views.

## Browser Compatibility

Web SDK compiles with a Chrome 88 target, but that does not mean every mainstream environment is fully supported. The following browser versions are the ones we aim to support:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK relies on `Intl.Segmenter`. If your browser or runtime environment does not support it, add the matching polyfill first. We recommend `@formatjs/intl-segmenter`.
</Callout>

If a compatibility problem occurs, try the matching polyfill first. If the problem persists, [submit an issue](https://github.com/dream-num/univer/issues/new/choose).

## Node.js Compatibility

<Callout type="warning">
  This section only covers running Web SDK in a Node.js environment. It does not apply when you use Node.js-based build tools to run Web SDK in a browser.
</Callout>

Web SDK runs on Node.js v18.17.0 and later.

## Highlights

| Feature | Purpose |
| --- | --- |
| [Fields and attachments](/guides/bases/features/core/fields) | Text, numbers, choices, members, dates, and attachments. |
| [Records, links, and hierarchy](/guides/bases/features/core/records) | Batch edits, local pagination, table links, and parent-child records. |
| [Views](/guides/bases/features/core/views) | Grid, Kanban, Calendar, Gantt, Gallery, filtering, sorting, grouping, and conditional colors. |
| [Formulas](/guides/bases/features/core/formulas) | Field calculations and explicitly configured cross-document references. |
| [Permissions](/guides/bases/features/core/permissions) | Editing permissions for Bases, tables, fields, records, and views. |
| [Import and export](/guides/bases/features/import-export) | Import Excel, CSV, and TSV, and export table data; requires a conversion backend. |
| [Dashboards and pivot views](/guides/bases/features/dashboard) | Summarize table data and combine charts, filters, text, and images. |
| [Comments](/guides/bases/features/thread-comment) | Discuss records; shared discussions require a comment service. |
| [Collaboration](/guides/bases/features/collaboration) | Edit the same Base together; requires a collaboration service. |
| [Edit history](/guides/bases/features/edit-history) | Read server-stored versions and differences. |

## How to Read the Documentation

The documentation navigation appears on the left. Pages are ordered from basic to advanced, so you can read them in order while building an application, or go directly to the pages that match your use case. You can also switch to the Univer Bases documentation at the top of the sidebar.

The table of contents on the right navigates between sections of the current page. To find a page quickly, use the search bar at the top or the Ctrl+K / Cmd+K shortcut.

Start with the [Quick Start](/guides/bases/getting-started/installation) guide.

## Pre-Requisite Knowledge

The documentation aims to be approachable, but it assumes some baseline knowledge so that the pages can stay focused on Web SDK.

The pages are most useful with a basic understanding of JavaScript and its ecosystem. If you plan to run Web SDK on Node.js, a basic understanding of Node.js also helps.
