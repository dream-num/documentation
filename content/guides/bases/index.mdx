## What is Univer Bases

Univer Bases is the structured data product in Univer Pro. It is designed for applications where the primary object is a set of records instead of a worksheet grid: lightweight databases, content workflows, approval trackers, CRM-style tables, and internal tools are good fits.

Bases is an independent Univer unit type. The core package owns tables, fields, records, views, formula calculation, search, commands, and collaboration mutations. The UI package renders the standalone workbench and the built-in views.


## Browser Compatibility

Univer is compiled with a target of Chrome 88, but this does not mean it fully supports all mainstream environments. We strive to ensure Univer works well in the following browsers and Node.js environments:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer relies on `Intl.Segmenter`. If your browser or runtime environment does not support it, please add a
  corresponding polyfill first. We recommend using `@formatjs/intl-segmenter`.
</Callout>

If you encounter compatibility issues, please first try to resolve them using the appropriate polyfills. If the issue persists, feel free to [submit an issue](https://github.com/dream-num/univer/issues/new/choose).

## Node.js Compatibility

<Callout type="warning">
  Note: This only applies to running Univer in a Node.js environment and does not apply to cases where Univer is run in
  a browser using build tools based on Node.js.
</Callout>

Univer can run in a Node.js environment, supporting versions v18.17.0 and later.


## When to use Bases

Use Bases when users need structured records with field types, filtered views, sorting, grouping, and different projections over the same data. If users mainly edit cells in a spreadsheet, use [Univer Sheets](/guides/sheets). If they need a free-form canvas, use [Univer Boards](/guides/boards).

## Install packages

```bash
pnpm add @univerjs-pro/bases @univerjs-pro/bases-ui
```

## Package map

- `@univerjs-pro/bases`: base data model, table/field/record/view commands, JSON1 collaboration mutations, formula integration, field plugins, search, facade APIs, and `UniverBasesPlugin`
- `@univerjs-pro/bases-ui`: standalone workbench, grid/calendar/kanban/gallery/gantt views, field editors, record detail panel, toolbar and context menu operations, render modules, and `UniverBasesUIPlugin`

## Register plugins

The snippet below shows the Bases-specific part of the setup. A complete application also needs the shared Univer core, render engine, UI, license, and formula engine plugins.

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/bases/facade'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```
