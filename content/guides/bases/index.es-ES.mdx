## Qué es Univer Bases

Univer Bases es el producto de datos estructurado en Univer Office SDK. Está destinado a aplicaciones organizadas alrededor de un conjunto de registros en lugar de una rejilla de hoja de trabajo: bases de datos ligeras, flujos de trabajo de contenido, rastreadores de aprobación, tablas de estilo CRM y herramientas internas.

Bases es parte de [Web SDK](/guides/sheets), que maneja editores integrados y procesamiento de contenidos sin cabeza. [Server SDK](/server) proporciona los módulos para la colaboración y el intercambio de archivos, y [AI SDK](/ai) da acceso a un agente a los registros.

Bases es un tipo de unidad separado en Web SDK. El paquete central posee tablas, campos, registros, vistas, cálculo de fórmulas, búsqueda, comandos y mutaciones de colaboración. El paquete UI ofrece el banco de trabajo independiente y las vistas incorporadas.

## Compatibilidad del navegador

Web SDK compila con un objetivo Chrome 88, pero eso no significa que cada entorno principal sea totalmente compatible. Las siguientes versiones del navegador son las que pretendemos apoyar:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK se basa en `Intl.Segmenter`. Si su navegador o entorno de tiempo de ejecución no lo soporta, agregue el polífilo de combinación primero. Recomendamos `@formatjs/intl-segmenter` .
</Callout>

Si se produce un problema de compatibilidad, prueba primero el polífilo que coincide. Si el problema persiste, [presentar una cuestión](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilidad con Node.js

<Callout type="warning">
  Esta sección solo cubre la ejecución de Web SDK en un entorno Node.js. No se aplica cuando utiliza herramientas de construcción basadas en Node.js para ejecutar Web SDK de un navegador.
</Callout>

Web SDK funciona en Node.js v18.17.0 y más tarde.

## Cómo leer la documentación

La navegación de la documentación aparece a la izquierda. Las páginas se ordenan de base a avanzada, por lo que puede leerlas en orden mientras construye una aplicación, o ir directamente a las páginas que coincidan con su caso de uso. También puede cambiar a la documentación Univer Bases en la parte superior de la barra lateral.

La tabla de contenidos en las barras derechas entre secciones de la página actual. Para encontrar una página rápidamente, utilice la barra de búsqueda en la parte superior o el acceso directo Ctrl+K / Cmd+K.

Empieza con la guía [Inicio rápido](/guides/bases/getting-started/installation).

## Conocimientos previos requeridos

La documentación pretende ser accesible, pero supone algún conocimiento de referencia para que las páginas puedan mantenerse centradas en Web SDK.

Las páginas son más útiles con una comprensión básica de JavaScript y su ecosistema. Si usted planea ejecutar Web SDK en Node.js, una comprensión básica del Node.js también ayuda.
