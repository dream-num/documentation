## Qué es Univer Bases

Univer Bases es el producto de datos estructurados de Univer Pro. Está diseñado para aplicaciones donde el objeto principal es un conjunto de registros en lugar de una cuadrícula de hoja de cálculo: bases de datos livianas, flujos de trabajo de contenido, rastreadores de aprobación, tablas estilo CRM y herramientas internas son buenas opciones.

Bases es un tipo de unidad independiente de Univer. El paquete principal posee tablas, campos, registros, vistas, cálculo de fórmulas, búsqueda, comandos y mutaciones de colaboración. El paquete UI representa el banco de trabajo independiente y las vistas integradas.

## Cuándo usar Bases

Utilice Bases cuando los usuarios necesiten registros estructurados con tipos de campos, vistas filtradas, clasificación, agrupación y diferentes proyecciones sobre los mismos datos. Si los usuarios editan principalmente celdas en una hoja de cálculo, utilice [Hojas Univer](/guides/sheets). Si necesitan un lienzo de forma libre, utilice [Tableros Univer](/guides/boards).

## Instalar paquetes

```bash
pnpm add @univerjs-pro/bases @univerjs-pro/bases-ui
```

## Mapa de paquete

- `@univerjs-pro/bases`: modelo de datos base, comandos de tabla/campo/registro/vista, mutaciones de colaboración JSON1, integración de fórmulas, complementos de campo, búsqueda, API de fachada y `UniverBasesPlugin`
- `@univerjs-pro/bases-ui`: banco de trabajo independiente, vistas de cuadrícula/calendario/kanban/galería/gantt, editores de campo, panel de detalles de registro, barra de herramientas y menú contextual, módulos de renderizado y `UniverBasesUIPlugin`

## Registrar complementos

El siguiente fragmento muestra la parte específica de Bases del configuración. Una aplicación completa también necesita el núcleo compartido de Univer, el motor de renderizado, la interfaz de usuario, la licencia y los complementos del motor de fórmulas.

```ts
import { UniverBasesPlugin } from '@univerjs-pro/bases'
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/bases/facade'

univer.registerPlugin(UniverBasesPlugin)
univer.registerPlugin(UniverBasesUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BASE, {})
```

## Leer a continuación

- Utilice [Univer Pro](/guides/pro) para la licencia y la configuración del lado del servidor.
- Utilice la [Referencia de API Pro](/guides/pro/api) cuando necesite las API del servidor y el contexto de implementación.
- Utilice [Univer Sheets](/guides/sheets) si la función que está creando se parece más a una hoja de cálculo que a una base de datos de registros.
