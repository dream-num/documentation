---
title: 许可证
description: 获取 Univer SDK Pro 许可证，并在前端应用中完成配置。
---

使用需要授权的 Pro 功能时，请通过 [Univer 官方网站](https://univer.ai)了解授权范围并获取许可证。拿到**客户端许可证内容**后，按项目使用的预设模式或插件模式配置即可，两种方式选择一种。

<Callout type="warning" title="0.25.x 用户请阅读旧版文档">
  如果项目使用 **0.25.x**，旧服务端的许可证配置见 [0.25.x 旧版 Pro 文档](https://dream-num.github.io/documentation/v0.25/zh-CN/guides/pro/)。
</Callout>

## 预设模式 [#in-preset-mode]

在已有的 Pro 预设配置中添加 `license`。例如，使用 `UniverSheetsAdvancedPreset` 时：

```ts
UniverSheetsAdvancedPreset({
  // 保留其他已有配置，将占位符替换为客户端许可证内容
  license: 'YOUR_CLIENT_LICENSE',
})
```

这里填写的是许可证内容，不是许可证文件的路径。

## 插件模式 [#in-plugin-mode]

在已有的 Univer 实例上注册 `UniverLicensePlugin`，并放在其他 Pro 插件之前：

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_CLIENT_LICENSE',
})
```

## 协同应用中的配置

协同应用同样需要在浏览器端配置许可证。可以对照 [Office 快速开始](https://office.univer.ai/zh-CN/collaboration/quick-start)中的前端示例，查看许可证插件与协同插件的注册位置。前后端包版本需要符合 [SDK 环境与版本要求](https://office.univer.ai/zh-CN/requirements)。

许可证决定可以使用哪些 Pro 功能；用户能否查看或编辑某份文档，由业务权限决定。配置许可证后，仍需按[服务端集成](/guides/server-integration)接入登录和文档权限。

## 配置后检查

重新打开应用，验证需要的 Pro 功能。如果仍有水印或授权限制，先检查许可证是否完整、是否在有效期内、是否覆盖当前功能和版本；插件模式还需检查注册顺序。仍无法解决时，联系许可证提供方。
