---
title: Интеграция в Astro
---

Сначала прочитайте [Установка и базовое использование](/guides/docs/getting-started/installation). В приведенном ниже примере Univer Docs монтируется на странице Astro внутри контейнера с явной высотой.

Инициализируйте редактор из простого тега `<script>` так, чтобы он работал в браузере. Запустите эту инициализацию на первой загрузке и снова на `astro:page-load` и удалите редактор перед `astro:before-swap` при использовании ClientRouter. Держите редактор импорт из передней части Astro. Подробности события документированы в [Навигационные события Astro](https://docs.astro.build/en/reference/modules/astro-transitions/) .

### Шаги интеграции

1. Инициализируйте Univer в `mount()` / `astro:page-load`.
2. Удалите его в `astro:before-swap`.

### Настройка пресетов [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | DOM-элемент для размещения редактора или его идентификатор. |

### Пример кода

```astro title="src/pages/index.astro"
<div id="univer-docs" style="height: 600px"></div>

<script>
  import type { Univer } from '@univerjs/presets'
  import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
  import UniverPresetDocsCoreruRU from '@univerjs/preset-docs-core/locales/ru-RU'
  import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

  import '@univerjs/preset-docs-core/lib/index.css'

  let univerInstance: Univer | undefined

  function mount() {
    const container = document.getElementById('univer-docs')
    if (!container || univerInstance) return

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.RU_RU,
      locales: { [LocaleType.RU_RU]: mergeLocales(UniverPresetDocsCoreruRU) },
      presets: [UniverDocsCorePreset({ container })],
    })

    univerAPI.createDocument({})
    univerInstance = univer
  }

  function dispose() {
    univerInstance?.dispose()
    univerInstance = undefined
  }

  mount()
  document.addEventListener('astro:page-load', mount)
  document.addEventListener('astro:before-swap', dispose)
</script>
```
