import { SiAngular, SiAstro, SiNextdotjs, SiReact, SiVuedotjs, SiWebcomponentsdotorg } from '@icons-pack/react-simple-icons'

Univer はさまざまな UI ライブラリ/フレームワークとの連携をサポートし、異なる環境で利用できます。React、Vue、Angular いずれでもスムーズに統合できます。

使用中のフレームワークに慣れている場合は、該当する連携ガイドへ直接進めます。
