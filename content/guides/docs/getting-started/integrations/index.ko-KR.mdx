import { SiAngular, SiAstro, SiNextdotjs, SiReact, SiVuedotjs, SiWebcomponentsdotorg } from '@icons-pack/react-simple-icons'

Univer는 다양한 UI 라이브러리 및 프레임워크와의 통합을 지원하므로 여러 환경에서 Univer를 사용할 수 있습니다. React, Vue, Angular 등 어떤 환경에서도 매끄러운 통합 경험을 제공합니다.

사용 중인 프레임워크나 라이브러리에 이미 익숙하다면 해당 통합 가이드로 바로 이동할 수 있습니다.
