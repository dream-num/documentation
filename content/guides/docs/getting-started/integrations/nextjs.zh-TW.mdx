---
title: 在 Next.js 中整合
---

請先閱讀[安裝和基本使用](/guides/docs/getting-started/installation)。下面的範例使用 Next.js App Router，把 Univer Docs 掛載到設定了明確高度的容器中。

編輯器從 Client Component 中以 `ssr: false`[^ssr] 載入。僅宣告 `use client` 指令不會禁用預渲染，跳過 SSR 的做法見 [Next.js](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr) 指南。

### 整合步驟

1. 在 `useEffect` 中初始化 Univer。
2. 在 `useEffect` 返回的清理函式中銷燬它。

### 預設設定 [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 掛載 Univer 的元素，或該元素的 DOM ID。 |

### 範例程式碼

每次掛載都會建立自己的子容器。銷燬操作放在微任務中執行，等外層 React 清理完成後執行，因此巢狀的 React root 不會在 React 提交期間被同步解除安裝。

```tsx title="univer-editor.tsx"
'use client'

import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreZhTW from '@univerjs/preset-docs-core/locales/zh-TW'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { useEffect, useRef } from 'react'

import '@univerjs/preset-docs-core/lib/index.css'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.ZH_TW,
      locales: {
        [LocaleType.ZH_TW]: mergeLocales(
          UniverPresetDocsCoreZhTW,
        ),
      },
      presets: [
        UniverDocsCorePreset({
          container,
        }),
      ],
    })

    univerAPI.createDocument({})

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return (
    <div ref={containerRef} style={{ height: 600 }} />
  )
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: 伺服器端渲染（SSR）會在瀏覽器載入頁面前執行渲染程式，此時沒有瀏覽器的 `window` 與 DOM。Client Component 仍可能被預先渲染，因此需單獨停用編輯器元件的 SSR。
