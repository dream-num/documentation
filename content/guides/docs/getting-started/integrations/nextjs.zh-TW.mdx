---
title: 在 Next.js 中整合
---

請先閱讀[安裝與基本使用](/guides/docs/getting-started/installation)。以下範例透過 Next.js App Router 將 Univer Docs 掛載到具有明確高度的容器中。

在用戶端元件中透過 `ssr: false`[^ssr] 動態載入編輯器。只宣告 `use client` 不會關閉預先渲染。 [Next.js](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr).

### 整合步驟

1. 在 `useEffect` 中初始化 Univer
2. 在 `useEffect` 的清理函式中銷燬 Univer

### 範例程式碼

每次掛載使用獨立的子容器，並在外層 React 清理完成後的微任務中銷毀實例，避免在 React 提交期間同步卸載巢狀 React root。

```tsx title="univer-editor.tsx"
'use client'

import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreZhTW from '@univerjs/preset-docs-core/locales/zh-TW'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { useEffect, useRef } from 'react'

import '@univerjs/preset-docs-core/lib/index.css'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.ZH_TW,
      locales: {
        [LocaleType.ZH_TW]: mergeLocales(
          UniverPresetDocsCoreZhTW,
        ),
      },
      presets: [
        UniverDocsCorePreset({
          container,
        }),
      ],
    })

    univerAPI.createDocument({})

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return (
    <div ref={containerRef} style={{ height: 600 }} />
  )
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: 伺服器端渲染（SSR）會在瀏覽器載入頁面前執行渲染程式，此時沒有瀏覽器的 `window` 與 DOM。Client Component 仍可能被預先渲染，因此需單獨停用編輯器元件的 SSR。
