---
title: Astro에 통합하기
---

먼저 [설치 및 기본 사용](/guides/docs/getting-started/installation)를 읽으십시오. Astro 페이지에 Univer Docs를 마운트 아래의 예는 명시된 높이로 컨테이너 내부에 있습니다.

일반 `<script>` 태그에서 편집기를 초기화하여 브라우저에서 실행합니다. 처음 로드에서 실행하고 `astro:page-load`에서 다시 실행하고 클라이언트로 변환 할 때 `astro:before-swap` 전에 편집기의 디포지트를 실행하십시오. 편집기가 Astro frontmatter에서 가져옵니다. 이벤트 세부 사항은 [Astro의 내비게이션 이벤트](https://docs.astro.build/en/reference/modules/astro-transitions/)에 문서화됩니다.

### 통합 단계

1. `mount()` / `astro:page-load`에서 Univer를 초기화합니다.
2. `astro:before-swap`에서 그것을 처리하십시오.

### 프리셋 설정 [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 편집기를 마운트할 DOM 요소 또는 해당 요소의 ID입니다. |

### 예제 코드

```astro title="src/pages/index.astro"
<div id="univer-docs" style="height: 600px"></div>

<script>
  import type { Univer } from '@univerjs/presets'
  import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
  import UniverPresetDocsCorekoKR from '@univerjs/preset-docs-core/locales/ko-KR'
  import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

  import '@univerjs/preset-docs-core/lib/index.css'

  let univerInstance: Univer | undefined

  function mount() {
    const container = document.getElementById('univer-docs')
    if (!container || univerInstance) return

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.KO_KR,
      locales: { [LocaleType.KO_KR]: mergeLocales(UniverPresetDocsCorekoKR) },
      presets: [UniverDocsCorePreset({ container })],
    })

    univerAPI.createDocument({})
    univerInstance = univer
  }

  function dispose() {
    univerInstance?.dispose()
    univerInstance = undefined
  }

  mount()
  document.addEventListener('astro:page-load', mount)
  document.addEventListener('astro:before-swap', dispose)
</script>
```
