---
title: Intégrer dans Next.js
---

Lisez d'abord [l'installation et l'utilisation de base](/guides/docs/getting-started/installation). L'exemple ci-dessous utilise le routeur d'application Next.js et monte Univer Docs dans un conteneur à hauteur explicite.

Chargez l'éditeur à partir d'un élément client avec `ssr: false`[^ssr]. La directive `use client` ne désactive pas à elle seule le prérendement, alors suivez le guide [Next.js](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr) pour sauter SSR.

### Étapes d’intégration

1. Initialisez Univer dans `useEffect`.
2. Détruisez-le dans la fonction de nettoyage retournée par `useEffect`.

### Configuration des préréglages [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | Élément DOM de montage de l’éditeur ou son identifiant. |

### Exemple de code

Chaque montage crée son propre conteneur enfant. L'élimination se déroule dans une microtâche après le nettoyage React environnant, de sorte qu'une racine React imbriquée n'est jamais démontée synchronement lors d'un commit React.

```tsx title="univer-editor.tsx"
'use client'

import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEnUS from '@univerjs/preset-docs-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { useEffect, useRef } from 'react'

import '@univerjs/preset-docs-core/lib/index.css'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          UniverPresetDocsCoreEnUS,
        ),
      },
      presets: [
        UniverDocsCorePreset({
          container,
        }),
      ],
    })

    univerAPI.createDocument({})

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return (
    <div ref={containerRef} style={{ height: 600 }} />
  )
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: Le rendu côté serveur (SSR) exécute le code de rendu avant le chargement de la page dans le navigateur, sans `window` ni DOM. Un Client Component peut aussi être prérendu : il faut désactiver le SSR pour le composant de l’éditeur.
