---
title: Web Component に統合する
---

<Callout>
  カスタムコンポーネントとしてWebコンポーネントを使用するには、[カスタムコンポーネント](/guides/docs/ui/components#web-component)を参照してください。

</Callout>

UniverはWebコンポーネント内でホストすることができます。エディタをカスタム要素として登録し、他のHTML要素のようにマウントします。

### プリセット設定 [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | エディターのマウント先となる DOM 要素、またはその ID。 |

### 事例紹介

```typescript
import type { Univer } from '@univerjs/presets'
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreJaJP from '@univerjs/preset-docs-core/locales/ja-JP'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'

class UniverEditorElement extends HTMLElement {
  private univer?: Univer

  connectedCallback() {
    if (this.univer) return
    const container = this

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.JA_JP,
      locales: {
        [LocaleType.JA_JP]: mergeLocales(
          UniverPresetDocsCoreJaJP,
        ),
      },
      presets: [
        UniverDocsCorePreset({
          container,
        }),
      ],
    })

    univerAPI.createDocument({})

    this.univer = univer
  }

  disconnectedCallback() {
    this.univer?.dispose()
    this.univer = undefined
  }
}

customElements.define('univer-docs-editor', UniverEditorElement)
```

```html
<univer-docs-editor style="display: block; height: 600px"></univer-docs-editor>
```
