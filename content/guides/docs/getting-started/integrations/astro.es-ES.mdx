---
title: Integrar en Astro
---

Lea [instalación y uso básico](/guides/docs/getting-started/installation) primero. El ejemplo a continuación monta Univer Docs en una página Astro, dentro de un contenedor con una altura explícita.

Inicializar el editor desde una sencilla etiqueta `<script>` para que se ejecute en el navegador. Ejecute esta inicialización en primera carga y de nuevo en `astro:page-load`, y descargue el editor antes de `astro:before-swap` cuando se utilice ClientRouter. Mantenga el editor importa de Astro frontmatter. Los detalles del evento se documentan en [Eventos de navegación de Astro](https://docs.astro.build/en/reference/modules/astro-transitions/).

### Pasos de integración

1. Inicializa Univer en `mount()` / `astro:page-load`.
2. Desórtelo en `astro:before-swap`.

### Configuración de preajustes [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | Elemento DOM donde se monta el editor o su ID. |

### Código de ejemplo

```astro title="src/pages/index.astro"
<div id="univer-docs" style="height: 600px"></div>

<script>
  import type { Univer } from '@univerjs/presets'
  import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
  import UniverPresetDocsCoreesES from '@univerjs/preset-docs-core/locales/es-ES'
  import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

  import '@univerjs/preset-docs-core/lib/index.css'

  let univerInstance: Univer | undefined

  function mount() {
    const container = document.getElementById('univer-docs')
    if (!container || univerInstance) return

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.ES_ES,
      locales: { [LocaleType.ES_ES]: mergeLocales(UniverPresetDocsCoreesES) },
      presets: [UniverDocsCorePreset({ container })],
    })

    univerAPI.createDocument({})
    univerInstance = univer
  }

  function dispose() {
    univerInstance?.dispose()
    univerInstance = undefined
  }

  mount()
  document.addEventListener('astro:page-load', mount)
  document.addEventListener('astro:before-swap', dispose)
</script>
```
