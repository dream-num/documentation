---
title: 在 Next.js 中集成
---

请先阅读[安装和基本使用](/guides/docs/getting-started/installation)。下面的示例使用 Next.js App Router，把 Univer Docs 挂载到设置了明确高度的容器中。

编辑器从 Client Component 中以 `ssr: false`[^ssr] 加载。仅声明 `use client` 指令不会禁用预渲染，跳过 SSR 的做法见 [Next.js](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr) 指南。

### 集成步骤

1. 在 `useEffect` 中初始化 Univer。
2. 在 `useEffect` 返回的清理函数中销毁它。

### 预设配置 [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 挂载 Univer 的元素，或该元素的 DOM ID。 |

### 示例代码

每次挂载都会创建自己的子容器。销毁操作放在微任务中执行，等外层 React 清理完成后运行，因此嵌套的 React root 不会在 React 提交期间被同步卸载。

```tsx title="univer-editor.tsx"
'use client'

import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreZhCN from '@univerjs/preset-docs-core/locales/zh-CN'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { useEffect, useRef } from 'react'

import '@univerjs/preset-docs-core/lib/index.css'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.ZH_CN,
      locales: {
        [LocaleType.ZH_CN]: mergeLocales(
          UniverPresetDocsCoreZhCN,
        ),
      },
      presets: [
        UniverDocsCorePreset({
          container,
        }),
      ],
    })

    univerAPI.createDocument({})

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return (
    <div ref={containerRef} style={{ height: 600 }} />
  )
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: 服务端渲染（SSR）会在浏览器加载页面前执行渲染代码，此时没有浏览器的 `window` 和 DOM。Client Component 仍可能被预渲染，因此需要单独关闭编辑器组件的 SSR。
