Читать далее [Установка и базовое использование](/guides/docs/getting-started/installation) В приведенном ниже примере используется Next.js Приложение Router and mounts Univer Док в контейнере с явной высотой.

Загрузите редактор из клиентского компонента с помощью `ssr: false`[^ssr]. Только директива `use client` не отключает предварительный рендеринг, поэтому следуйте руководству [Next.js](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr) для пропуска SSR.

### Шаги интеграции

1. Инициализируйте Univer внутри `useEffect`.
2. Уничтожьте его в функции очистки, возвращенной `useEffect`.

### Настройка пресетов [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | DOM-элемент для размещения редактора или его идентификатор. |

### Пример кода

Утилизация выполняется в микрозадаче после окружающей очистки React, поэтому вложенный корень React никогда не размещается синхронно во время выполнения React.

```tsx title="univer-editor.tsx"
'use client'

import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEnUS from '@univerjs/preset-docs-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { useEffect, useRef } from 'react'

import '@univerjs/preset-docs-core/lib/index.css'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          UniverPresetDocsCoreEnUS,
        ),
      },
      presets: [
        UniverDocsCorePreset({
          container,
        }),
      ],
    })

    univerAPI.createDocument({})

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return (
    <div ref={containerRef} style={{ height: 600 }} />
  )
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: Серверный рендеринг (SSR) выполняет код отрисовки до загрузки страницы браузером, без `window` и DOM. Client Component также может предварительно отрисовываться, поэтому SSR редактора отключается отдельно.
