---
title: Integrar en Next.js
---

Lea el [instalación y uso básico](/guides/docs/getting-started/installation) primero. El ejemplo a continuación utiliza el router Next.js App y monta los Docs Univer en un contenedor con una altura explícita.

Carga al editor de un componente cliente con `ssr: false`[^ssr]. La directiva `use client` por sí sola no deshabilita prerendering, por lo que siga la guía [Next.js](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr) para saltar SSR.

### Pasos de integración

1. Inicializa Univer dentro de `useEffect`.
2. Destruyelo en la función de limpieza devuelta por `useEffect`.

### Configuración de preajustes [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | Elemento DOM donde se monta el editor o su ID. |

### Código de ejemplo

Cada montura crea su propio contenedor para niños. El despojo corre en un microtarea después de la limpieza React circundante, por lo que una raíz React anidada nunca se encuentra sin montar sincrónicamente durante un compromiso React.

```tsx title="univer-editor.tsx"
'use client'

import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEnUS from '@univerjs/preset-docs-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { useEffect, useRef } from 'react'

import '@univerjs/preset-docs-core/lib/index.css'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          UniverPresetDocsCoreEnUS,
        ),
      },
      presets: [
        UniverDocsCorePreset({
          container,
        }),
      ],
    })

    univerAPI.createDocument({})

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return (
    <div ref={containerRef} style={{ height: 600 }} />
  )
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: El renderizado del lado del servidor (SSR) ejecuta el código de renderizado antes de cargar la página en el navegador, sin `window` ni DOM. Un Client Component también puede prerenderizarse, por lo que debe desactivar el SSR del componente del editor.
