---
title: Next.js への統合
---

[インストールと基本的な使い方](/guides/docs/getting-started/installation)を最初に読みます。以下の例では、Next.jsアプリルータを使用し、Univer Docsを明示的な高さを持つコンテナにマウントします。

`ssr: false`[^ssr] でクライアントコンポーネントからエディタをロードします。 `use client`ディレクティブは、プレレンダーを無効化しないため、[Next.js](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr)ガイドに従ってSSRをスキッピングします。

### 統合手順

1. `useEffect` 内で Univer を初期化します。
2. `useEffect`で返されたクリーンアップ機能で破壊します。

### プリセット設定 [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | エディターのマウント先となる DOM 要素、またはその ID。 |

### 事例紹介

各マウントは、独自の子コンテナを作成します。 React のクリーンアップを囲むと、処分はマイクロタスクで実行されるので、ネストされた React root は、React commit の間に同期的にマウントされることはありません。

```tsx title="univer-editor.tsx"
'use client'

import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreJaJP from '@univerjs/preset-docs-core/locales/ja-JP'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import { useEffect, useRef } from 'react'

import '@univerjs/preset-docs-core/lib/index.css'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const { univer, univerAPI } = createUniver({
      locale: LocaleType.JA_JP,
      locales: {
        [LocaleType.JA_JP]: mergeLocales(
          UniverPresetDocsCoreJaJP,
        ),
      },
      presets: [
        UniverDocsCorePreset({
          container,
        }),
      ],
    })

    univerAPI.createDocument({})

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return (
    <div ref={containerRef} style={{ height: 600 }} />
  )
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: サーバーサイドレンダリング（SSR）はブラウザーがページを読み込む前に描画コードを実行します。この環境には `window` や DOM がありません。Client Component も事前描画される場合があるため、エディターの SSR を個別に無効化します。
