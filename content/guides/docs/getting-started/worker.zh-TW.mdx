Univer Docs 可以透過註冊 `UniverDocsLayoutWorkerPlugin`，將文件排版放到 Web Worker[^web-worker] 中執行。該外掛須註冊在 Docs 核心外掛之後。它接收的 `workerFactory` 負責為排版服務建立新的 Worker。

下面的程式碼是對[安裝和基本使用](/guides/docs/getting-started/installation)中配置的擴充套件。外掛必須在建立或載入內容之前註冊；如需修改已註冊的外掛，應修改原有註冊，而不是重複註冊同一個外掛。

## 主執行緒

`UniverDocsLayoutWorkerPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `workerFactory` | `() => Worker` |  | 建立負責文件排版的 Worker。該回撥為必填項。 |
| <ConfigKey depth={0}>fontFaces</ConfigKey> | `object[]` |  | 在排版開始前，將指定的字型載入到編輯器和排版 Worker 中。 |
| <ConfigKey depth={1}>family</ConfigKey> | `string` |  | 用於文件排版的字型名稱。 |
| <ConfigKey depth={1}>source</ConfigKey> | `string \| ArrayBuffer` |  | 字型位元組，或 CSS `FontFace` 的 source，例如 `url(...)`。 |
| <ConfigKey depth={1}>descriptors</ConfigKey> | `FontFaceDescriptors` |  | 字重、樣式等瀏覽器 `FontFace` 描述符。 |
| `requestTimeoutMs` | `number` | `15_000` | 單次 Worker 請求耗時超過該值（毫秒）時，開始執行恢復。 |

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Worker 入口

```typescript title="worker.ts"
import { Univer } from '@univerjs/core'
import { UniverDocsWorkerPlugin } from '@univerjs/docs/worker'

const univer = new Univer()
univer.registerPlugin(UniverDocsWorkerPlugin)
```

使用 module 型別的 Worker，併為其提供單獨的入口檔案。Worker 與主執行緒的包版本必須保持一致。渲染和使用者互動仍留在主執行緒。

[^web-worker]: Web Worker 在瀏覽器主執行緒之外執行 JavaScript，透過訊息與主執行緒通訊，無法直接存取頁面 DOM。將計算移入 Worker 不代表將編輯器介面也移入其中。
