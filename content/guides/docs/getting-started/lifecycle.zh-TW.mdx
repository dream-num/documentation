## 全域生命週期

- **Starting**: Univer 正在初始化，尚不存在任何業務例項。
- **Ready**: 第一個業務例項已建立。之後建立的例項不會再次觸發該階段。
- **Rendered**: 標準 UI 已完成第一次渲染切換，非同步內容可能仍在載入。
- **Steady**: 標準 UI 在 Rendered 之後經過一段延遲進入此階段，不會等待所有非同步任務完成。

### Facade API

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="事件監聽的範圍">

`LifeCycleChanged` 報告 Univer 的全域性階段，而不是某個外掛的階段。例如，在全域性進入 `Ready` 之後載入外掛 B，B 仍會執行 `onReady()`，但不會再發出一次全域性 `Ready` 事件。

新增的監聽器可能立即收到當前階段，`Starting` 也不例外。如果只需瞭解當前所處階段，可直接呼叫 `univerAPI.getCurrentLifecycleStage()`。

</Callout>

如需移除監聽器，請使用呼叫返回的 `disposable` 物件：

```typescript
disposable.dispose()
```

外掛載入時執行 `onStarting()`，隨後執行到 Univer 當前所處的全域性階段。下面的範例可以改變 B 的載入時機，以展示它的鉤子呼叫與 A 的差異。

通用外掛在註冊時載入。業務型別外掛通常在該型別的第一個例項建立之前載入。某個型別已經啟動之後，為該型別新增的外掛會延後，成批載入。顯式依賴可以讓該外掛提前載入。

同一批外掛的鉤子同步執行，按依賴順序逐階段執行，不會等待鉤子中的非同步任務。訪問業務例項、DOM 元素或資源之前，請先確認對應物件已經就緒。
