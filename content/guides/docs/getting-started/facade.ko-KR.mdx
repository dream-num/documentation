Univer의 아키텍처는 복잡한 요구 사항을 커버하도록 설계되었습니다. Facade API는 간단한 레이어를 제공합니다.

이 페이지는 Facade API를 응용 프로그램에 추가하는 방법을 설명합니다. 기능 섹션은 각 기능에 대한 주요 Facade API 목록을 나열합니다. 전체 목록을 보려면 플러그인의 API 참조를 참조하십시오.

<Callout type="warning" title="주 메뉴">
  일부 Facade API는 비동기이며, 특히 데이터 수정 API는 일반적으로 Promise를 반환합니다. 변경 후 즉시 데이터를 읽을 필요가있는 경우 `await` 통화 또는 체인 `.then()`. 그렇지 않으면 결과가 예상치 못한 일 수 있습니다. API가 Promise를 돌려보내는 것을 결정하려면 해당 플러그인의 API 참조를 참조하십시오.
</Callout>

## 플러그인 모드에서 Facade API 통합하기

### 설치

Univer 플러그인 모드에 설치되면 각 플러그인은 Facade API 구현의 자체 부분을 포함하고, 그 부품은 글로벌 Facade API 루트 객체에 첨부합니다. Facade API를 제공하는 플러그인의 경우, 해당 구현을 필요에 따라 가져올 수 있습니다.

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs/ui/facade'
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="주 메뉴">
  모든 플러그인에는 전면 패키지가 포함되어 있지 않습니다. 각 기능의 문서는 그것이 있는지 여부를 나타냅니다.
</Callout>

### 사용법

Facade API는 기존 Univer 인스턴스를 포장합니다. 먼저 인스턴스를 만들고 API를 빌드합니다.

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

### 주의 사항

모든 Facade API이 호출되기 때문에 효과가 발생합니다. 특정 수명주기 단계에서만 작동합니다. 통화가 효과가 없다면 나중에 단계로 실행하십시오.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Code to be executed when the lifecycle stage is Rendered
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Code to be executed when the lifecycle stage is Steady
  }
})
```
## 프리셋 모드에서 Facade API 통합하기

미리 설정 모드에서, 미리 설정은 포함 된 기능에 Facade API를 가져옵니다. Univer 인스턴스를 만들기 위해 일치하는 Facade API 예를 반환, `univerAPI`, 직접 사용할 수 있습니다.
