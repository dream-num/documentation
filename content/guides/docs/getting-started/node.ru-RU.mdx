Univer изоморфен: он может работать не только в браузере, но и в среде Node.js. На основе Headless Univer можно создавать сервисы обработки данных, которые генерируют или изменяют документы на сервере и взаимодействуют с Univer Docs через Facade API.

В Node.js используйте режим плагинов и регистрируйте нужные плагины без компонентов браузерного интерфейса.

## Установка

```package-install
npm install @univerjs/core @univerjs/engine-render @univerjs/engine-formula @univerjs/docs
```

## Использование

```typescript
import { LocaleType, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import '@univerjs/docs/facade'

const univer = new Univer({
  locale: LocaleType.RU_RU,
  locales: {
    [LocaleType.RU_RU]: {},
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverDocsPlugin)

const univerAPI = FUniver.newAPI(univer)
univerAPI.createDocument({})
```

## Пример совместного редактирования в Node.js [#node-collaboration-example]

Node.js может работать как клиент совместного редактирования: загружать существующий документ с сервера, изменять его содержимое через API Facade и синхронизировать изменения с другими клиентами, открывшими тот же документ. Перед запуском подготовьте [сервис совместного редактирования](/server/collaboration/quick-start), [клиентскую лицензию](/server/license) и ID доступного документа.

### Файлы примера

Расположите файлы следующим образом:

```text
src/docs/node/
├── main.ts
└── univer.ts
```

- `univer.ts`: создаёт Univer и регистрирует плагины функций документов, расширения Facade и клиент совместного редактирования Node.js.
- `main.ts`: загружает документ для совместного редактирования и демонстрирует API абзацев, текста, колонтитулов, блоков примечаний, блоков кода, цитат, списков, фигур, таблиц и колонок.

Замените `your-license`, адрес сервера и Cookie в `univer.ts`, а также ID документа в `main.ts`.

```typescript title="main.ts"
import type { FConnectorShape } from '@univerjs-pro/engine-shape/facade'
import { FUniver } from '@univerjs/core/facade'
import process from 'node:process'
import { createUniverOnNode } from './univer'

async function run(): Promise<void> {
  const univer = createUniverOnNode()
  const univerAPI = FUniver.newAPI(univer)

  const document = await univerAPI.getCollaboration().loadDocAsync('your-unit-id')
  if (!document) {
    throw new Error(
      'Не удалось загрузить документ для совместного редактирования. Проверьте ID документа и права доступа.',
    )
  }

  testDocsFacadeAPI(univerAPI)
  testDocsHeaderFooterFacadeAPI(univerAPI)
  testDocsCalloutFacadeAPI(univerAPI)
  testDocsCodeFacadeAPI(univerAPI)
  testDocsQuoteFacadeAPI(univerAPI)
  testDocsListFacadeAPI(univerAPI)
  testDocsShapeFacadeAPI(univerAPI)
  testDocsTableFacadeAPI(univerAPI)
  testDocsColumnFacadeAPI(univerAPI)

  await univerAPI.getCollaboration().flush(document.getId())
  console.warn('Изменения документа синхронизированы с сервером.')
}

function testDocsShapeFacadeAPI(univerAPI: FUniver) {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return
  const paragraph = fDocument.getParagraphs()[0]
  if (!paragraph) return
  const anchor = {
    paragraphId: paragraph.getId(),
    segmentId: paragraph.getSegmentId(),
  }

  const shape = fDocument.insertShape({
    shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
    placement: {
      wrappingStyle: univerAPI.Enum.TextWrappingStyle.WRAP_SQUARE,
      anchor,
      position: { horizontalOffset: 80, verticalOffset: 80 },
    },
    transform: { width: 320, height: 160 },
    shapeData: {
      fill: {
        fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
        color: '#DBEAFE',
      },
      stroke: {
        lineStrokeType: univerAPI.Enum.ShapeLineTypeEnum.SolidLine,
        color: '#2563EB',
        width: 2,
      },
    },
  })
  if (!shape) return

  shape
    .setRotation(4)
    .setStrokeOpacity(0.9)
    .getText()
    .setText('Пример фигуры документа через API Facade')
    .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
    .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)

  const target = fDocument.insertShape({
    shapeType: univerAPI.Enum.ShapeTypeEnum.Ellipse,
    placement: {
      wrappingStyle: univerAPI.Enum.TextWrappingStyle.WRAP_SQUARE,
      anchor,
      position: { horizontalOffset: 500, verticalOffset: 100 },
    },
    transform: { width: 160, height: 120 },
    shapeData: {
      fill: { fillType: univerAPI.Enum.ShapeFillEnum.SolidFill, color: '#DCFCE7' },
      stroke: { lineStrokeType: univerAPI.Enum.ShapeLineTypeEnum.SolidLine, color: '#16A34A', width: 2 },
    },
  })
  if (!target) return

  const connector = fDocument.insertShape({
    shapeType: univerAPI.Enum.ShapeTypeEnum.BentConnector3,
    placement: {
      wrappingStyle: univerAPI.Enum.TextWrappingStyle.WRAP_SQUARE,
      anchor,
      position: { horizontalOffset: 360, verticalOffset: 130 },
    },
    transform: { width: 180, height: 80 },
  })
  if (!connector || !connector.isConnectorShape()) return

  const sourceSites = shape.getConnectionSites()
  const targetSites = target.getConnectionSites()
  ;(connector as FConnectorShape)
    .setStrokeColor('#475569')
    .setStrokeWidth(2)
    .setEndArrow(univerAPI.Enum.ShapeArrowTypeEnum.Arrow, univerAPI.Enum.ShapeArrowSizeEnum.Medium)
    .bindStart(shape.getId(), sourceSites[0]?.index ?? 0)
    .bindEnd(target.getId(), targetSites[2]?.index ?? targetSites[0]?.index ?? 0)

  console.warn('ID фигуры документа:', shape.getId())
  console.warn('Количество фигур документа:', fDocument.getShapes().length)
}

function testDocsFacadeAPI(univerAPI: FUniver): void {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return

  const intro = fDocument.appendParagraph(
    `Привет от клиента совместного редактирования Node.js. Текущее время: ${new Date().toString()}.`,
  )
  intro.appendText(' [встроенная вставка]')

  const beforeIntro = fDocument.insertParagraph(
    intro.getInfo().paragraphIndex,
    'Текст вставлен перед вводным абзацем с помощью объекта абзаца.',
  )
  const foundIntro = fDocument.findParagraphByText('клиента совместного редактирования Node.js')
  const introMatches = fDocument.findParagraphs({ text: 'клиента совместного редактирования Node.js' })
  const introRange = intro.getRange()
  const bodyBeforeDelete = fDocument.getBody()
  const deleteStartOffset = bodyBeforeDelete.dataStream.indexOf(' [встроенная вставка]')
  if (deleteStartOffset >= 0) {
    fDocument.deleteRange({
      startOffset: deleteStartOffset,
      endOffset: deleteStartOffset + ' [встроенная вставка]'.length,
    })
  }

  intro.setStyle({
    textStyle: {
      fs: 12,
    },
  })

  console.warn(`ID текущего документа: ${fDocument.getId()}`)
  console.warn(`Название текущего документа: ${fDocument.getName()}`)
  console.warn(`Является ли текущий документ современным: ${fDocument.isModern()}`)
  console.warn(`ID вводного абзаца: ${intro.getId()}`)
  console.warn(`Индекс дочернего узла вводного абзаца после перемещения: ${intro.getInfo().paragraphIndex}`)
  console.warn('Диапазон вводного абзаца:', introRange)
  console.warn('ID найденного вводного абзаца:', foundIntro?.getId())
  console.warn('Количество совпавших вводных абзацев:', introMatches.length)
  console.warn('Количество абзацев основного текста:', fDocument.getParagraphs().length)
  console.warn(`ID вставленного абзаца: ${beforeIntro.getId()}`)
  console.warn(`Длина основного текста снимка документа: ${fDocument.save().body?.dataStream.length ?? 0}`)
}

function testDocsHeaderFooterFacadeAPI(univerAPI: FUniver): void {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return

  if (fDocument.isModern()) {
    console.warn('Пример колонтитулов пропущен: современные документы не поддерживают колонтитулы страниц.')
    return
  }

  const headerSegmentId = fDocument.ensurePageHeader()
  const footerSegmentId = fDocument.ensurePageFooter()

  const headerParagraph = fDocument.appendParagraph(
    'Пример верхнего колонтитула Docs в Node.js через API Facade.',
    headerSegmentId,
  )
  headerParagraph.appendText(` Документ: ${fDocument.getName() || fDocument.getId()}`)
  const footerParagraph = fDocument.appendParagraph(
    'Пример нижнего колонтитула Docs в Node.js через API Facade.',
    footerSegmentId,
  )

  fDocument.insertText(0, 'Верхний колонтитул страницы:', headerSegmentId)
  footerParagraph.setStyle({
    textStyle: {
      fs: 10,
    },
  })

  console.warn('ID сегмента верхнего колонтитула документа:', headerSegmentId)
  console.warn(
    'Абзацы верхнего колонтитула документа:',
    fDocument.getParagraphs(headerSegmentId).map((paragraph) => paragraph.getText()),
  )
  console.warn('Длина текста верхнего колонтитула документа:', fDocument.getBody(headerSegmentId).dataStream.length)
  console.warn('ID сегмента нижнего колонтитула документа:', footerSegmentId)
  console.warn(
    'ID абзаца нижнего колонтитула документа:',
    fDocument.findParagraphByText('нижнего колонтитула Docs в Node.js через API Facade', footerSegmentId)?.getId(),
  )
}

function testDocsColumnFacadeAPI(univerAPI: FUniver): void {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return

  if (!fDocument.isModern()) {
    console.warn('Пример колонок пропущен: группы колонок требуют современного документа.')
    return
  }

  const groupId = createSampleId('column-group')
  const group = fDocument.insertColumnGroup(3, {
    columnGroupId: groupId,
    columnIds: [createSampleId('column-left'), createSampleId('column-middle'), createSampleId('column-right')],
    gap: 18,
    widthRatios: [1.1, 1, 0.9],
  })

  if (!group) return

  const [leftColumn, middleColumn, rightColumn] = group.getColumns()
  const leftOffset = leftColumn?.getInsertOffset()
  if (leftOffset != null) {
    fDocument.insertText(leftOffset, 'Левая колонка примера Facade.')
  }

  const middleOffset = middleColumn?.getInsertOffset()
  if (middleOffset != null) {
    fDocument.insertText(middleOffset, 'Средняя колонка примера Facade.')
  }

  const rightOffset = rightColumn?.getInsertOffset()
  if (rightOffset != null) {
    fDocument.insertTableFromData(
      [
        ['Показатель', 'Сейчас', 'Следующий шаг'],
        ['Охват функций', 'Колонки', 'Верхний/Нижний колонтитул'],
      ],
      {
        headerRowCount: 1,
        offset: rightOffset,
        tableId: createSampleId('column-table'),
      },
    )
  }

  group.setWidthRatios([1.2, 1, 0.8])

  const insertedColumn = middleColumn
    ? group.addColumn(
        middleColumn.getId(),
        univerAPI.Enum.DocsColumnPositionEnum.RIGHT,
        createSampleId('column-inserted'),
      )
    : null
  const insertedOffset = insertedColumn?.getInsertOffset()
  if (insertedOffset != null) {
    fDocument.insertText(insertedOffset, 'Колонка вставлена через API Facade.')
  }

  const foundByText = fDocument.findColumnGroupByText('Средняя колонка')
  const foundById = fDocument.findColumnGroups({ columnGroupId: group.getId() })
  const firstColumn = group.getColumn(0)
  const groupRange = group.getRange()
  const rangeLookup = groupRange ? fDocument.getColumnGroupAt(groupRange.startOffset) : null

  console.warn('Информация о группе колонок документа:', group.describe())
  console.warn('Количество групп колонок, найденных по ID:', foundById.length)
  console.warn('ID группы колонок, найденной по тексту:', foundByText?.getId())
  console.warn('ID группы колонок, найденной по диапазону:', rangeLookup?.getId())
  console.warn('Текст первой колонки документа:', firstColumn?.getText())
}
```

### Примечания по запуску

`loadDocAsync()` загружает существующий документ с сервера, поэтому вызывать `createDocument()` не требуется. Сервис совместного редактирования определяет пользователя и проверяет права по данным аутентификации, например Cookie в `customHeaders`. Сервер возвращает `memberID` соединения.

В примере отключены офлайн-кеш браузера и блокировка экземпляра между вкладками, поэтому вызывать `setCurrentUser()` для разделения кеша по учётным записям не нужно. Если позже понадобятся функции, зависящие от локального текущего пользователя, например комментарии, его можно задать через `UserManagerService`. Это не заменяет серверную аутентификацию.

Пример колонтитулов применим только к документам с разбивкой на страницы, а пример колонок — только к современным документам. Пример проверяет режим документа через `isModern()` и пропускает неподдерживаемые операции.

Пример вставляет содержимое в существующий документ, поэтому рекомендуется использовать тестовый документ. После выполнения пример сохраняет соединение совместного редактирования. Откройте тот же документ в браузере, чтобы увидеть изменения. `flush()` ожидает подтверждения сервера для изменений в очереди. Для одноразового скрипта вызовите `univer.dispose()` после завершения всех асинхронных операций и синхронизации.
