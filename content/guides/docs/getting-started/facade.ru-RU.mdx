Архитектура Univer предназначена для удовлетворения сложных требований, что затрудняет ее прямое использование. Facade API обеспечивает более простой слой поверх него.

На этой странице описано, как добавить Facade API в ваше приложение. В разделе «Особенности» перечислены основные Facade API для каждой функции. Для полного списка см. ссылку API плагина, который его предоставляет.

<Callout type="warning" title="Осторожно">
  Некоторые API-интерфейсы Facade являются асинхронными, особенно API-интерференции, которые модифицируют данные, которые обычно возвращают Обещание. Если вам нужно прочитать данные сразу после изменения, `await` вызов или цепь `.then()`. В противном случае результат может быть неожиданным. Чтобы определить, какие API-интервенции возвращают Обетование, см. ссылку API соответствующего плагина.
</Callout>

## Интеграция Facade API в режиме плагинов

### Установка

Когда Univer устанавливается в режиме плагина, каждый плагин содержит свою собственную часть реализации Facade API, и эти части прикрепляются к глобальному корневому объекту Facade API. Для плагинов, которые предоставляют Facade API импортируйте соответствующую реализацию по мере необходимости:

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs/ui/facade'
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="Осторожно">
  Не каждый плагин включает в себя пакет фасада. В документации каждой функции указано, есть ли он.
</Callout>

### Использование

Facade API обертывает существующий экземпляр Univer. Сначала создайте экземпляр, а затем создайте из него API:

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

### Важные замечания

Не каждый Facade API вступает в силу, как только он называется. Некоторые работают только на определенном этапе жизненного цикла. Если вызов не имеет эффекта, запустите его на более позднем этапе:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Code to be executed when the lifecycle stage is Rendered
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Code to be executed when the lifecycle stage is Steady
  }
})
```
## Интеграция Facade API в режиме предустановок

В заданном режиме заданный импортирует Facade API для функций, которые он включает.Создание экземпляра Univer возвращает соответствующий экземпляр Facade API, `univerAPI` , который может использоваться непосредственно.
