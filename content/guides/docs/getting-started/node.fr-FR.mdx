Univer est isomorphe, ce qui signifie qu’il peut s’exécuter aussi bien dans un navigateur que dans un environnement Node.js. Vous pouvez développer des services de traitement de données basés sur Univer sans interface graphique afin de générer ou de modifier des documents côté serveur, et interagir avec Univer Docs au moyen de la Facade API.

Dans Node.js, utilisez le mode plugin et enregistrez les plugins nécessaires sans inclure ceux de l’interface du navigateur.

## Installation

```package-install
npm install @univerjs/core @univerjs/engine-render @univerjs/engine-formula @univerjs/docs
```

## Utilisation

```typescript
import { LocaleType, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import '@univerjs/docs/facade'

const univer = new Univer({
  locale: LocaleType.FR_FR,
  locales: {
    [LocaleType.FR_FR]: {},
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverDocsPlugin)

const univerAPI = FUniver.newAPI(univer)
univerAPI.createDocument({})
```

## Exemple de collaboration dans Node.js [#node-collaboration-example]

Node.js peut servir de client de collaboration : charger un document existant depuis le serveur, modifier son contenu avec l’API Facade et synchroniser les changements avec les autres clients ayant ouvert le même document. Avant l’exécution, préparez un [service de collaboration](/server/collaboration/quick-start), une [licence client](/server/license) et un ID de document accessible.

### Fichiers de l’exemple

Organisez les fichiers comme suit :

```text
src/docs/node/
├── main.ts
└── univer.ts
```

- `univer.ts` : crée Univer et enregistre les plugins de fonctions documentaires, les extensions Facade et le client de collaboration Node.js.
- `main.ts` : charge un document collaboratif et présente les API de paragraphes, de texte, d’en-têtes et pieds de page, d’encadrés, de blocs de code, de citations, de listes, de formes, de tableaux et de colonnes.

Remplacez `your-license`, l’URL du serveur et le Cookie dans `univer.ts`, ainsi que l’ID du document dans `main.ts`.

```typescript title="main.ts"
import type { FConnectorShape } from '@univerjs-pro/engine-shape/facade'
import { FUniver } from '@univerjs/core/facade'
import process from 'node:process'
import { createUniverOnNode } from './univer'

async function run(): Promise<void> {
  const univer = createUniverOnNode()
  const univerAPI = FUniver.newAPI(univer)

  const document = await univerAPI.getCollaboration().loadDocAsync('your-unit-id')
  if (!document) {
    throw new Error('Impossible de charger le document collaboratif. Vérifiez l’ID du document et les droits d’accès.')
  }

  testDocsFacadeAPI(univerAPI)
  testDocsHeaderFooterFacadeAPI(univerAPI)
  testDocsCalloutFacadeAPI(univerAPI)
  testDocsCodeFacadeAPI(univerAPI)
  testDocsQuoteFacadeAPI(univerAPI)
  testDocsListFacadeAPI(univerAPI)
  testDocsShapeFacadeAPI(univerAPI)
  testDocsTableFacadeAPI(univerAPI)
  testDocsColumnFacadeAPI(univerAPI)

  await univerAPI.getCollaboration().flush(document.getId())
  console.warn('Les modifications du document ont été synchronisées avec le serveur.')
}

function testDocsShapeFacadeAPI(univerAPI: FUniver) {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return
  const paragraph = fDocument.getParagraphs()[0]
  if (!paragraph) return
  const anchor = {
    paragraphId: paragraph.getId(),
    segmentId: paragraph.getSegmentId(),
  }

  const shape = fDocument.insertShape({
    shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
    placement: {
      wrappingStyle: univerAPI.Enum.TextWrappingStyle.WRAP_SQUARE,
      anchor,
      position: { horizontalOffset: 80, verticalOffset: 80 },
    },
    transform: { width: 320, height: 160 },
    shapeData: {
      fill: {
        fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
        color: '#DBEAFE',
      },
      stroke: {
        lineStrokeType: univerAPI.Enum.ShapeLineTypeEnum.SolidLine,
        color: '#2563EB',
        width: 2,
      },
    },
  })
  if (!shape) return

  shape
    .setRotation(4)
    .setStrokeOpacity(0.9)
    .getText()
    .setText('Exemple de forme de document avec l’API Facade')
    .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
    .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)

  const target = fDocument.insertShape({
    shapeType: univerAPI.Enum.ShapeTypeEnum.Ellipse,
    placement: {
      wrappingStyle: univerAPI.Enum.TextWrappingStyle.WRAP_SQUARE,
      anchor,
      position: { horizontalOffset: 500, verticalOffset: 100 },
    },
    transform: { width: 160, height: 120 },
    shapeData: {
      fill: { fillType: univerAPI.Enum.ShapeFillEnum.SolidFill, color: '#DCFCE7' },
      stroke: { lineStrokeType: univerAPI.Enum.ShapeLineTypeEnum.SolidLine, color: '#16A34A', width: 2 },
    },
  })
  if (!target) return

  const connector = fDocument.insertShape({
    shapeType: univerAPI.Enum.ShapeTypeEnum.BentConnector3,
    placement: {
      wrappingStyle: univerAPI.Enum.TextWrappingStyle.WRAP_SQUARE,
      anchor,
      position: { horizontalOffset: 360, verticalOffset: 130 },
    },
    transform: { width: 180, height: 80 },
  })
  if (!connector || !connector.isConnectorShape()) return

  const sourceSites = shape.getConnectionSites()
  const targetSites = target.getConnectionSites()
  ;(connector as FConnectorShape)
    .setStrokeColor('#475569')
    .setStrokeWidth(2)
    .setEndArrow(univerAPI.Enum.ShapeArrowTypeEnum.Arrow, univerAPI.Enum.ShapeArrowSizeEnum.Medium)
    .bindStart(shape.getId(), sourceSites[0]?.index ?? 0)
    .bindEnd(target.getId(), targetSites[2]?.index ?? targetSites[0]?.index ?? 0)

  console.warn('ID de la forme du document :', shape.getId())
  console.warn('Nombre de formes du document :', fDocument.getShapes().length)
}

function testDocsFacadeAPI(univerAPI: FUniver): void {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return

  const intro = fDocument.appendParagraph(
    `Bonjour depuis le client de collaboration Node.js. Heure actuelle : ${new Date().toString()}.`,
  )
  intro.appendText(' [insertion en ligne]')

  const beforeIntro = fDocument.insertParagraph(
    intro.getInfo().paragraphIndex,
    'Texte inséré avant l’introduction à l’aide d’un objet paragraphe.',
  )
  const foundIntro = fDocument.findParagraphByText('client de collaboration Node.js')
  const introMatches = fDocument.findParagraphs({ text: 'client de collaboration Node.js' })
  const introRange = intro.getRange()
  const bodyBeforeDelete = fDocument.getBody()
  const deleteStartOffset = bodyBeforeDelete.dataStream.indexOf(' [insertion en ligne]')
  if (deleteStartOffset >= 0) {
    fDocument.deleteRange({
      startOffset: deleteStartOffset,
      endOffset: deleteStartOffset + ' [insertion en ligne]'.length,
    })
  }

  intro.setStyle({
    textStyle: {
      fs: 12,
    },
  })

  console.warn(`ID du document courant : ${fDocument.getId()}`)
  console.warn(`Nom du document courant : ${fDocument.getName()}`)
  console.warn(`Le document courant est-il moderne : ${fDocument.isModern()}`)
  console.warn(`ID du paragraphe d’introduction : ${intro.getId()}`)
  console.warn(`Indice enfant du paragraphe d’introduction après déplacement : ${intro.getInfo().paragraphIndex}`)
  console.warn('Plage du paragraphe d’introduction :', introRange)
  console.warn('ID du paragraphe d’introduction trouvé :', foundIntro?.getId())
  console.warn('Nombre de paragraphes d’introduction correspondants :', introMatches.length)
  console.warn('Nombre de paragraphes du corps :', fDocument.getParagraphs().length)
  console.warn(`ID du paragraphe inséré : ${beforeIntro.getId()}`)
  console.warn(`Longueur du corps de l’instantané du document : ${fDocument.save().body?.dataStream.length ?? 0}`)
}

function testDocsHeaderFooterFacadeAPI(univerAPI: FUniver): void {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return

  if (fDocument.isModern()) {
    console.warn(
      'Exemple d’en-tête et de pied de page ignoré : les documents modernes ne prennent pas en charge les en-têtes et pieds de page.',
    )
    return
  }

  const headerSegmentId = fDocument.ensurePageHeader()
  const footerSegmentId = fDocument.ensurePageFooter()

  const headerParagraph = fDocument.appendParagraph(
    'Exemple d’en-tête Docs Node.js avec l’API Facade.',
    headerSegmentId,
  )
  headerParagraph.appendText(` Document : ${fDocument.getName() || fDocument.getId()}`)
  const footerParagraph = fDocument.appendParagraph(
    'Exemple de pied de page Docs Node.js avec l’API Facade.',
    footerSegmentId,
  )

  fDocument.insertText(0, 'En-tête de page :', headerSegmentId)
  footerParagraph.setStyle({
    textStyle: {
      fs: 10,
    },
  })

  console.warn('ID du segment d’en-tête du document :', headerSegmentId)
  console.warn(
    'Paragraphes de l’en-tête du document :',
    fDocument.getParagraphs(headerSegmentId).map((paragraph) => paragraph.getText()),
  )
  console.warn('Longueur du corps de l’en-tête du document :', fDocument.getBody(headerSegmentId).dataStream.length)
  console.warn('ID du segment de pied de page du document :', footerSegmentId)
  console.warn(
    'ID du paragraphe de pied de page du document :',
    fDocument.findParagraphByText('pied de page Docs Node.js avec l’API Facade', footerSegmentId)?.getId(),
  )
}

function testDocsColumnFacadeAPI(univerAPI: FUniver): void {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return

  if (!fDocument.isModern()) {
    console.warn('Exemple de colonnes ignoré : les groupes de colonnes nécessitent un document moderne.')
    return
  }

  const groupId = createSampleId('column-group')
  const group = fDocument.insertColumnGroup(3, {
    columnGroupId: groupId,
    columnIds: [createSampleId('column-left'), createSampleId('column-middle'), createSampleId('column-right')],
    gap: 18,
    widthRatios: [1.1, 1, 0.9],
  })

  if (!group) return

  const [leftColumn, middleColumn, rightColumn] = group.getColumns()
  const leftOffset = leftColumn?.getInsertOffset()
  if (leftOffset != null) {
    fDocument.insertText(leftOffset, 'Colonne de gauche de l’exemple Facade.')
  }

  const middleOffset = middleColumn?.getInsertOffset()
  if (middleOffset != null) {
    fDocument.insertText(middleOffset, 'Colonne centrale de l’exemple Facade.')
  }

  const rightOffset = rightColumn?.getInsertOffset()
  if (rightOffset != null) {
    fDocument.insertTableFromData(
      [
        ['Indicateur', 'Actuel', 'Étape suivante'],
        ['Fonctionnalités couvertes', 'Colonnes', 'En-tête/Pied de page'],
      ],
      {
        headerRowCount: 1,
        offset: rightOffset,
        tableId: createSampleId('column-table'),
      },
    )
  }

  group.setWidthRatios([1.2, 1, 0.8])

  const insertedColumn = middleColumn
    ? group.addColumn(
        middleColumn.getId(),
        univerAPI.Enum.DocsColumnPositionEnum.RIGHT,
        createSampleId('column-inserted'),
      )
    : null
  const insertedOffset = insertedColumn?.getInsertOffset()
  if (insertedOffset != null) {
    fDocument.insertText(insertedOffset, 'Colonne insérée via l’API Facade.')
  }

  const foundByText = fDocument.findColumnGroupByText('Colonne centrale')
  const foundById = fDocument.findColumnGroups({ columnGroupId: group.getId() })
  const firstColumn = group.getColumn(0)
  const groupRange = group.getRange()
  const rangeLookup = groupRange ? fDocument.getColumnGroupAt(groupRange.startOffset) : null

  console.warn('Informations sur le groupe de colonnes du document :', group.describe())
  console.warn('Nombre de groupes de colonnes trouvés par ID :', foundById.length)
  console.warn('ID du groupe de colonnes trouvé par texte :', foundByText?.getId())
  console.warn('ID du groupe de colonnes trouvé par plage :', rangeLookup?.getId())
  console.warn('Texte de la première colonne du document :', firstColumn?.getText())
}
```

### Notes d’exécution

`loadDocAsync()` charge un document existant sur le serveur ; il est inutile d’appeler `createDocument()`. Le service de collaboration identifie l’utilisateur et vérifie les permissions à partir des informations d’authentification, telles que le Cookie dans `customHeaders`. Le serveur renvoie le `memberID` de la connexion.

Cet exemple désactive le cache hors ligne du navigateur et le verrou d’instance entre onglets. Il est donc inutile d’appeler `setCurrentUser()` pour isoler le cache entre comptes. Si vous utilisez ensuite des fonctions comme les commentaires, qui dépendent de l’utilisateur courant local, vous pouvez définir l’utilisateur de l’application avec `UserManagerService` ; cela ne remplace pas l’authentification du serveur.

L’exemple d’en-tête et de pied de page s’applique uniquement aux documents paginés ; celui des colonnes s’applique uniquement aux documents modernes. L’exemple vérifie le mode du document avec `isModern()` et ignore les opérations non prises en charge.

L’exemple insère du contenu dans un document existant ; utilisez de préférence un document de test. L’exemple maintient la connexion collaborative après son exécution. Ouvrez le même document dans un navigateur pour voir les modifications. `flush()` attend l’accusé de réception du serveur pour les modifications en attente. Pour un script exécuté une seule fois, appelez `univer.dispose()` une fois toutes les opérations asynchrones et la synchronisation terminées.
