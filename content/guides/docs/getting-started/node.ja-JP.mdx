Univer は同型（isomorphic）特性を備えており、ブラウザだけでなく Node.js 環境でも利用できます。Headless Univer を基にデータ処理サービスを構築し、サーバー側でドキュメントを生成・編集し、Facade API を通じて Univer Docs と連携できます。

<PlaygroundFrame lang="ja-JP" slug="docs/node-via-plugin" clickToShow />

Headless Univer の使い方はブラウザ版とほぼ同じです。プリセットモードではすぐに使えるプリセットを提供し、プラグインモードでは UI 関連プラグインを除外するだけで構成できます。

### プリセットモード

#### インストール

```package-install
npm install @univerjs/preset-docs-node-core
```

#### 使い方

```typescript
import { UniverDocsNodeCorePreset } from '@univerjs/preset-docs-node-core' // [!code ++]
import docsNodeCoreJaJP from '@univerjs/preset-docs-node-core/locales/ja-JP' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

async function run(): Promise<void> {
  const { univer, univerAPI } = createUniver({
    locale: LocaleType.JA_JP,
    locales: {
      [LocaleType.JA_JP]: mergeLocales(
        docsNodeCoreJaJP, // [!code ++]
      ),
    },
    presets: [
      UniverDocsNodeCorePreset(), // [!code ++]
    ],
  })

  // ここで Facade API を自由に呼び出してドキュメント処理が可能です
}

run()
```

### プラグインモード

#### インストール

```package-install
npm install @univerjs/core @univerjs/engine-render @univerjs/engine-formula @univerjs/docs
```

#### 使い方

```typescript
import { LocaleType, Univer, UniverInstanceType } from '@univerjs/core'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: {},
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverDocsPlugin)

univer.createUnit(UniverInstanceType.UNIVER_DOC, {})
```
