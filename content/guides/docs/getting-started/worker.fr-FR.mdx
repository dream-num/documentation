Univer Docs peut exécuter la mise en page d'un document dans un Web Worker[^web-worker] en enregistrant `UniverDocsLayoutWorkerPlugin`. Enregistrez le plugin après le plugin de base Docs. Le `workerFactory` il accepte crée un nouveau Worker pour le service de mise en page.

Les extraits ci-dessous prolongent l'installation décrite dans [l'installation et l'utilisation de base](/guides/docs/getting-started/installation). Les plugins doivent être enregistrés avant que le contenu ne soit créé ou chargé. Pour modifier une inscription existante, modifiez cette inscription au lieu d'enregistrer le même plugin deux fois.

## Thread principal

`UniverDocsLayoutWorkerPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `workerFactory` | `() => Worker` |  | Crée le Worker qui exécute la mise en page du document. Requis. |
| <ConfigKey depth={0}>fontFaces</ConfigKey> | `object[]` |  | Charge les polices spécifiées dans l'éditeur et dans le layout Worker avant le démarrage de la layout. |
| <ConfigKey depth={1}>family</ConfigKey> | `string` |  | Nom de famille de police utilisé pour la mise en page du document. |
| <ConfigKey depth={1}>source</ConfigKey> | `string \| ArrayBuffer` |  | Les octets de police, ou une source CSS `FontFace` comme `url(...)`. |
| <ConfigKey depth={1}>descriptors</ConfigKey> | `FontFaceDescriptors` |  | Descripteurs `FontFace` du navigateur, dont la graisse et le style. |
| `requestTimeoutMs` | `number` | `15_000` | Démarre la récupération lorsqu'une seule demande Worker fonctionne plus longtemps que cette valeur, en millisecondes. |

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Point d’entrée du Worker

```typescript title="worker.ts"
import { Univer } from '@univerjs/core'
import { UniverDocsWorkerPlugin } from '@univerjs/docs/worker'

const univer = new Univer()
univer.registerPlugin(UniverDocsWorkerPlugin)
```

Utilisez un module Worker avec un fichier d'entrée séparé. Gardez les versions du paquet dans le Worker et sur le thread principal identiques. Le rendu et l'interaction utilisateur restent sur le think principal.

[^web-worker]: Un Web Worker exécute JavaScript hors du thread principal du navigateur et communique par messages. Il ne peut pas accéder directement au DOM : déplacer les calculs ne déplace pas l’interface de l’éditeur.
