Docs peut exécuter la mise en page dans un Web Worker avec `UniverDocsLayoutWorkerPlugin`. Enregistrez-le après le plugin Docs principal. `workerFactory` crée un nouveau Worker pour le service de mise en page.

Commencez par [l’installation et les premiers pas](/guides/docs/getting-started/installation). Ces extraits complètent la configuration existante. Enregistrez les plugins avant de créer ou charger du contenu ; modifiez les enregistrements existants sans les dupliquer.

## Thread principal

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Point d’entrée du Worker

```typescript title="worker.ts"
import { startDocsLayoutWorker } from '@univerjs/docs'

startDocsLayoutWorker()
```

Utilisez un Worker de type module et un fichier d’entrée séparé. Alignez les versions des packages des deux côtés. Le rendu et les interactions restent sur le thread principal.
