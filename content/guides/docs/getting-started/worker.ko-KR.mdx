Docs는 `UniverDocsLayoutWorkerPlugin`으로 문서 레이아웃을 Web Worker에서 계산할 수 있습니다. Docs 핵심 플러그인 다음에 등록하고 `workerFactory`로 레이아웃 서비스의 새 Worker를 만드세요.

먼저 [설치 및 기본 사용법](/guides/docs/getting-started/installation)을 완료하세요. 아래 코드는 기존 설정을 확장합니다. 콘텐츠를 만들거나 불러오기 전에 플러그인을 등록하고, 이미 등록한 플러그인은 중복 등록하지 말고 설정을 수정하세요.

## 메인 스레드

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Worker 진입점

```typescript title="worker.ts"
import { startDocsLayoutWorker } from '@univerjs/docs'

startDocsLayoutWorker()
```

모듈 Worker와 별도 진입점 파일을 사용하세요. Worker와 메인 스레드의 패키지 버전을 맞춰야 합니다. 렌더링과 사용자 상호 작용은 메인 스레드에서 처리합니다.
