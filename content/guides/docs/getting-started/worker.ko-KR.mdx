Docs는 `UniverDocsLayoutWorkerPlugin`으로 문서 레이아웃을 Web Worker[^web-worker]에서 계산할 수 있습니다. Docs 핵심 플러그인 다음에 등록하고 `workerFactory`로 레이아웃 서비스의 새 Worker를 만드세요.

먼저 [설치 및 기본 사용법](/guides/docs/getting-started/installation)을 완료하세요. 아래 코드는 기존 설정을 확장합니다. 콘텐츠를 만들거나 불러오기 전에 플러그인을 등록하고, 이미 등록한 플러그인은 중복 등록하지 말고 설정을 수정하세요.

## 메인 스레드

`UniverDocsLayoutWorkerPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `workerFactory` | `() => Worker` |  | 문서 레이아웃을 처리할 Worker를 만듭니다. 필수 콜백입니다. |
| <ConfigKey depth={0}>fontFaces</ConfigKey> | `object[]` |  | 레이아웃 전에 편집기와 Worker에서 글꼴을 불러옵니다. |
| <ConfigKey depth={1}>family</ConfigKey> | `string` |  | 문서 레이아웃에 사용하는 글꼴 이름입니다. |
| <ConfigKey depth={1}>source</ConfigKey> | `string \| ArrayBuffer` |  | 글꼴 바이트 또는 `url(...)` 같은 CSS `FontFace` 소스입니다. |
| <ConfigKey depth={1}>descriptors</ConfigKey> | `FontFaceDescriptors` |  | 굵기와 스타일 등 브라우저 `FontFace` 속성입니다. |
| `requestTimeoutMs` | `number` | `15_000` | Worker 요청이 지정한 밀리초를 넘으면 복구를 시작합니다. |

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Worker 진입점

```typescript title="worker.ts"
import { Univer } from '@univerjs/core'
import { UniverDocsWorkerPlugin } from '@univerjs/docs/worker'

const univer = new Univer()
univer.registerPlugin(UniverDocsWorkerPlugin)
```

모듈 Worker와 별도 진입점 파일을 사용하세요. Worker와 메인 스레드의 패키지 버전을 맞춰야 합니다. 렌더링과 사용자 상호 작용은 메인 스레드에서 처리합니다.

[^web-worker]: Web Worker는 브라우저의 메인 스레드 밖에서 JavaScript를 실행하고 메시지로 통신합니다. 페이지 DOM에 직접 접근할 수 없으며, 계산을 Worker로 옮겨도 편집기 UI가 함께 이동하지는 않습니다.
