Univer Docs는 `UniverDocsLayoutWorkerPlugin`를 등록하여 Web Worker[^web-worker]에서 문서 레이아웃을 실행할 수 있습니다. Docs 핵심 플러그인 후 플러그인을 등록하십시오. `workerFactory`는 레이아웃 서비스에 대한 새로운 작업자를 만듭니다.

아래 스니펫은 [설치 및 기본 사용](/guides/docs/getting-started/installation)에 설명된 설정 확장을 확장합니다. 플러그인은 내용이 생성되거나 로드되기 전에 등록되어야 합니다. 기존 등록을 변경하려면, 동일한 플러그인을 등록 대신 등록을 수정합니다.

## 메인 스레드

`UniverDocsLayoutWorkerPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `workerFactory` | `() => Worker` |  | 문서 레이아웃을 실행하는 노동자를 만듭니다. 필수. |
| <ConfigKey depth={0}>fontFaces</ConfigKey> | `object[]` |  | 편집기에서 지정된 글꼴을로드하고 레이아웃 시작 전에 레이아웃 작업자에서. |
| <ConfigKey depth={1}>family</ConfigKey> | `string` |  | 문서 레이아웃에 사용되는 글꼴 가족 이름. |
| <ConfigKey depth={1}>source</ConfigKey> | `string \| ArrayBuffer` |  | 글꼴 바이트, 또는 `FontFace` 소스와 같은 `url(...)`. |
| <ConfigKey depth={1}>descriptors</ConfigKey> | `FontFaceDescriptors` |  | 굵기와 스타일 등 브라우저 `FontFace` 속성입니다. |
| `requestTimeoutMs` | `number` | `15_000` | 단일 노동자 요청이 이 값보다 더 길게 실행될 때 복구를 시작합니다. 밀리 초. |

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Worker 진입점

```typescript title="worker.ts"
import { Univer } from '@univerjs/core'
import { UniverDocsWorkerPlugin } from '@univerjs/docs/worker'

const univer = new Univer()
univer.registerPlugin(UniverDocsWorkerPlugin)
```

별도의 항목 파일로 모듈 작업기를 사용합니다. 작업자의 패키지 버전을 유지하고 주요 스레드에 동일합니다. 렌더링 및 사용자 상호 작용은 주요 스레드에 남아 있습니다.

[^web-worker]: Web Worker는 브라우저의 메인 스레드 밖에서 JavaScript를 실행하고 메시지로 통신합니다. 페이지 DOM에 직접 접근할 수 없으며, 계산을 Worker로 옮겨도 편집기 UI가 함께 이동하지는 않습니다.
