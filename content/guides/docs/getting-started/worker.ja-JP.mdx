Docs は `UniverDocsLayoutWorkerPlugin` により文書のレイアウト処理を Web Worker[^web-worker] で実行できます。Docs コアプラグインの後に登録し、`workerFactory` でレイアウトサービス用の新しい Worker を作成します。

まず[インストールと基本的な使い方](/guides/docs/getting-started/installation)を完了してください。以下のコードは既存の設定に追加するものです。コンテンツの作成や読み込み前にプラグインを登録し、登録済みのプラグインは重複登録せず設定を変更してください。

## メインスレッド

`UniverDocsLayoutWorkerPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `workerFactory` | `() => Worker` |  | 文書レイアウトを実行する Worker を生成します。このコールバックは必須です。 |
| <ConfigKey depth={0}>fontFaces</ConfigKey> | `object[]` |  | レイアウトの前にエディターと Worker の両方でフォントを読み込みます。 |
| <ConfigKey depth={1}>family</ConfigKey> | `string` |  | 文書のレイアウトに使うフォント名。 |
| <ConfigKey depth={1}>source</ConfigKey> | `string \| ArrayBuffer` |  | フォントデータまたは `url(...)` などの CSS `FontFace` ソース。 |
| <ConfigKey depth={1}>descriptors</ConfigKey> | `FontFaceDescriptors` |  | ウェイトやスタイルなど、ブラウザーの `FontFace` 記述子。 |
| `requestTimeoutMs` | `number` | `15_000` | Worker への 1 回の要求が指定したミリ秒数を超えると復旧を開始します。 |

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Worker のエントリー

```typescript title="worker.ts"
import { Univer } from '@univerjs/core'
import { UniverDocsWorkerPlugin } from '@univerjs/docs/worker'

const univer = new Univer()
univer.registerPlugin(UniverDocsWorkerPlugin)
```

モジュール Worker と専用のエントリーファイルを使用します。Worker とメインスレッドのパッケージバージョンを揃えてください。描画とユーザー操作はメインスレッドで実行されます。

[^web-worker]: Web Worker はブラウザーのメインスレッド外で JavaScript を実行し、メッセージで通信します。ページの DOM には直接アクセスできません。計算を Worker に移しても、エディター UI は移動しません。
