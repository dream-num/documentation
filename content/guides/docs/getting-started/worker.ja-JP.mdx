Univer Docsは、`UniverDocsLayoutWorkerPlugin`を登録することで、Web Worker[^web-worker]でドキュメントレイアウトを実行できます。 Docs コアプラグインの後にプラグインを登録します。 `workerFactory`は、レイアウトサービスの新しいワーカーを作成します。

以下のスニペットは、[インストールと基本的な使い方](/guides/docs/getting-started/installation)で記述されたセットアップを拡張します。 コンテンツが作成またはロードされる前にプラグインを登録する必要があります。 既存の登録を変更するには、同じプラグインを2回登録する代わりに、その登録を変更します。

## メインスレッド

`UniverDocsLayoutWorkerPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `workerFactory` | `() => Worker` |  | ドキュメントのレイアウトを実行するワーカーを作成します。 必須。 |
| <ConfigKey depth={0}>fontFaces</ConfigKey> | `object[]` |  | エディタで指定されたフォントをロードし、レイアウトを開始する前にワーカーをレイアウトします。 |
| <ConfigKey depth={1}>family</ConfigKey> | `string` |  | ドキュメントレイアウトに使用されるフォントファミリー名。 |
| <ConfigKey depth={1}>source</ConfigKey> | `string \| ArrayBuffer` |  | `url(...)`などのCSS `FontFace`ソース |
| <ConfigKey depth={1}>descriptors</ConfigKey> | `FontFaceDescriptors` |  | ウェイトやスタイルなど、ブラウザーの `FontFace` 記述子。 |
| `requestTimeoutMs` | `number` | `15_000` | 1人の労働者の要求がこの値より長く動くとき回復を始めて下さい、ミリ秒で。 |

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Worker のエントリー

```typescript title="worker.ts"
import { Univer } from '@univerjs/core'
import { UniverDocsWorkerPlugin } from '@univerjs/docs/worker'

const univer = new Univer()
univer.registerPlugin(UniverDocsWorkerPlugin)
```

別のエントリファイルでモジュールワーカーを使用してください。 ワーカー内のパッケージバージョンとメインスレッドの同一キーで保持します。 レンダリングとユーザーインタラクションは、メインスレッドに残ります。

[^web-worker]: Web Worker はブラウザーのメインスレッド外で JavaScript を実行し、メッセージで通信します。ページの DOM には直接アクセスできません。計算を Worker に移しても、エディター UI は移動しません。
