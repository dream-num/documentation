Univer Docs 以同一內容引擎提供兩種文件型態。依應用需求選擇版面配置；文字、段落、樣式與快照持久化使用同一套 API。

| 依任務選擇 | 傳統文件 | 現代文件 |
| --- | --- | --- |
| 典型情境 | 報告、合約及需要實體分頁的正式文件。 | 知識頁面、專案簡報及連續流式內容。 |
| 版面配置 | 頁面、節、頁首頁尾與頁面分欄。 | 連續配置、標題摺疊與可編輯的分欄群組。 |
| 版面 API | [Section API](/reference/facade/document-section) | [ColumnGroup API](/reference/facade/document-column-group) |

## 建立文件 [#create-document]

完成[安裝](/guides/docs/getting-started/installation)後，選擇下列一個建立範例。預設／外掛模式決定 Univer 的安裝方式；傳統／現代決定文件版面，兩者是獨立的選擇。各 Univer 套件保持同版；範例使用 1.3.0。

<Tabs items={["傳統文件", "現代文件"]}>
  <Tab>

```typescript
const doc = univerAPI.createDocument({
  id: 'launch-plan-traditional',
  title: 'Launch plan',
  documentStyle: {
    documentFlavor: univerAPI.Enum.DocumentFlavor.TRADITIONAL,
  },
})

const heading = doc.appendParagraph('Launch plan')
heading.setStyle({ namedStyleType: univerAPI.Enum.NamedStyleType.HEADING_1 })
doc.appendParagraph('Status: Draft')
```

  </Tab>
  <Tab>

```typescript
const doc = univerAPI.createDocument({
  id: 'launch-plan-modern',
  title: 'Launch plan',
  documentStyle: {
    documentFlavor: univerAPI.Enum.DocumentFlavor.MODERN,
  },
})

const heading = doc.appendParagraph('Launch plan')
heading.setStyle({ namedStyleType: univerAPI.Enum.NamedStyleType.HEADING_1 })
doc.appendParagraph('Status: Draft')
```

  </Tab>

## 識別文件型態 [#document-flavor]

使用 `getDocumentFlavor()`、`isTraditional()` 與 `isModern()` 識別文件。未明確宣告型態的快照可能為 `UNSPECIFIED`，不能以 `!isModern()` 認定為傳統文件。載入快照時保留已宣告的型態。

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')
console.log(doc.getDocumentFlavor(), doc.isTraditional(), doc.isModern())
```

繼續閱讀 [Docs API](/guides/docs/features/core/docs-api)，了解段落 ID、文字範圍、編輯、樣式與儲存。頁面排版見[傳統文件](/guides/docs/features/traditional)，連續配置見[現代文件](/guides/docs/features/modern)。各項能力仍需註冊對應的功能外掛。
