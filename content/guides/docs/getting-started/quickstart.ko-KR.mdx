Univer Docs는 플러그인으로 구성되며 스냅샷의 문서를 저장하고 명령을 통해 변경되며 Facade API를 통해 정상적으로 구동됩니다. 이 페이지는 이러한 4가지 개념을 설명합니다. 편집기를 실행하려면 [설치 및 기본 사용](/guides/docs/getting-started/installation)로 계속 실행하십시오.

## 기본 개념 [#basic-concepts]

나머지 페이지는이 4 가지 용어를 사용:

- 플러그인
- 스냅샷
- 명령
- Facade API

### 플러그인

플러그인은 Univer의 모든 기능을 제공하며 아키텍처의 가장 작은 건물 블록을 구성합니다. Univer 응용 프로그램은 플러그인 세트로 구성됩니다.

플러그인은 두 가지 역할 중 하나를 수행합니다.

1. 그것은 기능을 구현합니다. `@univerjs/docs-hyper-link`, 예를 들어, 하이퍼 링크 모델과 Univer Docs에 명령을 추가합니다.
2. 기본 기능을 제공합니다. `@univerjs/engine-render`는 렌더링을 제공합니다.

플러그인만 포함하면 애플리케이션이 필요하므로 사용하지 않는 코드가 로드되지 않습니다. 사용 가능한 플러그인이 요구 사항을 커버하지 않을 때, Univer를 확장하는 플러그인을 작성하십시오.

#### 관련 링크

1. [하이퍼링크](/guides/docs/features/hyper-link)는 미리 설정 모드 또는 플러그인 모드에서 Docs 기능을 추가하는 방법을 설명합니다.
2. [Univer 건축](/blog/univer)는 Univer의 내부 구성을 더 자세히 설명합니다.

### 스냅샷

Univer Docs는 [`IDocumentData`](/guides/docs/model/document-data#idocumentdata)로 문서를 저장합니다. 스냅샷은 문서 본체, 문서 레벨 스타일, 헤더 및 영상, 도면, 목록, 테이블 및 플러그인 리소스를 설명합니다.

옵션 `resources` 필드에서 플러그인 리사이드에 의해 정의된 데이터.

<Callout type="warning" title="주 메뉴">
  스냅 샷은 데이터 만 보유합니다. 편집기가 실행되는 동안 문서 상태를 추적하지 않습니다. 스냅 샷으로 현재 상태를 저장하려면 Facade API의 스냅 샷 방법을 호출하십시오.
</Callout>

### 명령

Univer Docs에서, 콘텐츠 또는 형식화 패스로 각 변경 명령을 통해. 이 디자인은 변경 추적, undo, redo, 및 협업 편집 가능한, 그리고 다른 하나와 함께 일관성있는 관련 기능을 유지.

Facade API는 인수를 준비하고 해당 Docs 명령을 실행합니다.

<Callout type="warning" title="주 메뉴">
  **스냅샷을 직접 수정하지 마십시오.** 이러한 쓰기에는 효과가 없으며 레이아웃과 UI를 날짜로 나타낸다. 명령이나 Facade API를 통해 데이터를 변경한다.
</Callout>

### Facade API

사무실 응용 프로그램은 본질적으로 복잡하고, 지원해야 할 아키텍처는 복잡합니다. Facade API는 그 수준에서 작업 할 필요가 제거 : Univer의 첫 번째 파티 플러그인을 감싸고 간단한 항목 포인트를 노출합니다.

Facade API는 여전히 활동적인 발달의 밑에 있습니다. 당신은 질문 또는 필요조건이 있는 경우에, GitHub에 문제점을 엽니다.

그것은 일상적인 일을 위해 suffices를 요약합니다. 복잡한 특징은 여전히 Univer의 건축과 저수준 API의 직접적인 사용의 이해를 요구할지도 모릅니다.

## 프리셋 모드와 플러그인 모드

미리 설정은 이미 구성 된 플러그인의 번들입니다. 두 모드 모두 같은 플러그인을 포함 할 때, 그들은 동일한 기능을 제공합니다. 미리 설정은 설정 작업을 감소; 플러그인 모드는 구성을 나타 내고 응용 프로그램에로드합니다.

<Callout type="warning">
  같은 버전에서 모든 Univer 의존도를 유지하십시오. 미리 설정하면 플러그인이 포함되면 두 번째 시간을 등록하지 마십시오.
</Callout>

| 플러그인 모드 | 프리셋 모드 |
| --- | --- |
| 응용 프로그램은 Facade 확장을 가져옵니다. | 미리 설정은 Facade 확장을 포함합니다 |
| Application controls 플러그인 등록 순서 | preset는 플러그인을 관리합니다. |
| Plugins는 수요에 적재됩니다 | 구성한 프리셋은 초기화 시 로드 |
