Univer Docs의 플러그인, 스냅샷, 명령, Facade API를 알아봅니다. 편집기 생성은 [설치 및 기본 사용](/guides/docs/getting-started/installation)을 참고하세요.

## 기본 개념 [#basic-concepts]

Univer를 더 깊이 알아보기 전에 이 문서를 읽고 Univer의 기본 개념을 이해해 두세요. Univer를 더욱 원활하게 사용하는 데 도움이 됩니다.

기본 개념은 다음과 같습니다.

- 플러그인
- 스냅샷
- 명령
- Facade API

### 플러그인

Univer의 모든 기능은 플러그인으로 제공됩니다. 플러그인은 Univer의 기본 구성 요소이며, 여러 플러그인을 조합하여 하나의 Univer 애플리케이션을 만듭니다.

플러그인의 역할은 다음과 같습니다.

1. 기능 구현. 예를 들어 `@univerjs/docs-hyper-link`는 Univer Docs의 하이퍼링크 모델과 명령을 제공합니다.
2. 기본 기능 제공. 예를 들어 `@univerjs/engine-render`는 렌더링 기능을 제공합니다.

Univer 플러그인을 조합하여 요구 사항에 맞는 Univer 애플리케이션을 구성하고 불필요한 코드가 로드되지 않도록 할 수 있습니다. 또한 플러그인을 직접 작성하여 필요에 맞게 Univer의 기능을 확장할 수도 있습니다.

#### 관련 링크

1. preset 모드 또는 plugin 모드에서 Docs 기능을 추가하는 방법은 [하이퍼링크](/guides/docs/features/hyper-link)를 참고하세요.
2. Univer의 아키텍처 설계를 자세히 알아보려면 [Univer 아키텍처](/blog/univer)를 참고하세요.

### 스냅샷

Univer Docs는 [`IDocumentData`](/guides/docs/model/document-data#idocumentdata)를 스냅샷 형식으로 사용합니다. 문서 본문, 문서 수준 스타일, 머리글과 바닥글, 드로잉, 목록, 표, 플러그인 리소스를 설명합니다.

선택 사항인 `resources` 필드는 플러그인이 정의한 데이터를 저장합니다.

<Callout type="warning" title="주의">
  주의하세요! Univer의 스냅샷은 데이터 저장에만 사용되며 런타임의 최신 문서 상태를 반영하지 않습니다! 문서 상태를
  스냅샷으로 저장하려면 Facade API의 스냅샷 저장 메서드를 사용하세요.
</Callout>

### 명령

Univer Docs에서는 문서 내용과 서식의 변경을 명령을 통해 실행합니다. 이를 통해 변경 사항을 추적하고 실행 취소, 다시 실행, 공동 편집을 구현하며 관련 기능을 조정할 수 있습니다.

Facade API는 내부에서 매개변수를 준비하고 해당 Docs 명령을 실행합니다.

<Callout type="warning" title="주의">
  **스냅샷을 직접 수정하지 마세요!** 변경 사항이 적용되지 않으며 뷰나 UI도 업데이트되지 않습니다. 명령 또는 Facade API를
  통해 데이터를 수정하세요.
</Callout>

### Facade API

오피스 애플리케이션은 매우 복잡하므로 Univer의 아키텍처 역시 매우 복잡합니다. 개발자가 Univer를 더 쉽게 사용할 수 있도록 Univer의 퍼스트 파티 플러그인을 래핑한 Facade API를 제공합니다. Facade API는 개발자가 Univer를 더 쉽게 사용할 수 있도록 간결한 인터페이스를 제공합니다.

Facade API는 계속해서 개선되고 있습니다. 질문이나 요구 사항이 있다면 GitHub에 이슈를 제출해 주세요.

Facade API는 기반 구현의 세부 사항을 추상화한 고수준 API입니다. 일반적인 작업은 간소화해 주지만, 복잡한 기능을 구현할 때는 Univer의 아키텍처를 이해하고 저수준 API를 직접 사용해야 할 수 있습니다.

## 프리셋 모드와 플러그인 모드

프리셋은 미리 구성된 플러그인 묶음입니다. 같은 플러그인을 포함하면 두 모드의 기능은 같습니다. 간단한 설정에는 프리셋을, 구성과 로딩을 직접 제어하려면 플러그인 모드를 사용하세요.

<Callout type="warning">
  모든 Univer 의존성의 버전을 일치시키세요. 프리셋에 포함된 플러그인을 중복 등록하지 마세요.
</Callout>

| 플러그인 모드 | 프리셋 모드 |
| --- | --- |
| Facade 확장을 직접 가져오기 | Facade 확장 포함 |
| 등록 순서를 직접 제어 | 프리셋이 포함된 플러그인을 관리 |
| 필요한 시점에 플러그인 로드 | 구성한 프리셋은 초기화 시 로드 |
