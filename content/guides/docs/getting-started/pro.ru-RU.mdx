Для более сложных сценариев использования Univer предлагает версию Pro. Она обладает расширенными возможностями и подходит для приложений, которым требуется более высокая производительность и дополнительная функциональность.

Разделы документации, относящиеся к Univer SDK Pro, отмечены значком <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} />.

Для некоторых функций Univer SDK Pro требуется интеграция с сервером Univer. Подробности см. в разделе [«Сервер Univer SDK Pro»](/guides/pro/server).

Без лицензии на некоторые функции Univer SDK Pro действуют ограничения:

| Функция | Ограничения без лицензии |
| --- | --- |
| Печать | Водяной знак<br />Не более 1 страницы за одну печать |
| Совместное редактирование | Водяной знак<br />Одновременно можно совместно редактировать не более 5 документов<br />Не более 3 участников на документ |
| Импорт и экспорт DOCX | Водяной знак<br />Размер импортируемого файла — не более 1 МБ |

Информацию о приобретении лицензии Univer SDK Pro см. на [странице покупки Univer SDK Pro](/guides/pro).
