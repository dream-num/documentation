Для более сложных сценариев использования Univer предлагает версию Pro. Она обладает расширенными возможностями и подходит для приложений, которым требуется более высокая производительность и дополнительная функциональность.

Разделы документации, относящиеся к Univer Pro, отмечены значком <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} />.

Для некоторых функций Univer Pro требуется интеграция с сервером Univer. Подробности см. в разделе [«Сервер Univer Pro»](/guides/pro/server).

Без лицензии на некоторые функции Univer Pro действуют ограничения:

| Функция | Ограничения без лицензии |
| --- | --- |
| Печать | Водяной знак<br />Не более 3 страниц за одну печать |
| Совместное редактирование | Водяной знак<br />Одновременно можно совместно редактировать не более 5 документов<br />Не более 3 участников на документ |
| Импорт и экспорт | Водяной знак<br />Размер импортируемого файла — не более 1 МБ<br />В экспортируемом файле — не более 10 тыс. ячеек |

Информацию о приобретении лицензии Univer Pro см. на [странице покупки Univer Pro](/guides/pro).
