title: 透過 CDN 使用 Univer
---

如果你不使用包管理工具，也可以透過 `<script>` 標籤引入 Univer。

## 名稱空間規範

Univer 的全域性構建（UMD）會在全域性物件上暴露一個名稱空間，它們的命名規範如下：

```plain
# 預設
@univerjs/presets -> UniverPresets
@univerjs/preset-docs-core -> UniverPresetDocsCore
@univerjs/preset-docs-core/locales/zh-TW -> UniverPresetDocsCoreZhTW

# 外掛
@univerjs/core -> UniverCore
@univerjs/docs-ui -> UniverDocsUi
@univerjs-pro/docs-print -> UniverProDocsPrint
@univerjs/docs-ui/locale/zh-TW -> UniverDocsUiZhTW
@univerjs/core/facade -> UniverCoreFacade
```

## 預設模式 [#preset-mode]

### 使用全域性構建版本

我們在當前主流的 CDN 服務商（例如 [jsDelivr](https://www.jsdelivr.com)、[unpkg](https://unpkg.com)）都提供了 Univer 的 UMD 構建，你可以在 HTML 檔案中引入這些資源（當然你也可以下載這些檔案然後透過自己的伺服器或者 CDN 網路分發）：

<Callout type="warning" title="注意事項">
  透過 `<script>` 標籤引入 Univer 的 UMD 構建包在使用方式上和使用包管理工具以及構建工具並無太大差異，但需要注意：雖然預設包本質上是外掛的集合，但當你想引入某個特定外掛的物件或方法時，你必須從外掛的名稱空間中獲取，而不是從它們所被包含的預設包的名稱空間中獲取。

  例如，雖然 `@univerjs/core` 被包含在 `@univerjs/presets` 中，但你仍然需要從 `@univerjs/core` 的名稱空間 `UniverCore` 中獲取它們：
</Callout>

#### 示例

```html
<head>
  <script src="https://unpkg.com/react@18.3.1/umd/react.production.min.js"></script>
  <script src="https://unpkg.com/react-dom@18.3.1/umd/react-dom.production.min.js"></script>
  <script src="https://unpkg.com/rxjs/dist/bundles/rxjs.umd.min.js"></script>
  <script src="https://unpkg.com/echarts@5.6.0/dist/echarts.min.js"></script>

  <script src="https://unpkg.com/@univerjs/presets/lib/umd/index.js"></script>

  <script src="https://unpkg.com/@univerjs/preset-docs-core/lib/umd/index.js"></script>
  <script src="https://unpkg.com/@univerjs/preset-docs-core/lib/umd/locales/zh-TW.js"></script>
  <link rel="stylesheet" href="https://unpkg.com/@univerjs/preset-docs-core/lib/index.css" />
  <style>
    html,
    body,
    #root,
    #app {
      padding: 0;
      margin: 0;
      height: 100%;
    }
  </style>
</head>
<body>
  <div id="app"></div>

  <script>
    const { createUniver } = UniverPresets
    const { LocaleType, mergeLocales } = UniverCore
    const { UniverDocsCorePreset } = UniverPresetDocsCore

    const { univerAPI } = createUniver({
      locale: LocaleType.ZH_TW,
      locales: {
        [LocaleType.ZH_TW]: mergeLocales(UniverPresetDocsCoreZhTW),
      },
      presets: [UniverDocsCorePreset()],
    })

    univerAPI.createUniverDoc({})
  </script>
</body>
```

## 外掛模式 [#plugin-mode]

### 使用全域性構建版本

和預設模式一樣 Univer 也為每個外掛都提供了 UMD 包，但與之不同的是，你需要手動引入每個外掛的 UMD 包以及它們的前置依賴包。這個過程非常繁瑣，我們並**不推薦**這種方式。請在完全理解外掛機制（如外掛之間的依賴關係，以及外掛樣式檔案的引入順序）之後再考慮使用。

#### 示例

     * [^2]: [support for React 19] https://github.com/dream-num/univer/pull/4247
     */

    /**
     * Fix `Uncaught TypeError: client.createRoot is not a function`
     * If using UMD React < 18, you might need the following code.
     */
    ;(function (global) {
      'use strict'

        throw new Error('ReactDOM must be loaded before ReactCreateRoot.')

      const ReactDOM = global.ReactDOM
      if (!ReactDOM.createRoot) {
        ReactDOM.createRoot = function (container) {
          return {
            render: (element) => {
              ReactDOM.render(element, container)
            },

    })(this)

    /**
     * Fix `Uncaught TypeError: jsxRuntime.jsx is not a function`
     * If using UMD React, you might need the following code.
     * Reference: https://unpkg.com/react@18.3.1/cjs/react-jsx-runtime.production.min.js
     */
    ;(function (global) {
      'use strict'
      if (!global.React) {
        throw new Error('React must be loaded before ReactJSXRuntime.')
      }
      const React = global.React
      if (!React.jsx || !React.jsxs) {
        const REACT_ELEMENT_TYPE = Symbol.for('react.element')
        const hasOwnProperty = Object.prototype.hasOwnProperty
        const RESERVED_PROPS = {
          key: true,

            key = `${config.key}`

          }
          for (var propName in config) {
            if (hasOwnProperty.call(config, propName) && !RESERVED_PROPS.hasOwnProperty(propName)) {
              props[propName] = config[propName]
            }
          }
          if (type && type.defaultProps) {
            const defaultProps = type.defaultProps

              if (props[propName] === undefined) {
                props[propName] = defaultProps[propName]
              }
            }
          }

## 指定版本

unpkg 和 jsDeliver 都支援指定特定版本的資源。以 unpkg 為例，如果你想使用 `x.y.z` 版本的 Univer，僅需在 URL 中加上 `@<version>` 來指定版本即可：

```diff
- https://unpkg.com/@univerjs/presets/lib/umd/index.js
+ https://unpkg.com/@univerjs/presets@x.y.z/lib/umd/index.js
```
