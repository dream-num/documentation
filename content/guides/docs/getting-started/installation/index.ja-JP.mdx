---
title: インストールと基本的な使い方
---

Univerはプラグインから構築されています。各機能は別々のモジュールとして出荷されますので、同じコアは、非常に異なる種類の電子文書アプリケーションに組み立てることができます。この柔軟性は、コストを運ぶ:最初の使用時に、アプリケーションは、必要なプラグインを決定する必要があります。

Univerは、**プラグインモード**と**プリセットモード**の2つの方法を提供します。 **プリセット** は、既に設定されているプラグインのバンドです。 複雑な拡張機能がなければ、両方のモードは同じ機能を提供します。

<Callout type="warning" title="注意事項">
  - 両方のモードでは、すべての依存関係は同じバージョン番号を使用する必要があります。
  - プリセットにプラグインが含まれている場合は、プラグインを別々にインポートしないでください。 両方を登録すると、期待どおりに動作しないプラグインの競合や機能を引き起こす可能性があります。
</Callout>

2つのモードは次の通りです。

| プラグインモード | プリセットモード |
| --- | --- |
| ファサードのパッケージは手動で輸入されます | ファサードのパッケージはプリセットによって提供されます |
| 同じ種類の機能を提供するプラグインについては、登録注文を管理する必要があります | プリセットは、その機能の登録順を管理します。 |
| プラグインは、要求に応じてレイジーロードすることができます | 初期化時に同期的にロードされるプリセット |

**深いカスタム化か延長** では、プラグインモードを選択し、各プラグインを組み合わせて個別に設定します。プリセットモードは、バンドルが既に組み立てられているため、より高速なスタートを提供します。

## プラグインモードでのセットアップ

Univerはプラグインとして機能を提供します。 一部のコアプラグインは、製品が機能するために必要であり、残りのプラグインは必要なときにのみ追加されます。 以下の例は、プラグインによってプラグインを組み立ててインストールする、最小限のUniver Docsアプリケーションです。

プリセットモードとは異なり、プラグインモードにはデフォルトではFacade API[^facade-entry]は含まれません。以下の例では、Facade APIを使用しており、APIインスタンスを作成する前に、対応するファサードパッケージをインポートします。

### パッケージマネージャーの使用

#### インストール

UniverはReactとインターフェイスをレンダリングし、RxJSでデータストリームを処理します。またVueまたはAngularアプリケーションに埋め込むこともできます。`react`、`react-dom`および`rxjs`のピア依存関係[^peer-dependency]がインストールされていることを確認してください。以下の Yarnコマンドには、明示的に含まれています。

`@univerjs/*`と`@univerjs-pro/*`パッケージは**同じバージョン**を使用する必要があります。

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/engine-formula @univerjs/engine-render @univerjs/ui"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}
/>

#### 使い方

Univerを初期化する前に、コンテナを明示的な高さで作成します。

```html
<div id="app" style="height: 600px"></div>
```

`FUniver.newAPI(univer)` を呼び出す前に、例で使用されるファサードエントリをインポートします。`@univerjs/design`、`@univerjs/ui`の順番でスタイルをロードし、製品CSS。

<Callout type="warning" title="注意事項">
  - すべてのプラグインには、ファサードパッケージ、言語パック、スタイルファイルが含まれます。各機能の状態のドキュメントは、その機能を提供します。
  - スタイルのインポートの順序は、他のプラグインのスタイルの前に`@univerjs/design`と`@univerjs/ui`CSSをロードします。
</Callout>

<Steps>
  <Step>
    まず、Univerのスタイルファイル、言語パック、プラグインをインポートします。

    ```typescript
    import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
    import { FUniver } from '@univerjs/core/facade'
    import DesignJaJP from '@univerjs/design/locale/ja-JP'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIJaJP from '@univerjs/docs-ui/locale/ja-JP'
    import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIJaJP from '@univerjs/ui/locale/ja-JP'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    ```
  </Step>
  <Step>
    次に、例で使われるファサードパッケージをインポートします。

    ```typescript
    import '@univerjs/engine-formula/facade'
    import '@univerjs/ui/facade'
    import '@univerjs/docs/facade'
    import '@univerjs/docs-ui/facade'
    ```
  </Step>
  <Step>
    次に、Univerインスタンスを作成し、これらのプラグインを登録します。

    ```typescript
    const univer = new Univer({
      locale: LocaleType.JA_JP,
      locales: {
        [LocaleType.JA_JP]: mergeLocales(
          DesignJaJP,
          UIJaJP,
          DocsUIJaJP,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverFormulaEnginePlugin)

    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
    })

    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)

    univerAPI.createDocument({})
    ```
  </Step>
</Steps>

#### `univer.registerPlugin` と `univer.registerPlugins` メソッド [#registerPlugin]

`univer.registerPlugin` は、Univerインスタンスに 1 つのプラグインを登録し、インスタンスが作成された後に呼び出される必要があります。

署名は `univer.registerPlugin(Plugin, options)` で、`Plugin`はプラグインで登録して `options`が各プラグインで定義するオプション設定です。

一度に複数のプラグインを登録するには、`univer.registerPlugins` に配列を渡します。プラグインが 1 か所で管理されると便利です。

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  UniverFormulaEnginePlugin,
  [UniverUIPlugin, {
    container: 'app',
  }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
])
```

#### 一部プラグインの遅延読み込み

プラグインモードは、各プラグインの読み込み時間を制御することができます。一般的なアプローチは、アプリケーション起動時に重要なプラグインのみをロードし、最初のレンダーが完了するまで残りのプラグインをデフラグします。

```typescript
// ...

const univerAPI = FUniver.newAPI(univer)

univerAPI.createDocument({})

import('@univerjs/watermark').then(({ UniverWatermarkPlugin }) => {
  univer.registerPlugin(UniverWatermarkPlugin, {
    textWatermarkSettings: {
      content: 'Hello, Univer!',
      fontSize: 36,
    },
  })
})
```

## モバイル対応 [#mobile-support]

<Callout type="warning">
  以下のモバイルプラグインをエクスポートする SDK パッケージが必要です。すべての `@univerjs/*` と `@univerjs-pro/*` の依存関係を**同じバージョン**に揃えてください。

  `1.0.0-rc.0`は`UniverDocsMobileUIPlugin`をエクスポートしません。このモバイルエントリーを含むビルドを使用して、例を実行します。
</Callout>

Univer Docs のタッチコントロールでは、**モバイルUIプラグイン**.[^mobile-ui-mode]エディタが作成される前に UI モードを選択する必要があります。

上記のプラグインモードの例では、**交換する** では、UI のインポートと登録を下回し、`createUnit()`; 既に初期化されているデスクトップエディタに追加しないでください。モデルプラグイン、エンジン、ロケールファイル、CSS、ファサードのインポートは変更されません。デスクトップとモバイルクラスは **同じパッケージエントリ**からエクスポートされます。

`UniverMobileUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターのマウント先となる DOM 要素、またはその ID。 |
| `disableAutoFocus` | `true` | `true` | 起動時にエディターへの自動フォーカスを抑止します。 |

```typescript
import { UniverDocsMobileUIPlugin } from '@univerjs/docs-ui'
import { UniverMobileUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverMobileUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsMobileUIPlugin)
```

`UniverSheetsCorePreset`と`UniverDocsCorePreset`は現在デスクトップUIプラグインを登録し、`mobile: true`オプションを提供していません。 モバイルでは、プラグインは個別に組み立てられなければなりません。デスクトッププリセット後にモバイルプラグインを追加してもUIを交換しません。

### コンテナーとタッチ操作

コンテナに明示的な高さを設定し、ページビューポートを設定します。 `100dvh`は、ダイナミックビューポート高さに従います。 ターゲットモバイルブラウザでは、スクロール、ピンチズーム、テキスト選択、クリップボードアクセス、および画面上のキーボードをテストします。 デスクトップエディタを再設定すると、モバイルプラグインに切り替えません。

`UniverMobileUIPlugin` のデフォルトは `disableAutoFocus: true`、従って編集者は初期化の間に自動的に焦点を合わせません。

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
<div id="app" style="height: 100dvh"></div>
```

## プリセットモードで作成

プリセットモードは、コードの20行未満のUniver Docsアプリケーションを開始します。

### パッケージマネージャーを使う

プロジェクトがすでに現代のフロントエンドツーリングを使用している場合は、Univer を追加するのは簡単です。 Univer アプリケーションをビルドし、ES モジュールをうまくサポートするツールで、[ツイート](https://vitejs.dev/)、[エスビルド](https://esbuild.github.io/)または[ウェブパック 5](https://webpack.js.org/)。 その他のツール、Webpack 4 たとえば、追加の構成が必要な場合があります。

#### インストール

プロジェクトで使用されるパッケージマネージャで`@univerjs/presets`をインストールします。

```package-install
npm install @univerjs/presets @univerjs/preset-docs-core
```

#### 使い方

<Callout type="warning">
  ビルドツールがpackage.json の `exports` フィールドをサポートしていない場合(Webpack 4) では共通です。マップされたパスは、手動で実際のパスに変更する必要があります。
</Callout>

次のコードは、Univer Docs アプリケーションを開始します。

```html title="index.html"
<div id="app" style="height: 600px"></div>
```

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreJaJP from '@univerjs/preset-docs-core/locales/ja-JP'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'

const { univer, univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetDocsCoreJaJP,
    ),
  },
  presets: [
    UniverDocsCorePreset({
      container: 'app',
    }),
  ],
})

univerAPI.createDocument({})
```

`univerAPI`オブジェクトはUniver Facade APIであり、Univerが提供する機能のほとんどはそれを介して呼び出されます。

</Callout>

#### `createUniver` メソッド

`createUniver`は、言語、テーマ、プラグインを含むインスタンスを記述する設定オブジェクトを受け入れます。UniverインスタンスとFacade APIのインスタンスを含むオブジェクトを返します。

最も一般的に使用される特性は次のとおりです。

- `locale`: `LocaleType`の列挙値として言語環境。
- `locales`: 言語パック、言語環境によってキープされる、各値は言語パックオブジェクトです。
- `theme`:オプションのテーマオブジェクト。
- `presets`:`UniverDocsCorePreset`などの登録プリセット。
- `plugins`:プリセットに加えてプラグインを登録します。

`plugins` プロパティを使用して、プリセットパッケージが含まれていないプラグイン、またはアプリケーションによって実装されたプラグイン。プラグインは、Univerインスタンスが取得した後、`univer.registerPlugin`と登録することもできます。

<Callout>
  オプションの完全なセットについては、[APIリファレンス/createUniver](https://docs.univer.ai/reference/methods/create-univer) を参照してください。
</Callout>

## その他のリリース

Univerは、安定的なリリースに加えて、正式にリリースされていない機能への早期アクセスを提供するアルファ/ベータおよびナイトリーチャンネルを公開しています。 より多くの機能は、より多くのリスクも持ち運びます。これらのビルドにはバグ、不完全な機能、または不安定な機能が含まれている場合があります。 可能な限り生産環境でそれらを避けてください。

### Alpha/Beta リリース

Univer開発チームが新しい機能または重要な変更を完了すると、パッケージをアルファまたはベータチャネルにプリリリースすることができます。 下記のコマンドでアルファまたはベータビルドをインストールします。

```package-install
npm install @univerjs/<package-name>@alpha # Alpha バージョン
npm install @univerjs/<package-name>@beta # Beta バージョン
```

[GitHubの問題](https://github.com/dream-num/univer/issues)による開発チームにプレリリースに関する問題とフィードバックが報告できます。これらの早期ビルドに関するフィードバックを歓迎します。

[^facade-entry]: Facade は、登録済みプラグインの機能をアプリケーションから操作する API です。Facade のエントリをインポートすると API メソッドが追加されますが、機能プラグイン自体は登録されません。

[^peer-dependency]: `peerDependencies` は、ホストアプリケーションが互換性のあるバージョンを用意する依存パッケージです。Univer とアプリケーションが React などのライブラリを共有できます。

[^mobile-ui-mode]: モバイル UI プラグインは初期化時にタッチ用の部品とサービスを選択します。端末の自動判定や、ウィンドウサイズ変更による既存インスタンスの切り替えは行いません。モードを変更する場合は文書の状態を保存し、旧インスタンスを破棄してから選択したプラグインで初期化します。
