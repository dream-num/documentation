Univer proporciona una versión Pro para afrontar escenarios de aplicaciones más complejos. La versión Pro incluye más características y capacidades, adecuadas para aplicaciones que requieren mayor rendimiento y más funcionalidades.

Las partes de la documentación relacionadas con Univer SDK Pro estarán marcadas con <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} />.

Algunas características de Univer SDK Pro requieren integración con el servidor Univer. Consulte [Univer SDK Pro Server](/guides/pro/server) para obtener más detalles.

Univer SDK Pro tiene algunas limitaciones en ciertas funciones cuando no tiene licencia:

| Característica | Limitaciones sin licencia |
| --- | --- |
| Printing | Marca de agua<br />No más de 1 página por impresión |
| Edición colaborativa | Marca de agua<br />No se pueden editar de forma colaborativa más de 5 documentos al mismo tiempo<br />No más de 3 colaboradores por documento |
| Importación y exportación de DOCX | Marca de agua<br />Importar archivos de no más de 1 MB |

Para obtener información sobre cómo obtener una licencia de Univer SDK Pro, consulte la [Página de compra de Univer SDK Pro](/guides/pro).
