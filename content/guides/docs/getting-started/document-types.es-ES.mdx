Univer Docs ofrece dos tipos de documentos sobre el mismo motor de contenido. Elige el diseño para tu aplicación; texto, párrafos, estilos y persistencia de instantáneas usan las mismas API.

| Elegir según la tarea | Tradicional | Moderno |
| --- | --- | --- |
| Uso habitual | Informes, contratos y documentos que necesitan páginas físicas. | Páginas de conocimiento, resúmenes de proyectos y contenido continuo. |
| Diseño | Páginas, secciones, encabezados, pies y columnas de página. | Flujo continuo, títulos plegables y grupos de columnas editables. |
| API de diseño | API Section | API ColumnGroup |

## Crear un documento [#create-document]

Tras la [instalación](/guides/docs/getting-started/installation), elige uno de los ejemplos siguientes. El modo preajuste/plugin define la instalación; Tradicional/Moderno define el diseño. Son decisiones independientes. Mantén la misma versión de los paquetes Univer; los ejemplos usan 1.3.0.

<Tabs items={["Documentos tradicionales", "Documentos modernos"]}>
  <Tab>

```typescript
const doc = univerAPI.createDocument({
  id: 'launch-plan-traditional',
  title: 'Launch plan',
  documentStyle: {
    documentFlavor: univerAPI.Enum.DocumentFlavor.TRADITIONAL,
  },
})

const heading = doc.appendParagraph('Launch plan')
heading.setStyle({ namedStyleType: univerAPI.Enum.NamedStyleType.HEADING_1 })
doc.appendParagraph('Status: Draft')
```

  </Tab>
  <Tab>

```typescript
const doc = univerAPI.createDocument({
  id: 'launch-plan-modern',
  title: 'Launch plan',
  documentStyle: {
    documentFlavor: univerAPI.Enum.DocumentFlavor.MODERN,
  },
})

const heading = doc.appendParagraph('Launch plan')
heading.setStyle({ namedStyleType: univerAPI.Enum.NamedStyleType.HEADING_1 })
doc.appendParagraph('Status: Draft')
```

## Identificar el tipo [#document-flavor]

Usa `getDocumentFlavor()`, `isTraditional()` e `isModern()` para identificar el tipo. Una instantánea sin tipo explícito puede ser `UNSPECIFIED`: `!isModern()` no demuestra que sea tradicional. Conserva el tipo declarado al cargar la instantánea.

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')
console.log(doc.getDocumentFlavor(), doc.isTraditional(), doc.isModern())
```
