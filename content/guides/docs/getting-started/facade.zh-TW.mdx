Univer 的架構需要覆蓋複雜需求，因此不易直接使用。Facade API 是在該架構之上提供的更簡單的封裝層。

本文介紹如何將 Facade API 新增到應用中。“功能”章節列出各功能主要的 Facade API；完整列表請參閱提供該 API 的外掛的 API 參考。

<Callout type="warning" title="注意事項">
  部分 Facade API 是非同步的，修改資料的 API 通常返回 Promise。如果需要在修改後立即讀取資料，請使用 await 或 .then() 等待結果，否則結果可能與預期不符。具體哪些 API 返回 Promise，請參閱對應外掛的 API 參考。
</Callout>

## 外掛模式引入 Facade API

### 安裝

以外掛模式安裝 Univer 時，Facade API 的實現分佈在各外掛中，各外掛將自己的實現掛載到全域性的 Facade API 根物件上。對於提供 Facade API 的外掛，按需引入其實現：

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs/ui/facade'
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="注意事項">
  並非所有外掛都包含 facade 包，各功能的文件會說明。
</Callout>

### 使用

Facade API 封裝已有的 Univer 例項，因此需要先建立例項，再透過 `FUniver` 建置 API：

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

### 注意事項

並非所有 Facade API 在呼叫後都會立即生效。部分 API 只在特定的生命週期階段生效。如果呼叫沒有產生效果，請在更靠後的階段執行：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // 在生命週期階段為 Rendered 時執行的程式碼
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // 在生命週期階段為 Steady 時執行的程式碼
  }
})
```
## 預設模式引入 Facade API

在預設模式下，預設會引入其包含功能的 Facade API。建立 Univer 例項時會返回一個對應的 Facade API 例項 `univerAPI`，可直接使用。
