Univer Docs 可以通过注册 `UniverDocsLayoutWorkerPlugin`，将文档排版放到 Web Worker[^web-worker] 中执行。该插件须注册在 Docs 核心插件之后。它接收的 `workerFactory` 负责为排版服务创建新的 Worker。

下面的代码是对[安装和基本使用](/guides/docs/getting-started/installation)中配置的扩展。插件必须在创建或加载内容之前注册；如需修改已注册的插件，应修改原有注册，而不是重复注册同一个插件。

## 主线程

`UniverDocsLayoutWorkerPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `workerFactory` | `() => Worker` |  | 创建负责文档排版的 Worker。该回调为必填项。 |
| <ConfigKey depth={0}>fontFaces</ConfigKey> | `object[]` |  | 在排版开始前，将指定的字体加载到编辑器和排版 Worker 中。 |
| <ConfigKey depth={1}>family</ConfigKey> | `string` |  | 用于文档排版的字体名称。 |
| <ConfigKey depth={1}>source</ConfigKey> | `string \| ArrayBuffer` |  | 字体字节，或 CSS `FontFace` 的 source，例如 `url(...)`。 |
| <ConfigKey depth={1}>descriptors</ConfigKey> | `FontFaceDescriptors` |  | 字重、样式等浏览器 `FontFace` 描述符。 |
| `requestTimeoutMs` | `number` | `15_000` | 单次 Worker 请求耗时超过该值（毫秒）时，开始执行恢复。 |

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Worker 入口

```typescript title="worker.ts"
import { Univer } from '@univerjs/core'
import { UniverDocsWorkerPlugin } from '@univerjs/docs/worker'

const univer = new Univer()
univer.registerPlugin(UniverDocsWorkerPlugin)
```

使用 module 类型的 Worker，并为其提供单独的入口文件。Worker 与主线程的包版本必须保持一致。渲染和用户交互仍留在主线程。

[^web-worker]: Web Worker 在浏览器主线程之外执行 JavaScript，通过消息与主线程通信，不能直接访问页面 DOM。把计算放入 Worker 并不意味着把编辑器界面也迁入其中。
