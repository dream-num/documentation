Docs 可以通过 `UniverDocsLayoutWorkerPlugin` 将文档排版放到 Web Worker[^web-worker] 中执行。在 Docs 核心插件之后注册它，使用 `workerFactory` 为排版服务创建新的 Worker。

先完成[安装和基本使用](/guides/docs/getting-started/installation)。以下代码用于扩展已有配置。请在创建或加载内容之前注册插件；已有的插件注册应直接修改，不要重复注册。

## 主线程

`UniverDocsLayoutWorkerPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `workerFactory` | `() => Worker` |  | 创建负责文档排版的 Worker。必须提供此回调。 |
| <ConfigKey depth={0}>fontFaces</ConfigKey> | `object[]` |  | 排版前在编辑器和 Worker 中加载这些字体。 |
| <ConfigKey depth={1}>family</ConfigKey> | `string` |  | 文档排版使用的字体名称。 |
| <ConfigKey depth={1}>source</ConfigKey> | `string \| ArrayBuffer` |  | 字体字节或 CSS `FontFace` 来源，例如 `url(...)`。 |
| <ConfigKey depth={1}>descriptors</ConfigKey> | `FontFaceDescriptors` |  | 浏览器 `FontFace` 的字重、样式等属性。 |
| `requestTimeoutMs` | `number` | `15_000` | 单次 Worker 请求超过此时长后开始恢复，单位为毫秒。 |

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Worker 入口

```typescript title="worker.ts"
import { Univer } from '@univerjs/core'
import { UniverDocsWorkerPlugin } from '@univerjs/docs/worker'

const univer = new Univer()
univer.registerPlugin(UniverDocsWorkerPlugin)
```

使用模块类型的 Worker 和独立入口文件。Worker 与主线程的包版本需要一致，渲染和用户交互仍在主线程执行。

[^web-worker]: Web Worker 在浏览器主线程之外执行 JavaScript，通过消息与主线程通信，不能直接访问页面 DOM。把计算放入 Worker 并不意味着把编辑器界面也迁入其中。
