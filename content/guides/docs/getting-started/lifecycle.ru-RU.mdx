## Глобальный жизненный цикл

- **Начинать**: Univer является инициализацией, и бизнес-единицы пока не существует.
- **Готовы**: Создано первое бизнес-подразделение. Созданные позднее подразделения не запускают этот этап снова.
- **отданный**: Стандартный пользовательский интерфейс завершил свой первый переключатель рендеринга. Асинхронный контент все еще может загружаться.
- **стойкий**: Стандартный пользовательский интерфейс достигает этой стадии после задержки, которая следует за Rendered. Он не ждет завершения всех асинхронных задач.

### Facade API

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="Что сообщает событие">

`LifeCycleChanged` сообщает о глобальном этапе Univer. Если плагин B загружается после глобального `Ready`, например, B по-прежнему работает под управлением `onReady()` , но второе глобальное событие `Ready` не испускается.

Слушатель, добавленный в любое время, может немедленно открыть огонь по текущей стадии, включая `Starting`. Для определения текущей стадии звоните `univerAPI.getCurrentLifecycleStage()` напрямую.

</Callout>

Чтобы удалить слушателя, используйте объект `disposable`, возвращенный по вызову:

```typescript
disposable.dispose()
```

## Хуки жизненного цикла плагинов

Плагин запускает `onStarting()`, когда он загружается, а затем переходит на глобальную стадию, в которой находится Univer. Демо ниже изменяется, когда B загружается, и показывает, как его крючковые вызовы сравниваются с A.

<LifecycleDemo />

Общие плагины загружаются при регистрации. Плагины бизнес-типа обычно загружаются до создания первого блока этого типа. Новый плагин для типа, который уже начал загружаться позже, в отложенной партии. Явные зависимости могут загружать его раньше.

Крючки работают синхронно внутри партии, шаг за шагом и в порядке зависимости. Ничто не ждет асинхронной работы внутри крючка. Подтвердите, что блок, DOM-элемент или ресурс фактически готовы перед доступом к нему.
