Univer Docs puede ejecutar el diseño de documentos en un Web Worker[^web-worker] mediante el registro de `UniverDocsLayoutWorkerPlugin`. Registra el plugin después del plugin de núcleo de Docs. El `workerFactory` acepta crea un nuevo Worker para el servicio de diseño.

Los snippets a continuación extienden la configuración descrita en [instalación y uso básico](/guides/docs/getting-started/installation). Los plugins deben ser registrados antes de que se cree o cargue el contenido. Para cambiar un registro existente, modifique ese registro en lugar de registrar el mismo plugin dos veces.

## Hilo principal

`UniverDocsLayoutWorkerPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `workerFactory` | `() => Worker` |  | Crea el Trabajador que ejecuta la distribución de documentos. |
| <ConfigKey depth={0}>fontFaces</ConfigKey> | `object[]` |  | Carga las fuentes especificadas en el editor y en el diseño Worker antes de que comience el diseño. |
| <ConfigKey depth={1}>family</ConfigKey> | `string` |  | Nombre de la familia de fuentes utilizado para la distribución de documentos. |
| <ConfigKey depth={1}>source</ConfigKey> | `string \| ArrayBuffer` |  | Bytes de fuentes, o una fuente CSS `FontFace` como `url(...)`. |
| <ConfigKey depth={1}>descriptors</ConfigKey> | `FontFaceDescriptors` |  | Descriptores `FontFace` del navegador, como peso y estilo. |
| `requestTimeoutMs` | `number` | `15_000` | Comienza la recuperación cuando una sola solicitud de Worker funciona más tiempo que este valor, en milisegundos. |

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Entrada del Worker

```typescript title="worker.ts"
import { Univer } from '@univerjs/core'
import { UniverDocsWorkerPlugin } from '@univerjs/docs/worker'

const univer = new Univer()
univer.registerPlugin(UniverDocsWorkerPlugin)
```

Utilice un módulo Trabajador con un archivo de entrada independiente. Mantenga las versiones del paquete en el Worker y en el hilo principal idéntico. Rendering e interacción del usuario permanecen en el hilo central.

[^web-worker]: Un Web Worker ejecuta JavaScript fuera del hilo principal del navegador y se comunica mediante mensajes. No puede acceder directamente al DOM; mover los cálculos no mueve la interfaz del editor.
