Docs puede calcular la maquetación en un Web Worker[^web-worker] con `UniverDocsLayoutWorkerPlugin`. Regístralo después del plugin principal de Docs. `workerFactory` crea un nuevo Worker para el servicio de maquetación.

Completa primero la [instalación y el uso básico](/guides/docs/getting-started/installation). Estos fragmentos amplían la configuración existente. Registra los plugins antes de crear o cargar contenido; modifica los registros existentes sin duplicarlos.

## Hilo principal

`UniverDocsLayoutWorkerPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `workerFactory` | `() => Worker` |  | Crea el Worker que compone el documento. Esta función es obligatoria. |
| <ConfigKey depth={0}>fontFaces</ConfigKey> | `object[]` |  | Carga las fuentes en el editor y en el Worker antes de componer el documento. |
| <ConfigKey depth={1}>family</ConfigKey> | `string` |  | Nombre de la fuente para componer el documento. |
| <ConfigKey depth={1}>source</ConfigKey> | `string \| ArrayBuffer` |  | Bytes de la fuente o un origen CSS `FontFace` como `url(...)`. |
| <ConfigKey depth={1}>descriptors</ConfigKey> | `FontFaceDescriptors` |  | Descriptores `FontFace` del navegador, como peso y estilo. |
| `requestTimeoutMs` | `number` | `15_000` | Inicia la recuperación si una solicitud al Worker supera este plazo en milisegundos. |

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Entrada del Worker

```typescript title="worker.ts"
import { Univer } from '@univerjs/core'
import { UniverDocsWorkerPlugin } from '@univerjs/docs/worker'

const univer = new Univer()
univer.registerPlugin(UniverDocsWorkerPlugin)
```

Usa un Worker de tipo módulo y un archivo de entrada independiente. Mantén iguales las versiones de los paquetes en ambos lados. El renderizado y la interacción permanecen en el hilo principal.

[^web-worker]: Un Web Worker ejecuta JavaScript fuera del hilo principal del navegador y se comunica mediante mensajes. No puede acceder directamente al DOM; mover los cálculos no mueve la interfaz del editor.
