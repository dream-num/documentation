L'architecture de Univer est conçue pour couvrir des exigences complexes, ce qui rend l'utilisation directe difficile. Le Facade API fournit une couche plus simple en plus.

Cette page décrit comment ajouter le Facade API à votre application. La section Caractéristiques énumère le principal Facade API pour chaque fonction. Pour la liste complète, voir la référence API du plugin qui le fournit.

<Callout type="warning" title="Attention">
  Certaines API Facade sont asynchrones, en particulier les API qui modifient les données, qui renvoient généralement une Promise. Si vous devez lire les données immédiatement après une modification, `await` l'appel ou la chaîne `.then()`. Sinon, le résultat peut être inattendu. Pour déterminer quelles API renvoient une Promise, consultez la référence API du plugin correspondant.
</Callout>

## Intégrer la Facade API en mode plug-in

### Installation

Lorsque Univer est installé en mode plugin, chaque plugin contient sa propre partie de l'implémentation Facade API, et ces parties se fixent à un objet racine global Facade API. Pour les plugins qui fournissent Facade API importer l'implémentation correspondante au besoin:

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs/ui/facade'
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="Attention">
  Chaque plugin n'inclut pas un paquet façade. La documentation de chaque fonctionnalité indique si elle le fait.
</Callout>

### Utilisation

Le Facade API enveloppe une instance existante de Univer. Créez d'abord l'instance, puis créez l'API à partir de celle-ci :

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

### Points d’attention

Tous les Facade API ne prennent pas effet dès qu'il est appelé. Certains ne fonctionnent qu'à un stade particulier du cycle de vie. Si un appel n'a pas d'effet, exécutez-le à un stade ultérieur:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Code to be executed when the lifecycle stage is Rendered
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Code to be executed when the lifecycle stage is Steady
  }
})
```
## Intégration de Facade API en mode préréglage

En mode préréglé, le préréglé importe le Facade API pour les fonctionnalités qu'il inclut. Créer une instance Univer renvoie une instance Facade API correspondante, `univerAPI`, qui peut être utilisée directement.
