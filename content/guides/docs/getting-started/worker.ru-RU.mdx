Univer Docs может запускать макет документов в Web Worker[^web-worker] путем регистрации `UniverDocsLayoutWorkerPlugin`. Зарегистрируйте плагин после основного плагина Docs. `workerFactory`, который он принимает, создает нового Работника для службы макета.

Приведенные ниже фрагменты расширяют настройку, описанную в [Установка и базовое использование](/guides/docs/getting-started/installation). Плагины должны быть зарегистрированы до создания или загрузки контента. Чтобы изменить существующую регистрацию, измените эту регистрацию вместо того, чтобы дважды зарегистрировать один и тот же плагин.

## Основной поток

`UniverDocsLayoutWorkerPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `workerFactory` | `() => Worker` |  | Создает Рабочего, который запускает макет документа. |
| <ConfigKey depth={0}>fontFaces</ConfigKey> | `object[]` |  | Загружает указанные шрифты в редакторе и в макете Рабочий до начала макета. |
| <ConfigKey depth={1}>family</ConfigKey> | `string` |  | Шрифтовое имя семьи, используемое для макета документа. |
| <ConfigKey depth={1}>source</ConfigKey> | `string \| ArrayBuffer` |  | байты шрифта или источник CSS `FontFace`, такой как `url(...)`. |
| <ConfigKey depth={1}>descriptors</ConfigKey> | `FontFaceDescriptors` |  | Дескрипторы `FontFace` браузера, включая насыщенность и стиль. |
| `requestTimeoutMs` | `number` | `15_000` | Начинается восстановление, когда один запрос Рабочего длится дольше, чем это значение, в миллисекундах. |

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Точка входа Worker

```typescript title="worker.ts"
import { Univer } from '@univerjs/core'
import { UniverDocsWorkerPlugin } from '@univerjs/docs/worker'

const univer = new Univer()
univer.registerPlugin(UniverDocsWorkerPlugin)
```

Используйте модуль Worker с отдельным файлом ввода. Сохраняйте версии пакетов в Worker и на основном потоке идентичными. Рендеринг и взаимодействие пользователей остаются на главном потоке.

[^web-worker]: Web Worker выполняет JavaScript вне главного потока браузера и обменивается с ним сообщениями. Прямого доступа к DOM нет: перенос вычислений не переносит интерфейс редактора.
