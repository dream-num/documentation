Docs может выполнять компоновку документа в Web Worker[^web-worker] через `UniverDocsLayoutWorkerPlugin`. Зарегистрируйте его после основного плагина Docs. `workerFactory` создаёт новый Worker для службы компоновки.

Сначала выполните [установку и базовую настройку](/guides/docs/getting-started/installation). Эти фрагменты дополняют существующую конфигурацию. Регистрируйте плагины до создания или загрузки содержимого; изменяйте уже имеющуюся регистрацию без дублирования.

## Основной поток

`UniverDocsLayoutWorkerPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `workerFactory` | `() => Worker` |  | Создаёт Worker для разметки документа. Функция обязательна. |
| <ConfigKey depth={0}>fontFaces</ConfigKey> | `object[]` |  | Загружает шрифты в редакторе и Worker до разметки. |
| <ConfigKey depth={1}>family</ConfigKey> | `string` |  | Имя шрифта для разметки документа. |
| <ConfigKey depth={1}>source</ConfigKey> | `string \| ArrayBuffer` |  | Байты шрифта или источник CSS `FontFace`, например `url(...)`. |
| <ConfigKey depth={1}>descriptors</ConfigKey> | `FontFaceDescriptors` |  | Дескрипторы `FontFace` браузера, включая насыщенность и стиль. |
| `requestTimeoutMs` | `number` | `15_000` | Запускает восстановление, если запрос к Worker занимает больше указанного числа миллисекунд. |

```typescript title="main.ts"
import { UniverDocsLayoutWorkerPlugin } from '@univerjs/docs'

univer.registerPlugin(UniverDocsLayoutWorkerPlugin, {
  workerFactory: () => new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Точка входа Worker

```typescript title="worker.ts"
import { Univer } from '@univerjs/core'
import { UniverDocsWorkerPlugin } from '@univerjs/docs/worker'

const univer = new Univer()
univer.registerPlugin(UniverDocsWorkerPlugin)
```

Используйте модульный Worker и отдельный файл точки входа. Версии пакетов в обоих потоках должны совпадать. Отрисовка и взаимодействие с пользователем остаются в основном потоке.

[^web-worker]: Web Worker выполняет JavaScript вне главного потока браузера и обменивается с ним сообщениями. Прямого доступа к DOM нет: перенос вычислений не переносит интерфейс редактора.
