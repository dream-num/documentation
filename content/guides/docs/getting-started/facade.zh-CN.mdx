Univer 的架构需要覆盖复杂需求，因此不易直接使用。Facade API 是在该架构之上提供的更简单的封装层。

本文介绍如何将 Facade API 添加到应用中。“功能”章节列出各功能主要的 Facade API；完整列表请参阅提供该 API 的插件的 API 参考。

<Callout type="warning" title="注意事项">
  部分 Facade API 是异步的，修改数据的 API 通常返回 Promise。如果需要在修改后立即读取数据，请使用 await 或 .then() 等待结果，否则结果可能与预期不符。具体哪些 API 返回 Promise，请参阅对应插件的 API 参考。
</Callout>

## 插件模式引入 Facade API

### 安装

以插件模式安装 Univer 时，Facade API 的实现分布在各插件中，各插件将自己的实现挂载到全局的 Facade API 根对象上。对于提供 Facade API 的插件，按需引入其实现：

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs/ui/facade'
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="注意事项">
  并非所有插件都包含 facade 包，各功能的文档会说明。
</Callout>

### 使用

Facade API 封装已有的 Univer 实例，因此需要先创建实例，再通过 `FUniver` 构建 API：

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

### 注意事项

并非所有 Facade API 在调用后都会立即生效。部分 API 只在特定的生命周期阶段生效。如果调用没有产生效果，请在更靠后的阶段执行：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // 在生命周期阶段为 Rendered 时执行的代码
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // 在生命周期阶段为 Steady 时执行的代码
  }
})
```
## 预设模式引入 Facade API

在预设模式下，预设会引入其包含功能的 Facade API。创建 Univer 实例时会返回一个对应的 Facade API 实例 `univerAPI`，可直接使用。
