La arquitectura de Univer está diseñada para cubrir requisitos complejos, lo que hace difícil de usar directamente. El Facade API proporciona una capa más simple encima de ella.

Esta página describe cómo agregar el Facade API a su aplicación. La sección Características enumera el Facade API principal para cada característica. Para la lista completa, vea la referencia API del plugin que lo proporciona.

<Callout type="warning" title="Precaución">
  Algunas API de Facade son asincrónicas, especialmente las API que modifican los datos, que generalmente devuelven una promesa. Si necesita leer los datos inmediatamente después de un cambio, `await` la llamada o cadena `.then()`. De lo contrario, el resultado puede ser inesperado. Para determinar qué API devuelve una promesa, vea la referencia de API del plugin correspondiente.
</Callout>

## Integración de Facade API en modo complemento

### Instalación

Cuando Univer se instala en modo plugin, cada plugin contiene su propia parte de la implementación Facade API, y esas partes se adhieren a un objeto raíz Facade API global. Para plugins que proporcionan Facade API importan la implementación correspondiente según sea necesario:

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs/ui/facade'
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="Precaución">
  No todos los plugins incluyen un paquete de fachada. La documentación de cada función indica si lo hace.
</Callout>

### Uso

El Facade API envuelve una instancia Univer existente. Crea la instancia primero, luego construye la API de ella:

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

### Precauciones

No todos los Facade API tienen efecto tan pronto como se llama. Algunos sólo trabajan en una etapa de ciclo de vida particular. Si una llamada no tiene efecto, ejecute en una etapa posterior:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Code to be executed when the lifecycle stage is Rendered
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Code to be executed when the lifecycle stage is Steady
  }
})
```
## Integración de Facade API en modo preestablecido

En modo preestablecido, el preset importa el Facade API para las características que incluye. Creando una instancia Univer devuelve una instancia de Facade API, `univerAPI` que se puede utilizar directamente.
