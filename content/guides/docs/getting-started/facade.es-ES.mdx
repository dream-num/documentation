Para cumplir con requisitos complejos, la arquitectura de Univer también es bastante compleja, lo que puede causar algunas dificultades de uso. Para abordar esto, proporcionamos una API de Facade más simple y fácil de usar.

Este capítulo mostrará en detalle cómo agregar la API de Facade a su aplicación. En el siguiente capítulo "Características", enumeraremos la API de Facade principal de cada característica. Si desea ver todas las API de Facade, consulte la referencia de API de cada complemento.

<Callout type="warning" title="Cuation">
Algunas API de Facade son asincrónicas, especialmente aquellas que modifican datos, que a menudo devuelven una Promesa. Si necesita recuperar datos inmediatamente después de modificarlos, utilice `await` o `.then()`; de lo contrario, puede obtener resultados inesperados. Para saber qué API específicas devuelven promesas, consulte el manual de referencia de API correspondiente.
</Callout>

## Integración de Facade API en modo preestablecido

Si integra Univer con el modo preestablecido, importará automáticamente la API de Facade para las funciones incluidas y devolverá una instancia de API de Facade correspondiente `univerAPI` cuando cree una instancia de Univer. Puede usarlo directamente.

## Integración de Facade API en modo complemento

### Instalación

Para integrar Facade API en el caso de instalar Univer a través del modo complemento, la implementación de Facade API se distribuye en varios complementos y se monta en el objeto raíz global de Facade API. Esto significa que para aquellos complementos que proporcionan Facade API, puede importar sus implementaciones de Facade API correspondientes según sea necesario.

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs/ui/facade'
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="Cuation">
No todos los complementos incluyen un paquete de fachada; especificaremos esto en la documentación de cada característica.
</Callout>

### Uso

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

### Precauciones

No todas las API de Facade se pueden llamar inmediatamente; Algunas API deben usarse en etapas específicas del ciclo de vida. Si tiene problemas con la ejecución inmediata, consulte el siguiente método para elegir la etapa del ciclo de vida adecuada para la ejecución:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // Code to be executed when the lifecycle stage is Rendered
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // Code to be executed when the lifecycle stage is Steady
  }
})
```
