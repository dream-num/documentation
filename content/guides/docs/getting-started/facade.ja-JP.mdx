Univerのアーキテクチャは、複雑な要件をカバーするように設計されており、直接使用することは困難です。 Facade APIは、よりシンプルなレイヤーを提供します。

このページでは、Facade API をアプリケーションに追加する方法について説明します。 機能セクションでは、各機能のメインの Facade APIを一覧表示しています。 完全なリストについては、そのプラグインの API リファレンスを参照してください。

<Callout type="warning" title="キューション">
  一部のファサード API は非同期で、特にデータを変更する API です。通常、プロミスを返すものです。変更直後にデータを読む必要がある場合は、`await` 呼び出しまたはチェーン `.then()`。それ以外の場合、結果は予期しない可能性があります。どの API が Promise を返すかを判断するには、対応するプラグインの API リファレンスを参照してください。
</Callout>

## プラグインモードで Facade API を使う

### インストール

Univer がプラグインモードでインストールされると、各プラグインには Facade API実装の独自の部分が含まれており、これらの部分はグローバル Facade APIroot オブジェクトに添付されます。 Facade APIを提供するプラグインについては、必要に応じて対応する実装をインポートします。

```typescript
import { FUniver } from '@univerjs/core/facade'

import '@univerjs/ui/facade'
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

<Callout type="warning" title="キューション">
  すべてのプラグインにはファサードパッケージが含まれているわけではありません。各機能のドキュメントは、それが実行するかどうかを記述します。
</Callout>

### 使い方

Facade API は、既存の Univerインスタンスをラップします。最初にインスタンスを作成し、そこから API をビルドします。

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

### 注意事項

Facade APIは、呼び出されるとすぐに効果が出るわけではありません。特定のライフサイクルステージでしか動作しません。コールが効果がない場合、後段で実行してください。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  if (stage === univerAPI.Enum.LifecycleStages.Rendered) {
    // ライフサイクルが Rendered のときに実行
  }
  if (stage === univerAPI.Enum.LifecycleStages.Steady) {
    // ライフサイクルが Steady のときに実行
  }
})
```
## プリセットモードで Facade API を使う

プリセットモードでは、プリセットは、Facade API をインポートします。Univerインスタンスを作成すると、Facade APIのインスタンスをマッチングし、直接使用できる `univerAPI`を返します。
