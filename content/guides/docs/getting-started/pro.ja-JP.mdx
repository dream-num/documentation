Univer はより複雑なユースケースに対応するため、Univer Pro を提供しています。Pro 版には高性能・高機能が含まれ、より高度な要件に適しています。

ドキュメント内で Univer Pro に関連する内容は <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} /> で示しています。

Univer Pro の一部機能は Univer サーバーと連携して利用します。詳細は [Univer Pro サーバー](/guides/pro/server) を参照してください。

ライセンス未取得の場合、Univer Pro の一部機能は制限されます。

| 機能 | 未認証時の制限 |
| --- | --- |
| 印刷 | 透かし<br />1 回の印刷は最大 3 ページ |
| 共同編集 | 透かし<br />同時に共同編集できるドキュメント数は最大 5<br />1 ドキュメントの共同編集者は最大 3 人 |
| インポート & エクスポート | 透かし<br />インポートは 1MB まで<br />エクスポートは最大 10k セル |

Univer Pro のライセンスについては [Univer Pro 購入ページ](/guides/pro) を参照してください。
