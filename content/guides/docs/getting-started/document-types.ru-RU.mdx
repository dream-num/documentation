Univer Docs предоставляет два типа документов на общем движке содержимого. Выберите макет для приложения; текст, абзацы, стили и сохранение снимков используют одни и те же API.

| Выбор по задаче | Традиционный | Современный |
| --- | --- | --- |
| Назначение | Отчёты, договоры и документы с физическими страницами. | Базы знаний, проектные заметки и непрерывное содержимое. |
| Макет | Страницы, разделы, колонтитулы и колонки страницы. | Непрерывный поток, сворачивание заголовков и редактируемые группы колонок. |
| API макета | [Section API](/reference/facade/document-section) | [ColumnGroup API](/reference/facade/document-column-group) |

## Создание документа [#create-document]

После [установки](/guides/docs/getting-started/installation) выберите один из примеров создания. Режим пресетов/плагинов определяет способ установки, а Traditional/Modern — макет. Это независимые решения. Используйте одинаковые версии пакетов Univer; примеры рассчитаны на 1.3.0.

<Tabs items={["Традиционные документы", "Современные документы"]}>
  <Tab>

```typescript
const doc = univerAPI.createDocument({
  id: 'launch-plan-traditional',
  title: 'Launch plan',
  documentStyle: {
    documentFlavor: univerAPI.Enum.DocumentFlavor.TRADITIONAL,
  },
})

const heading = doc.appendParagraph('Launch plan')
heading.setStyle({ namedStyleType: univerAPI.Enum.NamedStyleType.HEADING_1 })
doc.appendParagraph('Status: Draft')
```

  </Tab>
  <Tab>

```typescript
const doc = univerAPI.createDocument({
  id: 'launch-plan-modern',
  title: 'Launch plan',
  documentStyle: {
    documentFlavor: univerAPI.Enum.DocumentFlavor.MODERN,
  },
})

const heading = doc.appendParagraph('Launch plan')
heading.setStyle({ namedStyleType: univerAPI.Enum.NamedStyleType.HEADING_1 })
doc.appendParagraph('Status: Draft')
```

  </Tab>

## Определение типа [#document-flavor]

Определяйте тип через `getDocumentFlavor()`, `isTraditional()` и `isModern()`. Снимок без явного типа может иметь значение `UNSPECIFIED`: `!isModern()` не означает Traditional. При загрузке сохраняйте объявленный тип.

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')
console.log(doc.getDocumentFlavor(), doc.isTraditional(), doc.isModern())
```

## Общие операции [#shared-content]

ID абзацев, текстовые диапазоны, редактирование, стили и сохранение описаны в [Docs API](/guides/docs/features/core/docs-api). Макеты рассматриваются в руководствах по [традиционным](/guides/docs/features/traditional) и [современным](/guides/docs/features/modern) документам. Для каждой возможности нужны соответствующие плагины.
