Univer Docs は同じコンテンツエンジン上で 2 種類のドキュメントを提供します。用途に応じてレイアウトを選択します。テキスト、段落、スタイル、スナップショットの保存には共通の API を使います。

| 用途で選ぶ | 従来型 | モダン |
| --- | --- | --- |
| 主な用途 | レポート、契約書など、物理的なページが必要な文書。 | ナレッジページ、プロジェクト概要、連続するコンテンツ。 |
| レイアウト | ページ、セクション、ヘッダー、フッター、ページ内の段組み。 | 連続レイアウト、見出しの折りたたみ、編集可能な段組みグループ。 |
| レイアウト API | [Section API](/reference/facade/document-section) | [ColumnGroup API](/reference/facade/document-column-group) |

## ドキュメントの作成 [#create-document]

[インストール](/guides/docs/getting-started/installation)後、以下の作成例から 1 つ選びます。プリセット／プラグインモードは導入方法、従来型／モダンは文書レイアウトを指定する独立した選択です。Univer パッケージのバージョンを統一してください。例は 1.3.0 を使用します。

<Tabs items={["従来型ドキュメント", "モダンドキュメント"]}>
  <Tab>

```typescript
const doc = univerAPI.createDocument({
  id: 'launch-plan-traditional',
  title: 'Launch plan',
  documentStyle: {
    documentFlavor: univerAPI.Enum.DocumentFlavor.TRADITIONAL,
  },
})

const heading = doc.appendParagraph('Launch plan')
heading.setStyle({ namedStyleType: univerAPI.Enum.NamedStyleType.HEADING_1 })
doc.appendParagraph('Status: Draft')
```

  </Tab>
  <Tab>

```typescript
const doc = univerAPI.createDocument({
  id: 'launch-plan-modern',
  title: 'Launch plan',
  documentStyle: {
    documentFlavor: univerAPI.Enum.DocumentFlavor.MODERN,
  },
})

const heading = doc.appendParagraph('Launch plan')
heading.setStyle({ namedStyleType: univerAPI.Enum.NamedStyleType.HEADING_1 })
doc.appendParagraph('Status: Draft')
```

  </Tab>
</Tabs>

## 種類の判定 [#document-flavor]

`getDocumentFlavor()`、`isTraditional()`、`isModern()` で種類を判定します。種類のないスナップショットは `UNSPECIFIED` の場合があります。`!isModern()` だけでは従来型と判定できません。読み込み時には宣言された種類を保持してください。

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')
console.log(doc.getDocumentFlavor(), doc.isTraditional(), doc.isModern())
```

## 共通のコンテンツ操作 [#shared-content]

段落 ID、テキスト範囲、編集、スタイル、保存は [Docs API](/guides/docs/features/core/docs-api) を参照してください。ページレイアウトは[従来型](/guides/docs/features/traditional)、連続レイアウトは[モダン](/guides/docs/features/modern)で説明します。各機能には対応するプラグインが必要です。
