Headless Univer는 Univer의 첨부 편집기 UI없이 콘텐츠 실행 시간입니다. 브라우저 편집기로 동일한 콘텐츠 모델, 명령, 계산 및 Facade API를 사용합니다. Node.js에서 콘텐츠를 처리하거나 UI가 필요없는 작업을 위한 브라우저에서 실행할 수 있습니다. 사용 가능한 기능은 제품 및 기능 플러그인이 등록되어 있습니다.

Node.js에서는 문서, 읽기 및 편집 단락 및 텍스트, 변경 구조 및 스타일을 만들거나로드 할 수 있으며 Univer 스냅 샷을 저장합니다. 테이블, 목록, 열, 공식 및 모양은 내용 플러그인이 필요합니다. 편집 내용은 페이지 스크린 샷을 생성하지 않습니다.

아래 예제는 플러그인 모드를 사용합니다. `@univerjs/core` 및 제품 콘텐츠 플러그인은 헤드리스 콘텐츠 레이어를 형성합니다. `@univerjs/ui`, 제품 `*-ui` 패키지 및 기본 브라우저 코어 사전 설정은이 설정의 일부가 아닙니다. 예를 들어 `@univerjs/engine-render`를 공유 의존성으로 유지하지만 캔버스 나 편집기를 마운트하지 않습니다. 완전한 분류 및 예외를 위해 [Headless 패키지 경계](/overview/features/shared/server-calculation#headless-packages)을 참조하십시오.

로컬 스냅 샷 작업은 협업 서비스가 필요하지 않습니다. 협업 예에는 클라이언트, 서버 및 인증이 필요합니다. 사무실 변환은 [Server SDK](/server/import-export/node)를 필요로하며 스크린 샷은 [렌더링 런타임](/ai/visual-inspection)가 필요합니다. `/facade` 가져 오기는 기능이 플러그인이없고 UI API를 헤드리스 API로 전환하지 않습니다.

## 설치

```package-install
npm install @univerjs/core @univerjs/engine-render @univerjs/engine-formula @univerjs/docs
```

## 사용법

```typescript
import { LocaleType, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import '@univerjs/docs/facade'

const univer = new Univer({
  locale: LocaleType.KO_KR,
  locales: {
    [LocaleType.KO_KR]: {},
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverDocsPlugin)

const univerAPI = FUniver.newAPI(univer)
univerAPI.createDocument({})
```

## Node.js 환경의 공동 편집 예제 [#node-collaboration-example]

Node.js는 협업 클라이언트로 작동할 수 있습니다. 서버에서 기존 문서를로드하고 Facade API를 통해 문서를 편집하고 동일한 문서가 열린 다른 클라이언트에 대한 변경을 동기화합니다. 예를 들어 실행하기 전에 [협력 서비스](/server/collaboration/quick-start), [고객 라이센스](/server/license) 및 액세스 가능한 문서 ID를 준비하십시오.

### 플러그인 설정 [#plugin-configuration]

`UniverLicensePlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `license` | `string` |  | 클라이언트 라이선스 파일의 내용입니다. |

`UniverDrawingPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>override</ConfigKey> | `[DependencyIdentifier, Provider \| null][]` |  | Dependency overrides 그림 플러그인 적용. |
| <ConfigKey depth={1}>[0]</ConfigKey> | `DependencyIdentifier` |  | 신뢰성을 식별합니다. 이미지 저장을 위해, `IImageIoService`를 사용하십시오. |
| <ConfigKey depth={1}>[1]</ConfigKey> | `Provider \| null` |  | 기본 하나를 대체하는 공급자. `null`를 통과하여 이 서비스를 공동 공급합니다. |

`UniverCollaborationClientPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `socketService` | `Ctor<ICollaborationSocketService>` |  | 소켓 구현이 런타임 사용. |
| `enableOfflineEditing` | `boolean` | `false` | 로컬로 편집할 수 있습니다. |
| `enableSingleActiveInstanceLock` | `boolean` | `false` | 한 브라우저 인스턴스에서만 문서가 적극적으로 편집되도록 합니다. |

| `wsSessionTicketUrl` | `string` | `'/universer-api/user/session-ticket'` | WebSocket 세션 티켓을 발급하는 엔드포인트. |

| `signUrlServerUrl` | `string` | `'/universer-api/file/{fileID}/sign-url'` | 파일 URL을 표시하는 엔드포인트. `{fileID}` 플레이스홀더를 유지하십시오. |
| `downloadEndpointUrl` | `string` |  | 파일 다운로드에 대한 기본 URL. |
| `authzUrl` | `string` | `'/universer-api/authz'` | 권한을 확인하는 엔드포인트입니다. |
| `sendChangesetTimeout` | `number` | `2000` | 얼마나 긴 편집은 그들이 보내지기 전에 배치됩니다, 밀리 초. |
| `retryConnectingInterval` | `number` | `20000` | 재연결 간격입니다. 단위는 밀리초입니다. |
| <ConfigKey depth={0}>customHeaders</ConfigKey> | `Record<string, string>` |  | 연결로 전송되는 여분 우두머리. |
| <ConfigKey depth={1}>[header]</ConfigKey> | `string` |  | 이 HTTP 헤더에 대해 보내지는 값입니다. |

import type { FConnectorShape } from '@univerjs-pro/engine-shape/facade'
import { FUniver } from '@univerjs/core/facade'
import process from 'node:process'
import { createUniverOnNode } from './univer'

async function run(): Promise<void> {
  const univer = createUniverOnNode()
  const univerAPI = FUniver.newAPI(univer)

  const document = await univerAPI.getCollaboration().loadDocAsync('your-unit-id')
  if (!document) {
    throw new Error('공동 편집 문서를 불러오지 못했습니다. 문서 ID와 접근 권한을 확인하세요.')
  }

  testDocsFacadeAPI(univerAPI)
  testDocsHeaderFooterFacadeAPI(univerAPI)
  testDocsCalloutFacadeAPI(univerAPI)
  testDocsCodeFacadeAPI(univerAPI)
  testDocsQuoteFacadeAPI(univerAPI)
  testDocsListFacadeAPI(univerAPI)
  testDocsShapeFacadeAPI(univerAPI)
  testDocsTableFacadeAPI(univerAPI)
  testDocsColumnFacadeAPI(univerAPI)

  await univerAPI.getCollaboration().flush(document.getId())
  console.warn('문서 변경 사항을 서버에 동기화했습니다.')
}

function testDocsShapeFacadeAPI(univerAPI: FUniver) {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return
  const paragraph = fDocument.getParagraphs()[0]
  if (!paragraph) return
  const anchor = {
    paragraphId: paragraph.getId(),
    segmentId: paragraph.getSegmentId(),
  }

  const shape = fDocument.insertShape({
    shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
    placement: {
      wrappingStyle: univerAPI.Enum.TextWrappingStyle.WRAP_SQUARE,
      anchor,
      position: { horizontalOffset: 80, verticalOffset: 80 },
    },
    transform: { width: 320, height: 160 },
    shapeData: {
      fill: {
        fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
        color: '#DBEAFE',
      },
      stroke: {
        lineStrokeType: univerAPI.Enum.ShapeLineTypeEnum.SolidLine,
        color: '#2563EB',
        width: 2,
      },
    },
  })
  if (!shape) return

  shape
    .setRotation(4)
    .setStrokeOpacity(0.9)
    .getText()
    .setText('문서 도형 Facade 예제')
    .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
    .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)

  const target = fDocument.insertShape({
    shapeType: univerAPI.Enum.ShapeTypeEnum.Ellipse,
    placement: {
      wrappingStyle: univerAPI.Enum.TextWrappingStyle.WRAP_SQUARE,
      anchor,
      position: { horizontalOffset: 500, verticalOffset: 100 },
    },
    transform: { width: 160, height: 120 },
    shapeData: {
      fill: { fillType: univerAPI.Enum.ShapeFillEnum.SolidFill, color: '#DCFCE7' },
      stroke: { lineStrokeType: univerAPI.Enum.ShapeLineTypeEnum.SolidLine, color: '#16A34A', width: 2 },
    },
  })
  if (!target) return

  const connector = fDocument.insertShape({
    shapeType: univerAPI.Enum.ShapeTypeEnum.BentConnector3,
    placement: {
      wrappingStyle: univerAPI.Enum.TextWrappingStyle.WRAP_SQUARE,
      anchor,
      position: { horizontalOffset: 360, verticalOffset: 130 },
    },
    transform: { width: 180, height: 80 },
  })
  if (!connector || !connector.isConnectorShape()) return

  const sourceSites = shape.getConnectionSites()
  const targetSites = target.getConnectionSites()
  ;(connector as FConnectorShape)
    .setStrokeColor('#475569')
    .setStrokeWidth(2)
    .setEndArrow(univerAPI.Enum.ShapeArrowTypeEnum.Arrow, univerAPI.Enum.ShapeArrowSizeEnum.Medium)
    .bindStart(shape.getId(), sourceSites[0]?.index ?? 0)
    .bindEnd(target.getId(), targetSites[2]?.index ?? targetSites[0]?.index ?? 0)

  console.warn('문서 도형 ID:', shape.getId())
  console.warn('문서 도형 수:', fDocument.getShapes().length)
}

function testDocsFacadeAPI(univerAPI: FUniver): void {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return

  const intro = fDocument.appendParagraph(
    `Node.js 공동 편집 클라이언트에서 보내는 인사입니다. 현재 시간: ${new Date().toString()}.`,
  )
  intro.appendText(' [인라인 삽입]')

  const beforeIntro = fDocument.insertParagraph(
    intro.getInfo().paragraphIndex,
    '문단 객체를 사용하여 소개 문단 앞에 삽입한 내용입니다.',
  )
  const foundIntro = fDocument.findParagraphByText('Node.js 공동 편집 클라이언트')
  const introMatches = fDocument.findParagraphs({ text: 'Node.js 공동 편집 클라이언트' })
  const introRange = intro.getRange()
  const bodyBeforeDelete = fDocument.getBody()
  const deleteStartOffset = bodyBeforeDelete.dataStream.indexOf(' [인라인 삽입]')
  if (deleteStartOffset >= 0) {
    fDocument.deleteRange({
      startOffset: deleteStartOffset,
      endOffset: deleteStartOffset + ' [인라인 삽입]'.length,
    })
  }

  intro.setStyle({
    textStyle: {
      fs: 12,
    },
  })

  console.warn(`현재 문서 ID: ${fDocument.getId()}`)
  console.warn(`현재 문서 이름: ${fDocument.getName()}`)
  console.warn(`현재 문서가 모던 문서인지 여부: ${fDocument.isModern()}`)
  console.warn(`소개 문단 ID: ${intro.getId()}`)
  console.warn(`이동 후 소개 문단의 자식 노드 인덱스: ${intro.getInfo().paragraphIndex}`)
  console.warn('소개 문단 범위:', introRange)
  console.warn('찾은 소개 문단 ID:', foundIntro?.getId())
  console.warn('일치하는 소개 문단 수:', introMatches.length)
  console.warn('본문 문단 수:', fDocument.getParagraphs().length)
  console.warn(`삽입한 문단 ID: ${beforeIntro.getId()}`)
  console.warn(`문서 스냅샷 본문 길이: ${fDocument.save().body?.dataStream.length ?? 0}`)
}

function testDocsHeaderFooterFacadeAPI(univerAPI: FUniver): void {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return

  if (fDocument.isModern()) {
    console.warn('머리글/바닥글 예제를 건너뜁니다. 모던 문서는 페이지 머리글과 바닥글을 지원하지 않습니다.')
    return
  }

  const headerSegmentId = fDocument.ensurePageHeader()
  const footerSegmentId = fDocument.ensurePageFooter()

  const headerParagraph = fDocument.appendParagraph('Docs Node.js 머리글 Facade 예제.', headerSegmentId)
  headerParagraph.appendText(` 문서: ${fDocument.getName() || fDocument.getId()}`)
  const footerParagraph = fDocument.appendParagraph('Docs Node.js 바닥글 Facade 예제.', footerSegmentId)

  fDocument.insertText(0, '페이지 머리글:', headerSegmentId)
  footerParagraph.setStyle({
    textStyle: {
      fs: 10,
    },
  })

  console.warn('문서 머리글 세그먼트 ID:', headerSegmentId)
  console.warn(
    '문서 머리글 문단:',
    fDocument.getParagraphs(headerSegmentId).map((paragraph) => paragraph.getText()),
  )
  console.warn('문서 머리글 본문 길이:', fDocument.getBody(headerSegmentId).dataStream.length)
  console.warn('문서 바닥글 세그먼트 ID:', footerSegmentId)
  console.warn('문서 바닥글 문단 ID:', fDocument.findParagraphByText('바닥글 Facade 예제', footerSegmentId)?.getId())
}

function testDocsCodeFacadeAPI(univerAPI: FUniver): void {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return

  const paragraph = fDocument.appendParagraph('const message = "Docs Node.js 코드 블록 Facade에서 보내는 인사";')
  const code = fDocument.insertCode(paragraph, {
    blockId: createSampleId('code'),
    config: {
      language: 'typescript',
      showLineNumbers: true,
      tabSize: 4,
      wrap: true,
    },
  })

  if (!code) return

  code.updateConfig({

function testDocsColumnFacadeAPI(univerAPI: FUniver): void {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return

  if (!fDocument.isModern()) {
    console.warn('단 나누기 예제를 건너뜁니다. 단 그룹에는 모던 문서가 필요합니다.')
    return
  }

  const groupId = createSampleId('column-group')
  const group = fDocument.insertColumnGroup(3, {
    columnGroupId: groupId,
    columnIds: [createSampleId('column-left'), createSampleId('column-middle'), createSampleId('column-right')],
    gap: 18,
    widthRatios: [1.1, 1, 0.9],
  })

  if (!group) return

  const [leftColumn, middleColumn, rightColumn] = group.getColumns()
  const leftOffset = leftColumn?.getInsertOffset()
  if (leftOffset != null) {
    fDocument.insertText(leftOffset, '단 나누기 Facade 왼쪽 단.')
  }

  const middleOffset = middleColumn?.getInsertOffset()
  if (middleOffset != null) {
    fDocument.insertText(middleOffset, '단 나누기 Facade 가운데 단.')
  }

  const rightOffset = rightColumn?.getInsertOffset()
  if (rightOffset != null) {
    fDocument.insertTableFromData(
      [
        ['지표', '현재', '다음 단계'],
        ['지원 기능', '단 나누기', '머리글/바닥글'],
      ],
      {
        headerRowCount: 1,
        offset: rightOffset,
        tableId: createSampleId('column-table'),
      },
    )
  }

  group.setWidthRatios([1.2, 1, 0.8])

  const insertedColumn = middleColumn
    ? group.addColumn(
        middleColumn.getId(),
        univerAPI.Enum.DocsColumnPositionEnum.RIGHT,
        createSampleId('column-inserted'),
      )
    : null
  const insertedOffset = insertedColumn?.getInsertOffset()
  if (insertedOffset != null) {
    fDocument.insertText(insertedOffset, 'Facade API로 삽입한 단.')
  }

  const foundByText = fDocument.findColumnGroupByText('가운데 단')
  const foundById = fDocument.findColumnGroups({ columnGroupId: group.getId() })
  const firstColumn = group.getColumn(0)
  const groupRange = group.getRange()
  const rangeLookup = groupRange ? fDocument.getColumnGroupAt(groupRange.startOffset) : null

  console.warn('문서 첫 번째 단의 텍스트:', firstColumn?.getText())
}

### 실행 안내

`loadDocAsync()`는 서버에서 이미 존재하는 문서를로드하므로 `createDocument()`가 필요하지 않습니다. 협업 서비스는 사용자를 식별하고 `customHeaders`의 쿠키와 같은 인증 정보로부터 권한을 확인합니다. 서버는 연결의 `memberID`를 반환합니다.

예를 들어 브라우저 오프라인 캐싱과 탭의 단일 활성 인스턴스 잠금을 해제하므로 `setCurrentUser()`는 계정 사이의 캐시 고립에 필요하지 않습니다. 해당 기능은 해당 지역의 현재 사용자에 따라 주석이 추가되면 애플리케이션 사용자는 `UserManagerService`를 통해 설정할 수 있습니다. 이것은 서버 인증을 대체하지 않습니다.

헤더/footer 예제는 문서만 적용되며, 열 예제는 현대 문서에만 적용됩니다. 예를 들어 `isModern()`로 문서 모드를 확인하고 해당 작업을 건너뛰지 않습니다.

예를 들어 기존 문서에 내용을 삽입하므로 테스트 문서를 사용합니다. 협업 연결은 예가 완료된 후 열립니다. 브라우저에서 동일한 문서를 열고 변경 사항을 볼 수 있습니다. `flush()`는 서버가 할당된 협업 변경 사항을 인정하도록 기다립니다. 한 샷 스크립트를 위해 `univer.dispose()`를 호출하여 모든 비동기 작업 및 동기화가 완료되었습니다.
