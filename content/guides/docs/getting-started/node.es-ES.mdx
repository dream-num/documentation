Univer tiene una característica isomórfica, lo que significa que puede ejecutarse no solo en el navegador sino también en un entorno Node.js. Puede desarrollar servicios de procesamiento de datos basados en Headless Univer para generar o modificar documentos en el lado del servidor e interactuar con Univer Docs a través de la API de Facade.

En Node.js, usa el modo complemento y registra los complementos necesarios sin incluir los de interfaz del navegador.

## Instalación

```package-install
npm install @univerjs/core @univerjs/engine-render @univerjs/engine-formula @univerjs/docs
```

## Uso

```typescript
import { LocaleType, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import '@univerjs/docs/facade'

const univer = new Univer({
  locale: LocaleType.ES_ES,
  locales: {
    [LocaleType.ES_ES]: {},
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverDocsPlugin)

const univerAPI = FUniver.newAPI(univer)
univerAPI.createDocument({})
```

## Ejemplo de colaboración en Node.js [#node-collaboration-example]

Node.js puede actuar como cliente de colaboración: cargar un documento existente del servidor, modificar su contenido mediante la API de Facade y sincronizar los cambios con otros clientes que tengan abierto el mismo documento. Antes de ejecutarlo, prepara un [servicio de colaboración](/server/collaboration/quick-start), una [licencia de cliente](/server/license) y un ID de documento accesible.

### Archivos del ejemplo

Organiza los archivos con esta estructura:

```text
src/docs/node/
├── main.ts
└── univer.ts
```

- `univer.ts`: crea Univer y registra los plugins de funciones de documentos, las extensiones de Facade y el cliente de colaboración de Node.js.
- `main.ts`: carga un documento colaborativo y muestra las API de párrafos, texto, encabezados y pies de página, bloques destacados, bloques de código, citas, listas, formas, tablas y columnas.

Sustituye `your-license`, la URL del servidor y la Cookie en `univer.ts`, así como el ID del documento en `main.ts`.

```typescript title="univer.ts"
      [IMentionIOService, null],

    license: 'your-license',

  univer.registerPlugin(UniverThreadCommentPlugin)

    override: [[IImageIoService, null]],

  univer.registerPlugin(UniverDocsDrawingPlugin)
  univer.registerPlugin(UniverDocsHyperLinkPlugin)

function registerCollaborationPlugins(univer: Univer): void {
  const serverUrl = 'https://your-univer-server.example.com'

  univer.registerPlugin(UniverNetworkPlugin)
  univer.registerPlugin(UniverCollaborationPlugin)
  univer.registerPlugin(UniverCollaborationClientPlugin, {
    socketService: NodeCollaborationSocketService,
    enableOfflineEditing: false,
    enableSingleActiveInstanceLock: false,
    snapshotServerUrl: `${serverUrl}/universer-api/snapshot`,
    collabSubmitChangesetUrl: `${serverUrl}/universer-api/comb`,
    collabWebSocketUrl: `${serverUrl}/universer-api/comb/connect`,
    wsSessionTicketUrl: `${serverUrl}/universer-api/user/session-ticket`,
    uploadFileServerUrl: `${serverUrl}/universer-api/stream/file/upload`,
    signUrlServerUrl: `${serverUrl}/universer-api/file/{fileID}/sign-url`,
    downloadEndpointUrl: serverUrl,
    authzUrl: `${serverUrl}/universer-api/authz`,
    sendChangesetTimeout: 200,
    retryConnectingInterval: 1000,
    customHeaders: {
      // Ejemplo: si tu servidor Univer requiere autenticación mediante cookies, puedes definir aquí la cabecera 'cookie'.

      // ... más cabeceras
    },
  })
  univer.registerPlugin(UniverCollaborationClientNodePlugin)
}
```

```typescript title="main.ts"
import type { FConnectorShape } from '@univerjs-pro/engine-shape/facade'
import { FUniver } from '@univerjs/core/facade'
import process from 'node:process'
import { createUniverOnNode } from './univer'

async function run(): Promise<void> {
  const univer = createUniverOnNode()
  const univerAPI = FUniver.newAPI(univer)

  const document = await univerAPI.getCollaboration().loadDocAsync('your-unit-id')
  if (!document) {
    throw new Error(
      'No se pudo cargar el documento colaborativo. Comprueba el ID del documento y los permisos de acceso.',
    )
  }

  testDocsFacadeAPI(univerAPI)
  testDocsHeaderFooterFacadeAPI(univerAPI)
  testDocsCalloutFacadeAPI(univerAPI)
  testDocsCodeFacadeAPI(univerAPI)
  testDocsQuoteFacadeAPI(univerAPI)
  testDocsListFacadeAPI(univerAPI)
  testDocsShapeFacadeAPI(univerAPI)
  testDocsTableFacadeAPI(univerAPI)
  testDocsColumnFacadeAPI(univerAPI)

  await univerAPI.getCollaboration().flush(document.getId())
  console.warn('Los cambios del documento se han sincronizado con el servidor.')
}

function testDocsShapeFacadeAPI(univerAPI: FUniver) {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return
  const paragraph = fDocument.getParagraphs()[0]
  if (!paragraph) return
  const anchor = {
    paragraphId: paragraph.getId(),
    segmentId: paragraph.getSegmentId(),
  }

  const shape = fDocument.insertShape({
    shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
    placement: {
      wrappingStyle: univerAPI.Enum.TextWrappingStyle.WRAP_SQUARE,
      anchor,
      position: { horizontalOffset: 80, verticalOffset: 80 },
    },
    transform: { width: 320, height: 160 },
    shapeData: {
      fill: {
        fillType: univerAPI.Enum.ShapeFillEnum.SolidFill,
        color: '#DBEAFE',
      },
      stroke: {
        lineStrokeType: univerAPI.Enum.ShapeLineTypeEnum.SolidLine,
        color: '#2563EB',
        width: 2,
      },
    },
  })
  if (!shape) return

  shape
    .setRotation(4)
    .setStrokeOpacity(0.9)
    .getText()
    .setText('Ejemplo de forma del documento con la API de Facade')
    .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
    .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)

  const target = fDocument.insertShape({
    shapeType: univerAPI.Enum.ShapeTypeEnum.Ellipse,
    placement: {
      wrappingStyle: univerAPI.Enum.TextWrappingStyle.WRAP_SQUARE,
      anchor,
      position: { horizontalOffset: 500, verticalOffset: 100 },
    },
    transform: { width: 160, height: 120 },
    shapeData: {
      fill: { fillType: univerAPI.Enum.ShapeFillEnum.SolidFill, color: '#DCFCE7' },
      stroke: { lineStrokeType: univerAPI.Enum.ShapeLineTypeEnum.SolidLine, color: '#16A34A', width: 2 },
    },
  })
  if (!target) return

  const connector = fDocument.insertShape({
    shapeType: univerAPI.Enum.ShapeTypeEnum.BentConnector3,
    placement: {
      wrappingStyle: univerAPI.Enum.TextWrappingStyle.WRAP_SQUARE,
      anchor,
      position: { horizontalOffset: 360, verticalOffset: 130 },
    },
    transform: { width: 180, height: 80 },
  })
  if (!connector || !connector.isConnectorShape()) return

  const sourceSites = shape.getConnectionSites()
  const targetSites = target.getConnectionSites()
  ;(connector as FConnectorShape)
    .setStrokeColor('#475569')
    .setStrokeWidth(2)
    .setEndArrow(univerAPI.Enum.ShapeArrowTypeEnum.Arrow, univerAPI.Enum.ShapeArrowSizeEnum.Medium)
    .bindStart(shape.getId(), sourceSites[0]?.index ?? 0)
    .bindEnd(target.getId(), targetSites[2]?.index ?? targetSites[0]?.index ?? 0)

  console.warn('ID de la forma del documento:', shape.getId())
  console.warn('Número de formas del documento:', fDocument.getShapes().length)
}

function testDocsFacadeAPI(univerAPI: FUniver): void {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return

  const intro = fDocument.appendParagraph(
    `Saludos desde el cliente de colaboración de Node.js. Hora actual: ${new Date().toString()}.`,
  )
  intro.appendText(' [inserción en línea]')

  const beforeIntro = fDocument.insertParagraph(
    intro.getInfo().paragraphIndex,
    'Texto insertado antes de la introducción mediante un objeto de párrafo.',
  )
  const foundIntro = fDocument.findParagraphByText('cliente de colaboración de Node.js')
  const introMatches = fDocument.findParagraphs({ text: 'cliente de colaboración de Node.js' })
  const introRange = intro.getRange()
  const bodyBeforeDelete = fDocument.getBody()
  const deleteStartOffset = bodyBeforeDelete.dataStream.indexOf(' [inserción en línea]')
  if (deleteStartOffset >= 0) {
    fDocument.deleteRange({
      startOffset: deleteStartOffset,
      endOffset: deleteStartOffset + ' [inserción en línea]'.length,
    })
  }

  intro.setStyle({
    textStyle: {
      fs: 12,
    },
  })

  console.warn(`ID del documento actual: ${fDocument.getId()}`)
  console.warn(`Nombre del documento actual: ${fDocument.getName()}`)
  console.warn(`¿El documento actual es moderno?: ${fDocument.isModern()}`)
  console.warn(`ID del párrafo de introducción: ${intro.getId()}`)
  console.warn(`Índice hijo del párrafo de introducción tras moverlo: ${intro.getInfo().paragraphIndex}`)
  console.warn('Rango del párrafo de introducción:', introRange)
  console.warn('ID del párrafo de introducción encontrado:', foundIntro?.getId())
  console.warn('Número de párrafos de introducción coincidentes:', introMatches.length)
  console.warn('Número de párrafos del cuerpo:', fDocument.getParagraphs().length)
  console.warn(`ID del párrafo insertado: ${beforeIntro.getId()}`)
  console.warn(`Longitud del cuerpo de la instantánea del documento: ${fDocument.save().body?.dataStream.length ?? 0}`)
}

function testDocsHeaderFooterFacadeAPI(univerAPI: FUniver): void {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return

  if (fDocument.isModern()) {
    console.warn(
      'Se omite el ejemplo de encabezado y pie de página: los documentos modernos no admiten encabezados ni pies de página.',
    )
    return
  }

  const headerSegmentId = fDocument.ensurePageHeader()
  const footerSegmentId = fDocument.ensurePageFooter()

  const headerParagraph = fDocument.appendParagraph(
    'Ejemplo de encabezado de Docs en Node.js con la API de Facade.',
    headerSegmentId,
  )
  headerParagraph.appendText(` Documento: ${fDocument.getName() || fDocument.getId()}`)
  const footerParagraph = fDocument.appendParagraph(
    'Ejemplo de pie de página de Docs en Node.js con la API de Facade.',
    footerSegmentId,
  )

  fDocument.insertText(0, 'Encabezado de página:', headerSegmentId)
  footerParagraph.setStyle({
    textStyle: {
      fs: 10,
    },
  })

  console.warn('ID del segmento de encabezado del documento:', headerSegmentId)
  console.warn(
    'Párrafos del encabezado del documento:',
    fDocument.getParagraphs(headerSegmentId).map((paragraph) => paragraph.getText()),
  )
  console.warn(
    'Longitud del cuerpo del encabezado del documento:',
    fDocument.getBody(headerSegmentId).dataStream.length,
  )
  console.warn('ID del segmento de pie de página del documento:', footerSegmentId)
  console.warn(
    'ID del párrafo de pie de página del documento:',
    fDocument.findParagraphByText('pie de página de Docs en Node.js con la API de Facade', footerSegmentId)?.getId(),
  )
}

function testDocsColumnFacadeAPI(univerAPI: FUniver): void {
  const fDocument = univerAPI.getActiveDocument()
  if (!fDocument) return

  if (!fDocument.isModern()) {
    console.warn('Se omite el ejemplo de columnas: los grupos de columnas requieren un documento moderno.')
    return
  }

  const groupId = createSampleId('column-group')
  const group = fDocument.insertColumnGroup(3, {
    columnGroupId: groupId,
    columnIds: [createSampleId('column-left'), createSampleId('column-middle'), createSampleId('column-right')],
    gap: 18,
    widthRatios: [1.1, 1, 0.9],
  })

  if (!group) return

  const [leftColumn, middleColumn, rightColumn] = group.getColumns()
  const leftOffset = leftColumn?.getInsertOffset()
  if (leftOffset != null) {
    fDocument.insertText(leftOffset, 'Columna izquierda del ejemplo de Facade.')
  }

  const middleOffset = middleColumn?.getInsertOffset()
  if (middleOffset != null) {
    fDocument.insertText(middleOffset, 'Columna central del ejemplo de Facade.')
  }

  const rightOffset = rightColumn?.getInsertOffset()
  if (rightOffset != null) {
    fDocument.insertTableFromData(
      [
        ['Indicador', 'Actual', 'Siguiente paso'],
        ['Funciones cubiertas', 'Columnas', 'Encabezado/Pie de página'],
      ],
      {
        headerRowCount: 1,
        offset: rightOffset,
        tableId: createSampleId('column-table'),
      },
    )
  }

  group.setWidthRatios([1.2, 1, 0.8])

  const insertedColumn = middleColumn
    ? group.addColumn(
        middleColumn.getId(),
        univerAPI.Enum.DocsColumnPositionEnum.RIGHT,
        createSampleId('column-inserted'),
      )
    : null
  const insertedOffset = insertedColumn?.getInsertOffset()
  if (insertedOffset != null) {
    fDocument.insertText(insertedOffset, 'Columna insertada mediante la API de Facade.')
  }

  const foundByText = fDocument.findColumnGroupByText('Columna central')
  const foundById = fDocument.findColumnGroups({ columnGroupId: group.getId() })
  const firstColumn = group.getColumn(0)
  const groupRange = group.getRange()
  const rangeLookup = groupRange ? fDocument.getColumnGroupAt(groupRange.startOffset) : null

  console.warn('Información del grupo de columnas del documento:', group.describe())
  console.warn('Número de grupos de columnas encontrados por ID:', foundById.length)
  console.warn('ID del grupo de columnas encontrado por texto:', foundByText?.getId())
  console.warn('ID del grupo de columnas encontrado por rango:', rangeLookup?.getId())
  console.warn('Texto de la primera columna del documento:', firstColumn?.getText())
}
```

### Notas de ejecución

`loadDocAsync()` carga un documento existente del servidor; no necesitas llamar a `createDocument()`. El servicio de colaboración identifica al usuario y comprueba sus permisos mediante la información de autenticación, como la Cookie incluida en `customHeaders`. El servidor devuelve el `memberID` de la conexión.

Este ejemplo desactiva la caché sin conexión del navegador y el bloqueo de instancia entre pestañas, por lo que no es necesario llamar a `setCurrentUser()` para aislar la caché por cuenta. Si más adelante usas funciones como comentarios, que dependen del usuario actual local, puedes establecer el usuario de la aplicación mediante `UserManagerService`; esto no sustituye la autenticación del servidor.

El ejemplo de encabezado y pie de página solo se aplica a documentos paginados; el de columnas, a documentos modernos. El ejemplo comprueba el modo del documento con `isModern()` y omite las operaciones no compatibles.

El ejemplo inserta contenido en un documento existente, por lo que se recomienda usar un documento de prueba. El ejemplo mantiene la conexión colaborativa después de ejecutarse. Abre el mismo documento en un navegador para ver los cambios. `flush()` espera la confirmación del servidor para los cambios pendientes. Si lo conviertes en un script de una sola ejecución, llama a `univer.dispose()` cuando hayan terminado todas las operaciones asíncronas y la sincronización.
