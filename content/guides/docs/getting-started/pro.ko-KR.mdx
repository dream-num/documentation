Univer는 더 복잡한 애플리케이션 시나리오를 지원하기 위해 Pro 버전을 제공합니다. Pro 버전은 더 많은 기능과 역량을 갖추고 있어 높은 성능과 다양한 기능이 필요한 애플리케이션에 적합합니다.

문서에서 Univer SDK Pro와 관련된 부분은 <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} /> 아이콘으로 표시됩니다.

[서버 통합](/guides/server-integration)에 따라 예제 실행, 앱 연결, 영속성과 권한 검증을 진행하세요. 구현 세부 정보와 Web/Server 예제는 [Univer Office](https://office.univer.ai/collaboration/quick-start)를 참고하세요.

라이선스가 없으면 Univer SDK Pro의 일부 기능에 다음과 같은 제한이 적용됩니다.

| 기능 | 라이선스 미보유 시 제한 사항 |
| --- | --- |
| 인쇄 | 워터마크<br />한 번에 최대 1페이지 인쇄 |
| 협업 편집 | 워터마크<br />동시에 협업 편집할 수 있는 문서는 최대 5개<br />문서당 공동 작업자는 최대 3명 |
| DOCX 가져오기 및 내보내기 | 워터마크<br />가져올 파일은 최대 1MB |

Univer SDK Pro 라이선스 발급 방법은 [Univer](https://univer.ai)를 참고하세요.
