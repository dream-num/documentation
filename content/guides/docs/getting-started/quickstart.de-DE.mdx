## Starter-Kit

Wenn Sie lieber mit einer lokalen Entwicklungsumgebung beginnen möchten, können Sie mit den folgenden Starter-Kits in nur wenigen Sekunden eine neue Univer-App erstellen.

<Tabs items={['npm', 'pnpm']}>
  <Tab>
Um den folgenden Befehl auszuführen, muss auf Ihrem Gerät `nodejs >= 18`, `npm >= 8` und `git` installiert sein.

    ```shell
    npx degit dream-num/univer-doc-start-kit univer-doc-start-kit
    cd univer-doc-start-kit
    npm install
    npm run dev
    ```
  </Tab>
  <Tab>
Für den folgenden Befehl ist Folgendes erforderlich: Auf dem Gerät sind `nodejs >= 18`, `pnpm >= 7` und `git` installiert.

    ```shell
    pnpm dlx degit dream-num/univer-doc-start-kit univer-doc-start-kit
    cd univer-doc-start-kit
    pnpm install
    pnpm dev
    ```
  </Tab>
</Tabs>

Gute Arbeit bei Ihren ersten Schritten mit Univer! Sie haben Ihr erstes Projekt erfolgreich erstellt und einen Eindruck davon bekommen, was Univer kann.

## Grundlegende Konzepte [#basic-concepts]

Bevor Sie tiefer in Univer eintauchen Lesen Sie dieses Dokument, um die Grundkonzepte von Univer zu verstehen, die Ihnen helfen werden, Univer reibungsloser zu nutzen.

Zu den Grundkonzepten gehören:

- Plugin
- Snapshot
- Befehl
- Fassaden-API

## Plugins

Alle Funktionen von Univer werden durch Plugins bereitgestellt, die die Grundbausteine von Univer sind. Mehrere Plugins zusammen bilden eine Univer-Anwendung.

Die Zu den Aufgaben von Plugins gehören:

1. Implementierung von Funktionen wie `@univerjs/sheets-filter` zur Bereitstellung von Filterfunktionen.
2. Bereitstellung einiger grundlegender Funktionen, z. B. `@univerjs/engine-render` bietet Rendering-Funktionen.

Sie können die Plugins von Univer kombinieren, um eine Univer-Anwendung anzupassen, die Ihren Anforderungen entspricht, und das Laden unnötigen Codes zu vermeiden. Sie können die Funktionalität von Univer auch erweitern, indem Sie Plugins schreiben, um individuelle Anforderungen zu erfüllen.

## Schnappschuss

Sie müssen einen Snapshot in Univer laden, um ein Dokument zu laden. Jeder Dokumenttyp bietet sein eigenes Snapshot-Format. Bitte lesen Sie die obige API-Dokumentation, um zu erfahren, wie Sie einen Snapshot schreiben, der den Formatanforderungen entspricht:

1. Das Snapshot-Format von a Die Tabelle ist [`IWorkbookData`](/guides/sheets/model/workbook-data#iworkbookdata).
2. Das Snapshot-Format eines Dokuments ist [`IDocumentData`](/guides/docs/model/document-data#idocumentdata).

Funktionale Plugins können Ressourcen wie Bilder usw. über das Feld `resources` speichern. Weitere Informationen finden Sie unter [Benutzerdefiniertes Plugin-Modell](/guides/recipes/tutorials/custom-model).

<Callout type="warning" title="Caution">
Hinweis! Der Snapshot von Univer wird nur zum Speichern von Daten verwendet. Es spiegelt nicht den aktuellsten Dokumentstatus zur Laufzeit wider! Wenn Sie den Dokumentstatus als Snapshot speichern möchten, verwenden Sie die Methode zum Speichern des Snapshots in der Facade-API.
</Callout>

## Befehl

In Univer müssen alle Datenänderungen über Befehle ausgeführt werden. Der befehlsbasierte Ansatz kann Änderungen an Werten besser verfolgen, Funktionen wie Rückgängig machen, Wiederherstellen und gemeinsame Bearbeitung implementieren, komplexe verknüpfte Logik zwischen Funktionen verwalten usw.

Wenn Sie Dokumentdaten über Befehle ändern möchten, lesen Sie bitte [So finden Sie die Befehls-ID](/guides/recipes/practices/find-the-command-id). Wenn Sie sich dafür entscheiden, Dokumentdaten über die Facade-API zu ändern, bereitet die Facade-API tatsächlich Parameter für Sie vor und führt Befehle im Hintergrund aus.

<Callout type="warning" title="Caution">
**Ändern Sie den Snapshot nicht direkt!** Dies wird nicht wirksam und löst keine Aktualisierung von Ansichten oder Benutzeroberfläche aus. Bitte ändern Sie Daten über Befehle oder die Facade-API.
</Callout>

## Facade-API

Aufgrund der hohen Komplexität von Büroanwendungen ist auch die Architektur von Univer sehr komplex. Um Entwicklern die Nutzung von Univer zu erleichtern, stellen wir die Facade-API zur Verfügung, die einen Wrapper für die Erstanbieter-Plugins von Univer darstellt und einfachere Schnittstellen bereitstellt, die Entwicklern die Nutzung von Univer erleichtern.

Die Facade-API wird aktiv verbessert. Wenn Sie Fragen oder Anforderungen haben, reichen Sie bitte ein Problem auf GitHub ein.

Die Facade-API ist eine High-Level-API, die die zugrunde liegenden Details abstrahiert. Während es allgemeine Aufgaben vereinfacht, erfordern komplexe Funktionen möglicherweise ein Verständnis der Architektur von Univer und die direkte Verwendung der Low-Level-API.
