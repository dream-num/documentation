## 인터페이스 언어

`locale`는 메뉴, 도구 팁, 대화 상자 및 기타 번역 UI에 사용되는 언어 팩을 선택합니다. `locales`은 언어 팩을 선택하지 않고 등록합니다. Univer 인스턴스의 모든 단위는 이러한 설정을 공유합니다. `LocaleType` 값을 전달하십시오. 예를 들어 `LocaleType.EN_US`.

- **모든 제품: UI**: `locale`는 번역된 메뉴, 툴팁, 대화 상자 및 플러그인 라벨을 변경합니다. 사용자 콘텐츠를 수정하거나 기존 단위로 이름을 변경하지 않습니다.
- **장: 세포 체재 및 공식**: 수와 날짜는 숫자 체재 locale override로 첫째로, 그 후에 workbook 스냅샷 `locale`, 그 후에 예를들면 `locale` 만듭니다. `region`는 이것의 무엇이든을 대체하지 않습니다. `DOLLAR`와 같은 공식적인 행동은 재정적인 결과에 적용된 통화 체재, 아직도 `locale`를 따르고, CJK 입력 정상화는 또한 `locale`를 사용합니다.
- **Docs: 통계**: `locale`는 단어 세그먼트와 계산을 결정합니다.

### 실행 중 언어 변경

전환 언어 전에, 설치된 플러그인 또는 사전 설정이 제공하는 모든 언어 팩을로드합니다. `loadLocales()`는 언어를 전환하지 않고 번역을 병합합니다. `setLocale()` 스위치는 모든 것을 다운로드하지 않고로드 된 번역으로 전환합니다. 번역이없는 키는 키 자체로 나타납니다. 다음 예제는 공유 UI 언어 팩을 로드합니다. 다른 설치된 플러그인에 대한 대상 언어 팩을 동일한 병합 통화로 추가하십시오.

```typescript
import { LocaleType, mergeLocales } from '@univerjs/core'
import UIEnUS from '@univerjs/ui/locale/en-US'

univerAPI.loadLocales(LocaleType.EN_US, mergeLocales(UIEnUS))
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentLocale()) // enUS
```

### 플러그인 모드에서 언어 팩 등록하기

플러그인 모드에서, 각 플러그인에서 언어 팩을 가져다가 하나의 객체로 병합하고 `Univer` 인스턴스에 객체를 전달합니다.

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import DesignEnUS from '@univerjs/design/locale/en-US' // [!code highlight]
import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US' // [!code highlight]
import UIEnUS from '@univerjs/ui/locale/en-US' // [!code highlight]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DesignEnUS, // [!code highlight]
      UIEnUS, // [!code highlight]
      DocsUIEnUS, // [!code highlight]
    ),
  },
})
```

<Callout type="warning" title="주 메뉴">
  모든 플러그인에는 언어 팩이 포함되어 있지 않습니다. 각 기능의 문서는 그것이 있는지 여부를 나타냅니다.
</Callout>

### 프리셋 모드에서 언어 팩 등록하기

Preset 패키지는 이미 플러그인의 언어 팩을 포함, 그래서 그들은 preset에서 직접 가져올 수 있습니다:

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEnUS from '@univerjs/preset-docs-core/locales/en-US' // [!code highlight]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetDocsCoreEnUS, // [!code highlight]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
  ],
})
```

### 언어 팩 병합 [#mergeLocales]

`mergeLocales`는 여러 플러그인 또는 사전 설정 언어 팩을 단일 완전한 언어 팩 객체로 병합합니다. 다음과 같이 사용하십시오:

<Tabs items={['플러그인 모드', '프리셋 모드']}>
  <Tab>
    ```typescript
    import { mergeLocales } from '@univerjs/core'

    // You can pass multiple language pack objects to merge
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // You can also pass an array of language pack objects
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    ])
    ```
  </Tab>
  <Tab>
    ```typescript

    // You can pass multiple language pack objects to merge
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // You can also pass an array of language pack objects
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,

    ])
    ```
  </Tab>

### 사용자 지정 언어 팩

사용자 정의 언어 팩은 수동으로 조립 될 수 있습니다. 필요한 개체를 구축하고 `Univer` 인스턴스에 전달하십시오. 참고를 위해 사전 설정 언어 팩은 일반적으로 `<rootDir>/packages/<PLUGIN_NAME>/locale` 아래에 저장됩니다.

```typescript
import { LocaleType, Univer } from '@univerjs/core'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: {
      ui: {
        shortcut: {
          undo: '元に戻す',
          redo: 'やり直す',
        },
      },
    },
  },
})
```

### 번역 기여하기

Univer는 다음과 같은 내장 언어 팩을 포함합니다:

- `zh-CN`: 중국어 간체
- `en-US`: 영어
- `zh-TW`: 중국어 번체
- `zh-HK`: 중국어 번체(홍콩)
- `ru-RU`: 러시아어
- `vi-VN`: 베트남어
- `fa-IR`: 페르시아어
- `fr-FR`: 프랑스어
- `ja-JP`: 일본어
- `ko-KR`: 한국어
- `es-ES`: 스페인어
- `ca-ES`: 카탈루냐어
- `sk-SK`: 슬로바키아어
- `ar-SA`: 아랍어
- `de-DE`: 독일어
- `id-ID`: 인도네시아어
- `it-IT`: 이탈리아어
- `pl-PL`: 폴란드어
- `pt-BR`: 포르투갈어(브라질)

Univer는 오픈 소스이며, 언어 팩을 추가하거나 개선하는 기여는 환영합니다.

## 지역 설정

`region`는 지역 기능에 따라 지역 컨벤션을 결정합니다. Univer 인스턴스의 단위는이 설정을 공유합니다.

둘 다 조정은 `LocaleType` 가치를 가지고 갑니다. 예를 들면, `LocaleType.EN_US`는 `enUS`이고, `en-US`는 언어 팩 파일 이름과 BCP 47 꼬리표입니다. `region`로 `US` `SG`와 같은 국가 코드를 통과하지 마십시오. 지역은 UI가 다른 `locale`를 사용할 때 그것의 언어 팩을 요구하지 않습니다.

`region`가 명시적으로 설정되지 않을 때 `locale`를 다음과 같이 설정하지 않습니다. `region`을 초기화 또는 `setRegion()` 호출하여 `setLocale()`는 선택한 지역을 유지한 후 언어 변경 사항입니다. 다음과 같이 자동을 복원하려면 공개 API가 없습니다. 따라서 변경할 때 두 값을 업데이트하십시오.

독일 지역 협약을 적용하면서 UI 언어를 유지하려면 `createUniver()` 또는 `new Univer()` 중 `locale` 옆에 `region: LocaleType.DE_DE`을 추가하십시오.

```typescript
import { LocaleType } from '@univerjs/core'

univerAPI.setRegion(LocaleType.DE_DE)
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentRegion()) // deDE
```

이 예에서 UI는 영어 및 지역 형식화로 전환됩니다. `getCurrentLocale()` 및 `getCurrentRegion()`는 효과적인 식별자를 반환합니다. 둘 다 함께 변경하려면 동일한 `LocaleType` 값을 가진 setters를 모두 호출하십시오.

- **시트: 통화 통제**: `region`는 통화 도구 모음 아이콘, 통화 및 회계 옵션 및 미리보기를 결정하고 통화 명령이 적용된 패턴을 표시합니다. 기존 셀 형식을 다시 작성하지 않거나 통화 값 변환하지 않습니다.
- **Docs: 통계**: `region`는 그룹화 분리기를 포함하여 통계 대화 상자 그리고 상태 막대기에서 보이는 조사를 배열합니다. `region`를 바꾸는 것은 계산 규칙을 바꾸지 않습니다.
- **스레드 의견, 활성화시**: `region`는 24 시간 시간 및 라틴어 손가락을 사용하여 의견에서 보이는 날짜와 시간 체재를 통제합니다. `locale` 통제 코멘트 UI 원본. 더하여 조정은 타임스탬프를 저장하고, `region`은 시간대 조정이 아닙니다.
- **보드, 슬라이드,베이스, PDF**: `locale`는 번역된 UI를 통제합니다. `region`은 통합된 실 의견과 같은 그것을, 이용하는 공유한 특징에 적용합니다; 그것은 자동적으로 자료표 널 또는 활주 원본, 기본적인 분야, 또는 PDF 내용이 아닙니다.

## 오른쪽에서 왼쪽으로 배치

<Callout type="warning" title="주 메뉴">
  RTL은 현재 UI 레이어에서만 지원됩니다. 렌더링 레이어는 RTL을 지원하지 않습니다.
</Callout>

레이아웃 방향은 별도 설정입니다. 초기화에 `direction`를 설정하거나 `univerAPI.setDirection('rtl')` 또는 `setDirection('ltr')`로 전화하십시오. `locale` 나 `region` 만을 변경하면 레이아웃 방향을 전환하지 않습니다.

```typescript
univerAPI.setDirection('rtl')
```
