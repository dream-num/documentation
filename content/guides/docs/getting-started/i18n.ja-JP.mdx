## プリセットモードでの言語パックの登録

プリセットには対応するプラグインの言語パックが含まれているため、プリセットからインポートするだけで利用できます。

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreJaJP from '@univerjs/preset-docs-core/locales/ja-JP' // [!code highlight]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetDocsCoreJaJP, // [!code highlight]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
  ],
})
```

## プラグインモードでの言語パックの登録

プラグインの言語パックを使う場合は、言語パックを提供するプラグインから対応ロケールを読み込み、それらを結合して `Univer` インスタンスに渡す必要があります。以下は例です。

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import DesignJaJP from '@univerjs/design/locale/ja-JP' // [!code highlight]
import DocsUIJaJP from '@univerjs/docs-ui/locale/ja-JP' // [!code highlight]
import UIJaJP from '@univerjs/ui/locale/ja-JP' // [!code highlight]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DesignJaJP, // [!code highlight]
      UIJaJP, // [!code highlight]
      DocsUIJaJP, // [!code highlight]
    ),
  },
})
```
