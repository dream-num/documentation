## インターフェースの言語

`locale`は、メニュー、ツールチップ、ダイアログ、その他の翻訳されたUIに使用される言語パックを選択します。 `locales`では、言語パックを1つ選択せずに登録します。 Univerインスタンス内のすべてのユニットは、これらの設定を共有します。 `LocaleType`値を渡します。たとえば、`LocaleType.EN_US`。

- **すべての製品: UI**: `locale`は、翻訳されたメニュー、ツールチップ、ダイアログ、プラグインラベルを変更します。 ユーザーのコンテンツを変更したり、既存のユニットの名前を変更したりすることはありません。
- **シート: 細胞のフォーマットおよび方式**: 数値と日付は、最初にオーバーライドされた番号形式のローカライズでレンダリングされ、ワークブックは`locale`をスナップショットし、その後`locale`。 `region`はこれらのいずれかを置き換えません。 `DOLLAR`や財務結果に適用される通貨フォーマットなどの式挙動は、`locale`以降、CJK入力ノーマライゼーションも`locale`を使用しています。
- **Docs: 統計**:`locale`は単語の区分およびカウントを決定します。

### 実行時の言語の切り替え

言語を切り替える前に、インストールされたプラグインやプリセットが提供されるすべての言語パックを読み込みます。 `loadLocales()`は、言語を切り替えることなく、翻訳をマージします。 `setLocale()` は、ダウンロードせずに読み込まれた翻訳に切り替えます。 翻訳のないキーは、キー自体として表示されます。 次の例では、共有されたUI言語パックをロードします。 同じマージコールに他のインストールされたプラグインのターゲット言語パックを追加します。

```typescript
import { LocaleType, mergeLocales } from '@univerjs/core'
import UIEnUS from '@univerjs/ui/locale/en-US'

univerAPI.loadLocales(LocaleType.EN_US, mergeLocales(UIEnUS))
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentLocale()) // enUS
```

### プラグインモードでの言語パックの登録

プラグインモードでは、言語パックを1つのプラグインからインポートし、それらを単一のオブジェクトにマージし、そのオブジェクトを`Univer`インスタンスに渡します。

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import DesignJaJP from '@univerjs/design/locale/ja-JP' // [!code highlight]
import DocsUIJaJP from '@univerjs/docs-ui/locale/ja-JP' // [!code highlight]
import UIJaJP from '@univerjs/ui/locale/ja-JP' // [!code highlight]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DesignJaJP, // [!code highlight]
      UIJaJP, // [!code highlight]
      DocsUIJaJP, // [!code highlight]
    ),
  },
})
```

<Callout type="warning" title="キューション">
  すべてのプラグインには、言語パックが含まれています。各機能のドキュメントは、それが実行するかどうかを記述します。
</Callout>

### プリセットモードでの言語パックの登録

プリセットパッケージには、プラグインの言語パックが既に含まれているため、プリセットから直接インポートできます。

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreJaJP from '@univerjs/preset-docs-core/locales/ja-JP' // [!code highlight]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetDocsCoreJaJP, // [!code highlight]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
  ],
})
```

### 言語パックのマージ [#mergeLocales]

`mergeLocales`は、複数のプラグインやプリセット言語パックを単一の完全な言語パックオブジェクトにマージします。次のように使用します。

<Tabs items={['プラグインモード', 'プリセットモード']}>
  <Tab>
    ````typescript
    import { mergeLocales } from '@univerjs/core'

    // 複数の言語パックオブジェクトを引数で渡してマージできます
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // 配列としてまとめて渡すことも可能です
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    ])
    ````
  </Tab>
  <Tab>
    ````typescript
    import { mergeLocales } from '@univerjs/presets'

    // 複数の言語パックオブジェクトを引数で渡してマージできます
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // 配列としてまとめて渡すことも可能です
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    ])
    ````
  </Tab>
</Tabs>

### カスタム言語パック

カスタム言語パックは手動で組み立てることができます。必要なオブジェクトを作成し、`Univer`インスタンスに渡します。参照のために、プリセット言語パックは通常`<rootDir>/packages/<PLUGIN_NAME>/locale`の下に保存されます。

````typescript
import { LocaleType, Univer } from '@univerjs/core'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: {
      ui: {
        shortcut: {
          undo: '元に戻す',
          redo: 'やり直す',
        },
      },
    },
  },
})
````

### 翻訳への貢献

Univerには、以下の組み込み言語パックが含まれています。

- `zh-CN`: 中国語（簡体字）
- `en-US`: 英語
- `zh-TW`: 中国語（繁体字）
- `zh-HK`: 中国語（繁体字・香港）
- `ru-RU`: ロシア語
- `vi-VN`: ベトナム語
- `fa-IR`: ペルシャ語
- `fr-FR`: フランス語
- `ja-JP`: 日本語
- `ko-KR`: 韓国語
- `es-ES`: スペイン語
- `ca-ES`: カタルーニャ語
- `sk-SK`: スロバキア語
- `ar-SA`: アラビア語
- `de-DE`: ドイツ語
- `id-ID`: インドネシア語
- `it-IT`: イタリア語
- `pl-PL`: ポーランド語
- `pt-BR`: ポルトガル語（ブラジル）

Univerはオープンソースであり、言語パックを追加または改善する貢献を歓迎します。

## 地域設定

`region`は、地域の機能が続く地域の慣行を決定します。 Univerインスタンスのユニットは、この設定を共有します。

どちらの設定も`LocaleType`値を取ります。例えば`LocaleType.EN_US`は`enUS`で、`en-US`は言語パックファイル名とBCP 47タグです。`US`や`SG`などの国コードを`region`に渡さないでください。UIが異なる`locale`を使用しているとき、地域は言語パックを必要としません。

`region`が明示的に設定されていない場合、その後の`setLocale()`呼び出しを含む`locale`に続いています。 初期化時に`region`を設定したり、`setRegion()`を呼び出すと、この自動で次のようになります。 選択した領域を維持した後の言語変更。 以下に自動復元するためのパブリックAPIはありません。 そのため、両方の値を一緒に変更する必要があります。

ドイツの地方慣習を適用する際のUI言語を維持するためには、`createUniver()`か`new Univer()`の`locale`に次`region: LocaleType.DE_DE`を加えて下さい。

```typescript
import { LocaleType } from '@univerjs/core'

univerAPI.setRegion(LocaleType.DE_DE)
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentRegion()) // deDE
```

この例では、UI は英語と地域の書式設定に切り替えて、ドイツ語を留まっています。`getCurrentLocale()` と `getCurrentRegion()`は、効果的な識別子を返します。両方を一緒に変更するには、同じ `LocaleType`値で両方のセッターを呼び出します。

- **シート:通貨コントロール**: `region`は通貨ツールバーのアイコン、通貨と会計オプション、および通貨コマンドが適用するパターンを決定します。 変更は、既存のセルフォーマットを刷新したり、通貨値を変更したりしません。
- **Docs: 統計**: `region`は、統計ダイアログとセパレータをグループ化を含むステータスバーに表示されたカウントをフォーマットします。 `region`を変更しても、カウントルールは変更されません。
- **スレッドコメント, 有効にしたときに**: `region`は、コメントに示されている日付と時刻の形式を、24時間時間、ラテンの数字で制御します。 `locale` はコメントUIテキストを制御します。 保存されたタイムスタンプを変更し、`region`がタイムゾーンの設定ではありません。
- **ボード、スライド、ベース、PDF**: `locale`は、翻訳されたUIを制御します。 `region` は、スレッドコメントなどの共有機能に適用されます。それは自動的にボードやスライドテキスト、ベースフィールド、またはPDFコンテンツを再フォーマットしません。

## 右から左へのレイアウト

<Callout type="warning" title="キューション">
  RTL は UI レイヤーでのみサポートされます。レンダリングレイヤーは RTL をサポートしていません。
</Callout>

レイアウトの方向は別の設定です。 `direction` を初期化に設定するか、`univerAPI.setDirection('rtl')`または `setDirection('ltr')`. 変更 `locale` or `region`単独ではレイアウトの方向を切り替えません。

```typescript
univerAPI.setDirection('rtl')
```
