Univer Docs 基于同一内容引擎提供两种文档形态。根据应用需要选择布局；文本、段落、样式与快照持久化使用同一套 API。

| 按任务选择 | 传统文档 | 现代文档 |
| --- | --- | --- |
| 典型场景 | 报告、合同及需要物理分页的正式文档。 | 知识页面、项目简报及连续流式内容。 |
| 布局方式 | 页面、节、页眉页脚与页面分栏。 | 连续布局、标题折叠与可编辑的分栏组。 |
| 布局 API | [Section API](/reference/facade/document-section) | [ColumnGroup API](/reference/facade/document-column-group) |

## 创建文档 [#create-document]

完成[安装](/guides/docs/getting-started/installation)后，选择下面一个创建示例。预设／插件模式决定 Univer 的安装方式；传统／现代决定文档布局，两者是独立的选择。各 Univer 包保持同版；示例使用 1.3.0。

<Tabs items={["传统文档", "现代文档"]}>
  <Tab>

```typescript
const doc = univerAPI.createDocument({
  id: 'launch-plan-traditional',
  title: 'Launch plan',
  documentStyle: {
    documentFlavor: univerAPI.Enum.DocumentFlavor.TRADITIONAL,
  },
})

const heading = doc.appendParagraph('Launch plan')
heading.setStyle({ namedStyleType: univerAPI.Enum.NamedStyleType.HEADING_1 })
doc.appendParagraph('Status: Draft')
```

  </Tab>
  <Tab>

```typescript
const doc = univerAPI.createDocument({
  id: 'launch-plan-modern',
  title: 'Launch plan',
  documentStyle: {
    documentFlavor: univerAPI.Enum.DocumentFlavor.MODERN,
  },
})

const heading = doc.appendParagraph('Launch plan')
heading.setStyle({ namedStyleType: univerAPI.Enum.NamedStyleType.HEADING_1 })
doc.appendParagraph('Status: Draft')
```

  </Tab>
</Tabs>

## 识别文档形态 [#document-flavor]

通过 `getDocumentFlavor()`、`isTraditional()` 和 `isModern()` 识别文档。没有显式声明形态的快照可能为 `UNSPECIFIED`，不能用 `!isModern()` 认定它是传统文档。加载快照时保留其已声明的形态。

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')
console.log(doc.getDocumentFlavor(), doc.isTraditional(), doc.isModern())
```
