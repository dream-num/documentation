## Conceptos básicos [#basic-concepts]

Antes de profundizar en Univer, lee este documento para comprender los conceptos básicos de Univer, que te ayudarán a utilizar Univer con mayor fluidez.

Los conceptos básicos incluyen:

- Complemento
- Instantánea
- Comando
- Fachada API

### Complementos

Todas las funciones de Univer son proporcionadas por complementos, que son los componentes básicos de Univer. Varios complementos combinados forman una aplicación Univer.

Las responsabilidades de los complementos incluyen:

1. Implementar funciones, por ejemplo, `@univerjs/docs-hyper-link` proporciona el modelo y los comandos de hipervínculos para Univer Docs.
2. Proporcionar algunas capacidades básicas, como `@univerjs/engine-render` proporciona capacidades de renderizado.

Puede combinar los complementos de Univer para personalizar una aplicación Univer que cumpla con sus requisitos y evite cargar código innecesario. También puede ampliar la funcionalidad de Univer escribiendo complementos para satisfacer necesidades personalizadas.

### Instantánea

Univer Docs utiliza [`IDocumentData`](/guides/docs/model/document-data#idocumentdata) como formato de instantánea. Describe el cuerpo del documento, los estilos del documento, los encabezados y pies de página, los dibujos, las listas, las tablas y los recursos de complementos.

El campo opcional `resources` almacena datos definidos por complementos.

<Callout type="warning" title="Caution">
  ¡Nota! La instantánea de Univer solo se utiliza para almacenar datos. ¡No refleja el último estado del documento en
  tiempo de ejecución! Si desea guardar el estado del documento como una instantánea, utilice el método para guardar la
  instantánea en la API de Facade.
</Callout>

### Comando

En Univer Docs, los cambios en el contenido y el formato del documento se ejecutan mediante comandos. Esto permite realizar un seguimiento de los cambios, implementar las funciones de deshacer, rehacer y edición colaborativa, y coordinar las funciones relacionadas.

La API de Facade prepara los parámetros y ejecuta internamente los comandos de Docs correspondientes.

<Callout type="warning" title="Caution">
  **¡No modifique la instantánea directamente!** Esto no tendrá efecto y no activará la actualización de las vistas o la
  interfaz de usuario. Modifique los datos mediante comandos o la API de Facade.
</Callout>

### API de Facade

Debido a la alta complejidad de las aplicaciones de oficina, la arquitectura de Univer también es muy compleja. Para facilitar el uso de Univer a los desarrolladores, proporcionamos la API de Facade, que es un contenedor para los complementos propios de Univer, que proporciona interfaces más simples que facilitan a los desarrolladores el uso de Univer.

La API de Facade se está mejorando activamente. Si tiene alguna pregunta o requisito, envíe un problema en GitHub.

La API Facade es una API de alto nivel que abstrae los detalles subyacentes. Si bien simplifica las tareas comunes, las características complejas pueden requerir comprender la arquitectura de Univer y usar la API de bajo nivel directamente.

## Modo preset y modo plugin

Un preset agrupa plugins preconfigurados. Ambos modos ofrecen las mismas capacidades si incluyen los mismos plugins. Los presets simplifican la configuración; el modo plugin permite controlar la composición y la carga.

<Callout type="warning">
  Mantenga versiones compatibles entre todas las dependencias de Univer. No vuelva a registrar un plugin que ya esté incluido en un preset.
</Callout>

| Modo plugin | Modo preset |
| --- | --- |
| Importar explícitamente las extensiones Facade | Extensiones Facade incluidas |
| Controlar el orden de registro | El preset gestiona sus plugins |
| Cargar plugins cuando se necesiten | Cargar los presets configurados al inicializar |
