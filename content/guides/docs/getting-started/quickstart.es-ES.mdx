## Kit de inicio

Si prefiere comenzar con un entorno de desarrollo local, puede usar los siguientes kits de inicio para crear una nueva aplicación Univer en solo unos segundos.

<Tabs items={['npm', 'pnpm']}>
  <Tab>
Para ejecutar el siguiente comando, su dispositivo debe tener `nodejs >= 18`, `npm >= 8` y `git` instalados.

    ```shell
    npx degit dream-num/univer-doc-start-kit univer-doc-start-kit
    cd univer-doc-start-kit
    npm install
    npm run dev
    ```
  </Tab>
  <Tab>
Ejecutar el siguiente comando requiere que tu dispositivo tenga `nodejs >= 18`, `pnpm >= 7` y `git` instalados.

    ```shell
    pnpm dlx degit dream-num/univer-doc-start-kit univer-doc-start-kit
    cd univer-doc-start-kit
    pnpm install
    pnpm dev
    ```
  </Tab>
</Tabs>

## Conceptos básicos [#basic-concepts]

Antes de profundizar en Univer, lee este documento para comprender los conceptos básicos de Univer, que te ayudarán a utilizar Univer con mayor fluidez.

Los conceptos básicos incluyen:

- Complemento
- Instantánea
- Comando
- Fachada API

## Complementos

Todas las funciones de Univer son proporcionadas por complementos, que son los componentes básicos de Univer. Varios complementos combinados forman una aplicación Univer.

Las responsabilidades de los complementos incluyen:

1. Implementar características, como `@univerjs/sheets-filter` proporciona funcionalidad de filtrado.
2. Proporcionar algunas capacidades básicas, como `@univerjs/engine-render` proporciona capacidades de renderizado.

Puede combinar los complementos de Univer para personalizar una aplicación Univer que cumpla con sus requisitos y evite cargar código innecesario. También puede ampliar la funcionalidad de Univer escribiendo complementos para satisfacer necesidades personalizadas.

## Instantánea

Necesitas cargar una instantánea en Univer para cargar un documento. Cada tipo de documento proporciona su propio formato de instantánea. Consulte la documentación de la API anterior para aprender cómo escribir una instantánea que cumpla con los requisitos de formato:

1. El formato de instantánea de una hoja de cálculo es [`IWorkbookData`](/guides/sheets/model/workbook-data#iworkbookdata).
2. El formato de instantánea de un documento es [`IDocumentData`](/guides/docs/model/document-data#idocumentdata).

Los complementos funcionales pueden almacenar recursos, como imágenes, etc., a través del campo `resources`. Para obtener más información, consulte [Complemento de modelo personalizado](/guides/recipes/tutorials/custom-model).

<Callout type="warning" title="Caution">
¡Nota! La instantánea de Univer solo se utiliza para almacenar datos. ¡No refleja el último estado del documento en tiempo de ejecución! Si desea guardar el estado del documento como una instantánea, utilice el método para guardar la instantánea en la API de Facade.
</Callout>

## Comando

En Univer, todas las modificaciones de datos deben ejecutarse mediante comandos. El enfoque basado en comandos puede realizar un mejor seguimiento de los cambios en los valores, implementar funciones como deshacer, rehacer y edición colaborativa, manejar una lógica asociada compleja entre funciones, etc.

Si desea modificar los datos del documento mediante comandos, consulte [Cómo encontrar el ID del comando](/guides/recipes/practices/find-the-command-id). Si elige modificar los datos del documento a través de la API de Facade, la API de Facade preparará los parámetros para usted y ejecutará comandos detrás de escena.

<Callout type="warning" title="Caution">
**¡No modifique la instantánea directamente!** Esto no tendrá efecto y no activará la actualización de las vistas o la interfaz de usuario. Modifique los datos mediante comandos o la API de Facade.
</Callout>

## API de Facade

Debido a la alta complejidad de las aplicaciones de oficina, la arquitectura de Univer también es muy compleja. Para facilitar el uso de Univer a los desarrolladores, proporcionamos la API de Facade, que es un contenedor para los complementos propios de Univer, que proporciona interfaces más simples que facilitan a los desarrolladores el uso de Univer.

La API de Facade se está mejorando activamente. Si tiene alguna pregunta o requisito, envíe un problema en GitHub.

La API Facade es una API de alto nivel que abstrae los detalles subyacentes. Si bien simplifica las tareas comunes, las características complejas pueden requerir comprender la arquitectura de Univer y usar la API de bajo nivel directamente.
