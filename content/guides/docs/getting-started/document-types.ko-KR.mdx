Univer Docs는 같은 콘텐츠 엔진에서 두 가지 문서 유형을 제공합니다. 앱에 맞는 레이아웃을 선택하세요. 텍스트, 문단, 스타일, 스냅샷 저장에는 같은 API를 사용합니다.

| 작업에 따라 선택 | 전통 문서 | 현대 문서 |
| --- | --- | --- |
| 주요 용도 | 실제 페이지가 필요한 보고서, 계약서 등 정형 문서. | 지식 페이지, 프로젝트 개요, 연속적인 콘텐츠. |
| 레이아웃 | 페이지, 섹션, 머리글, 바닥글, 페이지 단 나누기. | 연속 레이아웃, 제목 접기, 편집 가능한 단 그룹. |
| 레이아웃 API | [Section API](/reference/facade/document-section) | [ColumnGroup API](/reference/facade/document-column-group) |

## 문서 생성 [#create-document]

[설치](/guides/docs/getting-started/installation) 후 아래 생성 예제 중 하나를 선택하세요. 프리셋/플러그인 모드는 설치 방법이고 전통/현대는 문서 레이아웃입니다. 두 선택은 독립적입니다. Univer 패키지는 같은 버전으로 유지하세요. 예제는 1.3.0을 사용합니다.

<Tabs items={["전통 문서", "현대 문서"]}>
  <Tab>

```typescript
const doc = univerAPI.createDocument({
  id: 'launch-plan-traditional',
  title: 'Launch plan',
  documentStyle: {
    documentFlavor: univerAPI.Enum.DocumentFlavor.TRADITIONAL,
  },
})

const heading = doc.appendParagraph('Launch plan')
heading.setStyle({ namedStyleType: univerAPI.Enum.NamedStyleType.HEADING_1 })
doc.appendParagraph('Status: Draft')
```

  </Tab>
  <Tab>

```typescript
const doc = univerAPI.createDocument({
  id: 'launch-plan-modern',
  title: 'Launch plan',
  documentStyle: {
    documentFlavor: univerAPI.Enum.DocumentFlavor.MODERN,
  },
})

const heading = doc.appendParagraph('Launch plan')
heading.setStyle({ namedStyleType: univerAPI.Enum.NamedStyleType.HEADING_1 })
doc.appendParagraph('Status: Draft')
```

  </Tab>
</Tabs>

## 문서 유형 확인 [#document-flavor]

`getDocumentFlavor()`, `isTraditional()`, `isModern()`으로 유형을 확인합니다. 유형을 지정하지 않은 스냅샷은 `UNSPECIFIED`일 수 있으므로 `!isModern()`만으로 전통 문서라고 판단하면 안 됩니다. 스냅샷을 불러올 때 선언된 유형을 유지하세요.

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')
console.log(doc.getDocumentFlavor(), doc.isTraditional(), doc.isModern())
```

## 공통 콘텐츠 작업 [#shared-content]

문단 ID, 텍스트 범위, 편집, 스타일, 저장은 [Docs API](/guides/docs/features/core/docs-api)를 참고하세요. 페이지 레이아웃은 [전통 문서](/guides/docs/features/traditional), 연속 레이아웃은 [현대 문서](/guides/docs/features/modern)에서 설명합니다. 각 기능에는 해당 플러그인이 필요합니다.
