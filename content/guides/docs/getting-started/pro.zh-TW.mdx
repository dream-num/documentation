Univer 為了滿足更復雜的應用場景，提供了 Univer SDK Pro 版本。Pro 版本包含了更多的功能和特性，適用於需要更高效能和更多功能的應用場景。

文件中與 Univer SDK Pro 相關的部分會以 <IconWrapper className="inline-flex" type="pro" size="sm" icon={null} /> 進行標識。

部分 Univer SDK Pro 的功能需要配合 Univer 的服務端使用，具體請參考 [Univer SDK Pro 服務端](/guides/pro/server) 進行整合。

在未獲得許可證的情況下，Univer SDK Pro 的部分功能會受到限制：

| 功能 | 未授權限制 |
| --- | --- |
| 列印 | 水印<br />每次列印不超過 1 頁 |
| 協同編輯 | 水印<br />同時協作文件數量不超過 5 個<br />每個文件的協作者數量不超過 3 個 |
| DOCX 匯入 & 匯出 | 水印<br />匯入檔案不超過 1MB |

關於 Univer SDK Pro 的授權方式，請參考 [Univer SDK Pro 購買頁面](/guides/pro)。
