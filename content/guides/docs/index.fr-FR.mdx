## Qu’est-ce qu’Univer Docs ?

Univer Office SDK est un cadre complet pour les applications de productivité de construction. Univer Docs est l'éditeur de document de Univer Office SDK et le composant Docs de Web SDK. Il fonctionne dans le navigateur et sur le serveur (Node.js).

Univer Docs obtient ses capacités d'édition à partir de [Web SDK](/guides/sheets), qui couvre les éditeurs intégrés et le traitement de contenu sans tête. La collaboration et la conversion de fichiers proviennent de [Server SDK](/server), et [AI SDK](/ai) permet à un agent de travailler avec des documents.

Univer Docs prend en charge l'extension et la personnalisation. Vous pouvez construire des applications avec elle allant de l'entrée de texte simple à la composition complexe, que vous travailliez individuellement ou en équipe.

## Compatibilité avec les navigateurs

Web SDK est compilé avec une cible Chrome 88 , mais cela ne signifie pas que chaque environnement courant est entièrement pris en charge . Nous essayons de garder Web SDK fonctionnant dans les navigateurs suivants et Node.js environnements :

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK se base sur `Intl.Segmenter`. Si votre navigateur ou environnement d'exécution ne le supporte pas, ajoutez d'abord le polyfill correspondant. Nous recommandons `@formatjs/intl-segmenter` .
</Callout>

Si vous rencontrez un problème de compatibilité, essayez d'abord le polyfill correspondant. Si le problème persiste, [ouvrir un numéro](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilité avec Node.js

<Callout type="warning">
  Cela ne s'applique que lorsque Web SDK fonctionne lui-même dans Node.js. Il ne s'agit pas de Web SDK fonctionnant dans un navigateur via un outil de construction basé sur Node.js.
</Callout>

Web SDK fonctionne sur Node.js v18.17.0 et plus tard.

## Points forts

Univer Docs prend en charge les fonctionnalités suivantes:

- **Caractéristiques de base du document** : saisie de texte complet, y compris les paramètres de paragraphe, l'espacement avant et après les paragraphes, l'alignement des paragraphes, la dentelation et la suspension, et la saisie de texte en-paragraphes, comme la compression de ponctuation, la suspension de ponctuation et l'espacements des caractères, et la rupture des mots occidentaux.
- **En-têtes et pieds de page**
- **Images flottantes**
- **Liens hypertextes**
- Et bien plus encore…

Les pages sous [Caractéristiques](/guides/docs/features/core) décrivent chaque fonction en détail.

## Comment lire la documentation

La navigation de documentation est à gauche. Les pages sont commandées de base à avancée, de sorte que vous pouvez les suivre en séquence pendant que vous construisez une application, ou les lire dans n'importe quel ordre et sauter aux sections qui s'appliquent à votre cas. Le haut de la barre latérale vous permet également de passer entre la documentation de produit.

Sur la droite se trouve un aperçu de la page courante, ce qui facilite le déplacement entre les sections. Pour trouver une page rapidement, utilisez la barre de recherche en haut ou le raccourci de recherche (Ctrl+K ou Cmd+K).

Si vous êtes nouveau dans Univer Docs, commencez par [Démarrage rapide](/guides/docs/getting-started/installation).

## Connaissances préalables

La documentation est destinée à être accessible, mais elle suppose toujours une base de référence pour qu'elle puisse rester concentrée sur Web SDK.

Une compréhension de base de JavaScript et de son écosystème vous aidera à tirer le meilleur parti de la documentation.

Si vous prévoyez d'exécuter Web SDK sur Node.js, vous avez également besoin d'une compréhension de base de Node.js.

[Univer Server SDK](/server) fournit les modules nécessaires à la collaboration, à l'historique partagé ou aux commentaires, et à la conversion de fichiers. Vous composez ces modules dans votre moteur d'application, qui gère également l'authentification, les permissions, le stockage et le déploiement.

Web SDK prend en charge l'extension, afin que vous puissiez l'adapter aux exigences de votre application.
