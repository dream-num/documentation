## Univer Docs 是什么

Univer Office SDK 是用于构建生产力应用的全栈框架。Univer Docs 是 Univer Office SDK 的电子文档编辑器，也是 Web SDK 中的 Docs 部分。它可以在浏览器和服务器（Node.js）上运行。

Univer Docs 的编辑能力由 [Web SDK](/guides/sheets) 提供，覆盖嵌入式编辑器和无界面内容处理。协同和文件转换由 [Server SDK](/server) 提供，[AI SDK](/ai) 则让 Agent 能够处理文档。

Univer Docs 支持扩展和定制。你可以用它构建从简单文字录入到复杂排版的各种应用，无论个人开发还是团队协作。

## 浏览器兼容性

Web SDK 的编译目标是 Chrome 88，但这并不意味着所有主流环境都能得到完整支持。我们会尽量保证 Web SDK 在以下浏览器和 Node.js 环境中正常工作：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK 依赖 `Intl.Segmenter`。如果你的浏览器或运行时环境不支持它，请先添加对应的 polyfill。我们推荐 `@formatjs/intl-segmenter`。
</Callout>

遇到兼容性问题时，请先尝试对应的 polyfill。如果问题仍然存在，请[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 兼容性

<Callout type="warning">
  以下内容仅适用于 Web SDK 本身在 Node.js 中运行的情况，不适用于通过基于 Node.js 的构建工具在浏览器中运行 Web SDK 的情况。
</Callout>

Web SDK 支持 Node.js v18.17.0 及之后的版本。

## 主要功能

Univer Docs 支持以下功能：

- **基本电子文档功能**：全文排版，包括段落设置、段前段后间距、段落对齐、缩进和悬挂，以及段内排版能力，例如标点挤压、标点悬挂、字符间距和西文断词。
- **页眉页脚**
- **浮动图片**
- **超链接**
- 以及更多……

每项功能的详细说明见[功能](/guides/docs/features/core)下的页面。

## 如何使用这些文档

文档导航位于左侧。页面按从基础到高级的顺序排列，你可以按顺序阅读，也可以在构建应用时按需跳读。侧边栏顶部还可切换产品文档。

右侧是当前页面的大纲，便于在各节之间跳转。如需快速找到某个页面，请使用顶部的搜索栏或搜索快捷键（Ctrl+K 或 Cmd+K）。

如果你是初次使用 Univer Docs，请从[快速开始](/guides/docs/getting-started/installation)入手。

## 前置知识

这套文档尽量照顾新手，但仍假设读者具备一定基础，以便内容能够聚焦于 Web SDK。

对 JavaScript 及其生态的基本了解，有助于你充分利用这套文档。

如果你计划在 Node.js 上运行 Web SDK，还需要对 Node.js 有基本了解。

协同、共享历史或评论、文件转换所需的模块由 [Univer Server SDK](/server) 提供。你在业务后端中组合这些模块，同时由业务后端负责身份认证、权限、存储和部署。仅在浏览器中编辑文档时，不需要这些模块。
