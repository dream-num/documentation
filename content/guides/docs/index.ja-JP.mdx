## Univer Docs とは

Univer は生産性アプリケーションを構築するためのフルスタックフレームワークで、Univer Docs はそのドキュメントコンポーネントです。

Univer Docs はブラウザとサーバー（Node.js）の両方で動作し、柔軟性・拡張性・カスタマイズ性を備えています。簡単なテキスト入力から企業向けの複雑な組版まで、さまざまなアプリケーションを構築できます。個人開発者でもチーム開発でも、Univer Docs を使えばドキュメントベースの強力なアプリケーションを素早く構築できます。


## ブラウザ互換性

Univer は Chrome 88 をターゲットとしてコンパイルされていますが、これはすべての主流環境を完全にサポートすることを保証するものではありません。Univer が以下のブラウザおよび Node.js 環境で問題なく動作するよう努めています。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer は `Intl.Segmenter`
  に依存しています。お使いのブラウザまたはランタイム環境でこれがサポートされていない場合は、先に対応するポリフィルを追加してください。`@formatjs/intl-segmenter`
  の利用を推奨します。
</Callout>

互換性に関する問題が発生した場合、まずは適切なポリフィルを使用して解決を試みてください。それでも問題が解決しない場合は、[Issue の提出](https://github.com/dream-num/univer/issues/new/choose) をご検討ください。

## Node.js 互換性

<Callout type="注意事項">
  注意：これは Univer を Node.js 環境で実行する場合にのみ適用され、Node.js
  ベースのビルドツールを使ってブラウザで実行する場合には該当しません。
</Callout>

Univer は Node.js 環境でも動作可能で、v18.17.0 以降のバージョンをサポートしています。


## 主な機能

Univer Docs は次のような幅広い機能をサポートしています。

- **基本ドキュメント機能**：段落設定、段前後の余白、段落揃え、インデント/ぶら下げなどの全文組版に加え、句読点の詰め、句読点のぶら下げ、字間調整、欧文の単語分割などの段落内組版もサポート。
- **ヘッダーとフッター**
- **浮動画像**
- **ハイパーリンク**
- など...

詳細は [機能](/guides/docs/features/core) セクションを参照してください。コア機能と主要機能は [GitHub](https://github.com/dream-num/univer) でオープンソースとして公開され、無料で利用できます。

## ドキュメントの読み方

画面左側にドキュメントのナビゲーションがあります。ページは基礎から応用へ順に構成されているため、その順で進めてもよいですし、必要な章だけを選んで読むこともできます。サイドバー上部で Univer Docs のドキュメントに切り替えることもできます。

画面右側には現在ページの目次が表示されます。目的のページを素早く見つけたい場合は、上部の検索バーや検索ショートカット（Ctrl+K または Cmd+K）を利用してください。

まずは [クイックスタート](/guides/docs/getting-started/quickstart) から始めることをおすすめします。

## 前提知識

ドキュメントは初心者にも分かりやすく設計していますが、Univer に集中できるよう、読み始める前にいくつかの基礎知識があることを前提としています。

効率よく理解するために、JavaScript とそのエコシステムの基本的な理解をおすすめします。

Node.js 上で Univer を動かしたい場合は、Node.js の基礎知識も必要です。

Pro 機能を試したり Univer Server を導入する場合は、Linux、Docker、Docker Compose（または Kubernetes）の基礎知識があるとスムーズです。
