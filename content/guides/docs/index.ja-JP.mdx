## Univer Docs とは

Univer Office SDKは、生産性アプリケーションの構築のためのフルスタックフレームワークです。 Univer Docsは、Univer Office SDKとWeb SDKのDocsコンポーネントのドキュメントエディタです。 これは、ブラウザとサーバー(Node.js)で動作します。

Univer Docsは、組込みエディタとヘッドレスコンテンツ処理をカバーする[Web SDK](/guides/sheets)からその編集機能を取得します。 [Server SDK](/server)と[AI SDK](/ai)のコラボレーションとファイル変換は、エージェントが文書を扱うことを可能にします。

Univer Docs は、拡張とカスタマイズをサポートしています。シンプルなテキスト入力から複雑な型設定まで、個別に作業したり、チームの一部として作業したりできるアプリケーションを構築できます。

## ブラウザ互換性

Web SDKはChrome 88ターゲットとコンパイルされますが、すべての主流環境が完全にサポートされています。次のブラウザとNode.js環境で動作するWeb SDKを維持しようとします。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDKは`Intl.Segmenter`に依存しています。お使いのブラウザやランタイム環境がサポートされていない場合は、対応するポリフィルを最初に追加してください。 `@formatjs/intl-segmenter`をお勧めします。
</Callout>

互換性の問題が発生した場合は、最初に対応するポリフィルを試してみてください。問題が主張している場合は、[問題を開く](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 互換性

<Callout type="warning">
  Web SDK自体がNode.jsで実行されるときのみ適用されます。 Node.jsベースのビルドツールを使用して、Web SDKがブラウザで実行されるときには適用されません。
</Callout>

Web SDKはNode.js v18.17.0以降で動作します。

## 主な機能

Univer Docs は、以下の機能をサポートしています。

- **基本的な文書の特徴**:段落の設定、段落前後の間隔、段落の直線、刻印および掛かることおよび句読の圧縮、句読の掛かること、特性の間隔およびウェスタン・ワードの壊れ目のようなinパラグラフのタイプ設定を含む完全なテキストの整形。
- **ヘッダーとフッター**
- **浮動画像**
- **ハイパーリンク**
- など...

[おすすめ商品](/guides/docs/features/core)の下のページでは、各機能の詳細を記述します。

## ドキュメントの読み方

ドキュメントのナビゲーションは左にあります。ページは基本から上級まで順に注文されますので、アプリケーションをビルドしたり、任意の順序でそれらを読み、あなたのケースに適用されるセクションにスキップしたりすることができます。サイドバーの上部には、製品文書間で切り替えることもできます。

右側は、セクション間で移動しやすくなる現在のページの概要です。ページをすばやく見つけるには、検索バーをトップまたは検索ショートカット(Ctrl+KまたはCmd+K)で使用してください。

Univer Docs に新しい場合は、[クイックスタート](/guides/docs/getting-started/installation). で起動します。

## 前提知識

ドキュメントは近接する意図ですが、まだWeb SDKに集中できるようにベースラインを想定しています。

JavaScriptとその生態系の基本的な理解は、ドキュメントを最大限に活用するのに役立ちます。

Node.jsでWeb SDKを実行したい場合は、Node.jsの基本理解が必要です。

[Univer Server SDK](/server)は、コラボレーション、共有履歴、コメント、ファイル変換のドキュメントのニーズをモジュールに提供します。 これらのモジュールは、認証、パーミッション、ストレージ、およびデプロイメントも処理します。 ブラウザで編集することは、それらのいずれかを必要としません。
