## Qué es Univer Docs

Univer Office SDK es un marco completo para la construcción de aplicaciones de productividad. Univer Docs es el editor de documentos de Univer Office SDK y el componente Docs de Web SDK. Funciona en el navegador y en el servidor (Node.js).

Univer Docs obtiene sus capacidades de edición de [Web SDK](/guides/sheets), que cubre editores embebidos y procesamiento de contenidos sin cabeza. La colaboración y conversión de archivos provienen de [Server SDK](/server) y [AI SDK](/ai) permite a un agente trabajar con documentos.

Univer Docs soporta la extensión y la personalización. Puede construir aplicaciones con él que van desde la entrada de texto simple a la composición compleja, ya sea que trabaje individualmente o como parte de un equipo.

## Compatibilidad del navegador

Web SDK está compilado con un objetivo Chrome 88, pero eso no significa que cada entorno principal es totalmente compatible. Intentamos mantener Web SDK trabajando en los siguientes navegadores y entornos Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK se basa en `Intl.Segmenter`. Si su navegador o entorno de tiempo de ejecución no lo soporta, agregue el polífilo correspondiente primero. Recomendamos `@formatjs/intl-segmenter` .
</Callout>

Si encuentras un problema de compatibilidad, prueba primero el polifill correspondiente. Si el problema persiste, [abrir una cuestión](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilidad con Node.js

<Callout type="warning">
  Esto se aplica sólo cuando Web SDK se ejecuta en Node.js. No se aplica cuando Web SDK funciona en un navegador a través de una herramienta de construcción basada en Node.js.
</Callout>

Web SDK funciona en Node.js v18.17.0 y más tarde.

## Aspectos destacados

Univer Docs soporta las siguientes características:

- **Características básicas del documento**: composición completa de texto, incluyendo ajustes de párrafo, espaciamiento antes y después de párrafos, alineación del párrafo, indentación y ahorcamiento, y tipografías en el párrafo tales como compresión de puntuación, colgación de puntuación, espaciamiento de caracteres y ruptura de palabras occidentales.
- **Encabezado y pie de página**
- **Imágenes flotantes**
- **Hipervínculos**
- y más...

Las páginas bajo [Características](/guides/docs/features/core) describen cada característica en detalle.

## Cómo leer la documentación

La navegación de la documentación está a la izquierda. Las páginas se ordenan de base a avanzada, por lo que puede seguirlas en secuencia mientras construye una aplicación, o leerlas en cualquier orden y saltar a las secciones que se aplican a su caso. La parte superior de la barra lateral también le permite cambiar entre la documentación del producto.

A la derecha es un esquema de la página actual, lo que hace más fácil moverse entre secciones. Para encontrar una página rápidamente, utilice la barra de búsqueda en la parte superior o el acceso directo de búsqueda (Ctrl+K o Cmd+K).

Si usted es nuevo en Univer Docs, comience con [Inicio rápido](/guides/docs/getting-started/installation).

## Conocimientos previos requeridos

La documentación está destinada a ser accesible, pero sigue asumiendo una base de referencia para que pueda mantenerse centrada en Web SDK.

Una comprensión básica de JavaScript y su ecosistema le ayudará a sacar el máximo provecho de la documentación.

Si planea ejecutar Web SDK en Node.js, también necesita una comprensión básica de Node.js.

[Univer Server SDK](/server) proporciona a los módulos un documento necesita de colaboración, historia compartida o comentarios, y conversión de archivos. Usted compone estos módulos en su backend de aplicación, que también maneja la autenticación, permisos, almacenamiento y despliegue. Editar solo en el navegador no requiere ninguno de ellos.
