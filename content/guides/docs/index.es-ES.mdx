## Qué es Univer Docs

Web SDK es un marco completo para crear aplicaciones de productividad y Univer Docs es el componente de documentos de Web SDK.

Univer Docs puede ejecutarse tanto en el navegador como en el servidor (Node.js). Está diseñado para ser altamente flexible, extensible y personalizable, y puede usarse para crear una amplia gama de aplicaciones, desde la simple entrada de texto hasta la composición tipográfica compleja. Ya sea que sea un desarrollador individual o parte de un equipo, Univer Docs puede ayudarlo a crear potentes aplicaciones basadas en documentos de forma rápida y sencilla.


## Compatibilidad del navegador

Web SDK está compilado con un objetivo de Chrome 88, pero esto no significa que sea totalmente compatible con todos los entornos principales. Nos esforzamos por garantizar que Web SDK funcione bien en los siguientes navegadores y entornos Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK depende de `Intl.Segmenter`. Si su navegador o entorno de ejecución no lo admite, primero agregue el polyfill
  correspondiente. Recomendamos usar `@formatjs/intl-segmenter`.
</Callout>

Si encuentra problemas de compatibilidad, primero intente resolverlos utilizando los polyfills adecuados. Si el problema persiste, no dude en [enviar un problema](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilidad con Node.js

<Callout type="warning">
  Nota: Esto solo se aplica a la ejecución de Web SDK en un entorno Node.js y no se aplica a los casos en los que Web SDK
  se ejecuta en un navegador usando herramientas de compilación basadas en Node.js.
</Callout>

Web SDK puede ejecutarse en un entorno Node.js, con versiones compatibles v18.17.0 y posteriores.


## Aspectos destacados

Univer Docs ahora admite una amplia gama de funciones, que incluyen:

- **Funciones básicas de documentos**: composición tipográfica de texto completo, que incluye configuración de párrafos, espaciado antes y después de los párrafos, alineación de párrafos, sangría y colgante, así como capacidades de composición tipográfica dentro de los párrafos, como compresión de puntuación, puntuación colgante, espaciado entre caracteres y división de palabras occidental.
- **Encabezado y pie de página**
- **Imágenes flotantes**
- **Hipervínculos**
- y más...

Para obtener más detalles, consulte las páginas debajo del Sección [Características](/guides/docs/features/core).

## Cómo leer la documentación

En el lado izquierdo de la pantalla, encontrará la barra de navegación de documentos. Las páginas de los documentos están organizadas secuencialmente, desde lo básico hasta lo avanzado, para que pueda seguirlas paso a paso al crear su aplicación. Sin embargo, puede leerlos en cualquier orden o pasar a las páginas que se apliquen a su caso de uso. También puedes consultar Univer Docs en la parte superior de la barra lateral.

En el lado derecho de la pantalla, verá una tabla de contenido que facilita la navegación entre las secciones de una página. Si necesita encontrar rápidamente una página, puede usar la barra de búsqueda en la parte superior o el acceso directo de búsqueda (Ctrl+K o Cmd+K).

Para comenzar, consulte la guía de [Inicio rápido](/guides/docs/getting-started/installation).

## Conocimientos previos requeridos

Aunque nuestros documentos están diseñados para ser amigables para principiantes, necesitamos establecer una base para que los documentos puedan manténgase enfocado en Web SDK.

Para aprovechar al máximo nuestros documentos, se recomienda que tenga un conocimiento básico de JavaScript y su ecosistema.

Si está interesado en ejecutar Web SDK en Node.js, también debe tener un conocimiento básico de Node.js.

Si desea probar Web SDK e implementar Univer Server, le recomendamos que tenga un conocimiento básico de Linux, Docker y Docker Compose (o Kubernetes).
