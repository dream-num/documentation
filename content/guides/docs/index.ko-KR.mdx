## Univer Docs란?

Univer Office SDK는 생산성 애플리케이션을 구축하기위한 풀 스택 프레임 워크입니다. Univer Docs는 Univer Office SDK의 문서 편집기이며 Web SDK 의 Docs 구성 요소입니다. 그것은 브라우저에서 실행하고 서버 (Node.js).

Univer Docs는 임베디드 편집기와 헤드리스 콘텐츠 처리를 포함하는 [Web SDK](/guides/sheets)에서 편집 기능을 얻습니다. 협업 및 파일 변환은 [Server SDK](/server) 및 [AI SDK](/ai)로 제공되며 문서에서 작업할 수 있습니다.

Univer Docs는 확장 및 사용자 정의를 지원합니다. 간단하게 텍스트 입력에서 복잡한 설정에 이르기까지 응용 프로그램을 구축 할 수 있으며 개별적으로 또는 팀의 일부로 작동합니다.

## 브라우저 호환성

Web SDK는 크롬 88 대상과 컴파일되지만, 모든 주류 환경을 완벽하게 지원하지 않습니다. 다음 브라우저와 Node.js 환경에서 Web SDK 작업을 유지하려고합니다.

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK는 `Intl.Segmenter`에 의존합니다. 브라우저 또는 실행 환경이 그것을 지원하지 않는 경우, 대응 polyfill을 먼저 추가하십시오. 우리는 `@formatjs/intl-segmenter`를 추천합니다.
</Callout>

호환성 문제가 발생하면 해당 폴리필을 먼저 시도하십시오. 문제가 지속되면 [자주 묻는 질문](https://github.com/dream-num/univer/issues/new/choose).

## Node.js 호환성

<Callout type="warning">
  Web SDK 자체가 Node.js에서 실행될 때에만 적용됩니다. Node.js 기반 빌드 도구를 통해 브라우저에서 Web SDK가 실행될 때 적용되지 않습니다.
</Callout>

Web SDK는 Node.js v18.17.0 이상에서 실행됩니다.

## 주요 기능

Univer Docs는 다음과 같은 기능을 지원합니다:

- **기본 문서 기능**: 단락 조정을 포함하여 가득 차있는 원본 유형 조정, 단락, 단락 정렬, indentation 및 거는, 및 punctuation 압축과 같은 in-paragraph 유형 조정, punctuations 거는, 특성 간격, 및 서쪽 단어 끊기.
- **머리글과 바닥글**
- **플로팅 이미지**
- **하이퍼링크**
- 그 밖의 다양한 기능

[제품 설명](/guides/docs/features/core)의 페이지는 각 기능을 상세히 설명합니다.

## 문서 읽는 방법

문서 탐색은 왼쪽에 있습니다. 페이지는 기본에서 고급으로 주문되므로 응용 프로그램을 구축하거나, 어떤 주문에 대해 읽거나, 케이스에 적용하는 섹션으로 건너 뛸 수 있습니다. 사이드바의 상단은 제품 문서 사이에 전환 할 수 있습니다.

오른쪽에 현재 페이지의 개요입니다. 섹션을 쉽게 이동할 수 있습니다. 페이지를 빠르게 찾으려면 상단 또는 검색 단축키 (Ctrl + K 또는 Cmd + K)에서 검색 막대를 사용하십시오.

Univer Docs에 새로운 경우 [빠른 시작](/guides/docs/getting-started/installation)로 시작합니다.

## 사전 지식

문서는 접근 할 수 있지만 여전히 기본을 가정하므로 Web SDK에 집중할 수 있습니다.

JavaScript의 기본 이해와 생태계는 문서에서 가장 많은 것을 얻을 수 있도록 도와줍니다.

Node.js에서 Web SDK를 실행할 계획이라면 Node.js의 기본 이해가 필요합니다.

[Univer Server SDK](/server)는 협업, 공유 역사 또는 의견 및 파일 변환에 대한 문서의 필요성을 제공합니다. 또한 인증, 권한, 저장 및 배포를 처리하는 응용 프로그램 백엔드에 이러한 모듈을 구성합니다. 브라우저에서 편집은 혼자서는 필요하지 않습니다.
