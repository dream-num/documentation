## IDocumentBody

`IDocumentBody` speichert den Hauptflussinhalt eines Univer Docs-Dokuments.

Der eigentliche Text wird in `dataStream` gespeichert. Stile und Strukturinformationen werden in parallelen Arrays gespeichert und über Indizes mit dem Text verknüpft.

### Eigenschaften

| Eigenschaft | Typ | Beschreibung |
| --- | --- | --- |
| dataStream | `string` | Einfacher Textstrom des Dokumentkörpers. Sonderzeichen kennzeichnen Absätze, Abschnittsumbrüche, Tabellen und benutzerdefinierte Blöcke. |
| textRuns? | `ITextRun[]` | Inline-Stilbereiche. |
| paragraphs? | `IParagraph[]` | Absatzmetadaten und Absatzstile. |
| sectionBreaks? | `ISectionBreak[]` | Abschnittswechselmetadaten. |
| customBlocks? | `ICustomBlock[]` | Plugin-definierte Blockplatzhalter. |
| tables? | `ICustomTable[]` | Tabellenmarkierungen im Dokumentkörper. Tabellendefinitionen befinden sich in `IDocumentData.tableSource`. |
| columnGroups? | `ICustomColumnGroup[]` | Spaltengruppenmarkierungen. |
| blockRanges? | `IDocumentBlockRange[]` | Strukturierte Blockbereiche wie Callout-, Zitat- und Codeblöcke. |
| customRanges? | `ICustomRange[]` | Spezielle Bereiche wie Hyperlinks, Felder, Lesezeichen, Kommentare, Erwähnungen und Plugin-definierte Bereiche. |
| customDecorations? | `ICustomDecoration[]` | Dekorationsbereiche wie Kommentarhervorhebungen. |
| payloads? | `Record<string, string>` | Temporäre Nutzlasten zum Kopieren/Einfügen. Dieses Feld wird nicht beibehalten. |

### dataStream

`dataStream` ist die Quelle der Wahrheit für den Haupttext. Ein Absatz endet normalerweise mit `\r\n`.

```typescript
const body: IDocumentBody = {
  dataStream: 'Title\r\nHello Univer\r\n',
  paragraphs: [
    { startIndex: 5, paragraphId: 'p-title' },
    { startIndex: 19, paragraphId: 'p-body' },
  ],
}
```

### Sonderzeichen

Einige Dokumentelemente werden durch Steuerzeichen in `dataStream` dargestellt und vom Renderer erweitert:

| Zeichen | Bedeutung |
| --- | --- |
| `\r\n` | Absatzumbruch |
| `\n` | Abschnittsumbruch |
| `\f` | Seitenumbruch |
| `\v` | Spaltenumbruch |
| `\t` | Tab |
| `\0` | Dokumentende |
| `\b` | Benutzerdefinierter Blockplatzhalter |

Tabellen und benutzerdefinierte Bereiche verwenden intern auch Steuerzeichen. Wenn Sie mit Tabellen, Links, Kommentaren und Funktionen auf Blockebene arbeiten, bevorzugen Sie Facade-APIs oder -Befehle statt handschriftlicher Steuerzeichen.

## Beziehung mit IDocumentData

`IDocumentBody` speichert nur den Hauptdokumentfluss. Externe Ressourcen werden auf `IDocumentData` gespeichert:

- `tableSource` speichert Tabellendefinitionen.
- `drawings` speichert Bild- und Zeichnungsobjekte.
- `headers` und `footers` enthalten jeweils ihre eigenen `IDocumentBody`.
- `lists` speichert Listendefinitionen, auf die durch Absatzaufzählungszeichen verwiesen wird.
- `resources` speichert Plugin-definierte Daten.
