## 基於索引的模型

Univer Docs 不把富文字儲存為巢狀樹。純文字儲存在 `body.dataStream`[^utf16-offsets] 中，樣式和結構透過下標範圍附加到文字上。

最常見的下標結構如下：

- `ITextRun`：行內文字樣式範圍。
- `IParagraph`：段落中繼資訊與段落樣式。
- `ISectionBreak`：章節分隔符中繼資訊。

## ITextRun

`ITextRun` 描述一段連續文字的樣式。

| 屬性 | 類型 | 描述 |
| --- | --- | --- |
| st | `number` | **起始索引，包含該位置。** |
| ed | `number` | **結束索引，不包含該位置。** |
| sId? | `string` | 引用的樣式 ID。 |
| ts? | `ITextStyle` | 行內文字樣式物件。 |

```typescript
const body: IDocumentBody = {
  dataStream: '你好 Univer\r\n',
  textRuns: [
    {
      st: 0,
      ed: 2,
      ts: { bl: 1 },
    },
    {
      st: 3,
      ed: 9,
      ts: { cl: { rgb: '#2563eb' } },
    },
  ],
}
```

在上面的範例中，`你好` 為粗體，`Univer` 為藍色。段落分隔符 `\r\n` 不包含在樣式範圍內。

## IParagraph

`IParagraph` 描述段落級元資訊。`startIndex` 指向 `dataStream` 中的段落分隔符。

| 屬性 | 類型 | 描述 |
| --- | --- | --- |
| startIndex | `number` | 段落分隔符所在索引。 |
| paragraphId | `string` | 穩定的段落 ID。 |
| paragraphStyle? | `IParagraphStyle` | 段落樣式，例如對齊、縮排、行距和標題型別。 |
| bullet? | `IBullet` | 清單標記中繼資訊。 |

```typescript
const body: IDocumentBody = {
  dataStream: '你好 Univer\r\n第二行\r\n',
  paragraphs: [
    {
      startIndex: 9,
      paragraphId: 'p-1',
      paragraphStyle: {
        namedStyleType: NamedStyleType.HEADING_1,
      },
    },
    {
      startIndex: 14,
      paragraphId: 'p-2',
    },
  ],
}
```

### 段落內的單字換行 [#word-wrap]

`paragraphStyle.wordWrap` 由段落設定中的**允許西文在單詞中間換行**控制。`BooleanNumber.TRUE` 允許單詞跨行拆分，`BooleanNumber.FALSE` 保持單詞完整。該值缺失時，先繼承所引用段落樣式的值，再繼承 `documentStyle.defaultParagraphStyle` 的值；兩處均未設定時不拆分單詞。`@univerjs/core` 的 `resolveDocumentParagraphWordWrap(document, paragraph)` 返回生效值，且不會把繼承得到的預設值寫入快照。該設定不影響 Sheets 單元格的換行。DOCX 的 `w:wordWrap` 儲存的是相反的表示，不要直接複製其 XML 值。

## ISectionBreak

`ISectionBreak` 同樣透過下標把章節級設定附加到文字流上。它可以為某個章節覆蓋頁面大小、頁邊距、頁首頁尾、分欄和文字方向。

```typescript
const body: IDocumentBody = {
  dataStream: '第一節\n第二節\r\n',
  sectionBreaks: [
    {
      startIndex: 3,
      pageSize: { width: 595, height: 842 },
      marginTop: 72,
      marginBottom: 72,
    },
  ],
}
```

## 注意事項

- 下標必須與 `dataStream` 對齊。下標錯誤會導致樣式範圍、段落、選區或渲染不同步。
- 編輯執行中的文件時，優先使用 Facade API 和命令。
- 手動構造快照時，先構造 `dataStream`，再根據該字串計算樣式範圍和段落位置。

[^utf16-offsets]: 文字偏移以 JavaScript 的 UTF-16 程式碼單元計數，不是可見字元數，例如 `"😀".length` 為 2。文字樣式範圍為 `[st, ed)`，包含 `st`、不包含 `ed`，不可套用工作表區域包含結束索引的規則。
