## Indexbasiertes Modell

Univer Docs speichert Rich Text nicht als verschachtelten Baum. Es speichert einfachen Text in `body.dataStream` und verwendet dann Indexbereiche, um dem Text Stil und Struktur zu verleihen.

Die gängigsten indexbasierten Strukturen sind:

- `ITextRun`: Inline-Textstilbereich.
- `IParagraph`: Absatzmetadaten und Absatzstil.
- `ISectionBreak`: Abschnittsumbruch Metadaten.

## ITextRun

`ITextRun` beschreibt den Stil eines fortlaufenden Textbereichs.

| Eigenschaft | Typ | Beschreibung |
| --- | --- | --- |
| st | `number` | Startindex, einschließlich. |
| ed | `number` | Endindex, exklusiv. |
| sId? | `string` | Referenzierte Stil-ID. |
| ts? | `ITextStyle` | Inline-Textstil Objekt. |

```typescript
const body: IDocumentBody = {
  dataStream: 'Hello Univer\r\n',
  textRuns: [
    {
      st: 0,
      ed: 5,
      ts: { bl: 1 },
    },
    {
      st: 6,
      ed: 12,
      ts: { cl: { rgb: '#2563eb' } },
    },
  ],
}
```

In diesem Beispiel ist `Hello` fett und `Univer` blau. Der Absatzumbruch `\r\n` ist nicht in den gestalteten Bereichen enthalten.

## IParagraph

`IParagraph` beschreibt Metadaten auf Absatzebene. `startIndex` verweist auf die Absatzumbruchposition in `dataStream`.

| Eigenschaft | Typ | Beschreibung |
| --- | --- | --- |
| startIndex | `number` | Index des Absatzumbruchs. |
| paragraphId | `string` | Stabile Absatz-ID. |
| paragraphStyle? | `IParagraphStyle` | Absatzstil wie Ausrichtung, Einzug, Zeilenabstand und Überschriftentyp. |
| bullet? | `IBullet` | Markierungsmetadaten auflisten. |

```typescript
const body: IDocumentBody = {
  dataStream: 'Hello Univer\r\nSecond line\r\n',
  paragraphs: [
    {
      startIndex: 12,
      paragraphId: 'p-1',
      paragraphStyle: {
        namedStyleType: NamedStyleType.HEADING_1,
      },
    },
    {
      startIndex: 25,
      paragraphId: 'p-2',
    },
  ],
}
```

## ISectionBreak

`ISectionBreak` verwendet außerdem einen Index, um Einstellungen auf Abschnittsebene mit dem Textstream zu verbinden. Es kann Seitengröße, Ränder, Kopf- und Fußzeilen, Spalten und Textrichtung für einen Abschnitt überschreiben.

```typescript
const body: IDocumentBody = {
  dataStream: 'First section\nSecond section\r\n',
  sectionBreaks: [
    {
      startIndex: 13,
      pageSize: { width: 595, height: 842 },
      marginTop: 72,
      marginBottom: 72,
    },
  ],
}
```

## Hinweise

- Halten Sie die Indizes an `dataStream` ausgerichtet. Falsche Indizes können dazu führen, dass Stilbereiche, Absätze, Auswahlen oder das Rendering inkonsistent werden.
- Bevorzugen Sie Facade-APIs und -Befehle zum Bearbeiten eines aktiven Dokuments.
- Wenn Sie Snapshots manuell generieren, erstellen Sie zuerst `dataStream` und berechnen Sie dann Bereiche und Absatzpositionen aus dieser Zeichenfolge.
