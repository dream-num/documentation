## IDocumentBody

`IDocumentBody` 儲存 Univer Docs 文件的正文流內容。

文字內容本身儲存在 `dataStream` 中，樣式和結構資訊儲存在並列陣列裡，每一項透過下標與文字關聯。

### 屬性

| 屬性 | 類型 | 描述 |
| --- | --- | --- |
| dataStream | `string` | 正文的純文字。段落、章節、表格和自定義塊均用特殊字元標記。 |
| textRuns? | `ITextRun[]` | 行內樣式範圍。 |
| paragraphs? | `IParagraph[]` | 段落中繼資訊與段落樣式。 |
| sectionBreaks? | `ISectionBreak[]` | 章節分隔符中繼資訊。 |
| customBlocks? | `ICustomBlock[]` | 插件定義的區塊佔位符。 |
| tables? | `ICustomTable[]` | 正文中的表格標記。表格定義儲存在 `IDocumentData.tableSource` 中。 |
| columnGroups? | `ICustomColumnGroup[]` | 分欄群組標記。 |
| blockRanges? | `IDocumentBlockRange[]` | 結構化塊範圍，例如 callout、quote 和 code block。 |
| customRanges? | `ICustomRange[]` | 超連結、欄位、書籤、評論、mention 以及外掛定義的範圍。 |
| customDecorations? | `ICustomDecoration[]` | 評論高亮等裝飾範圍。 |
| payloads? | `Record<string, string>` | 複製貼上用的臨時資料，不會被持久化。 |

### dataStream

`dataStream` 是正文文字的權威來源。段落通常以 `\r\n` 結束。

```typescript
const body: IDocumentBody = {
  dataStream: '標題\r\nHello Univer\r\n',
  paragraphs: [
    { startIndex: 2, paragraphId: 'p-title' },
    { startIndex: 16, paragraphId: 'p-body' },
  ],
}
```

### 特殊字元

部分元素在 `dataStream` 中以控制字元的形式儲存，渲染時再展開為對應元素：

| 字元 | 含義 |
| --- | --- |
| `\r\n` | 段落分隔符 |
| `\n` | 章節分隔符 |
| `\f` | 分頁符 |
| `\v` | 分欄符 |
| `\t` | Tab |
| `\0` | 文件結束符 |
| `\b` | 自訂區塊佔位符 |

表格和自定義範圍內部同樣使用控制字元。處理表格、連結、評論或塊級功能時，請使用 Facade API 或命令，不要手動寫入控制字元。

## 與 IDocumentData 的關係

`IDocumentBody` 只承載文件的正文流，其餘資源均儲存在 `IDocumentData` 上：

- `tableSource` 儲存表格定義。
- `drawings` 儲存圖片和繪圖物件。
- `headers` 和 `footers` 各自包含自己的 `IDocumentBody`。
- `lists` 儲存段落項目符號引用的清單定義。
- `resources` 儲存外掛定義的資料。
