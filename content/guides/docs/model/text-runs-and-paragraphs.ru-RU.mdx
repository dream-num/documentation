## Модель на основе индексов

Univer Docs не хранит богатый текст в виде вложенного дерева.Обычный текст хранится в `body.dataStream`[^utf16-offsets], а стили и структура прикрепляются к тексту через диапазоны индексов.

Наиболее распространенными структурами являются:

- `ITextRun`: диапазон стиля символов.
- `IParagraph`: метаданные и стиль абзаца.
- `ISectionBreak`: метаданные разрыва раздела.

## ITextRun

`ITextRun` описывает стиль одного непрерывного текстового диапазона.

| Свойство | Тип | Описание |
| --- | --- | --- |
| st | `number` | **Начальный индекс включительно.** |
| ed | `number` | **Конечный индекс не включительно.** |
| sId? | `string` | Идентификатор связанного стиля. |
| ts? | `ITextStyle` | Объект стиля символов. |

```typescript
const body: IDocumentBody = {
  dataStream: 'Hello Univer\r\n',
  textRuns: [
    {
      st: 0,
      ed: 5,
      ts: { bl: 1 },
    },
    {
      st: 6,
      ed: 12,
      ts: { cl: { rgb: '#2563eb' } },
    },
  ],
}
```

В этом примере `Hello` выделено полужирным, а `Univer` — синим цветом. Разрыв абзаца `\r\n` не входит в стилизованные диапазоны.

## IParagraph

`IParagraph` содержит метаданные уровня абзаца. `startIndex` указывает на разрыв абзаца в `dataStream`.

| Свойство | Тип | Описание |
| --- | --- | --- |
| startIndex | `number` | Индекс разрыва абзаца. |
| paragraphId | `string` | Стабильный идентификатор абзаца. |
| styleId? | `string` | Именованный стиль, на который ссылается абзац. |
| paragraphStyle? | `IParagraphStyle` | Стиль абзаца, например выравнивание, отступы, межстрочный интервал и тип заголовка. |
| bullet? | `Partial<IBullet> \| null` | Переопределение нумерации. Не задавайте его, чтобы наследовать нумерацию из именованного стиля, или задайте `null`, чтобы отключить нумерацию. |

```typescript
const body: IDocumentBody = {
  dataStream: 'Hello Univer\r\nSecond line\r\n',
  paragraphs: [
    {
      startIndex: 12,
      paragraphId: 'p-1',
      paragraphStyle: {
        namedStyleType: NamedStyleType.HEADING_1,
      },
    },
    {
      startIndex: 25,
      paragraphId: 'p-2',
    },
  ],
}
```

### Нумерация списков [#list-numbering]

Когда `bullet` не задан, абзац сохраняет нумерацию, определённую его именованным стилем. Задайте для `bullet` значение `null`, чтобы убрать нумерацию у этого абзаца, или задайте отдельные поля, например `nestingLevel`, чтобы переопределить часть унаследованного маркера.

Чтобы прочитать действующий список, используйте `resolveDocumentParagraphBullet(document, paragraph)` из `@univerjs/core`. Для абзаца без нумерации возвращается `undefined`. Унаследованные значения не записываются обратно в снимок.

```ts
import { resolveDocumentParagraphBullet } from '@univerjs/core'

const bullet = resolveDocumentParagraphBullet(document, paragraph)
if (bullet) {
  console.log(bullet.listType, bullet.nestingLevel)
}
```

### Перенос внутри слова [#word-wrap]

`paragraphStyle.wordWrap` контролируется параметром абзаца **Позвольте латинскому тексту обернуть в середине слова.**. `BooleanNumber.TRUE` позволяет слову делиться по строкам, а `BooleanNumber.FALSE` сохраняет каждое слово целым. Когда значение отсутствует, оно наследуется от стиля указанного абзаца сначала, затем от `documentStyle.defaultParagraphStyle`; если ни задает его, слова не разделяются. `resolveDocumentParagraphWordWrap(document, paragraph)` от `@univerjs/core` возвращает эффективное значение и не записывает унаследованные по умолчанию в снимок. Обертка ячеек листов не затрагивается. DOCX `w:wordWrap` хранит обратное, поэтому не копируйте его значение XML напрямую.

## ISectionBreak

`ISectionBreak` также использует индекс для прикрепления настроек уровня раздела к текстовому потоку. Он может переопределять размер страницы, поля, заголовки, нижние колонки, столбцы и направление текста для раздела.

```typescript
const body: IDocumentBody = {
  dataStream: 'First section\nSecond section\r\n',
  sectionBreaks: [
    {
      startIndex: 13,
      pageSize: { width: 595, height: 842 },
      marginTop: 72,
      marginBottom: 72,
    },
  ],
}
```

## Примечания

- Держите индексы выровненными с `dataStream`Неправильные индексы могут оставлять диапазоны стилей, абзацы, выборки или рендеринг из синхронизации.
- Предпочитает API и команды Facade при редактировании активного документа.
- Когда вы создаете снимки вручную, сначала создайте `dataStream`, а затем вычислите диапазоны и позиции абзацев из этой строки.

[^utf16-offsets]: Смещения измеряются в кодовых единицах UTF-16 JavaScript, а не видимых символах: `"😀".length` равно 2. Текстовый диапазон `[st, ed)` не включает конец, в отличие от диапазонов ячеек.
