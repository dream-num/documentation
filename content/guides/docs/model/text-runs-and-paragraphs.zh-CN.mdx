## 基于下标的模型

Univer Docs 不把富文本存储为嵌套树。纯文本存储在 `body.dataStream`[^utf16-offsets] 中，样式和结构通过下标范围附加到文本上。

最常见的下标结构如下：

- `ITextRun`：行内文本样式范围。
- `IParagraph`：段落元信息和段落样式。
- `ISectionBreak`：章节分隔符元信息。

## ITextRun

`ITextRun` 描述一段连续文本的样式。

| 属性 | 类型 | 描述 |
| --- | --- | --- |
| st | `number` | **起始下标，包含该位置。** |
| ed | `number` | **结束下标，不包含该位置。** |
| sId? | `string` | 引用的样式 ID。 |
| ts? | `ITextStyle` | 行内文本样式对象。 |

```typescript
const body: IDocumentBody = {
  dataStream: '你好 Univer\r\n',
  textRuns: [
    {
      st: 0,
      ed: 2,
      ts: { bl: 1 },
    },
    {
      st: 3,
      ed: 9,
      ts: { cl: { rgb: '#2563eb' } },
    },
  ],
}
```

在上面的示例中，`你好` 为粗体，`Univer` 为蓝色。段落分隔符 `\r\n` 不包含在样式范围内。

## IParagraph

`IParagraph` 描述段落级元信息。`startIndex` 指向 `dataStream` 中的段落分隔符。

| 属性 | 类型 | 描述 |
| --- | --- | --- |
| startIndex | `number` | 段落分隔符所在下标。 |
| paragraphId | `string` | 稳定的段落 ID。 |
| paragraphStyle? | `IParagraphStyle` | 段落样式，例如对齐、缩进、行距和标题类型。 |
| bullet? | `IBullet` | 列表标记元信息。 |

```typescript
const body: IDocumentBody = {
  dataStream: '你好 Univer\r\n第二行\r\n',
  paragraphs: [
    {
      startIndex: 9,
      paragraphId: 'p-1',
      paragraphStyle: {
        namedStyleType: NamedStyleType.HEADING_1,
      },
    },
    {
      startIndex: 14,
      paragraphId: 'p-2',
    },
  ],
}
```

### 段落内的单词换行 [#word-wrap]

`paragraphStyle.wordWrap` 由段落设置中的**允许西文在单词中间换行**控制。`BooleanNumber.TRUE` 允许单词跨行拆分，`BooleanNumber.FALSE` 保持单词完整。该值缺失时，先继承所引用段落样式的值，再继承 `documentStyle.defaultParagraphStyle` 的值；两处均未设置时不拆分单词。`@univerjs/core` 的 `resolveDocumentParagraphWordWrap(document, paragraph)` 返回生效值，且不会把继承得到的默认值写入快照。该设置不影响 Sheets 单元格的换行。DOCX 的 `w:wordWrap` 存储的是相反的表示，不要直接复制其 XML 值。

## ISectionBreak

`ISectionBreak` 同样通过下标把章节级设置附加到文本流上。它可以为某个章节覆盖页面大小、页边距、页眉页脚、分栏和文字方向。

```typescript
const body: IDocumentBody = {
  dataStream: '第一节\n第二节\r\n',
  sectionBreaks: [
    {
      startIndex: 3,
      pageSize: { width: 595, height: 842 },
      marginTop: 72,
      marginBottom: 72,
    },
  ],
}
```

## 注意事项

- 下标必须与 `dataStream` 对齐。下标错误会导致样式范围、段落、选区或渲染不同步。
- 编辑运行中的文档时，优先使用 Facade API 和命令。
- 手动构造快照时，先构造 `dataStream`，再根据该字符串计算样式范围和段落位置。

[^utf16-offsets]: 文本偏移按 JavaScript 的 UTF-16 代码单元计数，不是肉眼看到的字符数，例如 `"😀".length` 为 2。文本样式范围是 `[st, ed)`，包含 `st`、不包含 `ed`，不能套用工作表区域包含结束索引的规则。
