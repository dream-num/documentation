## IDocumentBody

`IDocumentBody` は Univer Docs ドキュメントの本文フローを保存します。

テキスト自体は`dataStream`に保存されます。スタイルと構造は並列配列で保存され、各エントリはインデックスによってテキストにリンクされます。

### プロパティ

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| dataStream | `string` | テキストとしてドキュメント ボディ。 特別な文字は、段落をマークします。セクションは、テーブル、カスタム ブロックを破ります。 |
| textRuns? | `ITextRun[]` | インラインスタイル範囲。 |
| paragraphs? | `IParagraph[]` | 段落メタデータと段落スタイル。 |
| sectionBreaks? | `ISectionBreak[]` | セクション区切りのメタデータ。 |
| customBlocks? | `ICustomBlock[]` | プラグイン定義のブロックプレースホルダー。 |
| tables? | `ICustomTable[]` | 文書ボディの表のマーカー。表の定義は`IDocumentData.tableSource`で貯えられます。 |
| columnGroups? | `ICustomColumnGroup[]` | カラムグループマーカー。 |
| blockRanges? | `IDocumentBlockRange[]` | callout、quote、code block などの構造化ブロック範囲。 |
| customRanges? | `ICustomRange[]` | ハイパーリンク、フィールド、ブックマーク、コメント、mention、プラグイン定義範囲。 |
| customDecorations? | `ICustomDecoration[]` | コメントハイライトなどの装飾範囲。 |
| payloads? | `Record<string, string>` | コピー/ペースト時の一時データ。永続化されません。 |

### dataStream

`dataStream`は、体テキストの権威的なソースです。 段落は通常、`\r\n`で終了します。

```typescript
const body: IDocumentBody = {
  dataStream: 'Title\r\nHello Univer\r\n',
  paragraphs: [
    { startIndex: 5, paragraphId: 'p-title' },
    { startIndex: 19, paragraphId: 'p-body' },
  ],
}
```

### 特殊文字

一部の要素は、`dataStream` の制御文字として保存され、レンダラーによって拡張されます。

| 文字 | 意味 |
| --- | --- |
| `\r\n` | 段落区切り |
| `\n` | セクション区切り |
| `\f` | ページ区切り |
| `\v` | カラム区切り |
| `\t` | タブ |
| `\0` | ドキュメント終端 |
| `\b` | カスタムブロックプレースホルダー |

表やカスタム範囲は、内部で制御文字を使用します。テーブル、リンク、コメント、またはブロックレベルの機能を扱う場合は、Facade API またはコマンドを使用して、制御文字を手で書き込む代わりに使用します。

## IDocumentData との関係

`IDocumentBody`は、主要な文書フローのみをカバーしています。 他のすべてのリソースは、`IDocumentData`に保存されます。

- `tableSource` はテーブル定義を保存します。
- `drawings` は画像や描画オブジェクトを保存します。
- `headers` と `footers` はそれぞれ独自の `IDocumentBody` を持ちます。
- `lists` は段落の箇条書きが参照するリスト定義を保存します。
- `resources` はプラグイン定義データを保存します。
