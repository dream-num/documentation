## IDocumentBody

`IDocumentBody` は Univer Docs ドキュメントの本文フローを保存します。

実際のテキストは `dataStream` に保存され、スタイルや構造情報は別の配列に保存されます。それらはテキストのインデックスによって関連付けられます。

### プロパティ

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| dataStream | `string` | 本文のプレーンテキストストリーム。段落、セクション、テーブル、カスタムブロックは特殊文字で表現されます。 |
| textRuns? | `ITextRun[]` | インラインスタイル範囲。 |
| paragraphs? | `IParagraph[]` | 段落メタデータと段落スタイル。 |
| sectionBreaks? | `ISectionBreak[]` | セクション区切りのメタデータ。 |
| customBlocks? | `ICustomBlock[]` | プラグイン定義のブロックプレースホルダー。 |
| tables? | `ICustomTable[]` | 本文内のテーブルマーカー。テーブル定義は `IDocumentData.tableSource` に保存されます。 |
| columnGroups? | `ICustomColumnGroup[]` | カラムグループマーカー。 |
| blockRanges? | `IDocumentBlockRange[]` | callout、quote、code block などの構造化ブロック範囲。 |
| customRanges? | `ICustomRange[]` | ハイパーリンク、フィールド、ブックマーク、コメント、mention、プラグイン定義範囲。 |
| customDecorations? | `ICustomDecoration[]` | コメントハイライトなどの装飾範囲。 |
| payloads? | `Record<string, string>` | コピー/ペースト時の一時データ。永続化されません。 |

### dataStream

段落は `\r`、セクションは `\n` で終わるため、セクションの最後の段落は通常 `\r\n` で終わります。`paragraphs[].startIndex` は `\r`、`sectionBreaks[].startIndex` は `\n` を指します。

```typescript
const body: IDocumentBody = {
  dataStream: 'Title\rHello Univer\r\n',
  paragraphs: [
    { startIndex: 5, paragraphId: 'p-title' },
    { startIndex: 18, paragraphId: 'p-body' },
  ],
  sectionBreaks: [{ startIndex: 19, sectionId: 's-main' }],
}
```

メタデータとともに `paragraphId`、`sectionId` を永続化してください。これらは文字位置が変わっても段落と従来型セクションを識別します。実行時操作と各概念の違いは [Docs API](/guides/docs/features/core/docs-api#document-identifiers)を参照してください。

### 特殊文字

一部のドキュメント要素は `dataStream` 内の制御文字で表現され、レンダラーによって対応する要素に変換されます。

| 文字 | 意味 |
| --- | --- |
| `\r` | 段落区切り |
| `\n` | セクション区切り |
| `\f` | ページ区切り |
| `\v` | カラム区切り |
| `\t` | タブ |
| `\0` | ドキュメント終端 |
| `\b` | カスタムブロックプレースホルダー |

テーブルやカスタム範囲も内部で制御文字を使用します。テーブル、リンク、コメント、ブロック機能を扱う場合は、制御文字を直接書くのではなく Facade APIを使用してください。

## IDocumentData との関係

`IDocumentBody` は本文フローのみを保存します。外部リソースは `IDocumentData` に保存されます。

- `tableSource` はテーブル定義を保存します。
- `drawings` は画像や描画オブジェクトを保存します。
- `headers` と `footers` はそれぞれ独自の `IDocumentBody` を持ちます。
- `lists` は段落の箇条書きが参照するリスト定義を保存します。
- `resources` はプラグイン定義データを保存します。
