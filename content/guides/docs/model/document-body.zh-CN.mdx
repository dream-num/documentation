## IDocumentBody

`IDocumentBody` 保存 Univer Docs 文档的正文流内容。

文本内容本身存储在 `dataStream` 中，样式和结构信息存储在并列数组里，每一项通过下标与文本关联。

### 属性

| 属性 | 类型 | 描述 |
| --- | --- | --- |
| dataStream | `string` | 正文的纯文本。段落、章节、表格和自定义块均用特殊字符标记。 |
| textRuns? | `ITextRun[]` | 行内样式范围。 |
| paragraphs? | `IParagraph[]` | 段落元信息和段落样式。 |
| sectionBreaks? | `ISectionBreak[]` | 章节分隔符元信息。 |
| customBlocks? | `ICustomBlock[]` | 插件定义的块占位符。 |
| tables? | `ICustomTable[]` | 正文中的表格标记。表格定义存储在 `IDocumentData.tableSource` 中。 |
| columnGroups? | `ICustomColumnGroup[]` | 分栏组标记。 |
| blockRanges? | `IDocumentBlockRange[]` | 结构化块范围，例如 callout、quote 和 code block。 |
| customRanges? | `ICustomRange[]` | 超链接、字段、书签、评论、mention 以及插件定义的范围。 |
| customDecorations? | `ICustomDecoration[]` | 评论高亮等装饰范围。 |
| payloads? | `Record<string, string>` | 复制粘贴用的临时数据，不会被持久化。 |

### dataStream

`dataStream` 是正文文本的权威来源。段落通常以 `\r\n` 结束。

```typescript
const body: IDocumentBody = {
  dataStream: '标题\r\nHello Univer\r\n',
  paragraphs: [
    { startIndex: 2, paragraphId: 'p-title' },
    { startIndex: 16, paragraphId: 'p-body' },
  ],
}
```

### 特殊字符

部分元素在 `dataStream` 中以控制字符的形式存储，渲染时再展开为对应元素：

| 字符 | 含义 |
| --- | --- |
| `\r\n` | 段落分隔符 |
| `\n` | 章节分隔符 |
| `\f` | 分页符 |
| `\v` | 分栏符 |
| `\t` | 制表符 |
| `\0` | 文档结束符 |
| `\b` | 自定义块占位符 |

表格和自定义范围内部同样使用控制字符。处理表格、链接、评论或块级功能时，请使用 Facade API 或命令，不要手动写入控制字符。

## 与 IDocumentData 的关系

`IDocumentBody` 只承载文档的正文流，其余资源均存储在 `IDocumentData` 上：

- `tableSource` 存储表格定义。
- `drawings` 存储图片和绘图对象。
- `headers` 和 `footers` 各自包含自己的 `IDocumentBody`。
- `lists` 存储段落项目符号引用的列表定义。
- `resources` 存储插件定义的数据。
