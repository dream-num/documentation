## IDocumentData

[`IDocumentData`](https://reference.univer.ai/en-US/interfaces/IDocumentData) ist das von Univer Docs verwendete Snapshot-Format.

Es beschreibt eine vollständige Dokumenteinheit, einschließlich Textkörper, Stil auf Dokumentebene, Kopf- und Fußzeilen, Zeichnungen, Listen, Tabellen und Plugin Ressourcen.

### Eigenschaften

| Eigenschaft | Typ | Beschreibung |
| --- | --- | --- |
| id | `string` | Eindeutige Dokumenteinheiten-ID. |
| rev? | `number` | Dokumentrevision, Wird bei der gemeinsamen Bearbeitung verwendet. |
| locale? | `LocaleType` | Gebietsschema des Dokuments. |
| title? | `string` | Dokumenttitel. |
| body? | `IDocumentBody` | Rich-Text-Haupttext. [Details](/guides/docs/model/document-body) |
| documentStyle | `IDocumentStyle` | Seiten-, Layout-, Kopf-/Fußzeilen- und Standardtextstileinstellungen auf Dokumentebene. |
| settings? | `IDocumentSettings` | Laufzeiteinstellungen wie `zoomRatio`. |
| resources? | `IResources` | Plugin-Ressourcen. |
| disabled? | `boolean` | Ob das Dokument deaktiviert ist. |
| headers? | `IHeaders` | Kopfzeilenkörper nach Kopfzeilen-ID verschlüsselt. |
| footers? | `IFooters` | Fußzeilenkörper nach Fußzeilen-ID verschlüsselt. |
| lists? | `ILists` | Vom Absatz verwendete Definitionen auflisten Aufzählungszeichen. |
| drawings? | `IDrawings` | Zeichnungsobjekte wie Bilder. |
| drawingsOrder? | `string[]` | Renderreihenfolge von Zeichnungen. |
| tableSource? | `ITables` | Tabellendefinitionen, auf die der Dokumentkörper verweist. |

### Beispiel

```typescript
const documentData: IDocumentData = {
  id: 'doc-1',
  title: 'Demo Document',
  locale: LocaleType.EN_US,
  body: {
    dataStream: 'Hello Univer\r\n',
    textRuns: [
      {
        st: 0,
        ed: 12,
        ts: { fs: 14 },
      },
    ],
    paragraphs: [
      {
        startIndex: 12,
        paragraphId: 'paragraph-1',
      },
    ],
  },
  documentStyle: {
    pageSize: { width: 595, height: 842 },
    marginTop: 72,
    marginBottom: 72,
    marginLeft: 72,
    marginRight: 72,
  },
}
```

### Verwendung

`IDocumentData` wird hauptsächlich verwendet für:

1. [Erstellen eines Univer Docs-Dokuments](/guides/docs/features/core/docs-api#create-document)
2. [Speichern eines Univer Docs-Dokuments snapshot](/guides/docs/features/core/docs-api#get-document-data)
3. [Importieren oder Exportieren von `.docx`-Dateien](/guides/docs/features/import-export)
4. Speichern von Rich Text in Sheets-Zellen bis `ICellData.p`

<Callout type="warning">
Ein Snapshot ist ein persistenter Snapshot Datenstruktur. Ändern Sie es nicht direkt nach der Ausführung eines Dokuments. Verwenden Sie Facade-APIs oder Befehle, um Dokumentinhalte zu ändern.
</Callout>
