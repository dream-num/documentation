## 인덱스 기반 모델

Univer Docs는 배열된 나무로 부유한 원본을 저장하지 않습니다. 보통 원본은 `body.dataStream`[^utf16-offsets]에서 저장되고, 작풍 및 구조는 색인 범위를 통해서 텍스트에 붙어 있습니다.

가장 일반적인 구조는:

- `ITextRun`: 인라인 텍스트 스타일 범위입니다.
- `IParagraph`: 단락 메타데이터와 단락 스타일입니다.
- `ISectionBreak`: 구역 나누기 메타데이터입니다.

## ITextRun

`ITextRun`는 1개의 지속적인 원본 범위의 작풍을 설명합니다.

| 속성 | 타입 | 설명 |
| --- | --- | --- |
| st | `number` | **시작 인덱스이며, 해당 위치를 포함합니다.** |
| ed | `number` | **끝 인덱스이며, 해당 위치를 포함하지 않습니다.** |
| sId? | `string` | 참조되는 스타일 ID입니다. |
| ts? | `ITextStyle` | 인라인 텍스트 스타일 객체입니다. |

```typescript
const body: IDocumentBody = {
  dataStream: 'Hello Univer\r\n',
  textRuns: [
    {
      st: 0,
      ed: 5,
      ts: { bl: 1 },
    },
    {
      st: 6,
      ed: 12,
      ts: { cl: { rgb: '#2563eb' } },
    },
  ],
}
```

이 예제에서는 `Hello`가 굵게 표시되고 `Univer`가 파란색으로 표시됩니다. 단락 나누기 `\r\n`은 스타일 범위에 포함되지 않습니다.

## IParagraph

`IParagraph`는 단락 수준의 메타 데이터를 보유하고 있습니다. `startIndex` 포인트는 `dataStream`의 단락에 있습니다.

| 속성 | 타입 | 설명 |
| --- | --- | --- |
| startIndex | `number` | 단락 나누기의 인덱스입니다. |
| paragraphId | `string` | 안정적인 단락 ID입니다. |
| styleId? | `string` | 단락이 참조하는 명명된 스타일입니다. |
| paragraphStyle? | `IParagraphStyle` | 맞춤, 들여쓰기, 줄 간격, 제목 유형과 같은 단락 스타일입니다. |
| bullet? | `Partial<IBullet> \| null` | 번호 매기기 재정의입니다. 생략하면 명명된 스타일에서 번호 매기기를 상속하고, `null`로 설정하면 번호 매기기를 끕니다. |

```typescript
const body: IDocumentBody = {
  dataStream: 'Hello Univer\r\nSecond line\r\n',
  paragraphs: [
    {
      startIndex: 12,
      paragraphId: 'p-1',
      paragraphStyle: {
        namedStyleType: NamedStyleType.HEADING_1,
      },
    },
    {
      startIndex: 25,
      paragraphId: 'p-2',
    },
  ],
}
```

### 목록 번호 매기기 [#list-numbering]

`bullet`을 생략하면 단락은 명명된 스타일에서 정의한 번호 매기기를 유지합니다. `bullet`을 `null`로 설정하면 해당 단락의 번호 매기기를 제거하고, `nestingLevel`과 같은 개별 필드를 설정하면 상속된 글머리 기호의 일부만 재정의합니다.

`@univerjs/core`의 `resolveDocumentParagraphBullet(document, paragraph)`로 적용된 목록을 읽습니다. 번호가 없는 단락에는 `undefined`를 반환하며, 상속된 값을 스냅샷에 다시 쓰지 않습니다.

```ts
import { resolveDocumentParagraphBullet } from '@univerjs/core'

const bullet = resolveDocumentParagraphBullet(document, paragraph)
if (bullet) {
  console.log(bullet.listType, bullet.nestingLevel)
}
```

### 문단 내 단어 줄 바꿈 [#word-wrap]

`paragraphStyle.wordWrap`는 단락 설정 **라틴어 텍스트가 단어의 중간에 포장 할 수 있습니다**에 의해 통제됩니다. `BooleanNumber.TRUE`는 선의 맞은편에 분할하는 낱말을 허용하고, `BooleanNumber.FALSE`는 각 낱말 전체를 지킵니다. 가치가 누락될 때, 그것은 참고된 단락 작풍에서, 그 후에 `documentStyle.defaultParagraphStyle`에서 상속합니다; 그것을 놓지 않는 경우에, 낱말은 분할되지 않습니다. `@univerjs/core`에서 `resolveDocumentParagraphWordWrap(document, paragraph)`는 효과적인 가치를 돌려보내고 스냅샷으로 상속한 과태를 쓰지 않습니다. DOCX `w:wordWrap`는 역을 저장합니다, 그래서 그것의 계산서를 직접 복사하지 않습니다.

## ISectionBreak

`ISectionBreak`는 또한 텍스트 스트림에 섹션 레벨 설정을 첨부하는 인덱스를 사용합니다. 섹션에 페이지 크기, 마진, 헤더, 발기, 열 및 텍스트 방향을 무시할 수 있습니다.

```typescript
const body: IDocumentBody = {
  dataStream: 'First section\nSecond section\r\n',
  sectionBreaks: [
    {
      startIndex: 13,
      pageSize: { width: 595, height: 842 },
      marginTop: 72,
      marginBottom: 72,
    },
  ],
}
```

## 참고

- `dataStream`로 정렬 된 인덱스를 유지하십시오. 잘못된 인덱스는 스타일 범위, 단락, 선택 또는 동기화에서 렌더링 할 수 있습니다.
- Prefer Facade APIs 및 명령은 활성화된 문서를 편집할 때.
- 손으로 스냅 샷을 만들 때 `dataStream`를 먼저 빌드 한 다음 그 문자열에서 범위와 단락 위치를 계산합니다.

[^utf16-offsets]: 텍스트 위치는 보이는 글자 수가 아닌 JavaScript UTF-16 코드 단위로 셉니다. 예를 들어 `"😀".length`는 2입니다. 텍스트 범위 `[st, ed)`는 끝을 포함하지 않으므로 시트 범위의 끝 포함 규칙과 다릅니다.
