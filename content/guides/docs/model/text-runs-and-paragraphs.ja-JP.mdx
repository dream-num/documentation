## インデックスベースのモデル

Univer Docsは、ネストされたツリーとしてリッチテキストを保存しません。 プレーンテキストは、`body.dataStream`[^utf16-offsets]に保存され、スタイルと構造はインデックス範囲を介してテキストに添付されます。

最もよくある構造は次のとおりです。

- `ITextRun`: インラインテキストスタイル範囲。
- `IParagraph`: 段落メタデータと段落スタイル。
- `ISectionBreak`: セクション区切りメタデータ。

## ITextRun

`ITextRun`は1つの連続的なテキスト レンジの様式を記述します。

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| st | `number` | **開始インデックス。この位置を含みます。** |
| ed | `number` | **終了インデックス。この位置は含みません。** |
| sId? | `string` | 参照するスタイル ID。 |
| ts? | `ITextStyle` | インラインテキストスタイル。 |

```typescript
const body: IDocumentBody = {
  dataStream: 'Hello Univer\r\n',
  textRuns: [
    {
      st: 0,
      ed: 5,
      ts: { bl: 1 },
    },
    {
      st: 6,
      ed: 12,
      ts: { cl: { rgb: '#2563eb' } },
    },
  ],
}
```

この例では、`Hello` が太字になり、`Univer` が青色になります。段落区切り `\r\n` はスタイル範囲に含まれません。

## IParagraph

`IParagraph`は段落レベルのメタデータを保持しています。 `startIndex`の段落の壊れ目では`dataStream`がポイントします。

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| startIndex | `number` | 段落区切りのインデックス。 |
| paragraphId | `string` | 安定した段落 ID。 |
| styleId? | `string` | 段落が参照する名前付きスタイル。 |
| paragraphStyle? | `IParagraphStyle` | 配置、インデント、行間、見出し種別などの段落スタイル。 |
| bullet? | `Partial<IBullet> \| null` | 番号付けの上書き。省略すると名前付きスタイルの番号付けを継承し、`null` を設定すると番号付けを無効にします。 |

```typescript
const body: IDocumentBody = {
  dataStream: 'Hello Univer\r\nSecond line\r\n',
  paragraphs: [
    {
      startIndex: 12,
      paragraphId: 'p-1',
      paragraphStyle: {
        namedStyleType: NamedStyleType.HEADING_1,
      },
    },
    {
      startIndex: 25,
      paragraphId: 'p-2',
    },
  ],
}
```

### リストの番号付け [#list-numbering]

`bullet` を省略すると、段落は名前付きスタイルで定義された番号付けを保持します。その段落から番号付けを削除するには `bullet` を `null` に設定します。`nestingLevel` などの個々のフィールドを設定すると、継承した箇条書きの一部だけを上書きできます。

`@univerjs/core` の `resolveDocumentParagraphBullet(document, paragraph)` で有効なリストを読み取ります。番号付けのない段落では `undefined` を返し、継承した値をスナップショットに書き戻しません。

```ts
import { resolveDocumentParagraphBullet } from '@univerjs/core'

const bullet = resolveDocumentParagraphBullet(document, paragraph)
if (bullet) {
  console.log(bullet.listType, bullet.nestingLevel)
}
```

### 段落内の単語の折り返し [#word-wrap]

`paragraphStyle.wordWrap` は **単語の途中でラテン語をラップできるようにする** の段落の設定によって制御されます。`BooleanNumber.TRUE` は単語がラインを渡る分裂することを割り当て、`BooleanNumber.FALSE` は各単語を全保ちます。 値が失われるとき、それは参照された段落様式から最初に、そして `documentStyle.defaultParagraphStyle` から継承します; 決してそれを置くなら、単語は分裂しません。 `@univerjs/core` からの `resolveDocumentParagraphWordWrap(document, paragraph)` は有効な価値を戻し、スナップショットに渡されたデフォルトを継承しません。 シートの細胞の包みは不満です。 DOCX `w:wordWrap` は逆に貯えます、従って XML 値を直接コピーしません。

## ISectionBreak

`ISectionBreak`は、テキストストリームにセクションレベルの設定を添付するためにインデックスを使用します。ページサイズ、マージン、ヘッダー、フッター、列、およびセクションのテキスト方向をオーバーライドできます。

```typescript
const body: IDocumentBody = {
  dataStream: 'First section\nSecond section\r\n',
  sectionBreaks: [
    {
      startIndex: 13,
      pageSize: { width: 595, height: 842 },
      marginTop: 72,
      marginBottom: 72,
    },
  ],
}
```

## 注意事項

- `dataStream` と整列するインデックスを保持します。 間違ったインデックスは、スタイル範囲、段落、選択、または同期からレンダリングを離れることができます。
- アクティブなドキュメントを編集するときに、Facade API とコマンドを優先します。
- 手でスナップショットを作成すると、まず `dataStream` をビルドし、その文字列から範囲と段落の位置を計算します。

[^utf16-offsets]: 文字位置は見た目の文字数ではなく JavaScript の UTF-16 コード単位で数えます。例えば `"😀".length` は 2 です。テキスト範囲は `[st, ed)` で終端を含まず、シート範囲の終端を含む規則とは異なります。
