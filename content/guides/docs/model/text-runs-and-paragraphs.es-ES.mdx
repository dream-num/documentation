## Modelo basado en índices

Univer Docs no almacena texto rico como árbol anidado. El texto plano se almacena en `body.dataStream`[^utf16-offsets], y los estilos y la estructura se adjuntan al texto a través de rangos de índice.

Las estructuras más comunes son:

- `ITextRun`: rango de estilos de texto en línea.
- `IParagraph`: metadatos de párrafo y estilo de párrafo.
- `ISectionBreak`: salto de sección metadatos.

## ITextRun

`ITextRun` describe el estilo de un rango de texto continuo.

| Propiedad | Tipo | Descripción |
| --- | --- | --- |
| st | `number` | **Índice inicial, inclusive.** |
| ed | `number` | **Índice final, exclusivo.** |
| sId? | `string` | ID de estilo referenciado. |
| ts? | `ITextStyle` | Estilo de texto en línea objeto. |

```typescript
const body: IDocumentBody = {
  dataStream: 'Hello Univer\r\n',
  textRuns: [
    {
      st: 0,
      ed: 5,
      ts: { bl: 1 },
    },
    {
      st: 6,
      ed: 12,
      ts: { cl: { rgb: '#2563eb' } },
    },
  ],
}
```

En este ejemplo, `Hello` está en negrita y `Univer` es azul. El salto de párrafo `\r\n` no está incluido en los rangos de estilo.

## IParagraph

`IParagraph` contiene metadatos a nivel de párrafo. `startIndex` señala en la pausa del párrafo en `dataStream`.

| Propiedad | Tipo | Descripción |
| --- | --- | --- |
| startIndex | `number` | Índice del salto de párrafo. |
| paragraphId | `string` | ID de párrafo estable. |
| paragraphStyle? | `IParagraphStyle` | Estilo de párrafo como alineación, sangría, interlineado y tipo de encabezado. |
| bullet? | `IBullet` | Metadatos del marcador de lista. |

```typescript
const body: IDocumentBody = {
  dataStream: 'Hello Univer\r\nSecond line\r\n',
  paragraphs: [
    {
      startIndex: 12,
      paragraphId: 'p-1',
      paragraphStyle: {
        namedStyleType: NamedStyleType.HEADING_1,
      },
    },
    {
      startIndex: 25,
      paragraphId: 'p-2',
    },
  ],
}
```

### Salto de línea dentro de una palabra [#word-wrap]

`paragraphStyle.wordWrap` está controlado por la fijación del párrafo **Permitir que el texto latino se envuelva en medio de una palabra**. `BooleanNumber.TRUE` permite una palabra para dividir en líneas, y `BooleanNumber.FALSE` guarda cada palabra entera. Cuando el valor se pierde, hereda del estilo de párrafo referencia primero, luego de `documentStyle.defaultParagraphStyle`; si ninguno lo establece, las palabras no se dividen. `resolveDocumentParagraphWordWrap(document, paragraph)` desde `@univerjs/core` devuelve el valor efectivo y no escribe predeterminados heredados en la instantánea. La envoltura de la celda de las hojas no se ve afectada. DOCX `w:wordWrap` almacena el inverso, así que no copie su valor XML directamente.

## ISectionBreak

`ISectionBreak` también utiliza un índice para adjuntar ajustes de nivel de sección a la secuencia de texto. Puede anular el tamaño de la página, márgenes, encabezados, pies, columnas y dirección de texto para una sección.

```typescript
const body: IDocumentBody = {
  dataStream: 'First section\nSecond section\r\n',
  sectionBreaks: [
    {
      startIndex: 13,
      pageSize: { width: 595, height: 842 },
      marginTop: 72,
      marginBottom: 72,
    },
  ],
}
```

## Notas

- Mantenga índices alineados con `dataStream`. Los índices erróneos pueden dejar rangos de estilo, párrafos, selecciones o renderizado fuera de sincronización.
- Preferir Facade APIs y comandos al editar un documento activo.
- Cuando usted construye instantáneas a mano, construir `dataStream` primero, luego computar rangos y posiciones de párrafo de esa cadena.

[^utf16-offsets]: Las posiciones cuentan unidades UTF-16 de JavaScript, no caracteres visibles: `"😀".length` es 2. Un intervalo de texto `[st, ed)` excluye el final, a diferencia de los rangos de celdas que lo incluyen.
