## Modèle fondé sur des index

Univer Docs ne stocke pas de texte riche comme un arbre imbriqué. Le texte simple est stocké dans `body.dataStream`[^utf16-offsets], et les styles et la structure sont attachés au texte à travers des gammes d'index.

Les structures les plus courantes sont les suivantes:

- `ITextRun` : plage de style de texte en ligne.
- `IParagraph` : métadonnées et style du paragraphe.
- `ISectionBreak` : métadonnées du saut de section.

## ITextRun

`ITextRun` décrit le style d'une plage de texte continue.

| Propriété | Type | Description |
| --- | --- | --- |
| st | `number` | **Index de début, inclus.** |
| ed | `number` | **Index de fin, exclu.** |
| sId? | `string` | ID du style référencé. |
| ts? | `ITextStyle` | Objet de style de texte en ligne. |

```typescript
const body: IDocumentBody = {
  dataStream: 'Hello Univer\r\n',
  textRuns: [
    {
      st: 0,
      ed: 5,
      ts: { bl: 1 },
    },
    {
      st: 6,
      ed: 12,
      ts: { cl: { rgb: '#2563eb' } },
    },
  ],
}
```

Dans cet exemple, `Hello` est en gras et `Univer` en bleu. Le saut de paragraphe `\r\n` n’est pas inclus dans les plages mises en forme.

## IParagraph

`IParagraph` détient des métadonnées au niveau du paragraphe. `startIndex` pointe à la rupture du paragraphe dans `dataStream`.

| Propriété | Type | Description |
| --- | --- | --- |
| startIndex | `number` | Index du saut de paragraphe. |
| paragraphId | `string` | ID stable du paragraphe. |
| paragraphStyle? | `IParagraphStyle` | Style du paragraphe, comme l’alignement, le retrait, l’interligne et le type de titre. |
| bullet? | `IBullet` | Métadonnées du marqueur de liste. |

```typescript
const body: IDocumentBody = {
  dataStream: 'Hello Univer\r\nSecond line\r\n',
  paragraphs: [
    {
      startIndex: 12,
      paragraphId: 'p-1',
      paragraphStyle: {
        namedStyleType: NamedStyleType.HEADING_1,
      },
    },
    {
      startIndex: 25,
      paragraphId: 'p-2',
    },
  ],
}
```

### Retour à la ligne au milieu d’un mot [#word-wrap]

`paragraphStyle.wordWrap` est contrôlé par le réglage du paragraphe **Permettre au texte latin de s'envelopper au milieu d'un mot**. `BooleanNumber.TRUE` permet à un mot de diviser les lignes, et `BooleanNumber.FALSE` garde chaque mot entier. Lorsque la valeur est manquante, il hérite du style de paragraphe référencé d'abord, puis de `documentStyle.defaultParagraphStyle`; si ni l'un ni l'autre ne le définit, les mots ne sont pas séparés. `resolveDocumentParagraphWordWrap(document, paragraph)` de `@univerjs/core` retourne la valeur effective et n'écrit pas les valeurs par défaut héritées dans l'instantané. `w:wordWrap` stocke l'inverse, donc ne copiez pas directement sa valeur XML.

## ISectionBreak

`ISectionBreak` utilise également un index pour fixer les paramètres de niveau de section au flux de texte. Il peut surcharger la taille de page, les marges, les en-têtes, les pied de page, des colonnes et la direction du texte pour une section.

```typescript
const body: IDocumentBody = {
  dataStream: 'First section\nSecond section\r\n',
  sectionBreaks: [
    {
      startIndex: 13,
      pageSize: { width: 595, height: 842 },
      marginTop: 72,
      marginBottom: 72,
    },
  ],
}
```

## Remarques

- Gardez les index alignés sur `dataStream`. Les index erronés peuvent laisser des plages de style, des paragraphes, des sélections ou un rendu hors de la synchronisation.
- Préférez les API et les commandes Facade lors de l'édition d'un document actif.
- Lorsque vous construisez des instantanés à la main, créez d'abord `dataStream`, puis calculez les plages et les positions des paragraphes à partir de cette chaîne.

[^utf16-offsets]: Les positions comptent les unités UTF-16 de JavaScript, pas les caractères visibles : `"😀".length` vaut 2. Une plage de texte `[st, ed)` exclut sa fin, contrairement aux plages de cellules dont les indices de fin sont inclusifs.
