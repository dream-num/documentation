## Univer Docs 是什麼

Univer 是一個用於構建生產力應用程式的全棧框架，Univer Docs 是 Univer 的電子文件元件。

Univer Docs 可以在瀏覽器和伺服器（Node.js）上執行，並且擁有靈活、可擴充和可客製化的特性，你可以用它構建各種應用程式，無論是簡單的文字錄入還是企業級的複雜排版。無論你是個人開發者還是團隊的一員，Univer Docs 都可以幫助你快速輕鬆地構建強大的基於電子文件的應用程式。

## 主要功能

Univer Docs 現在支援廣泛的功能，包括：

- **基本電子文件功能**：支援全文排版，包括段落設定，段前後間距、段落對齊、縮排和懸掛等，也包括段落中的排版能力，標點擠壓、標點懸掛、字偶間距、西文斷詞等。
- **頁首頁尾**
- **浮動圖片**
- **超連結**
- 以及更多...

請參閱 [功能](/guides/docs/features/core) 部分下的頁面以瞭解詳情。核心和主要功能在 [GitHub 上開源](https://github.com/dream-num/univer)並且支援免費使用。

## 如何使用這些文件

在螢幕的左側是文件導航欄。文件頁面按從基礎到高階的順序組織，你可以按照這個順序循序漸進地瞭解 Univer，或者跳到你感興趣的章節。你還可以在側邊欄的頂部切換 Univer Docs 的文件。

螢幕的右側是當前頁面的大綱。如果你需要快速找到頁面，可以使用頂部的搜尋欄或搜尋快捷鍵（Ctrl+K 或 Cmd+K）。

我們推薦從 [快速開始](/guides/docs/getting-started/quickstart) 出發瞭解 Univer。

## 前置知識

儘管我們已經盡力使得文件對新手也易於理解，但是我們必須假設你在開始閱讀之前已經瞭解了一些基礎知識，以便我們的文件可以專注於 Univer。

為了充分利用我們的文件，建議你對 JavaScript 及其生態系統有基本的瞭解。

如果你有興趣在 Node.js 上執行 Univer，你還應該對 Node.js 有基本的瞭解。

如果你想嘗試高階功能並部署 Univer Server，我們建議你對 Linux、Docker 和 Docker Compose（或 Kubernetes）有基本的瞭解。
