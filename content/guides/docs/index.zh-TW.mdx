## Univer Docs 是什麼

Univer Office SDK 是用於建置生產力應用的全棧框架。Univer Docs 是 Univer Office SDK 的電子文件編輯器，也是 Web SDK 中的 Docs 部分。它可以在瀏覽器和伺服器（Node.js）上執行。

Univer Docs 的編輯能力由 [Web SDK](/guides/sheets) 提供，覆蓋嵌入式編輯器和無介面內容處理。協同和檔案轉換由 [Server SDK](/server) 提供，[AI SDK](/ai) 則讓 Agent 能夠處理文件。

Univer Docs 支援擴充套件和定製。你可以用它建置從簡單文字錄入到複雜排版的各種應用，無論個人開發還是團隊協作。

## 瀏覽器相容性

Web SDK 的編譯目標是 Chrome 88，但這並不意味著所有主流環境都能得到完整支援。我們會盡量保證 Web SDK 在以下瀏覽器和 Node.js 環境中正常工作：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK 依賴 `Intl.Segmenter`。如果你的瀏覽器或執行時環境不支援它，請先新增對應的 polyfill。我們推薦 `@formatjs/intl-segmenter`。
</Callout>

遇到相容性問題時，請先嚐試對應的 polyfill。如果問題仍然存在，請[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 相容性

<Callout type="warning">
  以下內容僅適用於 Web SDK 本身在 Node.js 中執行的情況，不適用於透過基於 Node.js 的建置工具在瀏覽器中執行 Web SDK 的情況。
</Callout>

Web SDK 支援 Node.js v18.17.0 及之後的版本。

## 主要功能

Univer Docs 支援以下功能：

- **基本電子文件功能**：全文排版，包括段落設定、段前段後間距、段落對齊、縮排和懸掛，以及段內排版能力，例如標點擠壓、標點懸掛、字元間距和西文斷詞。
- **頁首頁尾**
- **浮動圖片**
- **超連結**
- 以及更多……

每項功能的詳細說明見[功能](/guides/docs/features/core)下的頁面。

## 如何使用這些文件

文件導航位於左側。頁面按從基礎到高階的順序排列，你可以按順序閱讀，也可以在建置應用時按需跳讀。側邊欄頂部還可切換產品文件。

右側是當前頁面的大綱，便於在各節之間跳轉。如需快速找到某個頁面，請使用頂部的搜尋欄或搜尋快捷鍵（Ctrl+K 或 Cmd+K）。

如果你是初次使用 Univer Docs，請從[快速開始](/guides/docs/getting-started/installation)入手。

## 前置知識

這套文件儘量照顧新手，但仍假設讀者具備一定基礎，以便內容能夠聚焦於 Web SDK。

對 JavaScript 及其生態的基本瞭解，有助於你充分利用這套文件。

如果你計劃在 Node.js 上執行 Web SDK，還需要對 Node.js 有基本瞭解。

協同、共享歷史或評論、檔案轉換所需的模組由 [Univer Server SDK](/server) 提供。你在業務後端中組合這些模組，同時由業務後端負責身分認證、權限、儲存和部署。僅在瀏覽器中編輯文件時，不需要這些模組。
