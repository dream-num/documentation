## Was ist Univer Docs

Univer ist ein Full-Stack-Framework zum Erstellen von Produktivitätsanwendungen, und Univer Docs ist die Dokumentkomponente von Univer.

Univer Docs kann sowohl im Browser als auch auf dem Server (Node.js) ausgeführt werden. Es ist äußerst flexibel, erweiterbar und anpassbar und kann zum Erstellen einer Vielzahl von Anwendungen verwendet werden, von der einfachen Texteingabe bis hin zum komplexen Satz. Egal, ob Sie ein einzelner Entwickler oder Teil eines Teams sind, Univer Docs kann Ihnen dabei helfen, schnell und einfach leistungsstarke dokumentbasierte Anwendungen zu erstellen.

## Highlights

Univer Docs unterstützt jetzt eine breite Palette von Funktionen, darunter:

- **Grundlegende Dokumentfunktionen**: Volltextsatz, einschließlich Absatz Einstellungen, Abstand vor und nach Absätzen, Absatzausrichtung, Einrückung und Hängen sowie Satzfunktionen innerhalb von Absätzen wie Interpunktionskomprimierung, Interpunktionshängen, Zeichenabstand und Umbrechen westlicher Wörter.
- **Kopf- und Fußzeile**
- **Floating Images**
- **Hyperlinks**
- und mehr...

Weitere Einzelheiten finden Sie auf den Seiten unter Abschnitt [Funktionen](/guides/docs/features/core). Die Kern- und Hauptfunktionen sind Open-Source auf [GitHub](https://github.com/dream-num/univer) und können kostenlos verwendet werden.

## So lesen Sie die Dokumentation

Auf der linken Seite des Bildschirms finden Sie die Navigationsleiste für Dokumente. Die Seiten der Dokumente sind der Reihe nach organisiert, von „einfach“ bis „erweitert“, sodass Sie ihnen beim Erstellen Ihrer Anwendung Schritt für Schritt folgen können. Sie können sie jedoch in beliebiger Reihenfolge lesen oder zu den Seiten springen, die für Ihren Anwendungsfall gelten. Sie können sich Univer Docs auch oben in der Seitenleiste ansehen.

Auf der rechten Seite des Bildschirms sehen Sie ein Inhaltsverzeichnis, das die Navigation zwischen den Abschnitten einer Seite erleichtert. Wenn Sie eine Seite schnell finden müssen, können Sie die Suchleiste oben oder die Suchverknüpfung (Strg+K oder Befehlstaste+K) verwenden.

Um zu beginnen, schauen Sie sich die Anleitung [Quick Start](/guides/docs/getting-started/quickstart) an.

## Erforderliche Kenntnisse

Obwohl unsere Dokumente anfängerfreundlich gestaltet sind, müssen wir eine Grundlage schaffen, damit die Dokumente bestehen bleiben können konzentriert sich auf Univer.

Um das Beste aus unseren Dokumenten herauszuholen, wird empfohlen, dass Sie über grundlegende Kenntnisse von JavaScript und seinem Ökosystem verfügen.

Wenn Sie daran interessiert sind, Univer auf Node.js auszuführen, sollten Sie auch über grundlegende Kenntnisse von Node.js verfügen.

Wenn Sie Univer Pro ausprobieren und Univer Server bereitstellen möchten, empfehlen wir Ihnen, über grundlegende Kenntnisse von Linux, Docker und Docker Compose (bzw Kubernetes).
