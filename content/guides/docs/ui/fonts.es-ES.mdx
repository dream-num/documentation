## Definición de estructura de fuentes

En Univer, la interfaz `IFontConfig` describe una fuente:

| Propiedad | Tipo | Descripción |
| --- | --- | --- |
| `value` | `string` | El identificador único de la fuente, generalmente la primera entrada en una fuente-familia CSS. |
| `label` | `string` | Clave de traducción. Si la clave no tiene traducción cuando se crea la instancia Univer, el valor suministrado se muestra sin cambios. |
| `category` | `FontCategory` | Categoría de fuentes, que agrupa fuentes en la UI. Opcional. |

<Callout>
  Univer no impide que los usuarios seleccionen una fuente que no está instalada. Si el cliente no tiene la fuente, el navegador sustituye su fuente predeterminada.
</Callout>

## Uso de fuentes personalizadas

El parámetro `customFontFamily` en `UniverUIPlugin` controla las opciones que ofrece el desplegable de fuentes.

`UniverUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | El elemento para montar o el DOM ID de ese elemento. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Añade estas fuentes al menú desplegable. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Añade estas fuentes al menú desplegable. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Nombre de la fuente en CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Nombre visible o clave de traducción. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Categoría: `sans-serif`, `serif`, `monospace`, `display` o `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Sustituye las fuentes integradas por la lista indicada. |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // Whether to override the default font list, defaults to false
    override: true,
  },
})
```

## API de Facade

Las fuentes no tienen que ser conocidas al iniciarse. El Facade API puede agregar nuevas fuentes al tiempo de ejecución, que se requiere cuando los recursos de fuentes se cargan de forma asincrónica.

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
