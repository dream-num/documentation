## Sistema de diseño

El sistema de diseño está construido en Tailwind CSS y define un conjunto de fichas de diseño. El motor de renderización y la capa de vista utilizan estas fichas, que mantiene su estilo consistente. Las fichas se definen en el paquete `@univerjs/themes`, por lo que cambiarlas cambia la apariencia de la aplicación.

## Componentes

La capa de vista consta de componentes React. Si una aplicación ya utiliza React, utilizando los componentes Univer o registrando los personalizados toma poco esfuerzo. React no es necesario para componentes personalizados, sin embargo: Univer también admite Vue (3.x) y componentes Web.

Los componentes básicos son proporcionados por el paquete `@univerjs/design` y componentes de iconos por el envase `@univerjs/icons`. Ambos pueden utilizarse fuera de Univer .

Los componentes personalizados suelen aparecer en uno de los siguientes lugares:

- Botones personalizados en el menú Ribbon o Contexto
- Paneles tales como la barra lateral o un popup que albergan el componente
- Un reemplazo para un componente incorporado
