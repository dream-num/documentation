## Structure d’une police

Dans Univer, l'interface `IFontConfig` décrit une police :

| Propriété | Type | Description |
| --- | --- | --- |
| `value` | `string` | L'identificateur unique de la police, généralement la première entrée dans une famille de polices CSS. |
| `label` | `string` | Clé de traduction. Si la clé n'a pas de traduction lorsque l'instance Univer est créée, la valeur fournie est affichée inchangée. |
| `category` | `FontCategory` | Catégorie de police, qui regroupe les polices dans l'interface utilisateur. Facultatif. |

<Callout>
  Univer n'empêche pas les utilisateurs de sélectionner une police qui n'est pas installée. Si le client n'a pas la police, le navigateur remplace sa police par défaut.
</Callout>

## Utiliser des polices personnalisées

Le paramètre `customFontFamily` sur `UniverUIPlugin` contrôle les options que le menu déroulant offre.

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | L'élément à monter ou l'ID DOM de cet élément. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Ajoute ces polices à la liste déroulante. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Ajoute ces polices à la liste déroulante. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Nom de la police utilisé en CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Nom affiché ou clé de traduction. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Catégorie parmi `sans-serif`, `serif`, `monospace`, `display` ou `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Remplace les polices intégrées par la liste fournie. |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // Whether to override the default font list, defaults to false
    override: true,
  },
})
```

## Facade API

Les polices n'ont pas à être connues au démarrage. Le Facade API peut ajouter de nouvelles polices à l'exécution, ce qui est nécessaire lorsque les ressources de police chargent asynchronement.

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
