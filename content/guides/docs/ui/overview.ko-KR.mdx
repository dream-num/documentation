## 디자인 시스템

디자인 시스템은 테일 윈드 CSS에 내장되어 디자인 토큰의 세트를 정의합니다. 렌더링 엔진과 전망 레이어는 이러한 토큰을 모두 사용하여 스타일링 일관성을 유지합니다. 토큰은 `@univerjs/themes` 패키지에 정의되어 있으므로 응용 프로그램의 모양을 변경합니다.

## 컴포넌트

전망 층은 React 성분으로 이루어져 있습니다. 신청이 이미 React를 사용하는 경우에, Univer 분대를 사용하여 또는 주문 하나가 조금 노력이 걸립니다. React는 주문 성분을 위해 요구되지 않습니다, 그러나: Univer에는 또한 Vue (3.x)와 웹 성분을 지원합니다.

기본 구성 요소는 `@univerjs/icons` 패키지에 의해 `@univerjs/design` 포장 및 아이콘 구성 요소에 의해 제공됩니다. 둘 다 Univer 밖에 사용할 수 있습니다.

사용자 정의 구성 요소는 다음과 같은 장소 중 하나에서 일반적으로 나타납니다 :

- 리본 또는 Context 메뉴의 사용자 정의 버튼
- 구성 요소를 호스트하는 Sidebar 또는 Popup과 같은 패널
- 내장 구성 요소에 대한 교체

다음 페이지는 등록 및 사용자 정의 구성 요소를 사용하는 방법을 설명합니다.
