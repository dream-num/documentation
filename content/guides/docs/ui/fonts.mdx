## Font structure definition

In Univer, the `IFontConfig` interface describes a font:

| Property | Type | Description |
| --- | --- | --- |
| `value` | `string` | The unique identifier of the font, usually the first entry in a CSS font-family. |
| `label` | `string` | Translation key. If the key has no translation when the Univer instance is created, the supplied value is shown unchanged. |
| `category` | `FontCategory` | Font category, which groups fonts in the UI. Optional. |

<Callout>
  Univer does not prevent users from selecting a font that is not installed. If the client does not have the font, the browser substitutes its default font.
</Callout>

## Using custom fonts

The `customFontFamily` parameter on `UniverUIPlugin` controls which options the font dropdown offers.

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Default | What it does |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | The element to mount into, or the DOM ID of that element. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Adds these font choices to the dropdown. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Adds these font choices to the dropdown. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Font family name used in CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Display name or translation key. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Font group. Use `sans-serif`, `serif`, `monospace`, `display`, or `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Replaces the built-in choices with the supplied list. |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // Whether to override the default font list, defaults to false
    override: true,
  },
})
```

## Facade API

Fonts do not have to be known at startup. The Facade API can add new fonts at runtime, which is required when font resources load asynchronously.

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
