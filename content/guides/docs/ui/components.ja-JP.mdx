Univerは、レンダー関数の引数としてコンポーネントを受け入れません。コンポーネントは、まず、Facade APIで、Univerがカスタムコンテンツをマウントする任意の場所で使用することができる前に、最初に登録する必要があります。

Facade API インスタンスがまだ使用できない場合は、[Facade API](/guides/docs/getting-started/facade)を参照してください。

## カスタムコンポーネントの登録

```typescript
// [!code word:componentKey]
// [!code word:CustomComponent]
// [!code word:options]
univerAPI.registerComponent(componentKey, CustomComponent, options)
```

`univerAPI.registerComponent`を使用してカスタムコンポーネントを登録します。このメソッドは3つのパラメーターを受け入れます。

- `componentKey`: コンポーネントの固有の識別子で、Univer は後で参照するために使用します。
- `CustomComponent`: Reactコンポーネント、Vue コンポーネント、または Web コンポーネントであるコンポーネントの実装。
- `options`: コンポーネントのフレームワークなど、オプションの設定は依存します。

### React コンポーネント [#react]

React コンポーネントは追加のセットアップを必要としません。有効な Reactコンポーネントは登録できます。

```tsx
function ReactComponent(props: Record<string, any>) {
  return <div>Hello Univer!</div>
}

univerAPI.registerComponent('MyReactComponent', ReactComponent)
```

### Vue コンポーネント [#vue]

#### Vue 3.x

Vueコンポーネントはアダプターが必要です。`@univerjs/ui-adapter-vue3`から`UniverVue3AdapterPlugin`をインストールして登録します。

```package-install
npm install @univerjs/ui-adapter-vue3
```

```typescript
import { UniverVue3AdapterPlugin } from '@univerjs/ui-adapter-vue3'

univer.registerPlugin(UniverVue3AdapterPlugin)
```

Vue コンポーネントが登録されている場合、`framework` オプションを `'vue3'` に設定します。

```tsx
const Vue3Component = defineComponent({
  setup(props) {
    return () => <div>Hello Univer!</div>
  },
})

univerAPI.registerComponent('MyVue3Component', Vue3Component, {
  // [!code word:vue3]
  framework: 'vue3',
})
```

#### Vue 2.x

Vue 2.x は EOL (生命の終端) であり、もはや維持されないので、Univer は UI のアダプター プラグインを提供していません。カスタム プラグインは、代わりにアダプターを実装できます。次の例は 1 つの実装を示しています。

```typescript title="ui-adapter-vue2.ts"
import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
import { ComponentManager, UniverUIPlugin } from '@univerjs/ui'
import Vue from 'vue'

/**
 * Univer が Vue 2 コンポーネントを UI コンポーネントとして使用できるようにするプラグイン。
 */
@DependentOn(UniverUIPlugin)
export class UniverVue2AdapterPlugin extends Plugin {
  static override pluginName = 'UNIVER_UI_VUE2_ADAPTER_PLUGIN'

  constructor(
    private readonly _config = {},
    @Inject(Injector) protected readonly _injector: Injector,
    @Inject(ComponentManager) protected readonly _componentManager: ComponentManager,
  ) {
    super()
  }

  override onStarting(): void {
    const { createElement, useEffect, useRef } = this._componentManager.reactUtils

    this._componentManager.setHandler('vue2', (component: any) => {
      return (props: Record<string, any>) =>
        createElement(VueComponentWrapper, {
          component,
          props: Object.keys(props).reduce<Record<string, any>>((acc, key) => {
            if (key !== 'key') {
              acc[key] = props[key]
            }
            return acc
          }, {}),
          reactUtils: { createElement, useEffect, useRef },
        })
    })
  }
}

export function VueComponentWrapper(options: {
  component: any
  props: Record<string, any>
  reactUtils: typeof ComponentManager.prototype.reactUtils
}) {
  const { component, props, reactUtils } = options
  const { createElement, useEffect, useRef } = reactUtils

  const domRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!domRef.current) return

    const Constructor = Vue.extend(component)

    const instance = new Constructor({
      data: props,
    })
    instance.$mount()

    domRef.current.appendChild(instance.$el)

    return () => {
      instance.$destroy()
    }
  }, [props])

  return createElement('div', { ref: domRef })
}
```

プラグインを登録します。

```typescript
import { UniverVue2AdapterPlugin } from './ui-adapter-vue2' // [!code ++]

univer.registerPlugin(UniverUIPlugin)
univer.registerPlugin(UniverVue2AdapterPlugin) // [!code ++]
```

Vue 2.xコンポーネントは、`framework`オプションを`'vue2'`に設定する必要があります。

```tsx
const Vue2Component = Vue.component('MyVue2Component', {
  template: '<div>Hello, Univer!</div>',
})

univerAPI.registerComponent('MyVue2Component', Vue2Component, {
  // [!code word:vue2]
  framework: 'vue2',
})
```

### Web Components [#web-component]

Web コンポーネントは Web コンポーネントの標準に従う必要があります。`@univerjs/ui-adapter-web-component` から `UniverWebComponentAdapterPlugin`をインストールし、登録します。

```package-install
npm install @univerjs/ui-adapter-web-component
```

```typescript
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

univer.registerPlugin(UniverWebComponentAdapterPlugin)
```

Web コンポーネントが登録されている場合、`framework` オプションを `'web-component'` に設定します。

```tsx
class WebComponent extends HTMLElement {
  constructor() {
    super()
    const shadow = this.attachShadow({ mode: 'open' })
    const div = document.createElement('div')
    div.textContent = 'Hello Univer!'
    shadow.appendChild(div)
  }
}

univerAPI.registerComponent('my-web-component', WebComponent, {
  // [!code word:web-component]
  framework: 'web-component',
})
```

### Angular [#angular]

`@angular/elements`から`createCustomElement`のカスタム要素にAngularコンポーネントを変換し、Univer Webコンポーネントアダプタを介して要素を登録します。 コンポーネントは、Univerサイドバーまたはダイアログで使用できます。

`@angular/elements` は、`@angular/core`, `@univerjs/ui-adapter-web-component`と同じバージョンで他の Univer パッケージと同じバージョンに保管します。

Univer が初期化され、ホストコンポーネントの Angular のインジェクタを渡した後、関数を呼び出します。`private readonly injector = inject(Injector)` でインジェクタを取得し、`registerAngularPanel(univer, univerAPI, this.injector)` を呼び出す。ホストコンポーネントは `inject` と `Injector` を `@angular/core` からインポートします。

```typescript title="angular-panel.ts"
import type { Injector } from '@angular/core'
import type { FUniver, Univer } from '@univerjs/presets'
import { Component } from '@angular/core'
import { createCustomElement } from '@angular/elements'
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

@Component({
  selector: 'app-angular-panel',
  standalone: true,
  template: '<p>Hello from Angular!</p>',
})
export class AngularPanelComponent {}

export function registerAngularPanel(univer: Univer, univerAPI: FUniver, injector: Injector) {
  const element = createCustomElement(AngularPanelComponent, { injector })

  univer.registerPlugin(UniverWebComponentAdapterPlugin)
  return univerAPI.registerComponent('univer-angular-panel', element, {
    framework: 'web-component',
  })
}
```

エディターの描画後、登録したキーをサイドバーの内容として指定します。

```typescript
const sidebar = univerAPI.openSidebar({
  header: { title: 'Angular' },
  children: { label: 'univer-angular-panel' },
  width: 360,
})
```

返された登録とサイドバーのハンドルを保持し、必要なくない場合、それぞれに`dispose()`を呼び出します。 一度にエレメントを登録します。 その名前にはハイフンが含まれており、Angularコンポーネントセレクターとは異なる必要があります。

Angular Elements は、要素のプロパティと出力を DOM `CustomEvent` イベントにマップします。 Univerアダプタはプロパティを設定しますが、Angular出力には購読しません。 アプリケーションは、必要なときにそれらのイベントを購読します。

## カスタムコンポーネントの使用

以下の方法は、Univer UI でカスタムコンポーネントを配置する一般的な方法をカバーします。

<Callout type="warning" title="注意事項">
  1. これらのメソッドを呼び出す前に、Univerがレンダリングを終了するまで待ちます。 2. 使用する前に登録が必要なコンポーネントを登録します。 3. 追加のコンポーネントをクリーンアップおよび削除するために`dispose()`を呼び出す; それ以外のアプリケーションはメモリを漏洩させます。
</Callout>

### カスタムメニューアイテムの追加

上部メニューバー(Ribbon)と右クリックメニュー(Context Menu)は、カスタムコンポーネントを含むことができます。メニュー項目にコンポーネントを追加するには、カスタムプラグインが必要です。

### 組み込みコンポーネントの置き換え

<Callout type="error" title="インフォメーション">
  組み込みコンポーネントの置き換えは、それに依存する他の機能を破ることができます。 コンポーネントを交換する前にソースコードとドキュメントを読んで、注意を払ってください。
</Callout>

`univerAPI.registerComponent` は、デフォルトでオーバーライド (`override: true`) を登録します。オーバーライドは、プラグインがこのコールの前後にデフォルトを登録するかどうか、組み込みコンポーネントに優先されます。オーバーライドの 1 つだけは `componentKey` ごとにアクティブにすることができますので、別の登録を行う前に、以前の登録を解除します。 1 つが登録されている場合、リターンされた登録で`dispose()` を呼び出すと、ビルトインのデフォルトが復元されます。代わりに、`{ override: false }` を渡します。

対応するビューが初めて開く前にオーバーライドを登録します。登録の変更は、既にインストールされているビューを自動的に再レンダーしません。

例えば、組み込みのColorPickerコンポーネントを交換するには、シングルコールが必要です。

```tsx
// Following code only replaces the UI of the built-in ColorPicker component, not its functionality
univerAPI.registerComponent('UI_COLOR_PICKER_COMPONENT', () => <input type="color" />)
```

### ユーザー情報のレンダリングを置き換える

`@univerjs/ui` は `UserInfo` を通じてユーザー名とアバターをレンダリングします。`UserInfo` は `USER_INFO_COMPONENT` に登録されたコンポーネントを通じてレンダリングし、登録がない場合は `DefaultUserInfo` にフォールバックします。対応するビューが開く前にホストコンポーネントを登録します。

```tsx
import { USER_INFO_COMPONENT } from '@univerjs/ui'
import type { IUserInfoProps } from '@univerjs/ui'

function HostUserInfo({ user, part, context, className, fallbackSrc }: IUserInfoProps) {
  if (part === 'avatar') {
    return <img className={className} src={user.avatar ?? fallbackSrc} alt="" />
  }

  return (
    <span className={className} data-user-id={user.userId} data-scene={context.scene}>
      {user.name ?? user.userId}
    </span>
  )
}

univerAPI.registerComponent(USER_INFO_COMPONENT, HostUserInfo)
```

`UserInfo` は次のフィールドを渡します。

- `user`: `{ userId?, name?, avatar?, isAnonymous? }`。`userId` はソースのユーザー識別子であり、プロフィールの読み込み前から利用でき、コラボレーションのセッション ID ではありません。
- `part`: `'name'` または `'avatar'`。コンポーネントは各部分を個別にレンダリングします。
- `context`: `{ scene, unitId?, subUnitId?, commentId?, threadId?, versionId?, objectId?, tableId?, fieldId?, recordId? }`。`scene` は `'comment-author'`、`'history-author'`、`'history-filter'`、`'permission-member'`、`'permission-creator'`、`'base-person'` のいずれかです。関連するドキュメントを持たない独立したコントロールでは `unitId` は指定されません。
- `avatarSize?`、`fallbackSrc?`、`className?`: アバターと名前要素の任意のレンダリングヒント。

`DefaultUserInfo` は組み込みの名前とアバターをレンダリングし、ホストがカスタマイズしないシーンに使用できます。`inheritUserInfoComponent(source, target)` は、ソースの `ComponentManager` のユーザー情報コンポーネントを別のコンポーネントマネージャー（履歴やプレビュー用の子 `Univer` インスタンスなど）に登録し、同じオーバーライドをそこでも適用します。ソースにユーザー情報コンポーネントがない場合は `DefaultUserInfo` を登録します。

このオーバーライドはレンダリングのみを変更します。保存済みのメンション、検索テキスト、Canvas の出力は変更しません。他のコンポーネントのオーバーライドと同様に、ビューが初めて開く前に登録してください。登録の変更は、既にマウントされているビューを再レンダリングしません。

### コンテンツコンポーネントとしての使用

#### サイドバーで

`univerAPI.openSidebar`は、コンテンツが登録されたコンポーネントであるUniverインターフェイスのサイドバーを開きます。

```tsx
// [!code word:MyCustomSidebarComponent]
// 適切なタイミング（例：Univer が読み込まれた後）でコンポーネントを登録する必要があります
univerAPI.registerComponent('MyCustomSidebarComponent', () => <div>Hello Univer!</div>)

const sidebar = univerAPI.openSidebar({
  header: { title: 'My Sidebar' },
  children: { label: 'MyCustomSidebarComponent' },
  onClose: () => {
    console.log('close')
  },
  width: 360,
})

// 後でサイドバーを閉じる
sidebar.dispose()
```

[`univerAPI.openSidebar`](/reference/facade/univer#opensidebar) を参照してください。

#### ダイアログで

`univerAPI.openDialog`は、コンテンツがカスタムコンポーネントであるダイアログを開きます。

```tsx
// [!code word:MyCustomDialogComponent]
// 適切なタイミング（例：Univer が読み込まれた後）でコンポーネントを登録する必要があります
univerAPI.registerComponent('MyCustomDialogComponent', () => <div>Hello Univer!</div>)

const dialog = univerAPI.openDialog({
  id: 'unique-dialog-id', // ダイアログの一意の識別子
  draggable: true,
  width: 300,
  title: { title: 'My Dialog' },
  children: {
    label: 'MyCustomDialogComponent',
  },
  destroyOnClose: true,
  preservePositionOnDestroy: true,
  onClose: () => {},
})

// 後でダイアログを閉じる
dialog.dispose()
```

[`univerAPI.openDialog`](/reference/facade/univer#opendialog) を参照してください。
