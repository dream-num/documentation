Univer はコンポーネントを直接レンダリング関数の引数として渡しません。Facade API を使ってコンポーネントを Univer に登録した後、各マウントポイントで利用できます。

Facade API の取得方法が分からない場合は [Facade API](/guides/docs/getting-started/facade) を参照してください。
