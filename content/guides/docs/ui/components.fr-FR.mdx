---
title: Composants personnalisés
description: Univer propose plusieurs méthodes pour intégrer des composants personnalisés et ainsi étendre et adapter ses fonctionnalités. Ce guide présente plusieurs méthodes courantes.
icon: Component
---

Univer ne transmet directement aucun composant en tant que paramètre aux fonctions de rendu. Vous devez d’abord enregistrer les composants auprès d’Univer à l’aide de la Facade API avant de pouvoir les utiliser aux différents points de montage.

Si vous ne savez pas comment obtenir une instance de la Facade API, consultez la page [Facade API](/guides/docs/getting-started/facade).
