Univer n'accepte pas un composant comme argument pour une fonction de rendu. Un composant doit d'abord être enregistré via le Facade API avant de pouvoir être utilisé à n'importe quel endroit où Univer monte du contenu personnalisé.

Si une instance Facade API n'est pas encore disponible, consultez [Facade API](/guides/docs/getting-started/facade).

## Enregistrer des composants personnalisés

```typescript
// [!code word:componentKey]
// [!code word:CustomComponent]
// [!code word:options]
univerAPI.registerComponent(componentKey, CustomComponent, options)
```

Utilisez `univerAPI.registerComponent` pour enregistrer un composant personnalisé. La méthode accepte trois paramètres :

- `componentKey` : l'identifiant unique du composant, que Univer utilise pour le référencer plus tard.
- `CustomComponent` : l'implémentation du composant, qui peut être un composant React, un composant Vue ou un composant Web.
- `options`: paramètres optionnels, comme le cadre sur lequel le composant dépend.

### Composants React [#react]

Les composants React ne nécessitent aucune configuration supplémentaire. Tout composant React valide peut être enregistré :

```tsx
function ReactComponent(props: Record<string, any>) {
  return <div>Hello Univer!</div>
}

univerAPI.registerComponent('MyReactComponent', ReactComponent)
```

### Composants Vue [#vue]

#### Vue 3.x

Les composants Vue nécessitent un adaptateur. Installez et enregistrez `UniverVue3AdapterPlugin` depuis `@univerjs/ui-adapter-vue3` :

```package-install
npm install @univerjs/ui-adapter-vue3
```

```typescript
import { UniverVue3AdapterPlugin } from '@univerjs/ui-adapter-vue3'

univer.registerPlugin(UniverVue3AdapterPlugin)
```

Définissez l'option `framework` sur `'vue3'` lorsqu'un composant Vue est enregistré :

```tsx
const Vue3Component = defineComponent({
  setup(props) {
    return () => <div>Hello Univer!</div>
  },
})

univerAPI.registerComponent('MyVue3Component', Vue3Component, {
  // [!code word:vue3]
  framework: 'vue3',
})
```

#### Vue 2.x

Vue 2.x est EOL (End of Life) et n'est plus entretenu, donc Univer ne fournit pas de plugin d'adaptateur d'interface utilisateur pour lui. Un plugin personnalisé peut implémenter l'adaptateur à la place. L'exemple suivant montre une implémentation:

```typescript title="ui-adapter-vue2.ts"
import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
import { ComponentManager, UniverUIPlugin } from '@univerjs/ui'
import Vue from 'vue'

/**
 * The plugin that allows Univer to use Vue 2 components as UI components.
 */
@DependentOn(UniverUIPlugin)
export class UniverVue2AdapterPlugin extends Plugin {
  static override pluginName = 'UNIVER_UI_VUE2_ADAPTER_PLUGIN'

  constructor(
    private readonly _config = {},
    @Inject(Injector) protected readonly _injector: Injector,
    @Inject(ComponentManager) protected readonly _componentManager: ComponentManager,
  ) {
    super()
  }

  override onStarting(): void {
    const { createElement, useEffect, useRef } = this._componentManager.reactUtils

    this._componentManager.setHandler('vue2', (component: any) => {
      return (props: Record<string, any>) =>
        createElement(VueComponentWrapper, {
          component,
          props: Object.keys(props).reduce<Record<string, any>>((acc, key) => {
            if (key !== 'key') {
              acc[key] = props[key]
            }
            return acc
          }, {}),
          reactUtils: { createElement, useEffect, useRef },
        })
    })
  }
}

export function VueComponentWrapper(options: {
  component: any
  props: Record<string, any>
  reactUtils: typeof ComponentManager.prototype.reactUtils
}) {
  const { component, props, reactUtils } = options
  const { createElement, useEffect, useRef } = reactUtils

  const domRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!domRef.current) return

    const Constructor = Vue.extend(component)

    const instance = new Constructor({
      data: props,
    })
    instance.$mount()

    domRef.current.appendChild(instance.$el)

    return () => {
      instance.$destroy()
    }
  }, [props])

  return createElement('div', { ref: domRef })
}
```

Puis enregistrez le plugin:

```typescript
import { UniverVue2AdapterPlugin } from './ui-adapter-vue2' // [!code ++]

univer.registerPlugin(UniverUIPlugin)
univer.registerPlugin(UniverVue2AdapterPlugin) // [!code ++]
```

Les composants Vue 2.x nécessitent que l'option `framework` soit réglée sur `'vue2'`:

```tsx
const Vue2Component = Vue.component('MyVue2Component', {
  template: '<div>Hello, Univer!</div>',
})

univerAPI.registerComponent('MyVue2Component', Vue2Component, {
  // [!code word:vue2]
  framework: 'vue2',
})
```

### Web Components [#web-component]

Les composants Web doivent suivre la norme des composants Web. Installez et enregistrez `UniverWebComponentAdapterPlugin` depuis `@univerjs/ui-adapter-web-component`:

```package-install
npm install @univerjs/ui-adapter-web-component
```

```typescript
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

univer.registerPlugin(UniverWebComponentAdapterPlugin)
```

Définissez l'option `framework` sur `'web-component'` lorsqu'un composant Web est enregistré :

```tsx
class WebComponent extends HTMLElement {
  constructor() {
    super()
    const shadow = this.attachShadow({ mode: 'open' })
    const div = document.createElement('div')
    div.textContent = 'Hello Univer!'
    shadow.appendChild(div)
  }
}

univerAPI.registerComponent('my-web-component', WebComponent, {
  // [!code word:web-component]
  framework: 'web-component',
})
```

### Angular [#angular]

Convertissez un composant Angular en un élément personnalisé avec `createCustomElement` à partir de `@angular/elements`, puis enregistrez l'élément via l'adaptateur de composant Web Univer. Le composant peut ensuite être utilisé dans une barre latérale ou une boîte de dialogue Univer .

Conserver `@angular/elements` dans la même version que `@angular/core` et `@univerjs/ui-adapter-web-component` sur la même version qu'avec les autres paquets Univer.

Appelez la fonction après l'initialisation de Univer et passez l'injecteur Angular du composant hôte. Obtenez l'in injecteur avec `private readonly injector = inject(Injector)`, puis appelez `registerAngularPanel(univer, univerAPI, this.injector)`. Le composant hôte importe `inject` ou `Injector` depuis `@angular/core` .

```typescript title="angular-panel.ts"
import type { Injector } from '@angular/core'
import type { FUniver, Univer } from '@univerjs/presets'
import { Component } from '@angular/core'
import { createCustomElement } from '@angular/elements'
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

@Component({
  selector: 'app-angular-panel',
  standalone: true,
  template: '<p>Hello from Angular!</p>',
})
export class AngularPanelComponent {}

export function registerAngularPanel(univer: Univer, univerAPI: FUniver, injector: Injector) {
  const element = createCustomElement(AngularPanelComponent, { injector })

  univer.registerPlugin(UniverWebComponentAdapterPlugin)
  return univerAPI.registerComponent('univer-angular-panel', element, {
    framework: 'web-component',
  })
}
```

Une fois l’éditeur rendu, utilisez la clé enregistrée comme contenu de la barre latérale :

```typescript
const sidebar = univerAPI.openSidebar({
  header: { title: 'Angular' },
  children: { label: 'univer-angular-panel' },
  width: 360,
})
```

Conserver l'enregistrement retourné et les poignées latérales et appeler `dispose()` sur chaque fois qu'il n'est plus nécessaire. Enregistrer l'élément une fois par application. Son nom doit contenir un trait d'union et doit différer du sélecteur de composants Angular.

Angular Elements map inputs to element properties and outputs to DOM `CustomEvent` events. L'adaptateur Univer définit des propriétés mais ne s'abonne pas aux sorties Angular. L'application s'inscrit à ces événements lorsqu'ils sont nécessaires.

## Utiliser des composants personnalisés

Les méthodes ci-dessous couvrent les moyens communs de placer un composant personnalisé dans l'interface utilisateur Univer.

<Callout type="warning" title="Attention">
  1. Attendez jusqu'à ce que Univer ait terminé le rendu avant d'appeler ces méthodes. 2. Enregistrer les composants qui nécessitent l'enregistrement avant l'utilisation. 3. Appelez `dispose()` pour nettoyer et supprimer les composants ajoutés; sinon l'application fuit la mémoire.
</Callout>

### Ajouter des éléments de menu personnalisés

Tant la barre de menu supérieure (Ribbon) que le menu à clic droit (Context Menu) peuvent contenir des composants personnalisés. L'ajout d'un composant à un élément de menu nécessite un plugin personnalisé.

### Remplacer des composants intégrés

<Callout type="error" title="Avertissement">
  Le remplacement d'un composant intégré peut briser d'autres fonctionnalités qui en dépendent. Lisez le code source et la documentation avant de remplacer un composant, et continuez avec prudence.
</Callout>

`univerAPI.registerComponent` enregistre une redéfinition par défaut (`override: true`). La redéfinition a priorité sur le composant intégré, que le plugin enregistre sa valeur par défaut avant ou après cet appel. Une seule redéfinition peut être active par `componentKey`, donc disposer de l'enregistrement précédent avant d'en enregistrer un autre. Appeler `dispose()` sur l'enregistrement retourné restaure la valeur par défaut si l'un d'entre eux est enregistré. Passez `{ override: false }` pour enregistrer une valeur par défaut.

Enregistrez une redéfinition avant que la vue correspondante ne s'ouvre pour la première fois. Les modifications d'inscription ne renverront pas automatiquement les vues déjà montées.

Par exemple, le remplacement du composant ColorPicker intégré nécessite un seul appel :

```tsx
// Following code only replaces the UI of the built-in ColorPicker component, not its functionality
univerAPI.registerComponent('UI_COLOR_PICKER_COMPONENT', () => <input type="color" />)
```

### Utiliser des composants comme contenu

#### Dans la barre latérale

`univerAPI.openSidebar` ouvre une barre latérale dans l'interface Univer dont le contenu est un composant enregistré.

```tsx
// [!code word:MyCustomSidebarComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomSidebarComponent', () => <div>Hello Univer!</div>)

const sidebar = univerAPI.openSidebar({
  header: { title: 'My Sidebar' },
  children: { label: 'MyCustomSidebarComponent' },
  onClose: () => {
    console.log('close')
  },
  width: 360,
})

// Later close the sidebar
sidebar.dispose()
```

Voir [`univerAPI.openSidebar`](/reference/facade/univer#opensidebar).

#### Dans une boîte de dialogue

`univerAPI.openDialog` ouvre une boîte de dialogue dont le contenu est un composant personnalisé.

```tsx
// [!code word:MyCustomDialogComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomDialogComponent', () => <div>Hello Univer!</div>)

const dialog = univerAPI.openDialog({
  id: 'unique-dialog-id', // The unique identifier for the dialog
  draggable: true,
  width: 300,
  title: { title: 'My Dialog' },
  children: {
    label: 'MyCustomDialogComponent',
  },
  destroyOnClose: true,
  preservePositionOnDestroy: true,
  onClose: () => {},
})

// Later close the dialog
dialog.dispose()
```

Voir [`univerAPI.openDialog`](/reference/facade/univer#opendialog).
