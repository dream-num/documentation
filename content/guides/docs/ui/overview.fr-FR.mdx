## Système de design

Le système de conception est construit sur Tailwind CSS et définit un ensemble de jetons de conception. Le moteur de rendu et la couche de vue utilisent ces jetons, qui maintiennent leur style cohérent. Les jetons sont définis dans le paquet `@univerjs/themes`, donc les changer change l'apparence de l'application.

## Composants

La couche de vue se compose de composants React. Si une application utilise déjà React, utiliser les composants Univer ou enregistrer des composants personnalisés prend peu d'effort. React n'est pas nécessaire pour les composants personnalisés, cependant: Univer prend également en charge Vue (3.x) et Web Components.

Les composants de base sont fournis par le paquet `@univerjs/design` et les composants d'icônes par le pack `@univerjs/icons`. Les deux peuvent également être utilisés en dehors de Univer .

Les composants personnalisés apparaissent généralement dans l'un des endroits suivants:

- Boutons personnalisés dans le menu Ruban ou Contexte
- Panneaux tels que la barre latérale ou un popup qui héberge le composant
- Un remplacement d'un composant intégré
