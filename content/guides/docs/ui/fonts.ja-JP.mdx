## フォント構造の定義

Univerでは、`IFontConfig`インターフェイスはフォントを記述します:

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| `value` | `string` | フォントのユニークな識別子、通常はCSSフォントファミリーの最初のエントリ。 |
| `label` | `string` | 翻訳キー。Univerインスタンスが作成されると、キーが翻訳されていない場合、供給された値は変更されません。 |
| `category` | `FontCategory` | フォントカテゴリ、UI でフォントをグループ化します。 任意。 |

<Callout>
  Univerは、インストールされていないフォントを選択しないからユーザが選択しないようにします。クライアントがフォントを持っていない場合、ブラウザはデフォルトのフォントを置き換えます。
</Callout>

## カスタムフォントの使用

ふりがな `customFontFamily` パラメータ `UniverUIPlugin` フォントのドロップダウンが提供するオプションを制御する。

`UniverUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | その要素の DOM ID にマウントする要素。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | ドロップダウンにフォントを追加します。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | ドロップダウンにフォントを追加します。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS で使うフォント名。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 表示名または翻訳キー。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 分類。`sans-serif`、`serif`、`monospace`、`display`、`handwriting` を指定できます。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 既定のフォント一覧を指定した一覧に置き換えます。 |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // デフォルトのフォントリストを上書きするかどうか、デフォルトは false
    override: true,
  },
})
```

## Facade API

フォントは起動時に知られる必要はありません。Facade APIは、フォントリソースが非同期にロードしたときに必要となるランタイムで新しいフォントを追加できます。

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
