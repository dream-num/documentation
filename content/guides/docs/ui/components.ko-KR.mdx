title: 사용자 정의 컴포넌트
description: Univer는 사용자 정의 컴포넌트를 통합하는 다양한 방법을 제공하여 기능을 확장하고 원하는 대로 구성할 수 있도록 지원합니다. 이 가이드에서는 일반적으로 사용하는 몇 가지 방법을 소개합니다.
icon: Component
---

Univer는 컴포넌트를 렌더링 함수에 매개변수로 직접 전달하지 않습니다. 여러 마운트 지점에서 컴포넌트를 사용하려면 먼저 Facade API를 통해 Univer에 등록해야 합니다.

Facade API 인스턴스를 가져오는 방법이 익숙하지 않다면 [Facade API](/guides/docs/getting-started/facade)를 참고하세요.
