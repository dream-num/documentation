---
title: 自定義元件
description: Univer 提供了多種方式來整合自定義元件，使你能夠擴充套件和定製 Univer 的功能。本指南將介紹幾種常用的方法。
icon: Component
---

Univer 並不會直接將元件作為引數直接傳遞給任何渲染函式，你需要透過 Facade API 將元件註冊到 Univer 中之後，才能在各個掛載點使用它們。

如果你還不瞭解如何獲取 Facade API 的例項，可以參考 [Facade API](/guides/docs/getting-started/facade)。
