## Структура описания шрифта

В Univer интерфейс `IFontConfig` описывает шрифт:

| Свойство | Тип | Описание |
| --- | --- | --- |
| `value` | `string` | Уникальный идентификатор шрифта, обычно первая запись в семействе шрифтов CSS. |
| `label` | `string` | Если ключ не имеет перевода при создании экземпляра Univer, поставляемое значение отображается без изменений. |
| `category` | `FontCategory` | Категория шрифтов, которая группирует шрифты в UI. Optional. |

<Callout>
  Univer не мешает пользователям выбирать шрифт, который не установлен.Если у клиента нет шрифта, браузер заменяет его по умолчанию.
</Callout>

## Использование пользовательских шрифтов

Параметр `customFontFamily` на `UniverUIPlugin` контролирует, какие опции предлагает выпадающий шрифт.

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Элемент для установки, или DOM ID этого элемента. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Добавляет шрифты в раскрывающийся список. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Добавляет шрифты в раскрывающийся список. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Имя шрифта в CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Отображаемое имя или ключ перевода. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Группа шрифтов: `sans-serif`, `serif`, `monospace`, `display` или `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Заменяет встроенный список указанными шрифтами. |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // Whether to override the default font list, defaults to false
    override: true,
  },
})
```

## Facade API

Шрифты не обязательно должны быть известны при запуске. Facade API может добавлять новые шрифты во время выполнения, что требуется при асинхронной загрузке ресурсов шрифта.

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
