Univer не передаёт компоненты напрямую в качестве параметров функций рендеринга. Чтобы использовать компоненты в различных точках монтирования, сначала зарегистрируйте их в Univer через Facade API.

Если вы не знаете, как получить экземпляр Facade API, обратитесь к разделу [Facade API](/guides/docs/getting-started/facade).
