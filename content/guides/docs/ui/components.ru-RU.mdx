Univer не принимает компонент в качестве аргумента для функции рендеринга. Компонент должен быть сначала зарегистрирован через Facade API, прежде чем он может быть использован в любом месте, где Univer монтирует пользовательский контент.

Если экземпляр Facade API еще не доступен, см. [Facade API](/guides/docs/getting-started/facade).

## Регистрация пользовательских компонентов

```typescript
// [!code word:componentKey]
// [!code word:CustomComponent]
// [!code word:options]
univerAPI.registerComponent(componentKey, CustomComponent, options)
```

Используйте `univerAPI.registerComponent` для регистрации пользовательского компонента. Метод принимает три параметра:

- `componentKey`: уникальный идентификатор компонента, который Univer использует для ссылки на него позже.
- `CustomComponent`: реализация компонента, который может быть компонентом React, компонентом Vue или веб-компонентом.
- `options`: дополнительные настройки, такие как фреймворк, от которого зависит компонент.

### Компоненты React [#react]

Компоненты React не требуют дополнительной настройки. Любой действительный компонент React может быть зарегистрирован:

```tsx
function ReactComponent(props: Record<string, any>) {
  return <div>Hello Univer!</div>
}

univerAPI.registerComponent('MyReactComponent', ReactComponent)
```

### Компоненты Vue [#vue]

#### Vue 3.x

Компоненты Vue требуют адаптера.Установите и зарегистрируйте `UniverVue3AdapterPlugin` от `@univerjs/ui-adapter-vue3`:

```package-install
npm install @univerjs/ui-adapter-vue3
```

```typescript
import { UniverVue3AdapterPlugin } from '@univerjs/ui-adapter-vue3'

univer.registerPlugin(UniverVue3AdapterPlugin)
```

Установите опцию `framework` на `'vue3'` при регистрации компонента Vue:

```tsx
const Vue3Component = defineComponent({
  setup(props) {
    return () => <div>Hello Univer!</div>
  },
})

univerAPI.registerComponent('MyVue3Component', Vue3Component, {
  // [!code word:vue3]
  framework: 'vue3',
})
```

#### Vue 2.x

Vue 2.x - это EOL (End of Life) и больше не поддерживается, поэтому Univer не предоставляет для него плагин адаптера пользовательского интерфейса. Вместо этого пользовательский плагин может реализовать адаптер. Следующий пример показывает одну реализацию:

```typescript title="ui-adapter-vue2.ts"
import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
import { ComponentManager, UniverUIPlugin } from '@univerjs/ui'
import Vue from 'vue'

/**
 * The plugin that allows Univer to use Vue 2 components as UI components.
 */
@DependentOn(UniverUIPlugin)
export class UniverVue2AdapterPlugin extends Plugin {
  static override pluginName = 'UNIVER_UI_VUE2_ADAPTER_PLUGIN'

  constructor(
    private readonly _config = {},
    @Inject(Injector) protected readonly _injector: Injector,
    @Inject(ComponentManager) protected readonly _componentManager: ComponentManager,
  ) {
    super()
  }

  override onStarting(): void {
    const { createElement, useEffect, useRef } = this._componentManager.reactUtils

    this._componentManager.setHandler('vue2', (component: any) => {
      return (props: Record<string, any>) =>
        createElement(VueComponentWrapper, {
          component,
          props: Object.keys(props).reduce<Record<string, any>>((acc, key) => {
            if (key !== 'key') {
              acc[key] = props[key]
            }
            return acc
          }, {}),
          reactUtils: { createElement, useEffect, useRef },
        })
    })
  }
}

export function VueComponentWrapper(options: {
  component: any
  props: Record<string, any>
  reactUtils: typeof ComponentManager.prototype.reactUtils
}) {
  const { component, props, reactUtils } = options
  const { createElement, useEffect, useRef } = reactUtils

  const domRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!domRef.current) return

    const Constructor = Vue.extend(component)

    const instance = new Constructor({
      data: props,
    })
    instance.$mount()

    domRef.current.appendChild(instance.$el)

    return () => {
      instance.$destroy()
    }
  }, [props])

  return createElement('div', { ref: domRef })
}
```

Затем зарегистрируйте плагин:

```typescript
import { UniverVue2AdapterPlugin } from './ui-adapter-vue2' // [!code ++]

univer.registerPlugin(UniverUIPlugin)
univer.registerPlugin(UniverVue2AdapterPlugin) // [!code ++]
```

Компоненты Vue 2.x требуют настройки опции `framework` на `'vue2'`:

```tsx
const Vue2Component = Vue.component('MyVue2Component', {
  template: '<div>Hello, Univer!</div>',
})

univerAPI.registerComponent('MyVue2Component', Vue2Component, {
  // [!code word:vue2]
  framework: 'vue2',
})
```

### Web Components [#web-component]

Веб-компоненты должны соответствовать стандарту Web Components.Установите и зарегистрируйте `UniverWebComponentAdapterPlugin` от `@univerjs/ui-adapter-web-component`:

```package-install
npm install @univerjs/ui-adapter-web-component
```

```typescript
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

univer.registerPlugin(UniverWebComponentAdapterPlugin)
```

Установите опцию `framework` на `'web-component'` при регистрации веб-компонента:

```tsx
class WebComponent extends HTMLElement {
  constructor() {
    super()
    const shadow = this.attachShadow({ mode: 'open' })
    const div = document.createElement('div')
    div.textContent = 'Hello Univer!'
    shadow.appendChild(div)
  }
}

univerAPI.registerComponent('my-web-component', WebComponent, {
  // [!code word:web-component]
  framework: 'web-component',
})
```

### Angular [#angular]

Преобразовать компонент Angular в пользовательский элемент с `createCustomElement` из `@angular/elements`, затем зарегистрировать элемент через адаптер веб-компонента Univer. Затем компонент можно использовать в боковой панели или диалоге Univer .

Сохраняйте `@angular/elements` в той же версии, что и `@angular/core`, и `@univerjs/ui-adapter-web-component` в той же самой версии, как и другие пакеты Univer.

Вызовите функцию после инициализации Univer и передайте инжектор Angular хост-компонента. Получите инжектор с `private readonly injector = inject(Injector)`, затем позвоните `registerAngularPanel(univer, univerAPI, this.injector)`. Компонент хоста импортирует `inject` а `Injector` из `@angular/core`

```typescript title="angular-panel.ts"
import type { Injector } from '@angular/core'
import type { FUniver, Univer } from '@univerjs/presets'
import { Component } from '@angular/core'
import { createCustomElement } from '@angular/elements'
import { UniverWebComponentAdapterPlugin } from '@univerjs/ui-adapter-web-component'

@Component({
  selector: 'app-angular-panel',
  standalone: true,
  template: '<p>Hello from Angular!</p>',
})
export class AngularPanelComponent {}

export function registerAngularPanel(univer: Univer, univerAPI: FUniver, injector: Injector) {
  const element = createCustomElement(AngularPanelComponent, { injector })

  univer.registerPlugin(UniverWebComponentAdapterPlugin)
  return univerAPI.registerComponent('univer-angular-panel', element, {
    framework: 'web-component',
  })
}
```

После отрисовки редактора используйте зарегистрированный ключ как содержимое боковой панели:

```typescript
const sidebar = univerAPI.openSidebar({
  header: { title: 'Angular' },
  children: { label: 'univer-angular-panel' },
  width: 360,
})
```

Сохраните возвращенные ручки регистрации и боковой панели и вызовите `dispose()` на каждом, когда он больше не нужен. Зарегистрируйте элемент один раз в приложении. Его название должно содержать дефис и должно отличаться от селектора компонентов Angular.

Angular Элементы отображают входы в свойства элементов и выходы в события DOM `CustomEvent`. Адаптер Univer устанавливает свойства, но не подписывается на выходы Angular, приложение подписывается под этими событиями, когда они необходимы.

## Использование пользовательских компонентов

Приведенные ниже методы охватывают общие способы размещения пользовательского компонента в пользовательском интерфейсе Univer.

<Callout type="warning" title="Внимание">
  1. Подождите, пока Univer закончит рендеринг, прежде чем вызывать эти методы. 2. Регистрируйте компоненты, которые требуют регистрации перед использованием. 3. Позвоните `dispose()`, чтобы очистить и удалить добавленные компоненты; в противном случае приложение утечет память.
</Callout>

### Добавление пользовательских пунктов меню

Как верхняя панель меню (Ribbon), так и меню правого клика (Context Menu) могут содержать пользовательские компоненты.Добавление компонента в элемент меню требует пользовательского плагина.

### Замена встроенных компонентов

<Callout type="error" title="Предупреждение">
  Замена встроенного компонента может нарушить другие функции, которые зависят от него.Прочитайте исходный код и документацию перед заменой компонента и действуйте с осторожностью.
</Callout>

`univerAPI.registerComponent` регистрирует оверрайд по умолчанию (`override: true`). Оверрайд имеет приоритет над встроенным компонентом независимо от того, регистрирует ли плагин свой дефолт до или после этого вызова. Только один оверрайдер может быть активным на `componentKey`, поэтому удалите предыдущую регистрацию перед регистрацией другого. Звонок `dispose()` на возвращенной регистрации восстанавливает встроенный по умолчанию, если он зарегистрирован. Перейдите `{ override: false }` для регистрации по умолчанию.

Зарегистрируйте оверрайд до того, как соответствующее представление откроется в первый раз.Регистрационные изменения не автоматически переоформляют уже смонтированные представления.

Например, для замены встроенного компонента ColorPicker требуется один звонок:

```tsx
// Following code only replaces the UI of the built-in ColorPicker component, not its functionality
univerAPI.registerComponent('UI_COLOR_PICKER_COMPONENT', () => <input type="color" />)
```

### Использование в качестве компонентов содержимого

#### На боковой панели

`univerAPI.openSidebar` открывает боковую панель в интерфейсе Univer, содержание которого является зарегистрированным компонентом.

```tsx
// [!code word:MyCustomSidebarComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomSidebarComponent', () => <div>Hello Univer!</div>)

const sidebar = univerAPI.openSidebar({
  header: { title: 'My Sidebar' },
  children: { label: 'MyCustomSidebarComponent' },
  onClose: () => {
    console.log('close')
  },
  width: 360,
})

// Later close the sidebar
sidebar.dispose()
```

См. [`univerAPI.openSidebar`](/reference/facade/univer#opensidebar).

#### В диалоговом окне

`univerAPI.openDialog` открывает диалог, содержание которого является пользовательским компонентом.

```tsx
// [!code word:MyCustomDialogComponent]
// You should register the component at an appropriate time (e.g., after Univer has loaded)
univerAPI.registerComponent('MyCustomDialogComponent', () => <div>Hello Univer!</div>)

const dialog = univerAPI.openDialog({
  id: 'unique-dialog-id', // The unique identifier for the dialog
  draggable: true,
  width: 300,
  title: { title: 'My Dialog' },
  children: {
    label: 'MyCustomDialogComponent',
  },
  destroyOnClose: true,
  preservePositionOnDestroy: true,
  onClose: () => {},
})

// Later close the dialog
dialog.dispose()
```

См. [`univerAPI.openDialog`](/reference/facade/univer#opendialog).
