## 字型結構定義

Univer 使用 `IFontConfig` 介面定義字型：

| 屬性 | 類型 | 說明 |
| --- | --- | --- |
| `value` | `string` | 字型的唯一標識，通常也是 CSS font-family 中的首選值。 |
| `label` | `string` | 翻譯鍵。建立 Univer 例項時，如果該鍵沒有對應譯文，則直接顯示傳入的值。 |
| `category` | `FontCategory` | 字型類別，用於在 UI 中對字型分組。可選。 |

<Callout>
  Univer 不限制使用者選擇未安裝的字型。客戶端未安裝該字型時，瀏覽器會使用預設字型替代。
</Callout>

## 使用自訂字型

字型下拉選單提供哪些選項，由 `UniverUIPlugin` 的 `customFontFamily` 參數決定。

`UniverUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 編輯器掛載到的 DOM 元素或元素 ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | 將這些字型選項新增到字型下拉選單。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | 將這些字型選項新增到字型下拉選單。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS 中使用的字型名稱。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 顯示名稱或翻譯鍵。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 字型分組，可選值為 `sans-serif`、`serif`、`monospace`、`display` 或 `handwriting`。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 使用傳入的列表替換內建選項。 |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // 是否覆蓋預設字型列表，預設為 false
    override: true,
  },
})
```

## Facade API

字型不必在啟動時確定。字型資源需要非同步載入時，可以在執行時透過 Facade API 新增新字型。

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
