## Система дизайна

Система проектирования построена на Tailwind CSS и определяет набор дизайнерских токенов. Движок рендеринга и уровень обзора используют эти токены, что сохраняет их стиль последовательным. Токены определены в пакете `@univerjs/themes`, поэтому изменение их меняет внешний вид приложения.

## Компоненты

Слой представления состоит из компонентов React. Если приложение уже использует React, использование компонентов Univer или регистрация пользовательских требует небольших усилий. React не требуется для пользовательских компонентов, однако: Univer также поддерживает Vue (3.x) и Web Components.

Основные компоненты предоставляются пакетом `@univerjs/design` и компонентами значков пакетом `@univerjs/icons`. Оба могут также использоваться за пределами Univer .

Компоненты обычно появляются в одном из следующих мест:

- Пользовательские кнопки в ленте или меню контекста
- Панели, такие как боковая панель или всплывающее окно, в котором находится компонент
- Замена встроенного компонента

Следующие страницы описывают, как зарегистрировать и использовать пользовательские компоненты.
