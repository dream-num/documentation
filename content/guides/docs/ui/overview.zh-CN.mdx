## 设计系统

设计系统构建在 Tailwind CSS 之上，定义了一组 design token。渲染引擎和视图层都使用这套 token，因此两者的样式保持一致。token 定义在 `@univerjs/themes` 包中，修改这些 token 即可改变应用的样式。

## 组件

视图层由 React 组件构成。如果应用本身使用 React，无论是直接使用 Univer 的组件，还是注册自定义组件，都不需要太多额外工作。自定义组件并非只能使用 React，Univer 同样支持 Vue（3.x）和 Web Components。

基础组件位于 `@univerjs/design` 包，图标组件位于 `@univerjs/icons` 包。两者也可以脱离 Univer 单独使用。

自定义组件通常出现在以下位置：

- Ribbon 或 Context Menu 中的自定义按钮
- Sidebar、Popup 等承载组件的面板
- 替换内置组件
