## デザインシステム

設計システムは、Tailwind CSS上に構築され、設計トークンのセットを定義します。レンダリングエンジンとビューレイヤーは、これらのトークンを両方使用し、スタイリングを一貫した状態に保ちます。トークンは`@univerjs/themes`パッケージで定義されています。そのため、アプリケーションの外観を変更します。

## コンポーネント

ビューレイヤーは、Reactコンポーネントで構成されています。 アプリケーションが既にReactを使用している場合は、Univerのコンポーネントを使用して、カスタムコンポーネントを登録するか、少し手間がかかります。 Reactはカスタムコンポーネントには必須ではありませんが、UniverもVue (3.x)とWebコンポーネントをサポートしています。

`@univerjs/icons`パッケージの`@univerjs/design`のパッケージおよびアイコンの部品によって基本的な部品は提供されます。両方ともUniverの外で使用することができます。

カスタムコンポーネントは通常、次の場所のいずれかに表示されます。

- リボンまたはコンテキストメニューのカスタムボタン
- コンポーネントをホストするSidebarやポップアップなどのパネル
- 組み込みコンポーネントの交換

次のページでは、カスタムコンポーネントの登録と使用方法について説明します。
