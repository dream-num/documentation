## Design system

The design system is built on Tailwind CSS and defines a set of design tokens. The rendering engine and the view layer both use these tokens, which keeps their styling consistent. The tokens are defined in the `@univerjs/themes` package, so changing them changes the appearance of the application.

## Components

The view layer consists of React components. If an application already uses React, using the Univer components or registering custom ones takes little effort. React is not required for custom components, however: Univer also supports Vue (3.x) and Web Components.

Basic components are provided by the `@univerjs/design` package and icon components by the `@univerjs/icons` package. Both can also be used outside Univer.

Custom components usually appear in one of the following places:

- Custom buttons in the Ribbon or Context Menu
- Panels such as the Sidebar or a Popup that host the component
- A replacement for a built-in component
