## 設計系統

設計系統建置在 Tailwind CSS 之上，定義了一組 design token。渲染引擎和檢視層都使用這套 token，因此兩者的樣式保持一致。token 定義在 `@univerjs/themes` 包中，修改這些 token 即可改變應用的樣式。

## 元件

檢視層由 React 元件構成。如果應用本身使用 React，無論是直接使用 Univer 的元件，還是註冊自定義元件，都不需要太多額外工作。自定義元件並非只能使用 React，Univer 同樣支援 Vue（3.x）和 Web Components。

基礎元件位於 `@univerjs/design` 包，圖示元件位於 `@univerjs/icons` 包。兩者也可以脫離 Univer 單獨使用。

自定義元件通常出現在以下位置：

- Ribbon 或 Context Menu 中的自定義按鈕
- Sidebar、Popup 等承載元件的面板
- 替換內建元件
