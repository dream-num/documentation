## 字体结构定义

在 Univer 中，字体使用 `IFontConfig` 接口进行定义：

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `value` | `string` | 字体的唯一标识符，通常也是 CSS font-family 的首选值。 |
| `label` | `string` | 用于国际化的翻译键，如果在 Univer 实例创建时没有指定该键值时，则直接显示传入值。|
| `category` | `FontCategory` | 字体类别，用于 UI 分组（可选）。 |

<Callout>
  Univer 不会阻止用户选择未安装的字体，如果客户端没有安装某个字体，浏览器会直接使用默认字体进行替代显示。
</Callout>


## 使用自定义字体

你可以通过配置 `UniverUIPlugin` 的 `customFontFamily` 参数来定义字体下拉菜单中的选项。

`UniverUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 编辑器挂载的 DOM 元素或元素 ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | 在字体下拉列表中添加这些选项。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | 在字体下拉列表中添加这些选项。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS 使用的字体名称。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 显示名称或翻译键。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 字体分组，可选 `sans-serif`、`serif`、`monospace`、`display` 或 `handwriting`。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 用传入的列表替换内置字体选项。 |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // 是否覆盖默认字体列表，默认为 false
    override: true,
  },
})
```

## Facade API

除了在初始化时配置，你还可以通过 Facade API 在运行时动态注册新的字体。这在需要异步加载字体资源的场景下非常有用。

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: '苹方（简）',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
