## 字体结构定义

Univer 使用 `IFontConfig` 接口定义字体：

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `value` | `string` | 字体的唯一标识，通常也是 CSS font-family 中的首选值。 |
| `label` | `string` | 翻译键。创建 Univer 实例时，如果该键没有对应译文，则直接显示传入的值。 |
| `category` | `FontCategory` | 字体类别，用于在 UI 中对字体分组。可选。 |

<Callout>
  Univer 不限制用户选择未安装的字体。客户端未安装该字体时，浏览器会使用默认字体替代。
</Callout>

## 使用自定义字体

字体下拉菜单提供哪些选项，由 `UniverUIPlugin` 的 `customFontFamily` 参数决定。

`UniverUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 编辑器挂载到的 DOM 元素或元素 ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | 将这些字体选项添加到字体下拉列表。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | 将这些字体选项添加到字体下拉列表。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS 中使用的字体名称。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 显示名称或翻译键。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 字体分组，可选值为 `sans-serif`、`serif`、`monospace`、`display` 或 `handwriting`。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 使用传入的列表替换内置选项。 |

```typescript
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'PingFang SC',
        label: '苹方（简）',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Helvetica Neue',
        label: 'Helvetica Neue',
        category: FontCategory.SANS_SERIF,
      },
    ],
    // 是否覆盖默认字体列表，默认为 false
    override: true,
  },
})
```

## Facade API

字体不必在启动时确定。字体资源需要异步加载时，可以在运行时通过 Facade API 添加新字体。

```typescript
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([{
  value: 'PingFang SC',
  label: '苹方（简）',
  category: FontCategory.SANS_SERIF,
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: FontCategory.SANS_SERIF,
}])
```
