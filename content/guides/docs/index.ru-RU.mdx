## Что такое Univer Docs

Univer Office SDK - это полнотекстовый фреймворк для построения приложений производительности. Univer Docs - редактор документов Univer Office SDK и компонент Docs Web SDK. Он работает в браузере и на сервере (Node.js).

Univer Docs получает свои возможности редактирования от [Web SDK](/guides/sheets), который охватывает встроенные редакторы и обработку безголового контента.Сотрудничество и преобразование файлов происходят от [Server SDK](/server) и [AI SDK](/ai) позволяет агенту работать с документами.

Univer Docs поддерживает расширение и настройку. С его помощью можно создавать приложения, которые варьируются от простого ввода текста до сложного набора текста, независимо от того, работаете ли вы индивидуально или в составе команды.

## Совместимость с браузерами

Web SDK компилируется с целью Chrome 88, но это не означает, что все основные среды полностью поддерживаются. Мы стараемся поддерживать работу Web SDK в следующих браузерах и средах Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK полагается на `Intl.Segmenter`. Если ваш браузер или среда выполнения не поддерживает его, сначала добавьте соответствующий полифилл. Мы рекомендуем `@formatjs/intl-segmenter` .
</Callout>

Если вы столкнулись с проблемой совместимости, попробуйте сначала соответствующий полифилл. Если проблема сохраняется, [Открыть вопрос](https://github.com/dream-num/univer/issues/new/choose).

## Совместимость с Node.js

<Callout type="warning">
  Это применимо только тогда, когда Web SDK сам работает в Node.js. Он не применяется, когда Web SDK работает в браузере через инструмент сборки на основе Node.js.
</Callout>

Web SDK работает на Node.js v18.17.0 и более поздней версии.

## Основные возможности

Univer Docs поддерживает следующие функции:

- **Основные характеристики документа**: набор полного текста, включая настройки абзаца, интервал до и после абзацев, выравнивание абзаца, углубление и висение, и набор абзацев, такой как сжатие пунктуации, висение пунктуации , интервал символа и разбиение западного слова.
- **Колонтитулы**
- **Плавающие изображения**
- **Гиперссылки**
- и многое другое...

Страницы под [Особенности](/guides/docs/features/core) подробно описывают каждую функцию.

## Как читать документацию

Навигация по документации находится слева. Страницы заказываются от базовых до продвинутых, поэтому вы можете следовать им последовательно, пока строите приложение, или читать их в любом порядке и переходить к разделам, которые относятся к вашему случаю. Верхняя часть боковой панели также позволяет переключаться между документацией на продукт.

Справа - контур текущей страницы, что облегчает перемещение между разделами. Чтобы быстро найти страницу, используйте строку поиска вверху или ярлык поиска (Ctrl+K или Cmd+K).

Если вы новичок в Univer, начните с [Быстрый старт](/guides/docs/getting-started/installation).

## Необходимые знания

Документация должна быть доступной, но она по-прежнему предполагает базовый уровень, чтобы она могла сосредоточиться на Web SDK.

Базовое понимание JavaScript и его экосистемы поможет вам получить максимальную отдачу от документации.

Если вы планируете запускать Web SDK на Node.js, вам также необходимо базовое понимание Node.js.

[Univer Server SDK](/server) предоставляет модулям документ, необходимый для совместной работы, общей истории или комментариев, и преобразования файлов. Вы составляете эти модули в бэкэнде приложения, который также обрабатывает аутентификацию, разрешения, хранение и развертывание. Редактирование в одном браузере не требует ни одного из них.
