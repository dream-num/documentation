## Что такое Univer Docs

Univer SDK — полнофункциональный фреймворк для создания офисных приложений, а Univer Docs — его компонент для работы с документами.

Univer Docs работает как в браузере, так и на сервере (Node.js). Компонент отличается высокой гибкостью, расширяемостью и широкими возможностями настройки. С его помощью можно создавать самые разные приложения: от простых полей для ввода текста до сложных систем вёрстки. Независимо от того, работаете вы самостоятельно или в команде, Univer Docs позволяет быстро и легко создавать мощные приложения для работы с документами.


## Совместимость с браузерами

Univer SDK компилируется для Chrome 88, но это не означает полной поддержки всех распространённых сред. Мы стремимся обеспечить стабильную работу Univer SDK в следующих браузерах и средах Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK использует `Intl.Segmenter`. Если ваш браузер или среда выполнения не поддерживает этот API, сначала добавьте
  соответствующий полифил. Мы рекомендуем `@formatjs/intl-segmenter`.
</Callout>

Если возникли проблемы с совместимостью, сначала попробуйте устранить их с помощью подходящих полифилов. Если проблема сохраняется, [создайте issue](https://github.com/dream-num/univer/issues/new/choose).

## Совместимость с Node.js

<Callout type="warning">
  Примечание: это относится только к запуску Univer SDK в среде Node.js и не относится к случаям, когда Univer SDK запускается в
  браузере с помощью инструментов сборки на базе Node.js.
</Callout>

Univer SDK может работать в среде Node.js и поддерживает версии v18.17.0 и выше.


## Основные возможности

Univer Docs поддерживает множество функций, среди которых:

- **Базовые функции для работы с документами**: полноценная вёрстка текста, включая параметры абзаца, интервалы до и после абзаца, выравнивание, отступы и выступы, а также внутрипараграфная типографика — сжатие и висячая пунктуация, межсимвольные интервалы и перенос слов на латинице.
- **Колонтитулы**
- **Плавающие изображения**
- **Гиперссылки**
- и многое другое...

Подробнее см. на страницах раздела [«Возможности»](/guides/docs/features/core). Исходный код основных и ключевых функций опубликован на [GitHub](https://github.com/dream-num/univer), и ими можно пользоваться бесплатно.

## Как читать документацию

Слева на экране находится панель навигации по документации. Страницы расположены последовательно — от базовых тем к более сложным, поэтому при создании приложения их можно изучать шаг за шагом. При этом вы можете читать их в любом порядке или сразу переходить к тем страницам, которые относятся к вашему сценарию. В верхней части боковой панели также можно выбрать Univer Docs.

Справа на экране находится оглавление, с помощью которого удобно переходить между разделами страницы. Чтобы быстро найти нужную страницу, воспользуйтесь строкой поиска вверху или сочетанием клавиш для поиска (Ctrl+K или Cmd+K).

Для начала ознакомьтесь с руководством [«Быстрый старт»](/guides/docs/getting-started/quickstart).

## Необходимые знания

Хотя наша документация рассчитана на начинающих, для её ясности и сосредоточенности на Univer SDK мы предполагаем некоторый базовый уровень знаний.

Чтобы получить от документации максимум пользы, рекомендуем знать основы JavaScript и его экосистемы.

Если вы хотите запускать Univer SDK в Node.js, также потребуется базовое понимание Node.js.

Если вы хотите попробовать Univer SDK Pro и развернуть Univer Server, рекомендуем знать основы Linux, Docker и Docker Compose (или Kubernetes).
