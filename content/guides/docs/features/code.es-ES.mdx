La función de bloque de código le permite insertar y mostrar fragmentos de código formateados dentro de un documento, con resaltado de sintaxis impulsado por Prism.js.

## Introducción

En Univer Docs, los bloques de código le permiten:

- **Insertar fragmentos de código**: agregar bloques de código formateados en cualquier parte de su documento.
- **Resaltado de sintaxis**: resaltar código automáticamente según el idioma.
- **Salir y cancelar**: salir o cancelar fácilmente el formato de código de párrafos vacíos.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/docs-code @univerjs-pro/docs-code-ui
```

### Uso

```typescript
import { UniverDocsCodePlugin } from '@univerjs-pro/docs-code' // [!code ++]
import { UniverDocsCodeUIPlugin } from '@univerjs-pro/docs-code-ui' // [!code ++]
import DocsCodeUIEnUS from '@univerjs-pro/docs-code-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-code-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCodeUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCodePlugin) // [!code ++]
univer.registerPlugin(UniverDocsCodeUIPlugin) // [!code ++]
```

Si tiene una licencia comercial para Univer, consulte [Uso de la licencia en el cliente](/guides/pro/license#in-plugin-mode) para la configuración.

## API de fachada

Asegúrese de importar la fachada antes de usar la API:

```typescript
import '@univerjs-pro/docs-code/facade'
```

### Obtener todos los bloques de código

```typescript
const doc = univerAPI.getActiveDocument()
const codes = doc?.getCodes() ?? []
```

### Insertar un bloque de código

```typescript
const doc = univerAPI.getActiveDocument()
const code = doc?.insertCode({
  startOffset: 12,
  endOffset: 35,
})
```

### Salir de un bloque de código

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitCode()
```

### Cancelar código vacío Párrafo

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyCodeParagraph()
```
