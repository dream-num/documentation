Un bloque de código coloca el código formateado dentro de un documento. El resaltado sintaxis es proporcionado por Prism.js.

## Introducción

En Univer Docs, los bloques de código sirven a algunas necesidades comunes:

- Se puede insertar un bloque de código formateado en cualquier lugar del documento.
- El código se destaca automáticamente según su idioma.
- Un párrafo de código vacío permite al usuario salir del bloque o cancelar el formato de código.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/docs-code @univerjs-pro/docs-code-ui
```

### Uso

```typescript
import { UniverDocsCodePlugin } from '@univerjs-pro/docs-code' // [!code ++]
import { UniverDocsCodeUIPlugin } from '@univerjs-pro/docs-code-ui' // [!code ++]
import DocsCodeUIEnUS from '@univerjs-pro/docs-code-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-code-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCodeUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCodePlugin) // [!code ++]
univer.registerPlugin(UniverDocsCodeUIPlugin) // [!code ++]
```

Si su aplicación utiliza Univer bajo una licencia comercial, configure como se describe en [Utilizando Licencia en Cliente](/server/license#in-plugin-mode).

## Compatibilidad móvil [#mobile-support]

Configure el [editor móvil](/guides/docs/getting-started/installation#mobile-support) primero. En la configuración de modo plugin en esta página, sustitúyase los registros de escritorio enumerados a continuación con las exportaciones móviles de los mismos paquetes, y haga el reemplazo **antes de abrir un documento**. Mantenga los plugins modelo, estilos, locales y las importaciones Facade, y no registre ambas variantes.

| Paquete | Registro de escritorio | Registro móvil |
| --- | --- | --- |
| `@univerjs-pro/docs-code-ui` | `UniverDocsCodeUIPlugin` | `UniverDocsCodeMobileUIPlugin` |

## API de fachada

Importar la fachada antes de llamar estos métodos:

```typescript
import '@univerjs-pro/docs-code/facade'
```

### Obtener todos los bloques de código

```typescript
const doc = univerAPI.getActiveDocument()
const codes = doc?.getCodes() ?? []
```

### Insertar un bloque de código

```typescript
const doc = univerAPI.getActiveDocument()
const code = doc?.insertCode({
  startOffset: 12,
  endOffset: 35,
})
```

### Salir de un bloque de código

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitCode()
```

### Cancelar código vacío Párrafo

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyCodeParagraph()
```

## Fuentes monoespaciadas para código [#code-fonts]

El selector de fuentes en la barra de herramientas de bloques de códigos sólo enumera las fuentes registradas con `FontCategory.MONOSPACE`. La selección de una fuente se aplica a todo el bloque de código, incluyendo sus estilos de párrafo.

Para registrar una fuente monoespacial personalizada, llame a `addFonts()`:

```ts
import { FontCategory } from '@univerjs/ui'
import '@univerjs/ui/facade'

univerAPI.addFonts([
  { value: 'JetBrains Mono', label: 'JetBrains Mono', category: FontCategory.MONOSPACE },
])
```

El registro sólo añade una entrada al selector. El archivo de fuente en sí debe ser cargado con CSS o el navegador FontFace API, como se describe en [fuentes personalizadas](/guides/docs/ui/fonts). Este método funciona tanto con el plugin como la inicialización preestablecida.
