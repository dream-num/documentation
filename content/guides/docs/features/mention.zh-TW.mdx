提及功能允許使用者在 Univer Docs 中輸入 `@` 並插入一個 mention 實體，例如應用中的人員、團隊、工單或其他物件。插入後的 mention 會作為 `CustomRangeType.MENTION` 自訂範圍儲存在文件正文中。

## 互動方式

- 在文件中輸入 `@` 打開提及彈層。
- 繼續輸入會把 `search` 傳給 mention 資料來源。
- 選擇候選項後，會用類似 `@Alice` 的實體替換已輸入的觸發文字。
- 移動游標或刪除到觸發位置之前會關閉彈層。

## 外掛模式

### 安裝

```package-install
npm install @univerjs/docs-mention-ui
```

### 使用

```typescript
import { UniverDocsMentionUIPlugin } from '@univerjs/docs-mention-ui' // [!code ++]

import '@univerjs/docs-mention-ui/lib/index.css' // [!code ++]

univer.registerPlugin(UniverDocsMentionUIPlugin) // [!code ++]
```

## 提供候選資料

提及彈層會從 `IMentionIOService` 讀取候選項。Univer 內建的本地實作會返回目前使用者；生產應用通常會替換為連接使用者目錄、團隊服務、工單系統或其他業務資料來源的實作。

```typescript
import type { IListMentionParam, IListMentionResponse, IMentionIOService } from '@univerjs/core'
import { MentionType } from '@univerjs/core'

class DirectoryMentionIOService implements IMentionIOService {
  async list(params: IListMentionParam): Promise<IListMentionResponse> {
    const users = await searchUsers(params.search ?? '')

    return {
      list: [{
        type: MentionType.PERSON,
        title: 'People',
        metadata: {},
        mentions: users.map(user => ({
          objectType: MentionType.PERSON,
          objectId: user.id,
          label: user.name,
          metadata: {
            icon: user.avatarUrl,
            email: user.email,
          },
        })),
      }],
      page: params.page,
      size: params.size,
      total: users.length,
    }
  }
}
```

建立應用時，透過 Univer 的依賴覆蓋註冊自訂服務。

```typescript
import { IMentionIOService, LocaleType, Univer } from '@univerjs/core'

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  override: [
    [IMentionIOService, { useClass: DirectoryMentionIOService }],
  ],
})
```

## 資料模型

mention 插入後，可見文字會寫入 `body.dataStream`，實體元資訊會持久化到 `body.customRanges`。

```typescript
const documentData = {
  body: {
    dataStream: 'Hello @Alice\\r\\n',
    customRanges: [{
      startIndex: 6,
      endIndex: 11,
      rangeId: 'mention-1',
      rangeType: CustomRangeType.MENTION,
      wholeEntity: true,
      properties: {
        id: 'mention-1',
        label: 'Alice',
        type: 'user',
        email: 'alice@example.com',
      },
    }],
  },
}
```

<Callout type="info">
  Mentions 是文件自訂範圍。如果應用在 `metadata` 中儲存額外欄位，請保持這些欄位可序列化，這樣文件快照才能安全持久化和還原。
</Callout>
