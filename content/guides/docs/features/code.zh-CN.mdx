代码块用于在文档中插入格式化的代码片段，语法高亮由 Prism.js 提供。

## 介绍

在 Univer Docs 中，代码块可满足以下几类常见需求：

- 可在文档的任意位置插入格式化的代码块。
- 代码按语言自动高亮。
- 在空的代码段落中，可以退出代码块或取消代码格式。

## 插件模式

### 安装

```package-install
npm install @univerjs-pro/docs-code @univerjs-pro/docs-code-ui
```

### 使用

```typescript
import { UniverDocsCodePlugin } from '@univerjs-pro/docs-code' // [!code ++]
import { UniverDocsCodeUIPlugin } from '@univerjs-pro/docs-code-ui' // [!code ++]
import DocsCodeUIZhCN from '@univerjs-pro/docs-code-ui/locale/zh-CN' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-code-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_CN,
  locales: {
    [LocaleType.ZH_CN]: mergeLocales(
      DocsCodeUIZhCN, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCodePlugin) // [!code ++]
univer.registerPlugin(UniverDocsCodeUIPlugin) // [!code ++]
```

使用 Univer 商业许可证时，按[在客户端使用许可证](/server/license#in-plugin-mode)中的说明完成配置。

## 移动端适配 [#mobile-support]

请先配置[移动端编辑器](/guides/docs/getting-started/installation#mobile-support)。在本页插件模式的初始化代码中，将下列桌面端注册替换为同一个包导出的移动端插件，替换须在**打开文档前**完成。模型插件、样式、语言包和 Facade 导入均需保留，不要同时注册两个版本。

| 来源包 | 桌面端注册 | 移动端注册 |
| --- | --- | --- |
| `@univerjs-pro/docs-code-ui` | `UniverDocsCodeUIPlugin` | `UniverDocsCodeMobileUIPlugin` |

## Facade API

调用下列方法前需先导入 facade：

```typescript
import '@univerjs-pro/docs-code/facade'
```

### 获取所有代码块

```typescript
const doc = univerAPI.getActiveDocument()
const codes = doc?.getCodes() ?? []
```

### 插入代码块

```typescript
const doc = univerAPI.getActiveDocument()
const code = doc?.insertCode({
  startOffset: 12,
  endOffset: 35,
})
```

### 退出代码块

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitCode()
```

### 取消空代码段落

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyCodeParagraph()
```

## 代码块等宽字体 [#code-fonts]

代码块工具栏的字体选择器仅列出以 `FontCategory.MONOSPACE` 注册的字体。选择某个字体后，该字体会应用到整个代码块，包括其中的段落样式。

要注册自定义等宽字体，调用 `addFonts()`：

```ts
import { FontCategory } from '@univerjs/ui'
import '@univerjs/ui/facade'

univerAPI.addFonts([
  { value: 'JetBrains Mono', label: 'JetBrains Mono', category: FontCategory.MONOSPACE },
])
```

注册只会向选择器添加一个选项，字体文件本身仍需通过 CSS 或浏览器 FontFace API 加载，具体做法见[自定义字体](/guides/docs/ui/fonts)。该方法在插件模式和预设模式下均可使用。
