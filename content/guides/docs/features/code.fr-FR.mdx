La fonctionnalité de blocs de code vous permet d’insérer et d’afficher des extraits de code mis en forme dans un document, avec une coloration syntaxique fournie par Prism.js.

## Introduction

Dans Univer Docs, les blocs de code vous permettent de :

- **Insérer des extraits de code** : ajoutez des blocs de code mis en forme n’importe où dans votre document.
- **Appliquer la coloration syntaxique** : mettez automatiquement le code en couleur selon le langage.
- **Quitter et annuler** : quittez ou annulez facilement la mise en forme du code depuis un paragraphe vide.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/docs-code @univerjs-pro/docs-code-ui
```

### Utilisation

```typescript
import { UniverDocsCodePlugin } from '@univerjs-pro/docs-code' // [!code ++]
import { UniverDocsCodeUIPlugin } from '@univerjs-pro/docs-code-ui' // [!code ++]
import DocsCodeUIEnUS from '@univerjs-pro/docs-code-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-code-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCodeUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCodePlugin) // [!code ++]
univer.registerPlugin(UniverDocsCodeUIPlugin) // [!code ++]
```

Si vous disposez d’une licence commerciale Univer, consultez la page [Utiliser une licence côté client](/guides/pro/license#in-plugin-mode) pour savoir comment la configurer.

## API Facade

Veillez à importer la facade avant d’utiliser l’API :

```typescript
import '@univerjs-pro/docs-code/facade'
```

### Obtenir tous les blocs de code

```typescript
const doc = univerAPI.getActiveDocument()
const codes = doc?.getCodes() ?? []
```

### Insérer un bloc de code

```typescript
const doc = univerAPI.getActiveDocument()
const code = doc?.insertCode({
  startOffset: 12,
  endOffset: 35,
})
```

### Quitter un bloc de code

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitCode()
```

### Annuler un paragraphe de code vide

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyCodeParagraph()
```
