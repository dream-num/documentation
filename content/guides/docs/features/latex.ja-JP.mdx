Docs は、ドキュメントモデルの編集可能なコンテンツとして LaTeX 式ソースを保存し、ブラウザエディタでレンダリングします。

## プラグインモード [#plugin-mode]

### インストール [#installation]

```package-install
npm install @univerjs-pro/docs-latex @univerjs-pro/docs-latex-ui
```

### 使い方 [#usage]

```typescript
import { UniverDocsLatexPlugin } from '@univerjs-pro/docs-latex' // [!code ++]
import { UniverDocsLatexUIPlugin } from '@univerjs-pro/docs-latex-ui' // [!code ++]
import DocsLatexUIJaJP from '@univerjs-pro/docs-latex-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-latex-ui/lib/index.css' // [!code ++]
import '@univerjs-pro/docs-latex/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsLatexUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsLatexPlugin) // [!code ++]
univer.registerPlugin(UniverDocsLatexUIPlugin) // [!code ++]
```

Univer の商用ライセンスを保持している場合は、設定の [クライアントでのライセンスの使用](/server/license#in-plugin-mode)を参照してください。

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/docs/getting-started/installation#mobile-support)を最初にセットアップします。このページに記載されているプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換えて、置換**ドキュメントを開く前に**を完了します。モデルプラグイン、スタイル、ロケール、ファサードのインポートは変更されず、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/docs-latex-ui` | `UniverDocsLatexUIPlugin` | `UniverDocsLatexMobileUIPlugin` |

## Facade API

LaTeX APIを呼び出す前にファサードエントリーをインポートします。

```typescript
import '@univerjs-pro/docs-latex/facade'
```

現在の document に formula を挿入します。

```typescript
const doc = univerAPI.getActiveDocument()

const formula = doc?.insertLatexFormula({
  latex: 'E=mc^2',
  index: 12,
})
```

Formula を読み取り、更新します。

```typescript
const formulas = doc?.getLatexFormulas() ?? []
const firstFormula = doc?.findLatexFormulaByText('mc')

firstFormula?.update({
  latex: '\\frac{a}{b}',
})
```

式は、 id または ドキュメントのデータストリームのオフセットによっても取得できます。

```typescript
const byId = doc?.getLatexFormula('formula-range-id')
const atOffset = doc?.getLatexFormulaAt(42)

console.log(byId?.describe(), atOffset?.getLatex())
```
