Une table des matières écrit des entrées pour les rubriques dans le corps du document et est séparée du panneau de navigation des contours. Ajoutez ces deux plugins à la configuration de base de Docs avant de créer un document, fusionnez la locale de l'interface utilisateur dans `locales`, et chargez la feuille de style. Ni le noyau de Docs ni le préréglage avancé de Docs ne les incluent.

La table des matières est disponible dans les documents traditionnels. Dans les documents modernes, Univer masque le menu de la table des matières.

```package-install
npm install @univerjs/docs-toc @univerjs/docs-toc-ui
```

```ts
import { UniverDocsTocPlugin } from '@univerjs/docs-toc'
import { UniverDocsTocUIPlugin } from '@univerjs/docs-toc-ui'
import FeatureLocale from '@univerjs/docs-toc-ui/locale/fr-FR'
import { LocaleType } from '@univerjs/core'

import '@univerjs/docs-toc-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.FR_FR, FeatureLocale)

univer.registerPlugin(UniverDocsTocPlugin)
univer.registerPlugin(UniverDocsTocUIPlugin)
```

## Insertion et mise à jour [#commands]

Placez le curseur dans le document avant de l'insérer. L'interface utilisateur gère l'insertion, les mises à jour complètes, les mises a jour de page seulement et la suppression. Lorsque `rangeId` n'est pas passé, une mise à jour cible la table des matières à la sélection actuelle.

```ts
import { InsertTableOfContentsCommand, UpdateTableOfContentsCommand } from '@univerjs/docs-toc'

await univerAPI.executeCommand(InsertTableOfContentsCommand.id, {
  levels: 3,
  showPageNumbers: true,
  rightAlignPageNumbers: true,
})
await univerAPI.executeCommand(UpdateTableOfContentsCommand.id, { mode: 'entireTable' })
```

L'actuateur évalue les instructions de table des matières (`\o`). Les autres commutateurs Word d'un fichier importé restent dans les métadonnées du FIELD, mais ils ne sont pas tous évalués. Voir [paramètres de commande](/reference/packages/plugins/univerjs/docs-toc).
