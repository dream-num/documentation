La table des matières insère les titres dans le corps du document. Elle est distincte du volet de navigation. Ajoutez ces plugins à Docs Core avant de créer le document, fusionnez la locale UI dans `locales` et chargez le CSS. Les presets Core et Advanced ne les incluent pas.

```package-install
npm install @univerjs/docs-toc @univerjs/docs-toc-ui
```

```ts
import { UniverDocsTocPlugin } from '@univerjs/docs-toc'
import { UniverDocsTocUIPlugin } from '@univerjs/docs-toc-ui'
import FeatureLocale from '@univerjs/docs-toc-ui/locale/fr-FR'
import { LocaleType } from '@univerjs/core'

import '@univerjs/docs-toc-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.FR_FR, FeatureLocale)

univer.registerPlugin(UniverDocsTocPlugin)
univer.registerPlugin(UniverDocsTocUIPlugin)
```

## Insertion et mise à jour [#commands]

Placez le curseur dans le document avant insertion. L’UI permet l’insertion, la mise à jour complète ou des seuls numéros de page, et la suppression. Sans `rangeId`, la mise à jour cible la table à la sélection courante.

```ts
import { InsertTableOfContentsCommand, UpdateTableOfContentsCommand } from '@univerjs/docs-toc'

await univerAPI.executeCommand(InsertTableOfContentsCommand.id, {
  levels: 3,
  showPageNumbers: true,
  rightAlignPageNumbers: true,
})
await univerAPI.executeCommand(UpdateTableOfContentsCommand.id, { mode: 'entireTable' })
```

La mise à jour évalue les instructions fondées sur les niveaux de plan (`\o`). Les autres commutateurs Word sont conservés dans les métadonnées FIELD sans être tous évalués. Voir les [paramètres](/reference/packages/plugins/univerjs/docs-toc).
