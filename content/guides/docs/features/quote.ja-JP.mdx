引用ブロック機能を使用すると、ドキュメント内に引用テキストを挿入して書式設定でき、通常のコンテンツとは異なる視覚的スタイルを適用できます。

## はじめに

Univer Docs では、引用ブロックを使用して以下ができます：

- **引用テキストを書式設定**：引用に独特のスタイルを適用します。
- **コンテンツをネスト**：引用ブロック内にリッチコンテンツを含めます。
- **簡単に終了**：空の段落から引用書式をすばやく終了します。

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/docs-quote @univerjs-pro/docs-quote-ui
```

### 使用法

```typescript
import { UniverDocsQuotePlugin } from '@univerjs-pro/docs-quote' // [!code ++]
import { UniverDocsQuoteUIPlugin } from '@univerjs-pro/docs-quote-ui' // [!code ++]
import DocsQuoteUIJaJP from '@univerjs-pro/docs-quote-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-quote-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsQuoteUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsQuotePlugin) // [!code ++]
univer.registerPlugin(UniverDocsQuoteUIPlugin) // [!code ++]
```

Univer の商用ライセンスをお持ちの場合は、[クライアントでのライセンス使用](/guides/pro/license#in-plugin-mode)を参照してください。

## Facade API

API を使用する前に facade をインポートしてください：

```typescript
import '@univerjs-pro/docs-quote/facade'
```

### すべての引用ブロックを取得

```typescript
const doc = univerAPI.getActiveDocument()
const quotes = doc?.getQuotes() ?? []
```

### 引用ブロックを挿入

```typescript
const doc = univerAPI.getActiveDocument()
const quote = doc?.insertQuote({
  startOffset: 12,
  endOffset: 35,
})
```

### 引用ブロックを終了

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitQuote()
```

### 空の引用段落をキャンセル

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyQuoteParagraph()
```
