引用されたテキストを引用符ブロックで入力し、引用符ブロックを記述することで、引用語句がその内容と異なる読み込まれるように独自のスタイリングを実行できます。

## はじめに

Univer Docs では、引用符ブロックは次のようになります。

- 引用されたテキストの異なるスタイル。
- ブロック内でネストされた豊富なコンテンツ。
- 空の段落にあるときの引用形式からクイック 出口。

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/docs-quote @univerjs-pro/docs-quote-ui
```

### 使用法

```typescript
import { UniverDocsQuotePlugin } from '@univerjs-pro/docs-quote' // [!code ++]
import { UniverDocsQuoteUIPlugin } from '@univerjs-pro/docs-quote-ui' // [!code ++]
import DocsQuoteUIJaJP from '@univerjs-pro/docs-quote-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-quote-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsQuoteUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsQuotePlugin) // [!code ++]
univer.registerPlugin(UniverDocsQuoteUIPlugin) // [!code ++]
```

商用ライセンスを使用する場合は、[クライアントでのライセンスの使用](/server/license#in-plugin-mode) で説明するように設定します。

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/docs/getting-started/installation#mobile-support)を最初に構成します。 このページに記載されているプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換え、**ドキュメントを開く前に**を実行します。 モデルプラグイン、スタイル、ロケール、ファサードのインポートをキープし、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/docs-quote-ui` | `UniverDocsQuoteUIPlugin` | `UniverDocsQuoteMobileUIPlugin` |

## Facade API

以下の API を使用する前にファサードをインポートします。

```typescript
import '@univerjs-pro/docs-quote/facade'
```

### すべての引用ブロックを取得

```typescript
const doc = univerAPI.getActiveDocument()
const quotes = doc?.getQuotes() ?? []
```

### 引用ブロックを挿入

```typescript
const doc = univerAPI.getActiveDocument()
const quote = doc?.insertQuote({
  startOffset: 12,
  endOffset: 35,
})
```

### 引用線の色を設定

```typescript
const quote = univerAPI.getActiveDocument()?.getQuote('quote-block-id')
quote?.setLineColor('#5B5FC7')
```

### 引用テキストの色を設定

```typescript
const quote = univerAPI.getActiveDocument()?.getQuote('quote-block-id')
quote?.setTextColor('#242424')
```
