Mit der Codeblockfunktion können Sie Folgendes tun Fügen Sie formatierte Codeausschnitte in ein Dokument ein und zeigen Sie sie an, mit Syntaxhervorhebung von Prism.js.

## Einführung

In Univer Docs ermöglichen Ihnen Codeblöcke Folgendes:

- **Codeausschnitte einfügen**: Fügen Sie formatierte Codeblöcke an einer beliebigen Stelle in Ihrem Dokument hinzu.
- **Syntaxhervorhebung**: Markieren Sie Code automatisch basierend auf der Sprache.
- **Beenden und Abbrechen**: Einfaches Beenden oder Abbrechen der Codeformatierung aus leeren Absätzen.

## Plugin-Modus

### Installation

```package-install
npm install @univerjs-pro/docs-code @univerjs-pro/docs-code-ui
```

### Verwendung

```typescript
import { UniverDocsCodePlugin } from '@univerjs-pro/docs-code' // [!code ++]
import { UniverDocsCodeUIPlugin } from '@univerjs-pro/docs-code-ui' // [!code ++]
import DocsCodeUIEnUS from '@univerjs-pro/docs-code-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-code-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCodeUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCodePlugin) // [!code ++]
univer.registerPlugin(UniverDocsCodeUIPlugin) // [!code ++]
```

Wenn Sie eine kommerzielle Lizenz für Univer haben, finden Sie Informationen zur Konfiguration unter [Lizenz im Client verwenden](/guides/pro/license#in-plugin-mode).

## Fassaden-API

Stellen Sie sicher, dass Sie die Fassade importieren, bevor Sie die verwenden API:

```typescript
import '@univerjs-pro/docs-code/facade'
```

### Alle Codeblöcke abrufen

```typescript
const doc = univerAPI.getActiveDocument()
const codes = doc?.getCodes() ?? []
```

### Einen Codeblock einfügen

```typescript
const doc = univerAPI.getActiveDocument()
const code = doc?.insertCode({
  startOffset: 12,
  endOffset: 35,
})
```

### Einen Codeblock verlassen

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitCode()
```

### Leeren Codeabsatz abbrechen

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyCodeParagraph()
```
