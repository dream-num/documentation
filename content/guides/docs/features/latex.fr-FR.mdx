Docs stocke la source de la formule LaTeX en tant que contenu modifiable dans le modèle de document et la rend dans l'éditeur de navigateur.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/docs-latex @univerjs-pro/docs-latex-ui
```

### Utilisation

```typescript
import { UniverDocsLatexPlugin } from '@univerjs-pro/docs-latex' // [!code ++]
import { UniverDocsLatexUIPlugin } from '@univerjs-pro/docs-latex-ui' // [!code ++]
import DocsLatexUIEnUS from '@univerjs-pro/docs-latex-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-latex-ui/lib/index.css' // [!code ++]
import '@univerjs-pro/docs-latex/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsLatexUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsLatexPlugin) // [!code ++]
univer.registerPlugin(UniverDocsLatexUIPlugin) // [!code ++]
```

Si vous possédez une licence commerciale pour Univer, référez-vous à [Utilisation de la licence dans le client](/server/license#in-plugin-mode) pour la configuration.

## Prise en charge mobile [#mobile-support]

Configurez d'abord le [éditeur mobile](/guides/docs/getting-started/installation#mobile-support). Dans la configuration en mode plugin décrite sur cette page, remplacez les enregistrements de bureau ci-dessous par les exportations mobiles des mêmes paquets, et remplissez le remplacement **avant d'ouvrir un document** . Gardez les plugins modèles, styles, locales et Facade importés inchangés, et ne pas enregistrer les deux variantes.

| Paquet | Inscription de bureau | Inscription mobile |
| --- | --- | --- |
| `@univerjs-pro/docs-latex-ui` | `UniverDocsLatexUIPlugin` | `UniverDocsLatexMobileUIPlugin` |

## API Facade

Importez l'entrée de façade avant d'appeler n'importe quelle API LaTeX :

```typescript
import '@univerjs-pro/docs-latex/facade'
```

Insérez une formule dans le document actif :

```typescript
const doc = univerAPI.getActiveDocument()

const formula = doc?.insertLatexFormula({
  latex: 'E=mc^2',
  index: 12,
})
```

Lisez et mettez à jour les formules :

```typescript
const formulas = doc?.getLatexFormulas() ?? []
const firstFormula = doc?.findLatexFormulaByText('mc')

firstFormula?.update({
  latex: '\\frac{a}{b}',
})
```

Une formule peut également être récupérée par variance id ou par son offset dans le flux de données du document:

```typescript
const byId = doc?.getLatexFormula('formula-range-id')
const atOffset = doc?.getLatexFormulaAt(42)

console.log(byId?.describe(), atOffset?.getLatex())
```
