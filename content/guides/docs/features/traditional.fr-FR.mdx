Applicable aux documents traditionnels.

Créez des rapports et des documents formels avec des pages physiques. Les sections gèrent les dimensions, marges, colonnes et en-têtes/pieds de page. Le texte et les blocs utilisent les API Docs communes.

Terminez l’[installation](/guides/docs/getting-started/installation) et [créez le type de document correspondant](/guides/docs/getting-started/document-types#create-document). Exécutez ensuite les extraits dans l’ordre sur ce document.

Vérifiez le type avant d’appeler les API de mise en page.

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc?.isTraditional()) throw new Error('Create a Traditional document first')
```

## Configuration de page [#page-setup]

Configurez la première section. Les dimensions sont en pixels de mise en page à 96 DPI. Les valeurs de section remplacent celles du document ; `getEffectivePageSetup()` renvoie les valeurs effectives.

```typescript
const section = doc.getSection(0)
if (!section) throw new Error('Section not found')

const updated = section.setPageSetup({
  pageSize: { width: 794, height: 1123 },
  marginTop: 72,
  marginBottom: 72,
  marginLeft: 72,
  marginRight: 72,
})
if (!updated) throw new Error('Page setup failed')
console.log(section.getEffectivePageSetup())
```

## Colonnes de page [#page-columns]

Ces colonnes appartiennent à une section traditionnelle ; le texte y circule pendant la pagination. `setColumns(1)` rétablit une seule colonne. Elles diffèrent des [groupes de colonnes](/guides/docs/features/columns) modernes.

```typescript
if (!section.setColumns(2, { gap: 18, separator: true })) {
  throw new Error('Page columns could not be updated')
}
console.log(section.describe().columnCount) // 2
```

## En-têtes, pieds de page et champs [#header-footer-fields]

Créez les segments d’en-tête et de pied de page de la section, puis modifiez-les avec les API de paragraphes communes. Le segment ID identifie leur flux de texte. Le Ribbon dédié propose les numéros de page, les variantes première/paire/impaire et les champs de date et d’heure.

```typescript
const headerId = section.ensureHeader()
const footerId = section.ensureFooter()
doc.appendParagraph('Launch plan | Internal', headerId)
doc.appendParagraph('Product Operations', footerId)
```

Dans les documents traditionnels, leur édition ouvre un Ribbon contextuel pour l’insertion, la navigation, les options de première page et de pages paires/impaires, et la position. Vous pouvez insérer la page courante, le nombre total de pages ou une date et heure localisées. Les champs de page affichent la valeur propre à chaque page. Pour la date/heure, activez la mise à jour automatique pour créer un champ, ou désactivez-la pour insérer du texte fixe. Les champs date/heure sont actualisés à l’ouverture ou avec **Mettre à jour les champs**, pas en continu. Les documents modernes n’utilisent pas d’en-têtes ni de pieds de page paginés.

## Pagination [#pagination]

`keepNext` conserve autant que possible un titre avec le paragraphe suivant ; `keepLines` garde les lignes du paragraphe ensemble ; `pageBreakBefore` commence le paragraphe sur une nouvelle page. Un contenu plus haut qu’une page peut être scindé. Les documents modernes n’appliquent pas ces règles à des pages physiques.

```typescript
const title = doc.findParagraphByText('Launch plan')
if (!title) throw new Error('Title not found')
title.setStyle({ keepNext: univerAPI.Enum.BooleanNumber.TRUE, keepLines: univerAPI.Enum.BooleanNumber.TRUE })

const checklist = doc.appendParagraph('Delivery checklist')
checklist.setStyle({ pageBreakBefore: univerAPI.Enum.BooleanNumber.TRUE })
```

## Sections [#sections]

Insérez un saut de section à une limite de paragraphe de premier niveau. `nextSectionType` définit le début de la section suivante. Les ID restent stables après une modification en amont ; `getSection(index)` attend un index à partir de zéro, pas un ID.

```typescript
const chapter = doc.findParagraphByText('Delivery checklist')
if (!chapter) throw new Error('Chapter not found')

const previousSection = doc.insertSectionBreak(chapter.getInfo().startOffset, {
  nextSectionType: univerAPI.Enum.SectionType.NEXT_PAGE,
})
if (!previousSection) throw new Error('Section break could not be inserted')
console.log(doc.getSections().map(item => item.getId()))
```
