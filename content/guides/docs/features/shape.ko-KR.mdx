형상 기능 삽입 및 문서 내부 도면을 편집, 기본 형상과 화살표에서 유량 요소에.

## 소개

Univer Docs에서, 모양은 뒤에 오는 가동을 지원합니다:

- 직사각형, 원형, 화살표 및 다른 간단한 모양을 추가하십시오.
- 채색, 국경 및 텍스트를 조정합니다.
- 문서에서 어디에서든 모양을 배치합니다.

## 플러그인 모드

### 설치

```package-install
npm install @univerjs-pro/engine-formula @univerjs-pro/docs-shape @univerjs-pro/docs-shape-ui
```

<Callout type="warn">
  모양은 또한 `@univerjs-pro/engine-formula`에서 `UniverProFormulaEnginePlugin`를 요구합니다. 기본 설정에서는 기존 `UniverFormulaEnginePlugin` 가져 오기 및 이 플러그인으로 등록을 대체합니다. 모양 삽입을 만들 수 있기 때문에 공식 엔진을 모두 등록하지 마십시오. 확실한 오류가 없습니다.
</Callout>

### 사용법

```typescript
import { UniverDocsShapePlugin } from '@univerjs-pro/docs-shape' // [!code ++]
import { UniverDocsShapeUIPlugin } from '@univerjs-pro/docs-shape-ui' // [!code ++]
import DocsShapeUIEnUS from '@univerjs-pro/docs-shape-ui/locale/en-US' // [!code ++]
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-shape-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsShapeUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverProFormulaEnginePlugin) // [!code ++]
univer.registerPlugin(UniverDocsShapePlugin) // [!code ++]
univer.registerPlugin(UniverDocsShapeUIPlugin) // [!code ++]
```

상업 라이센스를 사용한다면 [Client의 라이센스 사용](/server/license#in-plugin-mode)에 설명된 것과 같이 구성하십시오.

## 모바일 지원 [#mobile-support]

[모바일 편집기](/guides/docs/getting-started/installation#mobile-support)를 먼저 구성하십시오. 이 페이지에서 설명 된 플러그인 모드 설정에서 동일한 패키지에서 모바일 수출로 아래 데스크탑 등록을 대체하고 **문서 열기**을 수행하십시오. 모델 플러그인, 스타일, 로컬 및 Facade 가져 오기를 유지하고 변형을 등록하지 마십시오.

| 패키지 | 데스크톱 등록 | 모바일 등록 |
| --- | --- | --- |
| `@univerjs-pro/docs-shape-ui` | `UniverDocsShapeUIPlugin` | `UniverDocsShapeMobileUIPlugin` |

## 도형 텍스트 편집

`insertShape()`에 의해 반환된 모양 목표를 가진 일, 아래 예에서 또는 이전 예에서. `getText()`는 살아있는 [FShape텍스](/reference/facade/shape-text) 손잡이를 반환합니다. `getPlainText()`와 일반 텍스트를 읽고 `setText()`로 모든 것을 대체하고 글꼴, 색상 및 정렬 방법을 통해 포맷을 적용합니다.

```ts
import '@univerjs-pro/docs-shape/facade'

const document = univerAPI.getActiveDocument()
const paragraph = document?.getParagraphs()[0]
if (!document || !paragraph) throw new Error('No active document paragraph')
const shape = document.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.Rect,
  placement: {
    wrappingStyle: univerAPI.Enum.TextWrappingStyle.INLINE,
    anchor: { paragraphId: paragraph.getId(), segmentId: paragraph.getSegmentId() },
  },
})
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()`는 기존 텍스트를 대체합니다. 하나의 모양이 여러 스타일을 필요로 할 때 `setRichText()`를 사용하십시오. 기존의 풍부한 텍스트를 변경하려면 `getRichText()?.copy()`을 편집하고 빌더를 편집하고 `setRichText()`로 전달하십시오. 분리 된 빌더가 자체에 적용되지 않습니다. 더 많은 옵션은 [텍스트 스타일](/reference/facade/shape-text#settextstyle) 및 [텍스트 상자 패딩 및 레이아웃](/reference/facade/shape-text#settextboxoptions)에서 사용할 수 있습니다.

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## 도형 서식 복사 [#format-painter]

소스 모양을 선택, 형식 화가에 턴, 그리고 다음 대상 모양을 선택. 화가 사본 작성, 스트로크, 효과, 및 지원된 텍스트 포맷, 그리고 대상의 정체성, 기하학, 텍스트 콘텐츠 및 공식 바인딩을 나타낸다. 명확한 포맷은 삽입에 사용되는 기본을 복원. SmartArt는 제외됩니다. 모양 UI 플러그인은이 동작을 자동으로 등록합니다.
