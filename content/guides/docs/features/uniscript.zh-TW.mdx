Uniscript 提供了線上快速新增或編輯 Facade API 的能力。安裝之後，工具欄會出現一個新的按鈕，點選後會彈出一個側邊欄，可以在其中輸入程式碼並執行。我們文件中任何 univerAPI 開頭的程式碼均可在此處執行。

<Callout title="友情提示">
  Uniscript 的面板中注入了 Facade API 的例項物件 `univerAPI`，可以直接使用它來呼叫文件中所提到的 Facade API。
</Callout>

## 預設模式

Uniscript 並未提供預設模式，但支援與其外掛混用。

### 安裝

```package-install
npm install @univerjs/uniscript
```

### 使用

```typescript
import { UniverUniscriptPlugin } from '@univerjs/uniscript' // [!code ++]

import '@univerjs/uniscript/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      UniverPresetDocsCoreZhTW,
      UniscriptZhTW, // [!code ++]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
  ],
  plugins: [
    UniverUniscriptPlugin, // [!code ++]
  ],
})
```

## 外掛模式

### 安裝

```package-install
npm install @univerjs/uniscript
```

### 使用

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverUniscriptPlugin } from '@univerjs/uniscript' // [!code ++]

import '@univerjs/uniscript/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      UniscriptZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverUniscriptPlugin) // [!code ++]
```
