圖片可用於豐富文件內容、增強視覺表達和幫助說明或突出重點資訊。

## 外掛模式

### 安裝

```package-install
npm install @univerjs/drawing @univerjs/drawing-ui @univerjs/docs-drawing @univerjs/docs-drawing-ui
```

### 使用

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsDrawingPlugin } from '@univerjs/docs-drawing' // [!code ++]
import { UniverDocsDrawingUIPlugin } from '@univerjs/docs-drawing-ui' // [!code ++]
import DocsDrawingUIZhTW from '@univerjs/docs-drawing-ui/locale/zh-TW' // [!code ++]
import { UniverDrawingPlugin } from '@univerjs/drawing' // [!code ++]
import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui' // [!code ++]
import DrawingUIZhTW from '@univerjs/drawing-ui/locale/zh-TW' // [!code ++]

import '@univerjs/drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/docs-drawing-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      DrawingUIZhTW, // [!code ++]
      DocsDrawingUIZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverDrawingUIPlugin) // [!code ++]
univer.registerPlugin(UniverDocsDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverDocsDrawingUIPlugin) // [!code ++]
```

如使用[協同編輯](/guides/docs/features/collaboration)功能，需要新增 `override` 配置：

```typescript
univer.registerPlugin(UniverDrawingPlugin, {
  override: [[IImageIoService, null]], // [!code ++]
})
```

## 行動裝置支援 [#mobile-support]

先設定[行動版編輯器](/guides/docs/getting-started/installation#mobile-support)。在本頁外掛模式的初始化程式碼中，將下列桌面版註冊替換為同一套件匯出的行動版外掛，並在**開啟文件前**完成。保留模型外掛、樣式、語言套件與 Facade 匯入，請勿同時註冊兩個版本。

| 套件 | 桌面版註冊 | 行動版註冊 |
| --- | --- | --- |
| `@univerjs/docs-drawing-ui` | `UniverDocsDrawingUIPlugin` | `UniverDocsDrawingMobileUIPlugin` |
| `@univerjs/drawing-ui` | `UniverDrawingUIPlugin` | `UniverDrawingMobileUIPlugin` |

## 預設模式

### 安裝

```package-install
npm install @univerjs/preset-docs-drawing
```

### 使用

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreZhTW from '@univerjs/preset-docs-core/locales/zh-TW'
import { UniverDocsDrawingPreset } from '@univerjs/preset-docs-drawing' // [!code ++]
import UniverPresetDocsDrawingZhTW from '@univerjs/preset-docs-drawing/locales/zh-TW' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-drawing/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      UniverPresetDocsCoreZhTW,
      UniverPresetDocsDrawingZhTW, // [!code ++]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
    UniverDocsDrawingPreset(), // [!code ++]
  ],
})
```

如使用[協同編輯](/guides/docs/features/collaboration)功能，請確保在 `UniverDocsDrawingPreset` 中傳入 `collaboration: true` 選項。

```typescript
UniverDocsDrawingPreset({
  collaboration: true, // [!code ++]
})
```

## Facade API

外掛模式需要先匯入 Facade 擴充：

```typescript
import '@univerjs/docs-drawing/facade'
```

透過 `FDocument` 插入、查詢和管理文件圖片：

```typescript
const document = univerAPI.getActiveDocument()
const image = await document?.insertImage({
  source: 'https://example.com/image.png',
  imageSourceType: univerAPI.Enum.ImageSourceType.URL,
  width: 320,
  wrappingStyle: univerAPI.Enum.DocsImageWrappingStyle.INLINE,
})

document?.getImage(image?.getId() ?? '')
document?.getImages()
```

傳回的 `FDocumentImage` 可調整大小、旋轉、定位、文字環繞、圖層或刪除圖片。
