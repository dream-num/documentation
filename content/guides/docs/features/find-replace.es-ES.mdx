Buscar y reemplazar examina texto literal en el cuerpo del documento actual, incluidas las tablas. Admite distinguir mayúsculas y minúsculas, palabras completas, navegar entre coincidencias y reemplazar una o todas.

<Callout type="info">
  No se admiten encabezados, pies de página, comentarios, dibujos, expresiones regulares, búsquedas de formato ni caracteres especiales.
</Callout>

## Modo plugin

### Instalación

```package-install
npm install @univerjs/find-replace @univerjs/docs-find-replace
```

### Uso

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsFindReplacePlugin } from '@univerjs/docs-find-replace'
import FindReplaceEsES from '@univerjs/find-replace/locale/es-ES'

import '@univerjs/find-replace/lib/index.css'

const univer = new Univer({
  locale: LocaleType.ES_ES,
  locales: {
    [LocaleType.ES_ES]: mergeLocales(FindReplaceEsES),
  },
})

univer.registerPlugin(UniverDocsFindReplacePlugin)
```

## Atajos de teclado

- `Ctrl/Cmd + F`: abrir búsqueda
- `Ctrl/Cmd + H`: abrir reemplazo
- `Enter` / `Shift + Enter`: coincidencia siguiente / anterior
- `Escape`: devolver el foco al documento
