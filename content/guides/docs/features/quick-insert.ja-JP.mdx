クイック挿入は `/` コマンドのような挿入メニューを提供します。空行の行頭で `/` を入力するとメニューが表示され、テキスト、リスト、区切り線、表、画像などを検索して挿入できます。現在はプラグインモードのみ対応です。

## 操作方法

- 行頭で `/` を入力してメニューを開く
- 空行の左側に `+` ボタンが表示され、クリックするとすべてのメニューを開く
- キーワードでフィルタ；↑/↓ で移動、Enter で挿入、Esc で閉じる

## プラグインモード

### インストール

```package-install
npm install @univerjs/docs-quick-insert-ui
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsQuickInsertUIPlugin } from '@univerjs/docs-quick-insert-ui' // [!code ++]
import DocsQuickInsertUIJaJP from '@univerjs/docs-quick-insert-ui/locale/ja-JP' // [!code ++]

import '@univerjs/docs-quick-insert-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsQuickInsertUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsQuickInsertUIPlugin) // [!code ++]
```
