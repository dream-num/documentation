La tabla de contenido inserta títulos en el cuerpo del documento y es distinta del panel de navegación. Añade estos plugins a Docs Core antes de crear el documento, combina la traducción UI en `locales` y carga el CSS. Los presets Core y Advanced no los incluyen.

```package-install
npm install @univerjs/docs-toc @univerjs/docs-toc-ui
```

```ts
import { UniverDocsTocPlugin } from '@univerjs/docs-toc'
import { UniverDocsTocUIPlugin } from '@univerjs/docs-toc-ui'
import FeatureLocale from '@univerjs/docs-toc-ui/locale/es-ES'
import { LocaleType } from '@univerjs/core'

import '@univerjs/docs-toc-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.ES_ES, FeatureLocale)

univer.registerPlugin(UniverDocsTocPlugin)
univer.registerPlugin(UniverDocsTocUIPlugin)
```

## Insertar y actualizar [#commands]

Coloca el cursor en el documento antes de insertar. La UI permite insertar, actualizar toda la tabla o solo los números de página, y eliminarla. Sin `rangeId`, se actualiza la tabla de la selección actual.

```ts
import { InsertTableOfContentsCommand, UpdateTableOfContentsCommand } from '@univerjs/docs-toc'

await univerAPI.executeCommand(InsertTableOfContentsCommand.id, {
  levels: 3,
  showPageNumbers: true,
  rightAlignPageNumbers: true,
})
await univerAPI.executeCommand(UpdateTableOfContentsCommand.id, { mode: 'entireTable' })
```

La actualización evalúa instrucciones por nivel de esquema (`\o`). Los demás modificadores de Word se conservan en FIELD, pero no todos se evalúan. Consulta los [parámetros](/reference/packages/plugins/univerjs/docs-toc).
