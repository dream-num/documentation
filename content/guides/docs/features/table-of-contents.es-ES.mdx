Una tabla de contenidos escribe entradas para los encabezados en el cuerpo de documento y está separada del panel de navegación del esbozo. Agrega estos dos plugins a la configuración del núcleo de Docs antes de crear un documento, fusionar el UI locale en `locales`, y cargar la hoja de estilo. Ni el núcleo de Doc ni el preset avanzado de Docs los incluye.

```package-install
npm install @univerjs/docs-toc @univerjs/docs-toc-ui
```

```ts
import { UniverDocsTocPlugin } from '@univerjs/docs-toc'
import { UniverDocsTocUIPlugin } from '@univerjs/docs-toc-ui'
import FeatureLocale from '@univerjs/docs-toc-ui/locale/es-ES'
import { LocaleType } from '@univerjs/core'

import '@univerjs/docs-toc-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.ES_ES, FeatureLocale)

univer.registerPlugin(UniverDocsTocPlugin)
univer.registerPlugin(UniverDocsTocUIPlugin)
```

## Insertar y actualizar [#commands]

Coloque el cursor en el documento antes de insertar. La UI maneja la inserción, actualizaciones completas, actualizaciones de página-número-s-sólo, y la eliminación. Cuando `rangeId` no se pasa, una actualización apunta la tabla de contenidos en la selección actual.

```ts
import { InsertTableOfContentsCommand, UpdateTableOfContentsCommand } from '@univerjs/docs-toc'

await univerAPI.executeCommand(InsertTableOfContentsCommand.id, {
  levels: 3,
  showPageNumbers: true,
  rightAlignPageNumbers: true,
})
await univerAPI.executeCommand(UpdateTableOfContentsCommand.id, { mode: 'entireTable' })
```

El actualizador evalúa las instrucciones de tabla de contenido de nivel esbozo (`\o`). Otros conmutadores de Word de un archivo importado permanecen en los metadatos FIELD, pero no todos ellos son evaluados. [parámetros de comando](/reference/packages/plugins/univerjs/docs-toc).
