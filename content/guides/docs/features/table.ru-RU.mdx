Усовершенствованные таблицы обеспечивают полное редактирование таблиц в Univer Docs: стиль ячеек, границы, изменения строк и столбцов, а также заполнение таблицы из данных.

## Введение

В Univer Docs таблицы поддерживают следующие операции:

- Создайте таблицу с указанными вами размерами.
- Добавить, удалить и переместить строки и столбцы.
- Применяйте границы, фоны и форматирование текста к ячейкам.
- Слияние и разделение ячеек для создания сложных макетов.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### Использование

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIEnUS from '@univerjs-pro/docs-table-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsTableUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

Если вы используете коммерческую лицензию, настройте ее, как описано в [Использование лицензии у клиента](/server/license#in-plugin-mode).

## Facade API

Импорт фасада перед использованием любого из следующих API:

```typescript
import '@univerjs-pro/docs-table/facade'
```

### Вставка таблицы

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### Вставка таблицы из данных

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### Получение всех таблиц

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### Удаление таблицы

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```

## Границы таблиц [#table-borders]

Выберите таблицу или ее ячейки, чтобы открыть контекстную вкладку Таблица. Пограничный сборщик предоставляет предустановки для всех, внешних, внутренних, индивидуальных краев и без границ, а также элементы управления для цвета, ширины и стиля линии. `UniverDocsTableUIPlugin` предоставляет эти элементы управления.

## Редактирование, история и совместная работа [#editing-history]

Настройщики таблиц Фасада и структурные правки применяются через команды документов, поэтому они участвуют в отмене/редо и коллаборации. `setTableStyle()` объединяет фоновые и пограничные изменения в одну запись истории. `setColumnType()` также отменяется и синхронизируется, а типы столбцов следуют за своими столбцами при перемещении столбцов. `setCellText()` заменяет целое значение ячейки: одновременные замены разрешаются как атомные значения, тогда как обычные редактирования символов используют текст OT. Если заблокированный элемент управления контентом отклоняет редактирование ячейки, вызов возвращает `false` и не потребляет историю отмены/редо.

## Выравнивание всей таблицы [#table-alignment]

В традиционном документе выберите таблицу и используйте **Таблица → Таблица выравнивания** на ленте, чтобы поместить таблицу влево, в центр или вправо от области содержимого страницы. Эта настройка перемещает саму таблицу и не меняет выравнивание текста внутри ячеек. Управление отключено в современных документах.

Значение сохраняется в `tableSource[tableId].align` и поддерживает undo/redo и save.После регистрации плагина таблицы то же действие доступно через публичную команду ниже. Передайте существующий идентификатор таблицы из снимка документа. Недействительные цели, отключенные документы и современные документы возвращают `false`.

```ts
import { DocsTableSetTableAlignCommand } from '@univerjs-pro/docs-table'
import { TableAlignmentType } from '@univerjs/core'

const aligned = await univerAPI.executeCommand(DocsTableSetTableAlignCommand.id, {
  unitId: documentId,
  tableId,
  value: TableAlignmentType.CENTER,
})
```
