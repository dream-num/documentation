Функция расширенных таблиц предоставляет широкие возможности редактирования таблиц в Univer Docs: оформление ячеек, настройку границ, работу со строками и столбцами, а также заполнение данными.

## Введение

Расширенные таблицы в Univer Docs позволяют:

- **Вставлять таблицы программно**: создавать таблицы заданного размера.
- **Изменять структуру**: добавлять, удалять и перемещать строки и столбцы.
- **Оформлять ячейки**: настраивать границы, фон и форматирование текста.
- **Объединять и разделять ячейки**: создавать сложные макеты, комбинируя ячейки.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### Использование

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIEnUS from '@univerjs-pro/docs-table-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsTableUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

Если у вас есть коммерческая лицензия Univer, инструкции по настройке см. в разделе [Использование лицензии на клиенте](/guides/pro/license#in-plugin-mode).

## Facade API

Перед использованием API обязательно импортируйте facade:

```typescript
import '@univerjs-pro/docs-table/facade'
```

### Вставка таблицы

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### Вставка таблицы из данных

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### Получение всех таблиц

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### Удаление таблицы

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```
