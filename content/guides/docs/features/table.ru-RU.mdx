Функция расширенных таблиц предоставляет широкие возможности редактирования таблиц в Univer Docs: оформление ячеек, настройку границ, работу со строками и столбцами, а также заполнение данными.

## Введение

Расширенные таблицы в Univer Docs позволяют:

- **Вставлять таблицы программно**: создавать таблицы заданного размера.
- **Изменять структуру**: добавлять, удалять и перемещать строки и столбцы.
- **Оформлять ячейки**: настраивать границы, фон и форматирование текста.
- **Объединять и разделять ячейки**: создавать сложные макеты, комбинируя ячейки.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### Использование

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIEnUS from '@univerjs-pro/docs-table-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsTableUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

Если у вас есть коммерческая лицензия Univer, инструкции по настройке см. в разделе [Использование лицензии на клиенте](/server/license#in-plugin-mode).

## Поддержка мобильных устройств [#mobile-support]

Сначала настройте [мобильный редактор](/guides/docs/getting-started/installation#mobile-support). В коде инициализации режима плагинов на этой странице замените указанные настольные регистрации мобильными экспортами тех же пакетов **до открытия документа**. Сохраните модели, стили, локализации и импорты Facade; не регистрируйте оба варианта.

| Пакет | Настольная регистрация | Мобильная регистрация |
| --- | --- | --- |
| `@univerjs-pro/docs-table-ui` | `UniverDocsTableUIPlugin` | `UniverDocsTableMobileUIPlugin` |

## Facade API

Перед использованием API обязательно импортируйте facade:

```typescript
import '@univerjs-pro/docs-table/facade'
```

### Вставка таблицы

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### Вставка таблицы из данных

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### Получение всех таблиц

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### Удаление таблицы

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```

## Границы таблиц [#table-borders]

Выберите таблицу или её ячейки для открытия контекстной вкладки таблицы. Средство выбора границ предлагает все, внешние, внутренние, отдельные границы или их отсутствие, а также цвет, толщину и стиль линий. Эти элементы предоставляет `UniverDocsTableUIPlugin`.

## Редактирование, история и совместная работа [#editing-history]

Сеттеры и структурные изменения таблиц выполняются командами и поддерживают отмену, повтор и совместную работу. `setTableStyle()` объединяет фон и границы в одну запись истории. `setColumnType()` также синхронизируется и отменяется; тип следует за перемещаемым столбцом. `setCellText()` заменяет всё значение ячейки: одновременные замены используют атомарное разрешение конфликтов, а посимвольное редактирование — текстовый OT. Операция, отклонённая заблокированным элементом управления содержимым, возвращает `false`, не расходуя историю.

## Выравнивание всей таблицы [#table-alignment]

В документе Traditional выделите таблицу и выберите её выравнивание на Ribbon: слева, по центру или справа относительно области содержимого страницы. Меняется положение таблицы, а не выравнивание текста в ячейках. В документах Modern этот элемент отключён.

Значение хранится в `tableSource[tableId].align`; поддерживаются отмена, повтор и сохранение. После регистрации плагина таблиц можно выполнить публичную команду с ID существующей таблицы из снимка. Недопустимая цель, отключённый документ или документ Modern дают `false`.

```ts
import { DocsTableSetTableAlignCommand } from '@univerjs-pro/docs-table'
import { TableAlignmentType } from '@univerjs/core'

const aligned = await univerAPI.executeCommand(DocsTableSetTableAlignCommand.id, {
  unitId: documentId,
  tableId,
  value: TableAlignmentType.CENTER,
})
```
