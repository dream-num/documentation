La función de bloque de citas le permite insertar y formatear texto citado en un documento, con un estilo visual que distingue las citas del contenido normal.

## Introducción

En Univer Docs, los bloques de citas le permiten para:

- **Dar formato al texto citado**: aplique un estilo distintivo a las citas.
- **Contenido anidado**: incluya contenido enriquecido dentro de los bloques de comillas.
- **Salida fácil**: salga rápidamente del formato de comillas desde párrafos vacíos.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/docs-quote @univerjs-pro/docs-quote-ui
```

### Uso

```typescript
import { UniverDocsQuotePlugin } from '@univerjs-pro/docs-quote' // [!code ++]
import { UniverDocsQuoteUIPlugin } from '@univerjs-pro/docs-quote-ui' // [!code ++]
import DocsQuoteUIEnUS from '@univerjs-pro/docs-quote-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-quote-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsQuoteUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsQuotePlugin) // [!code ++]
univer.registerPlugin(UniverDocsQuoteUIPlugin) // [!code ++]
```

Si tiene una licencia comercial de Univer, consulte [Uso de la licencia en Cliente](/guides/pro/license#in-plugin-mode) para la configuración.

## API de fachada

Asegúrese de importar la fachada antes de usar la API:

```typescript
import '@univerjs-pro/docs-quote/facade'
```

### Obtener todos los bloques de cotización

```typescript
const doc = univerAPI.getActiveDocument()
const quotes = doc?.getQuotes() ?? []
```

### Insertar un bloque de cotización

```typescript
const doc = univerAPI.getActiveDocument()
const quote = doc?.insertQuote({
  startOffset: 12,
  endOffset: 35,
})
```

### Definir el color de línea de la cita

```typescript
const quote = univerAPI.getActiveDocument()?.getQuote('quote-block-id')
quote?.setLineColor('#5B5FC7')
```

### Definir el color de texto de la cita

```typescript
const quote = univerAPI.getActiveDocument()?.getQuote('quote-block-id')
quote?.setTextColor('#242424')
```
