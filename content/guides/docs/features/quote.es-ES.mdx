Puede insertar y formatear texto citado en un documento con un bloque de citas, que lleva su propio estilo para que una cita lea de manera diferente del contenido que lo rodea.

## Introducción

En Univer Docs, un bloque de cotización proporciona lo siguiente:

- Un estilo distinto para el texto citado.
- Contenido rico anidado dentro del bloque.
- Una salida rápida del formato de cita cuando usted está en un párrafo vacío.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/docs-quote @univerjs-pro/docs-quote-ui
```

### Uso

```typescript
import { UniverDocsQuotePlugin } from '@univerjs-pro/docs-quote' // [!code ++]
import { UniverDocsQuoteUIPlugin } from '@univerjs-pro/docs-quote-ui' // [!code ++]
import DocsQuoteUIEnUS from '@univerjs-pro/docs-quote-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-quote-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsQuoteUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsQuotePlugin) // [!code ++]
univer.registerPlugin(UniverDocsQuoteUIPlugin) // [!code ++]
```

Si utiliza una licencia comercial, configure como se describe en [Utilizando Licencia en Cliente](/server/license#in-plugin-mode).

## Compatibilidad móvil [#mobile-support]

Configure el [editor móvil](/guides/docs/getting-started/installation#mobile-support) primero. En la configuración de modo plugin descrito en esta página, sustitúyase el registro de escritorio a continuación con la exportación móvil del mismo paquete, y lo haga **antes de abrir un documento**. Mantenga los plugins modelo, estilos, locales y las importaciones Facade, y no registre ambas variantes.

| Paquete | Registro de escritorio | Registro móvil |
| --- | --- | --- |
| `@univerjs-pro/docs-quote-ui` | `UniverDocsQuoteUIPlugin` | `UniverDocsQuoteMobileUIPlugin` |

## API de fachada

Importar la fachada antes de utilizar cualquiera de las siguientes API:

```typescript
import '@univerjs-pro/docs-quote/facade'
```

### Obtener todos los bloques de cotización

```typescript
const doc = univerAPI.getActiveDocument()
const quotes = doc?.getQuotes() ?? []
```

### Insertar un bloque de cotización

```typescript
const doc = univerAPI.getActiveDocument()
const quote = doc?.insertQuote({
  startOffset: 12,
  endOffset: 35,
})
```

### Definir el color de línea de la cita

```typescript
const quote = univerAPI.getActiveDocument()?.getQuote('quote-block-id')
quote?.setLineColor('#5B5FC7')
```

### Definir el color de texto de la cita

```typescript
const quote = univerAPI.getActiveDocument()?.getQuote('quote-block-id')
quote?.setTextColor('#242424')
```
