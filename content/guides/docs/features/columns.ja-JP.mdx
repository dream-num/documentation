列レイアウトは、編集可能な列グループをUniver Docsに追加します。 列グループは、2〜5列を含むブロックです。 この構造は、テーブルとテキストを混合するコンパクトな編集レイアウト、比較セクション、ニュースレター、および文書をサポートしています。

## はじめに

Univer Docs では、列のレイアウトは 4 つの区域をカバーします:

- 2列、3列、またはカスタムラティオグループをドキュメントオフセットに配置することができます。
- Docs UI でカラムをインサート、サイズ変更、削除します。
- ファサード API クエリ カラム グループ、特定の列にコンテンツを入力し、コード内の幅比を更新します。
- カラムの変更は、標準のリッチテキストコマンドパイプラインを経由して、undo、redo、およびコラボレーションがUIオペレーションと同じドキュメント変更を受け取ります。

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/docs-column @univerjs-pro/docs-column-ui
```

### 使用法

```typescript
import { UniverDocsColumnUIPlugin } from '@univerjs-pro/docs-column-ui' // [!code ++]
import DocsColumnUIJaJP from '@univerjs-pro/docs-column-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-column-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsColumnUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsColumnUIPlugin) // [!code ++]
```

アプリケーションが商用ライセンスで Univer を使用している場合は、[クライアントでのライセンスの使用](/server/license#in-plugin-mode). で説明するように設定します。

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/docs/getting-started/installation#mobile-support)を最初に構成します。このページのプラグインモード設定では、同じパッケージからモバイルエクスポートに以下にリストされているデスクトップ登録を置き換え、代替**ドキュメントを開く前に**を作ります。モデルプラグイン、スタイル、ロケール、ファサードのインポートを保持し、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/docs-column-ui` | `UniverDocsColumnUIPlugin` | `UniverDocsColumnMobileUIPlugin` |

## Facade API

これらのメソッドを呼び出す前にファサードをインポートします。

```typescript
import '@univerjs-pro/docs-column/facade'
```

### カラムグループを挿入

```typescript
const doc = univerAPI.getActiveDocument()
const group = doc?.insertColumnGroup(3, {
  gap: 18,
  widthRatios: [1.1, 1, 0.9],
})
```

### 特定のカラムに内容を挿入

```typescript
const doc = univerAPI.getActiveDocument()
const group = doc?.insertColumnGroup(2)
const [left, right] = group?.getColumns() ?? []

const leftOffset = left?.getInsertOffset()
if (leftOffset != null) {
  doc?.insertText('Summary\rKey decisions and context.', {
    startOffset: leftOffset,
    endOffset: leftOffset,
  })
}

const rightOffset = right?.getInsertOffset()
if (rightOffset != null) {
  doc?.insertTableFromData([
    ['Item', 'Owner'],
    ['Launch checklist', 'Docs team'],
  ], { offset: rightOffset, headerRowCount: 1 })
}
```

### カラムグループを検索

```typescript
const doc = univerAPI.getActiveDocument()

const groups = doc?.getColumnGroups() ?? []
const byId = doc?.getColumnGroup('column-group-id')
const atOffset = doc?.getColumnGroupAt(128)
const matched = doc?.findColumnGroups('Launch') ?? []

console.log(groups.map(group => group.describe()))
console.log(byId, atOffset, matched)
```

### グループをリサイズまたは編集

```typescript
const doc = univerAPI.getActiveDocument()
const group = doc?.getColumnGroups()[0]

group?.setWidthRatios([1.2, 1, 0.8])

const first = group?.getColumn(0)
if (first) {
  group?.addColumn(first.getId(), 'right')
}
```

### カラムグループを削除

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteColumnGroup('column-group-id')
```
