コンテンツの表は、ドキュメント ボディに見出しのエントリを記述し、アウトライン ナビゲーション パネルから分離されます。ドキュメントを作成する前に、これらの2つのプラグインを Docs コア セットアップに追加し、UI を `locales` にマージし、スタイルシートをロードします。ドキュメント コアや Docsアドバンスト プリセットにはこれらが含まれます。

目次は従来の文書で利用できます。モダン文書では、Univer は目次のメニューを非表示にします。

```package-install
npm install @univerjs/docs-toc @univerjs/docs-toc-ui
```

```ts
import { UniverDocsTocPlugin } from '@univerjs/docs-toc'
import { UniverDocsTocUIPlugin } from '@univerjs/docs-toc-ui'
import FeatureLocale from '@univerjs/docs-toc-ui/locale/ja-JP'
import { LocaleType } from '@univerjs/core'

import '@univerjs/docs-toc-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.JA_JP, FeatureLocale)

univer.registerPlugin(UniverDocsTocPlugin)
univer.registerPlugin(UniverDocsTocUIPlugin)
```

## 挿入と更新 [#commands]

インサートする前に、文書にカーソルを配置します。 UI は、インサート、フルアップデート、ページ番号のみの更新、削除を処理します。 `rangeId` が渡されないと、更新は現在の選択でコンテンツの表を対象としています。

```ts
import { InsertTableOfContentsCommand, UpdateTableOfContentsCommand } from '@univerjs/docs-toc'

await univerAPI.executeCommand(InsertTableOfContentsCommand.id, {
  levels: 3,
  showPageNumbers: true,
  rightAlignPageNumbers: true,
})
await univerAPI.executeCommand(UpdateTableOfContentsCommand.id, { mode: 'entireTable' })
```

updater は、アウトラインレベルのテーブルのコンテンツの指示 (`\o`) を評価します。インポートされたファイルから他のワードスイッチは FIELD メタデータに残りますが、それらはすべて評価されません。 [コマンドパラメータ](/reference/packages/plugins/univerjs/docs-toc) を参照してください。
