<Callout type="warning">
  Используете **0.25.x**? Откройте [архив документации Pro](https://dream-num.github.io/documentation/v0.25/zh-CN/guides/pro/). Для новых интеграций используется самостоятельно размещаемый Collaboration SDK; инструкции и API прежнего Univer Server не применяются.
</Callout>

Следуйте руководству по [Интеграция совместного редактирования](/guides/server-integration/collaboration): запустите пример, подключите приложение и проверьте хранение данных и права доступа. Реализация и примеры Web/Server находятся в [Univer Office](https://office.univer.ai/collaboration/quick-start).

Создайте Unit через бизнес-API с аутентификацией, вызывающий Collaboration Service, затем загрузите полученный ID в браузере. Настройте HTTP, Session Ticket и WebSocket по [Quick Start](https://office.univer.ai/collaboration/quick-start), хранение через Database Adapter и отдельные [проверки прав](https://office.univer.ai/collaboration/identity-and-authorization) на чтение, JOIN и изменение.

## Facade API [#loading-collaborative-documents]

```ts
import '@univerjs-pro/collaboration-client/facade'

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadDocAsync('your-unit-id')
```
