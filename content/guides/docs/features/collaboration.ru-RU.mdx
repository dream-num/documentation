Следуйте руководству по [Интеграция совместного редактирования](/server/collaboration/browser-integration): запустите пример, подключите приложение и проверьте хранение данных и права доступа. Реализация и примеры Web/Server находятся в [Univer Office](/server/collaboration/quick-start).

Создайте Unit через бизнес-API с аутентификацией, вызывающий Collaboration Service, затем загрузите полученный ID в браузере. Настройте HTTP, Session Ticket и WebSocket по [Quick Start](/server/collaboration/quick-start), хранение через Database Adapter и отдельные [проверки прав](/server/collaboration/identity-and-authorization) на чтение, JOIN и изменение.

## Facade API [#loading-collaborative-documents]

```ts
import '@univerjs-pro/collaboration-client/facade'

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadDocAsync('your-unit-id')
```
