LaTeX 公式功能會把可編輯的公式源碼保存到 Docs 模型中，並在瀏覽器編輯器中渲染出來。

## 外掛模式

### 安裝

```package-install
npm install @univerjs-pro/docs-latex @univerjs-pro/docs-latex-ui
```

### 使用

```typescript
import { UniverDocsLatexPlugin } from '@univerjs-pro/docs-latex' // [!code ++]
import { UniverDocsLatexUIPlugin } from '@univerjs-pro/docs-latex-ui' // [!code ++]
import DocsLatexUIZhTW from '@univerjs-pro/docs-latex-ui/locale/zh-TW' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-latex-ui/lib/index.css' // [!code ++]
import '@univerjs-pro/docs-latex/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      DocsLatexUIZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsLatexPlugin) // [!code ++]
univer.registerPlugin(UniverDocsLatexUIPlugin) // [!code ++]
```

如果你擁有 Univer 商業授權，請參考 [在客戶端使用 License](/guides/pro/license#in-plugin-mode)。

## Facade API

呼叫 LaTeX API 前先引入 facade 入口：

```typescript
import '@univerjs-pro/docs-latex/facade'
```

向目前文件插入公式：

```typescript
const doc = univerAPI.getActiveDocument()

const formula = doc?.insertLatexFormula({
  latex: 'E=mc^2',
  index: 12,
})
```

讀取並更新公式：

```typescript
const formulas = doc?.getLatexFormulas() ?? []
const firstFormula = doc?.findLatexFormulaByText('mc')

firstFormula?.update({
  latex: '\\frac{a}{b}',
})
```

也可以按 range id 或文件 data-stream offset 查詢：

```typescript
const byId = doc?.getLatexFormula('formula-range-id')
const atOffset = doc?.getLatexFormulaAt(42)

console.log(byId?.describe(), atOffset?.getLatex())
```
