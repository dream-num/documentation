La inserción rápida proporciona un menú de estilo de comando de barra diagonal para insertar contenido. Escriba `/` al comienzo de una línea vacía para abrir el menú e insertar rápidamente texto, listas, divisores, tablas, imágenes y más. Actualmente, esta función solo admite el modo complemento.

## Interacciones

- Escriba `/` al comienzo de una línea para abrir el menú
- Aparece un botón `+` a la izquierda de un párrafo vacío; haz clic en él para abrir todos los menús disponibles
- Escribe para filtrar; use ↑/↓ para navegar, Enter para insertar, Esc para cerrar

## Modo de complemento

### Instalación

```package-install
npm install @univerjs/docs-quick-insert-ui
```

### Uso

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsQuickInsertUIPlugin } from '@univerjs/docs-quick-insert-ui' // [!code ++]
import DocsQuickInsertUIEnUS from '@univerjs/docs-quick-insert-ui/locale/en-US' // [!code ++]

import '@univerjs/docs-quick-insert-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsQuickInsertUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsQuickInsertUIPlugin) // [!code ++]
```

## Compatibilidad móvil [#mobile-support]

Configure primero el [editor móvil](/guides/docs/getting-started/installation#mobile-support). En la inicialización en modo plugin de esta página, sustituya los registros de escritorio siguientes por las exportaciones móviles de los mismos paquetes **antes de abrir un documento**. Conserve modelos, estilos, traducciones e importaciones Facade; no registre ambas variantes.

| Paquete | Registro de escritorio | Registro móvil |
| --- | --- | --- |
| `@univerjs/docs-quick-insert-ui` | `UniverDocsQuickInsertUIPlugin` | `UniverDocsQuickInsertMobileUIPlugin` |
