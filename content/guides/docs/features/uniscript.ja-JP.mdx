Uniscript は Facade API をオンラインで素早く追加/編集できる機能です。インストールするとツールバーに新しいボタンが表示され、クリックするとサイドバーが開きます。ここでコードを入力して実行できます。ドキュメント内の `univerAPI` から始まるコードはすべてここで実行可能です。

<Callout title="補足">
  Uniscript のパネルには Facade API のインスタンス `univerAPI` が注入されており、ドキュメントで紹介されている Facade API をそのまま呼び出せます。
</Callout>

## プリセットモード

Uniscript はプリセットを提供していませんが、プラグインとして組み合わせて利用できます。

### インストール

```package-install
npm install @univerjs/uniscript
```

### 使い方

```typescript
import { UniverUniscriptPlugin } from '@univerjs/uniscript' // [!code ++]

import '@univerjs/uniscript/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetDocsCoreJaJP,
      UniscriptJaJP, // [!code ++]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
  ],
  plugins: [
    UniverUniscriptPlugin, // [!code ++]
  ],
})
```

## プラグインモード

### インストール

```package-install
npm install @univerjs/uniscript
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverUniscriptPlugin } from '@univerjs/uniscript' // [!code ++]

import '@univerjs/uniscript/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniscriptJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverUniscriptPlugin) // [!code ++]
```
