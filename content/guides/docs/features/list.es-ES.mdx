Las listas mejoradas extienden los Docs Univer con niveles anidados, glifos personalizados y la edición de la estructura de la lista.

## Introducción

En Univer Docs, las listas mejoradas proporcionan las siguientes capacidades:

- Múltiples niveles de anidación.
- Una selección de símbolos de bala y estilos de numeración.
- Promover, demotar y reordenar las operaciones en los artículos de la lista.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/docs-list @univerjs-pro/docs-list-ui
```

### Uso

```typescript
import { UniverDocsListPlugin } from '@univerjs-pro/docs-list' // [!code ++]
import { UniverDocsListUIPlugin } from '@univerjs-pro/docs-list-ui' // [!code ++]
import DocsListUIEnUS from '@univerjs-pro/docs-list-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-list-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsListUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsListPlugin) // [!code ++]
univer.registerPlugin(UniverDocsListUIPlugin) // [!code ++]
```

Si utiliza una licencia comercial, configure como se describe en [Utilizando Licencia en Cliente](/server/license#in-plugin-mode).

## Compatibilidad móvil [#mobile-support]

Configurar el [editor móvil](/guides/docs/getting-started/installation#mobile-support) primero. En la configuración de modo plugin descrita en esta página, sustitúyase el registro de escritorio mostrado a continuación con la exportación móvil del mismo paquete, y complete el reemplazo **antes de abrir un documento**. Mantenga los plugins modelo, estilos, locales y las importaciones Facade, y no registre ambas variantes.

| Paquete | Registro de escritorio | Registro móvil |
| --- | --- | --- |
| `@univerjs-pro/docs-list-ui` | `UniverDocsListUIPlugin` | `UniverDocsListMobileUIPlugin` |

## API de fachada

Importar la fachada antes de llamar a cualquiera de las siguientes API:

```typescript
import '@univerjs-pro/docs-list/facade'
```

### Insertar una lista

```typescript
import { PresetListType } from '@univerjs/core'

const doc = univerAPI.getActiveDocument()
doc?.insertList({
  startOffset: 0,
  endOffset: 10,
  listType: PresetListType.BULLET_LIST,
})
```

### Obtener todas las listas

```typescript
const doc = univerAPI.getActiveDocument()
const lists = doc?.getLists() ?? []
```

### Establecer tipo de glifo de lista

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListGlyphType(0, ListGlyphType.DECIMAL)
```

### Establecer nivel de lista

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListLevel(0, 1)
```
