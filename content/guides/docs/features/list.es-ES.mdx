La función de lista mejorada proporciona capacidades de lista avanzadas para Univer Docs, incluidas listas anidadas, glifos personalizados y manipulación flexible de listas.

## Introducción

En Univer Docs, las listas mejoradas le permiten:

- **Crear listas anidadas**: crear jerarquías de listas de varios niveles.
- **Personalizar glifos**: usar diferentes símbolos de viñetas y numeración estilos.
- **Manipular la estructura de la lista**: promocionar, degradar y reordenar elementos de la lista.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/docs-list @univerjs-pro/docs-list-ui
```

### Uso

```typescript
import { UniverDocsListPlugin } from '@univerjs-pro/docs-list' // [!code ++]
import { UniverDocsListUIPlugin } from '@univerjs-pro/docs-list-ui' // [!code ++]
import DocsListUIEnUS from '@univerjs-pro/docs-list-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-list-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsListUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsListPlugin) // [!code ++]
univer.registerPlugin(UniverDocsListUIPlugin) // [!code ++]
```

Si tiene una licencia comercial de Univer, consulte [Uso de la licencia en el cliente](/guides/pro/license#in-plugin-mode) para la configuración.

## API de fachada

Asegúrese de importar la fachada antes de usar la API:

```typescript
import '@univerjs-pro/docs-list/facade'
```

### Insertar una lista

```typescript
import { PresetListType } from '@univerjs/core'

const doc = univerAPI.getActiveDocument()
doc?.insertList({
  startOffset: 0,
  endOffset: 10,
  listType: PresetListType.BULLET_LIST,
})
```

### Obtener todas las listas

```typescript
const doc = univerAPI.getActiveDocument()
const lists = doc?.getLists() ?? []
```

### Establecer tipo de glifo de lista

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListGlyphType(0, ListGlyphType.DECIMAL)
```

### Establecer nivel de lista

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListLevel(0, 1)
```
