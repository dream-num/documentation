La función de marca de agua tiene como objetivo proporcionar una solución de marca de agua flexible y segura para páginas web o aplicaciones. Con esta función, los desarrolladores pueden generar dinámicamente marcas de agua de texto o imágenes en la página para evitar el uso no autorizado o la difusión de contenido, y admite varias configuraciones.

<PlaygroundFrame lang="en-US" slug="docs/watermark" clickToShow />

## Modo preestablecido

La marca de agua no proporciona un ajuste preestablecido, pero admite la mezcla con sus complementos.

### Instalación

```package-install
npm install @univerjs/watermark
```

### Uso

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverDocsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## Modo de complemento

### Instalación

```package-install
npm install @univerjs/watermark
```

### Uso

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

### Complementos y Configuración

#### @univerjs/watermark

Este complemento proporciona la implementación principal de la funcionalidad de marca de agua. Permite a los desarrolladores agregar marcas de agua de texto o imágenes a las aplicaciones y ofrece varias opciones de configuración para personalizar la apariencia y el comportamiento de la marca de agua. Proporciona el complemento `UniverWatermarkPlugin`.

Referencia: [@univerjs/watermark](https://docs.univer.ai/reference/packages/plugins/univerjs/watermark)

## API de Facade

### Importación

<Callout type="info" title="Plugin mode note">
Solo el modo complemento requiere importar manualmente el paquete Facade. El modo preestablecido ya incluye el paquete Facade correspondiente, por lo que no se necesita ninguna importación adicional.
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### Establecer marca de agua

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### Eliminar marca de agua

```typescript
univerAPI.deleteWatermark()
```
