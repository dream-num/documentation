Las marcas de agua son superposiciones de texto o imagen en una página web o aplicación que evitan que el contenido se utilice o se apruebe sin permiso. Se generan dinámicamente y ofrecen una serie de opciones de configuración.

<Callout type="info">
  Utilice el [Watermark Generator](/tools/watermark-generator) para previsualizar estilos de marca de agua y descargar la configuración de plugin como JSON.
</Callout>

<PlaygroundFrame lang="en-US" slug="docs/watermark" clickToShow />

## Modo de complemento

### Instalación

```package-install
npm install @univerjs/watermark
```

### Uso

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

## Modo preestablecido

No existe preset de marca de agua, pero el plugin puede ser registrado junto a sus presets.

### Instalación

```package-install
npm install @univerjs/watermark
```

### Uso

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverDocsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## API de Facade

### Importación

<Callout type="info" title="Nota del modo Plugin">
  Sólo el modo plugin requiere una importación manual Facade. El modo Preset ya agrupa el paquete Facade, por lo que no se necesita ninguna importación adicional.
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### Establecer marca de agua

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### Eliminar marca de agua

```typescript
univerAPI.deleteWatermark()
```
