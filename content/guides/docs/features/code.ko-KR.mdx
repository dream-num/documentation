코드 블록 기능을 사용하면 Prism.js 기반의 구문 강조와 함께 서식이 적용된 코드 조각을 문서에 삽입하고 표시할 수 있습니다.

## 소개

Univer Docs에서 코드 블록을 사용하면 다음 작업을 할 수 있습니다.

- **코드 조각 삽입**: 문서 어디에나 서식이 적용된 코드 블록을 추가합니다.
- **구문 강조**: 언어에 따라 코드를 자동으로 강조합니다.
- **종료 및 취소**: 빈 단락에서 코드 서식을 간편하게 종료하거나 취소합니다.

## 플러그인 모드

### 설치

```package-install
npm install @univerjs-pro/docs-code @univerjs-pro/docs-code-ui
```

### 사용법

```typescript
import { UniverDocsCodePlugin } from '@univerjs-pro/docs-code' // [!code ++]
import { UniverDocsCodeUIPlugin } from '@univerjs-pro/docs-code-ui' // [!code ++]
import DocsCodeUIEnUS from '@univerjs-pro/docs-code-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-code-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCodeUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCodePlugin) // [!code ++]
univer.registerPlugin(UniverDocsCodeUIPlugin) // [!code ++]
```

Univer 상용 라이선스가 있다면 구성 방법은 [클라이언트에서 라이선스 사용](/guides/pro/license#in-plugin-mode)을 참고하세요.

## Facade API

API를 사용하기 전에 facade를 가져와야 합니다.

```typescript
import '@univerjs-pro/docs-code/facade'
```

### 모든 코드 블록 가져오기

```typescript
const doc = univerAPI.getActiveDocument()
const codes = doc?.getCodes() ?? []
```

### 코드 블록 삽입

```typescript
const doc = univerAPI.getActiveDocument()
const code = doc?.insertCode({
  startOffset: 12,
  endOffset: 35,
})
```

### 코드 블록 종료

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitCode()
```

### 빈 코드 단락 취소

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyCodeParagraph()
```
