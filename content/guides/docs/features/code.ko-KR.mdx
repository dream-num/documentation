문서 내의 코드 블록 장소 형식화 된 코드. Syntax 강조는 Prism.js에 의해 제공됩니다.

## 소개

Univer Docs에서, 코드 블록은 몇 가지 일반적인 요구를 제공합니다:

- 포맷 된 코드 블록은 문서에서 어디에서든지 삽입 할 수 있습니다.
- 코드는 언어에 따라 자동으로 강조됩니다.
- 빈 코드 단락은 사용자가 블록을 종료하거나 코드 형식을 취소 할 수 있습니다.

## 플러그인 모드

### 설치

```package-install
npm install @univerjs-pro/docs-code @univerjs-pro/docs-code-ui
```

### 사용법

```typescript
import { UniverDocsCodePlugin } from '@univerjs-pro/docs-code' // [!code ++]
import { UniverDocsCodeUIPlugin } from '@univerjs-pro/docs-code-ui' // [!code ++]
import DocsCodeUIEnUS from '@univerjs-pro/docs-code-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-code-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCodeUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCodePlugin) // [!code ++]
univer.registerPlugin(UniverDocsCodeUIPlugin) // [!code ++]
```

애플리케이션이 상용 라이선스에 따라 Univer를 사용한다면 [Client의 라이센스 사용](/server/license#in-plugin-mode)에 설명된 것과 같이 구성합니다.

## 모바일 지원 [#mobile-support]

[모바일 편집기](/guides/docs/getting-started/installation#mobile-support)를 먼저 구성하십시오. 이 페이지의 플러그인 모드 설정에서 동일한 패키지에서 모바일 수출으로 나열된 데스크탑 등록을 대체하고 **문서 열기** 교체하십시오. 모델 플러그인, 스타일, 로컬 및 Facade 가져 오기를 유지하고 두 가지 변형을 등록하지 마십시오.

| 패키지 | 데스크톱 등록 | 모바일 등록 |
| --- | --- | --- |
| `@univerjs-pro/docs-code-ui` | `UniverDocsCodeUIPlugin` | `UniverDocsCodeMobileUIPlugin` |

## Facade API

이 방법을 호출하기 전에 정면을 가져 오기 :

```typescript
import '@univerjs-pro/docs-code/facade'
```

### 모든 코드 블록 가져오기

```typescript
const doc = univerAPI.getActiveDocument()
const codes = doc?.getCodes() ?? []
```

### 코드 블록 삽입

```typescript
const doc = univerAPI.getActiveDocument()
const code = doc?.insertCode({
  startOffset: 12,
  endOffset: 35,
})
```

### 코드 블록 종료

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitCode()
```

### 빈 코드 단락 취소

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyCodeParagraph()
```

## 코드 블록 고정폭 글꼴 [#code-fonts]

코드 블록 도구 모음의 글꼴 선택은 `FontCategory.MONOSPACE`에 등록 된 글꼴 만 나열합니다. 글꼴 선택은 단락 스타일을 포함하여 전체 코드 블록에 적용됩니다.

사용자 정의 모노 공간 글꼴을 등록하려면 `addFonts()`로 전화하십시오.

```ts
import { FontCategory } from '@univerjs/ui'
import '@univerjs/ui/facade'

univerAPI.addFonts([
  { value: 'JetBrains Mono', label: 'JetBrains Mono', category: FontCategory.MONOSPACE },
])
```

등록은 픽업자에게만 입력합니다. 글꼴 파일 자체는 [사용자 정의 글꼴](/guides/docs/ui/fonts)에 설명된 것과 같이 CSS 또는 Browser FontFace API로 로드되어야 합니다. 이 방법은 플러그인과 사전 설정 초기화와 함께 작동합니다.
