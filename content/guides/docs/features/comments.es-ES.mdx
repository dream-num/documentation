Los usuarios pueden agregar comentarios y respuestas dentro de un documento, por lo que los miembros del equipo pueden discutir el contenido en su lugar.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs/docs-thread-comment @univerjs/docs-thread-comment-ui
```

### Uso

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsThreadCommentPlugin } from '@univerjs/docs-thread-comment' // [!code ++]
import { UniverDocsThreadCommentUIPlugin } from '@univerjs/docs-thread-comment-ui' // [!code ++]
import { UniverThreadCommentPlugin } from '@univerjs/thread-comment' // [!code ++]
import { UniverThreadCommentUIPlugin } from '@univerjs/thread-comment-ui' // [!code ++]
import DocsCommentLocale from '@univerjs/docs-thread-comment-ui/locale/en-US'
import ThreadCommentUIEnUS from '@univerjs/thread-comment-ui/locale/en-US' // [!code ++]
import '@univerjs/docs-thread-comment/facade' // [!code ++]
import '@univerjs/docs-thread-comment-ui/lib/index.css'
import '@univerjs/thread-comment-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      ThreadCommentUIEnUS,
      DocsCommentLocale, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverThreadCommentPlugin) // [!code ++]
univer.registerPlugin(UniverThreadCommentUIPlugin) // [!code ++]
univer.registerPlugin(UniverDocsThreadCommentPlugin) // [!code ++]
univer.registerPlugin(UniverDocsThreadCommentUIPlugin) // [!code ++]
```

#### Uso con la función de colaboración

Si la aplicación utiliza [Colaboración](/guides/docs/features/collaboration), registre el plugin de fuente de datos también:

```package-install
npm install @univerjs-pro/thread-comment-datasource
```

```typescript
import { UniverThreadCommentDataSourcePlugin } from '@univerjs-pro/thread-comment-datasource' // [!code ++]

univer.registerPlugin(UniverThreadCommentDataSourcePlugin) // [!code ++]
```

## Compatibilidad móvil [#mobile-support]

Configure el [editor móvil](/guides/docs/getting-started/installation#mobile-support) primero. En la configuración de modo plugin en esta página, sustitúyase los registros de escritorio enumerados a continuación con las exportaciones móviles de los mismos paquetes, y haga el reemplazo **antes de abrir un documento**. Mantenga los plugins modelo, estilos, locales y las importaciones Facade, y no registre ambas variantes.

| Paquete | Registro de escritorio | Registro móvil |
| --- | --- | --- |
| `@univerjs/docs-thread-comment-ui` | `UniverDocsThreadCommentUIPlugin` | `UniverDocsThreadCommentMobileUIPlugin` |
| `@univerjs/thread-comment-ui` | `UniverThreadCommentUIPlugin` | `UniverThreadCommentMobileUIPlugin` |

## Modo de preset

### Instalación

```package-install
npm install @univerjs/preset-docs-thread-comment
```

### Usage

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEnUS from '@univerjs/preset-docs-core/locales/en-US'
import { UniverDocsThreadCommentPreset } from '@univerjs/preset-docs-thread-comment' // [!code ++]
import UniverPresetDocsThreadCommentEnUS from '@univerjs/preset-docs-thread-comment/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-thread-comment/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetDocsCoreEnUS,
      UniverPresetDocsThreadCommentEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
    UniverDocsThreadCommentPreset(), // [!code ++]
  ],
})
```

## Facade de comentarios [#comment-facade]

Importar el comentario compartido Facade y el producto Facade antes de llamar estos métodos. Los ayudantes del producto crean anclas estables, y la API compartida maneja respuestas, actualizaciones, resolución y eliminación. `getComments()` lee el estado local. `listCommentsAsync()` sincroniza los hilos que ya se conocen a través de la fuente de datos configurada; no descubre cada hilo en el servidor.

```ts
import '@univerjs/thread-comment/facade'
import '@univerjs/docs-thread-comment/facade'

const range = univerAPI.getActiveDocument()?.getTextRange(0, 1)
if (range) {
  await range.createCommentAsync('Please review this text.')
  console.log(await range.listCommentsAsync())
}
```

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## Conversaciones compartidas [#shared-discussions]

Los debates compartidos requieren que el servicio de comentarios y el punto final estén conectados a través de [Server SDK](/server/collaboration/extensions). Después de la configuración de la colaboración y la licencia, regístrese `UniverThreadCommentDataSourcePlugin` de `@univerjs-pro/thread-comment-datasource`. La fuente de datos suministrada llama `/universer-api/comment/unit/{unitId}/...` y `/universer-api/user/list`, por lo que la aplicación debe exponer esas rutas.

## Comentarios en imágenes y gráficos [#object-comments]

Configure el dibujo host o plugins de gráficos primero, a continuación, agregue la integración que coincide a continuación y su entrada Facade antes de abrir la Unidad. Modo de plugin y modo preset ambos requieren que estas integraciones sean registradas explícitamente.

```package-install
npm install @univerjs-pro/docs-drawing-thread-comment @univerjs-pro/docs-chart-thread-comment
```

```typescript
import { UniverDocsDrawingThreadCommentPlugin } from '@univerjs-pro/docs-drawing-thread-comment'
import { UniverDocsChartThreadCommentPlugin } from '@univerjs-pro/docs-chart-thread-comment'
import '@univerjs-pro/docs-drawing-thread-comment/facade'
import '@univerjs-pro/docs-chart-thread-comment/facade'

univer.registerPlugin(UniverDocsDrawingThreadCommentPlugin)
univer.registerPlugin(UniverDocsChartThreadCommentPlugin)
```

Después de que una Unidad esté abierta, se pueden añadir comentarios a imágenes y gráficos que ya existen en ella. `getComments()` devuelve los hilos cargados localmente, y `listCommentsAsync()` sincroniza los hilos que sabe antes de devolverlos.

```typescript
const host = univerAPI.getActiveDocument()
const image = host?.getImages()[0]
const chart = host?.getCharts()[0]
await image?.createCommentAsync('Review this image.')
await chart?.createCommentAsync('Verify the chart source.')
```
