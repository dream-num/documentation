このページの API は、変換バックエンドが必要です。[ファイル交換統合](/server/import-export) に従って、アップロード、変換、タスクのクエリ、ダウンロードを接続し、ブラウザプラグインの設定を行います。スナップショット API はバックエンドも必要ですが、共同ドキュメントを必要としません。コラボレーション Exchange の例は、Sheet を実証しているため、ターゲットリリースが必要なファイルタイプをサポートすることを検証します。

エクスポートが失敗した場合は、[ライセンスエラーコードとタスクの失敗処理](/server/import-export#export-errors) を参照してください。

## 対応形式

このページでは、ブラウザ API を記述しています。Office ファイルの変換には、同じドキュメントタイプとフォーマットをサポートするバックエンドが必要です。

| インポート | エクスポート |
| --- | --- |
| `.doc`, `.docx` | `.docx` |

`.doc`と`.docx`は、以下のインポートAPIを使用します。 エクスポートは常に`.docx`を生成します。 従来の`.doc`フォーマットはエクスポートできません。

## Facade API

### インポート

<Callout type="info" title="プラグインモードノート">
  プラグインモードのみ、Facadeパッケージを手動でインポートする必要があります。プリセットモードには、対応するファサードパッケージが含まれているため、追加のインポートは必要ありません。
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/docs-exchange-client/facade'
```

### `.docx` のインポート

#### `.docx` をインポートして `unitId` を取得

<Callout type="warning" title="キューション">
  この方法は、サーバー上にドキュメントを作成し、`unitId`を返すため、コラボレーションが必要です。コラボレーションが有効になっていない場合は、スナップショットのインポートを使用します。
</Callout>

共同編集が有効になっている場合、各ドキュメントには独自の`unitId`があります。`file`パラメータで`univerAPI.importDocToUnitIdAsync`を呼び出すと、`unitId`が返されます。これにより、ドキュメントへのアクセスに使用されます。`file`パラメーターは`File`オブジェクトまたはリモートファイルURLを受け付けます。

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importDocToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadDocAsync(unitId)
}
```

#### `.docx` をインポートして `IDocumentData` を取得

<Callout>スナップショットのインポートはコラボレーションを必要としません。ドキュメントがコラボレーションを必要とするときに`unitId`のインポートを使用してください。</Callout>

`univerAPI.importDocToSnapshotAsync`は`.docx`ファイルをインポートし、`IDocumentData`としてドキュメントデータを返します。

```typescript
// File オブジェクトを受け取る
const snapshot = await univerAPI.importDocToSnapshotAsync(file)
// リモート URL を受け取る
// const snapshot = await univerAPI.importDocToSnapshotAsync('https://example.com/filename.docx');

// スナップショットから新規ドキュメントを作成
if (snapshot) univerAPI.createDocument(snapshot)
```

### `.docx` のエクスポート

#### `unitId` で `.docx` をエクスポート

<Callout type="warning" title="注意事項">
  `unitId` でのエクスポートは共同編集が必要です。共同編集がない場合はスナップショットを使用してください。
</Callout>

共同編集を有効にすると、各ドキュメントは独自の`unitId`を持っています。 `univerAPI.exportDocByUnitIdAsync`パラメータで`unitId`を呼び出して、`File`オブジェクトを受け取ります。

```typescript
const fDocument = univerAPI.getActiveDocument()
const unitId = fDocument.getId()
const file = await univerAPI.exportDocByUnitIdAsync(unitId)

// Facade API でファイルをダウンロード
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

#### `IDocumentData` で `.docx` をエクスポート

<Callout>スナップショットのエクスポートは共同編集不要で、ローカル処理向きです。</Callout>

`univerAPI.exportDocBySnapshotAsync`は`IDocumentData`を受け入れ、`File`オブジェクトを返します。

```typescript
const fDocument = univerAPI.getActiveDocument()
const snapshot = fDocument.save()
const file = await univerAPI.exportDocBySnapshotAsync(snapshot)

// Facade API でファイルをダウンロード
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

## 組み込みのインポート・エクスポートメニューと UI 操作の削除 [#import-export-ui-migration]

<Callout type="warning" title="注意:">
  バージョン**1.2.0**から、Univerは、組み込みのインポート/エクスポートメニューやUIのインタラクションが不要です。 アンダーリングサービスとファサードAPIは利用できます。
</Callout>

アプリケーションがまだそれらのメニューとUIの相互作用を必要とする場合、[組み込みのインポート/エクスポートメニューとUIインタラクションのマイグレーション例](https://office.univer.ai/showcase/docs/custom-import-export)は、それらをカスタムプラグインに移動する方法を示しています。 例には、オンラインで閲覧したり、ダウンロードしたりできる完全なソースコードが含まれています。
