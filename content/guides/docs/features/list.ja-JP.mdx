リストの強化は、Univer Docs をネストされたレベル、カスタム グリフ、リスト構造の編集で拡張します。

## はじめに

Univer Docs では、強化されたリストは次の機能を提供します。

- 複数のネスティングレベル。
- 弾丸シンボルと番号のスタイルの選択。
- リスト項目の操作を促進、削除、および再注文する。

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/docs-list @univerjs-pro/docs-list-ui
```

### 使用法

```typescript
import { UniverDocsListPlugin } from '@univerjs-pro/docs-list' // [!code ++]
import { UniverDocsListUIPlugin } from '@univerjs-pro/docs-list-ui' // [!code ++]
import DocsListUIJaJP from '@univerjs-pro/docs-list-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-list-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsListUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsListPlugin) // [!code ++]
univer.registerPlugin(UniverDocsListUIPlugin) // [!code ++]
```

商用ライセンスを使用する場合は、[クライアントでのライセンスの使用](/server/license#in-plugin-mode) で説明するように設定します。

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/docs/getting-started/installation#mobile-support)を最初にセットアップします。このページに記載されているプラグインモード設定では、同じパッケージからモバイルエクスポートで示されているデスクトップ登録を置き換え、交換**ドキュメントを開く前に**を完了します。モデルプラグイン、スタイル、ロケール、ファサードのインポートを保持し、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/docs-list-ui` | `UniverDocsListUIPlugin` | `UniverDocsListMobileUIPlugin` |

## Facade API

以下の API のいずれかを呼び出す前にファサードをインポートします。

```typescript
import '@univerjs-pro/docs-list/facade'
```

### リストを挿入

```typescript
import { PresetListType } from '@univerjs/core'

const doc = univerAPI.getActiveDocument()
doc?.insertList({
  startOffset: 0,
  endOffset: 10,
  listType: PresetListType.BULLET_LIST,
})
```

### すべてのリストを取得

```typescript
const doc = univerAPI.getActiveDocument()
const lists = doc?.getLists() ?? []
```

### リスト記号タイプを設定

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListGlyphType(0, ListGlyphType.DECIMAL)
```

### リストレベルを設定

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListLevel(0, 1)
```
