検索と置換では、表を含む現在の文書本文からリテラル文字列を検索できます。大文字と小文字の区別、単語単位の一致、候補間の移動、現在またはすべての一致の置換に対応しています。

<Callout type="info">
  ヘッダー、フッター、コメント、描画、正規表現、書式検索、特殊文字には対応していません。
</Callout>

## プラグインモード

### インストール

```package-install
npm install @univerjs/find-replace @univerjs/docs-find-replace
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsFindReplacePlugin } from '@univerjs/docs-find-replace'
import FindReplaceJaJP from '@univerjs/find-replace/locale/ja-JP'

import '@univerjs/find-replace/lib/index.css'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(FindReplaceJaJP),
  },
})

univer.registerPlugin(UniverDocsFindReplacePlugin)
```

## キーボードショートカット

- `Ctrl/Cmd + F`：検索を開く
- `Ctrl/Cmd + H`：置換を開く
- `Enter` / `Shift + Enter`：次 / 前の一致
- `Escape`：文書にフォーカスを戻す
