Las notas de pie de página y las notas se aplican a los documentos tradicionales y paginados. Una nota de pie se expone en la página que lo hace referencia; una nota de final se coloca de acuerdo con la configuración de notas del documento. Esta API no admite documentos modernos.

## Modo de complemento [#plugin-mode]

### Instalación

```package-install
npm install @univerjs-pro/docs-reference @univerjs-pro/docs-reference-ui
```

### Uso

Añadir estos plugins a un editor de Docs con una licencia configurada, y cargar los estilos de UI y el local que coincide con el editor.

```ts
import { UniverDocsReferencePlugin } from '@univerjs-pro/docs-reference'
import { UniverDocsReferenceUIPlugin } from '@univerjs-pro/docs-reference-ui'
import ReferenceLocale from '@univerjs-pro/docs-reference-ui/locale/es-ES'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/docs-reference/facade'
import '@univerjs-pro/docs-reference-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.ES_ES, ReferenceLocale)
univer.registerPlugin(UniverDocsReferencePlugin)
univer.registerPlugin(UniverDocsReferenceUIPlugin)
```

## Modo preestablecido [#preset-mode]

### Instalación

```package-install
npm install @univerjs/presets @univerjs/preset-docs-core @univerjs/preset-docs-drawing @univerjs/preset-docs-advanced
```

### Uso

`UniverDocsAdvancedPreset` ya incluye ambos plugins. Cuando utiliza este preset, mantenga su registro y no agregue los plugins de nuevo.

Combina el núcleo, el dibujo y los presets avanzados, y fusiona sus recursos locales. La licencia del cliente se configura como se describe en [usando una licencia](/server/license#in-preset-mode).

```ts
import { UniverDocsAdvancedPreset } from '@univerjs/preset-docs-advanced'
import AdvancedLocale from '@univerjs/preset-docs-advanced/locales/es-ES'
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import CoreLocale from '@univerjs/preset-docs-core/locales/es-ES'
import { UniverDocsDrawingPreset } from '@univerjs/preset-docs-drawing'
import DrawingLocale from '@univerjs/preset-docs-drawing/locales/es-ES'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-drawing/lib/index.css'
import '@univerjs/preset-docs-advanced/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.ES_ES,
  locales: {
    [LocaleType.ES_ES]: mergeLocales(CoreLocale, DrawingLocale, AdvancedLocale),
  },
  presets: [
    UniverDocsCorePreset({ container: 'app' }),
    UniverDocsDrawingPreset(),
    UniverDocsAdvancedPreset(),
  ],
})
```

### Configuración de preajustes [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | Elemento DOM donde se monta el editor o su ID. |

## Insertar y gestionar notas

```ts
const document = univerAPI.getActiveDocument()
if (document) {
  const noteId = document.insertFootnote(0)
  if (noteId) console.log(document.getParagraphs(noteId))
  console.log(document.getFootnotes(), document.getEndnotes())
}
```

El offset es una posición UTF-16 en el cuerpo principal y cuenta con fichas estructurales. La inserción devuelve `null` cuando la posición es inválida, el contenido de nota es inválvido, el callador carece de permiso, o el documento es moderno. De lo contrario, devuelve un ID de nota estable. La referencia y el contenido de la nota pertenecen al mismo paso de deshacer y la misma mutación de colaboración.

Lea las notas con `getFootnotes()` / `getEndnotes()` y retírelas con el número y la colocación de `deleteFootnote(noteId)`/`deleteEndnote(noteId)`. `setFootnoteSettings()` o `setEndnoteSettings()`, y pasando `null` despeja cualquier configuración explícita. Mantenga el ID de la nota devuelta para abordar el contenido, ya que los números mostrados pueden cambiar después de la paginación.
