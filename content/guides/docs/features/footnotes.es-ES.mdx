Añade notas a documentos tradicionales paginados. Las notas al pie se colocan en la página de su referencia y las notas al final siguen la configuración del documento. Esta API no admite documentos modernos.

## Modo de complemento [#plugin-mode]

### Instalación

```package-install
npm install @univerjs-pro/docs-reference @univerjs-pro/docs-reference-ui
```

### Uso

Añade estos plugins a un editor Docs con la licencia configurada. Carga los estilos y los recursos del idioma del editor.

```ts
import { UniverDocsReferencePlugin } from '@univerjs-pro/docs-reference'
import { UniverDocsReferenceUIPlugin } from '@univerjs-pro/docs-reference-ui'
import ReferenceLocale from '@univerjs-pro/docs-reference-ui/locale/es-ES'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/docs-reference/facade'
import '@univerjs-pro/docs-reference-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.ES_ES, ReferenceLocale)
univer.registerPlugin(UniverDocsReferencePlugin)
univer.registerPlugin(UniverDocsReferenceUIPlugin)
```

## Modo preestablecido [#preset-mode]

### Instalación

```package-install
npm install @univerjs/presets @univerjs/preset-docs-core @univerjs/preset-docs-drawing @univerjs/preset-docs-advanced
```

### Uso

`UniverDocsAdvancedPreset` ya incluye ambos plugins. Si utilizas ese preset, no los registres de nuevo.

Combina los presets principal, de dibujo y avanzado, y fusiona sus recursos de idioma. Configura la licencia del cliente según [Uso de la licencia](/server/license#in-preset-mode).

```ts
import { UniverDocsAdvancedPreset } from '@univerjs/preset-docs-advanced'
import AdvancedLocale from '@univerjs/preset-docs-advanced/locales/es-ES'
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import CoreLocale from '@univerjs/preset-docs-core/locales/es-ES'
import { UniverDocsDrawingPreset } from '@univerjs/preset-docs-drawing'
import DrawingLocale from '@univerjs/preset-docs-drawing/locales/es-ES'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-drawing/lib/index.css'
import '@univerjs/preset-docs-advanced/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.ES_ES,
  locales: {
    [LocaleType.ES_ES]: mergeLocales(CoreLocale, DrawingLocale, AdvancedLocale),
  },
  presets: [
    UniverDocsCorePreset({ container: 'app' }),
    UniverDocsDrawingPreset(),
    UniverDocsAdvancedPreset(),
  ],
})
```

## Insertar y gestionar notas

```ts
const document = univerAPI.getActiveDocument()
if (document) {
  const noteId = document.insertFootnote(0)
  if (noteId) console.log(document.getParagraphs(noteId))
  console.log(document.getFootnotes(), document.getEndnotes())
}
```

El desplazamiento es una posición UTF-16 del cuerpo principal, incluidos los tokens estructurales. La inserción devuelve `null` si la posición o el contenido no son válidos, faltan permisos o el documento es moderno. Si tiene éxito, devuelve un ID estable. La referencia y el contenido forman parte de la misma mutación de deshacer y colaboración.

Lee las notas con `getFootnotes()` / `getEndnotes()` y elimínalas con `deleteFootnote(noteId)` / `deleteEndnote(noteId)`. `setFootnoteSettings()` y `setEndnoteSettings()` configuran la numeración y ubicación; `null` restablece la configuración explícita. Conserva el ID devuelto para acceder al contenido: el número visible puede cambiar tras paginar de nuevo.
