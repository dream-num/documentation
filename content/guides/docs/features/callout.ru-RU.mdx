Выноски позволяют акцентировать важную информацию в документе с помощью визуально заметных блоков, для которых можно настраивать значки и цвета.

## Введение

В Univer Docs выноски позволяют:

- **Акцентировать важную информацию**: привлекать внимание к важным примечаниям, предупреждениям и советам.
- **Настраивать оформление**: выбирать значки и цветовые схемы в соответствии с содержимым.
- **Организовывать содержимое**: структурировать документ с помощью визуально отделённых разделов.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/docs-callout @univerjs-pro/docs-callout-ui
```

### Использование

```typescript
import { UniverDocsCalloutPlugin } from '@univerjs-pro/docs-callout' // [!code ++]
import { UniverDocsCalloutUIPlugin } from '@univerjs-pro/docs-callout-ui' // [!code ++]
import DocsCalloutUIEnUS from '@univerjs-pro/docs-callout-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-callout-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCalloutUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCalloutPlugin) // [!code ++]
univer.registerPlugin(UniverDocsCalloutUIPlugin) // [!code ++]
```

Если у вас есть коммерческая лицензия Univer, ознакомьтесь с разделом [Использование лицензии в клиенте](/guides/pro/license#in-plugin-mode), чтобы настроить её.

## Facade API

Перед использованием API обязательно импортируйте facade:

```typescript
import '@univerjs-pro/docs-callout/facade'
```

### Получение всех выносок

```typescript
const doc = univerAPI.getActiveDocument()
const callouts = doc?.getCallouts() ?? []
```

### Получение выноски по ID

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.getCallout('callout-block-id')
```

### Вставка выноски

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.insertCallout({
  startOffset: 12,
  endOffset: 35,
  config: { icon: '💡' },
})
```

### Обновление конфигурации выноски

```typescript
const doc = univerAPI.getActiveDocument()
doc?.updateCallout('callout-block-id', { icon: '⚠️' })
```

### Настройка значка выноски

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setCalloutIcon('callout-block-id', '📝')
```
