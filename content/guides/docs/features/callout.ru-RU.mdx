Вызов отделяет часть информации от окружающего текста.Иконка и цвета настраиваемы, поэтому примечание, предупреждение и наконечник могут иметь различный внешний вид.

## Введение

В Univer Docs блоки вызова служат трем целям:

- Они обращают внимание на записку, предупреждение или совет.
- Они применяют иконку и выбранные для блока цвета, поэтому его внешний вид соответствует содержанию.
- Они делят документ на разделы, которые визуально разделены и читаются независимо.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/docs-callout @univerjs-pro/docs-callout-ui
```

### Использование

```typescript
import { UniverDocsCalloutPlugin } from '@univerjs-pro/docs-callout' // [!code ++]
import { UniverDocsCalloutUIPlugin } from '@univerjs-pro/docs-callout-ui' // [!code ++]
import DocsCalloutUIEnUS from '@univerjs-pro/docs-callout-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-callout-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCalloutUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCalloutPlugin) // [!code ++]
univer.registerPlugin(UniverDocsCalloutUIPlugin) // [!code ++]
```

Если ваше приложение использует Univer под коммерческой лицензией, настройте его так, как описано в [Использование лицензии у клиента](/server/license#in-plugin-mode).

## Facade API

Импорт фасада перед вызовом API:

```typescript
import '@univerjs-pro/docs-callout/facade'
```

### Получение всех выносок

```typescript
const doc = univerAPI.getActiveDocument()
const callouts = doc?.getCallouts() ?? []
```

### Получение выноски по ID

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.getCallout('callout-block-id')
```

### Вставка выноски

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.insertCallout({
  startOffset: 12,
  endOffset: 35,
  config: { icon: '💡' },
})
```

### Обновление конфигурации выноски

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.updateConfig({ icon: '⚠️' })
```

### Настройка внешнего вида выноски

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.setIcon('📝')
callout?.setBackgroundColor('#FFF4E5')
callout?.setBorder({ color: '#E6A23C', width: 2 })
callout?.setTextColor('#5C3B00')
```

Изменения внешнего вида применяются через команды документа, поэтому отменяйте, переделывайте и совместное использование их. `setTextColor()` применяет цвет ко всему тексту в вызове; позвоните `resetTextColor()`, чтобы удалить эту ошибку и восстановить цвета текста, унаследованные от документа.

```ts
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.resetTextColor()
```
