プリントは、ドキュメントコンテンツをプリンターに送信したり、オフラインで閲覧したり共有したりするためのPDFとしてエクスポートしたりします。

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/docs-print
```

### 使い方

```typescript
import { UniverDocsPrintPlugin } from '@univerjs-pro/docs-print' // [!code ++]
import DocsPrintPluginJaJP from '@univerjs-pro/docs-print/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-print/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsPrintPluginJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsPrintPlugin) // [!code ++]
```

商用ライセンスを使用する場合は、[クライアントでのライセンスの使用](/server/license#in-plugin-mode) で説明するように設定します。

## プリセットモード

`@univerjs/preset-docs-advanced`プリセットにプリントが入っています。

### インストール

<Callout>
  `@univerjs/preset-docs-advanced`から`UniverDocsAdvancedPreset`は、ランタイムで`UniverDocsDrawingPreset`に依存しているため、`@univerjs/preset-docs-drawing`を最初にインストールします。
</Callout>

```package-install
npm install @univerjs/preset-docs-drawing @univerjs/preset-docs-advanced
```

### 使い方

```typescript
import { UniverDocsAdvancedPreset } from '@univerjs/preset-docs-advanced' // [!code ++]
import UniverPresetDocsAdvancedJaJP from '@univerjs/preset-docs-advanced/locales/ja-JP' // [!code ++]
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreJaJP from '@univerjs/preset-docs-core/locales/ja-JP'
import { UniverDocsDrawingPreset } from '@univerjs/preset-docs-drawing' // [!code ++]
import UniverPresetDocsDrawingJaJP from '@univerjs/preset-docs-drawing/locales/ja-JP' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-docs-advanced/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetDocsCoreJaJP,
      UniverPresetDocsDrawingJaJP, // [!code ++]
      UniverPresetDocsAdvancedJaJP, // [!code ++]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
    UniverDocsDrawingPreset(), // [!code ++]
    UniverDocsAdvancedPreset(), // [!code ++]
  ],
})
```

商用ライセンスを使用する場合は、[クライアントでのライセンスの使用](/server/license#in-preset-mode) で説明するように設定します。
