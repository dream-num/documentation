Docs almacena la fuente de la fórmula LaTeX como contenido editable en el modelo de documento y lo hace en el editor del navegador.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/docs-latex @univerjs-pro/docs-latex-ui
```

### Uso

```typescript
import { UniverDocsLatexPlugin } from '@univerjs-pro/docs-latex' // [!code ++]
import { UniverDocsLatexUIPlugin } from '@univerjs-pro/docs-latex-ui' // [!code ++]
import DocsLatexUIEnUS from '@univerjs-pro/docs-latex-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-latex-ui/lib/index.css' // [!code ++]
import '@univerjs-pro/docs-latex/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsLatexUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsLatexPlugin) // [!code ++]
univer.registerPlugin(UniverDocsLatexUIPlugin) // [!code ++]
```

Si tiene una licencia comercial para Univer, consulte [Utilizando Licencia en Cliente](/server/license#in-plugin-mode) para la configuración.

## Compatibilidad móvil [#mobile-support]

Configurar el [editor móvil](/guides/docs/getting-started/installation#mobile-support) primero. En la configuración de modo plugin descrita en esta página, sustitúyase los registros de escritorio a continuación con las exportaciones móviles de los mismos paquetes, y complete el reemplazo **antes de abrir un documento**. Mantenga el modelo plugins, estilos, locales y las importaciones Facade sin cambios, y no registre ambas variantes.

| Paquete | Registro de escritorio | Registro móvil |
| --- | --- | --- |
| `@univerjs-pro/docs-latex-ui` | `UniverDocsLatexUIPlugin` | `UniverDocsLatexMobileUIPlugin` |

## API de fachada

Importar la entrada de fachada antes de llamar a cualquier API de LaTeX:

```typescript
import '@univerjs-pro/docs-latex/facade'
```

Inserte una fórmula en el documento activo:

```typescript
const doc = univerAPI.getActiveDocument()

const formula = doc?.insertLatexFormula({
  latex: 'E=mc^2',
  index: 12,
})
```

Lea y actualice fórmulas:

```typescript
const formulas = doc?.getLatexFormulas() ?? []
const firstFormula = doc?.findLatexFormulaByText('mc')

firstFormula?.update({
  latex: '\\frac{a}{b}',
})
```

Una fórmula también puede ser recuperada por el rango id o por su compensación en la secuencia de datos del documento:

```typescript
const byId = doc?.getLatexFormula('formula-range-id')
const atOffset = doc?.getLatexFormulaAt(42)

console.log(byId?.describe(), atOffset?.getLatex())
```
