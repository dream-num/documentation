Поиск и замена работают с обычным текстом в теле текущего документа, включая таблицы. Поддерживаются учёт регистра, поиск целых слов, переход между совпадениями и замена одного или всех совпадений.

<Callout type="info">
  Колонтитулы, комментарии, рисунки, регулярные выражения, поиск форматирования и специальные символы не поддерживаются.
</Callout>

## Режим плагина

### Установка

```package-install
npm install @univerjs/find-replace @univerjs/docs-find-replace
```

### Использование

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsFindReplacePlugin } from '@univerjs/docs-find-replace'
import FindReplaceRuRU from '@univerjs/find-replace/locale/ru-RU'

import '@univerjs/find-replace/lib/index.css'

const univer = new Univer({
  locale: LocaleType.RU_RU,
  locales: {
    [LocaleType.RU_RU]: mergeLocales(FindReplaceRuRU),
  },
})

univer.registerPlugin(UniverDocsFindReplacePlugin)
```

## Сочетания клавиш

- `Ctrl/Cmd + F`: открыть поиск
- `Ctrl/Cmd + H`: открыть замену
- `Enter` / `Shift + Enter`: следующее / предыдущее совпадение
- `Escape`: вернуть фокус документу
