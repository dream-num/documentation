Les contrôles de contenu (SDT) prennent en charge texte enrichi ou brut, cases à cocher, dates, listes, images, groupes, sections répétées et blocs de document. Configurez Docs Core et la licence Pro, puis ces plugins avant de créer le document. Fusionnez la locale UI dans `locales` et chargez le CSS. Docs Advanced ne les inclut pas.

```package-install
npm install @univerjs-pro/docs-sdt @univerjs-pro/docs-sdt-ui
```

```ts
import { UniverDocsSdtPlugin } from '@univerjs-pro/docs-sdt'
import { UniverDocsSdtUIPlugin } from '@univerjs-pro/docs-sdt-ui'
import FeatureLocale from '@univerjs-pro/docs-sdt-ui/locale/fr-FR'
import { LocaleType } from '@univerjs/core'

import '@univerjs-pro/docs-sdt-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.FR_FR, FeatureLocale)

univer.registerPlugin(UniverDocsSdtPlugin)
univer.registerPlugin(UniverDocsSdtUIPlugin)
```

## Insérer à la sélection [#insert]

La commande utilise la sélection de texte active et entoure le contenu existant lorsque le contrôle le permet. Les éléments répétés sont créés via leur section parente.

```ts
import { InsertSdtCommand } from '@univerjs-pro/docs-sdt-ui'

await univerAPI.executeCommand(InsertSdtCommand.id, { kind: 'checkbox' })
```

## Verrous et persistance [#locks-and-persistence]

Les contrôles sont des plages `CustomRangeType.SDT` dans `IDocumentBody.customRanges`, avec des métadonnées dans `ISdtCustomRange.properties`. Le verrou de contenu empêche la modification des valeurs ; celui du contrôle empêche de retirer son enveloppe. Une section répétée peut interdire l’ajout et la suppression d’éléments. Utilisez les commandes pour conserver l’annulation et le rétablissement.

Voir les [commandes](/reference/packages/plugins/univerjs-pro/docs-sdt) et l’[API UI](/reference/packages/plugins/univerjs-pro/docs-sdt-ui). La conversion DOCX relève d’[Exchange](/guides/docs/features/import-export) et ne garantit pas la conservation de toutes les propriétés Word ou liaisons XML personnalisées.
