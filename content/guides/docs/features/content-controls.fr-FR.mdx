Avant de créer le document, enregistrez les plugins de licence Docs core et Pro, puis enregistrez les deux paquets ci-dessous. Fusionnez la locale de l'interface utilisateur dans `locales` et chargez la feuille de style. Le préréglage avancé Docs n'inclut pas ces paquets.

```package-install
npm install @univerjs-pro/docs-sdt @univerjs-pro/docs-sdt-ui
```

```ts
import { UniverDocsSdtPlugin } from '@univerjs-pro/docs-sdt'
import { UniverDocsSdtUIPlugin } from '@univerjs-pro/docs-sdt-ui'
import FeatureLocale from '@univerjs-pro/docs-sdt-ui/locale/fr-FR'
import { LocaleType } from '@univerjs/core'

import '@univerjs-pro/docs-sdt-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.FR_FR, FeatureLocale)

univer.registerPlugin(UniverDocsSdtPlugin)
univer.registerPlugin(UniverDocsSdtUIPlugin)
```

## Insérer à la sélection [#insert]

La commande s'applique à la sélection active de texte. Lorsque le type de contrôle la supporte, la sélection courante est enveloppée dans le nouveau contrôle. Les éléments de la section Répéter sont créés dans la section parent.

```ts
import { InsertSdtCommand } from '@univerjs-pro/docs-sdt-ui'

await univerAPI.executeCommand(InsertSdtCommand.id, { kind: 'checkbox' })
```

## Verrous et persistance [#locks-and-persistence]

Les commandes sont stockées dans `IDocumentBody.customRanges` sous la forme de gammes `CustomRangeType.SDT`, et leurs métadonnées sont stockées dans la `ISdtCustomRange.properties`. Un verrou de contenu empêche les modifications de valeur, et un verrou de contrôle empêche la suppression de l'emballage. Une section répétitive peut également interdire l'insertion et la suppression d'éléments.

Voir les pages de référence [commandes du modèle](/reference/packages/plugins/univerjs-pro/docs-sdt) et [API de l'interface utilisateur](/reference/packages/plugins/univerjs-pro/docs-sdt-ui). La conversion DOCX est gérée par [Échanges](/guides/docs/features/import-export); la prise en charge de l'éditeur ne signifie pas que chaque propriété Word ou reliure XML personnalisée convertit sans perte.
