Mit der Zitatblockfunktion können Sie zitierten Text in ein Dokument einfügen und formatieren, mit einem visuellen Stil, der Zitate von regulärem Inhalt unterscheidet.

## Einführung

In Univer Docs können Sie mit Anführungszeichenblöcken Folgendes tun:

- **Zitierten Text formatieren**: Auf Zitate einen unverwechselbaren Stil anwenden.
- **Inhalt verschachteln**: Umfangreiche Inhalte in Anführungszeichenblöcke einschließen.
- **Einfaches Beenden**: Zitatformatierung aus leeren Absätzen schnell beenden.

## Plugin-Modus

### Installation

```package-install
npm install @univerjs-pro/docs-quote @univerjs-pro/docs-quote-ui
```

### Nutzung

```typescript
import { UniverDocsQuotePlugin } from '@univerjs-pro/docs-quote' // [!code ++]
import { UniverDocsQuoteUIPlugin } from '@univerjs-pro/docs-quote-ui' // [!code ++]
import DocsQuoteUIEnUS from '@univerjs-pro/docs-quote-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-quote-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsQuoteUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsQuotePlugin) // [!code ++]
univer.registerPlugin(UniverDocsQuoteUIPlugin) // [!code ++]
```

Wenn Sie eine kommerzielle Lizenz für Univer haben, lesen Sie bitte unter [Verwenden der Lizenz im Client](/guides/pro/license#in-plugin-mode) für die Konfiguration.

## Fassaden-API

Stellen Sie sicher, dass Sie die Fassade importieren, bevor Sie die API verwenden:

```typescript
import '@univerjs-pro/docs-quote/facade'
```

### Alle Angebotsblöcke abrufen

```typescript
const doc = univerAPI.getActiveDocument()
const quotes = doc?.getQuotes() ?? []
```

### Einen Angebotsblock einfügen

```typescript
const doc = univerAPI.getActiveDocument()
const quote = doc?.insertQuote({
  startOffset: 12,
  endOffset: 35,
})
```

### Linienfarbe des Zitats festlegen

```typescript
const quote = univerAPI.getActiveDocument()?.getQuote('quote-block-id')
quote?.setLineColor('#5B5FC7')
```

### Textfarbe des Zitats festlegen

```typescript
const quote = univerAPI.getActiveDocument()?.getQuote('quote-block-id')
quote?.setTextColor('#242424')
```
