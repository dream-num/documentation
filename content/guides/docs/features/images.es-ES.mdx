Las imágenes agregan contenido visual a un documento. Pueden ilustrar un punto, colocar una imagen de referencia al lado del texto, o hacer destacar información clave.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs/drawing @univerjs/drawing-ui @univerjs/docs-drawing @univerjs/docs-drawing-ui
```

### Uso

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsDrawingPlugin } from '@univerjs/docs-drawing' // [!code ++]
import { UniverDocsDrawingUIPlugin } from '@univerjs/docs-drawing-ui' // [!code ++]
import DocsDrawingUIEnUS from '@univerjs/docs-drawing-ui/locale/en-US' // [!code ++]
import { UniverDrawingPlugin } from '@univerjs/drawing' // [!code ++]
import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui' // [!code ++]
import DrawingUIEnUS from '@univerjs/drawing-ui/locale/en-US' // [!code ++]

import '@univerjs/drawing-ui/lib/index.css' // [!code ++]
import '@univerjs/docs-drawing-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DrawingUIEnUS, // [!code ++]
      DocsDrawingUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverDrawingUIPlugin) // [!code ++]
univer.registerPlugin(UniverDocsDrawingPlugin) // [!code ++]
univer.registerPlugin(UniverDocsDrawingUIPlugin) // [!code ++]
```

Si la aplicación utiliza [Colaboración](/guides/docs/features/collaboration), agregue la configuración `override`:

```typescript
univer.registerPlugin(UniverDrawingPlugin, {
  override: [[IImageIoService, null]], // [!code ++]
})
```

### Configuración de plugins [#plugin-configuration]

`UniverDrawingPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>override</ConfigKey> | `[DependencyIdentifier, Provider \| null][]` |  | Sustituciones de dependencias del plugin de dibujo. |
| <ConfigKey depth={1}>[0]</ConfigKey> | `DependencyIdentifier` |  | Identificador de la dependencia. Para las imágenes usa `IImageIoService`. |
| <ConfigKey depth={1}>[1]</ConfigKey> | `Provider \| null` |  | Proveedor sustituto. Pasa `null` para que la colaboración proporcione el servicio. |

## Compatibilidad móvil [#mobile-support]

Configure el [editor móvil](/guides/docs/getting-started/installation#mobile-support) primero. En la configuración de modo plugin en esta página, sustitúyase los registros de escritorio a continuación con las exportaciones móviles de los mismos paquetes, y lo haga **antes de abrir un documento**. Mantenga los plugins modelo, estilos, locales y las importaciones Facade, y no registre ambas variantes.

| Paquete | Registro de escritorio | Registro móvil |
| --- | --- | --- |
| `@univerjs/docs-drawing-ui` | `UniverDocsDrawingUIPlugin` | `UniverDocsDrawingMobileUIPlugin` |
| `@univerjs/drawing-ui` | `UniverDrawingUIPlugin` | `UniverDrawingMobileUIPlugin` |

## Modo de preset

### Instalación

```package-install
npm install @univerjs/preset-docs-drawing
```

### Usage

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEnUS from '@univerjs/preset-docs-core/locales/en-US'
import { UniverDocsDrawingPreset } from '@univerjs/preset-docs-drawing' // [!code ++]
import UniverPresetDocsDrawingEnUS from '@univerjs/preset-docs-drawing/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-drawing/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetDocsCoreEnUS,
      UniverPresetDocsDrawingEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
    UniverDocsDrawingPreset(), // [!code ++]
  ],
})
```

Si la aplicación utiliza [Colaboración](/guides/docs/features/collaboration), pasar `collaboration: true` a `UniverDocsDrawingPreset`:

```typescript
UniverDocsDrawingPreset({
  collaboration: true, // [!code ++]
})
```

### Configuración de preset [#preset-configuration]

`UniverDocsDrawingPreset`

| <span data-config-options="">Option</span> | Tipo | Default | ¿Qué hace? |
| --- | --- | --- | --- |
| `collaboration` | `boolean` | `false` | Ejecute la imagen I/O a través del servicio de colaboración, lo que hace que el almacenamiento de imágenes sea colaborativo. |

## API Facade

En modo plugin, importe primero la extensión Facade:

```typescript
import '@univerjs/docs-drawing/facade'
```

`FDocument` inserts, consultas y administra imágenes de documentos:

```typescript
const document = univerAPI.getActiveDocument()
const image = await document?.insertImage({
  source: 'https://example.com/image.png',
  imageSourceType: univerAPI.Enum.ImageSourceType.URL,
  width: 320,
  wrappingStyle: univerAPI.Enum.TextWrappingStyle.INLINE,
})

document?.getImage(image?.getId() ?? '')
document?.getImages()
```

El `FDocumentImage` devuelto redimensiona, gira, reposiciones, reenvuelvas, reordena o elimina la imagen.
