拡張テーブル機能は、Univer Docs に豊富なテーブル編集機能を提供します。セルスタイル、枠線のカスタマイズ、行列の操作、データの入力が可能です。

## はじめに

Univer Docs では、拡張テーブルを使用して以下ができます：

- **プログラムでテーブルを挿入**：指定したサイズのテーブルを作成します。
- **構造を操作**：行と列の追加、削除、移動を行います。
- **セルをスタイル設定**：枠線、背景、テキスト書式を適用します。
- **セルを結合・分割**：複雑なレイアウトのためにセルを結合します。

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### 使用法

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIJaJP from '@univerjs-pro/docs-table-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsTableUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

Univer の商用ライセンスをお持ちの場合は、[クライアントでのライセンス使用](/guides/pro/license#in-plugin-mode)を参照してください。

## Facade API

API を使用する前に facade をインポートしてください：

```typescript
import '@univerjs-pro/docs-table/facade'
```

### テーブルを挿入

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### データからテーブルを挿入

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### すべてのテーブルを取得

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### テーブルを削除

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```
