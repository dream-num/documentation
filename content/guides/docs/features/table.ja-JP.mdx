強化されたテーブルは、Univer Docs でフルテーブル編集を提供します。 セルスタイリング、ボーダー、行、列の変更、およびデータからテーブルを埋めます。

## はじめに

Univer Docs では、以下の操作をサポートしています。

- 指定した寸法でテーブルを作成します。
- 行と列の追加、削除、および移動。
- 境界線、背景、およびテキストのフォーマットをセルに適用します。
- 複雑なレイアウトを構築するためにセルをマージし、分割します。

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### 使用法

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIJaJP from '@univerjs-pro/docs-table-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsTableUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

商用ライセンスを使用する場合は、[クライアントでのライセンスの使用](/server/license#in-plugin-mode) で説明するように設定します。

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/docs/getting-started/installation#mobile-support)を最初に構成します。 このページに記載されているプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換えて、**ドキュメントを開く前に**を実行します。 モデルプラグイン、スタイル、ロケール、ファサードのインポートをキープし、1つのバリアントだけを登録します。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/docs-table-ui` | `UniverDocsTableUIPlugin` | `UniverDocsTableMobileUIPlugin` |

## Facade API

以下の API を使用する前にファサードをインポートします。

```typescript
import '@univerjs-pro/docs-table/facade'
```

### テーブルを挿入

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### データからテーブルを挿入

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### すべてのテーブルを取得

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### テーブルを削除

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```

## 表の罫線 [#table-borders]

コンテキストテーブルタブを開くには、テーブルまたはそのセルを選択します。 境界ピッカーは、色、幅、および線スタイルを制御するとともに、すべての、外側、内部、個々のエッジ、および境界線のプリセットを提供します。 `UniverDocsTableUIPlugin`は、これらの制御を提供します。

## 編集、履歴、共同編集 [#editing-history]

テーブルファサードセッターと構造的な編集はドキュメントコマンドで適用されますので、それらは undo/redo とコラボレーションに参加します。 `setTableStyle()` 背景とボーダーの変更を1つの履歴エントリに結合します。 `setColumnType()` また、行列が移動したときに列タイプが列に従います。 `setCellText()` 全セル値に置き換えます。同時置換は原子値として解決します。一方、通常の文字がテキストOTを使用するように編集します。ロックされたコンテンツコントロールがセルの編集を拒否した場合、コールリターン `false` とりあえず歴史を消費しません。

## 表全体の配置 [#table-alignment]

従来の文書では、テーブルを選択し、リボンの**テーブル→テーブルアライメント**を使用して、ページのコンテンツエリアの左、中央、または右にテーブルを配置します。 この設定はテーブル自体を動かし、セル内のテキストアライメントを変更しません。 コントロールは、モダン文書で無効です。

値が`tableSource[tableId].align`に保存され、undo/redoをサポートし、保存します。テーブルプラグインを登録した後、以下のパブリックコマンドで同じアクションが利用できます。ドキュメントスナップショットから既存のテーブルIDを渡します。無効なターゲット、無効なドキュメント、およびモダンドキュメントは`false`を返します。

```ts
import { DocsTableSetTableAlignCommand } from '@univerjs-pro/docs-table'
import { TableAlignmentType } from '@univerjs/core'

const aligned = await univerAPI.executeCommand(DocsTableSetTableAlignCommand.id, {
  unitId: documentId,
  tableId,
  value: TableAlignmentType.CENTER,
})
```
