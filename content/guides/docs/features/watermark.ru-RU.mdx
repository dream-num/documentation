Функция водяных знаков позволяет создавать гибкие и надёжные решения для защиты веб-страниц и приложений. Разработчики могут динамически добавлять на страницу текстовые или графические водяные знаки, чтобы предотвратить несанкционированное использование и распространение контента. Доступны различные параметры настройки.

## Режим пресетов

Для водяных знаков нет отдельного пресета, но соответствующий плагин можно использовать совместно с пресетами.

### Установка

```package-install
npm install @univerjs/watermark
```

### Использование

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverDocsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## Режим плагинов

### Установка

```package-install
npm install @univerjs/watermark
```

### Использование

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

### Плагины и настройка

#### @univerjs/watermark

Этот плагин содержит основную реализацию водяных знаков. Он позволяет добавлять в приложения текстовые или графические водяные знаки и предоставляет различные параметры для настройки их внешнего вида и поведения. Плагин экспортируется как `UniverWatermarkPlugin`.

Справочник: [@univerjs/watermark](https://docs.univer.ai/reference/packages/plugins/univerjs/watermark)

## Facade API

### Импорт

<Callout type="info" title="Примечание для режима плагинов">
  Импортировать пакет Facade вручную нужно только в режиме плагинов. В режиме пресетов соответствующий пакет Facade уже подключён, поэтому дополнительный импорт не требуется.
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### Добавление водяного знака

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### Удаление водяного знака

```typescript
univerAPI.deleteWatermark()
```
