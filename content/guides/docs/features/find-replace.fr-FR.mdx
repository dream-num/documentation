Find & Remplace recherche le corps du document actuel pour le texte littéral, y compris le texte dans les tableaux. Il prend en charge la correspondance de cas sensible et de mots entiers, la navigation entre les correspondances, et le remplacement de la correspondance actuelle ou de toutes les correspondances.

<Callout type="info">
  Les en-têtes, les pied de page, les commentaires, les dessins, les expressions régulières, les recherches basées sur le formatage et les caractères spéciaux ne sont pas pris en charge.
</Callout>

## Mode plugin

### Installation

```package-install
npm install @univerjs/find-replace @univerjs/docs-find-replace
```

### Utilisation

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsFindReplacePlugin } from '@univerjs/docs-find-replace'
import FindReplaceFrFR from '@univerjs/find-replace/locale/fr-FR'

import '@univerjs/find-replace/lib/index.css'

const univer = new Univer({
  locale: LocaleType.FR_FR,
  locales: {
    [LocaleType.FR_FR]: mergeLocales(FindReplaceFrFR),
  },
})

univer.registerPlugin(UniverDocsFindReplacePlugin)
```

## Raccourcis clavier

- `Ctrl/Cmd + F` : ouvrir la recherche
- `Ctrl/Cmd + H` : ouvrir le remplacement
- `Entrée` / `Maj + Entrée` : occurrence suivante / précédente
- `Échap` : rendre le focus au document
