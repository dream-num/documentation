La recherche et le remplacement portent sur le texte littéral du corps du document actif, y compris les tableaux. La casse, les mots entiers, la navigation et le remplacement d'une occurrence ou de toutes les occurrences sont pris en charge.

<Callout type="info">
  Les en-têtes, pieds de page, commentaires, dessins, expressions régulières, recherches de mise en forme et caractères spéciaux ne sont pas pris en charge.
</Callout>

## Mode plugin

### Installation

```package-install
npm install @univerjs/find-replace @univerjs/docs-find-replace
```

### Utilisation

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsFindReplacePlugin } from '@univerjs/docs-find-replace'
import FindReplaceFrFR from '@univerjs/find-replace/locale/fr-FR'

import '@univerjs/find-replace/lib/index.css'

const univer = new Univer({
  locale: LocaleType.FR_FR,
  locales: {
    [LocaleType.FR_FR]: mergeLocales(FindReplaceFrFR),
  },
})

univer.registerPlugin(UniverDocsFindReplacePlugin)
```

## Raccourcis clavier

- `Ctrl/Cmd + F` : ouvrir la recherche
- `Ctrl/Cmd + H` : ouvrir le remplacement
- `Entrée` / `Maj + Entrée` : occurrence suivante / précédente
- `Échap` : rendre le focus au document
