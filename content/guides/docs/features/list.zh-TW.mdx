增強列表為 Univer Docs 增加了多級巢狀、自定義符號和列表結構調整能力。

## 介紹

在 Univer Docs 中，增強列表提供以下能力：

- 多級巢狀；
- 可選擇專案符號和編號樣式；
- 對列表項執行提升、降級和重排操作。

## 外掛模式

### 安裝

```package-install
npm install @univerjs-pro/docs-list @univerjs-pro/docs-list-ui
```

### 使用

```typescript
import { UniverDocsListPlugin } from '@univerjs-pro/docs-list' // [!code ++]
import { UniverDocsListUIPlugin } from '@univerjs-pro/docs-list-ui' // [!code ++]
import DocsListUIZhTW from '@univerjs-pro/docs-list-ui/locale/zh-TW' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-list-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      DocsListUIZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsListPlugin) // [!code ++]
univer.registerPlugin(UniverDocsListUIPlugin) // [!code ++]
```

使用 Univer 商業許可證時，配置方式參見[在客戶端使用許可證](/server/license#in-plugin-mode)。

## 行動裝置支援 [#mobile-support]

請先完成[行動版編輯器](/guides/docs/getting-started/installation#mobile-support)的配置。在本頁外掛模式的初始化程式碼中，將下表中的桌面版註冊替換為同一套件匯出的行動版外掛，並且必須在**開啟文件前**完成替換。模型外掛、樣式、語言套件和 Facade 匯入均需保留，兩個版本不要同時註冊。

| 套件 | 桌面版註冊 | 行動版註冊 |
| --- | --- | --- |
| `@univerjs-pro/docs-list-ui` | `UniverDocsListUIPlugin` | `UniverDocsListMobileUIPlugin` |

## Facade API

呼叫下列 API 之前，需要先匯入 facade：

```typescript
import '@univerjs-pro/docs-list/facade'
```

### 插入清單

```typescript
import { PresetListType } from '@univerjs/core'

const doc = univerAPI.getActiveDocument()
doc?.insertList({
  startOffset: 0,
  endOffset: 10,
  listType: PresetListType.BULLET_LIST,
})
```

### 取得所有清單

```typescript
const doc = univerAPI.getActiveDocument()
const lists = doc?.getLists() ?? []
```

### 設定清單符號類型

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListGlyphType(0, ListGlyphType.DECIMAL)
```

### 設定清單層級

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListLevel(0, 1)
```
