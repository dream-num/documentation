[共同編集の統合](/server/collaboration/browser-integration)に沿って、サンプルの実行、アプリへの組み込み、永続化と権限の検証を進めてください。実装と Web/Server サンプルは [共同編集クイックスタート](/server/collaboration/quick-start) を参照してください。

認証済みの業務 API から Collaboration Service を呼び出して Unit を作成し、返された ID をブラウザーで読み込みます。[Quick Start](/server/collaboration/quick-start) で HTTP、Session Ticket、WebSocket を設定し、Database Adapter で永続化します。読み取り、JOIN、編集は[サーバー側の権限](/server/collaboration/identity-and-authorization)で個別に保護してください。

## 文書を読み込む [#document-loading]

文書を読み込む前に現在のユーザーを設定してください。現在のユーザーは共同編集の身元とローカルのオフラインキャッシュの所有者を決めます。設定後、Facade で明示的に読み込みます。

```ts
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadDocAsync('your-unit-id')
```

<Callout type="warning">
現在のバージョンの `UniverCollaborationClientUIPlugin` は、起動時に URL の `unit` と `type` クエリを読んで文書を自動的に読み込みます。この動作は非推奨で、今後のバージョンで削除されます。初期化時に `enableUrlUnitLoader: false` を設定して無効にしてください。
</Callout>

以下の設定を既存のプラグイン登録または共同編集プリセット呼び出しに統合します。プリセットモードでは、`collaborationPreset` を既存の `createUniver()` のプリセット一覧に追加します。

<Tabs items={['プラグインモード', 'プリセットモード']}>
  <Tab>
    ```ts
    import { UniverCollaborationClientUIPlugin } from '@univerjs-pro/collaboration-client-ui'

    univer.registerPlugin(UniverCollaborationClientUIPlugin, {
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverDocsCollaborationPreset } from '@univerjs/preset-docs-collaboration'

    const collaborationPreset = UniverDocsCollaborationPreset({
      universerEndpoint: 'https://your-backend.example.com',
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
</Tabs>
