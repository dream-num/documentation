共同編集機能は、複数のユーザーが同一ドキュメントを同時編集し、変更をリアルタイムで同期できるようにします。チームでの協業や複数人編集のシナリオに最適です。

## プリセットモード

### インストール

<Callout>
  `@univerjs/preset-docs-collaboration` の `UniverDocsCollaborationPreset` は実行時に `UniverDocsDrawingPreset` と `UniverDocsAdvancedPreset` に依存します。先に `@univerjs/preset-docs-drawing` と `@univerjs/preset-docs-advanced` をインストールしてください。
</Callout>

```package-install
npm install @univerjs/preset-docs-drawing @univerjs/preset-docs-advanced @univerjs/preset-docs-collaboration
```

### 使い方

```typescript
import { UniverDocsAdvancedPreset } from '@univerjs/preset-docs-advanced' // [!code ++]
import UniverPresetDocsAdvancedJaJP from '@univerjs/preset-docs-advanced/locales/ja-JP' // [!code ++]
import { UniverDocsCollaborationPreset } from '@univerjs/preset-docs-collaboration' // [!code ++]
import UniverPresetDocsCollaborationJaJP from '@univerjs/preset-docs-collaboration/locales/ja-JP' // [!code ++]
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreJaJP from '@univerjs/preset-docs-core/locales/ja-JP'
import { UniverDocsDrawingPreset } from '@univerjs/preset-docs-drawing' // [!code ++]
import UniverPresetDocsDrawingJaJP from '@univerjs/preset-docs-drawing/locales/ja-JP' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/presets/lib/styles/preset-docs-core.css'
import '@univerjs/preset-docs-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-docs-advanced/lib/index.css' // [!code ++]
import '@univerjs/preset-docs-collaboration/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetDocsCoreJaJP,
      UniverPresetDocsDrawingJaJP, // [!code ++]
      UniverPresetDocsAdvancedJaJP, // [!code ++]
      UniverPresetDocsCollaborationJaJP, // [!code ++]
    ),
  },
  collaboration: true, // [!code ++]
  presets: [
    UniverDocsCorePreset(),
    UniverDocsDrawingPreset({ // [!code ++]
      collaboration: true, // [!code ++]
    }), // [!code ++]
    UniverDocsAdvancedPreset({ // [!code ++]
      collaboration: true, // [!code ++]
    }), // [!code ++]
    UniverDocsCollaborationPreset({ // [!code ++]
      universerEndpoint: 'http://localhost:3010', // [!code ++]
    }), // [!code ++]
  ],
})
```

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/collaboration @univerjs-pro/collaboration-client @univerjs-pro/collaboration-client-ui
```

### 使い方

```typescript
import { UniverCollaborationPlugin } from '@univerjs-pro/collaboration' // [!code ++]
import { UniverCollaborationClientPlugin } from '@univerjs-pro/collaboration-client' // [!code ++]
import { BrowserCollaborationSocketService, UniverCollaborationClientUIPlugin } from '@univerjs-pro/collaboration-client-ui' // [!code ++]
import CollaborationClientJaJP from '@univerjs-pro/collaboration-client/locale/ja-JP' // [!code ++]
import { IAuthzIoService, IMentionIOService, IUndoRedoService, LocaleType, mergeLocales, Univer } from '@univerjs/core' // [!code ++]

import '@univerjs-pro/collaboration-client/facade' // [!code ++]
import '@univerjs-pro/collaboration-client-ui/facade' // [!code ++]

import '@univerjs-pro/collaboration-client/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      CollaborationClientJaJP, // [!code ++]
    ),
  },
})

// override オプションを [[IAuthzIoService, null]] に設定すると、Univer は組み込み IAuthzIoService を登録しません。
// [[IUndoRedoService, null]] で組み込み IUndoRedoService を無効化できます。
// [[IMentionIOService, null]] で組み込み IMentionIOService を無効化できます。
// これにより、UniverCollaborationPlugin が提供する認可/UndoRedo/メンション機能を使用できます。
const univer = new Univer({
  override: [ // [!code ++]
    [IAuthzIoService, null], // [!code ++]
    [IUndoRedoService, null], // [!code ++]
    [IMentionIOService, null], // [!code ++]
  ], // [!code ++]
})

univer.registerPlugin(UniverCollaborationPlugin) // [!code ++]
univer.registerPlugin(UniverCollaborationClientPlugin, { // [!code ++]
  socketService: BrowserCollaborationSocketService, // [!code ++]
  authzUrl: 'http://localhost:3010/universer-api/authz', // [!code ++]
  snapshotServerUrl: 'http://localhost:3010/universer-api/snapshot', // [!code ++]
  collabSubmitChangesetUrl: 'http://localhost:3010/universer-api/comb', // [!code ++]
  collabWebSocketUrl: 'ws://localhost:3010/universer-api/comb/connect', // [!code ++]
}) // [!code ++]
univer.registerPlugin(UniverCollaborationClientUIPlugin) // [!code ++]
```

Univer の商用ライセンスをお持ちの場合は、設定方法について [クライアントでのライセンス](/guides/pro/license#in-plugin-mode) を参照してください。

## 共同編集ドキュメントのデータ

共同編集プラグインは Univer サーバーに依存し、共同編集ドキュメントのデータは Univer サーバーに保存されます。

### `unitId`

Univer サーバー上の各共同編集ドキュメントは一意の `unitId` を持ちます。共同編集クライアントは `unitId` を使って該当ドキュメントのデータを取得します。

### `type`

`type` は共同編集ドキュメントの種別で、初期データ構造を決定します。

## 共同編集ドキュメントの作成

Univer サーバー上で共同編集ドキュメントを作成する方法はいくつかあります。

- [Create Document](/guides/pro/api#create-document) API で空のドキュメントを作成する。
- [インポートプラグイン](/guides/docs/features/import-export) の `FUniver.importDOCXToUnitIdAsync` で `.docx` を取り込む。

## URL パラメータによる共同編集ドキュメントの読み込み

`@univerjs-pro/collaboration-client` は URL パラメータ `unit` と `type` に基づいて自動的にデータを読み込む機能を提供します。シナリオによってはデータロードのロジックを簡略化できます。

この機能を使用する場合は、既存の読み込みロジックを調整し、URL に `unit` と `type` を追加してください。

```typescript
import { UniverInstanceType } from '@univerjs/core'
// プリセットモードでは `UniverInstanceType` を `@univerjs/presets` からインポートできます
import { UniverInstanceType } from '@univerjs/presets'

// 共同編集を使わない場合の既存ロジック
univer.createUnit(UniverInstanceType.UNIVER_DOC, {}) // [!code --]

// 共同編集ドキュメント向けのロジック
const url = new URL(window.location.href) // [!code ++]
const unit = url.searchParams.get('unit') // [!code ++]

if (unit) { // [!code ++]
  // unit パラメータがあれば自動的にデータが読み込まれる
} else { // [!code ++]
  // ない場合は新規ドキュメントを作成
  fetch(`/universer-api/snapshot/${UniverInstanceType.UNIVER_DOC}/unit/-/create`, { // [!code ++]
    method: 'POST', // [!code ++]
    headers: { // [!code ++]
      'Content-Type': 'application/json', // [!code ++]
    }, // [!code ++]
    body: JSON.stringify({ // [!code ++]
      type: UniverInstanceType.UNIVER_DOC, // instance type // [!code ++]
      name: 'New Doc By Univer', // doc name // [!code ++]
      creator: 'user', // creator name // [!code ++]
    }), // [!code ++]
  }).then((response) => { // [!code ++]
    if (!response.ok) { // [!code ++]
      throw new Error('create unit failed') // [!code ++]
    } // [!code ++]
    return response.json() // [!code ++]
  }).then((data) => { // [!code ++]
    if (!data.unitID) { // [!code ++]
      throw new Error('create unit failed') // [!code ++]
    } // [!code ++]
    url.searchParams.set('unit', data.unitID) // [!code ++]
    url.searchParams.set('type', String(UniverInstanceType.UNIVER_DOC)) // [!code ++]
    window.location.href = url.toString() // [!code ++]
  }).catch((error) => { // [!code ++]
    console.error(error) // [!code ++]
  }) // [!code ++]
} // [!code ++]
```

## Facade API

### 共同編集ドキュメントの読み込み

URL パラメータを使わずに共同編集ドキュメントを読み込みたい場合は、Facade API からも読み込めます。

```typescript
const collaboration = univerAPI.getCollaboration()
const workbook = await collaboration.loadSheetAsync('your-unit-id')
```
