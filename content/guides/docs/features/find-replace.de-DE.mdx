Suchen und Ersetzen durchsucht Klartext im aktuellen Dokumentkörper einschließlich Tabellen. Groß-/Kleinschreibung, ganze Wörter, die Navigation zwischen Treffern sowie das Ersetzen eines oder aller Treffer werden unterstützt.

<Callout type="info">
  Kopf- und Fußzeilen, Kommentare, Zeichnungen, reguläre Ausdrücke, Formatierungssuche und Sonderzeichen werden nicht unterstützt.
</Callout>

## Plugin-Modus

### Installation

```package-install
npm install @univerjs/find-replace @univerjs/docs-find-replace
```

### Verwendung

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsFindReplacePlugin } from '@univerjs/docs-find-replace'
import FindReplaceDeDE from '@univerjs/find-replace/locale/de-DE'

import '@univerjs/find-replace/lib/index.css'

const univer = new Univer({
  locale: LocaleType.DE_DE,
  locales: {
    [LocaleType.DE_DE]: mergeLocales(FindReplaceDeDE),
  },
})

univer.registerPlugin(UniverDocsFindReplacePlugin)
```

## Tastenkürzel

- `Ctrl/Cmd + F`: Suche öffnen
- `Ctrl/Cmd + H`: Ersetzen öffnen
- `Enter` / `Shift + Enter`: nächster / vorheriger Treffer
- `Escape`: Fokus zum Dokument zurückgeben
