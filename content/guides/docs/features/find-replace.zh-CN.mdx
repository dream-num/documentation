查找与替换可搜索当前文档正文（包括表格）中的纯文本。它支持区分大小写、全字匹配、跳转匹配项，以及替换当前或全部匹配项。

<Callout type="info">
  暂不支持页眉、页脚、评论、绘图、正则表达式、格式搜索和特殊字符。
</Callout>

## 插件模式

### 安装

```package-install
npm install @univerjs/find-replace @univerjs/docs-find-replace
```

### 使用

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsFindReplacePlugin } from '@univerjs/docs-find-replace'
import FindReplaceZhCN from '@univerjs/find-replace/locale/zh-CN'

import '@univerjs/find-replace/lib/index.css'

const univer = new Univer({
  locale: LocaleType.ZH_CN,
  locales: {
    [LocaleType.ZH_CN]: mergeLocales(FindReplaceZhCN),
  },
})

univer.registerPlugin(UniverDocsFindReplacePlugin)
```

## 键盘快捷键

- `Ctrl/Cmd + F`：打开查找
- `Ctrl/Cmd + H`：打开替换
- `Enter` / `Shift + Enter`：下一个 / 上一个匹配项
- `Escape`：将焦点返回文档
