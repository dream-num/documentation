워터마크 기능은 웹 페이지나 애플리케이션을 위한 유연하고 안전한 워터마크 솔루션을 제공합니다. 개발자는 페이지에 텍스트 또는 이미지 워터마크를 동적으로 생성하여 콘텐츠의 무단 사용이나 유포를 방지할 수 있으며, 다양한 구성 옵션도 지원합니다.

<Callout type="info">
  [워터마크 설정 생성기](/tools/watermark-generator)에서 워터마크 스타일을 미리 보고 플러그인 설정을 JSON으로 다운로드할 수 있습니다.
</Callout>

## 플러그인 모드

### 설치

```package-install
npm install @univerjs/watermark
```

### 사용법

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

### 플러그인 설정 [#plugin-configuration]

## 프리셋 모드

워터마크는 프리셋을 제공하지 않지만 플러그인과 함께 사용할 수 있습니다.

### 설치

```package-install
npm install @univerjs/watermark
```

### 사용법

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverDocsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## Facade API

### 가져오기

<Callout type="info" title="플러그인 모드 참고 사항">
  플러그인 모드에서만 Facade 패키지를 직접 가져와야 합니다. 프리셋 모드에는 해당 Facade 패키지가 이미 포함되어 있으므로 별도로 가져올 필요가 없습니다.
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### 워터마크 설정

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### 워터마크 제거

```typescript
univerAPI.deleteWatermark()
```
