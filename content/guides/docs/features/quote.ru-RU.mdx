Блоки цитат позволяют вставлять и форматировать цитаты в документе, визуально отделяя их от обычного содержимого.

## Введение

В Univer Docs с помощью блоков цитат можно:

- **Форматировать цитаты**: применять к ним особое оформление.
- **Вкладывать содержимое**: размещать внутри блоков цитат форматированный контент.
- **Легко выходить из блока**: быстро отключать формат цитаты в пустом абзаце.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/docs-quote @univerjs-pro/docs-quote-ui
```

### Использование

```typescript
import { UniverDocsQuotePlugin } from '@univerjs-pro/docs-quote' // [!code ++]
import { UniverDocsQuoteUIPlugin } from '@univerjs-pro/docs-quote-ui' // [!code ++]
import DocsQuoteUIEnUS from '@univerjs-pro/docs-quote-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-quote-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsQuoteUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsQuotePlugin) // [!code ++]
univer.registerPlugin(UniverDocsQuoteUIPlugin) // [!code ++]
```

Если у вас есть коммерческая лицензия Univer, ознакомьтесь с разделом [Использование лицензии в клиенте](/guides/pro/license#in-plugin-mode).

## Facade API

Перед использованием API обязательно импортируйте facade:

```typescript
import '@univerjs-pro/docs-quote/facade'
```

### Получение всех блоков цитат

```typescript
const doc = univerAPI.getActiveDocument()
const quotes = doc?.getQuotes() ?? []
```

### Вставка блока цитаты

```typescript
const doc = univerAPI.getActiveDocument()
const quote = doc?.insertQuote({
  startOffset: 12,
  endOffset: 35,
})
```

### Выход из блока цитаты

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitQuote()
```

### Отмена пустого абзаца с цитатой

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyQuoteParagraph()
```
