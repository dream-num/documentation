Вы можете вставлять и форматировать цитируемый текст в документе с блоком цитат, который имеет свой собственный стиль, так что цитата читается иначе, чем контент вокруг него.

## Введение

В Univer Docs блок котировок предоставляет следующее:

- Отличительный стиль для цитируемого текста.
- Богатый контент вложен в блок.
- Быстрый выход из форматирования цитаты, когда вы находитесь на пустом абзаце.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/docs-quote @univerjs-pro/docs-quote-ui
```

### Использование

```typescript
import { UniverDocsQuotePlugin } from '@univerjs-pro/docs-quote' // [!code ++]
import { UniverDocsQuoteUIPlugin } from '@univerjs-pro/docs-quote-ui' // [!code ++]
import DocsQuoteUIEnUS from '@univerjs-pro/docs-quote-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-quote-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsQuoteUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsQuotePlugin) // [!code ++]
univer.registerPlugin(UniverDocsQuoteUIPlugin) // [!code ++]
```

Если вы используете коммерческую лицензию, настройте ее, как описано в [Использование лицензии у клиента](/server/license#in-plugin-mode).

## Поддержка мобильных устройств [#mobile-support]

Сначала настройте [Мобильный редактор](/guides/docs/getting-started/installation#mobile-support). В настройках плагин-режима, описанных на этой странице, замените регистрацию рабочего стола ниже на мобильный экспорт из того же пакета и сделайте это **Перед тем, как открыть документ**, сохраните плагины модели, стили, локализации и импорт Facade и не регистрируйте оба варианта.

## Facade API

Импорт фасада перед использованием любого из следующих API:

```typescript
import '@univerjs-pro/docs-quote/facade'
```

### Получение всех блоков цитат

```typescript
const doc = univerAPI.getActiveDocument()
const quotes = doc?.getQuotes() ?? []
```

### Вставка блока цитаты

```typescript
const doc = univerAPI.getActiveDocument()
const quote = doc?.insertQuote({
  startOffset: 12,
  endOffset: 35,
})
```

### Цвет линии цитаты

```typescript
const quote = univerAPI.getActiveDocument()?.getQuote('quote-block-id')
quote?.setLineColor('#5B5FC7')
```

### Цвет текста цитаты

```typescript
const quote = univerAPI.getActiveDocument()?.getQuote('quote-block-id')
quote?.setTextColor('#242424')
```
