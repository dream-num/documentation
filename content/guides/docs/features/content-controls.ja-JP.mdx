コンテンツコントロール(SDT)は、リッチテキスト、プレーンテキスト、チェックボックス、日付、リスト、写真、グループ、リピーティングセクション、およびドキュメントパートをサポートしています。 ドキュメントを作成する前に、DocsコアとProライセンスプラグインを登録し、以下の2つのパッケージを登録します。 UIを`locales`にマージし、スタイルシートをロードします。 Docsの高度なプリセットには、これらのパッケージは含まれていません。

```package-install
npm install @univerjs-pro/docs-sdt @univerjs-pro/docs-sdt-ui
```

```ts
import { UniverDocsSdtPlugin } from '@univerjs-pro/docs-sdt'
import { UniverDocsSdtUIPlugin } from '@univerjs-pro/docs-sdt-ui'
import FeatureLocale from '@univerjs-pro/docs-sdt-ui/locale/ja-JP'
import { LocaleType } from '@univerjs/core'

import '@univerjs-pro/docs-sdt-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.JA_JP, FeatureLocale)

univer.registerPlugin(UniverDocsSdtPlugin)
univer.registerPlugin(UniverDocsSdtUIPlugin)
```

## 選択位置に挿入 [#insert]

コマンドは、アクティブなテキスト選択に適用されます。 コントロールタイプがそれをサポートすると、現在の選択は新しいコントロールにラップされます。 繰り返しセクション項目は、親セクションを通して作成されます。

```ts
import { InsertSdtCommand } from '@univerjs-pro/docs-sdt-ui'

await univerAPI.executeCommand(InsertSdtCommand.id, { kind: 'checkbox' })
```

## ロックと保存 [#locks-and-persistence]

`IDocumentBody.customRanges` では、`CustomRangeType.SDT`の範囲で制御が保存され、そのメタデータは `ISdtCustomRange.properties`に保存されます。コンテンツロックは値編集を防ぎ、制御ロックはラッパーの除去を防止します。繰り返しセクションは、アイテムの投入と削除を禁止することができます。値、プロパティ、および繰り返し項目をコマンドで変更することで、undo と redo が一貫したままになります。

[モデルコマンド](/reference/packages/plugins/univerjs-pro/docs-sdt)と[UI APIの使い方](/reference/packages/plugins/univerjs-pro/docs-sdt-ui)の参照ページを参照してください。 DOCX変換は[取引銀行](/guides/docs/features/import-export)によって処理されます。 エディタのサポートは、すべてのWordプロパティまたはカスタムXMLバインディングが損失なしで変換するという意味ではありません。
