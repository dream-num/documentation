コンテンツコントロール（SDT）はリッチテキスト、テキスト、チェックボックス、日付、リスト、画像、グループ、繰り返しセクション、文書パーツに対応します。Docs Core と Pro ライセンスを設定し、文書作成前に以下を登録します。UI ロケールを `locales` にマージして CSS を読み込みます。Docs Advanced には含まれません。

```package-install
npm install @univerjs-pro/docs-sdt @univerjs-pro/docs-sdt-ui
```

```ts
import { UniverDocsSdtPlugin } from '@univerjs-pro/docs-sdt'
import { UniverDocsSdtUIPlugin } from '@univerjs-pro/docs-sdt-ui'
import FeatureLocale from '@univerjs-pro/docs-sdt-ui/locale/ja-JP'
import { LocaleType } from '@univerjs/core'

import '@univerjs-pro/docs-sdt-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.JA_JP, FeatureLocale)

univer.registerPlugin(UniverDocsSdtPlugin)
univer.registerPlugin(UniverDocsSdtUIPlugin)
```

## 選択位置に挿入 [#insert]

コマンドは現在のテキスト選択を使用します。対応するコントロールは既存の選択内容を囲みます。繰り返し項目は親セクション経由で作成します。

```ts
import { InsertSdtCommand } from '@univerjs-pro/docs-sdt-ui'

await univerAPI.executeCommand(InsertSdtCommand.id, { kind: 'checkbox' })
```

## ロックと保存 [#locks-and-persistence]

コントロールは `IDocumentBody.customRanges` の `CustomRangeType.SDT` 範囲として保存され、メタデータは `ISdtCustomRange.properties` に格納されます。内容ロックは値変更、コントロールロックは枠の削除を防止します。繰り返しセクションは項目の追加・削除も制限できます。元に戻す・やり直す処理のため、変更はコマンド経由で行います。

[モデルコマンド](/reference/packages/plugins/univerjs-pro/docs-sdt)と [UI API](/reference/packages/plugins/univerjs-pro/docs-sdt-ui)を参照してください。DOCX 変換は [Exchange](/guides/docs/features/import-export) が担当し、すべての Word 属性や XML バインディングの完全な再現を保証するものではありません。
