Mit der Callout-Funktion können Sie wichtige Informationen in einem Dokument mit visuell unterschiedlichen Blöcken hervorheben, komplett mit anpassbaren Symbolen und Farben.

## Einführung

In Univer Docs ermöglichen Ihnen Callout-Blöcke dies um:

- **Wichtige Informationen hervorheben**: Machen Sie auf wichtige Hinweise, Warnungen oder Tipps aufmerksam.
- **Darstellung anpassen**: Wählen Sie aus verschiedenen Symbolen und Farbschemata passend zu Ihrem Inhalt.
- **Inhalt organisieren**: Strukturieren Sie Ihr Dokument mit visuell getrennten Abschnitten.

## Plugin-Modus

### Installation

```package-install
npm install @univerjs-pro/docs-callout @univerjs-pro/docs-callout-ui
```

### Verwendung

```typescript
import { UniverDocsCalloutPlugin } from '@univerjs-pro/docs-callout' // [!code ++]
import { UniverDocsCalloutUIPlugin } from '@univerjs-pro/docs-callout-ui' // [!code ++]
import DocsCalloutUIEnUS from '@univerjs-pro/docs-callout-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-callout-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCalloutUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCalloutPlugin) // [!code ++]
univer.registerPlugin(UniverDocsCalloutUIPlugin) // [!code ++]
```

Wenn Sie eine kommerzielle Lizenz für Univer haben, lesen Sie bitte [Lizenz verwenden in Client](/guides/pro/license#in-plugin-mode) für die Konfiguration.

## Fassaden-API

Stellen Sie sicher, dass Sie die Fassade importieren, bevor Sie die API verwenden:

```typescript
import '@univerjs-pro/docs-callout/facade'
```

### Alle Callouts abrufen

```typescript
const doc = univerAPI.getActiveDocument()
const callouts = doc?.getCallouts() ?? []
```

### Ein Callout nach ID abrufen

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.getCallout('callout-block-id')
```

### Ein Callout einfügen

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.insertCallout({
  startOffset: 12,
  endOffset: 35,
  config: { icon: '💡' },
})
```

### Callout-Konfiguration aktualisieren

```typescript
const doc = univerAPI.getActiveDocument()
doc?.updateCallout('callout-block-id', { icon: '⚠️' })
```

### Callout-Symbol festlegen

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setCalloutIcon('callout-block-id', '📝')
```
