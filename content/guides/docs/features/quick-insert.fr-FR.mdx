L’insertion rapide propose un menu de commandes accessible avec une barre oblique pour insérer du contenu. Saisissez `/` au début d’une ligne vide pour ouvrir le menu et insérer rapidement du texte, des listes, des séparateurs, des tableaux, des images et bien plus encore. Cette fonctionnalité n’est actuellement disponible qu’en mode plugin.

## Interactions

- Saisissez `/` au début d’une ligne pour ouvrir le menu
- Un bouton `+` apparaît à gauche d’un paragraphe vide ; cliquez dessus pour ouvrir tous les menus disponibles
- Saisissez du texte pour filtrer les options ; utilisez ↑/↓ pour naviguer, Entrée pour insérer et Échap pour fermer

## Mode plugin

### Installation

```package-install
npm install @univerjs/docs-quick-insert-ui
```

### Utilisation

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsQuickInsertUIPlugin } from '@univerjs/docs-quick-insert-ui' // [!code ++]
import DocsQuickInsertUIEnUS from '@univerjs/docs-quick-insert-ui/locale/en-US' // [!code ++]

import '@univerjs/docs-quick-insert-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsQuickInsertUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsQuickInsertUIPlugin) // [!code ++]
```
