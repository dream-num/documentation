La fonctionnalité de listes avancées enrichit Univer Docs avec des listes imbriquées, des symboles personnalisés et des outils souples pour manipuler les listes.

## Introduction

Dans Univer Docs, les listes avancées vous permettent de :

- **Créer des listes imbriquées** : construisez des hiérarchies de listes à plusieurs niveaux.
- **Personnaliser les symboles** : utilisez différents types de puces et de numérotation.
- **Modifier la structure des listes** : augmentez ou diminuez le niveau des éléments et réorganisez-les.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/docs-list @univerjs-pro/docs-list-ui
```

### Utilisation

```typescript
import { UniverDocsListPlugin } from '@univerjs-pro/docs-list' // [!code ++]
import { UniverDocsListUIPlugin } from '@univerjs-pro/docs-list-ui' // [!code ++]
import DocsListUIEnUS from '@univerjs-pro/docs-list-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-list-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsListUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsListPlugin) // [!code ++]
univer.registerPlugin(UniverDocsListUIPlugin) // [!code ++]
```

Si vous disposez d’une licence commerciale Univer, consultez la page [Utiliser une licence côté client](/guides/pro/license#in-plugin-mode) pour connaître la procédure de configuration.

## API Facade

Veillez à importer la facade avant d’utiliser l’API :

```typescript
import '@univerjs-pro/docs-list/facade'
```

### Insérer une liste

```typescript
import { PresetListType } from '@univerjs/core'

const doc = univerAPI.getActiveDocument()
doc?.insertList({
  startOffset: 0,
  endOffset: 10,
  listType: PresetListType.BULLET_LIST,
})
```

### Obtenir toutes les listes

```typescript
const doc = univerAPI.getActiveDocument()
const lists = doc?.getLists() ?? []
```

### Définir le type de symbole d’une liste

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListGlyphType(0, ListGlyphType.DECIMAL)
```

### Définir le niveau d’une liste

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListLevel(0, 1)
```
