Les listes améliorées étendent les Docs Univer avec des niveaux imbriqués, des glyphes personnalisés et l'édition de la structure de la liste.

## Introduction

Dans Univer Docs, les listes améliorées fournissent les capacités suivantes:

- Niveaux de nidification multiples.
- Un choix de symboles et de styles de numérotation.
- Promouvoir, démoter et réorganiser les opérations sur les articles de la liste.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/docs-list @univerjs-pro/docs-list-ui
```

### Utilisation

```typescript
import { UniverDocsListPlugin } from '@univerjs-pro/docs-list' // [!code ++]
import { UniverDocsListUIPlugin } from '@univerjs-pro/docs-list-ui' // [!code ++]
import DocsListUIEnUS from '@univerjs-pro/docs-list-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-list-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsListUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsListPlugin) // [!code ++]
univer.registerPlugin(UniverDocsListUIPlugin) // [!code ++]
```

Si vous utilisez une licence commerciale, configurez-la comme décrit dans [Utilisation de la licence dans le client](/server/license#in-plugin-mode).

## Prise en charge mobile [#mobile-support]

Configurez d'abord le [éditeur mobile](/guides/docs/getting-started/installation#mobile-support). Dans la configuration en mode plugin décrite sur cette page, remplacez l'enregistrement de bureau indiqué ci-dessous par l'exportation mobile du même paquet, et remplissez le remplacement **avant d'ouvrir un document** . Gardez les plugins modèles, styles, locaux et importations Facade, et ne enregistrez pas les deux variantes.

| Paquet | Inscription de bureau | Inscription mobile |
| --- | --- | --- |
| `@univerjs-pro/docs-list-ui` | `UniverDocsListUIPlugin` | `UniverDocsListMobileUIPlugin` |

## API Facade

Importez la façade avant d'appeler l'une des API suivantes :

```typescript
import '@univerjs-pro/docs-list/facade'
```

### Insérer une liste

```typescript
import { PresetListType } from '@univerjs/core'

const doc = univerAPI.getActiveDocument()
doc?.insertList({
  startOffset: 0,
  endOffset: 10,
  listType: PresetListType.BULLET_LIST,
})
```

### Obtenir toutes les listes

```typescript
const doc = univerAPI.getActiveDocument()
const lists = doc?.getLists() ?? []
```

### Définir le type de symbole d’une liste

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListGlyphType(0, ListGlyphType.DECIMAL)
```

### Définir le niveau d’une liste

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListLevel(0, 1)
```
