ハイパーリンクを使うと、ドキュメント内から外部 Web ページやメールアドレスなどへ素早くアクセスできます。

## プラグインモード

### インストール

```package-install
npm install @univerjs/docs-hyper-link @univerjs/docs-hyper-link-ui
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsHyperLinkPlugin } from '@univerjs/docs-hyper-link' // [!code ++]
import { UniverDocsHyperLinkUIPlugin } from '@univerjs/docs-hyper-link-ui' // [!code ++]
import DocsHyperLinkUIJaJP from '@univerjs/docs-hyper-link-ui/locale/ja-JP' // [!code ++]

import '@univerjs/docs-hyper-link-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsHyperLinkUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsHyperLinkPlugin) // [!code ++]
univer.registerPlugin(UniverDocsHyperLinkUIPlugin) // [!code ++]
```

## モバイル対応 [#mobile-support]

まず[モバイルエディター](/guides/docs/getting-started/installation#mobile-support)を設定します。このページのプラグインモードの初期化コードで、以下のデスクトップ登録を同じパッケージのモバイル版に置き換え、**文書を開く前に**完了してください。モデル、スタイル、言語ファイル、Facade は維持し、両方を同時に登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs/docs-hyper-link-ui` | `UniverDocsHyperLinkUIPlugin` | `UniverDocsHyperLinkMobileUIPlugin` |

## プリセットモード

### インストール

```package-install
npm install @univerjs/preset-docs-hyper-link
```

### 使い方

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreJaJP from '@univerjs/preset-docs-core/locales/ja-JP'
import { UniverDocsHyperLinkPreset } from '@univerjs/preset-docs-hyper-link' // [!code ++]
import UniverPresetDocsHyperLinkJaJP from '@univerjs/preset-docs-hyper-link/locales/ja-JP' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-hyper-link/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      UniverPresetDocsCoreJaJP,
      UniverPresetDocsHyperLinkJaJP, // [!code ++]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
    UniverDocsHyperLinkPreset(), // [!code ++]
  ],
})
```

## Facade API でリンクを作成・編集する

`link(text, url)` はリンク付きテキストを追加し、その範囲を記録します。文字位置を手動で計算する必要はありません。後からリンク先を変えるときは、`getLinks()` が返す範囲 ID を使います。

```ts
const richText = univerAPI
  .newRichText()
  .text('Read ')
  .link('Univer Office SDK documentation', 'https://docs.univer.ai')
  .text(' for details.')

const [link] = richText.getLinks()
if (!link) throw new Error('Link was not created')

richText.updateLink(link.rangeId, 'https://docs.univer.ai/guides')
```

`removeLink(link.rangeId)` は表示テキストを残したままリンク先だけを削除します。
