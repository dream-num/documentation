增強表格為 Univer Docs 提供了完整的表格編輯能力，包括單元格樣式、邊框、行列操作和資料填充。

## 介紹

在 Univer Docs 中，表格支援以下操作：

- 按指定的行列數建立表格；
- 新增、刪除和移動行列；
- 為單元格設定邊框、背景和文字格式；
- 合併和拆分單元格，以建置複雜版面配置。

## 外掛模式

### 安裝

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### 使用

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIZhTW from '@univerjs-pro/docs-table-ui/locale/zh-TW' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      DocsTableUIZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

使用 Univer 商業許可證時，配置方式參見[在客戶端使用許可證](/server/license#in-plugin-mode)。

## 行動裝置支援 [#mobile-support]

請先完成[行動版編輯器](/guides/docs/getting-started/installation#mobile-support)的配置。在本頁外掛模式的初始化程式碼中，將下表中的桌面版註冊替換為同一套件匯出的行動版外掛，並且必須在**開啟文件前**完成替換。模型外掛、樣式、語言套件和 Facade 匯入均需保留，兩個版本不要同時註冊。

| 套件 | 桌面版註冊 | 行動版註冊 |
| --- | --- | --- |
| `@univerjs-pro/docs-table-ui` | `UniverDocsTableUIPlugin` | `UniverDocsTableMobileUIPlugin` |

## Facade API

呼叫下列 API 之前，需要先匯入 facade：

```typescript
import '@univerjs-pro/docs-table/facade'
```

### 插入表格

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### 從資料插入表格

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### 取得所有表格

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### 刪除表格

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```

## 表格框線 [#table-borders]

選中表格或其中的單元格，即可開啟表格上下文選項卡。邊框選擇器提供全部、外側、內部、單側和無邊框幾種預設，並提供顏色、粗細和線型的控制元件。這些控制元件由 `UniverDocsTableUIPlugin` 提供。

## 編輯、復原與協同 [#editing-history]

表格 Facade 的設定方法和結構編輯都透過文件命令執行，因此會參與撤銷、重做和協同。`setTableStyle()` 將背景和邊框的修改合併為一條歷史記錄。`setColumnType()` 同樣可撤銷、可同步，列型別會隨列一起移動。`setCellText()` 替換整個單元格值：並行替換按原子值衝突處理，普通逐字編輯仍使用文字 OT。被鎖定內容控制元件拒絕的單元格編輯返回 `false`，且不消耗撤銷/重做歷史。

## 整個表格的對齊方式 [#table-alignment]

在傳統文件中選中表格，然後使用 Ribbon 上的“表格 → 表格對齊”，將整個表格在頁面正文區域內左對齊、居中或右對齊。該設定調整的是表格本身的位置，不會改變單元格內文字的對齊方式。現代文件中此控制元件不可用。

對齊值儲存在 `tableSource[tableId].align` 中，支援撤銷、重做和儲存。登錄檔格外掛後，也可以透過下面的公開命令執行同樣的操作，`tableId` 取自文件快照中已有的表格 ID。目標無效、文件被禁用或屬於現代文件時，命令返回 `false`。

```ts
import { DocsTableSetTableAlignCommand } from '@univerjs-pro/docs-table'
import { TableAlignmentType } from '@univerjs/core'

const aligned = await univerAPI.executeCommand(DocsTableSetTableAlignCommand.id, {
  unitId: documentId,
  tableId,
  value: TableAlignmentType.CENTER,
})
```
