增強表格功能為 Univer Docs 提供了豐富的表格編輯能力，包括儲存格樣式、邊框自訂、行列操作和資料填充。

## 介紹

在 Univer Docs 中，增強表格使您能夠：

- **以程式方式插入表格**：建立指定尺寸的表格。
- **操作結構**：新增、刪除和移動行列。
- **樣式儲存格**：套用邊框、背景和文字格式。
- **合併和拆分儲存格**：組合儲存格以實現複雜版面配置。

## 外掛模式

### 安裝

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### 使用

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIZhTW from '@univerjs-pro/docs-table-ui/locale/zh-TW' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      DocsTableUIZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

如果您擁有 Univer 商業授權，請參閱[在用戶端使用授權](/server/license#in-plugin-mode)進行配置。

## 行動裝置支援 [#mobile-support]

先設定[行動版編輯器](/guides/docs/getting-started/installation#mobile-support)。在本頁外掛模式的初始化程式碼中，將下列桌面版註冊替換為同一套件匯出的行動版外掛，並在**開啟文件前**完成。保留模型外掛、樣式、語言套件與 Facade 匯入，請勿同時註冊兩個版本。

| 套件 | 桌面版註冊 | 行動版註冊 |
| --- | --- | --- |
| `@univerjs-pro/docs-table-ui` | `UniverDocsTableUIPlugin` | `UniverDocsTableMobileUIPlugin` |

## Facade API

使用 API 前請確保已匯入 facade：

```typescript
import '@univerjs-pro/docs-table/facade'
```

### 插入表格

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### 從資料插入表格

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### 取得所有表格

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### 刪除表格

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```
