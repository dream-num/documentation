Vous pouvez insérer et formater le texte cité dans un document avec un bloc de citation, qui porte son propre style de sorte qu'une citation lit différemment du contenu qui l'entoure.

## Introduction

Dans Univer Docs, un bloc de guillemets fournit ce qui suit :

- Un style distinct pour le texte cité.
- Riche contenu niché à l'intérieur du bloc.
- Une sortie rapide du formatage des guillemets lorsque vous êtes sur un paragraphe vide.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/docs-quote @univerjs-pro/docs-quote-ui
```

### Utilisation

```typescript
import { UniverDocsQuotePlugin } from '@univerjs-pro/docs-quote' // [!code ++]
import { UniverDocsQuoteUIPlugin } from '@univerjs-pro/docs-quote-ui' // [!code ++]
import DocsQuoteUIEnUS from '@univerjs-pro/docs-quote-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-quote-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsQuoteUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsQuotePlugin) // [!code ++]
univer.registerPlugin(UniverDocsQuoteUIPlugin) // [!code ++]
```

Si vous utilisez une licence commerciale, configurez-la comme décrit dans [Utilisation de la licence dans le client](/server/license#in-plugin-mode).

## Prise en charge mobile [#mobile-support]

Configurez d'abord le [éditeur mobile](/guides/docs/getting-started/installation#mobile-support). Dans la configuration en mode plugin décrite sur cette page, remplacez l'enregistrement de bureau ci-dessous par l'exportation mobile du même paquet, et faites-le **avant d'ouvrir un document** . Gardez les plugins modèles, styles, locaux et importations de Facade, et ne enregistrez pas les deux variantes.

| Paquet | Inscription de bureau | Inscription mobile |
| --- | --- | --- |
| `@univerjs-pro/docs-quote-ui` | `UniverDocsQuoteUIPlugin` | `UniverDocsQuoteMobileUIPlugin` |

## API Facade

Importez la façade avant d'utiliser l'une des API suivantes :

```typescript
import '@univerjs-pro/docs-quote/facade'
```

### Obtenir tous les blocs de citation

```typescript
const doc = univerAPI.getActiveDocument()
const quotes = doc?.getQuotes() ?? []
```

### Insérer un bloc de citation

```typescript
const doc = univerAPI.getActiveDocument()
const quote = doc?.insertQuote({
  startOffset: 12,
  endOffset: 35,
})
```

### Définir la couleur du trait de citation

```typescript
const quote = univerAPI.getActiveDocument()?.getQuote('quote-block-id')
quote?.setLineColor('#5B5FC7')
```

### Définir la couleur du texte de citation

```typescript
const quote = univerAPI.getActiveDocument()?.getQuote('quote-block-id')
quote?.setTextColor('#242424')
```
