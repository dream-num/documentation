メンションを使うと、ユーザーは Univer Docs で `@` を入力し、人物、チーム、チケット、アプリケーション内の他のオブジェクトを mention エンティティとして挿入できます。挿入された mention は、ドキュメント本文の `CustomRangeType.MENTION` カスタム範囲として保存されます。

## インタラクション

- ドキュメントで `@` を入力すると、メンションポップアップが開きます。
- 続けて入力すると、`search` 値が mention データソースに渡されます。
- 候補を選択すると、入力したトリガーテキストが `@Alice` のようなエンティティに置き換えられます。
- カーソルを移動するか、トリガー位置より前まで削除すると、ポップアップが閉じます。

## プラグインモード

### インストール

```package-install
npm install @univerjs/docs-mention-ui
```

### 使用法

```typescript
import { UniverDocsMentionUIPlugin } from '@univerjs/docs-mention-ui' // [!code ++]

import '@univerjs/docs-mention-ui/lib/index.css' // [!code ++]

univer.registerPlugin(UniverDocsMentionUIPlugin) // [!code ++]
```

## 候補データを提供する

メンションポップアップは `IMentionIOService` から候補を読み取ります。Univer の既定のローカル実装は現在のユーザーを返します。本番アプリケーションでは、ユーザーディレクトリ、チームサービス、課題管理システム、または他の業務データソースに接続する実装に置き換えることが一般的です。

```typescript
import type { IListMentionParam, IListMentionResponse, IMentionIOService } from '@univerjs/core'
import { MentionType } from '@univerjs/core'

class DirectoryMentionIOService implements IMentionIOService {
  async list(params: IListMentionParam): Promise<IListMentionResponse> {
    const users = await searchUsers(params.search ?? '')

    return {
      list: [{
        type: MentionType.PERSON,
        title: 'People',
        metadata: {},
        mentions: users.map(user => ({
          objectType: MentionType.PERSON,
          objectId: user.id,
          label: user.name,
          metadata: {
            icon: user.avatarUrl,
            email: user.email,
          },
        })),
      }],
      page: params.page,
      size: params.size,
      total: users.length,
    }
  }
}
```

アプリケーション作成時に、Univer の依存関係 override でカスタムサービスを登録します。

```typescript
import { IMentionIOService, LocaleType, Univer } from '@univerjs/core'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  override: [
    [IMentionIOService, { useClass: DirectoryMentionIOService }],
  ],
})
```

## データモデル

mention が挿入されると、表示テキストは `body.dataStream` に書き込まれ、エンティティのメタデータは `body.customRanges` に永続化されます。

```typescript
const documentData = {
  body: {
    dataStream: 'Hello @Alice\\r\\n',
    customRanges: [{
      startIndex: 6,
      endIndex: 11,
      rangeId: 'mention-1',
      rangeType: CustomRangeType.MENTION,
      wholeEntity: true,
      properties: {
        id: 'mention-1',
        label: 'Alice',
        type: 'user',
        email: 'alice@example.com',
      },
    }],
  },
}
```

<Callout type="info">
  Mentions はドキュメントのカスタム範囲です。アプリケーションが `metadata` に追加フィールドを保存する場合は、スナップショットを安全に永続化および復元できるよう、シリアライズ可能な値にしてください。
</Callout>
