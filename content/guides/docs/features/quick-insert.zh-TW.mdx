快速插入提供類似「/ 指令」的插入體驗。在空行行首輸入 `/` 會彈出選單，支援關鍵字搜尋並快速插入文字、清單、分隔線、表格、圖片等內容。目前僅支援外掛模式。

## 互動方式

- 行首輸入 `/` 開啟選單
- 空行左側出現 `+` 按鈕，點擊可開啟全部可用選單
- 輸入關鍵字篩選選單；↑/↓ 切換，Enter 插入，Esc 關閉

## 外掛模式

### 安裝

```package-install
npm install @univerjs/docs-quick-insert-ui
```

### 使用

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsQuickInsertUIPlugin } from '@univerjs/docs-quick-insert-ui' // [!code ++]
import DocsQuickInsertUIZhTW from '@univerjs/docs-quick-insert-ui/locale/zh-TW' // [!code ++]

import '@univerjs/docs-quick-insert-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      DocsQuickInsertUIZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsQuickInsertUIPlugin) // [!code ++]
```

## 行動裝置支援 [#mobile-support]

先設定[行動版編輯器](/guides/docs/getting-started/installation#mobile-support)。在本頁外掛模式的初始化程式碼中，將下列桌面版註冊替換為同一套件匯出的行動版外掛，並在**開啟文件前**完成。保留模型外掛、樣式、語言套件與 Facade 匯入，請勿同時註冊兩個版本。

| 套件 | 桌面版註冊 | 行動版註冊 |
| --- | --- | --- |
| `@univerjs/docs-quick-insert-ui` | `UniverDocsQuickInsertUIPlugin` | `UniverDocsQuickInsertMobileUIPlugin` |
