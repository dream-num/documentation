Configura HTTP, Session Ticket y WebSocket según [Quick Start](/server/collaboration/quick-start), persiste con un Database Adapter y protege lectura, JOIN y edición mediante [permisos del servidor](/server/collaboration/identity-and-authorization).

## Elegir quién carga el documento [#document-loading]

Establece el usuario actual antes de cargar un documento. Se recomienda la carga explícita: establece el usuario actual, llama al método Facade siguiente y configura `enableUrlUnitLoader: false` al inicializar; es obligatorio con presets o `createUniver()`. La carga automática por URL, activada por defecto, lee los parámetros `unit` y `type` cuando `UniverCollaborationClientUIPlugin` arranca, así que en ese caso el usuario actual debe establecerse antes de registrar los plugins de colaboración.

Combine estas opciones con el registro de plugins o la llamada al preset de colaboración existente. En modo preestablecido, añada `collaborationPreset` a la lista de presets de su `createUniver()`, junto con los del editor.

<Tabs items={['Modo de complemento', 'Modo preestablecido']}>
  <Tab>
    ```ts
    import { UniverCollaborationClientUIPlugin } from '@univerjs-pro/collaboration-client-ui'

    univer.registerPlugin(UniverCollaborationClientUIPlugin, {
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverDocsCollaborationPreset } from '@univerjs/preset-docs-collaboration'

    const collaborationPreset = UniverDocsCollaborationPreset({
      universerEndpoint: 'https://your-backend.example.com',
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
</Tabs>

Desactivar la carga automática por URL mantiene disponibles la edición colaborativa y la carga explícita mediante Facade.

## Facade API [#loading-collaborative-documents]

```ts
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadDocAsync('your-unit-id')
```
