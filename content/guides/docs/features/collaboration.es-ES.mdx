La edición colaborativa conecta el editor del navegador a un backend. Comience con [Integración de la colaboración](/server/collaboration/browser-integration) para ejecutar el ejemplo y conectar la identidad, permisos y almacenamiento de su aplicación. La configuración del navegador y servidor se describe en [Inicio rápido de la colaboración](/server/collaboration/quick-start).

Cree el documento a través de una API autenticada en su aplicación, luego cargue el identificador de Unidad que devuelve con el método de abajo. Utilice el mismo identificador cuando abra ese documento de nuevo.

## Cargar el documento [#document-loading]

Establecer el usuario actual antes de cargar un documento. El usuario actual identifica al colaborador y posee el caché local fuera de línea. Después de que el usuario actual se establece, cargar el documento explícitamente a través de la Facade:

```ts
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadDocAsync('your-unit-id')
```

La página [estado de sincronización, registros y recuperación de conflictos](/server/collaboration/browser-integration#sync-status) describe cómo construir indicadores de ahorro y proteger ediciones no reconocidas antes de una recarga.

## Eliminación de la carga integrada por URL de documentos colaborativos [#url-unit-loader-migration]

<Callout type="warning" title="Nota">
  A partir de la versión **1.2.0**, Univer ha eliminado la carga URL incorporada para documentos de colaboración. Ya no lee automáticamente los parámetros de URL `unit` y `type` para cargar un documento de colaboración.
</Callout>

Si su aplicación depende de ese comportamiento, un plugin personalizado puede restaurarlo.

### Integrar el plugin personalizado

Copia los cuatro archivos abajo en su proyecto, preservando esta estructura del directorio:

```text
custom-url-load/
├── plugin.ts
├── controllers/
│   └── data-loader.controller.ts
└── services/
    ├── url.service.ts
    └── web-url.service.ts
```

Iniciar el editor y los plugins de colaboración primero, establecer el usuario actual siguiente, y registrar `CustomUrlLoadPlugin` último. Este enfoque funciona tanto en modo plugin como en modo preestablecido:

```ts
import { UserManagerService } from '@univerjs/core'
import { CustomUrlLoadPlugin } from './custom-url-load/plugin'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

univer.registerPlugin(CustomUrlLoadPlugin)
```

Después del registro, el plugin carga el documento, por lo que `loadDocAsync()` no es necesario para ese documento. Si su aplicación ya carga documentos a través de la Facade, mantenga el enfoque descrito en la sección anterior y maneje URLs como la aplicación requiere.

    ```ts
    import { UniverCollaborationClientPlugin } from '@univerjs-pro/collaboration-client'
    import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
    import { CollaborationDataLoaderController } from './controllers/data-loader.controller'
    import { IURLService } from './services/url.service'
    import { WebURLService } from './services/web-url.service'

    @DependentOn(UniverCollaborationClientPlugin)
    export class CustomUrlLoadPlugin extends Plugin {
      static override pluginName = 'CUSTOM_URL_LOAD_PLUGIN'

      constructor(
        _config: undefined,
        @Inject(Injector) protected override readonly _injector: Injector
      ) {
        super()
      }

      override onStarting(): void {
        this._injector.add([IURLService, { useClass: WebURLService }])
        this._injector.add([CollaborationDataLoaderController])

        this.disposeWithMe(this._injector.get(IURLService))
        this.disposeWithMe(this._injector.get(CollaborationDataLoaderController))
      }
    }
    ```

    ```ts
    import { DataLoaderService } from '@univerjs-pro/collaboration-client'
    import { ILogService, Inject, RxDisposable } from '@univerjs/core'
    import { IURLService } from '../services/url.service'

    /**
     * Carga un documento colaborativo desde los parámetros de la URL.
     */
    export class CollaborationDataLoaderController extends RxDisposable {
      constructor(
        @IURLService private readonly _urlService: IURLService,
        @ILogService private readonly _logService: ILogService,
        @Inject(DataLoaderService) private readonly _dataLoaderService: DataLoaderService
      ) {
        super()

        const unitId = this._urlService.getParam('unit')
        const type = this._urlService.getParam('type')
        if (!unitId || !type) {
          return
        }

        this._dataLoaderService.loadUnit(unitId, Number(type))
          .catch((error: unknown) => {
            this._logService.error('[CollaborationDataLoaderController]', error)
          })
      }
    }
    ```

    ```ts
    import type { IURLService } from './url.service'
    import { RxDisposable } from '@univerjs/core'
    import { fromEvent, map, shareReplay, takeUntil } from 'rxjs'

    export class WebURLService extends RxDisposable implements IURLService {
      readonly urlChange$ = fromEvent(window, 'popstate').pipe(
        map(() => undefined),
        takeUntil(this.dispose$),
        shareReplay({ bufferSize: 1, refCount: true })
      )

      getParam(key: string): string | undefined {
        return new URL(window.location.href).searchParams.get(key) ?? undefined
      }

      setParam(key: string, value: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.set(key, value)
        this._updateUrl(url, useReplace)
      }

      removeParam(key: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.delete(key)
        this._updateUrl(url, useReplace)
      }

      private _updateUrl(url: URL, useReplace: boolean): void {
        if (useReplace) {
          window.history.replaceState(window.history.state, '', url.toString())
        } else {
          window.history.pushState(window.history.state, '', url.toString())
        }
      }
    }
    ```
