引用區塊功能允許您在文件中插入和格式化引用文字，並套用與一般內容不同的視覺樣式。

## 介紹

在 Univer Docs 中，引用區塊使您能夠：

- **格式化引用文字**：為引文套用獨特的樣式。
- **巢狀內容**：在引用區塊中包含富文字內容。
- **輕鬆退出**：快速從空段落退出引用格式。

## 外掛模式

### 安裝

```package-install
npm install @univerjs-pro/docs-quote @univerjs-pro/docs-quote-ui
```

### 使用

```typescript
import { UniverDocsQuotePlugin } from '@univerjs-pro/docs-quote' // [!code ++]
import { UniverDocsQuoteUIPlugin } from '@univerjs-pro/docs-quote-ui' // [!code ++]
import DocsQuoteUIZhTW from '@univerjs-pro/docs-quote-ui/locale/zh-TW' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-quote-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      DocsQuoteUIZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsQuotePlugin) // [!code ++]
univer.registerPlugin(UniverDocsQuoteUIPlugin) // [!code ++]
```

如果您擁有 Univer 商業授權，請參閱[在用戶端使用授權](/guides/pro/license#in-plugin-mode)進行配置。

## Facade API

使用 API 前請確保已匯入 facade：

```typescript
import '@univerjs-pro/docs-quote/facade'
```

### 取得所有引用區塊

```typescript
const doc = univerAPI.getActiveDocument()
const quotes = doc?.getQuotes() ?? []
```

### 插入引用區塊

```typescript
const doc = univerAPI.getActiveDocument()
const quote = doc?.insertQuote({
  startOffset: 12,
  endOffset: 35,
})
```

### 退出引用區塊

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitQuote()
```

### 取消空引用段落

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyQuoteParagraph()
```
