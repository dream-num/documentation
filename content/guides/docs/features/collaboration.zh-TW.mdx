請從[協同整合](/server/collaboration/browser-integration)開始，依序執行範例、接入業務、驗證持久化和權限。實作細節與可執行的 Web/Server 範例請見 [協同快速開始](/server/collaboration/quick-start)。

先由經過認證的業務 API 呼叫 Collaboration Service 建立 Unit，再於瀏覽器載入回傳的識別碼。依[快速開始](/server/collaboration/quick-start)一起設定 HTTP、Session Ticket 和 WebSocket，以 Database Adapter 持久化，並透過[伺服器端 Middleware](/server/collaboration/identity-and-authorization)分別檢查讀取、JOIN 和修改權限。

## 選擇文件載入方式 [#document-loading]

預設情況下，`UniverCollaborationClientUIPlugin` 會在啟動時讀取 URL 中的 `unit` 與 `type` 查詢參數並載入文件。如果由應用程式選擇文件並呼叫 Facade 載入，請在初始化時設定 `enableUrlUnitLoader: false`，由應用程式統一觸發載入。

將以下選項合併至既有的外掛註冊或協同預設呼叫。預設模式下，將 `collaborationPreset` 放入既有 `createUniver()` 的預設清單，與編輯器預設一起使用。

<Tabs items={['外掛模式', '預設模式']}>
  <Tab>
    ```ts
    import { UniverCollaborationClientUIPlugin } from '@univerjs-pro/collaboration-client-ui'

    univer.registerPlugin(UniverCollaborationClientUIPlugin, {
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverDocsCollaborationPreset } from '@univerjs/preset-docs-collaboration'

    const collaborationPreset = UniverDocsCollaborationPreset({
      universerEndpoint: 'https://your-backend.example.com',
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
</Tabs>

關閉 URL 自動載入後，協同編輯和明確呼叫 Facade 載入仍可使用。

## Facade API [#loading-collaborative-documents]

```ts
import '@univerjs-pro/collaboration-client/facade'

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadDocAsync('your-unit-id')
```
