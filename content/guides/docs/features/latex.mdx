Docs stores the LaTeX formula source as editable content in the document model and renders it in the browser editor.

## Plugin Mode

### Installation

```package-install
npm install @univerjs-pro/docs-latex @univerjs-pro/docs-latex-ui
```

### Usage

```typescript
import { UniverDocsLatexPlugin } from '@univerjs-pro/docs-latex' // [!code ++]
import { UniverDocsLatexUIPlugin } from '@univerjs-pro/docs-latex-ui' // [!code ++]
import DocsLatexUIEnUS from '@univerjs-pro/docs-latex-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-latex-ui/lib/index.css' // [!code ++]
import '@univerjs-pro/docs-latex/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsLatexUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsLatexPlugin) // [!code ++]
univer.registerPlugin(UniverDocsLatexUIPlugin) // [!code ++]
```

If you hold a commercial license for Univer, refer to [Using License in Client](/server/license#in-plugin-mode) for the configuration.

## Mobile support [#mobile-support]

Set up the [mobile editor](/guides/docs/getting-started/installation#mobile-support) first. In the plugin-mode setup described on this page, replace the desktop registrations below with the mobile exports from the same packages, and complete the replacement **before opening a document**. Keep the model plugins, styles, locales, and Facade imports unchanged, and do not register both variants.

| Package | Desktop registration | Mobile registration |
| --- | --- | --- |
| `@univerjs-pro/docs-latex-ui` | `UniverDocsLatexUIPlugin` | `UniverDocsLatexMobileUIPlugin` |

## Facade API

Import the facade entry before calling any LaTeX API:

```typescript
import '@univerjs-pro/docs-latex/facade'
```

Insert a formula into the active document:

```typescript
const doc = univerAPI.getActiveDocument()

const formula = doc?.insertLatexFormula({
  latex: 'E=mc^2',
  index: 12,
})
```

Read and update formulas:

```typescript
const formulas = doc?.getLatexFormulas() ?? []
const firstFormula = doc?.findLatexFormulaByText('mc')

firstFormula?.update({
  latex: '\\frac{a}{b}',
})
```

A formula can also be retrieved by range id or by its offset in the document's data stream:

```typescript
const byId = doc?.getLatexFormula('formula-range-id')
const atOffset = doc?.getLatexFormulaAt(42)

console.log(byId?.describe(), atOffset?.getLatex())
```
