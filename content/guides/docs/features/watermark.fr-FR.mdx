La fonctionnalité de filigrane offre une solution souple et sécurisée pour les pages web et les applications. Elle permet aux développeurs de générer dynamiquement des filigranes textuels ou graphiques sur la page afin d’empêcher toute utilisation ou diffusion non autorisée du contenu. Elle prend également en charge diverses options de configuration.

<PlaygroundFrame lang="fr-FR" slug="docs/watermark" clickToShow />

## Mode prédéfini

Le filigrane ne fournit aucun préréglage, mais son plugin peut être combiné à des préréglages.

### Installation

```package-install
npm install @univerjs/watermark
```

### Utilisation

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverDocsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## Mode plugin

### Installation

```package-install
npm install @univerjs/watermark
```

### Utilisation

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

### Plugins et configuration

#### @univerjs/watermark

Ce plugin fournit l’implémentation principale de la fonctionnalité de filigrane. Il permet aux développeurs d’ajouter des filigranes textuels ou graphiques aux applications et propose diverses options de configuration pour personnaliser leur apparence et leur comportement. Il fournit le plugin `UniverWatermarkPlugin`.

Référence : [@univerjs/watermark](https://docs.univer.ai/reference/packages/plugins/univerjs/watermark)

## API Facade

### Importation

<Callout type="info" title="Remarque sur le mode plugin">
  Seul le mode plugin nécessite d’importer manuellement le package Facade. Le mode prédéfini inclut déjà le package Facade correspondant ; aucune importation supplémentaire n’est donc nécessaire.
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### Ajouter un filigrane

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### Supprimer le filigrane

```typescript
univerAPI.deleteWatermark()
```
