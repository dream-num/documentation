コードブロック機能を使用すると、ドキュメント内に書式設定されたコードスニペットを挿入して表示でき、Prism.js によるシンタックスハイライトもサポートしています。

## はじめに

Univer Docs では、コードブロックを使用して以下ができます：

- **コードスニペットを挿入**：ドキュメントの任意の場所に書式設定されたコードブロックを追加します。
- **シンタックスハイライト**：プログラミング言語に基づいてコードを自動的にハイライトします。
- **終了とキャンセル**：空の段落からコード書式を簡単に終了またはキャンセルします。

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/docs-code @univerjs-pro/docs-code-ui
```

### 使用法

```typescript
import { UniverDocsCodePlugin } from '@univerjs-pro/docs-code' // [!code ++]
import { UniverDocsCodeUIPlugin } from '@univerjs-pro/docs-code-ui' // [!code ++]
import DocsCodeUIJaJP from '@univerjs-pro/docs-code-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-code-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsCodeUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCodePlugin) // [!code ++]
univer.registerPlugin(UniverDocsCodeUIPlugin) // [!code ++]
```

Univer の商用ライセンスをお持ちの場合は、[クライアントでのライセンス使用](/guides/pro/license#in-plugin-mode)を参照してください。

## Facade API

API を使用する前に facade をインポートしてください：

```typescript
import '@univerjs-pro/docs-code/facade'
```

### すべてのコードブロックを取得

```typescript
const doc = univerAPI.getActiveDocument()
const codes = doc?.getCodes() ?? []
```

### コードブロックを挿入

```typescript
const doc = univerAPI.getActiveDocument()
const code = doc?.insertCode({
  startOffset: 12,
  endOffset: 35,
})
```

### コードブロックを終了

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitCode()
```

### 空のコード段落をキャンセル

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyCodeParagraph()
```
