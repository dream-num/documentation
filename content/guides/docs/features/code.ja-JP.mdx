コードブロックは、ドキュメント内の整形コードを配置します。Syntax のハイライトは Prism.js によって提供されます。

## はじめに

Univer Docs では、コードブロックはいくつかの一般的なニーズに対応します。

- 文書内のどこにでも、フォーマットされたコードブロックを差し込むことができます。
- コードは言語に応じて自動的に強調されます。
- 空のコード段落により、ユーザーはブロックを終了したり、コードのフォーマットを解除したりすることができます。

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/docs-code @univerjs-pro/docs-code-ui
```

### 使用法

```typescript
import { UniverDocsCodePlugin } from '@univerjs-pro/docs-code' // [!code ++]
import { UniverDocsCodeUIPlugin } from '@univerjs-pro/docs-code-ui' // [!code ++]
import DocsCodeUIJaJP from '@univerjs-pro/docs-code-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-code-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsCodeUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCodePlugin) // [!code ++]
univer.registerPlugin(UniverDocsCodeUIPlugin) // [!code ++]
```

アプリケーションが商用ライセンスで Univer を使用している場合は、[クライアントでのライセンスの使用](/server/license#in-plugin-mode). で説明するように設定します。

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/docs/getting-started/installation#mobile-support)を最初に構成します。このページのプラグインモード設定では、同じパッケージからモバイルエクスポートに以下にリストされているデスクトップ登録を置き換え、代替**ドキュメントを開く前に**を作ります。モデルプラグイン、スタイル、ロケール、ファサードのインポートを保持し、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/docs-code-ui` | `UniverDocsCodeUIPlugin` | `UniverDocsCodeMobileUIPlugin` |

## Facade API

これらのメソッドを呼び出す前にファサードをインポートします。

```typescript
import '@univerjs-pro/docs-code/facade'
```

### すべてのコードブロックを取得

```typescript
const doc = univerAPI.getActiveDocument()
const codes = doc?.getCodes() ?? []
```

### コードブロックを挿入

```typescript
const doc = univerAPI.getActiveDocument()
const code = doc?.insertCode({
  startOffset: 12,
  endOffset: 35,
})
```

### コードブロックを終了

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitCode()
```

### 空のコード段落をキャンセル

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyCodeParagraph()
```

## コード用の等幅フォント [#code-fonts]

コードブロックツールバーのフォントピッカーは、`FontCategory.MONOSPACE`に登録しているフォントのみをリストします。フォントを選択すると、その段落スタイルを含む、コードブロック全体に適用されます。

カスタムのモノスペースフォントを登録するには、`addFonts()` を呼び出します。

```ts
import { FontCategory } from '@univerjs/ui'
import '@univerjs/ui/facade'

univerAPI.addFonts([
  { value: 'JetBrains Mono', label: 'JetBrains Mono', category: FontCategory.MONOSPACE },
])
```

登録は、ピッカーにエントリーを追加するだけです。 フォントファイル自体は、[カスタムフォント](/guides/docs/ui/fonts)で説明されているように、CSSまたはブラウザFace APIでロードする必要があります。 この方法は、プラグインとプリセットの初期化の両方で動作します。
