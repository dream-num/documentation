목차는 제목 항목을 문서 본문에 삽입합니다. 탐색용 개요 패널과는 별도 기능입니다. Docs Core 설정에 다음 플러그인을 추가하고 문서를 만들기 전에 UI 언어 팩을 `locales`에 병합하고 CSS를 불러오세요. Core 및 Advanced 프리셋에는 포함되지 않습니다.

```package-install
npm install @univerjs/docs-toc @univerjs/docs-toc-ui
```

```ts
import { UniverDocsTocPlugin } from '@univerjs/docs-toc'
import { UniverDocsTocUIPlugin } from '@univerjs/docs-toc-ui'
import FeatureLocale from '@univerjs/docs-toc-ui/locale/ko-KR'
import { LocaleType } from '@univerjs/core'

import '@univerjs/docs-toc-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.KO_KR, FeatureLocale)

univer.registerPlugin(UniverDocsTocPlugin)
univer.registerPlugin(UniverDocsTocUIPlugin)
```

## 삽입과 업데이트 [#commands]

삽입 전에 문서에 커서를 놓으세요. UI에서 삽입, 전체 업데이트, 페이지 번호만 업데이트, 삭제를 수행할 수 있습니다. `rangeId`를 생략하면 현재 선택 위치의 목차를 업데이트합니다.

```ts
import { InsertTableOfContentsCommand, UpdateTableOfContentsCommand } from '@univerjs/docs-toc'

await univerAPI.executeCommand(InsertTableOfContentsCommand.id, {
  levels: 3,
  showPageNumbers: true,
  rightAlignPageNumbers: true,
})
await univerAPI.executeCommand(UpdateTableOfContentsCommand.id, { mode: 'entireTable' })
```

업데이트는 개요 수준 기반 목차 명령(`\o`)을 계산합니다. 다른 Word 스위치는 FIELD 메타데이터에 보존되지만 모두 계산하지는 않습니다. [명령 매개변수](/reference/packages/plugins/univerjs/docs-toc)를 참고하세요.
