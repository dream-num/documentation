ウォーターマーク機能は、Web ページやアプリケーションに柔軟で安全なウォーターマークを提供します。テキストや画像のウォーターマークを動的に生成し、無断使用や拡散の防止に役立ちます。さまざまな設定オプションも備えています。

<Callout type="info">
  [透かし設定ジェネレーター](/tools/watermark-generator)で透かしのスタイルをプレビューし、プラグイン用の設定を JSON としてダウンロードできます。
</Callout>

## プラグインモード

### インストール

```package-install
npm install @univerjs/watermark
```

### 使い方

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

## プリセットモード

ウォーターマークはプリセットを提供していませんが、プラグインとして組み合わせて利用できます。

### インストール

```package-install
npm install @univerjs/watermark
```

### 使い方

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverDocsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## Facade API

### インポート

<Callout type="info" title="プラグインモード注意">
  Facade パッケージの手動 import が必要なのはプラグインモードのみです。プリセットモードには対応する Facade パッケージが内蔵されているため、追加の import は不要です。
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### ウォーターマークを設定

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### ウォーターマークを削除

```typescript
univerAPI.deleteWatermark()
```
