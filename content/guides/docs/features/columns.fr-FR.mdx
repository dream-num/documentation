La mise en page des colonnes ajoute des groupes de colonnes modifiables à Univer Docs. Un groupe de colonnes est un bloc qui contient de deux à cinq colonnes. Cette structure prend en charge les mises en page éditoriales compactes, les sections de comparaison, les bulletins d'information et les documents qui mélangent le texte avec les tableaux.

## Introduction

Dans Univer Docs, la mise en page des colonnes couvre quatre domaines :

- Un groupe de deux colonnes, trois colonnes ou ratios personnalisés peut être placé à l'offset d'un document.
- Les utilisateurs insèrent, redimensionnent et suppriment des colonnes via l'interface utilisateur Docs.
- Facade APIs requête groupes de colonnes, insérer du contenu dans une colonne spécifique, et mettre à jour les rapports de largeur dans le code.
- Les changements de colonne passent par le pipeline standard de commande en texte riche, de sorte que les opérations de l'interface utilisateur permettent de supprimer, de refaire et de collaborer.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/docs-column @univerjs-pro/docs-column-ui
```

### Utilisation

```typescript
import { UniverDocsColumnUIPlugin } from '@univerjs-pro/docs-column-ui' // [!code ++]
import DocsColumnUIEnUS from '@univerjs-pro/docs-column-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-column-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsColumnUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsColumnUIPlugin) // [!code ++]
```

Si votre application utilise Univer sous une licence commerciale, configurez-la comme décrit dans [Utilisation de la licence dans le client](/server/license#in-plugin-mode).

## Prise en charge mobile [#mobile-support]

Configurez d'abord le [éditeur mobile](/guides/docs/getting-started/installation#mobile-support). Dans la configuration en mode plugin de cette page, remplacez les enregistrements de bureau énumérés ci-dessous par les exportations mobiles des mêmes paquets, et faites le remplacement **avant d'ouvrir un document** . Gardez les modèles plugins, styles, locaux et importations Facade, et ne enregistrez pas les deux variantes.

| `@univerjs-pro/docs-column-ui` | `UniverDocsColumnUIPlugin` | `UniverDocsColumnMobileUIPlugin` |

## API Facade

Importez la façade avant d'appeler ces méthodes:

```typescript
import '@univerjs-pro/docs-column/facade'
```

### Insérer un groupe de colonnes

```typescript
const doc = univerAPI.getActiveDocument()
const group = doc?.insertColumnGroup(3, {
  gap: 18,
  widthRatios: [1.1, 1, 0.9],
})
```

### Insérer du contenu dans une colonne

```typescript
const doc = univerAPI.getActiveDocument()
const group = doc?.insertColumnGroup(2)
const [left, right] = group?.getColumns() ?? []

const leftOffset = left?.getInsertOffset()
if (leftOffset != null) {
  doc?.insertText('Summary\rKey decisions and context.', {
    startOffset: leftOffset,
    endOffset: leftOffset,
  })
}

const rightOffset = right?.getInsertOffset()
if (rightOffset != null) {
  doc?.insertTableFromData([
    ['Item', 'Owner'],
    ['Launch checklist', 'Docs team'],
  ], { offset: rightOffset, headerRowCount: 1 })
}
```

### Rechercher des groupes de colonnes

```typescript
const doc = univerAPI.getActiveDocument()

const groups = doc?.getColumnGroups() ?? []
const byId = doc?.getColumnGroup('column-group-id')
const atOffset = doc?.getColumnGroupAt(128)
const matched = doc?.findColumnGroups('Launch') ?? []

console.log(groups.map(group => group.describe()))
console.log(byId, atOffset, matched)
```

### Redimensionner ou modifier un groupe

```typescript
const doc = univerAPI.getActiveDocument()
const group = doc?.getColumnGroups()[0]

group?.setWidthRatios([1.2, 1, 0.8])

const first = group?.getColumn(0)
if (first) {
  group?.addColumn(first.getId(), 'right')
}
```

### Supprimer un groupe de colonnes

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteColumnGroup('column-group-id')
```
