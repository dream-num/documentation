Die Formfunktion ermöglicht dies Sie können Formen und Zeichnungen in ein Dokument einfügen und bearbeiten, einschließlich grundlegender geometrischer Formen, Pfeile und Flussdiagrammelemente.

## Einführung

In Univer Docs ermöglichen Ihnen Formen Folgendes:

- **Geometrische Formen einfügen**: Rechtecke, Kreise, Pfeile und mehr hinzufügen.
- **Erscheinungsbild anpassen**: Füllfarben, Rahmen und Text anpassen.
- **Frei positionieren**: Formen an einer beliebigen Stelle im Dokument platzieren Dokument.

## Plugin-Modus

### Installation

```package-install
npm install @univerjs-pro/docs-shape @univerjs-pro/docs-shape-ui
```

### Nutzung

```typescript
import { UniverDocsShapePlugin } from '@univerjs-pro/docs-shape' // [!code ++]
import { UniverDocsShapeUIPlugin } from '@univerjs-pro/docs-shape-ui' // [!code ++]
import DocsShapeUIEnUS from '@univerjs-pro/docs-shape-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-shape-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsShapeUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsShapePlugin) // [!code ++]
univer.registerPlugin(UniverDocsShapeUIPlugin) // [!code ++]
```

Wenn Sie eine kommerzielle Lizenz für haben Univer, siehe [Lizenz im Client verwenden](/guides/pro/license#in-plugin-mode) für die Konfiguration.
