<Callout type="warning" title="Attention">
  Les fonctionnalités d’importation et d’exportation nécessitent la prise en charge du serveur Univer. Assurez-vous d’avoir correctement installé et configuré le serveur Univer. Pour en savoir plus, consultez la page [Passer à la version Pro](/guides/pro).
</Callout>

Les fonctionnalités d’importation et d’exportation permettent d’importer des fichiers `.docx` dans des documents Univer ou d’exporter le contenu de documents au format `.docx` via le serveur Univer, afin de faciliter les échanges avec d’autres logiciels ou plateformes bureautiques.

<Callout title="Pourquoi Univer gère-t-il l’importation et l’exportation au moyen de services backend ?">
  Une implémentation reposant uniquement sur le frontend ne peut pas répondre aux besoins des entreprises en matière de performances et de résultats. C’est pourquoi nous fournissons des services backend pour assurer ces fonctionnalités. Vous pouvez utiliser des bibliothèques open source d’analyse de fichiers DOCX pour convertir les fichiers en structures de données conformes à l’interface `IDocumentData`, puis importer ces données dans Univer à l’aide de l’API Facade.
</Callout>

Une fois l’importation effectuée depuis l’option correspondante de la barre de menus, une notification s’affiche dans l’angle inférieur gauche de la page. Elle confirme la réussite de l’opération et fournit un lien vers le document importé. Si le comportement d’importation et d’exportation par défaut ne répond pas à vos besoins, consultez la page [Personnaliser l’importation de documents](/guides/recipes/tutorials/custom-import) pour savoir comment adapter l’importation.

## Choisir une méthode d’importation ou d’exportation

Deux méthodes sont disponibles, selon que la collaboration est nécessaire ou non :

| Méthode | Collaboration requise | Cas d’usage recommandé | API |
| --- | --- | --- | --- |
| Par `unitId` | Oui | Documents collaboratifs conservés sur le serveur | `importDOCXToUnitIdAsync` / `exportDOCXByUnitIdAsync` |
| Par instantané | Non | Flux de travail locaux ou hors ligne, ou simple conversion de format | `importDOCXToSnapshotAsync` / `exportDOCXBySnapshotAsync` |

Si votre projet utilise la collaboration, c’est-à-dire des documents conservés sur le serveur et ouverts à l’aide d’un `unitId`, choisissez la méthode par `unitId`. Dans les autres cas, utilisez la méthode par instantané.

## Mode prédéfini

### Installation

<Callout>
  Le prédéfini `UniverDocsAdvancedPreset` du package `@univerjs/preset-docs-advanced` dépend du prédéfini `UniverDocsDrawingPreset` lors de l’exécution. Commencez par installer `@univerjs/preset-docs-drawing`.
</Callout>

```package-install
npm install @univerjs/preset-docs-drawing @univerjs/preset-docs-advanced
```

### Utilisation

```typescript
import { UniverDocsAdvancedPreset } from '@univerjs/preset-docs-advanced' // [!code ++]
import UniverPresetDocsAdvancedEnUS from '@univerjs/preset-docs-advanced/locales/en-US' // [!code ++]
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEnUS from '@univerjs/preset-docs-core/locales/en-US'
import { UniverDocsDrawingPreset } from '@univerjs/preset-docs-drawing' // [!code ++]
import UniverPresetDocsDrawingEnUS from '@univerjs/preset-docs-drawing/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-docs-advanced/lib/index.css' // [!code ++]

const { univer, univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetDocsCoreEnUS,
      UniverPresetDocsDrawingEnUS, // [!code ++]
      UniverPresetDocsAdvancedEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
    UniverDocsDrawingPreset(), // [!code ++]
    UniverDocsAdvancedPreset({ // [!code ++]
      universerEndpoint: 'http://localhost:3010', // [!code ++]
    }), // [!code ++]
  ],
})
```

Si vous disposez d’une licence commerciale Univer, consultez la page [Utiliser une licence côté client](/guides/pro/license#in-preset-mode) pour savoir comment la configurer.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/docs-exchange-client
```

### Utilisation

```typescript
import { UniverDocsExchangeClientPlugin } from '@univerjs-pro/docs-exchange-client' // [!code ++]
import DocsExchangeClientEnUS from '@univerjs-pro/docs-exchange-client/locale/en-US' // [!code ++]
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client' // [!code ++]
import ExchangeClientEnUS from '@univerjs-pro/exchange-client/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/exchange-client/facade' // [!code ++]

import '@univerjs-pro/exchange-client/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      ExchangeClientEnUS, // [!code ++]
      DocsExchangeClientEnUS, // [!code ++]
    ),
  },
})

const UNIVER_SERVER_ENDPOINT = `http://localhost:8000` // [!code ++]

univer.registerPlugin(UniverExchangeClientPlugin, { // [!code ++]
  uploadFileServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/stream/file/upload`, // [!code ++]
  importServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/exchange/{type}/import`, // [!code ++]
  exportServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/exchange/{type}/export`, // [!code ++]
  getTaskServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/exchange/task/{taskID}`, // [!code ++]
  signUrlServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/file/{fileID}/sign-url`, // [!code ++]
  downloadEndpointUrl: `${UNIVER_SERVER_ENDPOINT}/`, // [!code ++]
}) // [!code ++]
univer.registerPlugin(UniverDocsExchangeClientPlugin) // [!code ++]
```

Si vous disposez d’une licence commerciale Univer, consultez la page [Utiliser une licence côté client](/guides/pro/license#in-plugin-mode) pour savoir comment la configurer.

### Plugins et configuration

Les options de configuration de `UniverExchangeClientPlugin` sont les suivantes :

```typescript
interface IUniverExchangeClientConfig {
  // Configuration for the Univer server
  downloadEndpointUrl?: string
  uploadFileServerUrl?: string
  importServerUrl?: string
  exportServerUrl?: string
```

## API Facade

### Importation

<Callout type="info" title="Remarque sur le mode plugin">
  Seul le mode plugin nécessite d’importer manuellement le package Facade. Le mode prédéfini inclut déjà le package Facade correspondant ; aucune importation supplémentaire n’est donc nécessaire.
</Callout>

### Importation

```typescript
import '@univerjs-pro/exchange-client/facade'
```

### Importer un fichier `.docx`

#### Importer un fichier `.docx` et obtenir son `unitId`

<Callout type="warning" title="Attention">
  Cette méthode nécessite la collaboration : elle crée un document sur le serveur et renvoie un `unitId`. Utilisez l’importation par instantané si la collaboration n’est pas activée.
</Callout>

Lorsque l’édition collaborative est activée, chaque document possède un `unitId` unique. L’appel de `univerAPI.importDOCXToUnitIdAsync` avec le paramètre `file` renvoie cet `unitId`, qui permet d’accéder au document. Le paramètre `file` peut être un objet `File` ou l’URL d’un fichier distant.

```typescript
// Accept a File object
const unitId = await univerAPI.importDOCXToUnitIdAsync(file)
// Or accept a remote file URL
// const unitId = await univerAPI.importDOCXToUnitIdAsync('https://example.com/filename.docx');

// Using with collaborative editing to automatically load data https://docs.univer.ai/en-US/guides/docs/features/collaboration#loading-collaborative-documents
const url = new URL(window.location.href)
url.searchParams.set('unit', unitId)
url.searchParams.set('type', '1') // The meaning of 1 is UniverInstanceType.UNIVER_DOC
window.location.href = url.toString()

// Or call the API: univerAPI.loadServerUnit(unitId, 1) to load the document, refer to /reference/facade/univer#loadserverunit for specific parameters
```

#### Importer un fichier `.docx` et obtenir ses données `IDocumentData`

<Callout>
  L’importation par instantané ne nécessite pas la collaboration. Pour les documents collaboratifs, utilisez l’importation par `unitId`.
</Callout>

L’appel de `univerAPI.importDOCXToSnapshotAsync` pour importer un fichier `.docx` renvoie les données du document au format `IDocumentData`.

```typescript
// Accept a File object
const snapshot = await univerAPI.importDOCXToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importDOCXToSnapshotAsync('https://example.com/filename.xlsx');

// Create a new document via snapshot
univerAPI.createDocument(snapshot)
```

### Exporter un fichier `.docx`

#### Exporter un fichier `.docx` à l’aide de son `unitId`

<Callout type="warning" title="Attention">
  L’exportation par `unitId` nécessite la collaboration. Si la collaboration n’est pas activée, utilisez l’exportation par instantané.
</Callout>

Lorsque l’édition collaborative est activée, chaque document possède un `unitId` unique. L’appel de `univerAPI.exportDOCXByUnitIdAsync` avec le paramètre `unitId` renvoie un objet `File`.

```typescript
const fDocument = univerAPI.getActiveDocument()
const unitId = fDocument.getId()
const file = await univerAPI.exportDOCXByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

#### Exporter un fichier `.docx` à l’aide de données `IDocumentData`

<Callout>
  L’exportation par instantané ne nécessite pas la collaboration et convient aux flux de travail locaux.
</Callout>

L’appel de `univerAPI.exportDOCXBySnapshotAsync` avec des données `IDocumentData` renvoie un objet `File`.

```typescript
const fDocument = univerAPI.getActiveDocument()
const snapshot = fDocument.save()
const file = await univerAPI.exportDOCXBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```
