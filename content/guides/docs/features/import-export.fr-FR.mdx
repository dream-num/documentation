Les API de cette page nécessitent un moteur de conversion. Suivez [intégration d'échange de fichiers](/server/import-export) pour connecter les téléchargements, conversions, requêtes de tâches, et téléchargements, puis configurer les plugins du navigateur. Les API Snapshot nécessitent également ce moteur, mais ils ne nécessitent pas de document collaboratif. L'exemple de collaboration Exchange démontre Feuilles, donc vérifier que la version cible supporte les types de fichiers requis.

Si une exportation échoue, voir [codes d'erreur de licence et traitement de l'échec des tâches](/server/import-export#export-errors).

## Formats pris en charge

Le tableau décrit les API du navigateur sur cette page. La conversion de fichier Office nécessite également un moteur de recherche qui prend en charge le même type de document et le même format.

| Importation | Exportation |
| --- | --- |
| `.doc`, `.docx` | `.docx` |

`.doc` et `.docx` utilisent les API d'importation ci-dessous. Exporter produit toujours `.docx`; le format `.doc` ancien ne peut pas être exporté.

## API Facade

### Importation

<Callout type="info" title="Note du mode greffon">
  Seul le mode plugin nécessite l'importation manuelle du paquet Facade. Le mode Preset inclut déjà le paquet Facade correspondant, donc aucune importation supplémentaire n'est nécessaire.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/docs-exchange-client/facade'
```

### Importer un fichier `.docx`

#### Importer un fichier `.docx` et obtenir son `unitId`

<Callout type="warning" title="Attention">
  Cette méthode nécessite une collaboration, car elle crée un document sur le serveur et renvoie un `unitId`. Si la collaboration n'est pas activée, utilisez l'import snapshot.
</Callout>

Lorsque l'édition collaborative est activée, chaque document a un `unitId` unique. Appelez `univerAPI.importDocToUnitIdAsync` avec le paramètre `file`, et il retourne le `unitId`, qui est ensuite utilisé pour accéder au document. Le paramètre `file` accepte un objet `File` ou une URL de fichier distant.

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importDocToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadDocAsync(unitId)
}
```

#### Importer un fichier `.docx` et obtenir ses données `IDocumentData`

<Callout>Utilisez l'importation `unitId` lorsque le document nécessite une collaboration.</Callout>

`univerAPI.importDocToSnapshotAsync` importe un fichier `.docx` et retourne les données du document sous la forme de `IDocumentData`.

```typescript
// Accept a File object
const snapshot = await univerAPI.importDocToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importDocToSnapshotAsync('https://example.com/filename.docx');

// Create a new document via snapshot
if (snapshot) univerAPI.createDocument(snapshot)
```

### Exporter un fichier `.docx`

#### Exporter un fichier `.docx` à l’aide de son `unitId`

<Callout type="warning" title="Attention">
  L’exportation par `unitId` nécessite la collaboration. Si la collaboration n’est pas activée, utilisez l’exportation
  par instantané.
</Callout>

Lorsque l'édition collaborative est activée, chaque document possède un `unitId` unique. Appelez `univerAPI.exportDocByUnitIdAsync` avec le paramètre `unitId` pour recevoir un objet `File`.

```typescript
const fDocument = univerAPI.getActiveDocument()
const unitId = fDocument.getId()
const file = await univerAPI.exportDocByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

#### Exporter un fichier `.docx` à l’aide de données `IDocumentData`

<Callout>
  L’exportation par instantané ne nécessite pas la collaboration et convient aux flux de travail locaux.
</Callout>

`univerAPI.exportDocBySnapshotAsync` accepte `IDocumentData` et renvoie un objet `File`.

```typescript
const fDocument = univerAPI.getActiveDocument()
const snapshot = fDocument.save()
const file = await univerAPI.exportDocBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

## Suppression des menus et des interactions UI d’importation et d’exportation intégrés [#import-export-ui-migration]

<Callout type="warning" title="Remarque">
  À partir de la version **1.2.0**, Univer n'inclut plus les menus d'importation/exportation intégrés ou les interactions UI. Les services sous-jacents et les API Facade restent disponibles.
</Callout>

Si l'application nécessite toujours ces menus et interactions d'interface utilisateur, le [exemple de migration pour les menus d'importation/exportation intégrés et les interactions d'assurance-chômage](https://office.univer.ai/showcase/docs/custom-import-export) montre comment les déplacer dans un plugin personnalisé. L'exemple inclut le code source complet, qui peut être consulté en ligne ou téléchargé.
