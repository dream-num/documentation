## Formats pris en charge

Le tableau décrit les API du navigateur présentées ici. La conversion des fichiers Office nécessite un backend compatible avec le même type de document et le même format.

| Importation | Exportation |
| --- | --- |
| `.doc`, `.docx` | `.docx` |

## API Facade

### Importation

<Callout type="info" title="Remarque sur le mode plugin">
  Seul le mode plugin nécessite d’importer manuellement le package Facade. Le mode prédéfini inclut déjà le package
  Facade correspondant ; aucune importation supplémentaire n’est donc nécessaire.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/docs-exchange-client/facade'
```

### Importer un fichier `.docx`

#### Importer un fichier `.docx` et obtenir son `unitId`

<Callout type="warning" title="Attention">
  Cette méthode nécessite la collaboration : elle crée un document sur le serveur et renvoie un `unitId`. Utilisez
  l’importation par instantané si la collaboration n’est pas activée.
</Callout>

Lorsque l’édition collaborative est activée, chaque document possède un `unitId` unique. L’appel de `univerAPI.importDocToUnitIdAsync` avec le paramètre `file` renvoie cet `unitId`, qui permet d’accéder au document. Le paramètre `file` peut être un objet `File` ou l’URL d’un fichier distant.

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importDocToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadDocAsync(unitId)
}
```

#### Importer un fichier `.docx` et obtenir ses données `IDocumentData`

<Callout>
  L’importation par instantané ne nécessite pas la collaboration. Pour les documents collaboratifs, utilisez
  l’importation par `unitId`.
</Callout>

L’appel de `univerAPI.importDocToSnapshotAsync` pour importer un fichier `.docx` renvoie les données du document au format `IDocumentData`.

```typescript
// Accept a File object
const snapshot = await univerAPI.importDocToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importDocToSnapshotAsync('https://example.com/filename.docx');

// Create a new document via snapshot
if (snapshot) univerAPI.createDocument(snapshot)
```

### Exporter un fichier `.docx`

#### Exporter un fichier `.docx` à l’aide de son `unitId`

<Callout type="warning" title="Attention">
  L’exportation par `unitId` nécessite la collaboration. Si la collaboration n’est pas activée, utilisez l’exportation
  par instantané.
</Callout>

Lorsque l’édition collaborative est activée, chaque document possède un `unitId` unique. L’appel de `univerAPI.exportDocByUnitIdAsync` avec le paramètre `unitId` renvoie un objet `File`.

```typescript
const fDocument = univerAPI.getActiveDocument()
const unitId = fDocument.getId()
const file = await univerAPI.exportDocByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

#### Exporter un fichier `.docx` à l’aide de données `IDocumentData`

<Callout>
  L’exportation par instantané ne nécessite pas la collaboration et convient aux flux de travail locaux.
</Callout>

L’appel de `univerAPI.exportDocBySnapshotAsync` avec des données `IDocumentData` renvoie un objet `File`.

```typescript
const fDocument = univerAPI.getActiveDocument()
const snapshot = fDocument.save()
const file = await univerAPI.exportDocBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```
