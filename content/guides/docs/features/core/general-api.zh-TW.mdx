可用的 Facade API 取決於當前單元型別和已註冊的外掛。本頁介紹 Docs 應用中最常用的一部分 Facade API。

## 導入

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 命令

Univer 中的大多數操作都透過命令系統執行。統一的執行路徑為撤銷、重做和協同功能提供了基礎。

<Callout>
  命令系統的設計細節參見 [Univer 命令系統](/blog/univer#command-system)。
</Callout>

### 監聽命令

如需在命令執行前執行程式碼，請監聽 `Event.BeforeCommandExecute`；如需在命令執行後執行程式碼，請監聽 `Event.CommandExecuted`。

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('命令執行前：', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('命令執行後：', id, params)
})
```

如需阻止命令執行，請在 `BeforeCommandExecute` 監聽器中將 `event.cancel` 設為 `true`。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'doc.command.set-name') {
    event.cancel = true
  }
})
```

每個監聽器都會返回一個 `IDisposable`，不再需要時應及時銷燬。

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### 執行命令

如果已經知道命令 ID 和參數，可以透過 `FUniver.executeCommand` 執行命令。下面的 Docs 命令會重新命名當前文件：

```typescript
const document = univerAPI.getActiveDocument()

if (document) {
  await univerAPI.executeCommand('doc.command.set-name', {
    unitId: document.getId(),
    name: '專案筆記',
  })
}
```

## 事件 API

`univerAPI.Event` 上的事件來自 Univer Core 和當前應用已註冊的外掛。Core 提供命令事件和文件生命週期事件，Docs 外掛在此基礎上新增自己的事件。使用事件前，請先確認提供該事件的外掛已經註冊。

當前版本可用的事件名稱和參數型別，請參閱 [Facade Events 參考](/reference/facade/events)。

使用 `addEvent` 訂閱事件，銷燬返回的物件即可取消訂閱：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'doc.command.set-name') {
    console.log('文件名稱已變更')
  }
})

// 不再需要時移除監聽器
disposable.dispose()
```

## 復原和重做

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## 系統剪貼簿

註冊 Docs UI 外掛後，`copy` 和 `paste` 作用於文件當前的選區和游標位置。

```typescript
await univerAPI.copy()
await univerAPI.paste()
```

<Callout>
  複製和貼上依賴瀏覽器原生的 Clipboard API。頁面未獲得焦點、呼叫不是由使用者操作觸發或沒有剪貼簿權限時，操作可能失敗。詳情請參閱 [MDN 文件](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API)。
</Callout>

## WebSocket

預設安裝已經包含 `univerAPI.createSocket(url)`，可直接使用。外掛模式需要先安裝 `@univerjs/network`、註冊 `UniverNetworkPlugin`，再引入它的 Facade 擴充套件。

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

之後即可訂閱 Socket 事件、傳送訊息並關閉連線：

```typescript
const socket = univerAPI.createSocket('wss://example.com/docs')

socket.open$.subscribe(() => socket.send('hello'))
socket.message$.subscribe((message) => console.log('WebSocket 訊息：', message.data))
socket.error$.subscribe((error) => console.error('WebSocket 錯誤：', error))
socket.close()
```

## 列舉 API

常用的列舉型別透過 `univerAPI.Enum` 提供：

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_DOC)
console.log(univerAPI.Enum.LifecycleStages.Rendered)
```

## 工具方法 API

通用的工具方法透過 `univerAPI.Util` 提供：

```typescript
console.log(univerAPI.Util.tools.isString('Univer Docs')) // true
```
