title: API de Univer Docs
---

Univer Docs es responsable de la clasificación de documentos, y sus conceptos siguen a Microsoft Word de cerca.

## Importación

```typescript
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

## Operación de documentos

En una unidad de documento, `unitId` es el identificador único del documento, y los documentos no tienen un `subUnitId`.

El contenido de texto se almacena en la cadena `body.dataStream`, que no contiene información de estilo.

La información de estilo se almacena en una estructura de datos separada, que se refiere al texto a través de referencias de índice.

Las roturas de línea, las pausas de página, secciones, párrafos y tablas están marcadas por un carácter especial en el texto. Rendering convierte estos caracteres en los elementos correspondientes.

<Callout>
  Los siguientes artículos describen el diseño de las estructuras de datos de documentos: [Univer Arquitectura de documentos y diseño de módulos](/blog/univer-doc-architecture) y [Una exploración inicial de Univer Diseño de clasificación de documentos](/blog/doc-typesetting-design).

### Crear documento [#create-document]

Llame a `univerAPI.createDocument(data)` para crear un documento. El método devuelve el envoltorio de fachada `FDocument` correspondiente.

Su argumento es un objeto de datos de documento opcional que contiene los datos iniciales. Pasando `{}` crea un documento vacío.

Para trabajar con la instancia `univer` subyacente en lugar de la Facade API, llame a `univer.createUnit(UniverInstanceType.UNIVER_DOC, data)`.

```typescript
// [!code word:data]
const doc = univerAPI.createDocument(data)
```

### Obtener ID de unidad de documento

```typescript
const doc = univerAPI.getActiveDocument()
const unitId = doc?.getId()
```

### Obtener datos del documento [#get-document-data]

```typescript
const doc = univerAPI.getActiveDocument()
const saveData = doc.save()
```

### Deshacerse del documento

Cuando un documento ya no es necesario, llame a `dispose` en la instancia Univer para destruirlo.

```typescript
univer.dispose()
```

## Operar texto

Las llamadas en esta sección modifican el texto en el área de texto rico.

### Insertar texto

Apéndice el texto especificado al final del área de texto.

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, 'Univer')
```

### Eliminar texto

Eliminar el texto por los offsets de documentos.

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteRange({ startOffset: 0, endOffset: 1 })
```

## Modificar estilo

Establece un estilo de texto en un párrafo.

```typescript
const doc = univerAPI.getActiveDocument()
const paragraph = doc?.getParagraphs()[0]

paragraph?.setStyle({
  textStyle: {
    cl: {
      rgb: '#FF0000',
    },
  },
})
```

## Insertar salto de página

`\f` es el personaje de la página. Insertarlo en el documento crea una pausa de página.

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, '\f')
```

## Estadísticas del documento

El `DocumentDataModel` subyacente calcula estadísticas para todo el documento o para los rangos seleccionados.

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')

const statistics = await doc.getDocumentDataModel().getStatistics({
  locale: univerAPI.Enum.LocaleType.ES_ES,
})
console.log(statistics.words, statistics.charactersWithSpaces, statistics.paragraphs)
```

`getStatistics()` devuelve la palabra, el carácter y los recuentos del párrafo. Pase `ranges` para contar sólo el texto seleccionado, o pasar un `AbortSignal` en `signal` a cancelar cálculos que ya no son necesarios.
