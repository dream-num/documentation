title: Univer Docs API

Univer Docs는 문서 유형 설정에 책임지고, 그 개념은 Microsoft Word를 밀접하게 따릅니다.

## 가져오기

```typescript
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

## 문서 조작

문서 단위에서 `unitId`는 문서의 고유 식별자이며 문서는 `subUnitId`가 없습니다.

텍스트 콘텐츠는 `body.dataStream` 문자열에 저장되며 스타일 정보가 포함되지 않습니다.

스타일 정보는 별도의 데이터 구조에 저장되며, 인덱스 참조를 통해 텍스트로 다시 나타납니다.

라인 틈, 페이지 틈, 섹션, 단락 및 테이블은 텍스트의 특수 문자로 표시됩니다. 렌더링은 해당 요소로이 문자를 변환합니다.

<Callout>
  다음 기사는 문서 데이터 구조의 디자인을 설명합니다. [Univer 문서 건축 및 모듈 디자인](/blog/univer-doc-architecture) 및 [Univer 문서 설정 디자인의 초기 탐험](/blog/doc-typesetting-design).

### 문서 만들기 [#create-document]

`univerAPI.createDocument(data)`를 호출하여 문서를 작성합니다. 이 방법은 해당 `FDocument` 정면 래퍼를 반환합니다.

인수는 초기 데이터가 포함된 옵션 문서 데이터 객체입니다. `{}`를 통과하면 빈 문서를 생성합니다.

Facade API 대신 `univer` 인스턴스를 실행하려면 `univer.createUnit(UniverInstanceType.UNIVER_DOC, data)`로 전화하십시오.

```typescript
// [!code word:data]
const doc = univerAPI.createDocument(data)
```

### 문서 unitId 가져오기

```typescript
const doc = univerAPI.getActiveDocument()
const unitId = doc?.getId()
```

### 문서 데이터 가져오기 [#get-document-data]

```typescript
const doc = univerAPI.getActiveDocument()
const saveData = doc.save()
```

### 문서 폐기하기

문서가 더 이상 필요하지 않을 때 `dispose`를 Univer 인스턴스에 호출하여 파괴하십시오.

```typescript
univer.dispose()
```

## 텍스트 조작

이 섹션의 호출은 풍부한 텍스트 영역에서 텍스트를 수정합니다.

### 텍스트 삽입하기

텍스트 영역의 끝에 지정된 텍스트를 승인합니다.

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, 'Univer')
```

### 텍스트 삭제하기

문서 오프셋에 의해 텍스트를 제거.

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteRange({ startOffset: 0, endOffset: 1 })
```

## 스타일 수정

단락에 텍스트 스타일을 설정합니다.

```typescript
const doc = univerAPI.getActiveDocument()
const paragraph = doc?.getParagraphs()[0]

paragraph?.setStyle({
  textStyle: {
    cl: {
      rgb: '#FF0000',
    },
  },
})
```

## 페이지 나누기 삽입

`\f`는 페이지 틈 캐릭터입니다. 문서에 삽입하면 페이지가 끊어집니다.

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, '\f')
```

## 문서 통계

`DocumentDataModel`는 전체 문서 또는 선택한 범위에 대한 통계를 계산합니다.

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')

const statistics = await doc.getDocumentDataModel().getStatistics({
  locale: univerAPI.Enum.LocaleType.KO_KR,
})
console.log(statistics.words, statistics.charactersWithSpaces, statistics.paragraphs)
```

`getStatistics()`는 단어, 문자, 단락 카운트를 반환합니다. 선택된 텍스트 만 계산하려면 `ranges`를 통과하거나 `signal`에서 `AbortSignal`을 전달하여 더 이상 필요하지 않은 계산을 취소합니다.
