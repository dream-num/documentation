title: Univer Docs API
---

Univer Docs は Microsoft Word に近い概念で、プロフェッショナルな文書組版機能を提供します。

## インポート

```typescript
import '@univerjs/docs-ui/facade'
```

## ドキュメント操作

コマンドシステムでは、`unitId` はドキュメントの一意識別子に対応し、ドキュメントには `subUnitId` はありません。

ドキュメントの本文は `body.dataStream` 文字列に保存され、ここにはスタイル情報は含まれません。

スタイル情報は別のデータ構造に保持され、インデックス参照で本文と関連付けられます。

改行、改ページ、セクション、段落、表などの要素は、本文内の特殊文字で表現され、レンダリング時に対応する要素へ変換されます。

<Callout>
  ドキュメントデータ構造の設計について詳しく知りたい場合は、[Univer Document Architecture and Module Design](/blog/univer-doc-architecture) と [An Initial Exploration of Univer Document Typesetting Design](/blog/doc-typesetting-design) を参照してください。
</Callout>

### ドキュメントの作成

`univer.createUnit` メソッドで新しいドキュメントインスタンスを作成します。第 1 引数に `UniverInstanceType.UNIVER_DOC` を渡すとドキュメントを作成します。

第 2 引数は初期データを含む `DocumentDataModel` オブジェクトで、`{}` を渡すと空のドキュメントを作成します。

作成結果として `unitId` を含む `DocumentDataModel` が返ります。

```typescript
// [!code word:data]
univer.createUnit(UniverInstanceType.UNIVER_DOC, data)
```

### ドキュメントの unitId を取得

```typescript
const doc = univerAPI.getActiveDocument()
const unitId = doc?.getId()
```

### ドキュメントデータを取得

```typescript
const doc = univerAPI.getActiveDocument()
const saveData = doc.getSnapshot()
```

### ドキュメントを破棄

不要になったら Univer インスタンスの `dispose` を呼び出して破棄します。

```typescript
univer.dispose()
```

## テキスト操作

リッチテキスト領域のテキスト要素を編集します。

### テキストを挿入

末尾に指定したテキストを追加します。

```typescript
const doc = univerAPI.getActiveDocument()
doc?.appendText('Univer')
```

### テキストを削除

カーソルの前の文字を削除します。

```typescript
univerAPI.executeCommand('doc.command.delete-left')
```

カーソルの後の文字を削除します。

```typescript
univerAPI.executeCommand('doc.command.delete-right')
```

## スタイルの変更

選択中テキストの文字色を設定します。

```typescript
univerAPI.executeCommand('doc.command.set-inline-format-text-color', { value: '#ff0000' })
```

## 改ページの挿入

`\f` 文字は改ページで、ドキュメントに改ページを挿入できます。

```typescript
const doc = univerAPI.getActiveDocument()
doc?.appendText('\f')
```

## リストの挿入

カーソル位置の段落に箇条書きを挿入します。繰り返し実行すると解除されます。

```typescript
univerAPI.executeCommand('doc.command.list-operation', { listType: 'BULLET_LIST' })
```

カーソル位置の段落に番号付きリストを挿入します。繰り返し実行すると解除されます。

```typescript
univerAPI.executeCommand('doc.command.list-operation', { listType: 'ORDER_LIST' })
```
