Univer Docsはドキュメントの型設定を担当しており、そのコンセプトはMicrosoft Wordを密接にフォローしています。

## インポート

```typescript
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

## ドキュメント操作

ドキュメントユニットでは、`unitId`はドキュメントのユニークな識別子であり、ドキュメントには`subUnitId`はありません。

テキストコンテンツは`body.dataStream`文字列に保存され、スタイル情報は一切含まれていません。

スタイル情報は別々のデータ構造で保存され、インデックス参照でテキストに戻る。

行は、テキストの特別な文字によってマークされている各ページが壊れ、セクション、段落、およびテーブルが壊れます。レンダリングは、これらの文字を対応する要素に変換します。

<Callout>
  次の記事では、文書のデータ構造の設計を記述します。 [Univer ドキュメントアーキテクチャとモジュール設計](/blog/univer-doc-architecture) と [Univer文書の定形設計の初期調査](/blog/doc-typesetting-design).
</Callout>

### ドキュメントの作成 [#create-document]

`univerAPI.createDocument(data)`を呼び出して文書を作成します。このメソッドは、対応する`FDocument`ファサードラッパーを返します。

その引数は、初期データを含むオプションのドキュメントデータオブジェクトです。 `{}` を渡ると空のドキュメントが作成されます。

Facade APIの代わりに、`univer`インスタンスを根本的に動作させるには、`univer.createUnit(UniverInstanceType.UNIVER_DOC, data)`を呼び出します。

```typescript
// [!code word:data]
const doc = univerAPI.createDocument(data)
```

### ドキュメントの unitId を取得

```typescript
const doc = univerAPI.getActiveDocument()
const unitId = doc?.getId()
```

### ドキュメントデータを取得 [#get-document-data]

```typescript
const doc = univerAPI.getActiveDocument()
const saveData = doc.save()
```

### ドキュメントを破棄

ドキュメントが不要になった場合は、Univer インスタンスで `dispose`を呼び出して破壊します。

```typescript
univer.dispose()
```

## テキスト操作

このセクションの呼び出しは、リッチテキスト領域でテキストを変更します。

### テキストを挿入

指定されたテキストをテキスト領域の最後に表示します。

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, 'Univer')
```

### テキストを削除

ドキュメントオフセットでテキストを削除します。

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteRange({ startOffset: 0, endOffset: 1 })
```

## スタイルの変更

段落にテキストスタイルを設定します。

```typescript
const doc = univerAPI.getActiveDocument()
const paragraph = doc?.getParagraphs()[0]

paragraph?.setStyle({
  textStyle: {
    cl: {
      rgb: '#FF0000',
    },
  },
})
```

## 改ページの挿入

`\f`はページブレイクの文字です。ドキュメントに貼り付けるとページブレイクが作成されます。

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, '\f')
```

## ドキュメント統計

`DocumentDataModel` は、文書全体または選択した範囲の統計を計算します。

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')

const statistics = await doc.getDocumentDataModel().getStatistics({
  locale: univerAPI.Enum.LocaleType.JA_JP,
})
console.log(statistics.words, statistics.charactersWithSpaces, statistics.paragraphs)
```

`getStatistics()`は、単語、文字、および段落のカウントを返します。 `ranges`を渡すと、選択したテキストのみをカウントするか、`signal`の`AbortSignal`を通過して、不要になった計算をキャンセルします。
