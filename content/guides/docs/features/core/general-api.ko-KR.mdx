Univer에서 사용할 수있는 Facade API는 현재 단위 유형과 응용 프로그램에 등록 된 플러그인에 따라 다릅니다. 이 페이지는 Docs 응용 프로그램에서 가장 자주 사용되는 API를 설명합니다.

## 가져오기

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 명령

Univer의 대부분의 작업은 명령 시스템을 통해 실행됩니다. 이 통합된 실행 경로는 undo, redo 및 협업을 지원합니다.

<Callout>
  명령 시스템의 디자인을 위해 [Univer 명령 시스템](/blog/univer#command-system)를 참조하십시오.
</Callout>

### 명령 수신

`Event.BeforeCommandExecute`에 가입하여 명령 실행 전에 코드를 실행하고 `Event.CommandExecuted`로 완료한 후 코드를 실행합니다.

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('명령 실행 전:', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('명령 실행 후:', id, params)
})
```

실행에서 명령을 방지하려면 `BeforeCommandExecute` 청취자에서 `event.cancel`에서 `true`을 설정하십시오.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'doc.command.set-name') {
    event.cancel = true
  }
})
```

각 청취자는 `IDisposable`를 반환합니다. 청취자가 더 이상 필요하지 않을 때 반환된 객체를 처리하십시오.

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### 명령 실행

명령 ID와 매개 변수가 알려지면 `FUniver.executeCommand`로 명령을 실행합니다. 다음과 같은 Docs 명령은 활성 문서를 다시 입력합니다.

```typescript
const document = univerAPI.getActiveDocument()

if (document) {
  await univerAPI.executeCommand('doc.command.set-name', {
    unitId: document.getId(),
    name: '프로젝트 노트',
  })
}
```

## 이벤트 API

`univerAPI.Event`의 이벤트는 Univer 코어와 응용 프로그램에 등록 된 플러그인에서 온다. 코어는 명령 이벤트 및 문서 라이프 사이클 이벤트를 제공, Docs 플러그인은 자신의 이벤트를 추가합니다. 이벤트를 사용 하기 전에 이벤트를 제공 하는 플러그인을 확인 합니다.

[Facade 이벤트 참조](/reference/facade/events)는 현재 릴리스에서 사용할 수있는 이벤트 이름과 매개 변수 유형을 나열합니다.

구독하려면 `addEvent`를 호출하면 반환된 객체를 취소합니다.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'doc.command.set-name') {
    console.log('문서 이름이 변경되었습니다')
  }
})

// 더 이상 필요하지 않은 리스너를 제거합니다
disposable.dispose()
```

## 실행 취소 및 다시 실행

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## 시스템 클립보드

Docs UI 플러그인이 등록되면 `copy`와 `paste`는 문서의 현재 선택과 관심 위치에 작동한다.

```typescript
await univerAPI.copy()
await univerAPI.paste()
```

<Callout>
  브라우저의 기본 클립보드 API에 복사 및 붙여넣기. 페이지가 집중하지 않을 때 실패할 수 있습니다. 호출이 사용자 행동에 의해 시작되지 않을 때, 또는 클립보드 권한이 사용할 수 없습니다. 자세한 내용은 [MDN 클립보드 문서](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API)를 참조하십시오.
</Callout>

## UI

[Docs UI 구성 요소](/guides/docs/ui/components) 페이지는 메뉴, 도구 모음 및 기타 Docs 인터페이스를 확장하는 방법을 설명합니다.

## WebSocket

미리 설치 설치는 이미 `univerAPI.createSocket(url)`를 노출합니다. 플러그인 모드에서 `@univerjs/network`을 설치하고 `UniverNetworkPlugin` 를 등록하고 사용하기 전에 Facade 확장을 가져옵니다.

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

후, 당신은 소켓 이벤트에 가입 할 수 있습니다, 메시지를 보내, 연결 닫기:

```typescript
const socket = univerAPI.createSocket('wss://example.com/docs')

socket.open$.subscribe(() => socket.send('hello'))
socket.message$.subscribe((message) => console.log('WebSocket 메시지:', message.data))
socket.error$.subscribe((error) => console.error('WebSocket 오류:', error))
socket.close()
```

## 열거형 API

일반적인 enum 유형은 `univerAPI.Enum`를 통해 드러납니다:

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_DOC)
console.log(univerAPI.Enum.LifecycleStages.Rendered)
```

## 유틸리티 메서드 API

`univerAPI.Util`를 통해 공유 유틸리티 방법은 다음과 같습니다.

```typescript
console.log(univerAPI.Util.tools.isString('Univer Docs')) // true
```
