Univer Docs bietet professionelle Dokumentsatzfunktionen mit Konzepten, die eng an Microsoft Word angelehnt sind.

## Importieren

```typescript
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

## Dokumente verwalten

Bei Dokumenteinheiten entspricht `unitId` der eindeutigen Kennung des Dokuments, bei Dokumenten jedoch nicht a `subUnitId`.

Der Textinhalt des Dokuments wird in der Zeichenfolge `body.dataStream` gespeichert, die keine Stilinformationen enthält.

Stilinformationen werden separat in einer anderen Datenstruktur gespeichert und über Indexverweise mit dem Textinhalt verknüpft.

Für Elemente wie Zeilenumbrüche, Seitenumbrüche, Abschnitte, Absätze und Tabellen werden unterschiedliche Sonderzeichen verwendet, um sie im Textinhalt zu kennzeichnen. Diese Sonderzeichen werden beim Rendern in entsprechende Elemente umgewandelt.

<Callout>
Möchten Sie mehr über den Entwurf von Dokumentdatenstrukturen erfahren? Wir empfehlen die Lektüre von [Univer Document Architecture and Module Design](/blog/univer-doc-architecture) und [An Initial Exploration of Univer Document Typesetting Design](/blog/doc-typesetting-design).
</Callout>

### Dokument erstellen [#create-document]

Verwenden Sie `univerAPI.createDocument(data)`, um ein neues Dokument zu erstellen und seine `FDocument`-Fassade zu erhalten Wrapper.

Der Parameter ist ein optionales Dokumentdatenobjekt, das die Anfangsdaten für das Dokument enthält. Wenn `{}` übergeben wird, wird ein leeres Dokument erstellt.

Wenn Sie direkt mit der zugrunde liegenden `univer`-Instanz anstelle der Facade-API arbeiten, verwenden Sie `univer.createUnit(UniverInstanceType.UNIVER_DOC, data)`.

```typescript
// [!code word:data]
const doc = univerAPI.createDocument(data)
```

### Dokument-Unit-ID abrufen

```typescript
const doc = univerAPI.getActiveDocument()
const unitId = doc?.getId()
```

### Dokumentdaten abrufen [#get-document-data]

```typescript
const doc = univerAPI.getActiveDocument()
const saveData = doc.save()
```

### Dokument entsorgen

Wann Wenn wir das Dokument nicht mehr benötigen, können wir die Methode `dispose` der Univer-Instanz aufrufen, um die Instanz zu zerstören.

```typescript
univer.dispose()
```

## Text bearbeiten

Textelemente im Rich-Text-Bereich ändern

### Text einfügen

Angegebenen Text an das Ende dieses Textbereichs anhängen.

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, 'Univer')
```

### Text löschen

Text nach Dokumentoffsets löschen.

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteRange({ startOffset: 0, endOffset: 1 })
```

## Ändern Stil

Legen Sie den Textstil für einen Absatz fest.

```typescript
const doc = univerAPI.getActiveDocument()
const paragraph = doc?.getParagraphs()[0]

paragraph?.setStyle({
  textStyle: {
    cl: {
      rgb: '#FF0000',
    },
  },
})
```

## Seitenumbruch einfügen

Das Zeichen `\f` ist ein Seitenumbruch, der zum Einfügen eines Seitenumbruchs in das Dokument verwendet wird.

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, '\f')
```
