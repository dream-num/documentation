可用的 Facade API 取决于当前单元类型和已注册的插件。本页介绍 Docs 应用中最常用的一部分 Facade API。

## 引入

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 命令

Univer 中的大多数操作都通过命令系统执行。统一的执行路径为撤销、重做和协同功能提供了基础。

<Callout>
  命令系统的设计细节参见 [Univer 命令系统](/blog/univer#command-system)。
</Callout>

### 监听命令

如需在命令执行前运行代码，请监听 `Event.BeforeCommandExecute`；如需在命令执行后运行代码，请监听 `Event.CommandExecuted`。

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('命令执行前：', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('命令执行后：', id, params)
})
```

如需阻止命令执行，请在 `BeforeCommandExecute` 监听器中将 `event.cancel` 设为 `true`。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'doc.command.set-name') {
    event.cancel = true
  }
})
```

每个监听器都会返回一个 `IDisposable`，不再需要时应及时销毁。

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### 执行命令

如果已经知道命令 ID 和参数，可以通过 `FUniver.executeCommand` 执行命令。下面的 Docs 命令会重命名当前文档：

```typescript
const document = univerAPI.getActiveDocument()

if (document) {
  await univerAPI.executeCommand('doc.command.set-name', {
    unitId: document.getId(),
    name: '项目笔记',
  })
}
```

## 事件 API

`univerAPI.Event` 上的事件来自 Univer Core 和当前应用已注册的插件。Core 提供命令事件和文档生命周期事件，Docs 插件在此基础上添加自己的事件。使用事件前，请先确认提供该事件的插件已经注册。

当前版本可用的事件名称和参数类型，请参阅 [Facade Events 参考](/reference/facade/events)。

使用 `addEvent` 订阅事件，销毁返回的对象即可取消订阅：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'doc.command.set-name') {
    console.log('文档名称已更改')
  }
})

// 不再需要时移除监听器
disposable.dispose()
```

## 撤销和重做

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## 系统剪贴板

注册 Docs UI 插件后，`copy` 和 `paste` 作用于文档当前的选区和光标位置。

```typescript
await univerAPI.copy()
await univerAPI.paste()
```

<Callout>
  复制和粘贴依赖浏览器原生的 Clipboard API。页面未获得焦点、调用不是由用户操作触发或没有剪贴板权限时，操作可能失败。详情请参阅 [MDN 文档](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API)。
</Callout>

## WebSocket

预设安装已经包含 `univerAPI.createSocket(url)`，可直接使用。插件模式需要先安装 `@univerjs/network`、注册 `UniverNetworkPlugin`，再引入它的 Facade 扩展。

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

之后即可订阅 Socket 事件、发送消息并关闭连接：

```typescript
const socket = univerAPI.createSocket('wss://example.com/docs')

socket.open$.subscribe(() => socket.send('hello'))
socket.message$.subscribe((message) => console.log('WebSocket 消息：', message.data))
socket.error$.subscribe((error) => console.error('WebSocket 错误：', error))
socket.close()
```

## 枚举 API

常用的枚举类型通过 `univerAPI.Enum` 提供：

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_DOC)
console.log(univerAPI.Enum.LifecycleStages.Rendered)
```

## 工具方法 API

通用的工具方法通过 `univerAPI.Util` 提供：

```typescript
console.log(univerAPI.Util.tools.isString('Univer Docs')) // true
```
