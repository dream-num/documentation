Univer Docs fournit les fonctionnalités essentielles d’un éditeur de documents, notamment un moteur de formules, un moteur de rendu, un système de conception et une bibliothèque de composants d’interface. Ensemble, elles forment une puissante plateforme de traitement de documents qui prend en charge différents formats et des opérations complexes.

## Fonctionnalités

Les principales fonctionnalités d’Univer Docs sont les suivantes :

- **Rendu des documents** : permet le rendu des documents Univer Docs, y compris celui du curseur et des sélections.
- **Mise en page des documents** : permet la composition de l’ensemble du texte, notamment le réglage des paragraphes, l’espacement avant et après les paragraphes, leur alignement, les retraits et les retraits suspendus. Elle offre également des fonctions de composition au sein des paragraphes, telles que la compression et la suspension de la ponctuation, l’espacement des caractères et la coupure des mots occidentaux.
- **Calcul des formules** : permet d’ajouter et de calculer des formules Univer (en cours de développement).
- **Gestion des tableaux** : permet d’insérer et de modifier des tableaux simples, notamment d’ajouter ou de supprimer des lignes et de modifier des cellules.
- **Styles de documents** : Univer Docs prend en charge aussi bien les *styles de documents traditionnels* similaires à ceux de Microsoft Word (avec pagination, en-têtes et pieds de page) que les *styles de documents modernes* similaires à ceux de Notion. Avec un style moderne, aucune pagination n’est nécessaire, le contenu peut s’étendre indéfiniment et différents éléments de niveau bloc, officiels ou tiers (texte, images, tableaux, etc.), peuvent être combinés dans une même mise en page (fonctionnalité prévue).
- **En-têtes et pieds de page** : permet d’insérer des en-têtes et des pieds de page, d’en modifier le contenu et de distinguer la première page des pages paires et impaires (uniquement dans les documents traditionnels).
- **Listes** : permet d’insérer et de modifier des listes ordonnées, non ordonnées et de tâches, ainsi que d’augmenter ou de réduire leur retrait.
- **Système de plugins** : permet d’utiliser des plugins personnalisés, tels que des plugins de formules, d’images ou de graphiques. Il s’agit également de l’une des capacités architecturales fondamentales d’Univer.

## Mode prédéfini

### Installation

```package-install
npm install @univerjs/presets @univerjs/preset-docs-core
```

### Utilisation

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEnUS from '@univerjs/preset-docs-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'

const { univer, univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetDocsCoreEnUS,
    ),
  },
  presets: [
    UniverDocsCorePreset(),
  ],
})

univerAPI.createDocument({})
```

### Préréglages et configuration

#### @univerjs/presets

Ce préréglage fournit la méthode `createUniver` permettant de créer une application Univer et expose toutes les méthodes et tous les objets de **@univerjs/core** et **@univerjs/design**.

La méthode `createUniver` accepte un objet de configuration comprenant notamment les options de thème, de langue et de préréglages. Elle renvoie une instance de `Univer`, `univer`, ainsi qu’une instance de `FUniver`, `univerAPI`, qui permet d’appeler l’API Facade.

```typescript
interface CreateUniverParameter {
  // Univer instance theme, default is `defaultTheme`
  theme: IStyleSheet
  // Whether to use dark mode, default is false
  darkMode?: boolean
  // The locale of the Univer instance
  locale: LocaleType
  // The locale objects to use, with keys as locale types and values as corresponding locale objects
  locales: ILocales
  // The log level of the Univer instance
  logLevel?: LogLevel
  // The list of presets to use.
  presets: IPresets[]
  // The list of plugins to use.
  plugins: IPlugins[]
}
```

Référence : [`createUniver`(https://docs.univer.ai/reference/methods/create-univer)

#### @univerjs/preset-docs-core

Il s’agit du préréglage principal d’Univer Docs. Il réunit les fonctions essentielles aux documents électroniques, telles que l’éditeur de documents, le moteur de formules et le moteur de rendu.

```typescript
interface IUniverDocsCorePresetConfig {
  // Container element, can be a string or a DOM element
  container?: string | HTMLElement
  // Whether to show the header
  header?: boolean
  // Whether to show the header toolbar
  toolbar?: boolean
  // The type of the header toolbar. 'classic': default classic mode; 'collapsed': compact mode; 'simple': ungrouped mode
  ribbonType?: RibbonType
  // Whether to show the footer
  footer?: boolean
  // Whether to show the context menu
  contextMenu?: boolean
  // Whether to disable auto focus
  disableAutoFocus?: true
  // Dependency injection override configuration
  override?: DependencyOverride
  // Menu configuration
  menu?: MenuConfig

  // ... More configuration options
}
```

L’option de configuration `menu` permet de définir simplement si certains éléments de menu doivent être affichés ou masqués :

```typescript
UniverSheetsCorePreset({
  menu: {
    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

Ici, `'sheet.command.set-range-bold'` et `'sheet.command.set-range-italic'` sont les noms des commandes correspondant aux éléments de menu concernés.

Référence : [@univerjs/preset-docs-core(https://docs.univer.ai/reference/packages/presets/univerjs/preset-docs-core)

## Mode plugin

### Installation

```package-install
npm install @univerjs/core @univerjs/engine-render @univerjs/engine-formula @univerjs/design @univerjs/ui @univerjs/docs @univerjs/docs-ui
```

### Utilisation

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIEnUS from '@univerjs/docs-ui/lib/locale/en-US'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'

import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DesignEnUS,
      UIEnUS,
      DocsUIEnUS,
    ),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
})
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)

const univerAPI = FUniver.newAPI(univer)

univerAPI.createDocument({})
```

### Plugins et configuration

#### @univerjs/core

Ce plugin constitue la bibliothèque principale d’Univer. Il fournit les fonctionnalités de base, comme la création d’instances Univer, les thèmes et les langues.

```typescript
interface UniverParameter {
  // Univer instance theme, default is `defaultTheme`
  theme: IStyleSheet
  // Whether to use dark mode, default is false
  darkMode?: boolean
  // The locale of the Univer instance
  locale: LocaleType
  // The locale objects to use, with keys as locale types and values as corresponding locale objects
  locales: ILocales
  // The log level of the Univer instance
  logLevel?: LogLevel
}
```

Référence : [`Univer`(https://docs.univer.ai/reference/classes/univer)

#### @univerjs/engine-render

Ce plugin est le moteur de rendu d’Univer. Il assure le rendu, notamment celui des barres de défilement, du curseur et des sélections. Il fournit le plugin `UniverRenderEnginePlugin`.

Référence : [@univerjs/engine-render(https://docs.univer.ai/reference/packages/plugins/univerjs/engine-render)

#### @univerjs/engine-formula

Ce plugin est le moteur de formules d’Univer. Il assure le calcul et le traitement des formules et fournit le plugin `UniverFormulaEnginePlugin`.

Référence : [@univerjs/engine-formula(https://docs.univer.ai/reference/packages/plugins/univerjs/engine-formula)

#### @univerjs/design

Ce plugin est le système de conception d’Univer. Il fournit tous les composants et styles de base.

Voir : [chapitre consacré à l’interface utilisateur](/guides/docs/ui/overview)

#### @univerjs/ui

Ce plugin constitue la base de l’interface utilisateur d’Univer. Il fournit le plugin `UniverUIPlugin`.

Le plugin `UniverUIPlugin` propose plusieurs options de configuration permettant de définir la disposition générale de l’interface.

```typescript
interface IUniverUIConfig {
  // Container element, can be a string or a DOM element
  container?: string | HTMLElement
  // Whether to show the header
  header?: boolean
  // Whether to show the header toolbar
  toolbar?: boolean
  // The type of the header toolbar. 'classic': default classic mode; 'collapsed': compact mode; 'simple': ungrouped mode
  ribbonType?: RibbonType
  // Whether to show the context menu
  contextMenu?: boolean
  // Whether to disable auto focus
  disableAutoFocus?: true
  // Dependency injection override configuration
  override?: DependencyOverride
  // Menu configuration
  menu?: MenuConfig
}
```

L’option de configuration `menu` permet de définir simplement si certains éléments de menu doivent être affichés ou masqués :

```typescript
univer.registerPlugin(UniverSheetsUIPlugin, {
  menu: {
    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

Ici, `'sheet.command.set-range-bold'` et `'sheet.command.set-range-italic'` sont les noms des commandes correspondant aux éléments de menu concernés.

Référence : [@univerjs/ui(https://docs.univer.ai/reference/packages/plugins/univerjs/ui)

#### @univerjs/docs

Ce plugin est le plugin principal d’Univer Docs. Il fournit le plugin `UniverDocsPlugin`.

Référence : [@univerjs/docs(https://docs.univer.ai/reference/packages/plugins/univerjs/docs)

#### @univerjs/docs-ui

Ce plugin est le plugin d’interface utilisateur d’Univer Docs. Il comprend les composants d’interface et les interactions de l’éditeur de documents, et fournit le plugin `UniverDocsUIPlugin`.

Référence : [@univerjs/docs-ui(https://docs.univer.ai/reference/packages/plugins/univerjs/docs-ui)
