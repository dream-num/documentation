Univer Docs bietet Kernfunktionen, darunter einen Dokumenteditor, eine Formel-Engine, eine Rendering-Engine, ein Designsystem und eine UI-Komponentenbibliothek. Zusammen bilden sie eine leistungsstarke Dokumentverarbeitungsplattform, die verschiedene Dokumentformate und komplexe Vorgänge unterstützt.

## Funktionen

Zu den Kernfunktionen von Univer Docs gehören:

- **Dokument-Rendering**: Unterstützt das Rendern von Univer Docs, einschließlich Cursor- und Auswahl-Rendering.
- **Dokumentensatz**: Unterstützt den Volltextsatz, einschließlich Absatzeinstellungen, Abstand vor und nach Absätzen, Absatzausrichtung, Einzug und hängender Einzug. Es umfasst auch Satzfunktionen innerhalb von Absätzen, wie Interpunktionskomprimierung, hängende Interpunktion, Zeichenabstand und Umbrechen westlicher Wörter.
- **Formelberechnung**: Unterstützt das Hinzufügen und Berechnen von Univer-Formeln (in Entwicklung).
- **Tabellenfunktionen**: Unterstützt das Einfügen grundlegender Tabellen und Bearbeiten von Tabellen, einschließlich Hinzufügen und Löschen von Zeilen und Bearbeiten von Zellen.
- **Dokumentstile**: Univer Docs unterstützt beide *traditionellen Dokumentstile* ähnlich wie Microsoft Word (einschließlich Paginierung, Kopf- und Fußzeilen) und *moderne Dokumentstile* ähnlich wie Notion. In modernen Dokumentstilen ist keine Paginierung erforderlich, der Inhalt kann unendlich erweitert werden und es unterstützt den gemischten Satz verschiedener offizieller oder Drittpartei-Elemente auf Blockebene (wie Text, Bilder, Tabellen usw.) (geplant).
- **Kopf- und Fußzeilen**: Unterstützt das Einfügen von Kopf- und Fußzeilen, das Bearbeiten von Kopf- und Fußzeileninhalten und die Unterscheidung zwischen ersten Seiten und ungeraden/geraden Seiten (wird nur in herkömmlichen Dokumenten unterstützt).
- **Listenfunktionen**: Unterstützt das Einfügen und Bearbeiten geordneter, ungeordneter und Aufgabenlisten sowie das Ein- und Ausrücken von Listen.
- **Emoji und Symbole**: Emoji und Symbole über das Docs-Menüband einfügen.
- **Plugin-System**: Unterstützt ein Plugin-System, das benutzerdefinierte Plugins wie Formel-Plugins und Bilder ermöglicht Plugins, Diagramm-Plugins usw. Dies ist auch eine der zentralen Architekturfunktionen von Univer.

## Voreinstellungsmodus

### Installation

```package-install
npm install @univerjs/presets @univerjs/preset-docs-core
```

### Verwendung

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEnUS from '@univerjs/preset-docs-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'

const { univer, univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetDocsCoreEnUS,
    ),
  },
  presets: [
    UniverDocsCorePreset(),
  ],
})

univerAPI.createDocument({})
```

### Voreinstellungen und Konfiguration

#### @univerjs/presets

Diese Voreinstellung stellt die Methode `createUniver` zum Erstellen einer Univer-Anwendung bereit und macht alle Methoden und Objekte von **@univerjs/core** und verfügbar **@univerjs/design**.

Die Methode `createUniver` akzeptiert ein Konfigurationsobjekt, das Optionen für Thema, Sprache, Voreinstellungen usw. enthält. Sie gibt eine `Univer`-Instanz `univer` und eine `FUniver`-Instanz `univerAPI` zum Aufrufen der Fassade zurück API.

```typescript
interface CreateUniverParameter {
  // Univer instance theme, default is `defaultTheme`
  theme: IStyleSheet
  // Whether to use dark mode, default is false
  darkMode?: boolean
  // The locale of the Univer instance
  locale: LocaleType
  region?: LocaleType
  // The locale objects to use, with keys as locale types and values as corresponding locale objects
  locales: ILocales
  // The log level of the Univer instance
  logLevel?: LogLevel
  // The list of presets to use.
  presets: IPresets[]
  // The list of plugins to use.
  plugins: IPlugins[]
}
```

Referenz: [`createUniver`(https://docs.univer.ai/reference/methods/create-univer)

#### @univerjs/preset-docs-core

Diese Voreinstellung ist die Kernvoreinstellung von Univer Docs und enthält wesentliche Kernfunktionen für elektronische Dokumente wie Dokumenteneditor, Formel-Engine und Rendering-Engine.

```typescript
interface IUniverDocsCorePresetConfig {
  // Container element, can be a string or a DOM element
  container?: string | HTMLElement
  // Whether to show the header
  header?: boolean
  // Whether to show the header toolbar
  toolbar?: boolean
  // The type of the header toolbar. 'classic': default classic mode; 'collapsed': compact mode; 'simple': ungrouped mode
  ribbonType?: RibbonType
  // Whether to show the footer
  footer?: boolean
  // Whether to show the context menu
  contextMenu?: boolean
  // Whether to disable auto focus
  disableAutoFocus?: true
  // Dependency injection override configuration
  override?: DependencyOverride
  // Menu configuration
  menu?: MenuConfig

  // ... More configuration options
}
```

Die Konfigurationsoption `menu` kann sein Wird verwendet, um einfach den Anzeige- oder Ausblendungsstatus bestimmter spezifischer Menüelemente festzulegen:

```typescript
UniverSheetsCorePreset({
  menu: {
    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

Hier sind `'sheet.command.set-range-bold'` und `'sheet.command.set-range-italic'` die Namen der Befehle, die die entsprechenden Menüelemente angeben.

Referenz: [@univerjs/preset-docs-core(https://docs.univer.ai/reference/packages/presets/univerjs/preset-docs-core)

## Plugin-Modus

### Installation

```package-install
npm install @univerjs/core @univerjs/engine-render @univerjs/engine-formula @univerjs/design @univerjs/ui @univerjs/docs @univerjs/docs-ui
```

### Nutzung

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIEnUS from '@univerjs/docs-ui/lib/locale/en-US'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'

import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DesignEnUS,
      UIEnUS,
      DocsUIEnUS,
    ),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
})
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)

const univerAPI = FUniver.newAPI(univer)

univerAPI.createDocument({})
```

### Plugins und Konfiguration

#### @univerjs/core

Dieses Plugin ist die Kernbibliothek von Univer und bietet grundlegende Funktionen wie das Erstellen von Univer-Instanzen, Themes und Sprachen.

```typescript
interface UniverParameter {
  // Univer instance theme, default is `defaultTheme`
  theme: IStyleSheet
  // Whether to use dark mode, default is false
  darkMode?: boolean
  // The locale of the Univer instance
  locale: LocaleType
  // The locale objects to use, with keys as locale types and values as corresponding locale objects
  locales: ILocales
  // The log level of the Univer instance
  logLevel?: LogLevel
}
```

Referenz: [`Univer`(https://docs.univer.ai/reference/classes/univer)

#### @univerjs/engine-render

Dieses Plugin ist die Rendering-Engine von Univer, verantwortlich für das Rendern, Bildlaufleisten, Cursor und Auswahlwiedergabe. Es stellt den `UniverRenderEnginePlugin` bereit.

Referenz: [@univerjs/engine-render(https://docs.univer.ai/reference/packages/plugins/univerjs/engine-render)

#### @univerjs/engine-formula

Dieses Plugin ist die Formel-Engine von Univer, die für die Berechnung und Verarbeitung von Formeln verantwortlich ist. Es stellt `UniverFormulaEnginePlugin` bereit.

Referenz: [@univerjs/engine-formula(https://docs.univer.ai/reference/packages/plugins/univerjs/engine-formula)

#### @univerjs/design

Dieses Plugin ist das Designsystem von Univer und stellt alle grundlegenden Komponenten und Stile bereit.

Siehe: [UI Kapitel](/guides/docs/ui/overview)

#### @univerjs/ui

Dieses Plugin ist die UI-Grundlage von Univer. Es stellt die Option `UniverUIPlugin` bereit.

Die Option `UniverUIPlugin` bietet einige Konfigurationsoptionen, die für die grundlegende Layoutkonfiguration verwendet werden können.

```typescript
interface IUniverUIConfig {
  // Container element, can be a string or a DOM element
  container?: string | HTMLElement
  // Whether to show the header
  header?: boolean
  // Whether to show the header toolbar
  toolbar?: boolean
  // The type of the header toolbar. 'classic': default classic mode; 'collapsed': compact mode; 'simple': ungrouped mode
  ribbonType?: RibbonType
  // Whether to show the context menu
  contextMenu?: boolean
  // Whether to disable auto focus
  disableAutoFocus?: true
  // Dependency injection override configuration
  override?: DependencyOverride
  // Menu configuration
  menu?: MenuConfig
}
```

Die Konfigurationsoption `menu` kann verwendet werden, um einfach den Anzeige- oder Ausblendungsstatus bestimmter spezifischer Menüelemente festzulegen:

```typescript
univer.registerPlugin(UniverSheetsUIPlugin, {
  menu: {
    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

Hier sind `'sheet.command.set-range-bold'` und `'sheet.command.set-range-italic'` die Namen der Befehle und geben die entsprechenden Menüelemente an.

Referenz: [@univerjs/ui(https://docs.univer.ai/reference/packages/plugins/univerjs/ui)

#### @univerjs/docs

Dieses Plugin ist das Kern-Plugin von Univer Docs. Es stellt `UniverDocsPlugin` bereit.

Referenz: [@univerjs/docs(https://docs.univer.ai/reference/packages/plugins/univerjs/docs)

#### @univerjs/docs-ui

Dieses Plugin ist das UI-Plugin von Univer Docs, das UI-Komponenten und Interaktionen für den Dokumenteditor enthält. Es stellt den `UniverDocsUIPlugin` bereit.

Referenz: [@univerjs/docs-ui(https://docs.univer.ai/reference/packages/plugins/univerjs/docs-ui)
