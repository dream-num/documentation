Univer Docs는 문서 편집기, 공식 엔진, 렌더링 엔진, 디자인 시스템 및 UI 구성 요소 라이브러리로 구성되어 있습니다. 함께 여러 문서 형식과 복잡한 작업을 지원하는 문서 처리 플랫폼을 형성합니다.

## 기능

- **문서 렌더링.** Univer Docs는 문서 내용, 커서 및 선택을 렌더링합니다.
- **문서 유형 설정.** 전체 텍스트 유형 설정 커버 단락 설정 : 단락, 정렬, indentation 및 거는 indent 후 간격. 단락 내에서, 그것은 또한 punctuation 압축, 거는 punctuations, 문자 간격 및 서부 단어 끊기.
- **공식 계산.** Univer Docs는 Univer 공식을 추가하고 계산하는 것을 지원합니다. 이 기능은 발달에서 아직도 입니다.
- **테이블.** Univer Docs는 기본 테이블을 삽입하고, 줄과 편집 셀을 추가하거나 삭제하는 것을 포함하여 편집합니다.
- **문서 스타일.** Univer Docs는 Microsoft Word (pagination, headers 및 footers)와 유사한 _traditional 문서 styles_를 모두 지원합니다. 현대 문서는 Paginate가 아닙니다. 콘텐츠는 제한없이 확장되며, 텍스트, 이미지 및 테이블과 같은 공식 또는 타사 블록 레벨 요소를 확장하여 동일한 문서 (예정)에서 혼합 할 수 있습니다.
- **헤더와 발자.** Univer Docs는 헤더나 영상을 삽입하고 내용을 편집합니다. 첫 페이지와 확률/even 페이지는 다를 수 있습니다 (전용 문서만).
- **이름 *** Univer Docs는 삽입 및 편집 명령, 무상 및 작업 목록, 그리고 들여쓰기 또는 알아내기를 지원합니다.
- **이모티콘과 기호.** Emoji와 기호는 Docs 리본에서 삽입 될 수 있습니다.
- **플러그인 시스템.** Univer Docs는 공식 이미지 및 도표 플러그인과 같은 주문 플러그인을 지원합니다. 플러그인 시스템은 Univer의 핵심 건축 기능 중 하나입니다.

## 플러그인 모드

### 설치

```package-install
npm install @univerjs/core @univerjs/engine-render @univerjs/engine-formula @univerjs/design @univerjs/ui @univerjs/docs @univerjs/docs-ui
```

### 사용법

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIEnUS from '@univerjs/docs-ui/lib/locale/en-US'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, DocsUIEnUS),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
})
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)

const univerAPI = FUniver.newAPI(univer)

univerAPI.createDocument({})
```

### 플러그인 설정 [#plugin-configuration]

#### @univerjs/core

핵심 라이브러리는 테마와 언어와 함께 Univer 생성기를 제공합니다.

```typescript
import type { IUniverConfig } from '@univerjs/core'
import { LocaleType, Univer } from '@univerjs/core'

const config: IUniverConfig = {
  locale: LocaleType.KO_KR,
  darkMode: false,
}
const univer = new Univer(config)
```

참고: [`IUniverConfig`](/reference/packages/plugins/univerjs/core#iuniverconfig)

#### @univerjs/engine-render

렌더링 엔진은 렌더링, 스크롤바, 커서 및 선택을 담당합니다. `UniverRenderEnginePlugin`로 등록됩니다.

참고: [@univerjs/engine-render](https://docs.univer.ai/reference/packages/plugins/univerjs/engine-render)

#### @univerjs/engine-formula

공식 엔진 계산 및 공정 공식. 그것은 `UniverFormulaEnginePlugin`로 등록됩니다.

참고: [@univerjs/engine-formula](https://docs.univer.ai/reference/packages/plugins/univerjs/engine-formula)

#### @univerjs/design

디자인 시스템은 기본 구성 요소와 스타일을 제공합니다.

참고: [UI 장](/guides/docs/ui/overview)

```typescript
univer.registerPlugin(UniverDocsUIPlugin, {
  menu: {
    'doc.command.set-inline-format-bold': {

      hidden: true,
      disabled: true,
    },
  },
})
```

`'doc.command.set-inline-format-bold'` 및 `'doc.command.set-inline-format-italic'`는 해당 메뉴 항목을 식별하는 명령명입니다.

## 프리셋 모드

### 설치

```package-install
npm install @univerjs/presets @univerjs/preset-docs-core
```

### 사용법

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEnUS from '@univerjs/preset-docs-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-docs-core/lib/index.css'

const { univer, univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(UniverPresetDocsCoreEnUS),
  },
  presets: [UniverDocsCorePreset()],
})

univerAPI.createDocument({})
```

### 프리셋 설정 [#preset-configuration]

#### @univerjs/presets

```typescript
UniverDocsCorePreset({

      hidden: true,
```

## 보기 컨트롤 [#ribbon-controls]

View Ribbon은 페이지 설정, 줌 및 풀스크린 컨트롤을 포함합니다. 줌 선택기 및 줌 바는 하단의 동일한 문서 보기 스케일을 보여줍니다. 그 스케일을 변경하지 않는 텍스트 포맷.

## 메뉴 순서와 그리드 배치 [#menu-order-and-grid-layout]

Docs 메뉴 ID를 가진 공유 [`MenuConfig`](/reference/packages/plugins/univerjs/ui#menuconfig)를 정의하고, 그 후에 사용중인 통합 형태를 위해 적용하십시오:

```ts
import type { MenuConfig } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.start.format': { order: -1 },
  'doc.command.set-inline-format-bold': {
    order: 0,
    gridLayout: { row: 2, column: 2 },
  },
  'doc.command.set-inline-format-italic': {
    gridLayout: { row: 2, column: 1 },
  },
}
```

이 옵션은 사용중인 통합 모드에 대한 기존 초기화에 해당합니다. 다른 플러그인, Locale, 테마, 컨테이너 설정을 유지하고 같은 플러그인을 두 번 등록하지 마십시오.

<Tabs items={['플러그인 모드', '프리셋 모드']}>
  <Tab>
    ```typescript
    import { UniverUIPlugin } from '@univerjs/ui'

    univer.registerPlugin(UniverUIPlugin, {
      ribbonType: 'grid',
      menu,
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
    ```

## 문서 개요 [#document-outline]

왼쪽의 개요는 헤드링 사이에 이동합니다. 그것은 문서에 내용을 삽입하지 않습니다. `toc`가 부유 할 때, 현대 문서는 윤곽과 전통적인 문서를 숨깁니다. 명시된 `true` 또는 `false`는 기본적으로 무시합니다. 공간이 부족하거나 테이블이 오버랩 할 때 패널 붕괴, 공간이 사용할 때 다시 열 수 있습니다.

이 옵션은 기존 초기화로, 동일한 플러그인을 두 번 등록하지 않습니다.

<Tabs items={['플러그인 모드', '프리셋 모드']}>
  <Tab>
    ```ts
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'

    univer.registerPlugin(UniverDocsUIPlugin, { toc: true })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [UniverDocsCorePreset({ container: 'app', toc: true })],
    })
    ```
  </Tab>
</Tabs>

## Facade API로 메뉴 업데이트 [#menu-facade]

초기화 후, 기존 인스턴스에서 [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig)를 호출합니다.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig(menu)
```

`order`는 가장 낮은것에서 가장 높은 것에서 siblings를 분류합니다. `gridLayout`은 격자 리본에 단지 적용하고 각 2 줄 그룹 내의 1 근거한 협조를 이용합니다. 고정된 갱신은 UI를 즉각 지정하고 새로 고침하지 않은 재산을 보존합니다. 플러그인 형태에서는, `menu`를 `UniverUIPlugin`에 통과하고, Facade를 부르기 전에 `@univerjs/ui/facade`을 수입합니다. [메뉴 레이아웃 가이드](/guides/sheets/features/core#menu-order-and-grid-layout)Z 격자 분야 및 관례 단추는 배열합니다.

## 붙여넣기 옵션 [#paste-options]

Docs는 3개의 풀 모드를 제공합니다: 근원 체재, 일치 목적지 체재를 지키고, 원본을 단지 지킵니다. 일치 목적지 체재는 대담한과 italic와 같은 지원 강조하는 동안 표적 원본과 단락 작풍을 채택합니다. 원본 전용 풀은 이미지와 하이퍼링크를 제거하고, 테이블 내용은 탭 격리한 원본이 됩니다. 포스트 뚱뚱한 선택권은 가장 최근 풀에 적용합니다. 브라우저 구획 클립보드가 읽는 경우에, 키보드 단축키 또는 체계 풀 명령을 사용하십시오.

데스크톱에서 리본 **팟캐스트** 드롭다운은 undo와 redo 옆에 있으며 모양 텍스트를 편집하는 동안 숨겨집니다. **페이스 북** 서브메누는 바탕 화면과 모바일 모두의 컨텍스트 메뉴의 형식 그룹에 있습니다.

## 머리글과 바닥글 필드 [#header-footer-fields]

기존 문서에서 헤더 또는 발터를 편집하고 삽입 및 탐색 컨트롤, 첫 페이지 및 확률/even-page 옵션 및 위치 설정과 함께 컨텍스트 리본을 열 수 있습니다. 리본은 현재 페이지와 총 페이지 필드를 삽입하거나 현지화 된 날짜와 시간을 삽입 할 수 있습니다. 페이지 필드는 각 렌더링 된 페이지의 값을 보여줍니다. 날짜와 시간을 위해 자동 업데이 트를 사용하여 필드를 저장하고 고정 텍스트를 삽입할 수 있습니다. 날짜 및 시간 필드가 문서가 열릴 때 새로 고침 될 수 있습니다. **관련 기사** 선택, 그들은 지속적으로 업데이트하지 않습니다. 현대 문서는 페이지 헤더 또는 발기를 사용하지 않습니다.

## 제목 섹션 접기 [#heading-collapse]

Modern 문서(`documentStyle.documentFlavor: DocumentFlavor.MODERN`)에서는 섹션 내용이 있는 제목 1~5 옆에 삼각형이 표시됩니다. 접으면 제목은 남고 다음 같은 수준 또는 상위 제목까지의 내용이 숨겨집니다. 하위 제목, 표, 이미지도 포함됩니다. 각 표 셀과 Modern 문서의 단은 별도의 제목 계층을 갖습니다.

붕괴 행동은 `toc`의 독립적입니다. 전통적인 문서와 임베디드 텍스트 편집기는 붕괴 제어를 표시하지 않습니다. 의 확장 부모 헤드는 배열 된 헤드의 붕괴 상태를 보존합니다.

<HeadingCollapseDemo />

`IParagraph.headingCollapsed`는 Univer 스냅샷에 저장되며 `true`만이 섹션을 축소합니다. 내용은 스냅샷에 남아 있으며, 상태는 undo/redo 및 협업에 참여합니다. 숨겨진 콘텐츠 내부 선택은 눈에 띄는 헤드로 이동합니다. Office 가져 오기 및 내보내기를 통해 보존은 보장되지 않습니다.

프로그램 변경을 위해, 문서 ID와 안정되어 있는 `paragraphId`를 스냅샷으로 등록 명령을 호출합니다. `collapsed: false` 설정은 섹션을 확장합니다.

```ts
import { SetHeadingCollapsedCommand } from '@univerjs/docs'

const changed = await univerAPI.executeCommand(SetHeadingCollapsedCommand.id, {
  unitId: documentId,
  paragraphId: headingParagraphId,
  collapsed: true,
})
```

명령은 `false`를 통칭하지 않은 상태 또는 기존 문서를 포함한 잘못된 대상을 반환합니다. 조상이 숨겨져있는 제목, 콜냅싱 할 때 빈 섹션 또는 편집 권한이 없습니다. [명령 계약](/reference/packages/plugins/univerjs/docs#heading-collapse) 참조.
