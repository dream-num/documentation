Univer Docs は、ドキュメントエディタ、数式エンジン、レンダリングエンジン、デザインシステム、UI コンポーネントライブラリを備えたコア機能を提供します。これらが組み合わさり、さまざまな文書形式や複雑な操作を支える強力な文書処理基盤を構成します。

## 機能

Univer Docs のコア機能には以下が含まれます。

- **ドキュメント描画**：カーソルと選択範囲を含む Univer Docs の描画をサポート。
- **ドキュメント組版**：段落設定、前後の余白、段落揃え、インデント、ぶら下げインデントなどの全体組版をサポート。句読点の詰め、ぶら下げ句読点、文字間隔、欧文の単語分割などの段落内組版も含まれます。
- **数式計算**：Univer 数式の追加と計算をサポート（開発中）。
- **表機能**：基本的な表の挿入と編集、行の追加/削除、セル編集をサポート。
- **ドキュメントスタイル**：Univer Docs は Microsoft Word に近い _従来型スタイル_（ページ区切り、ヘッダー/フッターなど）と、Notion に近い _モダンスタイル_ の両方をサポートします。モダンスタイルではページ分割不要で、コンテンツが無限に伸び、公式/サードパーティのブロック要素（テキスト、画像、表など）の混在組版に対応します（予定）。
- **ヘッダーとフッター**：ヘッダー/フッターの挿入・編集、先頭ページ/奇数偶数ページの区別をサポート（従来型のみ）。
- **リスト機能**：番号付き/箇条書き/タスクリストの挿入・編集、インデント/逆インデントに対応。
- **絵文字と記号**：Docs リボンから絵文字や記号を挿入できます。
- **プラグインシステム**：数式、画像、チャートなどのカスタムプラグインを追加できる拡張機構。Univer の中核アーキテクチャの 1 つです。

## プリセットモード

### インストール

```package-install
npm install @univerjs/presets @univerjs/preset-docs-core
```

### 使い方

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreJaJP from '@univerjs/preset-docs-core/locales/ja-JP'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'

const { univer, univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(UniverPresetDocsCoreJaJP),
  },
  presets: [UniverDocsCorePreset()],
})

univerAPI.createDocument({})
```

### プリセットと設定

#### @univerjs/presets

このプリセットは `createUniver` を提供し、**@univerjs/core** と **@univerjs/design** のすべてのメソッド/オブジェクトを公開します。

`createUniver` はテーマ、言語、プリセットなどを含む設定オブジェクトを受け取り、`Univer` インスタンス `univer` と Facade API 用の `FUniver` インスタンス `univerAPI` を返します。

```typescript
interface CreateUniverParameter {
  // Univer インスタンスのテーマ。デフォルトは `defaultTheme`
  theme: IStyleSheet
  // ダークモードを使用するか。デフォルトは false
  darkMode?: boolean
  // Univer インスタンスのロケール
  locale: LocaleType
  region?: LocaleType
  // 使用するロケールオブジェクト（キーはロケール種別）
  locales: ILocales
  // ログレベル
  logLevel?: LogLevel
  // 使用するプリセット一覧
  presets: IPresets[]
  // 使用するプラグイン一覧
  plugins: IPlugins[]
}
```

参考：[`createUniver`](https://docs.univer.ai/reference/methods/create-univer)

#### @univerjs/preset-docs-core

ドキュメントエディタ、数式エンジン、レンダリングエンジンなど、Univer Docs の基盤機能を含むコアプリセットです。

```typescript
interface IUniverDocsCorePresetConfig {
  // コンテナ要素。文字列または DOM 要素
  container?: string | HTMLElement
  // ヘッダーを表示するか
  header?: boolean
  // ヘッダーツールバーを表示するか
  toolbar?: boolean
  // ヘッダーツールバーの種別。'classic': デフォルトのクラシック; 'collapsed': コンパクト; 'simple': 非グループ
  ribbonType?: RibbonType
  // フッターを表示するか
  footer?: boolean
  // コンテキストメニューを表示するか
  contextMenu?: boolean
  // 自動フォーカスを無効化するか
  disableAutoFocus?: true
  // 依存性注入の上書き設定
  override?: DependencyOverride
  // メニュー設定
  menu?: MenuConfig

  // ... その他の設定項目
}
```

`menu` オプションは特定メニューの表示/非表示を簡単に制御できます。

```typescript
UniverSheetsCorePreset({
  menu: {
    'sheet.command.set-range-bold': {
      hidden: true,
    },
    'sheet.command.set-range-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

ここでの `'sheet.command.set-range-bold'` と `'sheet.command.set-range-italic'` はコマンド名で、該当メニュー項目を指します。

参考：[@univerjs/preset-docs-core](https://docs.univer.ai/reference/packages/presets/univerjs/preset-docs-core)

## プラグインモード

### インストール

```package-install
npm install @univerjs/core @univerjs/engine-render @univerjs/engine-formula @univerjs/design @univerjs/ui @univerjs/docs @univerjs/docs-ui
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignJaJP from '@univerjs/design/locale/ja-JP'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIJaJP from '@univerjs/docs-ui/lib/locale/ja-JP'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIJaJP from '@univerjs/ui/locale/ja-JP'

import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(DesignJaJP, UIJaJP, DocsUIJaJP),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverFormulaEnginePlugin)

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
})

univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)

const univerAPI = FUniver.newAPI(univer)

univerAPI.createDocument({})
```
