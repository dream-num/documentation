Univer Docsは、ドキュメントエディタ、フォーミュラエンジン、レンダリングエンジン、設計システム、UIコンポーネントライブラリで構成されています。 一緒に、複数のドキュメントフォーマットと複雑な操作をサポートするドキュメント処理プラットフォームを形成します。

## 機能

- **ドキュメントレンダリング。** Univer Docs は、ドキュメントの内容、カーソル、選択をレンダリングします。
- **ドキュメントの型設定。** のフルテキストの整形は段落の設定をカバーします: 段落の前と後に間隔をあけて下さい、アライメント、インデントを掛けて下さい。 段落の中で、それはまた句読の圧縮、掛かる句読点、特性の間隔およびウェスタン・ワードの壊れ目をカバーします。
- **式計算。** Univer Docsは、Univerの式の追加と計算をサポートしています。 この機能は開発中です。
- **テーブル。** Univer Docs は、基本的なテーブルをインサートし、それらを編集し、行や編集セルの追加や削除を含みます。
- **ドキュメントスタイル。** Univer Docsは、Microsoft Word (pagination、ヘッダ、フッター) と、Notion に似た _modern のドキュメントスタイル_ のどちらの _traditional 文書スタイル_ もサポートしています。 現代の文書は、制限なくコンテンツが展開されず、公式またはサードパーティのブロックレベルの要素は、テキスト、画像、テーブルなどの同じ文書(予定)で混在させることができます。
- **ヘッダーとフッター。** Univer Docs は、ヘッダやフッターの編集やコンテンツの編集をサポートしています。最初のページとオッズ/even のページは異なる (条件付き文書のみ)。
- **リスト。** Univer Docsは、注文、未注文、タスクリスト、インデントまたはインデントをインサートおよび編集をサポートしています。
- **絵文字とシンボル。** 絵文字とシンボルは、Docs リボンから差し込むことができます。
- **プラグインシステム。** Univer Docsは、式、イメージ、チャートプラグインなどのカスタムプラグインをサポートしています。プラグインシステムは、Univerのコアアーキテクチャ機能の1つです。

## プラグインモード

### インストール

```package-install
npm install @univerjs/core @univerjs/engine-render @univerjs/engine-formula @univerjs/design @univerjs/ui @univerjs/docs @univerjs/docs-ui
```

### 使い方

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignJaJP from '@univerjs/design/locale/ja-JP'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIJaJP from '@univerjs/docs-ui/lib/locale/ja-JP'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIJaJP from '@univerjs/ui/locale/ja-JP'
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(DesignJaJP, UIJaJP, DocsUIJaJP),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverFormulaEnginePlugin)

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
})

univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)

const univerAPI = FUniver.newAPI(univer)

univerAPI.createDocument({})
```

### プラグイン設定 [#plugin-configuration]

#### @univerjs/core

コアライブラリは、テーマと言語とともに、Univerコンストラクタを提供します。

```typescript
import type { IUniverConfig } from '@univerjs/core'
import { LocaleType, Univer } from '@univerjs/core'

const config: IUniverConfig = {
  locale: LocaleType.JA_JP,
  darkMode: false,
}
const univer = new Univer(config)
```

参考: [`IUniverConfig`](/reference/packages/plugins/univerjs/core#iuniverconfig)

#### @univerjs/engine-render

レンダリングエンジンは、レンダリング、スクロールバー、カーソル、および選択を担当しています。`UniverRenderEnginePlugin`として登録されています。

参考: [@univerjs/エンジンレンダリング](https://docs.univer.ai/reference/packages/plugins/univerjs/engine-render)

#### @univerjs/engine-formula

式エンジンは計算し、式を処理します。`UniverFormulaEnginePlugin`として登録されます。

参考: [@univerjs/エンジンフォーミュラ](https://docs.univer.ai/reference/packages/plugins/univerjs/engine-formula)

#### @univerjs/design

設計システムは基礎部品および様式を提供します。

基本コンポーネントとスタイルを提供するデザインシステムです。[UI の概要](/guides/docs/ui/overview)を参照してください。

```typescript
  menu: {
    'doc.command.set-inline-format-bold': {
      hidden: true,
    },
    'doc.command.set-inline-format-italic': {
      hidden: true,
      disabled: true,

  },
})
```

`'doc.command.set-inline-format-bold'`と`'doc.command.set-inline-format-italic'`は、対応するメニュー項目を識別するコマンド名です。

## プリセットモード

### インストール

```package-install
npm install @univerjs/presets @univerjs/preset-docs-core
```

### 使い方

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreJaJP from '@univerjs/preset-docs-core/locales/ja-JP'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-docs-core/lib/index.css'

const { univer, univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(UniverPresetDocsCoreJaJP),
  },
  presets: [UniverDocsCorePreset()],
})

univerAPI.createDocument({})
```

| <ConfigKey depth={3}>iconSize</ConfigKey> | `number` |  | アイコンのサイズ。単位はピクセルです。 |
| `footer` | `boolean` | `true` | フッターを表示するか、内部の操作項目を設定します。 |
| `toc` | `boolean` |  | 文書のアウトラインを表示します。既定ではモダン文書で表示され、従来形式では非表示です。 |

`menu`を使用して、特定のメニュー項目の状態を表示、非表示、またはその他の変更します。

```typescript
UniverDocsCorePreset({
  menu: {
    'doc.command.set-inline-format-bold': {
      hidden: true,
    },
    'doc.command.set-inline-format-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

`'doc.command.set-inline-format-bold'`と`'doc.command.set-inline-format-italic'`は、対応するメニュー項目を識別するコマンド名です。

参考：[@univerjs/preset-docs-core](https://docs.univer.ai/reference/packages/presets/univerjs/preset-docs-core)

## 表示の操作 [#ribbon-controls]

ビューリボンには、ページ設定、ズーム、フルスクリーンコントロールが含まれています。 ズームセレクターとズームバーが同じドキュメントビュースケールを表示します。 そのスケールを変更してもテキストのフォーマットを変更しません。

## メニューの順序とグリッド配置 [#menu-order-and-grid-layout]

Docs メニュー ID で共有された [`MenuConfig`](/reference/packages/plugins/univerjs/ui#menuconfig) を定義し、インテグレーション モードに使用します。

```ts
import type { MenuConfig } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.start.format': { order: -1 },
  'doc.command.set-inline-format-bold': {
    order: 0,
    gridLayout: { row: 2, column: 2 },
  },
  'doc.command.set-inline-format-italic': {
    gridLayout: { row: 2, column: 1 },
  },
}
```

これらのオプションを、使用中の統合モードの既存の初期化にマージします。他のプラグイン、ロケール、テーマ、およびコンテナの設定を保持し、同じプラグインを2回登録しません。

  <Tab>
    ```typescript
    import { UniverUIPlugin } from '@univerjs/ui'

    univer.registerPlugin(UniverUIPlugin, {
      ribbonType: 'grid',
      menu,
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [
        UniverDocsCorePreset({

          menu,
        }),
      ],
    })
    ```

  </Tab>

## 文書のアウトライン [#document-outline]

左側の輪郭は見出しの間に移動します。それは文書にコンテンツの表を差し込みません。 `toc`が省略されると、現代の文書は輪郭と伝統的な文書を隠します。 明示的な`true`または`false`は、デフォルトで上書きします。 スペースが不十分な場合やテーブルがそれをオーバーラップし、スペースが利用可能なときに再オープンするときパネルが崩壊します。

このオプションを既存の初期化にマージし、同じプラグインを2回登録しません。

<Tabs items={['プラグインモード', 'プリセットモード']}>
  <Tab>
    ```ts
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'

    univer.registerPlugin(UniverDocsUIPlugin, { toc: true })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
    import { createUniver } from '@univerjs/presets'

    const { univerAPI } = createUniver({
      presets: [UniverDocsCorePreset({ container: 'app', toc: true })],
    })
    ```

## Facade API でメニューを更新する [#menu-facade]

初期化後、既存のインスタンスに [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) を呼び出します。

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig(menu)
```

`order` は、最低から最上位の兄弟をソートします。`gridLayout` は、グリッド リボンのみに適用され、1 ベースの座標を各 2 列グループ内で使用します。ランタイムの更新は、指定されていないプロパティを保存し、すぐに UI を更新します。プラグイン モードでは、`menu` を `UniverUIPlugin` に渡し、ファサードを呼び出す前に `@univerjs/ui/facade` をインポートします。[メニューレイアウトガイド](/guides/sheets/features/core#menu-order-and-grid-layout) はグリッド フィールドとカスタム ボタンをカバーします。

## 貼り付けオプション [#paste-options]

Docs は、ソースの書式設定、マッチ先の書式化、テキストのみを保持する3つのペーストモードを提供します。マッチ先のフォーマットは、ターゲットテキストと段落のスタイルを採用し、太字や反復などの強調を維持しています。テキストのみのペーストは、画像とハイパーリンクを削除し、テーブルのコンテンツはタブ区切りテキストになります。ポストペーストオプションは、最新のペーストに適用されます。ブラウザブロッククリップボードが読み込まれた場合は、キーボードショートカットまたはシステムペーストコマンドを使用します。

デスクトップでは、リボン**ペースト**のドロップダウンは、undoとredoの横にあり、形状のテキストを編集する際に隠されています。 **スペシャルペースト**サブメニューは、デスクトップとモバイルの両方のコンテキストメニューの整形グループにあります。

## ヘッダーとフッターのフィールド [#header-footer-fields]

伝統的な文書では、ヘッダまたはフッターを編集すると、インジェクションとナビゲーションコントロール、ファーストページとオッズ/evenページオプション、および位置設定が付いたコンテキストリボンが開きます。リボンは、現在のページと総ページフィールド、またはローカライズされた日付と時刻を入力できます。ページフィールドは、各レンダリングされたページの値を表示します。日付と時刻については、フィールドを保存するための自動更新を有効にし、インサート固定テキストを無効にします。ドキュメントが開いているとき、または**更新フィールド**が選択されたとき、または更新されたときに日付と時間フィールドが更新され、それらは更新されず、ヘッダーは更新されません。

## 見出しの折りたたみ [#heading-collapse]

Modern 文書（`documentStyle.documentFlavor: DocumentFlavor.MODERN`）では、節の内容がある見出し 1〜5 の横に三角形が表示されます。折りたたむと見出しを残し、次の同じレベル以上の見出しまでの内容（子見出し、表、画像を含む）を隠します。各表セルと Modern の段組みは独自の見出し階層を持ちます。

崩壊動作は`toc`とは独立しています。従来の文書と埋め込まれたテキストエディタは、崩壊制御を表示しません。親見出しを拡大すると、ネストされた見出しの崩壊状態が維持されます。

<HeadingCollapseDemo />

`IParagraph.headingCollapsed`はUniverのスナップショットに格納され、`true`だけがセクションを崩壊させます。 コンテンツはスナップショットに残り、状態は、undo/redoとコラボレーションに参加しているので、他のエディタはそれを参照してください。 隠されたコンテンツ内の選択は、表示された見出しに移動します。 Officeのインポートとエクスポートによる保存は保証されません。

プログラマティックな変更については、登録したコマンドをドキュメント ID と、スナップショットから安定した `paragraphId` で呼び出します。`collapsed: false`の設定は、セクションを拡張します。

```ts
import { SetHeadingCollapsedCommand } from '@univerjs/docs'

const changed = await univerAPI.executeCommand(SetHeadingCollapsedCommand.id, {
  unitId: documentId,
  paragraphId: headingParagraphId,
  collapsed: true,
})
```

コマンドは、変更されていない状態または無効なターゲットの `false` を返します。従来の文書を含む、反対側で隠されている見出し、折り返し時に空のセクション、または編集権限を欠落させる。 [コマンド契約](/reference/packages/plugins/univerjs/docs#heading-collapse)を参照してください。
