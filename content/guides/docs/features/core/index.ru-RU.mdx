Univer Docs состоит из редактора документов, движка формулы, движок рендеринга, системы проектирования и библиотеки компонентов пользовательского интерфейса.Вместе они образуют платформу обработки документов, которая поддерживает несколько форматов документов и сложные операции.

## Возможности

- **Отображение документов.** Univer Docs отображает содержимое документа, курсор и выбор.
- **Набор документов.** Полнотекстовое наборирование охватывает настройки абзаца: интервал до и после абзаца, выравнивание, отступ и висящий отступ.В пределах абзаца также охватывает сжатие пунктуации, пунктуацию висения, интервал символов и разбиение западных слов.
- **Расчет формулы.** Univer Docs поддерживает добавление и вычисление формул Univer. Эта возможность все еще находится в разработке.
- **Столы.** Univer Docs поддерживает вставку базовых таблиц и редактирование их, включая добавление или удаление строк и редакцию ячеек.
- **Стили документов.** Univer Docs поддерживает как традиционные стили документов, похожие на Microsoft Word (заголовки, заголовки и нижние колонтитулы), так и современные стили документов (похожие на Notion).Современные документы не имеют пагината: контент расширяется без ограничений, а официальные или сторонние элементы уровня блоков, такие как текст, изображения и таблицы, могут быть смешаны в одном и том же документе (планируемом).
- **Заголовки и футеры.** Univer Docs поддерживает вставку заголовка или футера и редактирование его содержимого.Первые страницы и странные/четные страницы могут отличаться (только традиционные документы).
- **Списки.** Univer Docs поддерживает вставку и редактирование упорядоченных, неупорядоченные и списки задач, а также их вставку или врезку.
- **Эмодзи и символы.** эмодзи и символы могут быть вставлены из ленты Docs.
- **Система плагинов.** Univer Docs поддерживает пользовательские плагины, такие как плагины формул, изображений и диаграмм. Система плагинов также является одной из основных архитектурных возможностей Univer.

## Режим плагинов

### Установка

```package-install
npm install @univerjs/core @univerjs/engine-render @univerjs/engine-formula @univerjs/design @univerjs/ui @univerjs/docs @univerjs/docs-ui
```

### Использование

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIEnUS from '@univerjs/docs-ui/lib/locale/en-US'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, DocsUIEnUS),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
})
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)

const univerAPI = FUniver.newAPI(univer)

univerAPI.createDocument({})
```

### Настройка плагинов [#plugin-configuration]

#### @univerjs/core

Базовая библиотека предоставляет конструктор Univer вместе с темами и языками.

```typescript
import type { IUniverConfig } from '@univerjs/core'
import { LocaleType, Univer } from '@univerjs/core'

const config: IUniverConfig = {
  locale: LocaleType.RU_RU,
  darkMode: false,
}
const univer = new Univer(config)
```

Справочник: [`IUniverConfig`](/reference/packages/plugins/univerjs/core#iuniverconfig)

#### @univerjs/engine-render

Двигатель рендеринга отвечает за рендеринг, полосы прокрутки, курсор и выбор. Он зарегистрирован как `UniverRenderEnginePlugin`.

Справочник: [@univerjs/engine-render](https://docs.univer.ai/reference/packages/plugins/univerjs/engine-render)

#### @univerjs/engine-formula

Двигатель формулы вычисляет и обрабатывает формулы. Он зарегистрирован как `UniverFormulaEnginePlugin`.

Справочник: [@univerjs/engine-formula](https://docs.univer.ai/reference/packages/plugins/univerjs/engine-formula)

#### @univerjs/design

Система проектирования обеспечивает базовые компоненты и стили.

См. также: [раздел об UI](/guides/docs/ui/overview)

Используйте `menu`, чтобы показать, скрыть или иным образом изменить состояние определенных пунктов меню:

```typescript
univer.registerPlugin(UniverDocsUIPlugin, {
  menu: {
    'doc.command.set-inline-format-bold': {
      hidden: true,
    },
    'doc.command.set-inline-format-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

`'doc.command.set-inline-format-bold'` и `'doc.command.set-inline-format-italic'` - это имена команд, которые идентифицируют соответствующие пункты меню.

## Режим предустановок

### Установка

```package-install
npm install @univerjs/presets @univerjs/preset-docs-core
```

### Использование

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEnUS from '@univerjs/preset-docs-core/locales/en-US'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-docs-core/lib/index.css'

const { univer, univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(UniverPresetDocsCoreEnUS),
  },
  presets: [UniverDocsCorePreset()],
})

univerAPI.createDocument({})
```

| <ConfigKey depth={3}>showLabel</ConfigKey> | `boolean` | `false` | Покажите заголовок рядом с иконой. |
| <ConfigKey depth={3}>width</ConfigKey> | `number` |  | Ширина элемента в пикселях. |
| <ConfigKey depth={3}>minWidth</ConfigKey> | `number` |  | Минимальная ширина в пикселях до переноса группы в меню «Ещё». |
| <ConfigKey depth={3}>iconSize</ConfigKey> | `number` |  | Размер значка в пикселях. |
| `footer` | `boolean` | `true` | Показывает нижнюю панель или настраивает её элементы. |
| `toc` | `boolean` |  | Показывает структуру документа. По умолчанию она видна в современном режиме и скрыта в традиционном. |

Используйте `menu`, чтобы показать, скрыть или иным образом изменить состояние определенных пунктов меню:

```typescript
UniverDocsCorePreset({
  menu: {
    'doc.command.set-inline-format-bold': {
      hidden: true,
    },
    'doc.command.set-inline-format-italic': {
      hidden: true,
      disabled: true,
    },
  },
})
```

`'doc.command.set-inline-format-bold'` и `'doc.command.set-inline-format-italic'` - это имена команд, которые идентифицируют соответствующие пункты меню.

Справочник: [@univerjs/preset-docs-core](https://docs.univer.ai/reference/packages/presets/univerjs/preset-docs-core)

## Управление просмотром [#ribbon-controls]

Лента View содержит настройки страницы, зум и полноэкранные элементы управления. Селектор зума и полоса зума внизу показывают одну и ту же шкалу просмотра документа. Изменение этой шкалы не меняет форматирование текста.

## Порядок меню и размещение в сетке [#menu-order-and-grid-layout]

Определите общий [`MenuConfig`](/reference/packages/plugins/univerjs/ui#menuconfig) с идентификаторами меню Docs, а затем примените его для используемого режима интеграции:

```ts
import type { MenuConfig } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.start.format': { order: -1 },
  'doc.command.set-inline-format-bold': {
    order: 0,
    gridLayout: { row: 2, column: 2 },
  },
  'doc.command.set-inline-format-italic': {
    gridLayout: { row: 2, column: 1 },
  },
}
```

## Структура документа [#document-outline]

Наброски слева перемещаются между заголовками. В документ не вставляется таблица содержимого. При опущении `toc` современные документы показывают контур и традиционные документы скрывают его. Явный `true` или `false` перекрывает либо по умолчанию. Панель разрушается, когда пространства недостаточно, либо таблица перекрывает его, и вновь открывается, когда пространство доступно.

Объединение этой опции в существующую инициализацию, и не регистрировать один и тот же плагин дважды.

  <Tab>

    ```ts
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'

    univer.registerPlugin(UniverDocsUIPlugin, { toc: true })
    ```
  </Tab>
  <Tab>

    ```ts
    import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
    import { createUniver } from '@univerjs/presets'
    ```

## Обновление меню через Facade API [#menu-facade]

После инициализации позвоните в [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) по существующему экземпляру:

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig(menu)
```

`order` сортирует братьев и сестер от самых низких до самых высоких. `gridLayout` применяется только к сетке Ribbon и использует 1-базовые координаты в каждой группе из двух рядов. Обновления Runtime сохраняют свойства, которые не были указаны, и сразу же обновляют пользовательский интерфейс. В режиме плагина передайте `menu` `UniverUIPlugin` и импортируйте `@univerjs/ui/facade` перед вызовом Facade. [Руководство по составлению меню](/guides/sheets/features/core#menu-order-and-grid-layout) покрывает поля сетки и пользовательские кнопки.

## Параметры вставки [#paste-options]

Docs предоставляет три режима вставки: сохранение форматирования источника, сопоставление форматирования назначения и сохранение только текста. Форматирование назначения матча принимает целевой текст и стили абзаца при сохранении поддерживаемого акцента, такого как жирный и курсивный. Вставка только текста удаляет изображения и гиперссылки, а содержимое таблицы становится отдельным текстом. Опции после вставки применяются к самой последней вставке. Если браузер блокирует чтение буфера обмена, используйте ярлык клавиатуры или команду системной вставки.

На настольном компьютере выпадающий Ribbon **паста** расположен рядом с undo и redo, и он скрыт при редактировании текста формы.Подменю **Специальный паст** находится в группе форматирования контекстного меню как на настольном, так и на мобильном устройствах.

## Поля колонтитулов [#header-footer-fields]

В традиционных документах редактирование заголовка или футера открывает контекстную ленту с элементами управления вставкой и навигацией, опциями первой страницы и нечетной/четной страницы и настройками позиционирования. Лента может вставлять поля текущей страницы и общей страницы, или локализованную дату и время. Поля страниц показывают значение для каждой визуализированной страницы. Для даты и времени позволяют автоматически обновлять поле и отключать его для вставки фиксированного текста. Поля даты и времени обновляются при открытии документа или при выборе **Обновить поля**, и они не обновляются непрерывно. Современные документы не используют заголовки страниц или футеры.

## Сворачивание разделов [#heading-collapse]

В документах Modern (`documentStyle.documentFlavor: DocumentFlavor.MODERN`) рядом с заголовками уровней 1–5, имеющими содержимое раздела, показан треугольник. При сворачивании заголовок остаётся, а содержимое до следующего заголовка того же или более высокого уровня скрывается, включая вложенные заголовки, таблицы и изображения. У каждой ячейки таблицы и колонки Modern своя иерархия.

Поведение коллапса не зависит от `toc`. Традиционные документы и встроенные текстовые редакторы не отображают элементы управления коллапсом. Расширение родительского заголовка сохраняет состояние коллапсов своих вложенных заголовков.

<HeadingCollapseDemo />

`IParagraph.headingCollapsed` хранится в снимке Univer, и только `true` сворачивает раздел. Содержание остается в снимках, а государство участвует в отмене/редо и сотрудничестве, поэтому другие редакторы видят его. Выбор внутри скрытого контента переходит в видимый заголовок. Сохранение через Office импорт и экспорт не гарантируется.

Для программных изменений вызов зарегистрированной команды с ID документа и стабильного `paragraphId` из снимка.Настройка `collapsed: false` расширяет раздел.

```ts
import { SetHeadingCollapsedCommand } from '@univerjs/docs'

const changed = await univerAPI.executeCommand(SetHeadingCollapsedCommand.id, {
  unitId: documentId,
  paragraphId: headingParagraphId,
  collapsed: true,
})
```

Команда возвращает `false` для неизмененного состояния или недействительной цели, включая традиционный документ, заголовок, скрытый предком, пустой раздел при коллапсе или отсутствующее разрешение на редактирование.См. [Командный контракт](/reference/packages/plugins/univerjs/docs#heading-collapse).
