Univerで利用可能なファサードAPIは、アプリケーションに登録された現在のユニットタイプとプラグインによって異なります。 このページでは、Docsアプリケーションで最も頻繁に使用されるAPIについて説明します。

## インポート

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## コマンド

Univerのほとんどの操作は、コマンドシステムを介して実行されます。この統一された実行パスは、undo、redo、およびコラボレーションをサポートしています。

<Callout>
  コマンドシステムの設計については、[Univerコマンドシステム](/blog/univer#command-system)を参照してください。
</Callout>

### コマンドの監視

`Event.BeforeCommandExecute` にコマンドが実行される前にコードを実行し、`Event.CommandExecuted`にコードが終了すると実行します。

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('コマンド実行前:', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('コマンド実行後:', id, params)
})
```

実行からコマンドを防止するため、`BeforeCommandExecute` リスナーで `event.cancel` から `true` に設定します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'doc.command.set-name') {
    event.cancel = true
  }
})
```

各リスナーは、`IDisposable`を返します。リスナーが不要になったときに、返されたオブジェクトを消去します。

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### コマンドの実行

コマンド ID とパラメーターが既知の場合、コマンドを `FUniver.executeCommand` で実行します。次の Docs コマンドは、アクティブなドキュメントの名前を変更します。

```typescript
const document = univerAPI.getActiveDocument()

if (document) {
  await univerAPI.executeCommand('doc.command.set-name', {
    unitId: document.getId(),
    name: 'プロジェクトノート',
  })
}
```

## イベント API

`univerAPI.Event`のイベントは、Univerコアとアプリケーションに登録しているプラグインから来ています。Coreは、コマンドイベントとドキュメントのライフサイクルイベントを提供し、Docsプラグインはイベントを自分で追加します。イベントをイベントに使用する前に、プラグインが登録されていることを確認してください。

[ファサードイベントの参照](/reference/facade/events)は、現在のリリースで利用可能なイベント名とパラメータタイプをリストします。

`addEvent` を購読し、返されたオブジェクトを退会します。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'doc.command.set-name') {
    console.log('文書名が変更されました')
  }
})

// 不要になったリスナーを削除します
disposable.dispose()
```

## 元に戻すとやり直し

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## システムクリップボード

Docs UI プラグインが登録された後、`copy` と `paste`は、ドキュメントの現在の選択とキャレット位置で動作します。

```typescript
await univerAPI.copy()
await univerAPI.paste()
```

<Callout>
  コピー&ペーストは、ブラウザのネイティブクリップボードAPIに依存します。 ユーザーが操作を開始していないとき、またはクリップボードの許可が利用できなくなったときに、ページがフォーカスしていないときに失敗することができます。 詳細は、[MDN クリップボードのドキュメント](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API)を参照してください。
</Callout>

## UI

[Docs UIコンポーネント](/guides/docs/ui/components)のページでは、Docsインターフェイスのメニュー、ツールバー、その他の部分を拡張する方法について説明します。

## WebSocket

`univerAPI.createSocket(url)`を既にプリセットインストールします。プラグインモードでは、`@univerjs/network`をインストールし、`UniverNetworkPlugin`を登録し、使用前にファサード拡張をインポートします。

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

その後、ソケットイベントを購読したり、メッセージを送信したり、接続を閉じたりすることができます。

```typescript
const socket = univerAPI.createSocket('wss://example.com/docs')

socket.open$.subscribe(() => socket.send('hello'))
socket.message$.subscribe((message) => console.log('WebSocket メッセージ:', message.data))
socket.error$.subscribe((error) => console.error('WebSocket エラー:', error))
socket.close()
```

## 列挙型 API

`univerAPI.Enum`を通して共通のenumのタイプは露出します:

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_DOC)
console.log(univerAPI.Enum.LifecycleStages.Rendered)
```

## ユーティリティメソッド API

共有ユーティリティメソッドは、`univerAPI.Util` を介して公開されます。

```typescript
console.log(univerAPI.Util.tools.isString('Univer Docs')) // true
```
