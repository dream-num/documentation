Univer Docs отвечает за набор документов, и его концепции тесно связаны с Microsoft Word.

## Импорт

```typescript
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

## Работа с документами

В блоке документов `unitId` является уникальным идентификатором документа, а документы не имеют `subUnitId`.

Текстовое содержимое хранится в строке `body.dataStream`, которая не содержит информации о стиле.

Информация о стиле хранится в отдельной структуре данных, которая ссылается на текст через ссылки на индексы.

Линейные разрывы, разрывы страниц, разделы, абзацы и таблицы каждый помечаются специальным символом в тексте.Рендеры преобразуют эти символы в соответствующие элементы.

### Создание документа [#create-document]

Позвоните `univerAPI.createDocument(data)`, чтобы создать документ. Способ возвращает соответствующую обёртку фасада `FDocument`.

Его аргумент — необязательный объект данных документа, который содержит исходные данные.Переход `{}` создаёт пустой документ.

Чтобы работать с базовым экземпляром `univer` вместо Facade API, позвоните в `univer.createUnit(UniverInstanceType.UNIVER_DOC, data)`.

```typescript
// [!code word:data]
const doc = univerAPI.createDocument(data)
```

### Получение unitId документа

```typescript
const doc = univerAPI.getActiveDocument()
const unitId = doc?.getId()
```

### Получение данных документа [#get-document-data]

```typescript
const doc = univerAPI.getActiveDocument()
const saveData = doc.save()
```

### Удаление документа

Когда документ больше не нужен, позвоните в `dispose` на экземпляре Univer, чтобы уничтожить его.

```typescript
univer.dispose()
```

## Работа с текстом

Звонки в этом разделе изменяют текст в области богатого текста.

### Вставка текста

Добавить указанный текст в конец текстовой области.

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, 'Univer')
```

### Удаление текста

Удалить текст с помощью офсетов документов.

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteRange({ startOffset: 0, endOffset: 1 })
```

## Изменение стиля

Установите стиль текста на абзаце.

```typescript
const doc = univerAPI.getActiveDocument()
const paragraph = doc?.getParagraphs()[0]

paragraph?.setStyle({
  textStyle: {
    cl: {
      rgb: '#FF0000',
    },
  },
})
```

## Вставка разрыва страницы

`\f` - это символ разбивки страниц. Вставка его в документ создает разрыв страницы.

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, '\f')
```

## Статистика документа

Базовый `DocumentDataModel` вычисляет статистику для всего документа или для выбранных диапазонов.

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')

const statistics = await doc.getDocumentDataModel().getStatistics({
  locale: univerAPI.Enum.LocaleType.RU_RU,
})
console.log(statistics.words, statistics.charactersWithSpaces, statistics.paragraphs)
```

`getStatistics()` возвращает значение слова, символа и абзаца.Пройдите `ranges`, чтобы подсчитать только выбранный текст, или пропустите `AbortSignal` в `signal` для отмены вычислений, которые больше не требуются.
