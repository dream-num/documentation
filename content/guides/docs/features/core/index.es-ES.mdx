Univer Docs consiste en un editor de documentos, un motor de fórmulas, un motor renderizado, un sistema de diseño y una biblioteca de componentes UI. Juntos forman una plataforma de procesamiento de documentos que admite múltiples formatos de documentos y operaciones complejas.

## Características

- **Presentación de documentos.** Univer Docs presenta el contenido del documento, el cursor y la selección.
- **Se escriben documentos.** La composición de texto completo cubre la configuración del párrafo: espaciamiento antes y después de un párrafo, alineación, indentación y la indentación colgante. En un párrafo, también cubre la compresión de punción, punción colgante, espaciación de caracteres y ruptura de palabras occidentales.
- **Cálculo de Fórmula.** Univer Docs soporta añadir y calcular fórmulas Univer. Esta capacidad todavía está en desarrollo.
- **Tablas.** Univer Docs soporta insertar tablas básicas y editarlas, incluyendo añadir o eliminar filas y celdas de edición.
- **Estilos de documentos.** Univer Docs soporta ambos estilos de documentos _traditional_ similares a Microsoft Word (pagination, headers, and footers) y _modern document styles_ similar to Notion. Los documentos modernos no paginan: el contenido se expande sin límite, y los elementos oficiales o de terceros de nivel de bloque, tales como texto, imágenes y tablas, se pueden mezclar en el mismo documento (planned).
- **Cabeceras y calzado.** Univer Docs soporta insertar una cabecera o una calzada y editar su contenido. Las primeras páginas y las páginas pueden diferir (sólo documentos tradicionales).
- **Listas.** Univer Docs soporta insertar y editar listas ordenadas, no ordenadas, y tareas, y la indentación o la identificación.
- **Emoji y símbolos.** Emoji y símbolos se pueden insertar desde la cinta de Docs.
- **Sistema de enchufe.** Univer Docs admite plugins personalizados, como fórmula, imagen y plugins de gráficos. El sistema de plugins es también una de las capacidades arquitectónicas básicas de Univer.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs/core @univerjs/engine-render @univerjs/engine-formula @univerjs/design @univerjs/ui @univerjs/docs @univerjs/docs-ui
```

### Uso

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverDocsPlugin } from '@univerjs/docs'
import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
import DocsUIEnUS from '@univerjs/docs-ui/lib/locale/en-US'
import { UniverFormulaEnginePlugin } from '@univerjs/engine-formula'
import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs/docs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, DocsUIEnUS),
  },
})

univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverFormulaEnginePlugin)
univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
})
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)

const univerAPI = FUniver.newAPI(univer)

univerAPI.createDocument({})
```

### Configuración de plugins [#plugin-configuration]

#### @univerjs/core

La biblioteca central proporciona el constructor Univer, junto con temas e idiomas.

```typescript
import type { IUniverConfig } from '@univerjs/core'
import { LocaleType, Univer } from '@univerjs/core'

const config: IUniverConfig = {
  locale: LocaleType.ES_ES,
  darkMode: false,
}
const univer = new Univer(config)
```

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
```

## Controles de vista [#ribbon-controls]

La cinta View contiene ajustes de página, zoom y controles de pantalla completa. El selector de zoom y la barra de zoom en la parte inferior muestran la misma escala de visualización de documentos.

## Orden de menús y disposición en cuadrícula [#menu-order-and-grid-layout]

Define un [`MenuConfig`](/reference/packages/plugins/univerjs/ui#menuconfig) compartido con los IDs del menú Docs, luego aplicarlo para el modo de integración en uso:

```ts
import type { MenuConfig } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.start.format': { order: -1 },
  'doc.command.set-inline-format-bold': {
    order: 0,
    gridLayout: { row: 2, column: 2 },
  },
  'doc.command.set-inline-format-italic': {
    gridLayout: { row: 2, column: 1 },
  },
}
```

Combina estas opciones en la inicialización existente para el modo de integración en uso. Retenga el otro plugin, locale, tema y configuración de contenedores, y no registre el mismo plugin dos veces.

## Esquema del documento [#document-outline]

El esbozo de las naves izquierdas entre las partidas. No inserta una tabla de contenidos en el documento. Cuando `toc` se omite, los documentos modernos muestran el esbozo y los documentos tradicionales lo ocultan. Un `true` explícito o `false` anula por defecto. El panel se derrumba cuando el espacio es insuficiente o una tabla lo superpone, y se vuelve a cuando el espacio disponible.

Combina esta opción en la inicialización existente, y no registra el mismo plugin dos veces.

## Opciones de pegado [#paste-options]

Docs proporciona tres modos de pasta: mantener el formato de fuente, el formato de destino de partido, y mantener el texto sólo. El formato de destino coincide adopta el texto objetivo y los estilos de párrafo mientras mantiene el énfasis soportado como audaz e itálica. El pegado de texto elimina imágenes y hipervínculos, y el contenido de la tabla se convierte en texto separado de la pestaña. Las opciones de post-paste se aplican a la pasta más reciente.

En el escritorio, el desplegable Ribbon **Paste** está situado junto al deshacer y redo, y está oculto mientras se edita el texto de forma. El submenú **Pegado especial** se encuentra en el grupo de formato del menú contextual tanto en el escritorio como en el móvil.

## Campos de encabezado y pie de página [#header-footer-fields]

En documentos tradicionales, la edición de una cabecera o un pie abre una cinta contextual con controles de inserción y navegación, opciones de primera página y de par o página, y ajustes de posicionamiento. La cinta puede insertar campos de página y página completa, o una fecha y hora localizados. Los campos de página muestran el valor de cada página renderizada. Para la fecha y el tiempo, permite la actualización automática para almacenar un campo, y desactivarlo para insertar el texto fijo. **Actualizar campos** se selecciona, y no actualizan continuamente. Los documentos modernos no utilizan encabezados de página o pies de página.

## Plegar secciones [#heading-collapse]

Los documentos Modern (`documentStyle.documentFlavor: DocumentFlavor.MODERN`) muestran un triángulo junto a los títulos 1–5 que tienen contenido en su sección. Al plegar, el título permanece y se oculta el contenido hasta el siguiente título de nivel igual o superior, incluidos subtítulos, tablas e imágenes. Cada celda y columna Modern tiene su propia jerarquía.

El comportamiento del colapso es independiente de `toc`. Los documentos tradicionales y los editores de texto incrustados no muestran los controles del colapso. Ampliar una dirección padre preserva el estado del colapso de sus encabezados anidados.

<HeadingCollapseDemo />

`IParagraph.headingCollapsed` se almacena en la instantánea Univer, y sólo `true` colapsa una sección. El contenido permanece en la instantánea, y el estado participa en el deshacer/redo y la colaboración, por lo que otros editores lo ven. Una selección dentro del contenido oculto se mueve a la partida visible. La preservación a través de la importación de oficinas y la exportación no está garantizada.

Para los cambios programáticos, llame al comando registrado con el documento ID y un `paragraphId` estable de la instantánea. Configuración `collapsed: false` amplía la sección.

```ts
import { SetHeadingCollapsedCommand } from '@univerjs/docs'

const changed = await univerAPI.executeCommand(SetHeadingCollapsedCommand.id, {
  unitId: documentId,
  paragraphId: headingParagraphId,
  collapsed: true,
})
```

El comando devuelve `false` para un estado inalterado o un objetivo inválido, incluyendo un documento tradicional, un encabezamiento oculto por un ancestro, una sección vacía al colapsar o faltar permiso de edición.
