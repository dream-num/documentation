title: Univer Docs API

Univer Docs 提供專業級文件排版能力，相關概念會儘可能與 Microsoft Word 保持一致。

## 引入

```typescript
import '@univerjs/docs-ui/facade'
```

## 操作文件

命令系統中 `unitId` 對應的是文件的唯一標識，文件不存在 `subUnitId`。

文件的文字內容儲存在 `body.dataStream` 字串中，此字串不包含樣式資訊。

樣式資訊單獨儲存在另外的資料結構中，並透過下標索引與文字內容關聯。

對於換行、分頁、章節、段落、表格等元素， 在文字內容中使用不同的特殊字元來標記，這些特殊字元在渲染時被轉換為對應的元素。

<Callout>
  想要進一步瞭解文件的資料結構設計嗎？推薦閱讀[《Univer 文件架構及模組設計》](/blog/univer-doc-architecture) 和[《Univer 文件排版設計初探》](/blog/doc-typesetting-design)。
</Callout>

### 建立文件

`univer.createUnit` 方法用於建立一個新的文件例項。當第一個參數的值為 `UniverInstanceType.UNIVER_DOC` 時，表示建立一個文件例項。

此時第二個參數是一個可選的 `DocumentDataModel` 物件，包含了文件的初始資料。如果傳入 `{}`，則建立一個空文件。

建立成功後返回一個 `DocumentDataModel` 物件，包含了文件的唯一標識 `unitId` 和其他相關資訊。

```typescript
// [!code word:data]
univer.createUnit(UniverInstanceType.UNIVER_DOC, data)
```

### 獲取文件 unitId

```typescript
const doc = univerAPI.getActiveDocument()
const unitId = doc?.getId()
```

### 獲取文件資料

```typescript
const doc = univerAPI.getActiveDocument()
const saveData = doc.getSnapshot()
```

### 銷燬文件

當我們不再需要文件時，可以呼叫 Univer 例項的 `dispose` 方法來銷燬例項。

```typescript
univer.dispose()
```

## 操作文字

對富文字區域的文字元素進行操作

### 插入文字

將指定的文字新增到此文字區域的末尾。

```typescript
const doc = univerAPI.getActiveDocument()
doc?.appendText('Univer')
```

### 刪除文字

刪除游標前的字元

```typescript
univerAPI.executeCommand('doc.command.delete-left')
```

刪除游標後的字元

```typescript
univerAPI.executeCommand('doc.command.delete-right')
```

## 修改樣式

為選中的文字設定字型色

```typescript
univerAPI.executeCommand('doc.command.set-inline-format-text-color', { value: '#ff0000' })
```

## 插入分頁符

`\f` 為分頁符，用於在文件中插入分頁符。

```typescript
const doc = univerAPI.getActiveDocument()
doc?.appendText('\f')
```

## 插入列表

給游標所在段落新增一個無序列表，重複呼叫則取消無序列表

```typescript
univerAPI.executeCommand('doc.command.list-operation', { listType: 'BULLET_LIST' })
```

給游標所在段落新增一個有序列表，重複呼叫則取消有序列表

```typescript
univerAPI.executeCommand('doc.command.list-operation', { listType: 'ORDER_LIST' })
```
