---
title: Univer Docs API
---

Univer Docs 負責文件排版，相關概念與 Microsoft Word 保持基本一致。

## 引入

```typescript
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

## 操作文件

文件單元的 `unitId` 是該文件的唯一標識，文件沒有 `subUnitId`。

文字內容儲存在 `body.dataStream` 字串中，該字串不包含樣式資訊。

樣式資訊儲存在另一個獨立的資料結構中，並透過下標索引關聯到文字內容。

換行、分頁、章節、段落、表格等元素在文字中分別用特殊字元標記，渲染時這些字元會轉換為對應的元素。

<Callout>
  文件資料結構的詳細設計參見[《Univer 文件架構及模組設計》](/blog/univer-doc-architecture)和[《Univer 文件排版設計初探》](/blog/doc-typesetting-design)。
</Callout>

### 建立文件 [#create-document]

呼叫 `univerAPI.createDocument(data)` 可建立文件，並返回對應的 `FDocument` facade 包裝物件。

其參數是一個可選的文件資料物件，包含文件的初始資料。傳入 `{}` 會建立一個空文件。

如果要直接操作底層 `univer` 例項而不使用 Facade API，請呼叫 `univer.createUnit(UniverInstanceType.UNIVER_DOC, data)`。

```typescript
// [!code word:data]
const doc = univerAPI.createDocument(data)
```

### 獲取文件 unitId

```typescript
const doc = univerAPI.getActiveDocument()
const unitId = doc?.getId()
```

### 獲取文件資料 [#get-document-data]

```typescript
const doc = univerAPI.getActiveDocument()
const saveData = doc.save()
```

### 銷燬文件

文件不再需要時，呼叫 Univer 例項的 `dispose` 方法銷燬該例項。

```typescript
univer.dispose()
```

## 操作文字

本節中的呼叫都會修改富文字區域內的文字。

### 插入文字

將指定文字追加到文字區域的末尾。

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, 'Univer')
```

### 刪除文字

根據文件偏移量刪除文字。

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteRange({ startOffset: 0, endOffset: 1 })
```

## 修改樣式

設定段落的文字樣式。

```typescript
const doc = univerAPI.getActiveDocument()
const paragraph = doc?.getParagraphs()[0]

paragraph?.setStyle({
  textStyle: {
    cl: {
      rgb: '#FF0000',
    },
  },
})
```

## 插入分頁符

`\f` 是分頁符，在文件中插入該字元會產生分頁。

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, '\f')
```

## 文件統計

底層 `DocumentDataModel` 可統計整篇文件或指定文字範圍的資料。

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')

const statistics = await doc.getDocumentDataModel().getStatistics({
  locale: univerAPI.Enum.LocaleType.ZH_TW,
})
console.log(statistics.words, statistics.charactersWithSpaces, statistics.paragraphs)
```

`getStatistics()` 返回詞數、字元數和段落數。傳入 `ranges` 時只統計選中的文字；傳入 `signal` 可以取消不再需要的計算。
