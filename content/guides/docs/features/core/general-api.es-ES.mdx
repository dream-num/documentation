Las API de Facade disponibles en Univer dependen del tipo de unidad actual y de los plugins registrados en la aplicación. Esta página describe las API más utilizadas en una aplicación de Docs.

## Importación

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Comandos

La mayoría de las operaciones en Univer se ejecutan a través del sistema de comandos. Esta ruta de ejecución unificada soporta deshacer, redo y colaboración.

<Callout>
  Para el diseño del sistema de comandos, vea [Sistema de comando Univer](/blog/univer#command-system).
</Callout>

### Escuchar comandos

Suscríbete a `Event.BeforeCommandExecute` para ejecutar código antes de ejecutar un comando, y a `Event.CommandExecuted` ejecutar código después de que termine.

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('Antes del comando:', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('Comando ejecutado:', id, params)
})
```

Para evitar que un comando ejecute, establece `event.cancel` a `true` en un oyente `BeforeCommandExecute`.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'doc.command.set-name') {
    event.cancel = true
  }
})
```

Cada oyente devuelve un `IDisposable`. Despose el objeto devuelto cuando el oyente ya no es necesario.

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### Ejecutar comandos

Cuando se conoce el ID de comando y sus parámetros, ejecute el comando con `FUniver.executeCommand`. El siguiente comando Docs renombra el documento activo:

```typescript
const document = univerAPI.getActiveDocument()

if (document) {
  await univerAPI.executeCommand('doc.command.set-name', {
    unitId: document.getId(),
    name: 'Notas del proyecto',
  })
}
```

## API de eventos

Los eventos en `univerAPI.Event` provienen del núcleo Univer y de los plugins registrados en la aplicación. Core proporciona eventos de comandos y eventos de ciclo de vida de documentos, y los plugins Docs añaden sus propios eventos. Confirme que el plugin que proporciona un evento está registrado antes de utilizar el evento.

El [Facade Eventos referencia](/reference/facade/events) enumera los nombres de los eventos y los tipos de parámetro disponibles en la versión actual.

Llame a `addEvent` para suscribirse, y luego deseche el objeto devuelto para darse de baja:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'doc.command.set-name') {
    console.log('El nombre del documento ha cambiado')
  }
})

// Elimine el listener cuando ya no sea necesario
disposable.dispose()
```

## Deshacer y rehacer

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## Portapapeles del sistema

Después de que el plugin de Docs UI esté registrado, `copy` y `paste` operan en la selección actual y la posición de cuidado en el documento.

```typescript
await univerAPI.copy()
await univerAPI.paste()
```

<Callout>
  Copiar y pegar dependen de la API nativa del navegador. Pueden fallar cuando la página no tiene foco, cuando la llamada no se inicia por una acción del usuario, o cuando el permiso del portapapeles no está disponible. Para obtener más información, consulte el [Documentación del portapapeles MDN](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API).
</Callout>

## WebSocket

Una instalación preestablecida ya expone `univerAPI.createSocket(url)`. En modo plugin, instale `@univerjs/network`, registre `UniverNetworkPlugin` e importe su extensión Facade antes de usar.

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

Después, puede suscribirse a eventos de socket, enviar mensajes y cerrar la conexión:

```typescript
const socket = univerAPI.createSocket('wss://example.com/docs')

socket.open$.subscribe(() => {
  socket.send('hello')
})

socket.message$.subscribe((message) => {
  console.log('Mensaje WebSocket:', message.data)
})

socket.error$.subscribe((error) => {
  console.error('Error de WebSocket:', error)
})

socket.close()
```

## API de enumeración

Los tipos comunes de enum están expuestos a través de `univerAPI.Enum`:

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_DOC)
console.log(univerAPI.Enum.LifecycleStages.Rendered)
```

## API de métodos de utilidad

Los métodos de utilidad compartidos se exponen a través de `univerAPI.Util`:

```typescript
console.log(univerAPI.Util.tools.isString('Univer Docs')) // true
```
