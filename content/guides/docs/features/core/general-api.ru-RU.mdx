API-интерфейсы Facade, доступные в Univer, зависят от текущего типа блока и плагинов, зарегистрированных в приложении. На этой странице описаны API, наиболее часто используемые в приложении Docs.

## Импорт

```typescript
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Команды

Большинство операций в Univer выполняются через систему команд. Этот унифицированный путь выполнения поддерживает отмену, переделку и совместную работу.

<Callout>
  Конструкцию командной системы см. в [Командная система Univer](/blog/univer#command-system).
</Callout>

### Прослушивание команд

Подписывайтесь на `Event.BeforeCommandExecute` для запуска кода перед выполнением команды, а на `Event.CommandExecuted` - для запуска код после его завершения.

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('Перед командой:', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('Команда выполнена:', id, params)
})
```

Чтобы предотвратить выполнение команды, установите `event.cancel` на `true` в прослушивателе `BeforeCommandExecute`.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'doc.command.set-name') {
    event.cancel = true
  }
})
```

Каждый слушатель возвращает `IDisposable`.Удалите возвращенный объект, когда слушатель больше не нужен.

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### Выполнение команд

Когда идентификатор команды и ее параметры известны, выполните команду с помощью `FUniver.executeCommand`. Следующая команда Docs переименовывает активный документ:

```typescript
const document = univerAPI.getActiveDocument()

if (document) {
  await univerAPI.executeCommand('doc.command.set-name', {
    unitId: document.getId(),
    name: 'Заметки проекта',
  })
}
```

## API событий

События на `univerAPI.Event` происходят из ядра Univer и из плагинов, зарегистрированных в приложении. Core предоставляет командные события и события жизненного цикла документов, а плагины Docs добавляют свои собственные события. Подтверждают, что плагин, предоставляющий событие, зарегистрирован перед использованием события.

[Ссылка на события Facade](/reference/facade/events) перечисляет имена событий и типы параметров, доступные в текущем выпуске.

Позвоните `addEvent`, чтобы подписаться, а затем удалите возвращенный объект, чтобы отказаться от подписки:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'doc.command.set-name') {
    console.log('Имя документа изменено')
  }
})

// Удалите обработчик, когда он больше не нужен
disposable.dispose()
```

## Отмена и повтор действий

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## Системный буфер обмена

После регистрации плагина Docs UI, `copy` и `paste` работают на текущей позиции выбора и ухода в документе.

```typescript
await univerAPI.copy()
await univerAPI.paste()
```

<Callout>
  Копирование и вставка полагаются на собственный API Clipboard браузера. Они могут выйти из строя, когда страница не имеет фокуса, когда вызов не инициирован действием пользователя или когда разрешение буфера обмена недоступно. Подробности см. в [MDN клипборд документация](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API).
</Callout>

## WebSocket

Предустановленная установка уже выставляет `univerAPI.createSocket(url)`. В режиме плагина установите `@univerjs/network`, зарегистрируйте `UniverNetworkPlugin` и импортируйте его расширение Facade перед использованием.

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

После этого вы можете подписаться на события сокетов, отправлять сообщения и закрывать соединение:

```typescript
const socket = univerAPI.createSocket('wss://example.com/docs')

socket.open$.subscribe(() => socket.send('hello'))
socket.message$.subscribe((message) => console.log('Сообщение WebSocket:', message.data))
socket.error$.subscribe((error) => console.error('Ошибка WebSocket:', error))
socket.close()
```

## API перечислений

Типы обычного числа выставляются через `univerAPI.Enum`:

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_DOC)
console.log(univerAPI.Enum.LifecycleStages.Rendered)
```

## API вспомогательных методов

Общие методы полезности выставляются через `univerAPI.Util`:

```typescript
console.log(univerAPI.Util.tools.isString('Univer Docs')) // true
```
