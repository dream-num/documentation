---
title: Univer Docs API
---

Univer Docs 负责文档排版，相关概念与 Microsoft Word 保持基本一致。

## 引入

```typescript
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

## 操作文档

文档单元的 `unitId` 是该文档的唯一标识，文档没有 `subUnitId`。

文本内容保存在 `body.dataStream` 字符串中，该字符串不包含样式信息。

样式信息保存在另一个独立的数据结构中，并通过下标索引关联到文本内容。

换行、分页、章节、段落、表格等元素在文本中分别用特殊字符标记，渲染时这些字符会转换为对应的元素。

<Callout>
  文档数据结构的详细设计参见[《Univer 文档架构及模块设计》](/blog/univer-doc-architecture)和[《Univer 文档排版设计初探》](/blog/doc-typesetting-design)。
</Callout>

### 创建文档 [#create-document]

调用 `univerAPI.createDocument(data)` 可创建文档，并返回对应的 `FDocument` facade 包装对象。

其参数是一个可选的文档数据对象，包含文档的初始数据。传入 `{}` 会创建一个空文档。

如果要直接操作底层 `univer` 实例而不使用 Facade API，请调用 `univer.createUnit(UniverInstanceType.UNIVER_DOC, data)`。

```typescript
// [!code word:data]
const doc = univerAPI.createDocument(data)
```

### 获取文档 unitId

```typescript
const doc = univerAPI.getActiveDocument()
const unitId = doc?.getId()
```

### 获取文档数据 [#get-document-data]

```typescript
const doc = univerAPI.getActiveDocument()
const saveData = doc.save()
```

### 销毁文档

文档不再需要时，调用 Univer 实例的 `dispose` 方法销毁该实例。

```typescript
univer.dispose()
```

## 操作文本

本节中的调用都会修改富文本区域内的文本。

### 插入文本

将指定文本追加到文本区域的末尾。

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, 'Univer')
```

### 删除文本

根据文档偏移量删除文本。

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteRange({ startOffset: 0, endOffset: 1 })
```

## 修改样式

设置段落的文本样式。

```typescript
const doc = univerAPI.getActiveDocument()
const paragraph = doc?.getParagraphs()[0]

paragraph?.setStyle({
  textStyle: {
    cl: {
      rgb: '#FF0000',
    },
  },
})
```

## 插入分页符

`\f` 是分页符，在文档中插入该字符会产生分页。

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertText(0, '\f')
```

## 文档统计

底层 `DocumentDataModel` 可统计整篇文档或指定文本范围的数据。

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')

const statistics = await doc.getDocumentDataModel().getStatistics({
  locale: univerAPI.Enum.LocaleType.ZH_CN,
})
console.log(statistics.words, statistics.charactersWithSpaces, statistics.paragraphs)
```

`getStatistics()` 返回词数、字符数和段落数。传入 `ranges` 时只统计选中的文本；传入 `signal` 可以取消不再需要的计算。
