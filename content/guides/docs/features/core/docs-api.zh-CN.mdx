通过 Univer Docs API，在应用中创建、编辑和保存文档。你可以定位指定段落更新报告、修改文字样式，也可以向用户显示自动化操作修改的位置。下面以一份发布计划为例，串起从创建到保存的完整过程。

[创建文档](#create-document) · [编辑指定段落](#edit-paragraph) · [修改文字样式](#text-style) · [保存结果](#get-document-data)

示例使用 **Univer 1.3.0**。请先完成 [Docs 安装](/guides/docs/getting-started/installation)，并保持各 Univer 包版本一致。

## ID、文本片段与偏移量 [#document-identifiers]

用持久化 ID 标识内容，用偏移量表示文本位置。在前面插入文字会改变索引，但不会改变已有段落或节的身份。

| 标识 | 含义 | 获取与定位 |
| --- | --- | --- |
| `unitId` | 整篇文档；Docs 没有 `subUnitId`。 | `doc.getId()` |
| `paragraphId` | 持久化的段落标识。 | `paragraph.getId()`；`doc.getParagraph(id, segmentId?)` |
| `sectionId` | 传统文档中持久化的节标识。 | `section.getId()`；`doc.getSection(index)` 接收从 **0** 开始的索引，不是 ID。 |
| `segmentId` | 正文（`''`）、页眉或页脚的文本流。 | `paragraph.getSegmentId()` |
| `startOffset`、`endOffset` | 文本片段内的 UTF-16 位置，包含起点、不包含终点。 | `paragraph.getRange()` 或 `range.getRange()` |

段落和节的句柄会在调用时重新按持久化 ID 定位。`FDocumentTextRange` 则保存**固定偏移量**：在范围前插入或删除文字后，需要重新获取范围。段落或节被删除后，旧句柄不再有效。详见[段落](/reference/facade/document-paragraph)、[节](/reference/facade/document-section)和[文本范围](/reference/facade/document-text-range)。

## 引入 Facade

插件模式下，内容操作引入 Docs Facade，显示选区还需 Docs UI Facade。预设模式已包含对应的 Facade 入口。

```typescript
import '@univerjs/docs/facade'
import '@univerjs/docs-ui/facade'
```

## 创建文档 [#create-document]

本例创建两个段落和一个传统文档节。后续代码均操作返回的 `doc`。快照显式提供 ID，便于之后定位同一个段落。

```typescript
const doc = univerAPI.createDocument({
  id: 'launch-plan',
  title: 'Launch plan',
  body: {
    dataStream: 'Launch plan\rStatus: Draft\r\n',
    paragraphs: [
      { startIndex: 11, paragraphId: 'p-title' },
      { startIndex: 25, paragraphId: 'p-status' },
    ],
    sectionBreaks: [{ startIndex: 26, sectionId: 's-main' }],
  },
  documentStyle: {
    documentFlavor: univerAPI.Enum.DocumentFlavor.TRADITIONAL,
    pageSize: { width: 595, height: 842 },
    marginTop: 40,
    marginBottom: 40,
    marginLeft: 40,
    marginRight: 40,
  },
})
```

编辑器中会显示“Launch plan”和“Status: Draft”两个段落。应用可通过 `p-title`、`p-status` 在后续操作中继续找到它们。

`\r` 结束一个段落，`\n` 结束一个节，`startIndex` 指向相应的控制字符。详见[正文数据结构](/guides/docs/model/document-body)。运行时 API 会维护这些索引，不要通过改写实时快照编辑内容。

## 定位并编辑段落 [#edit-paragraph]

使用文档中真实的段落 ID。`setText()` 替换当前段落文字；`appendText()` 在段落结束符前追加文字。下面即使先在文档前面插入内容，也仍会修改原来的状态段落。

```typescript
const paragraph = doc.getParagraph('p-status')
if (!paragraph) throw new Error('Status paragraph not found')

const paragraphId = paragraph.getId()
doc.insertText(0, '[Review] ')
paragraph.setText('Status: Ready')
paragraph.appendText(' for review')

console.log(doc.getParagraph(paragraphId)?.getText())
// Status: Ready for review
```

第一个段落变为“[Review] Launch plan”，第二个段落变为“Status: Ready for review”。状态段落的位置发生变化，但其 ID 保持不变。

## 无需切换选区即可修改文字样式 [#text-style]

找到目标文字后直接设置样式，无需先创建可见选区，也适用于 Agent 和无头处理任务。

```typescript
const status = doc.getParagraph('p-status')
const ready = status?.findText('Ready')
if (!ready) throw new Error('Target text not found')

ready.setTextStyle({ cl: { rgb: '#2563eb' }, bl: 1 })
console.log(ready.getText())
```

“Ready”会显示为蓝色粗体，同一段落中的其他文字保持原样。

`setTextStyle()` 修改已有字符，不是为后续输入设置全局颜色。段落布局及默认文字样式使用 `paragraph.setStyle()`，详见 [FDocumentParagraph.setStyle()](/reference/facade/document-paragraph#setstyle)。

## 在编辑器中显示选区 [#text-selection]

本例定位正文中的文字，请先处于正文编辑状态，再把当前偏移量传给 `setSelection()`。该方法依赖 Docs UI，返回 `void`，不修改内容。它使用**当前正在编辑的文本片段**，没有 `segmentId` 参数，不会自动从页眉或页脚切回正文。

```typescript
const target = doc.getParagraph('p-status')?.findText('Ready')
if (!target) throw new Error('Target text not found')

const { startOffset, endOffset } = target.getRange()
doc.setSelection(startOffset, endOffset)
```

## 定位传统文档的节 [#document-sections]

Section API 适用于 **Traditional（传统分页）** 文档；Modern 文档使用 ColumnGroup API。`getSection(0)` 获取第一个节；按已知 ID 查找时遍历当前节列表，不要把字符串 ID 传给 `getSection()`。

```typescript
if (doc.isTraditional()) {
  const firstSection = doc.getSection(0)
  console.log(firstSection?.getId())

  const section = doc.getSections().find(item => item.getId() === 's-main')
  console.log(section?.getRange())
}
```

## 保存与销毁 [#get-document-data]

`save()` 返回当前快照，包含段落和节 ID，由应用自行持久化。用 `disposeUnit()` 销毁一篇文档；宿主卸载时用 `univer.dispose()` 销毁整个编辑器。

```typescript
const snapshot = doc.save()
console.log(snapshot.body?.paragraphs, snapshot.body?.sectionBreaks)

// When this document is no longer needed:
// univerAPI.disposeUnit(doc.getId())
```

## 操作文本 [#操作文本]

### 插入文本 [#插入文本]

在指定偏移量插入文字。偏移量 0 表示正文开头。

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')

doc.insertText(0, 'Review: ')
```

### 删除文本 [#删除文本]

删除 startOffset（包含）到 endOffset（不包含）之间的文字。

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')

doc.deleteRange({ startOffset: 0, endOffset: 8 })
```

## 插入分页符 [#插入分页符]

在传统分页文档中，将分页符插入指定位置。

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc) throw new Error('No active document')

if (doc.isTraditional()) {
  doc.insertText(0, '\f')
}
```
