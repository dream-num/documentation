Les liens hypertextes permettent d’accéder rapidement à des pages web externes, des adresses e-mail et d’autres contenus depuis un document.

## Mode preset

### Installation

```package-install
npm install @univerjs/preset-docs-hyper-link
```

### Utilisation

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreFrFR from '@univerjs/preset-docs-core/locales/fr-FR'
import { UniverDocsHyperLinkPreset } from '@univerjs/preset-docs-hyper-link' // [!code ++]
import UniverPresetDocsHyperLinkFrFR from '@univerjs/preset-docs-hyper-link/locales/fr-FR' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-hyper-link/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.FR_FR,
  locales: {
    [LocaleType.FR_FR]: mergeLocales(
      UniverPresetDocsCoreFrFR,
      UniverPresetDocsHyperLinkFrFR, // [!code ++]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
    UniverDocsHyperLinkPreset(), // [!code ++]
  ],
})
```

## Mode plugin

### Installation

```package-install
npm install @univerjs/docs-hyper-link @univerjs/docs-hyper-link-ui
```

### Utilisation

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsHyperLinkPlugin } from '@univerjs/docs-hyper-link' // [!code ++]
import { UniverDocsHyperLinkUIPlugin } from '@univerjs/docs-hyper-link-ui' // [!code ++]
import DocsHyperLinkUIFrFR from '@univerjs/docs-hyper-link-ui/locale/fr-FR' // [!code ++]

import '@univerjs/docs-hyper-link-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.FR_FR,
  locales: {
    [LocaleType.FR_FR]: mergeLocales(
      DocsHyperLinkUIFrFR, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsHyperLinkPlugin) // [!code ++]
univer.registerPlugin(UniverDocsHyperLinkUIPlugin) // [!code ++]
```

## Créer et modifier des liens avec l’API Facade

`link(text, url)` ajoute un texte lié et mémorise sa plage, sans calcul manuel des positions. Utilisez l’identifiant renvoyé par `getLinks()` pour modifier ensuite la destination.

```ts
const richText = univerAPI
  .newRichText()
  .text('Read ')
  .link('Univer documentation', 'https://docs.univer.ai')
  .text(' for details.')

const [link] = richText.getLinks()
if (!link) throw new Error('Link was not created')

richText.updateLink(link.rangeId, 'https://docs.univer.ai/guides')
```

`removeLink(link.rangeId)` supprime la destination tout en conservant le texte visible.
