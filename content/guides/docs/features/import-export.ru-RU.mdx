## Поддерживаемые форматы

В таблице указаны форматы браузерных API этой страницы. Для преобразования файлов Office нужен сервер с поддержкой соответствующего типа документа и формата.

| Импорт | Экспорт |
| --- | --- |
| `.doc`, `.docx` | `.docx` |

## Facade API

### Импорт

<Callout type="info" title="Примечание для режима плагинов">
  Импортировать пакет Facade вручную нужно только в режиме плагинов. В режиме предустановок соответствующий пакет Facade
  уже подключён, поэтому дополнительный импорт не требуется.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/docs-exchange-client/facade'
```

### Импорт `.docx`

#### Импорт файла `.docx` с получением `unitId`

<Callout type="warning" title="Внимание">
  Для этого метода требуется совместная работа: он создаёт документ на сервере и возвращает `unitId`. Если совместная
  работа не включена, используйте импорт снимка.
</Callout>

При совместном редактировании у каждого документа есть уникальный `unitId`. Метод `univerAPI.importDocToUnitIdAsync` принимает параметр `file` и возвращает `unitId`, по которому можно открыть документ. Параметр `file` может быть объектом `File` или URL удалённого файла.

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importDocToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadDocAsync(unitId)
}
```

#### Импорт файла `.docx` с получением `IDocumentData`

<Callout>
  Для импорта снимка совместная работа не требуется. Для совместных документов используйте импорт по `unitId`.
</Callout>

Метод `univerAPI.importDocToSnapshotAsync` импортирует файл `.docx` и возвращает данные документа в формате `IDocumentData`.

```typescript
// Accept a File object
const snapshot = await univerAPI.importDocToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importDocToSnapshotAsync('https://example.com/filename.docx');

// Create a new document via snapshot
if (snapshot) univerAPI.createDocument(snapshot)
```

### Экспорт `.docx`

#### Экспорт файла `.docx` по `unitId`

<Callout type="warning" title="Внимание">
  Для экспорта по `unitId` требуется совместная работа. Если она не включена, используйте экспорт снимка.
</Callout>

При совместном редактировании у каждого документа есть уникальный `unitId`. Метод `univerAPI.exportDocByUnitIdAsync` принимает параметр `unitId` и возвращает объект `File`.

```typescript
const fDocument = univerAPI.getActiveDocument()
const unitId = fDocument.getId()
const file = await univerAPI.exportDocByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

#### Экспорт файла `.docx` с помощью `IDocumentData`

<Callout>Для экспорта снимка совместная работа не требуется; этот способ подходит для локальных сценариев.</Callout>

Метод `univerAPI.exportDocBySnapshotAsync` принимает `IDocumentData` и возвращает объект `File`.

```typescript
const fDocument = univerAPI.getActiveDocument()
const snapshot = fDocument.save()
const file = await univerAPI.exportDocBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```
