## Поддерживаемые форматы

В таблице описаны API-интерфейсы браузера на этой странице.Конверсия файлов Office также требует бэкэнда, который поддерживает тот же тип и формат документа.

| Импорт | Экспорт |
| --- | --- |
| `.doc`, `.docx` | `.docx` |

Как `.doc`, так и `.docx` используют импортные API ниже. Экспорт всегда производит `.docx`; устаревший формат `.doc` не может быть экспортирован.

## Facade API

### Импорт

<Callout type="info" title="Заметка о режиме плагина">
  Только режим плагина требует импорта пакета Facade вручную.Предустановленный режим уже включает соответствующий пакет Facade, поэтому дополнительный импорт не требуется.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/docs-exchange-client/facade'
```

### Импорт `.docx`

#### Импорт файла `.docx` с получением `unitId`

<Callout type="warning" title="Осторожно">
  Этот метод требует совместной работы, потому что он создает документ на сервере и возвращает `unitId`. Если совместная работа не включена, используйте импорт снимков.
</Callout>

При включенном совместном редактировании каждый документ имеет уникальный `unitId`. Звоните `univerAPI.importDocToUnitIdAsync` с параметром `file`, и он возвращает `unitId` , который затем используется для доступа к документу. Параметр `file` принимает объект `File` или удаленный URL-адрес файла.

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importDocToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadDocAsync(unitId)
}
```

#### Импорт файла `.docx` с получением `IDocumentData`

<Callout>Импорт снимка не требует сотрудничества. Используйте импорт `unitId`, когда документ требует сотрудничества.</Callout>

`univerAPI.importDocToSnapshotAsync` импортирует файл `.docx` и возвращает данные документа как `IDocumentData`.

```typescript
// Accept a File object
const snapshot = await univerAPI.importDocToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importDocToSnapshotAsync('https://example.com/filename.docx');

// Create a new document via snapshot
if (snapshot) univerAPI.createDocument(snapshot)
```

### Экспорт `.docx`

#### Экспорт файла `.docx` по `unitId`

<Callout type="warning" title="Внимание">
  Для экспорта по `unitId` требуется совместная работа. Если она не включена, используйте экспорт снимка.
</Callout>

При включенном совместном редактировании каждый документ имеет уникальный `unitId`. Позвоните `univerAPI.exportDocByUnitIdAsync` с параметром `unitId`, чтобы получить объект `File`

```typescript
const fDocument = univerAPI.getActiveDocument()
const unitId = fDocument.getId()
const file = await univerAPI.exportDocByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

#### Экспорт файла `.docx` с помощью `IDocumentData`

<Callout>Для экспорта снимка совместная работа не требуется; этот способ подходит для локальных сценариев.</Callout>

`univerAPI.exportDocBySnapshotAsync` принимает `IDocumentData` и возвращает объект `File`.

```typescript
const fDocument = univerAPI.getActiveDocument()
const snapshot = fDocument.save()
const file = await univerAPI.exportDocBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

## Удаление встроенных меню и UI-взаимодействий для импорта и экспорта [#import-export-ui-migration]

<Callout type="warning" title="Замечание">
  Начиная с версии **1.2.0**, Univer больше не включает в себя встроенные меню импорта/экспорта или взаимодействия пользовательского интерфейса.
</Callout>

Если приложение по-прежнему требует этих меню и взаимодействия пользовательского интерфейса, [Пример миграции для встроенных меню импорта / экспорта и взаимодействия пользовательского интерфейса](https://office.univer.ai/showcase/docs/custom-import-export) показывает, как переместить их в пользовательский плагин. Пример включает в себя полный исходный код, который можно просматривать онлайн или загружать.
