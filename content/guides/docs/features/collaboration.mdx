Collaborative editing connects your browser editor to a backend. Start with [Collaboration integration](/server/collaboration/browser-integration) to run the example and connect your application's identity, permissions, and storage. See [Collaboration Quick Start](/server/collaboration/quick-start) for the browser and server configuration.

Create the document through an authenticated application API, then load the returned Unit identifier with the method below. Reuse that identifier when opening the same document again.

## Load the document [#document-loading]

Set the current user before loading a document. The current user identifies the collaborator and owns the local offline cache. After setting it, load the document explicitly with the Facade:

```ts
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadDocAsync('your-unit-id')
```

<Callout type="warning">
The current version of `UniverCollaborationClientUIPlugin` still reads the `unit` and `type` query parameters on startup and loads that document. This behavior is deprecated and will be removed in a later version. Set `enableUrlUnitLoader: false` during initialization to turn it off.
</Callout>

Merge the options below into your existing plugin registration or collaboration preset call. In preset mode, add `collaborationPreset` to the existing `createUniver()` presets list alongside your editor presets.

<Tabs items={['Plugin Mode', 'Preset Mode']}>
  <Tab>
    ```ts
    import { UniverCollaborationClientUIPlugin } from '@univerjs-pro/collaboration-client-ui'

    univer.registerPlugin(UniverCollaborationClientUIPlugin, {
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverDocsCollaborationPreset } from '@univerjs/preset-docs-collaboration'

    const collaborationPreset = UniverDocsCollaborationPreset({
      universerEndpoint: 'https://your-backend.example.com',
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
