Suivez l’[Intégration collaborative](/server/collaboration/browser-integration) pour exécuter l’exemple, connecter votre application et vérifier la persistance et les autorisations. Les détails et exemples Web/Server sont disponibles sur [Démarrage rapide de la collaboration](/server/collaboration/quick-start).

Créez le Unit via une API métier authentifiée appelant Collaboration Service, puis chargez son identifiant dans le navigateur. Configurez HTTP, Session Ticket et WebSocket selon le [Quick Start](/server/collaboration/quick-start), puis la persistance et les [autorisations serveur](/server/collaboration/identity-and-authorization) pour la lecture, JOIN et les modifications.

## Choisir qui charge le document [#document-loading]

Par défaut, `UniverCollaborationClientUIPlugin` lit les paramètres URL `unit` et `type` au démarrage et charge le document. Si votre application choisit le document et appelle elle-même la Facade, définissez `enableUrlUnitLoader: false` à l’initialisation pour centraliser le chargement dans l’application.

Fusionnez ces options dans votre enregistrement de plugin ou appel de preset existant. En mode preset, ajoutez `collaborationPreset` à la liste des presets de votre `createUniver()`, avec ceux de l’éditeur.

<Tabs items={['Mode plugin', 'Mode preset']}>
  <Tab>
    ```ts
    import { UniverCollaborationClientUIPlugin } from '@univerjs-pro/collaboration-client-ui'

    univer.registerPlugin(UniverCollaborationClientUIPlugin, {
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverDocsCollaborationPreset } from '@univerjs/preset-docs-collaboration'

    const collaborationPreset = UniverDocsCollaborationPreset({
      universerEndpoint: 'https://your-backend.example.com',
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
</Tabs>

La désactivation du chargement automatique par URL conserve la collaboration et le chargement explicite via la Facade.

## Facade API [#loading-collaborative-documents]

```ts
import '@univerjs-pro/collaboration-client/facade'

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadDocAsync('your-unit-id')
```
