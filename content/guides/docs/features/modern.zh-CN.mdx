适用：现代文档。

用连续内容流构建知识页面和协作简报。现代文档与传统文档共用段落、文字样式、表格、图片及内容块；形态专属能力包括标题折叠和分栏组。

先完成[安装](/guides/docs/getting-started/installation)，并[创建对应形态的文档](/guides/docs/getting-started/document-types#create-document)。下方代码依次操作该文档。

调用布局 API 前，先确认文档形态。

```typescript
const doc = univerAPI.getActiveDocument()
if (!doc?.isModern()) throw new Error('Create a Modern document first')
```

## 分栏组 [#column-groups]

先按[分栏组配置](/guides/docs/features/columns)注册插件与 Facade 入口，并配置该 Pro 功能的许可证。示例创建两个可编辑栏，再通过公开 API 填入内容。修改左栏后再获取右栏偏移量，因为文本编辑会改变位置。

```typescript
const group = doc.insertColumnGroup(2, { gap: 18, widthRatios: [1, 1] })
if (!group) throw new Error('Column group could not be inserted')

const [left, right] = group.getColumns()
const leftOffset = left.getInsertOffset()
if (leftOffset == null) throw new Error('Left column not found')
doc.insertText(leftOffset, 'Goals\rShip a focused pilot.')

const rightOffset = right.getInsertOffset()
if (rightOffset == null) throw new Error('Right column not found')
doc.insertText(rightOffset, 'Next steps\rReview the launch checklist.')

console.log(left.getText(), right.getText())
```

## 标题折叠 [#heading-collapse]

现代文档（`documentStyle.documentFlavor: DocumentFlavor.MODERN`）会在具有章节内容的一级至五级标题旁显示三角按钮。折叠后保留标题，隐藏其后直到下一个同级或更高级标题之前的内容，包括子标题、表格和图片。每个表格单元格和现代文档分栏都有独立的标题层级。

标题折叠不受 `toc` 控制。传统文档和嵌入式文本编辑器不显示折叠控件。展开父标题时，子标题会保留各自的折叠状态。

<HeadingCollapseDemo />

`IParagraph.headingCollapsed` 随 Univer 快照保存，仅 `true` 表示折叠。正文内容仍在快照中，折叠支持撤销、重做和协同，并与其他编辑者共享。隐藏内容中的选区会移到可见标题。该约定不保证 Office 导入导出保留折叠状态。

通过代码修改时，使用文档 ID 和快照中稳定的 `paragraphId` 执行已注册的命令。设为 `collapsed: false` 可展开。

```ts
import { SetHeadingCollapsedCommand } from '@univerjs/docs'

const heading = doc.findParagraphByText('Launch plan')
if (!heading) throw new Error('Heading not found')

const changed = await univerAPI.executeCommand(SetHeadingCollapsedCommand.id, {
  unitId: doc.getId(),
  paragraphId: heading.getId(),
  collapsed: true,
})
```

状态未变或目标无效时，命令返回 `false`，例如传统文档、被祖先标题隐藏的标题、折叠空章节或无编辑权限。详见[命令契约](/reference/packages/plugins/univerjs/docs#heading-collapse)。

## 共用内容块 [#shared-blocks]

表格、列表、代码块、引用块、标注块和[跨文档嵌入](/guides/docs/features/embed)属于共用内容能力，需要各自的功能插件。

## 打印与导出 [#output]

现代文档编辑时不显示物理分页；[打印模块](/guides/docs/features/print)会为连续内容生成输出分页。[导入导出](/guides/docs/features/import-export)仍需转换服务，导入选项可以指定目标文档形态。编辑布局和输出分页不能视为完全相同。
