La función de tabla mejorada proporciona capacidades avanzadas de edición de tablas para Univer Docs, incluido el estilo de celda, personalización de bordes, manipulación de filas y columnas y llenado de datos.

## Introducción

En Univer Docs, las tablas mejoradas le permiten:

- **Insertar tablas mediante programación**: crear tablas con dimensiones específicas.
- **Manipular la estructura**: agregar, eliminar y mover filas y columnas.
- **Estilizar celdas**: aplicar bordes, fondos y formato de texto.
- **Fusionar y dividir celdas**: combinar celdas para diseños complejos.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### Uso

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIEnUS from '@univerjs-pro/docs-table-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsTableUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

Si tiene una licencia comercial de Univer, consulte [Uso de la licencia en el cliente](/server/license#in-plugin-mode) para configuración.

## API de fachada

Asegúrese de importar la fachada antes de usar la API:

```typescript
import '@univerjs-pro/docs-table/facade'
```

### Insertar una tabla

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### Insertar una tabla a partir de datos

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### Obtener todas las tablas

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### Eliminar una tabla

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```

## Bordes de tabla [#table-borders]

Seleccione una tabla o sus celdas para abrir la pestaña contextual Tabla. El selector ofrece bordes completos, exteriores, interiores, individuales y sin bordes, además de color, grosor y estilo de línea. Estos controles los proporciona `UniverDocsTableUIPlugin`.

## Edición, historial y colaboración [#editing-history]

Los setters y cambios estructurales de tablas usan comandos con deshacer/rehacer y colaboración. `setTableStyle()` agrupa fondo y borde en una entrada del historial. `setColumnType()` también se deshace y sincroniza; los tipos acompañan a las columnas movidas. `setCellText()` sustituye el valor completo: las sustituciones simultáneas usan resolución atómica y las ediciones de caracteres usan OT de texto. Una edición rechazada por un control de contenido bloqueado devuelve `false` sin consumir el historial.

## Alinear toda la tabla [#table-alignment]

En documentos Traditional, seleccione una tabla y use su menú de alineación en el Ribbon para situarla a la izquierda, en el centro o a la derecha del área de contenido. Cambia la posición de la tabla, no la alineación del texto de las celdas. El control está deshabilitado en documentos Modern.

El valor se guarda en `tableSource[tableId].align` y admite deshacer, rehacer y guardar. Tras registrar el plugin de tablas, también puede ejecutar el comando público siguiente con un ID de tabla existente en el snapshot. Los destinos no válidos, documentos deshabilitados y documentos Modern devuelven `false`.

```ts
import { DocsTableSetTableAlignCommand } from '@univerjs-pro/docs-table'
import { TableAlignmentType } from '@univerjs/core'

const aligned = await univerAPI.executeCommand(DocsTableSetTableAlignCommand.id, {
  unitId: documentId,
  tableId,
  value: TableAlignmentType.CENTER,
})
```
