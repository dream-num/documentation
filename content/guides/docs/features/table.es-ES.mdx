Las tablas mejoradas proporcionan la edición completa de tablas en Univer Docs: estilo celular, fronteras, cambios de fila y columna, y llenando una tabla de datos.

## Introducción

En Univer Docs, las tablas soportan las siguientes operaciones:

- Cree una tabla con las dimensiones que especifique.
- Añadir, eliminar y mover filas y columnas.
- Aplicar las fronteras, los antecedentes y el formato de texto a las células.
- Combinar y dividir celdas para construir diseños complejos.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### Uso

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIEnUS from '@univerjs-pro/docs-table-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsTableUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

Si utiliza una licencia comercial, configure como se describe en [Utilizando Licencia en Cliente](/server/license#in-plugin-mode).

## API de fachada

Importar la fachada antes de utilizar cualquiera de las siguientes API:

```typescript
import '@univerjs-pro/docs-table/facade'
```

### Insertar una tabla

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### Insertar una tabla a partir de datos

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### Obtener todas las tablas

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### Eliminar una tabla

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```

## Bordes de tabla [#table-borders]

Seleccione una tabla o sus celdas para abrir la pestaña de Tabla contextual. El selector de bordes proporciona presets para todos, exteriores, interiores, individuales-edge, y sin fronteras, junto con controles para el color, ancho y estilo de línea. `UniverDocsTableUIPlugin` suministra estos controles.

## Edición, historial y colaboración [#editing-history]

Setters Table Facade y ediciones estructurales se aplican a través de comandos de documentos, por lo que participan en deshacer/redo y colaboración. `setTableStyle()` combina los cambios de fondo y de frontera en una entrada de historia. `setColumnType()` es también indomable y sincronizado, y los tipos de columnas siguen sus columnas cuando las columnas se mueven. `setCellText()` reemplaza todo el valor celular: los reemplazos concurrentes resuelven como valores atómicos, mientras que las ediciones de caracteres ordinarios usan texto OT. Si un control de contenido bloqueado rechaza una edición de celda, la llamada devuelve `false` y no consume historia de deshacer/redo.

## Alinear toda la tabla [#table-alignment]

En un documento tradicional, seleccione una tabla y utilice **Cuadro → Alineación de la tabla** en la cinta para colocar la tabla a la izquierda, centro o derecha del área de contenido de la página. Este ajuste mueve la tabla en sí y no cambia la alineación de texto dentro de las células. El control está deshabilitado en documentos modernos.

El valor se almacena en `tableSource[tableId].align` y soporta el deshacer/redo y el ahorro. Después del plugin de la tabla está registrado, la misma acción está disponible a través del comando público a continuación. Pase un ID de tabla existente de la instantánea del documento. Objetivos inválidos, documentos discapacitados, y documentos modernos devuelve `false`.

```ts
import { DocsTableSetTableAlignCommand } from '@univerjs-pro/docs-table'
import { TableAlignmentType } from '@univerjs/core'

const aligned = await univerAPI.executeCommand(DocsTableSetTableAlignCommand.id, {
  unitId: documentId,
  tableId,
  value: TableAlignmentType.CENTER,
})
```
