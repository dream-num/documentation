內容控制元件（SDT）支援富文字、純文字、核取方塊、日期、列表、圖片、分組、重複節和文件部件。建立文件前，先註冊 Docs 核心外掛和 Pro 許可證外掛，再註冊下列兩個包。將 UI 語言套件合併到 `locales` 並載入樣式表。Docs 高階預設不包含這兩個包。

```package-install
npm install @univerjs-pro/docs-sdt @univerjs-pro/docs-sdt-ui
```

```ts
import { UniverDocsSdtPlugin } from '@univerjs-pro/docs-sdt'
import { UniverDocsSdtUIPlugin } from '@univerjs-pro/docs-sdt-ui'
import FeatureLocale from '@univerjs-pro/docs-sdt-ui/locale/zh-TW'
import { LocaleType } from '@univerjs/core'

import '@univerjs-pro/docs-sdt-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.ZH_TW, FeatureLocale)

univer.registerPlugin(UniverDocsSdtPlugin)
univer.registerPlugin(UniverDocsSdtUIPlugin)
```

## 在選取範圍插入 [#insert]

命令作用於當前文字選區。在控制元件型別支援的情況下，已選中的內容會被包裹進新控制元件。重複節的專案透過父級重複節建立，不能單獨插入。

```ts
import { InsertSdtCommand } from '@univerjs-pro/docs-sdt-ui'

await univerAPI.executeCommand(InsertSdtCommand.id, { kind: 'checkbox' })
```

## 鎖定與持久化 [#locks-and-persistence]

控制元件以 `CustomRangeType.SDT` 範圍儲存在 `IDocumentBody.customRanges` 中，後設資料儲存在 `ISdtCustomRange.properties` 中。內容鎖阻止修改值，控制元件鎖阻止刪除外層控制元件；重複節還可以禁止插入和刪除專案。值、屬性和重複項均需透過命令修改，以保證撤銷/重做一致。

完整介面見[模型命令](/reference/packages/plugins/univerjs-pro/docs-sdt)和 [UI API](/reference/packages/plugins/univerjs-pro/docs-sdt-ui)。DOCX 轉換由 [Exchange](/guides/docs/features/import-export) 完成；編輯器支援並不表示每個 Word 屬性和自定義 XML 繫結都能無損轉換。
