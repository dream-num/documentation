A callout separates a piece of information from the surrounding text. The icon and the colors are configurable, so a note, a warning, and a tip can each have a distinct appearance.

## Introduction

In Univer Docs, callout blocks serve three purposes:

- They draw attention to a note, a warning, or a tip.
- They apply the icon and colors selected for the block, so its appearance matches the content.
- They divide a document into sections that are visually separate and read independently.

## Plugin mode

### Installation

```package-install
npm install @univerjs-pro/docs-callout @univerjs-pro/docs-callout-ui
```

### Usage

```typescript
import { UniverDocsCalloutPlugin } from '@univerjs-pro/docs-callout' // [!code ++]
import { UniverDocsCalloutUIPlugin } from '@univerjs-pro/docs-callout-ui' // [!code ++]
import DocsCalloutUIEnUS from '@univerjs-pro/docs-callout-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-callout-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCalloutUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCalloutPlugin) // [!code ++]
univer.registerPlugin(UniverDocsCalloutUIPlugin) // [!code ++]
```

If your application uses Univer under a commercial license, configure it as described in [Using License in Client](/server/license#in-plugin-mode).

## Facade API

Import the facade before calling the API:

```typescript
import '@univerjs-pro/docs-callout/facade'
```

### Get all callouts

```typescript
const doc = univerAPI.getActiveDocument()
const callouts = doc?.getCallouts() ?? []
```

### Get a callout by ID

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.getCallout('callout-block-id')
```

### Insert a callout

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.insertCallout({
  startOffset: 12,
  endOffset: 35,
  config: { icon: '💡' },
})
```

### Update callout config

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.updateConfig({ icon: '⚠️' })
```

### Set callout appearance

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.setIcon('📝')
callout?.setBackgroundColor('#FFF4E5')
callout?.setBorder({ color: '#E6A23C', width: 2 })
callout?.setTextColor('#5C3B00')
```

Appearance changes are applied through document commands, so undo, redo, and collaboration receive them. `setTextColor()` applies a color to all text in the callout; call `resetTextColor()` to remove that override and restore the text colors inherited from the document.

```ts
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.resetTextColor()
```
