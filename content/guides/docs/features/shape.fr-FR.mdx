La fonction forme insère et édite des dessins dans un document, des formes géométriques de base et des flèches aux éléments du diagramme de flux.

## Introduction

Dans Univer Docs, les formes supportent les opérations suivantes :

- Ajouter les rectangles, les cercles, les flèches et autres formes simples.
- Réglez la couleur de remplissage, les bordures et le texte.
- Placez une forme n'importe où dans le document.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/engine-formula @univerjs-pro/docs-shape @univerjs-pro/docs-shape-ui
```

<Callout type="warn">
  Les formes nécessitent également `UniverProFormulaEnginePlugin` de `@univerjs-pro/engine-formula`. Dans la configuration de base, remplacez l'importation et l'enregistrement `UniverFormulaEnginePlugin` existant avec ce plugin. Ne pas enregistrer les deux moteurs de formule, car cela peut faire échouer l'insertion de la forme avec une erreur de dépendance manquante.
</Callout>

### Utilisation

```typescript
import { UniverDocsShapePlugin } from '@univerjs-pro/docs-shape' // [!code ++]
import { UniverDocsShapeUIPlugin } from '@univerjs-pro/docs-shape-ui' // [!code ++]
import DocsShapeUIEnUS from '@univerjs-pro/docs-shape-ui/locale/en-US' // [!code ++]
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-shape-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsShapeUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverProFormulaEnginePlugin) // [!code ++]
univer.registerPlugin(UniverDocsShapePlugin) // [!code ++]
univer.registerPlugin(UniverDocsShapeUIPlugin) // [!code ++]
```

Si vous utilisez une licence commerciale, configurez-la comme décrit dans [Utilisation de la licence dans le client](/server/license#in-plugin-mode).

## Modifier le texte d’une forme

Fonctionnez avec l'objet de forme retourné par `insertShape()`, soit dans l'exemple ci-dessous, soit dans le précédent exemple. `getText()` retourne une poignée en direct [Texte en forme de texte](/reference/facade/shape-text). Lisez le texte simple avec `getPlainText()`, remplacez-le par `setText()` et appliquez le formatage à travers la police, la couleur et les méthodes d'alignement.

```ts
import '@univerjs-pro/docs-shape/facade'

const document = univerAPI.getActiveDocument()
const paragraph = document?.getParagraphs()[0]
if (!document || !paragraph) throw new Error('No active document paragraph')
const shape = document.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.Rect,
  placement: {
    wrappingStyle: univerAPI.Enum.TextWrappingStyle.INLINE,
    anchor: { paragraphId: paragraph.getId(), segmentId: paragraph.getSegmentId() },
  },
})
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()` remplace le texte existant. Utilisez `setRichText()` quand une forme nécessite plusieurs styles. Pour modifier le texte riche existant, appelez `getRichText()?.copy()`, modifiez le constructeur et passez-le à `setRichText()`; les modifications à ce constructeur détaché ne s'appliquent pas par eux-mêmes. D'autres options sont disponibles dans [Style de texte](/reference/facade/shape-text#settextstyle) et [Rembourrage et mise en page de la boîte de texte](/reference/facade/shape-text#settextboxoptions).

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## Reproduire la mise en forme des formes [#format-painter]

Sélectionnez une forme source, allumez le formateur, puis sélectionnez la forme cible. Le peintre copie le remplissage, le trait, les effets et le formatage de texte supporté, et laisse l'identité de la cible, la géométrie, le contenu texte et les liaisons de formule inchangés. La suppression du formatage restaure les valeurs par défaut utilisées lors de l'insertion. SmartArt est exclu.
