フットノートとエンドノートは、伝統的な、開花した文書に適用されます。 フットノートは、それを参照するページ上にレイアウトされます。 エンドノートは文書の最終設定に従って配置されます。 このAPIは、現代の文書をサポートしていません。

## プラグインモード [#plugin-mode]

### インストール

```package-install
npm install @univerjs-pro/docs-reference @univerjs-pro/docs-reference-ui
```

### 使い方

これらのプラグインを Docs エディタに 設定されたライセンスを追加し、UI スタイルとエディタにマッチする locale を読み込みます。

```ts
import { UniverDocsReferencePlugin } from '@univerjs-pro/docs-reference'
import { UniverDocsReferenceUIPlugin } from '@univerjs-pro/docs-reference-ui'
import ReferenceLocale from '@univerjs-pro/docs-reference-ui/locale/ja-JP'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/docs-reference/facade'
import '@univerjs-pro/docs-reference-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.JA_JP, ReferenceLocale)
univer.registerPlugin(UniverDocsReferencePlugin)
univer.registerPlugin(UniverDocsReferenceUIPlugin)
```

## プリセットモード [#preset-mode]

### インストール

```package-install
npm install @univerjs/presets @univerjs/preset-docs-core @univerjs/preset-docs-drawing @univerjs/preset-docs-advanced
```

### 使い方

`UniverDocsAdvancedPreset`は、プラグインを既に含んでいます。このプリセットを使用する場合は、登録を続け、プラグインを再度追加しないでください。

コア、図面、および高度なプリセットを組み合わせて、ローカルリソースをマージします。クライアントライセンスは、[ライセンスの使用](/server/license#in-preset-mode)で記述されているように構成されます。

```ts
import { UniverDocsAdvancedPreset } from '@univerjs/preset-docs-advanced'
import AdvancedLocale from '@univerjs/preset-docs-advanced/locales/ja-JP'
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import CoreLocale from '@univerjs/preset-docs-core/locales/ja-JP'
import { UniverDocsDrawingPreset } from '@univerjs/preset-docs-drawing'
import DrawingLocale from '@univerjs/preset-docs-drawing/locales/ja-JP'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-drawing/lib/index.css'
import '@univerjs/preset-docs-advanced/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(CoreLocale, DrawingLocale, AdvancedLocale),
  },
  presets: [
    UniverDocsCorePreset({ container: 'app' }),
    UniverDocsDrawingPreset(),
    UniverDocsAdvancedPreset(),
  ],
})
```

### プリセット設定 [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | エディターのマウント先となる DOM 要素、またはその ID。 |

## 脚注の挿入と管理

```ts
const document = univerAPI.getActiveDocument()
if (document) {
  const noteId = document.insertFootnote(0)
  if (noteId) console.log(document.getParagraphs(noteId))
  console.log(document.getFootnotes(), document.getEndnotes())
}
```

オフセットは、本体のUTF-16位置であり、構造トークンをカウントします。 Insertionは、位置が無効なときに`null`を返します。ノートコンテンツが無効な場合、発信者は許可を欠いているか、文書は近代的です。それ以外の場合は、安定したノートIDを返します。参照とノートコンテンツは同じundoステップと同じコラボレーションミューテーションに属しています。

メモを読む `getFootnotes()` / `getEndnotes()` そしてそれらを取除いて下さい `deleteFootnote(noteId)` / `deleteEndnote(noteId)`. `setFootnoteSettings()` そして、 `setEndnoteSettings()` 制御番号および配置、および渡ること `null` 任意の明示的な設定をクリアします。表示された数字は、ページネーション後に変更できるため、コンテンツのアドレスに返されたメモIDを保持します。
