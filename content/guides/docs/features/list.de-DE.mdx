Die erweiterte Listenfunktion bietet erweiterte Listenfunktionen für Univer Docs, einschließlich verschachtelter Listen, benutzerdefinierter Glyphen und flexibler Listen Manipulation.

## Einführung

In Univer Docs ermöglichen Ihnen erweiterte Listen Folgendes:

- **Verschachtelte Listen erstellen**: Listenhierarchien auf mehreren Ebenen erstellen.
- **Glyphen anpassen**: Verschiedene Aufzählungszeichen und Nummerierungsstile verwenden.
- **Listenstruktur manipulieren**: Listenelemente heraufstufen, herabstufen und neu anordnen.

## Plugin Modus

### Installation

```package-install
npm install @univerjs-pro/docs-list @univerjs-pro/docs-list-ui
```

### Nutzung

```typescript
import { UniverDocsListPlugin } from '@univerjs-pro/docs-list' // [!code ++]
import { UniverDocsListUIPlugin } from '@univerjs-pro/docs-list-ui' // [!code ++]
import DocsListUIEnUS from '@univerjs-pro/docs-list-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-list-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsListUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsListPlugin) // [!code ++]
univer.registerPlugin(UniverDocsListUIPlugin) // [!code ++]
```

Wenn Sie eine kommerzielle Lizenz für Univer haben, lesen Sie bitte die Konfiguration unter [Lizenz im Client verwenden](/guides/pro/license#in-plugin-mode).

## Fassaden-API

Stellen Sie sicher, dass Sie die Fassade importieren, bevor Sie die API verwenden:

```typescript
import '@univerjs-pro/docs-list/facade'
```

### Eine Liste einfügen

```typescript
import { PresetListType } from '@univerjs/core'

const doc = univerAPI.getActiveDocument()
doc?.insertList({
  startOffset: 0,
  endOffset: 10,
  listType: PresetListType.BULLET_LIST,
})
```

### Alle Listen abrufen

```typescript
const doc = univerAPI.getActiveDocument()
const lists = doc?.getLists() ?? []
```

### Glyphentyp der Liste festlegen

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListGlyphType(0, ListGlyphType.DECIMAL)
```

### Listenebene festlegen

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListLevel(0, 1)
```
