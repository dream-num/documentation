Функция расширенных списков предоставляет дополнительные возможности для работы со списками в Univer Docs: вложенные списки, настраиваемые маркеры и гибкое изменение структуры.

## Введение

Расширенные списки в Univer Docs позволяют:

- **Создавать вложенные списки**: формировать многоуровневую иерархию списков.
- **Настраивать маркеры**: использовать разные символы и стили нумерации.
- **Изменять структуру списка**: повышать и понижать уровень элементов, а также менять их порядок.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/docs-list @univerjs-pro/docs-list-ui
```

### Использование

```typescript
import { UniverDocsListPlugin } from '@univerjs-pro/docs-list' // [!code ++]
import { UniverDocsListUIPlugin } from '@univerjs-pro/docs-list-ui' // [!code ++]
import DocsListUIEnUS from '@univerjs-pro/docs-list-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-list-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsListUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsListPlugin) // [!code ++]
univer.registerPlugin(UniverDocsListUIPlugin) // [!code ++]
```

Если у вас есть коммерческая лицензия Univer, сведения о настройке см. в разделе [«Использование лицензии в клиенте»](/guides/pro/license#in-plugin-mode).

## Facade API

Перед использованием API обязательно импортируйте facade:

```typescript
import '@univerjs-pro/docs-list/facade'
```

### Вставка списка

```typescript
import { PresetListType } from '@univerjs/core'

const doc = univerAPI.getActiveDocument()
doc?.insertList({
  startOffset: 0,
  endOffset: 10,
  listType: PresetListType.BULLET_LIST,
})
```

### Получение всех списков

```typescript
const doc = univerAPI.getActiveDocument()
const lists = doc?.getLists() ?? []
```

### Настройка типа маркера списка

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListGlyphType(0, ListGlyphType.DECIMAL)
```

### Настройка уровня списка

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListLevel(0, 1)
```
