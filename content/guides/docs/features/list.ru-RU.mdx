Расширенные списки расширяют Univer Docs с вложенными уровнями, пользовательскими глифами и редактированием структуры списков.

## Введение

В Univer Docs расширенные списки предоставляют следующие возможности:

- Множественные уровни гнездования.
- Выбор символов пули и стилей нумерации.
- Продвигать, удалять и переупорядочивать операции по спискам.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/docs-list @univerjs-pro/docs-list-ui
```

### Использование

```typescript
import { UniverDocsListPlugin } from '@univerjs-pro/docs-list' // [!code ++]
import { UniverDocsListUIPlugin } from '@univerjs-pro/docs-list-ui' // [!code ++]
import DocsListUIEnUS from '@univerjs-pro/docs-list-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-list-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsListUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsListPlugin) // [!code ++]
univer.registerPlugin(UniverDocsListUIPlugin) // [!code ++]
```

Если вы используете коммерческую лицензию, настройте ее, как описано в [Использование лицензии у клиента](/server/license#in-plugin-mode).

## Поддержка мобильных устройств [#mobile-support]

Сначала настройте [Мобильный редактор](/guides/docs/getting-started/installation#mobile-support). В настройках плагин-режима, описанных на этой странице, замените регистрацию рабочего стола, показанную ниже, на мобильный экспорт из того же пакета и заполните замену **Перед тем, как открыть документ**, сохраните плагины модели, стили, локализации и импорт Facade и не регистрируйте оба варианта.

## Facade API

Импорт фасада перед вызовом любого из следующих API:

```typescript
import '@univerjs-pro/docs-list/facade'
```

### Вставка списка

```typescript
import { PresetListType } from '@univerjs/core'

const doc = univerAPI.getActiveDocument()
doc?.insertList({
  startOffset: 0,
  endOffset: 10,
  listType: PresetListType.BULLET_LIST,
})
```

### Получение всех списков

```typescript
const doc = univerAPI.getActiveDocument()
const lists = doc?.getLists() ?? []
```

### Настройка типа маркера списка

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListGlyphType(0, ListGlyphType.DECIMAL)
```

### Настройка уровня списка

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setListLevel(0, 1)
```
