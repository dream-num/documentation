Erwähnungen ermöglichen es Benutzern, `@` in Univer Docs einzugeben und eine Erwähnungseinheit wie eine Person, ein Team, ein Ticket oder ein anderes Objekt aus Ihrer Anwendung einzufügen. Die eingefügte Erwähnung wird als benutzerdefinierter `CustomRangeType.MENTION`-Bereich im Dokumenttext gespeichert.

## Interaktionen

- Geben Sie `@` in das Dokument ein, um das Erwähnungs-Popup zu öffnen.
- Fahren Sie mit der Eingabe fort, um einen `search`-Wert an die Erwähnungsdatenquelle zu übergeben.
- Wählen Sie einen Kandidaten aus, um den eingegebenen Triggertext durch eine Entität wie zu ersetzen `@Alice`.
- Bewegen Sie den Cursor oder löschen Sie vor dem Auslöser, um das Popup zu schließen.

## Plugin-Modus

### Installation

```package-install
npm install @univerjs/docs-mention-ui
```

### Verwendung

```typescript
import { UniverDocsMentionUIPlugin } from '@univerjs/docs-mention-ui' // [!code ++]

import '@univerjs/docs-mention-ui/lib/index.css' // [!code ++]

univer.registerPlugin(UniverDocsMentionUIPlugin) // [!code ++]
```

## Erwähnungskandidaten bereitstellen

Das Erwähnungs-Popup liest Kandidaten von `IMentionIOService`. Univer stellt eine lokale Standardimplementierung bereit, die den aktuellen Benutzer zurückgibt. Produktionsanwendungen ersetzen ihn normalerweise durch eine Implementierung, die durch ein Benutzerverzeichnis, einen Teamdienst, einen Issue-Tracker oder eine andere Geschäftsdatenquelle unterstützt wird.

```typescript
import type { IListMentionParam, IListMentionResponse, IMentionIOService } from '@univerjs/core'
import { MentionType } from '@univerjs/core'

class DirectoryMentionIOService implements IMentionIOService {
  async list(params: IListMentionParam): Promise<IListMentionResponse> {
    const users = await searchUsers(params.search ?? '')

    return {
      list: [{
        type: MentionType.PERSON,
        title: 'People',
        metadata: {},
        mentions: users.map(user => ({
          objectType: MentionType.PERSON,
          objectId: user.id,
          label: user.name,
          metadata: {
            icon: user.avatarUrl,
            email: user.email,
          },
        })),
      }],
      page: params.page,
      size: params.size,
      total: users.length,
    }
  }
}
```

Registrieren Sie den Dienst über die Abhängigkeitsüberschreibung von Univer beim Erstellen der Anwendung.

```typescript
import { IMentionIOService, LocaleType, Univer } from '@univerjs/core'

const univer = new Univer({
  locale: LocaleType.EN_US,
  override: [
    [IMentionIOService, { useClass: DirectoryMentionIOService }],
  ],
})
```

## Datenmodell

Wenn eine Erwähnung eingefügt wird, wird der sichtbare Text in `body.dataStream` geschrieben und die Entitätsmetadaten bleiben darin erhalten `body.customRanges`.

```typescript
const documentData = {
  body: {
    dataStream: 'Hello @Alice\\r\\n',
    customRanges: [{
      startIndex: 6,
      endIndex: 11,
      rangeId: 'mention-1',
      rangeType: CustomRangeType.MENTION,
      wholeEntity: true,
      properties: {
        id: 'mention-1',
        label: 'Alice',
        type: 'user',
        email: 'alice@example.com',
      },
    }],
  },
}
```

<Callout type="info">
Erwähnungen sind benutzerdefinierte Dokumentbereiche. Wenn Ihre Anwendung zusätzliche Felder in `metadata` speichert, halten Sie sie serialisierbar, damit der Dokument-Snapshot beibehalten und sicher wiederhergestellt werden kann.
</Callout>
