增强表格为 Univer Docs 提供了完整的表格编辑能力，包括单元格样式、边框、行列操作和数据填充。

## 介绍

在 Univer Docs 中，表格支持以下操作：

- 按指定的行列数创建表格；
- 添加、删除和移动行列；
- 为单元格设置边框、背景和文字格式；
- 合并和拆分单元格，以构建复杂布局。

## 插件模式

### 安装

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### 使用

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIZhCN from '@univerjs-pro/docs-table-ui/locale/zh-CN' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_CN,
  locales: {
    [LocaleType.ZH_CN]: mergeLocales(
      DocsTableUIZhCN, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

使用 Univer 商业许可证时，配置方式参见[在客户端使用许可证](/server/license#in-plugin-mode)。

## 移动端适配 [#mobile-support]

请先完成[移动端编辑器](/guides/docs/getting-started/installation#mobile-support)的配置。在本页插件模式的初始化代码中，将下表中的桌面端注册替换为同一个包导出的移动端插件，并且必须在**打开文档前**完成替换。模型插件、样式、语言包和 Facade 导入均需保留，两个版本不要同时注册。

| 来源包 | 桌面端注册 | 移动端注册 |
| --- | --- | --- |
| `@univerjs-pro/docs-table-ui` | `UniverDocsTableUIPlugin` | `UniverDocsTableMobileUIPlugin` |

## Facade API

调用下列 API 之前，需要先导入 facade：

```typescript
import '@univerjs-pro/docs-table/facade'
```

### 插入表格

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### 从数据插入表格

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### 获取所有表格

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### 删除表格

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```

## 表格边框 [#table-borders]

选中表格或其中的单元格，即可打开表格上下文选项卡。边框选择器提供全部、外侧、内部、单侧和无边框几种预设，并提供颜色、粗细和线型的控件。这些控件由 `UniverDocsTableUIPlugin` 提供。

## 编辑、撤销与协同 [#editing-history]

表格 Facade 的设置方法和结构编辑都通过文档命令执行，因此会参与撤销、重做和协同。`setTableStyle()` 将背景和边框的修改合并为一条历史记录。`setColumnType()` 同样可撤销、可同步，列类型会随列一起移动。`setCellText()` 替换整个单元格值：并发替换按原子值冲突处理，普通逐字编辑仍使用文本 OT。被锁定内容控件拒绝的单元格编辑返回 `false`，且不消耗撤销/重做历史。

## 表格整体对齐 [#table-alignment]

在传统文档中选中表格，然后使用 Ribbon 上的“表格 → 表格对齐”，将整个表格在页面正文区域内左对齐、居中或右对齐。该设置调整的是表格本身的位置，不会改变单元格内文字的对齐方式。现代文档中此控件不可用。

对齐值保存在 `tableSource[tableId].align` 中，支持撤销、重做和保存。注册表格插件后，也可以通过下面的公开命令执行同样的操作，`tableId` 取自文档快照中已有的表格 ID。目标无效、文档被禁用或属于现代文档时，命令返回 `false`。

```ts
import { DocsTableSetTableAlignCommand } from '@univerjs-pro/docs-table'
import { TableAlignmentType } from '@univerjs/core'

const aligned = await univerAPI.executeCommand(DocsTableSetTableAlignCommand.id, {
  unitId: documentId,
  tableId,
  value: TableAlignmentType.CENTER,
})
```
