Die erweiterte Tabellenfunktion bietet umfassende Tabellenbearbeitungsfunktionen für Univer Docs, einschließlich Zellenstil, Rahmenanpassung, Zeilen- und Spaltenmanipulation und Daten Population.

## Einführung

In Univer Docs ermöglichen Ihnen erweiterte Tabellen Folgendes:

- **Tabellen programmgesteuert einfügen**: Tabellen mit angegebenen Abmessungen erstellen.
- **Struktur manipulieren**: Zeilen und Spalten hinzufügen, löschen und verschieben.
- **Zellen formatieren**: Rahmen, Hintergründe und Textformatierung anwenden.
- **Zellen zusammenführen und teilen**: Zellen für komplexe Layouts kombinieren.

## Plugin-Modus

### Installation

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### Nutzung

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIEnUS from '@univerjs-pro/docs-table-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsTableUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

Wenn Sie eine kommerzielle Lizenz für Univer haben, finden Sie Informationen zur Konfiguration unter [Lizenz im Client verwenden](/guides/pro/license#in-plugin-mode).

## Fassaden-API

Stellen Sie sicher, dass Sie die Fassade importieren, bevor Sie die API verwenden:

```typescript
import '@univerjs-pro/docs-table/facade'
```

### Eine Tabelle einfügen

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### Eine Tabelle aus Daten einfügen

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### Alle Tabellen abrufen

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### Eine Tabelle löschen

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```
