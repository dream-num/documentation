Управление контентом (SDT) поддерживает богатый текст, простой текст, флажки, даты, списки, изображения, группы, повторяющиеся разделы и части документов. Перед созданием документа регистрируйте плагины ядра Docs и лицензии Pro, затем регистрируйте два пакета ниже. Слить локализацию пользовательского интерфейса в `locales` и загрузить таблицу стилей. Расширенный предустановленный набор Docs не включает эти пакеты.

```package-install
npm install @univerjs-pro/docs-sdt @univerjs-pro/docs-sdt-ui
```

```ts
import { UniverDocsSdtPlugin } from '@univerjs-pro/docs-sdt'
import { UniverDocsSdtUIPlugin } from '@univerjs-pro/docs-sdt-ui'
import FeatureLocale from '@univerjs-pro/docs-sdt-ui/locale/ru-RU'
import { LocaleType } from '@univerjs/core'

import '@univerjs-pro/docs-sdt-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.RU_RU, FeatureLocale)

univer.registerPlugin(UniverDocsSdtPlugin)
univer.registerPlugin(UniverDocsSdtUIPlugin)
```

## Вставка в выделение [#insert]

Команда относится к активному выбору текста. Когда тип управления поддерживает его, текущий выбор обернут в новый контроль. Повторяющиеся элементы создаются через их родительский раздел.

```ts
import { InsertSdtCommand } from '@univerjs-pro/docs-sdt-ui'

await univerAPI.executeCommand(InsertSdtCommand.id, { kind: 'checkbox' })
```

## Блокировки и сохранение [#locks-and-persistence]

Управляющие хранятся в `IDocumentBody.customRanges` в диапазоне `CustomRangeType.SDT`, а их метаданные хранятся в `ISdtCustomRange.properties`. Замок содержимого предотвращает редактирование значений, а блокировка управления предотвращает удаление обертки. Повторяющийся раздел также может запретить вставку и удаление элементов. Измените значения, свойства и повторение элементов с помощью команд, чтобы отменить и переделать оставаться согласованным.
