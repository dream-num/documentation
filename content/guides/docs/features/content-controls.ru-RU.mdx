Элементы SDT поддерживают форматированный и обычный текст, флажки, даты, списки, изображения, группы, повторяющиеся разделы и блоки документа. Настройте Docs Core и лицензию Pro, затем зарегистрируйте плагины до создания документа. Добавьте локаль UI в `locales` и подключите CSS. Docs Advanced их не включает.

```package-install
npm install @univerjs-pro/docs-sdt @univerjs-pro/docs-sdt-ui
```

```ts
import { UniverDocsSdtPlugin } from '@univerjs-pro/docs-sdt'
import { UniverDocsSdtUIPlugin } from '@univerjs-pro/docs-sdt-ui'
import FeatureLocale from '@univerjs-pro/docs-sdt-ui/locale/ru-RU'
import { LocaleType } from '@univerjs/core'

import '@univerjs-pro/docs-sdt-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.RU_RU, FeatureLocale)

univer.registerPlugin(UniverDocsSdtPlugin)
univer.registerPlugin(UniverDocsSdtUIPlugin)
```

## Вставка в выделение [#insert]

Команда использует текущее текстовое выделение и оборачивает его содержимое, если тип элемента это допускает. Повторяющиеся элементы создаются через родительский раздел.

```ts
import { InsertSdtCommand } from '@univerjs-pro/docs-sdt-ui'

await univerAPI.executeCommand(InsertSdtCommand.id, { kind: 'checkbox' })
```

## Блокировки и сохранение [#locks-and-persistence]

Элементы хранятся как диапазоны `CustomRangeType.SDT` в `IDocumentBody.customRanges`, метаданные — в `ISdtCustomRange.properties`. Блокировка содержимого запрещает изменение значений, блокировка элемента — удаление оболочки. Раздел может запрещать добавление и удаление повторов. Для поддержки отмены и повтора изменяйте данные через команды.

См. [команды](/reference/packages/plugins/univerjs-pro/docs-sdt) и [UI API](/reference/packages/plugins/univerjs-pro/docs-sdt-ui). Преобразованием DOCX занимается [Exchange](/guides/docs/features/import-export); поддержка редактора не гарантирует сохранность всех свойств Word и привязок XML.
