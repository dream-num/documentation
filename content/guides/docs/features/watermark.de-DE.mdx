Die Wasserzeichenfunktion zielt darauf ab, eine flexible und sichere Wasserzeichenlösung für Webseiten oder Anwendungen bereitzustellen. Mit dieser Funktion können Entwickler dynamisch Text- oder Bildwasserzeichen auf der Seite generieren, um die unbefugte Nutzung oder Verbreitung von Inhalten zu verhindern, und sie unterstützt verschiedene Konfigurationen.

<PlaygroundFrame lang="en-US" slug="docs/watermark" clickToShow />

## Voreinstellungsmodus

Wasserzeichen bietet keine Voreinstellung, unterstützt aber das Mischen mit seinen Plugins.

### Installation

```package-install
npm install @univerjs/watermark
```

### Verwendung

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const { univerAPI } = createUniver({
  // ...
  presets: [
    UniverDocsCorePreset(),
  ],
  plugins: [
    [UniverWatermarkPlugin, { // [!code ++]
      textWatermarkSettings: { // [!code ++]
        content: 'Hello, Univer!', // [!code ++]
        fontSize: 36, // [!code ++]
      }, // [!code ++]
    }], // [!code ++]
  ],
})
```

## Plugin-Modus

### Installation

```package-install
npm install @univerjs/watermark
```

### Verwendung

```typescript
import { UniverWatermarkPlugin } from '@univerjs/watermark' // [!code ++]

import '@univerjs/watermark/facade' // [!code ++]

const univer = new Univer({
  // ...
})

univer.registerPlugin(UniverWatermarkPlugin, { // [!code ++]
  textWatermarkSettings: { // [!code ++]
    content: 'Hello, Univer!', // [!code ++]
    fontSize: 36, // [!code ++]
  }, // [!code ++]
}) // [!code ++]
```

### Plugins und Konfiguration

#### @univerjs/watermark

Dieses Plugin stellt die Kernimplementierung der Wasserzeichenfunktionalität bereit. Es ermöglicht Entwicklern das Hinzufügen von Text- oder Bildwasserzeichen zu Anwendungen und bietet verschiedene Konfigurationsoptionen, um das Erscheinungsbild und Verhalten des Wasserzeichens anzupassen. Es stellt das Plugin `UniverWatermarkPlugin` bereit.

Referenz: [@univerjs/watermark](https://docs.univer.ai/reference/packages/plugins/univerjs/watermark)

## Facade-API

### Importieren

<Callout type="info" title="Plugin mode note">
Nur im Plugin-Modus muss das Facade-Paket manuell importiert werden. Der Voreinstellungsmodus enthält bereits das entsprechende Facade-Paket, sodass kein zusätzlicher Import erforderlich ist.
</Callout>

```typescript
import '@univerjs/watermark/facade'
```

### Wasserzeichen setzen

```typescript
univerAPI.addWatermark('text', { content: 'hello', repeat: true })
```

### Wasserzeichen entfernen

```typescript
univerAPI.deleteWatermark()
```
