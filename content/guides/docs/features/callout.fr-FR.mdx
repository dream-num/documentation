La fonctionnalité d’encadré permet de mettre en valeur les informations importantes d’un document dans des blocs visuellement distincts, avec des icônes et des couleurs personnalisables.

## Introduction

Dans Univer Docs, les encadrés permettent de :

- **Mettre en valeur les informations clés** : attirer l’attention sur des remarques, des avertissements ou des conseils importants.
- **Personnaliser l’apparence** : choisir parmi différentes icônes et palettes de couleurs en fonction du contenu.
- **Organiser le contenu** : structurer le document à l’aide de sections visuellement séparées.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/docs-callout @univerjs-pro/docs-callout-ui
```

### Utilisation

```typescript
import { UniverDocsCalloutPlugin } from '@univerjs-pro/docs-callout' // [!code ++]
import { UniverDocsCalloutUIPlugin } from '@univerjs-pro/docs-callout-ui' // [!code ++]
import DocsCalloutUIEnUS from '@univerjs-pro/docs-callout-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-callout-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCalloutUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCalloutPlugin) // [!code ++]
univer.registerPlugin(UniverDocsCalloutUIPlugin) // [!code ++]
```

Si vous disposez d’une licence commerciale Univer, consultez la page [Utiliser une licence côté client](/guides/pro/license#in-plugin-mode) pour savoir comment la configurer.

## API Facade

Veillez à importer la façade avant d’utiliser l’API :

```typescript
import '@univerjs-pro/docs-callout/facade'
```

### Obtenir tous les encadrés

```typescript
const doc = univerAPI.getActiveDocument()
const callouts = doc?.getCallouts() ?? []
```

### Obtenir un encadré par son ID

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.getCallout('callout-block-id')
```

### Insérer un encadré

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.insertCallout({
  startOffset: 12,
  endOffset: 35,
  config: { icon: '💡' },
})
```

### Mettre à jour la configuration d’un encadré

```typescript
const doc = univerAPI.getActiveDocument()
doc?.updateCallout('callout-block-id', { icon: '⚠️' })
```

### Définir l’icône d’un encadré

```typescript
const doc = univerAPI.getActiveDocument()
doc?.setCalloutIcon('callout-block-id', '📝')
```
