찾기 및 바꾸기는 표를 포함한 현재 문서 본문에서 일반 텍스트를 검색합니다. 대/소문자 구분, 단어 단위 일치, 일치 항목 이동, 현재 또는 모든 일치 항목 바꾸기를 지원합니다.

<Callout type="info">
  머리글, 바닥글, 댓글, 그리기, 정규식, 서식 검색 및 특수 문자는 지원하지 않습니다.
</Callout>

## 플러그인 모드

### 설치

```package-install
npm install @univerjs/find-replace @univerjs/docs-find-replace
```

### 사용법

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsFindReplacePlugin } from '@univerjs/docs-find-replace'
import FindReplaceKoKR from '@univerjs/find-replace/locale/ko-KR'

import '@univerjs/find-replace/lib/index.css'

const univer = new Univer({
  locale: LocaleType.KO_KR,
  locales: {
    [LocaleType.KO_KR]: mergeLocales(FindReplaceKoKR),
  },
})

univer.registerPlugin(UniverDocsFindReplacePlugin)
```

## 키보드 단축키

- `Ctrl/Cmd + F`: 찾기 열기
- `Ctrl/Cmd + H`: 바꾸기 열기
- `Enter` / `Shift + Enter`: 다음 / 이전 일치 항목
- `Escape`: 문서로 포커스 돌리기
