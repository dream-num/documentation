Content controls (SDT)는 풍부한 텍스트, 일반 텍스트, 체크 박스, 날짜, 목록, 그림, 그룹, 반복 섹션 및 문서 부품을 지원합니다. 문서를 작성하기 전에 Docs 코어 및 Pro 라이센스 플러그인을 등록 한 다음 아래 두 패키지를 등록하십시오. `locales`로 UI Locale를 Merge하고 Stylesheet을로드하십시오. Docs 고급 프리셋은 이러한 패키지를 포함하지 않습니다.

```package-install
npm install @univerjs-pro/docs-sdt @univerjs-pro/docs-sdt-ui
```

```ts
import { UniverDocsSdtPlugin } from '@univerjs-pro/docs-sdt'
import { UniverDocsSdtUIPlugin } from '@univerjs-pro/docs-sdt-ui'
import FeatureLocale from '@univerjs-pro/docs-sdt-ui/locale/ko-KR'
import { LocaleType } from '@univerjs/core'

import '@univerjs-pro/docs-sdt-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.KO_KR, FeatureLocale)

univer.registerPlugin(UniverDocsSdtPlugin)
univer.registerPlugin(UniverDocsSdtUIPlugin)
```

## 선택 위치에 삽입 [#insert]

명령은 활성 텍스트 선택에 적용됩니다. 제어 유형이 지원할 때, 현재 선택은 새로운 제어로 감싸입니다. 반복 섹션 항목은 부모 섹션을 통해 생성됩니다.

```ts
import { InsertSdtCommand } from '@univerjs-pro/docs-sdt-ui'

await univerAPI.executeCommand(InsertSdtCommand.id, { kind: 'checkbox' })
```

## 잠금과 저장 [#locks-and-persistence]

제어는 `CustomRangeType.SDT` 범위로 `IDocumentBody.customRanges`에 저장되며, 메타데이터는 `ISdtCustomRange.properties`에서 저장됩니다. 콘텐츠 잠금은 값 편집을 방지하고 제어 잠금은 래퍼의 제거를 방지합니다. 반복 섹션은 또한 삽입 및 삭제 항목도 제거 할 수 있습니다. 변경 값, 속성 및 명령을 통해 항목을 반복하여 일관성을 유지하고 재도 유지하십시오.

[모델 명령](/reference/packages/plugins/univerjs-pro/docs-sdt) 및 [UI API를](/reference/packages/plugins/univerjs-pro/docs-sdt-ui) 참조 페이지를 참조하십시오. DOCX 변환은 [계정 관리](/guides/docs/features/import-export)에 의해 처리됩니다; 편집기 지원은 손실없이 모든 워드 속성 또는 사용자 정의 XML 바인딩 변환이 의미하지 않습니다.
