콘텐츠 컨트롤(SDT)은 서식 있는 텍스트, 일반 텍스트, 확인란, 날짜, 목록, 그림, 그룹, 반복 구역 및 문서 요소를 지원합니다. Docs Core와 Pro 라이선스를 설정하고 문서 생성 전에 아래 플러그인을 등록하세요. UI 언어 팩을 `locales`에 병합하고 CSS를 불러옵니다. Docs Advanced에는 포함되지 않습니다.

```package-install
npm install @univerjs-pro/docs-sdt @univerjs-pro/docs-sdt-ui
```

```ts
import { UniverDocsSdtPlugin } from '@univerjs-pro/docs-sdt'
import { UniverDocsSdtUIPlugin } from '@univerjs-pro/docs-sdt-ui'
import FeatureLocale from '@univerjs-pro/docs-sdt-ui/locale/ko-KR'
import { LocaleType } from '@univerjs/core'

import '@univerjs-pro/docs-sdt-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.KO_KR, FeatureLocale)

univer.registerPlugin(UniverDocsSdtPlugin)
univer.registerPlugin(UniverDocsSdtUIPlugin)
```

## 선택 위치에 삽입 [#insert]

명령은 현재 텍스트 선택을 사용하며 지원되는 컨트롤은 선택된 내용을 감쌉니다. 반복 항목은 부모 구역을 통해 생성합니다.

```ts
import { InsertSdtCommand } from '@univerjs-pro/docs-sdt-ui'

await univerAPI.executeCommand(InsertSdtCommand.id, { kind: 'checkbox' })
```

## 잠금과 저장 [#locks-and-persistence]

컨트롤은 `IDocumentBody.customRanges`의 `CustomRangeType.SDT` 범위로 저장되며 메타데이터는 `ISdtCustomRange.properties`에 있습니다. 콘텐츠 잠금은 값 편집을, 컨트롤 잠금은 래퍼 삭제를 막습니다. 반복 구역은 항목 추가 및 삭제도 제한할 수 있습니다. 실행 취소/다시 실행을 유지하려면 명령으로 값을 변경하세요.

[모델 명령](/reference/packages/plugins/univerjs-pro/docs-sdt)과 [UI API](/reference/packages/plugins/univerjs-pro/docs-sdt-ui)를 참고하세요. DOCX 변환은 [Exchange](/guides/docs/features/import-export)가 담당하며 모든 Word 속성이나 사용자 지정 XML 바인딩의 무손실 변환을 보장하지 않습니다.
