La característica de la forma inserta y edita dibujos dentro de un documento, desde formas geométricas básicas y flechas hasta elementos de diagrama de flujo.

## Introducción

En Univer Docs, las formas soportan las siguientes operaciones:

- Añadir rectángulos, círculos, flechas y otras formas simples.
- Ajusta el color, las fronteras y el texto.
- Coloque una forma en cualquier lugar del documento.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/engine-formula @univerjs-pro/docs-shape @univerjs-pro/docs-shape-ui
```

<Callout type="warn">
  Las formas también requieren `UniverProFormulaEnginePlugin` de `@univerjs-pro/engine-formula`. En la configuración base, sustitúyase la importación y registro `UniverFormulaEnginePlugin` existente con este plugin. No registre ambos motores de fórmula, porque hacerlo puede hacer que la inserción de forma falle con un error de dependencia perdido.
</Callout>

### Uso

```typescript
import { UniverDocsShapePlugin } from '@univerjs-pro/docs-shape' // [!code ++]
import { UniverDocsShapeUIPlugin } from '@univerjs-pro/docs-shape-ui' // [!code ++]
import DocsShapeUIEnUS from '@univerjs-pro/docs-shape-ui/locale/en-US' // [!code ++]
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-shape-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsShapeUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverProFormulaEnginePlugin) // [!code ++]
univer.registerPlugin(UniverDocsShapePlugin) // [!code ++]
univer.registerPlugin(UniverDocsShapeUIPlugin) // [!code ++]
```

Si utiliza una licencia comercial, configure como se describe en [Utilizando Licencia en Cliente](/server/license#in-plugin-mode).

## Editar el texto de una forma

Trabajar con el objeto de forma devuelto por `insertShape()`, ya sea en el ejemplo a continuación o en el ejemplo anterior. `getText()` devuelve un mango vivo [FShapeText](/reference/facade/shape-text).Leer texto plano con `getPlainText()`, reemplazar todo con `setText()`, y aplicar formato a través de los métodos de fuente, color y alineación.

```ts
import '@univerjs-pro/docs-shape/facade'

const document = univerAPI.getActiveDocument()
const paragraph = document?.getParagraphs()[0]
if (!document || !paragraph) throw new Error('No active document paragraph')
const shape = document.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.Rect,
  placement: {
    wrappingStyle: univerAPI.Enum.TextWrappingStyle.INLINE,
    anchor: { paragraphId: paragraph.getId(), segmentId: paragraph.getSegmentId() },
  },
})
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()` reemplaza el texto existente. Utilice `setRichText()` cuando una forma necesita varios estilos. Para cambiar el texto rico existente, llame a `getRichText()?.copy()`, edite el constructor, y pasar a `setRichText()`; las ediciones a ese constructor separado no se aplican por su cuenta. Más opciones están disponibles en [estilo de texto](/reference/facade/shape-text#settextstyle) y [texto caja de relleno y diseño](/reference/facade/shape-text#settextboxoptions).

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## Copiar formato de formas [#format-painter]

Seleccione una forma de origen, gire en el pintor de formato y luego seleccione la forma de destino. El pintor copia llena, trazo, efectos, y el formato de texto compatible, y deja la identidad del objetivo, geometría, contenido de texto y unión de fórmula sin cambios. El formato de limpieza restaura los defectos utilizados en la inserción. SmartArt está excluido. La forma UI plugin registra este comportamiento automáticamente.
