コールアウトは、周囲のテキストから情報の一部を分離します。アイコンと色は構成可能であるため、ノート、警告、ヒントはそれぞれ異なる外観を持つことができます。

## はじめに

Univer Docs では、コールアウトブロックは 3 つの目的を果たします。

- 注意、警告、またはヒントに注意を払います。
- ブロックに選択したアイコンと色を適用するので、その外観はコンテンツにマッチします。
- 文書を視覚的に分離し、独立して読むセクションに分割します。

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/docs-callout @univerjs-pro/docs-callout-ui
```

### 使用法

```typescript
import { UniverDocsCalloutPlugin } from '@univerjs-pro/docs-callout' // [!code ++]
import { UniverDocsCalloutUIPlugin } from '@univerjs-pro/docs-callout-ui' // [!code ++]
import DocsCalloutUIJaJP from '@univerjs-pro/docs-callout-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-callout-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsCalloutUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCalloutPlugin) // [!code ++]
univer.registerPlugin(UniverDocsCalloutUIPlugin) // [!code ++]
```

アプリケーションが商用ライセンスで Univer を使用している場合は、[クライアントでのライセンスの使用](/server/license#in-plugin-mode). で説明するように設定します。

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/docs/getting-started/installation#mobile-support)を最初に構成します。このページのプラグインモード設定では、同じパッケージからモバイルエクスポートに以下にリストされているデスクトップ登録を置き換え、代替**ドキュメントを開く前に**を作ります。モデルプラグイン、スタイル、ロケール、ファサードのインポートを保持し、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/docs-callout-ui` | `UniverDocsCalloutUIPlugin` | `UniverDocsCalloutMobileUIPlugin` |

## Facade API

API を呼び出す前にファサードをインポートします。

```typescript
import '@univerjs-pro/docs-callout/facade'
```

### すべてのコールアウトを取得

```typescript
const doc = univerAPI.getActiveDocument()
const callouts = doc?.getCallouts() ?? []
```

### ID でコールアウトを取得

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.getCallout('callout-block-id')
```

### コールアウトを挿入

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.insertCallout({
  startOffset: 12,
  endOffset: 35,
  config: { icon: '💡' },
})
```

### コールアウト設定を更新

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.updateConfig({ icon: '⚠️' })
```

### コールアウトの外観を設定

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.setIcon('📝')
callout?.setBackgroundColor('#FFF4E5')
callout?.setBorder({ color: '#E6A23C', width: 2 })
callout?.setTextColor('#5C3B00')
```

ドキュメントコマンドで出現する変更が適用されるので、undo、redo、およびコラボレーションはそれらを受け取ります。 `setTextColor()`は、コールアウト中のすべてのテキストに色を適用します。 文書から継承されたテキスト色を上書きし、復元するために、`resetTextColor()`を呼び出します。

```ts
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.resetTextColor()
```
