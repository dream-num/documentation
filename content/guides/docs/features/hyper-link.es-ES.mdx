Los hipervínculos se utilizan para navegar y acceder rápidamente a páginas web externas, direcciones de correo electrónico y otro contenido en documentos.

## Modo preset

### Instalación

```package-install
npm install @univerjs/preset-docs-hyper-link
```

### Uso

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEsES from '@univerjs/preset-docs-core/locales/es-ES'
import { UniverDocsHyperLinkPreset } from '@univerjs/preset-docs-hyper-link' // [!code ++]
import UniverPresetDocsHyperLinkEsES from '@univerjs/preset-docs-hyper-link/locales/es-ES' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-hyper-link/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.ES_ES,
  locales: {
    [LocaleType.ES_ES]: mergeLocales(
      UniverPresetDocsCoreEsES,
      UniverPresetDocsHyperLinkEsES, // [!code ++]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
    UniverDocsHyperLinkPreset(), // [!code ++]
  ],
})
```

## Modo de complemento

### Instalación

```package-install
npm install @univerjs/docs-hyper-link @univerjs/docs-hyper-link-ui
```

### Uso

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsHyperLinkPlugin } from '@univerjs/docs-hyper-link' // [!code ++]
import { UniverDocsHyperLinkUIPlugin } from '@univerjs/docs-hyper-link-ui' // [!code ++]
import DocsHyperLinkUIEsES from '@univerjs/docs-hyper-link-ui/locale/es-ES' // [!code ++]

import '@univerjs/docs-hyper-link-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ES_ES,
  locales: {
    [LocaleType.ES_ES]: mergeLocales(
      DocsHyperLinkUIEsES, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsHyperLinkPlugin) // [!code ++]
univer.registerPlugin(UniverDocsHyperLinkUIPlugin) // [!code ++]
```

## Crear y editar enlaces con la API Facade

`link(text, url)` añade texto enlazado y registra su rango, por lo que no es necesario calcular desplazamientos. Use el identificador devuelto por `getLinks()` para cambiar el destino más adelante.

```ts
const richText = univerAPI
  .newRichText()
  .text('Read ')
  .link('Univer SDK documentation', 'https://docs.univer.ai')
  .text(' for details.')

const [link] = richText.getLinks()
if (!link) throw new Error('Link was not created')

richText.updateLink(link.rangeId, 'https://docs.univer.ai/guides')
```

`removeLink(link.rangeId)` elimina el destino sin borrar el texto visible.
