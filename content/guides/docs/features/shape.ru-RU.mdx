Функция формы вставляет и редактирует рисунки внутри документа, от основных геометрических форм и стрелок до элементов блок-схемы.

## Введение

В Univer Docs формы поддерживают следующие операции:

- Добавьте прямоугольники, круги, стрелки и другие простые формы.
- Настройте цвет, границы и текст.
- Поместите форму в любом месте документа.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/engine-formula @univerjs-pro/docs-shape @univerjs-pro/docs-shape-ui
```

<Callout type="warn">
  Формы также требуют `UniverProFormulaEnginePlugin` от `@univerjs-pro/engine-formula`. В базовой настройке замените существующий импорт и регистрацию `UniverFormulaEnginePlugin` этим плагином. Не регистрируйте оба движка формулы, потому что это может привести к отказу вставки формы с ошибкой отсутствия зависимости.
</Callout>

### Использование

```typescript
import { UniverDocsShapePlugin } from '@univerjs-pro/docs-shape' // [!code ++]
import { UniverDocsShapeUIPlugin } from '@univerjs-pro/docs-shape-ui' // [!code ++]
import DocsShapeUIEnUS from '@univerjs-pro/docs-shape-ui/locale/en-US' // [!code ++]
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-shape-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsShapeUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverProFormulaEnginePlugin) // [!code ++]
univer.registerPlugin(UniverDocsShapePlugin) // [!code ++]
univer.registerPlugin(UniverDocsShapeUIPlugin) // [!code ++]
```

Если вы используете коммерческую лицензию, настройте ее, как описано в [Использование лицензии у клиента](/server/license#in-plugin-mode).

## Редактирование текста фигуры

Работайте с объектом формы, возвращенным `insertShape()`, либо в примере ниже, либо в более раннем примере. `getText()` возвращает живую ручку [FShapeText](/reference/facade/shape-text). Прочитайте простой текст с `getPlainText()` , замените все это `setText()` и применяйте форматирование с помощью шрифта, цвета и методов выравнивания.

```ts
import '@univerjs-pro/docs-shape/facade'

const document = univerAPI.getActiveDocument()
const paragraph = document?.getParagraphs()[0]
if (!document || !paragraph) throw new Error('No active document paragraph')
const shape = document.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.Rect,
  placement: {
    wrappingStyle: univerAPI.Enum.TextWrappingStyle.INLINE,
    anchor: { paragraphId: paragraph.getId(), segmentId: paragraph.getSegmentId() },
  },
})
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()` заменяет существующий текст. Используйте `setRichText()`, когда одной форме требуется несколько стилей. Чтобы изменить существующий богатый текст, позвоните в `getRichText()?.copy()` , отредактируйте конструктор и передайте его `setRichText()`; изменения к этому отдельному конструктору не применяются сами по себе. Дополнительные опции доступны в [Текстовый стиль](/reference/facade/shape-text#settextstyle) и [текстовая обшивка и макет](/reference/facade/shape-text#settextboxoptions).

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## Копирование формата фигур [#format-painter]

Выберите исходную форму, включите форматировщик, а затем выберите целевую форму. Художник копирует заполнение, штрих, эффекты и поддерживаемое форматирование текста и оставляет идентичность цели, геометрию, текстовое содержимое и связывание формулы без изменений. Очистка форматирования восстанавливает по умолчанию используемые при вставке. SmartArt исключен. Плагин UI формы автоматически регистрирует это поведение.
