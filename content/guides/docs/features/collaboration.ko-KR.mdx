[공동 편집 통합](/server/collaboration/browser-integration)에 따라 예제 실행, 앱 연결, 영속성과 권한 검증을 진행하세요. 구현 세부 정보와 Web/Server 예제는 [협업 빠른 시작](/server/collaboration/quick-start)를 참고하세요.

인증된 비즈니스 API에서 Collaboration Service로 Unit을 생성한 뒤 반환된 ID를 브라우저에서 로드하세요. [Quick Start](/server/collaboration/quick-start)에 따라 HTTP, Session Ticket, WebSocket을 설정하고 Database Adapter로 저장하세요. 읽기, JOIN, 수정은 [서버 권한](/server/collaboration/identity-and-authorization)으로 각각 보호해야 합니다.

## 문서 로딩 방식 선택 [#document-loading]

기본적으로 `UniverCollaborationClientUIPlugin`은 시작 시 URL의 `unit`과 `type` 쿼리를 읽어 문서를 로드합니다. 앱에서 문서를 선택하고 Facade 로더를 직접 호출한다면 초기화 시 `enableUrlUnitLoader: false`로 설정하여 앱이 로딩 시작을 담당하도록 하세요.

아래 옵션을 기존 플러그인 등록 또는 공동 편집 프리셋 호출에 병합하세요. 프리셋 모드에서는 기존 `createUniver()`의 프리셋 목록에 `collaborationPreset`을 추가합니다.

<Tabs items={['플러그인 모드', '프리셋 모드']}>
  <Tab>
    ```ts
    import { UniverCollaborationClientUIPlugin } from '@univerjs-pro/collaboration-client-ui'

    univer.registerPlugin(UniverCollaborationClientUIPlugin, {
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
  <Tab>
    ```ts
    import { UniverDocsCollaborationPreset } from '@univerjs/preset-docs-collaboration'

    const collaborationPreset = UniverDocsCollaborationPreset({
      universerEndpoint: 'https://your-backend.example.com',
      enableUrlUnitLoader: false,
    })
    ```
  </Tab>
</Tabs>

URL 자동 로딩을 꺼도 공동 편집과 명시적인 Facade 로딩은 사용할 수 있습니다.

## Facade API [#loading-collaborative-documents]

```ts
import '@univerjs-pro/collaboration-client/facade'

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadDocAsync('your-unit-id')
```
