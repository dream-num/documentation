[공동 편집 통합](/server/collaboration/browser-integration)에 따라 예제 실행, 앱 연결, 영속성과 권한 검증을 진행하세요. 구현 세부 정보와 Web/Server 예제는 [Univer Office](/server/collaboration/quick-start)를 참고하세요.

인증된 비즈니스 API에서 Collaboration Service로 Unit을 생성한 뒤 반환된 ID를 브라우저에서 로드하세요. [Quick Start](/server/collaboration/quick-start)에 따라 HTTP, Session Ticket, WebSocket을 설정하고 Database Adapter로 저장하세요. 읽기, JOIN, 수정은 [서버 권한](/server/collaboration/identity-and-authorization)으로 각각 보호해야 합니다.

## Facade API [#loading-collaborative-documents]

```ts
import '@univerjs-pro/collaboration-client/facade'

const collaboration = univerAPI.getCollaboration()
const unit = await collaboration.loadDocAsync('your-unit-id')
```
