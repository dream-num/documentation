程式碼塊用於在文件中插入格式化的程式碼片段，語法高亮由 Prism.js 提供。

## 介紹

在 Univer Docs 中，程式碼塊可滿足以下幾類常見需求：

- 可在文件的任意位置插入格式化的程式碼塊。
- 程式碼按語言自動高亮。
- 在空的程式碼段落中，可以退出程式碼塊或取消程式碼格式。

## 外掛模式

### 安裝

```package-install
npm install @univerjs-pro/docs-code @univerjs-pro/docs-code-ui
```

### 使用

```typescript
import { UniverDocsCodePlugin } from '@univerjs-pro/docs-code' // [!code ++]
import { UniverDocsCodeUIPlugin } from '@univerjs-pro/docs-code-ui' // [!code ++]
import DocsCodeUIZhTW from '@univerjs-pro/docs-code-ui/locale/zh-TW' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-code-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      DocsCodeUIZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCodePlugin) // [!code ++]
univer.registerPlugin(UniverDocsCodeUIPlugin) // [!code ++]
```

使用 Univer 商業許可證時，按[在客戶端使用許可證](/server/license#in-plugin-mode)中的說明完成配置。

## 行動裝置支援 [#mobile-support]

請先配置[行動版編輯器](/guides/docs/getting-started/installation#mobile-support)。在本頁外掛模式的初始化程式碼中，將下列桌面版註冊替換為同一套件匯出的行動版外掛，替換須在**開啟文件前**完成。模型外掛、樣式、語言套件和 Facade 匯入均需保留，不要同時註冊兩個版本。

| 套件 | 桌面版註冊 | 行動版註冊 |
| --- | --- | --- |
| `@univerjs-pro/docs-code-ui` | `UniverDocsCodeUIPlugin` | `UniverDocsCodeMobileUIPlugin` |

## Facade API

呼叫下列方法前需先匯入 facade：

```typescript
import '@univerjs-pro/docs-code/facade'
```

### 取得所有程式碼區塊

```typescript
const doc = univerAPI.getActiveDocument()
const codes = doc?.getCodes() ?? []
```

### 插入程式碼區塊

```typescript
const doc = univerAPI.getActiveDocument()
const code = doc?.insertCode({
  startOffset: 12,
  endOffset: 35,
})
```

### 退出程式碼區塊

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitCode()
```

### 取消空程式碼段落

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyCodeParagraph()
```

## 程式碼區塊等寬字型 [#code-fonts]

程式碼塊工具欄的字型選擇器僅列出以 `FontCategory.MONOSPACE` 註冊的字型。選擇某個字型後，該字型會應用到整個程式碼塊，包括其中的段落樣式。

要註冊自定義等寬字型，呼叫 `addFonts()`：

```ts
import { FontCategory } from '@univerjs/ui'
import '@univerjs/ui/facade'

univerAPI.addFonts([
  { value: 'JetBrains Mono', label: 'JetBrains Mono', category: FontCategory.MONOSPACE },
])
```

註冊只會向選擇器新增一個選項，字型檔案本身仍需透過 CSS 或瀏覽器 FontFace API 載入，具體做法見[自定義字型](/guides/docs/ui/fonts)。該方法在外掛模式和預設模式下均可使用。
