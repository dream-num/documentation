## 支援的格式

下表列出本頁瀏覽器 API 支援的格式。轉換 Office 檔案還要求後端支援相同的文件型別和格式。

| 匯入 | 匯出 |
| --- | --- |
| `.doc`, `.docx` | `.docx` |

`.doc` 和 `.docx` 都使用下方的匯入 API。匯出始終生成 `.docx`，舊版 `.doc` 格式不支援匯出。

## Facade API

### 匯入

<Callout type="info" title="外掛模式提示">
  只有外掛模式需要手動匯入 Facade 包。預設模式已經包含對應的 Facade 包，無需額外匯入。
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/docs-exchange-client/facade'
```

### 匯入 `.docx`

#### 匯入 `.docx` 檔案並獲取 `unitId`

<Callout type="warning" title="注意事項">
  該方法依賴協同服務，因為它會在伺服器端建立文件並返回 `unitId`。未啟用協同服務時，請使用快照匯入。
</Callout>

啟用協同編輯後，每個文件都有唯一的 `unitId`。使用 `univerAPI.importDocToUnitIdAsync` 並傳入 `file` 參數，會返回 `unitId`，隨後可用它訪問文件。`file` 參數可以是 `File` 物件，也可以是遠端檔案的 URL。

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importDocToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadDocAsync(unitId)
}
```

#### 匯入 `.docx` 檔案並獲取 `IDocumentData`

`univerAPI.importDocToSnapshotAsync` 匯入 `.docx` 檔案，並以 `IDocumentData` 返回文件資料。快照匯入不依賴協同服務；文件需要協同編輯時，請使用 `unitId` 匯入。

```typescript
// 接受 File 物件
const snapshot = await univerAPI.importDocToSnapshotAsync(file)
// 或者接受遠端檔案的 URL
// const snapshot = await univerAPI.importDocToSnapshotAsync('https://example.com/filename.docx');

// 透過快照建立一個新的文件
if (snapshot) univerAPI.createDocument(snapshot)
```

### 匯出 `.docx`

#### 透過 `unitId` 匯出 `.docx` 檔案

<Callout type="warning" title="注意事項">
  `unitId` 匯出依賴協同服務。未啟用協同服務時，請使用快照匯出。
</Callout>

啟用協同編輯後，每個文件都有唯一的 `unitId`。使用 `univerAPI.exportDocByUnitIdAsync` 並傳入 `unitId` 參數，會返回一個 `File` 物件。

```typescript
const fDocument = univerAPI.getActiveDocument()
const unitId = fDocument.getId()
const file = await univerAPI.exportDocByUnitIdAsync(unitId)

// 透過 Facade API 下載檔案
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

#### 透過 `IDocumentData` 匯出 `.docx` 檔案

<Callout>快照匯出不依賴協同服務，適合本地工作流。</Callout>

`univerAPI.exportDocBySnapshotAsync` 接收 `IDocumentData`，並返回一個 `File` 物件。

```typescript
const fDocument = univerAPI.getActiveDocument()
const snapshot = fDocument.save()
const file = await univerAPI.exportDocBySnapshotAsync(snapshot)

// 透過 Facade API 下載檔案
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

## 移除內建匯入匯出選單和 UI 互動 [#import-export-ui-migration]

<Callout type="warning" title="注意事項">
  從 **1.2.0** 版本開始，Univer 不再內建匯入匯出選單和 UI 互動。底層服務和 Facade API 仍然可用。
</Callout>

如果應用仍然需要這些選單和 UI 互動，請參閱[內建匯入匯出選單和 UI 互動遷移方案](https://office.univer.ai/zh-CN/showcase/docs/custom-import-export)，其中說明了如何將它們遷移到自定義外掛。範例提供完整原始碼，可線上檢視或下載。
