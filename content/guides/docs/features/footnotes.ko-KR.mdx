기존 페이지형 문서에 각주와 미주를 추가합니다. 각주는 참조가 있는 페이지에 배치되고 미주는 문서 설정에 따라 배치됩니다. 이 API는 모던 문서를 지원하지 않습니다.

## 설치

라이선스가 설정된 기존 Docs 편집기에 다음 플러그인을 추가하고 UI 스타일과 편집기 언어 리소스를 불러오세요.

`UniverDocsAdvancedPreset`에는 두 플러그인이 포함되어 있습니다. 해당 preset을 사용한다면 다시 등록하지 마세요.

```package-install
npm install @univerjs-pro/docs-reference @univerjs-pro/docs-reference-ui
```

```ts
import { UniverDocsReferencePlugin } from '@univerjs-pro/docs-reference'
import { UniverDocsReferenceUIPlugin } from '@univerjs-pro/docs-reference-ui'
import ReferenceLocale from '@univerjs-pro/docs-reference-ui/locale/ko-KR'
import { LocaleType } from '@univerjs/core'

import '@univerjs-pro/docs-reference/facade'
import '@univerjs-pro/docs-reference-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.KO_KR, ReferenceLocale)
univer.registerPlugin(UniverDocsReferencePlugin)
univer.registerPlugin(UniverDocsReferenceUIPlugin)
```

## 주석 삽입 및 관리

```ts
const document = univerAPI.getActiveDocument()
if (document) {
  const noteId = document.insertFootnote(0)
  if (noteId) console.log(document.getParagraphs(noteId))
  console.log(document.getFootnotes(), document.getEndnotes())
}
```

오프셋은 구조 토큰을 포함한 본문의 UTF-16 위치입니다. 위치나 내용이 유효하지 않거나 편집 권한이 없거나 모던 문서이면 `null`을 반환합니다. 성공하면 안정적인 주석 ID를 반환합니다. 참조와 주석 내용은 같은 실행 취소 및 협업 mutation에 포함됩니다.

`getFootnotes()` / `getEndnotes()`로 읽고 `deleteFootnote(noteId)` / `deleteEndnote(noteId)`로 삭제합니다. `setFootnoteSettings()`와 `setEndnoteSettings()`로 번호와 배치를 설정하고 `null`로 명시적 설정을 초기화합니다. 내용에 접근할 때는 반환된 ID를 보관해 사용하세요. 표시 번호는 페이지 배치가 바뀌면 달라질 수 있습니다.
