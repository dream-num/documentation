Footnotes 및 endnotes는 전통적, 질화 된 문서에 적용됩니다. footnotes는 참조 페이지에 놓습니다. endnote는 문서의 endnote 설정에 따라 배치됩니다. 이 API는 현대 문서를 지원하지 않습니다.

## 플러그인 모드 [#plugin-mode]

### 설치

```package-install
npm install @univerjs-pro/docs-reference @univerjs-pro/docs-reference-ui
```

### 사용법

이 플러그인을 Docs 편집기에 구성된 라이센스를 추가하고, UI 스타일과 편집기에 맞는 로컬을로드합니다.

```ts
import { UniverDocsReferencePlugin } from '@univerjs-pro/docs-reference'
import { UniverDocsReferenceUIPlugin } from '@univerjs-pro/docs-reference-ui'
import ReferenceLocale from '@univerjs-pro/docs-reference-ui/locale/ko-KR'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/docs-reference/facade'
import '@univerjs-pro/docs-reference-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.KO_KR, ReferenceLocale)
univer.registerPlugin(UniverDocsReferencePlugin)
univer.registerPlugin(UniverDocsReferenceUIPlugin)
```

## 프리셋 모드 [#preset-mode]

### 설치

```package-install
npm install @univerjs/presets @univerjs/preset-docs-core @univerjs/preset-docs-drawing @univerjs/preset-docs-advanced
```

### 사용법

`UniverDocsAdvancedPreset`는 이미 플러그인을 포함합니다. 이 미리 설치를 사용할 때, 등록을 유지하고 플러그인을 다시 추가하지 마십시오.

핵심, 도면 및 고급 프리셋을 결합하고 로컬 리소스를 병합합니다. 클라이언트 라이센스는 [사용방법](/server/license#in-preset-mode)에 설명되어 있습니다.

```ts
import { UniverDocsAdvancedPreset } from '@univerjs/preset-docs-advanced'
import AdvancedLocale from '@univerjs/preset-docs-advanced/locales/ko-KR'
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import CoreLocale from '@univerjs/preset-docs-core/locales/ko-KR'
import { UniverDocsDrawingPreset } from '@univerjs/preset-docs-drawing'
import DrawingLocale from '@univerjs/preset-docs-drawing/locales/ko-KR'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-drawing/lib/index.css'
import '@univerjs/preset-docs-advanced/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.KO_KR,
  locales: {
    [LocaleType.KO_KR]: mergeLocales(CoreLocale, DrawingLocale, AdvancedLocale),
  },
  presets: [
    UniverDocsCorePreset({ container: 'app' }),
    UniverDocsDrawingPreset(),
    UniverDocsAdvancedPreset(),
  ],
})
```

### 프리셋 설정 [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | 편집기를 마운트할 DOM 요소 또는 해당 요소의 ID입니다. |

## 주석 삽입 및 관리

```ts
const document = univerAPI.getActiveDocument()
if (document) {
  const noteId = document.insertFootnote(0)
  if (noteId) console.log(document.getParagraphs(noteId))
  console.log(document.getFootnotes(), document.getEndnotes())
}
```

오프셋은 본체의 UTF-16 위치이며 구조적 토큰을 계산합니다. 삽입은 위치가 유효하지 않을 때 `null`를 반환합니다. 참고 내용은 유효하지 않습니다. 콜러는 허가가 부족하거나 문서는 현대적입니다. 그렇지 않으면 안정된 메모 ID를 반환합니다. 참고 및 메모 내용은 동일한 undo 단계와 동일한 협업 뮤테이션에 속합니다.

`getFootnotes()` / `getEndnotes()`와 노트를 읽고 `deleteFootnote(noteId)`/`deleteEndnote(noteId)`로 제거하십시오. `setFootnoteSettings()` 및 `setEndnoteSettings()` 제어 번호 및 배치를 제거하고 `null`를 통과하십시오. 표시된 숫자가 pagination 후에 변화할 수 있기 때문에, 만족한 내용을 위한 반환된 주 ID를 지키십시오.
