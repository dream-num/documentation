Les notes de bas de page et les notes de fin s'appliquent aux documents traditionnels et paginés. Une note de bas de ligne est présentée sur la page qui la mentionne; une note de fin de page est placée selon les paramètres des notes de fin de document.

## Mode plugin [#plugin-mode]

### Installation

```package-install
npm install @univerjs-pro/docs-reference @univerjs-pro/docs-reference-ui
```

### Utilisation

Ajoutez ces plugins à un éditeur Docs avec une licence configurée, et chargez les styles d'interface utilisateur et la locale qui correspond à l'éditeur.

```ts
import { UniverDocsReferencePlugin } from '@univerjs-pro/docs-reference'
import { UniverDocsReferenceUIPlugin } from '@univerjs-pro/docs-reference-ui'
import ReferenceLocale from '@univerjs-pro/docs-reference-ui/locale/fr-FR'
import { LocaleType } from '@univerjs/core'
import '@univerjs-pro/docs-reference/facade'
import '@univerjs-pro/docs-reference-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.FR_FR, ReferenceLocale)
univer.registerPlugin(UniverDocsReferencePlugin)
univer.registerPlugin(UniverDocsReferenceUIPlugin)
```

## Mode prédéfini [#preset-mode]

### Installation

```package-install
npm install @univerjs/presets @univerjs/preset-docs-core @univerjs/preset-docs-drawing @univerjs/preset-docs-advanced
```

### Utilisation

`UniverDocsAdvancedPreset` inclut déjà les deux plugins. Lorsque vous utilisez ce preset, gardez son enregistrement et n'ajoutez pas les plugins à nouveau.

Combinez les préréglages de base, de dessin et avancés et fusionnez leurs ressources locales. La licence client est configurée comme décrit dans [utilisant une licence](/server/license#in-preset-mode).

```ts
import { UniverDocsAdvancedPreset } from '@univerjs/preset-docs-advanced'
import AdvancedLocale from '@univerjs/preset-docs-advanced/locales/fr-FR'
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import CoreLocale from '@univerjs/preset-docs-core/locales/fr-FR'
import { UniverDocsDrawingPreset } from '@univerjs/preset-docs-drawing'
import DrawingLocale from '@univerjs/preset-docs-drawing/locales/fr-FR'
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'
import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-drawing/lib/index.css'
import '@univerjs/preset-docs-advanced/lib/index.css'

const { univerAPI } = createUniver({
  locale: LocaleType.FR_FR,
  locales: {
    [LocaleType.FR_FR]: mergeLocales(CoreLocale, DrawingLocale, AdvancedLocale),
  },
  presets: [
    UniverDocsCorePreset({ container: 'app' }),
    UniverDocsDrawingPreset(),
    UniverDocsAdvancedPreset(),
  ],
})
```

### Configuration des préréglages [#preset-configuration]

`UniverDocsCorePreset`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` | `'app'` | Élément DOM de montage de l’éditeur ou son identifiant. |

## Insérer et gérer les notes

```ts
const document = univerAPI.getActiveDocument()
if (document) {
  const noteId = document.insertFootnote(0)
  if (noteId) console.log(document.getParagraphs(noteId))
  console.log(document.getFootnotes(), document.getEndnotes())
}
```

L'offset est une position UTF-16 dans le corps principal et compte les jetons structurels. L'insertion renvoie `null` lorsque la position est invalide, le contenu de la note est invalide, l'appelant manque de permission, ou le document est moderne. Sinon, elle retourne un identifiant de note stable. La référence et le contenu de note appartiennent à la même étape de désactivation et à la même mutation de collaboration.

Lisez les notes avec `getFootnotes()` / `getEndnotes()` et retirez-les avec `deleteFootnote(noteId)` / `deleteEndnote(noteId)`. `setFootnoteSettings()` et `setEndnoteSettings()` la numérotation de contrôle et le placement, et passez `null` efface tous les paramètres explicites. Gardez l'identifiant de note retourné pour l'adresse du contenu, parce que les numéros affichés peuvent changer après la pagination.
