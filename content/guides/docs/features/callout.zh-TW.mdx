標註塊將一段重要資訊與周圍正文分開呈現。圖示和顏色均可配置，因此說明、警告和提示可以各自呈現不同的外觀。

## 介紹

在 Univer Docs 中，標註塊有三個用途：

- 將讀者的注意力引向重要說明、警告或提示。
- 應用為標註塊選擇的圖示和配色，使其外觀與內容一致。
- 將文件劃分為視覺上相互獨立、可單獨閱讀的區段。

## 外掛模式

### 安裝

```package-install
npm install @univerjs-pro/docs-callout @univerjs-pro/docs-callout-ui
```

### 使用

```typescript
import { UniverDocsCalloutPlugin } from '@univerjs-pro/docs-callout' // [!code ++]
import { UniverDocsCalloutUIPlugin } from '@univerjs-pro/docs-callout-ui' // [!code ++]
import DocsCalloutUIZhTW from '@univerjs-pro/docs-callout-ui/locale/zh-TW' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-callout-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_TW,
  locales: {
    [LocaleType.ZH_TW]: mergeLocales(
      DocsCalloutUIZhTW, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCalloutPlugin) // [!code ++]
univer.registerPlugin(UniverDocsCalloutUIPlugin) // [!code ++]
```

使用 Univer 商業許可證時，按[在客戶端使用許可證](/server/license#in-plugin-mode)中的說明完成配置。

## 行動裝置支援 [#mobile-support]

請先配置[行動版編輯器](/guides/docs/getting-started/installation#mobile-support)。在本頁外掛模式的初始化程式碼中，將下列桌面版註冊替換為同一套件匯出的行動版外掛，替換須在**開啟文件前**完成。模型外掛、樣式、語言套件和 Facade 匯入均需保留，不要同時註冊兩個版本。

| 套件 | 桌面版註冊 | 行動版註冊 |
| --- | --- | --- |
| `@univerjs-pro/docs-callout-ui` | `UniverDocsCalloutUIPlugin` | `UniverDocsCalloutMobileUIPlugin` |

## Facade API

呼叫 API 前需先匯入 facade：

```typescript
import '@univerjs-pro/docs-callout/facade'
```

### 取得所有標註塊

```typescript
const doc = univerAPI.getActiveDocument()
const callouts = doc?.getCallouts() ?? []
```

### 根據 ID 取得標註塊

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.getCallout('callout-block-id')
```

### 插入標註塊

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.insertCallout({
  startOffset: 12,
  endOffset: 35,
  config: { icon: '💡' },
})
```

### 更新標註塊配置

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.updateConfig({ icon: '⚠️' })
```

### 設定標註塊外觀

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.setIcon('📝')
callout?.setBackgroundColor('#FFF4E5')
callout?.setBorder({ color: '#E6A23C', width: 2 })
callout?.setTextColor('#5C3B00')
```

外觀修改透過文件命令執行，因此撤銷、重做和協同編輯都能取得這些變更。`setTextColor()` 為標註塊內的全部文字設定顏色；呼叫 `resetTextColor()` 可移除此覆蓋，並恢復從文件繼承的文字顏色。

```ts
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.resetTextColor()
```
