Un callout separa un pedazo de información del texto circundante. El icono y los colores son configurables, por lo que una nota, una advertencia, y una punta puede cada uno tener una apariencia distinta.

## Introducción

En Univer Docs, los bloques de llamada sirven tres propósitos:

- Llaman la atención a una nota, una advertencia o una punta.
- Aplican el icono y los colores seleccionados para el bloque, por lo que su apariencia coincide con el contenido.
- Dividen un documento en secciones que son visualmente separadas y leídos independientemente.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/docs-callout @univerjs-pro/docs-callout-ui
```

### Uso

```typescript
import { UniverDocsCalloutPlugin } from '@univerjs-pro/docs-callout' // [!code ++]
import { UniverDocsCalloutUIPlugin } from '@univerjs-pro/docs-callout-ui' // [!code ++]
import DocsCalloutUIEnUS from '@univerjs-pro/docs-callout-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-callout-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCalloutUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCalloutPlugin) // [!code ++]
univer.registerPlugin(UniverDocsCalloutUIPlugin) // [!code ++]
```

Si su aplicación utiliza Univer bajo una licencia comercial, configure como se describe en [Utilizando Licencia en Cliente](/server/license#in-plugin-mode).

## API de fachada

Importar la fachada antes de llamar a la API:

```typescript
import '@univerjs-pro/docs-callout/facade'
```

### Obtener todas las llamadas

```typescript
const doc = univerAPI.getActiveDocument()
const callouts = doc?.getCallouts() ?? []
```

### Obtener una llamada por ID

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.getCallout('callout-block-id')
```

### Insertar una llamada

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.insertCallout({
  startOffset: 12,
  endOffset: 35,
  config: { icon: '💡' },
})
```

### Actualizar configuración de llamada

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.updateConfig({ icon: '⚠️' })
```

### Establecer la apariencia de la llamada

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.setIcon('📝')
callout?.setBackgroundColor('#FFF4E5')
callout?.setBorder({ color: '#E6A23C', width: 2 })
callout?.setTextColor('#5C3B00')
```

Los cambios de apariencia se aplican a través de comandos de documentos, por lo que deshacer, redo y colaboración los reciben. `setTextColor()` aplica un color a todo el texto en el callout; llame a `resetTextColor()` para eliminar esa anulación y restaurar los colores de texto heredados del documento.

```ts
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.resetTextColor()
```
