La función de llamada le permite resaltar información importante en un documento con bloques visualmente distintos, completos con íconos y colores personalizables.

## Introducción

En Univer Docs, los bloques de llamada le permiten:

- **Resaltar información clave**: llamar la atención sobre notas, advertencias o consejos importantes.
- **Personalizar la apariencia**: elija entre diferentes íconos y combinaciones de colores para que coincidan con su contenido.
- **Organiza el contenido**: estructura tu documento con secciones separadas visualmente.

## Modo de complemento

### Instalación

```package-install
npm install @univerjs-pro/docs-callout @univerjs-pro/docs-callout-ui
```

### Uso

```typescript
import { UniverDocsCalloutPlugin } from '@univerjs-pro/docs-callout' // [!code ++]
import { UniverDocsCalloutUIPlugin } from '@univerjs-pro/docs-callout-ui' // [!code ++]
import DocsCalloutUIEnUS from '@univerjs-pro/docs-callout-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-callout-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCalloutUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCalloutPlugin) // [!code ++]
univer.registerPlugin(UniverDocsCalloutUIPlugin) // [!code ++]
```

Si tienes una licencia comercial de Univer, consulta [Uso de la licencia en el cliente](/guides/pro/license#in-plugin-mode) para la configuración.

## API de fachada

Asegúrate de importar la fachada antes de usar el API:

```typescript
import '@univerjs-pro/docs-callout/facade'
```

### Obtener todas las llamadas

```typescript
const doc = univerAPI.getActiveDocument()
const callouts = doc?.getCallouts() ?? []
```

### Obtener una llamada por ID

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.getCallout('callout-block-id')
```

### Insertar una llamada

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.insertCallout({
  startOffset: 12,
  endOffset: 35,
  config: { icon: '💡' },
})
```

### Actualizar configuración de llamada

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.updateConfig({ icon: '⚠️' })
```

### Establecer la apariencia de la llamada

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.setIcon('📝')
callout?.setBackgroundColor('#FFF4E5')
callout?.setBorder({ color: '#E6A23C', width: 2 })
callout?.setTextColor('#5C3B00')
```
