Controles de contenidos (SDT) soportan texto rico, texto plano, casillas de verificación, fechas, listas, imágenes, grupos, secciones de repetición, y partes de documentos. Antes de crear el documento, registre el núcleo de Docs y los plugins de licencia Pro, luego registre los dos paquetes siguientes.Introduzca el local UI en `locales` y cargue la hoja de estilo.

```package-install
npm install @univerjs-pro/docs-sdt @univerjs-pro/docs-sdt-ui
```

```ts
import { UniverDocsSdtPlugin } from '@univerjs-pro/docs-sdt'
import { UniverDocsSdtUIPlugin } from '@univerjs-pro/docs-sdt-ui'
import FeatureLocale from '@univerjs-pro/docs-sdt-ui/locale/es-ES'
import { LocaleType } from '@univerjs/core'

import '@univerjs-pro/docs-sdt-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.ES_ES, FeatureLocale)

univer.registerPlugin(UniverDocsSdtPlugin)
univer.registerPlugin(UniverDocsSdtUIPlugin)
```

## Insertar en la selección [#insert]

El comando se aplica a la selección de texto activa. Cuando el tipo de control lo soporta, la selección actual se envuelve en el nuevo control. Los elementos de sección de repetición se crean a través de su sección padre.

```ts
import { InsertSdtCommand } from '@univerjs-pro/docs-sdt-ui'

await univerAPI.executeCommand(InsertSdtCommand.id, { kind: 'checkbox' })
```

## Bloqueos y persistencia [#locks-and-persistence]

Los controles se almacenan en los rangos `IDocumentBody.customRanges` como `CustomRangeType.SDT`, y sus metadatos se almacena en `ISdtCustomRange.properties`. Una cerradura de contenido evita las ediciones de valor, y una cerradura del control evita la eliminación del envoltorio. Una sección de repetición también puede desactivar los elementos de inserción y eliminación.

Ver las páginas de referencia [comandos modelo](/reference/packages/plugins/univerjs-pro/docs-sdt) y [UI API](/reference/packages/plugins/univerjs-pro/docs-sdt-ui). La conversión DOCX es manejada por [Cambio](/guides/docs/features/import-export); soporte de editor no significa que cada propiedad de Word o convertidos de unión XML personalizados sin pérdida.
