Los controles SDT admiten texto enriquecido o simple, casillas, fechas, listas, imágenes, grupos, secciones repetidas y bloques de documento. Configura Docs Core y la licencia Pro, y registra estos plugins antes de crear el documento. Combina la traducción UI en `locales` y carga el CSS. Docs Advanced no los incluye.

```package-install
npm install @univerjs-pro/docs-sdt @univerjs-pro/docs-sdt-ui
```

```ts
import { UniverDocsSdtPlugin } from '@univerjs-pro/docs-sdt'
import { UniverDocsSdtUIPlugin } from '@univerjs-pro/docs-sdt-ui'
import FeatureLocale from '@univerjs-pro/docs-sdt-ui/locale/es-ES'
import { LocaleType } from '@univerjs/core'

import '@univerjs-pro/docs-sdt-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.ES_ES, FeatureLocale)

univer.registerPlugin(UniverDocsSdtPlugin)
univer.registerPlugin(UniverDocsSdtUIPlugin)
```

## Insertar en la selección [#insert]

El comando usa la selección de texto activa y envuelve el contenido existente cuando el control lo permite. Los elementos repetidos se crean mediante la sección principal.

```ts
import { InsertSdtCommand } from '@univerjs-pro/docs-sdt-ui'

await univerAPI.executeCommand(InsertSdtCommand.id, { kind: 'checkbox' })
```

## Bloqueos y persistencia [#locks-and-persistence]

Los controles son rangos `CustomRangeType.SDT` en `IDocumentBody.customRanges`, con metadatos en `ISdtCustomRange.properties`. El bloqueo de contenido impide cambiar valores; el del control impide quitar su envoltura. Las secciones repetidas pueden impedir añadir o eliminar elementos. Usa comandos para mantener deshacer y rehacer.

Consulta los [comandos](/reference/packages/plugins/univerjs-pro/docs-sdt) y la [API UI](/reference/packages/plugins/univerjs-pro/docs-sdt-ui). La conversión DOCX corresponde a [Exchange](/guides/docs/features/import-export); no implica conservar sin pérdidas toda propiedad de Word o vínculo XML personalizado.
