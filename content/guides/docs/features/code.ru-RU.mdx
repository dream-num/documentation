Функция блоков кода позволяет вставлять в документ и отображать в нём форматированные фрагменты кода с подсветкой синтаксиса на базе Prism.js.

## Введение

Блоки кода в Univer Docs позволяют:

- **Вставлять фрагменты кода**: добавлять форматированные блоки кода в любое место документа.
- **Подсвечивать синтаксис**: автоматически выделять элементы кода в зависимости от языка.
- **Выходить из блока и отменять форматирование**: легко завершать или отменять форматирование кода в пустых абзацах.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/docs-code @univerjs-pro/docs-code-ui
```

### Использование

```typescript
import { UniverDocsCodePlugin } from '@univerjs-pro/docs-code' // [!code ++]
import { UniverDocsCodeUIPlugin } from '@univerjs-pro/docs-code-ui' // [!code ++]
import DocsCodeUIEnUS from '@univerjs-pro/docs-code-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-code-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCodeUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCodePlugin) // [!code ++]
univer.registerPlugin(UniverDocsCodeUIPlugin) // [!code ++]
```

Если у вас есть коммерческая лицензия Univer, инструкции по настройке см. в разделе [Использование лицензии на клиенте](/guides/pro/license#in-plugin-mode).

## Facade API

Перед использованием API обязательно импортируйте фасад:

```typescript
import '@univerjs-pro/docs-code/facade'
```

### Получение всех блоков кода

```typescript
const doc = univerAPI.getActiveDocument()
const codes = doc?.getCodes() ?? []
```

### Вставка блока кода

```typescript
const doc = univerAPI.getActiveDocument()
const code = doc?.insertCode({
  startOffset: 12,
  endOffset: 35,
})
```

### Выход из блока кода

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitCode()
```

### Отмена пустого абзаца с кодом

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyCodeParagraph()
```
