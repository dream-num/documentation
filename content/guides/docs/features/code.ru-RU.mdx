Блок кода размещает отформатированный код внутри документа.Подчеркивание синтаксиса обеспечивается Prism.js.

## Введение

В Univer Docs кодовые блоки обслуживают несколько общих потребностей:

- Отформатированный блок кода может быть вставлен в любом месте документа.
- Код высвечивается автоматически в соответствии с его языком.
- Пустой абзац кода позволяет пользователю выйти из блока или отменить форматирование кода.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/docs-code @univerjs-pro/docs-code-ui
```

### Использование

```typescript
import { UniverDocsCodePlugin } from '@univerjs-pro/docs-code' // [!code ++]
import { UniverDocsCodeUIPlugin } from '@univerjs-pro/docs-code-ui' // [!code ++]
import DocsCodeUIEnUS from '@univerjs-pro/docs-code-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-code-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsCodeUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCodePlugin) // [!code ++]
univer.registerPlugin(UniverDocsCodeUIPlugin) // [!code ++]
```

Если ваше приложение использует Univer под коммерческой лицензией, настройте его так, как описано в [Использование лицензии у клиента](/server/license#in-plugin-mode).

## Facade API

Импортируйте фасад, прежде чем называть эти методы:

```typescript
import '@univerjs-pro/docs-code/facade'
```

### Получение всех блоков кода

```typescript
const doc = univerAPI.getActiveDocument()
const codes = doc?.getCodes() ?? []
```

### Вставка блока кода

```typescript
const doc = univerAPI.getActiveDocument()
const code = doc?.insertCode({
  startOffset: 12,
  endOffset: 35,
})
```

### Выход из блока кода

```typescript
const doc = univerAPI.getActiveDocument()
doc?.exitCode()
```

### Отмена пустого абзаца с кодом

```typescript
const doc = univerAPI.getActiveDocument()
doc?.cancelEmptyCodeParagraph()
```

## Моноширинные шрифты кода [#code-fonts]

Сборщик шрифтов в панели инструментов блока кода перечисляет только шрифты, зарегистрированные в `FontCategory.MONOSPACE`.Выбор шрифта применяется ко всему блоку кода, включая его стили абзацев.

Чтобы зарегистрировать пользовательский монопространственный шрифт, позвоните в `addFonts()`:

```ts
import { FontCategory } from '@univerjs/ui'
import '@univerjs/ui/facade'

univerAPI.addFonts([
  { value: 'JetBrains Mono', label: 'JetBrains Mono', category: FontCategory.MONOSPACE },
])
```

Регистрация только добавляет запись в пикер. Сам файл шрифта должен быть загружен CSS или браузером FontFace API, как описано в [шрифты на заказ](/guides/docs/ui/fonts). Этот метод работает как с плагином, так и с предустановленной инициализацией.
