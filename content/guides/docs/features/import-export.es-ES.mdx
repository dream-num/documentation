Las API de esta página requieren un backend de conversión. Siga [integración del intercambio de archivos](/server/import-export) para conectar cargas, conversiones, consultas de tareas y descargas, luego configure los plugins del navegador. Las API de Snapshot también requieren que backend, pero no requieren un documento de colaboración. El ejemplo de Exchange muestra hojas, así que verifique que la versión de destino soporta los tipos de archivos necesarios.

Si una exportación falla, vea [códigos de error de licencia y manejo de fallos de tarea](/server/import-export#export-errors).

## Formatos compatibles

La tabla describe las APIs del navegador en esta página. La conversión de archivo de Office también requiere un backend que soporta el mismo tipo de documento y formato.

| Importación | Exportación |
| --- | --- |
| `.doc`, `.docx` | `.docx` |

Tanto `.doc` como `.docx` utilizan las API de importación a continuación. Exportar siempre produce `.docx`; el formato `.doc` legado no se puede exportar.

## Fachada API

### Importación

<Callout type="info" title="Nota del modo Plugin">
  Sólo el modo plugin requiere importar manualmente el paquete Facade. El modo Preset ya incluye el paquete Facha correspondiente, por lo que no se necesita ninguna importación adicional.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/docs-exchange-client/facade'
```

### Importando `.docx`

#### Importe el archivo `.docx` y obtenga `unitId`

<Callout type="warning" title="Precaución">
  Este método requiere colaboración, ya que crea un documento en el servidor y devuelve un `unitId`. Si la colaboración no está activada, utilice la importación de instantáneas.
</Callout>

Cuando la edición colaborativa está habilitada, cada documento tiene un `unitId` único. Llame a `univerAPI.importDocToUnitIdAsync` con el parámetro `file` y devuelve el `unitId`, que se utiliza para acceder al documento. El parámetro `file` acepta un objeto `File` o una URL de archivo remoto.

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importDocToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadDocAsync(unitId)
}
```

#### Importe el archivo `.docx` y obtenga `IDocumentData`

<Callout>La importación de instantáneas no requiere colaboración. Utilice la importación de `unitId` cuando el documento requiere colaboración.</Callout>

`univerAPI.importDocToSnapshotAsync` importa un archivo `.docx` y devuelve los datos del documento como `IDocumentData`.

```typescript
// Accept a File object
const snapshot = await univerAPI.importDocToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importDocToSnapshotAsync('https://example.com/filename.docx');

// Create a new document via snapshot
if (snapshot) univerAPI.createDocument(snapshot)
```

### Exportando `.docx`

#### Exportar archivo `.docx` usando `unitId`

<Callout type="warning" title="Caution">
  La exportación `unitId` requiere colaboración. Si la colaboración no está habilitada, utilice la exportación de
  instantáneas.
</Callout>

Cuando la edición colaborativa está habilitada, cada documento tiene un `unitId` único. Llame a `univerAPI.exportDocByUnitIdAsync` con el parámetro `unitId` para recibir un objeto `File`.

```typescript
const fDocument = univerAPI.getActiveDocument()
const unitId = fDocument.getId()
const file = await univerAPI.exportDocByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

#### Exportar el archivo `.docx` usando `IDocumentData`

<Callout>La exportación de instantáneas no requiere colaboración y es adecuada para flujos de trabajo locales.</Callout>

`univerAPI.exportDocBySnapshotAsync` acepta `IDocumentData` y devuelve un objeto `File`.

```typescript
const fDocument = univerAPI.getActiveDocument()
const snapshot = fDocument.save()
const file = await univerAPI.exportDocBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

## Eliminación de los menús y las interacciones de UI de importación y exportación integrados [#import-export-ui-migration]

<Callout type="warning" title="Nota">
  A partir de la versión **1.2.0**, Univer ya no incluye menús integrados de importación/exportación o interacciones UI. Los servicios subyacentes y las API de Facade permanecen disponibles.
</Callout>

Si la aplicación todavía requiere esos menús e interacciones de la interfaz de usuario, el [ejemplo de migración para menús integrados de importación/exportación e interacciones de la UI](https://office.univer.ai/showcase/docs/custom-import-export) muestra cómo moverlos en un plugin personalizado. El ejemplo incluye el código fuente completo, que se puede ver en línea o descargar.
