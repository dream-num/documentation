<Callout type="warning" title="Caution">
  La funcionalidad de importación y exportación requiere soporte de Univer servidor. Asegúrese de haber instalado y
  configurado correctamente el servidor Univer. Para obtener más información, consulte: [Actualización a
  Pro](/guides/pro)
</Callout>

La función de importación y exportación permite a los usuarios importar archivos `.docx` a documentos de Univer o exportar contenido de documentos como archivos `.docx` a través del servidor de Univer, lo que facilita la interacción con otro software o plataformas de oficina.

<Callout title="Why does Univer implement import and export through backend services?">
  La importación y exportación implementadas únicamente a través del frontend no pueden satisfacer las necesidades
  empresariales en términos de rendimiento y resultados. Por lo tanto, brindamos servicios de backend para implementar
  la funcionalidad de importación y exportación. Puede utilizar bibliotecas de análisis DOCX de código abierto para
  analizar archivos en estructuras de datos que se ajusten a la interfaz `IDocumentData` y luego utilizar la API de
  Facade para importar datos a Univer.
</Callout>

Después de importar exitosamente a través de la entrada de importación en la barra de menú, aparecerá una notificación en la esquina inferior izquierda de la página, mostrando información sobre la importación exitosa y proporcionando un enlace para acceder al documento importado. Si el comportamiento predeterminado de importación y exportación no satisface sus necesidades, consulte [Documentos de importación personalizados](/blog/custom-import) para aprender cómo personalizar el comportamiento de importación.

## Cómo elegir Importar/Exportar

Hay dos rutas, dependiendo de si se requiere colaboración:

| Ruta            | Requiere colaboración | Mejor para                                                               | API                                                     |
| --------------- | --------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------- |
| By `unitId`     | Yes                   | Documentos colaborativos que persisten en el tablero servidor            | `importDocToUnitIdAsync` / `exportDocByUnitIdAsync`     |
| Por instantánea | No                    | Flujos de trabajo locales o fuera de línea, o solo conversión de formato | `importDocToSnapshotAsync` / `exportDocBySnapshotAsync` |

Si su proyecto utiliza colaboración (documentos persistentes en el servidor abiertos a través de `unitId`), elija la `unitId` ruta. De lo contrario, utilice la ruta de la instantánea.

## Modo preestablecido

### Instalación

<Callout>
  El valor preestablecido `UniverDocsAdvancedPreset` de `@univerjs/preset-docs-advanced` depende del valor
  preestablecido `UniverDocsDrawingPreset` en tiempo de ejecución. Primero instale `@univerjs/preset-docs-drawing`.
</Callout>

```package-install
npm install @univerjs/preset-docs-drawing @univerjs/preset-docs-advanced
```

### Uso

```typescript
import { UniverDocsAdvancedPreset } from '@univerjs/preset-docs-advanced' // [!code ++]
import UniverPresetDocsAdvancedEnUS from '@univerjs/preset-docs-advanced/locales/en-US' // [!code ++]
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEnUS from '@univerjs/preset-docs-core/locales/en-US'
import { UniverDocsDrawingPreset } from '@univerjs/preset-docs-drawing' // [!code ++]
import UniverPresetDocsDrawingEnUS from '@univerjs/preset-docs-drawing/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-docs-advanced/lib/index.css' // [!code ++]

const { univer, univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetDocsCoreEnUS,
      UniverPresetDocsDrawingEnUS, // [!code ++]
      UniverPresetDocsAdvancedEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
    UniverDocsDrawingPreset(), // [!code ++]
    UniverDocsAdvancedPreset({
      // [!code ++]
      universerEndpoint: 'http://localhost:3010', // [!code ++]
    }), // [!code ++]
  ],
})
```

Si tiene una licencia comercial para Univer, consulte [Uso de la licencia en el cliente](/guides/pro/license#in-preset-mode) para la configuración.

### Preajustes y configuración

```typescript
interface IUniverSheetsAdvancedPresetConfig {
  // This is the endpoint for the Univer server
  universerEndpoint?: string
}
```

## Complemento Modo

### Instalación

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/docs-exchange-client
```

### Uso

```typescript
import { UniverDocsExchangeClientPlugin } from '@univerjs-pro/docs-exchange-client' // [!code ++]
import DocsExchangeClientEnUS from '@univerjs-pro/docs-exchange-client/locale/en-US' // [!code ++]
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client' // [!code ++]
import ExchangeClientEnUS from '@univerjs-pro/exchange-client/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/exchange-client/facade' // [!code ++]
import '@univerjs-pro/docs-exchange-client/facade' // [!code ++]

import '@univerjs-pro/exchange-client/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      ExchangeClientEnUS, // [!code ++]
      DocsExchangeClientEnUS, // [!code ++]
    ),
  },
})

const UNIVER_SERVER_ENDPOINT = `http://localhost:8000` // [!code ++]

univer.registerPlugin(UniverExchangeClientPlugin, {
  // [!code ++]
  uploadFileServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/stream/file/upload`, // [!code ++]
  importServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/exchange/{type}/import`, // [!code ++]
  exportServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/exchange/{type}/export`, // [!code ++]
  getTaskServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/exchange/task/{taskID}`, // [!code ++]
  signUrlServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/file/{fileID}/sign-url`, // [!code ++]
  downloadEndpointUrl: `${UNIVER_SERVER_ENDPOINT}/`, // [!code ++]
}) // [!code ++]
univer.registerPlugin(UniverDocsExchangeClientPlugin) // [!code ++]
```

Si tiene una licencia comercial de Univer, consulte [Uso de la licencia en el cliente](/guides/pro/license#in-plugin-mode) para la configuración.

### Complementos y configuración

Las opciones de configuración para `UniverExchangeClientPlugin` son las siguientes:

interface IUniverExchangeClientConfig {

## Fachada API

### Importación

<Callout type="info" title="Plugin mode note">
  Sólo el modo complemento requiere importar manualmente el paquete Facade. El modo Preestablecido ya incluye el paquete
  Fachada correspondiente, por lo que no se necesita ninguna importación adicional.
</Callout>

### Importar

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/docs-exchange-client/facade'
```

### Importando `.docx`

#### Importe el archivo `.docx` y obtenga `unitId`

<Callout type="warning" title="Caution">
  Este método requiere colaboración: crea un documento de servidor y devuelve un `unitId`. Utilice la importación de
  instantáneas si la colaboración no está habilitada.
</Callout>

Cuando la edición colaborativa está habilitada, cada documento tiene un `unitId` único. El uso de `univerAPI.importDocToUnitIdAsync` con el parámetro `file` devolverá el `unitId`, que se puede utilizar para acceder al documento. El parámetro `file` puede ser un objeto `File` o una URL de archivo remoto.

```typescript
// Accept a File object
const unitId = await univerAPI.importDocToUnitIdAsync(file)
// Or accept a remote file URL
// const unitId = await univerAPI.importDocToUnitIdAsync('https://example.com/filename.docx');

// Using with collaborative editing to automatically load data https://docs.univer.ai/en-US/guides/docs/features/collaboration#loading-collaborative-documents
const url = new URL(window.location.href)
url.searchParams.set('unit', unitId)
url.searchParams.set('type', '1') // The meaning of 1 is UniverInstanceType.UNIVER_DOC
window.location.href = url.toString()

// Or call the API: univerAPI.loadServerUnit(unitId, 1) to load the document, refer to /reference/facade/univer#loadserverunit for specific parameters
```

#### Importe el archivo `.docx` y obtenga `IDocumentData`

<Callout>
  La importación de instantáneas no requiere colaboración. Utilice la importación `unitId` para documentos
  colaborativos.
</Callout>

Utilizar `univerAPI.importDocToSnapshotAsync` para importar un archivo `.docx` devolverá los datos del documento en el formato `IDocumentData`.

```typescript
// Accept a File object
const snapshot = await univerAPI.importDocToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importDocToSnapshotAsync('https://example.com/filename.docx');

// Create a new document via snapshot
univerAPI.createDocument(snapshot)
```

### Exportando `.docx`

#### Exportar archivo `.docx` usando `unitId`

<Callout type="warning" title="Caution">
  La exportación `unitId` requiere colaboración. Si la colaboración no está habilitada, utilice la exportación de
  instantáneas.
</Callout>

Cuando la edición colaborativa está habilitada, cada documento tiene un `unitId` único. El uso de `univerAPI.exportDocByUnitIdAsync` con el parámetro `unitId` devolverá un objeto `File`.

```typescript
const fDocument = univerAPI.getActiveDocument()
const unitId = fDocument.getId()
const file = await univerAPI.exportDocByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

#### Exportar el archivo `.docx` usando `IDocumentData`

<Callout>La exportación de instantáneas no requiere colaboración y es adecuada para flujos de trabajo locales.</Callout>

El uso de `univerAPI.exportDocBySnapshotAsync` con `IDocumentData` devolverá un `File` objeto.

```typescript
const fDocument = univerAPI.getActiveDocument()
const snapshot = fDocument.save()
const file = await univerAPI.exportDocBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```
