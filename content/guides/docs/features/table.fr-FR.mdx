Les tables améliorées fournissent une édition complète de la table dans Univer Docs : style cellulaire, bordures, changements de lignes et de colonnes, et remplissant une table à partir de données.

## Introduction

Dans Univer Docs, les tableaux supportent les opérations suivantes :

- Créez une table avec les dimensions que vous spécifiez.
- Ajouter, supprimer et déplacer les lignes et les colonnes.
- Appliquer les bordures, les fonds et le formatage de texte aux cellules.
- Fusionner et diviser les cellules pour construire des configurations complexes.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### Utilisation

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIEnUS from '@univerjs-pro/docs-table-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsTableUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

Si vous utilisez une licence commerciale, configurez-la comme décrit dans [Utilisation de la licence dans le client](/server/license#in-plugin-mode).

## API Facade

Importez la façade avant d'utiliser l'une des API suivantes :

```typescript
import '@univerjs-pro/docs-table/facade'
```

### Insérer un tableau

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### Insérer un tableau à partir de données

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### Obtenir tous les tableaux

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### Supprimer un tableau

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```

## Bordures de tableau [#table-borders]

Sélectionnez une table ou ses cellules pour ouvrir l'onglet Table contextuelle. Le sélectionneur de bordures fournit des préréglages pour tous, extérieur, intérieur, à l'extrémité individuelle et aucune bordure, ainsi que des contrôles pour la couleur, la largeur et le style de ligne. `UniverDocsTableUIPlugin` fournit ces contrôles.

## Édition, historique et collaboration [#editing-history]

`setTableStyle()` combine les changements de fond et de bordure en une seule entrée d'historique. `setColumnType()` est également impossible à faire et synchronisé, et les types de colonnes suivent leurs colonnes lorsque les colonnes se déplacent. `setCellText()` remplace toute la valeur de la cellule: remplacements simultanés se résolvent comme valeurs atomiques, tandis que les modifications de caractères ordinaires utilisent le texte OT. Si un contrôle de contenu verrouillé rejette une modification de cellule, l'appel retourne `false` et ne consomme pas l'historique d'undo/redo.

## Aligner le tableau entier [#table-alignment]

Dans un document traditionnel, sélectionnez une table et utilisez **Tableau → Alignement de la table** sur le ruban pour placer la table à gauche, au centre ou à droite de la zone de contenu de la page. Ce réglage déplace la table elle-même et ne modifie pas l'alignement du texte à l'intérieur des cellules.

La valeur est stockée dans `tableSource[tableId].align` et prend en charge l'annulation/redo et l'enregistrement. Après l'enregistrement du plugin table, la même action est disponible via la commande publique ci-dessous. Passez un ID de table existant à partir de l'instantané du document. `false`.

```ts
import { DocsTableSetTableAlignCommand } from '@univerjs-pro/docs-table'
import { TableAlignmentType } from '@univerjs/core'

const aligned = await univerAPI.executeCommand(DocsTableSetTableAlignCommand.id, {
  unitId: documentId,
  tableId,
  value: TableAlignmentType.CENTER,
})
```
