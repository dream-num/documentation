La fonctionnalité de tableaux avancés enrichit Univer Docs avec des outils complets de modification des tableaux, notamment la mise en forme des cellules, la personnalisation des bordures, la manipulation des lignes et des colonnes et l’insertion de données.

## Introduction

Dans Univer Docs, les tableaux avancés vous permettent de :

- **Insérer des tableaux par programmation** : créez des tableaux aux dimensions définies.
- **Modifier la structure** : ajoutez, supprimez et déplacez des lignes et des colonnes.
- **Mettre en forme les cellules** : appliquez des bordures, des arrière-plans et une mise en forme du texte.
- **Fusionner et fractionner des cellules** : combinez des cellules pour créer des mises en page complexes.

## Mode plugin

### Installation

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### Utilisation

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIEnUS from '@univerjs-pro/docs-table-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsTableUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

Si vous disposez d’une licence commerciale Univer, consultez la page [Utiliser une licence côté client](/server/license#in-plugin-mode) pour savoir comment la configurer.

## API Facade

Veillez à importer la facade avant d’utiliser l’API :

```typescript
import '@univerjs-pro/docs-table/facade'
```

### Insérer un tableau

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### Insérer un tableau à partir de données

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### Obtenir tous les tableaux

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### Supprimer un tableau

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```

## Bordures de tableau [#table-borders]

Sélectionnez un tableau ou ses cellules pour ouvrir l’onglet contextuel Tableau. Le sélecteur propose toutes les bordures, les bordures extérieures, intérieures, individuelles ou aucune, ainsi que leur couleur, épaisseur et style. Ces contrôles sont fournis par `UniverDocsTableUIPlugin`.

## Édition, historique et collaboration [#editing-history]

Les setters et modifications structurelles des tables passent par des commandes avec annuler/rétablir et collaboration. `setTableStyle()` regroupe fond et bordure en une entrée d’historique. `setColumnType()` est aussi annulable et synchronisé ; les types suivent les colonnes déplacées. `setCellText()` remplace la valeur complète : les remplacements simultanés utilisent une résolution atomique, tandis que les éditions de caractères utilisent l’OT texte. Une modification refusée par un contrôle de contenu verrouillé renvoie `false` sans consommer l’historique.

## Aligner le tableau entier [#table-alignment]

Dans un document Traditional, sélectionnez un tableau puis utilisez son menu d’alignement dans le Ribbon pour le placer à gauche, au centre ou à droite de la zone de contenu. Cela déplace le tableau sans modifier l’alignement du texte des cellules. Le contrôle est désactivé dans les documents Modern.

La valeur est enregistrée dans `tableSource[tableId].align` et prend en charge annulation, rétablissement et sauvegarde. Après enregistrement du plugin de tableaux, utilisez la commande publique ci-dessous avec un ID de tableau existant dans le snapshot. Une cible invalide, un document désactivé ou Modern renvoie `false`.

```ts
import { DocsTableSetTableAlignCommand } from '@univerjs-pro/docs-table'
import { TableAlignmentType } from '@univerjs/core'

const aligned = await univerAPI.executeCommand(DocsTableSetTableAlignCommand.id, {
  unitId: documentId,
  tableId,
  value: TableAlignmentType.CENTER,
})
```
