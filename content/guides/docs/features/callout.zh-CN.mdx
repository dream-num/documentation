标注块将一段重要信息与周围正文分开呈现。图标和颜色均可配置，因此说明、警告和提示可以各自呈现不同的外观。

## 介绍

在 Univer Docs 中，标注块有三个用途：

- 将读者的注意力引向重要说明、警告或提示。
- 应用为标注块选择的图标和配色，使其外观与内容一致。
- 将文档划分为视觉上相互独立、可单独阅读的区段。

## 插件模式

### 安装

```package-install
npm install @univerjs-pro/docs-callout @univerjs-pro/docs-callout-ui
```

### 使用

```typescript
import { UniverDocsCalloutPlugin } from '@univerjs-pro/docs-callout' // [!code ++]
import { UniverDocsCalloutUIPlugin } from '@univerjs-pro/docs-callout-ui' // [!code ++]
import DocsCalloutUIZhCN from '@univerjs-pro/docs-callout-ui/locale/zh-CN' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-callout-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.ZH_CN,
  locales: {
    [LocaleType.ZH_CN]: mergeLocales(
      DocsCalloutUIZhCN, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsCalloutPlugin) // [!code ++]
univer.registerPlugin(UniverDocsCalloutUIPlugin) // [!code ++]
```

使用 Univer 商业许可证时，按[在客户端使用许可证](/server/license#in-plugin-mode)中的说明完成配置。

## 移动端适配 [#mobile-support]

请先配置[移动端编辑器](/guides/docs/getting-started/installation#mobile-support)。在本页插件模式的初始化代码中，将下列桌面端注册替换为同一个包导出的移动端插件，替换须在**打开文档前**完成。模型插件、样式、语言包和 Facade 导入均需保留，不要同时注册两个版本。

| 来源包 | 桌面端注册 | 移动端注册 |
| --- | --- | --- |
| `@univerjs-pro/docs-callout-ui` | `UniverDocsCalloutUIPlugin` | `UniverDocsCalloutMobileUIPlugin` |

## Facade API

调用 API 前需先导入 facade：

```typescript
import '@univerjs-pro/docs-callout/facade'
```

### 获取所有标注块

```typescript
const doc = univerAPI.getActiveDocument()
const callouts = doc?.getCallouts() ?? []
```

### 根据 ID 获取标注块

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.getCallout('callout-block-id')
```

### 插入标注块

```typescript
const doc = univerAPI.getActiveDocument()
const callout = doc?.insertCallout({
  startOffset: 12,
  endOffset: 35,
  config: { icon: '💡' },
})
```

### 更新标注块配置

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.updateConfig({ icon: '⚠️' })
```

### 设置标注块外观

```typescript
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.setIcon('📝')
callout?.setBackgroundColor('#FFF4E5')
callout?.setBorder({ color: '#E6A23C', width: 2 })
callout?.setTextColor('#5C3B00')
```

外观修改通过文档命令执行，因此撤销、重做和协同编辑都能获取这些变更。`setTextColor()` 为标注块内的全部文字设置颜色；调用 `resetTextColor()` 可移除此覆盖，并恢复从文档继承的文字颜色。

```ts
const callout = univerAPI.getActiveDocument()?.getCallout('callout-block-id')
callout?.resetTextColor()
```
