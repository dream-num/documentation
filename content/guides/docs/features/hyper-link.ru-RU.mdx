Гиперссылка указывает от документа к внешней веб-странице, адресу электронной почты или другому контенту.

## Режим плагина

### Установка

```package-install
npm install @univerjs/docs-hyper-link @univerjs/docs-hyper-link-ui
```

### Использование

```typescript
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { UniverDocsHyperLinkPlugin } from '@univerjs/docs-hyper-link' // [!code ++]
import { UniverDocsHyperLinkUIPlugin } from '@univerjs/docs-hyper-link-ui' // [!code ++]
import DocsHyperLinkUIRuRU from '@univerjs/docs-hyper-link-ui/locale/ru-RU' // [!code ++]

import '@univerjs/docs-hyper-link-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.RU_RU,
  locales: {
    [LocaleType.RU_RU]: mergeLocales(
      DocsHyperLinkUIRuRU, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsHyperLinkPlugin) // [!code ++]
univer.registerPlugin(UniverDocsHyperLinkUIPlugin) // [!code ++]
```

## Поддержка мобильных устройств [#mobile-support]

Сначала настройте [Мобильный редактор](/guides/docs/getting-started/installation#mobile-support). В настройке плагин-режима на этой странице замените регистрацию рабочего стола ниже на мобильный экспорт из тех же пакетов, и сделайте это **Перед тем, как открыть документ**, сохраните плагины модели, стили, локализации и импорт Facade и не регистрируйте оба варианта.

## Режим предустановки

### Установка

```package-install
npm install @univerjs/preset-docs-hyper-link
```

### Использование

```typescript
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreRuRU from '@univerjs/preset-docs-core/locales/ru-RU'
import { UniverDocsHyperLinkPreset } from '@univerjs/preset-docs-hyper-link' // [!code ++]
import UniverPresetDocsHyperLinkRuRU from '@univerjs/preset-docs-hyper-link/locales/ru-RU' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-hyper-link/lib/index.css' // [!code ++]

const { univerAPI } = createUniver({
  locale: LocaleType.RU_RU,
  locales: {
    [LocaleType.RU_RU]: mergeLocales(
      UniverPresetDocsCoreRuRU,
      UniverPresetDocsHyperLinkRuRU, // [!code ++]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
    UniverDocsHyperLinkPreset(), // [!code ++]
  ],
})
```

## Создание и редактирование ссылок через Facade API

`link(text, url)` добавляет связанный текст и записывает диапазон, который он охватывает, поэтому смещения символов не должны рассчитываться вручную. Чтобы изменить пункт назначения позже, передайте идентификатор диапазона, возвращенный `getLinks()`.

```ts
const richText = univerAPI
  .newRichText()
  .text('Read ')
  .link('Univer Office SDK documentation', 'https://docs.univer.ai')
  .text(' for details.')

const [link] = richText.getLinks()
if (!link) throw new Error('Link was not created')

richText.updateLink(link.rangeId, 'https://docs.univer.ai/guides')
```

`removeLink(link.rangeId)` удаляет пункт назначения и сохраняет видимый текст.
