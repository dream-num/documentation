Docs хранит источник формулы LaTeX в виде редактируемого контента в модели документа и отображает его в редакторе браузера.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/docs-latex @univerjs-pro/docs-latex-ui
```

### Использование

```typescript
import { UniverDocsLatexPlugin } from '@univerjs-pro/docs-latex' // [!code ++]
import { UniverDocsLatexUIPlugin } from '@univerjs-pro/docs-latex-ui' // [!code ++]
import DocsLatexUIEnUS from '@univerjs-pro/docs-latex-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-latex-ui/lib/index.css' // [!code ++]
import '@univerjs-pro/docs-latex/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsLatexUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsLatexPlugin) // [!code ++]
univer.registerPlugin(UniverDocsLatexUIPlugin) // [!code ++]
```

Если у вас есть коммерческая лицензия на Univer, обратитесь к [Использование лицензии у клиента](/server/license#in-plugin-mode) для настройки.

## Поддержка мобильных устройств [#mobile-support]

Сначала настройте [Мобильный редактор](/guides/docs/getting-started/installation#mobile-support). В настройках плагин-режима, описанных на этой странице, замените регистрацию рабочего стола ниже мобильным экспортом из тех же пакетов и заполните замену **Перед тем, как открыть документ** . Держите плагины модели, стили, локализации и импорт Facade неизменными и не регистрируйте оба варианта.

| Пакет | Настольная регистрация | Мобильная регистрация |
| --- | --- | --- |
| `@univerjs-pro/docs-latex-ui` | `UniverDocsLatexUIPlugin` | `UniverDocsLatexMobileUIPlugin` |

## Facade API

Импортируйте вход на фасад перед вызовом любого API LaTeX:

```typescript
import '@univerjs-pro/docs-latex/facade'
```

Вставьте формулу в активный документ:

```typescript
const doc = univerAPI.getActiveDocument()

const formula = doc?.insertLatexFormula({
  latex: 'E=mc^2',
  index: 12,
})
```

Получите и измените формулы:

```typescript
const formulas = doc?.getLatexFormulas() ?? []
const firstFormula = doc?.findLatexFormulaByText('mc')

firstFormula?.update({
  latex: '\\frac{a}{b}',
})
```

Формулу также можно извлечь по идентификатору диапазона или по его смещению в потоке данных документа:

```typescript
const byId = doc?.getLatexFormula('formula-range-id')
const atOffset = doc?.getLatexFormulaAt(42)

console.log(byId?.describe(), atOffset?.getLatex())
```
