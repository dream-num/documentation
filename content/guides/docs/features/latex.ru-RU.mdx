Функция формул LaTeX позволяет хранить в модели документа редактируемый исходный код формулы и отображать её в браузерном редакторе Docs.

## Режим плагинов

### Установка

```package-install
npm install @univerjs-pro/docs-latex @univerjs-pro/docs-latex-ui
```

### Использование

```typescript
import { UniverDocsLatexPlugin } from '@univerjs-pro/docs-latex' // [!code ++]
import { UniverDocsLatexUIPlugin } from '@univerjs-pro/docs-latex-ui' // [!code ++]
import DocsLatexUIEnUS from '@univerjs-pro/docs-latex-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-latex-ui/lib/index.css' // [!code ++]
import '@univerjs-pro/docs-latex/facade' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsLatexUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsLatexPlugin) // [!code ++]
univer.registerPlugin(UniverDocsLatexUIPlugin) // [!code ++]
```

Если у вас есть коммерческая лицензия Univer, инструкции по настройке см. в разделе [Использование лицензии на клиенте](/guides/pro/license#in-plugin-mode).

## Facade API

Перед вызовом API LaTeX импортируйте точку входа facade:

```typescript
import '@univerjs-pro/docs-latex/facade'
```

Вставьте формулу в активный документ:

```typescript
const doc = univerAPI.getActiveDocument()

const formula = doc?.insertLatexFormula({
  latex: 'E=mc^2',
  index: 12,
})
```

Получите и измените формулы:

```typescript
const formulas = doc?.getLatexFormulas() ?? []
const firstFormula = doc?.findLatexFormulaByText('mc')

firstFormula?.update({
  latex: '\\frac{a}{b}',
})
```

Формулы также можно искать по идентификатору диапазона или смещению в потоке данных документа:

```typescript
const byId = doc?.getLatexFormula('formula-range-id')
const atOffset = doc?.getLatexFormulaAt(42)

console.log(byId?.describe(), atOffset?.getLatex())
```
