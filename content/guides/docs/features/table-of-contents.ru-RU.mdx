Таблица содержимого записывает записи для заголовков в корпус документа и отделена от панели навигации контуров. Добавьте эти два плагина в настройку ядра Docs перед созданием документа, объедините локализацию пользовательского интерфейса в `locales` и загрузите таблицу стилей. Ни ядро Docs, ни расширенный предустановленный набор Docs не включают их.

Оглавление доступно в традиционных документах. В современных документах Univer скрывает меню оглавления.

```package-install
npm install @univerjs/docs-toc @univerjs/docs-toc-ui
```

```ts
import { UniverDocsTocPlugin } from '@univerjs/docs-toc'
import { UniverDocsTocUIPlugin } from '@univerjs/docs-toc-ui'
import FeatureLocale from '@univerjs/docs-toc-ui/locale/ru-RU'
import { LocaleType } from '@univerjs/core'

import '@univerjs/docs-toc-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.RU_RU, FeatureLocale)

univer.registerPlugin(UniverDocsTocPlugin)
univer.registerPlugin(UniverDocsTocUIPlugin)
```

## Вставка и обновление [#commands]

Поместите курсор в документ перед вставкой. UI обрабатывает вставку, полные обновления, обновления только для страниц и удаление. Когда `rangeId` не пройден, обновление нацелено на таблицу содержимого при текущем выборе.

```ts
import { InsertTableOfContentsCommand, UpdateTableOfContentsCommand } from '@univerjs/docs-toc'

await univerAPI.executeCommand(InsertTableOfContentsCommand.id, {
  levels: 3,
  showPageNumbers: true,
  rightAlignPageNumbers: true,
})
await univerAPI.executeCommand(UpdateTableOfContentsCommand.id, { mode: 'entireTable' })
```

Обновитель оценивает инструкции таблицы содержимого на уровне контуров (`\o`). Другие переключатели Word из импортированного файла остаются в метаданных FIELD, но не все из них оцениваются. См. [Командные параметры](/reference/packages/plugins/univerjs/docs-toc).
