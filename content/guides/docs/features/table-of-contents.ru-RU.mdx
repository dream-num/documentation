Оглавление вставляет заголовки в тело документа и отличается от панели навигации. Добавьте плагины к Docs Core до создания документа, объедините локаль UI с `locales` и подключите CSS. Пресеты Core и Advanced их не включают.

```package-install
npm install @univerjs/docs-toc @univerjs/docs-toc-ui
```

```ts
import { UniverDocsTocPlugin } from '@univerjs/docs-toc'
import { UniverDocsTocUIPlugin } from '@univerjs/docs-toc-ui'
import FeatureLocale from '@univerjs/docs-toc-ui/locale/ru-RU'
import { LocaleType } from '@univerjs/core'

import '@univerjs/docs-toc-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.RU_RU, FeatureLocale)

univer.registerPlugin(UniverDocsTocPlugin)
univer.registerPlugin(UniverDocsTocUIPlugin)
```

## Вставка и обновление [#commands]

Перед вставкой поместите курсор в документ. UI поддерживает вставку, полное обновление, обновление только номеров страниц и удаление. Без `rangeId` обновляется оглавление в текущем выделении.

```ts
import { InsertTableOfContentsCommand, UpdateTableOfContentsCommand } from '@univerjs/docs-toc'

await univerAPI.executeCommand(InsertTableOfContentsCommand.id, {
  levels: 3,
  showPageNumbers: true,
  rightAlignPageNumbers: true,
})
await univerAPI.executeCommand(UpdateTableOfContentsCommand.id, { mode: 'entireTable' })
```

Обновление вычисляет инструкции по уровням структуры (`\o`). Другие переключатели Word сохраняются в метаданных FIELD, но не все вычисляются. См. [параметры команд](/reference/packages/plugins/univerjs/docs-toc).
