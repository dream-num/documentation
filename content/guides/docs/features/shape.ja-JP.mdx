形状の特徴は、基本的な幾何学的な形状と矢印からフローチャート要素まで、文書内の図面をインサートし、編集します。

## はじめに

Univer Docs では、以下の操作をサポートしています。

- 長方形、円、矢印、その他の単純な形状を追加します。
- 塗りつぶしの色、境界、テキストを調節します。
- 文書のどこにでも形を置きます。

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/engine-formula @univerjs-pro/docs-shape @univerjs-pro/docs-shape-ui
```

<Callout type="warn">
  形状は、`@univerjs-pro/engine-formula`から`UniverProFormulaEnginePlugin`も必要です。 ベースセットアップでは、既存の`UniverFormulaEnginePlugin`のインポートとこのプラグインで登録を交換します。 両方の式エンジンを登録しないでください。そのため、形状のインサートが不足している依存エラーで失敗する可能性があります。
</Callout>

### 使用法

```typescript
import { UniverDocsShapePlugin } from '@univerjs-pro/docs-shape' // [!code ++]
import { UniverDocsShapeUIPlugin } from '@univerjs-pro/docs-shape-ui' // [!code ++]
import DocsShapeUIJaJP from '@univerjs-pro/docs-shape-ui/locale/ja-JP' // [!code ++]
import { UniverProFormulaEnginePlugin } from '@univerjs-pro/engine-formula' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-shape-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsShapeUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverProFormulaEnginePlugin) // [!code ++]
univer.registerPlugin(UniverDocsShapePlugin) // [!code ++]
univer.registerPlugin(UniverDocsShapeUIPlugin) // [!code ++]
```

商用ライセンスを使用する場合は、[クライアントでのライセンスの使用](/server/license#in-plugin-mode) で説明するように設定します。

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/docs/getting-started/installation#mobile-support)を最初に構成します。 このページに記載されているプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換え、**ドキュメントを開く前に**を実行します。 モデルプラグイン、スタイル、ロケール、ファサードのインポートをキープし、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/docs-shape-ui` | `UniverDocsShapeUIPlugin` | `UniverDocsShapeMobileUIPlugin` |

## 図形のテキストを編集する

`insertShape()` が返した形状のオブジェクトで、以下または以前の例で動作します。 `getText()`は、ライブ [FShapeText(ファシェプテキスト)](/reference/facade/shape-text)ハンドルを返します。 `getPlainText()`でプレーンテキストを読み、`setText()`とすべてのものを交換し、フォント、色、およびアライメントメソッドを通してフォーマットを適用します。

```ts
import '@univerjs-pro/docs-shape/facade'

const document = univerAPI.getActiveDocument()
const paragraph = document?.getParagraphs()[0]
if (!document || !paragraph) throw new Error('No active document paragraph')
const shape = document.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.Rect,
  placement: {
    wrappingStyle: univerAPI.Enum.TextWrappingStyle.INLINE,
    anchor: { paragraphId: paragraph.getId(), segmentId: paragraph.getSegmentId() },
  },
})
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()`は既存のテキストを置き換えます。 1つの形状がいくつかのスタイルを必要とするときに`setRichText()`を使用します。 既存のリッチテキストを変更するには、`getRichText()?.copy()`を呼び出し、ビルダーを編集し、`setRichText()`に渡します。 その分離されたビルダーに編集は、自分で適用されません。 より多くのオプションは[テキストスタイル](/reference/facade/shape-text#settextstyle)と[テキスト ボックスのパディングとレイアウト](/reference/facade/shape-text#settextboxoptions)で利用可能です。

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## 図形の書式コピー [#format-painter]

ソースの形状を選択し、フォーマットの画家をオンにして、ターゲットの形状を選択します。 画家は、塗りつぶし、ストローク、エフェクト、およびサポートされているテキストのフォーマットをコピーし、対象のアイデンティティ、幾何学、テキストコンテンツ、および式結合を変更しないままにします。 フォーマットをクリアすると、インサートで使用されるデフォルトを復元します。 SmartArtは除外されます。 形状 UI プラグインは、この動作を自動的に登録します。
