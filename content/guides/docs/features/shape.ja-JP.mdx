図形機能を使用すると、ドキュメント内に図形や描画を挿入して編集できます。基本的な幾何学的図形、矢印、フローチャート要素などが含まれます。

## はじめに

Univer Docs では、図形を使用して以下ができます：

- **幾何学的図形を挿入**：長方形、円、矢印などを追加します。
- **外観をカスタマイズ**：塗りつぶし色、枠線、テキストを調整します。
- **自由に配置**：図形をドキュメント内の任意の場所に配置します。

## プラグインモード

### インストール

```package-install
npm install @univerjs-pro/docs-shape @univerjs-pro/docs-shape-ui
```

### 使用法

```typescript
import { UniverDocsShapePlugin } from '@univerjs-pro/docs-shape' // [!code ++]
import { UniverDocsShapeUIPlugin } from '@univerjs-pro/docs-shape-ui' // [!code ++]
import DocsShapeUIJaJP from '@univerjs-pro/docs-shape-ui/locale/ja-JP' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/docs-shape-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: mergeLocales(
      DocsShapeUIJaJP, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsShapePlugin) // [!code ++]
univer.registerPlugin(UniverDocsShapeUIPlugin) // [!code ++]
```
