<Callout type="warning" title="주의">
  가져오기 및 내보내기 기능을 사용하려면 Univer 서버의 지원이 필요합니다. Univer 서버가 올바르게 설치되고 구성되었는지
  확인하세요. 자세한 내용은 [Pro로 업그레이드하기](/guides/pro)를 참고하세요.
</Callout>

가져오기 및 내보내기 기능을 사용하면 Univer 서버를 통해 `.docx` 파일을 Univer 문서로 가져오거나 문서 콘텐츠를 `.docx` 파일로 내보낼 수 있어 다른 오피스 소프트웨어나 플랫폼과 쉽게 연동할 수 있습니다.

<Callout title="Univer가 백엔드 서비스를 통해 가져오기 및 내보내기를 구현하는 이유는 무엇인가요?">
  프런트엔드만으로 구현한 가져오기 및 내보내기는 성능과 결과 측면에서 기업의 요구 사항을 충족하기 어렵습니다. 따라서
  가져오기 및 내보내기 기능을 구현하는 백엔드 서비스를 제공합니다. 오픈 소스 DOCX 파싱 라이브러리를 사용해 파일을
  `IDocumentData` 인터페이스에 맞는 데이터 구조로 파싱한 다음, Facade API로 데이터를 Univer에 가져올 수도 있습니다.
</Callout>

메뉴 모음의 가져오기 항목을 통해 파일을 성공적으로 가져오면 페이지 왼쪽 아래에 알림이 표시됩니다. 알림에는 가져오기 성공 정보와 가져온 문서로 이동하는 링크가 포함됩니다. 기본 가져오기 및 내보내기 동작이 요구 사항에 맞지 않는다면 [문서 가져오기 사용자 지정](/guides/recipes/tutorials/custom-import)을 참고해 가져오기 동작을 사용자 지정하는 방법을 알아보세요.

## 가져오기/내보내기 방식 선택하기

협업 필요 여부에 따라 두 가지 방식을 선택할 수 있습니다.

| 방식          | 협업 필요 여부 | 적합한 용도                                              | API                                                     |
| ------------- | -------------- | -------------------------------------------------------- | ------------------------------------------------------- |
| `unitId` 사용 | 예             | 서버에 저장되는 협업 문서                                | `importDocToUnitIdAsync` / `exportDocByUnitIdAsync`     |
| 스냅샷 사용   | 아니요         | 로컬 또는 오프라인 워크플로 또는 형식 변환만 필요한 경우 | `importDocToSnapshotAsync` / `exportDocBySnapshotAsync` |

프로젝트에서 협업 기능을 사용한다면, 즉 서버에 저장된 문서를 `unitId`로 연다면 `unitId` 방식을 선택하세요. 그 외에는 스냅샷 방식을 사용하세요.

## 프리셋 모드

### 설치

<Callout>
  `@univerjs/preset-docs-advanced`의 `UniverDocsAdvancedPreset` 프리셋은 런타임에 `UniverDocsDrawingPreset` 프리셋을
  필요로 합니다. 먼저 `@univerjs/preset-docs-drawing`을 설치하세요.
</Callout>

```package-install
npm install @univerjs/preset-docs-drawing @univerjs/preset-docs-advanced
```

### 사용법

```typescript
import { UniverDocsAdvancedPreset } from '@univerjs/preset-docs-advanced' // [!code ++]
import UniverPresetDocsAdvancedEnUS from '@univerjs/preset-docs-advanced/locales/en-US' // [!code ++]
import { UniverDocsCorePreset } from '@univerjs/preset-docs-core'
import UniverPresetDocsCoreEnUS from '@univerjs/preset-docs-core/locales/en-US'
import { UniverDocsDrawingPreset } from '@univerjs/preset-docs-drawing' // [!code ++]
import UniverPresetDocsDrawingEnUS from '@univerjs/preset-docs-drawing/locales/en-US' // [!code ++]
import { createUniver, LocaleType, mergeLocales } from '@univerjs/presets'

import '@univerjs/preset-docs-core/lib/index.css'
import '@univerjs/preset-docs-drawing/lib/index.css' // [!code ++]
import '@univerjs/preset-docs-advanced/lib/index.css' // [!code ++]

const { univer, univerAPI } = createUniver({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      UniverPresetDocsCoreEnUS,
      UniverPresetDocsDrawingEnUS, // [!code ++]
      UniverPresetDocsAdvancedEnUS, // [!code ++]
    ),
  },
  presets: [
    UniverDocsCorePreset(),
    UniverDocsDrawingPreset(), // [!code ++]
    UniverDocsAdvancedPreset({
      // [!code ++]
      universerEndpoint: 'http://localhost:3010', // [!code ++]
    }), // [!code ++]
  ],
})
```

Univer 상용 라이선스가 있다면 [클라이언트에서 라이선스 사용하기](/guides/pro/license#in-preset-mode)를 참고해 구성하세요.

### 프리셋 및 구성

`UniverDocsAdvancedPreset`의 구성 옵션은 다음과 같습니다.

```typescript
interface IUniverSheetsAdvancedPresetConfig {
  // This is the endpoint for the Univer server
  universerEndpoint?: string
}
```

## 플러그인 모드

### 설치

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/docs-exchange-client
```

### 사용법

```typescript
import { UniverDocsExchangeClientPlugin } from '@univerjs-pro/docs-exchange-client' // [!code ++]
import DocsExchangeClientEnUS from '@univerjs-pro/docs-exchange-client/locale/en-US' // [!code ++]
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client' // [!code ++]
import ExchangeClientEnUS from '@univerjs-pro/exchange-client/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'

import '@univerjs-pro/exchange-client/facade' // [!code ++]
import '@univerjs-pro/docs-exchange-client/facade' // [!code ++]

import '@univerjs-pro/exchange-client/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      ExchangeClientEnUS, // [!code ++]
      DocsExchangeClientEnUS, // [!code ++]
    ),
  },
})

const UNIVER_SERVER_ENDPOINT = `http://localhost:8000` // [!code ++]

univer.registerPlugin(UniverExchangeClientPlugin, {
  // [!code ++]
  uploadFileServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/stream/file/upload`, // [!code ++]
  importServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/exchange/{type}/import`, // [!code ++]
  exportServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/exchange/{type}/export`, // [!code ++]
  getTaskServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/exchange/task/{taskID}`, // [!code ++]
  signUrlServerUrl: `${UNIVER_SERVER_ENDPOINT}/universer-api/file/{fileID}/sign-url`, // [!code ++]
  downloadEndpointUrl: `${UNIVER_SERVER_ENDPOINT}/`, // [!code ++]
}) // [!code ++]
univer.registerPlugin(UniverDocsExchangeClientPlugin) // [!code ++]
```

Univer 상용 라이선스가 있다면 [클라이언트에서 라이선스 사용하기](/guides/pro/license#in-plugin-mode)를 참고해 구성하세요.

### 플러그인 및 구성

## Facade API

### 가져오기

<Callout type="info" title="플러그인 모드 참고 사항">
  플러그인 모드에서만 Facade 패키지를 직접 가져와야 합니다. 프리셋 모드에는 해당 Facade 패키지가 이미 포함되어 있으므로
  별도로 가져올 필요가 없습니다.
</Callout>

### 가져오기

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/docs-exchange-client/facade'
```

### `.docx` 가져오기

#### `.docx` 파일을 가져오고 `unitId` 받기

<Callout type="warning" title="주의">
  이 메서드를 사용하려면 협업 기능이 필요합니다. 서버 문서를 만들고 `unitId`를 반환합니다. 협업 기능을 사용하지 않는다면
  스냅샷 가져오기를 사용하세요.
</Callout>

협업 편집을 사용하면 각 문서에 고유한 `unitId`가 부여됩니다. `file` 매개변수와 함께 `univerAPI.importDocToUnitIdAsync`를 사용하면 문서에 접근할 수 있는 `unitId`가 반환됩니다. `file` 매개변수에는 `File` 객체나 원격 파일 URL을 사용할 수 있습니다.

```typescript
// Accept a File object
const unitId = await univerAPI.importDocToUnitIdAsync(file)
// Or accept a remote file URL
// const unitId = await univerAPI.importDocToUnitIdAsync('https://example.com/filename.docx');

// Using with collaborative editing to automatically load data https://docs.univer.ai/en-US/guides/docs/features/collaboration#loading-collaborative-documents
const url = new URL(window.location.href)
url.searchParams.set('unit', unitId)
url.searchParams.set('type', '1') // The meaning of 1 is UniverInstanceType.UNIVER_DOC
window.location.href = url.toString()

// Or call the API: univerAPI.loadServerUnit(unitId, 1) to load the document, refer to /reference/facade/univer#loadserverunit for specific parameters
```

#### `.docx` 파일을 가져오고 `IDocumentData` 받기

<Callout>스냅샷 가져오기는 협업 기능이 필요하지 않습니다. 협업 문서에는 `unitId` 가져오기를 사용하세요.</Callout>

`univerAPI.importDocToSnapshotAsync`를 사용해 `.docx` 파일을 가져오면 `IDocumentData` 형식의 문서 데이터가 반환됩니다.

```typescript
// Accept a File object
const snapshot = await univerAPI.importDocToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importDocToSnapshotAsync('https://example.com/filename.docx');

// Create a new document via snapshot
univerAPI.createDocument(snapshot)
```

### `.docx` 내보내기

#### `unitId`를 사용해 `.docx` 파일 내보내기

<Callout type="warning" title="주의">
  `unitId` 내보내기를 사용하려면 협업 기능이 필요합니다. 협업 기능을 사용하지 않는다면 스냅샷 내보내기를 사용하세요.
</Callout>

협업 편집을 사용하면 각 문서에 고유한 `unitId`가 부여됩니다. `unitId` 매개변수와 함께 `univerAPI.exportDocByUnitIdAsync`를 사용하면 `File` 객체가 반환됩니다.

```typescript
const fDocument = univerAPI.getActiveDocument()
const unitId = fDocument.getId()
const file = await univerAPI.exportDocByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

#### `IDocumentData`를 사용해 `.docx` 파일 내보내기

<Callout>스냅샷 내보내기는 협업 기능이 필요하지 않으며 로컬 워크플로에 적합합니다.</Callout>

`IDocumentData`와 함께 `univerAPI.exportDocBySnapshotAsync`를 사용하면 `File` 객체가 반환됩니다.

```typescript
const fDocument = univerAPI.getActiveDocument()
const snapshot = fDocument.save()
const file = await univerAPI.exportDocBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```
