이 페이지의 API는 변환 백엔드가 필요합니다. [파일 교환 통합](/server/import-export)를 따라 업로드, 변환, 작업 쿼리 및 다운로드를 연결하고 브라우저 플러그인을 구성합니다. Snapshot API는 또한 백엔드이 필요하지만 협업 문서가 필요하지 않습니다. 협업 교환 예는 시트를 보여줍니다. 타겟 릴리스가 필요한 파일 형식을 지원한다는 것을 확인합니다.

수출이 실패하면 [라이센스 오류 코드 및 작업 실패 처리](/server/import-export#export-errors)를 참조하십시오.

## 지원 형식

테이블은이 페이지에서 브라우저 API를 설명합니다. Office 파일 변환은 동일한 문서 유형과 형식을 지원하는 백엔드가 필요합니다.

| 가져오기 | 내보내기 |
| --- | --- |
| `.doc`, `.docx` | `.docx` |

`.doc`와 `.docx` 모두는 아래 수입품 APIs를 이용합니다. 수출은 항상 `.docx`를 일으킵니다; 유산 `.doc` 체재는 수출될 수 없습니다.

## Facade API

### 가져오기

<Callout type="info" title="플러그인 모드 참고">
  플러그인 모드는 수동으로 Facade 패키지를 가져올 필요가 있습니다. 미리 설정 모드는 이미 해당 Facade 포장을 포함하므로 추가 수입이 필요하지 않습니다.
</Callout>

```typescript
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/docs-exchange-client/facade'
```

### `.docx` 가져오기

#### `.docx` 파일을 가져오고 `unitId` 받기

<Callout type="warning" title="주 메뉴">
  이 방법은 협업이 필요하므로 서버에서 문서를 작성하고 `unitId`를 반환합니다. 협업이 활성화되지 않으면 스냅 샷 가져 오기를 사용하십시오.
</Callout>

협업 편집이 활성화되면 각 문서에는 `unitId`가 있습니다. `file` 매개 변수를 가진 `univerAPI.importDocToUnitIdAsync`를 호출하고 `unitId`을 반환하면 문서에 액세스하는 데 사용됩니다. `file` 매개변수는 `File` 객체 또는 원격 파일 URL을 받아들입니다.

```typescript
import '@univerjs-pro/collaboration-client/facade'

const unitId = await univerAPI.importDocToUnitIdAsync(file)

if (unitId) {
  await univerAPI.getCollaboration().loadDocAsync(unitId)
}
```

#### `.docx` 파일을 가져오고 `IDocumentData` 받기

<Callout>Snapshot import는 협업이 필요하지 않습니다. 문서가 협업을 필요로 할 때 `unitId` 가져 오기를 사용하십시오.</Callout>

`univerAPI.importDocToSnapshotAsync`는 `.docx` 파일을 가져 와서 `IDocumentData`로 문서 데이터를 반환합니다.

```typescript
// Accept a File object
const snapshot = await univerAPI.importDocToSnapshotAsync(file)
// Or accept a remote file URL
// const snapshot = await univerAPI.importDocToSnapshotAsync('https://example.com/filename.docx');

// Create a new document via snapshot
if (snapshot) univerAPI.createDocument(snapshot)
```

### `.docx` 내보내기

#### `unitId`를 사용해 `.docx` 파일 내보내기

<Callout type="warning" title="주의">
  `unitId` 내보내기를 사용하려면 협업 기능이 필요합니다. 협업 기능을 사용하지 않는다면 스냅샷 내보내기를 사용하세요.
</Callout>

협업 편집이 활성화되면 각 문서는 고유한 `unitId`. 전화 `univerAPI.exportDocByUnitIdAsync` 이름 * `unitId` 매개 변수를 수신 `File` 객체.

```typescript
const fDocument = univerAPI.getActiveDocument()
const unitId = fDocument.getId()
const file = await univerAPI.exportDocByUnitIdAsync(unitId)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```

#### `IDocumentData`를 사용해 `.docx` 파일 내보내기

<Callout>스냅샷 내보내기는 협업 기능이 필요하지 않으며 로컬 워크플로에 적합합니다.</Callout>

`univerAPI.exportDocBySnapshotAsync`는 `IDocumentData`를 받아 `File` 객체를 반환합니다.

```typescript
const fDocument = univerAPI.getActiveDocument()
const snapshot = fDocument.save()
const file = await univerAPI.exportDocBySnapshotAsync(snapshot)

// Download the file through the Facade API
if (file) univerAPI.downloadFile(file, 'univer', 'docx')
```
