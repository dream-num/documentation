고급 표 기능은 셀 스타일 지정, 테두리 사용자 지정, 행과 열 조작, 데이터 입력 등 Univer Docs를 위한 풍부한 표 편집 기능을 제공합니다.

## 소개

Univer Docs의 고급 표로 다음 작업을 할 수 있습니다.

- **프로그래밍 방식으로 표 삽입**: 지정한 크기의 표를 만듭니다.
- **구조 조작**: 행과 열을 추가, 삭제, 이동합니다.
- **셀 스타일 지정**: 테두리, 배경, 텍스트 서식을 적용합니다.
- **셀 병합 및 분할**: 복잡한 레이아웃을 위해 셀을 결합합니다.

## 플러그인 모드

### 설치

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### 사용법

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIEnUS from '@univerjs-pro/docs-table-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsTableUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

Univer 상용 라이선스가 있다면 구성 방법은 [클라이언트에서 라이선스 사용하기](/server/license#in-plugin-mode)를 참고하세요.

## Facade API

API를 사용하기 전에 facade를 반드시 가져오세요.

```typescript
import '@univerjs-pro/docs-table/facade'
```

### 표 삽입하기

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### 데이터로 표 삽입하기

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### 모든 표 가져오기

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### 표 삭제하기

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```

## 표 테두리 [#table-borders]

표나 셀을 선택하면 상황별 표 탭이 나타납니다. 테두리 선택기에서 전체, 바깥쪽, 안쪽, 개별 가장자리 및 테두리 없음 프리셋을 선택하고 색상, 두께, 선 스타일을 조정할 수 있습니다. 이 컨트롤은 `UniverDocsTableUIPlugin`에서 제공합니다.

## 편집, 실행 취소, 공동 편집 [#editing-history]

표 Facade 설정과 구조 편집은 문서 명령을 사용하며 실행 취소/다시 실행과 공동 편집을 지원합니다. `setTableStyle()`은 배경과 테두리 변경을 한 기록으로 묶습니다. `setColumnType()`도 실행 취소 및 동기화를 지원하며 열 이동 시 유형도 따라갑니다. `setCellText()`는 셀 값 전체를 바꾸므로 동시 교체에는 원자 값 충돌 규칙을 사용하고 일반 문자 편집에는 텍스트 OT를 사용합니다. 잠긴 콘텐츠 컨트롤이 거부한 셀 편집은 `false`를 반환하며 기록을 소모하지 않습니다.

## 표 전체 정렬 [#table-alignment]

Traditional 문서에서 표를 선택한 뒤 Ribbon의 표 정렬 메뉴로 페이지 본문 영역 안에서 왼쪽, 가운데, 오른쪽에 배치합니다. 셀 내부 텍스트가 아닌 표 전체 위치를 변경합니다. Modern 문서에서는 이 컨트롤이 비활성화됩니다.

값은 `tableSource[tableId].align`에 저장되며 실행 취소, 다시 실행, 저장을 지원합니다. 표 플러그인을 등록한 뒤 스냅샷에 있는 표 ID로 아래 공개 명령을 실행할 수도 있습니다. 잘못된 대상, 비활성 문서, Modern 문서에서는 `false`를 반환합니다.

```ts
import { DocsTableSetTableAlignCommand } from '@univerjs-pro/docs-table'
import { TableAlignmentType } from '@univerjs/core'

const aligned = await univerAPI.executeCommand(DocsTableSetTableAlignCommand.id, {
  unitId: documentId,
  tableId,
  value: TableAlignmentType.CENTER,
})
```
