향상된 테이블은 Univer Docs에서 전체 테이블 편집을 제공합니다 : 셀 스타일링, 국경, 행 및 열 변경, 데이터에서 테이블을 채우기.

## 소개

Univer Docs에서 테이블은 다음 작업을 지원합니다.

- 지정된 치수로 테이블을 만듭니다.
- 추가, 삭제 및 이동 행 및 열.
- 경계, 배경 및 텍스트 포맷을 세포에 적용하십시오.
- Merge 및 분할 셀 복잡한 레이아웃을 구축합니다.

## 플러그인 모드

### 설치

```package-install
npm install @univerjs-pro/docs-table @univerjs-pro/docs-table-ui
```

### 사용법

```typescript
import { UniverDocsTablePlugin } from '@univerjs-pro/docs-table' // [!code ++]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui' // [!code ++]
import DocsTableUIEnUS from '@univerjs-pro/docs-table-ui/locale/en-US' // [!code ++]
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import '@univerjs-pro/docs-table-ui/lib/index.css' // [!code ++]

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(
      DocsTableUIEnUS, // [!code ++]
    ),
  },
})

univer.registerPlugin(UniverDocsTablePlugin) // [!code ++]
univer.registerPlugin(UniverDocsTableUIPlugin) // [!code ++]
```

상업 라이센스를 사용한다면 [Client의 라이센스 사용](/server/license#in-plugin-mode)에 설명된 것과 같이 구성하십시오.

## 모바일 지원 [#mobile-support]

[모바일 편집기](/guides/docs/getting-started/installation#mobile-support)를 먼저 구성하십시오. 이 페이지에서 설명 된 플러그인 모드 설정에서 동일한 패키지에서 모바일 내보내기로 아래 데스크탑 등록을 대체하고 **문서 열기**을 수행하십시오. 모델 플러그인, 스타일, 로컬 및 Facade 가져 오기를 유지하고 하나의 변형 만 등록하십시오.

| 패키지 | 데스크톱 등록 | 모바일 등록 |
| --- | --- | --- |
| `@univerjs-pro/docs-table-ui` | `UniverDocsTableUIPlugin` | `UniverDocsTableMobileUIPlugin` |

## Facade API

다음 API를 사용하기 전에 정면을 가져 오기 :

```typescript
import '@univerjs-pro/docs-table/facade'
```

### 표 삽입하기

```typescript
const doc = univerAPI.getActiveDocument()
const table = doc?.insertTable(3, 4, { tableId: 'my-table' })
table?.setCellText(0, 0, 'Name')
```

### 데이터로 표 삽입하기

```typescript
const doc = univerAPI.getActiveDocument()
doc?.insertTableFromData([
  ['Name', 'Status'],
  ['Facade', 'Ready'],
], { headerRowCount: 1 })
```

### 모든 표 가져오기

```typescript
const doc = univerAPI.getActiveDocument()
const tables = doc?.getTables() ?? []
```

### 표 삭제하기

```typescript
const doc = univerAPI.getActiveDocument()
doc?.deleteTable('my-table')
```

## 표 테두리 [#table-borders]

테이블 또는 그 셀을 선택하여 컨텍스트 테이블 탭을 엽니 다. 국경 피커는 색상, 너비 및 라인 스타일에 대한 제어와 함께 모든, 외부, 내부, 개별 가장자리 및 국경에 대한 사전 설정 제공. `UniverDocsTableUIPlugin` 이러한 컨트롤을 공급합니다.

## 편집, 실행 취소, 공동 편집 [#editing-history]

Table Facade setters 및 구조 편집은 문서 명령을 통해 적용되므로 undo/redo 및 협업에 참여합니다. `setTableStyle()` 배경과 경계를 하나의 역사 입력으로 변경합니다. `setColumnType()` 또한 동기화되고, 열 유형은 열이 움직이면 열을 따릅니다. `setCellText()` 전체 셀 값 교체 : 동시 교체는 원자 값으로 해결, 일반 문자는 텍스트 OT을 편집합니다. 고정 된 콘텐츠 제어가 셀 편집을 거부하면, 통화 반환 `false` 그리고 undo/redo 역사를 사용하지 않습니다.

## 표 전체 정렬 [#table-alignment]

전통적인 문서에서 테이블을 선택하고 리본에 **테이블 → 테이블 정렬**를 사용하여 왼쪽, 중앙 또는 페이지 내용 영역의 오른쪽 테이블을 배치하십시오. 이 설정은 테이블 자체를 이동하고 세포 내부의 텍스트 정렬을 변경하지 않습니다. 제어는 현대 문서에서 비활성화됩니다.

값은 `tableSource[tableId].align`에 저장되며 undo/redo 및 save를 지원합니다. 테이블 플러그인이 등록되면 아래 공공 명령을 통해 동일한 동작이 가능합니다. 문서 스냅 샷에서 기존 테이블 ID를 통과하십시오. 잘못된 대상, 사용 가능한 문서 및 현대 문서 반환 `false`.

```ts
import { DocsTableSetTableAlignCommand } from '@univerjs-pro/docs-table'
import { TableAlignmentType } from '@univerjs/core'

const aligned = await univerAPI.executeCommand(DocsTableSetTableAlignCommand.id, {
  unitId: documentId,
  tableId,
  value: TableAlignmentType.CENTER,
})
```
