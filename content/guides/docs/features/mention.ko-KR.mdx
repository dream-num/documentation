멘션을 사용하면 Univer Docs에서 `@`를 입력해 애플리케이션의 사용자, 팀, 티켓 또는 기타 객체와 같은 멘션 엔터티를 삽입할 수 있습니다. 삽입한 멘션은 문서 본문에 `CustomRangeType.MENTION` 사용자 지정 범위로 저장됩니다.

## 사용 방법

- 문서에서 `@`를 입력하면 멘션 팝업이 열립니다.
- 계속 입력하면 멘션 데이터 소스에 `search` 값이 전달됩니다.
- 후보를 선택하면 입력한 트리거 텍스트가 `@Alice`와 같은 엔터티로 바뀝니다.
- 커서를 이동하거나 트리거 앞의 문자를 삭제하면 팝업이 닫힙니다.

## 플러그인 모드

### 설치

```package-install
npm install @univerjs/docs-mention-ui
```

### 사용법

```typescript
import { UniverDocsMentionUIPlugin } from '@univerjs/docs-mention-ui' // [!code ++]

import '@univerjs/docs-mention-ui/lib/index.css' // [!code ++]

univer.registerPlugin(UniverDocsMentionUIPlugin) // [!code ++]
```

## 멘션 후보 제공하기

멘션 팝업은 `IMentionIOService`에서 후보를 읽습니다. Univer는 현재 사용자를 반환하는 기본 로컬 구현을 제공합니다. 프로덕션 애플리케이션에서는 일반적으로 사용자 디렉터리, 팀 서비스, 이슈 트래커 또는 기타 비즈니스 데이터 소스를 기반으로 하는 구현으로 교체합니다.

```typescript
import type { IListMentionParam, IListMentionResponse, IMentionIOService } from '@univerjs/core'
import { MentionType } from '@univerjs/core'

class DirectoryMentionIOService implements IMentionIOService {
  async list(params: IListMentionParam): Promise<IListMentionResponse> {
    const users = await searchUsers(params.search ?? '')

    return {
      list: [{
        type: MentionType.PERSON,
        title: 'People',
        metadata: {},
        mentions: users.map(user => ({
          objectType: MentionType.PERSON,
          objectId: user.id,
          label: user.name,
          metadata: {
            icon: user.avatarUrl,
            email: user.email,
          },
        })),
      }],
      page: params.page,
      size: params.size,
      total: users.length,
    }
  }
}
```

애플리케이션을 만들 때 Univer의 종속성 재정의를 통해 서비스를 등록하세요.

```typescript
import { IMentionIOService, LocaleType, Univer } from '@univerjs/core'

const univer = new Univer({
  locale: LocaleType.EN_US,
  override: [
    [IMentionIOService, { useClass: DirectoryMentionIOService }],
  ],
})
```

## 데이터 모델

멘션을 삽입하면 표시되는 텍스트는 `body.dataStream`에 기록되고 엔터티 메타데이터는 `body.customRanges`에 저장됩니다.

```typescript
const documentData = {
  body: {
    dataStream: 'Hello @Alice\\r\\n',
    customRanges: [{
      startIndex: 6,
      endIndex: 11,
      rangeId: 'mention-1',
      rangeType: CustomRangeType.MENTION,
      wholeEntity: true,
      properties: {
        id: 'mention-1',
        label: 'Alice',
        type: 'user',
        email: 'alice@example.com',
      },
    }],
  },
}
```

<Callout type="info">
  멘션은 문서의 사용자 지정 범위입니다. 애플리케이션이 `metadata`에 추가 필드를 저장한다면 문서 스냅샷을 안전하게 저장하고 복원할 수 있도록 직렬화 가능한 형태를 유지하세요.
</Callout>
