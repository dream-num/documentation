## What is Univer Docs

Univer Office SDK is a full-stack framework for building productivity applications. Univer Docs is the document editor of Univer Office SDK and the Docs component of Web SDK. It runs in the browser and on the server (Node.js).

Univer Docs obtains its editing capabilities from [Web SDK](/guides/sheets), which covers embedded editors and headless content processing. Collaboration and file conversion come from [Server SDK](/server), and [AI SDK](/ai) enables an agent to work with documents.

Univer Docs supports extension and customization. You can build applications with it that range from simple text entry to complex typesetting, whether you work individually or as part of a team.

## Browser compatibility

Web SDK is compiled with a Chrome 88 target, but that does not mean every mainstream environment is fully supported. We try to keep Web SDK working in the following browsers and Node.js environments:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK relies on `Intl.Segmenter`. If your browser or runtime environment does not support it, add the corresponding polyfill first. We recommend `@formatjs/intl-segmenter`.
</Callout>

If you encounter a compatibility problem, try the corresponding polyfill first. If the problem persists, [open an issue](https://github.com/dream-num/univer/issues/new/choose).

## Node.js compatibility

<Callout type="warning">
  This applies only when Web SDK itself runs in Node.js. It does not apply when Web SDK runs in a browser through a Node.js-based build tool.
</Callout>

Web SDK runs on Node.js v18.17.0 and later.

## Highlights

Univer Docs supports the following features:

- **Basic document features**: full text typesetting, including paragraph settings, spacing before and after paragraphs, paragraph alignment, indentation and hanging, and in-paragraph typesetting such as punctuation compression, punctuation hanging, character spacing, and Western word breaking.
- **Header and footer**
- **Floating images**
- **Hyperlinks**
- and more...

The pages under [Features](/guides/docs/features/core) describe each feature in detail.

## Pre-requisite knowledge

The documentation is intended to be approachable, but it still assumes a baseline so that it can stay focused on Web SDK.

A basic understanding of JavaScript and its ecosystem will help you get the most out of the documentation.

If you plan to run Web SDK on Node.js, you also need a basic understanding of Node.js.

[Univer Server SDK](/server) provides the modules a document needs for collaboration, shared history or comments, and file conversion. You compose these modules in your application backend, which also handles authentication, permissions, storage, and deployment. Editing in the browser alone does not require any of them.

## Extend Univer Docs

Web SDK supports extension, so you can adapt it to the requirements of your application.
