## Что такое Univer Boards

Univer Boards — это продукт Univer Pro для работы на холсте. Он подходит для случаев, когда документ представляет собой не таблицу, страницу или набор слайдов, а свободное рабочее пространство: здесь можно размещать белые доски, диаграммы, стикеры, соединительные линии, встроенные таблицы и интеллект-карты.

Boards реализован как отдельный тип модуля Univer. Во время выполнения вы создаёте модуль `UniverInstanceType.UNIVER_BOARD`, а затем регистрируете плагины модели и интерфейса, необходимые для поддержки нужных элементов.


## Совместимость с браузерами

Univer компилируется для Chrome 88, но это не означает полной поддержки всех распространённых сред. Мы стремимся обеспечить стабильную работу Univer в следующих браузерах и средах Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer использует `Intl.Segmenter`. Если ваш браузер или среда выполнения не поддерживает этот API, сначала добавьте
  соответствующий полифил. Мы рекомендуем `@formatjs/intl-segmenter`.
</Callout>

Если возникли проблемы с совместимостью, сначала попробуйте устранить их с помощью подходящих полифилов. Если проблема сохраняется, [создайте issue](https://github.com/dream-num/univer/issues/new/choose).

## Совместимость с Node.js

<Callout type="warning">
  Примечание: это относится только к запуску Univer в среде Node.js и не относится к случаям, когда Univer запускается в
  браузере с помощью инструментов сборки на базе Node.js.
</Callout>

Univer может работать в среде Node.js и поддерживает версии v18.17.0 и выше.


## Когда использовать Boards

Используйте Boards, если вашему приложению нужен большой холст, на котором пользователи могут свободно располагать содержимое. Типичные примеры — доски для мозгового штурма, блок-схемы, карты планирования, командные ретроспективы и диаграммы продуктов. Если основной объект — табличные данные, начните с [Univer Bases](/guides/bases). Если это электронная таблица, начните с [Univer Sheets](/guides/sheets).

## Установка пакетов

Основная среда выполнения Board разделена на пакет модели и пакет интерфейса. Элементы таблиц и интеллект-карт предоставляются необязательными пакетами, которые подключаются поверх основной среды Board.

```bash
pnpm add @univerjs-pro/boards @univerjs-pro/boards-ui
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

## Обзор пакетов

- `@univerjs-pro/boards`: модель данных доски, схема элементов, команды, мутации, сервисы адаптеров, точка входа фасада и `UniverBoardsPlugin`
- `@univerjs-pro/boards-ui`: интерфейс холста доски, область просмотра, выделение, редактирование фигур, соединительные линии, стикеры, рисование от руки, панель инструментов, контекстное меню и `UniverBoardsUIPlugin`
- `@univerjs-pro/boards-table`: интеграция элементов таблиц на доске и `UniverBoardsTablePlugin`
- `@univerjs-pro/boards-table-ui`: интерфейс элементов таблиц, интеграция отрисовки, точки входа локалей и `UniverBoardsTableUIPlugin`
- `@univerjs-pro/boards-mind`: интеграция элементов интеллект-карт и `UniverBoardsMindPlugin`
- `@univerjs-pro/boards-mind-ui`: интеграция интерфейса интеллект-карт и `UniverBoardsMindUIPlugin`

## Регистрация плагинов

В примере ниже показана часть настройки, относящаяся к Board. Для полноценного приложения также необходимы общие плагины ядра Univer, движка отрисовки, интерфейса, лицензии и рисования от руки.

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/boards/facade'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})
```
