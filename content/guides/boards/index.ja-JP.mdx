## Univer Boards とは

Univer Boards は、Univer Pro のキャンバス製品です。ドキュメントがグリッド、ページ、スライドデッキのいずれでもなく、自由形式のワークスペースである場合に使用します。ホワイトボード、図、付箋、コネクタ、埋め込みテーブル、マインドマップは、すべてここで扱えます。

Boards は、独立した Univer ユニットタイプとして実装されています。実行時に `UniverInstanceType.UNIVER_BOARD` ユニットを作成し、サポートする要素に必要なモデルプラグインと UI プラグインを登録します。


## ブラウザ互換性

Univer は Chrome 88 をターゲットとしてコンパイルされていますが、これはすべての主流環境を完全にサポートすることを保証するものではありません。Univer が以下のブラウザおよび Node.js 環境で問題なく動作するよう努めています。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer は `Intl.Segmenter`
  に依存しています。お使いのブラウザまたはランタイム環境でこれがサポートされていない場合は、先に対応するポリフィルを追加してください。`@formatjs/intl-segmenter`
  の利用を推奨します。
</Callout>

互換性に関する問題が発生した場合、まずは適切なポリフィルを使用して解決を試みてください。それでも問題が解決しない場合は、[Issue の提出](https://github.com/dream-num/univer/issues/new/choose) をご検討ください。

## Node.js 互換性

<Callout type="注意事項">
  注意：これは Univer を Node.js 環境で実行する場合にのみ適用され、Node.js
  ベースのビルドツールを使ってブラウザで実行する場合には該当しません。
</Callout>

Univer は Node.js 環境でも動作可能で、v18.17.0 以降のバージョンをサポートしています。


## Boards を使う場面

ユーザーがコンテンツを空間的に配置できる大きなキャンバスがアプリケーションに必要な場合は、Boards を使用します。代表的な例として、ブレインストーミングボード、フローチャート、計画マップ、チームの振り返り、製品図などがあります。主に扱うものが表形式のデータであれば [Univer Bases](/guides/bases) を、スプレッドシートであれば [Univer Sheets](/guides/sheets) を使用してください。

## パッケージのインストール

Board のコアランタイムは、モデルパッケージと UI パッケージに分かれています。テーブル要素とマインドマップ要素は、Board ランタイムに追加できる任意のパッケージです。

```bash
pnpm add @univerjs-pro/boards @univerjs-pro/boards-ui
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

## パッケージ構成

- `@univerjs-pro/boards`: Board のデータモデル、要素スキーマ、コマンド、ミューテーション、アダプターサービス、ファサードのエントリ、`UniverBoardsPlugin`
- `@univerjs-pro/boards-ui`: Board のキャンバス UI、ビューポート、選択、図形編集、コネクタ、付箋、インク操作、ツールバー、コンテキストメニュー、`UniverBoardsUIPlugin`
- `@univerjs-pro/boards-table`: Board のテーブル要素の統合、`UniverBoardsTablePlugin`
- `@univerjs-pro/boards-table-ui`: テーブル要素の UI、レンダリングの統合、ロケールのエントリポイント、`UniverBoardsTableUIPlugin`
- `@univerjs-pro/boards-mind`: マインドマップ要素の統合、`UniverBoardsMindPlugin`
- `@univerjs-pro/boards-mind-ui`: マインドマップ UI の統合、`UniverBoardsMindUIPlugin`

## プラグインの登録

以下のスニペットは、セットアップのうち Board 固有の部分を示しています。完全なアプリケーションには、Univer の共通コア、レンダリングエンジン、UI、ライセンス、インクの各プラグインも必要です。

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/boards/facade'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})
```
