## Univer Boards とは

Univer Boards は、Univer Pro のキャンバス製品です。ドキュメントがグリッド、ページ、スライドデッキのいずれでもなく、自由形式のワークスペースである場合に使用します。ホワイトボード、図、付箋、コネクタ、埋め込みテーブル、マインドマップは、すべてここで扱えます。

Boards は、独立した Univer ユニットタイプとして実装されています。実行時に `UniverInstanceType.UNIVER_BOARD` ユニットを作成し、サポートする要素に必要なモデルプラグインと UI プラグインを登録します。


## ブラウザ互換性

Univer は Chrome 88 をターゲットとしてコンパイルされていますが、これはすべての主流環境を完全にサポートすることを保証するものではありません。Univer が以下のブラウザおよび Node.js 環境で問題なく動作するよう努めています。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer は `Intl.Segmenter`
  に依存しています。お使いのブラウザまたはランタイム環境でこれがサポートされていない場合は、先に対応するポリフィルを追加してください。`@formatjs/intl-segmenter`
  の利用を推奨します。
</Callout>

互換性に関する問題が発生した場合、まずは適切なポリフィルを使用して解決を試みてください。それでも問題が解決しない場合は、[Issue の提出](https://github.com/dream-num/univer/issues/new/choose) をご検討ください。

## Node.js 互換性

<Callout type="注意事項">
  注意：これは Univer を Node.js 環境で実行する場合にのみ適用され、Node.js
  ベースのビルドツールを使ってブラウザで実行する場合には該当しません。
</Callout>

Univer は Node.js 環境でも動作可能で、v18.17.0 以降のバージョンをサポートしています。

## 主な機能

- **ページと要素の順序**：ページを `pages` に、描画可能なオブジェクトを各ページの `elements` に保存し、両方の階層で明示的な順序配列を使用します。
- **キャンバス要素**：テキスト、図形、画像、コネクター、グループ、コンテナ、スイムレーンを扱います。
- **コマンド駆動の編集**：要素の変更、順序、親子関係を 1 つのコマンド層に集約し、権限と、任意の履歴・コラボレーション統合用フックを提供します。
- **ブラウザーキャンバス**：要素を描画し、選択、変形、クリップボード、テキスト編集、ビューポート操作、パネルを提供します。
- **拡張可能なアダプター**：表、マインドマップ、グラフ、リソース、印刷、交換などの任意の Boards 機能を追加できます。
- **永続化**：ページ、リソース、テーマ、アクティブページの状態を含む `IBoardData` スナップショットを作成、復元、保存します。

## ドキュメントの読み方

画面左側にドキュメントのナビゲーションがあります。ページは基礎から応用へ順に構成されているため、その順で進めてもよいですし、必要な章だけを選んで読むこともできます。サイドバー上部で Univer Boards のドキュメントに切り替えることもできます。

画面右側には現在ページの目次が表示されます。目的のページを素早く見つけたい場合は、上部の検索バーや検索ショートカット（Ctrl+K または Cmd+K）を利用してください。

まずは [クイックスタート](/guides/boards/getting-started/quickstart) から始めることをおすすめします。

## 前提知識

ドキュメントは初心者にも分かりやすく設計していますが、Univer に集中できるよう、読み始める前にいくつかの基礎知識があることを前提としています。

効率よく理解するために、JavaScript とそのエコシステムの基本的な理解をおすすめします。

Node.js 上で Univer を動かしたい場合は、Node.js の基礎知識も必要です。

Pro 機能を試したり Univer Server を導入する場合は、Linux、Docker、Docker Compose（または Kubernetes）の基礎知識があるとスムーズです。
