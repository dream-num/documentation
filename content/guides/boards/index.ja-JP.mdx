## Univer Boards とは

Univer Boards は Univer Pro のキャンバス製品です。ホワイトボード、フローチャート、付箋ボード、コネクタ図、埋め込みテーブル、マインドマップを扱うためのワークスペースとして使います。内容がセル、ページ、スライドではなく、大きなキャンバス上に自由に配置される場合は Boards が適しています。

Boards は実行時に独立した Univer unit として作成します。アプリケーションでは `UniverInstanceType.UNIVER_BOARD` を作成し、必要に応じて Board モデル、キャンバス UI、テーブル要素、マインドマップのプラグインを登録します。

## Boards を使う場面

ブレインストーミング、業務フロー、プロジェクト計画、ふりかえりボード、プロダクト構成図など、空間的に編集する領域が必要な場合は Boards から始めます。中心となるデータが構造化レコードと複数ビューであれば [Univer Bases](/guides/bases)、スプレッドシートであれば [Univer Sheets](/guides/sheets) を参照してください。

## パッケージのインストール

Boards の基本ランタイムはモデルパッケージと UI パッケージに分かれています。テーブル要素とマインドマップ要素は、Boards の上に追加する任意のパッケージです。

```bash
pnpm add @univerjs-pro/boards @univerjs-pro/boards-ui
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

## パッケージ構成

- `@univerjs-pro/boards`: Board データモデル、要素 schema、コマンド、mutation、アダプターサービス、Facade エントリ、`UniverBoardsPlugin`
- `@univerjs-pro/boards-ui`: Board キャンバス UI、ビューポート、選択、図形編集、コネクタ、付箋、インク操作、ツールバー、コンテキストメニュー、`UniverBoardsUIPlugin`
- `@univerjs-pro/boards-table`: Board テーブル要素の統合と `UniverBoardsTablePlugin`
- `@univerjs-pro/boards-table-ui`: テーブル要素 UI、レンダー統合、ロケールエントリ、`UniverBoardsTableUIPlugin`
- `@univerjs-pro/boards-mind`: マインドマップ要素の統合と `UniverBoardsMindPlugin`
- `@univerjs-pro/boards-mind-ui`: マインドマップ UI の統合と `UniverBoardsMindUIPlugin`

## プラグイン登録

以下は Boards に関係する登録部分だけです。実際のアプリケーションでは Univer core、レンダーエンジン、UI、License、Ink などの共通プラグインも必要です。

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/boards/facade'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})
```
