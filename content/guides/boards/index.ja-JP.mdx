## Univer Boards とは

UniverボードはUniver Office SDKのキャンバス製品です。 ドキュメントがグリッド、ページ、またはスライドデッキがなくなり、フリーフォームのワークスペース:ホワイトボード、図形、スティッキーノート、コネクタ、埋め込みテーブル、およびマインドマップがすべてここに所属しています。

[Web SDK](/guides/sheets)はブラウザに埋め込まれたキャンバスのために使用し、Web SDKはまたヘッドレスコンテンツ処理を扱います。[Server SDK](/server) は共同で、ファイル交換を提供し、[AI SDK](/ai)はあなたのボードを編集する代理店を可能にします。

ボードは、Web SDKの独立したユニットタイプです。ランタイムでは、アプリケーションは`UniverInstanceType.UNIVER_BOARD`ユニットを作成し、サポートが必要な要素のモデルとUIプラグインを登録します。

## ブラウザ互換性

Web SDKは、Chrome 88ターゲットにコンパイルします。このターゲットは、Web SDKがあらゆる環境で動作するということを意味しません。次のブラウザとNode.js環境がサポートされています。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK は `Intl.Segmenter` に依存しています。ブラウザやランタイム環境がサポートされていない場合は、対応する polyfill を最初に追加します。推奨される polyfill は `@formatjs/intl-segmenter` です。
</Callout>

互換性の問題が発生した場合は、最初に対応するポリフィルを適用します。問題が主張している場合は、[課題を提出する](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 互換性

<Callout type="warning">
  Node.js内でWeb SDKを実行しているセクションです。Web SDKがNode.jsに基づいてビルドツールを介してブラウザで動作する時には適用されません。
</Callout>

Web SDKはNode.js v18.17.0以降で動作します。

## 主な機能

- **ページと要素の注文**: `pages` に格納されているページと、各ページの `elements`、両方のレベルでの明示的な順序配列で保存可能なオブジェクト。
- **キャンバス要素**:テキスト、形状、画像、コネクタ、グループ、コンテナ、およびスイムレーン。
- **コマンド主導の編集**: 要素の変更, 順序付け, 親関係は、オプションの履歴とコラボレーションの統合のためのパーミッションとホックを運ぶ1つのコマンドレイヤーを介してルーティング.
- **ブラウザ キャンバス**:要素レンダリング、選択、変換、クリップボード、テキスト編集、ビューポート制御、パネル。
- **拡張可能なアダプター**:テーブル、マインドマップ、チャート、リソース、プリント、交換などのオプションのボード機能。
- **パージストエンス**:ページ、リソース、テーマ、アクティブページの状態を含む`IBoardData`スナップショットの作成、復元、および保存。

## ドキュメントの読み方

左側のnavbarは、基本から上級まで、ページを順番にリストします。そのため、読者はアプリケーションを構築しながらステップバイステップでそれらに従うことができます。ページは、任意の順番で読み込むことができ、ユースケースに適用しないページはスキップすることができます。サイドバーヘッダーは、Univerボードのドキュメントへの切り替えを提供します。

右側のコンテンツの表は、現在のページのセクション間のナビゲーションを提供します。ページをすばやく見つけるには、トップまたは検索ショートカット(Ctrl + KまたはCmd + K)で検索バーを使用します。

[クイックスタート](/guides/boards/getting-started/installation)ガイドをご覧ください。

## 前提知識

ドキュメントは新人のために書かれていますが、Web SDKに集中できるようにベースラインの知識を想定しています。

リーダーは、JavaScriptとその生態系の基本的な理解とドキュメントの最も多くを取得します。

Web SDKがNode.jsで動作する場合、Node.jsの基本的な理解も推奨しています。

同じボードを編集したり、共有履歴、コメント、ファイル変換が必要な場合は、対応するモジュールを[Univer Server SDK](/server)から追加して、アプリケーションバックエンドで実行します。認証、許可、ストレージ、およびデプロイメントは、アプリケーションの責任を負います。ブラウザで開くボードは、これらのサービスを必要としません。
