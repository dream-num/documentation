Avant d'installer Univer Boards, examinez les quatre concepts qui apparaissent dans son API et sa documentation. Ensemble, ils expliquent comment une carte est assemblée, stockée, modifiée et contrôlée.

## Notions fondamentales [#basic-concepts]

### Plugins

Univer fournit des fonctionnalités par l'intermédiaire de plugins. `@univerjs-pro/boards` fournit le modèle Board, les commandes et `UniverBoardsPlugin`; `@univerjs-pro/boards-ui` fournit la toile, l'interface d'édition, et `UniverBoardsUIPlugin`. Le texte riche, le dessin, l'encre et l'édition de forme sont des dépendances de rendu techniques qui sont enregistrées pendant la configuration. Vous n'avez pas besoin de connaissance préalable d'un autre produit Univer.

Enregistrez uniquement les plugins produits que votre application utilise. Le [guide d'installation](/guides/boards/getting-started/installation) liste la configuration complète du navigateur et ses dépendances.

### Instantané et modèle de données

`IBoardData` est la forme persistante d'une unité de conseil. Les pages sont stockées dans `pages`, avec leur ordre dans `pageOrder`; chaque page stocke ses éléments dans `elements` et de leur ordre d'exécution `elementOrder`. Les ressources, les thèmes, la page active, le zoom et les paramètres du tableau font également partie de l'instantané.

Utilisez un snapshot pour créer, enregistrer ou restaurer une carte. Après que l'unité est en cours d'exécution, ne modifiez pas directement l'objet snapspot. [Structure des données du Comité](/guides/boards/model/board-data) et [Éléments du conseil](/guides/boards/model/board-elements) décrivent le schéma.

### Commandes

Les changements d'exécution sont appliqués à travers des commandes. L'insertion d'un élément, le changement de sa transformation, le déplacement dans un conteneur ou le changement d'état de page maintient le modèle, la toile, le défaire/refaire et les chemins de collaboration cohérents lorsque le changement passe par le calque de commande ou le calque Facade.

Dans le code d'application, préférez le Facade API. Utilisez les ID de commande directement pour une intégration de niveau inférieur que la Facade n'expose pas.

### API Facade

Le Facade API enveloppe la commande Board et les calques de modèle dans `FBoard` et les poignées d'éléments. Importez `@univerjs-pro/boards/facade`, enregistrez les plugins, et créez l'API avec `FUniver.newAPI(univer)`. L'API peut ensuite créer ou trouver une carte, lire sa page active et ses éléments, et gérer les conteneurs et les nageaux.

Continuez avec [Installation et utilisation de base](/guides/boards/getting-started/installation), puis suivez le [Conseils Guide Facade API](/guides/boards/getting-started/facade) pour créer et modifier le contenu du tableau.
