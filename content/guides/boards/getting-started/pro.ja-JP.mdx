Univer Boards は Univer Pro の機能です。本番環境のアプリケーションには有効な Pro ライセンスが必要であり、ほかの Pro 製品と同様にデプロイ時の考慮事項があります。

## ライセンスプラグイン

Board プラグインより先に `UniverLicensePlugin` を登録します。

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

ライセンステキストはソース管理の対象外にしてください。ブラウザーアプリケーションでは、ビルド設定またはランタイム設定を通じてライセンステキストを注入します。

## パッケージスコープ

Board のパッケージは `@univerjs-pro` スコープで提供されています。

| 機能 | パッケージ |
| --- | --- |
| Board のコアモデル | `@univerjs-pro/boards` |
| ブラウザー向け Board UI | `@univerjs-pro/boards-ui` |
| テーブル要素 | `@univerjs-pro/boards-table`, `@univerjs-pro/boards-table-ui` |
| マインドマップ要素 | `@univerjs-pro/boards-mind`, `@univerjs-pro/boards-mind-ui` |

## デプロイに関する注意事項

- 製品に必要な要素のプラグインだけを登録してください。
- Board UI の CSS は、共通の Univer UI CSS より後に読み込んでください。
- Node.js サービスではモデルパッケージだけを使用してください。
- Board のスナップショットはアプリケーションデータとして永続化し、Univer のアップグレードと同時に移行してください。

ライセンス、サーバー、デプロイの詳細については、[Univer Pro](/guides/pro)を参照してください。
