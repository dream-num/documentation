Перед установкой досок Univer просмотрите четыре концепции, которые появляются в его API и документации.Вместе они объясняют, как собирается, хранится, изменяется и контролируется доска.

## Основные понятия [#basic-concepts]

### Плагины

Univer предоставляет функции через плагины. `@univerjs-pro/boards` обеспечивает модель платы, команды и `UniverBoardsPlugin`; `@univerjs-pro/boards-ui` предлагает холст, интерфейс редактирования и `UniverBoardsUIPlugin`. Богатый текст, рисунок, чернила и редактирование формы - это технические зависимости рендеринга, которые регистрируются во время настройки. Вам не нужны предварительные знания другого продукта Univer . Элементы таблицы и карты памяти предоставляются дополнительными плагинами платы.

Зарегистрируйте только плагины продукта, которые использует ваше приложение. [Руководство по установке](/guides/boards/getting-started/installation) перечисляет полную конфигурацию браузера и его зависимости.

### Снимок и модель данных

`IBoardData` - это постоянная форма блока платы. Страницы хранятся в `pages`, с их заказом в `pageOrder`; каждая страница хранит свои элементы в `elements` и их порядок рендеринга в `elementOrder`. Ресурсы, темы, активная страница, масштабирование и настройки платы также являются частью снимка.

Используйте моментальный снимок для создания, сохранения или восстановления платы. После запуска устройства не модифицируйте объект моментального снимка напрямую. [Структура данных Board Data Structure](/guides/boards/model/board-data) и [Элементы совета](/guides/boards/model/board-elements) описывают схему.

### Команды

Изменения времени выполнения применяются через команды. Вставка элемента, изменение его преобразования, перемещение его в контейнер или изменение состояния страницы поддерживает согласованность модели, холста, отмены / изменения и путей совместной работы, когда изменение проходит через командный уровень или слой Фасада.

В прикладном коде отдают предпочтение Facade API. Используйте идентификаторы команд непосредственно только для интеграции более низкого уровня, которую Фасад не раскрывает.

### Facade API

Facade API заворачивает уровни команд и моделей в `FBoard` и ручки элементов. Импортируйте `@univerjs-pro/boards/facade`, регистрируйте плагины и создайте API с `FUniver.newAPI(univer)`. Затем API может создавать или находить доску, читать ее активную страницу и элементы, а также управлять контейнерами и плавающими путями.

Продолжайте с [Установка и базовое использование](/guides/boards/getting-started/installation), а затем следуйте за [Руководство по Facade API](/guides/boards/getting-started/facade) для создания и редактирования содержимого платы.
