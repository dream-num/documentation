Facade API は、Univer のサービスとユニットモデルをアプリケーションから利用するためのレイヤーです。ボードの作成、アクティブなページの読み取り、要素の追加、コンテナの更新、スイムレーンの管理といった一般的なボード操作に使用します。

<Callout type="warning" title="注意">
  一部の Facade API は非同期です。変更直後にデータを読み取る必要がある場合は、`await` または `.then()` を使用してください。
</Callout>

## Facade エントリを有効にする

Boards は Univer Pro プラグインとして配布されています。アプリケーションで使用するボード機能に対応した Facade エントリをインポートします。

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

Univer インスタンスと必要なプラグインを登録した後に、API オブジェクトを作成します。

```ts
const univerAPI = FUniver.newAPI(univer)
```

## ボードを作成・読み取りする

Facade レイヤーを介してボードユニットを作成するには、`createBoard` を使用します。低レベルのセットアップコードでは、`univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)` を使用してユニットを作成します。

```ts
const board = univerAPI.createBoard({
  id: 'board-demo',
  name: 'Board Demo',
})

const activeBoard = univerAPI.getActiveBoard()
const sameBoard = univerAPI.getBoard(board.getId())
```

## ページと要素を操作する

`FBoard` Facade を使用すると、アプリケーションコードから内部サービスを解決せずに、アクティブなページの読み取り、要素の検索、要素データの更新を行えます。

```ts
const pageId = board.getActivePageId()
const elements = board.getElements(pageId)

await board.addElement({
  id: 'note-1',
  type: 'text',
  transform: { left: 120, top: 80, width: 240, height: 80 },
  text: 'Planning note',
}, { pageId })

await board.updateElement('note-1', {
  patch: {
    transform: { left: 160, top: 120, width: 280, height: 96 },
  },
  pageId,
})
```

## コンテナとスイムレーン

コンテナに属する要素を変更するには、ボードの Facade を使用します。コンテナ API は、ボードのスナップショット内の順序と親子関係を維持します。

```ts
const container = await board.createContainer({
  pageId,
  title: 'Backlog',
  transform: { left: 80, top: 80, width: 520, height: 360 },
})

await board.moveElementsToContainer(['note-1'], container.id, { pageId })
await board.fitContainerToContent(container.id, { pageId })
```
