La API de Facade proporciona una capa orientada a la aplicación sobre los servicios y modelos de unidades de Univer. Úselo para operaciones comunes del tablero, como crear tableros, leer páginas activas, agregar elementos, actualizar contenedores y administrar carriles.

<Callout type="warning" title="Caution">
Algunas API de Facade son asíncronas. Si necesita leer datos inmediatamente después de cambiarlos, use `await` o `.then()`.
</Callout>

## Habilite la entrada de fachada

Los tableros se distribuyen como complementos de Univer Pro. Importe la entrada de fachada para la capacidad del tablero utilizada por su aplicación:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

Cree el objeto API después de que se registren la instancia de Univer y los complementos necesarios:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Cree y lea un tablero

Utilice `createBoard` para crear una unidad de tablero a través de la capa de fachada. En el código de configuración de nivel inferior, cree la unidad con `univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)`.

```ts
const board = univerAPI.createBoard({
  id: 'board-demo',
  name: 'Board Demo',
})

const activeBoard = univerAPI.getActiveBoard()
const sameBoard = univerAPI.getBoard(board.getId())
```

## Trabajar con páginas y elementos

La fachada `FBoard` lee la página activa, busca elementos y actualiza los datos de los elementos sin requerir código de aplicación para resolver servicios internos.

```ts
const pageId = board.getActivePageId()
const elements = board.getElements(pageId)

await board.addElement({
  id: 'note-1',
  type: 'text',
  transform: { left: 120, top: 80, width: 240, height: 80 },
  text: 'Planning note',
}, { pageId })

await board.updateElement('note-1', {
  patch: {
    transform: { left: 160, top: 120, width: 280, height: 96 },
  },
  pageId,
})
```

## Contenedores y carriles

Utilice la fachada Board para cambios de membresía de contenedores. Las API de contenedor conservan el orden y las relaciones entre padres e hijos en la instantánea del tablero.

```ts
const container = await board.createContainer({
  pageId,
  title: 'Backlog',
  transform: { left: 80, top: 80, width: 520, height: 360 },
})

await board.moveElementsToContainer(['note-1'], container.id, { pageId })
await board.fitContainerToContent(container.id, { pageId })
```
