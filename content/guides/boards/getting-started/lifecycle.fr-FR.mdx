## Cycle de vie global

- **Début**: Univer initialise; il n'existe pas encore d'unité commerciale.
- **Prêt**: La première unité commerciale a été créée. Les unités ultérieures ne déclenchent pas cette étape à nouveau.
- **Rendu**: L'interface utilisateur standard a effectué son premier commutateur de rendu. Le contenu asynchrone ne peut pas encore être chargé.
- **Stabilité** : L'interface utilisateur standard atteint cette étape après un délai après la livraison. Elle n'attend pas que les tâches asynchrones soient terminées.

### API Facade

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="Ce que signale l’événement">

`LifeCycleChanged` rapporte la phase globale de Univer. Si le plugin B se charge après la phase globale `Ready`, B appelle toujours `onReady()` mais aucun événement global supplémentaire `Ready` n'est émis.

Un auditeur peut recevoir l'étape actuelle immédiatement après son ajout, y compris `Starting`. Pour lire seulement l'étape courante, appelez directement `univerAPI.getCurrentLifecycleStage()` .

</Callout>

Pour supprimer un auditeur, disposer l'objet `disposable` retourné :

```typescript
disposable.dispose()
```

## Hooks de cycle de vie des plugins

Un plugin exécute `onStarting()` quand il charge, puis rattrape jusqu'à la phase globale actuelle. Changez le temps de charge de B pour comparer ses appels de crochet avec ceux de A.

<LifecycleDemo />

Les plugins de type Business chargent généralement avant la construction de la première unité de ce type. Pour un type qui a déjà commencé, de nouveaux plugins de ce type chargent dans un lot différé. Les dépendances explicites peuvent causer un plugin à charger plus tôt.

Crochets dans un lot exécuté synchronement, étape par étape et en ordre de dépendance, et n'attendez pas de travail asynchrone à l'intérieur d'eux. Confirmez que l'unité, l'élément DOM ou la ressource est prêt avant d'y accéder.
