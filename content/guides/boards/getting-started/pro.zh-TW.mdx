Univer Boards 是 Univer SDK Pro 的功能。正式環境應用程式必須具備有效的 Pro 授權，並採用與其他 Pro 產品相同的部署考量。

## 授權外掛程式

請先註冊 `UniverLicensePlugin`，再註冊 Board 外掛程式：

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

請勿將授權文字納入版本控制。在瀏覽器應用程式中，請透過建置或執行階段設定注入授權文字。

## 套件命名空間

Board 套件位於 `@univerjs-pro` 命名空間：

| 功能 | 套件 |
| --- | --- |
| 核心畫板模型 | `@univerjs-pro/boards` |
| 瀏覽器版畫板 UI | `@univerjs-pro/boards-ui` |
| 表格元素 | `@univerjs-pro/boards-table`, `@univerjs-pro/boards-table-ui` |
| 心智圖元素 | `@univerjs-pro/boards-mind`, `@univerjs-pro/boards-mind-ui` |

## 部署注意事項

- 只註冊產品所需的元素外掛程式。
- 請在共用 Univer UI CSS 之後載入 Board UI CSS。
- Node.js 服務只需使用模型套件。
- 將 Board 快照當作應用程式資料持久化，並在升級 Univer 時一併遷移。

請從[伺服器端整合](/guides/server-integration)開始，依序執行範例、接入業務、驗證持久化和權限。實作細節與可執行的 Web/Server 範例請見 [Univer Office 文件](https://office.univer.ai/zh-CN/collaboration/quick-start)。
