Univer Boards 的 API 和文档中反复出现四个概念，安装前应先理解它们。这些概念分别说明 Board 如何组装、存储、变更和控制。

## 基本概念 [#basic-concepts]

### 插件

Univer 通过插件提供功能。`@univerjs-pro/boards` 提供 Board 模型、命令和 `UniverBoardsPlugin`；`@univerjs-pro/boards-ui` 提供画布、编辑界面和 `UniverBoardsUIPlugin`。富文本、绘图、墨迹和形状编辑属于安装时注册的技术渲染依赖，使用前无需了解其他 Univer 产品。表格和思维导图元素由可选的 Board 插件提供。

应用只注册实际使用的产品插件。[安装指南](/guides/boards/getting-started/installation)列出了完整的浏览器端配置及其依赖。

### 快照和数据模型

`IBoardData` 是 Board 单元的持久化格式。页面存储在 `pages` 中，页面顺序存储在 `pageOrder` 中；每个页面的元素存储在 `elements` 中，渲染顺序存储在 `elementOrder` 中。资源、主题、当前页面、缩放比例和 Board 设置也属于快照的一部分。

快照用于创建、保存或恢复 Board。单元运行后，不要直接修改快照对象。具体结构参见 [Board 数据结构](/guides/boards/model/board-data)和 [Board 元素](/guides/boards/model/board-elements)。

### 命令

运行时的变更通过命令执行。插入元素、修改元素变换、将元素移入容器或更改页面状态时，只要经由命令层或 Facade 层，模型、画布、撤销/重做和协同路径即可保持一致。

应用代码应优先使用 Facade API。仅在需要 Facade 未提供的更底层集成时，才直接使用命令 ID。

### Facade API

Facade API 以 `FBoard` 和元素句柄封装 Board 的命令层与模型层。导入 `@univerjs-pro/boards/facade`，注册插件，再调用 `FUniver.newAPI(univer)` 创建 API。此后即可创建或查找 Board、读取当前页面和元素，以及管理容器和泳道。

接下来请阅读[安装和基本使用](/guides/boards/getting-started/installation)，再参照 [Boards Facade API 指南](/guides/boards/getting-started/facade)创建和编辑 Board 内容。
