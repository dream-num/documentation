In diesem Kapitel wird die Installation und grundlegende Verwendung von Univer Boards vorgestellt. Boards wird als Univer Pro-Produkt vertrieben und verwendet derzeit den Plugin-Modus.

Wenn Sie mit den Kernkonzepten von Univer nicht vertraut sind, lesen Sie zuerst [Quickstart](/guides/boards/getting-started/quickstart).

## Mit Plugin-Modus erstellen

Univer stellt Boards als eine Reihe von Plugins zur Verfügung. Ein Browser-Editor registriert normalerweise die gemeinsame Univer-Laufzeit, das Pro-Lizenz-Plugin, Dokument- und Zeichnungsabhängigkeiten und dann das Board-Modell und die UI-Plugins.

### Installation

Installieren Sie die Mindestpakete für einen Browser-Board-Editor:

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab>

### Verwendung

<Callout type="warning" title="Caution">
  - Registrieren Sie `UniverLicensePlugin`, bevor Sie Board-Plugins registrieren.
  - Importieren Sie Shared UI CSS vor Produkt-UI-CSS.
  - Registrierung optional Element-Plugins, bevor Sie Snapshots öffnen, die diese Elementtypen enthalten.
</Callout>

<Steps>
  <Step>
Importieren Sie Stile, Gebietsschemapakete und die erforderlichen Plugins:

    ```ts
    import { UniverBoardsPlugin } from '@univerjs-pro/boards'
    import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
    import BoardsUIEnUS from '@univerjs-pro/boards-ui/locale/en-US'
    import { UniverInkUIPlugin } from '@univerjs-pro/ink-ui'
    import InkUIEnUS from '@univerjs-pro/ink-ui/locale/en-US'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui'
    import DrawingUIEnUS from '@univerjs/drawing-ui/locale/en-US'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs/drawing-ui/lib/index.css'
    import '@univerjs-pro/ink-ui/lib/index.css'
    import '@univerjs-pro/boards-ui/lib/index.css'
    ```
  </Step>
  <Step>
Importieren Sie den Fassadeneintrag, wenn Sie die Fassaden-API verwenden möchten:

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/boards/facade'
    ```
  </Step>
  <Step>
Erstellen Sie eine Univer-Instanz, registrieren Sie Plugins und erstellen Sie eine Board-Einheit:

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          DocsUIEnUS,
          DrawingUIEnUS,
          InkUIEnUS,
          BoardsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)
    univer.registerPlugin(UniverDrawingUIPlugin)
    univer.registerPlugin(UniverInkUIPlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBoardsPlugin)
    univer.registerPlugin(UniverBoardsUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

Das von `FUniver.newAPI(univer)` zurückgegebene Objekt `univerAPI` ist die Fassaden-API von Univer. Verwenden Sie es, um Boards zu erstellen und Board-Elemente zu bearbeiten.

## Optionale Feature-Pakete

Feature-Pakete hinzufügen, wenn der Board-Editor den entsprechenden Elementtyp benötigt:

```shell
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

Beispiele für die Feature-Registrierung finden Sie unter [Tabellen](/guides/boards/features/tables), [Mind Maps](/guides/boards/features/mind-maps) und [Import & Export](/guides/boards/features/import-export).

## Andere Veröffentlichungskanäle

Neben stabilen Veröffentlichungen bietet Univer Alpha-, Beta- und Nightly-Kanäle an. Mit diesen Kanälen können Sie kommende Funktionen früher testen, sie weisen jedoch möglicherweise unvollständiges oder instabiles Verhalten auf. Vermeiden Sie den Einsatz in der Produktion, es sei denn, Sie haben einen Validierungsplan.

```package-install
npm install @univerjs-pro/boards@alpha
npm install @univerjs-pro/boards@beta
```
