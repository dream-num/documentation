Univer Boards 的 API 和文件中反覆出現四個概念，安裝前應先理解它們。這些概念分別說明 Board 如何組裝、儲存、變更和控制。

## 基本概念 [#basic-concepts]

### 外掛程式

Univer 透過外掛提供功能。`@univerjs-pro/boards` 提供 Board 模型、命令和 `UniverBoardsPlugin`；`@univerjs-pro/boards-ui` 提供畫布、編輯介面和 `UniverBoardsUIPlugin`。富文字、繪圖、墨跡和形狀編輯屬於安裝時註冊的技術渲染依賴，使用前無需瞭解其他 Univer 產品。表格和思維導圖元素由可選的 Board 外掛提供。

應用只註冊實際使用的產品外掛。[安裝指南](/guides/boards/getting-started/installation)列出了完整的瀏覽器端配置及其依賴。

### 快照和資料模型

`IBoardData` 是 Board 單元的持久化格式。頁面儲存在 `pages` 中，頁面順序儲存在 `pageOrder` 中；每個頁面的元素儲存在 `elements` 中，渲染順序儲存在 `elementOrder` 中。資源、主題、當前頁面、縮放比例和 Board 設定也屬於快照的一部分。

快照用於建立、儲存或恢復 Board。單元執行後，不要直接修改快照物件。具體結構參見 [Board 資料結構](/guides/boards/model/board-data)和 [Board 元素](/guides/boards/model/board-elements)。

### 命令

執行時的變更透過命令執行。插入元素、修改元素變換、將元素移入容器或更改頁面狀態時，只要經由命令層或 Facade 層，模型、畫布、撤銷/重做和協同路徑即可保持一致。

應用程式碼應優先使用 Facade API。僅在需要 Facade 未提供的更底層整合時，才直接使用命令 ID。

### Facade API

Facade API 以 `FBoard` 和元素控制代碼封裝 Board 的命令層與模型層。匯入 `@univerjs-pro/boards/facade`，註冊外掛，再呼叫 `FUniver.newAPI(univer)` 建立 API。此後即可建立或查詢 Board、讀取當前頁面和元素，以及管理容器和泳道。

接下來請閱讀[安裝和基本使用](/guides/boards/getting-started/installation)，再參照 [Boards Facade API 指南](/guides/boards/getting-started/facade)建立和編輯 Board 內容。
