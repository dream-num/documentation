Univer Boards는 Univer SDK Pro 기능입니다. 프로덕션 애플리케이션에는 유효한 Pro 라이선스가 필요하며, 다른 Pro 제품과 동일한 배포 사항을 고려해야 합니다.

## 라이선스 플러그인

Board 플러그인을 등록하기 전에 `UniverLicensePlugin`을 등록하세요.

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

라이선스 텍스트는 소스 제어 외부에 보관하세요. 브라우저 애플리케이션에서는 빌드 또는 런타임 구성을 통해 주입하세요.

## 패키지 범위

Board 패키지는 `@univerjs-pro` 범위에 속합니다.

| 기능 | 패키지 |
| --- | --- |
| 핵심 Board 모델 | `@univerjs-pro/boards` |
| 브라우저 Board UI | `@univerjs-pro/boards-ui` |
| 표 요소 | `@univerjs-pro/boards-table`, `@univerjs-pro/boards-table-ui` |
| 마인드맵 요소 | `@univerjs-pro/boards-mind`, `@univerjs-pro/boards-mind-ui` |

## 배포 참고 사항

- 제품에 필요한 요소 플러그인만 등록하세요.
- 공유 Univer UI CSS 다음에 Board UI CSS를 로드하세요.
- Node.js 서비스에서는 모델 패키지만 사용하세요.
- Board 스냅샷을 애플리케이션 데이터로 저장하고 Univer 업그레이드와 함께 마이그레이션하세요.

라이선스, 서버 및 배포에 관한 자세한 내용은 [Univer SDK Pro](/guides/pro)를 참고하세요.
