## 全域生命週期

- **Starting**: 初始化階段，尚無任何業務例項。
- **Ready**: 首個業務例項已建立。此後建立的例項不會再次觸發這個階段。
- **Rendered**: 標準 UI 已完成首次渲染切換，非同步內容可能尚未載入完成。
- **Steady**: 標準 UI 在 Rendered 之後延遲進入這一階段，不等待非同步任務全部結束。

### Facade API

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="事件監聽的範圍">

`LifeCycleChanged` 反映 Univer 的全域性階段。例如，全域性已進入 `Ready` 後再載入外掛 B，B 仍會呼叫 `onReady()`，但不會再次觸發全域性 `Ready` 事件。

監聽器新增後可能立即收到當前階段，`Starting` 也在其中。如需僅取得當前階段，直接呼叫 `univerAPI.getCurrentLifecycleStage()`。

</Callout>

要移除監聽器，請釋放返回的 `disposable` 物件：

```typescript
disposable.dispose()
```

## 外掛生命週期鉤子

外掛載入時執行 `onStarting()`，隨後補執行至當前全域性階段的鉤子。調整 B 的載入時機，即可對比它與 A 的鉤子呼叫。

<LifecycleDemo />

通用外掛在註冊時載入。業務型別的外掛通常在首次構造該型別例項之前載入。若該型別已啟動，新增的外掛會推遲到批次中載入。顯式依賴可以使外掛提前載入。

同一批外掛的鉤子按依賴順序逐階段同步執行，不等待其中的非同步任務。訪問具體的例項、DOM 元素或資源之前，需先確認其已就緒。
