Facade API 是面向應用的介面層，位於 Univer 服務和單元模型之上。常見的 Board 操作均由它完成：建立畫板、讀取當前頁面、新增元素、更新容器、管理泳道。

<Callout type="warning" title="注意">
  Board 的變更操作是同步的，返回 `boolean` 或可能為空的控制代碼。讀取結果之前請檢查返回值。
</Callout>

## 啟用 Facade 進入點

Boards 以 Web SDK 外掛的形式釋出。請為應用使用的 Board 能力匯入對應的 Facade 入口：

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

Univer 例項和所需外掛註冊完成後，建立 API 物件：

```ts
const univerAPI = FUniver.newAPI(univer)
```
