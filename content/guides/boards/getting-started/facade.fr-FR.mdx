Facade API fournit une couche destinée aux applications au-dessus des services et des modèles d’unité Univer. Utilisez-la pour les opérations Board courantes, comme créer des boards, lire les pages actives, ajouter des éléments, mettre à jour des conteneurs et gérer les couloirs.

<Callout type="warning" title="Attention">
  Les mutations Board sont synchrones et renvoient un `boolean` ou un objet nullable. Vérifiez la valeur de retour.
</Callout>

## Activer le point d’entrée de Facade

Boards est distribué sous forme de plugins Univer Pro. Importez le point d’entrée de Facade correspondant à la fonctionnalité Board utilisée par votre application :

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

Créez l’objet API après avoir enregistré l’instance Univer et les plugins requis :

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Créer et lire un board

Utilisez `createBoard` pour créer une unité Board par l’intermédiaire de la couche Facade. Dans le code de configuration de plus bas niveau, créez l’unité avec `univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)`.

```ts
const board = univerAPI.createBoard({
  id: 'board-demo',
  name: 'Board Demo',
})

const activeBoard = univerAPI.getActiveBoard()
const sameBoard = univerAPI.getBoard(board.getId())
```

## Manipuler les pages et les éléments

La Facade `FBoard` lit la page active, recherche des éléments et met à jour leurs données sans que le code de l’application ait à résoudre les services internes.

```ts
const elements = board.getElements()

const note = board.insertText({
  id: 'note-1',
  left: 120,
  top: 80,
  width: 240,
  height: 80,
  text: 'Planning note',
})
if (!note) throw new Error('Cannot insert note')

board.setElementTransform('note-1', {
  left: 160,
  top: 120,
  width: 280,
  height: 96,
})
```

## Conteneurs et couloirs

Utilisez la Facade Board pour modifier l’appartenance aux conteneurs. Les API de conteneur conservent l’ordre et les relations parent-enfant dans l’instantané Board.

```ts
const containerId = 'backlog'
const containerCreated = board.createContainer({
  id: containerId,
  title: 'Backlog',
  left: 80,
  top: 80,
  width: 520,
  height: 360,
})
if (!containerCreated) {
  throw new Error('Cannot create container')
}

board.moveElementsToContainer(['note-1'], containerId)
board.fitContainerToContent(containerId)
```
