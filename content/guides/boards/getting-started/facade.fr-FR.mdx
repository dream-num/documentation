Facade API fournit une couche destinée aux applications au-dessus des services et des modèles d’unité Univer. Utilisez-la pour les opérations Board courantes, comme créer des boards, lire les pages actives, ajouter des éléments, mettre à jour des conteneurs et gérer les couloirs.

<Callout type="warning" title="Attention">
  Les mutations Board sont synchrones et renvoient un `boolean` ou un objet nullable. Vérifiez la valeur de retour.
</Callout>

## Activer le point d’entrée de Facade

Boards est distribué sous forme de plugins Univer SDK Pro. Importez le point d’entrée de Facade correspondant à la fonctionnalité Board utilisée par votre application :

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

Créez l’objet API après avoir enregistré l’instance Univer et les plugins requis :

```ts
const univerAPI = FUniver.newAPI(univer)
```
