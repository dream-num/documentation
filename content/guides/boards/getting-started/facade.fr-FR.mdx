Facade API est la couche d'application sur les services et les modèles d'unités Univer. Elle couvre les opérations communes de la Commission : création d'une carte, lecture de la page active, ajout d'éléments, mise à jour des conteneurs et gestion des nageuses.

<Callout type="warning" title="Attention">
  Les mutations Board sont synchrones et renvoient un `boolean` ou un objet nullable. Vérifiez la valeur de retour.
</Callout>

## Activer le point d’entrée de Facade

Les panneaux sont distribués sous forme de plugins Web SDK. Importez l'entrée de façade pour la capacité de la carte que l'application utilise:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

Créez l'objet API après l'instance Univer et les plugins requis sont enregistrés :

```ts
const univerAPI = FUniver.newAPI(univer)
```
