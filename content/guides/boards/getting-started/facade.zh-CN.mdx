Facade API 在 Univer 服务和单元模型之上提供了面向应用的接口层。你可以用它执行常见的 Board 操作，例如创建画板、读取当前页面、添加元素、更新容器和管理泳道。

<Callout type="warning" title="注意">
  Board 变更 API 是同步的，并返回 `boolean` 或可为空的句柄。读取结果前请检查返回值。
</Callout>

## 启用 Facade 入口

Boards 以 Univer Pro 插件的形式分发。请为应用所使用的 Board 功能导入对应的 Facade 入口：

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

注册 Univer 实例和所需插件后，创建 API 对象：

```ts
const univerAPI = FUniver.newAPI(univer)
```

## 创建和读取画板

使用 `createBoard` 通过 Facade 层创建 Board 单元。在底层初始化代码中，请使用 `univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)` 创建该单元。

```ts
const board = univerAPI.createBoard({
  id: 'board-demo',
  name: 'Board Demo',
})

const activeBoard = univerAPI.getActiveBoard()
const sameBoard = univerAPI.getBoard(board.getId())
```

## 操作页面和元素

通过 `FBoard` Facade，可以读取当前页面、查找元素和更新元素数据，而无需在应用代码中解析内部服务。

```ts
const elements = board.getElements()

const note = board.insertText({
  id: 'note-1',
  left: 120,
  top: 80,
  width: 240,
  height: 80,
  text: 'Planning note',
})
if (!note) throw new Error('Cannot insert note')

board.setElementTransform('note-1', {
  left: 160,
  top: 120,
  width: 280,
  height: 96,
})
```

## 容器和泳道

使用 Board Facade 更改元素所属的容器。容器 API 会保留 Board 快照中的排列顺序和父子关系。

```ts
const containerId = 'backlog'
const containerCreated = board.createContainer({
  id: containerId,
  title: 'Backlog',
  left: 80,
  top: 80,
  width: 520,
  height: 360,
})
if (!containerCreated) {
  throw new Error('Cannot create container')
}

board.moveElementsToContainer(['note-1'], containerId)
board.fitContainerToContent(containerId)
```
