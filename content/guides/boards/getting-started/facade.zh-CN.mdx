Facade API 是面向应用的接口层，位于 Univer 服务和单元模型之上。常见的 Board 操作均由它完成：创建画板、读取当前页面、添加元素、更新容器、管理泳道。

<Callout type="warning" title="注意">
  Board 的变更操作是同步的，返回 `boolean` 或可能为空的句柄。读取结果之前请检查返回值。
</Callout>

## 启用 Facade 入口

Boards 以 Web SDK 插件的形式发布。请为应用使用的 Board 能力导入对应的 Facade 入口：

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

Univer 实例和所需插件注册完成后，创建 API 对象：

```ts
const univerAPI = FUniver.newAPI(univer)
```
