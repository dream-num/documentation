Univer Boards 是一项 Univer Pro 功能。生产应用需要有效的 Pro 许可证，并且要考虑与其他 Pro 产品相同的部署事项。

## 许可证插件

请先注册 `UniverLicensePlugin`，再注册 Board 插件：

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

请勿将许可证文本纳入源代码管理。在浏览器应用中，请通过构建配置或运行时配置注入许可证文本。

## 软件包命名空间

Board 软件包位于 `@univerjs-pro` 命名空间下：

| 功能 | 软件包 |
| --- | --- |
| Board 核心模型 | `@univerjs-pro/boards` |
| 浏览器端 Board UI | `@univerjs-pro/boards-ui` |
| 表格元素 | `@univerjs-pro/boards-table`, `@univerjs-pro/boards-table-ui` |
| 思维导图元素 | `@univerjs-pro/boards-mind`, `@univerjs-pro/boards-mind-ui` |

## 部署注意事项

- 只注册产品所需的元素插件。
- 在 Univer 通用 UI CSS 之后加载 Board UI CSS。
- 在 Node.js 服务中只使用模型软件包。
- 将 Board 快照作为应用数据持久化，并在升级 Univer 时一并迁移。

有关许可证、服务器和部署的详细信息，请参阅 [Univer Pro](/guides/pro)。
