Univer Boards входит в состав Univer SDK Pro. Для рабочих приложений требуется действующая лицензия Pro и соблюдение тех же требований к развёртыванию, что и для других продуктов Pro.

## Плагин лицензии

Зарегистрируйте `UniverLicensePlugin` перед плагинами Boards:

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

Не храните текст лицензии в системе контроля версий. В браузерных приложениях передавайте его через конфигурацию сборки или среды выполнения.

## Область пакетов

Пакеты Boards находятся в области `@univerjs-pro`:

| Возможность | Пакеты |
| --- | --- |
| Базовая модель доски | `@univerjs-pro/boards` |
| Интерфейс доски для браузера | `@univerjs-pro/boards-ui` |
| Элементы таблиц | `@univerjs-pro/boards-table`, `@univerjs-pro/boards-table-ui` |
| Элементы интеллект-карт | `@univerjs-pro/boards-mind`, `@univerjs-pro/boards-mind-ui` |

## Рекомендации по развёртыванию

- Регистрируйте только те плагины элементов, которые нужны вашему продукту.
- Загружайте CSS интерфейса Boards после общего CSS интерфейса Univer.
- В сервисах Node.js используйте только пакеты моделей.
- Храните снимки состояния Boards как данные приложения и переносите их при обновлении Univer.

Следуйте руководству по [интеграции сервера](/guides/server-integration): запустите пример, подключите приложение и проверьте хранение данных и права доступа. Реализация и примеры Web/Server находятся в [Univer Office](https://office.univer.ai/collaboration/quick-start).
