Univer Boards est une fonctionnalité d’Univer SDK Pro. Les applications en production nécessitent une licence Pro valide et doivent respecter les mêmes contraintes de déploiement que les autres produits Pro.

## Plugin de licence

Enregistrez `UniverLicensePlugin` avant les plugins Board :

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

Conservez le texte de la licence hors du système de gestion de versions. Dans les applications web, injectez-le par l’intermédiaire de votre configuration de build ou d’exécution.

## Portée des paquets

Les paquets Board appartiennent au scope `@univerjs-pro` :

| Fonctionnalité | Paquets |
| --- | --- |
| Modèle Board principal | `@univerjs-pro/boards` |
| Interface Board pour navigateur | `@univerjs-pro/boards-ui` |
| Éléments de tableau | `@univerjs-pro/boards-table`, `@univerjs-pro/boards-table-ui` |
| Éléments de carte mentale | `@univerjs-pro/boards-mind`, `@univerjs-pro/boards-mind-ui` |

## Remarques sur le déploiement

- Enregistrez uniquement les plugins d’éléments nécessaires à votre produit.
- Chargez la feuille de style CSS de l’interface Board après celle de l’interface Univer partagée.
- Dans les services Node.js, utilisez uniquement les paquets du modèle.
- Conservez les instantanés Board comme données d’application et migrez-les lors des mises à niveau d’Univer.

Suivez l’[intégration serveur](/guides/server-integration) pour exécuter l’exemple, connecter votre application et vérifier la persistance et les autorisations. Les détails et exemples Web/Server sont disponibles sur [Univer Office](https://office.univer.ai/collaboration/quick-start).
