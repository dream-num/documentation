Univer Boards ist eine Funktion von Univer Pro. Produktionsanwendungen benötigen eine gültige Pro-Lizenz und dieselben Überlegungen zur Bereitstellung wie andere Pro-Produkte.

## Lizenz-Plugin

Registrieren Sie `UniverLicensePlugin`, bevor Sie Board-Plugins registrieren:

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

Bewahren Sie den Lizenztext außerhalb der Quellcodeverwaltung auf. In Browseranwendungen fügen Sie es über Ihre Build- oder Laufzeitkonfiguration ein.

## Paketumfang

Board-Pakete befinden sich im `@univerjs-pro`-Bereich:

| Funktionen | Pakete |
| --- | --- |
| Kernplatinenmodell | `@univerjs-pro/boards` |
| Browserboard-Benutzeroberfläche | `@univerjs-pro/boards-ui` |
| Tabellenelemente | `@univerjs-pro/boards-table`, `@univerjs-pro/boards-table-ui` |
| Mindmap-Elemente | `@univerjs-pro/boards-mind`, `@univerjs-pro/boards-mind-ui` |

## Bereitstellungshinweise

- Registrieren Sie nur die für Ihr Produkt erforderlichen Element-Plugins.
- Laden Sie Board-UI-CSS nach gemeinsamem Univer-UI-CSS.
- Verwenden Sie Modellpakete nur in Node.js Dienste.
- Board-Snapshots als Anwendungsdaten beibehalten und zusammen mit Univer-Upgrades migrieren.

Details zu Lizenz, Server und Bereitstellung finden Sie unter [Univer Pro](/guides/pro).
