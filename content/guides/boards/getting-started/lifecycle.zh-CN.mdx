## 全局生命周期

- **Starting**: 初始化阶段，尚无任何业务实例。
- **Ready**: 首个业务实例已创建。此后创建的实例不会再次触发这个阶段。
- **Rendered**: 标准 UI 已完成首次渲染切换，异步内容可能尚未加载完成。
- **Steady**: 标准 UI 在 Rendered 之后延迟进入这一阶段，不等待异步任务全部结束。

### Facade API

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="事件监听的范围">

`LifeCycleChanged` 反映 Univer 的全局阶段。例如，全局已进入 `Ready` 后再加载插件 B，B 仍会调用 `onReady()`，但不会再次触发全局 `Ready` 事件。

监听器添加后可能立即收到当前阶段，`Starting` 也在其中。如需仅获取当前阶段，直接调用 `univerAPI.getCurrentLifecycleStage()`。

</Callout>

要移除监听器，请释放返回的 `disposable` 对象：

```typescript
disposable.dispose()
```

## 插件生命周期钩子

插件加载时执行 `onStarting()`，随后补执行至当前全局阶段的钩子。调整 B 的加载时机，即可对比它与 A 的钩子调用。

<LifecycleDemo />

通用插件在注册时加载。业务类型的插件通常在首次构造该类型实例之前加载。若该类型已启动，新增的插件会推迟到批量中加载。显式依赖可以使插件提前加载。

同一批插件的钩子按依赖顺序逐阶段同步执行，不等待其中的异步任务。访问具体的实例、DOM 元素或资源之前，需先确认其已就绪。
