Facade API bietet eine anwendungsorientierte Ebene über Univer-Diensten und Einheitenmodellen. Verwenden Sie es für allgemeine Board-Vorgänge wie das Erstellen von Boards, das Lesen aktiver Seiten, das Hinzufügen von Elementen, das Aktualisieren von Containern und das Verwalten von Swimlanes.

<Callout type="warning" title="Caution">
Board-Mutationen sind synchron und geben `boolean` oder ein optionales Handle zurück. Prüfen Sie den Rückgabewert.
</Callout>

## Aktivieren Sie den Fassadeneintrag

Boards wird als Univer Pro-Plugins vertrieben. Importieren Sie den Fassadeneintrag für die von Ihrer Anwendung verwendete Board-Funktion:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

Erstellen Sie das API-Objekt, nachdem die Univer-Instanz und die erforderlichen Plugins registriert wurden:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Erstellen und lesen Sie ein Board

Verwenden Sie `createBoard`, um eine Board-Einheit durch die Fassadenebene zu erstellen. Erstellen Sie im Setup-Code auf niedrigerer Ebene die Einheit mit `univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)`.

```ts
const board = univerAPI.createBoard({
  id: 'board-demo',
  name: 'Board Demo',
})

const activeBoard = univerAPI.getActiveBoard()
const sameBoard = univerAPI.getBoard(board.getId())
```

## Arbeiten Sie mit Seiten und Elementen

Die `FBoard`-Fassade liest die aktive Seite, sucht nach Elementen und aktualisiert Elementdaten, ohne dass Anwendungscode zum Auflösen interner Dienste erforderlich ist.

```ts
const elements = board.getElements()

const note = board.insertText({
  id: 'note-1',
  left: 120,
  top: 80,
  width: 240,
  height: 80,
  text: 'Planning note',
})
if (!note) throw new Error('Cannot insert note')

board.setElementTransform('note-1', {
  left: 160,
  top: 120,
  width: 280,
  height: 96,
})
```

## Container und Swimlanes

Verwenden Sie die Board-Fassade für Änderungen der Containermitgliedschaft. Container-APIs bewahren die Reihenfolge und Eltern-Kind-Beziehungen im Board-Snapshot.

```ts
const containerId = 'backlog'
const containerCreated = board.createContainer({
  id: containerId,
  title: 'Backlog',
  left: 80,
  top: 80,
  width: 520,
  height: 360,
})
if (!containerCreated) {
  throw new Error('Cannot create container')
}

board.moveElementsToContainer(['note-1'], containerId)
board.fitContainerToContent(containerId)
```
