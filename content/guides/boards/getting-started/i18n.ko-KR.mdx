## 인터페이스 언어

`locale`은 메뉴, 도구 팁, 대화 상자 및 기타 번역 된 UI 텍스트에 사용되는 언어 팩을 선택합니다. `locales`은 하나를 선택하지 않고 언어 팩을 등록합니다. 설정은 Univer 인스턴스의 단위로 공유됩니다. `LocaleType` 값을 `LocaleType.EN_US`와 같은 사용하십시오.

- **모든 제품: UI**: `locale`는 메뉴, 툴팁, 대화 상자 및 플러그인 라벨의 언어를 변경합니다. 그것은 사용자 콘텐츠를 번역하거나 기존 단위로 이름을 변경하지 않습니다.
- **장: 세포 체재 및 공식**: 셀에서 렌더링 된 번호와 날짜는 먼저 번호 형식 로컬 오버라이드를 통해 해결, 그 후 작업 책 스냅 샷 `locale`, 마지막으로 인스턴스 `locale`. `region`는 그들 중 하나를 대체하지 않습니다. `DOLLAR` 및 금융 결과의 통화 형식과 같은 공식 행동은 여전히 `locale`를 사용하고, CJK 입력 정상화는 또한 `locale`을 사용합니다.
- **Docs: 통계**: `locale`는 단어 세그먼트와 계산을 결정합니다.

### 실행 중 언어 변경

모든 설치된 플러그인의 언어 팩을로드하고 전환 언어 전에 미리 설정. `loadLocales()`는 전환 언어없이 번역을 병합; `setLocale()`은 언어를 선택하지만 아무것도 다운로드합니다. 누락 된 번역 키는 키 자체로 표시됩니다. 예를 들어 공유 UI 팩을로드합니다. 다른 설치된 플러그인의 대상 언어 팩은 동일한 통화로 병합해야합니다.

```typescript
import { LocaleType, mergeLocales } from '@univerjs/core'
import UIEnUS from '@univerjs/ui/locale/en-US'

univerAPI.loadLocales(LocaleType.EN_US, mergeLocales(UIEnUS))
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentLocale()) // enUS
```

### 사용자 지정 언어 팩

Univer는 또한 주문 언어 팩을 지원합니다. 필요한 언어 팩 객체를 조립하고 `Univer` 인스턴스로 전달하십시오. 미리 설치된 언어 팩은 `<rootDir>/packages/<PLUGIN_NAME>/locale`에 보통 저장됩니다.

```typescript
import { LocaleType, Univer } from '@univerjs/core'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: {
      ui: {
        shortcut: {
          undo: '元に戻す',
          redo: 'やり直す',
        },
      },
    },
  },
})
```

### 번역 기여하기

Univer는 현재 다음과 같은 기본 제공 언어 팩을 지원합니다.

- `zh-CN`: 중국어 간체
- `en-US`: 영어
- `zh-TW`: 중국어 번체
- `zh-HK`: 중국어 번체(홍콩)
- `ru-RU`: 러시아어
- `vi-VN`: 베트남어
- `fa-IR`: 페르시아어
- `fr-FR`: 프랑스어
- `ja-JP`: 일본어
- `ko-KR`: 한국어
- `es-ES`: 스페인어
- `ca-ES`: 카탈루냐어
- `sk-SK`: 슬로바키아어
- `ar-SA`: 아랍어
- `de-DE`: 독일어
- `id-ID`: 인도네시아어
- `it-IT`: 이탈리아어
- `pl-PL`: 폴란드어
- `pt-BR`: 포르투갈어(브라질)

Univer는 오픈 소스이며, 전세계 개발자들이 로컬을 추가하거나 개선할 수 있도록 환영합니다.

## 지역 설정

`region`는 해당 지역 인식 기능에 따라 지역 협약을 선택합니다. 설정은 Univer 인스턴스의 단위에 의해 공유됩니다.

둘 다 조정은 `LocaleType` 가치를 가지고 갑니다. 예를 들면, `LocaleType.EN_US`는 `enUS`이고, `en-US`는 언어 팩 파일 이름과 BCP 47 꼬리표입니다. `region`로 `US` `SG`와 같은 국가 부호를 통과하지 마십시오. 지역은 UI가 다른 Locale를 이용하는 때 그것의 자신의 언어 팩을 필요로 하지 않습니다.

`region`를 명시하지 않고 나중에 `setLocale()` 통화를 포함한 `locale`을 따르십시오. 초기화 중에 `region` 설정 또는 `setRegion()` 호출을하면이 자동을 다음으로 중지합니다. 그 후, 언어가 변경되지 않은 지역을 남깁니다. 공개 API는 다음과 같은 행동을 복원하지 않고, 함께 변경할 때 두 값을 업데이트하십시오.

독일 지역 컨벤션을 사용하는 동안 UI 언어를 유지하려면 `locale` 또는 `new Univer()`의 `createUniver()` 옆에 `region: LocaleType.DE_DE`를 추가하십시오.

```typescript
import { LocaleType } from '@univerjs/core'

univerAPI.setRegion(LocaleType.DE_DE)
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentRegion()) // deDE
```

여기서 UI는 독일어를 포맷하는 동안 영어에 있습니다. `getCurrentLocale()` 및 `getCurrentRegion()`는 효과에 대한 식별자를 반환합니다. 한 번에 변경하려면 동일한 `LocaleType` 값으로 두 개의 세터를 호출하십시오.

- **시트: 통화 통제**: `region`는 도구 모음, 통화 및 회계 선택 및 미리보기의 통화 아이콘을 제어하고 통화 명령이 적용된 패턴을 표시합니다. 기존 셀 형식을 다시 작성하지 않거나 monetary 값을 변환하지 않습니다.
- **Docs: 통계**: `region`는 통계 대화 상자 및 상태 표시 줄에 표시된 숫자를 그룹화 분리기를 포함하여 배열합니다. `region`를 바꾸는 것은 계산 규칙을 바꾸지 않습니다.
- **스레드 의견, 활성화시**: `region`는 날짜와 시간 체재를 24 시간 시간 시간과 라틴 손가락과 더불어 통제합니다. `locale`은 코멘트 UI 원본을 통제합니다. 더 적은 변화는 타임스탬프를 저장하고, `region`에는 시간대 조정이 아닙니다.
- **보드, 슬라이드,베이스, PDF**: `locale`는 번역한 UI를 통제합니다. `region`은 통합된 실 의견과 같은 그것을, 그러나 reformat 널 또는 활주 원본, 기본적인 분야, 또는 PDF 내용과 같은 공유한 특징에 유효합니다.
