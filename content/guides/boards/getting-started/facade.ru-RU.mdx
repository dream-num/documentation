Facade API предоставляет прикладной уровень поверх сервисов и моделей модулей Univer. Используйте его для типичных операций с досками: создания досок, чтения активных страниц, добавления элементов, обновления контейнеров и управления дорожками.

<Callout type="warning" title="Внимание">
  Некоторые методы Facade API асинхронны. Если данные нужно прочитать сразу после изменения, используйте `await` или `.then()`.
</Callout>

## Подключение точки входа Facade

Boards распространяется в виде плагинов Univer Pro. Импортируйте точку входа Facade для возможностей Boards, которые использует ваше приложение:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

Создайте объект API после регистрации экземпляра Univer и необходимых плагинов:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Создание и чтение доски

Используйте `createBoard`, чтобы создать модуль доски через уровень Facade. В низкоуровневом коде конфигурации создавайте модуль с помощью `univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)`.

```ts
const board = univerAPI.createBoard({
  id: 'board-demo',
  name: 'Board Demo',
})

const activeBoard = univerAPI.getActiveBoard()
const sameBoard = univerAPI.getBoard(board.getId())
```

## Работа со страницами и элементами

Facade `FBoard` позволяет читать активную страницу, находить элементы и обновлять их данные без обращения к внутренним сервисам из кода приложения.

```ts
const pageId = board.getActivePageId()
const elements = board.getElements(pageId)

await board.addElement({
  id: 'note-1',
  type: 'text',
  transform: { left: 120, top: 80, width: 240, height: 80 },
  text: 'Planning note',
}, { pageId })

await board.updateElement('note-1', {
  patch: {
    transform: { left: 160, top: 120, width: 280, height: 96 },
  },
  pageId,
})
```

## Контейнеры и дорожки

Используйте Facade Boards для изменения принадлежности элементов к контейнерам. API контейнеров сохраняет порядок и родительско-дочерние связи в снимке состояния доски.

```ts
const container = await board.createContainer({
  pageId,
  title: 'Backlog',
  transform: { left: 80, top: 80, width: 520, height: 360 },
})

await board.moveElementsToContainer(['note-1'], container.id, { pageId })
await board.fitContainerToContent(container.id, { pageId })
```
