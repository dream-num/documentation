---
title: Import Web SDK via CDN
---

Univer Boards does not provide a preset UMD bundle. Add it to an existing Univer UMD runtime in plugin mode. The code block below is not a standalone runtime.

## Load in dependency order

1. Load React, ReactDOM, and RxJS.
2. Load the shared Univer dependencies: Core and Core Facade, render, Design, UI, Docs and Docs UI, Drawing and Drawing UI, license, shape engine and its Facade, Ink and Ink UI, Shape Editor and its UI.
3. Load the Boards files below, and keep every `@univerjs` and `@univerjs-pro` package on the same version.

```html
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/locale/en-US.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/boards-ui/lib/index.css" />
```

These files expose `UniverProBoards`, `UniverProBoardsUi`, `UniverProBoardsFacade`, and `UniverProBoardsUiEnUS`. The Boards UI Facade file adds methods to the existing Board facade and does not create another global. Merge the locale object when constructing Univer, then register `UniverBoardsPlugin` and `UniverBoardsUIPlugin` from the first two namespaces.

For a complete package-manager setup, return to [Installation & Basic Usage](/guides/boards/getting-started/installation).
