---
title: インストールと基本的な使い方
---

UniverボードはUniver Office SDKの一部です。現在、プラグインモードで出荷されます。このページでは、インストールと最初のエディタをレンダリングするために必要な手順について説明します。

Univerのコアコンセプトに慣れていない場合は、[クイックスタート](/guides/boards/getting-started/quickstart)を最初に読みます。

Univer は 2 つの統合モードをサポートしています: *Preset Mode* と *Plugin Mode*。 Preset Mode は、あらかじめ設定されたプラグインのセットをバウンスすることで、セットアップ作業を削減します。 **深いカスタム化か延長**が必要な場合は、プラグインを個別に組み合わせて設定するので、プラグインモードは適切な選択肢です。

## プラグインモードでのセットアップ

ボードはプラグインのセットとして配布されます。ブラウザエディタは通常、共有されたUniverランタイムとライセンスプラグインを最初に登録し、ドキュメントと図面の依存関係、そして最後にボードモデルとUIプラグインを登録します。

### パッケージマネージャーの使用

ビルドツールは、`package.json`のESモジュールと`exports`フィールドをサポートする必要があります。

#### インストール

UniverはReactとUIを構築し、RxJSでデータストリームを処理します。VueまたはAngularアプリケーションに埋め込むこともできます。 `react`、`react-dom`および`rxjs`ピアの依存関係[^peer-dependency]がインストールされていることを確認してください。 下の Yarnコマンドは、明示的にリストします。

すべての `@univerjs/*` と `@univerjs-pro/*` パッケージのバージョンを揃えてください。

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/drawing-ui @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/ink-ui @univerjs-pro/shape-editor-ui @univerjs-pro/boards @univerjs-pro/boards-ui"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}
/>

#### 使い方

Univerを初期化する前にコンテナを作成し、それを明示的な高さにします。

```html
<div id="app" style="height: 600px"></div>
```

`FUniver.newAPI(univer)`を呼び出す前に、このページで使用されているファサードエントリをインポートします。 `@univerjs/design` CSSを最初にロードし、`@univerjs/ui`CSSと製品CSSが続きます。

<Callout type="warning" title="注意">
  - ボードプラグインの前に`UniverLicensePlugin`を登録します。
  - 製品固有の UI CSS より先に、共通の UI CSS をインポートしてください。
  - これらの要素タイプを含むスナップショットを開く前に、オプションの要素プラグインを登録します。
  - `UniverBoardsUIPlugin` は、図形に自動的に `UniverProFormulaEnginePlugin`Z をロードします。同じ `Univer`インスタンスが `UniverFormulaEnginePlugin`、`@univerjs-pro/engine-formula`をインストールし、そのエンジンのインポートと `UniverProFormulaEnginePlugin`の初期化コードに置き換えてください。両方の式エンジンを登録しないでください。
</Callout>

<Steps>
  <Step>
    スタイル、ロケールパック、必要なプラグインをインポートします。

    ```ts
    import { UniverBoardsPlugin } from '@univerjs-pro/boards'
    import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
    import BoardsUIEnUS from '@univerjs-pro/boards-ui/locale/en-US'
    import { UniverInkUIPlugin } from '@univerjs-pro/ink-ui'
    import InkUIJaJP from '@univerjs-pro/ink-ui/locale/ja-JP'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui'
    import DrawingUIEnUS from '@univerjs/drawing-ui/locale/en-US'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs/drawing-ui/lib/index.css'
    import '@univerjs-pro/ink-ui/lib/index.css'
    import '@univerjs-pro/boards-ui/lib/index.css'
    ```
  </Step>
  <Step>
    Facade API[^facade-entry]が要求された場合の正面の記入項目を輸入して下さい:

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/boards/facade'
    ```
  </Step>
  <Step>
    Univerインスタンスを作成し、プラグインを登録し、ボードユニットを作成します。

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          DocsUIEnUS,
          DrawingUIEnUS,
          InkUIJaJP,
          BoardsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)
    univer.registerPlugin(UniverDrawingUIPlugin)
    univer.registerPlugin(UniverInkUIPlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBoardsPlugin)
    univer.registerPlugin(UniverBoardsUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

#### プラグイン設定 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターのマウント先となる DOM 要素、またはその ID。 |

`UniverLicensePlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `license` | `string` |  | クライアント用ライセンスファイルの内容。 |

#### `univer.registerPlugin` と `univer.registerPlugins` メソッド [#registerPlugin]

`univer.registerPlugin`はUniverインスタンスにプラグインを追加します。インスタンスを作成した後にそれを呼び出します。

呼び出しは、`Plugin` が登録するプラグインであり、`options` がプラグインからプラグインに変化するオプションの設定であるフォーム `univer.registerPlugin(Plugin, options)` を取ります。

`univer.registerPlugins`は配列を受け入れ、1つの呼び出しで複数のプラグインを登録します。これにより、プラグインリストを1つの場所に保存します。

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, { container: 'app' }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverDrawingPlugin,
  UniverDrawingUIPlugin,
  UniverInkUIPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverBoardsPlugin,
  UniverBoardsUIPlugin,
])
```

`FUniver.newAPI(univer)`は`univerAPI`のUniverであるFacade APIオブジェクトを返します。 ボードを作成し、ボード要素で操作するために使用します。

## モバイル対応 [#mobile-support]

<Callout type="warning">
  以下のモバイルプラグインをエクスポートする SDK パッケージが必要です。すべての `@univerjs/*` と `@univerjs-pro/*` の依存関係を**同じバージョン**に揃えてください。

  `1.0.0-rc.0` は `UniverBoardsMobileUIPlugin` をエクスポートしません。このモバイルエントリーを含むビルドで以下の例を使用してください。
</Callout>

Univerボードのタッチ指向制御のために、**モバイルUIプラグイン**.[^mobile-ui-mode]エディタを作成する前にUIモードを選択します。

上記のプラグインモードの例では、**交換する** のこれらの UI のインポートと登録前に `createUnit()`. 既に開始したデスクトップエディタにそれらを追加しないでください。 モデルプラグイン、エンジン、ロケールファイル、CSS、ファサードのインポートを保持します。 デスクトップとモバイルクラスは、**同じパッケージエントリ**のエクスポートに名前を付けています。

`UniverMobileUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターのマウント先となる DOM 要素、またはその ID。 |
| `disableAutoFocus` | `true` | `true` | エディタが起動時にフォーカスを浴びるのを止めます。 |

```typescript
import { UniverBoardsMobileUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverDocsMobileUIPlugin } from '@univerjs/docs-ui'
import { UniverDrawingMobileUIPlugin } from '@univerjs/drawing-ui'
import { UniverMobileUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverMobileUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsMobileUIPlugin)
univer.registerPlugin(UniverDrawingMobileUIPlugin)
univer.registerPlugin(UniverBoardsMobileUIPlugin)
```

### コンテナーとタッチ操作

コンテナに明示的な高さを与え、ページビューポートを設定します。 `100dvh`は、ダイナミックビューポート高さに従います。 スクロール、ピンチズーム、テキスト選択、クリップボードアクセス、およびターゲットモバイルブラウザの画面上のキーボードをテストします。 デスクトップエディタを縮小すると、モバイルプラグインに切り替えません。

`UniverMobileUIPlugin` のデフォルトは `disableAutoFocus: true`、従って編集者は初期化の間に自動的に焦点を合わせません。

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
<div id="app" style="height: 100dvh"></div>
```

## オプション機能のパッケージ

ボードエディタが対応する要素タイプを必要とするときに機能パッケージを追加します。

```shell
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

登録例については、[テーブル](/guides/boards/features/tables)、[マインドマップ](/guides/boards/features/mind-maps)および[輸入および輸出](/guides/boards/features/import-export)を参照してください。

## その他のリリース

Univerは、安定したリリースに加えて、アルファとベータチャネルも公開しています。 彼らは正式に出荷されていない機能への早期アクセスを提供します。 トレードオフはリスクが高いです。 これらのビルドには、バグ、未完成の機能、または不安定な動作が含まれている場合があります。 可能な限り生産でそれらを避けてください。

### Alpha/Beta リリース

Univerの開発チームは、新しい機能または重要な変更を完了すると、アルファまたはベータチャネルに作業をプレリリースできます。次のコマンドでUniverパッケージのアルファまたはベータビルドをインストールします。

```package-install
npm install @univerjs-pro/boards@alpha # Alpha バージョン
npm install @univerjs-pro/boards@beta # Beta バージョン
```

アルファまたはベータビルドで問題が発生した場合、またはフィードバックがある場合は、[GitHubの問題](https://github.com/dream-num/univer/issues)によるUniver開発チームに報告してください。

[^peer-dependency]: `peerDependencies` は、ホストアプリケーションが互換性のあるバージョンを用意する依存パッケージです。Univer とアプリケーションが React などのライブラリを共有できます。

[^facade-entry]: Facade は、登録済みプラグインの機能をアプリケーションから操作する API です。Facade のエントリをインポートすると API メソッドが追加されますが、機能プラグイン自体は登録されません。

[^mobile-ui-mode]: モバイル UI プラグインは初期化時にタッチ用の部品とサービスを選択します。端末の自動判定や、ウィンドウサイズ変更による既存インスタンスの切り替えは行いません。モードを変更する場合は文書の状態を保存し、旧インスタンスを破棄してから選択したプラグインで初期化します。
