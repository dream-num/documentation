---
title: CDN 経由で Univer Boards をインポート
---

Univer Boards には preset UMD バンドルがありません。既存の Univer UMD ランタイムにプラグインモードで追加してください。以下のブロックだけでは動作しません。

## 依存関係の順序で読み込む

1. React、ReactDOM、RxJS を読み込みます。
2. 共通の Univer 依存関係である Core と Core Facade、レンダリング、Design、UI、Docs と Docs UI、Drawing と Drawing UI、Pro ライセンス、Pro 図形エンジンとその Facade、Ink と Ink UI、Shape Editor とその UI を読み込みます。
3. 次の Boards ファイルを読み込みます。すべての `@univerjs` と `@univerjs-pro` パッケージで同じバージョンを使用してください。

```html
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/locale/ja-JP.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/boards-ui/lib/index.css" />
```

これらのファイルは `UniverProBoards`、`UniverProBoardsUi`、`UniverProBoardsFacade`、`UniverProBoardsUiJaJP` を公開します。Boards UI Facade ファイルは既存の Board facade にメソッドを追加し、新しいグローバルオブジェクトは作成しません。Univer の作成時にロケールオブジェクトを統合し、最初の 2 つの名前空間から `UniverBoardsPlugin` と `UniverBoardsUIPlugin` を登録します。

パッケージマネージャーを使う完全な設定については、[インストールと基本的な使い方](/guides/boards/getting-started/installation)に戻ってください。
