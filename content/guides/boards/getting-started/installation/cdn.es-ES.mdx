title: Importar Univer Boards a través de CDN

Univer Boards no tiene un paquete UMD preset. Use el modo plugin para añadirlo a un entorno UMD de Univer existente; el siguiente bloque no es un entorno independiente.

## Cargar en orden de dependencias

1. Cargue React, ReactDOM y RxJS.
2. Cargue las dependencias compartidas de Univer: Core y Core Facade, renderizado, Design, UI, Docs y Docs UI, Drawing y Drawing UI, licencia Pro, motor de formas Pro y su Facade, Ink e Ink UI, y Shape Editor y su UI.
3. Cargue los archivos de Boards que aparecen abajo. Use la misma versión para todos los paquetes `@univerjs` y `@univerjs-pro`.

```html
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/locale/es-ES.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/boards-ui/lib/index.css" />
```

Estos archivos exponen `UniverProBoards`, `UniverProBoardsUi`, `UniverProBoardsFacade` y `UniverProBoardsUiEsES`. El archivo Facade de Boards UI añade métodos al facade de Board existente y no crea otro objeto global. Combine el objeto de idioma al crear Univer y registre `UniverBoardsPlugin` y `UniverBoardsUIPlugin` desde los dos primeros espacios de nombres.

Para ver la configuración completa con un gestor de paquetes, vuelva a [Instalación y uso básico](/guides/boards/getting-started/installation).
