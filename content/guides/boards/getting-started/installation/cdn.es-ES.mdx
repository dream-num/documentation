---
title: Importar Web SDK a través de CDN
---

Univer Boards no proporciona un paquete UMD preestablecido. Añádalo a un tiempo de ejecución Univer UMD existente en modo plugin. El bloque de códigos a continuación no es un tiempo de funcionamiento independiente.

## Cargar en orden de dependencias

1. Cargue React, ReactDOM y RxJS.
2. Cargar las dependencias Univer compartidas: Core y Core Facade, render, Design, UI, Docs y Docs UI, Dibujo y Dibujo UI, licencia, motor de forma y su Facade, tinta y tinta UI, Editor de Forma y su UI.
3. Cargue los archivos de las tablas a continuación, y mantenga cada paquete `@univerjs` y `@univerjs-pro` en la misma versión.

```html
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/locale/es-ES.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/boards-ui/lib/index.css" />
```

Estos archivos exponen `UniverProBoards`, `UniverProBoardsUi`, `UniverProBoardsFacade`, y `UniverProBoardsUiEnUS`. El archivo Boards UI Facade añade métodos a la fachada existente de la Junta y no crea otro global. Combina el objeto local al construir Univer, luego registra `UniverBoardsPlugin` y `UniverBoardsUIPlugin` de los dos primeros espacios de nombres.

Para ver la configuración completa con un gestor de paquetes, vuelva a [Instalación y uso básico](/guides/boards/getting-started/installation).
