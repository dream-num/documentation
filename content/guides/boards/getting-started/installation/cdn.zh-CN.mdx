Univer Boards 没有 preset UMD 包。请使用插件模式把它加入已有的 Univer UMD 运行时；以下代码块并不是独立运行时。

## 按依赖顺序加载

1. 加载 React、ReactDOM 和 RxJS。
2. 加载 Univer 通用依赖：Core 和 Core Facade、渲染引擎、Design、UI、Docs 与 Docs UI、Drawing 与 Drawing UI、Pro 许可证、Pro 形状引擎及其 Facade、Ink 与 Ink UI、Shape Editor 及其 UI。
3. 加载下面的 Boards 文件。所有 `@univerjs` 和 `@univerjs-pro` 包应使用同一版本。

```html
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/locale/zh-CN.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/boards-ui/lib/index.css" />
```

这些文件公开 `UniverProBoards`、`UniverProBoardsUi`、`UniverProBoardsFacade` 和 `UniverProBoardsUiZhCN`。Boards UI Facade 文件会给现有 Board facade 添加方法，不会创建新的全局命名空间。创建 Univer 时合并语言包对象，再从前两个命名空间注册 `UniverBoardsPlugin` 和 `UniverBoardsUIPlugin`。

如需完整的包管理器配置，请返回[安装和基本使用](/guides/boards/getting-started/installation)。
