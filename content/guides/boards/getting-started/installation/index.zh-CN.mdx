title: 安装和基本使用
---

Univer Boards 是 Univer Office SDK 的一部分，目前以插件模式发布。本文介绍如何安装，以及如何渲染第一个编辑器。

如果对 Univer 的核心概念还不熟悉，请先阅读[快速入门](/guides/boards/getting-started/quickstart)。

Univer 提供*预设模式*和*插件模式*两种集成方式。预设模式预先组合好一组插件，可以减少配置工作；如果需要**深度定制或扩展**，插件模式更合适，因为需要自行组合和配置各个插件。

## 通过插件模式创建

Boards 以一组插件的形式发布。浏览器端编辑器通常先注册 Univer 通用运行时和许可证插件，再注册文档与绘图依赖，最后注册 Board 的模型插件和 UI 插件。

### 使用包管理器

构建工具需要支持 ES Module 和 `package.json` 中的 `exports` 字段。

#### 安装

Univer 的界面由 React 构建，数据流由 RxJS 处理，也可以嵌入 Vue 或 Angular 应用。请确认已安装 `react`、`react-dom` 和 `rxjs` 这几个 peer dependencies[^peer-dependency]，下面的 Yarn 命令会将它们显式列出。

所有 `@univerjs/*` 和 `@univerjs-pro/*` 包必须保持**同一版本**。

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/drawing-ui @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/ink-ui @univerjs-pro/shape-editor-ui @univerjs-pro/boards @univerjs-pro/boards-ui"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}

#### 使用

请先创建容器，再初始化 Univer，并为容器指定明确的高度：

```html
<div id="app" style="height: 600px"></div>
```

调用 `FUniver.newAPI(univer)` 之前，先导入本页用到的 Facade 入口。CSS 按以下顺序加载：先 `@univerjs/design`，再 `@univerjs/ui`，最后是产品 CSS。

<Callout type="warning" title="注意">
  - 先注册 `UniverLicensePlugin`，再注册 Board 插件。
  - 先导入通用 UI CSS，再导入产品 UI CSS。
  - 打开包含可选元素类型的快照之前，先注册对应的元素插件。
  - `UniverBoardsUIPlugin` 会为形状自动加载 `UniverProFormulaEnginePlugin`。如果同一个 `Univer` 实例还注册了 `UniverFormulaEnginePlugin`，请安装 `@univerjs-pro/engine-formula`，并在初始化代码中把该引擎的导入和注册替换为 `UniverProFormulaEnginePlugin`。不要同时注册两个公式引擎。
</Callout>

<Steps>
  <Step>
    导入样式、语言包和必需的插件：

    ```ts
    import { UniverBoardsPlugin } from '@univerjs-pro/boards'
    import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
    import BoardsUIEnUS from '@univerjs-pro/boards-ui/locale/en-US'
    import { UniverInkUIPlugin } from '@univerjs-pro/ink-ui'
    import InkUIZhCN from '@univerjs-pro/ink-ui/locale/zh-CN'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui'
    import DrawingUIEnUS from '@univerjs/drawing-ui/locale/en-US'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs/drawing-ui/lib/index.css'
    import '@univerjs-pro/ink-ui/lib/index.css'
    import '@univerjs-pro/boards-ui/lib/index.css'
    ```
  </Step>
  <Step>
    如需使用 Facade API[^facade-entry]，请导入 Facade 入口：

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/boards/facade'
    ```
  </Step>
  <Step>
    创建 Univer 实例、注册插件，再创建一个 Board 单元：

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          DocsUIEnUS,
          DrawingUIEnUS,
          InkUIZhCN,
          BoardsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)
    univer.registerPlugin(UniverDrawingUIPlugin)
    univer.registerPlugin(UniverInkUIPlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBoardsPlugin)
    univer.registerPlugin(UniverBoardsUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

#### 插件配置 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 挂载用的 DOM 元素或元素 ID。 |

`UniverLicensePlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 客户端许可证文件的内容。 |

#### `univer.registerPlugin` 与 `univer.registerPlugins` 方法 [#registerPlugin]

`univer.registerPlugin` 用于向 Univer 实例注册一个插件，请在创建实例之后调用。

调用形式为 `univer.registerPlugin(Plugin, options)`。其中 `Plugin` 是要注册的插件，`options` 是可选的配置项，不同插件的配置项不同。

`univer.registerPlugins` 接收一个数组，一次注册多个插件，便于集中管理插件列表。

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, { container: 'app' }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverDrawingPlugin,
  UniverDrawingUIPlugin,
  UniverInkUIPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverBoardsPlugin,
  UniverBoardsUIPlugin,
])
```

`FUniver.newAPI(univer)` 返回的 `univerAPI` 对象是 Univer 的 Facade API，可用于创建白板和操作白板元素。

## 移动端适配 [#mobile-support]

<Callout type="warning">
  这些示例要求 SDK 包导出下面列出的移动端插件。所有 `@univerjs/*` 和 `@univerjs-pro/*` 依赖必须保持**同一版本**。

  `1.0.0-rc.0` 未导出 `UniverBoardsMobileUIPlugin`，请先改用包含该移动端入口的构建版本，再参考下面的示例。
</Callout>

Univer Boards 通过**移动端 UI 插件**提供触摸操作界面。[^mobile-ui-mode] UI 模式需要在创建编辑器之前确定。

在上面的插件模式示例中，请**替换**下面这些 UI 插件的导入和注册，并在 `createUnit()` 之前完成，不要将它们追加到已经启动的桌面端编辑器中。模型插件、引擎、语言包、CSS 和 Facade 导入均需保留。桌面端和移动端的类都是**同一个包入口**的具名导出。

`UniverMobileUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 挂载用的 DOM 元素或元素 ID。 |
| `disableAutoFocus` | `true` | `true` | 编辑器启动时不获取焦点。 |

```typescript
import { UniverBoardsMobileUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverDocsMobileUIPlugin } from '@univerjs/docs-ui'
import { UniverDrawingMobileUIPlugin } from '@univerjs/drawing-ui'
import { UniverMobileUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverMobileUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsMobileUIPlugin)
univer.registerPlugin(UniverDrawingMobileUIPlugin)
univer.registerPlugin(UniverBoardsMobileUIPlugin)
```

### 插件对照

只注册实际用到的功能，并保留其模型插件和必需依赖。提供移动端 UI 导出，并不意味着桌面端和移动端的操作界面完全一致。Pro 功能仍需相应的许可证。如果某项功能需要后端，请在应用侧接入 [Univer Server SDK](/server)。

### 容器与触摸交互

为容器指定明确的高度，并配置页面 viewport。`100dvh` 会跟随动态视口高度。滚动、双指缩放、文字选择、剪贴板访问和软键盘都需要在目标移动浏览器中测试。仅缩小桌面端编辑器不会切换到移动端插件。

`UniverMobileUIPlugin` 默认使用 `disableAutoFocus: true`，因此编辑器初始化时不会自动获取焦点。

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
<div id="app" style="height: 100dvh"></div>
```

## 可选功能包

Board 编辑器需要某种元素类型时，请添加对应的功能包：

```shell
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

注册示例见[表格](/guides/boards/features/tables)、[思维导图](/guides/boards/features/mind-maps)和[导入导出](/guides/boards/features/import-export)。

## 其他发布版本

除稳定版本外，Univer 还发布 alpha 和 beta 通道，用于提前获取尚未正式发布的功能。代价是更高的风险：这些构建可能包含 bug、未完成的功能或不稳定的行为。请尽可能避免在生产环境中使用。

### Alpha / Beta 版本

Univer 开发团队完成新功能或较大改动后，可能会先将其发布到 alpha 或 beta 通道。安装某个 Univer 包的 alpha 或 beta 版本，可使用以下命令：

```package-install
npm install @univerjs-pro/boards@alpha # Alpha 版本
npm install @univerjs-pro/boards@beta # Beta 版本
```

如果 alpha 或 beta 版本出现问题，或有相关反馈，请通过 [GitHub Issues](https://github.com/dream-num/univer/issues) 报告给 Univer 开发团队。

[^peer-dependency]: `peerDependencies` 表示需要由宿主项目提供兼容版本的依赖。这样 Univer 可以与应用共享 React 等库，而不是各自携带一份。

[^facade-entry]: Facade 是面向应用的 API，封装已注册插件的能力。导入 Facade 入口会扩展 API 方法，但不会代替功能插件的注册。

[^mobile-ui-mode]: 移动端 UI 插件在初始化时选择触摸控件和移动端服务，不会自动判断设备，也不会在窗口尺寸变化时切换已有实例。若要切换模式，应先保留文档状态，销毁旧实例，再使用所选插件组合初始化。
