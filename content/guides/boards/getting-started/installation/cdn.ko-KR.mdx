---
title: CDN으로 Univer Boards 가져오기
---

Univer Boards는 preset UMD 번들을 제공하지 않습니다. 플러그인 모드로 기존 Univer UMD 런타임에 추가하세요. 아래 블록만으로는 독립 실행할 수 없습니다.

## 종속성 순서로 로드

1. React, ReactDOM, RxJS를 로드합니다.
2. 공통 Univer 종속성인 Core와 Core Facade, 렌더링, Design, UI, Docs와 Docs UI, Drawing과 Drawing UI, Pro 라이선스, Pro 도형 엔진과 Facade, Ink와 Ink UI, Shape Editor와 UI를 로드합니다.
3. 아래 Boards 파일을 로드합니다. 모든 `@univerjs` 및 `@univerjs-pro` 패키지에 같은 버전을 사용하세요.

```html
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/locale/ko-KR.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/boards-ui/lib/index.css" />
```

이 파일은 `UniverProBoards`, `UniverProBoardsUi`, `UniverProBoardsFacade`, `UniverProBoardsUiKoKR`를 노출합니다. Boards UI Facade 파일은 기존 Board facade에 메서드를 추가하며 새 전역 객체를 만들지 않습니다. Univer를 생성할 때 로케일 객체를 병합하고 처음 두 네임스페이스에서 `UniverBoardsPlugin`과 `UniverBoardsUIPlugin`을 등록하세요.

패키지 관리자를 사용하는 전체 설정은 [설치 및 기본 사용법](/guides/boards/getting-started/installation)을 참고하세요.
