---
title: 安裝與基本使用
---

Univer Boards 是 Univer Office SDK 的一部分，目前以外掛模式釋出。本文介紹如何安裝，以及如何渲染第一個編輯器。

如果對 Univer 的核心概念還不熟悉，請先閱讀[快速入門](/guides/boards/getting-started/quickstart)。

Univer 提供*預設模式*和*外掛模式*兩種整合方式。預設模式預先組合好一組外掛，可以減少配置工作；如果需要**深度定製或擴充套件**，外掛模式更合適，因為需要自行組合和配置各個外掛。

## 透過外掛模式建立

Boards 以一組外掛的形式釋出。瀏覽器端編輯器通常先註冊 Univer 通用執行時和許可證外掛，再註冊文件與繪圖依賴，最後註冊 Board 的模型外掛和 UI 外掛。

### 使用套件管理器

建置工具需要支援 ES Module 和 `package.json` 中的 `exports` 欄位。

#### 安裝

Univer 的介面由 React 建置，資料流由 RxJS 處理，也可以嵌入 Vue 或 Angular 應用。請確認已安裝 `react`、`react-dom` 和 `rxjs` 這幾個 peer dependencies[^peer-dependency]，下面的 Yarn 命令會將它們顯式列出。

所有 `@univerjs/*` 和 `@univerjs-pro/*` 包必須保持**同一版本**。

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/drawing-ui @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/ink-ui @univerjs-pro/shape-editor-ui @univerjs-pro/boards @univerjs-pro/boards-ui"

#### 使用

請先建立容器，再初始化 Univer，併為容器指定明確的高度：

```html
<div id="app" style="height: 600px"></div>
```

呼叫 `FUniver.newAPI(univer)` 之前，先匯入本頁用到的 Facade 入口。CSS 按以下順序載入：先 `@univerjs/design`，再 `@univerjs/ui`，最後是產品 CSS。

<Callout type="warning" title="注意">
  - 先註冊 `UniverLicensePlugin`，再註冊 Board 外掛。
  - 先匯入通用 UI CSS，再匯入產品 UI CSS。
  - 開啟包含可選元素型別的快照之前，先註冊對應的元素外掛。
  - `UniverBoardsUIPlugin` 會為形狀自動載入 `UniverProFormulaEnginePlugin`。如果同一個 `Univer` 例項還註冊了 `UniverFormulaEnginePlugin`，請安裝 `@univerjs-pro/engine-formula`，並在初始化程式碼中把該引擎的匯入和註冊替換為 `UniverProFormulaEnginePlugin`。不要同時註冊兩個公式引擎。
</Callout>

<Steps>
  <Step>
    匯入樣式、語系套件和必要的外掛程式：

    ```ts
    import { UniverBoardsPlugin } from '@univerjs-pro/boards'
    import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
    import BoardsUIEnUS from '@univerjs-pro/boards-ui/locale/en-US'
    import { UniverInkUIPlugin } from '@univerjs-pro/ink-ui'
    import InkUIZhTW from '@univerjs-pro/ink-ui/locale/zh-TW'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui'
    import DrawingUIEnUS from '@univerjs/drawing-ui/locale/en-US'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs/drawing-ui/lib/index.css'
    import '@univerjs-pro/ink-ui/lib/index.css'
    import '@univerjs-pro/boards-ui/lib/index.css'
    ```
  </Step>
  <Step>
    如需使用 Facade API[^facade-entry]，請匯入 Facade 入口：

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/boards/facade'
    ```
  </Step>
  <Step>
    建立 Univer 例項、註冊外掛，再建立一個 Board 單元：

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          DocsUIEnUS,
          DrawingUIEnUS,
          InkUIZhTW,
          BoardsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)
    univer.registerPlugin(UniverDrawingUIPlugin)
    univer.registerPlugin(UniverInkUIPlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBoardsPlugin)
    univer.registerPlugin(UniverBoardsUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

#### 外掛設定 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 掛載用的 DOM 元素或元素 ID。 |

`UniverLicensePlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 用戶端授權檔的內容。 |

#### `univer.registerPlugin` 與 `univer.registerPlugins` 方法 [#registerPlugin]

`univer.registerPlugin` 用於向 Univer 例項註冊一個外掛，請在建立例項之後呼叫。

呼叫形式為 `univer.registerPlugin(Plugin, options)`。其中 `Plugin` 是要註冊的外掛，`options` 是可選的配置項，不同外掛的配置項不同。

`univer.registerPlugins` 接收一個陣列，一次註冊多個外掛，便於集中管理外掛列表。

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, { container: 'app' }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverDrawingPlugin,
  UniverDrawingUIPlugin,
  UniverInkUIPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverBoardsPlugin,
  UniverBoardsUIPlugin,
])
```

`FUniver.newAPI(univer)` 返回的 `univerAPI` 物件是 Univer 的 Facade API，可用於建立白板和操作白板元素。

## 行動裝置支援 [#mobile-support]

<Callout type="warning">
  這些範例要求 SDK 包匯出下面列出的行動版外掛。所有 `@univerjs/*` 和 `@univerjs-pro/*` 依賴必須保持**同一版本**。

  `1.0.0-rc.0` 未匯出 `UniverBoardsMobileUIPlugin`，請先改用包含該行動版入口的建置版本，再參考下面的範例。
</Callout>

Univer Boards 透過**行動版 UI 外掛**提供觸控操作介面。[^mobile-ui-mode] UI 模式需要在建立編輯器之前確定。

在上面的外掛模式範例中，請**替換**下面這些 UI 外掛的匯入和註冊，並在 `createUnit()` 之前完成，不要將它們追加到已經啟動的桌面版編輯器中。模型外掛、引擎、語言套件、CSS 和 Facade 匯入均需保留。桌面版和行動版的類都是**同一套件入口**的具名匯出。

`UniverMobileUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 掛載用的 DOM 元素或元素 ID。 |
| `disableAutoFocus` | `true` | `true` | 編輯器啟動時不取得焦點。 |

```typescript
import { UniverBoardsMobileUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverDocsMobileUIPlugin } from '@univerjs/docs-ui'
import { UniverDrawingMobileUIPlugin } from '@univerjs/drawing-ui'
import { UniverMobileUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverMobileUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsMobileUIPlugin)
univer.registerPlugin(UniverDrawingMobileUIPlugin)
univer.registerPlugin(UniverBoardsMobileUIPlugin)
```

### 外掛對照

只註冊實際用到的功能，並保留其模型外掛和必需依賴。提供行動版 UI 匯出，並不意味著桌面版和行動版的操作介面完全一致。Pro 功能仍需相應的許可證。如果某項功能需要後端，請在應用側接入 [Univer Server SDK](/server)。

| 套件 | 桌面版註冊 | 行動版註冊 |
| --- | --- | --- |
| `@univerjs/ui` | `UniverUIPlugin` | `UniverMobileUIPlugin` |
| `@univerjs/docs-ui` | `UniverDocsUIPlugin` | `UniverDocsMobileUIPlugin` |
| `@univerjs/drawing-ui` | `UniverDrawingUIPlugin` | `UniverDrawingMobileUIPlugin` |
| `@univerjs-pro/boards-ui` | `UniverBoardsUIPlugin` | `UniverBoardsMobileUIPlugin` |
| `@univerjs/thread-comment-ui` | `UniverThreadCommentUIPlugin` | `UniverThreadCommentMobileUIPlugin` |
| `@univerjs-pro/shape-editor-ui` | `UniverShapeEditorUIPlugin` | `UniverShapeEditorMobileUIPlugin` |
| `@univerjs-pro/chart-ui` | `UniverChartUIPlugin` | `UniverChartMobileUIPlugin` |
| `@univerjs-pro/exchange-client` | `UniverExchangeClientPlugin` | `UniverExchangeClientMobileUIPlugin` |
| `@univerjs-pro/boards-chart-ui` | `UniverBoardsChartUIPlugin` | `UniverBoardsChartMobileUIPlugin` |
| `@univerjs-pro/boards-mind-ui` | `UniverBoardsMindUIPlugin` | `UniverBoardsMindMobileUIPlugin` |

### 容器與觸控互動

為容器指定明確的高度，並配置頁面 viewport。`100dvh` 會跟隨動態視口高度。滾動、雙指縮放、文字選擇、剪貼簿訪問和軟鍵盤都需要在目標移動瀏覽器中測試。僅縮小桌面版編輯器不會切換到行動版外掛。

`UniverMobileUIPlugin` 預設使用 `disableAutoFocus: true`，因此編輯器初始化時不會自動取得焦點。

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
<div id="app" style="height: 100dvh"></div>
```

## 選用功能套件

Board 編輯器需要某種元素型別時，請新增對應的功能包：

```shell
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

註冊範例見[表格](/guides/boards/features/tables)、[思維導圖](/guides/boards/features/mind-maps)和[匯入匯出](/guides/boards/features/import-export)。

## 其他發佈版本

除穩定版本外，Univer 還發布 alpha 和 beta 通道，用於提前取得尚未正式釋出的功能。代價是更高的風險：這些建置可能包含 bug、未完成的功能或不穩定的行為。請儘可能避免在生產環境中使用。

### Alpha / Beta 版本

Univer 開發團隊完成新功能或較大改動後，可能會先將其釋出到 alpha 或 beta 通道。安裝某個 Univer 包的 alpha 或 beta 版本，可使用以下命令：

```package-install
npm install @univerjs-pro/boards@alpha # Alpha 版本
npm install @univerjs-pro/boards@beta # Beta 版本
```

如果 alpha 或 beta 版本出現問題，或有相關反饋，請透過 [GitHub Issues](https://github.com/dream-num/univer/issues) 報告給 Univer 開發團隊。
