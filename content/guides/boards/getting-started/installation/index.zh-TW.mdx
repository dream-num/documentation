本章介紹 Univer Boards 的安裝方式與基本用法。Boards 是 Univer Pro 產品，目前採用外掛程式模式提供。

如果不熟悉 Univer 的核心概念，請先閱讀[快速入門](/guides/boards/getting-started/quickstart)。

## 使用外掛程式模式建立

Univer 以一組外掛程式的形式提供 Boards。瀏覽器編輯器通常會依序註冊共用的 Univer 執行環境、Pro 授權外掛程式、文件與繪圖相依套件，接著再註冊 Board 模型和 UI 外掛程式。

### 安裝

安裝瀏覽器版 Board 編輯器所需的最基本套件：

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab>
    ```shell
    npm install @univerjs/core @univerjs/design @univerjs/docs @univerjs/docs-ui @univerjs/drawing @univerjs/drawing-ui @univerjs/engine-render @univerjs/ui @univerjs-pro/license @univerjs-pro/ink-ui @univerjs-pro/shape-editor-ui @univerjs-pro/boards @univerjs-pro/boards-ui
    ```
  </Tab>
  <Tab>

### 用法

<Callout type="warning" title="注意">
  - 請先註冊 `UniverLicensePlugin`，再註冊 Board 外掛程式。
  - 請先匯入共用 UI CSS，再匯入產品 UI CSS。
  - 開啟含有選用元素類型的快照前，請先註冊對應的元素外掛程式。
</Callout>

<Steps>
  <Step>
    匯入樣式、語系套件和必要的外掛程式：

    ```ts
    import { UniverBoardsPlugin } from '@univerjs-pro/boards'
    import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
    import BoardsUIEnUS from '@univerjs-pro/boards-ui/locale/en-US'
    import { UniverInkUIPlugin } from '@univerjs-pro/ink-ui'
    import InkUIZhTW from '@univerjs-pro/ink-ui/locale/zh-TW'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui'
    import DrawingUIEnUS from '@univerjs/drawing-ui/locale/en-US'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs/drawing-ui/lib/index.css'
    import '@univerjs-pro/ink-ui/lib/index.css'
    import '@univerjs-pro/boards-ui/lib/index.css'
    ```
  </Step>
  <Step>
    如要使用 Facade API，請匯入 Facade 進入點：

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/boards/facade'
    ```
  </Step>
  <Step>
    建立 Univer 執行個體、註冊外掛程式，並建立 Board 單元：

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          DocsUIEnUS,
          DrawingUIEnUS,
          BoardsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)
    univer.registerPlugin(UniverDrawingUIPlugin)
    univer.registerPlugin(UniverInkUIPlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBoardsPlugin)
    univer.registerPlugin(UniverBoardsUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

`FUniver.newAPI(univer)` 傳回的 `univerAPI` 物件就是 Univer 的 Facade API。您可以使用它建立白板及操作白板元素。

## 選用功能套件

當 Board 編輯器需要對應的元素類型時，請加入相關功能套件：

```shell
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

如需功能註冊範例，請參閱[表格](/guides/boards/features/tables)、[心智圖](/guides/boards/features/mind-maps)和[匯入與匯出](/guides/boards/features/import-export)。

## 其他發行管道

除了穩定版本，Univer 也提供 alpha、beta 和 nightly 發行管道。您可以透過這些管道提早試用即將推出的功能，但其中可能包含尚未完成或不穩定的行為。除非已有驗證計畫，否則請勿在正式環境中使用。

```package-install
npm install @univerjs-pro/boards@alpha
npm install @univerjs-pro/boards@beta
```
