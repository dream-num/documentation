title: Подключение Web SDK через CDN
---

Платы Univer не предоставляют предустановленный пакет UMD. Добавьте его к существующей среде выполнения Univer UMD в режиме плагина. Блок кода ниже не является автономным временем выполнения.

## Загрузка в порядке зависимостей

1. Загрузите React, ReactDOM и RxJS.
2. Загрузите общие зависимости Univer: Core и Core Facade, render, Design, UI, Docs and Docs UI, Drawing and Drawing UI, лицензионный движок формы и его интерфейс Facade, Ink and Ink, редактор формы и его пользовательский интерфейс.
3. Загрузите файлы с платами ниже и сохраните все пакеты `@univerjs` и `@univerjs-pro` в одной версии.

```html
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/locale/ru-RU.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/boards-ui/lib/index.css" />
```

Эти файлы обнажают `UniverProBoards`, `UniverProBoardsUi`, `UniverProBoardsFacade` и `UniverProBoardsUiEnUS`. Файл Boards UI Facade добавляет методы к существующему фасаду платы и не создает другого глобального. Слить объект локализации при построении Univer, затем зарегистрировать `UniverBoardsPlugin` и `UniverBoardsUIPlugin` из первых двух пространств имен.

Полная настройка с менеджером пакетов описана в разделе [Установка и основы использования](/guides/boards/getting-started/installation).
