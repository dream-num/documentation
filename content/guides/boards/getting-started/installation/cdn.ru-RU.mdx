---
title: Подключение Univer Boards через CDN
---

У Univer Boards нет готового preset UMD-бандла. Добавьте его в существующую среду Univer UMD в режиме плагинов; следующий блок не является самостоятельной средой.

## Загрузка в порядке зависимостей

1. Загрузите React, ReactDOM и RxJS.
2. Загрузите общие зависимости Univer: Core и Core Facade, отрисовку, Design, UI, Docs и Docs UI, Drawing и Drawing UI, лицензию Pro, движок фигур Pro и его Facade, Ink и Ink UI, а также Shape Editor и его UI.
3. Загрузите файлы Boards ниже. Используйте одну версию для всех пакетов `@univerjs` и `@univerjs-pro`.

```html
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/locale/ru-RU.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/boards-ui/lib/index.css" />
```

Эти файлы создают пространства имён `UniverProBoards`, `UniverProBoardsUi`, `UniverProBoardsFacade` и `UniverProBoardsUiRuRU`. Файл Boards UI Facade добавляет методы к существующему facade Board и не создаёт нового глобального объекта. Объедините объект локализации при создании Univer, затем зарегистрируйте `UniverBoardsPlugin` и `UniverBoardsUIPlugin` из первых двух пространств имён.

Полная настройка с менеджером пакетов описана в разделе [Установка и основы использования](/guides/boards/getting-started/installation).
