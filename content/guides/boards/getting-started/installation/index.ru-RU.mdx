В этой главе описаны установка и основы использования Univer Boards. Boards распространяется как продукт Univer Office SDK и в настоящее время работает в режиме плагинов.

Если вы не знакомы с основными концепциями Univer, сначала прочитайте [краткое руководство](/guides/boards/getting-started/quickstart).

## Настройка в режиме плагинов

Univer предоставляет Boards в виде набора плагинов. В браузерном редакторе обычно регистрируют общую среду выполнения Univer, плагин лицензии , зависимости для документов и рисования, а затем плагины модели доски и пользовательского интерфейса.

### Использование менеджера пакетов

Используйте сборщик с поддержкой ES Modules и поля `exports` в `package.json`.

#### Установка

Univer использует React для интерфейса и RxJS для потоков данных; его также можно встроить в Vue или Angular. Убедитесь, что peer dependencies `react`, `react-dom` и `rxjs` установлены. Команда Yarn ниже включает их явно.

Используйте одинаковую версию всех пакетов `@univerjs/*` и `@univerjs-pro/*`.

#### Использование

Перед инициализацией Univer создайте контейнер и задайте ему явную высоту:

```html
<div id="app" style="height: 600px"></div>
```

Перед вызовом `FUniver.newAPI(univer)` импортируйте точки входа facade из примера ниже. Импортируйте CSS в порядке: `@univerjs/design`, `@univerjs/ui`, затем CSS продукта.

<Callout type="warning" title="Внимание">
  - Зарегистрируйте `UniverLicensePlugin` перед плагинами доски.
  - Импортируйте общий CSS пользовательского интерфейса перед CSS пользовательского интерфейса продукта.
  - Зарегистрируйте плагины дополнительных элементов перед открытием снимков состояния, содержащих элементы этих типов.
</Callout>

<Steps>
  <Step>
    Импортируйте стили, пакеты локализации и необходимые плагины:

    ```ts
    import { UniverBoardsPlugin } from '@univerjs-pro/boards'
    import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
    import BoardsUIEnUS from '@univerjs-pro/boards-ui/locale/en-US'
    import { UniverInkUIPlugin } from '@univerjs-pro/ink-ui'
    import InkUIEnUS from '@univerjs-pro/ink-ui/locale/en-US'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui'
    import DrawingUIEnUS from '@univerjs/drawing-ui/locale/en-US'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs/drawing-ui/lib/index.css'
    import '@univerjs-pro/ink-ui/lib/index.css'
    import '@univerjs-pro/boards-ui/lib/index.css'
    ```
  </Step>
  <Step>
    Если вы хотите использовать Facade API, импортируйте его точку входа:

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/boards/facade'
    ```
  </Step>
  <Step>
    Создайте экземпляр Univer, зарегистрируйте плагины и создайте доску:

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          DocsUIEnUS,
          DrawingUIEnUS,
          InkUIEnUS,
          BoardsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)
    univer.registerPlugin(UniverDrawingUIPlugin)
    univer.registerPlugin(UniverInkUIPlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBoardsPlugin)
    univer.registerPlugin(UniverBoardsUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

#### Методы `univer.registerPlugin` и `univer.registerPlugins` [#registerPlugin]

Метод `univer.registerPlugin` используется для регистрации плагина в экземпляре Univer. После создания экземпляра Univer вызовите этот метод, чтобы зарегистрировать плагины.

Плагин можно зарегистрировать с помощью метода `univer.registerPlugin(Plugin, options)`, где `Plugin` — регистрируемый плагин, а `options` — необязательные параметры конфигурации, которые могут различаться в зависимости от плагина.

Для одновременной регистрации нескольких плагинов передайте массив в `univer.registerPlugins`. Это удобно, когда требуется централизованно управлять плагинами.

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, { container: 'app' }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverDrawingPlugin,
  UniverDrawingUIPlugin,
  UniverInkUIPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverBoardsPlugin,
  UniverBoardsUIPlugin,
])
```

Объект `univerAPI`, возвращаемый методом `FUniver.newAPI(univer)`, представляет собой Facade API Univer. Используйте его для создания досок и работы с их элементами.

## Пакеты дополнительных возможностей

Добавляйте пакеты возможностей, когда редактору досок требуется соответствующий тип элемента:

```shell
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

Примеры регистрации возможностей приведены в разделах [«Таблицы»](/guides/boards/features/tables), [«Интеллект-карты»](/guides/boards/features/mind-maps) и [«Импорт и экспорт»](/guides/boards/features/import-export).

## Другие каналы выпуска

Помимо стабильных выпусков, Univer предлагает каналы alpha / beta и nightly. Они позволяют заранее получить доступ к новейшим функциям, которые еще не выпущены официально. Однако вместе с новыми возможностями возрастают и риски: такие версии могут содержать ошибки, неполные или нестабильные функции. По возможности не используйте их в рабочей среде.

### Выпуски Alpha / Beta

После завершения работы над новой функцией или существенным изменением команда разработчиков Univer может предварительно опубликовать их в канале alpha или beta. Установить alpha- или beta-версию пакета Univer можно следующей командой:

```package-install
npm install @univerjs-pro/boards@alpha # Alpha version
npm install @univerjs-pro/boards@beta # Beta version
```

Если при использовании alpha- или beta-версий вы обнаружите проблему или захотите поделиться отзывом, сообщите об этом команде разработчиков Univer через [GitHub Issues](https://github.com/dream-num/univer/issues).

Мы будем рады вашим отзывам о предварительных выпусках.
