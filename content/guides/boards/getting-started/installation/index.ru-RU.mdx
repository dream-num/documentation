Платы Univer являются частью Univer Office SDK и в настоящее время поставляются в режиме плагина. Эта страница охватывает установку и шаги, необходимые для рендеринга первого редактора.

Если вы не знакомы с основными концепциями Univer, сначала прочитайте [Быстрый старт](/guides/boards/getting-started/quickstart).

Univer поддерживает два режима интеграции: *Preset Mode* и *Plugin Mode*. Preset Mode снижает работу настройки путем объединения предварительно настроенного набора плагинов. Если вам нужен **Глубокая настройка или расширения**, режим плагина является подходящим выбором, потому что вы объединяете и настраиваете плагины индивидуально.

## Настройка в режиме плагинов

Редактор браузера обычно сначала регистрирует совместно используемое время выполнения Univer и плагин лицензии, затем зависимости от документа и чертежа и, наконец, модель платы и плагины пользовательского интерфейса.

### Использование менеджера пакетов

Инструмент сборки должен поддерживать модули ES и поле `exports` в `package.json`.

#### Установка

Univer строит свой пользовательский интерфейс с React и обрабатывает потоки данных с помощью RxJS; он также может быть встроен в приложения Vue или Angular. Подтверждают, что установлены зависимости `react`, `react-dom` и `rxjs` peer[^peer-dependency]. Команда Yarn ниже перечисляет их явно.

Используйте **одинаковую версию** всех пакетов `@univerjs/*` и `@univerjs-pro/*`.

#### Использование

Создайте контейнер перед инициализацией Univer и придайте ему явную высоту:

```html
<div id="app" style="height: 600px"></div>
```

Импортировать фасадные записи, используемые на этой странице, прежде чем позвонить `FUniver.newAPI(univer)`. Загрузите сначала `@univerjs/design` CSS, затем `@univerjs/ui` и продукт CSS последний.

<Callout type="warning" title="Внимание">
  - Зарегистрируйте `UniverLicensePlugin` перед плагинами.
  - Импортируйте общий CSS пользовательского интерфейса перед CSS пользовательского интерфейса продукта.
  - Регистрируйте дополнительные плагины элементов перед открытием снимка, который содержит эти типы элементов.
  - `UniverBoardsUIPlugin` загружает `UniverProFormulaEnginePlugin` автоматически для форм. Если один и тот же экземпляр `Univer` также регистрирует `UniverFormulaEnginePlugin`, установите `@univerjs-pro/engine-formula` и замените импорт и регистрацию этого двигателя `UniverProFormulaEnginePlugin` в коде инициализации. Не регистрируйте оба двигателя формулы.
</Callout>

<Steps>
  <Step>
    Импортируйте стили, пакеты локализации и необходимые плагины:

    ```ts
    import { UniverBoardsPlugin } from '@univerjs-pro/boards'
    import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
    import BoardsUIEnUS from '@univerjs-pro/boards-ui/locale/en-US'
    import { UniverInkUIPlugin } from '@univerjs-pro/ink-ui'
    import InkUIEnUS from '@univerjs-pro/ink-ui/locale/en-US'
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { LocaleType, mergeLocales, Univer, UniverInstanceType } from '@univerjs/core'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverDocsPlugin } from '@univerjs/docs'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
    import { UniverDrawingPlugin } from '@univerjs/drawing'
    import { UniverDrawingUIPlugin } from '@univerjs/drawing-ui'
    import DrawingUIEnUS from '@univerjs/drawing-ui/locale/en-US'
    import { UniverRenderEnginePlugin } from '@univerjs/engine-render'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs/drawing-ui/lib/index.css'
    import '@univerjs-pro/ink-ui/lib/index.css'
    import '@univerjs-pro/boards-ui/lib/index.css'
    ```
  </Step>
  <Step>
    Импорт фасада, если требуется Facade API[^facade-entry]:

    ```ts
    import { FUniver } from '@univerjs/core/facade'
    import '@univerjs-pro/boards/facade'
    ```
  </Step>
  <Step>
    Создайте экземпляр Univer, зарегистрируйте плагины и создайте блок управления:

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          DocsUIEnUS,
          DrawingUIEnUS,
          InkUIEnUS,
          BoardsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverRenderEnginePlugin)
    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverDocsPlugin)
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverDrawingPlugin)
    univer.registerPlugin(UniverDrawingUIPlugin)
    univer.registerPlugin(UniverInkUIPlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverBoardsPlugin)
    univer.registerPlugin(UniverBoardsUIPlugin)

    univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})

    const univerAPI = FUniver.newAPI(univer)
    ```
  </Step>
</Steps>

| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для размещения редактора или его идентификатор. |

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое файла клиентской лицензии. |

#### Методы `univer.registerPlugin` и `univer.registerPlugins` [#registerPlugin]

`univer.registerPlugin` добавляет плагин в экземпляр Univer. Позвоните ему после создания экземпляра.

Звонок принимает форму `univer.registerPlugin(Plugin, options)`, где `Plugin` является плагином для регистрации, а `options` - это дополнительная конфигурация, которая варьируется от плагина до плагина.

`univer.registerPlugins` принимает массив и регистрирует несколько плагинов в одном вызове, который сохраняет список плагинов в одно место.

```typescript
univer.registerPlugins([
  UniverRenderEnginePlugin,
  [UniverUIPlugin, { container: 'app' }],
  UniverDocsPlugin,
  UniverDocsUIPlugin,
  UniverDrawingPlugin,
  UniverDrawingUIPlugin,
  UniverInkUIPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverBoardsPlugin,
  UniverBoardsUIPlugin,
])
```

`FUniver.newAPI(univer)` возвращает объект `univerAPI`, который является Univer Facade API. Используйте его для создания досок и работы с бортовыми элементами.

## Поддержка мобильных устройств [#mobile-support]

<Callout type="warning">
  Для примеров нужны пакеты SDK, экспортирующие перечисленные мобильные плагины. Все зависимости `@univerjs/*` и `@univerjs-pro/*` должны иметь **одинаковую версию**.

  `1.0.0-rc.0` не экспортирует `UniverBoardsMobileUIPlugin`. Для этого примера используйте сборку, содержащую соответствующую мобильную точку входа.
</Callout>

Для сенсорных элементов управления в платах Univer используйте режим **Мобильные плагины UI**.[^mobile-ui-mode] Выберите режим пользовательского интерфейса перед созданием редактора.

В примере с плагин-режимом, приведенном выше, **заменить** эти пользовательские интерфейсы импортируют и регистрируют до `createUnit()`. Не добавляйте их к уже начатому редактору рабочего стола. Сохраните плагины модели, движки, локальные файлы, CSS и импорт Facade. Классы рабочего стола и мобильных устройств называются экспортом **та же самая упаковка** .

`UniverMobileUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для размещения редактора или его идентификатор. |
| `disableAutoFocus` | `true` | `true` | Это мешает редактору сосредоточиться на запуске. |

```typescript
import { UniverBoardsMobileUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverDocsMobileUIPlugin } from '@univerjs/docs-ui'
import { UniverDrawingMobileUIPlugin } from '@univerjs/drawing-ui'
import { UniverMobileUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverMobileUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsMobileUIPlugin)
univer.registerPlugin(UniverDrawingMobileUIPlugin)
univer.registerPlugin(UniverBoardsMobileUIPlugin)
```

### Соответствие плагинов

Зарегистрируйте только те функции, которые вы используете, и сохраните их плагины моделей и требуемые зависимости. Экспорт мобильного интерфейса не означает, что настольные и мобильные интерфейсы имеют одинаковые элементы управления. Функции Pro по-прежнему требуют соответствующей лицензии. Если функция нуждается в бэкэнде, интегрируйте его со стороны приложения с [Univer Server SDK](/server).

### Контейнер и сенсорное управление

Дайте контейнеру явную высоту и настройте видопорт страницы. `100dvh` следует за динамической высотой видопорта. Прокрутка теста, щипковый зум, выбор текста, доступ к буферу обмена и экранная клавиатура в целевых мобильных браузерах. Уменьшение редактора рабочего стола не переключает его на мобильные плагины.

`UniverMobileUIPlugin` по умолчанию выполняется `disableAutoFocus: true`, поэтому редактор не фокусируется автоматически во время инициализации.

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
<div id="app" style="height: 100dvh"></div>
```


Примеры регистрации см. в [Столик](/guides/boards/features/tables), [Карты разума](/guides/boards/features/mind-maps) и [Импорт и экспорт](/guides/boards/features/import-export).

## Другие каналы выпуска

Помимо стабильных релизов, Univer также публикует альфа- и бета-каналы. Они обеспечивают ранний доступ к функциям, которые не были отправлены официально. Компромисс выше: эти сборки могут содержать ошибки, незавершенные функции или нестабильное поведение. Избегайте их в производстве, когда это возможно.

### Выпуски Alpha / Beta

Когда команда разработчиков Univer завершает новую функцию или существенное изменение, она может предварительно выпустить работу на альфа- или бета-канал.Установите альфа-или бета-сборку пакета Univer со следующей командой:

```package-install
npm install @univerjs-pro/boards@alpha # Alpha version
npm install @univerjs-pro/boards@beta # Beta version
```

Если проблема возникает с альфа- или бета-сборкой, или у вас есть обратная связь, сообщите об этом команде разработчиков Univer через [Обсуждение GitHub](https://github.com/dream-num/univer/issues).

[^peer-dependency]: `peerDependencies` — зависимости, совместимые версии которых предоставляет основное приложение. Это позволяет Univer и приложению использовать общую копию библиотек, например React.

[^facade-entry]: Facade — прикладной API зарегистрированных плагинов. Импорт точки входа Facade добавляет методы API, но не регистрирует сам функциональный плагин.

[^mobile-ui-mode]: Мобильный UI-плагин выбирает сенсорные элементы управления и мобильные сервисы при инициализации. Он не определяет устройство автоматически и не переключает существующий экземпляр при изменении размера окна. Чтобы сменить режим, сохраните состояние документа, уничтожьте старый экземпляр и инициализируйте выбранный набор плагинов.
