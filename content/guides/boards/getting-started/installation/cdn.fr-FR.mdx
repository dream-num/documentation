---
title: Importer Web SDK via un CDN
---

Univer Boards ne fournit pas de bundle UMD prédéfini. Ajoutez-le à un runtime UMD Univer existant en mode plugin. Le bloc de code ci-dessous n'est pas un run time autonome.

## Charger dans l’ordre des dépendances

1. Chargez React, ReactDOM et RxJS.
2. Chargez les dépendances partagées Univer : Façade de base et de base, rendu, conception, UI, Docs et Docs UI, interface de dessin et dessin, licence, moteur de forme et son interface de facade, d'encre et d'encre, éditeur de formes et son interface utilisateur.
3. Chargez les fichiers des tableaux ci-dessous, et conservez chaque paquet `@univerjs` et `@univerjs-pro` dans la même version.

```html
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/locale/fr-FR.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/boards-ui/lib/index.css" />
```

Ces fichiers exposent `UniverProBoards`, `UniverProBoardsUi`, `UniverProBoardsFacade` et `UniverProBoardsUiEnUS`. Le fichier Boards UI Facade ajoute des méthodes à la façade de Board existante et ne crée pas un autre global. Fusionner l'objet local lors de la construction Univer, puis enregistrer `UniverBoardsPlugin` et `UniverBoardsUIPlugin` à partir des deux premiers espaces de noms.

Pour la configuration complète avec un gestionnaire de packages, revenez à [Installation et utilisation de base](/guides/boards/getting-started/installation).
