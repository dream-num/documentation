---
title: Importer Univer Boards via un CDN
---

Univer Boards ne fournit pas de bundle UMD preset. Utilisez le mode plugin pour l’ajouter à un environnement Univer UMD existant ; le bloc suivant n’est pas un environnement autonome.

## Charger dans l’ordre des dépendances

1. Chargez React, ReactDOM et RxJS.
2. Chargez les dépendances Univer partagées : Core et Core Facade, rendu, Design, UI, Docs et Docs UI, Drawing et Drawing UI, licence Pro, moteur de formes Pro et sa Facade, Ink et Ink UI, ainsi que Shape Editor et son UI.
3. Chargez les fichiers Boards ci-dessous. Utilisez la même version pour tous les packages `@univerjs` et `@univerjs-pro`.

```html
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/index.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/facade.js"></script>
<script src="https://unpkg.com/@univerjs-pro/boards-ui/lib/umd/locale/fr-FR.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@univerjs-pro/boards-ui/lib/index.css" />
```

Ces fichiers exposent `UniverProBoards`, `UniverProBoardsUi`, `UniverProBoardsFacade` et `UniverProBoardsUiFrFR`. Le fichier Facade de Boards UI ajoute des méthodes à la facade Board existante sans créer de nouvel objet global. Fusionnez l’objet de langue lors de la création d’Univer, puis enregistrez `UniverBoardsPlugin` et `UniverBoardsUIPlugin` depuis les deux premiers espaces de noms.

Pour la configuration complète avec un gestionnaire de packages, revenez à [Installation et utilisation de base](/guides/boards/getting-started/installation).
