Univer Boards es una capacidad de Univer SDK Pro. Las aplicaciones de producción necesitan una licencia Pro válida y las mismas consideraciones de implementación que otros productos Pro.

## Complemento de licencia

Registre `UniverLicensePlugin` antes de registrar los complementos de Board:

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

Mantenga el texto de la licencia fuera del control de código fuente. En aplicaciones de navegador, inyéctelo a través de su compilación o configuración de tiempo de ejecución.

## Alcance del paquete

Los paquetes de placa se encuentran en el alcance `@univerjs-pro`:

| Capacidad | Paquetes |
| --- | --- |
| Modelo de tablero central | `@univerjs-pro/boards` |
| UI del tablero del navegador | `@univerjs-pro/boards-ui` |
| Elementos de tabla | `@univerjs-pro/boards-table`, `@univerjs-pro/boards-table-ui` |
| Elementos de mapa mental | `@univerjs-pro/boards-mind`, `@univerjs-pro/boards-mind-ui` |

## Notas de implementación

- Registre solo los complementos de elementos requeridos por su producto.
- Cargue CSS de UI de Board después de CSS compartido de UI de Univer.
- Utilice paquetes de modelo solo en Node.js servicios.
- Conserve las instantáneas de Board como datos de la aplicación y migrelas junto con las actualizaciones de Univer.

Para obtener detalles sobre la licencia, el servidor y la implementación, consulte [Univer SDK Pro](/guides/pro).
