Facade API는 Univer 서비스 및 유닛 모델 위에 애플리케이션용 계층을 제공합니다. Board 만들기, 활성 페이지 읽기, 요소 추가, 컨테이너 업데이트, 스윔레인 관리와 같은 일반적인 Board 작업에 사용하세요.

<Callout type="warning" title="주의">
  Board 변경 API는 동기식이며 `boolean` 또는 nullable 핸들을 반환합니다. 반환값을 확인하세요.
</Callout>

## Facade 진입점 활성화

Boards는 Univer Pro 플러그인으로 배포됩니다. 애플리케이션에서 사용하는 Board 기능의 Facade 진입점을 가져옵니다.

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

Univer 인스턴스와 필수 플러그인을 등록한 후 API 객체를 만듭니다.

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Board 만들기 및 읽기

`createBoard`를 사용하여 Facade 계층을 통해 Board 유닛을 만듭니다. 하위 수준 설정 코드에서는 `univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)`으로 유닛을 만듭니다.

```ts
const board = univerAPI.createBoard({
  id: 'board-demo',
  name: 'Board Demo',
})

const activeBoard = univerAPI.getActiveBoard()
const sameBoard = univerAPI.getBoard(board.getId())
```

## 페이지 및 요소 작업

`FBoard` Facade는 애플리케이션 코드에서 내부 서비스를 직접 확인할 필요 없이 활성 페이지를 읽고, 요소를 조회하고, 요소 데이터를 업데이트합니다.

```ts
const elements = board.getElements()

const note = board.insertText({
  id: 'note-1',
  left: 120,
  top: 80,
  width: 240,
  height: 80,
  text: 'Planning note',
})
if (!note) throw new Error('Cannot insert note')

board.setElementTransform('note-1', {
  left: 160,
  top: 120,
  width: 280,
  height: 96,
})
```

## 컨테이너 및 스윔레인

컨테이너 소속을 변경하려면 Board Facade를 사용하세요. 컨테이너 API는 Board 스냅샷에서 순서와 부모-자식 관계를 유지합니다.

```ts
const containerId = 'backlog'
const containerCreated = board.createContainer({
  id: containerId,
  title: 'Backlog',
  left: 80,
  top: 80,
  width: 520,
  height: 360,
})
if (!containerCreated) {
  throw new Error('Cannot create container')
}

board.moveElementsToContainer(['note-1'], containerId)
board.fitContainerToContent(containerId)
```
