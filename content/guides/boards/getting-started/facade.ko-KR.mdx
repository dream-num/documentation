Facade API는 Univer 서비스 및 유닛 모델 위에 애플리케이션용 계층을 제공합니다. Board 만들기, 활성 페이지 읽기, 요소 추가, 컨테이너 업데이트, 스윔레인 관리와 같은 일반적인 Board 작업에 사용하세요.

<Callout type="warning" title="주의">
  Board 변경 API는 동기식이며 `boolean` 또는 nullable 핸들을 반환합니다. 반환값을 확인하세요.
</Callout>

## Facade 진입점 활성화

Boards는 Univer SDK Pro 플러그인으로 배포됩니다. 애플리케이션에서 사용하는 Board 기능의 Facade 진입점을 가져옵니다.

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

Univer 인스턴스와 필수 플러그인을 등록한 후 API 객체를 만듭니다.

```ts
const univerAPI = FUniver.newAPI(univer)
```
