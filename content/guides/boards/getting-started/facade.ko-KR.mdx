Facade API는 Univer 서비스 및 단위 모형에 신청 직면 층입니다. 그것은 널을 창조하고, 활동적인 페이지를 추가하고, 성분을 새롭게 하고, 콘테이너를 새롭게 하고, 수영을 관리하.

<Callout type="warning" title="주의">
  Board 변경 API는 동기식이며 `boolean` 또는 nullable 핸들을 반환합니다. 반환값을 확인하세요.
</Callout>

## Facade 진입점 활성화

보드는 Web SDK 플러그인으로 배포됩니다. 응용 프로그램 용도 :

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

Univer 인스턴스 이후 API 객체를 생성하고 필요한 플러그인은 등록됩니다.

```ts
const univerAPI = FUniver.newAPI(univer)
```

## 다음 단계

Facade 확장은 이제 활성화됩니다. 다음 페이지는 다음 주제를 설명합니다.

- [일반 API](/guides/boards/features/core/general-api)는 공유된 명령, 사건, undo 및 redo, UI 연장, 네트워킹, enums 및 유틸리티를 포함합니다.
- [Univer 보드 API](/guides/boards/features/core/boards-api)는 보드를 만들고 읽는 방법을 설명합니다.
- [제품정보](/guides/boards/features/core/elements) 및 [널 정면 참고](/reference/facade/board)는 세부 사항에서 보드 작업을 설명합니다.
