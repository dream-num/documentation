## Univer Boards 是什麼

Univer Boards 是 Univer Pro 中的畫布產品。當文件不再是網格、頁面或投影片，而是自由形式的工作區時，就適合使用 Univer Boards：白板、圖表、便利貼、連接線、嵌入式表格和心智圖都能在此使用。

Boards 是以獨立的 Univer 單元類型實作。執行時，請建立 `UniverInstanceType.UNIVER_BOARD` 單元，再依據要支援的元素註冊所需的模型與 UI 外掛。

## 什麼時候使用 Boards

如果應用程式需要讓使用者在大型畫布上自由安排內容，請使用 Boards。常見用途包括腦力激盪白板、流程圖、規劃圖、團隊回顧和產品圖表。如果主要處理的是表格式資料，請從 [Univer Bases](/guides/bases) 開始；如果是試算表，請從 [Univer Sheets](/guides/sheets) 開始。

## 安裝套件

Board 的核心執行環境分為模型套件與 UI 套件。表格與心智圖元素則是建構於 Board 執行環境之上的選用套件。

```bash
pnpm add @univerjs-pro/boards @univerjs-pro/boards-ui
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

## 套件對照

- `@univerjs-pro/boards`：Board 資料模型、元素結構描述、命令、變更操作、轉接器服務、Facade 進入點，以及 `UniverBoardsPlugin`
- `@univerjs-pro/boards-ui`：Board 畫布 UI、檢視區、選取、形狀編輯、連接線、便利貼、墨跡互動、工具列、內容選單，以及 `UniverBoardsUIPlugin`
- `@univerjs-pro/boards-table`：Board 表格元素整合與 `UniverBoardsTablePlugin`
- `@univerjs-pro/boards-table-ui`：表格元素 UI、渲染整合、語系進入點，以及 `UniverBoardsTableUIPlugin`
- `@univerjs-pro/boards-mind`：心智圖元素整合與 `UniverBoardsMindPlugin`
- `@univerjs-pro/boards-mind-ui`：心智圖 UI 整合與 `UniverBoardsMindUIPlugin`

## 註冊外掛

以下程式碼片段只顯示 Board 專用的設定。完整的應用程式還需要共用的 Univer 核心、渲染引擎、UI、授權和墨跡外掛。

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/boards/facade'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})
```
