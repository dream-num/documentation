## Univer Boards 是什麼

Univer Boards 是 Univer Office SDK 中的畫布產品。當文件不再是網格、頁面或幻燈片，而是一塊自由版面配置的工作區時，即可使用 Univer Boards：白板、圖表、便籤、連線線、嵌入式表格和思維導圖都屬於這一工作區。

Boards 使用 [Web SDK](/guides/sheets) 在瀏覽器中提供嵌入式畫布，無介面內容處理同樣由 Web SDK 完成。[Server SDK](/server) 提供協同與檔案交換能力，[AI SDK](/ai) 使 Agent 能夠編輯畫布。

Boards 是 Web SDK 中一種獨立的單元型別。執行時需要建立一個 `UniverInstanceType.UNIVER_BOARD` 單元，再按需要支援的元素註冊對應的模型外掛和 UI 外掛。

## 瀏覽器相容性

Web SDK 的編譯目標是 Chrome 88，但這並不意味著它能在所有環境中執行。Web SDK 在以下瀏覽器和 Node.js 環境中受支援：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK 依賴 `Intl.Segmenter`。如果瀏覽器或執行時環境不支援它，應先新增對應的 polyfill，推薦使用 `@formatjs/intl-segmenter`。
</Callout>

遇到相容性問題時，應先嚐試對應的 polyfill；如果問題仍然存在，請[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 相容性

<Callout type="warning">
  本說明僅適用於在 Node.js 中執行 Web SDK 的情況，不適用於透過基於 Node.js 的建置工具在瀏覽器中執行 Web SDK 的情況。
</Callout>

Web SDK 支援 Node.js v18.17.0 及之後的版本。

## 主要功能

- **頁面與元素順序**：頁面儲存在 `pages` 中，可繪製物件儲存在每個頁面的 `elements` 中，兩個層級都使用顯式的順序陣列。
- **畫布元素**：文字、形狀、圖片、連線線、組、容器和泳道。
- **命令驅動的編輯**：元素變更、順序和父子關係統一經過命令層，該層承載權限，以及可選的歷史記錄和協同整合掛鉤。
- **瀏覽器畫布**：渲染元素，並處理選擇、變換、剪貼簿、文字編輯、視口控制和麵板。
- **可擴充套件介面卡**：表格、思維導圖、圖表、資源、列印和交換等可選的 Boards 能力。
- **持久化**：建立、恢復和儲存 `IBoardData` 快照，包括頁面、資源、主題和活動頁面狀態。

## 如何使用這些文件

左側導航欄按從基礎到高階的順序列出文件頁面，可以在建置應用的過程中按順序閱讀。頁面也可以按任意順序閱讀，或跳過與自身場景無關的頁面。側邊欄頂部可以切換到 Univer Boards 文件。

右側的目錄用於在當前頁面的各章節之間導航。如需快速找到某個頁面，可使用頂部的搜尋欄或搜尋快捷鍵（Ctrl+K 或 Cmd+K）。

入門請參閱[快速開始](/guides/boards/getting-started/installation)。

## 前置知識

文件面向新讀者編寫，但假定讀者具備基礎知識，以便內容集中在 Web SDK 上。

對 JavaScript 及其生態有基本瞭解，有助於充分利用這些文件。

如果要在 Node.js 上執行 Web SDK，還建議對 Node.js 有基本瞭解。

如果一塊畫布需要多人同時編輯，或需要共享歷史、評論、檔案轉換，應在應用後端引入 [Univer Server SDK](/server) 的對應模組。身分認證、權限、儲存和部署仍由應用負責。僅在瀏覽器中開啟的畫布不需要這些服務。
