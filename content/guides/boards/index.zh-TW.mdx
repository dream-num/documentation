## Univer Boards 是什麼

Univer Boards 是 Univer Pro 中的畫布產品。當文件不再是網格、頁面或投影片，而是自由形式的工作區時，就適合使用 Univer Boards：白板、圖表、便利貼、連接線、嵌入式表格和心智圖都能在此使用。

Boards 是以獨立的 Univer 單元類型實作。執行時，請建立 `UniverInstanceType.UNIVER_BOARD` 單元，再依據要支援的元素註冊所需的模型與 UI 外掛。


## 瀏覽器相容性

Univer 的編譯目標是 Chrome 88，但這並不意味著 Univer 能夠完全支援所有主流環境。我們會盡力確保 Univer 在以下瀏覽器和 Node.js 環境中能夠正常運行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer 依賴 `Intl.Segmenter`，如果你的瀏覽器或執行環境暫不支援它，請先補上對應的 polyfill。我們推薦使用
  `@formatjs/intl-segmenter`。
</Callout>

如果遇到無法相容的情況，請先借助對應的 polyfill 來解決，如果仍然無法解決，請[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 相容性

<Callout type="warning">
  以下僅適用於在 Node.js 環境中運行 Univer 的情況，並不適用於那些基於 Node.js 使用建構工具在瀏覽器中運行 Univer 的情況。
</Callout>

Univer 可以在 Node.js 環境中運行，支援的版本為 v18.17.0 及之後的版本。

## 主要功能

- **頁面與元素順序**：頁面儲存在 `pages` 中，可繪製物件儲存在每個頁面的 `elements` 中，兩個層級都使用明確的順序陣列。
- **畫布元素**：處理文字、圖形、圖片、連接線、群組、容器與泳道圖。
- **命令驅動的編輯**：讓元素變更、順序與父子關係統一經過命令層，並提供權限及選用歷程與協同作業整合所需的掛鉤。
- **瀏覽器畫布**：算繪元素，並提供選取、變形、剪貼簿、文字編輯、檢視區控制與面板功能。
- **可擴充的配接器**：加入表格、心智圖、圖表、資源、列印與交換等選用 Boards 功能。
- **持久化**：建立、還原與儲存包含頁面、資源、主題及使用中頁面狀態的 `IBoardData` 快照。

## 如何使用這些文件

在螢幕的左側是文件導航欄。文件頁面按從基礎到高階的順序組織，你可以按照這個順序循序漸進地瞭解 Univer，或者跳到你感興趣的章節。你還可以在側邊欄的頂部切換 Univer Boards 的文件。

螢幕的右側是當前頁面的大綱。如果你需要快速找到頁面，可以使用頂部的搜尋欄或搜尋快捷鍵（Ctrl+K 或 Cmd+K）。

我們推薦從 [快速開始](/guides/boards/getting-started/quickstart) 出發瞭解 Univer。

## 前置知識

儘管我們已經盡力使得文件對新手也易於理解，但是我們必須假設你在開始閱讀之前已經瞭解了一些基礎知識，以便我們的文件可以專注於 Univer。

為了充分利用我們的文件，建議你對 JavaScript 及其生態系統有基本的瞭解。

如果你有興趣在 Node.js 上執行 Univer，你還應該對 Node.js 有基本的瞭解。

如果你想嘗試高階功能並部署 Univer Server，我們建議你對 Linux、Docker 和 Docker Compose（或 Kubernetes）有基本的瞭解。
