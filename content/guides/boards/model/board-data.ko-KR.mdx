## IBoardData

`IBoardData`는 Univer 널에 의해 이용된 스냅샷 체재입니다. 그것은 페이지 순서, 페이지 자료, 자원, 테마, 활동적인 페이지, 급상승 비율 및 널 수준 조정을 포함하여 1개의 널 단위를, 설명합니다.

### 속성

| 속성 | 타입 | 설명 |
| --- | --- | --- |
| id | `string` | 보드 유닛의 고유 ID입니다. |
| rev? | `number` | persistence 또는 공동 레이어에 의해 사용되는 옵션 개정 값. |
| name | `string` | 보드 이름입니다. |
| appVersion | `string` | 스냅샷을 생성한 패키지의 버전입니다. |
| locale? | `string` | 보드의 로캘입니다. |
| defaultPageSize | `IBoardPageSize` | 이사회 페이지의 기본 크기. |
| pageOrder | `string[]` | 순서가 지정된 보드 페이지 ID 목록입니다. |
| pages | `Record\<string, IBoardPage\>` | 페이지 스냅 샷, 페이지 ID에 의해 키 입력. |
| activePageId? | `string` | 활동 페이지의 Id. |
| theme? | `IBoardThemeData` | 현재 보드 테마입니다. |
| themes? | `Record\<string, IBoardThemeData\>` | 이름이 지정된 추가 테마입니다. |
| zoomRatio? | `number` | 현재 확대/축소 비율입니다. |
| resources? | `IResources` | 이미지, 리치 텍스트, 테이블 및 기타 요소에서 사용하는 외부 리소스입니다. |
| custom? | `Record\<string, unknown\> | null` | Metadata는 응용 프로그램에 의해 정의됩니다. |
| boardSettings? | `IBoardSettings` | 보드 수준의 UI 및 상호 작용 설정입니다. |

### 페이지 데이터

`IBoardPage`는 id에 의해 키 맵의 요소, 그리고 `elementOrder` 그들이 렌더링 하는 순서 정의. 스냅 샷을 만들 때 동기화에 두 개의 구조를 유지.

```ts
const boardData = {
  id: 'board-1',
  name: 'Planning board',
  appVersion: '1.0.0',
  defaultPageSize: { width: 1920, height: 1080 },
  pageOrder: ['page-1'],
  pages: {
    'page-1': {
      id: 'page-1',
      pageType: 'page',
      name: 'Page 1',
      elementOrder: ['text-1'],
      elements: {
        'text-1': {
          id: 'text-1',
          type: 'text',
          transform: { left: 120, top: 96, width: 240, height: 80 },
          text: 'Kickoff',
        },
      },
    },
  },
  activePageId: 'page-1',
}
```

## 용도

`IBoardData`의 주요 용도는 다음과 같습니다.

1. `UniverInstanceType.UNIVER_BOARD` 단위 만들기.
2. Persisting 및 복원 보드 문서.
3. 수입, 수출, 서버 측 처리에 대한 데이터 준비.
4. 페이지, 요소 및 설정으로 보드를 씨앗을 파는 첫 번째 렌더링 전에.

<Callout type="warning">
  Snapshot 개체는 지속 데이터입니다. 보드가 실행되면, 스냅 샷 객체를 직접 mutating 대신 Facade API를 사용하십시오.
</Callout>
