## IBoardData

`IBoardData` — формат снимка, используемый платами Univer. Он описывает один блок платы, включая порядок страницы, данные страницы, ресурсы, темы, активную страницу, соотношение зум и настройки уровня платы.

### Свойства

| Свойство | Тип | Описание |
| --- | --- | --- |
| id | `string` | Уникальный идентификатор доски. |
| rev? | `number` | Факультативное значение пересмотра, используемое уровнем настойчивости или совместной работы. |
| name | `string` | Название доски. |
| appVersion | `string` | Версия пакета, создавшего снимок состояния. |
| locale? | `string` | Локаль доски. |
| defaultPageSize | `IBoardPageSize` | Размер по умолчанию страниц совета директоров. |
| pageOrder | `string[]` | Упорядоченный список идентификаторов страниц доски. |
| pages | `Record\<string, IBoardPage\>` | Снимки страниц, помеченные идентификатором страницы. |
| activePageId? | `string` | Id активной страницы. |
| theme? | `IBoardThemeData` | Текущая тема доски. |
| themes? | `Record\<string, IBoardThemeData\>` | Дополнительные именованные темы. |
| zoomRatio? | `number` | Текущий масштаб. |
| resources? | `IResources` | Внешние ресурсы, используемые изображениями, форматированным текстом, таблицами и другими элементами. |
| custom? | `Record\<string, unknown\> | null` | Метаданные, определенные вашим приложением. |
| boardSettings? | `IBoardSettings` | Настройки интерфейса и взаимодействия на уровне доски. |

### Данные страницы

`IBoardPage` хранит элементы в карте, на которой размещена клавиша id, а `elementOrder` определяет порядок, в котором они отображаются.Сохраняйте две структуры синхронизированными, когда вы создаете снимок самостоятельно.

```ts
const boardData = {
  id: 'board-1',
  name: 'Planning board',
  appVersion: '1.0.0',
  defaultPageSize: { width: 1920, height: 1080 },
  pageOrder: ['page-1'],
  pages: {
    'page-1': {
      id: 'page-1',
      pageType: 'page',
      name: 'Page 1',
      elementOrder: ['text-1'],
      elements: {
        'text-1': {
          id: 'text-1',
          type: 'text',
          transform: { left: 120, top: 96, width: 240, height: 80 },
          text: 'Kickoff',
        },
      },
    },
  },
  activePageId: 'page-1',
}
```

## Использование

Основными видами использования `IBoardData` являются:

1. Создание `UniverInstanceType.UNIVER_BOARD`.
2. Сохранение и восстановление документов Совета.
3. Подготовка данных для импорта, экспорта или серверной обработки.
4. Посещение доски со страницами, элементами и настройками перед первым рендером.

<Callout type="warning">
  Объекты снимка - это данные о стойкости. После запуска платы используйте API Facade вместо того, чтобы напрямую мутировать объект снимка.
</Callout>
