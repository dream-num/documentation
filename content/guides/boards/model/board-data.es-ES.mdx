## IBoardData

`IBoardData` es el formato de instantánea utilizado por Univer Boards. Describe una unidad de la Junta, incluyendo el orden de página, datos de página, recursos, temas, la página activa, la relación de zoom y ajustes de nivel de la tabla.

### Propiedades

| Propiedad | Tipo | Descripción |
| --- | --- | --- |
| id | `string` | Identificación única de la unidad del tablero. |
| rev? | `number` | Valor de revisión opcional utilizado por la capa de persistencia o colaboración. |
| name | `string` | Nombre del tablero. |
| appVersion | `string` | Versión del paquete que creó la instantánea. |
| locale? | `string` | Configuración regional del tablero. |
| defaultPageSize | `IBoardPageSize` | Tamaño predeterminado de las páginas de la Junta. |
| pageOrder | `string[]` | Lista ordenada de páginas del tablero ids. |
| pages | `Record\<string, IBoardPage\>` | instantáneas de página, llave por página id. |
| activePageId? | `string` | Id de la página activa. |
| theme? | `IBoardThemeData` | Tema del tablero actual. |
| themes? | `Record\<string, IBoardThemeData\>` | Temas con nombre adicionales. |
| zoomRatio? | `number` | Relación de zoom actual. |
| resources? | `IResources` | Recursos externos utilizados por imágenes, texto enriquecido, tablas y otros elementos. |
| custom? | `Registro\<cadena, desconocido\> | null` | Metadatos definidos por su aplicación. |
| boardSettings? | `IBoardSettings` | IU a nivel de tablero y configuración de interacción. |

### Datos de la página

`IBoardPage` almacena elementos en un mapa clavedo por id, y `elementOrder` define el orden en el que renderizan. Mantenga las dos estructuras en sincronía cuando construya una instantánea.

```ts
const boardData = {
  id: 'board-1',
  name: 'Planning board',
  appVersion: '1.0.0',
  defaultPageSize: { width: 1920, height: 1080 },
  pageOrder: ['page-1'],
  pages: {
    'page-1': {
      id: 'page-1',
      pageType: 'page',
      name: 'Page 1',
      elementOrder: ['text-1'],
      elements: {
        'text-1': {
          id: 'text-1',
          type: 'text',
          transform: { left: 120, top: 96, width: 240, height: 80 },
          text: 'Kickoff',
        },
      },
    },
  },
  activePageId: 'page-1',
}
```

## Uso

Los principales usos de `IBoardData` son:

1. Creación de una unidad `UniverInstanceType.UNIVER_BOARD`.
2. Persiste y restaura los documentos de la Junta.
3. Preparación de datos para el procesamiento de importación, exportación o servidor.
4. Ver una Junta con páginas, elementos y ajustes antes de la primera entrega.

<Callout type="warning">
  Los objetos Snapshot son datos de persistencia. Una vez que se ejecuta una Junta, utilice las API de Facade en lugar de mutar directamente el objeto snapshot.
</Callout>
