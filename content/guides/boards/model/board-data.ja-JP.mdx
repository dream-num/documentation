## IBoardData

`IBoardData`はUniverボードで使用されるスナップショットフォーマットです。ページオーダー、ページデータ、リソース、テーマ、アクティブなページ、ズーム比、ボードレベルの設定を含む1つのボードユニットについて説明します。

### プロパティ

| プロパティ | 型 | 説明 |
| --- | --- | --- |
| id | `string` | ボードユニットの一意な ID。 |
| rev? | `number` | 永続性やコラボレーション層で使用されるオプションのリビジョン値。 |
| name | `string` | ボード名。 |
| appVersion | `string` | スナップショットを作成したパッケージのバージョン。 |
| locale? | `string` | ボードのロケール。 |
| defaultPageSize | `IBoardPageSize` | ボードページのデフォルトサイズ。 |
| pageOrder | `string[]` | ボードページ ID の順序付きリスト。 |
| pages | `Record\<string, IBoardPage\>` | ページのスナップショット、ページ ID によってキー化されます。 |
| activePageId? | `string` | アクティブページのID。 |
| theme? | `IBoardThemeData` | 現在のボードテーマ。 |
| themes? | `Record\<string, IBoardThemeData\>` | 名前が付けられた追加のテーマ。 |
| zoomRatio? | `number` | 現在のズーム倍率。 |
| resources? | `IResources` | 画像、リッチテキスト、テーブルなどの要素で使用される外部リソース。 |
| custom? | `Record\<string, unknown\> | null` | アプリケーションで定義されるメタデータ。 |
| boardSettings? | `IBoardSettings` | ボード単位の UI および操作設定。 |

### ページデータ

`IBoardPage` は id のキーのマップにある要素を格納し、`elementOrder`はレンダーする順番を定義します。スナップショットを自分で構築するときに 2 つの構造を同期させます。

```ts
const boardData = {
  id: 'board-1',
  name: 'Planning board',
  appVersion: '1.0.0',
  defaultPageSize: { width: 1920, height: 1080 },
  pageOrder: ['page-1'],
  pages: {
    'page-1': {
      id: 'page-1',
      pageType: 'page',
      name: 'Page 1',
      elementOrder: ['text-1'],
      elements: {
        'text-1': {
          id: 'text-1',
          type: 'text',
          transform: { left: 120, top: 96, width: 240, height: 80 },
          text: 'Kickoff',
        },
      },
    },
  },
  activePageId: 'page-1',
}
```

## 用途

`IBoardData`の主な用途は次のとおりです。

1. `UniverInstanceType.UNIVER_BOARD`ユニットの作成
2. ボード文書の永続および修復。
3. インポート、エクスポート、またはサーバー側の処理のためのデータを準備します。
4. 最初のレンダリングの前にページ、要素、および設定でボードをシードします。

<Callout type="warning">
  スナップショットオブジェクトは永続データです。 ボードが実行されると、スナップショットオブジェクトを直接ミュートする代わりにFacade APIを使用します。
</Callout>
