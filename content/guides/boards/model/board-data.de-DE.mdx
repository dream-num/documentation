## IBoardData

`IBoardData` ist das von Univer Boards verwendete Snapshot-Format. Es beschreibt eine Board-Einheit, einschließlich Seitenreihenfolge, Seitendaten, Ressourcen, Themen, aktive Seite, Zoomverhältnis und Einstellungen auf Board-Ebene.

### Eigenschaften

| Eigenschaft | Typ | Beschreibung |
| --- | --- | --- |
| id | `string` | Eindeutige ID der Board-Einheit. |
| rev? | `number` | Optionaler Revisionswert, der von Persistenz- oder Kollaborationsebenen verwendet wird. |
| name | `string` | Board-Name. |
| appVersion | `string` | Version des Pakets, das den Snapshot erstellt hat. |
| locale? | `string` | Gebietsschema des Boards. |
| defaultPageSize | `IBoardPageSize` | Standardseitengröße für Board-Seiten. |
| pageOrder | `string[]` | Geordnete Liste der Board-Seiten ids. |
| pages | `Record\<string, IBoardPage\>` | Seiten-Snapshots, sortiert nach Seiten-ID. |
| activePageId? | `string` | Aktive Seiten-ID. |
| theme? | `IBoardThemeData` | Aktuelles Board-Thema. |
| themes? | `Record\<string, IBoardThemeData\>` | Zusätzliche benannte Themen. |
| zoomRatio? | `number` | Aktuelles Zoomverhältnis. |
| resources? | `IResources` | Externe Ressourcen, die von Bildern, Rich Text, Tabellen und anderen Elementen verwendet werden. |
| custom? | `Datensatz\<string, unbekannt\> | null` | Anwendungsdefiniert Metadaten. |
| boardSettings? | `IBoardSettings` | UI- und Interaktionseinstellungen auf Board-Ebene. |

### Seitendaten

`IBoardPage` speichert Elemente nach ID und verwendet `elementOrder`, um die Renderreihenfolge zu definieren. Halten Sie beide Strukturen synchron, wenn Sie selbst einen Snapshot erstellen.

```ts
const boardData = {
  id: 'board-1',
  name: 'Planning board',
  appVersion: '1.0.0',
  defaultPageSize: { width: 1920, height: 1080 },
  pageOrder: ['page-1'],
  pages: {
    'page-1': {
      id: 'page-1',
      pageType: 'page',
      name: 'Page 1',
      elementOrder: ['text-1'],
      elements: {
        'text-1': {
          id: 'text-1',
          type: 'text',
          transform: { left: 120, top: 96, width: 240, height: 80 },
          text: 'Kickoff',
        },
      },
    },
  },
  activePageId: 'page-1',
}
```

## Verwendung

`IBoardData` wird hauptsächlich verwendet, um:

1. eine `UniverInstanceType.UNIVER_BOARD`-Einheit zu erstellen.
2. Board-Dokumente beizubehalten und wiederherzustellen.
3. Daten für den Import, Export oder die serverseitige Verarbeitung vorzubereiten.
4. Ein Board mit Seiten, Elementen, und Einstellungen vor dem Rendern.

<Callout type="warning">
Snapshot-Objekte sind Persistenzdaten. Nachdem ein Board ausgeführt wird, bevorzugen Sie Facade-APIs, anstatt das Snapshot-Objekt direkt zu ändern.
</Callout>
