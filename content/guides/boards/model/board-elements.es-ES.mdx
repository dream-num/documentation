Las páginas del tablero almacenan objetos dibujables en `elements` y su orden visual en `elementOrder`. Cada elemento tiene un `id`, un `type`, y un `transform` que registra su posición y tamaño en el lienzo.

## Campos de elementos comunes

| Campo | Tipo | Descripción |
| --- | --- | --- |
| id | `string` | Id. del elemento, único dentro de la página. |
| type | `BoardElementType` | Tipo de elemento, como `text`, `shape`, `image`, `connector`, `container`, `table` o `group`. |
| transform | `IBoardElementTransform` | Valores de posición, tamaño, rotación, escala, sesgo y giro. |
| parentId? | `string` | Id del contenedor o grupo padre. |
| laneId? | `string` | Swimlane id cuando el elemento está dentro de una natación. |
| name? | `string` | Nombre del elemento legible por humanos. |
| description? | `string` | Accesibilidad o metadatos de la aplicación. |
| visible? | `boolean` | Si el elemento debe representarse. |
| selectable? | `boolean` | Si el editor puede seleccionar el elemento. |
| locked? | `boolean` | Si la edición está bloqueada. |
| custom? | `Registro\<cadena, desconocido\> | null` | Metadatos definidos por su aplicación. |

## Tipos de elementos

| Tipo | Extra datos | Uso típico |
| --- | --- | --- |
| `text` | `text`, `textStyle`, `textData` | Notas adhesivas, etiquetas y bloques de texto enriquecido. |
| `shape` | `shapeData` | Rectángulos, flechas, leyendas y formas personalizadas. |
| `image` | `source`, `imageSourceType`, `crop` | Imágenes incrustadas. |
| `connector` | `connectorData` | Líneas y flechas adjuntas a puntos o formas libres. |
| `container` | `containerData` | Marcos, áreas, carriles, paquetes UML y límites del sistema. |
| `table` | `tableId` | Elementos de tabla de tablero proporcionados por el complemento de tabla. |
| `chart` | `chartId` | Elementos de gráfico. |
| `media` | `mediaType`, `source` | Marcadores de posición de audio y vídeo. |
| `group` | `children` | Colecciones de elementos agrupados. |

## Contenedores

Un contenedor determina qué elementos le pertenecen a través de `containerData.behavior`, y qué elementos captura a través de la `containerData.capturePolicy`. Utilice los métodos de contenedores Facade para mover elementos dentro y fuera, de modo que el orden y las relaciones entre padres siguen siendo consistentes.

```ts
board.wrapElementsInContainer(['task-1', 'task-2'], {
  title: 'Sprint 1',
})
```

## Carriles [#swimlanes]

Una natación es un contenedor que transporta `containerData.swimlane`. Cada carril tiene un id estable, un título, un valor de pedido, un tamaño y un estado opcional colapsado.

```ts
board.setSwimlaneLanes('lane-board', {
  orientation: 'horizontal',
  lanes: [
    { id: 'todo', title: 'Todo', order: 0, size: 240 },
    { id: 'doing', title: 'Doing', order: 1, size: 240 },
  ],
})
```

## Conectores

Los conectores consisten en puntos finales y datos de enrutamiento. Un punto final puede ser un punto libre, un límite de forma, un sitio de conexión, o una línea de vida. Los datos de rutina generalmente dependen de la geometría, así que use operaciones de Facade o acciones de la interfaz de usuario cuando edite un conector.
