## Qué es Univer Boards

Univer Boards es el producto de lienzo en Univer Pro. Se utiliza cuando el documento ya no es una cuadrícula, una página o una plataforma de diapositivas, sino un espacio de trabajo de forma libre: aquí pertenecen pizarras, diagramas, notas adhesivas, conectores, tablas integradas y mapas mentales.

Boards se implementa como un tipo de unidad independiente de Univer. En tiempo de ejecución, crea una unidad `UniverInstanceType.UNIVER_BOARD`, luego registra el modelo y los complementos de interfaz de usuario que necesita para los elementos que desea admitir.

## Cuándo usar tableros

Utilice tableros cuando su aplicación necesite un lienzo grande donde los usuarios organicen el contenido espacialmente. Los ejemplos típicos incluyen tableros de lluvia de ideas, diagramas de flujo, mapas de planificación, retrospectivas de equipos y diagramas de productos. Si su objeto principal son datos tabulares, comience con [Univer Bases](/guides/bases). Si es una hoja de cálculo, comience con [Univer Sheets](/guides/sheets).

## Instalar paquetes

El tiempo de ejecución principal de Board se divide en un paquete de modelo y un paquete de UI. Los elementos de tabla y mapa mental son paquetes opcionales colocados en capas encima del tiempo de ejecución del tablero.

```bash
pnpm add @univerjs-pro/boards @univerjs-pro/boards-ui
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

## Mapa de paquete

- `@univerjs-pro/boards`: modelo de datos del tablero, esquema de elementos, comandos, mutaciones, servicios de adaptador, entrada de fachada y `UniverBoardsPlugin`
- `@univerjs-pro/boards-ui`: interfaz de usuario del lienzo del tablero, ventana gráfica, selección, edición de formas, conectores, notas adhesivas, tinta interacción, barra de herramientas, menú contextual y `UniverBoardsUIPlugin`
- `@univerjs-pro/boards-table`: integración de elementos de tabla de tablero y `UniverBoardsTablePlugin`
- `@univerjs-pro/boards-table-ui`: interfaz de usuario de elementos de tabla, integración de renderizado, puntos de entrada locales y `UniverBoardsTableUIPlugin`
- `@univerjs-pro/boards-mind`: integración de elementos de mapa mental y `UniverBoardsMindPlugin`
- `@univerjs-pro/boards-mind-ui`: integración de la interfaz de usuario del mapa mental y `UniverBoardsMindUIPlugin`

## Registrar complementos

El siguiente fragmento muestra la parte de la configuración específica del tablero. Una aplicación completa también necesita el núcleo compartido de Univer, el motor de renderizado, la interfaz de usuario, la licencia y los complementos de tinta.

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/boards/facade'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})
```
