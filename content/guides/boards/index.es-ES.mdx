## Qué es Univer Boards

Univer Boards es el producto de lona en Univer Office SDK. Se utiliza cuando un documento ya no es una cuadrícula, una página, o una cubierta de diapositivas pero un espacio de trabajo de forma libre: pizarras, diagramas, notas pegajosas, conectores, tablas incrustadas, y mapas mentales pertenecen aquí.

Las tablas utilizan [Web SDK](/guides/sheets) para lienzos incrustados en el navegador, y Web SDK también maneja el procesamiento de contenido sin cabeza. [Server SDK](/server) proporciona colaboración e intercambio de archivos, y [AI SDK](/ai) permite a un agente editar una tabla.

Boards es un tipo de unidad independiente en Web SDK. En el tiempo de ejecución, una aplicación crea una unidad `UniverInstanceType.UNIVER_BOARD` y luego registra el modelo y los plugins UI para los elementos que necesita para soportar.

## Compatibilidad del navegador

Web SDK compila a un objetivo Chrome 88. Ese objetivo no implica que Web SDK se ejecuta en cada entorno. Los siguientes navegadores y entornos Node.js son compatibles:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK se basa en `Intl.Segmenter`. Si el navegador o el entorno de tiempo de ejecución no lo soporta, agregue primero el polífilo correspondiente. El polifilo recomendado es `@formatjs/intl-segmenter` .
</Callout>

Si ocurre un problema de compatibilidad, aplique primero el polífilo correspondiente. Si el problema persiste, [presentar una cuestión](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilidad con Node.js

<Callout type="warning">
  Esta sección cubre la ejecución Web SDK dentro de Node.js solamente. No se aplica cuando Web SDK se ejecuta en un navegador a través de herramientas de construcción basadas en Node.js.
</Callout>

Web SDK funciona en Node.js v18.17.0 y más tarde.

## Aspectos destacados

- **Páginas y orden de elementos**: páginas almacenadas en `pages` y objetos dibujables almacenados en el `elements` de cada página, con un array de orden explícito en ambos niveles.
- **Elementos de las islas**: texto, formas, imágenes, conectores, grupos, contenedores y nataciónles.
- **Edición impulsada por comandos**: cambios de elementos, pedidos y relaciones entre padres se enrutieron a través de una capa de comandos que lleva permisos y ganchos para la historia opcional e integraciones de colaboración.
- **Navegador de tela**: renderización de elementos, selección, transformaciones, portapapeles, edición de texto, controles de visualización y paneles.
- **Adaptadores extensibles**: capacidades opcionales de la Junta como tablas, mapas mentales, gráficos, recursos, impresión e intercambio.
- **Persistencia**: creación, restauración y ahorro de una instantánea `IBoardData`, incluyendo páginas, recursos, temas y estado de página activa.

## Cómo leer la documentación

El navbar en la izquierda enumera las páginas en orden, desde lo básico hasta lo avanzado, para que los lectores puedan seguirlas paso a paso mientras construyen una aplicación. Las páginas se pueden leer en cualquier orden, y las páginas que no se aplican al caso de uso pueden ser saltadas. El encabezado de la barra lateral proporciona un cambio a la documentación de las Juntas Univer.

La tabla de contenidos de la derecha proporciona navegación entre secciones de la página actual. Para localizar una página rápidamente, utilice la barra de búsqueda en la parte superior o el acceso directo de búsqueda (Ctrl+K o Cmd+K).

Para empezar, vea la guía [Inicio rápido](/guides/boards/getting-started/installation).

## Conocimientos previos requeridos

La documentación está escrita para los recién llegados, pero asume el conocimiento de base para que pueda mantenerse enfocado en Web SDK.

Los lectores sacan el máximo provecho de la documentación con un entendimiento básico de JavaScript y su ecosistema.

Si Web SDK va a funcionar en Node.js, también se recomienda una comprensión básica de Node.js.

Cuando varias personas editan la misma tabla, o la historia compartida, los comentarios o la conversión de archivos son necesarios, agregue los módulos correspondientes de [Univer Server SDK](/server) y ejecutelos en el backend de la aplicación. Autenticación, permisos, almacenamiento y despliegue siguen siendo la responsabilidad de la aplicación . Una tabla que sólo se abre en el navegador no requiere estos servicios.
