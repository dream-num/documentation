## Univer Boards 是什么

Univer Boards 是 Univer Office SDK 中的画布产品。当文档不再是网格、页面或幻灯片，而是一块自由布局的工作区时，即可使用 Univer Boards：白板、图表、便签、连接线、嵌入式表格和思维导图都属于这一工作区。

Boards 使用 [Web SDK](/guides/sheets) 在浏览器中提供嵌入式画布，无界面内容处理同样由 Web SDK 完成。[Server SDK](/server) 提供协同与文件交换能力，[AI SDK](/ai) 使 Agent 能够编辑画布。

Boards 是 Web SDK 中一种独立的单元类型。运行时需要创建一个 `UniverInstanceType.UNIVER_BOARD` 单元，再按需要支持的元素注册对应的模型插件和 UI 插件。

## 浏览器兼容性

Web SDK 的编译目标是 Chrome 88，但这并不意味着它能在所有环境中运行。Web SDK 在以下浏览器和 Node.js 环境中受支持：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK 依赖 `Intl.Segmenter`。如果浏览器或运行时环境不支持它，应先添加对应的 polyfill，推荐使用 `@formatjs/intl-segmenter`。
</Callout>

遇到兼容性问题时，应先尝试对应的 polyfill；如果问题仍然存在，请[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 兼容性

<Callout type="warning">
  本说明仅适用于在 Node.js 中运行 Web SDK 的情况，不适用于通过基于 Node.js 的构建工具在浏览器中运行 Web SDK 的情况。
</Callout>

Web SDK 支持 Node.js v18.17.0 及之后的版本。

## 主要功能

- **页面与元素顺序**：页面存储在 `pages` 中，可绘制对象存储在每个页面的 `elements` 中，两个层级都使用显式的顺序数组。
- **画布元素**：文本、形状、图片、连接线、组、容器和泳道。
- **命令驱动的编辑**：元素变更、顺序和父子关系统一经过命令层，该层承载权限，以及可选的历史记录和协同集成挂钩。
- **浏览器画布**：渲染元素，并处理选择、变换、剪贴板、文本编辑、视口控制和面板。
- **可扩展适配器**：表格、思维导图、图表、资源、打印和交换等可选的 Boards 能力。
- **持久化**：创建、恢复和保存 `IBoardData` 快照，包括页面、资源、主题和活动页面状态。

## 如何使用这些文档

左侧导航栏按从基础到高级的顺序列出文档页面，可以在构建应用的过程中按顺序阅读。页面也可以按任意顺序阅读，或跳过与自身场景无关的页面。侧边栏顶部可以切换到 Univer Boards 文档。

右侧的目录用于在当前页面的各章节之间导航。如需快速找到某个页面，可使用顶部的搜索栏或搜索快捷键（Ctrl+K 或 Cmd+K）。

入门请参阅[快速开始](/guides/boards/getting-started/installation)。

## 前置知识

文档面向新读者编写，但假定读者具备基础知识，以便内容集中在 Web SDK 上。

对 JavaScript 及其生态有基本了解，有助于充分利用这些文档。

如果要在 Node.js 上运行 Web SDK，还建议对 Node.js 有基本了解。

如果一块画布需要多人同时编辑，或需要共享历史、评论、文件转换，应在应用后端引入 [Univer Server SDK](/server) 的对应模块。身份认证、权限、存储和部署仍由应用负责。仅在浏览器中打开的画布不需要这些服务。
