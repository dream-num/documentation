## Univer Boards 是什么

Univer Boards 是 Univer SDK Pro 中的画布产品。当文档不再是网格、页面或幻灯片，而是一个自由布局的工作区时，就可以使用它：白板、图表、便签、连接线、嵌入式表格和思维导图都适合在这里创建。

Boards 以独立的 Univer SDK 单元类型实现。运行时需要创建一个 `UniverInstanceType.UNIVER_BOARD` 单元，再根据要支持的元素注册相应的模型和 UI 插件。


## 浏览器兼容性

Univer SDK 的编译目标是 Chrome 88，但这并不意味着 Univer SDK 能够完全支持所有主流环境。我们会尽力确保 Univer SDK 在以下浏览器和 Node.js 环境中能够正常运行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK 依赖 `Intl.Segmenter`，如果你的浏览器或运行时环境暂不支持它，请先补充对应的 polyfill。我们推荐使用
  `@formatjs/intl-segmenter`。
</Callout>

如果遇到无法兼容的情况，请先借助对应的 polyfill 来解决，如果仍然无法解决，请[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 兼容性

<Callout type="warning">
  以下仅适用于在 Node.js 环境中运行 Univer SDK 的情况，并不适用于那些基于 Node.js 使用构建工具在浏览器中运行 Univer SDK 的情况。
</Callout>

Univer SDK 可以在 Node.js 环境中运行，支持的版本为 v18.17.0 及之后的版本。

## 主要功能

- **页面与元素顺序**：页面存储在 `pages` 中，可绘制对象存储在每个页面的 `elements` 中，两个层级都使用显式顺序数组。
- **画布元素**：处理文本、形状、图片、连接线、组、容器和泳道。
- **命令驱动的编辑**：让元素变更、顺序和父子关系统一经过命令层，并提供权限及可选历史记录和协同集成所需的挂钩。
- **浏览器画布**：渲染元素，并提供选择、变换、剪贴板、文本编辑、视口控制和面板功能。
- **可扩展适配器**：添加表格、思维导图、图表、资源、打印和交换等可选 Boards 能力。
- **持久化**：创建、恢复和保存包含页面、资源、主题与活动页面状态的 `IBoardData` 快照。
