## Univer Boards 是什么

Univer Boards 是 Univer Pro 中的画布产品。当文档不再是网格、页面或幻灯片，而是一个自由布局的工作区时，就可以使用它：白板、图表、便签、连接线、嵌入式表格和思维导图都适合在这里创建。

Boards 以独立的 Univer 单元类型实现。运行时需要创建一个 `UniverInstanceType.UNIVER_BOARD` 单元，再根据要支持的元素注册相应的模型和 UI 插件。


## 浏览器兼容性

Univer 的编译目标是 Chrome 88，但这并不意味着 Univer 能够完全支持所有主流环境。我们会尽力确保 Univer 在以下浏览器和 Node.js 环境中能够正常运行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer 依赖 `Intl.Segmenter`，如果你的浏览器或运行时环境暂不支持它，请先补充对应的 polyfill。我们推荐使用
  `@formatjs/intl-segmenter`。
</Callout>

如果遇到无法兼容的情况，请先借助对应的 polyfill 来解决，如果仍然无法解决，请[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 兼容性

<Callout type="warning">
  以下仅适用于在 Node.js 环境中运行 Univer 的情况，并不适用于那些基于 Node.js 使用构建工具在浏览器中运行 Univer 的情况。
</Callout>

Univer 可以在 Node.js 环境中运行，支持的版本为 v18.17.0 及之后的版本。


## 什么时候使用 Boards

当应用需要一块让用户自由摆放内容的大画布时，可以使用 Boards。常见场景包括头脑风暴白板、流程图、规划图、团队复盘和产品图。如果主要处理表格型数据，请从 [Univer Bases](/guides/bases) 开始；如果主要处理电子表格，请从 [Univer Sheets](/guides/sheets) 开始。

## 安装包

Board 核心运行时分为模型包和 UI 包。表格和思维导图元素则通过构建在 Board 运行时之上的可选包提供。

```bash
pnpm add @univerjs-pro/boards @univerjs-pro/boards-ui
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

## 包一览

- `@univerjs-pro/boards`：Board 数据模型、元素模式、命令、变更、适配器服务、Facade 入口和 `UniverBoardsPlugin`
- `@univerjs-pro/boards-ui`：Board 画布 UI、视口、选择、形状编辑、连接线、便签、墨迹交互、工具栏、上下文菜单和 `UniverBoardsUIPlugin`
- `@univerjs-pro/boards-table`：Board 表格元素集成与 `UniverBoardsTablePlugin`
- `@univerjs-pro/boards-table-ui`：表格元素 UI、渲染集成、本地化入口和 `UniverBoardsTableUIPlugin`
- `@univerjs-pro/boards-mind`：思维导图元素集成与 `UniverBoardsMindPlugin`
- `@univerjs-pro/boards-mind-ui`：思维导图 UI 集成与 `UniverBoardsMindUIPlugin`

## 注册插件

下面的代码片段仅展示 Board 相关的设置。完整应用还需要 Univer 的共享核心、渲染引擎、UI、许可证和墨迹插件。

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/boards/facade'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})
```
