---

La API de Facade proporciona una capa orientada a la aplicación sobre los servicios y modelos de unidades de Univer. Úselo para operaciones comunes del tablero, como crear tableros, leer páginas activas, agregar elementos, actualizar contenedores y administrar carriles.

<Callout type="warning" title="Precaución">
Las mutaciones de Board son síncronas y devuelven `boolean` o un identificador anulable. Compruebe el valor devuelto.
</Callout>

## Habilite la entrada de fachada

Los tableros se distribuyen como complementos de Web SDK. Importe la entrada de fachada para la capacidad del tablero utilizada por su aplicación:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

La revisión del diseño y las capturas de abajo también requieren registrar `UniverBoardsUIPlugin` y añadir este import.

```ts
import '@univerjs-pro/boards-ui/facade'
```

Cree el objeto API después de que se registren la instancia de Univer y los complementos necesarios:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Cree y lea un tablero

Utilice `createBoard` para crear una unidad de tablero a través de la capa de fachada. En el código de configuración de nivel inferior, cree la unidad con `univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)`.

```ts
const board = univerAPI.createBoard({
  id: 'board-demo',
  name: 'Board Demo',
})

const activeBoard = univerAPI.getActiveBoard()
const sameBoard = univerAPI.getBoard(board.getId())
```

## Revisar la disposición del tablero y tomar capturas [#rendered-layout]

Ejecuta los ejemplos cuando el tablero ya esté visible en el navegador.

### Detectar problemas de disposición [#inspect-layout]

Llama a `analyzeRenderedLayout()` para detectar, por ejemplo, conectores que se cruzan o texto que se sale de una forma. La revisión no modifica el tablero. En cada problema, `rule` indica el tipo y `focusBounds` la zona que conviene revisar.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active board')

const analysis = board.analyzeRenderedLayout()
if (!analysis) throw new Error('The board is not ready for layout inspection')

for (const { rule, focusBounds } of analysis.issues) {
  console.log(rule, focusBounds)
}
```

[`analyzeRenderedLayout()`](/reference/facade/board#analyzerenderedlayout)

### Capturar un elemento concreto [#capture-element]

Para incluir un paso del diagrama en un informe, sustituye `review-step` por el ID del elemento. Usa `resolveCaptureBounds()` para obtener el área de captura y pásala a `getScreenshot()`. El `dataUrl` devuelto se puede usar como origen de la imagen PNG.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active board')

const target = board.resolveCaptureBounds({ elementIds: ['review-step'], padding: 16 })
if (!target || !target.ok) throw new Error('Cannot locate the element to capture')

const screenshot = await board.getScreenshot({ bounds: target.bounds })
if (!screenshot) throw new Error('Cannot capture the selected area')

console.log(screenshot.dataUrl)
```

[`resolveCaptureBounds()`](/reference/facade/board#resolvecapturebounds) · [`getScreenshot()`](/reference/facade/board#getscreenshot)
