Facade API es la capa que se orienta a la aplicación sobre los servicios Univer y los modelos unitarios. Cubre las operaciones comunes de la Junta: crear una tabla, leer la página activa, añadir elementos, actualizar contenedores y gestionar nadoles.

<Callout type="warning" title="Precaución">
  Las mutaciones de la junta son sincronizadas y devuelven un `boolean` o un mango nulable. Compruebe el valor de retorno antes de leer el resultado.
</Callout>

## Habilite la entrada de fachada

Las tablas se distribuyen como plugins Web SDK. Importar la entrada de fachada para la capacidad de la Junta que la aplicación utiliza:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

La revisión del diseño y las capturas de abajo también requieren registrar `UniverBoardsUIPlugin` y añadir este import.

```ts
import '@univerjs-pro/boards-ui/facade'
```

Crear el objeto API después de la instancia Univer y los plugins necesarios se han registrado:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Cree y lea un tablero

`createBoard` crea una unidad de tablero a través de la fachada. En el código de configuración de nivel inferior, crear la unidad con `univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)`.

```ts
const board = univerAPI.createBoard({
  id: 'board-demo',
  name: 'Board Demo',
})

const activeBoard = univerAPI.getActiveBoard()
const sameBoard = univerAPI.getBoard(board.getId())
```

## Revisar la disposición del tablero y tomar capturas [#rendered-layout]

Ejecuta los ejemplos cuando el tablero ya esté visible en el navegador.

### Detectar problemas de disposición [#inspect-layout]

`analyzeRenderedLayout()` reporta problemas como el cruce de conectores o texto que no cabe dentro de una forma. La llamada sólo reporta los problemas y deja el diseño sin cambios. Cada número lleva `rule`, que da el tipo de problema, y `focusBounds` que da el área a inspeccionar.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active board')

const analysis = board.analyzeRenderedLayout()
if (!analysis) throw new Error('The board is not ready for layout inspection')

for (const { rule, focusBounds } of analysis.issues) {
  console.log(rule, focusBounds)
}
```

[`analyzeRenderedLayout()`](/reference/facade/board#analyzerenderedlayout)

### Capturar un elemento concreto [#capture-element]

Para incluir una imagen de un paso de flujo en un informe, sustitúyase `review-step` por el elemento ID de ese paso. `resolveCaptureBounds()` calcula el área para capturar. Pase esa área a `getScreenshot()` para obtener una URL de datos PNG que se puede utilizar como fuente de imagen.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active board')

const target = board.resolveCaptureBounds({ elementIds: ['review-step'], padding: 16 })
if (!target || !target.ok) throw new Error('Cannot locate the element to capture')

const screenshot = await board.getScreenshot({ bounds: target.bounds })
if (!screenshot) throw new Error('Cannot capture the selected area')

console.log(screenshot.dataUrl)
```

[`resolveCaptureBounds()`](/reference/facade/board#resolvecapturebounds) · [`getScreenshot()`](/reference/facade/board#getscreenshot)
