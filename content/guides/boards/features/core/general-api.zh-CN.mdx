Univer 中可用的 Facade API 取决于当前单元类型和已注册的插件。本页介绍其中 Univer Boards 应用常用的部分。

## 引入

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 命令

Univer 中的大多数操作都注册到命令系统。这条统一的执行路径支持撤销、重做和协同。

<Callout>
  设计思路见 [Univer 命令系统](/blog/univer#command-system)。
</Callout>

### 监听命令

`Event.BeforeCommandExecute` 在命令执行前触发，`Event.CommandExecuted` 在命令执行完成后触发。

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('命令执行前：', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('命令执行后：', id, params)
})
```

在 `BeforeCommandExecute` 监听器中将 `event.cancel` 设为 `true`，可以阻止命令执行。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'board.command.set-name') {
    event.cancel = true
  }
})
```

每个监听器都会返回 `IDisposable`。不再需要该监听器时，请销毁返回值。

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### 执行命令

在已知命令 ID 和参数的情况下，通过 `FUniver.executeCommand` 执行命令。下面的 Boards 命令会重命名当前 Board：

```typescript
const board = univerAPI.getActiveBoard()

if (board) {
  await univerAPI.executeCommand('board.command.set-name', {
    unitId: board.getId(),
    name: '项目笔记',
  })
}
```

## 事件 API

`univerAPI.Event` 中的事件名来自 Univer Core 和当前应用注册的插件。Core 提供通用的命令事件和单元事件，插件可以在此基础上继续添加。使用某个事件之前，请确认提供该事件的插件已经注册。

当前版本的事件名称和参数类型见 [Facade Events 参考](/reference/facade/events)。

使用 `addEvent` 订阅事件；取消订阅时销毁返回的对象：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'board.command.set-name') {
    console.log('Board名称已更改')
  }
})

// 不再需要时移除监听器
disposable.dispose()
```

## 撤销和重做

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## WebSocket

如需使用 WebSocket API，请安装 `@univerjs/network`、注册 `UniverNetworkPlugin`，并导入它的 Facade 扩展。

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

注册后，Socket 支持订阅事件、发送消息和关闭连接：

```typescript
const socket = univerAPI.createSocket('wss://example.com/boards')

socket.open$.subscribe(() => socket.send('hello'))
socket.message$.subscribe((message) => console.log('WebSocket 消息：', message.data))
socket.error$.subscribe((error) => console.error('WebSocket 错误：', error))
socket.close()
```

## 枚举 API

通用枚举类型通过 `univerAPI.Enum` 提供：

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_BOARD)
console.log(univerAPI.Enum.BoardElementType.Shape)
```

## 工具方法 API

通用工具方法通过 `univerAPI.Util` 提供：

```typescript
console.log(univerAPI.Util.tools.isString('Univer Boards')) // true
```
