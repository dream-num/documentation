Facade API provides an application-facing layer over Univer services and unit models. Use it for common Board operations such as creating boards, reading active pages, adding elements, updating containers, and managing swimlanes.

<Callout type="warning" title="Caution">
  Board mutations are synchronous and return `boolean` or a nullable handle. Check the return value before reading the result.
</Callout>

## Enable the facade entry

Boards is distributed as Web SDK plugins. Import the facade entry for the Board capability used by your application:

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

The layout check and screenshot examples also require `UniverBoardsUIPlugin` and the import below.

```ts
import '@univerjs-pro/boards-ui/facade'
```

Create the API object after the Univer instance and required plugins are registered:

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Create and read a board

Use `createBoard` to create a Board unit through the facade layer. In lower-level setup code, create the unit with `univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)`.

```ts
const board = univerAPI.createBoard({
  id: 'board-demo',
  name: 'Board Demo',
})

const activeBoard = univerAPI.getActiveBoard()
const sameBoard = univerAPI.getBoard(board.getId())
```

## Check a board’s layout and take screenshots [#rendered-layout]

Run the following examples after the board is visible in the browser.

### Find layout problems [#inspect-layout]

Use `analyzeRenderedLayout()` to check for problems such as crossing connectors or text that doesn’t fit inside a shape. The call leaves the layout as it is. For each issue, `rule` gives the type of problem and `focusBounds` gives the area to inspect.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active board')

const analysis = board.analyzeRenderedLayout()
if (!analysis) throw new Error('The board is not ready for layout inspection')

for (const { rule, focusBounds } of analysis.issues) {
  console.log(rule, focusBounds)
}
```

[`analyzeRenderedLayout()`](/reference/facade/board#analyzerenderedlayout)

### Capture a specific element [#capture-element]

To add an image of a flowchart step to a report, replace `review-step` with the step’s element ID. `resolveCaptureBounds()` finds the area to capture. Pass that area to `getScreenshot()` to get a PNG data URL you can use as an image source.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active board')

const target = board.resolveCaptureBounds({ elementIds: ['review-step'], padding: 16 })
if (!target || !target.ok) throw new Error('Cannot locate the element to capture')

const screenshot = await board.getScreenshot({ bounds: target.bounds })
if (!screenshot) throw new Error('Cannot capture the selected area')

console.log(screenshot.dataUrl)
```

[`resolveCaptureBounds()`](/reference/facade/board#resolvecapturebounds) · [`getScreenshot()`](/reference/facade/board#getscreenshot)
