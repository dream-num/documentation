---
title: Элементы
---

Элементы — это видимое содержание доски: текст, изображения, формы и разъемы.Изменения, вносимые через фасад `FBoard`, следуют обычному командному пути, поэтому к ним также относятся отмена, переделка и коллаборация.

## Чтение элементов

Получите активную доску перед чтением ее активной страницы.Когда требуются только стабильные идентификаторы, типы, границы и порядок, используйте дескрипторы вместо того, чтобы зависеть от полного внутреннего снимка.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active board')

const elements = board.describeElements()
const shapes = board.findElements({
  elementType: univerAPI.Enum.BoardElementType.Shape,
})
```

## Вставка фигур и текста

Используйте методы семантической вставки вместо построения низкоуровневых моментальных снимков элементов. Для `insertShape` `transform` несет геометрию, а возвращенная рукоятка живой формы обнажает API текста и стиля.

```ts
const shape = board.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 80, width: 180, height: 100 },
  name: 'Review card',
})
if (!shape) throw new Error('Cannot insert shape')

shape.getText().setText('Review')
shape.setRotation(6)
```

`insertText` добавляет автономный текст, а `insertImage` — изображения.Когда необходимо добавить несколько элементов одной командой, используйте пакетные варианты.

## Редактирование текста фигуры

Используйте форму, возвращенную `insertShape()` в примере ниже, или форму, полученную в предыдущем разделе. `getText()` возвращает живую ручку [FShapeText](/reference/facade/shape-text). Позвоните `getPlainText()`, чтобы прочитать текст, `setText()` для замены всего этого, а также шрифт, цвет и методы выравнивания для его форматирования.

```ts
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()` заменяет существующий текст. Используйте `setRichText()`, когда одна форма требует нескольких стилей. Чтобы изменить существующий богатый текст, позвоните `getRichText()?.copy()` , отредактируйте конструктор и передайте его `setRichText()`. Изменения в этом отдельном конструкторе не применяются автоматически. [Текстовый стиль](/reference/facade/shape-text#settextstyle) и [текстовая обшивка и макет](/reference/facade/shape-text#settextboxoptions) описывают дополнительные опции.

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## Соединение элементов

Разъем может прикрепляться к существующим идентификаторам элементов.Сохранить возвращенный разъем или его идентификатор, когда его стиль, метка или конечные точки должны быть изменены позже.

```ts
const target = board.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.Rect,
  transform: { left: 360, top: 80, width: 180, height: 100 },
})
if (!target) throw new Error('Cannot insert target')

const connector = board.insertConnector({
  fromElementId: shape.getId(),
  toElementId: target.getId(),
  style: { endMarker: { type: 'filledTriangle', size: 'md' } },
})
if (!connector) throw new Error('Cannot insert connector')
```

## Преобразование и размещение элементов

Передайте только те свойства, которые должны меняться. Методы упорядочивания, выравнивания, распределения и автоматической компоновки также принимают идентификаторы элементов.

```ts
if (!board.setElementTransform(shape.getId(), { left: 120, top: 140, rotation: 12 })) {
  throw new Error('Cannot transform shape')
}

if (!board.bringElementsToFront([shape.getId()])) {
  throw new Error('Cannot bring shape to front')
}
```

## Удаление элементов

`removeElement` удаляет один элемент, а `removeElements` убирает партию атомарно. Оба возвращают, удалось ли команде.

```ts
if (!board.removeElements([connector.id, target.getId()])) {
  throw new Error('Cannot remove elements')
}
```

Для обрамленных групп и плаваний продолжайте с [Контейнеры и Swimlanes](/guides/boards/features/core/containers). [Ссылка на фасадные доски](/reference/facade/board) и [Модель данных элементов платы](/guides/boards/model/board-elements) предоставляют дополнительные детали.
