El Facade API disponible en Univer depende del tipo de unidad actual y de los plugins registrados. Esta página cubre las API comunes utilizadas en una aplicación Univer Boards.

## Importación

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Comandos

La mayoría de las operaciones en Univer están registradas con el sistema de comandos. Esta única ruta de ejecución soporta deshacer, redo y colaboración.

<Callout>
  Para la racionalidad del diseño, vea el [Sistema de comando Univer](/blog/univer#command-system).
</Callout>

### Escuchar comandos

`Event.BeforeCommandExecute` dispara antes de ejecutar un comando, y `Event.CommandExecuted` se dispara después de que termine.

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('Antes del comando:', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('Comando ejecutado:', id, params)
})
```

Un oyente `BeforeCommandExecute` puede evitar que un comando se ejecute estableciendo `event.cancel` a `true`.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'board.command.set-name') {
    event.cancel = true
  }
})
```

Cada oyente devuelve un `IDisposable`. Desórtelo cuando el oyente ya no es necesario.

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### Ejecutar comandos

Cuando se conoce el ID de comando y sus parámetros, ejecute el comando con `FUniver.executeCommand`. El siguiente comando Boards renombra el tablero activo:

```typescript
const board = univerAPI.getActiveBoard()

if (board) {
  await univerAPI.executeCommand('board.command.set-name', {
    unitId: board.getId(),
    name: 'Notas del proyecto',
  })
}
```

## API de eventos

`univerAPI.Event` lista los nombres de los eventos de Univer y de los plugins registrados en la aplicación actual. Core suministra el comando compartido y los eventos de unidad, y los plugins pueden añadir su propio. Confirme que el plugin que proporciona un evento está registrado antes de utilizar el evento.

El [Facade Eventos referencia](/reference/facade/events) enumera los nombres de los eventos y los tipos de parámetro en la versión actual.

Suscríbete con `addEvent`, y deshaga el objeto devuelto para darse de baja:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'board.command.set-name') {
    console.log('El nombre del Board ha cambiado')
  }
})

// Elimine el listener cuando ya no sea necesario
disposable.dispose()
```

## Deshacer y rehacer

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## WebSocket

Para usar las API de WebSocket, instale `@univerjs/network`, registre `UniverNetworkPlugin` e importe su extensión Facade.

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

Después del registro, el socket admite suscribirse a eventos de toma de corriente, enviar mensajes y cerrar la conexión:

```typescript
const socket = univerAPI.createSocket('wss://example.com/boards')

socket.open$.subscribe(() => {
  socket.send('hello')
})

socket.message$.subscribe((message) => {
  console.log('Mensaje WebSocket:', message.data)
})

socket.error$.subscribe((error) => {
  console.error('Error de WebSocket:', error)
})

socket.close()
```

## API de enumeración

Los tipos comunes de enum están expuestos en `univerAPI.Enum`:

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_BOARD)
console.log(univerAPI.Enum.BoardElementType.Shape)
```

## API de métodos de utilidad

Las utilidades compartidas están expuestas en `univerAPI.Util`:

```typescript
console.log(univerAPI.Util.tools.isString('Univer Boards')) // true
```
