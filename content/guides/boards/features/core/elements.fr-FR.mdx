---
title: Éléments
---

Les éléments sont le contenu visible d'un panneau : texte, images, formes et connecteurs. Les modifications apportées à la façade `FBoard` suivent le chemin de commande normal, donc défaire, refaire et collaborer s'appliquent également à eux.

## Lire les éléments

Obtenir le tableau actif avant de lire sa page active. Lorsque seuls des identifiants stables, des types, des limites et des commandes sont requis, utiliser des descripteurs au lieu de dépendre de l'instantané interne complet.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active board')

const elements = board.describeElements()
const shapes = board.findElements({
  elementType: univerAPI.Enum.BoardElementType.Shape,
})
```

## Insérer des formes et du texte

Utilisez les méthodes d'insertion sémantique au lieu de construire des instantanés d'éléments de bas niveau. Pour `insertShape`, `transform` porte la géométrie, et la poignée de forme live retournée expose le texte et les API de style.

```ts
const shape = board.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 80, width: 180, height: 100 },
  name: 'Review card',
})
if (!shape) throw new Error('Cannot insert shape')

shape.getText().setText('Review')
shape.setRotation(6)
```

`insertText` ajoute du texte autonome, et `insertImage` apporte des images. Lorsque plusieurs éléments doivent être ajoutés avec une commande, utilisez les variantes par lots.

## Modifier le texte d’une forme

Utilisez la forme retournée par `insertShape()` dans l'exemple ci-dessous, ou la forme obtenue dans la section précédente. `getText()` retourne une poignée [Texte en forme de texte](/reference/facade/shape-text) en direct. Appelez `getPlainText()` pour lire le texte, `setText()` et les méthodes de police, de couleur et d'alignement pour le formater.

```ts
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()` remplace le texte existant. Utilisez `setRichText()` lorsqu'une seule forme nécessite plusieurs styles. Pour modifier le texte riche existant, appelez `getRichText()?.copy()`, modifiez le constructeur et passez-le à `setRichText()`. Les modifications apportées à ce constructeur détaché ne sont pas appliquées automatiquement. [Style de texte](/reference/facade/shape-text#settextstyle) et [Rembourrage et mise en page de la boîte de texte](/reference/facade/shape-text#settextboxoptions) décrivent d'autres options.

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## Relier les éléments

Un connecteur peut se fixer aux ID d'éléments existants. Gardez le connecteur retourné ou son ID lorsque son style, son étiquette ou ses paramètres seront modifiés plus tard.

```ts
const target = board.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.Rect,
  transform: { left: 360, top: 80, width: 180, height: 100 },
})
if (!target) throw new Error('Cannot insert target')

const connector = board.insertConnector({
  fromElementId: shape.getId(),
  toElementId: target.getId(),
  style: { endMarker: { type: 'filledTriangle', size: 'md' } },
})
if (!connector) throw new Error('Cannot insert connector')
```

## Transformer et organiser les éléments

Passez seulement les propriétés qui doivent changer. Les méthodes de commande, d'alignement, de distribution et de mise en page automatique acceptent également les ID des éléments.

```ts
if (!board.setElementTransform(shape.getId(), { left: 120, top: 140, rotation: 12 })) {
  throw new Error('Cannot transform shape')
}

if (!board.bringElementsToFront([shape.getId()])) {
  throw new Error('Cannot bring shape to front')
}
```

## Supprimer des éléments

`removeElement` supprime un seul élément, et `removeElements` enlève un lot atomiquement. Les deux retournent si la commande a réussi.

```ts
if (!board.removeElements([connector.id, target.getId()])) {
  throw new Error('Cannot remove elements')
}
```
