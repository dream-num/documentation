Facade API, доступный в Univer зависит от текущего типа блока и зарегистрированных плагинов. Эта страница охватывает общие API, используемые в приложении Univer Boards.

## Импорт

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'

const univerAPI = FUniver.newAPI(univer)
```

## Команды

Большинство операций в Univer зарегистрированы в системе команд. Этот единственный путь выполнения поддерживает отмену, переделку и совместную работу.

<Callout>
  Для обоснования дизайна см. [Командная система Univer](/blog/univer#command-system).
</Callout>

### Прослушивание команд

`Event.BeforeCommandExecute` загорается до того, как выполняется команда, а `Event.CommandExecuted` стреляет после ее окончания.

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('Перед командой:', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('Команда выполнена:', id, params)
})
```

Слушатель `BeforeCommandExecute` может предотвратить запуск команды, установив `event.cancel` на `true`.

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'board.command.set-name') {
    event.cancel = true
  }
})
```

Каждый слушатель возвращает `IDisposable`. Удалите его, когда слушатель больше не нужен.

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### Выполнение команд

Когда идентификатор команды и ее параметры известны, выполните команду с помощью `FUniver.executeCommand`. Следующая команда Boards переименовывает активную плату:

```typescript
const board = univerAPI.getActiveBoard()

if (board) {
  await univerAPI.executeCommand('board.command.set-name', {
    unitId: board.getId(),
    name: 'Заметки проекта',
  })
}
```

## API событий

`univerAPI.Event` перечисляет имена событий из ядра Univer и из плагинов, зарегистрированных в текущем приложении. Core поставляет общие командные и единичные события, а плагины могут добавлять свои собственные. Подтверждают, что плагин, предоставляющий событие, зарегистрирован перед использованием события.

[Ссылка на события Facade](/reference/facade/events) перечисляет имена событий и типы параметров в текущем выпуске.

Подписывайтесь на `addEvent` и утилизируйте возвращенный объект, чтобы отказаться от подписки:

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'board.command.set-name') {
    console.log('Имя Board изменено')
  }
})

// Удалите обработчик, когда он больше не нужен
disposable.dispose()
```

## WebSocket

Для работы с WebSocket установите `@univerjs/network`, зарегистрируйте `UniverNetworkPlugin` и импортируйте его Facade-расширение.

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

После регистрации розетка поддерживает подписку на события розетки, отправку сообщений и закрытие соединения:

```typescript
const socket = univerAPI.createSocket('wss://example.com/boards')

socket.open$.subscribe(() => socket.send('hello'))
socket.message$.subscribe((message) => console.log('Сообщение WebSocket:', message.data))
socket.error$.subscribe((error) => console.error('Ошибка WebSocket:', error))
socket.close()
```

## API перечислений

Типы общего числа выставляются на `univerAPI.Enum`:

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_BOARD)
console.log(univerAPI.Enum.BoardElementType.Shape)
```

## API вспомогательных методов

Общие утилиты отображаются на `univerAPI.Util`:

```typescript
console.log(univerAPI.Util.tools.isString('Univer Boards')) // true
```
