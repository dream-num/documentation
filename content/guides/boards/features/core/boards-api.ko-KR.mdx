Facade API는 Univer 서비스 및 유닛 모델 위에 애플리케이션용 계층을 제공합니다. Board 만들기, 활성 페이지 읽기, 요소 추가, 컨테이너 업데이트, 스윔레인 관리와 같은 일반적인 Board 작업에 사용하세요.

<Callout type="warning" title="주의">
  Board 변경 API는 동기식이며 `boolean` 또는 nullable 핸들을 반환합니다. 반환값을 확인하세요.
</Callout>

## Facade 진입점 활성화

Boards는 Web SDK 플러그인으로 배포됩니다. 애플리케이션에서 사용하는 Board 기능의 Facade 진입점을 가져옵니다.

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

아래 레이아웃 검사와 스크린샷에는 `UniverBoardsUIPlugin` 등록과 다음 가져오기도 필요합니다.

```ts
import '@univerjs-pro/boards-ui/facade'
```

Univer 인스턴스와 필수 플러그인을 등록한 후 API 객체를 만듭니다.

```ts
const univerAPI = FUniver.newAPI(univer)
```

## Board 만들기 및 읽기

`createBoard`를 사용하여 Facade 계층을 통해 Board 유닛을 만듭니다. 하위 수준 설정 코드에서는 `univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)`으로 유닛을 만듭니다.

```ts
const board = univerAPI.createBoard({
  id: 'board-demo',
  name: 'Board Demo',
})

const activeBoard = univerAPI.getActiveBoard()
const sameBoard = univerAPI.getBoard(board.getId())
```

반환된 `FBoard` 객체는 활성 페이지와 해당 콘텐츠의 진입점입니다. 자세한 작업은 다음 가이드를 참고하세요.

- [요소](/guides/boards/features/core/elements)에서는 Board 요소 읽기, 삽입, 연결, 변형, 배치 및 삭제를 설명합니다.
- [컨테이너 및 스윔레인](/guides/boards/features/core/containers)에서는 프레임 그룹, 소속 관계 및 스윔레인 구조를 설명합니다.

## 보드 레이아웃 확인 및 스크린샷 [#rendered-layout]

브라우저에 보드가 표시된 후 아래 예제를 실행하세요.

### 레이아웃 문제 찾기 [#inspect-layout]

흐름도의 연결선이 서로 교차하거나 텍스트가 도형 밖으로 나오는지 확인하려면 `analyzeRenderedLayout()`을 호출합니다. 검사 중 레이아웃은 바뀌지 않습니다. 각 문제의 `rule`은 유형을, `focusBounds`는 확인할 영역을 나타냅니다.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active board')

const analysis = board.analyzeRenderedLayout()
if (!analysis) throw new Error('The board is not ready for layout inspection')

for (const { rule, focusBounds } of analysis.issues) {
  console.log(rule, focusBounds)
}
```

[`analyzeRenderedLayout()`](/reference/facade/board#analyzerenderedlayout)

### 지정한 요소 캡처하기 [#capture-element]

흐름도의 한 단계를 보고서에 넣으려면 `review-step`을 해당 요소의 ID로 바꿉니다. `resolveCaptureBounds()`로 캡처 범위를 구해 `getScreenshot()`에 전달합니다. 반환된 `dataUrl`은 이미지 주소로 사용할 수 있습니다.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active board')

const target = board.resolveCaptureBounds({ elementIds: ['review-step'], padding: 16 })
if (!target || !target.ok) throw new Error('Cannot locate the element to capture')

const screenshot = await board.getScreenshot({ bounds: target.bounds })
if (!screenshot) throw new Error('Cannot capture the selected area')

console.log(screenshot.dataUrl)
```

[`resolveCaptureBounds()`](/reference/facade/board#resolvecapturebounds) · [`getScreenshot()`](/reference/facade/board#getscreenshot)
