Univer 보드 코어는 브라우저에서 실행되는 대화형 캔버스가있는 페이지 및 정렬 모델을 결합합니다. 두 Web SDK 패키지는 모델과 UI를 제공하며 독립적 인 `UNIVER_BOARD` 장치를 형성합니다.

## 기능

- **페이지 및 요소 주문**: 페이지는 `pages`에 저장되고, drawable 목표는 각 페이지의 `elements`에서 저장됩니다; 둘 다 수준은 명백한 순서 배열을 유지합니다.
- **캔버스 요소**: 성분은 원본, 모양, 이미지, 연결관, 그룹, 콘테이너 및 swimlanes일 수 있습니다.
- **명령 중심 편집**: 요소 변경, 주문 및 부모 - 어린이 관계는 또한 선택적 역사와 협력 통합을위한 권한과 후크를 운반하는 하나의 명령 층을 통해 모든 패스를 전달합니다.
- **브라우저 캔버스**: 캔버스 렌더링 요소와 선택, 변환, 클립보드, 텍스트 편집, 뷰포트 컨트롤 및 패널을 제공합니다.
- **Extensible 어댑터**: 테이블, 마음 지도, 도표, 자원, 인쇄 및 교환과 같은 널 기능은 선택적이고 접합기로 통합됩니다.
- **관련 제품**: 보드는 `IBoardData` 스냅 샷으로 생성, 복원 및 저장 될 수 있습니다, 페이지, 리소스, 테마 및 활성 페이지 상태 포함.

## 플러그인 모드

### 설치

[설치 및 기본 사용](/guides/boards/getting-started/installation)에서 설정된 Univer 런타임에 두 개의 보드 패키지를 추가하십시오.

```package-install
npm install @univerjs-pro/boards @univerjs-pro/boards-ui
```

### 제품 플러그인 등록

공유 렌더링, 문서, 그림, 잉크, 모양 편집 및 라이센스 의존성을 먼저 등록하여 설치 가이드에 설명 된대로 이사회 플러그인을 등록하십시오.

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

import '@univerjs-pro/boards-ui/lib/index.css'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

`UniverBoardsPlugin`는 이사회 모델, 명령, 요소 서비스, 어댑터 및 권한을 등록합니다. `UniverBoardsUIPlugin`은 렌더링 된 캔버스 및 브라우저 상호 작용을 제공합니다.

보드 컨텍스트 메뉴는 공유 [`MenuConfig`](/reference/packages/plugins/univerjs/ui#menuconfig)를 사용합니다. `menu`을 기존 `UniverUIPlugin` 등록에 `UniverBoardsUIPlugin`에 추가하십시오. 다음 예는 컨텍스트-menu 그룹의 시작 부분에 중복됩니다.

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'board.menu.duplicate-selection': { order: -1 },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', menu })
```

`order`는 주문 종료에 있는 컨텍스트-menu 아이템을 동기화하고 그룹 사이에 아이템을 이동하지 않습니다. 명령 ID와 다를 수 있는 제품 메뉴 정의에서 메뉴 아이템 ID를 사용하십시오.

#### 캔버스 도구 모음

보드는 전용 캔버스 도구 모음을 사용하고 표준 제품 리본을 등록하지 않습니다. `gridLayout`는 공유 그리드 리본 만 제어합니다. 캔버스 도구 모음 또는 컨텍스트 메뉴를 리어 레인지하지 않습니다. 캔버스 도구는 `UniverBoardsUIPlugin.toolbar.tools`를 통해 구성됩니다. 다음 예는 기존 플러그인 등록에서 펜 도구를 비활성화합니다.

```ts
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: { tools: { pen: false } },
})
```

`toolbar.tools`는 도구가 사용할 수 있는지 여부, 그 순서 또는 그리드 배치를 제어합니다. 캔버스 컨트롤과 공유 메뉴의 차이에 대한 [게시판 UI 참고](/reference/packages/plugins/univerjs-pro/boards-ui)를 참조하십시오.

## 프리셋 모드

Univer 보드는 현재 전용 프리셋을 제공하지 않습니다. 모델과 브라우저 UI를 모두 위한 플러그인 모드를 사용합니다.

## Facade API로 메뉴 업데이트 [#menu-facade]

### 실행 중 업데이트

`univerAPI`를 `FUniver.newAPI(univer)`로 만들기 전에 `@univerjs/ui/facade` 가져 오기. [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig)는 변경 사항을 합병하고 지정되지 않은 필드를 보존하고 메뉴를 새로 고침합니다. 오버라이드는 또한 메뉴에 등록되어 있습니다.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'board.menu.duplicate-selection': { order: 5 },
})
```
