Le noyau Univer Boards combine un modèle page-et-élément avec une toile interactive qui fonctionne dans le navigateur. Deux paquets Web SDK fournissent le modèle et l'interface utilisateur, et ensemble ils forment une unité `UNIVER_BOARD` indépendante.

## Fonctionnalités

- **Pages et commande d'éléments**: Les pages sont stockées dans `pages`, et les objets dessinables sont stockés dans le `elements` de chaque page; les deux niveaux maintiennent un tableau d'ordre explicite.
- **Éléments de toile**: Les éléments peuvent être du texte, des formes, des images, des connecteurs, des groupes, des conteneurs et des nageuses.
- **Révision par commande**: Les changements d'éléments, la commande et les relations parent-enfant passent tous par un seul calque de commande, qui porte également des permissions et des crochets pour les intégrations d'historique et de collaboration optionnelles.
- **La toile du navigateur**: La toile rend les éléments et fournit la sélection, les transformations, le presse-papier, l'édition de texte, les commandes de viewport et les panneaux.
- **Adaptateurs extensibles**: Les fonctions de la carte telles que les tables, les cartes mentales, les graphiques, les ressources, l'impression et l'échange sont optionnelles et intégrées comme adaptateurs.
- **Persistance**: Une carte peut être créée, restaurée et sauvegardée sous forme d'un instantané `IBoardData`, qui comprend des pages, des ressources, des thèmes et un état de page active.

## Mode plugin

### Installation

Ajouter les deux paquets de Boards à l'exécution Univer configurée dans [Installation et utilisation de base](/guides/boards/getting-started/installation) :

```package-install
npm install @univerjs-pro/boards @univerjs-pro/boards-ui
```

### Enregistrement des plugins du produit

Enregistrez d'abord le rendu partagé, le document, le dessin, l'encre, l'édition de forme et les dépendances de licence, comme décrit dans le guide d'installation, puis enregistrez les plugins Boards:

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

import '@univerjs-pro/boards-ui/lib/index.css'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

`UniverBoardsPlugin` enregistre le modèle Board, les commandes, les services d'éléments, les adaptateurs et les permissions. `UniverBoardsUIPlugin` fournit les interactions de toile et de navigateur rendues.

Les menus contextuels des tableaux utilisent le [`MenuConfig`](/reference/packages/plugins/univerjs/ui#menuconfig) partagé. Ajouter `menu` à l'enregistrement `UniverUIPlugin` existant plutôt qu'à `UniverBoardsUIPlugin`. L'exemple suivant déplace Duplicate vers le début de son groupe contextuel :

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'board.menu.duplicate-selection': { order: -1 },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', menu })
```

`order` trie les éléments du menu contextuel dans l'ordre croissant et ne déplace pas un élément entre les groupes. Utilisez l'identifiant de l'élément de menu de la définition du menu produit, qui peut différer de l'identificateur de commande.

#### Barre d’outils du canevas

Les cartes utilisent une barre d'outils de toile dédiée et n'enregistrent pas un produit standard Ribbon. `gridLayout` contrôle uniquement la grille partagée Ribbon; il ne réorganise pas la barre d'outil de toile ou les menus contextuels. Les outils de toile sont configurés à travers `UniverBoardsUIPlugin.toolbar.tools`. L'exemple suivant désactive l'outil stylo dans l'enregistrement de plugin existant:

```ts
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: { tools: { pen: false } },
})
```

`toolbar.tools` contrôle si un outil est disponible, et non pas sa commande ou son emplacement de grille. Consultez le [Conseils d'assurance-chômage](/reference/packages/plugins/univerjs-pro/boards-ui) pour connaître la différence entre les commandes de toile et les menus partagés.

## Mode preset

Univer Boards ne fournit pas de préréglage dédié à l'heure actuelle. Utilisez le mode plugin pour le modèle et l'interface utilisateur du navigateur.

## Mettre à jour les menus avec l’API Facade [#menu-facade]

### Mise à jour à l’exécution

Importez `@univerjs/ui/facade` avant de créer `univerAPI` avec `FUniver.newAPI(univer)`. [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) fusionne les modifications, conserve les champs non spécifiés et rafraîchit les menus. Les dépassements s'appliquent également aux menus enregistrés plus tard.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'board.menu.duplicate-selection': { order: 5 },
})
```
