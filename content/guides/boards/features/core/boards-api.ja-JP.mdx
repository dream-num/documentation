Facade API は、Univer のサービスとユニットモデルをアプリケーションから利用するためのレイヤーです。ボードの作成、アクティブなページの読み取り、要素の追加、コンテナの更新、スイムレーンの管理といった一般的なボード操作に使用します。

<Callout type="warning" title="注意">
  Board の変更 API は同期処理で、`boolean` または null 許容のハンドルを返します。戻り値を確認してください。
</Callout>

## Facade エントリを有効にする

Boards は Web SDK プラグインとして配布されています。アプリケーションで使用するボード機能に対応した Facade エントリをインポートします。

```ts
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'
```

下記のレイアウト確認とスクリーンショットには、`UniverBoardsUIPlugin` の登録と次のインポートも必要です。

```ts
import '@univerjs-pro/boards-ui/facade'
```

Univer インスタンスと必要なプラグインを登録した後に、API オブジェクトを作成します。

```ts
const univerAPI = FUniver.newAPI(univer)
```

## ボードを作成・読み取りする

Facade レイヤーを介してボードユニットを作成するには、`createBoard` を使用します。低レベルのセットアップコードでは、`univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)` を使用してユニットを作成します。

```ts
const board = univerAPI.createBoard({
  id: 'board-demo',
  name: 'Board Demo',
})

const activeBoard = univerAPI.getActiveBoard()
const sameBoard = univerAPI.getBoard(board.getId())
```

## コア機能に進む

返された `FBoard` オブジェクトが、アクティブページとそのコンテンツの入口です。詳しい操作は次のガイドを参照してください。

- [要素](/guides/boards/features/core/elements)では、Board 要素の読み取り、挿入、接続、変形、配置、削除を説明します。
- [コンテナーとスイムレーン](/guides/boards/features/core/containers)では、枠付きグループ、所属関係、スイムレーン構造を説明します。

## ボードのレイアウト確認とスクリーンショット [#rendered-layout]

ブラウザーにボードが表示されたら、以下の例を実行できます。

### レイアウトの問題を見つける [#inspect-layout]

フローチャートのコネクタが交差していないか、テキストが図形からはみ出していないかを調べるには、`analyzeRenderedLayout()` を使います。検査でレイアウトは変わりません。各項目の `rule` は問題の種類、`focusBounds` は確認する範囲です。

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active board')

const analysis = board.analyzeRenderedLayout()
if (!analysis) throw new Error('The board is not ready for layout inspection')

for (const { rule, focusBounds } of analysis.issues) {
  console.log(rule, focusBounds)
}
```

[`analyzeRenderedLayout()`](/reference/facade/board#analyzerenderedlayout)

### 指定した要素を画像にする [#capture-element]

フローチャートの一工程をレポートに載せるには、`review-step` をその要素の ID に置き換えます。`resolveCaptureBounds()` で撮影範囲を求め、`getScreenshot()` に渡します。返される `dataUrl` は画像の URL として使用できます。

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active board')

const target = board.resolveCaptureBounds({ elementIds: ['review-step'], padding: 16 })
if (!target || !target.ok) throw new Error('Cannot locate the element to capture')

const screenshot = await board.getScreenshot({ bounds: target.bounds })
if (!screenshot) throw new Error('Cannot capture the selected area')

console.log(screenshot.dataUrl)
```

[`resolveCaptureBounds()`](/reference/facade/board#resolvecapturebounds) · [`getScreenshot()`](/reference/facade/board#getscreenshot)
