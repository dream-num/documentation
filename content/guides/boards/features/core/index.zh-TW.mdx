Univer Boards 的核心由頁面與元素模型和執行在瀏覽器中的互動畫布組成。模型和 UI 分別由兩個 Web SDK 包提供，二者共同構成獨立的 `UNIVER_BOARD` 單元。

## 功能

- **頁面與元素順序**：頁面儲存在 `pages` 中，可繪製物件儲存在每頁的 `elements` 中，兩個層級都維護顯式的順序陣列。
- **畫布元素**：元素可以是文字、形狀、圖片、連線線、組、容器或泳道。
- **命令驅動的編輯**：元素變更、順序調整和父子關係均經過同一命令層，權限以及可選的歷史記錄和協同整合鉤子也位於該層。
- **瀏覽器畫布**：畫布負責渲染元素，並提供選擇、變換、剪貼簿、文字編輯、視口控制和麵板。
- **可擴充套件介面卡**：表格、思維導圖、圖表、資源、列印、交換等 Board 能力均為可選，並透過介面卡接入。
- **持久化**：畫板可以建立、恢復和儲存為 `IBoardData` 快照，快照涵蓋頁面、資源、主題和當前頁面狀態。

## 外掛模式

### 安裝

將兩個 Boards 包新增到[安裝與基礎使用](/guides/boards/getting-started/installation)中配置好的 Univer 執行時：

```package-install
npm install @univerjs-pro/boards @univerjs-pro/boards-ui
```

### 註冊產品外掛

按照安裝指南的說明，先註冊共享的渲染、文件、繪圖、墨跡、形狀編輯和許可證依賴，再註冊 Boards 外掛：

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

import '@univerjs-pro/boards-ui/lib/index.css'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

`UniverBoardsPlugin` 註冊 Board 模型、命令、元素服務、介面卡和權限。`UniverBoardsUIPlugin` 提供渲染畫布和瀏覽器互動。

Boards 的右鍵選單使用共享的 [`MenuConfig`](/reference/packages/plugins/univerjs/ui#menuconfig)。`menu` 應新增到已有的 `UniverUIPlugin` 註冊配置中，不要傳給 `UniverBoardsUIPlugin`。下面的範例將“建立副本”移到所在右鍵選單分組的首位：

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'board.menu.duplicate-selection': { order: -1 },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', menu })
```

`order` 按數值升序排列同級右鍵選單項，不會將選單項移到其他分組。選單項 ID 應使用產品選單定義中的 ID，它可能與命令 ID 不同。

#### 畫布工具列

Boards 使用獨立的畫布工具欄，不註冊標準的品類 Ribbon。`gridLayout` 僅控制共享的網格 Ribbon，不會重排畫布工具欄或右鍵選單。畫布工具透過 `UniverBoardsUIPlugin.toolbar.tools` 配置。下面的範例在已有外掛註冊中禁用畫筆工具：

```ts
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: { tools: { pen: false } },
})
```

`toolbar.tools` 控制工具是否可用，不控制工具順序或網格位置。畫布控制元件與共享選單的區別見 [Boards UI 參考](/reference/packages/plugins/univerjs-pro/boards-ui)。

## 預設模式

Univer Boards 目前不提供專用預設。模型和瀏覽器 UI 均使用外掛模式。

## 用 Facade API 更新選單 [#menu-facade]

### 執行階段更新

先匯入 `@univerjs/ui/facade`，再透過 `FUniver.newAPI(univer)` 建立 `univerAPI`。[`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) 會合並改動、保留未指定的欄位並重新整理選單。這些覆蓋同樣會應用到之後註冊的選單。

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'board.menu.duplicate-selection': { order: 5 },
})
```
