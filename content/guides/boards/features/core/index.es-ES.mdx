El núcleo de Univer Boards combina un modelo de páginas y elementos con un lienzo interactivo en el navegador. El modelo y la interfaz se distribuyen en dos paquetes de Univer SDK Pro y funcionan como una unidad `UNIVER_BOARD` independiente.

## Funciones

- **Páginas y orden de elementos**: almacena las páginas en `pages` y los objetos dibujables en `elements`, con matrices de orden explícitas en ambos niveles.
- **Elementos del lienzo**: trabaja con texto, formas, imágenes, conectores, grupos, contenedores y carriles.
- **Edición mediante comandos**: dirige los cambios, el orden y las relaciones padre-hijo por una capa de comandos con permisos y puntos de integración para el historial y la colaboración opcionales.
- **Lienzo del navegador**: renderiza elementos y ofrece selección, transformaciones, portapapeles, edición de texto, controles de vista y paneles.
- **Adaptadores extensibles**: añade funciones opcionales de Boards como tablas, mapas mentales, gráficos, recursos, impresión e intercambio.
- **Persistencia**: crea, restaura y guarda una instantánea `IBoardData` con páginas, recursos, temas y el estado de la página activa.

## Modo preset

Univer Boards no ofrece actualmente un preset específico. Usa el modo plugin tanto para el modelo como para la interfaz del navegador.

## Modo plugin

### Instalación

Añade los dos paquetes de Boards al entorno de Univer descrito en [Instalación y uso básico](/guides/boards/getting-started/installation):

```package-install
npm install @univerjs-pro/boards @univerjs-pro/boards-ui
```

### Registro de los plugins del producto

Registra primero las dependencias compartidas de renderizado, documentos, dibujo, tinta y edición de formas, además de la licencia Pro, como indica la guía de instalación; después registra los plugins de Boards:

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

import '@univerjs-pro/boards-ui/lib/index.css'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

`UniverBoardsPlugin` registra el modelo Board, los comandos, los servicios de elementos, los adaptadores y los permisos. `UniverBoardsUIPlugin` añade el lienzo renderizado y las interacciones del navegador.
