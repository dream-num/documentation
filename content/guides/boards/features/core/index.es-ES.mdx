El núcleo de las juntas Univer combina un modelo de página y elemento con un lienzo interactivo que funciona en el navegador. Dos paquetes Web SDK entregan el modelo y la interfaz de usuario, y juntos forman una unidad `UNIVER_BOARD` independiente.

## Funciones

- **Páginas y orden de elementos**: Las páginas se almacenan en `pages`, y los objetos dibujables se guardan en el `elements` de cada página; ambos niveles mantienen un array de orden explícito.
- **Elementos de las islas**: Los elementos pueden ser texto, formas, imágenes, conectores, grupos, contenedores y natación.
- **Edición impulsada por comandos**: Los cambios de Elemento, el orden y las relaciones entre padres e hijos pasan a través de una capa de comandos, que también lleva permisos y ganchos para la historia opcional e integraciones de colaboración.
- **Navegador de tela**: El lienzo hace elementos y proporciona selección, transforma, portapapeles, edición de texto, controles de visualización y paneles.
- **Adaptadores extensibles**: Las capacidades de la Junta como tablas, mapas mentales, gráficos, recursos, impresión e intercambio son opcionales y se integran como adaptadores.
- **Persistencia**: Una tabla puede ser creada, restaurada y guardada como una instantánea `IBoardData`, que incluye páginas, recursos, temas y estado de página activa.

## Modo plugin

### Instalación

Añada los dos paquetes de tableros al Univer con el tiempo de ejecución establecido en [Instalación &quot; Usage básico](/guides/boards/getting-started/installation):

```package-install
npm install @univerjs-pro/boards @univerjs-pro/boards-ui
```

### Registro de los plugins del producto

Registrar primero el renderizado compartido, documento, dibujo, tinta, configuración y dependencias de licencia, como se describe en la guía de instalación, luego registrar los plugins de las Juntas:

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

import '@univerjs-pro/boards-ui/lib/index.css'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

`UniverBoardsPlugin` registra el modelo de la Junta, comandos, servicios de elementos, adaptadores y permisos. `UniverBoardsUIPlugin` proporciona las interacciones de lona y navegador renderizado.

Los menús contextuales de las juntas utilizan el [`MenuConfig`](/reference/packages/plugins/univerjs/ui#menuconfig) compartido. Añadir `menu` al registro `UniverUIPlugin` existente en lugar de a `UniverBoardsUIPlugin`. El siguiente ejemplo mueve Duplicar al comienzo de su grupo context-menu:

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'board.menu.duplicate-selection': { order: -1 },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', menu })
```

`order` clasifica los elementos de contexto-menú de hermanos en orden ascendente y no mueve un elemento entre grupos. Utilice el ID del elemento del menú de la definición del menú del producto, que puede diferir del ID de comando.

#### Barra de herramientas del lienzo

Las tablas utilizan una barra de herramientas de tela dedicada y no registra un producto estándar Ribbon. `gridLayout` controla sólo la cinta de cuadrícula compartida; no reorganiza la barra de herramientas del lienzo o los menús contextuales. Las herramientas de cubo se configuran a través de `UniverBoardsUIPlugin.toolbar.tools`. El siguiente ejemplo desactiva la herramienta de la pluma en el registro de plugin existente:

```ts
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: { tools: { pen: false } },
})
```

`toolbar.tools` controla si una herramienta está disponible, no su colocación de pedidos o cuadrícula. Vea el [Juntas Referencia de la UI](/reference/packages/plugins/univerjs-pro/boards-ui) para la diferencia entre controles de tela y menús compartidos.

## Modo preset

Univer Boards no proporciona un preset dedicado en la actualidad. Utilice el modo plugin para el modelo y el navegador UI.

## Actualizar los menús con la API Facade [#menu-facade]

### Actualizaciones en ejecución

Importar `@univerjs/ui/facade` antes de crear `univerAPI` con `FUniver.newAPI(univer)`. [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) fusiona los cambios, conserva campos no especificados y refresca los menús. Los overrides también se aplican a los menús registrados más adelante.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'board.menu.duplicate-selection': { order: 5 },
})
```
