Univer 中可用的 Facade API 取決於當前單元型別和已註冊的外掛。本頁介紹其中 Univer Boards 應用常用的部分。

## 導入

```typescript
import { FUniver } from '@univerjs/core/facade'
import '@univerjs-pro/boards/facade'

const univerAPI = FUniver.newAPI(univer)
```

## 命令

Univer 中的大多數操作都註冊到命令系統。這條統一的執行路徑支援撤銷、重做和協同。

<Callout>
  設計思路見 [Univer 命令系統](/blog/univer#command-system)。
</Callout>

### 監聽命令

`Event.BeforeCommandExecute` 在命令執行前觸發，`Event.CommandExecuted` 在命令執行完成後觸發。

```typescript
const beforeDisposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, ({ id, params }) => {
  console.log('命令執行前：', id, params)
})

const afterDisposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id, params }) => {
  console.log('命令執行後：', id, params)
})
```

在 `BeforeCommandExecute` 監聽器中將 `event.cancel` 設為 `true`，可以阻止命令執行。

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.BeforeCommandExecute, (event) => {
  if (event.id === 'board.command.set-name') {
    event.cancel = true
  }
})
```

每個監聽器都會返回 `IDisposable`。不再需要該監聽器時，請銷燬返回值。

```typescript
beforeDisposable.dispose()
afterDisposable.dispose()
disposable.dispose()
```

### 執行命令

在已知命令 ID 和參數的情況下，透過 `FUniver.executeCommand` 執行命令。下面的 Boards 命令會重新命名當前 Board：

```typescript
const board = univerAPI.getActiveBoard()

if (board) {
  await univerAPI.executeCommand('board.command.set-name', {
    unitId: board.getId(),
    name: '專案筆記',
  })
}
```

## 事件 API

`univerAPI.Event` 中的事件名來自 Univer Core 和當前應用註冊的外掛。Core 提供通用的命令事件和單元事件，外掛可以在此基礎上繼續新增。使用某個事件之前，請確認提供該事件的外掛已經註冊。

當前版本的事件名稱和參數型別見 [Facade Events 參考](/reference/facade/events)。

使用 `addEvent` 訂閱事件；取消訂閱時銷燬返回的物件：

```typescript
const disposable = univerAPI.addEvent(univerAPI.Event.CommandExecuted, ({ id }) => {
  if (id === 'board.command.set-name') {
    console.log('Board名稱已變更')
  }
})

// 不再需要時移除監聽器
disposable.dispose()
```

## 復原和重做

```typescript
await univerAPI.undo()
await univerAPI.redo()
```

## WebSocket

如需使用 WebSocket API，請安裝 `@univerjs/network`、註冊 `UniverNetworkPlugin`，並匯入它的 Facade 擴充套件。

```typescript
import { UniverNetworkPlugin } from '@univerjs/network'
import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)
```

註冊後，Socket 支援訂閱事件、傳送訊息和關閉連線：

```typescript
const socket = univerAPI.createSocket('wss://example.com/boards')

socket.open$.subscribe(() => socket.send('hello'))
socket.message$.subscribe((message) => console.log('WebSocket 訊息：', message.data))
socket.error$.subscribe((error) => console.error('WebSocket 錯誤：', error))
socket.close()
```

## 列舉 API

通用列舉型別透過 `univerAPI.Enum` 提供：

```typescript
console.log(univerAPI.Enum.UniverInstanceType.UNIVER_BOARD)
console.log(univerAPI.Enum.BoardElementType.Shape)
```

## 工具方法 API

通用工具方法透過 `univerAPI.Util` 提供：

```typescript
console.log(univerAPI.Util.tools.isString('Univer Boards')) // true
```
