Ядро Univer Boards сочетает в себе модель страницы и элемента с интерактивным холстом, который работает в браузере.Два пакета Web SDK доставляют модель и пользовательский интерфейс, и вместе они образуют независимый блок `UNIVER_BOARD`.

## Возможности

- **Страницы и порядок элементов**: Страницы хранятся в `pages`, а рисуемые объекты хранятся в `elements` каждой страницы; оба уровня поддерживают явный массив заказов.
- **Канвасные элементы**: Элементы могут быть текстом, формами, изображениями, разъемами, группами, контейнерами и плавающими плавниками.
- **Редактирование на командной основе**: изменения элементов, порядок и отношения между родителями и детьми проходят через один командный уровень, который также содержит разрешения и крючки для дополнительной истории и интеграции совместной работы.
- **Полотно для браузера**: холст отображает элементы и обеспечивает выбор, преобразования, буфер обмена, редактирование текста, элементы управления портом просмотра и панели.
- **Расширяемые адаптеры**: Возможности платы, такие как таблицы, карты памяти, диаграммы, ресурсы, печать и обмен, являются дополнительными и интегрированы в качестве адаптеров.
- **настойчивость**: Доска может быть создана, восстановлена и сохранена как снимок `IBoardData`, который включает в себя страницы, ресурсы, темы и состояние активной страницы.

## Режим плагинов

### Установка

Добавьте два пакета плат в время выполнения Univer, установленное в [Установка и базовое использование](/guides/boards/getting-started/installation):

```package-install
npm install @univerjs-pro/boards @univerjs-pro/boards-ui
```

### Регистрация плагинов продукта

Сначала зарегистрируйте общий рендер, документ, чертеж, чернила, редактирование формы и зависимости от лицензии, как описано в руководстве по установке, а затем зарегистраируйте плагины Boards:

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

import '@univerjs-pro/boards-ui/lib/index.css'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

`UniverBoardsPlugin` регистрирует модель платы, команды, службы элементов, адаптеры и разрешения. `UniverBoardsUIPlugin` обеспечивает визуализируемое полотно и взаимодействие с браузером.

Контекстные меню досок используют совместно используемый [`MenuConfig`](/reference/packages/plugins/univerjs/ui#menuconfig). Добавьте `menu` к существующей регистрации `UniverUIPlugin`, а не к `UniverBoardsUIPlugin`

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'board.menu.duplicate-selection': { order: -1 },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', menu })
```

`order` сортирует сиблинговые контекстно-меню элементы в порядке возрастания и не перемещает элемент между группами. Используйте идентификатор пункта меню из определения меню продукта, который может отличаться от идентификатора команды.

#### Панель инструментов холста

Платы используют выделенную панель инструментов холста и не регистрируют стандартный продукт Ribbon. `gridLayout` управляет только общей сеткой Ribbon; он не перестраивает панель инструментов холстов или контекстные меню. Инструменты холста настраиваются через `UniverBoardsUIPlugin.toolbar.tools`. Следующий пример отключает инструмент пера в существующей регистрации плагина:

```ts
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: { tools: { pen: false } },
})
```

`toolbar.tools` контролирует, доступен ли инструмент, а не его порядок или расположение сетки. См. [Советы UI Ссылки](/reference/packages/plugins/univerjs-pro/boards-ui) для разницы между элементами управления холстом и общими меню.

## Режим Preset

Платы Univer в настоящее время не предоставляют выделенного предустановленного режима. Используйте режим плагина как для модели, так и для пользовательского интерфейса браузера.

## Обновление меню через Facade API [#menu-facade]

### Обновление во время работы

Импорт `@univerjs/ui/facade` перед созданием `univerAPI` с `FUniver.newAPI(univer)`. [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) объединяет изменения, сохраняет неуточненные поля и обновляет меню. Переопределения также применяются к меню, зарегистрированным позже.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'board.menu.duplicate-selection': { order: 5 },
})
```
