Univer ボードは、ページアンドエレメントモデルと、ブラウザで実行するインタラクティブなキャンバスを組み合わせています。2つの Web SDK パッケージはモデルと UI を配信し、それぞれ独立した `UNIVER_BOARD`ユニットを形成します。

## 機能

- **ページと要素の注文**:ページは`pages`に保存され、描画可能なオブジェクトは各ページの`elements`に格納されます。両方のレベルは、明示的な注文配列を維持します。
- **キャンバス要素**:要素はテキスト、形状、画像、コネクタ、グループ、コンテナ、およびスイムレーンであることができます。
- **コマンド主導の編集**:要素の変更、注文、親子関係は、すべての1つのコマンドレイヤーを通過し、権限とホックをオプションの履歴とコラボレーション統合のために運ぶ。
- **ブラウザ キャンバス**: キャンバスは要素をレンダリングし、選択、変圧器、クリップボード、テキスト編集、ビューポート制御、パネルを提供します。
- **拡張可能なアダプター**:テーブル、マインドマップ、チャート、リソース、プリント、交換などのボード機能がオプションで、アダプターとして統合されています。
- **パージストエンス**: ボードは、ページ、リソース、テーマ、アクティブページの状態を含む`IBoardData`スナップショットとして作成、復元、保存することができます。

## プラグインモード

### インストール

[インストールと基本的な使い方](/guides/boards/getting-started/installation) で設定された Univer ランタイムに 2 つのボードのパッケージを追加します。

```package-install
npm install @univerjs-pro/boards @univerjs-pro/boards-ui
```

### 製品プラグインの登録

インストールガイドに記載されているように、共有レンダー、ドキュメント、図面、インク、形状編集、およびライセンスの依存関係を最初に登録し、ボードのプラグインを登録します。

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

import '@univerjs-pro/boards-ui/lib/index.css'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

`UniverBoardsPlugin`は、ボードモデル、コマンド、要素サービス、アダプター、およびパーミッションを登録します。`UniverBoardsUIPlugin` は、レンダリングされたキャンバスとブラウザのインタラクションを提供します。

ボードのコンテキストメニューは、共有[`MenuConfig`](/reference/packages/plugins/univerjs/ui#menuconfig)を使用します。 `menu`を既存の`UniverUIPlugin`登録に`UniverBoardsUIPlugin`に追加します。 次の例は、コンテキストメニューグループの先頭に重複移動します。

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'board.menu.duplicate-selection': { order: -1 },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', menu })
```

`order` は、昇順のコンテキストメニュー項目を並べ替え、グループ間で項目を移動しません。メニュー項目 ID を製品メニューの定義から使用し、コマンド ID とは異なる場合があります。

#### キャンバスツールバー

ボードは専用のキャンバスツールバーを使用し、標準的な製品リボンを登録していません。 `gridLayout`は共有グリッドリボンのみを制御します。キャンバスツールバーやコンテクストメニューを並べ替えることはありません。 キャンバスツールは`UniverBoardsUIPlugin.toolbar.tools`を介して構成されています。 次の例では、既存のプラグイン登録でペンツールを無効にします。

```ts
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: { tools: { pen: false } },
})
```

`toolbar.tools`は、ツールが利用可能かどうか、その注文やグリッド配置を制御します。 キャンバスコントロールと共有メニューの違いについては、[ボード UI リファレンス](/reference/packages/plugins/univerjs-pro/boards-ui)を参照してください。

## プリセットモード

Univerボードは、現在専用のプリセットを提供していません。 プラグインモードを使用して、モデルとブラウザUIの両方を使用できます。

## Facade API でメニューを更新する [#menu-facade]

### 実行時の更新

`univerAPI`を`FUniver.newAPI(univer)`で作成する前に`@univerjs/ui/facade`を読み込む。[`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig)は変更をマージし、不特定フィールドを保存し、メニューをリフレッシュします。オーバーライドは、後で登録されたメニューにも適用されます。

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'board.menu.duplicate-selection': { order: 5 },
})
```
