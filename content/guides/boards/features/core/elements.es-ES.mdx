---
title: Elementos
---

Los elementos son el contenido visible de un tablero: texto, imágenes, formas y conectores. Los cambios realizados a través de la fachada `FBoard` siguen el camino normal del comando, así que deshacer, redo y colaboración se aplican a ellos también.

## Leer elementos

Obtenga la tabla activa antes de leer su página activa. Cuando sólo se requieren IDs estables, tipos, límites y pedidos, use descriptores en lugar de depender de la instantánea interna completa.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active board')

const elements = board.describeElements()
const shapes = board.findElements({
  elementType: univerAPI.Enum.BoardElementType.Shape,
})
```

## Insertar formas y texto

Utilice los métodos de inserción semánticos en lugar de construir instantáneas de elementos de bajo nivel. Para `insertShape`, `transform` lleva la geometría, y el mango de forma en vivo devuelto expone el texto y API de estilo.

```ts
const shape = board.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.RoundRect,
  transform: { left: 80, top: 80, width: 180, height: 100 },
  name: 'Review card',
})
if (!shape) throw new Error('Cannot insert shape')

shape.getText().setText('Review')
shape.setRotation(6)
```

`insertText` añade texto independiente, y `insertImage` agrega imágenes. Cuando se deben añadir varios elementos con un comando, utilice las variantes de lote.

## Editar el texto de una forma

Utilice la forma devuelta por `insertShape()` en el ejemplo a continuación, o la forma obtenida en la sección anterior. `getText()` devuelve un mango [FShapeText](/reference/facade/shape-text) vivo. Llame a `getPlainText()` para leer el texto, `setText()` a reemplazar todo, y la fuente, color y los métodos de alineación para formatearlo.

```ts
if (!shape) throw new Error('Shape is not available')
const shapeText = shape.getText()
console.log(shapeText.getPlainText())
shapeText
  .setText('Quarterly review')
  .setFontSize(18)
  .setColor('#2563eb')
  .setBold(true)
  .setHorizontalAlign(univerAPI.Enum.HorizontalAlign.CENTER)
  .setVerticalAlign(univerAPI.Enum.VerticalAlign.MIDDLE)
```

`setText()` reemplaza el texto existente. Utilice `setRichText()` cuando una forma única requiere varios estilos. Para modificar el texto rico existente, llame a `getRichText()?.copy()`, edite el constructor y pasar a `setRichText()`. Los cambios a ese constructor separado no se aplican automáticamente. [Estilo de texto](/reference/facade/shape-text#settextstyle) y [texto caja de relleno y diseño](/reference/facade/shape-text#settextboxoptions) describen otras opciones.

```ts
const richText = univerAPI.newRichText()
  .text('Quarterly ')
  .bold('review')
shapeText.setRichText(richText)
```

## Conectar elementos

Un conector puede conectarse a los IDs de elementos existentes. Mantenga el conector devuelto o su ID cuando su estilo, etiqueta o puntos finales se van a cambiar más adelante.

```ts
const target = board.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.Rect,
  transform: { left: 360, top: 80, width: 180, height: 100 },
})
if (!target) throw new Error('Cannot insert target')

const connector = board.insertConnector({
  fromElementId: shape.getId(),
  toElementId: target.getId(),
  style: { endMarker: { type: 'filledTriangle', size: 'md' } },
})
if (!connector) throw new Error('Cannot insert connector')
```

## Transformar y organizar elementos

Pase sólo las propiedades que deben cambiar. Los métodos de orden, alineación, distribución y diseño automático también aceptan IDs de elementos.

```ts
if (!board.setElementTransform(shape.getId(), { left: 120, top: 140, rotation: 12 })) {
  throw new Error('Cannot transform shape')
}

if (!board.bringElementsToFront([shape.getId()])) {
  throw new Error('Cannot bring shape to front')
}
```

## Eliminar elementos

`removeElement` elimina un solo elemento, y `removeElements` quita un lote atómico. Ambos devuelven si el comando tuvo éxito.

```ts
if (!board.removeElements([connector.id, target.getId()])) {
  throw new Error('Cannot remove elements')
}
```
