title: История изменений

Изменив положение элементов, текст или соединительные линии, откройте историю, чтобы просмотреть предыдущие версии, сравнить изменения и при наличии прав восстановить версию. История читает версии, сохранённые на сервере. Отмена и повтор действуют в текущем сеансе редактирования и не требуют сервиса истории.

## Подготовка сервисов совместного редактирования и истории

Выполните [интеграцию совместного редактирования](/server/collaboration/browser-integration) и [настройку лицензии](/server/license). Убедитесь, что два сеанса могут редактировать один документ Boards и что изменения сохраняются после перезагрузки.

Следуйте разделу [Расширения совместного редактирования Office](/server/collaboration/extensions) и [примеру истории](/server/collaboration/examples#history), чтобы подключить хранение истории и права доступа. Базовое совместное редактирование не включает историю автоматически. Сервер также должен поддерживать список версий, их содержимое и восстановление.

## Добавление плагинов истории

Добавьте следующую настройку к существующей конфигурации продукта, лицензии и совместного редактирования. Если пресет или другая конфигурация уже регистрирует эти плагины, измените её, а не регистрируйте плагины повторно.

```package-install
npm install @univerjs-pro/edit-history @univerjs-pro/edit-history-ui @univerjs-pro/boards-history @univerjs-pro/boards-history-ui
```

```ts
import { UniverEditHistoryPlugin } from '@univerjs-pro/edit-history'
import EditHistoryLocale from '@univerjs-pro/edit-history-ui/locale/en-US'
import { UniverBoardsHistoryPlugin } from '@univerjs-pro/boards-history'
import { UniverBoardsHistoryUIPlugin } from '@univerjs-pro/boards-history-ui'
import HistoryLocale from '@univerjs-pro/boards-history-ui/locale/en-US'
import { LocaleType, mergeLocales } from '@univerjs/core'

import '@univerjs-pro/edit-history-ui/lib/index.css'
import '@univerjs-pro/boards-history-ui/lib/index.css'

const historyServerUrl = '/api/history'

univerAPI.loadLocales(LocaleType.EN_US, mergeLocales(EditHistoryLocale, HistoryLocale))
univer.registerPlugin(UniverEditHistoryPlugin, { historyServerUrl })
univer.registerPlugin(UniverBoardsHistoryPlugin)
univer.registerPlugin(UniverBoardsHistoryUIPlugin, {
  univerContainerId: 'app',
  historyServerUrl,
})
```

Замените `/api/history` адресом API истории вашего приложения и убедитесь, что API соответствует запросам клиента. Оба значения `historyServerUrl` должны совпадать. В `univerContainerId` укажите DOM ID контейнера редактора и загрузите языковой пакет, соответствующий языку редактора.

Просмотрщик истории создаёт отдельный редактор только для чтения. Для собственного контента используйте `viewerPlugins`, чтобы добавить плагины, которые ещё не входят в просмотрщик. Не регистрируйте встроенные плагины просмотрщика повторно.

## Просмотр и восстановление версий

Откройте историю из меню редактора и выберите версию, чтобы просмотреть её содержимое и изменения. Восстановление изменяет текущий общий документ. Эта операция должна быть доступна только пользователям с правом восстановления, и сервер обязан проверять это право.

Для проверки интеграции измените положение элементов, текст или соединительные линии, дождитесь подтверждения совместного редактирования и проверьте список версий и их содержимое. Повторно откройте приложение и перезапустите сервис, чтобы проверить сохранность данных. Восстановите предыдущую версию и убедитесь, что другой сеанс браузера получил восстановленное состояние.

Если список пуст, проверьте, записывалась ли история документа, затем проверьте ID документа и URL сервиса. Если просмотр работает, а восстановление нет, проверьте право восстановления и соединение совместного редактирования. Чтение истории тоже требует авторизации: старые версии могут содержать данные, которые позднее были удалены.
