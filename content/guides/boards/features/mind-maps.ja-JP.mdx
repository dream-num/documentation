Board のマインドマップ機能は任意です。Board キャンバス内でマインドマップのノードや操作が必要な場合に追加してください。

## マインドマップ機能の登録

```ts
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import BoardsMindUIEnUS from '@univerjs-pro/boards-mind-ui/locale/en-US'

import '@univerjs-pro/boards-mind-ui/lib/index.css'

univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## 各パッケージの役割

- `@univerjs-pro/boards-mind` は、マインドマップ要素を Board モデルに統合します。
- `@univerjs-pro/boards-mind-ui` は、マインドマップの編集、レンダリング、UI 操作を追加します。また、ブラウザーエディター向けに `@univerjs-pro/boards-mind-ui/locale/*` と `@univerjs-pro/boards-mind-ui/lib/index.css` も提供します。

## ランタイムの選択

ブラウザーエディターでは両方のパッケージを使用します。サーバー側でスナップショットを処理する場合は、モデルパッケージを `UniverBoardsPlugin` とともに登録し、UI パッケージは登録しないでください。

マインドマップ要素を含むスナップショットを開く前に、マインドマップ機能を登録してください。
