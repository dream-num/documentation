ボードマインドマップのサポートはオプションです。ボードキャンバス内のマインドマップノードやインタラクションが必要な場合は、追加してください。

## マインドマップ機能の登録

```ts
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import BoardsMindUIJaJP from '@univerjs-pro/boards-mind-ui/locale/ja-JP'
import '@univerjs-pro/boards-mind/facade'
import '@univerjs-pro/boards-mind-ui/lib/index.css'

univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/boards/getting-started/installation#mobile-support)を最初に構成します。 このページに記載されているプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換えて、**ドキュメントを開く前に**を実行します。 モデルプラグイン、スタイル、ロケール、ファサードのインポートを保存し、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/boards-mind-ui` | `UniverBoardsMindUIPlugin` | `UniverBoardsMindMobileUIPlugin` |

## 各パッケージの役割

- `@univerjs-pro/boards-mind` は、マインドマップ要素を Board モデルに統合します。
- `@univerjs-pro/boards-mind-ui`は、マインドマップレンダリング、編集、UIインタラクションを追加します。 また、`@univerjs-pro/boards-mind-ui/locale/*`ローカルファイルとブラウザエディタが必要とする`@univerjs-pro/boards-mind-ui/lib/index.css`スタイルシートを提供します。

## ランタイムの選択

ブラウザエディタはパッケージを両方必要とします。サーバー側のスナップショット処理では、モデルパッケージを`UniverBoardsPlugin`に登録し、UIパッケージを省略します。

マインドマップの要素を含むスナップショットを開く前にマインドマップのサポートを登録します。

## Facade API

構造化されたファサードを使用して、基礎ボードの形状やコネクターを個別に編集するのではなく、構造化したファサードを使用してください。

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const mindMap = board.insertMindMap({
  left: 180,
  top: 180,
  root: {
    text: 'Release',
    children: [
      { text: 'Product', children: [{ text: 'Scope' }, { text: 'UX' }] },
      { text: 'Engineering', children: [{ text: 'API' }, { text: 'QA' }] },
      { text: 'Launch', children: [{ text: 'Docs' }] },
    ],
  },
})
if (!mindMap) throw new Error('Cannot insert mind map')

const qa = mindMap.getNodes().find(node => node.getText() === 'QA')
qa?.addChild({ text: 'Automation' })
```

`FBoard` オファー `insertMindMap`, `getMindMap`, と `getMindMaps`. `FBoardMindMap` ノードのルックアップ、子孫、レイアウト、境界、 `reflow`, `setLayout`, `setBranchLineType`, と `remove`. Nodeはサポートテキスト、子供および兄弟のインサート、reparenting、昇進、除去、命令、スタイリングおよび崩壊の状態を扱います。

## 指定領域への再配置

`reflow()` 原子は、ボード座標で指定された矩形内のマインドマップをレイアウトし、センタリングします。 これは、ノードとテキストサイズを保存します。 デフォルトでは、最小限のサポートされているギャップでコールレトリーを呼び出します。 レイアウトがまだ適合していないか、読み残らない場合は、ボードは変更されず、コールは `requiredBounds`で`reason: 'bounds-too-small'`を返します。

```ts
const result = mindMap.reflow({
  bounds: { left: 80, top: 80, width: 1_000, height: 600 },
  padding: 24,
})

if (!result.success) {
  console.warn(result.reason, result.requiredBounds)
}
```

対象となる矩形は、マインドマップが配置される場所だけを決定します。リフローは、マインドマッピングコンテナを再生したり、サイズ変更したりし、成功したリフローは単一のundoアイテムになります。
