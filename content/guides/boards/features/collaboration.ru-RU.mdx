С поддержкой совместной работы несколько пользователей могут редактировать одну и ту же плату и видеть изменения друг друга. Следуйте за [Интеграция сотрудничества](/server/collaboration/browser-integration), чтобы настроить бэкэнд, аутентификацию, разрешения и хранилище, а затем настроить [лицензия](/server/license).

## Настройка и загрузка документа

Используйте [Сотрудничество Quick Start](/server/collaboration/quick-start), чтобы добавить конфигурацию клиента совместной работы в существующий редактор Boards. В этом примере используются листы, поэтому бэкэнд должен по-прежнему создавать и сохранять документ Boards и возвращать его идентификатор в браузер.

Установите текущего пользователя перед загрузкой документа. [Интеграция сотрудничества](/server/collaboration/browser-integration) описывает процедуру.

```ts
import '@univerjs-pro/boards/facade'
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const document = await univerAPI.getCollaboration().loadBoardAsync('your-document-id')
if (!document) throw new Error('Document could not be loaded')
```

При повторном открытии или совместном использовании документа используется один и тот же идентификатор.Не создавайте локальный пустой документ вместо серверного документа.

Для сохранения показателей и защиты правок, которые сервер еще не признал до перезагрузки, см. [Статус синхронизации, повторы и восстановление конфликта](/server/collaboration/browser-integration#sync-status).

## Удаление встроенной загрузки совместных документов по URL [#url-unit-loader-migration]

<Callout type="warning" title="Замечание">
  Начиная с версии **1.2.0**, Univer больше не загружает совместные документы с URL. Он больше не считывает параметры URL `unit` и `type` автоматически.
</Callout>

Если приложение зависит от этого поведения, пользовательский плагин может восстановить его.

### Подключение собственного плагина

Скопируйте четыре файла ниже в проект и сохраните следующую структуру каталога:

```text
custom-url-load/
├── plugin.ts
├── controllers/
│   └── data-loader.controller.ts
└── services/
    ├── url.service.ts
    └── web-url.service.ts
```

Инициализируйте редактор и плагины для совместной работы, установите текущего пользователя, а затем зарегистрируйте `CustomUrlLoadPlugin`.

```ts
import { UserManagerService } from '@univerjs/core'
import { CustomUrlLoadPlugin } from './custom-url-load/plugin'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

univer.registerPlugin(CustomUrlLoadPlugin)
```

После регистрации плагин обрабатывает загрузку, поэтому `loadBoardAsync()` не требуется для одного и того же документа.Если приложение уже загружает документы через Facade, сохраните подход из предыдущего раздела и обработайте URL-адреса в соответствии с требованиями приложения.

    ```ts
    import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
    import { CollaborationDataLoaderController } from './controllers/data-loader.controller'
    import { IURLService } from './services/url.service'
    import { WebURLService } from './services/web-url.service'

    @DependentOn(UniverCollaborationClientPlugin)
    export class CustomUrlLoadPlugin extends Plugin {
      static override pluginName = 'CUSTOM_URL_LOAD_PLUGIN'

      constructor(
        _config: undefined,
        @Inject(Injector) protected override readonly _injector: Injector
      ) {
        super()
      }

      override onStarting(): void {
        this._injector.add([IURLService, { useClass: WebURLService }])
        this._injector.add([CollaborationDataLoaderController])

        this.disposeWithMe(this._injector.get(IURLService))
        this.disposeWithMe(this._injector.get(CollaborationDataLoaderController))
      }
    }
    ```

    ```ts
    import { DataLoaderService } from '@univerjs-pro/collaboration-client'
    import { ILogService, Inject, RxDisposable } from '@univerjs/core'
    import { IURLService } from '../services/url.service'

    /**
     * Загружает совместный документ по параметрам URL.
     */
    export class CollaborationDataLoaderController extends RxDisposable {
      constructor(
        @IURLService private readonly _urlService: IURLService,
        @ILogService private readonly _logService: ILogService,
        @Inject(DataLoaderService) private readonly _dataLoaderService: DataLoaderService
      ) {
        super()

        const unitId = this._urlService.getParam('unit')
        const type = this._urlService.getParam('type')
        if (!unitId || !type) {
          return
        }

        this._dataLoaderService.loadUnit(unitId, Number(type))
          .catch((error: unknown) => {
            this._logService.error('[CollaborationDataLoaderController]', error)
          })
      }
    }
    ```

    ```ts
    import type { IURLService } from './url.service'
    import { RxDisposable } from '@univerjs/core'
    import { fromEvent, map, shareReplay, takeUntil } from 'rxjs'

    export class WebURLService extends RxDisposable implements IURLService {
      readonly urlChange$ = fromEvent(window, 'popstate').pipe(
        map(() => undefined),
        takeUntil(this.dispose$),
        shareReplay({ bufferSize: 1, refCount: true })
      )

      getParam(key: string): string | undefined {
        return new URL(window.location.href).searchParams.get(key) ?? undefined
      }

      setParam(key: string, value: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.set(key, value)
        this._updateUrl(url, useReplace)
      }

      removeParam(key: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.delete(key)
        this._updateUrl(url, useReplace)
      }

      private _updateUrl(url: URL, useReplace: boolean): void {
        if (useReplace) {
          window.history.replaceState(window.history.state, '', url.toString())
        } else {
          window.history.pushState(window.history.state, '', url.toString())
        }
      }
    }
    ```

## Проверка синхронизации и прав доступа

Откройте один и тот же идентификатор в двух отдельных сеансах браузера. Отредактируйте текст или переместите элемент в одном сеансе, затем проверьте другой. Подтвердите, что контент выживает при перезагрузке страниц, переподключении и перезапуске службы. Используйте просмотрщик и несанкционированные учетные записи, чтобы подтвердить, что сервер отклоняет записи и читает, что их разрешения запрещают.

Сотрудничество не позволяет использовать [Редактировать историю](/guides/boards/features/edit-history) или [Импорт и экспорт](/guides/boards/features/import-export); каждая из них требует отдельной конфигурации.
