Несколько пользователей могут редактировать одну доску и видеть изменения друг друга. Выполните [интеграцию совместного редактирования](/server/collaboration/browser-integration), подключив серверную часть, аутентификацию, права доступа и хранилище, затем настройте [лицензию](/server/license).

## Настройка и загрузка документа

Добавьте настройки клиента Collaboration в существующий редактор Boards по инструкции [Быстрый старт Office](/server/collaboration/quick-start). Пример использует Sheets; ваш сервер должен создать и сохранить документ Boards, а затем вернуть его ID браузеру.

```ts
import '@univerjs-pro/boards/facade'
import '@univerjs-pro/collaboration-client/facade'

const document = await univerAPI.getCollaboration().loadBoardAsync('your-document-id')
if (!document) throw new Error('Document could not be loaded')
```

При повторном открытии или публикации ссылки на документ используйте тот же ID. Не заменяйте загрузку серверного документа созданием пустого локального документа.

## Проверка синхронизации и прав доступа

Откройте один ID в двух независимых сеансах браузера. Измените текст или переместите элемент в одном сеансе и проверьте второй. Убедитесь, что содержимое сохраняется после перезагрузки страницы, повторного подключения и перезапуска сервиса. С помощью учётных записей читателя и пользователя без доступа проверьте, что сервер отклоняет запрещённые операции чтения и записи.

[История изменений](/guides/boards/features/edit-history) и [импорт и экспорт](/guides/boards/features/import-export) требуют отдельной настройки: совместное редактирование не включает их автоматически.
