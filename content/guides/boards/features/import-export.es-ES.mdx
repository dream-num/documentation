Los tableros pueden participar en flujos de trabajo de importación/exportación Pro a través de adaptadores de importación y exportación de tableros. Los formatos de archivo exactos dependen de los servicios Pro Exchange registrados en su aplicación.

## Registre primero el tiempo de ejecución de Board

```ts
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsExchangeClientPlugin)
```

Registre complementos de elementos opcionales antes de importar datos que puedan contener esos elementos:

```ts
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## Transferencia de instantáneas

Para persistencia a nivel de aplicación, guarde y restaure la instantánea de Board:

```ts
const board = univerAPI.getActiveBoard()
const snapshot = board.getData()

univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)
```

## Intercambio interactivo

`@univerjs-pro/boards-exchange-client` registra los adaptadores de importación y exportación. Abra el flujo configurado mediante los métodos Facade.

```ts
if (!board.beginImport()) throw new Error('Cannot open Board import')

// Export UI supports registered targets such as image or PDF.
if (!board.beginExport('image')) throw new Error('Cannot open Board export')
```

Para conocer los requisitos de licencia e implementación, consulte [Univer Pro](/guides/pro).

## Exportación Facade e importación Mermaid

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/boards-exchange-client/facade'

const file = await univerAPI.exportBoardByUnitIdAsync(board.getId())
if (file) univerAPI.downloadFile(file, 'board', 'pptx')
await board.insertMermaidAsync('flowchart LR\n  A[Borrador] --> B[Revisión]')
```
