製品エディタとライセンス設定が完了した後にコメントプラグインを登録し、共有された製品 UI スタイルを locale リソースとともに読み込みます。製品プラグインはコメントリソースを所有しているため、スナップショットが復元される前に登録する必要があります。

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs-pro/boards-thread-comment @univerjs-pro/boards-thread-comment-ui
```

```ts
import { UniverBoardsThreadCommentPlugin } from '@univerjs-pro/boards-thread-comment'
import { UniverBoardsThreadCommentUIPlugin } from '@univerjs-pro/boards-thread-comment-ui'
import ProductLocale from '@univerjs-pro/boards-thread-comment-ui/locale/ja-JP'
import { LocaleType, mergeLocales } from '@univerjs/core'
import SharedLocale from '@univerjs/thread-comment-ui/locale/ja-JP'

import '@univerjs/thread-comment-ui/lib/index.css'
import '@univerjs-pro/boards-thread-comment-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.JA_JP, mergeLocales(SharedLocale, ProductLocale))
univer.registerPlugin(UniverBoardsThreadCommentPlugin)
univer.registerPlugin(UniverBoardsThreadCommentUIPlugin)
```

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/boards/getting-started/installation#mobile-support)を最初に構成します。 このページに記載されているプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換えて、**ドキュメントを開く前に**を実行します。 モデルプラグイン、スタイル、ロケール、ファサードのインポートを保存し、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/boards-thread-comment-ui` | `UniverBoardsThreadCommentUIPlugin` | `UniverBoardsThreadCommentMobileUIPlugin` |

## コメント Facade [#comment-facade]

これらのメソッドが呼び出される前に、共有コメントファサードと製品ファサードをインポートします。 製品のヘルパーは安定したアンカーを作成し、共有された API は、応答、更新、解像度、削除を処理します。 `getComments()` は、ローカルの状態を読み取ります。 `listCommentsAsync()`は、設定されたデータソースを通してすでに知っているスレッドを同期させます。 サーバ上のすべてのスレッドを発見しません。

```ts
import '@univerjs/thread-comment/facade'
import '@univerjs-pro/boards-thread-comment/facade'

const board = univerAPI.getActiveBoard()
if (board) {
  await board.createPositionCommentAsync({ x: 320, y: 180 }, 'Review this area.')
  console.log(await board.listCommentsAsync())
}
```

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## 共有ディスカッション [#shared-discussions]

共有された議論のために、コメントサービスとエンドポイントを[Server SDK](/server/collaboration/extensions)から統合し、コラボレーションとライセンス設定が完了した後、`@univerjs-pro/thread-comment-datasource`からの`UniverThreadCommentDataSourcePlugin`を登録します。 提供されたデータソースは`/universer-api/comment/unit/{unitId}/...`と`/universer-api/user/list`を呼び出します。 したがって、アプリケーションはこれらのルートを明示しなければなりません。 コメントは、独自のサーバー権限を必要とする書き込み; ドキュメント編集権限はそれらをカバーしません。
