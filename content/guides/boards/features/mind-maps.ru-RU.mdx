Поддержка карты памяти совета является необязательной. Добавьте ее, когда продукт нуждается в узлах карты памяти и взаимодействиях внутри холста совета.

## Регистрация поддержки интеллект-карт

```ts
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import BoardsMindUIRuRU from '@univerjs-pro/boards-mind-ui/locale/ru-RU'
import '@univerjs-pro/boards-mind/facade'
import '@univerjs-pro/boards-mind-ui/lib/index.css'

univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## Поддержка мобильных устройств [#mobile-support]

Сначала настройте [Мобильный редактор](/guides/boards/getting-started/installation#mobile-support). В настройках плагин-режима, описанных на этой странице, замените регистрацию рабочего стола ниже на мобильный экспорт из тех же пакетов и сделайте это **Перед тем, как открыть документ**, сохраните плагины модели, стили, локализации и импорт Facade и не регистрируйте оба варианта.

| Пакет | Настольная регистрация | Мобильная регистрация |
| --- | --- | --- |
| `@univerjs-pro/boards-mind-ui` | `UniverBoardsMindUIPlugin` | `UniverBoardsMindMobileUIPlugin` |

## Назначение пакетов

- `@univerjs-pro/boards-mind` интегрирует элементы интеллект-карт с моделью Board.
- `@univerjs-pro/boards-mind-ui` добавляет рендеринг, редактирование и взаимодействие с пользовательским интерфейсом. Он также предоставляет файлы `@univerjs-pro/boards-mind-ui/locale/*` и таблицу стилей `@univerjs-pro/boards-mind-ui/lib/index.css`, которые требуются редакторам браузера.

## Выбор пакетов для среды выполнения

Редактор браузера требует оба пакета. Для обработки снимков на стороне сервера зарегистрируйте пакет модели с `UniverBoardsPlugin` и опустите пакеты пользовательского интерфейса.

Зарегистрируйте поддержку карты разума перед открытием снимка, который содержит элементы карты разума.

## Facade API

Используйте структурированный Фасад, а не редактирование базовых форм платы и разъемов индивидуально.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const mindMap = board.insertMindMap({
  left: 180,
  top: 180,
  root: {
    text: 'Release',
    children: [
      { text: 'Product', children: [{ text: 'Scope' }, { text: 'UX' }] },
      { text: 'Engineering', children: [{ text: 'API' }, { text: 'QA' }] },
      { text: 'Launch', children: [{ text: 'Docs' }] },
    ],
  },
})
if (!mindMap) throw new Error('Cannot insert mind map')

const qa = mindMap.getNodes().find(node => node.getText() === 'QA')
qa?.addChild({ text: 'Automation' })
```

`FBoard` предоставляет `insertMindMap`, `getMindMap` и `getMindMaps`. `FBoardMindMap` обеспечивает поиск узлов, потомков, компоновку, границы, `reflow` , `setLayout` `setBranchLineType` and `remove` Узел обрабатывает текст поддержки, вставку ребенка и брата, репарацию, продвижение, отсоединение, заказ, стиль и состояние коллапса.

## Размещение в заданных границах

`reflow()` атомарно выкладывает и центрирует карту разума внутри прямоугольника, указанного в координатах платы. Он сохраняет узел и размеры текста. По умолчанию повторы вызовов с наименьшими поддерживаемыми промежутками. Если макет по-прежнему не подходит или остается читаемым, плата остается неизменной, а вызов возвращает `reason: 'bounds-too-small'` с `requiredBounds`.

```ts
const result = mindMap.reflow({
  bounds: { left: 80, top: 80, width: 1_000, height: 600 },
  padding: 24,
})

if (!result.success) {
  console.warn(result.reason, result.requiredBounds)
}
```

Прямоугольник мишени определяет только место, где размещена карта разума.Рефлекс не восстанавливает, не обрезает и не изменяет размер контейнера карты разума, а успешный рефлектор становится единым пунктом отмены.
