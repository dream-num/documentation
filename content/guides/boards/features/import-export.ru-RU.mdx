`@univerjs-pro/boards-exchange-client` поддерживает импорт исходного текста Mermaid и экспорт файлов PPTX.

## Поддерживаемые форматы

В таблице описаны API-интерфейсы браузера на этой странице. Для преобразования файлов Office также требуется бэкэнд, поддерживающий соответствующий тип и формат документа.

| Импорт | Экспорт |
| --- | --- |
| Исходный текст Mermaid | `.pptx` |

Импорт Mermaid вставляет исходный текст в качестве элементов платы через `insertMermaidAsync`; он не является импортером файлов Office. Экспортные API-интерфейсы производят `.pptx` и требуют конверсионного бэкэнда. Они не обеспечивают импорт PPTX или экспорт изображений и PDF. Дополнительные цели экспорта, зарегистрированные хост-приложением, являются отдельными возможностями.

## Сначала зарегистрируйте среду выполнения досок

```ts
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsExchangeClientPlugin)
```

Перед импортом данных, которые могут содержать дополнительные типы элементов, зарегистрируйте соответствующие плагины:

```ts
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## Передача снимка

Чтобы сохранять данные на уровне приложения, сохраняйте и восстанавливайте снимок доски:

```ts
const board = univerAPI.getActiveBoard()
const snapshot = board.getData()

univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)
```

## Экспорт Facade и импорт Mermaid

`@univerjs-pro/boards-exchange-client` регистрирует экспортные и импортные API-интерфейсы Mermaid.

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/boards-exchange-client/facade'

const file = await univerAPI.exportBoardByUnitIdAsync(board.getId())
if (file) univerAPI.downloadFile(file, 'board', 'pptx')
await board.insertMermaidAsync('flowchart LR\n  A[Черновик] --> B[Проверка]')
```

Используйте `exportBoardBySnapshotAsync(snapshot)` для данных, которые не прикреплены к живой плате. `transformSnapshotJsonToBoardDataAsync` и `transformBoardDataToSnapshotJsonAsync` преобразуют блоки моментального снимка, используемые службой обмена.

Для экспорта PPTX требуется бэкэнд конверсии, поддерживающий снимки с плат, интегрированные через [Univer Server SDK](/server/import-export). [клиентская лицензия](/server/license) настроен отдельно; регистрация плагина браузера не обеспечивает конечных точек конверсии.

## Удаление встроенных меню и UI-взаимодействий для экспорта [#import-export-ui-migration]

<Callout type="warning" title="Обратите внимание">
  Начиная с версии **1.2.0**, Univer больше не включает встроенные меню и UI-взаимодействия для экспорта. Базовые сервисы и Facade API остаются доступными.
</Callout>

Если приложению по-прежнему нужны оригинальные экспортные меню и взаимодействия пользовательского интерфейса, [Пример миграции для встроенных экспортных меню и взаимодействия пользовательского интерфейса](https://office.univer.ai/showcase/boards/custom-import-export) демонстрирует, как их восстановить с помощью пользовательского плагина. Пример включает в себя полный исходный код, который можно просматривать онлайн или загружать.
