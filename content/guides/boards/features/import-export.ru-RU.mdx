`@univerjs-pro/boards-exchange-client` поддерживает импорт исходного текста Mermaid и экспорт файлов PPTX.

## Поддерживаемые форматы

В таблице указаны форматы браузерных API этой страницы. Для преобразования файлов Office нужен сервер с поддержкой соответствующего типа документа и формата.

| Импорт | Экспорт |
| --- | --- |
| Исходный текст Mermaid | `.pptx` |

## Сначала зарегистрируйте среду выполнения досок

```ts
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsExchangeClientPlugin)
```

Перед импортом данных, которые могут содержать дополнительные типы элементов, зарегистрируйте соответствующие плагины:

```ts
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## Передача снимка

Чтобы сохранять данные на уровне приложения, сохраняйте и восстанавливайте снимок доски:

```ts
const board = univerAPI.getActiveBoard()
const snapshot = board.getData()

univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)
```

## Экспорт Facade и импорт Mermaid

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/boards-exchange-client/facade'

const file = await univerAPI.exportBoardByUnitIdAsync(board.getId())
if (file) univerAPI.downloadFile(file, 'board', 'pptx')
await board.insertMermaidAsync('flowchart LR\n  A[Черновик] --> B[Проверка]')
```
