Board 的心智圖支援是選用功能。若產品需要在 Board 畫布中使用心智圖節點與互動功能，請加入這項支援。

## 註冊心智圖支援

```ts
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import BoardsMindUIEnUS from '@univerjs-pro/boards-mind-ui/locale/en-US'

import '@univerjs-pro/boards-mind-ui/lib/index.css'

univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## 行動裝置支援 [#mobile-support]

先設定[行動版編輯器](/guides/boards/getting-started/installation#mobile-support)。在本頁外掛模式的初始化程式碼中，將下列桌面版註冊替換為同一套件匯出的行動版外掛，並在**開啟文件前**完成。保留模型外掛、樣式、語言套件與 Facade 匯入，請勿同時註冊兩個版本。

| 套件 | 桌面版註冊 | 行動版註冊 |
| --- | --- | --- |
| `@univerjs-pro/boards-mind-ui` | `UniverBoardsMindUIPlugin` | `UniverBoardsMindMobileUIPlugin` |

## 套件職責

- `@univerjs-pro/boards-mind` 將心智圖元素整合至 Board 模型。
- `@univerjs-pro/boards-mind-ui` 加入心智圖的編輯、渲染與 UI 互動功能，並為瀏覽器編輯器提供 `@univerjs-pro/boards-mind-ui/locale/*` 和 `@univerjs-pro/boards-mind-ui/lib/index.css`。

## 執行環境選擇

在瀏覽器編輯器中，請同時使用這兩個套件。若要在伺服器端處理快照，請將模型套件與 `UniverBoardsPlugin` 一併註冊，不必註冊 UI 套件。

開啟含有心智圖元素的快照前，請先註冊心智圖支援。
