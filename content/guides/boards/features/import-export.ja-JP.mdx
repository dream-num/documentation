`@univerjs-pro/boards-exchange-client` は Mermaid ソースのインポートと PPTX ファイルのエクスポートに対応しています。

## 対応形式

このページでは、ブラウザ API を記述しています。Office ファイルを変換するには、対応するドキュメントタイプとフォーマットをサポートするバックエンドが必要です。

| インポート | エクスポート |
| --- | --- |
| Mermaid ソーステキスト | `.pptx` |

Mermaidのインポートは、`insertMermaidAsync`を介してボード要素としてソーステキストを差し込みます。それは、Officeファイル輸入業者ではありません。エクスポートAPIは`.pptx`を生成し、変換バックエンドが必要です。彼らはPPTXのインポートや画像やPDFエクスポートを提供しません。ホストアプリケーションによって登録された追加のエクスポートターゲットは、別の機能です。

## 最初に Board ランタイムを登録する

```ts
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsExchangeClientPlugin)
```

対象の要素を含む可能性があるデータをインポートする場合は、事前にオプションの要素プラグインを登録します。

```ts
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## スナップショットの受け渡し

アプリケーションレベルでデータを永続化するには、Board のスナップショットを保存し、復元します。

```ts
const board = univerAPI.getActiveBoard()
const snapshot = board.getData()

univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)
```

## Facade エクスポートと Mermaid インポート

`@univerjs-pro/boards-exchange-client`はボードのエクスポートとMermaidのインポートAPIを登録します。

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/boards-exchange-client/facade'

const file = await univerAPI.exportBoardByUnitIdAsync(board.getId())
if (file) univerAPI.downloadFile(file, 'board', 'pptx')
await board.insertMermaidAsync('flowchart LR\n  A[下書き] --> B[レビュー]')
```

`exportBoardBySnapshotAsync(snapshot)` はライブボードに添付されていないデータに使用します。 `transformSnapshotJsonToBoardDataAsync`と`transformBoardDataToSnapshotJsonAsync`は、交換サービスで使用されるスナップショットブロックを変換します。

PPTXエクスポートは、ボードスナップショットをサポートし、[Univer Server SDK](/server/import-export)を介して統合されたコンバージョンバックエンドが必要です。 [クライアントライセンス](/server/license)は別々に構成されています。 ブラウザプラグインを登録すると、コンバージョンエンドポイントを提供していません。

## 組み込みのエクスポートメニューと UI 操作の削除 [#import-export-ui-migration]

<Callout type="warning" title="注意">
  **1.2.0** 以降、Univer の組み込みエクスポートメニューと UI 操作は削除されました。基盤となるサービスと Facade API は引き続き利用できます。
</Callout>

アプリケーションが元のエクスポートメニューとUIインタラクションを必要としている場合、[組み込みのエクスポートメニューとUIインタラクションのマイグレーション例](https://office.univer.ai/showcase/boards/custom-import-export)は、カスタムプラグインでそれらを復元する方法を示しています。 例には、オンラインで閲覧したり、ダウンロードしたりできる完全なソースコードが含まれています。
