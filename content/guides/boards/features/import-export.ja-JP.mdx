Boards は、Board のインポートおよびエクスポートアダプターを介して、Pro のインポート／エクスポートワークフローに組み込むことができます。対応するファイル形式は、アプリケーションに登録されている Pro の交換サービスによって異なります。

## 最初に Board ランタイムを登録する

```ts
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsExchangeClientPlugin)
```

対象の要素を含む可能性があるデータをインポートする場合は、事前にオプションの要素プラグインを登録します。

```ts
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## スナップショットの受け渡し

アプリケーションレベルでデータを永続化するには、Board のスナップショットを保存し、復元します。

```ts
const board = univerAPI.getActiveBoard()
const snapshot = board.getData()

univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)
```

## 対話型の入出力

`@univerjs-pro/boards-exchange-client` がインポートとエクスポートのアダプターを登録します。Facade メソッドで設定済みのフローを開きます。

```ts
if (!board.beginImport()) throw new Error('Cannot open Board import')

// Export UI supports registered targets such as image or PDF.
if (!board.beginExport('image')) throw new Error('Cannot open Board export')
```

ライセンスとデプロイの要件については、[Univer Pro](/guides/pro) を参照してください。
