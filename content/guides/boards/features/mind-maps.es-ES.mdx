El soporte de la hoja de mente es opcional. Añádalo cuando el producto necesite nodos de la mente y las interacciones dentro del lienzo de la Junta.

## Registrar soporte para mapas mentales

```ts
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import BoardsMindUIEsES from '@univerjs-pro/boards-mind-ui/locale/es-ES'
import '@univerjs-pro/boards-mind/facade'
import '@univerjs-pro/boards-mind-ui/lib/index.css'

univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## Compatibilidad móvil [#mobile-support]

Configure el [editor móvil](/guides/boards/getting-started/installation#mobile-support) primero. En la configuración de modo plugin descrito en esta página, sustitúyase los registros de escritorio a continuación con las exportaciones móviles de los mismos paquetes, y lo haga **antes de abrir un documento**. Mantenga los plugins modelo, estilos, locales y las importaciones Facade, y no registre ambas variantes.

| Paquete | Registro de escritorio | Registro móvil |
| --- | --- | --- |
| `@univerjs-pro/boards-mind-ui` | `UniverBoardsMindUIPlugin` | `UniverBoardsMindMobileUIPlugin` |

## Responsabilidades del paquete

- `@univerjs-pro/boards-mind` integra elementos de mapas mentales con el modelo de tablero.
- `@univerjs-pro/boards-mind-ui` añade renderización de mapas mentales, edición e interacción UI. También proporciona los archivos `@univerjs-pro/boards-mind-ui/locale/*` locale y la hoja de estilo `@univerjs-pro/boards-mind-ui/lib/index.css` que los editores del navegador requieren.

## Opciones de tiempo de ejecución

Un editor de navegador requiere ambos paquetes. Para el procesamiento de instantáneas lado servidor, registre el paquete modelo con `UniverBoardsPlugin` y omitir los paquetes UI.

Registrar el soporte mental-mapa antes de abrir una instantánea que contiene elementos de la mente-mapa.

## Facade API

Utilice la Facade estructurada en lugar de editar las formas y conectores de la Junta subyacentes individualmente.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const mindMap = board.insertMindMap({
  left: 180,
  top: 180,
  root: {
    text: 'Release',
    children: [
      { text: 'Product', children: [{ text: 'Scope' }, { text: 'UX' }] },
      { text: 'Engineering', children: [{ text: 'API' }, { text: 'QA' }] },
      { text: 'Launch', children: [{ text: 'Docs' }] },
    ],
  },
})
if (!mindMap) throw new Error('Cannot insert mind map')

const qa = mindMap.getNodes().find(node => node.getText() === 'QA')
qa?.addChild({ text: 'Automation' })
```

`FBoard` proporciona `insertMindMap`, `getMindMap`, y `getMindMaps`. `FBoardMindMap` proporciona búsqueda de nodos, descendientes, diseño, límites, `reflow`, `setLayout`, `setBranchLineType`, y `remove`. Mangos de nodos soportan texto, inserción de niños y hermanos, reparenting, promotion, detaching, ordering, styling, y estado de colapso.

## Redistribuir dentro de límites

`reflow()` se encuentra atómico y centra un mapa mental dentro de un rectángulo especificado en las coordenadas de la Junta. Conserva los tamaños de nodo y texto. Por defecto la llamada se alimenta con las brechas más pequeñas soportadas. Si el diseño todavía no cabe o sigue siendo legible, la Junta permanece sin cambios y la llamada devuelve `reason: 'bounds-too-small'` con `requiredBounds`.

```ts
const result = mindMap.reflow({
  bounds: { left: 80, top: 80, width: 1_000, height: 600 },
  padding: 24,
})

if (!result.success) {
  console.warn(result.reason, result.requiredBounds)
}
```

El rectángulo de destino determina sólo dónde se coloca el mapa mental. El reflujo no reparenta, corta o redimensiona el contenedor de la mente-mapa, y un reflujo exitoso se convierte en un solo elemento de deshacer.
