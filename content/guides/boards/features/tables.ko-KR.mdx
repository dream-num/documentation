보드 테이블 지원은 모델 및 UI 패키지로 나뉩니다. 보드 캔버스에 편집 가능한 테이블 요소를 필요로하는 브라우저 편집기는 패키지를 모두 등록해야합니다.

## 표 지원 등록하기

```ts
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import BoardsTableUIEnUS from '@univerjs-pro/boards-table-ui/locale/en-US'

import '@univerjs-pro/boards-table/facade'
import '@univerjs-pro/boards-table-ui/lib/index.css'

univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
```

## 모바일 지원 [#mobile-support]

[모바일 편집기](/guides/boards/getting-started/installation#mobile-support)를 먼저 구성하십시오. 이 페이지에서 설명 된 플러그인 모드 설정에서 동일한 패키지에서 모바일 내보내기로 아래 데스크탑 등록을 대체하고 **문서 열기**을 수행하십시오. 모델 플러그인, 스타일, 로컬 및 Facade 가져 오기를 유지하고 두 변형을 등록하지 마십시오.

| 패키지 | 데스크톱 등록 | 모바일 등록 |
| --- | --- | --- |
| `@univerjs-pro/boards-table-ui` | `UniverBoardsTableUIPlugin` | `UniverBoardsTableMobileUIPlugin` |

## 패키지 역할

- `@univerjs-pro/boards-table`은 표 요소를 보드 모델과 통합합니다.
- `@univerjs-pro/boards-table-ui`는 보드 캔버스에 테이블 렌더링 및 편집 UI를 추가합니다. 또한 `@univerjs-pro/boards-table-ui/locale/*` Locale 파일과 `@univerjs-pro/boards-table-ui/lib/index.css` stylesheet를 브라우저 편집기가 필요합니다.

## 스냅샷 데이터

보드 테이블 요소는 `tableId`를 저장하고 각 보드 요소에 공통된 필드. 테이블 플러그인은 테이블 페이로드를 소유하고, 요소는 보드 리소스를 통해 페이로드를 참조합니다.

```ts
const table = board.insertTable({
  left: 120,
  top: 120,
  width: 480,
  height: 280,
  rows: 3,
  columns: 4,
})
if (!table) throw new Error('Cannot insert Board table')
```

`table` 요소를 포함하는 스냅 샷을 열 전에 테이블 지원을 등록하십시오.

## 안정적인 표 색상

보드 테이블이 삽입되거나 스타일 변경 될 때 플러그인은 그 테이블과 해결 된 테마 팔레트를 저장합니다. 기존 테이블은 글로벌 Univer 테마가 변경 될 때 색상을 유지합니다. 다른 테이블 스타일을 선택하면 그 테이블에 의해 소유 된 새로운 테마 스냅 샷을 만듭니다.
