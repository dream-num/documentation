Зарегистрируйте `@univerjs-pro/boards-print`, чтобы печатать активную страницу Board или экспортировать её в PNG либо JPEG. Эти же действия доступны на ленте.

```ts
import { ExportBoardImageOperation, PrintBoardOperation, UniverBoardsPrintPlugin } from '@univerjs-pro/boards-print'

import '@univerjs-pro/boards-print/lib/index.css'

univer.registerPlugin(UniverBoardsPrintPlugin)

await univerAPI.executeCommand(PrintBoardOperation.id)
await univerAPI.executeCommand(ExportBoardImageOperation.id, { format: 'png' })
```

Добавьте `@univerjs-pro/boards-print/locale/<locale>` в языковую конфигурацию Univer, чтобы локализовать подписи на ленте.
