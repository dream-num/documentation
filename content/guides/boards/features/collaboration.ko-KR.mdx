여러 사용자가 같은 보드를 편집하고 서로의 변경 사항을 확인할 수 있습니다. [공동 편집 통합](/server/collaboration/browser-integration)에 따라 백엔드, 인증, 권한, 저장소를 연결한 다음 [라이선스](/server/license)를 설정하세요.

## 문서 설정 및 로드

[Office 빠른 시작](/server/collaboration/quick-start)을 참고하여 기존 Boards 편집기에 Collaboration Client 설정을 추가하세요. 해당 예제는 Sheets를 사용하므로, 백엔드에서는 Boards 문서를 생성하고 영구 저장한 뒤 그 ID를 브라우저에 반환해야 합니다.

```ts
import '@univerjs-pro/boards/facade'
import '@univerjs-pro/collaboration-client/facade'

const document = await univerAPI.getCollaboration().loadBoardAsync('your-document-id')
if (!document) throw new Error('Document could not be loaded')
```

문서를 다시 열거나 공유할 때도 동일한 ID를 사용하세요. 서버 문서를 로드하는 대신 로컬의 빈 문서를 만들면 안 됩니다.

## 동기화 및 권한 확인

독립된 두 브라우저 세션에서 같은 ID를 여세요. 한 세션에서 텍스트를 수정하거나 요소를 이동한 뒤 다른 세션에 반영되는지 확인하세요. 페이지 새로 고침, 재연결, 서비스 재시작 후에도 내용이 유지되는지 검증하세요. 보기 전용 계정과 권한이 없는 계정으로 서버가 허용되지 않은 쓰기와 읽기를 거부하는지 확인하세요.

[편집 기록](/guides/boards/features/edit-history)과 [가져오기 및 내보내기](/guides/boards/features/import-export)는 별도로 설정해야 합니다. 공동 편집을 도입해도 자동으로 활성화되지는 않습니다.
