---
title: 容器與泳道
icon: '#pro/PanelsTopLeft'
---

容器讓 Boards 能呈現框選區域、泳道、UML 套件區塊，以及其他父子結構。容器的隸屬關係會透過 `parentId` 儲存在子元素上；若為泳道，則另透過 `laneId` 儲存。

## 建立容器

```ts
const board = univerAPI.getActiveBoard()
const pageId = board.getActivePageId()

const container = await board.createContainer({
  pageId,
  title: 'Scope',
  transform: { left: 80, top: 80, width: 640, height: 360 },
})
```

## 將元素移入容器

```ts
await board.moveElementsToContainer(['card-1', 'card-2'], container.id, { pageId })
await board.fitContainerToContent(container.id, { pageId })
```

## 設定隸屬行為

```ts
await board.setContainerMembershipLocked(container.id, true, { pageId })
await board.setContainerAutoResize(container.id, false, { pageId })
```

## 泳道

泳道是具有分道設定的容器。請使用專用的 Facade API 來新增、移除、調整大小、重新排序、收合及重新命名分道。

```ts
const swimlane = await board.createSwimlane({
  pageId,
  transform: { left: 80, top: 80, width: 720, height: 360 },
  swimlane: {
    orientation: 'horizontal',
    lanes: [
      { id: 'todo', title: 'Todo', order: 0, size: 240 },
      { id: 'done', title: 'Done', order: 1, size: 240 },
    ],
  },
})

await board.renameSwimlaneLane(swimlane.id, 'todo', 'Backlog', { pageId })
```
