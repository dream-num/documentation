La prise en charge des tableaux dans Board est répartie entre un paquet de modèle et un paquet d’interface utilisateur. Enregistrez les deux paquets dans les éditeurs pour navigateur qui doivent proposer des tableaux modifiables sur le canevas de Board.

## Enregistrer la prise en charge des tableaux

```ts
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import BoardsTableUIEnUS from '@univerjs-pro/boards-table-ui/locale/en-US'

import '@univerjs-pro/boards-table/facade'
import '@univerjs-pro/boards-table-ui/lib/index.css'

univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
```

## Rôle des paquets

- `@univerjs-pro/boards-table` intègre les tableaux au modèle de Board.
- `@univerjs-pro/boards-table-ui` ajoute le rendu et l’interface de modification des tableaux au canevas de Board. Il fournit également `@univerjs-pro/boards-table-ui/locale/*` et `@univerjs-pro/boards-table-ui/lib/index.css` aux éditeurs pour navigateur.

## Données de l’instantané

Un tableau de Board stocke un `tableId` et les champs communs aux éléments de Board. Les données du tableau sont gérées par le plug-in de tableaux et référencées dans les ressources de Board.

```ts
const table = board.insertTable({
  left: 120,
  top: 120,
  width: 480,
  height: 280,
  rows: 3,
  columns: 4,
})
if (!table) throw new Error('Cannot insert Board table')
```

Enregistrez la prise en charge des tableaux avant d’ouvrir des instantanés contenant des éléments `table`.
