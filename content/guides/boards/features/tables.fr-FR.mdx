Un éditeur de navigateur qui a besoin d'éléments de table modifiables sur la toile Board doit enregistrer les deux paquets.

## Enregistrer la prise en charge des tableaux

```ts
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import BoardsTableUIEnUS from '@univerjs-pro/boards-table-ui/locale/en-US'

import '@univerjs-pro/boards-table/facade'
import '@univerjs-pro/boards-table-ui/lib/index.css'

univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
```

## Prise en charge mobile [#mobile-support]

Configurez d'abord le [éditeur mobile](/guides/boards/getting-started/installation#mobile-support). Dans la configuration en mode plugin décrite sur cette page, remplacez les enregistrements de bureau ci-dessous avec les exportations mobiles des mêmes paquets, et faites-le **avant d'ouvrir un document** . Gardez les plugins modèles, styles, locaux et importations de Facade, et ne enregistrez pas les deux variantes.

| Paquet | Inscription de bureau | Inscription mobile |
| --- | --- | --- |
| `@univerjs-pro/boards-table-ui` | `UniverBoardsTableUIPlugin` | `UniverBoardsTableMobileUIPlugin` |

## Rôle des paquets

- `@univerjs-pro/boards-table` intègre les tableaux au modèle de Board.
- `@univerjs-pro/boards-table-ui` ajoute l'interface de rendu et d'édition de table sur la toile de tableau. Il fournit également les fichiers locaux `@univerjs-pro/boards-table-ui/locale/*` et la feuille de style `@univerjs-pro/boards-table-ui/lib/index.css` dont les éditeurs de navigateurs ont besoin.

## Données de l’instantané

Un élément de table de tableau stocke un `tableId` et les champs communs à chaque élément de la table. Le plugin de table possède la charge utile de la table, et l'élément renvoie la charge utile par les ressources de la carte.

```ts
const table = board.insertTable({
  left: 120,
  top: 120,
  width: 480,
  height: 280,
  rows: 3,
  columns: 4,
})
if (!table) throw new Error('Cannot insert Board table')
```

Enregistrez le support de table avant d'ouvrir un instantané contenant des éléments `table`.

## Couleurs de tableau stables

Lorsqu'une table Board est insérée ou que son style change, le plugin stocke la palette de thèmes résolues avec cette table. Les tables existantes conservent leurs couleurs lorsque le thème global Univer change. La sélection d'un autre style de table crée un nouveau snapshot de thème appartenant à cette table.
