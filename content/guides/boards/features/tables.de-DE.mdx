Die Board-Tabellenunterstützung ist in Modell- und UI-Pakete aufgeteilt. Registrieren Sie beide Pakete in Browser-Editoren, die bearbeitbare Tabellenelemente auf der Board-Leinwand benötigen.

## Tabellenunterstützung registrieren

```ts
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import BoardsTableUIEnUS from '@univerjs-pro/boards-table-ui/locale/en-US'

import '@univerjs-pro/boards-table/facade'
import '@univerjs-pro/boards-table-ui/lib/index.css'

univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
```

## Paketverantwortlichkeiten

- `@univerjs-pro/boards-table` integriert Tabellenelemente in das Board-Modell.
- `@univerjs-pro/boards-table-ui` fügt Tabellenrendering und Bearbeitungsoberfläche auf der Board-Leinwand hinzu. Es stellt außerdem `@univerjs-pro/boards-table-ui/locale/*` und `@univerjs-pro/boards-table-ui/lib/index.css` für Browser-Editoren bereit.

## Snapshot-Daten

Ein Board-Tabellenelement speichert ein `tableId` und allgemeine Board-Elementfelder. Die Tabellennutzlast wird vom Tabellen-Plugin verwaltet und über Board-Ressourcen referenziert.

```ts
const table = board.insertTable({
  left: 120,
  top: 120,
  width: 480,
  height: 280,
  rows: 3,
  columns: 4,
})
if (!table) throw new Error('Cannot insert Board table')
```

Registrieren Sie die Tabellenunterstützung, bevor Sie Snapshots öffnen, die `table`-Elemente enthalten.
