La prise en charge des cartes mentales dans Boards est facultative. Ajoutez-la si votre produit nécessite des nœuds de carte mentale et des interactions avec ceux-ci dans le canevas Board.

## Enregistrer la prise en charge des cartes mentales

```ts
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import BoardsMindUIEnUS from '@univerjs-pro/boards-mind-ui/locale/en-US'

import '@univerjs-pro/boards-mind-ui/lib/index.css'

univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## Rôle des packages

- `@univerjs-pro/boards-mind` intègre les éléments de carte mentale au modèle Board.
- `@univerjs-pro/boards-mind-ui` ajoute la modification, le rendu et les interactions avec l'interface utilisateur des cartes mentales. Il fournit également `@univerjs-pro/boards-mind-ui/locale/*` et `@univerjs-pro/boards-mind-ui/lib/index.css` pour les éditeurs utilisés dans un navigateur.

## Choix selon l'environnement d'exécution

Utilisez les deux packages dans un éditeur exécuté dans un navigateur. Pour traiter des instantanés côté serveur, enregistrez le package du modèle avec `UniverBoardsPlugin` et n'incluez pas les packages d'interface utilisateur.

Enregistrez la prise en charge des cartes mentales avant d'ouvrir des instantanés qui contiennent des éléments de carte mentale.
