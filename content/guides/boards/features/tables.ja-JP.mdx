Board のテーブル機能は、モデルパッケージと UI パッケージに分かれています。Board キャンバス上でテーブル要素を編集するブラウザーエディターには、両方のパッケージを登録してください。

## テーブル機能の登録

```ts
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import BoardsTableUIEnUS from '@univerjs-pro/boards-table-ui/locale/en-US'

import '@univerjs-pro/boards-table/facade'
import '@univerjs-pro/boards-table-ui/lib/index.css'

univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
```

## 各パッケージの役割

- `@univerjs-pro/boards-table` は、テーブル要素を Board モデルに統合します。
- `@univerjs-pro/boards-table-ui` は、Board キャンバスにテーブルのレンダリング機能と編集 UI を追加します。また、ブラウザーエディター向けに `@univerjs-pro/boards-table-ui/locale/*` と `@univerjs-pro/boards-table-ui/lib/index.css` も提供します。

## スナップショットデータ

Board のテーブル要素には、`tableId` と Board 要素に共通するフィールドが保存されます。テーブルのペイロードはテーブルプラグインによって管理され、Board リソースを介して参照されます。

```ts
const table = board.insertTable({
  left: 120,
  top: 120,
  width: 480,
  height: 280,
  rows: 3,
  columns: 4,
})
if (!table) throw new Error('Cannot insert Board table')
```

`table` 要素を含むスナップショットを開く前に、テーブル機能を登録してください。
