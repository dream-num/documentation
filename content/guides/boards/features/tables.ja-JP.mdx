ボードテーブルのサポートは、モデルとUIパッケージに分割されます。ボードキャンバス上の編集可能なテーブル要素を必要とするブラウザエディタは、両方のパッケージを登録する必要があります。

## テーブル機能の登録

```ts
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import BoardsTableUIEnUS from '@univerjs-pro/boards-table-ui/locale/en-US'

import '@univerjs-pro/boards-table/facade'
import '@univerjs-pro/boards-table-ui/lib/index.css'

univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
```

## モバイル対応 [#mobile-support]

[モバイルエディタ](/guides/boards/getting-started/installation#mobile-support)を最初に構成します。 このページに記載されているプラグインモード設定では、デスクトップの登録を同じパッケージからモバイルエクスポートに置き換えて、**ドキュメントを開く前に**を実行します。 モデルプラグイン、スタイル、ロケール、ファサードのインポートを保存し、両方のバリアントを登録しないでください。

| パッケージ | デスクトップの登録 | モバイルの登録 |
| --- | --- | --- |
| `@univerjs-pro/boards-table-ui` | `UniverBoardsTableUIPlugin` | `UniverBoardsTableMobileUIPlugin` |

## 各パッケージの役割

- `@univerjs-pro/boards-table` は、テーブル要素を Board モデルに統合します。
- `@univerjs-pro/boards-table-ui`は、ボードキャンバスにテーブルレンダリングと編集UIを追加します。 また、`@univerjs-pro/boards-table-ui/locale/*`ローカルファイルとブラウザエディタが必要とする`@univerjs-pro/boards-table-ui/lib/index.css`スタイルシートを提供します。

## スナップショットデータ

ボードテーブル要素は、`tableId`と、すべてのボード要素に共通するフィールドを保存します。テーブルプラグインはテーブルペイロードを所有し、要素はボードリソースを介してペイロードを参照します。

```ts
const table = board.insertTable({
  left: 120,
  top: 120,
  width: 480,
  height: 280,
  rows: 3,
  columns: 4,
})
if (!table) throw new Error('Cannot insert Board table')
```

`table`要素を含むスナップショットを開く前にテーブルのサポートを登録します。

## テーブル色を固定する

ボードテーブルがインサートされたり、そのスタイルの変更が行われるとき、プラグインはそのテーブルで解決されたテーマパレットを保存します。既存のテーブルは、グローバルUniverテーマの変更時に色を保ちます。別のテーブルスタイルを選択すると、そのテーブルが保有する新しいテーマスナップショットが作成されます。
