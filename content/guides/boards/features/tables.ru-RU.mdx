Поддержка таблицы платы разделена на пакеты моделей и пользовательского интерфейса. Редактор браузера, которому нужны редактируемые элементы таблицы на холсте платы, должен зарегистрировать оба пакета.

## Регистрация поддержки таблиц

```ts
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import BoardsTableUIEnUS from '@univerjs-pro/boards-table-ui/locale/en-US'

import '@univerjs-pro/boards-table/facade'
import '@univerjs-pro/boards-table-ui/lib/index.css'

univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
```

## Поддержка мобильных устройств [#mobile-support]

Сначала настройте [Мобильный редактор](/guides/boards/getting-started/installation#mobile-support). В настройках плагин-режима, описанных на этой странице, замените регистрацию рабочего стола ниже на мобильный экспорт из тех же пакетов и сделайте это **Перед тем, как открыть документ**, сохраните плагины модели, стили, локализации и импорт Facade и не регистрируйте оба варианта.

| Пакет | Настольная регистрация | Мобильная регистрация |
| --- | --- | --- |
| `@univerjs-pro/boards-table-ui` | `UniverBoardsTableUIPlugin` | `UniverBoardsTableMobileUIPlugin` |

## Назначение пакетов

- `@univerjs-pro/boards-table` интегрирует элементы таблиц с моделью доски.
- `@univerjs-pro/boards-table-ui` добавляет пользовательский интерфейс для рендеринга и редактирования таблиц на холсте Совета. Он также предоставляет файлы `@univerjs-pro/boards-table-ui/locale/*` и таблицу стилей `@univerjs-pro/boards-table-ui/lib/index.css`, которые требуются редакторам браузера.

## Данные снимка

Элемент таблицы содержит `tableId` и поля, общие для каждого элемента таблицы. Плагин таблицы владеет полезной нагрузкой таблицы, и элемент ссылается на полезную нагрузку через ресурсы платы.

```ts
const table = board.insertTable({
  left: 120,
  top: 120,
  width: 480,
  height: 280,
  rows: 3,
  columns: 4,
})
if (!table) throw new Error('Cannot insert Board table')
```

Зарегистрируйте поддержку таблицы перед открытием снимка, который содержит элементы `table`.

## Стабильные цвета таблиц

При вставке таблицы или изменении ее стиля плагин хранит решенную палитру тем с этой таблицей. Существующие таблицы сохраняют свои цвета при изменении глобальной темы Univer. Выбор другого стиля таблицы создает новый снимок темы, принадлежащий этой таблице.
