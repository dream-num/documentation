Поддержка таблиц на досках разделена между пакетами модели и пользовательского интерфейса. В браузерных редакторах, где таблицы на холсте доски должны быть доступны для редактирования, зарегистрируйте оба пакета.

## Регистрация поддержки таблиц

```ts
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import BoardsTableUIEnUS from '@univerjs-pro/boards-table-ui/locale/en-US'

import '@univerjs-pro/boards-table-ui/lib/index.css'

univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
```

## Назначение пакетов

- `@univerjs-pro/boards-table` интегрирует элементы таблиц с моделью доски.
- `@univerjs-pro/boards-table-ui` добавляет на холст доски отрисовку таблиц и пользовательский интерфейс для их редактирования. Пакет также предоставляет `@univerjs-pro/boards-table-ui/locale/*` и `@univerjs-pro/boards-table-ui/lib/index.css` для браузерных редакторов.

## Данные снимка

Элемент таблицы на доске хранит `tableId` и общие поля элементов доски. Данные таблицы обрабатываются плагином таблиц, а доступ к ним осуществляется через ресурсы доски.

```ts
await board.addElement({
  id: 'table-element-1',
  type: 'table',
  transform: { left: 120, top: 120, width: 480, height: 280 },
  tableId: 'table-1',
}, { pageId })
```

Зарегистрируйте поддержку таблиц, прежде чем открывать снимки с элементами типа `table`.
