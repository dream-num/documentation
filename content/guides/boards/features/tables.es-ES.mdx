El soporte de mesa se divide en paquetes modelo y UI. Un editor de navegadores que necesita elementos de mesa editables en el lienzo de la Junta debe registrar ambos paquetes.

## Registrar compatibilidad con tablas

```ts
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import BoardsTableUIEnUS from '@univerjs-pro/boards-table-ui/locale/en-US'

import '@univerjs-pro/boards-table/facade'
import '@univerjs-pro/boards-table-ui/lib/index.css'

univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
```

## Compatibilidad móvil [#mobile-support]

Configure el [editor móvil](/guides/boards/getting-started/installation#mobile-support) primero. En la configuración de modo plugin descrito en esta página, sustitúyase los registros de escritorio a continuación con las exportaciones móviles de los mismos paquetes, y lo haga **antes de abrir un documento**. Mantenga los plugins modelo, estilos, locales y las importaciones Facade, y no registre ambas variantes.

| Paquete | Registro de escritorio | Registro móvil |
| --- | --- | --- |
| `@univerjs-pro/boards-table-ui` | `UniverBoardsTableUIPlugin` | `UniverBoardsTableMobileUIPlugin` |

## Responsabilidades del paquete

- `@univerjs-pro/boards-table` integra elementos de tabla con el modelo de Board.
- `@univerjs-pro/boards-table-ui` añade la reproducción de mesa y la edición de la interfaz de usuario en el lienzo de la Junta. También proporciona los archivos `@univerjs-pro/boards-table-ui/locale/*` locale y la hoja de estilo `@univerjs-pro/boards-table-ui/lib/index.css` que los editores del navegador requieren.

## Datos instantáneos

Un elemento de tabla de la tabla almacena un `tableId` y los campos comunes a cada elemento de la Junta. El plugin de la tabla posee la carga útil de la tabla, y el elemento hace referencia a la carga útil a través de los recursos de la Junta .

```ts
const table = board.insertTable({
  left: 120,
  top: 120,
  width: 480,
  height: 280,
  rows: 3,
  columns: 4,
})
if (!table) throw new Error('Cannot insert Board table')
```

Regístrate soporte de mesa antes de abrir una instantánea que contenga elementos `table`.

## Colores de tabla estables

Cuando se inserta una tabla de tableros o su estilo cambia, el plugin almacena la paleta temática resuelta con esa tabla. Las tablas existentes mantienen sus colores cuando el tema global Univer cambia. Elegir otro estilo de mesa crea una nueva instantánea de tema propiedad de esa tabla.
