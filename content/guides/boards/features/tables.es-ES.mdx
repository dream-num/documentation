La compatibilidad con tablas de tablero se divide en paquetes de modelo y UI. Registre ambos paquetes en editores de navegador que necesiten elementos de tabla editables en el lienzo de Board.

## Registrar compatibilidad con tablas

```ts
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import BoardsTableUIEnUS from '@univerjs-pro/boards-table-ui/locale/en-US'

import '@univerjs-pro/boards-table/facade'
import '@univerjs-pro/boards-table-ui/lib/index.css'

univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
```

## Responsabilidades del paquete

- `@univerjs-pro/boards-table` integra elementos de tabla con el modelo de Board.
- `@univerjs-pro/boards-table-ui` agrega representación de tablas y edición de interfaz de usuario en el lienzo de Board. También proporciona `@univerjs-pro/boards-table-ui/locale/*` y `@univerjs-pro/boards-table-ui/lib/index.css` para editores de navegador.

## Datos instantáneos

Un elemento de tabla Board almacena un `tableId` y campos de elementos comunes de Board. La carga útil de la tabla se administra mediante el complemento de la tabla y se hace referencia a ella a través de los recursos de la placa.

```ts
const table = board.insertTable({
  left: 120,
  top: 120,
  width: 480,
  height: 280,
  rows: 3,
  columns: 4,
})
if (!table) throw new Error('Cannot insert Board table')
```

Registre el soporte de la tabla antes de abrir instantáneas que contengan elementos `table`.

## Colores de tabla estables

Cuando se inserta una tabla de Board o cambia su estilo, el complemento guarda con ella la paleta de tema resuelta. Las tablas existentes conservan sus colores aunque cambie el tema global de Univer; seleccionar otro estilo crea una nueva instantánea de tema propia de la tabla.
