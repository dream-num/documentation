Die Unterstützung von Board-Mindmaps ist optional. Fügen Sie es hinzu, wenn Ihr Produkt Mindmap-Knoten und Interaktionen innerhalb der Board-Leinwand benötigt.

## Mindmap-Unterstützung registrieren

```ts
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import BoardsMindUIEnUS from '@univerjs-pro/boards-mind-ui/locale/en-US'

import '@univerjs-pro/boards-mind-ui/lib/index.css'

univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## Paketverantwortlichkeiten

- `@univerjs-pro/boards-mind` integriert Mindmap-Elemente in das Board-Modell.
- `@univerjs-pro/boards-mind-ui` fügt Mindmap-Bearbeitung, Rendering und UI-Interaktion hinzu. Es bietet außerdem `@univerjs-pro/boards-mind-ui/locale/*` und `@univerjs-pro/boards-mind-ui/lib/index.css` für Browser-Editoren.

## Laufzeitoptionen

Verwenden Sie beide Pakete in einem Browser-Editor. Registrieren Sie für die serverseitige Snapshot-Verarbeitung das Modellpaket bei `UniverBoardsPlugin` und überspringen Sie UI-Pakete.

Registrieren Sie die Mindmap-Unterstützung, bevor Sie Snapshots öffnen, die Mindmap-Elemente enthalten.
