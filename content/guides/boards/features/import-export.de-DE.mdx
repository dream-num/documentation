Boards können über Board-Import- und Exportadapter an Pro-Import-/Export-Workflows teilnehmen. Die genauen Dateiformate hängen von den in Ihrer Anwendung registrierten Pro-Exchange-Diensten ab.

## Registrieren Sie zuerst die Board-Laufzeit

```ts
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

Registrieren Sie optionale Element-Plugins, bevor Sie Daten importieren, die diese Elemente enthalten können:

```ts
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## Snapshot-Übergabe

Für Persistenz auf Anwendungsebene speichern und wiederherstellen Sie den Board-Snapshot:

```ts
const board = univerAPI.getActiveBoard()
const snapshot = board.getData()

univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)
```

## Entwurfseinfügung

Wenn ein Importfluss einen Board-Entwurf zurückgibt, fügen Sie ihn durch die Fassade ein, damit Elementreihenfolge, Ressourcen und Containermitgliedschaft konsistent angewendet werden.

```ts
await board.insertDraft(draft, {
  pageId: board.getActivePageId(),
  position: { x: 160, y: 120 },
})
```

Lizenz- und Bereitstellungsanforderungen finden Sie unter [Univer Pro](/guides/pro).
