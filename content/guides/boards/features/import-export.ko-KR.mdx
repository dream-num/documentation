`@univerjs-pro/boards-exchange-client`는 Mermaid 소스 가져오기와 PPTX 파일 내보내기를 지원합니다.

## 지원 형식

테이블은이 페이지에서 브라우저 API를 설명합니다. Office 파일을 변환하는 것은 해당 문서 유형과 형식을 지원하는 백엔드가 필요합니다.

| 가져오기 | 내보내기 |
| --- | --- |
| Mermaid 소스 텍스트 | `.pptx` |

Mermaid 수입품은 `insertMermaidAsync`를 통해서 널 성분으로 근원 원본을 삽입합니다; 그것은 사무실 파일 수입업자가 아닙니다. 수출 APIs는 `.pptx` 생성하고 변환 백엔드를 요구합니다. 그들은 PPTX 수입품 또는 이미지 및 PDF 수출을 제공하지 않습니다. 주인 신청에 의해 등록된 추가 수출 목표는 분리된 기능입니다.

## 먼저 보드 런타임 등록하기

```ts
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsExchangeClientPlugin)
```

해당 요소가 포함될 수 있는 데이터를 가져오기 전에 선택적 요소 플러그인을 등록하세요.

```ts
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## 스냅샷 전달

애플리케이션 수준에서 데이터를 영구적으로 유지하려면 보드 스냅샷을 저장하고 복원하세요.

```ts
const board = univerAPI.getActiveBoard()
const snapshot = board.getData()

univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)
```

## Facade 내보내기와 Mermaid 가져오기

`@univerjs-pro/boards-exchange-client`는 보드 수출 및 Mermaid 수입 API를 등록합니다.

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/boards-exchange-client/facade'

const file = await univerAPI.exportBoardByUnitIdAsync(board.getId())
if (file) univerAPI.downloadFile(file, 'board', 'pptx')
await board.insertMermaidAsync('flowchart LR\n  A[초안] --> B[검토]')
```

`exportBoardBySnapshotAsync(snapshot)`를 사용하여 라이브 보드에 첨부되지 않는 데이터. `transformSnapshotJsonToBoardDataAsync` 및 `transformBoardDataToSnapshotJsonAsync`는 교환 서비스에서 사용되는 스냅 샷 블록을 변환합니다.

PPTX 수출은 [Univer Server SDK](/server/import-export)를 통해 통합 된 보드 스냅 샷을 지원하는 변환 백엔드가 필요합니다. [고객 라이센스](/server/license)는 별도로 구성됩니다. 브라우저 플러그인을 등록하면 변환 엔드 포인트를 제공하지 않습니다.
