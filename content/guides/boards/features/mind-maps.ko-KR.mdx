Board mind-map 지원은 선택 사항입니다. 제품 필요 시 주의사항 노드 및 상호 작용이 Board Canvas 내부에 추가될 때 추가하십시오.

## 마인드맵 지원 등록하기

```ts
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import BoardsMindUIKoKR from '@univerjs-pro/boards-mind-ui/locale/ko-KR'
import '@univerjs-pro/boards-mind/facade'
import '@univerjs-pro/boards-mind-ui/lib/index.css'

univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## 모바일 지원 [#mobile-support]

[모바일 편집기](/guides/boards/getting-started/installation#mobile-support)를 먼저 구성하십시오. 이 페이지에서 설명 된 플러그인 모드 설정에서 동일한 패키지에서 모바일 내보내기로 아래 데스크탑 등록을 대체하고 **문서 열기**을 수행하십시오. 모델 플러그인, 스타일, 로컬 및 Facade 가져 오기를 유지하고 두 변형을 등록하지 마십시오.

| 패키지 | 데스크톱 등록 | 모바일 등록 |
| --- | --- | --- |
| `@univerjs-pro/boards-mind-ui` | `UniverBoardsMindUIPlugin` | `UniverBoardsMindMobileUIPlugin` |

## 패키지 역할

- `@univerjs-pro/boards-mind`는 마인드맵 요소를 보드 모델과 통합합니다.
- `@univerjs-pro/boards-mind-ui`는 마음지도 렌더링, 편집 및 UI 상호 작용을 추가합니다. 또한 `@univerjs-pro/boards-mind-ui/locale/*` 로컬 파일과 `@univerjs-pro/boards-mind-ui/lib/index.css` 스타일 시트를 브라우저 편집기가 요구됩니다.

## 런타임 선택

브라우저 편집기는 패키지를 모두 필요로 합니다. 서버 측 스냅 샷 처리의 경우 `UniverBoardsPlugin`와 모델 패키지를 등록하고 UI 패키지를 omit합니다.

마음지도를 열어주기 전에 지원해 주세요.

## Facade API

구조화 된 Facade를 사용하여 언더 라이딩 보드 모양과 커넥터를 개별적으로 편집합니다.

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const mindMap = board.insertMindMap({
  left: 180,
  top: 180,
  root: {
    text: 'Release',
    children: [
      { text: 'Product', children: [{ text: 'Scope' }, { text: 'UX' }] },
      { text: 'Engineering', children: [{ text: 'API' }, { text: 'QA' }] },
      { text: 'Launch', children: [{ text: 'Docs' }] },
    ],
  },
})
if (!mindMap) throw new Error('Cannot insert mind map')

const qa = mindMap.getNodes().find(node => node.getText() === 'QA')
qa?.addChild({ text: 'Automation' })
```

`FBoard`는 `insertMindMap`, `getMindMap` 및 `getMindMaps`를 제공합니다. `FBoardMindMap`는 노드 조회, 후손가락, 배치, 경계, `reflow`, `setLayout`, `setBranchLineType` 및 `remove`를 제공합니다. 노드는 텍스트, 어린이 및 체적 삽입, reparenting, 승진, detaching, 주문, 스타일링 및 붕괴 상태를 지원합니다.

## 지정 영역 안에 재배치

`reflow()` 원자로는 보드 좌표에 지정된 직사각형 내부의 마음지도를 놓고 있습니다. 노드와 텍스트 크기를 보존합니다. 기본적으로 가장 작은 지원 간격으로 통화 저장소에 의해. 레이아웃이 여전히 적합하지 않거나 유지되지 않는 경우, 보드는 변경되지 않고 호출은 `reason: 'bounds-too-small'`를 `requiredBounds`로 반환합니다.

```ts
const result = mindMap.reflow({
  bounds: { left: 80, top: 80, width: 1_000, height: 600 },
  padding: 24,
})

if (!result.success) {
  console.warn(result.reason, result.requiredBounds)
}
```

대상 직사각형은 마음지도가 배치되는 유일한 것을 결정합니다. 썰물은, 클립, 또는 마음지도 콘테이너를 resize하지 않으며, 성공적인 썰물는 단 하나 undo 품목이 됩니다.
