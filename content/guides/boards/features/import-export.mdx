Boards supports Mermaid source import and PPTX export through `@univerjs-pro/boards-exchange-client`.

## Supported formats

The table describes the browser APIs on this page. Converting Office files also requires a backend that supports the corresponding document type and format.

| Import | Export |
| --- | --- |
| Mermaid source text | `.pptx` |

Mermaid import inserts source text as Board elements through `insertMermaidAsync`; it is not an Office file importer. The export APIs produce `.pptx` and require a conversion backend. They do not provide PPTX import or image and PDF export. Additional export targets registered by the host application are separate capabilities.

## Register the Board runtime first

```ts
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsExchangeClientPlugin)
```

Register optional element plugins before importing data that may contain those elements:

```ts
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## Snapshot handoff

For application-level persistence, save and restore the Board snapshot:

```ts
const board = univerAPI.getActiveBoard()
const snapshot = board.getData()

univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)
```

## Interactive exchange

`@univerjs-pro/boards-exchange-client` registers the Board export and Mermaid import APIs.

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/boards-exchange-client/facade'

const file = await univerAPI.exportBoardByUnitIdAsync(board.getId())
if (file) univerAPI.downloadFile(file, 'board', 'pptx')

await board.insertMermaidAsync('flowchart LR\n  A[Draft] --> B[Review]')
```

Use `exportBoardBySnapshotAsync(snapshot)` for data that is not attached to a live board. `transformSnapshotJsonToBoardDataAsync` and `transformBoardDataToSnapshotJsonAsync` convert the snapshot blocks used by the exchange service.

PPTX export requires a conversion backend that supports Board snapshots, integrated through the [Univer Server SDK](/server/import-export). The [client license](/server/license) is configured separately; registering a browser plugin does not provide conversion endpoints.

## Removal of built-in export menus and UI interactions [#import-export-ui-migration]

<Callout type="warning" title="Note">
  Starting with version **1.2.0**, Univer no longer includes built-in export menus and UI interactions. The underlying services and Facade APIs remain available.
</Callout>

If the application still needs the original export menus and UI interactions, the [migration example for built-in export menus and UI interactions](https://office.univer.ai/showcase/boards/custom-import-export) demonstrates how to restore them with a custom plugin. The example includes the complete source code, which can be viewed online or downloaded.
