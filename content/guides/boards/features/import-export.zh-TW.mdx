透過 `@univerjs-pro/boards-exchange-client`，畫板可以匯入 Mermaid 原始碼並匯出 PPTX 檔案。

## 支援的格式

下表列出本頁瀏覽器 API 所處理的格式。轉換 Office 檔案還需要後端支援對應的文件型別和格式。

| 匯入 | 匯出 |
| --- | --- |
| Mermaid 原始碼文字 | `.pptx` |

Mermaid 匯入透過 `insertMermaidAsync` 將原始碼插入為畫板元素，不是 Office 檔案匯入。匯出 API 生成 `.pptx`，需要轉換後端，不提供 PPTX 匯入或圖片、PDF 匯出。宿主應用自行註冊的其他匯出目標屬於獨立能力。

## 先註冊 Board 執行環境

```ts
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsExchangeClientPlugin)
```

在匯入可能包含可選元素的資料之前，先註冊對應的元素外掛：

```ts
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## 快照交接

如需在應用層面實現持久化，儲存並恢復畫板快照：

```ts
const board = univerAPI.getActiveBoard()
const snapshot = board.getData()

univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)
```

## Facade 匯出與 Mermaid 匯入

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/boards-exchange-client/facade'

const file = await univerAPI.exportBoardByUnitIdAsync(board.getId())
if (file) univerAPI.downloadFile(file, 'board', 'pptx')
await board.insertMermaidAsync('flowchart LR\n  A[草稿] --> B[審閱]')
```

匯出 PPTX 時，需要透過 [Univer Server SDK](/server/import-export) 整合支援 Board 快照的轉換後端。[客戶端許可證](/server/license)需單獨配置；註冊瀏覽器外掛不會提供轉換介面。

## 移除內建匯出選單和 UI 互動 [#import-export-ui-migration]

<Callout type="warning" title="注意事項">
  從 **1.2.0** 起，Univer 不再內建匯出選單和 UI 互動，底層服務和 Facade API 仍然可用。
</Callout>

如果應用仍需要原有的匯出選單和 UI 互動，可以參考[內建匯出選單和 UI 互動遷移方案](https://office.univer.ai/zh-CN/showcase/boards/custom-import-export)，透過自定義外掛恢復這些選單和互動。範例提供完整原始碼，可線上檢視或下載。
