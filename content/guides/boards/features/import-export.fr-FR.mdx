`@univerjs-pro/boards-exchange-client` permet d’importer du code source Mermaid et d’exporter des fichiers PPTX.

## Formats pris en charge

Le tableau décrit les API du navigateur sur cette page. La conversion des fichiers Office nécessite également un moteur de recherche qui prend en charge le type et le format de document correspondant.

| Importation | Exportation |
| --- | --- |
| Code source Mermaid | `.pptx` |

L'importation de Mermaid insère le texte source en tant qu'éléments de la carte via `insertMermaidAsync`; ce n'est pas un importateur de fichiers Office. Les API d'exportation produisent `.pptx` et nécessitent un moteur de conversion. Elles ne fournissent pas d'importation PPTX ni d'exportation d'image et de PDF.

## Enregistrer d’abord l’environnement d’exécution de Board

```ts
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsExchangeClientPlugin)
```

Enregistrez les plug-ins d’éléments facultatifs avant d’importer des données susceptibles de contenir ces éléments :

```ts
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## Transmission d’un instantané

Pour assurer la persistance au niveau de l’application, enregistrez et restaurez l’instantané du Board :

```ts
const board = univerAPI.getActiveBoard()
const snapshot = board.getData()

univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)
```

## Export Facade et import Mermaid

`@univerjs-pro/boards-exchange-client` enregistre les API d'exportation de Board et d'importation de Mermaid.

```ts
import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/boards-exchange-client/facade'

const file = await univerAPI.exportBoardByUnitIdAsync(board.getId())
if (file) univerAPI.downloadFile(file, 'board', 'pptx')
await board.insertMermaidAsync('flowchart LR\n  A[Brouillon] --> B[Révision]')
```

Utilisez `exportBoardBySnapshotAsync(snapshot)` pour les données qui ne sont pas attachées à une carte en direct. `transformSnapshotJsonToBoardDataAsync` et `transformBoardDataToSnapshotJsonAsync` convertissent les blocs d'instantanés utilisés par le service d'échange.

L'exportation de PPTX nécessite un moteur de conversion qui prend en charge les snapshots Board, intégrés dans le [Univer Server SDK](/server/import-export). Le [licence client](/server/license) est configuré séparément; l'enregistrement d'un plugin navigateur ne fournit pas de paramètres de conversion.

## Suppression des menus et des interactions UI d’exportation intégrés [#import-export-ui-migration]

<Callout type="warning" title="À noter">
  À partir de la version **1.2.0**, Univer a supprimé les menus et les interactions UI d’exportation intégrés. Les services sous-jacents et les API Facade restent disponibles.
</Callout>

Si l'application a encore besoin des menus d'exportation originaux et des interactions UI, le [exemple de migration pour les menus d'exportation intégrés et les interactions d'assurance-chômage](https://office.univer.ai/showcase/boards/custom-import-export) démontre comment les restaurer avec un plugin personnalisé. L'exemple inclut le code source complet, qui peut être consulté en ligne ou téléchargé.
