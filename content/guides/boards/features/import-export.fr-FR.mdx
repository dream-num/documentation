title: Importation et exportation

Les Boards peuvent s’intégrer aux processus d’importation et d’exportation Pro grâce aux adaptateurs d’importation et d’exportation de Board. Les formats de fichiers exacts dépendent des services d’échange Pro enregistrés dans votre application.

## Enregistrer d’abord l’environnement d’exécution de Board

```ts
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsExchangeClientPlugin)
```

Enregistrez les plug-ins d’éléments facultatifs avant d’importer des données susceptibles de contenir ces éléments :

```ts
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
```

## Transmission d’un instantané

Pour assurer la persistance au niveau de l’application, enregistrez et restaurez l’instantané du Board :

```ts
const board = univerAPI.getActiveBoard()
const snapshot = board.getData()

univer.createUnit(UniverInstanceType.UNIVER_BOARD, snapshot)
```

## Échange interactif

`@univerjs-pro/boards-exchange-client` enregistre les adaptateurs d’import et d’export. Ouvrez le flux configuré avec les méthodes Facade.

```ts
if (!board.beginImport()) throw new Error('Cannot open Board import')

// Export UI supports registered targets such as image or PDF.
if (!board.beginExport('image')) throw new Error('Cannot open Board export')
```
