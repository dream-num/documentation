Registra los plugins después del editor del producto y la licencia. Carga los estilos y los idiomas de la interfaz común y del producto. El plugin del producto gestiona los recursos de comentarios: regístralo antes de restaurar un snapshot.

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs-pro/boards-thread-comment @univerjs-pro/boards-thread-comment-ui
```

```ts
import { UniverBoardsThreadCommentPlugin } from '@univerjs-pro/boards-thread-comment'
import { UniverBoardsThreadCommentUIPlugin } from '@univerjs-pro/boards-thread-comment-ui'
import ProductLocale from '@univerjs-pro/boards-thread-comment-ui/locale/es-ES'
import { LocaleType, mergeLocales } from '@univerjs/core'
import SharedLocale from '@univerjs/thread-comment-ui/locale/es-ES'

import '@univerjs/thread-comment-ui/lib/index.css'
import '@univerjs-pro/boards-thread-comment-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.ES_ES, mergeLocales(SharedLocale, ProductLocale))
univer.registerPlugin(UniverBoardsThreadCommentPlugin)
univer.registerPlugin(UniverBoardsThreadCommentUIPlugin)
```

## Facade de comentarios [#comment-facade]

Importa la Facade común y la del producto. Los métodos del producto crean anclas estables; la API común gestiona respuestas, cambios, resolución y eliminación. `getComments()` lee el estado local. `listCommentsAsync()` sincroniza los hilos ya conocidos mediante la fuente configurada; no descubre todos los hilos del servidor.

```ts
import '@univerjs/thread-comment/facade'
import '@univerjs-pro/boards-thread-comment/facade'

const board = univerAPI.getActiveBoard()
if (board) {
  await board.createPositionCommentAsync({ x: 320, y: 180 }, 'Review this area.')
  console.log(await board.listCommentsAsync())
}
```

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## Conversaciones compartidas [#shared-discussions]

Integra Comment Service y Endpoint con [Server SDK](/server/collaboration/extensions) y registra `UniverThreadCommentDataSourcePlugin` de `@univerjs-pro/thread-comment-datasource` tras configurar la colaboración y la licencia. La fuente incluida usa `/universer-api/comment/unit/{unitId}/...` y `/universer-api/user/list`: expón esas rutas en la aplicación. El servidor debe autorizar la lectura y escritura de comentarios de forma independiente de la edición del documento.
