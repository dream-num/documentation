Зарегистрируйте плагины комментариев после того, как редактор продукта и конфигурация лицензии завершены, и загрузите общие и пользовательские стили продукта вместе с локальными ресурсами. Плагин продукта владеет своими ресурсами комментариев, поэтому он должен быть зарегистрирован до восстановления снимка.

```package-install
npm install @univerjs/thread-comment @univerjs/thread-comment-ui @univerjs-pro/boards-thread-comment @univerjs-pro/boards-thread-comment-ui
```

```ts
import { UniverBoardsThreadCommentPlugin } from '@univerjs-pro/boards-thread-comment'
import { UniverBoardsThreadCommentUIPlugin } from '@univerjs-pro/boards-thread-comment-ui'
import ProductLocale from '@univerjs-pro/boards-thread-comment-ui/locale/ru-RU'
import { LocaleType, mergeLocales } from '@univerjs/core'
import SharedLocale from '@univerjs/thread-comment-ui/locale/ru-RU'

import '@univerjs/thread-comment-ui/lib/index.css'
import '@univerjs-pro/boards-thread-comment-ui/lib/index.css'

univerAPI.loadLocales(LocaleType.RU_RU, mergeLocales(SharedLocale, ProductLocale))
univer.registerPlugin(UniverBoardsThreadCommentPlugin)
univer.registerPlugin(UniverBoardsThreadCommentUIPlugin)
```

## Поддержка мобильных устройств [#mobile-support]

Сначала настройте [Мобильный редактор](/guides/boards/getting-started/installation#mobile-support). В настройках плагин-режима, описанных на этой странице, замените регистрацию рабочего стола ниже на мобильный экспорт из тех же пакетов и сделайте это **Перед тем, как открыть документ**, сохраните плагины модели, стили, локализации и импорт Facade и не регистрируйте оба варианта.

| Пакет | Настольная регистрация | Мобильная регистрация |
| --- | --- | --- |
| `@univerjs-pro/boards-thread-comment-ui` | `UniverBoardsThreadCommentUIPlugin` | `UniverBoardsThreadCommentMobileUIPlugin` |

## Facade комментариев [#comment-facade]

Импорт совместного комментария Facade и продукта Facade до того, как эти методы будут названы. Помощники продукта создают стабильные якоря, а общий API обрабатывает ответы, обновления, разрешение и удаление. `getComments()` читает локальное состояние. `listCommentsAsync()` синхронизирует потоки, о которых он уже знает, через настроенный источник данных; он не обнаруживает каждый поток на сервере.

```ts
import '@univerjs/thread-comment/facade'
import '@univerjs-pro/boards-thread-comment/facade'

const board = univerAPI.getActiveBoard()
if (board) {
  await board.createPositionCommentAsync({ x: 320, y: 180 }, 'Review this area.')
  console.log(await board.listCommentsAsync())
}
```

```ts
import '@univerjs/thread-comment/facade'

const [thread] = univerAPI.getComments({ resolved: false })
if (thread) {
  await univerAPI.replyCommentAsync({
    unitId: thread.unitId,
    subUnitId: thread.subUnitId,
    threadId: thread.threadId,
    content: 'Reviewed.',
  })
}
```

## Общие обсуждения [#shared-discussions]

Для общих обсуждений интегрируйте Службу комментариев и конечную точку через [Server SDK](/server/collaboration/extensions), затем зарегистрируйте `UniverThreadCommentDataSourcePlugin` от `@univerjs-pro/thread-comment-datasource` после завершения конфигурации совместной работы и лицензии. Поставляемый источник данных вызывает `/universer-api/comment/unit/{unitId}/...` и `/universer-api/user/list`. Поэтому приложение должно раскрыть эти маршруты. Комментарии читают и пишут требуют собственных разрешений сервера; разрешения на редактирование документов их не покрывают.
