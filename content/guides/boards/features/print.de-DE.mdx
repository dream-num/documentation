---
title: Drucken
icon: '#pro/Printer'
---

Registrieren Sie `@univerjs-pro/boards-print`, um die aktive Board-Seite zu drucken oder als PNG beziehungsweise JPEG zu exportieren. Dieselben Aktionen stehen im Menüband zur Verfügung.

```ts
import { ExportBoardImageOperation, PrintBoardOperation, UniverBoardsPrintPlugin } from '@univerjs-pro/boards-print'

import '@univerjs-pro/boards-print/lib/index.css'

univer.registerPlugin(UniverBoardsPrintPlugin)

await univerAPI.executeCommand(PrintBoardOperation.id)
await univerAPI.executeCommand(ExportBoardImageOperation.id, { format: 'png' })
```

Fügen Sie `@univerjs-pro/boards-print/locale/<locale>` Ihrer Univer-Sprachkonfiguration hinzu, um die Beschriftungen im Menüband zu übersetzen.
