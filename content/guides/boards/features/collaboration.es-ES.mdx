Con la colaboración activada, varios usuarios pueden editar la misma tabla y ver los cambios de los demás. Siga [integración de la colaboración](/server/collaboration/browser-integration) para configurar el backend, autenticación, permisos y almacenamiento, a continuación, configure el [licencia](/server/license).

## Configurar y cargar un documento

Utilice el [Inicio rápido de la colaboración](/server/collaboration/quick-start) para agregar configuración de cliente de colaboración a un editor de juntas existentes. Ese ejemplo utiliza hojas de cálculo, por lo que el backend debe todavía crear y persistir un documento de las juntas y devolver su ID al navegador.

Establecer el usuario actual antes de cargar el documento. [Integración de la colaboración](/server/collaboration/browser-integration) describe el procedimiento.

```ts
import '@univerjs-pro/boards/facade'
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const document = await univerAPI.getCollaboration().loadBoardAsync('your-document-id')
if (!document) throw new Error('Document could not be loaded')
```

La reapertura o el intercambio del documento utiliza el mismo ID. No cree un documento en blanco local en lugar del documento del servidor.

Para los indicadores de ahorro y para proteger las ediciones que el servidor aún no ha reconocido antes de una recarga, véase [estado de sincronización, registros y recuperación de conflictos](/server/collaboration/browser-integration#sync-status).

## Eliminación de la carga integrada por URL de documentos colaborativos [#url-unit-loader-migration]

<Callout type="warning" title="Nota">
  Empezando con la versión **1.2.0**, Univer ya no carga documentos de colaboración desde la URL. Ya no lee los parámetros de URL `unit` y `type` automáticamente.
</Callout>

Si la aplicación depende de ese comportamiento, un plugin personalizado puede restaurarlo.

### Integrar el plugin personalizado

Copie los cuatro archivos abajo en el proyecto y mantenga la siguiente estructura del directorio:

```text
custom-url-load/
├── plugin.ts
├── controllers/
│   └── data-loader.controller.ts
└── services/
    ├── url.service.ts
    └── web-url.service.ts
```

Inicia el editor y los plugins de colaboración, establece el usuario actual, y luego regístrese `CustomUrlLoadPlugin`.

```ts
import { UserManagerService } from '@univerjs/core'
import { CustomUrlLoadPlugin } from './custom-url-load/plugin'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

univer.registerPlugin(CustomUrlLoadPlugin)
```

Una vez registrado, el plugin maneja la carga, por lo que `loadBoardAsync()` no es necesario para el mismo documento. Si la aplicación ya carga documentos a través de la Facade, mantenga el enfoque de la sección anterior y maneje URLs de acuerdo con los requisitos de la aplicación.

    import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
    import { CollaborationDataLoaderController } from './controllers/data-loader.controller'
    import { IURLService } from './services/url.service'
    import { WebURLService } from './services/web-url.service'

    @DependentOn(UniverCollaborationClientPlugin)
    export class CustomUrlLoadPlugin extends Plugin {
      static override pluginName = 'CUSTOM_URL_LOAD_PLUGIN'

      constructor(
        _config: undefined,
        @Inject(Injector) protected override readonly _injector: Injector
      ) {
        super()
      }

      override onStarting(): void {
        this._injector.add([IURLService, { useClass: WebURLService }])
        this._injector.add([CollaborationDataLoaderController])

        this.disposeWithMe(this._injector.get(IURLService))
        this.disposeWithMe(this._injector.get(CollaborationDataLoaderController))
      }
    }

    import { DataLoaderService } from '@univerjs-pro/collaboration-client'
    import { ILogService, Inject, RxDisposable } from '@univerjs/core'
    import { IURLService } from '../services/url.service'

    /**
     * Carga un documento colaborativo desde los parámetros de la URL.
     */
    export class CollaborationDataLoaderController extends RxDisposable {
      constructor(
        @IURLService private readonly _urlService: IURLService,
        @ILogService private readonly _logService: ILogService,
        @Inject(DataLoaderService) private readonly _dataLoaderService: DataLoaderService
      ) {
        super()

        const unitId = this._urlService.getParam('unit')
        const type = this._urlService.getParam('type')
        if (!unitId || !type) {
          return
        }

        this._dataLoaderService.loadUnit(unitId, Number(type))
          .catch((error: unknown) => {
            this._logService.error('[CollaborationDataLoaderController]', error)
          })
      }
    }

    import type { IURLService } from './url.service'
    import { RxDisposable } from '@univerjs/core'
    import { fromEvent, map, shareReplay, takeUntil } from 'rxjs'

    export class WebURLService extends RxDisposable implements IURLService {
      readonly urlChange$ = fromEvent(window, 'popstate').pipe(
        map(() => undefined),
        takeUntil(this.dispose$),
        shareReplay({ bufferSize: 1, refCount: true })
      )

      getParam(key: string): string | undefined {
        return new URL(window.location.href).searchParams.get(key) ?? undefined
      }

      setParam(key: string, value: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.set(key, value)
        this._updateUrl(url, useReplace)
      }

      removeParam(key: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.delete(key)
        this._updateUrl(url, useReplace)
      }

      private _updateUrl(url: URL, useReplace: boolean): void {
        if (useReplace) {
          window.history.replaceState(window.history.state, '', url.toString())
        } else {
          window.history.pushState(window.history.state, '', url.toString())
        }
      }
    }

## Verificar la sincronización y los permisos

Abra el mismo ID en dos sesiones separadas del navegador. Edite texto o mueva un elemento en una sesión, luego compruebe el otro. Confirme que el contenido sobrevive reloads de página, reconexiones y un reinicio de servicio. Utilice el espectador y las cuentas no autorizadas para confirmar que el servidor rechaza escribe y lee que sus permisos prohíben.

La colaboración no permite [Editar historia](/guides/boards/features/edit-history) o [Importación y exportación](/guides/boards/features/import-export); cada una requiere configuración separada.
