## What is Univer Boards

Univer Boards is the canvas product in Univer SDK Pro. It is used when the document is no longer a grid, a page, or a slide deck, but a free-form workspace: whiteboards, diagrams, sticky notes, connectors, embedded tables, and mind maps all belong here.

Boards is implemented as an independent Univer SDK unit type. At runtime you create a `UniverInstanceType.UNIVER_BOARD` unit, then register the model and UI plugins you need for the elements you want to support.


## Browser Compatibility

Univer SDK is compiled with a target of Chrome 88, but this does not mean it fully supports all mainstream environments. We strive to ensure Univer SDK works well in the following browsers and Node.js environments:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK relies on `Intl.Segmenter`. If your browser or runtime environment does not support it, please add a
  corresponding polyfill first. We recommend using `@formatjs/intl-segmenter`.
</Callout>

If you encounter compatibility issues, please first try to resolve them using the appropriate polyfills. If the issue persists, feel free to [submit an issue](https://github.com/dream-num/univer/issues/new/choose).

## Node.js Compatibility

<Callout type="warning">
  Note: This only applies to running Univer SDK in a Node.js environment and does not apply to cases where Univer SDK is run in
  a browser using build tools based on Node.js.
</Callout>

Univer SDK can run in a Node.js environment, supporting versions v18.17.0 and later.

## Highlights

- **Pages and element ordering**: Store pages in `pages` and drawable objects in each page's `elements`, with explicit order arrays for both levels.
- **Canvas elements**: Work with text, shapes, images, connectors, groups, containers, and swimlanes.
- **Command-driven editing**: Route element changes, ordering, and parent relationships through one command layer with permissions and hooks for optional history and collaboration integrations.
- **Browser canvas**: Render elements and provide selection, transforms, clipboard, text editing, viewport controls, and panels.
- **Extensible adapters**: Add optional Board capabilities such as tables, mind maps, charts, resources, print, and exchange.
- **Persistence**: Create, restore, and save an `IBoardData` snapshot, including pages, resources, themes, and active-page state.

## Pre-Requisite Knowledge

Although our docs are designed to be beginner-friendly, we need to establish a baseline so that the docs can stay focused on Univer SDK.

To get the most out of our docs, it’s recommended that you have a basic understanding of JavaScript and its ecosystem.

If you are interested in running Univer SDK on Node.js, you should also have a basic understanding of Node.js.

If you would like to try Univer SDK Pro and deploy Univer Server, we recommend that you have a basic understanding of Linux, Docker and Docker Compose (or Kubernetes).
