## What is Univer Boards

Univer Boards is the canvas product in Univer Pro. It is used when the document is no longer a grid, a page, or a slide deck, but a free-form workspace: whiteboards, diagrams, sticky notes, connectors, embedded tables, and mind maps all belong here.

Boards is implemented as an independent Univer unit type. At runtime you create a `UniverInstanceType.UNIVER_BOARD` unit, then register the model and UI plugins you need for the elements you want to support.

## When to use Boards

Use Boards when your application needs a large canvas where users arrange content spatially. Typical examples include brainstorming boards, flowcharts, planning maps, team retrospectives, and product diagrams. If your main object is tabular data, start with [Univer Bases](/guides/bases). If it is a spreadsheet, start with [Univer Sheets](/guides/sheets).

## Install packages

The core Board runtime is split into a model package and UI package. Table and mind-map elements are optional packages layered on top of the Board runtime.

```bash
pnpm add @univerjs-pro/boards @univerjs-pro/boards-ui
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

## Package map

- `@univerjs-pro/boards`: board data model, element schema, commands, mutations, adapter services, facade entry, and `UniverBoardsPlugin`
- `@univerjs-pro/boards-ui`: board canvas UI, viewport, selection, shape editing, connectors, sticky notes, ink interaction, toolbar, context menu, and `UniverBoardsUIPlugin`
- `@univerjs-pro/boards-table`: board table element integration and `UniverBoardsTablePlugin`
- `@univerjs-pro/boards-table-ui`: table element UI, render integration, locale entry points, and `UniverBoardsTableUIPlugin`
- `@univerjs-pro/boards-mind`: mind map element integration and `UniverBoardsMindPlugin`
- `@univerjs-pro/boards-mind-ui`: mind map UI integration and `UniverBoardsMindUIPlugin`

## Register plugins

The snippet below shows the Board-specific part of the setup. A complete application also needs the shared Univer core, render engine, UI, license, and ink plugins.

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/boards/facade'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})
```
