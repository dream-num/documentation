## Was ist Univer Boards

Univer Boards ist das Canvas-Produkt in Univer Pro. Es wird verwendet, wenn es sich bei dem Dokument nicht mehr um ein Raster, eine Seite oder ein Foliendeck, sondern um einen Freiform-Arbeitsbereich handelt: Whiteboards, Diagramme, Haftnotizen, Anschlüsse, eingebettete Tabellen und Mindmaps gehören hierher.

Boards ist als unabhängiger Univer-Einheitentyp implementiert. Zur Laufzeit erstellen Sie eine `UniverInstanceType.UNIVER_BOARD`-Einheit und registrieren dann das Modell und die UI-Plugins, die Sie für die Elemente benötigen, die Sie unterstützen möchten.

## Wann Sie Boards verwenden

Verwenden Sie Boards, wenn Ihre Anwendung eine große Leinwand benötigt, auf der Benutzer Inhalte räumlich anordnen. Typische Beispiele sind Brainstorming-Boards, Flussdiagramme, Planungskarten, Team-Retrospektiven und Produktdiagramme. Wenn Ihr Hauptobjekt tabellarische Daten sind, beginnen Sie mit [Univer Bases](/guides/bases). Wenn es sich um eine Tabellenkalkulation handelt, beginnen Sie mit [Univer Sheets](/guides/sheets).

## Pakete installieren

Die Kern-Board-Laufzeit ist in ein Modellpaket und ein UI-Paket aufgeteilt. Tabellen- und Mindmap-Elemente sind optionale Pakete, die über der Board-Laufzeit liegen.

```bash
pnpm add @univerjs-pro/boards @univerjs-pro/boards-ui
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

## Paketzuordnung

- `@univerjs-pro/boards`: Board-Datenmodell, Elementschema, Befehle, Mutationen, Adapterdienste, Fassadeneintrag und `UniverBoardsPlugin`
- `@univerjs-pro/boards-ui`: Board-Canvas-Benutzeroberfläche, Ansichtsfenster, Auswahl, Formbearbeitung, Anschlüsse, Haftnotizen, Tinteninteraktion, Symbolleiste, Kontextmenü und `UniverBoardsUIPlugin`
- `@univerjs-pro/boards-table`: Board-Tabellenelement-Integration und `UniverBoardsTablePlugin`
- `@univerjs-pro/boards-table-ui`: Tabellenelement-Benutzeroberfläche, Render-Integration, Gebietsschema-Einstiegspunkte und `UniverBoardsTableUIPlugin`
- `@univerjs-pro/boards-mind`: Mindmap-Elementintegration und `UniverBoardsMindPlugin`
- `@univerjs-pro/boards-mind-ui`: Mindmap-UI-Integration und `UniverBoardsMindUIPlugin`

## Plugins registrieren

Der folgende Ausschnitt zeigt den Board-spezifischen Teil des Setups. Eine vollständige Anwendung benötigt außerdem den gemeinsamen Univer-Kern, die Render-Engine, die Benutzeroberfläche, die Lizenz und die Ink-Plugins.

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/boards/facade'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})
```
