## Qu’est-ce qu’Univer Boards ?

Univer Boards est le produit en toile de Univer Office SDK. Il est utilisé lorsqu'un document n'est plus une grille, une page ou une planche à diapositives, mais un espace de travail en forme libre : tableaux blancs, diagrammes, notes collantes, connecteurs, tables intégrées et cartes mentales.

Les cartes utilisent [Web SDK](/guides/sheets) pour les toiles intégrées dans le navigateur, et Web SDK gère également le traitement de contenu sans tête. [Server SDK](/server) fournit la collaboration et l'échange de fichiers, et [AI SDK](/ai) permet à un agent de modifier une carte.

Boards est un type d'unité indépendant dans Web SDK. Au moment de l'exécution, une application crée une unité `UniverInstanceType.UNIVER_BOARD` et enregistre ensuite les plugins modèle et UI pour les éléments dont elle a besoin pour prendre en charge.

## Compatibilité avec les navigateurs

Web SDK compile vers une cible Chrome 88. Cette cible n'implique pas que Web SDK fonctionne dans chaque environnement. Les navigateurs suivants et les environnements Node.js sont pris en charge:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK s'appuie sur `Intl.Segmenter`. Si le navigateur ou l'environnement d'exécution ne le supporte pas, ajoutez d'abord le polyfill correspondant. Le polyfill recommandé est `@formatjs/intl-segmenter` .
</Callout>

Si un problème de compatibilité survient, appliquez d'abord le polyfill correspondant. Si le problème persiste, [soumettre un problème](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilité avec Node.js

<Callout type="warning">
  Cette section couvre l'exécution de Web SDK dans Node.js seulement. Elle ne s'applique pas lorsque Web SDK fonctionne dans un navigateur via des outils de construction basés sur Node.js.
</Callout>

Web SDK fonctionne dans Node.js v18.17.0 et plus tard.

## Points forts

- **Pages et commande d'éléments** : pages stockées dans `pages` et objets dessinables stockés dans le `elements` de chaque page, avec un tableau d'ordre explicite aux deux niveaux.
- **Éléments de toile**: texte, formes, images, connecteurs, groupes, conteneurs et nageuses.
- **Révision par commande** : changements d'éléments, commande et relations parent via une couche de commande qui porte des permissions et des crochets pour les intégrations optionnelles d'historique et de collaboration.
- **La toile du navigateur**: rendu d'éléments, sélection, transformations, presse-papiers, édition de texte, commandes de viewport et panneaux.
- **Adaptateurs extensibles**: capacités optionnelles de la carte telles que les tables, les cartes mentales, les graphiques, les ressources, l'impression et l'échange.
- **Persistance** : création, restauration et sauvegarde d'un instantané `IBoardData`, incluant pages, ressources, thèmes et état de page active.

## Comment lire la documentation

Le navbar de gauche énumère les pages dans l'ordre, de basique à avancé, afin que les lecteurs puissent les suivre étape par étape pendant la construction d'une application. Les pages peuvent être lues dans n'importe quel ordre, et les pages qui ne s'appliquent pas au cas d'utilisation peuvent être ignorées. L'en-tête de la barre latérale fournit un commutateur à la documentation Univer Boards.

La table des matières de droite permet de naviguer entre les sections de la page actuelle. Pour localiser rapidement une page, utilisez la barre de recherche en haut ou le raccourci de recherche (Ctrl+K ou Cmd+K).

Pour commencer, consultez le guide [Démarrage rapide](/guides/boards/getting-started/installation).

## Connaissances préalables

La documentation est écrite pour les nouveaux arrivants, mais elle suppose des connaissances de base afin qu'elle puisse rester concentrée sur Web SDK.

Les lecteurs tirent le meilleur parti de la documentation avec une compréhension de base de JavaScript et de son écosystème.

Si Web SDK doit fonctionner sur Node.js, une compréhension de base de Node.js est également recommandée.

Lorsque plusieurs personnes éditent le même forum, ou partagent l'historique, les commentaires ou la conversion de fichiers sont nécessaires, ajoutez les modules correspondants de [Univer Server SDK](/server) et exécutez-les dans le moteur d'application. L'authentification, les autorisations, le stockage et le déploiement restent la responsabilité de l'application. Un forum qui ouvre seulement dans le navigateur n'exige pas ces services.

## Étendre Univer Boards

Web SDK est construit pour être étendu, de sorte qu'il peut être adapté à l'application en cours de construction.
