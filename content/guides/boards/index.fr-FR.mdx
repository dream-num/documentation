## Qu'est-ce qu'Univer Boards ?

Univer Boards est le produit de création sur canevas d'Univer Pro. Il convient lorsque le document n'est plus une grille, une page ou un diaporama, mais un espace de travail libre : tableaux blancs, diagrammes, notes adhésives, connecteurs, tableaux intégrés et cartes mentales y trouvent tous leur place.

Boards est implémenté comme un type d'unité Univer indépendant. Lors de l'exécution, créez une unité `UniverInstanceType.UNIVER_BOARD`, puis enregistrez les plugins de modèle et d'interface utilisateur nécessaires aux éléments que vous souhaitez prendre en charge.

## Quand utiliser Boards

Utilisez Boards si votre application nécessite un grand canevas sur lequel les utilisateurs peuvent organiser librement le contenu. Les tableaux de brainstorming, organigrammes, plans de projet, rétrospectives d'équipe et diagrammes de produit en sont des exemples courants. Si votre objet principal est constitué de données tabulaires, commencez par [Univer Bases](/guides/bases). S'il s'agit d'une feuille de calcul, commencez par [Univer Sheets](/guides/sheets).

## Installer les packages

L'environnement d'exécution principal de Board est divisé en un package de modèle et un package d'interface utilisateur. Les éléments de tableau et de carte mentale sont fournis par des packages facultatifs qui viennent compléter cet environnement.

```bash
pnpm add @univerjs-pro/boards @univerjs-pro/boards-ui
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

## Vue d'ensemble des packages

- `@univerjs-pro/boards` : modèle de données Board, schéma des éléments, commandes, mutations, services d'adaptation, point d'entrée de la façade et `UniverBoardsPlugin`
- `@univerjs-pro/boards-ui` : interface utilisateur du canevas Board, zone d'affichage, sélection, modification des formes, connecteurs, notes adhésives, interactions à main levée, barre d'outils, menu contextuel et `UniverBoardsUIPlugin`
- `@univerjs-pro/boards-table` : intégration des éléments de tableau dans Board et `UniverBoardsTablePlugin`
- `@univerjs-pro/boards-table-ui` : interface utilisateur des éléments de tableau, intégration du rendu, points d'entrée des locales et `UniverBoardsTableUIPlugin`
- `@univerjs-pro/boards-mind` : intégration des éléments de carte mentale et `UniverBoardsMindPlugin`
- `@univerjs-pro/boards-mind-ui` : intégration de l'interface utilisateur des cartes mentales et `UniverBoardsMindUIPlugin`

## Enregistrer les plugins

L'extrait ci-dessous présente uniquement la partie de la configuration propre à Board. Une application complète nécessite également les plugins partagés pour le cœur d'Univer, le moteur de rendu, l'interface utilisateur, la licence et la saisie à main levée.

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/boards/facade'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})
```
