`@univerjs-pro/boards-ui`는 보드 캔버스를 위한 브라우저 UI를 제공합니다. 메인 장면, 선택 오버레이, 뷰포트 상호작용, 도구 모음, 컨텍스트 메뉴, 텍스트 편집, 도형 편집, 커넥터 편집 및 선택적 요소 UI 통합을 렌더링합니다.

## 필수 런타임

브라우저 보드 편집기에서는 Board UI 플러그인보다 먼저 공용 UI 및 렌더링 플러그인이 필요합니다.

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverDrawingUIPlugin)
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

## 워크벤치 옵션

`IUniverBoardsUIConfig.workbench`는 Univer 워크벤치에서 Board UI가 담당할 영역을 제어합니다.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

탐색 기능이나 도구 모음을 이미 제공하는 애플리케이션 셸에 Boards를 임베드할 때 사용하세요.

## 상호작용 옵션

`interaction` 설정은 확대/축소 범위, 휠 동작, 맞춤 안내선, 간격 안내선, 크기 조절 핸들 및 삽입 대기 미리보기를 제어합니다.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```
