`@univerjs-pro/boards-ui`는 라이선스가 필요한 Univer Boards 브라우저 캔버스를 제공합니다. 장면, 선택 및 뷰포트 상호 작용, 도구 모음, 컨텍스트 메뉴, 텍스트, 도형, 커넥터와 지원되는 Board 요소의 편집 UI를 렌더링합니다.

## Board UI 등록

Board 플러그인보다 먼저 `UniverLicensePlugin`을 구성합니다. Docs, Drawing, Ink, Shape Editor는 기술적 렌더링 및 편집 종속성이므로 해당 제품을 미리 알 필요가 없습니다.

`UniverLicensePlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `license` | `string` |  | 클라이언트 라이선스 파일의 내용입니다. |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```

전체 종속성, 스타일, 로케일 등록 순서는 [설치 및 기본 사용법](/guides/boards/getting-started/installation)을 참고하세요.

## 캔버스 옵션

`IUniverBoardsUIConfig`는 그리드, 삽입 기본값, 도형과 스티커 메모 색상, 도구, 뷰포트 바, 렌더 어댑터, 빠른 추가, 정밀 선택, 치수 표시, 공동 작업 커서도 제어합니다.

## 메뉴 설정과 캔버스 도구 모음 [#menu-configuration]

시작할 때 [컨텍스트 메뉴와 캔버스 도구를 설정](/guides/boards/features/core#menu-order-and-grid-layout)합니다. 편집기 시작 후에는 [메뉴 Facade API](/guides/boards/features/core#menu-facade)로 컨텍스트 메뉴를 변경합니다.
