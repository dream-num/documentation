ボードは、色、フォント、塗りつぶしスタイル、線のスタイル、効果、背景スタイルのテーマデータに対応しています。テーマデータはボードのスナップショットに保存され、ボードの Facade を通じて更新できます。

## テーマを適用する

```ts
const board = univerAPI.getActiveBoard()

await board.setTheme({
  id: 'brand-theme',
  name: 'Brand Theme',
  colorScheme: {
    accent1: '#2563eb',
    accent2: '#16a34a',
    dk1: '#111827',
    lt1: '#ffffff',
  },
  fontScheme: {
    heading: 'Inter',
    body: 'Inter',
  },
})
```

## テーマデータを取得する

```ts
const theme = board.getThemeData()
```

## スナップショットのフィールド

| フィールド | 説明 |
| --- | --- |
| `theme` | ボードで現在使用されているテーマ。 |
| `themes` | ID をキーとする、名前付きの追加テーマ。 |
| `colorScheme` | 要素やスタイルで使用されるセマンティックカラートークン。 |
| `fontScheme` | 見出しと本文のフォントファミリー。 |
| `fmtScheme` | 塗りつぶし、線、効果、背景のスタイル一覧。 |
