`@univerjs-pro/boards-ui` stellt die Browser-Benutzeroberfläche für die Board-Leinwand bereit. Es rendert die Hauptszene, die Auswahlüberlagerung, die Interaktion mit dem Ansichtsfenster, Symbolleisten, Kontextmenüs, Textbearbeitung, Formbearbeitung, Verbindungsbearbeitung und optionale Element-UI-Integrationen.

## Erforderliche Laufzeit

Ein Browser-Board-Editor benötigt die gemeinsame Benutzeroberfläche und Render-Plugins vor dem Board-UI-Plugin:

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverDrawingUIPlugin)
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

## Workbench-Optionen

`IUniverBoardsUIConfig.workbench` steuert, welche Teile der Univer-Workbench die Board-UI verwenden besitzt.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

Verwenden Sie dies, wenn Sie Boards in eine Anwendungs-Shell einbetten, die bereits Navigation oder Symbolleisten bereitstellt.

## Interaktionsoptionen

`interaction`-Konfiguration steuert Zoomgrenzen, Radverhalten, Ausrichtungshilfen, Abstandshilfen, Größenänderungsgriffe und ausstehende Einfügevorschauen.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```
