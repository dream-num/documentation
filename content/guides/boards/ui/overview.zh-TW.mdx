`@univerjs-pro/boards-ui` 提供 Univer Boards 的授權版瀏覽器畫布。它負責算繪場景、選取範圍與檢視區互動、工具列、內容選單、文字編輯、形狀編輯、連接線編輯，以及支援的 Board 元素類型 UI。

## 註冊 Board UI

請在 Board 外掛程式前設定 `UniverLicensePlugin`。Docs、Drawing、Ink 和 Shape Editor 套件是技術算繪與編輯相依套件；使用 Boards 不要求你瞭解這些品類。

`UniverLicensePlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 用戶端授權檔的內容。 |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```

完整的相依套件、樣式和語言套件註冊順序請參閱[安裝與基本使用](/guides/boards/getting-started/installation)。

## 畫布選項

`IUniverBoardsUIConfig` 也控制網格外觀、插入預設值、可用形狀與便利貼顏色、工具列工具、檢視區捲軸、算繪配接器，以及快速新增、精確選取、尺寸提示和協作游標等設定。

## 選單設定與畫布工具列 [#menu-configuration]

啟動時可[設定右鍵選單與畫布工具](/guides/boards/features/core#menu-order-and-grid-layout)。編輯器啟動後，使用[選單 Facade API](/guides/boards/features/core#menu-facade)更新右鍵選單。
