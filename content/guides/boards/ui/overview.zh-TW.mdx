`@univerjs-pro/boards-ui` 提供 Board 畫布的瀏覽器 UI。它會算繪主場景、選取範圍覆蓋層、視埠互動、工具列、快顯功能表、文字編輯、圖形編輯、連接線編輯，以及選用的元素 UI 整合功能。

## 必要的執行環境

在瀏覽器中使用 Board 編輯器時，必須先載入共用 UI 與算繪外掛程式，再載入 Board UI 外掛程式：

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverDrawingUIPlugin)
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

## 工作台選項

`IUniverBoardsUIConfig.workbench` 控制 Univer 工作台中由 Board UI 負責的區域。

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

若要將 Boards 嵌入已提供導覽或工具列的應用程式外殼，請使用此設定。

## 互動選項

`interaction` 設定可控制縮放限制、滾輪行為、對齊參考線、間距參考線、調整大小控點，以及待插入元素的預覽。

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```
