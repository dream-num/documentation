Los tableros admiten datos de temas para colores, fuentes, estilos de relleno, estilos de línea, efectos y fondo. estilos. Los datos del tema se almacenan en la instantánea del tablero y se pueden actualizar a través de la fachada del tablero.

## Aplicar un tema

```ts
const board = univerAPI.getActiveBoard()

await board.setTheme({
  id: 'brand-theme',
  name: 'Brand Theme',
  colorScheme: {
    accent1: '#2563eb',
    accent2: '#16a34a',
    dk1: '#111827',
    lt1: '#ffffff',
  },
  fontScheme: {
    heading: 'Inter',
    body: 'Inter',
  },
})
```

## Leer datos del tema

```ts
const theme = board.getThemeData()
```

## Campos de instantáneas

| Campo | Descripción |
| --- | --- |
| `theme` | Tema actual utilizado por el Tablero. |
| `themes` | Temas con nombre adicionales codificados por ID. |
| `colorScheme` | Tokens de color semánticos utilizados por elementos y estilos. |
| `fontScheme` | Familias de fuentes para encabezados y cuerpos. |
| `fmtScheme` | Listas de estilos de relleno, trazo, efectos y fondo. |
