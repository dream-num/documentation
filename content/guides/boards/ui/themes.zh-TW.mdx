如需設定應用程式配色與深色模式，請參閱[主題與深色模式](/guides/fundamentals/ui/themes)。

畫板支援顏色、字型、填滿樣式、線條樣式、效果及背景樣式等主題資料。主題資料儲存在畫板快照中，並可透過畫板 Facade 更新。

## 套用主題

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

// Theme ids come from Board presets or host theme registration.
if (!board.setTheme('brand-theme')) throw new Error('Cannot apply Board theme')
```

## 讀取主題資料

```ts
const theme = board.getThemeData()
```

## 快照欄位

| 欄位          | 說明                               |
| ------------- | ---------------------------------- |
| `theme`       | 畫板目前使用的主題。               |
| `themes`      | 以識別碼為索引鍵的其他具名主題。   |
| `colorScheme` | 元素與樣式所使用的語意化色彩權杖。 |
| `fontScheme`  | 標題與內文字型。                   |
| `fmtScheme`   | 填滿、描邊、效果及背景樣式清單。   |
