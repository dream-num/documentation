`@univerjs-pro/boards-ui` fournit le canevas sous licence de Univer Boards dans le navigateur. Il affiche la scène, les interactions de sélection et de viewport, les barres d’outils, les menus contextuels, ainsi que l’édition du texte, des formes, des connecteurs et des types d’éléments pris en charge.

## Enregistrer l’interface Board

Configurez `UniverLicensePlugin` avant les plugins Board. Docs, Drawing, Ink et Shape Editor sont des dépendances techniques de rendu et d’édition ; utiliser Boards ne demande aucune connaissance préalable de ces produits.

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```

Consultez [Installation et utilisation de base](/guides/boards/getting-started/installation) pour l’ordre complet des dépendances, styles et langues.

## Options du canevas

`IUniverBoardsUIConfig` contrôle aussi la grille, les valeurs d’insertion, les formes et couleurs de notes, les outils, les barres du viewport, les adaptateurs de rendu, l’ajout rapide, la sélection précise, les dimensions et les curseurs de collaboration.
