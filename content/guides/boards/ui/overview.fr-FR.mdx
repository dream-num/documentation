## Système de design

Le système de design d’Univer repose sur Tailwind CSS. Il définit un ensemble de design tokens qui sont réutilisés par le moteur de rendu afin de garantir la cohérence des styles entre ce dernier et la couche de présentation. Vous pouvez personnaliser les styles de votre application en modifiant ces tokens, qui se trouvent dans le package `@univerjs/themes`.



## Composants

Univer utilise des composants React pour construire la couche de présentation. Les développeurs qui utilisent également React peuvent ainsi très facilement employer les composants d’Univer ou enregistrer leurs propres composants. Cela ne signifie toutefois pas que React est le seul moyen de créer des composants personnalisés : Univer prend aussi en charge d’autres technologies, telles que Vue (version 3.x) et les Web Components.

Tous les composants de base se trouvent dans le package `@univerjs/design`, tandis que les composants d’icônes sont regroupés dans le package `@univerjs/icons`. Ces composants peuvent également être utilisés indépendamment d’Univer.

Les composants personnalisés sont souvent utilisés dans les cas suivants :

- Ajout de boutons personnalisés dans le Ribbon / Context Menu
- Intégration de composants personnalisés dans la Sidebar / Popup, etc.
- Remplacement des composants intégrés

Les chapitres suivants expliquent en détail comment enregistrer et utiliser des composants personnalisés.


`@univerjs-pro/boards-ui` fournit l'interface utilisateur du canevas Board dans le navigateur. Il prend en charge la scène principale, la superposition de sélection, les interactions avec la zone d'affichage, les barres d'outils, les menus contextuels, la modification du texte, des formes et des connecteurs, ainsi que les intégrations facultatives de l'interface utilisateur pour les éléments.

## Environnement d'exécution requis

Un éditeur Board exécuté dans un navigateur nécessite les plugins partagés d'interface utilisateur et de rendu avant le plugin d'interface utilisateur de Board :

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverDrawingUIPlugin)
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

## Options du plan de travail

`IUniverBoardsUIConfig.workbench` détermine les parties du plan de travail Univer prises en charge par l'interface utilisateur de Board.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

Utilisez cette configuration lorsque vous intégrez Boards dans une structure d'application qui fournit déjà la navigation ou les barres d'outils.

## Options d'interaction

La configuration `interaction` contrôle les limites de zoom, le comportement de la molette, les guides d'alignement et d'espacement, les poignées de redimensionnement et les aperçus d'insertion en attente.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```
