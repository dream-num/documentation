ボードは、ボードのデータでフォントの選択肢を保存します。ボードのテーマは、`fontScheme.heading`と`fontScheme.body`を定義することができ、個々のテキスト要素は、フォントファミリー、フォントサイズ、および`textStyle`に重点を置くことができます。

## テキスト要素のフォントを設定する

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const label = board.insertText({
  text: 'Milestone',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

ボードテキスト編集は、Docs UI と共有されるテキストパイプラインを使用しており、これは `@univerjs-pro/boards-ui` の技術的な依存関係です。 ボードのレンダリングの前に、ホストページ内の任意のWebフォントをロードします。 それ以外の場合は、ブラウザは既に利用可能なフォントを置換し、テキストメトリックが変更されることがあります。

アプリケーション全体のテーマについては、[テーマとダークモード](/guides/boards/ui/themes)を参照してください。 ボード文書のテーマは、ボードスナップショットの一部のままです。
