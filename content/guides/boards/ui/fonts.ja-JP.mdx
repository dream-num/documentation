Boards use the shared Univer document and UI font pipeline for rich text, text boxes, and shape text. Register Docs UI and shared UI plugins before `UniverBoardsUIPlugin` so text editing has the required services.

## Configure theme fonts

The Board theme can define heading and body font families:

```ts
await board.setTheme({
  name: 'Internal Theme',
  fontScheme: {
    heading: 'Inter',
    body: 'Inter',
  },
})
```

## Text element fonts

Text elements can also carry explicit text style:

```ts
await board.addElement({
  id: 'label-1',
  type: 'text',
  transform: { left: 120, top: 96, width: 240, height: 64 },
  text: 'Milestone',
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
}, { pageId })
```

Load web fonts in the host application before rendering the Board to avoid layout shifts.
