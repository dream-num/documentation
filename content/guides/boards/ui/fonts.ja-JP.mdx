ボードでは、リッチテキスト、テキストボックス、図形内のテキストに、Univer のドキュメントと UI で共通のフォント処理基盤を使用します。テキスト編集に必要なサービスを利用できるように、Docs UI プラグインと共有 UI プラグインを `UniverBoardsUIPlugin` より先に登録してください。

## テーマのフォントを設定する

ボードのテーマでは、見出しと本文のフォントファミリーを定義できます。

```ts
const currentThemeId = board.getThemeData().id
if (!currentThemeId || !board.setTheme(currentThemeId)) {
  throw new Error('Cannot apply Board theme')
}
```

## テキスト要素のフォント

テキスト要素には、明示的なテキストスタイルも設定できます。

```ts
const label = board.insertText({
  id: 'label-1',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  text: 'Milestone',
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

レイアウトのずれを防ぐため、ボードをレンダリングする前に、ホストアプリケーションで Web フォントを読み込んでください。
