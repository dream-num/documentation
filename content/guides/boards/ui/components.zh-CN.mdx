`@univerjs-pro/boards-ui` 导出 Board 画布使用的组件和扩展服务。它们需要已初始化的 Univer 依赖注入环境和 Board 单元，不是独立的设计系统组件。

## 公开的画布组件

```ts
import {
  BoardShapeTextEditorContainer,
  BoardWorkbench,
} from '@univerjs-pro/boards-ui'
```

插件会在内部注册形状和连接线浮动工具栏。应用应使用受支持的服务，不要替换私有组件键。

## 支持的扩展点

- `IBoardToolbarContributionService` 向 Board 工具栏添加创建或辅助操作。
- `IBoardSettingsMenuContributionService` 向设置菜单添加操作、导入或输出项。
- `IBoardSidePanelService` 打开 Board 侧边面板并返回可释放句柄。
- `additionalRenderAdapters` 在不替换内置 `BOARD_ELEMENT_RENDER_ADAPTERS` 列表的情况下添加渲染器。
- `registerBoardDocumentTextExtension` 扩展 Board 文档文本的渲染。

主插件移除时请释放每项注册。
