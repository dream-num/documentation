`@univerjs-pro/boards-ui` 导出 Board 画布所使用的组件和扩展服务。这些组件需要已初始化的 Univer 依赖注入环境和 Board 单元；它们不是独立的设计系统组件。

## 公开的画布组件

```ts
import {
  BoardShapeTextEditorContainer,
  BoardWorkbench,
} from '@univerjs-pro/boards-ui'
```

形状和连接线的浮动工具栏由插件自行注册。请使用受支持的服务，不要替换私有的组件键。

## 支持的扩展点

- `IBoardToolbarContributionService` 向 Board 工具栏添加创建或辅助操作。
- `IBoardSettingsMenuContributionService` 向设置菜单添加操作、导入或输出项。
- `IBoardSidePanelService` 打开 Board 侧边面板，并返回一个可释放的句柄。
- `additionalRenderAdapters` 添加渲染器，但不替换内置的 `BOARD_ELEMENT_RENDER_ADAPTERS` 列表。
- `registerBoardDocumentTextExtension` 扩展 Board 文档文本的渲染。

主插件移除时，应释放每一项注册。
