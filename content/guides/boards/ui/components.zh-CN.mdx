画板 UI 由渲染控制器、菜单、浮动工具栏、画布弹出层和工作台部件组成。大多数应用只需注册 `UniverBoardsUIPlugin`，即可使用默认组件。

## 自定义工作台可见区域

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

## 自定义工具栏工具

通过 `toolbar.tools` 可以禁用默认工具栏中的画板工具，或修改其标签。

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: {
    tools: {
      connector: { enabled: true, label: 'Connector' },
      pen: false,
    },
  },
})
```

## 扩展元素渲染

如果应用引入了自定义画板元素类型，或需要覆盖某个元素的绘制方式，请使用 `additionalRenderAdapters`。

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  additionalRenderAdapters: [customAdapter],
})
```
