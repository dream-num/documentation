有关应用配色和暗黑模式，请参阅[主题与暗黑模式](/guides/fundamentals/ui/themes)。

画板主题数据包括颜色、字体、填充样式、线条样式、效果和背景样式。主题数据存储在画板快照中，可以通过画板 Facade 更新。

## 应用主题

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

// Theme ids come from Board presets or host theme registration.
if (!board.setTheme('brand-theme')) throw new Error('Cannot apply Board theme')
```

## 读取主题数据

```ts
const theme = board.getThemeData()
```

## 快照字段

| 字段          | 说明                             |
| ------------- | -------------------------------- |
| `theme`       | 画板当前使用的主题。             |
| `themes`      | 以 ID 为键的其他命名主题。       |
| `colorScheme` | 元素和样式使用的语义化颜色令牌。 |
| `fontScheme`  | 标题和正文字体。                 |
| `fmtScheme`   | 填充、描边、效果和背景样式列表。 |
