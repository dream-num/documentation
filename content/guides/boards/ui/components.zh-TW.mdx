`@univerjs-pro/boards-ui` 匯出 Board 畫布使用的元件和擴充服務。它們需要已初始化的 Univer 相依注入環境和 Board 單元，不是獨立的設計系統元件。

## 公開的畫布元件

```ts
import {
  BoardShapeTextEditorContainer,
  BoardWorkbench,
} from '@univerjs-pro/boards-ui'
```

外掛程式會在內部註冊形狀和連接線浮動工具列。應用程式應使用支援的服務，不要替換私有元件鍵。

## 支援的擴充點

- `IBoardToolbarContributionService` 向 Board 工具列加入建立或輔助動作。
- `IBoardSettingsMenuContributionService` 向設定選單加入動作、匯入或輸出項目。
- `IBoardSidePanelService` 開啟 Board 側邊面板並傳回可釋放控制代碼。
- `additionalRenderAdapters` 在不替換內建 `BOARD_ELEMENT_RENDER_ADAPTERS` 清單的情況下加入算繪器。
- `registerBoardDocumentTextExtension` 擴充 Board 文件文字的算繪。

移除主外掛程式時請釋放每項註冊。
