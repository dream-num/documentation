畫板 UI 由算繪控制器、選單、浮動工具列、畫布彈出視窗及工作區元件所構成。大多數應用程式會註冊 `UniverBoardsUIPlugin` 來使用預設元件。

## 自訂工作區的顯示狀態

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

## 自訂工具列工具

`toolbar.tools` 可停用預設工具列提供的畫板工具，或變更其標籤。

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: {
    tools: {
      connector: { enabled: true, label: 'Connector' },
      pen: false,
    },
  },
})
```

## 擴充元素算繪

當應用程式加入自訂畫板元素類型，或需要覆寫元素的繪製方式時，請使用 `additionalRenderAdapters`。

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  additionalRenderAdapters: [customAdapter],
})
```
