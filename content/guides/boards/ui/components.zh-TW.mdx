`@univerjs-pro/boards-ui` 匯出 Board 畫布所使用的元件和擴充套件服務。這些元件需要已初始化的 Univer 依賴注入環境和 Board 單元；它們不是獨立的設計系統元件。

## 公開的畫布元件

```ts
import {
  BoardShapeTextEditorContainer,
  BoardWorkbench,
} from '@univerjs-pro/boards-ui'
```

形狀和連線線的浮動工具欄由外掛自行註冊。請使用受支援的服務，不要替換私有的元件鍵。

## 支援的擴充點

- `IBoardToolbarContributionService` 向 Board 工具列加入建立或輔助動作。
- `IBoardSettingsMenuContributionService` 向設定選單加入動作、匯入或輸出項目。
- `IBoardSidePanelService` 開啟 Board 側邊面板，並返回一個可釋放的控制代碼。
- `additionalRenderAdapters` 新增渲染器，但不替換內建的 `BOARD_ELEMENT_RENDER_ADAPTERS` 列表。
- `registerBoardDocumentTextExtension` 擴充 Board 文件文字的算繪。

主外掛移除時，應釋放每一項註冊。
