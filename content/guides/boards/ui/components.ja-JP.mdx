`@univerjs-pro/boards-ui` は Board キャンバスで使用するコンポーネントと拡張サービスを公開します。初期化済みの Univer インジェクターと Board ユニットが必要で、単独のデザインシステム部品ではありません。

## 公開キャンバスコンポーネント

```ts
import {
  BoardShapeTextEditorContainer,
  BoardWorkbench,
} from '@univerjs-pro/boards-ui'
```

図形とコネクターのフローティングツールバーはプラグインが内部登録します。非公開のコンポーネントキーを置き換えず、対応するサービスを使用してください。

## 対応する拡張ポイント

- `IBoardToolbarContributionService` は作成または補助アクションをツールバーに追加します。
- `IBoardSettingsMenuContributionService` はアクション、インポート、出力項目を設定メニューに追加します。
- `IBoardSidePanelService` はサイドパネルを開き、破棄可能なハンドルを返します。
- `additionalRenderAdapters` は `BOARD_ELEMENT_RENDER_ADAPTERS` を置き換えずにレンダラーを追加します。
- `registerBoardDocumentTextExtension` は Board 文書テキストの描画を拡張します。

ホストプラグインを削除するときに、各登録を破棄してください。
