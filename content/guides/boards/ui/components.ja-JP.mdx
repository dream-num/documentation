ボード UI は、レンダーコントローラー、メニュー、フローティングツールバー、キャンバス上のポップオーバー、ワークベンチの各パーツで構成されます。ほとんどのアプリケーションでは、`UniverBoardsUIPlugin` を登録してデフォルトのコンポーネントを使用します。

## ワークベンチの表示をカスタマイズする

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

## ツールバーのツールをカスタマイズする

`toolbar.tools` を使用すると、デフォルトのツールバーに表示されるボード用ツールを無効にしたり、ラベルを変更したりできます。

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: {
    tools: {
      connector: { enabled: true, label: 'Connector' },
      pen: false,
    },
  },
})
```

## 要素のレンダリングを拡張する

アプリケーションに独自のボード要素タイプを導入する場合や、要素の描画方法を上書きする場合は、`additionalRenderAdapters` を使用します。

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  additionalRenderAdapters: [customAdapter],
})
```
