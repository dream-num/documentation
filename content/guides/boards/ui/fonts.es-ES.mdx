Boards guarda las fuentes en los datos de Board. Un tema puede definir `fontScheme.heading` y `fontScheme.body`; cada elemento de texto puede sobrescribir familia, tamaño y énfasis con `textStyle`.

## Configurar la fuente de un texto

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const label = board.insertText({
  text: 'Milestone',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

La edición de texto usa la canalización compartida de Docs UI, una dependencia técnica de `@univerjs-pro/boards-ui`. Cargue las fuentes web en la página host antes de renderizar Board para evitar sustituciones y cambios de métricas.

Para el tema compartido de la aplicación, consulte [Temas y modo oscuro](/guides/boards/ui/themes). El tema del documento Board permanece en su instantánea.
