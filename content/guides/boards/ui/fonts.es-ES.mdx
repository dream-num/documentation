Los tableros utilizan el documento compartido de Univer y el canal de fuentes de la interfaz de usuario para texto enriquecido, cuadros de texto y texto de formas. Registre la interfaz de usuario de Docs y los complementos de la interfaz de usuario compartidos antes del `UniverBoardsUIPlugin` para que la edición de texto tenga los servicios necesarios.

## Configure las fuentes del tema

El tema Board puede definir familias de fuentes para encabezados y cuerpos:

```ts
const currentThemeId = board.getThemeData().id
if (!currentThemeId || !board.setTheme(currentThemeId)) {
  throw new Error('Cannot apply Board theme')
}
```

## Fuentes de elementos de texto

Los elementos de texto también pueden llevar un estilo de texto explícito:

```ts
const label = board.insertText({
  id: 'label-1',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  text: 'Milestone',
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

Cargue fuentes web en la aplicación host antes de renderizar el Board para evitar cambios de diseño.
