Boards поддерживает данные тем для цветов, шрифтов, стилей заливки и линий, эффектов и стилей фона. Данные темы хранятся в снимке Board, а обновлять их можно через фасад Board.

## Применение темы

```ts
const board = univerAPI.getActiveBoard()

await board.setTheme({
  id: 'brand-theme',
  name: 'Brand Theme',
  colorScheme: {
    accent1: '#2563eb',
    accent2: '#16a34a',
    dk1: '#111827',
    lt1: '#ffffff',
  },
  fontScheme: {
    heading: 'Inter',
    body: 'Inter',
  },
})
```

## Чтение данных темы

```ts
const theme = board.getThemeData()
```

## Поля снимка

| Поле | Описание |
| --- | --- |
| `theme` | Текущая тема, используемая в Board. |
| `themes` | Дополнительные именованные темы с идентификаторами в качестве ключей. |
| `colorScheme` | Семантические токены цветов, используемые элементами и стилями. |
| `fontScheme` | Семейства шрифтов для заголовков и основного текста. |
| `fmtScheme` | Списки стилей заливки, обводки, эффектов и фона. |
