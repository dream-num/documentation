Board UI는 렌더링 컨트롤러, 메뉴, 플로팅 도구 모음, 캔버스 팝오버 및 워크벤치 부분으로 구성됩니다. 대부분의 애플리케이션은 `UniverBoardsUIPlugin`을 등록하여 기본 구성 요소를 사용합니다.

## 워크벤치 표시 여부 사용자 지정

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

## 도구 모음 도구 사용자 지정

`toolbar.tools`를 사용하면 기본 도구 모음에 표시되는 Board 도구를 비활성화하거나 레이블을 변경할 수 있습니다.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: {
    tools: {
      connector: { enabled: true, label: 'Connector' },
      pen: false,
    },
  },
})
```

## 요소 렌더링 확장

애플리케이션에서 사용자 지정 Board 요소 유형을 도입하거나 요소를 그리는 방식을 재정의하려면 `additionalRenderAdapters`를 사용하세요.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  additionalRenderAdapters: [customAdapter],
})
```
