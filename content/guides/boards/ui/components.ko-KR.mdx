`@univerjs-pro/boards-ui`는 Board 캔버스에서 사용하는 컴포넌트와 확장 서비스를 내보냅니다. 초기화된 Univer 인젝터와 Board 유닛이 필요하며 독립적인 디자인 시스템 위젯이 아닙니다.

## 공개 캔버스 컴포넌트

```ts
import {
  BoardShapeTextEditorContainer,
  BoardWorkbench,
} from '@univerjs-pro/boards-ui'
```

도형 및 커넥터 플로팅 도구 모음은 플러그인이 내부에서 등록합니다. 비공개 컴포넌트 키를 교체하지 말고 지원되는 서비스를 사용하세요.

## 지원되는 확장 지점

- `IBoardToolbarContributionService`는 생성 또는 보조 작업을 도구 모음에 추가합니다.
- `IBoardSettingsMenuContributionService`는 작업, 가져오기, 출력 항목을 설정 메뉴에 추가합니다.
- `IBoardSidePanelService`는 사이드 패널을 열고 폐기 가능한 핸들을 반환합니다.
- `additionalRenderAdapters`는 `BOARD_ELEMENT_RENDER_ADAPTERS`를 교체하지 않고 렌더러를 추가합니다.
- `registerBoardDocumentTextExtension`은 Board 문서 텍스트 렌더링을 확장합니다.

호스트 플러그인을 제거할 때 각 등록을 폐기하세요.
