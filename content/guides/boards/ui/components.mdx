Board UI is built from render controllers, menus, floating toolbars, canvas popovers, and workbench parts. Most applications use the default components by registering `UniverBoardsUIPlugin`.

## Customize workbench visibility

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

## Customize toolbar tools

`toolbar.tools` can disable or relabel Board tools exposed by the default toolbar.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: {
    tools: {
      connector: { enabled: true, label: 'Connector' },
      pen: false,
    },
  },
})
```

## Extend element rendering

Use `additionalRenderAdapters` when your application introduces custom Board element types or wants to override how an element is painted.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  additionalRenderAdapters: [customAdapter],
})
```
