## 字体结构定义

在 Univer 中，字体使用 `IFontConfig` 接口进行定义：

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `value` | `string` | 字体的唯一标识符，通常也是 CSS font-family 的首选值。 |
| `label` | `string` | 用于国际化的翻译键，如果在 Univer 实例创建时没有指定该键值时，则直接显示传入值。|
| `category` | `'sans-serif' \| 'serif' \| 'monospace' \| 'display' \| 'handwriting'` | 字体类别，用于 UI 分组（可选）。 |

<Callout>
  Univer 不会阻止用户选择未安装的字体，如果客户端没有安装某个字体，浏览器会直接使用默认字体进行替代显示。
</Callout>

## 使用自定义字体

你可以通过为 `UniverSheetsCorePreset`（预设模式）或 `UniverUIPlugin`（插件模式）配置 `customFontFamily` 参数来定义字体下拉菜单中的选项。

<Tabs items={['预设模式', '插件模式']}>
  <Tab>
    ```typescript
    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          container: 'app',
          customFontFamily: {
            list: [
              {
                value: 'PingFang SC',
                label: '苹方（简）',
                category: 'sans-serif',
              },
              {
                value: 'Helvetica Neue',
                label: 'Helvetica Neue',
                category: 'sans-serif',
              },
            ],
            // 是否覆盖默认字体列表，默认为 false
            override: true,
          },
        }),
      ],
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
      customFontFamily: {
        list: [
          {
            value: 'PingFang SC',
            label: '苹方（简）',
            category: 'sans-serif',
          },
          {
            value: 'Helvetica Neue',
            label: 'Helvetica Neue',
            category: 'sans-serif',
          },
        ],
        // 是否覆盖默认字体列表，默认为 false
        override: true,
      },
    })
    ```
  </Tab>
</Tabs>

### Facade API

除了在初始化时配置，你还可以通过 Facade API 在运行时动态注册新的字体。这在需要异步加载字体资源的场景下非常有用。

```typescript
univerAPI.addFonts([{
  value: 'PingFang SC',
  label: '苹方（简）',
  category: 'sans-serif',
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: 'sans-serif',
}])
```


画板中的富文本、文本框和形状文本共用 Univer 文档与 UI 的字体处理流程。请先注册 Docs UI 和共享 UI 插件，再注册 `UniverBoardsUIPlugin`，以便文本编辑功能获得所需的服务。

## 配置主题字体

画板主题可以定义标题和正文字体：

```ts
const currentThemeId = board.getThemeData().id
if (!currentThemeId || !board.setTheme(currentThemeId)) {
  throw new Error('Cannot apply Board theme')
}
```

## 文本元素字体

文本元素也可以指定文本样式：

```ts
const label = board.insertText({
  id: 'label-1',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  text: 'Milestone',
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

请在渲染画板前通过宿主应用加载 Web 字体，以免布局发生偏移。
