---
title: 自定义字体列表
icon: BookType
---

Boards 将字体选择保存在 Board 数据中。Board 主题可以通过 `fontScheme.heading` 和 `fontScheme.body` 定义标题和正文字体，单个文本元素可以通过 `textStyle` 覆盖字体族、字号和强调样式。

## 设置文本元素字体

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const label = board.insertText({
  text: 'Milestone',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

Board 的文本编辑使用与 Docs UI 共用的文本管线，这也是 `@univerjs-pro/boards-ui` 的一项技术依赖。请在 Board 渲染之前由宿主页面加载 Web 字体，否则浏览器会使用已有字体替代，文本尺寸也可能随之变化。

应用整体主题请参阅[主题与暗黑模式](/guides/boards/ui/themes)。Board 文档主题仍保存在 Board 快照中。
