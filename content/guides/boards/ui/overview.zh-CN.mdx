`@univerjs-pro/boards-ui` 为画板画布提供浏览器端 UI。它负责渲染主场景、选区叠加层、视口交互、工具栏、上下文菜单、文本编辑、形状编辑、连接线编辑，以及可选的元素 UI 集成。

## 必需的运行时

浏览器端画板编辑器需要先注册共享 UI 和渲染插件，再注册画板 UI 插件：

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverDrawingUIPlugin)
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

## 工作台选项

`IUniverBoardsUIConfig.workbench` 控制画板 UI 接管 Univer 工作台的哪些部分。

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

如果要将画板嵌入已经提供导航栏或工具栏的应用程序外壳中，请使用此配置。

## 交互选项

`interaction` 配置用于控制缩放限制、滚轮行为、对齐辅助线、间距辅助线、调整大小手柄，以及待插入元素的预览。

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```
