Boards stores font choices in the Board data. A Board theme can define `fontScheme.heading` and `fontScheme.body`, and an individual text element can override the font family, font size, and emphasis in its `textStyle`.

## Set text element fonts

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const label = board.insertText({
  text: 'Milestone',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

Board text editing uses the text pipeline shared with Docs UI, which is a technical dependency of `@univerjs-pro/boards-ui`. Load any web font in the host page before the Board renders; otherwise the browser substitutes a font that is already available, and text metrics may change.

For the application-wide theme, see [Themes and Dark Mode](/guides/boards/ui/themes). Board document themes remain part of the Board snapshot.
