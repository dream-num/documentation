`@univerjs-pro/boards-ui` provides the browser UI for the Board canvas. It renders the main scene, selection overlay, viewport interaction, toolbars, context menus, text editing, shape editing, connector editing, and optional element UI integrations.

## Required runtime

A browser Board editor needs the shared UI and render plugins before the Board UI plugin:

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverDrawingUIPlugin)
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

## Workbench options

`IUniverBoardsUIConfig.workbench` controls which parts of the Univer workbench the Board UI owns.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

Use this when embedding Boards in an application shell that already provides navigation or toolbars.

## Interaction options

`interaction` config controls zoom limits, wheel behavior, alignment guides, spacing guides, resize handles, and pending insert previews.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```
