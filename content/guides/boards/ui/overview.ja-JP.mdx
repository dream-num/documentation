`@univerjs-pro/boards-ui` は、ボードキャンバス用のブラウザー UI を提供します。メインシーン、選択オーバーレイ、ビューポート操作、ツールバー、コンテキストメニュー、テキスト編集、図形編集、コネクター編集、およびオプションの要素 UI 連携をレンダリングします。

## 必要なランタイム

ブラウザー上で動作するボードエディターでは、ボード UI プラグインより先に、共通 UI プラグインとレンダリングプラグインが必要です。

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverDrawingUIPlugin)
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

## ワークベンチのオプション

`IUniverBoardsUIConfig.workbench` では、Univer ワークベンチのどの部分をボード UI が管理するかを指定します。

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

ナビゲーションやツールバーを備えたアプリケーションシェルにボードを埋め込む場合は、この設定を使用します。

## 操作オプション

`interaction` 設定では、ズーム範囲、ホイール操作、配置ガイド、間隔ガイド、サイズ変更ハンドル、および挿入待ち要素のプレビューを制御します。

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```
