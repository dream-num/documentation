`@univerjs-pro/boards-ui`は、Univerボードのライセンスブラウザのキャンバスです。シーンをレンダリングし、選択とビューポートの相互作用を処理します。また、ツールバー、コンテキストメニュー、テキスト編集、形状編集、コネクタ編集、およびサポートされているボード要素タイプ用のUIを提供します。

## Board UI を登録する

ボードプラグインの前に `UniverLicensePlugin` を設定します。 Docs、Drawing、Ink、Shape Editor はレンダリングおよび編集のための技術的な依存関係です。 ボードを使用して、それらの製品の事前の知識を必要としません。

`UniverLicensePlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `license` | `string` |  | クライアントライセンスファイルの内容。 |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```

完全な依存性、スタイル、および locale の登録順については、[インストールと基本的な使い方](/guides/boards/getting-started/installation) を参照してください。

## キャンバス設定

`IUniverBoardsUIConfig`は格子出現、インサートのデフォルト、利用できる形および粘着性があるノート色、ツールバー用具、viewport棒、レンダリングのアダプター、および速い付加、精密な選択、次元およびコラベータ カーソルのような選択を制御します。

## メニュー設定とキャンバスツールバー [#menu-configuration]

[コンテキストメニューとキャンバスツール](/guides/boards/features/core#menu-order-and-grid-layout) を起動時に設定します。既存のコンテキストメニューを変更するには、[メニュー Facade API](/guides/boards/features/core#menu-facade)を使用します。
