Boards verwenden die gemeinsame Univer-Dokument- und UI-Schriftartenpipeline für Rich Text, Textfelder und Formtext. Registrieren Sie Docs UI und Shared UI-Plugins vor `UniverBoardsUIPlugin`, damit die Textbearbeitung über die erforderlichen Dienste verfügt.

## Designschriftarten konfigurieren

Das Board-Design kann Überschriften- und Textschriftfamilien definieren:

```ts
await board.setTheme({
  name: 'Internal Theme',
  fontScheme: {
    heading: 'Inter',
    body: 'Inter',
  },
})
```

## Textelementschriftarten

Textelemente können auch explizite Textstile enthalten:

```ts
await board.addElement({
  id: 'label-1',
  type: 'text',
  transform: { left: 120, top: 96, width: 240, height: 64 },
  text: 'Milestone',
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
}, { pageId })
```

Laden Sie Webschriftarten in der Hostanwendung, bevor Sie das Board rendern, um Layoutverschiebungen zu vermeiden.
