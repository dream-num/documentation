`@univerjs-pro/boards-ui` es el lienzo del navegador con licencia para las juntas Univer. Representa la escena, maneja la selección y las interacciones de viewport, y proporciona las barras de herramientas, menús de contexto, edición de texto, edición de forma, edición de conectores, e interfaz de usuario para los tipos de elementos soportados de la Junta.

## Registrar la interfaz de Board

Configure `UniverLicensePlugin` antes de los plugins de la Junta. Docs, Dibujo, Tinta y Editor de Forma son dependencias técnicas para renderizar y editar; el uso de las Juntas no requiere conocimiento previo de esos productos.

`UniverLicensePlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenido del archivo de licencia del cliente. |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```

Para la orden de registro de la dependencia completa, estilo y local, vea [Instalación &quot; Usage básico](/guides/boards/getting-started/installation).

## Opciones del lienzo

`IUniverBoardsUIConfig` también controla la apariencia de la red, inserta predeterminados, formas disponibles y colores pegajosos, herramientas de barras de herramientas, barras de visualización, adaptadores de renderizado y opciones tales como rápida adición, selección precisa, dimensiones y cursores colaboradores.

## Configuración de menús y barra de herramientas del lienzo [#menu-configuration]

Configure [menús contextuales y herramientas de tela](/guides/boards/features/core#menu-order-and-grid-layout) al inicio. Para cambiar un menú contextual existente, utilice el [menú Facade API](/guides/boards/features/core#menu-facade).
