`@univerjs-pro/boards-ui` proporciona el lienzo con licencia de Univer Boards en el navegador. Renderiza la escena, la selección y el viewport, las barras de herramientas, los menús contextuales y la edición de texto, formas, conectores y tipos de elemento compatibles.

## Registrar la interfaz de Board

Configure `UniverLicensePlugin` antes de los plugins de Board. Docs, Drawing, Ink y Shape Editor son dependencias técnicas de renderizado y edición; usar Boards no exige conocer esos productos.

`UniverLicensePlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenido del archivo de licencia del cliente. |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```

Consulte [Instalación y uso básico](/guides/boards/getting-started/installation) para ver el orden completo de dependencias, estilos e idiomas.

## Opciones del lienzo

`IUniverBoardsUIConfig` también controla la cuadrícula, los valores de inserción, las formas y colores de notas, las herramientas, las barras del viewport, los adaptadores de renderizado, la adición rápida, la selección precisa, las dimensiones y los cursores de colaboración.

## Configuración de menús y barra de herramientas del lienzo [#menu-configuration]

Al iniciar, [configura los menús contextuales y las herramientas del lienzo](/guides/boards/features/core#menu-order-and-grid-layout). Para cambiar un menú contextual existente, usa la [API Facade de menús](/guides/boards/features/core#menu-facade).
