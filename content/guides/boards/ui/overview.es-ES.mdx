## Sistema de diseño

El sistema de diseño de Univer está construido en Tailwind CSS, creando una serie de tokens de diseño que son reutilizados por el motor de renderizado para garantizar un estilo consistente entre el motor de renderizado y la capa de vista. Puede personalizar los estilos de su aplicación modificando estos tokens, que se almacenan en el paquete `@univerjs/themes`.



## Componentes

Univer usa componentes de React para construir la capa de vista, lo que hace que sea muy fácil para los desarrolladores que también usan React usar los componentes de Univer o registrar componentes personalizados. Sin embargo, esto no significa que sólo puedas usar React para crear componentes personalizados; Univer también admite otros marcos, como Vue (versión 3.x) y componentes web.

Todos los componentes básicos se almacenan en el paquete `@univerjs/design` y los componentes de íconos se almacenan en el paquete `@univerjs/icons`. Estos componentes también se pueden usar independientemente de Univer.

Los componentes personalizados se usan a menudo en los siguientes escenarios:

- Agregar botones personalizados en la cinta/menú contextual
- Integrar componentes personalizados en la barra lateral/emergente, etc.
- Reemplazar componentes integrados

Proporcionaremos instrucciones detalladas sobre cómo registrar y usar componentes personalizados en los siguientes capítulos.


`@univerjs-pro/boards-ui` proporciona la interfaz de usuario del navegador para el lienzo del tablero. Representa la escena principal, la superposición de selección, la interacción de la ventana gráfica, las barras de herramientas, los menús contextuales, la edición de texto, la edición de formas, la edición de conectores y las integraciones de la interfaz de usuario de elementos opcionales.

## Tiempo de ejecución requerido

Un editor de tablero del navegador necesita la interfaz de usuario compartida y los complementos de procesamiento antes que el complemento de la interfaz de usuario de la placa:

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverDrawingUIPlugin)
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

## Opciones de Workbench

`IUniverBoardsUIConfig.workbench` controla qué partes del banco de trabajo de Univer la interfaz de usuario de Board posee.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

Utilice esto al incrustar tableros en un shell de aplicación que ya proporciona navegación o barras de herramientas.

## Opciones de interacción

La configuración `interaction` controla los límites de zoom, el comportamiento de las ruedas, las guías de alineación, las guías de espaciado, los controladores de cambio de tamaño y las vistas previas de inserción pendientes.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```
