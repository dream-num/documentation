Boards prend en charge les données de thème pour les couleurs, les polices, les styles de remplissage, les styles de trait, les effets et les styles d'arrière-plan. Ces données sont stockées dans l'instantané Board et peuvent être mises à jour à l'aide de la façade Board.

## Appliquer un thème

```ts
const board = univerAPI.getActiveBoard()

await board.setTheme({
  id: 'brand-theme',
  name: 'Brand Theme',
  colorScheme: {
    accent1: '#2563eb',
    accent2: '#16a34a',
    dk1: '#111827',
    lt1: '#ffffff',
  },
  fontScheme: {
    heading: 'Inter',
    body: 'Inter',
  },
})
```

## Lire les données du thème

```ts
const theme = board.getThemeData()
```

## Champs de l'instantané

| Champ | Description |
| --- | --- |
| `theme` | Thème actuellement utilisé par Board. |
| `themes` | Thèmes nommés supplémentaires, indexés par identifiant. |
| `colorScheme` | Jetons de couleur sémantiques utilisés par les éléments et les styles. |
| `fontScheme` | Familles de polices des titres et du corps du texte. |
| `fmtScheme` | Listes de styles de remplissage, de trait, d'effet et d'arrière-plan. |
