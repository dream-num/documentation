`@univerjs-pro/boards-ui` экспортирует компоненты и сервисы расширения холста Board. Для них нужны инициализированный инжектор Univer и модуль Board; это не автономные элементы дизайн-системы.

## Публичные компоненты холста

```ts
import {
  BoardShapeTextEditorContainer,
  BoardWorkbench,
} from '@univerjs-pro/boards-ui'
```

Плавающие панели фигур и соединителей регистрируются плагином внутри. Используйте поддерживаемые сервисы вместо замены закрытых ключей компонентов.

## Поддерживаемые точки расширения

- `IBoardToolbarContributionService` добавляет действия создания или вспомогательные действия на панели.
- `IBoardSettingsMenuContributionService` добавляет в меню действия, импорт и вывод.
- `IBoardSidePanelService` открывает боковую панель и возвращает освобождаемый дескриптор.
- `additionalRenderAdapters` добавляет рендереры без замены `BOARD_ELEMENT_RENDER_ADAPTERS`.
- `registerBoardDocumentTextExtension` расширяет отрисовку текста документа Board.

Освобождайте каждую регистрацию при удалении плагина хоста.
