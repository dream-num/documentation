Интерфейс Board состоит из контроллеров отрисовки, меню, плавающих панелей инструментов, всплывающих элементов холста и частей рабочей области. В большинстве приложений используются стандартные компоненты, которые подключаются при регистрации `UniverBoardsUIPlugin`.

## Настройка видимости рабочей области

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

## Настройка инструментов панели

С помощью `toolbar.tools` можно отключить инструменты Board на стандартной панели или изменить их подписи.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: {
    tools: {
      connector: { enabled: true, label: 'Connector' },
      pen: false,
    },
  },
})
```

## Расширение отрисовки элементов

Используйте `additionalRenderAdapters`, если в приложении появились пользовательские типы элементов Board или нужно переопределить способ отрисовки элемента.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  additionalRenderAdapters: [customAdapter],
})
```
