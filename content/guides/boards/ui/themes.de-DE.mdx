Boards unterstützen Designdaten für Farben, Schriftarten, Füllstile, Linienstile, Effekte und Hintergrundstile. Themendaten werden im Board-Snapshot gespeichert und können über die Board-Fassade aktualisiert werden.

## Thema anwenden

```ts
const board = univerAPI.getActiveBoard()

await board.setTheme({
  id: 'brand-theme',
  name: 'Brand Theme',
  colorScheme: {
    accent1: '#2563eb',
    accent2: '#16a34a',
    dk1: '#111827',
    lt1: '#ffffff',
  },
  fontScheme: {
    heading: 'Inter',
    body: 'Inter',
  },
})
```

## Themendaten lesen

```ts
const theme = board.getThemeData()
```

## Snapshot-Felder

| Feld | Beschreibung |
| --- | --- |
| `theme` | Aktuelles Thema, das von verwendet wird Board. |
| `themes` | Zusätzliche benannte Themen, die nach ID kodiert sind. |
| `colorScheme` | Semantische Farbtokens, die von Elementen und Stilen verwendet werden. |
| `fontScheme` | Schriftfamilien für Überschriften und Textkörper. |
| `fmtScheme` | Füll-, Strich-, Effekt- und Hintergrundstillisten. |
