Die Board-Benutzeroberfläche besteht aus Render-Controllern, Menüs, schwebenden Symbolleisten, Canvas-Popovers und Workbench-Teilen. Die meisten Anwendungen verwenden die Standardkomponenten durch die Registrierung von `UniverBoardsUIPlugin`.

## Workbench-Sichtbarkeit anpassen

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

## Symbolleisten-Tools anpassen

`toolbar.tools` kann Board-Tools deaktivieren oder neu beschriften, die von der Standard-Symbolleiste angezeigt werden.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: {
    tools: {
      connector: { enabled: true, label: 'Connector' },
      pen: false,
    },
  },
})
```

## Element-Rendering erweitern

Verwenden Sie `additionalRenderAdapters`, wenn Ihre Anwendung benutzerdefinierte Board-Elementtypen einführt oder möchte überschreiben, wie ein Element gezeichnet wird.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  additionalRenderAdapters: [customAdapter],
})
```
