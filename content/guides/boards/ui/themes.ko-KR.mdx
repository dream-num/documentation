Boards는 색상, 글꼴, 채우기 스타일, 선 스타일, 효과 및 배경 스타일을 위한 테마 데이터를 지원합니다. 테마 데이터는 Board 스냅샷에 저장되며 Board 퍼사드를 통해 업데이트할 수 있습니다.

## 테마 적용

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

// Theme ids come from Board presets or host theme registration.
if (!board.setTheme('brand-theme')) throw new Error('Cannot apply Board theme')
```

## 테마 데이터 읽기

```ts
const theme = board.getThemeData()
```

## 스냅샷 필드

| 필드 | 설명 |
| --- | --- |
| `theme` | Board에서 현재 사용하는 테마입니다. |
| `themes` | ID를 키로 사용하는 추가 명명 테마입니다. |
| `colorScheme` | 요소와 스타일에서 사용하는 의미 기반 색상 토큰입니다. |
| `fontScheme` | 제목과 본문 글꼴 모음입니다. |
| `fmtScheme` | 채우기, 선, 효과 및 배경 스타일 목록입니다. |
