## Система дизайна

Система дизайна Univer построена на Tailwind CSS и содержит набор дизайн-токенов, которые повторно используются движком отрисовки. Это обеспечивает единообразие стилей между движком отрисовки и слоем представления. Чтобы настроить стили приложения, можно изменить эти токены, хранящиеся в пакете `@univerjs/themes`.



## Компоненты

Univer использует компоненты React для построения слоя представления, поэтому разработчикам, которые также работают с React, очень просто использовать компоненты Univer или регистрировать собственные. При этом пользовательские компоненты не обязательно создавать только на React: Univer поддерживает и другие технологии, например Vue версии 3.x и Web Components.

Все базовые компоненты находятся в пакете `@univerjs/design`, а компоненты значков — в пакете `@univerjs/icons`. Их также можно использовать независимо от Univer.

Пользовательские компоненты часто применяются в следующих случаях:

- Добавление пользовательских кнопок в Ribbon / Context Menu
- Интеграция пользовательских компонентов в Sidebar / Popup и другие элементы
- Замена встроенных компонентов

В следующих главах подробно описано, как регистрировать и использовать пользовательские компоненты.


`@univerjs-pro/boards-ui` предоставляет браузерный интерфейс для холста Board. Он отвечает за отрисовку основной сцены, слоя выделения, взаимодействия с областью просмотра, панелей инструментов, контекстных меню, редактирования текста, фигур и соединительных линий, а также за необязательные интеграции интерфейса для элементов.

## Необходимое окружение

Для работы редактора Board в браузере перед плагином Board UI необходимо подключить общие плагины интерфейса и отрисовки:

```ts
univer.registerPlugin(UniverRenderEnginePlugin)
univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsPlugin)
univer.registerPlugin(UniverDocsUIPlugin)
univer.registerPlugin(UniverDrawingPlugin)
univer.registerPlugin(UniverDrawingUIPlugin)
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
```

## Параметры рабочей области

`IUniverBoardsUIConfig.workbench` определяет, какими частями рабочей области Univer управляет Board UI.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

Используйте этот параметр при встраивании Boards в оболочку приложения, в которой уже предусмотрены навигация или панели инструментов.

## Параметры взаимодействия

Конфигурация `interaction` управляет пределами масштабирования, поведением колеса мыши, направляющими выравнивания и интервалов, маркерами изменения размера и предварительным просмотром ожидающих вставки элементов.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```
