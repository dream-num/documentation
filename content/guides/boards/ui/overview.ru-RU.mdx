`@univerjs-pro/boards-ui` - это лицензированный холст браузера для досок Univer. Он отображает сцену, обрабатывает взаимодействие выбора и просмотра и предоставляет панели инструментов, контекстные меню, редактирование текста, редакцию формы, редактуру разъема и пользовательский интерфейс для поддерживаемых типов элементов платы.

## Регистрация интерфейса Board

Настройка `UniverLicensePlugin` перед плагинами Совета директоров.Документы, чертежи, чернила и редактор форм - это технические зависимости для рендеринга и редактирования; использование Советов не требует предварительного знания этих продуктов.

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое клиентского файла лицензии. |

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```

Для получения полной зависимости, стиля и локального заказа на регистрацию см. [Установка и базовое использование](/guides/boards/getting-started/installation).

## Параметры холста

`IUniverBoardsUIConfig` также контролирует внешний вид сетки, по умолчанию вставки, доступные формы и липкие цвета нот, инструменты панели инструментов, панели просмотра, адаптеры рендеринга и такие опции, как быстрое добавление, точный выбор, размеры и курсоры коллаборационистов.

## Настройка меню и панели инструментов холста [#menu-configuration]

Настройте [контекстные меню и инструменты canvas](/guides/boards/features/core#menu-order-and-grid-layout) при запуске. Для изменения существующего контекстного меню используйте [Меню Facade API](/guides/boards/features/core#menu-facade).
