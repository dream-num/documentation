`@univerjs-pro/boards-ui` предоставляет лицензируемый браузерный холст Univer Boards. Он отображает сцену, выделение и навигацию, панели инструментов, контекстные меню, а также редактирование текста, фигур, соединителей и поддерживаемых элементов Board.

## Регистрация интерфейса Board

Настройте `UniverLicensePlugin` до плагинов Board. Docs, Drawing, Ink и Shape Editor являются техническими зависимостями отрисовки и редактирования; знать эти продукты заранее не требуется.

```ts
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
  interaction: {
    minZoomRatio: 0.1,
    maxZoomRatio: 4,
    wheelZoomWithModifier: true,
    trackpadPanEnabled: true,
  },
})
```

Полный порядок регистрации зависимостей, стилей и локалей приведён в разделе [Установка и основы использования](/guides/boards/getting-started/installation).

## Параметры холста

`IUniverBoardsUIConfig` также управляет сеткой, значениями вставки, фигурами и цветами заметок, инструментами, полосами области просмотра, адаптерами отрисовки, быстрым добавлением, точным выделением, размерами и курсорами соавторов.
