Boards는 글꼴 선택을 Board 데이터에 저장합니다. Board 테마는 `fontScheme.heading`과 `fontScheme.body`를 정의할 수 있고, 개별 텍스트 요소는 `textStyle`로 글꼴 패밀리, 크기, 강조를 덮어쓸 수 있습니다.

## 텍스트 요소 글꼴 설정

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const label = board.insertText({
  text: 'Milestone',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

Board 텍스트 편집은 `@univerjs-pro/boards-ui`의 기술적 종속성인 공통 Docs UI 텍스트 파이프라인을 사용합니다. 글꼴 대체와 텍스트 측정값 변경을 피하려면 Board를 렌더링하기 전에 호스트 페이지에서 웹 글꼴을 로드하세요.

공통 애플리케이션 테마는 [테마 및 다크 모드](/guides/boards/ui/themes)를 참고하세요. Board 문서 테마는 스냅샷에 저장됩니다.
