보드는 보드 데이터의 글꼴 선택을 저장합니다. 보드 테마는 `fontScheme.heading` 및 `fontScheme.body`를 정의 할 수 있으며 개별 텍스트 요소는 폰트 가족, 폰트 크기, `textStyle`에 강조 할 수 있습니다.

## 텍스트 요소 글꼴 설정

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const label = board.insertText({
  text: 'Milestone',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

보드 텍스트 편집은 `@univerjs-pro/boards-ui`의 기술 의존성 인 Docs UI와 공유 된 텍스트 파이프라인을 사용합니다. 보드 렌더링 전에 호스트 페이지의 웹 글꼴을로드하십시오. 그렇지 않으면 브라우저는 이미 사용할 수있는 글꼴을 대체하고 텍스트 미터는 변경 될 수 있습니다.

애플리케이션 전체 테마의 경우 [테마와 다크 모드](/guides/boards/ui/themes)를 참조하십시오. 보드 문서 테마는 보드 스냅 샷의 일부 남아 있습니다.
