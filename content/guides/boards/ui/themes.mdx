Boards support theme data for colors, fonts, fill styles, line styles, effects, and background styles. Theme data is stored on the Board snapshot and can be updated through the Board facade.

## Apply a theme

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

// Theme ids come from Board presets or host theme registration.
if (!board.setTheme('brand-theme')) throw new Error('Cannot apply Board theme')
```

## Read theme data

```ts
const theme = board.getThemeData()
```

## Snapshot fields

| Field | Description |
| --- | --- |
| `theme` | Current theme used by the Board. |
| `themes` | Additional named themes keyed by id. |
| `colorScheme` | Semantic color tokens used by elements and styles. |
| `fontScheme` | Heading and body font families. |
| `fmtScheme` | Fill, stroke, effect, and background style lists. |
