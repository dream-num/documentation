La interfaz de usuario de la placa se crea a partir de controladores de renderizado, menús, barras de herramientas flotantes, ventanas emergentes de lienzo y partes del banco de trabajo. La mayoría de las aplicaciones utilizan los componentes predeterminados registrando `UniverBoardsUIPlugin`.

## Personalizar la visibilidad del banco de trabajo

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

## Personalizar las herramientas de la barra de herramientas

`toolbar.tools` puede deshabilitar o volver a etiquetar las herramientas del tablero expuestas por la barra de herramientas predeterminada.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: {
    tools: {
      connector: { enabled: true, label: 'Connector' },
      pen: false,
    },
  },
})
```

## Extender la representación de elementos

Utilice `additionalRenderAdapters` cuando su aplicación introduzca tipos de elementos de tablero personalizados o desee anular la forma en que El elemento está pintado.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  additionalRenderAdapters: [customAdapter],
})
```
