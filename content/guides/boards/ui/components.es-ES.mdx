`@univerjs-pro/boards-ui` exporta los componentes y servicios de extensión del lienzo Board. Requieren un inyector Univer inicializado y una unidad Board; no son widgets independientes del sistema de diseño.

## Componentes públicos

```ts
import {
  BoardShapeTextEditorContainer,
  BoardWorkbench,
} from '@univerjs-pro/boards-ui'
```

El plugin registra internamente las barras flotantes de formas y conectores. Use los servicios compatibles en lugar de reemplazar claves privadas.

## Puntos de extensión compatibles

- `IBoardToolbarContributionService` añade acciones de creación o auxiliares a las barras.
- `IBoardSettingsMenuContributionService` añade entradas de acción, importación o salida al menú.
- `IBoardSidePanelService` abre un panel lateral y devuelve un recurso desechable.
- `additionalRenderAdapters` añade renderizadores sin reemplazar `BOARD_ELEMENT_RENDER_ADAPTERS`.
- `registerBoardDocumentTextExtension` amplía el renderizado del texto de documento Board.

Libere cada registro cuando se retire el plugin host.
