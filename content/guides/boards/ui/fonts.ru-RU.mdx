Для форматированного текста, текстовых полей и текста внутри фигур Boards использует общий механизм работы со шрифтами документов и интерфейса Univer. Зарегистрируйте плагины интерфейса Docs и общие плагины интерфейса до `UniverBoardsUIPlugin`, чтобы при редактировании текста были доступны необходимые сервисы.

## Настройка шрифтов темы

В теме Board можно задать семейства шрифтов для заголовков и основного текста:

```ts
await board.setTheme({
  name: 'Internal Theme',
  fontScheme: {
    heading: 'Inter',
    body: 'Inter',
  },
})
```

## Шрифты текстовых элементов

Для текстовых элементов также можно явно задать стиль текста:

```ts
await board.addElement({
  id: 'label-1',
  type: 'text',
  transform: { left: 120, top: 96, width: 240, height: 64 },
  text: 'Milestone',
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
}, { pageId })
```

Чтобы избежать смещения элементов макета, загружайте веб-шрифты в основном приложении до отрисовки Board.
