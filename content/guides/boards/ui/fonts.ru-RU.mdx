Платы хранят выбор шрифта в данных Совета. Тема Совета может определять `fontScheme.heading` и `fontScheme.body`, а отдельный текстовый элемент может переопределять семейство шрифтов, размер шрифта и акцент в его `textStyle`.

## Настройка шрифта текстового элемента

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const label = board.insertText({
  text: 'Milestone',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

Редактирование текста на плате использует текстовый конвейер, совместно используемый с пользовательским интерфейсом Docs, который является технической зависимостью от `@univerjs-pro/boards-ui`. Загрузите любой веб-шрифт на главной странице до рендеринга; в противном случае браузер заменяет уже доступный шрифт, и метрики текста могут измениться.

Для темы, охватывающей всю область применения, см. [Темы и темный режим](/guides/boards/ui/themes). Темы документов Совета остаются частью снимка Совета.
