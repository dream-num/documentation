## Структура описания шрифта

В Univer шрифты определяются с помощью интерфейса `IFontConfig`:

| Свойство | Тип | Описание |
| --- | --- | --- |
| `value` | `string` | Уникальный идентификатор шрифта, обычно также предпочтительное значение CSS-свойства font-family. |
| `label` | `string` | Ключ перевода для интернационализации. Если при создании экземпляра Univer этот ключ не задан, значение отображается без изменений. |
| `category` | `'sans-serif' \| 'serif' \| 'monospace' \| 'display' \| 'handwriting'` | Категория шрифта, используемая для группировки в интерфейсе (необязательно). |

<Callout>
  Univer не запрещает пользователям выбирать неустановленные шрифты. Если шрифт не установлен на устройстве, браузер заменит его шрифтом по умолчанию.
</Callout>

## Использование пользовательских шрифтов

Пункты раскрывающегося списка шрифтов можно задать с помощью параметра `customFontFamily` для `UniverSheetsCorePreset` (режим предустановок) или `UniverUIPlugin` (режим плагинов).

<Tabs items={['Режим предустановок', 'Режим плагинов']}>
  <Tab>
    ```typescript
    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          container: 'app',
          customFontFamily: {
            list: [
              {
                value: 'PingFang SC',
                label: '苹方（简）',
                category: 'sans-serif',
              },
              {
                value: 'Helvetica Neue',
                label: 'Helvetica Neue',
                category: 'sans-serif',
              },
            ],
            // Whether to override the default font list, defaults to false
            override: true,
          },
        }),
      ],
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
      customFontFamily: {
        list: [
          {
            value: 'PingFang SC',
            label: '苹方（简）',
            category: 'sans-serif',
          },
          {
            value: 'Helvetica Neue',
            label: 'Helvetica Neue',
            category: 'sans-serif',
          },
        ],
        // Whether to override the default font list, defaults to false
        override: true,
      },
    })
    ```
  </Tab>
</Tabs>

### Facade API

Помимо настройки при инициализации, новые шрифты можно динамически регистрировать во время выполнения через Facade API. Это особенно удобно, когда файлы шрифтов необходимо загружать асинхронно.

```typescript
univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: 'sans-serif',
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: 'sans-serif',
}])
```


Для форматированного текста, текстовых полей и текста внутри фигур Boards использует общий механизм работы со шрифтами документов и интерфейса Univer. Зарегистрируйте плагины интерфейса Docs и общие плагины интерфейса до `UniverBoardsUIPlugin`, чтобы при редактировании текста были доступны необходимые сервисы.

## Настройка шрифтов темы

В теме Board можно задать семейства шрифтов для заголовков и основного текста:

```ts
const currentThemeId = board.getThemeData().id
if (!currentThemeId || !board.setTheme(currentThemeId)) {
  throw new Error('Cannot apply Board theme')
}
```

## Шрифты текстовых элементов

Для текстовых элементов также можно явно задать стиль текста:

```ts
const label = board.insertText({
  id: 'label-1',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  text: 'Milestone',
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

Чтобы избежать смещения элементов макета, загружайте веб-шрифты в основном приложении до отрисовки Board.
