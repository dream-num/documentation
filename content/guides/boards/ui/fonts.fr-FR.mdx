Un thème de la carte peut définir `fontScheme.heading` et `fontScheme.body`, et un élément de texte individuel peut surcharger la famille de polices, la taille de police et l'accent mis dans sa `textStyle`.

## Définir la police d’un texte

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const label = board.insertText({
  text: 'Milestone',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

L'édition de texte de la carte utilise le pipeline de texte partagé avec Docs UI, qui est une dépendance technique de `@univerjs-pro/boards-ui`. Chargez toute police web dans la page hôte avant que la carte ne rende; sinon, le navigateur remplace une police qui est déjà disponible, et les paramètres de texte peuvent changer.

Pour le thème à l'échelle de l'application, voir [Thèmes et mode sombre](/guides/boards/ui/themes). Les thèmes de document de la Commission font partie de l'instantané de la Commission.
