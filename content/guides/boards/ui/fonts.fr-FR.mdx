title: Liste de polices personnalisée
icon: BookType
---

Boards conserve les choix de polices dans les données Board. Un thème peut définir `fontScheme.heading` et `fontScheme.body`, tandis qu’un élément de texte peut remplacer la famille, la taille et l’emphase avec `textStyle`.

## Définir la police d’un texte

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const label = board.insertText({
  text: 'Milestone',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

L’édition de texte utilise la chaîne Docs UI partagée, une dépendance technique de `@univerjs-pro/boards-ui`. Chargez les polices web dans la page hôte avant d’afficher le Board pour éviter les substitutions et changements de métriques.

Pour le thème partagé de l’application, consultez [Thèmes et mode sombre](/guides/boards/ui/themes). Le thème du document Board reste dans son instantané.
