Boards utilise le pipeline partagé de polices des documents et de l'interface utilisateur d'Univer pour le texte enrichi, les zones de texte et le texte des formes. Enregistrez les plugins de l'interface utilisateur de Docs et les plugins d'interface partagés avant `UniverBoardsUIPlugin` afin que les services nécessaires à la modification de texte soient disponibles.

## Configurer les polices du thème

Le thème Board peut définir les familles de polices des titres et du corps du texte :

```ts
const currentThemeId = board.getThemeData().id
if (!currentThemeId || !board.setTheme(currentThemeId)) {
  throw new Error('Cannot apply Board theme')
}
```

## Polices des éléments de texte

Les éléments de texte peuvent également comporter un style de texte explicite :

```ts
const label = board.insertText({
  id: 'label-1',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  text: 'Milestone',
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

Chargez les polices web dans l'application hôte avant d'effectuer le rendu de Board afin d'éviter tout décalage de mise en page.
