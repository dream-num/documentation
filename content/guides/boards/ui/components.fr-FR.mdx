L'interface utilisateur de Board se compose de contrôleurs de rendu, de menus, de barres d'outils flottantes, de fenêtres contextuelles sur le canevas et de composants du plan de travail. La plupart des applications utilisent les composants par défaut en enregistrant `UniverBoardsUIPlugin`.

## Personnaliser l'affichage du plan de travail

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  workbench: {
    content: true,
    header: false,
    headerMenu: false,
    toolbar: false,
    footer: false,
  },
})
```

## Personnaliser les outils de la barre d'outils

`toolbar.tools` permet de désactiver ou de renommer les outils Board proposés dans la barre d'outils par défaut.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  toolbar: {
    tools: {
      connector: { enabled: true, label: 'Connector' },
      pen: false,
    },
  },
})
```

## Étendre le rendu des éléments

Utilisez `additionalRenderAdapters` lorsque votre application introduit des types d'éléments Board personnalisés ou souhaite remplacer le mode de rendu d'un élément.

```ts
univer.registerPlugin(UniverBoardsUIPlugin, {
  additionalRenderAdapters: [customAdapter],
})
```
