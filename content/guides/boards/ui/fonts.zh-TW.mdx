畫板會共用 Univer 文件與 UI 的字型處理流程，以呈現富文字、文字方塊及圖形文字。請先註冊 Docs UI 與共用 UI 外掛，再註冊 `UniverBoardsUIPlugin`，確保文字編輯功能具備所需的服務。

## 設定主題字型

畫板主題可以定義標題與內文字型：

```ts
const currentThemeId = board.getThemeData().id
if (!currentThemeId || !board.setTheme(currentThemeId)) {
  throw new Error('Cannot apply Board theme')
}
```

## 文字元素的字型

文字元素也可以指定明確的文字樣式：

```ts
const label = board.insertText({
  id: 'label-1',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  text: 'Milestone',
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

請在呈現畫板前，先於宿主應用程式中載入網頁字型，以避免版面配置偏移。
