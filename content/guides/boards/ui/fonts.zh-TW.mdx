---
title: 自訂字型列表
icon: BookType
---

Boards 將字型選擇儲存在 Board 資料中。Board 主題可以透過 `fontScheme.heading` 和 `fontScheme.body` 定義標題和正文字型，單個文字元素可以透過 `textStyle` 覆蓋字型族、字號和強調樣式。

## 設定文字元素字型

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const label = board.insertText({
  text: 'Milestone',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

Board 的文字編輯使用與 Docs UI 共用的文字管線，這也是 `@univerjs-pro/boards-ui` 的一項技術依賴。請在 Board 渲染之前由宿主頁面載入 Web 字型，否則瀏覽器會使用已有字型替代，文字尺寸也可能隨之變化。

應用整體主題請參閱[主題與暗黑模式](/guides/boards/ui/themes)。Board 文件主題仍儲存在 Board 快照中。
