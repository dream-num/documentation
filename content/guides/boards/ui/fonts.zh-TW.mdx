Boards 把字型選擇儲存在 Board 資料中。Board 主題可以透過 `fontScheme.heading` 和 `fontScheme.body` 定義標題與內文字型；單一文字元素可以透過 `textStyle` 覆寫字型家族、字級和強調樣式。

## 設定文字元素字型

```ts
const board = univerAPI.getActiveBoard()
if (!board) throw new Error('No active Board')

const label = board.insertText({
  text: 'Milestone',
  left: 120,
  top: 96,
  width: 240,
  height: 64,
  textStyle: {
    fontFamily: 'Inter',
    fontSize: 18,
    bold: true,
  },
})
if (!label) throw new Error('Cannot insert label')
```

Board 文字編輯使用共用 Docs UI 文字管線，它是 `@univerjs-pro/boards-ui` 的技術相依套件。請在算繪 Board 前由主頁面載入 Web 字型；否則瀏覽器會替換為可用字型，文字尺寸也可能改變。

共用應用程式主題請參閱[主題與深色模式](/guides/boards/ui/themes)。Board 文件主題仍儲存在 Board 快照中。
