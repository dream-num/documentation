## Univer Boards란?

Univer 널은 Univer Office SDK에 있는 화포 제품입니다. 그것은 문서가 더 이상 격자, 페이지, 또는 활주 갑판 그러나 자유로운 모양 작업 공간이 없을 때 사용됩니다: 백색판, 도표, 끈끈한 주, 연결관, 묻힌 테이블 및 마음 지도는 여기에서 속합니다.

보드는 브라우저에서 임베디드 캔버스에 [Web SDK](/guides/sheets)를 사용하며 Web SDK는 헤드리스 콘텐츠 처리를 처리하고 있습니다. [Server SDK](/server)은 협업 및 파일 교환을 제공하며 [AI SDK](/ai)에서는 보드를 편집할 수 있습니다.

보드는 Web SDK의 독립적 인 단위 유형입니다. 런타임에서 응용 프로그램은 `UniverInstanceType.UNIVER_BOARD` 단위를 만들고 그 다음 요소에 대한 모델과 UI 플러그인을 등록하여 지원을해야합니다.

## 브라우저 호환성

Web SDK는 크롬 88 대상에 컴파일합니다. 즉, Web SDK가 모든 환경에서 실행되지 않습니다. 다음 브라우저와 Node.js 환경이 지원됩니다.

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK는 `Intl.Segmenter`에 의존합니다. 브라우저 또는 실행 환경이 그것을 지원하지 않는 경우, 대응 polyfill을 먼저 추가하십시오. 추천된 polyfill는 `@formatjs/intl-segmenter`입니다.
</Callout>

호환성 문제가 발생하면 해당 폴리필을 먼저 적용하십시오. 문제가 발생하면 [자주 묻는 질문](https://github.com/dream-num/univer/issues/new/choose).

## Node.js 호환성

<Callout type="warning">
  이 섹션은 Node.js 내부 Web SDK를 실행합니다. Web SDK가 Node.js에 기반한 빌드 도구를 통해 브라우저에서 실행될 때 적용되지 않습니다.
</Callout>

Web SDK는 Node.js v18.17.0 이상에서 실행됩니다.

## 주요 기능

- **페이지 및 요소 주문**: `pages`에 저장된 페이지는 각 페이지의 `elements`에서 저장한, 수평 둘 다에 명시한 순서 배열과 더불어.
- **캔버스 요소**: 원본, 모양, 이미지, 연결관, 그룹, 콘테이너, 및 swimlanes.
- **명령 중심 편집**: 요소 변경, 주문 및 부모 관계는 선택적 역사와 협업 통합을 위해 권한과 후크를 운반하는 하나의 명령 레이어를 통해 경로.
- **브라우저 캔버스**: 요소 렌더링, 선택, 변환, 클립보드, 텍스트 편집, 뷰포트 컨트롤, 패널.
- **Extensible 어댑터**: 테이블, 마음 지도, 도표, 자원, 인쇄 및 교환과 같은 선택적인 널 기능.
- **관련 제품** : 페이지, 리소스, 테마 및 활성 페이지 상태를 포함하여 `IBoardData` 스냅 샷의 생성, 복원 및 저장.

## 문서 읽는 방법

왼쪽의 navbar는 기본에서 고급으로 페이지가 표시됩니다. 따라서 독자가 응용 프로그램을 구축하면서 단계에 따라 단계를 따를 수 있습니다. 페이지는 어떤 순서로 읽을 수 있으며 사용 사례에 적용되지 않는 페이지는 건너 뛸 수 있습니다. 사이드바 헤더는 Univer 보드 문서로 전환을 제공합니다.

오른쪽의 내용의 테이블은 현재 페이지의 섹션 사이에 탐색을 제공합니다. 페이지를 신속하게 찾을 수 있도록 상단 또는 검색 단축키 (Ctrl + K 또는 Cmd + K)에서 검색 바를 사용합니다.

시작하려면 [빠른 시작](/guides/boards/getting-started/installation) 가이드를 참조하십시오.

## 사전 지식

문서는 newcomers에 작성되었지만, Web SDK에 집중할 수 있도록 기본 지식이 있다고 가정합니다.

리더는 JavaScript 및 생태계의 기본 이해를 가진 문서의 대부분을 얻습니다.

Web SDK가 Node.js에서 실행되는 경우 Node.js의 기본 이해도 좋습니다.

여러 사람들이 동일한 보드를 편집하거나 공유 된 역사, 의견, 또는 파일 변환이 필요합니다. [Univer Server SDK](/server)에서 해당 모듈을 추가하고 응용 프로그램 백엔드에서 실행하십시오. 인증, 권한, 저장 및 배포는 응용 프로그램의 책임에 남아 있습니다. 브라우저에서만 열리는 보드는 이러한 서비스를 필요로하지 않습니다.
