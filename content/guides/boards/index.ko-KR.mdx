## Univer Boards란?

Univer Boards는 Univer Pro의 캔버스 제품입니다. 문서가 더 이상 그리드나 페이지, 슬라이드 덱이 아니라 자유 형식의 작업 공간이어야 할 때 사용합니다. 화이트보드, 다이어그램, 스티커 메모, 연결선, 임베드된 표, 마인드 맵을 모두 이곳에서 다룰 수 있습니다.

Boards는 독립적인 Univer 유닛 유형으로 구현됩니다. 런타임에서 `UniverInstanceType.UNIVER_BOARD` 유닛을 생성한 다음, 지원하려는 요소에 필요한 모델 및 UI 플러그인을 등록합니다.


## 브라우저 호환성

Univer는 Chrome 88을 대상으로 컴파일되지만, 이것이 모든 주요 환경을 완벽하게 지원한다는 의미는 아닙니다. Univer가 다음 브라우저 및 Node.js 환경에서 원활하게 작동하도록 최선을 다하고 있습니다.

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer는 `Intl.Segmenter`에 의존합니다. 브라우저 또는 런타임 환경에서 이를 지원하지 않는다면 먼저 해당 polyfill을
  추가하세요. `@formatjs/intl-segmenter` 사용을 권장합니다.
</Callout>

호환성 문제가 발생하면 먼저 적절한 polyfill을 사용해 해결해 보세요. 문제가 계속되면 언제든지 [이슈를 제출해 주세요](https://github.com/dream-num/univer/issues/new/choose).

## Node.js 호환성

<Callout type="warning">
  참고: 이 내용은 Node.js 환경에서 Univer를 실행하는 경우에만 적용되며, Node.js 기반 빌드 도구를 사용해 브라우저에서
  Univer를 실행하는 경우에는 적용되지 않습니다.
</Callout>

Univer는 Node.js 환경에서 실행할 수 있으며 v18.17.0 이상 버전을 지원합니다.


## Boards를 사용해야 하는 경우

사용자가 콘텐츠를 공간에 자유롭게 배치할 수 있는 대형 캔버스가 애플리케이션에 필요하다면 Boards를 사용하세요. 브레인스토밍 보드, 순서도, 계획 맵, 팀 회고, 제품 다이어그램 등이 대표적인 예입니다. 주요 대상이 표 형식 데이터라면 [Univer Bases](/guides/bases)로 시작하세요. 스프레드시트라면 [Univer Sheets](/guides/sheets)로 시작하세요.

## 패키지 설치

핵심 Board 런타임은 모델 패키지와 UI 패키지로 나뉩니다. 표와 마인드 맵 요소는 Board 런타임 위에 추가하는 선택적 패키지입니다.

```bash
pnpm add @univerjs-pro/boards @univerjs-pro/boards-ui
pnpm add @univerjs-pro/boards-table @univerjs-pro/boards-table-ui
pnpm add @univerjs-pro/boards-mind @univerjs-pro/boards-mind-ui
```

## 패키지 구성

- `@univerjs-pro/boards`: Board 데이터 모델, 요소 스키마, 명령, 변형, 어댑터 서비스, 퍼사드 진입점 및 `UniverBoardsPlugin`
- `@univerjs-pro/boards-ui`: Board 캔버스 UI, 뷰포트, 선택 영역, 도형 편집, 연결선, 스티커 메모, 잉크 상호작용, 도구 모음, 컨텍스트 메뉴 및 `UniverBoardsUIPlugin`
- `@univerjs-pro/boards-table`: Board 표 요소 통합 및 `UniverBoardsTablePlugin`
- `@univerjs-pro/boards-table-ui`: 표 요소 UI, 렌더링 통합, 로캘 진입점 및 `UniverBoardsTableUIPlugin`
- `@univerjs-pro/boards-mind`: 마인드 맵 요소 통합 및 `UniverBoardsMindPlugin`
- `@univerjs-pro/boards-mind-ui`: 마인드 맵 UI 통합 및 `UniverBoardsMindUIPlugin`

## 플러그인 등록

아래 코드 조각은 Board 관련 설정만 보여 줍니다. 완전한 애플리케이션에는 공통 Univer 코어, 렌더링 엔진, UI, 라이선스 및 잉크 플러그인도 필요합니다.

```ts
import { UniverBoardsPlugin } from '@univerjs-pro/boards'
import { UniverBoardsMindPlugin } from '@univerjs-pro/boards-mind'
import { UniverBoardsMindUIPlugin } from '@univerjs-pro/boards-mind-ui'
import { UniverBoardsTablePlugin } from '@univerjs-pro/boards-table'
import { UniverBoardsTableUIPlugin } from '@univerjs-pro/boards-table-ui'
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'
import { UniverInstanceType } from '@univerjs/core'
import '@univerjs-pro/boards/facade'

univer.registerPlugin(UniverBoardsPlugin)
univer.registerPlugin(UniverBoardsUIPlugin)
univer.registerPlugin(UniverBoardsMindPlugin)
univer.registerPlugin(UniverBoardsMindUIPlugin)
univer.registerPlugin(UniverBoardsTablePlugin)
univer.registerPlugin(UniverBoardsTableUIPlugin)

univer.createUnit(UniverInstanceType.UNIVER_BOARD, {})
```
