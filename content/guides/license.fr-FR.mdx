---
title: Licence
description: Obtenir une licence Univer Office SDK et la configurer dans votre application navigateur.
---

Pour les fonctionnalités nécessitant une licence, consultez les offres sur le [site Univer](https://univer.ai) et obtenez une licence. Configurez le **contenu de la licence client** dans le mode préréglage ou plugin utilisé par votre projet.

## Mode préréglage [#in-preset-mode]

Ajoutez `license` à votre configuration de préréglage existante. Par exemple, avec `UniverSheetsAdvancedPreset` :

```ts
UniverSheetsAdvancedPreset({
  // Keep your other options and replace this placeholder with the client license content.
  license: 'YOUR_CLIENT_LICENSE',
})
```

Fournissez le contenu de la licence, et non le chemin d’un fichier de licence.

## Mode plugin [#in-plugin-mode]

Enregistrez `UniverLicensePlugin` sur votre instance Univer existante, avant les autres plugins :

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_CLIENT_LICENSE',
})
```

## Applications collaboratives

Les applications collaboratives configurent également la licence dans le navigateur. L’exemple navigateur du [démarrage rapide Office](/server/collaboration/quick-start) montre où enregistrer le plugin de licence avec ceux de collaboration. Alignez les paquets du navigateur et du serveur selon les [exigences d’environnement et de version des SDK](/server/requirements).

La licence détermine les fonctionnalités disponibles. Les autorisations de votre application déterminent qui peut consulter ou modifier un document. Après la configuration de la licence, suivez l’[intégration serveur](/server) pour connecter la connexion utilisateur et les droits sur les documents.

## Vérifier la configuration

Rouvrez l’application et essayez les fonctionnalités nécessaires. Si des filigranes ou restrictions subsistent, vérifiez que le contenu de la licence est complet, valide et couvre la fonctionnalité et la version utilisées. En mode plugin, vérifiez aussi l’ordre d’enregistrement. Contactez votre fournisseur de licence si le problème persiste.
