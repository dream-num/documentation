## Designsystem

Das Designsystem von Univer basiert auf Tailwind CSS und erstellt eine Reihe von Design-Tokens, die von der Rendering-Engine wiederverwendet werden, um einen konsistenten Stil zwischen der Rendering-Engine und der Ansichtsebene sicherzustellen. Sie können die Stile Ihrer Anwendung anpassen, indem Sie diese Token ändern, die im Paket `@univerjs/themes` gespeichert sind.
