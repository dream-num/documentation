## Verwenden von Official Themen

`@univerjs/themes` exportiert `defaultTheme` (auch als `blueTheme`), `darkBlueTheme`, `greenTheme`, `orangeTheme`, `purpleTheme`, `redTheme` und `yellowTheme`.

<Callout>Wenn kein Thema angegeben ist, wird standardmäßig `defaultTheme` verwendet.</Callout>

### Themen-Plugins installieren

#### Voreingestellter Modus

Im voreingestellten Modus können Themen aus dem Paket `@univerjs/presets` importiert werden:

```typescript
// import { defaultTheme } from "@univerjs/presets";
import { yellowTheme } from '@univerjs/presets'

const { univer } = createUniver({
  theme: yellowTheme,
  // theme: defaultTheme,
})
```

#### Plugin-Modus

Im Plugin-Modus werden Themen von bereitgestellt `@univerjs/themes`-Paket, das Sie zuerst installieren müssen.

```package-install
npm install @univerjs/themes
```

```typescript
import { yellowTheme } from '@univerjs/themes'
// import { defaultTheme } from "@univerjs/themes";

const univer = new Univer({
  theme: yellowTheme,
  // theme: defaultTheme,
})
```

## Designs anpassen

Sie können Designs anpassen, indem Sie ein Objekt erstellen, das der `Theme`-Schnittstelle entspricht. Lesen Sie [diese Dokumentation ](https://docs.univer.ai/reference/types/theme), um zu verstehen, wie die Standard-Designvariablen definiert sind.

```typescript title="custom-theme.ts"
import type { Theme } from '@univerjs/presets'
// import type { Theme } from "@univerjs/themes";

export const customTheme: Theme = {
  white: '#FEFEFE',
  black: '#1C1C1C',
  primary: {
    50: '#F6F5FF',
    100: '#EDEBFE',
    200: '#DCD7FE',
    300: '#CABFFD',
    400: '#AC94FA',
    500: '#9061F9',
    600: '#7E3AF2',
    700: '#6C2BD9',
    800: '#5521B5',
    900: '#4A1D96',
  },
  // ...
}
```

```typescript
// Import your custom theme here
import { customTheme } from './custom-theme'

const univer = new Univer({
  theme: customTheme,
})
```

## Dunkler Modus

Univer unterstützt Dunkel Modus, der aktiviert werden kann, indem die Eigenschaft `darkMode` auf `true` gesetzt wird.

```typescript
new Univer({
  darkMode: true,
})
```

### Facade API

Sie können den Dunkelmodus auch dynamisch mit der Facade API umschalten.

```typescript
import { darkBlueTheme } from '@univerjs/themes'

univerAPI.setTheme(darkBlueTheme)
const currentTheme = univerAPI.getCurrentTheme()
console.log(univerAPI.isDarkMode(), currentTheme)

univerAPI.toggleDarkMode(false)
```
