## Komponenten

Univer verwendet React-Komponenten zum Erstellen der Ansichtsebene, was es Entwicklern, die auch React verwenden, sehr einfach macht, entweder die Komponenten von Univer zu verwenden oder benutzerdefinierte Komponenten zu registrieren. Dies bedeutet jedoch nicht, dass Sie React nur zum Erstellen benutzerdefinierter Komponenten verwenden können. Univer unterstützt auch andere Frameworks wie Vue (Version 3.x) und Web Components.

Alle Basiskomponenten werden im Paket `@univerjs/design` gespeichert, und Symbolkomponenten werden im Paket `@univerjs/icons` gespeichert. Diese Komponenten können auch unabhängig von Univer verwendet werden.

Benutzerdefinierte Komponenten werden häufig in den folgenden Szenarien verwendet:

- Hinzufügen benutzerdefinierter Schaltflächen im Menüband/Kontextmenü
- Integration benutzerdefinierter Komponenten in Seitenleiste/Popup usw.
- Ersetzen integrierter Komponenten

Detaillierte Anweisungen zur Registrierung und Verwendung benutzerdefinierter Komponenten finden Sie in den folgenden Kapiteln.
