## Schriftstrukturdefinition

In Univer werden Schriftarten mithilfe der Schnittstelle `IFontConfig` definiert:

| Eigenschaft | Typ | Beschreibung |
| --- | --- | --- |
| `value` | `string` | Die eindeutige Kennung der Schriftart, normalerweise der bevorzugte Wert für CSS-Schriftfamilie. |
| `label` | `string` | Der Übersetzungsschlüssel für die Internationalisierung. Wenn dieser Schlüssel beim Erstellen der Univer-Instanz nicht angegeben wird, wird der übergebene Wert direkt angezeigt. |
| `category` | `'sans-serif' \| 'serif' \| 'monospace' \| 'display' \| 'handwriting'` | Schriftkategorie, die für die UI-Gruppierung verwendet wird (optional). |

<Callout>
Univer verhindert nicht, dass Benutzer nicht installierte Schriftarten auswählen. Wenn eine Schriftart nicht auf dem Client installiert ist, ersetzt der Browser sie durch die Standardschriftart.
</Callout>

## Benutzerdefinierte Schriftarten verwenden

Sie können die Optionen im Schriftarten-Dropdown-Menü definieren, indem Sie den Parameter `customFontFamily` für `UniverSheetsCorePreset` (Voreinstellungsmodus) oder `UniverUIPlugin` (Plugin-Modus) konfigurieren.

<Tabs items={['Preset Mode', 'Plugin Mode']}>
  <Tab>
    ```typescript
    const { univerAPI } = createUniver({
      presets: [
        UniverSheetsCorePreset({
          container: 'app',
          customFontFamily: {
            list: [
              {
                value: 'PingFang SC',
                label: '苹方（简）',
                category: 'sans-serif',
              },
              {
                value: 'Helvetica Neue',
                label: 'Helvetica Neue',
                category: 'sans-serif',
              },
            ],
            // Whether to override the default font list, defaults to false
            override: true,
          },
        }),
      ],
    })
    ```
  </Tab>
  <Tab>
    ```typescript
    univer.registerPlugin(UniverUIPlugin, {
      container: 'app',
      customFontFamily: {
        list: [
          {
            value: 'PingFang SC',
            label: '苹方（简）',
            category: 'sans-serif',
          },
          {
            value: 'Helvetica Neue',
            label: 'Helvetica Neue',
            category: 'sans-serif',
          },
        ],
        // Whether to override the default font list, defaults to false
        override: true,
      },
    })
    ```
  </Tab>
</Tabs>

### Fassaden-API

Zusätzlich zur Konfiguration während der Initialisierung können Sie neue Schriftarten auch dynamisch registrieren unter Laufzeit über die Facade API. Dies ist sehr nützlich in Szenarien, in denen Schriftartressourcen asynchron geladen werden müssen.

```typescript
univerAPI.addFonts([{
  value: 'PingFang SC',
  label: 'PingFang SC',
  category: 'sans-serif',
}, {
  value: 'Helvetica Neue',
  label: 'Helvetica Neue',
  category: 'sans-serif',
}])
```
