## Méthode `mergeLocales` [#mergeLocales]

La méthode `mergeLocales` permet de fusionner les packs linguistiques de plusieurs plugins ou préréglages en un seul objet complet. Vous pouvez l’utiliser comme suit :

<Tabs items={['Mode préréglage', 'Mode plugin']}>
  <Tab>
    ```typescript
    import { mergeLocales } from '@univerjs/presets'

    // You can pass multiple language pack objects to merge
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // You can also pass an array of language pack objects
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    ])
    ```
  </Tab>
  <Tab>
    ```typescript
    import { mergeLocales } from '@univerjs/core'

    // You can pass multiple language pack objects to merge
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // You can also pass an array of language pack objects
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    ])
    ```
  </Tab>
</Tabs>

## Packs linguistiques personnalisés

Univer prend également en charge les packs linguistiques personnalisés. Vous pouvez créer un objet de pack linguistique selon vos besoins et le transmettre à l’instance `Univer`. Les packs linguistiques des préréglages se trouvent généralement dans le répertoire `<rootDir>/packages/<PLUGIN_NAME>/locale`.

```typescript
const univer = new Univer({
  locale: 'ja-JP',
  locales: {
    'ja-JP': {
      ui: {
        shortcut: {
          undo: '元に戻す',
          redo: 'やり直す',
        },
      },
    },
  },
})
```

## Contribuer aux traductions

Univer propose actuellement les packs linguistiques intégrés suivants :

- `zh-CN` : chinois simplifié
- `en-US` : anglais
- `zh-TW` : chinois traditionnel
- `zh-HK` : chinois traditionnel (Hong Kong)
- `ru-RU` : russe
- `vi-VN` : vietnamien
- `fa-IR` : persan
- `fr-FR` : français
- `ja-JP` : japonais
- `ko-KR` : coréen
- `es-ES` : espagnol
- `ca-ES` : catalan
- `sk-SK` : slovaque
- `ar-SA` : arabe
- `de-DE` : allemand
- `id-ID` : indonésien
- `it-IT` : italien
- `pl-PL` : polonais
- `pt-BR` : portugais (Brésil)

Univer OSS est un projet open source inclusif. Nous invitons les développeurs du monde entier à ajouter ou à améliorer les locales d’Univer.
