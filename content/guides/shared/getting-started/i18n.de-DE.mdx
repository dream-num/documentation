## `mergeLocales` Methode [#mergeLocales]

`mergeLocales` Methode wird verwendet, um mehrere Plugins oder voreingestellte Sprachpakete zu einem vollständigen Sprachpaketobjekt zusammenzuführen. Sie können es wie folgt verwenden:

<Tabs items={['Preset Mode', 'Plugin Mode']}>
  <Tab>
    ```typescript
    import { mergeLocales } from '@univerjs/presets'

    // You can pass multiple language pack objects to merge
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // You can also pass an array of language pack objects
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    ])
    ```
  </Tab>
  <Tab>
    ```typescript
    import { mergeLocales } from '@univerjs/core'

    // You can pass multiple language pack objects to merge
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // You can also pass an array of language pack objects
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    ])
    ```
  </Tab>
</Tabs>

## Benutzerdefinierte Sprachpakete

Univer unterstützt auch benutzerdefinierte Sprachpakete. Sie können ein Sprachpaketobjekt nach Bedarf zusammenstellen und es an die Instanz `Univer` übergeben. Die voreingestellten Sprachpakete werden im Allgemeinen im Verzeichnis `<rootDir>/packages/<PLUGIN_NAME>/locale` gespeichert.

```typescript
const univer = new Univer({
  locale: 'ja-JP',
  locales: {
    'ja-JP': {
      ui: {
        shortcut: {
          undo: '元に戻す',
          redo: 'やり直す',
        },
      },
    },
  },
})
```

## Mitwirkende Übersetzungen

Univer bietet derzeit die folgenden integrierten Sprachpakete an:

- `zh-CN`: Vereinfachtes Chinesisch
- `en-US`: Englisch
- `zh-TW`: Traditionell Chinesisch
- `zh-HK`: Traditionelles Chinesisch (Hongkong)
- `ru-RU`: Russisch
- `vi-VN`: Vietnamesisch
- `fa-IR`: Persisch
- `fr-FR`: Französisch
- `ja-JP`: Japanisch
- `ko-KR`: Koreanisch
- `es-ES`: Spanisch
- `ca-ES`: Katalanisch
- `sk-SK`: Slowakisch
- `ar-SA`: Arabisch
- `de-DE`: Deutsch
- `id-ID`: Indonesisch
- `it-IT`: Italienisch
- `pl-PL`: Polnisch
- `pt-BR`: Portugiesisch (Brasilianisch)

Univer OSS ist ein Open-Source-Projekt voller Inklusivität, und wir heißen Entwickler aus der ganzen Welt willkommen, Gebietsschemas für Univer hinzuzufügen oder zu verbessern.
