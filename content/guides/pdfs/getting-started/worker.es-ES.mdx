Los PDF pueden renderizar las miniaturas de la página en un Worker[^web-worker]. Pasando `thumbnailWorkerURL` a `UniverPdfsUIPlugin` hace que el Worker use `OffscreenCanvas` . Esta opción no mueve a todo el editor de PDF en un Trabajador.

Comience con [instalación y uso básico](/guides/pdfs/getting-started/installation); los snippets de abajo extienden esa configuración. Registre los plugins antes de crear o cargar contenido, y actualice un registro existente en lugar de registrar el mismo plugin dos veces.

## Hilo principal

`UniverPdfsUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | Genera miniaturas en un Worker del navegador. |

```typescript title="main.ts"
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'

univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Entrada del Worker

```typescript title="worker.ts"
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

Utilice un módulo Trabajador con un archivo de entrada independiente. Mantenga las versiones del paquete en el Worker y en el hilo principal alineado. Rendering e interacción del usuario permanecen en el hilo central.

[^web-worker]: Un Web Worker ejecuta JavaScript fuera del hilo principal del navegador y se comunica mediante mensajes. No puede acceder directamente al DOM; mover los cálculos no mueve la interfaz del editor.
