PDFs permite renderizar miniaturas de páginas en un Worker. Pasa `thumbnailWorkerURL` a `UniverPdfsUIPlugin`. El Worker usa `OffscreenCanvas`. Esta opción afecta a las miniaturas, no al editor PDF completo.

Completa primero la [instalación y el uso básico](/guides/pdfs/getting-started/installation). Estos fragmentos amplían la configuración existente. Registra los plugins antes de crear o cargar contenido; modifica los registros existentes sin duplicarlos.

## Hilo principal

```typescript title="main.ts"
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'

univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Entrada del Worker

```typescript title="worker.ts"
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

Usa un Worker de tipo módulo y un archivo de entrada independiente. Mantén iguales las versiones de los paquetes en ambos lados. El renderizado y la interacción permanecen en el hilo principal.
