title: 升级到 Pro
icon: '#pro/Sparkles'
---

Univer PDFs 通过 Univer Pro 分发。生产应用需要有效的 Pro 许可证，由服务器支持的功能还需要部署 Univer Pro Server。

## 许可证插件

请在 PDF 插件之前注册许可证，并将许可证文本保存在源代码管理之外：

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

通过构建或运行时配置注入该值。请勿在浏览器或 Node.js 源文件中嵌入许可证字符串、会话 Cookie 或服务器凭据。

## PDF 包

| 能力                      | 包                                                                    |
| ------------------------- | --------------------------------------------------------------------- |
| PDF 单元模型和 Facade     | `@univerjs-pro/pdfs`                                                  |
| 编辑器和协作契约          | `@univerjs-pro/pdfs-editor`                                           |
| 浏览器 Canvas 和编辑器 UI | `@univerjs-pro/pdfs-ui`                                               |
| PDF 导入和导出            | `@univerjs-pro/exchange-client`、`@univerjs-pro/pdfs-exchange-client` |
| 浏览器打印                | `@univerjs-pro/pdfs-print`                                            |
| 实时协作                  | `@univerjs-pro/collaboration`、`@univerjs-pro/collaboration-client`   |

目前没有 PDF 预设。请仅注册应用所需的插件。

## 服务器要求

| 工作流                        | 是否需要 Univer Pro Server |
| ----------------------------- | :------------------------: |
| 创建、查看或编辑本地 PDF 快照 |             否             |
| 导入或导出 PDF 文件           |             是             |
| 持久化并协同编辑 PDF 单元     |             是             |
| 打开浏览器打印对话框          |             否             |

导入和导出 API 的快照变体不要求协作持久化，但转换仍然通过 Exchange 服务器运行。

## 部署说明

- 在 PDF 功能 CSS 之前加载 Univer 公共 UI CSS。
- 通过插件选项配置 Exchange 和协作端点，不要在应用各处硬编码部署专用 URL。
- Node.js 服务中不要包含仅供浏览器使用的 UI 和打印插件。
- 在依赖完全一致的视觉保真度之前，验证使用不常见字体、色彩空间、批注或其他高级 PDF 功能的导入文件。

有关许可证和服务器部署的详细信息，请参阅 [Univer Pro](/guides/pro)。
