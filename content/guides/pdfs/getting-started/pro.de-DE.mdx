Univer PDFs wird über Univer Pro vertrieben. Produktionsanwendungen benötigen eine gültige Pro-Lizenz; servergestützte Funktionen benötigen außerdem eine Univer-Pro-Server-Bereitstellung.

## Lizenz-Plugin

Registrieren Sie die Lizenz vor den PDF-Plugins und halten Sie den Lizenztext aus der Quellcodeverwaltung heraus:

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

Fügen Sie den Wert über Ihre Build- oder Laufzeitkonfiguration ein. Betten Sie keine Lizenzzeichenfolgen, Sitzungscookies oder Serveranmeldedaten in Browser- oder Node.js-Quelldateien ein.

## PDF-Pakete

| Fähigkeit                           | Pakete                                                                |
| ----------------------------------- | --------------------------------------------------------------------- |
| PDF-Einheitsmodell und Facade       | `@univerjs-pro/pdfs`                                                  |
| Editor- und Zusammenarbeitsverträge | `@univerjs-pro/pdfs-editor`                                           |
| Browser-Canvas und Editoroberfläche | `@univerjs-pro/pdfs-ui`                                               |
| PDF-Import und -Export              | `@univerjs-pro/exchange-client`, `@univerjs-pro/pdfs-exchange-client` |
| Browserdruck                        | `@univerjs-pro/pdfs-print`                                            |
| Echtzeit-Zusammenarbeit             | `@univerjs-pro/collaboration`, `@univerjs-pro/collaboration-client`   |

Derzeit gibt es kein PDF-Preset. Registrieren Sie nur die Plugins, die Ihre Anwendung benötigt.

## Serveranforderungen

| Arbeitsablauf                                            | Univer Pro Server erforderlich |
| -------------------------------------------------------- | :----------------------------: |
| Lokalen PDF-Snapshot erstellen, anzeigen oder bearbeiten |              Nein              |
| PDF-Datei importieren oder exportieren                   |               Ja               |
| PDF-Einheit speichern und gemeinsam bearbeiten           |               Ja               |
| Druckdialog des Browsers öffnen                          |              Nein              |

Die Snapshot-Varianten der Import- und Export-APIs vermeiden die gemeinsame Speicherung, die Konvertierung erfolgt jedoch weiterhin über den Exchange-Server.

## Bereitstellungshinweise

- Laden Sie das gemeinsame Univer-UI-CSS vor dem CSS der PDF-Funktionen.
- Konfigurieren Sie Exchange- und Collaboration-Endpunkte über Plugin-Optionen, statt bereitstellungsspezifische URLs in der gesamten Anwendung fest zu codieren.
- Halten Sie Node.js-Dienste frei von Browser-exklusiven UI- und Druck-Plugins.
- Validieren Sie importierte PDFs, die ungewöhnliche Schriftarten, Farbräume, Anmerkungen oder andere erweiterte PDF-Funktionen verwenden, bevor Sie sich auf exakte visuelle Wiedergabetreue verlassen.

Details zu Lizenz und Serverbereitstellung finden Sie unter [Univer Pro](/guides/pro).
