PDFs 支持在 Worker[^web-worker] 中渲染页面缩略图。将 `thumbnailWorkerURL` 传给 `UniverPdfsUIPlugin` 后，Worker 会使用 `OffscreenCanvas`。该选项不会把整个 PDF 编辑器移入 Worker。

请先完成[安装和基本使用](/guides/pdfs/getting-started/installation)，下面的代码片段在该配置的基础上继续扩展。插件必须在创建或加载内容之前注册；如果插件已经注册，应修改原有注册，不要重复注册。

## 主线程

`UniverPdfsUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | 在浏览器 Worker 中渲染缩略图。 |

```typescript title="main.ts"
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'

univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Worker 入口

```typescript title="worker.ts"
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

使用模块类型的 Worker 和独立的入口文件。Worker 与主线程中的包版本必须保持一致。渲染和用户交互仍保留在主线程。

[^web-worker]: Web Worker 在浏览器主线程之外执行 JavaScript，通过消息与主线程通信，不能直接访问页面 DOM。把计算放入 Worker 并不意味着把编辑器界面也迁入其中。
