Univer PDFs распространяется в составе Univer SDK Pro. Для рабочих приложений требуется действующая лицензия Pro, а для серверных функций — также развёртывание Univer SDK Pro Server.

## Плагин лицензии

Зарегистрируйте лицензию перед плагинами PDF и храните её текст вне системы контроля версий:

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

Передавайте значение через конфигурацию сборки или среды выполнения. Не встраивайте строки лицензий, файлы cookie сеанса или учётные данные сервера в исходные файлы браузерного приложения или Node.js.

## Пакеты PDF

| Возможность                             | Пакеты                                                                |
| --------------------------------------- | --------------------------------------------------------------------- |
| Модель модуля PDF и фасад               | `@univerjs-pro/pdfs`                                                  |
| Контракты редактора и совместной работы | `@univerjs-pro/pdfs-editor`                                           |
| Браузерный холст и интерфейс редактора  | `@univerjs-pro/pdfs-ui`                                               |
| Импорт и экспорт PDF                    | `@univerjs-pro/exchange-client`, `@univerjs-pro/pdfs-exchange-client` |
| Браузерная печать                       | `@univerjs-pro/pdfs-print`                                            |
| Совместная работа в реальном времени    | `@univerjs-pro/collaboration`, `@univerjs-pro/collaboration-client`   |

Готовой конфигурации PDF пока нет. Регистрируйте только те плагины, которые нужны приложению.

## Требования к серверу

| Процесс                                                     | Требуется Univer SDK Pro Server |
| ----------------------------------------------------------- | :-------------------------: |
| Создание, просмотр или редактирование локального снимка PDF |             Нет             |
| Импорт или экспорт файла PDF                                |             Да              |
| Сохранение и совместное редактирование модуля PDF           |             Да              |
| Открытие браузерного диалога печати                         |             Нет             |

Варианты API импорта и экспорта, работающие со снимками, не требуют совместного хранения, однако преобразование по-прежнему выполняется сервером Exchange.

## Примечания по развёртыванию

- Загружайте CSS общего интерфейса Univer перед CSS функций PDF.
- Настраивайте конечные точки Exchange и совместной работы через параметры плагинов, а не размещайте URL конкретного развёртывания по всему коду приложения.
- Не добавляйте в сервисы Node.js плагины интерфейса и печати, предназначенные только для браузера.
- Проверяйте импортированные PDF, в которых используются необычные шрифты, цветовые пространства, аннотации или другие расширенные функции PDF, прежде чем рассчитывать на точное визуальное соответствие.

Дополнительные сведения о лицензии и развёртывании сервера см. в разделе [Univer SDK Pro](/guides/pro).
