安裝 Univer PDFs 前，請先了解構成 PDF 整合基礎的四個概念：

- 外掛 Plugin
- 快照與資料模型 Snapshot and Data Model
- 命令 Command
- Facade API

## 基本概念 [#basic-concepts]

### 外掛

Univer PDFs 由外掛組合而成。`UniverPdfsPlugin` 註冊 `UNIVER_PDF` 單元模型和可持久化的 PDF 命令。`UniverPdfsUIPlugin` 提供瀏覽器檢視器，並預設啟用編輯控制項。列印、交換或協同等選用套件，只需依產品需求加入。

這些外掛執行於 Univer 共用的核心、算繪、設計和 UI 服務之上。它們是 PDF 應用程式的技術依賴，不要求你使用過其他 Univer 品類。

### 快照與資料模型

一個 PDF 單元以 [`IPdfUnitData` 快照](/guides/pdfs/model/pdf-data)持久化。`document` 是匯入或空白的來源基準，已接受的編輯則儲存在 `editState` 中，不會直接重寫該基準。

使用 `pdf.save()` 取得完整的目前快照。`pdf.getDocument()` 會回傳來源基準，因此持久化使用者編輯時應使用 `save()`。

### 命令

執行時的資料變更透過命令執行，讓驗證、檢視更新、編輯歷程和匯出意圖進入同一條變更流程。PDF Facade 方法會替你準備參數並執行對應命令。

<Callout type="warning" title="注意">
  不要直接修改執行中 PDF 單元的快照或來源文件。請使用 PDF Facade 方法或已註冊的命令。
</Callout>

### Facade API

在核心 Facade 入口之後匯入 `@univerjs-pro/pdfs/facade`，即可把 PDF API 擴充到 `FUniver`。該入口提供 `createPdf()`、`getActivePdf()` 和 `getPdf()` 等方法。

完整設定與範例請參閱[使用 PDF Facade API](/guides/pdfs/getting-started/facade)。
