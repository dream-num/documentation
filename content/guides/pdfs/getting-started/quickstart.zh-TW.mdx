以下四個概念出現在每一處 PDF 整合中，安裝 Univer PDFs 之前應先了解：

- 外掛 Plugin
- 快照與資料模型 Snapshot and Data Model
- 命令 Command
- Facade API

## 基本概念 [#basic-concepts]

### 外掛

Univer PDFs 由一組外掛構成。`UniverPdfsPlugin` 註冊 `UNIVER_PDF` 單元模型和可持久化的 PDF 命令；`UniverPdfsUIPlugin` 提供瀏覽器檢視器，並預設套件含編輯控制元件。僅在應用需要這些能力時新增列印、檔案交換或協同包。

這兩個外掛執行在 Univer 各產品共用的核心、渲染、設計和 UI 服務之上。這些服務是 PDF 應用的技術依賴，使用它們不需要事先熟悉其他 Univer 產品。

### 快照與資料模型

PDF 單元以 [`IPdfUnitData` 快照](/guides/pdfs/model/pdf-data)持久化。`document` 欄位儲存源基線，其內容為匯入的文件或空白文件。已接受的編輯寫入 `editState`，因此源基線本身不會被就地改寫。

呼叫 `pdf.save()` 可獲得完整的當前快照。`pdf.getDocument()` 只返回源基線，因此使用者編輯需要透過 `save()` 持久化。

### 命令

執行時的改動均透過命令應用，校驗、檢視更新、編輯歷史和匯出意圖由此落在同一條鏈路上。PDF Facade 方法會準備命令參數並執行相應的命令。

<Callout type="warning" title="注意">
  不要直接修改執行中的 PDF 單元的快照或源文件。請改用 PDF Facade 方法或已註冊的命令。
</Callout>

### Facade API

在核心 Facade 入口之後匯入 `@univerjs-pro/pdfs/facade`，即可為 `FUniver` 新增 PDF API。該入口提供 `createPdf()`、`getActivePdf()`、`getPdf()` 等方法。

完整的配置方式和範例見[使用 PDF Facade API](/guides/pdfs/getting-started/facade)。

接下來請閱讀[安裝和基本使用](/guides/pdfs/getting-started/installation)。
