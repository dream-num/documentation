---
title: 在 Next.js 中整合
---

請先閱讀[安裝和基本使用](/guides/pdfs/getting-started/installation)。下面的範例使用 Next.js App Router 掛載 Univer Pdfs，容器需要指定明確的高度。

在客戶端元件中透過 `ssr: false`[^ssr] 載入編輯器。僅新增 `use client` 指令並不會關閉預渲染，具體參見 [Next.js](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr)。

`YOUR_CLIENT_LICENSE` 處應填寫客戶端許可證的內容，不能填寫檔案路徑。參見[許可證配置](/server/license)。

### 整合步驟

1. 在 `useEffect` 中建立 Univer 例項。
2. 在 `useEffect cleanup` 中銷燬該例項。

### 外掛設定 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 編輯器掛載的 DOM 元素或元素 ID。 |

`UniverLicensePlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 用戶端授權檔的內容。 |

### 範例程式碼

每次掛載都使用獨立的子容器。銷燬操作放在外層 React 清理之後的微任務中執行，因此巢狀的 React root 不會在 React 提交過程中被同步解除安裝。

```tsx title="univer-editor.tsx"
'use client'

import { useEffect, useRef } from 'react'
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIzhTW from '@univerjs-pro/pdfs-ui/locale/zh-TW'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignzhTW from '@univerjs/design/locale/zh-TW'
import { UniverUIPlugin } from '@univerjs/ui'
import UIzhTW from '@univerjs/ui/locale/zh-TW'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const univer = new Univer({
      locale: LocaleType.ZH_TW,
      locales: {
        [LocaleType.ZH_TW]: mergeLocales(
          DesignzhTW,
          UIzhTW,
          PdfsUIzhTW,
        ),
      },
    })

    univer.registerPlugin(UniverLicensePlugin, {
      license: 'YOUR_CLIENT_LICENSE',
    })
    univer.registerPlugin(UniverUIPlugin, { container })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return <div ref={containerRef} style={{ height: 600 }} />
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: 伺服器端渲染（SSR）會在瀏覽器載入頁面前執行渲染程式，此時沒有瀏覽器的 `window` 與 DOM。Client Component 仍可能被預先渲染，因此需單獨停用編輯器元件的 SSR。
