---
title: Интеграция с Next.js
---

Начните с [Установка и базовое использование](/guides/pdfs/getting-started/installation). В приведенном ниже примере используется маршрутизатор приложений Next.js для установки Pdfs Univer в контейнере с явной высотой.

Загрузите редактор из Компонента клиента с помощью `ssr: false`[^ssr]. Только директива `use client` не отключает предварительный рендеринг. См. [Next.js](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr).

Размещайте содержимое лицензии клиента там, где появляется `YOUR_CLIENT_LICENSE`; путь файла здесь не работает. См. [Конфигурация лицензии](/server/license).

### Шаги интеграции

1. Создайте экземпляр Univer в `useEffect`.
2. Освободите экземпляр в функции очистки `useEffect`.

### Настройка плагинов [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для редактора или его идентификатор. |

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое клиентского файла лицензии. |

### Пример кода

Утилизация выполняется в микрозадаче после окружающей очистки React, поэтому вложенные корни React не синхронно устанавливаются во время выполнения React.

```tsx title="univer-editor.tsx"
'use client'

import { useEffect, useRef } from 'react'
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIruRU from '@univerjs-pro/pdfs-ui/locale/ru-RU'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignruRU from '@univerjs/design/locale/ru-RU'
import { UniverUIPlugin } from '@univerjs/ui'
import UIruRU from '@univerjs/ui/locale/ru-RU'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const univer = new Univer({
      locale: LocaleType.RU_RU,
      locales: {
        [LocaleType.RU_RU]: mergeLocales(
          DesignruRU,
          UIruRU,
          PdfsUIruRU,
        ),
      },
    })

    univer.registerPlugin(UniverLicensePlugin, {
      license: 'YOUR_CLIENT_LICENSE',
    })
    univer.registerPlugin(UniverUIPlugin, { container })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return <div ref={containerRef} style={{ height: 600 }} />
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: Серверный рендеринг (SSR) выполняет код отрисовки до загрузки страницы браузером, без `window` и DOM. Client Component также может предварительно отрисовываться, поэтому SSR редактора отключается отдельно.
