---
title: Intégrer dans Astro
---

Commencer par [l'installation et l'utilisation de base](/guides/pdfs/getting-started/installation). L'exemple ci-dessous utilise Astro pour monter des Pdfs Univer dans un conteneur avec une hauteur explicite.

Utilisez un élément simple `<script>` pour initialiser l'éditeur directement dans le navigateur. Initialiser sur la première charge et de nouveau sur `astro:page-load`. Avec ClientRouter, disposer de l'instance avant `astro:before-swap` . Conserver les importations de l'éditeur hors de la matière première Astro (voir [Événements de navigation Astro](https://docs.astro.build/en/reference/modules/astro-transitions/)).

### Étapes d’intégration

1. Créez l'instance Univer dans `mount()` / `astro:page-load`.
2. Jetez l'instance dans `astro:before-swap`.

### Configuration des plugins [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Élément DOM où monter l’éditeur, ou son identifiant. |

`UniverLicensePlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenu du fichier de licence client. |

### Exemple de code

```astro title="src/pages/index.astro"
<div id="univer-pdfs" style="height: 600px"></div>

<script>
  import { UniverLicensePlugin } from '@univerjs-pro/license'
  import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
  import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
  import PdfsUIfrFR from '@univerjs-pro/pdfs-ui/locale/fr-FR'
  import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
  import { FUniver } from '@univerjs/core/facade'
  import DesignfrFR from '@univerjs/design/locale/fr-FR'
  import { UniverUIPlugin } from '@univerjs/ui'
  import UIfrFR from '@univerjs/ui/locale/fr-FR'

  import '@univerjs/design/lib/index.css'
  import '@univerjs/ui/lib/index.css'
  import '@univerjs-pro/pdfs-ui/lib/index.css'

  import '@univerjs-pro/pdfs/facade'

  let univerInstance: Univer | undefined

  function mount() {
    const container = document.getElementById('univer-pdfs')
    if (!container || univerInstance) return

    const univer = new Univer({
      locale: LocaleType.FR_FR,
      locales: {
        [LocaleType.FR_FR]: mergeLocales(
          DesignfrFR,
          UIfrFR,
          PdfsUIfrFR,
        ),
      },
    })

    univer.registerPlugin(UniverLicensePlugin, {
      license: 'your license.txt',
    })
    univer.registerPlugin(UniverUIPlugin, { container })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })
    univerInstance = univer
  }

  function dispose() {
    univerInstance?.dispose()
    univerInstance = undefined
  }

  mount()
  document.addEventListener('astro:page-load', mount)
  document.addEventListener('astro:before-swap', dispose)
</script>
```
