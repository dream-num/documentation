title: Интеграция в React

Сначала прочитайте [Установка и базовое использование](/guides/pdfs/getting-started/installation). Компонент React ниже монтирует Univer Pdfs в контейнере, высота которого установлена явно.

### Шаги интеграции

1. Создайте экземпляр Univer в `useEffect`.
2. Освободите экземпляр в функции очистки `useEffect`.

### Настройка плагинов [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для размещения редактора или его идентификатор. |

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое файла клиентской лицензии. |

### Пример кода

Каждое крепление получает свой собственный контейнер для детей. экземпляр утилизируется в микрозадаче, после того, как очистка окружающего React завершена, поэтому вложенные корни React никогда не синхронно не устанавливаются во время выполнения React.

```tsx
import { useEffect, useRef } from 'react'
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIruRU from '@univerjs-pro/pdfs-ui/locale/ru-RU'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignruRU from '@univerjs/design/locale/ru-RU'
import { UniverUIPlugin } from '@univerjs/ui'
import UIruRU from '@univerjs/ui/locale/ru-RU'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

export function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const univer = new Univer({
      locale: LocaleType.RU_RU,
      locales: {
        [LocaleType.RU_RU]: mergeLocales(
          DesignruRU,
          UIruRU,
          PdfsUIruRU,
        ),
      },
    })

    univer.registerPlugin(UniverLicensePlugin, {
      license: 'your license.txt',
    })
    univer.registerPlugin(UniverUIPlugin, { container })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return <div ref={containerRef} style={{ height: 600 }} />
}
```
