---
title: Angular に統合する
---

[インストールと基本的な使い方](/guides/pdfs/getting-started/installation) で起動します。以下の例では、Angularコンポーネントを使用して、明示的な高さを持つコンテナに Univer Pdfs をマウントします。

### 統合手順

1. `ngAfterViewInit` で Univerインスタンスを作成します。
2. `ngOnDestroy` のインスタンスをディスポースします。

### プラグイン設定 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターを配置する DOM 要素またはその ID。 |

`UniverLicensePlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `license` | `string` |  | クライアントライセンスファイルの内容。 |

### 事例紹介

```typescript
import type { AfterViewInit, ElementRef, OnDestroy } from '@angular/core'
import { Component, ViewChild } from '@angular/core'
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIjaJP from '@univerjs-pro/pdfs-ui/locale/ja-JP'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignjaJP from '@univerjs/design/locale/ja-JP'
import { UniverUIPlugin } from '@univerjs/ui'
import UIjaJP from '@univerjs/ui/locale/ja-JP'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

@Component({
  selector: 'app-univer',
  standalone: true,
  template: '<div #container style="height: 600px"></div>',
})
export class UniverComponent implements AfterViewInit, OnDestroy {
  @ViewChild('container') containerRef!: ElementRef<HTMLDivElement>
  private univer?: Univer

  ngAfterViewInit() {
    const container = this.containerRef.nativeElement

    const univer = new Univer({
      locale: LocaleType.JA_JP,
      locales: {
        [LocaleType.JA_JP]: mergeLocales(
          DesignjaJP,
          UIjaJP,
          PdfsUIjaJP,
        ),
      },
    })

    univer.registerPlugin(UniverLicensePlugin, {
      license: 'your license.txt',
    })
    univer.registerPlugin(UniverUIPlugin, { container })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })
    this.univer = univer
  }

  ngOnDestroy() {
    this.univer?.dispose()
  }
}
```
