---
title: Intégrer dans Next.js
---

Commencer par [l'installation et l'utilisation de base](/guides/pdfs/getting-started/installation). L'exemple ci-dessous utilise le routeur d'application Next.js pour monter des Pdfs Univer dans un conteneur avec une hauteur explicite.

Charger l'éditeur à partir d'un élément client avec `ssr: false`[^ssr]. Une directive `use client` seule ne désactive pas le prérendu. Voir [Next.js](https://nextjs.org/docs/app/guides/lazy-loading#skipping-ssr).

Placez le contenu de la licence client où `YOUR_CLIENT_LICENSE` apparaît; un chemin de fichier ne fonctionne pas ici. Voir [Configuration de la licence](/server/license).

### Étapes d’intégration

1. Créez l'instance Univer dans `useEffect`.
2. Libérez l’instance dans la fonction de nettoyage de `useEffect`.

### Configuration des plugins [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Élément DOM où monter l’éditeur, ou son identifiant. |

`UniverLicensePlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenu du fichier de licence client. |

### Exemple de code

Chaque montage a son propre conteneur enfant. L'élimination se déroule dans une microtâche après le nettoyage React environnant, de sorte que les racines imbriquées React ne sont pas démontées synchronement lors d'un commit React.

```tsx title="univer-editor.tsx"
'use client'

import { useEffect, useRef } from 'react'
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIfrFR from '@univerjs-pro/pdfs-ui/locale/fr-FR'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignfrFR from '@univerjs/design/locale/fr-FR'
import { UniverUIPlugin } from '@univerjs/ui'
import UIfrFR from '@univerjs/ui/locale/fr-FR'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

export default function UniverEditor() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const host = containerRef.current
    if (!host) return
    const container = document.createElement('div')
    container.style.height = '100%'
    host.append(container)

    const univer = new Univer({
      locale: LocaleType.FR_FR,
      locales: {
        [LocaleType.FR_FR]: mergeLocales(
          DesignfrFR,
          UIfrFR,
          PdfsUIfrFR,
        ),
      },
    })

    univer.registerPlugin(UniverLicensePlugin, {
      license: 'YOUR_CLIENT_LICENSE',
    })
    univer.registerPlugin(UniverUIPlugin, { container })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })

    return () => {
      queueMicrotask(() => {
        univer.dispose()
        container.remove()
      })
    }
  }, [])

  return <div ref={containerRef} style={{ height: 600 }} />
}
```

```tsx title="page.tsx"
'use client'

import dynamic from 'next/dynamic'

const UniverEditor = dynamic(() => import('./univer-editor'), { ssr: false })

export default function Page() {
  return <UniverEditor />
}
```

[^ssr]: Le rendu côté serveur (SSR) exécute le code de rendu avant le chargement de la page dans le navigateur, sans `window` ni DOM. Un Client Component peut aussi être prérendu : il faut désactiver le SSR pour le composant de l’éditeur.
