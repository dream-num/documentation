---
title: Интеграция в Astro
---

Начните с [Установка и базовое использование](/guides/pdfs/getting-started/installation). В приведенном ниже примере Astro используется для установки Univer Pdfs в контейнер с явной высотой.

Используйте простой элемент `<script>` для инициализации редактора непосредственно в браузере. Инициируйте первую загрузку и снова на `astro:page-load`. С ClientRouter удалите экземпляр перед `astro:before-swap` . Держите импорт редактора из передней панели Astro см. [Навигационные события Astro](https://docs.astro.build/en/reference/modules/astro-transitions/)

### Шаги интеграции

1. Создайте экземпляр Univer в `mount()` / `astro:page-load`.
2. Удалите экземпляр в `astro:before-swap`.

### Настройка плагинов [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для редактора или его идентификатор. |

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое клиентского файла лицензии. |

### Пример кода

```astro title="src/pages/index.astro"
<div id="univer-pdfs" style="height: 600px"></div>

<script>
  import { UniverLicensePlugin } from '@univerjs-pro/license'
  import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
  import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
  import PdfsUIruRU from '@univerjs-pro/pdfs-ui/locale/ru-RU'
  import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
  import { FUniver } from '@univerjs/core/facade'
  import DesignruRU from '@univerjs/design/locale/ru-RU'
  import { UniverUIPlugin } from '@univerjs/ui'
  import UIruRU from '@univerjs/ui/locale/ru-RU'

  import '@univerjs/design/lib/index.css'
  import '@univerjs/ui/lib/index.css'
  import '@univerjs-pro/pdfs-ui/lib/index.css'

  import '@univerjs-pro/pdfs/facade'

  let univerInstance: Univer | undefined

  function mount() {
    const container = document.getElementById('univer-pdfs')
    if (!container || univerInstance) return

    const univer = new Univer({
      locale: LocaleType.RU_RU,
      locales: {
        [LocaleType.RU_RU]: mergeLocales(
          DesignruRU,
          UIruRU,
          PdfsUIruRU,
        ),
      },
    })

    univer.registerPlugin(UniverLicensePlugin, {
      license: 'your license.txt',
    })
    univer.registerPlugin(UniverUIPlugin, { container })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })
    univerInstance = univer
  }

  function dispose() {
    univerInstance?.dispose()
    univerInstance = undefined
  }

  mount()
  document.addEventListener('astro:page-load', mount)
  document.addEventListener('astro:before-swap', dispose)
</script>
```
