---

PDFs はページサムネイルを Worker で描画できます。`UniverPdfsUIPlugin` に `thumbnailWorkerURL` を渡します。Worker は `OffscreenCanvas` を使用します。この設定はサムネイル用であり、PDF エディター全体を Worker に移すものではありません。

まず[インストールと基本的な使い方](/guides/pdfs/getting-started/installation)を完了してください。以下のコードは既存の設定に追加するものです。コンテンツの作成や読み込み前にプラグインを登録し、登録済みのプラグインは重複登録せず設定を変更してください。

## メインスレッド

```typescript title="main.ts"
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'

univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Worker のエントリー

```typescript title="worker.ts"
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

モジュール Worker と専用のエントリーファイルを使用します。Worker とメインスレッドのパッケージバージョンを揃えてください。描画とユーザー操作はメインスレッドで実行されます。
