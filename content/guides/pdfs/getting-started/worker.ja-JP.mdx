PDF は Worker[^web-worker] でページサムネイルをレンダリングできます。`thumbnailWorkerURL`を `UniverPdfsUIPlugin`に渡してワーカーが `OffscreenCanvas`を使うようにします。このオプションは、PDF エディタ全体をワーカーに動かしません。

[インストールと基本的な使い方](/guides/pdfs/getting-started/installation)で始まり、以下のスニペットは、その設定を拡張します。 コンテンツの作成や読み込み前にプラグインを登録し、同じプラグインを2回登録するのではなく、既存の登録を更新します。

## メインスレッド

`UniverPdfsUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | ブラウザーの Worker でサムネイルを生成します。 |

```typescript title="main.ts"
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'

univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Worker のエントリー

```typescript title="worker.ts"
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

モジュールワーカーを別のエントリファイルで使用してください。 ワーカーとメインスレッドにパッケージバージョンを合わせたままにします。 レンダリングとユーザーインタラクションは、メインスレッドに残ります。

[^web-worker]: Web Worker はブラウザーのメインスレッド外で JavaScript を実行し、メッセージで通信します。ページの DOM には直接アクセスできません。計算を Worker に移しても、エディター UI は移動しません。
