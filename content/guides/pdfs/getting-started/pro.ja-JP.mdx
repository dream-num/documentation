Univer PDFs は Univer SDK Pro を通じて提供されます。本番アプリケーションには有効な Pro ライセンスが必要であり、サーバーを利用する機能には Univer SDK Pro Server のデプロイも必要です。

## ライセンスプラグイン

PDF プラグインより先にライセンスを登録し、ライセンステキストをソース管理の対象外にしてください。

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

値はビルドまたはランタイム構成から注入してください。ライセンス文字列、セッション Cookie、サーバー認証情報をブラウザーまたは Node.js のソースファイルに埋め込まないでください。

## PDF パッケージ

| 機能                              | パッケージ                                                            |
| --------------------------------- | --------------------------------------------------------------------- |
| PDF ユニットモデルと Facade       | `@univerjs-pro/pdfs`                                                  |
| エディターと共同編集の契約        | `@univerjs-pro/pdfs-editor`                                           |
| ブラウザー Canvas とエディター UI | `@univerjs-pro/pdfs-ui`                                               |
| PDF のインポートとエクスポート    | `@univerjs-pro/exchange-client`、`@univerjs-pro/pdfs-exchange-client` |
| ブラウザー印刷                    | `@univerjs-pro/pdfs-print`                                            |
| リアルタイム共同編集              | `@univerjs-pro/collaboration`、`@univerjs-pro/collaboration-client`   |

現在、PDF のプリセットはありません。アプリケーションに必要なプラグインだけを登録してください。

## サーバー要件

| ワークフロー                                    | Univer SDK Pro Server が必要 |
| ----------------------------------------------- | :----------------------: |
| ローカル PDF スナップショットの作成、表示、編集 |          いいえ          |
| PDF ファイルのインポートまたはエクスポート      |           はい           |
| PDF ユニットの永続化と共同編集                  |           はい           |
| ブラウザーの印刷ダイアログを開く                |          いいえ          |

インポート API とエクスポート API のスナップショット版では共同編集用の永続化は不要ですが、変換は引き続き Exchange サーバーで実行されます。

## デプロイに関する注意

- PDF 機能の CSS より先に、Univer の共通 UI CSS を読み込んでください。
- デプロイ固有の URL をアプリケーション全体にハードコードせず、プラグインオプションで Exchange と共同編集のエンドポイントを構成してください。
- Node.js サービスには、ブラウザー専用の UI プラグインと印刷プラグインを含めないでください。
- 正確な表示の再現性に依存する前に、一般的でないフォント、カラースペース、注釈、その他の高度な PDF 機能を使うインポート済み PDF を検証してください。

ライセンスとサーバーデプロイについて詳しくは、[Univer SDK Pro](/guides/pro)を参照してください。
