## 인터페이스 언어

`locale`는 메뉴, 도구 팁, 대화 상자 및 다른 번역 인터페이스 텍스트에 사용되는 언어 팩을 선택합니다. `locales`은 언어를 선택하지 않고 입력합니다. Univer 인스턴스의 모든 단위는이 설정을 공유합니다. `LocaleType`와 같은 `LocaleType.EN_US`의 값이 제공됩니다.

- **모든 제품: UI**: `locale`은 메뉴, 도구 설명, 대화 상자와 플러그인 레이블의 번역을 바꿉니다. 사용자 콘텐츠나 기존 단위 이름은 바꾸지 않습니다.
- **장: 세포 체재 및 공식**: 셀 번호와 날짜 렌더링 번호 형식 로컬 오버라이드를 사용하여 먼저, 그 다음 작업 책 스냅 샷 `locale`, 그 다음 `locale`. `region`는 이러한 설정의 어떤 교체하지 않습니다. `locale` 여전히 금융 결과에 `DOLLAR` 및 통화 형식과 같은 공식 동작을 지배합니다. CJK 입력 정상화는 또한 `locale`를 사용합니다.
- **Docs: 통계**: `locale`는 단어 세그먼트 및 계산을 구동한다.

### 실행 중 언어 변경

모든 설치 플러그인 또는 언어를 전환하기 전에 사전 설정에 대한 언어 팩을로드하십시오. `loadLocales()`은 언어를 전환하지 않고 번역을 병합하고 `setLocale()`은 모든 것을 다운로드하지 않고로드 팩 중 하나를 선택합니다. 누락 된 번역 키는 키 자체로 표시됩니다. 예를 들어 공유 UI 팩을로드합니다. 동일한 통화에 다른 설치 된 플러그인을위한 대상 언어 팩을 병합합니다.

```typescript
import { LocaleType, mergeLocales } from '@univerjs/core'
import UIEnUS from '@univerjs/ui/locale/en-US'

univerAPI.loadLocales(LocaleType.EN_US, mergeLocales(UIEnUS))
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentLocale()) // enUS
```

### 사용자 지정 언어 팩

Univer는 또한 사용자 지정 언어 팩을 지원합니다. 필요한 언어 팩 객체를 구축하고 `Univer` 인스턴스로 전달하십시오. 사전 설정 언어 팩은 `<rootDir>/packages/<PLUGIN_NAME>/locale` 디렉토리에 일반적으로 있습니다.

```typescript
import { LocaleType, Univer } from '@univerjs/core'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: {
      ui: {
        shortcut: {
          undo: '元に戻す',
          redo: 'やり直す',
        },
      },
    },
  },
})
```

### 번역 기여하기

Univer는 현재 다음과 같은 내장 언어 팩을 발송합니다.

- `zh-CN`: 중국어 간체
- `en-US`: 영어
- `zh-TW`: 중국어 번체
- `zh-HK`: 중국어 번체(홍콩)
- `ru-RU`: 러시아어
- `vi-VN`: 베트남어
- `fa-IR`: 페르시아어
- `fr-FR`: 프랑스어
- `ja-JP`: 일본어
- `ko-KR`: 한국어
- `es-ES`: 스페인어
- `ca-ES`: 카탈루냐어
- `sk-SK`: 슬로바키아어
- `ar-SA`: 아랍어
- `de-DE`: 독일어
- `id-ID`: 인도네시아어
- `it-IT`: 이탈리아어
- `pl-PL`: 폴란드어
- `pt-BR`: 포르투갈어(브라질)

Univer는 오픈 소스 프로젝트이며, 로컬를 추가하거나 개선하는 기여도는 환영합니다.

## 지역 설정

`region`는 지역 기능에 의해 사용되는 지역 협약을 선택합니다. Univer 인스턴스의 모든 단위는이 설정을 공유합니다.

둘 다 조정은 `LocaleType` 가치를 가지고 갑니다. 예를 들면, `LocaleType.EN_US`에는 가치 `enUS`가 있고, `en-US`는 언어 팩 파일 이름과 BCP 47 꼬리표입니다. `region`로 `US` `SG`와 같은 국가 코드를 통과하지 마십시오. 공용영역이 다른 Locale를 사용할 때, 지역은 일치 언어 팩을 요구하지 않습니다.

`region`가 설정되지 않은 경우 나중에 `setLocale()` 통화를 포함한 `locale`를 따르십시오. 초기화 중에 `region` 설정 또는 `setRegion()` 호출은 다음 자동 종료 및 나중에 언어 변경은 선택한 영역을 유지. 공개 API는 다음과 같이 자동 복원; 두 값이 변경 될 때 두 세트 모두 호출.

`createUniver()` 또는 `new Univer()`의 `locale` 옆에 `region: LocaleType.DE_DE`를 추가하여 독일 지역 컨벤션을 적용하면서 인터페이스 언어를 유지하십시오.

```typescript
import { LocaleType } from '@univerjs/core'

univerAPI.setRegion(LocaleType.DE_DE)
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentRegion()) // deDE
```

이 예제에서 인터페이스는 영어 및 지역 형식은 독일어 남아있다. `getCurrentLocale()` 및 `getCurrentRegion()`는 영향을받는 식별자를 반환합니다. 모두 변경하려면 동일한 `LocaleType` 값과 setters를 모두 호출하십시오.

- **시트: 통화 통제**: `region`는 통화 툴바 아이콘, 통화 및 회계 선택 및 미리보기 및 통화 명령에 의해 적용된 패턴을 제어합니다. 기존 셀 형식을 다시 작성하지 않거나 통화 값을 변환하지 않습니다.
- **Docs: 통계**: `region`는 통계 대화 상자와 상태 표시 줄에 표시된 카운트를 그룹화 분리기를 나타냅니다. `region`를 변경하면 계산 규칙을 변경하지 않습니다.
- **스레드 의견, 활성화시**: `region`는 24 시간 시간 및 라틴어 손가락과 더불어 표시된 날짜 및 시간 체재를, 통제합니다. `locale` 통제 코멘트 UI 원본. 더 적은 변화는 타임스탬프를 저장했습니다; `region`에는 시간대 조정이 아닙니다.
- **보드, 슬라이드,베이스, PDF**: `locale`는 번역된 UI를 통제합니다. `region`은 통합될 때 실 의견과 같은 그것을, 사용하는 공유한 특징을 위해 유효합니다; 그것은 자동적으로 자료표 또는 활주 원본, 기본적인 분야, 또는 PDF 내용을 재포장하지 않습니다.

<Callout type="warning" title="주 메뉴">
  RTL 지원은 현재 UI 레이어만 다룹니다. 렌더링 레이어는 RTL을 지원하지 않습니다.
</Callout>

<Callout type="warning" title="주 메뉴">
  모든 플러그인에는 언어 팩이 포함되어 있지 않습니다. 플러그인이 제공하는 각 기능 상태에 대한 문서.
</Callout>

```typescript
univerAPI.setDirection('rtl')
```
