## Язык интерфейса

`locale` выбирает языковой пакет, используемый для меню, подсказок, диалогов и другого переведенного текста интерфейса. `locales` регистрирует языковые пакеты без выбора одного. Все единицы в экземпляре Univer разделяют эту настройку. Значения приходят от `LocaleType`, например `LocaleType.EN_US`.

- **Все продукты: интерфейс**: `locale` меняет переводы меню, подсказок, диалогов и подписей плагинов. Пользовательский текст и имена существующих документов не меняются.
- **Листы: форматы ячеек и формулы**: Номера ячеек и даты отображаются сначала с использованием оверрайда номерного формата, затем снимка из книги `locale`, затем экземпляра `locale`. `region` не заменяет ни одну из этих настроек. `locale` по-прежнему регулирует поведение формул, таких как `DOLLAR` и формат валюты по финансовым результатам. Нормализация ввода CJK также использует `locale` .
- **Док: статистика**: `locale` управляет сегментацией и подсчетом слов.

### Смена языка во время работы

Загрузите языковые пакеты для каждого установленного плагина или предустановленного перед переключением языка. `loadLocales()` сливает переводы без переключения языка, а `setLocale()` выбирает среди загруженных пакетов без скачивания. В качестве самого ключа отображается отсутствующий ключ перевода. Пример загружает общий пакет пользовательского интерфейса; сливает пакеты целевого языка для других установленных плагинов в том же вызове.

```typescript
import { LocaleType, mergeLocales } from '@univerjs/core'
import UIEnUS from '@univerjs/ui/locale/en-US'

univerAPI.loadLocales(LocaleType.EN_US, mergeLocales(UIEnUS))
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentLocale()) // enUS
```

### Объединение языковых пакетов [#mergeLocales]

`mergeLocales` объединяет несколько плагинов или предустановленных языковых пакетов в один полный объект языкового пакета. Обе формы ниже действительны:

<Tabs items={['Режим пресетов', 'Режим плагинов']}>
  <Tab>
    ```typescript
    import { mergeLocales } from '@univerjs/presets'

    // You can pass multiple language pack objects to merge
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // You can also pass an array of language pack objects
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    ])
    ```
  </Tab>
  <Tab>
    ```typescript
    import { mergeLocales } from '@univerjs/core'

    // You can pass multiple language pack objects to merge
    const locales = mergeLocales(
      plugin1Locales,
      plugin2Locales,
      presetLocales,
    )
    // You can also pass an array of language pack objects
    const locales = mergeLocales([
      plugin1Locales,
      plugin2Locales,

    ])
    ```

### Пользовательские языковые пакеты

Univer также поддерживает пользовательские языковые пакеты. Постройте объект языкового пакета по мере необходимости и передайте его в экземпляр `Univer`. Предустановленные языковые наборы обычно расположены в каталоге `<rootDir>/packages/<PLUGIN_NAME>/locale` .

```typescript
import { LocaleType, Univer } from '@univerjs/core'

const univer = new Univer({
  locale: LocaleType.JA_JP,
  locales: {
    [LocaleType.JA_JP]: {
      ui: {
        shortcut: {
          undo: '元に戻す',
          redo: 'やり直す',
        },
      },
    },
  },
})
```

### Участие в переводе

В настоящее время Univer поставляется со следующими встроенными языковыми пакетами:

- `zh-CN`: упрощённый китайский
- `en-US`: английский
- `zh-TW`: традиционный китайский
- `zh-HK`: традиционный китайский (Гонконг)
- `ru-RU`: русский
- `vi-VN`: вьетнамский
- `fa-IR`: персидский
- `fr-FR`: французский
- `ja-JP`: японский
- `ko-KR`: корейский
- `es-ES`: испанский
- `ca-ES`: каталонский
- `sk-SK`: словацкий
- `ar-SA`: арабский
- `de-DE`: немецкий
- `id-ID`: индонезийский
- `it-IT`: итальянский
- `pl-PL`: польский
- `pt-BR`: португальский (Бразилия)

Univer - это проект с открытым исходным кодом, и приветствуются вклады, которые добавляют или улучшают локализации.

## Региональные настройки

`region` выбирает региональные конвенции, используемые региональными функциями. Все единицы в экземпляре Univer разделяют эту настройку.

Обе настройки принимают значения `LocaleType`. Например, `LocaleType.EN_US` имеет значение `enUS`, в то время как `en-US` — имя файла языкового пакета и тег BCP 47. Не пропускайте коды стран, такие как `US` или `SG` как `region`... Когда интерфейс использует другую локацию, регион не требует соответствующего языкового набора.

Если `region` никогда не устанавливается, он следует за `locale`, включая более поздние вызовы `setLocale()`. Настройка `region` во время инициализации или вызова `setRegion()` заканчивается тем, что автоматическое следование, а более поздними языковыми изменениями удерживается выбранная область. Ни один публичный API не восстанавливает автоматическое следования; вызовите оба наборщика, когда два значения должны измениться вместе.

Добавьте `region: LocaleType.DE_DE` рядом с `locale` в `createUniver()` или `new Univer()`, чтобы сохранить язык интерфейса при применении немецких региональных конвенций.

```typescript
import { LocaleType } from '@univerjs/core'

univerAPI.setRegion(LocaleType.DE_DE)
univerAPI.setLocale(LocaleType.EN_US)

console.log(univerAPI.getCurrentRegion()) // deDE
```

В этом примере интерфейс является английским, а региональное форматирование остается немецким. `getCurrentLocale()` и `getCurrentRegion()` возвращают действующие идентификаторы. Чтобы изменить оба вместе, вызовите оба установщика с одинаковым значением `LocaleType`.

- **Листы: валютный контроль**: `region` управляет значком панели инструментов валюты, выбором валюты и учетной записи, а также шаблоном, применяемым командой валюты. Изменение его не переписывает существующие форматы ячеек или конвертирует денежные значения.
- **Док: статистика**: `region` форматирует подсчеты, показанные в диалоге статистики и строке состояния, например разделители групп.Изменение `region` не меняет правил подсчета.
- **Комментарии, когда включено**: `region` контролирует отображаемый формат даты и времени, с 24-часовым временем и латинскими цифрами. `locale` управляет комментарием UI-текста. Ни один из них не изменяет сохраненные метки времени; `region` не является настроем часовой зоны.
- **Доски, слайды, базы, PDF**: `locale` управляет переведенным пользовательским интерфейсом. `region` доступен для общих функций, которые потребляют его, таких как комментарии потоков при интеграции; он не автоматически переформатирует доску или слайд-текст, поля базы или PDF-контент.
