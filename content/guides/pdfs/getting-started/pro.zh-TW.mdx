Univer PDFs 透過 Univer SDK Pro 發布。正式環境應用程式需要有效的 Pro 授權，由伺服器支援的功能還需要部署 Univer SDK Pro Server。

## 授權外掛

請在 PDF 外掛之前註冊授權，並將授權文字保存在版本控制之外：

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

透過建置或執行階段設定注入此值。請勿在瀏覽器或 Node.js 來源檔案中嵌入授權字串、工作階段 Cookie 或伺服器認證。

## PDF 套件

| 能力                      | 套件                                                                  |
| ------------------------- | --------------------------------------------------------------------- |
| PDF 單元模型和 Facade     | `@univerjs-pro/pdfs`                                                  |
| 編輯器和協作契約          | `@univerjs-pro/pdfs-editor`                                           |
| 瀏覽器 Canvas 和編輯器 UI | `@univerjs-pro/pdfs-ui`                                               |
| PDF 匯入和匯出            | `@univerjs-pro/exchange-client`、`@univerjs-pro/pdfs-exchange-client` |
| 瀏覽器列印                | `@univerjs-pro/pdfs-print`                                            |
| 即時協作                  | `@univerjs-pro/collaboration`、`@univerjs-pro/collaboration-client`   |

目前沒有 PDF 預設。請僅註冊應用程式所需的外掛。

## 伺服器需求

| 工作流程                      | 是否需要 Univer SDK Pro Server |
| ----------------------------- | :------------------------: |
| 建立、檢視或編輯本機 PDF 快照 |             否             |
| 匯入或匯出 PDF 檔案           |             是             |
| 持久化並協同編輯 PDF 單元     |             是             |
| 開啟瀏覽器列印對話方塊        |             否             |

匯入和匯出 API 的快照變體不要求協作持久化，但轉換仍然透過 Exchange 伺服器執行。

## 部署說明

- 在 PDF 功能 CSS 之前載入 Univer 共用 UI CSS。
- 透過外掛選項設定 Exchange 和協作端點，不要在應用程式各處硬編碼部署專用 URL。
- Node.js 服務中不要包含僅供瀏覽器使用的 UI 和列印外掛。
- 在依賴完全一致的視覺保真度之前，驗證使用不常見字型、色彩空間、註解或其他進階 PDF 功能的匯入檔案。

有關授權和伺服器部署的詳細資訊，請參閱 [Univer SDK Pro](/guides/pro)。
