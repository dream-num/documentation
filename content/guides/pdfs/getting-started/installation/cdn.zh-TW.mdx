---
title: 透過 CDN 引入 Univer PDFs
icon: 'CloudDownload'
---

UMD 建置會公開以下 PDF 專用入口。所有 `@univerjs/*` 與 `@univerjs-pro/*` URL 必須使用相同版本。

| UMD 路徑 | 全域命名空間 |
| --- | --- |
| `@univerjs-pro/pdfs/lib/umd/index.js` | `UniverProPdfs` |
| `@univerjs-pro/pdfs/lib/umd/facade.js` | `UniverProPdfsFacade` |
| `@univerjs-pro/pdfs-ui/lib/umd/index.js` | `UniverProPdfsUi` |
| `@univerjs-pro/pdfs-ui/lib/umd/locale/en-US.js` | `UniverProPdfsUiEnUS` |

先載入 peer 依賴與共用執行環境，再依照清單順序載入每個套件的依賴。`pdfs` 應早於 `pdfs-ui`，UI locale 應位於 `pdfs-ui` 之後，PDF Facade 入口應位於 `@univerjs/core/facade` 之後。UMD 不會自動解析這張依賴圖。

套件清單、CSS、外掛註冊和授權設定請返回[安裝與基本使用](/guides/pdfs/getting-started/installation)查看。
