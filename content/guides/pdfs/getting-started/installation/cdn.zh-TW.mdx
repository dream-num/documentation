---
title: 透過 CDN 使用 Web SDK
---

UMD 建置提供以下 PDF 專用入口。所有 `@univerjs/*` 與 `@univerjs-pro/*` 的 URL 必須使用同一版本。

| UMD 路徑 | 全域命名空間 |
| --- | --- |
| `@univerjs-pro/pdfs/lib/umd/index.js` | `UniverProPdfs` |
| `@univerjs-pro/pdfs/lib/umd/facade.js` | `UniverProPdfsFacade` |
| `@univerjs-pro/pdfs-ui/lib/umd/index.js` | `UniverProPdfsUi` |
| `@univerjs-pro/pdfs-ui/lib/umd/locale/en-US.js` | `UniverProPdfsUiEnUS` |

先載入 peer 依賴和共用執行時，再按 manifest 順序載入各個包的依賴。`pdfs` 位於 `pdfs-ui` 之前，UI locale 位於 `pdfs-ui` 之後，PDF Facade 入口位於 `@univerjs/core/facade` 之後。UMD 不會自動解析這張依賴圖。

包列表、CSS 引入、外掛註冊和許可證配置請參閱[安裝和基本使用](/guides/pdfs/getting-started/installation)。
