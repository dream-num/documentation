---
title: 通过 CDN 使用 Web SDK
---

UMD 构建提供以下 PDF 专用入口。所有 `@univerjs/*` 与 `@univerjs-pro/*` 的 URL 必须使用同一版本。

| UMD 路径 | 全局命名空间 |
| --- | --- |
| `@univerjs-pro/pdfs/lib/umd/index.js` | `UniverProPdfs` |
| `@univerjs-pro/pdfs/lib/umd/facade.js` | `UniverProPdfsFacade` |
| `@univerjs-pro/pdfs-ui/lib/umd/index.js` | `UniverProPdfsUi` |
| `@univerjs-pro/pdfs-ui/lib/umd/locale/en-US.js` | `UniverProPdfsUiEnUS` |

先加载 peer 依赖和共用运行时，再按 manifest 顺序加载各个包的依赖。`pdfs` 位于 `pdfs-ui` 之前，UI locale 位于 `pdfs-ui` 之后，PDF Facade 入口位于 `@univerjs/core/facade` 之后。UMD 不会自动解析这张依赖图。

包列表、CSS 引入、插件注册和许可证配置请参阅[安装和基本使用](/guides/pdfs/getting-started/installation)。
