title: 通过 CDN 引入 Univer PDFs
icon: 'CloudDownload'
---

UMD 构建会暴露以下 PDF 专用入口。所有 `@univerjs/*` 与 `@univerjs-pro/*` URL 必须使用相同版本。

| UMD 路径 | 全局命名空间 |
| --- | --- |
| `@univerjs-pro/pdfs/lib/umd/index.js` | `UniverProPdfs` |
| `@univerjs-pro/pdfs/lib/umd/facade.js` | `UniverProPdfsFacade` |
| `@univerjs-pro/pdfs-ui/lib/umd/index.js` | `UniverProPdfsUi` |
| `@univerjs-pro/pdfs-ui/lib/umd/locale/en-US.js` | `UniverProPdfsUiEnUS` |

先加载 peer 依赖与共用运行时，再按清单顺序加载每个包的依赖。`pdfs` 应早于 `pdfs-ui`，UI locale 应位于 `pdfs-ui` 之后，PDF Facade 入口应位于 `@univerjs/core/facade` 之后。UMD 不会自动解析这张依赖图。

包列表、CSS、插件注册和许可证配置请返回[安装和基本使用](/guides/pdfs/getting-started/installation)查看。
