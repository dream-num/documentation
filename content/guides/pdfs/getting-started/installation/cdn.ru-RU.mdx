---
title: Подключение Web SDK через CDN
---

Все URL-адреса `@univerjs/*` и `@univerjs-pro/*` должны использовать одну и ту же версию.

| Путь UMD | Глобальное пространство имён |
| --- | --- |
| `@univerjs-pro/pdfs/lib/umd/index.js` | `UniverProPdfs` |
| `@univerjs-pro/pdfs/lib/umd/facade.js` | `UniverProPdfsFacade` |
| `@univerjs-pro/pdfs-ui/lib/umd/index.js` | `UniverProPdfsUi` |
| `@univerjs-pro/pdfs-ui/lib/umd/locale/en-US.js` | `UniverProPdfsUiEnUS` |

Загрузите одноранговые зависимости и сначала совместно используемое время выполнения, затем следуйте явному порядку для зависимостей каждого пакета. `pdfs` предшествует `pdfs-ui`, локализация пользовательского интерфейса следует за `pdfs-ui` и запись PDF Facade следует за `@univerjs/core/facade`. UMD не разрешает этот граф зависимостей автоматически.

Список пакетов, импорт CSS, регистрация плагинов и настройка лицензий см. в [Установка и базовое использование](/guides/pdfs/getting-started/installation).
