Univer PDFs est un produit Web SDK et ne propose actuellement aucun préréglage. Créez les applications PDF en mode plugin.

## Configuration en mode plugin

### Utilisation d’un gestionnaire de packages

Utilisez un outil de compilation compatible avec les modules ES et le champ `exports` de `package.json`.

#### Installation

Univer utilise React pour son interface et RxJS pour les flux de données ; il peut aussi être intégré à Vue ou Angular. Vérifiez que les peer dependencies `react`, `react-dom` et `rxjs` sont installées. La commande Yarn ci-dessous les inclut explicitement.

Conservez la même version pour tous les packages `@univerjs/*` et `@univerjs-pro/*`.

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}
/>

Conservez tous les packages `@univerjs/*` et `@univerjs-pro/*` à la même version.

#### Utilisation

Créez le conteneur avant d’initialiser Univer et définissez une hauteur explicite :

```html
<div id="app" style="height: 600px"></div>
```

Importez les entrées facade utilisées ci-dessous avant d’appeler `FUniver.newAPI(univer)`. Importez les CSS dans cet ordre : `@univerjs/design`, `@univerjs/ui`, puis ceux du produit.

<Steps>
  <Step>
    Importez les styles de l'interface partagée avant celui de l'interface PDF, puis fusionnez les packs de locales activés par votre application :

    ```ts
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
    import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
    import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
    import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
    import { FUniver } from '@univerjs/core/facade'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/pdfs-ui/lib/index.css'
    ```

  </Step>
  <Step>
    Importez le point d'entrée de la façade PDF. Cet import à effet de bord ajoute les méthodes et les énumérations PDF à `FUniver` :

    ```ts
    import '@univerjs-pro/pdfs/facade'
    ```

  </Step>
  <Step>
    Créez l'environnement d'exécution, enregistrez explicitement l'ensemble des plugins, puis créez un PDF :

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          PdfsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })
    ```

  </Step>
</Steps>

#### Méthodes `univer.registerPlugin` et `univer.registerPlugins` [#registerPlugin]

La méthode `univer.registerPlugin` sert à enregistrer un plugin dans l’instance Univer. Vous pouvez l’appeler après avoir créé l’instance Univer afin d’y enregistrer des plugins.

Vous pouvez enregistrer un plugin avec la méthode `univer.registerPlugin(Plugin, options)`, où `Plugin` désigne le plugin à enregistrer et `options` les paramètres de configuration facultatifs, qui peuvent varier d’un plugin à l’autre.

Vous pouvez également utiliser `univer.registerPlugins` pour passer un tableau et enregistrer plusieurs plugins en une seule fois. Cette possibilité est utile lorsque vous devez centraliser la gestion des plugins.

```typescript
univer.registerPlugins([
  [UniverUIPlugin, { container: 'app' }],
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverPdfsPlugin,
  UniverPdfsUIPlugin,
])
```

## Worker de miniatures facultatif

Les miniatures des pages peuvent être affichées sur le thread principal sans configuration supplémentaire. Pour les documents plus volumineux, fournissez un worker de module dédié avec `thumbnailWorkerURL`.

Créez un point d'entrée de worker tel que `pdf-thumbnail.worker.ts` :

```ts
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

Transmettez ensuite son URL lors de l'enregistrement du plugin d'interface PDF :

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./pdf-thumbnail.worker.ts', import.meta.url), { type: 'module' }),
})
```

L'option accepte également une URL sous forme de chaîne ou un `Worker` existant. Si les workers ou `OffscreenCanvas` ne sont pas disponibles, l'affichage des miniatures revient au thread principal.

## Édition collaborative

`@univerjs-pro/pdfs-editor` ne fait pas partie de la pile locale. Ne l’enregistrez pas seul : installez et enregistrez d’abord la pile complète `@univerjs-pro/collaboration`, `@univerjs-pro/collaboration-client` et `@univerjs-pro/collaboration-client-ui` comme décrit dans [Collaboration](/guides/pdfs/features/collaboration), puis installez et enregistrez le plugin de cycle de vie de l’éditeur PDF.

## Utilisation avec Node.js

Les services Node.js peuvent enregistrer uniquement `UniverPdfsPlugin`, sans les packages d’interface du navigateur. Ajoutez la pile de collaboration complète ci-dessus uniquement si le service doit charger ou synchroniser des unités PDF conservées.

## Autres versions

Outre les versions stables, Univer propose des canaux alpha / beta et nightly. Ces versions vous donnent un accès anticipé aux fonctionnalités les plus récentes qui n’ont pas encore été publiées officiellement. Gardez toutefois à l’esprit que davantage de fonctionnalités implique aussi davantage de risques. Ces versions peuvent contenir des bugs, des fonctionnalités incomplètes ou instables. Évitez autant que possible de les utiliser dans des environnements de production.

### Version alpha / beta

Lorsque l’équipe de développement d’Univer termine une nouvelle fonctionnalité ou une modification importante, elle peut la publier en avant-première sur le canal alpha ou beta. Vous pouvez installer la version alpha / beta d’un package Univer à l’aide de la commande suivante :

```package-install
npm install @univerjs-pro/pdfs@alpha # Alpha version
npm install @univerjs-pro/pdfs@beta # Beta version
```

Si vous rencontrez un problème ou souhaitez faire part de vos commentaires lors de l’utilisation des versions alpha / beta, signalez-les à l’équipe de développement d’Univer via les [issues GitHub](https://github.com/dream-num/univer/issues).

Vos retours sur ces versions préliminaires sont les bienvenus.
