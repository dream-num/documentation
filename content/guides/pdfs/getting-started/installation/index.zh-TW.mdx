title: 安裝與基本使用
---

Univer PDFs 屬於 Univer Office SDK，目前尚未提供預設，因此 PDF 應用採用外掛模式建置。

Univer 提供兩種整合方式：預設模式和外掛模式。預設模式提供預先配置好的外掛組合，可以減少裝配工作量；如果需要**深度定製或擴充套件**，則使用外掛模式，由開發者自行選擇和配置每個外掛。

## 透過外掛模式建立

### 使用套件管理器

建置工具需要支援 ES Modules 以及 `package.json` 中的 `exports` 欄位。

#### 安裝

Univer 的介面基於 React，資料流基於 RxJS，也可以嵌入 Vue 或 Angular 應用。請確認 `react`、`react-dom`、`rxjs` 這幾個 peer dependencies[^peer-dependency] 已經安裝；下面的 Yarn 命令會一併安裝它們。

所有 `@univerjs/*` 和 `@univerjs-pro/*` 包必須保持**相同版本**。

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}
/>

所有 `@univerjs/*` 和 `@univerjs-pro/*` 包均須保持**相同版本**。

#### 使用

先建立容器並指定明確的高度，再初始化 Univer：

```html
<div id="app" style="height: 600px"></div>
```

呼叫 `FUniver.newAPI(univer)` 之前，先匯入下文用到的 facade 入口。樣式按 `@univerjs/design`、`@univerjs/ui`、產品 CSS 的順序引入。

<Steps>
  <Step>
    先引入公共 UI 樣式，再引入 PDF UI 樣式，併合並應用啟用的語言套件：

    ```ts
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
    import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
    import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
    import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
    import { FUniver } from '@univerjs/core/facade'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'
    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/pdfs-ui/lib/index.css'
    ```

  </Step>
  <Step>
    匯入 PDF Facade[^facade-entry] 入口。該副作用匯入會為 `FUniver` 增加 PDF 方法和列舉：

    ```ts
    import '@univerjs-pro/pdfs/facade'
    ```

  </Step>
  <Step>
    建立執行時，註冊顯式的外掛棧，然後建立一個 PDF：

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          PdfsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })
    ```

  </Step>
</Steps>

#### 外掛設定 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 編輯器掛載的 DOM 元素或元素 ID。 |

`UniverLicensePlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 用戶端授權檔的內容。 |

#### `univer.registerPlugin` 與 `univer.registerPlugins` 方法 [#registerPlugin]

Univer 例項建立完成後，呼叫 `univer.registerPlugin` 即可在該例項上註冊外掛。

呼叫形式為 `univer.registerPlugin(Plugin, options)`：`Plugin` 是要註冊的外掛，`options` 是可選配置物件，每個外掛可以定義自己的配置項。

如需一次註冊多個外掛，可向 `univer.registerPlugins` 傳入陣列，以便集中管理外掛。

```typescript
univer.registerPlugins([
  [UniverUIPlugin, { container: 'app' }],
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverPdfsPlugin,
  UniverPdfsUIPlugin,
])
```

## 行動裝置支援 [#mobile-support]

當前 `@univerjs-pro/pdfs-ui` 包沒有匯出獨立的行動版 UI 外掛，既不存在 `MobileUIPlugin` 匯入項，也不存在 `mobile: true` 選項，請不要嘗試使用它們。容器變窄並不能說明觸控支援已經完整，現有 UI 需要在目標裝置上實際驗證。

## 選用的縮圖 Worker

頁面縮圖預設在主執行緒渲染，無需額外配置。文件較大時，可透過 `thumbnailWorkerURL` 交給專用的模組 Worker 處理。

建立一個 Worker 入口，例如 `pdf-thumbnail.worker.ts`：

```ts
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

註冊 PDF UI 外掛時傳入該 Worker 的 URL：

`UniverPdfsUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | 在瀏覽器 Worker 中產生頁面縮圖。 |

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./pdf-thumbnail.worker.ts', import.meta.url), { type: 'module' }),
})
```

該選項也接受字串 URL 或已有的 `Worker`。如果 Worker 或 `OffscreenCanvas` 不可用，縮圖渲染會回退到主執行緒。

## 採用協作的編輯

`@univerjs-pro/pdfs-editor` 不屬於純本地的外掛棧，也不能單獨工作。請先按[協作](/guides/pdfs/features/collaboration)文件安裝並註冊完整的 `@univerjs-pro/collaboration`、`@univerjs-pro/collaboration-client`、`@univerjs-pro/collaboration-client-ui` 外掛棧，再安裝並註冊 PDF 編輯器生命週期外掛。

## Node.js 用法

Node.js 服務可以只註冊 `UniverPdfsPlugin`，不需要任何瀏覽器 UI 包。只有服務需要載入或同步已持久化的 PDF 單元時，才需要加上上述協作外掛棧。

## 其他發佈版本

除穩定版外，Univer 還維護 alpha 和 beta 通道，可用於提前使用尚未正式釋出的功能。功能更多也意味著風險更高：這些版本可能存在缺陷、功能不完整或特性不穩定，應儘量避免用於生產環境。

### Alpha / Beta 版本

Univer 團隊完成新功能或較大改動後，可能先將其釋出到 alpha 或 beta 通道。安裝某個包的 alpha / beta 版本：

```package-install
npm install @univerjs-pro/pdfs@alpha # Alpha 版本
npm install @univerjs-pro/pdfs@beta # Beta 版本
```

使用 alpha / beta 版本時如遇到問題或有反饋，請透過 [GitHub Issues](https://github.com/dream-num/univer/issues) 告知 Univer 團隊。歡迎反饋這些早期版本的實際使用情況。
