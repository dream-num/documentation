---
title: CDN 経由での Web SDK のインポート
---

UMDビルドでは、以下のPDF固有のエントリを提供しています。すべての`@univerjs/*`と`@univerjs-pro/*` URLは、同じバージョンを使用する必要があります。

| UMD パス | グローバル名前空間 |
| --- | --- |
| `@univerjs-pro/pdfs/lib/umd/index.js` | `UniverProPdfs` |
| `@univerjs-pro/pdfs/lib/umd/facade.js` | `UniverProPdfsFacade` |
| `@univerjs-pro/pdfs-ui/lib/umd/index.js` | `UniverProPdfsUi` |
| `@univerjs-pro/pdfs-ui/lib/umd/locale/en-US.js` | `UniverProPdfsUiEnUS` |

ピアの依存関係と共有ランタイムを最初にロードし、各パッケージの依存関係のマニフェストの順序に従います。 `pdfs` は `pdfs-ui` を優先し、 UI のロケールは `pdfs-ui` に従い、PDF ファサードのエントリは `@univerjs/core/facade` に従います。 UMD はこの依存関係グラフを自動的に解決しません。

パッケージリスト、CSS のインポート、プラグインの登録、ライセンス設定については、[インストールと基本的な使い方](/guides/pdfs/getting-started/installation) を参照してください。
