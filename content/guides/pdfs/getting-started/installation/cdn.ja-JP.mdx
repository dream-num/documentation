title: CDN から Univer PDFs を読み込む

UMD ビルドは、次の PDF 固有エントリをグローバルに公開します。すべての `@univerjs/*` と `@univerjs-pro/*` の URL で同じバージョンを指定してください。

| UMD パス | グローバル名前空間 |
| --- | --- |
| `@univerjs-pro/pdfs/lib/umd/index.js` | `UniverProPdfs` |
| `@univerjs-pro/pdfs/lib/umd/facade.js` | `UniverProPdfsFacade` |
| `@univerjs-pro/pdfs-ui/lib/umd/index.js` | `UniverProPdfsUi` |
| `@univerjs-pro/pdfs-ui/lib/umd/locale/en-US.js` | `UniverProPdfsUiEnUS` |

peer 依存関係と共通ランタイムを先に読み込み、その後に各パッケージの依存関係をマニフェスト順で読み込みます。`pdfs` は `pdfs-ui` より先、UI locale は `pdfs-ui` の後、PDF Facade は `@univerjs/core/facade` の後に読み込みます。UMD は依存グラフを自動解決しません。

パッケージ一覧、CSS、プラグイン登録、ライセンス設定は[インストールと基本使用](/guides/pdfs/getting-started/installation)に戻って確認してください。
