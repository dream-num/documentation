title: 설치 및 기본 사용법
---

Univer PDF는 Univer Office SDK의 일부이며 미리 설치를 제공하지 않습니다. PDF 응용 프로그램은 플러그인 모드에서 조립됩니다.

Univer는 두 가지 통합 모드를 지원합니다: 미리 설정 모드 및 플러그인 모드. 미리 설정 모드는 배선의 양을 줄이기 위해 플러그인의 사전 설정된 번들을 제공합니다. **깊은 주문화 또는 연장**가 필요한 경우 플러그인 모드를 사용하여 각 플러그인이 선택되고 개별적으로 구성됩니다.

## 플러그인 모드로 설정하기

### 패키지 관리자 사용

구조 공구는 ES 단위를 지원하고 `package.json`에 있는 `exports` 분야를 지원해야 합니다.

#### 설치

Univer는 React와 RxJS를 가진 그것의 자료 시내를 건설하고, 또한 Vue 또는 Angular 신청에서 끼워넣을 수 있습니다. `react`, `react-dom` 및 `rxjs` 동료 Dependencies[^peer-dependency]가 설치된다는 것을 증명하십시오. 털실 명령은 아래에 그(것)들을 명시적으로 추가합니다.

모든 `@univerjs/*` 및 `@univerjs-pro/*` 패키지의 버전을 동일하게 유지하세요.

#### 사용법

Univer 초기화하기 전에 명시된 높이로 컨테이너를 만듭니다.

```html
<div id="app" style="height: 600px"></div>
```

`FUniver.newAPI(univer)`를 호출하기 전에 아래의 사용 된 정면 항목을 가져옵니다. `@univerjs/design` CSS를 먼저 가져 와서 `@univerjs/ui`의 CSS 및 제품 CSS가 지속됩니다.

<Steps>
  <Step>
    PDF UI 스타일 전에 공유 UI 스타일을 가져 와서 응용 프로그램을 활성화 할 수있는 Locale 팩을 병합 :

    ```ts
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
    import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
    import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
    import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
    import { FUniver } from '@univerjs/core/facade'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverDocsUIPlugin } from '@univerjs/docs-ui'
    import DocsUIEnUS from '@univerjs/docs-ui/locale/en-US'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'
    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs/docs-ui/lib/index.css'
    import '@univerjs-pro/pdfs-ui/lib/index.css'
    ```

  </Step>
  <Step>
    PDF Facade[^facade-entry] 항목 가져 오기. 이 부작용 가져 오기는 `FUniver`에 PDF 방법과 ENums를 추가합니다.

    ```ts
    import '@univerjs-pro/pdfs/facade'
    ```

  </Step>
  <Step>
    런타임을 만들고 명시적인 플러그인 스택을 등록한 다음 PDF를 만드세요.

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          DocsUIEnUS,
          PdfsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverDocsUIPlugin)
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })
    ```

  </Step>
</Steps>

#### 플러그인 설정 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 편집기를 마운트할 DOM 요소 또는 요소 ID입니다. |

`UniverLicensePlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `license` | `string` |  | 클라이언트 라이선스 파일의 내용입니다. |

#### `univer.registerPlugin` 및 `univer.registerPlugins` 메서드 [#registerPlugin]

Univer 인스턴스가 생성되면 `univer.registerPlugin`를 호출하여 플러그인을 등록하십시오.

호출은 `univer.registerPlugin(Plugin, options)` 양식을 가지고 있습니다. `Plugin`는 등록하는 플러그인이며 `options` 옵션 구성 객체입니다. 각 플러그인은 자체 옵션을 정의합니다.

한 번에 여러 플러그인을 등록하려면 `univer.registerPlugins`에 배열을 통과하십시오. 이것은 플러그인 관리를 한 곳에서 유지합니다.

```typescript
univer.registerPlugins([
  [UniverUIPlugin, { container: 'app' }],
  UniverDocsUIPlugin,
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverPdfsPlugin,
  UniverPdfsUIPlugin,
])
```

<Callout type="info">
  `UniverPdfsUIPlugin`은 `UniverDocsUIPlugin`에 의존하므로, 그 전에 공유 문서 UI 플러그인을 등록하세요.
</Callout>

## 모바일 지원 [#mobile-support]

모바일 PDF UI는 같은 패키지의 별도 익스포트인 `UniverPdfsMobileUIPlugin`입니다. `mobile: true` 옵션과 PDF preset은 없습니다. PDF를 열기 전에 UI 모드를 선택하고 데스크톱 UI 등록을 **교체**하세요. 두 가지를 모두 등록하지 마세요.

| 패키지 | 데스크톱 등록 | 모바일 등록 |
| --- | --- | --- |
| `@univerjs/ui` | `UniverUIPlugin` | `UniverMobileUIPlugin` |
| `@univerjs/docs-ui` | `UniverDocsUIPlugin` | `UniverDocsMobileUIPlugin` |
| `@univerjs-pro/pdfs-ui` | `UniverPdfsUIPlugin` | `UniverPdfsMobileUIPlugin` |
| `@univerjs-pro/pdfs-print` | `UniverPdfsPrintPlugin` | `UniverPdfsMobilePrintPlugin` |

```ts
import { UniverDocsMobileUIPlugin } from '@univerjs/docs-ui'
import { UniverPdfsMobileUIPlugin } from '@univerjs-pro/pdfs-ui'
import { UniverPdfsMobilePrintPlugin } from '@univerjs-pro/pdfs-print'
import { UniverMobileUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverMobileUIPlugin, { container: 'app' })
univer.registerPlugin(UniverDocsMobileUIPlugin, { footer: false })
univer.registerPlugin(UniverPdfsMobileUIPlugin)

// Optional: add Print to the mobile viewer menu.
univer.registerPlugin(UniverPdfsMobilePrintPlugin)
```

`UniverPdfsMobileUIPlugin`은 `UniverMobileUIPlugin`과 `UniverDocsMobileUIPlugin`을 의존성으로 선언하므로, 두 플러그인을 먼저 등록하세요. 모바일에서는 데스크톱의 썸네일 레일 대신 페이지 미리 보기 그리드로 열립니다. 이 스택을 언제 마운트할지는 호스트 애플리케이션이 결정합니다(예: 뷰포트 너비 기준). 데스크톱 플러그인을 좁은 컨테이너에 넣는다고 모바일 UI가 만들어지지는 않습니다. 모바일 인쇄 플러그인은 [인쇄](/guides/pdfs/features/print#mobile-support)를 참고하세요.

## 선택적 썸네일 워커

페이지 thumbnails는 추가 구성없이 주요 스레드에 렌더링합니다. 더 큰 문서를 위해 `thumbnailWorkerURL`를 통해 전용 모듈 작업자에게 전달하십시오.

`pdf-thumbnail.worker.ts`와 같은 워커 진입점을 만드세요.

```ts
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

PDF UI 플러그인을 등록할 때 worker URL을 전달하십시오:

`UniverPdfsUIPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | 브라우저 Worker에서 페이지 썸네일을 생성합니다. |

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./pdf-thumbnail.worker.ts', import.meta.url), { type: 'module' }),
})
```

이 옵션은 문자열 URL 또는 기존 `Worker`도 허용합니다. 워커나 `OffscreenCanvas`를 사용할 수 없으면 썸네일 렌더링은 메인 스레드로 대체됩니다.

## 협업 기반 편집

`@univerjs-pro/pdfs-editor`는 로컬 전용 스택의 일부가 아니며 독립적으로 기능을 할 수 없습니다. `@univerjs-pro/collaboration`, `@univerjs-pro/collaboration-client` 및 `@univerjs-pro/collaboration-client-ui` 스택을 설치하고 등록하십시오. [회사연혁](/guides/pdfs/features/collaboration)에 설명 된대로 PDF 편집기 수명주기 플러그인.

## Node.js 사용법

Node.js 서비스는 브라우저 UI 패키지 없이 `UniverPdfsPlugin`를 등록할 수 있습니다. 서비스가 로드하거나 동기화 할 때만 협력 스택을 추가하십시오.

## 기타 릴리스

안정적인 릴리스 외에도 Univer는 아직 공식적으로 출시되지 않은 기능을 제공하는 알파 및 베타 채널을 유지합니다. 또한 더 많은 기능을 의미 :이 버전은 버그, 불완전한 기능, 또는 불안정한 기능을 포함 할 수 있으므로 생산에서 불가능합니다.

### Alpha / Beta 릴리스

Univer 팀은 새로운 기능 또는 중요한 변화를 완료할 때 알파 또는 베타 채널로 변경을 미리 릴리스 할 수 있습니다. 패키지의 알파 또는 베타 버전을 설치하십시오.

```package-install
npm install @univerjs-pro/pdfs@alpha # Alpha version
npm install @univerjs-pro/pdfs@beta # Beta version
```

문제가 발생하거나 알파 또는 베타 버전을 사용하는 동안 피드백을 가지고 있다면 [GitHub 문제](https://github.com/dream-num/univer/issues)를 통해 Univer 팀에보고하십시오. 이 초기 릴리스의 피드백은 환영합니다.
