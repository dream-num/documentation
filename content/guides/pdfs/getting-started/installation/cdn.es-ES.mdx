title: Importar Web SDK a través de CDN
---

Las construcciones UMD proporcionan las siguientes entradas específicas de PDF. Todas las URLs `@univerjs/*` y `@univerjs-pro/*` deben usar la misma versión.

| Ruta UMD | Espacio de nombres global |
| --- | --- |
| `@univerjs-pro/pdfs/lib/umd/index.js` | `UniverProPdfs` |
| `@univerjs-pro/pdfs/lib/umd/facade.js` | `UniverProPdfsFacade` |
| `@univerjs-pro/pdfs-ui/lib/umd/index.js` | `UniverProPdfsUi` |
| `@univerjs-pro/pdfs-ui/lib/umd/locale/en-US.js` | `UniverProPdfsUiEnUS` |

Las dependencias de carga de pares y el tiempo de ejecución compartido primero, luego seguir orden manifiesto para las dependencias de cada paquete. `pdfs` precede `pdfs-ui`, la UI locale sigue `pdfs-ui`, y la entrada PDF Facade sigue `@univerjs/core/facade`. UMD no resuelve este gráfico de dependencia automáticamente.

Para la lista de paquetes, CSS importa, registro de plugins y configuración de licencias, vea [Instalación &quot; Usage básico](/guides/pdfs/getting-started/installation).
