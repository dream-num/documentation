The UMD builds provide the following PDF-specific entries. All `@univerjs/*` and `@univerjs-pro/*` URLs must use the same version.

| UMD path | Global namespace |
| --- | --- |
| `@univerjs-pro/pdfs/lib/umd/index.js` | `UniverProPdfs` |
| `@univerjs-pro/pdfs/lib/umd/facade.js` | `UniverProPdfsFacade` |
| `@univerjs-pro/pdfs-ui/lib/umd/index.js` | `UniverProPdfsUi` |
| `@univerjs-pro/pdfs-ui/lib/umd/locale/en-US.js` | `UniverProPdfsUiEnUS` |

Load peer dependencies and the shared runtime first, then follow manifest order for each package's dependencies. `pdfs` precedes `pdfs-ui`, the UI locale follows `pdfs-ui`, and the PDF Facade entry follows `@univerjs/core/facade`. UMD does not resolve this dependency graph automatically.

For the package list, CSS imports, plugin registration, and license setup, see [Installation & Basic Usage](/guides/pdfs/getting-started/installation).
