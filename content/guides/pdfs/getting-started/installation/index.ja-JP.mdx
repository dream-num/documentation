---
title: インストールと基本的な使い方
---

Univer PDFはUniver Office SDKの一部であり、まだプリセットを提供していないため、プラグインモードでPDFアプリケーションが組み立てられます。

Univerは、2つの統合モードをサポートしています:プリセットモードとプラグインモード。プリセットモードは、プラグインの事前構成済みのバンドルを提供し、配線量を削減します。 **深いカスタム化か延長**が必要な場合は、プラグインモードを使用して、各プラグインが選択され、個別に設定されます。

## プラグインモードでのセットアップ

### パッケージマネージャーの使用

ビルドツールは、`package.json`のESモジュールと`exports`フィールドをサポートする必要があります。

#### インストール

UniverはReactとRxJSでのデータストリームでUIをビルドし、VueまたはAngularアプリケーションに埋め込むこともできます。 `react`、`react-dom`および`rxjs`ピア依存関係[^peer-dependency]がインストールされていることを確認してください。 下の Yarnコマンドは、明示的に追加します。

すべての `@univerjs/*` と `@univerjs-pro/*` パッケージのバージョンを揃えてください。

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}
/>

すべての `@univerjs/*` パッケージと `@univerjs-pro/*` パッケージで**同じバージョン**を使用してください。

#### 使い方

Univerを初期化する前に、コンテナを明示的な高さで作成します。

```html
<div id="app" style="height: 600px"></div>
```

`FUniver.newAPI(univer)` を呼び出す前に下で使用されるファサードエントリをインポートします。 `@univerjs/design` CSS を最初にインポートし、`@univerjs/ui`CSS と製品CSS を最後にインポートします。

<Steps>
  <Step>
    PDF UI スタイルの前に共有 UI スタイルをインポートし、アプリケーションが有効にする locale パックをマージします。

    ```ts
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
    import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
    import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
    import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
    import { FUniver } from '@univerjs/core/facade'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'
    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/pdfs-ui/lib/index.css'
    ```

  </Step>
  <Step>
    PDFファサード[^facade-entry]エントリーをインポートします。 この副作用のインポートは、PDFメソッドを追加し、`FUniver`に列挙します。

    ```ts
    import '@univerjs-pro/pdfs/facade'
    ```

  </Step>
  <Step>
    ランタイムを作成し、明示的なプラグインスタックを登録してから、PDF を作成します。

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          PdfsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })
    ```

  </Step>
</Steps>

#### プラグイン設定 [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターを配置する DOM 要素またはその ID。 |

`UniverLicensePlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `license` | `string` |  | クライアントライセンスファイルの内容。 |

#### `univer.registerPlugin` と `univer.registerPlugins` メソッド [#registerPlugin]

Univerインスタンスが作成されると、`univer.registerPlugin` を呼び出してプラグインを登録します。

コールには、`univer.registerPlugin(Plugin, options)` の形式があります。 `Plugin`は、登録するプラグインで、`options`にはオプションの構成オブジェクトです。 各プラグインは独自のオプションを定義します。

一度に複数のプラグインを登録するには、配列を `univer.registerPlugins` に渡します。これにより、プラグインの管理を一元に保ちます。

```typescript
univer.registerPlugins([
  [UniverUIPlugin, { container: 'app' }],
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverPdfsPlugin,
  UniverPdfsUIPlugin,
])
```

## モバイル対応 [#mobile-support]

現在の`@univerjs-pro/pdfs-ui`パッケージは専用のモバイルUIプラグインをエクスポートしません。`MobileUIPlugin`のインポートと`mobile: true`オプションの両方を提供し、どちらを使用しても試みません。狭いコンテナは、タッチサポートが完了していることを証明しません。ターゲットデバイス上の既存のUIを評価します。

## 任意のサムネイル Worker

ページサムネイルは、追加の構成なしでメインスレッド上にレンダリングします。 より大きい文書では、`thumbnailWorkerURL`を介して専用のモジュールワーカーにそれらを渡します。

`pdf-thumbnail.worker.ts` などの Worker エントリを作成します。

```ts
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

PDF UI プラグインを登録する際に、ワーカー URL を渡します。

`UniverPdfsUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | ブラウザーの Worker でページのサムネイルを生成します。 |

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./pdf-thumbnail.worker.ts', import.meta.url), { type: 'module' }),
})
```

このオプションには文字列 URL または既存の `Worker` も指定できます。Worker または `OffscreenCanvas` を利用できない場合、サムネイルのレンダリングはメインスレッドにフォールバックします。

## 共同編集を使用する場合

`@univerjs-pro/pdfs-editor` ローカルのみのスタックの一部ではなく、独立して機能することはできません。 インストールして、完了を登録します `@univerjs-pro/collaboration`, `@univerjs-pro/collaboration-client`, と `@univerjs-pro/collaboration-client-ui` 記述されるように積み重ねて下さい [コラボレーション](/guides/pdfs/features/collaboration)PDFエディタのライフサイクルプラグインをインストールして登録します。

## Node.js での使用

Node.jsサービスは、任意のブラウザUIパッケージなしで`UniverPdfsPlugin`を登録することができます。サービスが永続したPDFユニットをロードまたは同期する必要があるときのみ、上記のコラボレーションスタックを追加します。

## その他のリリース

Univerは、安定的なリリースに加えて、まだ正式にリリースされていない機能へのアクセスを提供するアルファおよびベータチャネルを維持しています。 より多くの機能は、より多くのリスクも意味します。 これらのバージョンには、バグ、不完全な機能、または不安定な機能が含まれている可能性があるため、可能な限り生産でそれらを避けます。

### Alpha/Beta リリース

Univer チームが新しい機能または重要な変更を完了すると、アルファまたはベータチャネルの変更をプレリリースできます。パッケージのアルファまたはベータ版をインストールします。

```package-install
npm install @univerjs-pro/pdfs@alpha # Alpha バージョン
npm install @univerjs-pro/pdfs@beta # Beta バージョン
```

問題が発生した場合、またはアルファまたはベータ版を使用しているときにフィードバックがある場合は、[GitHubの問題](https://github.com/dream-num/univer/issues)を通じてUniverチームに報告してください。 これらの早期リリースに関するフィードバックを歓迎します。
