Univer PDFs は Univer Pro 製品で、現在プリセットは提供されていません。PDF アプリケーションはプラグインモードで作成してください。

## ブラウザーエディターをインストールする

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab>

    ```shell
    npm install @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-editor @univerjs-pro/pdfs-ui
    ```

  </Tab>
  <Tab>

    ```shell
    pnpm add @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-editor @univerjs-pro/pdfs-ui
    ```

  </Tab>
  <Tab>

    ```shell
    yarn add @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-editor @univerjs-pro/pdfs-ui react react-dom rxjs
    ```

  </Tab>
</Tabs>

すべての `@univerjs/*` パッケージと `@univerjs-pro/*` パッケージで同じバージョンを使用してください。

## プラグインを登録する

<Steps>
  <Step>
    共通 UI のスタイルを PDF UI のスタイルより先にインポートし、アプリケーションで有効にするロケールパックを統合します。

    ```ts
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
    import { UniverPdfEditorPlugin } from '@univerjs-pro/pdfs-editor'
    import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
    import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
    import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
    import { FUniver } from '@univerjs/core/facade'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/pdfs-ui/lib/index.css'
    ```

  </Step>
  <Step>
    PDF Facade エントリをインポートします。この副作用インポートにより、`FUniver` に PDF のメソッドと列挙型が追加されます。

    ```ts
    import '@univerjs-pro/pdfs/facade'
    ```

  </Step>
  <Step>
    ランタイムを作成し、明示的なプラグインスタックを登録してから、PDF を作成します。

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          PdfsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfEditorPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })
    ```

  </Step>
</Steps>

## 任意のサムネイル Worker

ページサムネイルは、追加設定なしでメインスレッド上にレンダリングできます。大きなドキュメントには、`thumbnailWorkerURL` を通じて専用のモジュール Worker を指定できます。

`pdf-thumbnail.worker.ts` などの Worker エントリを作成します。

```ts
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

PDF UI プラグインの登録時にその URL を渡します。

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./pdf-thumbnail.worker.ts', import.meta.url), { type: 'module' }),
})
```

このオプションには文字列 URL または既存の `Worker` も指定できます。Worker または `OffscreenCanvas` を利用できない場合、サムネイルのレンダリングはメインスレッドにフォールバックします。

## Node.js での使用

Node.js サービスでは、ブラウザー UI パッケージを使わずに `UniverPdfsPlugin` と `UniverPdfEditorPlugin` を登録できます。永続化された PDF ユニットの読み込みまたは同期が必要な場合にのみ、共同編集クライアントを追加してください。
