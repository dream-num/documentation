Univer PDFs входит в состав Univer Pro и пока не предоставляет готовой конфигурации. Создавайте приложения PDF в режиме плагинов.

## Установка браузерного редактора

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab>

    ```shell
    npm install @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui
    ```

  </Tab>
  <Tab>

    ```shell
    pnpm add @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui
    ```

  </Tab>
  <Tab>

    ```shell
    yarn add @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui react react-dom rxjs
    ```

  </Tab>
</Tabs>

Используйте одну и ту же версию для всех пакетов `@univerjs/*` и `@univerjs-pro/*`.

## Регистрация плагинов

<Steps>
  <Step>
    Импортируйте стили общего интерфейса перед стилем интерфейса PDF и объедините пакеты локалей, включённые в приложении:

    ```ts
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
    import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
    import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
    import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
    import { FUniver } from '@univerjs/core/facade'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'

    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/pdfs-ui/lib/index.css'
    ```

  </Step>
  <Step>
    Импортируйте точку входа фасада PDF. Этот импорт с побочным эффектом добавляет в `FUniver` методы и перечисления PDF:

    ```ts
    import '@univerjs-pro/pdfs/facade'
    ```

  </Step>
  <Step>
    Создайте среду выполнения, явно зарегистрируйте набор плагинов и создайте PDF:

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          PdfsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })
    ```

  </Step>
</Steps>

## Необязательный воркер миниатюр

Миниатюры страниц могут отрисовываться в основном потоке без дополнительной настройки. Для больших документов передайте выделенный модульный воркер через `thumbnailWorkerURL`.

Создайте точку входа воркера, например `pdf-thumbnail.worker.ts`:

```ts
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

Затем передайте его URL при регистрации плагина интерфейса PDF:

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./pdf-thumbnail.worker.ts', import.meta.url), { type: 'module' }),
})
```

Параметр также принимает строковый URL или существующий объект `Worker`. Если воркеры или `OffscreenCanvas` недоступны, миниатюры отрисовываются в основном потоке.

## Совместное редактирование

`@univerjs-pro/pdfs-editor` не входит в локальный стек. Не регистрируйте его отдельно: сначала установите и зарегистрируйте полный стек `@univerjs-pro/collaboration`, `@univerjs-pro/collaboration-client` и `@univerjs-pro/collaboration-client-ui`, как описано в разделе [Совместная работа](/guides/pdfs/features/collaboration), а затем установите и зарегистрируйте плагин жизненного цикла редактора PDF.

## Использование в Node.js

Сервисы Node.js могут регистрировать только `UniverPdfsPlugin` без браузерных пакетов интерфейса. Добавляйте полный стек совместной работы, описанный выше, только если сервису нужно загружать или синхронизировать сохранённые модули PDF.
