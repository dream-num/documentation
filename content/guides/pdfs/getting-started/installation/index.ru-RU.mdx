title: Установка и основы использования
---

PDF-файлы Univer являются частью Univer Office SDK и еще не предоставляют предустановленного набора, поэтому приложение PDF собирается в режиме плагина.

Univer поддерживает два режима интеграции: предустановленный режим и режим плагина. Предустановочный режим обеспечивает предварительно сконфигурированный пакет плагинов, что уменьшает количество проводки. Если вам нужен **Глубокая настройка или расширения**, используйте режим плагина, где каждый плагин выбирается и настраивается индивидуально.

## Настройка в режиме плагинов

### Использование менеджера пакетов

Инструмент сборки должен поддерживать модули ES и поле `exports` в `package.json`.

#### Установка

Univer строит свой пользовательский интерфейс с React и свои потоки данных с RxJS, а также может быть встроен в приложение Vue или Angular. Убедитесь, что установлены одноранговые зависимости `react`, `react-dom` а также `rxjs` [^peer-dependency] Команда Yarn ниже добавляет их явно.

Используйте **одинаковую версию** всех пакетов `@univerjs/*` и `@univerjs-pro/*`.

<InstallTabs
  packages="@univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui"
  overrides={{ yarn: { append: 'react react-dom rxjs' } }}
/>

Используйте одну и ту же версию для всех пакетов `@univerjs/*` и `@univerjs-pro/*`.

#### Использование

Создайте контейнер с явной высотой перед инициализацией Univer:

```html
<div id="app" style="height: 600px"></div>
```

Импортировать фасадные записи, используемые ниже, прежде чем звонить `FUniver.newAPI(univer)`. Импортировать `@univerjs/design` CSS сначала, затем `@univerjs/ui` и продукт CSS последним.

<Steps>
  <Step>
    Импортируйте общие стили пользовательского интерфейса перед стилем PDF UI и объедините локальные пакеты, которые позволяет приложение:

    ```ts
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
    import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
    import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
    import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
    import { FUniver } from '@univerjs/core/facade'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'
    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/pdfs-ui/lib/index.css'
    ```

  </Step>
  <Step>
    Импорт PDF-файла Facade[^facade-entry]. Этот импорт побочных эффектов добавляет методы PDF и перечисления в `FUniver`:

    ```ts
    import '@univerjs-pro/pdfs/facade'
    ```

  </Step>
  <Step>
    Создайте среду выполнения, явно зарегистрируйте набор плагинов и создайте PDF:

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          PdfsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })
    ```

  </Step>
</Steps>

#### Настройка плагинов [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для редактора или его идентификатор. |

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое клиентского файла лицензии. |

#### Методы `univer.registerPlugin` и `univer.registerPlugins` [#registerPlugin]

После создания экземпляра Univer позвоните в `univer.registerPlugin`, чтобы зарегистрировать на нем плагин.

Звонок имеет форму `univer.registerPlugin(Plugin, options)`. `Plugin` является плагином для регистрации, а `options` — необязательным объектом конфигурации. Каждый плагин определяет свои собственные опции.

Чтобы зарегистрировать несколько плагинов одновременно, передайте массив в `univer.registerPlugins`. Это удерживает управление плагинами в одном месте.

```typescript
univer.registerPlugins([
  [UniverUIPlugin, { container: 'app' }],
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverPdfsPlugin,
  UniverPdfsUIPlugin,
])
```

## Поддержка мобильных устройств [#mobile-support]

Текущий пакет `@univerjs-pro/pdfs-ui` не экспортирует выделенный мобильный плагин пользовательского интерфейса. Он не предоставляет ни импорт `MobileUIPlugin`, ни опцию `mobile: true`. Узкий контейнер не доказывает, что сенсорная поддержка завершена; оценить существующий пользовательский интерфейс на целевых устройствах.

## Необязательный воркер миниатюр

Миниатюры страниц отображаются на основном потоке без дополнительной конфигурации.Для более крупных документов передайте их специальному модулю-работнику через `thumbnailWorkerURL`.

Создайте точку входа воркера, например `pdf-thumbnail.worker.ts`:

```ts
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

Перейдите по URL-адресу рабочего при регистрации плагина PDF UI:

`UniverPdfsUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | Формирует миниатюры страниц в Worker браузера. |

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./pdf-thumbnail.worker.ts', import.meta.url), { type: 'module' }),
})
```

Параметр также принимает строковый URL или существующий объект `Worker`. Если воркеры или `OffscreenCanvas` недоступны, миниатюры отрисовываются в основном потоке.

## Совместное редактирование

`@univerjs-pro/pdfs-editor` не является частью локального стека, и он не может функционировать независимо.Установите и зарегистрируйте полный стек `@univerjs-pro/collaboration`, `@univerjs-pro/collaboration-client` и `@univerjs-pro/collaboration-client-ui` как описано в [Сотрудничество](/guides/pdfs/features/collaboration).

## Использование в Node.js

Служба Node.js может регистрировать `UniverPdfsPlugin` без какого-либо пакета пользовательского интерфейса браузера. Добавьте стек совместной работы выше только тогда, когда службе необходимо загрузить или синхронизировать сохраняющиеся PDF-блоки.

## Другие каналы выпуска

Помимо стабильных релизов, Univer поддерживает альфа- и бета-каналы, которые обеспечивают доступ к функциям, которые еще официально не выпущены.Больше функций также означает больший риск: эти версии могут содержать ошибки, неполную функциональность или нестабильные функции, поэтому избегайте их в производстве, где это возможно.

### Выпуски Alpha / Beta

Когда команда Univer завершает новую функцию или существенное изменение, она может предварительно выпустить изменение на альфа- или бета-канал. Установите альфа-или бета-версию пакета с:

```package-install
npm install @univerjs-pro/pdfs@alpha # Alpha version
npm install @univerjs-pro/pdfs@beta # Beta version
```

Если проблема возникает или у вас есть обратная связь при использовании альфа- или бета-версии, сообщите об этом команде Univer через [Обсуждение GitHub](https://github.com/dream-num/univer/issues).
