---
title: CDN으로 Web SDK 가져오기
---

UMD 빌드는 다음과 같은 PDF 별 항목을 제공합니다. 모든 `@univerjs/*` 및 `@univerjs-pro/*` URL은 동일한 버전을 사용해야합니다.

| UMD 경로 | 전역 네임스페이스 |
| --- | --- |
| `@univerjs-pro/pdfs/lib/umd/index.js` | `UniverProPdfs` |
| `@univerjs-pro/pdfs/lib/umd/facade.js` | `UniverProPdfsFacade` |
| `@univerjs-pro/pdfs-ui/lib/umd/index.js` | `UniverProPdfsUi` |
| `@univerjs-pro/pdfs-ui/lib/umd/locale/en-US.js` | `UniverProPdfsUiEnUS` |

로드 피어 의존성 및 공유 실행 시간 먼저, 다음 각 패키지의 의존성에 대한 표시 순서를 따르십시오. `pdfs`는 `pdfs-ui`를 전진, UI Locale는 `pdfs-ui`을 따르고, PDF 정면 항목은 `@univerjs/core/facade`. UMD는이 의존성 그래프를 자동으로 해결하지 않습니다.

패키지 목록의 경우 CSS 가져오기, 플러그인 등록 및 라이센스 설정, [설치 및 기본 사용](/guides/pdfs/getting-started/installation)를 참조하십시오.
