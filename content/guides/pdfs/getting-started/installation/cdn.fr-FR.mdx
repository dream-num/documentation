---
title: Importer Univer PDFs via un CDN
---

Les builds UMD exposent les entrées propres aux PDF ci-dessous. Utilisez la même version dans toutes les URL `@univerjs/*` et `@univerjs-pro/*`.

| Chemin UMD | Espace de noms global |
| --- | --- |
| `@univerjs-pro/pdfs/lib/umd/index.js` | `UniverProPdfs` |
| `@univerjs-pro/pdfs/lib/umd/facade.js` | `UniverProPdfsFacade` |
| `@univerjs-pro/pdfs-ui/lib/umd/index.js` | `UniverProPdfsUi` |
| `@univerjs-pro/pdfs-ui/lib/umd/locale/en-US.js` | `UniverProPdfsUiEnUS` |

Chargez d’abord les dépendances peer et du runtime partagé, puis celles de chaque package dans l’ordre du manifeste. Chargez `pdfs` avant `pdfs-ui`, la locale d’interface après `pdfs-ui`, et `@univerjs/core/facade` avant l’entrée Facade de PDF. UMD ne résout pas ce graphe automatiquement.

Pour la liste des packages, les styles, l’enregistrement des plugins et la licence, revenez à [Installation et utilisation de base](/guides/pdfs/getting-started/installation).
