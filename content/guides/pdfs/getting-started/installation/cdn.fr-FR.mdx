title: Importer Web SDK via un CDN
---

Toutes les URL `@univerjs/*` et `@univerjs-pro/*` doivent utiliser la même version.

| Chemin UMD | Espace de noms global |
| --- | --- |
| `@univerjs-pro/pdfs/lib/umd/index.js` | `UniverProPdfs` |
| `@univerjs-pro/pdfs/lib/umd/facade.js` | `UniverProPdfsFacade` |
| `@univerjs-pro/pdfs-ui/lib/umd/index.js` | `UniverProPdfsUi` |
| `@univerjs-pro/pdfs-ui/lib/umd/locale/en-US.js` | `UniverProPdfsUiEnUS` |

Load peer dependences and the shared runtime first, puis suivre l'ordre manifeste pour les dépendances de chaque paquet. `pdfs` précède `pdfs-ui`, la locale de l'interface utilisateur suit `pdfs-ui`, et l'entrée PDF Facade suit `@univerjs/core/facade`. UMD ne résout pas ce graphique de dépendance automatiquement.

Pour la liste des paquets, les importations CSS, l'enregistrement des plugins et la configuration de la licence, voir [Installation et utilisation de base](/guides/pdfs/getting-started/installation).
