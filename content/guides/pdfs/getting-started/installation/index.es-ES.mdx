Univer PDFs es parte del Univer Office SDK y no proporciona un preset todavía, por lo que una aplicación PDF se monta en modo plugin.

Univer admite dos modos de integración: modo preestablecido y modo plugin. El modo Preset proporciona un paquete preconfigurado de plugins, que reduce la cantidad de cableado. Si necesita **profunda personalización o extensiones**, utilice el modo plugin, donde cada plugin se selecciona y configura individualmente.

## Configuración a través del modo complemento

### Uso del Administrador de paquetes

La herramienta de construcción debe apoyar ES Modules y el campo `exports` en `package.json`.

#### Instalación

Univer construye su interfaz de usuario con React y sus flujos de datos con RxJS, y también se puede incrustar en una aplicación Vue o Angular. Verifique que las `react`, `react-dom`, y `rxjs` dependencias de pares[^peer-dependency] están instaladas.

Mantén todos los paquetes `@univerjs/*` y `@univerjs-pro/*` en **la misma versión**.

#### Uso

Crear el contenedor con una altura explícita antes de inicializar Univer:

```html
<div id="app" style="height: 600px"></div>
```

Importar las entradas de fachada utilizadas a continuación antes de llamar `FUniver.newAPI(univer)`. Importar `@univerjs/design` CSS primero, luego `@univerjs/ui`CSS, y el producto CSS último.

<Steps>
  <Step>
    Importar los estilos compartidos de interfaz de usuario antes del estilo PDF de la interfaz de usuario, y combinar los paquetes locales que la aplicación permite:

    ```ts
    import { UniverLicensePlugin } from '@univerjs-pro/license'
    import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
    import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
    import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
    import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
    import { FUniver } from '@univerjs/core/facade'
    import DesignEnUS from '@univerjs/design/locale/en-US'
    import { UniverUIPlugin } from '@univerjs/ui'
    import UIEnUS from '@univerjs/ui/locale/en-US'
    import '@univerjs/design/lib/index.css'
    import '@univerjs/ui/lib/index.css'
    import '@univerjs-pro/pdfs-ui/lib/index.css'
    ```

  </Step>
  <Step>
    Importar la entrada PDF Facade[^facade-entry]. Esta importación de efectos secundarios añade los métodos PDF y los enums a `FUniver`:

    ```ts
    import '@univerjs-pro/pdfs/facade'
    ```

  </Step>
  <Step>
    Cree el entorno de ejecución, registre la pila explícita de plugins y cree un PDF:

    ```ts
    const univer = new Univer({
      locale: LocaleType.EN_US,
      locales: {
        [LocaleType.EN_US]: mergeLocales(
          DesignEnUS,
          UIEnUS,
          PdfsUIEnUS,
        ),
      },
    })

    univer.registerPlugin(UniverUIPlugin, { container: 'app' })
    univer.registerPlugin(UniverLicensePlugin, {
      license: process.env.CLIENT_LICENSE_TEXT,
    })
    univer.registerPlugin(UniverPdfsPlugin)
    univer.registerPlugin(UniverPdfsUIPlugin)

    const univerAPI = FUniver.newAPI(univer)
    univerAPI.createPdf({ name: 'Untitled PDF' })
    ```

  </Step>
</Steps>

#### Configuración de plugins [#plugin-configuration]

`UniverUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Elemento DOM donde se monta el editor, o su ID. |

`UniverLicensePlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenido del archivo de licencia del cliente. |

#### Métodos `univer.registerPlugin` y `univer.registerPlugins` [#registerPlugin]

Después de crear la instancia Univer, llame a `univer.registerPlugin` para registrar un plugin en ella.

La llamada tiene el formulario `univer.registerPlugin(Plugin, options)`. `Plugin` es el plugin para registrarse, y `options` Es un objeto de configuración opcional. Cada plugin define sus propias opciones.

Para registrar varios plugins a la vez, pasar un array a `univer.registerPlugins`. Esto mantiene la gestión del plugin en un solo lugar.

```typescript
univer.registerPlugins([
  [UniverUIPlugin, { container: 'app' }],
  [UniverLicensePlugin, {
    license: process.env.CLIENT_LICENSE_TEXT,
  }],
  UniverPdfsPlugin,
  UniverPdfsUIPlugin,
])
```

## Compatibilidad móvil [#mobile-support]

El paquete `@univerjs-pro/pdfs-ui` actual no exporta un plugin UI móvil dedicado. No proporciona una importación `MobileUIPlugin` ni una opción `mobile: true`, así que no trate de usar tampoco. Un contenedor estrecho no prueba que el soporte táctil está completo; evalúa la interfaz de usuario existente en los dispositivos de destino.

## Worker de miniaturas opcional

Las miniaturas de página se renderizan en el hilo principal sin configuración adicional. Para documentos más grandes, páselas a un trabajador de módulos dedicado a través de `thumbnailWorkerURL`.

Cree una entrada de worker como `pdf-thumbnail.worker.ts`:

```ts
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

Pase la URL del trabajador al registrar el plugin PDF UI:

`UniverPdfsUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | Genera miniaturas de página en un Worker del navegador. |

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./pdf-thumbnail.worker.ts', import.meta.url), { type: 'module' }),
})
```

La opción también acepta una URL como cadena o un `Worker` existente. Si los workers u `OffscreenCanvas` no están disponibles, el renderizado de miniaturas vuelve al hilo principal.

## Edición colaborativa

`@univerjs-pro/pdfs-editor` no es parte de una pila local solo, y no puede funcionar de forma independiente. Instalar y registrar la pila `@univerjs-pro/collaboration` completa, `@univerjs-pro/collaboration-client` y `@univerjs-pro/collaboration-client-ui` como se describe en [Colaboración](/guides/pdfs/features/collaboration), luego instalar y registrar el plugin de ciclo de vida del editor PDF.

## Uso con Node.js

Un servicio Node.js puede registrar `UniverPdfsPlugin` sin ningún paquete UI del navegador. Añada la pila de colaboración arriba sólo cuando el servicio necesita cargar o sincronizar unidades PDF perduradas.

## Otras versiones

Además de los lanzamientos estables, Univer mantiene canales alfa y beta que proporcionan acceso a características que aún no se publican oficialmente. Más características también significan más riesgo: estas versiones pueden contener fallos, funcionalidad incompleta o características inestables, así que evite en producción donde sea posible.

### Lanzamiento alfa/beta

Cuando el equipo Univer completa una nueva característica o un cambio significativo, puede pre-renunciar el cambio al canal de alfa o beta. Instalar una versión alfa o de beta de un paquete con:

```package-install
npm install @univerjs-pro/pdfs@alpha # Alpha version
npm install @univerjs-pro/pdfs@beta # Beta version
```

Si un problema ocurre o tiene comentarios al utilizar una versión alfa o beta, informe al equipo Univer a través de [Cuestiones de GitHub](https://github.com/dream-num/univer/issues). La retroalimentación sobre estas versiones tempranas es bienvenida.
