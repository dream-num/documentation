## Глобальный жизненный цикл

Univer проходит четыре этапа в процессе запуска:

- **Starting**: Инициализация, бизнес-единицы ещё не созданы.
- **Готовы**: создано первое бизнес-подразделение. Позднее подразделения не запускают этот этап снова.
- **отданный**: стандартный пользовательский интерфейс выполнил свой первый переключатель рендеринга, хотя асинхронный контент все еще может загружаться.
- **стойкий**: стандартный пользовательский интерфейс достигает этой стадии после задержки после Rendered. Он не ждет всех асинхронных задач.

### Facade API

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="Что сообщает событие">

`LifeCycleChanged` сообщает о глобальном этапе Univer. Если плагин B загружается после глобального этапа `Ready`, B по-прежнему работает под управлением `onReady()` , но второго глобального события `Ready` не происходит.

При добавлении слушателя его обратный вызов может сразу же получить текущий этап, в том числе `Starting`. Для определения текущего этапа без слушателя позвоните `univerAPI.getCurrentLifecycleStage()` .

</Callout>

Чтобы удалить слушателя, используйте возвращенный объект `disposable`:

```typescript
disposable.dispose()
```

## Хуки жизненного цикла плагинов

Плагин запускает `onStarting()`, когда он загружается, а затем догоняет текущую глобальную стадию. Загрузите плагин B в разных точках, чтобы сравнить его вызовы крючка с вызовами плагина A.

<LifecycleDemo />

Общие плагины загружаются, когда они зарегистрированы. Плагины бизнес-типа обычно загружаются до того, как построен первый блок этого типа. Плагина добавляется для типа, который уже начал загружаться в отложенной партии. Явная зависимость может привести к загрузке плагина раньше.

Крючки в каждой партии выполняются синхронно, поэтапно и в порядке зависимости, а асинхронная работа внутри крючка не ожидается.Прежде чем получить доступ к конкретному блоку, DOM-элементу или ресурсу, подтвердите, что он готов.
