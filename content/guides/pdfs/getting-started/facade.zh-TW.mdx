PDF Facade 為 PDF 單元、頁面、可編輯元素和可見的原生文字提供面向應用程式的物件。Facade 變更透過 Univer 命令執行；當變更具有反向操作時，它會參與復原和重做。

## 啟用 PDF Facade

在建立 API 物件之前匯入副作用入口：

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

此匯入會向 `FUniver` 加入 PDF 方法；另外註冊 `UniverPdfsPlugin` 才會提供 PDF 單元模型。

## 建立和尋找 PDF 單元

呼叫 `createPdf` 時如果不提供來源文件，會建立一個 A4 空白頁。

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
```

使用 `createPdf(snapshot)` 可以還原先前由 `pdf.save()` 傳回的資料。

## 操作頁面和元素

Facade 中的放置值以 PDF 點為單位。核心快照幾何使用 EMU，因此應用程式碼應優先使用 Facade 變換，而不是直接編輯物件座標。

```ts
const page = pdf.getPageByIndex(0) ?? pdf.insertPage()

const title = page.insertTextBox({
  text: 'Quarterly review',
  left: 36,
  top: 36,
  width: 320,
  height: 48,
  fontSize: 22,
})

title.setTextStyle({ bold: true, fill: '#1d4ed8' })

const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Metric', 'Value', 'Users', '42'],
  left: 36,
  top: 108,
  width: 360,
  height: 108,
})

table.getCell(1, 1).setText('43')
```

每個可編輯元素都支援識別、變換、可見性、鎖定、堆疊順序和移除。專用包裝器還提供文字、清單、表格、圖片、分隔線和註解操作。

## 取代匯入的原生文字

匯入的 PDF 文字在提升之前會保持為原生內容。`getTextSpans()` 傳回目前可見原生文字的快照控制代碼；`replaceText()` 會在一次持久化變更中抑制該來源文字片段並建立可編輯文字方塊。

```ts
const [span] = page.getTextSpans()

if (span) {
  const editableText = span.replaceText('Reviewed text')
  editableText.setTextStyle({ fill: '#111827' })
}
```

`FPdfTextSpan` 是列舉時刻的快照。取代後，舊控制代碼已失效，不得再次使用。

## 儲存單元

```ts
const snapshot = pdf.save()
```

`save()` 傳回一個分離的 `IPdfUnitData` 快照，其中包含不可變的匯入基線和持久化編輯層。`getDocument()` 傳回來源基線，而不是視覺上具現化編輯結果的文件。

完整方法清單請參閱 [PDF Facade 參考](/reference/facade/pdf)。
