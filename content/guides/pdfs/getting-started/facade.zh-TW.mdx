本入門頁只負責將 PDF Facade 接入應用程式。請註冊 `UniverPdfsPlugin` 以提供 PDF 單元模型，然後在呼叫 `FUniver.newAPI()` 前匯入副作用入口。

## 啟用 PDF Facade

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

副作用匯入會為 `FUniver` 和 `univerAPI.Enum` 擴充 PDF 方法與列舉。

建立、尋找、儲存和編輯 PDF 單元請繼續閱讀 [Univer PDFs API](/guides/pdfs/features/core/pdfs-api)。
