Фасад PDF предоставляет прикладные объекты для модулей PDF, страниц, редактируемых элементов и видимого нативного текста. Изменения фасада выполняются через команды Univer и участвуют в отмене и повторном выполнении, если у изменения есть обратная операция.

## Включение фасада PDF

Импортируйте точку входа с побочным эффектом до создания объекта API:

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

Этот импорт добавляет методы PDF в `FUniver`; отдельная регистрация `UniverPdfsPlugin` предоставляет модель модуля PDF.

## Создание и поиск модулей PDF

Вызов `createPdf` без исходного документа создаёт одну пустую страницу A4.

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
```

Используйте `createPdf(snapshot)`, чтобы восстановить данные, ранее возвращённые методом `pdf.save()`.

## Работа со страницами и элементами

Значения размещения в фасаде выражаются в пунктах PDF. Геометрия основного снимка использует EMU, поэтому в коде приложения следует применять преобразования фасада, а не изменять координаты объектов напрямую.

```ts
const page = pdf.getPageByIndex(0) ?? pdf.insertPage()

const title = page.insertTextBox({
  text: 'Quarterly review',
  left: 36,
  top: 36,
  width: 320,
  height: 48,
  fontSize: 22,
})

title.setTextStyle({ bold: true, fill: '#1d4ed8' })

const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Metric', 'Value', 'Users', '42'],
  left: 36,
  top: 108,
  width: 360,
  height: 108,
})

table.getCell(1, 1).setText('43')
```

Каждый редактируемый элемент поддерживает идентификацию, преобразования, видимость, блокировку, z-порядок и удаление. Специализированные обёртки добавляют операции с текстом, списками, таблицами, изображениями, разделителями и аннотациями.

## Замена импортированного нативного текста

Импортированный текст PDF остаётся нативным содержимым до повышения. `getTextSpans()` возвращает дескрипторы снимков текущего видимого нативного текста; `replaceText()` скрывает этот исходный диапазон и создаёт редактируемое текстовое поле одним сохраняемым изменением.

```ts
const [span] = page.getTextSpans()

if (span) {
  const editableText = span.replaceText('Reviewed text')
  editableText.setTextStyle({ fill: '#111827' })
}
```

`FPdfTextSpan` — это снимок на момент перечисления. После замены старый дескриптор устаревает, и его нельзя использовать повторно.

## Сохранение модуля

```ts
const snapshot = pdf.save()
```

`save()` возвращает отдельный снимок `IPdfUnitData`, содержащий неизменяемую импортированную основу и сохраняемый слой правок. `getDocument()` возвращает исходную основу, а не визуально материализованный отредактированный документ.

Полный список методов приведён в [справочнике по фасаду PDF](/reference/facade/pdf).
