Эта страница охватывает только то, как интегрировать PDF Facade в приложение. Зарегистрируйте `UniverPdfsPlugin` для модели блока PDF, затем импортируйте запись о побочных эффектах, прежде чем звонить `FUniver.newAPI()`.

## Включение фасада PDF

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

Импорт с побочным эффектом расширяет `FUniver` и `univerAPI.Enum` методами и перечислениями PDF.

Чтобы создавать, находить, сохранять и редактировать блоки PDF, продолжайте с [Univer PDF API](/guides/pdfs/features/core/pdfs-api).
