Эта начальная страница отвечает только за подключение фасада PDF к приложению. Зарегистрируйте `UniverPdfsPlugin` для модели модуля PDF, затем импортируйте точку входа с побочным эффектом до вызова `FUniver.newAPI()`.

## Включение фасада PDF

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

Импорт с побочным эффектом расширяет `FUniver` и `univerAPI.Enum` методами и перечислениями PDF.

Перейдите к [API Univer PDFs](/guides/pdfs/features/core/pdfs-api), чтобы создавать, находить, сохранять и редактировать модули PDF.
