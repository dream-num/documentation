PDF 퍼사드는 PDF 유닛, 페이지, 편집 가능한 요소 및 표시되는 네이티브 텍스트를 위한 애플리케이션용 객체를 제공합니다. 퍼사드 변경은 Univer 명령을 통해 실행되며, 변경에 역연산이 있으면 실행 취소 및 다시 실행에 참여합니다.

## PDF 퍼사드 활성화

API 객체를 만들기 전에 부수 효과 진입점을 가져오세요.

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

이 가져오기는 `FUniver`에 PDF 메서드를 추가합니다. 별도로 `UniverPdfsPlugin`을 등록하면 PDF 유닛 모델이 제공됩니다.

## PDF 유닛 만들기 및 찾기

소스 문서 없이 `createPdf`를 호출하면 A4 빈 페이지 하나가 생성됩니다.

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
```

`pdf.save()`가 이전에 반환한 데이터를 복원하려면 `createPdf(snapshot)`을 사용하세요.

## 페이지 및 요소 작업

퍼사드 배치 값은 PDF 포인트로 표현됩니다. 핵심 스냅샷 기하 정보는 EMU를 사용하므로, 애플리케이션 코드는 객체 좌표를 직접 편집하지 말고 퍼사드 변환을 사용하는 것이 좋습니다.

```ts
const page = pdf.getPageByIndex(0) ?? pdf.insertPage()

const title = page.insertTextBox({
  text: 'Quarterly review',
  left: 36,
  top: 36,
  width: 320,
  height: 48,
  fontSize: 22,
})

title.setTextStyle({ bold: true, fill: '#1d4ed8' })

const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Metric', 'Value', 'Users', '42'],
  left: 36,
  top: 108,
  width: 360,
  height: 108,
})

table.getCell(1, 1).setText('43')
```

편집 가능한 모든 요소는 식별, 변환, 표시 여부, 잠금, z 순서 및 제거 기능을 지원합니다. 특화된 래퍼는 텍스트, 목록, 표, 이미지, 구분선 및 주석 작업을 추가합니다.

## 가져온 네이티브 텍스트 바꾸기

가져온 PDF 텍스트는 승격되기 전까지 네이티브 콘텐츠로 유지됩니다. `getTextSpans()`는 현재 표시되는 네이티브 텍스트의 스냅샷 핸들을 반환합니다. `replaceText()`는 해당 소스 범위를 숨기고 한 번의 영속적 변경으로 편집 가능한 텍스트 상자를 만듭니다.

```ts
const [span] = page.getTextSpans()

if (span) {
  const editableText = span.replaceText('Reviewed text')
  editableText.setTextStyle({ fill: '#111827' })
}
```

`FPdfTextSpan`은 열거된 시점의 스냅샷입니다. 바꾼 뒤에는 이전 핸들이 유효하지 않으므로 다시 사용해서는 안 됩니다.

## 유닛 저장

```ts
const snapshot = pdf.save()
```

`save()`는 변경할 수 없는 가져온 기준 문서와 영속적 편집 레이어를 포함하는 분리된 `IPdfUnitData` 스냅샷을 반환합니다. `getDocument()`는 시각적으로 구체화된 편집 문서가 아니라 소스 기준 문서를 반환합니다.

전체 메서드 목록은 [PDF 퍼사드 레퍼런스](/reference/facade/pdf)를 참고하세요.
