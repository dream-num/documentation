이 페이지는 PDF Facade를 응용 프로그램에 통합하는 방법을 포함합니다. PDF 단위 모형을 위한 `UniverPdfsPlugin`를 등록하고, `FUniver.newAPI()`에게 전화하기 전에 부작용을 가져옵니다.

## PDF 퍼사드 활성화

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

부수 효과 import는 `FUniver`와 `univerAPI.Enum`에 PDF 메서드와 열거형을 추가합니다.

생성, 찾기, 저장 및 PDF 단위를 편집하려면 [Univer PDF의 API](/guides/pdfs/features/core/pdfs-api)로 계속하십시오.
