이 시작 페이지의 역할은 PDF 퍼사드를 애플리케이션에 연결하는 것뿐입니다. PDF 유닛 모델을 위해 `UniverPdfsPlugin`을 등록한 다음 `FUniver.newAPI()`를 호출하기 전에 부수 효과 진입점을 가져오세요.

## PDF 퍼사드 활성화

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

부수 효과 import는 `FUniver`와 `univerAPI.Enum`에 PDF 메서드와 열거형을 추가합니다.

PDF 유닛 만들기, 찾기, 저장 및 편집은 [Univer PDFs API](/guides/pdfs/features/core/pdfs-api)에서 계속 확인하세요.
