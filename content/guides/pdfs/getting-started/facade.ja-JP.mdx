この入門ページの役割は、PDF Facade をアプリケーションへ接続することだけです。PDF ユニットモデル用に `UniverPdfsPlugin` を登録し、`FUniver.newAPI()` を呼ぶ前に副作用エントリをインポートします。

## PDF Facade を有効にする

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

副作用インポートは、`FUniver` と `univerAPI.Enum` に PDF のメソッドと列挙型を追加します。

PDF ユニットの作成、取得、保存、編集については [Univer PDFs API](/guides/pdfs/features/core/pdfs-api) に進んでください。
