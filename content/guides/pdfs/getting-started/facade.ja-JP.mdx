このページでは、PDFファサードをアプリケーションに統合する方法のみをカバーしています。 `UniverPdfsPlugin`をPDFユニットモデルに登録し、`FUniver.newAPI()`を呼び出す前に副作用のエントリをインポートします。

## PDF Facade を有効にする

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

副作用インポートは、`FUniver` と `univerAPI.Enum` に PDF のメソッドと列挙型を追加します。

PDF ユニットの作成、検索、保存、編集を行うには、[Univer PDF APIのPDF化](/guides/pdfs/features/core/pdfs-api) を続行します。
