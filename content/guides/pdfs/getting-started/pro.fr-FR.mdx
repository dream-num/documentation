Univer PDFs est distribué avec Univer SDK Pro. Les applications en production nécessitent une licence Pro valide, et les fonctionnalités assurées par le serveur nécessitent également un déploiement d'Univer SDK Pro Server.

## Plugin de licence

Enregistrez la licence avant les plugins PDF et conservez son texte hors du contrôle de version :

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

Injectez la valeur par votre configuration de build ou d'exécution. N'intégrez pas de chaînes de licence, de cookies de session ni d'identifiants de serveur dans les fichiers source du navigateur ou de Node.js.

## Packages PDF

| Fonctionnalité                                    | Packages                                                              |
| ------------------------------------------------- | --------------------------------------------------------------------- |
| Modèle d'unité PDF et façade                      | `@univerjs-pro/pdfs`                                                  |
| Contrats de l'éditeur et de collaboration         | `@univerjs-pro/pdfs-editor`                                           |
| Canevas et interface d'édition dans le navigateur | `@univerjs-pro/pdfs-ui`                                               |
| Importation et exportation PDF                    | `@univerjs-pro/exchange-client`, `@univerjs-pro/pdfs-exchange-client` |
| Impression dans le navigateur                     | `@univerjs-pro/pdfs-print`                                            |
| Collaboration en temps réel                       | `@univerjs-pro/collaboration`, `@univerjs-pro/collaboration-client`   |

Il n'existe actuellement aucun préréglage PDF. Enregistrez uniquement les plugins nécessaires à votre application.

## Configuration requise côté serveur

| Processus                                                  | Univer SDK Pro Server requis |
| ---------------------------------------------------------- | :----------------------: |
| Créer, afficher ou modifier un snapshot PDF local          |           Non            |
| Importer ou exporter un fichier PDF                        |           Oui            |
| Conserver et modifier une unité PDF de façon collaborative |           Oui            |
| Ouvrir la boîte de dialogue d'impression du navigateur     |           Non            |

Les variantes des API d'importation et d'exportation qui utilisent un snapshot évitent la persistance collaborative, mais la conversion passe toujours par le serveur Exchange.

## Notes de déploiement

- Chargez le CSS de l'interface partagée d'Univer avant le CSS des fonctionnalités PDF.
- Configurez les points de terminaison Exchange et de collaboration avec les options des plugins au lieu de coder en dur des URL propres au déploiement dans toute l'application.
- N'intégrez pas les plugins d'interface et d'impression réservés au navigateur dans les services Node.js.
- Validez les PDF importés qui utilisent des polices, des espaces colorimétriques, des annotations ou d'autres fonctionnalités PDF avancées inhabituelles avant de vous fier à une fidélité visuelle exacte.

Pour en savoir plus sur la licence et le déploiement du serveur, consultez [Univer SDK Pro](/guides/pro).
