The PDF Facade provides application-facing objects for PDF units, pages, editable elements, and visible native text. Facade mutations run through Univer commands and participate in undo and redo when the mutation has an inverse.

## Enable the PDF Facade

Import the side-effect entry before creating the API object:

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

The import adds PDF methods to `FUniver`; registering `UniverPdfsPlugin` separately supplies the PDF unit model.

## Create and find PDF units

Calling `createPdf` without a source document creates one blank A4 page.

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
```

Use `createPdf(snapshot)` to restore data previously returned by `pdf.save()`.

## Work with pages and elements

Facade placement values are expressed in PDF points. Core snapshot geometry uses EMU, so application code should prefer Facade transforms instead of editing object coordinates directly.

```ts
const page = pdf.getPageByIndex(0) ?? pdf.insertPage()

const title = page.insertTextBox({
  text: 'Quarterly review',
  left: 36,
  top: 36,
  width: 320,
  height: 48,
  fontSize: 22,
})

title.setTextStyle({ bold: true, fill: '#1d4ed8' })

const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Metric', 'Value', 'Users', '42'],
  left: 36,
  top: 108,
  width: 360,
  height: 108,
})

table.getCell(1, 1).setText('43')
```

Every editable element supports identity, transforms, visibility, locking, z-order, and removal. Specialized wrappers add text, list, table, image, divider, and annotation operations.

## Replace imported native text

Imported PDF text remains native content until it is promoted. `getTextSpans()` returns snapshot handles for currently visible native text; `replaceText()` suppresses that source span and creates an editable text box in one durable mutation.

```ts
const [span] = page.getTextSpans()

if (span) {
  const editableText = span.replaceText('Reviewed text')
  editableText.setTextStyle({ fill: '#111827' })
}
```

An `FPdfTextSpan` is a snapshot from the time it was enumerated. After replacement, the old handle is stale and must not be reused.

## Save the unit

```ts
const snapshot = pdf.save()
```

`save()` returns a detached `IPdfUnitData` snapshot containing the immutable imported baseline and the durable edit layer. `getDocument()` returns the source baseline, not the visually materialized edited document.

For the complete method list, see the [PDF Facade reference](/reference/facade/pdf).
