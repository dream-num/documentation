PDF Facade 为 PDF 单元、页面、可编辑元素和可见的原生文本提供面向应用的对象。Facade 变更通过 Univer 命令执行；当变更存在逆操作时，它会参与撤销和重做。

## 启用 PDF Facade

在创建 API 对象之前导入副作用入口：

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

该导入会向 `FUniver` 添加 PDF 方法；另行注册 `UniverPdfsPlugin` 才会提供 PDF 单元模型。

## 创建和查找 PDF 单元

调用 `createPdf` 时如果不提供源文档，会创建一个 A4 空白页。

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
```

使用 `createPdf(snapshot)` 可以恢复此前由 `pdf.save()` 返回的数据。

## 操作页面和元素

Facade 中的放置值以 PDF 点为单位。核心快照几何使用 EMU，因此应用代码应优先使用 Facade 变换，而不是直接编辑对象坐标。

```ts
const page = pdf.getPageByIndex(0) ?? pdf.insertPage()

const title = page.insertTextBox({
  text: 'Quarterly review',
  left: 36,
  top: 36,
  width: 320,
  height: 48,
  fontSize: 22,
})

title.setTextStyle({ bold: true, fill: '#1d4ed8' })

const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Metric', 'Value', 'Users', '42'],
  left: 36,
  top: 108,
  width: 360,
  height: 108,
})

table.getCell(1, 1).setText('43')
```

每个可编辑元素都支持标识、变换、可见性、锁定、层叠顺序和移除。专用包装器还提供文本、列表、表格、图片、分隔线和批注操作。

## 替换导入的原生文本

导入的 PDF 文本在提升之前会保持为原生内容。`getTextSpans()` 返回当前可见原生文本的快照句柄；`replaceText()` 会在一次持久化变更中抑制该源文本片段并创建可编辑文本框。

```ts
const [span] = page.getTextSpans()

if (span) {
  const editableText = span.replaceText('Reviewed text')
  editableText.setTextStyle({ fill: '#111827' })
}
```

`FPdfTextSpan` 是枚举时刻的快照。替换后，旧句柄已经失效，不得再次使用。

## 保存单元

```ts
const snapshot = pdf.save()
```

`save()` 返回一个分离的 `IPdfUnitData` 快照，其中包含不可变的导入基线和持久化编辑层。`getDocument()` 返回源基线，而不是视觉上物化了编辑结果的文档。

完整的方法列表请参阅 [PDF Facade 参考](/reference/facade/pdf)。
