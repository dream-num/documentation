本入门页只负责将 PDF Facade 接入应用。请注册 `UniverPdfsPlugin` 以提供 PDF 单元模型，然后在调用 `FUniver.newAPI()` 前导入副作用入口。

## 启用 PDF Facade

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

副作用导入会为 `FUniver` 和 `univerAPI.Enum` 扩展 PDF 方法与枚举。

创建、查找、保存和编辑 PDF 单元请继续阅读 [Univer PDFs API](/guides/pdfs/features/core/pdfs-api)。
