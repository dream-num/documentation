Quatre concepts réapparaissent dans chaque intégration PDF et méritent d'être compris avant d'installer les PDF Univer :

- Plugin
- Snapshot et modèle de données
- Commande
- Facade API

## Concepts de base [#basic-concepts]

### Plugins

Univer PDF se compose de plugins. `UniverPdfsPlugin` enregistre le modèle d'unité `UNIVER_PDF` et les commandes PDF durables. `UniverPdfsUIPlugin` ajoute le visionneur du navigateur et, par défaut, les commandes d'édition. Ajouter les paquets d'impression, d'échange ou de collaboration seulement lorsque l'application a besoin de ces capacités.

Les deux plugins fonctionnent sur les services de base, de rendu, de conception et d'interface utilisateur que Univer partage entre les produits. Ces services sont des dépendances techniques de l'application PDF, et l'utilisation des plugins PDF ne nécessite pas d'expérience avec un autre produit Univer.

### Snapshot et modèle de données

Une unité PDF est maintenue en tant que [Snapshot `IPdfUnitData`](/guides/pdfs/model/pdf-data). Le champ `document` contient la référence source, qui est importée ou vide. Les modifications acceptées sont stockées dans `editState` à la place, de sorte que la référence elle-même n'est jamais réécrite en place.

Appelez `pdf.save()` pour obtenir l'instantané complet actuel. `pdf.getDocument()` retourne la référence source, de sorte que les modifications utilisateur doivent être maintenues avec `save()`.

### Commande

Les modifications à l'exécution sont appliquées par des commandes qui conservent la validation, les mises à jour, l'historique de modification et l'intention d'exporter sur le même chemin.

<Callout type="warning" title="Attention">
  Ne modifiez pas directement l'instantané ou le document source d'une unité PDF en cours d'exécution. Utilisez les méthodes PDF Facade ou les commandes enregistrées.
</Callout>

### Facade API

Importez `@univerjs-pro/pdfs/facade` après l'entrée de base Facade pour ajouter les API PDF à `FUniver`. L'entrée fournit des méthodes telles que `createPdf()`, `getActivePdf()` et `getPdf()` .

Pour des instructions et des exemples complets de configuration, voir [Utilisation du PDF Facade API](/guides/pdfs/getting-started/facade).
