Avant d’installer Univer PDFs, découvrez les quatre concepts qui structurent toute intégration PDF :

- Plugin
- Snapshot et modèle de données
- Commande
- Facade API

## Concepts de base [#basic-concepts]

### Plugins

Univer PDFs est assemblé à partir de plugins. `UniverPdfsPlugin` enregistre le modèle d’unité `UNIVER_PDF` et les commandes PDF persistantes. `UniverPdfsUIPlugin` ajoute la visionneuse dans le navigateur et, par défaut, les contrôles d’édition. Ajoutez les packages d’impression, d’échange ou de collaboration uniquement si votre application en a besoin.

Ces plugins utilisent les services partagés de noyau, de rendu, de design et d’interface de Univer. Il s’agit de dépendances techniques de l’application PDF ; aucune expérience préalable avec un autre produit Univer n’est nécessaire.

### Snapshot et modèle de données

Chaque unité PDF est persistée sous la forme d’un [snapshot `IPdfUnitData`](/guides/pdfs/model/pdf-data). Son `document` est la source de référence importée ou vide, tandis que les modifications acceptées sont enregistrées dans `editState` sans réécrire directement cette référence.

Utilisez `pdf.save()` pour obtenir le snapshot actuel complet. `pdf.getDocument()` renvoie la source de référence ; utilisez donc `save()` pour persister les modifications de l’utilisateur.

### Commande

Les modifications à l’exécution passent par des commandes. La validation, la mise à jour de la vue, l’historique d’édition et l’intention d’exportation suivent ainsi le même flux. Les méthodes Facade de PDF préparent les paramètres et exécutent ces commandes.

<Callout type="warning" title="Attention">
  Ne modifiez pas directement le snapshot ou le document source d’une unité PDF active. Utilisez les méthodes Facade de PDF ou des commandes enregistrées.
</Callout>

### Facade API

Importez `@univerjs-pro/pdfs/facade` après l’entrée Facade du noyau pour ajouter les API PDF à `FUniver`. Cette entrée fournit notamment `createPdf()`, `getActivePdf()` et `getPdf()`.

Consultez [Utiliser la Facade API de PDF](/guides/pdfs/getting-started/facade) pour la configuration complète et des exemples.

Continuez avec [Installation et utilisation de base](/guides/pdfs/getting-started/installation).
