Univer PDFs is distributed through Univer SDK Pro. Production applications need a valid Pro license, while server-backed features also need a Univer SDK Pro Server deployment.

## License plugin

Register the license before the PDF plugins and keep the license text outside source control:

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

Inject the value through your build or runtime configuration. Do not embed license strings, session cookies, or server credentials in browser or Node.js source files.

## PDF packages

| Capability                         | Packages                                                              |
| ---------------------------------- | --------------------------------------------------------------------- |
| PDF unit model and Facade          | `@univerjs-pro/pdfs`                                                  |
| Editor and collaboration contracts | `@univerjs-pro/pdfs-editor`                                           |
| Browser canvas and editor UI       | `@univerjs-pro/pdfs-ui`                                               |
| PDF import and export              | `@univerjs-pro/exchange-client`, `@univerjs-pro/pdfs-exchange-client` |
| Browser printing                   | `@univerjs-pro/pdfs-print`                                            |
| Realtime collaboration             | `@univerjs-pro/collaboration`, `@univerjs-pro/collaboration-client`   |

There is no PDF preset at this time. Register only the plugins needed by your application.

## Server requirements

| Workflow                                    | Univer SDK Pro Server required |
| ------------------------------------------- | :------------------------: |
| Create, view, or edit a local PDF snapshot  |             No             |
| Import or export a PDF file                 |            Yes             |
| Persist and collaboratively edit a PDF unit |            Yes             |
| Open the browser print dialog               |             No             |

The snapshot variants of the import and export APIs avoid collaborative persistence, but conversion still runs through the Exchange server.

## Deployment notes

- Load shared Univer UI CSS before PDF feature CSS.
- Configure Exchange and collaboration endpoints through plugin options rather than hard-coding deployment-specific URLs throughout the application.
- Keep Node.js services free of browser-only UI and print plugins.
- Validate imported PDFs that use uncommon fonts, color spaces, annotations, or other advanced PDF features before relying on exact visual fidelity.

For license and server deployment details, see [Univer SDK Pro](/guides/pro).
