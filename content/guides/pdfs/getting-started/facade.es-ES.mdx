La responsabilidad de esta guía inicial es únicamente conectar PDF Facade con la aplicación. Registre `UniverPdfsPlugin` para el modelo de unidad PDF e importe después la entrada con efectos secundarios antes de llamar a `FUniver.newAPI()`.

## Habilitar PDF Facade

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

La importación con efectos secundarios amplía `FUniver` y `univerAPI.Enum` con métodos y enumeraciones de PDF.

Continúe con la [API de Univer PDFs](/guides/pdfs/features/core/pdfs-api) para crear, buscar, guardar y editar unidades PDF.
