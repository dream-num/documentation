Esta página solo cubre cómo integrar el PDF Facade en una aplicación. Registrar `UniverPdfsPlugin` para el modelo de unidad PDF, luego importar la entrada de efectos secundarios antes de llamar a `FUniver.newAPI()`.

## Habilitar PDF Facade

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

La importación con efectos secundarios amplía `FUniver` y `univerAPI.Enum` con métodos y enumeraciones de PDF.

Para crear, encontrar, guardar y editar unidades PDF, continúe con [Univer API de PDF](/guides/pdfs/features/core/pdfs-api).
