La Facade de PDF proporciona objetos orientados a la aplicación para unidades PDF, páginas, elementos editables y texto nativo visible. Las mutaciones de Facade se ejecutan mediante comandos de Univer y participan en deshacer y rehacer cuando la mutación tiene una inversa.

## Habilitar la Facade de PDF

Importe la entrada por efecto secundario antes de crear el objeto de API:

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

La importación añade métodos PDF a `FUniver`; registrar `UniverPdfsPlugin` por separado proporciona el modelo de unidad PDF.

## Crear y buscar unidades PDF

Llamar a `createPdf` sin un documento de origen crea una página A4 en blanco.

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
```

Utilice `createPdf(snapshot)` para restaurar datos devueltos anteriormente por `pdf.save()`.

## Trabajar con páginas y elementos

Los valores de colocación de Facade se expresan en puntos PDF. La geometría de la instantánea principal utiliza EMU, por lo que el código de la aplicación debería preferir las transformaciones de Facade en lugar de editar directamente las coordenadas de los objetos.

```ts
const page = pdf.getPageByIndex(0) ?? pdf.insertPage()

const title = page.insertTextBox({
  text: 'Quarterly review',
  left: 36,
  top: 36,
  width: 320,
  height: 48,
  fontSize: 22,
})

title.setTextStyle({ bold: true, fill: '#1d4ed8' })

const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Metric', 'Value', 'Users', '42'],
  left: 36,
  top: 108,
  width: 360,
  height: 108,
})

table.getCell(1, 1).setText('43')
```

Todos los elementos editables admiten identidad, transformaciones, visibilidad, bloqueo, orden z y eliminación. Los wrappers especializados añaden operaciones de texto, lista, tabla, imagen, divisor y anotación.

## Sustituir texto nativo importado

El texto PDF importado permanece como contenido nativo hasta que se promueve. `getTextSpans()` devuelve identificadores de instantánea para el texto nativo visible actualmente; `replaceText()` suprime ese fragmento de origen y crea un cuadro de texto editable en una sola mutación persistente.

```ts
const [span] = page.getTextSpans()

if (span) {
  const editableText = span.replaceText('Reviewed text')
  editableText.setTextStyle({ fill: '#111827' })
}
```

Un `FPdfTextSpan` es una instantánea del momento en que se enumeró. Después de sustituirlo, el identificador anterior queda obsoleto y no debe reutilizarse.

## Guardar la unidad

```ts
const snapshot = pdf.save()
```

`save()` devuelve una instantánea `IPdfUnitData` independiente que contiene la base importada inmutable y la capa de edición persistente. `getDocument()` devuelve la base de origen, no el documento editado materializado visualmente.

Para consultar la lista completa de métodos, consulte la [referencia de Facade de PDF](/reference/facade/pdf).
