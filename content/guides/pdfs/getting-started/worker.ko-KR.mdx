PDF는 Worker[^web-worker]에서 페이지 썸네일을 렌더링할 수 있습니다. `thumbnailWorkerURL`를 `UniverPdfsUIPlugin`로 전달하면 Worker 사용 `OffscreenCanvas`가 됩니다. 이 옵션은 Worker로 전체 PDF 편집기를 이동하지 않습니다.

[설치 및 기본 사용](/guides/pdfs/getting-started/installation)와 함께 시작; 아래 스니펫은 설정 확장. 생성 또는 로딩 컨텐츠를 만들기 전에 플러그인을 등록하고 동일한 플러그인을 등록하는 것보다 기존 등록을 업데이트합니다.

## 메인 스레드

`UniverPdfsUIPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | 브라우저 Worker에서 미리 보기를 생성합니다. |

```typescript title="main.ts"
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'

univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Worker 진입점

```typescript title="worker.ts"
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

별도의 항목 파일로 모듈 작업기를 사용합니다. 작업자의 패키지 버전을 유지하고 주요 스레드 정렬. 렌더링 및 사용자 상호 작용은 주요 스레드에 남아.

[^web-worker]: Web Worker는 브라우저의 메인 스레드 밖에서 JavaScript를 실행하고 메시지로 통신합니다. 페이지 DOM에 직접 접근할 수 없으며, 계산을 Worker로 옮겨도 편집기 UI가 함께 이동하지는 않습니다.
