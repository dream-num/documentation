## 全域生命週期

Univer 在啟動過程中依次經過四個全域性階段：

- **Starting**：初始化階段，此時還沒有任何業務例項。
- **Ready**：第一個業務例項已經建立，之後再建立例項不會重新觸發該階段。
- **Rendered**：標準 UI 已完成首次渲染切換，非同步內容可能仍在載入。
- **Steady**：標準 UI 在 Rendered 之後延遲一段時間進入該階段，不會等待所有非同步任務結束。

### Facade API

```typescript
const currentStage = univerAPI.getCurrentLifecycleStage()

const disposable = univerAPI.addEvent(univerAPI.Event.LifeCycleChanged, ({ stage }) => {
  console.log(stage)
})
```

<Callout type="warning" title="事件監聽的範圍">

`LifeCycleChanged` 報告的是 Univer 的全域性階段。例如，全域性進入 `Ready` 階段之後才載入外掛 B，B 仍會執行 `onReady()`，但不會再產生全域性 `Ready` 事件。

新增監聽器時，其回撥可能立即收到當前階段，`Starting` 也在其中。如果只需要確認當前所處的階段，可直接呼叫 `univerAPI.getCurrentLifecycleStage()`。

</Callout>

移除監聽器時，使用返回的 `disposable` 物件：

```typescript
disposable.dispose()
```

## 外掛生命週期鉤子

外掛載入時執行 `onStarting()`，隨後補齊到當前全域性階段。在不同時機載入外掛 B，可以對比它與外掛 A 的鉤子呼叫。

<LifecycleDemo />

通用外掛在註冊時載入。業務型別的外掛通常在建立該型別的第一個例項之前載入。如果某個型別已經啟動，之後為該型別新增的外掛會在延遲批次中載入。顯式宣告依賴可以使外掛提前載入。

每個批次中的鉤子按階段、按依賴順序同步呼叫，不等待鉤子內的非同步任務。在訪問具體的例項、DOM 元素或資源之前，先確認其已就緒。
