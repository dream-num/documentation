Die PDF-Facade stellt anwendungsorientierte Objekte für PDF-Einheiten, Seiten, bearbeitbare Elemente und sichtbaren nativen Text bereit. Facade-Mutationen werden über Univer-Befehle ausgeführt und unterstützen Rückgängig und Wiederholen, wenn die Mutation eine Inverse besitzt.

## PDF-Facade aktivieren

Importieren Sie den Side-Effect-Einstieg, bevor Sie das API-Objekt erstellen:

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

Der Import fügt `FUniver` PDF-Methoden hinzu; durch die separate Registrierung von `UniverPdfsPlugin` wird das PDF-Einheitsmodell bereitgestellt.

## PDF-Einheiten erstellen und finden

Der Aufruf von `createPdf` ohne Quelldokument erstellt eine leere A4-Seite.

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
```

Verwenden Sie `createPdf(snapshot)`, um zuvor von `pdf.save()` zurückgegebene Daten wiederherzustellen.

## Mit Seiten und Elementen arbeiten

Facade-Platzierungswerte werden in PDF-Punkten angegeben. Die Geometrie des Core-Snapshots verwendet EMU. Anwendungscode sollte daher Facade-Transformationen bevorzugen, statt Objektkoordinaten direkt zu bearbeiten.

```ts
const page = pdf.getPageByIndex(0) ?? pdf.insertPage()

const title = page.insertTextBox({
  text: 'Quarterly review',
  left: 36,
  top: 36,
  width: 320,
  height: 48,
  fontSize: 22,
})

title.setTextStyle({ bold: true, fill: '#1d4ed8' })

const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Metric', 'Value', 'Users', '42'],
  left: 36,
  top: 108,
  width: 360,
  height: 108,
})

table.getCell(1, 1).setText('43')
```

Jedes bearbeitbare Element unterstützt Identität, Transformationen, Sichtbarkeit, Sperren, Z-Reihenfolge und Entfernen. Spezialisierte Wrapper fügen Text-, Listen-, Tabellen-, Bild-, Trennlinien- und Anmerkungsoperationen hinzu.

## Importierten nativen Text ersetzen

Importierter PDF-Text bleibt nativer Inhalt, bis er heraufgestuft wird. `getTextSpans()` gibt Snapshot-Handles für den aktuell sichtbaren nativen Text zurück; `replaceText()` unterdrückt diesen Quellabschnitt und erstellt in einer einzigen dauerhaften Mutation ein bearbeitbares Textfeld.

```ts
const [span] = page.getTextSpans()

if (span) {
  const editableText = span.replaceText('Reviewed text')
  editableText.setTextStyle({ fill: '#111827' })
}
```

Ein `FPdfTextSpan` ist ein Snapshot zum Zeitpunkt seiner Aufzählung. Nach dem Ersetzen ist das alte Handle veraltet und darf nicht wiederverwendet werden.

## Einheit speichern

```ts
const snapshot = pdf.save()
```

`save()` gibt einen losgelösten `IPdfUnitData`-Snapshot zurück, der die unveränderliche importierte Basis und die dauerhafte Bearbeitungsebene enthält. `getDocument()` gibt die Quellbasis zurück, nicht das visuell materialisierte bearbeitete Dokument.

Die vollständige Methodenliste finden Sie in der [PDF-Facade-Referenz](/reference/facade/pdf).
