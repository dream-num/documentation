Antes de instalar Univer PDFs, conoce los cuatro conceptos que estructuran cualquier integración de PDF:

- Complemento
- Instantánea y modelo de datos
- Comando
- API de Facade

## Conceptos básicos [#basic-concepts]

### Complementos

Univer PDFs se compone de complementos. `UniverPdfsPlugin` registra el modelo de unidad `UNIVER_PDF` y los comandos persistentes de PDF. `UniverPdfsUIPlugin` añade el visor en el navegador y, de forma predeterminada, los controles de edición. Añade paquetes de impresión, intercambio o colaboración solo cuando tu aplicación los necesite.

Estos complementos se apoyan en los servicios compartidos de núcleo, renderizado, diseño e interfaz de Univer. Son dependencias técnicas de la aplicación PDF; no necesitas experiencia previa con otro producto de Univer.

### Instantánea y modelo de datos

Cada unidad PDF se conserva como una [instantánea `IPdfUnitData`](/guides/pdfs/model/pdf-data). Su `document` es la base de origen importada o vacía, mientras que las ediciones aceptadas se guardan en `editState` sin reescribir esa base directamente.

Usa `pdf.save()` para obtener la instantánea actual completa. `pdf.getDocument()` devuelve la base de origen, por lo que debes usar `save()` al conservar las ediciones del usuario.

### Comando

Los cambios en tiempo de ejecución se ejecutan mediante comandos. Así, la validación, la actualización de la vista, el historial de edición y la intención de exportación forman parte del mismo flujo. Los métodos de Facade de PDF preparan los parámetros y ejecutan esos comandos.

<Callout type="warning" title="Precaución">
  No modifiques directamente la instantánea ni el documento de origen de una unidad PDF activa. Usa los métodos de Facade de PDF o comandos registrados.
</Callout>

### API de Facade

Importa `@univerjs-pro/pdfs/facade` después de la entrada Facade del núcleo para añadir las API de PDF a `FUniver`. Esta entrada proporciona métodos como `createPdf()`, `getActivePdf()` y `getPdf()`.

Consulta [Uso de la API Facade de PDF](/guides/pdfs/getting-started/facade) para ver la configuración y los ejemplos completos.

A continuación, continúa con [Instalación y uso básico](/guides/pdfs/getting-started/installation).
