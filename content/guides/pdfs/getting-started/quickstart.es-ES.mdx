Cuatro conceptos se repiten en cada integración PDF y vale la pena entender antes de instalar Univer PDFs:

- Complemento
- Instantánea y modelo de datos
- Comando
- API de Facade

## Conceptos básicos [#basic-concepts]

### Complementos

Univer PDFs consta de plugins. `UniverPdfsPlugin` registra el modelo de unidad `UNIVER_PDF` y los comandos PDF duraderos. `UniverPdfsUIPlugin` añade el visor del navegador y, por defecto, los controles de edición. Agrega los paquetes de impresión, intercambio o colaboración sólo cuando la aplicación necesita esas capacidades.

Ambos plugins funcionan en el núcleo, renderizado, diseño y servicios UI que Univer comparte a través de productos. Estos servicios son dependencias técnicas de la aplicación PDF, y el uso de los plugins PDF no requiere experiencia con otro producto Univer.

### Instantánea y modelo de datos

Una unidad PDF se persistió como un [instantánea `IPdfUnitData`](/guides/pdfs/model/pdf-data). El campo `document` posee la base de referencia fuente, que es importada o en blanco. Las ediciones aceptadas se almacenan en `editState` en lugar de ello, por lo que la base misma nunca se reescribe en su lugar.

Llame a `pdf.save()` para obtener la instantánea actual completa. `pdf.getDocument()` devuelve la base de referencia de origen, por lo que las ediciones de usuario deben ser persistidas con `save()`.

### Comando

Los cambios en el tiempo de ejecución se aplican a través de comandos, que mantiene la validación, ver actualizaciones, editar historia y exportar la intención en el mismo camino. Los métodos PDF Facade preparan los parámetros de comandos y ejecutan los comandos.

<Callout type="warning" title="Precaución">
  No modifique el documento de instantáneas o fuente de una unidad de PDF ejecutada directamente. Use métodos PDF Facade o comandos registrados en su lugar.
</Callout>

### API de Facade

Importar `@univerjs-pro/pdfs/facade` después de la entrada de Facade central para agregar las API de PDF a `FUniver`. La entrada proporciona métodos como `createPdf()`, `getActivePdf()` y `getPdf()` .

Para obtener instrucciones y ejemplos completos, consulte [Utilizando el PDF Facade API](/guides/pdfs/getting-started/facade).
