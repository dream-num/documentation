Univer PDFs는 Univer SDK Pro를 통해 배포됩니다. 프로덕션 애플리케이션에는 유효한 Pro 라이선스가 필요하며, 서버 기반 기능에는 Univer SDK Pro Server 배포도 필요합니다.

## 라이선스 플러그인

PDF 플러그인보다 먼저 라이선스를 등록하고 라이선스 텍스트는 소스 제어 외부에 보관하세요.

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

빌드 또는 런타임 설정을 통해 값을 주입하세요. 브라우저나 Node.js 소스 파일에 라이선스 문자열, 세션 쿠키 또는 서버 자격 증명을 포함하지 마세요.

## PDF 패키지

| 기능                         | 패키지                                                                |
| ---------------------------- | --------------------------------------------------------------------- |
| PDF 유닛 모델 및 퍼사드      | `@univerjs-pro/pdfs`                                                  |
| 편집기 및 협업 계약          | `@univerjs-pro/pdfs-editor`                                           |
| 브라우저 캔버스 및 편집기 UI | `@univerjs-pro/pdfs-ui`                                               |
| PDF 가져오기 및 내보내기     | `@univerjs-pro/exchange-client`, `@univerjs-pro/pdfs-exchange-client` |
| 브라우저 인쇄                | `@univerjs-pro/pdfs-print`                                            |
| 실시간 협업                  | `@univerjs-pro/collaboration`, `@univerjs-pro/collaboration-client`   |

현재 PDF 프리셋은 없습니다. 애플리케이션에 필요한 플러그인만 등록하세요.

## 서버 요구 사항

| 워크플로                               | Univer SDK Pro Server 필요 |
| -------------------------------------- | :--------------------: |
| 로컬 PDF 스냅샷 만들기, 보기 또는 편집 |         아니요         |
| PDF 파일 가져오기 또는 내보내기        |           예           |
| PDF 유닛 저장 및 공동 편집             |           예           |
| 브라우저 인쇄 대화 상자 열기           |         아니요         |

가져오기 및 내보내기 API의 스냅샷 변형은 협업 저장을 생략하지만, 변환은 여전히 Exchange 서버를 통해 실행됩니다.

## 배포 참고 사항

- 공통 Univer UI CSS를 PDF 기능 CSS보다 먼저 불러오세요.
- 배포별 URL을 애플리케이션 곳곳에 하드 코딩하지 말고 플러그인 옵션을 통해 Exchange 및 협업 엔드포인트를 설정하세요.
- Node.js 서비스에는 브라우저 전용 UI 및 인쇄 플러그인을 포함하지 마세요.
- 일반적이지 않은 글꼴, 색 공간, 주석 또는 기타 고급 PDF 기능을 사용하는 가져온 PDF는 정확한 시각적 충실도에 의존하기 전에 검증하세요.

라이선스 및 서버 배포에 관한 자세한 내용은 [Univer SDK Pro](/guides/pro)를 참고하세요.
