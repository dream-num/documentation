Univer PDFs をインストールする前に、PDF 統合の基礎となる 4 つの概念を確認します。

- プラグイン
- スナップショットとデータモデル
- コマンド
- Facade API

## 基本概念 [#basic-concepts]

### プラグイン

Univer PDFs はプラグインを組み合わせて構成します。`UniverPdfsPlugin` は `UNIVER_PDF` ユニットモデルと永続的な PDF コマンドを登録します。`UniverPdfsUIPlugin` はブラウザー用ビューアーと、既定で編集コントロールを追加します。印刷、交換、コラボレーションのパッケージは、必要な機能だけを追加してください。

これらのプラグインは、Univer 共通のコア、レンダリング、デザイン、UI サービス上で動作します。これらは PDF アプリケーションの技術的依存関係であり、ほかの Univer 製品を使用した経験は必要ありません。

### スナップショットとデータモデル

1 つの PDF ユニットは [`IPdfUnitData` スナップショット](/guides/pdfs/model/pdf-data)として保存されます。`document` はインポート済みまたは空のソース基準で、確定した編集はその基準を直接書き換えずに `editState` へ保存されます。

現在の完全なスナップショットは `pdf.save()` で取得します。`pdf.getDocument()` はソース基準を返すため、ユーザーの編集を永続化するときは `save()` を使用してください。

### コマンド

実行中の変更はコマンドを通して行います。これにより、検証、ビューの更新、編集履歴、エクスポート意図が同じ変更フローに入ります。PDF の Facade メソッドはパラメーターを準備してコマンドを実行します。

<Callout type="warning" title="注意">
  実行中の PDF ユニットのスナップショットやソース文書を直接変更しないでください。PDF の Facade メソッドまたは登録済みコマンドを使用してください。
</Callout>

### Facade API

コアの Facade エントリの後で `@univerjs-pro/pdfs/facade` をインポートすると、`FUniver` に PDF API が追加されます。このエントリは `createPdf()`、`getActivePdf()`、`getPdf()` などを提供します。

完全な設定と例は [PDF Facade API の使用](/guides/pdfs/getting-started/facade)を参照してください。
