Univer PDFs를 설치하기 전에 PDF 통합의 기반이 되는 네 가지 개념을 알아봅니다.

- 플러그인
- 스냅샷과 데이터 모델
- 명령
- Facade API

## 기본 개념 [#basic-concepts]

### 플러그인

Univer PDFs는 플러그인을 조합해 구성합니다. `UniverPdfsPlugin`은 `UNIVER_PDF` 유닛 모델과 영속 PDF 명령을 등록합니다. `UniverPdfsUIPlugin`은 브라우저 뷰어와 기본 편집 컨트롤을 추가합니다. 인쇄, 교환, 협업 패키지는 애플리케이션에 해당 기능이 필요할 때만 추가하세요.

이 플러그인들은 Univer의 공용 코어, 렌더링, 디자인, UI 서비스 위에서 동작합니다. 이는 PDF 애플리케이션의 기술적 의존성이며 다른 Univer 제품을 사용해 본 경험은 필요하지 않습니다.

### 스냅샷과 데이터 모델

하나의 PDF 유닛은 [`IPdfUnitData` 스냅샷](/guides/pdfs/model/pdf-data)으로 저장됩니다. `document`는 가져온 원본 또는 빈 원본 기준이며, 확정된 편집은 그 기준을 직접 다시 쓰지 않고 `editState`에 저장됩니다.

현재의 완전한 스냅샷은 `pdf.save()`로 가져옵니다. `pdf.getDocument()`는 원본 기준을 반환하므로 사용자 편집을 저장할 때는 `save()`를 사용하세요.

### 명령

실행 중인 변경은 명령을 통해 수행됩니다. 그러면 검증, 뷰 갱신, 편집 기록, 내보내기 의도가 같은 변경 흐름에 참여합니다. PDF Facade 메서드는 매개변수를 준비하고 해당 명령을 실행합니다.

<Callout type="warning" title="주의">
  실행 중인 PDF 유닛의 스냅샷이나 원본 문서를 직접 변경하지 마세요. PDF Facade 메서드나 등록된 명령을 사용하세요.
</Callout>

### Facade API

코어 Facade 엔트리 다음에 `@univerjs-pro/pdfs/facade`를 가져오면 `FUniver`에 PDF API가 추가됩니다. 이 엔트리는 `createPdf()`, `getActivePdf()`, `getPdf()` 등의 메서드를 제공합니다.

전체 설정과 예제는 [PDF Facade API 사용](/guides/pdfs/getting-started/facade)을 참고하세요.

다음으로 [설치 및 기본 사용법](/guides/pdfs/getting-started/installation)을 진행하세요.
