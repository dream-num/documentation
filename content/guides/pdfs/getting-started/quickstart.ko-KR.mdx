모든 PDF 통합에서 4 가지 개념을 반복하고 Univer PDF를 설치하기 전에 이해하는 것이 좋습니다.

- 플러그인
- 스냅샷과 데이터 모델
- 명령
- Facade API

## 기본 개념 [#basic-concepts]

### 플러그인

Univer PDF는 플러그인으로 구성되어 있습니다. `UniverPdfsPlugin`는 `UNIVER_PDF` 단위 모델과 튼튼한 PDF 명령을 등록합니다. `UniverPdfsUIPlugin`은 브라우저 뷰어를 추가하고 기본적으로 편집 컨트롤을 포함합니다. 응용 프로그램이 그 기능을 필요로 할 때 인쇄, 교환 또는 협업 패키지를 추가하십시오.

Univer는 핵심, 렌더링, 디자인 및 UI 서비스에 모두 실행됩니다. 이 서비스는 PDF 응용 프로그램의 기술적 의존성이며 PDF 플러그인을 사용하여 다른 Univer 제품으로 경험을 요구하지 않습니다.

### 스냅샷과 데이터 모델

PDF 단위는 [`IPdfUnitData` 스냅 샷](/guides/pdfs/model/pdf-data)로 persisted. `document` 필드는 수입 또는 공백인 근원 지선을 붙듭니다. 수락된 편집은 대신 `editState`에서 저장됩니다, 그래서 기본 자체는 결코 장소에 있는 rewritten.

`pdf.save()`를 호출하여 전체 전류 스냅 샷을 얻을 수 있습니다. `pdf.getDocument()`는 소스 기본을 반환하므로 사용자 편집은 `save()`로 지속되어야합니다.

### 명령

runtime에서 변경은 유효성 검사를 유지하고 업데이트, 편집 기록 및 동일한 경로에 수출 의도를 확인하는 명령을 통해 적용됩니다. PDF Facade 방법은 명령 매개 변수를 준비하고 명령을 실행합니다.

<Callout type="warning" title="주 메뉴">
  실행중인 PDF 단위의 스냅 샷 또는 소스 문서를 직접 수정하지 마십시오. 대신 PDF Facade 방법 또는 등록 명령을 사용하십시오.
</Callout>

### Facade API

`@univerjs-pro/pdfs/facade`를 `FUniver`에 PDF API를 추가하기 위해 코어 Facade 항목 후 ZXQ3를 가져 오기. 항목은 `createPdf()`, `getActivePdf()` 및 `getPdf()`와 같은 방법을 제공합니다.

완전한 설정 지침 및 예제를 위해 [PDF Facade API 사용](/guides/pdfs/getting-started/facade)를 참조하십시오.

계속 [설치 및 기본 사용](/guides/pdfs/getting-started/installation).
