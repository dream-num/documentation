Univer PDFs se distribuye mediante Univer SDK Pro. Las aplicaciones de producción necesitan una licencia Pro válida, mientras que las funciones respaldadas por servidor también requieren una implementación de Univer SDK Pro Server.

## Plugin de licencia

Registre la licencia antes que los plugins de PDF y mantenga el texto de la licencia fuera del control de código fuente:

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
```

Inyecte el valor mediante la configuración de compilación o del entorno de ejecución. No incruste cadenas de licencia, cookies de sesión ni credenciales de servidor en archivos de código fuente del navegador o de Node.js.

## Paquetes PDF

| Capacidad                                     | Paquetes                                                              |
| --------------------------------------------- | --------------------------------------------------------------------- |
| Modelo de unidad PDF y Facade                 | `@univerjs-pro/pdfs`                                                  |
| Contratos del editor y de colaboración        | `@univerjs-pro/pdfs-editor`                                           |
| Canvas e interfaz de editor para el navegador | `@univerjs-pro/pdfs-ui`                                               |
| Importación y exportación de PDF              | `@univerjs-pro/exchange-client`, `@univerjs-pro/pdfs-exchange-client` |
| Impresión en el navegador                     | `@univerjs-pro/pdfs-print`                                            |
| Colaboración en tiempo real                   | `@univerjs-pro/collaboration`, `@univerjs-pro/collaboration-client`   |

Actualmente no existe un preset para PDF. Registre únicamente los plugins que necesite su aplicación.

## Requisitos del servidor

| Flujo de trabajo                                        | Requiere Univer SDK Pro Server |
| ------------------------------------------------------- | :------------------------: |
| Crear, visualizar o editar una instantánea PDF local    |             No             |
| Importar o exportar un archivo PDF                      |             Sí             |
| Conservar y editar de forma colaborativa una unidad PDF |             Sí             |
| Abrir el diálogo de impresión del navegador             |             No             |

Las variantes de instantánea de las API de importación y exportación evitan la persistencia colaborativa, pero la conversión sigue realizándose mediante el servidor Exchange.

## Notas de implementación

- Cargue el CSS de la interfaz compartida de Univer antes que el CSS de funciones PDF.
- Configure los endpoints de Exchange y colaboración mediante opciones de plugins, en lugar de codificar URL específicas de la implementación por toda la aplicación.
- Mantenga los servicios de Node.js libres de plugins de interfaz e impresión exclusivos del navegador.
- Valide los archivos PDF importados que utilicen fuentes, espacios de color, anotaciones u otras funciones PDF avanzadas poco habituales antes de depender de una fidelidad visual exacta.

Para obtener información sobre licencias e implementación del servidor, consulte [Univer SDK Pro](/guides/pro).
