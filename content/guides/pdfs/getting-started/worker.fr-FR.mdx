PDFs peut rendre les miniatures des pages dans un Worker. Passez `thumbnailWorkerURL` à `UniverPdfsUIPlugin`. Le Worker utilise `OffscreenCanvas`. Ce réglage concerne les miniatures, pas l’ensemble de l’éditeur PDF.

Commencez par [l’installation et les premiers pas](/guides/pdfs/getting-started/installation). Ces extraits complètent la configuration existante. Enregistrez les plugins avant de créer ou charger du contenu ; modifiez les enregistrements existants sans les dupliquer.

## Thread principal

```typescript title="main.ts"
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'

univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Point d’entrée du Worker

```typescript title="worker.ts"
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

Utilisez un Worker de type module et un fichier d’entrée séparé. Alignez les versions des packages des deux côtés. Le rendu et les interactions restent sur le thread principal.
