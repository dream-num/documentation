Перед установкой Univer PDFs познакомьтесь с четырьмя понятиями, на которых строится любая интеграция PDF:

- Плагин
- Снимок и модель данных
- Команда
- Facade API

## Основные понятия [#basic-concepts]

### Плагины

Univer PDFs собирается из плагинов. `UniverPdfsPlugin` регистрирует модель юнита `UNIVER_PDF` и сохраняемые команды PDF. `UniverPdfsUIPlugin` добавляет браузерный просмотрщик и, по умолчанию, элементы редактирования. Подключайте пакеты для печати, обмена или совместной работы только при необходимости.

Эти плагины работают на общих сервисах ядра, рендеринга, дизайна и интерфейса Univer. Это технические зависимости PDF-приложения; опыт работы с другими продуктами Univer не требуется.

### Снимок и модель данных

Каждый PDF-юнит сохраняется как [снимок `IPdfUnitData`](/guides/pdfs/model/pdf-data). Его `document` — импортированная или пустая исходная основа, а принятые изменения записываются в `editState`, не перезаписывая эту основу напрямую.

Полный текущий снимок возвращает `pdf.save()`. `pdf.getDocument()` возвращает исходную основу, поэтому для сохранения пользовательских изменений используйте `save()`.

### Команда

Изменения во время работы выполняются командами. Благодаря этому проверка, обновление представления, история редактирования и намерение экспорта проходят через единый поток изменений. Методы Facade для PDF подготавливают параметры и выполняют эти команды.

<Callout type="warning" title="Внимание">
  Не изменяйте снимок или исходный документ запущенного PDF-юнита напрямую. Используйте методы PDF Facade или зарегистрированные команды.
</Callout>

### Facade API

Импортируйте `@univerjs-pro/pdfs/facade` после основного Facade-входа, чтобы добавить API PDF в `FUniver`. Этот вход предоставляет `createPdf()`, `getActivePdf()`, `getPdf()` и другие методы.

Полная настройка и примеры приведены в разделе [Использование PDF Facade API](/guides/pdfs/getting-started/facade).

Далее перейдите к разделу [Установка и основы использования](/guides/pdfs/getting-started/installation).
