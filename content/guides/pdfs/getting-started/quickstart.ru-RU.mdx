Четыре концепции повторяются в каждой интеграции PDF и заслуживают понимания перед установкой Univer PDF:

- Плагин
- Снимок и модель данных
- Команда
- Facade API

## Основные понятия [#basic-concepts]

### Плагины

Univer PDFs состоит из плагинов. `UniverPdfsPlugin` регистрирует модульную модель `UNIVER_PDF` и прочные команды PDF. `UniverPdfsUIPlugin` добавляет просмотрщик браузера и, по умолчанию, элементы управления редактированием. Добавлять пакеты печати, обмена или совместной работы только тогда, когда приложение нуждается в этих возможностях.

Оба плагина работают на ядре, рендеринге, дизайне и UI-сервисах, которые Univer разделяет между продуктами.Эти сервисы являются техническими зависимостями приложения PDF, и использование плагинов PDF не требует опыта работы с другим продуктом Univer.

### Снимок и модель данных

Блок PDF сохраняется в виде [Скриншоты `IPdfUnitData`](/guides/pdfs/model/pdf-data). Поле `document` содержит исходную базовую линию, которая либо импортирована, либо пуста. Принятые правки хранятся в `editState`, поэтому сама базовая линия никогда не переписывается на месте.

Позвоните `pdf.save()`, чтобы получить полный текущий снимок. `pdf.getDocument()` возвращает исходный исходный уровень, поэтому пользовательские изменения должны быть сохранены с `save()`.

### Команда

Изменения во время выполнения применяются через команды, которые поддерживают валидацию, просматривают обновления, редактируют историю и экспортируют намерение по одному и тому же пути. PDF методы Facade подготавливают параметры команд и выполняют команды.

<Callout type="warning" title="Осторожно">
  Не изменяйте снимок или исходный документ запущенного PDF-блока напрямую. Используйте методы PDF Facade или зарегистрированные команды вместо этого.
</Callout>

### Facade API

Импорт `@univerjs-pro/pdfs/facade` после базовой записи Facade для добавления PDF API в `FUniver`. В записи представлены такие методы, как `createPdf()`, `getActivePdf()` и `getPdf()` .

Полные инструкции по настройке и примеры см. в [Использование PDF Facade API](/guides/pdfs/getting-started/facade).
