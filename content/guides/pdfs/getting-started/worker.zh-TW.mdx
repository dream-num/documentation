PDFs 支援在 Worker[^web-worker] 中渲染頁面縮圖。將 `thumbnailWorkerURL` 傳給 `UniverPdfsUIPlugin` 後，Worker 會使用 `OffscreenCanvas`。該選項不會把整個 PDF 編輯器移入 Worker。

請先完成[安裝和基本使用](/guides/pdfs/getting-started/installation)，下面的程式碼片段在該配置的基礎上繼續擴充套件。外掛必須在建立或載入內容之前註冊；如果外掛已經註冊，應修改原有註冊，不要重複註冊。

## 主執行緒

`UniverPdfsUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | 在瀏覽器 Worker 中渲染縮圖。 |

```typescript title="main.ts"
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'

univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Worker 入口

```typescript title="worker.ts"
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

使用模組型別的 Worker 和獨立的入口檔案。Worker 與主執行緒中的包版本必須保持一致。渲染和使用者互動仍保留在主執行緒。

[^web-worker]: Web Worker 在瀏覽器主執行緒之外執行 JavaScript，透過訊息與主執行緒通訊，無法直接存取頁面 DOM。將計算移入 Worker 不代表將編輯器介面也移入其中。
