Cette page de démarrage sert uniquement à connecter la façade PDF à l'application. Enregistrez `UniverPdfsPlugin` pour le modèle d'unité PDF, puis importez le point d'entrée à effet de bord avant d'appeler `FUniver.newAPI()`.

## Activer la façade PDF

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

L'import à effet de bord étend `FUniver` et `univerAPI.Enum` avec les méthodes et énumérations PDF.

Continuez avec l'[API Univer PDFs](/guides/pdfs/features/core/pdfs-api) pour créer, rechercher, enregistrer et modifier des unités PDF.
