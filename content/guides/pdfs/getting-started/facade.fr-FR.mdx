Cette page couvre seulement comment intégrer la Facade PDF dans une application. Inscrivez `UniverPdfsPlugin` pour le modèle d'unité PDF, puis importez l'entrée d'effet latéral avant d'appeler `FUniver.newAPI()`.

## Activer la façade PDF

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

L'import à effet de bord étend `FUniver` et `univerAPI.Enum` avec les méthodes et énumérations PDF.

Pour créer, trouver, enregistrer et éditer des unités PDF, continuez avec [API PDFs Univer](/guides/pdfs/features/core/pdfs-api).
