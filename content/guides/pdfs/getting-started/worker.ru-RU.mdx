PDFs поддерживает отрисовку миниатюр страниц в Worker. Передайте `thumbnailWorkerURL` в `UniverPdfsUIPlugin`. Worker использует `OffscreenCanvas`. Эта настройка относится к миниатюрам, а не ко всему редактору PDF.

Сначала выполните [установку и базовую настройку](/guides/pdfs/getting-started/installation). Эти фрагменты дополняют существующую конфигурацию. Регистрируйте плагины до создания или загрузки содержимого; изменяйте уже имеющуюся регистрацию без дублирования.

## Основной поток

```typescript title="main.ts"
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'

univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Точка входа Worker

```typescript title="worker.ts"
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

Используйте модульный Worker и отдельный файл точки входа. Версии пакетов в обоих потоках должны совпадать. Отрисовка и взаимодействие с пользователем остаются в основном потоке.
