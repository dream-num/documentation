PDF-файлы могут отображать миниатюры страниц в Worker[^web-worker]. Передача `thumbnailWorkerURL` в `UniverPdfsUIPlugin` заставляет Worker использовать `OffscreenCanvas`, что не перемещает весь редактор PDF в Worker.

Начните с [Установка и базовое использование](/guides/pdfs/getting-started/installation); приведенные ниже фрагменты расширяют эту настройку. Зарегистрируйте плагины перед созданием или загрузкой контента и обновите существующую регистрацию, а не регистрируйте один и тот же плагин дважды.

## Основной поток

`UniverPdfsUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | Создаёт миниатюры в Worker браузера. |

```typescript title="main.ts"
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'

univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new Worker(new URL('./worker.ts', import.meta.url), { type: 'module' }),
})
```

## Точка входа Worker

```typescript title="worker.ts"
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

Используйте модуль Worker с отдельным файлом ввода. Держите версии пакетов в Worker и на главном потоке выровненными. Рендеринг и взаимодействие пользователей остаются на основном потоке.

[^web-worker]: Web Worker выполняет JavaScript вне главного потока браузера и обменивается с ним сообщениями. Прямого доступа к DOM нет: перенос вычислений не переносит интерфейс редактора.
