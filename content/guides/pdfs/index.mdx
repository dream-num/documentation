## What is Univer PDFs

Univer PDFs is the PDF product in Univer Pro. It represents a PDF as a formal `UNIVER_PDF` unit, preserves the imported source document, and stores accepted edits in a separate durable edit layer. The browser UI renders both layers as one continuous document.

Use Univer PDFs when an application needs to create or open PDFs, add editable content, preserve imported PDF fidelity, collaborate on changes, export the result, or hand the active document to the browser print workflow.

<Callout type="warning" title="Plugin mode only">
  There is no PDF preset package. Register the PDF model, UI, and optional feature plugins explicitly.
</Callout>

## Package map

| Package                              | Role                                                                                                  |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `@univerjs-pro/pdfs`                 | PDF unit model, durable editing primitives, snapshot contracts, and the PDF Facade entry              |
| `@univerjs-pro/pdfs-ui`              | Canvas renderer, continuous page UI, editor controls, locale packs, and the optional thumbnail worker |
| `@univerjs-pro/pdfs-editor`          | PDF editor lifecycle integration for a collaboration-enabled Univer application                       |
| `@univerjs-pro/pdfs-exchange-client` | Server-backed PDF import and export, menu integration, and exchange Facade APIs                       |
| `@univerjs-pro/pdfs-print`           | Browser print menu, print preparation UI, styles, and locale packs                                    |

Keep every `@univerjs/*` and `@univerjs-pro/*` package on the same version.

## Minimal browser setup

The local viewer and editor require the shared Univer UI, the Pro license, the PDF model, and the PDF UI plugin.

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import { LocaleType, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import { UniverUIPlugin } from '@univerjs/ui'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {},
})

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Project brief' })
```

`createPdf` creates a blank PDF with one A4 page when no imported document is supplied.
