Le texte PDF et le menu de police de l'éditeur s'inspirent de deux sources connexes mais distinctes.

| Source | Ce qu’elle contrôle |
| --- | --- |
| `document.assets.fonts` et le `fontId` d’un segment | Les métadonnées de police PDF importées et les ressources utilisées pour reconstruire le contenu natif. |
| `fontFamily` d’un segment éditable | Famille CSS utilisée pour mettre en page et rendre le texte éditable. |
| La liste de polices partagée d’Univer | Les options affichées dans le menu déroulant de police de l'inspecteur PDF. |

L'ajout d'une option à la liste partagée n'ajoute pas d'actif à `document.assets.fonts`, et il ne télécharge pas ou n'intègre pas de fichier de police.

## Configurer la liste de l’éditeur

Lorsque `editor.enabled` est `true`, l'inspecteur PDF utilise le `FontFamilyDropdown` partagé. Configurez cette liste sur `UniverUIPlugin` lors de l'initialisation du navigateur :

`UniverUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Élément DOM de montage de l’éditeur ou son identifiant. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Ajoute ces polices au menu déroulant. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Ajoute ces polices au menu déroulant. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Nom de la police utilisé en CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Nom affiché ou clé de traduction. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Catégorie parmi `sans-serif`, `serif`, `monospace`, `display` ou `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Remplace les polices intégrées par la liste fournie. |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
      { value: 'Noto Serif', label: 'Noto Serif', category: FontCategory.SERIF },
    ],
    override: false,
  },
})
```

Chargez chaque police de navigateur via `@font-face` ou une feuille de style. Sinon Canvas utilise la police de retour du navigateur.

## Ajouter des choix à l’exécution

Après que l'interface utilisateur Facade a chargé, ajouter les choix à la même liste partagée avec `addFonts`:

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
])
```

Ceci ne met à jour que la liste des polices d'applications. Il ne charge pas les octets de police ou ne réécrit pas les versions PDF existantes.

## Appliquer une police au texte PDF éditable

Passez `fontFamily` lors de l'insertion de texte, ou mettez à jour une boîte de texte modifiable à travers la Facade PDF:

```ts
const page = univerAPI.getActivePdf()?.getPageByIndex(0)
const textBox = page?.insertTextBox({
  text: 'Hello PDF',
  fontFamily: 'Inter',
  fontSize: 14,
  left: 36,
  top: 36,
})

textBox?.setTextStyle({ fontFamily: 'Noto Serif' })
```

Le texte importé natif retourné par `page.getTextSpans()` est un instantané, de sorte que son style ne peut pas être changé en place. Appelez d'abord `replaceText(...)` pour le convertir en une zone de texte modifiable, puis appelez `setTextStyle`.
