`UniverPdfsUIPlugin` 使用 Univer 標準工作臺的各個區域組裝 PDF 介面。

| 模式 | PDF UI 外掛掛載的元件 |
| --- | --- |
| `editor.enabled: false` | 內容區中單一連續、虛擬化的唯讀頁面檢視。 |
| `editor.enabled: true` | 左側欄的頁面縮圖欄、PDF Canvas、PDF 底欄、功能區與快顯功能表項目、屬性面板、剪貼簿整合、插入控制項，以及編輯器專用選單元件。 |

將 `editor.enabled` 設為 `false` 會掛載唯讀檢視，並移除所有編輯器專用部件，包括縮圖欄、底欄、功能區、屬性面板和列印操作。行動版外掛還會額外掛載行動版頂端列和選單版面。

## PDF 元件邊界

PDF Canvas、縮圖欄、底欄、檢查器、表格選擇器和工具模式標籤所涉及的 React 檢視與元件識別符號都屬於內部實現細節。`@univerjs-pro/pdfs-ui` 根入口不匯出它們，它們也不是受支援的替換插槽。

不要猜測或複製內部元件鍵並透過 `univerAPI.registerComponent` 替換這些檢視。需要控制 PDF 行為時，請使用 [PDF Facade 指南](/guides/pdfs/getting-started/facade)中支援的 API。

## 在 PDF 旁加入應用程式層級 UI

共享 UI Facade 仍可註冊應用元件，並在普通的 Univer 側邊欄或對話方塊中顯示。它擴充套件的是外圍應用介面，不會替換 PDF 外掛的元件。

```tsx
const registration = univerAPI.registerComponent(
  'pdf-help-panel',
  () => <div>PDF workflow help</div>,
)

const sidebar = univerAPI.openSidebar({
  id: 'pdf-help',
  header: { title: 'PDF help' },
  children: { label: 'pdf-help-panel' },
  width: 320,
})

// 不再需要此外掛功能時：
sidebar.dispose()
registration.dispose()
```

請在 UI Facade 載入完成後註冊元件，並在移除擴充套件時釋放這兩個控制代碼。
