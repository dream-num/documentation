`UniverPdfsUIPlugin` 使用 Univer 标准工作台的各个区域组装 PDF 界面。

| 模式 | PDF UI 插件挂载的组件 |
| --- | --- |
| `editor.enabled: false` | 内容区中单个连续、虚拟化的只读页面视图。 |
| `editor.enabled: true` | 左侧栏的页面缩略图栏、PDF Canvas、PDF 底栏、Ribbon 与右键菜单项、属性面板、剪贴板集成、插入控件，以及编辑器专用菜单组件。 |

将 `editor.enabled` 设为 `false` 会挂载只读视图，并移除所有编辑器专用部件，包括缩略图栏、底栏、Ribbon、属性面板和打印操作。移动端插件还会额外挂载移动端顶栏和菜单布局。

## PDF 组件边界

PDF Canvas、缩略图栏、底栏、检查器、表格选择器和工具模式标签所涉及的 React 视图与组件标识符都属于内部实现细节。`@univerjs-pro/pdfs-ui` 根入口不导出它们，它们也不是受支持的替换插槽。

不要猜测或复制内部组件键并通过 `univerAPI.registerComponent` 替换这些视图。需要控制 PDF 行为时，请使用 [PDF Facade 指南](/guides/pdfs/getting-started/facade)中支持的 API。

## 在 PDF 旁添加应用级 UI

共享 UI Facade 仍可注册应用组件，并在普通的 Univer 侧边栏或对话框中显示。它扩展的是外围应用界面，不会替换 PDF 插件的组件。

```tsx
const registration = univerAPI.registerComponent(
  'pdf-help-panel',
  () => <div>PDF workflow help</div>,
)

const sidebar = univerAPI.openSidebar({
  id: 'pdf-help',
  header: { title: 'PDF help' },
  children: { label: 'pdf-help-panel' },
  width: 320,
})

// 不再需要该扩展时：
sidebar.dispose()
registration.dispose()
```

请在 UI Facade 加载完成后注册组件，并在移除扩展时释放这两个句柄。
