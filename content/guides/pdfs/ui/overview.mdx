`@univerjs-pro/pdfs-ui` renders `UNIVER_PDF` units in the browser. It provides the continuous page canvas, page thumbnails and organizer, selection and editing modes, search, ribbon and context-menu actions, inspector controls, and runtime services used by images and printing.

## Register the UI plugin

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'

import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: true },
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

Merge `PdfsUIEnUS` with the shared design and UI locale packs passed to `new Univer(...)`.

## Viewer-only mode

Editing is enabled by default. Disable the editor controllers while retaining the PDF canvas and viewing UI:

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

This configuration controls UI and local editor services. It does not change the persisted PDF snapshot or grant application-level access control.

## Thumbnail worker

`thumbnailWorkerURL` accepts a string, `URL`, or an existing `Worker`. The worker module must start the exported PDF thumbnail runtime:

```ts title="pdf-thumbnail-worker.ts"
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

Point the plugin configuration at the built worker module. When no compatible worker is configured, thumbnail rendering falls back to the main-thread renderer.

The worker path is an application asset, so its final URL depends on the bundler and deployment base path.

## UI capabilities and Facade APIs

The UI includes tools for page organization, search, selection, native-text editing, text boxes, paragraphs, lists, tables, images, dividers, annotations, and undo and redo. These UI actions use PDF commands and runtime services internally.

Do not infer a public Facade method from the presence of a ribbon button. Use the [PDF Facade reference](/reference/facade/pdf) for supported programmatic APIs, [Import & Export](/guides/pdfs/features/import-export) for exchange methods, and [Print](/guides/pdfs/features/print) for the browser print menu.
