`@univerjs-pro/pdfs-ui`는 PDF 유닛을 Univer 표준 워크벤치에 마운트하며 Univer Office SDK 라이선스로 제공됩니다.

## 패키지 역할

| 패키지 | 역할 |
| --- | --- |
| `@univerjs-pro/pdfs` | `UNIVER_PDF` 단위, 문서 모델 및 튼튼한 PDF 명령을 등록하십시오. |
| `@univerjs-pro/pdfs-ui` | 브라우저 캔버스, 썸네일 레일, 풋커를 장착합니다. 로컬 편집 컨트롤은 기본적으로 활성화됩니다. |
| `@univerjs-pro/pdfs-editor` | 협업 측면에 대한 편집기 의존성을 선언합니다. 그것은 PDF UI를 마운트하지 않으며 `editor.enabled`를 제어하지 않습니다. |

`UniverPdfsUIPlugin`는 `UniverLicensePlugin` 및 `UniverPdfsPlugin`에 따라 UI 플러그인을 등록하기 전에 라이센스 PDF 설정을 완료합니다.

## UI 플러그인 등록

`UniverPdfsUIPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | PDF 편집기 설정입니다. |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | `false`로 설정하면 PDF가 읽기 전용으로 열립니다. |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | 브라우저 Worker에서 미리 보기를 생성합니다. |

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIKoKR from '@univerjs-pro/pdfs-ui/locale/ko-KR'
import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin)
```

Merge `PdfsUIEnUS`는 `new Univer(...)`로 전달된 로컬로 변환합니다. 로컬 팩은 PDF-특성 리본, 검사기, 컨텍스트-menu 및 페이지 레일 라벨을 번역합니다.

## 뷰어 및 편집기 모드

편집이 활성화되면 플러그인은 페이지 썸네일 레일, PDF 캔버스, 풋터를 마운트하고, 리본, 컨텍스트 메뉴, 검사기, 클립보드, 삽입 명령, 편집 작업 및 컨트롤러를 추가로 등록합니다.

애플리케이션에서 편집 컨트롤을 노출하지 않아야 한다면 뷰어 전용 모드를 사용하세요.

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

`editor: { enabled: false }`이면 플러그인은 연속적이고 가상화된 읽기 전용 페이지 뷰만 마운트합니다. 썸네일 레일, 풋터, 리본, 검사기가 등록되지 않으므로 UI에서 썸네일 탐색, 풋터의 페이지 컨트롤, 확대/축소 메뉴, 인쇄 작업을 사용할 수 없습니다. 이 옵션은 마운트되는 UI와 편집 전용 컨트롤러 및 서비스를 변경합니다. 저장된 PDF 스냅샷을 수정하지 않습니다.

## 모바일 레이아웃

모바일 플러그인은 데스크톱 workbench 부품을 감싸지 않고 교체합니다. 페이지 미리 보기 그리드로 열리며, 페이지를 탭하여 편집하고, 헤더에서 undo, redo 및 페이지 작업을 사용합니다. 콘텐츠를 선택하면 서식 및 편집을 위한 떠 있는 도구 모음이 열리고, 읽기 전용 레이아웃은 페이지 수와 확대/축소를 제공합니다.

익스포트된 위치로 확장 작업을 등록하세요: 보기 및 편집 레이아웃에는 `PDF_MOBILE_VIEWER_MENU_POSITION`, 편집 전용에는 `PDF_MOBILE_EDITOR_MENU_POSITION`을 사용합니다.

## 썸네일 워커

`thumbnailWorkerURL`에는 문자열, `URL` 또는 기존 `Worker`를 지정할 수 있습니다. 대상 모듈은 패키지가 내보내는 워커 런타임을 시작해야 합니다.

```ts title="pdf-thumbnail-worker.ts"
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

worker는 전용 작업자 범위를 필요로 합니다. worker가 구성되지 않은 경우, 브라우저는 필수 API를 부족하거나, 메인 스레드만 제공할 수 있는 리소스에 따라, thumbnails 메인 스레드에 렌더링 됩니다.

## 공개 API 경계

UI는 내부적으로 PDF 명령과 서비스를 호출합니다. 리본 버튼은 일치하지 않습니다. 지원되는 프로그램 편집을 위해 [PDF의 사전 가이드](/guides/pdfs/getting-started/facade)를 사용하십시오; 변환을 위해, [수입 및 수출](/guides/pdfs/features/import-export)을 사용하십시오; 브라우저 인쇄를 위해, 사용 [제품정보](/guides/pdfs/features/print).

시작시 [메뉴 구성](/guides/pdfs/features/core#menu-order-and-grid-layout)의 주문 및 그리드 배치를 구성합니다. 기존 메뉴를 변경하려면 [메뉴 Facade API](/guides/pdfs/features/core#menu-facade)를 사용하십시오.
