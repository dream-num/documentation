`@univerjs-pro/pdfs-ui`는 브라우저에서 `UNIVER_PDF` 유닛을 렌더링합니다. 연속 페이지 캔버스, 페이지 썸네일 및 구성 도구, 선택 및 편집 모드, 검색, 리본 및 컨텍스트 메뉴 작업, 검사기 컨트롤, 이미지와 인쇄에서 사용하는 런타임 서비스를 제공합니다.

## UI 플러그인 등록

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'

import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: true },
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

`PdfsUIEnUS`를 `new Univer(...)`에 전달하는 공통 디자인 및 UI 로캘 팩과 병합하세요.

## 뷰어 전용 모드

편집은 기본적으로 활성화되어 있습니다. PDF 캔버스와 보기 UI는 유지하면서 편집기 컨트롤러를 비활성화하세요.

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

이 설정은 UI와 로컬 편집기 서비스를 제어합니다. 저장된 PDF 스냅샷을 변경하거나 애플리케이션 수준의 접근 제어 권한을 부여하지는 않습니다.

## 썸네일 워커

`thumbnailWorkerURL`은 문자열, `URL` 또는 기존 `Worker`를 허용합니다. 워커 모듈은 내보낸 PDF 썸네일 런타임을 시작해야 합니다.

```ts title="pdf-thumbnail-worker.ts"
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

플러그인 설정이 빌드된 워커 모듈을 가리키도록 하세요. 호환되는 워커를 설정하지 않으면 썸네일 렌더링은 메인 스레드 렌더러로 대체됩니다.

워커 경로는 애플리케이션 자산이므로 최종 URL은 번들러 및 배포 기준 경로에 따라 달라집니다.

## UI 기능 및 퍼사드 API

UI에는 페이지 구성, 검색, 선택, 네이티브 텍스트 편집, 텍스트 상자, 단락, 목록, 표, 이미지, 구분선, 주석 및 실행 취소/다시 실행을 위한 도구가 포함됩니다. 이러한 UI 작업은 내부적으로 PDF 명령과 런타임 서비스를 사용합니다.

리본 버튼이 있다고 해서 공개 퍼사드 메서드가 있다고 추론하지 마세요. 지원되는 프로그래밍 API는 [PDF 퍼사드 레퍼런스](/reference/facade/pdf), Exchange 메서드는 [가져오기 및 내보내기](/guides/pdfs/features/import-export), 브라우저 인쇄 메뉴는 [인쇄](/guides/pdfs/features/print)를 참고하세요.
