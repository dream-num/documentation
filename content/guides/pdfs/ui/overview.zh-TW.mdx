`@univerjs-pro/pdfs-ui` 將 PDF 單元掛載到 Univer 標準工作臺中，並透過 Univer Office SDK 獲得許可證。

## 套件職責

| 套件 | 職責 |
| --- | --- |
| `@univerjs-pro/pdfs` | 註冊 `UNIVER_PDF` 單元、文件模型與可持久化的 PDF 命令。 |
| `@univerjs-pro/pdfs-ui` | 掛載瀏覽器 Canvas、縮圖欄和底欄；本地編輯控制元件預設啟用。 |
| `@univerjs-pro/pdfs-editor` | 宣告協同側的編輯器依賴，不掛載 PDF UI，也不控制 `editor.enabled`。 |

`UniverPdfsUIPlugin` 相依於 `UniverLicensePlugin` 和 `UniverPdfsPlugin`。請先完成具授權的 PDF 基礎設定，再註冊 UI 外掛。

## 註冊 UI 外掛

`UniverPdfsUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | PDF 編輯器設定。 |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | 設為 `false` 時以唯讀模式開啟 PDF。 |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | 在瀏覽器 Worker 中產生縮圖。 |

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIZhTW from '@univerjs-pro/pdfs-ui/locale/zh-TW'
import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin)
```

將 `PdfsUIZhCN` 合併到傳給 `new Univer(...)` 的語言套件中。該語言套件負責翻譯 PDF 功能區、檢查器、右鍵選單和頁面欄的文案。

## 檢視與編輯模式

啟用編輯時，外掛會掛載頁面縮圖欄、PDF Canvas 和底欄，並額外註冊功能區、右鍵選單、檢查器、剪貼簿、插入命令，以及編輯操作和控制器。

如果目前應用程式只需檢視 PDF，可以關閉編輯控制項：

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

設定 `editor: { enabled: false }` 後，外掛只掛載一個連續、虛擬化的唯讀頁面檢視。縮圖欄、底欄、功能區和檢查器都不會註冊，因此 UI 中不提供縮圖導覽、底欄中的頁面控制項、縮放選單和列印操作。該選項會改變已掛載的 UI 以及編輯專用的控制器和服務，不會修改已儲存的 PDF 快照。

## 行動版版面配置

行動版外掛會替換桌面版工作臺的各個部分，而不是在它們外層再包一層。它會以頁面預覽格狀檢視開啟。輕觸頁面即可編輯，頂端列提供撤銷、重做和頁面操作。選中內容時會顯示用於格式設定和編輯的浮動工具列。唯讀版面則提供頁數和縮放。

註冊擴充操作時，請使用匯出的位置：檢視與編輯版面使用 `PDF_MOBILE_VIEWER_MENU_POSITION`，僅編輯時使用 `PDF_MOBILE_EDITOR_MENU_POSITION`。

## 縮圖 Worker

`thumbnailWorkerURL` 接受字串、`URL` 或現有的 `Worker`。對應模組必須啟動包匯出的 Worker 執行時：

```ts title="pdf-thumbnail-worker.ts"
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

該 Worker 必須執行在專用 Worker 作用域中。如果未配置 Worker、瀏覽器缺少所需 API，或頁面依賴只能在主執行緒提供的資源，縮圖會在主執行緒渲染。

## 公開 API 邊界

UI 會在內部呼叫 PDF 命令和服務。功能區中存在按鈕並不代表存在對應的公共方法。支援的程式設計式編輯請參閱 [PDF Facade 指南](/guides/pdfs/getting-started/facade)，格式轉換請參閱[匯入匯出](/guides/pdfs/features/import-export)，瀏覽器列印請參閱[列印](/guides/pdfs/features/print)。

## 選單順序與網格佈局 [#menu-configuration]

啟動時，請在[選單配置](/guides/pdfs/features/core#menu-order-and-grid-layout)中設定順序和網格位置。如需修改已有選單，請使用[選單 Facade API](/guides/pdfs/features/core#menu-facade)。
