## Système de design

Le système de design d’Univer repose sur Tailwind CSS. Il définit un ensemble de design tokens qui sont réutilisés par le moteur de rendu afin de garantir la cohérence des styles entre ce dernier et la couche de présentation. Vous pouvez personnaliser les styles de votre application en modifiant ces tokens, qui se trouvent dans le package `@univerjs/themes`.



## Composants

Univer utilise des composants React pour construire la couche de présentation. Les développeurs qui utilisent également React peuvent ainsi très facilement employer les composants d’Univer ou enregistrer leurs propres composants. Cela ne signifie toutefois pas que React est le seul moyen de créer des composants personnalisés : Univer prend aussi en charge d’autres technologies, telles que Vue (version 3.x) et les Web Components.

Tous les composants de base se trouvent dans le package `@univerjs/design`, tandis que les composants d’icônes sont regroupés dans le package `@univerjs/icons`. Ces composants peuvent également être utilisés indépendamment d’Univer.

Les composants personnalisés sont souvent utilisés dans les cas suivants :

- Ajout de boutons personnalisés dans le Ribbon / Context Menu
- Intégration de composants personnalisés dans la Sidebar / Popup, etc.
- Remplacement des composants intégrés

Les chapitres suivants expliquent en détail comment enregistrer et utiliser des composants personnalisés.


`@univerjs-pro/pdfs-ui` affiche les unités `UNIVER_PDF` dans le navigateur. Il fournit le canevas de pages continues, les miniatures et l'organisateur de pages, les modes de sélection et de modification, la recherche, les actions du ruban et du menu contextuel, les commandes de l'inspecteur et les services d'exécution utilisés par les images et l'impression.

## Enregistrer le plugin d'interface

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'

import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: true },
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

Fusionnez `PdfsUIEnUS` avec les packs de locales partagés du design et de l'interface transmis à `new Univer(...)`.

## Mode visionneuse uniquement

La modification est activée par défaut. Désactivez les contrôleurs de l'éditeur tout en conservant le canevas PDF et l'interface de consultation :

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

Cette configuration contrôle l'interface et les services locaux de l'éditeur. Elle ne modifie pas le snapshot PDF conservé et n'accorde aucun contrôle d'accès au niveau de l'application.

## Worker de miniatures

`thumbnailWorkerURL` accepte une chaîne, une `URL` ou un `Worker` existant. Le module du worker doit démarrer l'environnement d'exécution exporté pour les miniatures PDF :

```ts title="pdf-thumbnail-worker.ts"
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

Faites pointer la configuration du plugin vers le module de worker compilé. Lorsqu'aucun worker compatible n'est configuré, l'affichage des miniatures revient au moteur de rendu du thread principal.

Le chemin du worker est une ressource de l'application ; son URL finale dépend donc du bundler et du chemin de base du déploiement.

## Fonctionnalités de l'interface et API de façade

L'interface comprend des outils pour l'organisation des pages, la recherche, la sélection, la modification du texte natif, les zones de texte, les paragraphes, les listes, les tableaux, les images, les séparateurs, les annotations, ainsi que l'annulation et le rétablissement. Ces actions utilisent les commandes PDF et les services d'exécution en interne.

Ne déduisez pas l'existence d'une méthode publique de la façade de celle d'un bouton dans le ruban. Consultez la [référence de la façade PDF](/reference/facade/pdf) pour les API programmatiques prises en charge, [Importation et exportation](/guides/pdfs/features/import-export) pour les méthodes Exchange et [Impression](/guides/pdfs/features/print) pour le menu d'impression du navigateur.
