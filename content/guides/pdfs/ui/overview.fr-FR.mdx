`@univerjs-pro/pdfs-ui` monte les unités PDF dans l’espace de travail Univer standard et est fourni sous licence Univer Office SDK.

## Responsabilités des packages

| Package | Responsabilité |
| --- | --- |
| `@univerjs-pro/pdfs` | Enregistre l'unité `UNIVER_PDF`, le modèle de document et les commandes PDF durables. |
| `@univerjs-pro/pdfs-ui` | Monte la toile du navigateur, le rail miniature et le pied de page; les commandes d'édition locales sont activées par défaut. |
| `@univerjs-pro/pdfs-editor` | Déclare les dépendances de l'éditeur du côté de la collaboration. Il ne monte pas l'interface utilisateur PDF et ne contrôle pas `editor.enabled`. |

`UniverPdfsUIPlugin` dépend de `UniverLicensePlugin` et `UniverPdfsPlugin`, ainsi compléter la configuration PDF sous licence avant d'enregistrer le plugin UI.

## Enregistrer le plugin d’interface

`UniverPdfsUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | Paramètres de l’éditeur PDF. |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | Utilisez `false` pour ouvrir le PDF en lecture seule. |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | Crée les vignettes dans un Worker du navigateur. |

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIFrFR from '@univerjs-pro/pdfs-ui/locale/fr-FR'
import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin)
```

Fusionner `PdfsUIEnUS` dans les localités passées à `new Univer(...)`. Le paquet local traduit les étiquettes de ruban, d'inspecteur, de contextuel-menu et de page-rail spécifiques au format PDF.

## Modes visionneuse et éditeur

Lorsque l'édition est activée, le plugin monte le rail de miniatures de page, le canevas PDF et le pied de page, et il enregistre en outre le ruban, les menus contextuels, l'inspecteur, le presse-papiers, les commandes d'insertion, ainsi que les actions et contrôleurs d'édition.

Utilisez le mode lecture seule lorsque l’application ne doit pas exposer ces contrôles :

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

Avec `editor: { enabled: false }`, le plugin monte uniquement une vue de page continue et virtualisée en lecture seule. Le rail de miniatures, le pied de page, le ruban et l'inspecteur ne sont pas enregistrés, donc la navigation par miniatures, les contrôles de page du pied de page, le menu de zoom et l'action d'impression ne sont pas disponibles dans l'interface. Cette option modifie l'interface utilisateur montée ainsi que les contrôleurs et services spécifiques à l'édition. Cette option ne modifie pas un instantané PDF enregistré.

## Disposition mobile

Le plugin mobile remplace les parties de l'espace de travail de bureau au lieu de les encapsuler. Il s'ouvre sur une grille d'aperçu des pages. Touchez une page pour la modifier, et utilisez l'en-tête pour l'annulation, le rétablissement et les actions de page. La sélection d'un contenu ouvre une barre d'outils flottante de mise en forme et d'édition, et la disposition en lecture seule propose le nombre de pages et le zoom.

Enregistrez les actions d'extension avec les positions exportées : `PDF_MOBILE_VIEWER_MENU_POSITION` pour la disposition de consultation et d'édition, ou `PDF_MOBILE_EDITOR_MENU_POSITION` pour l'édition uniquement.

## Worker de miniatures

`thumbnailWorkerURL` accepte une chaîne, une `URL` ou un `Worker` existant. Le module référencé doit démarrer le runtime exporté :

```ts title="pdf-thumbnail-worker.ts"
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

Si aucun travailleur n'est configuré, le navigateur n'a pas les API requises, ou une page dépend d'une ressource que seul le thread principal peut fournir, les vignettes rendent sur le thread.

## Limite de l’API publique

L'interface utilisateur invoque les commandes et les services PDF en interne. Un bouton ruban n'implique pas de méthode publique correspondante. Pour l'édition programmatique prise en charge, utilisez le [PDF Guide Facade](/guides/pdfs/getting-started/facade); pour la conversion, utilisez [Importation et exportation](/guides/pdfs/features/import-export) ; pour l'impression du navigateur, utilisez [Imprimer](/guides/pdfs/features/print).

## Ordre des menus et disposition en grille [#menu-configuration]

Au démarrage, configurez l'ordre et le placement de la grille dans [configuration du menu](/guides/pdfs/features/core#menu-order-and-grid-layout). Pour modifier un menu existant, utilisez le [menu Facade API](/guides/pdfs/features/core#menu-facade) .
