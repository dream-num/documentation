PDF 文字與編輯器的字型選單使用兩個相關但不同的資料來源。

| 資料來源 | 控制內容 |
| --- | --- |
| `document.assets.fonts` 與文字片段的 `fontId` | 用來還原原生內容的已匯入 PDF 字型中繼資料與資源。 |
| 可編輯文字片段上的 `fontFamily` | 版面配置和渲染可編輯文字時使用的 CSS 字型族。 |
| Univer 的共享字型列表 | PDF 屬性面板字型下拉選單顯示的選項。 |

在共用清單加入選項，不會在 `document.assets.fonts` 新增資源，也不會下載或嵌入字型檔案。

## 設定編輯器字型清單

`editor.enabled` 為 `true` 時，PDF 檢查器使用共享的 `FontFamilyDropdown`。請在初始化瀏覽器時透過 `UniverUIPlugin` 配置該列表：

`UniverUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 掛載目標 DOM 元素或元素 ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | 把這些字型加入下拉框。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | 把這些字型加入下拉框。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS 中使用的字型族名稱。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 顯示名稱或翻譯鍵。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 字型群組，可選 `sans-serif`、`serif`、`monospace`、`display` 或 `handwriting`。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 以傳入的清單取代內建字型選項。 |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'Inter',
        label: 'Inter',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Noto Serif',
        label: 'Noto Serif',
        category: FontCategory.SERIF,
      },
    ],
    override: false,
  },
})
```

請透過 `@font-face` 或樣式表自行載入瀏覽器字型，否則 Canvas 會使用瀏覽器的替代字型。

## 在執行階段新增選項

UI Facade 載入完成後，可透過 `addFonts` 向同一個共享列表追加選項：

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  {
    value: 'Inter',
    label: 'Inter',
    category: FontCategory.SANS_SERIF,
  },
])
```

該方法只更新應用的字型列表，不載入字型二進位制，也不會改寫現有的 PDF 文字片段。

## 為可編輯 PDF 文字設定字型

插入文字時傳入 `fontFamily`，或透過 PDF Facade 更新可編輯文字方塊：

```ts
const page = univerAPI.getActivePdf()?.getPageByIndex(0)
const textBox = page?.insertTextBox({
  text: 'Hello PDF',
  fontFamily: 'Inter',
  fontSize: 14,
  left: 36,
  top: 36,
})

textBox?.setTextStyle({ fontFamily: 'Noto Serif' })
```

`page.getTextSpans()` 返回的原生匯入文字是快照，無法直接修改樣式。請先呼叫 `replaceText(...)` 將其轉換為可編輯文字框，再呼叫 `setTextStyle`。
