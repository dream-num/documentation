`@univerjs-pro/pdfs-ui` monta las unidades PDF en el área de trabajo estándar de Univer y se licencia mediante Univer Office SDK.

## Responsabilidades de los paquetes

| Paquete | Responsabilidad |
| --- | --- |
| `@univerjs-pro/pdfs` | Registra la unidad `UNIVER_PDF`, el modelo de documento y los comandos PDF duraderos. |
| `@univerjs-pro/pdfs-ui` | Se monta el lienzo del navegador, el carril de miniatura y el pie de página; los controles de edición local están habilitados por defecto. |
| `@univerjs-pro/pdfs-editor` | Declara las dependencias del editor en el lado de la colaboración. No monta la interfaz de usuario PDF y no controla `editor.enabled`. |

`UniverPdfsUIPlugin` depende de `UniverLicensePlugin` y `UniverPdfsPlugin`, así que complete la configuración de PDF con licencia antes de registrar el plugin UI.

## Registrar el plugin de interfaz

`UniverPdfsUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | Activa la interfaz de edición. Usa `false` para solo lectura. |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | Activa la interfaz de edición. Usa `false` para solo lectura. |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | Genera miniaturas en un Worker del navegador. |

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEsES from '@univerjs-pro/pdfs-ui/locale/es-ES'
import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin)
```

Combina `PdfsUIEnUS` en los locales pasados a `new Univer(...)`. El paquete local traduce la cinta, el inspector, context-menu y las etiquetas de la página.

## Modos de visor y editor

El plugin siempre monta el carril de página-thumbnail, lona PDF y pie. Editar está habilitado por defecto, y el plugin también registra la cinta, menús contextuales, inspector, portapapeles, comandos de inserción, y acciones de edición y controladores.

Usa el modo de solo lectura cuando la aplicación no deba mostrar esos controles:

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

Esta opción cambia la interfaz de usuario montada, así como los controladores y servicios específicos de edición. No es una política de autorización y no modifica una instantánea de PDF guardada.

## Worker de miniaturas

`thumbnailWorkerURL` acepta una cadena, un `URL` o un `Worker` existente. El módulo indicado debe iniciar el runtime exportado:

```ts title="pdf-thumbnail-worker.ts"
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

El trabajador requiere un ámbito de trabajo dedicado. Si no se configura ningún trabajador, el navegador carece de las API requeridas, o una página depende de un recurso que sólo el hilo principal puede proporcionar, las miniaturas renderizan en el hilo principal.

## Límite de la API pública

La UI invoca comandos y servicios PDF internamente. Un botón de cinta no implica un método público que coincida. Para la edición programática compatible, utilice el [Guía de la Fachada](/guides/pdfs/getting-started/facade); para la conversión, utilice [Importación y exportación](/guides/pdfs/features/import-export), para la impresión del navegador, use [Imprimir](/guides/pdfs/features/print).

## Orden de menús y disposición en cuadrícula [#menu-configuration]

Al inicio, configure el orden y la colocación de la cuadrícula en [configuración del menú](/guides/pdfs/features/core#menu-order-and-grid-layout). Para cambiar un menú existente, utilice el [menú Facade API](/guides/pdfs/features/core#menu-facade).
