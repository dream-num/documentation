## Sistema de diseño

El sistema de diseño de Univer está construido en Tailwind CSS, creando una serie de tokens de diseño que son reutilizados por el motor de renderizado para garantizar un estilo consistente entre el motor de renderizado y la capa de vista. Puede personalizar los estilos de su aplicación modificando estos tokens, que se almacenan en el paquete `@univerjs/themes`.



## Componentes

Univer usa componentes de React para construir la capa de vista, lo que hace que sea muy fácil para los desarrolladores que también usan React usar los componentes de Univer o registrar componentes personalizados. Sin embargo, esto no significa que sólo puedas usar React para crear componentes personalizados; Univer también admite otros marcos, como Vue (versión 3.x) y componentes web.

Todos los componentes básicos se almacenan en el paquete `@univerjs/design` y los componentes de íconos se almacenan en el paquete `@univerjs/icons`. Estos componentes también se pueden usar independientemente de Univer.

Los componentes personalizados se usan a menudo en los siguientes escenarios:

- Agregar botones personalizados en la cinta/menú contextual
- Integrar componentes personalizados en la barra lateral/emergente, etc.
- Reemplazar componentes integrados

Proporcionaremos instrucciones detalladas sobre cómo registrar y usar componentes personalizados en los siguientes capítulos.


`@univerjs-pro/pdfs-ui` renderiza unidades `UNIVER_PDF` en el navegador. Proporciona el canvas de páginas continuas, las miniaturas y el organizador de páginas, los modos de selección y edición, la búsqueda, las acciones de la cinta y el menú contextual, los controles del inspector y los servicios de ejecución utilizados por las imágenes y la impresión.

## Registrar el plugin de interfaz

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'

import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: true },
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

Combine `PdfsUIEnUS` con los paquetes de configuración regional compartidos de diseño e interfaz pasados a `new Univer(...)`.

## Modo exclusivo de visor

La edición está habilitada de forma predeterminada. Deshabilite los controladores del editor mientras conserva el canvas PDF y la interfaz de visualización:

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

Esta configuración controla la interfaz y los servicios locales del editor. No cambia la instantánea PDF persistente ni concede control de acceso en el ámbito de la aplicación.

## Worker de miniaturas

`thumbnailWorkerURL` acepta una cadena, una `URL` o un `Worker` existente. El módulo worker debe iniciar el entorno de ejecución de miniaturas PDF exportado:

```ts title="pdf-thumbnail-worker.ts"
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

Oriente la configuración del plugin al módulo worker compilado. Cuando no se configura un worker compatible, el renderizado de miniaturas vuelve al renderizador del hilo principal.

La ruta del worker es un recurso de la aplicación, por lo que su URL final depende del bundler y de la ruta base de implementación.

## Capacidades de la interfaz y API Facade

La interfaz incluye herramientas para organizar páginas, buscar, seleccionar, editar texto nativo, cuadros de texto, párrafos, listas, tablas, imágenes, divisores, anotaciones, así como deshacer y rehacer. Estas acciones de interfaz utilizan internamente comandos PDF y servicios de ejecución.

No deduzca un método Facade público a partir de la presencia de un botón en la cinta. Utilice la [referencia de Facade de PDF](/reference/facade/pdf) para las API programáticas compatibles, [Importación y exportación](/guides/pdfs/features/import-export) para los métodos de Exchange e [Impresión](/guides/pdfs/features/print) para el menú de impresión del navegador.
