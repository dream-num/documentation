`UniverPdfsUIPlugin`は標準的なUniverの仕事台の部品からのPDFインターフェイスを組み立てます。

| モード | PDF UI プラグインがマウントするコンポーネント |
| --- | --- |
| 常時 | 左サイドバーのページサムネイルレール、コンテンツ領域の PDF Canvas、PDF フッター。 |
| `editor.enabled: true` | リボンとコンテクストメニューの項目、プロパティのインスペクター、クリップボードのインテグレーション、インサート制御、およびエディタ専用のメニューコンポーネント。 |

`editor.enabled`を`false`に設定すると、ビューアパーツが保持され、エディタ専用のコンポーネントとサービスが削除されます。

## PDF コンポーネントの境界

Reactのビューとコンポーネントの識別子は、PDFのキャンバス、サムネイルレール、フッター、インスペクター、テーブルピッカー、およびツールモードラベルの後ろにあります。 `@univerjs-pro/pdfs-ui`ルートエントリからエクスポートされていない、および彼らはサポートされた交換スロットではありません。

`univerAPI.registerComponent`を介してこれらのビューを置き換えるには、内部コンポーネントキーを推論またはコピーしないでください。サポートされているPDF動作については、[PDFファサードガイド](/guides/pdfs/getting-started/facade)を使用します。

## PDF の隣にアプリケーション UI を追加する

共有 UI ファサードは、アプリケーションコンポーネントを登録して、通常の Univer サイドバーまたはダイアログで表示することができます。これにより、周囲のアプリケーションを拡張し、PDF プラグインのコンポーネントを置き換えません。

```tsx
const registration = univerAPI.registerComponent(
  'pdf-help-panel',
  () => <div>PDF workflow help</div>,
)

const sidebar = univerAPI.openSidebar({
  id: 'pdf-help',
  header: { title: 'PDF help' },
  children: { label: 'pdf-help-panel' },
  width: 320,
})

// 拡張が不要になったとき：
sidebar.dispose()
registration.dispose()
```

UI Facade の読み込み後にコンポーネントを登録し、拡張を削除するときは両方のハンドルを破棄してください。
