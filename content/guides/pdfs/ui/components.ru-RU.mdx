`UniverPdfsUIPlugin` собирает интерфейс PDF из стандартных областей рабочей среды Univer.

| Режим | Компоненты, монтируемые плагином PDF UI |
| --- | --- |
| Всегда | Панель миниатюр в левой боковой панели, холст PDF в области содержимого и нижняя панель PDF. |
| `editor.enabled: true` | Лента и контекстные меню, инспектор свойств, интеграция буфера обмена, элементы вставки и компоненты меню редактора. |

При `editor.enabled: false` части просмотрщика сохраняются, а компоненты и службы только для редактора не регистрируются.

## Граница компонентов PDF

React-представления и идентификаторы холста, панели миниатюр, нижней панели, инспектора, выбора таблицы и метки режима — внутренние детали реализации. Корневая точка входа `@univerjs-pro/pdfs-ui` их не экспортирует, и они не являются поддерживаемыми слотами замены.

Не угадывайте и не копируйте внутренний ключ для замены этих представлений через `univerAPI.registerComponent`. Управляйте поведением PDF через поддерживаемые API из [руководства по PDF Facade](/guides/pdfs/getting-started/facade).

## Добавление интерфейса приложения рядом с PDF

Общий UI Facade позволяет зарегистрировать компонент приложения и показать его в обычной боковой панели или диалоге Univer. Это расширяет окружающее приложение, но не заменяет компонент PDF-плагина.

```tsx
const registration = univerAPI.registerComponent(
  'pdf-help-panel',
  () => <div>PDF workflow help</div>,
)

const sidebar = univerAPI.openSidebar({
  id: 'pdf-help',
  header: { title: 'PDF help' },
  children: { label: 'pdf-help-panel' },
  width: 320,
})

// Когда расширение больше не нужно:
sidebar.dispose()
registration.dispose()
```

Регистрируйте компонент после загрузки UI Facade и освобождайте оба дескриптора при удалении расширения.
