`UniverPdfsUIPlugin` собирает PDF-интерфейс из стандартных рабочих частей Univer.

| Режим | Компоненты, монтируемые плагином PDF UI |
| --- | --- |
| Всегда | Панель миниатюр в левой боковой панели, холст PDF в области содержимого и нижняя панель PDF. |
| `editor.enabled: true` | Лента и элементы контекст-меню, инспектор свойств, интеграция буфера обмена, элементы управления вставкой и компоненты меню только для редактора. |

Настройка `editor.enabled` на `false` сохраняет части просмотра и удаляет только компоненты и службы редактора.

## Граница компонентов PDF

Представления React и идентификаторы компонентов за холстом PDF, миниатюрным рельсом, нижним колонтитулом, инспектором, сборщиком столов и меткой режима инструмента являются внутренними деталями реализации. Они не экспортируются из корневой записи `@univerjs-pro/pdfs-ui`, и они не поддерживают слоты для замены.

Не выводите и не копируйте внутренний ключ компонента для замены этих просмотров через `univerAPI.registerComponent`. Для поддерживаемого поведения PDF используйте [PDF Facade Руководство](/guides/pdfs/getting-started/facade) .

## Добавление интерфейса приложения рядом с PDF

Общий интерфейс Facade все еще может регистрировать компонент приложения и отображать его в обычной боковой панели или диалоге Univer. Это расширяет окружающее приложение и не заменяет компонент плагина PDF.

```tsx
const registration = univerAPI.registerComponent(
  'pdf-help-panel',
  () => <div>PDF workflow help</div>,
)

const sidebar = univerAPI.openSidebar({
  id: 'pdf-help',
  header: { title: 'PDF help' },
  children: { label: 'pdf-help-panel' },
  width: 320,
})

// Когда расширение больше не нужно:
sidebar.dispose()
registration.dispose()
```

Регистрируйте компонент после загрузки UI Facade и освобождайте оба дескриптора при удалении расширения.
