`@univerjs-pro/pdfs-ui` 在浏览器中渲染 `UNIVER_PDF` 单元。它提供连续页面 Canvas、页面缩略图和管理器、选择与编辑模式、搜索、功能区和上下文菜单操作、检查器控件，以及图片和打印所使用的运行时服务。

## 注册 UI 插件

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'

import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: true },
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

将 `PdfsUIEnUS` 与传给 `new Univer(...)` 的公共 Design 和 UI 语言包合并。

## 仅查看模式

编辑默认启用。可以禁用编辑器控制器，同时保留 PDF Canvas 和查看 UI：

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

该配置控制 UI 和本地编辑器服务。它不会更改持久化的 PDF 快照，也不会授予应用级访问控制。

## 缩略图 Worker

`thumbnailWorkerURL` 接受字符串、`URL` 或现有的 `Worker`。Worker 模块必须启动导出的 PDF 缩略图运行时：

```ts title="pdf-thumbnail-worker.ts"
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

让插件配置指向构建后的 Worker 模块。未配置兼容 Worker 时，缩略图渲染会回退到主线程渲染器。

Worker 路径是应用资源，因此其最终 URL 取决于打包器和部署基础路径。

## UI 能力和 Facade API

UI 包含页面管理、搜索、选择、原生文本编辑、文本框、段落、列表、表格、图片、分隔线、批注以及撤销和重做工具。这些 UI 操作在内部使用 PDF 命令和运行时服务。

不要根据功能区按钮的存在推断公共 Facade 方法。请通过 [PDF Facade 参考](/reference/facade/pdf)了解受支持的编程 API，通过[导入与导出](/guides/pdfs/features/import-export)了解 Exchange 方法，并通过[打印](/guides/pdfs/features/print)了解浏览器打印菜单。
