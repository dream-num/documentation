`@univerjs-pro/pdfs-ui` rendert `UNIVER_PDF`-Einheiten im Browser. Es stellt den fortlaufenden Seiten-Canvas, Seitenminiaturen und -organisation, Auswahl- und Bearbeitungsmodi, Suche, Menüband- und Kontextmenüaktionen, Inspektorsteuerelemente sowie von Bildern und Drucken verwendete Laufzeitdienste bereit.

## UI-Plugin registrieren

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'

import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: true },
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

Führen Sie `PdfsUIEnUS` mit den gemeinsamen Design- und UI-Sprachpaketen zusammen, die an `new Univer(...)` übergeben werden.

## Reiner Betrachtermodus

Die Bearbeitung ist standardmäßig aktiviert. Deaktivieren Sie die Editorcontroller, während Sie PDF-Canvas und Anzeigeoberfläche beibehalten:

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

Diese Konfiguration steuert die Benutzeroberfläche und lokale Editordienste. Sie ändert weder den gespeicherten PDF-Snapshot noch gewährt sie eine Zugriffskontrolle auf Anwendungsebene.

## Thumbnail-Worker

`thumbnailWorkerURL` akzeptiert eine Zeichenfolge, eine `URL` oder einen vorhandenen `Worker`. Das Worker-Modul muss die exportierte PDF-Thumbnail-Laufzeit starten:

```ts title="pdf-thumbnail-worker.ts"
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

Verweisen Sie in der Plugin-Konfiguration auf das gebaute Worker-Modul. Wenn kein kompatibler Worker konfiguriert ist, fällt das Rendern der Miniaturen auf den Renderer im Hauptthread zurück.

Der Worker-Pfad ist ein Anwendungs-Asset; seine endgültige URL hängt daher vom Bundler und Basispfad der Bereitstellung ab.

## UI-Funktionen und Facade-APIs

Die Benutzeroberfläche enthält Werkzeuge für Seitenorganisation, Suche, Auswahl, native Textbearbeitung, Textfelder, Absätze, Listen, Tabellen, Bilder, Trennlinien, Anmerkungen sowie Rückgängig und Wiederholen. Diese UI-Aktionen verwenden intern PDF-Befehle und Laufzeitdienste.

Leiten Sie nicht aus dem Vorhandensein einer Menüband-Schaltfläche auf eine öffentliche Facade-Methode. Verwenden Sie die [PDF-Facade-Referenz](/reference/facade/pdf) für unterstützte programmatische APIs, [Import und Export](/guides/pdfs/features/import-export) für Exchange-Methoden und [Drucken](/guides/pdfs/features/print) für das Browser-Druckmenü.
