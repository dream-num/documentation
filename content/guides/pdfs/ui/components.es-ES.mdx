`UniverPdfsUIPlugin` compone la interfaz PDF con las áreas estándar del espacio de trabajo de Univer.

| Modo | Componentes que monta el plugin PDF UI |
| --- | --- |
| Siempre | Barra de miniaturas en la barra lateral izquierda, lienzo PDF en el área de contenido y pie de PDF. |
| `editor.enabled: true` | Cinta y menús contextuales, inspector de propiedades, integración con el portapapeles, controles de inserción y componentes de menú del editor. |

Con `editor.enabled: false` se conservan las partes del visor y se omiten los componentes y servicios exclusivos del editor.

## Límite de los componentes PDF

Las vistas React y los identificadores del lienzo, la barra de miniaturas, el pie, el inspector, el selector de tablas y la etiqueta de modo son detalles internos. La entrada raíz de `@univerjs-pro/pdfs-ui` no los exporta y no son puntos de sustitución compatibles.

No copies ni deduzcas una clave interna para reemplazar estas vistas mediante `univerAPI.registerComponent`. Usa la [guía de la Facade PDF](/guides/pdfs/getting-started/facade) para controlar el comportamiento PDF mediante API compatibles.

## Añadir UI de aplicación junto a un PDF

La Facade de UI compartida sí puede registrar un componente de aplicación y mostrarlo en una barra lateral o un diálogo normal de Univer. Esto amplía la aplicación circundante; no sustituye un componente del plugin PDF.

```tsx
const registration = univerAPI.registerComponent(
  'pdf-help-panel',
  () => <div>PDF workflow help</div>,
)

const sidebar = univerAPI.openSidebar({
  id: 'pdf-help',
  header: { title: 'PDF help' },
  children: { label: 'pdf-help-panel' },
  width: 320,
})

// Cuando la extensión ya no sea necesaria:
sidebar.dispose()
registration.dispose()
```

Registra el componente después de cargar la Facade de UI y libera ambos manejadores al retirar la extensión.
