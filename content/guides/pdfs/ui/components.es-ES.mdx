`UniverPdfsUIPlugin` monta la interfaz PDF de las partes estándar del banco de trabajo Univer.

| Modo | Componentes que monta el plugin PDF UI |
| --- | --- |
| Siempre | Barra de miniaturas en la barra lateral izquierda, lienzo PDF en el área de contenido y pie de PDF. |
| `editor.enabled: true` | Artículos de cinta y context-menu, inspector de propiedades, integración de portapapeles, controles de inserción y componentes de menú solo editor. |

Configurar `editor.enabled` a `false` retiene las partes del espectador y elimina los componentes y servicios sólo del editor.

## Límite de los componentes PDF

Las vistas de React y los identificadores de componentes detrás del lienzo PDF, el carril de miniatura, la caldera, el inspector, el selector de mesa y la etiqueta de movimiento de herramientas son detalles de la implementación interna. No se exportan desde la entrada de la raíz `@univerjs-pro/pdfs-ui`, y no son compatibles con ranuras de reemplazo.

No infiere ni copie una clave de componente interno para reemplazar estas vistas a través de `univerAPI.registerComponent`. Para el comportamiento PDF compatible, utilice el [Guía de la Fachada](/guides/pdfs/getting-started/facade) .

## Añadir UI de aplicación junto a un PDF

La UI Facade compartida todavía puede registrar un componente de aplicación y mostrarlo en una barra lateral o diálogo Univer regular. Esto extiende la aplicación circundante y no reemplaza un componente del plugin PDF.

```tsx
const registration = univerAPI.registerComponent(
  'pdf-help-panel',
  () => <div>PDF workflow help</div>,
)

const sidebar = univerAPI.openSidebar({
  id: 'pdf-help',
  header: { title: 'PDF help' },
  children: { label: 'pdf-help-panel' },
  width: 320,
})

// Cuando la extensión ya no sea necesaria:
sidebar.dispose()
registration.dispose()
```

Registra el componente después de cargar la Facade de UI y libera ambos manejadores al retirar la extensión.
