PDF テキストとエディターのフォントメニューは、関連はあるものの異なるデータソースを使います。

| データソース | 制御する内容 |
| --- | --- |
| `document.assets.fonts` とテキストランの `fontId` | ネイティブ内容の再現に使う、インポート済み PDF フォントのメタデータとリソース。 |
| 編集可能なテキストランの `fontFamily` | 編集可能テキストのレイアウトと描画に使う CSS フォントファミリー。 |
| Univer の共有フォントリスト | PDF インスペクターのフォントドロップダウンに表示する選択肢。 |

共有リストに選択肢を追加しても、`document.assets.fonts` にアセットは追加されず、フォントファイルのダウンロードや埋め込みも行われません。

## エディターのフォントリストを設定する

`editor.enabled` が `true` の場合、PDF インスペクターは共有の `FontFamilyDropdown` を使います。ブラウザー設定の `UniverUIPlugin` でリストを指定します。

`UniverUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターを配置する DOM 要素またはその ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | ドロップダウンにフォントを追加します。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | ドロップダウンにフォントを追加します。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS で使うフォント名。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 表示名または翻訳キー。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 分類。`sans-serif`、`serif`、`monospace`、`display`、`handwriting` を指定できます。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 既定のフォント一覧を指定した一覧に置き換えます。 |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'Inter',
        label: 'Inter',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Noto Serif',
        label: 'Noto Serif',
        category: FontCategory.SERIF,
      },
    ],
    override: false,
  },
})
```

ブラウザーフォントは `@font-face` やスタイルシートで別途読み込んでください。読み込まれていない場合、Canvas はブラウザーの代替フォントを使います。

## 実行時に選択肢を追加する

UI Facade の読み込み後は、`addFonts` で同じ共有リストに選択肢を追加できます。

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  {
    value: 'Inter',
    label: 'Inter',
    category: FontCategory.SANS_SERIF,
  },
])
```

このメソッドが更新するのはアプリケーションのフォントリストだけです。フォントバイトの読み込みや既存 PDF ランの書き換えは行いません。

## 編集可能な PDF テキストにフォントを設定する

テキスト挿入時に `fontFamily` を渡すか、PDF Facade で編集可能なテキストボックスを更新します。

```ts
const page = univerAPI.getActivePdf()?.getPageByIndex(0)
const textBox = page?.insertTextBox({
  text: 'Hello PDF',
  fontFamily: 'Inter',
  fontSize: 14,
  left: 36,
  top: 36,
})

textBox?.setTextStyle({ fontFamily: 'Noto Serif' })
```

`page.getTextSpans()` が返すインポート済みネイティブテキストはスナップショットであり、その場ではスタイルを変更できません。`replaceText(...)` で編集可能なテキストボックスへ昇格してから `setTextStyle` を呼び出してください。
