PDFテキストとエディタのフォントメニューは、関連する2つの異なるソースを描画します。

| データソース | 制御する内容 |
| --- | --- |
| `document.assets.fonts` とテキストランの `fontId` | インポートされたPDFフォントメタデータと、ネイティブコンテンツを再構築するために使用されるリソース。 |
| 編集可能なテキストランの `fontFamily` | 編集可能テキストのレイアウトと描画に使う CSS フォントファミリー。 |
| Univer の共有フォントリスト | PDF 検査器のフォントのドロップダウンに表示されるオプション。 |

共有リストにオプションを追加すると、`document.assets.fonts` にアセットを追加せず、フォントファイルのダウンロードや埋め込みは行いません。

## エディターのフォントリストを設定する

`editor.enabled`が`true`の場合、PDFの検査官は共有された`FontFamilyDropdown`を使用します。ブラウザを初期化する際に、`UniverUIPlugin`にそのリストを設定してください。

`UniverUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | エディターのマウント先となる DOM 要素、またはその ID。 |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | これらのフォントをドロップダウンに追加します。 |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | これらのフォントをドロップダウンに追加します。 |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS で使うフォント名。 |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 表示名または翻訳キー。 |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 分類。`sans-serif`、`serif`、`monospace`、`display`、`handwriting` を指定できます。 |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 既定のフォント一覧を指定した一覧に置き換えます。 |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      {
        value: 'Inter',
        label: 'Inter',
        category: FontCategory.SANS_SERIF,
      },
      {
        value: 'Noto Serif',
        label: 'Noto Serif',
        category: FontCategory.SERIF,
      },
    ],
    override: false,
  },
})
```

`@font-face`またはスタイルシートを介して各ブラウザフォントをロードします。 それ以外のキャンバスは、ブラウザのフォールバックフォントを使用します。

## 実行時に選択肢を追加する

UIファサードが読み込まれた後、`addFonts`と同じ共有リストに選択肢を追加します。

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  {
    value: 'Inter',
    label: 'Inter',
    category: FontCategory.SANS_SERIF,
  },
])
```

アプリケーションフォントリストを更新するだけです。 既存の PDF が実行されているフォントバイトや書き換えをロードしません。

## 編集可能な PDF テキストにフォントを設定する

`fontFamily`をテキストを差し込むか、PDFファサードを通して編集可能なテキスト ボックスを更新して下さい:

```ts
const page = univerAPI.getActivePdf()?.getPageByIndex(0)
const textBox = page?.insertTextBox({
  text: 'Hello PDF',
  fontFamily: 'Inter',
  fontSize: 14,
  left: 36,
  top: 36,
})

textBox?.setTextStyle({ fontFamily: 'Noto Serif' })
```

`page.getTextSpans()`で返されたネイティブインポートされたテキストはスナップショットなので、そのスタイルは代わりに変更できません。 `replaceText(...)`を最初に呼び出して、編集可能なテキストボックスに変換し、`setTextStyle`を呼び出す。
