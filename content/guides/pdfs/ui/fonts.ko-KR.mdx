PDF 텍스트와 편집기 글꼴 메뉴는 두 개의 관련되었지만 명백한 소스에 그려집니다.

| 원본 | 제어하는 내용 |
| --- | --- |
| `document.assets.fonts`와 텍스트 런의 `fontId` | PDF 글꼴 메타데이터를 가져오고 기본 콘텐츠를 재구성하는 데 사용되는 리소스. |
| 편집 가능한 텍스트 런의 `fontFamily` | 편집 가능한 텍스트의 레이아웃과 렌더링에 사용하는 CSS 글꼴 패밀리. |
| Univer 공유 글꼴 목록 | PDF 검사기의 글꼴 드롭다운에 표시된 옵션. |

공유 목록에 옵션을 추가하면 `document.assets.fonts`에 자산을 추가하지 않으며 글꼴 파일을 다운로드하거나 삽입하지 않습니다.

## 편집기 글꼴 목록 설정

`editor.enabled`가 `true`일 때, PDF 검사기는 공유 `FontFamilyDropdown`를 사용합니다. 브라우저 초기화시 `UniverUIPlugin`에 해당 목록을 구성합니다.

`UniverUIPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | 편집기를 마운트할 DOM 요소 또는 해당 요소의 ID입니다. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | 이 글꼴을 드롭다운에 추가합니다. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | 이 글꼴을 드롭다운에 추가합니다. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | CSS에서 사용하는 글꼴 이름입니다. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | 표시 이름 또는 번역 키입니다. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | 글꼴 분류입니다. `sans-serif`, `serif`, `monospace`, `display`, `handwriting`을 사용할 수 있습니다. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | 기본 글꼴 목록을 지정한 목록으로 바꿉니다. |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
      { value: 'Noto Serif', label: 'Noto Serif', category: FontCategory.SERIF },
    ],
    override: false,
  },
})
```

`@font-face` 또는 스타일 시트를 통해 각 브라우저 글꼴을로드하십시오. 그렇지 않으면 캔버스는 브라우저의 fallback 글꼴을 사용합니다.

## 런타임에 옵션 추가

UI Facade가 로드 된 후 `addFonts`와 동일한 공유 목록에 추가 선택을 추가하십시오.

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
])
```

이 응용 글꼴 목록을 업데이트합니다. 그것은 글꼴 바이트를로드하지 않거나 기존 PDF 실행을 다시 작성하지 않습니다.

## 편집 가능한 PDF 텍스트에 글꼴 적용

텍스트를 삽입하거나 PDF Facade를 통해 편집 가능한 텍스트 상자를 업데이트 할 때 `fontFamily`를 통과하십시오.

```ts
const page = univerAPI.getActivePdf()?.getPageByIndex(0)
const textBox = page?.insertTextBox({
  text: 'Hello PDF',
  fontFamily: 'Inter',
  fontSize: 14,
  left: 36,
  top: 36,
})

textBox?.setTextStyle({ fontFamily: 'Noto Serif' })
```

`page.getTextSpans()`에 의해 반환된 Native 가져온 텍스트는 스냅 샷이므로 스타일은 장소에서 변경 될 수 없습니다. `replaceText(...)`를 먼저 호출하여 편집 가능한 텍스트 상자에 변환 한 다음 `setTextStyle`로 전화하십시오.
