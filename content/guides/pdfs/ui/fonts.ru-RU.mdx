Текст PDF и меню шрифта редактора опираются на два связанных, но разных источника.

| Источник | Что он определяет |
| --- | --- |
| `document.assets.fonts` и `fontId` текстового фрагмента | Импортированные метаданные шрифта PDF и ресурсы, используемые для реконструкции нативного контента. |
| `fontFamily` редактируемого фрагмента | CSS-семейство для компоновки и отрисовки редактируемого текста. |
| Общий список шрифтов Univer | Варианты, показанные в раскрывающемся шрифте инспектора PDF. |

Добавление опции в общий список не добавляет актив в `document.assets.fonts` и не загружает и не встраивает файл шрифта.

## Настройка списка редактора

Когда `editor.enabled` является `true`, PDF-инспектор использует общий `FontFamilyDropdown`. Настройте этот список на `UniverUIPlugin` при инициализации браузера:

`UniverUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | DOM-элемент для размещения редактора или его идентификатор. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Добавляет эти шрифты в выпадающий. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Добавляет эти шрифты в выпадающий. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Имя шрифта в CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Отображаемое имя или ключ перевода. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Группа шрифтов: `sans-serif`, `serif`, `monospace`, `display` или `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Заменяет встроенный список указанными шрифтами. |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
      { value: 'Noto Serif', label: 'Noto Serif', category: FontCategory.SERIF },
    ],
    override: false,
  },
})
```

Загрузите каждый шрифт браузера через `@font-face` или таблицу стилей. В противном случае Canvas использует резервный шрифт браузера.

## Добавление вариантов во время выполнения

После загрузки UI Facade добавьте варианты в тот же общий список с `addFonts`:

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
])
```

Это только обновляет список шрифтов приложений. Он не загружает байты шрифтов или не переписывает существующие PDF-запуски.

## Применение шрифта к редактируемому тексту PDF

Перейдите `fontFamily` при вставке текста или обновите редактируемый текстовый блок через PDF-фасад:

```ts
const page = univerAPI.getActivePdf()?.getPageByIndex(0)
const textBox = page?.insertTextBox({
  text: 'Hello PDF',
  fontFamily: 'Inter',
  fontSize: 14,
  left: 36,
  top: 36,
})

textBox?.setTextStyle({ fontFamily: 'Noto Serif' })
```

Нативный импортированный текст, возвращенный `page.getTextSpans()`, представляет собой снимок, поэтому его стиль не может быть изменен на месте. Позвоните `replaceText(...)` сначала, чтобы преобразовать его в редактируемый текстовый ящик, а затем позвоните в `setTextStyle`.
