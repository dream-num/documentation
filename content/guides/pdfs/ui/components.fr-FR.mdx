`UniverPdfsUIPlugin` assemble l'interface PDF à partir de pièces standard Univer.

| Mode | Composants montés par le plugin PDF UI |
| --- | --- |
| `editor.enabled: false` | Une vue de page en lecture seule unique, continue et virtualisée dans la zone de contenu. |
| `editor.enabled: true` | Rail de miniatures dans la barre latérale gauche, canevas PDF, pied de page PDF, ruban et éléments de menu contextuel, inspecteur des propriétés, intégration de presse-papiers, commandes d'insertion et composants de menus uniquement pour l'éditeur. |

La configuration de `editor.enabled` à `false` monte la vue en lecture seule et supprime toutes les parties réservées à l'éditeur, y compris le rail de miniatures, le pied de page, le ruban, l'inspecteur et l'action d'impression. Le plugin mobile monte en plus une barre supérieure mobile et une disposition de menus mobile.

## Limite des composants PDF

Les vues React et les identificateurs de composants derrière la toile PDF, le rail miniature, le pied de page, l'inspecteur, le sélecteur de table et l'étiquette en mode outil sont des détails d'implémentation internes. Ils ne sont pas exportés à partir de l'entrée racine `@univerjs-pro/pdfs-ui`, et ils ne sont pas pris en charge fentes de remplacement.

Ne pas déduire ou copier une clé de composant interne pour remplacer ces vues par `univerAPI.registerComponent`. Pour le comportement PDF supporté, utilisez le [PDF Guide Facade](/guides/pdfs/getting-started/facade) .

## Ajouter une interface applicative à côté d’un PDF

L'interface utilisateur partagée Facade peut encore enregistrer un composant d'application et l'afficher dans une barre latérale ou une boîte de dialogue Univer régulière. Cela étend l'application environnante et ne remplace pas un composant du plugin PDF.

```tsx
const registration = univerAPI.registerComponent(
  'pdf-help-panel',
  () => <div>PDF workflow help</div>,
)

const sidebar = univerAPI.openSidebar({
  id: 'pdf-help',
  header: { title: 'PDF help' },
  children: { label: 'pdf-help-panel' },
  width: 320,
})

// Lorsque l’extension n’est plus nécessaire :
sidebar.dispose()
registration.dispose()
```

Enregistrez le composant après le chargement de la Facade UI et libérez les deux handles lors du retrait de l’extension.
