`@univerjs-pro/pdfs-ui` монтирует PDF-юниты в стандартной рабочей области Univer и лицензируется в составе Univer Office SDK.

## Ответственность пакетов

| Пакет | Ответственность |
| --- | --- |
| `@univerjs-pro/pdfs` | Регистрирует юнит `UNIVER_PDF`, модель документа и сохраняемые PDF-команды. |
| `@univerjs-pro/pdfs-ui` | Монтирует браузерный холст, панель миниатюр и нижнюю панель. Локальные средства редактирования включены по умолчанию. |
| `@univerjs-pro/pdfs-editor` | Объявляет зависимости редактора для совместной работы. Он не монтирует интерфейс PDF и не управляет `editor.enabled`. |

`UniverPdfsUIPlugin` зависит от `UniverLicensePlugin` и `UniverPdfsPlugin`. Сначала завершите лицензированную базовую настройку PDF, затем зарегистрируйте UI-плагин.

## Регистрация UI-плагина

`UniverPdfsUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | Включает интерфейс редактирования. Укажите `false` для просмотра. |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | Включает интерфейс редактирования. Укажите `false` для просмотра. |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | Создаёт миниатюры в Worker браузера. |

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIRuRU from '@univerjs-pro/pdfs-ui/locale/ru-RU'
import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin)
```

Добавьте `PdfsUIRuRU` к локалям, передаваемым в `new Univer(...)`. Этот пакет локализует ленту PDF, инспектор, контекстные меню и панель страниц.

## Режимы просмотра и редактирования

Плагин всегда монтирует панель миниатюр страниц, холст PDF и нижнюю панель. Редактирование включено по умолчанию и дополнительно регистрирует ленту, контекстные меню, инспектор, буфер обмена, команды вставки, действия и контроллеры редактирования.

Если приложение не должно показывать элементы редактирования, включите режим только для просмотра:

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

Параметр меняет только смонтированный интерфейс, а также контроллеры и службы, предназначенные для редактирования. Это не политика доступа, и он не изменяет сохранённый снимок PDF.

## Воркер миниатюр

`thumbnailWorkerURL` принимает строку, `URL` или существующий `Worker`. Указанный модуль должен запустить экспортируемую среду воркера:

```ts title="pdf-thumbnail-worker.ts"
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

Воркер должен работать в выделенной области Worker. Если он не настроен, в браузере нет необходимых API или страница требует ресурс только главного потока, миниатюры отрисовываются в главном потоке.

## Граница публичного API

Интерфейс вызывает PDF-команды и службы внутри пакета. Наличие кнопки на ленте не означает существование одноимённого публичного метода. Для поддерживаемого программного редактирования используйте [руководство по PDF Facade](/guides/pdfs/getting-started/facade), для преобразования — [Импорт и экспорт](/guides/pdfs/features/import-export), а для печати из браузера — [Печать](/guides/pdfs/features/print).

## Порядок меню и сеточная раскладка [#menu-configuration]

При запуске задайте порядок и позиции в [настройках меню](/guides/pdfs/features/core#menu-order-and-grid-layout). Для изменения готового меню используйте [Facade API меню](/guides/pdfs/features/core#menu-facade).
