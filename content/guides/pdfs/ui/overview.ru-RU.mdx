## Система дизайна

Система дизайна Univer построена на Tailwind CSS и содержит набор дизайн-токенов, которые повторно используются движком отрисовки. Это обеспечивает единообразие стилей между движком отрисовки и слоем представления. Чтобы настроить стили приложения, можно изменить эти токены, хранящиеся в пакете `@univerjs/themes`.



## Компоненты

Univer использует компоненты React для построения слоя представления, поэтому разработчикам, которые также работают с React, очень просто использовать компоненты Univer или регистрировать собственные. При этом пользовательские компоненты не обязательно создавать только на React: Univer поддерживает и другие технологии, например Vue версии 3.x и Web Components.

Все базовые компоненты находятся в пакете `@univerjs/design`, а компоненты значков — в пакете `@univerjs/icons`. Их также можно использовать независимо от Univer.

Пользовательские компоненты часто применяются в следующих случаях:

- Добавление пользовательских кнопок в Ribbon / Context Menu
- Интеграция пользовательских компонентов в Sidebar / Popup и другие элементы
- Замена встроенных компонентов

В следующих главах подробно описано, как регистрировать и использовать пользовательские компоненты.


`@univerjs-pro/pdfs-ui` отрисовывает модули `UNIVER_PDF` в браузере. Пакет предоставляет холст непрерывных страниц, миниатюры и организатор страниц, режимы выделения и редактирования, поиск, команды ленты и контекстного меню, элементы управления инспектора, а также службы времени выполнения для изображений и печати.

## Регистрация плагина интерфейса

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'

import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: true },
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

Объедините `PdfsUIEnUS` с общими пакетами локалей дизайна и интерфейса, передаваемыми в `new Univer(...)`.

## Режим только для просмотра

Редактирование включено по умолчанию. Отключите контроллеры редактора, сохранив холст PDF и интерфейс просмотра:

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

Эта конфигурация управляет интерфейсом и локальными службами редактора. Она не изменяет сохранённый снимок PDF и не предоставляет контроль доступа на уровне приложения.

## Воркер миниатюр

`thumbnailWorkerURL` принимает строку, объект `URL` или существующий `Worker`. Модуль воркера должен запустить экспортированную среду выполнения миниатюр PDF:

```ts title="pdf-thumbnail-worker.ts"
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

Укажите собранный модуль воркера в конфигурации плагина. Если совместимый воркер не настроен, миниатюры отрисовываются средствами основного потока.

Путь воркера является ресурсом приложения, поэтому его итоговый URL зависит от сборщика и базового пути развёртывания.

## Возможности интерфейса и API фасада

Интерфейс включает инструменты для организации страниц, поиска, выделения, редактирования нативного текста, текстовых полей, абзацев, списков, таблиц, изображений, разделителей, аннотаций, а также отмены и повтора. Эти действия интерфейса используют внутренние команды PDF и службы времени выполнения.

Не делайте вывод о наличии публичного метода фасада только по наличию кнопки на ленте. Поддерживаемые программные API перечислены в [справочнике по фасаду PDF](/reference/facade/pdf), методы Exchange описаны в разделе [Импорт и экспорт](/guides/pdfs/features/import-export), а браузерное меню печати — в разделе [Печать](/guides/pdfs/features/print).
