`@univerjs-pro/pdfs-ui` монтирует PDF-юниты в стандартной рабочей области Univer и лицензируется в составе Univer Office SDK.

## Ответственность пакетов

| Пакет | Ответственность |
| --- | --- |
| `@univerjs-pro/pdfs` | Регистрирует блок `UNIVER_PDF`, модель документа и прочные команды PDF. |
| `@univerjs-pro/pdfs-ui` | Монтирует холст браузера, эскизный рельс и нижний колонтитул; локальные элементы управления редактированием включены по умолчанию. |
| `@univerjs-pro/pdfs-editor` | Объявляет зависимости редактора от стороны совместной работы. Он не монтирует интерфейс PDF и не контролирует `editor.enabled`. |

`UniverPdfsUIPlugin` зависит от `UniverLicensePlugin` и `UniverPdfsPlugin`, поэтому заполните лицензированную настройку PDF перед регистрацией плагина пользовательского интерфейса.

## Регистрация UI-плагина

`UniverPdfsUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | Настройки редактора PDF. |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | Значение `false` открывает PDF только для чтения. |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | Создаёт миниатюры в Worker браузера. |

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIRuRU from '@univerjs-pro/pdfs-ui/locale/ru-RU'
import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin)
```

Объедините `PdfsUIEnUS` в области, переданные `new Univer(...)`. Пакет locale переводит ленту, специфичную для PDF, инспектора, контекст-меню и метки Page-rail.

## Режимы просмотра и редактирования

При включенном редактировании плагин монтирует рельс для миниатюр страницы, холст PDF и нижний колонтитул, а также дополнительно регистрирует ленту, контекстные меню, инспектор, буфер обмена, команды вставки и действия редактирования и контроллеры.

Если приложение не должно показывать элементы редактирования, включите режим только для просмотра:

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

С `editor: { enabled: false }` плагин монтирует только непрерывное виртуализированное представление страниц в режиме только для чтения. Панель миниатюр, нижний колонтитул, лента и инспектор не регистрируются, поэтому навигация по миниатюрам, элементы управления страницами в нижнем колонтитуле, меню масштабирования и действие печати недоступны из UI. Эта опция изменяет установленный пользовательский интерфейс, а также контроллеры и сервисы для редактирования. Эта настройка не изменяет сохраненный снимок PDF.

## Мобильная раскладка

Мобильный плагин заменяет части настольной рабочей панели, а не оборачивает их. Он открывается на сетке предварительного просмотра страниц. Коснитесь страницы, чтобы отредактировать ее, а в верхней панели доступны отмена, переделка и действия со страницами. Выбор содержимого открывает плавающую панель инструментов для форматирования и редактирования, а раскладка только для чтения предлагает количество страниц и масштаб.

Регистрируйте действия расширения с помощью экспортируемых позиций: `PDF_MOBILE_VIEWER_MENU_POSITION` для раскладки просмотра и редактирования или `PDF_MOBILE_EDITOR_MENU_POSITION` только для редактирования.

## Воркер миниатюр

`thumbnailWorkerURL` принимает строку, `URL` или существующий `Worker`. Указанный модуль должен запустить экспортируемую среду воркера:

```ts title="pdf-thumbnail-worker.ts"
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

Рабочему требуется выделенный рабочий объем. Если ни один рабочий не настроен, браузеру не хватает требуемых API, или страница зависит от ресурса, который может предоставить только основной поток, миниатюры отображаются на основном потоке.

## Граница публичного API

UI вызывает команды PDF и службы внутри. Кнопка ленты не подразумевает подходящего публичного метода. Для поддерживаемого программного редактирования используйте [PDF Facade Руководство](/guides/pdfs/getting-started/facade); для преобразования используйте [Импорт и экспорт](/guides/pdfs/features/import-export), для печати браузера используйте [Печать](/guides/pdfs/features/print).
