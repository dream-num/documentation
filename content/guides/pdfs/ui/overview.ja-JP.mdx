`@univerjs-pro/pdfs-ui` は PDF ユニットを Univer の標準ワークベンチにマウントし、Univer Office SDK のライセンスで提供されます。

## パッケージの責務

| パッケージ | 責務 |
| --- | --- |
| `@univerjs-pro/pdfs` | `UNIVER_PDF`ユニット、ドキュメントモデル、耐久性のあるPDFコマンドを登録します。 |
| `@univerjs-pro/pdfs-ui` | ブラウザのキャンバス、サムネイルレール、フッターをマウントします。ローカル編集コントロールはデフォルトで有効です。 |
| `@univerjs-pro/pdfs-editor` | エディタの依存関係をコラボレーション側で宣言します。PDF UI をマウントせず、`editor.enabled` を制御しません。 |

`UniverPdfsUIPlugin`は`UniverLicensePlugin`と`UniverPdfsPlugin`に依存しているため、UIプラグインを登録する前にライセンス済みのPDF設定を完了します。

## UI プラグインの登録

`UniverPdfsUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | PDF エディターの設定。 |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | `false` にすると PDF は読み取り専用になります。 |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | ブラウザーの Worker でサムネイルを生成します。 |

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIJaJP from '@univerjs-pro/pdfs-ui/locale/ja-JP'
import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin)
```

`PdfsUIEnUS`を`new Univer(...)`に渡るロケールにマージします。ローカライズパックは、PDF固有のリボン、検査装置、コンテクストメニュー、およびページレールラベルを翻訳します。

## ビューアーモードと編集モード

編集を有効にすると、プラグインはページサムネイルレール、PDF キャンバス、フッターをマウントし、さらにリボン、コンテキストメニュー、インスペクター、クリップボード、挿入コマンド、編集アクションとコントローラーを登録します。

表示専用にする場合は編集コントロールを無効にします。

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

`editor: { enabled: false }` の場合、プラグインは連続した仮想化された読み取り専用のページビューのみをマウントします。サムネイルレール、フッター、リボン、インスペクターは登録されないため、サムネイルナビゲーション、フッターのページコントロール、ズームメニュー、印刷アクションは UI から利用できません。このオプションは、マウントされた UI と編集固有のコントローラーとサービスを変更します。保存された PDF スナップショットを変更しません。

## モバイルレイアウト

モバイルプラグインは、デスクトップのワークベンチ部品をラップするのではなく置き換えます。ページプレビューのグリッドで開き、ページをタップして編集します。元に戻す・やり直す、ページ操作はヘッダーから行います。コンテンツを選択すると、書式設定と編集用のフローティングツールバーが開きます。読み取り専用レイアウトでは、ページ数とズームを利用できます。

拡張アクションは、エクスポートされた位置（表示と編集のレイアウトには `PDF_MOBILE_VIEWER_MENU_POSITION`、編集のみには `PDF_MOBILE_EDITOR_MENU_POSITION`）で登録します。

## サムネイル Worker

`thumbnailWorkerURL` には文字列、`URL`、既存の `Worker` を指定できます。対象モジュールで、パッケージが公開する Worker ランタイムを起動します。

```ts title="pdf-thumbnail-worker.ts"
import { UniverPdfsUIWorkerPlugin } from '@univerjs-pro/pdfs-ui/worker'
import { Univer } from '@univerjs/core'

const univer = new Univer()
univer.registerPlugin(UniverPdfsUIWorkerPlugin)
```

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

ワーカーには専用のワーカースコープが必要です。ワーカーが設定されていない場合、ブラウザは必要なAPIを欠くか、またはページはメインスレッドのみが提供するリソースに依存し、メインスレッドでサムネイルがレンダリングされます。

## 公開 API の境界

UI は PDF コマンドとサービスを内部で呼びます。リボンボタンはマッチするパブリックメソッドではありません。サポートされているプログラマティック編集では、[PDFファサードガイド](/guides/pdfs/getting-started/facade) を使用します。変換には、[輸入および輸出](/guides/pdfs/features/import-export) を使用します。ブラウザの印刷には、[プリントアウト](/guides/pdfs/features/print) を使用します。

## メニューの順序とグリッドレイアウト [#menu-configuration]

スタートアップでは、[メニュー設定](/guides/pdfs/features/core#menu-order-and-grid-layout) で注文とグリッド配置を設定します。既存のメニューを変更するには、[メニュー Facade API](/guides/pdfs/features/core#menu-facade)を使用します。
