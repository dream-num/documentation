`@univerjs-pro/pdfs-ui` は、ブラウザー内で `UNIVER_PDF` ユニットをレンダリングします。連続ページ Canvas、ページサムネイルとオーガナイザー、選択モードと編集モード、検索、リボンとコンテキストメニューの操作、インスペクターコントロール、画像と印刷に使用するランタイムサービスを提供します。

## UI プラグインを登録する

```ts
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'

import '@univerjs-pro/pdfs-ui/lib/index.css'

univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: true },
  thumbnailWorkerURL: new URL('./pdf-thumbnail-worker.js', import.meta.url),
})
```

`PdfsUIEnUS` を、`new Univer(...)` に渡す共通の Design および UI ロケールパックと統合します。

## 閲覧専用モード

編集はデフォルトで有効です。PDF Canvas と閲覧 UI を維持したままエディターコントローラーを無効にできます。

```ts
univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: false },
})
```

この構成は UI とローカルエディターサービスを制御します。永続化された PDF スナップショットは変更せず、アプリケーションレベルのアクセス制御を付与するものでもありません。

## サムネイル Worker

`thumbnailWorkerURL` には、文字列、`URL`、または既存の `Worker` を指定できます。Worker モジュールでは、エクスポートされた PDF サムネイルランタイムを起動する必要があります。

```ts title="pdf-thumbnail-worker.ts"
import { startPdfPageThumbnailWorker } from '@univerjs-pro/pdfs-ui'

startPdfPageThumbnailWorker()
```

プラグイン構成から、ビルド済みの Worker モジュールを参照します。互換性のある Worker が構成されていない場合、サムネイルのレンダリングはメインスレッドのレンダラーにフォールバックします。

Worker のパスはアプリケーションアセットであるため、最終的な URL はバンドラーとデプロイのベースパスによって決まります。

## UI 機能と Facade API

UI には、ページ整理、検索、選択、ネイティブテキスト編集、テキストボックス、段落、リスト、テーブル、画像、区切り線、注釈、元に戻す操作とやり直し操作のためのツールが含まれます。これらの UI 操作は、内部で PDF コマンドとランタイムサービスを使用します。

リボンボタンが存在するだけで公開 Facade メソッドがあると判断しないでください。サポートされるプログラム API については [PDF Facade リファレンス](/reference/facade/pdf)、Exchange メソッドについては[インポートとエクスポート](/guides/pdfs/features/import-export)、ブラウザー印刷メニューについては[印刷](/guides/pdfs/features/print)を参照してください。
