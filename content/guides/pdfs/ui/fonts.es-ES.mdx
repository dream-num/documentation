Texto PDF y el menú de fuentes del editor dibujan en dos fuentes relacionadas pero distintas.

| Fuente | Qué controla |
| --- | --- |
| `document.assets.fonts` y el `fontId` de un fragmento | Metadatos de fuentes PDF importados y los recursos utilizados para reconstruir contenido nativo. |
| `fontFamily` de un fragmento editable | La familia CSS utilizada para componer y renderizar texto editable. |
| La lista de fuentes compartida de Univer | Las opciones que se muestran en el desplegable de fuentes del inspector PDF. |

Agregar una opción a la lista compartida no añade un activo a `document.assets.fonts`, y no descarga ni incrusta un archivo de fuente.

## Configurar la lista del editor

Cuando `editor.enabled` es `true`, el inspector PDF utiliza el `FontFamilyDropdown` compartido. Configurar la lista en `UniverUIPlugin` al iniciar el navegador:

`UniverUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `container` | `string \| HTMLElement` |  | Elemento DOM donde se monta el editor o su ID. |
| <ConfigKey depth={0}>customFontFamily</ConfigKey> | `IFontConfig[] \| object` |  | Añade estas fuentes a la desplegable. |
| <ConfigKey depth={1}>list</ConfigKey> | `IFontConfig[]` |  | Añade estas fuentes a la desplegable. |
| <ConfigKey depth={2}>value</ConfigKey> | `string` |  | Nombre de la fuente en CSS. |
| <ConfigKey depth={2}>label</ConfigKey> | `string` |  | Nombre visible o clave de traducción. |
| <ConfigKey depth={2}>category</ConfigKey> | `FontCategory` |  | Categoría: `sans-serif`, `serif`, `monospace`, `display` o `handwriting`. |
| <ConfigKey depth={1}>override</ConfigKey> | `boolean` | `false` | Sustituye las fuentes integradas por la lista indicada. |

```ts
import { FontCategory, UniverUIPlugin } from '@univerjs/ui'

univer.registerPlugin(UniverUIPlugin, {
  container: 'app',
  customFontFamily: {
    list: [
      { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
      { value: 'Noto Serif', label: 'Noto Serif', category: FontCategory.SERIF },
    ],
    override: false,
  },
})
```

Cargar cada fuente del navegador a través de `@font-face` o una hoja de estilo. De lo contrario Canvas utiliza la fuente de respaldo del navegador.

## Añadir opciones en tiempo de ejecución

Después de que la UI Facade haya cargado, anexar opciones a la misma lista compartida con `addFonts`:

```ts
import { FontCategory } from '@univerjs/ui'

univerAPI.addFonts([
  { value: 'Inter', label: 'Inter', category: FontCategory.SANS_SERIF },
])
```

Esto sólo actualiza la lista de fuentes de aplicación. No carga bytes de fuentes o reescribir las carreras PDF existentes.

## Aplicar una fuente a texto PDF editable

Pase `fontFamily` al insertar texto, o actualice un cuadro de texto editable a través de la Facade PDF:

```ts
const page = univerAPI.getActivePdf()?.getPageByIndex(0)
const textBox = page?.insertTextBox({
  text: 'Hello PDF',
  fontFamily: 'Inter',
  fontSize: 14,
  left: 36,
  top: 36,
})

textBox?.setTextStyle({ fontFamily: 'Noto Serif' })
```

El texto importado nativo devuelto por `page.getTextSpans()` es una instantánea, por lo que su estilo no se puede cambiar en su lugar. Llame a `replaceText(...)` primero para convertirlo en una caja de texto editable, luego llame a `setTextStyle`.
