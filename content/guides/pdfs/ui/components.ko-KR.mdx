`UniverPdfsUIPlugin`는 표준 Univer 작업대 부속에서 PDF 공용영역을 조립합니다.

| 모드 | PDF UI 플러그인이 마운트하는 컴포넌트 |
| --- | --- |
| `editor.enabled: false` | 콘텐츠 영역의 하나의 연속적이고 가상화된 읽기 전용 페이지 뷰. |
| `editor.enabled: true` | 왼쪽 사이드바의 페이지 썸네일 레일, PDF 캔버스, PDF 풋터, 리본 및 컨텍스트-menu 항목, 속성 검사기, 클립보드 통합, 삽입 제어 및 편집기 전용 메뉴 구성 요소. |

`editor.enabled`를 `false`로 설정하면 읽기 전용 뷰를 마운트하고 썸네일 레일, 풋터, 리본, 검사기, 인쇄 작업을 포함한 모든 편집기 전용 부품을 제거합니다. 모바일 플러그인은 모바일 상단 표시줄과 메뉴 레이아웃을 추가로 마운트합니다.

## PDF 컴포넌트 경계

React 전망과 성분 식별자는 PDF 화포, 엄밀한 가로장, footer, inspector, 테이블 피커 및 공구 형태 상표의 내부 실시 세부사항입니다. 그들은 `@univerjs-pro/pdfs-ui` 뿌리 입장에서 수출되지 않으며, 그들은 지원한 보충 구멍이 아닙니다.

`univerAPI.registerComponent`를 통해 이러한 레이아웃을 대체하기 위해 내부 구성 요소 키를 삽입하거나 복사하지 마십시오. 지원되는 PDF 동작을 위해 [PDF의 사전 가이드](/guides/pdfs/getting-started/facade)을 사용하십시오.

## PDF 옆에 애플리케이션 UI 추가

공유 UI Facade는 여전히 애플리케이션 구성 요소를 등록하고 일반 Univer 사이드바 또는 대화 상자에서 표시 할 수 있습니다. 이 주변 응용 프로그램을 확장하고 PDF 플러그인의 구성 요소를 대체하지 않습니다.

```tsx
const registration = univerAPI.registerComponent(
  'pdf-help-panel',
  () => <div>PDF workflow help</div>,
)

const sidebar = univerAPI.openSidebar({
  id: 'pdf-help',
  header: { title: 'PDF help' },
  children: { label: 'pdf-help-panel' },
  width: 320,
})

// 확장이 더 이상 필요하지 않을 때:
sidebar.dispose()
registration.dispose()
```

UI Facade를 로드한 후 컴포넌트를 등록하고 확장을 제거할 때 두 핸들을 모두 해제하세요.
