## Univer PDFs란?

Univer PDFs는 Univer Pro의 PDF 제품입니다. PDF를 정식 `UNIVER_PDF` 유닛으로 표현하고, 가져온 원본 문서를 보존하며, 승인된 편집 내용을 별도의 영속적 편집 레이어에 저장합니다. 브라우저 UI는 두 레이어를 하나의 연속된 문서로 렌더링합니다.

애플리케이션에서 PDF를 만들거나 열고, 편집 가능한 콘텐츠를 추가하고, 가져온 PDF의 충실도를 유지하고, 변경 사항을 공동 편집하고, 결과를 내보내거나 활성 문서를 브라우저 인쇄 워크플로에 전달해야 할 때 Univer PDFs를 사용하세요.

<Callout type="warning" title="플러그인 모드만 지원">
  PDF 프리셋 패키지는 없습니다. PDF 모델, UI, 선택적 기능 플러그인을 명시적으로 등록하세요.
</Callout>


## 브라우저 호환성

Univer는 Chrome 88을 대상으로 컴파일되지만, 이것이 모든 주요 환경을 완벽하게 지원한다는 의미는 아닙니다. Univer가 다음 브라우저 및 Node.js 환경에서 원활하게 작동하도록 최선을 다하고 있습니다.

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer는 `Intl.Segmenter`에 의존합니다. 브라우저 또는 런타임 환경에서 이를 지원하지 않는다면 먼저 해당 polyfill을
  추가하세요. `@formatjs/intl-segmenter` 사용을 권장합니다.
</Callout>

호환성 문제가 발생하면 먼저 적절한 polyfill을 사용해 해결해 보세요. 문제가 계속되면 언제든지 [이슈를 제출해 주세요](https://github.com/dream-num/univer/issues/new/choose).

## Node.js 호환성

<Callout type="warning">
  참고: 이 내용은 Node.js 환경에서 Univer를 실행하는 경우에만 적용되며, Node.js 기반 빌드 도구를 사용해 브라우저에서
  Univer를 실행하는 경우에는 적용되지 않습니다.
</Callout>

Univer는 Node.js 환경에서 실행할 수 있으며 v18.17.0 이상 버전을 지원합니다.


## 패키지 구성

| 패키지                               | 역할                                                                        |
| ------------------------------------ | --------------------------------------------------------------------------- |
| `@univerjs-pro/pdfs`                 | PDF 유닛 모델, 영속적 편집 기본 요소, 스냅샷 계약 및 PDF 퍼사드 진입점      |
| `@univerjs-pro/pdfs-ui`              | 캔버스 렌더러, 연속 페이지 UI, 편집기 컨트롤, 로캘 팩 및 선택적 썸네일 워커 |
| `@univerjs-pro/pdfs-editor`          | 협업이 활성화된 Univer 애플리케이션을 위한 PDF 편집기 수명 주기 통합        |
| `@univerjs-pro/pdfs-exchange-client` | 서버 기반 PDF 가져오기 및 내보내기, 메뉴 통합 및 Exchange 퍼사드 API        |
| `@univerjs-pro/pdfs-print`           | 브라우저 인쇄 메뉴, 인쇄 준비 UI, 스타일 및 로캘 팩                         |

모든 `@univerjs/*` 및 `@univerjs-pro/*` 패키지를 동일한 버전으로 유지하세요.

## 최소 브라우저 설정

로컬 뷰어와 편집기에는 공통 Univer UI, Pro 라이선스, PDF 모델 및 PDF UI 플러그인이 필요합니다.

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import { LocaleType, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import { UniverUIPlugin } from '@univerjs/ui'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {},
})

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Project brief' })
```

가져온 문서를 제공하지 않으면 `createPdf`는 A4 빈 페이지 하나가 있는 PDF를 만듭니다.
