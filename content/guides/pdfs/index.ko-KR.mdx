## Univer PDFs란?

Univer PDF는 Univer Office SDK의 PDF 제품입니다. PDF는 공식 `UNIVER_PDF` 단위가 됩니다: 수입된 근원 문서는 그것으로 보존되고, 받아들여진 편집은 분리한 튼튼한 편집 층에서 저장됩니다. 브라우저 UI는 1개의 지속적인 문서로 층을 둘 다 만듭니다.

Univer PDF는 [Web SDK](/guides/sheets) 내부의 단위 유형입니다, 그것의 자신의 SDK 아닙니다. Web SDK는 구경꾼과 머리없는 내용 처리를 제공합니다. 협업 및 파일 변환은 [Server SDK](/server)의 일부이며, 에이전트 워크플로는 [AI SDK](/ai)에 속합니다.

Univer PDF를 사용하면 응용 프로그램을 만들거나 PDF를 열 필요가 있으며, 편집 가능한 콘텐츠를 추가하고, 수입된 PDF의 모양을 보존하고, 변경 사항을 공유하고, 결과를 내보내거나 브라우저의 인쇄 워크플로우에 열린 문서를 직접 내보내십시오.

<Callout type="warning" title="플러그인 모드만">
  PDF 프리셋 패키지가 없습니다. PDF 모델, UI 및 옵션 기능 플러그인을 명시적으로 등록하십시오.
</Callout>

## 브라우저 호환성

Web SDK는 크롬 88 대상과 컴파일하지만, 모든 주류 환경을 완전히 지원되지 않습니다. Web SDK은 다음과 같은 브라우저와 Node.js 버전에서 올바르게 실행되도록 유지됩니다.

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK는 `Intl.Segmenter`에 달려 있습니다. 브라우저 또는 런타임이 지원되지 않는 경우, polyfill을 먼저 추가하십시오. 추천된 polyfill는 `@formatjs/intl-segmenter`입니다.
</Callout>

호환성 문제가 발생하면 일치하는 polyfill을 먼저 시도하십시오. 문제가 지속되면 [자주 묻는 질문](https://github.com/dream-num/univer/issues/new/choose).

## Node.js 호환성

<Callout type="warning">
  이 Node.js 내부 Web SDK를 실행하는 데에만 적용됩니다. Node.js 기반 빌드 도구를 통해 브라우저에서 Web SDK을 실행하지 않습니다.
</Callout>

Web SDK는 Node.js v18.17.0 이상에서 실행됩니다.

## 주요 기능

- PDF 단위 모델은 소스 문서, 페이지 구조, 자원 및 `IPdfUnitData`에서 튼튼한 편집 의도를 유지합니다.
- 페이지는 탐색 및 삽입 할 수 있으며 텍스트, 목록, 테이블, 이미지, 배당자 및 표기는 편집 할 수 있습니다.
- 브라우저 workbench는 PDF 페이지와 엄지나일을 렌더링하고 선택, 편집 컨트롤, 클립보드 동작 및 검사기 UI를 처리합니다.
- 허용된 변경은 튼튼한 명령과 돌연변이 배치를 통해 이동, 그래서 저장, undo, 및 redo는 동일한 모형에 대하여 운영합니다.
- Facade API는 PDF, 페이지, 요소 및 기본 텍스트 개체를 사용하여 PDF 단위를 작성하고, 찾기, 편집 및 저장합니다.

## 문서 읽는 방법

문서 탐색은 왼쪽에 있습니다. 페이지는 기본에서 고급으로 주문되므로 응용 프로그램을 구축하거나 사용 사례에 건너 뛸 수 있습니다. Univer PDF는 사이드바 상단에서 선택할 수 있습니다.

오른쪽의 내용의 테이블은 현재 페이지의 섹션 사이에 탐색합니다. 다른 페이지를 찾으려면 상단 또는 검색 단축키 (Ctrl + K 또는 Cmd + K)에서 검색 막대를 사용하십시오.

[빠른 시작](/guides/pdfs/getting-started/installation) 가이드로 시작하십시오.

## 사전 지식

문서는 접근 할 수 있지만, Web SDK에 집중할 수 있도록 기본을 가정합니다.

리더는 JavaScript 및 주변 생태계의 기본 이해와 문서에서 가장 많이 얻을 수 있습니다.

Node.js에서 Web SDK를 실행할 계획이라면 Node.js의 기본 이해도 좋습니다.

협업, 공유된 역사, 의견 및 파일 변환은 서버 측 기능입니다. 그들은 백업에 [Univer Server SDK](/server)에서 모듈을 구성함으로써 활성화됩니다; 인증, 권한, 저장 및 배포는 응용 프로그램의 책임에 남아 있습니다. 브라우저에서만 PDF 편집은 아무도 없습니다.
