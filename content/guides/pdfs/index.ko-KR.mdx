## Univer PDFs란?

Univer PDFs는 Univer Pro의 PDF 제품입니다. PDF를 정식 `UNIVER_PDF` 유닛으로 표현하고, 가져온 원본 문서를 보존하며, 승인된 편집 내용을 별도의 영속적 편집 레이어에 저장합니다. 브라우저 UI는 두 레이어를 하나의 연속된 문서로 렌더링합니다.

애플리케이션에서 PDF를 만들거나 열고, 편집 가능한 콘텐츠를 추가하고, 가져온 PDF의 충실도를 유지하고, 변경 사항을 공동 편집하고, 결과를 내보내거나 활성 문서를 브라우저 인쇄 워크플로에 전달해야 할 때 Univer PDFs를 사용하세요.

<Callout type="warning" title="플러그인 모드만 지원">
  PDF 프리셋 패키지는 없습니다. PDF 모델, UI, 선택적 기능 플러그인을 명시적으로 등록하세요.
</Callout>


## 브라우저 호환성

Univer는 Chrome 88을 대상으로 컴파일되지만, 이것이 모든 주요 환경을 완벽하게 지원한다는 의미는 아닙니다. Univer가 다음 브라우저 및 Node.js 환경에서 원활하게 작동하도록 최선을 다하고 있습니다.

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer는 `Intl.Segmenter`에 의존합니다. 브라우저 또는 런타임 환경에서 이를 지원하지 않는다면 먼저 해당 polyfill을
  추가하세요. `@formatjs/intl-segmenter` 사용을 권장합니다.
</Callout>

호환성 문제가 발생하면 먼저 적절한 polyfill을 사용해 해결해 보세요. 문제가 계속되면 언제든지 [이슈를 제출해 주세요](https://github.com/dream-num/univer/issues/new/choose).

## Node.js 호환성

<Callout type="warning">
  참고: 이 내용은 Node.js 환경에서 Univer를 실행하는 경우에만 적용되며, Node.js 기반 빌드 도구를 사용해 브라우저에서
  Univer를 실행하는 경우에는 적용되지 않습니다.
</Callout>

Univer는 Node.js 환경에서 실행할 수 있으며 v18.17.0 이상 버전을 지원합니다.

## 주요 기능

- **PDF Unit 모델**: 원본 문서, 페이지 구조, 리소스 및 영구 편집 의도를 `IPdfUnitData`에 저장합니다.
- **페이지 및 요소 작업**: 페이지 탐색과 삽입은 물론 편집 가능한 텍스트, 목록, 표, 이미지, 구분선 및 주석을 지원합니다.
- **브라우저 워크벤치**: PDF 페이지 렌더링, 미리 보기, 선택, 편집 컨트롤, 클립보드 동작 및 검사기 UI를 제공합니다.
- **명령 파이프라인**: 승인된 변경 사항을 영구 명령과 변형 배치로 적용하여 저장, 실행 취소 및 다시 실행이 하나의 모델을 공유합니다.
- **Facade API**: PDF, 페이지, 요소 및 네이티브 텍스트 객체를 통해 PDF Unit을 생성, 조회, 편집 및 저장합니다.

## 문서 읽는 방법

화면 왼쪽에는 문서 탐색 메뉴가 있습니다. 문서 페이지는 기초부터 고급 내용까지 순서대로 구성되어 있어 애플리케이션을 만들 때 단계별로 따라갈 수 있습니다. 필요에 따라 원하는 순서로 읽거나 사용 사례에 해당하는 페이지로 바로 이동해도 됩니다. 사이드바 상단에서 Univer PDFs를 확인할 수도 있습니다.

화면 오른쪽에는 페이지의 각 섹션으로 쉽게 이동할 수 있는 목차가 있습니다. 페이지를 빠르게 찾으려면 상단 검색창이나 검색 단축키(Ctrl+K 또는 Cmd+K)를 사용하세요.

시작하려면 [빠른 시작](/guides/pdfs/getting-started/quickstart) 가이드를 확인하세요.

## 사전 지식

이 문서는 초보자도 쉽게 읽을 수 있도록 작성했지만, Univer에 집중해 설명하려면 몇 가지 기본 지식이 필요합니다.

문서를 최대한 활용하려면 JavaScript와 관련 생태계에 대한 기본적인 이해가 있는 것이 좋습니다.

Node.js에서 Univer를 실행하려면 Node.js에 대한 기본적인 이해도 필요합니다.

Univer Pro를 사용하고 Univer Server를 배포하려면 Linux, Docker, Docker Compose(또는 Kubernetes)에 대한 기본적인 이해가 있는 것이 좋습니다.
