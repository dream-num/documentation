## Was ist Univer PDFs

Univer PDFs ist das PDF-Produkt in Univer Pro. Es stellt ein PDF als formale `UNIVER_PDF`-Einheit dar, bewahrt das importierte Quelldokument und speichert akzeptierte Bearbeitungen in einer separaten dauerhaften Bearbeitungsebene. Die Browseroberfläche rendert beide Ebenen als ein durchgängiges Dokument.

Verwenden Sie Univer PDFs, wenn eine Anwendung PDFs erstellen oder öffnen, bearbeitbare Inhalte hinzufügen, die Wiedergabetreue importierter PDFs bewahren, gemeinsam an Änderungen arbeiten, das Ergebnis exportieren oder das aktive Dokument an den Druckablauf des Browsers übergeben muss.

<Callout type="warning" title="Nur Plugin-Modus">
  Es gibt kein PDF-Preset-Paket. Registrieren Sie das PDF-Modell, die Benutzeroberfläche und optionale Funktions-Plugins
  ausdrücklich.
</Callout>

## Paketübersicht

| Paket                                | Aufgabe                                                                                                            |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| `@univerjs-pro/pdfs`                 | PDF-Einheitsmodell, dauerhafte Bearbeitungsprimitive, Snapshot-Verträge und PDF-Facade-Einstieg                    |
| `@univerjs-pro/pdfs-ui`              | Canvas-Renderer, fortlaufende Seitenoberfläche, Editorsteuerelemente, Sprachpakete und optionaler Thumbnail-Worker |
| `@univerjs-pro/pdfs-editor`          | Integration des PDF-Editorlebenszyklus für eine Univer-Anwendung mit aktivierter Zusammenarbeit                    |
| `@univerjs-pro/pdfs-exchange-client` | Servergestützter PDF-Import und -Export, Menüintegration und Exchange-Facade-APIs                                  |
| `@univerjs-pro/pdfs-print`           | Browser-Druckmenü, Oberfläche zur Druckvorbereitung, Stile und Sprachpakete                                        |

Verwenden Sie für alle Pakete unter `@univerjs/*` und `@univerjs-pro/*` dieselbe Version.

## Minimale Browser-Einrichtung

Der lokale Betrachter und Editor benötigt die gemeinsame Univer-Benutzeroberfläche, die Pro-Lizenz, das PDF-Modell und das PDF-UI-Plugin.

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import { LocaleType, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import { UniverUIPlugin } from '@univerjs/ui'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {},
})

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Project brief' })
```

`createPdf` erstellt ein leeres PDF mit einer A4-Seite, wenn kein importiertes Dokument angegeben wird.
