## Univer PDFs とは

Univer PDFs は Univer SDK Pro の PDF 製品です。PDF を正式な `UNIVER_PDF` ユニットとして表現し、インポートされたソースドキュメントを保持しながら、確定した編集を独立した永続編集レイヤーに保存します。ブラウザー UI は、両方のレイヤーを一続きのドキュメントとしてレンダリングします。

PDF の作成や表示、編集可能なコンテンツの追加、インポートした PDF の忠実度維持、変更の共同編集、結果のエクスポート、アクティブなドキュメントのブラウザー印刷が必要なアプリケーションで Univer PDFs を使用します。

<Callout type="warning" title="プラグインモードのみ">
  PDF のプリセットパッケージはありません。PDF モデル、UI、必要な機能プラグインを明示的に登録してください。
</Callout>


## ブラウザ互換性

Univer SDK は Chrome 88 をターゲットとしてコンパイルされていますが、これはすべての主流環境を完全にサポートすることを保証するものではありません。Univer SDK が以下のブラウザおよび Node.js 環境で問題なく動作するよう努めています。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK は `Intl.Segmenter`
  に依存しています。お使いのブラウザまたはランタイム環境でこれがサポートされていない場合は、先に対応するポリフィルを追加してください。`@formatjs/intl-segmenter`
  の利用を推奨します。
</Callout>

互換性に関する問題が発生した場合、まずは適切なポリフィルを使用して解決を試みてください。それでも問題が解決しない場合は、[Issue の提出](https://github.com/dream-num/univer/issues/new/choose) をご検討ください。

## Node.js 互換性

<Callout type="注意事項">
  注意：これは Univer SDK を Node.js 環境で実行する場合にのみ適用され、Node.js
  ベースのビルドツールを使ってブラウザで実行する場合には該当しません。
</Callout>

Univer SDK は Node.js 環境でも動作可能で、v18.17.0 以降のバージョンをサポートしています。

## 主な機能

- **PDF Unit モデル**：ソース文書、ページ構造、リソース、永続的な編集内容を `IPdfUnitData` に保存します。
- **ページと要素の操作**：ページの移動と挿入に加え、テキスト、リスト、表、画像、区切り線、注釈を編集できます。
- **ブラウザーワークベンチ**：PDF ページの描画、サムネイル、選択、編集コントロール、クリップボード、インスペクター UI を提供します。
- **コマンドパイプライン**：確定した変更を永続的なコマンドとミューテーションバッチで適用し、保存、元に戻す、やり直しで同じモデルを使用します。
- **Facade API**：PDF、ページ、要素、ネイティブテキストの各オブジェクトから PDF Unit を作成、検索、編集、保存できます。

## ドキュメントの読み方

画面左側にドキュメントのナビゲーションがあります。ページは基礎から応用へ順に構成されているため、その順で進めてもよいですし、必要な章だけを選んで読むこともできます。サイドバー上部で Univer PDFs のドキュメントに切り替えることもできます。

画面右側には現在ページの目次が表示されます。目的のページを素早く見つけたい場合は、上部の検索バーや検索ショートカット（Ctrl+K または Cmd+K）を利用してください。

まずは [クイックスタート](/guides/pdfs/getting-started/quickstart) から始めることをおすすめします。

## 前提知識

ドキュメントは初心者にも分かりやすく設計していますが、Univer SDK に集中できるよう、読み始める前にいくつかの基礎知識があることを前提としています。

効率よく理解するために、JavaScript とそのエコシステムの基本的な理解をおすすめします。

Node.js 上で Univer SDK を動かしたい場合は、Node.js の基礎知識も必要です。

Pro 機能を試したり Univer Server を導入する場合は、Linux、Docker、Docker Compose（または Kubernetes）の基礎知識があるとスムーズです。
