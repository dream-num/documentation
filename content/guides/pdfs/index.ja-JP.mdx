## Univer PDFs とは

Univer PDFはUniver Office SDKのPDF製品です。 PDFは正式な`UNIVER_PDF`ユニットになります。インポートされたソース文書はそのまま保存され、承認された編集は別の耐久性のある編集層に保存されます。 ブラウザUIは、両方のレイヤーを1つの連続文書としてレンダリングします。

Univer PDFは、[Web SDK](/guides/sheets)内のユニットタイプで、独自のSDKではありません。 Web SDKは、ビューアとヘッドレスのコンテンツ処理を提供します。 コラボレーションとファイル変換は、[Server SDK](/server)の一部です。 エージェントワークフローは[AI SDK](/ai)に属しています。

アプリケーションが PDF を作成または開いている必要があるときに Univer PDF を使用して、編集可能なコンテンツを追加し、インポートされた PDF の外観を保存し、変更をコラボレーションし、結果をエクスポートしたり、開いた文書をブラウザのプリントワークフローに転送します。

<Callout type="warning" title="プラグインモードのみ">
  PDF プリセット パッケージはありません。PDF モデル、UI、および任意のオプションの機能プラグインを明示的に登録します。
</Callout>

## ブラウザ互換性

Web SDKは、Chrome 88ターゲットとコンパイルしますが、すべての主流環境が完全にサポートされています。 Web SDK は、次のブラウザとNode.jsバージョンで正しく動作するように維持されます。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK は `Intl.Segmenter` に依存します。ブラウザやランタイムがサポートされていない場合は、最初に polyfill を追加します。推奨される polyfill は `@formatjs/intl-segmenter` です。
</Callout>

互換性の問題が発生した場合は、まずマッチングポリフィルを試してください。問題が主張している場合は、[課題を提出する](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 互換性

<Callout type="warning">
  これは、Node.js内でWeb SDKを実行するためにのみ適用されます。 これは、Node.jsベースのビルドツールを介してブラウザでWeb SDKを実行するカバーしません。
</Callout>

Web SDKはNode.js v18.17.0以降で動作します。

## 主な機能

- PDF ユニットモデルは、ソースコード文書、ページ構造、リソース、および `IPdfUnitData` の耐久性のある編集意図を保持します。
- ページをナビゲートし、入力することができます。テキスト、リスト、テーブル、画像、ディバイダー、アノテーションは編集できます。
- ブラウザのワークベンチは PDF ページとサムネイルをレンダリングし、選択、編集制御、クリップボードの動作、およびインスペクター UI を処理します。
- 受入された変更は、耐久性のあるコマンドと変異のバッチを通過するので、同じモデルに対して保存、保存、削除、および redo が動作する。
- Facade APIは、PDF、ページ、要素、およびネイティブテキストオブジェクトをアプリケーションフェーシングすることで、PDFユニットを作成、検索、編集、および保存します。

## ドキュメントの読み方

ドキュメントのナビゲーションは左にあります。ページは基本から上級まで順に注文されますので、アプリケーションの構築中にシーケンスで読み込むか、ユースケースのセクションにスキップすることができます。 Univer PDFはサイドバーの上部で選択することもできます。

右側のコンテンツの表は、現在のページのセクション間を移動します。別のページを見つけるには、検索バーをトップまたは検索ショートカット(Ctrl + KまたはCmd + K)で使用してください。

[クイックスタート](/guides/pdfs/getting-started/installation)ガイドから始めましょう。

## 前提知識

ドキュメントは近づくように書かれていますが、Web SDKに集中できるようにベースラインを想定しています。

リーダーは、JavaScriptと周囲の生態系の基本的な理解とドキュメントから最も多くを取得します。

Node.jsでWeb SDKを実行しようとすると、Node.jsの基本的な理解も推奨されます。

コラボレーション、共有履歴、コメント、およびファイル変換はサーバー側の機能です。 [Univer Server SDK](/server)からモジュールをバックエンドにコンパイルすることで有効になります。認証、権限、ストレージ、およびデプロイメントは、アプリケーションの責任を負います。 ブラウザでのみ編集されたPDFは、それらのどれも必要です。
