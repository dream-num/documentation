## Univer PDFs とは

Univer PDFs は Univer Pro の PDF 製品です。PDF を正式な `UNIVER_PDF` ユニットとして表現し、インポートされたソースドキュメントを保持しながら、確定した編集を独立した永続編集レイヤーに保存します。ブラウザー UI は、両方のレイヤーを一続きのドキュメントとしてレンダリングします。

PDF の作成や表示、編集可能なコンテンツの追加、インポートした PDF の忠実度維持、変更の共同編集、結果のエクスポート、アクティブなドキュメントのブラウザー印刷が必要なアプリケーションで Univer PDFs を使用します。

<Callout type="warning" title="プラグインモードのみ">
  PDF のプリセットパッケージはありません。PDF モデル、UI、必要な機能プラグインを明示的に登録してください。
</Callout>


## ブラウザ互換性

Univer は Chrome 88 をターゲットとしてコンパイルされていますが、これはすべての主流環境を完全にサポートすることを保証するものではありません。Univer が以下のブラウザおよび Node.js 環境で問題なく動作するよう努めています。

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer は `Intl.Segmenter`
  に依存しています。お使いのブラウザまたはランタイム環境でこれがサポートされていない場合は、先に対応するポリフィルを追加してください。`@formatjs/intl-segmenter`
  の利用を推奨します。
</Callout>

互換性に関する問題が発生した場合、まずは適切なポリフィルを使用して解決を試みてください。それでも問題が解決しない場合は、[Issue の提出](https://github.com/dream-num/univer/issues/new/choose) をご検討ください。

## Node.js 互換性

<Callout type="注意事項">
  注意：これは Univer を Node.js 環境で実行する場合にのみ適用され、Node.js
  ベースのビルドツールを使ってブラウザで実行する場合には該当しません。
</Callout>

Univer は Node.js 環境でも動作可能で、v18.17.0 以降のバージョンをサポートしています。


## パッケージ構成

| パッケージ                           | 役割                                                                                              |
| ------------------------------------ | ------------------------------------------------------------------------------------------------- |
| `@univerjs-pro/pdfs`                 | PDF ユニットモデル、永続編集プリミティブ、スナップショット契約、PDF Facade エントリ               |
| `@univerjs-pro/pdfs-ui`              | Canvas レンダラー、連続ページ UI、エディターコントロール、ロケールパック、任意のサムネイル Worker |
| `@univerjs-pro/pdfs-editor`          | 共同編集対応の Univer アプリケーション向け PDF エディターライフサイクル統合                       |
| `@univerjs-pro/pdfs-exchange-client` | サーバーを利用する PDF のインポートとエクスポート、メニュー統合、Exchange Facade API              |
| `@univerjs-pro/pdfs-print`           | ブラウザー印刷メニュー、印刷準備 UI、スタイル、ロケールパック                                     |

すべての `@univerjs/*` パッケージと `@univerjs-pro/*` パッケージで同じバージョンを使用してください。

## ブラウザーの最小構成

ローカルのビューアーとエディターには、Univer の共通 UI、Pro ライセンス、PDF モデル、PDF UI プラグインが必要です。

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import { LocaleType, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import { UniverUIPlugin } from '@univerjs/ui'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {},
})

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Project brief' })
```

インポートするドキュメントを指定しない場合、`createPdf` は A4 の空白ページを 1 ページ含む PDF を作成します。
