## Что такое Univer PDFs

Univer PDFs является PDF-продуктом в Univer Office SDK. PDF становится формальным `UNIVER_PDF` блоком: импортированный исходный документ сохраняется как был, а принятые правки хранятся в отдельном прочном слое редактирования. Пользовательский интерфейс браузера визуализирует оба слоя как один непрерывный документ.

Univer PDF - это модульный тип внутри [Web SDK](/guides/sheets), а не собственный SDK. Web SDK обеспечивает обработку контента без головы. Сотрудничество и преобразование файлов являются частью [Server SDK](/server) и рабочие процессы агента принадлежат [AI SDK](/ai).

Используйте Univer PDF, когда приложение должно создавать или открывать PDF-файлы, добавлять редактируемый контент, сохранять внешний вид импортированного PDF-файла, сотрудничать с изменениями, экспортировать результат или передавать открытый документ в рабочий процесс печати браузера.

<Callout type="warning" title="Только режим плагина">
  Не существует предустановленного пакета PDF. Вы регистрируете модель PDF, пользовательский интерфейс и любые дополнительные плагины функций явно.
</Callout>

## Совместимость с браузерами

Web SDK компилируется с целью Chrome 88, но это не означает, что все основные среды полностью поддерживаются. Web SDK поддерживается для правильной работы в следующих браузерах и версиях Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK зависит от `Intl.Segmenter`. Если браузер или среда выполнения не поддерживает его, сначала добавьте полифилл. Рекомендуемым полифиллом является `@formatjs/intl-segmenter` .
</Callout>

Когда возникает проблема совместимости, попробуйте сначала сопоставить полифилл. Если проблема сохраняется, [Представить вопрос](https://github.com/dream-num/univer/issues/new/choose).

## Совместимость с Node.js

<Callout type="warning">
  Это относится только к запуску Web SDK внутри Node.js. Он не охватывает запуск Web SDK в браузере через инструмент сборки на основе Node.js.
</Callout>

Web SDK работает в Node.js v18.17.0 и позже.

## Основные возможности

- Модель модуля PDF сохраняет исходный документ, структуру страницы, ресурсы и намерение длительного редактирования в `IPdfUnitData`.
- Страницы можно перемещать и вставлять, а текст, списки, таблицы, изображения, разделители и аннотации можно редактировать.
- Рабочая панель браузера отображает страницы PDF и миниатюры и обрабатывает выбор, управление редактированием, поведение буфера обмена и пользовательский интерфейс инспектора.
- Принятые изменения проходят через прочные команды и партии мутаций, поэтому сохранение, отмена и переделка работают против одной и той же модели.
- Facade API создает, находит, редактирует и сохраняет PDF-единицы через PDF, страницу, элемент и объекты нативного текста.

## Как читать документацию

Навигация по документации находится слева. Страницы заказываются от базовых до расширенных, поэтому их можно читать последовательно при создании приложения или пропускать в разделы, которые требуются в случае использования. Univer PDF также можно выбрать в верхней части боковой панели.

Таблица содержимого справа перемещается между разделами текущей страницы.Чтобы найти другую страницу, используйте строку поиска вверху или ярлык поиска (Ctrl+K или Cmd+K).

Начните с руководства [Быстрый старт](/guides/pdfs/getting-started/installation).

## Необходимые знания

Документация написана, чтобы быть доступной, но она предполагает базовый уровень, чтобы она могла сосредоточиться на Web SDK.

Читатели получают максимальную отдачу от документации с базовым пониманием JavaScript и окружающей экосистемы.

Если вы планируете запустить Web SDK на Node.js, рекомендуется также базовое понимание Node.js.

Сотрудничество, общая история, комментарии и преобразование файлов являются функциями на стороне сервера. Они включаются путем создания модулей из [Univer Server SDK](/server) в бэкэнде; аутентификация, разрешения, хранение и развертывание остаются ответственностью приложения. PDF, отредактированный только в браузере, не требует ни одного из них.
