## Что такое Univer PDFs

Univer PDFs — это продукт Univer Pro для работы с PDF. Он представляет PDF как полноценный модуль `UNIVER_PDF`, сохраняет импортированный исходный документ и записывает принятые правки в отдельный сохраняемый слой. Браузерный интерфейс отображает оба слоя как один непрерывный документ.

Используйте Univer PDFs, если приложению нужно создавать или открывать PDF, добавлять редактируемое содержимое, сохранять точность импортированного PDF, совместно вносить изменения, экспортировать результат или передавать активный документ в браузерный процесс печати.

<Callout type="warning" title="Только режим плагинов">
  Готового пакета настроек PDF нет. Явно зарегистрируйте модель PDF, интерфейс и необязательные плагины функций.
</Callout>


## Совместимость с браузерами

Univer компилируется для Chrome 88, но это не означает полной поддержки всех распространённых сред. Мы стремимся обеспечить стабильную работу Univer в следующих браузерах и средах Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer использует `Intl.Segmenter`. Если ваш браузер или среда выполнения не поддерживает этот API, сначала добавьте
  соответствующий полифил. Мы рекомендуем `@formatjs/intl-segmenter`.
</Callout>

Если возникли проблемы с совместимостью, сначала попробуйте устранить их с помощью подходящих полифилов. Если проблема сохраняется, [создайте issue](https://github.com/dream-num/univer/issues/new/choose).

## Совместимость с Node.js

<Callout type="warning">
  Примечание: это относится только к запуску Univer в среде Node.js и не относится к случаям, когда Univer запускается в
  браузере с помощью инструментов сборки на базе Node.js.
</Callout>

Univer может работать в среде Node.js и поддерживает версии v18.17.0 и выше.


## Обзор пакетов

| Пакет                                | Назначение                                                                                                                      |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `@univerjs-pro/pdfs`                 | Модель модуля PDF, примитивы сохраняемых правок, контракты снимков и точка входа фасада PDF                                     |
| `@univerjs-pro/pdfs-ui`              | Отрисовка холста, интерфейс непрерывных страниц, элементы управления редактора, пакеты локалей и необязательный воркер миниатюр |
| `@univerjs-pro/pdfs-editor`          | Интеграция жизненного цикла редактора PDF в приложение Univer с поддержкой совместной работы                                    |
| `@univerjs-pro/pdfs-exchange-client` | Серверные импорт и экспорт PDF, интеграция меню и API фасада Exchange                                                           |
| `@univerjs-pro/pdfs-print`           | Меню браузерной печати, интерфейс подготовки к печати, стили и пакеты локалей                                                   |

Используйте одну и ту же версию для всех пакетов `@univerjs/*` и `@univerjs-pro/*`.

## Минимальная настройка в браузере

Для локального средства просмотра и редактора нужны общий интерфейс Univer, лицензия Pro, модель PDF и плагин интерфейса PDF.

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import { LocaleType, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import { UniverUIPlugin } from '@univerjs/ui'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {},
})

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Project brief' })
```

Если импортированный документ не задан, `createPdf` создаёт пустой PDF с одной страницей A4.
