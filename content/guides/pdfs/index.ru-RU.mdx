## Что такое Univer PDFs

Univer PDFs — это продукт Univer SDK Pro для работы с PDF. Он представляет PDF как полноценный модуль `UNIVER_PDF`, сохраняет импортированный исходный документ и записывает принятые правки в отдельный сохраняемый слой. Браузерный интерфейс отображает оба слоя как один непрерывный документ.

Используйте Univer PDFs, если приложению нужно создавать или открывать PDF, добавлять редактируемое содержимое, сохранять точность импортированного PDF, совместно вносить изменения, экспортировать результат или передавать активный документ в браузерный процесс печати.

<Callout type="warning" title="Только режим плагинов">
  Готового пакета настроек PDF нет. Явно зарегистрируйте модель PDF, интерфейс и необязательные плагины функций.
</Callout>


## Совместимость с браузерами

Univer SDK компилируется для Chrome 88, но это не означает полной поддержки всех распространённых сред. Мы стремимся обеспечить стабильную работу Univer SDK в следующих браузерах и средах Node.js:

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK использует `Intl.Segmenter`. Если ваш браузер или среда выполнения не поддерживает этот API, сначала добавьте
  соответствующий полифил. Мы рекомендуем `@formatjs/intl-segmenter`.
</Callout>

Если возникли проблемы с совместимостью, сначала попробуйте устранить их с помощью подходящих полифилов. Если проблема сохраняется, [создайте issue](https://github.com/dream-num/univer/issues/new/choose).

## Совместимость с Node.js

<Callout type="warning">
  Примечание: это относится только к запуску Univer SDK в среде Node.js и не относится к случаям, когда Univer SDK запускается в
  браузере с помощью инструментов сборки на базе Node.js.
</Callout>

Univer SDK может работать в среде Node.js и поддерживает версии v18.17.0 и выше.

## Основные возможности

- **Модель PDF Unit**: хранит исходный документ, структуру страниц, ресурсы и постоянные правки в `IPdfUnitData`.
- **Операции со страницами и элементами**: поддерживает навигацию и вставку страниц, а также редактируемый текст, списки, таблицы, изображения, разделители и аннотации.
- **Браузерная рабочая область**: отображает страницы PDF и миниатюры, предоставляет выделение, элементы редактирования, буфер обмена и инспектор.
- **Конвейер команд**: применяет принятые изменения через постоянные команды и пакеты мутаций, чтобы сохранение, отмена и повтор использовали одну модель.
- **Facade API**: создаёт, находит, изменяет и сохраняет PDF Unit через объекты PDF, страниц, элементов и исходного текста.

## Как читать документацию

Слева на экране находится панель навигации по документации. Страницы расположены последовательно — от базовых тем к более сложным, поэтому при создании приложения их можно изучать шаг за шагом. При этом вы можете читать их в любом порядке или сразу переходить к тем страницам, которые относятся к вашему сценарию. В верхней части боковой панели также можно выбрать Univer PDFs.

Справа на экране находится оглавление, с помощью которого удобно переходить между разделами страницы. Чтобы быстро найти нужную страницу, воспользуйтесь строкой поиска вверху или сочетанием клавиш для поиска (Ctrl+K или Cmd+K).

Для начала ознакомьтесь с руководством [«Быстрый старт»](/guides/pdfs/getting-started/quickstart).

## Необходимые знания

Хотя наша документация рассчитана на начинающих, для её ясности и сосредоточенности на Univer SDK мы предполагаем некоторый базовый уровень знаний.

Чтобы получить от документации максимум пользы, рекомендуем знать основы JavaScript и его экосистемы.

Если вы хотите запускать Univer SDK в Node.js, также потребуется базовое понимание Node.js.

Если вы хотите попробовать Univer SDK Pro и развернуть Univer Server, рекомендуем знать основы Linux, Docker и Docker Compose (или Kubernetes).
