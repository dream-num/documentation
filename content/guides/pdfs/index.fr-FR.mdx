## Qu'est-ce qu'Univer PDFs ?

Univer PDFs est le produit PDF d'Univer Pro. Il représente un PDF comme une unité `UNIVER_PDF` formelle, conserve le document source importé et stocke les modifications acceptées dans une couche de modifications persistantes distincte. L'interface du navigateur affiche les deux couches comme un seul document continu.

Utilisez Univer PDFs lorsqu'une application doit créer ou ouvrir des PDF, ajouter du contenu modifiable, préserver la fidélité des PDF importés, collaborer sur les modifications, exporter le résultat ou transmettre le document actif au processus d'impression du navigateur.

<Callout type="warning" title="Mode plugin uniquement">
  Il n'existe aucun package de préréglage PDF. Enregistrez explicitement le modèle PDF, l'interface utilisateur et les
  plugins de fonctionnalités facultatives.
</Callout>


## Compatibilité avec les navigateurs

Univer est compilé avec Chrome 88 comme cible, mais cela ne signifie pas qu’il prend entièrement en charge tous les environnements courants. Nous nous efforçons d’assurer son bon fonctionnement dans les navigateurs et environnements Node.js suivants :

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer s’appuie sur `Intl.Segmenter`. Si votre navigateur ou votre environnement d’exécution ne le prend pas en
  charge, ajoutez d’abord un polyfill adapté. Nous vous recommandons d’utiliser `@formatjs/intl-segmenter`.
</Callout>

Si vous rencontrez des problèmes de compatibilité, essayez d’abord de les résoudre à l’aide des polyfills appropriés. Si le problème persiste, n’hésitez pas à [ouvrir une issue](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilité avec Node.js

<Callout type="warning">
  Remarque : ces informations concernent uniquement l’exécution d’Univer dans un environnement Node.js. Elles ne
  s’appliquent pas lorsqu’Univer s’exécute dans un navigateur avec des outils de build basés sur Node.js.
</Callout>

Univer peut s’exécuter dans un environnement Node.js à partir de la version v18.17.0.


## Vue d'ensemble des packages

| Package                              | Rôle                                                                                                                                  |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| `@univerjs-pro/pdfs`                 | Modèle d'unité PDF, primitives de modification persistante, contrats de snapshot et point d'entrée de la façade PDF                   |
| `@univerjs-pro/pdfs-ui`              | Moteur de rendu du canevas, interface de pages continues, commandes de l'éditeur, packs de locales et worker de miniatures facultatif |
| `@univerjs-pro/pdfs-editor`          | Intégration du cycle de vie de l'éditeur PDF pour une application Univer avec collaboration                                           |
| `@univerjs-pro/pdfs-exchange-client` | Importation et exportation PDF assurées par le serveur, intégration des menus et API de façade Exchange                               |
| `@univerjs-pro/pdfs-print`           | Menu d'impression du navigateur, interface de préparation de l'impression, styles et packs de locales                                 |

Conservez tous les packages `@univerjs/*` et `@univerjs-pro/*` à la même version.

## Configuration minimale dans le navigateur

La visionneuse et l'éditeur locaux nécessitent l'interface partagée d'Univer, la licence Pro, le modèle PDF et le plugin d'interface PDF.

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import { LocaleType, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import { UniverUIPlugin } from '@univerjs/ui'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {},
})

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Project brief' })
```

`createPdf` crée un PDF vide avec une page A4 lorsqu'aucun document importé n'est fourni.
