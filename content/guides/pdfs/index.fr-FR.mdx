## Qu’est-ce qu’Univer PDFs ?

Univer PDFs est le produit PDF d'Univer SDK Pro. Il représente un PDF comme une unité `UNIVER_PDF` formelle, conserve le document source importé et stocke les modifications acceptées dans une couche de modifications persistantes distincte. L'interface du navigateur affiche les deux couches comme un seul document continu.

Utilisez Univer PDFs lorsqu'une application doit créer ou ouvrir des PDF, ajouter du contenu modifiable, préserver la fidélité des PDF importés, collaborer sur les modifications, exporter le résultat ou transmettre le document actif au processus d'impression du navigateur.

<Callout type="warning" title="Mode plugin uniquement">
  Il n'existe aucun package de préréglage PDF. Enregistrez explicitement le modèle PDF, l'interface utilisateur et les
  plugins de fonctionnalités facultatives.
</Callout>


## Compatibilité avec les navigateurs

Univer SDK est compilé avec Chrome 88 comme cible, mais cela ne signifie pas qu’il prend entièrement en charge tous les environnements courants. Nous nous efforçons d’assurer son bon fonctionnement dans les navigateurs et environnements Node.js suivants :

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK s’appuie sur `Intl.Segmenter`. Si votre navigateur ou votre environnement d’exécution ne le prend pas en
  charge, ajoutez d’abord un polyfill adapté. Nous vous recommandons d’utiliser `@formatjs/intl-segmenter`.
</Callout>

Si vous rencontrez des problèmes de compatibilité, essayez d’abord de les résoudre à l’aide des polyfills appropriés. Si le problème persiste, n’hésitez pas à [ouvrir une issue](https://github.com/dream-num/univer/issues/new/choose).

## Compatibilité avec Node.js

<Callout type="warning">
  Remarque : ces informations concernent uniquement l’exécution d’Univer SDK dans un environnement Node.js. Elles ne
  s’appliquent pas lorsqu’Univer SDK s’exécute dans un navigateur avec des outils de build basés sur Node.js.
</Callout>

Univer SDK peut s’exécuter dans un environnement Node.js à partir de la version v18.17.0.

## Points forts

- **Modèle d’unité PDF** : conserve le document source, la structure des pages, les ressources et les intentions de modification persistantes dans `IPdfUnitData`.
- **Opérations sur les pages et les éléments** : prend en charge la navigation et l’insertion de pages ainsi que le texte, les listes, les tableaux, les images, les séparateurs et les annotations modifiables.
- **Espace de travail du navigateur** : fournit l’affichage des pages PDF, les miniatures, la sélection, les commandes d’édition, le presse-papiers et l’inspecteur.
- **Pipeline de commandes** : applique les changements acceptés par des commandes et lots de mutations persistants afin que l’enregistrement, l’annulation et le rétablissement utilisent le même modèle.
- **Facade API** : crée, retrouve, modifie et enregistre les unités PDF au moyen d’objets PDF, page, élément et texte natif.

## Comment lire la documentation

La barre de navigation de la documentation se trouve à gauche de l’écran. Les pages sont classées du niveau débutant au niveau avancé afin que vous puissiez les suivre pas à pas pendant la création de votre application. Vous pouvez cependant les consulter dans l’ordre de votre choix ou accéder directement aux pages correspondant à votre cas d’utilisation. Vous pouvez également sélectionner Univer PDFs en haut de la barre latérale.

À droite de l’écran, une table des matières facilite la navigation entre les différentes sections de la page. Pour trouver rapidement une page, utilisez la barre de recherche située en haut ou le raccourci de recherche (Ctrl+K ou Cmd+K).

Pour commencer, consultez le guide de [démarrage rapide](/guides/pdfs/getting-started/quickstart).

## Connaissances préalables

Bien que notre documentation soit conçue pour les débutants, il nous faut établir quelques prérequis afin qu’elle puisse rester centrée sur Univer SDK.

Pour en tirer pleinement parti, il est recommandé de posséder des notions de base en JavaScript et de connaître son écosystème.

Si vous souhaitez exécuter Univer SDK sur Node.js, des notions de base sur Node.js sont également nécessaires.

Si vous souhaitez essayer Univer SDK Pro et déployer Univer Server, nous vous recommandons de posséder des connaissances de base sur Linux, Docker et Docker Compose (ou Kubernetes).
