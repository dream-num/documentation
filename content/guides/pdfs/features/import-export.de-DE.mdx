PDF-Import und -Export sind servergestützte Konvertierungsabläufe. Sowohl die APIs für gespeicherte Einheiten als auch die Snapshot-APIs benötigen den Univer-Exchange-Dienst; der Snapshot-Pfad entfernt lediglich die Anforderung an Zusammenarbeit und Speicherung.

<Callout type="warning" title="Server erforderlich">
  Konfigurieren Sie einen Univer Pro Server, bevor Sie diese APIs aktivieren. Ohne die Endpunkte für Upload,
  Konvertierung, Aufgaben und signierte Dateien geben die Methoden keine konvertierte Einheit oder Datei zurück.
</Callout>

## Exchange-Plugins registrieren

```package-install
npm install @univerjs-pro/exchange-client @univerjs-pro/pdfs-exchange-client
```

Fügen Sie der Einrichtung aus [Installation und grundlegende Verwendung](/guides/pdfs/getting-started/installation) die Exchange-Sprachpakete und den Stil hinzu:

```ts
import { UniverExchangeClientPlugin } from '@univerjs-pro/exchange-client'
import ExchangeClientEnUS from '@univerjs-pro/exchange-client/locale/en-US'
import { UniverPdfsExchangeClientPlugin } from '@univerjs-pro/pdfs-exchange-client'
import PdfsExchangeClientEnUS from '@univerjs-pro/pdfs-exchange-client/locale/en-US'

import '@univerjs-pro/exchange-client/lib/index.css'

import '@univerjs-pro/exchange-client/facade'
import '@univerjs-pro/pdfs-exchange-client/facade'
```

Führen Sie `ExchangeClientEnUS` und `PdfsExchangeClientEnUS` in dem an `Univer` übergebenen Sprachpaket zusammen. Registrieren Sie anschließend den gemeinsamen Exchange-Client vor dem PDF-Adapter:

```ts
const serverEndpoint = 'https://your-univer-server.example.com'

univer.registerPlugin(UniverExchangeClientPlugin, {
  uploadFileServerUrl: `${serverEndpoint}/universer-api/stream/file/upload`,
  importServerUrl: `${serverEndpoint}/universer-api/exchange/{type}/import`,
  exportServerUrl: `${serverEndpoint}/universer-api/exchange/{type}/export`,
  getTaskServerUrl: `${serverEndpoint}/universer-api/exchange/task/{taskID}`,
  signUrlServerUrl: `${serverEndpoint}/universer-api/file/{fileID}/sign-url`,
  downloadEndpointUrl: serverEndpoint,
})
univer.registerPlugin(UniverPdfsExchangeClientPlugin)
```

Lassen Sie die Endpunktoptionen weg, wenn der Univer-Server über die standardmäßigen Same-Origin-Routen `/universer-api/*` verfügbar ist. Erhöhen Sie `maxTimeoutTime`, wenn die Konvertierung großer PDFs die standardmäßige Zeitüberschreitung der Aufgabe überschreiten kann.

## Datenpfad auswählen

| Pfad         | Speichert eine Servereinheit | Erfordert Zusammenarbeit | Konvertierungsserver |
| ------------ | :--------------------------: | :----------------------: | :------------------: |
| Einheiten-ID |              Ja              |            Ja            |     Erforderlich     |
| Snapshot     |             Nein             |           Nein           |     Erforderlich     |

### In eine gespeicherte Einheit importieren

Die Eingabe kann eine Browser-`File` oder eine URL sein. Laden Sie die zurückgegebene Einheit über den konfigurierten Collaboration-Client.

```ts
const unitId = await univerAPI.importPdfToUnitIdAsync(file)

if (unitId) {
  const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)
  console.log(pdf?.getName())
}
```

### In einen Snapshot importieren

Verwenden Sie den Snapshot-Import für eine lokale PDF-Einheit, die nicht als Teil der Konvertierungsaufgabe gespeichert werden soll:

```ts
const snapshot = await univerAPI.importPdfToSnapshotAsync(file)

if (snapshot) {
  univerAPI.createPdf(snapshot)
}
```

### Exportieren und herunterladen

Exportieren Sie eine gespeicherte Einheit anhand ihrer ID:

```ts
const file = await univerAPI.exportPdfByUnitIdAsync(unitId)

if (file) {
  univerAPI.downloadFile(file, 'project-brief', 'pdf')
}
```

Exportieren Sie den aktuellen lokalen Snapshot, ohne ihn vorher zu speichern:

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  const file = await univerAPI.exportPdfBySnapshotAsync(pdf.save())

  if (file) {
    univerAPI.downloadFile(file, pdf.getName(), 'pdf')
  }
}
```

Diese APIs geben eine `File` zurück. Der Browserdruck ist ein separater Arbeitsablauf, der den Druckdialog des Systems öffnet; siehe [Drucken](/guides/pdfs/features/print).
