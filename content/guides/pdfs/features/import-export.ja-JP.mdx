## 対応形式

以下は本ページのブラウザー API が対応する形式です。Office ファイルの変換には、同じドキュメント種類と形式に対応したバックエンドが必要です。

| インポート | エクスポート |
| --- | --- |
| `.pdf` | `.pdf` |

## データ経路を選択する

| 経路             | サーバーユニットを永続化 | 共同編集が必要 | 変換サーバー |
| ---------------- | :----------------------: | :------------: | :----------: |
| ユニット ID      |           はい           |      はい      |     必須     |
| スナップショット |          いいえ          |     いいえ     |     必須     |

### 永続ユニットとしてインポートする

入力にはブラウザーの `File` または URL を使用できます。返されたユニットは、構成済みの共同編集クライアントを通じて読み込みます。

```ts
const unitId = await univerAPI.importPdfToUnitIdAsync(file)

if (unitId) {
  const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)
  console.log(pdf?.getName())
}
```

### スナップショットとしてインポートする

変換タスクの一部として永続化しないローカル PDF ユニットには、スナップショットのインポートを使用します。

```ts
const snapshot = await univerAPI.importPdfToSnapshotAsync(file)

if (snapshot) {
  univerAPI.createPdf(snapshot)
}
```

### エクスポートしてダウンロードする

永続化されたユニットを ID でエクスポートします。

```ts
const file = await univerAPI.exportPdfByUnitIdAsync(unitId)

if (file) {
  univerAPI.downloadFile(file, 'project-brief', 'pdf')
}
```

現在のローカルスナップショットは、先に永続化せずにエクスポートできます。

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  const file = await univerAPI.exportPdfBySnapshotAsync(pdf.save())

  if (file) {
    univerAPI.downloadFile(file, pdf.getName(), 'pdf')
  }
}
```

これらの API は `File` を返します。ブラウザー印刷はシステムの印刷ダイアログを開く別のワークフローです。[印刷](/guides/pdfs/features/print)を参照してください。
