以下の API は変換バックエンドが必要です。[ファイル交換統合](/server/import-export) からファイルアップロード、変換、タスクのクエリ、ダウンロードを接続し、ブラウザプラグインの設定を行います。スナップショット API は同じバックエンドを使用しますが、共同ドキュメントを必要としません。コラボレーション Exchange の例は、Sheet を記述するため、対象のリリースが必要なファイルタイプをサポートしていることを確認してください。

エクスポートが失敗した場合は、[ライセンスエラーコードとタスクの失敗処理](/server/import-export#export-errors) を参照してください。

## 対応形式

このページでは、ブラウザ API をカバーしています。Office ファイルの変換には、同じドキュメントタイプとフォーマットをサポートするバックエンドが必要です。

| インポート | エクスポート |
| --- | --- |
| `.pdf` | `.pdf` |

これらの API は PDF ファイルをインポートし、エクスポートします。 PDF コンテンツを DOCX、XLSX、または PPTX に変換しません。 ブラウザの印刷は別のワークフローです。

## データ経路を選択する

| 経路             | サーバーユニットを永続化 | 共同編集が必要 | 変換サーバー |
| ---------------- | :----------------------: | :------------: | :----------: |
| ユニット ID      |           はい           |      はい      |     必須     |
| スナップショット |          いいえ          |     いいえ     |     必須     |

### 永続ユニットとしてインポートする

ブラウザの`File`またはURLを渡すと、設定されたコラボレーションクライアントを介して返されたユニットをロードします。

```ts
const unitId = await univerAPI.importPdfToUnitIdAsync(file)

if (unitId) {
  const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)
  console.log(pdf?.getName())
}
```

### スナップショットとしてインポートする

変換タスクが主張しないローカルPDFユニットのスナップショットのインポートを使用する:

```ts
const snapshot = await univerAPI.importPdfToSnapshotAsync(file)

if (snapshot) {
  univerAPI.createPdf(snapshot)
}
```

### エクスポートしてダウンロードする

ID によって永続的なユニットをエクスポート:

```ts
const file = await univerAPI.exportPdfByUnitIdAsync(unitId)

if (file) {
  univerAPI.downloadFile(file, 'project-brief', 'pdf')
}
```

現在のローカルスナップショットは、先に永続化せずにエクスポートできます。

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  const file = await univerAPI.exportPdfBySnapshotAsync(pdf.save())

  if (file) {
    univerAPI.downloadFile(file, pdf.getName(), 'pdf')
  }
}
```

これらの API は `File` を返します。ブラウザでの印刷は、システム印刷ダイアログを開く別のワークフローです。 [プリントアウト](/guides/pdfs/features/print)を参照してください。

### 開いている PDF へのページ追加とエクスポート

Exchange ファサードは、すでに開いている PDF でも動作します。`univerAPI.appendPdfAsync(file, unitId?)` はファイルをインポートし、そのページを指定した PDF（ユニット ID を省略した場合はアクティブな PDF）に追加します。対象がない場合やページを追加できない場合は `false` に解決されます。

`univerAPI.exportPdfAsync(unitId?)` は、キャンバス上で編集中のテキストをコミットして開いているドキュメントをエクスポートするため、ローカルスナップショットの PDF でも永続化されたユニットでも動作します。保留中の編集をコミットできない場合や、ドキュメントが開かれていない場合は `undefined` に解決されます。

```ts
// Append every page of another PDF to the open document.
const appended = await univerAPI.appendPdfAsync(file)

// Export the open PDF, including canvas edits that have not been committed yet.
const exported = await univerAPI.exportPdfAsync()
if (exported) {
  univerAPI.downloadFile(exported, 'project-brief', 'pdf')
}
```

どちらのメソッドも `@univerjs-pro/pdfs-exchange-client/facade` によって `FUniver` に追加されます。すでに保持している `IPdfUnitData` を追加するには、`pdf.appendPdf(snapshot)` を直接呼び出します。詳細は [PDF Facade API](/guides/pdfs/features/core/pdfs-api#append-pages) を参照してください。

## 組み込みのインポート・エクスポートメニューと UI 操作の削除 [#import-export-ui-migration]

<Callout type="warning" title="注意">
  **1.2.0** 以降、Univer の組み込みインポート・エクスポートメニューと UI 操作は削除されました。基盤となるサービスと Facade API は引き続き利用できます。
</Callout>

アプリケーションが既存のインポート/エクスポートメニューとUIインタラクションを維持する必要がある場合は、[組み込みのインポート/エクスポートメニューとUIインタラクションのマイグレーション例](https://office.univer.ai/showcase/pdfs/custom-import-export)は、カスタムプラグインでそれらを復元する方法を示しています。 例には、オンラインで閲覧したり、ダウンロードしたりできるフルソースが含まれています。
