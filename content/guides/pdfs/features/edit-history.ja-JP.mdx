---
title: 編集履歴
icon: 'RotateCcwClock'
---

PDF ユニットは編集中に undo と redo をサポートしていますが、シート、ドキュメント、スライド、ボード、ベース用の専用のバージョン履歴パネルプラグインはありません。 PDF 用の別の製品履歴 UI プラグインを登録しないでください。

## 元に戻す・やり直す

undo と redo は、現在フォーカスしている Univer Unit に適用されます。

```ts
await univerAPI.undo()
await univerAPI.redo()
```

これらの呼び出しは、サーバー側のバージョンリストを作成しず、以前のセッションからバージョンを取得できません。 他の操作については、[一般的な API](/guides/pdfs/features/core/general-api)を参照してください。

## セッションをまたぐバージョン管理

[PDF コラボレーション](/guides/pdfs/features/collaboration) を始めて下さい。 版を長期保つ必要がある適用は [オフィスの履歴サービス](/server/collaboration/extensions)、ターゲット解放が PDF のデータを支えることを確認し、版のリストおよび視聴者を実装します。 一般的な歴史サービスはそれ自体によってPDFの履歴のパネルを加えません。

コンテンツを復元するには、ページ上に表示されたデータを置き換える以上が必要です。 また、ドキュメントの承認、アクティブなコラボレーションセッションとの調整、関連するPDFファイルの保持が必要です。
