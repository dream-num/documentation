PDFs は編集中の元に戻す・やり直す操作に対応しています。現在、Sheets、Docs、Slides、Boards、Bases と同等の専用バージョン履歴パネルプラグインはありません。PDFs に他の製品の History UI プラグインを登録しないでください。

## 元に戻す・やり直す

元に戻す・やり直す操作は、フォーカスされている Univer ユニットに適用されます。

```ts
await univerAPI.undo()
await univerAPI.redo()
```

これらの操作はサーバー側のバージョン一覧を作成せず、以前のセッションのバージョンも取得しません。その他の操作は[汎用 API](/guides/pdfs/features/core/general-api) を参照してください。

## セッションをまたぐバージョン管理

まず [PDFs の共同編集](/guides/pdfs/features/collaboration)を導入します。バージョンを長期間保持するには、[Office 履歴サービス](/server/collaboration/extensions)を参照し、対象リリースで PDF データがサポートされていることを確認したうえで、アプリケーションにバージョン一覧とビューアーを実装してください。汎用 History サービスを追加しても PDF 履歴パネルは自動的に追加されません。

内容の復元には、ドキュメントの認可、アクティブな共同編集セッションとの調整、関連する PDF ファイルの保持が必要です。ページに表示するデータを置き換えるだけでは不十分です。
