Интерфейс PDF предоставляет инструменты редактирования для распространённых браузерных процессов. Код приложения может выполнять такие же сохраняемые изменения модели через `@univerjs-pro/pdfs/facade`.

## Добавление текста и структурированного содержимого

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const paragraph = page.insertParagraph({
  text: 'Release summary',
  left: 36,
  top: 36,
  width: 240,
  height: 72,
  fontSize: 18,
})

paragraph.appendBlock({
  text: 'Approved for publication',
  textStyle: { italic: true },
})

const list = page.insertList({
  text: 'Verify content',
  kind: univerAPI.Enum.PdfListKind.UNORDERED,
  preset: univerAPI.Enum.PdfListPresetId.UNORDERED_DISC,
  left: 36,
  top: 132,
  width: 240,
  height: 108,
})

list.insertItem(1, { text: 'Export final PDF' })
list.insertItem(2, { text: 'Archive source', level: 1 })
```

Уровни списка ограничены диапазоном от `0` до `8`. Для повышения уровня элемента также нужен предшествующий элемент, который может стать его родительским элементом.

## Редактирование таблицы

```ts
const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Owner', 'Status', 'Docs', 'Ready'],
  left: 312,
  top: 36,
  width: 240,
  height: 108,
})

table.resize(3, 2)
table.getCell(2, 0).setText('Legal')
table.getCell(2, 1).setText('Review')
```

Таблица может содержать не более 10,000 ячеек. `getPdfTableThemePresets()` возвращает встроенные описания готовых настроек, которые можно передавать в процессы оформления таблиц.

## Добавление изображений и аннотаций

```ts
const image = await page.insertImageAsync('/assets/signature.png', {
  left: 312,
  top: 180,
  width: 144,
  height: 72,
  opacity: 0.9,
})

image.setRotation(-4).bringToFront()

const highlight = page.insertAnnotation({
  annotationType: univerAPI.Enum.PdfAnnotationType.HIGHLIGHT,
  left: 36,
  top: 264,
  width: 180,
  height: 18,
})

highlight.setStyle({
  fill: { color: '#fde047' },
  opacity: 0.6,
})
```

Вставка через фасад поддерживает аннотации выделения цветом, подчёркивания, зачёркивания, волнистого подчёркивания и рисования от руки. Основное перечисление включает дополнительные подтипы аннотаций PDF, которые не принимаются этим API вставки.

## Замена импортированного текста

Импортированный нативный текст считывается через `getTextSpans()`. Замена диапазона — атомарное повышение: Univer скрывает соответствующую исходную операцию и вставляет редактируемое текстовое поле в сохранённой позиции.

```ts
const matchingSpan = page.getTextSpans().find((span) => span.getText().includes('Draft'))

if (matchingSpan) {
  matchingSpan.replaceText('Final')
}
```

После замены перечислите диапазоны заново: старый дескриптор снимка становится недействительным.

## Преобразование и удаление элементов

Все редактируемые элементы страницы используют общие методы преобразования и управления z-порядком:

```ts
image.setPosition(300, 180).setSize(180, 90).setVisible(true).setLocked(false).sendBackward()

const snapshot = pdf.save()
```

Изменения фасада передаются через команды Univer. Не изменяйте `snapshot.document` или `snapshot.editState` напрямую, пока модуль активен.
