Las API de abajo requieren un backend de conversión. Comience con [integración del intercambio de archivos](/server/import-export) para conectar cargas de archivos, conversión, consultas de tareas y descargas, luego configure los plugins del navegador. Las API de instantáneas utilizan el mismo backend pero no requieren un documento de colaboración. El ejemplo de Exchange muestra hojas, así que confirma que la versión de destino soporta los tipos de archivos necesarios.

Si una exportación falla, vea [códigos de error de licencia y manejo de fallos de tarea](/server/import-export#export-errors).

## Formatos compatibles

La tabla cubre las APIs del navegador en esta página. La conversión de archivo de Office también requiere un backend que soporta el mismo tipo de documento y formato.

| Importación | Exportación |
| --- | --- |
| `.pdf` | `.pdf` |

Estas API importan y exportan archivos PDF solamente. No convierten contenido PDF a DOCX, XLSX o PPTX. La impresión del navegador es un flujo de trabajo separado.

## Elegir una ruta de datos

| Ruta         | Conserva una unidad del servidor | Requiere colaboración | Servidor de conversión |
| ------------ | :------------------------------: | :-------------------: | :--------------------: |
| ID de unidad |                Sí                |          Sí           |      Obligatorio       |
| Instantánea  |                No                |          No           |      Obligatorio       |

### Importar a una unidad persistente

Pase un navegador `File` o una URL, luego cargue la Unidad devuelta a través del cliente de colaboración configurado.

```ts
const unitId = await univerAPI.importPdfToUnitIdAsync(file)

if (unitId) {
  const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)
  console.log(pdf?.getName())
}
```

### Importar a una instantánea

Utilice la importación de instantáneas para una unidad de PDF local que la tarea de conversión no persiste:

```ts
const snapshot = await univerAPI.importPdfToSnapshotAsync(file)

if (snapshot) {
  univerAPI.createPdf(snapshot)
}
```

### Exportar y descargar

Exportar una unidad perdurada por su ID:

```ts
const file = await univerAPI.exportPdfByUnitIdAsync(unitId)

if (file) {
  univerAPI.downloadFile(file, 'project-brief', 'pdf')
}
```

Exporte la instantánea local actual sin conservarla primero:

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  const file = await univerAPI.exportPdfBySnapshotAsync(pdf.save())

  if (file) {
    univerAPI.downloadFile(file, pdf.getName(), 'pdf')
  }
}
```

Estas API devuelven a `File`. La impresión en el navegador es un flujo de trabajo separado que abre el diálogo de impresión del sistema. [Imprimir](/guides/pdfs/features/print).

### Añadir páginas y exportar un PDF abierto

La fachada de intercambio también funciona sobre un PDF que ya está abierto. `univerAPI.appendPdfAsync(file, unitId?)` importa el archivo y añade sus páginas al PDF indicado, o al PDF activo cuando se omite el ID de la unidad. Se resuelve como `false` cuando no hay destino o las páginas no se pueden añadir.

`univerAPI.exportPdfAsync(unitId?)` confirma el texto que todavía se está editando en el lienzo y exporta el documento abierto, así que sirve tanto para un PDF de instantánea local como para una unidad persistente. Se resuelve como `undefined` cuando la edición pendiente no se puede confirmar o el documento ya no está abierto.

```ts
// Append every page of another PDF to the open document.
const appended = await univerAPI.appendPdfAsync(file)

// Export the open PDF, including canvas edits that have not been committed yet.
const exported = await univerAPI.exportPdfAsync()
if (exported) {
  univerAPI.downloadFile(exported, 'project-brief', 'pdf')
}
```

Ambos métodos los añade `@univerjs-pro/pdfs-exchange-client/facade` a `FUniver`. Llame directamente a `pdf.appendPdf(snapshot)` para añadir un `IPdfUnitData` que ya tenga. Consulte [Univer API de PDF](/guides/pdfs/features/core/pdfs-api#append-pages).

## Eliminación de los menús y las interacciones de UI de importación y exportación integrados [#import-export-ui-migration]

<Callout type="warning" title="Nota">
  A partir de la versión **1.2.0**, Univer eliminó los menús y las interacciones de UI de importación y exportación integrados. Los servicios subyacentes y las API de Facade siguen disponibles.
</Callout>

Si una aplicación necesita mantener los menús de importación/exportación existentes y las interacciones de la interfaz de usuario, el [ejemplo de migración para menús integrados de importación/exportación e interacciones de la UI](https://office.univer.ai/showcase/pdfs/custom-import-export) muestra cómo restaurarlos con un plugin personalizado. El ejemplo incluye la fuente completa, que se puede ver en línea o descargar.
