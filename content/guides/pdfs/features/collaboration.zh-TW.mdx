先由經過認證的業務 API 呼叫 Collaboration Service 建立 Unit，再於瀏覽器載入回傳的識別碼。依[快速開始](https://office.univer.ai/zh-CN/collaboration/quick-start)一起設定 HTTP、Session Ticket 和 WebSocket，以 Database Adapter 持久化，並透過[伺服器端 Middleware](https://office.univer.ai/zh-CN/collaboration/identity-and-authorization)分別檢查讀取、JOIN 和修改權限。

<Callout>
  使用這些 API 前，請先確認目標伺服器支援 PDF Unit；Sheets 協同範例成功執行不代表已支援 PDF。
</Callout>

## 載入協作 PDF

透過伺服器 API 或 `importPdfToUnitIdAsync` 建立 PDF 單元後，使用協作 Facade 載入：

```ts
const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)

if (!pdf) {
  throw new Error(`PDF unit not found: ${unitId}`)
}

console.log(pdf.getId(), pdf.getName())
```

`loadPdfAsync` 會載入伺服器快照、準備協作工作階段並傳回 `FPdf`。當單元無法與 PDF 關聯時，它會傳回 `null`。
