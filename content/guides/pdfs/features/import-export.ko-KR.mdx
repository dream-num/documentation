아래 API는 변환 백엔드가 필요합니다. [파일 교환 통합](/server/import-export)로 시작하면 파일 업로드, 변환, 작업 쿼리 및 다운로드를 연결하고 브라우저 플러그인을 구성합니다. Snapshot API는 동일한 백엔드를 사용하지만 협업 문서가 필요하지 않습니다. 협업 교환 예제는 시트를 보여 주므로 대상 릴리스가 필요한 파일 형식을 지원한다는 것을 확인합니다.

수출이 실패하면 [라이센스 오류 코드 및 작업 실패 처리](/server/import-export#export-errors)를 참조하십시오.

## 지원 형식

이 페이지의 브라우저 API를 다룹니다. Office 파일 변환은 또한 동일한 문서 유형과 형식을 지원하는 백엔드가 필요합니다.

| 가져오기 | 내보내기 |
| --- | --- |
| `.pdf` | `.pdf` |

이 APIs 가져 오기 및 내보내기 PDF 파일 만. 그들은 PDF 콘텐츠를 DOCX, XLSX 또는 PPTX로 변환하지 않습니다. 브라우저 인쇄는 별도의 워크플로우입니다.

## 데이터 경로 선택

| 경로    | 서버 유닛 저장 | 협업 필요 | 변환 서버 |
| ------- | :------------: | :-------: | :-------: |
| 유닛 ID |       예       |    예     |   필요    |
| 스냅샷  |     아니요     |  아니요   |   필요    |

### 저장된 유닛으로 가져오기

브라우저 `File` 또는 URL을 입력한 후, 지정된 협업 클라이언트를 통해 리턴 유닛을 로드합니다.

```ts
const unitId = await univerAPI.importPdfToUnitIdAsync(file)

if (unitId) {
  const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)
  console.log(pdf?.getName())
}
```

### 스냅샷으로 가져오기

변환 작업이 지속되지 않는 로컬 PDF 단위에 대한 snapshot 가져 오기를 사용합니다.

```ts
const snapshot = await univerAPI.importPdfToSnapshotAsync(file)

if (snapshot) {
  univerAPI.createPdf(snapshot)
}
```

### 내보내기 및 다운로드

ID로 persisted 단위를 수출하십시오:

```ts
const file = await univerAPI.exportPdfByUnitIdAsync(unitId)

if (file) {
  univerAPI.downloadFile(file, 'project-brief', 'pdf')
}
```

현재 로컬 스냅샷을 먼저 저장하지 않고 내보내세요.

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  const file = await univerAPI.exportPdfBySnapshotAsync(pdf.save())

  if (file) {
    univerAPI.downloadFile(file, pdf.getName(), 'pdf')
  }
}
```

이 API는 `File`를 반환합니다. 브라우저의 인쇄는 시스템 인쇄 대화 상자를 열 수있는 별도의 워크플로입니다. [제품정보](/guides/pdfs/features/print)을 참조하십시오.
