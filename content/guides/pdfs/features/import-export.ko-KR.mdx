## 지원 형식

아래 표는 이 페이지의 브라우저 API가 지원하는 형식입니다. Office 파일 변환에는 해당 문서 유형과 형식을 지원하는 백엔드가 필요합니다.

| 가져오기 | 내보내기 |
| --- | --- |
| `.pdf` | `.pdf` |

## 데이터 경로 선택

| 경로    | 서버 유닛 저장 | 협업 필요 | 변환 서버 |
| ------- | :------------: | :-------: | :-------: |
| 유닛 ID |       예       |    예     |   필요    |
| 스냅샷  |     아니요     |  아니요   |   필요    |

### 저장된 유닛으로 가져오기

입력은 브라우저 `File` 또는 URL일 수 있습니다. 설정한 협업 클라이언트를 통해 반환된 유닛을 불러오세요.

```ts
const unitId = await univerAPI.importPdfToUnitIdAsync(file)

if (unitId) {
  const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)
  console.log(pdf?.getName())
}
```

### 스냅샷으로 가져오기

변환 작업의 일부로 저장하면 안 되는 로컬 PDF 유닛에는 스냅샷 가져오기를 사용하세요.

```ts
const snapshot = await univerAPI.importPdfToSnapshotAsync(file)

if (snapshot) {
  univerAPI.createPdf(snapshot)
}
```

### 내보내기 및 다운로드

저장된 유닛을 ID로 내보내세요.

```ts
const file = await univerAPI.exportPdfByUnitIdAsync(unitId)

if (file) {
  univerAPI.downloadFile(file, 'project-brief', 'pdf')
}
```

현재 로컬 스냅샷을 먼저 저장하지 않고 내보내세요.

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  const file = await univerAPI.exportPdfBySnapshotAsync(pdf.save())

  if (file) {
    univerAPI.downloadFile(file, pdf.getName(), 'pdf')
  }
}
```

이 API는 `File`을 반환합니다. 브라우저 인쇄는 시스템 인쇄 대화 상자를 여는 별도의 워크플로입니다. [인쇄](/guides/pdfs/features/print)를 참고하세요.
