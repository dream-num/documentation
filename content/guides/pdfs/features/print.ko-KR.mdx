`@univerjs-pro/pdfs-print`는 활성 PDF에 브라우저 인쇄 작업을 추가합니다. 현재 페이지를 구체화하고 시스템 인쇄 대화 상자를 엽니다.

## 인쇄 등록

```package-install
npm install @univerjs-pro/pdfs-print
```

브라우저 설정에 인쇄 로캘과 스타일을 추가한 다음 `UniverPdfsUIPlugin` 뒤에 플러그인을 등록하세요.

```ts
import { UniverPdfsPrintPlugin } from '@univerjs-pro/pdfs-print'
import PdfsPrintEnUS from '@univerjs-pro/pdfs-print/locale/en-US'

import '@univerjs-pro/pdfs-print/lib/index.css'

// Merge PdfsPrintEnUS with PdfsUIEnUS and the shared UI locales.
univer.registerPlugin(UniverPdfsPrintPlugin)
```

플러그인은 자체 메뉴 항목과 인쇄 진행 UI를 추가합니다. `FUniver`에는 PDF 인쇄 메서드가 없습니다. 사용자는 등록된 브라우저 UI를 통해 인쇄를 시작합니다.

## 인쇄는 파일 내보내기가 아님

| 워크플로 | 결과                                                                   | 서버 필요 | 환경                |
| -------- | ---------------------------------------------------------------------- | :-------: | ------------------- |
| 인쇄     | 브라우저 또는 운영 체제 인쇄 대화 상자를 엽니다                        |  아니요   | 브라우저 전용       |
| 내보내기 | 애플리케이션이 제어하는 다운로드를 위한 변환된 PDF `File`을 반환합니다 |    예     | Exchange 클라이언트 |

인쇄 대화 상자에서 “PDF로 저장”을 제공할 수 있지만, 이는 브라우저 기능입니다. 애플리케이션에 PDF 파일 객체, 결정적인 다운로드 흐름 또는 서버 측 변환이 필요하면 `exportPdfByUnitIdAsync` 또는 `exportPdfBySnapshotAsync`를 사용하세요.
