`@univerjs-pro/pdfs-print`는 브라우저에서 활성 PDF에 대한 인쇄 작업을 추가합니다. 현재 페이지를 재료화하고 시스템 인쇄 대화 상자를 엽니다.

## 인쇄 등록

```package-install
npm install @univerjs-pro/pdfs-print
```

인쇄 locale 및 stylesheet를 브라우저 설정에 추가하면 `UniverPdfsUIPlugin` 이후에 플러그인을 등록하십시오.

```ts
import { UniverPdfsPrintPlugin } from '@univerjs-pro/pdfs-print'
import PdfsPrintEnUS from '@univerjs-pro/pdfs-print/locale/en-US'

import '@univerjs-pro/pdfs-print/lib/index.css'

// Merge PdfsPrintEnUS with PdfsUIEnUS and the shared UI locales.
univer.registerPlugin(UniverPdfsPrintPlugin)
```

플러그인은 자체 메뉴 항목과 인쇄 진행 UI를 추가합니다. `FUniver`는 PDF 인쇄 방법을 제공하지 않습니다. 그래서 인쇄는 등록 된 브라우저 UI에서 시작합니다.

인쇄는 페이지를 재료화하기 전에 캔버스에서 아직 편집 중인 텍스트를 커밋하므로, 인쇄 결과가 현재 문서와 일치합니다.

## 모바일 지원 [#mobile-support]

먼저 [모바일 편집기](/guides/pdfs/getting-started/installation#mobile-support)를 설정한 다음, `UniverPdfsPrintPlugin`를 같은 패키지의 `UniverPdfsMobilePrintPlugin`로 교체하세요. 이 플러그인은 `UniverPdfsMobileUIPlugin`과 `UniverMobileUIPlugin`을 필요로 하며, 모바일 뷰어와 읽기 전용 메뉴에 인쇄를 추가하고, 문서가 모바일 픽셀 예산을 초과하면 페이지 캔버스를 축소합니다.

## 인쇄는 파일 내보내기가 아님

| 워크플로 | 결과                                                                   | 서버 필요 | 환경                |
| -------- | ---------------------------------------------------------------------- | :-------: | ------------------- |
| 인쇄 | 브라우저 또는 운영 체제 인쇄 대화 상자를 엽니다. | 아니요 | 브라우저 전용 |
| 내보내기 | 애플리케이션이 제어하는 다운로드를 위한 변환된 PDF `File`을 반환합니다 |    예     | Exchange 클라이언트 |

인쇄 대화 상자는 "PDF로 저장"을 제공 할 수 있지만, 옵션은 브라우저에서 제공됩니다. 응용 프로그램은 PDF 파일 개체를 필요로 할 때, 자체 제어의 다운로드 흐름, 또는 서버 측 변환, 그것은 `exportPdfByUnitIdAsync` 또는 `exportPdfBySnapshotAsync`를 사용해야합니다.
