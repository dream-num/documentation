PDF UI는 일반적인 브라우저 워크플로를 위한 편집 도구를 제공합니다. 애플리케이션 코드는 `@univerjs-pro/pdfs/facade`를 통해 동일한 영속적 모델 변경을 수행할 수 있습니다.

## 텍스트 및 구조화된 콘텐츠 추가

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const paragraph = page.insertParagraph({
  text: 'Release summary',
  left: 36,
  top: 36,
  width: 240,
  height: 72,
  fontSize: 18,
})

paragraph.appendBlock({
  text: 'Approved for publication',
  textStyle: { italic: true },
})

const list = page.insertList({
  text: 'Verify content',
  kind: univerAPI.Enum.PdfListKind.UNORDERED,
  preset: univerAPI.Enum.PdfListPresetId.UNORDERED_DISC,
  left: 36,
  top: 132,
  width: 240,
  height: 108,
})

list.insertItem(1, { text: 'Export final PDF' })
list.insertItem(2, { text: 'Archive source', level: 1 })
```

목록 수준은 `0`부터 `8`까지로 제한됩니다. 항목 수준을 높이려면 부모 역할을 할 수 있는 앞선 항목도 있어야 합니다.

## 표 편집

```ts
const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Owner', 'Status', 'Docs', 'Ready'],
  left: 312,
  top: 36,
  width: 240,
  height: 108,
})

table.resize(3, 2)
table.getCell(2, 0).setText('Legal')
table.getCell(2, 1).setText('Review')
```

표에는 최대 10,000개의 셀이 포함될 수 있습니다. `getPdfTableThemePresets()`는 표 테마 워크플로에 전달할 수 있는 기본 제공 프리셋 설명자를 반환합니다.

## 이미지 및 주석 추가

```ts
const image = await page.insertImageAsync('/assets/signature.png', {
  left: 312,
  top: 180,
  width: 144,
  height: 72,
  opacity: 0.9,
})

image.setRotation(-4).bringToFront()

const highlight = page.insertAnnotation({
  annotationType: univerAPI.Enum.PdfAnnotationType.HIGHLIGHT,
  left: 36,
  top: 264,
  width: 180,
  height: 18,
})

highlight.setStyle({
  fill: { color: '#fde047' },
  opacity: 0.6,
})
```

퍼사드 삽입은 강조, 밑줄, 취소선, 물결 밑줄 및 잉크 주석을 지원합니다. 핵심 열거형에는 이 삽입 API에서 허용되지 않는 추가 PDF 주석 하위 유형이 포함되어 있습니다.

## 가져온 텍스트 바꾸기

네이티브로 가져온 텍스트는 `getTextSpans()`를 통해 읽습니다. 범위를 바꾸는 것은 원자적 승격입니다. Univer는 해당 소스 작업을 숨기고 캡처된 위치에 편집 가능한 텍스트 상자를 삽입합니다.

```ts
const matchingSpan = page.getTextSpans().find((span) => span.getText().includes('Draft'))

if (matchingSpan) {
  matchingSpan.replaceText('Final')
}
```

바꾼 뒤에는 범위를 다시 열거하세요. 이전 스냅샷 핸들은 유효하지 않게 됩니다.

## 요소 변환 및 제거

편집 가능한 모든 페이지 요소는 변환 및 z 순서 메서드를 공유합니다.

```ts
image.setPosition(300, 180).setSize(180, 90).setVisible(true).setLocked(false).sendBackward()

const snapshot = pdf.save()
```

퍼사드 변경은 Univer 명령을 통해 전달됩니다. 유닛이 활성 상태인 동안 `snapshot.document` 또는 `snapshot.editState`를 직접 변경하지 마세요.
