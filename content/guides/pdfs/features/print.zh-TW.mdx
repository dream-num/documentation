`@univerjs-pro/pdfs-print` 為當前 PDF 提供瀏覽器列印入口。該外掛會物化當前頁面，然後開啟系統列印對話方塊。

## 註冊列印

```package-install
npm install @univerjs-pro/pdfs-print
```

在瀏覽器配置中加入列印的語言套件與樣式，然後在 `UniverPdfsUIPlugin` 之後註冊該外掛：

```ts
import { UniverPdfsPrintPlugin } from '@univerjs-pro/pdfs-print'
import PdfsPrintEnUS from '@univerjs-pro/pdfs-print/locale/en-US'

import '@univerjs-pro/pdfs-print/lib/index.css'

// Merge PdfsPrintEnUS with PdfsUIEnUS and the shared UI locales.
univer.registerPlugin(UniverPdfsPrintPlugin)
```

外掛會新增自己的選單項和列印進度 UI。`FUniver` 沒有提供 PDF 列印方法，列印需從已註冊的瀏覽器 UI 發起。

列印會在具體化頁面之前，先提交畫布上仍在編輯的文字，因此列印結果與當前文件一致。

## 行動裝置支援 [#mobile-support]

請先完成[行動版編輯器](/guides/pdfs/getting-started/installation#mobile-support)的設定，再將 `UniverPdfsPrintPlugin` 替換為同一個套件中的 `UniverPdfsMobilePrintPlugin`。此外掛依賴 `UniverPdfsMobileUIPlugin` 和 `UniverMobileUIPlugin`，會把「列印」加入行動版檢視器和唯讀選單，並在文件超出行動版像素預算時按比例縮小頁面畫布。

## 列印不是檔案匯出

| 工作流程 | 結果                                        | 是否需要伺服器 | 環境            |
| -------- | ------------------------------------------- | :------------: | --------------- |
| 列印     | 開啟瀏覽器或作業系統列印對話方塊            |       否       | 僅瀏覽器        |
| 匯出     | 傳回轉換後的 PDF `File`，供應用程式控制下載 |       是       | Exchange 客戶端 |

列印對話方塊可能提供“另存為 PDF”，但該能力來自瀏覽器本身。如果應用需要一個 PDF 檔案物件、一條可自行控制的下載流程，或伺服器端轉換，應使用 `exportPdfByUnitIdAsync` 或 `exportPdfBySnapshotAsync`。
