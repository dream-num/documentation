本頁的 API 需要轉換後端。請先按[匯入匯出整合](/server/import-export)接通檔案上傳、轉換、任務查詢與下載，再配置瀏覽器外掛。快照 API 使用同一個後端，但不需要協同文件。協同 Exchange 範例演示的是 Sheets，接入前請確認目標版本支援所需的檔案型別。

匯出失敗時，請參閱[許可證錯誤碼與任務失敗處理](/server/import-export#export-errors)。

## 支援的格式

下表列出本頁瀏覽器 API 覆蓋的格式。Office 檔案轉換還要求後端支援相同的文件型別與格式。

| 匯入 | 匯出 |
| --- | --- |
| `.pdf` | `.pdf` |

這些 API 僅匯入和匯出 PDF 檔案，不能將 PDF 內容轉換為 DOCX、XLSX 或 PPTX。瀏覽器列印是另一條流程。

## 選擇資料路徑

| 路徑    | 是否持久化伺服器單元 | 是否需要協作 | 轉換伺服器 |
| ------- | :------------------: | :----------: | :--------: |
| 單元 ID |          是          |      是      |    必要    |
| 快照    |          否          |      否      |    必要    |

### 匯入為持久化單元

輸入可以是瀏覽器 `File` 或 URL。返回的單元由配置好的協作客戶端載入：

```ts
const unitId = await univerAPI.importPdfToUnitIdAsync(file)

if (unitId) {
  const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)
  console.log(pdf?.getName())
}
```

### 匯入為快照

如需一個本地 PDF 單元，且不希望轉換任務將其持久化，請使用快照匯入：

```ts
const snapshot = await univerAPI.importPdfToSnapshotAsync(file)

if (snapshot) {
  univerAPI.createPdf(snapshot)
}
```

### 匯出並下載

按 ID 匯出已持久化的單元：

```ts
const file = await univerAPI.exportPdfByUnitIdAsync(unitId)

if (file) {
  univerAPI.downloadFile(file, 'project-brief', 'pdf')
}
```

當前本地快照無需先持久化即可直接匯出：

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  const file = await univerAPI.exportPdfBySnapshotAsync(pdf.save())

  if (file) {
    univerAPI.downloadFile(file, pdf.getName(), 'pdf')
  }
}
```

這些 API 返回 `File`。瀏覽器列印是另一條工作流，會開啟系統列印對話方塊。詳情見[列印](/guides/pdfs/features/print)。

### 附加頁面並匯出已開啟的 PDF

Exchange facade 同樣可用於已經開啟的 PDF。`univerAPI.appendPdfAsync(file, unitId?)` 會匯入檔案，並把它的頁面附加到指定的 PDF。省略單元 ID 時附加到當前 PDF。沒有目標或頁面無法附加時，會解析為 `false`。

`univerAPI.exportPdfAsync(unitId?)` 會先提交畫布上仍在編輯的文字，再匯出已開啟的文件，因此本機快照 PDF 和已持久化的單元都適用。待提交的編輯無法提交或文件已不再開啟時，會解析為 `undefined`。

```ts
// Append every page of another PDF to the open document.
const appended = await univerAPI.appendPdfAsync(file)

// Export the open PDF, including canvas edits that have not been committed yet.
const exported = await univerAPI.exportPdfAsync()
if (exported) {
  univerAPI.downloadFile(exported, 'project-brief', 'pdf')
}
```

這兩個方法由 `@univerjs-pro/pdfs-exchange-client/facade` 新增到 `FUniver`。如已持有 `IPdfUnitData`，可直接呼叫 `pdf.appendPdf(snapshot)` 附加。詳情見 [PDF Facade API](/guides/pdfs/features/core/pdfs-api#append-pages)。

## 移除內建匯入匯出選單和 UI 互動 [#import-export-ui-migration]

<Callout type="warning" title="注意事項">
  從 **1.2.0** 版本開始，Univer 移除了內建的匯入匯出選單和 UI 互動，底層服務與 Facade API 仍然保留。
</Callout>

如果應用需要保留現有的匯入匯出選單和 UI 互動，可參照[內建匯入匯出選單和 UI 互動遷移方案](https://office.univer.ai/zh-CN/showcase/pdfs/custom-import-export)，透過自定義外掛將其恢復。範例包含完整原始碼，可線上檢視或下載。
