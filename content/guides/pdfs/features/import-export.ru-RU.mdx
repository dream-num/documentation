## Поддерживаемые форматы

Таблица охватывает API-интерфейсы браузера на этой странице.Конверсия файлов Office также требует бэкэнда, который поддерживает тот же тип и формат документа.

| Импорт | Экспорт |
| --- | --- |
| `.pdf` | `.pdf` |

Эти API импортируют и экспортируют только PDF-файлы. Они не конвертируют PDF-контент в DOCX, XLSX или PPTX. Браузерная печать - это отдельный рабочий процесс.

## Выбор пути данных

| Путь      | Сохраняет модуль на сервере | Требует совместной работы | Сервер преобразования |
| --------- | :-------------------------: | :-----------------------: | :-------------------: |
| ID модуля |             Да              |            Да             |       Требуется       |
| Снимок    |             Нет             |            Нет            |       Требуется       |

### Импорт в сохраняемый модуль

Передайте браузеру `File` или URL-адрес, а затем загрузите возвращенный блок через настроенный клиент совместной работы.

```ts
const unitId = await univerAPI.importPdfToUnitIdAsync(file)

if (unitId) {
  const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)
  console.log(pdf?.getName())
}
```

### Импорт в снимок

Используйте моментальный импорт для локального блока PDF, чтобы задача преобразования не сохранялась:

```ts
const snapshot = await univerAPI.importPdfToSnapshotAsync(file)

if (snapshot) {
  univerAPI.createPdf(snapshot)
}
```

### Экспорт и скачивание

Экспортировать устоявшуюся единицу по ее ID:

```ts
const file = await univerAPI.exportPdfByUnitIdAsync(unitId)

if (file) {
  univerAPI.downloadFile(file, 'project-brief', 'pdf')
}
```

Экспортируйте текущий локальный снимок, не сохраняя его предварительно:

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  const file = await univerAPI.exportPdfBySnapshotAsync(pdf.save())

  if (file) {
    univerAPI.downloadFile(file, pdf.getName(), 'pdf')
  }
}
```

Эти API возвращают `File`. Печать в браузере - это отдельный рабочий процесс, который открывает системный диалог печати. См. [Печать](/guides/pdfs/features/print) .

### Добавление страниц и экспорт открытого PDF

Фасад Exchange также работает с уже открытым PDF. `univerAPI.appendPdfAsync(file, unitId?)` импортирует файл и добавляет его страницы в указанный PDF или в активный PDF, если идентификатор модуля опущен. Возвращает `false`, когда нет цели или страницы невозможно добавить.

`univerAPI.exportPdfAsync(unitId?)` фиксирует текст, который все еще редактируется на холсте, и экспортирует открытый документ, поэтому работает как для PDF локального снимка, так и для сохраненного модуля. Возвращает `undefined`, когда незавершенное редактирование не удается зафиксировать или документ больше не открыт.

```ts
// Append every page of another PDF to the open document.
const appended = await univerAPI.appendPdfAsync(file)

// Export the open PDF, including canvas edits that have not been committed yet.
const exported = await univerAPI.exportPdfAsync()
if (exported) {
  univerAPI.downloadFile(exported, 'project-brief', 'pdf')
}
```

Оба метода добавляются в `FUniver` с помощью `@univerjs-pro/pdfs-exchange-client/facade`. Вызовите `pdf.appendPdf(snapshot)` напрямую, чтобы добавить уже имеющийся `IPdfUnitData`. См. [PDF Facade API](/guides/pdfs/features/core/pdfs-api#append-pages).

## Удаление встроенных меню и UI-взаимодействий для импорта и экспорта [#import-export-ui-migration]

<Callout type="warning" title="Обратите внимание">
  Начиная с версии **1.2.0**, Univer больше не включает встроенные меню и UI-взаимодействия для импорта и экспорта. Базовые сервисы и Facade API остаются доступными.
</Callout>

Пример включает в себя полный источник, который можно просматривать онлайн или загружать.
