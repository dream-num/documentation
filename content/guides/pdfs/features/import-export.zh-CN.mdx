## 支持的格式

下表列出本页浏览器 API 覆盖的格式。Office 文件转换还要求后端支持相同的文档类型与格式。

| 导入 | 导出 |
| --- | --- |
| `.pdf` | `.pdf` |

这些 API 仅导入和导出 PDF 文件，不能将 PDF 内容转换为 DOCX、XLSX 或 PPTX。浏览器打印是另一条流程。

## 选择数据路径

| 路径    | 是否持久化服务器单元 | 是否需要协作 | 转换服务器 |
| ------- | :------------------: | :----------: | :--------: |
| 单元 ID |          是          |      是      |    必需    |
| 快照    |          否          |      否      |    必需    |

### 导入为持久化单元

输入可以是浏览器 `File` 或 URL。返回的单元由配置好的协作客户端加载：

```ts
const unitId = await univerAPI.importPdfToUnitIdAsync(file)

if (unitId) {
  const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)
  console.log(pdf?.getName())
}
```

### 导入为快照

如需一个本地 PDF 单元，且不希望转换任务将其持久化，请使用快照导入：

```ts
const snapshot = await univerAPI.importPdfToSnapshotAsync(file)

if (snapshot) {
  univerAPI.createPdf(snapshot)
}
```

### 导出和下载

按 ID 导出已持久化的单元：

```ts
const file = await univerAPI.exportPdfByUnitIdAsync(unitId)

if (file) {
  univerAPI.downloadFile(file, 'project-brief', 'pdf')
}
```

当前本地快照无需先持久化即可直接导出：

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  const file = await univerAPI.exportPdfBySnapshotAsync(pdf.save())

  if (file) {
    univerAPI.downloadFile(file, pdf.getName(), 'pdf')
  }
}
```

这些 API 返回 `File`。浏览器打印是另一条工作流，会打开系统打印对话框。详情见[打印](/guides/pdfs/features/print)。

### 追加页面并导出已打开的 PDF

Exchange facade 也可用于已经打开的 PDF。`univerAPI.appendPdfAsync(file, unitId?)` 会导入文件并将页面追加到指定 PDF。省略单元 ID 时追加到当前 PDF。没有目标或页面无法追加时，该方法返回 `false`。

`univerAPI.exportPdfAsync(unitId?)` 会先提交画布上仍在编辑的文本，再导出打开的文档，因此本地快照 PDF 和已持久化的单元都适用。待提交的编辑无法提交或文档已不再打开时，该方法返回 `undefined`。

```ts
// Append every page of another PDF to the open document.
const appended = await univerAPI.appendPdfAsync(file)

// Export the open PDF, including canvas edits that have not been committed yet.
const exported = await univerAPI.exportPdfAsync()
if (exported) {
  univerAPI.downloadFile(exported, 'project-brief', 'pdf')
}
```

这两个方法由 `@univerjs-pro/pdfs-exchange-client/facade` 添加到 `FUniver`。如已持有 `IPdfUnitData`，可直接调用 `pdf.appendPdf(snapshot)` 追加。详情见 [PDF Facade API](/guides/pdfs/features/core/pdfs-api#append-pages)。

## 移除内置导入导出菜单和 UI 交互 [#import-export-ui-migration]

<Callout type="warning" title="注意事项">
  从 **1.2.0** 版本开始，Univer 移除了内置的导入导出菜单和 UI 交互，底层服务与 Facade API 仍然保留。
</Callout>

如果应用需要保留现有的导入导出菜单和 UI 交互，可参照[内置导入导出菜单和 UI 交互迁移方案](https://office.univer.ai/zh-CN/showcase/pdfs/custom-import-export)，通过自定义插件将其恢复。示例包含完整源码，可在线查看或下载。
