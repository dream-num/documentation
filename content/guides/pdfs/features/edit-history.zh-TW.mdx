PDF 單元在編輯過程中支援撤銷與重做，但沒有類似 Sheets、Docs、Slides、Boards、Bases 的獨立版本歷史面板外掛。不要為 PDF 註冊其他產品的 History UI 外掛。

## 復原與重做

撤銷與重做作用於當前獲得焦點的 Univer 單元：

```ts
await univerAPI.undo()
await univerAPI.redo()
```

這兩個呼叫不會生成伺服器端版本列表，也無法讀取此前會話中的歷史版本。其他操作見[通用 API](/guides/pdfs/features/core/general-api)。

## 跨工作階段的版本

先接入 [PDFs 協同編輯](/guides/pdfs/features/collaboration)。如需長期保留版本，請查閱 [Office 歷史服務](/server/collaboration/extensions)，確認目標版本支援 PDF 資料，並在應用中實現版本列表與檢視介面。接入通用 History 服務不會自動為 PDF 編輯器新增歷史面板。

恢復歷史內容並不只是替換頁面上顯示的資料，還需要處理文件權限、與當前協同會話的配合，以及關聯 PDF 檔案的保留。
