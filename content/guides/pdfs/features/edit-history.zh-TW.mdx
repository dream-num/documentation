PDFs 支援編輯過程中的復原與重做。目前沒有與 Sheets、Docs、Slides、Boards 或 Bases 相同的專用版本歷史面板外掛。請勿為 PDFs 註冊其他產品的 History UI 外掛。

## 復原與重做

復原與重做作用於目前取得焦點的 Univer 單元：

```ts
await univerAPI.undo()
await univerAPI.redo()
```

這些操作不會建立伺服器端版本清單，也不會讀取先前工作階段的版本。其他操作請參閱[通用 API](/guides/pdfs/features/core/general-api)。

## 跨工作階段的版本

先接入 [PDFs 協同編輯](/guides/pdfs/features/collaboration)。若要長期保留版本，請參考 [Office 歷史服務](/server/collaboration/extensions)，確認目標版本支援 PDF 資料，並在應用程式中實作版本清單與檢視器。加入通用 History 服務不會自動產生 PDF 歷史面板。

還原內容需要檢查文件授權、與目前協同工作階段協調，並保留關聯的 PDF 檔案。只替換頁面顯示的資料並不足夠。
