description: Añada y actualice texto, listas, tablas, imágenes, divisores y anotaciones mediante la Facade de PDF.

La interfaz PDF ofrece herramientas de edición para flujos de trabajo habituales en el navegador. El código de la aplicación puede realizar los mismos cambios persistentes en el modelo mediante `@univerjs-pro/pdfs/facade`.

## Añadir texto y contenido estructurado

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const paragraph = page.insertParagraph({
  text: 'Release summary',
  left: 36,
  top: 36,
  width: 240,
  height: 72,
  fontSize: 18,
})

paragraph.appendBlock({
  text: 'Approved for publication',
  textStyle: { italic: true },
})

const list = page.insertList({
  text: 'Verify content',
  kind: univerAPI.Enum.PdfListKind.UNORDERED,
  preset: univerAPI.Enum.PdfListPresetId.UNORDERED_DISC,
  left: 36,
  top: 132,
  width: 240,
  height: 108,
})

list.insertItem(1, { text: 'Export final PDF' })
list.insertItem(2, { text: 'Archive source', level: 1 })
```

Los niveles de lista están limitados de `0` a `8`. Aumentar el nivel de un elemento también requiere un elemento anterior que pueda actuar como padre.

## Editar una tabla

```ts
const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Owner', 'Status', 'Docs', 'Ready'],
  left: 312,
  top: 36,
  width: 240,
  height: 108,
})

table.resize(3, 2)
table.getCell(2, 0).setText('Legal')
table.getCell(2, 1).setText('Review')
```

Una tabla puede contener como máximo 10,000 celdas. `getPdfTableThemePresets()` devuelve descriptores de presets integrados que pueden pasarse a los flujos de trabajo de temas de tabla.

## Añadir imágenes y anotaciones

```ts
const image = await page.insertImageAsync('/assets/signature.png', {
  left: 312,
  top: 180,
  width: 144,
  height: 72,
  opacity: 0.9,
})

image.setRotation(-4).bringToFront()

const highlight = page.insertAnnotation({
  annotationType: univerAPI.Enum.PdfAnnotationType.HIGHLIGHT,
  left: 36,
  top: 264,
  width: 180,
  height: 18,
})

highlight.setStyle({
  fill: { color: '#fde047' },
  opacity: 0.6,
})
```

La inserción mediante Facade admite anotaciones de resaltado, subrayado, tachado, subrayado ondulado y tinta. La enumeración principal incluye subtipos de anotación PDF adicionales que esta API de inserción no acepta.

## Sustituir texto importado

El texto nativo importado se lee mediante `getTextSpans()`. Sustituir un fragmento es una promoción atómica: Univer suprime la operación de origen correspondiente e inserta un cuadro de texto editable en la posición capturada.

```ts
const matchingSpan = page.getTextSpans().find((span) => span.getText().includes('Draft'))

if (matchingSpan) {
  matchingSpan.replaceText('Final')
}
```

Vuelva a enumerar los fragmentos después de una sustitución; el identificador de instantánea anterior queda obsoleto.

## Transformar y eliminar elementos

Todos los elementos editables de página comparten métodos de transformación y orden z:

```ts
image.setPosition(300, 180).setSize(180, 90).setVisible(true).setLocked(false).sendBackward()

const snapshot = pdf.save()
```

Los cambios de Facade se encaminan mediante comandos de Univer. Evite modificar directamente `snapshot.document` o `snapshot.editState` mientras la unidad esté activa.
