`@univerjs-pro/pdfs-print` ajoute une action d'impression pour le PDF actif dans le navigateur. Il matérialise les pages actuelles et ouvre la boîte de dialogue d'impression système.

## Enregistrer l'impression

```package-install
npm install @univerjs-pro/pdfs-print
```

Ajouter la locale d'impression et la feuille de style à la configuration du navigateur, puis enregistrer le plugin après `UniverPdfsUIPlugin`:

```ts
import { UniverPdfsPrintPlugin } from '@univerjs-pro/pdfs-print'
import PdfsPrintEnUS from '@univerjs-pro/pdfs-print/locale/en-US'

import '@univerjs-pro/pdfs-print/lib/index.css'

// Merge PdfsPrintEnUS with PdfsUIEnUS and the shared UI locales.
univer.registerPlugin(UniverPdfsPrintPlugin)
```

Le plugin ajoute son propre élément de menu et d'impression de progrès UI. `FUniver` ne fournit pas de méthode d'impression PDF, donc l'impression commence à partir de l'interface utilisateur du navigateur enregistré.

L'impression valide le texte encore en cours d'édition sur le canevas avant de matérialiser les pages, de sorte que le résultat imprimé corresponde au document actuel.

## Prise en charge mobile [#mobile-support]

Configurez d'abord l'[éditeur mobile](/guides/pdfs/getting-started/installation#mobile-support), puis remplacez `UniverPdfsPrintPlugin` par `UniverPdfsMobilePrintPlugin` du même paquet. Il exige `UniverPdfsMobileUIPlugin` et `UniverMobileUIPlugin`, ajoute l'impression aux menus de la visionneuse mobile et en lecture seule, et réduit l'échelle des canevas de page lorsqu'un document dépasse le budget de pixels mobile.

## L'impression n'est pas l'exportation d'un fichier

| Processus   | Résultat                                                                               | Serveur requis | Environnement         |
| ----------- | -------------------------------------------------------------------------------------- | :------------: | --------------------- |
| Impression | Ouvre la boîte de dialogue d'impression du navigateur ou du système d'exploitation | Non | Navigateur uniquement |
| Exportation | Renvoie un objet `File` PDF converti pour un téléchargement contrôlé par l'application |      Oui       | Client Exchange       |

La boîte de dialogue d'impression peut offrir --Enregistrer en PDF, mais cette option vient du navigateur. Lorsqu'une application a besoin d'un objet de fichier PDF, un flux de téléchargement sous son propre contrôle, ou la conversion côté serveur, elle doit utiliser `exportPdfByUnitIdAsync` ou `exportPdfBySnapshotAsync`.
