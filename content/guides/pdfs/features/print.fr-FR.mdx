`@univerjs-pro/pdfs-print` ajoute une action d'impression dans le navigateur pour le PDF actif. Il matérialise les pages actuelles et ouvre la boîte de dialogue d'impression du système.

## Enregistrer l'impression

```package-install
npm install @univerjs-pro/pdfs-print
```

Ajoutez la locale et le style d'impression à la configuration du navigateur, puis enregistrez le plugin après `UniverPdfsUIPlugin` :

```ts
import { UniverPdfsPrintPlugin } from '@univerjs-pro/pdfs-print'
import PdfsPrintEnUS from '@univerjs-pro/pdfs-print/locale/en-US'

import '@univerjs-pro/pdfs-print/lib/index.css'

// Merge PdfsPrintEnUS with PdfsUIEnUS and the shared UI locales.
univer.registerPlugin(UniverPdfsPrintPlugin)
```

Le plugin ajoute son propre élément de menu et une interface de progression de l'impression. Il n'existe aucune méthode d'impression PDF dans `FUniver` ; les utilisateurs lancent l'impression avec l'interface enregistrée dans le navigateur.

## L'impression n'est pas l'exportation d'un fichier

| Processus   | Résultat                                                                               | Serveur requis | Environnement         |
| ----------- | -------------------------------------------------------------------------------------- | :------------: | --------------------- |
| Impression  | Ouvre la boîte de dialogue d'impression du navigateur ou du système d'exploitation     |      Non       | Navigateur uniquement |
| Exportation | Renvoie un objet `File` PDF converti pour un téléchargement contrôlé par l'application |      Oui       | Client Exchange       |

La boîte de dialogue d'impression peut proposer « Enregistrer au format PDF », mais il s'agit d'une fonctionnalité du navigateur. Utilisez `exportPdfByUnitIdAsync` ou `exportPdfBySnapshotAsync` lorsque votre application a besoin d'un objet fichier PDF, d'un flux de téléchargement déterministe ou d'une conversion côté serveur.
