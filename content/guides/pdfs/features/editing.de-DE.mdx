Die PDF-Benutzeroberfläche stellt Bearbeitungswerkzeuge für gängige Browser-Arbeitsabläufe bereit. Anwendungscode kann dieselben dauerhaften Modelländerungen über `@univerjs-pro/pdfs/facade` durchführen.

## Text und strukturierte Inhalte hinzufügen

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const paragraph = page.insertParagraph({
  text: 'Release summary',
  left: 36,
  top: 36,
  width: 240,
  height: 72,
  fontSize: 18,
})

paragraph.appendBlock({
  text: 'Approved for publication',
  textStyle: { italic: true },
})

const list = page.insertList({
  text: 'Verify content',
  kind: univerAPI.Enum.PdfListKind.UNORDERED,
  preset: univerAPI.Enum.PdfListPresetId.UNORDERED_DISC,
  left: 36,
  top: 132,
  width: 240,
  height: 108,
})

list.insertItem(1, { text: 'Export final PDF' })
list.insertItem(2, { text: 'Archive source', level: 1 })
```

Listenebenen sind auf `0` bis `8` beschränkt. Das Erhöhen der Ebene eines Elements erfordert außerdem ein vorhergehendes Element, das als übergeordnetes Element dienen kann.

## Tabelle bearbeiten

```ts
const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Owner', 'Status', 'Docs', 'Ready'],
  left: 312,
  top: 36,
  width: 240,
  height: 108,
})

table.resize(3, 2)
table.getCell(2, 0).setText('Legal')
table.getCell(2, 1).setText('Review')
```

Eine Tabelle darf höchstens 10,000 Zellen enthalten. `getPdfTableThemePresets()` gibt integrierte Preset-Beschreibungen zurück, die an Arbeitsabläufe für Tabellendesigns übergeben werden können.

## Bilder und Anmerkungen hinzufügen

```ts
const image = await page.insertImageAsync('/assets/signature.png', {
  left: 312,
  top: 180,
  width: 144,
  height: 72,
  opacity: 0.9,
})

image.setRotation(-4).bringToFront()

const highlight = page.insertAnnotation({
  annotationType: univerAPI.Enum.PdfAnnotationType.HIGHLIGHT,
  left: 36,
  top: 264,
  width: 180,
  height: 18,
})

highlight.setStyle({
  fill: { color: '#fde047' },
  opacity: 0.6,
})
```

Die Facade-Einfügung unterstützt Hervorhebungs-, Unterstreichungs-, Durchstreichungs-, Wellenlinien- und Freihandanmerkungen. Die Core-Enumeration enthält zusätzliche PDF-Anmerkungsuntertypen, die von dieser Einfüge-API nicht akzeptiert werden.

## Importierten Text ersetzen

Nativer importierter Text wird über `getTextSpans()` gelesen. Das Ersetzen eines Abschnitts ist eine atomare Heraufstufung: Univer unterdrückt die entsprechende Quelloperation und fügt an der erfassten Position ein bearbeitbares Textfeld ein.

```ts
const matchingSpan = page.getTextSpans().find((span) => span.getText().includes('Draft'))

if (matchingSpan) {
  matchingSpan.replaceText('Final')
}
```

Zählen Sie die Abschnitte nach einer Ersetzung erneut auf; das alte Snapshot-Handle ist danach veraltet.

## Elemente transformieren und entfernen

Alle bearbeitbaren Seitenelemente verwenden dieselben Transformations- und Z-Reihenfolge-Methoden:

```ts
image.setPosition(300, 180).setSize(180, 90).setVisible(true).setLocked(false).sendBackward()

const snapshot = pdf.save()
```

Facade-Änderungen werden über Univer-Befehle geleitet. Verändern Sie `snapshot.document` oder `snapshot.editState` nicht direkt, während die Einheit aktiv ist.
