`@univerjs-pro/pdfs-print` добавляет функцию Print для активного PDF в браузере. Он материализует текущие страницы и открывает системный диалог печати.

## Регистрация печати

```package-install
npm install @univerjs-pro/pdfs-print
```

Добавьте в настройки браузера локаль печати и таблицу стилей, а затем зарегистрируйте плагин после `UniverPdfsUIPlugin`:

```ts
import { UniverPdfsPrintPlugin } from '@univerjs-pro/pdfs-print'
import PdfsPrintEnUS from '@univerjs-pro/pdfs-print/locale/en-US'

import '@univerjs-pro/pdfs-print/lib/index.css'

// Merge PdfsPrintEnUS with PdfsUIEnUS and the shared UI locales.
univer.registerPlugin(UniverPdfsPrintPlugin)
```

Плагин добавляет свой собственный пункт меню и прогресс печати UI. `FUniver` не предоставляет метод печати PDF, поэтому печать начинается с зарегистрированного пользовательского интерфейса браузера.

## Печать не является экспортом файла

| Процесс | Результат                                                                              | Требуется сервер | Среда           |
| ------- | -------------------------------------------------------------------------------------- | :--------------: | --------------- |
| Печать | Открывает браузер или операционную систему для печати диалогов | Нет | Только браузер |
| Экспорт | Возвращает преобразованный объект `File` PDF для скачивания под управлением приложения |        Да        | Клиент Exchange |

Диалог печати может предлагать «Сохранить как PDF», но эта опция исходит из браузера.Когда приложению нужен объект PDF-файла, поток загрузки под собственным контролем или конверсия на стороне сервера, он должен использовать `exportPdfByUnitIdAsync` или `exportPdfBySnapshotAsync`.
