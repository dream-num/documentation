`@univerjs-pro/pdfs-print` добавляет браузерную команду печати для активного PDF. Плагин материализует текущие страницы и открывает системный диалог печати.

## Регистрация печати

```package-install
npm install @univerjs-pro/pdfs-print
```

Добавьте локаль и стиль печати в браузерную конфигурацию, затем зарегистрируйте плагин после `UniverPdfsUIPlugin`:

```ts
import { UniverPdfsPrintPlugin } from '@univerjs-pro/pdfs-print'
import PdfsPrintEnUS from '@univerjs-pro/pdfs-print/locale/en-US'

import '@univerjs-pro/pdfs-print/lib/index.css'

// Merge PdfsPrintEnUS with PdfsUIEnUS and the shared UI locales.
univer.registerPlugin(UniverPdfsPrintPlugin)
```

Плагин добавляет собственный пункт меню и интерфейс хода печати. В `FUniver` нет метода печати PDF; пользователи запускают печать через зарегистрированный браузерный интерфейс.

## Печать не является экспортом файла

| Процесс | Результат                                                                              | Требуется сервер | Среда           |
| ------- | -------------------------------------------------------------------------------------- | :--------------: | --------------- |
| Печать  | Открывает диалог печати браузера или операционной системы                              |       Нет        | Только браузер  |
| Экспорт | Возвращает преобразованный объект `File` PDF для скачивания под управлением приложения |        Да        | Клиент Exchange |

Диалог печати может предлагать команду «Сохранить как PDF», но это возможность браузера. Используйте `exportPdfByUnitIdAsync` или `exportPdfBySnapshotAsync`, если приложению нужен объект файла PDF, детерминированный процесс скачивания или преобразование на стороне сервера.
