PDF UI は、一般的なブラウザーワークフロー向けの編集ツールを提供します。アプリケーションコードでも、`@univerjs-pro/pdfs/facade` を通じて同じ永続モデルの変更を実行できます。

## テキストと構造化コンテンツを追加する

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const paragraph = page.insertParagraph({
  text: 'Release summary',
  left: 36,
  top: 36,
  width: 240,
  height: 72,
  fontSize: 18,
})

paragraph.appendBlock({
  text: 'Approved for publication',
  textStyle: { italic: true },
})

const list = page.insertList({
  text: 'Verify content',
  kind: univerAPI.Enum.PdfListKind.UNORDERED,
  preset: univerAPI.Enum.PdfListPresetId.UNORDERED_DISC,
  left: 36,
  top: 132,
  width: 240,
  height: 108,
})

list.insertItem(1, { text: 'Export final PDF' })
list.insertItem(2, { text: 'Archive source', level: 1 })
```

リストレベルの範囲は `0` から `8` です。項目のレベルを上げるには、その親として機能する先行項目も必要です。

## テーブルを編集する

```ts
const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Owner', 'Status', 'Docs', 'Ready'],
  left: 312,
  top: 36,
  width: 240,
  height: 108,
})

table.resize(3, 2)
table.getCell(2, 0).setText('Legal')
table.getCell(2, 1).setText('Review')
```

1 つのテーブルに含められるセルは最大 10,000 個です。`getPdfTableThemePresets()` は、テーブルテーマのワークフローに渡せる組み込みプリセット記述子を返します。

## 画像と注釈を追加する

```ts
const image = await page.insertImageAsync('/assets/signature.png', {
  left: 312,
  top: 180,
  width: 144,
  height: 72,
  opacity: 0.9,
})

image.setRotation(-4).bringToFront()

const highlight = page.insertAnnotation({
  annotationType: univerAPI.Enum.PdfAnnotationType.HIGHLIGHT,
  left: 36,
  top: 264,
  width: 180,
  height: 18,
})

highlight.setStyle({
  fill: { color: '#fde047' },
  opacity: 0.6,
})
```

Facade から挿入できる注釈は、ハイライト、下線、取り消し線、波線、インク注釈です。コアの列挙型には、この挿入 API が受け付けない追加の PDF 注釈サブタイプも含まれます。

## インポートしたテキストを置き換える

インポートしたネイティブテキストは `getTextSpans()` で読み取ります。テキスト範囲の置き換えは不可分な昇格操作です。Univer は対応するソース操作を抑制し、取得済みの位置に編集可能なテキストボックスを挿入します。

```ts
const matchingSpan = page.getTextSpans().find((span) => span.getText().includes('Draft'))

if (matchingSpan) {
  matchingSpan.replaceText('Final')
}
```

置き換え後はテキスト範囲を再度列挙してください。以前のスナップショットハンドルは無効になります。

## 要素を変換および削除する

すべての編集可能なページ要素は、変換と重なり順のメソッドを共有します。

```ts
image.setPosition(300, 180).setSize(180, 90).setVisible(true).setLocked(false).sendBackward()

const snapshot = pdf.save()
```

Facade の変更は Univer コマンドを通じて実行されます。ユニットがアクティブな間は、`snapshot.document` または `snapshot.editState` を直接変更しないでください。
