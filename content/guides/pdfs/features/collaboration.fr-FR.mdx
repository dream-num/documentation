Suivez l’[Intégration collaborative](/server/collaboration/browser-integration) pour exécuter l’exemple, connecter votre application et vérifier la persistance et les autorisations. Les détails et exemples Web/Server sont disponibles sur [Univer Office](/server/collaboration/quick-start).

Créez le Unit via une API métier authentifiée appelant Collaboration Service, puis chargez son identifiant dans le navigateur. Configurez HTTP, Session Ticket et WebSocket selon le [Quick Start](/server/collaboration/quick-start), puis la persistance et les [autorisations serveur](/server/collaboration/identity-and-authorization) pour la lecture, JOIN et les modifications.

<Callout>
  Avant d’utiliser ces API, vérifiez que le backend cible prend en charge les Unit PDF. Le bon fonctionnement de l’exemple Sheets ne prouve pas la prise en charge PDF.
</Callout>

## Charger un PDF collaboratif

Après avoir créé une unité PDF avec l'API du serveur ou `importPdfToUnitIdAsync`, chargez-la avec la façade de collaboration :

```ts
const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)

if (!pdf) {
  throw new Error(`PDF unit not found: ${unitId}`)
}

console.log(pdf.getId(), pdf.getName())
```

`loadPdfAsync` charge le snapshot du serveur, prépare la session de collaboration et renvoie un objet `FPdf`. Elle renvoie `null` lorsque l'unité ne peut pas être associée à un PDF.
