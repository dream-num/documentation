Univer PDFs 핵심 기능은 정식 PDF Unit, 영구 편집 레이어 및 브라우저 워크벤치를 제공합니다. 가져온 PDF 콘텐츠는 원본 기준으로 유지되고, 승인된 변경 사항은 Unit 스냅샷에 저장되어 현재 문서로 렌더링됩니다.

## 기능

- **PDF Unit 모델**: 원본 문서, 페이지 구조, 리소스 및 영구 편집 의도를 `IPdfUnitData`에 저장합니다.
- **페이지 및 요소 작업**: 페이지 탐색과 삽입은 물론 편집 가능한 텍스트, 목록, 표, 이미지, 구분선 및 주석을 지원합니다.
- **브라우저 워크벤치**: PDF 페이지 렌더링, 미리 보기, 선택, 편집 컨트롤, 클립보드 동작 및 검사기 UI를 제공합니다.
- **명령 파이프라인**: 승인된 변경 사항을 영구 명령과 변형 배치로 적용하여 저장, 실행 취소 및 다시 실행이 하나의 모델을 공유합니다.
- **Facade API**: PDF, 페이지, 요소 및 네이티브 텍스트 객체를 통해 PDF Unit을 생성, 조회, 편집 및 저장합니다.

## 프리셋 모드

Univer PDFs는 현재 프리셋 패키지를 제공하지 않습니다. PDF 애플리케이션은 플러그인 모드로 만드세요.

## 플러그인 모드

### 설치

```package-install
npm install @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui
```

### 사용법

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'

import '@univerjs-pro/pdfs/facade'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, PdfsUIEnUS),
  },
})

univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Untitled PDF' })
```

`UniverPdfsPlugin`은 PDF Unit과 영구 명령을 담당하고, `UniverPdfsUIPlugin`은 브라우저 뷰어와 편집 컨트롤을 담당합니다. 보기 전용 UI에는 `{ editor: { enabled: false } }`를 지정하세요. 협업 기반 애플리케이션은 필요한 협업 플러그인과 함께 `@univerjs-pro/pdfs-editor`를 추가할 수 있습니다.

## Facade API

부수 효과 가져오기 `@univerjs-pro/pdfs/facade`는 `FUniver`에 PDF API를 추가합니다. 원본 문서 없이 `createPdf()`를 호출하면 빈 A4 PDF가 만들어지고, `save()`가 반환한 스냅샷을 전달하면 Unit이 복원됩니다.

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  const page = pdf.getPageByIndex(0) ?? pdf.insertPage()
  const snapshot = pdf.save()
}
```

실행 중인 PDF는 Facade 메서드나 명령으로 업데이트하고 `snapshot.document` 또는 `snapshot.editState`를 직접 변경하지 마세요.
