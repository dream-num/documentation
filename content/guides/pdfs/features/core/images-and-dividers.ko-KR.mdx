PDF 이미지 관리, 편집 가능한 자원입니다. URL, UUID, base64 문자열, 또는 `insertImageAsync()`에 blob 소스를 전달하거나 단계에 삽입하는 분리 된 빌더를 사용합니다.

## 이미지 삽입

```ts
const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  {
    left: 36,
    top: 36,
    width: 144,
    height: 72,
    opacity: 0.9,
  }
)

image.setRotation(-4).bringToFront()
```

자동 소스 탐지는 절대 `http` 및 `https` URL을 인식합니다. URL 소스로 상대적인 경로에 허용되지 않습니다. 따라서 절대 URL을 사용하므로 유효한 관리 리소스 UUID 또는 Base64 데이터.

## 이미지 빌더 사용

```ts
const imageInfo = page
  .newImage()
  .setSource('https://example.com/assets/chart.png')
  .setAbsolutePosition(216, 36)
  .setSize(240, 135)
  .setOpacity(0.85)
  .build()

const chart = page.insertImage(imageInfo)
```

`build()`는 분리된 객체에 작동하며 PDF를 수정하지 않습니다. `insertImage()`로 결과를 전달하십시오. 기존 관리 이미지를 업데이트하려면 라이브 `setSource()` 방법 및 라이브 변환, 작물 및 불투명 방법을 사용하십시오.

## 이미지 자르기

이미지를 선택하고 속성 검사기를 열어 **이미지 자르기**를 선택합니다. 자르기 영역이나 그 모서리를 드래그하여 표시할 창을 설정하고, 필요하면 고정 비율을 사용한 뒤 자르기를 적용하세요. 자르기는 영구적이며 undo 및 redo에 참여합니다.

`FPdfImage.getCrop()`는 PDF 포인트 단위로, 이미지 프레임의 왼쪽 위 모서리에서 측정한 자르기 창을 반환하며, 이미지가 잘리지 않았으면 `null`을 반환합니다. `setCrop({ left, top, right, bottom })`는 같은 좌표를 적용하고 `right > left`와 `bottom > top`을 요구하며, 유한하지 않거나 비어 있는 사각형에는 `RangeError`를 던집니다.

자르기 값은 이미지 프레임을 기준으로 유지되므로, 이미지 크기를 조정하거나 회전해도 같은 표시 영역이 유지됩니다.

## 구분선 추가

```ts
const divider = page.insertDivider({
  left: 36,
  top: 144,
  width: 420,
  strokeWidth: 1,
})

divider.setStroke({
  width: 2,
  color: '#3366ff',
})
```

디바이더 기하학 및 스트로크 길이는 PDF 포인트로 측정됩니다. `getStroke()`는 분리된 스냅 샷을 반환하고 `setStroke()`은 기하학을 수정하지 않고 스트로크를 대체합니다.

`FPdfImage`는 `getSource()`, `getImageSourceType()`, `setSource()`, `getCrop()`, `setCrop()`, `getOpacity()`, `setOpacity()`, `remove()`도 제공합니다. 이미지 불투명도는 `0`부터 `1` 사이여야 합니다.
