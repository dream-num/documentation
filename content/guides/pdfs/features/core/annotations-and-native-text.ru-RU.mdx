title: Аннотации и нативный текст
description: Вставляйте поддерживаемые аннотации PDF и преобразуйте импортированный нативный текст в редактируемые текстовые поля.
---

Редактируемые аннотации являются сохраняемыми наложениями. Импортированный текст остаётся нативным, пока видимый текстовый фрагмент не будет преобразован через фасад.

## Вставка аннотаций

```ts
const highlight = page.insertAnnotation({
  annotationType: univerAPI.Enum.PdfAnnotationType.HIGHLIGHT,
  left: 36,
  top: 72,
  width: 180,
  height: 18,
  markup: {
    color: '#fde047',
    opacity: 0.6,
  },
})
```

Фасадная вставка поддерживает выделение, подчеркивание, вычеркивание, висячие и чернильные аннотации. Аннотации чернил требуют непустых путей, и этот вставочный API отклоняет другие подтипы аннотаций ядра.

## Чтение данных и стиля аннотации

```ts
const markup = highlight.getMarkup()
const style = highlight.getStyle()

highlight.setStyle({
  stroke: { color: '#ca8a04', width: 1 },
  opacity: 0.75,
})
```

`getMarkup()` и `getInk()` возвращают отсоединенную геометрию, измеренную в точках PDF. `setStyle()` обновляет поддерживаемые поля заполнения, хода и непрозрачности. Opacity должен быть между `0`и `1`.

## Замена импортированного нативного текста

```ts
const matchingSpan = page
  .getTextSpans()
  .find((span) => span.getText().includes('Draft'))

if (matchingSpan) {
  const textBox = matchingSpan.replaceText('Final')
  textBox.setTextStyle({ bold: true })
}
```

`getTextSpans()` возвращает снимки нативного текста, который в настоящее время виден и не подавляется. `replaceText()` подавляет операцию источника и вставляет редактируемый `FPdfTextBox` в захваченное положение в качестве одного атомного шага.

`FPdfTextSpan` - это ручка для моментального снимка, которая после замены устаревает. Позвоните `getTextSpans()` еще раз перед следующей нативной текстовой операцией.
