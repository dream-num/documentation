PDFファサードは、PDFユニットとページエントリポイントを`FUniver`に追加します。 APIオブジェクトを作成する前に、副作用のエントリをインポートします。

## PDF Facade を有効にする

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

`UniverPdfsPlugin`インスタンスにUniverを登録して、アプリケーションはPDFユニットをホストすることができます。

## PDF ユニットを作成、取得、保存する

`document`が省略されると、`createPdf()`は1つの空白A4ページでユニットを作成します。 ユニットを復元するには、`save()`で以前に返されたスナップショットを渡します。

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
const snapshot = pdf.save()
```

ファサードメソッドやコマンドを使用して、実行中のPDFを更新します。保存されたスナップショットは、永続データを分離します。

## ページに入る

`FPdfPage`はページの編集可能な上敷および輸入された原文のための共通の記入項目ポイントです:

```ts
const firstPage = pdf.getPageByIndex(0) ?? pdf.insertPage()
const elements = firstPage.getElements()
const nativeText = firstPage.getTextSpans()
```

[ページと要素](/guides/pdfs/features/core/pages-and-elements)、[テキストとリスト](/guides/pdfs/features/core/text-and-lists)の[テーブル](/guides/pdfs/features/core/tables)は、[画像とディバイダー](/guides/pdfs/features/core/images-and-dividers)または[注釈とネイティブテキスト](/guides/pdfs/features/core/annotations-and-native-text)を集中的に操作する。

## PDF ユニットをアンロードする

不要になったときにIDでPDFユニットをアンロードします。アプリケーション全体が破壊される場合にのみ、root `univer`インスタンスをディスポースします。

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  univerAPI.disposeUnit(pdf.getId())
}
```

正確なシグネチャと戻り値の型は [PDF Facade リファレンス](/reference/facade/pdf)を参照してください。
