Univer PDFs 提供正式的 PDF Unit、持久化編輯層和瀏覽器工作臺。匯入的 PDF 內容始終是基線，已接受的修改儲存在 Unit 快照中，並渲染為當前文件。

## 功能

- **PDF Unit 模型**：在 `IPdfUnitData` 中儲存來源文件、頁面結構、資源和持久化編輯意圖。
- **頁面與元素操作**：支援頁面導航和頁面插入，並處理可編輯的文字、列表、表格、圖片、分隔線和批註。
- **瀏覽器工作臺**：渲染 PDF 頁面和縮圖，處理選擇、編輯控制元件和剪貼簿行為，並提供檢查器介面。
- **命令管線**：已接受的修改透過持久化命令和變更批次應用，儲存、撤銷和重做共用同一套模型。
- **Facade API**：透過面向應用的 PDF、頁面、元素和原生文字物件建立、查詢、編輯和儲存 PDF Unit。

## 外掛程式模式

### 安裝

```package-install
npm install @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui
```

### 使用

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/pdfs/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, PdfsUIEnUS),
  },
})

univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Untitled PDF' })
```

### 外掛設定 [#plugin-configuration]

`UniverLicensePlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 用戶端授權檔的內容。 |

#### `UniverPdfsUIPlugin`

| <span data-config-options="">設定項目</span> | 類型 | 預設值 | 作用 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | 啟用 PDF 編輯器或 Slides 編輯器控制元件；關閉後僅顯示內容。 |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | 啟用 PDF 編輯器或 Slides 編輯器控制元件；關閉後僅顯示內容。 |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | 在瀏覽器 Worker 中渲染縮圖。 |

`UniverPdfsPlugin` 負責 PDF Unit 和持久化命令，`UniverPdfsUIPlugin` 負責瀏覽器檢視器及其編輯控制元件。僅需檢視介面時，可在註冊 `UniverPdfsUIPlugin` 時傳入 `{ editor: { enabled: false } }`。基於協同的應用還可以註冊 `@univerjs-pro/pdfs-editor`，以及它所依賴的協同外掛。

| <ConfigKey depth={2}>params</ConfigKey> | `Record<string, unknown> \| (() => Record<string, unknown> \| undefined)` |  | 傳給命令的參數，或返回這些參數的函式。 |
| <ConfigKey depth={2}>gridLayout</ConfigKey> | `object` |  | 在格線功能區中的位置。 |
| <ConfigKey depth={3}>row</ConfigKey> | `1 \| 2` |  | 群組內第 1 列或第 2 列。 |
| <ConfigKey depth={3}>column</ConfigKey> | `number` |  | 群組內的欄號，從 1 開始。 |
| <ConfigKey depth={3}>rowSpan</ConfigKey> | `1 \| 2` | `1` | 占用的列數。 |
| <ConfigKey depth={3}>columnSpan</ConfigKey> | `number` | `1` | 占用的欄數。 |
| <ConfigKey depth={3}>showLabel</ConfigKey> | `boolean` | `false` | 在圖示旁顯示標題。 |
| <ConfigKey depth={3}>width</ConfigKey> | `number` |  | 控制項寬度，單位為像素。 |
| <ConfigKey depth={3}>minWidth</ConfigKey> | `number` |  | 分組移入更多選單前的最小寬度，單位為畫素。 |

| `ribbonType` | `RibbonType` | `classic` | 選擇 Ribbon 版面。 |

`menu` 和 `ribbonType` 應設定在已有的 `UniverUIPlugin` 註冊配置中。它們屬於共享 UI 配置，不屬於 `UniverPdfsUIPlugin`。下面的範例使用 PDFs 的實際選單項 ID：

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'pdf.menu.tool.highlight': {
    order: 1,
    gridLayout: { row: 2, column: 1 },
  },
  'pdf.menu.tool.ink': {
    order: 0,
    gridLayout: { row: 1, column: 1 },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order` 按數值從小到大排列同級頁籤、分組或選單項，不會將選單項移動到其他分組。選單項 ID 可從其 `data-u-command` 屬性取得，不應假設它與命令 ID 相同。

## 預設模式

Univer PDFs 目前未提供預設套件。PDF 應用請使用外掛模式建立。

## 編輯與檢視控制 [#ribbon-controls]

開始工具欄提供複製、剪下、貼上、工具模式和批註工具。插入工具欄提供頁面、文字框、段落、列表、表格、圖片和分隔線。檢視工具欄提供縮放、全屏、批註顯隱和連續滾動。選中文字或表格後會顯示對應的上下文控制元件，包括屬性面板和表格樣式。這些 Ribbon 控制元件需要 `UniverPdfsUIPlugin` 保持預設的 `editor.enabled: true` 設定。

## 用 Facade API 更新選單 [#menu-facade]

### 執行階段更新

先匯入 `@univerjs/ui/facade`，再透過 `FUniver.newAPI(univer)` 建立 `univerAPI`。[`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) 會合並修改、保留未指定的欄位並重新整理選單。覆蓋配置同樣適用於之後註冊的選單。

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'pdf.menu.tool.highlight': { gridLayout: { row: 2, column: 1, showLabel: true, width: 96 } },
})
```

`gridLayout` 僅影響網格 Ribbon。每個分組固定兩行，`row` 和 `column` 均從 1 開始。顯式指定的位置優先於 `order` 確定的視覺順序，因此交換兩個已佔用的單元格時，應同時修改兩個選單項。未指定的可選欄位沿用已有配置或 Schema。跨行、跨列、標籤、寬度和圖示尺寸見 [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout)。

請保持 `UniverPdfsUIPlugin` 的編輯功能開啟：`editor.enabled: false` 會跳過該品類 Ribbon 的註冊，選單覆蓋配置也不會建立缺失的按鈕。

自定義按鈕和子選單入口同樣如此：[`createMenu()`、`createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem) 也接受 `order` 和 `gridLayout`，並透過 `appendTo()` 完成註冊。彈出選單內容不使用 Ribbon 的網格版面配置。
