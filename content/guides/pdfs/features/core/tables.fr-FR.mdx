---
title: Tableaux
description: Insérez, redimensionnez, stylisez et modifiez des tableaux PDF structurés avec la façade.
---

`FPdfTable` conserve une grille structurée avec des wrappers de cellule stables et une histoire de texte modifiable par cellule.

## Insérer et modifier un tableau

```ts
const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Owner', 'Status', 'Docs', 'Ready'],
  left: 36,
  top: 36,
  width: 360,
  height: 108,
})

table.resize(3, 2)
table.getCell(2, 0).setText('Legal')
table.getCell(2, 1).setText('Review')
```

Les nombres de lignes et de colonnes doivent être des entiers positifs sûrs, et un tableau ne peut pas dépasser 10 000 cellules. Le redimensionnement conserve les cellules qui se chevauchent par position.

## Appliquer un thème de tableau

```ts
const [preset] = univerAPI.getPdfTableThemePresets()

if (preset) {
  table.setTheme({
    styleId: preset.id,
    options: { firstRow: true },
  })
}
```

`getPdfTableThemePresets()` retourne des descripteurs détachés `{ id, group }`. Utilisez l'`id` d'un préréglage comme `styleId` ; ne transmettez pas directement le descripteur à `setTheme()`.

## Styles de cellule

```ts
table.getCell(0, 0).setStyle({
  fill: { color: '#eef3ff' },
  fontColor: '#1d4ed8',
  horizontalAlignment: univerAPI.Enum.HorizontalAlign.CENTER,
  verticalAlign: univerAPI.Enum.PdfTableCellVerticalAlign.MIDDLE,
})
```

`FPdfTableCell.setStyle()` accepte les champs du conteneur ainsi que `fontColor` et `horizontalAlignment` pour toute la cellule. Utilisez `PdfTableCellVerticalAlign` via `univerAPI.Enum`.

Les méthodes de tableau comprennent `getRowCount()`, `getColumnCount()`, `getCell()`, `resize()`, `getTheme()` et `setTheme()`. Les méthodes de cellule comprennent `getText()`, `setText()`, `getStyle()` et `setStyle()`.
