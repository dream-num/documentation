title: 表格
description: 透過 Facade API 插入、調整大小、設定樣式並編輯結構化 PDF 表格。
---

`FPdfTable` 維護一個結構化網格，單元格包裝器保持穩定，每個單元格儲存一個可編輯的文字 story。

## 插入與編輯表格

```ts
const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Owner', 'Status', 'Docs', 'Ready'],
  left: 36,
  top: 36,
  width: 360,
  height: 108,
})

table.resize(3, 2)
table.getCell(2, 0).setText('Legal')
table.getCell(2, 1).setText('Review')
```

行數和列數必須為正安全整數，且表格最多包含 10,000 個單元格。調整大小時，重疊區域內的單元格保持原有位置。

## 套用表格主題

```ts
const [preset] = univerAPI.getPdfTableThemePresets()

if (preset) {
  table.setTheme({
    styleId: preset.id,
    options: { firstRow: true },
  })
}
```

`getPdfTableThemePresets()` 返回獨立的 `{ id, group }` 描述符。應將預設的 `id` 作為 `styleId` 傳入，不要將描述符本身傳給 `setTheme()`。

## 儲存格樣式

```ts
table.getCell(0, 0).setStyle({
  fill: { color: '#eef3ff' },
  fontColor: '#1d4ed8',
  horizontalAlignment: univerAPI.Enum.HorizontalAlign.CENTER,
  verticalAlign: univerAPI.Enum.PdfTableCellVerticalAlign.MIDDLE,
})
```

`FPdfTableCell.setStyle()` 接受容器欄位，以及作用於整個單元格的 `fontColor` 和 `horizontalAlignment`。`PdfTableCellVerticalAlign` 應透過 `univerAPI.Enum` 使用。

## 表格操作

選中儲存格即可顯示**表格操作**。桌面端這些操作位於所選表格的屬性面板中，可透過上下文中的**表格**頁籤開啟。行動端則在選取工具列的**表格操作**中提供同一組操作。操作包括選取儲存格、合併或拆分儲存格，以及在兩側插入行或列。這些操作還可以刪除行、列和整張表格，並設定**行高**或**列寬**。合併需要選取由多個儲存格組成的矩形範圍。

表格編輯會持久儲存，並進入撤銷與重做歷史。

表格方法包括 `getRowCount()`、`getColumnCount()`、`getCell()`、`resize()`、`getTheme()` 和 `setTheme()`；單元格方法包括 `getText()`、`setText()`、`getStyle()` 和 `setStyle()`。
