Univer PDFs обеспечивает формальный блок PDF, прочный слой редактирования и рабочий стол браузера. Импортированный PDF остается базовым; принятые изменения хранятся в снимке блока и визуализируются в качестве текущего документа.

## Возможности

- **Модель PDF Unit**: хранит исходный документ, структуру страниц, ресурсы и постоянные правки в `IPdfUnitData`.
- **Операции с страницами и элементами**: Вставляет страницы, перемещается между страницами и работает с редактируемым текстом, списками, таблицами, изображениями, разделителями и аннотациями.
- **Рабочая панель браузера**: Отображает PDF-страницы и миниатюры, управляет выбором, редактированием элементов управления и поведением буфера обмена и предоставляет пользовательский интерфейс инспектора.
- **Командный трубопровод**: Применяет принятые изменения с помощью прочных команд и пакетов мутаций, поэтому сохраняйте, отменяйте и переделывайте работу на одной модели.
- **Facade API**: создаёт, находит, изменяет и сохраняет PDF Unit через объекты PDF, страниц, элементов и исходного текста.

## Режим плагинов

### Установка

```package-install
npm install @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui
```

### Использование

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/pdfs/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, PdfsUIEnUS),
  },
})

univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Untitled PDF' })
```

### Настройка плагинов [#plugin-configuration]

`UniverLicensePlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| `license` | `string` |  | Содержимое файла клиентской лицензии. |

#### `UniverPdfsUIPlugin`

| <span data-config-options="">Параметр</span> | Тип | По умолчанию | Действие |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | Включает редактор PDF или элементы управления редактором Slides. |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | Включает редактор PDF или элементы управления редактором Slides. |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | Отображает миниатюры в браузере Worker. |

`UniverPdfsPlugin` владеет блоком PDF и прочными командами. `UniverPdfsUIPlugin` обладает браузером просмотра и его элементами управления редактированием. Для пользовательского интерфейса, предназначенного только для просмотра, зарегистрируйте `UniverPdfsUIPlugin` с помощью `{ editor: { enabled: false } }`. Поддерживаемые совместно приложения также могут регистрировать `@univerjs-pro/pdfs-editor` вместе с плагинами для совместной работы, которые ему требуются.

Настройте `menu` и `ribbonType` в существующей регистрации `UniverUIPlugin`. Это общие параметры пользовательского интерфейса и не принадлежат `UniverPdfsUIPlugin`, в примере используются фактические идентификаторы меню из PDF-файлов:

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'pdf.menu.tool.highlight': {
    order: 1,
    gridLayout: { row: 2, column: 1 },
  },
  'pdf.menu.tool.ink': {
    order: 0,
    gridLayout: { row: 1, column: 1 },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order` сортирует вкладки, группы или пункты одного уровня по возрастанию и не переносит пункты в другую группу. Идентификатор пункта можно получить из атрибута `data-u-command`; он не обязательно совпадает с идентификатором команды.

## Режим Preset

Univer PDF в настоящее время не предоставляет предустановленный пакет. Создавайте PDF-приложения в режиме плагина.

## Средства редактирования и просмотра [#ribbon-controls]

Вкладка Пуск предоставляет инструменты копирования, вырезания, вставки, режима инструмента и аннотации. Вставка предоставляет страницы, текстовые поля, абзацы, списки, таблицы, изображения и разделители. Просмотр обеспечивает зум, полноэкранный режим, видимость аннотации и непрерывную прокрутку. Выбор текста или таблицы открывает ее контекстуальные элементы управления, включая инспектора и стиль таблицы. Эти элементы управления лентой требуют настройки `editor.enabled: true` по умолчанию в `UniverPdfsUIPlugin`.

## Обновление меню через Facade API [#menu-facade]

### Обновление во время работы

Импорт `@univerjs/ui/facade` перед созданием `univerAPI` с `FUniver.newAPI(univer)`. [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) объединяет изменения, сохраняет неуточненные поля и обновляет меню. Переопределения также применяются к меню, зарегистрированным позже.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'pdf.menu.tool.highlight': { gridLayout: { row: 2, column: 1, showLabel: true, width: 96 } },
})
```

`gridLayout` влияет только на сетку Ribbon. Каждая группа имеет два ряда, а `row` и `column` начинаются с 1. Явная позиция имеет приоритет над визуальным порядком, установленным `order`, поэтому обновляйте оба элемента при замене двух занятых ячеек. Дополнительные поля наследуют существующую конфигурацию или схему. См. [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout) для пролетов, меток, ширины и размеров значков.

Продолжайте редактировать в `UniverPdfsUIPlugin`: `editor.enabled: false` пропускает регистрацию продукта Ribbon, а переопределения меню не регистрируют отсутствующие кнопки.

Для пользовательских кнопок и триггеров подменю [`createMenu()` и `createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem) также принимает `order` и `gridLayout`; `appendTo()` регистрирует их.Всплывающее содержимое не использует макет сетки Ribbon.
