PDF Facade добавляет PDF-блоки и точки входа на страницу в `FUniver`. Импортируйте вход с побочным эффектом перед созданием объекта API.

## Подключение PDF Facade

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

Зарегистрируйте `UniverPdfsPlugin` на экземпляре Univer, чтобы приложение могло размещать PDF-единицы.

## Создание, поиск и сохранение модулей PDF

Когда `document` опущен, `createPdf()` создает блок с одной пустой страницей A4. Чтобы восстановить блок, передайте снимок, ранее возвращенный `save()`.

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
const snapshot = pdf.save()
```

Используйте методы или команды Facade для обновления запущенного PDF. Сохраненный снимок - это отсоединенные данные о стойкости.

## Вход на страницу

`FPdfPage` является общей точкой входа для редактируемых наложений страницы и импортируемого нативного текста:

```ts
const firstPage = pdf.getPageByIndex(0) ?? pdf.insertPage()
const elements = firstPage.getElements()
const nativeText = firstPage.getTextSpans()
```

Для целенаправленных операций продолжайте с [Страницы и элементы](/guides/pdfs/features/core/pages-and-elements), [Текст и списки](/guides/pdfs/features/core/text-and-lists), [Таблицы](/guides/pdfs/features/core/tables), [Изображения и разделители](/guides/pdfs/features/core/images-and-dividers) или [Аннотации и родной текст](/guides/pdfs/features/core/annotations-and-native-text).

## Выгрузка модуля PDF

Выгрузите PDF-блок по ID, когда он больше не нужен. Удалите корень `univer` только тогда, когда все приложение будет уничтожено.

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  univerAPI.disposeUnit(pdf.getId())
}
```

Точные сигнатуры и типы возвращаемых значений приведены в [справочнике PDF Facade](/reference/facade/pdf).
