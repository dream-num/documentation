Univer PDFs 提供正式的 PDF Unit、持久化编辑层和浏览器工作台。导入的 PDF 内容始终是基线，已接受的修改存储在 Unit 快照中，并渲染为当前文档。

## 功能

- **PDF Unit 模型**：在 `IPdfUnitData` 中存储源文档、页面结构、资源和持久化编辑意图。
- **页面与元素操作**：支持页面导航和页面插入，并处理可编辑的文本、列表、表格、图片、分隔线和批注。
- **浏览器工作台**：渲染 PDF 页面和缩略图，处理选择、编辑控件和剪贴板行为，并提供检查器界面。
- **命令管线**：已接受的修改通过持久化命令和变更批次应用，保存、撤销和重做共用同一套模型。
- **Facade API**：通过面向应用的 PDF、页面、元素和原生文本对象创建、查找、编辑和保存 PDF Unit。

## 插件模式

### 安装

```package-install
npm install @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui
```

### 使用

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/pdfs/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, PdfsUIEnUS),
  },
})

univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Untitled PDF' })
```

### 插件配置 [#plugin-configuration]

`UniverLicensePlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `license` | `string` |  | 客户端许可证文件的内容。 |

#### `UniverPdfsUIPlugin`

| <span data-config-options="">配置项</span> | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | 启用 PDF 编辑器或 Slides 编辑器控件；关闭后仅显示内容。 |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | 启用 PDF 编辑器或 Slides 编辑器控件；关闭后仅显示内容。 |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | 在浏览器 Worker 中渲染缩略图。 |

`UniverPdfsPlugin` 负责 PDF Unit 和持久化命令，`UniverPdfsUIPlugin` 负责浏览器查看器及其编辑控件。仅需查看界面时，可在注册 `UniverPdfsUIPlugin` 时传入 `{ editor: { enabled: false } }`。基于协同的应用还可以注册 `@univerjs-pro/pdfs-editor`，以及它所依赖的协同插件。

`menu` 和 `ribbonType` 应设置在已有的 `UniverUIPlugin` 注册配置中。它们属于共享 UI 配置，不属于 `UniverPdfsUIPlugin`。下面的示例使用 PDFs 的实际菜单项 ID：

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'pdf.menu.tool.highlight': {
    order: 1,
    gridLayout: { row: 2, column: 1 },
  },
  'pdf.menu.tool.ink': {
    order: 0,
    gridLayout: { row: 1, column: 1 },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order` 按数值从小到大排列同级页签、分组或菜单项，不会将菜单项移动到其他分组。菜单项 ID 可从其 `data-u-command` 属性获取，不应假设它与命令 ID 相同。

## 预设模式

Univer PDFs 目前未提供预设包。PDF 应用请使用插件模式创建。

## 编辑与视图控制 [#ribbon-controls]

PDF Ribbon 基于 Univer 共享的 Ribbon 构建。开始页签提供撤销与重做、剪贴板操作、交互模式选择器、页面管理与插入，以及打印。插入页签增加文本框、图片、段落、分隔线、表格和列表。批注页签将高亮、下划线和删除线与自由绘制及画笔选项归为一组。视图页签提供缩放、全屏、批注显隐、连续滚动和属性面板。选中文本、表格或图片时，会打开对应的文本、表格或图片上下文页签，属性面板、表格样式和图片变换操作也位于其中。这些 Ribbon 控件需要 `UniverPdfsUIPlugin` 保持默认的 `editor.enabled: true` 设置。

## 用 Facade API 更新菜单 [#menu-facade]

### 运行时更新

先导入 `@univerjs/ui/facade`，再通过 `FUniver.newAPI(univer)` 创建 `univerAPI`。[`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) 会合并修改、保留未指定的字段并刷新菜单。覆盖配置同样适用于之后注册的菜单。

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'pdf.menu.tool.highlight': { gridLayout: { row: 2, column: 1, showLabel: true, width: 96 } },
})
```

`gridLayout` 仅影响网格 Ribbon。每个分组固定两行，`row` 和 `column` 均从 1 开始。显式指定的位置优先于 `order` 确定的视觉顺序，因此交换两个已占用的单元格时，应同时修改两个菜单项。未指定的可选字段沿用已有配置或 Schema。跨行、跨列、标签、宽度和图标尺寸见 [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout)。

请保持 `UniverPdfsUIPlugin` 的编辑功能开启：`editor.enabled: false` 会跳过该品类 Ribbon 的注册，菜单覆盖配置也不会创建缺失的按钮。

自定义按钮和子菜单入口同样如此：[`createMenu()`、`createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem) 也接受 `order` 和 `gridLayout`，并通过 `appendTo()` 完成注册。弹出菜单内容不使用 Ribbon 的网格布局。
