API редактирования PDF построены на командах Univer, и они участвуют в отмене и переделке, когда команда имеет обратную операцию.Начните с темы, которая соответствует контенту, который вам нужно изменить.

## Темы редактирования

- [Страницы и элементы](/guides/pdfs/features/core/pages-and-elements) охватывает вставку страниц, перечисление редактируемых наложений и преобразование, укладку, блокировку или удаление элементов.
- [Текст и списки](/guides/pdfs/features/core/text-and-lists) охватывает текстовые поля, блоки абзацев и семантические списки.
- [Таблицы](/guides/pdfs/features/core/tables) охватывает вставку и изменение размера сеток, обновление ячеек и применение тем.
- [Изображения и разделители](/guides/pdfs/features/core/images-and-dividers) охватывает управляемые изображения и векторные делители.
- [Аннотации и родной текст](/guides/pdfs/features/core/annotations-and-native-text) охватывает поддерживаемые аннотации и способы продвижения импортного текста.

## Объединение операций

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  { left: 36, top: 36, width: 144, height: 72 }
)

image.setRotation(-4).bringToFront()
```

Значения размещения фасада измеряются в точках PDF. Для изображения, которое исходит из URL, используйте абсолютный URL `http` или `https`. Автоматическое обнаружение источника не принимает относительные пути.

Для создания блока, поиска, сохранения и полного обзора обертки см. [Univer PDF API](/guides/pdfs/features/core/pdfs-api).
