API редактирования PDF выполняются через команды Univer и участвуют в отмене и повторе при наличии обратной операции. Начните с темы, соответствующей изменяемому содержимому.

## Темы редактирования

- [Страницы и элементы](/guides/pdfs/features/core/pages-and-elements): вставка страниц, перечисление редактируемых наложений, преобразование, порядок, блокировка и удаление.
- [Текст и списки](/guides/pdfs/features/core/text-and-lists): редактирование текстовых полей, блоков абзацев и семантических списков.
- [Таблицы](/guides/pdfs/features/core/tables): вставка и изменение размера сеток, обновление ячеек и применение тем.
- [Изображения и разделители](/guides/pdfs/features/core/images-and-dividers): вставка управляемых изображений и векторных разделителей.
- [Аннотации и нативный текст](/guides/pdfs/features/core/annotations-and-native-text): добавление поддерживаемых аннотаций и преобразование импортированного текста.

## Объединение операций

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  { left: 36, top: 36, width: 144, height: 72 }
)

image.setRotation(-4).bringToFront()
```

Размещение в фасаде задаётся в пунктах PDF. Для изображений по URL используйте абсолютные адреса `http` или `https`; автоопределение не принимает относительные пути.

Создание, поиск и сохранение модулей, а также полный обзор обёрток приведены в [API Univer PDFs](/guides/pdfs/features/core/pdfs-api).
