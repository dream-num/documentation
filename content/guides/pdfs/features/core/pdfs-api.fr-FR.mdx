title: Univer PDFs API
description: Créez, trouvez, enregistrez, ouvrez et déchargez des unités PDF avec PDF Facade API.
---

PDF Facade ajoute à `FUniver` les unités PDF et les points d'entrée des pages. Importez son point d'entrée à effet de bord avant de créer l'objet API.

## Activer PDF Facade

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

Enregistrez `UniverPdfsPlugin` dans l'instance Univer afin que l'application puisse héberger des unités PDF.

## Créer, trouver et enregistrer des unités PDF

Lorsque `document` est omis, `createPdf()` crée une unité avec une page A4 vierge. Transmettez un instantané précédemment renvoyé par `save()` pour restaurer une unité.

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
const snapshot = pdf.save()
```

Utilisez les méthodes Facade ou les commandes pour mettre à jour un PDF en cours d'exécution. Traitez l'instantané enregistré comme des données de persistance détachées.

## Entrer dans une page

`FPdfPage` est le point d'entrée commun pour les superpositions modifiables et le texte natif importé d'une page :

```ts
const firstPage = pdf.getPageByIndex(0) ?? pdf.insertPage()
const elements = firstPage.getElements()
const nativeText = firstPage.getTextSpans()
```

Continuez avec [Pages et éléments](/guides/pdfs/features/core/pages-and-elements), [Texte et listes](/guides/pdfs/features/core/text-and-lists), [Tableaux](/guides/pdfs/features/core/tables), [Images et séparateurs](/guides/pdfs/features/core/images-and-dividers) ou [Annotations et texte natif](/guides/pdfs/features/core/annotations-and-native-text) pour les opérations détaillées.

## Décharger une unité PDF

Déchargez une unité PDF par son identifiant lorsqu'elle n'est plus nécessaire. Détruisez l'instance racine `univer` uniquement lorsque toute l'application est fermée.

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  univerAPI.disposeUnit(pdf.getId())
}
```

Pour les signatures et types de retour exacts, consultez la [référence PDF Facade](/reference/facade/pdf).
