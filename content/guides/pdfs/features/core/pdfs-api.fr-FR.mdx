La Facade PDF ajoute des unités PDF et des points d'entrée de page à `FUniver`. Importez l'entrée des effets secondaires avant de créer l'objet API.

## Activer PDF Facade

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

Enregistrez `UniverPdfsPlugin` sur l'instance Univer afin que l'application puisse héberger des unités PDF.

## Créer, trouver et enregistrer des unités PDF

Lorsque `document` est omis, `createPdf()` crée une unité avec une page A4 vide. Pour restaurer une unité, passez un instantané précédemment retourné par `save()`.

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
const snapshot = pdf.save()
```

Utilisez les méthodes ou les commandes Facade pour mettre à jour un PDF en cours d'exécution. Un instantané enregistré est des données de persistance détachées.

## Ajouter des pages depuis un autre PDF [#append-pages]

`FPdf.appendPdf(source)` ajoute toutes les pages d'un instantané `IPdfUnitData` et enregistre la modification dans l'historique d'annulation et de rétablissement. La méthode renvoie `false` lorsque le PDF n'est plus ouvert.

La façade d'échange ajoute deux méthodes pour un PDF déjà ouvert. `univerAPI.appendPdfAsync(file, unitId?)` importe le fichier et ajoute ses pages au PDF indiqué, ou au PDF actif lorsque l'ID d'unité est omis. Elle renvoie `false` lorsqu'il n'y a pas de cible ou que les pages ne peuvent pas être ajoutées. `univerAPI.exportPdfAsync(unitId?)` valide le texte encore en cours d'édition sur le canevas puis exporte le PDF ouvert. Elle renvoie `undefined` lorsque la validation échoue ou que le document n'est plus ouvert.

Ces méthodes d'échange sont ajoutées à `FUniver` par `@univerjs-pro/pdfs-exchange-client/facade` :

```ts
const pdf = univerAPI.getActivePdf()
pdf?.appendPdf(importedSnapshot)

await univerAPI.appendPdfAsync(file)          // current PDF
await univerAPI.appendPdfAsync(file, unitId)  // specific PDF
const exported = await univerAPI.exportPdfAsync()
```

## Entrer dans une page

`FPdfPage` est le point d'entrée commun pour les superpositions modifiables d'une page et le texte natif importé :

```ts
const firstPage = pdf.getPageByIndex(0) ?? pdf.insertPage()
const elements = firstPage.getElements()
const nativeText = firstPage.getTextSpans()
```

Pour les opérations ciblées, continuer avec [Pages et éléments](/guides/pdfs/features/core/pages-and-elements), [Texte et listes](/guides/pdfs/features/core/text-and-lists), [Tableaux](/guides/pdfs/features/core/tables), [Images et séparateurs](/guides/pdfs/features/core/images-and-dividers) ou [Annotations et texte autochtone](/guides/pdfs/features/core/annotations-and-native-text).

## Décharger une unité PDF

Déchargez une unité PDF par ID quand elle n'est plus nécessaire. Jetez l'instance root `univer` seulement lorsque l'application entière est détruite.

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  univerAPI.disposeUnit(pdf.getId())
}
```

Pour les signatures et types de retour exacts, consultez la [référence PDF Facade](/reference/facade/pdf).
