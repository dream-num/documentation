Univer PDFは、正式なPDFユニット、耐久性のある編集層、およびブラウザのワークベンチを提供します。 インポートされたPDFはベースラインのままです。 受け入れられた変更は、ユニットのスナップショットに保存され、現在の文書としてレンダリングされます。

## 機能

- **PDF Unit モデル**：ソース文書、ページ構造、リソース、永続的な編集内容を `IPdfUnitData` に保存します。
- **ページと要素の操作**:ページをインサートし、ページ間をナビゲートし、編集可能なテキスト、リスト、テーブル、画像、ディバイダー、および注釈で動作します。
- **ブラウザのワークベンチ**: PDFページとサムネイルをレンダリングし、選択管理、編集制御、クリップボードの動作を管理し、検査官UIを提供します。
- **コマンドパイプライン**: 耐久性のあるコマンドと変異のバッチで受け入れられた変更を適用しているので、保存、削除、および1つのモデルで動作する redo。
- **Facade API**：PDF、ページ、要素、ネイティブテキストの各オブジェクトから PDF Unit を作成、検索、編集、保存できます。

## プラグインモード

### インストール

```package-install
npm install @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui
```

### 使用方法

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/pdfs/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, PdfsUIEnUS),
  },
})

univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Untitled PDF' })
```

### プラグイン設定 [#plugin-configuration]

`UniverLicensePlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| `license` | `string` |  | クライアント用ライセンスファイルの内容。 |

#### `UniverPdfsUIPlugin`

| <span data-config-options="">オプション</span> | 型 | 既定値 | 動作 |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | PDFエディタやスライドエディタのコントロールを有効にします。 |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | PDFエディタやスライドエディタのコントロールを有効にします。 |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | ブラウザワーカーでサムネイルをレンダリングします。 |

`UniverPdfsPlugin`は PDF ユニットと耐久性のあるコマンドを所有しています。 `UniverPdfsUIPlugin` はブラウザビューアとその編集制御を所有しています。ビューア専用 UI の場合、`UniverPdfsUIPlugin`を `{ editor: { enabled: false } }`に登録します。コラボレーションバックアプリケーションは、`@univerjs-pro/pdfs-editor`とコラボプラグインを併用して登録することもできます。

既存の`UniverUIPlugin`登録で`menu`と`ribbonType`を設定。これらは共有UIオプションであり、`UniverPdfsUIPlugin`に属していません。例はPDFから実際のメニューIDを使用します。

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'pdf.menu.tool.highlight': {
    order: 1,
    gridLayout: { row: 2, column: 1 },
  },
  'pdf.menu.tool.ink': {
    order: 0,
    gridLayout: { row: 1, column: 1 },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order` は同じ階層のタブ、グループ、メニュー項目を昇順に並べます。項目を別のグループに移すことはありません。メニュー項目 ID は `data-u-command` 属性で確認できます。コマンド ID と同じとは限りません。

## プリセットモード

Univer PDFはプリセットパッケージを提供していません。プラグインモードでPDFアプリケーションを作成します。

## 編集と表示の操作 [#ribbon-controls]

[スタート]タブでは、元に戻す・やり直す、クリップボード操作、操作モードの選択、ページの整理と挿入、印刷を提供します。挿入では、テキストボックス、画像、段落、区切り線、テーブル、リストを追加します。アノテーションでは、ハイライト、下線、取り消し線をフリーハンド描画とペンのオプションとともにまとめています。ビューでは、ズーム、フルスクリーン、アノテーションの表示、連続スクロール、プロパティパネルを提供します。テキスト、テーブル、または画像を選択すると、対応する [テキスト]、[テーブル]、[画像] のコンテキストタブが開き、プロパティパネル、テーブルスタイル、画像変換の各操作もここに配置されます。これらのリボンコントロールには、`UniverPdfsUIPlugin` の既定の `editor.enabled: true` 設定が必要です。

## Facade API でメニューを更新する [#menu-facade]

### 実行時の更新

`univerAPI`を`FUniver.newAPI(univer)`で作成する前に`@univerjs/ui/facade`を読み込む。[`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig)は変更をマージし、不特定フィールドを保存し、メニューをリフレッシュします。オーバーライドは、後で登録されたメニューにも適用されます。

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'pdf.menu.tool.highlight': { gridLayout: { row: 2, column: 1, showLabel: true, width: 96 } },
})
```

`gridLayout`はグリッドリボンのみに影響します。各グループは2列、`row`と`column`が1で起動します。明示的な位置は、`order`によって設定された視覚的な順に優先されます。そのため、2つの占有セルが交換されると、両方の項目を更新します。オプションフィールドは、既存の構成またはスキーマを継承します。スパン、ラベル、幅、およびアイコンサイズについては、[`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout)を参照してください。

`UniverPdfsUIPlugin`: `editor.enabled: false` では、製品リボンの登録をスキップし、メニューオーバーライドは欠落ボタンを登録しません。

カスタムボタンとサブメニュートリガーの場合、[`createMenu()`および`createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem) は `order`、`gridLayout`; `appendTo()` 登録します。ポップアップコンテンツはリボングリッドレイアウトを使用しません。
