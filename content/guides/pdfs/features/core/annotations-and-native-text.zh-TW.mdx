---
title: 註解與原生文字
description: 插入受支援的 PDF 註解，並將匯入的原生文字提升為可編輯文字方塊。
---

可編輯批註是持久化的疊加層。匯入的文字保持原生狀態，直到透過 Facade 將某個可見文字片段提升為可編輯文字框。

## 插入註解

```ts
const highlight = page.insertAnnotation({
  annotationType: univerAPI.Enum.PdfAnnotationType.HIGHLIGHT,
  left: 36,
  top: 72,
  width: 180,
  height: 18,
  markup: {
    color: '#fde047',
    opacity: 0.6,
  },
})
```

Facade 插入支援高亮、下劃線、刪除線、波浪線與墨跡批註。墨跡批註必須包含非空路徑，該插入 API 不接受其他核心批註子型別。

## 讀取註解資料與樣式

```ts
const markup = highlight.getMarkup()
const style = highlight.getStyle()

highlight.setStyle({
  stroke: { color: '#ca8a04', width: 1 },
  opacity: 0.75,
})
```

`getMarkup()` 與 `getInk()` 返回脫離文件的幾何資料，單位為 PDF 點。`setStyle()` 更新受支援的填充、描邊與不透明度欄位，不透明度必須介於 `0` 和 `1` 之間。

## 取代匯入的原生文字

```ts
const matchingSpan = page
  .getTextSpans()
  .find((span) => span.getText().includes('Draft'))

if (matchingSpan) {
  const textBox = matchingSpan.replaceText('Final')
  textBox.setTextStyle({ bold: true })
}
```

`getTextSpans()` 返回原生文字的快照，僅包含當前可見且未被抑制的部分。`replaceText()` 以單個原子操作抑制源操作，並在捕獲到的位置插入一個可編輯的 `FPdfTextBox`。

`FPdfTextSpan` 是一個快照控制代碼，替換後會失效。執行下一次原生文字操作前，需重新呼叫 `getTextSpans()`。
