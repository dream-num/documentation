PDF 編集 API は Univer コマンドに組み込まれており、コマンドが逆動作しているときには undo と redo に参加しています。変更が必要なコンテンツと一致するトピックから始めます。

## 編集トピック

- [ページと要素](/guides/pdfs/features/core/pages-and-elements)は、ページをインサートし、編集可能なオーバーレイを列挙し、変換、スタック、ロック、または要素を削除カバーします。
- [テキストとリスト](/guides/pdfs/features/core/text-and-lists)はテキストボックス、段落ブロック、セマンティックリストをカバーしています。
- [テーブル](/guides/pdfs/features/core/tables)は、グリッドの挿し出しと再サイズをカバーし、セルを更新し、テーマを適用します。
- [画像とディバイダー](/guides/pdfs/features/core/images-and-dividers)は管理されたイメージおよびベクトル ディバイダーをカバーします。
- [注釈とネイティブテキスト](/guides/pdfs/features/core/annotations-and-native-text)は、サポートされているアノテーションとインポートされたテキストを宣伝する方法をカバーしています。

## 操作を組み合わせる

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  { left: 36, top: 36, width: 144, height: 72 }
)

image.setRotation(-4).bringToFront()
```

ファサード配置値はPDFポイントで測定されます。URLから来る画像は、絶対`http`または`https` URLを使用します。自動ソース検出は相対パスを受け入れません。

ユニットの作成、ルックアップ、保存、およびラッパーの完全な概要については、[Univer PDF APIのPDF化](/guides/pdfs/features/core/pdfs-api)を参照してください。
