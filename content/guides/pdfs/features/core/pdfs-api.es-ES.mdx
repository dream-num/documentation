title: Univer PDFs API

---

El PDF Facade añade unidades PDF y puntos de entrada de página a `FUniver`. Importar la entrada de efectos secundarios antes de crear el objeto API.

## Habilitar PDF Facade

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

Registrar `UniverPdfsPlugin` en la instancia Univer para que la aplicación pueda albergar unidades PDF.

## Crear, buscar y guardar unidades PDF

Cuando `document` se omite, `createPdf()` crea una unidad con una página A4 en blanco. Para restaurar una unidad, pasar una instantánea previamente devuelta por `save()`.

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
const snapshot = pdf.save()
```

Use métodos o comandos Facade para actualizar un PDF en ejecución. Una instantánea guardada es datos de persistencia desprendidos.

## Entrar en una página

`FPdfPage` es el punto de entrada común para las superposiciones editables de una página y el texto nativo importado:

```ts
const firstPage = pdf.getPageByIndex(0) ?? pdf.insertPage()
const elements = firstPage.getElements()
const nativeText = firstPage.getTextSpans()
```

Para operaciones concentradas, continúe con [Páginas y elementos](/guides/pdfs/features/core/pages-and-elements), [Texto y Listas](/guides/pdfs/features/core/text-and-lists), [Cuadros](/guides/pdfs/features/core/tables), [Imágenes y divisores](/guides/pdfs/features/core/images-and-dividers), o [Anotaciones y Texto Nativo](/guides/pdfs/features/core/annotations-and-native-text).

## Descargar una unidad PDF

Descargue una unidad PDF por ID cuando ya no sea necesaria. Desarrolle la instancia `univer` raíz sólo cuando la aplicación entera es destruida.

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  univerAPI.disposeUnit(pdf.getId())
}
```

Para ver las firmas y los tipos de retorno exactos, consulte la [referencia de PDF Facade](/reference/facade/pdf).
