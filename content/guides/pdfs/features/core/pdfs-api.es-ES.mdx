title: Univer PDFs API
description: Cree, busque, guarde, abra y descargue unidades PDF mediante PDF Facade API.
---

PDF Facade añade unidades PDF y puntos de entrada de página a `FUniver`. Importe su entrada de efecto secundario antes de crear el objeto API.

## Habilitar PDF Facade

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

Registre `UniverPdfsPlugin` en la instancia de Univer para que la aplicación pueda alojar unidades PDF.

## Crear, buscar y guardar unidades PDF

Cuando se omite `document`, `createPdf()` crea una unidad con una página A4 en blanco. Pase una instantánea devuelta previamente por `save()` para restaurar una unidad.

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
const snapshot = pdf.save()
```

Use métodos Facade o comandos para actualizar un PDF en ejecución. Trate la instantánea guardada como datos de persistencia independientes.

## Entrar en una página

`FPdfPage` es el punto de entrada común para las superposiciones editables y el texto nativo importado de una página:

```ts
const firstPage = pdf.getPageByIndex(0) ?? pdf.insertPage()
const elements = firstPage.getElements()
const nativeText = firstPage.getTextSpans()
```

Continúe con [Páginas y elementos](/guides/pdfs/features/core/pages-and-elements), [Texto y listas](/guides/pdfs/features/core/text-and-lists), [Tablas](/guides/pdfs/features/core/tables), [Imágenes y divisores](/guides/pdfs/features/core/images-and-dividers) o [Anotaciones y texto nativo](/guides/pdfs/features/core/annotations-and-native-text) para operaciones específicas.

## Descargar una unidad PDF

Descargue una unidad PDF por su ID cuando deje de necesitarla. Destruya la instancia raíz `univer` solo cuando se cierre toda la aplicación.

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  univerAPI.disposeUnit(pdf.getId())
}
```

Para ver las firmas y los tipos de retorno exactos, consulte la [referencia de PDF Facade](/reference/facade/pdf).
