Las API de edición de PDF se construyen en comandos Univer, y participan en deshacer y rehacer cuando el comando tiene una operación inversa. Comience con el tema que coincide con el contenido que necesita cambiar.

## Temas de edición

- [Páginas y elementos](/guides/pdfs/features/core/pages-and-elements) cubre las páginas de inserción, enumerando las capas editables y transformando, apilando, bloqueando o eliminando elementos.
- [Texto y Listas](/guides/pdfs/features/core/text-and-lists) cubre cuadros de texto, bloques de párrafo y listas semánticas.
- [Cuadros](/guides/pdfs/features/core/tables) cubre la inserción y el redimensionamiento de rejillas, la actualización de células y la aplicación de temas.
- [Imágenes y divisores](/guides/pdfs/features/core/images-and-dividers) cubre imágenes gestionadas y separadores vectoriales.
- [Anotaciones y Texto Nativo](/guides/pdfs/features/core/annotations-and-native-text) cubre las anotaciones soportadas y cómo promover el texto importado.

## Combinar operaciones

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  { left: 36, top: 36, width: 144, height: 72 }
)

image.setRotation(-4).bringToFront()
```

Los valores de colocación de Facade se miden en puntos PDF. Para una imagen que viene de una URL, utilice una URL absoluta `http` o `https`. La detección automática de fuentes no acepta caminos relativos.

Para la creación de Unidad, búsqueda, ahorro y una visión completa del envoltorio, vea el [Univer API de PDF](/guides/pdfs/features/core/pdfs-api).
