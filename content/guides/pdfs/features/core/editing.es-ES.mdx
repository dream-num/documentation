Las API de edición PDF se ejecutan mediante comandos de Univer y participan en deshacer y rehacer cuando hay una operación inversa. Empiece por el tema correspondiente al contenido que quiera cambiar.

## Temas de edición

- [Páginas y elementos](/guides/pdfs/features/core/pages-and-elements): inserte páginas, enumere overlays editables, transforme, apile, bloquee y elimine elementos.
- [Texto y listas](/guides/pdfs/features/core/text-and-lists): edite cuadros de texto, bloques de párrafo y listas semánticas.
- [Tablas](/guides/pdfs/features/core/tables): inserte y redimensione cuadrículas, actualice celdas y aplique temas.
- [Imágenes y divisores](/guides/pdfs/features/core/images-and-dividers): inserte imágenes administradas y divisores vectoriales.
- [Anotaciones y texto nativo](/guides/pdfs/features/core/annotations-and-native-text): añada anotaciones compatibles y promueva texto importado.

## Combinar operaciones

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  { left: 36, top: 36, width: 144, height: 72 }
)

image.setRotation(-4).bringToFront()
```

Los valores de posición de Facade usan puntos PDF. Use URL absolutas `http` o `https` para imágenes basadas en URL; la detección automática no acepta rutas URL relativas.

Para crear, buscar y guardar unidades y consultar todos los wrappers, vea la [API de Univer PDFs](/guides/pdfs/features/core/pdfs-api).
