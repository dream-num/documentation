Univer PDF는 형식적인 PDF 단위, 튼튼한 편집 층 및 브라우저 작업대를 제공합니다. 수입된 PDF는 기본 유지됩니다; 받아들여진 변화는 단위 스냅샷에서 저장되고 현재 문서로 렌더링됩니다.

## 기능

- **PDF Unit 모델**: 원본 문서, 페이지 구조, 리소스 및 영구 편집 의도를 `IPdfUnitData`에 저장합니다.
- **페이지 및 요소 작업**: 페이지를 삽입하고, 페이지를 탐색하고, 편집 가능한 텍스트, 목록, 테이블, 이미지, 배당체 및 주석과 함께 작동합니다.
- **브라우저 workbench**: PDF 페이지를 렌더링하고 썸네일을 관리하고, 선택, 편집 컨트롤 및 클립보드 동작을 관리하며, 검사기 UI를 제공합니다.
- **명령 파이프라인**: 튼튼한 명령과 뮤테이션 배치를 통해 승인되는 변화, 그래서 저장, undo, 및 redo는 1개의 모형에 작동합니다.
- **Facade API**: PDF, 페이지, 요소 및 네이티브 텍스트 객체를 통해 PDF Unit을 생성, 조회, 편집 및 저장합니다.

## 플러그인 모드

### 설치

```package-install
npm install @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui
```

### 사용법

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/pdfs/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, PdfsUIEnUS),
  },
})

univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Untitled PDF' })
```

#### `UniverPdfsUIPlugin`

| <span data-config-options="">옵션</span> | 유형 | 기본값 | 동작 |

`UniverPdfsPlugin`는 PDF 단위와 튼튼한 명령을 소유합니다. `UniverPdfsUIPlugin`은 브라우저 뷰어와 그것의 편집 통제를 소유합니다. 뷰어 전용 UI를 위해, `UniverPdfsUIPlugin`를 `{ editor: { enabled: false } }`로 등록하십시오. 공동 백업 응용 프로그램은 또한 `@univerjs-pro/pdfs-editor`을 공동 플러그인과 함께 등록할 수 있습니다.

기존 `UniverUIPlugin` 등록에서 `menu` 및 `ribbonType`를 구성합니다. 이들은 공유 UI 옵션이며 `UniverPdfsUIPlugin`에 속하지 않습니다. 예를 들어 PDF에서 실제 메뉴 ID를 사용합니다.

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'pdf.menu.tool.highlight': {
    order: 1,
    gridLayout: { row: 2, column: 1 },
  },
  'pdf.menu.tool.ink': {
    order: 0,
    gridLayout: { row: 1, column: 1 },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order`는 같은 계층의 탭, 그룹 또는 메뉴 항목을 오름차순으로 정렬하며 항목을 다른 그룹으로 옮기지는 않습니다. 메뉴 항목 ID는 `data-u-command` 속성에서 확인할 수 있습니다. 명령 ID와 같다고 가정하지 마세요.

## 프리셋 모드

Univer PDF는 현재 미리 설치 패키지를 제공하지 않습니다. 플러그인 모드에서 PDF 응용 프로그램을 작성하십시오.

## 편집 및 보기 컨트롤 [#ribbon-controls]

PDF 리본은 Univer 공유 리본 위에 구축됩니다. 시작 탭은 undo 및 redo, 클립보드 작업, 상호작용 모드 선택기, 페이지 구성 및 삽입, 인쇄를 제공합니다. 삽입 탭은 텍스트 상자, 이미지, 단락, 구분선, 표, 목록을 추가합니다. 주석 탭은 형광펜, 밑줄, 취소선을 자유 그리기 및 펜 옵션과 함께 묶습니다. 보기 탭은 확대/축소, 전체 화면, 주석 표시 여부, 연속 스크롤, 속성 패널을 제공합니다. 텍스트, 표 또는 이미지를 선택하면 해당 컨텍스트 텍스트, 표, 이미지 탭이 열리며, 속성 패널, 표 스타일, 이미지 변환 작업도 여기에 있습니다. 이 리본 컨트롤은 `UniverPdfsUIPlugin`의 기본 `editor.enabled: true` 설정을 요구합니다.

## Facade API로 메뉴 업데이트 [#menu-facade]

### 실행 중 업데이트

`univerAPI`를 `FUniver.newAPI(univer)`로 만들기 전에 `@univerjs/ui/facade` 가져 오기. [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig)는 변경 사항을 합병하고 지정되지 않은 필드를 보존하고 메뉴를 새로 고침합니다. 오버라이드는 또한 메뉴에 등록되어 있습니다.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'pdf.menu.tool.highlight': { gridLayout: { row: 2, column: 1, showLabel: true, width: 96 } },
})
```

`gridLayout`는 그리드 리본에만 영향을줍니다. 각 그룹에는 두 개의 행 및 `row` 및 `column` 시작이 있습니다. 명시된 위치는 `order`가 설정한 시각적 주문에 대해 우선 순위를 부여하므로 두 개의 점유 셀이 스왑 될 때 항목을 업데이트하십시오. 선택 필드는 기존 구성 또는 스키마를 상속합니다. 스팬, 라벨, 너비 및 아이콘 크기에 대한 [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout)를 참조하십시오.

`UniverPdfsUIPlugin`: `editor.enabled: false`는 제품 리본의 등록을 건너 뛰고, 메뉴 overrides는 누락된 단추를 등록하지 않습니다.

사용자 정의 버튼 및 서브 우 트리에 대 한, [`createMenu()` 및 `createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem) 또한 `order`와 `gridLayout`를 받아 들인 `appendTo()` 그들을 등록. 팝업 콘텐츠 리본 그리드 레이아웃을 사용 하지 않습니다.
