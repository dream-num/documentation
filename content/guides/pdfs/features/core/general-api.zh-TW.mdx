根 Facade API 將 Univer 通用執行時與當前 PDF 應用註冊的外掛組合在一起。本頁介紹各品類通用的機制，不要求讀者使用過其他 Univer 文件型別。PDF 單元與頁面入口見 [Univer PDFs API](/guides/pdfs/features/core/pdfs-api)。

## 建立 API 物件

先註冊 Univer 例項與所需的外掛，再建立一個 `FUniver` 包裝物件：

```ts
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

在此之前匯入的 Facade 入口會將各自的方法新增到該物件上。

## 命令

`executeCommand()` 非同步執行已註冊的命令。僅在命令明確支援同步執行時，才使用 `syncExecuteCommand()`。常用的 PDF 操作仍應優先使用 Facade 方法。

## 事件

```ts
const commandLog = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ id }) => console.log('Executed:', id)
)

// 不再需要時移除監聽器。
commandLog.dispose()
```

應用需要檢查或取消命令時，可使用 `BeforeCommandExecute`。`LifeCycleChanged` 會報告 `Rendered`、`Steady` 等通用編輯器階段。

## 復原與重做

撤銷與重做作用於當前獲得焦點的 Univer 單元，二者都返回 Promise：

```ts
await univerAPI.undo()
await univerAPI.redo()
```

帶逆操作的 PDF Facade 變更會計入當前聚焦 PDF 單元的歷史記錄。

## 系統剪貼簿

註冊 `UniverPdfsUIPlugin` 並啟用 PDF 編輯後，UI Facade 的 `copy()` 與 `paste()` 會將剪貼簿命令傳送到當前聚焦的 PDF 單元：

```ts
import '@univerjs/ui/facade'

await univerAPI.copy()
await univerAPI.paste()
```

對於可編輯的 PDF 物件，PDF UI 外掛將複製的內容儲存在當前瀏覽器會話中，而不寫入作業系統剪貼簿。瀏覽器中的原生文字編輯仍遵循瀏覽器自身的剪貼簿行為。

## UI

UI Facade 可以顯示訊息、開啟對話方塊或側邊欄、註冊元件，並控制內建 UI 區域：

```ts
univerAPI.setUIVisible(univerAPI.Enum.BuiltInUIPart.TOOLBAR, true)
```

這些方法需要 `UniverUIPlugin`，PDF 編輯控制元件還需要 `UniverPdfsUIPlugin`。

## WebSocket

WebSocket 支援是可選的。建立 API 物件前，請先註冊 Network 外掛並匯入其 Facade 入口：

```ts
import { UniverNetworkPlugin } from '@univerjs/network'

import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)

const socket = univerAPI.createSocket('wss://example.com/pdfs')
socket.open$.subscribe(() => socket.send('ready'))
```

訊息協議、鑑權、重連與協同衝突處理仍由宿主應用負責。

## 列舉

`univerAPI.Enum` 提供通用執行時的列舉，以及 PDF Facade 新增的列舉：

```ts
const lifecycle = univerAPI.Enum.LifecycleStages.Steady
const annotationType = univerAPI.Enum.PdfAnnotationType.HIGHLIGHT
```

## 工具

`univerAPI.Util` 提供共享的輔助方法，例如數字格式化、矩形運算與通用工具：

```ts
const payload = univerAPI.Util.tools.deepClone({
  pageId: 'page-1',
  selectedElementIds: ['element-1'],
})
```

完整的通用 API 見 [Facade 參考](/reference/facade/univer)。
