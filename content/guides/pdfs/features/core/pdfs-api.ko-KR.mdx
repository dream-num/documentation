PDF Facade는 `FUniver`에 PDF 단위와 페이지 항목 점수를 추가합니다. API 객체를 만들기 전에 부작용 항목을 가져옵니다.

## PDF Facade 활성화

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

Univer에 `UniverPdfsPlugin`를 등록하여 응용 프로그램은 PDF 단위를 호스팅 할 수 있습니다.

## PDF 유닛 생성, 조회 및 저장

`document`가 omitted 때, `createPdf()`는 하나의 빈 A4 페이지를 가진 단위를 만듭니다. 단위를 복원하려면, 이전에 `save()`로 반환 스냅 샷을 통과하십시오.

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
const snapshot = pdf.save()
```

Facade 메서드 또는 명령을 사용하여 실행 PDF를 업데이트하십시오. 저장된 스냅 샷은 각기 다른 지속 데이터를 분리합니다.

## 페이지 진입

`FPdfPage`는 페이지의 편집 가능한 오바레이 및 수입한 원본을 위한 일반적인 입장 점입니다:

```ts
const firstPage = pdf.getPageByIndex(0) ?? pdf.insertPage()
const elements = firstPage.getElements()
const nativeText = firstPage.getTextSpans()
```

집중된 가동을 위해, [페이지 및 요소](/guides/pdfs/features/core/pages-and-elements), [텍스트 및 목록](/guides/pdfs/features/core/text-and-lists)의 [의 특징](/guides/pdfs/features/core/tables)로 계속, [이미지 및 디바이더](/guides/pdfs/features/core/images-and-dividers) 또는 [주석 및 기본 텍스트](/guides/pdfs/features/core/annotations-and-native-text).

## PDF 유닛 언로드

더 이상 필요하지 않을 때 ID로 PDF 단위를로드하십시오. 전체 응용 프로그램이 파괴 될 때 루트 `univer` 인스턴스를 처리하십시오.

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  univerAPI.disposeUnit(pdf.getId())
}
```

정확한 시그니처와 반환 타입은 [PDF Facade 레퍼런스](/reference/facade/pdf)를 참고하세요.
