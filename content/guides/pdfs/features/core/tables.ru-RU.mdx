`FPdfTable` поддерживает структурированную сетку со стабильными обертками ячеек, и каждая ячейка содержит одну редактируемую текстовую историю.

## Вставка и редактирование таблицы

```ts
const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Owner', 'Status', 'Docs', 'Ready'],
  left: 36,
  top: 36,
  width: 360,
  height: 108,
})

table.resize(3, 2)
table.getCell(2, 0).setText('Legal')
table.getCell(2, 1).setText('Review')
```

Ряды и столбцы должны быть положительными безопасными целыми числами, а таблица не может превышать 10 000 клеток.Размер сохраняет положения клеток в перекрывающейся области.

## Применение темы таблицы

```ts
const [preset] = univerAPI.getPdfTableThemePresets()

if (preset) {
  table.setTheme({
    styleId: preset.id,
    options: { firstRow: true },
  })
}
```

`getPdfTableThemePresets()` возвращает отдельные дескрипторы `{ id, group }`. Используйте предустановленный `id` в качестве `styleId`; не передавайте сам дескриптор `setTheme()` .

## Стили ячеек

```ts
table.getCell(0, 0).setStyle({
  fill: { color: '#eef3ff' },
  fontColor: '#1d4ed8',
  horizontalAlignment: univerAPI.Enum.HorizontalAlign.CENTER,
  verticalAlign: univerAPI.Enum.PdfTableCellVerticalAlign.MIDDLE,
})
```

`FPdfTableCell.setStyle()` принимает контейнерные поля плюс `fontColor` и `horizontalAlignment`, которые применяются ко всей ячейке. Используйте `PdfTableCellVerticalAlign` через `univerAPI.Enum`.

Методы таблицы: `getRowCount()`, `getColumnCount()`, `getCell()`, `resize()`, `getTheme()` и `setTheme()`. Методы ячейки: `getText()`, `setText()`, `getStyle()` и `setStyle()`.
