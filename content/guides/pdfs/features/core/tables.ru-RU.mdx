`FPdfTable` хранит структурированную сетку со стабильными обёртками ячеек и отдельной редактируемой текстовой историей для каждой ячейки.

## Вставка и редактирование таблицы

```ts
const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Owner', 'Status', 'Docs', 'Ready'],
  left: 36,
  top: 36,
  width: 360,
  height: 108,
})

table.resize(3, 2)
table.getCell(2, 0).setText('Legal')
table.getCell(2, 1).setText('Review')
```

Количество строк и столбцов должно быть положительным безопасным целым числом, а таблица не может содержать более 10 000 ячеек. При изменении размера пересекающиеся ячейки сохраняются по позиции.

## Применение темы таблицы

```ts
const [preset] = univerAPI.getPdfTableThemePresets()

if (preset) {
  table.setTheme({
    styleId: preset.id,
    options: { firstRow: true },
  })
}
```

`getPdfTableThemePresets()` возвращает отдельные дескрипторы `{ id, group }`. Используйте `id` набора как `styleId`; не передавайте дескриптор напрямую в `setTheme()`.

## Стили ячеек

```ts
table.getCell(0, 0).setStyle({
  fill: { color: '#eef3ff' },
  fontColor: '#1d4ed8',
  horizontalAlignment: univerAPI.Enum.HorizontalAlign.CENTER,
  verticalAlign: univerAPI.Enum.PdfTableCellVerticalAlign.MIDDLE,
})
```

`FPdfTableCell.setStyle()` принимает поля контейнера, а также `fontColor` и `horizontalAlignment` для всей ячейки. Используйте `PdfTableCellVerticalAlign` через `univerAPI.Enum`.

Методы таблицы: `getRowCount()`, `getColumnCount()`, `getCell()`, `resize()`, `getTheme()` и `setTheme()`. Методы ячейки: `getText()`, `setText()`, `getStyle()` и `setStyle()`.
