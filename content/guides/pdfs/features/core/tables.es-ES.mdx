---
title: Tablas
description: Inserte, redimensione, aplique estilos y edite tablas PDF estructuradas mediante Facade.
---

`FPdfTable` mantiene una cuadrícula estructurada con wrappers de celda estables y una historia de texto editable por celda.

## Insertar y editar una tabla

```ts
const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Owner', 'Status', 'Docs', 'Ready'],
  left: 36,
  top: 36,
  width: 360,
  height: 108,
})

table.resize(3, 2)
table.getCell(2, 0).setText('Legal')
table.getCell(2, 1).setText('Review')
```

Las filas y columnas deben ser enteros positivos seguros y una tabla no puede superar 10,000 celdas. El redimensionado conserva por posición las celdas que se solapan.

## Aplicar un tema de tabla

```ts
const [preset] = univerAPI.getPdfTableThemePresets()

if (preset) {
  table.setTheme({
    styleId: preset.id,
    options: { firstRow: true },
  })
}
```

`getPdfTableThemePresets()` devuelve descriptores `{ id, group }` independientes. Use el `id` de un preset como `styleId`; no pase el descriptor directamente a `setTheme()`.

## Estilos de celda

```ts
table.getCell(0, 0).setStyle({
  fill: { color: '#eef3ff' },
  fontColor: '#1d4ed8',
  horizontalAlignment: univerAPI.Enum.HorizontalAlign.CENTER,
  verticalAlign: univerAPI.Enum.PdfTableCellVerticalAlign.MIDDLE,
})
```

`FPdfTableCell.setStyle()` acepta campos del contenedor además de `fontColor` y `horizontalAlignment` para toda la celda. Use `PdfTableCellVerticalAlign` mediante `univerAPI.Enum`.

Los métodos de tabla incluyen `getRowCount()`, `getColumnCount()`, `getCell()`, `resize()`, `getTheme()` y `setTheme()`. Los métodos de celda incluyen `getText()`, `setText()`, `getStyle()` y `setStyle()`.
