---

`FPdfTable` mantiene una rejilla estructurada con envoltorios de celdas estables, y cada célula tiene una historia de texto editable.

## Insertar y editar una tabla

```ts
const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Owner', 'Status', 'Docs', 'Ready'],
  left: 36,
  top: 36,
  width: 360,
  height: 108,
})

table.resize(3, 2)
table.getCell(2, 0).setText('Legal')
table.getCell(2, 1).setText('Review')
```

Las filas y las columnas deben ser enteros seguros positivos, y una tabla no puede exceder de 10.000 células. Redimensionar preserva las posiciones de las células en la región superpuesta.

## Aplicar un tema de tabla

```ts
const [preset] = univerAPI.getPdfTableThemePresets()

if (preset) {
  table.setTheme({
    styleId: preset.id,
    options: { firstRow: true },
  })
}
```

`getPdfTableThemePresets()` devuelve descriptores `{ id, group }` separados. Usa el `id` del preset como `styleId`; no pase el propio descriptor a `setTheme()`.

## Estilos de celda

```ts
table.getCell(0, 0).setStyle({
  fill: { color: '#eef3ff' },
  fontColor: '#1d4ed8',
  horizontalAlignment: univerAPI.Enum.HorizontalAlign.CENTER,
  verticalAlign: univerAPI.Enum.PdfTableCellVerticalAlign.MIDDLE,
})
```

`FPdfTableCell.setStyle()` acepta campos de contenedores más `fontColor` y `horizontalAlignment`, que se aplican a toda la célula. Utilice `PdfTableCellVerticalAlign` a través de `univerAPI.Enum`.

## Acciones de tabla

Seleccione una celda para mostrar **Acciones de tabla**. En escritorio se encuentran en el panel de propiedades de la tabla seleccionada, que la pestaña contextual **Tabla** puede abrir. En móvil, **Acciones de tabla** en la barra de herramientas de selección abre la misma sección. Las acciones seleccionan celdas, combinan o dividen celdas e insertan filas o columnas en cualquier lado. También eliminan filas, columnas y la tabla entera, y establecen **Alto de fila** o **Ancho de columna**. Combinar requiere una selección rectangular de varias celdas.

Las ediciones de tabla son duraderas y participan en deshacer y rehacer.

Los métodos de tabla incluyen `getRowCount()`, `getColumnCount()`, `getCell()`, `resize()`, `getTheme()` y `setTheme()`. Los métodos de celda incluyen `getText()`, `setText()`, `getStyle()` y `setStyle()`.
