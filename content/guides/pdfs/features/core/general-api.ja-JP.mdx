ルートFacade APIは、共有UniverランタイムとPDFアプリケーションによって登録されたプラグインを組み合わせています。このページでは、Univer製品と同じ方法で動作するメカニズムをカバーしており、別のUniverドキュメントタイプでは経験を想定していません。PDFユニットとページのエントリポイントについては、[Univer PDF APIのPDF化](/guides/pdfs/features/core/pdfs-api)で続けてください。

## API オブジェクトを作成する

Univerインスタンスと必要なプラグインを登録した後、単一の`FUniver`ラッパーを作成します。

```ts
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

このコールの前にインポートされたファサードエントリは、同じオブジェクトにメソッドを追加します。

## コマンド

`executeCommand()` は、登録済みのコマンドを非同期的に実行します。コマンドが同期実行を明示的にサポートする場合にのみ、`syncExecuteCommand()`を使用してください。一般的なPDF操作では、Facade メソッドは優先エントリ ポイントのままです。

## イベント

```ts
const commandLog = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ id }) => console.log('Executed:', id)
)

// 不要になったらリスナーを削除します。
commandLog.dispose()
```

アプリケーションがコマンドを検査またはキャンセルする必要がある場合は、`BeforeCommandExecute`を使用します。 `LifeCycleChanged`は、`Rendered`や`Steady`などの一般的なエディタステージを報告します。

## 元に戻す／やり直す

undo と redo は、現在フォーカスしている Univer Unit に適用され、両方のリターンの約束:

```ts
await univerAPI.undo()
await univerAPI.redo()
```

PDF は、逆操作による変化が集中した PDF ユニットの履歴に入ります。

## システムクリップボード

`UniverPdfsUIPlugin` が登録され、PDF 編集が有効になっていると、UI ファサードの `copy()`と`paste()`メソッドは、クリップボードのコマンドを集中した PDF ユニットに送信します。

```ts
import '@univerjs/ui/facade'

await univerAPI.copy()
await univerAPI.paste()
```

編集可能なPDFオブジェクトの場合、PDF UIプラグインは、オペレーティングシステムのクリップボードに書き込むのではなく、現在のブラウザセッションでコピーされたペイロードを保持します。 ブラウザでのネイティブテキスト編集は、ブラウザのクリップボードの動作に引き続き続きます。

## UI

UIファサードは、メッセージを表示し、ダイアログとサイドバーを開き、コンポーネントを登録し、組み込みのUI部分を制御します。

```ts
univerAPI.setUIVisible(univerAPI.Enum.BuiltInUIPart.TOOLBAR, true)
```

これらの方法は、`UniverUIPlugin`、およびPDF編集制御も`UniverPdfsUIPlugin`を必要とします。

## WebSocket

WebSocket は任意機能です。API オブジェクトを作成する前に Network プラグインを登録し、その Facade エントリをインポートします。

```ts
import { UniverNetworkPlugin } from '@univerjs/network'

import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)

const socket = univerAPI.createSocket('wss://example.com/pdfs')
socket.open$.subscribe(() => socket.send('ready'))
```

メッセージプロトコル、認証、再接続、およびコラボレーションの競合処理は、ホストアプリケーションの責任を保ちます。

## 列挙型

`univerAPI.Enum`は、PDFファサードによって追加されたランタイム列と列を調べます。

```ts
const lifecycle = univerAPI.Enum.LifecycleStages.Steady
const annotationType = univerAPI.Enum.PdfAnnotationType.HIGHLIGHT
```

## ユーティリティ

`univerAPI.Util` は数値書式、矩形演算、共通ツールなどの共有ヘルパーを提供します。

```ts
const payload = univerAPI.Util.tools.deepClone({
  pageId: 'page-1',
  selectedElementIds: ['element-1'],
})
```

[ファサードの参照](/reference/facade/univer) では、完全な共通 API がドキュメント化されます。
