---
title: Annotations et texte natif
description: Insérez les annotations PDF prises en charge et transformez le texte natif importé en zones de texte modifiables.
---

Les annotations modifiables sont des overlays persistants. Le texte importé reste natif jusqu'à la promotion d'une plage visible avec la façade.

## Insérer des annotations

```ts
const highlight = page.insertAnnotation({
  annotationType: univerAPI.Enum.PdfAnnotationType.HIGHLIGHT,
  left: 36,
  top: 72,
  width: 180,
  height: 18,
  markup: {
    color: '#fde047',
    opacity: 0.6,
  },
})
```

Les annotations d'encre nécessitent des chemins non vides, et cette API d'insertion rejette les autres sous-types d'annotation du noyau.

## Lire les données et le style d'une annotation

```ts
const markup = highlight.getMarkup()
const style = highlight.getStyle()

highlight.setStyle({
  stroke: { color: '#ca8a04', width: 1 },
  opacity: 0.75,
})
```

`getMarkup()` et `getInk()` retournent la géométrie détachée mesurée en points PDF. `setStyle()` met à jour les champs de remplissage, de course et d'opacité pris en charge. L'opapacité doit être entre `0`et `1`.

## Remplacer le texte natif importé

```ts
const matchingSpan = page
  .getTextSpans()
  .find((span) => span.getText().includes('Draft'))

if (matchingSpan) {
  const textBox = matchingSpan.replaceText('Final')
  textBox.setTextStyle({ bold: true })
}
```

`getTextSpans()` retourne des instantanés de texte natif qui sont actuellement visibles et non supprimés. `replaceText()` supprime l'opération source et insère un `FPdfTextBox` modifiable à la position capturée comme une seule étape atomique.

Un `FPdfTextSpan` est une poignée d'instantané qui devient bloquée après le remplacement. Appelez à nouveau `getTextSpans()` avant la prochaine opération native-text.
