---
title: 주석과 네이티브 텍스트
description: 지원되는 PDF 주석을 삽입하고 가져온 네이티브 텍스트를 편집 가능한 텍스트 상자로 승격합니다.
---

편집 가능한 주석은 영속 오버레이입니다. 가져온 텍스트는 보이는 텍스트 범위를 퍼사드로 승격할 때까지 네이티브 상태로 유지됩니다.

## 주석 삽입

```ts
const highlight = page.insertAnnotation({
  annotationType: univerAPI.Enum.PdfAnnotationType.HIGHLIGHT,
  left: 36,
  top: 72,
  width: 180,
  height: 18,
  markup: {
    color: '#fde047',
    opacity: 0.6,
  },
})
```

Facade insertion은 하이라이트, 밑줄, 파업, 스쿼그리, 잉크 주석을 지원합니다. 잉크 annotations는 비 빈번한 경로가 필요하며, 이 삽입 API는 다른 핵심 연고 서브타입을 거부합니다.

## 주석 데이터 및 스타일 읽기

```ts
const markup = highlight.getMarkup()
const style = highlight.getStyle()

highlight.setStyle({
  stroke: { color: '#ca8a04', width: 1 },
  opacity: 0.75,
})
```

`getMarkup()`와 `getInk()`는 PDF 점에서 측정된 기하학을 반환합니다. `setStyle()` 업데이트 지원되는 채우기, 치기 및 불투명 분야. 불투명은 `0` 및 `1` 사이에서 있어야 합니다.

## 가져온 네이티브 텍스트 바꾸기

```ts
const matchingSpan = page
  .getTextSpans()
  .find((span) => span.getText().includes('Draft'))

if (matchingSpan) {
  const textBox = matchingSpan.replaceText('Final')
  textBox.setTextStyle({ bold: true })
}
```

`getTextSpans()`는 현재 눈에 띄지 않고 억제되지 않은 기본 텍스트의 스냅 샷을 반환합니다. `replaceText()`은 소스 작업을 억제하고 단일 원자 단계로 캡처 된 위치에 편집 가능한 `FPdfTextBox`를 삽입합니다.

`FPdfTextSpan`는 교체 후 stale이되는 스냅샷 핸들입니다. 다음 네이티브 텍스트 작업 전에 `getTextSpans()`를 다시 호출하십시오.
