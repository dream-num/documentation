Le noyau d’Univer PDFs fournit une unité PDF formelle, une couche de modifications persistante et un espace de travail dans le navigateur. Le PDF importé reste la source de référence, tandis que les changements acceptés sont enregistrés dans l’instantané de l’unité et affichés comme document courant.

## Fonctionnalités

- **Modèle d’unité PDF** : conserve le document source, la structure des pages, les ressources et les intentions de modification persistantes dans `IPdfUnitData`.
- **Opérations sur les pages et les éléments** : prend en charge la navigation et l’insertion de pages ainsi que le texte, les listes, les tableaux, les images, les séparateurs et les annotations modifiables.
- **Espace de travail du navigateur** : fournit l’affichage des pages PDF, les miniatures, la sélection, les commandes d’édition, le presse-papiers et l’inspecteur.
- **Pipeline de commandes** : applique les changements acceptés par des commandes et lots de mutations persistants afin que l’enregistrement, l’annulation et le rétablissement utilisent le même modèle.
- **Facade API** : crée, retrouve, modifie et enregistre les unités PDF au moyen d’objets PDF, page, élément et texte natif.

## Mode prédéfini

Univer PDFs ne fournit actuellement aucun package de preset. Créez les applications PDF en mode plugin.

## Mode plugin

### Installation

```package-install
npm install @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui
```

### Utilisation

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'

import '@univerjs-pro/pdfs/facade'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, PdfsUIEnUS),
  },
})

univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Untitled PDF' })
```

`UniverPdfsPlugin` gère l’unité PDF et les commandes persistantes ; `UniverPdfsUIPlugin` gère le visualiseur dans le navigateur et ses commandes d’édition. Pour une interface en lecture seule, utilisez `{ editor: { enabled: false } }`. Une application collaborative peut ajouter `@univerjs-pro/pdfs-editor` avec les plugins de collaboration dont il dépend.
