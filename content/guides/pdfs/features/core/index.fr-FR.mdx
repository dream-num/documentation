Univer PDFs fournit une unité PDF formelle, une couche d'édition durable, et un banc de travail de navigateur. Le PDF importé reste la base de référence; les modifications acceptées sont stockées dans l'instantané de l'unité et rendues comme document courant.

## Fonctionnalités

- **Modèle d’unité PDF** : conserve le document source, la structure des pages, les ressources et les intentions de modification persistantes dans `IPdfUnitData`.
- **Opérations de pages et d'éléments**: Insère des pages, navigue entre des pages, et fonctionne avec du texte modifiable, des listes, des tableaux, des images, des diviseurs et des annotations.
- **Browser Workbench** : Renver les pages PDF et les vignettes, gère la sélection, les contrôles d'édition et le comportement du presse-papiers, et fournit l'interface utilisateur de l'inspecteur.
- **Ligne de commande**: Applique les changements acceptés par des commandes durables et des lots de mutations, donc enregistrer, annuler et refaire fonctionne sur un modèle.
- **Facade API** : crée, retrouve, modifie et enregistre les unités PDF au moyen d’objets PDF, page, élément et texte natif.

## Mode plugin

### Installation

```package-install
npm install @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui
```

### Utilisation

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/pdfs/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, PdfsUIEnUS),
  },
})

univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Untitled PDF' })
```

### Configuration des plugins [#plugin-configuration]

`UniverLicensePlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenu du fichier de licence côté client. |

#### `UniverPdfsUIPlugin`

| <span data-config-options="">Option</span> | Type | Valeur par défaut | Effet |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | Active l'éditeur PDF ou les commandes de l'éditeur de diapositives. |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | Active l'éditeur PDF ou les commandes de l'éditeur de diapositives. |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | Renders miniatures dans un navigateur Worker. |

`UniverPdfsPlugin` possède l'unité PDF et les commandes durables. `UniverPdfsUIPlugin` est propriétaire du visionneur de navigateur et de ses commandes d'édition. Pour l'interface utilisateur uniquement, enregistrez `UniverPdfsUIPlugin` avec `{ editor: { enabled: false } }`. Les applications soutenues par la collaboration peuvent également enregistrer `@univerjs-pro/pdfs-editor` ainsi que les plugins de collaboration dont elle a besoin.

Configurez `menu` et `ribbonType` dans l'enregistrement `UniverUIPlugin` existant. Ce sont des options d'interface utilisateur partagées et n'appartiennent pas à `UniverPdfsUIPlugin`. L'exemple utilise des identifiants de menu réels à partir de PDFs:

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'pdf.menu.tool.highlight': {
    order: 1,
    gridLayout: { row: 2, column: 1 },
  },
  'pdf.menu.tool.ink': {
    order: 0,
    gridLayout: { row: 1, column: 1 },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order` trie par ordre croissant les onglets, groupes ou éléments de même niveau, sans déplacer un élément vers un autre groupe. L’identifiant d’un élément est disponible dans son attribut `data-u-command` ; il ne correspond pas nécessairement à l’identifiant de la commande.

## Mode prédéfini

Univer PDFs ne fournit pas actuellement un paquet prédéfini. Créez des applications PDF en mode Plugin.

## Contrôles d’édition et d’affichage [#ribbon-controls]

L'onglet Démarrer fournit des outils de copie, de découpe, de collage, de mode d'outil et d'annotation. L'insertion fournit des pages, des boîtes de texte, des paragraphes, des listes, des tableaux, des images et des diviseurs. L'affichage fournit un zoom, un plein écran, une visibilité d'anotation et un défilement continu. `editor.enabled: true` mise en place `UniverPdfsUIPlugin`.

## Mettre à jour les menus avec l’API Facade [#menu-facade]

### Mise à jour à l’exécution

Importez `@univerjs/ui/facade` avant de créer `univerAPI` avec `FUniver.newAPI(univer)`. [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) fusionne les modifications, conserve les champs non spécifiés et rafraîchit les menus. Les dépassements s'appliquent également aux menus enregistrés plus tard.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'pdf.menu.tool.highlight': { gridLayout: { row: 2, column: 1, showLabel: true, width: 96 } },
})
```

`gridLayout` n'affecte que la grille Ribbon. Chaque groupe a deux rangées, et `row` et `column` 1. Une position explicite a priorité sur l'ordre visuel défini par `order`, donc mettre à jour les deux éléments lorsque deux cellules occupées sont échangées. Les champs optionnels héritent de la configuration ou du schéma existant. [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout) pour les travées, étiquettes, largeurs et tailles d'icônes.

Gardez l'édition activée dans `UniverPdfsUIPlugin` : `editor.enabled: false` saute l'enregistrement du produit Ribbon, et les dépassements de menu ne enregistrent pas les boutons manquants.

Pour les boutons personnalisés et les déclencheurs de sous-menu, [`createMenu()` et `createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem) accepte également `order` et `gridLayout`; `appendTo()` les enregistre. Le contenu popup n'utilise pas la disposition de la grille Ribbon.
