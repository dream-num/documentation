`FPdf` 管理頁面。每個 `FPdfPage` 提供放置在該頁上的持久化可編輯疊加層。

## 讀取與插入頁面

頁面索引從 0 開始。`insertPage(index?)` 在指定索引處插入頁面；省略索引時，頁面追加到末尾。空文件使用 A4 尺寸。

```ts
const pdf = univerAPI.getActivePdf()

if (!pdf) {
  throw new Error('No active PDF')
}

const page = pdf.getPageByIndex(0) ?? pdf.insertPage()
const pages = pdf.getPages()
const samePage = pdf.getPageById(page.getId())
```

## 列舉可編輯元素

`getElements()` 按 z 順序傳回可編輯覆蓋層，不包含匯入 PDF 中的原生物件。

```ts
const elements = page.getElements()
const [firstElement] = elements
const sameElement = firstElement ? page.getElementById(firstElement.getId()) : null
```

需要專用包裝器時，使用對應的型別化 getter：`getTextBoxes()`、`getParagraphs()`、`getLists()`、`getTables()`、`getImages()`、`getDividers()` 和 `getAnnotations()`。

## 變換與移除元素

透過 Facade 設定位置時，單位為 PDF 點。`getData()` 返回的快照中，幾何值使用核心 PDF 單位，因此應透過 Facade 方法修改位置。

```ts
const [element] = page.getElements()

if (element) {
  element
    .setPosition(36, 72)
    .setSize(288, 144)
    .setRotation(5)
    .setVisible(true)
    .setLocked(false)
    .bringToFront()
}
```

呼叫 `remove()` 刪除可編輯元素。刪除後不要複用已經失效的包裝器。
