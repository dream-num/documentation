`FPdf`가 페이지를 소유하고 각 `FPdfPage`는 해당 페이지에 배치된 영속 편집 오버레이를 제공합니다.

## 페이지 읽기 및 삽입

페이지 인덱스는 0에서 시작합니다. `insertPage(index?)`는 지정된 인덱스에서 페이지를 삽입하거나 인덱스가 omitted 때 페이지를 부과합니다. 빈 문서는 A4 치수를 사용합니다.

```ts
const pdf = univerAPI.getActivePdf()

if (!pdf) {
  throw new Error('No active PDF')
}

const page = pdf.getPageByIndex(0) ?? pdf.insertPage()
const pages = pdf.getPages()
const samePage = pdf.getPageById(page.getId())
```

## 편집 가능한 요소 열거

`getElements()`는 z-order에서 편집 가능한 오버레이를 반환합니다. 수입된 PDF에서 기본 객체를 반환하지 않습니다.

```ts
const elements = page.getElements()
const [firstElement] = elements
const sameElement = firstElement ? page.getElementById(firstElement.getId()) : null
```

전문화한 래퍼를 위해, 타자를 씌우는 라이더를 이용합니다: `getTextBoxes()`, `getParagraphs()`, `getLists()`, `getTables()`, `getImages()`, `getDividers()` 및 `getAnnotations()`.

## 요소 변환 및 제거

퍼사드 배치는 PDF 포인트를 사용합니다. `getData()`가 반환하는 스냅샷 기하 정보는 코어 PDF 단위를 사용하므로 퍼사드 메서드로 배치를 업데이트하세요.

```ts
const [element] = page.getElements()

if (element) {
  element
    .setPosition(36, 72)
    .setSize(288, 144)
    .setRotation(5)
    .setVisible(true)
    .setLocked(false)
    .bringToFront()
}
```

`remove()`를 호출하여 편집 가능한 요소를 삭제합니다. 제거 후 stale 래퍼를 재사용하지 마십시오.
