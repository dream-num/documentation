---
title: Anotaciones y texto nativo
description: Inserte anotaciones PDF compatibles y convierta texto nativo importado en cuadros de texto editables.
---

Las anotaciones editables son overlays persistentes. El texto importado sigue siendo nativo hasta que se promueve un fragmento visible mediante Facade.

## Insertar anotaciones

```ts
const highlight = page.insertAnnotation({
  annotationType: univerAPI.Enum.PdfAnnotationType.HIGHLIGHT,
  left: 36,
  top: 72,
  width: 180,
  height: 18,
  markup: {
    color: '#fde047',
    opacity: 0.6,
  },
})
```

La inserción de Facade soporta resaltar, subrayar, strikeout, squiggly, y anotaciones de tinta. Las anotaciones en tinta requieren caminos no vacíos, y esta API de inserción rechaza los otros subtipos de anotación básica.

## Leer datos y estilos de anotación

```ts
const markup = highlight.getMarkup()
const style = highlight.getStyle()

highlight.setStyle({
  stroke: { color: '#ca8a04', width: 1 },
  opacity: 0.75,
})
```

`getMarkup()` y `getInk()` vuelven geometría desprendida medida en puntos PDF. `setStyle()` actualiza los campos de llenado, trazo y opacidad soportados. La opacidad debe ser entre `0` e `1`.

## Sustituir texto nativo importado

```ts
const matchingSpan = page
  .getTextSpans()
  .find((span) => span.getText().includes('Draft'))

if (matchingSpan) {
  const textBox = matchingSpan.replaceText('Final')
  textBox.setTextStyle({ bold: true })
}
```

`getTextSpans()` devuelve instantáneas de texto nativo que actualmente es visible y no suprimida. `replaceText()` suprime la operación de origen e inserta un `FPdfTextBox` editable en la posición capturada como un solo paso atómico.

Un `FPdfTextSpan` es un mango de instantáneas que se vuelve estancado después del reemplazo. Llame a `getTextSpans()` de nuevo antes de la próxima operación de texto nativo.
