PDF 编辑 API 均以 Univer 命令实现，当命令带有逆操作时，该命令会进入撤销与重做历史。请从与所需修改内容对应的主题开始阅读。

## 编辑主题

- [页面与元素](/guides/pdfs/features/core/pages-and-elements)：包括插入页面、枚举可编辑叠加层，以及变换、层叠、锁定与移除元素。
- [文本与列表](/guides/pdfs/features/core/text-and-lists)：包括文本框、段落块与语义化列表。
- [表格](/guides/pdfs/features/core/tables)：包括插入与调整网格、更新单元格，以及套用主题。
- [图片与分隔线](/guides/pdfs/features/core/images-and-dividers)：包括托管图片与矢量分隔线。
- [批注与原生文本](/guides/pdfs/features/core/annotations-and-native-text)：包括受支持的批注，以及将导入文本提升为可编辑内容。

## 组合操作

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  { left: 36, top: 36, width: 144, height: 72 }
)

image.setRotation(-4).bringToFront()
```

Facade 的放置值以 PDF 点为单位。图片来自 URL 时，需提供绝对的 `http` 或 `https` 地址；自动源检测不接受相对路径。

单元创建、查找、保存以及包装器的完整说明，见 [Univer PDFs API](/guides/pdfs/features/core/pdfs-api)。
