PDF 编辑 API 通过 Univer 命令执行；当操作具有逆操作时，会进入撤销与重做历史。请从与待修改内容对应的主题开始。

## 编辑主题

- [页面与元素](/guides/pdfs/features/core/pages-and-elements)：插入页面、枚举可编辑叠加层，以及变换、层叠、锁定和移除元素。
- [文本与列表](/guides/pdfs/features/core/text-and-lists)：编辑文本框、段落块和语义化列表。
- [表格](/guides/pdfs/features/core/tables)：插入与调整网格、更新单元格并应用主题。
- [图片与分隔线](/guides/pdfs/features/core/images-and-dividers)：插入托管图片和矢量分隔线。
- [批注与原生文本](/guides/pdfs/features/core/annotations-and-native-text)：添加受支持的批注并提升导入文本。

## 组合操作

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  { left: 36, top: 36, width: 144, height: 72 }
)

image.setRotation(-4).bringToFront()
```

Facade 放置值使用 PDF 点。URL 图片应使用绝对 `http` 或 `https` 地址；自动源检测不接受相对 URL 路径。

单元创建、查找、保存与完整包装器总览请参阅 [Univer PDFs API](/guides/pdfs/features/core/pdfs-api)。
