title: Modifier des PDF

---

Les API d'édition PDF sont construites sur les commandes Univer, et elles participent à la désactivation et au redécoupage lorsque la commande a une opération inverse. Commencez par le sujet qui correspond au contenu que vous devez modifier.

## Thèmes de modification

- [Pages et éléments](/guides/pdfs/features/core/pages-and-elements) couvre l'insertion de pages, l'enumeration de superpositions modifiables, et la transformation, empilage, verrouillage ou suppression d'éléments.
- [Texte et listes](/guides/pdfs/features/core/text-and-lists) couvre les boîtes de texte, les blocs de paragraphes et les listes sémantiques.
- [Tableaux](/guides/pdfs/features/core/tables) couvre l'insertion et le redimensionnement des grilles, la mise à jour des cellules et l'application des thèmes.
- [Images et séparateurs](/guides/pdfs/features/core/images-and-dividers) couvre les images gérées et les diviseurs vectoriels.
- [Annotations et texte autochtone](/guides/pdfs/features/core/annotations-and-native-text) couvre les annotations prises en charge et comment promouvoir le texte importé.

## Combiner les opérations

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  { left: 36, top: 36, width: 144, height: 72 }
)

image.setRotation(-4).bringToFront()
```

Pour une image qui provient d'une URL, utilisez une URL `http` ou `https` absolue. La détection automatique des sources n'accepte pas les chemins relatifs.

Pour la création d'unité, la recherche, l'enregistrement et un aperçu complet de l'emballage, voir le [API PDFs Univer](/guides/pdfs/features/core/pdfs-api).
