title: Modifier des PDF

---

Les API de modification PDF passent par les commandes Univer et participent à l'annulation et au rétablissement lorsqu'une opération inverse existe. Commencez par le thème correspondant au contenu à modifier.

## Thèmes de modification

- [Pages et éléments](/guides/pdfs/features/core/pages-and-elements) : insérez des pages, énumérez les overlays modifiables, transformez, empilez, verrouillez et supprimez des éléments.
- [Texte et listes](/guides/pdfs/features/core/text-and-lists) : modifiez les zones de texte, les blocs de paragraphe et les listes sémantiques.
- [Tableaux](/guides/pdfs/features/core/tables) : insérez et redimensionnez des grilles, modifiez les cellules et appliquez des thèmes.
- [Images et séparateurs](/guides/pdfs/features/core/images-and-dividers) : insérez des images gérées et des séparateurs vectoriels.
- [Annotations et texte natif](/guides/pdfs/features/core/annotations-and-native-text) : ajoutez les annotations prises en charge et promouvez le texte importé.

## Combiner les opérations

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  { left: 36, top: 36, width: 144, height: 72 }
)

image.setRotation(-4).bringToFront()
```

Les placements de façade utilisent des points PDF. Utilisez des URL absolues `http` ou `https` pour les images URL ; la détection automatique n'accepte pas les chemins relatifs.

Pour créer, rechercher et enregistrer des unités et voir tous les wrappers, consultez l'[API Univer PDFs](/guides/pdfs/features/core/pdfs-api).
