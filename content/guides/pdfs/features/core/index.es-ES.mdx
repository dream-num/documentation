Univer PDFs proporciona una unidad PDF formal, una capa de edición duradera y un banco de trabajo del navegador. El PDF importado sigue siendo la base de referencia; los cambios aceptados se almacenan en la instantánea de la unidad y se hacen como el documento actual.

## Funciones

- **Modelo de unidad PDF**: almacena el documento de origen, la estructura de páginas, los recursos y la intención de edición persistente en `IPdfUnitData`.
- **Operaciones de página y elementos**: Inserta páginas, navega entre páginas y trabaja con texto editable, listas, tablas, imágenes, separadores y anotaciones.
- **Navegador banco de trabajo**: Renders páginas PDF y miniaturas, gestiona la selección, los controles de edición y el comportamiento del portapapeles, y proporciona al inspector UI.
- **Oleoducto de mando**: Aplica cambios aceptados a través de comandos duraderos y murciélagos de mutación, así que guardar, deshacer y redo operan en un modelo.
- **Facade API**: crea, busca, edita y guarda unidades PDF mediante objetos de PDF, página, elemento y texto nativo.

## Modo plugin

### Instalación

```package-install
npm install @univerjs/core @univerjs/design @univerjs/ui @univerjs-pro/license @univerjs-pro/pdfs @univerjs-pro/pdfs-ui
```

### Uso

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import PdfsUIEnUS from '@univerjs-pro/pdfs-ui/locale/en-US'
import { LocaleType, mergeLocales, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import DesignEnUS from '@univerjs/design/locale/en-US'
import { UniverUIPlugin } from '@univerjs/ui'
import UIEnUS from '@univerjs/ui/locale/en-US'
import '@univerjs-pro/pdfs/facade'
import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {
    [LocaleType.EN_US]: mergeLocales(DesignEnUS, UIEnUS, PdfsUIEnUS),
  },
})

univer.registerPlugin(UniverUIPlugin, { container: 'app' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Untitled PDF' })
```

### Configuración de plugins [#plugin-configuration]

`UniverLicensePlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| `license` | `string` |  | Contenido del archivo de licencia del cliente. |

#### `UniverPdfsUIPlugin`

| <span data-config-options="">Opción</span> | Tipo | Valor predeterminado | Efecto |
| --- | --- | --- | --- |
| <ConfigKey depth={0}>editor</ConfigKey> | `object` |  | Permite que el editor PDF o los controles del editor de diapositivas. |
| <ConfigKey depth={1}>enabled</ConfigKey> | `boolean` | `true` | Permite que el editor PDF o los controles del editor de diapositivas. |
| `thumbnailWorkerURL` | `string \| URL \| Worker` |  | Renders miniaturas en un navegador Trabajador. |

`UniverPdfsPlugin` posee la unidad PDF y los comandos duraderos. `UniverPdfsUIPlugin` es dueña del navegador y sus controles de edición. Para la interfaz de usuario visual, registre `UniverPdfsUIPlugin` con `{ editor: { enabled: false } }`. Las aplicaciones respaldadas por la colaboración también pueden registrar `@univerjs-pro/pdfs-editor` junto con los plugins de colaboración que requiere.

Configure `menu` y `ribbonType` en el registro `UniverUIPlugin` existente. Estas son opciones de interfaz de usuario compartidas y no pertenecen a `UniverPdfsUIPlugin`. El ejemplo utiliza IDs de menú reales de PDF:

```ts
import type { MenuConfig } from '@univerjs/ui'
import { UniverUIPlugin } from '@univerjs/ui'

const menu: MenuConfig = {
  'ribbon.view': { order: -1 },
  'ribbon.start.layout': { order: -1 },
  'pdf.menu.tool.highlight': {
    order: 1,
    gridLayout: { row: 2, column: 1 },
  },
  'pdf.menu.tool.ink': {
    order: 0,
    gridLayout: { row: 1, column: 1 },
  },
}

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid', menu })
```

`order` ordena de menor a mayor las pestañas, grupos o elementos del mismo nivel; no mueve elementos a otro grupo. El identificador del elemento se obtiene de su atributo `data-u-command` y no tiene por qué coincidir con el de la orden.

## Modo preestablecido

Univer PDFs no proporciona actualmente un paquete preestablecido. Cree aplicaciones PDF en modo Plugin.

## Controles de edición y vista [#ribbon-controls]

La pestaña Inicio proporciona copia, corte, pasta, modo de herramienta y herramientas de anotación. Inserta proporciona páginas, cuadros de texto, párrafos, listas, tablas, imágenes y separadores. Ver proporciona zoom, pantalla completa, visibilidad de anotar y desplazamiento continuo. Selección de texto o una tabla abre sus controles contextuales, incluyendo el estilismo de inspección y tabla. Estos controles de cinta requieren el ajuste por defecto `editor.enabled: true` en `UniverPdfsUIPlugin`.

## Actualizar los menús con la API Facade [#menu-facade]

### Actualizaciones en ejecución

Importar `@univerjs/ui/facade` antes de crear `univerAPI` con `FUniver.newAPI(univer)`. [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) fusiona los cambios, conserva campos no especificados y refresca los menús. Los overrides también se aplican a los menús registrados más adelante.

```ts
import '@univerjs/ui/facade'

univerAPI.updateMenuConfig({
  'pdf.menu.tool.highlight': { gridLayout: { row: 2, column: 1, showLabel: true, width: 96 } },
})
```

`gridLayout` afecta sólo a la rejilla Ribbon. Cada grupo tiene dos filas, y `row` y `column` comienzan a 1. Una posición explícita tiene precedencia sobre el orden visual establecido en `order`, así que actualice ambos elementos cuando se intercambian dos celdas ocupadas. Los campos opcionales heredan la configuración o esquema existente. Ver [`IRibbonGridLayout`](/reference/packages/plugins/univerjs/ui#iribbongridlayout) para los lazos, etiquetas, anchos y tamaños de iconos.

Mantenga la edición activada en `UniverPdfsUIPlugin`: `editor.enabled: false` salta el registro del producto Ribbon, y los overrides del menú no registran los botones perdidos.

Para botones y disparadores de submenú personalizados, [`createMenu()` y `createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem) también acepta `order` y `gridLayout`; `appendTo()` los registra. El contenido de popup no utiliza el diseño de la rejilla de cinta.
