---
title: 圖片與分隔線
description: 向 PDF 頁面插入受管理圖片、更新圖片資源並加入向量分隔線。
---

PDF 圖片是託管的可編輯資源。URL、UUID、base64 字串或 blob 源均可傳給 `insertImageAsync()`；如需分階段插入，可使用分離式 builder。

## 插入圖片

```ts
const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  {
    left: 36,
    top: 36,
    width: 144,
    height: 72,
    opacity: 0.9,
  }
)

image.setRotation(-4).bringToFront()
```

自動源檢測只將絕對的 `http` 與 `https` 地址識別為 URL，不接受相對路徑。請改用絕對 URL、有效的託管資源 UUID 或 base64 資料。

## 使用圖片 builder

```ts
const imageInfo = page
  .newImage()
  .setSource('https://example.com/assets/chart.png')
  .setAbsolutePosition(216, 36)
  .setSize(240, 135)
  .setOpacity(0.85)
  .build()

const chart = page.insertImage(imageInfo)
```

`build()` 在分離的物件上操作，不會修改 PDF，其返回值傳給 `insertImage()`。如需更新已有的託管圖片，請使用 live 的 `setSource()` 方法以及變換、裁剪與不透明度方法。

## 裁剪圖片

選中圖片，開啟屬性面板，然後選擇**裁剪圖片**。拖曳裁剪區域或四角調整可見範圍，可選擇固定比例，然後套用裁剪。裁剪結果會持久儲存，並進入撤銷與重做歷史。

`FPdfImage.getCrop()` 返回以 PDF 點為單位、從圖片框架左上角量起的裁剪視窗。圖片未裁剪時返回 `null`。`setCrop({ left, top, right, bottom })` 使用同一組座標，並要求 `right > left`、`bottom > top`。非有限值或空矩形會拋出 `RangeError`。

裁剪值始終相對於圖片框架，因此調整圖片大小或旋轉後，可見區域保持不變。

## 加入分隔線

```ts
const divider = page.insertDivider({
  left: 36,
  top: 144,
  width: 420,
  strokeWidth: 1,
})

divider.setStroke({
  width: 2,
  color: '#3366ff',
})
```

分隔線的幾何與描邊長度均以 PDF 點為單位。`getStroke()` 返回分離的快照，`setStroke()` 僅替換描邊，不改變幾何。

`FPdfImage` 還提供 `getSource()`、`getImageSourceType()`、`setSource()`、`getCrop()`、`setCrop()`、`getOpacity()`、`setOpacity()` 和 `remove()`。圖片的不透明度必須介於 `0` 和 `1` 之間。
