Корень Facade API объединяет совместно используемое время выполнения Univer с плагинами, зарегистрированными приложением PDF. Эта страница охватывает механизмы, которые ведут себя одинаково в продуктах Univer, и она не предполагает опыт работы с другим типом документа Univer. Для блоков PDF и точек входа в страницу продолжайте с [Univer PDF API](/guides/pdfs/features/core/pdfs-api) .

## Создание объекта API

Создайте одну обертку `FUniver` после регистрации экземпляра Univer и необходимых плагинов:

```ts
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

Фасадные записи, импортированные до этого вызова, добавляют свои методы к одному и тому же объекту.

## Команды

`executeCommand()` запускает зарегистрированную команду асинхронно. Используйте `syncExecuteCommand()` только тогда, когда команда явно поддерживает синхронное выполнение. Для обычных операций PDF методы Facade остаются предпочтительной точкой входа.

## События

```ts
const commandLog = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ id }) => console.log('Executed:', id)
)

// Позже удалите слушатель.
commandLog.dispose()
```

Используйте `BeforeCommandExecute`, когда приложение должно проверить или отменить команду. `LifeCycleChanged` сообщает об общих этапах редактора, таких как `Rendered` и `Steady`.

## Отмена и повтор

Отмена и переделка применяются к Univer Unit, который в настоящее время имеет фокус, и оба обещания возврата:

```ts
await univerAPI.undo()
await univerAPI.redo()
```

Изменения в PDF-фасаде с обратной операцией входят в историю сфокусированного PDF-блока.

## Системный буфер обмена

Когда `UniverPdfsUIPlugin` зарегистрирован и включено редактирование PDF, методы `copy()` и `paste()` UI Facade отправляют команды буфера обмена в сфокусированный блок PDF:

```ts
import '@univerjs/ui/facade'

await univerAPI.copy()
await univerAPI.paste()
```

Для редактируемых PDF-объектов плагин PDF UI сохраняет скопированную полезную нагрузку в текущей сессии браузера, а не записывает ее в буфер обмена операционной системы. Нативное редактирование текста в браузере по-прежнему следует за поведением буфера обмена браузера.

## UI

Фасад пользовательского интерфейса отображает сообщения, открывает диалоги и боковые панели, регистрирует компоненты и управляет встроенными частями пользовательского интерфейсов:

```ts
univerAPI.setUIVisible(univerAPI.Enum.BuiltInUIPart.TOOLBAR, true)
```

Эти методы требуют `UniverUIPlugin`, а элементы управления редактированием PDF также требуют `UniverPdfsUIPlugin`.

## WebSocket

WebSocket — необязательная возможность. Зарегистрируйте плагин Network и импортируйте его точку входа Facade до создания объекта API:

```ts
import { UniverNetworkPlugin } from '@univerjs/network'

import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)

const socket = univerAPI.createSocket('wss://example.com/pdfs')
socket.open$.subscribe(() => socket.send('ready'))
```

Протоколы сообщений, аутентификация, повторное подключение и обработка конфликтов в сотрудничестве остаются ответственностью хост-приложения.

## Перечисления

`univerAPI.Enum` раскрывает перечни времени выполнения и перечни, добавленные PDF Facade:

```ts
const lifecycle = univerAPI.Enum.LifecycleStages.Steady
const annotationType = univerAPI.Enum.PdfAnnotationType.HIGHLIGHT
```

## Утилиты

`univerAPI.Util` предоставляет общие средства форматирования чисел, операций с прямоугольниками и другие инструменты:

```ts
const payload = univerAPI.Util.tools.deepClone({
  pageId: 'page-1',
  selectedElementIds: ['element-1'],
})
```

Полный общий API документирован в [Ссылка на фасад](/reference/facade/univer).
