---
title: Imágenes y divisores
description: Inserte imágenes administradas, actualice recursos de imagen y añada divisores vectoriales a páginas PDF.
---

Las imágenes PDF son gestionadas, recursos editables. Pase una URL, UUID, cadena base64 o fuente de bloque a `insertImageAsync()`, o utilice el constructor desprendido para insertar en etapas.

## Insertar una imagen

```ts
const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  {
    left: 36,
    top: 36,
    width: 144,
    height: 72,
    opacity: 0.9,
  }
)

image.setRotation(-4).bringToFront()
```

La detección automática de fuentes reconoce las URL absolutas `http` y `https`. No acepta un camino relativo como fuente de URL, por lo que utiliza una URL absoluta, un UUID de recursos gestionados válidos, o datos base64.

## Usar el builder de imágenes

```ts
const imageInfo = page
  .newImage()
  .setSource('https://example.com/assets/chart.png')
  .setAbsolutePosition(216, 36)
  .setSize(240, 135)
  .setOpacity(0.85)
  .build()

const chart = page.insertImage(imageInfo)
```

`build()` opera en un objeto separado y no modifica el PDF. Pase el resultado a `insertImage()`. Para actualizar una imagen administrada existente, utilice el método `setSource()` en vivo y los métodos de transformación, cultivo y opacidad en vivo.

## Añadir un divisor

```ts
const divider = page.insertDivider({
  left: 36,
  top: 144,
  width: 420,
  strokeWidth: 1,
})

divider.setStroke({
  width: 2,
  color: '#3366ff',
})
```

La geometría de los vídeos y las longitudes de los trazos se miden en puntos PDF. `getStroke()` devuelve una instantánea desprendida, y `setStroke()` reemplaza el trazo sin modificar la geometría.

`FPdfImage` también ofrece `getSource()`, `getImageSourceType()`, `setSource()`, `getCrop()`, `setCrop()`, `getOpacity()`, `setOpacity()` y `remove()`. La opacidad debe estar entre `0` y `1`.
