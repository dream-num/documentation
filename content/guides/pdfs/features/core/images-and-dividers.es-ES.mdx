---
title: Imágenes y divisores
description: Inserte imágenes administradas, actualice recursos de imagen y añada divisores vectoriales a páginas PDF.
---

Las imágenes PDF son recursos editables administrados. Use `insertImageAsync()` con una URL, UUID, cadena base64 o blob, o utilice el builder independiente para una inserción por etapas.

## Insertar una imagen

```ts
const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  {
    left: 36,
    top: 36,
    width: 144,
    height: 72,
    opacity: 0.9,
  }
)

image.setRotation(-4).bringToFront()
```

La detección automática reconoce URL absolutas `http` y `https`. Las rutas URL relativas no se aceptan como fuentes URL; use una URL absoluta, un UUID válido de recurso administrado o datos base64.

## Usar el builder de imágenes

```ts
const imageInfo = page
  .newImage()
  .setSource('https://example.com/assets/chart.png')
  .setAbsolutePosition(216, 36)
  .setSize(240, 135)
  .setOpacity(0.85)
  .build()

const chart = page.insertImage(imageInfo)
```

`build()` es independiente y no modifica el PDF. Pase su resultado a `insertImage()`. Actualice una imagen administrada existente mediante sus métodos activos de fuente, transformación, recorte y opacidad.

## Añadir un divisor

```ts
const divider = page.insertDivider({
  left: 36,
  top: 144,
  width: 420,
  strokeWidth: 1,
})

divider.setStroke({
  width: 2,
  color: '#3366ff',
})
```

La geometría del divisor y las longitudes del trazo usan puntos PDF. `getStroke()` devuelve una instantánea independiente y `setStroke()` sustituye el trazo sin cambiar la geometría.

`FPdfImage` también ofrece `getSource()`, `getImageSourceType()`, `setSource()`, `getCrop()`, `setCrop()`, `getOpacity()`, `setOpacity()` y `remove()`. La opacidad debe estar entre `0` y `1`.
