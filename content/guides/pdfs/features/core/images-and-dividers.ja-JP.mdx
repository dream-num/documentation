---
title: 画像と区切り線
description: 管理対象画像の挿入、画像リソースの更新、PDF ページへのベクター区切り線の追加を行います。
---

PDF画像は管理、編集可能なリソースです。URL、UID、base64文字列、または`insertImageAsync()`にbobソースを渡すか、離脱したビルダーを使用してステージにインサートします。

## 画像を挿入する

```ts
const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  {
    left: 36,
    top: 36,
    width: 144,
    height: 72,
    opacity: 0.9,
  }
)

image.setRotation(-4).bringToFront()
```

自動ソース検出は、絶対の`http`と`https` URLを認識します。 URLソースとして相対パスを受け入れないので、絶対URL、有効な管理リソースUID、またはベース64データを使用します。

## 画像ビルダーを使う

```ts
const imageInfo = page
  .newImage()
  .setSource('https://example.com/assets/chart.png')
  .setAbsolutePosition(216, 36)
  .setSize(240, 135)
  .setOpacity(0.85)
  .build()

const chart = page.insertImage(imageInfo)
```

`build()`は、離脱されたオブジェクトで動作し、PDFを変更しません。 結果を`insertImage()`に渡します。 既存の管理されたイメージを更新するには、ライブ`setSource()`メソッドとライブトランス、クロップ、オパシティメソッドを使用します。

## 画像をトリミングする

画像を選択してプロパティインスペクターを開き、**画像をトリミング**を選択します。トリミング領域またはその角をドラッグして表示範囲を設定し、必要に応じて固定比率を指定してから適用します。トリミングは永続化され、元に戻す・やり直す操作の対象になります。

`FPdfImage.getCrop()` は、画像フレームの左上隅を基準とした PDF ポイント単位のトリミング領域を返します。画像がトリミングされていない場合は `null` を返します。`setCrop({ left, top, right, bottom })` は同じ座標を適用し、`right > left` と `bottom > top` を必要とします。有限でない値や空の矩形を渡すと `RangeError` をスローします。

トリミング値は画像フレームを基準に保たれるため、画像のサイズ変更や回転を行っても表示範囲は変わりません。

## 区切り線を追加する

```ts
const divider = page.insertDivider({
  left: 36,
  top: 144,
  width: 420,
  strokeWidth: 1,
})

divider.setStroke({
  width: 2,
  color: '#3366ff',
})
```

ジオメトリとストロークの長さをPDFポイントで測定します。 `getStroke()`は、切り離されたスナップショットを返し、`setStroke()` はジオメトリを変更することなくストロークを交換します。

`FPdfImage` は `getSource()`、`getImageSourceType()`、`setSource()`、`getCrop()`、`setCrop()`、`getOpacity()`、`setOpacity()`、`remove()` も提供します。透明度は `0` から `1` です。
