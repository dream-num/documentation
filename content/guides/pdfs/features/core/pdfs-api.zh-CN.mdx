title: Univer PDFs API
description: 通过 PDF Facade API 创建、查找、保存、进入和卸载 PDF 单元。
---

PDF Facade 为 `FUniver` 增加了 PDF 单元和页面入口。创建 API 对象之前，应先导入副作用入口。

## 启用 PDF Facade

```ts
import { FUniver } from '@univerjs/core/facade'

import '@univerjs-pro/pdfs/facade'

const univerAPI = FUniver.newAPI(univer)
```

在 Univer 实例上注册 `UniverPdfsPlugin`，应用即可承载 PDF 单元。

## 创建、查找和保存 PDF 单元

省略 `document` 时，`createPdf()` 会创建一个仅含一张空白 A4 页面的单元。如需恢复单元，应传入之前 `save()` 返回的快照。

```ts
const pdf = univerAPI.createPdf({
  id: 'project-brief',
  name: 'Project brief',
})

const activePdf = univerAPI.getActivePdf()
const samePdf = univerAPI.getPdf(pdf.getId())
const snapshot = pdf.save()
```

更新运行中的 PDF 时，应使用 Facade 方法或命令。保存的快照是独立的持久化数据。

## 从其他 PDF 追加页面 [#append-pages]

`FPdf.appendPdf(source)` 会追加 `IPdfUnitData` 快照中的全部页面，并记录到撤销与重做历史。PDF 不再打开时，该方法返回 `false`。

Exchange facade 还提供两个方法，用于处理已经打开的 PDF。`univerAPI.appendPdfAsync(file, unitId?)` 会导入文件并将页面追加到指定 PDF。省略单元 ID 时追加到当前 PDF。没有目标或页面无法追加时，该方法返回 `false`。`univerAPI.exportPdfAsync(unitId?)` 会先提交画布上仍在编辑的文本，再导出打开的 PDF。提交失败或文档已不再打开时，该方法返回 `undefined`。

这些 Exchange 方法由 `@univerjs-pro/pdfs-exchange-client/facade` 添加到 `FUniver`：

```ts
const pdf = univerAPI.getActivePdf()
pdf?.appendPdf(importedSnapshot)

await univerAPI.appendPdfAsync(file)          // current PDF
await univerAPI.appendPdfAsync(file, unitId)  // specific PDF
const exported = await univerAPI.exportPdfAsync()
```

## 进入页面

`FPdfPage` 是访问页面可编辑叠加层和导入原生文本的常用入口：

```ts
const firstPage = pdf.getPageByIndex(0) ?? pdf.insertPage()
const elements = firstPage.getElements()
const nativeText = firstPage.getTextSpans()
```

具体操作请参阅[页面与元素](/guides/pdfs/features/core/pages-and-elements)、[文本与列表](/guides/pdfs/features/core/text-and-lists)、[表格](/guides/pdfs/features/core/tables)、[图片与分隔线](/guides/pdfs/features/core/images-and-dividers)或[批注与原生文本](/guides/pdfs/features/core/annotations-and-native-text)。

## 卸载 PDF 单元

不再需要某个 PDF 单元时，应按 ID 卸载。仅在销毁整个应用时，才释放根 `univer` 实例。

```ts
const pdf = univerAPI.getActivePdf()

if (pdf) {
  univerAPI.disposeUnit(pdf.getId())
}
```

准确的签名与返回类型请参阅 [PDF Facade 参考](/reference/facade/pdf)。
