PDF 편집 API는 Univer 명령을 통해 실행되며 역연산이 있으면 실행 취소 및 다시 실행에 참여합니다. 변경할 콘텐츠에 맞는 주제부터 시작하세요.

## 편집 주제

- [페이지와 요소](/guides/pdfs/features/core/pages-and-elements): 페이지 삽입, 편집 가능한 오버레이 열거, 변환, 쌓임 순서, 잠금 및 제거.
- [텍스트와 목록](/guides/pdfs/features/core/text-and-lists): 텍스트 상자, 문단 블록 및 의미론적 목록 편집.
- [표](/guides/pdfs/features/core/tables): 그리드 삽입과 크기 조정, 셀 업데이트 및 테마 적용.
- [이미지와 구분선](/guides/pdfs/features/core/images-and-dividers): 관리 이미지와 벡터 구분선 삽입.
- [주석과 네이티브 텍스트](/guides/pdfs/features/core/annotations-and-native-text): 지원되는 주석 추가 및 가져온 텍스트 승격.

## 작업 결합

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  { left: 36, top: 36, width: 144, height: 72 }
)

image.setRotation(-4).bringToFront()
```

퍼사드 배치 값은 PDF 포인트를 사용합니다. URL 기반 이미지에는 절대 `http` 또는 `https` URL을 사용하세요. 자동 소스 감지는 상대 URL 경로를 허용하지 않습니다.

유닛 만들기, 찾기, 저장 및 전체 래퍼 개요는 [Univer PDFs API](/guides/pdfs/features/core/pdfs-api)를 참고하세요.
