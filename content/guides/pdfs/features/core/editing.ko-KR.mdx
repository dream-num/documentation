PDF 편집 API는 Univer 명령에 내장되어 있으며, 명령이 역동적 인 동작을 가질 때 불행하고 재도에 참여합니다. 변경할 필요가있는 콘텐츠를 일치시키는 주제로 시작하십시오.

## 편집 주제

- [페이지 및 요소](/guides/pdfs/features/core/pages-and-elements)는 페이지를 삽입하고, 편집 가능한 오버레이를 삽입하고, 변환하고, 겹쳐 쌓이고, 잠그고, 또는 성분을 제거하.
- [텍스트 및 목록](/guides/pdfs/features/core/text-and-lists)는 텍스트 상자, 단락 및 세분화 목록을 포함합니다.
- [의 특징](/guides/pdfs/features/core/tables)는 삽입하고 격자를 재조합하고, 세포를 새롭게 하고, 테마를 적용합니다.
- [이미지 및 디바이더](/guides/pdfs/features/core/images-and-dividers)는 관리된 이미지와 벡터 분배자를 포함합니다.
- [주석 및 기본 텍스트](/guides/pdfs/features/core/annotations-and-native-text)는 지원되는 주석을 포함하고 수입한 원본을 승진시키는 방법.

## 작업 결합

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  { left: 36, top: 36, width: 144, height: 72 }
)

image.setRotation(-4).bringToFront()
```

Facade 배치 값은 PDF 포인트로 측정됩니다. URL에서 제공되는 이미지의 경우 절대 `http` 또는 `https` URL을 사용하십시오. 자동 소스 탐지는 상대 경로에 허용되지 않습니다.

단위 생성, 조회, 저장 및 래퍼의 완전한 개요를 위해, [Univer PDF의 API](/guides/pdfs/features/core/pdfs-api)를 보십시오.
