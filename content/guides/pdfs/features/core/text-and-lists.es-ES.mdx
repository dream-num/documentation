---
title: Texto y listas
description: Inserte y edite cuadros de texto, bloques de párrafo y listas PDF semánticas.
---

El texto PDF puede ser un cuadro de texto editable simple, un marco de párrafo basado en una historia o una lista semántica.

## Cuadros de texto

```ts
const textBox = page.insertTextBox({
  text: 'Quarterly review',
  left: 36,
  top: 36,
  width: 280,
  height: 48,
  fontSize: 20,
})

textBox.setTextStyle({ bold: true, fill: '#1d4ed8' })
textBox.setTextStyle({ italic: true }, { start: 0, end: 9 })
```

`setTextStyle(style, range?)` aplica un estilo a todo el cuadro o a un rango UTF-16 cuyo inicio es inclusivo y cuyo final es exclusivo.

## Párrafos

Los bloques de párrafo tienen identificadores estables. Léalos con `getBlocks()` antes de actualizar el texto, el estilo o el orden.

```ts
const paragraph = page.insertParagraph({
  text: 'Release summary',
  left: 36,
  top: 108,
  width: 280,
  height: 96,
})

paragraph.appendBlock({
  text: 'Approved for publication',
  textStyle: { italic: true },
})

const [block] = paragraph.getBlocks()

if (block) {
  paragraph.setBlockStyle(block.id, { align: 'center' })
}
```

## Listas semánticas

```ts
const list = page.insertList({
  text: 'Verify content',
  kind: univerAPI.Enum.PdfListKind.ORDERED,
  preset: univerAPI.Enum.PdfListPresetId.ORDERED_NUMBER_ALPHA,
  left: 36,
  top: 228,
  width: 280,
  height: 120,
})

list.insertItem(1, { text: 'Export final PDF' })
list.insertItem(2, { text: 'Archive source', level: 1 })
list.setStartNumber(3)
```

Los niveles de lista van de `0` a `8`. Aumentar un nivel requiere un elemento anterior que pueda actuar como padre; `setStartNumber()` solo está disponible para listas ordenadas.

Los cuadros de texto también ofrecen `getTextRuns()`, `getTextAnchor()` y `setTextAnchor()`. Los párrafos ofrecen `insertBlock()`, `appendBlock()`, `setBlockText()`, `setBlockStyle()` y `removeBlock()`.
