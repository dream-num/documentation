`FPdfTable`는 안정적인 셀 래퍼와 구조 그리드를 유지하고 각 셀은 하나의 편집 가능한 텍스트 이야기를 보유하고 있습니다.

## 표 삽입 및 편집

```ts
const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Owner', 'Status', 'Docs', 'Ready'],
  left: 36,
  top: 36,
  width: 360,
  height: 108,
})

table.resize(3, 2)
table.getCell(2, 0).setText('Legal')
table.getCell(2, 1).setText('Review')
```

행과 열은 긍정적 인 안전 정수이어야하며 테이블은 10,000 셀을 초과 할 수 없습니다. 과잉 지역에서 세포의 위치를 보존합니다.

## 표 테마 적용

```ts
const [preset] = univerAPI.getPdfTableThemePresets()

if (preset) {
  table.setTheme({
    styleId: preset.id,
    options: { firstRow: true },
  })
}
```

`getPdfTableThemePresets()`는 detached `{ id, group }` descriptors를 반환합니다. `styleId`로 사전 설정의 `id`를 사용하십시오; `setTheme()`에 descriptor 자체를 통과하지 마십시오.

## 셀 스타일

```ts
table.getCell(0, 0).setStyle({
  fill: { color: '#eef3ff' },
  fontColor: '#1d4ed8',
  horizontalAlignment: univerAPI.Enum.HorizontalAlign.CENTER,
  verticalAlign: univerAPI.Enum.PdfTableCellVerticalAlign.MIDDLE,
})
```

`FPdfTableCell.setStyle()`는 컨테이너 필드를 `fontColor`와 `horizontalAlignment`로 받아 전체 셀에 적용할 수 있습니다. `PdfTableCellVerticalAlign`를 사용하여 `univerAPI.Enum`을 사용하십시오.

표 메서드는 `getRowCount()`, `getColumnCount()`, `getCell()`, `resize()`, `getTheme()`, `setTheme()`입니다. 셀 메서드는 `getText()`, `setText()`, `getStyle()`, `setStyle()`입니다.
