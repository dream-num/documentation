PDF-изображения управляются, редактируются ресурсами. Передайте URL-адрес, UUID, строку base64 или источник blob в `insertImageAsync()` или используйте отдельный конструктор для поэтапной вставки.

## Вставка изображения

```ts
const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  {
    left: 36,
    top: 36,
    width: 144,
    height: 72,
    opacity: 0.9,
  }
)

image.setRotation(-4).bringToFront()
```

Автоматическое обнаружение источника распознает абсолютные URL-адреса `http` и `https`. Он не принимает относительный путь в качестве источника URL, поэтому используйте абсолютный URL-адрес, действительный UUID с управляемым ресурсом или данные base64.

## Использование построителя изображений

```ts
const imageInfo = page
  .newImage()
  .setSource('https://example.com/assets/chart.png')
  .setAbsolutePosition(216, 36)
  .setSize(240, 135)
  .setOpacity(0.85)
  .build()

const chart = page.insertImage(imageInfo)
```

`build()` работает на отдельном объекте и не изменяет PDF. Передайте результат `insertImage()`. Чтобы обновить существующее управляемое изображение, используйте метод live `setSource()` и методы live Transform, crop и непрозрачность.

## Обрезка изображения

Выберите изображение, откройте инспектор свойств и выберите **Обрезать изображение**. Перетащите область обрезки или ее углы, чтобы задать видимое окно, при необходимости с фиксированным соотношением, затем примените обрезку. Обрезка сохраняется и участвует в отмене и переделке.

`FPdfImage.getCrop()` возвращает окно обрезки в пунктах PDF, отсчитываемое от верхнего левого угла рамки изображения, или `null`, когда изображение не обрезано. `setCrop({ left, top, right, bottom })` применяет те же координаты и требует `right > left` и `bottom > top`. Он выбрасывает `RangeError` для неконечных или пустых прямоугольников.

Значения обрезки остаются относительными к рамке изображения, поэтому изменение размера или поворот изображения сохраняет ту же видимую область.

## Добавление разделителя

```ts
const divider = page.insertDivider({
  left: 36,
  top: 144,
  width: 420,
  strokeWidth: 1,
})

divider.setStroke({
  width: 2,
  color: '#3366ff',
})
```

Геометрия разделителя и длина хода измеряются в точках PDF. `getStroke()` возвращает отдельный снимок, а `setStroke()` заменяет ход без изменения геометрии.

`FPdfImage` также предоставляет `getSource()`, `getImageSourceType()`, `setSource()`, `getCrop()`, `setCrop()`, `getOpacity()`, `setOpacity()` и `remove()`. Непрозрачность должна быть от `0` до `1`.
