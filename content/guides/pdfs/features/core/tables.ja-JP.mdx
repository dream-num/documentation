---
title: テーブル
description: Facade API で構造化 PDF テーブルを挿入、サイズ変更、スタイル設定、編集します。
---

`FPdfTable`は、安定したセルラッパーで構造化されたグリッドを維持し、各セルは1つの編集可能なテキストストーリーを保持します。

## テーブルを挿入、編集する

```ts
const table = page.insertTable({
  rowCount: 2,
  columnCount: 2,
  cellTexts: ['Owner', 'Status', 'Docs', 'Ready'],
  left: 36,
  top: 36,
  width: 360,
  height: 108,
})

table.resize(3, 2)
table.getCell(2, 0).setText('Legal')
table.getCell(2, 1).setText('Review')
```

列と列は正の安全な整数であり、テーブルは10,000個のセルを上回ることができません。 再サイズは、重なり領域内の細胞の位置を保持します。

## テーブルテーマを適用する

```ts
const [preset] = univerAPI.getPdfTableThemePresets()

if (preset) {
  table.setTheme({
    styleId: preset.id,
    options: { firstRow: true },
  })
}
```

`getPdfTableThemePresets()`は、`{ id, group }`の記述子を取り外しました。プリセットの`id`を`styleId`として使用して下さい;`setTheme()`に記述子自体を渡しません。

## セルのスタイル

```ts
table.getCell(0, 0).setStyle({
  fill: { color: '#eef3ff' },
  fontColor: '#1d4ed8',
  horizontalAlignment: univerAPI.Enum.HorizontalAlign.CENTER,
  verticalAlign: univerAPI.Enum.PdfTableCellVerticalAlign.MIDDLE,
})
```

`FPdfTableCell.setStyle()` は、コンテナフィールドと `fontColor`、`horizontalAlignment` (セル全体に適用) を受け取ります。 `univerAPI.Enum`を介して `PdfTableCellVerticalAlign`を使用してください。

## テーブル操作

セルを選択すると **テーブル操作** が表示されます。デスクトップでは、選択したテーブルのプロパティパネルに表示され、コンテキストの **テーブル** タブから開くことができます。モバイルでは、選択ツールバーの **テーブル操作** から同じセクションを開きます。操作では、セルの選択、セルの結合と分割、前後の行または列の挿入が行えます。また、行、列、テーブル全体の削除、**行の高さ** や **列の幅** の設定も行えます。結合には複数セルの矩形選択が必要です。

テーブルの編集は永続化され、元に戻す・やり直す操作の対象になります。

テーブルのメソッドは `getRowCount()`、`getColumnCount()`、`getCell()`、`resize()`、`getTheme()`、`setTheme()` です。セルのメソッドは `getText()`、`setText()`、`getStyle()`、`setStyle()` です。
