La raíz Facade API combina el tiempo de ejecución Univer compartido con los plugins registrados por la aplicación PDF. Esta página cubre mecanismos que se comportan de la misma manera a través de los productos Univer, y no asume experiencia con otro tipo de documento Univer. Para Unidades PDF y puntos de entrada de página, continúe con [Univer API de PDF](/guides/pdfs/features/core/pdfs-api) .

## Crear el objeto API

Cree un solo envoltorio `FUniver` después de registrar la instancia Univer y los plugins necesarios:

```ts
import { FUniver } from '@univerjs/core/facade'

const univerAPI = FUniver.newAPI(univer)
```

Las entradas de fachada importadas antes de esta llamada añaden sus métodos al mismo objeto.

## Comandos

`executeCommand()` ejecuta un comando registrado asincrónicamente. Usar `syncExecuteCommand()` sólo cuando el comando explícitamente soporta la ejecución sincrónica. Para operaciones comunes en PDF, los métodos Facade siguen siendo el punto de entrada preferido.

## Eventos

```ts
const commandLog = univerAPI.addEvent(
  univerAPI.Event.CommandExecuted,
  ({ id }) => console.log('Executed:', id)
)

// Más adelante, elimine el listener.
commandLog.dispose()
```

Utilice `BeforeCommandExecute` cuando la aplicación necesita inspeccionar o cancelar un comando. `LifeCycleChanged` reporta etapas de editor comunes como `Rendered` y `Steady`.

## Deshacer y rehacer

Deshacer y rehacer se aplican a la Univer Unit que actualmente tiene foco, y ambas promesas de retorno:

```ts
await univerAPI.undo()
await univerAPI.redo()
```

Cambios en PDF Facade con una operación inversa entra en la historia de la unidad PDF enfocada.

## Portapapeles del sistema

Cuando `UniverPdfsUIPlugin` está registrado y se habilita la edición de PDF, los métodos `copy()` y `paste()` de la UI Facade envían comandos de portapapeles a la unidad de PDF enfocada:

```ts
import '@univerjs/ui/facade'

await univerAPI.copy()
await univerAPI.paste()
```

Para objetos PDF editables, el plugin PDF UI mantiene la carga de pago copiada en la sesión actual del navegador en lugar de escribirla al portapapeles del sistema operativo. La edición de texto nativo en el navegador sigue todavía el comportamiento del portapapelado del navegador.

## UI

La UI Facade muestra mensajes, abre diálogos y barras laterales, registra componentes y controla partes de la UI integradas:

```ts
univerAPI.setUIVisible(univerAPI.Enum.BuiltInUIPart.TOOLBAR, true)
```

Estos métodos requieren `UniverUIPlugin`, y los controles de edición de PDF también requieren `UniverPdfsUIPlugin`.

## WebSocket

WebSocket es opcional. Registre el plugin Network e importe su entrada Facade antes de crear el objeto API:

```ts
import { UniverNetworkPlugin } from '@univerjs/network'

import '@univerjs/network/facade'

univer.registerPlugin(UniverNetworkPlugin)

const socket = univerAPI.createSocket('wss://example.com/pdfs')
socket.open$.subscribe(() => socket.send('ready'))
```

Los protocolos de mensaje, autenticación, reconexión y manejo de conflictos de colaboración siguen siendo responsabilidad de la aplicación host.

## Enumeraciones

`univerAPI.Enum` expone los enums de tiempo de ejecución y los enumes añadidos por el PDF Facade:

```ts
const lifecycle = univerAPI.Enum.LifecycleStages.Steady
const annotationType = univerAPI.Enum.PdfAnnotationType.HIGHLIGHT
```

## Utilidades

`univerAPI.Util` expone ayudas compartidas como el formato numérico, las operaciones con rectángulos y las herramientas comunes:

```ts
const payload = univerAPI.Util.tools.deepClone({
  pageId: 'page-1',
  selectedElementIds: ['element-1'],
})
```

La API común completa está documentada en el [Facade reference](/reference/facade/univer).
