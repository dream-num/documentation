---
title: 图片与分隔线
description: 向 PDF 页面插入托管图片、更新图片资源并添加矢量分隔线。
---

PDF 图片是托管的可编辑资源。URL、UUID、base64 字符串或 blob 源均可传给 `insertImageAsync()`；如需分阶段插入，可使用分离式 builder。

## 插入图片

```ts
const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  {
    left: 36,
    top: 36,
    width: 144,
    height: 72,
    opacity: 0.9,
  }
)

image.setRotation(-4).bringToFront()
```

自动源检测只将绝对的 `http` 与 `https` 地址识别为 URL，不接受相对路径。请改用绝对 URL、有效的托管资源 UUID 或 base64 数据。

## 使用图片 builder

```ts
const imageInfo = page
  .newImage()
  .setSource('https://example.com/assets/chart.png')
  .setAbsolutePosition(216, 36)
  .setSize(240, 135)
  .setOpacity(0.85)
  .build()

const chart = page.insertImage(imageInfo)
```

`build()` 在分离的对象上操作，不会修改 PDF，其返回值传给 `insertImage()`。如需更新已有的托管图片，请使用 live 的 `setSource()` 方法以及变换、裁剪与不透明度方法。

## 裁剪图片

选中图片，打开属性面板，然后选择**裁剪图片**。拖动裁剪区域或四角调整可见范围，可选择固定比例，然后应用裁剪。裁剪结果会持久保存，并进入撤销与重做历史。

`FPdfImage.getCrop()` 返回以 PDF 点为单位、从图片框架左上角量起的裁剪窗口。图片未裁剪时返回 `null`。`setCrop({ left, top, right, bottom })` 使用同一坐标系，并要求 `right > left`、`bottom > top`。非有限值或空矩形会抛出 `RangeError`。

裁剪值始终相对于图片框架，因此调整图片大小或旋转后，可见区域保持不变。

## 添加分隔线

```ts
const divider = page.insertDivider({
  left: 36,
  top: 144,
  width: 420,
  strokeWidth: 1,
})

divider.setStroke({
  width: 2,
  color: '#3366ff',
})
```

分隔线的几何与描边长度均以 PDF 点为单位。`getStroke()` 返回分离的快照，`setStroke()` 仅替换描边，不改变几何。

`FPdfImage` 还提供 `getSource()`、`getImageSourceType()`、`setSource()`、`getCrop()`、`setCrop()`、`getOpacity()`、`setOpacity()` 和 `remove()`。图片的不透明度必须介于 `0` 和 `1` 之间。
