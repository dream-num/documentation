---
title: 注釈とネイティブテキスト
description: 対応する PDF 注釈を挿入し、インポートしたネイティブテキストを編集可能なテキストボックスに昇格します。
---

編集可能な注釈は永続オーバーレイです。インポートしたテキストは、表示中のテキスト範囲を Facade で昇格するまでネイティブのままです。

## 注釈を挿入する

```ts
const highlight = page.insertAnnotation({
  annotationType: univerAPI.Enum.PdfAnnotationType.HIGHLIGHT,
  left: 36,
  top: 72,
  width: 180,
  height: 18,
  markup: {
    color: '#fde047',
    opacity: 0.6,
  },
})
```

ファサードインサートは、ハイライト、アンダーライン、ストライクアウト、スクイズ、インクアノテーションをサポートしています。インキアノテーションは、非エンプティパスを必要とし、このインサートAPIは、他のコアアノテーションサブタイプを拒否します。

## 注釈のデータとスタイルを取得する

```ts
const markup = highlight.getMarkup()
const style = highlight.getStyle()

highlight.setStyle({
  stroke: { color: '#ca8a04', width: 1 },
  opacity: 0.75,
})
```

`getMarkup()`と`getInk()`は、PDFポイントで測定されたジオメトリを取り外しました。 `setStyle()`では、サポートされているフィリング、ストローク、およびオパシティが`0`および`1`の間である必要があります。

## インポートしたネイティブテキストを置き換える

```ts
const matchingSpan = page
  .getTextSpans()
  .find((span) => span.getText().includes('Draft'))

if (matchingSpan) {
  const textBox = matchingSpan.replaceText('Final')
  textBox.setTextStyle({ bold: true })
}
```

`getTextSpans()`は、現在表示されていないネイティブテキストのスナップショットを返します。 `replaceText()` は、ソースの動作を抑制し、単一の原子ステップとしてキャプチャされた位置で編集可能な `FPdfTextBox`を差し込みます。

`FPdfTextSpan`は、交換後にストールされるスナップショットハンドルです。次のネイティブテキスト操作の前に再び`getTextSpans()`を呼び出します。
