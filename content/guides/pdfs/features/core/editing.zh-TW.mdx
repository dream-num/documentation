---
title: 編輯 PDF
description: 按頁面、文字、表格、圖片、分隔線、註解和原生文字選擇對應的 PDF Facade 工作流程。
---

PDF 編輯 API 透過 Univer 命令執行；當操作具有反向操作時，會進入復原與重做歷史。請從與待修改內容對應的主題開始。

## 編輯主題

- [頁面與元素](/guides/pdfs/features/core/pages-and-elements)：插入頁面、列舉可編輯覆蓋層，以及變換、堆疊、鎖定和移除元素。
- [文字與清單](/guides/pdfs/features/core/text-and-lists)：編輯文字方塊、段落區塊和語意化清單。
- [表格](/guides/pdfs/features/core/tables)：插入與調整格線、更新儲存格並套用主題。
- [圖片與分隔線](/guides/pdfs/features/core/images-and-dividers)：插入受管理圖片和向量分隔線。
- [註解與原生文字](/guides/pdfs/features/core/annotations-and-native-text)：加入受支援的註解並提升匯入文字。

## 組合操作

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  { left: 36, top: 36, width: 144, height: 72 }
)

image.setRotation(-4).bringToFront()
```

Facade 放置值使用 PDF 點。URL 圖片應使用絕對 `http` 或 `https` 位址；自動來源偵測不接受相對 URL 路徑。

單元建立、尋找、儲存與完整包裝器總覽請參閱 [Univer PDFs API](/guides/pdfs/features/core/pdfs-api)。
