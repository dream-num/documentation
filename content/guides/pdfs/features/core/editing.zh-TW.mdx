PDF 編輯 API 均以 Univer 命令實現，當命令帶有逆操作時，該命令會進入撤銷與重做歷史。請從與所需修改內容對應的主題開始閱讀。

## 編輯主題

- [頁面與元素](/guides/pdfs/features/core/pages-and-elements)：包括插入頁面、列舉可編輯疊加層，以及變換、層疊、鎖定與移除元素。
- [文字與列表](/guides/pdfs/features/core/text-and-lists)：包括文字框、段落塊與語義化列表。
- [表格](/guides/pdfs/features/core/tables)：包括插入與調整網格、更新單元格，以及套用主題。
- [圖片與分隔線](/guides/pdfs/features/core/images-and-dividers)：包括託管圖片與向量分隔線。
- [批註與原生文字](/guides/pdfs/features/core/annotations-and-native-text)：包括受支援的批註，以及將匯入文字提升為可編輯內容。

## 組合操作

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.getPageByIndex(0)

if (!page) {
  throw new Error('No active PDF page')
}

const image = await page.insertImageAsync(
  'https://example.com/assets/signature.png',
  { left: 36, top: 36, width: 144, height: 72 }
)

image.setRotation(-4).bringToFront()
```

Facade 的放置值以 PDF 點為單位。圖片來自 URL 時，需提供絕對的 `http` 或 `https` 地址；自動源檢測不接受相對路徑。

單元建立、查詢、儲存以及包裝器的完整說明，見 [Univer PDFs API](/guides/pdfs/features/core/pdfs-api)。
