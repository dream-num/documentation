`@univerjs-pro/pdfs-print` añade una acción de impresión para el PDF activo en el navegador. Se materializa las páginas actuales y abre el diálogo de impresión del sistema.

## Registrar la impresión

```package-install
npm install @univerjs-pro/pdfs-print
```

Añada la hoja de estilo y local de impresión a la configuración del navegador, a continuación, registre el plugin después de `UniverPdfsUIPlugin`:

```ts
import { UniverPdfsPrintPlugin } from '@univerjs-pro/pdfs-print'
import PdfsPrintEnUS from '@univerjs-pro/pdfs-print/locale/en-US'

import '@univerjs-pro/pdfs-print/lib/index.css'

// Merge PdfsPrintEnUS with PdfsUIEnUS and the shared UI locales.
univer.registerPlugin(UniverPdfsPrintPlugin)
```

El plugin añade su propio elemento de menú y progreso de impresión UI. `FUniver` no proporciona ningún método de impresión PDF, por lo que la impresión comienza desde el navegador registrado UI.

## Imprimir no es exportar un archivo

| Flujo de trabajo | Resultado                                                                        | Requiere servidor | Entorno          |
| ---------------- | -------------------------------------------------------------------------------- | :---------------: | ---------------- |
| Imprimir | Abre el diálogo de impresión del navegador o sistema operativo | No | Solo navegador |
| Exportar         | Devuelve un `File` PDF convertido para una descarga controlada por la aplicación |        Sí         | Cliente Exchange |

El diálogo de impresión puede ofrecer “Guardar en PDF”, pero esa opción viene del navegador. Cuando una aplicación necesita un objeto de archivo PDF, un flujo de descarga bajo su propio control, o conversión del lado del servidor, debe utilizar `exportPdfByUnitIdAsync` o `exportPdfBySnapshotAsync`.
