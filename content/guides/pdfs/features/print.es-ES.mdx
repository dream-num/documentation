`@univerjs-pro/pdfs-print` añade una acción Imprimir del navegador para el PDF activo. Materializa las páginas actuales y abre el diálogo de impresión del sistema.

## Registrar la impresión

```package-install
npm install @univerjs-pro/pdfs-print
```

Añada la configuración regional y el estilo de impresión a la configuración del navegador y, a continuación, registre el plugin después de `UniverPdfsUIPlugin`:

```ts
import { UniverPdfsPrintPlugin } from '@univerjs-pro/pdfs-print'
import PdfsPrintEnUS from '@univerjs-pro/pdfs-print/locale/en-US'

import '@univerjs-pro/pdfs-print/lib/index.css'

// Merge PdfsPrintEnUS with PdfsUIEnUS and the shared UI locales.
univer.registerPlugin(UniverPdfsPrintPlugin)
```

El plugin añade su propio elemento de menú y una interfaz de progreso de impresión. No existe ningún método de impresión PDF en `FUniver`; los usuarios inician la impresión mediante la interfaz registrada del navegador.

## Imprimir no es exportar un archivo

| Flujo de trabajo | Resultado                                                                        | Requiere servidor | Entorno          |
| ---------------- | -------------------------------------------------------------------------------- | :---------------: | ---------------- |
| Imprimir         | Abre el diálogo de impresión del navegador o del sistema operativo               |        No         | Solo navegador   |
| Exportar         | Devuelve un `File` PDF convertido para una descarga controlada por la aplicación |        Sí         | Cliente Exchange |

El diálogo de impresión puede ofrecer «Guardar como PDF», pero esa es una capacidad del navegador. Utilice `exportPdfByUnitIdAsync` o `exportPdfBySnapshotAsync` cuando su aplicación necesite un objeto de archivo PDF, un flujo de descarga determinista o una conversión en el servidor.
