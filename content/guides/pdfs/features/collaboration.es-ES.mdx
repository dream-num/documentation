Comience con [Integración de la colaboración](/server/collaboration/browser-integration) para ejecutar el ejemplo oficial, conectar una aplicación y verificar la persistencia y autorización. Los detalles de la implementación y los ejemplos ejecutables de Web/Server se proporcionan en [Inicio rápido de la colaboración](/server/collaboration/quick-start).

Una API de negocios autenticada crea la Unidad llamando al Servicio de Colaboración, y el navegador entonces carga el identificador devuelto por esa llamada. Configure los puntos de entrada HTTP, Session Ticket y WebSocket, como se describe en [Inicio rápido](/server/collaboration/quick-start). Almacene datos a través de un adaptador de base de datos, y ejecute políticas de lectura, unión y edición con [servidor middleware](/server/collaboration/identity-and-authorization).

<Callout>
  Antes de utilizar estas API, confirme que el backend objetivo es compatible con Unidades PDF. Un ejemplo de colaboración en hojas de trabajo no indica que se admite PDF.
</Callout>

## Cargar un PDF colaborativo

Una unidad PDF creada a través de la API del servidor o a través de `importPdfToUnitIdAsync` está cargada con la colaboración Facade después de que se establezca el usuario actual. Ver [Integración de la colaboración](/server/collaboration/browser-integration) para la configuración del usuario.

```ts
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)

if (!pdf) {
  throw new Error(`PDF unit not found: ${unitId}`)
}

console.log(pdf.getId(), pdf.getName())
```

`loadPdfAsync` carga la instantánea del servidor, prepara la sesión de colaboración y devuelve un `FPdf`. Devuelve `null` si la unidad no puede estar asociada con un PDF.

[Estado de sincronización, registros y recuperación de conflictos](/server/collaboration/browser-integration#sync-status) explica cómo construir indicadores de ahorro y preservar ediciones no reconocidas antes de una recarga.

## Eliminación de la carga integrada por URL de documentos colaborativos [#url-unit-loader-migration]

<Callout type="warning" title="Nota">
  A partir de la versión **1.2.0**, Univer ha eliminado la carga integrada por URL de documentos colaborativos. Ya no lee automáticamente los parámetros `unit` y `type` de la URL para cargar un documento colaborativo.
</Callout>

Un plugin personalizado puede restaurar este comportamiento para aplicaciones que confían en él.

### Integrar el plugin personalizado

Copia los cuatro archivos abajo en el proyecto, preservando esta estructura del directorio:

```text
custom-url-load/
├── plugin.ts
├── controllers/
│   └── data-loader.controller.ts
└── services/
    ├── url.service.ts
    └── web-url.service.ts
```

Registrar el editor y los plugins de colaboración primero, luego establecer el usuario actual antes de registrar `CustomUrlLoadPlugin`.

```ts
import { UserManagerService } from '@univerjs/core'
import { CustomUrlLoadPlugin } from './custom-url-load/plugin'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

univer.registerPlugin(CustomUrlLoadPlugin)
```

Después del registro, el plugin carga el documento en sí, por lo que llamar a `loadPdfAsync()` para el mismo documento es innecesario. Una aplicación que ya carga documentos a través de la Facade puede mantener el enfoque de la sección anterior y manejar URLs de acuerdo a sus propios requisitos.

    ```ts
    import { UniverCollaborationClientPlugin } from '@univerjs-pro/collaboration-client'
    import { DependentOn, Inject, Injector, Plugin } from '@univerjs/core'
    import { CollaborationDataLoaderController } from './controllers/data-loader.controller'
    import { IURLService } from './services/url.service'
    import { WebURLService } from './services/web-url.service'

    @DependentOn(UniverCollaborationClientPlugin)
    export class CustomUrlLoadPlugin extends Plugin {
      static override pluginName = 'CUSTOM_URL_LOAD_PLUGIN'

      constructor(
        _config: undefined,
        @Inject(Injector) protected override readonly _injector: Injector
      ) {
        super()
      }

      override onStarting(): void {
        this._injector.add([IURLService, { useClass: WebURLService }])
        this._injector.add([CollaborationDataLoaderController])

        this.disposeWithMe(this._injector.get(IURLService))
        this.disposeWithMe(this._injector.get(CollaborationDataLoaderController))
      }
    }
    ```

    ```ts
    import { DataLoaderService } from '@univerjs-pro/collaboration-client'
    import { ILogService, Inject, RxDisposable } from '@univerjs/core'
    import { IURLService } from '../services/url.service'

    /**
     * Carga un documento colaborativo desde los parámetros de la URL.
     */
    export class CollaborationDataLoaderController extends RxDisposable {
      constructor(
        @IURLService private readonly _urlService: IURLService,
        @ILogService private readonly _logService: ILogService,
        @Inject(DataLoaderService) private readonly _dataLoaderService: DataLoaderService
      ) {
        super()

        const unitId = this._urlService.getParam('unit')
        const type = this._urlService.getParam('type')
        if (!unitId || !type) {
          return
        }

        this._dataLoaderService.loadUnit(unitId, Number(type))
          .catch((error: unknown) => {
            this._logService.error('[CollaborationDataLoaderController]', error)
          })
      }
    }
    ```

    ```ts
    import type { IURLService } from './url.service'
    import { RxDisposable } from '@univerjs/core'
    import { fromEvent, map, shareReplay, takeUntil } from 'rxjs'

    export class WebURLService extends RxDisposable implements IURLService {
      readonly urlChange$ = fromEvent(window, 'popstate').pipe(
        map(() => undefined),
        takeUntil(this.dispose$),
        shareReplay({ bufferSize: 1, refCount: true })
      )

      getParam(key: string): string | undefined {
        return new URL(window.location.href).searchParams.get(key) ?? undefined
      }

      setParam(key: string, value: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.set(key, value)
        this._updateUrl(url, useReplace)
      }

      removeParam(key: string, useReplace = false): void {
        const url = new URL(window.location.href)
        url.searchParams.delete(key)
        this._updateUrl(url, useReplace)
      }

      private _updateUrl(url: URL, useReplace: boolean): void {
        if (useReplace) {
          window.history.replaceState(window.history.state, '', url.toString())
        } else {
          window.history.pushState(window.history.state, '', url.toString())
        }
      }
    }
    ```
