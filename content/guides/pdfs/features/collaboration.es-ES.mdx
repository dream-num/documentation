## Cargar un PDF colaborativo

Después de crear una unidad PDF mediante la API del servidor o `importPdfToUnitIdAsync`, cárguela con la Facade de colaboración:

```ts
const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)

if (!pdf) {
  throw new Error(`PDF unit not found: ${unitId}`)
}

console.log(pdf.getId(), pdf.getName())
```

`loadPdfAsync` carga la instantánea del servidor, prepara la sesión de colaboración y devuelve un `FPdf`. Devuelve `null` cuando la unidad no puede asociarse con un PDF.
