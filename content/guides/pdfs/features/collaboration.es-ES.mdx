Sigue la [Integración colaborativa](/server/collaboration/browser-integration) para ejecutar el ejemplo, conectar tu aplicación y verificar persistencia y permisos. Los detalles y ejemplos Web/Server están en [Inicio rápido de colaboración](/server/collaboration/quick-start).

Crea el Unit mediante una API de negocio autenticada que invoque Collaboration Service y carga el ID devuelto en el navegador. Configura HTTP, Session Ticket y WebSocket según [Quick Start](/server/collaboration/quick-start), persiste con un Database Adapter y protege lectura, JOIN y edición mediante [permisos del servidor](/server/collaboration/identity-and-authorization).

<Callout>
  Antes de usar estas API, verifica que el backend admita Unit PDF. Un ejemplo funcional de colaboración con Sheets no demuestra compatibilidad con PDF.
</Callout>

## Cargar un PDF colaborativo

Después de crear una unidad PDF mediante la API del servidor o `importPdfToUnitIdAsync`, cárguela con la Facade de colaboración:

Establece el usuario actual antes de cargar el documento. Consulta [Integración de colaboración](/server/collaboration/browser-integration).

```ts
import { UserManagerService } from '@univerjs/core'
import '@univerjs-pro/collaboration-client/facade'

univer.__getInjector().get(UserManagerService).setCurrentUser({ userID, name, avatar })

const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)

if (!pdf) {
  throw new Error(`PDF unit not found: ${unitId}`)
}

console.log(pdf.getId(), pdf.getName())
```

`loadPdfAsync` carga la instantánea del servidor, prepara la sesión de colaboración y devuelve un `FPdf`. Devuelve `null` cuando la unidad no puede asociarse con un PDF.
