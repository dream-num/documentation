先由经过认证的业务 API 调用 Collaboration Service 创建 Unit，再在浏览器中加载返回的标识。按[快速开始](/zh-CN/server/collaboration/quick-start)一起配置 HTTP、Session Ticket 和 WebSocket 入口，通过 Database Adapter 持久化，并用[服务端 Middleware](/zh-CN/server/collaboration/identity-and-authorization)分别校验读取、JOIN 和修改权限。

<Callout>
  使用这些 API 前，请先确认目标服务端支持 PDF Unit；Sheets 协同示例运行成功不能证明 PDF 已受支持。
</Callout>

## 加载协作 PDF

通过服务器 API 或 `importPdfToUnitIdAsync` 创建 PDF 单元后，使用协作 Facade 加载：

```ts
const pdf = await univerAPI.getCollaboration().loadPdfAsync(unitId)

if (!pdf) {
  throw new Error(`PDF unit not found: ${unitId}`)
}

console.log(pdf.getId(), pdf.getName())
```

`loadPdfAsync` 会加载服务器快照、准备协作会话并返回 `FPdf`。当单元无法关联到 PDF 时，它会返回 `null`。
