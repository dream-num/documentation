`@univerjs-pro/pdfs-print` は、アクティブな PDF にブラウザーの印刷操作を追加します。現在のページを実体化し、システムの印刷ダイアログを開きます。

## 印刷を登録する

```package-install
npm install @univerjs-pro/pdfs-print
```

ブラウザー構成に印刷用のロケールとスタイルを追加し、`UniverPdfsUIPlugin` より後にプラグインを登録します。

```ts
import { UniverPdfsPrintPlugin } from '@univerjs-pro/pdfs-print'
import PdfsPrintEnUS from '@univerjs-pro/pdfs-print/locale/en-US'

import '@univerjs-pro/pdfs-print/lib/index.css'

// Merge PdfsPrintEnUS with PdfsUIEnUS and the shared UI locales.
univer.registerPlugin(UniverPdfsPrintPlugin)
```

プラグインは独自のメニュー項目と印刷進捗 UI を追加します。`FUniver` に PDF 印刷メソッドはありません。ユーザーは登録済みのブラウザー UI から印刷を開始します。

## 印刷とファイルエクスポートの違い

| ワークフロー | 結果                                                             | サーバーが必要 | 環境                  |
| ------------ | ---------------------------------------------------------------- | :------------: | --------------------- |
| 印刷         | ブラウザーまたはオペレーティングシステムの印刷ダイアログを開く   |     いいえ     | ブラウザーのみ        |
| エクスポート | アプリケーション側でダウンロードできる変換済み PDF `File` を返す |      はい      | Exchange クライアント |

印刷ダイアログに「PDF として保存」が表示されることがありますが、これはブラウザーの機能です。アプリケーションで PDF ファイルオブジェクト、決定的なダウンロードフロー、またはサーバー側変換が必要な場合は、`exportPdfByUnitIdAsync` または `exportPdfBySnapshotAsync` を使用してください。
