`@univerjs-pro/pdfs-print`は、ブラウザでアクティブなPDF用のプリントアクションを追加します。 現在のページを材料化し、システムプリントダイアログを開きます。

## 印刷を登録する

```package-install
npm install @univerjs-pro/pdfs-print
```

プリントのロケールとスタイルシートをブラウザの設定に追加し、`UniverPdfsUIPlugin`の後にプラグインを登録します。

```ts
import { UniverPdfsPrintPlugin } from '@univerjs-pro/pdfs-print'
import PdfsPrintEnUS from '@univerjs-pro/pdfs-print/locale/en-US'

import '@univerjs-pro/pdfs-print/lib/index.css'

// Merge PdfsPrintEnUS with PdfsUIEnUS and the shared UI locales.
univer.registerPlugin(UniverPdfsPrintPlugin)
```

プラグインは、独自のメニュー項目を追加し、進捗 UI を印刷します。`FUniver` は PDF プリント方法を提供しず、登録済みのブラウザー UI から印刷が開始されます。

印刷は、ページを実体化する前にキャンバス上で編集中のテキストをコミットするため、印刷結果は現在のドキュメントと一致します。

## モバイル対応 [#mobile-support]

先に[モバイルエディター](/guides/pdfs/getting-started/installation#mobile-support)を設定し、`UniverPdfsPrintPlugin` を同じパッケージの `UniverPdfsMobilePrintPlugin` に置き換えます。これには `UniverPdfsMobileUIPlugin` と `UniverMobileUIPlugin` が必要です。モバイルビューアと読み取り専用メニューに印刷を追加し、ドキュメントがモバイルのピクセル上限を超える場合はページキャンバスを縮小します。

## 印刷とファイルエクスポートの違い

| ワークフロー | 結果                                                             | サーバーが必要 | 環境                  |
| ------------ | ---------------------------------------------------------------- | :------------: | --------------------- |
| 印刷 | ブラウザまたはオペレーティングシステムのプリントダイアログを開く | いいえ | ブラウザーのみ |
| エクスポート | アプリケーション側でダウンロードできる変換済み PDF `File` を返す |      はい      | Exchange クライアント |

印刷ダイアログは「PDFとして保存」を提供するかもしれませんが、そのオプションはブラウザから来ます。アプリケーションがPDFファイルオブジェクトを必要とするとき、独自の制御の下でダウンロードフロー、またはサーバー側の変換では、`exportPdfByUnitIdAsync`または`exportPdfBySnapshotAsync`を使用する必要があります。
