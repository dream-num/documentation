`@univerjs-pro/pdfs-print` fügt für das aktive PDF eine Browseraktion zum Drucken hinzu. Das Plugin materialisiert die aktuellen Seiten und öffnet den Druckdialog des Systems.

## Drucken registrieren

```package-install
npm install @univerjs-pro/pdfs-print
```

Fügen Sie der Browser-Einrichtung das Druck-Sprachpaket und den Stil hinzu und registrieren Sie das Plugin anschließend nach `UniverPdfsUIPlugin`:

```ts
import { UniverPdfsPrintPlugin } from '@univerjs-pro/pdfs-print'
import PdfsPrintEnUS from '@univerjs-pro/pdfs-print/locale/en-US'

import '@univerjs-pro/pdfs-print/lib/index.css'

// Merge PdfsPrintEnUS with PdfsUIEnUS and the shared UI locales.
univer.registerPlugin(UniverPdfsPrintPlugin)
```

Das Plugin fügt einen eigenen Menüeintrag und eine Fortschrittsanzeige für den Druck hinzu. Auf `FUniver` gibt es keine PDF-Druckmethode; Benutzer starten den Druck über die registrierte Browseroberfläche.

## Drucken ist kein Dateiexport

| Arbeitsablauf | Ergebnis                                                                          | Server erforderlich | Umgebung        |
| ------------- | --------------------------------------------------------------------------------- | :-----------------: | --------------- |
| Drucken       | Öffnet den Druckdialog des Browsers oder Betriebssystems                          |        Nein         | Nur Browser     |
| Exportieren   | Gibt eine konvertierte PDF-`File` für einen anwendungsgesteuerten Download zurück |         Ja          | Exchange-Client |

Der Druckdialog kann „Als PDF speichern“ anbieten; dies ist jedoch eine Browserfunktion. Verwenden Sie `exportPdfByUnitIdAsync` oder `exportPdfBySnapshotAsync`, wenn Ihre Anwendung ein PDF-Dateiobjekt, einen deterministischen Downloadablauf oder eine serverseitige Konvertierung benötigt.
