PDFs는 편집 중 실행 취소와 다시 실행을 지원합니다. 현재 Sheets, Docs, Slides, Boards, Bases와 같은 전용 버전 기록 패널 플러그인은 제공하지 않습니다. PDFs에 다른 제품의 History UI 플러그인을 등록하지 마세요.

## 실행 취소 및 다시 실행

실행 취소와 다시 실행은 포커스가 있는 Univer 단위에 적용됩니다.

```ts
await univerAPI.undo()
await univerAPI.redo()
```

이 작업은 서버 측 버전 목록을 생성하거나 이전 세션의 버전을 가져오지 않습니다. 다른 작업은 [일반 API](/guides/pdfs/features/core/general-api)를 참고하세요.

## 세션 간 버전 관리

먼저 [PDFs 공동 편집](/guides/pdfs/features/collaboration)을 연결하세요. 버전을 장기간 보관하려면 [Office 기록 서비스](/server/collaboration/extensions)를 참고하고, 대상 릴리스의 PDF 데이터 지원 여부를 확인한 뒤 애플리케이션에서 버전 목록과 뷰어를 구현하세요. 일반 History 서비스를 추가해도 PDF 기록 패널이 자동으로 생기지는 않습니다.

콘텐츠를 복원하려면 문서 권한 검사, 활성 공동 편집 세션과의 조정, 연결된 PDF 파일 보관이 필요합니다. 페이지에 표시되는 데이터만 교체해서는 충분하지 않습니다.
