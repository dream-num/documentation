## 什么是 Univer PDFs

Univer PDFs 是 Univer Pro 中的 PDF 产品。它将 PDF 表示为正式的 `UNIVER_PDF` 单元，保留导入的源文档，并将已接受的编辑存储在独立的持久化编辑层中。浏览器 UI 会将这两层渲染为一份连续文档。

当应用需要创建或打开 PDF、添加可编辑内容、保持导入 PDF 的保真度、协同修改、导出结果，或将当前文档交给浏览器打印流程时，可以使用 Univer PDFs。

<Callout type="warning" title="仅支持插件模式">
  PDF 目前没有预设包。请显式注册 PDF 模型、UI 以及可选的功能插件。
</Callout>


## 浏览器兼容性

Univer 的编译目标是 Chrome 88，但这并不意味着 Univer 能够完全支持所有主流环境。我们会尽力确保 Univer 在以下浏览器和 Node.js 环境中能够正常运行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer 依赖 `Intl.Segmenter`，如果你的浏览器或运行时环境暂不支持它，请先补充对应的 polyfill。我们推荐使用
  `@formatjs/intl-segmenter`。
</Callout>

如果遇到无法兼容的情况，请先借助对应的 polyfill 来解决，如果仍然无法解决，请[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 兼容性

<Callout type="warning">
  以下仅适用于在 Node.js 环境中运行 Univer 的情况，并不适用于那些基于 Node.js 使用构建工具在浏览器中运行 Univer 的情况。
</Callout>

Univer 可以在 Node.js 环境中运行，支持的版本为 v18.17.0 及之后的版本。


## 包一览

| 包                                   | 作用                                                                |
| ------------------------------------ | ------------------------------------------------------------------- |
| `@univerjs-pro/pdfs`                 | PDF 单元模型、持久化编辑原语、快照契约和 PDF Facade 入口            |
| `@univerjs-pro/pdfs-ui`              | Canvas 渲染器、连续页面 UI、编辑器控件、语言包和可选的缩略图 Worker |
| `@univerjs-pro/pdfs-editor`          | 面向启用协作的 Univer 应用的 PDF 编辑器生命周期集成                 |
| `@univerjs-pro/pdfs-exchange-client` | 由服务器支持的 PDF 导入导出、菜单集成和 Exchange Facade API         |
| `@univerjs-pro/pdfs-print`           | 浏览器打印菜单、打印准备 UI、样式和语言包                           |

请让所有 `@univerjs/*` 和 `@univerjs-pro/*` 包保持相同版本。

## 最小浏览器配置

本地查看器和编辑器需要 Univer 公共 UI、Pro 许可证、PDF 模型和 PDF UI 插件。

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import { LocaleType, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import { UniverUIPlugin } from '@univerjs/ui'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {},
})

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Project brief' })
```

如果没有提供导入的文档，`createPdf` 会创建包含一个 A4 空白页的 PDF。
