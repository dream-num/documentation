## Univer PDFs 是什么

Univer PDFs 是 Univer SDK Pro 中的 PDF 产品。它将 PDF 表示为正式的 `UNIVER_PDF` 单元，保留导入的源文档，并将已接受的编辑存储在独立的持久化编辑层中。浏览器 UI 会将这两层渲染为一份连续文档。

当应用需要创建或打开 PDF、添加可编辑内容、保持导入 PDF 的保真度、协同修改、导出结果，或将当前文档交给浏览器打印流程时，可以使用 Univer PDFs。

<Callout type="warning" title="仅支持插件模式">
  PDF 目前没有预设包。请显式注册 PDF 模型、UI 以及可选的功能插件。
</Callout>


## 浏览器兼容性

Univer SDK 的编译目标是 Chrome 88，但这并不意味着 Univer SDK 能够完全支持所有主流环境。我们会尽力确保 Univer SDK 在以下浏览器和 Node.js 环境中能够正常运行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer SDK 依赖 `Intl.Segmenter`，如果你的浏览器或运行时环境暂不支持它，请先补充对应的 polyfill。我们推荐使用
  `@formatjs/intl-segmenter`。
</Callout>

如果遇到无法兼容的情况，请先借助对应的 polyfill 来解决，如果仍然无法解决，请[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 兼容性

<Callout type="warning">
  以下仅适用于在 Node.js 环境中运行 Univer SDK 的情况，并不适用于那些基于 Node.js 使用构建工具在浏览器中运行 Univer SDK 的情况。
</Callout>

Univer SDK 可以在 Node.js 环境中运行，支持的版本为 v18.17.0 及之后的版本。

## 主要功能

- **PDF Unit 模型**：在 `IPdfUnitData` 中存储源文档、页面结构、资源和持久化编辑意图。
- **页面与元素操作**：支持页面导航和插入，以及可编辑的文本、列表、表格、图像、分隔线和批注。
- **浏览器工作台**：提供 PDF 页面渲染、缩略图、选择、编辑控件、剪贴板行为和检查器界面。
- **命令管线**：通过持久化命令和变更批次应用已接受的修改，使保存、撤销和重做共享同一模型。
- **Facade API**：通过 PDF、页面、元素和原生文本对象创建、查找、编辑和保存 PDF Unit。
