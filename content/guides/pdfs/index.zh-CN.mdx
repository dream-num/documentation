## Univer PDFs 是什么

Univer PDFs 是 Univer Office SDK 中的 PDF 产品。一份 PDF 会成为一个正式的 `UNIVER_PDF` 单元，导入的源文档保持原样，已接受的编辑则写入独立的持久化编辑层。浏览器 UI 将这两层渲染为一份连续的文档。

Univer PDFs 是 [Web SDK](/guides/sheets) 中的一种单元类型，不是独立的 SDK。查看器和无界面内容处理由 Web SDK 提供；协同与文件转换属于 [Server SDK](/server)，Agent 工作流属于 [AI SDK](/ai)。

当应用需要创建或打开 PDF、添加可编辑内容、保持导入 PDF 的原貌、协同修改、导出结果，或将当前文档交给浏览器打印流程时，可以使用 Univer PDFs。

<Callout type="warning" title="仅支持插件模式">
  PDF 没有预设包。PDF 模型、UI 和可选的功能插件都需要显式注册。
</Callout>

## 浏览器兼容性

Web SDK 的编译目标是 Chrome 88，但这并不表示所有主流环境都能获得完整支持。Web SDK 会在以下浏览器和 Node.js 版本上持续保持正常运行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK 依赖 `Intl.Segmenter`。如果浏览器或运行时环境不支持该 API，需要先添加 polyfill。推荐使用 `@formatjs/intl-segmenter`。
</Callout>

遇到兼容性问题时，先尝试对应的 polyfill。如果问题仍未解决，请[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 兼容性

<Callout type="warning">
  本说明仅适用于在 Node.js 环境中运行 Web SDK，不适用于通过基于 Node.js 的构建工具在浏览器中运行 Web SDK。
</Callout>

Web SDK 可在 Node.js v18.17.0 及更高版本中运行。

## 主要功能

- PDF Unit 模型将源文档、页面结构、资源和持久化编辑意图保存在 `IPdfUnitData` 中。
- 页面支持导航和插入，文本、列表、表格、图像、分隔线和批注均可编辑。
- 浏览器工作台负责渲染 PDF 页面和缩略图，并处理选择、编辑控件、剪贴板行为和检查器界面。
- 已接受的修改通过持久化命令和变更批次应用，因此保存、撤销和重做都作用于同一套模型。
- Facade API 通过面向应用的 PDF、页面、元素和原生文本对象创建、查找、编辑和保存 PDF Unit。

## 如何使用这些文档

文档导航栏位于页面左侧。页面按从基础到高级的顺序组织，可以按顺序阅读并同步构建应用，也可以直接跳转到所需的部分。侧边栏顶部还可以切换到 Univer PDFs。

右侧的目录用于在当前页面的各章节之间跳转。如需快速查找其他页面，可使用顶部搜索栏或搜索快捷键（Ctrl+K 或 Cmd+K）。

请从[快速开始](/guides/pdfs/getting-started/installation)开始。

## 前置知识

文档力求通俗易懂，但仍假定读者具备基础知识，以便将重点放在 Web SDK 本身。

对 JavaScript 及其周边生态有基本了解，可以获得更好的阅读效果。

如果计划在 Node.js 上运行 Web SDK，还需要对 Node.js 有基本了解。

协同、共享历史、评论和文件转换属于服务端能力。在业务后端中组合 [Univer Server SDK](/server) 的模块即可启用这些能力；身份认证、权限、存储和部署由应用负责。仅在浏览器中编辑 PDF 时，不需要这些能力。
