## Qué es Univer PDFs

Univer PDFs es el producto PDF de Univer Pro. Representa un PDF como una unidad formal `UNIVER_PDF`, conserva el documento de origen importado y almacena las ediciones aceptadas en una capa de edición persistente independiente. La interfaz del navegador representa ambas capas como un único documento continuo.

Utilice Univer PDFs cuando una aplicación necesite crear o abrir archivos PDF, añadir contenido editable, conservar la fidelidad del PDF importado, colaborar en los cambios, exportar el resultado o enviar el documento activo al flujo de impresión del navegador.

<Callout type="warning" title="Solo modo de plugins">
  No existe un paquete preset para PDF. Registre explícitamente el modelo PDF, la interfaz y los plugins de funciones
  opcionales.
</Callout>

## Mapa de paquetes

| Paquete                              | Función                                                                                                                                         |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `@univerjs-pro/pdfs`                 | Modelo de unidad PDF, primitivas de edición persistente, contratos de instantáneas y entrada Facade de PDF                                      |
| `@univerjs-pro/pdfs-ui`              | Renderizador de canvas, interfaz de páginas continuas, controles de edición, paquetes de configuración regional y worker de miniaturas opcional |
| `@univerjs-pro/pdfs-editor`          | Integración del ciclo de vida del editor PDF para una aplicación Univer con colaboración habilitada                                             |
| `@univerjs-pro/pdfs-exchange-client` | Importación y exportación de PDF respaldadas por servidor, integración de menús y API Facade de Exchange                                        |
| `@univerjs-pro/pdfs-print`           | Menú de impresión del navegador, interfaz de preparación de impresión, estilos y paquetes de configuración regional                             |

Mantenga todos los paquetes `@univerjs/*` y `@univerjs-pro/*` en la misma versión.

## Configuración mínima para el navegador

El visor y editor local requiere la interfaz compartida de Univer, la licencia Pro, el modelo PDF y el plugin de interfaz PDF.

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import { LocaleType, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import { UniverUIPlugin } from '@univerjs/ui'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {},
})

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Project brief' })
```

`createPdf` crea un PDF en blanco con una página A4 cuando no se proporciona ningún documento importado.
