## 什麼是 Univer PDFs

Univer PDFs 是 Univer Pro 中的 PDF 產品。它將 PDF 表示為正式的 `UNIVER_PDF` 單元，保留匯入的來源文件，並將已接受的編輯儲存在獨立的持久化編輯層中。瀏覽器 UI 會將這兩層呈現為一份連續文件。

當應用程式需要建立或開啟 PDF、加入可編輯內容、保持匯入 PDF 的保真度、協同修改、匯出結果，或將目前文件交給瀏覽器列印流程時，可以使用 Univer PDFs。

<Callout type="warning" title="僅支援外掛模式">
  PDF 目前沒有預設套件。請明確註冊 PDF 模型、UI 以及選用的功能外掛。
</Callout>


## 瀏覽器相容性

Univer 的編譯目標是 Chrome 88，但這並不意味著 Univer 能夠完全支援所有主流環境。我們會盡力確保 Univer 在以下瀏覽器和 Node.js 環境中能夠正常運行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Univer 依賴 `Intl.Segmenter`，如果你的瀏覽器或執行環境暫不支援它，請先補上對應的 polyfill。我們推薦使用
  `@formatjs/intl-segmenter`。
</Callout>

如果遇到無法相容的情況，請先借助對應的 polyfill 來解決，如果仍然無法解決，請[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 相容性

<Callout type="warning">
  以下僅適用於在 Node.js 環境中運行 Univer 的情況，並不適用於那些基於 Node.js 使用建構工具在瀏覽器中運行 Univer 的情況。
</Callout>

Univer 可以在 Node.js 環境中運行，支援的版本為 v18.17.0 及之後的版本。


## 套件一覽

| 套件                                 | 作用                                                                  |
| ------------------------------------ | --------------------------------------------------------------------- |
| `@univerjs-pro/pdfs`                 | PDF 單元模型、持久化編輯原語、快照契約和 PDF Facade 入口              |
| `@univerjs-pro/pdfs-ui`              | Canvas 呈現器、連續頁面 UI、編輯器控制項、語言套件和選用的縮圖 Worker |
| `@univerjs-pro/pdfs-editor`          | 面向啟用協作之 Univer 應用程式的 PDF 編輯器生命週期整合               |
| `@univerjs-pro/pdfs-exchange-client` | 由伺服器支援的 PDF 匯入匯出、選單整合和 Exchange Facade API           |
| `@univerjs-pro/pdfs-print`           | 瀏覽器列印選單、列印準備 UI、樣式和語言套件                           |

請讓所有 `@univerjs/*` 和 `@univerjs-pro/*` 套件保持相同版本。

## 最小瀏覽器設定

本機檢視器和編輯器需要 Univer 共用 UI、Pro 授權、PDF 模型和 PDF UI 外掛。

```ts
import { UniverLicensePlugin } from '@univerjs-pro/license'
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import { LocaleType, Univer } from '@univerjs/core'
import { FUniver } from '@univerjs/core/facade'
import { UniverUIPlugin } from '@univerjs/ui'

import '@univerjs/design/lib/index.css'
import '@univerjs/ui/lib/index.css'
import '@univerjs-pro/pdfs-ui/lib/index.css'

import '@univerjs-pro/pdfs/facade'

const univer = new Univer({
  locale: LocaleType.EN_US,
  locales: {},
})

univer.registerPlugin(UniverUIPlugin, { container: 'app', ribbonType: 'grid' })
univer.registerPlugin(UniverLicensePlugin, {
  license: process.env.CLIENT_LICENSE_TEXT,
})
univer.registerPlugin(UniverPdfsPlugin)
univer.registerPlugin(UniverPdfsUIPlugin)

const univerAPI = FUniver.newAPI(univer)
const pdf = univerAPI.createPdf({ name: 'Project brief' })
```

如果沒有提供匯入的文件，`createPdf` 會建立包含一個 A4 空白頁的 PDF。
