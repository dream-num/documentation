## Univer PDFs 是什麼

Univer PDFs 是 Univer Office SDK 中的 PDF 產品。一份 PDF 會成為一個正式的 `UNIVER_PDF` 單元，匯入的源文件保持原樣，已接受的編輯則寫入獨立的持久化編輯層。瀏覽器 UI 將這兩層渲染為一份連續的文件。

Univer PDFs 是 [Web SDK](/guides/sheets) 中的一種單元型別，不是獨立的 SDK。檢視器和無介面內容處理由 Web SDK 提供；協同與檔案轉換屬於 [Server SDK](/server)，Agent 工作流屬於 [AI SDK](/ai)。

當應用需要建立或開啟 PDF、新增可編輯內容、保持匯入 PDF 的原貌、協同修改、匯出結果，或將當前文件交給瀏覽器列印流程時，可以使用 Univer PDFs。

<Callout type="warning" title="僅支援外掛模式">
  PDF 沒有預設套件。PDF 模型、UI 和可選的功能外掛都需要顯式註冊。
</Callout>

## 瀏覽器相容性

Web SDK 的編譯目標是 Chrome 88，但這並不表示所有主流環境都能獲得完整支援。Web SDK 會在以下瀏覽器和 Node.js 版本上持續保持正常執行：

| Edge | Firefox | Chrome | Safari | Electron |
| ---- | ------- | ------ | ------ | -------- |
| >=88 | >=90    | >=88   | >=14.1 | >=12     |

<Callout type="warning">
  Web SDK 依賴 `Intl.Segmenter`。如果瀏覽器或執行時環境不支援該 API，需要先新增 polyfill。推薦使用 `@formatjs/intl-segmenter`。
</Callout>

遇到相容性問題時，先嚐試對應的 polyfill。如果問題仍未解決，請[提交 issue](https://github.com/dream-num/univer/issues/new/choose)。

## Node.js 相容性

<Callout type="warning">
  本說明僅適用於在 Node.js 環境中執行 Web SDK，不適用於透過基於 Node.js 的建置工具在瀏覽器中執行 Web SDK。
</Callout>

Web SDK 可在 Node.js v18.17.0 及更高版本中執行。

## 主要功能

- PDF Unit 模型將源文件、頁面結構、資源和持久化編輯意圖儲存在 `IPdfUnitData` 中。
- 頁面支援導航和插入，文字、列表、表格、影像、分隔線和批註均可編輯。
- 瀏覽器工作臺負責渲染 PDF 頁面和縮圖，並處理選擇、編輯控制元件、剪貼簿行為和檢查器介面。
- 已接受的修改透過持久化命令和變更批次應用，因此儲存、撤銷和重做都作用於同一套模型。
- Facade API 透過面向應用的 PDF、頁面、元素和原生文字物件建立、查詢、編輯和儲存 PDF Unit。

## 如何使用這些文件

文件導航欄位於頁面左側。頁面按從基礎到高階的順序組織，可以按順序閱讀並同步建置應用，也可以直接跳轉到所需的部分。側邊欄頂部還可以切換到 Univer PDFs。

右側的目錄用於在當前頁面的各章節之間跳轉。如需快速查詢其他頁面，可使用頂部搜尋欄或搜尋快捷鍵（Ctrl+K 或 Cmd+K）。

請從[快速開始](/guides/pdfs/getting-started/installation)開始。

## 前置知識

文件力求通俗易懂，但仍假定讀者具備基礎知識，以便將重點放在 Web SDK 本身。

對 JavaScript 及其周邊生態有基本瞭解，可以獲得更好的閱讀效果。

如果計劃在 Node.js 上執行 Web SDK，還需要對 Node.js 有基本瞭解。

協同、共享歷史、評論和檔案轉換屬於伺服器端能力。在業務後端中組合 [Univer Server SDK](/server) 的模組即可啟用這些能力；身分認證、權限、儲存和部署由應用負責。僅在瀏覽器中編輯 PDF 時，不需要這些能力。
