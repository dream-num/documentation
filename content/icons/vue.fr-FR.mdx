---

## Installation

```package-install
npm install @univerjs/icons-vue
```

`@univerjs/icons-vue` nécessite Vue 3.

## Utilisation de base

```vue
<script setup lang="ts">
import { SaveIcon, SearchIcon } from '@univerjs/icons-vue'
</script>

<template>
  <div class="flex items-center gap-2">
    <SaveIcon />
    <SearchIcon />
  </div>
</template>
```

## Taille et couleur

La taille des icônes est basée sur `1em`. Il est donc recommandé d'utiliser `fontSize` pour les redimensionner.

```vue
<script setup lang="ts">
import { SaveIcon } from '@univerjs/icons-vue'
</script>

<template>
  <SaveIcon :style="{ fontSize: '20px', color: '#2563eb' }" />
</template>
```

## Canal de couleur supplémentaire

Certaines icônes prennent en charge `extend.colorChannel1` :

```vue
<script setup lang="ts">
import { PaintBucketDoubleIcon } from '@univerjs/icons-vue'
</script>

<template>
  <PaintBucketDoubleIcon
    :style="{ fontSize: '20px' }"
    :extend="{ colorChannel1: '#ef4444' }"
  />
</template>
```
