description: Установка и использование Univer Icons в проектах на Vue 3.
---

## Установка

```package-install
npm install @univerjs/icons-vue
```

Для работы `@univerjs/icons-vue` требуется Vue 3.

## Основы использования

```vue
<script setup lang="ts">
import { SaveIcon, SearchIcon } from '@univerjs/icons-vue'
</script>

<template>
  <div class="flex items-center gap-2">
    <SaveIcon />
    <SearchIcon />
  </div>
</template>
```

## Размер и цвет

Размер иконок задаётся относительно `1em`, поэтому для его изменения рекомендуется использовать `fontSize`.

```vue
<script setup lang="ts">
import { SaveIcon } from '@univerjs/icons-vue'
</script>

<template>
  <SaveIcon :style="{ fontSize: '20px', color: '#2563eb' }" />
</template>
```

## Дополнительный цветовой канал

Некоторые иконки поддерживают `extend.colorChannel1`:

```vue
<script setup lang="ts">
import { PaintBucketDoubleIcon } from '@univerjs/icons-vue'
</script>

<template>
  <PaintBucketDoubleIcon
    :style="{ fontSize: '20px' }"
    :extend="{ colorChannel1: '#ef4444' }"
  />
</template>
```
