title: Iconos de React
description: Install and use Univer Icons in React projects.
---

## Instalación

```package-install
npm install @univerjs/icons
```

## Uso básico

```tsx
import { SaveIcon, SearchIcon } from '@univerjs/icons'

export function Toolbar() {
  return (
    <div className="flex items-center gap-2">
      <SaveIcon />
      <SearchIcon />
    </div>
  )
}
```

## Tamaño y color

Los íconos se basan en `1em`, por lo que `fontSize` es la forma recomendada de escalar íconos.

```tsx
import { SaveIcon } from '@univerjs/icons'

export function Example() {
  return <SaveIcon style={{ fontSize: '20px', color: '#2563eb' }} />
}
```

## Canal multicolor

Algunos íconos son compatibles `extend.colorChannel1`:

```tsx
import { PaintBucketDoubleIcon } from '@univerjs/icons'

export function ColorChannelDemo() {
  return (
    <PaintBucketDoubleIcon
      style={{ fontSize: '20px' }}
      extend={{ colorChannel1: '#ef4444' }}
    />
  )
}
```
