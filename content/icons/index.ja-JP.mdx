## Univer アイコンとは

Univer アイコンは、Univer の公式アイコンパッケージです。オフィス風の UI 向けに、ツリーシェイキング可能な React および Vue 3 のアイコンコンポーネントを提供します。

現在のドキュメントバージョン：<IconsVersion />

## リポジトリ

ソースコードと Issue の管理については、[dream-num/univer-icons](https://github.com/dream-num/univer-icons) を参照してください。

## パッケージ

- `@univerjs/icons`：React アイコンコンポーネント
- `@univerjs/icons-vue`：Vue 3 アイコンコンポーネント

どちらのパッケージも同じコンポーネント名を公開しているため、使用するフレームワークに合ったパッケージを選択できます。

## 命名規則

- コンポーネント名：`PascalCase` + 接尾辞 `Icon`（例：`SaveIcon`）
- 元の SVG ファイル名：`kebab-case`（例：`save-icon.svg`）
