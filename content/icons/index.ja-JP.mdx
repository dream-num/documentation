## What is Univer Icons

Univer Icons is the official Univer icon package. It provides tree-shakable React and Vue 3 icon components for office-style UI.

Current documentation version: <IconsVersion />

## Repository

Source code and issue tracking are available on [dream-num/univer-icons](https://github.com/dream-num/univer-icons).

## Packages

- `@univerjs/icons`: React icon components
- `@univerjs/icons-vue`: Vue 3 icon components

Both packages expose the same component names, so you can choose the package that matches your framework.

## Naming

- Component name: `PascalCase` + `Icon` suffix, e.g. `SaveIcon`
- Source SVG file name: `kebab-case`, e.g. `save-icon.svg`
