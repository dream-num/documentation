description: Vue 3 プロジェクトに Univer アイコンをインストールして使用します。
---

## インストール

```package-install
npm install @univerjs/icons-vue
```

`@univerjs/icons-vue` には Vue 3 が必要です。

## 基本的な使い方

```vue
<script setup lang="ts">
import { SaveIcon, SearchIcon } from '@univerjs/icons-vue'
</script>

<template>
  <div class="flex items-center gap-2">
    <SaveIcon />
    <SearchIcon />
  </div>
</template>
```

## サイズと色

アイコンは `1em` を基準としているため、サイズの変更には `fontSize` の使用を推奨します。

```vue
<script setup lang="ts">
import { SaveIcon } from '@univerjs/icons-vue'
</script>

<template>
  <SaveIcon :style="{ fontSize: '20px', color: '#2563eb' }" />
</template>
```

## マルチカラーチャンネル

一部のアイコンは `extend.colorChannel1` に対応しています。

```vue
<script setup lang="ts">
import { PaintBucketDoubleIcon } from '@univerjs/icons-vue'
</script>

<template>
  <PaintBucketDoubleIcon
    :style="{ fontSize: '20px' }"
    :extend="{ colorChannel1: '#ef4444' }"
  />
</template>
```
