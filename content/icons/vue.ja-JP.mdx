---

## Installation

```package-install
npm install @univerjs/icons-vue
```

`@univerjs/icons-vue` requires Vue 3.

## Basic Usage

```vue
<script setup lang="ts">
import { SaveIcon, SearchIcon } from '@univerjs/icons-vue'
</script>

<template>
  <div class="flex items-center gap-2">
    <SaveIcon />
    <SearchIcon />
  </div>
</template>
```

## Size and Color

Icons are based on `1em`, so `fontSize` is the recommended way to scale icons.

```vue
<script setup lang="ts">
import { SaveIcon } from '@univerjs/icons-vue'
</script>

<template>
  <SaveIcon :style="{ fontSize: '20px', color: '#2563eb' }" />
</template>
```

## Multi-Color Channel

Some icons support `extend.colorChannel1`:

```vue
<script setup lang="ts">
import { PaintBucketDoubleIcon } from '@univerjs/icons-vue'
</script>

<template>
  <PaintBucketDoubleIcon
    :style="{ fontSize: '20px' }"
    :extend="{ colorChannel1: '#ef4444' }"
  />
</template>
```
