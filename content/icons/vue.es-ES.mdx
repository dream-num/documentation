---
title: Íconos de Vue
description: Install and use Univer Icons in Vue 3 projects.
---

## Instalación

```package-install
npm install @univerjs/icons-vue
```

`@univerjs/icons-vue` requiere Vue 3.

## Uso básico

```vue
<script setup lang="ts">
import { SaveIcon, SearchIcon } from '@univerjs/icons-vue'
</script>

<template>
  <div class="flex items-center gap-2">
    <SaveIcon />
    <SearchIcon />
  </div>
</template>
```

## Tamaño y color

Los íconos se basan en `1em`, por lo que `fontSize` es la forma recomendada de escalar iconos.

```vue
<script setup lang="ts">
import { SaveIcon } from '@univerjs/icons-vue'
</script>

<template>
  <SaveIcon :style="{ fontSize: '20px', color: '#2563eb' }" />
</template>
```

## Canal multicolor

Algunos iconos admiten `extend.colorChannel1`:

```vue
<script setup lang="ts">
import { PaintBucketDoubleIcon } from '@univerjs/icons-vue'
</script>

<template>
  <PaintBucketDoubleIcon
    :style="{ fontSize: '20px' }"
    :extend="{ colorChannel1: '#ef4444' }"
  />
</template>
```
