## Qué es Univer Icons

Univer Icons es el paquete de iconos oficial de Univer. Proporciona componentes de iconos de React y Vue 3 que se pueden sacudir en árbol para una interfaz de usuario estilo oficina.

Versión de documentación actual: <IconsVersion />

## Repositorio

El código fuente y el seguimiento de problemas están disponibles en [dream-num/univer-icons](https://github.com/dream-num/univer-icons).

## Paquetes

- `@univerjs/icons`: componentes de íconos de React
- `@univerjs/icons-vue`: componentes de íconos de Vue 3

Ambos paquetes exponen los mismos nombres de componentes, por lo que puede elegir el paquete que coincida con su framework.

## Denominación

- Nombre del componente: `PascalCase` + `Icon` sufijo, p.e. `SaveIcon`
- Nombre del archivo SVG de origen: `kebab-case`, p.e. `save-icon.svg`
