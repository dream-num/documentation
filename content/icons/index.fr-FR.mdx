## Qu'est-ce qu'Univer Icons ?

Univer Icons est le paquet d'icônes officiel d'Univer. Il fournit des composants d'icônes React et Vue 3 compatibles avec le tree shaking pour les interfaces de type bureautique.

Version actuelle de la documentation : <IconsVersion />

## Dépôt

Le code source et le suivi des problèmes sont disponibles sur [dream-num/univer-icons](https://github.com/dream-num/univer-icons).

## Paquets

- `@univerjs/icons` : composants d'icônes React
- `@univerjs/icons-vue` : composants d'icônes Vue 3

Les deux paquets exportent les mêmes noms de composants. Vous pouvez donc choisir celui qui correspond à votre framework.

## Convention de nommage

- Nom du composant : `PascalCase` avec le suffixe `Icon`, par exemple `SaveIcon`
- Nom du fichier SVG source : `kebab-case`, par exemple `save-icon.svg`
