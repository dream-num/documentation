## Что такое Univer Icons

Univer Icons — официальный пакет иконок Univer. Он содержит компоненты иконок для React и Vue 3 с поддержкой исключения неиспользуемого кода и предназначен для интерфейсов офисных приложений.

Текущая версия документации: <IconsVersion />

## Репозиторий

Исходный код и система отслеживания ошибок доступны в репозитории [dream-num/univer-icons](https://github.com/dream-num/univer-icons).

## Пакеты

- `@univerjs/icons`: компоненты иконок для React
- `@univerjs/icons-vue`: компоненты иконок для Vue 3

Оба пакета экспортируют компоненты с одинаковыми именами, поэтому можно выбрать пакет для используемого фреймворка.

## Именование

- Имя компонента: `PascalCase` + суффикс `Icon`, например `SaveIcon`
- Имя исходного SVG-файла: `kebab-case`, например `save-icon.svg`
