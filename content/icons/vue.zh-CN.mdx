---
title: Vue Icons
description: 在 Vue 3 项目中安装和使用 Univer Icons。
---

## 安装

```package-install
npm install @univerjs/icons-vue
```

`@univerjs/icons-vue` 需要 Vue 3。

## 基础用法

```vue
<script setup lang="ts">
import { SaveIcon, SearchIcon } from '@univerjs/icons-vue'
</script>

<template>
  <div class="flex items-center gap-2">
    <SaveIcon />
    <SearchIcon />
  </div>
</template>
```

## 大小与颜色

图标尺寸基于 `1em`，推荐通过 `fontSize` 调整大小。

```vue
<script setup lang="ts">
import { SaveIcon } from '@univerjs/icons-vue'
</script>

<template>
  <SaveIcon :style="{ fontSize: '20px', color: '#2563eb' }" />
</template>
```

## 多色通道

部分图标支持 `extend.colorChannel1`：

```vue
<script setup lang="ts">
import { PaintBucketDoubleIcon } from '@univerjs/icons-vue'
</script>

<template>
  <PaintBucketDoubleIcon
    :style="{ fontSize: '20px' }"
    :extend="{ colorChannel1: '#ef4444' }"
  />
</template>
```
