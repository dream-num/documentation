## 설치

```package-install
npm install @univerjs/icons-vue
```

`@univerjs/icons-vue`를 사용하려면 Vue 3가 필요합니다.

## 기본 사용법

```vue
<script setup lang="ts">
import { SaveIcon, SearchIcon } from '@univerjs/icons-vue'
</script>

<template>
  <div class="flex items-center gap-2">
    <SaveIcon />
    <SearchIcon />
  </div>
</template>
```

## 크기 및 색상

아이콘은 `1em`을 기준으로 하므로 크기를 조절할 때는 `fontSize`를 사용하는 것이 좋습니다.

```vue
<script setup lang="ts">
import { SaveIcon } from '@univerjs/icons-vue'
</script>

<template>
  <SaveIcon :style="{ fontSize: '20px', color: '#2563eb' }" />
</template>
```

## 다중 색상 채널

일부 아이콘은 `extend.colorChannel1`을 지원합니다.

```vue
<script setup lang="ts">
import { PaintBucketDoubleIcon } from '@univerjs/icons-vue'
</script>

<template>
  <PaintBucketDoubleIcon
    :style="{ fontSize: '20px' }"
    :extend="{ colorChannel1: '#ef4444' }"
  />
</template>
```
