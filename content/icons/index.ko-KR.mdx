## Univer Icons란?

Univer Icons는 Univer의 공식 아이콘 패키지입니다. 오피스 스타일 UI를 위한 트리 셰이킹 가능한 React 및 Vue 3 아이콘 컴포넌트를 제공합니다.

현재 문서 버전: <IconsVersion />

## 저장소

소스 코드와 이슈 추적은 [dream-num/univer-icons](https://github.com/dream-num/univer-icons)에서 확인할 수 있습니다.

## 패키지

- `@univerjs/icons`: React 아이콘 컴포넌트
- `@univerjs/icons-vue`: Vue 3 아이콘 컴포넌트

두 패키지는 동일한 컴포넌트 이름을 제공하므로 사용하는 프레임워크에 맞는 패키지를 선택할 수 있습니다.

## 이름 지정 규칙

- 컴포넌트 이름: `PascalCase` + `Icon` 접미사(예: `SaveIcon`)
- 소스 SVG 파일 이름: `kebab-case`(예: `save-icon.svg`)
