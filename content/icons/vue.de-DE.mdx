---
title: Vue Icons
description: Install and use Univer Icons in Vue 3 projects.
---

## Installation

```package-install
npm install @univerjs/icons-vue
```

`@univerjs/icons-vue` erfordert Vue 3.

## Grundlegende Verwendung

```vue
<script setup lang="ts">
import { SaveIcon, SearchIcon } from '@univerjs/icons-vue'
</script>

<template>
  <div class="flex items-center gap-2">
    <SaveIcon />
    <SearchIcon />
  </div>
</template>
```

## Größe und Farbe

Icons basieren auf `1em`, daher ist `fontSize` die empfohlene Skalierungsmethode Symbole.

```vue
<script setup lang="ts">
import { SaveIcon } from '@univerjs/icons-vue'
</script>

<template>
  <SaveIcon :style="{ fontSize: '20px', color: '#2563eb' }" />
</template>
```

## Mehrfarbenkanal

Einige Symbole unterstützen `extend.colorChannel1`:

```vue
<script setup lang="ts">
import { PaintBucketDoubleIcon } from '@univerjs/icons-vue'
</script>

<template>
  <PaintBucketDoubleIcon
    :style="{ fontSize: '20px' }"
    :extend="{ colorChannel1: '#ef4444' }"
  />
</template>
```
