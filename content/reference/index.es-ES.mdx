Usa la Facade API para leer y modificar contenido Office desde tu aplicación. Busca una API por producto o consulta las opciones de inicialización y configuración de plugins.

## Prueba la API [#quick-start]

Completa primero la [instalación y el uso básico](/guides/sheets/getting-started/installation). Tras inicializar el editor Sheets y obtener `univerAPI` de `createUniver`, este código escribe en la celda A1:

```ts
const workbook = univerAPI.getActiveWorkbook()
const worksheet = workbook?.getActiveSheet()
worksheet?.getRange('A1').setValue('Hello, Univer!')
```

`univerAPI` es una instancia de `FUniver`. En Sheets, accede al libro, después a una hoja y finalmente a un rango de celdas. Consulta los [fundamentos de la Facade API](/guides/sheets/getting-started/facade) para la inicialización en modo plugin y las importaciones Facade de cada función.

## Inicialización y configuración [#configuration]

Usa [createUniver](/reference/methods/create-univer) con presets, o [Univer](/reference/classes/univer) para registrar plugins directamente. La instancia `Univer` gestiona plugins y unidades de documento; `univerAPI` ofrece operaciones de contenido para tu aplicación.

Empieza por [Sheets Core](/reference/packages/presets/univerjs/preset-sheets-core) o [Docs Core](/reference/packages/presets/univerjs/preset-docs-core). La sección **Packages → Presets / Plugins** de la barra lateral contiene las opciones de cada paquete. Las API de cada función requieren registrar sus plugins. En modo plugin, importa también la entrada Facade indicada en la guía de la función.

## Integración de servidor e IA [#server-and-ai]

Para colaboración en el backend y conversión de archivos, empieza por [Server SDK](/server). Para flujos CLI y operaciones de contenido mediante AI Agent, empieza por [AI SDK](/ai).
