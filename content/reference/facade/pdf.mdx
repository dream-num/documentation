Facade APIs for creating and resolving Univer PDF units.

> Import `@univerjs-pro/pdfs/facade` before using these APIs in plugin mode.

## univerAPI

| Method | Description |
| --- | --- |
| `createPdf` | Create a PDF unit from an `IPdfDocument` or `IPdfUnitData` snapshot. |
| `getActivePdf` | Get the active PDF unit. |
| `getPdf` | Get a PDF unit by id. |

```typescript
createPdf(data: IPdfDocument | IPdfUnitData, options?: ICreateUnitOptions): FPdf
getActivePdf(): FPdf | null
getPdf(id: string): FPdf | null
```

## FPdf

| Method | Description |
| --- | --- |
| `getId` | Get the PDF unit id. |
| `getName` | Get the PDF document name. |
| `getSnapshot` | Get the current `IPdfUnitData` snapshot. |
| `getDocument` | Get the current `IPdfDocument`. |
| `getModel` | Get the underlying `PdfDocumentModel`. |

```typescript
getId(): string
getName(): string
getSnapshot(): IPdfUnitData
getDocument(): IPdfDocument
getModel(): PdfDocumentModel
```

```ts
import { migratePdfUnitData } from '@univerjs-pro/pdfs'

import '@univerjs-pro/pdfs/facade'

const pdf = univerAPI.createPdf(migratePdfUnitData(pdfData))
console.log(pdf.getId(), pdf.getDocument().pages.length)
```
