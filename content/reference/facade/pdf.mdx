Register [`@univerjs-pro/pdfs`](/reference/packages/plugins/univerjs-pro/pdfs) or a preset that includes it. In plugin mode, import `@univerjs-pro/pdfs/facade`. Additional methods below require their listed plugin packages. See [Facade setup](/guides/pdfs/getting-started/facade).

### `FPdf.insertPage` [#insertpage]

Insert a blank PDF page at a zero-based index, or append it when no index is provided.

The new page inherits the adjacent page's size, rotation, and PDF boxes. An A4 page is
created when the document has no existing pages.

```typescript
insertPage(index?: number): FPdfPage
```

**Parameters**

- `index` — Optional. The zero-based insert index. Omit it to append the page.

**Returns**

The created page Facade.

**Throws**

If the index is outside the document page boundaries.

**Examples**

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf?.insertPage()
console.log(page?.getIndex())
```

**Types:** [`FPdfPage`](/reference/facade/pdf-page)

**Package:** [`@univerjs-pro/pdfs`](/reference/packages/plugins/univerjs-pro/pdfs) · [Type definitions](https://unpkg.com/@univerjs-pro/pdfs@1.0.0-rc.0/lib/types/facade/f-pdf.d.ts)
