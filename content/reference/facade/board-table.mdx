Facade for one Board table element and its table resource.

Instances are returned by `FBoard` table mixin methods. Do not construct this class directly because it needs the
active Board model, table resource service, and command service.

{/* API details are generated by scripts/sync-api-reference.mjs. */}

## Access

Access through:

- [`FBoard.insertTable()`](/reference/facade/board#inserttable)
- [`FBoard.getTable()`](/reference/facade/board#gettable)
- [`FBoard.getTables()`](/reference/facade/board#gettables)

## Setup

Register [`@univerjs-pro/boards-table`](/reference/packages/plugins/univerjs-pro/boards-table) or a preset that includes it. In plugin mode, import `@univerjs-pro/boards-table/facade`. Additional methods below require their listed plugin packages. See [Facade setup](/guides/boards/getting-started/facade).
