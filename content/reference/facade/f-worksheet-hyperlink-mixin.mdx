## APIs

### `getUrl`

Create a hyperlink url to this sheet

**Signature**
```typescript
getUrl(): string
```

**Returns**
- (`string`) — The url of this sheet

**Examples**
```ts
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getActiveSheet()
const url = fWorksheet.getUrl()
console.log(url)
```
