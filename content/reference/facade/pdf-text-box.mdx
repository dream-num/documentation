Facade for a simple editable PDF text box.

{/* API details are generated by scripts/sync-api-reference.mjs. */}

## Access

Access through:

- [`FPdfPage.getTextBoxes()`](/reference/facade/pdf-page#gettextboxes)
- [`FPdfPage.insertTextBox()`](/reference/facade/pdf-page#inserttextbox)
- [`FPdfTextSpan.replaceText()`](/reference/facade/pdf-text-span#replacetext)

## Inheritance

Extends [`FPdfPageElement`](/reference/facade/pdf-page-element). Its inherited members are available on this object.

## Example

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf.getPageByIndex(0)
const textBox = page.insertTextBox({
  text: 'Hello PDF',
  left: 36,
  top: 36,
})
console.log(textBox?.getText())

textBox
  .setText('Updated text')
  .setTextStyle(
    {
      bold: true,
    },
    {
      start: 0,
      end: 5,
    },
  )
  .setTextAnchor(univerAPI.Enum.PdfTextAnchor.MIDDLE)
console.log(textBox?.getText())
```
