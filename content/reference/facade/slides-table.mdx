Facade APIs for table elements in Univer Slides Pro.

> Import `@univerjs-pro/slides-table/facade` before using these APIs in plugin mode.

`@univerjs-pro/slides-table-ui/facade` exports UI helper utilities for table editing. It does not add separate `FSlide` or `FSlideTable` methods.

## Examples

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

const table = slide?.insertTableFromData([
  ['Name', 'Score'],
  ['Ada', '100'],
])

table?.setCellText(1, 1, '98')
```
