Facade object for a single docs table cell.

{/* API details are generated by scripts/sync-api-reference.mjs. */}

## Access

Access through:

- [`FDocumentTable.getCell()`](/reference/facade/document-table#getcell)

## Example

```ts
const fDocument = univerAPI.getActiveDocument()
const table = fDocument?.findTableByText('Status')
const cell = table.getCell(0, 0)
cell?.setText('Owner')
cell?.setBackgroundColor('#E8F1FF')
```

## Setup

Register [`@univerjs-pro/docs-table`](/reference/packages/plugins/univerjs-pro/docs-table) or a preset that includes it. In plugin mode, import `@univerjs-pro/docs-table/facade`. Additional methods below require their listed plugin packages. See [Facade setup](/guides/docs/getting-started/facade).
