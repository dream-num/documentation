Facade APIs for Univer Bases data, tables, views, records, permissions, and UI operations.

> Import `@univerjs-pro/bases/facade` and, when UI APIs are needed, `@univerjs-pro/bases-ui/facade` before using these APIs in plugin mode.

## Related Feature Plugins

Bases separates the data/model facade from the standalone workbench UI. Register both packages when users need the full Bases interface.

| Package | Plugin | Purpose |
| --- | --- | --- |
| `@univerjs-pro/bases` | `UniverBasesPlugin` | Base unit model, tables, fields, records, views, formula integration, search, collaboration mutations, and facade APIs. |
| `@univerjs-pro/bases-ui` | `UniverBasesUIPlugin` | Standalone workbench, grid/calendar/kanban/gallery/gantt views, field editors, record detail panel, toolbar, context menus, and render modules. |
