Facade object for a single docs code block.

{/* API details are generated by scripts/sync-api-reference.mjs. */}

## Access

Access through:

- [`FDocument.getCodes()`](/reference/facade/document#getcodes)
- [`FDocument.getCode()`](/reference/facade/document#getcode)
- [`FDocument.getCodeAt()`](/reference/facade/document#getcodeat)
- [`FDocument.findCodeByText()`](/reference/facade/document#findcodebytext)
- [`FDocument.findCodes()`](/reference/facade/document#findcodes)
- [`FDocument.insertCode()`](/reference/facade/document#insertcode)

## Example

```ts
const fDocument = univerAPI.getActiveDocument()
const codes = fDocument.getCodes()
console.log(codes)

const code = fDocument.findCodeByText('function')
console.log(code?.getText())
console.log(code?.getConfig())

code?.updateConfig({ config: { language: 'javascript', lineNumbers: true } })
console.log(code?.describe())

code?.unwrap()
code?.remove()
```

## Setup

Register [`@univerjs-pro/docs-code`](/reference/packages/plugins/univerjs-pro/docs-code) or a preset that includes it. In plugin mode, import `@univerjs-pro/docs-code/facade`. Additional methods below require their listed plugin packages. See [Facade setup](/guides/docs/getting-started/facade).
