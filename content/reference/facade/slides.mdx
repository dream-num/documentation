## Examples

```ts
const presentation = univerAPI.createPresentation({ name: 'Quarterly review' })
const slide = presentation.appendSlide()

const shape = slide.newShape()
  .setShapeType(univerAPI.Enum.SlideShapeTypeEnum.Rect)
  .setAbsolutePosition(80, 80)
  .setSize(240, 120)
  .build()

slide.insertShape(shape)
```
