Facade APIs for creating and editing Univer Slides presentations.

> Import `@univerjs-pro/slides/facade` before using these APIs in plugin mode.

## Related Feature Plugins

Slides has a core presentation facade plus optional UI and feature plugins. This page documents the core `@univerjs-pro/slides` facade; use the related reference pages for chart, table, and print facade APIs.

| Package | Plugin | Purpose |
| --- | --- | --- |
| `@univerjs-pro/slides` | `UniverSlidesPlugin` | Presentation unit model, slide/page element model, commands, mutations, and core facade APIs. |
| `@univerjs-pro/slides-ui` | `UniverSlidesUIPlugin` | Slide editor UI, thumbnails, canvas editing, object panels, context menus, and presentation playback. |
| `@univerjs-pro/slides-chart` | `UniverSlidesChartPlugin` | Chart elements and chart builder facade integration. |
| `@univerjs-pro/slides-chart-ui` | `UniverSlidesChartUIPlugin` | Chart element UI and render integration. |
| `@univerjs-pro/slides-table` | `UniverSlidesTablePlugin` | Table elements and table builder facade integration. |
| `@univerjs-pro/slides-table-ui` | `UniverSlidesTableUIPlugin` | Table element UI and render integration. |
| `@univerjs-pro/slides-print` | `UniverSlidesPrintPlugin` | Print dialog and slide printing facade integration. |
| `@univerjs-pro/slides-exchange-client` | `UniverSlidesExchangeClientPlugin` | Import/export client integration for Pro deployments. |
