Fluent base Builder for Charts that expose Cartesian axes and mark lines.

{/* API details are generated by scripts/sync-api-reference.mjs. */}

## Inheritance

Extends [`FChartBuilderBase`](/reference/facade/chart-builder-base). Its inherited members are available on this object.

## Example

```ts
const fWorkbook = univerAPI.getActiveWorkbook()
const fWorksheet = fWorkbook.getSheetByName('Sheet1')
const chartInfo = fWorksheet
  .newChart(univerAPI.Enum.ChartTypeString.Line)
  .setSource('A1:D8')
  .setYAxisTitle('Revenue')
  .build()
await fWorksheet.insertChart(chartInfo)
```

### `FAxisChartBuilder.setMarkLines` [#setmarklines]

Replaces all fixed-axis mark lines.

Omitted line-style fields use a 1 px solid stroke at full opacity and inherit the carrier
series color, falling back to the active theme. Endpoint symbols are hidden. Labels are hidden
unless a `label` object is supplied; an empty label object shows the axis-formatted value.

Read the current value from `builder.build().config.markLines`.

```typescript
setMarkLines(lines: readonly IChartMarkLineSpec[]): this
```

**Parameters**

- `lines` — Required. The complete ordered mark-line collection. An empty list clears it.

**Returns**

This builder for chaining.

**Examples**

```ts
builder.setMarkLines([{ axis: univerAPI.Enum.ChartSemanticAxis.PrimaryValue, value: 80 }])
const markLines = builder.build().config.markLines
```

### `FAxisChartBuilder.setYAxis` [#setyaxis]

Sets the Y axis configuration and returns this detached builder for chaining.
Supported numeric axes accept `{ scaleType: 'log', logBase: 2.5 }`.
Missing base defaults to 10 when first enabled. Finite out-of-range values are retained
for compatibility and render with base 10 plus diagnostics. Normal input uses 2–1000.
Apply an existing-chart draft with `await chart.update(builder.build())`.
Explicit `scaleType: 'linear'` removes the base; unrelated patches preserve it.

This method executes synchronously.

```typescript
setYAxis(value: IChartAxisSpec): this
```

**Parameters**

- `value` — Required. The semantic value to record.

**Returns**

This builder for chaining.

**Examples**

```ts
// Update an existing Line chart; Area and Column use the same Y-axis settings.
const sheet = univerAPI.getActiveWorkbook().getActiveSheet()
const chart = sheet.getCharts()[0]
const builder = chart
  .toBuilder(univerAPI.Enum.ChartTypeString.Line)
  .setYAxis({ scaleType: 'log', logBase: 2.5 })
await chart.update(builder.build())

// Change only the base of the logarithmic axis.
await chart.update(
  chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setYAxis({ logBase: 2 }).build(),
)

// Restore linear scaling and remove the logarithm base.
await chart.update(
  chart.toBuilder(univerAPI.Enum.ChartTypeString.Line).setYAxis({ scaleType: 'linear' }).build(),
)
```
