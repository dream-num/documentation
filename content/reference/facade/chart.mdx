The chart Facade API uses a host-scoped `charts` collection. Create a detached builder, configure it, then insert it into its host. The same lifecycle is used by Sheets, Slides, Boards, and Docs; each host adds its own data and layout methods.

> Import the matching product facade entry before using `charts`, for example `@univerjs-pro/sheets-chart/facade`.

## Sheets charts

Access `FWorksheetCharts` from `fWorksheet.charts`.

| Method                       | Description                                                      |
| ---------------------------- | ---------------------------------------------------------------- |
| `create()`                   | Creates a detached chart builder.                                |
| `insert(builder)`            | Inserts a configured builder and returns the host-bound builder. |
| `get(chartId)`               | Gets a chart builder by id.                                      |
| `list()`                     | Lists chart builders on the worksheet.                           |
| `remove(builderOrId)`        | Removes a chart by builder or id.                                |
| `registerTheme(name, theme)` | Registers a chart theme for the Univer runtime.                  |

```ts
const worksheet = univerAPI.getActiveWorkbook().getActiveSheet()

const builder = worksheet.charts
  .create()
  .setType(univerAPI.Enum.ChartTypeString.Column)
  .setSource({
    range: 'A1:D6',
    orientation: univerAPI.Enum.ChartSourceOrientation.Column,
  })
  .setTitle('Quarterly revenue')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)

const chart = await worksheet.charts.insert(builder)
```

Call configuration methods on a host-bound builder and then `commit()` to persist changes:

```ts
chart
  .setType(univerAPI.Enum.ChartTypeString.Line)
  .setLegend({ visible: true })
  .setSeries({ index: 0 }, { color: '#2F80ED' })
  .commit()
```

## Shared builder methods

`FChartBuilderBase` provides the semantic configuration shared by every host:

| Category                   | Methods                                                                                                                                                                                                            |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Chart type                 | `setType`                                                                                                                                                                                                          |
| Titles and legend          | `setTitle`, `clearTitle`, `setSubtitle`, `clearSubtitle`, `setLegend`, `clearLegend`                                                                                                                               |
| Axes and series            | `setXAxis`, `setYAxis`, `setRightYAxis`, `setSeries`, `clearSeries`, `setAllSeriesStyle`, `clearAllSeriesStyle`, `setTrendline`, `setAxisPointer`                                                                  |
| Appearance                 | `setTheme`, `clearTheme`, `setAppearance`, `clearAppearance`, `setAggregation`, `clearAggregation`                                                                                                                 |
| Field selection            | `setCategoryField`, `clearCategoryField`, `setValueFields`, `clearValueFields`                                                                                                                                     |
| Special chart options      | Concrete chart builders add methods such as `setLineStyle`, `setDoughnutHole`, `setBubbleMapping`, `setCandlestickFields`, `setHistogramField`, `setHierarchyFields`, `setGaugeValueField`, and `setChordMapping`. |
| Inspection and persistence | `describe`, `exportImage`, `commit`                                                                                                                                                                                |

Changing the type returns a builder with the methods specific to that chart type. Use `univerAPI.Enum.ChartTypeString` for canonical chart type values.

The current chart-type set includes `Candlestick`, `Histogram`, `Treemap`, `Sunburst`, `Gauge`, and `Chord` in addition to the existing cartesian, pie, relation, statistical, and flow chart types.

## Other chart hosts

All other hosts expose the same collection lifecycle:

| Host   | Collection         | Host-specific builder methods                                                                                                                             |
| ------ | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Slides | `fSlide.charts`    | `setData`, `getData`, `setDataSource`, `getDataSource`, `refreshDataSource`, `setAbsolutePosition`, `setSize`, `setPlaceholder`, `setStroke`, `setZOrder` |
| Boards | `fBoard.charts`    | `setData`, `getData`, `setDataSource`, `getDataSource`, `refreshDataSource`, `setPosition`, `setSize`, `setContainer`, `setLane`, `setZOrder`             |
| Docs   | `fDocument.charts` | `setData`, `getData`, `setDataSource`, `getDataSource`, `refreshDataSource`, `setAnchor`, `setLayout`, `setInline`, `setFloating`                         |

Use `create()`, configure the returned builder, and call `await charts.insert(builder)`. Use `list()`, `get(id)`, and `remove(builderOrId)` to manage existing charts.

Slides, Boards, and Docs can bind a chart to a referenced Unit resource instead of copying inline values:

```ts
const builder = slide.charts.create().setDataSource({
  unit: { selector: 'sales-workbook', type: 'sheet' },
  part: {
    kind: 'range',
    sheetName: 'Data',
    range: 'A1:B20',
    ref: 'Data!A1:B20',
  },
})

const chart = await slide.charts.insert(builder)
await chart.refreshDataSource()
```

```typescript
setDataSource(ref: IResourceRefChartDataSourceInput): this
getDataSource(): DeepReadonly<IResourceRef> | null
refreshDataSource(): Promise<void>
```
