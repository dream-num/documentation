從 `univerAPI`（`FUniver` 執行個體）開始。外掛擴充的方法歸入被擴充的類別，例如 Sheets Table 的方法位於 `FWorkbook` 和 `FWorksheet`。

在 Sheets 中，依 `FUniver → FWorkbook → FWorksheet → FRange` 存取物件。獨立物件和 Builder 各有專屬頁面，並提供取得物件的方法及父類別 API 入口。
