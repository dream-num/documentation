Make HTTP requests through `univerAPI.getNetwork()`. Register the Network plugin and import its Facade entry before using these methods. The response wraps the body, status, and headers; `getSSE` returns an observable stream.

The following example assumes your application serves a JSON list at `/api/items`:

```ts
const network = univerAPI.getNetwork()
const response = await network.get<{ id: string }[]>('/api/items')
console.log(response.status, response.body)
```

## Access

## Setup

Register [`@univerjs/network`](/reference/packages/plugins/univerjs/network) or a preset that includes it. In plugin mode, import `@univerjs/network/facade`. Additional methods below require their listed plugin packages. See [Facade setup](/guides/sheets/getting-started/facade).

### `FNetwork.getSSE` [#getsse]

Request for a stream of server-sent events. Instead of a single response, the server sends a stream of responses,
Univer wraps the stream in an [`Observable`](https://rxjs.dev/guide/observable) which you can call `subscribe` on.

```typescript
getSSE<T>(method: HTTPRequestMethod, url: string, params?: IPostRequestParams): Observable<HTTPEvent<T>>
```

**Parameters**

- `method` — Required. HTTP request method
- `url` — Required. The requested URL
- `params` — Optional. params Query parameters

**Returns**

An observable that emits the network response.
