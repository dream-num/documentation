Shared live Facade for an editable PDF page element.

{/* API details are generated by scripts/sync-api-reference.mjs. */}

## Access

Access through:

- [`FPdfPage.getElements()`](/reference/facade/pdf-page#getelements)
- [`FPdfPage.getElementById()`](/reference/facade/pdf-page#getelementbyid)

## Example

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf.getPageByIndex(0)
const element = page.getElements()[0]
console.log(element?.getTransform())
```

## Setup

Register [`@univerjs-pro/pdfs`](/reference/packages/plugins/univerjs-pro/pdfs) or a preset that includes it. In plugin mode, import `@univerjs-pro/pdfs/facade`. Additional methods below require their listed plugin packages. See [Facade setup](/guides/pdfs/getting-started/facade).
