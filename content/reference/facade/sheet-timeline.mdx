A live Timeline hosted by a Worksheet Drawing. Source/cache filtering is shared; presentation is per view.
All public visual dimensions are CSS pixels. Missing resource placeholders retain Drawing capabilities.
Business setters resolve false on ordinary validation/permission refusal. Exceptional inverse-recovery
listener failures reject and may require reconciliation of the coherent committed forward state.

## Access

Access through:

- [`FWorkbook.getTimelineById()`](/reference/facade/workbook#gettimelinebyid)
- [`FWorksheet.insertTimeline()`](/reference/facade/worksheet#inserttimeline)
- [`FWorksheet.getTimeline()`](/reference/facade/worksheet#gettimeline)
- [`FWorksheet.getTimelines()`](/reference/facade/worksheet#gettimelines)

Register [`@univerjs-pro/sheets-slicer`](https://www.npmjs.com/package/@univerjs-pro/sheets-slicer) or a preset that includes it. In plugin mode, import `@univerjs-pro/sheets-slicer/facade`. Additional methods below require their listed plugin packages. See [Facade setup](/guides/sheets/getting-started/facade).

can return false after view deletion while the Drawing survives; a later failure can retain Drawing deletion too.
Callers can re-read/reconcile committed state. Events describe final hosted state, not the boolean result.
Acceptance does not mean remote persistence or rendering.
