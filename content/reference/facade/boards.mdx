Facade APIs for creating, reading, and editing Univer Boards.

> Import `@univerjs-pro/boards/facade` before using these APIs in plugin mode.

## Related Feature Plugins

Boards is split into the core data/model facade and optional UI or element plugins. Register the plugins that match the Board features your application needs.

| Package | Plugin | Purpose |
| --- | --- | --- |
| `@univerjs-pro/boards` | `UniverBoardsPlugin` | Board unit model, element schema, commands, mutations, adapter services, and facade APIs. |
| `@univerjs-pro/boards-ui` | `UniverBoardsUIPlugin` | Canvas UI, viewport, selection, shape editing, connectors, sticky notes, ink interaction, toolbar, and context menu. |
| `@univerjs-pro/boards-table` | `UniverBoardsTablePlugin` | Board table element data integration. |
| `@univerjs-pro/boards-table-ui` | `UniverBoardsTableUIPlugin` | Board table element rendering and UI integration. |
| `@univerjs-pro/boards-mind` | `UniverBoardsMindPlugin` | Mind-map element model and operations. |
| `@univerjs-pro/boards-mind-ui` | `UniverBoardsMindUIPlugin` | Mind-map element UI and render integration. |
