Facade APIs and event names for the Sheets crosshair highlight plugin.

> Import `@univerjs/sheets-crosshair-highlight/facade` before using these APIs in plugin mode.

## Overview

### @univerjs/sheets-crosshair-highlight

| API | Signature | Description |
| --- | --- | --- |
| `setCrosshairHighlightEnabled` | `setCrosshairHighlightEnabled(enabled: boolean): FUniver` | Enable or disable crosshair highlighting. |
| `getCrosshairHighlightEnabled` | `getCrosshairHighlightEnabled(): boolean` | Get whether crosshair highlighting is enabled. |
| `Event.CrosshairHighlightEnabledChanged` | `CrosshairHighlightEnabledChanged` | Event fired after enabled state changes. |

## APIs

### `setCrosshairHighlightEnabled`

**Signature**
```typescript
setCrosshairHighlightEnabled(enabled: boolean): FUniver
```

**Examples**
```ts
univerAPI.setCrosshairHighlightEnabled(true)
univerAPI.setCrosshairHighlightEnabled(false)
```

### `CrosshairHighlightEnabledChanged`

**Signature**
```typescript

  const { enabled } = params
})
```

**Event Parameters**
- `enabled` `boolean` - The current enabled state.
