Facade for one story-backed editable paragraph frame.

{/* API details are generated by scripts/sync-api-reference.mjs. */}

## Access

Access through:

- [`FPdfPage.getParagraphs()`](/reference/facade/pdf-page#getparagraphs)
- [`FPdfPage.insertParagraph()`](/reference/facade/pdf-page#insertparagraph)

## Inheritance

Extends [`FPdfPageElement`](/reference/facade/pdf-page-element). Its inherited members are available on this object.

## Example

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf.getPageByIndex(0)
const paragraph = page.insertParagraph({
  text: 'First paragraph',
  fontSize: 24,
})
console.log(paragraph.getBlocks())

paragraph.appendBlock({
  text: 'Second paragraph',
  textStyle: {
    fontSize: 18,
    bold: true,
  },
})

const block = paragraph.getBlocks()[0]
paragraph
  .setBlockText(block.id, 'Updated first paragraph')
  .setBlockStyle(block.id, { align: 'center' })
```
