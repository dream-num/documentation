## Examples

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation?.getActiveSlide()

const chart = slide?.newChart()
  .setData([
    ['Month', 'Sales'],
    ['Jan', 10],
    ['Feb', 12],
  ])
  .setAbsolutePosition(80, 80)
  .setSize(480, 280)
  .build()

if (chart) {
  slide?.insertChart(chart)
}
```
