Facade APIs for chart elements in Univer Slides Pro.

> Import `@univerjs-pro/slides-chart/facade` before using these APIs in plugin mode.

## FSlideCharts

Access the collection from `fSlide.charts`.

| Method                       | Description                                                      |
| ---------------------------- | ---------------------------------------------------------------- |
| `create()`                   | Creates a detached slide chart builder.                          |
| `insert(builder)`            | Inserts a configured builder and returns the host-bound builder. |
| `get(id)`                    | Gets a slide chart builder by chart or element id.               |
| `list()`                     | Lists chart builders on the slide.                               |
| `remove(builderOrId)`        | Removes a chart by builder or id.                                |
| `registerTheme(name, theme)` | Registers a chart theme for the Univer runtime.                  |

## Example

```ts
const presentation = univerAPI.getActivePresentation()
const slide = presentation.getActiveSlide()

const builder = slide.charts
  .create()
  .setType(univerAPI.Enum.ChartTypeString.Column)
  .setData([
    ['Month', 'Revenue', 'Cost'],
    ['Jan', 120, 80],
    ['Feb', 180, 96],
    ['Mar', 240, 132],
  ])
  .setTitle('Quarterly revenue')
  .setAbsolutePosition(80, 120)
  .setSize(520, 320)

const chart = await slide.charts.insert(builder)

chart.setType(univerAPI.Enum.ChartTypeString.Line).setLegend({ visible: true }).commit()
```

Slide builders add `setData`, `getData`, `setDataSource`, `getDataSource`, `refreshDataSource`, `setAbsolutePosition`, `setSize`, `setPlaceholder`, `setStroke`, and `setZOrder` to the shared chart builder methods. Use `setDataSource` to bind a chart to a referenced Sheet range and `refreshDataSource()` to reload it. See [Chart](/reference/facade/chart#other-chart-hosts) for the shared configuration and reference shape.
