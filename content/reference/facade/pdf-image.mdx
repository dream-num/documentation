Facade for one editable managed PDF image.

{/* API details are generated by scripts/sync-api-reference.mjs. */}

## Access

Access through:

- [`FPdfPage.getImages()`](/reference/facade/pdf-page#getimages)
- [`FPdfPage.insertImage()`](/reference/facade/pdf-page#insertimage)
- [`FPdfPage.insertImageAsync()`](/reference/facade/pdf-page#insertimageasync)

## Inheritance

Extends [`FPdfPageElement`](/reference/facade/pdf-page-element). Its inherited members are available on this object.

## Example

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf.getPageByIndex(0)
const imageInfo = page
  .newImage()
  .setSource('https://avatars.githubusercontent.com/u/61444807?s=48&v=4')
  .setSize(240, 135)
  .build()
const image = page.insertImage(imageInfo)
console.log(image.getSource())
console.log(image.getImageSourceType())

image
  .setPosition(36, 72)
  .setRotation(15)
  .setCrop({ left: 0, top: 0, right: 100, bottom: 100 })
  .setOpacity(0.75)
```
