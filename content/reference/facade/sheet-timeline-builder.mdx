Detached Timeline configuration for a supported original Pivot date field; visual dimensions use CSS px.
Setters/build do not run commands. Date navigation uses Workbook Excel serials, not JavaScript Date.

{/* API details are generated by scripts/sync-api-reference.mjs. */}

## Access

Access through:

- [`FWorksheet.newTimeline()`](/reference/facade/worksheet#newtimeline)

## Setup

Register [`@univerjs-pro/sheets-slicer`](https://www.npmjs.com/package/@univerjs-pro/sheets-slicer) or a preset that includes it. In plugin mode, import `@univerjs-pro/sheets-slicer/facade`. Additional methods below require their listed plugin packages. See [Facade setup](/guides/sheets/getting-started/facade).
