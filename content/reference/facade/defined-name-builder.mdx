### `FDefinedNameBuilder.build` [#build]

Builds the defined name parameter.

```typescript
build(): ISetDefinedNameMutationParam
```

**Returns**

The defined name mutation parameter.

**Examples**

```ts
const fWorkbook = univerAPI.getActiveWorkbook()
const definedNameParam = fWorkbook
  .newDefinedNameBuilder()
  .setName('MyDefinedName')
  .setRef('Sheet1!$A$1')
  .setComment('A reference to A1 cell in Sheet1')
  .build()
fWorkbook.insertDefinedNameBuilder(definedNameParam)
```
