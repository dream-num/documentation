### `FThreeDChartBuilder.setThreeD` [#setthreed]

Sets the authored 3D view and layout options.
For axis-based charts, set `rightAngleAxes` to `false` to apply `perspective`.

```typescript
setThreeD(value: DeepNullish<IChart3DStyle>): this
```

**Parameters**

- `value` — Required. The 3D view and layout options.

**Returns**

This builder for chaining.

**Examples**

```ts
builder.setThreeD({
  view: { rotX: 15, rotY: 20, rightAngleAxes: false, perspective: 30 },
  gapDepth: 150,
})
```
