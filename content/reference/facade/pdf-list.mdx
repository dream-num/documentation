Facade for one story-backed semantic PDF list.

{/* API details are generated by scripts/sync-api-reference.mjs. */}

## Access

Access through:

- [`FPdfPage.getLists()`](/reference/facade/pdf-page#getlists)
- [`FPdfPage.insertList()`](/reference/facade/pdf-page#insertlist)

## Inheritance

Extends [`FPdfPageElement`](/reference/facade/pdf-page-element). Its inherited members are available on this object.

## Example

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf.getPageByIndex(0)
const list = page.insertList({
  text: 'First item',
  kind: univerAPI.Enum.PdfListKind.UNORDERED,
  preset: univerAPI.Enum.PdfListPresetId.UNORDERED_DISC,
})

list
  .insertItem(1, { text: '第二项' })
  .insertItem(2, { text: '子项', level: 1 })
  .insertItem(3, { text: '第四项' })
console.log(list.getItems())
```

### `FPdfList.changeItemLevel` [#changeitemlevel]

Set the absolute zero-based nesting level of one item.
Increasing the level requires a preceding item at the parent level, so the first item can only use level 0.

```typescript
changeItemLevel(itemId: string, level: number): this
```

**Parameters**

- `itemId` — Required. The stable item ID.
- `level` — Required. The nesting level from 0 through 8.

**Returns**

This list Facade for chaining.

**Examples**

```ts
const pdf = univerAPI.getActivePdf()
const page = pdf.getPageByIndex(0)
const list = page.getLists()[0]
if (list) {
  list.insertItem(1, { text: 'Child item' })
  list.changeItemLevel(list.getItems()[1].id, 1)
}
```

### `FPdfList.setStartNumber` [#setstartnumber]

```typescript

```

**Parameters**

- `startNumber` — Required. The positive first ordinal.

**Returns**
