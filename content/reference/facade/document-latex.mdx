Facade object for a single LaTeX formula in a Univer document.

{/* API details are generated by scripts/sync-api-reference.mjs. */}

## Access

Access through:

- [`FDocumentTextRange.replaceWithLatex()`](/reference/facade/document-text-range#replacewithlatex)
- [`FDocumentTextRange.insertLatexBefore()`](/reference/facade/document-text-range#insertlatexbefore)
- [`FDocumentTextRange.insertLatexAfter()`](/reference/facade/document-text-range#insertlatexafter)
- [`FDocumentParagraph.appendLatex()`](/reference/facade/document-paragraph#appendlatex)
- [`FDocumentParagraph.prependLatex()`](/reference/facade/document-paragraph#prependlatex)
- [`FDocument.getLatexFormulas()`](/reference/facade/document#getlatexformulas)
- [`FDocument.getLatexFormula()`](/reference/facade/document#getlatexformula)
- [`FDocument.getLatexFormulaAt()`](/reference/facade/document#getlatexformulaat)

## Example

```ts
const univerAPI = FUniver.newAPI(univer)
const document = univerAPI.getActiveDocument()
if (!document) throw new Error('No active document')
const formula = document.getLatexFormulas()[0]
if (!formula) throw new Error('No LaTeX formula')
console.log(formula.getLatex())
console.log(formula.getConfig())
if (!formula.update({ latex: '\\frac{a}{b}' })) throw new Error('Cannot update LaTeX formula')
```

Register [`@univerjs-pro/docs-latex`](/reference/packages/plugins/univerjs-pro/docs-latex) or a preset that includes it. In plugin mode, import `@univerjs-pro/docs-latex/facade`. Additional methods below require their listed plugin packages. See [Facade setup](/guides/docs/getting-started/facade).
