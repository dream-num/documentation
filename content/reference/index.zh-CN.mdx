通过 Facade API 在应用中读取和修改 Office 内容。你可以按产品查找接口，也可以从下方的初始化与插件配置入口开始。

## 试用 API [#quick-start]

先完成[安装和基本使用](/guides/sheets/getting-started/installation)。初始化 Sheets 编辑器并拿到 `createUniver` 返回的 `univerAPI` 后，下面的代码会向 A1 单元格写入内容：

```ts
const workbook = univerAPI.getActiveWorkbook()
const worksheet = workbook?.getActiveSheet()
worksheet?.getRange('A1').setValue('Hello, Univer!')
```

`univerAPI` 是 `FUniver` 实例。在 Sheets 中，从工作簿进入工作表，再取得单元格范围。插件模式的初始化方式与功能包的 Facade 导入方式，见 [Facade API 基础](/guides/sheets/getting-started/facade)。

## 初始化与配置 [#configuration]

Univer 提供*预设模式*和*插件模式*两种集成方式。预设模式通过预先组合好的插件简化配置，上手更简单；如果**需要深度扩展**，推荐使用插件模式，按需组合和配置插件。

在侧栏 **功能包 → Plugins** 中查看各插件的配置。[createUniver](/reference/methods/create-univer) 与 **Presets** 仍可用于便捷地加载预先组合好的插件。
