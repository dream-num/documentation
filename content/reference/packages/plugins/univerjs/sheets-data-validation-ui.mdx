Data validation UI for Univer Sheets.

```typescript
// [!code word:UniverSheetsDataValidationUIPlugin]
import { UniverSheetsDataValidationUIPlugin } from '@univerjs/sheets-data-validation-ui'

univer.registerPlugin(UniverSheetsDataValidationUIPlugin, {})
```

## Entry Points

- Locale: `@univerjs/sheets-data-validation-ui/locale/*`

## Panel customization

The root entry exports `DATA_VALIDATION_PANEL` for [overriding the built-in panel](/guides/sheets/ui/components), and `DataValidationPanelService` for coordinating its state. Resolve the service through Univer’s dependency injection container. It exposes `isOpen` / `open$`, `activeRule` / `activeRule$`, and `open()`, `close()`, and `setActiveRule()`.

## IUniverSheetsDataValidationUIConfig

```ts
import type { MenuConfig } from '@univerjs/ui'

export interface IUniverSheetsDataValidationUIConfig {
  menu?: MenuConfig

  /**
   * Whether to show the edit button in the dropdown list of data validation
   * @default true
   */
  showEditOnDropdown?: boolean

  /**
   * Whether to show the search box in the dropdown list of data validation
   * @default true
   */
  showSearchOnDropdown?: boolean
}
```
