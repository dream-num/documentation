```typescript
// [!code word:UniverSheetsHyperLinkPlugin]
import { UniverSheetsHyperLinkPlugin } from '@univerjs/sheets-hyper-link'

univer.registerPlugin(UniverSheetsHyperLinkPlugin)
```

This plugin provides the core hyperlink functionality for Univer Sheets, including hyperlink parsing, navigation, and cell-level hyperlink operations through the Facade API.

For hyperlink UI features (such as editing hyperlinks in the interface), you also need to register [`@univerjs/sheets-hyper-link-ui`](./sheets-hyper-link-ui).
