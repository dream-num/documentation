Built-in theme definitions for Univer.

```typescript
// [!code word:darkBlueTheme]
// [!code word:Theme]
import type { Theme } from '@univerjs/themes'
import { darkBlueTheme } from '@univerjs/themes'
```

## Theme

```ts
export type Theme = typeof defaultTheme
```

The package exports `defaultTheme` (also available as `blueTheme`), `darkBlueTheme`, `greenTheme`, `orangeTheme`, `purpleTheme`, `redTheme`, and `yellowTheme`.
