Find and replace provider integration for Univer Docs.

```typescript
import { UniverDocsFindReplacePlugin } from '@univerjs/docs-find-replace'

univer.registerPlugin(UniverDocsFindReplacePlugin)
```

This plugin connects Docs to the shared `@univerjs/find-replace` UI and services.
