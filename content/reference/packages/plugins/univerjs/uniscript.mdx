Monaco-based scripting editor for operating Univer through Facade APIs.

```typescript
// [!code word:UniverUniscriptPlugin]
// [!code word:IUniverUniscriptConfig]
import { UniverUniscriptPlugin } from '@univerjs/uniscript'

univer.registerPlugin(UniverUniscriptPlugin, IUniverUniscriptConfig)
```

## Entry Points

- Locale: `@univerjs/uniscript/locale/*`

## IUniverUniscriptConfig

```ts
import type { MenuConfig } from '@univerjs/ui'

export interface IUniverUniscriptConfig {
  menu?: MenuConfig
  getWorkerUrl?: (moduleID: string, label: string) => string
}
```
