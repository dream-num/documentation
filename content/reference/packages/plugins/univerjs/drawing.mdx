Shared drawing models, commands, and services for Univer.

```typescript
// [!code word:UniverDrawingPlugin]
import { UniverDrawingPlugin } from '@univerjs/drawing'

univer.registerPlugin(UniverDrawingPlugin, {})
```

## Image opacity

The root entry exports `normalizeImageOpacity(opacity: number | undefined): number`. It clamps finite values to `0`–`1` and returns `1` for `undefined` or non-finite values. Use it when normalizing drawing data. The [image Facade setters](/guides/sheets/features/images#image-opacity) validate input and throw `RangeError` for invalid values instead.

## IUniverDrawingConfig

```ts
import type { DependencyOverride } from '@univerjs/core'
import type { IOleConfig } from '@univerjs/drawing'

export interface IUniverDrawingConfig {
  ole?: IOleConfig
  override?: DependencyOverride
  /**
   * The maximum allowed size of uploaded images in bytes.
   * @default 5 * 1024 * 1024 (5MB)
   */
  allowImageSize?: number
}
```

## OLE attachments

The model plugin preserves original attachment resources independently of preview images, including in headless snapshots. `IOleConfig` configures authorized attachment storage, temporary Office previews, conversion to independent online documents, and application links. Register the host drawing UI for attachment controls. See [OLE integration and export options](/server/import-export#ole-attachments).
