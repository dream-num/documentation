Telemetry service contract for Univer packages.

```typescript
import { ITelemetryService } from '@univerjs/telemetry'

const telemetry = injector.get(ITelemetryService)
telemetry.capture('document_opened', { unitId })
```

Implementations provide initialization, identification, event capture, timing, performance tracking, and page-view methods.
