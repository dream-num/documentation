Structured table model and commands for Univer Sheets.

```typescript
// [!code word:UniverSheetsTablePlugin]
// [!code word:IUniverSheetsTableConfig]
import { UniverSheetsTablePlugin } from '@univerjs/sheets-table'

univer.registerPlugin(UniverSheetsTablePlugin, IUniverSheetsTableConfig)
```

## Entry Points

- Facade: `@univerjs/sheets-table/facade`
- Locale: `@univerjs/sheets-table/locale/*`

```ts
import type { IRangeThemeStyleJSON } from '@univerjs/sheets'
```
