Structured table UI for Univer Sheets.

```typescript
// [!code word:UniverSheetsTableUIPlugin]
// [!code word:IUniverSheetsTableUIConfig]
import { UniverSheetsTableUIPlugin } from '@univerjs/sheets-table-ui'

univer.registerPlugin(UniverSheetsTableUIPlugin, IUniverSheetsTableUIConfig)
```

## Entry Points

- Facade: `@univerjs/sheets-table-ui/facade`
- Locale: `@univerjs/sheets-table-ui/locale/*`

## IUniverSheetsTableUIConfig

```ts
import type { MenuConfig } from '@univerjs/ui'

export interface IUniverSheetsTableUIConfig {
  anchorHeight?: number
  anchorBackgroundColor?: string
  hideAnchor?: boolean

  menu?: MenuConfig
}
```
