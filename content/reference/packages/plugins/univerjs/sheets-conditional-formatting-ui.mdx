Conditional formatting UI for Univer Sheets.

```typescript
// [!code word:UniverSheetsConditionalFormattingUIPlugin]
import { UniverSheetsConditionalFormattingUIPlugin } from '@univerjs/sheets-conditional-formatting-ui'

univer.registerPlugin(UniverSheetsConditionalFormattingUIPlugin, {})
```

## Entry Points

- Locale: `@univerjs/sheets-conditional-formatting-ui/locale/*`

## Rule UI

The root entry exports helpers for custom rule lists and panels:

| Export | Usage |
| --- | --- |
| `getRuleDescribe(rule, localeService)` | Returns the localized description of a full `IConditionFormattingRule`. |
| `ConditionalFormattingRulePreview` | Renders the configured appearance. Pass `rule.rule`, not the full rule; it does not evaluate worksheet values. |
| `IConditionalFormattingRulePreviewProps` | Props for the preview, with an optional `rule: IConditionalFormattingRuleConfig`. |
| `CF_PANEL_KEY` | Key for overriding or opening the registered conditional-formatting panel. |
| `IConditionFormattingPanelProps` | Panel props, including `rule`, `RuleEditComponent`, `RuleListComponent`, and `onEditorExit`. |

`onEditorExit` runs when editing ends after submission, cancellation, or worksheet activation/removal. It is not a save-success or sidebar-close notification. The panel itself is registered under `CF_PANEL_KEY`; it is not exported as a React component from the package root.

See [rule descriptions and previews](/guides/sheets/features/conditional-formatting#custom-rule-ui) for an example and [component overrides](/guides/sheets/ui/components) for registration rules.
