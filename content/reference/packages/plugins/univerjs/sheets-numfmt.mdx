Number format services and commands for Univer Sheets.

```typescript
// [!code word:UniverSheetsNumfmtPlugin]
// [!code word:IUniverSheetsNumfmtConfig]
import { UniverSheetsNumfmtPlugin } from '@univerjs/sheets-numfmt'

univer.registerPlugin(UniverSheetsNumfmtPlugin, IUniverSheetsNumfmtConfig)
```

## IUniverSheetsNumfmtConfig

```ts
export interface IUniverSheetsNumfmtConfig {
  /**
   * Whether to disable the text format alert.
   */
  disableTextFormatAlert?: boolean
  /**
   * Whether to disable the text format mark.
   */
  disableTextFormatMark?: boolean
}
```
