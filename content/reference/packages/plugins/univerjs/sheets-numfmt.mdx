### Key Configuration Options

| Property | Type | Description |
| --- | --- | --- |
| `disableTextFormatAlert` | `boolean` | Whether to disable the text format alert when a number is stored as text. |
| `disableTextFormatMark` | `boolean` | Whether to disable the green mark indicator for cells with numbers stored as text. |
