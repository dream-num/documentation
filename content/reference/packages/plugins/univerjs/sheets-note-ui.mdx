Cell note UI for Univer Sheets.

```typescript
// [!code word:UniverSheetsNoteUIPlugin]
// [!code word:IUniverSheetsNoteUIConfig]
import { UniverSheetsNoteUIPlugin } from '@univerjs/sheets-note-ui'

univer.registerPlugin(UniverSheetsNoteUIPlugin, IUniverSheetsNoteUIConfig)
```

## Entry Points

- Facade: `@univerjs/sheets-note-ui/facade`
- Locale: `@univerjs/sheets-note-ui/locale/*`

## IUniverSheetsNoteUIConfig

```ts
import type { MenuConfig } from '@univerjs/ui'

export interface IUniverSheetsNoteUIConfig {
  menu?: MenuConfig

  defaultNoteSize?: {
    width: number
    height: number
  }
}
```
