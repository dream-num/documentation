Connects the shared resource picker to Univer Boards, including the toolbar, side panel, and drag-or-click insertion flow.

```ts
import { UniverBoardsResourcesUIPlugin } from '@univerjs-pro/boards-resources-ui'

import '@univerjs-pro/boards-resources-ui/lib/index.css'

univer.registerPlugin(UniverBoardsResourcesUIPlugin)
```

## Entry Points

- Locale: `@univerjs-pro/boards-resources-ui/locale/*`
- Style: `@univerjs-pro/boards-resources-ui/lib/index.css`
