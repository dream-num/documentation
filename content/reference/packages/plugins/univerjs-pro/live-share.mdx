Live share collaboration plugin for Web SDK. It requires a shared collaboration Session and a backend that implements the [Live Share protocol](/server/collaboration/extensions#live-share). The `1.0.0-rc.0` collaboration Endpoint does not implement this protocol.

```typescript
// [!code word:UniverLiveSharePlugin]
import { UniverLiveSharePlugin } from '@univerjs-pro/live-share'

univer.registerPlugin(UniverLiveSharePlugin, {})
```

## Entry Points

- Facade: `@univerjs-pro/live-share/facade`

import type { DependencyOverride } from '@univerjs/core'
