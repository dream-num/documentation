Chart model integration and Facade APIs for Univer Docs.

```ts
import { UniverDocsChartPlugin } from '@univerjs-pro/docs-chart'

import '@univerjs-pro/docs-chart/facade'

univer.registerPlugin(UniverDocsChartPlugin)
```

For referenced sources, also register [`UniverChartEmbedPlugin`](/reference/packages/plugins/univerjs-pro/chart-embed) before opening the document. Inline values do not require it. Load `UniverDocsChartUIPlugin` from `@univerjs-pro/docs-chart-ui` for chart rendering and editing.

The root exports `DocChartResourceService`, `IDocChartDataSource`, and `IDocChartDataSourceInput`. Docs owns its chart snapshots and data sources. Use `IResourceRefChartDataSourceInput` from `@univerjs-pro/chart-embed` with chart builders. See [`FDocument.newChart()`](/reference/facade/document#newchart) and [`FDocumentChart`](/reference/facade/document-chart).
