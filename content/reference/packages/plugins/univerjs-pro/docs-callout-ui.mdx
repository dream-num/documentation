Callout block UI plugin for Univer Docs.

```typescript
// [!code word:UniverDocsCalloutUIPlugin]
// [!code word:IUniverDocsCalloutUIConfig]
import { UniverDocsCalloutUIPlugin } from '@univerjs-pro/docs-callout-ui'

univer.registerPlugin(UniverDocsCalloutUIPlugin, IUniverDocsCalloutUIConfig)
```

## Entry Points

- Locale: `@univerjs-pro/docs-callout-ui/locale/*`

## IUniverDocsCalloutUIConfig

```ts
import type { MenuConfig } from '@univerjs/ui'

export interface IUniverDocsCalloutUIConfig {

}
```
