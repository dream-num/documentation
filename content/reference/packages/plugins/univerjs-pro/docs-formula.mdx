Inline data formula model integration and Facade APIs for Univer Docs.

```typescript
import { UniverDocsFormulaPlugin } from '@univerjs-pro/docs-formula'

import '@univerjs-pro/docs-formula/facade'

univer.registerPlugin(UniverDocsFormulaPlugin)
```

## Entry Points

- Facade: `@univerjs-pro/docs-formula/facade`

See the [Document Pro Facade reference](/reference/facade/document-pro#inline-data-formulas).
