LaTeX formula model integration and Facade APIs for Univer Docs. This package also provides the shared LaTeX renderer used by the Docs and Boards UI plugins.

```typescript
import { UniverDocsLatexPlugin } from '@univerjs-pro/docs-latex'

import '@univerjs-pro/docs-latex/facade'

univer.registerPlugin(UniverDocsLatexPlugin)
```

## Entry Points

- Facade: `@univerjs-pro/docs-latex/facade`
