Inline data formula editing and rendering UI for Univer Docs.

```typescript
import { UniverDocsFormulaUIPlugin } from '@univerjs-pro/docs-formula-ui'
import enUS from '@univerjs-pro/docs-formula-ui/locale/en-US'

univer.registerPlugin(UniverDocsFormulaUIPlugin)
```

## Entry Points

- Locale: `@univerjs-pro/docs-formula-ui/locale/*`

`IUniverDocsFormulaUIConfig` extends `IUniverShapeEditorUIConfig` and accepts an optional `menu` configuration.
