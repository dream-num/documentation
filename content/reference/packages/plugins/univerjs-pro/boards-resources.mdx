Materializes static resource payloads as Univer Boards elements. Register resource catalogs with `@univerjs-pro/resources` before opening a Board resource picker.

```ts
import { UniverBoardsResourcesPlugin } from '@univerjs-pro/boards-resources'

univer.registerPlugin(UniverBoardsResourcesPlugin)
```
