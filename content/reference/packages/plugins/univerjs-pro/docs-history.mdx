Document comparison, navigation, and restore semantics for Univer Pro version history.

```typescript
import { UniverDocsHistoryPlugin } from '@univerjs-pro/docs-history'

univer.registerPlugin(UniverDocsHistoryPlugin)
```

This model adapter composes `@univerjs-pro/edit-history` with the Docs data model. Use `@univerjs-pro/docs-history-ui` for ribbon and viewer integration.
