Ink drawing UI, pen state, outside interaction handling, and locale entries for Univer Pro editors.

```typescript
import { UniverInkUIPlugin } from '@univerjs-pro/ink-ui'

import enUS from '@univerjs-pro/ink-ui/locale/en-US'

import '@univerjs-pro/ink-ui/lib/index.css'

univer.registerPlugin(UniverInkUIPlugin)
```

## Entry Points

- Locale: `@univerjs-pro/ink-ui/locale/*`
- Style: `@univerjs-pro/ink-ui/lib/index.css`
