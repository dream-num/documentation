Slides ribbon and viewer integration for Univer SDK Pro version history.

```typescript
import { UniverSlidesHistoryUIPlugin } from '@univerjs-pro/slides-history-ui'
import enUS from '@univerjs-pro/slides-history-ui/locale/en-US'

univer.registerPlugin(UniverSlidesHistoryUIPlugin, {
  historyServerUrl: '/universer-api/history',
  univerContainerId: 'univer-container',
})
```

`viewerPlugins` can add product-specific plugins to the isolated history viewer.

## Entry Points

- Locale: `@univerjs-pro/slides-history-ui/locale/*`
