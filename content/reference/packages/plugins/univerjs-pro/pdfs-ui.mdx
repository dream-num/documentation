Canvas rendering and editing UI for Univer Pro PDF units, including the PDF View ribbon and virtual continuous scrolling.

```typescript
import { UniverPdfsUIPlugin } from '@univerjs-pro/pdfs-ui'
import enUS from '@univerjs-pro/pdfs-ui/locale/en-US'

univer.registerPlugin(UniverPdfsUIPlugin, {
  editor: { enabled: true },
  thumbnailWorkerURL: new Worker(new URL('./pdf-worker.js', import.meta.url), { type: 'module' }),
})
```

## Entry Points

- Locale: `@univerjs-pro/pdfs-ui/locale/*`
- Worker runtime: `startPdfPageThumbnailWorker` from `@univerjs-pro/pdfs-ui`
