Canvas, viewport, selection, shape editing, connectors, sticky notes, ink interaction, toolbar, and context menu UI for Univer Boards.

```typescript
import { UniverBoardsUIPlugin } from '@univerjs-pro/boards-ui'

import enUS from '@univerjs-pro/boards-ui/locale/en-US'

import '@univerjs-pro/boards-ui/lib/index.css'

univer.registerPlugin(UniverBoardsUIPlugin)
```

## Entry Points

- Locale: `@univerjs-pro/boards-ui/locale/*`
- Style: `@univerjs-pro/boards-ui/lib/index.css`
