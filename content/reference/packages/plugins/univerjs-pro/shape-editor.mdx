Formula-backed shape editing services and Facade APIs for Univer SDK Pro.

```typescript
import { UniverShapeEditorPlugin } from '@univerjs-pro/shape-editor'

import '@univerjs-pro/shape-editor/facade'

univer.registerPlugin(UniverShapeEditorPlugin)
```

## Entry Points

- Facade: `@univerjs-pro/shape-editor/facade`

See the [Shape Facade reference](/reference/facade/shape#formula-backed-shapes).
