Code block UI plugin for Univer Docs.

```typescript
// [!code word:UniverDocsCodeUIPlugin]
import { UniverDocsCodeUIPlugin } from '@univerjs-pro/docs-code-ui'

univer.registerPlugin(UniverDocsCodeUIPlugin, {})
```

## Entry Points

- Locale: `@univerjs-pro/docs-code-ui/locale/*`

## IUniverDocsCodeUIConfig

```ts
import type { MenuConfig } from '@univerjs/ui'

export interface IUniverDocsCodeUIConfig {
  menu?: MenuConfig
}
```

## Monospaced font picker

The code block toolbar lists fonts registered with `FontCategory.MONOSPACE` in the shared `IFontService`. Selecting one updates the whole block, including its paragraph styles. Register custom fonts with `univerAPI.addFonts()` and load their font files separately. See [code fonts](/guides/docs/features/code#code-fonts).
