Slicer and timeline controls, menus, and dialogs for Univer Sheets.

```typescript
import { UniverSheetsSlicerPlugin } from '@univerjs-pro/sheets-slicer'
import { UniverSheetsSlicerUIPlugin } from '@univerjs-pro/sheets-slicer-ui'
import '@univerjs-pro/sheets-slicer-ui/lib/index.css'

univer.registerPlugin(UniverSheetsSlicerPlugin)
univer.registerPlugin(UniverSheetsSlicerUIPlugin)
```

Load the locale and configure the required Sheets, drawing, Table, and PivotTable plugins as shown in the [slicer guide](/guides/sheets/features/slicer).

## Entry Points

- Locale: `@univerjs-pro/sheets-slicer-ui/locale/*`
- Styles: `@univerjs-pro/sheets-slicer-ui/lib/index.css`

## IUniverSheetsSlicerUIConfig

```ts
export interface IUniverSheetsSlicerUIConfig {
  maxMemberWindowSize: number
}
```

Plugin registration accepts `Partial<IUniverSheetsSlicerUIConfig>`. When supplied, `maxMemberWindowSize` sets the query window limit in [`@univerjs-pro/sheets-slicer`](/reference/packages/plugins/univerjs-pro/sheets-slicer#iuniversheetsslicerconfig). It must be a positive integer; the default is `200`.
