Shared chart UI controls, formatting panels, and floating menu utilities for Web SDK chart editors.

```typescript
import { ChartElementFloatMenu } from '@univerjs-pro/chart-ui'

import enUS from '@univerjs-pro/chart-ui/locale/en-US'

import '@univerjs-pro/chart-ui/lib/index.css'
```

## Entry Points

- Facade: `@univerjs-pro/chart-ui/facade`
- Locale: `@univerjs-pro/chart-ui/locale/*`
- Style: `@univerjs-pro/chart-ui/lib/index.css`

Import the Facade entry to add `exportImage({ format?: 'png' | 'svg' })` to live `FChart` instances. It returns a rendered data URL, or `undefined` when the current host has no UI renderer.

## Host editor composition

`ChartSetupPanel`, `ChartEditorTabs`, and `ChartDataSourceStatusView` provide shared editor controls. Docs, Slides, and Boards compose their own data-source editors and depend on `UniverEmbedUnitUIPlugin` for reference selection. The shared chart UI plugin does not register that viewer or the referenced-data runtime.

Use [`ReferencedDataSelector`](/reference/packages/plugins/univerjs-pro/embed-unit-ui) for reference selection and register [`UniverChartEmbedPlugin`](/reference/packages/plugins/univerjs-pro/chart-embed) when charts load referenced data. This also applies to mobile integrations.
