Table interaction, selection, keyboard UI, and table design ribbon controls for Univer Slides Pro.

```typescript
import { UniverSlidesTableUIPlugin } from '@univerjs-pro/slides-table-ui'

import enUS from '@univerjs-pro/slides-table-ui/locale/en-US'

import '@univerjs-pro/slides-table-ui/facade'
import '@univerjs-pro/slides-table-ui/lib/index.css'

univer.registerPlugin(UniverSlidesTableUIPlugin)
```

## Entry Points

- Facade: `@univerjs-pro/slides-table-ui/facade`
- Locale: `@univerjs-pro/slides-table-ui/locale/*`
- Style: `@univerjs-pro/slides-table-ui/lib/index.css`
