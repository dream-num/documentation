DOM Pivot View and 12-column Dashboard UI for Univer Base.

```typescript
import { UniverBaseDashboardUIPlugin } from '@univerjs-pro/bases-dashboard-ui'
import enUS from '@univerjs-pro/bases-dashboard-ui/locale/en-US'

import '@univerjs-pro/bases-dashboard-ui/lib/index.css'

univer.registerPlugin(UniverBaseDashboardUIPlugin)
```

Dashboard widgets support Pivot charts, Base table filters, rich text, images, and Formula Shapes.

## Entry Points

- Locale: `@univerjs-pro/bases-dashboard-ui/locale/*`
- Styles: `@univerjs-pro/bases-dashboard-ui/lib/index.css`
