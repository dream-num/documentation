Base comparison, change navigation, and restore semantics for Univer Pro version history.

```typescript
import { UniverBasesHistoryPlugin } from '@univerjs-pro/bases-history'

univer.registerPlugin(UniverBasesHistoryPlugin)
```

This model adapter composes `@univerjs-pro/edit-history` with the Bases data model. Use `@univerjs-pro/bases-history-ui` for ribbon and viewer integration.
