Chart model integration and Facade APIs for Univer Boards.

```ts
import { UniverBoardsChartPlugin } from '@univerjs-pro/boards-chart'

import '@univerjs-pro/boards-chart/facade'

univer.registerPlugin(UniverBoardsChartPlugin)
```

For referenced sources, also register [`UniverChartEmbedPlugin`](/reference/packages/plugins/univerjs-pro/chart-embed) before opening the board. Inline values do not require it. Load `UniverBoardsChartUIPlugin` from `@univerjs-pro/boards-chart-ui` for chart rendering and editing.

The root exports `IBoardChartDataSource` and `IBoardChartDataSourceInput`; `FBoardChart.getDataSource()` returns the host's data-source type. Use `IResourceRefChartDataSourceInput` from `@univerjs-pro/chart-embed` with chart builders. See [`FBoard.newChart()`](/reference/facade/board#newchart) and [`FBoardChart`](/reference/facade/board-chart).

## Entry Points

- Facade: `@univerjs-pro/boards-chart/facade`
