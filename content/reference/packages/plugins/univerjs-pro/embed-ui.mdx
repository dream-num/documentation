Host integration, child-view registration, activation, fullscreen, and menu overrides for embedded Univer units.

```ts
import { UniverEmbedUIPlugin } from '@univerjs-pro/embed-ui'
import EmbedUIEnUS from '@univerjs-pro/embed-ui/locale/en-US'

import '@univerjs-pro/embed-ui/lib/index.css'

univer.registerPlugin(UniverEmbedUIPlugin)
```

Merge `EmbedUIEnUS` into the locale map for applications that enable embed UI.

## Entry Points

- Locale: `@univerjs-pro/embed-ui/locale/*`
- Style: `@univerjs-pro/embed-ui/lib/index.css`
