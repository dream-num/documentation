Docs ribbon and viewer integration for Univer Pro version history.

```typescript
import { UniverDocsHistoryUIPlugin } from '@univerjs-pro/docs-history-ui'
import enUS from '@univerjs-pro/docs-history-ui/locale/en-US'

univer.registerPlugin(UniverDocsHistoryUIPlugin, {
  historyServerUrl: '/universer-api/history',
  univerContainerId: 'univer-container',
})
```

`viewerPlugins` can add product-specific plugins to the isolated history viewer.

## Entry Points

- Locale: `@univerjs-pro/docs-history-ui/locale/*`
