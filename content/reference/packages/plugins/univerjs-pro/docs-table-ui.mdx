Enhanced table UI plugin for Univer Docs.

```typescript
// [!code word:UniverDocsTableUIPlugin]
import { UniverDocsTableUIPlugin } from '@univerjs-pro/docs-table-ui'

univer.registerPlugin(UniverDocsTableUIPlugin, {})
```

## Entry Points

- Locale: `@univerjs-pro/docs-table-ui/locale/*`

## IUniverDocsTableUIConfig

```ts
import type { MenuConfig } from '@univerjs/ui'

export interface IUniverDocsTableUIConfig {
  /** Initial visibility of the table floating toolbar. Defaults to false. */
  floatingToolbar?: boolean
  menu?: MenuConfig
}
```
