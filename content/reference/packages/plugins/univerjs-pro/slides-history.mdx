Slides comparison, change navigation, and restore semantics for Univer Pro version history.

```typescript
import { UniverSlidesHistoryPlugin } from '@univerjs-pro/slides-history'

univer.registerPlugin(UniverSlidesHistoryPlugin)
```

This model adapter composes `@univerjs-pro/edit-history` with the Slides data model. Use `@univerjs-pro/slides-history-ui` for ribbon and viewer integration.
