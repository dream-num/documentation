Canvas, sidebar, playback, insertion tools, editable SmartArt commands, and object rendering UI for Univer Slides in Web SDK.

```typescript
import { UniverSlidesUIPlugin } from '@univerjs-pro/slides-ui'

import enUS from '@univerjs-pro/slides-ui/locale/en-US'

import '@univerjs-pro/slides-ui/lib/index.css'

univer.registerPlugin(UniverSlidesUIPlugin)
```

## Menu configuration

Configure the shared Ribbon through `UniverUIPlugin`'s [`menu` and `ribbonType` options](/reference/packages/plugins/univerjs/ui#menuconfig). They are not options of `UniverSlidesUIPlugin`. For example, `slide.menu.insert.text` and `slide.menu.insert.shape` accept sibling `order` and Ribbon `gridLayout` overrides.

Import `@univerjs/ui/facade` to use [`FUniver.updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) at runtime. [`createMenu()` and `createSubmenu()`](/reference/packages/plugins/univerjs/ui#ifacademenuitem) also accept placement options. See the [Slides menu guide](/guides/slides/features/core#menu-order-and-grid-layout) for initialization and update examples.

`editor.enabled: false` skips registration of the Slides Ribbon. Overrides do not register the missing menu items.
