Chart editor dialogs, insert controls, rendering, printing, and data editing UI for Univer Docs.

```ts
import { UniverDocsChartUIPlugin } from '@univerjs-pro/docs-chart-ui'
import DocsChartUIEnUS from '@univerjs-pro/docs-chart-ui/locale/en-US'

import '@univerjs-pro/docs-chart-ui/lib/index.css'

univer.registerPlugin(UniverDocsChartUIPlugin)
```

Merge `DocsChartUIEnUS` into the locale map for applications that enable Docs chart UI.

## Entry Points

- Locale: `@univerjs-pro/docs-chart-ui/locale/*`
- Style: `@univerjs-pro/docs-chart-ui/lib/index.css`
