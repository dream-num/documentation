Footnote and endnote commands for traditional paginated Docs documents. Requires the Docs plugin and a configured license.

```ts
import { UniverDocsReferencePlugin } from '@univerjs-pro/docs-reference'

import '@univerjs-pro/docs-reference/facade'

univer.registerPlugin(UniverDocsReferencePlugin)
```

The Facade entry extends `FDocument` with insertion, deletion, reads, and settings for both note types. See [Footnotes and endnotes](/guides/docs/features/footnotes) for integration and offset semantics.

`UniverDocsAdvancedPreset` already registers this plugin and its UI plugin. Do not register them again when using that preset.
