Slicer and timeline data, filtering, and Facade APIs for Univer Sheets.

```typescript
import { UniverSheetsSlicerPlugin } from '@univerjs-pro/sheets-slicer'
import '@univerjs-pro/sheets-slicer/facade'

univer.registerPlugin(UniverSheetsSlicerPlugin)
```

For interactive controls, also register [`@univerjs-pro/sheets-slicer-ui`](/reference/packages/plugins/univerjs-pro/sheets-slicer-ui). See the [slicer guide](/guides/sheets/features/slicer) for the required Sheets, drawing, Table, and PivotTable setup.

## Entry Points

- Facade: `@univerjs-pro/sheets-slicer/facade`

## IUniverSheetsSlicerConfig

```ts
export interface IUniverSheetsSlicerConfig {
  notExecuteFormula?: boolean
  maxMemberWindowSize?: number
}
```

`notExecuteFormula` is `true` on the main thread and `false` in the calculation Worker. Omit it when calculation and UI run in the same Univer instance.

`maxMemberWindowSize` limits the number of members returned by a query window. It defaults to `200` and must be a positive integer.

## Facade API

- [`FSheetSlicer`](/reference/facade/sheet-slicer) and [`FSheetTimeline`](/reference/facade/sheet-timeline) manage existing controls.
- [`FSheetSlicerBuilder`](/reference/facade/sheet-slicer-builder) and [`FSheetTimelineBuilder`](/reference/facade/sheet-timeline-builder) configure new controls.

`ISlicerSourceMetadata` describes the source field and its readiness. It contains `fieldId`, `name`, `ready`, and optional `timeline` bounds and interaction state.
