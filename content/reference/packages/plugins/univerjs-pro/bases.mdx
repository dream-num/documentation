Base data model, commands, mutations, services, and Facade APIs for Univer Bases.

```typescript
import { UniverBasesPlugin } from '@univerjs-pro/bases'

import enUS from '@univerjs-pro/bases/locale/en-US'

import '@univerjs-pro/bases/facade'

univer.registerPlugin(UniverBasesPlugin)
```

## Entry Points

- Facade: `@univerjs-pro/bases/facade`
- Locale: `@univerjs-pro/bases/locale/*`

Use the root exports `BASE_TABLE_NAME_REQUIREMENTS`, `validateBaseTableName()`, and `createUniqueBaseTableName()` when your own UI must enforce the same table-name contract as the Facade.
