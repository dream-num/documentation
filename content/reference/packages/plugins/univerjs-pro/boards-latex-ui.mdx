Renders LaTeX in Board text using the shared Docs LaTeX renderer.

```ts
import { UniverBoardsLatexUIPlugin } from '@univerjs-pro/boards-latex-ui'

univer.registerPlugin(UniverBoardsLatexUIPlugin)
```

Register it after `UniverBoardsUIPlugin` or `UniverBoardsMobileUIPlugin`. If the application also edits formulas in Docs, register the [Docs LaTeX UI plugin](/reference/packages/plugins/univerjs-pro/docs-latex-ui) for that editor.
