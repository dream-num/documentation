Print integration for Univer Docs.

```typescript
// [!code word:UniverDocsPrintPlugin]
import { UniverDocsPrintPlugin } from '@univerjs-pro/docs-print'

univer.registerPlugin(UniverDocsPrintPlugin, {})
```

## Entry Points

- Locale: `@univerjs-pro/docs-print/locale/*`

```ts
import type { MenuConfig } from '@univerjs/ui'

export interface IUniverDocsPrintConfig {
  menu?: MenuConfig[]
}
```
