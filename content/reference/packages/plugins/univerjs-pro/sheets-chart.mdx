Chart model integration for Univer Sheets.

```typescript
// [!code word:UniverSheetsChartPlugin]
import { UniverSheetsChartPlugin } from '@univerjs-pro/sheets-chart'

univer.registerPlugin(UniverSheetsChartPlugin)
```

## Entry Points

- Facade: `@univerjs-pro/sheets-chart/facade`
- Locale: `@univerjs-pro/sheets-chart/locale/*`

## IUniverSheetsChartConfig

```ts
import type { ChartRenderMode, IChartHostRect } from '@univerjs-pro/engine-chart'

export interface IUniverSheetsChartConfig {
  chartRenderMode?: ChartRenderMode
  defaultChartSize?: IChartHostRect
}
```

`chartRenderMode` defaults to `ChartRenderMode.Image`. `defaultChartSize` supplies the default chart rectangle.

## Chart sheet Facade [#chart-sheet-facade]

[`FWorkbook.insertChartSheet()`](/reference/facade/workbook#insertchartsheet) creates a chart sheet and its primary chart. [`FWorksheet.getPrimaryChart()`](/reference/facade/worksheet#getprimarychart) and [`FWorksheet.getCharts()`](/reference/facade/worksheet#getcharts) return live chart handles with these methods.

| Method | Behavior |
| --- | --- |
| `getWorksheet(): FWorksheet \| null` | Returns the current host after moves and undo/redo. Returns `null` when the chart or its host no longer exists. |
| `isPrimary(): boolean` | Checks whether the chart is the primary chart of its current chart sheet. |
| `moveTo(target: FWorksheet): Promise<this>` | Moves the chart to a sheet in the same workbook and Univer instance. Rejects if the target or move is invalid. |

Shared chart methods such as `setErrorBars()` are on [`FChart`](/reference/facade/chart).
