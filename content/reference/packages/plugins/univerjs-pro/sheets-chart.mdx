Chart model integration for Univer Sheets.

```typescript
// [!code word:UniverSheetsChartPlugin]
// [!code word:IUniverSheetsChartConfig]
import { UniverSheetsChartPlugin } from '@univerjs-pro/sheets-chart'

univer.registerPlugin(UniverSheetsChartPlugin)
```

## Entry Points

- Facade: `@univerjs-pro/sheets-chart/facade`
- Locale: `@univerjs-pro/sheets-chart/locale/*`

## IUniverSheetsChartConfig

```ts
import type { ChartRenderMode, IChartHostRect } from '@univerjs-pro/engine-chart'

export interface IUniverSheetsChartConfig {
  chartRenderMode?: ChartRenderMode
  defaultChartSize?: IChartHostRect
}
```

`chartRenderMode` defaults to `ChartRenderMode.Image`. `defaultChartSize` supplies the default chart rectangle.
