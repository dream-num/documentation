Shared version-history viewer workflow for Univer Pro products.

```typescript
import { UniverEditHistoryUIPlugin } from '@univerjs-pro/edit-history-ui'
import enUS from '@univerjs-pro/edit-history-ui/locale/en-US'

import '@univerjs-pro/edit-history-ui/lib/index.css'

univer.registerPlugin(UniverEditHistoryUIPlugin)
```

Product UI packages configure this shared viewer. Direct integrations can provide `viewerMode`, a history-session `descriptor`, `canRestore`, `onClose`, and `onRestore`.

## Entry Points

- Locale: `@univerjs-pro/edit-history-ui/locale/*`
- Styles: `@univerjs-pro/edit-history-ui/lib/index.css`
