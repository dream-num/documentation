PostHog-backed telemetry integration for Univer SDK Pro.

```typescript
import { PosthogTelemetryService, UniverTelemetryPlugin } from '@univerjs-pro/telemetry'

univer.registerPlugin(UniverTelemetryPlugin, {
  service: PosthogTelemetryService,
})
```

The configured service must implement `ITelemetryService` from `@univerjs/telemetry`.
