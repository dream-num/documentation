PDF document models, durable mutations, conversion contracts, and Facade APIs for Univer SDK Pro.

```typescript
import { UniverPdfsPlugin } from '@univerjs-pro/pdfs'

import '@univerjs-pro/pdfs/facade'

univer.registerPlugin(UniverPdfsPlugin)
```

## Entry Points

- Facade: `@univerjs-pro/pdfs/facade`

See the [PDF Facade reference](/reference/facade/pdf).
