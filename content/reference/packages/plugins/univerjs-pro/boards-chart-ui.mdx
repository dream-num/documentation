Chart editing UI, data editor, floating toolbar, and render integration for Univer Boards.

```ts
import { UniverBoardsChartUIPlugin } from '@univerjs-pro/boards-chart-ui'

import '@univerjs-pro/boards-chart-ui/lib/index.css'

univer.registerPlugin(UniverBoardsChartUIPlugin)
```

## Entry Points

- Locale: `@univerjs-pro/boards-chart-ui/locale/*`
- Style: `@univerjs-pro/boards-chart-ui/lib/index.css`
