Add browser printing for the active Univer PDF.

## Register the plugin

```typescript
import { UniverPdfsPrintPlugin } from '@univerjs-pro/pdfs-print'

import '@univerjs-pro/pdfs-print/lib/index.css'

univer.registerPlugin(UniverPdfsPrintPlugin)
```

Merge `@univerjs-pro/pdfs-print/locale/<locale>` into your Univer locale map to localize the print action. The root entry also exports `PdfsPrintMenuSchema` for menu customization.

## Entry Points

- Locale: `@univerjs-pro/pdfs-print/locale/*`
- Style: `@univerjs-pro/pdfs-print/lib/index.css`
