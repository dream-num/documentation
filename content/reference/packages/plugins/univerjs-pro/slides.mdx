Presentation model, slide commands, drawing integration, theme, and Facade APIs for Univer Slides Pro.

```typescript
import { UniverSlidesPlugin } from '@univerjs-pro/slides'

import enUS from '@univerjs-pro/slides/locale/en-US'

import '@univerjs-pro/slides/facade'

univer.registerPlugin(UniverSlidesPlugin)
```
## Entry Points

- Facade: `@univerjs-pro/slides/facade`
- Locale: `@univerjs-pro/slides/locale/*`
