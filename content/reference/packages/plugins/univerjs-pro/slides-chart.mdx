Chart elements, resources, commands, and Facade APIs for Univer Slides in Web SDK.

```typescript
import { UniverSlidesChartPlugin } from '@univerjs-pro/slides-chart'

import '@univerjs-pro/slides-chart/facade'

univer.registerPlugin(UniverSlidesChartPlugin)
```

For referenced sources, also register [`UniverChartEmbedPlugin`](/reference/packages/plugins/univerjs-pro/chart-embed) before opening the presentation. Inline values do not require it. Load `UniverSlidesChartUIPlugin` from `@univerjs-pro/slides-chart-ui` for chart rendering and editing.

The root exports `ISlideChartDataSource` and `ISlideChartDataSourceInput`; `FSlideChart.getChartData()` returns the chart snapshot and its host data source, or `null` when unavailable. Use `IResourceRefChartDataSourceInput` from `@univerjs-pro/chart-embed` with chart builders. See the [Slides chart guide](/guides/slides/features/charts).

## Entry Points

- Facade: `@univerjs-pro/slides-chart/facade`
