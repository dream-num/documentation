Enhanced list UI plugin for Univer Docs.

```typescript
// [!code word:UniverDocsListUIPlugin]
import { UniverDocsListUIPlugin } from '@univerjs-pro/docs-list-ui'

univer.registerPlugin(UniverDocsListUIPlugin, {})
```

## Entry Points

- Locale: `@univerjs-pro/docs-list-ui/locale/*`

## IUniverDocsListUIConfig

```ts
import type { MenuConfig } from '@univerjs/ui'

export interface IUniverDocsListUIConfig {
  menu?: MenuConfig
}
```
