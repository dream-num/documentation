Page- and element-anchored thread comments and Facade methods for Univer Slides.

```typescript
import { UniverSlidesThreadCommentPlugin } from '@univerjs-pro/slides-thread-comment'

import '@univerjs-pro/slides-thread-comment/facade'

univer.registerPlugin(UniverSlidesThreadCommentPlugin)

const slide = univerAPI.getActivePresentation()?.getSlideByIndex(0)
await slide?.createPositionCommentAsync({ x: 0.5, y: 0.25 }, 'Review this area.')
```

`FSlide` also exposes element-comment creation and local/synchronized comment queries; `FPageElement` exposes element-scoped helpers.

## Entry Points

- Facade: `@univerjs-pro/slides-thread-comment/facade`
