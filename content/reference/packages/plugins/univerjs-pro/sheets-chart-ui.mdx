Chart UI integration for Univer Sheets.

```typescript
// [!code word:UniverSheetsChartUIPlugin]
import { UniverSheetsChartUIPlugin } from '@univerjs-pro/sheets-chart-ui'

import enUS from '@univerjs-pro/sheets-chart-ui/locale/en-US'

import '@univerjs-pro/sheets-chart-ui/lib/index.css'

univer.registerPlugin(UniverSheetsChartUIPlugin)
```

## Entry Points

- Locale: `@univerjs-pro/sheets-chart-ui/locale/*`
- Style: `@univerjs-pro/sheets-chart-ui/lib/index.css`
