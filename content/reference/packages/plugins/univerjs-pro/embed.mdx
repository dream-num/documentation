Cross-unit embed model and runtime support for Univer products.

```ts
import { UniverEmbedPlugin } from '@univerjs-pro/embed'

import '@univerjs-pro/embed/facade'

univer.registerPlugin(UniverEmbedPlugin)
```

## Entry Points

- Facade: `@univerjs-pro/embed/facade`

## Resource references

Resource-reference helpers such as `parseResourceRef`, `formatResourceRef`, and `normalizeResourceRefInput`, together with their reference types, are exported by `@univerjs-pro/resources`. Import them from that package.
