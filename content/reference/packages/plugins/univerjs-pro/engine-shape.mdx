Shape rendering models, shape definitions, editable SmartArt data, z-order updates, and conversion utilities for Univer SDK Pro.

```typescript
import { ShapeModel, ShapeTypeEnum } from '@univerjs-pro/engine-shape'
```

Import `@univerjs-pro/engine-shape/facade` for live `FShape` APIs, including SmartArt node and layout editing and `setZOrder(index)`. See the [Shape Facade reference](/reference/facade/shape#smartart) for the insertion workflow.
