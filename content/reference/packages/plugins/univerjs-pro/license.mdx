License management plugin and services for Web SDK.

```typescript
// [!code word:UniverLicensePlugin]
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE_KEY',
})
```

Replace `YOUR_LICENSE_KEY` with the license issued for your deployment.

The front-end chart, sparkline, PivotTable and dashboard features described in the [Web SDK license guide](/server/license#web-sdk) are available without a signed license. License authorization controls watermarks on affected chart, print and screenshot output. Collaboration and Exchange apply their own server-side licensing rules.
