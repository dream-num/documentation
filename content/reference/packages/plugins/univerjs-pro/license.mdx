License management plugin and services for Univer SDK Pro.

```typescript
// [!code word:UniverLicensePlugin]
import { UniverLicensePlugin } from '@univerjs-pro/license'

univer.registerPlugin(UniverLicensePlugin, {
  license: 'YOUR_LICENSE_KEY',
})
```

Replace `YOUR_LICENSE_KEY` with the license issued for your deployment.

## IUniverLicenseInputConfig

```ts
export interface IUniverLicenseInputConfig {
  license?: string
}
```

## IUniverLicenseConfig

```ts
export interface IUniverLicenseConfig {
  ls?: string
  pbk?: string

  stv?: boolean
}
```
