Shared slicer and timeline models, styles, and canvas controls.

```typescript
import { UniverSlicerPlugin } from '@univerjs-pro/slicer'

univer.registerPlugin(UniverSlicerPlugin)
```

The plugin has no configuration options. In Sheets, use [`@univerjs-pro/sheets-slicer`](/reference/packages/plugins/univerjs-pro/sheets-slicer), which depends on this plugin.

## Public exports

- `ISlicerDefinition`, `ITimelineDefinition`, and `ISlicerResource` describe slicers, timelines, and their saved data.
- `SlicerSourceKind`, `SlicerTargetKind`, `SlicerControlKind`, and `TimelineLevel` identify sources, targets, controls, and timeline levels.
- `SlicerCacheCrossFilter` and `SlicerCacheSortOrder` configure filtering and sorting.
- `SlicerThemeService`, `SlicerCanvasControl`, and `SlicerShape` provide shared rendering support.
- `BUILT_IN_SLICER_STYLE_NAMES` and `BUILT_IN_TIMELINE_STYLE_NAMES` list the built-in styles.

See the [slicer guide](/guides/sheets/features/slicer) for Sheets setup and usage.
