Product-independent static resource registry for Web SDK. Resource identities are the combination of a registry id and resource id.

```ts
import { UniverResourcesPlugin } from '@univerjs-pro/resources'

univer.registerPlugin(UniverResourcesPlugin)
```

## Resource references

The root entry exports helpers for parsing, formatting, and validating resource references: `parseResourceRef`, `formatResourceRef`, `getResourceRefUnitKey`, `isResourceRefRangePart`, `isResourceRefTablePart`, `normalizeResourceRefInput`, `RESOURCE_REF_FILE_KIND`, `ResourceRefError`, and `ResourceRefErrorCode`.

It also exports the reference types `IResourceRef`, `IResourceRefRangePart`, `IResourceRefTablePart`, `ResourceRefFile`, `ResourceRefInput`, `ResourceRefPart`, and `ResourceRefUnitType`.

Import these APIs from `@univerjs-pro/resources`.
