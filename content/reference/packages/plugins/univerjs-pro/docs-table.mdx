## Whole-table alignment

`DocsTableSetTableAlignCommand` sets an existing Traditional document table's `align` property. Its parameters are `{ unitId, tableId, value }`, where `value` is `TableAlignmentType.START`, `CENTER`, or `END` from `@univerjs/core`. It supports undo/redo and saving; it does not change cell text alignment. Invalid targets, disabled documents, and Modern documents return `false`; setting the existing alignment returns `true` without a change. See [the command example](/guides/docs/features/table#table-alignment).
