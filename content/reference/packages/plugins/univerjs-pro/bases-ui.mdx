Canvas and workspace UI for Univer Bases views, selection, editing, toolbars, and panels.

```typescript
import { UniverBasesUIPlugin } from '@univerjs-pro/bases-ui'

import enUS from '@univerjs-pro/bases-ui/locale/en-US'

import '@univerjs-pro/bases-ui/facade'
import '@univerjs-pro/bases-ui/lib/index.css'

univer.registerPlugin(UniverBasesUIPlugin)
```

## Entry Points

- Facade: `@univerjs-pro/bases-ui/facade`
- Locale: `@univerjs-pro/bases-ui/locale/*`
- Style: `@univerjs-pro/bases-ui/lib/index.css`

## Additional root exports

- `BaseKeyboardOperation` and `executeBaseKeyboardOperation` for keyboard integration.
- `BaseClipboardService` and `IBaseClipboardService` for clipboard integration.
- `BaseEmbedRuntimeRegistryService` for embedded Base runtimes.
- `getBaseTableNameErrorMessage()` and `waitForBaseCanvasImages()` for validation messages and canvas-image readiness.
