## IUniverDocsCorePresetConfig

| Option | Type | Behavior |
| --- | --- | --- |
| `container, header, footer, toolbar, ribbonType, contextMenu, disableAutoFocus` | `UI options` | Forwarded to `UniverUIPlugin`; see [UI configuration](/reference/packages/plugins/univerjs/ui). |
| `menu` | `MenuConfig` | Menu item overrides, sibling `order` for Ribbon tabs/groups/items, and `gridLayout` for the grid Ribbon. Use Docs menu IDs, such as `doc.command.set-inline-format-bold`. See [menu configuration](/reference/packages/plugins/univerjs/ui#menuconfig) and [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) for runtime updates. |
| `collaboration` | `true` | Declared by the type but not consumed by this preset. Use top-level `createUniver({ collaboration: true, ... })` with the collaboration integration. |
