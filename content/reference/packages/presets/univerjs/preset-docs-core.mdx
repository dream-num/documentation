## IUniverDocsCorePresetConfig

| Option | Type | Behavior |
| --- | --- | --- |
| `container, header, footer, toolbar, ribbonType, menu, contextMenu, disableAutoFocus` | `UI options` | Forwarded to `UniverUIPlugin`; see [UI configuration](/reference/packages/plugins/univerjs/ui). |
| `collaboration` | `true` | Declared by the type but not consumed by this preset. Use top-level `createUniver({ collaboration: true, ... })` with the collaboration integration. |
