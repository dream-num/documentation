```typescript
import { UniverSheetsAdvancedPreset } from '@univerjs/preset-sheets-advanced'

const preset = UniverSheetsAdvancedPreset()
```

The preset includes the Sheets PivotTable, chart, PivotChart, and slicer model/UI plugins. Use it with the Sheets core and drawing presets. For PivotChart APIs, also import `@univerjs-pro/sheets-pivot-chart/facade`; see the [PivotChart guide](/guides/sheets/features/pivot-chart).

With Worker calculation, pair `UniverSheetsAdvancedPreset({ useWorker: true })` on the main thread with `UniverSheetsAdvancedWorkerPreset()` from `@univerjs/preset-sheets-advanced/worker`. The Worker preset registers `UniverSheetsPivotChartWorkerPlugin`; drawing and chart bindings remain on the main thread.

## IUniverSheetsAdvancedPresetConfig

| Option | Type | Behavior |
| --- | --- | --- |
| `license` | `string` | License passed to `UniverLicensePlugin`. |
| `universerEndpoint` | `string` | Base URL for exchange upload, task, signed URL, import, export, and download endpoints. |
| `useWorker` | `boolean` | Disables main-thread calculation in the Pro formula, PivotTable, PivotChart, and slicer plugins. Configure the Worker and its advanced preset separately. |
| `formula.function` | `custom function configuration` | Custom functions passed to the Pro formula engine. |
| `exchangeClientOptions` | `Partial<IUniverSheetsExchangeClientConfig>` | Spreadsheet import/export options; see [exchange configuration](/reference/packages/plugins/univerjs-pro/sheets-exchange-client). |
| `print.enforceWatermark` | `boolean` | Controls print watermark enforcement. |
| `pivot.maxLimitItemCount` | `number` | Maximum pivot item limit. |
| `slicer.maxMemberWindowSize` | `number` | Maximum members per slicer query window. Defaults to `200`; must be a positive integer. See [slicer configuration](/reference/packages/plugins/univerjs-pro/sheets-slicer-ui#iuniversheetssliceruiconfig). |
