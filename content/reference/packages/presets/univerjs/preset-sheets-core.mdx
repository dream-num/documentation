## IUniverSheetsCorePresetConfig

| Option | Type | Behavior |
| --- | --- | --- |
| `container` | `string or HTMLElement` | UI mount container. |
| `header, toolbar, ribbonType, contextMenu, disableAutoFocus, customFontFamily` | `UI options` | Forwarded to `UniverUIPlugin`; see [UI configuration](/reference/packages/plugins/univerjs/ui). |
| `menu` | `MenuConfig` | Menu item overrides, sibling `order` for Ribbon tabs/groups/items, and `gridLayout` for the grid Ribbon. See [menu configuration](/reference/packages/plugins/univerjs/ui#menuconfig) and [`updateMenuConfig()`](/reference/facade/univer#updatemenuconfig) for runtime updates. |
| `formulaBar, footer` | `Sheets UI options` | Forwarded to `UniverSheetsUIPlugin`; see [Sheets UI configuration](/reference/packages/plugins/univerjs/sheets-ui). |
| `disableTextFormatAlert, disableTextFormatMark` | `boolean` | Control the warning and marker for text-formatted numeric cells. |
| `docs` | `IUniverDocsPresetConfig` | The preset forwards `docs.hasScroll` to the Docs model plugin. |
| `sheets` | `IUniverSheetsPresetConfig` | Row/column style priority, merged-cell auto height, freeze synchronization, maximum auto-height count, clipboard and scrollbar options, protected-range display/user selection, and forced-string warnings. Set `sheets.allowArrowKeyWrapOnSheetBoundary` to `false` to stop arrow-key navigation at worksheet edges (default: `true`). Set `sheets.textLineGap` to add a finite, non-negative pixel gap between lines of cell text (default: `0`); see [text line spacing](/guides/sheets/features/core/default-style#text-line-gap). |
| `sheets.selectionAnimation` | `boolean` | Animates selection changes when clicking cells on desktop. Defaults to `true` and respects reduced motion. |
| `sheets.enableFillHandle` | `boolean` | Shows the desktop fill handle. Defaults to `true`. Fill commands and Facade APIs remain available. |
| `sheets.warnBeforeDragOverwrite` | `boolean` | Confirms overwrites when dragging a cell range. Defaults to `true`. Move validation and undo/redo apply in either case. |
| `formula` | `IUniverFormulaConfig` | Custom functions, function descriptions, initial formula computation and function screen tips. |
| `workerURL` | `IUniverRPCMainThreadConfig['workerURL']` | Enables the browser RPC worker for formula computation. Optional when calling the preset function. |
