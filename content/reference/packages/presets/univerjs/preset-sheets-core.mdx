## IUniverSheetsCorePresetConfig

| Option | Type | Behavior |
| --- | --- | --- |
| `container` | `string or HTMLElement` | UI mount container. |
| `header, toolbar, ribbonType, menu, contextMenu, disableAutoFocus, customFontFamily` | `UI options` | Forwarded to `UniverUIPlugin`; see [UI configuration](/reference/packages/plugins/univerjs/ui). |
| `formulaBar, footer` | `Sheets UI options` | Forwarded to `UniverSheetsUIPlugin`; see [Sheets UI configuration](/reference/packages/plugins/univerjs/sheets-ui). |
| `disableTextFormatAlert, disableTextFormatMark` | `boolean` | Control the warning and marker for text-formatted numeric cells. |
| `docs` | `IUniverDocsPresetConfig` | The preset forwards `docs.hasScroll` to the Docs model plugin. |
| `sheets` | `IUniverSheetsPresetConfig` | Row/column style priority, merged-cell auto height, freeze synchronization, maximum auto-height count, clipboard and scrollbar options, protected-range display/user selection, and forced-string warnings. |
| `formula` | `IUniverFormulaConfig` | Custom functions, function descriptions, initial formula computation and function screen tips. |
| `workerURL` | `IUniverRPCMainThreadConfig['workerURL']` | Enables the browser RPC worker for formula computation. Optional when calling the preset function. |
