## IUniverSheetsDrawingPresetConfig

| Option | Type | Behavior |
| --- | --- | --- |
| `allowImageSize` | `number` | Maximum uploaded image size in bytes; default 5 × 1024 × 1024. |
| `collaboration` | `boolean` | Removes the local image IO service so the collaboration integration can provide it. Default: false. |
