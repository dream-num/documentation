## IUniverSheetsNodeCorePresetConfig

| Option | Type | Behavior |
| --- | --- | --- |
| `formula` | `IUniverFormulaConfig` | Custom functions and Sheets formula configuration. |
| `workerSrc` | `string` | Node worker script path. Enables the RPC Node main plugin and delegates formula execution to the worker. |
