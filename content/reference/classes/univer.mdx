`Univer` owns the dependency container, plugins, and document units.

```typescript
import { Univer } from '@univerjs/core'

const univer = new Univer({ undoRedoHistoryLimit: 100 })
```

## Constructor parameters

The optional configuration is [`IUniverConfig`](/reference/packages/plugins/univerjs/core#iuniverconfig): theme, dark mode, language packs, region, layout direction, logging, undo history limit, and dependency overrides.

## Unit and plugin access

Use `registerPlugin()` to register plugins and the [Facade API](/reference/facade/univer) to create or access units. Call `univer.dispose()` when the application is removed to release its plugins and services.
