Facade API を使うと、アプリケーションから Office コンテンツを読み書きできます。製品別の索引から API を探すか、下の初期化とプラグイン設定から始めてください。

## API を試す [#quick-start]

まず[インストールと基本的な使い方](/guides/sheets/getting-started/installation)を完了してください。Sheets エディターを初期化し、`createUniver` が返す `univerAPI` を取得すると、次のコードで A1 セルに値を書き込めます。

```ts
const workbook = univerAPI.getActiveWorkbook()
const worksheet = workbook?.getActiveSheet()
worksheet?.getRange('A1').setValue('Hello, Univer!')
```

`univerAPI` は `FUniver` インスタンスです。Sheets では、ワークブックからワークシート、セル範囲へとアクセスします。プラグインモードの初期化と機能別の Facade インポートについては、[Facade API の基本](/guides/sheets/getting-started/facade)を参照してください。

## 初期化と設定 [#configuration]

プリセットを使う場合は [createUniver](/reference/methods/create-univer)、プラグインを直接登録する場合は [Univer](/reference/classes/univer) を参照してください。`Univer` インスタンスはプラグインとドキュメント単位を管理し、`univerAPI` はアプリケーション向けのコンテンツ操作を提供します。

基本設定は [Sheets Core](/reference/packages/presets/univerjs/preset-sheets-core) または [Docs Core](/reference/packages/presets/univerjs/preset-docs-core) から始められます。各パッケージの設定はサイドバーの **Packages → Presets / Plugins** にあります。機能 API を使うには対応するプラグインの登録が必要です。プラグインモードでは、機能ガイドに従って Facade エントリーもインポートしてください。

バックエンドの共同編集とファイル変換は [Server SDK](/server)、CLI ワークフローと AI Agent によるコンテンツ操作は [AI SDK](/ai) から始めてください。
