Facade API로 애플리케이션에서 Office 콘텐츠를 읽고 수정할 수 있습니다. 제품별 색인에서 API를 찾거나 아래의 초기화 및 플러그인 설정부터 시작하세요.

## API 사용해 보기 [#quick-start]

먼저 [설치 및 기본 사용법](/guides/sheets/getting-started/installation)을 완료하세요. Sheets 편집기를 초기화하고 `createUniver`가 반환하는 `univerAPI`를 가져온 다음, 아래 코드로 A1 셀에 값을 쓸 수 있습니다.

```ts
const workbook = univerAPI.getActiveWorkbook()
const worksheet = workbook?.getActiveSheet()
worksheet?.getRange('A1').setValue('Hello, Univer!')
```

`univerAPI`는 `FUniver` 인스턴스입니다. Sheets에서는 통합 문서에서 워크시트로, 다시 셀 범위로 접근합니다. 플러그인 모드 초기화와 기능별 Facade 가져오기는 [Facade API 기초](/guides/sheets/getting-started/facade)를 참고하세요.

## 초기화 및 설정 [#configuration]

프리셋을 사용하면 [createUniver](/reference/methods/create-univer)를, 플러그인을 직접 등록하면 [Univer](/reference/classes/univer)를 참고하세요. `Univer` 인스턴스는 플러그인과 문서 단위를 관리하고, `univerAPI`는 애플리케이션에서 콘텐츠를 조작하는 API를 제공합니다.

기본 설정은 [Sheets Core](/reference/packages/presets/univerjs/preset-sheets-core) 또는 [Docs Core](/reference/packages/presets/univerjs/preset-docs-core)에서 시작하세요. 사이드바의 **Packages → Presets / Plugins**에서 각 패키지 설정을 찾을 수 있습니다. 기능 API를 사용하려면 해당 플러그인을 등록해야 합니다. 플러그인 모드에서는 기능 가이드에 따라 Facade 진입점도 가져오세요.

## 서버 및 AI 통합 [#server-and-ai]

백엔드 공동 편집과 파일 변환은 [Server SDK](/server)에서, CLI 워크플로와 AI Agent 콘텐츠 작업은 [AI SDK](/ai)에서 시작하세요.
