透過 Facade API 在應用程式中讀取與修改 Office 內容。你可以依產品查找介面，也可以從下方的初始化與外掛設定入口開始。

## 試用 API [#quick-start]

先完成[安裝與基本使用](/guides/sheets/getting-started/installation)。初始化 Sheets 編輯器並取得 `createUniver` 傳回的 `univerAPI` 後，下列程式碼會向 A1 儲存格寫入內容：

```ts
const workbook = univerAPI.getActiveWorkbook()
const worksheet = workbook?.getActiveSheet()
worksheet?.getRange('A1').setValue('Hello, Univer!')
```

`univerAPI` 是 `FUniver` 執行個體。在 Sheets 中，從活頁簿進入工作表，再取得儲存格範圍。外掛模式的初始化方式與功能套件的 Facade 匯入方式，請見 [Facade API 基礎](/guides/sheets/getting-started/facade)。

## 初始化與設定 [#configuration]

使用預設時，從 [createUniver](/reference/methods/create-univer) 開始；直接註冊外掛時，請查看 [Univer](/reference/classes/univer)。`Univer` 執行個體負責管理外掛與文件單元，`univerAPI` 提供應用程式操作內容的介面。

基本設定可從 [Sheets Core](/reference/packages/presets/univerjs/preset-sheets-core) 或 [Docs Core](/reference/packages/presets/univerjs/preset-docs-core) 開始。側邊欄 **Packages → Presets / Plugins** 列出各功能套件的設定。使用功能 API 前，需要註冊對應外掛；外掛模式下，也應依功能指南匯入對應的 Facade 入口。
