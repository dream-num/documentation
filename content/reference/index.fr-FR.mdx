Utilisez la Facade API pour lire et modifier le contenu Office dans votre application. Choisissez un produit ci-dessous ou consultez les options d’initialisation et de configuration des plugins.

## Essayer l’API [#quick-start]

Suivez d’abord [l’installation et les premiers pas](/guides/sheets/getting-started/installation). Une fois l’éditeur Sheets initialisé et `univerAPI` obtenu depuis `createUniver`, ce code écrit dans la cellule A1 :

```ts
const workbook = univerAPI.getActiveWorkbook()
const worksheet = workbook?.getActiveSheet()
worksheet?.getRange('A1').setValue('Hello, Univer!')
```

`univerAPI` est une instance de `FUniver`. Dans Sheets, accédez au classeur, puis à la feuille et à une plage de cellules. Consultez les [bases de la Facade API](/guides/sheets/getting-started/facade) pour l’initialisation en mode plugin et les imports Facade propres à chaque fonctionnalité.

## Initialisation et configuration [#configuration]

Univer propose deux modes d’intégration : *le mode prédéfini* et *le mode plugin*. Le mode prédéfini simplifie la configuration grâce à des ensembles de plugins préconfigurés. Pour une **personnalisation ou des extensions approfondies**, nous recommandons le mode plugin, qui permet de combiner et de configurer les plugins individuellement.

Consultez **Packages → Plugins** pour les options de chaque plugin. [createUniver](/reference/methods/create-univer) et **Presets** restent disponibles pour charger des ensembles de plugins préconfigurés.
