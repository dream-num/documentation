---
title: データ型
description: Facade メソッド、スナップショット、セル、リッチテキストで使うデータ構造。
---

API の引数を作成し、戻り値を理解し、エディターのスナップショットを保存するための型です。各ページにインポート方法、定義、フィールド、関連する型を掲載しています。

| 用途 | 型 |
| --- | --- |
| セルの内容 | [CellValue](/reference/types/cell-value) · [ICellData](/reference/types/cell-data) |
| セルの座標と書式 | [IRange](/reference/types/range) · [IStyleData](/reference/types/style-data) |
| スプレッドシートのスナップショット | [IWorkbookData](/reference/types/workbook-data) · [IWorksheetData](/reference/types/worksheet-data) |
| ドキュメントとリッチテキスト | [IDocumentData](/reference/types/document-data) · [IDocumentBody](/reference/types/document-body) · [ITextRun](/reference/types/text-run) · [ITextStyle](/reference/types/text-style) |
| プレゼンテーション | [ISlideData](/reference/types/slide-data) · [ISlidePage](/reference/types/slide-page) |
| ホワイトボード | [IBoardData](/reference/types/board-data) |
| データベース | [IBaseSnapshot](/reference/types/base-snapshot) |
| PDF ユニット | [IPdfUnitData](/reference/types/pdf-unit-data) |
| アプリケーションの外観 | [Theme](/reference/types/theme) |

`IRange` のセル座標はゼロから始まり、開始位置と終了位置の両方を範囲に含みます。`ICellData` は通常の値、数式、リッチテキスト、スタイル参照を格納します。スナップショットは保存時点の状態を表します。編集中の内容を変更するには [Facade メソッド](/reference/facade/univer)を使ってください。

プラグインの設定は対応する[パッケージ](/reference#configuration)を参照してください。イベントコールバックのペイロードは[イベント](/reference/facade/events)に記載しています。メソッドのページには、ほかの引数や戻り値の型へのリンクもあります。
