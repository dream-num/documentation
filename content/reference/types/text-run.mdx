A text formatting run within an `IDocumentBody`. It associates a text interval[^utf16-offsets] with an `ITextStyle`.

[^utf16-offsets]: Text offsets use JavaScript UTF-16 code units, not visible character counts. For example, `"😀".length` is 2. A text run covers `[st, ed)`: `st` is included and `ed` is excluded; do not reuse the inclusive end indices of sheet ranges.
