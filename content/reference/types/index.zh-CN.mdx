---
title: 数据类型
description: Facade 方法、快照、单元格和富文本使用的数据结构。
---

使用这些类型构造 API 参数、理解返回数据并保存编辑器快照。各类型页面包含导入方式、定义、字段和相关类型。

| 用途 | 类型 |
| --- | --- |
| 单元格内容 | [CellValue](/reference/types/cell-value) · [ICellData](/reference/types/cell-data) |
| 单元格坐标与格式 | [IRange](/reference/types/range) · [IStyleData](/reference/types/style-data) |
| 电子表格快照 | [IWorkbookData](/reference/types/workbook-data) · [IWorksheetData](/reference/types/worksheet-data) |
| 文档与富文本 | [IDocumentData](/reference/types/document-data) · [IDocumentBody](/reference/types/document-body) · [ITextRun](/reference/types/text-run) · [ITextStyle](/reference/types/text-style) |
| 演示文稿 | [ISlideData](/reference/types/slide-data) · [ISlidePage](/reference/types/slide-page) |
| 画板 | [IBoardData](/reference/types/board-data) |
| 多维表格 | [IBaseSnapshot](/reference/types/base-snapshot) |
| PDF 单元 | [IPdfUnitData](/reference/types/pdf-unit-data) |
| 应用外观 | [Theme](/reference/types/theme) |

`IRange` 使用从零开始的单元格坐标，起止位置均包含在范围内。`ICellData` 包含普通值、公式、富文本和样式引用。快照描述已保存的状态；修改编辑器中的实时内容，请使用 [Facade 方法](/reference/facade/univer)。

插件配置请查看对应的[功能包](/reference#configuration)。事件回调的数据结构见[事件](/reference/facade/events)。方法页面也会链接到所用的其他参数和返回值类型。
