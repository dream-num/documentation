A rectangular selection described by zero-based row and column indices. Both end indices are inclusive: rows 0–1 and columns 0–1 identify `A1:B2`. This data object describes coordinates; [`FRange`](/reference/facade/range) provides operations on the cells.

```ts
import type { IRange } from '@univerjs/core'

const range: IRange = { startRow: 0, endRow: 1, startColumn: 0, endColumn: 1 } // A1:B2
```
