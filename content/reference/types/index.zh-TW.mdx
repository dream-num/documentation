---
title: 資料型別
description: Facade 方法、快照、儲存格和富文字使用的資料結構。
---

使用這些型別建立 API 參數、理解回傳資料並儲存編輯器快照。各型別頁面包含匯入方式、定義、欄位和相關型別。

| 用途 | 型別 |
| --- | --- |
| 儲存格內容 | [CellValue](/reference/types/cell-value) · [ICellData](/reference/types/cell-data) |
| 儲存格座標與格式 | [IRange](/reference/types/range) · [IStyleData](/reference/types/style-data) |
| 試算表快照 | [IWorkbookData](/reference/types/workbook-data) · [IWorksheetData](/reference/types/worksheet-data) |
| 文件與富文字 | [IDocumentData](/reference/types/document-data) · [IDocumentBody](/reference/types/document-body) · [ITextRun](/reference/types/text-run) · [ITextStyle](/reference/types/text-style) |
| 簡報 | [ISlideData](/reference/types/slide-data) · [ISlidePage](/reference/types/slide-page) |
| 白板 | [IBoardData](/reference/types/board-data) |
| 多維表格 | [IBaseSnapshot](/reference/types/base-snapshot) |
| PDF 單元 | [IPdfUnitData](/reference/types/pdf-unit-data) |
| 應用程式外觀 | [Theme](/reference/types/theme) |

`IRange` 使用從零開始的儲存格座標，起訖位置均包含在範圍內。`ICellData` 包含一般值、公式、富文字和樣式參照。快照描述已儲存的狀態；修改編輯器中的即時內容，請使用 [Facade 方法](/reference/facade/univer)。

外掛設定請查看對應的[套件](/reference#configuration)。事件回呼的資料結構見[事件](/reference/facade/events)。方法頁面也會連結至所用的其他參數和回傳值型別。
