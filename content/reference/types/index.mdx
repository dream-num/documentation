title: Data types
description: Data structures used by Facade methods, snapshots, cells, and rich text.
---

Use these types to construct API arguments, interpret returned data, and save editor snapshots. Each page includes its import, definition, fields, and related types.

| Working with | Types |
| --- | --- |
| Cell content | [CellValue](/reference/types/cell-value) · [ICellData](/reference/types/cell-data) |
| Cell coordinates and formatting | [IRange](/reference/types/range) · [IStyleData](/reference/types/style-data) |
| Spreadsheet snapshots | [IWorkbookData](/reference/types/workbook-data) · [IWorksheetData](/reference/types/worksheet-data) |
| Documents and rich text | [IDocumentData](/reference/types/document-data) · [IDocumentBody](/reference/types/document-body) · [ITextRun](/reference/types/text-run) · [ITextStyle](/reference/types/text-style) |
| Presentations | [ISlideData](/reference/types/slide-data) · [ISlidePage](/reference/types/slide-page) |
| Whiteboards | [IBoardData](/reference/types/board-data) |
| Bases | [IBaseSnapshot](/reference/types/base-snapshot) |
| PDF units | [IPdfUnitData](/reference/types/pdf-unit-data) |
| Application appearance | [Theme](/reference/types/theme) |

`IRange` uses zero-based, inclusive cell coordinates. `ICellData` contains plain values, formulas, rich text, and style references. A snapshot describes a saved state; use [Facade methods](/reference/facade/univer) to change the live editor.

For plugin configuration, open the corresponding [package](/reference#configuration). Event callbacks document their payloads in [Events](/reference/facade/events). Method pages link to any additional parameter and return types they use.
