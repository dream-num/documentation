---
title: Types de données
description: Structures de données des méthodes Facade, des instantanés, des cellules et du texte enrichi.
---

Utilisez ces types pour construire les arguments des API, interpréter les données renvoyées et enregistrer des instantanés de l’éditeur. Chaque page présente l’import, la définition, les champs et les types associés.

| Usage | Types |
| --- | --- |
| Contenu des cellules | [CellValue](/reference/types/cell-value) · [ICellData](/reference/types/cell-data) |
| Coordonnées et format des cellules | [IRange](/reference/types/range) · [IStyleData](/reference/types/style-data) |
| Instantanés de feuilles de calcul | [IWorkbookData](/reference/types/workbook-data) · [IWorksheetData](/reference/types/worksheet-data) |
| Documents et texte enrichi | [IDocumentData](/reference/types/document-data) · [IDocumentBody](/reference/types/document-body) · [ITextRun](/reference/types/text-run) · [ITextStyle](/reference/types/text-style) |
| Présentations | [ISlideData](/reference/types/slide-data) · [ISlidePage](/reference/types/slide-page) |
| Tableaux blancs | [IBoardData](/reference/types/board-data) |
| Bases de données | [IBaseSnapshot](/reference/types/base-snapshot) |
| Unités PDF | [IPdfUnitData](/reference/types/pdf-unit-data) |
| Apparence de l’application | [Theme](/reference/types/theme) |

`IRange` utilise des coordonnées de cellule commençant à zéro, avec les positions de début et de fin incluses. `ICellData` contient des valeurs simples, des formules, du texte enrichi et des références de style. Un instantané décrit un état enregistré ; utilisez les [méthodes Facade](/reference/facade/univer) pour modifier le contenu dans l’éditeur.

Pour configurer un plugin, consultez le [package](/reference#configuration) correspondant. Les données transmises aux callbacks d’événements sont décrites dans [Événements](/reference/facade/events). Les pages des méthodes renvoient aussi vers les autres types utilisés pour leurs paramètres et leurs valeurs de retour.
