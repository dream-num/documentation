---
title: Типы данных
description: Структуры данных для методов Facade, снимков, ячеек и форматированного текста.
---

Используйте эти типы для формирования аргументов API, обработки возвращаемых данных и сохранения снимков редактора. Каждая страница содержит способ импорта, определение, поля и связанные типы.

| Назначение | Типы |
| --- | --- |
| Содержимое ячеек | [CellValue](/reference/types/cell-value) · [ICellData](/reference/types/cell-data) |
| Координаты и формат ячеек | [IRange](/reference/types/range) · [IStyleData](/reference/types/style-data) |
| Снимки электронных таблиц | [IWorkbookData](/reference/types/workbook-data) · [IWorksheetData](/reference/types/worksheet-data) |
| Документы и форматированный текст | [IDocumentData](/reference/types/document-data) · [IDocumentBody](/reference/types/document-body) · [ITextRun](/reference/types/text-run) · [ITextStyle](/reference/types/text-style) |
| Презентации | [ISlideData](/reference/types/slide-data) · [ISlidePage](/reference/types/slide-page) |
| Доски | [IBoardData](/reference/types/board-data) |
| Базы данных | [IBaseSnapshot](/reference/types/base-snapshot) |
| Модули PDF | [IPdfUnitData](/reference/types/pdf-unit-data) |
| Внешний вид приложения | [Theme](/reference/types/theme) |

`IRange` использует координаты ячеек с отсчётом от нуля; начальная и конечная позиции входят в диапазон. `ICellData` содержит обычные значения, формулы, форматированный текст и ссылки на стили. Снимок описывает сохранённое состояние; для изменения содержимого в редакторе используйте [методы Facade](/reference/facade/univer).

Настройки плагинов описаны в соответствующих [пакетах](/reference#configuration). Данные, передаваемые обработчикам событий, приведены на странице [событий](/reference/facade/events). Страницы методов также содержат ссылки на другие типы параметров и возвращаемых значений.
