---
title: 데이터 타입
description: Facade 메서드, 스냅샷, 셀 및 서식 있는 텍스트에 사용하는 데이터 구조입니다.
---

이 타입으로 API 인수를 구성하고, 반환 데이터를 이해하고, 편집기 스냅샷을 저장할 수 있습니다. 각 페이지에는 가져오기 방법, 정의, 필드 및 관련 타입이 포함되어 있습니다.

| 용도 | 타입 |
| --- | --- |
| 셀 콘텐츠 | [CellValue](/reference/types/cell-value) · [ICellData](/reference/types/cell-data) |
| 셀 좌표와 서식 | [IRange](/reference/types/range) · [IStyleData](/reference/types/style-data) |
| 스프레드시트 스냅샷 | [IWorkbookData](/reference/types/workbook-data) · [IWorksheetData](/reference/types/worksheet-data) |
| 문서와 서식 있는 텍스트 | [IDocumentData](/reference/types/document-data) · [IDocumentBody](/reference/types/document-body) · [ITextRun](/reference/types/text-run) · [ITextStyle](/reference/types/text-style) |
| 프레젠테이션 | [ISlideData](/reference/types/slide-data) · [ISlidePage](/reference/types/slide-page) |
| 화이트보드 | [IBoardData](/reference/types/board-data) |
| 데이터베이스 | [IBaseSnapshot](/reference/types/base-snapshot) |
| PDF 단위 | [IPdfUnitData](/reference/types/pdf-unit-data) |
| 애플리케이션 모양 | [Theme](/reference/types/theme) |

`IRange`는 0부터 시작하는 셀 좌표를 사용하며 시작 위치와 끝 위치를 모두 범위에 포함합니다. `ICellData`에는 일반 값, 수식, 서식 있는 텍스트 및 스타일 참조가 포함됩니다. 스냅샷은 저장된 상태를 나타냅니다. 편집 중인 콘텐츠를 변경하려면 [Facade 메서드](/reference/facade/univer)를 사용하세요.

플러그인 설정은 해당 [패키지](/reference#configuration)를 참조하세요. 이벤트 콜백의 페이로드는 [이벤트](/reference/facade/events)에 설명되어 있습니다. 메서드 페이지에는 사용하는 다른 매개변수와 반환값 타입의 링크도 있습니다.
