---
title: Tipos de datos
description: Estructuras de datos para métodos Facade, instantáneas, celdas y texto enriquecido.
---

Usa estos tipos para construir los argumentos de las API, interpretar los datos devueltos y guardar instantáneas del editor. Cada página incluye la importación, la definición, los campos y los tipos relacionados.

| Uso | Tipos |
| --- | --- |
| Contenido de las celdas | [CellValue](/reference/types/cell-value) · [ICellData](/reference/types/cell-data) |
| Coordenadas y formato de las celdas | [IRange](/reference/types/range) · [IStyleData](/reference/types/style-data) |
| Instantáneas de hojas de cálculo | [IWorkbookData](/reference/types/workbook-data) · [IWorksheetData](/reference/types/worksheet-data) |
| Documentos y texto enriquecido | [IDocumentData](/reference/types/document-data) · [IDocumentBody](/reference/types/document-body) · [ITextRun](/reference/types/text-run) · [ITextStyle](/reference/types/text-style) |
| Presentaciones | [ISlideData](/reference/types/slide-data) · [ISlidePage](/reference/types/slide-page) |
| Pizarras | [IBoardData](/reference/types/board-data) |
| Bases de datos | [IBaseSnapshot](/reference/types/base-snapshot) |
| Unidades PDF | [IPdfUnitData](/reference/types/pdf-unit-data) |
| Apariencia de la aplicación | [Theme](/reference/types/theme) |

`IRange` usa coordenadas de celda que empiezan en cero e incluyen tanto la posición inicial como la final. `ICellData` contiene valores simples, fórmulas, texto enriquecido y referencias de estilo. Una instantánea describe un estado guardado; usa los [métodos Facade](/reference/facade/univer) para modificar el contenido en el editor.

Para configurar un plugin, consulta el [paquete](/reference#configuration) correspondiente. Los datos que reciben los callbacks de eventos se describen en [Eventos](/reference/facade/events). Las páginas de los métodos también enlazan a los demás tipos de sus parámetros y valores de retorno.
