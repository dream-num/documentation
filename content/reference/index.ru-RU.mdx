Используйте Facade API для чтения и изменения содержимого Office в приложении. Найдите интерфейс по продукту или начните с раздела инициализации и настройки плагинов ниже.

## Попробуйте API [#quick-start]

Сначала выполните [установку и базовую настройку](/guides/sheets/getting-started/installation). После инициализации редактора Sheets и получения `univerAPI` из `createUniver` этот код запишет значение в ячейку A1:

```ts
const workbook = univerAPI.getActiveWorkbook()
const worksheet = workbook?.getActiveSheet()
worksheet?.getRange('A1').setValue('Hello, Univer!')
```

`univerAPI` — экземпляр `FUniver`. В Sheets переходите от книги к листу, а затем к диапазону ячеек. Инициализация в режиме плагинов и импорт Facade для отдельных функций описаны в [основах Facade API](/guides/sheets/getting-started/facade).

## Инициализация и настройка [#configuration]

Для пресетов используйте [createUniver](/reference/methods/create-univer), а для прямой регистрации плагинов — [Univer](/reference/classes/univer). Экземпляр `Univer` управляет плагинами и единицами документов; `univerAPI` предоставляет приложению операции с содержимым.

Начните с [Sheets Core](/reference/packages/presets/univerjs/preset-sheets-core) или [Docs Core](/reference/packages/presets/univerjs/preset-docs-core). Настройки пакетов находятся в разделе **Packages → Presets / Plugins** боковой панели. Для API отдельной функции нужны соответствующие зарегистрированные плагины. В режиме плагинов также импортируйте точку входа Facade, указанную в руководстве по функции.
