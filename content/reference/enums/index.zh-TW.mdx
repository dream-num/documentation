---
title: 常用列舉
description: 內容、版面配置和 Univer 初始化中常用的列舉值。
---

從 `@univerjs/core` 匯入這些列舉。相較於快照中儲存的數字，列舉名稱讓程式碼更容易閱讀。

| 用途 | 列舉 |
| --- | --- |
| 儲存格值的型別 | [CellValueType](/reference/enums/cell-value-type) |
| 快照中的數字布林旗標 | [BooleanNumber](/reference/enums/boolean-number) |
| 儲存格與文字對齊 | [HorizontalAlign](/reference/enums/horizontal-align) · [VerticalAlign](/reference/enums/vertical-align) |
| 文字換行與框線 | [WrapStrategy](/reference/enums/wrap-strategy) · [BorderStyleTypes](/reference/enums/border-style-types) |
| 初始化階段 | [LifecycleStages](/reference/enums/lifecycle-stages) |
| 建立文件單元 | [UniverInstanceType](/reference/enums/univer-instance-type) |
| 語言與日誌 | [LocaleType](/reference/enums/locale-type) · [LogLevel](/reference/enums/log-level) |

透過 `univerAPI.Enum` 提供的功能列舉，見[完整 Facade 列舉目錄](/reference/facade/enums)，涵蓋資料驗證、篩選、圖表、形狀、Slides、Boards、Bases 和其他已載入外掛。

```ts
import { WrapStrategy } from '@univerjs/core'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')
sheet.getRange('A1:B4').setWrapStrategy(WrapStrategy.WRAP)
```
