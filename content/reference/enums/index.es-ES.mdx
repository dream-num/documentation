---
title: Enumeraciones comunes
description: Valores con nombre habituales para el contenido, el diseño y la inicialización de Univer.
---

Importa estas enumeraciones desde `@univerjs/core`. Sus nombres hacen que el código sea más fácil de leer que los valores numéricos almacenados en las instantáneas.

| Uso | Enumeración |
| --- | --- |
| Tipo de los valores de celda | [CellValueType](/reference/enums/cell-value-type) |
| Indicadores booleanos numéricos en las instantáneas | [BooleanNumber](/reference/enums/boolean-number) |
| Alineación de celdas y texto | [HorizontalAlign](/reference/enums/horizontal-align) · [VerticalAlign](/reference/enums/vertical-align) |
| Ajuste de texto y bordes | [WrapStrategy](/reference/enums/wrap-strategy) · [BorderStyleTypes](/reference/enums/border-style-types) |
| Etapas de inicialización | [LifecycleStages](/reference/enums/lifecycle-stages) |
| Creación de unidades | [UniverInstanceType](/reference/enums/univer-instance-type) |
| Idioma y registros | [LocaleType](/reference/enums/locale-type) · [LogLevel](/reference/enums/log-level) |

Para consultar los valores específicos de cada función que ofrece `univerAPI.Enum`, visita el [catálogo completo de enumeraciones Facade](/reference/facade/enums). Incluye valores de validación, filtros, gráficos, formas, Slides, Boards, Bases y otros plugins cargados.

```ts
import { WrapStrategy } from '@univerjs/core'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')
sheet.getRange('A1:B4').setWrapStrategy(WrapStrategy.WRAP)
```
