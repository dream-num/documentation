---
title: Énumérations communes
description: Valeurs nommées communes pour le contenu, la mise en page et l’initialisation de Univer.
---

Importez ces énumérations depuis `@univerjs/core`. Leurs noms rendent le code plus lisible que les valeurs numériques stockées dans les instantanés.

| Usage | Énumération |
| --- | --- |
| Type des valeurs de cellule | [CellValueType](/reference/enums/cell-value-type) |
| Indicateurs booléens numériques dans les instantanés | [BooleanNumber](/reference/enums/boolean-number) |
| Alignement des cellules et du texte | [HorizontalAlign](/reference/enums/horizontal-align) · [VerticalAlign](/reference/enums/vertical-align) |
| Renvoi à la ligne et bordures | [WrapStrategy](/reference/enums/wrap-strategy) · [BorderStyleTypes](/reference/enums/border-style-types) |
| Étapes d’initialisation | [LifecycleStages](/reference/enums/lifecycle-stages) |
| Création d’unités | [UniverInstanceType](/reference/enums/univer-instance-type) |
| Langue et journalisation | [LocaleType](/reference/enums/locale-type) · [LogLevel](/reference/enums/log-level) |

Pour les valeurs propres aux fonctionnalités exposées par `univerAPI.Enum`, consultez le [catalogue complet des énumérations Facade](/reference/facade/enums). Il couvre la validation, le filtrage, les graphiques, les formes, Slides, Boards, Bases et les autres plugins chargés.

```ts
import { WrapStrategy } from '@univerjs/core'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')
sheet.getRange('A1:B4').setWrapStrategy(WrapStrategy.WRAP)
```
