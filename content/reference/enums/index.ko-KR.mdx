---
title: 공통 열거형
description: 콘텐츠, 레이아웃 및 Univer 초기화에 사용하는 공통 열거형 값입니다.
---

이 열거형은 `@univerjs/core`에서 가져옵니다. 스냅샷에 저장되는 숫자 대신 열거형 이름을 사용하면 코드를 더 쉽게 읽을 수 있습니다.

| 용도 | 열거형 |
| --- | --- |
| 셀 값의 타입 | [CellValueType](/reference/enums/cell-value-type) |
| 스냅샷의 숫자형 불리언 플래그 | [BooleanNumber](/reference/enums/boolean-number) |
| 셀과 텍스트 정렬 | [HorizontalAlign](/reference/enums/horizontal-align) · [VerticalAlign](/reference/enums/vertical-align) |
| 텍스트 줄 바꿈과 테두리 | [WrapStrategy](/reference/enums/wrap-strategy) · [BorderStyleTypes](/reference/enums/border-style-types) |
| 초기화 단계 | [LifecycleStages](/reference/enums/lifecycle-stages) |
| 단위 생성 | [UniverInstanceType](/reference/enums/univer-instance-type) |
| 언어와 로깅 | [LocaleType](/reference/enums/locale-type) · [LogLevel](/reference/enums/log-level) |

`univerAPI.Enum`으로 제공되는 기능별 값은 [전체 Facade 열거형 목록](/reference/facade/enums)을 참조하세요. 데이터 유효성 검사, 필터, 차트, 도형, Slides, Boards, Bases 및 로드된 다른 플러그인의 값을 포함합니다.

```ts
import { WrapStrategy } from '@univerjs/core'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')
sheet.getRange('A1:B4').setWrapStrategy(WrapStrategy.WRAP)
```
