title: LogLevel
icon: '#ref/E'
---

```typescript
import { LogLevel, Univer } from '@univerjs/core'

const univer = new Univer({ logLevel: LogLevel.WARN })
```

| Value | Number | Enabled messages |
| --- | --- | --- |
| `SILENT` | 0 | None |
| `ERROR` | 1 | Errors |
| `WARN` | 2 | Warnings and errors |
| `INFO` | 3 | Information, warnings and errors |
| `VERBOSE` | 4 | Debug messages and all levels above |

`new Univer()` uses `INFO` by default; `createUniver()` uses `WARN` unless overridden.
