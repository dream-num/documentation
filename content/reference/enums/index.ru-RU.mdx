---
title: Общие перечисления
description: Общие именованные значения для содержимого, оформления и инициализации Univer.
---

Импортируйте эти перечисления из `@univerjs/core`. Их имена делают код понятнее, чем числовые значения, хранящиеся в снимках.

| Назначение | Перечисление |
| --- | --- |
| Тип значений ячеек | [CellValueType](/reference/enums/cell-value-type) |
| Числовые логические флаги в снимках | [BooleanNumber](/reference/enums/boolean-number) |
| Выравнивание ячеек и текста | [HorizontalAlign](/reference/enums/horizontal-align) · [VerticalAlign](/reference/enums/vertical-align) |
| Перенос текста и границы | [WrapStrategy](/reference/enums/wrap-strategy) · [BorderStyleTypes](/reference/enums/border-style-types) |
| Этапы инициализации | [LifecycleStages](/reference/enums/lifecycle-stages) |
| Создание модулей | [UniverInstanceType](/reference/enums/univer-instance-type) |
| Язык и журналирование | [LocaleType](/reference/enums/locale-type) · [LogLevel](/reference/enums/log-level) |

Значения отдельных функций, доступные через `univerAPI.Enum`, приведены в [полном каталоге перечислений Facade](/reference/facade/enums). Он включает проверку данных, фильтрацию, диаграммы, фигуры, Slides, Boards, Bases и другие загруженные плагины.

```ts
import { WrapStrategy } from '@univerjs/core'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')
sheet.getRange('A1:B4').setWrapStrategy(WrapStrategy.WRAP)
```
