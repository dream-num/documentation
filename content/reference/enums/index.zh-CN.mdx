---
title: 常用枚举
description: 内容、布局和 Univer 初始化中常用的枚举值。
---

从 `@univerjs/core` 导入这些枚举。与快照中存储的数字相比，枚举名称让代码更易读。

| 用途 | 枚举 |
| --- | --- |
| 单元格值的类型 | [CellValueType](/reference/enums/cell-value-type) |
| 快照中的数字布尔标记 | [BooleanNumber](/reference/enums/boolean-number) |
| 单元格与文本对齐 | [HorizontalAlign](/reference/enums/horizontal-align) · [VerticalAlign](/reference/enums/vertical-align) |
| 文本换行与边框 | [WrapStrategy](/reference/enums/wrap-strategy) · [BorderStyleTypes](/reference/enums/border-style-types) |
| 初始化阶段 | [LifecycleStages](/reference/enums/lifecycle-stages) |
| 创建文档单元 | [UniverInstanceType](/reference/enums/univer-instance-type) |
| 语言与日志 | [LocaleType](/reference/enums/locale-type) · [LogLevel](/reference/enums/log-level) |

通过 `univerAPI.Enum` 提供的功能枚举，见[完整 Facade 枚举目录](/reference/facade/enums)，涵盖数据验证、筛选、图表、形状、Slides、Boards、Bases 和其他已加载插件。

```ts
import { WrapStrategy } from '@univerjs/core'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')
sheet.getRange('A1:B4').setWrapStrategy(WrapStrategy.WRAP)
```
