---
title: 共通の列挙型
description: コンテンツ、レイアウト、Univer の初期化で使う共通の列挙値。
---

これらの列挙型は `@univerjs/core` からインポートします。スナップショットに保存される数値の代わりに列挙値の名前を使うと、コードが読みやすくなります。

| 用途 | 列挙型 |
| --- | --- |
| セル値の型 | [CellValueType](/reference/enums/cell-value-type) |
| スナップショット内の数値による真偽値 | [BooleanNumber](/reference/enums/boolean-number) |
| セルとテキストの配置 | [HorizontalAlign](/reference/enums/horizontal-align) · [VerticalAlign](/reference/enums/vertical-align) |
| テキストの折り返しと罫線 | [WrapStrategy](/reference/enums/wrap-strategy) · [BorderStyleTypes](/reference/enums/border-style-types) |
| 初期化の段階 | [LifecycleStages](/reference/enums/lifecycle-stages) |
| ユニットの作成 | [UniverInstanceType](/reference/enums/univer-instance-type) |
| 言語とログ | [LocaleType](/reference/enums/locale-type) · [LogLevel](/reference/enums/log-level) |

`univerAPI.Enum` で公開される機能別の値は、[Facade 列挙型一覧](/reference/facade/enums)を参照してください。データの入力規則、フィルター、グラフ、図形、Slides、Boards、Bases、その他の読み込み済みプラグインの値を掲載しています。

```ts
import { WrapStrategy } from '@univerjs/core'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')
sheet.getRange('A1:B4').setWrapStrategy(WrapStrategy.WRAP)
```
