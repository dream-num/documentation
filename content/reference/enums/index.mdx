---
title: Common enums
description: Common named values for content, layout, and Univer initialization.
---

Import these enums from `@univerjs/core`. Their names make code easier to read than the numeric values stored in snapshots.

| Purpose | Enum |
| --- | --- |
| Cell value interpretation | [CellValueType](/reference/enums/cell-value-type) |
| Numeric boolean flags in snapshots | [BooleanNumber](/reference/enums/boolean-number) |
| Cell and text alignment | [HorizontalAlign](/reference/enums/horizontal-align) · [VerticalAlign](/reference/enums/vertical-align) |
| Text wrapping and borders | [WrapStrategy](/reference/enums/wrap-strategy) · [BorderStyleTypes](/reference/enums/border-style-types) |
| Initialization progress | [LifecycleStages](/reference/enums/lifecycle-stages) |
| Unit creation | [UniverInstanceType](/reference/enums/univer-instance-type) |
| Locale and logging | [LocaleType](/reference/enums/locale-type) · [LogLevel](/reference/enums/log-level) |

For feature-specific values exposed as `univerAPI.Enum`, browse the [complete Facade enum catalog](/reference/facade/enums). It includes values for validation, filtering, charts, shapes, Slides, Boards, Bases, and other loaded plugins.

```ts
import { WrapStrategy } from '@univerjs/core'

const sheet = univerAPI.getActiveWorkbook()?.getActiveSheet()
if (!sheet) throw new Error('No active worksheet')
sheet.getRange('A1:B4').setWrapStrategy(WrapStrategy.WRAP)
```
