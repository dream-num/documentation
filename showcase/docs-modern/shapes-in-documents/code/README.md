# Native shapes

The demo runtime and authored data are English-only, including on a Chinese documentation page. Complete official English locale packs are retained. Any legacy locale argument is accepted but ignored; saved-snapshot argument positions are unchanged. Earlier bilingual test reports below describe the previous revision, not current language acceptance.

The preview and standalone entry use `createDemo()`. Its `univerAPI` exposes the public Facades below; the demo also exposes it as `window.univerAPI`. Native Grid controls handle interactive editing. Shape IDs are generated by the SDK: retain the ID returned by insertion instead of assuming a sample ID.

Start with a gallery shape:

```ts
const { univerAPI } = demo
const doc = univerAPI.getActiveDocument()
const shape = doc?.getShapes()[0]
if (!doc || !shape) throw new Error('Open the shape gallery first.')
```

## 1. Edit text and geometry

```ts
shape.getText().setText('Review')
shape.setShapeType(univerAPI.Enum.ShapeTypeEnum.RoundRect)
```

## 2. Change fill and outline

```ts
shape.setShapeData({
  ...shape.getShapeData(),
  fill: { fillType: univerAPI.Enum.ShapeFillEnum.SolidFill, color: '#d1fae5' },
  stroke: {
    lineStrokeType: univerAPI.Enum.ShapeLineTypeEnum.SolidLine,
    color: '#047857',
    width: 2,
  },
})
```

Use `{ fillType: univerAPI.Enum.ShapeFillEnum.NoFill }` for an unfilled outline.

## 3. Resize and rotate

```ts
shape.setSize(200, 80).setRotation(8)
```

## 4. Insert with square wrapping

```ts
const paragraph = doc.getParagraphs()[0]
const added = doc.insertShape({
  shapeType: univerAPI.Enum.ShapeTypeEnum.Ellipse,
  placement: {
    wrappingStyle: univerAPI.Enum.TextWrappingStyle.WRAP_SQUARE,
    anchor: { paragraphId: paragraph.getId() },
    position: { horizontalOffset: 64, verticalOffset: 24 },
  },
  transform: { width: 160, height: 80 },
})
if (!added) throw new Error('Shape insertion failed.')
added.getText().setText('Note')
const addedId = added.getId()
```

For inline placement, use `TextWrappingStyle.INLINE` and omit `position`. Behind-text placement uses `TextWrappingStyle.BEHIND_TEXT`; it does not reserve text space, so use a pale fill. Floating X is page-relative; Y is paragraph-relative.

## 5. Arrange and remove

```ts
doc.getShape(addedId)?.bringToFront()
if (!doc.getShape(addedId)?.remove()) throw new Error('Shape removal failed.')
```

Drawing order and behind-text placement are separate concepts. Use the native Grid Undo/Redo controls to reverse editing operations.

Theme changes call `univerAPI.toggleDarkMode()` and preserve edits. The demo imports the official English locale bundles and styles, including shape-editor UI dependencies, and keeps native license notices. It does not repair the beta.2 narrow-layout `breakType` issue or add custom reflow.
