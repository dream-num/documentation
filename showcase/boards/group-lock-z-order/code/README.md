# Groups, locks and layers

Native UI, demo labels and authored data are English-only, including on Chinese documentation pages. Legacy locale arguments are ignored; saved-snapshot argument positions are unchanged. Earlier bilingual acceptance reports below remain historical evidence, not validation of this English-only revision.

Four native Canvas clusters: three overlapping cards; one group of three shapes; an inner pair nested with a peer in an outer group; one locked and one movable shape. Four native text labels replace the museum story, unrelated connectors and host property/history/JSON panels.

Use native selection and contextual group/layer actions. The Canvas owns its native toolbar; the generic office toolbar is disabled, not replaced by fake Grid controls.

Initialization calls wrapElementsInContainer() twice for nesting and once for the simple group, then bringElementsToFront(). getElementParentChain() resolves the generated group ID. In DevTools, window.univerAPI.getActiveBoard() exposes real Canvas Facades.

```ts
const board = window.univerAPI.getActiveBoard()
board.sendElementsToBack(['layer-front'])
board.bringElementsForward(['layer-front'])
board.sendElementsBackward(['layer-front'])
board.bringElementsToFront(['layer-front'])
const groupId = board.getElementParentChain('group-a')[0]
board.translateElement(groupId, { dx: 30, dy: 20 })
board.getContainerChildren(groupId)
board.disbandContainer(groupId)
```

These are editing recipes, not duplicate buttons. Reload the page to restore the authored specimens after experimenting; inspect each boolean return instead of assuming an already-at-boundary layer move changes anything.

The current beta.2 metadata Facade rejects some valid lock patches. Lock initialization therefore uses exported SetBoardElementsMetadataOperation through syncExecuteCommand(), not an invented Facade or host-only state. translateElement() must reject the locked example; verify native drag enforcement separately. Nested disband Undo can restore membership while changing sibling layer order; this known SDK defect is not hidden or considered fixed.

Stable element IDs: layer-back/middle/front; group-a/b/c; nested-a/b/peer; locked/unlocked. Group IDs are generated by the SDK. There are 15 authored shapes (11 specimens and four labels), plus three initialized containers. The page ID is gallery.
