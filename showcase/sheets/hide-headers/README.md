# Hidden row and column headers

`WORKBOOK_DATA` sets both `rowHeader.hidden` and `columnHeader.hidden` to `BooleanNumber.TRUE`. Native row numbers and column letters are hidden without CSS overlays. The six cell values named A1–C2 are cell content, not headers; the native grid remains editable.

The Preview and export share the factory and official Sheets Core CSS with the complete English preset locale. Theme changes update the same Univer owner and preserve the complete edited workbook. Disposal removes only this demo's root and owner and is idempotent. `window.univerAPI` exposes the real Facade.
