# Kestrel repair café — local CSV intake

The café imports repair tickets, parts inventory and volunteer shifts into a two-sheet workbook. The existing highlighted B4, formula in C4, wrapped F6 and tall row, protected-by-convention footer and separate Reference sheet make replacement and preservation visible in the native grid. The source contains seven distinct CSV/TSV samples; none are generated by the SDK.

Open CSV in the native ribbon opens the browser file picker. The source/options disclosure also contains the real file input so narrow screens can select files when the ribbon entry is outside the viewport. Both only stage UTF-8 text. Review the compact source/options disclosure, then Import at selection. The native grid owns selection, editing, navigation and history. Successful import closes the disclosure. There are no host target/reset/history buttons or raw-cell audit panels. Theme changes retain both the existing owner and the uncommitted draft.

## Parser contract

`csv-plugin/utils.ts` is the actual parser used by this demo. Papa Parse handles quoting, embedded commas, doubled quotes and embedded newlines with `dynamicTyping: false`. Ragged records are padded to the widest row. Skip-empty-lines does not trim whitespace-only records. `readCsvFile()` uses fatal UTF-8 decoding; UTF-8 BOM is accepted, invalid UTF-8/UTF-16 is rejected. The textarea normalizes CRLF to LF; sample downloads preserve original bytes.

The local limits are 1 MiB of UTF-8, 2,000 records, 100 columns and 10,000 rectangular cells. These are demo safeguards, not SDK limits. The initial sheets have 40 rows × 12 columns; imports must fit. Empty input, malformed quotes, unsupported delimiters and out-of-bounds writes are rejected before changing cells. Reading a file pauses the editor; rejected files preserve the draft and workbook. Cancel and repeated selection of the same file are supported.

`demo.importText()` is a **demo helper, not a CSV SDK API**. It calls the same parser, takes the single native selection's top-left, checks bounds, and calls `FRange.setValues()` once with `{ v, t: CellValueType.STRING, f: null, si: null, p: null }`. This replaces values/formulas/rich text inside the import rectangle while preserving formatting and outside cells. Native Undo is used, never a custom undo stack. This is not XLSX Exchange, file upload, workbook CSV export, type inference or automatic worksheet resizing. No backend is involved.

## Runnable examples

Use these blocks in `/src/index.ts`, after `await demo.ready`, where the mutable `demo` and `container` bindings already exist. For the parser/sample blocks, add these imports to that entry file. The independent test harness exposes the same real bindings; the normal export does not add testing globals beyond `window.univerAPI`.

```js
import { parseCsv, readCsvFile } from './csv-plugin/utils'
import { CSV_SAMPLES } from './data'
```

### 1. Inspect quoting without writing cells

```ts
const rows = parseCsv(CSV_SAMPLES[0].text)
console.assert(rows[1][1] === 'Radio, pocket')
console.assert(rows[1][4] === 'Needs "A" battery')
console.assert(rows[2][4] === 'Cable checked\r\nFuse pending')
```

### 2. Import the repair intake through the same host helper

```ts
demo.univerAPI.getActiveWorkbook().getActiveSheet().getRange('B4').activate()
demo.importText(CSV_SAMPLES[0].text.replaceAll('\r\n', '\n'))
```

### 3. Check native cell text and preserved formatting

```ts
const sheet = demo.univerAPI.getActiveWorkbook().getActiveSheet()
console.assert(sheet.getRange('B5').getValue() === '0007')
console.assert(sheet.getRange('F6').getValue() === 'Cable checked\nFuse pending')
console.assert(sheet.getRange('A14').getValue() === 'Keep this footer')
console.assert(sheet.getRange('B4').getBackgrounds()[0][0] === '#fef3c7')
```

### 4. Native history for one range write

```ts
await demo.univerAPI.undo()
await demo.univerAPI.redo()
```

### 5. BOM and semicolon inventory, with decimal commas left as text

```ts
const sample = CSV_SAMPLES.find((item) => item.id === 'semicolon')
demo.importText(sample.text, sample.delimiter)
```

### 6. Tab-delimited Unicode volunteers

```ts
const sample = CSV_SAMPLES.find((item) => item.id === 'tab')
demo.importText(sample.text, sample.delimiter)
```

### 7. Formulas and identifiers remain literal text

```ts
const sample = CSV_SAMPLES.find((item) => item.id === 'literal')
demo.importText(sample.text)
const sheet = demo.univerAPI.getActiveWorkbook().getActiveSheet()
console.assert(sheet.getRange('C5').getValue() === '=1+1')
console.assert(sheet.getRange('C7').getValue() === '12345678901234567890')
```

### 8. Ragged rows, explicit empty-line policy

```ts
const text = CSV_SAMPLES.find((item) => item.id === 'ragged').text
console.assert(parseCsv(text).length === 4)
console.assert(parseCsv(text, ',', false).length === 6)
demo.importText(text, ',', false)
```

### 9. Selection size is not an import size constraint

```ts
const sheet = demo.univerAPI.getActiveWorkbook().getActiveSheet()
sheet.getRange('D10:E11').activate()
const imported = demo.importText('Part,Qty\nLED-04,12\nCable,0')
console.assert(imported.getA1Notation() === 'D10:E12')
```

### 10. Invalid input must not write

```ts
const before = JSON.stringify(demo.univerAPI.getActiveWorkbook().save())
for (const text of ['', 'Item,Note\nLamp,"Unclosed note']) {
  let rejected = false
  try { demo.importText(text) } catch { rejected = true }
  console.assert(rejected)
}
console.assert(JSON.stringify(demo.univerAPI.getActiveWorkbook().save()) === before)
```

### 11. Local UTF-8 decoding, independent from importing

```ts
const text = await readCsvFile(new File(['\uFEFFPart,Qty\nLED-04,12'], 'parts.csv'))
console.assert(text === 'Part,Qty\nLED-04,12')
let rejected = false
try { await readCsvFile(new File([new Uint8Array([0xff, 0xfe, 65, 0])], 'utf16.csv')) } catch { rejected = true }
console.assert(rejected)
```

### 12. Preserve workbook and draft across themes

```ts
demo.setDarkMode(true)
demo.setDarkMode(false)
```

### 13. Download a complete workbook snapshot, not a CSV export

```ts
const snapshot = demo.univerAPI.getActiveWorkbook().save()
const url = URL.createObjectURL(new Blob([JSON.stringify(snapshot, null, 2)], { type: 'application/json' }))
const link = document.createElement('a')
link.href = url
link.download = 'kestrel-workbook.json'
link.click()
setTimeout(() => URL.revokeObjectURL(url), 1000)
```

### 14. Recover the complete owner with the same workbook ID

```js
const snapshot = structuredClone(demo.univerAPI.getActiveWorkbook().save())
const darkMode = demo.univerAPI.isDarkMode()
const locale = demo.univerAPI.getCurrentLocale()
demo.dispose()
demo = createDemo(container, darkMode, locale, snapshot)
await demo.ready
```

Workbook JSON includes all SDK snapshot fields/resources; no IDs, empty arrays or defaults are stripped during comparison. An uncommitted CSV draft is host state, not workbook JSON. Recovery resets that draft to the original intake sample and starts new history; theme changes do neither.

## Verification

Run the unchanged parser checks with `node scripts/test-csv-parser.mjs` and native tests with `node scripts/test-csv-import-native.mjs`. The default URL is `http://localhost:3030/en-US/playground/sheets/csv-import-plugin`; use `SHOWCASE_DEMO_URL` for a full override or `SHOWCASE_BASE_URL` for the guide origin. Full reconstruction and entry-scope literals need the standalone harness.

```powershell
$env:SHOWCASE_BUILD_STANDALONE = '1'
$env:SHOWCASE_VITE_DIRECTORY = 'C:/Users/wbfsa/AppData/Local/Temp/univer-aster-formula-SHm1UE/node_modules/vite'
$env:SHOWCASE_RESULTS_DIR = 'test-results/csv-import-native'
node scripts/test-csv-import-native.mjs
```

Only this case is built, using exact installed dependency versions without installation. Tests close port 4416 and retain complete snapshot differences as strict failures. OS-level file-dialog Cancel cannot be automated here; its browser cancel-event contract is tested separately.

The current SDK restores visible values but does not round-trip every field exactly: import Undo/Redo interns inline background/wrap styles into new style IDs; Undo also adds an explicit text type. Native text-edit Undo adds a style entry and explicit text type. Full owner recovery changes the defined-name resource from an empty string to `{}`. These remain strict FAIL checks, even where the grid looks unchanged. The test does not normalize resources, styles, IDs or cell types to make history/restoration pass.
