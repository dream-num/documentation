# Fonts, fallback and glyphs

View defaults to fitting the native page width (up to 100%); choose 100% for native horizontal scrolling and detailed glyph inspection. A ResizeObserver reapplies fitting on editor resize, and mount fits to the current width. This calls the installed `SetDocZoomRatioOperation` through `FUniver.syncExecuteCommand()`; it is not CSS scaling and does not change point sizes or page geometry. Zoom is stored in the SDK snapshot, but the host view choice reapplies on reload/Reset; compare full snapshots at the same viewport and view choice. The view selector is not a font-style variant. Native toolbar zoom remains usable until the next container resize or mount.

On installed 1.0.0-beta.2, calling the range style setter directly does not create native history. This example explicitly registers `demo.command.alder-text-style` with `ICommandService` and invokes it with the real `FUniver.syncExecuteCommand()` Facade. Its handler calls `FDocumentTextRange.setTextStyle()`; the SDK command boundary supplies the mutation trigger required by native Undo/Redo. This is an example-defined command, not a built-in font command or a separate snapshot history. The exported code includes the registration. History availability also subscribes to SDK history changes, including deferred native typing.

The native table plugin requires a Pro license; trial notices/watermarks may appear without an applicable license. The demo does not hide them.

Run `pnpm install` and `pnpm dev`; verify the independent build with `pnpm build` and `pnpm preview`. Preview and standalone use one factory, including the official Docs Core, Docs Drawing and Docs Table UI stylesheets. No remote fonts, proprietary font files or backend are included.

The original Alder Archive report has twelve authored chapter-page boundaries, a native acquisition table and an embedded baseline reference figure. Six sample paragraphs cover Latin, CJK, Arabic/Hebrew, accents, symbols and a private-use glyph. Native footnotes/endnotes from the larger blueprint remain unimplemented; source notes are explicitly ordinary text. Font changes may repaginate the report.

Apply font family calls `FDocumentTextRange.setTextStyle({ ff })`; Apply size and weight patches `fs` (points) and `bl`. The host accepts 8–32 pt, not a claim about every SDK limit. Selected-sample scope resolves its unique `[ID]` marker on each action; whole-report scope includes headings and table text. Selection calls `FDocument.setSelection()`, and history uses `undo()`/`redo()`. Missing or duplicated markers disable the sample target. An invalid range exercises the real Facade guard without mutating the snapshot. Readback combines public range getters with native skeleton geometry, labeled as requested font properties rather than actual per-glyph fallback identity.

Local `FontFace(..., 'local(...)').load()` probes distinguish a resolvable regular primary face from a missing local face. Probes do not register replacement fonts. Missing-primary uses an explicit `Georgia, serif` fallback. A resolved face, nonzero glyph width or `document.fonts.check()` is not a coverage certificate: [MDN explains that check() may succeed for nonexistent fonts and does not check individual glyph coverage](https://developer.mozilla.org/en-US/docs/Web/API/FontFaceSet/check); see also [FontFace.load()](https://developer.mozilla.org/en-US/docs/Web/API/FontFace/load). Inspect RTL joining/order, accents and missing symbols in the actual editor. The private-use U+10FFFD character has no universal expected glyph. No missing glyph is replaced by an HTML image.

Initial reference-figure construction follows the existing SDK drawing command pattern; no demonstration button claims a nonexistent image-insertion Facade. The native table is created through its table Facade. State/Reset/theme replace current edits and history; reload/download uses the full current snapshot. JSON is not PDF/Word output. The authored review date is fixed, not the global SDK clock. Licensed embedded fonts, script-specific cross-platform metrics, full RTL/native accessibility and pending-operation lifecycle acceptance remain separate work.
