自訂元件

Univer 提供了多種方式來整合自訂元件，使你能夠擴充並客製化 Univer 的功能。本指南將介紹幾種常用的方法。

在 GitHub 上編輯

Univer 並不會直接將元件作為參數直接傳遞給任何渲染函式，你需要透過 Facade API 將元件註冊到 Univer 中之後，才能在各個掛載點使用它們。

如果你還不瞭解如何獲取 Facade API 的例項，可以參考 Facade API。

註冊自訂元件

使用 univerAPI.registerComponent 方法來註冊自訂元件。此方法接受三個參數：

  • componentKey: 元件的唯一識別符，用於在 Univer 中引用該元件。
  • CustomComponent: 元件的實現，可以是 React、Vue 或 Web Components。
  • options: 可選的配置選項，用於指定元件所依賴的框架或其他相關設定。
