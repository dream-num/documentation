公式

在 GitHub 上编辑

公式是 Univer 提供的核心能力之一，它可以让你在单元格中使用公式来计算数值，公式支持的函数和 Excel 一致，包括数学、逻辑、文本、日期等等。

如果工作簿中的公式数量较多，公式计算可能占用主线程并导致页面卡顿。建议将公式计算放到 Worker 进程中执行，以降低对页面渲染和交互的影响。具体配置方式请参考 Web Workers 章节。
